Foundry 构建模块

Foundry 的每一层都致力于以日益增长的复杂性和雄心交付业务成果这一目标，其软件定义的反馈回路贯穿数据、分析和业务团队。

  • 数据集成
  • 模型集成
  • 本体论
  • 工作流
  • 决策编排

数据集成

对所有数据源进行安全、可扩展且有韧性的集成。

[01] Foundry 数据连接

  • 200+ 数据连接器，采用可扩展的基于插件的范式

  • 灵活的入口拓扑，可利用基于代理、REST、JDBC 等多种方式

  • 易于配置的调度、成功标准和权限模型

  • 多模态（结构化、非结构化、流式、IoT、地理空间等）

[02] 数据转换

  • 灵活的架构，内置引擎（Spark 和 Flink）

  • 低代码/无代码转换（Preparation、Contour）

  • 像对待代码一样对待数据（版本控制、分支、完整的变更管理）

  • 通过 Job Spec 范式实现完整的溯源

[03] 管道编排

  • 与引擎无关的构建系统

  • 跨所有管道的智能刷新/状态跟踪

  • 与 Foundry 的健康监控无缝集成

[04] 安全

  • 基于角色、分类、目的的范式

  • 与现有授权模型集成

  • 默认传播；极高的可配置性

[05] 血缘

  • 与安全范式交织；提供不可变的跟踪

  • 支持影响分析和细粒度的使用分析

  • 丰富的 API 支持针对给定资源进行上游和下游导航

[06] 健康检查

  • 预置检查和可自定义检查

  • 利用 Foundry 的血缘系统进行告警和影响分析

  • 通过与 Foundry Issues 集成，实现完整的分类和跟踪

模型集成

模型和业务逻辑的灵活集成（或注册）。

[01] Code Workbooks

  • 用于模型构建的集成式端到端工作台（PySpark、R、SparkSQL）

  • 为模型构建者提供原生的安全数据访问（数据集和本体论范式）

  • 集成的模型训练、健康和管理服务

  • 灵活的部署选项，可用于运营（批处理和推理）

[02] 外部模型集成

  • 在任何行业标准工具集中构建和训练您的模型

  • 通过 API 驱动从这些外部工具连接到本体论

  • 准备就绪后，通过 Foundry 推广到生产环境

[03] 模型目标

  • 针对整个 Foundry 工作流中所使用模型的“任务控制”

  • 丰富且有竞争力的模型评估；比较性能

  • 直接绑定到本体论，为模型提供“类型系统”——使其能够在无数运营场景中被利用（而无需将负担转嫁给应用构建者）

本体论

将核心逻辑与数据相连接，创建整个企业的数字化呈现。

[01] 核心本体论

  • 包含您世界的关键语义（对象和关系）

  • 包含您世界的关键动态（函数、操作）

  • 集成的监控，以及与外部系统的可扩展性

[02] 决策捕获/回写

  • 将最终用户的数据捕获回本体论的结构化机制

  • 将数据捕获传播到外部系统的原生框架

  • 外部系统的响应可以融入多步骤工作流

[03] 开箱即用的对象探索

  • Object Explorer 提供了对本体论的安全、可扩展的点击式视图

  • Quiver 提供了基于图表的范式，支持（在众多工作流之中）对多维实时流数据的导航

  • Map 提供了用于探索本体论的地理空间画布

  • 每个“基础”应用都配备了持续更新的组件库

[04] 运营的基础（预告）

  • Workshop 和 Slate 是利用本体论的端到端应用构建器

  • 本体论原生支持“场景感知”，支持假设分析和运行复合模拟

  • Objects Gateway 以及其他众多 API，支持在外部工具集和框架中利用本体论

工作流

开箱即用的分析、报告和运营决策能力。

[01] 将分析演进为工作流

  • Object Explorer 旨在整合操作（Actions），将探索演进为工作流

  • Quiver 支持派生新的对象集，以及实时数据的派生流

  • Taurus 提供了一种以业务为中心的规则集定义和管理方法

[02] Workshop

  • Foundry 的原生无代码/低代码应用构建器，基于本体论（Ontology）运行

  • 管理底层的存储、计算、本体论数据和模型绑定以及安全范式——让应用构建者专注于构建本身

  • 在用户工作流复杂度方面设计为“低门槛、高上限”——从面向小团队的精简应用，到运营中心核心的关键任务应用

[03] Slate

  • Foundry 的所见即所得（WYSIWYG）小部件驱动开发解决方案

  • 利用核心 JavaScript 范式，旨在让前端开发者感到熟悉

  • 可灵活地与本体论数据以及表格/SQL 形式的数据进行交互

[04] API / 可扩展性

  • Objects Gateway 为构建者提供对本体论的安全、全方位访问

  • 自定义 Web 钩子和回写流程可以直接在 Foundry 的应用中编写

  • Foundry 的第三方授权框架允许外部客户端应用注册到平台，并充分利用 Foundry 的细粒度安全范式

决策编排

将决策同步回源系统。

[01] 场景与模拟（框架）

  • 像对待代码一样对待您的业务；分支、模拟，并进行全规模探索

  • 模拟可以利用所有类型的模型，包括高维线性求解器

  • 模拟可以是战术性的，也可以是长期运行的，并随数据和模型一起刷新

[02] Vertex

  • Foundry 开箱即用的应用，用于对本体论进行图/关系探索

  • 支持轻松创建新场景，并模拟“假设（what-if）”条件

  • 支持将多个模型串联在一起的复杂模拟

[03] 场景与假设分析的普及化

  • 在分析探索（例如在 Vertex 中）中定义的场景，可以被打包、约束，并呈现给更多运营用户（例如使用 Workshop）

  • 所有模拟数据和场景状态都可以通过编程方式访问

[04] 将决策同步回外部系统

  • Foundry 的“操作（Actions）”框架提供了一种结构化、安全且可审计的机制，用于将决策（及其他数据）发布到外部系统

  • 数据导出利用 Foundry 数据连接框架的所有能力

  • 从数据到决策的完整血缘得以维护，使组织在特定数据或元数据被写入外部时，始终能够追问“当时世界的状态是什么？”
