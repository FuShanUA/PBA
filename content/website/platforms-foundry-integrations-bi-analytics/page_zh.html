Foundry + BI / 分析工具实践

  • Foundry 与 Power BI® 的集成
  • Foundry 与 Tableau 的集成
合作伙伴
Power BI®
解决方案

使用 Foundry Power BI 集成工具将数据从 Foundry 直接摄取到您的 Power BI® 报告中。Power BI® 连接器 + ODBC 驱动程序支持与 Foundry 直接连接——并利用您已集成的 SAML IdP。

运作方式

与 Power BI® 的集成由两个组件组成。连接器在 Power BI® 内提供自定义界面，用于浏览和加载用户可用的 Foundry 数据集。在 Power BI® 中选择数据集后，实际的数据请求会委托给 ODBC 驱动程序组件。该驱动程序实现了用于与数据库通信的 ODBC 规范。Power BI® 原生支持与 ODBC 驱动程序通信，并针对用户选择加载的任何数据集向驱动程序发送查询。然后，驱动程序将这些查询发送到 Foundry，查询经计算后返回。

合作伙伴
Tableau
解决方案

使用 Foundry Tableau 集成工具将 Foundry 的数据直接连接到您的 Tableau 仪表板中，轻松创建由 Foundry 数据支撑的 Tableau 交互式仪表板。

运作方式

该集成利用 Foundry 访问控制，包括细粒度权限和受限视图。连接器支持 Tableau Desktop 和 Server、Tableau Online（通过 Bridge），以及基于令牌和 OAuth 的身份验证选项。
