Palantir Foundry 为集成而生。

自 2003 年以来，我们持续投入集成基础设施建设，用于连接广泛使用的企业软件，以及定制化和行业专用系统。

Foundry 为数据管道、AI/ML、分析、应用构建等提供安全、大规模的集成能力；使您能够在充分利用我们平台的同时，兼顾现有和未来的技术投资。

04 /

安全 [+] 身份验证

Foundry 的第三方应用程序身份验证和授权功能使非 Foundry 应用程序和脚本能安全地与 Foundry 的 API 交互。

OAuth2.0

入站 — 第三方应用程序在基于 Foundry API 进行构建时，可以使用 OAuth2.0 向 Foundry 进行身份验证。
出站 — Foundry 在连接第三方系统时也提供对 OAuth2.0 的一流支持，以带来更流畅的用户体验。

自定义身份验证

对于从 Foundry 到外部系统的出站请求，支持多种其他身份验证方法。原生连接器会根据目标系统推荐的身份验证方式进行定制，无论是使用 API 密钥、服务账户、JWT 认证还是其他方式。
