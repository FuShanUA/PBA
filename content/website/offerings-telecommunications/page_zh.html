面向电信行业的 Foundry

全球领先的电信公司中，有许多正在使用 Palantir 软件，帮助其在大规模范围内推动整个业务的数字化转型。

Foundry 为您的 CSP 各个环节的运营分析提供支持，使现场工程师、质量分析师和网络运营中心经理能够进行预防性维护、打造零接触网络，并快速解决供应商问题。

专为满足电信行业的需求而设计

  • 01 / 开放与可互操作

    Foundry 开放、可互操作且模块化 —— 能够与现有基础设施无缝集成，并消除传统软件产品中常见的锁定风险。

    通过使用开放的数据格式和语言，Foundry 确保在尽可能广泛的范围内保持可用性。所有代码均通过安全的 Git 仓库进行版本控制，并可供外部使用和复用。

    Foundry 还提供文档完善的 REST API，可用于与构建系统交互、管理数据健康，以及从第三方应用探索元数据、数据血缘和 Foundry 生态系统中的其他信息。

  • 02 / 支持本地部署与云原生

    Palantir 软件既可以作为云原生 SaaS 服务部署，也可以作为完全托管的本地部署解决方案。两种方案均提供同样世界一流的技术，帮助您实现数据与分析的运营化。

    我们的 Foundry 平台可作为 SaaS 服务运行在大多数超大规模云服务商的基础设施之上：Amazon Web Services (AWS)、Google Cloud (GCP)、Microsoft Azure 或 Oracle。对于任何这些数据系统，Palantir 都充分利用云优先技术，例如模块化微服务架构、自动扩缩容和分布式计算。

    对于已承诺使用 GCP 的电信运营商，Foundry 可直接通过 Google Marketplace 获取，因此 GCP 客户在商业和技术上都能受益：Foundry 的许可和消耗量可直接抵扣客户现有的承诺额度。

  • 03 / 第一天即创造价值

    从第一天起，Foundry 就能让电信运营商针对其最紧迫的挑战部署专家级质量的应用 —— 从智能故障预测、更精准地定位客户问题的根本原因，到改进开通和从线索到回款流程。

    Foundry 提供先进的专利技术和一系列专为优化电信运营而设计的开箱即用应用，使客户能够在数天（而非数月）内定制并向用户部署解决方案。

  • 04 / 为 GDPR 及更高要求而构建

    在一个监管和隐私限制严格的行业中，电信运营商需要强大的数据保护能力。

    Foundry 的一系列隐私和安全功能使电信运营商能够跟上 GDPR 和 CCPA 等法规所规定的不断演变的监管要求，甚至超越这些要求，以保护个人客户的隐私和身份。

    除标准访问控制外，Foundry 还允许用户应用动态数据最小化程序，例如假名化以及基于目的披露的加密，以满足相关数据保护法规的复杂要求。
