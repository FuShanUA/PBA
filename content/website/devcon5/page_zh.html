Agent Studio

AIP Agent Studio 允许用户构建交互式助手——称为 AIP Agents——它们配备企业专属的信息和工具，可在平台内部部署，也可通过本体论 SDK 和平台 API 对外部署。

智能体由大语言模型、本体论、文档和自定义工具驱动，并可集成到应用程序中，以促进动态的、具备上下文感知的读写工作流。

基于 Palantir 严格的安全模型，智能体仅被授予完成任务所必需的访问权限。

Pilot 是一个 AI 驱动的应用程序构建器，让你能够使用自然语言提示词，基于你的本体论创建全栈应用程序。

无需分别定义对象类型、编写操作类型、设计 UI 和连接 OSDK 钩子，Pilot 可处理完整的开发生命周期——从描述到可部署的应用程序——让你专注于构建什么，而不是如何构建。

当你的应用程序准备就绪时，Pilot 会提供引导式部署工作流，将其发布为生产托管的应用程序。

时间序列

时间序列数据是随时间推移进行的一系列测量，通常以固定间隔进行——例如每日航班总数、每小时产量，或亚秒级分辨率的高频温度读数。

要在 Foundry 中使用数据进行时间序列分析，你需要设置两个组件：一个时间序列对象类型，用于定义数据集的元数据并允许 Foundry 应用程序访问数据；以及一个时间序列同步，用于索引数据并为时间序列属性提供值。配置完成后，时间序列数据可以在 Foundry 应用程序（包括 Quiver、Vertex 和 Workshop）中进行可视化和分析。

AIP Analyst

AIP Analyst 是一个用于智能体工作流的界面，让你能够使用自然语言在本体论中执行临时分析。

你可以向 AIP Analyst 提问，智能体将自主搜索你的本体论、创建对象集并转换数据，然后生成摘要和可视化。

它支持一系列分析功能，包括地理空间过滤、SQL 查询、本体论聚合以及交互式 Vega 图表可视化。
