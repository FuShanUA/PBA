运作方式

Pipeline Builder 以速度和简洁为核心设计理念。

无需再为编写代码、维护库、运行构建和管理仓库复杂性而烦恼——专注于真正重要的项目。

  • 添加数据
  • 转换数据
  • 通过分支进行协作
  • 合并更改
  • 部署

添加数据

  • 要开始使用 Pipeline Builder，只需在 Palantir Foundry 中选择数据集即可。

  • Foundry 可以轻松地从任何源系统摄取数据——包括结构化、非结构化、物联网和地理空间源系统。

  • 此外，您也可以将原始文件拖放到 Foundry 中，快速完成一次性上传。

转换数据

  • 添加数据集后，您无需使用代码即可对其进行转换。

  • 借助 Pipeline Builder 强大的点击式函数集，您可以将原始 XML、JSON、PDF 等格式解析为结构化表格，并通过连接和合并操作组合数据集。

  • 您还可以对数据应用丰富且不断扩展的函数集，包括：清洗、转换、派生、透视、加密、聚合和过滤。Builder 还能处理图像、计算地理空间距离、执行金融运算等。 

通过分支进行协作

  • 如果您要为现有管道做贡献，可以创建一个分支，在隔离环境中安全地工作，而不会影响管道的主版本。 

  • 用户可以跨多个分支进行协作，甚至可以创建分支的分支。这种分支灵活性支持快速并行迭代、新功能开发、错误修复以及其他管道改进。  

合并更改

  • 当您完成分支上的工作后，可以提议将更改合并回您创建分支时所基于的管道（或分支）。并排比较可以准确显示更改的内容。 

  • Pipeline Builder 会检查是否存在任何合并冲突——包括由其他用户编辑与您相同的转换所导致的冲突——并提示您予以解决。

  • 您随时可以访问先前版本、编辑和合并的完整历史记录——从而实现大规模协作并自信地进行迭代。

部署

  • Pipeline Builder 会对整个管道进行即时检查，确保您提议的逻辑生成所有必需的列——防止导致代价高昂的停机错误。 

  • 验证通过后，合并即完成，分支将被部署以生成更新后的管道输出。

  • Pipeline Builder 可以部署到多种输出——包括批处理、流式处理、Palantir Gotham、时间序列和建模。 

  • Builder 会引导您完成整个过程。例如，如果您选择时间序列目标，Builder 将引导您完成所需的输入，例如每个序列的单个数据点和元数据。这些引导让您专注于逻辑本身，而非实现细节。 

为速度、规模与稳定性而设计

独立的管道逻辑

Pipeline Builder 可以连接到不同的逻辑执行引擎，包括 Spark、Flink 等。

完整的版本控制

版本管理和分支功能支持实验探索，帮助您自信地进行部署。

可复用的逻辑

Pipeline Builder 让您能够轻松提取和复用不同管道的管道逻辑，帮助节省创建新管道的预算和时间。

类型安全函数

函数具有强类型，可以在构建时之前立即标记错误，防止导致昂贵修复和代价高昂停机的中断。

抽象实现细节

用户专注于描述其端到端管道和期望的输出。构建、同步和其他编排都在后台处理。

严格的输出目标

如果未达到预期的输出目标，将阻止部署，以避免意外的下游中断。

内置安全

Pipeline Builder 融入了细粒度的安全检查和 Git 风格的变更管理——同时不牺牲速度或易用性。

互操作性

凭借强大的导出代码功能以及从头开始设计为运行时无关的架构，避免锁定。
