集成类型

数据集成

与其他系统之间同步数据，并在中间加入逻辑、模型和人工决策。

Foundry 旨在整合来自整个组织的数据并将其运营化。我们的客户已从各种来源集成数据，包括常用的数据库和数据仓库技术，以及数百个包含日常业务运营宝贵记录的定制系统。

用例：

  • 批量数据加载和导入

  • 批量数据导出（反向 ETL）*

  • 外部管道集成*

*并非适用于所有系统

应用程序集成

通过外部集成增强在 Foundry 中构建的应用。

构建数据丰富的应用程序，支持与任何运营系统、应用或服务的实时交互。开发者只需在 Foundry 中托管的单个应用程序，即可快速构建与定制系统以及广泛使用的 SaaS 服务商的安全且可扩展的集成：从用于实时消息传递的 Twilio 和 Slack，用于支付的 Stripe，用于 CRM 的 SAP 和 Salesforce，到用于运营的 JIRA 和 PagerDuty。

用例：

  • 集成来源 来运行该专业代码代理。你还可以通过 / 将收集到的信息存储在 至外部应用程序

  • 通过启用第三方集成来增强 Foundry 的原生功能

流式集成

以低延迟和高吞吐量将数据流式传输到 Foundry，以支持实时决策。

Foundry Streaming 允许拥有流式数据源和基础设施的客户，将这些数据与在 Foundry 中构建和部署的非流式数据及模型结合使用。

用例：

  • 从流式源或消息队列拉取数据

  • 将数据从流式源直接推送到 Foundry

  • 出站流式传输 [即将推出]

数据科学集成

利用现有的模型投资，并使用 Foundry 将模型集成到运营决策流程中。

外部开发的模型可以导入 Foundry，或通过与外部 API 集成来调用，从而将输出提供给最终用户、管道和运营应用程序。

用例：

  • 通过开源工具（如 scikit-learn、TensorFlow 和 OR-tools）或自定义库在平台内开发模型

  • 从外部环境导入模型（如笔记本、第三方数据科学产品或容器注册表）

  • 通过外部托管的 API 调用模型，处理托管在 Foundry 中的数据

分析集成

从第三方工具连接到 Foundry，以查看数据并与数据交互。

浏览第三方连接器，详细了解哪些系统通过专用连接器与 Foundry 提供开箱即用的连接。

用例：

  • 将 Foundry 中的精选数据集成到外部报告和商业智能应用程序中

  • 安全地对存储在 Foundry 中的数据使用第三方分析工具

注意： 原生连接器由 Palantir 构建，并不表示 Palantir 的官方合作伙伴关系或协作。 对特定系统的支持因集成类型和外部系统提供的接口而异。并非所有列出的系统都通过专用连接器提供支持，也并非所有系统都支持全部集成功能。
