通过 OSDK 利用 Defense 本体论

Defense 本体论对以下各项职能的基础作战数据进行标准化，为国防科技开发者提供一致的本体论软件开发工具包（OSDK）。
  • 抽象数据模型
  • 类 API 功能
  • 受作战条令启发的设计
  • 基于实战经验构建
  • 跨项目兼容性

抽象数据模型

抽象数据模型

Defense 本体论包含一组抽象类型，可应用于 Foundry 环境中的具体数据。

类 API 功能

类 API 功能

当抽象类型应用于 Foundry 数据时，Defense 本体论实际上起到了 API 的作用，支持在不同环境和网络间实现一次构建、随处部署的能力。

受作战条令启发的设计

受作战条令启发的设计

本体论结构的设计灵感来自成熟的军事条令，尤其是 CJADC2 作战职能。

基于实战经验构建

基于实战经验构建

Defense 本体论融合了众多国防部项目中的经验教训和最佳实践。

跨项目兼容性

跨项目兼容性

旨在与所有主要国防部项目工作兼容，确保一致性和互操作性。

严格必要 Cookie

始终处于活动状态

这些 Cookie 是网站运行所必需的，无法在我们的系统中关闭。它们通常仅在您发出服务请求的操作（例如设置您的隐私偏好、登录或填写表单）时才会被设置。您可以将浏览器设置为阻止这些 Cookie 或在出现这些 Cookie 时提醒您，但网站的部分功能将无法正常使用。这些 Cookie 不会存储任何可识别个人身份的信息。

定向 Cookie

根据美国隐私法律，您有权选择退出向第三方出售或共享您的个人信息。这些 Cookie 收集信息用于分析，并通过定向广告个性化您的体验。您可以使用此切换开关行使退出出售或共享个人信息的权利。如果您选择退出，我们将无法为您提供个性化广告，也不会将您的个人信息移交给任何第三方。此外，作为加利福尼亚州消费者，您可以通过此“行使我的权利”链接联系我们的法务部门，以进一步了解您的权利。如果您在浏览器中启用了隐私控制（例如插件），我们必须将其视为有效的退出请求。因此，我们将无法通过网络跟踪您的活动。这可能会影响我们根据您的偏好个性化广告的能力。
