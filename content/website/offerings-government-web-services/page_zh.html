什么是 PGWS？
Palantir Government Web Services (PGWS) 包含三项初始产品——Apollo、FedStart 和 Ontology SDK——帮助国防科技创新者利用我们积累的宝贵经验，更快地实现从 0 到 1 的突破。
PGWS 适合谁？
PGWS 服务于整个国防科技生态系统，为开发者提供所需的工具，让他们今天就构建、交付和管理明天的创新解决方案。
如何开始使用？
无论您已经在向政府推广解决方案的旅程中，还是刚刚起步，我们都能帮助您加速迈向一线。

01 Apollo：随处部署

扩展实例而无需扩展 DevOps

Apollo 可在异构环境中部署、监控、修复和保护您的软件。它能在数小时内让您对软件部署全局实现可视化和运营洞察，同时简化复杂的部署管道。

  • 数小时内了解您的软件部署全局 → 自动发现与软件控制中心

    • Apollo 让您对整个部署全局拥有完全的可视性和控制力，从而对您的软件充满信心。

  • 可靠地部署软件并管理发布 → 持续部署

    • 快速、可靠、轻松地部署新功能，让您把时间花在创新上，而不是编排上。

  • 高效支持您的软件 → CD + Day 2 运维

    • 在部署的每个阶段，通过安全性、变更管理和可靠性保持控制。

  • 将安全设为默认，强化合规 → SecOps

    • 通过集成的 SecOps 增强信心：持续漏洞扫描、可操作的结果、自动召回/回滚，以及自动执行的安全策略

02 Ontology SDK

加速数据访问

  • 快速开发应用

    • 只需极少的代码即可访问本体论，从而快速开发应用程序。

    • 更好的开发者体验意味着更好的应用程序，以及与运营用户之间更快的反馈循环。

  • 绝不被锁定

    • OSDK 降低了数据层和应用层的切换成本——这对真正的互操作性至关重要。

    • 可以通过 Ontology API 开发和部署新的可互操作应用程序，而脱离 Palantir 的切换成本仅限于其他供应商通过 API 将数据拉入其平台的部分。

  • 值得信赖的合作伙伴

    • 对于政府机构和符合条件的公司，我们可以提供一个低侧环境，使用概念性数据针对特定用例基于实际本体论进行开发。

    • 实际应用： 陆军和太空部队使用 OSDK 构建应用程序并提供可扩展性。了解更多关于我们的工作。

03 FedStart

消除认证障碍，轻松部署。

FedStart 帮助公司满足 FedRAMP 和 IL 合规要求，在数周内快速实现认证，成本仅为传统途径的一小部分。

运作方式

  • 让创新者通过三个简单步骤，在 Palantir 安全且已通过认证的环境中运行其产品：

    • 将您的应用程序容器化并创建 Helm chart

    • 使用以下方式部署您的应用程序 Apollo 部署到 FedStart 环境中

    • 完成安全集成

为什么选择 FedStart？

  • 无缝集成

  • 基于用量的定价

  • FedRAMP 和 IL5 合规由 Palantir 管理。

  • 政府 ATO 沟通、合规工件、持续监控和控制评估均由 Palantir 管理。
