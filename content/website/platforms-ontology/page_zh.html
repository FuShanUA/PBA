通过 Ontology MCP 为外部智能体赋能。

Ontology MCP 将您的本体论原语以 MCP 工具的形式暴露给外部智能体。外部智能体和系统可以读取对象、查询数据并执行预定义操作。治理 Palantir 原生智能体的安全控制同样适用于外部智能体，随着您的智能体生态不断扩展，实现对本体论的可信交互。
