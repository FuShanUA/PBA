软件定义系统集成 (SDSI)

通过连接并维护跨硬件能力的数据、AI 模型和软件，赋能未来的部队。

为明日的作战人员提供动力

正在进行现代化转型的组织日益需要在体系 (system of systems) 之间集成各种创新成果，这要求它们克服由此产生的复杂性：

  • 成本效率低下 由于大量的代码库维护以及手动数据和软件集成而不断放大。

  • 互操作性受限 原因是开放标准种类繁多。

  • 无法承受的计算需求 源于重复的数据处理工作流。 

  • 全系统混乱 由于缺乏单一事实来源，不同组件从不同数据源获取数据，损害了一致性。

  • 供应商锁定风险 因为无法查看和验证模块化开放系统方法 (MOSA) 标准。

工作原理 → 功能特性

Palantir SDSI 帮助组织快速采购、升级、迭代并向作战人员交付能力，从而释放新的效率。

本体论

SDSI 将各种不同的特定开放标准抽象化，将所有可用信息统一为一种可配置的通用开放语言。该语言将由组织拥有，并随时间不断演进。

干净的数据

SDSI 只对数据进行一次清洗、简化和融合。这节省了稀缺的计算资源，并生成一个可供所有租户使用的统一数据资产。

单一事实

SDSI 通过既定的世界观创建单一事实来源，作为模块化应用可通过开放 API 自动连接的基础基线。AI 模型可以基于共同的理解获取数据，从而产生连贯一致的结果。

自动化处理

提供可将传入数据流自动转换为单一、可配置开放格式的工具，创建一个任何集成系统或应用均可通过符合 MOSA 标准的 API 访问的通用世界观。

节约成本

通过提供以可预测的成本简化自动能力集成的工具，降低支出并缩短交付时间。

解决方案 → 能力

SDSI 补充了开放标准的固有优势，通过连接并维护跨硬件能力的数据、AI 模型和软件，赋能未来的部队。

软件管理

支持团队跨环境及边缘构建、持续部署和保护软件的软件。

数据管理

工具 用于将传入数据流自动转换为单一、可配置开放格式，创建一个任何集成系统或应用均可通过符合 MOSA 标准的 API 访问的通用世界观。

人工智能 (AI) 管理

针对边缘平台上的 AI 模型进行编排，确保合适的模型在合适的时间和地点处理合适的传感器数据，无论需求和依赖关系如何。

统一管理界面 (UMI)

一个易于访问的用户界面，将所有 SDSI 组件整合在一起，提供一个用于管理体系内所有系统、应用和数据的单一仪表板。
