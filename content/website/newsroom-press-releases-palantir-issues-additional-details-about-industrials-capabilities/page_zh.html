Palantir Issues Additional Details About Industrials Capabilities to be Shown at “Double Click” on Wednesday, April 14, 2021

播放视频

丹佛--(商业资讯)--Palantir Technologies (NYSE:PLTR) 今天发布了其将于2021年4月14日星期三上午11点（美国东部时间）在“Double Click”工业演示中重点展示的 Palantir Foundry 功能的更多细节。

Palantir 在工业领域的客户涵盖汽车、分销、重型制造、化工、公用事业等行业。这些客户依靠 Foundry 来优化运营和维护、预测网络健康状况，并应对突发事件。

在首期 Palantir 的 Double Click 系列中，工程师将演示实现这些工作的最新功能：

  • 链式模型仿真。 Foundry 可协调所有组织领域的数据模型，从而在 IoT 时间序列数据与支撑元数据之间建立语义关联。随后，该本体论可用于为反映组织实际运营的模型提供输入，而模型的输出又会回到本体论中。为了理解决策的全面影响，这些模型可以串联在一个数字孪生中，用于实时适应事件，或对未来事件进行严格的仿真。通过将模型构建与运营统一在一个平台中，任何洞察和优化都会贯穿于组织的日常决策。

  • 无与伦比的分析计算范围。为了克服本体论和时间序列数据上复杂但缓慢的查询与简单但快速的查询之间的常见权衡，Foundry 的查询优化器会重写分析查询，将算子下推到数据端，无论数据存储在“热”存储还是“冷”存储中。这意味着查询的执行性能更好、资源占用更小。此外，无论查询是通过 API 提交的、来自模型的，还是通过 Foundry 中的图形分析应用程序提交的，优化器都可供所有查询使用。这使客户能够实时查询多达数万亿条传感器读数。

  • 无需权衡的动态编排。 Foundry 提供已摄取到平台中的所有 IoT 时间序列数据。这些数据可通过最终用户 API 和多种工具轻松获取，而无需承担将所有数据存储在高性能存储中的成本。传统时间序列系统迫使客户在两种方案之间做出权衡：将数据保存在经过优化但昂贵的“热”存储中，或将归档数据卸载到更便宜的“冷”存储中（在冷存储中数据无法再被查询）。Foundry 的“热”/“温”系统通过按需自动将归档数据水合到热存储中，消除了这种权衡。使用 Foundry，客户在机器生成的数据上实现了高达 50 倍的压缩比（取决于初始格式）。这使得其资本资产配备数千个传感器的工业客户——例如飞机、油井和制造工厂——能够每秒流式传输和摄取数百万个新数据点。

除了这些功能之外，Palantir 还将重点介绍在 Foundry 之上提供的两个新原型（Archetype），使工业客户只需点击几下即可使用这些功能，包括：

  • Foundry 的质量原型（Quality Archetype） 使客户能够快速识别新出现的问题、加快根本原因分析、管理预测性维护、在提高召回准确率的同时降低保修成本，并在投入成本高昂的生产或供应链变更之前，对更换原材料或提高产量等变更进行数字化仿真。

  • Foundry 的供应链原型（Supply Chain Archetype） 使客户能够预测网络健康状况、针对潜在问题生成预警警报、通过算法比较和优化供应链场景、应对持续的冲击，并监控成本、准时率和二氧化碳排放量等关键 KPI。
