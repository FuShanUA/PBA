Agent Stack

"If we want to build meaningful agents that are doing real work, We need to be able to understand their work and build trust before increasing their autonomy."

Palantir Software Engineer Ankit Shankar unveils the Agent Stack, a set of products to help you build production agents for the enterprise, all built on the Ontology.

  • Orchestrator for durable execution

  • Agent Engine and Agent SDK for building agents of any shape

  • Agent Manager for actionable telemetry and observability

  • AIP Evolve for continuous, end-to-end optimization

Watch a simple agent get stress-tested against the real world — race conditions, human approvals, mid-task crashes — and see why trust, not intelligence, is what actually separates a good demo from a production agent.

Orchestrator

"The bottleneck for an agent's usefulness today is not intelligence. It's trust."

Palantir Group Lead John Mathews launches Orchestrator, the durable execution layer that lets agents crash, recover, wait, and resume exactly where they left off. Watch a patient discharge agent get torn down mid-task and rehydrate days later with zero lost state, zero duplicate side effects, and zero compute burned while it waits on a doctor's sign-off.

Agent Engine / Agent SDK

"By stitching these three primitives together, you get an agent loop that's actually a distributed state machine under the hood."

Palantir Group Lead Natasha Armbrust launches Agent Engine and Agent SDK, giving developers the core primitives to build agents that form a distributed state machine and are multiplayer by design.

  • Context items for defining agent sessions through strongly typed data

  • Events for expressively acting on changes in state

  • Effects for connecting agents to the outside world

Watch a patient discharge agent pause for nurse approval, reassess itself the moment a new lab result comes in, and render its reasoning clearly to every human in the loop, all in a few lines of code.

You can't optimize what you can't see, and you can't scale what only humans can fix.
