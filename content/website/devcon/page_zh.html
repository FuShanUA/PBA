Agent Stack

"如果我们想构建能够完成实际工作的有意义的智能体，我们就需要能够理解它们的工作，并在提升其自主性之前建立信任。"

Palantir 软件工程师 Ankit Shankar 发布了 Agent Stack，这是一套帮助您为企业构建生产级智能体的产品，全部构建在本体论之上。

  • 用于持久化执行的 Orchestrator

  • 用于构建任意形态智能体的 Agent Engine 和 Agent SDK

  • 用于可操作遥测和可观测性的 Agent Manager

  • 用于持续端到端优化的 AIP Evolve

观看一个简单的智能体在真实世界中接受压力测试——竞态条件、人工审批、任务中途崩溃——并了解为什么真正区分优秀演示与生产级智能体的是信任，而非智能。

Orchestrator

"如今智能体实用性的瓶颈不是智能，而是信任。"

Palantir 团队负责人 John Mathews 发布了 Orchestrator，这一持久化执行层让智能体可以崩溃、恢复、等待，并从上次中断的地方精确继续。观看一个患者出院智能体在任务中途被终止，数天后重新恢复，且零状态丢失、零重复副作用，在等待医生签字期间也零计算消耗。

Agent Engine / Agent SDK

"通过将这三个原语拼接在一起，您会得到一个智能体循环，其底层实际上是一个分布式状态机。"

Palantir 团队负责人 Natasha Armbrust 发布了 Agent Engine 和 Agent SDK，为开发者提供核心原语，用于构建构成分布式状态机且天生支持多人协作的智能体。

  • 上下文项：通过强类型数据定义智能体会话

  • 事件：以富有表现力的方式对状态变化做出响应

  • 效果：将智能体连接到外部世界

观看一个患者出院智能体暂停等待护士审批，在新化验结果送达的瞬间重新自我评估，并以几行代码向流程中的每个人清晰呈现其推理过程。

AIP Evolve

看不见就无法优化，只有人能修复就无法扩展。

Palantir 团队负责人 Christopher Jeganathan 和 Palantir 前沿部署工程师 Colton Rusch 借助 AIP Inspect 和 Agent Timeline 将原始智能体遥测数据转化为可读的叙事。随后他们发布了 AIP Evolve，这是一款新产品，可部署智能体团队，持续优化您 AI 系统中的任何目标，尤其是成本、质量和速度。

观看 Evolve 在一个制造工作流中将延迟降低多达 90%，将一个案例的处理时间从 45 秒缩短至 8.8 秒——通过自动针对您自己的评估测试模型替换、提示词重写和架构变更来实现。

SuperRepo

"没有出色的专业代码 DevOps 体验，就没有出色的专业代码开发者体验。"

Palantir 团队负责人 Ramzi Karam 发布了 SuperRepo，这是一个单一仓库，其中本体论函数、操作、前端和智能体以专业代码的形式统一定义和部署，并由本地嵌入式本体论提供支持，实现即时迭代。观看一个事件分诊智能体获得全新能力——模式变更、逻辑、前端、智能体更新——期间无需任何一次 CI 运行。

AIP Evolve x 坦帕总医院：优化医疗护理

医院的利润率不足 2%。AI 必须证明自己的价值。

坦帕总医院医生咨询服务医学主任 David Zihr 医生与 Palantir 前线部署工程师 Colton Rusch 展示了 AIP Evolve 如何将 AI 生成的使用审查成本降低近 70%。了解 Evolve 如何跨提供商筛选模型、重写提示词，甚至用确定性代码替代 AI，将 GPT 调用减少了 84% —— 与此同时，坦帕总医院自己的专家在 90% 的情况下更倾向于优化后的输出。

更多产品更新

数月的创新，几分钟的呈现。Palantir 工程师分享他们最近推向生产环境的功能发布，确保在 DevCon 及之后提供一流的产品体验。

01 — 通过 Registered Models 将你自己的模型引入 AIP

你的模型，直接导入 AIP。

  • 通过在 Control Panel 中的一次注册，连接来自任何提供商的任何 LLM

  • 注册的模型自动继承 AIP 的速率限制和工具调用支持

  • 通过 REST API 进行外部托管，或在 Foundry 计算模块中自托管，以在你自己的硬件和 GPU 上实现主权部署

观看 →

02 — 数据平面中的 SQL Studio、增量作业调试与时间旅行

查询数据、调试失败的作业或追踪变更，不应每次都需要自定义工具。

  • SQL Studio 现已正式发布（GA）——一个低延迟环境，可将查询动态路由到合适的引擎

  • 增量作业调试现在可为每种资源和计算类型生成标准化的失败报告

  • 时间旅行结合数据二分法，让你检查表以精确定位某个值发生变化的时间

03 — AIP 智能体的代码执行

每个执行代码的智能体都需要同样的保障：隔离、规模和安全。

  • 运行 Python 和 SQL，迭代处理文件，并执行多步骤工作流

  • 一个无代码的 AIP Chatbot Studio 智能体可分析文件系统中的文件，并根据 PDF 和 PowerPoint 源合成一份新文档

  • 一个专业代码 SDK 智能体可快速清理庞大而杂乱的数据集
