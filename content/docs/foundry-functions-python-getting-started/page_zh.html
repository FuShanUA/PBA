Python 函数入门

以下文档将指导您完成为在 Palantir 平台上使用而准备 Python 函数的初始步骤。您将学习如何创建 Python 函数仓库、提交和发布函数、在实时预览中进行测试等操作。

创建 Python 函数仓库

导航到您选择的项目，并通过选择以下选项来创建新的代码仓库： + New > Repository。然后选择 Python functions 模板来初始化您的仓库。我们建议将用于 Workshop 或基于本体论的应用程序的所有函数归组到单个仓库中，以尽量降低成本。

创建仓库后，导航到 python-functions/python/python-functions/my_function.py 文件。

探索仓库

您的仓库将使用一个 my_function.py 文件进行初始化，该文件包含一些示例函数，其中包括以下内容：

from functions.api import function, String

@function
def my_function() -> String:
    return "Hello World!"

请注意，该函数遵循以下约束：

  • 该函数必须使用 @function （来自 functions.api 包）进行装饰，才能被识别为 Python 函数。您可能有多个 Python 文件，每个文件中包含多个函数，但 只有带有此装饰器的函数 才会被注册为 Python 函数。
  • 该函数必须声明其所有输入的类型以及输出的类型，既可以使用 functions API 包中的类型，也可以使用其对应的 Python 类型。例如，上述示例的输出类型声明为来自 functions API 的 String ，但也可以声明为对应的 Python 类型 str。

即使您使用 API 类型来声明参数的类型（例如 String），您的函数在运行时也会被传入相应的 Python 类型（在本示例中为 str）。

要全面了解 Python 函数中的类型，请参阅我们的 类型参考文档。

要向您的仓库添加 Python 软件包，请使用 “库” 侧边面板，具体请参阅 发现并使用 Python 库。

在实时预览中测试

添加新函数后，您可以在 “函数” 辅助工具中立即运行它。从屏幕左下角打开 “函数” 辅助工具，然后选择 “实时预览”。选择 add_seconds_to_datetime 函数，填写输入值，然后选择 “运行” 以运行代码。

选择右上角的 “提交” ，将您的更改提交到仓库的 master 分支。

提交并发布函数

编写函数（或取消注释所提供的示例函数之一）后，请按照以下步骤提交并发布该函数。

  1. 要提交您的更改，请选择 Commit （位于 Source control 选项卡中），并添加提交消息。
  2. 选择屏幕顶部中央的 Branches 选项卡，然后选择 Tags and releases。
  3. 选择 New tag 并为该发布提供版本号。

  1. 选择 Tag and release 并等待发布步骤完成。

  2. 检查成功后，选择 Code 选项卡，然后打开 Functions 选项卡（位于页面底部）。您将看到 my_function 显示在结果中。

  1. 选择该函数，然后选择 Run 以执行您刚刚发布的函数。

添加另一个函数

现在，我们将向此代码仓库添加一个更复杂的函数，以进行测试和发布。将以下代码复制并粘贴到 my_function 文件的底部。

from functions.api import function, String
from datetime import datetime, timedelta

@function
def add_seconds_to_datetime(start_time: datetime, elapsed_millis: int) -> str:
    dt = start_time + timedelta(milliseconds=elapsed_millis)
    return dt.isoformat()
