apollo-cli cve list

按产品发布和容器镜像列出 CVE 截止日期

按产品发布和容器镜像列出 CVE 截止日期。

对于查询到的发布版本中发现的每个 CVE，每个受影响的容器镜像输出一行，显示产品坐标、CVE ID、容器镜像和截止日期。具有活动发现的 CVE 在截止日期处显示"Overdue"（逾期）。

输入源（至少需要一个）：

  1. 环境（-e）：查询环境中所有实体的产品发布
  2. YAML 文件（-f）：查询提供的 YAML 文件中列出的 Maven 坐标
  3. 产品 ID（-p）：查询指定产品的最新发布版本

示例用法：

列出环境中所有发布版本的 CVE 截止日期

apollo-cli cve list -e my-environment

列出特定产品最新版本的 CVE 截止日期

apollo-cli cve list -p com.palantir.foo

列出文件中坐标的 CVE 截止日期

apollo-cli cve list -f coordinates.yaml

输出为 JSON

apollo-cli cve list -e my-environment -o json

apollo-cli cve list [flags]

标志

标志用途
-e, --environment环境
-h, --helplist 命令的帮助信息
-f, --maven-coordinates-file包含 maven 坐标列表的文件（yaml 格式）
-p, --product-id格式为 'group' 的产品 ID

从父命令继承的标志

标志用途
--apollo-client-id用于生成 Bearer Token 的客户端 ID
--apollo-client-secret用于生成 Bearer Token 的客户端密钥
--apollo-token用于已验证端点的 Bearer Token
--apollo-token-provider指定如何提供用于已验证 Apollo 端点调用的 Bearer Token。有效值为 "auto"、"static"、"service-user" 或 "sso"（默认值为 "auto"）。如果指定了 "auto"，则根据已有配置选择模式：设置了 "apollo-token" 时为 "static"，同时设置了 "apollo-client-id" 和 "apollo-client-secret" 时为 "service-user"，否则为 "sso"（交互式浏览器登录）。如果同时设置了 bearer token 和（客户端 ID 或客户端密钥），则会报错。如果指定了 "static"，则使用 "apollo-token" 提供的 token。如果指定了 "service-user"，则使用 "apollo-client-id" 和 "apollo-client-secret" 从 Multipass 生成 token。如果指定了 "sso"，则使用针对 Multipass 的基于浏览器的交互式 SSO 登录（支持 YubiKey 等硬件密钥）；生成的 token 会按 profile 缓存并静默刷新。当命令首次需要 token 且不存在有效的缓存 token 时，登录流程将自动触发。
--apollo-urlApollo 的基础 URL，用于推导 API 端点
--debug启用调试级别的日志记录
--http-timeout所有 apollo 请求的超时时间（分钟）
-k, --insecure-skip-verify跳过服务器证书验证
-o, --output输出格式 (json,yaml,pretty)
--profile使用配置文件中的特定 profile
--quiet不将日志输出打印到 stderr
--space-id用于某些空间范围命令的空间 ID
--sso-callback-port用于 SSO OAuth 回调的本地环回端口；0 表示选择一个可用的临时端口
