流水线管理

本页面概述了 Pipeline Builder 中管道管理的功能和最佳实践。

在管道中复用逻辑

Pipeline Builder 支持通过以下方式在管道中复用逻辑： 参数 和 自定义函数。参数是可以在管道中的多个转换中使用的值。自定义函数包括自定义表达式和自定义转换，用于在单一位置复用逻辑。自定义表达式允许您保存带有可选参数的单个表达式，而自定义转换允许您将一系列转换板保存为单个转换。

大型管道管理

Pipeline Builder 支持分组和优化功能，以帮助管理大型管道。

您可以创建 文件夹 和子文件夹，以便在 Pipeline Builder 中对节点进行分组。这使您能够组织节点，并切换子集文件夹中节点的可见性，从而缩小管道的范围。

您可以使用 节点颜色分组 在 Pipeline Builder 中折叠相同颜色的节点，以提高图表的可读性。

您可以通过以下方式专注于图表的某个子部分： 显示和隐藏 节点。您可以手动选择这些节点，也可以根据颜色分组来显示和隐藏它们。

作业分组 在 Pipeline Builder 中允许您控制输出如何拆分为作业，以及每个作业的计算配置文件。侧边栏为单个未分组的作业显示专用部分，便于区分已分组和未分组的输出。

在构建管道时，您可以将多个输出之间共享的转换节点标记为 检查点。这些中间结果将在您下次构建时仅计算一次，从而节省计算资源。

为了获得更快的预览，您可以添加 输入采样 ，在构建管道原型时对输入数据进行降采样。管道部署仍将在完整数据集上运行。如果输入采样策略存在错误，这些错误将以节点徽标的形式显示在图表中和 管道错误 面板中进行管理。

您还可以 配置预览行为 ，以控制预览是自动运行还是需要确认，包括在注册级别和用户级别。

有关构建更快、提升性能和组织管道的更多实用指导，请参阅 Pipeline Builder 提示与技巧.
