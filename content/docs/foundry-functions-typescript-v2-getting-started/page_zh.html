TypeScript v2 函数入门

TypeScript v2 允许用户利用多项关键 改进（相比 TypeScript v1），包括 Node.js 运行时和一流的 OSDK 支持。请查看以下各部分以开始使用。

创建 TypeScript v2 函数仓库

导航至您选择的项目，然后选择 + New > Repository 来创建新的代码仓库。选择 TypeScript v2 函数模板以初始化您的仓库。

仓库创建完成后，导航至 typescript-functions/src/functions/helloWorld.ts 文件。

在将本体论类型导入函数之前，请先通过 资源导入 侧边栏添加您的对象类型和关联类型，然后生成并安装本体论 SDK。请参阅 生成本体论 SDK 以了解这些步骤。

编写函数

要编写新函数，请在仓库的 typescript-functions/src/functions 目录中创建一个新文件，并为其指定一个描述性名称，例如 helloWorld.ts。请使用 export default 编写您的函数，以便 Foundry 检测到它。

export default function helloWorld(): string {
    return "Hello World!";
}

您的函数必须满足以下条件，才能发布到 Foundry：

  1. 请在 .ts 文件中定义您的函数，该文件位于 typescript-functions/src/functions 目录中。您还可以在此目录下将相关函数分组到子目录中。
  2. 您的文件名必须与您的函数名一致。要发布名为 myFunction 的函数，必须在名为 myFunction.ts 的文件中定义，该文件位于 typescript-functions/src/functions 目录中。
  3. TypeScript 函数必须是文件的默认导出。
  4. 您的函数的输入和输出类型必须遵循受支持的函数类型，详见 类型参考。

您的函数文件路径用于唯一标识从中发布的函数。请注意，更改函数的文件路径将因此导致发布一个新函数。

在实时预览中测试

要在实时预览中测试您的函数，请打开 函数 助手并选择 实时预览。请选择您的函数，然后选择 运行 以执行。

提交并发布函数

选择 提交 （位于窗口右上角），将您的更改提交到仓库的 master 分支。要查看您的函数的检查，请打开 检查 选项卡（位于页面顶部）。在此处，进行提交后，您应该会看到一个正在运行的检查。

提交您的工作后，您将看到 标记版本 选项。这将发布您仓库中的所有函数。

选择 标记版本 以从该 master 分支标记发布版本。根据变更范围设置标签名称，然后选择 “标记并发布”。

要在标记和发布函数的过程中查看进度，请选择 “查看” 弹出窗口，或导航至 “标签” 选项卡。完成 “步骤 2：发布” 后，选择已发布的函数，以便在函数注册表中查看它们。

在权限传播过程中，函数可能无法立即在 Workshop 或函数注册表中按名称搜索到。

使用新函数

在标签通过检查后，导航回到 “代码” 选项卡（位于 代码仓库 中），然后选择 “函数” 辅助工具。您现在应该可以在 “已发布” 部分中看到您的函数。选择它并运行新函数：

后续步骤

创建并发布基本函数后，可以探索以下功能：

  • 本体论 SDK： 要查询或编辑本体论对象，请先导入所需的对象类型和关联类型，然后 生成并安装本体论 SDK。
  • 本体论编辑： 了解如何在函数中 创建、更新和删除对象 。
  • 暂存写入 [Beta]： 对于需要写后读保证或嵌套函数调用的编辑函数，请参见 暂存写入。
