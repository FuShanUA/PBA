Foundry CLI

Beta

SuperRepo 目前处于 beta 开发阶段,在您的租户中可能无法使用。在持续开发期间,功能可能会发生变化。

Foundry CLI (foundry)是一款命令行工具,可用于在您自己的计算机上开发 SuperRepo,无论仓库托管在 Palantir 平台内部还是外部。它可在 macOS、Windows 和 Linux 上运行。您可以使用它从模板搭建项目脚手架,并构建、预览和部署您的项目。

安装

您可以按照本部分中的步骤安装 Foundry CLI,也可以通过 Palantir 平台内的交互式安装流程进行安装。要打开该流程,请将 /workspace/code/superrepo 追加到您租户的根地址。

推荐流程

在可能的情况下,请通过平台内流程进行安装。该流程为安装预配的令牌比下方步骤所需的 用户生成的令牌 权限更受限,因此是更安全的选择。

步骤 1:设置您的 Foundry URL

在您的终端会话中将 FOUNDRY_URL 设置为您租户的根地址。

Copied!
1
export FOUNDRY_URL="insert_domain_here"
Copied!
1
$env:FOUNDRY_URL = "insert_domain_here"

步骤 2:向安装程序提供令牌

对于您的 Foundry 租户,请 生成令牌 并在同一终端会话中进行设置。用户生成的令牌没有作用域设置,因此不需要特定作用域。

Copied!
1
export TOKEN="insert_token_here"
Copied!
1
$env:TOKEN = "insert_token_here"

该 FOUNDRY_URL 和 TOKEN 变量会被第 3 步中的安装命令读取，该命令会从你的注册实例下载 CLI。它们并不是 CLI 安装后自身使用的凭据；你需要使用 foundry login 在下一节中建立这些凭据。因为该令牌仅在安装 CLI 时需要，所以登录后即可将其删除；即使令牌过期，已安装的 CLI 也不会受到影响。

第 3 步：安装 CLI

运行适用于你的操作系统的安装命令。CLI 始终从你的注册实例下载；它不会通过包管理器分发，也不会以独立下载的形式提供。

在 Windows 上， install-foundry.bat 是使用 $env:FOUNDRY_URL 和 $env:TOKEN 值下载的，这些值是你在第 1 步和第 2 步中设置的，因此请先在同一个 PowerShell 会话中运行这些步骤。

Copied!
1
curl -sS "$FOUNDRY_URL/code/api/extension/install-script" -H "Authorization: Bearer $TOKEN" | bash
Copied!
1
2
Invoke-WebRequest -Uri "$env:FOUNDRY_URL/code/api/extension/install-bat" -Headers @{ Authorization = "Bearer $env:TOKEN" } -OutFile "install-foundry.bat"
.\install-foundry.bat

向 Foundry 进行身份验证

登录你的 Foundry 注册实例，以便在开发 SuperRepo 项目时 CLI 能够访问平台。

Copied!
1
foundry login

该命令会提示你输入 Foundry URL 和令牌，然后会存储供后续所有 CLI 命令使用的凭据，包括本地开发服务器和 foundry deploy。如需在无提示的情况下登录，请在 FOUNDRY_TOKEN 环境变量和注册 URL，可使用 --foundry-url 选项。请在 CI 系统中使用此形式。

如果命令开始因授权错误而失败，说明由 foundry login 存储的凭据已过期。请在浏览器中使用以下命令重新授权：

Copied!
1
foundry login refresh

更新 CLI

Foundry CLI 可以将自身更新到最新版本。

Copied!
1
foundry update self

了解更多

要了解 Foundry CLI 的完整功能，您可以列出各个选项。

Copied!
1
foundry --help
