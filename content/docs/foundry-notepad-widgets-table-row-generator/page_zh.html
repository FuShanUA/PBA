表格行生成器

此小部件仅适用于 文档模板.

直方图 表格行生成器 支持为传递到 Notepad 文档模板的对象集中的每个对象动态生成一行。表格行生成器与 或非常相似，但表格行生成器返回的是行而不是通用章节，并且只能在 Notepad 表格中使用。

可以通过表格右键菜单或表格 插入 操作（位于工具栏中）将行生成器插入到常规 Notepad 表格中。或者，选择 + 添加组件 或在段落字段中键入 / 以打开 组件插入菜单，从中可以插入一个预填充了一个常规行和一个生成器行的表格行生成器。

将嵌入式小组件与表格行生成器连接

要将嵌入式小组件的输入参数与其周围的 表格行生成器连接，请将输入设置为 Object from generator。该 Object from generator 输入项将自动可供生成器内部接受对象模板输入的小组件选择。

使用表格行生成器对对象进行排序

要对生成器返回的对象进行排序，请使用 排序 控件。从 Sort by 下拉列表中选择要作为排序依据的对象属性。可排序的对象数量 上限为 2000 个.

模板配置

  • 生成器对象集 RID： 要传递给表格行生成器的对象集。表格行生成器将为该集合中的每个对象生成一个表格行。当前可传递的对象数量 上限为 100 个对象.

嵌套表格行生成器

表格行生成器可以 嵌套在顶层章节生成器中。嵌套表格行生成器可以配置为基于对象集模板输入生成，或基于顶层生成器对象的一级关联对象生成。

表格行生成器对象限制

默认情况下，顶层表格行生成器的生成限制设置为最多 100 个对象。对于嵌套在章节生成器中的表格行生成器，限制设置为最多 100 个对象。从大量对象生成行可能会对模板生成性能以及所生成文档的加载性能产生负面影响。
