查找具有给定列的数据集

您可以在数据血缘图中轻松搜索特定的数据集列：

  • 首先，确保将管道中所有感兴趣的数据集添加到您的血缘图中。

  • 接下来，选择所有感兴趣的数据集，方法是使用 拖拽选择模式 （位于应用左上角的工具切换栏中）。您也可以按住 Ctrl / Command 以一次选择多个节点，或使用 Ctrl / Command + A 以选择所有节点。



  • 然后,选择 查看所选内容属性的直方图 （位于数据血缘侧边栏中）。



  • 编辑标签 常用列 部分，您可以查看所选内容中按名称出现频率最高的列。

  • 点击其中某一列，即可高亮显示所选内容中包含该列的数据集。
