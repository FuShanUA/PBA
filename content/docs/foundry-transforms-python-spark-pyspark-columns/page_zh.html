概念：列

要按照本文档中的示例进行操作，请添加： from pyspark.sql import functions as F。

列由 PySpark 类管理： pyspark.sql.Column。每当您直接引用现有列或从现有列派生表达式时，都会创建 Column 实例。您可以通过以下任一方式引用列：

  • F.col("column_name")
  • F.column("column_name")

引用列并不等同于执行 select操作，因为“选择”列是指选取（并重新排序）您希望出现在结果数据集中的列。

获取架构

DataFrame.columns

以 Python 列表的形式返回所有列名

Copied!
1
columns = df.columns # ['age', 'name']

DataFrame.dtypes

以元组列表的形式返回所有列名及其数据类型

Copied!
1
dtypes = df.dtypes # [('age', 'int'), ('name', 'string')]

选择

DataFrame.select(*cols)

返回一个新的 DataFrame ，其中包含原始 DataFrame中列的一个子集。

例如，我们有一个包含 6 个命名列的 DataFrame： id, first_name, last_name, phone_number, address, is_active_member

idfirst_namelast_namephone_numberzip_codeis_active_member
1JohnDoe(123) 456-789010014true
2JaneEyre(213) 555-123490007true
..................

您可能希望转换 DataFrame，使其仅包含您关心的指定列（可用列的一个子集）。假设您只想要一个仅包含单个列的表 phone_number：

Copied!
1
df = df.select("phone_number")
phone_number
(123) 456-7890
(213) 555-1234
...

或者您只想要 id， first_name，以及 last_name （至少有 3 种不同的方法可以完成相同的任务）：

  1. 直接传入列名：

    Copied!
    1
df = df.select("id", "first_name", "last_name")

    或者传入列实例：

    Copied!
    1
df = df.select(F.col("id"), F.col("first_name"), F.col("last_name"))

  2. 传入列名数组：

    Copied!
    1
2
select_columns = ["id", "first_name", "last_name"]
df = df.select(select_columns)

  3. 传入一个“解包”的数组：

    Copied!
    1
2
3
select_columns = ["id", "first_name", "last_name"]
df = df.select(*select_columns)
# same as: df = df.select("id", "first_name", "last_name")
    idfirst_namelast_name
    1JohnDoe
    2JaneEyre
    .........

    此 * 位于 select_columns 之前，会解包 该数组，从而使其在功能上与 #1 的行为相同（参见注释）。这使您能够执行以下操作：

    Copied!
    1
2
3
select_columns = ["id", "first_name", "last_name"]
return df.select(*select_columns, "phone_number")
# same as: df = df.select("id", "first_name", "last_name", "phone_number")
    idfirst_namelast_namephone_number
    1JohnDoe(123) 456-7890
    2JaneEyre(213) 555-1234
    ............

请记住，您的输出数据集将 仅包含您选择的列，并且 按照您选择它们的顺序排列，而不是保留原始列顺序。这些名称是唯一且区分大小写的，并且必须已经作为一列存在于您要从中选择的数据集中。

该规则的一个例外是，你可以派生一个新列并立即选择它。你需要为新派生的列指定一个 alias（或名称）：

string1string2string3string4
firstsecondthirdFourth
onetwothreefour
Copied!
1
2
derived_column = F.concat_ws(":", F.col("string1"), F.col("string2"))
return df.select("string3", derived_column.alias("derived"))
string3derived
thirdfirst
threeone

创建、更新

DataFrame.withColumn(name, column)

Copied!
1
new_df = old_df.withColumn("column_name", derived_column)
  • new_df：生成的 dataframe 包含来自 old_df的所有列，但添加了 new_column_name 这一列。
  • old_df：我们要向其添加新列的 dataframe
  • column_name：你想要创建（如果该列不存在于 old_df 中）或更新（如果该列已存在于 old_df 中）的列的名称。
  • derived_column：用于派生列的表达式，该表达式会应用于 column_name （或你为该列指定的任何名称）下的每一行。

对于现有的 DataFrame，你可以使用 withColumn 方法来创建新列，或使用新值或修改后的值来更新现有列。这对于以下目标特别有用：

  1. 基于现有值派生新值

    Copied!
    1
df = df.withColumn("times_two", F.col("number") * 2) # times_two = number * 2
    Copied!
    1
df = df.withColumn("concat", F.concat(F.col("string1"), F.col("string2")))

  2. 将值从一种类型转换为另一种类型

    Copied!
    1
2
# cast `start_timestamp` to DateType and store the new value in `start_date`
df = df.withColumn("start_date", F.col("start_timestamp").cast("date"))

  3. 更新列

    Copied!
    1
2
# update column `string` with an all-lowercased version of itself
df = df.withColumn("string", F.lower(F.col("string")))

重命名、别名

DataFrame.withColumnRenamed(name, rename)

使用 .withColumnRenamed() 来重命名列：

Copied!
1
df = df.withColumnRenamed("old_name", "new_name")

另一种看待重命名列这一任务的方式（这应该能让你深入了解 PySpark 如何优化转换语句）是：

Copied!
1
df = df.withColumn("new_name", F.col("old_name")).drop("old_name")

但也存在几种情况，您派生新列时并未使用 withColumn ，但仍需为其命名。这时 alias （或其方法别名 name）就能派上用场了。下面是一些用法示例：

Copied!
1
2
3
4
df = df.select(derived_column.alias("new_name"))
df = df.select(derived_column.name("new_name")) # same as .alias("new_name")
df = df.groupBy("group") \
	.agg(F.sum("number").alias("sum_of_numbers"), F.count("*").alias("count"))

我们还可以利用 rename 一次重命名多个列：

Copied!
1
2
3
4
5
6
7
renames = {
    "column": "column_renamed",
    "data": "data_renamed",
}

for colname, rename in renames.items():
    df = df.withColumnRenamed(colname, rename)

删除

DataFrame.drop(*cols)

返回一个新的 DataFrame ，其中包含来自原始 DataFrame的部分列，并删除指定的列。（如果 schema 不包含给定的列名，则此操作会失败。）

删除列有两种方法：直接方法和间接方法。间接方法是使用 select，您可以用它选出想要 保留的列。直接方法是使用 drop，您需要提供想要 丢弃的列。两者的使用语法相似，只是在这里顺序无关紧要。下面举几个例子：

类型转换

Column.cast(type)

以下是现有的所有 DataTypes： NullType, StringType, BinaryType, BooleanType, DateType, TimestampType, DecimalType, DoubleType, FloatType, ByteType, IntegerType, LongType, ShortType, ArrayType, MapType, StructType, StructField

一般来说，你可以使用列上的 cast 方法将大多数数据类型从一种转换为另一种：

Copied!
1
2
3
from pyspark.sql.types import StringType
df.select(df.age.cast(StringType()).alias("age"))
# assume df.age is of IntegerType()

或

Copied!
1
2
df.select(df.age.cast("string").alias("age"))
# effectively the same as using StringType().
age
"2"
"5"

类型转换本质上会创建一个新的派生列，你可以直接在该列上执行 select, withColumn, filter等操作。"向下转换"（downcasting）和"向上转换"（upcasting）的概念同样适用于 PySpark，因此你可能会丢失先前数据类型中存储的更细粒度的信息，也可能会引入垃圾信息。

When、otherwise

F.when(condition, value).otherwise(value2)

参数：

  • condition - 一个布尔 Column 表达式
  • value - 一个字面值或 Column 表达式

求值后会得到一个列表达式，该表达式与 value 或 value2 参数相同。如果 Column.otherwise() 未被调用，则会为未匹配的条件返回一个 None （即 null）的列表达式。

该 when、 otherwise 操作符类似于 if-else 语句，用于计算新的列值。基本用法如下：

Copied!
1
2
3
4
5
# CASE WHEN (age >= 21) THEN true ELSE false END
at_least_21 = F.when(F.col("age") >= 21, True).otherwise(False)
# CASE WHEN (last_name != "") THEN last_name ELSE null
last_name = F.when(F.col("last_name") != "", F.col("last_name")).otherwise(None)
df = df.select(at_least_21.alias("at_least_21"), last_name.alias("last_name"))

您也可以将 when 语句串联起来，需要多少次都可以：

Copied!
1
switch = F.when(F.col("age") >= 35, "A").when(F.col("age") >= 21, "B").otherwise("C")

这些求值结果可以赋值给列，也可以在过滤器中使用：

Copied!
1
2
df = df.withColumn("switch", switch) # switch=A, B, or C
df = df.where(~F.isnull(last_name)) # filter for rows where the last_name (after empty strings were evaluated as null values) is not null
