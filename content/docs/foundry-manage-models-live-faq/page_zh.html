Modeling Objective 实时部署常见问题

以下是关于 Modeling Objective 实时部署的一些常见问题，这些问题与 直接部署 不同，后者是从模型页面配置的。了解更多关于创建和设置 实时部署 和 实时部署与直接部署之间的差异.

我发布的 Python 模型默认会包含哪些 conda 包/环境？

模型将使用已发布模型的模型适配器中配置的 conda 包/环境进行打包。Palantir 还会添加必要的轻量级包来为您的生产模型提供服务。

在向实时部署发送请求时，最多可以发送多少数据？

默认情况下，实时部署的单个请求最多接受 50MB。此上限是可配置的；请联系您的 Palantir 代表了解更多详情。

我可以为 Modeling Objective 实时部署创建监控吗？

可以。Modeling Objective 实时部署的可用性可以通过 监控视图.

除了公共库之外，我还可以在环境自定义中包含私有库吗？

我们支持将私有库和公共库导入到提交环境中。

  • 对于公共库，您需要确保所请求的库在公共渠道（例如 conda-forge）中可用， 并且这些公共渠道的配置方式使其能够在 Foundry 中被发现；
  • 对于在 Foundry 中创建的私有库，这些库必须 按照 Python 库指南正确发布.

我可以限制谁能在我的实例上创建实时部署吗？

可以。创建实时部署的权限可以与创建批量部署的权限分开设置。请联系您的 Palantir 代表获取指导。

我可以扩展我的 Python 模型吗？

可以。在 Palantir 的容器基础设施中部署时，Foundry 目前提供流量扩展功能。

默认情况下，每个部署配置了 2 个副本，以确保升级期间不会停机。默认的 CPU 和内存占用也较低，因此默认成本配置较低。

这可以 针对单个部署进行覆盖，以支持更大的模型或更高的预期负载。此外，还可以通过 Control Panel 为所有实时部署覆盖默认配置。

我可以在 GPU 上运行我的 Python 模型吗？

可以。Python 模型的 GPU 支持目前处于 测试版 开发阶段，可能无法在您的注册租户中使用。功能在积极开发过程中可能会发生变化。

我可以关闭我的部署以停止产生费用吗？

可以，您可以 禁用您的实时部署 ，操作方式为通过单个部署页面。

当您准备好再次使用它时，也可以通过 UI 重新启用它，部署将升级到最新版本。

或者，您也可以 删除部署；但此操作无法撤销，并且您将不再保留相同的 Target RID。

我的 Foundry ML Python 模型可以访问外部 API 吗？

可以。但是，您（或授权管理员）必须为实时部署配置网络出口。

实时部署请求期间会发生超时吗？

由于默认的对话读取超时，将会发生五分钟的超时，因为运行推理是一个同步过程。
