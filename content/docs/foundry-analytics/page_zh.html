分析

Foundry 为组织中的各类用户提供分析功能，并与 Foundry 本体论集成。开箱即用，Foundry 包含点选式和基于代码的工具，可实现基于表的分析、自上而下的可视化分析、地理空间分析、时间分析等。Foundry 中的分析旨在超越传统的“只读”范式，将数据写回本体论，从而在统一的安全、数据血缘和治理模型中产生有价值的新洞察。

核心应用程序

Foundry 的核心分析应用程序包括：

  • Contour，一款自上而下的分析应用程序，可大规模快速探索表格式数据、通过可视化转换派生新数据集并创建图表。
  • Quiver，一款多模态图表应用程序，支持对象驱动的分析、时间序列驱动的分析、点选式机器学习以及仪表板构建。
  • Code Workbook，一款融合数据工程与数据科学元素的应用程序，支持快速构建由 Python、R 或 SQL 驱动的转换，还可构建和训练机器学习模型等。
  • Notepad，一款集成解决方案，可嵌入来自 Foundry 各处的动态分析、可视化和运营工件，以及格式化文本和媒体。
  • Fusion，一款电子表格驱动的应用程序，将表格式计算与 Foundry 本体论和对象驱动查询系统的强大功能相结合。

分析连接性

Foundry 还旨在与您现有的分析工具深度集成。组织可以通过标准 API 和接口将其商业智能、可视化以及其他分析应用程序连接到 Foundry。集成选项包括：

  • 适用于常见工具的即开即用连接器，例如 Power BI® 和 Tableau。
  • REST API 用于按需连接。
  • ODBC 和 JDBC 驱动程序 用于通用连接。
  • Python ↗ 和 R ↗ 用于连接数据科学工具的 SDK。
  • 适用于 Microsoft Report Builder 和 Excel 等工具的引导式集成，此类集成利用了标准接口。
