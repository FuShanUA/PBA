录制工作流并编辑资源

本页面提供了录制工作流所需的配置和步骤说明。

创建 Flow Capture 资源

  1. 打开 Flow Capture 应用程序。
  2. 选择 + New Flow Capture （位于右上角）。

  1. 选择文件名和位置，将您的资源保存到 Compass 中。
  2. 选择 保存 以创建新的流程捕获资源。

选择系统提示模板

保存资源后，您将被重定向到 录制工作流 页面。在 您想要记录什么？，请选择与您想要生成的文档最匹配的模板。

目前提供以下模板：

  • 通用文档： 捕获工作流并将其转换为 Markdown 文档。
  • 报告 Bug： 重现您在平台中发现的问题，为产品合作伙伴提供丰富的详细信息。
  • 请求新功能： 指出平台的不足之处并提出改进建议。
  • 提供反馈： 在使用平台的过程中，描述产品行为、功能或可用性方面的反馈。

如果需要针对不同的用例调整生成提示，您稍后可以更改所选的模板。

录制前，请确保您了解组织的数据处理政策。Flow Capture 将录制屏幕截图和可选的音频；您必须确认所录制的内容适合预期用途，并按照您的安全政策进行处理。

准备录制

  1. 选择 录制工作流 以打开录制器确认界面。
  2. 在确认对话框中，选中复选框以确认所需的安全设置，然后选择 确认。

查看录制器控件和选项

  • 屏幕截图计数器： 在录制器覆盖层的左上角显示已捕获的屏幕截图数量。
  • 录制音频： 启用此开关可捕获音频，该音频将被转录并与录制内容相关联。
  • 自动截图： 启用此开关后，在您浏览平台的过程中，录制器会在每次点击时自动捕获屏幕截图。
  • 尺寸下拉菜单： 选择屏幕截图的捕获尺寸。此下拉菜单提供以下用于缩放录制框的选项：
    • 完整尺寸：以目标页面的完整分辨率进行捕获。
    • 缩放：缩放页面以适应录制器视口。
    • 自定义：为捕获框指定自定义尺寸。
  • URL 字段： 使用此选项可直接导航到您想要通过录制器捕获的页面。URL 字段仅接受同域 URL。您导航到的页面必须位于运行 Flow Capture 的同一 Foundry 注册中。

开始录制

  1. 启用 录制音频 如果您想要语音旁白和转写。
  2. 启用或禁用 自动截图 具体取决于您是否希望在点击时自动捕获截图。
  3. 选择 录制 以开始捕获您的会话。

录制时导航

在录制器 URL 字段中输入 URL，或在录制器 iframe 中浏览，以导航到您想要记录的页面。像平常一样与应用交互，以演示您想要记录的工作流程。

手动捕获屏幕截图

如果 自动截图 已启用时，系统将自动为每次点击事件截取屏幕截图，但您可以随时手动截取屏幕截图。请使用 截取屏幕截图 选项（位于录制控件中）来捕获当前视图，或使用键盘快捷键 Cmd+Shift+S （macOS）或 Ctrl+Shift+S （Windows）来截取屏幕截图。

在会话期间使用录制控件

  • 选择 暂停 以暂停捕获。
  • 选择 录制 以在暂停后继续。
  • 选择 放弃并退出 以取消会话并删除所有已捕获的媒体。
  • 完成工作流捕获后，请选择 完成。

录制后

您可以在编辑模式下打开流程捕获资源，在生成最终文档之前查看和编辑截图、转录文本以及生成的上下文。如果进行了录制，系统会自动转录您的音频，并将其与捕获的截图相关联。

编辑资源

使用流程捕获上的编辑控件完善截图和转录文本，并定义 LLM 生成上下文中包含哪些工件。编辑内容将处于暂存状态，直到您保存为止。

向 LLM 上下文添加内容

您可以将快照或转录文本添加到生成上下文中，使其在生成过程中可供 LLM 使用。为此，请将鼠标悬停在要添加的资产上，然后选择 添加到上下文。 您还可以通过以下方式将图像导入 Flow Capture：选择 上传 （位于 资产 页面右上角），并选择您要上传的文件。

裁剪图像

裁剪图像，将读者的注意力集中在相关的 UI 元素上。

  1. 选择要编辑的快照。
  2. 选择 裁剪图像。
  3. 通过拖动选择手柄在图像上绘制裁剪区域。
  4. 选择 应用 以接受裁剪。
  5. 完成编辑后，选择 保存编辑，然后选择 完成 以返回编辑模式。

模糊图像

在将屏幕截图包含在生成的文档或导出内容中之前，请先对敏感信息进行模糊处理。

  1. 选择要编辑的快照。
  2. 选择 模糊图像。
  3. 通过拖动选择控制柄来绘制要模糊的区域。
  4. 选择 应用 以预览模糊效果。
  5. 选择 保存编辑，然后选择 完成 以返回编辑模式。

编辑转录文本

在生成文档之前，您可以纠正或改进转录文本。

  1. 选择转录文本或铅笔图标以打开 编辑转录 对话框。
  2. 编辑 音频转录 字段中的文本。
  3. 要自动重新生成转录，请选择 重新生成。
  4. 选择 保存 并关闭对话框以返回编辑模式。
  5. 选择 取消 以在不保存的情况下关闭对话框。

删除或恢复图像和音频

您可以从流程捕获中移除图像或音频文件。已删除的项目会保持可恢复状态，直到您保存更改，方法是选择 保存 在编辑工具栏中。

  1. 将鼠标悬停在图像或音频卡片上，即可显示删除图标。
  2. 选择删除图标以将项目标记为已删除。
  3. 要在保存编辑之前恢复已删除的项目，请选择 恢复快照。
  4. 选择 保存，已删除的图像和音频将被永久移除。
