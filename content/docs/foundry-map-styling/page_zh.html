样式设置

使用 样式设置 来控制地图各图层中所含数据的可视化效果。通过编辑颜色、大小、描边宽度等属性,您可以突出显示数据的关键属性,并创建有助于理解数据规律或识别地理空间数据中异常值的地图。

样式设置选项

要编辑图层的样式设置,请使用 图层 面板中的编辑样式按钮:

此列表包含各种图层通用的样式设置选项,但每个图层可用的选项会因图层中所含数据的类型而异。例如, 填充多边形 选项仅在所配置的样式器以多边形形式渲染时才会显示。在每个选项中,可用的模式也会因图层类型而异:基于属性、函数和度量的样式设置仅在对象图层上可用,而固定样式设置则适用于所有图层类型。

颜色

使用 颜色 部分来控制图层中对象的着色方式。 颜色依据 下拉菜单包含可用于着色的各种模式:

  • 固定: 选择单一颜色,统一应用于图层中的所有对象。
  • 函数: 使用函数计算的值为对象着色。
  • 属性: 使用属性中的值为对象着色。
  • 度量： 为对象着色，使用的值来自 时间序列。

当按具有数值的函数、属性或时间序列进行着色时，请使用渐变编辑器将值映射到输出颜色。可以通过选择渐变条上的点来编辑渐变中使用的颜色。颜色渐变的数值范围（最小值/最大值）会自动推断得出，但可以关闭该功能以手动设置范围。

当按具有字符串值的函数、属性或时间序列进行着色时，“ 颜色映射 ”下拉菜单包含将值映射到颜色的多种方法：

  • 手动： 为每个值显式指定要使用的颜色。
  • 自动： 自动从配色方案中分配颜色，以区分不同的值，而无需配置特定值。
  • 无： 尝试将每个值直接应用为十六进制颜色。

不透明度

使用“ 不透明度 ”部分来控制图层中对象的透明度。

“ 值来源 ”下拉菜单包含可用于指定不透明度的各种方式：

  • 固定： 选择一个不透明度，统一应用于图层中的所有对象。

  • 按时间： 渲染 轨迹 或属于 事件的对象时，请根据全局 时间选择控制其不透明度。

    • 活动不透明度： 设置对象或点被视为处于活动状态时的不透明度。
    • 非活动不透明度： 设置对象或点不被视为处于活动状态时的不透明度。
    • 活动时间缓冲： 设置事件或轨迹点的时间戳必须与当前时间游标相距多近，才会被视为处于活动状态
    • 淡出持续时间： 设置对象变为非活动状态后，其不透明度从活动不透明度淡出到非活动不透明度所需的时间段。
    • 发生前隐藏： 如果启用，在时间游标经过事件开始时间或轨迹点时间戳之前，对象将完全隐藏。

    Value from 下拉菜单和 By time 不透明度选项仅在为 轨迹 或包含 事件数据的对象设置样式时才会显示。

缩放级别

使用 缩放级别 部分来控制图层中对象的可见范围。脱字符（^）表示您当前的缩放级别。

当视口处于有效范围内的缩放级别时，相应的显示内容将在地图上渲染。当超出该范围时，相应的显示内容将被隐藏。

缩放级别配置仅适用于切换为 可见的图层。

描边宽度

使用 描边宽度 部分可控制渲染线条时所用的宽度。

描边样式

使用 描边样式 部分可控制渲染线条时所用的虚线模式。可用选项包括：

  • 实线

  • 虚线

  • 点线

填充多边形

当 填充多边形 启用时，多边形将以最细的描边渲染，并以指定颜色填充其内部。禁用时，多边形则仅显示描边，其样式配置来自 描边宽度 和 描边样式。

图标

配置图标样式器时，请使用 图标 部分来配置为每个对象渲染的图标。 图标来源 下拉菜单包含可用于分配图标的模式：

  • 对象默认： 使用本体论中分配给该对象的图标。
  • 固定图标： 选择一个将应用于图层中所有对象的图标。
  • 属性： 通过将属性值映射到图标来为对象分配图标。

标记形状

配置图标样式器时，请使用 标记形状 部分来配置图标所在的标记形状。可用选项包括：

  • 圆形

  • 图钉

  • 无

包含在图例中

默认情况下，当按属性、函数或度量值为图层着色时，图例将显示颜色映射，以帮助您在查看地图时解读颜色。您可以通过禁用 “包含在图例中” 开关来移除图例。同样，当使用固定颜色着色时，您可以通过开启 “包含在图例中” 开关来选择显示图例条目。

标签和工具提示

有两个与标签和工具提示相关的可选开关：

显示标签： 控制图层中的每个项目是否在地图上显示标签。 显示工具提示： 控制图层中的项目在悬停时是否显示包含上下文信息的弹出窗口。

对象图层的标签内容

对于由对象支撑的图层，标签和工具提示可能包含以下内容：

  • 属性（包括 时间序列属性）
  • 函数
  • 序列
  • 关联对象数量

对象图层样式器

对象图层中的每个对象都可以通过指定多个 样式器在地图上以多种方式进行渲染。例如，具有 geopoint 类型属性的对象既可以渲染为图钉标记，也可以渲染为圆形。

编辑对象图层样式器

通过打开图层的样式面板来编辑对象图层的样式器。展开任意单个样式器以编辑其样式选项（颜色、不透明度等），或使用 添加样式器 按钮：

添加样式器菜单包含两个部分：

  • 按对象属性： 由地图根据图层的对象类型推断出的简单预配置样式器。
  • 按样式器类型： 具有更多配置选项的高级样式器。只有可为图层的对象类型进行完整配置的样式器才会启用。

可以为对象图层显式配置的高级样式器类型包括：

  • 图标： 为每个对象渲染一个带图标的标记。
  • 圆形： 根据中心点和半径值为每个对象渲染一个圆形。
  • 线段： 在两点之间渲染一条线段。
  • 轨迹面包屑： 对于移动对象，在对象的每个记录位置渲染一个圆形。
  • 轨迹线： 对于移动对象，渲染一条连接对象每个记录位置的线。

移动几何图形插值

当样式器中使用的几何源是轨迹（即随时间变化的位置）时，会出现一些附加选项，用于配置地图如何根据轨迹和 时间光标来选择要使用的点位置。

  • 插值模式： 更改地图是在已知点之间进行线性插值，还是使用最后一个已知点。
  • 最大时间间隔： 当两个连续轨迹点之间的时间差大于所配置的值时，轨迹会被视为在该时间段内没有数据，并且当时间光标位于该时间段内时，将渲染为无数据状态。

已保存的样式

已保存的样式 允许您保存地图的多种不同样式并在这些样式之间切换。在一张地图中提供多种样式，可以帮助您或地图的使用者理解所可视化数据的许多不同维度，而无需手动编辑图层样式。
