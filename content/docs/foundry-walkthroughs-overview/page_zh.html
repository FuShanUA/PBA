Walkthroughs

Walkthroughs 使用户能够生成自定义的分步教程，引导最终用户完成应用程序或工作流程。借助 Walkthroughs，您可以提供自定义的按需资源，改变最终用户的学习方式，从而利用根据您组织需求量身定制的自主引导式教程。

核心功能

  • 直观的界面： Walkthroughs 提供直观的设置界面，允许用户在创建 walkthrough 的过程中随时预览最终效果。
  • 跨应用程序引导： Walkthroughs 并不仅限于单个应用程序；一个 walkthrough 可以引导用户完成涵盖 Palantir 平台上多个应用程序的工作流程。
  • 共享学习： Walkthroughs 可以在整个组织内共享，为工作流和用例提供有针对性的按需支持。
  • 可自定义的内容： 创建量身定制的教程，以应对特定于您运营需求的用例和工作流。
  • 易于访问： 可以通过工作区侧边面板访问 Walkthroughs，因此学习资源在需要时始终可用。
  • 富媒体集成： 通过图像、视频和交互元素增强您的教程。
  • 进度跟踪： Walkthrough 会跟踪各个步骤的进度，让用户可以稍后回来，从上次中断的地方继续。

权限

要访问某个 walkthrough，用户必须拥有 Viewer 对该 walkthrough 资源的访问权限。如果用户对 walkthrough 中引用的资源没有权限，系统将不会引导他们前往该资源，而是会显示一条消息，提示存在他们无权查看的资源。

任何拥有 Editor Project 权限的用户都可以在该 Project 中创建 walkthrough。

访问已发布的 walkthrough

在查看具有关联 walkthrough 的资源时， 操作指南 选项将显示在工作区侧边栏中。

要访问操作指南，请选择 操作指南 选项（位于工作区侧边栏中）。当选择 下一步 或 上一步 在任意给定步骤中， Walkthroughs 面板会自动将您重定向到相应的资源。选择 了解更多 以访问每个步骤附带的文档。

您可以通过选择 文件 标签页查看所有相关的演练资源，并在顶部面板中查看所有最近或可用的演练。要暂停或恢复演练，您可以关闭或打开 分步指南 面板（当相关资源打开时）。
