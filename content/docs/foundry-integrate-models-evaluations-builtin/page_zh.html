内置评估器

palantir_models 包含用于标准回归和分类模型的预构建评估器。内置评估器会对您的模型运行推理，将预测结果与真实值列进行比较，并将一组标准指标记录到 评估 中，因此您无需手动计算常用指标。

内置评估器需要安装 scikit-learn 在您的环境中。

直方图 evaluate 函数

直方图 palantir_models.evaluations.evaluate 函数驱动内置评估器。您需要提供模型、输入数据、真实值列的名称，以及用于选择要使用的评估器的评估器配置。

import palantir_models as pm
from palantir_models.evaluations import evaluate, RegressionEvaluatorConfig
from palantir_models.transforms import ModelInput
from transforms.api import transform, Input


@pm.transforms.evaluation("error_analysis")
@transform.using(
    test_data=Input("/Housing/clean/test_set"),
    housing_model=ModelInput("/Housing/models/price_regressor", use_sidecar=True),
)
def compute(test_data, housing_model):
    evaluate(
        model=housing_model,
        inputs=test_data.pandas(),
        targets="actual_price",
        prediction_column="predicted_price",
        evaluator_config=RegressionEvaluatorConfig(),
    )

当在使用装饰器修饰的转换中调用时 @pm.transforms.evaluation, evaluate 会自动写入评估；您无需自行调用 create_evaluation 。要记录到您已创建的评估中，请通过 evaluation 参数选择一个百分比。

evaluate 传递它，并返回一个 EvaluationResult ，其 metrics 属性保存计算得到的指标。相同的指标也会作为副作用记录到评估中。

输入、目标和预测

  • inputs 会被转发给模型进行推理。 pandas or pyspark DataFrame 作为单个参数传递； tuple 会被解包为位置参数； dict 会被解包为关键字参数（除非模型声明了单个 map or struct 输入，在这种情况下字典会原样传递）。Spark DataFrame 会被物化为 pandas 以进行指标计算，因此数据必须能够放入驱动程序的内存中。
  • targets 是真实值列的名称。它必须解析为恰好一列，在 evaluation_df 中查找（如果提供），否则在 inputs来查找覆盖缺口；具有该键的节点是您工作流中没有任何监控视图在监视的资源。 evaluation_df 中查找。用于在真实值列不属于 inputs.
  • prediction_column 时提供真实值列。是模型输出中保存预测结果的列的名称。默认值为 targets的值，因此当模型输出列的名称不同时应显式设置。

模型要求

由于 evaluate 会为您运行推理，您的模型适配器必须满足以下几项要求：

  • 推理方法： evaluate 会调用您适配器的 predict 方法（如果您已重写该方法），否则回退到 transform。其中之一必须运行推理，且 predict 应接受与声明的每个 API 输入对应的参数，并按名称匹配。
  • 输入形状： 的形状 inputs 必须与模型声明的 API 输入匹配，遵循 输入、目标和预测.
  • 中的分发规则。输出形状： 推理必须返回一个 DataFrame——或一个 InferenceResults, dict, tuple，或 list 包含 DataFrame 的——且这些 DataFrame 中必须恰好有一个包含 prediction_column。如果没有输出 DataFrame 包含该列，或者有多个包含该列，评估将失败。
  • 概率列： 对于分类 roc_auc，配置的概率列也必须存在于输出中。

回归

用途 RegressionEvaluatorConfig 适用于预测连续值的模型。回归评估器会记录以下指标：

指标描述
example_count评估的样本数量。
mean_absolute_error平均绝对误差（MAE）。
mean_squared_error均方误差（MSE）。
root_mean_squared_error均方根误差（RMSE）。
r2R²（决定系数）。
max_error最大残差误差。
mean_absolute_percentage_error平均绝对百分比误差（MAPE）。

分类

用途 ClassificationEvaluatorConfig 适用于二元和多类别分类器。评估器将问题视为二元还是多类别，是根据预测和标签中发现的唯一类别数量自动确定的。

所有分类评估都会记录以下指标：

指标描述
example_count评估的样本数量。
accuracy总体准确率。
precision精确率。
recall召回率。
f1F1 分数。

此外：

  • 二元分类器 还会记录混淆矩阵计数 true_positives, true_negatives, false_positives日 false_negatives.
  • 多类别分类器 compute precision, recall日 f1 使用由 average 配置选项设置的平均策略。
  • 当提供类别概率时， roc_auc 也会使用一对其余（one-vs-rest）方案进行记录。

配置选项

选项类型描述
average"weighted" (default), "micro", "macro"，或 "samples"的平均策略，用于 precision, recall, f1日 roc_auc 多类别模型。对二元分类器忽略。
class_probabilities_columnsOptional[List[str]]每个类别对应一个模型输出列，按类别索引排序。 roc_auc.
class_probability_columnOptional[str]单个模型输出列，其行值为各类别概率的数组形式。必须通过 roc_auc.

提供类别概率 恰好一个 of class_probabilities_columns or class_probability_column；同时提供两者会引发错误。所引用的列必须存在于模型的输出中。若不提供概率， roc_auc 则被省略。

将内置指标分组为子集

每个评估器配置都接受一个 subset 选项。设置后，该评估器记录的所有指标都会加上前缀 subset/，从而将它们分组为一个 子集 显示在模型页面上。这使您可以对数据的不同切片运行相同的评估器并进行比较。

from palantir_models.evaluations import evaluate, RegressionEvaluatorConfig

# Evaluate each price tier separately and group the metrics under that tier.
for tier, group in test_data.pandas().groupby("price_tier"):
    evaluate(
        model=housing_model,
        inputs=group,
        targets="actual_price",
        prediction_column="predicted_price",
        evaluator_config=RegressionEvaluatorConfig(subset=tier),
    )

这会记录诸如 affordable/mean_absolute_error 和 luxury/r2.
