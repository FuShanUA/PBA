Time series property

Get a time series property or linked sensor associated with an object. To add a linked sensor, follow the steps below: 1. Select a root object type (for example: Weather Station). 2. Select a specific object instance (for example: FARO A). 3. Select a time series property or sensor from the dropdown showing available sensors. Once a sensor is selected it is rendered as a time series plot.

Input type

Object

Output type

Time series

You can also use the Columns button in the upper-right corner of the table to add time series properties or sensors.
