创建新应用程序

在用例应用程序中有两种创建新应用程序的方法：从概览页面创建，或通过左侧边栏从应用程序页面创建。

从概览页面创建新应用程序

在您的用例概览页面上，选择 + 创建新应用程序 位于 应用程序 区域的字段中添加命令。

如果您的用例尚未保存任何应用程序，您还可以选择 + 添加新应用程序 在该区域的中央。

从左侧边栏创建新应用程序

选择 应用程序 在左侧边栏中选择以打开应用程序页面。然后，选择 创建新应用程序 在右上角。

在监听器设置向导的 创建新应用程序 模态框中，选择您想要构建的应用程序，然后选择 创建.
