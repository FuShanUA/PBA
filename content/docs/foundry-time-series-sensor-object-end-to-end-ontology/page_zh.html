使用 Ontology Manager 创建传感器对象类型

本指南介绍如何使用 Ontology Manager 创建传感器对象类型并将其关联到根对象类型。完成以下步骤后，您将能够在平台中与传感器对象类型进行交互。在本示例中，您将创建一个 Flight Sensor 对象类型并将其关联到一个 Flight 根对象类型的模板化派生序列将不会显示在为针对

第一部分：创建传感器对象类型

  1. 导航到 Ontology Manager，然后选择 ,其中显示地图上各对象类型的对象数量。下方,每种属性类型各有一个部分,涵盖地图上存在的所有对象类型。面板顶部的筛选框允许您将结果筛选为名称匹配的属性。 （从左侧面板中）。
  2. 在屏幕右上角，选择 新建对象类型.
  3. 在出现的配置对话框中，配置您的对象类型元数据。
  4. 在监听器设置向导的 属性 步骤中，选择使用以下数据集支撑该对象类型： [Example] Sensors 您使用以下管道创建的数据集： 传感器数据管道.
  5. 然后，在 属性 字段中，选择字符串类型 unique_sensor_flight_id 属性作为主键。您也可以选择 同步数据源中的所有列 or 映射所有列 （如果这些选项可用）。
  6. 从左侧面板中选择 Title 列作为标题属性，这允许 Flight Sensor 对象类型在整个应用程序中以人类可读的名称显示。

  1. 根据您的平台版本，您可能会看到为以下对象类型配置权限和操作的选项： Flight Sensor 对象类型。我们的示例不需要额外的权限或操作配置。

  2. 完成对话框中的所有步骤后，选择 创建.

在 属性 新对象类型的 [Example] Sensors 选项卡，属性应如下图所示：

第二部分：为传感器对象类型配置时间序列属性

  1. 在 Data Connection 中导航至 [Example] Flight Sensor 在 Ontology Manager 中的对象类型，然后选择 功能 选项卡（从左侧面板中）。
  2. 在 时间序列属性 部分中，选择 + 添加.
  3. 选择现有的 Flight Sensor Series Id 属性作为时间序列属性，然后选择 设为默认时间序列属性 以便它自动显示在 Quiver 中。

  1. 选择您创建的时间序列同步 （在 Pipeline Builder 中）。在我们的示例中，它被称为 [Example] Time Series Sync | Sensor Readings.

  1. 选择 添加属性 以保存时间序列属性配置。

第三部分：将传感器对象类型关联到根对象类型

使用以下步骤在 [Example] Flight Sensor 和 [Example] Flight 对象类型之间添加关联。

  1. 在 [Example] Flight Sensor 在 Ontology Manager 中的视图，选择 新建 下拉菜单并选择 关联类型
  2. 在关联的左侧，选择 [Example] Flight Sensor 对象类型。在右侧，选择 [Example] Flight 对象类型。
  3. 将左侧 Flight Sensor 对象类型的基数设置为 多，右侧 Flight 对象类型的基数设置为 一，这意味着 Flight 对象类型与以下对象类型之间存在一对多关系： Flight Sensor 对象类型。
  4. 将 flight_id 列设置为以下对象类型的外键： Flight Sensor 对象类型，这将把 flight_id 设置为以下对象类型的主键： Flight 对象类型。

了解更多关于 关联类型（link types）.

第四部分：配置传感器对象类型

在时间序列部分，确保传感器对象类型的开关已打开。设置 Sensor link 以使用最近创建的 Flight to Flight Sensor 关联，将其分配给给定的 Employee。

  1. 将 链接 名称作为 Series Name 列。应用程序将在此系列名称下显示传感器对象数据。

  2. 组织 单位 的历史，方法是选择 单位 在传感器对象类型设置中的下拉菜单。

是否为分类 和 内部插值 可以从传感器对象类型上的属性推断得出，但在本用例中并非必需。 是否为分类 仅在需要区分分类时间序列值与数值时间序列值时才需要。 是否为枚举？ 在本用例中同样不是必需的，您可以忽略 Is deprecated 和 Sparkline preview 属性。

内部插值 用于让 Quiver 等应用程序推断相邻数据点之间的序列值。请查阅我们的 Quiver 插值文档 的文档以获取更多信息。

  1. 选择 保存 从屏幕右上角对对象类型的编辑，以在 Ontology 和整个平台中查看更改。

现在，您已准备好使用 Flight Sensor 和 Flight 在操作场景中使用对象类型。请继续阅读文档以了解如何 在 Workshop 和 Quiver 中使用传感器对象类型时间序列数据.
