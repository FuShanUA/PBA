向 Marketplace 产品添加对象和关联类型

用途 Foundry DevOps 将您的对象和关联类型包含在 市场产品 中，以便其他用户安装和重用。 了解如何创建您的第一个产品。

不支持的功能

大多数 对象属性类型 在 Marketplace 产品中受支持，但以下类型尚不可用：

  • 密码
  • 地理时间
  • 向量

对象本身无法随 Marketplace 打包。这意味着，例如，由操作（Actions）对对象所做的编辑无法打包到 Marketplace 产品中。但是，可以对数据集和对象类型进行打包，以便在安装 Marketplace 产品后创建新对象。

没有支撑数据源的对象类型 在 Marketplace 产品中受支持。

如果您需要上述任何不支持功能的支持，请联系 Palantir 支持团队。
