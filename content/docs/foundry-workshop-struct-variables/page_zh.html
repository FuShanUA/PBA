结构体变量

A 结构体变量 是一种复合变量，包含其他 Workshop 支持的 变量类型的字段。目前不支持嵌套结构体。

创建结构体变量

结构体变量可以在 Workshop 中静态初始化，也可以使用对象的 struct 属性，或使用返回 CustomType对象，您的计算函数必须接受一个名为 自定义类型文档 以了解更多。如果某个字段的类型在 Workshop 中不受支持，该字段将被忽略，并从初始化的变量中省略。

结构体和结构体数组变量也可以通过本体论 SQL 查询进行计算，其中字段派生自查询返回的列。请参阅 SQL 查询变量 文档以了解更多。

创建结构体数组变量

类似地，包含多个结构体的结构体数组变量可以使用对象的 struct array 属性或函数进行初始化。

遍历结构体数组

结构体数组变量可用于循环布局，从而在应用程序中实现性能更佳的循环设置，减少显示对象数据所需的加载调用次数；也可用于构建者希望显示由函数输出的非本体论数据的工作流中。要了解有关遍历数组的更多信息，请参阅 循环布局文档.

从结构体中提取字段

组件和变量转换操作无法整体使用结构体，因此必须提取各个结构体字段以供使用。下图展示了如何将字符串类型 name 字段从 person 结构体变量中提取，使用 提取结构体字段变量转换，然后用于 指标卡片组件.

将结构体用作函数输入

结构体和结构体数组变量也可以用作函数的输入。在配置使用结构体作为输入的函数时，可以通过悬停在 Preview schema 标签上预览结构体输入的必填字段。这使构建者能够通过将其与所选结构体变量的原始 Current value.
