参考轮廓边界

创建一个有界区域来表示多个时间序列之间的变异性，可用于根据这些边界监控其他时间序列。每个时间戳处的边界按以下步骤计算：

  1. 聚合该时间戳处的数据点，以计算平均值和标准差。
  2. 将平均值与标准差相加，生成上界。
  3. 用平均值减去标准差，生成下界。

使用相对时间序列，以确保存在可聚合的重叠数据。可以使用 事件比较图创建相对时间序列组，或对现有时间序列组使用 相对时间序列转换 来创建。下面的示例展示了如何根据优质茶叶批次的湿度数据创建参考轮廓边界，并将其用于监控其他批次的湿度。

输入类型

时间序列组

输出类型

  • 您可以使用 线性聚合 卡片来计算多个序列的平均值或标准差，如果您更希望得到的是单个代表性序列而非边界区域。
