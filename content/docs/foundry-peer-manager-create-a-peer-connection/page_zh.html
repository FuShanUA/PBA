创建对等连接

您可以在 Peer Manager 中创建和删除对等连接。

前提条件

在创建对等连接之前，您必须完成以下步骤：

  • 使用 网络入口 和 网络出口 扩展，在 Control Panel 中为您要建立对等连接的 注册 配置入口和出口策略。

要建立从您的注册导出数据的对等连接，您的本地注册必须允许通往远程注册的出口。此外，远程注册必须允许来自您的本地注册的入口。如果您要建立将数据从远程注册导入本地注册的对等连接，则情况相反。您的本地注册必须允许来自远程注册的入口，而远程注册必须允许通往您的本地注册的出口。

  • 直接在 Peer Manager 中建立您的注册与远程注册之间的连接。如果两个注册之间存在可用的网络连接，请 建立 Multipass exchanger (MPX) 连接。如果没有可用的网络连接，请通过您注册现有的跨域解决方案 建立数据中继连接 。
  • 请确保您是您要为其创建连接的本地 空间 的管理者。
  • 设置 平台标题 为您的注册，以便远程对等方能够 识别您的注册。

发起对等连接

要发起对等连接：

  1. 选择 创建对等请求 ，从 Peer Manager 的右上角打开 创建对等请求 对话框。
  2. 确定您注册的空间，请在 选择要对等的空间 下拉菜单中进行。
  3. 选择要导出、导入或两者兼有的数据类型。
  4. 选择 复制邀请码。
  5. 与对等注册上的管理员共享邀请码，该管理员将导入对等连接。

导入对等连接

要在收到邀请码后导入对等连接：

  1. 选择 输入邀请码 以打开 导入对等请求 弹出窗口。
  2. 将邀请码粘贴到空文本框中，以显示该弹出窗口中的 连接详情 面板。

  1. 确定您注册中用于接受对等对象或 Artifacts 的空间，请在 选择要对等的空间 下拉菜单中进行。

  2. 选择 设置安全性 ，以根据需要设置 连接的安全性。

  3. 选择 批准请求。

激活对等连接

在对等请求被接受后，请求发起方必须 激活 其右侧面板右下角的连接。
