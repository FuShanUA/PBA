变量支撑的布局

变量支撑的布局允许您使用变量动态控制布局组件的状态。这使您能够构建响应式应用程序，让用户界面元素对用户交互、对象属性或在函数中定义的自定义逻辑做出反应。

以下布局组件支持变量支撑：

  • 页面： 控制多页面模块中显示哪个页面
  • 区块： 控制可见性和折叠状态
  • 在分区顶部添加标签页，允许模块构建者在分区的每个标签页内配置不同的组件组合。 控制选中哪个选项卡
  • 浮层： 控制浮层处于打开还是关闭状态

字段或设置面板中的

您可以将字符串变量绑定到多页面模块，以控制显示哪个页面。当变量值与某个页面的 ID 匹配时，该页面将变为活动状态。

配置变量支撑的页面选择：

  1. 在编辑模式下，从左侧边栏打开模块设置面板。
  2. 在配置面板中的 页面下方，找到 字段或设置面板中的 setting.
  3. 选择一个字符串变量来控制显示的页面。
  4. 为每个页面设置唯一的 页面 ID ，使其与变量将包含的值相匹配。

此功能适用于通过 URL 参数深度链接到特定页面、根据用户操作在页面之间导航，或通过接口变量从父模块控制页面选择。

当 路由 已启用时，请将页面选择变量的默认值留空。路由会从 URL 提供初始值，而配置的默认值将在初始渲染时覆盖该值。

布局事件 切换页面的事件不会更新为变量支撑的页面选择配置的变量。若要让变量与事件触发的页面更改保持同步，请改用 set variable value 事件。

变量支撑的区块条件可见性

您可以将布尔变量绑定到区块，以控制其显示还是隐藏。默认情况下，当变量求值为 true 时区块隐藏，求值为 false时区块显示。您可以通过更改变量选择右侧的布尔选择器来反转此默认行为。

配置变量支撑的区块可见性：

  1. 在模块中选择该区块。
  2. 找到并启用 条件可见性 setting.
  3. 在配置面板中，找到 满足条件时隐藏区块 setting.
  4. 选择一个布尔变量来控制区块可见性。
  5. （可选）配置区块在布尔变量为 false 时隐藏。

这与折叠状态功能的区别在于：隐藏的区块完全不会出现在布局中，而折叠的区块仍会显示其标题，并且用户可以将其展开。系统不会提供用于更新区块可见性的事件。请改用 set variable value 事件。

变量支撑的区块折叠状态

您可以将布尔变量绑定到可折叠区块，以控制其展开还是折叠。当变量求值为 true时，区块折叠。当求值为 false时，区块展开。

布局事件 展开、折叠或切换区块的事件不会更新为变量支撑的折叠状态配置的变量。若要让变量与事件触发的区块状态更改保持同步，请改用 set variable value 事件。

配置变量支撑的折叠状态：

  1. 在模块中选择该区块。
  2. 在配置面板中，启用 可折叠 setting.
  3. 找到 变量支撑的折叠状态 设置并选择一个布尔变量。

此功能适用于仅在存在相关数据时才展开区块，或用于协调多个区块的展开和折叠行为。

变量支撑的浮层打开状态

您可以将布尔变量绑定到浮层，以控制其打开还是关闭。当变量求值为 true时，浮层打开。当求值为 false时，浮层关闭。

布局事件 打开或关闭浮层的事件会更新为变量支撑的打开状态配置的变量。您还可以配置 关闭时 事件，以便在浮层关闭时重置上游变量或执行其他操作。

配置变量支撑的浮层状态：

  1. 在模块中选择该浮层。
  2. 在配置面板中，找到 变量支撑的打开状态 setting.
  3. 选择一个布尔变量来控制浮层状态。

此功能可用于响应事件打开叠加层、通过接口变量从父模块控制叠加层状态，或协调多个叠加层。

变量支持的选定标签页

您可以将字符串变量绑定到标签页容器，以控制当前选中的标签页。当变量值与某个标签页的 ID 匹配时，该标签页将变为活动状态。此功能是双向的：选择标签页会更新变量，而更改变量则会选中相应的标签页。

与页面选择和分区折叠状态不同， 布局事件 更改选定标签页时，也会更新为变量支持的标签页选择所配置的变量值。

要配置变量支持的标签页选择：

  1. 在模块中选择标签页容器。
  2. 在配置面板中，找到 ，将用于确定所选选项卡。可以通过在选项卡部分的 setting.
  3. 选择一个字符串变量来控制选定的标签页。
  4. 为每个标签页设置唯一的 标签页 ID ，使其与变量将包含的值相匹配。

此功能可用于在多个标签页容器之间同步标签页状态、通过模块接口变量将选定的标签页保留在 URL 中，或根据模块中其他位置的用户操作以编程方式切换标签页。
