防范网络钓鱼攻击

网络钓鱼是攻击者在试图入侵技术基础设施时最常用的攻击向量。如果攻击者通过网络钓鱼攻击成功接管或窃取了 Foundry 客户的 SSO 账户凭据，他们很可能会尝试使用这些凭据访问 Foundry 平台。Palantir 已设计多项控制措施来帮助缓解网络钓鱼攻击可能带来的安全影响。然而，本着维护 共享安全模型的理念，Palantir 还建议客户遵循若干最佳实践，以加固自身攻击面、防范网络钓鱼。

多因素认证（MFA）

Foundry 客户负责通过单点登录（SSO）管理用户的访问权限和身份。在保护身份验证流程安全方面，最具影响力的控制措施之一是强制实施多因素认证（MFA）。确保所有用户都注册了 MFA，意味着攻击者需要攻破多重安全控制才能不当访问 Foundry 平台。

入口控制

Palantir 原生支持入口控制，具体说明请参阅 《配置网络入口》文档。Palantir 建议采用严格的 IP 白名单作为纵深防御控制措施，旨在阻止攻击者获得发起攻击行动所需的网络访问权限。

此外，Foundry 侧的任何入口控制都可以在用户自身的 SSO 控制中进行镜像，以实现冗余。

条件访问

如果使用 Microsoft Azure AD（或具有类似功能的 IdP），可以考虑利用 条件访问策略 ↗ 来进一步加强对 Foundry 的访问控制。即使在 IP 入口限制不可行的情况下，基于其他因素（例如是否已在设备管理中注册）限制访问，仍然可能具有安全价值。

单点登录（SSO）

如果任何客户无法实施具备适当安全控制措施的单点登录（SSO）解决方案，请联系您的 Palantir 代表；我们或许可以为您提供相关解决方案。

运营安全

在成功的钓鱼攻击中，人往往是关键的失败点，因此适当的 OpSec（操作安全）培训是确保用户不成为受害者的关键。与人员沟通时应涵盖的要点包括：

  • 密码卫生与管理。
  • 识别合法的网络域名（如 palantirfoundry.com）与攻击者运营的欺诈网站。
  • 识别来自 Foundry 平台的合法电子邮件与欺诈发件人发送的电子邮件。
