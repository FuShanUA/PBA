如何在 Slate 中检索和处理通过 iframe 部件从 Workshop 模块传入的对象集，尤其是在处理大量对象时？

要在 Slate 中检索和处理通过 iframe 部件从 Workshop 模块传入的对象集，请按照以下步骤操作：

  1. 用途 slate.getMessage 以获取筛选器负载。此步骤的代码片段为：

    const payload = {{slEventValue}};
return payload["workshop_variable_name"]

  2. 使用筛选器规范的负载设置一个 Slate 变量。

  3. 使用以下请求体查询对象集服务，并将 {{slate_var}} 替换为您的变量名：

    {
    objectSet: "{{slate_var}}",
    pageSize: 50
}

    这将返回一个 RID（资源标识符）列表。

  4. 使用 TypeScript 函数检索包含所有属性的对象。此步骤的代码片段为：

    Objects().search().yourObject(listOfRids).allAsync()

存在 100,000 个对象的限制，适用于 Objects().search()。如果您的对象集大于 pageSize，您需要通过创建一个函数来遍历每个分页结果，从而处理分页。 pageSize 可以根据您预期检索的对象数量以及对象服务和用户网络能够处理的数量进行调整。
