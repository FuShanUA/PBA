如何检索和处理通过 iframe 小部件从 Workshop 模块传递到 Slate 的对象集，尤其是在处理大量对象时？

要检索和处理通过 iframe 小部件从 Workshop 模块传递到 Slate 的对象集，请按照以下步骤操作：

  1. 使用 slate.getMessage 来获取筛选器负载。此步骤的代码片段如下：

    const payload = {{slEventValue}};
return payload["workshop_variable_name"]

  2. 使用筛选器规范的负载设置一个 Slate 变量。

  3. 使用以下请求体查询对象集服务，将 {{slate_var}} 替换为您的变量名称：

    {
    objectSet: "{{slate_var}}",
    pageSize: 50
}

    这将返回一个 RID（资源标识符）列表。

  4. 使用 TypeScript 函数来检索包含所有属性的对象。此步骤的代码片段如下：

    Objects().search().yourObject(listOfRids).allAsync()

请注意，存在 100,000 个对象的限制，适用于 Objects().search()。如果您的对象集超过 pageSize，您需要创建一个函数来遍历每个分页结果，以处理分页。该 pageSize 可根据您预期检索的对象数量以及对象服务和用户网络所能处理的范围进行调整。
