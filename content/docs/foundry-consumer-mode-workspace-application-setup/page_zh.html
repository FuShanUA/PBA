平台内消费者应用程序

Workshop、Slate 和 Carbon 应用程序均可配置为具有受限平台访问权限的消费者应用程序。这些应用程序支持自定义应用程序的快速迭代，让您能够以最少的维护负担将其部署给客户。

本指南将重点介绍 Workshop 应用程序 ，其非常适合以下用例：

  • 快速应用程序开发 ，提供低代码构建体验。
  • 交互式数据应用程序 ，需要丰富的用户界面。
  • 仪表板和分析 ，包含复杂的可视化。
  • 决策支持工具 ，将数据分析与操作相结合。

所有平台内应用程序均使用交互式登录流程，该流程可配置为自动重定向到已配置的身份提供程序。这为消费者用户提供了无缝的身份验证体验。请参阅 默认身份验证提供程序设置 以了解配置详情。

前提条件

本指南要求具备在 Workshop 中构建应用程序的经验。在以消费者模式发布平台内应用程序之前，请确保您已完成 Foundry 中的消费者模式配置。

设置

部署消费者产品有两种方法：

  1. [推荐] 使用 Marketplace，并创建独立的环境，将构建和测试与生产隔离开来。
  2. 直接在消费者空间中构建和编辑产品。

在本指南中，我们将直接在消费者空间中构建和编辑产品。但是，我们建议使用发布管理来实现更稳健的发布管理流程。请参阅我们的 DevOps 发布管理文档 以了解更多信息。

步骤 1：构建消费者应用程序

  1. 从模板创建项目： 使用消费者项目模板创建新项目。确保自动应用适当的角色分配。
  2. 配置对象类型和操作：
    • 创建属性适合消费者使用的对象类型。
    • 以最低要求的权限配置操作。
    • 设置具有适当消费者访问控制的数据源。
  3. 开发 Workshop 应用程序： 在项目中使用已配置的对象和操作创建新的 Workshop 应用程序。

步骤 2：配置消费者主页

  1. 导航至 控制面板 > 平台体验。
  2. 选择您的消费者组织。
  3. 查看 默认应用程序 （针对您的消费者）。
  4. 配置 主页 URL ，以将用户引导至该应用程序。

步骤 3：配置权限

  1. 将消费者组织添加到项目中： 导航至您的消费者项目。在右侧面板的 访问 标签页中，添加消费者组织并为其分配 Consumer 角色。
  2. 配置支撑数据集权限： 对于消费者应用程序中使用的对象类型的每个支撑数据集，请执行以下操作：
    • 将消费者组织添加到数据集的项目权限中。
    • 如果支撑数据集不在消费者空间中，请将其移动到消费者空间中的某个项目。
    • 如有需要，使用 受限视图 配置行级安全性，然后更新对象配置以使用该受限视图。
  3. 配置本体论权限： 将函数封装在操作中，以便更轻松地设置权限。对于应用程序中使用的所有操作，请将消费者组织组添加到操作提交条件中。

验证消费者用户体验

部署应用程序后，请按照以下步骤验证消费者用户体验。

  1. 测试消费者用户登录： 使用测试消费者账户登录。
  2. 验证自动重定向： 确认用户登录后会被重定向到正确的应用程序。
  3. 检查应用程序功能： 确保所有功能正常运行。
  4. 测试权限边界： 验证消费者用户无法访问内部资源。
  5. 验证数据访问： 确认用户只能通过已配置的限制查看相应的数据。

验证项目访问权限

在消费者项目的文件视图中，打开右侧面板中的 访问 选项卡。然后，选择 检查访问 以验证以下内容：

  • 消费者用户拥有访问应用程序所需的权限。
  • 消费者用户无法访问内部项目或数据集。
  • 角色分配按预期工作。

安全最佳实践

请遵循以下建议，以帮助保护用户和数据：

  • 将用户分隔到不同的组织中，以实现严格隔离。
  • 启用私有组织以防止用户被发现。
  • 为消费者、构建者和管理员使用不同的角色。
  • 定期审查组织和应用程序权限。

故障排除

用户无法访问应用程序

请验证该用户已被分配到正确的消费者组织，并确认该消费者用户在项目中拥有适当的角色。

应用程序功能无法正常工作

确保消费者组织有权访问所有必需的对象类型。验证消费者用户可以提交所需的操作，并且消费者用户组可以访问支撑数据集。

平台访问未受限

在 Control Panel 中审查平台访问限制，并确保主页 URL 配置正确。如果使用外部域名，请验证自定义域名设置。
