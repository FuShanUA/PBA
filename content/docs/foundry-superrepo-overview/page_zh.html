SuperRepo [测试版]

测试版

SuperRepo 目前处于 测试版 开发阶段，您的注册中可能无法使用该功能。在持续开发期间，功能可能会发生变化。

SuperRepo 是 Foundry 推出的一种全新方式，让开发者能够在专业代码（pro-code）monorepo 中构建以本体论为核心的复杂全栈应用程序。SuperRepo 提供了对平台越来越多核心组件的访问，例如 函数、 本体论以及 React 应用程序，以便在开发复杂应用程序时实现更深入的集成和更快的开发周期。

随着越来越多的平台功能获得一流的 SuperRepo 支持、覆盖日益增多的使用场景，SuperRepo 将成为以专业代码方式与平台功能交互的首选途径。

SuperRepo 旨在从两个角度改善应用程序的构建和交付体验：

  • 开发者体验： 集成在单个仓库中的全栈应用程序以及 Foundry CLI 使开发者能够在开发过程中测试其跨越整个应用程序的变更，而无需在各个阶段之间等待。这提高了开发者循环的迭代速度，使问题或中断能够立即浮现。
  • 可编程 DevOps： SuperRepo 允许开发团队和管理员在自己选择的位置托管代码，然后通过所选的 CI/CD 系统将其部署到多个环境，其中包括一个开箱即用的集成系统。Foundry CLI 可通过 Marketplace实现程序化 DevOps，使团队能够沿用现有流程，以自包含、可重现且经加密签名的捆绑包交付代码。

SuperRepo 的一项核心架构选择是围绕本体论构建，这使专业代码（pro-code）开发团队能够以代码方式构建本体论对象和应用程序，同时接入强大的 Foundry 生态系统。

最好将 SuperRepo 视为一种与平台交互的新界面。例如，SuperRepo 默认集成了本体论即代码（Ontology-as-code），支持以编程方式定义应用程序的领域模型。在本体论即代码中创建的类型在 UI 中可见，而在 UI 中创建的类型也可以 导入 到本体论即代码中。应用程序绝不会因本体论类型的创建方式而被孤立。
