开始使用

本教程将引导您构建一个简单的移动端 Workshop 应用程序，允许用户查看航班数据、筛选航班以及查看每个航班的详细信息。本教程使用大多数 Foundry 环境中包含的示例数据。由于 Foundry 本体论是根据您的需求和数据定制的，您可能无法访问教程中所述的确切对象类型。

本教程重点介绍创建移动端 Workshop 应用程序所需的步骤，并假设您已经熟悉构建 Workshop 应用程序以及使用本体论操作配置写回。如果您从未使用过 Workshop 或操作，建议先从常规的 Workshop 和操作类型教程开始：

  • Workshop 入门
  • 操作类型入门

第 1 部分：初始设置

首先，按照以下步骤创建一个可用于滚动浏览航班数据的基本应用程序：

  1. 创建一个新的 Workshop 模块。

  2. 选择 设置 在左侧边栏中，然后切换到 移动设备 设备类型。编辑器的尺寸将切换为移动设备的尺寸，布局将更新为单列。

  3. 现在，通过禁用旁边的开关来关闭导航栏 模块导航栏可见 在右上角。

  4. 选择 概述 在左侧边栏中，然后选择 添加对象集变量 开始向您的应用程序添加数据。在本例中，添加 [Example Data] Flight 对象类型到您的模块。

  5. 选择 + 添加小组件 并添加一个 对象列表 小部件到您的应用程序。配置该小部件以使用您的航班对象集变量，然后选择要在列表中显示的属性。在本例中，添加属性 Carrier Name, Origin City Name, Destination City Name, Departure日 Arrival 到列表中。

至此，您已经创建了一个可用于滚动浏览航班数据的基本应用程序。在下一步中，您将为此应用程序添加一些交互功能。

第 2 部分：添加筛选

在教程的这一部分中，您将添加筛选航班列表的功能。为了给用户提供足够的屏幕空间来应用筛选器，您将把筛选功能嵌套在 Workshop 抽屉中。

  1. 选择 的 在左侧边栏中，然后选择 + 并添加一个 新抽屉 到应用程序。将抽屉的标题和名称更新为“筛选航班”，并将其图标设置为筛选图标。

  2. 在抽屉中，选择 + 添加小组件 并添加一个 筛选列表 小部件。将筛选列表的输入数据配置为您之前创建的航班对象集变量。

  3. 自动预览行为 筛选器配置中，选择一些用户应该能够筛选的属性。在本例中，添加以下属性的筛选器 Origin City Name, Destination City Name日 Cancellation reason 属性。

  4. 使用以下方式关闭抽屉 X 在编辑器视图的右上角。回到航班视图中，点击 + 在顶部工具栏中，以在工具栏中添加一个小部件。选择 按钮组 小部件。

  5. 将按钮设置为具有 极简样式 和 大样式，然后选择 Button 1 以配置按钮及其行为。在本例中，我们希望按钮只显示筛选图标。删除按钮文本，然后在以下选项下选择筛选图标 左侧图标中的分支提案。选择 + 添加事件，然后选择 打开筛选航班.

  6. 接下来，更新您的对象列表以遵循筛选列表小部件生成的筛选器。选择对象列表小部件，然后通过选择以下选项来删除对象集变量配置 X 位于 输入数据.

  7. 选择 新对象集变量，并将您的新变量命名为“Filtered flights”。

  8. 自动预览行为 起始对象集中，选择您现有的名为“[Example Data] Flight”的对象集变量。接下来，选择 使用变量筛选 并选择您的筛选列表小部件的输出。

至此，您已为用户添加了根据您配置的一组属性筛选航班列表的功能。为了避免界面杂乱，这些筛选器显示在全页抽屉中，以便用户在返回筛选后的列表之前可以轻松地一次配置多个筛选器。

尝试打开抽屉并筛选来自 科罗拉多州丹佛 的因 天气而取消的航班。关闭抽屉，您将看到航班列表已相应更新。

在下一步中，您将让用户浏览所选航班的更多详细信息。

第 3 部分：添加所选对象视图

在本部分教程中，您将使用户能够在从列表中选择航班时导航到其他页面查看详细信息。

  1. 选择 的 在左侧边栏中，然后选择 + 并添加一个 新建页面 到应用程序。将页面的名称更新为“航班详情”。在新页面的页眉中，删除分区标题。

  2. 选择 + 在工具栏左侧的 对象集标题 微件。将该微件配置为使用“Object list 1 Active object”作为其输入对象集。

  3. 在页面内，选择 选项。要查看某个分区可用的布局选项，请在模块的任意空白分区上选择 ，然后如下选择 Flow 布局。这会为您的页面添加一个可滚动的主体，其中可包含多个微件。

  4. 接下来，显示当前航班的一些属性：

  • 选择新 Flow 布局中的分区，并将其标题更新为“属性”。

  • 选择 + 添加小组件 并添加一个属性列表微件

  • 将属性列表微件配置为同样使用“Object list 1 Active object”作为其输入对象集

  • 将属性列表微件更新为使用堆叠标签布局并设置为 1 列，然后选择要显示的一些属性。在本例中，显示 运营承运人, Carrier Name, 已取消日 取消原因.

  1. 然后，显示有关出发机场和到达机场的信息：
  • 选择 + 添加分区 在 Flow 布局的底部。将新分区的标题更新为“出发机场”
  • 选择 + 添加小组件 并添加一个属性列表微件
  • 点击设置菜单下的 选择对象集变量... 用户偏好 + 新建对象集变量。从“Object list 1 Active object”变量开始，然后 搜索周围 选项。 [示例数据] 出发机场 关联。将这个新变量重命名为“当前航班出发机场”。
  • 将属性列表微件更新为使用堆叠标签布局并设置为 1 列，然后选择要显示的一些属性。在本例中，显示 显示名称, 承运人数量, 出发航班数量, 目的地数量 properties.

  1. 重复上述步骤，添加一个显示到达机场信息的分区。

  2. 使用 的 左侧边栏切换回显示航班对象列表的原始页面。选择您的对象列表，然后选择 + 添加事件 位于 在选中活动对象时 在配置选项中。选择 切换到航班详情.

至此，您已添加了导航到其他页面以查看列表中每个航班详细信息的功能。尝试在您的对象列表中选择一个航班，以导航到您刚刚创建的“航班详情”页面。

最后，您将在桌面浏览器和手机上预览您的移动应用程序。

第 4 部分：查看和使用模块

选择 保存并发布 在右上角保存您的模块，然后选择 查看 ↗。这将在 Foundry 的移动应用启动器中打开您的应用程序。

至此，您有多种选项可在桌面浏览器和手机上预览您的移动应用程序：

  • 桌面浏览器预览。要预览您的应用程序在实际手机上的显示效果，请使用浏览器对移动设备模拟的支持：

    • Chrome 设备模式 ↗

    • Safari 响应式设计模式 ↗

    • Edge 模拟移动设备 ↗

  • 在移动设备上。如果您的移动设备可以访问您的 Foundry 环境的网络，您也可以通过在手机上打开 URL 来导航到您的应用程序。在某些浏览器（如 Chrome 和 Edge）中，您可以通过右键单击页面并选择 为此页面创建二维码来轻松完成此操作。然后，您可以使用移动设备扫描二维码以打开应用程序。

在移动应用启动器中，您可以使用浏览器的后退和前进交互来浏览页面。在 Android 设备上，您可以使用设备的返回按钮进行导航；在 iOS 上，您可以像下图所示那样从左侧或右侧滑动。
