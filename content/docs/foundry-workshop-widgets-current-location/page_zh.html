微件：当前位置管理器

直方图 当前位置管理器 微件会提示用户共享其位置，并将检测到的位置发布为字符串变量，供您在应用程序中使用。此外，该微件可以向最终用户显示检测到的位置的可读预览，该预览通过 Mapbox 反向地理编码 API 确定。

如果用户拒绝访问其当前位置，将显示警告，且不会设置当前位置变量值：

当前位置管理器微件仅在包含它的页面处于打开状态时才会提示用户共享其位置并更新检测到的用户位置。如果您的用户导航到应用程序中的其他页面，位置检测和更新将被暂停。我们建议将该微件放置在工具栏或其他显眼位置，以便在需要时始终可见。在包含当前位置管理器的页面上方打开抽屉不会阻止其更新；只有导航到其他页面才会导致更新暂停。

配置选项

以下是当前位置管理器的核心配置选项：

  • 添加一个新的标签页。创建后，选择包含该标签页的框以进行配置。 显示在位置预览左侧的文本标签。可以留空以移除该标签。
  • 位置输出变量： 存储用户当前位置的字符串变量 lat,long format.
  • 隐藏位置显示： 如果启用，标签和位置预览都将被隐藏，但系统仍会提示用户共享其位置。此外，系统不会尝试对用户的位置进行反向地理编码请求。这适用于无需向用户显示检测到的位置预览的情况。
