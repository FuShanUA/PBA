通用连接器

通用连接器可用于表示与任意外部系统的连接。作为一种连接器，它不直接支持其他连接器中提供的标准 能力 功能。但是，当仅将其用作 在代码中使用 连接器时，可以通过编写代码来创建这些标准功能的替代方案，包括批量同步、文件和表格导出、流式同步、流式导出、媒体同步、webhook 等。

通过为通用连接器配置相应的工作器、凭据和导出控制，开发人员可以使用它编写连接到任意外部系统的代码。当源所有者将网络、工作器、凭据和导出控制一起配置时，可以确保凭据仅用于指定的外部系统，并且导出标记在建立连接的不同代码环境中都得到强制执行。

设置

应从 新建连接 选项创建通用连接器，该选项位于代码仓库环境的侧边栏中，而不是通过 Data Connection 应用程序创建。但是，任何已配置的通用连接器都会与其他连接器一起显示在 Data Connection 中。

审查 我们的外部转换教程 ，了解如何直接从代码仓库设置通用连接器的更多信息。

网络

由于通用连接器必须在代码中使用，因此只有 您必须正确配置出站策略（如果使用 连接可以使用，可以配合 直接连接出口策略 用于可以接受来自 Palantir 的入站流量的系统，或配合 agent 代理出站策略 用于位于私有网络中且无法接受来自 Palantir 的入站流量的系统。

使用代理出口策略时，代理必须能够访问目标地址，并且目标系统必须配置为允许来自该代理的连接。 详细了解代理网络。

配置选项

从概念上讲，您可以将通用连接器视为一组 网络配置, 凭据日 可导出标记 它们旨在配合使用。

  • 网络配置 指定使用此通用连接器时代码应能够访问哪些系统。
  • 凭据 指定成功连接所必需的密钥值。
  • 可导出标记 指定哪些数据可以安全地离开 Palantir 平台并传输到指定的网络目的地。

为了提供上述功能，通用连接器提供以下配置选项：

选项是否必填？描述
Networking是一组 出站策略覆盖 指定应可访问哪些目标地址或 IP。
CredentialsNo可以使用一组键值对来存储凭据。目前，只能存储密钥值。不支持未加密的值。
Exportable control markingsNo如果通用连接器将与 Foundry 数据输入一起使用，则必须启用允许导出的设置，并且必须指定可导出标记集。有关数据连接导出控制的更多信息，请参阅 我们的文档.

Python 函数

通用连接器的转换

如果源仅附加了一个针对端口为 443 的 DNS 地址的出口策略，则可以将通用连接器转换为 REST API 源 。

执行此转换后，开发者将可以使用 内置 HTTP 客户端 在代码中使用，使开发者能够立即编写与外部系统交互的代码。
