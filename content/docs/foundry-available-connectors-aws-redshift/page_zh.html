AWS Redshift

将 Foundry 连接到 Amazon Redshift，以在 Redshift 数据库和 Foundry 数据集之间读取和写入数据。

支持的功能

功能状态
探索🟢 正式可用
批量同步🟢 正式可用
增量🟢 正式可用
表导出🟢 正式可用

数据模型

该连接器可将 Redshift 表中的关系数据传输到 Foundry 数据集中，并在传输过程中保留架构和数据类型。您还可以将 Foundry 数据集导出到 Redshift 表。

性能与限制

性能取决于您的 Redshift 集群大小和网络状况。Foundry 利用 Redshift 高效的数据传输机制来优化性能。

您的 Foundry 实例与 AWS Redshift 集群之间需要建立网络连接。这可能需要 VPC 对等连接、AWS PrivateLink 或具有适当安全配置的公共互联网访问。

设置

  1. 打开 Data Connection 应用程序，然后选择 + New Source （位于屏幕右上角）。
  2. 选择 AWS Redshift （从可用的连接器类型中）。
  3. 请按照其他配置提示，并使用以下各部分中的信息，继续完成连接器的设置。

了解有关 设置连接器 （在 Foundry 中）的更多信息。

配置选项

AWS Redshift 连接器提供以下配置选项：

选项是否必填？描述
Endpoint是用于访问 Redshift 的终端节点（例如 redshift.us-east-1.amazonaws.com）
Port是连接 Redshift 的端口（默认值：5439）
Database是Redshift 数据库的名称
Username是用于身份验证的用户名
Password是用于身份验证的密码
JDBC properties否添加属性名称和值以配置连接行为。了解更多 JDBC 属性 如下。

JDBC 属性

您可以选择添加 属性 ↗ 您可以选择向 JDBC 连接添加属性 ↗ 来配置行为。请参阅 AWS 文档，了解可添加到连接配置的其他可用 JDBC 属性。

云身份配置

云身份验证使 Foundry 能够访问您 AWS 实例中的资源。云身份在以下位置进行配置和管理： 注册 级别（在 Control Panel 中）。了解如何 配置云身份。

使用云身份验证时，角色 ARN 将显示在凭据部分。选择 云身份 凭据选项后，您还必须配置以下内容：

  1. 在目标 Amazon AWS 账户中配置 Identity and Access Management (IAM) 角色。
  2. 授予 IAM 角色对您希望连接的 Redshift 集群的访问权限。您通常可以通过 存储桶策略 ↗来完成此操作。
  3. 在 Redshift 源配置详细信息中，在 安全令牌服务 (STS) 角色 ↗ 配置下添加该 IAM 角色。Foundry 中的云身份 IAM 角色将尝试担任 AWS 账户 IAM 角色 ↗ 以访问 Redshift。
  4. 配置相应的信任策略 ↗ 以允许云身份 IAM 角色代入目标 AWS 账户 IAM 角色。

表导出配置选项

将数据导出到 Redshift 表时，记录会分批插入以获得更好的性能。默认批处理大小为 1,000 条记录，但可以根据您的性能需求和数据特征将其配置为每批最多 100,000 条记录。有关表导出配置选项的更多信息，请查阅我们的 文档。
