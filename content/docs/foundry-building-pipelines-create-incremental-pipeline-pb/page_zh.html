使用 Pipeline Builder 创建增量管道

在本教程中，我们将使用 Pipeline Builder 创建一个简单的增量管道，其输出为单个数据集。

下面使用的数据集是假设的示例，用于说明增量计算的适用方式。

要使用 Python 编写转换逻辑，您可以使用 Python 用户自定义函数 在 Pipeline Builder 中，或者编写 增量转换 以 Python 代码的形式。

第 1 部分：问题描述

假设我们有一个输入数据集 flights 每周追加新数据。我们希望仅筛选出从 JFK 机场出发的航班，然后仅将这些航班追加到输出 filtered_flights.

假设 flights 数据集有 2000 万行，但每周仅新增 100 万行。通过增量计算，管道只需考虑 flights 中最新未处理的事务，而不是像快照计算那样处理所有行。

如果管道定期运行，增量处理可以显著降低每次运行的数据规模，从而节省时间和资源。

以下部分将逐步介绍如何设置增量管道。

第 2 部分：验证增量要求

只有满足本部分中的所有注意事项，管道才会以增量计算方式运行。例如，您的输入必须通过 APPEND or UPDATE 事务进行更新，且这些事务不修改现有文件。否则，将输入标记为增量将不会产生任何效果。

首先，请检查是否满足所有增量约束条件：

  • 输入 flights 正在通过 APPEND 事务或 UPDATE 事务进行更新，且这些事务不修改现有文件。
  • 计算 filtered_flights from flights 的逻辑不需要在后续构建期间更改 filtered_flights 中任何先前写入的数据。
    • 如果您希望更改管道逻辑（例如，同时包含从 LGA 机场出发的航班），您可以更新管道。如果您希望将该逻辑应用于先前已处理的航班，您可能需要 重放 您的管道。
  • 如果管道包含窗口函数、聚合或透视操作，请确保这些操作仅作用于当前事务。

有关完整的注意事项列表，请参考这些重要的 限制 （针对 Pipeline Builder 中的增量计算）。

第 3 部分：创建您的管道

现在，我们可以初始化一个新管道（有关分步操作说明，请参考 在 Pipeline Builder 中创建批处理管道）。假设我们已经导入 flights 作为输入数据集。

首先，将您的输入数据集标记为 增量 使用数据集下方的按钮。您将看到右上角出现一个蓝色徽章，以指示此更改。

接下来，添加一个转换以筛选 flights 仅保留从 JFK 机场出发的航班。请注意数据集输入右侧带有工具提示 增量输入的图标。下游转换将带有此图标，以指示它们正在以增量方式处理。

在图表中，下游节点将带有与输入相同的蓝色徽章。

最后，添加一个输出数据集 filtered_flights.

对于增量管道，您可以选择 强制输出使用增量行为 并在无法以增量方式运行时使构建失败。

第 4 部分：部署输出数据集

您现在可以 部署您的管道.

窗口中，选择管道交付中的数据处理起始时间：

有时，可能需要重新处理先前的输入事务（例如，如果逻辑发生更改，而先前版本的输出数据现已过时）。在这些情况下，您可以选择 窗口中，选择管道交付中的数据处理起始时间： 以通过管道逻辑运行整个输入。重放之后，随着新的追加事务添加到输入中，您的管道应继续进行增量计算。

在部署时重放将在输出数据集上生成一个 SNAPSHOT 事务。
