路由

Workshop 路由可将模块的特定状态或视图写入 URL，让用户能够通过链接分享轻松地与他人共享这些视图。

启用路由

要为您的 Workshop 模块启用路由，请导航至 页面 已应用标签 设置 左侧的面板，并开启 启用路由 选项。

直方图 页面 部分会显示路由所用页面的概览，并提供一个附加面板来展示正在使用的变量，如下所示。

页面路由

启用路由后，当前页面的 ID 将被写入 URL。对于未定义页面 ID 的页面，页面 ID 不会写入 URL；用户在页面加载时将返回到模块的默认页面。

如果您的模块还使用了 变量支撑的页面选择，请勿在页面选择变量上设置默认值。变量的默认值优先于 URL 中的页面 ID，因此打开指向非默认页面的链接时，会短暂渲染该页面，然后重定向到默认页面。

变量路由

您还可以使用路由来保存和共享为模块接口配置使用的变量值。启用路由后，配置了路由 URL 更新行为的变量的当前值将直接作为 URL 查询参数写入。

要将模块接口变量包含在 URL 中，请使用以下配置选项之一。

  • 在可见的微件或布局使用时包含在 URL 中： 仅当以下条件成立时，URL 才会包含该变量的值：
    • 该值不是变量的默认值
    • 该变量被当前视图中出现的微件或布局使用。
  • 始终包含在 URL 中： 只要该值不是变量的默认值，URL 就会始终包含该变量的值。
  • 从不包含在 URL 中： 如果路由开关处于禁用状态，URL 将永远不会包含该变量的值。

如果查询参数的键与模块接口变量的外部 ID 匹配，则无论配置的 URL 包含行为如何，该查询参数的值都将用作变量的初始值。

局限性

URL 中不支持的变量类型

以下变量类型无法在 URL 中使用：

  • 对象集筛选器变量
  • 对象集变量 仅限于由其 RID 指定的单个对象

但是，您可以使用其他路由变量间接定义上述变量类型。例如，您可以创建一个用于路由的字符串变量，并使用该字符串变量定义对象集筛选变量的 default value 。

不从嵌入模块继承路由配置

嵌入 Workshop 模块 不会继承被嵌入模块的路由配置。要将嵌入模块中的变量值用于路由，请将所需的变量添加到子模块的 模块接口 中，并在嵌入模块配置中从父模块传入路由变量。
