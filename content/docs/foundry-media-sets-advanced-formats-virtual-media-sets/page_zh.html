虚拟媒体集

虚拟媒体集是一种特殊类型的媒体集，可直接从外部源系统读取文件，而无需将文件复制到 Foundry 的支撑存储中。这使您能够在 Foundry 中保持媒体集接口和功能的同时，处理存储在外部系统中的媒体文件。

支持的源类型

虚拟媒体集目前仅支持特定的源类型：

  • Amazon S3
    • 仅支持“访问密钥和秘密密钥”凭据类型。
    • 不支持使用 STS 角色的连接。
  • OneLake 和 Azure Blob Filesystem (ABFS)

无法使用代理连接创建虚拟媒体集同步。

局限性

虽然虚拟媒体集使您能够处理存储在 Foundry 之外的媒体文件，而无需因将这些文件复制到 Foundry 而产生存储成本，但虚拟媒体集存在一些局限性，如下所述：

  • 虚拟媒体集无法感知源系统中的更新和删除操作。例如，如果源系统中的某些媒体文件被注册到虚拟媒体集中，随后又从源系统中删除，那么虚拟媒体集中仍会包含与这些已删除文件对应的条目，但这些条目将无法再访问。
  • 对虚拟媒体集中的媒体条目应用转换时，转换后的媒体条目会持久化存储在 Foundry 的支撑存储中，并将产生存储成本。
  • 无法为虚拟媒体集配置其他输入格式。

创建虚拟媒体集

要设置虚拟媒体集同步，请按照以下说明操作： 媒体集同步文档 但请选择 虚拟媒体集同步 而非 媒体集同步。

使用转换将媒体项注册到虚拟媒体集

在 Data Connection 中创建虚拟媒体集后，您还可以使用 Python 转换来注册媒体项，而无需使用虚拟媒体集同步。这样可以对同步过程进行更多控制：

  • 您可以更好地控制资源使用和并行度，从而根据您的具体需求优化性能。
  • 您可以实现更复杂的逻辑来确定要同步哪些文件，这在虚拟媒体集同步提供的默认筛选选项无法满足您的使用场景时非常有用。
