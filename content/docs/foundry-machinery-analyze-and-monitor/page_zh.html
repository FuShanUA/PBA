分析和监控流程

Machinery 小部件可为已配置的 Machinery 流程提供运营洞察和监控功能。

  • 当用户在流程中积极开展工作时,深入了解流程运行情况。
  • 识别分析和监控工作流中的瓶颈。
  • 通过可配置的视图可视化流程流向和指标。

该小部件可在 Workshop 应用程序中将您的 Machinery 图渲染为可视化图表,用于显示指标、流程流向和对象分布。

Machinery 小部件可在 Workshop 模块中使用,也可以作为独立视图模式在 Machinery 应用程序中使用,但功能有限。

小部件配置

创建或打开一个 Workshop 模块，并选择 Machinery 概览小部件。默认情况下会选中小部件版本 v2，该版本支持 Machinery v2 资源。在小部件配置的顶部，选择您的 Machinery 图资源。

升级现有应用程序

默认情况下，新的 Machinery 小部件将创建为 v2 小部件。现有小部件需要升级到 v2。

  1. 要将旧版小部件升级到 v2，请打开 Workshop 编辑模式，使用 ... 下拉菜单。
  2. 在图表中的任意位置进行选择，然后在 小部件设置 菜单下选择 使用 Machinery v2。
  3. 请相应地更新您的 输入 。

输入

为图中的每个根流程配置输入对象集。Machinery 小部件会根据关联类型设置自动派生子流程对象集，子流程通过关联类型与其父对象相连，关联类型配置位于 对象类型。

示例： 如果您提供 100 个应用程序对象，且每个应用程序与多个审查对象相关联，该小部件会通过所配置的关联类型自动识别所有相关的审查。这意味着您只需为图中的每个根流程配置对象输入（通常为 1 个对象输入）。

指标视图

Machinery 小部件在实例化时会附带以下预配置指标视图：

  • 历史计数： 显示累计计数指标。
  • 当前计数： 显示状态中的当前计数。
  • 历史持续时间： 显示状态中的历史持续时间。
  • 当前持续时间： 显示状态中的当前持续时间。

应用程序构建者可以添加、删除、重新组织或自定义这些指标视图。

自定义视图还可以通过 + 添加项目 选项添加。对于每个视图，构建者可以定义一个带有数字格式设置和条件着色的节点指标、一个可选的边指标，并可启用桑基图边粗细设置。

输出

输出数据集可在 Workshop 模块中用于进一步分析。配置输出对象集，以根据图交互捕获筛选后的结果：

  • 为图中的每个流程创建一个输出（可选）
  • 输出对象集会应用 Machinery 应用程序内流程级别定义的筛选器，以及从父流程到子流程的周边搜索。
  • 输出会动态响应节点/边选择
  • 路径探索器和分布图表提供了影响输出的其他方式

节点和边选择

您可以通过切换以下任一选项来更改节点选择影响对象输出的方式：

  • 当前处于所选状态的流程
  • 曾经处于所选状态的流程

可以将边选择配置为显示曾经历过某次转换的对象，或仅显示经历过最后一次转换的对象。

配置视图

视图决定小部件中显示哪些指标和可视化内容。详情请参阅下方的“指标视图”部分。

小部件功能

在 Machinery 小部件中查看图的用户可以使用多项功能,包括指标循环切换与固定、多种使用模式以及筛选器。

指标视图、循环切换与固定

该小部件以节省空间的方式显示指标。在图上,一次只能看到一个节点指标;如果已选择,还可以看到一个可选的边指标。如果视口放大到足够程度,图将显示包含 3 个指标的节点卡片,并以当前活动视图开头。如果配置了桑基图(Sankey)的边,则在 Transitions 视图上,边的粗细用于表示流动频率。

预配置视图

小部件用户可以循环切换预配置的 指标视图，包括历史计数、当前计数、历史持续时间和当前持续时间。选择视图后，将鼠标悬停在任意节点上即可显示所有可用指标。

此外，选择某个节点指标可将其固定，使指标保持可见以便查看；再次选择即可取消固定。

流程一致性筛选

默认情况下，该小组件仅显示符合流程定义的流程：

  • Machinery 中不存在的状态和转换将被排除。
  • 指标仅基于符合定义的流程进行计算。
  • 如果图上的任何日志对象类型包含超过 100 万个对象，则将禁用一致性筛选，并且该图将涵盖所有输入对象，包括指标计算和输出对象集。

聚焦到父流程

在图表中，您可以聚焦到所需的父流程以缩小视图。

图表选择和输出

与图表交互以筛选输出对象集：

  • 选择节点以按状态筛选对象。
  • 选择边以按转换筛选对象。
  • 输出对象集会根据您的选择自动更新。

图表功能

以下图表功能可在小部件标题栏中单独启用或禁用。

  • 转换节点： 当您的图中包含在 Machinery 应用程序中配置的操作或自动化时，Machinery 小部件会将它们替换为隐式状态转换，以帮助您从状态转换的角度理解流程。您也可以选择改为显示转换节点，并在小部件配置中设置默认行为。
  • 子流程： 如果图中包含子流程，您可以将这些子流程替换为其隐式状态转换，以便在当前聚焦的流程上查看转换指标。
  • 偏差： 如果您的当前数据中存在偏离对象，这些对象默认会被隐藏。偏离对象是指呈现出流程定义中未包含的任何状态或转换的对象。您可以将它们设为不可见，并单独选择是否将它们包含在小部件输出中。

分析模式

在打开 Machinery 图表的情况下，您可以在位于图表右侧的路径探索器功能和时长分布功能之间进行切换。所选功能将在右侧打开。

路径探索器

使用路径探索器功能，一次分析一个流程的各个流程路径及其频率。要打开路径探索器，请选择位于图表右侧的路径探索器图标。

路径探索器会显示当前聚焦的流程所经过的所有路径，并显示路径频率分布（对象完成该路径的频率）。

将鼠标悬停在窗口中的某个路径上，即可在图表中看到该路径高亮显示。您还可以选择一个或多个路径来筛选输出结果。

请注意，当路径探索器打开时，路径选择将控制小部件的输出，并覆盖之前的节点/边选择。

时长分布

使用时长分布筛选器来识别性能异常值，并分析在各状态上花费的时间。

时长图表会响应图上的选择，并遵循已配置的节点和边选择选项。

选择单个桶或一定范围的桶将筛选输出的对象集。您可以将图表选择与图选择相结合，以查找具有不良行为的对象，例如在单个转换或状态中耗时过长。
