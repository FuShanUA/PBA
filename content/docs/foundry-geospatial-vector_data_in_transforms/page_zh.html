在转换中使用矢量数据 [旧版]

遗留版

直方图 geospatial-tools 库不再积极开发；请改用 Pipeline Builder 来加载、转换和处理地理空间数据。本页所述的地理空间数据类型操作功能已被 Pipeline Builder 的地理空间功能所取代。 了解有关 Pipeline Builder 地理空间功能的更多信息。

Geospatial Tools 是一个 Python 库，托管可复用的逻辑，用于在 Foundry 中对矢量地理空间数据管道执行常见转换。此库中提供的函数旨在用于 Python 转换中，以便将这些常见操作与管道其余逻辑的集成流程化。

此功能已被取代，取代者为 Pipeline Builder 的地理空间功能所取代。您应使用 Pipeline Builder 而不是 geospatial-tools 库，因为该 geospatial-tools 库不再维护，可能无法按预期运行。

本页的文档将保留作为参考，直到该 geospatial-tools 库。

该库目前包含以下辅助函数：

  • 清理地理空间数据
  • 空间函数
  • 空间连接

清理地理空间数据

Foundry 中干净的地理空间数据应满足：

  1. 表格化，因此数据可以在 Spark 转换中使用
  2. 格式化为有效的 GeoJSON ↗ 或 geohash，因此数据可以在 Foundry 本体论中使用
  3. 使用 EPSG:4326 ↗ CRS 进行投影，以便空间连接的双方使用相同的投影，并且 Foundry 地图能够正确渲染要素。

了解有关 CRS 和数据对齐的更多信息，请参阅 坐标参考系统和投影.

直方图 geospatial-tools 库提供 clean_geometry() 和 lat_long_to_geometry() 来执行步骤 (2) 和 (3)。如果您的原始数据是 GeoJSON、Shapefile、GDB、KML 或 KMZ，您可以使用 内置解析辅助函数 来执行步骤 (1)。

clean_geometry()

clean_geometry(geometry, input_crs, geometry_format='geojson', lat_long=False, output_format='geojson')

通过使几何列有效并将 CRS 规范化为 EPSG:4326 来清理地理空间几何列。

  • 参数
    • geometry (str）：输入几何列的名称。
    • input_crs (str）：输入几何的 CRS。
    • geometry_format (str，可选）：输入几何格式。支持的格式为 geojson, geohash （包含以下内容的字符串 latitude,longitude), wkt日 wkb。默认为 geojson.
    • lat_long (bool，可选）： True 如果输入几何坐标的顺序为 latitude,longitude，对于 geohash 输入很可能是这种情况，但对于 geojson or wkt。默认为 False.
    • output_format (str，可选）：输出几何格式（geojson or geohash）。默认为 geojson.
  • 示例 
    Copied!
    1

from transforms.api import transform_df, Input, Output
from geospatial_tools import geospatial
from geospatial_tools.functions import clean_geometry

@geospatial()
@transform_df(
    Output('/my/output/dataset'),
    raw_df=Input('/my/input/dataset'),
)
def compute(raw_df):
    clean_df = raw_df.withColumn('geometry', clean_geometry('geometry', 'EPSG:26910'))
    return clean_df

from transforms.api import transform_df, Input, Output
from geospatial_tools import geospatial
from geospatial_tools.functions import lat_long_to_geometry

@geospatial()
@transform_df(
    Output('/my/output/dataset'),
    raw_df=Input('/my/input/dataset'),

解析辅助函数

geojson_to_dataframe()

geojson_to_dataframe(dataset, properties=None, glob='*.geojson', batch_size=100000)

将 GeoJSON 文件转换为 dataframe。使用流处理来处理非常大的文件，而不会耗尽驱动程序内存。

  • 参数
    • dataset (transforms.api.Input）：包含 GeoJSON 文件的输入数据集。
    • properties (list[str]，可选）：要为其创建列的属性列表。如果未提供，所有属性将包含在 JSON "properties" 列中。
    • glob (str，可选）：用于识别数据集中 GeoJSON 文件的 glob 模式。默认为 *.geojson.
    • batch_size (int，可选）：每批次处理的记录数。如果驱动程序内存不足，应减小批次大小。默认值为 100000。
  • 示例

from transforms.api import transform, Input, Output
from geospatial_tools import geospatial
from geospatial_tools.parsers import geojson_to_dataframe

@geospatial()
@transform(
    output=Output('/my/output/dataset'),
    raw=Input('/my/input/dataset'),
)
def compute(raw, output):
    return output.write_dataframe(
        geojson_to_dataframe(raw)
    )

DataFrame.spatial_join(right_df, on, how='inner', **kwargs)

  • 参数

from transforms.api import transform, Input, Output
from geospatial_tools.spatial_joins import geopandas_spatial_join

@transform(
    output=Output('/my/output/dataset'),
    input_df_left=Input('/my/input/dataset/left'),
    input_df_right=Input('/my/input/dataset/right'),
)
def join(ctx, output, input_df_left, input_df_right):
  df_left = input_df_left.dataframe().toPandas()
  df_right = input_df_right.dataframe().toPandas()
  geometry_left = 'geometry'
  geometry_right = 'geometry'

  joined = geopandas_spatial_join(
        df_left,
        df_right,
        geometry_left,
        geometry_right,
        how='inner',
        op='intersects'
    )
    joined = ctx.spark_session.createDataFrame(joined)
    output.write_dataframe(joined)
