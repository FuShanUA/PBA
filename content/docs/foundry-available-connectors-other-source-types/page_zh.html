其他源类型

Foundry 的 Data Connection 框架使您能够配置来自各类企业数据系统的同步。这包括在制造、公用事业和医疗保健等特定行业中常用的数据源。本页面提供了一些已与 Foundry 集成的行业特定数据源的参考。

如果您有兴趣将某个数据系统与 Foundry 集成，请联系您的 Palantir 代表了解更多详情。

IOT / IIOT

物联网 (IOT) 和工业物联网 (IIOT) 系统通常会产生数据流和时间序列，这些数据可以同步到 Foundry 中，用于分析和运营工作流。最常见的做法是，使用 Data Connection 对 流式数据的支持来集成 IOT 数据源。与 Foundry 集成的一些 IOT / IIOT 系统示例包括：

  • Amazon IoT Core
  • Azure Event Hub
  • Google IoT Core
  • OPC-UA
  • OSI PI

地理空间系统

以下是一些通常与 Foundry 集成的地理空间数据系统的示例：

  • ESRI / ArcGIS
  • PostGIS
  • Oracle Spatial 数据库
  • WFS

此外，以多种文件格式导出的地理空间数据可以使用数据连接的 文件系统 和 Blob 存储源类型（例如 Amazon S3）来轻松集成。Foundry 中常用的地理空间文件格式包括：

  • Shapefile 文件
  • KMZ / KML
  • FGDB
  • Geojson

最后，数据连接对 REST API 可用于与其他常用的地理空间服务集成。

EHR / EMR

Data Connection 已在国际范围内用于连接各种电子健康记录 (EHR) 和电子病历 (EMR) 系统。如需了解更多详情，请联系您的 Palantir 代表。

生产力工具

与生产力工具和任务管理工具的连接通常使用 Data Connection 对 REST API的支持进行配置。此前已集成过的生产力工具示例如下：

  • Artifactory
  • Asana
  • GitHub
  • JIRA
  • PagerDuty
  • ServiceNOW
  • Slack
