使用其他身份提供程序

Foundry 实现了标准 SCIM 2.0 协议，因此并不限于本文档中所述的身份提供程序。任何支持 SCIM 2.0 的身份提供程序均可配置为向 Foundry 预配用户和组。

本文档为 Microsoft Entra ID 提供了详细的操作步骤，因为它是一种常用的身份提供程序，且其设置流程也代表了您在其他提供程序中会遇到的情况。如果您使用其他提供程序，可以遵循同样的总体方法：确定是否应使用子域、配置 ingress、将提供程序的 SCIM 客户端指向 Foundry SCIM 端点、使用 OAuth 2.0 客户端凭据授予进行身份验证，并将提供程序的用户和组属性映射到 Foundry 期望的、与您在 Control Panel 中的属性映射相匹配的属性。

请注意，尽管 SCIM 2.0 提供了标准协议，但各提供商在实现和开放该协议的方式上存在差异。具体的术语、配置界面、支持的属性以及可用的预配选项因提供商而异，而且某些提供商可能不支持规范的每个部分。因此，针对您所用提供商的确切步骤可能与本文档中所述的步骤有所不同，您可能需要查阅该提供商的 SCIM 文档来完成设置。
