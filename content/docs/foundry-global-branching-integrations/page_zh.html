集成

Global Branching 与平台上的各类应用程序集成，能够为广泛的资源启用隔离的开发工作流。虽然 Global Branching 应用程序在 Palantir 平台上为添加资源、变基（rebase）和合并等常见操作提供了统一的体验，但具体细节会因您所使用的 Foundry 应用程序而异。

以下文档涵盖了使用分支时各应用程序的具体细节，包括如何添加和修改资源、跨应用程序兼容性、变基行为以及任何已知的限制。

值得注意的限制

并非所有资源类型都已在全局分支中得到支持；对更多资源类型的支持正在开发中。特别需要注意：

  • TypeScript v2 和 Python 函数： 目前，您无法在分支上修改 TypeScript v2 或 Python 函数。您可以在分支上引用函数的特定版本，并在将其合并回 main 分支之前测试该版本。但是，函数代码将只能利用存在于 main 分支上的模式。
  • 本体论 SDK： 本体论 SDK 目前不支持分支。
