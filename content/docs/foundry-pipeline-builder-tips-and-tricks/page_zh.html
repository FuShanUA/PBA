更快地构建

配置用户偏好

  1. 导航到管道构建器视图右上角的设置菜单并选择 用户偏好，然后配置并保存您的设置。





最常用的两个设置是 折叠转换样式 和 自动命名转换路径。在 折叠转换样式 选择器中（位于 用户偏好内），将该设置切换为 伪代码 后，您的转换将以类似于编程代码的格式呈现。伪代码不遵循任何特定编程语言的语法。

快捷键（自动布局、缩放、隐藏等）

  1. 打开 帮助 下拉菜单（位于 Pipeline Builder 左上角）。



  2. 选择 查看快捷键 以打开 Pipeline Builder 的完整快捷键参考。



部分最常用的快捷键包括：

  • Up Arrow 以缩放并使所有管道节点适应屏幕
  • Cmd+H (macOS) 或 Ctrl+H (Windows) 以隐藏所选节点
  • Cmd+K (macOS) 或 Ctrl+K (Windows) 以取消隐藏所有隐藏的节点
  • Cmd+D (macOS) 或 Ctrl+D (Windows) 以选择节点的子节点
  • Cmd+E (macOS) 或 Ctrl+E (Windows) 以选择节点的父节点
  • Cmd+C (macOS) 或 Ctrl+C (Windows) 将节点复制到剪贴板

复制和粘贴节点

  1. 选择要复制的节点。使用 选择 按钮（位于右上角），或使用 Cmd+A (macOS) 或 Ctrl+A (Windows) 选择当前管道中的所有节点。如有需要，您也可以选择单个节点，或通过在节点周围单击并拖动来选择一组节点。
  2. 要复制所选内容，请右键单击并选择“ 复制”，或使用 Cmd+C （macOS）或 Ctrl+C （Windows）。



  3. 导航到目标管道，然后右键单击并选择“ 粘贴”，或使用 Cmd+V (macOS) 或 Ctrl+V (Windows)。

点击并拖动以连接节点

  1. 选择 输出圆圈 （该节点将用作输入）。



  2. 将该输出拖动到 输入圆圈 应接收其输出的节点。

查看未保存的更改

  1. 导航至屏幕右侧的侧边栏菜单，然后选择 查看更改。在此处，您可以查看当前分支中的未保存更改，并将其与其他 Pipeline Builder 分支进行比较。

决定每个节点中放置多少个转换

  • 每个节点中的转换数量没有固定限制。一般最佳做法是，将较大的转换函数串联分布在多个节点上，而不是将所有内容归组到单个节点中。这可以让您的管道更易于维护、排查故障和更新。
  • Pipeline Builder 还支持 自定义函数，它们允许您将一系列转换板打包为单个可重用的转换，并在整个管道中重复使用。在转换节点中时，选择 + 图标以配置自定义转换路径。

使用 LLM 生成概念性数据

  1. 在向手动输入的表格添加列后，选择 生成数据 （位于右上角）。
  2. 对于每一列，使用 自动填充 下拉菜单来选择数据类型，或选择 使用 LLM 生成 以输入自定义提示词。
  3. 配置好提示词后，选择 生成表格 （位于右下角）来填充表格。

用于构建和理解的 AI 工具

要在管道中直接使用大型语言模型 (LLM),请参阅 在 Pipeline Builder 中使用 LLM。

使用 AI 生成来构建新的转换节点

  1. 选择要从中构建的节点,然后从菜单中选择 生成 。



  2. 接下来，在文本框中输入提示词，然后选择 生成。



  3. Pipeline Builder 会在所选节点之后生成新节点，您可以像对管道中的任何其他节点一样对其进行重命名。

使用 AI explain 生成管道逻辑摘要

  1. 选择要解释的节点，然后选择图视图顶部中央的紫色灯泡图标。Pipeline Builder 会在文本框中生成所选节点逻辑的文字摘要。



  2. 您还可以通过选择转换面板右上角的紫色灯泡，直接在节点中使用 explain。

使用 AIP 正则表达式助手，借助 LLM 生成正则表达式模式

  1. 选择要在其上运行正则表达式函数的数据集，然后打开 转换 面板。
  2. 在 转换 窗口中，选择所需的正则表达式函数和目标列。
  3. 选择模式输入框右侧的紫色星形图标并输入您的提示。



  4. 选择 生成，然后通过选择 应用来验证输出。返回图形视图并预览转换的输出以确认结果。

使用 AI FDE 来支持管道的创建和构建

  1. 导航至屏幕左侧的 应用程序 菜单，并搜索 AI FDE。
  2. 打开 AI FDE 应用程序后，您可以通过将链接复制并粘贴到聊天框中，将现有管道添加为资源。
  3. 然后，您可以提示 AI FDE 在您的管道中构建更多节点。

改进管道

更快的管道模式

  1. 创建新的批处理管道时，请选择 更快 ，该选项位于 选择批处理计算 菜单。
  2. 您还可以将现有的标准批处理管道转换为更快的管道。请选择 转换为更快的管道 选项，该选项位于您标准管道的 设置 菜单中。



  3. 一旦您选择了 转换为更快的管道 选项，请选择 转换管道 按钮以确认转换。

如果您的管道包含与更快的管道不兼容的功能，您将收到一条错误消息，指出在转换之前需要移除或更改的内容。您还可以启用转换检查，以便使用底部面板在您的管道中查看这些警告。

更快的管道功能支持

更快的管道支持标准批处理管道中可用功能的一个子集。了解 在 Pipeline Builder 中使用更快的管道的更多信息。

使用计算配置文件缩短构建时间

  1. 创建管道后，导航至屏幕最右侧的 构建设置 菜单，以进一步调整计算设置。
  2. 在 构建设置 菜单中，前往 默认计算配置文件 并选择显示您当前计算配置文件大小的下拉菜单。
  3. 选择 配置文件管理策略 下拉菜单。共有三个选项。请选择最符合您需求的一项：
    • 标准： 默认的计算配置文件设置，无额外优化。最适合数据量可预测的生产级管道。
    • 暖池： 持续运行虚拟机以缩短管道启动时间。最适合小规模的迭代管道和低延迟开发任务。
    • 托管配置文件： 根据管道最近五次运行情况自动调整计算资源分配。最适合数据量波动较大或需要管理计算成本的管道。

快速管道中的计算配置文件支持

快速管道仅支持 标准 配置文件管理策略。

筛选预览数据

  1. 右键单击要从中采样的输入数据集，然后选择 采样策略 从下拉菜单中进行选择。您配置的采样策略将应用于采样输入之后的每个节点。



  2. 选择要在管道中的哪个数据集上配置采样策略。 筛选后的预览 允许您根据任意表达式筛选行。在以下示例中，只有 original_language 为 en 的行会被保留。

针对管道可靠性的单元测试

  1. 要创建新的单元测试，请选择右侧菜单中的图标，然后选择 + 新建测试 按钮，并选择要测试的转换。



  2. 接下来，通过选择架构（手动选择或从现有数据集中选择）来配置测试，然后在您的 单元测试输入节点中输入一行测试数据，并在 单元测试输出节点中输入预期的输出。



  3. 测试配置完成后，请选择 运行测试 并查看结果。有关更多信息，请参阅 Pipeline Builder 中的单元测试。

清晰地组织

用于组织的文件夹和颜色组

  1. 要 为节点设置文件夹 在管道构建器中，选择屏幕最右侧的文件图标。在 管道文件树 面板中，您可以创建新文件夹、将节点放入文件夹，以及显示或隐藏特定文件夹中的节点。



  2. 您还可以为节点着色，并根据着色将多个节点折叠为单个节点。

用于文档记录的文本节点

  1. 选择 添加新文本节点 图视图工具栏。文本节点支持 Markdown，并位于图中所有节点的后方。了解更多关于 文本节点。

查找和替换列名

  1. 导航到屏幕右侧的搜索面板。在那里，您可以搜索并替换管道中的列名。

自动布局节点和网格吸附

使用图视图工具栏中的自动布局和网格吸附选项来对齐节点并提高可读性。
