筛选转换表

根据列值和您分析中的数据，保留或删除转换表中匹配任一或所有条件的行。

可以使用公式或可视化编辑器来定义条件。要添加条件，请选择 + 添加筛选器。

使用可视化编辑器进行筛选

要配置条件，请选择一个列。支持的列类型包括字符串、日期、数字和布尔值。

选择列后，请选择比较运算符来配置条件。每种列类型提供一组不同的比较运算符：

  • 字符串： 开头为、结尾为、包含、不包含、是、不是、字符串转布尔值（当字符串列包含 true 或 false 值时使用）
  • 日期： 早于、当天或早于、晚于、当天或晚于、介于（含边界）、等于、不等于
  • 数字： 大于、大于或等于、小于、小于或等于、等于、不等于
  • 布尔值： 是、不是

下图显示了针对 greater than 比较运算符的条件配置，该配置将数字列 “Ground Elevation” 与由数值聚合计算得出的该列平均值进行比较。

使用公式进行筛选

要配置条件， 请指定公式 返回布尔值（true/false）。公式可以将列作为输入，并使用 @ （例如，@column > 0）来引用它们。您还可以在分析中使用数据，方法是引用其全局标识符 $XY （例如， @column > $A 其中 $A 是您分析中的一个数值参数）。

请注意，公式不支持字符串类型。若要按字符串列类型进行筛选，请使用可视化编辑器。
