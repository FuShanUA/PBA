加载方法

默认情况下，Map 应用会加载图层中的所有对象，以便在地图上进行渲染。这本身就会带来规模限制，因为您能够渲染的数据量仅限于可从本体论加载到浏览器中的数据量。 加载方法 配置通过限制应用仅加载显示地图可见范围所需的数据，便于呈现大规模对象集。

配置加载方法

您可以通过样式面板中的 加载方法 下拉菜单为显示配置加载方法。

加载方法选项如下：

  • 自动： 默认情况下，应用将使用图层内容来推断基于瓦片的加载与基于对象的加载之间的最佳选择。
  • 瓦片： 在地图视口范围内加载简化的几何数据。此选项最适合大型对象集以及需要优先考虑性能的场景。
  • 对象： 加载单个对象的完整详细信息。此选项最适合复杂的样式设置。

只有在满足以下条件时，您才能为显示选择加载方法：

  • 图层的对象类型至少具有一个 geopoint 或 geoshape 属性。
  • 几何属性具有 “可搜索” 渲染提示 （已在 Ontology Manager 中启用）。如果 “可搜索” 未启用，则切片将为空，地图上不会显示任何对象。
  • 该显示类型支持基于切片的渲染。目前仅支持基于图标、圆形和地理形状的显示。

使用基于切片的加载方法添加对象

对于支持基于切片的加载方法的对象类型，搜索对话框不会限制可添加到地图的对象数量。因此， “全部添加” 选项将始终处于启用状态。

基于切片的加载方法兼容性

在基于切片的显示中渲染的对象无法与 Map 应用程序的多项其他功能正常配合使用。许多不兼容的功能需要从服务加载数据，而这些服务无法支持基于切片的图层所渲染的数据规模。

以下部分列出了与基于切片的加载方法不兼容的 Map 功能。

样式

地理点和地理形状属性是 对象图层显示唯一支持的几何源，且所有 基于值的样式选项均仅支持属性值。

因此，以下选项 不 受支持：

  • 基于时间序列的样式（度量和 TSP）
  • 函数
  • 基于时间的不透明度
  • 标签
  • 时间轴几何图形
  • 周边搜索

筛选

以平铺方式显示的对象不会遵循 直方图 或 时间线中应用的筛选。

形状

以平铺方式显示的对象在 从当前选定内容创建形状时将不会被包含在内。
