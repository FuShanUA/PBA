Slate 应用程序可能变得非常复杂，数百个小工具、函数、查询和事件会交织成一张依赖关系网。Slate 应用程序的性能问题通常首先出现在用户界面中，例如表格缺少预期的数据，或按钮未能产生预期的响应。然而，这些问题的根本原因可能位于后端的某个位置。

发布日期：2023-01-17 健康检查对话框 和 调试器 便于错误的调查和解决，防止小工具中出现过期或不准确的数据。

直方图 健康检查对话框 通过将所有错误和警告整合到单一视图中，使应用程序构建者能够快速识别并解决失败的查询和函数。

直方图 调试器 支持使用断点进行应用程序测试，并使发现和解决 Slate 应用程序各组件中的问题变得更加容易。这还有助于应用程序构建者了解更改对其他应用程序组件的下游影响。

健康检查对话框

当 Slate 应用程序以编辑模式打开时，Slate 会在加载时自动检查所有查询和函数是否成功运行。但是，如果条件在默认应用程序状态下未满足，带条件的查询可能不会运行。

遇到的任何错误或警告都将显示在 操作栏 中，该栏位于页面顶部。

选择问题图标以打开健康检查对话框。在此处，可以直接跳转到画布或依赖关系图视图中引发问题的查询或函数。

错误也会显示在 查询 或 函数 面板中。查询面板将突出显示所有失败的查询。选择 测试 以运行该查询并查看详细错误。

函数面板不会突出显示所有失败的函数。要运行某个函数，请选择 测试。如果运行失败，将显示详细的错误消息以供进一步分析。

OSDK 错误

如果您的 Slate 应用程序使用 本体论 SDK (OSDK)，健康检查对话框还会显示 OSDK 加载错误。当 OSDK 加载失败时，选择 OSDK 选项卡以查看详细的错误信息和指导。使用对话框中的直接链接打开 OSDK 配置面板并修复配置问题。

调试器

Slate 调试器简化了错误调查的过程，同时在单一视图中提供所有相关信息。

启用调试器

要启用或禁用调试器，请切换 调试器 （位于依赖关系选项卡的右上角）。

启用调试器后，图中会添加一个底部抽屉。左侧列出所有设置了 断点的节点，右侧预览所选节点的当前值。您还可以从抽屉中运行和刷新应用程序。使用滚动条可以查看大型组件状态而不会被截断。

设置断点

组件添加到图中后，即可为其设置断点。要添加断点，请将鼠标悬停在图中的节点上并选择 断点 ，该按钮将显示在节点上方。设置断点后，底部抽屉中将显示该节点的条目。

运行或刷新应用程序时，执行将在运行到设有断点的节点之前暂停。

运行并刷新节点

在调试时，您可能需要在某个时刻重新运行一系列节点或组件。可以通过不同的方法重新运行节点。在调试器中，您可以选择任何节点上的播放按钮，这将执行从所选节点开始的所有节点，并在到达下一个断点时停止。

您还可以通过点击底部抽屉中的刷新按钮来刷新整个应用程序。刷新应用程序将重新触发所有事件，而无需重新加载页面。

最后，您可以通过在 Slate 应用程序本身中执行操作来手动触发节点。在应用程序界面中运行查询或选择按钮，其效果类似于在调试器中手动运行节点。
