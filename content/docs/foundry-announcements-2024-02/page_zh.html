foundry_ml Python 库将于 2025 年 10 月 31 日被弃用，并由 palantir_models 库取而代之。

发布日期：2024-02-22

截至目前， foundry_ml Python 库处于开发过程中的 计划弃用阶段 。该 foundry_ml 库将于 2025 年 10 月 31 日弃用，与 Python 3.9的计划弃用时间保持一致。作为替代，我们建议使用 palantir_models 框架在平台中开发、测试和部署模型。

什么是 palantir_models 框架？

该 palantir_models 框架为定制适用于 Foundry 工作流的模型提供了显著更高的灵活性，包括：

  • 自定义序列化、API 和推理逻辑，可轻松支持更广泛的模型和推理模式
  • 多输入和多输出模型
  • 自动打包 Python 依赖项，实现即时部署
  • 为 外部托管的模型 提供一流封装，以便在 Foundry 中进行模型评估和推理
  • 基于容器的模型，可支持超大型或高度自定义的建模框架
  • 直接访问媒体集以进行模型推理

使用 foundry_ml 训练的模型需要更新以使用 palantir_models 框架，截止日期为 2025 年 10 月 31 日。同样，使用 foundry_ml 开发的模型将无法在建模目标、Python 转换或建模目标部署中获得支持。如需了解如何通过使用 palantir_models构建新模型进行迁移，请参阅 如何在代码仓库中训练模型。

请注意，如果您希望阻止在新对象上执行效果，则必须通过选择 静音 选项来停用自动化，该选项位于屏幕右上角的下拉菜单中。

Sensitive Data Scanner [GA] 现已推出

发布日期：2024-02-08

Sensitive Data Scanner （“SDS”，前身为 "Foundry Inference"）可帮助组织在 Foundry 中跨数据集发现并保护敏感数据。治理用户可以使用 SDS 定义敏感数据模式、进行识别，并在发现匹配数据时自动执行相应操作。此外，用户还可通过更新后的界面准确跟踪和监控已启动的扫描。

Sensitive Data Scanner 将于 2 月 19 日当周在所有 Foundry 注册中正式发布。

Sensitive Data Scanner 一次性扫描概览。

自动发现并保护敏感数据

Sensitive Data Scanner (SDS) 使管理员能够在 Foundry 中发现并保护敏感数据。设置敏感数据扫描的过程非常简单，技术用户和非技术用户均可完成。首先，为 AIP 提供自然语言提示词，或直接输入正则表达式来指定敏感数据模式。然后，配置 Foundry 在发现与这些模式匹配的数据时自动执行的操作。

创建 SDS 匹配条件。

SDS 可用于临时扫描，也可以配置为随着新数据不断添加到平台而定期重复运行。

通过调整匹配条件和扫描执行的频率，个性化您的扫描。

跨多个应用，安心无忧

可以使用 Sensitive Data Scanner（敏感数据扫描器）来保护您的数据。请参考以下假设性示例：

  1. 某组织通过手动上传以及 Magritte 摄取作业，定期摄取包含个人身份信息（PII）的数据，此时可能会忘记在新数据集上设置 标记 。周期性运行的 SDS 扫描可用于防止 PII 无意间泄露给广大未授权用户。
  2. 在处理敏感数据的组织中，数据治理团队可以使用 SDS，通过采用一组合适的参数对数据集执行周期性扫描来锁定高度敏感的信息。团队成员可以创建 重叠匹配条件 以用于扫描，并确保最敏感的数据始终受到保护且在分析中受到限制。
  3. 借助 AIP 利用 LLM 开发运营工作流的组织，可以应用 SDS 来检查通过光学字符识别（OCR）从文档中提取的文本，然后再将其集成到本体论对象中，这有助于防止将敏感信息发送给 LLM。

有关更多信息，请查阅 Sensitive Data Scanner 文档。

Developer Console 中的网站托管简介 [Beta]

发布日期：2024-02-08

Developer Console 即将支持静态网站托管。静态网站包含预定义数量的文件（例如 HTML、CSS、JavaScript），这些文件会按存储时的原样直接下载到最终用户的浏览器中进行渲染。此前，要托管使用 OSDK 构建的静态 Web 应用，用户必须使用自己的外部网站托管解决方案，并结合诸如 React ↗等框架。此新功能允许开发者直接使用 Foundry 托管和提供网站服务，无需外部网站托管基础设施，从而简化了工作流程。

此功能将于 2 月中旬作为测试版功能面向所有 Foundry 托管域推出，并计划于今年晚些时候正式发布。

直接在 Foundry 上托管您的网站

在 Developer Console 中配置静态网站托管只需几个简单的步骤即可完成。首先，在左侧菜单中选择 网站托管 ，然后：

  1. 为网站设置应用程序域，以定义用户访问网站时使用的 URL。
  2. 将包含该网站的资源上传到 Foundry。
  3. 预览上传结果并发布到站点。

您还可以配置网站的访问权限，并直接在设置页面中为站点配置高级 内容安全策略（CSP） 设置。

Developer Console 即将支持静态网站托管。

谁可以配置网站托管？

任何拥有 Developer Console 编辑权限或所有者角色的用户都可以配置静态网站托管。应用程序的子域地址必须获得注册信息官（Enrollment Information Officer，EIO）的批准。批准请求可在 Developer Console 设置中进行管理，而 EIO 则通过 Control Panel 授予批准。

SMB Connector [Beta] 简介

发布日期：2024-02-01

SMB Connector [Beta] 允许您连接到服务器消息块 (SMB) 文件共享，并将文件引入 Palantir 平台。SMB 文件共享的常见示例包括 Windows 文件服务器、Samba 文件服务器以及大多数商用 NAS 设备。

在此之前，我们建议的 SMB 文件共享连接方式是将共享作为目录挂载到 Foundry Agent 的 服务器上，然后使用 Directory Connector 来引入文件。我们鼓励所有使用旧方式的用户迁移到新的 SMB Connector。

SMB Connector 相较于文件系统挂载的优势：

  • 无需对您的代理进行 SSH 访问
  • 可作为 直接连接运行
  • 不会在代理服务器上以明文形式存储凭据
  • 在服务器重启后仍然保留

有关更多信息，请查看 服务器消息块 (SMB) [Beta] （位于公开文档中）。
