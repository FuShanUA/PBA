Foundry

Foundry 连接器支持将数据从一个 Foundry 实例共享到另一个 Foundry 实例。此工作流需要访问两个 Foundry 实例，并将其中一个实例指定为“源”，另一个指定为“目标”。在整个数据连接过程中，用户将在目标实例上执行大多数功能。

请注意，此连接器目前不兼容 视图 作为输入，也不兼容 受限视图。目标实例摄取的数据集必须先在其源实例中物化。

例如，如果某个用例需要将数据从 red.palantirfoundry.com 到 blue.palantirfoundry.com，大部分设置和后续交互都将在目标实例中进行 blue.palantirfoundry.com，即传输数据最终落地的地方。下文讨论的工作流通过数据摄取读取数据，而非通过数据导出写入数据。

设置

  1. 打开 数据连接 应用程序并选择 + 新建源 在屏幕右上角。

  2. 选择 Foundry 从可用的连接器类型中。

  3. 选择使用 直接连接 （通过互联网），或 通过中间代理连接。

  4. 输入 hostname ，该值属于您的源 Foundry 实例。在这种情况下， blue.palantirfoundry.com 将拉取数据，其来源为 red.palantirfoundry.com，因此 red.palantirfoundry.com 是源实例。

  5. 请选择一种身份验证方式。

  6. 如果您使用的是直接连接，请为源实例创建出站策略。如需将数据从 red.palantirfoundry.com 摄取到 blue.palantirfoundry.com，请为 URL https://red.palantirfoundry.com 在 443 端口上创建出站策略。与传统的数据连接不同，您必须将源实例中的所有 IP 地址列入白名单。此操作通过控制面板完成，方法是选择相应选项来 配置网络入口

  7. 请按照以下说明配置源实例的入口 IP 允许列表，方法是将目标实例的 IP 地址添加到源实例的 网络入口 扩展（位于控制面板中）：

    1. 导航至目标实例中的 网络出口 控制面板扩展，以确定合适的 IP 地址。
    2. 启动 网络入口 源实例中的 Control Panel 扩展。
    3. 请查看现有文档以 配置网络入口。

如果您正在创建 基于代理的连接，则您必须根据代理所在的主机提供相应的 IP 地址。此外，您的代理必须至少使用 Java 21，因为使用 Foundry 连接器的基于代理的连接与较早版本的 Java 不兼容。 详细了解在配置网络出口时如何识别 IP。

如果您无法访问 网络入口 控制面板扩展，请联系 Palantir 支持。

了解有关 设置连接器 （在 Foundry 中）的更多信息。

身份验证

Foundry 连接器支持以下身份验证方法：

客户端凭据（生产环境）： 对于长期连接，我们仅允许使用客户端凭据。要创建客户端凭据，请按照以下步骤操作：

  1. 通过以下链接导航到开发者控制台：

1https://<SOURCE_FOUNDRY_INSTANCE>.palantirfoundry.com/workspace/developer-console/
  1. 选择 + 新建应用程序 并提供一个名称。
  2. 选择 否,我不会使用本体论 SDK 并务必 启用 您的应用程序(在选定其所属组织后)。
  3. 选择 后端服务。
  4. 为您的应用程序提供适当的权限。您可以选择 应用程序权限 或 用户权限 但默认情况下，您应保持应用程序权限处于勾选状态。
  5. 系统将向您显示客户端密钥，您必须将其复制到剪贴板，然后粘贴到目标 Foundry 实例中。
  6. 保存后，导航至 Oauth 与权限 在左侧菜单中。
  7. 复制您的客户端 ID。

此过程将创建一个 服务用户 ，您可以为该服务用户授予或拒绝对 Foundry 中资产的访问权限。要检查此服务用户是否有权访问某个数据集或项目，您可以使用给定资产的 检查访问权限 功能。

个人访问令牌（临时）： 出于安全考虑，我们不允许在生产用例中使用令牌。如果在运行同步时依赖于有效期超过 36 小时的令牌，则导入将会失败。

身份验证凭据需在目标实例中输入。在源实例中，您必须创建一个令牌，以授予目标实例读取数据的能力。为此，请导航至以下 URL：

Copied!
1https://<SOURCE_FOUNDRY_INSTANCE>.palantirfoundry.com/workspace/settings/tokens

然后，选择 + 创建令牌 （位于右上角）。在此步骤中，您可以为令牌命名并选择其有效期。然后，复制您的令牌并导航至目标 Foundry 实例。

所提供的凭据必须具有以下必要权限：

  • 浏览并读取源 Foundry 实例中的数据集
  • 从正在同步的特定项目和数据集读取数据

网络

Foundry 连接器需要通过 443 端口 (HTTPS) 对目标 Foundry 实例进行网络访问。目标实例需要具有与源实例 URL 相对应的出站策略。

要启用从一个 Foundry 实例到另一个 Foundry 实例的直接连接，相应的 出站策略 必须在 Data Connection 应用程序中设置源时添加。

使用代理进行连接时，无需出站策略。

从 Foundry 同步数据

要设置 Foundry 到 Foundry 的同步，请选择 浏览并创建同步 ，该按钮位于源 概览 屏幕的右上角。浏览源 Foundry 实例中可用的项目和数据集，然后选择要同步的数据集。准备就绪后，请选择 为 x 个数据集创建同步。

增量同步

增量（或追加）同步会维护最近一次同步的状态，并且仅从目标数据集中摄取新数据或已更改的数据。使用 Foundry 连接器建立此类摄取有两种方式。

增量选项 1：先摄取所有数据，之后仅摄取更新

可以将"初始增量状态"设置为任意久远的日期，例如 1970 年 1 月 1 日。在首次运行摄取时，将提取所有数据。从第二次运行开始，每次摄取将仅提取可用的最新数据。

增量选项 2：摄取特定日期之后的所有数据

"初始增量状态"可以设置为您选择的日期，例如 2024 年 1 月 1 日。与上述选项类似，首次运行数据摄取时将提取所有数据，随后的数据摄取将仅提取可用的最新数据。对于数据摄取的作者已知希望排除外部源系统中在特定日期之前写入的数据的使用场景，这是一个过滤性更强的选项。

创建流式同步

您可以将流从一个 Foundry 注册摄取到另一个 Foundry 注册。源注册中的数据集必须是流。可以通过数据集 RID 和分支名称建立同步。在指定架构并首次运行后，将在目标注册中创建一个新数据集。

流式偏移选项

可以将同步配置为仅摄取新创建的行，也可以配置为从摄取流中的所有现有行开始。需要考虑的主要权衡是：如果流式数据集足够大，从时间和计算的角度来看，摄取所有历史行的开销可能会很高。

虚拟表

虚拟表不支持数据集。只有 托管 Iceberg 表 位于"源" Foundry 实例上，才能被虚拟化。

本节提供了更多详细信息，说明如何使用 虚拟表 与 Foundry 数据源。同步到 Foundry 数据集时，本部分不适用。

在代码中调用 Foundry API

除了上述 Foundry 到 Foundry 的同步工作流之外，Python 转换还可以使用 OAuth2 客户端凭据授予模式直接调用 Foundry API。当你需要调用未以同步形式公开的 Foundry 端点时（例如，在转换中枚举项目内容、触发构建或从本体论 API 读取数据），请使用此模式。

整体设置（REST API 源配置、存储 client_id/client_secret 作为额外的机密，以及通用的令牌请求和分页脚手架）与任何其他 OAuth2 客户端凭证流程相同。请查看 OAuth 客户端凭证授权示例 （位于 REST API 连接器页面上），以了解通用模式。

以下各节介绍与第三方 API 不同的 Foundry 特有详细信息。

Foundry 令牌端点

Foundry 的 OAuth2 令牌端点为：

POST /multipass/api/oauth2/token

该端点托管在您正在调用的 Foundry 实例上。如果转换运行在与所调用的实例相同的实例上，则 hostname 在 REST API 数据源上即为同一实例；如果是不同的实例，则该数据源的 hostname 属于目标实例，并且您必须配置 出站策略 和 入站白名单 ，如 《网络连接》中所述。

了解有关 令牌端点参数。

Foundry 作用域

每个 Foundry API 端点都记录了其所需的作用域——各端点的参考信息请参见 API 文档。一些常见的示例：

作用域授予的访问权限
api:datasets-read读取数据集
api:datasets-write写入数据集
api:ontologies-read读取本体论对象和关联类型

仅请求您的转换所需的作用域。多个作用域之间用空格分隔，例如 api:datasets-read api:datasets-write。

创建客户端

该 client_id 和 client_secret （在令牌请求中使用的）来自 第三方应用程序 （已在目标 Foundry 实例上注册）。请按照上文 身份验证 中的步骤来创建后端服务应用程序并获取 client_id 和 client_secret，然后将其存储为 附加机密 在您的 REST API 源上。

必须为客户端创建的服务用户授予对转换需要访问的每个项目、数据集或本体论资源的权限。

示例：列出项目的子级

以下转换向 /multipass/api/oauth2/token请求访问令牌，然后使用该令牌，通过 Foundry /api/v2/filesystem/resources/{rid}/children 端点列出项目的子级。有关本示例复用的通用令牌请求和分页脚手架，请参阅 REST API OAuth 客户端凭据授权示例。

1import logging

3import pandas as pd
4from transforms.api import Output, transform_pandas
5from transforms.external.systems import external_systems, Source, ResolvedSource
6
7logger = logging.getLogger(__name__)
8
9
10@external_systems(
11    foundry_api_source=Source("<source_rid>")
12)
13@transform_pandas(
14    Output("<output_dataset_rid>"),
15)
16def compute(foundry_api_source: ResolvedSource) -> pd.DataFrame:
17    base_url = foundry_api_source.get_https_connection().url
18    client = foundry_api_source.get_https_connection().get_client()
19
20    client_id = foundry_api_source.get_secret("additionalSecretClientId")
21    client_secret = foundry_api_source.get_secret("additionalSecretClientSecret")
22
23    token_response = client.post(
24        base_url + "/multipass/api/oauth2/token",
25        data={
26            "grant_type": "client_credentials",
27            "client_id": client_id,
28            "client_secret": client_secret,
29            "scope": "api:datasets-read",
30        },
31        headers={"Content-Type": "application/x-www-form-urlencoded"},
32    )
33    token_response.raise_for_status()
34    access_token = token_response.json()["access_token"]
35
36    auth_headers = {"Authorization": f"Bearer {access_token}"}
37
38    project_rid = "ri.compass.main.folder.xxxxxxxx-xxxx-xxxx-xxxx-xxxxxxxxxxxx"
39    resources = []
40    page_token = None
41    while True:
42        params = {"pageSize": 100}
43        if page_token:
44            params["pageToken"] = page_token
45
46        response = client.get(
47            base_url + f"/api/v2/filesystem/resources/{project_rid}/children",
48            headers=auth_headers,
49            params=params,
50        )
51        response.raise_for_status()
52        body = response.json()
53
54        for resource in body.get("data", []):
55            resources.append({
56                "rid": resource.get("rid"),
57                "name": resource.get("displayName"),
58                "type": resource.get("type"),
59            })
60
61        page_token = body.get("nextPageToken")
62        if not page_token:
63            break
64
65        logger.info(f"Fetched {len(resources)} resources so far, continuing to next page.")
66
67    return pd.DataFrame(resources)
