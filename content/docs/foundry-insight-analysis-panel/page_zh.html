分析面板

您可以在工作簿左侧的分析面板中找到各种 Insight 分析工具。通过此面板，您可以逐步构建分析。在这里，您还可以找到可能已应用于您的 表格、 图表或 地图的筛选器。面板中显示的卡片代表分析结果以及达到这些结果所采取的步骤。

分析面板的标头包含路径名称，您可以对其进行编辑。标头右侧是可折叠的路径菜单。

路径菜单

您可以在分析面板内的路径菜单中查看以下选项：

复制路径： 将路径复制到当前工作簿中的另一个路径、新工作簿或您选择的现有工作簿。此操作将复制路径的详细信息，包括起始数据集以及代表路径中每个步骤的卡片。

引用对象集： 如果某条路径支撑着已发布的对象集，菜单中会显示引用该对象集的选项。引用已发布的对象集后，该对象集将作为起始数据块，放置在当前工作簿中的另一条路径、新工作簿或现有工作簿中。被引用的对象集为只读，这意味着您无法对其进行编辑。但是，此引用允许您与对象集数据进行交互，或在分析路径中添加更多步骤。包含对象集引用的路径，其结果也可以发布为对象集。

导出 xlsx： 将表格结果导出为 Excel 文件。最多可导出 200,000 个对象。

另存为列表： 您可以将路径保存为列表，以创建一个仅包含分析路径结果中找到的对象 ID 的资源文件。这意味着分析步骤本身不会保留在列表资源中。当您希望保留确切的分析结果以供将来参考时，保存列表非常有用。如果源对象类型中的底层数据发生变化（例如，数据随时间更新），列表不会改变；它是保存时结果的一个静态副本。可以通过添加或删除对象来编辑列表，您可以通过右键单击表中的单个对象将对象 ID 添加到列表中。

删除： 您可以选择删除分析路径，这是一个永久性操作。如果该路径支撑一个对象集，将会出现一个额外的对话框，询问您是否也要删除该对象集。如果删除支撑路径，已发布的对象集可以继续存在。

步骤卡片

在路径中，您可以使用工具功能区中的工具逐步构建分析。每次使用工具构建分析时，都会出现一个配置卡片，并显示该步骤所使用的对象数量。

在面板中选择某个步骤卡片，可导航到分析中的相应部分，并在表格、图表和地图部分查看结果。您还可以检查该特定步骤的数据结果。

工具

您可以从分析面板中的功能区访问 Insight 的所有分析工具：

  • 筛选
  • 关联
  • 转换

大多数卡片显示相同的值和选项：

  • 如果路径中存在多种对象类型，则会显示按对象类型划分的对象数量。
  • 能够将卡片从默认名称重命名（例如，将 Filter 更改为 Show positive reviews）。
  • 将鼠标悬停在卡片上，可查看其他选项：
    • 删除： 从分析中移除该卡片。
    • 折叠/展开： 展开卡片可查看工具配置的详细信息，或折叠卡片以显示简化的结果摘要。
    • 切换： 开启后，该工具将在分析路径中处于活动状态。关闭后，该工具将从路径中禁用。此选项允许您测试分析中的各个步骤，而无需从路径中移除卡片。

卡片无法重新排序，但您可以在路径中的现有步骤之间添加新卡片。将鼠标悬停在步骤卡片之间，即可查看 + 添加 选项，该选项将在这些卡片之间打开工具功能区。

选择任意卡片即可查看该步骤生成的数据，并在分析路径的任意位置检查数据详情。
