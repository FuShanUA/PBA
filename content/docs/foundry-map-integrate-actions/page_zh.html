本体论操作

您可以在本体论中配置 操作 ，用户可将这些操作应用于 Map 应用程序中的地理空间对象。例如，这些操作可能是基于选定的点、多边形或在地图上绘制的线条来创建或编辑对象。

点操作

当用户在地图上或点对象上右键单击时，操作菜单将显示所有适用于地理空间点的本体论操作。要定义适用于点的操作，该操作需要具备以下任一项：

  • 一 String 个参数，其类型类别为 Kind: geo Value: geopoint （数据将是 latitude,longitude的字符串），或者

  • 两 Double 个参数：
    • 一个接收纬度的参数，其类型类别为 Kind: geo Value: latitude，以及
    • 一个接收经度的参数，其类型类别为 Kind: geo Value: longitude。

形状操作

当用户选择一个多边形对象或在地图上绘制形状时， 操作 菜单将显示所有适用于地理空间形状的本体论操作。要定义适用于形状的操作，该操作需要具有一个 String 参数，其类型类别为 Kind: geo 和 Value: geojson，其中数据将是 GeoJSON 几何字符串。

使用操作来编辑对象 geoshape 属性

可以将操作配置为允许用户编辑 geoshape 地图上对象的属性。用户可以选择该对象，从 操作 菜单中选择相应的操作，然后根据需要修改形状（例如，添加或移动点、进行缓冲或平移形状）。

要将操作配置为允许用户编辑 geoshape 地图上对象的属性，请为所需的对象类型创建一个"修改对象"操作，并为其配置一个满足以下要求的参数：

  • 是一个 String 参数
  • 映射到 geoshape 对象上您希望更新的属性
  • 已禁用默认值
  • 类型类为：Kind: geo，Value: geojson
  • 类型类为：Kind: geo，Value: prefill
