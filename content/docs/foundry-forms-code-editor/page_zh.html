代码编辑器

日落

对于 Foundry 上的数据录入或回写工作流，Foundry Forms 已不再是推荐方案。建议改用 Foundry Ontology 构建用户输入工作流，将相关数据结构表示为对象类型，并通过 Actions 配置回写交互。详情请参阅《Forms 概览》文档。 在 Foundry Forms 中，每个表单字段都可以配置一个或多个验证器，以防止格式不正确的输入。以下是一些验证器示例： 文档。

直方图 代码编辑器 允许用户查看和编辑表单的 YAML 表示。虽然大多数配置都可以通过可视化编辑器完成，但代码编辑器提供了完整的功能，包括添加四个 仅代码字段.

要查看代码编辑器的实际效果，请选择表单左下角的黑色 </> 按钮将其打开。然后，使用可视化编辑器添加一个字段。请注意，在配置字段时，代码如何自动填充和更新。

选择代码编辑器右上角的书籍图标，可直接在代码编辑器窗口中打开示例和文档。

在顶层，有 name （表单的标题）、 fields （字段列表）和 sheets （一个 工作表列表）。然后，每个 sheet 本身也具有这些相同的选项。字段具有 通用选项的源（例如 uri, name日 type，以及特定选项（在 options下方），例如 placeholder, precision日 unit.

通用选项

可以为每个字段配置以下选项：

    uri: string
    type: string
    name: string
    urlParam: string
    tag: string
    helperText: string
    infoText: string
    columnSpan: integer
    disabled: Boolean
    hidden: Boolean
    isBlock: Boolean
    noLabel: Boolean
    validators: list<Validators>
    transforms: list<Transforms>
  • uri: 字段的唯一标识符。如果字段将被写回 Fusion 或本体论（Ontology），则需要分别与列名或属性 ID 匹配。如果字段不被写回，则需要以以下前缀开头 display..
  • type: 字段的类型（例如， Text, Numeric, DatePicker).
  • name: 字段的标签。
  • urlParam: 与字段关联的 URL 参数。这允许用户在表单嵌入 iframe 时预填值。
  • tag: 字段的另一个唯一标识符，但没有限制。这是一个字段引用另一个字段时使用的标识符（例如， Calculation, Template），但以下情况除外 附件.
  • helperText: 字段下方的说明文字。
  • infoText: 显示在字段标签旁边的信息提示内容。
  • columnSpan: 字段占用的列数。
  • disabled: 允许用户将字段设为只读。
  • hidden: 允许用户隐藏字段但记录其值。
  • isBlock: 允许用户将标签显示在字段上方而不是左侧。
  • noLabel: 允许用户隐藏字段的标签。此选项仅可通过代码编辑器使用。
  • validators: 验证器 应用于字段。
  • transforms: 转换 应用于字段。

仅代码字段

有四个字段只能通过代码编辑器使用：

  • 隐藏
  • 列表
  • 复合字段
  • 列表聚合

隐藏

直方图 hidden 字段允许用户在不显示字段的情况下记录值。其配置如下：

- uri: Hidden
  name: Hidden
  type: Hidden
  options:
    val: string

列表

直方图 列表 字段允许用户 存储多个值 （当字段本身不支持时）。其配置如下：

- uri: names
  name: Full names
  type: List
  options:
    # allowZeroItems: true
    item:
      type: Text
      # and other supported generic options (helperText, infoText, validators)
      options:
        placeholder: 'Last, First'
        # and other specific options

allowZeroItems 是可选的，默认值为 false。

复合字段

直方图 composite 字段允许用户将多个字段的值存储为一个字符串化的 JSON。其配置如下：

- uri: info
  name: Composite
  type: Composite
  options:
    fields:
      - uri: date_of_birth
        name: Date of birth
        type: DatePicker
        # and other supported generic options (helperText, infoText, disabled, isBlock, noLabel, validators)
        options:
          precision: day
          # and other specific options
      - uri: weight_kg
        name: Weight
        type: Numeric
        options:
          unit: kg

隐藏 字段以及那些 允许多值的类型 不允许在复合字段中使用的字段。

列表聚合

直方图 列表聚合 字段类似于 计算 和 模板 字段，但适用于以下字段： 存储多个值。其配置如下：

- uri: single_value
  tag: single_value
  name: Single Value
  type: RadioButtons
  options:
    options:
      - value: '10'
      - value: '20'
      - value: '30'
- uri: multi_values
  name: Multiple Values
  tag: multi_values
  type: Checkboxes
  options:
    options:
      - value: '40'
      - value: '50'
      - value: '60'
- uri: avg_value
  name: Average Value
  type: ListAggregate
  options:
    listOperation:
      operation: mean
      listTag: [single_value, multi_values]
    # errorValue: No values selected

或者，当与 composite 字段一起使用时：

- uri: grades
  tag: grades
  name: Grades
  type: List
  options:
    item:
      type: Composite
      options:
        fields:
          - uri: name
            name: Name
            type: Text
            options:
              placeholder: 'Last, First'
          - uri: grade
            name: Grade
            type: Numeric
            options:
              unit: '%'
- uri: all_grades
  name: All grades
  type: ListAggregate
  options:
    listOperation:
      operation: concatenate
      joinWith: ', '
      listTag: grades
      displayItem: grade
    # errorValue: No grades added

在配置 options 字段：

  • errorText 是可选的，默认为空字符串。
  • 在 listOperation:
    • operation 可以是 concatenate, sum, min, max, mean，或 count.
    • listTag 是被聚合字段（或字段数组）的标记。
    • joinWith 仅在操作为 concatenate.
    • displayItem 仅在聚合字段为 composite 字段时才需要，并且是嵌套字段的 URI。
