脱敏模式

脱敏模式会对 Workshop 应用中可见的内容进行视觉遮蔽，使您无需暴露底层数据即可共享模块的布局和结构。当您需要截图或共享屏幕并希望隐藏底层数据时，请使用脱敏模式。脱敏模式不同于 信息亭模式，后者会限制权限，而脱敏模式不会。

脱敏模式仅是一种视觉辅助手段，并非安全功能。Workshop 仍会加载和处理底层数据；脱敏模式仅会改变页面的渲染方式。请勿依赖脱敏模式来保护敏感信息，使其不被能够访问您浏览器会话且执意查看的用户获取。

启用脱敏模式

将查询参数 ?workshop_enableRedactMode=true 追加到任意 Workshop 模块的 URL 中，即可启用脱敏模式。该参数会在应用内导航期间保留在 URL 中，因此重新加载页面或复制 URL 都会保留脱敏状态。

脱敏模式会改变哪些内容

开启脱敏模式后，Workshop 会通过以下方式更改页面的呈现：

  • Workshop 会使用自定义字体渲染所有文本，该字体将每个字符替换为遮蔽的字形，同时保留单词的大致长度和形状。
  • Workshop 会将图标和图表绘图区域替换为对角条纹背景。
  • Workshop 会隐藏图像、SVG、画布、视频、音频元素以及嵌入的 iframe。

除此之外，模块行为不会发生变化。变量、事件、操作和数据获取均正常运行，您可以像在其他任何会话中一样浏览、筛选并与模块交互——只有页面渲染会发生变化。
