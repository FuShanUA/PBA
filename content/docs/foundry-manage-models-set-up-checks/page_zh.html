为所有提交设置检查

建模目标检查是一种确保模型在投入运营之前通过预定义质量检查的方法。目标检查可针对每个目标进行自定义，使具有不同专业背景的模型评审人员能够协作评估模型的性能。这种评估确保模型状态和讨论对建模目标的所有利益相关者而言是透明且有条理的，从而清晰呈现模型的质量状况。

例如，作为建模项目的管理者，您可能希望所有提交到您目标中的候选模型在发布前都获得批准。您可能需要的一些批准可能来自：

  • 一个管道基础设施团队，确认您的模型通过了冒烟测试。
  • 一个数据科学团队，负责确保模型的指标在部署到运营应用之前满足相关要求。
  • 一个伦理团队，确保训练数据保持适当的平衡，或确保模型满足机构公平性要求。

对于上述每项检查，与相关评审组或用户开展有针对性的讨论线程，有助于就模型是否具备部署条件得出结论，并为您的下一次模型迭代收集反馈。

您可以为上述每个检查点配置一个目标检查，以创建独立的讨论线程，从而提供一个专注的协作空间来评估该目标中的所有模型提交。

配置目标检查

要为您的目标配置检查，请前往 设置 页面（位于右侧边栏中），然后导航至 检查 选项卡。在这里，您可以创建一个新检查，包括名称、描述以及有资格批准该检查的用户或组。在下面的示例中，如果 pcl-team 组或 Administrators 组中的任何人批准该检查，则此检查将被标记为已批准。

您可以根据需要添加更多检查，或参考下面的示例检查。

通过检查协作评估模型提交

现在您已经为目标配置了相关检查，可以开始与各个评审组协作评估您的模型提交。

在模型提交页面上，导航至 检查 面板。在这里，您可以看到为目标配置的检查。评审人员在评估模型提交时可以批准、拒绝或对每项检查发表评论。此外，评审人员还可以添加附件（例如指标截图）或根据需要标记用户组。

目前，并非要求所有检查都获得批准后才能为模型提交创建发布。

基于自动评估的检查

还可以创建状态基于对给定输入数据集和评估库执行的评估结果的检查。

可用的输入数据集和评估库选项将继承自建模目标的 评估仪表板中定义的评估配置。此外，使用评估仪表板构建的指标将用于确定检查的状态。

指标要求定义了提交通过此检查所需满足的条件。当 PASS 状态在指标满足要求时达成。如果指标未满足要求，或在所选评估库生成的指标集中找不到该指标，则状态为 REJECT ，并附带一条说明拒绝原因的消息。如果尚未针对与该检查关联的提交、输入数据集和评估库组合构建指标，则检查的状态将为 PENDING。如果指标构建失败，也会出现待定状态。

归档检查

页面中，您可以通过检查旁边的“禁用”图标归档某个客观检查。归档的检查默认不再显示在提交的检查页面上。但是，通过选择 设置 按钮，仍可查看已归档检查的历史评论和审批记录。 视图右上角的 按钮，仍可查看已归档检查的历史评论和审批记录。

按检查状态筛选模型

您可以根据特定检查或整体提交的状态，筛选客观中的模型。当您想查看哪些模型已通过部署所需的所有检查，或者需要审查所有具有特定待处理检查的提交时，此功能非常有用。

在 Data Connection 中导航至 链接进行访问。 左侧的标签页，然后选择 所有模型 顶部的标签页。在此，您可以在表格中查看所有模型提交的列表及其整体检查状态。在左侧面板中，您可以看到标签为 检查状态的筛选组。在此，您可以选择要用于筛选提交的检查及其状态。
