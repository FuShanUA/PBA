Iceberg 表快照

Iceberg 快照是表在某一时间点的状态记录。它精确记录了快照提交那一刻构成该表的数据文件。每次向 Iceberg 表写入数据都会生成一个新快照。

本页介绍了什么是快照、在 Foundry 中的何处查看快照、快照操作的类型，以及快照如何映射到 Foundry 数据集事务。

快照的工作原理

在 Iceberg 中，每次数据写入都会在当前快照的基础上提交一个新快照，从而形成表演变的历史记录。快照本身并不存储数据，而是引用在该时刻构成表的数据文件集合，这一信息记录在表的元数据中。

可以通过快照过期来移除快照，您可以在 维护 标签页中对其进行配置。过期是不可逆的：您无法查看、时间旅行到或回滚到已过期的快照。

有关 Iceberg 快照和元数据模型的完整技术描述，请参阅 Apache Iceberg 表规范 ↗。

仅涉及元数据的操作（包括更新 schema、标识符列或分区）不会创建 Iceberg 快照，也不会出现在 快照 选项卡。新架构版本将在下一次生成快照的操作后显示在该选项卡中。

在 Foundry 中查看快照

该 快照 选项卡位于 数据集预览 中,以一系列快照的形式显示 Iceberg 表的历史记录。它是对 历史记录 选项卡的补充,该选项卡列出了针对该表运行的 Foundry 作业。

该 趋势 部分提供了您的快照在所选时间范围内的可视化概览,并使用 Iceberg 的 快照摘要指标 ↗。x 轴表示提交时间,每个点代表一个快照,绘制于其提交的时刻。

  • 总大小: Iceberg 的 total-files-size,以字节为单位计量,并在显示时采用基于 1024 的 IEC 二进制单位 ↗。表示随时间变化,所选分支上截至给定快照的有效数据文件和删除文件的总大小。不包括元数据文件和孤立文件。
  • 记录数: Iceberg 的 total-records。表示物理存储在有效数据文件中的记录。Iceberg 将其计算为之前的总数加上新增数据文件中的记录数,再减去移除数据文件中的记录数。由位置删除或等值删除表示的行仍包含在内,因此该指标可能会超过读取器可见的行数。
  • 文件数: Iceberg 的 total-data-files。表示给定快照中有效的数据文件数量。不包括删除文件、元数据文件和孤立文件。
  • 架构版本： 与给定快照关联的架构版本。

快照 表列出了所选时间范围内的所有快照（最新的在前），并包含以下列：

  • 时间戳： 快照提交时间。如果快照来自 Foundry 构建，则 查看作业 链接将打开该作业。
  • 快照 ID： 表的元数据文件中记录的快照 ID。点击即可复制。
  • 类型： 生成快照的操作（Append、Overwrite、Replace 或 Delete），如 快照类型中所述。
  • 大小、记录数、文件数： 所生成表的总计数据，以及该快照带来的新增和删除。
  • 架构： 快照中的架构版本。标记会突出显示引入了新版本的快照。
  • 归属： 发起写入的用户或组（如有）。

此视图中仅显示当前元数据文件中存在的快照。已过期的快照不再存在于元数据中，因此不会显示。

在表中选择架构版本将打开一个对话框，其中显示该架构版本的详细信息以及与上一架构版本相比的更改。

快照类型

每个快照都会记录生成该快照的操作类型。Iceberg 定义了四种快照类型。

追加

会添加新的数据文件，且不会修改或删除任何现有内容。普通追加会生成追加快照，对空表的首次写入也是如此。

对 新 Iceberg 表的首次写入 会被记录为 追加快照，即使其意图是完全替换表内容。这是预期行为。

当表为空时，追加数据与替换数据在逻辑上是等价的，因为没有任何可覆盖的内容。Iceberg 会将该操作记录为“追加”，因为只添加了文件，而没有删除任何文件。

覆盖

数据文件既会被添加，也会被删除，从而改变表中的逻辑记录集。覆盖快照涵盖部分覆盖和完全覆盖两种情况。对非空表的完全重写会生成覆盖快照，“Overwrite”和“Update”模式的 Data Connection 同步也是如此。

删除

数据会被逻辑删除，其方式要么是移除数据文件，要么是添加用于将行标记为待删除的删除文件。

替换

数据文件会被重写，而表的逻辑内容保持不变。典型的例子是压缩（compaction），可在 Maintenance 标签页中运行，它会为了性能而重新组织文件，但不会改变表所代表的记录。

快照如何映射到 Foundry 数据集事务

Foundry 数据集事务类型与 Iceberg 快照类型的对应关系如下。

Iceberg 快照类型Foundry 数据集事务
APPEND 快照APPEND 事务
OVERWRITE 快照UPDATE 事务
SNAPSHOT 事务
DELETE 快照DELETE 事务
REPLACE 快照（无对应项）
