VS Code 工作区的优势

本页面概述了在 Foundry 中使用 VS Code 编写和管理代码的优势。尤其是,在决定是否从代码仓库切换到 Foundry 中的 VS Code 时,应考虑以下几项优势。

借助 Continue 的 AI 驱动编码辅助

Foundry 中的 VS Code 附带 Continue,这是一款经过预配置的 AI 编码助手,可与 Palantir 提供的语言模型配合使用,并掌握相关 Palantir SDK 以及您的 Python 转换或 OSDK 仓库的相关知识。凭借对您的数据结构、本体论和组织的上下文理解,Continue 能够生成更准确、更相关的代码建议,并可访问 Foundry 专用工具来加速您的工作流程。

增强的预览功能

Foundry 中的 VS Code 提供了超越基本采样的强大预览功能:

  • Python 转换仓库中的完整数据集预览： 使用 完整数据集预览 即可在不进行随机采样的情况下预览转换的完整输出，从而获得与生产环境行为一致的准确结果。
  • 准确的增量预览： Palantir 扩展所运行的 增量解析和评估逻辑 与生产构建相同，同时适用于 Spark 转换和轻量级转换，并全面支持 v1 和 v2 增量语义。这样，您就能准确了解增量转换的具体行为。
  • 自定义筛选： 指定您自己的 代码定义的筛选器 以精确控制预览期间加载哪些数据，从而能够针对特定场景进行有针对性的测试。

优化的 VS Code 语言服务器

VS Code 中经过高度优化的语言服务器可带来高效、响应迅速的开发者体验，并在代码检查和自动补全等功能上实现大幅的速度提升。

集成终端

VS Code 的集成终端让您完全掌控开发环境。通过脚本自动化工作流，运行命令执行批量操作，并使用命令行界面高效管理版本控制。

灵活选择在 Foundry 或本地进行工作

VS Code 工作区 为您提供一个部署在 Palantir 基础设施上、可通过 Palantir 平台访问的环境。或者， Palantir extension for Visual Studio Code 可以安装在您本地的 VS Code IDE 中，以便直接与您在 Foundry 中的代码集成。

如需详细比较以帮助您确定哪种方式适合您，请查阅我们的文档，了解 如何在本地开发与 VS Code 工作区之间进行选择。

可自定义的用户体验

VS Code 工作区使您能够自定义工作流程并保存编码偏好设置,例如自定义按键绑定、可配置的颜色主题和布局,以及其他 UI 设置。
