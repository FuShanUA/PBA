应用于多列

支持环境：Batch、Faster、Streaming

通过选择列或对列应用函数来转换输入数据集。

转换类别: Popular

声明的参数

  • 要投影的列的条件： 输入 schema 中的所有列都将被测试，以查看它们是否匹配此条件。如果匹配，将对它们应用给定的表达式。
    ColumnPredicate
  • 数据集： 要应用操作的数据集。
    表格
  • 要应用的表达式： 对每个匹配条件的列应用一次的表达式。
    Expression<AnyType>
  • 保留其余列： 在数据集中保留所有未投影的列。
    Literal<Boolean>
  • 可选 保留匹配的列： 保留由条件匹配的原始列。如果投影列具有相同的名称，则原始列将被覆盖。
    Literal<Boolean>

示例

示例 1：基础用例

描述： 基于正则表达式重命名匹配的列。

参数值：

  • 要投影的列的条件：
    columnHasType(
     type: String,
    )
  • 数据集： ri.foundry.main.dataset.a
  • 要应用的表达式：
    dynamicAlias(
     expression:
    cast(
     expression: column,
     type: Integer,
    ),
     transformer:
    columnNameRegexReplace(
     input: column,
     pattern: str,
     replace: int,
    ),
    )
  • 保留其余列： true
  • 保留匹配的列： false

输入：

iddistance_strfactor_str
120001265

输出：

distance_intfactor_intid
200012651
