构建

A 构建 是用于计算新版本 数据集 的机制。构建提供计算的编排与协调，确保读取适当的输入数据，并将输出数据写入适当的位置。

一个构建由 作业组成，每个作业都是由共享逻辑定义的工作单元，并计算一个或多个输出数据集。如果一个作业定义了多个输出数据集，它们将始终一起更新，无法在不运行完整作业的情况下仅构建其中部分数据集。作业规范，即 JobSpec，是对作业应如何构建的定义。当 Foundry 中的数据转换逻辑发生更改时（例如数据工程师在 分支回退.

运行构建会一次性计算一组输出数据集。为了让数据持续在系统中流动， 计划 用于随时间推移运行构建。

您可以在 Foundry 中使用 构建应用程序.

作业与作业规范

A 作业 封装一个或多个 输出数据集 新版本的计算，其输入来自一组输入数据集。 JobSpec 通过详细说明输入数据集依赖关系以及作为作业一部分执行的逻辑，来定义如何构建作业。

输入数据集依赖关系被声明为一组 InputSpecs，每个 InputSpec 指定一个特定的输入数据集。InputSpec 根据数据集的视图指定要从数据集中读取的数据子集。

在 Foundry 中，许多类型的逻辑都可以表示为作业，包括但不限于：

  • 数据连接 同步 定义应如何从外部数据源读取数据。
  • 在 分支回退 中编写的转换允许您编写转换数据集的代码。
  • 运行状况检查 被定义为在数据集上生成的作业，用于验证数据集的特征。
  • 分析应用 支持定义转换数据集的逻辑。
  • An 导出 定义应如何将输入数据发送到 Foundry 之外。

作业状态

在任何给定时间，作业始终处于以下状态之一：

  • WAITING：作业的初始状态；作业正在等待其依赖的作业完成，尚未被调用。
  • RUN_PENDING：作业等待运行，但其执行环境尚未确认该状态。
  • RUNNING：作业已被调用，当前正在计算中。
  • ABORT_PENDING：作业已被中止，但其执行环境尚未确认中止状态。
  • ABORTED：作业因用户请求或依赖的作业失败而被中止。
  • FAILED：作业已被调用，但计算失败。
  • COMPLETED：作业已被调用，且计算成功完成。

构建生命周期

运行构建时，会执行若干步骤来验证提交的构建、确保数据一致性，并且仅运行生成新输出所必需的作业。

构建解析

作为第一步，构建会：

  • 检测指定的输入数据集中是否存在循环，如果存在循环则使构建失败。
  • 验证所有输入数据集是否存在，并为每个输入数据集识别适当的模式。
  • 在每个输出数据集上打开新的 事务 ，以确保只有当前活动的构建才能写入该输出数据集。这称为 构建锁定.
  • 检测是否有其他正在进行的构建会更改该构建的输入。如果有，该构建可能会被 排队 并等待其他构建完成。

作业执行

完成上述步骤后，构建中的作业将被执行。彼此不依赖的作业将并行运行。随着作业逐步经历各个 作业状态，整个构建的状态也会相应更新：

  • 如果构建中的某个作业失败，该构建中所有直接依赖的作业以及输出数据集上的事务都将被终止。此外，还可以选择将构建配置为同时中止所有非依赖的作业。
  • 如果构建中的所有作业都已完成，则该构建被视为已完成。

如果构建中的某个作业失败，先前已完成的作业可能已将数据写入其输出数据集。

过期状态

如果输出数据集被视为 最新 参数未定义）。请注意，相应的 Python 语法为 构建解析 步骤判定输入数据集和 JobSpec 中指定的逻辑自上次构建该输出数据集以来未发生更改，则该输出数据集即为最新。如果输出数据集是最新的，则在后续构建中不会重新计算。

要覆盖构建系统的默认过期行为，你可以运行 强制构建，它会在构建过程中重新计算所有数据集，无论它们是否已是最新。

取消单个作业

您可以取消单个正在运行的作业，而无需取消整个构建。在 Builds 应用程序中打开该构建，在 构建进度 部分中找到并选择该作业，打开其 操作 菜单，然后选择 取消作业.

分支

Foundry 中的构建实现了 分支 以支持数据管道上的协作工作流。要了解有关分支的更多信息：

  • 请参阅 分支概述 以获取高层次的说明。
  • 请参阅 构建中的分支 部分，以了解分支在构建中如何运作的详细信息。

实时日志

实时日志提供对正在运行的作业的实时可见性，使你能够监控作业的进展情况，并检查长时间运行的任务（如流或计算模块）。

你可以通过 Builds 应用程序访问实时日志。选择 实时查看 按钮（位于日志查看器右上角，在查看作业时显示）以开始生成。启用后，实时日志可能需要十秒钟的延迟才会显示在界面中。

实时日志的一个关键功能是按日志级别内置颜色编码，使你更容易识别和优先处理警告与错误：

  • 信息： 蓝色
  • 致命/错误： 红色
  • 警告： 橙色
  • 调试/跟踪： 灰色

此外，安全参数和参数以 JSON 块的形式显示，为你的数据提供结构化且易读的格式。

你可以随时选择 暂停 （位于界面右上角）来停止实时日志流，并从相同位置恢复。

时间范围选择不适用于实时日志，因为它们是从作业实时流式传输的。
