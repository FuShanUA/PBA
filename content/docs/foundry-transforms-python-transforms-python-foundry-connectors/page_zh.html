Foundry 连接器

用于通过 transforms API 与 Foundry 交互的连接器。

连接器可以交互式地用于构建 TransformInput 和 TransformOutput 对象，也可用于运行 Transform.

FoundryConnector

类 transforms.foundry.connectors.FoundryConnector(service_config, auth_header, filesystem_id=None, fallback_branches=None, resolver=None)

  • 用于访问的入口点 Foundry services.
  • 直方图 Foundry 对象通过提供操作数据集的 API 来管理与 Foundry 服务的交互。

参数

  • service_config (dict ↗)
    • Foundry 服务要连接到的配置字典。
  • auth_header (str ↗)
    • 连接到 Foundry 服务时使用的授权字符串。
  • filesystem_id (str ↗、可选的)
    • 要使用的支撑文件系统。
  • fallback_branches (List[str ↗], optional)
    • 回退分支。
  • resolver (Callable[[str ↗], str ↗], optional)
    • 用于将数据集别名解析为 rid 的函数。默认将别名解析为项目（Project）路径。

input(alias=None, rid=None, branch=None, end_txrid=None, start_txrid=None, schema_version=None)

  • 构造一个 TransformInput 。
  • 直方图 资源标识符 用于构造 TransformInput 的标识符将从给定的 alias 中解析，除非传入 rid 参数。

参数

  • 别名 (str ↗、可选的)
    • 数据集的别名。
  • rid (str ↗、可选的)
    • 数据集的资源标识符。
  • 分支 (str ↗、可选的)
    • 读取数据集所用的分支。如果未设置，则选择 回退机制 列表中在 目录.
  • end_txrid (str ↗、可选的)
    • 视图的结束事务。如果未设置，默认为给定分支上的最新事务。
  • start_txrid (str ↗、可选的)
    • 视图的起始事务。
  • schema_version (str ↗、可选的)
    • 读取时使用的模式（schema）版本。如果未设置，默认为给定分支上的最新模式版本。

返回

  • 表示所请求数据集的输入对象。

返回类型

  • transforms.api.TransformInput

抛出

  • ValueError ↗
    • 如果 别名 or rid （但不是两者同时）未指定。
  • ValueError ↗
    • 如果未指定分支，且在 目录.

output(alias=None, rid=None, branch=None, txrid=None, filesystem_id=None)

  • 构造一个 TransformOutput （根据给定的别名或 rid）。
  • 直方图 资源标识符 用于构造 transforms.api.TransformOutput 的标识符将从给定的 alias 中解析，除非传入 rid 参数。

参数

  • 别名 (str ↗、可选的)
    • 数据集的别名。
  • rid (str ↗、可选的)
    • 数据集的资源标识符。
  • 分支 (str ↗、可选的)
    • 写入数据集所用的分支。如果未设置，则选择 回退机制 list.
  • txrid (str ↗、可选的)
    • 数据应写入的事务。
  • filesystem_id (str ↗、可选的)
    • 如果数据集尚不存在，则在其中创建该数据集的文件系统。

返回

  • 表示所请求数据集的输出对象。

返回类型

  • transforms.api.TransformOutput

抛出

  • ValueError ↗
    • 如果 别名 or rid （但不是两者同时）未指定。

run（转换）

  • 运行给定的 转换 ，使用最新的输入和输出。

参数

  • 和构建数据的方法是应用一个联合操作。联合操作将两个数据集合并，以包含每个数据集的所有行。在Pipeline Builder中，联合操作会保留所有行，包括重复的行。 (transforms.api.Transform)
    • 要运行的转换。

auth_header

  • str
    • 用于联系 Foundry 的认证标头。

fallback_branches

  • List[str]
    • 用于检索数据集的回退分支。

spark_session

  • pyspark.sql.SparkSession ↗
    • 此连接器使用的 Spark 会话。
