转换数据

将数据集添加到工作区后，您可以在 Pipeline Builder 中开始转换和构建数据 添加数据集 到您的工作区。

选择数据集

要对数据集应用转换，请在您的工作区中选择一个数据集节点，然后单击 转换.

搜索转换

在转换页面中，按名称搜索转换类型，或从可用转换列表中浏览。如果您使用的是结构化（表格）数据集，此字段会显示完整的表格转换列表。

对于 JSON 或 Microsoft Excel 文件等半结构化数据集，搜索字段包含文件转换，允许您将数据集解析为表格格式。

Pipeline Builder 会列出文件转换，例如 从 Excel 文件中提取行，仅当所选节点以文件形式读取时才会显示。如果数据集带有 schema，Pipeline Builder 会将该节点作为表格读取，并改为列出表格转换，因此文件转换不会出现在搜索字段中。要解析 Excel 或其他原始文件，请将数据集添加为无 schema 的输入，而不是作为表格。

填写转换配置面板中的必填信息，包括列、表达式或值。在下面的示例中，我们选择了 Rename columns 转换，选择了要重命名的列，并为这些列输入了新的名称值。

复用现有表达式

Pipeline Builder 允许您在创建新表达式时复用现有表达式中的值。

当您替换嵌套表达式中的某个表达式时，新表达式默认会删除您之前设置的任何字段或值。如果您想保留这些现有的字段或值，请选择 复用值 （位于表达式旁边）。这会自动将之前的值复制到您的新表达式中。

应用转换

完成转换表单后，单击 保存您的更改。 将转换添加到您的工作流中。您将看到转换节点在图中连接到源数据集。我们将新转换命名为 Clean Facility Data和 Facility dataset.

您可以通过单击转换节点并选择 编辑来重命名或编辑转换。

拖动节点上的白色输出圆点可以更改图中的连接。

转换视图

Pipeline Builder 提供两种查看转换的方式：传统的折叠面板渲染和伪代码渲染。设置您的视图偏好后，将在整个 Palantir 平台上全局更新您的个人视图。

折叠面板渲染

折叠面板渲染格式以紧凑的、类似面板的结构显示转换。此视图是传统格式，可能更适合习惯于这种布局的用户。

伪代码渲染

伪代码渲染格式以更简洁的、类似代码的格式显示转换，但不遵循任何特定编程语言的语法。

连接（join）、合并（union）和 LLM 节点不受伪代码渲染选项的影响。

此选项对熟悉编码的用户或偏好以更文本化的方式呈现管道逻辑的用户特别有用。伪代码还会自动调整以适应您的屏幕，从而减少滚动操作。

启用伪代码渲染后，无法在 Pipeline Builder 中进行代码编辑。该格式仅用于提供更熟悉的视图。

您可以通过以下方法启用伪代码渲染选项：

  • 设置菜单： 在 Data Connection 中导航至 设置 菜单。然后，选择 在 并切换以下选项 伪代码 under 折叠转换样式.

  • 在转换路径中： 在任何转换路径中，选择 </> icon.
