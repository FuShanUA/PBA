向地图添加数据

通过向地图添加数据来开始您的地理空间分析。您可以从 Foundry 平台向地图添加两类地理空间数据：本体论对象和地图叠加层。

在 图层 面板中，点击 + 添加到地图 使用搜索对话框将这两类数据中的任意一种添加到您的地图。

添加本体论对象

在搜索对话框中， 对象 标签页允许您添加 具有地理空间数据的本体论对象 到您的地图。

在对话框中，您可以在顶部的 搜索... 字段中输入任意问题来搜索对象，或使用左侧的筛选面板缩小搜索的对象范围。

您还可以 在控制面板中配置对象搜索限制.

筛选对象

选择一个对象类型以筛选结果，使其仅包含该类型的对象。选择对象类型后，您可以使用 一个 选项旁边的警告图标：

一些最常用的属性会自动显示在筛选区域中，您可以通过选择感兴趣的属性值来缩小对象结果范围。

您可以通过选择 + 添加筛选器 并添加所需属性，来按对象类型上的任意属性进行筛选。选择 返回 让您选择的属性显示在筛选区域中。

选择并添加结果

在结果表中选择一个对象。要切换任意对象的选择状态，请按住 Cmd （macOS）或 Ctrl （Windows）键，或者另外使用 Shift 键来选择一定范围的对象。使用 + 添加所选对象将所选对象添加到地图，或者使用 全部添加.

地图限制了可以从搜索对话框添加的对象数量。默认情况下，您可以添加 1000 个对象。当达到此限制时， 全部添加 选项将被禁用，您需要 筛选您的结果 以减少对象数量，之后该选项才会重新启用。

按地理空间方式搜索对象

您可以在特定的地理空间关注区域内搜索对象。从 添加到地图 下拉菜单中，选择 搜索与形状相交的对象...:

系统将提示您绘制一个 形状 围绕您要搜索的地理空间区域：

绘制完形状后，对象搜索对话框将打开，并仅显示包含与您绘制的形状相交的地理空间数据的对象：

添加地图叠加层

直方图 如果希望某些分区仅在业务流程的特定环节出现，就可以使用浮层。浮层会作为一层遮罩，覆盖在当前选定页面的上方。 搜索对话框的标签页允许您添加在 现在允许用户通过点击式界面将栅格瓦片数据添加到图层。配置完成后，地图图层即可供用户在中创建的图层。这些图层包含地理空间数据集的预配置视图，可在多个地图中重复使用。

该对话框提供多种查找图层的方式：

  • 在 搜索... 字段中输入文本，按名称查找图层。
  • 使用直方图中的 标签 侧边栏的部分，将图层结果缩小到特定主题。
  • 通过在 路径中 input.
  • 通过在 创建者.

选择一个图层。按住 Cmd （macOS）或 Ctrl （Windows）键以切换图层的选择状态，或使用 Shift 键选择一定范围的图层。使用 添加图层.
