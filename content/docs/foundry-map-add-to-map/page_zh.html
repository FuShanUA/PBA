向地图添加数据

通过向地图添加数据来开始您的地理空间分析。您可以从 Foundry 平台向地图添加两种地理空间数据：本体论对象和地图叠加层。

在 图层 面板中，点击 + 添加到地图 即可使用搜索对话框将这两种数据中的任意一种添加到您的地图。

添加本体论对象

在搜索对话框中， 对象 选项卡允许您将 具有地理空间数据的本体论对象 添加到您的地图。

在对话框中，您可以在顶部的主 搜索... 字段中输入任意问题来搜索对象，或使用左侧的筛选器面板缩小所搜索对象的范围。

您还可以 在控制面板中配置对象搜索限制。

筛选对象

选择一种对象类型来筛选结果，使其仅包含该类型的对象。选择对象类型后，您可以使用 筛选器 选项进一步细化您的搜索：

一些最常用的属性会自动显示在筛选器区域中，您可以通过为感兴趣的属性选择相应值来缩小对象结果的范围。

您可以按对象类型上的任意属性进行筛选，只需选择 + 添加筛选器 并添加所需属性。选择 返回 后，所选属性将显示在筛选区域中。

选择并添加结果

在结果表格中选择一个对象。要切换任意对象的选中状态，请按住 Cmd (macOS) 或 Ctrl (Windows) 键，或者还可以使用 Shift 键来选择一定范围内的对象。要将所选对象添加到地图上，请使用 + 添加所选对象；要添加所有与您的搜索匹配的对象，请使用 全部添加。

地图限制了可从搜索对话框中添加的对象数量。默认情况下，您可以添加 1000 个对象。当达到此限制时， 全部添加 选项将被禁用，您需要先 筛选您的结果 以减少对象数量，然后该选项才会重新启用。

以地理空间方式搜索对象

您可以在特定感兴趣的地理空间区域中搜索对象。从 添加到地图 下拉菜单中，选择 搜索与形状相交的对象...：

然后，系统将提示您绘制一个 形状 ，使其围绕您想要搜索的地理空间区域：

绘制完形状后，对象搜索对话框将会打开，并且仅显示包含与您所绘制形状相交的地理空间数据的对象：

添加地图叠加层

搜索对话框中的 叠加层 选项卡允许您添加在 地图图层编辑器中创建的图层。这些图层包含地理空间数据集的预配置视图，可在多个地图中重复使用。

该对话框提供了多种查找图层的方式：

  • 在顶部的 搜索... 字段中输入文本，即可按名称查找图层。
  • 使用侧边栏中的 标签 部分来将图层结果缩小至特定主题。
  • 若要查找特定文件夹或项目中的图层，请在 路径内 输入框中键入该文件夹的路径。
  • 若要查找由特定用户创建的图层，请在 创建者中选择该用户。

选择一个图层。按住 Cmd （macOS）或 Ctrl （Windows）键可切换某个图层的选中状态，或使用 Shift 键选择某个范围内的图层。然后使用 添加图层将所选图层添加到地图上。
