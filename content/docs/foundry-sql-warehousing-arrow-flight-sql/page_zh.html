Arrow Flight SQL

测试版

Arrow Flight SQL 支持目前处于 测试版 开发阶段，可能不适用于您的注册。在积极开发期间，功能可能会发生变化。请联系 Palantir 支持团队以请求启用 Arrow Flight SQL。

Arrow Flight SQL ↗ 是一种用于与 SQL 服务器交互的协议。Arrow Flight SQL 使用 Apache Arrow 内存格式和 Flight RPC 协议，以实现高效且可移植的数据传输。

Foundry 实现了 Arrow Flight SQL 协议，这意味着任何 Flight SQL 客户端都可以连接到 Foundry，从而无需自定义配置即可实现众多第三方连接。

JDBC 驱动程序

Arrow Flight SQL 提供了一款 JDBC 驱动程序 ↗ ，可与任何基于 JDBC 的客户端应用程序配合使用，例如 DBeaver ↗、 DataGrip ↗或其他应用程序。请按照以下说明在 Foundry 中设置和使用 JDBC 驱动程序。

时间戳显示

从 19.0.0 版本开始，当客户端应用程序的本地时区不是 UTC 时，Flight SQL JDBC 驱动程序可能会显示不正确的时间戳值。根据应用程序读取时间戳的方式，时区偏移可能会在错误的方向上被应用。显示的时间误差可能达到本地 UTC 偏移量的两倍——例如，位于 UTC+1 时区的客户端显示的时间戳可能比正确值早两个小时。如果您的客户端应用程序支持配置时区，我们建议将其设置为 UTC。

第 1 部分：安装 JDBC 驱动程序

下载 JDBC 驱动程序（.jar 文件）↗。下载完成后，请将文件放置到客户端应用程序文档中为配置 JDBC 连接指定的适当位置。

第 2 部分：配置 JDBC 连接

JDBC 连接字符串的格式为：

jdbc:arrow-flight-sql://<FOUNDRY_HOSTNAME>:443
  • FOUNDRY_HOSTNAME 是您的 Foundry 环境的主机名（例如 subdomain.palantirfoundry.com）。

如果 JDBC 客户端要求显式指定驱动程序类，请指定 org.apache.arrow.driver.jdbc.ArrowFlightJdbcDriver。

使用令牌进行身份验证

使用从 Foundry 的 设置 页面生成的安全令牌进行身份验证。请参阅 用户生成的令牌 文档，其中包含如何获取令牌的说明。

如果客户端应用程序提供用户名和密码字段，请将用户名设置为 token 并将密码设置为您的用户生成令牌。这是提供令牌的推荐方式。

如果客户端应用程序不提供单独的凭据字段，请改为将令牌直接包含在连接字符串中：

jdbc:arrow-flight-sql://<FOUNDRY_HOSTNAME>:443/?token=<TOKEN>

使用 OAuth 2.0 客户端凭据进行身份验证

对于服务间连接，您可以使用 OAuth 2.0 客户端凭据流程通过已注册的第三方应用程序进行身份验证，而不是使用用户生成的令牌。第三方应用程序必须注册为 机密客户端 已配置客户端密钥。不支持公共客户端。

在 JDBC 驱动程序上设置以下连接属性：

属性值
oauth.flowclient_credentials
oauth.tokenUrihttps://<FOUNDRY_HOSTNAME>/multipass/api/oauth2/token
oauth.clientId您注册的第三方应用程序的客户端 ID。
oauth.clientSecret您注册的第三方应用程序的客户端密钥。
oauth.scopefoundry-sql-server:query

客户端应用程序必须被授予对其所查询资源执行相关 SQL 操作的权限。请参阅 SQL 权限 了解详情。

有关驱动程序支持的完整 OAuth 选项集，请参阅 Flight SQL JDBC 驱动程序 OAuth 文档 ↗。

角色和权限

通过 Arrow Flight SQL 访问 SQL 查询受 SQL 权限管控。参见 SQL 权限 以了解更多详情。
