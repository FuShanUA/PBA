选择

Map 应用提供了多种用于选择对象和注释的方法。

选择地图上的项

  • 选择项： 单击某个对象或注释即可将其选中。如果光标下有多个项，则所有项都将被选中。
  • 向现有选择中添加项： 在单击的同时按住 Ctrl（Windows）或 Cmd（macOS），可将光标下的项添加到所选内容中。
  • 选择矩形区域中的所有项： 在单击并拖动光标的同时按住 Shift，即可选择矩形区域中的所有项。
  • 清除选择： 单击地图上的空白区域。

更多选择选项可在 “选择” 工具栏菜单中找到。这些选项包括：

  • 全选： 选择地图上的所有项。
    • 也可通过 Ctrl+A（Windows）或 Cmd+A（macOS）键盘快捷键使用。
  • 全选“类型”： 选择与当前所选对象的对象类型相匹配的所有项。
    • 仅当现有选择中包含单一类型的对象时才可用。
  • 反转选择： 将所选内容切换为当前未选中的所有项。
    • 也可通过 Ctrl+I（Windows）或 Cmd+I（macOS）键盘快捷键使用。
  • 选择相交的对象： 选择与当前选中的所有项相交的所有对象。
    • 仅在已有选定内容时可用。
  • 选择与形状相交的对象...： 允许您绘制一个形状并选择所有与其相交的对象。
    • 仅在没有任何选定内容时可用。

这些功能在右键菜单中同样可用。

您可以通过 选择图层中的对象 菜单项（位于 图层操作 菜单中）来选择指定图层中的所有对象。

使用直方图选择项目

点击 直方图 面板中的一行，即可选择所有匹配的对象。选择第二行时按住 Shift 键，可选中一定范围的行。按住 Ctrl（Windows）或 Cmd（macOS）键可将该行添加到现有选定内容中。更多详情请参阅 直方图和筛选文档。

在地图上锁定对象

要锁定图层中的对象，请选择 … 选项，该选项位于 图层 面板的“对象”部分下方：

这将锁定图层中的对象，使其在地图上无法被选中。这些对象仍然可以从左侧的 图层、 查找和 直方图 面板，但您无法在地图上使用光标、选择快捷键或相交形状与它们进行交互。您仍然可以通过 … 菜单按钮来编辑图层的样式。

要解锁图层中的对象，请在 图层 面板中选择图层旁的锁定图标，或通过 … 下拉菜单访问。

选择面板

如果选择了多个对象， 选择 面板将列出这些对象。在此列表中，您可以单击单个对象，从而将选择范围缩小到该对象。选中单个对象后， 选择 面板（位于右侧）将显示该对象的详细信息。

如果对象具有操作，可以通过单击 图标来访问这些操作。其他操作（例如将地图居中于该对象、从地图中删除该对象以及在其他应用程序中打开该对象）可在 ... 菜单中使用。

该面板有四个选项卡。

  • 其中， 属性 选项卡将显示该对象的属性。
    • 您可以通过右键单击并选择 固定属性 来固定属性，这会使相应属性显示在顶部，并允许您隐藏其他属性。
    • 如果存在任何 函数 可用，这些内容可以通过选择 （位于右下角）来添加。选择某个函数会将该函数返回的值添加到属性列表中。
  • “ 序列 ”标签页将显示与该对象关联的所有序列。
  • “ 事件 ”标签页将显示当前选定的时间窗口内与该对象关联的所有事件。
  • “ 对象视图 ”标签页将显示已配置的对象视图 （在 Ontology Manager 的 “对象视图” 标签页中）。

您可以在 Ontology Manager 的 “功能” 标签页中更改对象的默认标签页。

从地图中移除项目

要从地图中移除选定的对象和注释，请执行以下操作之一：

  • 点击 “删除” （在工具栏中）
  • 选择右键菜单中的 “删除所选内容” 条目
  • 按下键盘上的删除键。

将显示一个提示框，确认已删除项目的数量，并提供 “撤销” 选项以撤销此操作。

要移除单个图层中的所有对象，请使用 “删除图层” 项（位于 “图层操作” 菜单中）。
