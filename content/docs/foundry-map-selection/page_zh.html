Map 应用程序提供了多种选择对象和注释的方法。

在地图上选择项目

  • 选择项目： 点击某个对象或注释即可将其选中。如果光标下有多个项目，则所有项目都会被选中。
  • 将项目添加到现有选择中： 按住 Ctrl（Windows）或 Cmd（macOS）并点击，可将光标下的项目添加到选择中。
  • 选择矩形区域内的所有项目： 按住 Shift 并点击拖动光标，可选择矩形区域内的所有项目。
  • 清除选择： 点击地图上的空白区域。

更多选择选项可在 选择 工具栏菜单中找到。这些选项包括：

  • 选中当前图中的所有节点。 选择地图上的所有项目。
    • 也可通过 Ctrl+A（Windows）或 Cmd+A（macOS）键盘快捷键使用。
  • 选择所有“类型”的项目： 选择与当前所选对象的对象类型匹配的所有项目。
    • 仅当现有选择中包含单一类型的对象时可用。
  • 反选： 将选择切换为当前未选中的所有项目。
    • 也可通过 Ctrl+I（Windows）或 Cmd+I（macOS）键盘快捷键使用。
  • 选择相交的对象： 选择与当前所有选中项目相交的所有对象。
    • 仅当存在现有选择时可用。
  • 选择与形状相交的项目...： 允许您绘制一个形状，并选择与其相交的所有对象。
    • 仅当不存在现有选择时可用。

这些功能也可在右键菜单中使用。

使用直方图选择项目

点击 直方图 面板中的某一行即可选择所有匹配的对象。按住 Shift 并选择第二行可选择一个行范围。按住 Ctrl（Windows）或 Cmd（macOS）可将该行添加到现有选择中。您可以在 直方图和筛选文档.

锁定地图上的对象

通过选择 … 选项来锁定图层中的对象，该选项位于 图层 面板的“对象”部分下：

这将锁定某个图层的对象，使其无法在地图上被选中。这些对象仍然可以从左侧的 图层, 选择日 直方图 面板中选择，但您无法在地图上通过光标、选择快捷键或相交形状与其交互。您仍然可以通过 … 菜单按钮编辑图层的样式。

要解锁图层中的对象，请在 图层 面板中选择图层旁边的锁定图标，或通过 … 这将打开一个对话框，您可以在其中为实体应用和编辑标签。

选择面板

如果选中了多个对象， 点击 面板将列出这些对象。在此列表中，您可以点击单个对象以将选择缩小到该对象。选中单个对象后， 点击 右侧的面板将显示该对象的详细信息。

如果该对象具有操作，可以通过点击 图标来访问。其他操作（例如将地图居中于该对象、从地图中删除该对象以及在其他应用程序中打开该对象）可从 ... 菜单中选择复选框来自定义可用的工具。

该面板有四个选项卡。

  • 直方图 属性 选项卡将显示对象的属性。
    • 您可以通过右键点击并选择 固定属性 来固定属性，这将使该属性显示在顶部，并允许您隐藏其他属性。
    • 如果有任何 函数 可用，可以通过在右下角选择 来添加。选择函数会将该函数返回的值添加到属性列表中。
  • 直方图 序列 选项卡将显示与该对象关联的所有序列。
  • 直方图 事件 选项卡将显示当前选定时间窗口内与该对象关联的所有事件。
  • 直方图 对象视图 选项卡将显示配置的对象视图 在本体论管理器的 对象视图 标签页.

您可以在本体论管理器中更改对象的默认选项卡 功能 标签页。

从地图中移除项目

要从地图中移除选定的对象和注释，请执行以下操作之一：

  • 点击设置菜单下的 删除 在工具栏中
  • 选择 删除所选内容 右键菜单中的条目
  • 按键盘上的删除键。

将出现一个提示框，确认已删除的项目数量，并提供 撤销 撤销此操作的选项。
