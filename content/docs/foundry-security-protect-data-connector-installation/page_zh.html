保护您的本地数据连接器

Palantir Foundry 旨在为从云端到边缘的几乎任何环境提供安全的协作。如果您在 Palantir 托管的 SaaS 平台之外运行 Foundry 数据连接器代理，例如在您自己的数据中心或您自己的云中，请遵循本页面上的指导来保护您的安装。

物理访问

如果您的 Foundry 数据连接器代理部署在裸机硬件上（例如在数据中心中），实施强有力的物理安全控制至关重要。对运行 Foundry 数据连接器代理的服务器的访问权限应仅限于授权人员。

对 Foundry 服务器的任何访问都应有时间限制、记录在案，并遵循行业最佳实践。未经授权访问运行 Foundry 的硬件可能会使攻击者有机会实施各种攻击并破坏安全控制。

数据加密

Foundry 数据连接器代理在数据摄取过程中实现对象级加密。数据连接器从 Foundry 平台接收加密密钥材料，对对象进行加密，然后将其提交至 Foundry API 进行摄取和存储。

传输中的数据

在数据连接器与 Foundry API 之间传输的所有数据均使用强加密协议和密码算法进行加密。

网络安全

网络分段

将 Foundry 数据连接器安装与环境的其余部分进行分段和隔离非常重要。以下是实现此目标的最佳实践列表。

  • 使用防火墙或其他技术实现网络隔离。
  • 使用经批准的协议、端口和子网的允许列表来控制对服务的访问。
  • 默认拒绝发往您的数据连接器安装的所有入站流量。
  • 仅将您的 Foundry 数据连接器安装暴露给尽可能小的网络集合。
  • 将您的 Foundry 数据连接器安装隔离在专用的私有网络（VLAN/子网）中。
  • 为 Foundry 数据连接器维护一份完善的网络需求清单，其中将涵盖贵组织将要从中摄取数据的所有源数据系统。具体内容将因您的需求而有很大差异。

出站控制

使用出站（出向）控制严格管控源自您的 Foundry 数据连接器安装的网络流量，这一点非常重要。

  • 维护一份允许列表，列出您的 Foundry 数据连接器安装可连接的目标 IP 或域名。
  • 拒绝您的 Foundry 数据连接器安装发起的所有其他网络访问。

网络安全控制措施

使用网络安全控制措施来保护您的 Palantir Foundry 数据连接器安装。

  • 使用入侵检测系统来识别异常活动。
  • 使用防火墙来识别并阻止网络利用或攻击企图。
  • 从您的网络中收集网络安全日志，以识别异常活动。

基础设施安全

服务器加固

使用行业标准配置指南（例如 CIS 或 NIST 控制措施）来加固用于您的 Foundry 数据连接器安装的服务器。

  • 仅使用受支持的现代操作系统。
  • 对用于 Foundry 安装的主机执行积极的漏洞管理和修补。
  • 严重安全漏洞应在 30 天或更短时间内完成修补。

主机安全

使用主机安全控制措施来保护您的 Foundry 数据连接器安装。

  • 从主机收集审计和安全日志，以识别异常活动。
  • 使用基于主机的安全控制措施（如入侵检测系统）来识别异常活动。
  • 使用数据丢失防护（DLP）技术来检测未经授权的数据传输。

特权访问

严格控制对 Foundry 数据连接器安装的特权访问非常重要。

  • 托管您 Foundry 数据连接器安装的后端基础设施应受到限制，仅可通过专用堡垒服务器或跳板机进行访问。
  • 对您的 Foundry 数据连接器安装的所有基础设施或云级别访问均应要求进行多因素身份验证。

应用程序补丁管理

Foundry 数据连接器支持自动更新至最新受支持版本，从而将运维人员的维护需求降至最低。
