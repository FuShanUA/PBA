Solution Designer

Solution Designer 是一款交互式工具，用于为基于 Palantir 平台构建的解决方案创建架构表示。它包括第一方和第三方集成点的表示、与平台资源的关联，以及对文档和最佳实践的按需访问。

Solution Designer 使您能够：

  • 从一系列行业和技术模式中汲取灵感。
  • 在直观的分步指导下，为您的项目创建解决方案架构。
  • 展示并比较各种架构方案，以就构建计划和策略达成共识。
  • 研究新产品和新功能，了解它们与平台其余部分的交互方式。
  • 借助 AI 驱动的分析和建议来审查和验证您的架构。
  • 利用 AI 生成实施计划，加快解决方案开发。

用例

使用 Solution Designer 处理各种用例，包括以下内容：

  • 平台探索：
    • 了解平台组件及其相互之间的交互方式。
    • 探索精选的行业和技术参考架构库，您可以将这些架构用于自己的特定用例。
    • 使用 AIP Architect 根据您的需求生成工作流计划，并获取 AI 引导的实施建议。
  • 解决方案架构开发：
    • 通过修改参考模式或导入现有资源，从头开始创建图表。
    • 为工作流或用例解决方案中的每个节点和关联添加注释或描述。
    • 基于您组织内已有的解决方案图进行构建。
    • 通过分层分组和嵌套结构来组织复杂的架构。
  • 架构审查与验证：
    • 使用 AIP Critic 通过交互式 AI 对话来审查您的图表。
    • 获取有关改进、替代方案和最佳实践的建议。
    • 验证您的架构是否符合 Palantir 平台的功能和模式。
    • 将实施计划导出为 PDF 文档，用于文档记录和知识共享。
  • 项目协作与知识传递：
    • 将架构讨论与特定的应用程序和代码关联起来。
    • 使用解决方案图来帮助新团队成员入职、记录正在进行或现有的工作、分享项目更新等。
    • 将图表导出为图像或 JSON，以便与利益相关者共享。
    • 加载 Data Lineage 图，以可视化现有的数据流并为其增添架构背景。
