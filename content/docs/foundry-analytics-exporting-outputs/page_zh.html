导出输出

Foundry 允许符合条件的用户导出分析输出，以便在平台外使用。

支持的导出包括 PDF 导出, 将可视化导出为图像日 导出为 CSV 或 XLSX.

PDF 导出

Notepad 支持将文档下载为 PDF，并可自定义内容，例如页面方向、页眉和页脚，以及各个嵌入内容（图表、表格等）的外观。

了解如何开始使用 Notepad。

数据导出

您可以在 Contour、Quiver 和 Code Workbook 中将分析结果导出为 CSV 和/或 XLSX。

Contour

有两种方法可以从 Contour 导出数据，两者的导出上限均为 100,000 行：

  • 添加一个 导出 看板到您的分析路径。

  • 或者，您可以在分析中选择相关看板并打开表格面板，然后选择所需的导出选项。

要从 Quiver 分析中导出数据，请选择 下载为 CSV （位于任何卡片的操作菜单中）。

代码仓库（Code Repositories）

要从 Code Workbook 导出数据，请选择 下载为 CSV （位于已保存为数据集的转换的操作菜单中）。默认导出上限为 100,000 行。未持久化的转换的结果无法下载为 CSV。 了解有关 Code Workbook 中已持久化和未持久化转换的更多信息。
