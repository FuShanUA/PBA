教程：使用 SuperRepo 进行开发

Beta

SuperRepo 目前处于 beta 开发阶段，可能无法在您的注册环境中使用。在积极开发过程中，功能可能会发生变化。

在将 SuperRepo 用于构建全栈应用时，它能发挥最大价值，因为 SuperRepo 支持以步调一致的方式编辑、预览和部署组件。

以下示例将逐步介绍如何导入现有 对象类型、定义新的关联类型、在新函数中引用它，以及将同一函数公开为 函数支撑的操作。换言之，该示例展示了如何交付一项横跨多个层面的功能。本教程以问题管理系统为背景；不过，相同的开发工作流程同样适用于各个领域中的各类全栈应用。

首先，我们来看一下 SuperRepo 仓库的结构。根目录始终包含一个 foundry.yml 文件，其中列出了项目的各个组件。例如，除其他设置外，它可能包含以下内容：

在接下来的章节中，您将修改 本体论 层（通过先导入再定义类型）、 TypeScript 函数 层（通过实现一个新函数）以及 应用 层（通过在前端展示结果）。

导入现有的对象类型

在 Palantir 平台中，全栈应用的领域模型是在本体论中定义的。在 SuperRepo 中，若要将现有的本体论类型导入到项目中，可以运行 foundry import ontology 命令，或者使用 Import 侧边栏（属于 Palantir extension for Visual Studio Code）。

随后，向导将引导您选择想要导入的类型。

最后，选择 Import to project 按钮即可将所选类型导入到 Foundry 项目中，并显示 foundry import ontology 命令，您需要运行该命令，以便将此导入固化到您的仓库中。

每当 ontology.mts 文件发生更改时，本地 Ontology SDK 包都会重新生成。您可以导航到 ontology:dev 部分来跟踪重建进度，该部分位于 foundry start (preview command) 在终端中的输出，可使用 Tab 和箭头键。

添加函数

SuperRepos 目前支持 TypeScript v2 函数。您可以定义一个函数，用于创建 relatedIssues 关联类型的实例，该类型定义在 展开“本体论” 部分。

为此，请创建一个名为 assignRelatedIssues.ts 的新文件，位于 functions/typescript-functions/src/functions。该文件包含的函数接受一个 Ontology SDK 客户端和两个 issue 作为参数，并将这两个 issue 关联起来。

import { Issue } from "@ontology/sdk";
import { Client, Osdk } from "@osdk/client";
import { createEditBatch, Edits } from "@osdk/functions";

type OntologyEdit = Edits.Link<Issue, "relatedIssues">;

function assignRelatedIssues(
  client: Client,
  issue: Osdk.Instance<Issue>,
  otherIssue: Osdk.Instance<Issue>,
): OntologyEdit[] {
  const batch = createEditBatch<OntologyEdit>(client);
  batch.link(issue, "relatedIssues", otherIssue);
  batch.link(otherIssue, "relatedIssues", issue);

  return batch.getEdits();
}

export const config = {
  apiName: "assignRelatedIssues",
};

export default assignRelatedIssues;

您可以立即预览此函数，方法是使用 适用于 Visual Studio Code 的 Palantir 扩展中的函数支持功能。

此 TypeScript v2 函数返回针对本体论的编辑；但是，这些编辑需要应用到本体论才能生效。只有操作才能修改本体论的内容，因此您需要将 assignRelatedIssues 公开为 函数支撑的操作 ，然后才能调用它来创建新的关联。

您可以在之前用于定义关联类型的同一个 ontology.mts 文件中创建一个新的函数支撑的操作，方法是调用 defineFunctionBackedAction 函数，如下所示：

export const assignRelatedIssuesAction = defineFunctionBackedAction({
  functionApiName: "assignRelatedIssues",
  apiName: "assign-related-issues-action",
});

这样，您就可以调用 assignRelatedIssues 操作，方法是在 React 应用中使用生成的 Ontology SDK。

通过前端公开操作

前面的章节演示了导入对象类型、创建关联类型以及定义 TypeScript v2 函数支持的操作。Foundry CLI 的预览流程确保这些内容全部通过本地生成的本体论 SDK 库公开。您可以在 本体论 SDK React 应用中使用此库。

在使用 @osdk/react 库 ↗时，只需几行代码即可访问这些新增项，如下所示。

总结

您更新了本体论，编写了一个函数，将其转换为函数支持的操作，通过本体论 SDK 公开了这些新增内容，并将其与前端集成——所有这些都无需离开代码仓库或您的 IDE。

在 SuperRepos 出现之前，实现此功能需要在四个应用程序之间来回切换、等待 CI 检查并多次重新发布本体论 SDK。SuperRepos 旨在消除这些开销。
