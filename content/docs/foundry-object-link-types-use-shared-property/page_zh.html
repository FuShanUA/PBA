在对象类型上使用共享属性

要将对象类型上的属性更新为共享属性，请完成以下步骤：

  1. 在 Ontology Manager 中导航到该对象类型。
  2. 在面板上选择要更新的属性，然后向下滚动到配置中的 共享属性 部分。
  1. 使用下拉菜单选择要使用的现有共享属性，或者通过 共享属性创建 对话框将该属性转换为新的共享属性。

该属性随后将显示为共享属性。要将共享属性的使用持久化到本体论中，请选择右上角的 保存 按钮。

  • 在对象上使用共享属性时，对象特定属性的属性 ID 和 API 名称将保持不变，以免破坏使用它们的现有下游工作流。
  • 在与共享属性关联期间，将禁用对从共享属性继承的属性元数据的直接编辑。您仍可以添加、删除或编辑类型类。加载该属性时，生成的类型类集合将是该属性及其关联共享属性中类型类的并集。
  • 如果您使用的共享属性具有与所选属性不同的 渲染提示 配置值，则使用共享属性将覆盖所选属性的配置值。请确保您的共享属性已针对您的使用场景配置了适当的渲染提示。

将共享属性从对象中分离

要将属性从共享属性中分离，请在 Ontology Manager 中对对象类型使用相同的属性面板，然后选择 分离。

这样做将移除属性与共享属性之间的关联。
