transforms.api.Output

class transforms.api.Output(alias=None, sever_permissions=False, description=None, checks=None)

转换输出的规范。

要将多个输出数据集指定为单个参数，请使用 transforms.api.OutputSet。

在 Pipeline中注册转换时，请确保每个 Output 别名在管道中是唯一的。注册多个 Transform 对象时，如果这些对象写入同一 Output 别名，则会引发 ValueError。请参阅 transforms.api.Pipeline.add_transforms。

  • 参数：

    • alias (str ↗ , 可选) – 数据集资源标识符（RID）或数据集的绝对 Compass 路径。如果未指定，则该参数未绑定。

    • sever_permissions (bool ↗ , 可选) –

      如果为 True，则会切断数据集权限与其输入权限之间的关联。如果参数未绑定，则忽略此选项。

      自版本 3.85.0 起已弃用：请改用 transforms.api.Input.stop_propagating 或 transforms.api.Input.stop_requiring。

    • description (str ↗ , 可选) – 输出描述。请注意，此功能尚未实现。

    • checks (List [Check ] , Check) – 一个或多个 Check 对象。

static instance(context, json_value)

使用来自 JobSpec 参数的原始 JSON 值和特定上下文创建参数实例。

返回值会被注入到转换计算函数中。

  • 参数：
    • context (ParamContext) – 一个上下文对象，其中包含创建实例时可能需要的属性。
    • json_value (any) – 从 JobSpec 参数反序列化得到的任意原始值。

历史

  • 在 1.53.0 版本中变更：现在是 FoundryOutputParam 的子类

属性 json_value

返回此参数要放入 JobSpec 的 JSON 值。

如果返回值为 None，则该参数被视为未绑定。如果任何转换的参数未绑定，则该转换被视为未绑定。对于未绑定的转换，JobSpec 不会被发布。

静态 lightweight_instance(_context, json_value)

从解析后的 JSON 值实例化一个输出类型。

output_results(instance, **kwargs)

生成一个从输出 RID 到 TransformsOutputResult的映射。结果会被合并到一个 TransformJobResult中。

  • 参数： instance – 一个由 instance()生成的类型的对象。

属性 schema

返回此类型参数的 JSON schema。必须返回一个有效的 JSON schema。
