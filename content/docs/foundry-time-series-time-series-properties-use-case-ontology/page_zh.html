使用 Ontology Manager 为对象添加时间序列属性

本指南参考了以下文档： 在时间序列对象类型上设置时间序列属性。您可以根据需要向对象类型添加任意数量的时间序列属性，前提是每个对象始终会关联一个时间序列集。请查阅我们的文档，以了解应选择 时间序列对象类型还是传感器对象类型.

您必须对以下两种 Route 和 Airport 对象类型重复以下步骤。在本指南结束时， Carrier, Route、 和 Airport 对象类型将各自拥有三个时间序列属性，分别用于 Daily Count of Flights, Daily Average Arrival Delay 和 Daily Average Departure Delay.

  1. 在 Data Connection 中导航至 Carrier 在 Ontology Manager 中的对象类型，然后选择 功能 tab.
  2. 在 时间序列属性 部分中选择 + 添加.

  1. 选择现有的 Daily Count of Flights 属性作为时间序列属性，然后选择 设为默认时间序列属性 ，使其自动显示在 Quiver 中。

  1. 选择您创建的时间序列同步 在 Pipeline Builder 中。在我们的示例中，它被称为 [Example] Time Series Sync | Event Pipeline.

  1. 对以下 Daily Average Arrival Delay and Daily Average Departure Delay 时间序列属性重复此过程。

现在时间序列属性已添加到对象类型中，我们可以在运营场景中使用这些时间序列属性了。请继续阅读文档，了解如何 在 Workshop 和 Quiver 中使用对象的时间序列属性
