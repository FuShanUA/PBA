本体论构建

Palantir 本体论 是组织的运营层。本体论位于集成到 Palantir 平台的数字资产之上（数据集, 虚拟表日 模型），并将这些资产与现实世界中的对应事物连接起来，涵盖工厂、设备和产品等物理资产，以及客户订单或金融交易等概念。在许多场景中，本体论充当组织的数字孪生，包含语义元素（对象、属性、关联）和动态元素（操作、函数、动态安全），以支持各类用例。

对象和关联类型

定义组织语义的过程是将现有数据源映射为本体论中的 对象、属性和关联 。本体论远不止数据目录或模式设计解决方案，它允许您为最终用户工作流定义坚实的基础，包括所有字段的丰富元数据，并为所有变更提供细粒度的安全性和治理。

了解如何创建本体论的语义元素： 对象类型（object types） 和 关联类型（link types）.

操作类型和函数

组织的动态——在遵守组织控制和治理的同时实现变更——是通过本体论中的 操作类型（action types） 和 函数来定义的。操作类型使您能够从组织中的操作人员处获取数据，或编排连接到现有系统的决策流程，而函数则提供了一种编写和演进任意复杂度业务逻辑的方式。

了解如何创建本体论的动态元素： 操作类型（action types） 和 函数.

接口

An 接口 是一种本体论类型，用于描述对象类型的结构及其能力。接口提供对象类型多态性，允许对共享相同结构的对象类型进行一致的建模和交互。

了解更多关于 接口（interfaces）.

助力决策制定

投资本体论的目标是促进组织大规模地做出更好的决策。为此，本体论深度集成到 Palantir 面向用户的分析和运营工具中：用户可以创建可重用的对象视图，在 Object Explorer 中搜索感兴趣的对象，在 Quiver 中执行复杂分析，在 Workshop 中构建高质量的应用程序等。
