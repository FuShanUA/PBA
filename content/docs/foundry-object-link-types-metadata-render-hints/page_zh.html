渲染提示

Foundry 使用 渲染提示 将有关本体论 属性 使用情况的信息传达给 Object Storage v1 (Phonograph) 以及平台中的用户应用程序。例如， sortable 字符串属性上的渲染提示会告知应用程序允许用户按该属性进行排序，就像在时间轴或图表中那样。

许多渲染提示与对象类型的重新索引性能相关。例如，您可以使用渲染提示向 Object Storage v1 (Phonograph) 表明某个属性无需在应用程序中进行聚合或排序，这样 Object Storage v1 在为这些属性建立索引时的工作量就会减少。

您可以在属性编辑器的属性窗格中选择和取消选择渲染提示（见下图）。

下表列出了每种可用渲染提示的 名称 和 描述。 该表还提供了有关渲染提示两个技术方面的信息：“是否添加原始索引？”和“是否需要重新索引？”（在下文中说明）。

  • 是否添加原始索引？
    • 为了应用会添加原始索引的渲染提示，Object Storage v1 (Phonograph) 在存储支撑数据集时，会通过创建另一个索引来存储渲染提示信息。
    • 由于这个额外的索引，对于应用了渲染提示的属性，将有两列被计入索引到对象存储 v1（Phonograph）中的总列数。
    • 这解释了为什么取消选中这些渲染提示可以提高重新索引到对象存储 v1（Phonograph）的性能。
  • 需要重新索引？
    • 某些渲染提示在本体论管理器中保存选择后会立即在用户应用程序中生效。
    • 对于其他需要重新索引的渲染提示，必须先将该对象类型的支撑数据源重新索引到对象存储 V1（Phonograph）中，更改才会反映在用户应用程序中。
    • 您可以等待下一次触发的重新索引，也可以手动启动重新索引，方法是：导航到该对象类型的 数据源 选项卡，然后选择蓝色的 重新索引 按钮（位于 Phonograph 窗格中）。

禁用格式化- 启用 （前提是属性值不应在对象视图中根据浏览器所在位置的本地数字格式化标准进行格式化）。
标识符- 启用 以提高重新索引性能，并指定具有数字基本类型且无需进行格式化或被视为数字的主键和外键。
    - 例如，对象视图不会将属性值格式化为数字，并且对象资源管理器不支持按范围对键进行筛选。
关键词- 启用 以在对象视图中显示属性时，在单独的部分中突出显示此属性。
长文本- 启用 如果属性值包含大量文本。
    - 例如，对象视图将以更易读的格式显示此属性的值。
低基数- 启用 以向应用程序表明此属性的可能值并不多。
    - 例如，某些对象视图小组件仅允许对可能值不多的属性进行筛选。

可选择- 对字符串属性启用 以允许用户对此属性执行聚合。
    - 例如，此属性将在对象资源管理器直方图和对象视图图表中进行聚合。
- 对数值和日期属性启用 以允许用户对精确词条值执行聚合，而不仅限于分布。
- 禁用 以在该属性不会在应用程序中被聚合的情况下提高重新索引性能。
- 启用 以使用精确匹配筛选功能。

Sortable- 启用 字符串属性上的该选项，允许用户按此属性排序。
    - 数值和日期属性始终可排序。
    - 例如，Object Views 中的时间线和图表将按此属性排序。
- 禁用 该选项可在应用程序不会对此属性进行排序时提高重新索引性能。
- 不建议用于数组，其将基于数组中的最小值进行排序。
- Searchable 渲染提示 也必须 与 Sortable 一起选中。		是是
Searchable- 禁用 该选项可在应用程序不会对此属性进行搜索或排序时提高重新索引性能。
    - 如果属性包含长字符串，性能提升将尤为显著。
- Searchable 必须被选中 ，以便应用程序能够应用 Selectable、Sortable 或 Low cardinality 渲染提示。		是是
Enable leading wildcards- 启用 字符串属性上的该选项，以支持前导通配符查询。
