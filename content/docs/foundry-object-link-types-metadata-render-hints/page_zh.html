渲染提示

Foundry 使用 渲染提示 来传达有关本体论 属性 to 对象存储 v1（Phonograph） 以及平台中用户应用的使用信息。例如， sortable 字符串属性上的渲染提示会告知应用程序允许用户对该属性进行排序，例如在时间线或图表中。

许多渲染提示与对象类型的重新索引性能相关。例如，您可以使用渲染提示向 对象存储 v1（Phonograph） 表明某个属性不需要在应用程序中进行聚合或排序，这样 Object Storage v1 在索引这些属性时的工作量就会减少。

您可以在属性编辑器的属性面板中选择和取消选择渲染提示（见下图）。

下表列出了 名称 和 描述 每个可用渲染提示的。该表还提供了渲染提示两个技术方面的信息："添加原始索引？"和"需要重新索引？"（说明如下）。

  • 添加原始索引？
    • 为了应用添加原始索引的渲染提示，Object Storage v1（Phonograph）在存储支撑数据集时会通过创建另一个索引来存储渲染提示信息。
    • 由于这个额外的索引，对于应用了渲染提示的属性，在索引到 Object Storage v1（Phonograph）的总列数中会计算两列。
    • 这解释了为什么取消选择这些渲染提示可以提高重新索引到 Object Storage v1（Phonograph）的性能。
  • 需要重新索引？
    • 某些渲染提示在选择保存到 Ontology Manager 后，会立即在用户应用程序中生效。
    • 对于其他需要重新索引的渲染提示，必须先将对象类型的支撑数据源重新索引到 Objects Storage V1（Phonograph），更改才会反映在用户应用程序中。
    • 您可以等待下一次触发的重新索引，也可以通过导航到 数据源 对象类型的选项卡并选择蓝色的 重新索引 按钮，位于 Phonograph pane.
