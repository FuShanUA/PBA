Spark 分布式模型训练

在分布式训练中，模型的训练是在多个并行工作的计算资源上进行的。Foundry 支持 Spark 环境中的分布式模型训练。分布式训练使您能够：

  • 更快、更高效地训练模型： 分布式训练可并发利用多个节点来加速模型训练。
  • 扩展训练数据集的规模： 通过将训练任务和数据拆分到多个节点上，您可以基于远超单节点方法内存上限的数据集来训练模型。

目前，仅 PySpark XGBoost 估算器 可直接用于 Foundry 中的分布式模型训练。未来可能会支持更多分布式训练库。

请按照以下步骤，了解如何在 Foundry 中执行分布式模型训练。

1. 配置您的 Spark 环境

在使用分布式训练库之前，您必须先正确配置您的 Spark 环境，方法是使用 Spark 配置文件。

必需的 Spark 配置文件

要执行分布式模型训练，您必须在仓库中导入并应用 KUBERNETES_OPEN_PORTS_ALL 配置文件，如下面的示例代码所示：

2. 设置分布式训练库

设置 XGBoost Spark 估算器

XGBoost 提供了用于分布式训练的无缝 PySpark 集成，可通过 SparkXGBClassifier ↗ 或 SparkXGBRegressor ↗ 估计器。

以下是 SparkXGBClassifier 基本设置的示例：

from xgboost.spark import SparkXGBClassifier

@configure(profile=["KUBERNETES_OPEN_PORTS_ALL"])
@transform(...)
def compute(...):
    xgb = SparkXGBClassifier(
        features_col=<your_feature_col_name>,
        # other parameters as needed
    )
    model = xgb.fit(<your_training_dataframe>)

有关更多配置详细信息，请参阅 XGBoost Spark 文档 ↗。

为分布式模型训练设置 GPU 支持

要在分布式模型训练中利用 GPU，请按照以下步骤操作：

  1. 将您的项目添加到 资源队列 （具有 GPU 支持）。
  2. 启用 GPU 配置文件 ，方法是将 EXECUTOR_GPU_ENABLED Spark 配置文件添加到您的转换中。
  3. 将 device 参数设置为 'gpu' 或 'cuda'，具体取决于您的 GPU 设置。

3. 分布式超参数优化

您可以选择执行超参数优化。我们建议使用 Optuna ↗ 在 转换中进行超参数优化。

  • Optuna 可与 Spark 和分布式训练工作流很好地集成，无需额外设置。
  • 有关更多详细信息，请参阅 Optuna 文档 ↗。

4. 将 SparkXGBClassifier 或 SparkXGBRegressor 与模型适配器配合使用

内置的 XGBoostSerializer （来自 palantir_models.serializers ） 并不 直接支持 XGBoost 的 Spark 估计器（SparkXGBClassifier / SparkXGBRegressor）。 取而代之，您应该：

  1. 照常训练您的 Spark XGBoost 模型。
  2. 提取底层的 Booster 对象（通过 .get_booster()）。
  3. 将 Booster 用于您的模型适配器。

注意： 如果您需要以分布式方式运行推理，您仍然可以将您的 ModelAdapter 注册到 PySpark UDF 中。请参阅 PySpark UDF 以了解详情。

from palantir_models.serializers import XGBoostSerializer
import palantir_models as pm

class BoosterModelAdapter(pm.ModelAdapter):

    @pm.auto_serialize(model=XGBoostSerializer())
    def __init__(self, booster):
        self.booster = booster

    @classmethod
    def api(cls):
        <...>

    def predict(self, input_df):
        return self.booster.predict(input_df)

from transforms.api import configure, transform
from transforms.api.schema import Input, ModelOutput
from xgboost.spark import SparkXGBClassifier  # or SparkXGBRegressor
from your_project.adapters import BoosterModelAdapter

@configure(profile=[
    "DYNAMIC_ALLOCATION_DISABLED",
    "NUM_EXECUTORS_2",
    "KUBERNETES_OPEN_PORTS_ALL"
])
@transform(
    training_df=Input(path="..."),
    model_output=ModelOutput(path="...")
)
def compute(ctx, training_df, model_output):
    # 1. Train the SparkXGBClassifier
    xgb = SparkXGBClassifier(...)
    spark_model = xgb.fit(training_df)

    # 2. Extract the underlying Booster
    booster = spark_model.get_booster()

    # 3. Create your model adapter
    adapter = BoosterModelAdapter(booster)

    # 4. Publish the model to Foundry
    model_output.publish(adapter)

有关配置适配器的更多信息，请参阅 模型适配器概述。
