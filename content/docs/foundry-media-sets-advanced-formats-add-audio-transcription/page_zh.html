创建一个交互式音频转录应用程序

本指南将教你如何构建一个工作流来转录音频，并使用以下工具创建一个用于查看转录内容的交互式应用程序 媒体集.

第 1 部分：在 Foundry 中将音频文件导入为媒体集

首先，你应该将你的音频文件导入为 媒体集。有两种方法可以做到这一点：

  • 直接上传
  • 数据连接

导入完成后，你将能够查看你的音频媒体集。

第 2 部分：通过 Pipeline Builder 转录音频媒体集

  1. 在 Pipeline Builder 中创建一个新管道，并将你的音频媒体集添加到该管道中。详细步骤可以在 初始设置部分 的 Pipeline Builder 文档中找到。

    你导入的音频媒体集应该如下所示：



  2. 接下来，选择 转录音频 转换，使用 转换.



  3. 为该 转录音频 转换指定输入并选择 保存您的更改。.



    使用直方图中的 media_reference 列（来自媒体集输入），并选择所需的语言。如果未提供语言，将从音频的前 30 秒推断语言。有多个配置选项可用。在本示例中，我们希望在输出中包含说话人分离（diarization）详细信息，因此我们将选择 更高性能 模式、 分段详细信息 输出类型，并开启 说话人识别.

  4. 你可以在表格中预览转录的输出。



    如果你不想使用转录组件（widget），你可以根据需要继续对音频转录字符串输出进行转换。

    如果你想使用转录组件，请继续阅读下面的第 3 部分，以为该组件创建转录分段。

第 3 部分：将转录分段本体化以用于 Workshop 组件

在本节中，我们将从转录输出创建分段对象，其中包含在转录组件中显示所需的属性。

  1. 使用直方图中的 数组展开 转换，将分段结构体（struct）数组转换为单独的行。

  2. 然后，应用 提取多个 struct 字段 来提取该组件所需的字段。我们将选择以下字段： id, begin, end, contents日 speaker_id。由于我们已经知道说话人的姓名，我们将使用 映射值 将说话人 ID 转换为说话人姓名。

第 4 部分：在 Workshop 中显示转录内容

  1. In 来运行该专业代码代理。你还可以通过，添加 音频和转录显示 小部件。



  2. 使用在 第 3 部分 中创建的对象类型作为分段对象集来配置该组件。请参阅 音频和转录显示小部件 文档以获取配置选项的完整列表。

  3. 配置要在该组件中使用的操作。

    你可以在你的分段对象集上创建 操作类型（action types） ，并在该组件中展示它们。例如，你可能希望允许用户编辑分段内容或更正时间戳。

    在本示例中，我们将配置一个简单的操作，允许用户编辑某个分段的说话人属性。

  4. 定义操作类型后，在 Workshop 中配置该操作。选择 启用操作 ，并选择你在你的对象类型上创建的操作。你可以配置图标和名称。当鼠标悬停在某个分段上时，这些将显示在分段工具栏中。

    你还可以配置 参数默认值 ，以从悬停的分段填充默认值。我们将使用 选定的分段 作为该操作要编辑的对象的参数默认值。



    在这个示例工作流中，我们现在可以在组件中检查某个分段并更正其说话人属性。
