配置工作区

已弃用的功能

这些文档仅适用于您看到 Foundry 套件 部分出现在 Control Panel 中的情况。如果您看到的是 应用程序访问 ，请参阅 配置应用程序访问。

如果您希望缩小用户访问范围并帮助用户专注于所提供的工作流，可以在 Control Panel 中通过 Foundry 套件 部分，按组织或用户组自定义可用的应用程序。

平台访问

除非另行限制，所有用户都可以访问 Foundry 平台的大部分区域。未加入具有平台访问权限的用户组的用户，将只能访问明确向其授予访问权限的、在 Slate 或 Workshop 中构建的面向最终用户的应用程序。此外，这些受限用户将看不到 Foundry 导航侧边栏，也无法导航至 Foundry 的其他部分。

对于具有平台访问权限的用户，您可以进一步自定义他们能够使用哪些工作区。

工作区

一个 工作区 是以下内容之一：

  • 不带 Foundry 侧边栏的独立应用程序
  • 与 Foundry 侧边栏一同显示的一组相关应用程序

Foundry 套件

要获得对 Control Panel 中 Foundry 套件部分的访问权限，您需要 管理应用程序访问 工作流（此前称为 管理 Foundry Suite 工作区) 属于 用户体验管理员 角色。该角色在控制面板的 组织权限 选项卡中进行管理。

获得 Foundry Suite 设置的访问权限后，您将在控制面板侧边栏中看到相应选项。在 Foundry Suite 页面上，您可以限制平台访问权限，并了解为特定组织启用了哪些工作区。

限制平台访问权限

要限制哪些用户能够访问整个 Foundry 平台，请选择 选择用户组 ，然后搜索应有权访问该平台的用户组。不属于其中任何用户组的用户将只能使用面向客户的自定义应用程序，且不会看到 Foundry 应用程序导航侧边栏。页面下方 Foundry 应用程序访问 部分中的工作区和应用程序访问配置仅适用于拥有平台访问权限的用户。

配置工作区

禁用对 Workshop 和应用程序的访问

无法访问 Workshop 或应用程序的用户将无法在侧边栏中找到相应的应用程序和 Workshop。此外，如果用户尝试通过链接访问未经授权的应用程序或 Workshop，将会遇到 403 "Permission denied"（权限被拒绝）错误。

Workshop 中的某些应用程序默认处于启用状态，且无法在 Workshop 内关闭，因为它们被视为该 Workshop 的核心功能。
