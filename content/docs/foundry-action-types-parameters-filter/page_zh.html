筛选参数下拉菜单的结果

为非对象引用多选或单对象引用参数添加筛选器，将决定参数下拉菜单中可选择哪些允许的值。

多选参数下拉菜单

在配置多选参数下拉菜单时，操作编辑器可以将允许值缩减为仅为对象集的属性。可以利用这一点，根据关联对象的属性来显示或预填充值。要实现此目的，请确保参数设置为显示多个选项，选择从对象集获取选项，配置所需的对象集，并选择包含参数下拉菜单所有允许值的属性。如果生成的对象集中只有一个关联对象可用，且该参数为必填项，则参数下拉菜单将自动预填充相应的属性值。生成的多选选项将派生自用户有权查看的对象集。换言之，在从对象集派生多选选项时，用户将无法看到其无权访问的对象的属性。

对象下拉菜单

在参数配置视图中，操作编辑器可以指定筛选器和 Search Arounds，以限制在所有操作界面的下拉菜单中显示的对象。配置筛选器后，操作表单将呈现一个下拉菜单，其中仅包含与筛选器匹配的对象。所选值也会在执行操作之前进行验证。

下拉菜单选项中显示的属性

下拉菜单选项会显示每个对象的标题以及对象类型的突出属性。与搜索词匹配的属性会最先显示，并高亮显示匹配的文本，随后显示其余的突出属性。没有值的突出属性将显示为 No value。

显示哪些属性取决于在 Ontology Manager 中针对对象类型配置的可见性，而非操作类型。用户只能看到其有权查看的对象，且用户无法查看的属性值不会显示。

数据隐私影响

在对象参数上使用新验证时，能够查看该操作类型的任何人都可能查看到数据。如果参数筛选器中存在敏感的静态值，即使用户无法查看被筛选的底层对象，他们也能够查看这些值。详细了解数据隐私影响。

支持的操作

按属性筛选

对象下拉菜单仅显示指定属性与所提供的任意值相匹配的对象。

该值可以由用户静态定义、从另一个参数推断，或者是某个 Object Reference 参数的属性。如果提供了多个用于比较的值，结果将是 OR 运算。

更改起始对象集

查询的起始集默认设置为该对象类型的所有对象，但可将其更改为任何其他类型。起始集也可以设置为某个 ObjectReference 列表参数。

Search Arounds

Search Around 会通过遍历当前集中每个对象上的关联来创建一个新集。例如，Github Issue of Current Employee 会获取当前集中的 Employees，并创建一个结果集，其中包含与这些 Employees 相关联的 Github Issues。
