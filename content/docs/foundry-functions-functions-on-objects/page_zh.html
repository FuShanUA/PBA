对象函数 (FOO)

Foundry 中的函数原生支持访问和修改本体论中对象和关联的数据。在本体论中定义对象类型和关联类型后，您可以将这些类型导入函数仓库，以自动生成代码绑定。这些代码绑定包括对以下功能的支持：

  • 将对象和对象集类型传入函数，作为 参数
  • 按需搜索对象集，使用 对象集 API
  • 修改对象，使用 OntologyEditFunctions

由于对本体论的原生支持，Foundry 中的函数远超常用的函数即服务 (FaaS) 平台——它们为数据存储、检索和修改提供了原生支持，且所有操作均受 Foundry 在数据安全、数据血缘和透明度方面的保证约束。

了解如何开始使用对象函数。

“对象函数”（有时也称为 “FOO”）是一个较为宽泛的术语，泛指读取对象数据的函数——无论是将对象数据作为参数传入，还是通过对象搜索读取；但在 Foundry 中，并不存在将“对象函数”与其他函数正式区分开来的概念。
