PDF 查看器

PDF 查看器微件支持基本功能（例如带文本高亮的关键字搜索和匹配时自动滚动），以及更复杂的功能（例如显示、创建文本和区域注释并与它们交互的能力），从而支持用户标记工作流。

该功能提供了许多增强功能，包括但不限于以下内容：

  • 接受字符串变量以在整个文档中进行关键字匹配。
  • 内置搜索功能，用于匹配用户提供的关键字。
  • 匹配高亮（当前匹配为绿色；其他为紫色）以及命中计数显示。
  • 自动跳转到第一个结果以及其他命中项之间。
  • 支持 MediaReferences（媒体集）.
  • 显示现有的注释对象。
  • 通过配置的操作创建注释。
  • 可自定义的注释交互，包括选中事件、属性显示工具提示以及自定义颜色高亮。

配置选项

微件配置支持多种媒体输入源，以及页码和文本的变量输入。变量页码输入会将用户导航到 PDF 中的指定页面。配置的文本输入将填充到搜索栏中，并针对该词执行关键字搜索。即使不配置微件，您仍然可以在 PDF 视图中手动输入任何搜索词。要开始在 PDF 文档上配置注释，请选择 启用注释 选项，并参考 配置注释 区域的字段中添加命令。

  • 配置 PDF 来源选项：

    • 选择所需的媒体源以向微件填充 PDF。下拉列表将提供您可以使用的受支持的媒体源。当前支持的媒体源包括 Compass、数据集、媒体引用和附件。选择媒体源后，该媒体源的配置将变为可用。媒体源示例可能包括：
      • Compass： 使用 Palantir 文件系统作为 PDF 的媒体源。选择此选项时，请提供以下内容：
        • Blobster RID： 一个字符串变量，用于指定所需 PDF 的 Blobster RID。
      • 数据集： 使用数据集作为 PDF 的媒体源。选择此选项时，请提供以下内容：
        • 数据集 RID： 一个字符串变量，用于指定包含所需 PDF 的数据集的 RID。
        • 文件路径： 一个字符串变量，用于指定所需 PDF 在数据集内的文件路径。
        • 分支： 一个字符串变量，用于指定数据集的 branchID。如果未指定分支，则默认为 master branch.
      • 媒体引用： 定义一个包含单个对象的对象集，并选择 媒体引用 类型的属性作为 PDF。
        • 包含单个对象的对象集： 所需 PDF 的对象集变量。所选对象集必须包含单个对象。
        • 属性： 从所选对象集中为所需 PDF 选择所需的媒体引用类型属性。
      • 附件： 定义一个包含单个对象的对象集，并选择附件属性作为 PDF 的媒体源。选择此选项时，请提供以下内容：
        • 包含单个对象的对象集： 所需 PDF 的对象集变量。所选对象集必须包含单个对象。
        • 属性： 从所选对象集中为所需 PDF 选择所需的附件属性。

  • 配置输入变量：

    • 自定义页码： 切换以启用/禁用使用数值变量来捕获用户当前所在的页码，和/或更改微件当前显示的页面。
    • 自定义初始搜索： 切换以启用/禁用使用字符串变量来预填充在微件中用于搜索的关键字。

  • 配置注释：

    • 显示现有注释： 每个图层可以配置一个注释对象集。要启用注释，必须添加并配置至少一个图层。每个图层具有以下可配置字段：

      • 注释图层名称： 设置注释图层的名称。此名称字段仅在微件的配置面板中显示。

      • 导入对象集： 输入要在图层中显示的注释对象集。

      • 页面属性： 选择指定注释对象所在 PDF 页码的整数对象属性。

      • 边界框属性： 选择用于指定标注对象边界框坐标的字符串数组对象属性。数组中的每个字符串元素应为字符串化的 JSON 对象，表示边界框的左上角 (x1, y1) 和右下角 (x2, y2)。

        • 由于标注可能包含多个边界框，因此需要使用数组。例如，三行文本需要三个边界框，每行一个。有效的边界框属性可能类似于 [ "{"x1":0.0, "y1":2.5, "x2":50.0, "y2":10.1}", "{"x1":2.0, "y1":12, "x2":35.0, "y2":14.2}" ]。

      • 选定的标注： 选择一个对象集，既用作初始选定标注对象的输入，也用作包含文档上当前选定标注的输出。

      • 选中事件： 配置 Workshop 事件，以便在选中标注时触发。

      • 在工具提示中显示的属性： 添加在选中此图层中的标注时显示在工具提示弹出框中的属性。

      • 编辑或删除现有标注（通过操作）： 配置显示在标注对象工具提示弹出框中的标注图层操作。

        • 操作图标： 选择一个图标以在弹出框中表示此操作。如果未设置图标，默认将使用铅笔图标。
        • 操作标签： 设置操作的显示名称，该名称将在悬停弹出框中的操作图标和操作表单标题上显示。
        • 对标注执行的操作： 设置一个可从弹出框触发的操作。可使用 Hovered object 变量引用悬停的对象。有关操作的更多信息，请查阅我们的 操作类型文档.

      • 高亮颜色：

        • 静态： 设置用于显示此图层中所有标注的静态颜色。
        • 颜色属性： 设置一个字符串对象属性，用于指定此图层中标注的高亮颜色。该字符串属性的格式必须为颜色十六进制代码（例如 "#FBD065"）。如果该字符串属性不包含有效的十六进制代码，则高亮颜色将默认为 GOLD5 (#FBD065)。
        • 自定义规则： 指定条件格式规则，以决定此图层中标注的高亮颜色。如果没有满足任何已配置的条件格式规则，则标注的高亮颜色将默认为 GOLD5 (#FBD065)。

      • 在高亮中显示文本： 从标注对象中选择一个属性，将其值作为文本直接显示在文档中高亮的区域内。配置后，标注将在高亮区域内显示属性值，而不是仅显示一个彩色矩形。

    • 创建标注（通过操作或事件）： 配置在新建文本和/或区域选择时运行的操作或事件。
      • 操作或事件图标： 选择一个图标，在进行新选择时在操作弹出框中表示此操作。
      • 操作或事件标签： 此标签将在悬停操作弹出框中的操作时显示为工具提示。如果此操作未设置图标，则此标签将显示在操作弹出框中。
      • 用于选择类型： 指定此操作是否应在文本选择、区域选择或两者的操作弹出框中显示。
      • 操作或事件： 设置一个可从操作弹出框触发的操作或事件。
        • 配置操作参数时，可使用特殊参数值引用当前文本或区域选择中的数据：
          • 页码： 当前文本或区域选择所在文档的页码。此选项可用于整数参数。
          • 选择坐标： 表示当前文本或区域选择边界框的字符串数组。此选项可用于字符串数组参数。
          • 高亮文本： 文本选择所选内容的字符串内容。对于区域选择，该值将为空字符串。此选项可用于字符串参数。
    • 滚动到批注： 切换以启用/禁用自动滚动到批注对象集中的对象。这可启用自动滚动到您选择的批注。

  • 配置更多选项：

    • 输出用户选择的文本： 切换以启用/禁用将用户的文本选择捕获到字符串变量中作为微件的输出。
    • 输出用户选择的坐标： 切换以启用/禁用将用户的选择坐标捕获到字符串数组变量中作为微件的输出。
    • 输出用户选择的页码： 切换以启用/禁用将用户进行选择时所在的页码捕获到数值变量中作为微件的输出。
    • 启用 PDF 下载： 切换以启用/禁用用户下载微件中显示的 PDF 的能力。

配置批注图层后，导出包含批注的 PDF 只能通过 PDF 查看器微件中的内置下载功能完成。不支持从微件外部的单独自定义按钮触发包含批注的 PDF 导出。
