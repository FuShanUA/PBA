属性

A 属性 的 对象类型 是现实世界实体或事件某个特征的模式定义。 属性值 指对象上某个属性的值，即该现实世界实体或事件的单个实例。

例如，在 Ontology Manager 中，一个 Employee 对象类型可以具有属性 employee number, start date日 role。概念上的员工“Melissa Chang”的 employee number属性值可能为“11502”， start date为“October 9, 2016”， role.

类似地，在 Ontology Manager 中，一个 Flight 对象类型可以具有属性 departure date, arrival date日 passenger count。对象“JFK → SFO 24-02-2021”的 departure date属性值可能为“24-02-2021”， arrival date为“25-02-2021”， passenger count.

本体论中的概念与数据集结构中的概念类似。本体论中属性的定义类似于数据集中的列，而属性值的定义类似于数据集中的字段。例如，一个 Employee 数据集可以具有以下列： employee number, start date日 role。在这种情况下，员工“Melissa Chang”所在行的 employee number 列的单个字段值将为“11502”。

Foundry 本体论并非抽象的数据模型，而是将每个本体论概念映射到组织的实际数据，使这一数据资产能够为现实世界的应用提供支持。通过在 Ontology Manager 中添加支撑数据源或配置创建对象类型对象的操作，可以在用户应用中创建和显示属性值。要为属性创建属性值 employee number, start date日 role （在类型为 Employee的对象上），组织可以向该 Employee 对象类型添加支撑数据源，并将其员工目录和其他企业数据导入本体论。如果每个对象都将通过操作创建，则可以改为 创建不带支撑数据源的对象类型.
