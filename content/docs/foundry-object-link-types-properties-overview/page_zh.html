属性

一个 属性 属于某个 对象类型 ，是对现实世界实体或事件某一特征的模式定义。一个 属性值 指的是对象上某一属性的值，或该现实世界实体或事件的单个实例。

例如，在 Ontology Manager 中， Employee 对象类型可能具有属性 employee number、 start date和 role。虚构的员工 “Melissa Chang” 可能具有属性值 “11502”（ employee number）、“2016年10月9日”（ start date）和 “软件工程师”（ role）。

同样，在 Ontology Manager 中， Flight 对象类型可能具有属性 departure date、 arrival date和 passenger count。对象 “JFK → SFO 24-02-2021” 可能具有属性值 “24-02-2021”（ departure date）、“25-02-2021”（ arrival date）和 “150”（ passenger count）。

支撑本体论的概念在数据集的结构中有类似的概念。本体论中属性的定义类似于数据集中列的定义，而属性值的定义则类似于数据集中字段的定义。例如， Employee 数据集可能包含以下列： employee number、 start date和 role。在这种情况下，单个字段在员工 “Melissa Chang” 所在行的 employee number 列中的值为 “11502”。

Foundry 本体论并非一个抽象的数据模型，而是将每个本体概念映射到组织的实际数据，从而使这一数据资产能够为现实世界的应用程序提供支持。通过添加支撑数据源，或在 Ontology Manager 中配置用于创建某一对象类型的对象的操作，即可在用户应用程序中创建并显示属性值。要为属性 employee number、 start date和 role （位于类型为 Employee的对象上）创建属性值，组织可以向 Employee 对象类型添加支撑数据源，并将其员工目录和其他企业数据导入本体论中。如果每个对象都将通过操作创建，则可以改为 创建不带支撑数据源的对象类型。
