构建数据集

您可以使用 Data Lineage 图来查看管道中哪些数据集已过期，然后使用 Builds 辅助工具直接从 Data Lineage 启动构建。

从 Data Lineage 触发的构建始终应用于图中配置的分支（包括回退分支）。

以下是几种常见的构建工作流：

  • 构建所有上游数据集
  • 仅构建所选数据集之间的所有转换
  • 仅构建所选数据集

构建所有上游数据集

此策略会构建所选数据集及所有上游数据集，以确保所选数据集完全更新。

默认情况下，此策略仅构建已过期的上游数据集，但您可以选择强制重新构建最新的数据集。强制重新构建在构建时间和资源方面可能开销较大。

  1. 将数据集添加到图中，或打开已保存的快照。
  2. 选择您要构建的数据集。
  3. 在 Builds 辅助工具中，选择 所有上游数据集，然后点击 属性，然后选择.

更新板（可能影响所有下游板） 属性，然后选择 业务 不 触发任何构建。您只会看到待构建数据集的预览。要更改包含的数据集，请点击 取消 构建预览并更改您选择的节点；您无法在构建预览界面中更改所选内容。

  1. 如果您想强制重新构建最新的数据集，请点击 强制构建 最新数据集。
  2. 检查待构建数据集列表后，点击 运行构建 以触发构建。

仅构建所选数据集之间的所有转换

此策略允许您将构建绑定到管道的一个子集。当新的原始数据定期进入您的管道，而您希望更新某个特定数据集以反映新数据，但又不想构建 所有 过期的上游数据集时，通常会使用此策略。然后，您可以使用 Data Lineage 确定还需要构建哪些其他数据集，使您关注的数据集更加最新。

  1. 将您最终要构建的数据集添加到图中。
  2. 将任何原始数据集添加到图中（或任何上游数据集）
  3. 选择所有节点。
  4. 在 Builds 辅助工具中，选择 仅构建所选数据集之间的所有转换 策略，然后点击 属性，然后选择.

更新板（可能影响所有下游板） 属性，然后选择 业务 不 触发任何构建。您只会看到基于所选节点的待构建数据集预览。现在您可以确切地看到需要构建哪些内容来更新您关注的数据集。您可能不想构建 所有 数据集——也许有一个非常大的派生数据集每天只应构建一次——所以请点击 全部添加到图 在列表底部。

所选数据集

此策略允许您选择要构建的单个数据集。如果数据集之间存在依赖关系，构建将按正确的顺序执行，以确保下游数据集在其上游数据集构建完成后再构建。

检查待构建数据集的最终列表后，点击 运行 构建以触发构建。

如果您想更改正在构建的数据集，必须点击 取消 当前构建预览，更改您选择的节点，然后进入新的预览。您无法在构建预览界面中更改构建选择。
