设置数据源

Foundry 数据源表示 Foundry 与外部系统之间的连接。Foundry 数据源类型的一些示例包括 Postgres 数据库、S3 存储桶、Linux 服务器上的文件系统、SAP 实例或通过 Internet 的 REST API。

总体而言，以下是将数据源连接到 Foundry 所需的步骤。步骤 1 到步骤 3 可能需要您在现有架构中更改或验证配置：

  1. 确保存在有效的网络连接 （位于数据源与 Foundry 之间）。
  2. 提供有效的凭据 供 Foundry 向数据源进行身份验证。
  3. 对于旧版 ）或您的代理网络（如果使用 数据源：确保代理具有 适当的驱动程序 以访问外部系统。
  4. 最后， 在 Data Connection 中创建数据源.

建立此数据源连接后，您可以配置 同步 以将特定数据集引入 Foundry。同步可以完全通过 Data Connection UI 进行配置，因此在您可以在 Foundry 中访问数据之前，数据源设置是最后一项可能需要在您组织的环境中更新配置的任务。

配置网络访问

要将 Foundry 连接到外部系统，请先验证网络路径：

  • 与 Foundry 托管在同一网络中并接受来自 Foundry 的入站连接的外部系统，只需要一条从 Foundry 到外部系统的有效网络连接。对于云托管的 Foundry 实例，这通常是云系统或 SaaS 服务的情况。
  • 在与 Foundry 不同的独立网络中托管的外部系统必须使用 代理 并具备两条有效的网络路径：(1) 从代理主机到外部系统，以及 (2) 从代理主机到 Foundry。对于云托管的 Foundry 实例，独立网络通常指本地部署网络。

（可选）设置代理并配置代理连接

如果外部系统托管在与 Foundry 网络不同的独立网络中，您将需要 设置 agent 。

使用 Foundry worker 和代理代理策略，代理仅用作网络代理，计算在 Foundry 中运行。旧版 代理 worker 数据源 同时使用代理进行网络连接和计算；请参阅 Foundry worker 与 agent worker 对比.

确保在您的网络中设置的代理与外部系统之间存在连接。该代理充当从您的网络进入 Foundry 的单一验证入口，并将处理读取数据并将其发送到 Foundry 实例的过程。对于每个新系统，您只需确认代理与新系统之间存在有效连接。

您不需要建立从外部系统到 Foundry 的直接网络出口，因为流量仅在代理与 Foundry 之间以及代理与外部系统之间流动。 了解有关数据连接架构的更多信息。

建立此连接所需的步骤因您的组织网络设置而异。无论您的具体设置如何，目标都是让代理能够连接到外部系统。这可能涉及在代理主机上配置出口设置、在外部系统上配置入口设置、跨网络的防火墙规则、代理上的代理设置、将源系统 证书 添加到代理信任库等。

如果您需要为代理配置代理设置以访问外部系统，可以 通过 Data Connection 完成.

配置网络策略

您必须拥有 Information security officer 注册上拥有 注册（enrollment） 才能配置网络出口。如果您没有配置出口的权限，请联系您的 Palantir 管理员以请求访问权限。

您可以在 Information security officer 角色 选项卡 部分中找到 控制面板。用户必须具有 Enrollment administrator 角色才能查看此部分。

您必须正确配置出站策略（如果使用 源还需要网络出口策略来路由流量。

要配置网络策略，请导航至 选项卡,该选项卡位于 Control Panel 的 控制面板中的部分。选择 直接连接策略 （如果您要连接的外部系统与 Foundry 托管在同一网络中）或 代理出口策略 （如果您要连接的源位于与 Foundry 不同的网络中）。

如果您无法查看 选项卡,该选项卡位于 Control Panel 的 部分，请联系您的 Palantir 管理员设置网络策略。

配置凭证

在大多数情况下，Foundry 需要经授权的凭证（例如用户名和密码）才能访问外部系统。我们建议使用专用的服务账户，其凭证范围仅限于 Foundry 中所需的访问权限。

按照贵组织用于建立服务账户的任何内部指南和流程，为源配置服务账户。在继续下一步之前，请记下凭证。

配置源

添加有关如何连接到您的源的详细信息。这些信息取决于您所使用的 源类型 ，通常包括基本凭证，例如连接 URL、云提供商区域等。

（可选）添加 JDBC 驱动程序

JDBC 源可能需要您上传 JDBC 驱动程序，然后指定应使用驱动程序中的哪个 Java 类。

（可选）添加证书

外部系统可能需要证书以确保连接可信。以下情况需要证书：

  • 使用带有自签名证书的 TLS 的系统，您需要为其添加 服务器证书.
  • 使用 mTLS 的系统，要求 Foundry 客户端通过 客户端证书.

证明其身份。要了解应添加服务器证书还是客户端证书，请参阅 服务器和客户端证书.

对于 Foundry worker 连接，请使用以下步骤将证书添加到源本身：

  1. 将 证书 卡片以查看源上选定的证书。
  2. 选择 添加证书 (or 创建新证书 （如果您尚未配置证书，请先执行此操作）。
  3. 选择要附加到源的客户端证书和服务器证书捆绑包。

请查阅 出口证书配置文档 的文档以获取更多信息。

要配置使用旧版证书创建的源，请选择 配置服务器证书（旧版） or 配置客户端证书和私钥（旧版） 在 连接详情 页面,位于 更多选项.

添加凭据

添加您 先前预配的 凭据，以允许源连接到您的数据。

保存并继续

选择 保存 （位于右下角）以完成源的设置。源完全设置好后，您可以继续 设置同步 以将数据导入 Foundry。

故障排除

要确认连接已建立，请选择 预览 （位于源页面右侧面板中）。

如果源未按预期工作，请参阅 故障排除 以了解可用的调试工具——包括 源终端 和 网络出口日志 ——以及有关连接和证书问题的指导。有关同步特定问题，请参阅 同步故障排除参考；如果您使用的是代理工作器，请参阅 代理故障排除参考.
