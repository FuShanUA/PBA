聊天机器人即函数

AIP聊天机器人可以发布为 函数，从而可以在平台上任何能够执行函数的地方使用它们。例如，构建者可以将AIP聊天机器人发布为函数，以便在 AIP Evals中对它们进行评估、通过 Automate自动化聊天机器人工作流，或将聊天机器人用于 代码仓库。您可以配置函数版本，使其在每次发布聊天机器人时发布，或在每次保存聊天机器人时发布。

函数输入

以下是以函数形式发布的聊天机器人所接受的输入：

  • userInput: 聊天机器人将对其做出响应的用户输入字符串。

  • sessionRid （可选）： 当前会话的字符串标识符，格式如下：

    ri.aip-agents..session.{uuid}
    • 要与聊天机器人开始新会话，请将 sessionRid 输入留空。请勿提供空字符串；请完全省略此输入。
    • 提供值以使用该会话的 RID 继续现有会话。
    • 所有函数执行均会返回此 RID。

  • 所有用于 应用程序状态 的应用程序变量都会作为可选输入添加。这些变量可用于覆盖默认的应用程序状态值。

    • 对于对象集变量，默认值为对象类型的基础对象集，这意味着默认情况下将包含该对象类型中的所有对象。
    • 对于字符串变量，默认值会在 Chatbot Studio 中显示和配置。

函数输出

以下是发布为函数的聊天机器人的输出：

  • markdownResponse: 聊天机器人生成的最终文本响应，使用 Markdown 格式化。

  • sessionRid: 当前会话的字符串标识符，格式如下：

    ri.aip-agents..session.{uuid}
    • 所有函数执行均会返回此 RID。
    • 将此值提供给下一次函数执行,以继续会话。

  • 所有用于 应用程序状态 的应用程序变量都将添加为可选输出。

    • 仅当值已更新时,才会为这些变量输出值。未更新的变量将为空。

将聊天机器人发布为函数

  1. 要在 Chatbot Studio 中将聊天机器人发布为函数,请选择以下项右侧的发布设置图标: 发布 右上角的按钮。这将打开 发布设置 对话框。



  2. 开启 从聊天机器人发布函数 选项,这将显示已发布函数的更多配置选项。



  3. 在扩展后的 发布设置 对话框中，选择一个本体论，并填写函数详细信息，例如函数名称、API 名称和描述。您也可以选择在保存聊天机器人时发布函数的次要版本，只需勾选 版本配置下方的复选框。



  4. 选择 发布聊天机器人和函数 （位于对话框底部）。

发布后，系统将显示一条 Toast 通知，告知您聊天机器人和函数均已发布，并提供一个链接，用于在本体论管理器中查看已发布的函数。如需查看该函数，您还可以打开 发布设置 并在以下位置选择它： 已发布的函数。

禁用聊天机器人函数发布

要禁用函数发布，请打开 发布设置 并开启或关闭 从聊天机器人发布函数 关闭。如果禁用此选项，在重新启用该选项之前，后续发布的聊天机器人版本将不会将您的聊天机器人注册为函数。您可以随时重新启用此选项。重新启用后，若要发布函数，请发布该聊天机器人。

使用 AIP Evals 评估聊天机器人

将聊天机器人发布为函数后，即可使用 AIP Evals 评估套件对其进行评估。要在 Chatbot Studio 中创建评估套件，请确保您的聊天机器人已发布为函数，然后打开 评估 标签页（位于左侧工具栏）。在此处，您可以选择 创建评估套件，系统将提示您为套件命名，并选择与聊天机器人相同的项目。

请注意，评估套件必须与聊天机器人位于同一项目中。创建后，若要在 AIP Evals 中打开评估套件，请选择所创建套件右侧的箭头图标。

在 AIP Evals 中设置测试用例时，请谨记以下几点：

  • 要与聊天机器人开始新会话，请确保 sessionRid 设置为 null。如果提供了会话 RID，聊天机器人将继续现有会话，而这在测试期间很可能并非预期行为。

  • 对象集变量必须设置为 null 或包含实际值。对象集变量不能为空。

有关评估套件的更多信息，请参阅 AIP Evals 文档。
