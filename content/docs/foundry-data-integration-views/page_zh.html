视图

A 要在标记和发布函数的过程中查看进度，请选择 的行为与 Foundry 数据集视图类似 数据集视图，但它不包含任何存储数据的文件。相反，它由其他数据集（称为支撑数据集）的并集在读取时构成。可以将视图视为“指向”其支撑数据集。

通过添加主键，视图还可以自动对数据进行去重。如果视图的任何支撑数据集有新数据，将自动触发构建，以确保去重后可以获得最新数据。视图的构建方式与常规数据集类似，但由于构建过程中不会实际读取或写入任何数据，因此几乎可以立即完成。

通常，您可以像使用常规数据集一样使用视图。但是，视图不能被指定为有效的转换 输出；相反，它们可以被指定为有效的转换 输入.

此外，视图只能与具有 schema 的数据集一起使用，因为视图是基于行进行操作的。

不应将在增量数据集上构建的视图用作下游转换的增量输入。当以增量方式读取视图时，去重仅在增量读取的事务范围内进行，而不是在整个视图范围内进行。

视图的一些主要用例包括以下内容：

  • 自动更新： 创建一个始终保持最新的并集数据集，而无需执行转换。
  • 文件夹组织： 在不同位置复制数据集，而不会产生额外的计算和存储成本。
  • 数据唯一性： 通过主键去重自动保证数据唯一性，无需转换。

创建视图

要创建新视图，请打开 文件 ，在左侧工作区导航面板中找到所需的项目或文件夹。然后，选择 New > View （位于右上角）以在当前项目或文件夹中创建新视图：

为视图选择名称和位置，然后继续进行配置。创建视图后，系统会在后台自动创建一个构建计划，每当支撑数据集更新时都会重新构建该视图。如果您想在创建或修改视图后立即读取它，则必须手动构建该视图。

选择支撑数据集

构建视图需要一个或多个支撑数据集。由于视图由其支撑数据集的并集构成，因此给定视图的每个支撑数据集必须具有相同的列名和类型集合，但列的顺序可以不同。初始配置完成后，可以通过导航到以下位置来修改视图的支撑数据集 Details > Dataset view settings.

如果您在支撑数据集中添加或删除列，视图可能会失败并出现 View:MismatchedNumberOfColumns 错误。要解决此问题，请导航到 Details > Dataset view settings 并启用 Schema 演变。这使视图能够自动适应其支撑数据集中的 schema 变更，而无需创建新视图。

添加主键

数据去重是视图的一项关键功能，您可以通过添加主键来启用该功能。配置主键后，视图将保证具有主键唯一性；视图中存在的每个主键仅出现在一行中。添加主键可确保在读取视图时，每个主键仅返回最新的数据。当视图的支撑数据集可能包含不需要的重复行时，这种自动去重功能尤其有用。

主键一旦设置，就无法修改，除非创建新视图。

要添加主键，请选择一个或多个列，这些列组合后将构成主键。所选列不得包含空值。

如果您在初始配置期间未添加主键，可以稍后通过导航到以下位置来添加 Details > Dataset view settings.

解决重复键

要添加主键，您还必须指定一个（或多个）列，用于解析重复的主键。对于具有相同主键的行，去重时会按照这些列的顺序保留值最高的行，并丢弃其余行。这可确保视图中出现的每个主键都是唯一的。

选择一个删除列

您还可以选择性地指定一个删除列，该列必须包含布尔值。去重后，如果某个主键最终保留的行在该删除列中的值为 true ，则该行将被排除在视图之外。

实际中的去重与删除

重复的主键会被解析 然后 删除列用于排除行。因此，只有某个主键的“最新”行中删除列的值才有意义。

去重和删除是在所有支撑数据集上执行的：

去重和删除通过以下组合方式实现：

  • 一个经过适当配置、自动创建的 投影 （位于视图上）。
  • 基于窗口函数的过滤逻辑，在每次读取时进行评估。

尽管过滤逻辑在每次读取时都会进行评估，但只要投影是最新的，且视图的支撑数据集自上次投影构建以来仅发生过 APPEND or UPDATE 事务，此逻辑的评估对运行时间和计算成本的影响可以忽略不计。

考虑到这种架构，我们建议仅在以下情况下创建配置了主键的视图。

  • 所有支撑数据集均通过 APPEND 或严格增量式更新 UPDATE transactions.
  • 部分支撑数据集通过 APPEND 或严格增量式更新 UPDATE 事务更新，部分通过 SNAPSHOT 事务更新，但通过 SNAPSHOT 事务更新的数据集构建频率较低。

如果对支撑数据集的更新需要完全重建投影，则会产生相当大的计算成本，因为读取方（Contour、转换作业等）在投影重建完成之前，必须在没有投影的情况下应用过滤逻辑。

使用视图

视图在 Foundry 中与常规 Foundry 数据集一样可见，并且可以在任何可使用常规数据集的地方使用。唯一的例外是视图不能作为有效的转换输出（但可以作为有效的转换输入）。视图的一个示例用例是高效地创建多个数据集的并集，并使用主键确保生成的视图具有数据唯一性。

使用视图移除标记

您的 Foundry 注册中可能未启用“使用视图移除标记”功能。请联系 Palantir 支持以启用此功能。

您可以使用视图来停止在支撑视图的数据集上传播标记。视图仅支持移除 强制性管控标记 ；您不能使用视图移除 组织 。要停止传播标记，请导航至 数据集视图设置 菜单中选择 详情 选项卡，然后选择 Edit > Manage marking propagation.

只有拥有 Remove Marking 权限的用户才能停止标记的传播。对标记传播的更改将在支撑数据集发生任何更新时生效。

请查阅我们的 有关移除标记的指南 的文档以获取更多信息。
