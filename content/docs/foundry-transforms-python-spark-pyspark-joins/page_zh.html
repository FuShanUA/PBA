连接

一个 DataFrame 在 PySpark 中可以像 SQL 中的表那样连接到另一个 dataframe 或连接到自身。Dataframe 与其他 dataframe 之间的连接使用的是 .join() 方法。它接受一个 DataFrame、一个连接约束（例如要连接的列名）以及一种连接方式（left、 right、 inner等）。

简单左连接

Copied!
1
df_joined = df_left.join(df_right, 'key', 'left')

df_joined 现在是 left 连接的结果，连接键为 df_left.key == df_right.key。PySpark 会自动删除 key 列的其中一个副本，因此 df_joined 只包含一个名为 key的列。

如果要连接的键在 df_left 和 df_right 中的名称不一致，建议在执行连接之前先对它们进行重命名。

名称冲突

请务必重命名或删除任何未显式用于连接的同名字段，因为连接完成后这些字段会发生冲突。 DataFrame 中的所有列都可以通过如下循环重命名，使其带有特定前缀：

Copied!
1
2
for column in df.columns:
	df = df.withColumnRenamed(column, 'some_prefix_' + column)

基于多个字段进行连接

该 .join() 方法可以接受一个用于连接的字段列表，而不是单个字段。

Copied!
1
df_joined = df_left.join(df_right, ['column1', 'column2', 'column3'], 'left')

df_joined 现在是基于 column1、 column2 和 column3的连接。同样，这里假设列名在 df_left 和 df_right之间保持一致。

高级任意连接约束

PySpark 支持使用由逻辑运算符组成的任意表达式进行连接。假设我们想要基于以下条件进行连接：某一列 ID、某个日期 start （位于我们左侧的 DataFrame 中）早于某个日期 end （位于我们右侧的 DataFrame中），并且根据某个字段 X的内容，可能要求也可能不要求 Y （位于我们右侧的 DataFrame 中）包含另一个值。

Copied!
1
2
3

key_constraint = df_left.ID == df_right.ID
date_constraint = df_left.start < df_right.end
case_constraint = F.when(df_left.X == 'some_value', df_right.Y == 'some_other_value')\
	.otherwise(True)
combined_constraints = key_constraint & date_constraint & case_constraint
df_joined = df_left.join(df_right, combined_constraints, 'left')

交叉连接（笛卡尔积）

使用交叉连接可以生成两个数据框的行之间的所有组合（也称为笛卡尔积），而无需根据键或其他约束进行任何匹配。由于交叉连接存在引发内存和性能问题的风险，应尽可能避免使用。

警告

如果您打算立即对结果进行筛选，请不要使用交叉连接。相反，请将筛选条件嵌入到连接约束中，以获得更高效的解决方案（参见上文中的 高级任意连接约束 ）。

您必须在自己的代码仓库中显式 导入配置文件 CROSS_JOIN_ENABLED ，才能使用交叉连接。
