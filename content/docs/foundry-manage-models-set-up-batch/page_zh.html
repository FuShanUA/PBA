设置批量部署

A 批量部署 是一种在建模目标内部配置的特殊管道，允许数据通过模型运行并将结果输出到 Foundry 数据集。这些输出数据集可以在构建计划中进行管理。

前提条件

在创建新的批量部署之前，需要满足两个前提条件：

  1. 目标中必须存在一个带有相应 环境标记 为 staging 或 production 的现有发布。

  2. 选择一个用于在模型中运行的输入数据集。理想情况下，该数据集应得到精心维护并定期更新——它代表您要解决的问题的新信息。

创建部署

要创建新的批量部署，请导航至 部署 部分（位于建模目标主页底部），然后选择 + 创建部署 （位于右上角）。

在提示中填写详细信息和相关信息。根据要求 #1 选择您的部署环境，选择在要求 #2 中确定的输入数据集，并为输出数据集选择位置和名称。此外，除了创建新的输出数据集外，也可以选择现有数据集作为输出数据集。

在建模目标中直接设置批量部署仅兼容使用单个表格数据集输入的模型。如果您的模型适配器需要多个输入，您可以在 Python 转换中设置批量推理 在 Python 转换中 来替代。

资源配置

在创建新的批量部署时，您可以为该单个部署配置所需的资源。资源通过以下方式进行配置： Spark 配置文件，这些配置将在推理期间应用于 Spark 环境。

如果创建新的批量部署，在初始部署配置时会显示 Spark 配置文件选择器。其行为与 Python 转换相同。如果省略，则不会为该部署配置任何 Spark 配置文件，并将使用默认资源配置文件。

要编辑现有批量部署上已配置的 Spark 配置文件，请导航至 部署 建模目标中的部分，从列出的部署中选择您的部署，然后选择以下位置的编辑按钮： 运行时配置 以编辑 Spark 配置文件。这将自动更新部署。

自动构建部署输出

要导航到部署视图，请选择新的部署。

要导航到输出数据集，请在部署详情视图中选择该数据集链接。

您可以 创建计划 在批量部署的输出数据集上创建计划，以便每当有新模型发布到该部署环境时自动更新。这是通过创建新的逻辑计划来实现的，该计划会在数据集的逻辑更新时构建输出数据集。当目标中发布新模型时，输出数据集的逻辑将被更新，此计划将被触发。
