映射

直方图 映射 小组件以可配置、交互式的地理空间可视化形式显示对象集或对象数据。此小组件与 Map 应用程序共享许多核心功能。有关图层配置以及与复杂地理空间数据交互的更多详细信息，请参阅 Map 文档.

地图可视化由三种类型的图层组成：

  • 底图： 也称为 基础图层，此图层提供背景地图图像。
  • 对象图层： 在基础图层之上以点或形状的形式表示对象数据。
  • 叠加图层： 预配置的地理空间数据集视图，可在多个地图中重复使用。

Map 小组件使用 MapboxGL ↗ 进行渲染，并且需要 WebGL。它针对桌面浏览器进行了优化，不支持移动环境。对于移动或非 WebGL 环境，请使用 Map [Legacy] 小组件。请参阅 Map [Legacy] 与 Map 对比，以获取选择小组件的相关指导。

以下是一些具有各种图层配置的地图示例：

图层

用户可以使用两种不同的选项来配置地图对象图层：

  • 本地配置（推荐）： 在 Workshop 小组件编辑器中构建和修改地图的内容与样式

  • 导入地图模板： 选择一个现有的 地图模板 资源以在您的模块中使用，并将变量映射到相应的输入参数。

本地配置

在小组件编辑器中，选择 添加对象图层 以向地图添加新图层。然后，打开新创建的图层，并在以下位置创建新的对象集变量或复用现有变量： 该输入变量决定了微件中展示的对象数据。。添加后，新的对象图层将显示在地图上。

通过本地配置，可以在小组件编辑器中完全控制图层设置：

  • 输入
    • 添加一个新的标签页。创建后，选择包含该标签页的框以进行配置。 通过编辑此文本字段来重命名图层显示标题。
    • 选定对象： 指定一个对象集变量，表示 Map 小组件中某个图层内所选对象的集合。此变量是双向的，既可用于更新图层中选定的对象，也可以响应用户在地图上选择的对象集并采用该对象集。
    • 图层可见性： 控制图层内容在地图中可见还是隐藏。此设置可以配置为静态值或布尔变量。
    • 锁定图层： 切换图层是否锁定。锁定图层中的对象无法被用户选择。
  • 样式
    • 在 样式 部分中，用户可以为图层配置默认颜色、不透明度以及标签/工具提示设置。有关这些选项的更多信息，请参阅 图层样式 部分（来自 Map 应用程序文档）。
  • 几何
    • 编辑标签 几何 部分中，用户可以编辑地图上显示的特定几何图形的样式。与 Map 应用程序中一样， 几何图形 是表示图层对象的不同方式。
    • 可以通过选择 添加几何图形来添加几何图形。通过从标签左侧拖动几何图形来重新排序，将鼠标悬停在几何图形上并选择垃圾桶图标来删除。
    • 加载方法 [beta] 也可以在 几何 部分中为支持的几何图形类型进行配置。
    • 如果对象类型包含 Geoshape 属性，并且您在地图图层几何图形中对其进行配置，Map 小组件将自动加载并渲染它。由于 Geoshape 值可能很大，它们可能会影响加载性能。详情请参阅 不支持的对象属性类型.
  • 图例可见性
    • 对象图层及其几何图形默认在地图的图例面板中可见。在 图例可见性 部分中，您可以切换整个图层或单个几何图形的可见性。

除对象图层外，本地配置编辑器还允许用户添加叠加图层。这些叠加图层是在 地图图层编辑器.

基础图层选择器控制默认的背景地图影像。当 显示基础图层选择器 开关启用时，用户可以在地图（Map）组件界面中编辑基础地图。

导入地图模板

有关使用现有资源配置地图组件的信息，请参阅 如何在 Workshop 模块中嵌入地图模板.

交互

  • 绘制选项： 配置工具栏中可用的形状绘制工具。
  • 绘制形状颜色： 配置地图上绘制形状的颜色。
  • 绘制形状不透明度： 配置地图上绘制形状的不透明度。
  • 形状输出类型： 控制绘制形状变量和所选形状变量的 GeoJSON 字符串输出是以 GeoJSON 要素还是几何集合的形式表示。
  • 绘制的形状： 一个双向字符串变量，以 GeoJSON 字符串的形式反映在地图界面中绘制的形状。
  • 绘制形状时： 配置在地图中绘制形状时触发的 Workshop 事件。
  • 启用单次绘制模式： 限制用户在地图界面上一次只能绘制一个形状，绘制新形状时自动移除上一个形状。
  • 操作后清除形状： 控制在使用绘制形状的操作（选择相交对象、搜索对象或搜索轨迹）之后是否清除这些形状。
  • 启用反子午线拆分： 控制跨越反子午线绘制的形状是否将被拆分为单独的多边形。
  • 启用基于形状的选择： 启用一个工具，用于选择地图上与绘制形状相交的对象。



  • 启用地理空间对象搜索： 启用一个工具，用于在 Ontology 中搜索与绘制形状相交的对象。



  • 启用基于形状的轨迹工具： 启用相关工具，允许用户在 Ontology 中搜索与绘制形状相交的轨迹，并按该形状筛选地图面包屑。



  • 启用形状编辑工具： 启用一个用于修改绘制形状的工具。



  • 启用测量： 允许用户查看其绘制形状的测量值。单位基于 地图设置 （如果已配置），或 默认为组织设置.
    • 启用多边形周长： 显示绘制多边形每条边的长度或总周长。
    • 启用多边形面积： 在绘制的多边形中心显示该多边形的面积。
    • 启用线条测量： 显示绘制线条的单个线段长度或总长度
  • 选定的形状： 一个双向字符串变量，以 GeoJSON 字符串的形式反映在地图界面上选定的形状。

选定时间

  • 启用时间轴： 在地图界面底部显示时间轴打开按钮。
    • 允许用户更改选定时间： 允许用户在时间轴面板中控制选定时间光标。
      • 启用面向用户的实时模式开关： 启用 查看最新 时间轴面板中的选项。
    • 默认打开时间轴： 默认打开时间轴，而无需选择时间轴按钮。
  • 选定时间： 使用 Workshop 变量控制选定时间，类型为 Timestamp or Date.
  • 时间窗口： 使用两个 Workshop 变量控制时间窗口，类型为 Timestamp or Date.
  • 时区： 将时间轴面板使用的时区更改为 Local or UTC.
    • 时间格式： 以下内容的附加配置： Local 时区采用以下时间格式 12-hour, 24-hour，或 Local.
  • 播放状态： 使用布尔变量控制时间轴是播放还是暂停。
  • 播放位置： 将当前播放时间（以毫秒为单位）输出为数值变量。
  • 自动暂停于： 使用时间戳数组变量在特定时间自动暂停播放。

界面

  • 图例： 在地图界面中显示图例面板。
  • 折叠图例面板： 首次打开地图时默认折叠图例面板。
  • 面板大小： 选择图例面板是以完整尺寸显示还是以紧凑方式显示。
  • 启用周边搜索： 启用 周边搜索 （使用工具栏和上下文菜单）。
  • 启用高级选择工具： 在工具栏和上下文菜单中启用选择工具。
  • 显示选择面板： 在 Map widget 界面的面板中显示当前选定对象的列表或所选对象的详细信息。
  • 视口自动缩放： 控制 Map widget 的缩放行为。
    • 导入对象集： 将地图居中于给定对象集的内容。
    • 所有对象： 将地图居中于添加到 Map widget 的所有对象
    • 仅在目标对象完全位于当前视口之外时更新： 将自动缩放行为限制在目标对象完全位于当前视口之外的情况
  • 视口边界： 此设置是一个双向字符串变量，其 GeoJSON 值表示地图的当前查看窗口。
  • 视口跟随对象集： 提供一个对象集，当对象的位置随所选时间变化时，地图窗口将保持以其为中心。
  • 启用切换到完整 Map 应用： 允许用户从 widget 打开 Map 应用，并使用其当前状态。
