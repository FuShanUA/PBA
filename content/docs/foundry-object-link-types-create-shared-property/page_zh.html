创建共享属性

在 Ontology Manager 应用程序的共享属性页面中创建并配置新的共享属性。

要访问该页面，请按照以下步骤操作：

  1. 选择 共享属性（Shared properties） Ontology Manager 中的菜单选项。
  1. 进入共享属性页面后，选择 新建共享属性 （位于右上角）。
  1. 这将打开共享属性创建弹窗，您可以在其中配置名称、描述、类型和其他元数据来创建共享属性。

共享属性可以使用常规属性元数据的一个子集进行配置：

  • 名称： 共享属性的名称。
  • 描述： 关于共享属性的说明文字。例如， start date 共享属性的描述可以是 The day the employee or contractor began working.
  • 基本类型： 指示此属性的值类型，并确定用户应用程序中可用的操作集合。例如， start date 属性的基本类型为 date。用户应用程序将允许您使用此属性配置时间线小部件。基本类型与底层列类型相关，并且必须与列类型匹配才能应用于对象类型
  • 值格式化： 根据属性的基本类型，可以对属性应用数值格式化、日期和时间格式化、用户 ID 和资源 ID 格式化，将其原始值转换为用户应用程序中更易读的形式。了解更多关于 和.
  • 类型类： 由用户应用程序解释的附加元数据。了解更多关于 类型类.
  • 渲染提示： 向用户应用程序指示如何渲染该属性的提示，可能与相同基本类型的大多数属性不同。许多渲染提示可用于影响定义该属性的对象类型的重新索引性能。例如，如果您不希望任何用户在 start date 属性上进行搜索或排序，可以取消选择 searchable and sortable 渲染提示，从而提高 Employee 对象类型的重新索引性能。了解更多关于 渲染提示.
  • 可见性： 向用户应用程序指示该属性的显示突出程度。 prominent 属性将使应用程序优先向用户显示该属性。 hidden 属性将不会出现在用户应用程序中。默认情况下， start date 属性将具有 normal visibility.
  1. 要将共享属性保存到本体论中，请选择 保存 （位于 Ontology Manager 的右上角）。
