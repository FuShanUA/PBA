按键分组

支持环境：Streaming

按提供的键列对输入进行键控。请注意，这不会对数据重新排序，仅在设置键之后保持每个键内部的顺序。重新键控数据可能不安全，因为如果新键控的数据依赖于任何特定顺序，而之前的键控并未维护该顺序，则我们无法保证该顺序。此外，如果启用了 cdc（变更数据捕获）模式，还会设置主键。主键定义了指示哪些行是更新、删除以及在读取为当前视图时的顺序的列。

转换类别: Other

声明的参数

  • 数据集： 要对其进行 key by 操作的数据集。
    表格
  • 启用 cdc 模式： 如果为 false，则仅设置分区列，用于控制排序保证；所有键列值相同的行将按接收顺序输出。如果为 true，则会同时设置分区列和主键，这不仅会修改排序保证，还会设置如何对所有键列值相同的行进行去重的配置。
    Literal<Boolean>
  • Key by 列： 按键对输入进行分区的列。如果启用了变更数据捕获（通过指定主键参数），这些列还将用于定义更新。如果某一行的键值与前一行的键值完全匹配，则该行被视为更新。
    Set<Column<Binary | Boolean | Byte | Double | Float | Integer | Long | Short | String | Timestamp>>
  • 可选 主键 deleted 列： 需要启用 cdc 模式。在变更数据捕获中用于定义删除。如果某一行的 deleted 列值设置为 true，且其键列与要删除的行完全匹配，则该行被视为删除。
    Column<Boolean>
  • 可选 主键排序列： 需要启用 cdc 模式。对于流式数据，建议留空。在变更数据捕获中用于定义批处理和归档数据集的排序。只有当某一行位于其试图修改的行之后时，该行才可以是更新或删除。如果留空且处于流式 cdc 模式，则最近流式传输的行将始终优先。
    List<Column<Byte | Date | Decimal | Integer | Long | Short | String | Timestamp>>
