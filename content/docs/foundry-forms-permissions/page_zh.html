权限

在大多数情况下，权限应保持默认设置。自定义权限通常会给跟踪不同用户可用的平台操作带来挑战。

创建表单

默认情况下，所有用户都可以创建由电子表格支撑的表单或没有来源的表单。只有一部分用户可以创建由对象类型支撑的表单。

详情

要创建表单，您需要在表单所在的文件系统文件夹中创建资源的权限。

您还需要基于表单支撑数据的具体权限：

  • 对于由对象支撑的表单： fforms:form-definition:create-phonograph-form
  • 对于由电子表格支撑的表单： fforms:form-definition:create-fusion-form
  • 对于没有支撑来源而创建的表单： fforms:form-definition:create-no-origin-form

以下用户组默认拥有这些权限，可以在 Foundry Forms 后端配置中覆盖：

  • fforms:form-definition:create-phonograph-form 授予 "fforms-admins" 和 "Platform Administrators" 组。
  • fforms:form-definition:create-fusion-form 授予所有用户。
  • fforms:form-definition:create-no-origin-form 授予所有用户。

创建新条目

默认情况下，用户只需要 Viewer 对所填写表单的权限即可创建新条目。在 Visual Editor 的设置面板中关闭 Allow creation of new objects without read or write permissions 以限制表单，使只有对支撑对象类型或电子表格拥有权限的用户才能填写表单。

详情

用户可能因以下原因而无法创建新条目：

  • 表单可能没有已发布的可填写版本。
  • 如果表单中存在任何 附件字段 那么用户必须拥有向附件文件夹上传文件的权限。

组织管理员 fforms:form-definition:view 授予对表单拥有 compass:view 权限的用户。这可以在 Foundry Forms 后端配置中覆盖。

编辑现有条目

与创建新条目一样，您需要查看表单的权限。此外，您还需要编辑支撑来源的权限，无论它是对象类型还是电子表格。

详情

直方图 Allow creation of new objects without read or write permissions 选项不影响编辑现有条目。目前没有用于编辑条目的等效选项。但是，Foundry Forms 之前支持此功能，为了向后兼容，某些较旧的表单可能仍允许在没有来源权限的情况下编辑条目。

与创建新条目一样，仍必须存在已发布的版本，并且您需要向附件字段中引用的任何文件夹上传文件的权限。

保存对表单定义的更改

要编辑表单，您需要 Editor 对表单的权限。如果您想限制谁可以对用户看到的表单版本进行更改，可以通过限制 谁拥有发布表单的权限.

详情

要编辑表单的未发布版本，您需要 fforms:form-definition:edit 对表单的权限。要编辑表单的已发布版本，您还需要 发布该表单版本.

所需的所有权限。默认情况下 fforms:form-definition:edit 来自 compass:edit 对表单的权限。这可以在 Foundry Forms 后端配置中覆盖。

发布表单版本

要发布表单，您需要 Editor 对表单的权限。如果您想将发布表单的权限限制为仅对表单拥有管理权限的用户，可以在后端配置中移动 fforms:form-definition:manage 来自 compass:edit to compass:manage 在后端配置中进行扩展。

详情

要发布表单版本，您需要 fforms:form-definition:manage 对表单的权限。此外，您还需要：

  • 管理表单来源的权限
  • compass:manage 对附件字段中使用的任何文件夹的权限

组织管理员 fforms:form-definition:manage 来自 compass:edit 对表单的权限。这些选项可以在 Foundry Forms 后端配置中更改，但对附件文件夹的要求无法更改。

创建表单的新版本

要创建表单的新版本，您需要 Editor 对表单的权限。根据您的使用场景，您还需要属于可以创建对象支撑或电子表格支撑表单的组。

详情

要创建表单的新版本，您需要以下权限： 创建该来源类型的表单。您还需要 fforms:form-definition:create-new-version 和 管理表单来源的权限.

fforms:form-definition:create-new-version 来自 compass:edit 默认情况下即拥有该权限，但可以在后端配置中更改。

更改表单的响应目标

要更改表单的响应目标，您需要：

  • 以下权限： 创建该来源类型的表单
  • 以下权限： 管理表单的来源
  • 以下权限： 保存对表单定义的更改，但您不需要对附件字段中出现的任何文件夹拥有权限。

更改表单某个版本的名称

要更改表单某个版本的名称，您需要 Editor 对该表单的权限。如果该表单是已发布版本，则您需要管理它的权限，同时还需要 管理其来源.

详情

要管理已发布的表单，您需要 fforms:form-definition:manage 对其的权限，该权限默认来自 compass:edit 。这可以在后端配置中被覆盖。

删除表单

要删除表单，您需要 Editor 对该表单的权限。您还需要 fforms:form-definition:manage，该权限默认来自 compass:edit 。这可以在后端配置中更改。

取消发布表单

要取消发布表单的已发布版本，您需要 Editor 对该表单的权限。您还需要 fforms:form-definition:manage，该权限默认来自 compass:edit 。这可以在后端配置中更改。

管理表单的来源

多种不同的操作都需要此权限。根据表单的支撑类型，所需权限有所不同：

  • fforms:form-definition:create-phonograph-form：表单由对象类型支撑
  • fforms:form-origin:manage：表单由电子表格支撑

fforms:form-definition:create-phonograph-form 授予“平台管理员”组的成员。 fforms:form-origin:manage 授予具有 fusion:edit-document 对支撑电子表格权限的用户。这些可以在 Foundry Forms 后端配置中更改。
