管理安全

先前称为 Workflow Builder 的应用程序现在更名为 Workflow Lineage。

要开始使用 Workflow Lineage，请打开 Workshop 应用程序或函数仓库，并使用键盘快捷键 Command + I （macOS）或 Ctrl + I （Windows）以查看相关的 Workflow Lineage 图谱，其中描绘了为应用程序提供支撑的对象、操作和函数。

您也可以直接导航至 Workflow Lineage 应用程序，并手动将资源添加到图谱中。

Workflow Lineage 中的颜色图例允许您同时查看本体论权限和资源权限。本体论权限有两种类型：

  • 定义： 指定用户是否可以查看或编辑实体定义。
  • 数据和执行： 指定用户是否可以查看对象数据或执行操作。

要了解特定用户的访问权限，您可以将其用户名输入到 查看身份 下拉菜单中进行预览。

批量更新资源上的本体论角色

您也可以批量编辑 本体论角色权限 （针对对象和操作），请按照以下步骤操作：

  1. 导航到某个资源并右键单击它，然后选择 编辑权限 （位于上下文菜单中）。

这将带您进入 编辑本体论资源权限 窗口，其中显示所选资源。

  1. 在 要授予的本体论角色 部分中，搜索您要添加的组。选择角色后，您应该会看到该角色显示在所选组的旁边。

  1. 确认此操作，请选择 授予角色 （位于右下角）。此时将出现一个包含提示的对话框， Are you sure you want to share these resources?。

  2. 选择 是，共享 以继续。请注意，此操作会立即生效且无法撤销。

批量更新操作的提交条件

此外，您可以将操作的提交条件更新为与源操作的提交条件相匹配。在工作流血缘图中，选择您想要更新的操作。然后，导航至 更新提交条件 ，该选项位于底部面板。

在面板左侧，选择您希望将其提交条件应用于其他操作的源操作。在所选源操作下方可以查看该源操作的提交条件。

完成后，选择蓝色的 更新 x 个操作 按钮，其中 x 是将要更新的操作数量。这将创建一个提案，您可以批准并提交该提案以使更改生效。
