回归训练器

回归训练器会并行或按顺序训练多个模型，以帮助其确定性能最佳的模型。如果该训练器判定由多个模型组成的加权集成比任何单个模型表现更好，它还会利用集成学习。此训练器基于 AutoGluon 的 ↗ TabularPredictor 类构建。

回归训练器还可以执行堆叠（stacking）或装袋（bagging）来进一步提升性能。堆叠是一种集成过程，将在输入数据上训练的模型集所产生的预测用于训练另一“层”模型，并且此过程可以重复进行。装袋是一种内部优化方法，其中每种模型架构都会在数据的多个随机样本上进行训练，然后将输出组合成一个集成模型。堆叠和装袋由 训练预设 参数控制。

模型集成的结构可在输出模型的实验页面中的 图表下查看。

训练的模型

在内部，系统会训练多个模型，除非通过排除相应模型或使用 超参数将其禁用。

以下类型的模型可供训练：

  • GBM： LightGBM ↗ 梯度提升模型
  • CAT： CatBoost ↗ 模型
  • XGB： XGBoost ↗ 模型
  • RF： 随机森林 ↗ 模型
  • XT: 极端随机树 ↗ 模型
  • KNN: KNearestNeighbors ↗ 模型
  • LR: 线性 ↗ 模型
  • NN_TORCH: PyTorch ↗ 专为表格回归设计的模型
  • FASTAI: fast.ai ↗ 专为表格回归设计的模型

虽然其中一些模型严格来说是分类模型，但在使用堆叠（stacking）时，它们仍可应用于回归任务。

参数

  • 评估指标： 用于在训练期间对模型性能进行评分的指标。不同的数据集在不同的评估指标上可能表现更好。有关更多详细信息，请参阅平台内文档。对于衡量误差的回归评估指标（例如 MAE、MSE 或 RMSE），数值越低表示性能越好。然而，对于 R² 和皮尔逊相关系数等指标，数值越高表示模型性能越好。
  • 训练预设： 训练预设是对装袋（bagging）和堆叠（stacking）相关更复杂参数的更高层抽象。
    • best_quality：启用堆叠和装袋。当需要尽可能最佳的模型时，应使用此预设，即使以牺牲训练和推理速度为代价。
    • high_quality：启用堆叠和装袋。训练时间和推理时间应比 best_quality 预设更快，但模型精度可能略低。
    • good_quality: 启用 stacking 和 bagging。此预设的训练和推理速度快于之前的预设，且具有不错的预测准确性。
    • medium_quality: 禁用 stacking 和 bagging。此预设的训练时间最快，但预测准确性适中。应用于原型开发。
  • 训练和推理限制：
    • 训练时间限制： 可选择设置训练花费的最长时间。在使用启用 stacking 和 bagging 的预设时，系统会尽力遵守此时间限制。达到时间限制后，作业的训练部分将结束。请注意，在模型验证完成且模型发布之前，作业不会结束。
    • 推理时间限制： 可选择设置给定模型在推理期间可运行的最长时间。任何超过此时间限制的模型都将被跳过。除非需要严格的推理时间限制，否则我们不建议设置此值。
  • 排除的模型类型： 排除某些模型类型，使其在训练期间不被使用。
  • 预测列名称： 预测列名称的覆盖值。默认情况下，将使用目标列名称。

高级：Stacking 配置

可选的堆叠配置字段允许对模型集成的构建方式进行更深入的控制：

  • 拟合加权集成： 启用后，一个 WeightedEnsemble 模型将在每个堆叠层生成。我们建议启用此选项以提升模型性能。
  • 使用所有模型拟合最后一个集成： 启用后，最后一个堆叠层的 WeightedEnsemble 将使用之前所有层的模型作为基础模型进行拟合。当使用禁用堆叠的预设时，此值无效。我们建议启用此选项以提升模型性能。
  • 拟合完整加权集成： 启用后，一个二级 WeightedEnsemble 模型将构建在启用 使用所有模型拟合最后一个集成 时生成的加权集成之上。如果 使用所有模型拟合最后一个集成 被禁用，或使用了禁用堆叠的预设，则此选项无效。

高级：超参数

可选的超参数字段允许对每个训练的模型进行更深入的自定义和控制，但有一点需要注意。定义此字段时，未在超参数字段中提供的任何模型都将被忽略。此字段将覆盖 AutoGluon 所选的默认超参数，并可能产生较差的结果。因此，我们建议避免使用此字段，除非您已查阅 AutoGluon 文档 ↗。在大多数情况下，默认超参数就能提供足够好的结果。

输出

回归训练器将输出一个 Foundry 模型，其中包含由验证步骤确定的最佳模型。有关该模型的详细信息，可以通过 导航到实验来访问，该实验将包含参数、指标和图表，可帮助深入了解模型的性能。
