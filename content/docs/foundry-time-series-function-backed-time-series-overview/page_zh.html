函数支撑的时间序列

函数支撑的时间序列使您能够使用在 函数中定义的 Python 逻辑来生成和转换数值时间序列。Foundry 会将函数的输出视为时间序列，无需定义时间序列同步。

功能

  • 自定义分析： 编写生成数值时间序列的 Python 函数。使用任何库（例如 statsmodels 或 Prophet），或使用专有代码执行高级分析。
  • 在 Foundry 中直接集成： 直接在 Quiver 中利用函数输出，并应用重采样、公式、连接和时间序列搜索等操作，同时确保兼容性和可组合性。
  • 按需数据访问： 轻松整合来自外部 API 或服务的数据，无需预先物化数据，从而实现快速原型设计和动态分析。
  • 参数化场景： 传递自定义输入（例如控制设置或预测期），以并排比较多个生成的序列。
  • 可扩展的生产工作流： 借助内置的结果缓存和流式执行来处理大型输出，同时保持交互的响应速度。

在下面的示例中，函数支撑的时间序列被用于 Workshop 模块中，以实时计算每周预测。操作员能够模拟不同场景，了解更改机器控制参数如何影响预测的性能预测。

运作方式

函数支撑的时间序列需要一个返回序列化数值时间序列的 Python Foundry 函数。当您查询数据时，Quiver 会使用指定的参数调用您的函数，在查询时动态生成时间序列。该输出随后在 Foundry 中被视为一等时间序列，使您能够应用进一步的操作和可视化。

此集成使您可以轻松地将自定义模型和即时分析整合到您的仪表板中，从而实现灵活且模块化的时间序列工作流。

示例用例

  • 预测和模拟： 使用您选择的库（例如 Prophet 或 statsmodels）生成预测，或使用在 Foundry 中构建的模型来分析未来趋势并进行情景规划。
  • 多变量分析： 组合来自多个传感器或指标的输出，以实现全面的时间序列分析。
  • 快速模型迭代： 快速迭代自定义模型，无需管理中间数据集或数据管道。

from functions.api import function
from timeseries_sdk.types import TimeSeries
from ontology_sdk.ontology.objects import Machine
from prophet import Prophet

@function
def performance_prophet_forecast(
    machine: Machine,
    periods: int = 96,      # number of future steps
    freq: str = "15min",    # sampling frequency
) -> list[bytes]:
    """
    Forecast a machine's performance_score using Prophet.
    """
    df = machine.performance_score.to_pandas(all_time=True)
    if df.empty:
        return TimeSeries.serialize(df)

    df = df.rename(columns={"timestamp": "ds", "value": "y"}).sort_values("ds")
    model = Prophet().fit(df)
    future = model.make_future_dataframe(periods=periods, freq=freq, include_history=True)
    forecast = model.predict(future)
    out = forecast[["ds", "yhat"]].rename(columns={"ds": "timestamp", "yhat": "value"})
    return TimeSeries.serialize(out)
