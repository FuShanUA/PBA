数据连接

数据连接 是一款应用程序，用于从外部系统和其他 Foundry 实例同步数据，以供在 Foundry 中使用。用户可以使用数据连接将数据同步到 Foundry，供数据集成、建模和本体论层使用。此外，数据连接还支持设置出站连接，以便通过 webhook 和数据导出向外部系统写回数据。

通过在工作区导航栏中选择相应图标，即可访问数据连接应用程序。

您也可以在应用程序门户中通过搜索找到数据连接应用程序。

如果这是您首次为组织将 Foundry 连接到您的数据，请先参阅 初始设置指南。

Foundry 通过以下三项原则对数据连接流程进行了标准化：

  • 健壮性
  • 可扩展性
  • 易用性

健壮性

系统之间的数据连接往往容易出现难以恢复的故障。外部环境中超出用户控制范围的问题（例如，网络连接不佳、磁盘故障或源系统无响应）会影响数据同步，还会破坏下游分析管道。数据不完整或损坏不仅是一项技术挑战，如果在未被察觉的情况下被使用，或在紧急需求时无法获取，还可能对组织构成潜在危险。

Foundry 主动应对这些常见故障点，具体措施包括：发生故障时自动重试；使用简单函数（例如文件系统和数据库同步）以低复杂度的查询从源系统小批量拉取数据；以及利用集成的数据健康监控系统，在发生严重故障时发出警报并揭示其他管道健康问题。这些功能相结合，可将数据不完整或损坏的风险降至最低。

Foundry 的另一大特色在于其秉持这样一个理念：数据应从最原始的源“原样”摄取，不进行任何外部预处理。在没有外部预处理的情况下，采用分支和版本控制的 Foundry 管道便成为原始数据在通往本体论的旅程中所发生的全部变更的唯一来源，且该路径上出现的任何问题均可在平台内部得到识别和解决。Data Connection 秉承这一设计理念，既支持表格同步，也支持基于文件的同步，并刻意只提供极少的选项，用于在数据到达目标数据集（即 Foundry 管道的起点）之前对数据进行转换。

可扩展性

企业拥有一系列多样化且复杂的系统，这些系统既能单独创造价值，也能作为集成系统整体发挥作用。每个系统都有各自的集成要求，而某些系统需要独特的功能或特性，这通常会使集成变得困难。

Foundry 为常见系统类型（例如关系型数据库、FTPS、HDFS、S3、SFTP 和本地目录）提供开箱即用的集成，同时还具备灵活连接和同步新系统类型数据的能力。在许多情况下，新系统可以复用现有插件，或只需对现有插件进行少量修改即可。核心功能（例如调度和上传）已实现标准化，因此只需调整连接本身即可。

Foundry 还支持通过专用的 Foundry 连接器在 Foundry 实例之间进行通信。借助此连接器，一个 Foundry 实例可以被视为另一个实例上的数据源，并支持具有增量选项的批处理同步和流式同步。

了解各种可用源类型的更多信息。

易用性

管理系统之间的数据连接可能是一个复杂的过程，会给负责每个步骤（同步、身份验证、调度与编排、监控）的管理员带来沉重的负担。

Foundry 借助后端服务屏蔽了这种复杂性：用户只需通过简单的前端用户界面设置和管理管道，后端服务即可承担大部分工作。这降低了此类通常较为复杂的技术任务的入门门槛，让更多用户能够进行数据连接。
