拖拽创建

本页面介绍 排程甘特图小组件的拖拽创建功能。如需为日历小组件设置拖拽创建，请参阅 拖拽创建。

使最终用户能够使用拖拽创建按需创建新的排程对象。拖拽创建允许您在特定行上，以“拖拽起点”和“拖拽终点”作为开始和结束时间戳来初始化一个新的排程对象。

要配置拖拽创建，您必须提供一个 Create Action Type拖放 puck 时，该小组件将调用此操作。

在以下示例中，我们将该排程层称为 Object type A。

设置拖拽创建行为

  1. 在本体论管理器中，导航至 Object type A 并创建一个 Create Action Type。该操作类型应具有以下参数：
    • 新对象的主键
    • 该 Start Timestamp 属性
    • 该 End Timestamp 属性
    • 该 foreign key 属性
    • （可选）添加您希望在创建对象时填充的属性。
    • 最终，该操作类型应配置为：输入 Start Timestamp、 End Timestamp和 foreign key 即可创建一个 object type A 对象，其中包含这些值。
  2. 现在，在 Workshop 中，导航至 输入数据 (Pucks) > [您的排程层] > 交互 > 拖动光标以创建操作。
  3. 在 拖拽创建操作下，选择您配置的操作类型。
  4. 在您刚才输入的操作类型下，选择 选择要配置的参数 并选择开始时间戳、结束时间戳以及外键参数。现在，您应该能看到配置中已列出这三个参数。接下来，我们将选择排程甘特图变量以预填充这些参数值。
    • 对于 开始时间戳 参数，在 本地默认值下，选择 选定的开始时间戳 （在弹出窗口中），以确保在拖拽创建时，组件会自动传入您开始拖拽的时间戳。
    • 对于 结束时间戳 参数，在 本地默认值下，选择 选定的结束时间戳 （在弹出窗口中）。这将确保在拖拽创建时，组件会自动传入您结束拖拽的时间戳。
    • 对于 外键 参数，在 本地默认值下，选择 资源 ID （在弹出窗口中），以确保在拖拽创建时，组件会自动传入您在其上触发拖拽创建的行（资源）。

使用

设置完成后， Shift + Drag 在给定行上，根据开始时间和结束时间。这将弹出您的“拖拽创建”操作表单。提交后，将为指定行创建一个新的计划对象，并纳入来自“拖拽起点”和“拖拽终点”操作的开始和结束时间戳。
