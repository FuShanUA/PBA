浏览 VS Code

您可以使用 VS Code 工作区 配合 适用于 Visual Studio Code 的 Palantir 扩展 来导入资源、预览函数、管理分支、提交和发布更改、升级您的仓库，以及在不离开编辑器的情况下使用本地开发工具。

将资源导入到函数仓库中

在函数中使用 Foundry 资源之前，请先将它们导入到您的仓库中：

  1. 选择 资源导入 图标，该图标在 VS Code 活动栏中显示为向下箭头。
  2. 在 资源 面板中，选择 本体论 SDK 或 平台 选项卡，具体取决于您要导入的资源。
  3. 选择 添加，然后选择一种资源类型，例如对象类型、接口、操作、查询函数或数据源。
  4. 查找并选择您要使用的资源，然后确认您的选择。
  5. 请等待代码生成和依赖项安装完成，然后在代码中引用该资源。

要获取最新的可用资源类型，请通过 仓库升级确保您的仓库保持最新。详细了解 导入本体论类型。

使用 Palantir 扩展进行开发和发布

在活动栏中选择 Palantir 图标以打开 Palantir 面板——该面板提供分支、预览、提交、发布和仓库管理操作。

创建或切换分支

使用 分支 部分，在开始编辑之前创建或切换分支：

  1. 选择 代码 或 全局 选项卡。
    • 代码 分支是代码仓库中变更的底层 Git 分支。
    • 全局 分支可以包含跨多个受支持的 Foundry 应用和资源的相关变更。
  2. 选择创建分支图标，该图标显示为带加号的分支。
  3. 输入新分支的名称，然后确认即可创建该分支。

是否支持全局分支取决于函数所用的语言和仓库配置。要了解更多信息，请参阅 VS Code 中的分支、 代码仓库中的分支选项，以及 在全局分支上开发和发布函数。

预览函数

  1. 在 Palantir 面板中，选择 函数预览。
  2. 选择一个函数，提供其输入，然后点击运行，即可使用所提供的输入值执行您的代码。
  3. 在代码执行过程中，查看输出、日志、编辑内容等。这将帮助您调试和测试函数。

如果您在全局分支上进行开发，预览将针对 Palantir 面板中当前选定的分支运行。了解有关 在实时预览中测试函数的更多信息。

提交、提议和标记更改

当您的预览和测试成功时：

  1. 选择 提交 在 更改 部分中，查看已更改的文件，并输入描述性的提交信息。
  2. 选择 提议更改 如果您的更改在合并前需要经过代码审查。
  3. 选择 标记版本 以选择版本并发布所选分支中的函数。

标记会发布仓库中的所有函数，而不仅仅是您最近编辑的函数。

了解有关 发布函数 和 函数版本控制的更多信息。

升级仓库

选择 升级 在 更改 部分以启动仓库升级。查看生成的更改，再次运行您的测试和函数预览，然后提交升级。了解有关 自动和手动仓库升级的更多信息。

保存时格式化

打开 设置，搜索 format on save，并启用 Editor: Format On Save。按 Cmd+S （macOS）或 Ctrl+S （Windows/Linux）以保存当前文件并运行已配置的格式化程序。您还可以运行 Format Document 命令（位于命令面板中）。
