Automate 入门

本教程将引导您使用 Automate 应用程序创建您的第一个简单自动化。本教程假设您已将数据集成到 Foundry 本体论中。如果您尚未完成此操作，请了解如何 创建您的本体论.

从 Automate 应用程序创建

首先从应用程序侧边栏打开 Automate 应用程序。这将带您进入 Automate 应用程序的 概述 页面。

直方图 概述 页面显示您最近的自动化活动列表，包括您可以查看的自动化总数、您拥有的自动化、您作为接收者的自动化以及已暂停的自动化的计数。您还可以查看最近查看的自动化列表、过去四周内的失败记录以及最近触发的自动化。

要创建您的第一个自动化，请选择 + 新建自动化 （位于页面右上角）。或者，您可以：

  • 将鼠标悬停在 Foundry 侧边栏中的 Automate 应用程序图标上并选择 + 新建自动化配置对象类型
  • 选择 + 新建 在 Compass 文件夹中并选择 自动化.

您将进入自动化创建向导（如下所示），可以在其中开始定义您的自动化条件。在本示例中，您将添加一个简单的 时间 条件。

现在，暂时保持时间配置页面不变，继续前往 效果 页面，方法是选择 属性，然后选择 如下图所示。

在 效果 页面中，您可以添加一个或多个在满足时间条件时执行的效果。选择 将 ，该选项位于 通知 卡片以继续前往 通知 效果配置页面。

直方图 通知效果 提供了许多配置选项。现在，在 接收者 文本输入框中将自己添加为静态接收者。为您的通知定义标题和消息，然后选择 预览 以查看消息在接收者端的显示效果。选择 属性，然后选择 以返回 效果 页面预览同步的数据。

您可以选择为通知添加其他效果，但在本示例中，您将继续前往自动化 摘要 页面，方法是选择 属性，然后选择 再次。

直方图 摘要 页面显示了为自动化配置的条件和效果的精简视图。选择 创建自动化 以添加文件名称、保存位置和过期日期（永久, 立即，或 直到 某个特定日期），以及 自动化的权限.

成功创建后，您将被重定向到新创建的自动化的详情页面，该页面将显示成功横幅。

选择顶部工具栏中的 Automate 图标以返回 Automate 概览页面。 最近活动 部分将在您的自动化触发后填充相关事件。

要检查您新创建的自动化，请导航至 自动化 选项卡，以查看您当前权限可见的所有自动化的表格。使用左侧的筛选窗格搜索特定的自动化，例如您刚刚创建的自动化。

有关配置选项的更多信息，请查看各种条件和效果文档。或者，探索 示例部分 以了解更复杂的 Automate 用例。
