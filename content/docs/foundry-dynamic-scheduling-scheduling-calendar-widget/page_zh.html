小组件模式

日程日历小组件有两种模式：只读模式和动态模式。默认情况下，小组件以只读模式启动，该模式专为查看和分析数据而设计，不会进行任何更改。切换到动态模式后，您可以直接在小组件中添加、编辑或删除日程对象。

输入数据（圆块）

  • 日程名称： 图层的名称，用于在配置过程中区分不同的图层。该值不会显示在小组件本身中。

  • 日程对象集： 这是日程日历小组件的输入变量，用于确定将显示哪些数据。为此对象集选择的对象类型必须具有表示开始时间和结束时间的属性。

  • 开始时间： 选择一个日期或时间戳属性，作为事件的开始时间。

  • 结束时间： 选择一个日期或时间戳属性，用作事件的结束时间。

  • 标题： 选择一个属性作为小组件中对象 puck 的显示标签值。

  • 颜色： 选择在图表中显示事件时使用的颜色。

    • 静态： 为所有 puck 选择单一颜色。
    • 分段依据： 选择一个属性，小组件将根据所选属性的值自动为 puck 进行颜色编码。
    • 动态： 配置应用于图表中 puck 的条件格式规则。

  • 弹出属性： 此部分确定当用户的光标悬停在日历上的某个 puck 上时，弹出卡片上将显示哪些属性。

  • 保存处理操作（动态模式）： 选择一个用于拖放交互的操作。此操作应为用于编辑日程对象开始时间和结束时间属性的修改操作。

    • 该操作必须具有用于修改日程对象开始时间和结束时间的参数。
    • 操作中的参数 ID 必须与您为开始时间和结束时间选择的属性 ID 完全一致。例如：
      • 如果您的开始时间属性为 start_time，则操作参数 ID 也必须为 start_time.
      • 如果您的结束时间属性为 end_time，则操作参数 ID 也必须为 end_time.
    • 所有参数都应标记为可选。

  • 启用拖拽创建（动态模式）： 选择一个操作，让最终用户可以通过在日历的空白区域拖拽来创建新的日程对象。请参阅 拖拽创建 以了解设置和使用详情。

显示配置

  • 每周起始日： 此选择确定当您的图表处于周视图或月视图时，哪一天将作为一周的开始。

  • 间隔大小（仅限动态模式）： 默认情况下，用户可以将对象分配到日程日历小组件上的任意时间，精确到具体分钟。对齐行为允许构建者设置对象可被分配的固定时间间隔。一旦 puck 被拖放到图表中的新位置，它将自动对齐到最接近的时间间隔的开始处。

  • 起始时间： 此选择决定图表在日视图或周视图中的开始时间。

  • 结束时间： 此选择决定图表在日视图或周视图中的结束时间。

拖拽创建

日历小组件允许最终用户按住修饰键并在日历上拖动来创建新的日程对象。

设置拖动创建行为

  1. 在 Ontology Manager 中，为日历图层中显示的对象类型创建一个 Create Action 此操作需要以下参数：

    • 直方图 Start Time 对象的属性
    • 直方图 End Time 对象的属性
    • （可选）您希望用户在创建对象时填写的任何其他属性。

    开始和结束时间参数可以定义为时间戳或日期类型，以匹配对象类型上相应的属性。

  2. 在 Workshop 中，导航到 Input Data (Pucks) > [your calendar layer] > Interactions > Enable Drag to Create.

  3. 选择 Create Action 您所配置的。

  4. 选择 选择要配置的参数，然后在 本地默认值:

    • 下绑定开始和结束时间参数。对于开始时间参数，选择 SELECTED START TIMESTAMP (or SELECTED START DATE （如果参数为日期类型），以便在拖动创建时，小组件传入您拖动起始的时间。
    • 对于结束时间参数，选择 SELECTED END TIMESTAMP (or SELECTED END DATE），以便在拖动创建时，小组件传入您拖动结束的时间。

用途

要创建新对象，请按住操作系统的修饰键并在日历的空白区域拖动：

  • macOS： hold Cmd （⌘）并拖动。
  • Windows： 按住 Windows 键并拖动。

当您释放拖动时，小组件会根据您拖动的开始和结束时间立即显示新提议的对象。默认情况下，每次创建时都会弹出表单以提供最大的可配置性。选择 有效时隐藏表单并立即应用 配置将隐藏此表单。新对象仅在保存更改后才会在本体论中创建。

常见配置问题

错误："操作参数 ID 必须与所选属性的 ID 一致"

当保存处理程序操作的参数 ID 与小组件配置中使用的属性 ID 不完全匹配时，会出现此错误。

原因： 小组件要求以下两者完全匹配：

  • 您的开始和结束时间属性的属性 ID
  • 保存处理程序操作中的参数 ID

解决方案：

  1. 在 Ontology Manager 中检查您的属性 ID：
    • 导航到您的日程对象类型。
    • 记下确切的属性 ID（例如， start_time, end_time).
  2. 检查您的操作参数 ID：
    • 在 Ontology Manager 中打开您的保存处理程序操作。
    • 在操作的参数配置中，验证参数 ID 与您的属性 ID 完全匹配。
    • 参数名称可以不同，但 参数 ID 必须与属性 ID 完全一致。
  3. 如有需要，请编辑操作参数 ID 以匹配您的属性 ID。
