在 Foundry 中使用 Anaconda

您可以直接通过 Code Repositories 和 Code Workbooks 使用 Anaconda 全面的 Conda 软件包，从而获得企业级数据科学能力，简化工作流程并加速分析和 AI 开发。

Anaconda 访问权限在 Foundry 注册中普遍可用，在 2027 年 6 月 29 日之前无需许可证费用。在该日期之后，使用 Anaconda 的工作流、构建和管道需要客户单独采购许可证。在 Foundry 中使用 Anaconda 的核心产品必须遵守其 嵌入式最终用户许可协议 ↗。Palantir 会与 Anaconda 共享以下使用信息：

  • 正在使用 Anaconda 的 Foundry 注册数量。
  • Foundry 部署类型，例如本地部署或云部署。

如有关于您注册中 Anaconda 的可用性或许可的任何问题，请联系 Palantir Support。

通过在 Code Repositories 或 Code Workbooks 中访问 Conda 软件包，您可以：

  • 无需离开 Foundry 即可使用 Anaconda 安全的、由企业维护的软件包集合。
  • 使用经过安全审查的可信库构建复杂的 AI、ML 和分析应用程序。
  • 在 Foundry 的受治理环境中利用专业的数据科学工具。

开始使用

在 Code Repositories 中，来自 Anaconda 仓库的 Conda 软件包可在 ”面板中找到。 例如，要使用 侧面板中找到。在选择之前搜索并选择软件包 添加并安装库.

Foundry 会自动配置必要的支撑仓库。

在 Code Workbooks 中，导航到您工作簿配置文件中的 Conda 环境选项卡，然后选择 添加软件包 以搜索并添加 Anaconda 软件包。

在工作簿中测试 Conda 环境 然后 保存配置文件更改以确保依赖项正确解析。当您保存对 Conda 环境的更改时，Foundry 会提示您确认已测试该配置。
