Microsoft Excel Online

The Microsoft Excel Online connector is a Palantir-provided driver for Microsoft Excel Online.

To create a new Microsoft Excel Online source, follow the standard setup flow for Palantir-provided drivers, then use the sections below for Microsoft Excel Online-specific configuration and networking. For the complete property reference, see the official Microsoft Excel Online driver documentation ↗.

Introduction

The Microsoft Excel Online connector reads live workbooks in OneDrive for Business or SharePoint Online. It exposes each worksheet as a relational table through Microsoft Graph.

Use batch syncs to read worksheet tables. Use table exports to append dataset rows to a workbook. To download a workbook or insert, update, and delete keyed rows, use a delegated Function with Microsoft Graph.

Choose an Excel connector

The connector to use depends on where the workbook is stored and how you need to access it.

ConnectorUse when
Microsoft ExcelThe workbook is stored as a file in Amazon S3, Azure Blob Storage, Azure Data Lake Storage, OneDrive, SharePoint, Google Drive, FTP, SFTP, or another supported backend.
Microsoft Excel Online (this connector)The workbook is stored in Microsoft 365 through OneDrive for Business or SharePoint Online. This connector uses Microsoft Graph and supports Entra ID authentication.
Microsoft SharePoint ExcelThe workbook is stored on an on-premises SharePoint Server 2010 or 2013 deployment. For SharePoint Online, use Microsoft Excel Online.

Use Microsoft Excel Online when your workbooks have a consistent tabular structure and you need worksheets or cell ranges exposed directly as source tables.

For greater flexibility over worksheet selection, cell ranges, data types, and workbook-specific parsing, ingest the workbook as a file with Microsoft OneDrive or Microsoft SharePoint. Then parse it in a transform using the Excel parser for Transforms, the parseExcel function in Pipeline Builder, or a library such as pandas.read_excel or openpyxl.

Authentication

Microsoft Excel Online authenticates to Microsoft 365 through Microsoft Entra ID. Set AuthScheme to AzureAD for delegated access to workbooks available to the signed-in user.

Delegated user sign-in (AzureAD)

With delegated authentication, a Microsoft 365 user signs in interactively. The source can access only files available to that user.

  1. Register an application in Microsoft Entra ID. Add a Web platform redirect URI and set it to the CallbackURL value obtained in step 3.

  2. Grant delegated Microsoft Graph permissions: Files.Read.All, Sites.Read.All, and offline_access. If your tenant restricts user consent for these scopes, an administrator who can grant tenant-wide consent must grant consent for the application.

  3. Create the Foundry source and set the JDBC properties:

    • AuthScheme = AzureAD
    • InitiateOAuth = REFRESH
    • AzureTenant = your tenant name or ID (for example contoso.onmicrosoft.com)
    • OAuthClientId / OAuthClientSecret = the registered application's client ID and secret
    • Scope = https://graph.microsoft.com/Files.Read.All https://graph.microsoft.com/Sites.Read.All offline_access

    Then copy the source's generated CallbackURL and paste it back as the application's Web redirect URI.

  4. Save, then select Authorize and complete the interactive sign-in as the user who can access the target workbook.

Table exports

This connector supports table exports. Learn how to set up a table export.

Read and write data

Read worksheet tables

Each worksheet in an accessible workbook is exposed as a table named {workbook}_{worksheet}. For example, a People sheet in People.xlsx becomes People_People. In the source connection properties, set Drive or SharepointURL to select a location, and set Workbook to select a workbook by name or ID. Use a batch sync to read the resulting tables.

Set ValueRenderOption to FormattedValue, UnformattedValue, or Formula to control whether the connector returns displayed values, raw values, or formula text.

Append rows with table exports

Use a table export to insert rows from a Foundry dataset into a workbook. Table exports do not update or delete individual rows. Use the delegated Function examples when you need keyed row operations.

Use Microsoft Excel Online in code

The following examples call Microsoft Graph with the signed-in user's delegated authorization. They cover four operations in Python and TypeScript v2: download a workbook, insert a row, update a row, and delete a row.

Before using an example:

  1. Configure a Microsoft Graph OAuth 2.0 authorization-code outbound application and REST source. Grant the delegated Files.ReadWrite, offline_access, openid, and profile scopes.
  2. Allow the source to be used in code and exported to Functions. Configure source-aware egress for Microsoft Graph, Microsoft identity, and the SharePoint host used for workbook downloads.
  3. Import the source into the Function repository. Replace the source, drive, workbook item, worksheet, and source alias placeholders.
  4. Authorize the source as the user who can access the target workbook.

The writer examples use a worksheet containing only the five columns Id, Name, Role, City, and PersonKey, with headers in A1:E1 and data starting in row 2. The insert and delete operations shift cells within columns A:E. Adapt the columns and ranges to your workbook.

import { Buffer } from "node:buffer";

import { UserFacingError } from "@osdk/functions";
import { getFetch, getSource } from "@palantir/functions-sources";


const SOURCE_RID = "ri.magritte..source.REPLACE_WITH_YOUR_SOURCE_RID";
const SOURCE_ALIAS = "MicrosoftGraphExcelDelegated";
const DRIVE_ID = "REPLACE_WITH_YOUR_DRIVE_ID";
const WORKBOOK_ITEM_ID = "REPLACE_WITH_YOUR_WORKBOOK_ITEM_ID";
const GRAPH_BASE_URL = "https://graph.microsoft.com/v1.0";

export const config = {
  apiName: "downloadExcelOnlineWorkbook",
  sources: [SOURCE_ALIAS],
};

export default async function downloadExcelOnlineWorkbook(): Promise<string> {
  const source = await getSource({ rid: SOURCE_RID });
  const { accessToken } = (await source.sessionCredentials?.get()) as {
    accessToken: string;
  };
  const sourceFetch = (await getFetch(source)) as typeof fetch;
  const url =
    `${GRAPH_BASE_URL}/drives/${encodeURIComponent(DRIVE_ID)}` +
    `/items/${encodeURIComponent(WORKBOOK_ITEM_ID)}/content`;
  const response = await sourceFetch(url, {
    method: "GET",
    headers: { Authorization: `Bearer ${accessToken}` },
    signal: AbortSignal.timeout(60_000),
  });
  if (!response.ok) {
    throw new UserFacingError(`Microsoft Graph returned HTTP ${response.status}.`);
  }
  return Buffer.from(await response.arrayBuffer()).toString("base64");
}

import { UserFacingError } from "@osdk/functions";
import { getFetch, getSource } from "@palantir/functions-sources";


const SOURCE_RID = "ri.magritte..source.REPLACE_WITH_YOUR_SOURCE_RID";
const SOURCE_ALIAS = "MicrosoftGraphExcelDelegated";
const DRIVE_ID = "REPLACE_WITH_YOUR_DRIVE_ID";
const WORKBOOK_ITEM_ID = "REPLACE_WITH_YOUR_WORKBOOK_ITEM_ID";
const WORKSHEET = "People";
const GRAPH_BASE_URL = "https://graph.microsoft.com/v1.0";

export const config = {
  apiName: "insertExcelOnlineRow",
  sources: [SOURCE_ALIAS],
};

export default async function insertExcelOnlineRow(
  businessKey: string,
  name: string,
  role: string,
  city: string,
): Promise<string> {
  const source = await getSource({ rid: SOURCE_RID });
  const { accessToken } = (await source.sessionCredentials?.get()) as {
    accessToken: string;
  };
  const sourceFetch = (await getFetch(source)) as typeof fetch;
  const workbookUrl =
    `${GRAPH_BASE_URL}/drives/${encodeURIComponent(DRIVE_ID)}` +
    `/items/${encodeURIComponent(WORKBOOK_ITEM_ID)}/workbook`;
  const rowUrl =
    `${workbookUrl}/worksheets/${encodeURIComponent(WORKSHEET)}` +
    `/range(address='${encodeURIComponent("A2:E2")}')`;
  const headers = {
    Authorization: `Bearer ${accessToken}`,
    "Content-Type": "application/json",
  };

  const inserted = await sourceFetch(`${rowUrl}/insert`, {
    method: "POST",
    headers,
    body: JSON.stringify({ shift: "Down" }),
  });
  if (!inserted.ok) {
    throw new UserFacingError(`Microsoft Graph returned HTTP ${inserted.status}.`);
  }

  const populated = await sourceFetch(rowUrl, {
    method: "PATCH",
    headers,
    body: JSON.stringify({
      values: [["", name, role, city, businessKey]],
    }),
  });
  if (!populated.ok) {
    throw new UserFacingError(`Microsoft Graph returned HTTP ${populated.status}.`);
  }
  return `Inserted row for ${businessKey}.`;
}

@function(api_name="updateExcelOnlineRow", sources=[SOURCE_RID])
def update_excel_online_row(
    business_key: str,
    name: str,
    role: str,
    city: str,
) -> str:
    workbook_url = (
        f"{GRAPH_BASE_URL}/drives/{quote(DRIVE_ID, safe='')}"
        f"/items/{quote(WORKBOOK_ITEM_ID, safe='')}/workbook"

            timeout=60,

        used_range.raise_for_status()

        key_index = rows[0].index("PersonKey")
        matches = [
            (number, row)
            for number, row in enumerate(rows[1:], start=2)
            if len(row) > key_index and str(row[key_index]) == business_key

        replacement = list(row)
        replacement[1:4] = [name, role, city]
        address = quote(f"A{row_number}:E{row_number}", safe="")
        updated = session.patch(
            f"{worksheet_url}/range(address='{address}')",
            json={"values": [replacement]},
            timeout=60,
        )
        updated.raise_for_status()
    return f"Updated row for {business_key}."

import { UserFacingError } from "@osdk/functions";
import { getFetch, getSource } from "@palantir/functions-sources";


const SOURCE_RID = "ri.magritte..source.REPLACE_WITH_YOUR_SOURCE_RID";
const SOURCE_ALIAS = "MicrosoftGraphExcelDelegated";
const DRIVE_ID = "REPLACE_WITH_YOUR_DRIVE_ID";
const WORKBOOK_ITEM_ID = "REPLACE_WITH_YOUR_WORKBOOK_ITEM_ID";
const WORKSHEET = "People";
const GRAPH_BASE_URL = "https://graph.microsoft.com/v1.0";

export const config = {
  apiName: "updateExcelOnlineRow",
  sources: [SOURCE_ALIAS],
};

export default async function updateExcelOnlineRow(
  businessKey: string,
  name: string,
  role: string,
  city: string,
): Promise<string> {
  const source = await getSource({ rid: SOURCE_RID });
  const { accessToken } = (await source.sessionCredentials?.get()) as {
    accessToken: string;
  };
  const sourceFetch = (await getFetch(source)) as typeof fetch;
  const workbookUrl =
    `${GRAPH_BASE_URL}/drives/${encodeURIComponent(DRIVE_ID)}` +
    `/items/${encodeURIComponent(WORKBOOK_ITEM_ID)}/workbook`;
  const worksheetUrl =
    `${workbookUrl}/worksheets/${encodeURIComponent(WORKSHEET)}`;
  const authorization = { Authorization: `Bearer ${accessToken}` };

  const usedRange = await sourceFetch(
    `${worksheetUrl}/usedRange(valuesOnly=true)`,
    { headers: authorization },
  );
  if (!usedRange.ok) {
    throw new UserFacingError(`Microsoft Graph returned HTTP ${usedRange.status}.`);
  }
  const rows = ((await usedRange.json()) as { values: unknown[][] }).values;
  const keyIndex = rows[0].indexOf("PersonKey");
  const matches = rows
    .slice(1)
    .map((row, index) => ({ row, rowNumber: index + 2 }))
    .filter(({ row }) => String(row[keyIndex]) === businessKey);
  if (matches.length !== 1) {
    throw new UserFacingError("Expected exactly one row with that PersonKey.");
  }

  const replacement = [...matches[0].row];
  replacement.splice(1, 3, name, role, city);
  const address = encodeURIComponent(
    `A${matches[0].rowNumber}:E${matches[0].rowNumber}`,
  );
  const updated = await sourceFetch(
    `${worksheetUrl}/range(address='${address}')`,
    {
      method: "PATCH",
      headers: {
        ...authorization,
        "Content-Type": "application/json",
      },
      body: JSON.stringify({ values: [replacement] }),
    },
  );
  if (!updated.ok) {
    throw new UserFacingError(`Microsoft Graph returned HTTP ${updated.status}.`);
  }
  return `Updated row for ${businessKey}.`;
}

import { UserFacingError } from "@osdk/functions";
import { getFetch, getSource } from "@palantir/functions-sources";


const SOURCE_RID = "ri.magritte..source.REPLACE_WITH_YOUR_SOURCE_RID";
const SOURCE_ALIAS = "MicrosoftGraphExcelDelegated";
const DRIVE_ID = "REPLACE_WITH_YOUR_DRIVE_ID";
const WORKBOOK_ITEM_ID = "REPLACE_WITH_YOUR_WORKBOOK_ITEM_ID";
const WORKSHEET = "People";
const GRAPH_BASE_URL = "https://graph.microsoft.com/v1.0";

export const config = {
  apiName: "deleteExcelOnlineRow",
  sources: [SOURCE_ALIAS],
};

export default async function deleteExcelOnlineRow(
  businessKey: string,
): Promise<string> {
  const source = await getSource({ rid: SOURCE_RID });
  const { accessToken } = (await source.sessionCredentials?.get()) as {
    accessToken: string;
  };
  const sourceFetch = (await getFetch(source)) as typeof fetch;
  const workbookUrl =
    `${GRAPH_BASE_URL}/drives/${encodeURIComponent(DRIVE_ID)}` +
    `/items/${encodeURIComponent(WORKBOOK_ITEM_ID)}/workbook`;
  const worksheetUrl =
    `${workbookUrl}/worksheets/${encodeURIComponent(WORKSHEET)}`;
  const authorization = { Authorization: `Bearer ${accessToken}` };

  const usedRange = await sourceFetch(
    `${worksheetUrl}/usedRange(valuesOnly=true)`,
    { headers: authorization },
  );
  if (!usedRange.ok) {
    throw new UserFacingError(`Microsoft Graph returned HTTP ${usedRange.status}.`);
  }
  const rows = ((await usedRange.json()) as { values: unknown[][] }).values;
  const keyIndex = rows[0].indexOf("PersonKey");
  const rowNumbers = rows
    .slice(1)
    .map((row, index) => ({ row, rowNumber: index + 2 }))
    .filter(({ row }) => String(row[keyIndex]) === businessKey)
    .map(({ rowNumber }) => rowNumber);
  if (rowNumbers.length !== 1) {
    throw new UserFacingError("Expected exactly one row with that PersonKey.");
  }

  const address = encodeURIComponent(
    `A${rowNumbers[0]}:E${rowNumbers[0]}`,
  );
  const deleted = await sourceFetch(
    `${worksheetUrl}/range(address='${address}')/delete`,
    {
      method: "POST",
      headers: {
        ...authorization,
        "Content-Type": "application/json",
      },
      body: JSON.stringify({ shift: "Up" }),
    },
  );
  if (!deleted.ok) {
    throw new UserFacingError(`Microsoft Graph returned HTTP ${deleted.status}.`);
  }
  return `Deleted row for ${businessKey}.`;
}
