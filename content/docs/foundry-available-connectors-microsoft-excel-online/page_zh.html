Microsoft Excel Online

Microsoft Excel Online 连接器是一种 由 Palantir 提供的驱动程序 ，适用于 Microsoft Excel Online。

要创建新的 Microsoft Excel Online 源，请按照 Palantir 提供的驱动程序的标准设置流程，然后使用以下部分进行 Microsoft Excel Online 特定的配置和网络设置。有关完整的属性参考，请参阅 官方 Microsoft Excel Online 驱动程序文档 ↗.

简介

Microsoft Excel Online 连接器可读取 OneDrive for Business 或 SharePoint Online 中的实时工作簿。它通过 Microsoft Graph 将每个工作表公开为关系表。

使用批量同步读取工作表表格。使用表格导出将数据集行追加到工作簿。要下载工作簿或插入、更新和删除带键的行，请使用通过 Microsoft Graph 的委托 Function。

选择 Excel 连接器

使用哪个连接器取决于工作簿的存储位置以及您需要访问它的方式。

连接器使用场景：
Microsoft Excel工作簿以文件形式存储在 Amazon S3、Azure Blob Storage、Azure Data Lake Storage、OneDrive、SharePoint、Google Drive、FTP、SFTP 或其他受支持的后端中。
Microsoft Excel Online （此连接器）工作簿通过 OneDrive for Business 或 SharePoint Online 存储在 Microsoft 365 中。此连接器使用 Microsoft Graph 并支持 Entra ID 身份验证。
Microsoft SharePoint Excel工作簿存储在本地 SharePoint Server 2010 或 2013 部署中。对于 SharePoint Online，请使用 Microsoft Excel Online。

当您的工作簿具有一致的表格结构，并且需要将工作表或单元格区域直接公开为源表时，请使用 Microsoft Excel Online。

如需在工作表选择、单元格区域、数据类型和工作簿特定解析方面获得更大的灵活性，请将工作簿作为文件摄取，使用 Microsoft OneDrive or Microsoft SharePoint。然后在转换中使用 转换的 Excel 解析器Workshop parseExcel 函数 在 Pipeline Builder 中进行解析，或使用诸如 pandas.read_excel or openpyxl.

身份验证

Microsoft Excel Online 通过 Microsoft Entra ID 向 Microsoft 365 进行身份验证。设置 AuthScheme to AzureAD 以委托方式访问已登录用户可用的工作簿。

委托用户登录（AzureAD)

使用委托身份验证时，Microsoft 365 用户以交互方式登录。源只能访问该用户可用的文件。

  1. 注册应用程序 在 Microsoft Entra ID 中。添加一个 Web 平台重定向 URI，并将其设置为 CallbackURL 在步骤 3 中获取的值。

  2. 授予委托的 Microsoft Graph 权限： Files.Read.All, Sites.Read.All日 offline_access。如果您的租户限制用户对这些作用域的同意，则必须由能够授予租户范围同意的管理员为应用程序授予同意。

  3. 创建 Foundry 源 并设置 JDBC 属性：

    • AuthScheme = AzureAD
    • InitiateOAuth = REFRESH
    • AzureTenant = 您的租户名称或 ID（例如 contoso.onmicrosoft.com)
    • OAuthClientId / OAuthClientSecret = 已注册应用程序的客户端 ID 和密钥
    • Scope = https://graph.microsoft.com/Files.Read.All https://graph.microsoft.com/Sites.Read.All offline_access

    然后复制源生成的 CallbackURL 并将其粘贴回应用程序的 Web 重定向 URI.

  4. 保存，然后选择 授权 并以能够访问目标工作簿的用户身份完成交互式登录。

读取和写入数据

读取工作表表格

可访问工作簿中的每个工作表都公开为一个名为 {workbook}_{worksheet}的表。例如， People 中的 People.xlsx 变为 People_People工作表。在源连接属性中，设置 Drive or SharepointURL 以选择位置，并设置 Workbook 以按名称或 ID 选择工作簿。使用 功能允许将外部系统的数据同步到Foundry 读取生成的表。

在您的终端会话中将 ValueRenderOption to FormattedValue, UnformattedValue，或 Formula 以控制连接器返回显示值、原始值还是公式文本。

使用表格导出追加行

使用 表导出 以将 Foundry 数据集中的行插入工作簿。表格导出不会更新或删除单个行。使用 委托 Function 示例 以执行带键的行操作。

在代码中使用 Microsoft Excel Online

以下示例使用已登录用户的委托授权调用 Microsoft Graph。它们涵盖 Python 和 TypeScript v2 中的四种操作：下载工作簿、插入行、更新行和删除行。

使用示例之前：

  1. 配置 Microsoft Graph OAuth 2.0 授权码出站应用程序和 REST 源。授予委托的 Files.ReadWrite, offline_access, openid日 profile scopes.
  2. 允许在代码中使用该源并将其导出到 Functions。为 Microsoft Graph、Microsoft 标识以及用于工作簿下载的 SharePoint 主机配置源感知出口。
  3. 将源导入 Function 仓库。替换源、驱动器、工作簿项、工作表和源别名的占位符。
  4. 以能够访问目标工作簿的用户身份为源授权。

写入示例使用仅包含以下五列的工作表 Id, Name, Role, City日 PersonKey，表头位于 A1:E1 ，数据从第 2 行开始。插入和删除操作会移动 A:E列内的单元格。请根据您的工作簿调整列和区域。

import { Buffer } from "node:buffer";

import { UserFacingError } from "@osdk/functions";
import { getFetch, getSource } from "@palantir/functions-sources";


const SOURCE_RID = "ri.magritte..source.REPLACE_WITH_YOUR_SOURCE_RID";
const SOURCE_ALIAS = "MicrosoftGraphExcelDelegated";
const DRIVE_ID = "REPLACE_WITH_YOUR_DRIVE_ID";
const WORKBOOK_ITEM_ID = "REPLACE_WITH_YOUR_WORKBOOK_ITEM_ID";
const GRAPH_BASE_URL = "https://graph.microsoft.com/v1.0";

export const config = {
  apiName: "downloadExcelOnlineWorkbook",
  sources: [SOURCE_ALIAS],
};

export default async function downloadExcelOnlineWorkbook(): Promise<string> {
  const source = await getSource({ rid: SOURCE_RID });
  const { accessToken } = (await source.sessionCredentials?.get()) as {
    accessToken: string;
  };
  const sourceFetch = (await getFetch(source)) as typeof fetch;
  const url =
    `${GRAPH_BASE_URL}/drives/${encodeURIComponent(DRIVE_ID)}` +
    `/items/${encodeURIComponent(WORKBOOK_ITEM_ID)}/content`;
  const response = await sourceFetch(url, {
    method: "GET",
    headers: { Authorization: `Bearer ${accessToken}` },
    signal: AbortSignal.timeout(60_000),
  });
  if (!response.ok) {
    throw new UserFacingError(`Microsoft Graph returned HTTP ${response.status}.`);
  }
  return Buffer.from(await response.arrayBuffer()).toString("base64");
}

import { UserFacingError } from "@osdk/functions";
import { getFetch, getSource } from "@palantir/functions-sources";


const SOURCE_RID = "ri.magritte..source.REPLACE_WITH_YOUR_SOURCE_RID";
const SOURCE_ALIAS = "MicrosoftGraphExcelDelegated";
const DRIVE_ID = "REPLACE_WITH_YOUR_DRIVE_ID";
const WORKBOOK_ITEM_ID = "REPLACE_WITH_YOUR_WORKBOOK_ITEM_ID";
const WORKSHEET = "People";
const GRAPH_BASE_URL = "https://graph.microsoft.com/v1.0";

export const config = {
  apiName: "insertExcelOnlineRow",
  sources: [SOURCE_ALIAS],
};

export default async function insertExcelOnlineRow(
  businessKey: string,
  name: string,
  role: string,
  city: string,
): Promise<string> {
  const source = await getSource({ rid: SOURCE_RID });
  const { accessToken } = (await source.sessionCredentials?.get()) as {
    accessToken: string;
  };
  const sourceFetch = (await getFetch(source)) as typeof fetch;
  const workbookUrl =
    `${GRAPH_BASE_URL}/drives/${encodeURIComponent(DRIVE_ID)}` +
    `/items/${encodeURIComponent(WORKBOOK_ITEM_ID)}/workbook`;
  const rowUrl =
    `${workbookUrl}/worksheets/${encodeURIComponent(WORKSHEET)}` +
    `/range(address='${encodeURIComponent("A2:E2")}')`;
  const headers = {
    Authorization: `Bearer ${accessToken}`,
    "Content-Type": "application/json",
  };

  const inserted = await sourceFetch(`${rowUrl}/insert`, {
    method: "POST",
    headers,
    body: JSON.stringify({ shift: "Down" }),
  });
  if (!inserted.ok) {
    throw new UserFacingError(`Microsoft Graph returned HTTP ${inserted.status}.`);
  }

  const populated = await sourceFetch(rowUrl, {
    method: "PATCH",
    headers,
    body: JSON.stringify({
      values: [["", name, role, city, businessKey]],
    }),
  });
  if (!populated.ok) {
    throw new UserFacingError(`Microsoft Graph returned HTTP ${populated.status}.`);
  }
  return `Inserted row for ${businessKey}.`;
}

import { UserFacingError } from "@osdk/functions";
import { getFetch, getSource } from "@palantir/functions-sources";


const SOURCE_RID = "ri.magritte..source.REPLACE_WITH_YOUR_SOURCE_RID";
const SOURCE_ALIAS = "MicrosoftGraphExcelDelegated";
const DRIVE_ID = "REPLACE_WITH_YOUR_DRIVE_ID";
const WORKBOOK_ITEM_ID = "REPLACE_WITH_YOUR_WORKBOOK_ITEM_ID";
const WORKSHEET = "People";
const GRAPH_BASE_URL = "https://graph.microsoft.com/v1.0";

export const config = {
  apiName: "updateExcelOnlineRow",
  sources: [SOURCE_ALIAS],
};

export default async function updateExcelOnlineRow(
  businessKey: string,
  name: string,
  role: string,
  city: string,
): Promise<string> {
  const source = await getSource({ rid: SOURCE_RID });
  const { accessToken } = (await source.sessionCredentials?.get()) as {
    accessToken: string;
  };
  const sourceFetch = (await getFetch(source)) as typeof fetch;
  const workbookUrl =
    `${GRAPH_BASE_URL}/drives/${encodeURIComponent(DRIVE_ID)}` +
    `/items/${encodeURIComponent(WORKBOOK_ITEM_ID)}/workbook`;
  const worksheetUrl =
    `${workbookUrl}/worksheets/${encodeURIComponent(WORKSHEET)}`;
  const authorization = { Authorization: `Bearer ${accessToken}` };

  const usedRange = await sourceFetch(
    `${worksheetUrl}/usedRange(valuesOnly=true)`,
    { headers: authorization },
  );
  if (!usedRange.ok) {
    throw new UserFacingError(`Microsoft Graph returned HTTP ${usedRange.status}.`);
  }
  const rows = ((await usedRange.json()) as { values: unknown[][] }).values;
  const keyIndex = rows[0].indexOf("PersonKey");
  const matches = rows
    .slice(1)
    .map((row, index) => ({ row, rowNumber: index + 2 }))
    .filter(({ row }) => String(row[keyIndex]) === businessKey);
  if (matches.length !== 1) {
    throw new UserFacingError("Expected exactly one row with that PersonKey.");
  }

  const replacement = [...matches[0].row];
  replacement.splice(1, 3, name, role, city);
  const address = encodeURIComponent(
    `A${matches[0].rowNumber}:E${matches[0].rowNumber}`,
  );
  const updated = await sourceFetch(
    `${worksheetUrl}/range(address='${address}')`,
    {
      method: "PATCH",
      headers: {
        ...authorization,
        "Content-Type": "application/json",
      },
      body: JSON.stringify({ values: [replacement] }),
    },
  );
  if (!updated.ok) {
    throw new UserFacingError(`Microsoft Graph returned HTTP ${updated.status}.`);
  }
  return `Updated row for ${businessKey}.`;
}

from urllib.parse import quote

import requests
from functions.api import UserFacingError, function
from functions.sources import get_source


SOURCE_RID = "ri.magritte..source.REPLACE_WITH_YOUR_SOURCE_RID"
DRIVE_ID = "REPLACE_WITH_YOUR_DRIVE_ID"
WORKBOOK_ITEM_ID = "REPLACE_WITH_YOUR_WORKBOOK_ITEM_ID"
WORKSHEET = "People"
GRAPH_BASE_URL = "https://graph.microsoft.com/v1.0"


def _delegated_session() -> requests.Session:
    source = get_source(rid=SOURCE_RID)
    session = requests.Session()
    access_token = source.get_session_credentials().get().access_token
    session.headers["Authorization"] = f"Bearer {access_token}"
    proxy_uri = source.get_https_proxy_uri()
    if proxy_uri:
        session.proxies.update({"http": proxy_uri, "https": proxy_uri})
    return session


@function(api_name="deleteExcelOnlineRow", sources=[SOURCE_RID])
def delete_excel_online_row(
    business_key: str,
) -> str:
    workbook_url = (
        f"{GRAPH_BASE_URL}/drives/{quote(DRIVE_ID, safe='')}"
        f"/items/{quote(WORKBOOK_ITEM_ID, safe='')}/workbook"
    )
    worksheet_url = f"{workbook_url}/worksheets/{quote(WORKSHEET, safe='')}"

    with _delegated_session() as session:
        used_range = session.get(
            f"{worksheet_url}/usedRange(valuesOnly=true)",
            timeout=60,
        )
        used_range.raise_for_status()
        rows = used_range.json()["values"]
        key_index = rows[0].index("PersonKey")
        row_numbers = [
            number
            for number, row in enumerate(rows[1:], start=2)
            if len(row) > key_index and str(row[key_index]) == business_key
        ]
        if len(row_numbers) != 1:
            raise UserFacingError("Expected exactly one row with that PersonKey.")

        address = quote(f"A{row_numbers[0]}:E{row_numbers[0]}", safe="")
        deleted = session.post(
            f"{worksheet_url}/range(address='{address}')/delete",
            json={"shift": "Up"},
            timeout=60,
        )
        deleted.raise_for_status()
    return f"Deleted row for {business_key}."

import { UserFacingError } from "@osdk/functions";
import { getFetch, getSource } from "@palantir/functions-sources";


const SOURCE_RID = "ri.magritte..source.REPLACE_WITH_YOUR_SOURCE_RID";
const SOURCE_ALIAS = "MicrosoftGraphExcelDelegated";
const DRIVE_ID = "REPLACE_WITH_YOUR_DRIVE_ID";
const WORKBOOK_ITEM_ID = "REPLACE_WITH_YOUR_WORKBOOK_ITEM_ID";
const WORKSHEET = "People";
const GRAPH_BASE_URL = "https://graph.microsoft.com/v1.0";

export const config = {
  apiName: "deleteExcelOnlineRow",
  sources: [SOURCE_ALIAS],
};

export default async function deleteExcelOnlineRow(
  businessKey: string,
): Promise<string> {
  const source = await getSource({ rid: SOURCE_RID });
  const { accessToken } = (await source.sessionCredentials?.get()) as {
    accessToken: string;
  };
  const sourceFetch = (await getFetch(source)) as typeof fetch;
  const workbookUrl =
    `${GRAPH_BASE_URL}/drives/${encodeURIComponent(DRIVE_ID)}` +
    `/items/${encodeURIComponent(WORKBOOK_ITEM_ID)}/workbook`;
  const worksheetUrl =
    `${workbookUrl}/worksheets/${encodeURIComponent(WORKSHEET)}`;
  const authorization = { Authorization: `Bearer ${accessToken}` };

  const usedRange = await sourceFetch(
    `${worksheetUrl}/usedRange(valuesOnly=true)`,
    { headers: authorization },
  );
  if (!usedRange.ok) {
    throw new UserFacingError(`Microsoft Graph returned HTTP ${usedRange.status}.`);
  }
  const rows = ((await usedRange.json()) as { values: unknown[][] }).values;
  const keyIndex = rows[0].indexOf("PersonKey");
  const rowNumbers = rows
    .slice(1)
    .map((row, index) => ({ row, rowNumber: index + 2 }))
    .filter(({ row }) => String(row[keyIndex]) === businessKey)
    .map(({ rowNumber }) => rowNumber);
  if (rowNumbers.length !== 1) {
    throw new UserFacingError("Expected exactly one row with that PersonKey.");
  }

  const address = encodeURIComponent(
    `A${rowNumbers[0]}:E${rowNumbers[0]}`,
  );
  const deleted = await sourceFetch(
    `${worksheetUrl}/range(address='${address}')/delete`,
    {
      method: "POST",
      headers: {
        ...authorization,
        "Content-Type": "application/json",
      },
      body: JSON.stringify({ shift: "Up" }),
    },
  );
  if (!deleted.ok) {
    throw new UserFacingError(`Microsoft Graph returned HTTP ${deleted.status}.`);
  }
  return `Deleted row for ${businessKey}.`;
}
