Foundry Rules 工作流配置

该 工作流配置编辑器 在更改整个 Foundry Rules 工作流的配置方式时使用；例如，在添加新的 输入 以供规则作者使用时，或在修改 工作流输出。工作流配置编辑器可以在 Ontology Manager 中访问，前提是 Foundry Rules 工作流已经 部署。Foundry Rules 工作流与某个项目绑定，并作为资源显示在您的项目文件夹中。这控制着工作流配置的权限，并允许用户重命名、移动或删除该工作流。

工作流输入

如 规则逻辑输入 部分所述， “输入” 窗格是配置编辑器中工作流所有者可以添加供规则作者使用的额外输入的位置。添加对象输入时，所有者还可以选择希望提供哪些相关的关联类型。

工作流输出

工作流输出指定工作流中所有 Foundry 规则输出的目标位置和格式。每个输出对应一个不同的 Foundry 数据集 在构建后，将包含引用它的所有 Foundry 规则的结果。在每个输出中，可以配置输出列的名称和类型。您还可以限制输出列 允许并默认采用的值。

转换配置

本部分包含用于配置 转换 （该转换用于生成 Foundry 规则的结果）的附加信息。它包含规则状态数据集的位置，以及任何 Spark 配置文件 （应用于该转换）。本部分属于高级配置，在首次设置 Foundry Rules 工作流时可以忽略。

规则执行

Foundry Rules 工作流配置还会生成一个转换管道来应用这些规则。转换管道是规则生效的地方；例如，通过创建警报或对数据进行分类/标记。下方的 数据血缘 图概述了一个 Foundry Rules 管道示例；管道的确切结构取决于用例，并可能根据需求和情况而有很大差异。

该管道会获取支撑 工作流输入 的数据集，连同规则回写数据集一起，并将这些规则应用于这些输入。然后，它会填充由 工作流输出 与规则输出的行。
