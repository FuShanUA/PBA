检查权限

您可以通过工作区侧边栏中的 检查访问 面板或 Data Lineage 工具来检查某人对项目、文件夹或文件的权限。

检查访问面板

要更详细地探索用户的权限，请使用 检查访问 面板。在项目、文件夹或文件上，打开侧边栏，然后选择 Access > Check access。此面板有时也被称为“访问检查器”。

访问要求和附加数据要求

直方图 检查访问 面板可用于确认用户是否满足项目、文件夹或文件的访问要求。显示在 访问要求下方，这包括：

  1. 满足组织和标记要求。
  2. 拥有一个或多个角色（直接、通过组或默认角色）。

除了上述访问要求外，某些文件可能还需要额外的权限，这些权限列在 附加数据要求构造一个本体论编辑容器。例如：

  • 通过血缘继承标记的数据集需要访问这些标记才能查看数据集的数据。
  • 显示对象表格的 Workshop 模块需要访问对象类型及其数据源。

在第一个示例中，虚拟用户 John Smith 满足此数据集的访问要求，但由于通过血缘继承的 Common: Food 标记而不满足附加数据要求。这意味着他可以查看数据集及其元数据，但不能查看其数据。

在第二个示例中， John Smith 也满足此 Workshop 模块的访问要求。该 Workshop 模块使用的对象类型、关联类型和操作类型 John Smith 需要访问才能使用该模块；这些元素列在 附加数据要求. John Smith 可以访问其中部分元素但不是全部（由彩色圆点指示）；点击右箭头图标可以让您更仔细地查看这些元素。

调度指标

除了 检查访问 侧边栏中的面板，您可以使用 Data Lineage 工具可视化某人在复杂数据管道中的访问情况。

您可以通过点击 探索数据血缘 来自 检查访问 面板，或选择 权限 作为 节点着色选项 （位于 Data Lineage 工具中右侧工具栏旁）来访问此视图。这提供两个子选项：

  • 资源访问： 图中的节点根据用户是否满足访问要求进行着色。
  • 数据集中的数据访问： 图中的节点根据用户是否满足附加数据要求进行着色。仅数据集支持此选项。

此外，您可以在图中选择一个节点并打开右侧边栏中的 访问信息 以查找与 检查访问 面板中进行管理。

Data Lineage 示例

在此示例中，虚拟用户 Jane Doe 满足管道中其中一个数据集的访问要求，但不满足另一个。在 访问信息 面板中，我们可以看到 Jane 不满足 Fruit 数据集的访问要求，因为她没有访问所需标记（Common: Food).

我们还可以看到 Jane 不满足管道中任何数据集的附加数据要求。在 访问信息 面板中检查时，我们可以看到 Jane 不满足 Derived Fruit 数据集的附加数据要求，因为她没有访问继承的标记（Common: Food).

有关更多信息，请参阅 Data Lineage 文档.
