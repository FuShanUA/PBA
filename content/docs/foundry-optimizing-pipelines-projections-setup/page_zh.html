设置投影

以下信息将指导您完成启用、配置和构建数据集投影的过程。

为您的数据集启用投影

Noho 是一项管理数据集投影的服务。通过在数据集的 schema 中进行配置，可以启用投影 noho: true.

您可以在从转换写入数据集时配置数据集的 schema，也可以在 详情 标签页。

导航到 Projections 标签页

您将看到一个 投影 标签页（当查看的数据集在其 schema 中已配置 noho: true 且您拥有编辑该数据集的权限时）。

打开创建对话框

选择 Add new projection.

选择投影列

选择要包含在投影中的列。

在大多数情况下， All columns 是合适的。但是，如果您知道查询只会选择其中一部分列，则可以对此进行调整。

选择投影类型

选择投影的类型。

  • 对于 过滤优化的投影时，请选择要用于过滤的列。
    • 顺序很重要，因为投影只会加速对此列表前缀的查询。
  • 对于 连接优化的投影时，请选择连接列和桶数量。
    • 只有在此确切列集合上的连接才会被加速。
    • 当与显式分桶的数据集或另一个连接优化的数据集进行连接时，桶数量必须相等。

创建投影

选择 Create projection 按钮。

投影现已存在，但尚不包含任何数据。这由投影旁边的红色警告图标表示。要在查询中使用投影，必须先按照后续步骤对其进行构建。

设置构建

为了让您更好地控制资源使用，维护投影的内部构建不会自动调度；您需要显式设置一个构建。

首先，切换开关 Enable projection builds on the current branch。这允许构建在 current 分支的情况下对分支执行操作。

然后，为构建配置一个调度。如果您想在不同的分支上调度构建，则需要导航到该分支并重复此过程。

（可选）构建投影

如果您不想等待构建，可以通过选择以下选项来显式构建投影 构建 按钮。

现在，等待构建完成。在投影更新之前，可能会运行多次构建。 Projection Build Status 行旁边的绿色对勾表示投影现已完全更新。
