拖放单个对象和已保存的探索

您可以将单个对象或从已保存的探索（最多可包含 5,000 个对象）派生的对象集从 Foundry 拖放到 Gaia 地图上。

要将单个对象从 Foundry 拖放到您的 Gaia 地图：

  1. 在 Foundry 中启动 Object Explorer。
  2. 搜索对象类型。
  3. 从 结果 面板（位于 Object Explorer 屏幕最右侧）中选择一个对象。
  4. 选择 Object Explorer 屏幕左上角的对象图标。
  5. 将对象从 Foundry 拖放到 Gaia 地图上的任意位置 - 您现在可以在地图上以及左侧面板中查看该对象，它属于名为 Dropped Object Layer [Date] [Time].

在将对象集从 Foundry 拖放到 Gaia 地图之前，您必须先从现有对象类型创建版本化对象集。要创建版本化对象集：

  1. 在 Foundry 中启动 Object Explorer。
  2. 搜索并选择您的对象类型。
  3. 选择 结果 在 Object Explorer 屏幕顶部功能区的中间。
  4. 使用搜索栏按对象类型的属性筛选要添加到对象集中的对象，以缩小选择范围。
    • 举个例子，如果你的对象类型捕获由 name 属性定义的位置，你可以通过输入以下内容来筛选 location 对象的选定范围 where name is location_1 or where name is location_2 并按下 enter or return 键盘上的按键。
    • 你还可以通过在对象类型的 Object Explorer 视图中的图表和图形上直接应用对象筛选器来筛选对象。
  5. 选择蓝色的 保存 按钮，将你选择的对象保存为 探索 在公共项目中。

创建并保存带版本的对象集作为 Exploration 后，你可以按照以下步骤将其拖放到你的 Gaia 地图上：

  1. 选择 新建 Exploration 从 Object Explorer 视图的顶部功能区。
  2. 根据你创建对象集时为其指定的名称进行搜索并选择。该对象集也可能显示在 Object Explorer 搜索栏下方的 我的 Exploration 和列表.
  3. 选择 Object Explorer 屏幕左上角的对象集图标。
  4. 将对象集从 Foundry 拖出并放到 Gaia 地图上的任意位置。对象将单独显示在地图上，并自动嵌套在左侧面板中以你保存的 Exploration 命名的搜索图层中。

当你向 Gaia 地图添加对象时——无论是单独添加还是作为来自 Object Explorer 或 Workshop 的对象集的一部分——如果地图上已存在某些对象，Gaia 会通知你。你可以选择包含或排除重复项。即使重复对象的父地图图层处于折叠状态，Gaia 也会将其高亮显示。

除了 Foundry 的 Object Explorer 之外，你还可以从 Gotham 中的对象视图将对象拖放到 Gaia 地图上。

在 Gaia 中搜索您的 Foundry 对象类型

你可以在 数据源 部分（位于 Gaia 左侧面板）中搜索 Foundry 对象类型。此外，在将对象添加到地图之前，你还可以对其应用几何和时间筛选器。要从 Gaia 搜索 Foundry 对象类型：

  1. 选择 数据来源 在地图的左侧面板中。
  2. 根据对象类型在 Foundry 中的名称进行搜索，它将显示在左侧面板底部的 ,其中显示地图上各对象类型的对象数量。下方,每种属性类型各有一个部分,涵盖地图上存在的所有对象类型。面板顶部的筛选框允许您将结果筛选为名称匹配的属性。.
  3. 选择 搜索对象 （位于你的对象类型旁边）。
  4. 选择要添加到地图的对象，并在对象搜索面板的顶部功能区中应用任何必要的几何筛选器。
    • All 会将发现的对象类型中的所有对象添加到你的地图。
    • View 只会添加当前地图视图中可用的对象。
    • Draw 会将对象添加到地图中，这些对象位于你可以在搜索面板中配置和添加的绘制形状内。
    • Select 使你能够从当前活动地图中选择一个项目。
  5. 应用任何必要的时间筛选器，以加载在 Static range or Rolling window.
  6. （可选）开启 实时更新搜索结果，该功能将根据与你筛选参数匹配的新创建对象，每 30 秒更新一次你的对象或对象集。
  7. 在以下位置为你的对象搜索输入名称 搜索标题 并选择 搜索.
  • 如果在加载搜索结果后无法查看某个对象，则应验证该对象类型是否包含指示其位置的地理空间属性，例如 geopoint or geoshape.
  • 如果你在 Foundry 中完成先决条件类型映射后仍无法在 Gotham 中搜索你的对象，则你的 Gotham 注册中可能未启用 Foundry 搜索功能。请联系 Palantir Support 以获取启用此功能的帮助。
