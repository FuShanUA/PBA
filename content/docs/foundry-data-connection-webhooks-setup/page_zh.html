教程

本教程假设您将使用可通过开放互联网访问的系统的 REST API。

创建源

首先导航到 数据连接 并选择 数据源 标签页。然后，选择 新建源 和 REST API.

使用源编辑器填写您要连接的 REST API 的配置详细信息。有关 REST API 源类型的更多详细信息，请参阅 源类型参考.

该源旨在包含建立连接所需的最少密钥和连接详细信息集。在使用此源配置各个 webhook 时，您将有机会添加其他请求详细信息，包括相对路径、查询参数、标头和正文内容。

其他源类型

某些其他源类型也支持 webhook。有关更多详细信息，请查看特定源类型的 参考页面 。

某些源（包括 SAP、旧版 Salesforce 和旧版 magritte-rest-v2）使用更复杂的任务配置。有关配置 webhook 任务的更多信息，请参阅 webhook 参考.

创建 webhook

创建源后，选择 Webhook 选项卡并选择 新建 webhook.

按照 新建 webhook 向导 中的步骤创建一个发出外部请求的 webhook。下面的示例展示了向 POST 我们示例域上的 /api/v1/createItem 端点发出的请求。正文构造为 Raw JSON，在本例中配置为接受两个字符串输入参数。

复制 webhook

如果您想创建一个与现有 webhook 配置相似的新 webhook（例如，同一 API 上的两个相似端点），可以选择复制现有的 webhook。要复制 webhook，请从源概览的 操作 菜单打开 Webhook 标签页，或使用 webhook 页面上的 操作 按钮，然后选择 复制.

配置选项

  1. 为 webhook 输入名称，并根据需要添加描述。
  2. （可选）开启 函数配置 以将 webhook 发布为函数。为您的函数提供本体论和 API 名称。请参阅 Webhook 函数参考 了解详情。
  3. 选择您在上一步教程中创建的源。如果您是从源页面直接进入向导的，该源将被预先选中。
  4. 添加您想在外部请求中使用的任何输入参数。
  5. 填写请求配置中所有必需的部分。您可以在路径、查询参数、标头和正文配置部分中引用输入参数。
  6. （可选）设置您想要应用于 webhook 的任何 限制 。请参阅 限制参考 了解详情。
  7. 选择 创建 以完成 webhook 的创建。

直接从 cURL 命令导入

此外，您也可以通过直接导入 cURL 命令来创建请求 Call。为此，请选择 Import from cURL 选项，并将您的 cURL 命令输入到 TextArea 中。如果您的 cURL 使用了支持的选项且关联的域已存在于 Source 中，则选择 Import cURL 将创建一个新的 Call。

测试 webhook

保存后，您可以运行测试请求来检查配置是否正确。您可以随时通过使用 Test Connection 侧面板来完成此操作。

发出测试请求后，您可以使用响应来解析输出参数。有关输出参数的更多信息，请参阅 webhooks 参考页面.
