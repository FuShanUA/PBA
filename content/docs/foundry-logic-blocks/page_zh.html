块

AIP Logic 函数由块组成，每个块接受一个输入、返回一个输出，并构成与数据的一次独立交互。块有许多不同的用途，例如读取或写入本体论、执行计算、聚合数据、调用其他函数或与 LLM 交互。一个块的输出可以在后续块中使用，从而通过将块串联起来构建复杂的操作。

块有许多不同的类型；下面介绍一些常用的块：

  • 使用 LLM
  • 应用操作
  • 执行函数
  • 循环
  • 条件语句
  • 创建变量

使用 LLM

“ 使用 LLM ”模块是 AIP Logic 的核心，使您能够利用 LLM 来定义逻辑模块。逻辑模块由 提示词、 工具，以及 输出。Use LLM 区块支持平台上的任何可用 LLM，这符合 Palantir 的 k-LLM 理念。

要一次性替换多个 Logic 函数中使用的模型，您可以 在 Workflow Lineage 中批量替换模型。

提示词

提示词是用自然语言编写的 LLM 指令。我们建议从最重要的信息开始（例如 LLM 应完成任务的概述），然后是 LLM 所需的数据，以及关于何时使用 工具的指导。在编写提示词时，请记住，LLM 只能访问你明确提供的内容。

在下面的示例提示词中，我们使用 LLM 从以往的电子邮件往来中搜索信息，以便为寻求解决方案的客户提供回复。该示例提示词以任务概述开头：

你是我的投诉处理助手。查找描述的事件与输入邮件中所述事件类似的其他邮件。只查看邮件正文。根据以往行之有效的做法确定最佳解决方案。只返回一条解决方案建议，不要列出每封邮件中的发现。

然后，提示词会指定要查询的数据（在本例中为投诉邮件，表示为 complaint 对象）。输入提示词后，您可以通过键入“/”并选择分析中可用的一个或多个变量，让 LLM 访问您的输入内容；在下面的截图中，我们选择了邮件对象的属性。

工具

工具是 AIP Logic 让 LLM 读取或写入本体论并支持现实世界运营的机制。AIP Logic 利用三类由本体论驱动的工具——数据、逻辑和操作——来有效地查询数据、执行逻辑运算并安全地采取操作。请注意，LLM 无法直接访问工具；LLM 只能请求使用工具，而这些工具调用随后由 AIP Logic 在调用用户的权限范围内执行。

可用的工具包括：

  • 应用操作
  • 调用函数
  • 查询对象
  • 计算器工具

应用操作

该 应用操作 工具使 LLM 能够使用 操作 来编辑本体论。您可以描述 LLM 应在何时使用所提供的操作。有关如何对本体论应用更改的更多详情，请查阅 使用逻辑函数编辑本体论。

调用函数

该 调用函数 工具允许您选择可供 LLM 调用的函数。函数可以在代码仓库中定义，也可以是现有的 Logic 函数。

查询对象

该 查询对象 工具指定 LLM 可访问的对象类型。您可以根据需要添加任意数量的对象类型，并指定 LLM 可访问哪些属性，以使查询更加节省 token。

计算器工具

该 计算器工具 使您能够使用 LLM 执行精确的数学计算。

应用操作

该 应用操作 块使您能够确定性地调用操作，而无需通过 LLM 块。该块让您能够精确控制参数的填写方式，并加快执行速度。在此示例中，我们可以调用一个为特定事件赋予优先级状态的操作。

需要从操作中调用 AIP Logic 函数，才能将编辑内容写回本体论。除非从操作中执行 Logic 函数，否则本体论不会被编辑，即使该函数包含一个 应用操作 块。

执行函数

该 执行函数 块允许您调用 Foundry 中已有的其他函数，例如 TypeScript、Python，甚至其他 Logic 函数。Execute 块使您能够复用已实现预期任务的现有函数，而无需自行重新实现逻辑。在下面的示例中，Execute 块用于利用语义搜索函数的输出，帮助返回类似事件的解决方案文本。

条件块

条件块是评估条件并根据该条件为真还是为假来执行不同路径的块。可以将条件块视为传统编程中的“if-then-else”语句：

  • 如果 条件为真， 则 执行一组操作
  • 否则 执行一组不同的操作

当您需要以不同的方式处理数据或根据特定条件运行不同的操作时，条件语句非常有用。

分支返回值

在 "then" 或 "else" 部分中，您可以定义条件分支应返回的值。共有 3 个选项：

  1. 定义路径： 创建要执行的块序列。
  2. 返回变量： 返回现有变量或前一个块的输出。
  3. 不执行操作： 将该分支配置为不执行任何操作（当另一个分支正在返回本体论编辑时可用）。

注意：您可以在条件块中配置多个分支，每个分支都有其自己的“when”条件和“then”操作。

使用条件分支时，所有分支必须返回一致的输出。例如，如果一个分支输出字符串，则所有其他分支（包括 else 分支）也必须输出字符串。如果分支通过操作返回本体论编辑，则所有分支必须要么运行操作，要么明确指定“不执行操作”。

循环

循环使 AIP Logic 能够遍历集合，并对每个元素运行转换和/或操作。循环适用于对元素列表执行操作，或对多个对象进行本体论编辑。

循环的输出可以是值列表或本体论编辑。

在循环中，您可以通过 element 变量访问当前元素，并通过 index 变量访问当前元素的索引（如有需要，可以重命名这些变量）。

循环仅适用于列表（List），而不适用于数组（Array）。如果选择数组作为循环的输入，系统会自动在循环之前插入一个 "Array to List"（数组转列表）块，先将输入转换为列表，再将其传入循环。

注意：如果循环中不包含任何操作，则每次迭代都将并行执行。

创建变量

该 创建变量 块会创建一个可在后续块中使用的变量。该变量可以是以下类型：array（数组）、boolean（布尔值）、date（日期）、double（双精度浮点数）、float（单精度浮点数）、integer（整数）、long（长整数）、object（对象）、short（短整数）、string（字符串）或 timestamp（时间戳）。
