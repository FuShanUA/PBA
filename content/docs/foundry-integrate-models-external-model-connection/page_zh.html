集成外部托管的模型

Batch deployments 目前不支持外部托管的模型。 配置一个使用外部模型的 Python 转换。

在 Foundry 中封装外部托管模型的好处

Foundry 支持创建一个模型，作为托管在第三方应用程序、服务或模型提供商（如 Azure Machine Learning、Amazon SageMaker、OpenAI 或 Vertex AI）中的模型的代理。这使得在 Foundry 之外开发的模型能够轻松地被 Foundry 用户、管道和运营应用程序使用。

一旦集成了外部托管的模型，Foundry 会提供以下功能：

  • 完整的版本控制、细粒度的权限管理以及受治理的模型血缘。
  • 通过以下方式进行模型管理和实时部署： 《建模目标》.
  • 与 Foundry 本体论绑定，支持通过以下方式进行运营化： 模型上的函数 以及假设情景分析。

上述功能可能与您的使用场景无关。例如，如果您不打算在 Foundry 中管理或评估模型，或者您有一个不应绑定到本体论中特定对象类型的通用模型（例如大型语言模型），那么在外部托管您的模型可能不是合适的解决方案。相反，您可能希望直接从 Foundry 调用模型的外部 API，而不是将其封装为 Foundry 模型。

在这些情况下，凭据可以在以下位置定义： 数据连接源 中，而不是按照下文所述作为模型定义的一部分进行配置。此源及相关的 出站策略覆盖 随后可以导入到 外部转换 中以启用批量推理，以及在您的 函数 中进行实时推理。

关于语言模型的其他注意事项

对于语言模型，请考虑 注册您的模型 到平台中，以便在 AIP 工具 中使用，例如 AIP 逻辑 或 Pipeline Builder 的 Use LLM 节点。这可以通过在 Foundry 中使用外部托管的模型来实现，但创建模型并非必需。 已注册模型页面 介绍了如何在 AIP 中注册您自己的模型。

创建与外部托管模型的自定义连接

要创建与外部托管模型的连接，您需要准备以下内容：

  • 用于连接到外部托管模型的连接详细信息。
  • A 模型适配器 ，它告诉 Foundry 如何创建与外部托管模型的连接并与之交互。
  • A Foundry 出站策略 ，允许 Foundry 连接到外部托管的模型。

您可以按照以下步骤创建一个代理外部托管模型的模型。

1. 创建新模型

第一步是创建一个新模型。可以通过在 Foundry 项目中选择 +New > Model 来完成，也可以通过新建或现有的 建模目标。在建模目标中，选择 添加模型.

下面的截图展示了在 Foundry 项目中通过选择以下方式创建新模型： +New > Model.

下面的截图展示了通过建模目标并选择以下方式创建新模型： 添加模型 （位于外部模型界面中）。

2. 选择添加模型的方法

选择 连接外部托管的模型，然后选择 属性，然后选择.

3. 设置出站策略

选择 自定义连接 作为外部托管模型的源，并在下拉菜单中选择一个 出口策略 在下拉菜单中，然后选择 属性，然后选择.

出站策略允许 Foundry 项目或工件将数据从 Foundry 发送到外部系统。出站策略可能由您组织的 Foundry 安全模型控制。如果您拥有所需权限，可以在 Control Panel 应用程序.

4. 配置模型适配器

为此模型选择模型适配器。模型适配器应配置为接受一个 ExternalModelContext 在加载时初始化与外部托管模型的连接。有关更多信息，请参阅有关如何创建 模型适配器，查看 示例模型适配器 （针对外部模型），并查看 API 定义 ，相对于 ExternalModelContext.

5. 配置模型连接

为您的自定义模型连接定义模型连接详细信息。连接配置包含两个组件：

  • URL （可选）：这是提供给模型适配器的基础 URL。它应为模型推理函数的 URL。
  • 连接配置 （可选）：连接配置不会被加密，并且可以在平台中随模型元数据一起查看。此组件可以存储特定的配置详细信息，例如模型名称、推理参数或阈值。

6. 配置凭据

为您的自定义模型连接定义凭据配置，然后选择 属性，然后选择.

  • 凭据配置 （可选）：凭据将被加密并与模型一起安全存储。这些凭据将在模型加载时被解密并提供给模型适配器。有权访问该模型的用户将能够使用此模型执行推理，而无论其对外部模型的底层访问权限如何。选择 属性，然后选择 以继续保存您的模型详细信息。

7. 配置详细信息并提交模型

输入此模型的模型保存位置、模型名称和版本说明。这将定义您模型的 Foundry 名称、位置和元数据。

如果您正在从建模目标创建此模型，请选择 提交 以创建您的模型并将此模型提交到您的建模目标。在建模目标中，您可以导航到该模型、查看配置并选择性地更新关联的凭据。

如果您正在 Foundry 项目中创建此模型，请选择 完成 以保存此模型。

from transforms.api import transform, Input, Output
from palantir_models.transforms import ModelInput
from transforms.external.systems import EgressPolicy, use_external_systems, ExportControl


@use_external_systems(
    export_control=ExportControl(markings=['<MARKING_ID>']),
    egress=EgressPolicy('ri.resource-policy-manager.<RID>')
)
@transform(
    output=Output("/Foundry/Externally Hosted Models/data/inferences"),
    model=ModelInput("/Foundry/Externally Hosted Models/models/Regression Model"),
    foundry_input=Input("/Foundry/Externally Hosted Models/data/regression_features_input")
)
def compute(
        export_control,
        egress,
        output,
        model,
        foundry_input
    ):
    input_df = foundry_input.pandas()
    results = model.transform(input_df)
    output.write_pandas(results.df_out)

import palantir_models as pm

import json
import pandas as pd


class ExampleModelAdapter(pm.ExternalModelAdapter):

    def __init__(self, url, credentials_map, configuration_map):
        # Extract model configuration from "Connection configuration" map
        model_name = configuration_map['model_name']
        model_parameter = configuration_map['model_parameter']

        # Extract model credentials from "Credentials configuration" map
        secret_key = credentials_map['secret_key']

        # Initiate http client at model load time
        self.client = ExampleClient(url, model_name, model_parameter, secret_key)

    @classmethod
    def init_external(cls, external_context: pm.ExternalContext) -> "pm.ExternalModelAdapter":
        return cls(
            url=external_context.base_url,
            credentials_map=external_context.resolved_credentials,
            configuration_map=external_context.connection_config,
        )

    @classmethod
    def api(cls):
        inputs = {"df_in": pm.Pandas()}
        outputs = {"df_out": pm.Pandas()}
        return inputs, outputs

    def predict(self, df_in):
        payload = {
            "instances": df_in.apply(lambda row: {"features": row.tolist()}, axis=1).tolist()
        }

        # Client is an example and will need to be edited to connect to your external model
        response = self.client.predict(
            ContentType="application/json",
            Body=json.dumps(payload)
        )

        result = response["Body"].read().decode()
        predictions = pd.DataFrame(json.loads(result)["predictions"])
        return predictions
