设置直接连接

此文档已过时，仅保留供历史参考。有关连接设置的最新指南，请参阅我们关于 设置源.

如果您尝试连接到可通过 Internet 访问的数据源（例如 REST API、SFTP 服务器或 Azure 存储账户），您可以配置直接连接，从而无需 设置代理。使用直接连接具有以下多项优势：

  • 无需预配、配置和管理代理及其主机
  • 避免通过您的网络路由 Internet 到 Foundry 的流量
  • 提供出色的正常运行时间和性能，因为基于云的同步不依赖于代理软件包或其主机

直接连接依赖于 Foundry 的容器基础设施，该基础设施仅在 Palantir 托管的 SaaS 平台中可用。因此，基于云的直接连接在您的环境中可能不可用。

如果您有兴趣配置基于云的直接连接，请按照以下步骤操作：

  1. 为您的注册配置网络出口策略 。
  2. 预配凭据 以连接到您的数据源。
  3. 在 Data Connection 中创建源.

配置网络策略

您必须拥有 信息安全官 角色才能在您的 注册 上配置网络出口。如果您没有配置出口的权限，请联系您的 Palantir 代表寻求帮助。

直方图 信息安全官 角色可在以下内容的注册权限部分找到 控制面板。管理员需要拥有 Enrollment 管理员 角色才能看到此部分。

要配置网络策略，请使用以下方式导航到控制面板 其他 Workshop 链接，位于 工作区侧边栏。在控制面板中，选择 选项卡,该选项卡位于 Control Panel 的 （位于侧边栏中）。如果您看不到此选项，请联系您的 Palantir 代表以完成以下步骤。

通过选择以下方式添加网络策略 添加网络策略。添加描述和连接详细信息，类似于您联系 Palantir 时提供的详细信息：

  • 如果您通过 HTTP(S) 连接，请添加数据源的 DNS 主机名
  • 如果您需要使用非 HTTP 协议，请添加 CIDR 地址和端口

保持默认的 可选 策略类型选择，然后选择 添加网络策略.

预配凭据

在大多数情况下，Foundry 需要经授权的凭据（例如用户名和密码）才能访问源。最佳做法是使用专供 Foundry 使用的服务账户。

按照您组织内部关于建立服务账户的任何指南和流程，为源预配服务账户。在继续下一步之前，请记下凭据。

在 Data Connection 中创建源

完成上述步骤后，您可以继续在 Data Connection 中创建源：

  • 登录后，导航到 数据连接 选项。 侧边栏.
  • 选择 数据源 tab.
  • 选择 新建源 （位于右上角）。
  • 选择 源类型 （对应于您的数据源）。
  • 选择 直接连接，然后选择 继续 （位于右下角）。

将源保存到项目中

接下来，为您的源命名并选择一个 项目 来放置它。我们通常建议为每个源创建一个新项目，因为这是对源自该源的数据集进行权限管理的最简洁方式。请查阅 源权限最佳实践 以了解更多信息。有关如何在 Foundry 中端到端构建数据管道的完整指南，请参阅 推荐的项目结构文档.

选择 创建源并继续 （位于右下角）。

选择您的网络策略

在下一页上，选择您 之前配置的 网络策略，方法是点击 使用现有策略 并搜索策略名称。

配置源并添加驱动程序

添加有关如何连接到您的源的详细信息。这些详细信息取决于您所使用的 源类型 ，通常包括基本凭据，例如连接 URL、云提供商区域等。

JDBC 数据源 可能需要添加并选择 驱动程序 以连接到您的数据源。虽然许多驱动程序随 Foundry 开箱即用，但您可能需要上传并选择驱动程序才能继续。

添加凭据

添加您 预先配置的 凭据，以允许直接连接访问您的数据。

保存并继续

选择 保存 （位于右下角）以完成直接连接的设置。数据源完全设置好后，您可以继续 设置同步 以将数据导入 Foundry。
