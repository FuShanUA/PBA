Widget overview

Widgets are the building blocks of a Workshop module. This page lists many commonly used widgets by category, not every widget. Scenario and mobile widgets are documented in the Scenarios and Mobile sections. Widgets that have a dedicated reference page link to it; widgets without one are described here only. Learn how to configure widgets and connect them with variables.

Core display widgets

  • Object Table: Renders an object set in a tabular display with each object displayed as a row.
  • Object List: Renders an object set in a list display with each object displayed as a card.
  • Object View: Renders Object Explorer’s object view for a single object.
  • Property List: Displays a configurable list of properties from a given object set.
  • Links: Renders the link types and linked objects of an object set in expandable and collapsible sections.
  • Object Set Title: Displays a summary of a given object set as a title.
  • Header text: Renders two rows of text optimized for display in a header.

Visualization widgets

  • Pie Chart: Visualizes object data as a pie or donut chart.
  • XY Chart: Visualizes an object set as a configurable bar, line, or scatter chart with support for multiple series, axes, and styling options.
  • Vega Chart: Lets users create fully customizable charts using the Vega and Vega-Lite grammars.
  • Waterfall Chart: Visualizes object data as a waterfall chart.
  • Map: Displays an object set as a configurable, interactive geospatial visualization.
  • Map [Legacy]: The previous version of the Map widget. Use the Map widget when building a new module.
  • Free-form Analysis: Enables users to independently investigate object data with flexibility, within the framework of the Workshop application.
  • Time Series Analysis: Lets users investigate time series data within a Workshop application.
  • Gantt Chart: Displays objects with time properties in a horizontal timeline view.
  • Image Annotation: Lets users annotate images by drawing rectangles around areas of interest.
  • Linked Compass Resources: Renders Compass resources linked to an object.
  • Markdown: Displays formatted text and can optionally configure object references in text.
  • Media Preview: Renders a preview of media, such as a PNG, JPEG, or PDF file, from a URL, Foundry RID, or Base64-encoded string. It can also display Base64-encoded visualizations returned by functions.
  • Spreadsheet Display: Displays spreadsheet files from a media reference property on an object, so users can view, search, and annotate spreadsheet content.
  • Video Display: Displays video from a media reference property on an object.
  • Audio and Transcription Display: Plays back audio from a media reference property on an object, and displays transcriptions from an object set of transcription segments.
  • Metric Card: Renders a configurable card to highlight key metrics.
  • PDF Viewer: Renders PDF files with keyword search capabilities.
  • Pivot Table: Enables the dynamic grouping and aggregation of object data and then displays this aggregated data in tabular form.
  • Resource List: Displays various types of Foundry resources.
  • Status Tracker: Displays statuses of a process on a timeline.
  • Timeline: Visualizes temporal data, rendering objects as events in a timeline.
  • Action Log Timeline: Renders object action logs in a temporal view.
  • Data Freshness: Displays the Last Updated timestamp of the most recent index time for configured object types and datasources.
  • Edit History: Displays the user edits made to an object's properties after edit history tracking is enabled for the object type.

Filtering widgets

Many filtering widgets output an object set filter variable, which captures the current filter state and can be applied to object set variables or reused in widget configurations. Learn more about configuring default filters and filter value extraction in Object set filter variables.

  • Filter List: Renders property filters as histograms, distribution charts, data pickers, and type-ahead selectors. You can also filter by object type or keyword.
  • Object Dropdown: Allows the user to select a single object from a list of objects.
  • Object Selector: Allows the user to select multiple objects from a list of objects.
  • String Selector: Allows the user to select a string from a list of strings.
  • Checkbox: Provides a checkbox that the user can toggle on or off.
  • Date and Time Picker: Allows the user to enter a single date and time value.
  • Date Input: Allows the user to enter a single date or date range.
  • Text Input: Allows the user to input text.
  • Numeric Input: Allows the user to enter a numeric value.
  • Exploration Filter Pills: Allows the user to visualize and apply filters to an object set.
  • Exploration Search Bar: Allows the user to visualize and apply filters to an object set through property types and linked object types.
  • Prominent Terms: Displays the total number of matches on an object set for prominently used terms.
  • User Select: Allows the user to select one or more Palantir users from a dropdown menu.

Event-triggering and navigational widgets

  • Button Group: Triggers actions, Workshop events, URLs, object set exports, function-backed exports, and media exports from configurable buttons.
  • Comments: Enables collaboration in a Workshop module.
  • Media Uploader: Uploads media files to Foundry and triggers actions using uploaded files as input.
  • Audio Recorder: Records audio and uploads recordings to a media reference property or a specified media set.
  • Tabs: Displays tabs that trigger Workshop events to navigate between pages and layers of a module.
  • Stepper: Guides users through a multi-step workflow and highlights the step that matches the selected tab or current page.
  • Inline Action: Lets users create, modify, or delete objects or links through forms or tables configured on Ontology action types.

Other widgets, such as the Metric Card, also support triggering commands, actions, or events through specific configuration options like the Interactive metric setting.

AIP widgets

  • AIP Analyst: Provides AI-powered analysis capabilities directly in a Workshop module.
  • AIP Chatbot: Provides interactive assistants equipped with enterprise-specific information and tools in operational workflows.
  • AIP Generated Content: Displays the response from an AIP Logic function or streams the response from an LLM.

Observability widgets

  • Observability Chart: Plots platform telemetry for a single resource over time, such as execution counts, latency, and compute utilization.

Embed Foundry applications

  • Iframe: Embeds a custom widget URL or Slate application via iframe.
  • Derived series: Embeds a derived series management space to create, update, and discover derived series.
  • Map Application Template: Displays an existing geospatial template created in the Map application.
  • Notepad - Embedded Document: Embeds a configured Notepad document in either read-only or edit mode.
  • Quiver Dashboard: Renders an embedded dashboard constructed and published from Quiver.
  • Vertex Graph: Displays an existing graph, graph template, or diagram created in the Vertex application.
  • Workshop: Embedded Module: Embeds another Workshop module as a widget.

Cross-application interactivity

  • App Pairing: Connects supported Palantir platform applications to a Workshop module, so that changes in one application update the paired module, and vice versa.
