小组件概览

小组件是 Workshop 模块的构建块。本页面按类别列出了许多常用小组件，但并非全部小组件。场景和移动端小组件记录在 场景 和 移动设备 部分中。拥有专门参考页面的小组件会链接到该页面；没有专门页面的小组件仅在此处描述。了解如何 配置小组件并将其与变量连接.

核心显示组件

  • 对象表格: 以表格形式渲染对象集，每个对象显示为一行。
  • 对象列表: 以列表形式渲染对象集，每个对象显示为一张卡片。
  • 对象视图: 为单个对象渲染对象浏览器的对象视图。
  • 属性列表: 显示来自给定对象集的可配置属性列表。
  • 关联: 在可展开和折叠的区块中渲染对象集的链接类型及链接对象。
  • 对象集标题: 将给定对象集的摘要显示为标题。
  • 标题文本： 渲染两行文本，针对在标题栏中的显示进行了优化。

可视化微件

  • 饼图: 将对象数据可视化为饼图或环形图。
  • XY 图表: 将对象集可视化为可配置的柱状图、折线图或散点图，并支持多系列、多坐标轴和样式选项。
  • Vega 图表: 允许用户使用 Vega 和 Vega-Lite 语法创建完全可自定义的图表。
  • 瀑布图： 将对象数据可视化为瀑布图。
  • 映射: 将对象集显示为可配置的交互式地理空间可视化。
  • Map [Legacy]: 地图小组件的旧版本。构建新模块时请使用 映射 小组件。
  • 《自由形式分析》：: 使用户能够在 Workshop 应用程序的框架内灵活地独立调查对象数据。
  • 时间序列分析: 允许用户在 Workshop 应用程序中调查时间序列数据。
  • 甘特图: 在水平时间线视图中显示具有时间属性的对象。
  • 《图像标注》：: 允许用户通过在感兴趣的区域周围绘制矩形来标注图像。
  • 关联的 Compass 资源: 渲染链接到对象的 Compass 资源。
  • 《Markdown》：: 显示格式化文本，并可选择在文本中配置对象引用。
  • 《媒体预览》：: 从 URL、Foundry RID 或 Base64 编码字符串渲染媒体预览，例如 PNG、JPEG 或 PDF 文件。它还可以显示由函数返回的 Base64 编码的可视化内容。
  • 电子表格显示: 显示对象上媒体引用属性中的电子表格文件，以便用户查看、搜索和标注电子表格内容。
  • 视频显示: 显示对象上媒体引用属性中的视频。
  • 音频和转录显示: 播放对象上媒体引用属性中的音频，并显示来自转录片段对象集的转录内容。
  • 指标卡片（Metric Card）: 渲染可配置的卡片以突出显示关键指标。
  • PDF 查看器: 渲染 PDF 文件并提供关键字搜索功能。
  • 《数据透视表》：: 支持对对象数据进行动态分组和聚合，并以表格形式显示这些聚合数据。
  • 《资源列表》：: 显示各种类型的 Foundry 资源。
  • 状态追踪器： 在时间线上显示流程的状态。
  • 时间轴: 可视化时间数据，将对象作为事件渲染在时间线中。
  • 《操作日志时间线》：: 在时间视图中渲染对象操作日志。
  • 数据新鲜度: 显示 最近更新时间 已配置对象类型和数据源的最近索引时间的时间戳。
  • 编辑历史: 在为对象类型启用编辑历史跟踪后，显示对对象属性所做的用户编辑。

筛选小部件

许多筛选控件会输出对象集筛选器变量，该变量捕获当前筛选状态，并可应用于对象集变量或在控件配置中重复使用。了解有关配置默认筛选器和筛选值提取的更多信息，请参阅 对象集筛选器变量.

  • 过滤列表: 将属性筛选器渲染为直方图、分布图、数据选择器和预先输入选择器。您还可以按对象类型或关键字进行筛选。
  • 对象下拉列表: 允许用户从对象列表中选择单个对象。
  • 对象选择器： 允许用户从对象列表中选择多个对象。
  • 字符串选择器: 允许用户从字符串列表中选择一个字符串。
  • 复选框： 提供一个用户可以打开或关闭的复选框。
  • 日期和时间选择器: 允许用户输入单个日期和时间值。
  • 日期输入： 允许用户输入单个日期或日期范围。
  • 文本输入: 允许用户输入文本。
  • 数字输入: 允许用户输入数值。
  • 探索筛选标签: 允许用户可视化对象集并对其应用筛选器。
  • 探索搜索栏: 允许用户通过属性类型和关联对象类型可视化对象集并对其应用筛选器。
  • 突出术语: 显示对象集上常用术语的匹配总数。
  • 用户选择: 允许用户从下拉菜单中选择一个或多个 Palantir 用户。

事件触发和导航小部件

  • 按钮组: 通过可配置的按钮触发操作、Workshop 事件、URL、对象集导出、函数支持的导出和媒体导出。
  • 评论: 在 Workshop 模块中实现协同协作。
  • 媒体上传器: 将媒体文件上传到 Foundry，并使用上传的文件作为输入触发操作。
  • 音频录制器: 录制音频并将录音上传到媒体引用属性或指定的媒体集。
  • 选项卡: 显示用于触发 Workshop 事件的选项卡，以便在模块的页面和图层之间导航。
  • 《步骤条》：: 引导用户完成多步骤工作流，并突出显示与所选选项卡或当前页面匹配的步骤。
  • 内联操作: 允许用户通过在 Ontology 操作类型上配置的表单或表格来创建、修改或删除对象或关联。

其他组件（例如 指标卡片（Metric Card））也支持通过特定配置选项（如 交互式指标 设置，对分支的合并保留实质性的控制权。

AIP 小组件

  • AIP Analyst: 直接在 Workshop 模块中提供 AI 驱动的分析功能。
  • AIP 聊天机器人: 在操作工作流中提供配备企业特定信息和工具的交互式助手。
  • AIP Generated Content: 显示 AIP Logic 函数的响应，或流式传输来自 LLM 的响应。

可观测性小组件

  • 可观测性图表: 绘制单个资源随时间变化的平台遥测数据，例如执行次数、延迟和计算利用率。

嵌入 Foundry 应用程序

  • Iframe: 通过 iframe 嵌入自定义小部件 URL 或 Slate 应用程序。
  • 派生序列: 嵌入派生序列管理空间，用于创建、更新和发现派生序列。
  • 地图应用模板: 显示在 Map 应用程序中创建的现有地理空间模板。
  • Notepad - 嵌入式文档: 以只读或编辑模式嵌入已配置的 Notepad 文档。
  • Quiver 仪表板: 渲染从 Quiver 构建并发布的嵌入式仪表板。
  • Vertex 图谱: 显示在 Vertex 应用程序中创建的现有图、图模板或图表。
  • Workshop：嵌入式模块: 将另一个 Workshop 模块作为小部件嵌入。

跨应用程序交互

  • 应用配对: 将受支持的 Palantir 平台应用程序连接到 Workshop 模块，使一个应用程序中的更改更新配对的模块，反之亦然。
