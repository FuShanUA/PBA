from pyspark.sql import functions as F

舍入

  • F.bround(x, scale=0)

    • 将列 x 的给定值舍入到 scale 位小数,使用 HALF_EVEN 舍入模式,前提是 scale >= 0 ;或舍入到整数部分,前提是 scale < 0。

  • F.ceil(x)

    • 对给定值进行向上取整。

  • F.round(column, scale=0)

  • F.floor(column)

对数

  • F.log(arg1, arg2=None)
  • F.log10(column)
  • F.log1p(column)

随机

  • F.rand(seed=None)

    • 从均匀分布 [0.0, 1.0] 中抽取的独立同分布 (i.i.d.) 样本

  • F.randn(seed=None)

    • 从标准正态分布中抽取的独立同分布 (i.i.d.) 样本

三角函数

  • F.cos(x)

    • 计算数值列 x 的余弦。

  • F.sin(x)

  • F.tan(x)

  • F.acos(x)

    • 计算数值列 x 的反余弦;返回的角度范围为 [0.0, π]。 cos-1(x)

  • F.asin(x)

    • 计算数值列 x 的反正弦;返回的角度范围为 [-π/2, π/2]。 sin-1(x)

  • F.atan(x)

    • 计算数值列 x 的反正切。 tan-1(x)

  • F.atan2(x, y)

    • 返回角度 theta,该角度来自直角坐标 (x, y) (由列 x、y 表示)到极坐标的转换 (r, theta)。

  • F.cosh(x)

    • 计算列 x 的双曲余弦。

  • F.sinh(x)

  • F.tanh(x)

角度

  • F.degrees(column)
  • F.radians(column)

  • F.abs(x)
    • 绝对值,作用于 x
  • F.cbrt(x)
    • 计算 立方根 ,作用于给定值。
  • F.exp(x)
  • F.expm1(x)
  • F.factorial(x)
  • F.greatest(*cols)
  • F.hypot(x, y)
  • F.least(*cols)
  • F.pow(x, y)
    • x 的幂运算,指数为 y
  • F.rint(column)
  • F.signum(column)
