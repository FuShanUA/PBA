配置由受限视图支撑的对象类型

受限视图（RV） 为本体论数据启用行级访问控制。与简单地授予对整个数据集或某一类型的所有对象的访问权限相比，这可以实现更细粒度的访问控制。

受限视图与数据集类似，但会限制对 数据集中的特定行 的访问。受限视图在数据集级别进行配置，本体论对象会继承受限视图策略中定义的细粒度权限。

使用受限视图支撑对象类型

使用受限视图支撑对象类型将控制用户可以查看的具体对象。例如，如果用户满足某个策略的要求，并且可以查看受限视图中的特定行，那么他们就能够查看相应的本体论对象。

要查看由数据集支撑的对象类型的对象，您还必须能够查看该数据集。

  • 要查看由 Object Storage v1（Phonograph）中受限视图支撑的对象类型的对象，您必须能够查看该对象类型本身；您不一定需要查看受限视图。相反，您只需满足该受限视图的 标记 及其针对该行的读取策略。
  • 在 Object Storage v2 (OSv2) 中，您必须能够查看受限视图，才能看到由该受限视图支撑的对象类型的对象。

在限制用户查看特定对象时，请在 Ontology Manager 中仅选择受限视图作为对象类型的支撑数据源。

索引的策略限制

对于 OSv2 对象类型，以下限制适用于受限视图数据源策略，并且 对象和属性安全策略:

  • 策略比较操作数必须使用 String or Boolean 基本类型，包括数组元素。
  • 不支持排序比较（小于、小于或等于、大于以及大于或等于）。

当策略未引用时间戳、日期和数值对象属性时，可以对这些属性进行索引。

本体论编辑

对本体论对象的访问可能会受到用户编辑的影响，因为可以编辑对象安全设置中引用的属性。在这种情况下，用户可能能够查看支撑受限视图中的某一行，但无法查看本体论中相应的对象，反之亦然。

安全配置

直方图 数据源 选项卡将显示其他配置选项，用于编辑 细粒度策略。该 细粒度策略 部分允许您配置编辑此类型对象的权限。

编辑的细粒度策略只能为使用 Object Storage v1 且未选择 仅允许通过操作进行编辑 选项的对象类型进行配置。对于所有其他对象类型，编辑权限通过编辑对象类型的操作类型来控制。 详细了解操作权限。

您可以配置这些策略，以适应您希望用户仅根据属性（如对象的某个属性）查看或编辑特定对象的情况。例如，您可能只希望来自 Europe （见 region 列）的用户查看和编辑欧洲对象，这可能与受限视图的策略不同。

有三种策略可以定义谁可以访问对象上的属性：

  • 读取： 此策略定义谁可以查看受限视图上的所有属性。使用上面的示例，这可能是比较 region 列与用户属性中的内容（Europe）的策略，以确定用户可以查看哪些对象。
  • 编辑属性： 此策略定义了允许谁更新为回写配置的、且未在任何细粒度权限策略定义中使用的属性。使用上面的示例，此策略将控制谁可以编辑 name 属性，但不控制谁可以编辑 region 属性，因为 region 属性在策略中被使用。
  • 编辑策略属性： 此策略定义了允许谁更新为回写配置的、且同时在任何细粒度权限策略定义中使用的属性。使用上面的示例，此策略将控制谁可以编辑 region property.

如果在对象类型注册到 Object Storage v1 (Phonograph) 之后更改了视图策略，则必须通过 更新 按钮（位于对象类型的 Phonograph 部分中）更新注册 数据源 “代码” 本体论管理器。如果未更新注册，则可能会根据之前注册的策略使受限视图的最新数据可用。默认情况下，Object Storage v2 中提供自动策略传播。
