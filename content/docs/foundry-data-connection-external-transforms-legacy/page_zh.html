外部转换 [旧版]

直接引用出口策略、凭据值和出口管制标记的转换处于 旧版 开发阶段，预计不会再进行额外开发。仍提供完整支持。我们建议使用 基于源的外部转换。

您可以在代码仓库中使用 Python 转换，直接在代码中连接外部系统。例如，如果您需要与外部系统交互的复杂逻辑，或想要使用第三方提供的软件开发工具包（SDK），这将非常有用。我们建议使用外部转换，通过 REST API 执行定时同步和导出。

基于源的外部转换 是使用代码连接外部系统的受支持方式。与本页面所述的旧版外部转换相比，其优势包括：连接无法从互联网访问的系统、无需更改代码即可轮换凭据，以及使用 虚拟表。如需了解更多优势以及这两种方法之间的工作流程差异，请查阅 外部转换与旧版外部转换的对比。

在继续之前，请务必创建 Python 转换代码仓库 并按照以下说明进行配置。

连接到外部系统的转换只有当它们 不 使用 Foundry 输入时，才能使用代码仓库中的 Preview 辅助工具进行预览。

允许代码仓库设置外部连接

本节介绍使用外部转换所需的配置。

外部转换只能与运行在 SECURE 模式下的代码仓库一起使用。其他安全模式需要联系 Palantir 支持团队才能使用。

启用外部系统交互

在您刚创建的代码仓库中，具有 Information Security Officer 角色的 Foundry 用户应导航至 仓库 设置 选项卡，然后导航至 仓库 > 外部系统 以开启以下选项： 允许从此仓库访问外部系统。

该 Information Security Officer 是 Foundry 中的默认角色；用户可以被授予 Information Security Officer 角色，该操作在 控制面板 的 注册权限下进行。

启用数据集输入

具有 Information Security Officer 角色的 Foundry 用户可以选择性地允许在外部转换中使用输入。

当数据集被用作可以与外部系统通信的转换的输入时，该数据集中的任何数据都有可能离开 Foundry。具有 Information Security Officer 角色应为此仓库中允许用作外部转换输入的任何数据选择相应的安全标记和组织标记集。

例如，您可能有一个带有 标记（位于 Palantir 组织）的数据集。要在外部转换中使用此数据集，信息安全官必须同时添加 标记和 Palantir 组织，具体是在代码仓库设置的步骤三 中完成。

添加 transforms-external-systems 库

为代码仓库启用外部系统交互后，您必须添加 transforms-external-systems 库，该库可在 侧边栏选项卡 （位于代码界面左侧）中找到。

如果您在 VS Code 工作区中使用 Python 转换仓库，请导航至 选项卡（位于顶部导航栏中），然后选择 以访问 和 设置。

配置出站和凭据

添加库后，您可以访问一个新的 选项卡，该选项卡位于代码界面左侧。

在此标签页中，您可以设置您的代码所调用的任何端点所需的网络出口策略，并添加供仓库使用的凭据（如有必要）。请注意，并非所有端点都需要凭据。

使用网络出口策略和凭据

添加出口策略

Foundry 要求从用户编写的代码发起的所有连接在访问外部目标时都必须绑定到网络出口策略。网络出口策略允许从用户编写的代码发起的、经许可的连接访问 Foundry 之外的目标。

如果您的租户已启用自助出口功能，您可以 创建和管理出口策略 （在 Control Panel 中进行）。如果您的连接需要添加新的网络路由，请联系您的信息安全官或 Palantir 支持团队，并提供出口策略的详细信息。

如果您的 Foundry 实例未启用自助出口功能，请联系 Palantir 支持团队，以便在内部启用该端点并配置策略。

在将出口策略用于外部转换（无论是全局还是非全局）之前，您必须从 Egress 标签页导入这些策略，该标签页位于代码仓库的 Egress and Credentials 面板中。该 Egress 标签页会展示您具有权限的所有策略，并将其分为三类：

  • 已导入： 当前代码仓库中可供您的转换使用的网络出口策略。
  • 可导入： 需要向网络出口策略添加项目引用。
  • 需要访问请求： 您对该策略拥有 Viewer 权限，但没有 Importer 权限。

在此标签页中，搜索所需的网络出口策略。如果该策略被标记为 Importable，请选中它，然后选择 将出口策略导入项目。

如果所需的网络出口策略被标记为 Access request required，则一名具有 Information Security Officer 角色的 Foundry 用户应授予您 Importer 角色。该操作在控制面板的 网络出口 页面中进行。要授予 Importer 角色，信息安全官应首先选择所需的网络策略，然后选择 操作 > 管理共享 ，将您添加为该策略的 Importer 。

添加凭据

如果您的外部系统需要授权凭据（用户名和密码）才能获得访问权限，您可以使用 凭据 标签页（位于 出口和凭据 侧面板中）来添加一组凭据，并在您的代码中使用它们。

如果源端点已建立允许列表流程，则您必须将 Foundry IP 地址加入允许列表。请联系 Palantir 支持团队获取所需的 IP 地址。

传递证书

如果您的外部系统要求传入 SSL/TLS 证书，您可以将该证书存储在凭证中，然后在外部转换逻辑中使用该凭证。

编写外部转换逻辑

现在，您可以编写向外部系统写入数据的 Python 数据转换了。我们建议先查看关于如何 编写 Python 数据转换 的基本说明，然后再编写外部转换。

从 transforms.external.systems 包中导入所需的 use_external_systems 装饰器以及 EgressPolicy 和 Credential （如果需要）输入。从 transforms-api中导入转换装饰器和 Output。如果您的外部源不需要凭证，则无需将 Credential 输入添加到您的逻辑中。

from transforms.external.systems import EgressPolicy, use_external_systems, Credential
import requests


@use_external_systems(

    creds=Credential('<credential RID>')

@transform(

)
def compute(egress, output, creds):

    response = requests.get('https://<API URL>', auth=(username, password), timeout=10).text

        f.write(response)

添加 Foundry 数据集输入

在某些情况下，编写用于处理 Foundry 输入数据的外部转换可能会很有用。例如，您可能希望查询 API 来为表格数据集中的每一行收集额外的元数据。或者，您可能有一个需要将 Foundry 数据镜像到外部软件系统的工作流。

此类情况被视为 受出口控制的 工作流，因为它们开启了将安全的 Foundry 数据导出到另一个安全保证未知且数据溯源被切断的系统的可能性。转换开发人员有责任评估导出工作流的安全性，并确保离开 Foundry 的数据在外部系统中得到妥善保护。Foundry 提供了治理控制，确保开发人员能够清晰地编码安全意图，并且信息安全官可以审计与外部系统交互的工作流的范围和意图。

要选择启用导出控制，请将 ExportControl 应用于您的外部转换。该 ExportControl 接受用于导出的安全标记和组织 ID 列表。这样，如果上游数据带有额外的安全标记，转换任务将必然失败。要扩展代码仓库中支持的可导出标记集合，必须由信息安全官调整代码仓库设置。请导航至 设置 > 代码仓库 选项卡。然后，在 外部系统 部分中，选择 允许在此代码仓库中将 Foundry 输入用于外部系统 （第 3 步下方）。

安全标记和组织均以标记的形式实现，应在导出控制配置中一并列出。有关缺失标记的错误消息可能指的是安全标记或组织。

例如，您可以使用导出外部转换来下载 Foundry 数据集中指定的图像 URL：

from transforms.api import transform, Input, Output
from transforms.external.systems import use_external_systems, ExportControl, EgressPolicy
from pyspark.sql.functions import udf
import shutil

@use_external_systems(
    export_control=ExportControl(markings=['<marking ID>']),
    egress=EgressPolicy(<policy RID>),
)
@transform(
    images_output=Output('/path/to/output/dataset'),
    image_urls=Input('/path/to/input/dataset'),
)
def compute(export_control, egress, images_output, image_urls):

    @udf
    def download(name, url):
        response = requests.get(url, stream=True)
        with images_output.filesystem().open(f'{name}.jpg', mode='wb') as out_file:
            shutil.copyfileobj(response.raw, out_file)

        return True

    image_urls.dataframe().withColumn('downloaded', download(col('Name'), col('Url'))).collect()

from transforms.api import transform
from transforms.mediasets import MediaSetOutput
from transforms.external.systems import use_external_systems
import requests
import tempfile


@use_external_systems()
@transform(
    media_set_output=MediaSetOutput('/path/to/output/media/set')
)
def compute(media_set_output):
    response = requests.get('https://<API URL>')
    fname = 'my_image.png'

    with tempfile.NamedTemporaryFile() as tmp:
        tmp.write(response.content)
        tmp.flush()

        with open(tmp.name, 'rb') as tmp_read:
            media_set_output.put_media_item(tmp_read, path=fname)

from transforms.external.systems import EgressPolicy, use_external_systems, Credential
from transforms.api import transform, Output
from mapbox import Static


@use_external_systems(
    egress=EgressPolicy('<policy RID>'),
    mapbox_creds=Credential('<credential RID>')
)
@transform(
    output=Output('/Users/username/datasets/example_mapbox'),
)
def compute(output, egress, mapbox_creds):
    mapbox_access_token = mapbox_creds.get('mapbox-token')
    client = Static(access_token=mapbox_access_token)
    london = client.image('mapbox.satellite', lat=51.5072, lon=0.0, z=12)
    with output.filesystem().open('london.log', 'w') as f:
        f.write(f'response code: {london.status_code}')
    with open('london.png', 'wb') as f:
        f.flush()
    with output.filesystem().open('london.png', 'wb') as f:
        f.write(london.content)

from transforms.api import transform, Input, Output, configure, incremental
from pyspark.sql import Row
from pyspark.sql import functions as F
from pyspark.sql import types as T
import logging
import time
import json
log = logging.getLogger(__name__)

@incremental()
@configure(profile=["KUBERNETES_NO_EXECUTORS"])
@use_external_systems(
    egress=EgressPolicy('<policy RID>'),
    creds=Credential('<credential RID>')
)
@transform(
    out=Output("<output_dataset>"),
)
def compute(ctx, out, egress, creds):
    # Get the filesystem of the output dataset to read and write files onto it:
    out_fs = out.filesystem()
    state_filename = "_state.json" # Prepend with "_" to consider it a hidden file and not show it in the dataset preview.
    state = {"last_seen" : 0} # Some arbitrary starting state

    # Try to fetch the state from the output dataset:
    try:
        with out_fs.open(state_filename, mode='r') as state_file:
            data = json.load(state_file)
            # Validate the fetched state:
            state = data
            logging.info(f"state file found, continuing from : {data}")

    except Exception as e:
        logging.warn("state file not found, starting over from default state")


    # Here, write logic to make API Calls, create custom processing, generate a dataframe and save it, or save files directly to the output dataset.
    # For example purposes, the following generates a dataframe and saves it on the output dataset (as if we fetched some data through API calls):
    out.write_dataframe(get_dataframe(ctx))
    # Update the state for next iteration:
    state["last_seen"] = 1 + state["last_seen"]

    # Save the new state on the output dataset:
    with out_fs.open(state_filename, "w") as state_file:
        json.dump(state, state_file)


# This function generates a dataframe for example purposes. This step would not be relevant in a production implementation:
def get_dataframe(ctx):
    # Define the schema of the dataframe:
    schema = T.StructType([
        T.StructField("name", T.StringType(), True),
        T.StructField("age", T.IntegerType(), True),
        T.StructField("city", T.StringType(), True)
    ])

    # Create a list of rows:
    data = [("Alice", 25, "New York"),
            ("Bob", 30, "San Francisco"),
            ("Charlie", 35, "London")]

    # Create a PySpark dataframe:
    df = ctx.spark_session.createDataFrame(data, schema=schema)
