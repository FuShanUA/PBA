从 Data Connection 将数据同步到 Iceberg 表

Beta

同步到 Iceberg 表的操作目前处于 Beta 开发阶段。

您可以使用 Data Connection 将数据从受支持的外部数据源直接同步到 Foundry Iceberg 表。

支持的数据源

当前支持的数据源类型如下：

  • 自定义 JDBC
  • Microsoft SQL Server
  • Oracle
  • PostgreSQL
  • Snowflake

Iceberg 同步仅在以下数据源上受支持： Foundry 工作进程 运行时。从私有网络摄取数据时，配置 agent 代理出站策略 是推荐的做法。

写入模式

Foundry 同时支持非增量和增量 批量同步 至 Iceberg，适用于这些源类型。您可以在源概览页面中创建新的 Iceberg 同步。

配置同步时，您可以在以下写入模式选项中进行选择：

  • "覆盖"写入模式： 用新数据覆盖 Iceberg 表中的所有行，并生成一个 overwrite Iceberg 快照。
  • "追加"写入模式： 将新行追加到 Iceberg 表中，同时保留所有现有数据，并生成一个 append Iceberg 快照。
  • "更新"写入模式： 更新 Iceberg 表中与主键标识符列匹配的现有行，并为之前未出现的标识符插入新行。这会生成一个 overwrite Iceberg 快照，仅覆盖受影响的数据文件。

还支持使用基于通配符的自定义 SQL 语句执行更加定制化的增量导入。请参阅 增量同步文档 以了解更多详情。

Iceberg 同步不支持架构演变。这意味着，在修改源表架构后重新运行同步将会失败。在这种情况下，请考虑基于更新后的表架构创建新的同步。
