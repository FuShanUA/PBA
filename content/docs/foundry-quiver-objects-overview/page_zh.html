Quiver 原生支持许多不同的卡片，用于筛选、转换和可视化对象数据。分析对象数据的第一步是将对象添加到分析中。

本文档介绍了将对象数据添加到 Quiver 分析中的几种不同方法。在熟悉了添加对象之后，您可以了解更多关于 筛选 和 对关联对象进行周边搜索.

添加对象类型

将对象数据添加到 Quiver 分析中最简单、最常见的方法是添加给定对象类型的所有对象。您可以通过选择 添加对象 （位于屏幕中央）来完成此操作。您可以随时通过选择 对象 按钮，位于 添加数据 已应用标签 分析顶部栏.

选择 添加对象 来添加其他对象数据，这将打开 Quiver 的 搜索栏 以浏览本体论中的对象类型。对象类型搜索菜单支持对对象类型进行关键字搜索。在左侧，搜索菜单显示任何 对象类型组的标签页，以及用于常用对象类型和时间序列对象类型的标签页。

选择一个对象类型将其添加到您的分析中。添加对象类型后，选择 X （位于右上角）以关闭搜索栏。现在您的分析中应该有一个对象集卡片，其中包含所选类型的所有对象。添加的卡片会显示集合中对象的表格预览，并在右上角显示所有对象的计数。

添加单个对象

您也可以将单个对象添加到您的分析中。为此，在打开对象类型搜索菜单后，在菜单顶部切换到 对象 标签页。在 对象 标签页上，您可以在特定对象类型中搜索单个对象，可以通过属性筛选器或关键字进行搜索。在结果表中选择一个对象会将该对象作为单个对象卡片添加到您的分析中。

从 Object Explorer 打开对象

对象分析通常从 Object Explorer 中的探索开始。如果您在 Object Explorer 中开始了工作流程，可以通过选择探索右上角的 在 Quiver 中分析 按钮，无缝过渡到 Quiver。这将创建一个新的 Quiver 分析，其中包含您探索中的对象。

导入已保存的对象集

将对象集添加到 Quiver 分析的另一种方法是导入已保存的对象集。为此，请选择对象类型或对象搜索菜单右上角的 导入对象集 按钮。这将打开文件选择器，允许您选择一个已保存的对象集添加到您的分析中。

使用 URL 预加载对象

还可以使用 URL 为新分析预加载定义的对象或对象集。可以使用以下端点来完成此操作：

  • 对象（Object）: /quiver/views/load/object/<object_rid>
  • 对象集： /quiver/views/load/object-set/<object_set_rid>
  • 对象类型： /quiver/view/load/object-type/<object_type_id>
