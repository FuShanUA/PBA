设置 webhook

前提条件

  1. 完成入门教程，以了解如何设置基本操作。
  2. 设置 webhook，以创建与外部系统的连接。在创建 webhook 之前，您可能需要与拥有连接源系统权限的系统管理员协作。

步骤

在下面的示例中，假设我们有一个名为 修改工单优先级 的 webhook，它接受一个 priority 字符串值并将其发送到外部系统。

导航到您的操作，选择 Logic 选项卡，选择 Add new rule，然后选择 Webhook。

默认情况下，新添加的 webhook 会被配置为副作用；这使 webhook 在 Foundry 中编辑对象之后运行。或者，选择回写，让 webhook 在对象编辑之前运行。

在下方的菜单中，选择您想要执行的 webhook。在本示例中，我们选择修改工单优先级 webhook。如果需要，您可以选择该 webhook 的其他版本。

接下来，根据操作参数配置 webhook 输入参数。默认情况下，系统会为每个 webhook 输入生成一个新的操作参数，除非已存在同名的操作参数，在这种情况下，现有参数会被自动配置。在本示例中，我们将名为 priority 的 webhook 输入映射到名为 Ticket Priority 的现有操作参数。

选择添加 webhook以完成向操作添加 webhook 规则。请注意，添加 webhook 后，Rules 部分会显示回写将在修改对象之前发生。

您可能需要删除在添加 webhook 时自动生成且现已不再使用的任何参数。

选择右上角的保存以保存对操作的更改。现在，应用操作时，将在对 Foundry 中的对象应用任何更改之前向外部系统发出请求。
