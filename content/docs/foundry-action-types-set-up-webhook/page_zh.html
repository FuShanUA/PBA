设置 webhook

前提条件

  1. 完成 如何开始使用 教程，了解如何设置基本操作。
  2. 设置一个 TypeScript v1 函数无法直接从源获取 OAuth 令牌。要在 TypeScript v1 函数中通过 OAuth 2.0 API 进行身份验证，请将调用封装在 以创建与外部系统的连接。在创建 webhook 之前，您可能需要与拥有连接源系统权限的系统管理员合作。

步骤

在下面的示例中，假设我们有一个名为 Modify ticket priority 的 webhook，它接受一个 priority 字符串值并将其发送到外部系统。

导航到您的操作，选择 逻辑 标签页中，选择 添加新规则，然后选择 Webhook.

默认情况下，新添加的 webhook 被配置为 副作用；这使得 webhook 在 Foundry 中编辑 在 对象时运行。或者，选择 回写 以使 webhook 在 然后 对象编辑时运行。

在下面的菜单中，选择您要执行的 webhook。在本示例中，我们选择 Modify ticket priority webhook。如果需要，您可以选择 webhook 的其他版本。

接下来，根据操作参数配置 webhook 输入参数。默认情况下，系统会为每个 webhook 输入生成一个新的操作参数，除非已存在同名的操作参数，在这种情况下，现有参数将被自动配置。在本示例中，我们将名为 priority 的 webhook 输入映射到名为 Ticket Priority.

选择 添加 webhook 的现有操作参数。以完成向您的操作添加 webhook 规则。添加 webhook 后，规则部分会显示回写将在对象被修改之前发生。

您可能需要删除在添加 webhook 时创建的、现已不再使用的任何自动生成的参数。

选择 保存 （位于右上角）以将对操作的更改保存。现在，当应用操作时，对外部系统的请求将在对 Foundry 中对象的任何更改应用之前发出。
