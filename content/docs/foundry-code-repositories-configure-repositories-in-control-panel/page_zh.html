在控制面板中配置代码仓库设置

您可以在以下位置配置许多组织范围内的代码仓库设置 控制面板。要修改这些设置，您需要 User Experience Administrator 角色.

可用设置

  • 使用 Palantir Visual Studio Code 扩展进行本地开发： 启用此设置后，您组织中的用户将能够克隆代码仓库，并使用 适用于 VS Code 的 Palantir 扩展在本地进行处理。此设置默认启用。
  • 通过 Palantir Visual Studio Code 扩展进行安全流式预览： 启用此设置后，您组织中的用户可以使用 安全流式传输 预览实现在本地预览数据集。本地数据集预览涉及将数据集的部分内容流式传输到用户机器的系统内存中。此设置默认启用。
  • 使用 Palantir MCP 服务器进行本地开发： 在本地 IDE（如 Claude Code、GitHub Copilot 或 Cursor）中使用 Palantir MCP，可让外部 AI 系统使用所配置用户令牌的权限，通过 AI 友好的 API 端点读取 Foundry 中的数据和元数据并进行交互。一旦数据通过 Palantir MCP 被外部系统访问，其使用治理责任将从 Palantir 转移到该外部系统。数据安全性将取决于您与该外部系统的关系。使用 Palantir MCP 并不意味着将使用 Palantir 的 AI 模型；AI 模型提供方由您所连接的外部系统决定（例如，GitHub Copilot 由 Microsoft 提供，Cursor 由 Cursor 提供）。

要在本地进行预览，用户必须通过上述本地预览设置获得允许，并且拥有对所预览输入执行 Download 操作的权限。这些是特权操作，允许用户在本地下载整个数据集，应谨慎授予。在无法向用户授予此权限的情况下，VS Code 开发者体验仍可通过 代码工作区获得，该方式可保证更严格的数据控制。更多详情，请参阅 安全注意事项 （针对本地预览）。

您可以了解更多关于本地开发、 预览和调试 Python 转换以及使用 Palantir 扩展 找到有关 Foundry Salesforce 连接器当前版本 (V2) 和 V1 版本的更新内容。
