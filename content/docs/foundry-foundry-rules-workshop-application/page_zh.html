Workshop 应用程序

标准的 Foundry Rules 应用程序是一个 Workshop 应用程序，通常包含两个页面：规则编辑器页面和提案审阅器页面。

  • 该 规则编辑器 页面用于创建、编辑和删除规则。
  • 该 提案审阅器 页面用于审阅和批准/拒绝规则提案。

另有一个 规则查看器 小组件，可用于创建只读的规则逻辑查看器。

规则编辑器

规则编辑器页面的用途是支持规则的创建和维护。下面的屏幕截图展示了一个示例规则编辑器页面，其中包含以下小组件（编号用于标识）：

  1. 筛选器列表： 一组用于筛选所显示规则的筛选器。
  2. 对象列表： 由筛选器列表 (1) 筛选的现有规则列表，可从中选择规则来填充规则编辑器 (3)。
  3. 规则编辑器： 一个接受 Foundry 操作以创建提案并根据参数自动生成所需字段的小组件。规则编辑器中显示的表单元素由本体论中为创建新规则而配置的操作决定。



在创建或编辑 规则之后， 提交更改 按钮用于创建新的 提案。该提案可在 Proposal Reviewer 页面上查看和审核。

Proposal Reviewer

Proposal Reviewer 页面允许对规则提案进行审核以及批准/拒绝。与 Rule Editor 一样，它包含三个部分（在下方截图中以数字标识）：

  1. 筛选列表： 一组筛选器，用于更改所显示的提案 (1)。
  2. 对象列表： 经过筛选列表筛选的提案列表 (2)，可以选择其中的提案以填充到 Proposal Reviewer (3) 中。
  3. Proposal Reviewer： 一个可接受 Foundry 操作以批准或拒绝提案的小部件。该小部件会显示已编辑属性的差异，其中更改后的值以黄色显示，先前的值以淡灰色显示。当用户批准提案时，所做的编辑将被应用，并且提案将被创建、编辑或删除（具体取决于提案）。
