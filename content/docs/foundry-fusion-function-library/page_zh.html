函数库

核心函数

这些函数是 Fusion 的默认方法。

abs(value: number): number

计算数字的绝对值（即不带符号的数字）。

例如： abs(-2) 将返回值 2。

参数

  • value: NUMBER

acos(value: number): number

返回数字的反余弦值。反余弦值是指其余弦值等于该数字的角度。返回的角度以弧度表示，范围为 0 到 Π。

例如： acos(1) 将返回值 0。

参数

  • value: NUMBER

all_token_match(value: any): same_as_first_argument

返回一个 value 带有修饰符的标记，允许以分词方式执行搜索和查找，要求所有词项都出现在结果中的某处。

参数

  • value: ANY

any_token_match(value: any): same_as_first_argument

返回一个 value 带有修饰符的标记，允许以分词方式执行搜索和查找，要求至少一个词项出现在结果中的某处。

参数

  • value: ANY

array([arg: any, ...]): string

创建一个包含所有输入属性的数组。生成的数组将被[方括号]包围。所有属性将列在单个单元格中。

例如： array('John', 'Mary', 'Richard') 结果为数组 [ John, Mary, Richard ]

注意：如果属性是字符串，则需要用'单引号'括起来。

参数

  • arg: ANY

array_concat([array: array, ...]): array

将所有输入数组合并为一个单一数组。

例如：假设单元格 A1 中有数组 [1,2,3]，单元格 A2 中有数组 [4,5,6]。 Array_concat(A1,A2) 将返回新数组 [1,2,3,4,5,6]。

参数

  • array: ARRAY

array_contains(array: array, value: any): boolean

检查 array 是否包含 value。如果数组包含该值，函数返回 true。

例如：如果数组 [ John, Mary, Richard ] 位于单元格 E7 中，实现 array_contains(E7, 'Richard') 将在数组中检查值 'Richard'。在这种情况下，函数将返回 True。如果我们输入 array_contains(E7, 'Louise')，函数将返回 False。

参数

  • array: ARRAY
  • value: ANY

array_difference(array: array, [differenceArrays: array, ...]): array

返回第一个数组中不在其他任何数组中出现的所有唯一元素，不保证顺序。

例如：给定数组 [ John, Mary, Richard, Richard ] 位于单元格 E7 中，而数组 [ John, Mary, Bob] 位于单元格 E8 中， array_difference(E7, E8) 将返回 [ Richard ].

参数

  • array: ARRAY
  • differenceArrays: ARRAY

array_distinct([value: any, ...]): array

返回一个仅包含输入参数中不同值的数组。

例如： array_distinct(array(3, 2, 1), 4, array(1, 2)) 将返回 array(3, 1, 4, 2)。

注意：值的顺序不会被保留。此外，附加到值上的任何标记（例如 fuzzy 或 exact）都将被丢弃。

参数

  • value: ANY

array_flatten([arg: any, ...]): string

创建一个包含所有输入属性的数组。生成的数组将被[方括号]包围。所有属性将列在单个单元格中。 此函数类似于 array，但会折叠单元格区域和数组，按从左到右、逐行的顺序取值。区域中的空值和错误将被忽略。

例如： array_flatten('John', A1:B2) 其中 A1 = array('Zoe', 'Charles'), A2 = 'Mary' 和 B2 = 'Richard'，结果为数组 [ John, Zoe, Charles, Mary, Richard ]。请注意，单元格 A1 中的数组被展平到输出中，而空单元格 B1 被跳过了。

注意：如果属性是字符串，则需要用'单引号'括起来。

参数

  • arg: ANY

（从 1 开始索引）的元素。例如：如果数组 [ John, Mary, Richard ] 位于单元格 E7 中，我们想验证位置 3 上的属性是哪个，可以使用 array_get_at_index(E7, 3)。这将返回 Richard，即数组中的第三个属性。

参数

参数

array_slice(array: array, start_index: number, [end_index: number]): array

切片 array 从 start_index （含）开始，到 end_index （含）结束，并返回一个数组。

例如：如果数组 [ John, Mary, Richard ] 位于单元格 E7 中， array_slice(E7, 1, 2) 将返回 [ John, Mary ]。 如果 start_index 为零或大于数组的长度，则返回一个空数组。例如 array_slice(E7, 5, 2) → []。如果 start_index 为负数，则将其用作从数组末尾开始的偏移量。例如 array_slice(E7, -2, 2) → [ Mary ]。如果 end_index 为零或大于数组的长度，则提取从该位置到数组末尾的子数组。例如 array_slice(E7, 2, 5) → [ Mary, Richard ]。如果 end_index 为负数，则将其用作从数组末尾开始的偏移量。例如 array_slice(E7, 1, -2) → [ John, Mary ].

参数

  • array: ARRAY
  • start_index: NUMBER
  • end_index: NUMBER

array_sort(array: array, [sort_direction: any]): array

返回给定数组按升序排序的结果。可以指定 FALSE 或 'DESC' 作为第二个参数以按降序排序。

例如：如果数组 [ 3, 4, 1 ] 位于单元格 E7 中，我们想对该数组进行排序，可以编写： array_sort(E7, 'DESC')。该函数将返回数组 [ 4, 3, 1 ]。

参数

  • array: ARRAY
  • sort_direction: ANY

array_zip([array: array, ...]): array

创建一个由分组元素组成的数组，其中第一个分组包含给定数组的第一个元素，第二个分组包含给定数组的第二个元素，依此类推。结果数组的长度将等于最短输入数组的长度。

例如：如果您有数组 ['a', 'b', 'c'] 位于单元格 A1 中，数组 [1, 2, 3] 位于单元格 A2 中。 array_zip(A1, A2) 将返回新数组 [ [ 'a', '1' ], [ 'b', '2' ], [ 'c', '3' ] ].

参数

  • array: ARRAY

asin(value: number): number

返回数字的反正弦值。反正弦是指正弦值为该数字的角度。返回的角度以弧度表示，范围为 -Π/2 到 Π/2。

例如： asin(-1) 将返回值 -Π/2。

参数

  • value: NUMBER

atan(value: number): number

返回数字的反正切值。反正切是指正切值为该数字的角度。返回的角度以弧度表示，范围为 -Π/2 到 Π/2。

例如： atan(0) 将返回值 0。

参数

  • value: NUMBER

atan2(x_num: number, y_num: number): number

返回指定的 x 坐标和 y 坐标的反正切值。反正切是从 x 轴到包含原点 (0, 0) 和坐标为 (x_num, y_num) 的点的直线之间的角度。该角度以弧度表示，介于 -Π 和 Π 之间（不包括 -Π）。

例如： atan2(1,1) 将返回值 0.785398163。

参数

  • x_num: NUMBER
  • y_num: NUMBER
