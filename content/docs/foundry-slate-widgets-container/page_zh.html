容器

容器 Widget 类别包含以下 Widget：

  • 基本
  • 对话框
  • Flex
  • 重复
  • 水平拆分
  • 垂直拆分
  • 选项卡式

下表提供了容器 Widget 可用属性的使用详情。表格后附有若干示例。

属性

属性描述类型必需修改者
flex指定容器是否应自动对齐并在子 Widget 之间分配空间。boolean是直接编辑
flexOptions用于配置子 Widget 对齐方式的选项。booleanNo直接编辑
lazyRenderingEnabled指定是否仅渲染可见的子 Widget。boolean是直接编辑
selectedTabIndex当前显示的选项卡的索引。number是直接编辑
tabContents存储每个选项卡中 Widget 的内部数组。{children: IWidgetModel[]}[]是用户交互
tabTitles每个选项卡的标题。ITabTitle[]是直接编辑
titlesEnabled指定是否在容器顶部显示可点击的选项卡标题。boolean是直接编辑
scrollingEnabled指定是否可以滚动溢出的内容。boolean是直接编辑
splitDirection指定容器的拆分方向。number是直接编辑
splitMovableInConsumerMode指定拆分容器在消费者模式下是否可调整大小boolean是直接编辑
splitPanel一个内部值，表示容器是否为拆分容器中的面板。boolean是用户交互
repeat指定内容重复的次数numberNo直接编辑
repeating指定容器是否为重复容器。boolean是直接编辑
previewRepeating指定是否预览重复容器。booleanNo直接编辑

ITabTitle

属性描述类型必需修改者
title此选项卡的标题。string是直接编辑

IFlexOptions

属性描述类型必需修改者
justifyContent指定子 Widget 在主轴上的布局方式。默认值为：水平 Flex 容器为 Left，垂直 Flex 容器为 Top。string是直接编辑
flexDirection指定子 Widget 对齐所依据的主轴。默认值为 Horizontally。string是直接编辑
flexWrap指定子 Widget 是否可以溢出到多行。默认值为未选中。string是直接编辑

用法

将 Widget 拖入或拖出容器可将其添加到当前选定的选项卡或从中移除。tabContents 属性在原始选项卡中不受支持，不应手动编辑，也不会响应用户交互的更改。

对话框 Widget

下表提供了对话框 Widget 可用属性的使用详情。表格后附有若干示例。

属性

属性描述类型必需修改者
title对话框的标题。stringNo直接编辑
canEscapeKeyClose使用 Escape 键时关闭对话框。boolean是直接编辑
canOutsideClickClose用户点击遮罩背景时关闭对话框。boolean是直接编辑

操作

操作名称描述
close触发此操作将关闭对话框。
open触发此操作会导致对话框打开。

事件

事件名称描述
closed当对话框完全关闭时会触发此事件。
opened当对话框完全打开时会触发此事件。

常用 CSS

您可以使用以下 CSS 来设置容器的背景颜色和边框：

2

4
5
sl-app-container {
  background: lightgrey;
  border-left:none;
  border-right:none;
}

尽管 sl-app-container 选择器和 background 属性可以正确设置容器小部件的背景颜色和边框，但请使用 div.canvas-body 选择器和 background-color 属性在您的本地样式表中调整 Slate 应用程序画布的颜色和边框。在下面的示例中，我们使用样式编辑器自定义了 Slate 画布、容器小部件和条形图的颜色：
