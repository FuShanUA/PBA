Foundry 中的 SQL

Foundry 支持对表格数据和本体论对象类型进行 SQL 查询，并使用通用的 Spark SQL 方言。SQL 可通过专用的 SQL Studio 应用程序、嵌入的 SQL 控制台 （在受支持的应用程序中），以及通过……连接的外部 SQL 客户端 Arrow Flight SQL 或 SQL REST API。

功能

Foundry 中的 SQL 使您能够：

  • 查询表格数据 使用由以下引擎提供支持的标准 SQL 语法 Furnace 引擎。
  • 查询本体论对象类型 使用 本体论 SQL 引擎。
  • 创建和修改表格数据。
  • 编写本体论 SQL 函数（测试版）。
  • 运行快速上下文查询 使用嵌入式 SQL 控制台。
  • 连接外部工具 以使用 SQL 查询 Foundry 资源。

入门

要在 Foundry 中开始使用 SQL：

  1. 学习基础知识 ，请查阅 SQL 方言 文档，以及 Furnace 和 本体论 SQL 引擎概览。
  2. 打开 SQL 编辑器，可通过 SQL Studio 或受支持应用程序中嵌入的 SQL 控制台。
  3. 运行您的第一个查询 参考 SQL 示例。
  4. 连接外部工具 ，使用 Arrow Flight SQL。

有关管理 SQL 访问的角色和权限的详细信息，请参阅 SQL 权限。
