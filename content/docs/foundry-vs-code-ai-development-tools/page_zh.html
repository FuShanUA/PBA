AI 开发工具

AI 开发工具可在 VS Code 工作区中使用，用于协助代码生成、测试、调试和优化。

Continue

Continue ↗ 是一个面向 VS Code 的开源扩展。Continue 提供用于 AI 代码生成的功能，包括 聊天 ↗， 内联编辑 ↗， 代码库索引 ↗， 自定义上下文选择 ↗，等等。

在 Palantir 平台中，Continue 已预先配置为可与 Palantir 提供的语言模型配合使用，并已掌握关于相关 Palantir SDK 以及您的 Python 转换或 OSDK 仓库的知识。这种对您的数据结构、本体论和组织的上下文理解，使 Continue 能够生成更准确、更相关的代码。

开始使用

以下是一些可用于开始使用 Continue 的命令和操作：

  • 从 VS Code 侧边栏打开 Continue 扩展，并使用模型选择器选择 Palantir 提供的模型。
  • 在编辑器中选择一个代码片段，并使用命令 cmd/ctrl + L 为新的聊天添加上下文。
  • 在编辑器中选择一个代码片段，并使用命令 cmd/ctrl + I 来编辑所选代码。
  • Enter @filename, @folder 或 @codebase 以引用代码库中的部分内容。
  • Enter @problems 以在打开的文件中包含 linting 错误。

Python 转换

在 Python 转换 仓库中，Continue 已经过预配置，能够理解如何编写 Python 转换。这包括以下主题的相关知识：

  • Python 转换 SDK 以及相关的 Palantir API。
  • 数据集架构：在您的消息或已添加的上下文中包含数据集 RID，即可自动包含数据集架构和元数据。
  • Foundry 专属的约定和最佳实践。

询问 How do I write a transform? 以开始使用。

OSDK

在 TypeScript OSDK 仓库中，Continue 已经过预配置，能够理解您仓库中包含的 OSDK。这包括以下内容：

  • TypeScript OSDK 及其相关库。
  • 本体论对象及其元数据、关联、操作和导入的函数。

提问 Tell me about my OSDK 即可在您的仓库中开始使用。

Palantir MCP 集成

默认情况下，Palantir MCP 已集成到 VS Code 工作区中。该 MCP 会向 LLM 智能体提供来自您的代码、库和 Foundry 的上下文。它还提供智能体工具，用于在您的仓库和 Foundry 中执行操作。

Palantir MCP 在 VS Code 工作区中提供以下工具：

  • 适用于 OSDK、Python 和 TypeScript 函数仓库的上下文工具。
  • 用于 Python 转换的预览工具，允许智能体运行转换并在出现错误时进行修复。
  • 本体论管理工具，供您探索和修改本体论。
  • Developer Console 工具，供智能体更新和重新生成 OSDK，而无需离开您的 IDE。
  • Foundry 导航工具，用于调查 Foundry 项目内容、查看单个数据集架构并运行 SQL 查询。

如需了解更多信息，请查阅我们的 Palantir MCP 文档。

定价

Continue 已包含在 VS Code 工作区中，无需额外费用。使用 Palantir 提供的模型将产生计算费用，具体依据为 Palantir 的 AIP 计算定价模式。

安全性

VS Code 工作区中的 Continue 已预先配置为使用您的注册中可用的 Palantir 提供的模型。为了保持整个平台所提供的相同级别的安全性，我们不建议直接在 Continue 扩展中添加其他模型。要添加其他模型，请使用 控制面板。

可用性

Continue 在 VS Code 工作区中自动可用，前提是 您的注册中已启用 AIP 。无需进行额外的安装或配置。请联系您的 Palantir 管理员为您的注册启用 AIP。

注意：AIP 功能的可用性可能会发生变化，并且可能因客户而异。
