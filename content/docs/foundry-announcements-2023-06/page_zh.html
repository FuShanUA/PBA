本体论 SDK 简介：基于本体论构建 [Beta]

发布日期：2023-06-22

全新的 Foundry 本体论 SDK 允许开发人员直接在开发环境中充分利用 Palantir Foundry 本体论的强大功能。您可以使用 Developer Console 来生成本体论 SDK，这是一个用于借助 Palantir API 创建和管理应用程序的新门户。本体论 SDK 以 TypeScript 包的形式创建，该包基于本体论中选定的子集。

通过将 Foundry 作为您的后端，您可以利用本体论执行查询和 Foundry 回写的强大能力，并结合细粒度的治理控制，加快开发能够助力您组织的应用程序。

本体论 SDK 的优势包括：

  • 加速开发： Ontology SDK 通过提供对 Ontology API 的便捷访问，帮助您快速开始开发和增强应用程序，让您只需几行代码即可读取并写回本体论。
  • 强大的类型安全性： 为 Ontology SDK 生成的函数和类型基于本体论中选定的相关子集。所有内容均提取自您的本体论，让您可以直接在编辑器中查询和探索数据。
  • 集中式维护： 由于本体论是在 Foundry 中集中构建和管理的，您可以专注于构建应用程序，并减少构建其数据基础通常所需的维护负担。
  • 设计即安全： 生成 Ontology SDK 时所使用的令牌，其作用域仅限于您希望应用程序访问的本体论实体。

此外，用于前端开发的 TypeScript 绑定现已推出，为开发人员提供了一种基于 Foundry 快速构建 React 应用程序的便捷方式。

生成的代码使用了有关您本体论的元数据（例如属性名称和描述），因此您可以直接在编辑器中查看这些信息。

使用 Developer Console 生成 Ontology SDK

本体论 SDK 通过 Developer Console 生成,这是一个新门户,您可以通过它创建和管理为使用 Palantir API 而构建的应用程序。首先,请启用 Control Panel 中的 Developer Console,或联系 Palantir 支持团队寻求帮助。

然后,从左侧边栏打开 Developer Console 以开始创建和配置应用程序。

Developer Console 提供快速入门说明和安装指南,帮助您开始使用本体论 SDK。要开始使用 TypeScript 和 React,我们提供了一个 TypeScript 示例入门仓库。请按照 README ↗ 中的说明开始。

了解更多关于 本体论 SDK的信息。

  • Python 软件包: 除 TypeScript 外,还可通过 Developer Console 获取 Python 本体论 SDK。

  • 自动生成的 API 文档: 为您的应用程序本体论 SDK 提供的平台内特定语言文档。

全新推出 AIP Assist 侧边栏 [Beta]

发布日期:2023-06-15

Palantir Foundry 的 AIP Assist 侧边栏是一款由 LLM 驱动的支持工具，在启用 AIP 的地方即可使用，旨在帮助用户浏览、理解其 Palantir 平台并从中创造价值。用户现在可以用自然语言向 AIP Assist 侧边栏提问，并获得针对其问题的实时帮助。

使用 AIP Assist 的优势包括：

  • 用户友好的界面： AIP Assist 由 LLM 驱动，界面直观，用户可以轻松提问并获得相关、自然且易于理解的回复。
  • 实时协助： AIP Assist 提供实时协助，帮助用户快速解决问题和疑问，提高用户工作效率，同时减少对支持团队的依赖。
  • 多语言支持： AIP 可以使用所有常用语言回答查询。
  • 上下文感知： AIP Assist 旨在保持对话上下文，能够感知您当前所在的 Foundry 应用。
  • Foundry 级别的安全性： AIP Assist 完全遵循 Palantir 的 AI 伦理原则 ↗ ，且不会访问您的数据。
  • 迭代改进： 用户可以对 AIP Assist 回复的质量提供反馈，帮助在持续开发中改进该工具。

我应该什么时候使用 AIP Assist 侧边栏？

AIP Assist 侧边栏会利用您请求周边的上下文来提供实时帮助，而无需访问您所在组织的任何数据。AIP Assist 基于 Palantir 的文档进行训练，并使用自然语言处理（NLP）和第三方大语言模型（LLM）来解析用户查询并提供最相关的响应，符合 Palantir 的安全标准。

例如，您可以通过侧边栏查询有关 Foundry 平台的问题、调试模型集成，甚至了解如何使用以 JavaScript 编写的 Slate 函数来转换数据结构。这些只是 AIP Assist 侧边栏提供的多方面支持领域中的一部分。

要在启用了 AIP 的实例上访问此工具，请选择 AIP Assist （位于工作区导航栏中），或使用键盘快捷键 Cmd+Shift+U （macOS）或 Ctrl+Shift+U （Windows）访问。打开后，您可以在 Ask a question... 输入框中开始以纯文本形式输入查询。

AIP 功能正在整个 Palantir 平台上持续增强。未来的公告将详细介绍适用于常用工具的其他 AIP 功能。

Notepad 中的 AIP 功能介绍

发布日期：2023-06-15

Foundry Notepad 引入了一系列 AIP 功能，旨在帮助您更快、更高效地共享本体论见解。您可以在 Notepad 中使用 AIP 自动对文本进行拼写检查、精简、修改或翻译——同时保留现有格式。

Notepad 的新 AIP 功能包括：

  • 修正拼写和语法： 支持英语、法语、德语、日语、韩语、西班牙语和乌克兰语。
  • 更改写作风格： 从“专业”（适用于报告）或“自信”（适用于公告）风格中进行选择。
  • 精简： 使文本块更加简洁。
  • 翻译： 将文本从一种受支持的语言翻译成另一种语言。
  • 预览多个命令： 预览在同一文本块上执行多个 AIP 操作的结果。例如，在替换原始文本之前，可同时预览拼写修正、精简效果以及法语翻译的结果。

要在 Notepad 中使用 AIP，请选择文本块旁边显示的拖动手柄，然后从下拉菜单中选择 “使用 AIP Assist 编辑” ，即可开始改进您的 Notepad 文档。如需参考，请参阅文档中的 “Notepad 中的 AIP 功能” 相关内容。

宣布推出 Cipher：基于密码学的数据最小化

发布日期：2023-06-06

Palantir Foundry 始终开箱即用地提供默认的静态数据加密和传输中数据加密，以保护您的数据免受攻击者侵害。 Cipher 通过让您的隐私和数据安全团队对运营用户所查看的数据进行细粒度控制，在现有防御层之上再增加一层保护。使用 Cipher 将单个数据集的可见性限制到列级别，或对用户的访问添加速率限制，作为额外的制衡手段。管理员可以 构建具体的 Cipher 工作流 ，而无需管理加密密钥的访问权限，同时用户可以获得直观的点击式工具来访问所需的敏感数据。

合适的人员、合适的时间、合适的数据

Cipher 让您能够轻松保护组织最重要数据的隐私和安全。

将 Cipher 与 标记 和 受限视图 结合使用，以满足对数据访问更细粒度的控制需求。管理员可以对单个数据集启用解密，精确到单元格级别，从而使用户只能访问与其工作流最相关的数据。Cipher 以细粒度级别管理数据的能力，确保数据权限的设置并非“全有或全无”的决策。

例如，您可以使用 Cipher 对敏感数据集列进行默认混淆，使数据科学家、数据工程师和应用开发人员无法查看具体数据。数据进入本体论层后，需要访问敏感信息的操作用户可在需要时获得精细的单元格级别访问权限。除了精细的权限之外，Cipher 还允许数据治理用户通过记录每次加密或解密操作及其相关原因，轻松审计谁访问了敏感数据。

我应该何时使用 Cipher？

Cipher 可用于默认混淆敏感信息，同时允许有选择地解除混淆。当某些操作用户因日常工作需要一次性访问敏感信息时，Cipher 尤其有用。例如，客户服务中心的员工只有在收到来自特定客户的客户服务请求时，才需要了解该客户的联系信息。

此外，在需要为操作用户设置可执行的解密操作数量的每日上限（即速率限制）的情况下，Cipher 也很有用。这有助于防止滥用敏感数据，即使用户确实有访问数据的正当需求。

Cipher 现已在所有 Foundry 注册中可用。如需了解有关 Cipher 的更多信息(包括其使用方式的具体示例),请查阅 Cipher 文档。

Workshop 推出 Resource List 小部件

发布日期:2023-06-06

应用构建者现在可以使用 Palantir Foundry 的 Workshop 中的 Resource List 小部件,创建引用数据集、管道、本体论对象等资源的丰富操作型落地页。

随着组织本体论范围的扩大和操作用例复杂性的增加,相关落地页体验的重要性也与日俱增。Resource List 小部件可轻松访问文件和项目层级中的资源,使 Workshop 应用能够为操作用户展示更广泛的高度相关资源。对象类型和对象集等资源可以根据查看用户的收藏或最近使用的资源动态显示,也可以固定为静态资源。此外,所有这些均可进行自定义,以满足定制的样式要求,从而实现一致的用户体验。

展示最相关的资源

使用文件和项目中可用的资源自定义资源列表小部件，并策划用户选择不同条目时产生的交互。通过 Workshop 直观的点击式界面，可选择显示文件和项目、对象类型或对象集。您还可以在一个视图中通过动态子类型使用标签来填充小部件，同时利用 Foundry 对组织目录层级结构和现有用户权限的内置知识。

通过策划符合您的组织及其各类用户群体需求的展示资源，提升着陆页的相关性。

高度可自定义的显示配置

选择要显示的资源后，您可以通过多种设置自定义资源的显示方式。对于对象类型，您可以设置基于查看用户的动态内容视图，其内容由所有资源、显著资源（在本体论管理器中设置）或用户收藏的资源组成。或者，也可以按 RID 显示指定的资源，并从三种样式中进行选择，自定义每个项目的标题、描述和样式，或者创建覆盖设置，使某些对象类型显示得更加突出。由于该小组件会遵循现有的文件层级和资源权限，您的用户将只能看到其有权访问的资源，从而为不同用户角色提供无缝的体验。

您还可以自定义图像的显示方式，选择以列表或图像卡片的形式显示。为每个项目选择图像卡片样式，并在需要时选择缩略图来代表资源。图像卡片可以以任一方向显示，并可搭配滚动条或轮播，以满足您的需求。

此外，点击条目后的操作也可以自定义。默认情况下，点击会打开资源，但您也可以从众多 Workshop 事件中设置点击产生的操作，或让该操作设置变量的值。

何时应在 Workshop 中使用 Resource List 小部件？

Workshop 的 Resource List 小部件在需要一种简单易用且功能强大的选项来向用户展示资源列表时，为应用构建者提供了一流编辑体验。例如，如果您有一个指向报告的链接，该链接映射到文件夹、数据集或 Notepad 文档，您可以通过 RID 精确定义条目数量，并指定覆盖每个条目显示方式的设置，从而获得一流编辑体验。

数据科学或分析导向的用户可能会继续发现 Contour 或 Quiver 等应用更为合适，因为 Workshop 旨在满足专注于本体论的操作用户的需求。有白标需求的应用构建者应考虑改在 Slate 中进行构建。

要了解 Resource List 小部件的可用配置，请参阅 Workshop 文档。

AIP 正式发布

发布日期：2023-06-01

截至上周，部分 Foundry 注册组织已可以在 控制面板中激活 AIP——Palantir 全新的人工智能平台。如果该配置可用，将会显示一个醒目的横幅（仅向 Foundry 管理员显示），以提醒用户注意此配置。

启用 AIP 后，Foundry 用户将可以提前使用 AIP Assist——这是一款由 LLM 驱动、基于 Foundry 文档训练的支持工具。在“帮助与支持”中，用户可以与基于 Foundry 内容训练的 AI 助手进行实时互动。请注意，Assist 具有上下文感知能力，可了解用户在 Foundry 中所处的位置，但无法访问任何数据或元数据。

AIP Assist 还能改进支持问题的提交流程：在与支持工程师沟通之前，它会先收集更多上下文信息并提供建议。测试表明，这可以在无需与支持工程师来回沟通的情况下妥善解决相当大比例的支持交互；而在问题确实需要支持工程师处理的情况下，则可减少为澄清问题而进行的后续跟进。

接下来是什么？

AIP 集成即将在更多 Foundry 工具中推出，包括 Slate、Pipeline Builder、Quiver、代码仓库、Notepad 和 Workshop。这些功能将针对各个应用进行调优；例如，Slate 中的 AIP 可以帮助自动生成自定义 CSS 样式、在 Slate 函数中自动补全 Javascript、为代码重构提供建议，并为小部件和查询等应用元素推荐有意义的名称。同时，Pipeline Builder 中的 AIP 可以将数据转换逻辑的自然语言描述转换为稳健且结构良好的管道，还能以自然语言总结和解释现有的数据管道。

Foundry AIP 正在快速发展。随着新的集成和功能陆续上线，有关未来更新的更多信息将发布在这些公告页面上。AIP 及底层语言模型服务（Language Model Service）的文档也将在未来几周内发布。

常见问题

  • 是否有任何 Foundry 数据用于训练 AIP 模型？
    • 否。AIP Assist 模型仅基于 Foundry 文档进行训练，无法访问 Foundry 中的数据。
  • 用户提示词会被发送到哪里？
    • AIP 模型与语言模型服务（Language Model Service）交互，该服务与 Microsoft 提供的建模基础设施进行交互。由于 Palantir 为 AIP 用户争取到了例外条款，用户提示词不会用于模型训练目的，也不会被 Microsoft 监控。有关语言模型服务和 AIP 安全保障的更多文档即将发布。

Mapbox Boundaries V4 现已可供安装

发布日期：2023-06-01

Mapbox V4 边界数据集现已可通过 Marketplace 安装到所有 Palantir Foundry 实例上。V4 版本包含对边界信息本身的更新以及功能上的改进。显著的边界变化（查看完整列表 ↗）包括来自 2020 年美国人口普查的更新街区和普查区，以及来自 2022 年美国选区重划的更新立法选区。安装 Boundaries V4 后，Foundry 中的地图将更可靠地在工具提示中显示区域名称，并支持在由边界数据支撑的地图图层上自动缩放至合适范围。

安装 Boundaries V4 或从以前的 Boundaries 版本迁移

如果您目前使用的是 Boundaries V3，我们强烈建议您进行升级，以便在 Workshop 地图小组件和 Contour 地图看板中获得最准确的边界和最佳用户体验。虽然 Foundry 将继续支持 Mapbox Boundaries V3，但未来与边界相关的功能开发将利用 Mapbox Boundaries V4 数据集的新功能，并要求以 V4 作为基准版本。

请查阅 有关如何在本体论中使用地理空间数据的文档 ，以进一步了解如何在 Foundry 中安装或升级到 Mapbox Boundaries V4。
