1. 教程 - 在 Foundry 中设置机器学习项目

在本教程的这一步骤中，您将在 Foundry 中创建一个机器学习项目。此步骤为必需步骤，将涵盖以下内容：

  1. 为机器学习构建 Foundry 项目结构
  2. 管理机器学习的数据
  3. 在 Foundry 中管理机器学习模型
  4. 在 Foundry 中管理机器学习项目

1.1 如何为机器学习构建 Foundry 项目结构

Foundry 项目是用于存储相关工作的文件夹结构。我们建议为每个机器学习项目创建一个独立的 Foundry 项目。该项目应包含：

  • A data 用于存储本项目所用数据集的文件夹，
  • A models 用于存储本项目模型的文件夹，
  • A code 用于存储本项目所用模型训练逻辑的文件夹，以及
  • 一个用于管理和部署生产模型的建模目标。

如果您没有创建新项目的权限，可以在现有项目中创建一个新文件夹，作为您的机器学习项目的根目录。

这有助于在需要时与其他团队有效沟通上游问题和平台问题，并减少解决问题的时间。它还可以提高平台的调试技能。 创建一个 新的 Foundry 项目 用于本教程，并创建上述文件夹 - 查看操作方法。如果您无法创建新的 Foundry 项目，请在现有项目中创建一个空文件夹来模拟新项目的根目录。

这有助于在需要时与其他团队有效沟通上游问题和平台问题，并减少解决问题的时间。它还可以提高平台的调试技能。 在您的 Foundry 项目中，选择 +New > Modeling Objective。建模目标的命名应与您尝试解决的机器学习问题的名称相关。在本例中，将该目标命名为 "House Price Prediction Objective"。

1.2 如何管理机器学习的数据

在本教程中，我们将构建一个机器学习模型来估算美国人口普查区的房价中位数。

我们将利用特征数据（关于美国人口普查区的历史详细信息）和标签（当时该人口普查区的房价中位数）来揭示特征与标签之间的关系，然后将该关系保存为 Foundry 中可复用的模型。将来，当我们拥有最新的特征数据（关于某个美国人口普查区的详细信息）但没有最新的标签（房价中位数）时，我们可以将该模型应用于该人口普查区的特征数据，以估算该人口普查区的房价。这类机器学习项目被称为监督式机器学习，是最常见的机器学习项目类型。

在 Foundry 中，监督式机器学习项目应包含两个数据集：

  1. A 已标注数据集 可用于模型训练和测试，以及
  2. An 未标注数据集 包含最新的特征但没有标签。我们将把模型应用于该数据集以生成推断（对我们标签的预测）。

这些数据集通常来自 与生产数据源的连接 或您的 本体论。不过，在本教程中，我们将上传 CSV 文件来模拟这些生产数据源。

这有助于在需要时与其他团队有效沟通上游问题和平台问题，并减少解决问题的时间。它还可以提高平台的调试技能。 下载 已标注的美国住房数据源 并将其上传到 data 文件夹中，命名为 housing_features_and_labels。下载 未标注的美国人口普查数据源 并将其上传到 data 文件夹中，命名为 housing_inference_data。您可以通过将 CSV 文件拖入文件夹结构来将其上传到 Foundry - 在本教程中，请将其作为结构化数据集上传。

1.3 如何管理机器学习模型

在 Foundry 中训练的模型与其训练时所使用的数据、代码和开发环境相关联。这有助于为所有模型的生成方式提供受治理的记录，并记录和共享历史实验的详细信息。

机器学习模型可以在 Foundry 的 Code Repositories 应用程序中进行训练。

代码仓库

Code Repositories 应用程序是一个基于 Web 的开发环境，用于编写数据管道和机器学习逻辑。对于机器学习，Foundry 提供了一个 模型集成 带有 模型训练 语言模板的仓库。

Code Repositories 支持 Git 进行本地代码迭代，但在 Foundry 中运行构建需要已提交的代码。Code Repositories 应用程序最适合编写生产级、可复现的数据管道和机器学习逻辑。

集成现有模型

如果您已经在 Foundry 之外训练了一个模型并希望在 Foundry 中使用它，可以通过以下方式集成该现有模型：

  • 从预训练模型文件发布模型，例如在 .pkl 本地开发环境中训练的 代码工作区文件，或在 旧系统中。请参考 scikit-learn 示例 获取分步演练。
  • 现有的本体论实体可以导入到 SuperRepo 中，而无需在代码中重新定义；请查看 来自 Hugging Face 的预训练模型文件
  • 上传 容器镜像作为模型
  • 创建一个模型来代理 外部托管的模型

本教程的这一步骤无需任何操作。

1.4 如何管理机器学习项目

在 Foundry 中，机器学习项目通过 Modeling Objectives 应用程序进行管理。建模目标通过以下方式为管理机器学习项目提供最佳实践建议：

  • 围绕特定问题组织机器学习项目
  • 创建系统化模型评估标准
  • 在投入生产使用之前支持多方模型评审
  • 维护生产中使用的所有模型的历史记录
  • 将模型开发与部署集成到批量管道或实时托管推理中

在本教程中，建模目标是预测一个人口普查区的房价中位数。

这有助于在需要时与其他团队有效沟通上游问题和平台问题，并减少解决问题的时间。它还可以提高平台的调试技能。 导航到之前创建的 "House Price Prediction Objective" 建模目标。在建模目标的页眉部分添加项目上下文，以便向其他团队描述该问题。选择页眉右侧的笔形图标进入编辑模式，为您的目标添加摘要和描述。描述字段支持 Markdown。建议内容的示例如下：

#### Goal: Build forecasting model to predict median house prices across America.

#### Data

This dataset was derived from the California responses in the 1990 U.S. census, using one row per census block group. A block group is the smallest geographical unit for which the U.S. Census Bureau publishes sample data (a block group typically has a population of 600 to 3,000 people).

The target variable is the **median_house_value** for California districts.

#### Reference

Pace, R. Kelley, and Ronald Barry, "Sparse Spatial Autoregressions," Statistics and Probability Letters,
Volume 33, Number 3, May 5 1997, p. 291-297.

Data derived from StatLib repository. <http://lib.stat.cmu.edu/datasets/>
