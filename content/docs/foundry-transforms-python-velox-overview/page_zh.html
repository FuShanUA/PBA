使用 Velox 加速 Spark

Spark 加速是一种利用底层硬件优化来提升 Spark 作业性能的技术。原生加速通过使用平台特定的特性，旨在显著缩短处理大规模数据工作负载所需的时间，从而实现更快的作业执行和更高的资源利用率。

Velox ↗ 是一个可复用、高性能的底层数据处理库，提供了一组用于构建高性能数据处理系统的基础组件。它被设计用作构建更高层数据处理系统的基础，并在 Foundry 中用于加速 Spark 作业。

详细了解 Foundry 中的原生加速.

快速开始

Spark 加速可用于任何现有的 Spark 管道。您无需对逻辑进行任何更改。

要在您的 Python 转换管道中使用原生加速，您必须完成以下步骤：

  1. 将您的 Python 仓库升级 到最新版本。
  2. 配置一个 堆外内存配置文件.
