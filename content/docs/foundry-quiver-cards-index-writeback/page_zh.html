操作按钮 可以添加到您的 Quiver 分析画布、时间序列图表和仪表板中，允许用户将数据回写到本体论。回写操作示例包括创建对象、更新现有对象的属性，或修改对象关联。

  • 添加并配置操作按钮
  • 直接从时间序列图表调用本体论操作
  • 使用选区边界值作为本体论操作的输入
  • 自定义按钮显示

此功能可用于增强各种工作流程，包括：

示例：创建一个 Annotation 对象实例

在时间序列图表中，您可以创建一个对象来记录所观察现象的上下文信息，例如机器故障的原因或影响股票指数的市场宏观事件。x 轴选区的起始和结束时间值将作为输入传递给 Create annotation 本体论操作，从而生成一个注释事件。使用多个事件对图表进行注释，可以更清晰地展示当前的数据可视化。

示例：调整运营值

您还可以调用本体论操作，根据观察到的现象更新属性值。例如，下面的时间序列图表显示了两条曲线，分别表示两类产品的每桶预测总成本：汽油（蓝色）和柴油（红色）。今天汽油的实际每桶总成本（y 轴，深蓝色圆点）在 6.35 到 8.45 美分/桶之间。这远高于 6.01 美分/桶的最低预测总成本。为了降低生产成本，您可以将 DRA 浓度从 15 ppm 调整到接近 6.5 ppm 的值。在 x 轴上选择 6 附近的范围，然后选择 调整 DRA 水平 本体论操作，该操作会自动填入选区边界值。

添加并配置操作按钮

要向分析中添加操作按钮：

  1. 打开 搜索栏 通过选择 按钮。 此外，“后续操作”栏现在支持搜索！您可以跨所有类别或在特定类别中搜索操作。搜索结果将包含该类别内的匹配项，并会突出显示来自其他类别的匹配项，确保您不会遗漏任何操作！ （位于分析顶部栏）。
  2. 搜索 action 或导航到 回写 类别（位于左侧）。
  3. 选择 操作按钮 card.

要配置操作按钮卡片：

  1. 在 参数 panel.
  2. 中找到操作按钮，选择 组织 齿轮图标以打开操作按钮编辑器。
  3. 从下拉菜单中选择一个现有的本体论 操作 。如果该操作尚不存在，您需要 创建新操作 （在本体论中）。

选择操作按钮后会显示一个表单，用于填写输入并提交操作。在操作按钮编辑器中，可以提供默认输入。

选择操作按钮后， Event start 参数的输入值将显示为 2010 年 1 月 1 日。用户在提交操作之前仍可以编辑此值。

直接从时间序列图表调用本体论操作

可以将 本体论操作 按钮直接添加到时间序列图表的选区菜单中。要向时间序列图表选区菜单添加操作按钮：

  1. 选择 组织 卡片标题上的齿轮图标，打开时间序列图表编辑器。
  2. 编辑标签 操作按钮 部分，打开下拉菜单，从分析中选择一个现有的操作按钮，或创建一个新的。本体论操作按钮现在将显示在选区菜单中。

使用选区边界值作为本体论操作的输入

当本体论操作按钮添加到时间序列图表后，您可以使用 x 轴或 y 轴选区的边界值来参数化操作输入。

要将选区边界值用作本体论操作输入：

  1. 打开操作按钮编辑器并展开 时间序列图表输入覆盖 section.
  2. 基于 x 轴选择、y 轴选择或两者添加覆盖。选择边界会根据数据类型映射到操作参数。例如，时间轴上的 x 轴选择可以映射到日期/时间操作参数。

在以下示例中，选择的左右边界被映射到 Event start 和 Event end 参数。从时间序列图表的选择菜单中选择操作按钮会自动填充这些值。
