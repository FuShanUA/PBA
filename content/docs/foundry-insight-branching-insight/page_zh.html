Insight 中的分支

Insight 与 Global Branching 集成，使您可以直接在 Insight 中分析您的本体论并对分支执行操作。分支上下文适用于您分析的数据和您执行的操作；Insight 工作簿本身不是可分支的资源，因此您在分支上时无法保存工作簿。自动保存仍可正常工作，因此您进行中的分析将得到保留。

有关 Global Branching 概念和工作流程的一般信息，请参阅 Global Branching 文档。

将您的会话范围限定到某个分支

您可以通过以下方式将 Insight 会话置于分支上：

  • 分支选择器： 使用工作簿标题栏或主页上的分支选择器切换到分支 main。
  • 分支任务栏： 当您已在分支上时，平台分支任务栏会显示在屏幕底部，方便您查看和管理分支上下文。
  • 分支 URL 参数： 通过包含 foundry-branch-rid 参数的链接打开 Insight，以便加载已限定到该分支范围的会话。其他应用程序（例如 Global Branching）可以通过这种方式链接到 Insight。

哪些内容支持分支感知

当您的会话位于分支上时，您的 Insight 分析将反映该分支而非 main，包括工作簿、主页以及您运行的任何操作。

分支上不支持的内容

某些写入或导出数据的操作尚不支持分支，因此当您在分支上时，Insight 会将其禁用。每个被禁用的控件都包含一个工具提示，说明其在分支上不可用。以下操作在分支上不受支持：

  • 保存工作簿，包括 保存 和 另存为 选项。
  • 保存布局。
  • 发布对象集，或将其保存为列表。
  • 导出到 Excel。
  • 在不支持分支的应用程序中打开结果。
即使无法保存工作簿，自动保存功能仍可正常工作

当您在分支上时，Insight 会自动保存您正在进行的分析，因此您的工作成果会得到保留，即使重新加载页面或导航离开也不会丢失。这与将工作簿保存到您的文件是两回事：在分支上时，您无法将工作簿保存为资源、发布对象集或保存布局。
