报告安全问题

报告安全事件

持续发生的事件将通过您的 Palantir 代表处理

如果您认为自己遇到了正在发生的安全事件， 请立即联系您的 Palantir 代表。他们将能够呼叫 Palantir 信息安全团队为您提供帮助。

对于常规安全问题，您可以直接联系 Palantir 计算机事件响应团队 (CIRT)。为此，请按照以下报告流程操作：

  • 请尽可能收集详细的技术信息，包括重现和验证该问题的步骤。
  • 加密电子邮件内容 ，使用我们的 GPG 密钥 ↗.
  • 请立即通知 Palantir 计算机事件响应团队 (CIRT)，发送电子邮件至 cirt@palantir.com。请注明最佳的回复联系方式。

报告产品安全漏洞

Palantir 客户

如果您认为自己发现了一个安全漏洞，请联系您的 Palantir 代表。他们将能够把您发现的任何漏洞问题直接上报给 Palantir 信息安全团队。

或者，您也可以按照以下步骤通过加密电子邮件直接向 Palantir CIRT 报告该漏洞 报告安全事件 部分。

漏洞赏金研究人员

Palantir 很自豪地将我们的负责任披露政策建立在 disclose.io ↗ 漏洞披露框架之上。安全是 Palantir 的核心宗旨之一，我们重视本着善意行事的安全专业人士提供的意见，以帮助我们为用户维持高水准的安全性和隐私保护。这包括鼓励负责任的漏洞研究和披露。本政策阐述了我们在发现和报告漏洞的背景下对善意的定义，以及您可以期待我们做出的相应回应。

有关我们负责任披露政策的完整内容（包括适用范围和漏洞赏金奖励），请参阅我们的 HackerOne 公开漏洞赏金计划页面 ↗.

要报告我们产品或基础设施中潜在的安全问题或漏洞，请遵循以下报告流程：

  • 请尽可能收集详细的技术信息，包括重现和验证该问题的步骤。
  • 如需提交报告，请访问我们的 HackerOne 公开漏洞赏金计划页面 ↗.
  • 确认所报告的问题最多可能需要五 (5) 个工作日。

安全问题

您在 Palantir 的代表将很乐意与您讨论有关 Foundry 安全的任何问题或顾虑。如果您的问题超出了他们的专业范围，他们将协调安排与 Palantir 安全部门的对话，讨论相关事宜。
