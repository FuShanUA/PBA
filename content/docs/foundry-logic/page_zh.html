AIP Logic

AIP Logic 是一个无代码开发环境，用于构建、测试和发布由 LLM 驱动的函数。AIP Logic 使您能够构建功能丰富、可利用本体论的 AI 驱动函数，而无需应对开发环境和 API 调用通常带来的复杂性。通过 Logic 直观的界面，应用程序构建者可以设计提示词、进行测试、评估和监控、设置自动化等。

您可以使用 AIP Logic 自动执行和支持您的关键任务，无论是将非结构化输入中的关键信息连接到您的本体论、解决日程安排冲突、通过找到最佳分配方案来优化资产性能、应对供应链中的中断，还是其他更多任务。

Logic 函数还可以 实现自动化 从而 自动应用本体论编辑，或将其暂存以供人工审核。

使用 Foundry Branching 在隔离环境中开发 Logic 函数。您还可以通过 指标监控 Logic 函数的运行状况和性能，包括成功和失败次数以及执行持续时间。

AIP Logic 提供直观的界面，可通过 Logic 函数利用本体论和 LLM。该函数可接收输入（如本体论对象或文本字符串），并可返回输出（对象和/或字符串）或对本体论进行编辑。例如，下方由 LLM 驱动的函数从本体论对象中获取输入数据，并将该数据与客户电子邮件进行交叉比对，从而根据以往的解决情况为给定问题推荐解决方案。

AIP Logic 构建于同样严格的 安全 模型之上，该模型管控着 Palantir 平台的其余部分，包括用户和 函数权限。这些平台安全控制仅向 LLM 授予完成任务所需的访问权限。

仅在读取时强制执行

行级和列级访问控制（包括 受限视图、 对象安全策略以及 属性安全策略）会过滤模型代表用户可读取的内容。模型永远无法看到用户无权读取的数据。这些控制不会延伸到模型的输出或其生成的任何本体论编辑。为了在数据向下游流动时保护数据，请将这些控制与 标记 或 基于分类的访问控制结合使用。有关完整模型，请参阅 访问控制传播。

详细了解 AIP Logic 的 核心概念 ，或 开始 构建 Logic 函数。评估函数时， AIP Evals 提供结果分析器，可按根本原因对失败的测试用例进行分类，并建议针对性地修改提示词，以改进结果。
