数据治理

Palantir 模型上下文协议 (MCP) 在 AI 系统与 Foundry 资源之间提供安全集成。安全与数据治理策略取决于 MCP 的使用方式和使用位置。

数据流与安全模型

Foundry 平台

在 Foundry 平台内通过 VS Code 中的 Continue 使用 Palantir MCP 时，适用以下数据流和安全模型：

  • LLM 提供商： 使用 Palantir 提供的第三方 LLM。
  • 数据治理： 遵循您的组织与 Palantir 之间现有的合同。
  • 数据位置： 所有数据均保留在您的 Foundry 环境中。
  • 安全性： 继承 Foundry 的安全模型和管控措施。

本地环境

用于本地开发的 Palantir MCP 默认处于禁用状态。要在本地环境中使用 Palantir MCP，您必须在 控制面板。

在本地机器上配合第三方 AI 工具（如 VS Code Copilot、Claude Code、Windsurf 或 Cursor）使用 Palantir MCP 时，适用以下数据流和安全模型：

  • LLM 提供商： 取决于所使用的接口。
    • Claude Code： 数据会发送至 Anthropic。
    • VS Code Copilot： 数据会发送至 Microsoft。
    • 其他工具： 请查看 LLM 提供商的政策。
  • 数据流： MCP 工具的输出会发送到相应的 LLM 提供商。
  • 数据治理： 取决于您与相应 LLM 提供商签订的合同。

写入权限

Palantir MCP 提供了一组有限的工具，可用于写入或修改您的本体论和数据集。我们不提供破坏性写入工具。所有可执行写入操作的工具要么是非破坏性的，要么需要人工批准更改。

LLM 代理 可以 创建新数据集，但 不允许 更新或删除现有数据集。

所有本体论修改（包括删除）都必须通过 提案审查进行处理；需要人工批准才能将更改合并到您的主本体论。
