元数据引用

对象类型在本体论中通过以下元数据表示：

  • ID： 对象类型的唯一标识符，主要用于在配置应用程序时引用此类型的对象。例如， employee 可能是 Employee 对象类型的 ID。
  • RID： Foundry 中为每个资源自动生成的唯一标识符。对象类型的 RID 将在整个平台的错误消息中被引用。
  • 图标： 用作对象类型视觉标识符的图片和颜色，当用户在用户应用程序中查看该类型的对象时会显示。例如，人员图标可用于表示 Employee 对象类型。
  • 显示名称： 在用户应用程序中，任何访问该类型对象的人看到的名称。例如， Employee 对象类型的显示名称可能是 Employee。
  • 复数显示名称： 在用户应用程序中，任何访问该类型多个对象的人看到的名称。例如， Employee 对象类型的复数显示名称可能是 Employees。
  • 描述： 有关对象类型的说明性文本，任何人都可以在用户应用程序中阅读。例如， Employee 对象类型的描述可能是 All full-time and part-time employees of Organization X。
  • 组： 组是一种标签，可帮助您对对象类型进行分类。例如， Employee 对象类型可能属于组 HR 和 Employee 360。
  • API 名称： 在代码中以编程方式引用该对象类型时使用的名称。例如， Employee 对象类型的 API 名称可能为 Employee。详细了解 API 名称。
  • 可见性： 向用户应用程序指示应如何突出地显示该对象类型。 prominent 对象类型将使应用程序优先向用户显示此对象类型。 hidden 对象类型将不会出现在用户应用程序中。默认情况下， Employee 对象类型的可见性将为 normal。
  • 状态： 向用户和其他本体论构建者表明该对象类型在开发过程中所处的阶段。它可以是 active、 experimental或 deprecated。默认情况下， Employee 对象类型的状态将为 experimental。详细了解 状态。
  • 索引状态： 该对象类型及其支撑数据源最近一次重新索引的状态。它可以是 success、 failed或 not started。详细了解 索引状态。
  • 写回： 指示该对象类型是否已生成写回数据集，以及是否允许最终用户对此类型的对象进行编辑，该设置可为 enabled 或 disabled。详细了解 回写数据集。
