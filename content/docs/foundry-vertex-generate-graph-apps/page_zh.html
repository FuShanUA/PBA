从其他应用程序生成图

您可以在其他 Foundry 应用程序中配置关联，该关联将自动生成预填充的 Vertex 图。

使用 URL 参数生成图

您可以使用 URL 参数执行以下操作：

  • 以现有图开始，或创建新图。
  • 通过指定对象 ID 或对象集 ID 向图中添加对象。
  • 运行 Search Around 函数。
  • 设置时间选择器的时间范围。

这些参数仅适用于创建新图的 URL（/workspace/vertex/graph/create）：

  • selectObjectRid：若指定对象存在，则选中该对象并将图以其为中心。
  • objectRid：将指定对象作为节点添加到图中。
  • objectSetRid：将指定对象集中的所有对象作为节点添加到图中。
  • searchAroundFnRid：将指定 Search Around 函数的结果添加到图中。如果与 objectRid 参数一起使用，该函数将以单个对象进行调用；或者以 objectSetRid 对象集中的所有对象进行调用。
    • 必须与 objectSetRid 或 objectRid URL 参数之一结合使用。

以下参数既适用于现有图的 URL（/workspace/vertex/graph/{graphRid}），也适用于新建图的 URL（/workspace/vertex/graph/create）：

  • selectedTime：设置所选时间。
  • startTime：设置时间范围的开始时间。
  • endTime：设置时间范围的结束时间。

所有时间既可以是以毫秒为单位的 UNIX 时间戳，也可以是 ISO 格式的日期/日期时间（例如 2020-02-15/2020-02-15 13:45:00 UTC）。如果 selectedTime 已指定，但 startTime 和 endTime 中至少有一个未指定，则时间范围将使用默认时长，并以所选时间为中心。如果 startTime 和 endTime 已指定，但 selectedTime 未指定，则所选时间将与 startTime相同。
