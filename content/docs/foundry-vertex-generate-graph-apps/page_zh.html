从其他应用程序生成图表

您可以在其他 Foundry 应用程序中配置一个链接，该链接将自动生成一个预填充的 Vertex 图表。

使用 URL 参数生成图表

您可以使用 URL 参数执行以下操作：

  • 以现有图表开始或创建新图表。
  • 通过指定对象 ID 或对象集 ID 将对象添加到图表中。
  • 运行 周边搜索 函数.
  • 设置时间选择器的时间范围。

这些参数仅适用于创建新图表的 URL（/workspace/vertex/graph/create):

  • selectObjectRid：如果指定对象存在，则选中该对象并将其居中显示在图表上。
  • objectRid：将指定对象作为节点添加到图表中。
  • objectSetRid将指定对象集中的所有对象作为节点添加到图表中。
  • searchAroundFnRid：将指定 周边搜索 函数的结果添加到图表中。该函数将被调用时传入单个对象（如果与 objectRid 参数一起使用），或传入来自 objectSetRid 对象集的所有对象。
    • 必须与以下任一参数结合使用： objectSetRid 或 objectRid URL 参数。

以下参数既适用于现有图表的 URL（/workspace/vertex/graph/{graphRid}），也适用于新创建图表的 URL（/workspace/vertex/graph/create):

  • selectedTime：设置选中的时间。
  • startTime：设置时间范围的开始时间。
  • endTime：设置时间范围的结束时间。

所有时间可以是毫秒单位的 UNIX 时间戳，或 ISO 格式的日期/日期时间（例如 2020-02-15/2020-02-15 13:45:00 UTC）。如果指定了 selectedTime 但至少有一个 startTime 和 endTime 未指定，则时间范围将使用默认时长并以选中的时间为中心。如果指定了 startTime 和 endTime 但未指定 selectedTime ，则选中的时间将与 startTime.
