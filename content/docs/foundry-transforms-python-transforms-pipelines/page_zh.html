转换

Foundry Transforms 是数据处理管道的核心构建块。它们定义了数据从输入到输出的流动方式，将计算逻辑和资源需求封装在一个单一的声明式单元中。

转换被注册在 Pipelines 中，这些可以由多个转换定义组成。

定义转换

每个转换包含三个关键组件：

  1. 装饰器： 定义输入、输出和配置
  2. 函数签名： 与装饰器中声明的输入和输出匹配
  3. 计算逻辑： 实际的数据处理代码

以下是定义转换的基本模式：

轻量级语法选项

您可以使用以下任一语法选项来定义单节点（轻量级）转换：

  • @transform.using(...)：推荐的 API
  • @transform.lightweight(...)：一个显式引用轻量级的别名
  • @lightweight 装饰器与以下内容一起使用 @transform(...)：旧版 API

版本要求

直方图 @transform.using API 要求 transforms 版本 3.68.0 或更高。要在 Code Repositories 中使用此功能，请按照以下指南升级您的仓库 仓库升级指南。请确保 transformsLangPythonPluginVersion 等于 1.978.0 或更高。

Spark API @transform.spark.using 要求 transforms 版本 3.95.0 或更高。请确保 transformsLangPythonPluginVersion 等于 1.1003.0 或更高。

要了解有关 transforms 版本的更多信息，请参阅 transforms 版本概述.

使用 @transform.using 排查版本错误

如果您收到类似以下的错误消息，您可能使用的是不支持更新语法的旧版 transforms 库：

  • Usage of transform.using() on outdated repository
  • AttributeError: 'function' object has no attribute 'using'

要解决此问题：

  • 将您的仓库升级到最新版本的 transforms 库和仓库模板，请遵循 仓库升级指南.
  • 或者，使用以下方式切换到旧版语法 @lightweight with @transform(...).

    conn = ctx.duckdb().conn
    df_from_duckdb = conn.sql("SELECT * FROM dataset").fetchdf()  # dataset is automatically registered

PySpark 转换

Pyspark 转换 默认情况下，转换在单个计算节点上运行，并利用 pandas 或 Polars 等数据处理库。对于大数据计算工作流，可以在 Python 转换中使用 PySpark ↗

PySpark 是一种包装语言，允许您与 Apache Spark 后端进行交互以快速处理数据。Spark 可以在分布式服务器网络上处理非常大的数据集，这在正确使用时提供了扩展性和可靠性优势。然而，它也伴随着更高的开销和资源使用，因此对于中小规模的数据来说不是一个好的选择。

虽然此处提供了 PySpark 转换 API 的高级概述，请参阅 Python 转换（Spark） 以获取更多详细信息。

配置 PySpark 转换

在 PySpark 转换中，资源通过 spark 配置文件进行配置。这些配置允许对大规模计算使用进行严格的访问控制。

Iceberg 表

您可以在 Python 转换中使用 Foundry Iceberg 表作为输入和输出，配合 transforms.tables 库。同样适用三部分转换结构。装饰器使用以下内容定义输入和输出 TableInput 和 TableOutput。函数签名接收运行时句柄，例如 IcebergInput 和 IcebergOutput。计算逻辑使用标准 DataFrame 代码来读取和写入数据。

有关在转换中使用 Iceberg 表的详细信息，请参阅 使用 Iceberg 的转换.

转换逻辑层级版本控制

TLLV 需要模块级导入，且在运行时不对模块进行修补

为了使 TLLV 正常运行，您的代码必须在模块级别声明所有导入，并且不应尝试修补或以其他方式修改另一个模块中的对象。如果您的项目不符合这一点，请 您必须禁用 TLLV。有关更多信息，请参阅下面的代码示例。

TLLV 默认是启用的。 要禁用 TLLV，请将 transformsPython 配置中的 tllv 设置为 false。此配置位于您的 Python transforms 子项目中的 build.gradle 文件中。 

transformsPython {
    tllv false
}

转换的版本是一个字符串，用于在考虑逻辑过时时比较两个转换版本。如果转换的输入未更改且转换的版本未更改，则转换的输出是最新的。如果版本发生变化，转换的输出将被无效并重新计算。

默认情况下，转换的版本包括以下内容：

  • 转换定义所在的模块
  • 转换所依赖的所有模块
  • 任何项目依赖项

如果其中任何内容发生变化，版本字符串将被更改。 如果您希望在所列部分未覆盖的文件发生更改时使输出失效，请设置 tllvFiles 菜单中选择 transformsPython 。一个使用案例是，如果您正在读取文件的配置，并且在配置更改时希望使输出失效。

事务性

转换操作将在一个事务的上下文中执行，该事务在输出上打开并在任务成功时提交。如果没有在输出上定义任何逻辑，或者在写入时捕获并吞下了错误，成功的转换将在这些输出上产生一个空快照。
