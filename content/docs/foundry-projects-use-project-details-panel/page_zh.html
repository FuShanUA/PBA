使用项目详情面板

您可以通过选择项目页面右侧的图标之一来打开资源详情面板。

概述

直方图 概述 面板汇集有关资源的一般信息，包括其资源标识符 (RID)。在项目的 文件 页面和文件夹页面上，详细信息面板会打开至 概述 ，除非它已在显示其他面板。要稍后返回该面板，请在右侧图标中选择信息图标。该图标的工具提示为 概述.

对于项目， 概述 会显示一个 描述Workshop 项目联系人，而 元数据 部分。在 描述 和 项目联系人之间，还可能出现另外三个部分：

  • 文档： 项目文档的预览，带有一个 将, 编辑，或 要在标记和发布函数的过程中查看进度，请选择 按钮，可打开 文档 面板。当项目有文档或您可以编辑项目的元数据时，您会看到此部分。
  • Marketplace 安装： 当项目由 Marketplace 安装创建，或项目包含已安装的 Marketplace 产品时，您会看到此部分。
  • 如果手动上传失败，回滚到已知稳定版本。 当启用了基于分类的访问控制时，您会看到此部分。

中的第一个字段是 元数据 is RID，即项目的资源标识符。要复制它，请选择只读字段末尾的复制按钮 RID 字段中，复制在 Quiver 仪表板中定义的对象输入名称。

其余的 元数据 字段按其显示顺序依次为 位置, 空间, Iceberg 存储, 标签, 所属项目组合, 状态, 和, 创建时间, 最后修改时间日 浏览量。仅在有可用详细信息时才会显示这些字段。

如果您可以查看项目的封面页但无法查看其内容， 概述 会显示一个精简的 元数据 部分，其中仅包含项目自身的 RID, 位置日 空间.

文档

此部分提供了一个基于Markdown的富文本编辑器，用于在 项目或文件夹级别编写文档，类似于工作区中的所有文档部分。

选项卡中选择

活动日志提供整个项目中所做更改的持续视图，仅在项目级别可见。对于构建新项目或维护长期项目的团队而言，活动日志使了解近期活动和协作变得更加容易，但它仅存储最近一个月的活动。

可发现性

如有需要，您可以将您的项目及其描述对其他组织中的人员进行公开。此功能正在开发中。

访问权限

直方图 访问权限 选项卡允许您管理项目内的组和用户访问角色。

对于一个项目 Owner，此面板提供了一个接口，用于添加所需的标记、管理默认访问权限，并通过授予其他用户和组角色来配置额外的访问权限。
