将字符串转换为日期

支持环境：Batch、Faster、Streaming

根据 Java DateTimeFormatter，返回与格式化字符串对应的日期。默认格式为 yyyy-MM-dd 和 yyyy-MM-dd'T'HH:mm:ss.SSSXXX。格式按顺序运行，将返回第一个匹配的格式。

表达式类别： 类型转换, 日期时间

声明的参数

  • 或 要解析为日期的字符串列。
    Expression<String>
  • 可选 格式： 输入日期格式（例如 yyyy-MM-dd 或 MM/dd/yyyy）。
    List<Literal<String>>

输出类型： 日期

示例

示例 1：基础用例

描述： 日期格式为可选项

参数值：

  • 或 2020-04-28
  • 格式： 空值

输出： 2020-04-28

示例 2：基础用例

描述： 日期格式为可选项

参数值：

  • 或 2020-04-28T01:00:00.000Z
  • 格式： 空值

输出： 2020-04-28

示例 3：基础用例

描述： 使用单一格式解析的日期。

参数值：

  • 或 28-2020-04
  • 格式： [dd-yyyy-MM]

输出： 2020-04-28

示例 4：基础用例

描述： 用于解析日期的多种格式

参数值：

  • 或 28-2020-04
  • 格式： [yyyy-MM-dd, dd-yyyy-MM]

输出： 2020-04-28

示例 5：基础用例

描述： 如果日期缺少前导零，仍可使用 "yyyy-M-d" 格式正确解析。

参数值：

  • 或 date
  • 格式： [yyyy-M-d]

参数值：

  • 格式： [dd-yyyy-MM HH:mm X]

输出： 2020-04-28

描述： 时区可以改变日期。

输出： 2020-04-27

示例 8：空值情况

描述： 空值列保持为空

参数值：

  • 或 空值
  • 格式： [dd-yyyy-MM]

输出： 空值

示例 9:边界情况

示例 11：边缘情况

描述： 年积日格式默认年份为 1970。

参数值：

  • 格式： [D]

示例 12：边界情况

描述： 三位数年积日格式默认年份为 1970。

参数值：

  • 格式： [DDD]

示例 13：边缘情况

描述： 不含年份的格式默认年份为 1970。

参数值：

  • 或 12-25

输出： 1970-12-25

示例 14：边界情况

  • 格式： [MM]

输出： 1970-03-01

示例 15：边界情况

  • 格式： [m]
