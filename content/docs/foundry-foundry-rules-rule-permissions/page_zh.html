编辑规则的权限

在某些工作流中，您可能希望限制可以编辑或修改规则的用户范围。以下示例展示了如何设置权限，使规则作者对影响其规则的任何更改拥有最终批准权。

权限设置如下：

  • 只有规则作者（以及超级用户）才能批准编辑其规则的提案。
  • 只有规则作者（以及超级用户）才能批准删除其规则的提案。
  • 只有规则作者和提案创建者（以及超级用户）才能拒绝针对规则所有者的规则提出的提案。
    • 为了缓解意外提案的问题，提案创建者也可以拒绝提案。例如，如果用户 A 意外对用户 B 的规则创建了提案，用户 A 可以拒绝（实际上是撤回）该提案。

请按照以下步骤实现此权限设置：

  1. 配置 批准编辑规则的提案 操作，使用户必须是与该提案关联的规则作者或超级用户。



  2. 配置 批准删除规则的提案 操作，使用户必须是与该提案关联的规则作者或超级用户。

  3. 配置 拒绝提案 操作，以便用户必须是与提案关联的规则作者、提案作者或超级用户之一。



如果您没有看到基于规则对象进行验证的选项，则可能是您尚未将该规则对象作为参数添加到操作中。请将新的规则对象参数添加到 拒绝提案 操作中，就像您为其他 Foundry Rules 操作添加规则对象参数一样。
