输入预设

为了使安装配置更快速、更可靠，您可以在产品输入中使用预设和默认值：

  • 预设： 为输入定义一组允许的值。如果预设被设为必选，安装人员必须从提供的选项中进行选择，且不允许使用自定义值。
  • 默认值： 在开始安装时，将其中一个预设指定为输入的初始值。

这些功能有助于确保遵循最佳实践、减少错误并加快安装流程。在安装过程中，带有默认值的输入会被自动映射，从而减少安装人员的手动操作。

添加预设和默认值

在打包产品时，请在表格中选择一个输入。您可以在侧边栏中设置预设和默认值。 在侧边栏中，您可以选择用于预设的方法。

  • 无： 该输入将不使用任何预设。
  • 来源： 使用您的源实体所依赖的同一输入。如果该输入随时间发生变化，预设将自动更新。
  • 覆盖： 手动提供预设列表。

配置预设后，您可以选择性地指定将哪个预设用作默认值。

  • 来源： 在 用作默认值 选项下选择，该选项位于 高级设置中。
  • 覆盖： 将鼠标悬停在所需的默认值上。使用 ... 下拉菜单，并将覆盖值设置为默认值。

您可以为输入项批量设置 来源 预设。为此，请在表格中选择输入项，然后使用页面底部的 设置预设 选项。

使用预设和默认值进行安装

设置完成后，安装人员将被引导使用预设来填充输入。在已配置的情况下，安装人员可以提供自己的输入值。

某些预设类型（例如本体论实体）使用基于 API 名称的预设，这意味着它们将在目标安装位置（空间和本体论）中被查找。请查看 跨环境兼容性 以了解更多详情。

安装人员可以选择 跟踪默认值，这样在升级到不同的产品版本时，如果默认值发生变化，输入将会自动更新。

跨环境兼容性

特定输入类型使用定位符（如 API 名称）来确保预设和默认值在不同环境和注册中都能正常工作。例如，对象类型预设会使用其 API 名称，在安装过程中查找目标本体论中相应的对象类型。

在受支持的情况下，此信息将在打包过程中显示。

如果目标安装环境中没有满足预设要求的资源（例如，没有具有所需 API 名称的对象类型，或没有具有所需 RID 的数据集），则无法选择该预设。如果 允许自定义值 已针对此类输入勾选，则安装人员可以为该输入提供自己的资源并继续进行安装。但是，如果不允许自定义值，安装人员将无法安装该产品。
