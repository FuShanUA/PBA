本体论指标

Ontology Manager 可配置为显示对象类型和关联类型的使用指标。

关键术语

  • 读取： 当应用程序为指定对象类型加载对象时，会记录一次读取。这包括在 Workshop 的表格中显示对象、从搜索中返回给定对象类型的所有对象、对对象类型上的属性进行聚合等。一次读取代表来自 对象存储 v1（Phonograph） 或对象集服务（OSS）的一次加载请求。一次加载或聚合多个对象只会记录为一次读取。Ontology Manager 中的任何对象类型或关联类型的使用均不包含在内。
  • 写入： 当应用程序由于 操作, 函数、Foundry 表单、直接的 Object Explorer 编辑或 API 调用而对此类型的对象进行编辑时，会记录一次写入。一次写入代表发送到 对象存储 v1（Phonograph）的一次编辑请求。一次批量编辑多个对象只会记录为一次写入。
  • 交互： 过去 30 天内对此类型对象的读取和写入总数。
  • 活跃用户： 过去 30 天内触发所记录的读取和写入的唯一用户 ID 数量。

查看使用情况

在 Ontology Manager 中有两个地方可以查看对象类型和关联类型的使用情况：

  • 使用图表位于 概述 标签页：过去 30 天使用情况的高层级摘要，使本体论用户能够快速了解对此资源进行破坏性变更的影响。

空的使用图表可能表明内部表未配置

如果您在使用图表中看到“过去 30 天无使用情况”，但您预期应该看到使用统计信息，则可能是内部表尚未配置。请联系您的 Palantir 代表以获取更多信息。

  • 专用的 用法 标签页：资源的详细使用指标。用户可以查看过去 30 天内谁使用了每个对象类型、何时使用以及在哪些 Foundry 应用程序中使用。此功能旨在通过更清晰地了解变更的影响，帮助本体论用户更安全地进行本体论变更。 用法 标签页也可以通过点击 查看更多 来访问，位于 概述 tab.

标签页中的使用图表上。

启用本体论使用情况 概述 标签页以及详细使用指标位于 用法 标签页，均可在 Control Panel 的 本体论设置 标签页中使用 本体论指标 开关进行配置。此开关只能由本体论管理员启用或禁用，更改可能需要长达 60 分钟才能在 Ontology Manager 中生效。

共享本体论使用情况

如果您的组织与另一个组织共享本体论，那么 用法 标签页将可供所有已开启本体论指标的组织中的用户访问。显示的使用指标仅包括有权访问该对象类型的用户以及来自已启用本体论指标的组织的使用情况。请参阅 标签页中的使用图表上。 的文档以获取更多信息。
