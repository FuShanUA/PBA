changelog(identifier_columns=None)

为给定表从上次处理的快照 ID 开始创建变更日志视图。

注意：仅支持 Iceberg 表。

如果提供了标识符列，则会创建基于标识符的变更日志。此类变更日志会提供对由给定标识符列唯一标识的行所执行的最新更改。这种方式性能更高，并且在执行行编辑时具有更大的灵活性。

如果不提供标识符列，则会创建净变更（net-changes）变更日志。此类变更日志通过抵消的方式合并对行执行的更改 DELETES 和 INSERTS 在快照范围内的更改。这会导致大量数据重排，并且比基于标识符的变更日志更慢。

如果此变更日志将用于更新输出表，则创建此变更日志时所使用的标识符列应与更新输出表时所使用的标识符列相匹配。

参见 Iceberg create_changelog_view ↗ 文档以了解更多信息。

  • 参数： identifier_columns (列表 [str ↗ ] , 可选) – 唯一标识每一行的列的列表（如果存在）。
  • 返回： 包含原始表结构以及 _change_type, _change_ordinal and _commit_snapshot_id 列的临时变更日志视图。对于基于标识符的变更日志， _change_type 可以是 INSERT, DELETE, UPDATE_AFTER or UPDATE_BEFORE。对于净变更（net-changes）变更日志， _change_type 可以是 INSERT or DELETE.
  • 返回类型： DataFrame ↗

dataframe(mode='added', options=None)

返回一个 pyspark.sql.DataFrame ↗ ，用于给定的读取模式。

changelog Iceberg 表的读取模式会返回给定表从上次处理的快照 ID 开始的变更日志视图。与 changelog() 方法不同，此方式始终创建净变更（net-changes）变更日志，其性能不是很高，但支持没有标识符列（即唯一标识每一行的列的列表）的表。请注意，此读取模式已被弃用。请使用 changelog() 来替代。

  • 参数：
    • mode (str ↗ , 可选) – 读取模式，可选值为 current、previous、added、modified、removed 或 changelog。默认值为 added。
    • options (dict ↗ , option) – 读取表时要传递的额外 Spark 读取选项。
  • 返回： 表的 DataFrame。
  • 返回类型： DataFrame ↗
