changelog(identifier_columns=None)

从上次处理的快照 ID 开始，为给定表创建变更日志视图。

注意：仅支持 Iceberg 表。

如果提供了标识符列，则会创建基于标识符的变更日志。此变更日志类型可为您提供对由给定标识符列唯一标识的行所做的最新更改。此方式性能更高，并且在执行行编辑时具有更大的灵活性。

如果未提供标识符列，则会创建净更改变更日志。此变更日志类型为您提供对行执行的合并后的更改，这是通过抵消 DELETES 和 INSERTS 在快照范围内实现的。这会导致大量数据重排，并且比基于标识符的变更日志更慢。

如果此变更日志旨在用于更新输出表，则创建该变更日志时所使用的标识符列应与更新输出表时所使用的标识符列相匹配。

请参阅 Iceberg create_changelog_view ↗ 文档以获取更多信息。

  • 参数： identifier_columns (List [str ↗ ] , 可选) – 唯一标识每一行的列的列表（如果存在）。
  • 返回： 临时变更日志视图，包含原始表结构以及 _change_type、 _change_ordinal 和 _commit_snapshot_id 列。对于基于标识符的变更日志， _change_type 可以是 INSERT、 DELETE、 UPDATE_AFTER 或 UPDATE_BEFORE。对于净变化变更日志， _change_type 可以是 INSERT 或 DELETE。
  • 返回类型： DataFrame ↗

dataframe(mode='added', options=None)

返回一个 pyspark.sql.DataFrame ↗ ，用于给定的读取模式。

changelog 读取模式（针对 Iceberg 表）会返回给定表自上次处理的快照 ID 以来的变更日志视图。与 changelog() 方法不同，这始终会创建净变化变更日志，其性能欠佳，但支持不含标识符列（即唯一标识每一行的列的列表）的表。请注意，此读取模式已弃用。请使用 changelog() 来替代。

  • 参数：
    • mode (str ↗ , 可选) – 读取模式，可选值为 current、previous、added、modified、removed 或 changelog。默认为 added。
    • options (dict ↗ , option) – 读取表时要传递的附加 Spark 读取选项。
  • 返回： 该表的 DataFrame。
  • 返回类型： DataFrame ↗
