现在，您可以在 Builder 管道中创建自己的函数套件，并将其用作管道中的一等转换。函数可以基于路径中的单个画板或多个画板来创建。这些函数由人类可读的部分组成，让组织中的非技术用户能够更轻松地参与和使用这些逻辑。您可以通过图视图中的

自定义函数包括 自定义表达式 和 自定义转换。这两种功能都适用于在管道中重复使用逻辑，同时在一个位置进行管理。在 Pipeline Builder 界面中，它们分别通过以下方式访问： 自定义表达式 和 自定义转换路径 图表工具 可复用项 来创建一个临时的实体级别维护窗口。

自定义转换 使您能够将一系列转换板保存为单个转换，以便在整个管道中重复使用。

自定义表达式 使您能够保存带有可选参数的单个表达式，以便在整个管道中重复使用。自定义表达式可在其他转换（如过滤器或 case 语句）中使用。

自定义函数通常由 name （必需）、 描述 （可选）、 函数参数 （可选）以及 函数定义 （必需）组成。

创建自定义表达式

要创建自定义表达式，请选择图形顶部的 可复用项 下拉菜单，然后选择 自定义表达式.

选择 添加自定义表达式.

在新窗口中配置您的自定义表达式。在左上角输入名称，在 参数 窗口中使用 添加参数 选项添加任意参数，并定义您的表达式。完成后选择 保存您的更改。 。

创建自定义表达式后，您可以在转换节点或转换中像搜索其他任何表达式一样搜索它。

创建自定义转换

创建自定义转换需要两个步骤：

  1. 将您的逻辑定义为一系列转换板。
  2. 将这些转换板转换为新的自定义函数。

下面，我们将逐步骤查看示例。

定义一系列转换板

假设您有一个包含 users的表格，并且您想创建一个主键来唯一标识每个用户。您知道每个用户的 first_name, last_name日 first_login_date 是一个唯一的组合。您想在数据集中添加一个类型为 primary_key 的列 String ，该列是这三列的哈希值，然后删除 first_name, last_name日 first_login_date。最后，如果存在重复项，您希望每个用户只保留一行，即保留 age 值。

最低的行。首先，将 first_name, last_name日 first_login_date 合并为一列。您可以使用 Concatenate strings 转换将这三列相加。

对于 Separator 字段中，输入 -。然后，在 表达式 下拉菜单中选择每一列。对于前两列，选择 first_name 和 last_name。但是， first_login_date 列不是我们第三个字段可选择的选项。这是因为它是 Date 类型，而 Concatenate strings 函数只接受 String 类型。

要解决此问题，请从 Cast 选项卡中插入一个 表达式 表达式。参数将为 first_login_date 选项卡中为 Expression 和 String 选项卡中为 Type 以将其转换为此类型。这避免了全局更改 first_login_date ，从而影响所有下游转换板。

将一系列转换板转换为自定义函数

现在，假设您希望在管道中的三个不同位置重用此逻辑。我们可以使用 Shift + Down Arrow 来选择两个板，然后选择 + 顶部栏中的按钮。

这将带您进入自定义函数创建页面。您会注意到列输入 first_name, last_name, first_login_date日 age 被划掉了；这是因为您正在创建的函数对于管道中正确类型的任意四个输入都是通用的，与列名无关。

要定义这些输入，请选择 添加参数 四次。通过点击黄色框来配置参数名称。

然后，通过点击每个参数右侧的齿轮图标来配置参数类型。这里，您希望前两个参数的类型为 Expression<String> 以表示 String 类型的列，第三个参数的类型为 Expression<Date>，最后一列的类型为 Expression<Integer>.

现在，您可以像之前一样将新参数添加到这两个板中。但是，它们现在将显示在 Parameters 部分，而不是 Columns 区域的字段中添加命令。

完成配置后，将函数命名为 Primary key generator，为其添加可选的描述，然后选择 应用所有更改.

新函数现在可在任何转换路径中使用。下次您需要使用此模式创建主键时，可以在转换下拉菜单中搜索 Primary key generator 。

您可以使用原始列填充您的自定义函数： first_name, last_name, first_login_date日 age.

通过将相关列名填充到自定义函数中，您将获得与在路径中使用相同转换创建函数相同的结果。但是，通过创建自定义函数，您可以将函数逻辑保存以便在整个管道中重用，而无需使用单独的转换板重新创建逻辑。
