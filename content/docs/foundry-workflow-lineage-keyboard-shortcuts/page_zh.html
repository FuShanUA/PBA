键盘快捷键

先前称为 Workflow Builder 的应用程序现在称为 Workflow Lineage。

要查看 Workflow Lineage 中可用的键盘快捷键列表，请选择 帮助 > 查看热键.

可用的热键如下：

全局macOSWindows
撤销上次更改Cmd + ZCtrl + Z
重做上次更改Cmd + YCtrl + Y
重做上次更改Cmd + Shift + ZCtrl + Shift + Z
保存图表Cmd + SCtrl + S
图表macOSWindows
缩放以适应节点↑↑
缩放以适应节点HomeHome
显示/隐藏 Workshop 应用程序拆分视图II
取消选择所有节点EscEsc
将节点复制到剪贴板Cmd + CCtrl + C
移除所选节点DeleteDel
移除所选节点BackspaceBackspace
布局所有节点Cmd + Shift + ACtrl + Shift + a
层次布局Shift + LShift + L
布局节点LL
聚类层次布局Alt + LAlt + L
网格布局GG
垂直布局VV
水平布局HH
选择所有节点Cmd + ACtrl + A
反选（选择未选中的节点）Cmd + ICtrl + I
选择下游节点→→
选择上游节点←←
选择所有下游Shift + →Shift + →
选择所有上游Shift + ←Shift + ←
