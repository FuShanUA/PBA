使用值类型

一旦您 创建了值类型，您就可以在整个 Foundry 中将其用作数据类型或可复用约束。支持的用例包括：

  • 将值类型分配给对象类型属性。
  • 将值类型分配给共享属性。
  • 将值类型作为逻辑类型分配给 Pipeline Builder 管道属性，方法是使用 logical type cast 表达式，并在写入对象目标时在该属性上选择值类型。
  • 约束操作参数可接受的值。

将值类型分配给属性

要将值类型分配给属性，请在属性配置过程中从下拉菜单中选择该值类型。

如果您将值类型应用于某个对象属性，而该属性包含未通过验证的属性值，则该对象类型将无法建立索引。您可以在 Ontology Manager 的对象类型健康状态中查看此类索引失败情况，并可在其中更正数据或更新值类型以解决该问题。

使用值类型约束操作参数

使用值类型约束将可复用的验证规则应用于操作参数：

  1. 在 Ontology Manager 中，打开操作类型并选择 参数 选项卡。
  2. 选择要约束的参数。
  3. 在 约束 卡片中，选择 值类型 作为约束类型。
  4. 选择一个值类型。
  5. 保存更改。

值类型选择器仅显示其 基础类型 与参数类型兼容的值类型。值类型约束适用于 String、 Integer、 Long、 Double、 Decimal、 Date和 Timestamp 参数，包括这些类型的列表参数。对于列表参数，请选择 Array 值类型来约束整个列表。若要将相同的约束应用于列表中的每一项，请选择兼容的非数组值类型。值类型约束不能应用于结构体参数或其字段。您可以 在单个结构体参数字段上配置其他受支持的约束。

在操作验证和提交期间，参数值必须满足所选的值类型约束。如果验证失败，则无法提交操作，并会显示值类型的 验证失败消息。值类型的非破坏性更新会自动传播到操作类型。详细了解 值类型版本。
