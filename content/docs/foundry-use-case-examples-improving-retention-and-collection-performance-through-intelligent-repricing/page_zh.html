通过智能重新定价提升留存率和催收绩效

行业领域： 金融服务

业务职能： 运营

一家支付处理商希望通过优化催收、对价格敏感度较低的商户进行重新定价，以及留住有流失风险的高价值客户，来增加来自中小商户的收入。然而，由于其数据环境高度分散且规模庞大，他们无法开展将这些构想付诸实施所需的分析。

挑战

在该处理商的运营规模下，主要面临两大挑战：

  • 缺乏有效的方法来确定商户催收的优先顺序或排名
  • 确定商户最优费率和费用的能力有限

解决方案

  • 商户活动的完整视图 — 该公司通过整合涵盖客户活动、定价、支付终端、账单、欺诈和信用历史的海量数据，对其客户群形成了前所未有的深入理解。

  • 催收效率提升 — 分析师开发统计模型，根据账户付款的可能性对其进行评级。高可能性账户会被转至内部催收团队，而低可能性账户则会转交第三方催收机构。

  • 新定价策略 — 分析师进行大规模分析,评估不同费用结构对客户留存率的影响。销售团队利用这些洞察为新账户制定更合理的价格,并对现有账户重新定价,以防止客户流失。

利益相关者和用户群体

  • 商户催收团队
  • 财务分析师
  • 数据科学家
  • 销售团队

财务分析师使用 Foundry 为商户开展重新定价工作,以确保留存率并实现收入最大化。

影响

  • 将无法收回的账户筛出并转给第三方,并对回收可能性高、价值高的账户进行优先处理,从而提升了催收绩效。得益于改进后的优先级排序,预计每年可额外收回数百万美元。
  • 重新定价模型助力商户开展重新定价工作,不仅提高了留存率,还在目标收入之外额外创造了数百万美元。

运作方式

  • 集成了客户关系管理 (CRM) 系统和其他数据源,以创建统一的 Foundry 本体论 来了解商户活动。为客户及其活动、定价、支付终端、账单、欺诈、信用记录等创建了对象和关联。
  • Contour 和其他 Foundry 分析工具用于执行分析,以确定新的催收和定价方法。不同定价方案的情景分析在 Contour 和 Code Workbook中非常简单。 Vertex 并且可以应用 Foundry Scenarios 来进一步支持此流程。
  • 用于确定催收优先级和重新定价的机器学习模型是在 代码仓库中实现的。 Foundry ML 也可以考虑在此处使用。
  • 重新定价应用程序是在 Slate中实现的。
