可视化函数

可视化函数 是使用 Quiver 的点击式界面构建的可重用逻辑块。这些函数可以在同一 Quiver 分析或其他 Quiver 分析中多次使用。可视化函数作为独立资源发布在 Foundry 中，可以与其他用户共享，其他用户也可以在自己的 Quiver 分析中使用这些函数。

可视化函数允许您：

  • 使用点击式界面构建可重用逻辑，无需编写代码，
  • 通过构建可重用函数的共享库与同事协作，
  • 在一个位置轻松更新多个分析中的通用逻辑，降低手动错误或逻辑不匹配的风险，
  • 简化大型分析，提升加载和导航性能。

输入

可视化函数包含零个或多个输入。输入是函数的参数，用户在使用函数时可以对其进行配置。支持的输入类型包括：指标、对象集、单个对象或时间序列。不支持将可视化（分类或非分类）和表格作为输入类型。

输出

可视化函数有一个输出。函数的输出是函数返回的结果。支持的输出类型包括：指标、对象集、单个对象或时间序列。

不支持将可视化（分类或非分类）和表格作为输出类型。

函数卡片包含函数的输出，可用作 Quiver 分析中其他卡片的输入。

逻辑

Quiver 函数的逻辑是分析图上输入和输出之间包含的所有卡片。
