创建派生序列

在 Time Series Catalog 应用程序中创建派生序列。从 Time Series Catalog 的起始页面，在左上角选择 派生序列 。在下一页，从右上角选择 + 新建派生序列 。请按照以下步骤继续创建您的派生序列。

1. 选择派生序列类型

选择您是要配置 模板化 还是 单一 派生序列。当您派生的新时间序列将使给定类型的所有对象受益时，应使用模板化派生序列。当您想要构建一个依赖于多个对象的派生时，应使用单一派生序列。

对于模板化派生序列，选择根对象类型后，您将进入逻辑视图，其中已选中一个指定类型的预览对象。您可以在页面顶部更新预览根对象。

对于单一派生序列，系统将提示您为逻辑选择起始对象。请注意，单一派生序列 并不 具有预览对象，因为逻辑中可能涉及多个对象。

确认后，您将被引导至逻辑视图，其中会显示 时间序列属性 卡片（每个所选对象对应一张）。

2. 添加时间序列数据

使用 时间序列属性 卡片，可从对象中选择时间序列，用于模板化派生序列和单一派生序列。

此卡片允许您选择对象上的时间序列属性，以及任何关联的传感器（如果存在）。

请记住，模板化派生序列必须在单个根对象上运行；在创建模板化派生序列时，Time Series Catalog 界面将阻止您向逻辑中添加多个对象。

在创建或编辑单一派生序列时，您可以随时从逻辑视图添加更多数据，方法是使用 添加时间序列数据 选项（位于右上角）。或者，选择 插入 （位于卡片上方或下方），然后选择 + 添加时间序列数据。

在弹出窗口中确认时间序列对象后，将创建 时间序列属性 卡片（每个所选对象对应一张）。

3. 应用转换

通过插入新卡片，将相关转换应用于您的时间序列。

例如，要在假设的 Machine 对象类型上计算压力损失，该对象类型带有 Inlet pressure 和 Outlet pressure 传感器，请添加以下卡片：

  1. 一个 时间序列属性 卡片，其中 Inlet pressure 已选定
  2. 一个 时间序列属性 卡片，其中 Outlet pressure 已选定
  3. 一个 时间序列公式 卡片，用于计算 $E - $G，假设标识符 $E 为 Inlet pressure 且 $G 为 Outlet pressure。标识符位于每个卡片的左上角。

4. 选择输出

完成推导后，通过选择 设为输出 （位于卡片标题栏右上角），即可将最终转换设为逻辑输出。

5. 保存

对逻辑满意后，选择 保存 （位于页面右上角）。

6. 配置本体论保存选项

选择 自动 本体论保存，以将派生序列直接保存到本体论。

自动本体论保存仅支持传感器对象类型。您可以选择在创建后配置自动本体论保存；但是，您将无法更改所选的对象类型。创建需要手动保存的派生序列后，请按照 文档 中的说明操作，以成功将引用保存到本体论。

选择将绑定到派生序列的对象类型。对于模板化派生序列，此对象类型可以是 根对象类型 （即您创建派生序列逻辑时所基于的对象类型），或其任一 关联的传感器对象类型。对于单一派生序列，可以选择任何根对象类型或传感器对象类型。

此绑定的对象类型是唯一可从中解析派生序列的对象类型。保存后，您将无法更改绑定的对象类型。

通过配置传感器名称、范围、属性映射和操作类型，继续设置自动本体论保存。

传感器名称： 提供一个传感器名称，以便在派生序列保存到本体论后对其进行标识。此值将包含在属性映射中。

范围选择： 模板化派生序列必须提供根对象范围。此范围允许您选择要为其保存此派生序列的根对象。将为每个选定的根对象创建一个传感器对象。目前，范围选择限制为 5000 个对象。

属性映射： 属性映射为传感器对象属性提供值。这些值将用于所有已创建的传感器对象。目前，仅支持字符串或布尔值。大多数传感器对象属性会自动映射。

操作类型： 自动本体论保存利用操作将派生序列保存到本体论。作为前提条件，您必须具有 Create object， Modify object，以及 Delete object 为对象类型配置的操作类型。如需了解有关为自动保存本体论设置操作类型的更多信息，请参阅 派生序列要求 文档。

有关派生序列存储位置的指导，请参阅时间序列 本体论设置文档。

7. 选择资源位置

选择名称和文件夹位置以保存生成的派生序列资源。

8. 审查

最后，在保存前审查本体论输出和资源位置信息，并可选择提供版本描述。

保存派生序列后，如需进行任何后续更改，必须前往 派生序列管理页面。

删除派生序列资源 不会 删除已添加到本体论中的关联对象。在删除派生序列资源之前，请先 从本体论中删除派生序列。

高级：在 Quiver 中创建派生序列

还可以直接从 Quiver 分析中创建派生序列。

选择任意时间序列卡片并查看 “派生序列选项” 配置，然后选择 “创建派生序列”。

保存对话框与时间序列目录创建对话框类似，但您必须选择要配置的派生序列类型。如果派生序列作用于多个对象，您将无法选择模板化选项。

从 Quiver 分析创建的派生序列在创建后将不会与其 源 分析保持关联；今后对派生序列的所有管理都必须在 派生序列管理页面中进行。

我们建议使用时间序列目录来创建派生序列，因为并非所有 Quiver 操作都在派生序列中受支持。
