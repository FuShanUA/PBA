代码工作区

Code Workspaces 将 JupyterLab®、RStudio® Workbench 和 VS Code 第三方 IDE 引入 Palantir Foundry，使用户能够在 Foundry 本体论的高质量数据上使用自己偏好的工具，从而提升工作效率并加速数据科学和统计工作流。Code Workspaces 容器与 Foundry 生态系统的其余部分原生集成，将熟悉的 IDE 与 Foundry 平台的优势（如数据安全、分支、构建调度和资源管理）相结合。

Code Workspaces 为平台管理员提供了一种易于部署、完全托管、安全且可用于生产环境的方式，向用户提供 JupyterLab®、RStudio® Workbench 和 VS Code，并内置 Foundry 的数据治理以及对 FedRAMP、GxP 等标准的合规性。借助 Code Workspaces，用户可以安全地连接到现有的内部系统，并在数据上构建分析、转换、模型、应用程序或完整的工作流，同时享有 Foundry 的访问控制和数据权限管理。

主要功能

Code Workspaces 的主要功能包括：

  • 安全性： Code Workspaces 构建于以下核心组件之上： Foundry 安全 这些组件是整个平台的基石，例如权限和细粒度访问控制。这为 Code Workspaces 中可用的第三方 IDE 提供了 Foundry 的安全模型。例如，在 Foundry 中限制对某个数据集的访问，也会限制 Code Workspaces IDE 对该数据集的访问，从而确保各工具之间权限的一致性。

  • 可自定义的环境： Code Workspaces 允许用户定义自定义环境配置文件，并根据需要增加或减少工作区的计算资源。

  • Git 工作流支持： Code Workspaces 由以下基础设施支撑： 代码仓库 该基础设施提供分支、合并和提交历史等业界标准的版本控制功能。这些功能使多个用户能够更轻松、更安全地在同一工作区中协同工作。

  • 代码查看器： 直方图 代码查看器 提供了一个只读界面，无需启动编辑器工作区即可浏览、搜索、比较和共享仓库的已提交状态。

  • 应用程序： 代码工作区目前支持 Dash ↗ 和 或 适用于 Python 应用程序，以及 Shiny® ↗ 适用于 R 应用程序。用户可以直接在 Code Workspaces 中创建应用程序工作流，并内置 Foundry 的版本控制、分支和数据治理功能。

  • 模型集成： 用户可以在 Code Workspace 中创建模型资产，并通过以下方式跟踪这些资产： 建模目标。可以从同一工作区创建多个模型。

  • 转换/构建集成： Code Workspaces 可作为转换的开发环境。在 Code Workspaces 中编写的逻辑可以作为数据转换管道发布，并与 Foundry 的 数据集成 工具包集成，包括构建、调度、数据血缘和健康检查。Code Workspaces 同时支持 R 转换和 Python/Jupyter® 转换。

  • AIP 辅助编码： JupyterLab® 和 RStudio® Code Workspaces 在工作区侧边栏中包含一个 AIP 代理，可连接到 支持的 AIP LLM。该代理可以生成和解释代码、分析数据、自动执行库安装和数据清理等重复性任务，并帮助您构建 Dash 和 Streamlit 应用程序。此功能在以下条件下可用： 已启用 AIP 的情况下.

  • 通过数据源集成外部系统： 数据源让您能够安全地与外部系统交互，并为交互式工作流和已发布的应用程序管理密钥、出口和导出控制。详情请参阅 与外部系统交互.

何时使用 Code Workspaces

Foundry 提供多种可用于分析或编程的应用程序。例如，如果您是分析师，Contour 可能最适合您——它是 Foundry 用于数据集分析的点击式低代码界面。

如果您需要编写大规模数据管道、设置数据连接或处理流数据，其他 Foundry 工具比 Code Workspaces 具备更多功能；对于这些用例，我们建议分别使用 如果希望用户在每次运行预览前手动确认，请开启, 数据连接日 Foundry Streaming。

具体而言，Code Workspaces 在单个节点上运行，而其他 Foundry 应用程序则利用 Spark 基础设施。因此，我们建议执行大规模数据转换的用户选择 如果希望用户在每次运行预览前手动确认，请开启 or 代码仓库 ，而不是 Code Workspaces。

使用 Code Workspaces 在 VS Code、JupyterLab® 或 RStudio® Workbench 中结合 Foundry 的数据和服务开发代码。使用 代码查看器 可以在不启动编辑器工作区的情况下检查或共享已提交的仓库代码。
