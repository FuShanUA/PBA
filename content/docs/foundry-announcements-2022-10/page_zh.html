Action Log 简介：将决策转化为数据

发布日期：2022-10-26

自动捕获决策

借助 Foundry 中的 Action Log，您现在可以在做出决策时存储世界的状态，从而不仅能够追踪正在发生的变化，还能了解变化的原因。

当用户在 Foundry 中做出决策（即“采取 操作”）时，它会修改本体论，这是一个反映组织运营现实的数据层。（在此处阅读更多关于 Foundry 本体论的信息.)

对本体论的所有更改都可以存储在 Action Log 中，以便为您的决策提供背景信息；这些更改可作为数据在 Foundry 中进行分析、调查和查看。其结果是一个完全情境化的交叉工作流网络，详细展示了您的组织如何运作以及正在做出哪些决策。

自动捕获您的决策

当您创建启用日志记录的新操作时，系统会随每次执行的操作自动创建 Action Log 对象类型。系统会在该对象与所提交操作编辑的所有对象之间创建多对一关联，使应用构建者能够遍历决策与本体论编辑之间的关系。

例如，如果同时完成四个任务，则会生成一个 Action Log 并关联到所有四个任务。授权用户随后可以查看 Action Log，以了解谁执行了该操作以及何时完成。所有这些只需一个开关即可完成。

回顾世界的原貌

Action Log 对象可以存储已编辑和未编辑的属性。默认情况下，Action Log 会存储用户 ID、时间戳和其他元数据。这使应用构建者能够在做出决策时捕获运营背景。当您更改操作的逻辑时，Action Log 对象类型的架构也会自动更新，让您在构建新的基于决策的工作流时保持迭代速度。例如，在完成任务时，您可以存储新编辑的“status”属性以及未更改的属性（如“region”）。这些信息可以帮助您回答诸如“在哪个区域任务完成所需时间最长？”之类的问题。

直接在 Foundry 中分析

使用 Workshop 中的 Action Log 部件，以时间线视图显示所选对象的更改历史。条目包括可配置的属性和参数化的文本描述，因此易于理解。此外，您可以将 Action Log 对象输入到其他 Foundry 应用中进行进一步分析，或作为转换的输入以构建更复杂的分析管道。
