排程甘特图 widget

排程甘特图是一个 Workshop widget，可为排程或资源分配工作流渲染交互式甘特图。在设置该 widget 之前，请确保您已配置好您的 动态排程本体论.

配置排程甘特图 widget 的模块构建者可以：

  • 为资源对象行设置标题和副标题属性（包括图标和函数支撑属性）。
  • 选择在右键菜单中显示的操作、事件和建议。
  • 选择一种 puck 样式 并自定义 puck 的颜色和交互（分配行为、吸附行为）。

Widget 布局

下图提供了该 widget 布局的概览。

  1. 排程对象（puck）： 每个排程对象在排程甘特图上渲染为一个 puck。用户可以拖放这些 puck 来更新对象的开始时间、结束时间和/或关联的资源对象。Puck 由两项额外功能支撑：
    • 排程对象详情： 当光标悬停在 puck 上时以卡片形式显示。默认情况下，卡片会显示开始/结束时间、在排程对象类型上配置的任何规则的状态，以及指向对象视图的关联。构建者还可以添加希望显示的属性。
    • 右键菜单： 当用户右键点击 puck 时触发。构建者可以配置操作、事件和建议。
  2. 资源对象或行： 每个资源对象在排程甘特图中渲染为一行。
    • 资源对象详情： 当光标悬停在某一行上时以卡片形式显示。卡片显示对象标题、应用构建者选择的属性以及指向对象视图的关联。
  3. 搜索栏： 排程甘特图 widget 包含一个 widget 内搜索栏。当用户输入搜索词时，结果将以黄色边框高亮显示。按下 Enter 键将使用结果创建一个新的搜索组。
  4. 违规规则筛选器： 违规规则筛选器用于聚焦排程中需要关注的方面。您可以开启/关闭要针对其排程进行评估的规则，并筛选出违反所选规则的对象。
  5. 用户偏好设置（已弃用）： 用户可以定义并保存其首选设置。可自定义的选项包括：
    • 时区： 默认情况下，Foundry 中的所有时间戳均为 UTC。此功能将处理用户选择的时区偏移。
    • 折叠 puck： 该 widget 会自动将重叠的 puck 合并为单个 puck 以节省屏幕空间。此开关允许用户开启和关闭此功能。
    • 显示当前时间线： 当前时间将以红色竖线表示。
    • 展开图例： 确定图例默认是展开还是折叠。
    • 展开未排程： 确定未排程抽屉默认是展开还是折叠。
    • 展开所有嵌套 puck： 确定嵌套 puck 默认是展开还是折叠。
    • 在外部选择时滚动到 puck： 如果启用，当用户在 widget 外部选择某个排程对象时，时间线将滚动到所选对象的位置。
    • 保留行宽： 用户可以通过拖动行边框来调整资源对象行的宽度。宽度偏好可以保存，以便在重新加载应用时宽度不会重置为默认值。
    • 保留行/分组顺序： 用户可以通过拖放手动重新排列资源对象行。顺序偏好可以保存，以便在重新加载应用时顺序不会重置为默认值。
  6. 未计划抽屉： 如果计划对象没有同时具有开始/结束时间和关联的资源对象，则被视为未计划。如果这些属性中的任何一个或全部为空，计划对象圆块将显示在未计划抽屉中。
  7. 变更日志： 变更日志会记录用户对其计划所做的所有编辑。
  8. 审查变更： 使用场景时会显示此选项。选择它会生成一个弹出窗口，其中包含在活动场景中所做的所有本体论编辑的摘要以及任何剩余的验证规则违规。确认后即可执行本体论编辑。

小部件设置

Scheduling Gantt Chart 小组件包含若干必选和可选的配置设置。本节提供概述，并且必选设置会被特别标注。

时间线数据

  • 开始时间戳 [必填]： 时间线的开始。
  • 结束时间戳 [必填]： 时间线的结束。

时间线配置

  • 自定义显示范围： 配置用户初次打开 Workshop 模块时时间线中显示的时间段。除非另有指定，用户将能够滚动 Scheduling Gantt Chart 的整个长度。
  • 自定义时间线网格精度： 为甘特图网格线选择一个时间单位，以覆盖默认的网格线。
  • 禁用时间线缩放和滚动： 禁用用户使用时间线滚动或缩放功能的能力。
  • 运营时间： 将图表中的范围划分为“运营/非运营”。这些区域将以不同的颜色着色。您可以配置每日计划、自定义时间范围或基于工作日的计划。可以选择启用 默认折叠 以在甘特图初次渲染时折叠非运营时间。
  • 时间线日期时间格式： 自定义时间线在不同缩放级别下的日期和时间格式。您可以为分钟、小时、天、周、月、季度和年份里程碑配置格式字符串。如果未提供格式，将使用默认格式。

行数据

  • 固定资源对象集 [必填]： 在界面中呈现为 Scheduling Gantt Chart 小组件的行。集合中的每个对象对应一行。

行配置

  • 标题图标： 选择一个与每行标题属性一起显示的图标。
  • 行标题： 选择一个属性以覆盖默认的行标题。您还可以切换当属性值为空时是否显示行标题。
  • 副标题： 选择资源对象集的一个或多个属性，这些属性将显示在对象标题下方。此外，为每个副标题选择一个图标，如下图所示。



  • 分组属性： 选择固定资源对象集的一个属性，将固定资源（行）划分为子组。定义的组可以通过图表中的开关打开或关闭。在下面的示例中，资源被划分为“Garden City”、“Garza”和“Hoople”组。





  • 默认排序： 允许对图表中的行顺序应用一个或多个默认排序。
  • 右键菜单： 请参阅 在行上触发操作和事件 的文档以获取更多信息。
    • 操作配置： 配置与资源对象类型相关的操作。这些操作可以是标准的本体论创建、修改或删除操作，也可以是自定义的 FoO 支撑的操作.
    • 搜索函数： 配置行级推荐函数。当用户在图表中没有安排任何内容的时间处右键单击时，将启动此函数。光标的位置对应于特定的时间和资源对象，随后可用作该函数的输入。
  • 行选择事件： 配置在图表中选中某行时触发的 Workshop 事件。例如，使带有更详细对象视图的抽屉出现。
  • 弹出式操作： 配置操作以替换悬停在行上时出现的默认弹出窗口。

输入数据（圆块）

每个日程层都在 输入数据（Puck） 部分中独立配置。一个日程层表示一组 Schedule 在甘特图上以 puck 形式显示的对象。每个层都有各自的子部分，用于配置数据、拖放行为、外观、交互和规则。

对于每个日程层，您可以选择一个 puck 样式 来更改视觉呈现。参见 日程层（puck）样式设置 以了解有关 puck 样式、着色和属性的更多信息。

同步至数据集

  • 日程对象集 [必需]： 直方图 Schedule 要在图表中渲染的对象。
  • 关联资源属性 [必需]： 来自该 Schedule 对象的、关联到 Resource object.
  • 对象的属性 来自该 Schedule 对象上用作开始时间的属性。
  • 结束时间属性 [必需]： 来自该 Schedule 对象上用作结束时间的属性。
  • 未分配 puck 的对象集筛选器： 仅应用于未分配 puck 的可选对象筛选器。

拖放

直方图 拖放 子部分配置 puck 在图表内的移动方式。参见 拖放文档 以获取详细的设置说明。

  • 分配行为： 确定 puck 在排程甘特图中的放置方式。预定义选项包括：

    • 分配： 可在图表中的任意位置拖放 puck。多个 puck 可以在同一时间分配给同一资源。



    • 分配（不允许重叠）： 与 分配类似，此选项确保相同对象类型的 puck 不会重叠。当一个 puck 被放置到另一个 puck 上方时，现有的 puck 以及之后时间段内已排程的所有内容都会自动移动，以避免重叠并保持顺序。



    • 分配（仅限资源）： 此选项为日程对象只能移动到不同资源的场景提供内置支持。
    • 分配（仅限时间）： 此选项为日程对象只能在时间上移动的场景提供内置支持。
    • 简单交换： 与 分配（不允许重叠） 类似，区别在于当一个 puck 被放置到另一个 puck 上方时，两个 puck 会互换位置。



    • 与下游交换： 与 简单交换类似，此选项允许选中的 puck 互换位置。不过在这种情况下，被交换的 puck 之后分配的所有后续 puck 也会跟随各自的前序 puck，从而有效地将整个序列向下游移动。



    • 吸附到前一个： Puck 将自动吸附到给定行上最近的现有 puck 的末端。



  • 吸附行为： 默认情况下，用户可以在排程甘特图组件上将对象分配到任意时间，精确到分钟。吸附行为允许构建者为对象的分配设置固定的时间间隔。一旦 puck 被放置到图表中的新位置，它将吸附到最接近的时间间隔的起始点。

    例如，配置医生预约日程的用户可能会确定所有分配（预约）都需要在整点（:00）或半点（:30）开始。

    • 直方图 吸附间隔大小 应为确定每个间隔时长的整数。在下面的示例中，间隔设置为 8 小时。



    • 直方图 开始时间戳 选项指吸附间隔开始的时间。默认情况下，吸附间隔从排程甘特图组件的开始时间戳起算。配置后，此变量将覆盖默认开始时间，并将 puck 吸附到配置的时间点。

  • 保存处理程序操作： 在 puck 被拖放或调整大小时调用的操作。

    • 保存处理程序必须修改该 Schedule 对象上的以下参数。每个参数都必须标记为可选。
      • 资源 ID（资源对象的外键）
      • 开始时间
      • 结束时间
    • 配置保存处理程序操作时，应提供组件自带的参数作为默认值。请参阅排程 拖放文档 的文档以获取更多信息。

外观

  • 颜色配置： 选择将用于此日程图层中所有色块的颜色。您可以从以下颜色选项中进行选择：
    • 静态： 选择此项后，所有色块将使用相同颜色，可通过下拉颜色选择器进行选择。静态着色的色块如下图所示。



    • 分段依据： 甘特图将循环使用一组默认颜色为图表上的色块着色。

    • 条件着色： 配置条件着色规则，根据属性值确定色块颜色。
    • 函数支撑： 配置一个 函数 ，该函数返回一个映射，将每个日程对象映射到十六进制颜色字符串或 自定义类型 with color and name 字段。提供 name 可启用图例支持。
  • 色块标题： 选择一个属性以覆盖默认的色块标题。
  • 色块属性： 选择直接显示在每个色块上的属性。属性在色块上的显示顺序与在组件配置中的顺序相同。
  • 弹出框属性： 选择在悬停于每个色块上时显示的属性。属性将按照配置中声明的顺序显示。
  • 色块排序顺序： 当色块在同一图层内重叠时，对色块应用排序。这不适用于背景色块。

交互

  • 自定义建议： 为您的日程对象选择建议函数。当用户拿起色块时，函数结果将渲染为图表上的高亮区域。这可用于指示用户可以或应该放置色块的位置。当 强制建议 启用时，用户只能将色块放置在高亮区域内（按住 Shift 键可覆盖此限制）。参见 建议函数 的文档以获取更多信息。
  • 拖动光标以创建操作： 允许在界面上执行拖动操作，为可排程对象类型创建新对象。用户按住 Shift 键并在组件内拖动光标即可启动该操作。参见 拖动创建文档 的文档以获取更多信息。



  • 右键菜单：
    • 操作配置： 配置与日程对象类型相关的操作。这些操作可以是标准的本体论创建、修改或删除操作，也可以是自定义的基于对象函数支撑的操作。
    • 搜索函数： 配置色块级别的推荐函数。当用户右键单击色块时会启动此函数。日程对象的开始/结束时间以及对象本身随后可用作函数的输入。
    • 事件： 配置可在组件内触发的标准 Workshop 事件组合。
  • 弹出式操作： 配置显示在色块弹出框选项卡中的操作，以替换默认的弹出框视图。
  • 启用跨组件拖放： 允许用户将其他组件中的对象拖入此日程图层。启用后，需配置一个放置操作，以确定如何处理被放置的对象。
  • 色块选择事件： 配置在图表中选中色块时触发的 Workshop 事件。

规则

应用于日程图层的可选验证规则。参见 验证规则 的文档以获取更多信息。

背景和事件色块样式不支持规则。

直方图 的 部分分为四个子部分，用于控制组件的视觉呈现。

时间轴

  • 时间轴位置： 将时间轴放置在图表的顶部或底部。
  • 显示光标时间标记： 开启后，时间轴上将渲染一条带标记的垂直线，对应光标的位置。您可以为标记配置时间显示格式。



  • 时区： 配置组件中显示时间所用的时区。可将其设置为静态值，或由 Workshop 变量支撑，以支持动态时区选择。
  • 展开图例： 确定图例默认处于展开还是折叠状态。

顶栏

  • 隐藏页眉： 隐藏页眉，包括搜索栏、验证规则筛选器和用户偏好设置。
  • 自定义页眉日期/时间格式： 为页眉日期范围显示配置自定义的日期和时间格式字符串。

  • 隐藏页脚： 隐藏页脚，包括未计划抽屉、变更日志和审查选项。
  • 隐藏未计划： 开启后，未计划切换按钮将被隐藏。
  • 展开未计划： 开启后，未计划冰球抽屉将默认展开。
  • 标准未分配冰球大小： 默认情况下，冰球的大小与时间长度成正比，如下图所示。

  • 按排程层拆分行： 每个排程层在给定的固定资源上包含一个子行。排程层的顺序和标签在 输入数据（Puck） 设置中确定，并在悬停在对象上时显示。此设置默认关闭，仅在应用程序配置了多个排程层时适用。

指标

直方图 指标 部分允许您提供自定义函数以向甘特图添加指标。您可以配置两种类型的指标：

  • 表头指标： 与图表时间轴对齐的指标。
  • 行指标： 与图表中每一行对齐的指标。

请参阅 内联指标 的文档以获取更多信息。

输出

排程甘特图小组件会生成输出变量，可供其他 Workshop 小组件使用以增强您的应用程序。这些输出变量包括：

  • 选定对象： 小组件中所选对象的对象集。
  • 搜索结果输出： 最近一次搜索/推荐返回的对象的对象集。仅当函数返回对象时，此输出才会填充。
  • 用户偏好（已弃用）： 一个序列化字符串，可与模块接口或状态保存一起使用，以持久化保存的用户偏好。

场景

组织 直接在您的应用程序代码中使用。场景作用域客户端的行为与常规 OSDK 客户端相同：您读取的每个对象、计算的每个聚合以及应用的每个操作都会自动针对场景的隔离沙箱而非主本体论进行评估。 用于排程甘特图小组件。

  • 启用场景： 开启后，允许指定一个可在所有其他感知场景的工作流中使用的场景变量。在小组件中所做的操作将首先写入场景。关闭后，在小组件中所做的操作将直接写入本体论。
  • 禁用场景： 一个布尔变量，用于控制是否禁用场景。设置为 true 时，操作将直接写入本体论。
