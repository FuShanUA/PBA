可用工具

Palantir 正在不断开发更多工具、提示词和资源，以改进 Palantir MCP。目前，Palantir MCP 提供以下工具：

Compass 工具

工具名称描述
list_resources_in_foundry_folder返回给定文件夹或项目 RID 中可用的资源，并支持分页。
get_project_imports返回已导入当前 Foundry 项目的数据集，支持分页。
list_foundry_namespaces列出用户有权访问的所有 Foundry 命名空间。可用于在创建项目之前发现可用的命名空间。
list_foundry_project_templates列出 Foundry 命名空间的可用项目模板。模板定义新项目的初始结构和设置。
create_foundry_project使用指定模板在指定命名空间中创建新的 Foundry 项目。
search_foundry_projects按名称或描述搜索 Foundry 项目。返回匹配的项目及其 RID、名称、描述和路径。

数据集工具

工具名称描述
get_foundry_dataset_schema返回给定数据集 RID 或数据集路径对应的 Palantir 数据集的定义,包括 schema 信息。
run_sql_query_on_foundry_dataset返回在可选分支上对 Palantir 数据集运行 SQL 查询的结果。
create_and_write_to_foundry_dataset使用 CSV 文件提供的数据在 Foundry 中创建数据集，适用于上传本地数据或创建模拟数据。
list_dataset_files根据给定的数据集 RID 或数据集路径，列出 Foundry 数据集中的文件。适用于探索没有 schema 的数据集。
build_datasets在 Python 转换仓库中构建数据集。
get_build_status返回 CI 检查或数据集构建的构建状态。支持按构建 RID、标签或分支进行检查。
search_dataset_builds根据数据集 RID、构建状态、分支和时间范围等条件搜索历史构建。
get_job_status根据作业 RID 检索特定作业的详细状态信息，包括错误消息和源代码信息。
get_dataset_stats返回 Foundry 数据集的大小和文件统计信息，包括总大小、文件数、隐藏文件数以及事务数量。

数据血缘工具

工具名称描述
get_resource_graph返回用于数据血缘可视化的资源图。

本体论工具

工具名称描述
get_foundry_ontology_rid获取给定 Foundry OSDK 应用程序或本地仓库的本体论 RID。
search_foundry_ontology针对给定的查询，在本体论中搜索相关的本体论实体。
search_foundry_functions针对给定的查询，在函数注册表中搜索相关的本体论实体。
view_foundry_object_type允许查看本体论中的现有对象类型，包括其属性、关联类型和操作类型。
create_or_update_foundry_object_type在提供的分支上创建或更新本体论中的对象类型。
delete_foundry_object_type在指定分支上删除本体论中的对象类型。
view_foundry_link_type允许查看本体论中现有的关联类型。
create_or_update_foundry_link_type在指定分支上创建或更新本体论中的关联类型。
delete_foundry_link_type在指定分支上删除本体论中的关联类型。
view_foundry_action_type允许查看本体论中现有的操作类型，包括其参数、逻辑规则和所依赖的对象类型。
create_or_update_foundry_action_type在提供的分支上创建或更新本体论中的操作类型。支持对象修改、删除和关联操作。
delete_foundry_action_type在提供的分支上从本体论中删除操作类型。

对象集工具

工具名称描述
query_ontology_objects根据指定条件查询本体论对象，并支持分页。
aggregate_ontology_objects对对象字段执行聚合函数，支持分组、筛选和多种聚合类型。

OSDK 工具

工具名称描述
get_ontology_sdk_context为用户的 OSDK 仓库获取关于本体论 SDK 的精选文档。
get_ontology_sdk_examples检索使用本体论 SDK 的代码示例，可按 SDK 版本和主题进行筛选。

平台 SDK 工具

工具名称描述
list_platform_sdk_apis列出给定 Foundry 产品可用的 Platform SDK API。
get_platform_sdk_api_reference获取 Platform SDK API 端点的 API 参考文档和代码示例。

代码仓库工具

工具名称描述
get_repository_context获取有关当前 Foundry 代码仓库的精选上下文，包括项目和本体论信息。
create_python_transforms_code_repository从头开始创建一个新的 Python 转换代码仓库。
clone_code_repository_locally将现有的 Foundry 代码仓库克隆到本地目录。
create_code_repository_pull_request在 Foundry 代码仓库中创建拉取请求。
list_code_repository_pull_requests列出 Foundry 代码仓库的拉取请求，支持按状态、分支、作者和标题进行筛选。
get_code_repository_pull_request获取拉取请求的全面信息，包括审查状态、CI 构建状态以及所有评论。
create_code_repository_pull_request_comment在 Foundry 代码仓库的拉取请求上创建评论。支持常规评论以及锚定到特定文件和行的行内评论。

全局分支工具

工具名称描述
create_global_branch创建一个具有指定显示名称和描述的新全局分支。
view_global_branch允许查看现有的全局分支，包括分支资源和本体论修改。
close_global_branch关闭现有的全局分支。
create_global_proposal创建新的全局提案，这是全局分支的最后一步。
view_global_proposal允许查看现有的全局提案，并根据其状态获取上下文信息。
close_global_proposal关闭现有的全局提案，而不将其合并。

Developer Console 工具

工具名称描述
connect_to_dev_console_app将非 Foundry 的 Git 仓库连接到 Developer Console 应用程序。
convert_to_osdk_react将现有的 OSDK 应用程序转换为使用 @osdk/react 搭配 OsdkProvider2，并可选择 @osdk/react-components。
generate_new_ontology_sdk_version将指定的 Foundry 提案所修改的本体论实体添加到本体论 SDK 中，并生成该 SDK 的新版本。
install_sdk_package检查 SDK 包生成的状态，并在就绪时提供安装说明。
view_osdk_definition获取 OSDK 定义的整体概览，包括对象类型、关联类型、操作类型和函数。

计算模块工具

工具名称描述
get_compute_modules_documentation获取有关计算模块和 compute_modules Python SDK 的精选文档。
get_compute_modules_info获取计算模块的状态和配置，包括运行时状态、扩缩容配置和运行时参数。
get_compute_modules_logs通过构建作业 RID 检索计算模块的最新日志，支持分页。
manage_compute_modules管理计算模块的生命周期：启动、停止或配置开发模式以进行自动升级。
execute_compute_modules_function同步执行计算模块函数。仅适用于运行在 FUNCTION 模式。

数据连接工具

工具名称描述
create_foundry_rest_api_data_source在 Foundry 中创建 REST API 数据源连接，用于与外部系统集成。
create_foundry_rest_api_data_source_webhook在 Foundry 中为 REST API 数据源创建 Webhook。
update_foundry_rest_api_data_source_webhook通过发布带有更新规范的新版本来更新 Foundry 中的现有 Webhook。
view_foundry_rest_api_data_source_webhook获取 Foundry 中现有 Webhook 的最新版本，包括其元数据、规范、输入、调用和输出。
get_or_create_network_egress_policy获取或创建 Foundry 中的网络出口策略。在创建 REST API 数据源和 Webhook 时非常有用。

文档搜索工具

工具名称描述
get_python_transforms_documentation获取有关 Python 转换和 transforms.api SDK 的精选文档。
get_typescript_v1_functions_documentation检索 TypeScript v1 函数仓库的文档和代码片段。
get_typescript_v2_functions_documentation检索 TypeScript v2 函数仓库的文档和代码片段。
get_custom_widget_documentation获取自定义小部件的综合文档，包括适用于 Workshop 和 Slate 的 React 小部件。
get_ml_documentation获取 Python 转换的综合 ML 文档，涵盖模型训练、MLOps 以及特定框架的模式。
get_spark_profile_documentation获取有关 Python 转换的 Spark profile 配置的文档，包括选择执行器内存、执行器数量和驱动程序设置的指导。
get_osdk_react_components_documentation获取……的文档 @osdk/react-components 库，包括 ObjectTable 以及其他预构建组件。
load_foundry_documentation_page通过路径加载完整的 Palantir Foundry 文档页面，并以 Markdown 格式返回完整的页面内容。
get_documentation_summaries检索特定 Foundry 主题区域的精选文档摘要包，涵盖关键概念、模式和参考资料。
search_foundry_documentation在 Palantir Foundry 平台文档索引中搜索与给定查询相关的上下文片段。 此工具仅在 AIP 中可用。
