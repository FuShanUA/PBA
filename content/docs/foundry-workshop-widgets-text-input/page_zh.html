文本输入

直方图 文本输入 小部件允许用户在表单字段中输入文本值。

配置选项

  • 标签
    • 为控件设置可选标签。此文本显示在控件顶部。
  • 字符串值
    • 小部件的输出变量，存储用户输入的文本。
  • 占位符
    • 定义在用户尚未输入文本时显示在输入字段中的占位符文本。
  • 格式
    • 将输入字段的格式设置为单行、多行文本区域或 Markdown 编辑器。
    • 单行
      • 回车事件： 设置按下回车键时触发的事件
    • 文本区域
      • 初始高度： 设置文本输入区域的初始高度
    • 《Markdown》：
      • 启用带有格式工具栏的富文本编辑体验。用户可以使用 Markdown 语法或工具栏控件来撰写和格式化文本。编辑器支持在富文本视图和原始 Markdown 视图之间切换。参见 Markdown 模式 了解详情。

Markdown 模式

当 format 字段设置为 《Markdown》：时，文本输入小部件将提供富文本编辑体验，其底层编辑器与 或中使用的编辑器相同。此模式适用于用户需要输入格式化文本的字段，例如描述、备注或评论。

功能

  • 格式工具栏： 使用工具栏控件应用粗体、斜体、代码等格式，无需了解 Markdown 语法。
  • 富文本和原始 Markdown 视图： 在富文本视图（带内联编辑的格式化预览）和原始 Markdown 视图（带 Markdown 语法的纯文本）之间切换。
  • 占位符文本： 配置编辑器为空时显示的占位符文本。
  • 自动调整大小： 使编辑器能够根据内容长度自动扩展。
  • 变量绑定： 输出字符串变量将内容存储为 Markdown 字符串，可供其他小部件（例如 《Markdown》： 小部件）使用以进行显示。

注意事项

  • Markdown 模式不支持回车事件触发（仅在单行模式下可用）。

  • 内容以 Markdown 格式的字符串存储在绑定的字符串变量中。使用此值的其他小部件应能够解析 Markdown 格式。

  • 图片语法限制： 包含图片语法的 Markdown 内容（例如， ![image text](image url)）在小部件加载时可能会导致“无法显示富文本内容”错误。出现此情况时，用户必须选择 查看源文本 来编辑内容。如果您的内容包含图片且不需要富文本格式工具栏，请考虑使用 文本区域 格式。
