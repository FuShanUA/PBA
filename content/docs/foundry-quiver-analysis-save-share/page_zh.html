保存和共享

保存分析

要保存 Quiver 分析，请选择 保存 （位于屏幕右上角）。

访问分析的历史版本

通过打开屏幕顶部的 分析历史 菜单，访问并还原到分析的历史版本。

如果您当前所在的分析版本中存在未保存的更改，系统将为您提供清除更改或将更改保存为新版本的选项。

分析权限

Quiver 分析的权限派生自其在 Foundry 文件系统中的 Project。当您将 Quiver 分析保存在某个 Project 中时，任何有权访问该 Project 的用户也将有权访问该分析。Project 与 Quiver 分析之间的访问级别保持一致。例如，具有查看权限的用户可以查看（但不能编辑）Quiver 分析，而具有编辑权限的用户可以查看并更新该分析。

共享分析

Quiver 分析的编辑者可以与其他用户共享分析。主要有两种方法：通过共享链接或向特定用户授予访问权限。这两种方法都可以通过 共享 按钮（位于顶部栏）打开一个侧面板。

选择 共享 按钮会打开一个包含共享选项的侧面板。

面板中，直接向特定用户或组授予角色，或开启

面板中，直接向特定用户或组授予角色，或开启 会创建一个特定链接，向通过该链接访问分析的用户授予一定级别的访问权限。

角色

直方图 角色 部分允许您以指定的访问级别向单个用户授予访问权限。

角色 会显示已获得该分析访问权限的所有用户，无论是通过共享链接、直接授予访问权限还是通过组成员身份获得的。
