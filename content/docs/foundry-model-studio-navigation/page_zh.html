导航

本页面概述了 Model Studio 的界面、导航和可用控件。

设置 Model Studio

要创建 Model Studio，请选择训练器，并指定名称和位置以输出 模型。

选择 下一步 将带您进入 配置向导。

主页

成功创建 Model Studio 并启动训练运行后，您将被引导至 Model Studio 主页。该页面包含有关您的 Model Studio 的信息，并提供访问输出模型和实验的链接。

该 启动训练运行 顶部的选项 最近的训练运行 表格在选中时会使用最新配置启动构建。位于 启动训练运行 选项旁边的下拉菜单包含用于编辑配置的控件，而 探索数据血缘 按钮位于顶部导航栏中，可用于查看您的模型工作室的数据血缘。打开数据血缘以设置 构建计划。

顶部导航栏下方是一个卡片，其中包含有关输出模型的详细信息，例如其名称、路径和状态。模型名称右侧的图标可能显示为黄色，表示源数据已更新，该模型被视为已过期。

训练运行

主页的主要部分显示了为 model studio 执行的训练运行列表。

表格各列如下：

  • 名称： 所执行配置的名称。可以在编辑 model studio 配置时设置该名称。
  • 开始时间： 训练作业开始的时间。
  • 状态： 训练作业的状态。
  • 配置版本： 一个递增的数字，指示训练作业执行时所使用的配置版本。每次对配置进行更改时，此数字都会递增。
  • 构建： 指向该作业的 构建 的链接。

在表格中选择一行，该行的更多详细信息便会显示在 侧边栏。

侧边栏

侧边栏会显示从 近期训练运行 表格中所选运行的信息。侧边栏顶部显示训练运行的执行日期。指向实验和所生成的模型版本的链接可在 操作 下拉菜单。

还可查看以下有关训练运行配置的信息：

  • 输入： 该 数据集输入 以及应用于该运行输入的列映射。
  • 参数： 为该作业配置的参数。
  • 资源： 该 计算资源 是为该作业申请的。
  • 变更日志： 在编辑配置后写入的可选配置变更日志。

配置向导

配置向导在创建或编辑模型工作室配置时使用，将引导您完成模型工作室配置的各个步骤。每个训练器都有其自身定义的配置选项。

  1. 输入： 定义 数据集输入 （训练器所需）。
  2. 参数： 定义训练作业所需的参数。每个训练器都会呈现各自的选项，并显示相关的平台内文档。
  3. 计算资源： 定义 vCPU 和内存 训练作业的资源。

完成向导中的所有步骤后，系统将要求您为配置版本提供名称和可选的变更日志。这些信息将提供描述性详细信息，说明该配置的功能以及与上一版本相比的变更内容。
