VS Code 工作区

VS Code 工作区和适用于 Visual Studio Code 的 Palantir 扩展均与 Microsoft 无任何关联，也未获得 Microsoft 的认可。

VS Code 工作区将 Microsoft 的 VS Code ↗ IDE 的强大功能直接引入 Palantir 平台。VS Code 工作区是部署在 Palantir 基础设施上的开发环境，可利用 代码工作区 来提供用于编写生产就绪代码的集成开发环境（IDE）。在所有启用了代码工作区的组织中，VS Code 工作区默认可用。无论您是在编写函数、构建 Python 转换、开发 OSDK React 应用程序，还是在处理计算模块（在此查看受支持工作流的完整列表），VS Code 工作区都能提供熟悉且强大的环境，并具备自动环境设置以及与 Foundry 资源的无缝集成。

开始使用 VS Code 工作区

访问工作区

  1. 在 VS Code 中打开现有 受支持的仓库 或创建新仓库。
  2. 在代码仓库中，您可以选择 在 VS Code 中打开 ，该选项位于右上角（仅对受支持的仓库显示）。
  3. 在创建新仓库时，选择 VS Code 将自动带您进入 VS Code 工作区。
  4. 您的环境已准备就绪，可以开始编码了。

将 VS Code 设为默认编辑器

您可以将 VS Code 设为所有受支持仓库类型的默认代码编辑器，方法是导航到任意仓库中的 设置 标签页，并选择 默认在 VS Code 工作区中打开仓库。

请注意，无论默认设置如何，某些仓库都会在 VS Code 中打开，因为这些仓库类型已针对 VS Code 工作区进行了优化。

受支持的工作流

VS Code 工作区支持以下各节中所述的工作流。

Python 转换

Palantir 扩展会在启动时自动设置您的 Python 环境，并提供以下功能：

  • 预览集成 支持无样本和代码定义的筛选选项
  • 调试支持 支持变量检查
  • 构建触发 可在编辑器内进行
  • 资源路径与资源标识符一同显示，便于导航
  • 自动代码环境设置
  • 适用于常见模式的代码片段

了解更多关于 Python 转换的信息。

函数

VS Code 工作区支持使用适用于 Visual Studio Code 的 Palantir 扩展来开发函数。对于受支持的函数仓库，您可以：

  • 导入 Foundry 资源并生成 SDK。
  • 在提交更改之前预览函数并检查结果。
  • 创建并切换 Code 和 Global 分支。
  • 提交并提议更改、为函数版本打标签以及升级仓库。
  • 在集成终端中运行单元测试和其他开发命令。

了解如何使用面向函数的 VS Code。

OSDK React 应用程序

VS Code 与 Developer Console集成，让您能够快速构建 React 应用程序。您可以在 Developer Console 的 代码仓库 部分创建 VS Code 工作区。

主要功能包括：

  • 通过 OSDK 实现与本体论的全面集成，以便与您独有的本体论资源进行交互
  • Git 仓库配置，并预先配置了 OAuth
  • CI 设置，可在每次发布时部署您的网站
  • 自动设置 node/npm 环境
  • 支持实时重新加载的开发服务器，可提供即时反馈

了解有关 OSDK React 应用程序的更多信息。

其他受支持的工作流

  • 计算模块： 构建具有运行和调试功能的 Python 计算模块。
  • Python 库： 开发和调试可复用的 Python 库。

参考：VS Code 工作区与代码仓库的对比

VS Code 和代码仓库的主要用途各不相同：

  • 代码仓库： 一款由 Palantir 构建的 IDE，专注于满足所有代码管理需求，包括编辑、版本控制、变更管理和持续集成。这是用于拉取请求审查和仓库管理的指定平台工具。

  • VS Code： 部署在 Palantir 基础设施上并可从 Palantir 平台访问的 VS Code 环境。提供熟悉的 VS Code 编辑体验，支持自动环境设置，并可通过以下扩展与 Foundry 资源集成： Palantir extension for Visual Studio Code。

  • Palantir extension for Visual Studio Code（本地）： 一款安装在本地 VS Code 应用程序中、用于直接与 Foundry 集成的扩展。在本地计算机上工作时，可为 Python 转换提供预览、调试和构建功能。

在工作区启动期间浏览代码

默认情况下，当您打开一个 已停止的 VS Code 工作区时， 代码查看器 会打开，同时其工作区会话在后台启动。当 VS Code 标签页图标显示工作区状态时，您可以浏览已提交的代码。代码查看器将保持打开状态，直到您选择 VS Code 标签页。
