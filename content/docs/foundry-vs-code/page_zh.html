VS Code 工作区

VS Code 工作区将 Microsoft 的 VS Code ↗ IDE 的强大功能直接带入 Palantir 平台。VS Code 工作区是部署在 Palantir 基础设施上的开发环境，利用 代码工作区 为编写可用于生产环境的代码提供一个集成开发环境（IDE）。在启用了 Code Workspaces 的所有组织中，VS Code 工作区默认可用。无论您是在编写函数、构建 Python 转换、开发 OSDK React 应用程序，还是处理计算模块（在此处查看支持的工作流完整列表），VS Code 工作区都能提供一个熟悉而强大的环境，并具有自动环境设置以及与 Foundry 资源的无缝集成。

开始使用 VS Code 工作区

访问工作区

  1. 打开现有工作区或创建新的 在 VS Code 中打开一个 受支持的代码仓库
  2. 在 Code Repositories 中，您可以选择 在 VS Code 中打开 位于右上角(显示于受支持的仓库)。
  3. 在创建新仓库时,选择 VS Code 将自动带你进入 VS Code 工作区。
  4. 你的环境已就绪,可以开始编码了。

将 VS Code 设为默认编辑器

您可以通过导航到任意仓库中的 设置 选项卡并选择 默认在 VS Code 工作区中打开仓库.

某些仓库无论默认设置如何都会在 VS Code 中打开，因为这些仓库类型已针对 VS Code 工作区进行了优化。

支持的工作流

VS Code 工作区支持以下各节中介绍的工作流。

Python 转换

Palantir 扩展会在启动时自动设置您的 Python 环境，并提供以下功能：

  • 预览集成 支持无样本和代码定义的筛选选项
  • 调试支持 支持变量检查
  • 构建触发 可在编辑器内部执行
  • 资源路径与资源标识符一起显示，便于导航
  • 自动代码环境设置
  • 常见模式的代码片段

了解有关 Python 转换的更多信息。

函数

VS Code 工作区支持使用适用于 Visual Studio Code 的 Palantir 扩展开发函数。对于支持的函数仓库，您可以：

  • 导入 Foundry 资源并生成 SDK。
  • 在提交更改之前预览函数并检查结果。
  • 创建并在多个 选项卡，选择 and 全局 branches.
  • 提交并提出更改、标记函数版本以及升级仓库。
  • 在集成终端中运行单元测试和其他开发命令。

了解如何在 VS Code 中导航函数。

OSDK React 应用

VS Code 已与 自定义小部件集成，让您能够快速构建 React 应用程序。您可以在 代码仓库 开发者控制台的相应部分创建 VS Code 工作区。

主要功能包括：

  • 通过 OSDK 实现与本体论的完全集成，以便与您独特的本体论资源进行交互
  • Git 仓库配置，OAuth 已预先配置
  • CI 设置，可在每次发布时部署您的网站
  • 自动 node/npm 环境设置
  • 带有实时重新加载功能的开发服务器，可提供即时反馈

自定义小组件

其他支持的工作流

  • 计算模块: 构建具有运行和调试功能的 Python 计算模块。
  • Python 库: 开发和调试可重用的 Python 库。

参考：VS Code 工作区与 Code Repositories 的对比

VS Code 和 Code Repositories 服务于不同的主要用途：

  • 代码仓库： 一个由 Palantir 构建的 IDE，专注于满足所有代码管理需求，包括编辑、版本控制、变更管理和持续集成。这是用于拉取请求审查和仓库管理的指定平台工具。

  • VS Code： 部署在 Palantir 基础设施上并可从 Palantir 平台访问的 VS Code 环境。通过 适用于 Visual Studio Code 的 Palantir 扩展.

  • 适用于 Visual Studio Code 的 Palantir 扩展（本地）： 安装在本地 VS Code 应用程序中以直接与 Foundry 集成的扩展。在本地计算机上工作时，为 Python 转换提供预览、调试和构建功能。

在工作区启动时浏览代码

默认情况下，当您打开 已停止的 VS Code 工作区, 代码查看器 会在其工作区会话于后台启动的同时打开。您可以在 VS Code 标签页图标显示工作区状态期间浏览已提交的代码。代码查看器将保持打开，直到您选择 VS Code 标签页。
