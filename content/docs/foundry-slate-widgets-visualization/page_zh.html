映射

Slate 的地图小部件由 Leaflet ↗.

地图由多个图层组成：基础图层（也称为瓦片图层；即背景地图影像），以及若干叠加图层（也称为要素图层；即您感兴趣的数据）。地图小部件的要素图层同时支持栅格瓦片和矢量瓦片。

有关构建自定义主题的示例，请参阅 Mapbox 文档 ↗ 其中对 Web 地图技术进行了有益的介绍。Slate 使用 Mapbox 作为其基础地图影像的来源。

术语

  • 地图瓦片： 地图小部件的基础图层，这些瓦片只是图像，不包含数据。您可以将地图瓦片视为地图的“背景”。地图瓦片在 杂项 选项卡中配置，并应用于整个地图小部件，而不仅仅是单个图层。同一时间只能显示一种地图瓦片。
  • 要素： 绘制在地图上的点或形状，与某种数据相关联。
  • 向量（Vector）： 表示图像的另一种方法。 栅格 图像逐像素地描述图像；本质上是一个由彩色像素组成的网格。 矢量 图像则相反，它描述点之间的线条。这意味着矢量图像可以在不同尺寸下清晰地显示。
  • 矢量瓦片： 以矢量形式包含形状数据。
  • 瓦片服务器： 以瓦片形式动态提供形状数据。
  • 地图瓦片源： 为地图提供基础瓦片。从技术上讲，它也是一种瓦片服务器。

图层类型

Slate 具有以下类型的叠加图层：

  • 位置
  • 热力图和热力网格
  • 形状
  • 矢量
  • 分级统计图
  • Raven

位置

位置图层仅包含 点 （Leaflet 标记 ↗），由经纬度对标识。您可以将地图小部件配置为将这些点显示为圆形或图标。

热力图和热力网格

热力图和热力网格图层也处理点数据，但它们不是简单地在地图上显示这些点，而是显示一个包含这些点的 分布 计算结果的叠加层。热力图以彩色渐变的形式显示点的密度，而热力网格将点分组到桶中，并将这些桶显示为离散的颜色单元格。

形状

除了单个点之外，形状和矢量图层还可以包含以下形式的 多边形 数据——即存储为一系列点及点之间连线的信息。形状图层以 GeoJSON ↗ 格式提供这些多边形。GeoJSON 文件可以直接从您的 Slate 服务器提供。

GeoJSON 要素以 JSON 形式存储，并被转换为 SVG（图像）文件。这些图像会在地图小部件首次加载时一次性全部加载。

矢量

矢量图层以矢量瓦片的形式提供形状数据。您必须运行一个外部瓦片服务器来提供矢量瓦片。 矢量瓦片是动态加载的（仅在其进入地图视野时加载）。矢量瓦片还直接在画布上绘制要素，而不是将其渲染为图像，因此矢量图层可以包含比形状图层多得多的要素

分级统计图

等值区域图层也处理多边形数据，但它们会为每个要素添加一个附加值，并将这些值映射到色阶上。这样，每个要素在地图上就会以与该值对应的颜色显示。这可用作对某些特定统计数据的可视化。

例如，你可能有一张按人口密度着色的州地图，或按社会脆弱性指数着色的邮政编码地图。

Raven

如果你需要在 Slate 应用中使用 Raven 地图，请联系你的 Palantir 代表。

基础瓦片

地图组件为基础瓦片图层提供了多种选项。这些选项包括深色主题、浅色主题、卫星主题、街道地图主题以及我们的默认主题。此外还有一个 所有 选项，可让你使用图层选择器直接在地图上切换主题。

在监听器设置向导的 杂项 属性编辑器的选项卡中，从 瓦片图层 下拉菜单中进行选择：

地图上的数据规模

形状图层（GeoJSON）支持的数据规模最低。当要素数量达到约 1,000 个时，地图性能会明显下降。对于更大的数据，你应该改用矢量图层。你也可以尝试简化 GeoJSON 中的几何图形以提高性能。

位置图层在大约 5,000-10,000 个点时会变慢。

禁用交互

如果你想在应用中显示静态地图，可以禁用平移和缩放。如果你只想显示要素数据（而不显示基础地图瓦片），也可以移除基础图层。

教程：添加表格小部件

假设您想添加一个 Table 小部件来显示航班数据。选择 微件 左上角的按钮，然后选择 Visualization > Table 以向您的 Slate 应用程序添加一个 Table 小部件。

将 Table 小部件重命名为更易于识别的名称。在属性编辑器中选择该小部件的名称并将其更改为 w_flightTable.

配置表格以使用 q_allFlights 查询，方法是输入 "{{q_allFlights}}" 菜单中选择 同步至数据集 字段。您应该会看到表格中填充了数据。

该值 "{{q_allFlights}}" 不是纯 JSON 语法。其中的括号是 Handlebars 语法，每个表达式都表示为 {{expression}}。参见 Handlebars 以了解其在 Slate 中的用法。）

现在您的表格已包含正确的数据，但格式还可以改进。选择 添加所有列 以查看底层数据中每一列的格式设置选项。

由于 flight_id 列不是人类可读的列，暂时隐藏该列。不过，我们会将其保留在表格中，以便稍后配置选择一行或多行的功能时参考。

对于其余的列，选择一个显示名称作为 标题 并添加格式字符串，使用 MomentJS ↗.

中的格式字符串来清理时间戳。

现在我们得到了一个能够清晰显示所有数据的表格：

切换到 杂项 属性编辑器中的选项卡，并勾选 允许选择 和 启用排序。用户现在可以直接选择列以查看按不同方式排序的表格，也可以点击特定行来选中它。

最后，决定用什么作为表格中某一行的唯一标识符。在本例中，使用航班名称。在标有 Key column ID中，选择 flight_id.

如果 服务器端分页/排序 选项未被勾选时，表格只会对已加载的数据进行排序和分页，在本例中目前只有表格的前 10 行。在 Slate 中，您可以可靠地将 5-10k 行数据加载到浏览器内存中，但这会受到用户浏览器标签页可用资源的限制。

在大多数情况下，最佳实践是配置服务器端分页和排序。由于 last-mile-flights 表中大约有 75k 个航班，而底层 flights 表中有数百万个航班，因此无法在客户端同时返回所有结果。
