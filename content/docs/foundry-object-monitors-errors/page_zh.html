本页面介绍了在使用 Object Monitors 应用或 监视器 视图（位于 Object Explorer 中）时可能会遇到的常见错误类别。

评估错误

由于底层数据问题，监控器可能无法评估。监控器会自动重试，但某些错误可能需要手动干预。例如，如果被监控的对象类型被删除，使用包含该类型对象的输入的监控器将无法评估。

监控器不同步

对象监控器使用对 已保存的探索 的引用来定义输入。该引用并非动态的，而是按照保存监控器时探索的现有状态进行存储。如果探索发生变化，除非更新监控器，否则监控器将继续使用探索的旧状态进行评估。在这种情况下，监控器上会显示警告横幅：

通知效果错误

监控评估成功后，通知可能无法发送。如果发生这种情况，历史事件将显示一个标签，指示该事件的通知未发送给订阅者，并附带错误标识符和错误消息等附加详情。

操作效果错误

监控评估成功后，操作效果可能无法执行。这种失败可能由多种原因导致，包括操作逻辑发生更改、使其与监控中保存的输入配置不兼容，或者因为操作的 提交标准 未得到满足。如果发生这种失败，历史事件时间线将显示一个标签，指示该事件的一个或多个操作未能执行，以及相关的错误详情。

权限

监控评估使用各个订阅者的权限。这是为了确保监控评估以及任何后续的操作或通知效果始终反映用户在监控被评估时可以访问的数据。如果用户缺少查看输入对象类型、已保存的探索和/或对象监控的权限，则可能会看到与权限相关的错误消息，而不是成功的评估。我们强烈建议将监控及其输入存储在共享 项目.
