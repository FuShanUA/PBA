在控制面板中配置 Vertex 设置

多种组织范围内的 Vertex 设置可以使用 控制面板进行配置。要修改 Vertex 设置，您需要 Vertex Admin 角色。

图默认设置

  • 默认时间选择： 默认时间选择涵盖的天数。
  • 默认图模式： 控制新图是以图表模式 [beta] 还是图模式创建。
  • 已启用的图标类别： 控制在图表模式 [beta] 中可以使用哪些图标类别。
Beta

图表模式目前处于 beta 开发阶段，在您的注册中可能无法使用。功能在持续开发期间可能会发生变化。要启用图表模式，请联系您的平台管理员 修改应用程序访问权限 （在控制面板中）。

数据加载

  • 时间序列轮询间隔： 在实时模式下，Vertex 检查时间序列值更新的频率（以秒为单位）。
  • 时间序列数据缺失警告： 当时间序列没有近期观测值时，Vertex 将显示警告。此设置控制所选时间与最接近的时间序列值之间允许的最长时间间隔（以小时为单位），超过该间隔后才会显示警告。
  • 对象搜索限制： 控制用户可以从搜索对话框添加到图中的对象数量上限。
  • 周边搜索限制： 控制通过 Search Around 向图中添加对象的行为。
    • 最大对象数量： Vertex 在单次 Search Around 中加载的最大对象数量。
    • 未分组对象的最大数量： Vertex 作为单个节点（而非分组）添加到图中的 Search Around 结果对象的最大数量。如果要添加到图中的对象数量超过此限制，这些对象将被自动分组。
    • 模板 Search Around 最大深度： 创建模板时允许的嵌套 Search Around 的最大数量。

模型配置

  • 旧版模型配置： 更新后的模型配置体验可通过 Modeling objectives 应用使用。虽然仍支持直接通过 Vertex 配置的模型，但现在不建议在 Vertex 配置面板中配置新模型。
  • 模型配置映射： 选择模型配置者可使用哪些类型的数据映射。
