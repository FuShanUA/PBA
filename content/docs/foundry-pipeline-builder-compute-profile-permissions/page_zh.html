配置计算配置文件权限

对于标准的批处理 Spark 支撑管道，计算配置文件权限在项目级别进行配置。当配置文件被导入到某个项目时，该项目中的每个管道都可以使用它。可以在 Pipeline Builder 图中直接导入配置文件，也可以在 控制面板 应用中添加或移除，或者直接在 Compass 中从项目的引用中移除。

计算配置文件分为两个权限层级：

  • 自动导入的配置文件 （最大不超过 medium）：自动导入到项目中。
  • 非自动导入的配置文件 （large 和 extra large）：必须由具有 Compass 项目编辑者或所有者角色以及 Resource Management 管理员角色的用户手动导入。此要求同样适用于 large 和 extra large 自定义计算配置文件。欲了解更多信息，请参阅 配置访问权限.

计算配置文件权限适用于所有项目，包括在此功能推出之前创建的项目。项目中已在使用的任何 large 或 extra large 配置文件将被保留，因此现有管道将继续运行，无需采取任何操作。要使用尚未导入的 large 或 extra large 配置文件，必须先将该配置文件导入到项目中。

Streaming 和 Faster 管道不受计算配置文件权限的影响。它们的计算配置文件选择流程保持不变，无需额外的权限配置。标准批处理 Spark 计算配置文件与 Faster 或 Streaming 配置文件的定义不同；欲了解更多信息，请参阅 构建设置.

直接从 Pipeline Builder 导入计算配置文件

如果您拥有 Compass 项目所有者或编辑者角色以及 Resource Management 管理员角色，则可以直接从 Pipeline Builder 导入计算配置文件。这些权限在 Compass 项目级别和 Resource Management 管理级别定义；在管道级别授予用户所有者权限并不能使其导入额外的计算配置文件。

如果您不具备导入所选配置文件所需的角色设置，您将看到 Large 和 Extra Large 选项处于禁用状态。

如果项目的资源中缺少所选的计算配置文件，您将看到错误 Build settings use one or more compute profiles that are not imported 在尝试部署管道时出现，如下面的截图所示。

如果您选择 导入计算配置文件 错误下方的按钮，系统将提示您导入缺失的配置文件。

一旦您选择 导入 1 个缺失的 Spark 配置文件，您将看到一条横幅，提示配置文件已成功导入。如果您没有 Compass 项目所有者或编辑者角色，或者没有 Resource Management 管理员角色，此导入按钮将被禁用。

此流程完成后，您将能够使用新导入的计算配置文件执行构建。

移除计算配置文件

您也可以在 Compass 项目中移除计算配置文件。导航到 外部引用 选项卡，选择您要移除的引用，然后选择 移除引用 右上角的按钮。

Marketplace 产品中的计算配置文件

安装包含管道的 Marketplace 产品时，系统会在安装过程中检查计算配置文件权限，并作为该流程的一部分导入所需的配置文件。因此，已安装的管道始终可以部署。如果您无权导入产品附带的配置文件，可以在安装过程中选择较小的配置文件。

在安装过程中导入大型或超大型配置文件与在项目中导入具有相同的权限要求。您必须拥有 Compass 项目编辑者或所有者角色，以及 Resource Management 管理员角色。
