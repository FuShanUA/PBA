Pipeline Builder 中的快速管道

Pipeline Builder 现在支持快速管道，它可以缩短批处理和增量管道的执行时间。此管道使用的后端由 DataFusion ↗提供支持，DataFusion 是一个用 Rust ↗编写的开源查询引擎。与基于 Spark 的传统管道相比，快速管道可以大幅加速计算过程。

快速管道此前被称为 轻量级管道，因为“轻量级”一词指的是执行这些管道所需的时间和计算资源的减少，而非其所处理数据的大小。更名反映出，快速管道既能缩短执行时间，又能降低计算资源使用量，即使对于大规模数据集也是如此。

快速管道经过专门设计，可优化构建时间并高效执行低延迟操作。特别是，运行时间在 15 分钟以内的管道将从快速管道配置中获益最多。

我们鼓励您尝试不同的管道配置来提升性能。您可以通过在分支上进行测试，或者复制现有管道以比较新配置与原始配置的性能，来探索这些功能。

创建新的快速管道

如果您不熟悉在 Pipeline Builder 中创建管道，请查阅以下文档： 如何在 Pipeline Builder 中创建批处理管道 在继续之前。

  1. 打开 Pipeline Builder 并选择 创建新管道。
  2. 输入管道名称和所需位置后，请选择 更快管道 （位于 管道类型下）。
  3. 选择 创建管道。

在更快管道与标准批处理管道之间转换

您可以按照以下步骤在更快管道与标准批处理管道之间相互转换。通过重复该流程并选择所需选项，可随时撤销此转换。

  1. 要转换批处理管道，请转到 设置 并选择 转换为更快管道。

要将管道转换回批处理管道，请转到 设置 并选择 转换为批处理管道。

  1. 如果管道与新管道类型兼容，您将看到一个对话框，可在其中确认转换。

  1. 如果管道与新管道类型不兼容，则在您尝试转换管道时会出现警告。该警告将列出与更快管道不兼容的任何表达式或转换。

您可以开启 显示管道转换检查 ，随时查看与更快管道选项不兼容的任何内容。

在您开启 显示管道转换检查后, 更快的转换兼容性检查 部分将出现在屏幕底部的 管道警告 面板中。该部分列出了在快速管道中不受支持的转换和表达式。要快速定位包含不受支持的转换的节点,请点击 转到节点 图标(位于相应行右侧)。

已知限制

快速管道目前不支持与标准批量管道相同的一组转换和表达式。最值得注意的是,不受支持的转换和表达式包括 LLM 功能、地理空间功能以及媒体集操作。

由于快速管道与批量管道之间存在差异,您应始终使用 预览 或通过检查构建输出来验证结果。

快速管道中的大多数受支持表达式,其行为与批量管道中的等效表达式相同。已知限制包括:

  • 浮点结果的最后几位数字可能有所不同。
  • Decimal 溢出将抛出错误,而不是输出 NULL 值。
  • 结构体无法与 <、 >、 ==等来进行比较。
  • pow 溢出时返回 NULL 而不是 inf。
  • 对于复杂类型（如结构体、数组、映射）及其向字符串的转换，Cast 功能可能存在差异。例如，这些类型转换为字符串时，null 值的呈现方式可能有所不同。
  • 对以下格式的支持有限： TimestampToString、 DateToString、 StringToTimestamp和 StringToDate。
  • 对于结构体、数组和映射等复杂类型，不支持最小值和最大值。
  • 空输出将生成 0 个文件，而非一个空文件。
  • 构建时不支持除行数以外的统计信息。
  • 不支持创建时间序列参考值。
  • 不支持已训练模型节点。

管道类型支持对比

以下大小建议仅作为一般规则，并不适用于所有查询。对于合适类型的转换，速度更快的轻量级引擎甚至可以在单个节点上处理 TB 级别的输入。

如果您的管道没有遇到上一节中提到的任何限制，我们建议先使用更快的选项。如果您的数据规模有此需求，或者您想使用尚不支持的转换和表达式，则可以切换到标准 Spark 选项。您可以 在不同类型的管道之间进行转换。
