Tableau OAuth 设置

Tableau 支持通过 OAuth 向 Foundry 进行身份验证。这意味着用户无需手动输入令牌，而是可以通过网页浏览器提示登录 Foundry。请参阅 Tableau 的 OAuth 连接 ↗ 文章，以了解 Tableau 中 OAuth 的概览。

启用此 OAuth 集成需要 Foundry 管理员权限。此外，如果您为 Tableau Server 启用 OAuth 集成，则需要 Tableau 管理员权限，并且必须重启 Tableau Server。

第 1 部分：为 Tableau Desktop 启用 OAuth 客户端

  1. 请按照 相关说明 在 第三方应用 控制面板中的配置页面。
  2. 选择 Tableau Desktop 在应用程序列表中；从 操作 菜单下选择 启用设置.
  3. 使用切换开关启用该应用程序。

当 Tableau 用户使用 OAuth 向 Foundry 进行身份验证时，将强制执行单个用户的权限。如果您使用了 项目访问 or 标记限制 面板为第三方应用程序配置限制，这些限制将在用户的个人权限之上应用。

此时，Tableau Desktop 用户可以按照 相关说明 使用 OAuth 向 Foundry 进行身份验证。

第 2 部分：为 Tableau Server 配置 OAuth 客户端

按照以下说明为发布到 Tableau Server 的报表启用 OAuth 身份验证。

步骤 1：为 Tableau Server 注册第三方应用程序

在同一 第三方应用 页面上，选择 新建应用程序 以创建一个新的第三方应用程序：

  1. 在 详情 步骤，将应用程序命名为 <ORGANIZATION> Tableau Server，并将组织名称替换为您自己的组织名称。
  2. 在 客户端类型 步骤，选择 机密客户端.
  3. 在 授权许可类型 步骤，选择 授权码模式 并设置 重定向 URL to https://<YOUR_SERVER>/auth/add_oauth_token，其中 <YOUR_SERVER> 是您的 Tableau Server 主机名。

创建该应用程序，并安全地保存客户端 ID 和密钥。

步骤 2：配置 Tableau Server

在服务器上运行以下命令，将客户端 ID、密钥和重定向 URL 替换为上一步中的相应值：

tsm configuration set -k oauth.config.clients -v "[{\"oauth.config.id\":\"FoundryJdbc\", \"oauth.config.client_id\":\"<YOUR_CLIENT_ID>\", \"oauth.config.client_secret\":\"<YOUR_CLIENT_SECRET>\", \"oauth.config.redirect_uri\":\"https://<YOUR_TABLEAU_SERVER>/auth/add_oauth_token\"}]" --force-keys

步骤 3：重启 Tableau Server

通过运行以下命令重启 Tableau Server：

tsm pending-changes apply

用法

Tableau Desktop

在 Tableau Desktop 中，用户现在可以按照 相关说明 通过 Foundry OAuth 身份验证选项进行身份验证。

Tableau Server

发布到 Tableau Server 时，可以将报表配置为在打开报表时提示查看者通过 OAuth 进行身份验证。这样，实时查询将使用查看者的权限运行。

要进行此配置，请在 Tableau Desktop 中使用 Foundry OAuth 身份验证选项开发报表。准备好发布后，选择 提示 选项进行身份验证。当用户在 Tableau Server 上查看报表时，实时连接将使用查看者的凭据刷新。
