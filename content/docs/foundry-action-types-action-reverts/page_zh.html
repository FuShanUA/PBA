撤销或还原操作

操作撤销功能在 本体论管理器 中允许在操作应用后立即撤销（即还原）该操作。您可以通过选择 撤销 来撤销操作，该选项显示在任何成功应用操作后的成功消息中。

新操作默认可撤销。

操作撤销功能仅适用于 Object Storage v2；也就是说，只有在 OSv2 中修改或创建对象类型的操作才能被撤销。如果您的对象类型当前未存储在 Object Storage v2 中，您可以按照此 指南.

配置可撤销的操作

目前，操作只能由应用该操作的用户撤销。

在监听器设置向导的 表单 选项卡中，切换启用 允许在操作提交后撤销 按钮。一旦此开关正确配置并保存到本体论中，您的操作即可被撤销。

直方图 允许在操作提交后撤销 开关进行控制，该开关位于本体论管理器的 表单 选项卡对于 2024 年 5 月之后创建且仅修改 OSv2 对象类型的操作将默认启用。 如果某个操作在 2024 年 5 月之前就已存在且修改 OSv2 中的对象类型，则操作撤销功能不会默认开启，但可以手动启用。

如果操作仅修改 OSv1 对象类型，则无法撤销该操作。

在某些情况下，操作撤销可能会失败：

  • 如果对象在操作之后发生了任何后续编辑，即使该编辑针对的是不同的属性，也无法撤销该对象上的操作。换言之，只有当操作是对对象的最新编辑时，才能撤销该对象上的操作。
  • 如果在操作提交后关闭了操作撤销功能，则无法撤销该操作，即使之后重新开启了操作撤销功能。

操作撤销只会撤销对对象实例的编辑，但不会撤销副作用（例如通知或 Webhook），也不会像已应用的操作那样调用它们。

在没有撤销操作提示框的情况下撤销删除操作

如果执行了删除操作且您希望撤销该删除，但撤销操作提示框已不再可用，则仅剩的补救方案是：

  • 迁移到新的对象类型，并使用函数复制所需的编辑；或者
  • 删除该对象类型上的所有编辑。
