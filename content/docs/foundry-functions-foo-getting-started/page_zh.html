对象函数入门

函数的核心特性之一是它们可以轻松访问已集成到 Foundry 本体论中的数据。本体论为您的组织提供数据的语义建模，使您能够轻松访问结构化数据，并在不同用例之间复用逻辑。

先决条件

本教程假定您已经创建并设置了一个 TypeScript 仓库。如果您尚未完成此操作，请先完成 入门 教程。

导入本体论类型

您想在函数中使用的任何对象类型、接口类型或关联类型，都必须导入到您的仓库所在的项目中。选择 资源导入 侧边栏后，即可查看已导入到项目中的对象类型。

您的组织可能没有 Airport 和 Flight 对象。跟随本教程操作时，请使用您有权访问的任何对象类型。

要导入更多对象类型，您需要选择 “添加” 按钮，该按钮位于 资源导入 侧边栏中。如果尚未选择本体论，系统将提示您选择一个本体论。如果您至少导入了一种本体论类型，则会自动确定所选的本体论。

选择本体论后，将出现一个搜索模态框。您的本体论将取决于组织中可用的对象类型。首先，选择几个对象类型以及连接它们的关联类型。此示例将导入 Airport 和 Flight 对象，以及它们之间的关联类型。

您还可以通过选择 接口 （位于 添加 按钮下）来导入本体论接口。

选择 “确认选择” 以将本体论类型导入项目中。Code Assist 将自动重启，以重新生成代码绑定，从而反映您新导入的对象类型和关联类型。

在 TypeScript v1 仓库中，您现在可以从 @foundry/ontology-api 包中导入本体论类型。如果您使用的是私有本体论，包名将改为 @foundry/ontology-api/<ontology-api-name>。

在 TypeScript v2 仓库中，系统会提示您 生成并安装本体论 SDK （在导入本体论类型后）。在编写函数之前，请先完成此步骤；只有在安装本体论 SDK 后，导入的类型才能在您的代码中使用，并且您需要从 @ontology/sdk 包中导入它们。

私有本体论

如果您使用的是私有本体论，请将 @foundry/ontology-api 替换为 @foundry/ontology-api/your-private-ontology-api-name-here ，该替换适用于以下所有 TypeScript v1 示例。

该 @foundry/ontology-api 包适用于 TypeScript v1 函数。在 TypeScript v2 仓库中，您必须先生成并安装本体论 SDK，然后才能从以下位置导入本体论类型： @ontology/sdk。请参阅 生成本体论 SDK 了解这些步骤。

添加由对象支持的函数

接下来，使用您刚刚导入的对象类型编写一个函数。您的代码将依赖于您可用的对象类型、属性和关联类型。切换回 Code 选项卡，然后尝试导入您刚刚添加的对象类型之一：

基于您自己的本体论对这些 API 进行试验，并编写一个根据您的对象类型返回值的函数。

在实时预览中测试

打开 函数助手，切换到 实时预览，并选择您在上文编写的函数。要在实时预览中运行由对象支撑的函数，您必须导入该对象类型的支撑数据源。选择 运行 选项旁边的警告图标：

然后，使用对话框为您的对象类型导入支撑数据源：

导入数据源后，选择一个对象，然后选择 运行 以查看结果：

实时预览权限

实时预览中对象类型的权限取决于 TypeScript 仓库对每个对象类型底层的支撑数据源的权限。在测试 创建通知的函数时，不会强制执行接收者的权限。因此，创建通知的函数在实时预览中可能会成功，但在 Foundry 中被其他位置的操作使用时可能会失败。

发布新函数

要发布新函数，请提交代码并使用 分支 标签页发布新标签。函数发布后，您可以使用 函数助手。

函数发布后，您就可以开始在整个平台的其他应用程序中使用它。
