规模和属性限制

设置了若干限制，以确保编辑后的对象类型能够快速处理编辑并更新面向用户的数据，而不会减慢实时应用程序的速度。超出这些限制的操作提交将不会成功，并向用户显示错误消息。

配置限制

直方图 Allow multiple values 开关允许用户向参数传入一个值列表。

限制最大值
基元列表参数中的元素数量10,000
对象引用列表参数中的元素数量1,000
在提交条件中使用时列表参数中的元素数量1,000

编辑限制

限制最大值
可编辑的 对象类型（object types） 数量（在单次操作提交中）50
可编辑的 对象 数量（在单次操作提交中）10,000
对 对象 的每次单独编辑（在操作提交中）32KB (OSv1), 3MB (OSv2)

批量调用限制

一个操作在批量调用中最多可被调用 10,000 次。当操作由函数支撑且该函数未配置为使用 批量执行.

在执行 编辑限制时，批量操作调用中应用的编辑将被视为一个单一组，无论这些编辑是由批次中的哪个请求引起的。

根据调用应用程序的不同，可能适用其他限制。

支持的属性

目前，操作不能用于编辑 主键 。修改主键等同于删除一个对象然后添加一个新对象；与其使用操作编辑主键，不如直接使用 规则.

通知接收人

使用 副作用通知，单次操作最多可通知 500 个接收者。当通知内容以“来自函数”的方式渲染时，此限制减少为五十个接收者。有关生成通知时需考虑的限制的更多信息，请参阅 通知的最大接收者限制.
