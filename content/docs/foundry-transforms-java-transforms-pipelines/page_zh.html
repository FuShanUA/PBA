转换和管道

A Transform 是对如何计算数据集的描述。它描述了以下内容：

  • 输入和输出数据集，
  • 用于将输入数据集转换为输出数据集的代码（称为计算函数），以及
  • 任何额外的配置（例如在运行时使用的自定义 Transforms 配置文件）。

所有转换目前默认为事务类型 SNAPSHOT.

输入和输出数据集以及转换代码在 Transform 对象中指定，然后注册到 Pipeline。如何定义 Transform 取决于两个因素：

  • 您是在定义 高级还是低级转换日
  • 您是使用自动注册还是手动注册来 将您的转换添加到项目的管道中.

转换类型

在 Java API 中，DataFrame 指 Spark 数据集

数据转换可以通过 DataFrame 对象以及文件来表达。这些 DataFrame 对象只是指常规的 Spark DataFrame。在 Spark Scala/Java API 中， DataFrame 由 Dataset。因此，作为用户，您在数据转换代码中直接与 Dataset 对象交互。
有关使用 Spark 的更多信息，您可以参阅 在线提供的 Spark Java API 文档 ↗ 。

对于依赖于 DataFrame 对象的转换，您可以：

  • 定义高级转换，它支持类型为 Dataset<Row>，或
  • 定义低级转换并显式调用方法来访问 Dataset<Row> ，其中包含您的输入数据集。

对于依赖于文件的转换，您必须定义低级转换，然后在您的数据集中访问文件。

以下是两种类型转换之间主要差异的总结：

描述高级转换低级转换
允许进行依赖于 DataFrame objects✓ *✓
允许进行依赖于文件访问的数据转换✓
支持多个输入数据集✓✓
支持多个输出数据集✓
计算函数必须返回 DataFrame value✓
计算函数写入输出，而不是返回值✓

* 对于依赖于 DataFrame 对象进行语义搜索。

对于这两种 Transform 类型，您都需要创建一个包含计算函数的类。在此类中，您的计算函数必须是使用 @Compute注解的公共非静态方法。如果没有此注解，您的数据转换代码将无法被正确注册。

注册类型

仓库中的每个 Transforms Java 子项目都会公开一个 Pipeline 对象。此 Pipeline 对象用于：

  1. 在 Foundry 中注册数据集及其构建方式的说明，以及
  2. 定位并执行在 Foundry 构建期间负责构建给定数据集的 Transform 对象。

向管道添加转换

一旦与您的项目关联的 Transform 管道将某个数据集声明为输出，您就可以在 Foundry 中构建该数据集。添加 Transform 对象的两种推荐方式是 Pipeline 可以 手动注册 和 自动注册.

对于大多数工作流，推荐使用自动注册

如果您有更高级的工作流和/或希望显式地将每个 Transform 对象添加到您项目的管道中，您可以使用手动注册。例如，如果您希望以元编程的方式将相同的数据转换逻辑应用于多个输入和输出数据集组合，使用手动注册会很有用。

否则，强烈建议使用自动注册，以确保您的注册代码简洁且集中。使用自动注册时， Pipeline.autoBindFromPackage() 会发现包中的任何 Transform 定义（前提是这些对象具有所需的 @Input 和 @Output 注解）。

自动注册

随着项目复杂性的增长，手动添加 Transform 对象的两种推荐方式是 Pipeline 可能会变得难以管理。因此， Pipeline 对象提供了 autoBindFromPackage() 方法来发现 Java 包中的所有 Transform 对象。要使用自动注册，您必须执行以下操作：

  • 定义一个与您的 Transform对应的类。使用自动注册时，您需要定义一个包含输入和输出数据集信息以及计算函数的类。
  • 添加足够的 @Input and @Output annotations.
  • 调用 Pipeline.autoBindFromPackage() 方法来注册您提供的 Java 包中的任何 Transform 定义。autoBindFromPackage() 方法只会注册具有所需注解的 Transform 定义。任何不具有所需注解的 Transform 都不会被添加到您项目的 Pipeline中，即使这些 Transform 位于您提供给 autoBindFromPackage() method.

手动注册

Transform 对象可以通过以下方式手动添加到 Pipeline 选项。 Pipeline.register() 方法。每次调用此方法可以注册一个 Transform。要将手动注册与 Transforms 一起使用，您必须执行以下操作：

  • 定义一个包含您的 Transform 对象计算函数的类。与自动注册不同，使用手动注册时，您需要在 PipelineDefiner 实现中提供有关输入和输出数据集的信息
  • 使用直方图中的 HighLevelTransform.builder() 或 LowLevelTransform.builder() 来指定要使用的计算函数，并提供您的输入和输出数据集。
  • 调用 Pipeline.register() 方法来显式地将您的 Transform 定义添加到您项目的管道中。
StopPropagating 和 StopRequiring 需要自动注册

诸如 @StopPropagating 和 @StopRequiring 之类的注解仅支持自动注册的 Java 转换。

Transform 上下文

在某些情况下，数据转换可能依赖于其输入数据集之外的其他内容。例如，转换可能需要访问当前的 Spark 会话，或访问 jobSpec 中的转换参数。在这种情况下，您可以注入一个 TransformContext 对象到转换中。为此，您的计算函数必须接受一个类型为 TransformContext. TransformContext 的参数。它包含 Transforms 的 authHeader、Spark 会话、转换参数以及一个 ServiceDiscovery 对象。 ServiceDiscovery 类会公开所发现的 Foundry 服务的服务 URI。

import org.apache.spark.sql.Dataset;
import org.apache.spark.sql.Row;

/**
* This is an example high-level Transform that accesses the TransformContext
*/
@Compute
public Dataset<Row> myComputeFunction(Dataset<Row> myInput, TransformContext context) {
    int limit = (int) context.parameters().get("limit");
    return myInput.limit(limit);
}

package myproject.datasets;

import com.palantir.transforms.lang.java.api.Compute;
import com.palantir.transforms.lang.java.api.Input;
import com.palantir.transforms.lang.java.api.Output;
import com.palantir.transforms.lang.java.api.TransformContext;
import org.apache.spark.sql.Dataset;
import org.apache.spark.sql.Row;

/**
* This is an example low-level Transform that accesses the TransformContext
*/
@Compute
public void compute(FoundryInput input, FoundryOutput output, TransformContext context) {
    int limit = (int) context.parameters().get("limit");
    output.getDataFrameWriter(input.asDataFrame().read().limit(limit)).write();
}
