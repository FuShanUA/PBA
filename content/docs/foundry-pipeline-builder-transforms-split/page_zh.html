拆分转换

拆分转换用于根据指定条件将输入数据划分为两个不同的输出。此转换会根据定义的条件对输入数据的每一行进行求值，并相应地将各行定向到两个输出之一。

支持的管道类型

拆分转换仅在标准批处理（Spark 支撑）和更快的管道（DataFusion 支撑）中受支持。 拆分 选项不会出现在流式管道中。

有关当前支持的执行模式列表，请参阅 Split on condition 函数参考中的条目。

将转换添加到管道

在图表中选择单个表节点，然后使用以下任一入口点：

  • 选择 拆分 在所选节点旁边显示的操作中。
  • 选择 拆分表 转换操作工具栏中的选项。

如果 拆分 选项未出现，请确认您正在使用标准批处理或更快的管道，并且恰好选择了一个表节点。该选项在不可用时会被隐藏，因此在流式管道中或所选节点不是表格形式（例如媒体集或基于文件的输入）时不会出现。

条件

拆分转换允许您定义一个条件来确定输入数据的划分方式。此条件是一个逻辑表达式，其求值结果为 True or False.

输出

直方图 True 输出将包含条件求值结果为 true 的行。这些行被定向到第一个输出。

直方图 False 输出将包含条件求值结果为 false 的行。这些行被定向到第二个输出。

要预览输出，您可以使用底部面板左上角的下拉菜单。选择 True 以查看 True 输出，或选择 False 以查看 False 输出。

要在下游转换中使用这些输出，请选择该转换，然后选择 True or False 输出作为您的下一个输入。

示例

考虑一个客户订单数据集。您希望根据阈值将订单分为两类：高价值订单和低价值订单。

在这种情况下， 条件 将是 order_value > 1000.

直方图 True 输出将包含满足以下条件的订单： order_value 超过 1000，而 False 输出将包含满足以下条件的订单： order_value 不超过 1000.
