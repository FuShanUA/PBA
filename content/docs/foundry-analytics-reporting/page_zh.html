报告

在 Foundry 中，我们将“报告”定义为创建带有注释的特定时间点内容，以便在平台内共享或下载。如果您想创建供他人直接使用的交互式内容，我们建议使用 Foundry 的 仪表板产品.

或

Notepad 是 Foundry 的报告工具。使用 Notepad，您可以创建实时更新和静态（“特定时间点”）文档、为文档添加注释、在平台内共享文档，以及将文档导出为 PDF。

Notepad 的主要功能包括：

  • 易于使用的文档创建和编辑体验。
  • 能够添加来自各种 Foundry 数据源的内容，包括 Quiver、Contour、Code Workbook 和 Object Explorer。
  • 支持使用动态输入的文档模板。
  • 可自定义的 PDF 导出。

了解如何开始使用 Notepad。

Reports [日落]

日落

Reports 的开发目前处于 日落 开发阶段，并将在未来某个日期被弃用。目前仍提供完整支持。先前保存的报告仍以只读形式可用，除非需要编辑，否则无需转换或迁移到新格式。我们建议将您的工作流迁移到其他应用程序和工具，以满足您的用例需求。

旧版 Foundry Reports 应用程序同时支持实时仪表板和静态报告用例。但是，其他 Foundry 工具对这些工作流提供了更好的支持和更丰富的功能集。对于大多数仪表板和报告用例，我们推荐以下产品：

  • Contour 仪表板 适用于由 Contour 分析生成的内容。Contour 仪表板比 Reports 提供了更好的交互性，具有图表间筛选等功能，以及可在迭代分析的同时通过简单的拖放界面构建仪表板。 了解有关 Contour 仪表板入门的更多信息。
  • Quiver 仪表板 适用于由 Quiver 分析驱动的内容。Reports 不支持嵌入大多数 Quiver 可视化类型。 了解有关 Quiver 仪表板入门的更多信息。
  • 或 适用于跨产品内容和大多数 Foundry 报告用例，如 上文. 了解有关 Notepad 入门的更多信息。

如果您要创建包含来自多个数据源内容的仪表板（例如一个 Contour 分析和一个 Code Workbook，或两个 Contour 分析），您可能仍需要使用 Reports。如果是这样，您可以 了解有关 Reports 入门的更多信息.
