开始使用

本页面介绍了在 Foundry 中使用 Palantir R SDK 编写数据转换时可用的结构和配置选项。

仓库结构

每个 R 转换都由一个 transforms spec 定义和配置，其定义以 YAML 格式编写并保存在 .transforms 文件夹中。仓库项目的完整内容将在运行时可用，并可用于该转换。

.
├── .transforms
|    └── happiness_ranking.yml
|
├── project
|    └── src
|        └── top_10.R
└── .Rprofile

对于从 代码工作区发布的 R 转换，转换 spec 文件会通过 UI 进行渲染和配置。

编写并配置一个简单的 R 转换

在下面的示例中，我们编写一个简单的数据转换，读取一个表格数据集，使用 R 包 dplyr应用筛选，并生成一个包含筛选结果的数据集。

library(foundry)
library(dplyr)

happiness_2019 <- datasets.read_table("happiness_2019")
top_10 <- happiness_2019 %>% filter(Overall_rank <= 10)
datasets.write_table(top_10, "top_10_happiest_countries")

以下是包含该转换定义的相应转换 spec 文件：

将下面提示中的 dataset.rid 字段中填入输入和输出数据集的数据集 RID。输出数据集必须先手动创建，因为我们目前不支持在检查时创建新的输出数据集。

您可以通过在 inputs or outputs 列表中添加新项来增加额外的输入和输出。

inputs:
- alias: "happiness_2019"
  properties:
    type: "dataset"
    dataset:
      rid: "<input dataset rid here>"
outputs:
- alias: "top_10_happiest_countries"
  properties:
    type: "dataset"
    dataset:
      rid: "<output dataset rid here>"
- alias: "second-output"
  properties:
    type: "dataset"
    dataset:
      rid: "<second output dataset rid here>"
runtime:
  type: "rscript"
  rscript:
    identifier: "R.4.1.x"
    filePath: "project/src/top_10.R"

运行时配置：

  • identifier：标识转换的运行时；例如，R.4.1.x 指的是 R 的 4.1 次版本发布。
  • filePath：从项目根目录到将要执行的 R 脚本文件的相对文件路径。

library(foundry)
library(ggplot2)

happiness_2019 <- datasets.read_table("happiness_2019")

png("/tmp/model_plot.png")
plot <- ggplot(happiness_2019, aes(GDP_per_capita, Overall_rank)) + geom_point() 
plot + stat_smooth(method = "lm", formula = y ~ x, geom = "smooth")
dev.off()

datasets.upload_files("/tmp/model_plot.png", "happinessGDP_plot")

管理 R 包和环境

默认情况下，R 转换仓库配置了 Artifacts Repositories ，它们镜像了 Posit™ Package Manager 和 Bioconductor。我们建议用户使用 renv ↗ 来安装 R 包并管理其转换的 R 环境。

In Code Workspace RStudio® Workbench, renv 默认已安装并可用。用户可以在 Packages 面板中搜索可用的包，并生成相应的 R 代码来安装它们。

R 转换还支持从 renv.lock恢复。如果仓库中存在 renv.lock 文件，您可以在转换开始时或在 renv.restore() 中运行 .Rprofile 来恢复 R 环境。

以下示例展示了可以运行以安装 R 转换所需包并生成 renv.lock 文件以保存项目库状态的 R 命令。生成的锁定文件随后可以提交，并用于以后恢复项目。
