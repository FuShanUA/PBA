Apollo MCP 服务器

Apollo Model Context Protocol (MCP) 服务器将 Apollo CLI 功能以工具形式提供给 AI 代理。您可以使用该服务器使 AI 代理能够查询环境、管理资源和搜索 Apollo 文档。

概述

Apollo MCP 服务器实现了 Model Context Protocol ↗，这是一项使 AI 代理能够与外部工具和资源进行交互的标准协议。当您将 AI 代理连接到 Apollo MCP 服务器时，该代理可以访问约 97 个用于管理 Apollo 资源的工具。

设置

要将 AI 代理连接到 Apollo MCP 服务器，请使用以下连接和身份验证详细信息。有关配置 MCP 服务器的说明，请参阅您所用 AI 代理的文档。

连接详细信息

  • 传输类型： http (HTTP 与 Server-Sent Events)
  • 服务器 URL： https://<apollo-hub-url>/apollo-mcp/mcp
    • 请将 <apollo-hub-url> 替换为您 Apollo Hub 的 URL。

身份验证

Apollo MCP 服务器使用 Apollo Bearer Token 进行身份验证。要创建令牌，请按照说明来 创建 Bearer Token。

连接到 MCP 服务器时，请在 Authorization 标头中传递 Bearer Token：

Copied!
1
Authorization: Bearer <your-apollo-token>

验证

配置 MCP 服务器后，在终端中验证连接：

  1. 让智能体列出可用的 Apollo 工具。智能体应返回大约 97 个工具。
  2. 让智能体执行一个简单的查询，例如“在 Apollo 文档中搜索环境。”
  3. 确认智能体可以调用 apollo_docs_search 并成功执行。

发现工具

Apollo MCP 服务器提供了一些工具，可帮助 AI 智能体发现可用的 Apollo 资源并构建查询。

搜索 Schema

Apollo GraphQL API 是查询 Apollo 资源的主要接口。MCP 服务器包含一个 Schema 搜索工具，使 AI 智能体能够在 GraphQL Schema 中查找查询、变更、类型、字段和枚举值。

智能体可以使用此工具：

  • 查找任务所需的查询或变更。
  • 发现某个类型上可用的字段。
  • 了解某个操作的输入参数。
  • 查找某个字段的枚举值。

Apollo 文档搜索

MCP 服务器内置了 Apollo 文档，AI 智能体可以搜索和阅读这些文档。可使用以下文档工具：

  • apollo_docs_search：搜索 Apollo 文档。
  • apollo_docs_read：读取 Apollo 文档的特定部分。

智能体可以使用这些工具：

  • 了解 Apollo 概念，例如环境、模块和发布通道。
  • 了解工作流，例如部署模块和管理变更请求。
  • 查找最佳实践，例如何时使用模块而非实体。
  • 排查故障并理解错误消息。
