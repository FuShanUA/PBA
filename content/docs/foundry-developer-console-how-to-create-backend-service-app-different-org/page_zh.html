使用其他组织创建应用程序

本指南介绍使用旧版权限的应用程序的工作流程。如果您的注册已启用由 Compass 管理的用户权限，应用程序将继承其父项目或文件夹的权限，共享工作流程可能有所不同。

在 Developer Console 中开发使用机密客户端的服务或应用程序时，Developer Console 会为您的应用程序创建一个服务用户。您必须向该服务用户授予对本体论进行读取和写入所需的任何权限。

在启用了基于分类的访问控制的环境中，服务用户不会自动继承应用程序的最高分类设置。您必须将该服务用户显式添加到相应的组和分类中，才能使其获得所需的访问级别。

默认情况下，服务用户将被添加为 Developer Console 中所选组织的访客，如下图所示。

Developer Console 的组织下拉列表仅显示在当前所选位置上标记的组织。即使您是某个组织的管理员，除非该组织已标记在您所选的位置上，否则它不会出现在下拉列表中。

但是，如果该组织与您的默认组织不同，您必须先完成以下两个步骤，才能查看该用户或向其授予权限：

  1. 将应用程序共享给您的组织
  2. 在您的组织中启用该应用程序

将应用程序共享给您的组织

请按照以下步骤准备您的应用程序，以便在您的组织中使用：

  1. 在开发者控制台中，导航至 共享与令牌 （位于左侧边栏）。

  1. 使用 将应用程序共享给组织 界面，将您的组织添加到列表中并保存您的更改。

在您的组织中启用该应用程序

将应用程序共享给您的默认组织后，您就可以切换回默认组织并再次找到该应用程序。

  1. 打开 第三方应用程序 页面（位于控制面板中），并找到您的应用程序。

  1. 选择 操作，然后选择 启用设置。
  2. 在页面顶部，开启 启用应用程序。

保存更改后，服务用户将作为访客添加到您的组织中，您便可以授予任何必要的权限。

Developer Console 会自动检测机密客户端的标记与其服务用户的标记之间是否存在不匹配。如果客户端与服务用户之间的标记或组织成员身份存在差异，Developer Console 将显示警告指示器。如果您在启用应用程序后遇到意外的权限问题，请检查这些警告。
