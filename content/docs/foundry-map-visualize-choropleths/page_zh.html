等值区域图

等值区域图会显示各个区域，并根据对每个区域内所有对象计算得出的聚合值对这些区域进行着色。等值区域图适用于可视化大型数据集中的空间模式。此示例地图展示了由3100万个交通事故对象生成的等值区域图，其中美国的每个州按该州境内发生事故的平均严重程度着色。

要配置等值区域图，请将您想要计算聚合的对象添加到地图中，然后从 “添加显示” 菜单（位于 “样式” 面板）中添加等值区域样式器。

接下来，您需要指定如何将对象分组到各个区域，以及每个区域应如何显示。等值区域与 多边形显示具有相同的样式选项，唯一区别在于所有值均基于对每个区域内所有对象计算得出的聚合结果。

将对象分组到区域

该 “区域” 样式设置部分（用于分级统计图）允许您指定如何将对象分组为各个区域，其中每个区域将在地图上显示为单个多边形。您可以通过具有 Map 应用程序支持的边界标识符类型的属性，或者通过与图层中的对象相关联的对象类型，将对象分组到一起。

按边界标识符分组

Map 应用程序支持为配置了某些常见标识符类型的对象渲染分级统计图。这些边界类型的多边形几何图形内置于 Map 应用程序中，如果您的数据已附加其中一种标识符类型，将使您的数据集成更加容易。

以下是地图支持的一些标识符类型示例：

  • ISO 3166 国家代码
  • 美国州缩写（CA、TX、OR 等）
  • 美国县 FIPS 代码

请参阅 用于地图的本体论对象 页面，详细了解所支持标识符的完整范围，以及如何配置属性类型以在地图中引用这些标识符。

要配置边界标识符，请选择 属性 选项（位于 分组依据 下拉菜单中），然后从已在 属性 下拉菜单。仅显示在本体论中配置为边界标识符的属性。

选择边界属性后，在计算用于样式设置的聚合时，该属性类型的值相同的所有对象将被归为一组。

按关联对象分组

如果您需要为区域提供自己的几何形状，可以通过选择本体论关联来对对象进行分组。然后，Map 应用程序会将关联到同一对象的对象归为一组。 详细了解本体论配置 ，该配置用于自定义区域几何形状。

按聚合设置样式

在等值区域图中，基于值的样式设置有所不同，因为每个区域的颜色是根据对该区域内对象计算得出的聚合结果来确定的。为等值区域图定义聚合的方式有两种： 标准和 表达式。

标准聚合

标准聚合是一种对区域内对象的某个属性进行聚合的简单方法。要配置标准聚合，请打开 属性 菜单，然后选择您要使用的属性和聚合函数（求和、平均值、最大值、最小值）。

表达式聚合

表达式聚合允许您定义对区域中对象的自定义聚合。通过添加多个表达式引用来构建表达式聚合，列表中的最后一个引用提供将用于为该区域着色的值。每个引用可以是以下之一：

  • 对分组到区域中的对象的属性执行的简单聚合
  • 来自区域本身的属性（仅在按关联对象分组时可用）
  • 组合另外两个引用的操作

例如，此地图使用表达式聚合，根据各分区内小径的密度为美国林务局护林员分区着色。

它使用三个表达式来计算小径密度：

  • 第一个表达式计算每个美国林务局护林员分区内小径的总长度。
  • 第二个表达式引用该区域的总面积。
  • 第三个表达式是一个操作，通过将第一个引用除以第二个引用来计算每英亩的平均小径长度。
