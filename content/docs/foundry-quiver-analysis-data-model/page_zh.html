卡片的输入和输出类型

Quiver 分析是通过一系列可以相互依赖的卡片构建的，从而形成一个分析图。Quiver 中的每张卡片可以接受零个或多个输入，并产生特定类型的输出。

例如：

  • A 数值聚合 卡片接受一个 object set 作为输入，并产生一个 number 作为输出。
  • A 滚动聚合 图表接受一个 time series 作为输入，并产生一个 time series 作为输出。
  • A 数字转日期 卡片接受一个 number 作为输入，并产生一个 time 作为输出。

查看完整的输入/输出类型列表。

只有当某张卡片的输出类型等于下游卡片的输入类型时，该卡片才能被添加为另一张卡片的输入。有时，如果两张卡片的输入/输出类型不匹配，则必须在它们之间添加一张转换卡片。

例如，一个 筛选对象集 不能直接作为输入传递给 或 因为筛选对象集产生一个对象集作为输出，而对象属性接受单个对象作为输入。要解决此问题， 对象选择器 必须放置在这两张卡片之间，因为对象选择器接受一个对象集作为输入，并产生单个对象作为输出。

理解卡片的输出类型以及它可以在哪些下游卡片中使用，是 Quiver 中一个非常重要的概念。幸运的是，Quiver 的 后续操作菜单（在悬停于卡片上时显示）有助于简化这个问题。它只显示能够将当前卡片的输出类型作为输入的卡片。后续操作菜单所使用的类型显示在菜单的右上角。

此外，在编辑器中为 Quiver 卡片配置变量输入时，只会显示具有兼容输出类型的卡片以供选择。例如，在下图中，当为 数字转日期 卡片配置输入数字时，我们可以选择数值参数作为输入（$I），但不能选择字符串参数（$H).
