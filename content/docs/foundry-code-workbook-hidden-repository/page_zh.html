隐藏代码仓库

Code Workbook 通过使用以下功能提供轻量级版本控制： 分支。此外，每个工作簿都由一个特殊的隐藏代码仓库支撑。该仓库作为代码工作簿中所写代码的安全备份，同时也会展示工作簿上所有代码更改的历史记录。

您可以通过打开 Code Workbook 界面右上角的齿轮图标菜单并选择以下选项来访问工作簿的隐藏代码仓库： 打开隐藏的 Code Repository.

特殊属性

工作簿的隐藏仓库将始终具有以下属性：

  • 该仓库是只读的： 仓库内容只能查看，绝不能直接在仓库中更新。更新仓库的唯一方法是在工作簿中进行代码更改。
  • 该仓库默认处于隐藏状态： 只能通过 Code Workbook 界面发现它。
  • 该仓库存储三个单独的文件： 直方图 pipeline.R, pipeline.py日 pipeline.sql 文件分别包含转换后的工作簿中各自语言的全部代码。
  • 该仓库保存完整的更改历史： 每个分支的工作簿代码更改的完整历史记录可在隐藏仓库的 提供了专为数据转换量身定制的版本控制体验，支持团队在同一工作簿中同时处理逻辑与数据。 标签页中查看。
  • 该仓库包含一个隐藏的 workbook.yml 文件： 该文件存储有关工作簿的基本元数据。

在工作簿分支上进行的每次代码更改都会自动向隐藏代码仓库中的相应分支创建一个新的提交。

如果代码工作簿中存在多个给定语言的代码单元，每个代码单元都将附加到同一个唯一的文件中： pipeline.R 对于 R， pipeline.py 对于 Python，以及 pipeline.sql 对于 SQL。这允许您在单个文件中查看给定语言的所有代码。在工作簿的 全局代码 部分中编写的代码也将存储在相应的文件中。

恢复丢失的代码

通过定期存储工作簿的备份，隐藏代码仓库是恢复丢失或意外删除的代码的推荐方式。要查看给定工作簿分支的历史记录，请打开隐藏仓库顶部的 提供了专为数据转换量身定制的版本控制体验，支持团队在同一工作簿中同时处理逻辑与数据。 标签页，选择所需的分支（例如 master），然后选择您想要检查代码更改的提交。然后，您可以复制代码并将其粘贴回工作簿。
