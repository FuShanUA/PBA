创建 Jupyter® 代码工作区

  1. 要为模型训练创建新的 Jupyter® 代码工作区，请导航到您的项目文件夹并选择 + New > Jupyter® Code Workspace，或选择 + 新建代码工作区 （在 Code Workspaces 应用程序中）。
  2. 在 Code Workspaces 中，选择 JupyterLab® 作为工作区类型，然后选择 继续 （位于右下角）。
  3. 为您的工作区命名，使其与您正在训练的模型相关。您还可以选择配置其他设置，例如工作区的计算资源或网络策略，方法是选择 高级 菜单中选择 分支回退 步骤。为笔记本命名后，选择 继续.
  4. 最后，选择 创建 以创建并启动工作区。

导入数据并编写模型训练代码

建立工作区后，您可以创建一个新的笔记本以导入数据并开始编写模型训练代码。

Code Workspaces 提供对其他 Foundry 代码编写环境（例如 Code Repositories）中可用软件包的访问。要添加新软件包，请打开 软件包 标签页（位于工作区左侧边栏），搜索您需要的软件包并选择它，然后点击 最新版 或其他可用版本，以打开终端并运行相应的安装命令。

将数据导入工作区

from sklearn.impute import SimpleImputer
from sklearn.linear_model import LinearRegression
from sklearn.pipeline import Pipeline
from sklearn.preprocessing import StandardScaler

numeric_features = ['median_income', 'housing_median_age', 'total_rooms']
numeric_transformer = Pipeline(
    steps=[
        ("imputer", SimpleImputer(strategy="median")),
        ("scaler", StandardScaler())
    ]
)

model = Pipeline(
    steps=[
        ("preprocessor", numeric_transformer),
        ("classifier", LinearRegression())
    ]
)
X_train = training_dataframe[numeric_features]
y_train = training_dataframe['median_house_value']
model.fit(X_train, y_train)

添加模型输出并实现模型适配器

要在 Code Workspaces 之外提供模型，您必须向工作区添加新的模型输出。Code Workspaces 将自动创建并存储一个新的 .py 文件到您现有的工作区中，在您创建新的模型输出后，您可以使用该文件来实现 模型适配器。模型适配器为 Foundry 中的所有模型提供标准接口，确保平台的生产应用程序可以在模型创建后立即使用这些模型。Foundry 基础设施将加载模型、配置其 Python 依赖项、公开其 API，并启用模型接口。

  1. 要添加输出，请打开 链接进行访问。 在左侧边栏中位于下方的选项卡 软件包 并选择 Add model > Create new model。为模型命名并将其保存到您选择的位置。

  1. 在您为模型命名并保存后，系统将提示您 发布新模型 在工作区左侧面板中。完成 步骤 1：安装 palantir_models 将代码片段复制到剪贴板，并在您原始的 .ipynb notebook 文件中运行。

  2. 成功安装后 palantir_models，在以下位置创建并开发您的模型适配器 步骤 2：开发您的模型适配器。模型适配器必须实现以下方法：

    1. save 和 load: 为了重用您的模型，您需要定义模型的保存和加载方式。Palantir 提供 默认方法 用于序列化（保存），在更复杂的情况下，您可以 实现自定义序列化 logic.
    2. api: 定义模型的 API，并告知 Foundry 您的模型需要哪种类型的输入数据。
    3. predict: 由 Foundry 调用以向您的模型提供数据。您可以在此处将输入数据传递给模型并生成推断（预测）。

    请参阅 模型适配器 API 参考 以了解更多详情。

import palantir_models as pm
from palantir_models.serializers import DillSerializer

class LinearRegressionModelAdapter(pm.ModelAdapter):

    @pm.auto_serialize(
        model=DillSerializer()
    )
    def __init__(self, model):
        self.model = model

    @classmethod
    def api(cls):
        columns = [
            ('median_income', float),
            ('housing_median_age', float),
            ('total_rooms', float),
        ]
        return {"df_in": pm.Pandas(columns)}, \
               {"df_out": pm.Pandas(columns + [('prediction', float)])}

    def predict(self, df_in):
        df_in['prediction'] = self.model.predict(
            df_in[['median_income', 'housing_median_age', 'total_rooms']]
        )
        return df_in

from palantir_models.code_workspaces import ModelOutput

# Model adapter has been defined in linear_regression_model_adapter.py
from linear_regression_model_adapter import LinearRegressionModelAdapter

# sklearn_model is a model trained in another cell
linear_regression_model_adapter = LinearRegressionModelAdapter(sklearn_model)

# "linear_regression_model" is the alias for this example model
model_output = ModelOutput("linear_regression_model")
model_output.publish(linear_regression_model_adapter)

该代码片段应可直接使用，但需要正确地将您训练的模型传递给适配器初始化。代码准备就绪后，您可以运行该单元格将模型发布到 Foundry。
