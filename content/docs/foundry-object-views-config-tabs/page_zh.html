配置标签页

一个 标签页 是对象视图内导航和内容分组的主要方式。每个标签页都包含一个 Workshop 模块，并支持自定义条件可见性、筛选设置和布局设置。

有两种类型的标签页可添加到您的对象视图：托管式 Workshop 模块和独立式 Workshop 模块。

  • 托管式 Workshop 模块： 我们建议使用 Workshop 在对象视图中构建新标签页。此选项允许您开发更复杂的视图，从而充分利用 Foundry 的应用程序构建功能。 详细了解由 Workshop 支撑的标签页。 托管式模块的权限会自动与对象视图保持同步，且无法重复使用。
  • 现有 Workshop 模块： 您可以将已在 Workshop 中构建的模块直接嵌入到对象视图标签页中。您可以在多个对象视图中使用同一模块。

某些标签页是使用 旧版 构建器构建的，该构建器允许您创建简单标签页，但在布局、小组件和数据选项方面的灵活性有限。无法再使用此构建器添加新标签页，但现有标签页仍受支持。

管理标签页

添加新标签页

您可以在编辑器内的两个位置添加标签页： 标签页 对象视图编辑器侧边栏的部分，或 添加标签页 按钮，该按钮位于对象视图预览本身的标签页列表中。任一选项均允许您选择所需的标签页类型。

删除标签页

您可以从对象视图编辑器侧边栏中的标签页列表中删除标签页。您也可以点击编辑器侧边栏中的标签页，导航至 高级，然后点击 删除标签页。

移动标签页

使用对象视图编辑器侧边栏中的标签页列表移动标签页。点击向上或向下箭头可在对象视图预览中重新排列标签页的顺序。

配置标签页设置

标签页可见性

可以通过多种方式有条件地向查看用户显示标签页。其中一种方法是使用已配置的对象视图和 配置文件。您还可以根据另外两个因素将标签页配置为有条件可见：

  • 属性值： 如果当前所查看对象的某一属性值等于或不等于给定值，则此条件成立。当标签页显示的内容仅与某个属性值符合预期值的对象相关时，属性值条件非常有用。
    • 例如，您可能希望向 Airport 对象添加一个 区域视图 标签页，该标签页仅适用于特定区域内的 Airport 对象。您可能有一个不同的 区域视图 标签页，该标签页针对其他区域设置了条件可见性。每个标签页可以有不同的可视化组件。
  • 关联可见性： 如果查看该标签页的用户有权查看当前所查看对象可能关联到的对象类型，则此条件成立。当标签页基于对象的关联显示内容，而查看用户可能无权查看这些关联另一侧的对象时，关联可见性条件非常有用。

标签页设置

您可以配置的其他常规标签页设置包括：

  • 标题： 标题设置用于控制在对象视图内的标签页列表中显示的标签。标签页标题应简短且能描述其内容。
  • 内容类型： 您可以使用此配置指定在标签页内显示的关联类型或关联（如适用）。如果您选择 关联 选项，您将在对象视图中的标签页标题旁看到一个徽章，显示有多少对象与当前查看的对象相关联。
  • 内容布局： 所有旧版标签页均支持双列小组件列表布局，当小组件指定其应对齐到特定列时，该布局即被激活。使用此配置选项可控制标签页级别的各列是等宽还是具有不同尺寸。
  • 跨区块筛选： 启用此设置后，此标签页中的小组件即可发布和使用通过与小组件交互所控制的筛选器。例如，您可能希望在某个图表中选择一个条目，并筛选所有其他图表以仅显示相关数据。您还可以自定义筛选器集的 ID，然后在其他标签页上使用相同的 ID，以便跨多个标签页使用和保留筛选器。
