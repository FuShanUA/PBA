配置选项卡

A 标签页 是对象视图（Object View）中导航和分组内容的主要方法。每个选项卡包含一个 Workshop 模块，并提供条件可见性、筛选设置和布局设置等自定义选项。

可添加到对象视图（Object View）的选项卡有两种类型：托管 Workshop 模块和独立 Workshop 模块。

  • 托管 Workshop 模块： 我们建议使用 来运行该专业代码代理。你还可以通过 在对象视图（Object View）中构建新选项卡。此选项允许您开发更复杂的视图，并充分利用 Foundry 的应用构建能力。 了解有关 Workshop 支撑选项卡的更多信息。 托管模块的权限会自动与对象视图（Object View）保持同步，且无法重复使用。
  • 现有 Workshop 模块： 您可以将已在 Workshop 中构建的模块直接嵌入到对象视图（Object View）选项卡中。您可以在多个对象视图中使用同一模块。

某些选项卡是使用 遗留版 构建器创建的，该构建器允许您创建布局、小部件和数据选项灵活性有限的简单选项卡。目前无法再使用此构建器添加新选项卡，但现有选项卡仍受支持。

管理选项卡

添加新选项卡

您可以在编辑器中的两个位置添加选项卡： 选项卡 对象视图（Object View）编辑器侧边栏的相应部分，或 添加标签页 对象视图（Object View）预览中选项卡列表上的按钮。两种选项都允许您选择所需的选项卡类型。

删除选项卡

您可以在对象视图（Object View）编辑器侧边栏的选项卡列表中删除选项卡。您也可以在编辑器侧边栏中点击该选项卡，然后导航至 高级，然后点击 删除选项卡.

移动选项卡

使用对象视图（Object View）编辑器侧边栏的选项卡列表移动选项卡。点击向上或向下箭头可在对象视图（Object View）预览中重新排列其顺序。

配置选项卡设置

选项卡可见性

可以通过多种方式有条件地向查看用户显示选项卡。其中一种方法是使用已配置的对象视图（Object View）和 配置文件。您还可以基于以下另外两个因素将选项卡配置为有条件可见：

  • 属性值： 如果当前查看对象的某个属性值等于或不等于给定值，则满足此条件。当选项卡显示的内容仅与某个属性值符合预期值的对象相关时，属性值条件非常有用。
    • 例如，您可能希望为机场（Airport）对象添加一个 区域视图 选项卡，该选项卡仅适用于特定区域的机场。您可以为其他区域设置不同的 区域视图 具有条件可见性的选项卡。每个选项卡可以有不同的可视化组件。
  • 关联可见性： 如果查看该选项卡的用户有权查看当前查看对象可能关联到的对象类型，则满足此条件。当选项卡显示基于对象关联的内容，而查看用户可能无权查看这些关联另一侧的对象时，关联可见性条件非常有用。

选项卡设置

您可以配置的其他常规选项卡设置包括：

  • 标题： 标题设置控制对象视图（Object View）中选项卡列表内显示的标签。选项卡标题应简短并能描述其内容。
  • 内容类型： 您可以使用此配置指定选项卡中显示的关联类型或关联（如相关）。如果您选择 关联 选项，您将在对象视图（Object View）中的选项卡标题旁看到一个徽章，显示当前查看对象所关联的对象数量。
  • 内容布局： 所有旧版标签页均支持双列小部件列表布局，当小部件指定应与特定列对齐时，该布局即被激活。使用此配置选项可控制标签页级别的列是等宽还是具有不同尺寸。
  • 横截面筛选： 启用此设置可允许此标签页内的小部件发布和使用通过与小部件交互所控制的筛选器。例如，您可能希望在图表中选择一个条目，并筛选所有其他图表以仅显示相关数据。您还可以自定义筛选器集的 ID，然后在其他标签页上使用相同的 ID，以便跨多个标签页使用和保留筛选器。
