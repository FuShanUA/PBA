设置 Slack 监听器

本指南将逐步介绍如何为 Slack 配置监听器，从而将 Slack 中的事件实时馈送到 Foundry 流式数据集。

详细了解 Slack。↗

先决条件

在配置之前，请确保：

  • 您的 enrollment 的入口策略已针对您的 Slack 实例所在的 AWS 区域或国家/地区进行了适当配置。 了解如何配置入口。

  • 您必须拥有自己的 Slack 实例并具有管理员访问权限。

操作说明

  1. 为您的集成创建一个新的 Slack 应用。 请参阅外部文档。↗



  2. 记下您应用的 signing secret 值，该值位于 Basic Information 部分。您需要此值才能成功设置监听器。



  3. 在 Foundry 的 Data Connection 应用中创建 Slack 监听器。

    a. 在 Message Signing Secret字段中，输入上一步中的 Signing Secret 值。

    b. 记下此页面上 Endpoints 字段中显示的 URL。

    c. 选择 save and continue。



  4. 现在需要信息安全官进行管理员审批。请查看该开关的描述。

  5. 在该监听器的 Test 页面上，选择 Start 以确保您的监听器已启用。您必须在继续操作之前完成此步骤，因为如果监听器未激活，下一步将会失败。



  6. 当监听器状态显示为活跃后，您就可以将监听器 URL 复制到 Slack 中以设置推送事件订阅。 a. 打开 Slack，然后导航至 事件订阅。

    b. 切换开关以启用事件订阅，然后将步骤 3 中的监听器 URL 输入到 请求 URL 字段。

    c. Slack 将验证监听器是否正确设置，您将在 URL 上方看到“已验证”消息，如下所示。

    d. 然后，您需要添加事件及相关作用域，以便 Slack 将事件推送到您的监听器。举个简单的例子，您可以添加 app_mention 事件，该事件需要 app_mentions:read 作用域。当机器人被明确提及时，将触发此事件。



  7. 请记住将您的应用程序安装到 Slack 工作区中。您应该在指定所需事件之后执行此操作，因为每当作用域发生更改时，都必须重新安装应用程序。



  8. 发送一条测试消息，并观察它出现在监听器的输出流中。
