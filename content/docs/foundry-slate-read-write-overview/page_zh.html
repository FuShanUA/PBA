读取和写入数据

Slate 可以从 Foundry 和外部系统发送和接收数据。 对象集, 对象上下文日 Foundry 函数 提供对本体论的轻松只读访问，而 Actions 部件 则专门允许用户向本体论写回数据。

直方图 本体论 SDK (OSDK) 在 Slate 的函数编辑器中提供对对象类型、关联类型、操作和函数的类型安全访问。

查询 提供对各种预配置端点的通用访问。查询中的每个数据源都必须通过管理面板进行配置。配置完成后，用户可以 利用查询 将数据从其他服务直接拉取到他们的应用程序中，或触发 post 请求将数据直接写入外部数据库。查询可用性是 Slate 中导入和导出数据最灵活、最开放的功能。

所有导入的数据在 Slate 中都以 JSON 格式表示，从而将来自所有数据源的数据统一为单一结构。数据一旦进入 Slate，就会失去这一上下文，并可以被自由操作以生成所需的工作流。

导入和导出组件可以配置为使用变量、函数、部件或其他查询的输出，并动态读取和写入数据。与对象集或操作相比，查询可以构建为与具体实现无关，且不限于预配置的交互。同一个查询可能先创建一个新的数据点，但再次运行该查询时则会更新之前创建的数据点。

对象集、对象上下文、Foundry 函数、OSDK 和操作所需的设置较少，但提供的灵活性也较低。
