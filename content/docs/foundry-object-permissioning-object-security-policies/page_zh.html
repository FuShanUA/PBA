对象和属性安全策略

对象安全策略允许您通过在对象类型上配置安全策略，独立于支撑数据源上的权限，来配置对象实例上的查看权限。这些策略用于实现 行级安全。

特定属性的可见性可以通过附加的 属性安全策略来保护。这些策略与对象安全策略完全相同，只是它们仅适用于选定的属性。这些策略用于实现 列级安全。

默认情况下,对象安全策略会应用于所有属性。当属性安全策略包含某个属性时,用户必须同时通过对象安全策略和属性安全策略,才能查看该属性值。对象和属性安全策略的组合用于实现 单元格级安全性。如果用户未通过对象安全策略,则该用户将无法查看该对象实例。如果用户通过了对象安全策略但未通过属性安全策略,则会看到 null 值来替代属性值。

配置对象和属性安全策略

对象实例及其属性的访问权限由以下条件决定:

  • Viewer 对对象类型的访问权限。
  • 传递细粒度策略（如果已配置）。
  • 传递任何 标记， 组织，或 分类 检查。

配置对象或属性安全策略后，用户无需 Viewer 访问对象类型支撑数据源的权限即可查看对象实例。

考虑一个示例，其中 Passenger 对象类型具有以下属性 User ID， Flight Number， Seat Assignment， Name、 Address和 Phone Number。部分乘客是 VIP，其信息只有拥有 VIP 标记访问权限的用户才能查看。此外，部分属性（例如 Name、 Address和 Phone Number）应仅对拥有 PII 标记且有权查看个人身份信息的用户可见。由于该支撑数据集由敏感数据组成，因此应为其添加 PII 以及 VIP。但是，没有敏感标记的用户仍应能够访问乘客的航班详情。

可以采取以下步骤来保护 Passenger 该对象类型，具体方法是使用对象安全策略。

  1. 导航至该对象类型的 安全 标签页。



  2. 选择 创建 于 安全策略 部分下，以使用对象安全策略覆盖数据源策略。



  3. 创建用于编辑对象实例查看权限的对象安全策略。您可以选择添加细粒度策略，并编辑组织和标记。



  4. 在 标记 配置中，停止继承 PII 和 VIP 标记，以便没有这些标记的用户可以查看对象实例。



  5. 添加 细粒度策略 以限制对 VIP 的访问。该 VIP 标记将作为 强制控制属性添加。每一行在强制控制属性中都有一组标记，用户必须满足这些标记才能访问该对象实例。



  6. 这样就创建了对象安全策略。现在，我们需要为 PII 属性应用 PII 标记来保护它们。我们可以通过添加属性安全策略来实现这一点。



  7. 选择需要保护的属性并为策略命名。然后，添加 PII 标记，在 管理标记 设置中进行。属性安全策略的配置设置与对象安全策略完全相同。



    选择 管理标记 （针对属性安全策略）并添加该 PII 标记。



  8. 此操作将创建属性安全策略。该策略中包含的属性现在同时受对象安全策略和新建的属性安全策略的保护。未包含在任何属性安全策略中的属性仍将受对象安全策略的保护。



编辑安全策略的权限

要创建或编辑对象或属性安全策略，您必须是该对象类型的 所有者 。如果您的注册使用 基于项目的权限，这意味着您必须在包含该对象类型的项目中拥有 Owner 角色。

属性安全策略限制

在配置一个或多个属性安全策略时，以下限制适用：

  • 必须已经配置了对象安全策略。
  • 主键属性不能作为任何属性安全策略的成员。
  • 非主键属性最多只能作为一个属性安全策略的成员。

配置对象类型的访问权限

对象类型的访问权限可在 本体论元数据权限中配置。用户需要能够 查看对象类型定义和实例。

配置细粒度策略

详细了解如何为行级安全配置细粒度策略。

属性安全策略的粒度策略限制

对于在属性安全策略上配置的粒度策略，属性安全策略的粒度策略与对象安全策略的粒度策略的合计 比较权重 必须保持在 10,000 的粒度策略比较限制之内。

配置强制控制

默认情况下，对象安全策略将从其数据源继承所有强制控制。其中包括 标记、 组织以及 分类。

随后可以进一步自定义对象安全策略，以添加新的强制控制，并移除不再需要的继承强制控制。

具有对象安全策略的物化

对象安全策略还会决定查看权限 物化后的 对象类型中的数据。

目前，具有对象安全策略的对象类型只能物化到 Foundry 数据集。最严格的权限将应用于物化后的数据。这包括以下内容：

  • 来自支撑数据源的所有标记。
  • 在对象或属性安全策略上应用的附加标记。
  • 来自所有对象和属性安全策略的细粒度策略中使用的所有强制控制属性的标记。

物化数据集上的事务受到物化数据集构建时生成的安全策略的保护。当用户在对象或属性安全策略中添加或删除标记时，该标记只会反映在标记存在期间提交的事务中。事务在物化作业 按计划构建时提交，由用户配置。 将标记添加到对象或属性安全策略后，请务必执行以下操作：

  • 如果标记需要立即传播到物化数据集，请构建物化数据集。
  • 使用该标记对物化数据集或支撑数据集进行标记，以保护物化数据集上的所有历史事务。

测试对象安全策略

配置对象安全策略时，您可以根据未保存的对象安全策略，测试特定用户查看已索引对象类型属性的能力。您还可以编辑细粒度策略中引用的属性值，以测试假设的对象实例，并确定您的策略是否配置正确。选择 测试策略 从 安全策略 部分以启动 测试安全策略 模态框。

在 测试安全策略 模态框中，使用 配置测试 面板来选择一个 用户 （您希望测试其在给定 对象上的可见性访问权限）。 结果 部分显示了在当前安全策略配置下，用户可以查看该对象的哪些属性。

对象安全策略测试的当前限制

  • 您无法测试 派生属性 可见性，因为这同样取决于用户在派生属性源对象上的可见性。
  • 如果您既不是安全策略中所引用组织的成员，也不是其管理员，那么在测试期间将不会考虑访客成员身份和次要组织。Foundry 会通过显示一个警告提示框来表明这一点，该提示框会列出您没有权限的组织。

从受限视图迁移到对象安全策略

建议使用对象安全策略而非 受限视图 ，适用于基于本体论构建的大多数用例。它们提供统一的单元格级安全性、近乎即时的策略更新，并支持流式处理和分支。 详细了解对象和属性安全策略的优势。

如果您之前设置了由受限视图支撑的对象类型，并且想要迁移到对象安全策略，可以使用下文所述的迁移工具。 详细了解对象和属性策略与数据源策略之间的区别。

您可以使用 安全 选项卡中的迁移工具，将对象类型的数据源从受限视图迁移到受限视图的支撑数据集（由对象安全策略保护）。该工具会配置安全策略，以匹配受限视图上定义的策略。

限制

迁移工具并不支持所有受限视图配置。以下配置不受支持：

  • 具有多个数据源的对象类型（MDO）。
  • 具有多个物化或单一受限视图物化的对象类型。
  • 受限视图，其 细粒度策略 使用了不支持的比较运算符，包括大于、大于或等于、小于和小于或等于。
  • 受限视图，其细粒度策略引用数值常量值（例如整数、长整数或双精度浮点数）。
  • 受限视图，其细粒度策略引用授权组 ID、组织标记 ID 或静态标记 ID 作为用户属性。请考虑使用 强制控制属性 以实现同等的安全性。

保留自主安全性

要保留项目对数据的查看限制（即从受限视图所在项目继承的安全配置），您可以使用迁移工具将对象类型移动到与受限视图相同的项目中。
