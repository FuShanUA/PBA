Foundry 连接器

用于通过转换 API 与 Foundry 交互的连接器。

Connector 可用于交互式构建 TransformInput 和 TransformOutput 对象，还可用于运行 Transform。

FoundryConnector

class transforms.foundry.connectors.FoundryConnector(service_config, auth_header, filesystem_id=None, fallback_branches=None, resolver=None)

  • 用于访问 Foundry 服务的入口点。
  • 该 Foundry 对象通过提供用于操作数据集的 API 来管理与 Foundry 服务的交互。

参数

  • service_config (dict ↗)
    • 符合 Java 类 com.palantir.remoting.api.config.service.ServicesConfigBlock 中 JSON 规范的配置字典。
  • auth_header (str ↗)
    • 连接 Foundry 服务时使用的授权字符串。
  • filesystem_id (str ↗，可选)
    • 要使用的支撑文件系统。
  • fallback_branches (List[str ↗], 可选)
    • 回退分支。
  • resolver (Callable[[str ↗], str ↗], 可选)
    • 用于将数据集别名解析为 rid 的函数。默认将别名作为项目路径进行解析。

input(alias=None, rid=None, branch=None, end_txrid=None, start_txrid=None, schema_version=None)

  • 构造一个 TransformInput 从给定的参数中。
  • 该 资源标识符 用于构造 TransformInput 将解析自给定的 alias 除非 rid 参数被传递。

参数

  • alias (str ↗, 可选)
    • 数据集的别名。
  • rid (str ↗, 可选)
    • 数据集的资源标识符。
  • branch (str ↗, 可选)
    • 用于读取数据集的分支。如果未设置，则会选择 fallbacks 列表中第一个存在于 Catalog中的分支。
  • end_txrid (str ↗, 可选)
    • 视图的结束事务，如果未设置，则默认为给定分支上的最新事务。
  • start_txrid (str ↗, 可选)
    • 视图的起始事务。
  • schema_version (str ↗, 可选)
    • 读取时使用的架构版本，如果未设置，则默认使用给定分支上的最新架构版本。

返回值

  • 表示所请求数据集的输入对象。

返回类型

  • transforms.api.TransformInput

抛出

  • ValueError ↗
    • 如果 别名 或 rid （但不可同时指定两者）未指定。
  • ValueError ↗
    • 如果未指定分支，且无法在以下位置找到回退分支： 目录。

output（alias=None, rid=None, branch=None, txrid=None, filesystem_id=None)

  • 构造一个 TransformOutput ，从给定的别名或 rid。
  • 该 资源标识符 用于构造 transforms.api.TransformOutput ，将解析自给定的 alias 除非 rid 参数被传入。

参数

  • alias (str ↗, 可选)
    • 数据集的别名。
  • rid (str ↗，可选)
    • 数据集的资源标识符。
  • branch (str ↗，可选)
    • 要将数据集写入的分支。如果未设置，将选择该分支作为 fallbacks 列表中的第一个分支。
  • txrid (str ↗, 可选)
    • 应将数据写入的事务。
  • filesystem_id (str ↗，可选)
    • 如果数据集尚不存在，则在其中创建该数据集的文件系统。

返回

  • 表示所请求数据集的输出对象。

返回类型

  • transforms.api.TransformOutput

抛出

  • ValueError ↗
    • 如果 alias 或 rid （但不是两者）未指定。

run（转换）

  • 运行给定的 转换 使用最新的输入和输出。

参数

  • transform (transforms.api.Transform)
    • 要运行的转换。

auth_header

  • str
    • 用于与 Foundry 通信的身份验证标头。

fallback_branches

  • List[str]
    • 用于检索数据集的回退分支。

spark_session

  • pyspark.sql.SparkSession ↗
    • 了解 SparkSession 是由 FoundrySparkManager创建的。
