SAP

将 Foundry 连接到 SAP 包含两个步骤：

  1. 安装 Advanced Business Application Programming (ABAP) 附加组件 在 SAP 端。
  2. 在 Foundry 端配置与您的 SAP 系统环境相匹配的源：
    • SAP ERP：SAP ECC、S/4HANA（本地部署和 Cloud Private Edition）以及其他 ERP Central Component 系统。
    • SAP SLT：通过 SAP Landscape Transformation (SLT) Replication Server 建立的连接，包括实时流式同步。

有关 SAP Business Warehouse (BW) 和现有集成的信息，请参阅 SAP（自定义源）。

本页面的其余部分将介绍 Connector 附加组件，并带您了解端到端设置的整体流程。

该 Palantir Foundry Connector 2.0 for SAP Applications （“Connector”）是一个 SAP 认证的附加组件，其开发合作伙伴为 Diskover Limited ↗。

Connector 可安全地从 SAP 系统（S/4HANA、ECC、Business Warehouse、SLT Replication Server）捕获数据和元数据，并将其集成到 Foundry 平台。Connector 安装在 SAP 应用层，遵循标准 SAP 安全策略，并使用原生 SAP 应用逻辑进行数据访问。

  • Connector 安装： Connector 是一个 SAP 认证的附加组件，使用 SAINT（SAP Add-On Installation Tool）进行安装。

  • Connector 通过 HTTPS 公开访问： Connector 通过 SICF 运行 Web 服务。这使得 Foundry Data Connector 能够通过 HTTPS 请求底层的 ERP 或 BW 数据。

  • 在 Foundry 中定义的数据传输逻辑： 数据传输的表、对象、筛选器和调度计划均在 Foundry 中定义，并由 Foundry Data Connection Coordinator 执行。

  • 应用层访问： 无论 SAP 底层运行的是哪种数据库，Palantir Foundry 都会将请求发送到 SAP ABAP 平台（以前称为 SAP NetWeaver Application Server）。不存在直接的数据库访问。所有信息访问均通过应用层进行。

  • SAP 标准安全： Foundry 将使用在 SAP 内受到保护和授权的 SAP 用户来调用 Connector。因此，所有 SAP 标准安全流程和策略均适用。无需对数据流安全进行额外维护。

  • SAP 应用逻辑访问： 表、函数、BW InfoProvider 和 BEx 查询均为可用于向 Foundry 提取数据的对象。

  • 系统负载和可扩展性： 连接器会在开始提取之前检查系统上的数据负载。如果未满足特定条件,则中止提取。连接器完全符合 SAP 的可扩展性。连接器可以共存于同一应用服务器中,也可以选择在专用于数据处理的独立应用服务器中运行。

设置指南

前提条件

  • SAP_BASIS 7.4 SP5 或更高版本(技术组件版本,同时适用于 SAP NetWeaver 和 SAP S/4HANA 系统)
  • SAP_BASIS 7.5(无最低 SP 级别要求)

这些均为最低版本。连接器支持所有更高的 SAP_BASIS 版本,包括基于 SAP_BASIS 8.x 的 SAP S/4HANA 版本(例如 SAP_BASIS 816)。

如果您计划使用 通过 OData 的 SLT,OData 组件(PALODATA)需要 SAP_BASIS 7.50 SP09 或更高版本。

如果您的主 SAP 系统运行的 SAP_BASIS 版本低于 7.4 SP5,请参阅 Remote Agent 安装 有关如何设置远程连接的详细信息。

快速入门

以下是将贵组织的 SAP 系统连接到 Foundry 的概要步骤。

  1. 请与您的 SAP Basis 团队协作，确定哪种连接模式最适合您的 SAP 系统环境。 详细了解三种连接模式。

  2. 在贵组织的网络中创建一个用于安装 Agent 的空间。

  3. 请确保 Agent 具备与 Foundry 通信所需的网络出口。

    Agent 与 SAP 服务器通信所用的端口是 ICM（Internet Communication Manager，即 SAP ABAP 平台的组件）的默认 HTTPS 端口。可以通过在 SAP 系统中运行 SMICM 事务代码来查找该端口号。

  4. 从 Foundry 下载 Connector 附加组件的安装包。

  5. 请让负责的团队（例如您的 SAP Basis 团队）将 Palantir Foundry Connector 2.0 for SAP Applications 附加组件 安装到相关的 SAP 系统上。

  6. 通过 Data Connection 下载 Agent 软件并进行安装。

  7. 在 Foundry 中设置 Source 以连接到 SAP 系统。Foundry 端的配置取决于哪种连接器与您的 SAP 系统环境相匹配：

    • SAP ERP：用于连接 SAP ECC、S/4HANA（本地部署和 Cloud Private Edition）以及其他 ERP Central Component 系统。
    • SAP SLT：用于通过 SAP Landscape Transformation (SLT) 复制服务器进行连接，包括实时流式同步。

    有关 SAP Business Warehouse (BW) 和现有集成的信息，请参阅 SAP（自定义源）.
