SAP

Foundry integrates with SAP through an add-on installed in your SAP system. The current SAP-endorsed architecture ↗ recommends connecting Foundry to this add-on through SAP Data Accelerator.

Connecting Foundry to SAP through SAP Data Accelerator consists of three steps:

  1. Install an Advanced Business Application Programming (ABAP) add-on on the SAP side.
  2. Configure SAP Data Accelerator.
  3. Configure a source using a Foundry worker that matches your SAP landscape:
    • SAP ERP: SAP ECC, S/4HANA (on-premise and Cloud Private Edition), and other ERP Central Component systems.
    • SAP SLT: Connections through an SAP Landscape Transformation (SLT) Replication Server, including real-time streaming syncs.

For SAP Business Warehouse (BW) and existing integrations, see SAP (Custom source).

The rest of this page describes the Connector add-on and walks through the high-level end-to-end setup flow.

The Palantir Foundry Connector 2.0 for SAP Applications ("Connector") is an ABAP add-on developed in partnership with Diskover Limited ↗. Learn about its SAP integration certification and validity period.

The Connector securely captures data and metadata from SAP systems (S/4HANA, ECC, Business Warehouse, SLT Replication Server) and integrates them into the Foundry platform. The Connector is installed on the SAP application layer, adheres to standard SAP security policies, and uses native SAP application logic for data access.

  • Connector installation: The Connector is an ABAP add-on installed using SAINT (SAP Add-On Installation Tool).

  • Connector exposes access over HTTPS: The Connector runs a web service via SICF. This allows the Foundry Data Connector to request underlying ERP or BW data over HTTPS.

  • Data transfer logic defined in Foundry: The tables, objects, filters and schedules of the data transfers are defined in Foundry and executed by the Foundry Data Connection Coordinator.

  • Application layer access: Palantir Foundry will send the request to the SAP ABAP platform (formerly known as the SAP NetWeaver Application Server) independent of which database is running under SAP. There is no direct database access. All information access is from the application layer.

  • SAP standard security: Foundry will call the Connector with an SAP user secured and authorized within SAP. Therefore, all SAP standard security procedures and policies apply. There is no additional maintenance of dataflow security.

  • SAP application logic access: Tables, functions, BW InfoProviders and BEx queries are all available objects for data extraction to Foundry.

  • System load and scalability: The Connector checks data load on the system before starting extraction. If certain criteria are not met, extraction is aborted. The Connector is fully aligned with SAP scalability. The Connector may co-exist within the same application server or, optionally, run in a separate application server reserved for data processing.

Setup guide

Prerequisites

  • SAP_BASIS 7.4 SP5 or above (the technical component version, applicable to both SAP NetWeaver and SAP S/4HANA systems)
  • SAP_BASIS 7.5 (no minimum SP level)

These are minimum versions. The Connector supports all higher SAP_BASIS versions, including SAP S/4HANA releases based on SAP_BASIS 8.x (for example, SAP_BASIS 816).

If you plan to use SLT via OData, the OData component (PALODATA) requires SAP_BASIS 7.50 SP09 or above.

If your primary SAP system is running an SAP_BASIS version lower than 7.4 SP5, see Remote Agent installation for details of how to set up a remote connection.

Getting started

We recommend connecting to SAP Data Accelerator using a Foundry worker with direct connection egress policies. Follow these steps when your SAP Data Accelerator hub is accessible from Foundry over the Internet:

  1. Work with your SAP Basis team to choose the appropriate add-on installation pattern for your SAP landscape.

  2. Download the Connector add-on installation packages from Foundry.

  3. Ask your SAP Basis team to install the Palantir Foundry Connector 2.0 for SAP Applications add-on on the relevant SAP systems.

  4. Request a Palantir-issued client certificate from Palantir Support.

  5. Complete the SAP Data Accelerator setup, including registering Foundry as a partner system and configuring SAP Cloud Connector.

  6. Create a source in Data Connection using a Foundry worker. Choose the connector that matches your SAP landscape:

    • SAP ERP: For connecting to SAP ECC, S/4HANA (on-premise and Cloud Private Edition), and other ERP Central Component systems.
    • SAP SLT: For connecting through an SAP Landscape Transformation (SLT) Replication Server, including real-time streaming syncs.

    For SAP Business Warehouse (BW) and existing integrations, see SAP (Custom source).

  7. Follow the SAP Data Accelerator source configuration guide to assign certificates, configure the Cloud Connector virtual host and port, and enable SAP Data Accelerator. Assign direct connection egress policies that allow HTTPS access to both the SAP Data Accelerator control plane and data plane.

Your backend SAP system can remain on a private network behind SAP Cloud Connector.

Connections without SAP Data Accelerator

This section describes the legacy connectivity model and is provided for reference only. Use SAP Data Accelerator for the SAP-endorsed integration architecture.

If you are not using SAP Data Accelerator, use a Data Connection agent to connect Foundry to your SAP system. Work with your SAP Basis team to choose the appropriate add-on installation pattern, then download and install the Connector add-on. Complete the following steps:

  1. Create an agent host within your organizational network.
  2. Configure network access from the agent host to Foundry and to your SAP system's HTTPS port. The SAP port is the default HTTPS port for ICM (Internet Communication Manager), a component of the SAP ABAP platform. Find the port number by running the SMICM transaction code in the SAP system.
  3. Download and install the agent through Data Connection.
  4. Create a secure tunnel cluster and deploy an initiator using the agent.
  5. Set up your SAP source using a Foundry worker. Assign secure tunnel policies for your SAP host and port using the cluster.
