准备时间序列对象类型支撑数据集

在创建新的时间序列对象类型之前，您必须首先拥有一个时间序列对象类型支撑数据集。以下说明描述了如何在 Pipeline Builder 中创建时间序列对象类型支撑数据集。

  1. 首先，专注于创建一个数据集，其中每一行代表新对象类型的单个对象。此数据集需要一个可用于唯一标识对象的主键列，以及每个非时间序列 属性 在对象上的列。
  2. 接下来，通过添加一个 序列 ID 来使此对象类型支撑数据集支持时间序列，每个 一个。您可能会在 Pipeline Builder 中通过以下转换之一添加此内容，具体取决于您的数据形状：
  • 不同测量/传感器类型的时间序列数据存储在不同的数据集中，您希望手动创建新的序列 ID 列。
  • 您有一个包含所有测量值的单一数据集和/或大量序列。
  • 对于单个测量/传感器类型，您有多个数据集。

单一数据集或大量序列

通过连接创建一个将每个序列名称作为列名的数据集，从而避免手动创建每个新的序列 ID 列。拥有此单一数据集后，请按照以下说明操作：

  1. 添加一个 Unpivot 转换。

    1. 在您的终端会话中将 输出逆透视列名称 as series_name.
    2. 在您的终端会话中将 逆透视值输出列名称 as series_value.
    3. 在监听器设置向导的 要逆透视的列 字段中，选择所有具有序列名称的列。

用于单个测量类型的多个数据集

您的对象类型必须处于 对象存储 v2 中，才能通过多个时间序列同步来支撑时间序列属性。

由于传感器数据通常由多个数据源提供支持，在一个数据集中对所有传感器数据进行规范化和转换可能颇具挑战性。有时这是无法做到的，因为某些传感器保存的是分类数据，而另一些则包含数值数据；不同的数据类型无法存在于同一个 时间序列同步中。为了避免将所有传感器数据转换并统一到一个时间序列数据集中，您可以将一个 一个 关联到多个时间序列同步。为此，您必须在 来选择多个时间序列同步。如果您的 TSP 由多个时间序列同步提供支持，您将需要使用 的对象类型支撑数据集上拥有一列。按照以下步骤创建限定序列 ID。您需要先 创建时间序列同步 ，然后再执行这些步骤。

  1. 通过在 Pipeline Builder 中选择 添加数据 ，将支撑您的每个时间序列同步（这些同步支撑您的时间序列属性）的支撑数据添加到您的管道中。

  2. 对于每个时间序列同步数据集，仅选择序列 ID 列，并对生成的单列数据集进行去重。

  3. 添加一个 Create time series reference values 转换。使用序列 ID 列作为 序列标识符 ，并选择相应的时间序列同步作为 时间序列同步 RID。将新列命名为 qualified_time_series_id 或类似名称。



  4. 连接 将限定序列 ID 列关联回您的对象类型支撑数据集。此步骤要求您的对象类型支撑数据集中的序列 ID 是唯一的。

创建新的时间序列对象类型

准备好时间序列对象类型支撑数据集后，按照设置助手中的路径 创建新的对象类型。此路径会将您重定向到 本体论管理器对象创建设置助手 ，您将在其中选择新数据集作为您的支撑数据源。完成助手对话框后，您就可以 设置时间序列属性.

如果您直接从本体论管理器主页（而不是从时间序列设置助手）启动对象创建设置助手，该助手在完成后将不会重定向到新对象类型的 功能 选项卡。
