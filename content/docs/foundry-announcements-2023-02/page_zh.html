地图图层编辑器 | 从数据集中获取 GeoJSON

地图图层编辑器 允许用户创建、编辑和预览地图图层，这些图层可在 Map 应用中使用。

通过此次更新，在地图图层编辑器中创建矢量图层时，您现在可以选择存储在数据集中的 GeoJSON 文件作为数据源。GeoJSON 是最常见的地理空间数据格式之一，因此数据集中经常会出现由数据连接或管道转换生成的 GeoJSON 文件。使用地图图层编辑器从您的 GeoJSON 文件快速创建图层，并可视化您的地理空间数据！

外部转换：通过代码连接

发布日期：2023-02-23

使用 Python 直接与外部 API 交互

Palantir Foundry 现已原生支持通过 Python 代码执行外部转换，以便与第三方提供商进行 API 通信。您无需再使用数据连接 REST 适配器构建调用以获取数据，而是可以直接与外部 API 交互，并在可用的情况下使用内置 SDK。在 代码仓库中启用外部系统设置后，您可以：

  • 将外部数据作为常规数据集引入 Foundry，并受益于代码仓库的原生功能。
  • 使用封装了附加逻辑的任意库和 SDK，以便于向端点发起复杂查询。
  • 直接在您的代码仓库中存储、定义并应用每次 API 调用所使用的凭据。

利用 SDK 集成数据

外部转换使您能够直接利用第三方提供商的 SDK 来连接外部系统并与之交互。这一功能使得从代码仓库发起 API 调用如同在本地开发环境中进行一样顺畅，为您节省时间和精力。例如，您现在无需再编写逻辑来确定要连接到哪些记录、如何从特定格式中获取数据，或根据 API 确定数据摄取的频率。您还可以在 Python 环境中使用封装了附加逻辑的任意库（可从代码仓库中的库标签页导入）。

一次配置、无需再管的连接和凭据

借助外部转换，您可以将外部连接所需的相关信息保留在触手可及之处，并置于您所编写代码的上下文中。利用最初在控制面板中配置的现有连接，并直接通过代码仓库中的外部系统标签页存储 API 访问凭据。

在代码编辑器中编写外部转换逻辑

设置很简单。只需导入编写转换和调用外部系统所需的库即可。此处展示的示例演示了如何使用外部转换进行 API 调用。该调用的 API 响应将写入在指定位置创建的 Foundry 数据集，并已准备好在代码仓库中进行转换，或作为您 Foundry 工作流的一部分。

我应该在什么时候使用外部转换？

外部转换让您能够像在 Foundry 中进行常规数据转换那样，充分利用代码仓库中的开发者工具，包括分支、检查与 CI、调试以及发布管理。

使用外部转换，可以将外部数据作为常规数据集引入 Foundry、使用任意库，并充分利用原生 SDK。

有关如何启用和编写外部转换的更多信息，请查阅 外部系统调用文档。

Quiver：使用 Vega 图表进行自定义可视化

发布日期：2023-02-14

在 Quiver 中创建自定义数据可视化

Quiver 现已提供一组丰富的可视化选项，可用于数据展示，支持 Vega 或 Vega-lite 图表。Vega 是一种可视化语法，可提供一系列额外选项，用于基于本体论以及在 Quiver 支持的其他数据源中查看您的数据。

除现有的 时间序列图表 和 对象图表，您现在可以创建自定义可视化图表，例如箱线图、旭日图、雷达图等。Vega 图表还可以轻松嵌入到其他应用程序中，例如 Workshop，可在其中添加 Quiver 仪表板。

使用转换表创建 Vega 或 Vega-lite 图表

在 Quiver 中，可以通过主图表工具栏或作为转换表的后续操作来创建 Vega 图表。转换表是 Quiver 中 Vega 图表的主要输入，使用转换表可确保数据以一致且标准化的格式加载到前端，而无需考虑数据的原始来源。转换表也是数据预处理的实用工具，例如派生新列、取并集、联接或分组。提醒一下，目前可以从对象集、数据透视表、条形图和数组创建转换表。

在 Vega 绘图中使用转换表的全局标识符来引用它们，例如 $A。要引用转换表中的特定列，请使用 $A.column_name 表示法进行引用。大多数 Vega 规范首先会将转换表引用传递到 data 部分的 values 键中。在适用的情况下，也可以使用 $ 表示法将数组和标量值传递到 Vega 绘图中。

有许多预设的 Vega 模板规范可供选择，用于预填充 JSON 规范。只需将引用的全局标识符替换为所需转换表的标识符即可。

什么时候应该使用 Vega 或 Vega-lite 绘图？

使用 Vega 和 Vega-lite 绘图来可视化本体论中的数据，并在支持 Quiver 仪表板的任何 Palantir Foundry 应用程序中进行展示。

在 Quiver 中，您可以使用内置设计模板（例如气泡图、箱线图、瀑布图、旭日图以及其他多种类型的绘图）快速入门，也可以自行创作。若要以更简洁的方式创作常见的可视化效果，可以考虑使用 Vega-Lite 库。

请查阅 Vega 绘图文档 （位于 Quiver 集合中）以了解更多信息。如需设计灵感和更高级的使用案例，请查看 Vega ↗ 和 Vega-lite ↗ 各自的文档，以了解各种可视化设计。

发布日期：2023-02-06

请注意，这是一项 beta 功能的公告，因此该应用程序或功能可能并非在所有 Foundry 租户中均可用。

项目中充斥着您的用例所使用的对象类型和操作类型？当输入和输出数据集分散在各个项目中时难以找到？或者只是想清理和整理用例中的资源？Use Case 应用提供了一个新框架，用于组织和整合项目中的关键资源和对象类型。
