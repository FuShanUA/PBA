Azure Cosmos DB

Azure Cosmos DB 连接器是一个 由 Palantir 提供的驱动程序 ，用于 Azure Cosmos DB。

要创建新的 Azure Cosmos DB 源，请按照 Palantir 提供的驱动程序的标准设置流程，然后使用以下部分进行 Azure Cosmos DB 特定的配置和网络设置。有关完整的属性参考，请参阅 官方 Azure Cosmos DB 驱动程序文档 ↗.

受支持的功能

功能状态
探索🟢 正式可用
批量同步🟢 正式可用
增量🟢 正式可用
OAuth 2.0 身份验证🟢 正式可用
表导出🟢 正式可用

配置

以下属性为必填项或推荐项。

属性是否必填？描述默认值
AccountEndpoint ↗必填该值应为 Cosmos DB 帐户“密钥”边栏选项卡中的 Cosmos DB 帐户 URL。https://<URL>
AuthScheme ↗必填连接到 Azure Cosmos DB 时使用的身份验证类型。AccountKey
AccountKey ↗推荐用于连接 Azure Cosmos DB REST API 的主密钥令牌或资源令牌。—
InitiateOAuth ↗推荐网络REFRESH
OAuthClientId ↗推荐指定创建自定义 OAuth 应用程序时分配的客户端 ID。（也称为消费者密钥。）此 ID 用于向 OAuth 授权服务器注册自定义应用程序。—
OAuthClientSecret ↗推荐指定创建自定义 OAuth 应用程序时分配的客户端密钥。（也称为消费者机密）。此密钥用于向 OAuth 授权服务器注册自定义应用程序。—
Schema ↗推荐指定要使用的 Azure Cosmos DB 数据库。—

网络

下表列出了源运行时必须能够访问的域。

为每个域名添加相应的 出口策略。如果该源托管在本地且无法从 Foundry 直接访问，请改用 代理出口策略 。代理主机本身也必须能够访问所列出的域。请参阅 使用代理作为代理服务器 了解详情。

域名必需
<AccountEndpoint>始终。AccountEndpoint 连接属性（格式可以为 https://<Server>:<Port>，也可以是完整 URL）
login.microsoftonline.comIf AuthScheme=AzureAD, AzureServicePrincipal、AzureServicePrincipalCert 以及 AzureEnvironment=GLOBAL (default)
login.chinacloudapi.cnIf AuthScheme=AzureAD, AzureServicePrincipal、AzureServicePrincipalCert 以及 AzureEnvironment=CHINA
login.microsoftonline.usIf AuthScheme=AzureAD, AzureServicePrincipal、AzureServicePrincipalCert 以及 AzureEnvironment=USGOVT 或 USGOVTDOD

OAuth 2.0 身份验证

此连接器支持 OAuth 2.0 身份验证。请按照 Palantir 提供的驱动程序的 OAuth 2.0 指南 来配置和授权连接。
