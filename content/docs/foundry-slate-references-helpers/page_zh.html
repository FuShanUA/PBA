Handlebar 辅助函数

辅助函数是可以在内部调用的预定义函数 Handlebars 模板中调用的函数。辅助函数具有名称、参数和返回值。例如，模板 {{add 5 var1}} 调用了 add 辅助函数，作用于一个整数 (5) 和一个名为 var1。如果 var1 的变量，其值为 7，则该模板的计算结果为 12。

辅助函数分为以下几类：

  • 内置辅助函数 - 来自 Handlebars 库
  • 核心辅助函数 - 可在查询和小组件中使用
  • 小组件辅助函数 - 仅可在小组件中使用
  • Foundry 辅助函数 - 仅可在 Foundry 查询中使用
  • SQL 辅助函数 - 仅可在 SQL 查询中使用

辅助函数不能在 函数 编辑器中使用。

toString

toString 辅助函数使用 JavaScript String() ↗。

示例

  • 对 String 使用 toString
    • {{toString 'hello'}} 渲染为 "hello"
  • 对 Number 使用 toString
    • {{toString 1}} 渲染为 "1"
  • 对 String 数组使用 toString
    • {{toString variable}} 其中上下文为 { variable: ["hello", "world"] } 渲染为 "hello,world"
  • 对 Number 数组使用 toString
    • {{toString variable}} 其中上下文为 { variable: [1, 2, 3] } 渲染为 "1,2,3"
  • 对 Object 使用 toString
    • {{toString variable}} 其中上下文为 { variable: {"hello": "world"} } 渲染为 "[Object Object]"

toNumber

toNumber 辅助函数使用 JavaScript Number() ↗函数将给定值转换为数字。如果该值无法转换为数字，将返回 NaN。

示例

  • 对 Number 使用 toNumber
    • {{toNumber 1}} 渲染为 1
  • 对表示数字的 String 使用 toNumber
    • {{toNumber '2'}} 渲染为 2
  • 对不表示数字的 String 使用 toNumber
    • {{toNumber 'hello'}} 渲染为 NaN
  • 在数组上使用 toNumber
    • {{toNumber variable}} 其中上下文为 { variable: [1, 2, 3] } 渲染为 NaN
  • 在对象上使用 toNumber
    • {{toNumber variable}} 其中上下文为 { variable: {"hello": "world"} } 渲染为 NaN

concat

concat 辅助函数接受任意数量的参数，并首先使用 JavaScript 的 String() 函数将每个参数转换为字符串，然后将它们连接在一起。

示例

  • 在两个数字上使用 concat
    • {{concat 1 2}} 渲染为 "12"
  • 在两个字符串和一个数字上使用 concat
    • {{concat 'hello' 'world' 2}} 渲染为 "helloworld2"
  • 在两个字符串数组上使用 concat
    • {{concat array1 array2}} 其中上下文为 { array1: ["hello", "world"], array2: ["again", "and again"] } 渲染为 "helloworldagainand again"
  • 在三个数字和一个对象上使用 concat
    • {{concat 1 2 3 variable}} 其中上下文为 { variable: {"hello": "world"} } 渲染为 "123[Object Object]"

substring

substring 辅助函数接受一个输入字符串（value）以及一个开始位置和一个结束位置（可选），然后将其传递给 JavaScript 的 substring() 函数。这使您能够获取输入字符串的子字符串。

示例

  • 在字符串上使用 substring
    • {{substring 'foo' 0 1}} 渲染为 "f"
  • 如果您使用的输入字符串比结束位置短，它将返回该输入字符串
    • {{substring 'foo' 0 6}} 渲染为 "foo"
  • 如果您不提供结束索引
    • {{substring 'foo' 1}} 渲染为 "oo"

是否包含

contains 辅助函数接受一个数组或字符串（value）以及一个要搜索的值（searchValue），如果该值存在于数组中则返回 true，否则返回 false。它通过调用 value.indexOf(searchvalue) !== -1.

示例

  • 在数组上使用 contains
    • {{contains variable 3}} 其中上下文为 { variable: [1, 2, 3] } 渲染为 true
  • 在字符串上使用 contains
    • {{contains variable "hello"}} 其中上下文为 { variable: "hello world" } 渲染为 true

jsonParse

jsonParse 辅助函数接受一个 JSON 字符串作为输入，并使用 JavaScript 的 JSON.parse ↗ 。

示例

  • 在 JSON 字符串化的字符串上使用 jsonParse
    • {{jsonParse '\"foo\"'}} 渲染为 "foo"
  • 在 JSON 字符串化的数组上使用 jsonParse
    • {{jsonParse varA}} 其中上下文为 "[\"hello\",\"world\"]" 渲染为 ["hello", "world"]
  • 在 JSON 字符串化的对象上使用 jsonParse
    • {{jsonParse varA}} 其中上下文为 "{\"varA\":{\"hello\":\"world\",\"foo\":[\"bar\",\"baz\"]}}" 渲染为 { varA: {"hello": "world", "foo": ["bar", "baz"]} }
  • 在数字上使用 jsonParse
    • {{jsonParse 123}} 在控制台中抛出错误，提示 "jsonParse: Error: value must be a string"
  • 在无效的 JSON 字符串上使用 jsonParse
    • {{jsonParse varA}} 其中上下文为 "[\"hello\"," 在控制台中抛出错误，提示 "jsonParse: SyntaxError: Unable to parse JSON string"

jsonStringify

jsonStringify 辅助函数接受任意对象作为输入，并返回该对象转换后的 JSON（通过传递给 JavaScript 的 JSON.stringify ↗ 函数）。

示例

  • 在字符串上使用 jsonStringify
    • {{jsonStringify 'foo'}} 渲染为 "foo" （双引号包含在渲染的文本中）
  • 在对象上使用 jsonStringify {{jsonStringify varA}} 其中上下文为 { varA: {"hello": "world", "foo": ["bar", "baz"]} } 渲染为 {"hello":"world","foo":["bar","baz"]} （同样，双引号包含在渲染的文本中）

eq

eq 辅助函数比较两个数字或字符串，检查它们是否相等

  Your name is Steven.
{{else}}
  Your name is not Steven.
{{/if}}

    其中上下文为 { name: "Steven" } 渲染为 "Your name is Steven."

别名

alias 辅助函数接受一个别名列名或表名。column 和 table 辅助函数会根据信息架构校验值。但是，临时列名或表名不在架构中。alias 辅助函数为用户提供了一种注册临时列名或表名的方式。当名称不是常量值时会抛出错误。

示例

  • 使用 alias 注册别名列名

    "SELECT id as {{alias 'alias_column_name'}} FROM table1 ORDER BY {{column aliasColumnName}};"

    其中上下文为 { aliasColumnName: "alias_column_name" } 渲染为

    "SELECT id as alias_column_name FROM table1 ORDER BY alias_column_name;"

  • 使用 alias 注册区分大小写的别名列名

    "SELECT id as "{{alias 'Alias Column Name'}}" FROM table1 ORDER BY "{{column aliasColumnName}}";"

    其中上下文为 { aliasColumnName: "Alias Column Name" } 渲染为

    "SELECT id as "Alias Column Name" FROM table1 ORDER BY "Alias Column Name";"

  • 使用 alias 注册别名表名

    "SELECT id as "{{alias 'Alias Column Name'}}" FROM table1 ORDER BY "{{column aliasColumnName}}";"

    其中上下文为 { aliasColumnName: "Alias Column Name" } 渲染为

    "SELECT id as "Alias Column Name" FROM table1 ORDER BY "Alias Column Name";"

  • 对非常量值使用 alias：

    "SELECT id as {{alias aliasColumnName}} FROM table1 ORDER BY {{table aliasColumnName}};"

    其中上下文为 { aliasColumnName: "alias_column_name" } 抛出错误，提示 "Only constant parameters are not allowed..."

模式

schema 辅助函数接受一个架构名称和一个白名单名称列表。它会检查架构名称是否在白名单名称列表中，并根据数据源的信息表校验架构名称。当架构名称不存在于白名单名称列表或信息表中时会抛出错误。

示例

  • 使用 schema 处理有效的架构名称 
    "SELECT * FROM {{schema schemaName 'schema1' 'schema2'}}.table1;"
    其中上下文为 { schemaName: "schema1" } 渲染为 
    "SELECT * FROM schema1.table1;"
  • 使用 schema 处理不在白名单名称列表中的架构名称 
    "SELECT * FROM {{schema schemaName 'schema1' 'schema2'}}.table1;"
    其中上下文为 { schemaName: "schemaNameNotInList" } 渲染为 
    "SELECT FROM schemaNameNotInList.table1"
    执行时会抛出错误，提示 "schema name must be in the list of the whitelist names."
  • 使用 schema 处理在白名单名称列表中包含引用的架构名称 
    "SELECT * FROM {{schema schemaName 'schema1' 'schema2' templatizedName}}.table1;"
    其中上下文为 { schemaName: "schema1", templatizedName: "anotherSchemaName" } 渲染为 
    "SELECT * FROM schema1.table1;"
    执行时会抛出错误，提示 "References ['templatizedName'] cannot be dynamic for security reasons."
  • 使用 schema 处理无效的架构名称 
    "SELECT * FROM {{schema schemaName 'invalidSchema1'}}.table1;"
    其中上下文为 { schemaName: "invalidSchema1" } 渲染为 
    "SELECT * FROM invalidSchema1.table1;"
    执行时会抛出错误，提示 "Invalid schema name 'invalidSchema1.'"

table

table 辅助函数接受一个表名和一个白名单名称列表。它会检查表名是否在白名单名称列表中，并根据数据源的信息表校验表名。当表名不存在于白名单名称列表或信息表中时会抛出错误。

示例

  • 使用 table 处理有效的表名 
    "SELECT * FROM {{table tableName 'table1' 'table2'}};"
    其中上下文为 { tableName: "table1" } 渲染为 
    "SELECT * FROM table1;"
  • 使用 table 处理不在白名单名称列表中的表名 
    "SELECT * FROM {{table tableName 'table1' 'table2'}};"
    其中上下文为 { tableName: "tableNameNotInList" } 渲染为 
    "SELECT * FROM tableNameNotInList;"
    执行时会抛出错误，提示 "table name must be in the list of the whitelist names."
  • 使用带有表名的 table，且该表名在白名单名称列表中 
    "SELECT * FROM {{table tableName 'table1' 'table2' templatizedName}};"
    其中上下文为 { tableName: "table1", templatizedName: "anotherTableName" } 渲染为 
    "SELECT * FROM table1;"
    执行时会抛出错误，提示 "References ['templatizedName'] cannot be dynamic for security reasons."
  • 使用带有无效表名的 table 
    "SELECT * FROM {{table tableName 'invalidTable1'}};"
    其中上下文为 { tableName: "invalidTable1" } 渲染为 
    "SELECT * FROM invalidTable1;"
    执行时会抛出错误，提示 "Invalid table name 'invalidTable1'."

列

column 辅助函数接受一个列名或列名列表，并根据数据源的信息表对其进行检查。当信息表中不存在某个列名时，它会抛出错误。

示例

  • 使用带有有效列名的 column 
    "SELECT {{column columnName}} FROM table1;"
    其中上下文为 { columnName: "column1" } 渲染为 
    "SELECT column1 FROM table1;"
  • 使用带有有效区分大小写列名的 column 
    "SELECT "{{column columnName}}" FROM table1;"
    其中上下文为 { columnName: "Column 1" } 渲染为 "SELECT "Column 1" FROM table1;"
  • 使用带有有效列名列表的 column 
    "SELECT {{column columnNames}} FROM table1;"
    其中上下文为 { columnNames: ["column1", "column2"] } 渲染为 
    "SELECT column1, column2 FROM table1;"
  • 使用带有无效列名的 column 
    "SELECT {{column columnName}} FROM table1;"
    其中上下文为 { columnName: "invalidColumn1" } 渲染为 
    "SELECT invalidColumn1 FROM table1;"
    并会抛出错误，提示 "Invalid column name 'invalidColumn1'."

param

param 辅助函数接受一个参数或参数列表。在常规模式下，它将参数存储在列表中并返回一个问号。在预览模式下，它返回参数。注意：预览模式用于预览渲染后的查询以及进行调试。

示例

  • 在常规模式下使用带有数字的 param 
    "SELECT * FROM table1 WHERE id = {{param parameter1}};"
    其中上下文为 { parameter1: 1234 } 渲染为 
    "SELECT * FROM table1 WHERE id = ?;"
    以及参数列表 [1234]
  • 在常规模式下使用带有字符串列表的 param 
    "SELECT * FROM table1 WHERE text IN ({{param parameter1}});"
    其中上下文为 { parameter1: ["some", "text"] } 渲染为 
    "SELECT * FROM table1 WHERE text IN (?, ?);"
    以及参数列表 ["some", "text"]
  • 在常规模式下使用 toString 辅助函数处理数字的 param 
    "SELECT * FROM table1 WHERE text = {{param (toString parameter1)}};"
    其中上下文为 { parameter1: 1234 } 渲染为 
    "SELECT * FROM table1 WHERE text = ?;"
    以及参数列表 ["1234"]
  • 在常规模式下使用 toNumber 辅助函数处理字符串的 param 
    "SELECT * FROM table1 WHERE text = {{param (toNumber parameter1)}};"
    其中上下文为 { parameter1: "1234" } 渲染为 
    "SELECT * FROM table1 WHERE text = ?;"
    以及参数列表 [1234]
  • 在常规模式下使用 concat 辅助函数进行 LIKE 操作的 param 
    "SELECT * FROM table1 WHERE text LIKE {{param (concat '%' parameter1 '%')}};"
    其中上下文为 { parameter1: "some text" } 渲染为 
    "SELECT * FROM table1 WHERE text = ?;" with the list of parameters `["%some text%"]`
  • 在预览模式下使用带有数字的 param 
    "SELECT * FROM table1 WHERE id = {{param parameter1}};"
    其中上下文为 { parameter1: 1234 } 渲染为 
    "SELECT * FROM table1 WHERE id = 1234;"
  • 在预览模式下使用带有字符串列表的 param 
    "SELECT * FROM table1 WHERE text IN ({{param parameter1}});"
    其中上下文为 { parameter1: ["some", "text"] } 渲染为 
    "SELECT * FROM table1 WHERE text IN ('some', 'text');"
  • 使用带有未定义参数的 param 
    "SELECT * FROM table1 WHERE id = {{param parameter1}};"
    其中上下文为 { } 抛出错误，提示 "Error: parameter value cannot be null in param helper"
  • 使用包含 null 的数组的 param 
    "SELECT * FROM table1 WHERE text IN ({{param parameter1}});"
    其中上下文为 { parameter: ["some", null] } 抛出错误，提示 "Error: parameter array cannot have null value in param helper"。
