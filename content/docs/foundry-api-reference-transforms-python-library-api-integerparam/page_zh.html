transforms.api.IntegerParam

class transforms.api.IntegerParam(default, *, description=None)

用作转换输入的 ParameterSpec 定义的规范。

  • 参数：
    • default (int ↗) – 该参数的默认值。
    • description (str ↗ , 可选) – 该参数的描述。

input_results(_instance, **_kwargs)

生成从输入 RID 到 TransformsInputResult的映射。结果会被合并到一个 TransformJobResult中。

  • 参数： instance – 一个由 instance()生成的类型的对象。

static instance(context, json_value)

使用来自 JobSpec 参数的原始 JSON 值和特定上下文创建参数实例。

返回值会被注入到转换计算函数中。

  • 参数：
    • context (ParamContext) – 一个上下文对象，其中包含创建实例时可能需要的属性。
    • json_value (any) – 从 JobSpec 参数反序列化得到的任意原始值。

property json_value

返回此参数要放入 JobSpec 的 JSON 值。

如果返回值为 None，则该参数被视为未绑定。如果转换的任一参数未绑定，则该转换被视为未绑定。对于未绑定的转换，JobSpec 不会被发布。

static lightweight_instance(context, json_value)

从解析后的 JSON 值实例化输入类型。

property schema

返回此类型参数的 JSON schema。必须返回有效的 JSON schema。
