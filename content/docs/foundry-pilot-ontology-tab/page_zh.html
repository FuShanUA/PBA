本体论选项卡

本体论 选项卡在 Pilot 工作区中显示 本体论 实体的交互式图谱，这些实体由 Pilot 为您的应用程序创建或复用。使用此选项卡可以查看您的数据模型、检查实体详情以及预览种子数据。

本体论图谱

本体论图谱是一种交互式可视化，其中显示以下信息：

  • 对象类型节点： 表示应用程序中的核心实体，并显示其属性。
  • 操作类型节点： 表示每个对象类型可用的操作。
  • 关联类型边： 显示对象类型之间的关系。

您可以平移、缩放并选择节点以探索图谱。图谱使用自动层次布局来排列节点和边。

实体状态图例

本体论图谱包含一个状态图例，用于指示每个实体的状态：

  • 现有： 来自本体论且正由 Pilot 复用的实体，其中包含 Pilot 所做的任何修改。
  • 提议： Pilot 在当前会话中创建的实体。

您可以按实体状态筛选图谱，以聚焦于特定类别。

数据预览

选择一个对象类型节点以打开数据预览面板。数据预览面板包含以下详细信息：

  • 为该对象类型定义的属性
  • Pilot 生成的种子数据中的示例记录
  • 可用记录的数量

使用数据预览来验证生成的种子数据是否符合您的预期。如果数据看起来不正确，请在聊天面板中让 Pilot 重新生成或调整种子数据。

控制 Pilot 可以修改的内容

在基于现有本体论进行构建时，您可以控制允许 Pilot 修改哪些实体，以及它能否创建新实体。请在 本体论权限 对话框中管理这些权限，您可以从以下两个位置访问该对话框：

  • 在开始构建之前，请选择 本体论权限 ，该选项位于欢迎屏幕上提示输入框的下方。
  • 导航至 本体论 选项卡，然后选择 本体论权限 ，该选项位于图表的右上角。

默认权限

该 本体论权限 对话框会为对象类型和操作类型设置默认行为：

  • 允许 Pilot 创建新的对象/操作类型： 控制 Pilot 是否可以提出全新的实体。禁用后，Pilot 将仅使用已部署本体论中已有的实体进行构建。
  • 默认编辑权限： 应用于您未单独配置的实体的权限。请选择 允许修改 以允许 Pilot 扩展实体，或选择 不允许修改 以完全按照部署时的状态引用这些实体。

更新这些默认设置不会覆盖您已针对单个实体设置的权限。

单个实体权限

您可以决定 Pilot 是否可以对已部署本体论中的单个对象类型或操作类型进行编辑。请从每个实体节点上的下拉菜单中选择以下选项之一：

  • 允许修改： Pilot 可以添加和编辑属性（针对对象类型）或参数（针对操作类型）。这可能会给您的本体论 API 引入破坏性更改。
  • 不允许修改： Pilot 会完全按照实体部署时的状态对其进行引用，且无法更改其架构。

关联类型没有自己的权限控制；它们遵循所连接对象类型的权限。

将实体设置为 不允许修改 ，即可在希望 Pilot 基于该实体进行构建而不更改您的生产数据模型时使用。如果您之后请求的更改需要修改被锁定的实体，Pilot 将暂停并询问您希望如何继续。届时，您可以选择允许 Pilot 进行修改、在 Foundry 中自行进行更改，或者保持实体原样。

当 Pilot 不被允许创建新实体，且每个实体都设置为 不允许修改，本体论已完全锁定。Pilot 将完全围绕现有的已部署实体及其可用的数据和操作来设计应用程序。

通过聊天修改本体论

您可以通过在聊天面板中输入指令来修改本体论。Pilot 使用专门的本体论架构师智能体来处理本体论更改。常见修改包括以下内容：

  • 为对象类型添加新属性： Add a "due date" property to the Task object type
  • 创建新对象类型： Create a Category object type with a name and description
  • 添加关联： Link each Task to a Category
  • 更改属性类型： Change the priority property from a string to an enum with values High, Medium, and Low

Pilot 应用更改后，本体论图会更新以反映新的结构。随后，应用构建智能体会更新前端代码，以使用修改后的本体论。
