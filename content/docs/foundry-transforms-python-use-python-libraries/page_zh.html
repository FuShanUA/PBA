发现并使用 Python 库

Code Repositories 允许您导入并使用公共库以及 Foundry 生成的库。以下信息仅适用于 或 库。

发现 Python 库

要搜索 Python 库，请点击 Code Repository 环境左侧面板中的 package 标签页。使用搜索框搜索可用的库。

点击库名称以显示库详细信息以及 添加库选项，该操作会将推荐版本的库添加到您的分支。

添加库后，Code Assist 依赖项将被刷新，您将能够从库中可用的包导入模块。

添加例外依赖项

添加 Python 库有时需要将必要的 artifact 仓库添加到您的代码仓库，并在 Project 中引用。在这种情况下，将出现一个对话框，请求您确认此操作。

依赖项对话框将突出显示您无权访问的任何必需仓库。您需要拥有这些仓库的访问权限才能使用该库。

Code Repositories 将尝试为您的库查找可用的支撑仓库并自动使用它们。如果您需要特定的支撑仓库，可以直接在仓库的 Artifact 设置 页面预览同步的数据。

固定特定库版本

如果您需要特定版本，可以 固定 该版本，方法是点击设置按钮并从列表中选择所需版本。这使您可以设置用于运行转换和测试的不同版本。

固定库的特定版本后，它将被添加到您的 meta.yaml 文件中，但不会使用 Task Runner 安装。请验证检查是否成功通过，然后重启 Code Assist 以将更改应用到您的 meta.yaml 文件。之后您就可以开始在仓库中使用所选版本的库。

固定的版本可能会阻止重要的库更新

固定特定版本时请务必谨慎。固定版本可能会阻止您的代码获取重要更新。请始终确保审查并更新您的依赖项。

审查库更改

在仓库中添加和移除 Python 库的操作与其他代码更改的行为相同。您应该提交更改并将其合并到受保护的分支。在 pull request 中，库更改将显示为 meta.yaml 文件。

中的更改。有时，当您创建 pull request 时，您会在以下类型的文件上看到合并冲突： .lock。这种情况发生在您处理分支期间发生了更新时。在这种情况下，请接受双方的更改并继续您的 pull request。

Artifact 仓库设置

通常，在使用 Python 库时无需访问仓库设置。所需的 artifact 仓库将在您添加 Python 包时自动添加。您应避免直接在设置标签页中编辑引用的 Python 仓库列表。

使用共享库时，对相关仓库的引用会被添加到项目中。您可以通过仓库设置选项卡中的“Artifacts”部分查看引用的仓库列表。

如果您是手动添加共享库依赖项，而不是通过 artifacts 包搜索添加的，则需要通过 artifacts 设置将该库仓库添加到使用方仓库的支撑仓库中。不建议手动添加依赖项，因为包搜索会为您完成此操作。

Task Runner

Task Runner 仅在较新的仓库中可用。您可以通过显示隐藏文件并检查 templateConfig.json 文件。

  • 如果您的仓库具有 parentTemplateId 且其 transforms，请确保 parentTemplateVersion 为 8.220.0 或更高版本，并且 Python 子模板为 1.484.0 或更高版本。
  • 如果您的仓库具有 parentTemplateId 且其 python-library，请确保 parentTemplateVersion 为 1.497.0 或更高。

您可以 升级您的仓库 以启用此功能。

启用 Task Runner 后，从左侧面板的 ”面板中找到。 例如，要使用 选项卡添加包时，将不再创建新的 Code Assist 工作区，而是开始在当前环境之上安装所请求的包，同时返回底层进程的所有日志。

如果安装成功，锁定文件将随新环境一起更新。如果安装失败，Task Runner 底部面板中会显示错误消息，可用于进一步排查问题。

Task Runner 只会更新 run 环境，目前不支持安装仅用于测试的依赖项。

Python 包的 Conda 解析

Conda 是一个开源的、与语言无关的包和环境管理器，在代码仓库中用于解析包依赖项并将一组包安装到独立的环境中。有关更多信息，请查阅 官方 Conda 文档 ↗ 或 环境创建简介.

Conda 锁定文件

在代码仓库中运行检查时，我们会针对 meta.yaml 文件中列出的包列表解析 Conda 环境，并生成带有 .lock 扩展名的隐藏 Conda 锁定文件；这些锁定文件会保存 Conda 环境。这种预先解析的环境使您提交代码时后续检查的 Conda 解析速度更快。

在以下情况下，我们会重新解析 Conda 环境并写入新的锁定文件：

  • 中的包列表发生了更改 meta.yaml file.
  • 仓库已升级到较新的模板版本。
  • 在您的锁定文件中发现了被召回的包。
  • 隐藏的 Conda 锁定文件已被删除或编辑。

当我们重新解析环境并写入新的锁定文件时，初始提交哈希为 SUPERSEDED 后跟另一个重写锁定文件的提交哈希。当我们需要重新解析环境时，检查可能需要更长的运行时间。

在平台之外下载已发布的 Python 库

可以从 Palantir Foundry 中发布的库，在 Foundry 之外下载：

  1. 获取用户令牌。在 Foundry 中，导航到您的用户账户设置并选择 令牌中的分支提案。选择 创建令牌，为您的令牌输入名称和描述，然后选择 生成。复制您的令牌。
共享的令牌可能被用于冒充您的身份

请勿与其他应用程序或用户共享您的令牌；恶意行为者可能利用它来冒充您的身份。

  1. 找到 <identifier> 您的 Python 库的。导航到目标 Python 库的 Code Repository。浏览器 URL 现在应具有类似以下的形式： https://<stack-url>/workspace/data-integration/code/repos/<identifier>/contents/refs%2Fheads%2F<branch>。在 URL 中，找到 <identifier>，它看起来像 ri.stemma.main.repository.XXXXXXXX-XXXX-XXXX-XXXX-XXXXXXXXXXXX.
  2. 获取库的软件包索引。在本地机器上打开终端并运行以下命令： curl -H "Authorization: Bearer $TOKEN" https://$STACK_URL/artifacts/api/repositories/$IDENTIFIER/contents/release/conda/$PLATFORM/repodata.json where $TOKEN 是您的用户令牌， $STACK_URL 与上一步中的 <stack-url> 相同， $IDENTIFIER 是上一步中的 <identifier> ，而 $PLATFORM 是仓库平台（例如 noarch, linux-64）。上述命令的输出是库内容的索引（即它包含的软件包）。每个软件包的形式为 <name>-<version>-<build-string>.tar.bz2.
  3. 下载特定软件包。您可以在终端中运行以下命令，从 Python 库下载特定软件包： curl -H "Authorization: Bearer $TOKEN" https://$STACK_URL/artifacts/api/repositories/$IDENTIFIER/contents/release/conda/$PLATFORM/$PACKAGE where $PLATFORM 是软件包平台（例如 noarch, linux-64），并 $PACKAGE 的形式为 <name>-<version>-<build-string>.tar.bz2.

在 Task Runner 中运行任务

您可以通过手动指定命令，从 Task Runner 手动触发软件包安装。

例如，要安装 pandas，请选择 Task Runner 标签页，然后输入以下命令：

install --packageSpecs=pandas

Task Runner 还支持以下命令：

  • uninstall：从运行环境中卸载软件包。
    • 注意：此命令还会卸载任何依赖于指定软件包的软件包。此命令仅在较新的仓库中可用。如果您的仓库具有 parentTemplateId 且其 transforms，请确保 Python 子模板位于 1.525.0 或更高版本。同样，如果您的仓库具有 parentTemplateId 且其 python-library，请确保 parentTemplateVersion 为 1.525.0 或更高。
    • 用法： uninstall --packageSpecs=<eg.numpy> 用于 Conda 软件包。
  • formatCode：格式化仓库中的文件。使用 Black 来格式化代码，并使用 pyproject.toml 进行自定义格式化程序配置。参见 该 Black 格式化程序配置文件文档 ↗ 的文档以获取更多信息。
  • whoneeds：显示当前运行环境中需要安装某个软件包的软件包树。
    • 注意：此命令仅在较新的仓库中可用。如果您的仓库具有 parentTemplateId 且其 transforms，请确保 Python 子模板位于 1.522.0 或更高版本。同样，如果您的仓库具有 parentTemplateId 且其 python-library，请确保 parentTemplateVersion 为 1.522.0 或更高。
    • 用法： whoneeds --packageSpec=<eg.transforms>
  • tasks：列出所有可运行的任务。
