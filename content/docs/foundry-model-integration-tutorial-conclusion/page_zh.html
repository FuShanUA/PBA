后续步骤

下一步是将此示例工作流转换为贵组织中的真实工作流。

这通常包括：

  1. 将来自各种数据源的数据集成到 Foundry 中，以创建一个 features_and_labels 可用于训练和测试不同模型的数据集。
  2. 尝试不同的模型架构、参数和特征，以获得模型的最佳性能。
  3. 通过批处理部署、实时部署或 Python 转换，将您模型的预测结果集成到 Foundry 本体论中，以便在运营应用中使用。
  4. 创建发布前检查 在您的建模目标中，以确保模型在发布前获得批准。
  5. 创建“回写”操作 以将用户操作捕获为新数据集，并使用这些数据对模型进行持续再训练和改进。
  6. 创建模型推理历史记录 以改进和迭代您的模型，从而获得更准确的性能和使用效果。
