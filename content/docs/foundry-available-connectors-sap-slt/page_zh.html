SAP SLT

SAP SLT 连接器允许您通过 SAP Landscape Transformation (SLT) 复制服务器将 Foundry 连接到 SAP 系统。基于数据库触发器，数据会从源 SAP ERP 系统复制到 SLT 系统中相应的操作增量队列 (ODQ)。SAP SLT 连接器使 Foundry 能够与以下内容交互：

  • 从源 ERP 系统复制的 SLT 复制服务器表
  • SLT 复制服务器系统中的本地表

使用 SAP SLT 源需要安装 Palantir Foundry Connector 2.0 for SAP Applications 附加组件 （安装在 SAP SLT 复制服务器上）。如需了解更多信息，请参阅 通过 SLT 进行连接。

设置

  1. 打开 数据连接 应用程序，然后选择 + 新建源 （位于屏幕右上角）。
  2. 选择 SAP SLT （从可用的连接器类型中选择）。
  3. 请按照后续的配置提示进行操作，并参考以下各节中的信息，继续完成连接器的设置。该源配置为在 Foundry worker上运行。对于现有的 agent worker 源，请参阅 agent worker 配置参考。

了解有关 设置连接器 （在 Foundry 中）的更多信息。

远程上下文

SAP SLT 连接器需要 远程上下文 值，该值是 SLT Replication Server 与源 ERP 系统之间 RFC 连接的唯一标识符。了解有关在 SLT 配置指南 中进行此配置的更多信息，并了解 SLT 连接。

网络和连接

您必须正确配置出站策略（如果使用 Foundry worker）或您的代理网络（如果使用 agent worker），以确保您的 SAP SLT 系统能够与 Foundry 通信。

Agent worker 的开发已进入 旧版 阶段。我们建议为新数据源使用 Foundry worker 连接。请参阅 Foundry worker 与 agent worker 的对比。

许多 SAP 系统使用自定义签名的证书，在首次配置连接时可能会导致 SSL 握手异常。请确保您拥有来自系统的正确自定义证书，并且 将其添加到源中 （如果使用 Foundry worker）或 直接添加到代理 （如果使用代理 worker）。

SAP Data Accelerator

要通过 SAP Data Accelerator （SAP 提供的托管连接服务，用于通过 SAP Cloud Connector 暴露的系统）访问此 SAP 系统，请将源的 host 和 port 设置为您的 Cloud Connector 虚拟主机和端口。然后，分配 Palantir 提供的客户端证书，允许出站流量访问 SAP Data Accelerator 控制平面和数据平面，并添加 SAP Data Accelerator 属性（填入您的控制平面 URL）。此路径需要使用 Foundry worker。

从 SAP SLT 同步数据

使用 探索视图 为 SAP SLT 表创建同步。在源概览页面中，选择 + New （位于批量同步旁），然后从下拉列表中选择所需的对象类型：

  • SLT 复制服务器： 源系统的数据通过 SLT 复制服务器进行复制，该过程使用源 ERP 系统上的数据库触发器。
  • 本地表： 数据直接从 SLT Replication Server 系统本身的表中读取。

流式同步

SAP SLT 连接器支持流式同步以进行实时数据复制。要创建流式同步，请选择 + 新建 旁边的按钮 流式同步 （位于源概览页面上）。

强制快照

“ 强制快照 ”开关控制数据流是否先读取整张表，再轮询增量更新。出现以下情况时，请启用此设置：

  • 源 ERP 系统上的数据库触发器已被重置或损坏。
  • SLT 复制服务器中的指针已丢失。

在整张表流式传输到 Foundry 后，请禁用此设置并保存，以便后续流式传输仅轮询更新。

API 版本

根据 SAP Note 3255746 ↗ （版本 11，2026 年 4 月），在本地部署和私有云环境中，均禁止非 SAP 应用程序通过 RFC（ODP-RFC）使用 ODP 数据复制 API。2026 年 6 月发布的 SAP 安全补丁在技术上会阻止未经授权的 ODP-RFC 调用。请在应用该补丁之前，将仍在使用旧版 ODP API 的同步迁移到 OData API。

附加组件版本为 2.34（SP34）或更高时，SAP SLT 同步可以使用 OData API。这基于 通过 OData 进行基于 ODP 的数据提取 ↗，这是 SAP 推荐的方式。SAP 不再允许使用旧版 ODP API。

使用 OData API 需要满足以下条件：

  • 需要 PALODATA 将附加组件 安装在 SLT 系统上。
  • SAP_BASIS 版本 7.50 SP09 或更高版本。详细了解 前提条件和配置。
API描述
OData每个表仅允许一个活动订阅。如果某个表已存在同步，则针对同一表的任何新同步都将失败，除非先释放现有的订阅。不包括远程上下文或并行分页。
ODP（旧版）允许每个表有多个订阅，使不同的同步能够独立摄取同一个表。包括远程上下文和并行分页。SAP 已不再允许此方式。

重置队列注册

使用 OData API 时，为表配置的第一个同步会占用活动订阅。如果您需要将该同步替换为其他配置，请启用 重置队列注册 以释放现有订阅并将其分配给当前同步。

启用重置队列注册后，每次运行同步都会触发数据集的全量重新加载。在重新分配订阅后，请禁用此设置，以避免重复进行全量重新加载。
