安装远程代理

访问较旧版本（低于 SAP_BASIS 7.4 SP5）的 SAP 系统

远程代理旨在通过主要的 Palantir Foundry Connector 2.0 for SAP Applications（"Connector"）访问远程 SAP 系统。如果 SAP_BASIS（技术组件版本，适用于 SAP NetWeaver 和 SAP S/4HANA 系统）版本低于 7.4 SP05，或者您希望将环境中的两个或更多 SAP 系统视为单个 Foundry Source，则应安装远程代理。远程代理的最低 SAP_BASIS 版本为 7.00 SP32。有关 SAP_BASIS 7.00 的较低产品版本或支持包，请参阅 为 ERP 4.6C/4.7 (620/640) 安装远程代理.

要安装远程代理，请在远程 SAP 系统中执行以下步骤：

  1. 下载安装包.
  2. 登录 SAP 系统客户端 000 使用具有授权的用户 SAINT.
  3. 运行 SAINT transaction.
  4. 导入 FOUNDRY-SAPCONN-INST-SP00SPXX.SAR 到 SAP 服务器：选择 安装包 > 加载包 > 从前端.

对于某些 SAINT/SPAM 版本，SPAM 或 SAINT 设置可能会影响安装过程。取消勾选 "无法进行签名检查，未实施 SAP 说明 2520826" 项，位于 "导入期间的检查" 部分下。在某些 SPAM 版本中，此复选框完全没有描述——您仍应取消勾选此框。

  1. 选择 开始时间 以进行安装。
  2. 可用包会被列出。如果未列出，请选择筛选器图标以停用筛选器。
  3. 继续下一步。
  4. 对于 Connector 安装，请选择 PALANTIR and PALAGENT.
  5. 选择 继续 以进入支持包选择。
  6. 从列表中选择最高可用的支持包，并确保两个组件选择了相同的 SP 级别。
  7. 确认安装队列并点击 继续.
  8. 选择 在对话模式下继续 用于准备阶段， 立即在后台继续 用于其他阶段，并开始安装。在大多数情况下，安装期间标记的警告对于 Connector 和远程代理安装可以忽略，包括标题为 "打开数据提取请求"的警告。对于任何其他警告，请按照警告消息中描述的步骤操作。
  9. 选择 完成 以完成安装
  10. 运行 PFCG 事务代码，并为以下角色执行授权配置文件生成和用户比较：

    • /PALANTIR/CONTENT_RINFOPRV_ALL
    • /PALANTIR/CONTENT_RTABLE_ALL
    • /PALANTIR/CONTENT_RTCODE_ALL
    • /PALANTIR/SERVICE_USER

配置

Connector 和 Connector 远程代理通过 SAP 远程函数调用 (RFC) 进行通信。因此，需要两个 RFC 连接：一个从 Connector 到远程代理，另一个从远程代理到 Connector。下一节详细介绍如何创建这些 RFC 连接。

RFC 配置

RFC 配置需要四个步骤：

  1. 创建到 SAP 系统的 RFC 连接。
  2. 创建从 Connector 到远程 SAP 系统的 RFC (SOURCE).
  3. 创建从远程 SAP 系统到 Connector 的 RFC (TARGET).
  4. 通过 Web 浏览器测试 Connector 远程代理。

创建到源/目标系统的 RFC 目标连接

在本节中，需要两个 RFC 连接：一个从 Connector 到远程代理，另一个从远程代理到 Connector。请按照 创建 RFC 连接 文档创建每个连接。您可以自由命名连接；例如， SAP_SOURCE 用于第一个， SAP_TARGET 用于第二个。

配置远程代理并注册 Connector

  1. 登录主 Connector 系统。
  2. 运行事务 /n/PALANTIR/PARAM_A1.
  3. 输入以下参数值：
    • Agent ID: AGENT 标识符（也称为 CONTEXT）
    • 是否为 4.7 或更旧版本： AGENT 版本标志
    • Agent Desc: AGENT 描述（供参考使用）
  4. 运行事务 /n/PALANTIR/PARAM_A2 并输入以下参数：
    • Agent ID: AGENT ID（如上一步所定义）
    • Param ID: PARAM ID（参数的分类）
    • Param Name: 参数名称（由 AGENT 使用）
    • Param Value: 参数值（由 AGENT 使用）
