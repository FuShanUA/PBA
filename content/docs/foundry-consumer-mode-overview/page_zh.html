消费者模式

消费者模式允许您配置 Foundry，使用户无需更广泛地访问 Foundry 平台即可访问特定应用程序。消费者模式对于构建企业对消费者 (B2C) 和企业对企业 (B2B) 应用程序特别有用，这类应用程序需要让外部用户在无需完整平台访问权限的情况下访问数据和工作流。

消费者模式并非单一的解决方案，而是一种配置 Foundry 的方式，使消费者用户、构建者和管理员只能访问与其角色相适应的功能和应用程序。

  • 消费者用户只能访问目标应用程序和必要的资源。
  • 消费者用户的 API 访问权限被限制为仅包含其特定需求。
  • 消费者用户绝不应看到 Foundry 登录页面，或者在已通过身份验证的情况下应被自动重定向。
  • 构建者可以利用 Marketplace 进行发布管理。
  • 构建者管理员可以强制确保消费者永远不会获得超出消费者角色的其他角色。

消费者应用解决方案

Foundry 支持四种面向消费者的应用配置：

平台内消费者应用程序

具有受限平台访问权限的 Workshop、Slate 或 Carbon 应用程序。

  • 推荐用途： 构建低代码自定义应用程序。使用低代码应用程序构建器快速迭代，构建完成后即可部署给客户，且维护负担极低。
  • 用户登录体验： 支持自动重定向到特定身份提供程序的登录流程，可避免出现多个登录界面。

OAuth 应用程序

一种托管在 Foundry 内的授权许可 OAuth 应用程序。

  • 推荐用途： 构建托管在 Foundry 中的专业代码应用程序，利用 Foundry 安全基元实现交互式自定义应用程序。
  • 用户登录体验： 登录流程使用 OAuth，并带有可配置的用户同意表单。
  • 托管方式： Foundry 子域名（例如， https://subdomain-for-app.your-foundry-domain.com/).

客户端凭证应用程序

一种使用客户端凭证流程在外部托管的 OAuth/OSDK 应用程序。

  • 推荐用途： 构建专业代码应用程序以实现最大用户规模，此类应用需要在 Foundry 之外实现客户自定义的用户身份验证和授权逻辑。
  • 用户登录体验： 应用程序构建者必须完全掌控登录体验。
  • 托管方式： 可通过 API 访问 Foundry 的外部托管环境。

公共应用程序

一种从 Foundry 子域名提供服务、无需任何最终用户身份验证的专业代码（pro-code）OSDK 应用程序。最终用户通过由 Foundry 管理的服务用户，与一组受限的、列入允许列表的本体论操作进行交互。

  • 推荐用途： 为目前没有、也不应需要 Foundry 账户的用户构建面向互联网的体验，例如数据收集表单、数据分发仪表板和注册流程。
  • 用户登录体验： 无需登录。任何访问该子域名的用户都可以使用该应用程序。
  • 托管： Foundry 子域名（例如， https://subdomain-for-app.your-foundry-domain.com/）。
  • 审批要求： 每个公共应用程序需要由您所在注册中的一名 信息安全官 进行用例审查和批准，之后才能启用。 了解有关公共应用程序的更多信息。

消费者模式注意事项

规模：确保您的解决方案满足您的需求

Palantir 平台管理的身份验证和授权支持以下指标：

  • 用户容量： 500,000+ 用户
  • 用户入驻： 每小时最多 5,000 名新用户
  • 组织限制： 默认情况下，每个注册包含五个组织

客户端凭据应用程序在 Foundry 之外管理身份验证和授权；仅 API 限制 适用。

无缝登录：防止不必要的身份验证

消费者模式支持无缝登录体验：

  • 每个域的默认 IDP： 自动重定向到已配置的身份提供程序。
  • Realm 参数支持： 直接链接到身份提供程序，使用 ?_realm=realmId 当为单个域配置了多个身份提供程序时。
  • 服务用户： 服务间身份验证使用客户端凭据进行 API 访问，无需每个用户单独登录。

安全：配置访问权限并防止平台暴露

消费者模式的安全性在多个层面上运作：

应用程序访问限制

  • 平台访问控制： 为消费方组织禁用更广泛的 Foundry 平台访问权限。
  • 特定于应用程序的访问权限： 仅授予对 Workshop、Slate 或 Carbon 应用程序的访问权限。

API 访问限制

  • 基于角色的权限： 强制实施应用程序功能所需的最小权限。
  • 服务用户权限： 对于客户端凭证，通过服务用户角色管理授权。

组织可见性控制

  • 用户和组隔离： 防止消费者发现组织内的其他用户或组。
  • 跨组织限制： 限制消费者组织和内部组织的用户与组之间的可见性和协作。
