Quiver

Quiver 提供了一个点击式界面，可对对象和 时间序列 数据进行分析，这些数据来自 本体论。您可以使用这些分析创建交互式 仪表板 ，让其他人能够在运营工作流中探索和调查数据。对于更简单的使用案例，Foundry 为 时间序列分析 和 对象集分析提供了简化的界面。请查阅我们关于 分析类型 的文档以进行比较。

主要功能

Quiver 使您能够：

  • 无需代码即可对对象和时间序列数据进行可视化、筛选和转换。

  • 使用 画布模式 构建分析，以组织和展示卡片，或使用 图形模式 检查卡片依赖关系和数据流。

  • 快速浏览关联对象类型之间的关系。

  • 对分析进行参数化，以便轻松切换不同的数据和结果视图。

  • 创建可嵌入诸如 Workshop 等运营应用程序中的交互式仪表板。

  • 创建可嵌入诸如 Notepad 等报告应用程序中的图表。

  • 直接保存分析并与同事分享。

  • 利用 Quiver 的 公式语言 执行更高级的计算。

  • 使用 转换表 和 数据集 执行更高级的转换和聚合。

何时使用 Quiver

Quiver 适合符合以下条件的分析使用案例：

  • 您的数据已映射到本体论中： 对象之间的关联在本体论中以原生方式表示，因此 Quiver 用户无需执行联接或识别主键或外键。通过在对象或对象集上执行 search around 来检索任何关联的对象，即可返回以关联形式表示的联接。
  • 您正在处理时间序列数据： Quiver 经过优化，可用于处理时间序列数据。Quiver 包含一个专用时间序列库，提供传感器和信号处理函数，并可由专有的时间序列数据库支撑，该数据库已针对高频信号上的特定操作进行了优化。请参阅 时间序列概述 以了解更多信息。
  • 您想要将分析结果嵌入到其他对象感知应用程序中： Quiver 仪表板可以嵌入到运营应用程序中，例如 Workshop。
  • 您想要将数据写回本体论： Quiver 可用于通过一项 操作将分析决策写回本体论。这使您能够立即捕获分析结论，供他人使用。
