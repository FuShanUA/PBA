Notepad

Notepad 是一款具备对象感知能力的协作式富文本编辑器。除了能够添加文本和图像等内容并进行格式化外，您还可以集成来自其他 Foundry 应用程序（例如 Contour、Quiver、Code Workbook 和 Object Explorer）的小组件（如图表）或对象。您还可以创建模板，用作生成新 Notepad 文档的蓝图。

功能

Notepad 的关键功能使您能够：

  • 嵌入图表、表格和图形 （来自其他 Foundry 应用程序）。
  • 导出和打印 所有 Notepad 文档，并可对导出呈现效果（嵌入外观、分页符等）进行精细化控制。
  • 维护结构化关联 指向嵌入的对象和资源，自动丰富底层的本体论。
  • 冻结内容 以捕获特定时间点的上下文。
  • 将文档模板化 以便基于新输入轻松创建报告版本。

用例

Notepad 支持以下工作流：

  • 临时笔记 （例如，在调查工作流中随嵌入内容一起记录笔记）。
  • 平台内文档编写 （例如，为管道、数据集或应用程序编写文档）。
  • 定期报告 （例如，使用模板生成月度状态报告）。
  • 模板化导出 （例如，根据所选对象按需创建文档模板的新副本）。

Notepad 不太适合以下用途：

  • 创建仪表板： Notepad 不支持基于用户输入或图表选择的动态筛选。如果您想创建一个仪表板来展示分析结果，可以考虑 Quiver 仪表板 用于对象或时间序列数据，或者， Contour 仪表板 用于表格数据。 Workshop 也可用于创建仪表板或更高级的运营应用程序。
  • 复杂的、基于页面的富文本编辑： Notepad 不具备典型桌面文本编辑器的可配置性。Notepad 旨在成为一个易于上手的文本编辑器，并针对与 Foundry 平台其余部分的集成进行了优化。
