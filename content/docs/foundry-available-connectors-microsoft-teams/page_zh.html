Microsoft Teams

Microsoft Teams 连接器是一个 由 Palantir 提供的驱动程序 ，用于 Microsoft Teams。

要创建新的 Microsoft Teams 源，请按照 Palantir 提供的驱动程序的标准设置流程，然后使用以下部分进行 Microsoft Teams 特定的配置和网络设置。完整的属性参考，请参阅 官方 Microsoft Teams 驱动程序文档 ↗.

简介

Microsoft Teams 连接器通过 Microsoft Graph API 读取您组织的 Teams。它将团队、频道、聊天、成员和消息以关系表的形式呈现，您可以在源资源管理器中浏览这些表。

对于计划读取，请使用 功能允许将外部系统的数据同步到Foundry 将 Teams 数据写入数据集。对于交互式读取或写入，请在代码中调用 Microsoft Graph 在代码中 从函数中调用。

身份验证和 Microsoft Graph 权限决定了连接器可以访问哪些 Teams 数据。请参阅 身份验证 以选择身份验证方法，并参阅 按功能划分的权限 了解每项操作所需的权限。

身份验证

Microsoft Teams 连接器通过 Microsoft Entra ID 向 Microsoft Graph 进行身份验证。使用 AuthScheme 选择身份验证方法：

AuthScheme身份验证方法使用场景：
AzureAD委派用户身份验证源访问应遵循已登录用户的权限，并且可以接受交互式授权。
AzureServicePrincipal使用客户端密钥的服务主体源访问不应限定于已登录用户。Microsoft Graph 权限可以提供租户范围的访问，或通过资源特定许可将访问限制为选定的团队。
AzureServicePrincipalCert使用证书的服务主体使用场景与 AzureServicePrincipal相同，但您的组织要求使用基于证书的凭据。

委派用户身份验证（AzureAD)

使用 AuthScheme=AzureAD 源以交互式用户身份登录，并以该用户身份读取 Graph。

  • 授予以下列出的委派 Microsoft Graph 权限 按功能划分的权限 的信息（适用于您的用例）。
  • 如果您的租户限制用户对这些范围的同意，则需要 全局管理员授予管理员同意 （首先为应用程序授予）。
  • 配置源时，添加 CallbackURL 属性。复制 Foundry 自动填充的 URL，并将其作为 Web 重定向 URI 添加到应用程序中。

配置源

在您的终端会话中将 AuthScheme=AzureAD, AzureTenant, OAuthClientId, OAuthClientSecret日 InitiateOAuth=REFRESH，然后添加自动填充的 CallbackURL 属性。选择 授权 并以您要读取其 Teams 数据的用户身份登录。Foundry 会完成交互式 OAuth 交换并自动刷新令牌。

服务主体身份验证（AzureServicePrincipal)

使用 AuthScheme=AzureServicePrincipal，源以应用程序而非已登录用户的身份进行身份验证。根据其被授予的权限，应用程序可以在整个租户范围内进行读取。

读取数据

要将 Microsoft Teams 数据读取到 Foundry 中，请在源资源管理器中选择一个表并 设置批量同步。使用委托身份验证时，同步会读取登录用户可访问的数据。使用服务主体身份验证时，访问权限取决于授予应用程序的权限，可以覆盖租户或选定的团队。请参阅 身份验证 以配置访问权限。

速率限制

Microsoft 对 GET /teams/{team-id}/channels/{channel-id}/messages 进行限流：每个应用程序每秒 200 个请求，每个应用程序每个租户每秒 20 个请求，每个频道每秒 1 个请求。请参阅 Microsoft Teams 服务限制 ↗.

import pandas as pd
import requests
from transforms.api import Output, transform
from transforms.external.systems import ResolvedSource, Source, external_systems

SOURCE_RID = "<source_rid>"
TENANT_ID = "<tenant_id>"
CLIENT_ID = "<client_id>"
TEAM_ID = "<team_id>"
CHANNEL_ID = "<channel_id>"
OUTPUT_RID = "<output_dataset_rid>"


@external_systems(teams=Source(SOURCE_RID))
@transform.using(output=Output(OUTPUT_RID))
def read_channel_messages(teams: ResolvedSource, output) -> None:
    session = requests.Session()
    proxy = teams.get_https_proxy_uri()
    if proxy:
        session.proxies.update({"http": proxy, "https": proxy})

    token_response = session.post(
        f"https://login.microsoftonline.com/{TENANT_ID}/oauth2/v2.0/token",
        data={
            "client_id": CLIENT_ID,
            "client_secret": teams.get_secret("OAuthClientSecret"),
            "scope": "https://graph.microsoft.com/.default",
            "grant_type": "client_credentials",
        },
        timeout=30,
    )
    token_response.raise_for_status()

    response = session.get(
        f"https://graph.microsoft.com/v1.0/teams/{TEAM_ID}/channels/{CHANNEL_ID}/messages",
        params={"$top": 20},
        headers={"Authorization": f"Bearer {token_response.json()['access_token']}"},
        timeout=30,
    )
    response.raise_for_status()

    rows = [
        {
            "id": message.get("id"),
            "created_date_time": message.get("createdDateTime"),
            "web_url": message.get("webUrl"),
        }
        for message in response.json().get("value", [])
    ]
    output.write_table(pd.DataFrame(rows))

import { ExternalSystems, Function } from "@foundry/functions-api";
import { MicrosoftTeamsSource } from "@foundry/external-systems/sources";

const TENANT_ID = "<tenant_id>";
const CLIENT_ID = "<client_id>";
const TEAM_ID = "<team_id>";
const CHANNEL_ID = "<channel_id>";

export class TeamsGraphFunctions {
    @ExternalSystems({ sources: [MicrosoftTeamsSource] })
    @Function()
    public async listChannelMessages(): Promise<string> {
        const tokenResponse = await MicrosoftTeamsSource.fetch(
            `https://login.microsoftonline.com/${TENANT_ID}/oauth2/v2.0/token`,
            {
                method: "POST",
                headers: { "Content-Type": "application/x-www-form-urlencoded" },
                body: new URLSearchParams({
                    client_id: CLIENT_ID,
                    client_secret: MicrosoftTeamsSource.getSecret("OAuthClientSecret"),
                    scope: "https://graph.microsoft.com/.default",
                    grant_type: "client_credentials",
                }).toString(),
            },
        );
        if (!tokenResponse.ok) throw new Error(`Microsoft token exchange returned ${tokenResponse.status}`);
        const token = await tokenResponse.json() as { access_token: string };

        const response = await MicrosoftTeamsSource.fetch(
            `https://graph.microsoft.com/v1.0/teams/${TEAM_ID}/channels/${encodeURIComponent(CHANNEL_ID)}/messages?$top=20`,
            { headers: { Authorization: `Bearer ${token.access_token}` } },
        );
        if (!response.ok) throw new Error(`Microsoft Graph returned ${response.status}`);

        const payload = await response.json() as {
            value?: Array<{ id?: string; createdDateTime?: string; webUrl?: string }>;
        };
        return JSON.stringify((payload.value ?? []).map((message) => ({
            id: message.id,
            createdDateTime: message.createdDateTime,
            webUrl: message.webUrl,
        })));
    }
}

import { getFetch, getSource } from "@palantir/functions-sources";

const SOURCE_RID = "<source_rid>";
const TEAM_ID = "<team_id>";
const CHANNEL_ID = "<channel_id>";

export const config = { sources: [SOURCE_RID] };

export default async function sendChannelMessage(text: string): Promise<string> {
    const source = await getSource({ rid: SOURCE_RID });
    const credentials = await source.sessionCredentials?.get();
    if (credentials?.type !== "oauth") throw new Error("Authorize the source first");
    const sourceFetch = await getFetch(source);

    const response = await sourceFetch(
        `https://graph.microsoft.com/v1.0/teams/${TEAM_ID}/channels/${encodeURIComponent(CHANNEL_ID)}/messages`,
        {
            method: "POST",
            headers: {
                Authorization: `Bearer ${credentials.accessToken}`,
                "Content-Type": "application/json",
            },
            body: JSON.stringify({ body: { content: text } }),
        },
    );
    if (!response.ok) throw new Error(`Microsoft Graph returned ${response.status}`);
    return ((await response.json()) as { id: string }).id;
}
