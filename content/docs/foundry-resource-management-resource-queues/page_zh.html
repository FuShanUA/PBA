注册详情

资源队列属于某个注册，而注册具有 vCPU 和 vGPU 限制，用于限制通过资源队列允许的 vCPU 和 vGPU 总量。换言之，注册中所有资源队列的 vCPU 限制之和必须小于或等于注册的 vCPU 限制；队列 vGPU 限制和注册 vGPU 限制也遵循相同的规则。

注册还有一个默认队列，除非另有指定，所有项目都会自动分配到该队列。此默认队列无法删除。

空间中的项目会自动分配到该空间的默认资源队列。除非另行配置，空间的默认资源队列与注册的默认资源队列相同。了解更多关于 组织与空间 以及它们与 组织与注册.

资源队列详情

资源队列是一种先进先出（FIFO）队列，用于限制可并发使用的计算资源数量。资源队列限制计算组中可用的服务级资源（如虚拟 CPU（vCPU）和虚拟 GPU（vGPU））的使用。

在项目中运行的工作负载会请求资源，这些请求随后会在资源队列中排队。当资源队列已满时，请求必须等待队列中再次出现可用空间。该队列是先进先出的；请求按其创建的顺序进行处理。

随后，工作负载会被发送到资源队列指定的计算组中运行，并在工作负载完成或终止后释放资源。

创建资源队列

要创建资源队列，请导航到资源管理（Resource Management）应用程序，选择 队列 （位于左侧），然后选择 新建.

资源队列类型

目前有两种资源队列类型：vCPU 资源队列和 vGPU 资源队列。大多数工作负载只需要 CPU，因此大多数项目由 vCPU 资源队列支撑。需要 GPU 的工作负载必须发送到 vGPU 资源队列，因此只能在由 vGPU 资源队列支撑的项目中运行。项目中工作负载所使用的 GPU 类型（例如 V100、T4）由该工作负载路由到的计算组决定。该计算组与支撑该项目的资源队列相关联。了解更多关于 计算组.

使用 GPU

如果要在项目中使用 GPU，必须创建 GPU 资源队列并将项目分配给该队列。例如，在运行用于训练机器学习模型的工作负载时，使用 GPU 可能会很有帮助。了解更多关于 模型集成。了解更多关于如何在 GPU 训练文档.
