为用例设置权限

用例权限仅管理以下内容的权限： 用例元数据.

元数据

用例元数据的权限通过以下方式进行管理： 角色 面板。在用例概览页面中，选择 ... 左侧边栏或概览页面右上角的选项，然后选择 管理权限.

你可以利用代码库升级拉取请求中的 角色 面板，以向用例添加或移除用户或组，并为他们分配 Use Case Owner or Use Case Editor 组织概览

用例所有者： 具有……的用户 Use Case Owner 权限既可以管理用例权限，也可以 编辑用例元数据.

用例编辑者： 具有……的用户 Use Case Editor 权限只能 编辑用例元数据.

默认情况下，用例元数据对组织中的所有人可见，即使用户无法查看或编辑用例资源。

“资源”

用例中包含的资源的权限由资源本身的权限或支撑该用例的 Project 权限管理。了解更多关于管理 项目 和 本体论资源 权限的信息。
