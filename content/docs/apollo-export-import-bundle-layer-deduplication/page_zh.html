Bundle 层去重（实验性）

Bundle 层去重是一项 实验性功能 ，并且可能会随时间推移而变化。它可用作优化工具，但存在发生故障的风险，可能导致导出或导入失败。如果遇到任何问题，应禁用该功能。这样做会导致 Bundle 变大。

Bundle 层去重是一项 Apollo Export 功能，可减少传输到特定目标位置的数据量。该功能的工作原理是跟踪已发送到某个目标位置的数据，并确保后续发送到该目标位置的 Bundle 不包含已传输过的数据。Bundle 层去重仅在一个 Bundle 中发送特定资源，从而减小 Bundle 大小。

前提条件

您必须拥有 Export 管道才能设置 Bundle 层去重。 了解有关创建 Export 管道的更多信息。

如何使用 Bundle 层去重

  1. 导航到 Export 应用程序并选择一个 Export 管道。在 目标 Hub 部分（在管道设置中，位于 传输设置 页面），添加您要将 Bundle 传输到的目标 Hub 以及每个 Hub 要使用的传输机制。然后，请确保 启用层去重 在 “高级设置” 开关下处于开启状态。

    要在共享相同 Target Hub 的多个管道之间启用层去重，请启用“请勿重新发送已由其他管道发送至同一 Target Hub 的层”选项。



  2. 导航到导出管道并 构建 Bundle。Bundle 构建完成后，请选择 “下载 Bundle” 并在下拉菜单中选择特定的 Target Hub，即可下载包含去重的 Bundle 以进行传输。您必须选择所需的 Target Hub，因为每个 Target Hub 的去重 Bundle 各不相同，而 “Any Hub” 选项不包含去重。如果您的管道使用了 “Bundle chunking”，您可以转到 “下载” 选项卡，下载所需 Target Hub 的所有分块。

    您仍然可以下载完整的 Any Hub Bundle（不含去重），但这样一来，未来的 Bundle 将无法受益于层去重带来的大小缩减。



  3. 导航到 Target Hub 中的导入应用程序，并上传您在上一步中下载的文件。

  4. 上传完成后，返回导出应用程序所在的 源 Hub 手动确认传输。只有这样，管道才能受益于 Bundle 层去重功能所提供的 Bundle 大小缩减。

    在上传完成且 Bundle 已存在于 Target Hub 上之前，请勿确认传输。 在 Target Hub 确认成功之前就确认传输成功，很可能会导致管道日后出现故障。

    如果 Bundle 未针对特定 Target Hub 下载、下载时间已超过七天，或属于未启用层去重的管道，则即使您确认手动传输，也不会应用层去重。



用于下载层去重 Bundle 的 Apollo CLI 命令

请参阅 Apollo CLI for Bundles 文档，详细了解如何通过终端下载和上传 Bundle。

要使用 apollo-cli 下载层去重 Bundle，您需要将标志 --transfer-target $TARGET_HUB 添加到下载 CLI 命令中，如下所示：

$ ./apollo-cli bundle download [bundle-rid] \
    --apollo-token "$APOLLO_TOKEN" \
    --apollo-url "$APOLLO_URL" \
    --transfer-target-rid $TARGET_HUB

您可以通过导航到 Export 应用程序并转到 Target Hubs 标签页来搜索所需的 Target Hub。

要获取上述命令的预填充版本：

  1. 在 Export 管道中导航到该 Bundle。
  2. 选择 下载 Bundle 以打开下载菜单。
  3. 从下拉菜单中选择所需的目标 Hub。
  4. 选择 复制 CLI 命令 以复制已自动填充所有参数的完整命令。
  5. 将命令粘贴到终端中 apollo-cli 可执行文件所在的位置，以下载 Bundle。

常见问题

为什么我需要确认手动传输？

确认 Bundle 后，会向其他 Apollo 用户表明该 Bundle 已成功上传，并且在目标 Hub 上的 Import Application 中可见。

当我确认 Bundle 已传输到其目的地后会发生什么？

确认 Bundle 后，Export Application 会检查 Bundle 的内容，以确定目标 Hub 上已存在哪些数据。它会利用此信息，通过删除已发送的重复信息来减小发送到该目标的后续 Bundle 的大小。此计算会针对所有管道和传输目标组合执行。这意味着每个目的地需要传输的数据量各不相同。

确认 Bundle 已传输后，会为其他用户保留 Bundle 传输至何处的记录。

如果我的 Bundle 未发送到目标 Hub，该怎么办？

如果您之前声明某个 Bundle 已传输到特定目的地，则可以撤销该确认。如果 Bundle 未能成功传输到其目的地，或者 Bundle 已从目标 Hub 中删除，则可以执行此操作。撤销 Bundle 确认后，Export 应用程序将假定该 Bundle 从未发送到目的地。

要撤销 Bundle 确认，请前往您之前确认传输的源 Hub 中的 Export 应用程序。
