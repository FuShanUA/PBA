对象列表

直方图 对象列表 小组件用于以列表或网格形式显示对象数据。配置对象列表小组件的模块构建者可以：

  • 在一个或多个对象类型上显示数据。
  • 选择要显示哪些属性类型和关联对象，以及以何种格式显示。
  • 可选择一个媒体属性，为每个对象显示图像或图标。
  • 设置初始排序条件。
  • 显示在 Ontology Manager 中配置的条件格式和数字格式选项。
  • 按对象隐藏空值属性，以获得更紧凑的显示效果。
  • 允许在列表中进行单选或多选。
  • 在列表中选择对象时触发 Workshop 事件。

配置选项

对于对象列表小组件，核心配置选项如下：

  • 输入数据
    • 导入对象集： 此输入变量决定小组件中显示的数据。模块构建者可以复用在此模块中其他位置创建的现有对象集变量，也可以内联定义新的对象集变量。下面显示的许多其他配置选项只有在填充此对象集参数后才能进行配置。
  • 属性配置
    • 添加媒体： 您可以选择在对象信息旁边显示图像。有关 媒体配置 的更多信息，请参见下文。
    • 添加属性： 在此处选择某个属性后，该属性将显示在列表中。
    • 默认排序： 此设置允许在列表中应用最多一个默认排序。模块构建者可以对列表中显示的可见属性类型或未显示的隐藏属性类型进行排序。
    • 启用用户排序： 启用后，列表上方将显示一个子标题栏，用户可以在其中更改列表的排序条件。用户可以对列表中显示的可见属性类型或未显示的隐藏属性类型进行排序。
    • 启用重新排序： 启用并配置后，允许用户在小组件中拖放项目以重新排序。只有使用对象卡片右侧出现的拖动手柄才能拖动项目。有关 重新排序配置 的更多信息，请参见下文。
    • 隐藏空值属性： 启用后，将在列表中按对象隐藏空值属性。
  • 点击
    • 活动对象： 这是此小组件两个输出变量中的第一个，输出当前活动/高亮行的单例对象集。此对象集随后可用于当前模块中的下游小组件。
    • 启用活动对象自动选择： 默认情况下，列表中的第一行会在加载时自动设置为活动对象。禁用此设置可阻止此行为，并导致加载时 活动对象 为空。
    • 选定对象： 这是此小组件两个输出变量中的第二个，输出当前勾选/选定行的对象集。此对象集随后可用于当前模块中的下游小组件。只有当 启用多选 开关设置为 true 时，才会使用并填充此输出变量。
    • 在活动对象选择时： 此选项使模块构建者能够配置在列表中选中某行时触发的 Workshop 事件，例如使显示更详细对象视图的抽屉面板出现。
    • 启用多选： 启用后，此开关允许用户在列表中勾选/选择多个对象。所选的对象集随后将通过 此选项输出当前所选对象的对象集。随后可以在当前模块内的下游小组件中使用此对象集。 对象集输出，供当前模块中的下游小部件使用。
  • 显示与格式设置
    • 标题： 如果填写了此字段，列表上方将显示一个包含此处输入的字符串标题的子标题。
    • 显示安全标记： 开启后， 属性安全标记 将以浓缩的灰色胶囊形式呈现，选中时会展开窗口视图。
    • 显示对象数量： 启用后，列表上方将显示一个子标题，其中显示输入对象集变量中包含的对象数量。
    • 小部件显示方式： 默认情况下以列表形式显示对象，但也可以以网格形式显示对象，并可指定行数、网格中每个对象卡片的大小以及卡片之间的间距。
    • 属性样式： 默认情况下，属性与其值内联显示，但也可以将属性与其值对齐显示。
    • 空状态消息： 自定义此小部件没有可显示对象时的空状态消息。

媒体配置

配置选项

对于对象列表小部件，媒体配置选项如下：

  • 属性： 这是对象集中包含要显示的图像的属性。目前支持图像 URL、图像附件和媒体引用属性。
  • 媒体显示方式： 所选媒体可以显示为大图像，或作为图标替换对象标题旁边的本体论图标。
  • 启用展开图像预览： 启用后，可以在模态框中展开并完整查看图像。
  • 悬停时显示属性： 启用后，悬停时将在图像上方的叠加层中显示其他属性。
  • 图像位置： 图像可以显示在多种位置，并且可以将其高度或宽度控制为固定大小。
  • 调整大小： 图像可以裁剪以填满空间，也可以适应容器以显示完整图像而不进行裁剪。

重新排序配置

构建者可以将对象列表中的项目配置为可重新排序，允许用户在小部件中拖放对象卡片。

局限性

  • 目前仅支持在单个对象列表小部件内进行重新排序。
  • 目前不支持在网格布局中重新排序项目。
  • 启用重新排序后，对象列表小部件将仅显示前 500 个对象。

配置选项

  • 条件启用： 设置一个布尔变量来确定是否在小部件中启用重新排序。
  • 主键数组： 设置一个包含所显示对象主键的字符串数组。数组中主键的顺序将决定这些对象在小部件已排序部分中的显示顺序。主键不在数组中的任何对象将显示在 未排序列表 部分，位于小部件中已排序对象的下方，可以以未排序的方式显示，或者应用 默认排序 （如果在小部件中进行了配置）。
    • 如果某个项目是从 未排序列表 部分拖放的，该对象的主键将被添加到主键数组中。同样，如果某个项目被拖放到小部件的 未排序列表 部分，该项的主键将从主键数组中移除。
    • 如果主键数组为空，或者所显示对象的主键与数组内容之间没有重叠，小部件顶部将显示一个提示，提醒用户"拖放未排序的项目到上方以进行排序"。
    • 如果主键数组包含当前未在 widget 中显示的对象的主键（例如被过滤出视图之外），它们的顺序仍将保持不变。例如，如果您的数组排序为 [A, B, C, D] but B 当前被过滤出 widget 的视图之外，可见列表将显示 [A, C, D]。如果用户重新排序 D between A and C，更新后的数组将为 [A, B, D, C]。唯一的例外是当用户将某个项目拖动到最后一个可见对象下方时。在这种情况下，该项目将被放置在最后一个可见对象之后。
  • 重新排序时： 构建者可以选择在 widget 中的项目重新排序时更新主键数组，或运行某个操作。
    • 更新数组变量： 当用户在 widget 中重新排序某个项目时，主键数组将相应更新。
      • 主键数组的更新不会自动保存或存储，这意味着如果用户刷新或离开模块，主键数组的任何更改都将丢失。构建者需要配置一个操作来存储主键数组的新值，以便保存对数组的更新。使用 更新数组变量 选项并结合单独配置的操作（例如模块中其他位置的按钮组 widget 中的操作），是您不希望在 widget 中每次重新排序项目时都触发操作时的一个好选择。
    • 提交操作： 配置一个 重新排序操作 ，该操作将在用户每次于 widget 中重新排序项目时触发。
