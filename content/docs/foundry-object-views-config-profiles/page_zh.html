配置配置文件

配置文件 使您能够配置如何向具有不同角色的用户呈现对象视图。您可以使用配置文件来控制对象视图 标签页 对不同用户的可见性，让他们看到符合其特定需求的视图。

配置配置文件

Object Explorer 由一项名为 Hubble的服务提供支持。要将组用作对象视图中的配置文件，请在平台设置的 组 标签页 中添加以下 Hubble 属性：

  • hubble:isProfile : true
  • hubble:displayName : Set a name you want end user to see
  • [可选] hubble:isDiscoverable : true
    • 将 hubble:isDiscoverable 属性设置为 true 会使该配置文件对不属于该组的用户可见。省略此属性意味着，只有该组中的用户才能访问分配给此特定配置文件的视图。

新创建的配置文件最多可能需要五分钟才能在对象视图编辑器中可用。

为对象视图分配配置文件

配置文件是在标签页级别分配的，也就是说，您可以为每个标签页分配特定的配置文件。要为标签页添加配置文件，请访问编辑器侧边栏，在 标签页 设置中点击某个标签页，选择 “可见性”，然后点击 “添加配置文件”。

以用户身份切换配置文件

将配置文件添加到对象视图后，您就可以在不同配置文件之间切换。在对象视图的标题栏中选择配置文件类型，即可访问包含可用配置文件的下拉菜单。您可以通过点击对象视图顶部的 查看对象身份： 来找到同一个下拉菜单。

以编辑者身份切换配置文件

编辑对象视图时，您也可以访问不同的配置文件。这样您就能查看每个配置文件可以看到哪些标签页。

为用户设置默认配置文件

要为用户或用户组设置默认配置文件，请将其添加为支撑该配置文件的组的成员。仅当用户是单个配置文件的成员时，此操作才会生效。

每个对象视图最多可以添加十个配置文件。
