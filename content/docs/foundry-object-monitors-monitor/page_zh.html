监视器

对象监视器已被取代，取而代之的是 Automate。Automate 是一款完全向后兼容的产品，为平台中的所有业务自动化提供统一入口。

监视器是一种资源，用于定义针对一个或多个输入的条件，以及在满足输入条件时应触发的任何操作或通知。

存储

对象监视器保存在 Foundry 项目层级结构中，并支持保存、共享、移动、删除和基于角色的访问控制等标准资源操作。

了解 Foundry 文件系统。

对象监视器由唯一的资源标识符标识，格式如下：

ri.object-sentinel.main.monitor.0cabb748-cf89-4404-be3c-c8f198cb2a0b

保留

对象监视器的历史活动将保留六个月，之后会被永久删除。如果必须在此日期之后存储历史活动，您可以使用操作将数据存储在一个长期存在的对象中，该对象的管理和控制方式与其他任何用户创建的对象相同，而这些对象均属于 Foundry 本体论。

数据被删除后，也会从监视器活动的 历史记录 标签页中移除，该标签页位于对象监视器应用程序中。您可以按照以下方式找到 历史记录 标签页：首先点击某个监视器以展开概览面板，然后点击 历史记录。

过期

对象监视器始终设有过期日期。允许的最长过期日期为未来三个月，可由在监视器上具有 Editor 角色的用户随时更新。

可以在 Object Monitors 应用程序界面中查看和延长过期日期。点击某个监视器，可在屏幕右侧查看监视器概览面板。然后，点击 Details 标签页。
