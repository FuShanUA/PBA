架构参考

Vulcan 期望您的注册环境中存在一组特定的本体论对象类型、操作、关联类型和属性类型类。本页面列出了 Vulcan 读取或写入的每一个类型类。

对象类型、操作和关联类型，请在 本体论管理器中创建，然后将本页面列出的类型类附加到其属性、操作参数和关联类型上。

架构稳定性

随着 Vulcan 的发展，架构细节可能会发生演变。每次 Vulcan 发布后，请对照本页面验证您的架构。

类型类是附加到属性上的标签，用于告知 Vulcan 该属性的用途。Vulcan 根据类型类而非名称来查找属性，因此您可以按照自己的本体论约定为属性命名。单个属性还可以承载多个类型类，从而同时服务于 Vulcan 和其他应用程序。

以下列出的所有类型类都位于 vulcan 命名空间中——也就是说，它们的 kind 字段始终为 "vulcan" ，且只有 name 字段会有所不同。

在下表中， 必需 表示相应的类型类必须存在于已配置的架构中。每种表格都会增加一项进一步的要求：

  • 对象属性： 必需属性在已存储的对象上也必须具有值。
  • 操作参数： 该操作必须公开一个具有所列类型类和数据类型的参数，以便 Vulcan 能够提供其值。
  • 关联类型： 该关联类型必须携带所列的类型类，以便 Vulcan 能够对其进行遍历。

对象类型

Vulcan 读取和写入以下对象类型。每个表格列出了 Vulcan 在该对象类型的属性上查找的类型类。

CAD 对象

表示一个 Vulcan 可以渲染的 3D 模型。模型几何体以媒体引用的形式存储。

类型类（name）必填数据类型描述
cad_media_reference是媒体引用CAD 模型文件。此属性接受 支持的模型格式中列出的任何格式。Vulcan 会根据文件扩展名检测格式。
up_axis否字符串模型的向上轴约定。可接受的值为 X、 Y和 Z。如果省略，Vulcan 会应用特定于格式的默认值： Y 适用于 GLB 和 GLTF， Z 适用于 STL、 OBJ、 PLY、 3MF、 DXF和 LAS，以及 LAZ。
model_unit否字符串当文件本身未声明单位时，Vulcan 如何解释模型的坐标。请为以下格式设置此属性： OBJ、 STL、 PLY、 DXF、 LAS和 LAZ，这些格式从不声明单位。此属性不影响 GLB、 GLTF或 3MF，因为 Vulcan 始终读取这些格式所声明的单位。接受的值为 m （或 meter / metre）和 mm （或 millimeter / millimetre）。Vulcan 会忽略任何其他值。

注释

表示附加到 CAD 模型某部分的注释。注释结合了文本标签、3D 附加点以及有关创建者和意图的元数据。

类型类（name）必填数据类型描述
annotation_id是字符串注释的唯一标识符。
annotation_title是字符串随注释一起显示的简短标签。
annotation_content是字符串较长的正文文本。
part_instance_id是字符串注释所附加到的零件实例的标识符。
annotation_attachment_x是双精度浮点数附加点的 X 坐标，以模型单位表示。
annotation_attachment_y是双精度浮点数附加点的 Y 坐标，以模型单位表示。
annotation_attachment_z是双精度浮点数附加点的 Z 坐标，以模型单位表示。
annotation_sphere_size是双精度浮点数标记半径，以模型单位表示。使用 0 来渲染点标记。
annotation_created_by是字符串创建该注释的用户的标识符。
annotation_intent是字符串注释标记的视觉意图。请参见 意图值 （见下文）。
annotation_timestamp是时间戳注释的创建时间。

意图值

该 annotation_intent 属性接受以下字符串值之一。Vulcan 会将每个值渲染为一种独特的标记颜色,因此您可以采用用户一眼就能识别的方式来编码严重程度或类别。Vulcan 不会对这些值强制规定语义含义,因此您可以将它们设置为符合自己的工作流程。

值标记颜色
none灰色
primary蓝色(创建新标注时的默认颜色)
success绿色
warning黄色
danger红色

测量

表示在模型上两个或多个点之间捕获的距离测量。

类型类(name)必填数据类型描述
measurement_id是字符串测量的唯一标识符。
measurement_points是双精度浮点数数组定义该测量的有序 3D 点坐标,以扁平数字数组的形式序列化。参见 点格式 如下。
measurement_created_by是字符串创建该测量的用户的标识符。
measurement_timestamp是时间戳创建测量的时间。

点格式

测量点序列化为扁平数字数组,其顺序为 [x1, y1, z1, x2, y2, z2, ...],以模型的坐标空间表示。因此,由两个点构成的测量包含六个数字;由三个点构成的测量包含九个数字。这些点会被解释为有序折线 — Vulcan 为测量报告的总距离是各连续点之间距离的总和。

剖切面

表示穿过模型的横截面平面。

类型类 (name)必填数据类型描述
section_plane_id是字符串横截面平面的唯一标识符。
section_plane_position是双精度浮点数数组恰好三个位置值，按 [x, y, z] 顺序。
section_plane_quaternion是双精度浮点数数组恰好四个四元数值，按 [x, y, z, w] 顺序。
section_plane_created_by是字符串创建横截面平面的用户标识符。
section_plane_timestamp是时间戳横截面平面的创建时间。

操作类型

Vulcan 通过操作将标注、测量和横截面平面写回本体论。每种操作类型由其携带的一组参数类型类来标识。

下表仅列出 Vulcan 提供的参数。您的操作定义必须填充所创建对象上的所有其他必需属性：

  • 对象 ID 和创建者属性，适用于所有三种操作。将创建者属性 — annotation_created_by、 measurement_created_by 或 section_plane_created_by — 设置为提交该操作的用户。
  • 时间戳属性，适用于 创建测量 和 创建横截面平面 操作。Vulcan 提供 annotation_timestamp ，仅适用于 创建标注。

其他操作参数不需要 Vulcan 类型类。当您在 Workshop 小组件中配置操作时，您可以为这些参数提供默认值，或将其公开为用户输入字段。

创建标注

参数类型类 (name)必填数据类型描述
annotation_title是字符串简短标签。
annotation_content是字符串正文文本。
part_instance_id是字符串标注所附着的零件实例。
annotation_attachment_x是双精度浮点数附着点的 X 坐标。
annotation_attachment_y是双精度浮点数附着点的 Y 坐标。
annotation_attachment_z是双精度浮点数附着点的 Z 坐标。
annotation_sphere_size是双精度浮点数以模型单位表示的标记半径。使用 0 即可获得点标记。
annotation_intent是字符串类别或严重程度。
annotation_timestamp是时间戳创建时间戳。
cad_object是对象引用标注所属 CAD 对象的引用。

创建测量

参数类型类（name）必填数据类型描述
measurement_points是双精度浮点数数组有序点坐标，采用 [x1, y1, z1, x2, y2, z2, ...] 格式。

创建剖切面

参数类型类（name）必填数据类型描述
section_plane_position是双精度浮点数数组正好三个位置值，按 [x, y, z] 顺序。
section_plane_quaternion是双精度浮点数数组正好四个四元数值，按 [x, y, z, w] 顺序。

关联类型

类型类（name）必填描述
cad_object是将标注与其父 CAD 对象关联。
