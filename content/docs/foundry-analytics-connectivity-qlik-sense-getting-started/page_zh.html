开始使用

本指南将教你如何在 Qlik Sense 中对 Foundry 进行身份验证，并开始加载数据集。

连接到 Foundry

  • 你需要拥有一个 Foundry 访问 令牌 以进行身份验证。
  • 你还需要服务器管理员创建的 Foundry DSN 的名称
  • 在 Qlik Sense 中，打开数据管理器，然后点击图标以创建新连接
  • 选择 OLE DB 作为数据源
  • 选择 Microsoft OLE DB Provider for ODBC Drivers 作为提供程序
  • 对于数据源，请输入 <Foundry_DSN>;PWD=<Token>，其中 <Foundry_DSN> 是服务器管理员创建的 DSN 的名称，而 <Token> 是你的 Foundry 令牌 例如，你最终可能会得到类似以下的内容 Foundry;PWD=eyJwbG50ci...
  • 选择 Specific user name and password，但请将它们留空
  • 为连接选择一个合适的名称。（Qlik 可能默认在名称中设置了令牌，请将其删除！）
  • 测试连接以检查一切是否正常，然后点击创建以打开表浏览器。

Qlik Sense 目前对可在"密码"字段中输入的最大密码长度有限制，该长度短于 Foundry 令牌。这就是我们将令牌设置在数据源字符串中而不是密码字段中的原因。

加载数据集

创建连接后，将打开一个表浏览器。你也可以通过选择之前创建的连接来打开此浏览器。在这里，你首先选择包含要加载的数据集的 Foundry 项目（在此称为"数据库"）。

然后会列出项目中的表，你可以选择要导入的表。
