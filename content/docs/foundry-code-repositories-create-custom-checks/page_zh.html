创建自定义检查

自定义检查可以创建为 Gradle ↗ 任务来创建。这些任务应添加到相应的内部 build.gradle 文件中，位于语言子文件夹内。以下是一个在执行时打印 Hello World 执行时（ doLast 方法会在任务执行时运行，而不是在配置时间）：

// Define custom task
task customTask {
    doLast {
        println "Hello World"
    }
 }

为了使任务在 CI 检查期间执行，必须有一个依赖于您的自定义任务的 CI 任务。这也在相同的 build.gradle 文件中定义。在下面的示例中，check 任务将在 CI 中的 customTask 之后执行；这就是 Hello World 消息将出现在 CI 日志中的位置。

Copied!
1
2
// Add CI dependency on custom task
 project.tasks.check.dependsOn customTask

为了使任务在任务列表末尾执行，您应该使用以下语法。

Copied!
1
2
// Execute custom task after CI checks are published
project.tasks.publish.configure { finalizedBy customTask }

要添加依赖项，您可以使用以下CI任务： project.tasks.check, project.tasks.test日 project.tasks.publish。我们强烈建议您不要使用或依赖其他CI任务（例如内部任务），因为这些任务无法保证，并且可能会发生变化。

有关Gradle构建脚本提供的功能的更多文档，请参见 Gradle文档 ↗.

不建议将自定义CI检查添加到 ci.yml 文件中，因为每次仓库升级时该文件都会被覆盖。
