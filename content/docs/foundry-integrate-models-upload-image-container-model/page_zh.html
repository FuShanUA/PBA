使用容器模型上传镜像

本页面将引导您完成使用容器支撑模型上传镜像的过程。在此工作流程中，您将创建一个模型、将镜像推送到模型资源，并配置模型版本。

1. 创建模型

要创建容器支撑的模型，首先创建镜像将要推送到的资源。该资源将控制模型权限；拥有该资源 Viewer 权限的用户将能够从 Foundry 中拉取镜像。

导航到任意建模目标并选择以下选项，即可创建新模型 +添加模型，然后选择 导入容器化模型.

2. 将镜像推送到模型

在 Palantir 中创建模型资源后，请按照说明将您的镜像推送到该 Asset 中。您推送的镜像必须符合 Foundry 的 镜像要求.

选择 生成令牌，然后复制默认命令块并进行编辑，将其中的镜像名称和标签（或摘要）替换为 example-package:<TAG> 您本地 Docker 仓库中的镜像名称和标签（或摘要）；根据 镜像要求，标签不允许为 'latest'。执行这些命令会将相关镜像推送到模型中，拥有 Viewer 权限的任何用户都可以访问该镜像。

根据镜像的大小，容器镜像可能需要几分钟才能在模型中可用。

镜像成功推送并出现在容器镜像列表中后，请选择 创建模型版本 以开始配置您的版本。为此，您必须首先编写一个 容器模型适配器 使用以下内容创建 模型适配器库模板.

在发布之前迭代您的模型适配器实现，请使用 sidecar 装饰器来测试该逻辑如何与模型中已有的容器配合工作。请按照 sidecar transforms 装饰器文档 中的步骤创建一个启用了该装饰器的新 transforms 仓库，并使用您刚创建的模型作为支撑 Artifacts 仓库。然后，在 transforms 仓库中定义一个实现该适配器的本地 Python 文件，并按如下所示手动实例化它：

from transforms.api import transform, Input, Output
from transforms.sidecar import sidecar, Volume
# This assumes you created a Python class testAdapter.py under a `myproject` folder and defined a class TestModelAdapter that implements palantir_models' ModelAdapter class.
from myproject.testAdapter import TestModelAdapter
import palantir_models.transforms


@sidecar(image='image-name', tag='1.0.0', volumes=[Volume("shared")])
@transform(
    output=Output("ri.foundry.main.dataset.<RID>"),
    source_df=Input("ri.foundry.main.dataset.<RID>"),
)
def compute(source_df, output):
    testingEntrypoint = TestModelAdapter(
       "/opt/palantir/sidecars/shared-volumes/shared",
       # Note that the port here should reflect the port on which your specific image is listening.
       "localhost:PORT")
    testingEntrypoint.transform_write(source_df, output)

3. 配置模型版本

在 配置模型版本 页面，选择要包含在特定模型版本中的一个或多个容器镜像。选择 属性，然后选择 以继续进行模型版本配置。

在 模型详情 页面的 配置模型 对话框中，配置要进行的语义版本变更类型。然后，添加可选的描述和配置文件，并选择您创建的适配器。在 模型适配器 配置部分中选择您的模型适配器仓库， 选择模型适配器 下拉菜单将填充该仓库中定义的所有有效适配器的最新版本。

最后，为每个镜像配置任何可选的运行时信息，包括内存限制、参数、任何环境变量或新的 exec 命令。如果您的适配器使用 requests 库，则指定镜像监听的端口至关重要。您可以为模型版本中选择的每个镜像配置运行时信息。

模型可以配置为生成遥测日志。如果您的 容器支持遥测，您可以在下方截图所示的步骤中为模型版本启用该功能。

4. 查看模型版本

模型版本创建完成后，其元数据将显示在 模型概览 模型页面的选项卡中。在那里，您可以使用左侧面板查看并导航到过去的版本。

在此页面，您可以 提交到建模目标（Modeling Objective） 选项。 + 右上角的图标或 操作 下拉菜单。您也可以将该模型用作 Python 转换的输入。如果模型由容器支撑，您需要在 ModelInput 类中指定第二个可选参数，以选择要在转换中使用的版本 RID。您还必须在您的转换仓库中添加对模型适配器的依赖。示例如下：

from transforms.api import transform, Input, Output
from palantir_models.transforms import ModelInput


@transform(
    output=Output("/path/to/output/output_dataset"),
    model=ModelInput(
        "ri.models.main.model.<RID>",
        "ri.models.main.model-version.<RID>"),
    source_df=Input("/path/to/input/input_dataset"),
)
def compute(model, source_df, output):
    model.transform_write(source_df, output)
