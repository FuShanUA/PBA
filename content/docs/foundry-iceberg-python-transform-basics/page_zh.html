Python 转换基础知识

在 Python 转换中，可以将 Iceberg 表用作输入和输出，方法是使用 transforms.tables API，该 API 可以从 transforms-tables 包中导入。

本页面提供了在 Python 转换中使用 Iceberg 表输入和输出的基础代码示例。

示例：生成一个简单的 Iceberg 表

Copied!
1import polars as pl
2from transforms.api import transform
3from transforms.tables import IcebergOutput, TableOutput
4
5
6@transform.using(
7    output=TableOutput("/.../Output")
8)
9def compute(output: IcebergOutput):
10    df_custom = pl.DataFrame({"phrase": ["Hello", "World"]})
11    output.write_table(df_custom)

高级：PyIceberg 原生扫描

上述示例使用了 Foundry 在 IcebergInput 和 IcebergOutput上的简化快捷方式，它们会读取和写入表的完整当前快照。这些简化的 API 为大多数标准管道提供了简洁的语法。但是，它们会将整个表物化到内存中，并且不提供对某些底层功能的访问，例如谓词下推、列投影或快照选择。

要访问这些更细粒度的控制，您可以将 .table() 应用于您的 IcebergInput ，以返回底层的 PyIceberg ↗ 表并公开完整的 PyIceberg 扫描 API。

Copied!
1from pyiceberg.expressions import And, EqualTo, GreaterThan
2from transforms.api import transform
3from transforms.tables import IcebergInput, IcebergOutput, TableInput, TableOutput
4
5
6@transform.using(
7    source_table=TableInput("/.../Input"),
8    output_table=TableOutput("/.../Output"),
9)
10def compute(source_table: IcebergInput, output_table: IcebergOutput):
11    iceberg_table = source_table.table()
12
13    scan = iceberg_table.scan(
14        row_filter=And(
15            EqualTo("region", "EMEA"),
16            GreaterThan("score", 0.5),
17        ),
18        selected_fields=("customer_id", "score", "region"),
19        limit=10_000,
20    )
21
22    output_table.write_table(scan.to_polars())
