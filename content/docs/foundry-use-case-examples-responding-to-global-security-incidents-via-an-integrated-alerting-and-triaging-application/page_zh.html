通过集成的告警与分诊应用程序响应全球安全事件

行业领域： 国防

业务职能： 安全

Palantir Foundry 的全球事件响应（Global Incident Response）产品可通过快速实施统一的数据驱动型解决方案，提升组织的安全与安保态势。该解决方案包含用于风险评分、事件分诊、人员清点、管理紧急通信以及理解和分析已采取行动的模块。所有这些工具均内置数据与隐私保护组件，并可与现有工具、数据源和标准作业程序（SOP）无缝集成。

挑战

为了有效开展事件响应工作，安全团队通常不得不在两者之间做出选择：要么采用一套号称能满足其所有需求却缺乏灵活性的开箱即用系统，要么利用各种构建模块自行定制搭建全球运营中心，以保留自主权与灵活性。

此外，全球组织的安全团队被有关混乱世界中不断涌现的事件的数据所淹没，在试图了解这些事件是否或如何影响其人员和资产的安全时，往往难以从噪音中分辨出有效信号。而当需要做出响应时，由于用于管理和跟踪组织不同部门的系统彼此孤立，要准确确定究竟哪些人员可能受到影响可能非常耗时，甚至无法实现。而且，无论某项响应多么有效，都不存在一个单一事实来源来记录何时做出了哪些决策，以及谁出于何种目的访问了哪些数据。

解决方案

某全球安全团队构建了一套全面的模块、场景和模型，同时保留了所需的灵活性和控制力，确保能够满足不断变化的需求，且不会被锁定在单一供应商或系统上。

在工作流解决方案方面，Foundry 提供了一个数据驱动的运营框架，用于接收安全警报、进行分类分级并采取相应行动。

安全运营分析师（用户类型）审查事件警报收件箱，根据事件对业务资产的预期影响来查看和分类事件，并响应和解决每个需要响应的事件。

安全负责人根据响应时间、解决成果以及响应过程中访问的数据，审查所有已采取的事件响应和警报分类操作。

用户和利益相关者

  • 安全运营（分析师、团队负责人等）
