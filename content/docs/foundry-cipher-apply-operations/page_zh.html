将 Cipher 操作应用于数据集的列

Cipher 允许您对数据集的整列进行加密、解密和哈希运算。该功能可在 Pipeline Builder、 Contour和 Python 转换中使用。

使用 代码仓库中的预览 或 Pipeline Builder 中的预览时，用户将 无法 看到 Cipher 操作的真实输出。相反，预览模式中的用户将看到 占位符值。需要注意的是，数据将在 构建时被加密。要查看 Cipher 操作的真实输出，用户应运行构建。

Pipeline Builder

Pipeline Builder 是一款数据集成应用程序，旨在让用户更轻松地在 Foundry 中执行高质量的数据集成。本节演示如何在 Pipeline Builder 中部署 Cipher 操作以混淆数据集的列。要在 Pipeline Builder 中运行 Cipher 操作，用户必须拥有 Cipher 数据管理员许可证 或 管理员许可证。

加密

首先，选择 Cipher 加密转换。然后，选择 Expression （要加密的列）。接下来，选择一个具有加密权限的数据管理员许可证，该许可证通常可在项目文件夹中找到（之前已在 Cipher 应用程序中颁发）。最后，为输出列命名。

解密

首先，选择 Cipher 解密转换。在选择 Expression时，请指定一个已经通过 Cipher 转换加密的列。对于 Cipher License RID，请选择具有解密权限的数据管理员许可证；此类许可证通常先在 Cipher 应用程序中签发，再保存到项目文件夹中。请注意，该许可证必须属于用于加密相关列的同一 Cipher 通道。最后，为输出列命名。

哈希

选择 Cipher 哈希转换。对于 Expression，请指定要进行哈希处理的列。接下来，选择一个有权通过哈希 Cipher 通道进行加密的数据管理员许可证。该许可证应已在 Cipher 应用程序中签发，随后保存到项目文件夹中。最后，为输出列命名。

如何使用 Cipher 加密管道（仅限管理员和数据管理员许可证）

首先，打开一个具有加密权限的 Cipher 许可证；此类许可证通常先在 Cipher 应用程序中签发，再保存到项目文件夹中。然后，在右上角选择“Create Pipeline”（创建管道）。

选择要加密的输入数据集，然后选择保存管道的目标文件夹，再选择要加密的数据集列。请注意，只有 String 列可用于加密；如果需要加密其他列，请先将其转换为 String。在选择 创建管道后，Cipher 将自动生成一个新管道并加密您之前选择的列。

Contour

Contour 提供了一个点击式用户界面，可对大规模表格执行数据分析。本节演示如何使用 Cipher 操作对 Contour 分析中的数据集列进行（去）混淆。要在 Contour 中运行 Cipher 操作，用户必须拥有 Cipher 数据管理员许可证 或 管理员许可证。首先，使用 Contour 工具栏的 搜索模式 将 Cipher 看板添加到分析中。您可以使用 Contour 的 表格看板 和 表格面板 来查看 Cipher 操作的结果。

使用 Cipher 看板的 Contour 分析路径无法 保存为数据集。

加密

要使用 Cipher 看板加密数据，请先选择要加密的列（列的选择顺序不会影响该操作）。接下来，请选择一个具有加密权限的数据管理员许可证或管理员许可证，此类许可证通常在之前于 Cipher 应用程序中发放后，可在项目文件夹中找到。选择 加密 操作并保存看板。此转换将更新列值，但列名称将保持不变。

解密

要使用 Cipher 看板加密数据，请先选择要解密的列（选择列的顺序对操作没有影响）。接下来，选择具有解密权限的数据管理员许可证或管理员许可证，此类许可证之前在 Cipher 应用程序中颁发后，通常可在项目文件夹中找到。选择 解密 操作并保存看板。此转换将更新列值，但列名称将保持不变。

哈希

要使用 Cipher 看板对数据进行哈希处理，请先选择要进行哈希的列（选择列的顺序对操作没有影响）。接下来，选择具有哈希权限的数据管理员许可证或管理员许可证，此类许可证之前在 Cipher 应用程序中颁发后，通常可在项目文件夹中找到。选择 哈希 操作并保存看板。此转换将更新列值，但列名称将保持不变。

from transforms.api import transform, Input, Output
from pyspark.sql.functions import col
from bellaso_python_lib.encryption.encrypter_input import EncrypterInput

@transform(
    encrypter=EncrypterInput("/path/to/cipher/license"),

    input_dataset=Input("/path/to/input/dataset")

    encrypted_df = input_dataset.dataframe().withColumn("your_column_name", encrypter.dataframe().encrypt_column(col("your_column_name")))
    output.write_dataframe(encrypted_df)

from transforms.mediasets import MediaSetInput, MediaSetOutput
import io
from bellaso_python_lib.encryption.encrypter_input import EncrypterInput
from bellaso_python_lib.types import Coordinate

@transform(
    mediaset_in=MediaSetInput("</path/to/input/media/set"),
    mediaset_out=MediaSetOutput("</path/to/output/media/set"),
    encrypter=EncrypterInput("/path/to/cipher/license"),
    polygons=Input("/path/to/polygon/dataset"),
)
def compute(mediaset_in, mediaset_out, encrypter, polygons, ctx,):

    media_references = mediaset_in.list_media_items_by_path_with_media_reference(
        ctx
    ).collect()  # noqa

    for row in media_references:
        image_file = mediaset_in.get_media_item(row["mediaItemRid"])

        plainview_image = image_file.read()

        # Encrypt a square in the top left of the image, 100 px by 100 px.
        polygon = [Coordinate({"x": 0, "y": 0}), Coordinate({"x": 100, "y": 0}), Coordinate({"x": 100, "y": 100}), Coordinate({"x": 0, "y": 100})]

        polygon_list = [polygon]

        if plainview_image:
            encrypted_image = encrypter.obfuscate_image(plainview_image, polygon_list, ctx)

            mediaset_out.put_media_item(io.BytesIO(encrypted_image), row["path"])

字符串级操作

该 bellaso-python-lib 库提供了作用于普通 Python 字符串而非 PySpark 列的字符串级方法。在与 PySpark 用户自定义函数不兼容的上下文中工作时（例如在嵌套函数内部，或在使用 F.transform() 处理数组列时），请使用这些方法。

from transforms.api import transform, Input, Output
from pyspark.sql import functions as F
from pyspark.sql.functions import col
from bellaso_python_lib.encryption.encrypter_input import EncrypterInput

@transform(
    encrypter=EncrypterInput("/path/to/cipher/license"),
    output=Output("/path/to/output/dataset"),
    input_dataset=Input("/path/to/input/dataset")
)
def encrypt_nested_values(ctx, input_dataset, output, encrypter):
    enc = encrypter.dataframe()
    encrypted_df = input_dataset.dataframe().withColumn(
        "encrypted_array",
        F.transform(col("string_array"), lambda x: F.lit(enc.encrypt_string(x)))
    )
    output.write_dataframe(encrypted_df)
