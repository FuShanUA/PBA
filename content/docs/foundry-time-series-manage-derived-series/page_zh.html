管理派生序列

晚于 创建派生序列 后，您将被重定向到派生序列的管理页面。该页面既表示生成的 Palantir 资源，也表示用于执行派生序列计算的 codex 模板。您也可以从平台文件系统导航到此页面。

管理页面包含以下三个主要选项卡。

概述

直方图 概述 选项卡允许用户预览其逻辑、本体论（Ontology）设置以及派生序列的常规详细信息。

选择 标题 or 描述 文本，以编辑在 Quiver 分析和其他应用程序中使用的标题和描述。选择 保存 （右上角）以查看更改并更新派生序列的显示信息。

逻辑

直方图 逻辑 选项卡可用于查看和编辑派生序列的逻辑。直接修改时间序列卡片即可编辑逻辑。选择 保存 （顶部工具栏中）以保存更改。

如果派生序列是手动保存到本体论（Ontology）的，则对逻辑的已保存更改将立即生效，除非该派生序列被固定到本体论中的特定版本。请参阅 手动保存文档 以了解如何使用固定版本。使用自动保存创建的派生序列对象始终引用特定版本。

本体论

直方图 本体论 选项卡用于管理派生序列的 自动保存 和本体论（Ontology）选项。自动保存的选项包括传感器名称、模板化派生序列的根对象范围以及属性映射。

对对象范围的更改必须先保存并部署。选择 保存 （顶部工具栏中）以查看并保存范围更改。保存后，选择 部署 （工具栏中）以将更改部署到本体论（Ontology）。

本体论状态

派生序列的本体论（Ontology）状态表示基于当前请求的逻辑版本和本体论选项，该派生序列是否为最新。

如果派生序列相对于本体论（Ontology）中请求的内容已过时，则状态将指示该派生序列已过时，必须重新部署。

要根据本体论（Ontology）选项更新派生序列，您必须 部署 将最新版本部署到本体论（Ontology）。选择 部署 以查看派生序列对象要在本体论（Ontology）中更新哪些内容，才能与基于本体论选项的预期相匹配。

下图显示了一个已过时的模板化派生序列的部署对话框。系统将提示您为每种关联的更新类型提供操作（Action）类型。例如，要删除对象，您必须提供一个可删除所绑定传感器对象类型对象的操作类型。

单一派生序列的本体论（Ontology）状态和部署对话框与此类似，不过单一派生序列始终预期本体论中 仅存在一个对象 。

以下示例描述了已过时的派生序列：

  1. 派生序列刚刚更新，但本体论（Ontology）中的现有对象不再引用最新逻辑。
  2. 在模板化派生序列中，动态根对象范围在已针对所有当前对象定义之后又捕获了更多对象。例如，如果根对象范围为“所有 Machines”，并且在部署派生序列后添加了新的 Machine ，则派生序列将预期存在该新 Machine的传感器对象。由于原始范围未捕获此新 Machine 对象，因此派生序列现已过时。

从本体论（Ontology）中删除

要从本体论中删除由派生序列创建的传感器对象，请选择右侧的下拉箭头 部署 按钮并选择 从本体论（Ontology）中删除。系统将提示您提供用于删除传感器对象的操作类型。
