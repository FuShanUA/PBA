输出列元数据

您可以在 Code Repository Transforms 中读取和写入输出数据集的列描述和列类型类。

有关轻量级转换，请参见 输出列元数据.

在 Code Repository Transforms 中更新列描述

您可以通过提供可选的 column_descriptions 参数指定给 write_dataframe() 函数的 TransformOutput.

  • 此参数应为 dict ↗ ，其键为列名，值为列描述。列描述的长度最多为 800 个字符。
  • 代码将自动计算您的 DataFrame ↗ 上可用的列名与您提供的 dict ↗ 中的键的交集，因此它不会尝试为不存在的列添加描述。

from transforms.api import transform, Input, Output


@transform(
    my_output=Output("/my/output"),
    my_input=Input("/my/input"),
)
def my_compute_function(my_input, my_output):
    my_output.write_dataframe(
        my_input.dataframe(),
        column_descriptions={
            "col_1": "col 1 description"
        }
    )

列类型类

直方图 column_typeclasses 属性返回一个结构化的 Dict<str, List<Dict<str, str>>>，它将列名映射到其列类型类。

  • 中的每个类型类 List 是否为 Dict[str, str] object.
    • 本 Dict 对象只能使用以下键 "name" and "kind"。这些键分别映射到用户想要的相应字符串。

本体论管理器中的一个 column_typeclasses 值为 {"my_column": [{"name": "my_typeclass_name", "kind": "my_typeclass_kind"}]}.

from transforms.api import transform, Input, Output


@transform(
    my_output=Output("ri.foundry.main.dataset.my-output-dataset"),
    my_input=Input("ri.foundry.main.dataset.my-input-dataset"),
)
def my_compute_function(my_input, my_output):
    recent = my_input.dataframe().limit(10)

    existing_typeclasses = my_input.column_typeclasses
    existing_descriptions = my_input.column_descriptions

    my_output.write_dataframe(
        recent,
        column_descriptions=existing_descriptions,
        column_typeclasses=existing_typeclasses
    )
