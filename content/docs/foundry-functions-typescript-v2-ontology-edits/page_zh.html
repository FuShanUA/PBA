本体论编辑

除了编写从本体论读取数据的函数之外，您还可以编写用于创建对象以及编辑对象属性和对象间关联的函数。 本页面介绍了函数中可用的对象编辑 API。 有关编辑函数工作原理的更多详细信息，请参阅 概览页面。

为了让函数中创建的编辑真正生效，本体论编辑函数 必须配置为 函数支撑的操作。 以这种方式配置操作，您可以提供额外的元数据、配置权限，并在各种操作界面中访问该操作。 如 文档中所述，在操作之外运行编辑函数实际上不会修改任何对象数据。

标准本体论编辑使用编辑批次。TypeScript v2 还支持 暂存写入，它可在函数内提供写后读保证：编辑在同一执行中对后续查询立即可见，并且嵌套的暂存写入函数调用会共享这些编辑。当函数必须读取其刚刚写入的数据时，请使用暂存写入。暂存写入目前处于 Beta 阶段，在您的租户中可能不可用。

警告

使用编辑批次时,在编辑对象后立即搜索这些对象可能会返回非预期的结果。此注意事项不适用于暂存写入。请参阅 注意事项部分 以了解详情。

定义编辑函数

编辑本体论的函数必须使用 Edits 类型(该类型由 @osdk/functions 包导出)来显式声明将要编辑的实体。以下示例声明了一个新类型,表示对 Employee 和 Ticket 对象类型以及 Employee 与 Ticket之间关联类型的编辑。对多个实体的编辑需要使用 | 运算符进行连接。

Copied!
1
2
3
4
import { Employee, Person, Ticket } from "@ontology/sdk";
import { Edits } from "@osdk/functions";

type OntologyEdit = Edits.Object<Employee> | Edits.Interface<Person> | Edits.Object<Ticket> | Edits.Link<Employee, "assignedTickets">;

然后,你必须声明该函数返回一个由新类型的编辑组成的数组。

Copied!
1
2
3
export default function createNewTicketAndAssignToEmployee(): OntologyEdit[] {
    // ...
}

此批次用于跟踪函数中所做的所有编辑。

更新属性

对象属性

使用所创建的批次上可用的 update 方法修改一个或多个对象属性:

Copied!
1
batch.update(employee, { lastName: newName });

如果你尚未将 employee 对象实例加载到内存中,也可以通过引用该对象的 API 名称和主键来更新它:

Copied!
1
batch.update({ $apiName: "Employee", $primaryKey: 23 }, { lastName: newName });

后续对 lastName 属性值（属于 employee ）的访问在同一函数执行的后期将 不会 反映您在调用 update 时对编辑批次所做的更改。

有时，将对象类型的某个实例的所有属性值复制到另一个实例会很有用。以下示例将 employee2 的属性值分配给 employee1：

Copied!
1
batch.update(employee1, employee2);

请注意，现有对象的主键属性值无法更新。

接口属性

您可以使用 update 方法，通过本体论接口修改对象的接口属性。在下面的示例中， person 的类型是一个本体论接口，但底层实例是一个实现 Person 接口的对象。

该 update 方法接受两个参数，这一点对于对象类型和接口均适用。对于接口，该方法接受要修改的接口以及要修改的接口属性。

Copied!
1
batch.update(person, { firstName: newFirstName });

请注意，由底层对象的主键属性实现的接口属性无法更新。

更新关联

对于多对多关联， link 和 unlink 方法可在所创建的批次上使用，用于添加或删除对象之间的关联。

Copied!
1
2
3
4
5
// Assign an employee to an office.
batch.link(employee, "office", office);

// Unassign an office from an employee.
batch.unlink(employee, "office", office);

对于一对一和一对多关联，请使用 update 方法修改源对象的外键属性，该方法可在已创建的批次上使用。下面的示例演示了一对多关联：一个员工可以拥有多个工单，但每个工单只能属于一个员工。

Copied!
1
2
3
4
5
// Assign a ticket to an employee.
batch.update({ $apiName: "Ticket", $primaryKey: 13 }, { assignedEmployeeId: 52 });

// Unassign a ticket.
batch.update({ $apiName: "Ticket", $primaryKey: 13 }, { assignedEmployeeId: undefined });

与更新属性类似，如果您之前尚未加载该对象类型的具体实例，也可以使用 API 名称和主键来引用关联的任一端。

Copied!
1
2
3
4
5
// Assign a ticket to an employee.
batch.link({ $apiName: "Employee", $primaryKey: 23 }, "assignedTickets", { $apiName: "Ticket", $primaryKey: 12 });

// Unassign a ticket from an employee.
batch.unlink({ $apiName: "Employee", $primaryKey: 23 }, "assignedTickets", { $apiName: "Ticket", $primaryKey: 12 });

创建对象

对象

您可以使用 create 方法在编辑批次上创建新对象。创建新对象时，您必须为其主键指定一个值，并可选择性地初始化其他任何属性。

在此示例中，我们使用给定的 ID 创建一个新的 Ticket 对象，并设置其 dueDate 属性，然后将其分配给给定的 Employee ，具体做法是修改 assignedTickets 关联。为了简化对 dueDate新值的计算，我们使用 luxon 库。

import { Employee, Ticket } from "@ontology/sdk";
import { Client, Osdk } from "@osdk/client";
import { createEditBatch, Edits, Integer } from "@osdk/functions";
import { DateTime } from "luxon";

type OntologyEdit = Edits.Object<Employee> | Edits.Object<Ticket> | Edits.Link<Employee, "assignedTickets">;

export default function createNewTicketAndAssignToEmployee(
    client: Client,
    employee: Osdk.Instance<Employee>,
    ticketId: Integer,
): OntologyEdit[] {
    const batch = createEditBatch<OntologyEdit>(client);

    batch.create(Ticket, {
        ticketId,
        dueDate: DateTime.now().plus({ days: 7 }).toFormat('yyyy-MM-dd'),
    });

    // The new ticket does not exist in the Ontology as a concrete instance, but we can link it
    // by referencing its API name and primary key.
    batch.link(employee, "assignedTickets", { $apiName: "Ticket", $primaryKey: ticketId });

    return batch.getEdits();
}

接口

您可以通过接口创建新的对象实例，方法是调用 create 方法并指定接口、支撑对象类型和一组接口属性。提供的接口属性中必须有一个由支撑对象类型的主键属性实现。

Copied!
1
2
3
4
5
editBatch.create(Person, {
    $objectType: "Employee",
    firstName: "John",
    lastName: "Doe",
});

删除对象

对象

您可以通过在编辑批次上调用 delete 方法来删除对象。

在此示例中，我们删除分配给给定员工的所有工单：

Copied!
1
2
3
for await (const ticket of employee.$link.assignedTickets.asyncIter()) {
    batch.delete(ticket);
}

也可以使用主键而非实例来删除对象：

Copied!
1
batch.delete({ $apiName: "Ticket", $primaryKey: 12 });

接口

您可以通过接口调用 delete 方法来删除对象。

Copied!
1
batch.delete(person);

编辑结构体属性

对象类型和接口类型的本体论结构体属性均可使用 TypeScript v2 函数进行编辑。 结构体类型 在 TypeScript v2 中使用 TypeScript 接口进行定义。函数中的结构体类型可用于编辑本体论结构体属性，前提是它们包含与该结构体属性相同的字段，且字段名称与本体论结构体属性字段的 API 名称相匹配。

interface Address {
    street: string,
    city: string,
    state: string,
    country: string,
    zipcode: string,
}

export default function updateEmployeeAddress(
    client: Client,
    employee: Osdk.Instance<Employee>,
    newAddress: Address
): OntologyEdit[] {
    const batch = createEditBatch<OntologyEdit>(client);
    batch.update(employee, { address: newAddress });
    return batch.getEdits();
}
