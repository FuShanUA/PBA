创建 recipe

在 Foundry 中有多种创建 recipe 的方法。使用本指南了解如何从 Recipes 应用程序、Dataset Preview 和 Quiver 创建 recipe。

从 Recipes 应用程序

从导航侧边栏打开 Recipes 应用程序。

点击设置菜单下的 新建 Recipe 位于界面右上角。

然后，您将被引导选择要通过 recipe 监控的资源。

从 Dataset Preview

要从 Dataset Preview 应用程序创建新 recipe，请选择 创建 recipe 菜单中选择 操作 菜单中选择复选框来自定义可用的工具。

Recipe 允许您通过定义以下内容来发送数据集的预览：

  • 关注的列
  • 随预览一起发送的消息
  • 收件人
  • 发送预览的条件
  • 消息类型（电子邮件或通知）

预览中最多可以发送五列。

从 Reports

报告可以自动化，按计划发送给指定的收件人，形式可以是附件 PDF 或电子邮件内嵌图片。

从 Reports 操作 菜单下选择 按计划发送电子邮件.

然后，撰写随预览一起发送的消息。

最后，安排电子邮件的发送时间。选择报告发送的日期；时区将默认为 recipe 创建者的本地系统时区。
