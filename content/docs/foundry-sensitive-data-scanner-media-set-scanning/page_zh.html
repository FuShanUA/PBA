媒体集扫描

敏感数据扫描器(SDS)可扫描媒体集,以查找与特定正则表达式匹配的数据。SDS 会将媒体集中的媒体项转换为文本,然后针对提取的文本运行该正则表达式。所使用的文本提取方法取决于所扫描的媒体集类型。

文本提取方法如下:

  • 图像和 PDF 媒体集: 光学字符识别(OCR)
  • 音频媒体集: 转录

媒体集只能使用仅限内容的正则表达式进行扫描 匹配条件.

问题 匹配操作 将自动聚合。这意味着，对于给定的媒体集，即使有多个媒体项与给定的匹配条件相匹配，也只会针对该媒体集创建一个问题。

文本提取限制

OCR 和音频转录可能无法完全精确地复制原始媒体内容中的文本。例如，OCR 可能会将一个单词拆分成两个字符串、将字母转换为大写，或者从不含文本的图像中错误地提取文本。这可能会导致在与正则表达式匹配时出现意外行为，尤其是在正则表达式假定文本符合特定格式或大小写规则的情况下。

要查看 SDS 运行正则表达式时所依据的文本，您可以创建一个 Pipeline Builder 以媒体集作为输入，并针对媒体集类型应用以下转换的管道：

  • PDF 媒体集： 使用 OCR 从 PDF 中提取文本。
  • 图像媒体集： 使用 OCR 从图像中提取文本。
  • 音频媒体集： 将音频转录为文本。

检查媒体集扫描结果

选择 打开扫描详情 按钮以查看扫描配置并检查结果。与已扫描的数据集类似， 扫描结果 部分是 SDS 列出所有包含扫描匹配结果的媒体集及其精确匹配条件的地方。

将光标悬停在任一匹配条件上，即可渲染触发该匹配条件的媒体项预览。

您还将看到已匹配和已扫描的媒体项总数。如果某个媒体集包含大量匹配结果，Foundry 将显示前十个匹配结果的预览。

选择缩略图可打开媒体项的详细视图，以便进一步探索，例如放大图像或查看多页文档。

优化 SDS 性能

SDS 会从每个媒体项中提取文本，因此扫描媒体集的计算成本可能很高。您可以使用以下策略来管理计算成本并优化扫描性能：

  • 子集采样： 为了限制计算成本并缩短扫描时长，您可以利用 采样策略 如果您只想扫描媒体集中的部分媒体项。类似于对数据集的行进行采样，这些策略同样适用于对媒体集中的媒体项进行采样。
  • 定时扫描： 如果您想对媒体集运行重复扫描，可以使用低频的 定时扫描，例如每周或每月运行一次，而不是连续扫描。

增量扫描

在重复扫描中，SDS 会扫描媒体集 以增量方式。这意味着 SDS 将仅扫描自上次成功扫描以来新增或更新的媒体项。这显著减少了周期性媒体扫描所需的时间和计算资源，因为 SDS 无需处理已扫描过的媒体项。

如果扫描是以增量方式执行的，结果表中的相应扫描行将显示一个信息图标。

您可以在扫描结果的上下文菜单中选择"查看扫描历史"来打开资源的扫描历史。扫描历史会显示之前所有增量扫描的时间线，包括已扫描项目的数量以及检测到的匹配条件。历史视图顶部的卡片会汇总展示所有增量扫描中检测到的匹配条件概览。您还可以选择对整个资源触发全量重新扫描。建议在从数据集中删除 PII 后执行此操作，因为这有助于您验证是否仍会检测到匹配条件，或者所有匹配的数据是否已被删除。

您也可以对整个资源触发全量重新扫描。在从数据集中删除 PII 后，请运行全量重新扫描，以验证是否仍会检测到匹配条件，或者所有匹配的数据是否已被删除。
