教程：添加散点图 widget

假设您想要创建一个散点图 widget 来显示路线指标，展示距离和时间值。选择 微件 左上角的按钮，然后选择 Chart > Scatter Plot 以向您的应用程序添加散点图 widget。它会预先填充一些示例数据，您可以在继续之前从右侧编辑器面板中清除这些数据。

首先，将图表 widget 重命名为易于识别的名称，例如 w_routeMetrics.

我们想要沿 x 轴绘制路线的平均距离。这意味着您必须设置 X 值 to "{{q_routeMetrics.avg_distance}}".

接下来，沿 y 轴绘制路线的持续时间。设置 Y 值 to "{{q_routeMetrics.avg_time}}" 菜单中选择 同步至数据集 标签页。

为了使散点图更易于阅读，请为您的坐标轴添加标签。选择 坐标轴 选项卡，并更改 名称 第一个 X 轴 对象的 x1 to Distance，并添加一个标签，例如 Distance (miles) 来描述所绘制的信息。您还可以打开网格线，以帮助确定每个点在图表上的位置。

命名您的 Y 轴 Duration，并按如下方式进行配置：

最后，为您的点设置不同的大小。我们希望点的大小随路线的繁忙程度而变化。为此，请切换回 同步至数据集 选项卡并设置 半径 to "{{q_routeMetrics.num_flights}}".

再次检查图表。似乎有些不对劲，因为图表现在被填满了。这是因为 半径 值在提供的值与半径的像素数之间按 1:1 绘制，而我们的某些路线有超过 150 个航班。您必须缩放半径值。您可以通过在查询中计算一个“显示”值来实现。您可以对此进行硬编码，但使用 变量 可以让您在以后轻松进行更改，而无需编辑查询。

选择 变量 顶部栏中的选项卡以打开 变量 窗口。在右下角创建一个新变量。将新变量命名为 v_routeCountDisplayScale 并设置值为 100.

返回 q_routeMetrics widget 并添加一个新列：

COUNT(flight_id)/{{v_routeCountDisplayScale}} as num_flights_disp

在此期间，为每行生成一个显示标签：

CONCAT(origin, ' -> ', dest) as route_name

SELECT
    origin,
    dest,
    AVG(distance) as avg_distance,
    AVG(actual_elapsed_time) as avg_time,
    COUNT(flight_id) as num_flights,
    COUNT(flight_id)/{{v_routeCountDisplayScale}} as num_flights_disp,
    CONCAT(origin, ' -> ', dest) as route_name
FROM "foundry_sync"."{{v_flightTable}}"
GROUP BY
    origin,
    dest
ORDER BY
    COUNT(flight_id) DESC
LIMIT 50

返回 w_routeMetrics widget 并调整 半径 配置以引用 num_flights_disp 列而不是 num_flights.

甘特图

甘特图沿分类 y 轴以水平条形显示基于时间的数据。您可以使用甘特图来可视化日程安排、项目时间线、事件持续时间，以及任何包含跨越开始时间和结束时间的项的数据集。甘特图共享 图表组件属性 如上文所述。

树状图

树状图小部件提供了一种灵活的方式来以一组嵌套矩形可视化分层数据。它有助于发现其他可视化中难以察觉的模式。

树状图用于可视化绝对数量（size）对于给定实体（label），该实体可能是某些（可选的） category 的一部分，并带有某些（可选的）相对数量（density）。 每个单元格的矩形具有：与其成比例的面积 size；由其定义的颜色 density 和 category；以及由其给定的名称 label.

可以使用此图表可视化的数据集的一些示例：

  • 股票（label）属于某个行业（category）并占有一定的市场份额（size）且有一定的价格涨跌幅（density)

  • 工厂位置（label）按区域（category）划分，生产一定数量的商品（size）并带有误报率（density)

  • 集群的节点（label）具有存储空间（size）以及一定的存储空间利用率百分比（density)

  • 人口规模（size）属于某些国家（label）归属于某个世界区域（category)

数据配置

  • label （可选）：显示在每个单元格上的名称
  • size：决定单元格矩形的大小
  • density （可选）：决定单元格颜色的深浅
  • category （可选）：决定单元格的分组，从而决定单元格的颜色

在默认示例中，单元格矩形对应于单元格 size。有两个类别， I 和 II。请注意， H 具有最大的尺寸（45），因此是最大的矩形。 H 也具有最小的密度（3），所以它的颜色最深（可以在颜色面板下的复选框中翻转渐变方向）。

颜色配置

根据是否启用 categories 和/或 densities ，可以使用不同的着色配置。

启用类别和启用密度

当两者 categories 和 densities 都启用时，单元格的颜色根据 色相-饱和度-明度 (HSV) ↗ 色彩空间中的渐变来定义。为每个类别定义一个色相。可以提供色相列表（0 到 360 之间的数字）或将类别名称映射到色相的字典。然后，所有类别的渐变都使用相同的已定义起始饱和度和明度。渐变通过渐变类型（变亮、变暗、增加饱和度、降低饱和度）和渐变强度来定义。

仅启用类别

仅启用 categories 时，您可以为类别指定颜色列表或将类别名称映射到颜色的字典。

颜色可以是十六进制（#FF0000、#00FF00）或规范名称（例如 red、green）。

仅启用密度

仅启用 densities 启用时，您可以定义一个颜色列表，将其作为带渐变的范围应用。您必须至少提供两种颜色来定义颜色渐变，但可以提供更多颜色以更精细地定义此颜色渐变。

颜色可以是十六进制（#FF0000、#00FF00）或规范名称（例如 red、green）。

禁用类别和禁用密度

当两者 categories 和 densities 都禁用时，您可以定义一个颜色列表作为调色板。它必须是长度与数据点数量相同的颜色列表。

颜色可以是十六进制（#FF0000、#00FF00）或规范名称（例如 red、green）。

杂项配置

可以进行一些可选的杂项配置：

  • 单元格样式

    • 每个单元格的边框宽度
    • 边框颜色
    • 单元格的标签
    • 单元格的工具提示

  • 图例

    • 图例位置（上、下、左、右）
    • 图例标签（用于图例的标题）

  • 单元格生成方式的平铺策略。平铺策略由 d3 ↗ 定义：Binary、Dice、Resquarify、Slice、Slice Dice、Squarify。

  • 选择（多选或单选）
