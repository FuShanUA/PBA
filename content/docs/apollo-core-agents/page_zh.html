Apollo 代理

Apollo 代理是在托管的 Spoke 环境中运行的任何代理，负责执行 Apollo Hub 提供的计划，并将报告状态回传给 Hub。在Spoke 控制平面中运行的代理示例是 Helm Chart Operator。

Apollo 代理负责与关键服务进行通信以管理环境：

  • Apollo Hub，提供 Apollo 代理需要执行的计划的最新信息。Apollo 代理与 Apollo Hub 交互，以了解需要执行哪些计划，并提供这些计划状态的更新。
  • 为环境声明的制品仓库，负责提供和存储 Helm Chart 和容器镜像。Apollo 代理必须能够从配置的制品仓库中拉取 chart 和镜像，以在环境内实施计划。

Apollo 代理仅通过来自环境的加密、单向出站请求与这些服务进行通信。这使环境操作员能够对所有已列入允许列表的网络流量拥有最终控制权。

传输中加密

在环境注册过程中，会生成一个特定于该环境的唯一加密密钥。该证书由 Apollo Hub 签名，并由 Apollo 代理用于返回 Hub 的所有通信，从而唯一地标识流量源自该代理，并防止身份冒用。

HTTP 代理支持

如果您的受管 Spoke 环境位于 HTTP 代理服务之后，您必须为 Apollo 代理配置相应的 HTTPS_PROXY 和 NO_PROXY 值，以确保该代理能够与 Hub 通信。
