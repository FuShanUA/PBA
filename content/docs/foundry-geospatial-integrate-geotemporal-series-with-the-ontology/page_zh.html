将地理时间序列与本体论集成

要在本体论中建立地理时间序列，以支持Palantir应用程序（例如Gaia地图）中的分析和可视化，您将使用 Pipeline Builder 来：

  • 创建一个 地理时间序列同步 ，使用 地理时间序列输出。
  • 创建一个 地理时间序列对象类型 ，使用 对象类型管道输出。
  • 将地理时间序列同步连接到地理时间序列对象类型，使用 地理时间序列引用（GTSR） 属性类型。该对象类型还包含实时和静态信息，例如船舶的当前位置和呼号。

如果您计划将本体论中的数据添加到Foundry 地图 而 非 Gaia，请使用 时间序列 来查看和分析与地理空间或地理时间对象相关联的数据。在我们的 地理空间时间序列用例教程中了解更多信息。

查阅 地理空间常见问题页面 ，或联系Palantir支持团队咨询其他问题，例如根据您的注册情况和具体用例，应使用哪种集成类型将地理时间数据索引到本体论中。

按照以下说明操作，将地理时间序列同步输出添加为地理时间序列对象类型的引用。

在Pipeline Builder中创建新管道

  1. 导航到 Pipeline Builder 并选择绿色的 新建管道 按钮。
  2. 为管道命名，并选择保存该管道的项目。
  3. 请先选择 流式管道 ，然后再选择 创建管道。时空序列也兼容批量管道，但流式管道支持对被跟踪实体进行实时更新。

导入并转换时空数据集

请查阅现有的 时空数据建模文档 ，然后再继续操作。

确定将为您的时空序列同步和对象类型提供支撑的流式 数据集 ，并按照以下说明将它们添加到您的管道中。

  1. 选择 添加 Foundry 数据 （如果您已将数据摄取到平台中）。
  2. 在 添加数据 对话框中搜索您的文件，然后选择 + 图标，将每个数据集添加到您的管道中。
  3. 选择 添加数据 （位于 添加数据 对话框右下角）。

创建时空序列同步

详细了解如何在 Pipeline Builder 中配置时空序列同步。

至少，您的流式数据集应包含用于捕获被跟踪实体随时间移动情况的列，例如其在给定时间戳下的纬度和经度，以及一个 string 列，使您能够将地理时间序列同步关联到对象类型。包含随时间变化的数据的列被称为 动态 字段，而保持不变的列（例如实体名称）则被称为 静态。

您的转换需求可能因流式数据集在摄取到 Foundry 时的原始状态而异。下面概述的示例数据包含以下各列，这些列映射到同步的 主要字段：

  • Series_ID： 一个 string 用于将地理时间序列同步关联到对象类型的列。 了解有关配置序列 ID 的更多信息。
  • Timestamp： 一个 timestamp 包含实体位置所记录时间的列。
  • Geopoint： 一个 geopoint 包含实体经纬度对的列。

该数据集包含 额外 的列，这些列将映射到地理时间序列同步的 属性 ，但 并非 同步在 Palantir 地图应用程序中正常运行所必需的。

如有必要，请使用 Pipeline Builder 的 Cast 和 Create GeoPoint 转换，以准备您的原始流式数据集并将其输出为地理时间序列同步。

请按照以下说明，从转换后的流式数据创建地理时间序列同步输出：

  1. 选择流式数据集或转换节点以显示垂直菜单栏，您将在其中选择金色的 + 图标以添加 新的地理时间序列同步 输出。
  2. 输入名称，并可选择在 名称和图标中更改同步的默认图标。
  3. 选择您的 目标命名空间 ，Foundry 会将同步写入其中。
  4. 将流式数据集中的相关列分配给同步的 主要字段。
  5. 设置同步的 观测架构 （如果已存在）。如果 不 存在，则可以将此字段留空；Foundry 会根据同步中映射的属性生成新的观测架构。 了解更多关于观测架构的信息。
  6. （可选）切换 实时 图标（位于任何其他 属性 的右侧），以将其中一个或多个标记为静态。

Foundry 会记录 实时 属性在每个新观测中的值，例如实体在给定时间戳处的速度。如果将某个属性标记为静态，Foundry 会记录该属性的最新值，并将其应用于序列中的所有观测。

  1. （可选）配置 样式 以控制同步的下游渲染。部署后，您还可以编辑地理时间序列对象类型的默认轨迹样式，位置在 几何样式 选项卡（位于 Ontology Manager）。
  2. （可选） 配置该集成的存储设置。
  3. 引用一个 接口 ，用于表示您的地理时间序列对象类型的属性，方法是选择 引用接口 ，然后在您的地理时间序列同步中映射这些属性。

该 Geotemporal Series 接口可在 Palantir 的核心本体论（Core Ontology）中安装，该本体论适用于大多数用例。如果您无法在 Ontology Manager 中访问该接口，请联系 Palantir 支持团队将其安装到您的租户中。

  1. 选择 保存 以保存您的地理时间序列同步。

创建您的地理时间序列对象类型

接下来，您将转换您的地理时间数据集，以创建一个地理时间序列对象类型并将其链接到您的地理时间序列同步，此链接称为 地理时间序列引用（GTSR）。

  1. 在您的管道中选择地理时间数据集，然后选择 转换 以插入新的转换。
  2. 搜索并选择 应用表达式。
  3. 选择标签为 Column, expression, or value 的输入字段，并从 列中选择数据集的主键列。在本示例中，数据集的 mmsi 列包含唯一的船舶标识符，可用作主键。
  4. 创建一个名为 Series_ID 的新列，该列是数据集唯一标识符的副本，例如 mmsi。您将使用此新列将您的地理时间序列同步关联到该对象类型。

  1. 选择 应用 ，然后再保存对管道的更改并预览您的数据。

在转换您的地理时间数据集后，请按照以下说明，使用 Pipeline Builder 的本体论输出来创建地理时间序列对象类型。

  1. 选择您刚刚创建的转换节点以呈现垂直菜单栏，您将在其中选择金色的 + 图标来添加 新对象类型 输出。

  1. 输入名称，并可根据需要在 名称和图标中为您的同步更改默认图标。
  2. 选择显示的属性右侧的省略号图标，以设置主键和标题属性。

  1. 选择您的 Series_ID 属性旁边的关联图标，然后通过选择 地理时间序列 > 从此管道将 GTSR 属性映射到您的对象类型。您还可以选择来自其他管道的地理时间序列同步，方法是选择 从 Foundry... 并选择相应的 地理时间序列集成。

一个对象类型最多只能有一个地理时间序列引用属性，并且该属性不能是地理时间序列引用的数组。

  1. 选择 实现接口 位于屏幕底部，然后选择您的地理时间序列同步所引用的同一接口。

  1. 选择 下一步 以在接口上实现所需的属性，然后 确认并实现 以在保存更改之前返回 Pipeline Builder 中的对象类型创建窗口。

部署您的管道

在配置地理时间序列同步、创建对象类型和接口并通过 GTSR 在两者之间建立关联后，请按照以下说明部署您的管道：

  1. 请确保对管道所做的所有更改均已保存。

  1. 选择 部署 以呈现 部署此管道 面板。

  1. （可选） 部署时重放 以从指定时间点重新运行您的管道。根据流的大小，重放管道可能会影响管道的部署速度。 了解有关 Pipeline Builder 中流式管道的其他选项的更多信息。
  2. 选择 部署管道。

管道部署完成且对象类型在您的本体论中创建后，您即可 将其观测数据可视化 在地图上。

可视化您的地理时间数据

仅当您的注册包含 Gotham 时，才能访问 Gaia。如对 Gaia 的访问权限或其平台内提供的其他文档有任何疑问，请联系 Palantir 支持团队。

在您的地理时空序列与本体论集成后，您就可以 将其关联的对象类型添加到您的 Gaia 地图。

在 Ontology Manager 中对您的对象类型进行类型映射， 以便 Gotham 能够访问它并将其渲染为 Gaia 中的数据图层。

要使用 Pipeline Builder 的高级地理时空功能，您 必须 对您的对象类型进行类型映射，以便 Gotham 能够发现它， 即使 您的注册中包含 Map Rendering Service。此要求包括将实体的位置作为 地理时空序列进行跟踪的用例。请查看 关于何时对对象类型进行类型映射的指南 以了解更多详情。

选择通过与本体论连接的地理时间图层渲染的 Foundry 对象，然后选择地图右下角的按钮以打开观测日志。该日志列出了在对象类型的支撑地理时间集成中配置的所有实时属性。使用滚动窗口选择器来控制要加载多久之前的观测记录。每行都提供一个 缩放至 按钮，点击后可跳转到该观测记录的位置。选择某条观测记录后，对象将移动到其历史轨迹上的对应点。当有新的观测记录可用时，会出现一个刷新按钮。

Ontology Manager 中的地理时空序列引用（GTSR）属性

您也可以直接在 Ontology Manager中配置 GTSR 属性类型。使用 您在上面创建的地理时间序列同步 ，在 新建的 或相同的 Pipeline Builder 管道中：

  1. 导入 或使用您创建该地理时间序列同步时所用的同一地理时间数据集。
  2. 在您的管道中选择该地理时间数据集，然后选择 “转换” 以插入新的转换。
  3. 搜索并选择 “创建地理时间序列引用” 表达式。

  1. 对于 Series ID ，请选择您之前为该地理时间序列同步选作序列 ID 的同一列。
  2. 对于 Geotemporal series integration RID ，请选择 RID ，取自您 已部署的 地理时间序列同步。
  3. 选择 “应用” ，然后再保存对管道的更改并预览您的数据。
  4. 退出转换并选择该转换节点以显示垂直菜单栏，您将在其中选择金色的 + 图标以添加 “新建数据集” 输出。
  5. 部署该管道，其中的数据集包含您的地理时间序列列。

在 Ontology Manager 中， 创建新的对象类型 ，并将您创建的新数据集用作 数据源。 对应的 Geotemporal Series Reference 属性类型应会根据您在 Pipeline Builder 中创建的列自动配置。如果未自动配置，您可以添加或 编辑现有属性类型 ，并将其设置为 Geotemporal Series Reference 类型。

您必须设置正确的 地理时空序列同步的 RID 才能继续。您还应该 实现地理时空接口 在此工作流中。

一个对象类型最多只能有一个地理时空序列引用属性，且该属性不能是地理时空序列引用的数组。
