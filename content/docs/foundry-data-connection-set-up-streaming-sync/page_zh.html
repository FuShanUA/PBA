设置流式同步

A 同步 是一项从源读取特定数据并将其摄取到 Foundry 中的任务。例如，如果您有一个包含多个表的关系型数据库源，您可以配置一个同步，将特定的表摄取到 Foundry 中。

流式同步与非流式（即批量或增量）同步类似 同步 但存在一些差异。主要区别在于，批量或增量同步会定期运行，而流式同步会持续运行，以尽可能低的延迟将数据拉取到 Foundry 中。

下面，我们将讨论创建同步所需的步骤：

  1. 定义数据 以从源进行同步。
  2. 定义一个位置 在 Foundry 中用于发送数据。
  3. 组织 流式同步。
  4. 运行 流式同步。

在本教程中，我们将使用 Kafka 源来设置同步。

第 1 部分：定义数据

首先，决定您希望将哪些数据同步到 Foundry 中。选择您的 流式源 在 Data Connection 中，然后选择右上角可用的操作：

  • 浏览并创建同步： 如果您的源类型支持 探索并创建同步，则会出现此选项，允许您在创建同步的同时浏览您的数据源。
  • 创建同步： 如果您的源类型不支持源浏览，则会出现此选项。

源探索

如果您的源类型支持源浏览，您将进入 探索源 Data Connection 中的页面，该页面显示可同步的数据。浏览视图的界面取决于您所使用的源类型。例如，Kafka 源浏览允许您查看 Kafka broker 上存在的 主题 ↗ 并预览这些主题中包含的数据。

在 Kafka 浏览视图中，您可以在页面左侧的列表中查看现有主题。

选择某个主题后，您可以预览该主题中的数据样本。

第 2 部分：定义同步位置

接下来，您需要决定将同步的数据集保存在 Foundry 中的位置。数据集的位置将根据 创建同步数据集时，推荐的最佳做法是将其与连接器一起保存。这使得对来自给定连接器的所有数据进行统一权限设置成为可能，这对于创建数据管道非常有帮助。了解更多关于 权限决定谁有权访问生成的数据集。

我们建议将同步的数据集与其源一起保存在同一个 Project 中，使它们具有相同的权限；匹配的数据集和源权限在创建数据管道时非常有用。 了解更多关于数据管道推荐的项目结构。

选择同步位置后，点击 创建流式同步 在右上角。

第 3 部分：配置流式同步

现在，您将进入 同步创建 Data Connection 中的页面，您可以在其中为同步定义特定于源的配置和核心流式配置。

  • 特定于源的配置： 位于配置页面顶部，这些选项取决于您的源类型，并配置传递给您所连接的特定源的参数。
  • 核心流式配置： 位于特定于源的配置下方，这些选项是所有流式同步通用的。核心配置包括吞吐量、架构和同步目标。

您可以在源配置选项中的 计算配置文件设置 （位于附加设置菜单中）下选择计算配置文件大小，从而为流式同步指定计算资源。对于使用 ）或您的代理网络（如果使用 的源，此选项不可用，因为其计算在代理主机上运行。

接下来，选择您的流的 吞吐量 。吞吐量决定了将创建的分区数量。选择更多的分区数量可以实现更高的吞吐量。选择 正常 吞吐量将允许该流达到最高 5 MB/s 的速度。

然后指定输入数据的架构；默认情况下，架构会从源推断得出，但如有必要可以覆盖。

配置同步后，选择 创建同步 使用

现在您的同步已创建，您将被带到 概述 标签页。

第 4 部分。运行同步

现在，您已准备好运行同步。选择 概述 选项卡以查看新同步的摘要，包括输出数据集、位置和可用操作。

点击设置菜单下的 开始时间 以开始将数据从外部流同步到 Foundry 中。

要查看流数据，请导航到您在创建同步时配置的流，以查看流预览页面。您应该能看到记录从 Kafka 主题流入流中。

后续步骤

现在您已成功运行了同步，了解如何 调试失败的流, 将数据推送到流中 使用基于推送的摄取，或者 将您的流与本体论集成.
