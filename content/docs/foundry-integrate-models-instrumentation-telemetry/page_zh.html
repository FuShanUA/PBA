模型中的插桩与遥测

可以从您的模型中发出某些类型的遥测数据，以便对生产环境中的推理工作流进行监控和调试。

本页面所述的功能适用于核心机器学习模型。有关语言模型，请参阅 语言模型适配器 参考文档。

要了解如何查看模型发出的遥测数据，请参阅我们的 AIP 可观测性文档。

支持的遥测类型

模型支持自定义日志和自定义 span。指标不由用户定义；Foundry 会记录对模型的所有推理调用的总执行时长。

每次调用模型时，都会自动创建一个覆盖该次推理调用总执行时长的 span，以及一条请求日志。

环境依赖

必须将 OpenTelemetry 库显式添加到您的模型环境中。请添加以下软件包：

  • opentelemetry-api 和 opentelemetry-sdk:发出自定义日志和自定义 span 所必需。
  • opentelemetry-instrumentation:自动对模型发出的出站网络请求进行插桩所必需。

日志

您可以在模型中发出自定义日志，并回溯查看这些日志。以下示例演示了如何使用标准 Python logging 模块。

Foundry 会为 OpenTelemetry SDK 设置全局日志记录器提供程序，因此通过 Python 的 logging 模块写入的日志会自动路由到 Foundry。如果您想使用第三方库进行日志记录，必须将其配置为通过从全局日志记录器提供程序获取的日志记录器来发出日志。

Copied!
1import logging
2
3import palantir_models as pm
4
5logger = logging.getLogger(__name__)
6
7class ExampleModelAdapter(pm.ModelAdapter):
8    ...
9
10    def predict(self, df_in):
11        logger.info("Running inference on %d rows.", len(df_in))
12        return self.model.predict(df_in)

Span

您还可以在模型中创建自定义 Span，以跟踪单次推理调用中特定操作的持续时间。以下示例演示了如何围绕某个预处理步骤创建自定义 Span。

Foundry 将为 OpenTelemetry SDK 设置全局追踪器提供程序（tracer provider），您将能够从中获取追踪器。如果您希望使用第三方库进行追踪，则必须将其配置为通过从全局追踪器提供程序获取的追踪器来发出追踪数据。

Copied!
1import palantir_models as pm
2
3from opentelemetry import trace
4
5tracer = trace.get_tracer(__name__)
6
7class ExampleModelAdapter(pm.ModelAdapter):
8    ...
9
10    def predict(self, df_in):
11        with tracer.start_as_current_span("preprocess"):
12            features = self._preprocess(df_in)
13
14        with tracer.start_as_current_span("inference"):
15            return self.model.predict(features)
