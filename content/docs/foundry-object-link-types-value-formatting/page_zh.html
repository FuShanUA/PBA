添加值格式化

值格式化 是指将特殊的格式化器应用于属性值，从而将原始值转换为更易读的形式。在下图中，左侧（之前）显示了 weight 和 value 列，未应用任何格式化。右侧（之后）将单位（“kg”）应用于 weight 列，而 value 列则以更紧凑的形式显示，并带有货币符号（“$100K”）。这两个都是数值格式化的示例。本体论还支持日期和时间格式化，以及用户 ID 格式化、资源 RID 格式化和工件 GID 格式化。

支持的值格式化

类型描述
数值格式化添加货币/单位/前缀、各种类型的记数法（紧凑、科学）以及百分比。请参阅 数值格式化部分 以了解更多详情。
日期和时间格式化以特定格式和特定时区渲染时间戳和日期。
Foundry ID 格式化将 Foundry ID 显示为用户的名字和姓氏或组名。
资源 RID 格式化将 Foundry 资源 ID（RID）显示为图标和资源名称，并带有可点击的链接以跳转至该资源。
工件 GID 格式化将制品全局 ID (GID) 显示为图标和制品名称，并附带可点击的链接，用于跳转到该制品。

添加值格式设置

在属性编辑器中：

  1. 选择要添加值格式设置的属性。
  2. 在属性窗格右侧面板中，您会看到根据属性基础类型而定的格式设置类型（值格式设置、数值格式设置、日期和时间格式设置等）。开启该格式设置。
  1. 数值格式设置与日期和时间格式设置还提供了其他格式设置选项，如下所述：
    • 数值格式设置选项
    • 日期和时间格式设置选项
  2. 选择可用的格式设置选项时，您将看到属性值在应用新格式设置后如何呈现的预览。

数值格式设置选项

名称描述用法
数值格式设置开/关切换开关。切换此开关可移除/添加数值格式设置。
基础类型包含各种可用的格式设置类型（货币、标准单位、百分比、前缀/后缀、固定值），以及每种类型的示例和描述。如果 Capacity in Pounds 具有关联单位，请选择 标准单位 （在此下拉列表中）。
使用分组添加区域设置感知的逗号分隔符。开启此选项后，123456 将显示为 123,456。
记数法包含紧凑/科学和工程记数法。选择紧凑记数法可近似表示数值，例如 123K。
最大小数位数小数点后显示的最大位数。小数位数更多的数值将被四舍五入到该位数。设置为 2 可将 3.14159 显示为 3.14。
最小小数位数小数点后显示的最少位数。较短的数值将用末尾的零填充。设置为 2 可将 3.5 显示为 3.50。
最大/最小有效位数显示的最多和最少有效位数，从第一个非零数字开始计算。将最大有效位数设置为 3 可将 3.14159 显示为 3.14。
最小整数位数小数点前显示的最少位数，用前导零填充。设置为 2 可将 5 显示为 05。
预览结果查看并测试数字格式化。在输入框中输入任意数字，只要与您预期在属性值中看到的数字类似，即可预览格式化效果。

日期和时间格式化选项

名称描述示例
日期仅显示日期（不含时间）Wed, Jul 22, 2020
日期和时间同时显示日期和时间，采用长格式Wed, July 22, 2020, 1:00:00 PM
日期和时间（短）同时显示日期和时间，采用短格式Jul 22, 2020, 1:00 PM
ISO 即时时间同时显示日期和时间（ISO 8601 格式）2020-07-22T13:00:00.000Z
相对于当前时间相对于现在的日期8 minutes ago
时间仅时间（不含日期）1:00 pm

格式化 相对于现在时，应用程序只会以相对方式格式化 24 小时以内的时间。超过 24 小时后，将以 日期和时间（短） 格式渲染，并显示星期几： Wed, Jul 22, 2020, 1:00 PM。

时区

如果您要格式化时间戳，可以指定渲染时间戳时所使用的时区，既可以是您输入的静态时区，也可以是应用程序用户的当前时区。输入静态时区时，您可以通过输入 UTC 偏移量或区域设置名称来搜索时区。

用户 ID 格式化

值格式化可应用于作为 Foundry/Multipass 用户 ID 或组 ID 的字符串，并可通过选择 用户名或组名 选项，将其转换为显示用户的名字和姓氏或组名称。此值格式化选项通常在您创建了 操作 用于编辑属性并将用户 ID 或组 ID 存储在其中一个属性字段中。在支撑数据中，此信息将存储为用户的 Foundry 用户 ID 或组 ID，并且可以应用值格式化来渲染用户的名称或组，而不是 ID。

常见问题解答

这能否与现有的类型类配合使用？

在 UI 中，值格式化优先于现有的类型类。如果您同时配置了两者，则会显示值格式化。不过，您可以在一个属性上使用值格式化，而在另一个属性上使用类型类。

这能否与对象视图中的可编辑属性配合使用？

值格式化适用于配置为 内联编辑的属性。具有旧版 hubble:editable 类型类的属性将禁用值格式化。
