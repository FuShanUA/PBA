添加值格式化

数值格式化 指对属性的值应用特殊的格式化程序，将原始值转换为更易读的形式。在下图中，左侧（早于）显示的是 weight 和 value 列，未应用任何格式化。右侧（晚于）的 weight 列应用了单位（“kg”），而 value 列以更紧凑的形式显示，并带有货币符号（“$100K”）。这些都是数值格式化的示例。本体论还支持日期和时间格式化，以及用户 ID 格式化、资源 RID 格式化和工件 GID 格式化。

支持的值格式化

类型描述
数值格式化添加货币/单位/前缀、各种类型的记数法（紧凑、科学）以及百分比。请参阅 数值格式化部分 以了解更多详情。
日期和时间格式化以特定格式以及特定时区渲染时间戳和日期。
Foundry ID 格式化将 Foundry ID 显示为用户的名字和姓氏或组名。
资源 RID 格式化将 Foundry 资源 ID（RID）显示为图标和资源名称，并带有可点击的链接，可导航到该资源。
工件 GID 格式化将工件全局 ID（GID）显示为图标和工件名称，并带有可点击的链接，可导航到该工件。

添加值格式化

在属性编辑器中：

  1. 选择要添加值格式化的属性。
  2. 在属性窗格的右侧面板中，您将看到根据属性的基本类型而定的格式化类型（值格式化、数值格式化、日期和时间格式化等）。开启该格式化。
  1. 数值格式化和日期和时间格式化还提供其他格式化选项，如下所述：
    • 数值格式化选项
    • 日期和时间格式化选项
  2. 当您选择可用的格式化选项时，您将看到应用新格式化后属性值的渲染效果预览。

数值格式化选项

名称描述用法
数值格式化开/关切换。切换此项可移除/添加数值格式化。
（在包含各种可用的格式化类型（货币、标准单位、百分比、前缀/后缀、固定值）以及每种类型的示例和描述。If Capacity in Pounds 具有关联的单位，请选择 标准单位 从此下拉菜单中选择。
使用分组添加符合区域设置的逗号分隔符。开启此项可将 123456 变为 123,456。
记数法包含紧凑/科学和工程记数法。选择紧凑可对值进行近似，例如 123K。
最大小数位数小数点后显示的最大位数。小数位数更多的值将四舍五入到此长度。设置为 2 以显示 3.14159 as 3.14.
最小小数位数小数点后显示的最少位数。较短的值将以尾随零填充。设置为 2 以显示 3.5 as 3.50.
最大/最小有效位数显示的最大和最少有效位数，从第一个非零数字开始计算。将最大有效位数设置为 3 以显示 3.14159 as 3.14.
最小整数位数小数点前显示的最少位数，以前导零填充。设置为 2 以显示 5 as 05.
预览结果查看和测试数值格式化。在输入框中输入任意数字（类似于您期望在属性值中看到的数字），即可预览格式化效果。

日期和时间格式化选项

名称描述示例
日期仅日期（无时间）Wed, Jul 22, 2020
日期和时间日期和时间，长格式Wed, July 22, 2020, 1:00:00 PM
日期和时间，短格式日期和时间，短格式Jul 22, 2020, 1:00 PM
ISO 即时时间日期和时间（ISO 8601 格式）2020-07-22T13:00:00.000Z
相对当前时间相对于当前时间的日期8 minutes ago
时间仅时间（无日期）1:00 pm

格式化时 相对当前时间，应用程序将仅以相对时间格式显示 24 小时以内的时间。超过此时间后，将以 日期和时间，短格式 形式显示，并包含星期几： Wed, Jul 22, 2020, 1:00 PM.

时区

如果要格式化时间戳，可以指定渲染时间戳所用的时区，可以是您输入的静态时区，也可以是应用程序用户的当前时区。输入静态时区时，您可以通过输入 UTC 偏移量或区域设置名称来搜索时区。

用户 ID 格式化

值格式化可应用于 Foundry/Multipass 用户 ID 或组 ID 的字符串，并通过选择 用户名或组名 选项将其转换为显示用户的名字和姓氏或组名。此值格式化选项通常在您创建了 操作 来编辑属性并将用户 ID 或组 ID 存储在其中一个属性字段中时使用。在底层数据中，此信息将存储为用户的 Foundry 用户 ID 或组 ID，而值格式化可用于渲染用户名或组名，而不是 ID。

FAQ

这是否适用于现有的类型类？

值格式化优先于 UI 中现有的类型类。如果两者都已配置，将显示值格式化。但是，您可以对一个属性使用值格式化，对另一个属性使用类型类。

这是否适用于 Object Views 中的可编辑属性？

值格式化支持为以下配置的属性： 内联编辑。具有旧版 hubble:editable 类型类的属性将禁用值格式化。
