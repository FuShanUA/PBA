部署支持时间序列的 Foundry Rules

这些说明假设时间序列已在您的平台中设置完毕。了解有关 在 Foundry 中使用时间序列的更多信息。

要在 Foundry Rules 中启用时间序列功能，请先按照相关步骤 部署 Foundry Rules。部署 Foundry Rules 后，需要执行以下所述步骤来启用时间序列支持：

  1. 要创建时间序列规则，其中一个工作流输入必须是时间序列根对象类型。对于您希望为其编写时间序列规则的所有输入对象类型，请打开 启用时间序列 开关。



  2. 如果您的时间序列数据是使用 时间序列属性设置的，则无需额外的配置步骤，您即可开始编写基于时间序列的规则。但是，如果您的时间序列数据是使用度量配置的，则必须完成以下步骤：

  • 在切换 启用时间序列 开关后，将打开一个对话框，提示您选择从 序列对象类型 到 根对象类型的关联。
  • 然后，在转换配置部分中，您必须添加 所有 为这些度量提供支撑的时间序列同步 。
