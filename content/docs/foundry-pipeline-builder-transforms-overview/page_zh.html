转换

Pipeline Builder 提供了一个灵活、强大且易于使用的界面，用于在 Foundry 中转换您的数据。使用现有工具（例如 Spark 或 SQL）编写数据转换，对于非编程人员和经验丰富的软件开发人员来说都可能具有挑战性且容易出错。此外，现有工具通常与特定的执行引擎耦合，并且需要使用代码库来表达数据转换。

Pipeline Builder 使用通用模型来描述数据转换。此后端是用于编写转换的工具与所述转换的执行之间的中间层。

Pipeline Builder 的底层架构旨在支持各种输出——数据集、本体论对象、流、时间序列以及导出到外部系统。您可以针对数据集、对象类型、关联类型运行批处理管道，或运行与流式数据集对应的流式管道。

在 Pipeline Builder 中使用转换

在 Pipeline Builder 中，您可以使用两种类型的数据转换：表达式和转换。表达式以表中的列作为输入，并输出单个列（例如 Split string），而转换以整个表作为输入并返回整个表（例如， Pivot or Filter).

我们将表达式和转换分组在同一个配置界面中。例如，您可以在其中找到 Drop columns 转换以及类似以下表达式 Cast 和 Concatenate strings。这使您可以在同一路径中一起使用表达式和转换，并在一个配置表单中将表达式嵌入转换中，如下所示，将 Length 表达式插入到 Filter 转换中。

其他数据结构化转换，即 连接, 第一个选中的数据集是日 拆分，拥有各自的配置窗格，并在 Pipeline Builder 界面中标记有独特的图标。

为简单起见，我们通常将所有类型的数据转换统称为转换。

连接

联接（join）组合两个至少有一个匹配列的数据集。根据您配置的联接类型，联接输出可以组合匹配的行并排除不匹配的行。

合并（union）组合两个数据集以包含所有行。

合并转换要求所有输入具有相同的架构。如果输入架构不完全匹配，合并将显示一条错误消息，其中列出缺失的列。

拆分

拆分（split）根据条件将单个输入分区为两个输出，将满足条件的行发送到 True 输出，将所有其余行发送到 False 输出。

拆分转换仅在标准批处理（Spark 支撑）和更快的管道（DataFusion 支撑）中受支持。 拆分 选项不会出现在流式管道中。

空值处理

在筛选、联接和 Case 转换中使用条件时，理解 null 值如何被求值非常重要。了解更多关于 空值处理 在 Pipeline Builder 条件中的信息。

用户自定义函数

如果您无法使用现有的转换选项来处理数据，或者有想要在多个管道中复用的复杂逻辑，您可以创建用户自定义函数（UDF）。用户自定义函数允许您在 Pipeline Builder 中运行可进行版本控制和升级的自定义代码。

注意： 我们建议使用 Python 函数 以获得最佳体验。如果您需要访问特定的 Python 库，也可以使用 Java UDF。

对于需要处理来自两个不同流的事件的流式管道，键控 CoProcess UDF 允许您定义自定义的有状态逻辑，该逻辑在两个输入之间维护状态，并从任一流独立地发出输出行。

仅在必要时使用用户自定义函数。我们建议尽可能使用 Pipeline Builder 中经过优化的 转换面板 。

已训练的模型

如果您需要在批处理或 流式管道中直接运行机器学习模型推理，您可以使用 已训练模型节点。这允许您导入在 Foundry 内部或外部训练的模型，并在无需编写代码的情况下对您的数据生成预测。模型作为隔离的 sidecar 进程运行。

训练模型节点仅支持批处理（Spark）和流式处理（Flink）执行模式，且仅适用于具有单个表格输入和输出的模型。
