查找数据集

Foundry 数据集通过以下方式导入 Fusion lookup 公式。这些公式类似于 Microsoft 的 VLOOKUP 函数，但用于从 Foundry 数据集中引入实时数据，而非电子表格。

您可以通过以下面板搜索数据并生成这些公式 查找和使用数据 面板 - 详见 查找和使用数据 了解更多详情。您也可以自行编写这些公式，并将其嵌套在其他公式中使用。

在派生系列逻辑中支持哪些 Quiver 卡片？ lookup 公式包括：

  • lookup：返回数据集某一列中的一组值，可附带可选筛选条件。单个结果以值的形式返回，多个结果则以数组形式返回。例如， =lookup(dataset_name, column_name, filter_column_1, filter_value_1, filter_column_2, filter_value_2).
  • lookup_array: Same as lookup 不同之处在于单个结果也以数组形式返回（长度为 1）。
  • lookup_distinct：返回数据集某一列中不重复的值集合，可附带可选筛选条件。
  • lookup_dropdown：返回一个下拉列表，其中可选值为查找的结果。
  • lookup_sorted：返回按数据集某一列升序或降序排列的一组值。
  • lookup_schema：返回包含数据集 schema 的数组。

您可以在以下位置找到有关这些具体公式的更多详情 你可以展示数值或迷你图，执行计算，或对时间序列运行基础函数。详情请查阅.

查找（例如 sum(lookup(...))）的结果限制为 2,000 条。如果您的工作流需要更多元素，应先在 Contour 中执行聚合或透视操作，然后将结果表保存为数据集，以便在 Fusion 中进行索引。

中的任何参数 lookup 都可以是电子表格中的单元格引用。这使您能够创建依赖于用户输入、派生单元格或其他查找的动态查找。您可以将这些单元格引用 lookup 调用拖动或复制/粘贴到电子表格的其他位置，以获取特定上下文的结果。

要展开来自 lookup的结果数组，您可以 Shift+拖动 将该单元格向下展开为多个单独的单元格。
