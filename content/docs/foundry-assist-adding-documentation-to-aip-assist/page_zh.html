使用 AIP Assist 提供自定义内容源

您可以在控制面板中配置自定义内容源对用户的可用性，从而通过 AIP Assist 提供该内容源，前提是内容源已完成 注册。

在使自定义源可供 AIP Assist 使用时，您可以选择仅在打开特定资源或一组资源时才提供该源，还是始终提供该源。如果您选择始终向用户提供内容的选项，则无论用户在使用 AIP Assist 时正在查看哪些资源，AIP Assist 都会使用该自定义源来回答用户的查询。我们建议将此功能用于有价值的自定义平台级内容， 连同 AIP Assist 在默认模式下存储在其搜索上下文中的平台文档和开发者文档一并提供。

向 AIP Assist 注册您的内容源

第一步是注册您的内容源并使其在 AIP Assist 中可用。根据您的需求，查看从以下来源注册内容的说明： Notepad 或 平台内自定义文档。

为您的用户启用内容源可见性

将自定义源注册到 AIP Assist 后，您需要为您注册中的用户配置该源的可见性。

以下步骤必须由具有 Control Panel 访问权限的平台管理员完成。

  1. 导航至 Control Panel，选择您的注册，然后打开 AIP Assist 页面。



  2. 选择 + 添加，这将打开一个列出当前已摄取文档的对话框。



  3. 找到相关文档，将其选中并添加。默认情况下，添加的源仅在创建该源时所用的仓库或 Notepad 文档中可见。此级别的可见性可用于测试 AIP Assist 的响应是否符合预期。



  4. 在包含您内容的自定义文档仓库或 Notepad 文档中，打开 AIP Assist 并输入专门针对您产品的问题，以确认 AIP Assist 的响应符合预期。



  5. 当您确信这些答案无误并希望将其提供给更多用户时，请导航至 Control Panel > AIP Assist，重新配置可见性。找到您的内容源并选择 管理。



  • 如果该内容与您在 Foundry 中任何位置的用户都相关，请选择 始终。



    • 如果内容仅在特定上下文中相关，例如在 Workshop 应用中，请选择 按资源 并添加相关资源。请注意，您可以添加多个资源。



  1. 保存您的更改。

现在，当用户就相关主题向 AIP Assist 提问时，您的内容将根据可见性设置供用户访问。
