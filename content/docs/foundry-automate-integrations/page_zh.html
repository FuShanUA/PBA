集成

  • AIP 逻辑
  • Autopilot
  • Contour
  • 或
  • 对象浏览器
  • 本体论管理器
  • 时间序列（Quiver）

AIP 逻辑

自动化您的 AIP Logic，以自动应用或暂存本体论编辑以供人工审核。自动化可以在现有对象上触发，也可以在创建新对象时触发。

从 Automate 调用 Logic 函数的方式取决于是否启用了暂存写入执行模式：

  • 启用暂存写入： 使用 操作效果 来调用由该函数支撑的操作类型。
  • 禁用暂存写入： 使用 Logic 效果 来直接调用该函数。

了解如何自动化您的 Logic 函数.

Autopilot

您可以直接在 Autopilot 中打开自动化，以可视化和管理您的自动化工作流。在自动化概览页面上，选择 在 Autopilot 中打开 来自 操作 菜单中选择复选框来自定义可用的工具。

当您从自动化打开 Autopilot 时，Autopilot 会自动生成一个包含所选自动化和建议的相关自动化的工作台。

了解有关 Autopilot 的更多信息.

Contour

Contour 仪表板 可以附加到自动化 通知效果 以通过电子邮件进行分发。

或

或 文档和 Notepad 模板 可以附加到自动化 通知效果，从而能够自动分发包含 Notepad 最新数据的报告和摘要。

要直接从 Notepad 创建自动化，请选择 操作 右上角的下拉菜单并选择 添加自动化.

您将被引导至该 Notepad 文档的自动化概览页面。选择 新建自动化 以启动自动化创建向导，该向导打开时会预先填充 Notepad 文档作为附件。

配置并保存自动化后，您将返回到文档内的自动化概览页面，该页面现在会显示您新创建的自动化。

对象浏览器

在以下位置创建自动化： 对象浏览器 请按照以下步骤操作：

  1. 选择 保存 在探索视图中。
  2. 选择一个项目或文件夹目标位置。



3. 保存后，选择 监视器 在页面右上角，以查看所有使用此探索作为输入的自动化。新创建的探索将显示一个空列表。



4. 选择 添加新自动化 以打开用于创建新自动化的简化设置视图。

本体论管理器

本体论管理器 使用户能够定义其 Foundry 本体论，包括对象类型和操作类型。Automate 通过两种方式与 Ontology Manager 集成：

  1. 直方图 自动化 AIP 使用量与限制 对象类型视图 显示与所选对象类型关联的所有自动化，包括在创建或更新该类型的对象时触发的自动化。选择 添加自动化 以启动自动化创建向导，并预先填充该对象类型作为条件。



  2. 同样， 自动化 AIP 使用量与限制 操作类型视图 显示在其 操作效果中的分支提案。选择 添加自动化 中使用所选操作类型的所有自动化

您可以在 Quiver 中自动化您的时间序列搜索逻辑，以便将时间序列数据中感兴趣的时段保存为本体论中的事件。
