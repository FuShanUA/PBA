媒体集

媒体集 让您能够存储、转换和处理媒体文件。媒体集可在整个平台中使用，为您的工作流提供支持。

支持的媒体集架构

媒体集具有架构类型，用于定义可在该媒体集中存储的文件类型，例如文档、图像或音频。每个媒体集还具有主格式，用于指定该媒体集中所有文件必须采用的文件格式。

媒体集支持的文件格式如下：

  • 音频
    • WAV (.wav)
    • FLAC (.flac)
    • MP3 (.mp3)
    • MP4 (.mp4)
    • NIST SPHERE (.sph)
    • WEBM (.webm)
  • DICOM
    • DICOM (.dcm)
  • 文档
    • PDF (.pdf)
    • DOCX (.docx) (作为 附加输入格式)
    • PPTX (.pptx) (作为 附加输入格式)
    • TXT (.txt) (作为 附加输入格式)
  • 电子邮件
    • EML（.eml）
  • 图像
    • PNG（.png）
    • JPEG（.jpg， .jpeg）
    • JP2K (.jp2)
    • BMP (.bmp)
    • TIFF (.tiff, .tif)
    • NITF (.nitf)
  • 电子表格
    • XLSX (.xlsx)
  • 视频
    • MP4 (.mp4)
    • MOV (.mov)
    • TS (.ts)
    • MKV (.mkv)
PDF 支持

不支持需要专有功能才能查看,或受密码、数字签名或加密保护的 PDF 文件。

XLSX 限制

某些高级 XLSX 功能（如复杂公式）以及包括图像在内的嵌入文件不受支持。

附加输入格式

媒体集还可以具有附加输入格式，从而允许将其他文件格式接受到媒体集中。上传时，这些文件将自动转换为主要格式。上传时仅接受指定的附加输入格式。

可以在创建媒体集时以及媒体集详情选项卡下配置附加输入格式。

附加输入格式无法指定给 虚拟媒体集。

某些文件类型只能作为附加输入格式进行处理。例如，DOCX（.docx)、PPTX (.pptx) 和 TXT (.txt) 文件可以作为附加输入文件格式上传到 PDF (.pdf) 媒体集，尽管不支持将它们作为主要文件格式。

请注意，并非所有主要格式都支持附加输入格式。

多模态媒体集

媒体集还可以配置为多模态媒体集，允许上传任意文件格式。这对于需要多种媒体架构类型文件的工作流非常有用。

多模态媒体集存在一些限制。平台内预览仅适用于使用 受支持的架构类型。预览功能也不适用于 其他输入格式 使用虚拟多模态媒体集时。 访问模式 适用于使用受支持架构类型的媒体项，但您需要先验证或筛选其架构。使用不受支持架构类型的媒体项无法与访问模式配合使用。

媒体引用

媒体集中的项可以通过以下方式引用： 媒体引用。媒体引用使您能够在 Foundry 中使用媒体项，而无需复制媒体项本身。

您可以使用媒体引用来引用数据集中的媒体集项。这对于以表格形式将媒体项与元数据或其他信息相关联非常有用。例如，您可以将原始 PDF 与其文件名、页数和提取的文本作为附加列进行关联。

您还可以将媒体引用用作 模型适配器 的输入，用于批量推理管道。

要为您的媒体集生成媒体引用列表，请使用 Pipeline Builder 中的 Get media references 函数。您还可以在 Python 转换中生成媒体引用，方法是导入 transforms-media 库并调用 list_media_items_by_path_with_media_reference 方法。

即使某个 路径 已被较新的上传覆盖，指向该“被覆盖”媒体条目的已保存媒体引用仍将继续渲染并引用原始条目。

从媒体集中删除媒体条目

软删除

当媒体条目在平台中被删除后，它将不再可见，但原始数据并未被永久删除。如果该媒体条目被直接链接，则仍可以访问。

您可以从媒体集中删除媒体项，方法是选择要删除的媒体项，然后选择 删除 操作。为防止误删，此操作将要求您在弹出窗口中再次选择 删除 以确认您确实要删除该媒体项。

成功删除该项后，媒体集将刷新并显示成功消息。现在您可以查看不包含已删除媒体项的媒体集。

删除限制

对于通过构建管道更新的媒体集，不支持删除媒体项。
