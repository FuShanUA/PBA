transforms.api.LightweightInput

class transforms.api.LightweightInput(alias, rid, branch=None)

在运行时传递给 ContainerTransform 对象的输入对象。

其目的是模拟 transforms.api.TransformInput API 的一个子集，同时提供对底层 foundry.transforms.Dataset的访问。

属性 alias

与此参数关联的数据集的别名。

arrow()

包含数据集完整视图的 PyArrow 表。

属性 branch

与此参数关联的数据集的分支。

dataframe()

包含数据集完整视图的 pandas DataFrame。

属性 end_transaction_rid

输入数据集的结束事务。

  • 类型： str ↗

filesystem()

以只读模式访问文件系统。

构造一个 FoundryDataSidecarFileSystem 对象，用于直接访问数据集的文件。

pandas()

包含数据集完整视图的 pandas DataFrame。

path()

下载数据集的底层文件并返回其路径。

polars(lazy=False)

包含数据集完整视图的 Polars DataFrame 或 LazyFrame。

  • 参数： lazy (bool ↗ , 可选) – 是否返回 LazyFrame 或 DataFrame。默认为 False。

属性 rid

与此参数关联的数据集的唯一资源标识符。

属性 start_transaction_rid

输入数据集的起始事务。

  • 类型： str ↗
