《图像标注》：

直方图 《图像标注》： 小部件用于通过在感兴趣区域周围绘制矩形来标注图像。

下面的截图展示了一个已配置的 图像注释 小部件正在创建标注的示例：

标注不会存储在小部件内部。要持久化一个矩形，请将其保存为 对象，保存在您的 本体论中。持久化的标注与其他对象的行为相同：可以被搜索、筛选、关联到其他对象、通过 权限进行保护，并在应用程序之间重用。

该小部件执行两种不同的角色：

  • 显示现有标注。 小部件读取标注对象的对象集，并将每个存储的边界框叠加显示在图像上。
  • 捕获新标注。 当用户绘制一个矩形时，小部件会将坐标写入 Workshop 变量。然后，您可以通过 操作.

将该变量持久化到本体论中。写回本体论的操作始终由操作执行； 加载对象数据。 并非必需。只有在进行“假设分析”时才需要场景，此时编辑内容会被暂存在本体论的一个隔离分支中，而不是直接提交。仅当您明确希望标注是临时的、并在写入正式本体论之前需要审核时，才使用场景。由于写回依赖于操作，在配置小部件之前，您需要准备好以下两项内容：

  1. An 标注对象类型 ，用于存储每个边界框。
  2. An 操作 ，用于创建（以及可选地删除或修改）这些标注对象。

从用户绘制矩形到持久化、关联的标注对象的端到端流程如下：

  1. 用户在图像上绘制一个矩形。
  2. 小部件将矩形的坐标写入 当前边界框选择 variable.
  3. 直方图 在创建标注时 设置会触发一个提交操作的 Workshop 事件，或者用户选择“保存”按钮来提交该操作。
  4. 该操作创建一个标注对象，设置边界框属性，并将新对象关联到拥有该图像的主体对象。
  5. 小部件重新加载标注对象集，并在图像上绘制已保存的框。

设置标注写回

以下步骤演示了最基本的标注工作流：让用户在图像上绘制一个框，并将其保存为关联到图像所属对象的对象。该示例使用一个 Inspection Photo 对象（持有图像）和一个 Image Annotation 对象（持有每个框），但您应替换为您自己本体论中的对象类型和属性名称。

此示例仅用于说明。由于您的本体论是根据您的数据定制的，下文引用的对象和操作类型可能不存在于您的租户中。请创建与您的数据模型相匹配的等效项。

  1. 对标注对象类型建模
  2. 创建操作
  3. 配置小部件输入
  4. 将新标注保存到本体论

步骤 1：对标注对象类型建模

In 本体论管理器中，创建一个用于存储标注的对象类型。它至少需要：

  • 主键： 一个值，例如 Annotation ID string.
  • 边界框属性： 一个字符串属性，将框坐标存储为 "x1, y1, x2, y2"，其中 (x1, y1) 是左上角， (x2, y2) 是右下角，使用像素坐标。这是小部件读取和写入的值。
  • 颜色属性（可选）： 一个保存十六进制颜色代码的字符串属性，例如 #FF0000，用于绘制该框。
  • 关联： 指向拥有该图像的对象的关联，例如从 Image Annotation to Inspection Photo的多对一关联。此关联将每个标注与正确的图像相关联，从而只显示相关的框。

步骤 2：创建操作

创建一个 操作 ，用于创建一个新的 Image Annotation 对象。其参数应包括：

  • 直方图 边界框 字符串，由小部件提供。
  • 对 主体对象 (the Inspection Photo）的引用，以便操作可以设置在步骤 1 中创建的关联。
  • （可选） 颜色 string.

您还可以创建操作来 删除 标注（用于“移除”控件），以及 修改 现有标注（如果您希望用户在保存后调整框）。有关定义操作类型的完整演练，请参阅 在 Workshop 中使用操作.

步骤 3：配置小部件输入

将图像标注小部件添加到您的模块中，并配置 配置选项:

  • 将 图像源 设置为当前图像的媒体引用或媒体 URL。
  • 在您的终端会话中将 标注对象 设置为您的 Image Annotation 对象的对象集，并筛选为当前的 Inspection Photo。按当前主体对象进行筛选可确保小部件仅绘制属于所显示图像的框。
  • 在您的终端会话中将 边界框属性 设置为您在步骤 1 中创建的字符串属性。
  • （可选）将 颜色属性 设置为您的十六进制颜色属性。
  • 在您的终端会话中将 当前边界框选择 设置为一个字符串变量。小部件会将用户当前正在绘制的框的坐标写入此变量；这是您传递给创建操作的值。
  • 在您的终端会话中将 活动标注对象 设置为一个对象集变量。当用户选择某个现有标注对象时，小部件会使用该对象填充此变量。

步骤 4：将新标注保存到本体论

当用户完成矩形的绘制后，坐标将保存在 当前边界框选择 变量中。要持久化这些坐标，请触发您在步骤 2 中创建的创建操作：

  • 使用直方图中的 在创建标注时 设置，以便在绘制矩形时触发 Workshop 事件（event） ，或者使用 按钮组小部件 添加一个“保存”按钮，让用户在保存前进行确认。
  • 在操作的参数默认值中，将 边界框 参数设置为 当前边界框选择 变量，并将 主体对象 参数设置为当前显示的对象（例如，活动的 Inspection Photo）。设置主体对象是将新标注关联到正确图像的关键。
  • （可选）将颜色参数设置为变量或静态十六进制代码。

操作提交后，新的 Image Annotation 对象将被写入本体论并关联到其主体对象。由于小部件的 标注对象 输入是一个对象集，它会重新加载以包含新对象，并在图像上绘制已保存的框。

配置选项

以下是新添加的图像标注小部件的初始状态及其初始配置面板的截图：

  • 输入数据
    • 图像源： 图像可以通过媒体 URL 或媒体引用来显示。目前此小部件支持以下图像文件类型：
      • 媒体 URL： 选择一个包含有效媒体 URL 的字符串变量以渲染媒体预览。如果引用来自数据集的媒体 URL，该 URL 应采用以下任一格式： .png, .jpg, .jpeg, .bmp，或 .webp,
        • https://{my-foundry-url}/foundry-data-proxy/api/web/dataproxy/datasets/{dataset rid}/transactions/{transaction rid}/{filename}
        • https://{my-foundry-url}/foundry-data-proxy/api/web/dataproxy/datasets/{dataset rid}/views/{branch name}/{filename}.
        • 否则，如果引用外部媒体 URL，请在您注册的 内容安全策略 settings.
      • 媒体引用： 定义一个包含单个对象的对象集，并选择 媒体引用 类型的属性，以渲染该对象的媒体预览。
    • 当前边界框选择： 一个字符串变量，用于跟踪以 "x1, y1, x2, y2" 格式存储的活动边界框选择坐标，其中 (x1, y1) 是框左上角的像素坐标，(x2, y2) 是框右下角的像素坐标。将此变量传递给您的创建操作，以保存用户绘制的框。
    • 活动标注对象： 表示当前所选标注的对象。
  • 标注
    • 标注对象： 表示要叠加到图像上的标注的对象集。将此对象集筛选为当前图像的主体对象，以便仅显示相关的标注。目前，每张图像最多支持 1000 个标注。
    • 边界框属性： 标注对象集的字符串属性，表示点向量。
    • 颜色属性： 标注对象集的字符串属性，表示要绘制的颜色（以十六进制代码表示）。此字段为可选。
    • 在创建标注时： 使模块构建者能够配置 Workshop 事件，以便在用户创建标注时触发。使用此功能可触发将绘制的框保存到本体论的 Action。
