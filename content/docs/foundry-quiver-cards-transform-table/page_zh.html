转换表

转换表 是对对象或从对象派生的表格数据执行批量分析的容器。转换表允许用户根据输入对象（包括时间序列）的属性派生列，并为对象数据提供连接和分组功能。

由于这些操作的计算强度较高， 最多允许 50,000 行 出现在转换表中。

转换表允许您：

  • 连接和聚合 objects;
  • 派生新列 （基于对象属性）；
  • 丰富数据 （通过创建或编辑值）；
  • 对时间序列执行转换 （批量处理列）；以及
  • 绘制输出 以多种方式展示操作结果。

添加转换

转换表搜索窗口可通过转换表中的 添加转换 按钮访问，其中显示按 转换操作类型分组的所有可用转换，例如编辑列、筛选、时间序列操作或空值/错误处理。大多数转换会添加相应类型的新列，但有些转换会改变表格的形状（例如，在连接其他对象类型或将表格分组以聚合行时）。

转换表的转换也可以直接从 后续操作菜单 的历史，方法是选择 转换 类别和转换添加。此操作将在分析中添加一个转换表卡片，并将所选转换应用于该表。

转换也可以应用于单个 支持的输入 （在转换表之外），仅对该值执行一次操作，而不是在表中执行批量操作。

要向分析添加转换卡片，只需使用 搜索窗口 在顶部菜单栏中进行搜索即可。

转换表输入

转换表可以接受多种类型的输入，包括对象集、分类图表、时间序列图表、时间序列图、数据集、透视表和其他转换表。用户也可以手动输入数据来构建转换表。

要向分析添加转换表，请选择 转换表 在顶部 表格 菜单中。这将打开编辑器面板，您可以在其中选择符合分析条件的现有输入。

输入：对象集

对象集是转换表最常见的输入。

您可以从分析中的任何对象集创建转换表，通过 后续操作 菜单中选择 Convert > Transform table.

每个转换表 有 50,000 行的限制 （无论是初始数据还是连接后的数据），因此您只能创建包含少于 50,000 个对象的转换表。

从对象集创建转换表时，集合中的每个对象对应一行，包含一个表示每个对象唯一 ID 的主键列，以及对象的每个 显著 属性（如本体论中定义）的列；如果没有显著属性，则显示对象的前几个属性（最多 20 个）。

通过点击表格右下角的 属性 按钮，可以添加或删除属性列，以及对象集的任何关联传感器对象。拖动列可在表格中重新排序。

您可以为转换表的每个转换步骤设置不同的列配置。了解更多关于 设置转换表格式 的信息，请参见下文部分。

输入：分类图表

条形图、折线图和散点图都可以作为转换表的输入。使用这些输入将显示图表上的类别和值，而不会提取底层数据。要提取底层数据，您应使用创建图表时所用的对象集。您可以通过选择图表、点击 后续操作 菜单，然后选择 Table > Transform table.

输入：时间序列图

时间序列图可以作为表格的输入，将时间序列数据转换为表格格式，以便进行操作、编辑或充实。

要从时间序列图创建转换表，请从图表中选择一个特定的时间序列图。然后，选择 表格 > 转换表 菜单中选择 后续操作 菜单，位于时间序列图表底部。

然后，从可用的 范围选项 中进行选择，位于转换编辑器面板中：

  • 使用输入时间序列的完整时间范围（默认）。
  • 指定要导入的时间范围，可以通过手动输入开始和结束时间戳，或通过引用范围参数来完成。

出于性能原因，转换表限制为 50,000 行；转换表将数据拉取到前端进行操作，而不是将数据推送到后端服务。因此，时间序列数据可能需要进行采样（分桶）以适应此限制。

您可以在 数据选项:

  • 中选择如何将时间序列数据转换为表格格式。在“采样”设置中，表格将为每个桶显示边界时间戳和值（最早和最晚、最小和最大）、平均值以及点数。您可以调整采样桶的数量。
  • 在“未采样”设置中，表格将显示原始的未采样数据（“tick 数据”），并包含三列：主键、时间戳和值。

时间戳序列数据默认以 UTC 显示。可以在转换表编辑器的列设置中将时间戳时区更改为用户所在的时区或其他静态时区。

输入：时间序列图表

时间序列图表可以作为表格的输入，将图表中的每个时间序列图作为表格中的一行打开。

要从时间序列图表创建转换表，请选择时间序列图表（而不是特定的时间序列图）。然后，选择 表格 > 来自图表时间序列的表格 菜单中选择 后续操作 菜单，位于时间序列图表底部。

输入：透视表和其他转换表

透视数据可以作为转换表的输入，使您能够使用公式对透视表列进行操作。与图表一样，从透视表创建转换表时不会引入其输入数据，而是引入透视后的数据本身。 转换表也可以作为转换表的输入。这在您希望将转换逻辑拆分为逻辑步骤的“块”，或将数据转换和数据格式化分开的情况下非常有用。 您可以通过选择以下方式从另一个表格创建转换表 表格 菜单中选择 后续操作 菜单，位于表格卡片底部。

输入：手动输入转换表

用户可以手动输入最多 5,000 行数据来创建新的转换表。手动输入转换表卡片具有类似电子表格的用户界面，并支持五种数据类型：字符串、数字、布尔值、时间以及 时间序列。用户可以像操作其他转换表一样与手动输入转换表进行交互并对其应用操作。

要向 Quiver 画布添加新的手动输入转换表，请选择 手动输入 在分析标题栏中，或在 按钮。 此外，“后续操作”栏现在支持搜索！您可以跨所有类别或在特定类别中搜索操作。搜索结果将包含该类别内的匹配项，并会突出显示来自其他类别的匹配项，确保您不会遗漏任何操作！ 对话框中搜索该表格。

手动输入表格示例工作流

  • 使用表格值对分析进行参数化： 将手动输入转换表与行和列选择器结合使用，以在不同行之间切换。表格中所选行的值可以用作下游分析中的动态参数。

  • 从外部源摄取少量数据以补充分析和本体论： 用户可以将电子表格中的元数据复制并粘贴到新表格中，以便通过搜索以下内容关联到现有对象集 连接至转换表 菜单中选择 后续操作菜单 位于对象集下方。

从关联的对象集和手动输入转换表中，配置 连接至转换表 转换以指定 关联条件.

  • 无需设置时间序列同步即可分析小型时间序列数据集： 复制并粘贴表格形式的时间序列数据，并使用 表格时间序列 卡片将表格转换为时间序列图，以继续使用 Quiver 的完整 时间序列操作.

对于超过 5,000 行的时间序列数据，或需要在 Foundry 中复用时间序列数据，请设置 时间序列同步 以提升性能和可复用性。

默认情况下，手动输入的转换表会为每一行生成一个随机的唯一主键，但用户可以选择将某一列设置为表的主键。主键会向下游传播，并在其他卡片（如转换表行选择器）中作为唯一标识符使用。

输入：本体论 SQL

本体论 SQL 结果可用作转换表的输入，将 SQL 查询结果转换为表格格式，以便进一步操作、丰富或可视化。

要从本体论 SQL 卡片创建转换表，请选择该本体论 SQL 卡片，然后选择 Convert > Transform tables 菜单中选择 后续操作 卡片底部的菜单。

当本体论 SQL 卡片转换为转换表时，各列对应于 SQL 查询返回的列。随后可以对结果数据应用任何转换表操作，例如筛选、分组、派生新列或绘图。

转换表输出

转换表的输出主要有四类：时间序列、图表、表格和数值。 可以通过 后续操作 表格底部的菜单添加转换表输出。

输出：时间序列

有多种方式可以从转换表输出时间序列数据：

  • 当悬停在 时间序列表格单元格上时，会出现一个“弹出”按钮。点击该按钮可在新的时间序列图中绘制该时间序列。
  • 通过选择 时间序列 > 分组时间序列图 菜单中选择 后续操作 表格底部的菜单，将时间序列列绘制在单个时间序列图上。从表中选择输入列和页面大小，以配置要叠加显示的时间序列数量。
  • 将表格格式（时间戳和数值）的时间序列数据转换为时间序列图，以使用 Quiver 中提供的全部时间序列可视化和转换功能。选择 时间序列 > 表格时间序列 菜单中选择 后续操作 表格底部的菜单。从转换表中选择时间戳（日期/时间）列和数值（数字）列，并可选择设置单位。如果表格数据中每个时间戳包含多个数值点，则仅绘制该时间戳的第一个点。

输出：图表

您可以根据转换表数据创建折线图、分类散点图、条形图或 Vega 图。这些图表可在 Quiver 中用于任何接受图表作为输入的功能，例如分类公式图或叠加图。

输出：表格

您可以基于现有转换表创建 新转换表 以提供一个可以独立于底层数据进行格式化和组织的视图。

输出：透视转换表

您可以创建一个 透视转换表 以显示聚合数据。

输出：数值

您可以对转换表的列进行聚合，并将其作为数字或数组输出到指标卡片上。这些指标可在 Quiver 中用于任何接受数字或数组作为输入的功能。

计算新列

要添加计算列，请选择 添加转换，然后选择与您要创建的数据类型对应的选项卡：数值、日期/时间、字符串、布尔值、数组或时间序列。

有关创建列时可用的完整转换列表，请参阅 转换表转换索引.

联接

关联到关联对象

当转换表以对象集作为输入时，您可以使用 本体论 将关联的对象合并到表中。此转换称为 关联到关联对象 ，可以在 表格 选项卡中的转换菜单下找到。

当您将对象集与其他关联对象进行合并时，系统会提示您选择 关联类型，即起始对象与传入对象之间的连接。生成的表将具有一个新的合并主键；该主键是起始对象集的主键与传入对象集的主键的组合。新的合并主键会将传入对象的属性添加到每个现有行上，从而增加列的数量。

如果您的起始对象仅连接到一个传入对象（即“一对一”或“多对一” 关联类型），则行数不会增加。如果每个起始对象有多个传入对象（换句话说，即“一对多” 关联类型），则表中的行数将会增加。

在下面的示例中，我们从一个公司对象集开始创建转换表。最初该表有 505 行（每个对象 1 行）。然后我们添加一个“合并关联对象”转换，以添加关联的 Stock Event 对象。现在，该表有 11,149 行，主键是两个对象主键的组合，并且已添加了来自 Stock Event 对象的列。

连接

直方图 连接 转换可以在 表格 选项卡中的转换菜单下找到。与 SQL 合并操作类似，它允许您合并两个转换表，同时指定匹配条件（由下图中的绿色方框标示）。

执行合并的步骤：

  1. 选择要合并到哪个表。
  2. 设置合并类型（左连接、内连接或全连接）。
  3. 配置匹配条件：匹配方式（全部、任意）以及来自输入表和合并表的一列或多列用于比较的列对。
  4. 选择要保留输入表中的哪些列。
  5. 选择要将合并表中的哪些列添加到输入表。如果输入表已经包含与要添加的列同名的列，则会添加 合并列的前缀 。

交叉连接

直方图 交叉合并 转换允许您通过执行 笛卡尔积 ↗ 合并来组合两个转换表。交叉合并会为第一个表的一行与第二个表的一行的每种配对组合生成一行。它不会 不 基于特定列进行合并。

分组

分组是在某个预定义的窗口或桶中对一组值进行聚合的操作。在转换表中，您可以通过两种方式实现此目的：

  • 分组依据
  • 先分组再合并（也称为合并分组依据）

分组依据

在 分组依据中，您可以为 分组依据 列中的每个属性创建一个类别。对于每个类别，所有关联的基于时间的列、数值列和时间序列列都会变成值的数组（也称为组）。可以对这些数组（组）执行数组转换和聚合操作。

例如，下面的转换表显示了一组具有不同海拔值的世界气象站。我们可以按气象站所在的国家对其进行分组，以创建每个国家的海拔值数组。

如果我们想对这些海拔值进行 聚合 ，例如计算每个国家的平均海拔，我们可以使用 数值分组聚合 转换，该转换将在表中添加一列，返回我们所选输入列的平均值（此处为 elevation_array).

合并分组依据 当您想要计算某个窗口化和聚合的量（例如上图中每个类别的平均屋顶高度），但又希望在保持表中行数不变（每栋建筑一行）的同时为聚合指标添加一个新列时，此功能非常有用。

时间序列

转换表旨在支持时间序列的批量分析。这意味着诸如筛选、求导或累积聚合之类的转换现在可以一次应用于多个时间序列。有关批量时间序列分析的全面指南，请参阅 批量分析时间序列.

有关所包含的各个时间序列转换的更多信息，请参阅 转换表转换索引.

根据要转换的数据类别，有三种方法可将时间序列列添加到转换表中；这些方法是：

  • 从时间序列对象的对象集中显示时间序列折线图（迷你图）
  • 从根对象添加传感器对象
  • 根据一组时间戳和值创建时间序列

从时间序列对象的对象集中显示时间序列折线图（迷你图）

设置转换表的格式

转换表的列可以设置自定义的宽度和高度，各个值本身也可以进行格式化。所有格式化操作均在转换表的 显示 选项卡中进行。

列格式化

所有列（无论是数值列还是其他列）都包含用于静态设置列宽和最小高度的格式化选项。

可以通过从转换菜单中添加 重命名列 转换来重命名列。

值的条件格式化

此外，数值列还具有值格式化和条件格式化选项，包含以下控件：

  1. D3/视觉格式： 这些数字格式化选项与 Quiver 中用于格式化指标卡片或其他数值数据的选项类似。 了解有关 D3 格式化的更多信息。↗
  2. 对齐方式： 这些选项控制数字在单元格中的位置；提供左对齐、居中对齐和右对齐设置。
  3. 条件着色： 这些选项支持基于阈值对值进行条件着色。阈值可以静态设置，也可以配置为引入 Quiver 分析中的任何其他数值。您可以选择为单元格的文本或背景着色。

格式化时间序列列

转换表中的时间序列列会渲染关联时间序列属性的迷你图。默认情况下，迷你图显示序列中数据的完整范围。可以通过以下方式更改此设置 显示 编辑器的选项卡：

  1. 在目标时间序列列的列标题中选择向下箭头图标。这将打开列操作菜单。
  2. 选择 配置显示设置 选项。这是一个快捷操作，可将转换表编辑器打开到相关配置部分，位于 显示 tab.
  3. 更改 视图范围 通过从菜单中选择一个选项来设置迷你图的视图范围。

您可以按照相同的步骤为对象集表中的迷你图配置视图范围。

视图范围选项

有四种设置迷你图视图范围的方式：

  • 完整数据范围： 默认选项。显示时间序列中的所有数据。对于大型时间序列，这可能会对性能产生负面影响。
  • 固定范围： 将视图范围设置为静态的开始日期和结束日期，例如， 2025-5-21 to 2025-06-04.
  • 相对范围： 将视图范围设置为相对于今天的范围。例如，从 2 weeks ago to Now。默认情况下，范围的结束日期设置为 Now，但可以通过选择右上角的 设置为相对时间 开关来输入特定时间。
  • 初始默认时间轴范围： 将视图范围设置为用于初始化默认时间轴的范围。此值由 全局设置 menu.

FAQ

我可以使用转换表创建分组时间序列吗？

可以。分组时间序列（从条形图创建时间序列，然后将其细分为多个时间序列的功能）可在转换表中使用。您可以使用“分组为时间序列”函数，配合一组日期或时间以及一组数值来创建分组时间序列。

请参阅 转换表中的时间序列 的文档以获取更多信息。

我可以格式化转换表吗？

可以，您可以使用参数或手动输入值，以便根据用户定义的逻辑规则格式化表格的单元格。

转换表的规模限制是多少？

出于性能原因，转换表限制为 50,000 行，因为转换表会将数据拉取到前端进行操作，而不是将数据推送到后端服务。

我可以在转换表中绘制值吗？

可以。转换表有四种输出：时间序列、表格、图表和值（指标卡片）。 请参阅相关文档： 转换表输出 的文档以获取更多信息。

对象集是转换表唯一允许的输入吗？

不可以。虽然在转换表中使用对象很常见，但您也可以使用转换表来处理时间序列数据、图表数据或表格（如透视表或其他转换表）。 在处理图表数据或透视表时，行将失去与底层对象的关联，您可以对聚合数据进行操作，但无法链接回底层数据。这使得您能够对透视表执行列级操作，以及以表格形式创建和处理绘图数据。
