配置 SLT（SAP Landscape Transformation Replication Server）

SAP Landscape Transformation Replication Server（SLT）是一种数据复制工具，它使用数据库触发器来执行变更数据捕获（CDC），从而实现从源 SAP 系统到目标系统的高效数据复制。

可以将 SLT 和 Palantir Foundry Connector 2.0 for SAP Applications（"Connector"）配置为协同工作，以实现从 SAP 到 Foundry 的 CDC 复制。

在此设置中，将创建一个带有专用上下文（队列别名）的 SLT 配置。

要将 SAP 表复制到 Foundry，需要为每个对象配置一个 Foundry 数据集同步。配置数据集同步后，SLT 将在相关 SAP 对象上配置触发器，随后 SAP 中对该对象的更改将被捕获并存储在 SLT 服务器的队列中，以用于 ODP（Operational Data Provisioning）场景。Foundry 将按照预先配置的调度轮询此队列，以将这些更改同步到 Foundry 数据集。从版本 2.34（SP34）及以上开始，Connector 使用 通过 OData 进行基于 ODP 的数据提取 ↗ 与 ODP 交互。

首次为 SAP 对象配置 Foundry 数据集同步时，SLT 将执行全量加载。后续的触发器将仅获取该对象的更改。SLT 队列的清除由 SLT 管理。

您还可以将 Foundry 数据集同步配置为让 SLT 对特定 SAP 对象执行全量加载（快照），而不是以 CDC 模式（增量）运行。

前提条件

本指南假设 Connector 已安装在实例上。您可以查看 Connector 的安装说明.

直接使用 ODP（Connector 版本 2.33（SP33）及以下）

  • SAP_BASIS（技术组件版本，适用于 SAP NetWeaver 和 SAP S/4HANA 系统）7.4 SP14+，用于 Connector 安装
  • DMIS 2011_1_730 组件 SP15+，用于 SAP SLT 和源系统
  • 允许对所有 Mass Transfer ID（MTID）进行 1:N 复制的 SAP SLT 配置

请确保在 SLT 系统上已实施以下 SAP 说明：

  • SAP OSS 说明 1660374 – Fetch 等待时间不够长；超时
  • SAP OSS 说明 2215583 – 从 ODQ 提取期间因数据内容被移动而导致的错误

请确保已阅读以下 SAP 说明，并在适用的情况下遵循相关步骤：

  • SAP OSS 说明 2697016 – 无法在 CNV_IUUC_DB_CONN131 中复制表 - 其他配置具有不同的触发器设置 - SAP Landscape Transformation Replication Server。
  • SAP OSS 说明 2787584 - 尽管用户拥有 SAP_ALL，LTRC 中仍出现授权问题 - SLT
  • SAP OSS 说明 3032108 - 是否支持 1:N 复制？- SLT

在 SAP SLT 场景中，较旧的 DMIS 版本中一个表最多可以有 1:4 注册（最多 4 个使用者）。从 DMIS 2018 SP4 开始，SAP 的新 CDC 功能已启用，不再限制允许的使用者数量。

通过 OData 使用 ODP（Connector 版本 2.34（SP34）及以上）

Connector 版本 2.34 引入了一个 PALODATA 组件，允许您使用 OData API 配置同步 如 SAP 所推荐 ↗.

资源配置

在 SAP 系统中，将 Connector 与 SLT 一起使用可能会占用大量资源。因此，在开始复制之前，应查阅 SAP 官方的 SLT 规模评估文档。在开始从 SAP 环境提取数据之前，请确保 SLT 服务器上（以及安装 Connector 的 SAP 应用服务器上，如果 SLT 和 Connector 位于不同的服务器）有可用的后台和对话进程。

  • 转到事务 SM50 以查看是否有可用的后台和对话进程。如果没有可用的进程，向 Foundry 传输数据将失败。
  • 请参阅 SAP 官方 SLT 规模评估指南 ↗ 以获取更多关于系统规模评估的指导。

SLT 配置

1. 创建到源系统的 RFC 目标连接

要创建 SLT 用于从 SAP 源系统复制数据的远程函数调用（RFC）连接，请参阅 创建 RFC 连接.

2a. 使用安装后向导为源系统创建 SLT 配置

要使用 Connector 安装后向导创建 SLT 配置，请使用 /n/PALANTIR/POST_INST 事务代码，并且仅启用步骤 7 创建 SLT 配置。SLT 配置的参数如下：

参数描述
Context Name唯一的配置名称
Context Description上下文描述，将显示给 SAP 事务中的用户 LTRC 以及 Foundry 中
Data Transfer Jobs数据传输作业的数量
Initial Load Jobs初始加载作业的数量
Calculation Jobs用于初始加载范围计算的计算作业数量
Authorization Group默认无授权组
Source RFC Destination逻辑目标 - 源系统的 RFC 目标名称
Read from Single Client如果将从单个客户端读取数据，请勾选此选项
Allow Multiple Usage如果允许多重使用，请勾选此选项

2b. 使用 SLT 工具为源系统创建 SLT 配置

步骤 2a 和 2b 只需执行其中之一。

  1. 要创建 SLT 配置，请使用 LTRC 事务代码创建 SLT 配置。
  2. 创建新配置。
  3. 在监听器设置向导的 常规数据 部分，填写 配置名称 and 描述.
  4. 在源系统部分：
    • 选择 RFC 连接.
    • 选择 RFC 目标 我们之前创建的连接（例如，在我们的示例中为 SAP_SOURCE）。尽管名称为 RFC 目标，请在此设置中选择源系统的连接。
    • 在控制面板中启用 允许多重使用.

    此设置允许多个订阅者从源系统检索复制的数据，并且在配置创建后无法更改。由于 允许多重使用 在仅使用单个订阅者时没有影响，我们建议在首次配置时启用它。要在以后启用多重使用，需要删除该配置并创建新配置。

    • 在生产环境中，启用 从单个客户端读取。所使用的客户端编号将是 RFC 连接中定义的编号。此设置将确保仅将生产数据复制到 Foundry。在现有的 SLT 环境中，所有配置应具有相同的设置。因此，请查阅 SAP OSS 说明 2372636 - Cannot replicate data when different trigger options exist - SLT.
  5. 在目标系统部分：
    • 选择 RFC 连接.
    • 选择 操作数据供给（ODP） for 加载对象数据。。对于更高支持包级别的 SAP_BASIS，此场景列于 其他 而非 RFC 连接.
    • 在您的终端会话中将 RFC 目标 as NONE.
    • 将任意别名设置为队列别名。最佳做法是为队列命名时显示源系统的 SAP 系统 ID（SID）。此队列别名稍后在定义 Foundry 数据集同步时将用作上下文。
  6. 在监听器设置向导的 数据传输设置 部分中，设置在 SAP SLT 服务器上运行的数据传输作业、初始加载作业和数据计算作业的数量。具体数量请参考 SLT 规模评估指南 ↗ 以了解复杂场景所需的作业数量。
  7. 检查并创建连接。
  8. 返回 SLT 主界面，对于事务代码 LTRC，请确保 SLT 系统上已针对 ODP 场景激活了 BAdI 实现。要检查该设置，请选择配置名称打开配置，然后点击 专家功能 选项卡。确保 BAdI 实现已激活，否则 ODP 将无法正常运行。
  9. 控制面板 SA38 事务（从主菜单进入）。如 SAP OSS 说明 1660374 - Fetch does not wait long enough; timeout所述，运行程序 SAP_RSADMIN_MAINTAIN 以设置参数 RODPS_FETCH_TIMEOUT。请以秒为单位指定该值。

3. 创建到 Connector 的 RFC 目标连接（远程 SLT 场景）

连接器可以部署在满足要求的独立 SAP 实例上。在这种情况下，连接器通过 RFC 连接与 SLT 服务器通信。因此，需要建立 RFC 连接以启用该通信通道。

请参阅 RFC 连接指南 以获取设置说明。

4. 配置 Connector 以使用 SAP SLT（远程 SLT 场景）

如果 SLT 和连接器位于不同的实例上，请执行以下额外的配置步骤：

  • 打开事务 /n/PALANTIR/PARAM
  • 输入以下参数值：
    • 参数 ID： SLT
    • 参数名称： RFC_CONFIGURATION
    • 参数值： RFC configuration name created in the beginning of this section (eg, SLT_SERVER_RFC)

如果未在配置表中设置这些参数，它们将默认为以下值：

  • timestamp: OFF
  • fetchOption: XML
  • pageSize: 50000

大型表同步的性能注意事项

连接器使用 SAP 的 ODP 框架将数据复制到 Foundry。ODP 将数据从源系统复制到 ODP 队列（表名 ODQDATA_F）。数据暂存在 ODQ中，数据传输到 ODP 队列后，连接器开始将请求的数据分页传输到 /PALANTIR/PAG_01 和 /PALANTIR/PAG_02 表。所有页面成功传输到 Foundry 后，Foundry 会发送关闭请求以清理这些表，该关闭请求会删除 /PALANTIR/PAG* 表中的条目。

在运行初始同步（例如历史同步或批量同步）时，请仔细检查数据库容量规划并考虑空间需求。空间不足可能导致 SLT 复制作业和向 Foundry 的传输失败，因此请先根据要复制的表进行数据库容量规划准备工作。

用于解决已知 SAP 问题的参数

还有另外两个参数可用作 SAP 已知问题的解决方案。

问题：SAP SLT 服务器不提供日期/时间字段的确切字段长度

问题：SAP SLT 服务器不提供日期/时间字段的确切字段长度。此问题已通过一份 SAP 说明修复。但是，如果您确实遇到有关数据类型长度的问题，在该说明实施之前，可以设置以下参数：

  • 参数 ID = SLT
  • 参数名称 = SLT_DATA_XXX (XXX 指字段的技术名称）
  • 参数值 = Length of the data type

在 SAP_BASIS 的早期支持包（SP 14）中， DATS 字段被 SAP 设置为 16 个字符。但是， DATS 字段应为 8 个字符（YYYYMMDD). TIMS 字段也被 SAP 设置为 16 个字符； TIMS 数据为 6 个字符（HHMMSS).

要解决此问题，请设置以下参数：

参数 ID参数名称参数值
SLTSLT_DATA_DATS8
SLTSLT_DATA_TIMS6

问题：小数位数不为 3 位的 SAP QUAN 数据类型

问题：SAP 有专门用于数量和金额的数据类型。数量数据类型 QUAN 默认包含 3 位小数。当连接器尝试获取包含 QUAN 数据类型的数据时，会自动为这些 QUAN 数据类型创建 3 位小数。但是，某些包含 QUAN 数据类型的 SAP 表具有不同的小数位数，却在传输到 Foundry 时被当作具有 3 位小数处理。

要解决此问题，请使用以下参数：

  • 参数 ID = SLT
  • 参数名称 = SLT_DTYPE_XXX (XXX 指字段的（数据类型）
  • 参数值 = Data Type Name which will be taken Into account

按如下方式设置参数，将 QUAN 数据类型更改为 decimal 数据类型：

参数 ID参数名称参数值
SLTSLT_DTYPE_QUANDEC
