开始使用

设置数据集

本教程使用一个公开可用的数据集（download titanic_dataset.csv），其中包含泰坦尼克号乘客的信息。

该数据集包含泰坦尼克号乘客的姓名、年龄、性别以及其他身份信息。前往 Foundry 并打开你的个人 Project。创建一个名为 Code Workbook Tutorial 的文件夹，并将泰坦尼克号数据集上传到该文件夹中，命名为 titanic_dataset.

设置 Code Workbook

值 新建 按钮，然后选择 代码仓库（Code Repositories） 来创建一个新的 Workbook。

导入数据集

点击设置菜单下的 导入数据集 开始。在出现的对话框中，搜索 titanic_dataset。选择你在设置过程中创建的文件，该文件应位于 /user/Code Workbook Tutorial/titanic_dataset.

找到所需的数据集后，点击该文件，然后点击 Select 将数据集添加到你的图中。

使用 Python 转换数据

现在 titanic_dataset 已导入到工作簿中，我们可以使用代码和可复用的逻辑块对其进行转换。将鼠标悬停在 titanic_dataset 上并点击 + 符号，即可添加一个下游转换。这会弹出一个下拉菜单，显示各种转换选项——选择 Python。

图中现在会出现一个 Python 代码节点，连接线表明它是 titanic_dataset的子节点。为这个转换指定一个别名， titanic_filtered，方法是点击逻辑面板顶部的文本框。

默认情况下，新创建的转换不会在 Foundry 中保存为数据集。你可以点击 保存为数据集 开关，选择将转换的结果保存为数据集。 了解更多关于将转换保存为数据集的信息。 保存为数据集的转换有两个名称：别名，以及 Foundry 数据集的名称。

使用 Pandas 数据框

如果你更习惯使用 Pandas 语法，你可以在 Python 节点中使用 Pandas。更新 titanic_filtered 以使用 Pandas。

首先，我们需要更改 titanic_dataset的输入类型。点击逻辑面板中的 Inputs 选项卡并展开侧边栏。你会看到输入类型被设置为 Spark 数据框。点击下拉菜单并选择 Pandas 数据框，以将 titanic_dataset 的输入类型更改为 Pandas 数据框。

接下来，更新你的代码以使用 Pandas 数据框，执行相同的筛选操作。

def titanic_filtered(titanic_dataset):
    output_df = titanic_dataset[(titanic_dataset['Survived'] == 1) & (titanic_dataset['Sex'] == 'female')]
    return output_df

这段代码将输出一个包含泰坦尼克号女性幸存者的 Pandas 数据框。

使用控制台

控制台为 Code Workbook 提供了一个 REPL（读取-求值-打印循环），可以对图中的任何转换或输入数据集进行快速、即席分析。为了方便你使用偏好的语言快速迭代，工作簿中每种已启用的语言都有一个对应的控制台。

打开位于页面右侧的控制台。选择 Python 控制台：

你可以通过在 Python 中执行命令来快速试验数据。你还可以将转换中的代码发送到控制台运行，方法是选中代码并使用 键盘快捷键 Cmd+Shift+Enter （macOS）或 Ctrl+Shift+Enter (Windows)。
