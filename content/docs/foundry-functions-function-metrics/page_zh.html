函数指标

函数指标显示函数类型过去30天内的近实时使用情况。您可以在 函数类型概览 页面中访问这些指标，该页面位于 Ontology Manager中；也可以在 Workflow Lineage 中通过选择给定执行对应的函数节点来访问。以下指标可用：

  • 成功/失败指标： 通过成功和失败计数来监控函数的当前状态。这有助于快速识别问题并支持主动故障排查，让您能够在失败发生时立即处理。
  • P95时长指标： 跟踪每种函数类型的第95百分位数（P95）执行时长。该指标突出显示了执行时长的较高区间，可帮助您发现性能瓶颈，并优化工作流以实现稳定高效的运行。

您还可以访问 运行历史，其中提供了给定函数过去七天执行情况的完整视图。如需了解更多信息，请参阅 本体论与AIP可观测性。

所有指标均使用来自Foundry遥测服务（FTS）的最新数据进行近实时更新。这确保您能够获取最新信息，用于监控、调试和维护函数的健康状况。

您还可以使用 Observability Chart 小部件 （位于 Workshop 中）将函数指标直接嵌入到操作应用程序中，以便与工作流的其余部分一同监控资源健康状况。

函数失败类型

函数指标有多种可能会显示的失败类别。这些类别包括：

  • 运行时失败： 执行函数时发生了意外错误，通常是由于函数代码中存在缺陷或未处理的情况。
  • 超出资源限制： 函数影响的对象类型数量超出了允许的限制（默认情况下通常为 10,000）。
  • 面向用户的错误： 发生了专门用于向用户显示的错误，通常会提供有关出错原因或解决方法的指导。
  • 无效输入错误： 提供给函数的一个或多个输入无效，或不符合所需的标准。
  • 无效输出错误： 函数生成的输出无效，或不符合预期的格式或规则。
  • 不允许加载数据错误： 函数执行尝试加载数据（包括对象、对象集、用户或组），但未被允许这样做。
  • 编辑了未声明的对象类型错误： 函数执行尝试更新、创建或删除一个对象，而该对象的对象类型未在函数规范中声明。
  • 结构化错误： 函数执行遇到其规范中定义的结构化错误。
  • 部署错误： 函数执行因函数部署错误而失败。
  • 一致性快照错误： 函数因一致性快照错误而无法执行。

设置监控警报

您还可以配置监控规则，以便在性能下降或发生故障时接收警报。函数监控支持针对 P95 函数持续时间以及时间窗口内函数失败次数的警报。有关配置说明，请参阅 监控函数。

权限

要查看函数指标，您必须是该函数的 viewer 。
