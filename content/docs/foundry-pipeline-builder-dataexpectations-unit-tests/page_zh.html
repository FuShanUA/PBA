Pipeline Builder 中的单元测试

通过单元测试提高您在 Pipeline Builder 中管道的可靠性。这些测试是调试、检测破坏性变更以及最终确保更高质量管道的宝贵工具。

什么是单元测试？

与代码中的单元测试类似，Pipeline Builder 中的单元测试是一种检查管道逻辑在使用预定义输入进行测试时是否产生预期输出的方法。单元测试包括：

  • 测试输入
  • 转换节点
  • 预期输出

测试输入和预期输出是通过手动输入的表格创建的，但您可以复制粘贴以加快创建速度。您可以在主 Pipeline Builder 工作区中选择要测试的转换节点。有关创建单元测试的更多信息，请参见下文。

创建单元测试

  1. 在主工作区的右侧面板中，选择 单元测试 图标。



  2. 选择 创建新测试 （位于屏幕中央）或 新建测试 （位于右上角）。这将在工作区顶部打开一个对话框，提示您选择相关节点。



  3. 选择所有相关节点后，选择 开始时间.



    这将带您进入单元测试配置窗口。

    • 黄色节点对应于先前选择的转换节点。
    • 绿色节点对应于测试输入。
    • 蓝色节点对应于测试输出。

    对于每个单元测试，您必须填写输入和输出数据。



  4. 通过双击节点来填写输入数据或预期输出数据。这将带您进入以下页面：



    在左侧选择：

    • 复用 schema： 将输出 schema 设置为与所连接表格的 schema 匹配。
    • 来自数据集： 使用现有数据集中的 schema。
    • 添加列： 手动输入数据 schema。

    设置好 schema 后，在中间的表格中填写各行，然后选择 保存您的更改。，然后选择 返回图表.



  5. 对所有输入和输出数据集重复此步骤。

完成后，您将能够在右侧面板中看到手动输入的数据，其中详细列出了每个表格的行数和列数。

运行单元测试

对于每个单元测试，您可以选择 运行测试 使用

测试运行后，您可以在下方看到测试结果。要查看具体的表格结果，请选择 查看测试结果.

这将在屏幕底部打开一个视图，显示预期输出和实际收到的输出。

完成单元测试的编辑和查看后，您可以选择 关闭单元测试 （位于右上角）。

删除单元测试

要删除单元测试，请先选中它，然后使用右上角的三个点打开选项菜单。选择 删除测试用例.

编辑现有单元测试

选择 单元测试 图标以查看管道中单元测试的列表。选择铅笔图标以编辑所选的单元测试。

要更改单元测试中选定的测试转换，请使用 重新选择 按钮。这将带您返回选择页面。

如果您在已作为单元测试中测试转换的节点之间添加节点，所添加的节点将自动显示在现有单元测试中。

要更改任何测试输入或预期输出，您可以直接双击图表视图中的节点，或选择右侧面板上的铅笔图标。

完成单元测试的编辑后，选择 关闭单元测试 （位于右上角）以返回主图表。

提案中的单元测试

对单元测试的任何更改也会显示在提案页面的 单元测试 选项卡（位于左侧面板）中。

在提案页面上，您将看到 单元测试成功 部分。Pipeline Builder 会在合并提案之前检查单元测试是否通过。

流式处理中的单元测试

对于流式单元测试，测试输入数据需要额外的 ordering long 类型的值，每一行都需要一个。

排序列是流式单元测试所必需的元数据列，用于控制行发出的全局顺序，但不会影响测试数据的实际内容或 schema。排序值应为测试中所有测试数据源中每一行的唯一 long 类型值，行将按排序值从最低到最高的顺序从数据源发出。

排序对于从流式转换中获得确定性和期望的输出非常重要，尤其是对于连接（join）和合并（union）操作。
