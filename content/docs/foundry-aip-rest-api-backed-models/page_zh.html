由 REST API 数据源支撑的模型

您可以通过在 Data Connection 中使用 REST API 数据源来支撑已注册的模型，从而将 AIP 连接到外部托管的模型提供商或账户。当您的模型提供标准提供商 API 时，这是推荐的做法。

如何注册和使用您自己的模型

您必须是 注册管理员 才能注册模型 ，并且 拥有 Owner 或 Editor 权限（针对您按照以下步骤配置的 Data Connection 数据源）。

在 Data Connection 中创建 REST API 数据源

首先，请按照以下步骤在 Data Connection 中创建 REST API 数据源：

  1. 打开 Data Connection 应用程序，然后选择 新建数据源 > REST API ，用于您的模型提供商的端点。
  2. 为您的数据源输入 名称 ，然后选择一个 数据源位置 ，您能够在其中保留 Owner 或 Editor 权限。
  3. 配置 域基础 URL、 身份验证 方法以及 端口 ，用于您的模型提供商。
  4. 请确保开启 启用导出到此数据源 和 启用导出到此数据源而不进行标记验证 （位于 导出配置 部分）。
  5. 完成 REST API 数据源的配置。您可以参考 REST API 连接器文档 以了解更多详细信息。

在 Control Panel 中注册模型

接下来，请按照以下步骤在 Control Panel 中注册模型：

  1. 打开 Control Panel 并导航至 AIP 设置 扩展程序，然后选择 已注册模型 标签页。
  2. 选择 注册模型。
  3. 搜索并选择 REST API 源 RID，通过 选择源 rid 下拉菜单（位于 源配置 页面）完成。
  4. 请在 配置源 API 和 模型 API 配置 部分中提供模型详细信息，例如模型提供商名称、模型名称和 API 端点路径。
  5. 按端点定义模型的功能。您声明的功能将决定该模型可以驱动哪些 AIP 功能。启用 推理、 结构化输出和 工具调用 可确保 AI FDE 和 AIP Analyst 能够使用该模型。
  6. 定义模型的速率限制，这是在 Resource Management 应用程序中启用容量管理和使用情况可观测性所必需的：
    • 注册速率限制： 定义该注册可用的每分钟最大请求数或每分钟 token 数。项目级限制按这些注册限制的百分比计算。
    • 用户速率限制： 定义适用于 AI FDE、AIP Analyst 和其他按用户归因的应用程序中使用情况的每用户限制。
  7. 返回 AIP 设置 扩展（位于控制面板中），并为您的注册启用已注册模型访问权限。您可以为整个注册或特定用户组授予访问权限。

后续步骤

您的已注册模型现已可在 AIP 应用程序中使用。它会显示在 已注册模型 选项卡下，该选项卡位于模型选择器中，而模型选择器适用于 所有受支持的应用程序。
