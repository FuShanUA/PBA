开发者工具链

Palantir 平台附带一套开发者工具，使您能够在本体论之上进行构建，并通过新的工作流、应用程序和功能释放价值。借助 Palantir 的开发者工具链，您可以直接在开发环境中访问本体论的全部强大功能。

除了本文档其他部分介绍的数据连接和应用程序构建工具之外，Palantir 开发者工具链还提供：

  • 核心 API 和 SDK 向您的应用程序开放本体论。
  • 开发环境 和 以开发者为中心的功能 加速您的工作流。
  • Palantir MCP 使 AI IDE 和 AI 智能体能够使用 Palantir 上下文，并在整个 Foundry 中执行操作。
  • 本体论 MCP 将本体论资源作为 MCP 工具公开给外部 AI 智能体。
  • 计算模块 对您的代码进行容器化并扩展您的部署。

核心 API 和 SDK

Palantir 开发者产品的核心是 API 和 SDK，它们开放了整个平台，让您能够构建直接与 Palantir 平台和您的本体论数据集成的应用程序。

本体论 SDK (OSDK)

该 本体论 SDK (OSDK) 使开发者能够以 Python、Java 和 TypeScript 语言从其本体论生成 SDK。OSDK 让您能够访问对象类型、应用操作来更新本体论中的数据、调用函数，以及运行 AIP Logic 函数，用于 启用了 AIP 的 注册。平台内置的开发者控制台包含针对您的应用程序所选实体的本体论专属文档。应用程序以公共或机密客户端的身份使用 OAuth 流程来访问数据。

API

Palantir 的 API 为在 Palantir 平台上进行构建的用户提供支持，使其能够以编程方式管理平台访问权限以及支撑本体论的数据。API 参考文档也可在平台内通过 Developer Console 获取。

可用的 Palantir API 包括：

  • 数据集 — 读取、写入和管理数据集，包括分支、事务、文件和视图。
  • 文件系统 — 管理空间、项目、文件夹和资源角色。
  • 管理 — 管理用户、群组、组织、主机和标记。
  • 编排 — 触发构建、检查作业并配置计划任务。
  • 连接 — 管理连接、虚拟表以及来自外部数据源的文件或表导入。
  • SQL 查询 — 对数据集执行 SQL。
  • 媒体集 [Beta] — 上传、检索和管理媒体集及其条目。

请参阅完整的 API 文档 以获取完整的端点列表，包括模型、审计日志、数据健康检查、流、检查点以及 Notepad。

平台 SDK

Palantir 的平台 SDK 已公开提供，支持 Python ↗ 和 TypeScript ↗，并会随着新 API 的推出而不断扩展。这些 SDK 可以与本体论 SDK 配合使用，并共用相同的 Palantir 平台客户端。

开发者环境与功能

除了专注于数据连接的开发工具（例如 管道构建器 和 代码仓库）之外， 代码工作区 让您能够在 Palantir 平台上进行构建的同时，使用 VS Code 等熟悉的 IDE。 VS Code 工作区 已与 Developer Console 集成，让您能够快速 构建 React 应用程序。您可以通过平台内的 Developer Console 创建 VS Code 工作区。

Palantir 面向开发者的功能旨在加速在平台上进行构建的过程。诸如 全局分支 等功能有助于为端到端工作流的开发创建一个安全、精简的环境。

Palantir MCP

Palantir MCP 是 Model Context Protocol ↗ 的一个实现，允许 AI IDE 和 AI 智能体在 Palantir 平台上自主构建端到端应用程序——从数据集成到本体论配置，再到应用程序开发。此外，您还可以使用 Palantir MCP 让外部 AI 系统查询文档、元数据和数据，以及在平台上执行高级任务。开发者可以使用 Palantir MCP 将辅助任务自动化，同时专注于自己正在构建的系统。

Ontology MCP

Ontology MCP (OMCP) 是 Developer Console 的一项功能，可将您应用程序的本体论资源公开为 Model Context Protocol (MCP) 工具，使外部 AI 智能体能够与您的本体论进行交互。虽然 Palantir MCP 专为本体论构建者和开发工作流而设计，但 Ontology MCP 则面向本体论使用者：即需要安全地对生产环境中的本体论数据进行读写的外部 AI 智能体。

本体论 MCP 将对象类型、操作类型和查询函数作为 MCP 工具公开，并与桌面代理和无头代理框架集成。

计算模块

计算模块功能使您能够在 Palantir 平台上部署交互式容器，从而引入您现有的代码库（无论使用何种语言）并在平台内运行。例如，借助计算模块，您可以将第三方机器学习模型引入平台，并将其集成到您的工作流中。

有关计算模块的更多信息，您可以观看此官方 使用 AIP 构建：计算模块 ↗ 视频并参考 文档。

自定义端点

自定义端点 使开发人员能够配置和部署用户自定义的 API 端点，这些端点具有各自的 URL 模式、请求和响应结构以及规范，同时可利用 Foundry 的后端功能。这些端点由本体论通过操作和函数提供支撑。
