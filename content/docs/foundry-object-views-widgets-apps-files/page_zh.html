应用和文件

应用和文件小组件 支持在当前对象视图中嵌入、显示和链接其他 Foundry 应用。这些嵌入式小组件可以支持在其他应用中构建的资产，例如 Quiver 或 Slate。此外，它们还使对象视图能够显示媒体、上传文件、添加超链接，或允许对该对象进行评论和对话。

如果您有兴趣构建更复杂的对象视图，请考虑创建 由 Workshop 支撑的标签页。

以下部分小组件不具备对象感知能力。这意味着它们与对象视图中其他小组件的交互受限。 * 示例 1：使用评论小组件时，评论仅保存在该特定对象视图中，而不会写回到实际对象。如果这些评论在特定对象的上下文之外也可能有用，请考虑使用操作来捕获它们。 * 示例 2：使用“关联文件”添加的文件会保存在 Foundry 中，但并未关联到该对象。如果您希望这些文件可重复使用，请考虑使用 操作附件。 * 示例 3：嵌入 Slate 或 Contour 确实允许您传递参数，但它不会发布或使用筛选器，也不允许与其他小部件（例如图表小部件）进行交叉筛选。

Quiver 仪表板

有关如何将 Quiver 仪表板嵌入对象视图的详细步骤，请参阅 Quiver 仪表板文档。

Slate 应用

此小部件会在对象视图中显示一个 Slate 应用 ，并支持这两个应用之间的状态共享和交互。从对象视图到 Slate 应用，会提供当前对象上下文和活动筛选器状态。从 Slate 应用到对象视图，Slate 中提供了一组事件，这些事件映射到对象资源管理器中的行为，例如打开新的“对象”或“探索”标签页，以及更新对象视图筛选器。

配置

Slate 资源 选择要显示的 Slate 资源。请确保所有有权查看该对象的用户也都能查看该应用。

对 Slate 资源采用“响应式”设计将获得最佳效果，因为应用会根据对象视图布局和可用的屏幕尺寸调整大小。

默认参数 默认情况下，当前对象及其对象类型的 ID 会被传递到 Slate 仪表板，并可映射到变量。可以关闭这些传递，或更改其目标变量。默认变量名称为 objectId 和 objectTypeId。在 Slate 应用程序中，请确保在 Variable 选项卡中手动创建匹配的变量。

自定义参数 使用额外的自定义参数，将属性值或静态预定义值传入 Slate 应用程序。在 Slate 应用程序中创建匹配的变量，以捕获这些参数并在应用程序中使用它们。

在 Slate 中使用参数

配置好的参数会在 Slate 应用程序加载时传入其中。在配置 Slate 应用程序时，必须为每个参数在 Variable 面板中创建相应的变量。 了解有关如何使用变量的更多信息。 要检查从 Object Explorer 传递到 Slate 的参数的键和值，可以在对象视图编辑器的调试工具栏中选择“View parameters”。

访问对象视图筛选器

对象视图筛选器以 IObjectSetFilter 格式共享，以便与 Slate 中提供的对象集 API 轻松配合使用。它们会自动发送到 Slate，使用的是跨框架 postMessage 当它们发生变化时,也可以使用从 Slate 发送到 Object Explorer 的事件手动请求。当您的 Slate 仪表板首次准备好接收筛选条件时,可以使用此请求事件来触发发送筛选条件。

要在 Slate 中捕获筛选条件,您应该配置一个 slate.getMessage 事件处理程序,该处理程序接收 post message 载荷,将其解析为 JSON,然后将结果设置到变量中。 了解更多有关事件的信息。 以下内容应足以将筛选条件捕获到变量中:

从 Slate 触发事件

Slate 可用于在 Object Explorer 中触发事件的事件类型包括:

  • 在 Object Explorer 中打开新的对象标签页(使用对象 RID)
  • 在 Object Explorer 中打开新的对象标签页(使用对象主键)
  • 在 Object Explorer 中为给定对象集打开一个新的探索标签页
  • 将对象集筛选器发布到对象视图
  • 清除对象视图上的对象集筛选器
  • 刷新当前对象视图上的数据
  • 请求将对象视图筛选器重新发送到 Slate

使用 slate.sendMessage 操作触发这些事件。在此操作中，从自定义逻辑返回事件消息对象。 了解有关事件的更多信息。 每个事件的预期格式如下所列。如需调试事件集成的帮助，请使用对象视图编辑器的调试工具栏。当捕获到 post message 但事件负载存在某种错误时，该工具栏将显示警告。

媒体预览

在提供附件属性或指向某种类型媒体（图像、PDF 等）的 URL 属性时，此小部件将显示媒体文件的单个大型内联预览。

配置

要使用 Media Preview 小部件，您需要将当前查看的对象配置为包含附件属性。附件属性会将相关媒体存储在 Foundry 中，并通过继承所添加到的对象的权限，确保媒体具有正确的权限。请参阅 此页面 以了解如何向您的附件属性添加媒体。

或者，也可以使用 Media Preview 小部件，通过存储在属性中的 URL 来显示 Foundry 上已有的媒体。查看对象视图的用户需要同时拥有对该对象和媒体存储位置的访问权限。要向您的对象视图添加媒体，请按照以下步骤操作：

  1. 将媒体上传到 Foundry： 数据集可用作存储任意文件集合的一种方式。要创建此类数据集，您可以先将文件上传到文件夹，然后在弹出的窗口中选择 将所有文件捆绑为单个数据集。如果您仅上传单个文件，此选项将显示为 上传到不含架构的数据集。

创建此数据集后，您可以根据需要添加更多文件。为此，请点击 导入 在数据集预览的右上角。

在弹出的对话框中,选择要上传的其他文件。

  1. 添加 URL 列: 在当前所查看对象的支撑数据集中,添加一个新列,其中包含每行对应的媒体文件 URL。URL 应采用以下格式: https://{my-foundry-url}/foundry-data-proxy/api/web/dataproxy/datasets/{dataset rid}/transactions/{transaction rid}/{filename} 或者 https://{my-foundry-url}/foundry-data-proxy/api/web/dataproxy/datasets/{dataset rid}/views/{branch name}/{filename}
    • 示例: https://{my-foundry-url}/foundry-data-proxy/api/web/dataproxy/datasets/ri.foundry.main.dataset.39ce332b-1d74-40ca-be35-5a5b48459a9a/transactions/ri.foundry.main.transaction.00000000-0000-30d2-8067-4b5d9c819f4c/sample-doc.pdf
    • 注意:如果您使用的是 PDF,则 URL 应以 /foundry-data-proxy/api/dataproxy 开头,而非 /foundry-data-proxy/api/web/dataproxy
  2. 将该列标记为 hubble:media_url (在本体论中): 在本体论中为该列创建一个属性,并为其指定一个类型类,其 kind = hubble 且 name = media_url。
    • 其他媒体类型类:其他可能的选项有 hubble:icon 和 hubble:thumbnail。它们将分别使用此 URL 作为对象的图标和搜索结果卡片中的缩略图。
  3. 在 Object Explorer 中向对象视图添加媒体小部件: 目前有两种类型的内置媒体小部件: Media Preview 和 Media Thumbnails。如果您编辑对象视图并点击 Add Section 即可看到每种分区类型的说明。该小部件需要配置 Media Property,即包含您希望预览的媒体 URL 的属性。

其他可配置的参数:

  • 标题（必填）：要在小部件标头上显示的标题。
  • 图标（必填）：要在小部件标头上显示的标头。
  • 帮助信息：在工具提示中显示额外的帮助信息。
  • 高度：渲染媒体小部件的高度（以像素为单位）。

超链接

超链接小部件会创建一个按钮，用作指向网页的简单链接。您可以在对象视图中添加任意数量的链接，每个链接既可以是静态的（即所有对象实例使用相同的链接），也可以是针对每个对象的动态链接。

配置

  1. 链接打开位置 - 选择是在浏览器同一标签页（默认）、不同标签页还是弹出式窗口中打开。弹出式窗口不太可靠；可能会因浏览器/已安装的扩展程序而出现问题或被拦截。此设置将适用于所有对象
  2. 链接意图 - 5 种链接“意图”，用于确定链接按钮的颜色。 蓝图意图 ↗ 应用于按钮的 CSS 类（默认为无）：
    1. “None” - 灰色
    2. “Primary” - 蓝色
    3. “Success” - 绿色
    4. “Warning” - 橙色
    5. “Danger” - 红色
  3. URL 类型 - 3 种 URL 配置：
    1. 属性 - 包含 URL 的动态属性，该 URL 将用作超链接目标。
      1. 配置方法：(1) 选择对象类型（通常是当前正在查看的对象）；(2) 选择应从中获取链接的属性列。有一个切换选项，可在值为 null 时隐藏超链接按钮。
      2. 例如，您可以有两个 "Website" 对象，两者都带有字段 site_URL （在您的本体论中定义），其中对象 1 的 site_URL 设置为 https://palantir.com ，而对象 2 的 site_URL 设置为 https://palantir.com/uk。
    2. 硬编码 - 显示在所有对象上的静态 URL。只需复制粘贴该 URL，并确保它包含 https://
    3. 模板化 - 模板化 URL 允许您根据对象的属性自定义链接。您可以将任意属性置于单个花括号之间，从而将其引入 URL { }。
      1. 例如，如果您将报告 RID 保存为属性 report_rid，要打开与每个对象关联的报告，您可以使用 URL 模板 /workspace/report/{report_rid}。
  4. 链接标题 - 显示在超链接按钮上的文本标签。该标签对所有对象都相同。

常见问题和注意事项：

  • 如果超链接失效，用户将被重定向到 Object Explorer 的着陆页。

链接的文件

“关联文件”小部件使用户能够将正在查看的对象关联到文件，既可以通过资源选择器浏览并选择 Foundry 中已有的文件，也可以从本地计算机将新文件上传到 Foundry。

配置

此部分没有自定义选项。您仍然可以在“格式”选项卡下更改标题和其他常规格式设置。

常见问题和注意事项：

  • 通过此小部件上传的文件不会作为本体论的一部分被回写，也就是说，它们不会作为属性保存到当前对象上。若要实现这一点，请考虑改用支持回写的 Foundry Forms。
  • 目前无法隐藏这两个选项中的任何一个，因此“上传文件”和“关联新文件”始终都会同时显示。
  • 目前无法为文件上传设置默认目标位置，因此用户每次上传时都必须在 Foundry 中浏览查找目标位置。

Iframe

您可以在对象视图中嵌入 Slate 仪表板或其他 Foundry 应用的内联框架，作为“网页中的网页”。使用 iframe 可将当前对象的值传递给 Slate 中的筛选变量或 Contour 中的参数。

配置

要嵌入 iframe，您需要按照下文所述，使用 Handlebar 语法将链接配置为正确的 Foundry 地址。

  1. 必需： 复制您想要嵌入的页面的完整链接，并删除 /workspace/之前的所有文本。
    • 报表示例：对于 https://EXAMPLE.palantirfoundry.com/workspace/report/ri.report.main.report.ABCDEF-1234-5678，您应该保留 /workspace/report/ri.report.main.report.ABCDEF-1234-5678。
    • Slate 示例：对于 https://EXAMPLE.palantirfoundry.com/workspace/slate/documents/SLATE_DOCUMENT_NAME，您应该保留 /workspace/slate/documents/SLATE_DOCUMENT_NAME。
  2. 必需： 添加 embedded=true 以直接显示完整视图。添加前缀 /? （如果 embedded=true 是唯一的语句），或者添加 & （如果 embedded=true 附加到其他语句）。
    • 报表示例： /workspace/report/ri.report.main.report.ABCDEF-1234-5678/?embedded=true
    • Slate 示例： /workspace/slate/documents/SLATE_DOCUMENT_NAME/latest?&embedded=true
  3. 可选： 将值传递给 Slate 以筛选特定变量/参数。在 Object Explorer 中使用对象类型 ID、特定对象 ID 或特定属性 ID。使用 & 并在花括号内指定要注入到 Slate 的值，例如 {{propertyID}}。这基于 Handlebar 语法。
    • 报表示例： /workspace/report/ri.report.main.report.ABCDEF-1234-5678/?PARAMETER_NAME={{propertyID}}&embedded=true
    • Slate 示例： /workspace/slate/documents/SLATE_DOCUMENT_NAME/latest?VARIABLE_NAME={{propertyID}}&embedded=true

其他配置

  • 标准 iframe 与无标头 iframe 的区别在于，无标头 iframe 会隐藏微件的标头；微件标头通常包含图标、标题，以及在配置中的 格式 选项卡下为微件添加标题的选项。
  • iframe 微件允许您设置微件的高度。默认值为 500，需要手动调整。
  • 设置好 iframe 后，您将在对象视图中微件的下方看到一个辅助窗口（仅在编辑模式下显示）。该辅助窗口包含特定于对象的提示，并显示可以将哪些属性和 ID 传递给 Slate 和其他 Foundry 应用程序。
  • 可以通过在 URL 中添加以下内容来隐藏报告标头： &__rp_headerBar=hidden。
  • 在符合安全和策略要求的前提下，或许可以在 Foundry 之外嵌入外部网站。如果您认为这对于您的用例是必要的，请联系您的 Palantir 代表。

评论

此微件为协作处理同一对象的用户提供一个本地对话框，并可选择提及其他用户（通过标记 @user_name）。

这些注释不会记录在对象本身上，也无法在 Foundry 中对此对话进行任何后续搜索或重用。

配置

此部分没有自定义选项。您仍可以在 格式 选项卡下更改标题和其他常规格式。

源数据集更改时的注释行为

如果对象类型的源数据集发生更改，相应的注释信息流将会消失。

注释写回

通过此小组件添加的注释不会作为本体论的一部分被写回；也就是说，这些注释不会作为属性保存在当前对象上。如果您的注释用例包括搜索、分析或从注释中学习，请考虑使用操作。
