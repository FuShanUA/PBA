应用和文件

应用和文件小部件 支持在当前对象视图中嵌入、显示和链接其他 Foundry 应用。这些嵌入式小部件可以支持在其他应用中构建的资产，例如 的流可在 or 将收集到的信息存储在。此外，它们还支持对象视图显示媒体、上传文件、添加超链接，或允许对该对象进行评论和对话。

如果您有兴趣构建更复杂的对象视图，可以考虑创建 Workshop 支撑的选项卡.

下面的一些小部件不具备对象感知能力。这意味着它们与对象视图中其他小部件的交互是受限的。 * 示例 1：使用评论小部件时，评论仅保存在该特定对象视图中，不会写回到实际对象。如果这些评论在特定对象的上下文之外可能有用，请考虑使用操作来捕获它们。 * 示例 2：使用“关联文件”添加的文件保存在 Foundry 中，但并未关联到该对象。如果您希望这些文件可重复使用，请考虑使用 操作附件。 * 示例 3：嵌入 Slate 或 Contour 确实允许您传递参数，但它不会发布或使用筛选器，也不允许与其他小部件（如图表小部件）进行交叉筛选。

Slate 应用

此小部件显示一个 Slate 应用 在对象视图中，并支持两个应用之间的状态共享和交互。从对象视图到 Slate 应用，当前对象上下文和活动筛选器状态是可用的。从 Slate 应用到对象视图，Slate 中提供了一组事件，这些事件映射到对象资源管理器中的行为，例如打开新的对象或探索选项卡，以及更新对象视图筛选器。

配置

Slate 资源 选择要显示的 Slate 资源。请确保所有有权查看该对象的用户也都能查看该应用。

为 Slate 资源采用“响应式”设计将获得最佳效果，因为应用会根据对象视图布局和可用的屏幕尺寸自动调整大小。

默认参数 默认情况下，当前对象及其对象类型的 ID 会传递到 Slate 仪表板，并可映射到变量。这些 ID 可以被关闭或更改其目标变量。默认变量名称为 objectId 和 objectTypeId。在 Slate 应用中，请确保在变量选项卡中手动创建匹配的变量。

自定义参数 使用额外的自定义参数将属性值或静态预定义值传递到 Slate 应用中。在 Slate 应用中创建匹配的变量以捕获这些参数，并在应用中使用它们。

在 Slate 中使用参数

配置的参数会在 Slate 应用加载时传递进去。在配置 Slate 应用时，每个参数都必须在变量面板中创建对应的变量。 了解更多关于如何使用变量的信息。 要检查从对象资源管理器传递到 Slate 的参数的键和值，您可以在对象视图编辑器的调试工具栏中选择“查看参数”。

访问对象视图筛选器

对象视图筛选器以 IObjectSetFilter 格式共享，以便于在 Slate 中使用可用的对象集 API。当筛选器发生变化时，它们会通过跨框架 postMessage 自动发送到 Slate，也可以通过从 Slate 向对象资源管理器发送事件来手动请求。当您的 Slate 仪表板首次准备好接收筛选器时，可以使用此请求事件来触发发送筛选器。

要在 Slate 中捕获筛选器，您需要配置一个 slate.getMessage 事件处理器，该处理器接收 post message 负载，将其解析为 JSON，然后将结果设置到一个变量中。 了解更多关于事件的信息。 以下内容应足以将筛选器捕获到一个变量中：

从 Slate 触发事件

Slate 可用于在 Object Explorer 中触发的事件类型包括：

  • 在 Object Explorer 中打开新的对象标签页（使用对象 RID）
  • 在 Object Explorer 中打开新的对象标签页（使用对象主键）
  • 在 Object Explorer 中为给定对象集打开新的探索标签页
  • 将对象集筛选器发布到对象视图
  • 清除对象视图上的对象集筛选器
  • 刷新当前对象视图上的数据
  • 请求将对象视图筛选器重新发送到 Slate

使用 slate.sendMessage 操作触发这些事件。通过此操作，从自定义逻辑中返回事件消息对象。 了解更多关于事件的信息。 每个事件的预期格式如下所示。如需调试事件集成的帮助，请使用对象视图编辑器的调试工具栏。当捕获到 post message 但事件负载在某些方面不正确时，该工具栏将显示警告。

《媒体预览》：

此小部件显示媒体文件的单个大内联预览，可基于附件属性或某个包含媒体类型（图像、PDF 等）URL 的属性。

配置

要使用媒体预览小部件，您需要将当前查看的对象配置为包含附件属性。附件属性将相关媒体存储在 Foundry 中，并通过继承所添加对象的权限来确保媒体具有正确的权限。参见 此页面 以了解如何将媒体添加到您的附件属性。

或者，媒体预览小部件也可用于通过存储在属性中的 URL 显示 Foundry 上的现有媒体。查看对象视图的用户需要同时拥有对该对象以及媒体存储位置的访问权限。要将媒体添加到您的对象视图，请按照以下步骤操作：

  1. 将媒体上传到 Foundry： 数据集可用作存储任意文件集合的一种方式。要创建此类数据集，您可以先将文件上传到某个文件夹，然后在弹出的窗口中选择 将所有文件捆绑为单个数据集。如果您仅上传单个文件，此选项将显示为 上传到无 schema 的数据集.

创建此数据集后，您可以根据需要添加更多文件。为此，请点击 导入 （位于数据集预览的右上角）。

在弹出的对话框中，选择要上传的其他文件。

  1. 添加 URL 列： 在当前查看对象的支撑数据集中，添加一个新列，为每个对应的行包含媒体文件的 URL。URL 应采用以下格式： https://{my-foundry-url}/foundry-data-proxy/api/web/dataproxy/datasets/{dataset rid}/transactions/{transaction rid}/{filename} OR https://{my-foundry-url}/foundry-data-proxy/api/web/dataproxy/datasets/{dataset rid}/views/{branch name}/{filename}
    • 示例： https://{my-foundry-url}/foundry-data-proxy/api/web/dataproxy/datasets/ri.foundry.main.dataset.39ce332b-1d74-40ca-be35-5a5b48459a9a/transactions/ri.foundry.main.transaction.00000000-0000-30d2-8067-4b5d9c819f4c/sample-doc.pdf
    • 注意：如果您使用的是 PDF，URL 应以 /foundry-data-proxy/api/dataproxy 开头，而不是 /foundry-data-proxy/api/web/dataproxy
  2. 将该列标记为 hubble:media_url （在本体论中）： 在本体论中为该列创建一个属性，并为其指定一个 Typeclass，其 kind = hubble 且 name = media_url.
    • 其他媒体 Typeclass：其他可选项为 hubble:icon and hubble:thumbnail。它们将分别使用此 URL 作为对象的图标或搜索结果卡片中的缩略图。
  3. 在 Object Explorer 中向对象视图添加媒体小部件： 目前有两种类型的内置媒体小部件： 《媒体预览》： and 媒体缩略图。如果您编辑对象视图并点击 添加分区 您可以查看每种类型板块的说明。该小部件需要配置 媒体属性，即包含您要预览的媒体 URL 的属性。

其他可配置的参数：

  • 标题（必填）：显示在小部件标题栏上的标题。
  • 图标（必填）：显示在小部件标题栏上的图标。
  • 帮助信息：在工具提示中显示额外的帮助信息。
  • 高度：渲染媒体小部件的高度（以像素为单位）。

超链接

超链接小部件会创建一个按钮，用作指向网页的简单链接。您可以向对象视图添加任意数量的链接，每个链接可以是静态的（即所有对象实例使用相同的链接），也可以是针对每个对象的动态链接。

配置

  1. 链接打开方式 - 选择是在浏览器的同一标签页（默认）、不同标签页还是弹出窗口中打开。弹出窗口的可靠性较低；可能会根据浏览器/已安装的扩展程序导致问题或被拦截。此设置将应用于所有对象
  2. 链接意图 - 5 种链接“意图”，用于确定链接按钮的颜色。 Blueprint Intent ↗ 应用于按钮的 CSS 类（默认为无）：
    1. “None” - 灰色
    2. “Primary” - 蓝色
    3. “Success” - 绿色
    4. “Warning” - 橙色
    5. “Danger” - 红色
  3. URL 类型 - 3 种 URL 配置类型：
    1. 属性 - 一个包含 URL 的动态属性，用作超链接目标。
      1. 配置方法：(1) 选择对象类型（通常是当前查看的对象）；(2) 选择链接应取自的属性列。有一个切换选项，可在值为 null 时隐藏超链接按钮。
      2. 例如，你可以有 2 个“网站”对象，它们都具有字段 site_URL 在本体论中定义，其中对象 1 具有 site_URL 设置为 https://palantir.com 而对象 2 具有 site_URL 设置为 https://palantir.com/uk.
    2. 硬编码 - 一个在所有对象上显示的静态 URL。只需复制粘贴该 URL，并确保它具有 https://
    3. 模板化 - 模板化 URL 允许你根据对象的属性自定义链接。你可以通过将属性封装在单花括号之间，将其带入 URL 中 { }.
      1. 例如，如果你将报表 RID 保存为属性 report_rid，你可以使用 URL 模板创建一个按钮，打开与每个对象关联的报表 /workspace/report/{report_rid}.
  4. 链接标题 - 显示在超链接按钮上的文本标签。所有对象的该标签都相同。

常见问题和注意事项：

  • 如果超链接失效，用户将被重定向到 Object Explorer 的登录页面。

关联文件

关联文件（Linked Files）小部件使用户能够将当前查看的对象链接到文件，既可以通过资源选择器浏览并选择 Foundry 中已有的文件，也可以从本地计算机将新文件上传到 Foundry。

配置

此部分没有自定义选项。你仍然可以在“格式”选项卡下更改标题和其他常规格式。

常见问题和注意事项：

  • 通过此小部件上传的文件不会作为本体论的一部分写回，即它们不会保存为当前对象的属性。要实现该功能，请考虑使用带写回功能的 Foundry Forms。
  • 目前无法隐藏两个选项中的任何一个，因此它始终同时显示“上传文件”和“链接新文件”。
  • 目前无法为文件上传设置默认目标位置，因此用户每次上传时都必须在 Foundry 中浏览选择目标位置。

Iframe

你可以在对象视图中嵌入 Slate 仪表板或其他 Foundry 应用的内联框架，作为“网页中的网页”。使用 iframe 可以将当前对象的值传递给 Slate 中的筛选变量或 Contour 中的参数。

配置

要嵌入 iframe，你需要使用 Handlebar 语法配置指向正确 Foundry 地址的链接，如下所述。

  1. Range： 复制你希望嵌入的页面的完整链接，并删除之前的所有文本 /workspace/.
    • 报表示例：对于 https://EXAMPLE.palantirfoundry.com/workspace/report/ri.report.main.report.ABCDEF-1234-5678，你应该保留 /workspace/report/ri.report.main.report.ABCDEF-1234-5678.
    • Slate 示例：对于 https://EXAMPLE.palantirfoundry.com/workspace/slate/documents/SLATE_DOCUMENT_NAME，你应该保留 /workspace/slate/documents/SLATE_DOCUMENT_NAME.
  2. Range： 将 embedded=true 以直接显示完整视图。添加前缀 /? if embedded=true 是唯一的语句，或者 & if embedded=true 附加到其他语句。
    • 报表示例： /workspace/report/ri.report.main.report.ABCDEF-1234-5678/?embedded=true
    • Slate 示例： /workspace/slate/documents/SLATE_DOCUMENT_NAME/latest?&embedded=true
  3. 可选： 将值传递给 Slate 以筛选特定变量/参数。在 Object Explorer 中使用对象类型 ID、特定对象 ID 或特定属性 ID。使用 & 并在花括号内说明你希望注入到 Slate 的值，例如 {{propertyID}}。这基于 Handlebar 语法。
    • 报表示例： /workspace/report/ri.report.main.report.ABCDEF-1234-5678/?PARAMETER_NAME={{propertyID}}&embedded=true
    • Slate 示例： /workspace/slate/documents/SLATE_DOCUMENT_NAME/latest?VARIABLE_NAME={{propertyID}}&embedded=true

其他配置

  • 标准 iframe 与无头 iframe 的区别在于，无头 iframe 会隐藏小部件的头部；小部件头部通常包含图标、标题，以及在配置中的 格式 选项卡下为小部件添加标题的选项。
  • iframe 小部件允许你设置小部件的高度。默认值为 500，需要手动调整。
  • 设置 iframe 后，您将在对象视图中的小组件下方看到一个辅助窗口（仅在编辑模式下显示）。该辅助窗口包含特定于对象的提示，并显示可以传递给 Slate 和其他 Foundry 应用程序的属性和 ID。
  • 可以通过在 URL 中添加以下内容来隐藏报告标题： &__rp_headerBar=hidden.
  • 在 Foundry 之外嵌入外部网站可能可行，但需符合安全和政策要求。如果您认为您的用例需要这样做，请联系您的 Palantir 代表。

评论

此小组件为协作处理对象的用户启用本地对话框，并可以选择提及其他用户（通过标记 @user_name).

这些评论不会捕获到对象本身上，也无法在 Foundry 中对此对话进行未来的搜索或重用。

配置

本部分没有自定义选项。您仍可以在以下位置更改标题和其他常规格式 格式 标签页。

源数据集更改时的评论行为

如果对象类型的源数据集发生更改，相应的评论流将消失。

评论的写回

通过此小组件添加的评论不会作为本体论的一部分写回；也就是说，这些评论不会保存为当前对象上的属性。如果您的评论用例包括搜索、分析或从评论中学习，请考虑使用操作。
