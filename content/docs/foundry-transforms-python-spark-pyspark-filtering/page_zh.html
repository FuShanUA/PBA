过滤

Filter, where

DataFrame.filter(expression)

返回一个新的 DataFrame ，其中包含由布尔表达式确定的行子集。该 expression 参数是一个布尔列表达式，可以通过多种方式派生。

filter 在转换的开头而非接近结尾处使用，以减少不必要的计算工作并提升构建时间性能。

如果您的数据集包含大量条目，但您只关注基于特定条件存在的行的子集。

Copied!
1
df = df.filter(F.col("age") >= 21) # limit dataset to only people over age 21

where 是 filter 的别名，两者功能完全相同（具体使用哪个方法名称，取决于您或您的团队认为哪个名称读起来更清晰）：

Copied!
1
df = df.where(F.col("age") >= 21) # limit dataset to only people over age 21

您还可以通过几种不同的方式来链式组合过滤器：

Copied!
1
2
df = df.filter(F.col("age") >= 21).filter(F.col("age") < 35) # or...
df = df.filter((F.col("age") >= 21) & (F.col("age") < 35)) # group comparisons using parenthesis to ensure correct order of evaluation.

常量（字面量）

每当您将某一列与常量（即“字面量”，例如单个硬编码的字符串、日期或数字）进行比较时，PySpark 实际上会将这种基本的 Python 数据类型求值为一个“字面量”（与声明 F.lit(value)）。字面量只是一个带有静态值的列表达式。在继续之前，了解这一重要区别非常重要，因为它意味着所有与字面量的比较（无论是隐式还是显式）都可以用具名列来替代。这意味着您可以轻松进行依赖于同一行中其他列的动态比较。

在某些上下文中，字面量无法被正确解释。例如，在与字符串进行比较时，您想要引用的是以该字符串命名的列还是字符串本身，可能会产生歧义。

Copied!
1
2
df = df.filter("X" == "Y") # Do X and Y refer to columns or literals?
dff = df.filter(F.col("X") == F.lit("Y")) # Unambiguous.

逻辑运算

PySpark 提供了许多二元逻辑运算。这些运算的结果始终是布尔列表达式的实例，可用于组合条件。

由于逻辑运算符的参数是整列数据，而不是 Python 基本类型，因此我们无法使用熟悉的 and 或 or Python 运算符。这些运算符要求两个参数都已求值为单个布尔值。PySpark 能够解释 & （按位与）、 | （按位或）运算符，以及 ~ 取反（波浪号）符号，来构建在所有行上运行效率极高的 SQL 查询。

这对我们的帮助之一是,它允许使用命名变量来引用二元运算的值。因此,为了提高可读性和清晰度,尤其是在筛选多个属性时,您可以为每个比较指定描述性名称:

# filter for records where users are aged [21, 35), or has first_name="John", or last_name=None (null)
at_least_21 = F.col("age") >= 21
younger_than_35 = F.col("age") < 35
within_age_range = at_least_21 & younger_than_35
name_is_john = F.col("first_name") == "John"
last_name_is_null = F.isnull(F.col("last_name"))
df = df.where(within_age_range | name_is_john | last_name_is_null)
return df

这对我们的另一种帮助是,我们可以利用逻辑运算来提供筛选逻辑:

  • &: 与

    Copied!
    1
df = df.filter(condition_a & condition_b)

  • |: 或

    Copied!
    1
df = df.filter(condition_a | condition_b)

  • ^: 异或

    Copied!
    1
df = df.filter(condition_a ^ condition_b)

  • ~: 非

    Copied!
    1
df = df.filter(~condition_a)

Like、rlike

上述 like 和 rlike 方法分别支持使用 SQL LIKE 和正则表达式语法进行模式匹配。

  • 对于简单的子字符串搜索,请使用 like。
  • 对于更复杂的模式匹配,请使用 rlike。

Column.like(sql_like)

基于 SQL LIKE 匹配返回一个布尔列,匹配模式由字面字符串或列提供:

Copied!
1
df = df.filter(F.col('name').like('Al%'))
agename
2"Alice"

SQL LIKE 通配符:

  • %: 表示 ≥ 0 个字符
  • _: 表示单个字符

示例(来自 w3schools ↗):

LIKE 运算符描述
Column.like('a%')查找以 "a" 开头的任意值
Column.like('%a')查找以 "a" 结尾的任意值
Column.like('%or%')查找在任意位置包含 "or" 的值
Column.like('_r%')查找在第二个位置包含 "r" 的值
Column.like('a_%_%')查找所有以 "a" 开头且字符数 ≥ 3 的值
Column.like('a%o')查找所有以 "a" 开头且以 "o" 结尾的值

Column.rlike(regex)

返回一个基于正则表达式匹配的布尔列表达式，该正则表达式由字符串字面量或列提供：

Column.startswith(string)

返回一个布尔列表达式，指示该列的字符串值是否以参数中提供的字符串（字面量或其他列）开头。

Copied!
1
df = df.filter(F.col("id").startswith("prefix-"))

Column.endswith(string)

返回一个布尔列表达式，指示该列的字符串值是否以参数中提供的字符串（字面量或其他列）结尾。

Copied!
1
df = df.filter(F.col("id").endswith("-suffix"))

Column.contains(string)

返回一个布尔列表达式，指示该列的字符串值是否包含参数中提供的字符串（字面量或其他列）。

Copied!
1
df = df.filter(F.col("id").contains("string"))
