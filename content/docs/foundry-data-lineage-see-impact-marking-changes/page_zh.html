查看标记更改的影响

您可以使用数据血缘来评估数据集标记的更改如何影响派生数据集。这在以下情况下非常有用 移除标记.

模拟不会考虑未最终确定的更改

标记模拟依赖于最近的数据集构建，不会考虑尚未最终确定的更改。请确认您使用的是最新版本的数据。

访问模拟模式

  1. 打开 访问信息 侧面板。
  2. 默认启用预览确认 模拟访问要求.
  3. 在图表上选择任意数据集。
  4. 点击设置菜单下的 编辑标记.

模拟标记更改

要模拟标记的应用，请搜索您想要应用的标记，勾选该标记旁边的复选框，然后选择 模拟更改 按钮。

已应用于数据集的标记将显示为已选中状态。要模拟标记的移除，请取消勾选该标记旁边的复选框，然后点击 模拟更改.

您只能移除直接应用于数据集上的标记。无法模拟移除通过数据集血缘或从父项目继承的标记。

分析模拟图表

在模拟模式下，图表的颜色将指示受标记更改影响的数据集。图表颜色在界面中已标注，可表示以下数据集状态：

  • 已应用模拟更改 显示在您已应用更改的数据集上。
  • 访问受影响 显示在更改前后标记将发生变化的数据集上。
  • 访问不受影响 显示在更改前后标记将保持不变的数据集上。
  • 无可见事务 显示在尚未构建的数据集上，或您没有权限查看事务的数据集上。

通过选择任意数据集， 访问信息 侧面板将显示模拟的访问要求。您可以打开和关闭模拟模式来查看差异，而不会丢失任何模拟更改。

了解更改的技巧

在进行更改之前，我们建议查阅 标记文档 以详细了解标记对用户的影响。

在模拟标记时，请考虑以下几点：

  • 数据集可以 停止传播标记 通过代码.
    • 在监听器设置向导的 权限 着色，数据血缘图表上停止传播标记的节点表示数据访问已 通过代码修改。此消息也会显示在 访问信息 节点属性侧面板的部分中。
    • 在代码助手中，您可以使用术语检查数据集的代码，以查看它是否停止传播标记 stop_propagating.
  • 数据集可以从 其他输入接收传播的标记；点击数据集节点中的左箭头可展开数据集输入。
  • 标记可以应用于 父项目或文件夹；当未启用模拟模式时，标记左侧将显示文件夹图标；当启用模拟模式时，标记模拟菜单中将显示文件夹图标。
