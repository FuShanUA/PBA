文本节点

您可以在管道中添加文本节点，以帮助记录文档并突出图中的细节。文本节点呈现在其他图节点的背景中，让您可以将它们用作分区线或分组标签，从而直观地组织复杂的管道。文本节点使用 Markdown 语法 ↗，并且可以像常规节点一样着色。它们不会受布局选项的影响，也不会附加到图上的任何特定节点。

添加文本节点

  1. 要向图中添加文本节点，请选择 文本 （位于图左上方）。



  2. 双击文本节点进行编辑并添加 Markdown 文本。输入时，更改会自动保存。



  3. 要退出编辑模式，请使用键盘快捷键 Mod+Enter 或 Escape，或在文本节点外部单击。要放弃更改并恢复到之前的版本，请使用编辑时可用的放弃选项。

为文本节点着色

要为文本节点着色，请右键单击并选择 为节点着色。选择一种颜色或添加新颜色。

您还可以使用右下角的三条线来调整文本节点的大小。如果文本长度超过文本节点的长度，该节点将自动变为可滚动。

此功能也适用于 Workflow Lineage。
