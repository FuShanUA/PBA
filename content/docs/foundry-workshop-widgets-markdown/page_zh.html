《Markdown》：

直方图 《Markdown》： 小组件支持渲染带有 Markdown 格式的文本。小组件中的高级功能可用于启用其他工作流，例如文本的归属、引用和用户标记。

配置 Markdown 小组件的模块构建者可以使用以下功能：

  • 基本 Markdown 文本格式，例如粗体、斜体、删除线和高亮
  • 更高级的 Markdown 格式，例如标题、表格、块样式、代码样式和 URL

  • 从特定高亮锚点文本嵌入到本体论对象的引用
  • 从特定高亮锚点文本触发点击 Workshop 事件

  • 在文本的特定部分显示标注对象
  • 从显示的标注对象触发点击 Workshop 操作和事件
  • 在文本的特定部分创建新的标注对象

配置选项

下面的截图显示了一个未配置的 Markdown 小组件的初始状态及其初始配置面板。

对于 Markdown 小组件，核心配置选项如下：

  • 输入数据：文本/变量

    • 文本： 如果选择文本选项，构建者可以直接在配置面板中输入他们想要显示的 Markdown 输入文本。
    • 选择此资源模式时，输入资源由一个字符串变量提供，该变量应包含图、图指针或图模板的 RID。 如果选择变量选项，可以选择一个字符串变量作为要显示的 Markdown 输入文本。

  • 显示选项：

    • 标签类型配置

      • 标准： 默认情况下，此选项处于启用状态，并以标准 Markdown 格式显示输入内容。
      • 内联引用： 如果启用，则允许在文本中嵌入对本体论对象的引用以及点击 Workshop 事件。这是 Markdown 语法的一个自定义扩展；请参阅 内联引用 部分以了解更多信息。
      • 标注： 如果启用，则允许显示嵌入在文本中的标注对象、对现有标注对象的用户交互，以及使用小组件创建新的标注对象。请参阅 标注 部分以了解更多信息。

    • 启用等宽字体： 切换以启用/禁用在小组件中以等宽字体显示文本。

    • 启用滚动： 切换以启用/禁用小组件的滚动。

    • 允许长单词换行： 切换以启用/禁用超出小组件宽度的长且不间断字符串（例如长 URL）的换行。启用时（这是新小组件的默认设置），此类字符串会换行到下一行，而不是溢出小组件。

    • 在换行符处断行： 切换以控制 Markdown 源中单个换行符的渲染方式。启用时（这是新小组件的默认设置），源中的单个换行符在渲染输出中开始新的一行。禁用时，单个换行符会折叠为空格，遵循标准 Markdown 渲染。

    • 文本对齐： 设置小组件内渲染的 Markdown 内容的对齐方式。选择 的数据集。选择另一个数据集节点作为 （默认值）、 居中，或 的数据集。点击.

      在 Markdown 表格语法中定义的显式逐列对齐（例如， | :---: |）优先于小组件级别的文本对齐设置。无论选择何种对齐方式，代码块都保持左对齐和全宽。

  • 用户文本选择：

    • 输出用户选择的原始文本： 将用户选择的文本输出为原始 Markdown 字符串。
      • 选定的文本： 输出的字符串变量，包含用户选择的文本（原始 Markdown 格式）。
    • 输出用户选择的索引： 将用户选定文本的起始和结束索引输出为数值变量。
      • 选定内容起始索引： 数值输出变量，包含用户选定文本的起始索引。
      • 选定内容结束索引： 数值输出变量，包含用户选定文本的结束索引。

文本高亮

直方图 ==text== 语法会应用单一的固定高亮颜色。此颜色无法通过 Markdown 语法更改：没有任何属性、参数或替代语法可以设置高亮颜色，因此 ==text== 始终以默认颜色呈现。

由于该小部件不呈现 HTML，因此诸如 <mark style="background-color: blue">text</mark> 之类的行内样式也无法更改颜色，而是会显示为字面文本。参见 局限性.

要以其他颜色显示高亮，请使用以下由配置驱动的选项之一，其中颜色是在小部件配置面板中设置的，而不是在 Markdown 文本中设置的：

  • 行内引用： 设置 高亮颜色 为每个被引用的对象类型设置。当高亮文本对应于本体论对象时，请使用此选项。参见 内联引用.
  • 注释： 设置 高亮颜色 为每个注释层设置。当高亮文本由存储在注释对象上的起始和结束索引定义时，或者当用户需要自行创建高亮时，请使用此选项。参见 标注.

行内引用支持静态定义的颜色、从已配置格式的本体论属性继承的颜色，或基于对象属性值的条件格式规则。注释支持静态定义的颜色或条件格式规则。条件格式可以为同一对象类型或注释层的对象显示不同的颜色。

Markdown 小部件中的对象引用

行内引用

作为一种高级功能，Markdown 小部件允许构建者标记 Markdown 文本的子集（“锚点”），然后使用这些锚点链接到特定的本体论对象并触发 Workshop 点击事件。

创建此类锚点的格式如下：

Copied!
1
:objectreference[$text_to_display]{objectType="$object_type_id" primaryKey="$object_primary_key"}

以下示例在一个句子中引用了两个 Flight Alerts 对象。首先，查看用户屏幕上应显示的预期最终状态。注意：下面引用的每个 Flight Alert 对象都可由用户单独选择，并随后成为 Markdown 小部件输出的所选对象集。

为实现上述效果，其支撑的 Markdown 输入如下：

Newark airport has __*rarely*__ seen flight issues in May, but there were two high-priority delays: :objectreference[Alert A00150]{objectType="flight-alert" primaryKey="A00150"} and :objectreference[Alert A00182]{objectType="flight-alert" primaryKey="A00182"}

除了上述针对 Markdown 输入的语法之外，构建者还可以为对象引用配置以下选项：

  • 已选对象集： 使用对象引用时必需。这是 Markdown 小部件的输出对象集。当用户在 Markdown 小部件中选择某个对象引用时，该对象将被输出到此对象集变量中。
  • 对象类型： 使用对象引用时必需。构建者应选择将在 Markdown 小部件中引用的所有对象类型。添加对象类型后，构建者还可以在内部配置面板中配置条件格式规则。如果在 Markdown 小部件中引用了某个对象类型，但未在此列表中进行配置，则该对象引用将不会显示在 Markdown 小部件中。
    • 对象类型： 指定要进一步配置颜色和事件选项的对象类型。
    • 高亮颜色： 选择静态颜色、从具有本体论格式的属性继承颜色，或定义自定义规则来确定颜色。
    • 选中时覆盖事件： 配置 Workshop 事件以针对指定的对象类型触发。这些事件将覆盖选中时的任何其他事件。
  • 选择行为： 控制 Markdown 部件内的选择行为。
    • If 无高亮 时，在 Markdown 部件中选择对象引用不会产生选中状态。
    • If 高亮最后选中项 时，在 Markdown 部件中选择对象引用将使最近选中的锚文本高亮显示。
    • If 高亮选中的引用 时，Markdown 部件内的高亮基于所选对象集的内容。当 Markdown 中的对象引用与来自另一个部件的对象呈 1:1 对应，且两个部件的所选对象集相同时，此选项效果最佳。
  • 选中时事件： 此选项允许模块构建者配置 Workshop 事件，在 Markdown 部件中选中对象引用时触发（例如，使包含更详细对象视图的抽屉出现）。

直方图 :objectreference 渲染器使用 objectType 和 primaryKey 属性来解析引用。高亮颜色不是语法的一部分：它根据 高亮颜色 为匹配的对象类型所配置的内容来解析。要以两种不同的静态颜色显示两个引用，请引用两种不同的对象类型，并为每种类型配置不同的 高亮颜色 ，如下例所示：

Two delays were reported at :objectreference[Newark]{objectType="airport" primaryKey="EWR"}:
:objectreference[Alert A00150]{objectType="flight-alert" primaryKey="A00150"} and
:objectreference[Alert A00182]{objectType="flight-alert" primaryKey="A00182"}.

使用上述输入， airport 引用和两个 flight-alert 引用将分别以 高亮颜色 为其各自对象类型设置的颜色显示。在语法本身中添加颜色属性无效，且未在 ,其中显示地图上各对象类型的对象数量。下方,每种属性类型各有一个部分,涵盖地图上存在的所有对象类型。面板顶部的筛选框允许您将结果筛选为名称匹配的属性。 下列出的对象类型的引用将显示为纯文本。

颜色也可以在同一对象类型的各个对象之间变化。为此，请将对象类型的 高亮颜色 设置为继承自配置了格式的本体论属性，或基于属性值定义条件格式规则。

标注

直方图 标注 选项可用于使用 Markdown 部件在文本上显示标注对象。此选项还允许用户与部件内的文本进行交互，方法是在选定的文本部分上创建新的标注对象，或对显示的标注对象运行操作和事件。

标注对象使用从零开始的数字索引捕获选定的文本，其中包含起始索引（含）和结束索引（不含），以表示文本选择的开始和结束位置。Markdown 部件标注目前不支持负索引。

选择 标注 选项后，将提供以下配置：

  • 显示现有标注 配置单独的标注对象图层，以在部件内显示各种标注。
    • 标注输入
      • 名称： 在部件配置中设置标注图层的名称。
      • 标注对象集： 指定包含要显示的标注对象类型的对象集。
      • 起始索引： 设置表示标注起始索引（含）的数字对象属性。
      • 结束索引： 设置表示标注结束索引（不含）的数字对象属性。
    • 现有标注交互
      • 选中的标注： 包含当前选中的标注对象的对象集。
      • 选中时事件： 设置在选中标注对象时触发的事件。
      • 在工具提示中显示的属性： 指定要在标注对象的悬停工具提示中显示的对象属性。
      • 悬停交互： 配置悬停交互（如操作和事件），这些交互将显示在标注对象的悬停工具提示中。
        • 图标： 设置悬停交互显示的图标。
        • 标题： 设置悬停交互显示的标题。该标题在将鼠标悬停在交互图标上时出现。
        • 交互： 配置可在标注对象上触发的操作或事件。
          • 悬停对象： 一个特殊的操作参数值，可用于引用悬停的标注对象。
    • 标注显示选项
      • 高亮颜色： 设置用于显示标注的颜色。可以静态定义自定义颜色，也可以设置条件格式规则。
      • 标注格式： 设置标注的显示方式。选项包括彩色高亮、使用实线或虚线的下划线，或同时使用高亮和下划线来显示标注。
  • 通过操作或事件创建标注： 配置操作或事件，以便在组件中高亮显示文本时创建新的标注对象。
    • 图标： 设置文本高亮显示时显示的图标。
    • 标题： 设置文本高亮显示时显示的标题。该标题在鼠标悬停于图标上时显示。
    • 交互： 配置可在高亮显示的文本上触发的操作或事件。
      • 高亮显示的文本： 一个特殊的操作参数值，可用于引用组件中高亮显示的文本。

局限性

Markdown 组件不支持渲染 HTML。提供给 Markdown 组件的 HTML 将作为文本渲染。这包括内联样式，因此无法使用 HTML 来控制渲染输出中的颜色、字体或间距。

直方图 ==text== highlight 语法会应用单一固定的颜色，无法在 Markdown 中更改。彩色高亮可在组件配置面板中的对象类型或标注层上进行配置。参见 文本高亮显示.
