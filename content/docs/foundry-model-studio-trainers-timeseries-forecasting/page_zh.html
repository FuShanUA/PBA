时间序列预测训练器

时间序列预测训练器会并行或按顺序训练多个模型，以帮助其确定表现最佳的模型。如果该训练器判定多个模型的加权集成表现优于任何单个模型，则还可以利用集成方法。该训练器是使用 AutoGluon 的 ↗ TimeSeriesPredictor 类构建的。

时间序列预测训练器依赖于准确的历史时间序列数据，在多个预定义的前瞻步长上预测未来数据。模型集成的结构可在输出模型的实验页面的 Plots部分查看。

已训练的模型

在内部，将会训练多个模型，除非通过排除相应模型或使用 hyperparameters将其禁用。

以下类型的模型可供训练：

  • AutoETS： 自动调优的指数平滑模型。
  • DeepAR： 自回归预测模型。
  • DirectTabular： 表格回归模型（一次性预测所有值）。
  • ETS： 朴素指数平滑模型。
  • NPTS： 非参数时间序列预测模型。
  • Naive： 基线模型，将时间戳 t 处的值设为 t-1处观测到的值。
  • PatchTST： 基于 Transformer 的时间序列预测模型。
  • RecursiveTabular： 类似于 DirectTabular，但会逐个预测值。
  • SeasonalNaive： 基线模型，将时间戳 t 等于该时间点的观测值 t-1 来自同一季节。
  • TemporalFusionTransformer： 一种结合了 LSTM 层和 Transformer 的深度学习模型，用于预测未来值的分位数。
  • Theta： Theta 预测模型。
  • TiDE： 时间序列密集编码器模型。

数据集

时间序列训练器对输入数据集的配置要求比 回归 或 分类 训练器更高。回归和分类训练器只需要一个训练数据集，而时间序列预测训练器则需要一个训练数据集和一个相应的静态数据集。

训练数据集

训练数据集应为时间序列数据集，至少包含一个时间戳列和一个目标值列。目标值列是模型将要预测的内容。

此外，训练数据集还支持以下选项的列映射：

  • 物品 ID： 当您在单个数据集中跟踪多个时间序列时，物品 ID 列映射会非常有用。例如，包含销售历史的数据集可能包含商品的物品 ID（例如 SKU），从而可以训练模型来相互独立地预测各个物品。
  • 已知协变量： 已知协变量是指在整个预测期内都已知的列。例如，列可以指示以下内容：
    • 节假日和周末：某一列可以指示给定的某一天是节假日还是周末，而此类信息在整个预测期内均为已知。
    • 事件日期：某一列可以指示当天发生了某个特定事件，例如体育赛事。 其余列将被视为 过去 协变量，这些值会波动且无法提前得知，例如温度或类似产品的销量。

静态数据集

静态数据集包含与时间无关的元数据。

其中可能包含以下数据：

  • 门店位置
  • 客户细分的年龄段
  • 定价层级或订阅级别

静态数据集的格式必须确保每个 item ID 在 训练数据集 中的映射都对应于静态数据集中的单独一行。

参数

  • 预测期长度： 推理期间需要预测的未来时间步数。
  • 评估指标： 用于在训练过程中对模型性能进行评分的指标。不同的数据集可能在不同评估指标上表现更佳。有关更多详细信息，请参阅平台内文档。评估指标越高，模型性能越好。所有评估指标均遵循此规律。
  • 时间限制： 可选择设置训练所花费的最大时间量。达到时间限制后，作业的训练部分将结束。请注意，在模型验证完成且模型发布之前，作业不会结束。
  • 训练预设： 训练预设是对 bagging 和 stacking 相关的更复杂参数的上层抽象。
    • best_quality：使用统计模型、深度学习模型和经典机器学习模型的组合，并包含更长的验证步骤和多次回测。此预设将生成最准确的模型，但训练可能需要较长时间。
    • high_quality：使用统计模型、深度学习模型和经典机器学习模型的组合。此预设将生成比 medium_quality 预设更准确的模型，但训练速度较慢。
    • medium_quality：使用统计模型和经典机器学习模型的组合，以及 TemporalFusionTransformer。此预设可生成性能不错且训练时间更短的模型。
    • fast_training：仅使用简单的统计模型和基于树的模型。此预设提供快速训练，但结果可能不够准确，仅建议用于原型设计。
  • 分位数级别： 分位数级别指定一组额外的分位数度量值（0.1、0.2、0.9 等），添加到预测输出中以提供概率分布预测。为某个分位数预测的值 0.1 表示实际值预计会低于该 0.1 值的时间占比为 10%。
  • 重采样选项： 用于将时间序列重采样为固定频率的选项。
    • 频率别名： 数据频率的别名。设置为 auto 时，训练器将尝试推断时间序列数据的频率。否则，每个选项都表示一种常见的时间戳频率。例如， B 表示时间戳以工作日为单位， W 以周为单位，依此类推。这些值基于 pandas ↗ 偏移别名。这将用于影响任何重采样，从而调整时间戳以符合统一的频率。
    • 数值聚合方法： 重采样时，可能需要修改值以将其“校正”为新的频率。此选项控制非分类值在重新采样到新时间戳之前如何跨时间戳进行聚合。
    • 分类聚合方法： 与数值聚合方法相同，但适用于分类值。
  • 缺失值填充策略： 影响如何填充目标列中的缺失值。
  • 启用集成： 当设为 true 时，将拟合由所有已训练模型组成的加权集成，并将其与单个模型进行比较，然后再确定最佳模型。
  • 排除的模型类型： 排除某些模型类型，使其不会在训练期间使用。

高级：超参数

可选的超参数字段允许对每个已训练的模型进行更深度的自定义和控制，但需注意一点。定义此字段后，未在超参数字段中提供的任何模型都将被忽略。此字段将覆盖 AutoGluon 选择的默认超参数，并可能产生较差的结果。因此，如果您尚未查阅 AutoGluon 文档 ↗。在大多数情况下，默认超参数已能提供足够好的结果。

输出

时间序列预测训练器将输出一个 Foundry 模型，其中包含由验证步骤确定的最佳模型。有关该模型的详细信息，可通过 导航至实验，其中包含参数、指标和图表，可帮助您深入了解模型的性能。

您可以使用 Quiver、Vertex 和 Workshop 等 Foundry 应用程序，将预测结果作为时间序列进行可视化和分析。 了解有关在 Foundry 中使用时间序列的更多信息。
