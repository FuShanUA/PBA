创建匹配操作

匹配操作允许敏感数据扫描器代表您对被检测为匹配的数据集自动执行操作。共有三种类型的匹配操作：

  • “应用标记”匹配操作： 指示敏感数据扫描器对匹配任何指定匹配条件的数据集应用标记。
  • “创建问题”匹配操作： 指示敏感数据扫描器在匹配任何指定匹配条件的列上创建问题。
  • “混淆数据”匹配操作： 指示敏感数据扫描器使用以下方式对匹配的数据进行加密或哈希处理： 密码.
测试您的匹配条件

如果您的敏感数据扫描覆盖大量数据集，我们建议您在继续之前先测试匹配条件，因为配置不当的匹配条件可能会以不必要的问题或数据集上的标记的形式产生误报。

您可以通过选择以下选项来测试匹配条件： 无匹配操作 作为您的扫描配置。一旦您验证了匹配条件与预期的数据格式相匹配，您就可以在未来的单次扫描或定期扫描中选择其他匹配操作之一。

与创建匹配条件类似，有两种方式可以开始创建匹配操作——从敏感数据扫描器着陆页开始，或者在创建敏感数据扫描时开始。

在登录页面中，选择 将 位于匹配条件侧边栏中列出的 可用匹配操作 （列于匹配操作侧边栏中）上方。

在创建敏感数据扫描时，在 选择匹配操作 页面上，您也可以通过点击 创建匹配操作 来创建匹配操作，并立即在您的扫描中使用它。

这两个起始点都会打开相同的匹配操作创建流程。在那里，您可以选择创建 添加标记 匹配操作，或者 创建 issue 匹配操作。

此外，“创建问题”匹配操作还提供高级配置：

  • 问题文本： 您可以自定义执行匹配操作时问题中包含的文本。
  • 问题标签： 您可以选择您的 空间 中可用的问题标签之一，以便于对问题进行有效的分类处理。
  • 问题严重性： 您可以根据要运行的扫描设置问题的优先级。
  • 通知数据集创建者有关该问题： 如果选中此项，创建该数据集的用户将被告知其创建的数据集中发现了敏感数据。
  • 在以下情况下不打开新问题：
    • 归档 ——如果选中此项，如果之前的扫描创建的问题随后被手动归档，敏感数据扫描器将不会创建新问题。
    • 已关闭 ——如果选中此项，如果之前的扫描创建的问题随后被手动关闭，敏感数据扫描器将不会创建新问题。

创建“混淆数据”匹配操作

混淆数据 匹配操作允许您使用以下方式自动加密或哈希匹配的数据 密码。对于每个扫描的资源，敏感数据扫描器将创建一个包含混淆后数据的输出数据集。

要创建新的混淆数据匹配操作，您可以打开 创建匹配操作 对话框并选择 混淆数据.

您将需要一个 Cipher 通道 以及一份 密钥许可证。如果您还没有这些，可以在 Cipher 中创建。

Cipher 通道指定用于混淆的加密算法。敏感数据扫描器支持：

  • 概率加密：AES GCM SIV
  • 确定性加密：AES SIV
  • 哈希：SHA512 和 SHA256

敏感数据扫描器不支持视觉混淆通道。

Cipher 许可证授予一组与 Cipher 通道交互的权限。敏感数据扫描器需要一个 Admin License，因为它需要访问加密密钥来执行混淆。

确认您有可用的 Cipher 许可证后，您可以在 创建匹配操作 对话框中搜索该表格。

匹配操作只能应用于与 Cipher 许可证位于同一项目中的已扫描资源。

混淆数据操作将为每个扫描的数据集创建一个输出数据集。根据扫描资源的数量，这可能会导致创建大量输出数据集。我们建议对少量数据运行此扫描。

混淆数据操作是 不可逆的 （通过敏感数据扫描器）。敏感数据扫描器创建的任何数据集都必须手动删除。

混淆模式

选择 显示高级配置 面板以展开一组四个不同的选项来自定义混淆模式。这定义了在匹配的情况下将混淆哪些具体数据：

  • 整列（默认）：如果找到匹配项，则混淆整列。
  • 整行：如果找到匹配项，则混淆整行。
  • 仅匹配单元格：仅混淆找到匹配项的单元格。
  • 仅匹配片段：仅混淆与匹配条件匹配的文本片段。
