保存和共享图表

数据血缘使您能够轻松保存图表并与其他用户共享。您可以通过选择应用程序右上角的 操作 标签页并从下拉菜单中选择一种方法，找到多种保存和共享的方式。

保存图表

在 操作 下拉菜单中选择以下选项来保存您的数据血缘图表：

  • 保存： 将您的数据血缘图表保存到其当前所在的文件或 Project 中的位置。
  • 另存为...： 为您的血缘图表选择一个名称，并将其保存到文件系统中的新位置。

您还可以使用以下选项打开之前保存的图表：

  • 打开图表： 选择打开您有权访问的其他已保存图表，或打开 剪贴板 标签页，输入数据集、调度、图表或路径的资源标识符（RID）。

您选择的分支会随保存的图表一同存储。如果您加载的图表包含与当前不同的分支配置，系统会询问您是否要切换至所保存的分支配置。

共享图表

您可以使用以下选项与其他用户共享图表：

  • 获取快速分享链接： 生成一个提供图表只读访问权限的可共享链接。此选项仅适用于属于同一组织的用户。要跨组织共享图表，请确保该图表已保存在 两个组织均可访问的共享 Project 中.
  • 导出图表为 SVG： 生成并下载 .svg 格式的血缘图表静态图像。

卸载实体（Uninstall entities） 共享 在应用程序右上角点击以打开侧边栏并查看 角色 详情。在此处，您可以开启链接共享，或授予用户或群组对图表的访问权限。
