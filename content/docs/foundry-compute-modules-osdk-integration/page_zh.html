OSDK 集成

本体论 SDK（OSDK）可在计算模块中使用，以与 Foundry 本体论对象进行交互。本页介绍了如何授予必要的权限、配置计算模块，以及在本地 Docker 构建和代码仓库中使用 OSDK。

前提条件

在计算模块中使用 OSDK 之前，您必须授予应用程序服务用户对所需本体论资源的访问权限，并使用适当的凭据配置计算模块。

向应用程序服务用户授予访问权限

来自 Developer Console 的客户端 ID 必须有权访问您的计算模块将要使用的本体论资源。

  1. 导航至 OAuth 和限制 选项卡，位于 Developer Console，然后选择 排查访问问题 ，位于 资源和操作限制 部分。
  2. 在您想要访问的资源的 Security 标签页中，搜索您的客户端 ID 并添加该用户。
  3. 对于由数据集支撑的本体论对象，您可能需要同时为对象集和底层数据集授予访问权限。请参阅 第三方应用程序文档 以获取有关配置访问权限的最新指南。

配置您的计算模块

您的计算模块需要网络出口和应用凭据才能使用 OSDK。

  1. 添加一个 源 （用于您的 Foundry 主机名），因为默认情况下出口处于禁用状态。
  2. 在您的计算模块的 配置 标签页中，选择 应用权限。有关执行模式的更多信息，请查阅 执行模式 文档。
  3. 选择 使用其他应用凭据。
  4. 输入来自 Developer Console 的客户端 ID 和客户端密钥，然后选择 应用，并保存您的配置。

您可以在计算模块代码中使用保留的 CLIENT_ID 和 CLIENT_SECRET 环境变量来访问凭证：

Copied!
1from compute_modules.auth import retrieve_third_party_id_and_creds
2
3client_id, client_secret = retrieve_third_party_id_and_creds()
Copied!
1String clientId = System.getenv("CLIENT_ID");
2String clientSecret = System.getenv("CLIENT_SECRET");

在本地 Docker 构建中使用 OSDK（Python）

本节将逐步介绍如何使用 Python 通过本地 Docker 构建来创建由 OSDK 支撑的计算模块。

设置您的 OSDK

  1. 在 Developer Console 中创建一个应用程序，并生成您的 OSDK。选择 Python 作为语言， Backend service 作为应用程序类型，并且 应用程序权限 用于权限模型。
  2. 使用 Developer Console 中的命令通过 pip 安装 OSDK 库。

编写计算模块代码

以下示例演示了如何在计算模块函数中使用 OSDK 进行身份验证并查询本体论对象：

Copied!
1from demo_python_sdk import FoundryClient, ConfidentialClientAuth
2import logging
3import os
4from compute_modules.logging import get_logger, set_internal_log_level
5from compute_modules.auth import retrieve_third_party_id_and_creds
6from compute_modules.annotations import function
7
8CLIENT_ID, CLIENT_CREDS = retrieve_third_party_id_and_creds()
9
10set_internal_log_level(logging.INFO)
11logger = get_logger(__name__)
12logger.setLevel(logging.INFO)
13
14foundry_url = os.environ["FOUNDRY_URL"]
15
16@function
17def get_object(context, event):
18    auth = ConfidentialClientAuth(
19        client_id=CLIENT_ID,
20        client_secret=CLIENT_CREDS,
21        hostname=foundry_url,
22        should_refresh=True,
23    )
24    client = FoundryClient(auth=auth, hostname=foundry_url)
25    EmployeeObject = client.ontology.objects.Employee
26    logger.info(EmployeeObject.take(1))
27    return "Success"

创建 Dockerfile

在本地构建时，OSDK 库托管在私有的 Foundry Artifact 仓库中。您必须使用 FOUNDRY_TOKEN 密钥，以便在 Docker 构建期间向代码仓库进行身份验证。

Copied!
1FROM --platform=linux/amd64 python:3.12
2COPY requirements.txt .
3RUN --mount=type=secret,id=FOUNDRY_TOKEN,env=FOUNDRY_TOKEN \
4    pip install -r requirements.txt --upgrade \
5    --extra-index-url "https://user:$FOUNDRY_TOKEN@yourenrollment.palantirfoundry.com/artifacts/api/repositories/ri.artifacts.main.repository.REDACTED/contents/release/pypi/simple" \
6    --extra-index-url "https://user:$FOUNDRY_TOKEN@yourenrollment.palantirfoundry.com/artifacts/api/repositories/ri.foundry-sdk-asset-bundle.main.artifacts.repository/contents/release/pypi/simple"
7COPY src .
8USER 5000
9ENTRYPOINT ["python", "app.py"]

请将 yourenrollment.palantirfoundry.com 替换为您实际的 Foundry 注册 URL，并将代码仓库的 RID 替换为 Developer Console 中提供的值。

构建并推送镜像

使用以下命令构建 Docker 镜像，并将 FOUNDRY_TOKEN 作为构建密钥传递：

Copied!
1docker buildx build --platform=linux/amd64 \
2    --secret id=FOUNDRY_TOKEN,env=FOUNDRY_TOKEN \
3    -t yourenrollment-container-registry.palantirfoundry.com/hello-world:0.0.1 .

有关构建和发布 Docker 镜像的更多信息，请查阅 容器 文档。

在 Code Repositories 中使用 OSDK

如果您在 Code Repositories 中开发计算模块，则可以将 OSDK 添加为库依赖项，而无需在本地安装。

Python

  1. 在 Developer Console 中创建应用程序并生成您的 OSDK。选择 Python 作为语言， 后端服务 作为应用程序类型，并且 应用程序权限 作为权限模型。将创建一个 Conda SDK。

  1. 在您的 Python 代码仓库中，打开 库 面板，搜索上一步生成的 Conda SDK，并将其添加。

  1. 在您的计算模块代码中使用 OSDK：
Copied!
1import os
2from osdk_compute_module_demo_sdk import ConfidentialClientAuth, FoundryClient
3from compute_modules.auth import retrieve_third_party_id_and_creds
4from compute_modules.annotations import function
5
6foundry_url = os.environ["FOUNDRY_URL"]
7CLIENT_ID, CLIENT_CREDS = retrieve_third_party_id_and_creds()
8
9@function
10def print_object(context, event):
11    auth = ConfidentialClientAuth(
12        client_id=CLIENT_ID,
13        client_secret=CLIENT_CREDS,
14        hostname=foundry_url,
15        should_refresh=True,
16        scopes=[
17            "api:ontologies-read",
18            "api:ontologies-write",
19            "api:mediasets-read",
20            "api:mediasets-write",
21        ],
22    )
23    client = FoundryClient(auth=auth, hostname=foundry_url)
24    EmployeeObject = client.ontology.objects.Employee
25    return str(EmployeeObject.take(1))

Java

  1. 在 Developer Console 中创建应用程序并生成您的 OSDK。选择 Java 作为语言， 后端服务 作为应用程序类型，并选择 应用程序权限 作为权限模型。系统将提供 Maven 定位符，例如 com.palantir.foundry:osdk-compute-module-demo-sdk。

  1. 在您的 Java 代码仓库中，打开 库 面板，搜索上一步生成的 Maven SDK，然后将其添加。

  1. 切换显示隐藏文件，找到 build.gradle 文件（位于您已部署的应用程序定义目录中）。将 Maven 定位符添加为依赖项。

  1. 在您的计算模块代码中使用 OSDK：
Copied!
1import com.palantir.foundry.osdk_compute_module_demo_sdk.FoundryClient;
2import com.palantir.foundry.osdk_compute_module_demo_sdk.objects.Employee;
3import com.palantir.osdk.api.Auth;
4import com.palantir.osdk.api.auth.ConfidentialClientAuth;
5import com.palantir.osdk.internal.api.FoundryConnectionConfig;
6import java.util.List;
7
8static String return_object() {
9    Auth auth = ConfidentialClientAuth.builder()
10            .clientId(System.getenv("CLIENT_ID"))
11            .clientSecret(System.getenv("CLIENT_SECRET"))
12            .build();
13
14    FoundryClient client = FoundryClient.builder()
15            .auth(auth)
16            .connectionConfig(FoundryConnectionConfig.builder()
17                    .foundryUri("https://yourenrollment.palantirfoundry.com")
18                    .build())
19            .build();
20
21    List<Employee> objects = client.ontology().objects().Employee()
22            .fetchStream().toList();
23    return objects.get(0).toString();
24}

通过 Marketplace 安装的计算模块

当通过 Marketplace 安装的计算模块使用 OSDK 时，Marketplace 安装项目中的本体论 RID 将通过 FOUNDRY_ONTOLOGY_RID 环境变量。这是安装项目的本体论 RID,而不是原始源项目的。

所有本体论实体的 API 名称在源本体论和目标本体论之间必须匹配。如果 API 名称不匹配,OSDK 将无法解析目标本体论中的实体。

使用 FOUNDRY_ONTOLOGY_RID 环境变量,以确保在初始化 OSDK 客户端时您的计算模块引用的是正确的本体论:

Copied!
1import os
2
3FOUNDRY_ONTOLOGY_RID = os.environ.get("FOUNDRY_ONTOLOGY_RID")
4CLIENT = FoundryClient(auth=AUTH, hostname=HOSTNAME, rid=FOUNDRY_ONTOLOGY_RID)
Copied!
1const originalOntologyRid: string = "{YOUR_ORIGINAL_ONTOLOGY_RID}";
2const ontologyRid: string = process.env.FOUNDRY_ONTOLOGY_RID ?? originalOntologyRid;
3const client: Client = createClient(url, ontologyRid, auth);
