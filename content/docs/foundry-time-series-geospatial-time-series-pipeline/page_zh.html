使用 Pipeline Builder 创建地理空间时间序列属性

您在 Pipeline Builder 中按照本指南创建的管道将生成 时间序列数据 ，数据来自原始位置更新，并准备带有序列 ID 引用的对象支撑数据集。此数据将支撑一个 时间序列同步 ，以便与 时间序列属性 相关联，这些属性位于 Ship 对象类型上。

本示例中使用的假定原始位置数据集包含以下列：

  • ship_id: string | 每艘船舶的唯一标识符。
  • timestamp: timestamp | 记录该位置的时间。
  • longitude: double | 船舶在记录时刻的经度。
  • latitude: double | 船舶在记录时刻的纬度。

您可以复制下方的原始数据，并在 Foundry 中将其导入为数据集，然后再将其添加到 Pipeline Builder 中的新管道：

ship-0012025-01-01 14:00:00140.009735.2652

第一部分：转换时间序列数据

使用原始位置数据集，在 Pipeline Builder 中应用以下转换，以创建与时间序列同步兼容的数据集。

1. 对纬度和经度列进行逆透视

由于该数据集将纬度和经度分别包含在单独的列中，请使用 Unpivot 转换将它们合并到单个值列中。这是匹配 时间序列同步所需架构的必要步骤。将数据集添加到管道后，添加一个转换节点，使用 Unpivot 将 latitude 和 longitude 列转换为新的 series_name Name 列 和 series_value Value 列。

2. 创建一个 series_id 列（使用 Concatenate strings 转换）

接下来，添加一个转换节点来拼接 series_name 和 ship_id 列，以创建一个新的 series_id 列（使用 Concatenate strings 转换）。

3. 创建对象的支撑数据集

接下来，你将使用 Drop columns、 Concatenate strings和 Drop duplicates 转换来创建 Ship 对象类型的支撑数据集。在管道中完成这些转换后，数据集将包含以下架构和值：

longitude_series_idlatitude_series_idship_id
longitude_ship-001latitude_ship-001ship-001
longitude_ship-002latitude_ship-002ship-002

添加一个转换节点，并应用上面列出的转换。

  • Drop columns： 删除 timestamp、 series_value、 series_name和 series_id 列。
  • Concatenate strings： 使用下划线作为 Separator 来拼接 latitude 和 longitude 列与 ship_id （在单独的转换块中）。
  • Drop duplicates： 删除 ship_id 列（在其用于与 latitude 和 longitude的拼接之后）。

配置好转换后，返回管道画布并选择 添加输出 > 新数据集 ，从新创建的转换节点输出一个数据集来支撑该对象类型。

为您的数据集取一个描述性名称，例如 cleansed-ship-information-dataset。选择 保存 （位于顶部功能区中），然后 部署 您的管道以创建该数据集。

4. 删除 ship_id 和 series_name ，然后将 series_value 转换为 Double

创建好对象类型的支撑数据集后，返回您在 第二步 中创建的转换节点，以创建您的时间序列同步。

既然 series_id 和 series_value 列派生自并取代了 ship_id 和 series_name，请添加一个转换节点来删除 ship_id 和 series_name ，然后将 series_value 转换为类型 Double。这使您能够从清洗后的数据集输出时间序列同步，该同步将支撑 轨迹纬度 和 轨迹经度 属性，这些属性属于 轨迹对象。

第二部分：创建时间序列同步

您可以参考 时间序列属性用例教程中的类似说明。不过，以下说明提供的指导专门针对此 Ship 地理空间对象类型示例。

要从清洗后的数据集输出时间序列同步，请选中管道画布上的最后一个转换节点，然后选择 添加输出 > 新时间序列同步。接下来，填写 序列 ID、 时间和 值 选项，这些选项位于 管道输出 抽屉中，该抽屉显示在您的管道右侧，其中包含您清洗后的数据集的 series_id、 timestamp和 series_value 列。保存并部署您的管道以创建时间序列同步。

您可以选择输出新的 数据集 而不是时间序列同步。不过，在 Pipeline Builder 中输出时间序列同步将为您省去一个步骤，该步骤发生在 本体论配置阶段。

Foundry 会将您新创建的时间序列同步保存在与您的管道相同的 Compass 文件夹 中。

创建时间序列同步后，您现在可以在您的本体论中创建并配置一个 对象类型，并将该时间序列同步作为其时间序列属性。
