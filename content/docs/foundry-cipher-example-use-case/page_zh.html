Cipher 示例用例

Cipher 的一个常见用例是默认对敏感数据进行加密，但允许出于合法目的的运营用户在需要时选择性地解密特定字段，并保留操作的审计记录。

在下面的示例图中，敏感数据落入带有安全 标记 的 Foundry 数据集中。这些步骤概述了如何使用 Cipher 在共享前对数据进行混淆，并仅为运营用户启用有针对性的解密。

复现步骤

  1. 在您的落地 Project 中创建 Cipher Channel 。
  2. 签发 Admin License 并将其访问权限授予相关的管理员用户。
  3. 通过 Transforms 混淆敏感列 and 取消标记 最小化数据集。
  4. 在运营用户有权访问的 Project 中引用该最小化数据集。
  5. 签发 decrypt Operational User License 并将其移动到面向运营用户的 Project 中。
  6. 设置您的 本体论 and 启用加密值的渲染.
