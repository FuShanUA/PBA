添加媒体集输出

在 Pipeline Builder 中使用媒体集时,您可以创建 媒体集输出 作为管道的结果。媒体集输出使您的管道能够提供干净且经过转换的媒体数据(如图像或音频),以供整个平台使用。

详细了解 媒体集和非结构化数据 在 Foundry 中的相关信息。

创建媒体集输出

要创建媒体集输出,请先 生成新的媒体集 ,然后将其 配置 为正确的格式,再部署管道并 构建输出。

生成新的媒体集

首先,选择 添加 (位于 媒体集 类型旁边),该类型位于图右侧的 管道输出 面板中。

或者,您也可以选择一个生成媒体的转换节点,然后选择 添加输出。

然后,选择 新建媒体集。

配置媒体集

配置输出媒体集需要设置若干参数。您可以使用名称字段来重命名输出媒体集。

为您的媒体集选择 媒体类型 。该类型应与您应用任何转换后媒体的输出类型相匹配。

选择 格式。这应与您应用任何转换后媒体的具体文件格式相匹配。

现在，您已成功配置新的输出媒体集。在管道部署之前，可以更改该配置。管道部署后，您的媒体集输出将在与管道相同的文件夹中创建。输出媒体集始终是事务性的，无法配置为无事务。了解更多关于 事务性和无事务媒体集。

当管道输出为媒体集时，不支持对媒体集输入进行增量处理。如果在媒体集输入上启用增量处理，则管道输出必须是数据集。了解更多关于 批量输入的计算模式。

构建媒体集输出

将媒体集输出添加到管道后，请务必保存您的更改。如果您已完成媒体转换和管道工作流定义，就可以部署管道并构建新的媒体集输出。
