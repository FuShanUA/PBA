如何从系统中干净地卸载代理程序？

要干净地卸载代理程序，请参阅 文档 了解如何在用户界面中重新安装或升级代理程序。在删除代理程序目录之前，请务必停止所有相关进程，并复制所有本地设置（例如代理配置）。此外，请按照代理程序设置文档中的说明，清除所有 cron 作业。

在 Foundry 中从 S3 导入数据集并应用 schema 时，是什么原因导致 'java.lang.NullPointerException' 和 'SchemaColumnConvertNotSupportedException' 错误？

该问题可能与在 Foundry 中应用 schema 时对列数据类型的错误解读有关。要进行调试，请下载 Parquet 文件并使用 Python 代码按所应用的 schema 读取数据。如果错误消息中提到了列名，可以将有问题的列从 schema 中排除，以查看其余部分是否能正确加载。

为确保 S3 存储桶仅包含最新导出的数据,您可以使用外部转换直接调用 AWS API,并实现用于清理或预处理/后处理的自定义逻辑。这可能包括在导出前删除存储桶中的所有内容、创建新目录或移动文件。此外,您还可以编写脚本,在从 Foundry 导出之前删除 S3 存储桶中的内容。

在单个同步中,多个代理如何处理分工?代理之间是否存在并行机制?

如何正确使用 rewritePaths 在将数据导出到 Azure 时重命名文件，以及为什么它只导出一个文件？

如何在两台主机之间迁移代理？

要在两台主机之间迁移代理，您应首先在旧主机上使用 ./auto_restart.sh clear; ./init.sh stop 正确关闭代理，以移除 cronjob 并停止 bootstrapper。然后，将包含代理的整个目录复制到新主机，可使用诸如 scp之类的工具，前提是两台主机均已启动且能够相互连接。

数据连接代理能否安装在 AWS Fargate（无服务器 ECS 或 EKS）上？

Palantir 不建议将 AWS Fargate（无服务器 ECS 或 EKS）用作部署 Data Connection Agents 的基础设施，主要原因是这类服务缺少默认附加的卷。选择使用这些服务在容器中部署代理并不受官方支持。

在使用基于代码的外部转换连接 Databricks 时，如何解决“仅支持单一连接”（Only single connections are supported）错误？

该错误由尝试调用 get_https_connection() 于非 REST API 源所致。解决方案是为 Databricks 实例创建一个 REST API 源，或为该连接构建自定义客户端。将凭据存储在“Generic”源或 REST API 源中也是一种可行的选择。
