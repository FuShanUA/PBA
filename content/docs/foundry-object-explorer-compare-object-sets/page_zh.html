比较对象集

比较视图为用户提供了比较两个筛选后的对象集的选项。这些对象可能来自对象的动态筛选，也可能来自之前保存的探索。

进入比较模式

要使用比较模式：

  • 前往 Object Explorer，打开一个对象类型，并筛选出您想要比较的该类型对象集。在下面的示例中，结果被筛选为从纽约市出发的航班。
  • 选择搜索栏下方的 Compare 按钮。选择 Compare后，您可以选择一个用于比较的对象集，例如：
    • 现有的已保存探索，
    • 给定类型的所有对象（例如 All Flights），或者
    • 您可以定义一个新的对象集用于比较。

下面，我们将从纽约市出发的航班与一个现有的探索进行比较，该探索针对所有从加利福尼亚州出发的航班。

要即时定义一个用于比较的新对象集（该过程称为“动态筛选”），请选择 Create new set of Flights ，如上图中的比较下拉菜单所示。

这将打开一个视图，使我们能够定义和编辑该对象集，或更改用于比较集的颜色：

进入比较模式后，布局中的所有图表都会发生变化，以并排显示各个被比较集的结果。这使我们能够查看各项内容的对比情况，例如从纽约（NYC）出发的航班与从加利福尼亚（CA）出发的航班最常见的到达机场，或飞机注册信息的对比。在此比较视图中，OE 的所有功能均得以保留，例如使用图表进行筛选、在表格视图中查看结果、操作、导出等。

筛选

如上所述，您可以对这些比较集联合应用筛选器，以缩小比较视图的范围。例如，您可能只想在比较中查看 A321 飞机上的航班，以便了解纽约的取消航班与加利福尼亚的取消航班相比情况如何。此操作与您在 OE 中通常的做法相同，即通过搜索栏（如下所示）或直接从图表应用筛选器。

协作

保存比较视图

这些比较视图可以像探索一样保存和共享，只需点击 保存 按钮,该按钮位于右上角。保存视图时,系统会提示您输入名称,您还可以提供可选的描述和/或自定义保存位置。

共享比较视图

要共享您的比较,只需选择 共享 按钮,该按钮位于 保存 按钮的左侧。系统将提示您决定要与哪些用户或群组共享此比较、授予他们何种访问级别,以及是否希望为此比较设置适用于所有用户的默认角色。共享您的比较并不会同时共享对关联的探索和/或底层对象的访问权限,因此,除有权访问已保存的比较本身之外,任何查看者还需要拥有适用于相应数据的适当角色。

搜索比较视图

可以使用主页上的 OE 主搜索栏来搜索这些已保存的比较。
