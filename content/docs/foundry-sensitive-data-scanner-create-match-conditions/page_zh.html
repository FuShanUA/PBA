Sensitive Data Scanner 提供一系列 内置 匹配条件，用于检测常见类型的 PII，例如社会安全号码、电子邮件地址或电话号码。您可以在右侧边栏中选择箭头展开 内置匹配条件 部分来找到这些条件：

内置匹配条件旨在检测常见类型的个人数据。但是，其有效性会因您的具体数据结构和格式而异。请确保这些条件符合您的独特数据标准，必要时可创建自定义条件。如果您有进一步的问题，请咨询您的数据保护官。

创建正则表达式匹配条件

创建正则表达式（regex）匹配条件时，您可以指定两种类型的正则表达式选项：内容正则表达式和列名正则表达式。

  • 内容正则表达式： Sensitive Data Scanner 将针对数据集的内容（而非数据集的列名）进行检查的正则表达式。
  • 列名正则表达式： Sensitive Data Scanner 将针对数据集的列名（而非内容本身）进行检查的正则表达式。

Sensitive Data Scanner 允许您组合这两种正则表达式选项以获得最大的精确性：

  • 如果内容正则表达式匹配，则高亮显示数据集。
  • 如果列名正则表达式匹配，则高亮显示数据集。
  • 如果 同时 内容和列名正则表达式均匹配，则高亮显示数据集。
  • 如果 内容或列名正则表达式之一匹配，则高亮显示数据集。 内容或列名正则表达式匹配。

内容正则表达式包含一个可选的内容阈值字段，您可以在其中指定一个大于 0 且小于或等于 100 的数字；该内容阈值是指给定数据集的特定列中必须与内容正则表达式匹配的单元格百分比，达到该阈值时该数据集才会被高亮显示为匹配。内容阈值字段是可选的。如果未指定值，只要内容正则表达式至少有一个匹配项，Sensitive Data Scanner 就会将数据集高亮显示为匹配。

创建语言模型匹配条件

语言模型匹配条件使用 LLM 来分类扫描的数据是否与自然语言提示匹配。它们适用于难以用正则表达式或固定值列表表示的敏感数据。

要创建语言模型匹配条件，请选择 语言模型 作为条件类型，选择一个模型，并定义匹配逻辑。您可以将该条件配置为评估：

  • 内容，即列中的数据值
  • 列名称
  • 内容和列名称，两者都必须匹配
  • 内容或列名称，任一匹配即可

编写一个提示词，描述模型应检测的敏感数据。如果您同时评估内容和列名称，可以对两项检查使用相同的提示词，也可以分别定义不同的提示词。您还可以添加正确示例和反例，以明确模型应标记和不应标记的内容。在保存匹配条件之前，请查看 完整提示词 预览。

当您在扫描中使用语言模型匹配条件时， LLM 使用量会归属于 每个被扫描的资源。使用语言模型匹配条件评估所有行的扫描可能速度较慢且成本较高，因此在不需要详尽扫描时，请考虑使用行子集。

创建重叠匹配条件

当要查找的敏感数据无法归纳为正则表达式时，重叠匹配条件非常有用。例如，创建一个匹配姓名的内容正则表达式可能很困难，尽管在某些情况下创建列名称正则表达式可能就足够了。但是，如果您已经拥有一个包含要扫描的敏感数据完整列表的数据集，则重叠匹配条件会很有用。
