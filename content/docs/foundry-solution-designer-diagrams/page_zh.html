图表

本页面介绍如何在 Solution Designer 中与图表进行交互，包括添加节点、创建连接、组织图表以及自定义视图。

向图表添加节点

Solution Designer 提供多种方式向图表中添加表示平台组件、资源或抽象概念的节点。

添加组件节点

组件节点表示特定的 Palantir 平台应用程序和工具，例如 如果希望用户在每次运行预览前手动确认，请开启, 来运行该专业代码代理。你还可以通过，或 Contour.

要添加组件节点：

  1. 选择 组件 按钮，或按 Cmd/Ctrl + B.
  2. 组件选择器对话框随即打开，按类别显示所有可用的平台组件。
  3. 在左侧浏览类别，或使用顶部的搜索栏查找特定组件。
  4. 从列表中选择一个组件，将其添加到画布中。

添加组件节点后， 配置其他详细信息 这些信息将呈现在图表上，为用户提供有关该节点在所描绘工作流中用途的更多信息。

添加资源节点

资源节点表示与图表关联的特定 Foundry 资源，例如 数据集, 对象类型（object types）, 函数，或 操作.

要添加资源节点：

  1. 选择 静态： 按钮。
  2. 将出现一个包含四个选项的下拉菜单：
    • 新建文件节点： 浏览 Foundry 资源以添加
    • 新建对象节点： 从本体论中选择对象类型
    • 新建接口节点： 从本体论中选择一个 接口 来自您的本体论
    • 新建操作节点： 从本体论中选择操作类型
  3. 在打开的模态框中搜索并选择资源，Solution Designer 会将该节点添加到画布中，并附带指向所选资源的链接。

资源节点会自动显示资源名称，并提供在其原生应用程序中打开该资源的链接。

添加概念节点

概念节点表示抽象的高层级工作流概念（例如“数据获取”或“分析”），您之后可以将其替换为具体的实现。这些节点主要用于 AIP Architect 以规划工作流。

要添加概念节点，请选择 概念 按钮，然后选择概念类型，例如 分析 or 数据处理.

您可以使用以下方式将抽象概念节点转换为具体的实现模式： AIP Architect.

添加组

分组允许您将相关节点组织到逻辑容器中。

要添加空分组，请选择 组 按钮，然后将节点拖入分组以将其添加为成员。

您也可以通过选择多个节点并使用 组 操作来设置自定义 favicon。 了解有关从现有节点创建分组的更多信息。.

添加文本节点

文本节点允许您直接在图表上添加注释、标注或文档。

要添加文本节点，请选择 添加文本节点 按钮，然后在画布上选择文本节点以编辑其内容。

配置节点

将节点添加到图表后，您可以配置其属性并将其关联到 Foundry 资源。

节点工具栏

选择节点时，其正上方会出现一个小工具栏。此工具栏是与节点交互和配置节点的主要方式。工具栏包含多个水平排列的按钮：

  • 主操作按钮： 对于关联了资源的节点，此按钮会在其原生应用程序（如 Pipeline Builder 或 Workshop）中打开该资源。对于未关联资源的节点，此按钮允许您关联资源。
  • 关联资源： 通过 RID 将 Foundry 资源与此节点关联。选择 关联资源 以打开资源选择器对话框，然后选择数据集、管道、应用程序或其他 Foundry 资源。关联后，节点将显示资源名称并提供指向该资源的直接导航。
  • 操作菜单： 选择 ... 以访问其他节点操作：
    • 重叠顺序： 更改重叠节点的分层方式。
    • 用户组： 创建一个以所选节点开头的新组。
    • 编辑背景颜色： 自定义节点的背景颜色。
    • 移除关联资源： 取消节点与 Foundry 资源的关联。
    • 编辑标签： 添加或移除标签，以便按标记、组织或团队对节点进行分类。
    • 删除： 从图中移除该节点。

自定义节点外观

您可以自定义节点在图中的显示方式：

  • 背景颜色： 右键单击节点并选择 更改背景颜色 或使用 操作 节点工具栏中的菜单。
  • 图标： 为自定义节点更改图标及其颜色。
  • 自定义标题： 选中节点后，直接选择节点标题即可进行编辑。
  • 调整节点大小： 将鼠标悬停在节点的角落或边缘，然后拖动调整大小控点来调整其尺寸。

节点文档卡片

每个节点都会在右上角显示一个文档卡片，其中展示其所代表的平台组件的相关信息。卡片显示：

  • 组件名称和图标： 标识该平台组件。
  • 简要描述： 对该组件功能的简短摘要。
  • 完整描述： 一个可展开的部分，包含有关组件功能和使用场景的更多详细信息，您可以选择 以显示接下来的五行。.
  • 文档链接： 在新标签页中打开该组件的官方 Foundry 文档。
  • 询问 Assist： 如果启用了 AIP，则会打开一个对话框，可向 AIP Assist 询问有关该组件的问题。

要最小化文档卡片，请选择卡片右上角的最小化按钮。此时会保留一个小的信息图标，您可以选择该图标以重新展开卡片。

创建连接

节点之间的连接（即边）表示架构中的数据流、依赖关系或关系。

连接节点

要创建连接：

  1. 将鼠标悬停在要从中连接的节点上。节点左右两侧边缘会出现小的圆形控点。
  2. 选择该控点并从源节点的 右侧控点 （输出）拖动。
  3. 将光标拖动到目标节点的 左侧控点 （输入）。
  4. 释放鼠标按钮以创建连接。

编辑或删除连接

要删除连接：

  1. 在画布上选择连接线，选中后该线将高亮显示。
  2. 媒体 Backspace or Delete.

或者，右键单击连接并选择 删除边 （位于上下文菜单中）。

连接标签

您可以为连接添加标签，以描述其关系或数据流。

要添加或编辑连接标签：

  1. 在画布上选择该连接。
  2. 选择连接上出现的标签区域。
  3. 在 Click to Edit 文本输入框中输入标签文本。
  4. 在标签外的画布任意位置单击以保存更改，然后再选择 保存.

您可以使用 画布工具栏.

节点分组

对相关节点进行分组有助于组织复杂的图，并为架构的不同部分创建逻辑边界。

从现有节点创建组

若要对现有节点进行分组：

  1. 按住 Cmd/Ctrl 并选择每个节点，或按住 Shift 并在节点周围拖出一个选择框。
  2. 选中节点后，选择 组 图表工具栏中的按钮，或右键单击并选择 组.

Solution Designer 会将所选节点分组到一个容器中。

管理组成员

创建分组后，请按照以下操作管理组成员。

  • 添加节点： 从画布中选择任意节点并将其拖到分组上。当节点进入分组边界内时，松开即可将其添加为成员。
  • 删除节点： 选择节点并将其拖出分组边界。该节点将从分组中移除，但仍保留在画布上。
  • 移动分组： 选择并拖动分组容器本身。所有成员节点将随之移动，并保持其相对位置。

画布控件

画布工具栏显示在画布的左下角，提供用于导航和操作图表的工具。工具栏包含若干垂直排列的图标按钮：

  • 放大： 提高缩放级别以查看更多细节。
  • 缩小： 降低缩放级别以查看图表的更多内容。
  • 将所有节点适应视图： 自动居中并缩放以显示整个图表。
  • 锁定图表： 启用只读模式以防止意外编辑。锁定后仍可平移和缩放。在演示过程中锁定图表非常有用。
  • 隐藏/显示背景点： 切换背景点网格的可见性。
  • 自动布局节点： 自动以网格状结构排列节点，间距均匀且边交叉最少。适用于整理杂乱的图表。
  • 切换边流动动画： 为画布上的边流动标签添加动画效果。
  • 隐藏/显示边标签： 隐藏或显示所有连接上的标签。
  • 隐藏/显示边有效性： 隐藏或显示边有效性的着色。
  • 最小化/最大化节点显示： 最小化节点上显示的信息。这有助于在大型或复杂的图表上节省空间。

迷你地图

迷你地图显示整个图表的鸟瞰视图以及当前视口的位置。

若要启用迷你地图：

  1. 打开 设置 面板（参见 设置).
  2. 切换 迷你地图 为启用状态。
  3. 迷你地图显示在画布的右下角。

选择迷你地图可跳转到图表的不同区域。

平移和缩放

若要导航画布：

  • 平移： 在空白画布区域选择并拖动，或在设置中启用 平移模式 以避免在平移时意外选中节点。
  • 缩放： 使用鼠标滚轮、触控板捏合手势或画布工具栏中的缩放按钮。
  • 适应视图： 选择 将所有节点适应视图 按钮可居中并缩放以显示所有节点。

高级节点操作

侧边菜单

在画布上选择节点时，屏幕右侧会打开一个侧边菜单面板，为该节点提供更多选项。

节点遍历

对于所有节点，侧边菜单都包含一个 节点遍历 部分，允许您通过导航连接的节点来探索图表：

  • 查看连接的节点： 查看与当前选中节点连接的所有节点的列表。
  • 跳转到连接的节点： 在列表中选择任意连接的节点，即可选中该节点并将其居中显示在画布上。
  • 理解数据流： 通过跟踪节点连接，快速追踪数据在架构中的流动方式。

节点遍历可帮助您浏览复杂的图表，并理解组件之间的关系，无需手动搜索。

对象遍历

对于链接到本体论对象类型的节点，侧边菜单包含一个 对象遍历 部分，显示该对象类型可用的本体论关联关系：

  • 查看关联关系： 查看本体论中定义的所有关联类型和相关对象类型。
  • 创建遍历： 选择特定关联关系，即可在画布上自动生成相关对象类型节点，其功能类似于节点工具栏中的 创建遍历 操作。
  • 探索本体论结构： 了解此对象类型如何连接到数据模型的其他部分。

上下文菜单

虽然画布和节点工具栏是与图表交互的主要方式，但您也可以使用上下文菜单作为替代：

  • 右键单击节点： 显示类似以下选项： 更改背景颜色, 组 与其他选定节点，以及 删除.
  • 右键单击画布： 显示类似以下选项： 添加注释, 添加空分组日 自动布局节点.

上下文菜单提供了对常用操作的快速访问，但大多数操作通过专用工具栏访问更为便捷。
