扩展接口

扩展接口允许您将多个接口组合在一起，创建一个新的、更具体的接口。这对于构建 抽象对象接口 特别有用，这些接口可实现多个 能力接口。接口会继承其所扩展接口的共享属性、关联类型约束和操作类型约束。一个接口可以扩展任意数量的其他接口。

要扩展接口，请按照以下步骤操作。

  1. 在 Ontology Manager 中，选择您要扩展的接口以打开接口概览页面。

  2. 在概览页面中，选择 扩展 （位于左侧面板）。

  3. 在接口扩展页面中，选择 添加扩展.

  1. 从下拉菜单中，选择要从当前接口扩展的接口。

  1. 在确认对话框中，查看将添加到接口扩展中的共享属性、关联类型约束和操作类型约束，然后选择 确认.

  2. 选择 保存 （位于右上角），将接口扩展添加到本体论中。

您也可以移除扩展以将一个接口与另一个接口解耦。此操作将从接口中移除所有继承的共享属性，移除所有继承的关联类型约束，移除所有继承的操作类型约束，并解除扩展接口与基础接口之间的关联。
