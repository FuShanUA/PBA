登录平台

Palantir 平台支持 SSO 身份验证以及使用通行密钥的无密码登录。如果您的组织使用 SSO，请按照您的 SSO 提供商提供的步骤操作。欲了解更多信息，请参阅 身份验证文档。要使用通行密钥登录平台或管理您的通行密钥，请查看以下章节。

设置并配置通行密钥

要配置通行密钥并使用其登录，您必须先收到一封来自 Palantir 的电子邮件，标题为“设置您的 Palantir 账户并登录”。此电子邮件将包含一次性密码和用于设置账户的链接。系统将提示您验证您的电话号码并创建通行密钥，之后即可使用该通行密钥登录。请查看以下章节以获取更详细的说明。

配置通行密钥时，您将有多种存储选项：

  • 将通行密钥保存到您正在使用的设备： 根据您的设备和浏览器的不同，在您当前使用的设备上保存通行密钥的选项会有所不同。例如，如果您使用的是 iPhone，可以将通行密钥保存到您的 iCloud 钥匙串；如果您使用的是 Google Chrome，则可以将通行密钥保存到您的 Chrome 用户配置文件或 Google 密码管理器中。您可以根据自己的偏好选择凭据存储方式，这可以是您最熟悉的方式，也可以是为您提供最简便身份验证选项的方式。
  • 将通行密钥保存到安全密钥： 安全密钥是物理设备，可通过添加额外的身份验证层来增强账户安全性。当您将通行密钥保存到安全密钥后，每次需要登录时，您都需要插入安全密钥并输入 PIN 码和/或触摸安全密钥的传感器。
  • 将通行密钥保存到移动设备： 当您将通行密钥保存到移动设备时，您将需要使用该设备扫描二维码进行登录。您还将能够直接从该设备登录，而无需扫描二维码。例如，如果您在笔记本电脑上添加通行密钥，并通过扫描二维码将其保存到移动设备上，则存储的通行密钥可用于直接从该移动设备登录。使用此选项时，请确保您的设备已启用蓝牙。

请注意，某些设备可能会自动提供存储通行密钥的默认选项，例如 Windows Hello 或 iCloud 钥匙串。您无需选择设备的默认选项来存储通行密钥。您可以选择退出默认对话框，并选择您偏好的通行密钥存储选项。

您无需使用特定的身份验证应用程序。您设备的内置安全功能（例如面部识别或指纹扫描）可与设备自带的相机配合使用。

视您的设备而定，选择安全密钥或移动设备的选项的显示方式可能略有不同。例如，在 iOS 上，该选项可能显示为 iPhone、iPad 或 Android 设备 并单独列出安全密钥，而其他设备上可能显示为 使用手机、平板电脑或安全密钥。请仔细阅读这些选项，并选择符合您期望的通行密钥存储方式的选项。

设备和浏览器支持

在尝试存储通行密钥之前，请确保您的移动设备和浏览器受支持。iOS 和 Android 设备支持以下版本：

  • iOS 设备： 支持最新版本的 iOS 及上一个版本。例如，如果 iOS 的最新版本是 iOS 18，则支持 iOS 18 和 17。
  • Android 设备： 支持运行 Android 13 及更高版本的设备。

    Palantir 平台 完全受支持 于最近六个月内发布的 Google Chrome 和 Microsoft Edge 版本。在移动设备上使用时，需要 Google Chrome、Microsoft Edge 或 Apple Safari。为获得最佳效果，请尽可能使用 Google Chrome 或 Microsoft Edge。

添加更多通行密钥

我们建议您为账户添加多个通行密钥作为备份。每个账户最多可添加四个通行密钥，但每个凭据存储中只能有一个通行密钥。这意味着您只能在 Windows Hello、iCloud 钥匙串、Samsung Pass 或其他凭据存储中存储一个通行密钥。如果您尝试创建新的通行密钥，请确保该凭据存储中尚未存储通行密钥。例如，如果您已在 iCloud 钥匙串中存储了通行密钥，再尝试在 iCloud 钥匙串中存储第二个通行密钥将会导致错误。

在添加更多通行密钥之前，请确保为现有通行密钥设置了描述性名称，以避免混淆。良好的通行密钥命名惯例是使用创建时所在的设备加上凭据存储，例如“工作笔记本电脑 Chrome”或“个人 iPhone 钥匙串”。

在账户锁定恢复期间，您的组织管理员可以看到通行密钥名称。请勿在通行密钥名称中包含个人或敏感信息。

故障排除

无法访问通行密钥

如果您无法访问任何通行密钥，则需要重置您的账户。此流程可能因您是自行创建注册，还是被添加到现有注册而有所不同。有关详细说明，请参阅 账户重置 部分。

我的一次性密码已过期

如果您的一次性密码 (OTP) 在您配置账户之前已过期，您必须重新申请一个。如果您是被添加到现有注册中的，请联系您的注册管理员以获取新的 OTP。

如果您创建了自己的注册，请找到来自 Palantir 的标题为“设置您的 Palantir 账户并登录”的电子邮件。选择 设置账户 选项以打开 欢迎使用 AIP 页面。在此，您可以选择登录表单下方的 需要帮助？ 链接，并填写支持表单以请求新的 OTP。

无法创建通行密钥

有多种原因可能导致通行密钥注册失败，包括验证超时、在创建通行密钥前未能通过身份验证，或与您尝试存储通行密钥的设备之间存在连接问题。请确保您在时间窗口内验证您的身份，并确保您的设备已启用蓝牙。

如果您仍然遇到问题，请确保您尝试使用的凭据存储区中尚不存在此账户的通行密钥。例如，如果您从平台删除了现有的 Windows Hello 通行密钥，然后在删除旧通行密钥之前就尝试注册新的 Windows Hello 通行密钥，而旧通行密钥仍存储于 您的设备，您将收到错误。您必须先从给定的凭据存储（例如 iCloud 钥匙串、Windows Hello 或 Google 密码管理器）中删除现有的通行密钥，然后才能在该凭据存储中存储新的通行密钥。

某些设备可能需要启用特定功能才能存储通行密钥。

  • 在 Apple 设备上，请在“系统设置”中启用 iCloud 钥匙串，并确保您的设置允许通行密钥在设备间同步。更多信息请参阅 iCloud 钥匙串文档 ↗。
  • 在 Android 设备上，必须启用屏幕锁定功能。出于安全原因，已设置屏幕锁定是在 Android 设备上使用通行密钥的前提条件。更多信息请参阅 Android 屏幕锁定文档 ↗。

每台设备、浏览器或操作系统都有自己的默认凭证存储，例如 iCloud 钥匙串或 Samsung Pass。请确保您选择的凭证存储已在您的设备上启用。

通行密钥在移动设备上无法使用

某些通行密钥是设备专用的，只有在使用存储该密钥的设备时才能正常使用。这些设备专用的通行密钥在创建时会提醒您它们只能在一台设备上使用。其他通行密钥则可以在多台设备上访问，例如存储在密码管理器中的通行密钥。为确保您能够跨设备使用通行密钥，请确保已在您的设备上为凭证存储提供程序启用自动填充功能。

例如，如果您希望在多台设备上使用 Google Password Manager 通行密钥，则必须在设备设置中将 Google Password Manager 启用为自动填充提供程序。有关跨设备使用 Google Password Manager 通行密钥的更多信息，请访问官方 Google Password Manager 文档 ↗。

忘记用户名

您的用户名是您注册 Palantir 账户时所用的电子邮件账户。您从 Palantir 收到的第一封电子邮件的标题为“Set up your Palantir account and log in”。请在您的所有电子邮件账户中搜索这封电子邮件，以确认您使用的是正确的账户。

客户端通行密钥问题

如果您遇到通行密钥问题，并且不确定问题是由 Palantir 平台还是软件/硬件限制引起的，您可以在以下网站测试您能否正常使用通行密钥： webauthn.io ↗。请在该网站上注册并使用通行密钥，以确认通行密钥是否能在您的设备上正常使用。如果您仍然遇到问题，或者问题似乎源自 Palantir 平台，请选择 需要帮助？ 登录表单下方的链接，然后填写 AIP/Developer Tier 支持 页面上的表单，以获取针对您问题的帮助。

在某些情况下，浏览器或操作系统可能因版本过旧而无法支持通行密钥。请确保您使用的是最新的操作系统，以及 Google Chrome、Microsoft Edge 或 Apple Safari 等浏览器，且其版本发布于过去六个月内。请查看我们 支持的浏览器 以了解更多信息。

我的组织不支持通行密钥

如果您的组织不以任何形式支持物理或数字通行密钥，则可能无法创建自助式 Palantir 账户（包括 AIP Developer Tier 账户）。如果您将参加 Palantir 活动并需要访问该平台，请联系活动组织者，确认是否可以为您提供兼容的硬件。

电话号码不可用

在创建账户时，系统会要求您提供电话号码。如果您收到错误消息 电话号码不可用，您需要输入其他号码。每个注册中电话号码只能使用一次。

电子邮件域名限制

您的注册可能会限制可用于注册或登录的电子邮件域名。如果您的电子邮件域名不受允许，您在注册时可能会遇到错误，提示您的域名受限或您的邀请已失效。登录时，域名限制可能导致登录失败，且不提供其他详细信息。

当注册管理员在发送邀请之后或创建您的账户之后更新域名限制时，可能会出现这种情况。如果您之前拥有访问权限，或收到的邀请链接已失效，请联系您的注册管理员，以确认当前允许使用哪些电子邮件域名，并在需要时请求新的邀请。

用于注册通行密钥的身份验证器不被允许

如果您使用的是过时的操作系统或浏览器，在尝试使用通行密钥时可能会收到以下错误：

The authenticator used to register the passkey is not allowed or its details could not be read.
Please confirm you are using a supported browser before trying again.

来自过时操作系统或浏览器的通行密钥因安全原因被阻止。要解决此问题，请更新您的操作系统或浏览器，或使用软件为最新版本的设备。请确保您使用的是 受支持的浏览器 以避免出现问题。

通行密钥不符合安全要求

某些注册实施了安全策略，限制可使用的通行密钥类型。如果您的通行密钥不满足这些要求，您在尝试登录或注册新通行密钥时会遇到错误，提示该通行密钥不符合注册的安全要求。如果在您注册通行密钥后策略发生了更改，该错误可能表明其不再符合要求。

这通常意味着您的注册需要特定的身份验证器，例如硬件安全密钥，而不是设备内置的通行密钥。如果您注册了多个通行密钥，请尝试使用其他密钥。请联系您的注册管理员，以确认哪些通行密钥类型已获准用于您的注册。
