颜色分组

您可以在管道构建器中使用节点颜色分组，以更好地组织和管理您的管道。颜色分组有助于识别节点并提高图表的可读性。颜色分组还可以折叠或隐藏，以简化图表视图并使管道可视化更加整洁。

在管道构建器中，管道通常按颜色垂直或水平进行分组。划分为垂直分区时，颜色可以清楚地区分集成的不同阶段，从原始输入到本体论输出。

水平划分时，颜色可用于对单个对象或少数几个紧密相关对象的上游血缘进行分组。

在下面的示例中，颜色分组同时进行了垂直和水平划分：垂直划分用于分隔原始输入的迭代阶段，水平划分用于对管道的对象输出进行分组。

创建并添加到颜色分组

要创建新的颜色分组，请选择 添加颜色 在图表右上角的图例中。然后，设置组的名称和颜色。 要将节点添加到组中，请右键单击节点并选择 为节点着色。然后，选择您创建的组以添加所选节点。

您也可以直接在图表上创建新的颜色组。选择要分组的节点，然后右键单击并选择 Color nodes > New color.

折叠和展开颜色组

您可以选择将颜色组折叠为单个组节点，以简化图表视图。如果您当前并不在特定颜色组内的节点中进行操作，则此选项尤其有用。

要折叠颜色分组，请右键单击颜色分组中的任意节点并选择 折叠颜色。或者，使用 折叠颜色 菜单（位于图形右上角，图例旁），并选择要折叠的分组。

要展开该分组，请右键单击分组节点并选择 展开颜色，或双击已折叠的分组节点。

显示和隐藏颜色分组

您可以选择隐藏单个颜色分组或隐藏所有其他颜色分组，以简化图表视图。要隐藏某种颜色，请转到颜色 图例 并选择您所选颜色旁边的眼睛图标。参见 显示和隐藏颜色分组 以了解更多详情。

修改颜色分组

从颜色分组中移除节点

要从颜色组中移除节点，请右键单击该节点，选择 为节点着色，然后选择组名称。

编辑或删除节点组

要编辑颜色组，请将鼠标悬停在图例中的组名称上，然后选择铅笔图标。您可以选择重命名、更改颜色或删除该组。

选择颜色组中的节点

要选择颜色组内的所有节点，请选择图例中的组名称。

复制带颜色分组的节点

使用键盘快捷键复制和粘贴节点时，颜色分组分配会保留（Ctrl+C / Ctrl+V （Windows）或 Cmd+C / Cmd+V 在 macOS 上）。这适用于在同一管道内粘贴节点，或在不同管道之间粘贴节点的情况。使用以下方式复制节点时，颜色分组也会保留 Ctrl+D (Windows) 或 Cmd+D (macOS)。

查看节点组的更改

当 管道更改提案被提交时，任何受更改影响的颜色组都将标记有独特的颜色边框。

选择 查看更改 以查看颜色组内的节点。任何有提议更改的单个节点都将高亮显示。

选择 返回管道图 以返回主要提案变更视图。
