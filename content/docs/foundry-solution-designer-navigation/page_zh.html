导航

Solution Designer 的界面由以下几个关键区域组成，以下各节将逐一介绍，帮助您浏览图表：

  • 导航栏 （屏幕顶部）： 包含图表名称、自动保存指示器、 保存 button, 操作 菜单（用于导入或导出图表）以及撤销/重做控件。
  • 图表工具栏 （屏幕左上方）： 包含用于向图表添加节点的按钮，例如通过 概念, 组件，或 静态：，以及对这些节点进行分组或添加描述性文本框。如果启用了 AIP 功能，您还将看到使用 AIP Generate and AIP Critic.
  • 画布 （中央）：构建和可视化图表的主要工作区。节点显示在此处，您可以拖动以平移，或使用鼠标滚轮或触控板进行缩放。
  • 节点工具栏 （在画布上查看节点时）：显示在任何选定节点上方，提供用于配置和管理节点的操作。参见 图表 了解详情。
  • 画布控件 （屏幕左下方）：提供一个包含缩放、布局和视图控件的工具栏。参见 图表 了解详情。
  • “侧边栏” （屏幕左侧）： 包含用于查看 图表信息、与 AIP Architect or AIP Critic交互、查看 参考图表以及配置 图表设置.

导航栏

Solution Designer 顶部的导航栏提供对图表级操作的访问，使您能够：

  • 从左上角的文件路径编辑图表名称。
  • 查看图表的自动保存状态，例如 Up to date with manually saved version or Saved 2m ago.
  • 通过撤销和重做按钮浏览您的编辑历史。
  • 使用以下功能手动保存图表： 保存 button.
  • 访问导入和导出选项，并上传图像，通过 AI 视觉功能将手绘或白板图表转换为可编辑的 Solution Designer 图表，使用 操作 menu.

查看并还原到以前的版本

Solution Designer 会维护图表的完整版本历史。每次自动保存和手动保存都会创建一个带有时间戳的新版本。

要查看所有图表版本，请选择版本图标，该图标显示为 v{N}，位于导航栏中自动保存状态指示器的左侧。这将启动 版本 模态框，其中显示所有已保存版本的列表，每个版本都显示保存该版本的时间戳、创建该版本的用户以及所做更改的预览或描述。

您可以通过选择以下选项来还原任何以前的版本： ... > Restore to this version。还原旧版本会创建一个新版本，并且不会从图表历史中删除任何版本。

操作菜单

使用直方图中的 操作 菜单，用于导入、导出、共享或清除图表，以及在 调度指标 中打开它（如果它包含资源，例如数据集或对象类型）。

  • 导入图表： 从 JSON 文件、图像上传图表，或从 Data Lineage 导入图表。
  • 导出图表： 您可以将整个图表或选定节点保存或复制到 JSON 文件中，用于备份、共享或粘贴到其他工具中。此外，您还可以将整个图表或选定节点导出为高分辨率 PNG 图像，Solution Designer 会以 2 倍缩放进行渲染以确保清晰度。

您必须拥有图表的编辑权限才能导出图表，因为只读查看者无法导出图表。

图表工具栏

图表工具栏显示在屏幕左上方，包含用于向图表添加节点和访问 Solution Designer 关键功能的按钮：

  • AIP Generate （如果启用了 AIP）：启动 AI 驱动的工作流规划。参见 AIP Architect.
  • 概念： 添加抽象概念节点。参见 概念节点.
  • 组件： 打开组件选择器以添加平台组件（Cmd/Ctrl + B）。参见 组件节点.
  • 资源： 添加与 Foundry 资源关联的节点。参见 资源节点.
  • 用户组： 添加空分组以组织节点。参见 组.
  • 文本： 添加文本节点以进行注释。参见 文本节点.
  • AIP Critic （如果启用了 AIP）：打开图表审阅面板。参见 AIP Critic.
  • 平移模式切换： 在编辑模式与只读平移模式之间切换。

“侧边栏”

选择屏幕左侧边栏中的图标以显示其完整视图，该视图可折叠且可调整大小。不同的按钮会在侧边栏中打开特定面板：

  • 图表信息： 提供一个文本输入框，您可以在其中编写图表描述，并呈现文档和教程链接。
  • AIP Architect： 使用 AIP Architect 进行 AI 驱动的工作流规划。参见 AIP Architect.
  • AIP Critic： 查看并使用 AI 驱动的图表审阅面板。参见 AIP Critic.
  • 参考图表： 加载并浏览 Solution Designer 的参考架构库。
  • 图表设置： 查看并配置图表的设置和显示选项。

参考架构库

直方图 参考图表 面板显示参考架构库，您可以在其中浏览和加载按类别（行业模式、技术模式和工作流模式）组织的预构建模式和模板。通过关键字搜索模式、进行预览，然后创建新图表、添加到现有图表或覆盖当前图表。

配置图表设置

直方图 图表设置 面板使您能够自定义图表的显示方式并配置 Solution Designer 功能。

可用设置包括边显示选项、画布视图控件（迷你地图、背景网格和平移模式）、图标显示模式以及 AIP 功能开关。设置会本地保存到您的图表中。

有关迷你地图和平移控件等特定画布功能的详细信息，请参见 画布控件 和 平移和缩放 文档。

键盘快捷键

Solution Designer 支持键盘快捷键以简化您的工作流程。

快捷键操作
Cmd/Ctrl + B打开组件选择器
Shift + 点击或拖拽多选节点
Backspace or Delete删除选定的节点或连接
Cmd/Ctrl + C将选定的节点复制到剪贴板
Cmd/Ctrl + V从剪贴板粘贴节点
Cmd/Ctrl + Z撤销上一个操作
Cmd/Ctrl + Y or Cmd/Ctrl + Shift + Z重做上一个操作

这些快捷键使您无需频繁切换菜单即可高效构建和修改图表。

URL 参数

Solution Designer 支持用于特定行为的 URL 参数：

  • viewer=true: 以只读查看器模式打开图表，并自动启用平移模式。适用于与只需查看而无需编辑的利益相关者共享图表。
  • focusRID=<resource-id>: 自动居中并缩放到由其资源 RID 标识的特定节点。

示例：创建指向只读图表的链接

https://{FOUNDRY_URL}/workspace/solution-designer/<diagram-rid>?viewer=true

这将以只读查看器模式打开图表，非常适合演示或审阅。
