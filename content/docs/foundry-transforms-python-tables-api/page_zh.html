API 概览

该 transforms-tables 库提供了 TableInput 和 TableOutput 参数，用于在 Python 转换中与虚拟表交互。它们的行为方式与 Input 和 Output 参数类似，这些参数与 Foundry 数据集一起使用。但是，写入虚拟表需要额外的配置来 指定数据源 以及表在外部系统中的存储位置。虚拟表将在检查期间创建，这与数据集输出的情况相同。创建后，数据源和表元数据的额外配置可从 TableOutput 中移除，并替换为表 RID，以使其更加简洁。

from transforms.api import transform
from transforms.tables import TableInput, TableOutput, TableTransformInput, TableTransformOutput, SnowflakeTable


@transform.spark.using(
    source_table=TableInput(alias: str),
    output_table=TableOutput(
        alias: str,  # The Compass path where the virtual table should be registered
        source: str,  # The source RID where the output table should be written
        table: Table,  # The locator defining where the output table should be stored in the external system
    ),
)
def compute(source_table: TableTransformInput, output_table: TableTransformOutput):
    ...  # Normal transforms API

该 table: Table 参数在 TableOutput 中定义了应在外部系统中创建输出表的位置。

创建后无法更改数据源和位置

虚拟表创建后，便无法更改其数据源或位置。修改数据源或位置将导致检查失败。

可用的 Table 子类如下：

  • BigQueryTable(project: str, dataset: str, table: str)
  • DatabricksTable(catalog: str, schema: str, table: str, format: Optional[str], location: Optional[str])
  • DeltaTable(path: str)
  • FilesTable(path: str, format: str)
  • IcebergTable(table: str, warehouse_path: Optional[str])
  • SnowflakeTable(database: str, schema: str, table: str)

您必须根据所要连接的数据源类型，使用相应的类。请参阅以下文档以了解更多信息。

BigQuery 计算下推（Ibis API）

对于 BigQuery 计算下推，请使用 transforms.tables 中特定于 Ibis 的输入和输出类，并配合 BigQuery 转换装饰器。Foundry 会根据配置的输入和输出表建立与 BigQuery 的 Ibis 连接。您可以使用 Ibis DataFrame API 表达数据转换。

装饰器： @transform.bigquery.using(...)

配置： TableInput 和 TableOutput 用于虚拟表引用和 BigQuery 表定位器，通过 BigQueryTable(project, dataset, table)

函数签名： def compute(source_table: IbisInput, output_table: IbisOutput)

方法：

  • IbisInput.table() 返回输入的 Ibis 表表达式
  • IbisOutput.write(table_expr) 将 Ibis 表表达式写入输出

from transforms.api import transform
from transforms.tables import (
    IbisInput,
    IbisOutput,
    TableInput,
    TableOutput,
    BigQueryTable,
)

@transform.bigquery.using(
    source_table=TableInput("ri.tables.main.table.1234"),
    output_table=TableOutput(
        "ri.tables.main.table.5678",
        "ri.magritte..source.1234",
        BigQueryTable("PROJECT", "DATASET", "TABLE"),
    ),
)
def compute(source_table: IbisInput, output_table: IbisOutput):
    table = source_table.table()
    output_table.write(table)

参见 BigQuery 计算下推 以获取使用 Ibis 的详细指导。

配置 Databricks ↗中的输出表。请注意，向 Databricks 中的表写入数据需要 外部访问 在 Unity Catalog 中进行设置。请查看虚拟表文档中的 Databricks 部分，以了解更多信息。

参数类型描述可选
catalogstrDatabricks 目录名称。否
schemastr目录中的架构（数据库）名称。否
tablestr表名称。否
formatOptional[str]文件格式（delta， iceberg）。默认为 delta。是
locationOptional[str]外部表的存储位置（例如， abfss://<bucket-path>/<table-directory>）。是

在 Databricks 中可以写入以下类型的表：

  • 外部 Delta 表： 该 location 参数应指定云存储中用于存储表的目录。该 format 参数默认为 delta ，因此并非必需。请参阅 Databricks 官方文档 ↗ 以了解更多有关外部表的信息。
  • 托管 Iceberg 表： 该 format 参数应设置为 iceberg。表的存储位置由 Unity Catalog 决定，因此该 location 参数并非必需。请参阅 Databricks 官方文档 ↗ 以了解更多有关托管 Iceberg 表的信息。
