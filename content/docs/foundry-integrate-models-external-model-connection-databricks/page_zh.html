示例:集成 Databricks 模型

本页面提供了一个示例配置和模型适配器,用于建立与 Databricks 中托管模型的自定义连接。请查看 外部模型集成的优势 以了解外部模型是否适合您的使用场景。

如需分步指南,请参阅以下文档: 如何创建模型适配器 以及 如何创建与外部托管模型的连接。

在本示例中,您将:

  1. 发布并标记模型适配器
  2. 配置外部托管模型以使用此模型适配器
  3. 在实时部署或 Python 转换中托管模型并使用该模型

发布并标记 Databricks 表格模型适配器

连接到外部模型的第一步是 发布并标记模型适配器 ,此操作需要使用代码仓库中的模型适配器库。下面的示例模型适配器配置了与 Unity Catalog 模型的连接,该模型部署在 Databricks Model Serving ↗上。以下代码已使用版本 Python 3.11.11、 databricks-sdk 0.55.0和 pandas 2.2.3进行了测试。在本示例中,我们将使用来自 Databricks 机器学习教程 ↗的葡萄酒质量预测问题。

Databricks 表格模型适配器示例

请注意，此模型适配器做出以下假设：

  • 此模型适配器假定提供给此模型的数据为表格数据。
  • 此模型适配器会将输入数据序列化为 JSON，并将该数据发送到 Databricks 模型服务端点。
  • 此模型适配器假定响应可以从 JSON 反序列化为 pandas DataFrame。
  • 此模型适配器需要三个输入来构造客户端。
    • host：在 连接配置 （Databricks 实例的主机 URL）中提供。
    • serving_endpoint_name：在 连接配置中提供。
    • token：以 凭据形式提供。

import logging

import palantir_models as pm
import pandas as pd
from databricks.sdk import WorkspaceClient
from databricks.sdk.service.serving import QueryEndpointResponse

logger = logging.getLogger(__name__)


class DatabricksExternalModelAdapter(pm.ExternalModelAdapter):
    def __init__(self, host, serving_endpoint_name, creds):
        self.serving_endpoint_name = serving_endpoint_name
        self.client = WorkspaceClient(host=host, token=creds["token"])

    @classmethod
    def init_external(cls, external_context: pm.ExternalContext) -> "pm.ExternalModelAdapter":
        return cls(
            host=external_context.connection_config["host"],
            serving_endpoint_name=external_context.connection_config["serving_endpoint_name"],
            creds=external_context.resolved_credentials,
        )

    @classmethod
    def api(cls):
        input_cols = [
            "fixed_acidity",
            "volatile_acidity",
            "citric_acid",
            "residual_sugar",
            "chlorides",
            "free_sulfur_dioxide",
            "total_sulfur_dioxide",
            "density",
            "pH",
            "sulphates",
            "alcohol",
            "is_red",
        ]

        inputs = {"df_in": pm.Pandas(columns=[(col, str) for col in input_cols])}
        outputs = {"df_out": pm.Pandas(columns=[("predictions", bool)])}
        return inputs, outputs

    def predict(self, df_in):
        try:
            response: QueryEndpointResponse = self.client.serving_endpoints.query(
                name=self.serving_endpoint_name,
                dataframe_records=df_in.to_dict(orient="records")
            )
        except Exception as err:
            logger.error(f"An error occurred while querying the model serving endpoint: {err}")
            raise err
        else:
            return pd.DataFrame(response.as_dict()).drop("served-model-name", axis=1)

配置 Databricks 表格模型

在发布并标记模型适配器后，您需要 配置您的外部托管模型 以使用此模型适配器，从而按模型适配器的预期提供所需的配置和凭据。

请注意，上述 DatabricksExternalModelAdapter 需要此 URL，且应将其设置为完整的 Databricks 模型服务端点 URL。

选择出口策略

以下使用的出口策略已针对您的 Databricks 工作区域名（例如 <workspace-name>.cloud.databricks.com 或您的自定义域名）在端口 443 上进行了配置。

配置模型适配器

请在 连接外部托管模型 对话框中选择已发布的模型适配器。

配置连接 URL

将 Base URL 设置为完整的 Databricks 服务端点 URL，方法是设置 host 和 serving_endpoint_name （Databricks 适配器所需）。

配置凭据

定义凭据配置，具体要求来自 示例 Databricks 表格模型适配器。

此适配器需要以下凭据配置：

  • token：具有访问模型服务端点权限的 Databricks 个人访问令牌。

import pandas as pd
from transforms.api import Output, transform, lightweight
from palantir_models.transforms import ModelInput
from transforms.external.systems import EgressPolicy, use_external_systems


@lightweight
@use_external_systems(
    egress=EgressPolicy('<databricks_egress_policy>')
)
@transform(
    out=Output("<output_dataset_path>"),
    model=ModelInput("<external_model_path>"),
)
def compute(egress, out, model):
    df_in = pd.DataFrame([
        {
            "fixed_acidity": "7.4",
            "volatile_acidity": "0.7",
            "citric_acid": "0.0",
            "residual_sugar": "1.9",
            "chlorides": "0.076",
            "free_sulfur_dioxide": "11",
            "total_sulfur_dioxide": "34",
            "density": "0.9978",
            "pH": "3.51",
            "sulphates": "0.56",
            "alcohol": "9.4",
            "is_red": "1.0"
        },
        {
            "fixed_acidity": "7.4",
            "volatile_acidity": "0.7",
            "citric_acid": "0.0",
            "residual_sugar": "1.9",
            "chlorides": "0.076",
            "free_sulfur_dioxide": "11",
            "total_sulfur_dioxide": "34",

            "pH": "3.51",
