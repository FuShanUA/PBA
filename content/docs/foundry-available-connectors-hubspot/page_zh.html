身份验证

HubSpot 源使用私有应用访问令牌进行身份验证。

在您的 HubSpot 账户中创建一个私有应用并复制其访问令牌。有关当前步骤，请查阅 HubSpot 私有应用文档 ↗.

此连接器正常工作，私有应用必须满足以下要求：

  • 您必须是 HubSpot 超级管理员才能创建私有应用。
  • 授予私有应用的权限范围决定了连接器可以探索和同步哪些表。请为您打算在 Foundry 中使用的每个权限范围授予读取或写入权限。

权限范围不足的私有应用仍可成功通过身份验证。源在连接时不会报错，但会静默省略令牌无法访问的所有表，因此探索中缺失的表通常表明缺少权限范围，而不是连接问题。HubSpot 中的两项后续更改也会产生相同的结果：当 HubSpot 账户订阅降级时，私有应用会失去权限范围；使用 稍后轮换并过期 选项轮换访问令牌时，先前的令牌将在七天后过期。

迁移

HubSpot 已于 2022 年 7 月 15 日停止允许创建新的 API 密钥，并于 2022 年 11 月 30 日终止了 API 密钥身份验证。请查阅 HubSpot API 密钥终止变更日志 ↗ 了解详情。使用 API 密钥的现有源必须迁移到私有应用访问令牌。

  1. 在 HubSpot 中创建一个私有应用并复制其访问令牌，如 身份验证.
  2. In Connection settings > Connection details中，选择 私有应用 中所述，将其作为凭据方法并输入访问令牌。
