评估频率

Automate 提供三种评估频率模式，适用于 对象集条件： 实时监控、 定时监控，以及 依赖自动化。

评估频率支持情况

下表总结了支持每种评估频率模式的条件类型：

条件类型实时监控定时监控依赖自动化

实时监控

对象更改出现在本体论中后，实时监控会在几分钟内运行评估。 本体论索引 必须完成后，Automate 才能检测到该更改。延迟预期因更改类型而异：补丁（用户编辑）较小且处理速度较快，而基础版本（支撑数据集更改）较大且处理耗时较长。

查看上表 以了解支持实时监控的对象集条件。

Automate 实时监控支持 漏斗式批量管道，并且部分支持 漏斗式流式管道。例如，流式支撑的对象类型无法用于 Objects added to set 或 Objects removed from set 条件类型。

要求：

  • 对象类型必须使用 对象存储 v2。

将对象类型从对象存储 v1 迁移到 v2 后，请重新保存自动化以启用实时监控。

不支持的对象集功能：

  • 相对时间条件
  • 多个对象类型
  • 联接的对象集
  • 某些筛选器类型，例如前缀、词项和短语
  • 函数生成的对象集
  • 接口

定时监控

定时监控可能会导致较高的计算资源使用量，尤其是对于按计划频繁运行的复杂查询。

定时监控会按用户定义的计划评估条件。当不支持实时监控时，条件将默认使用定时监控。在 Automate UI 中，定时监控标签将说明是哪项功能导致无法使用实时监控。

大多数支持实时监控的条件都可以切换到定时监控：既可以选择 定时监控 （位于 Automation 界面的 评估频率 下拉菜单中），也可以添加计划。计划可让您在特定时间点或按固定周期检查对象集条件。

示例用例：摘要电子邮件

每周发送一份上周创建的新 Support Ticket 对象列表，但仅在存在工单时才发送：

  1. 为 已添加对象 条件（包含所有 Support Ticket 对象）添加每周一上午 8:00 的计划。
  2. 添加通知效果以渲染列表。

查看 周报示例用例 ，其中详细介绍了如何配置发送摘要邮件的自动化。

自动化依赖

自动化依赖监控会在另一个自动化触发时评估条件。您可以选择添加等待时间参数。

请参阅 评估频率支持表 ，以了解哪些条件支持自动化依赖监控。值得注意的是， 在所有对象上运行 即使不支持实时监控，也支持自动化依赖监控。
