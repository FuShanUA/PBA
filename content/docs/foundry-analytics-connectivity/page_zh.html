连接性：SQL 和 BI

Foundry 的开放架构使数据和转换逻辑均以非专有格式提供。通过以开放格式存储数据、公开 API、支持轻松连接和导出数据，以及提供对转换代码的访问权限，Foundry 可以轻松地与第三方软件和开源工具进行互操作。

Foundry 的开放集成生态系统可以通过安装自定义连接器进一步丰富，这些连接器专为支持与 Power BI® 和 Tableau 等热门商业智能软件的特定集成而定制。Foundry 还提供对 ODBC 和 JDBC 驱动程序的访问权限，可用于与更多第三方工具进行集成。

使用本指南设置您的 Foundry 商业智能工具集成，通过 Foundry 进行身份验证，并开始在第三方工具中使用 Foundry 数据。

当前可用的连接器

  • Power BI® 连接器
  • Tableau 连接器
  • Microsoft Report Builder 连接器
  • Excel
  • Qlik Sense
  • MicroStrategy
  • Foundry ODBC 和 JDBC 驱动程序
