创建连接流

在 Logic Flows 应用中，您可以：

  • 循环布局模块选择与嵌入式模块小部件模块选择类似，需要选择一个子模块。构建者可以通过指南针资源选择器选择现有模块，或者使用 连接流（右上角）
  • 查看现有的连接流，按自动化分组

要打开该应用，请前往 /workspace/logic-flows.

要在以下位置创建连接流 Compass Files Lister，请按照以下步骤操作：

  1. 创建新连接流时，系统会显示一个对话框，允许您设置名称、项目及所需参数和配置。这些内容会在输入时自动验证，也可以通过点击 验证.
    手动验证。对于 Compass Files Lister 自动化，您需要设置输入文件夹和输出仓库。



    逻辑流是 项目作用域，这意味着您必须指定将创建连接流资源的项目。连接流应与用于连接该流的任何参数保存在同一项目中。

  2. 保存连接流后，它将显示在连接流列表中。



  3. 要触发作业，请点击 构建 （位于特定连接流的行内）。一条消息会将您指向 Builds 应用视图，您可以在其中监控作业的状态。



  4. 要检查作业的结果，请在目标仓库视图中验证拉取请求。



  5. 返回 Logic Flows 应用后，您可以查看您的连接流、其参数和配置，并从那里创建计划。
