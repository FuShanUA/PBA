导入 Hugging Face 模型

现已弃用的 导入开源模型 功能的用户可以使用 语言模型适配器 源代码作为起点，编写用于封装 Hugging Face 模型的适配器。所链接的适配器不再由 Palantir 积极维护，仅供参考。取而代之的是，应根据您自己的判断，直接在 Foundry 适配器仓库中发布、维护和扩展替代适配器。

除 Palantir AIP 原生支持的 LLM之外，Foundry 使用户能够与 Hugging Face ↗ 或 spaCy ↗等流行的语言模型框架进行集成。 此类自然语言框架可在 Foundry 中用作通过 Conda 或 PyPI 分发的软件包。

然而，这些语言模型框架通常要求用户从互联网下载预训练模型或语料库，以进行进一步的微调。这些下载内容通常需要额外的步骤才能在 Foundry 中完全正常运行。这是 Foundry 安全架构所致，该架构默认拒绝用户编写的 Python 代码访问公共互联网。所需的额外步骤取决于语言模型框架的具体细节。

Hugging Face

要将 Hugging Face 语言模型导入 Foundry，有两种可用选项：

  1. 将模型文件作为原始数据集导入。
  2. 将 Hugging Face 域名加入允许列表。

将模型文件作为数据集导入

您可以将 Hugging Face 模型中心的任何模型导入为数据集。您可以在代码仓库或代码工作区中使用该数据集。

首先， 下载 ↗ Hugging Face 上的模型文件。然后，将模型作为无模式数据集上传，以将文件导入 Foundry。这些文件既可以通过前端上传（新建 > 数据集 > 导入 > 选择所有文件）也可以通过 Data Connection 同步来上传，前提是模型文件存储在您的私有网络中的共享驱动器上。

导入的数据集应包含 Hugging Face 上模型详情页面的 文件和版本 标签页中的所有文件。但是，只需要一个二进制模型文件（例如， pytorch_model.bin 或 tf_model.h5）。在大多数情况下，我们建议使用 PyTorch 模型作为二进制模型文件。

模型文件存储到数据集中后，您就可以将该数据集用作转换的输入。根据模型的大小，您可能需要指定 Spark 配置文件 ，例如 DRIVER_MEMORY_MEDIUM 以将模型加载到内存中。以下代码使用了一个实用工具，该工具来自 foundry-huggingface-adapters:

将 Hugging Face 域名加入白名单

要直接从 Hugging Face 下载模型，您可以通过 配置网络出口策略，在您的 Foundry 注册中将相关域名加入白名单。需要加入白名单的相关域名如下：

  • https://huggingface.co ↗
  • https://hf.co ↗
  • https://cas-bridge.xethub.hf.co ↗
  • https://cas-server.xethub.hf.co ↗
  • https://transfer.xethub.hf.co ↗
  • https://cdn-lfs.hf.co ↗
  • https://cdn-lfs-us-1.hf.co ↗
  • https://cdn-lfs-eu-1.hf.co ↗
  • https://us.gcp.cdn.hf.co ↗
  • https://us.aws.cdn.hf.co ↗

您用于下载模型的 Hugging Face 域名可能会随时发生变化，恕不另行通知。如果在将上述域名加入白名单后仍无法下载模型，则应尝试通过记录请求日志来识别哪些域名仍被拦截，以协助您进行调试。您可以参考 Stack Overflow ↗ 上的详细说明，以帮助您在 httplib 级别启用调试。

此外，从 Hugging Face 加载模型的代码仓库必须已添加 transforms-external-systems 库 ，并且需要 进行相应配置 ，以使用新创建的出口策略。配置完成后，即可在 Python 转换中加载开源语言模型。

如果您收到错误 PermissionError: [Errno 13] Permission denied: '/.cache'，您必须在加载模型时传入缓存目录，如下面的示例所示。

在 Foundry 中的用法

在通过数据集或 Hugging Face 域获得对语言模型的访问权限后，您就可以将其作为 Palantir 模型进行集成，方法是使用 模型适配器 包装该语言模型，其定义见 代码仓库中的模型训练文档。

在 model_output.publish() 创建模型版本后，请使用 ModelInput 加载模型，以便在下游转换中运行推理。如需完整的转换示例（包括如何选择模型版本 API 中指定的输出），请查看 在 Python 转换中运行推理。
