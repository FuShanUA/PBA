Amazon Marketplace

Amazon Marketplace 连接器是一个 由 Palantir 提供的驱动程序 ，用于 Amazon Marketplace。

要创建新的 Amazon Marketplace 源，请按照 Palantir 提供的驱动程序的标准设置流程，然后使用以下部分进行 Amazon Marketplace 特定的配置和网络设置。有关完整的属性参考，请参阅 官方 Amazon Marketplace 驱动程序文档 ↗.

测试版

Amazon Marketplace 连接器目前处于 测试版 开发阶段，可能无法在您的注册租户中使用。功能在积极开发过程中可能会发生变化。

配置

以下属性为必填项或推荐项。

属性是否必填？描述默认值
IncludeReports ↗推荐将此连接属性设置为 true 可将已创建的报表公开为视图，该属性在两种架构（SellerCentral 和 VendorCentral）中均可用。FALSE
InitiateOAuth ↗推荐网络REFRESH
Marketplace ↗推荐您注册销售的 Marketplace 区域。United States
OAuthClientId ↗推荐指定创建自定义 OAuth 应用程序时分配的客户端 ID。（也称为消费者密钥。）此 ID 用于向 OAuth 授权服务器注册自定义应用程序。—
OAuthClientSecret ↗推荐指定创建自定义 OAuth 应用程序时分配的客户端密钥。（也称为消费者机密）。此密钥用于向 OAuth 授权服务器注册自定义应用程序。—
Schema ↗推荐要使用的架构类型。Marketplace
SellerId ↗推荐您在创建账户时收到的卖家 ID 或商家标识符。—

网络

下表列出了源运行时必须能够访问的域。

为每个域名添加相应的 出口策略。如果该源托管在本地且无法从 Foundry 直接访问，请改用 代理出口策略 作为替代。代理主机本身也必须能够访问所列出的域。请参阅 使用代理作为代理服务器 了解详情。

域名必需
sts.<AWSRegion>.amazon.comIf Schema=SellingPartner, cognito-identity.<AWSCognitoRegion>.amazonaws.<TLD>
sellingpartnerapi-<AWSRegion>.amazon.comIf Schema=SellingPartner, SellingPartner 映射
sandbox.sellingpartnerapi-<AWSRegion>.amazon.comIf Schema=SellingPartner and UseSandbox=True, SellingPartner 沙盒映射

api.amazon.com如果使用 OAuth

OAuth 2.0 身份验证

此连接器支持 OAuth 2.0 身份验证。请按照 Palantir 提供的驱动程序的 OAuth 2.0 指南 来配置和授权连接。

提取文件

可以通过执行 GetReport ↗ 存储过程从 Amazon Marketplace 提取文件。

要提取文件，请在同步定义中添加以下 SQL 查询。

Copied!
1
EXECUTE GetReport @ReportDocumentId = '1234'

这将生成一个输出数据集，其中文件内容存储在 Base64 编码的字符串列中，应在下游数据转换中将其解码为二进制。
