transforms.api.TableTransformInput

类 transforms.api.TableTransformInput(rid, branch, table_dfreader)

在运行时为虚拟表输入传递给转换对象的输入对象。模拟 TransformInput API。

属性 batch_incremental_configuration

将分批读取的增量输入的配置。

  • 类型： BatchIncrementalConfiguration

属性 branch

数据集的分支。

  • 类型： str ↗

属性 catalog

返回表的 Spark catalog 名称，供在 Spark 过程中使用（如果底层表类型支持）。

  • 返回： 表的 catalog 名称。
  • 返回类型： str ↗
  • 引发： ValueError ↗ – 如果底层表类型不提供 Spark catalog。

属性 column_descriptions

数据集的列描述。

  • 类型： Dict[str, str]

属性 column_typeclasses

数据集的列类型类。

  • 类型： Dict[str, str]

dataframe(options=None)

返回一个 pyspark.sql.DataFrame ↗ ，其中包含表的完整视图。

  • 参数： options (dict ↗ , option) – 读取表时要传递的额外 Spark 读取选项。
  • 返回： 表的 DataFrame。
  • 返回类型： pyspark.sql.DataFrame ↗

属性 end_transaction_rid

输入数据集的结束事务。

  • 类型： str ↗

filesystem()

构造一个用于从 FoundryFS 读取的 FileSystem 对象。

  • 返回： 一个用于从 Foundry 读取的 FileSystem 对象。
  • 返回类型： transforms.api.FileSystem

属性 identifier

返回表的完全限定、带目录前缀的 Spark V2 标识符（如果底层表类型支持）。

  • 返回： 表的完全限定标识符。
  • 返回类型： str ↗
  • 抛出： ValueError ↗ – 如果底层表类型未提供 Spark V2 标识符。

pandas()

pandas.DataFrame ↗：包含数据集完整视图的 Pandas 数据框。

property path

数据集的 Compass 路径。

  • 类型： str ↗

property rid

数据集的资源标识符。

  • 类型： str ↗

property start_transaction_rid

输入数据集的起始事务。

  • 类型： str ↗
