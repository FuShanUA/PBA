SAP 附加组件的安装

Palantir Foundry Connector 2.0 for SAP Applications（"Connector"）由 Palantir 与 Diskover Limited ↗合作开发，是一个基于 ABAP 的数据提取接口，用于将 SAP 系统中的数据集成到 Palantir Foundry。该 Connector 运行在 SAP ABAP 平台（以前称为 SAP NetWeaver Application Server）上，并通过 REST API 调用经 HTTPS 提供数据服务。

该 Connector 可用于将数据从 SAP 直接同步到 Foundry、在 SAP 中探索数据，以及通过远程函数向 SAP 写入数据。

该 Connector 由四个应用程序组件组成：

  • PALANTIR（必需）： Palantir Foundation 组件包含 PALCONN （Connector）、 PALAGENT （Remote Agent）和 PALODATA （通过 OData 的 SLT）所需的所有共享对象。
  • PALCONN： Palantir Foundry Connector 应用程序组件（PALCONN）包含所有与连接器相关的对象和服务。该组件不适用于 Remote Agent，且不能安装在 SAP_BASIS（技术组件版本，适用于 SAP NetWeaver 和 SAP S/4HANA 系统）7.4 SP05 以下的环境中。
  • PALAGENT（可选，适用于 SAP_BASIS 低于 7.4 SP05 的环境）： Palantir Foundry Remote Agent 应用程序组件（PALAGENT）包含所有与远程代理相关的对象和服务，用于从运行在 SAP_BASIS 7.4 SP05 以下的 SAP 应用程序中摄取数据。低于 SAP_BASIS 7.4 SP5 的系统必须通过运行 SAP_BASIS 7.4 SP5 或更高版本的系统进行远程访问，且该系统需安装 PALCONN 组件。请查阅 远程架构文档 以了解更多详情。
  • PALODATA（可选，仅适用于 SLT 系统）： Palantir Foundry OData 应用程序组件（PALODATA）包含与通过 OData API 摄取 SLT 数据相关的对象和服务，也称为 通过 OData 进行基于 ODP 的数据提取 ↗.

请先将附加组件安装到开发或沙盒系统中并进行充分测试，然后再安装到生产环境。

安装场景

该 Connector 有三种可用的安装场景。

对于所有场景， 请确保已下载相关的安装包 ，然后再继续。

独立安装

该 Connector 可以直接安装在源 SAP 系统上。此场景支持以下对象类型：

  • SAP 表和视图
  • InfoProvider
  • BEx 查询
  • SAP Business Content 提取器
  • SAP 函数 / BAPI
  • 基于 SAP ABAP 的 CDS 视图
  • 通过 SAP 函数进行回写（可选择使用 OAuth 2.0 进行用户归因）

对于此场景，请按照以下指南操作：

  • 安装 Connector

SLT 安装

对于 Connector 2.34 版（SP34）及更高版本，需要安装一个额外的 PALODATA 组件才能连接到 SLT。

直方图 PALODATA 组件为 SLT 同步提供 OData API，需要 SAP_BASIS 7.50 SP09 或更高版本。安装后，请按照 使用 OData 进行 SAP SLT 同步 使用 OData 配置新的同步，并将现有同步从 ODP API 迁移过来。

在此场景中，Connector 安装在 SAP SLT Replication Server 上。

在这种情况下，仅支持 SLT 对象类型。

对于此场景，请按照以下指南操作：

  • 安装 Connector
  • 配置 SAP SLT

Remote Agent 安装

源 ERP 系统可能不满足 Connector 的安装要求。在此场景中，应部署一个 SAP_BASIS 版本为 7.4 SP5 或更高的 SAP ABAP 平台作为源 SAP 系统的网关。Connector 应安装在网关服务器上，通过 RFC 连接与源 ERP 系统通信，并经 HTTPS 向 Foundry 提供数据服务。Connector 的 Remote Agent 应安装在源 ERP 系统上，以响应来自 Connector 的请求。

对于此场景，请按照以下指南操作：

  • 使用 主安装指南
  • 将 Connector 安装到网关服务器

如果源 ERP 系统的 SAP_BASIS 版本低于 7.0 SP32，请按照以下指南操作：

  • 为 ERP 4.6C/4.7 (620/640) 安装远程代理
