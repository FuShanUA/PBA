元数据参考

接口在 Ontology（本体论）中由以下元数据表示：

  • RID： Palantir 中每个资源自动生成的唯一标识符。接口的 RID 将在平台各处的错误消息中被引用。
  • 图标： 用作视觉标识符的图片和颜色，当用户在应用程序中查看此接口时会显示。接口的图标周围有虚线边框，以便在视觉上与对象类型图标区分开来。例如，带有虚线边框的建筑图标可用于表示 Facility interface.
  • 显示名称： 在用户应用程序中向访问此接口的任何人显示的名称。例如， Facility 接口的显示名称可以是 "Facility"。
  • 描述： 关于接口的说明文字，任何人都可以在用户应用程序中阅读。例如， Facility 接口的描述可以是 "用于表示航空设施的抽象对象类型接口"。
  • API 名称： 在代码中以编程方式引用接口时使用的名称。例如， Facility 接口的 API 名称可以是 facility.
  • 状态： 向用户和 Ontology 构建者发出的关于接口在开发流程中所处阶段的信号。它可以是 active, experimental, example，或 deprecated。默认情况下， Facility 接口将具有 experimental 状态。了解更多关于 状态的信息.
  • 可搜索： 一个布尔值，指定接口是否可搜索。可搜索的接口使用户能够一次性加载或搜索该接口的所有对象。可搜索的接口最多支持 75 个实现对象类型，而不可搜索的接口最多支持 1,000 个。默认情况下， Facility 接口将是可搜索的。
