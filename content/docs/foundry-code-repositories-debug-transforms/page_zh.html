调试转换

使用 Code Repositories 中的调试器工具，在数据转换运行时检查其行为。设置断点以暂停转换的执行，以便检查变量、查看数据框，并理解函数和库。

调试器仅适用于 或.

设置断点

要使用调试器，您需要设置 断点。断点向调试器发出信号，指示其应在何处暂停代码的执行，并允许您与变量和数据框进行交互。

您可以通过点击每行代码边距处的淡红色圆点来设置断点。调试器会暂停执行 然后 标记的行运行。如有需要，您可以在多个文件中设置多个断点。

使用内部库断点时，控制台功能可能会受到限制。在这些情况下，断点会显示为灰色，调试器会提供忽略该断点或使用受限控制台功能的选项。

运行调试器

在代码中添加断点后，点击 预览和调试 （位于代码编辑器操作栏中）。调试器面板将打开，并在遇到的第一个断点处暂停。调试器的左侧栏允许您导航代码、移除断点以及结束/停止调试会话。

您可以启用导航内部库的功能。找到 内部库调试已禁用 部分，然后选择 启用内部库调试.

在代码中导航时，编辑器会高亮显示下一行要执行的代码。使用以下按钮来推进调试器：

  1. 恢复执行： 继续执行，直至完成或在下一个断点处暂停。
  2. 单步跳过： 执行该行代码，而不进入内部函数。
  3. 单步进入： 如果该行代码中存在内部函数，则进入该内部函数。
  4. 单步跳出： 跳出内部函数并推进调试器。
  5. 停止执行： 完全停止调试器。
  6. 删除断点： 移除仓库中的所有断点，并在运行预览时不暂停执行。
  7. 设置： 打开/关闭调试器（不清除断点）。
  8. 文档： 打开文档以了解更多详细信息。

检查变量

在调试器运行期间，您可以在代码执行的确切位置检查变量和数据。

帧

帧表示调试器处于活动状态或存在断点的函数。每个帧显示函数名称，后跟函数所在文件的名称及其行号。

选择某个帧以检查该帧内的变量，并对其运行控制台命令。

变量

直方图 变量 部分显示转换执行期间存储在局部变量和全局变量中的值。

数据框的值基于预览样本，可能无法代表完整的数据集。请将其用于理解和调试代码，而不要将其作为转换输出的依据。

控制台

控制台允许您在运行调试器时使用 PySpark 命令与数据进行交互。控制台中有两种常用的模式：

  • 在控制台选项卡底部的命令行中直接对数据框和变量运行命令，并使用 Enter 或 Return 键发起命令。
  • 调用 print 转换代码中的函数，向控制台发送指示性信息。

请注意，控制台针对所选帧运行。尝试对属于其他帧的局部变量执行命令将导致 NameError。

配置调试器

通过导航到调试器选项卡并点击设置齿轮图标，可以开启和关闭调试器功能。如果您希望运行预览而不在断点处停止，请关闭调试器。

虽然调试器配置适用于整个仓库，但仓库中可能存在不受其支持的语言。如果某种语言不受调试器支持，则无论调试器设置如何，预览都将正常运行。

您还可以在 设置 选项卡（位于 首选项 > 调试器.
