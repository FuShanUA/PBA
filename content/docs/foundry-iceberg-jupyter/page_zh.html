在代码工作区中通过 Jupyter® notebook 使用 Iceberg

您可以在 代码工作区 中使用 Jupyter® notebook，并通过 PyIceberg、SQL 或 Spark 与 Iceberg 表进行交互。

对于虚拟 Iceberg 表， SQL 并不要求您将数据源添加到工作区，这意味着您无需在数据源上启用代码导入。如果该数据源不应在代码中使用，这可能是您的首选方案。

PyIceberg

按照以下说明，在 Jupyter® 笔记本中使用 PyIceberg 读取和写入 Iceberg 表：

  1. 在代码工作区中打开 Jupyter® 工作区。
  2. 选择 添加 > 读取数据 从 数据 面板以将 Iceberg 表添加到您的工作区。

  1. 请按照 导入表 部分（位于 数据 面板）中概述的步骤进行操作，以安装所需的客户端库、为该表添加别名，并复制代码片段来与您的数据进行交互。

SQL

请按照 上述相同步骤 以在 Jupyter® 笔记本中使用 SQL 查询 Iceberg 表。在您选择 读取数据 以将 Iceberg 表添加到您的工作区后，请将模式切换为 containers-sql 而非 transforms-table。

详细了解如何在代码工作区中使用 SQL 查询表格数据集。

Spark（高级用法）

按照以下各节中的说明，在 Jupyter® 笔记本中使用 Spark 读取和写入 Iceberg 表。

将代码工作区设置为使用 Iceberg

  1. PySpark 设置： 要设置使用 PySpark 的代码工作区，请按照 代码工作区常见问题解答文档中的说明进行操作。
  2. 上传 Iceberg JAR 文件： 下载 Spark 3.5 with Scala 2.12 和 aws-bundle JAR 文件，可从 Iceberg 的发布页面 ↗下载。创建一个名为 /libs的新文件夹，并将 JAR 文件上传到该文件夹中。
  3. 网络策略： 将您的 Iceberg 存储桶的网络策略导入到您的代码工作区中。

Jupyter® notebook 示例代码

首先，创建 Spark 会话。请注意，运行此代码将提示您输入用户令牌，该令牌可在您的账户设置中生成。参见 用户生成的令牌 ，了解创建令牌的分步指南。

4spark = (
5    SparkSession.builder
6        .master("local[*]")
7        .appName("foundry")
8        .config("spark.jars", "file:///home/user/repo/libs/iceberg-spark-runtime-3.5_2.12-1.9.1.jar,file:///home/user/repo/libs/iceberg-aws-bundle-1.9.1.jar")
9        .config("spark.sql.extensions", "org.apache.iceberg.spark.extensions.IcebergSparkSessionExtensions")

11        .config("spark.sql.catalog.foundry.type", "rest")
12        .config("spark.sql.catalog.foundry.uri", "https://<your_foundry_url>/iceberg")
13        .config("spark.sql.catalog.foundry.default-namespace", "foundry")
14        .config("spark.sql.catalog.foundry.token", getpass("Foundry token:"))
15        .config("spark.sql.defaultCatalog", "foundry")
16        .getOrCreate()
17)

转义空格

如果您的路径中包含空格，则必须确保该空格已被正确转义。在 Spark 中，您可以使用反引号 (`) 来转义空格，例如 `/.../My folder/Iceberg table`. 使用 PyIceberg，您可以使用 URL 编码。
