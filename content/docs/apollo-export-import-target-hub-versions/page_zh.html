目标 Hub 版本

如果您的管道环境元数据与目标 Hub 中的实际状态不同步，您可以更新管道以反映真实状态。这可以使 Bundle 更小，并确保发布基于有效的升级路径导出。您可以使用Bundle 预览来准确查看源 Hub 上的潜在升级阻碍因素。

先决条件

您必须拥有一个可导出环境的增量导出管道，才能使用目标 Hub 版本。了解有关创建导出管道的更多信息。

您必须在管道上构建过 Bundle，才能编辑目标 Hub 版本。

编辑目标 Hub 版本

您可以针对每个实体编辑目标 Hub 版本，也可以使用 JSON 进行批量编辑。

同步目标 Hub 和源 Hub 管道状态

在您的 Target Hub 中，导航到您的环境页面。选择 操作 > 下载实体 > 为 JSON。

下载该 JSON，然后将其上传到您的管道中。

未来的 Bundle 将基于这些更新后的版本进行构建。
