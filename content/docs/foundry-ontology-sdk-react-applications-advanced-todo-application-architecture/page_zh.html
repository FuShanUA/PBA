入门

要访问并安装高级待办事项应用程序示例，请打开代码工作区应用程序并选择创建 + 新建工作区。然后，选择 VS Code > Applications 并在精选示例列表中找到该应用程序。

您还可以在平台的 Examples (Build with AIP) 中搜索该应用程序，或者在 Developer Console 中搜索本体论 SDK 参考示例。

应用程序架构

以下章节将介绍您可以创建的高级待办事项应用程序的架构，包括路由、客户端配置以及在组件中的用法。

该应用程序采用现代 React 架构，包含以下特性：

  • 数据服务 Hook： 封装 OSDK 交互（useProjects、 useTasks等）。
  • UI 组件： 包含专注于展示和用户交互的组件。
  • 用于数据管理的 SWR（stale-while-revalidate）策略： 处理缓存、重新验证和后台更新。
  • 组件特定逻辑： 每个组件都能恰好访问其所需的数据。

身份验证配置

客户端在单独的 client.ts 文件中进行配置，该文件负责处理以下内容：

  1. OAuth 身份验证设置： 使用 OSDK OAuth 客户端配置身份验证流程。
  2. 客户端初始化： 使用经过身份验证的用户会话来设置 OSDK 客户端。
  3. 配置参数： 从 meta 标签中检索 Foundry URL、客户端 ID、重定向 URL 以及其他 OAuth 参数。

OAuth 客户端负责处理以下事项：

  • 身份验证重定向流程
  • 令牌获取与刷新
  • 会话管理
  • 确定用于 API 访问的适当作用域

import { useCallback } from "react";
import { useOsdkClient } from "@osdk/react";
import { OsdkITask } from "@advanced-to-do-application/sdk";
import type { IProject } from "./useProjects";

function MyComponent({ project }: { project: IProject }) {
  const client = useOsdkClient();

  const fetchData = useCallback(async () => {
    const tasksPage = await client(OsdkITask).where({
        projectId: { $eq: project.$primaryKey },
    }).fetchPage({
        $orderBy: { "dueDate": "desc", "status": "asc" },
    });
    // Process and return the data
  }, [client, project.$primaryKey]);

  // Rest of the component
}

此使用模式可确保以下几点：

  • 身份验证在应用程序根组件中集中处理。
  • 组件仅访问经过身份验证的用户有权查看的数据。
  • OAuth 令牌会自动刷新。
  • API 请求包含正确的身份验证标头。

应用程序配置

高级待办事项应用程序使用环境变量进行配置，从而允许在开发环境和生产环境之间采用不同的设置。配置值主要通过 HTML 中的 meta 标签应用，然后由 client.ts 文件读取。

环境文件

应用程序使用以下环境文件：

  • .env： 在所有环境中使用的基础环境变量。
  • .env.development： 开发环境专用变量（与 npm run dev配合使用）。
  • .env.production： 生产环境专用变量（与 npm run build配合使用）。

在以下文件中配置 meta 标签： index.html

应用程序在以下文件中使用 meta 标签： index.html 来动态配置 OSDK 客户端。这种方式避免了将敏感信息直接硬编码到 JavaScript 代码中：

<meta name="osdk-clientId" content="%VITE_FOUNDRY_CLIENT_ID%" />
<meta name="osdk-redirectUrl" content="%VITE_FOUNDRY_REDIRECT_URL%" />
<meta name="osdk-foundryUrl" content="%VITE_FOUNDRY_API_URL%" />
<meta name="osdk-ontologyRid" content="%VITE_FOUNDRY_ONTOLOGY_RID%" />

Meta 标签详解

  • osdk-clientId: 用于身份验证的 OAuth 客户端 ID。
  • osdk-redirectUrl: 身份验证成功后重定向的 URL。
  • osdk-foundryUrl: Foundry API 的基础 URL。
  • osdk-ontologyRid: 应用程序本体论的资源标识符。

const getBatchUserDetails = useCallback(async (userIds: string[]) => {
    const cachedUsers: UserDetails = {};
    const usersToFetch: string[] = [];

    userIds.forEach((userId) => {
      const cachedUser: State<unknown, unknown> | undefined = cache.get(`user-${userId}`);
      if (cachedUser && cachedUser.data) {
        cachedUsers[userId] = cachedUser.data as User;
      } else {
        usersToFetch.push(userId);
      }
    });

    if (usersToFetch.length > 0) {
      const usersRequest = await getBatch(client, usersToFetch.map((userId) => ({ userId })));
      Object.entries(usersRequest.data).forEach(([userId, user]) => {
        cachedUsers[userId] = user;
        mutate(`user-${userId}`, user, { revalidate: false });
      });
    }
    return cachedUsers;
  }, [cache, client]);
