可用事件和操作

本页面列出了 Slate 中在查询、函数、变量、组件和应用程序级别的所有可用事件和操作。了解如何在我们的 附加文档中配置和使用这些事件和操作.

全局事件

全局事件是在应用程序级别发生的事件，不特定于单个组件或查询。

slate.ready

直方图 slate.ready 事件在页面框架加载完成且查询开始运行后触发。任何希望在页面加载时立即触发的操作（例如，触发一些手动查询）都应在此处执行。

slate.resize

直方图 slate.resize 事件在浏览器窗口大小调整时触发。如果任何组件的大小基于浏览器窗口的大小，它们也会被调整大小。但是，某些组件（如图表）具有一个 redraw 操作，您可以触发该操作以确保组件即使在浏览器窗口大小变化时也能以正确的大小重新绘制。

slate.onNavigate[page_name]

slate.onNavigate[page_name] 在用户导航到添加了该事件的页面时触发。

slate.onPrint

slate.onPrint 在用户关闭之前通过 slate.print 操作来设置自定义 favicon。

slate.userStorageChanged

slate.userStorageChanged 在 slate.setUserStorage 操作更新 sl_user_storage时触发。如果另一个浏览器标签页或窗口更新了用户存储，该事件也会触发。 sl_user_storage 的新值可作为 {{slEventValue}}.

此事件适用于在页面加载时基于用户存储初始化局部变量，因为 sl_user_storage 在 slate.ready 触发时可能尚未完全加载。

slate.viewSaved

slate.viewSaved 在一个 可共享视图 通过 操作 下拉菜单或 slate.saveView 操作保存后触发。 {{slEventValue}} 包含新创建视图的视图 ID（字符串）。

此事件可以与 slate.loadView 操作配对以构建保存和加载工作流。例如，您可以存储来自 {{slEventValue}} 的视图 ID，稍后将其传递给 slate.loadView 以恢复该视图。

查询事件

查询事件是与 Slate 应用程序中的查询相关的事件，在查询完成或由于超时、查询格式错误或其他服务器问题导致查询未能成功完成时触发。每个查询都有自己独立的事件实例。

QUERY_NAME.success

此事件在由 QUERY_NAME 指定的查询成功完成时触发。每个查询都有自己独立的事件实例。

QUERY_NAME.failure

此事件在由 QUERY_NAME 未能成功完成，原因可能是超时、格式错误的查询或其他服务器问题。每个查询都有其自己的此事件实例。

函数事件

函数事件是与 Slate 函数执行相关的事件。每个函数都有其自己的这些事件的实例。

FUNCTION_NAME.ran

每当由以下指定的函数 FUNCTION_NAME 完成运行时，此事件就会触发。每个函数都有其自己的此事件实例。

变量事件

变量事件是与 Slate 变量交互相关的事件。每个变量都有其自己的这些事件的实例。

VARIABLE_NAME.changed

每当由以下指定的变量 VARIABLE_NAME 发生变化时，此事件就会触发。更改后的值将作为 {{slEventValue}}提供。每个变量都有其自己的此事件实例。

小部件事件

小部件事件是用于在您的 Slate 应用程序中引发操作或活动的触发器。它们可用于在您的应用程序中创建交互性并自动化流程。每个小部件都有其自己的这些事件的实例。

WIDGET_ID.cssClassesUpdated

每当属于指定小部件的“附加 CSS 类”属性 WIDGET_ID 发生变化时，此事件就会触发。此事件在 DOM 更新之后、绘制之前触发；这意味着如果您使用 CSS 类来更改不同小部件的大小，使用此事件来触发 redraw 对这些小部件的操作将完全按预期工作。每个小部件都有其自己的此事件实例。

WIDGET_ID.transitionend

每当指定小部件内部直接发生 JavaScript transitioned 事件时，此事件就会触发，该小部件由以下指定 WIDGET_ID。在这种情况下，“直接”意味着不是来自子小部件；每个 transitioned只触发一个事件。更具体地说，您可以使用 CSS 过渡来为页面上的元素设置动画，例如让侧边栏滑入滑出而不是弹出弹入。每当其中一个过渡完成时，JavaScript 将触发一个 transitioned 事件，Slate 会捕获并传递该事件。这样，您可以在过渡完成时触发页面上的其他更改，或对 resize 可能已更改大小的小部件执行操作。

每当此事件被触发时， {{slEventValue}} 是一个包含以下属性的 JavaScript 对象：

  • elapsedTime：过渡所花费的时间
  • propertyName：正在设置动画的属性的名称
  • targetId：如果正在设置动画的 DOM 元素具有 ID 属性，则可在此处获取该属性

这些属性可能有助于区分特定的过渡与其他过渡；请确保您的代码响应的是正确的事件。每个小部件都有其自己的此事件实例。

WIDGET_ID.INTERACTION_PROPERTY.changed

每当属于由以下指定的小部件的 INTERACTION_PROPERTY 属性 WIDGET_ID 发生变化时，此事件就会触发。更改后的值将作为 {{slEventValue}}提供。此事件并非在每个小部件的每个属性上都可用，而仅在“交互属性”上可用（即小部件中可由用户交互更改的属性，例如 selectedValue）。每个小部件交互属性都有其自己的此事件实例。

全局操作

全局操作控制应用程序级别的行为更改，例如页面或窗口修改、数据导出以及跨应用程序消息传递。

slate.navigateTo[page_name]

直方图 slate.navigateTo[page_name] 操作会将作用域中的页面更改为 page_name ，并且还会更新 URL 路由以指向目标页面。 共享变量 将在页面更改之间保持其状态。

slate.scrollToId

直方图 slate.scrollToId 操作将滚动页面（以及页面中的任何其他可滚动容器）到具有给定 ID 的 DOM 元素（在事件面板中的 JavaScript 代码中返回的 ID）。此操作可用于以编程方式将页面滚动到特定元素，或返回到可滚动表格或列表中记住的位置。

slate.setWindowTitle

直方图 slate.setWindowTitle 操作允许您重命名当前浏览器窗口的标题并更新标签页名称。调用该操作并返回一个字符串以设置标签页名称。如果在页面加载时未调用此操作，Slate 会默认将标签页标题设置为文档名称。

slate.print

直方图 slate.print 操作将打开浏览器的打印对话框，允许用户在打印前选择打印机选项。

slate.downloadBlob

直方图 slate.downloadBlob 操作允许您在遵循 Slate 导出限制的前提下下载任意数据 blob。要使用此操作，请添加如下返回语句：

    exportType: "download",

使用此事件将触发 slate.onExportWidget 事件，该事件将包含一个 slEventValue ，其中包含：

  • widgetId：被导出小部件的 ID。

设置 exportType to eventOnly 构建（build） slate.onExportWidget 事件，而不复制/下载文件。

直方图 slate.sendMessage 操作适用于嵌入在其他应用程序 iframe 中的 Slate 应用。具体而言，此操作会获取传递给它的值（从面板中的 JavaScript 代码返回），并向父级 iframe 发送如下形式的 postMessage：

Copied!
1

直方图 <payload> 是从面板中 JavaScript 代码返回的值。

直方图 slate.sendMessage 操作也可用于向其他窗口发送消息，即使 Slate 并未嵌入 iframe 中。

例如，您可以使用 slate.redirectToUrl 以在新标签页或浏览器窗口中打开子窗口，并为该窗口设置一个 ID。

查询操作

查询操作作用于特定查询或其结果集。它们使应用程序构建者能够在特定事件触发时运行查询或导出查询结果集。

QUERY_NAME.run

此操作将立即运行由 QUERY_NAME指定的查询。无论查询是否为手动查询，此操作均有效。每个查询都有其自己的此操作实例。

QUERY_NAME.export, QUERY_NAME.exportXlsx, QUERY_NAME.exportCsv

QUERY_NAME.export 将导出由 QUERY_NAME 指定的查询结果，格式为 .xlsx 文件。它将在服务器上运行查询，生成文件，并将其下载到用户的计算机上。每个查询都有其自己的此操作实例。

直方图 QUERY_NAME.export 操作可以作为事件的触发器添加，来源为 导出于 下拉菜单，位于 查询 标签页。

默认情况下，文件将被命名为 QUERY_NAME.xlsx。要更改此设置，请导航到 事件 选项卡并选择 QUERY_NAME.export。然后，您可以添加一个 return 语句来配置文件名。例如， return "january_data" or return {fileName: "january_data"} 将下载一个名为 january_data.xlsx的 .xlsx 文件。有效的文件名不能为空，且只能包含字母、数字、下划线或空格。如果 return 语句中的文件名无效，将使用查询的名称作为文件名。

您可以从 QUERY_NAME.exportXlsx or QUERY_NAME.exportCsv 操作中选择 操作 下拉菜单，位于 事件 选项卡。然后，您可以添加一个 return 语句，将文件名更改为有效的文件名。

QUERY_NAME.exportCsv, QUERY_NAME.exportXlsx

这些操作会下载由以下指定的查询的输出 QUERY_NAME 到用户的本地计算机。结果可以下载为 CSV 或 Excel 文件。默认情况下，文件将采用查询的名称，但您可以通过在事件中返回一个 { fileName: <<custom_string>> } 对象来自定义名称。

函数操作

函数操作作用于特定函数或其结果集。它们使应用程序构建者能够在特定事件触发时运行函数或导出函数结果集。

FUNCTION_NAME.run

此操作将立即运行由以下指定的函数 FUNCTION_NAME。每个函数都有其自己的此操作实例。

FUNCTION_NAME.export, FUNCTION_NAME.exportXlsx, FUNCTION_NAME.exportCsv

FUNCTION_NAME.export 将导出由以下指定的函数的结果 FUNCTION_NAME 为 .xlsx 文件。它将运行函数、将结果发送到服务器、生成文件并将其下载到用户的计算机。每个函数都有其自己的此操作实例。

直方图 FUNCTION_NAME.export 操作可以作为事件的触发器添加，来源为 导出于 下拉菜单，位于 函数 标签页。

默认情况下，文件将被命名为 FUNCTION_NAME.xlsx。要更改此设置，请导航到 事件 选项卡并选择 FUNCTION_NAME.export。然后，您可以添加一个 return 语句来配置文件名。例如， return "january_data" or return {fileName: "january_data"} 将下载一个名为 january_data.xlsx。有效的文件名不能为空，且只能包含字母、数字、下划线或空格。如果 return 语句中的文件名无效，将使用函数的名称作为文件名。

您可以从 FUNCTION_NAME.exportXlsx or FUNCTION_NAME.exportCsv 操作中选择 操作 下拉菜单，位于 事件 选项卡。然后，您可以添加一个 return 语句，将文件名更改为有效的文件名。

要使函数导出正常工作，函数必须返回一个对象，其中 每一个 属性表示列名，且每个属性值都是长度相等的数组，表示该列中每个单元格的值。这意味着，如果您正在处理查询结果，必须从查询中删除 ._results 属性；该属性由 Slate 添加，用于提供有关查询是否成功运行的信息，但它会阻止从函数导出。

变量操作

变量操作作用于特定变量。它们使应用程序构建者能够在特定事件触发时修改变量的值。

VARIABLE_NAME.set

此操作将设置由以下指定的变量 VARIABLE_NAME 为操作传递的任何值（即以下面板中 JavaScript 代码的返回值 操作 面板）。变量的旧值/当前值仍可作为 {{VARIABLE_NAME}}使用，使您能够使用先前的值来确定要设置的新值。每个变量都有其自己的此操作实例。
