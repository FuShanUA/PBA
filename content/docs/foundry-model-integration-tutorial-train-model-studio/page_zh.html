2a. 教程：在 Model Studio 中训练模型

在开始本教程的这一部分之前，您应该已经完成了 建模项目设置。

在本教程的这一部分中，我们将使用 Model Studio。我们将介绍以下步骤：

  1. 创建 Model Studio
  2. 配置 Model Studio 训练作业
  3. 监控训练作业
  4. 查看模型并将其提交到建模目标

2a.1 创建 Model Studio

导航到 Foundry 中的 Model Studio 应用程序。Model Studio 是一款无代码模型开发工具。

操作： 在您于本教程上一步中创建的 code 文件夹中，选择 + New > Model studio。您的 Model Studio 应根据您正在训练的模型来命名。在本例中，将该 Model Studio 命名为 median_house_price_model_studio。选择 Save 以创建并打开该 Model Studio。

2a.2 配置 Model Studio 训练作业

创建 Model Studio 后，系统将显示可供选择的训练器类型选项。在本教程中，我们将预测房价中位数，这是一个回归问题。

操作： 选择 回归 训练器。我们需要为 Model Studio 输出的模型提供一个名称和存储位置，因此请将模型命名为 regression_model ，并将输出位置设置为之前创建的 models 文件夹。设置完所有选项后，选择 “下一步” 以继续。

数据集映射

Model Studio 要求用户将数据集映射到由训练器预定义的输入。由于我们只有一个训练数据集，我们将把它映射到 “训练数据集” 输入。Model Studio 将自动进行训练-测试拆分，分离出 20% 的数据用于验证和测试。

操作： 在 “训练数据集” 卡片中，选择 “选择数据集” ，然后在对话框中选择 housing_features_and_labels 数据集。

可选： 选择数据集后，您可以使用 “预览” 按钮在页面底部打开预览面板来预览您的数据集，或者展开 “筛选器” 区域来定义要应用于数据集的筛选条件。

选择数据集后，我们需要告诉训练器某些列的含义。在本例中，我们想要告诉训练器 median_house_value 列是目标列。

操作： 在 “目标列”右侧的下拉菜单中，选择 median_house_value 列。

正确配置数据集后，选择 下一步 以继续。

参数配置

Model Studio 训练器提供了一组配置参数，用户可以根据需要更改这些参数，以提升模型性能。 详细了解回归训练器的参数。

操作： 在本教程中，我们要在速度与预测准确性之间找到平衡。为此，我们将设置以下参数：

  • 评估指标： 将其设置为 root_mean_squared_error。
  • 训练预设： 将其设置为 good_quality，这将提供高级集成技术，同时保持较快的训练速度。
  • 训练和推理限制 > 训练时间限制： 将其设置为 300 秒。
  • 预测列名称： 将其设置为 prediction。

将所有其他参数保持默认值。

正确配置参数后，选择 下一步 以继续。

资源配置

为了向 Model Studio 提供充足的资源，我们需要在默认值的基础上增加其资源。

操作： 将 vCPU 值设置为 2 ，并将 内存 值设置为 8 ，以便为作业提供 2 个 vCPU 和 8GB 内存。

正确配置资源后，选择 开始训练运行，这将打开一个对话框，要求您输入配置名称和变更日志。对于名称，请输入 Initial ，并将变更日志留空。然后，选择 开始训练运行 以启动构建。

2a.3 监控训练作业

启动作业后,您将被重定向到 Model Studio 主页。会有一个运行显示在 最近的训练运行列表中。

操作: 选择 查看构建 以导航到正在运行的作业并监控进度。

2a.4 查看模型并将其提交到建模目标

作业完成后,该运行的 状态 列中将显示一个绿色对勾。从这里,您可以查看生成的模型。

操作: 选择 最近的训练运行 表格中的第一行,然后选择侧边栏中显示在运行日期下方的模型名称,以查看生成的模型版本。查看模型版本后,选择 + 图标(提交到建模目标),位于左侧边栏的 建模目标 部分,以将该模型提交到您在 本教程第一步中创建的建模目标。系统会要求您提供提交名称和提交所有者。此元数据用于在建模目标中唯一地追踪该模型。为模型命名 regression_model 并将自己标记为提交所有者。
