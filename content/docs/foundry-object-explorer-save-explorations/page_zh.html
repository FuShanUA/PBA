保存探索

您可以将您在对象资源管理器中的工作保存并共享为一个 探索。保存的探索可让您在保留已应用筛选器和已配置布局的同时，重新访问同一组搜索参数。

保存探索

要保存探索，请选择屏幕右上角的蓝色 保存 按钮。系统还会提示您填写一些要保存的元数据信息，例如探索的标题。

探索可以保存为 私有 或 公开。

  • 如果您选择 私有，则探索将保存到您主文件夹中的“探索”文件夹内，且默认情况下仅您本人可以访问。
  • 如果您选择 公开，系统将提示您选择保存探索的位置。此后，任何有权访问该位置的用户都可以访问该探索。

您的注册配置可能会阻止在主文件夹中保存文件。在这种情况下，保存私有探索的选项也将被禁用。

共享您的探索并不会共享对底层对象的访问权限，因此除了访问已保存的探索本身之外，任何查看者还需要拥有适用于该数据的相应角色。

访问已保存的探索

已保存的探索将显示在您的 搜索结果 中，前提是您使用 对象资源管理器主页上的全局搜索栏。

您还可以通过顶部导航栏上的 探索 下拉菜单访问已保存的探索。该下拉菜单还内置了文本搜索功能和常用筛选选项，可进一步缩小所显示的探索范围。
