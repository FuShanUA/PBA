连接数据

从 Foundry 中获取价值的第一步是将其连接到您组织的数据源。Foundry 的数据连接工具支持各种标准企业数据源，包括基于云的对象存储、文件系统、数据库和数据仓库。

您可以使用不同的 Foundry 应用程序以多种方式连接数据，具体取决于您需要访问的数据类型。

数据连接

连接数据源以运行批处理、流式、媒体和 CDC 同步，并使用虚拟表。

直方图 数据连接 框架旨在通过数据集管理的一系列离散版本来随时间管理数据 事务。该框架支持跨时间的数据版本完整血缘，让您了解哪些同步任务生成了给定数据集的哪些版本。它还支持仅同步所需的数据，适用于每次同步无法进行完整数据加载的情况。

数据连接中的细粒度安全机制支持跨不同团队的联邦式数据同步管理。同步集合，甚至单个数据同步，可以仅对特定团队可见或可编辑（通过基于角色或分类的访问控制来定义）。了解更多关于 保护数据基础的信息.

您可以独立于实际的同步定义来管理同步元数据。这样可以对新配置进行完整分支管理，新的同步在分支中进行沙盒测试，之后才会影响任何下游转换作业。

HyperAuto

为了超越简单的数据同步解决方案， Palantir HyperAuto 实现了对软件定义数据集成（SDDI）的支持。这套工具集不仅允许组织连接到常见的 ERP 和 CRM 系统，还能以前所未有的速度以编程方式生成数据管道，对数据集进行清洗、规范化和协调，形成统一的数据资产。然后，该数据资产可以输入到 本体论 中，将数据转化为运营价值。

外部转换

使用 REST API 执行定时同步以及向外部系统导出数据。

如果您想连接外部数据源以创建同步并导出数据，我们建议使用 Code Repositories 编写 外部 Python 转换 （使用 REST API）。您还可以向转换添加数据集输入和媒体集输出。
