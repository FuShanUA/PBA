基本示例

本页面探讨了在 Preparations 界面中清理和准备数据的基本转换示例。

移除前导和尾部空白字符

如果某些值带有前导/尾随空格，它们将被计入 需要去除空格 类别（在统计区域中显示）。

点击旁边的粉色灯泡 需要去除空格，然后选择 裁剪空白字符 以去除该列中值的前导和尾随空格。

将空字符串设置为 null

如果某些值是空字符串，它们将被计入 空值 类别（在统计区域中显示）。

点击旁边的粉色灯泡 空值，然后选择 设置为 null 以将该列中的所有空字符串值设置为 null.

一次性规范化多个字符串列

  1. 选择您想要规范化的字符串列（如果未选择任何列，则默认为所有字符串列）。

  2. 从左侧面板中选择 规范化字符串 操作，并选择您想要应用的操作。

将值规范化为大写

左侧的统计面板将显示该列中有多少值是大写、小写或混合大小写。

要将值规范化为大写，请选择 更改大小写 操作并点击 大写转换 （您也可以根据需要使用 转小写 or 标题大小写 ）。

将货币字符串解析为数值列

如果数值中包含多余的非数字字符（例如， $1,234.56），该列的类型通常会被检测为 string。但是，为了对其进行数值分析，该列应为数值类型。

检查统计区域以确保值显示为 数值.

如果某些值显示为非字母、大写等类别，您必须先清理它们才能将其解析为数字。点击相关类别（例如 non-alpha）以查看这些值并开始清理。

值 更改类型 按钮，从下拉菜单中选择 Integer（用于整数）或 Double（用于带小数的数字）。

将表示无数据的值（如 N/A）设为 null

通常，列中最终会包含表示无可用数据的值（例如 N/A、Other、None、Unknown 等）。通常，这些值应被 null 以正确指示该单元格中没有可用数据。

  1. 在直方图中选择一个或多个值。

    • 如果您没有看到这些值，请尝试使用 筛选... box.

  2. 值 新值 操作，输入 /NULL，然后点击 保存您的更改。.

请确保在应用更改之前选择一个或多个值，否则整个列都将被设置为 null.

将邮政编码规范化为五位数字

邮政编码列有时可能是五位数字（12345）和九位数字（12345-6789）值的混合。通常，邮政编码应规范化为单一格式，以便进行分组和其他准备工作流程。

使用以下方法将邮政编码列规范化为五位数字 提取 操作。点击 提取 操作，选择 索引子字符串 来自 类型 下拉菜单，然后使用起始索引 1 和结束索引 5.

将所有列重命名为蛇形命名法

蛇形命名法（lowercase_with_underscores）是许多部署中常用的列命名标准。

值 规范化列名 操作。如果该操作不可见，请确保未选择任何列。选择 标准，然后点击 保存您的更改。.

所有列将立即被重命名为蛇形命名法，即列名中的特殊字符将被替换为小写字母和下划线格式。

重命名多个列

直方图 列 视图是重命名多个列的最简单方法。切换到 列 视图，点击 列 （位于屏幕顶部）。

对于任何需要重命名的列，点击列名并根据需要进行编辑。列名将变为绿色，表示更改已暂存但尚未应用。

修复所有列名后，点击 保存您的更改。 按钮，该按钮位于右侧 变更日志 的顶部，以保存所有列名更改。

删除空值列

有时，某些列仅包含 null 值。您可以通过删除整列来清理数据集。

检查统计面板以验证该列是否完全由空值组成；统计信息应显示为 100% 为 Null.

然后，点击 删除列 按钮以删除该列。

删除包含空值的行

有时，某些行在特定列中的 null 值无关紧要，可以将其删除。

选择该列，并检查统计面板的 Null 部分，以查看有多少行在该列中具有 null 值。

接下来，点击统计面板中的 Null ，然后点击 聚焦 按钮，以仅聚焦于具有 null 值的行。请确认这些行确实无关紧要且可以删除。

要删除这些行，请点击 删除行 按钮。

捕获原始数据的行顺序

在初始视图中，使用 添加新列 操作并使用以下表达式：

Copied!
1
monotonically_increasing_id()

这将添加一列数字，这些数字保证根据行顺序递增，但可能既不连续也不确定。

每次计算时该列的值都可能发生变化。这可能导致意外行为，例如从准备中保存的数据集在多次构建时与行关联的数字不同，或者行号列的直方图与表数据不一致。

添加行号（仅适用于小型数据集）

在初始视图中，使用 添加新列 操作并使用以下表达式：

Copied!
1
row_number() over (order by monotonically_increasing_id())

此行号表达式的计算成本可能非常高，在处理大型数据集时可能会显著影响准备工作的性能。

在变更日志中间插入更改

在初始视图中，选择要在其上方插入更改的变更。然后，通过点击该变更或在变更下拉菜单中选择 预览数据 来进入预览模式。

对准备进行更改。这些更改将显示在正在预览的变更上方，但在未来变更的下方。

通过点击 取消 退出预览模式，该选项位于预览警告栏中。
