解析 JSON 字符串

适用于:Batch、Faster、Streaming

根据给定的 schema 定义解析 JSON 字符串,忽略 schema 中未定义的任何字段。

表达式类别: 数据准备、常用、字符串、结构体

声明的参数

  • JSON: 要使用 schema 解析的 JSON。
    Expression<String>
  • 架构： 解析 JSON 字符串时使用的架构定义。
    Type<Array<AnyType> | Map<String, String> | Struct>
  • 可选 输出模式： 'simple' 输出模式会将解析失败的字段视为 null。'with errors' 输出模式将返回一个可解析的结构体，其中解析时发现的所有错误都位于 'error' 字段中，而有效解析的 JSON 则位于 'ok' 字段中。
    Enum<Simple, With errors>

输出类型： Array<AnyType> | Map<String, String> | Struct

参数值：

  • JSON： json
  • 架构： Struct<airline, 机场<id, 英里>>

 "airport": {
  "id": "JFK",
  "miles": 2000
 }
}		{

 airport: {
 id: JFK,
 miles: 2000,
},
}
