开始使用

本教程面向新的 Workshop 构建者，将引导您完成一个简单 Workshop 模块的配置。下面涵盖的概念包括创建新模块、配置对象表格（Object Table）、筛选列表（Filter List）和对象视图（Object View）等小部件，以及通过操作（Action）支撑的按钮组（Button Group）小部件启用回写。如需本材料的引导式版本，请参加 构建您的第一个应用程序课程 ↗ （位于 Palantir Learning 门户）。

在这个示例场景中，我们的目标是构建一个“航班警报收件箱”，用于显示潜在的航班延误和取消信息，并为用户提供选项，以便轻松理解这些警报并对其采取行动。我们的目标用户是一位需要实时跟踪这些警报、确定下一个需要响应的警报并快速解决警报的航空公司主管。

本教程仅作为示例说明。由于 Foundry 本体论是根据您的需求和数据定制的，您可能无法访问与本教程所述相同的本体论资源来完成本教程。

第一部分：初始设置

  1. 要创建新模块，请打开 Projects & Files （项目与文件），可在左侧工作区导航面板中找到，然后找到您想要的项目或文件夹。进入后，选择 New > Workshop module （右上角）以在当前项目或文件夹中创建新模块。新模块将继承其所在项目或文件夹的权限。
  2. 模块资源名称将显示在左上角；默认情况下，名称格式为“New module (2022-04-08 15:16:23)”。我们可以选择此默认名称，输入更具描述性且更易记的资源名称。在本例中，我们将模块命名为“Flight Inbox Tutorial”。完成此更改后，我们的屏幕应如下所示：

第二部分：配置初始视图

为 Flight Alert 对象添加并配置一个对象表格（Object Table）小部件：

  1. 在模块布局的右侧，选择 在 Workshop 中，选择，然后从出现的小部件选择器中选择 指标卡片 小部件。
  2. 在 Object table 1 小部件的配置面板中，使用 对象集 下拉菜单来定义将在此小部件中显示的数据。在下拉菜单中，选择 + New object set variable，并在出现的变量定义弹出窗口中，选择 Starting object set 下拉菜单并选择 [Example Data] Flight Alert。如果您找不到 [Example Data] Flight Alert，请联系 Palantir Support。
  3. 返回 Object table 1 小部件的主配置面板，找到 Column Configuration （列配置）部分并选择 Add all properties。这将为 [Example Data] Flight Alert 对象类型的每个属性在对象表格小部件中填充一列。如果需要，您也可以使用 + Add column 按钮配置特定列。
  4. 自动预览行为 列，根据需要调整列顺序并删除不需要的属性。例如，将 Flight Date 列拖到列表顶部，使其在对象表格中显示为对象标题之后的第一列。
  5. 在配置面板中向下滚动到 Default sort(s) （默认排序）部分，并选择 Flight Date 属性作为排序依据。

第三部分：配置筛选

要配置筛选，首先为 Flight Alert 对象添加并配置一个对象表格（Object Table）小部件：

  1. 添加并配置一个筛选列表（Filter List）小部件。在模块布局的左侧，选择 在 Workshop 中，选择，然后从出现的选择器中选择 Filter list 小部件。

  2. 在 Filter list 1 小部件中，选择 对象集 下拉菜单来定义将显示的数据。同样，选择 + New object set variable，并在出现的变量定义弹出窗口中，选择 Starting object set 下拉菜单，然后 [Example Data] Flight Alert。您必须定义一个新的对象集变量来支撑筛选列表小部件，以使筛选不会限制支撑该小部件的基础对象集。

  3. 返回 Filter list 1 小部件的主配置面板，找到 筛选器配置 部分以使用 + 添加筛选器 按钮为以下属性添加筛选器： 状态, 优先级日 Flight Date.

  4. 在筛选器列表配置中，设置 布局配置 to 垂直 以堆叠列表的形式显示筛选器。如需更紧凑的体验，您也可以选择 药丸，它以交互式药丸的形式显示筛选器，点击后会打开一个弹出窗口进行配置。

  5. 在此配置面板底部，开启开关以 允许用户添加和移除筛选器.

直方图 筛选器列表 1 筛选器输出 是一个对象集筛选器变量。您可以设置默认筛选器，并在需要时启用筛选器值提取，以便在模块的其他位置重复使用所选值。有关更多信息，请参阅相关文档： 对象集筛选器变量.

接下来，修改对象表格（Object Table）小部件，以接受来自筛选器列表（Filter List）小部件的筛选条件输出：

  1. 选择对象表格（Object Table）小部件，在屏幕右侧显示其配置面板。
  2. 在配置面板中，选择 对象集。在出现的变量定义弹出窗口中，选择 筛选器... — 使用变量 选项，并选择 筛选器列表 1 筛选器输出 variable.
  3. 通过在面板中开启某个筛选器来测试筛选功能是否正常（例如，筛选 Alert Type 为 Priority: Medium）。您应该会看到筛选器已应用到您的对象表格（Object Table）中。

第四部分：为对象视图（Object View）配置可折叠面板

为对象表格（Object Table）小部件中的活动对象添加并配置一个对象视图（Object View）小部件。

  1. 选择屏幕右侧围绕对象标题的部分，并注意 部分工具栏 ，它显示在模块顶部。选择 将 — 的数据集。点击 选项，在对象表格（Object Table）小部件右侧添加一个新部分。

  2. 选择新出现的部分。在右侧的 部分配置面板 中，开启以下选项： 部分标题 和 可折叠。同时，将列宽设置为 绝对 像素大小为 500.

  3. 接下来，选择 + 添加小组件 在此部分内，然后选择 对象视图 小部件。

  4. 在配置面板中，打开 要显示的对象 选项，并选择 Object Table 1 Active Object 变量，该变量是对象表格（Object Table）小部件的输出。

  5. 在对象视图（Object View）的 显示与格式设置 设置中，设置 外形规格 to 完整。由于该部分已配置了标题，您可以选择性地开启 隐藏标题 ，以避免同时显示部分标题和小部件标题。如果您选择 面板 外形规格，则请设置 面板行为 to 对象实例 以便面板显示对象表格（Object Table）中的活动对象。

第五部分：使用操作（Actions）启用写回功能

本部分假设 [Example Data] De-escalate Flight Alert 操作类型已经创建。有关如何创建新操作类型的详细信息，请参阅 有关如何在 Workshop 中使用操作（Actions）的文档.

现在，添加并配置一个“解决警报”（Resolve Alert）按钮，允许用户在解决问题时写回 Flight Alert 数据。

  1. 选择新配置的对象视图（Object View）标题上方的部分标题。选择右侧的加号（+），然后选择 按钮组 小部件。
  2. 接下来，配置按钮的标题和样式。在 按钮配置 标题下，选择第一个按钮，其名称为 Button 1 （默认名称）。在按钮配置中，更改 文本 to Resolve Alert，更改 Intent to Success，并更改 Left icon to Small tick.
  3. 然后我们配置当用户选择按钮时要触发的操作类型。在同一个 Item 块中，更改 设置标签页的标签。 设置为 操作，并使用 Select an action... 下拉菜单以选择 [Example Data] De-escalate Flight Alert 操作。在 Parameter Defaults 部分中，我们可以为此操作配置默认输入参数。对于 [Example Data] Flight Alert 参数，选择 Object table 1 Action object 变量，我们也使用该变量来支撑对象视图（Object View）小部件。将 注释 变量保留为无默认值，以便用户可以手动输入他们如何解决此航班警报。
  4. 编辑标签 [Example Data] Flight Alert 参数配置中，选择 隐藏 选项卡中为 Visibility in form 值。这将防止该 Alert 对象出现在用户与 Resolve Alert button.

第六部分：完善您的收件箱并添加标题

现在我们可以配置模块的整体标题。

  1. 选择模块顶部当前未配置的标题。在右侧显示的配置面板中，更改 图标 为一个 Airplane 图标，颜色为 Red 3。在同一个配置面板中，将 标题 输入设置为 Flight Alert Inbox.
  2. 最后，配置各分区的标题。要配置筛选器、对象表格和对象视图分区的标题，请分别选择每个标题。然后，使用右侧的配置面板配置 标题 图表工具 Section 配置（例如“Filters”），并选择要在每个分区标题中显示的 Blueprint 图标（例如“filter”）。您的最终结果应类似于下方以及本教程顶部的收件箱。
