配置私有链接出口

私有链接（也称 VPC 连接）是云提供商提供的服务，可在 Palantir 平台与托管在同一云提供商上的其他系统之间实现直接、安全的连接。了解更多私有链接相关信息。

私有链接出口是指从 Palantir 平台流向您的云 VPC 的流量。目前，用户可为以下服务配置私有链接出口：

  • 连接到托管在 AWS 中的客户服务的AWS 托管 Palantir 平台。
  • 连接到托管在 Azure 中的客户服务的Azure 托管 Palantir 平台。

本页面概述了如何在 Control Panel 中配置和管理私有链接出口，以及如何在 Palantir 平台中使用这些已创建的连接。

如果您想配置用于 Foundry 入口的私有链接（即从您的网络向 Foundry 发出请求），请查阅私有链接文档。

限制

  • 每个注册允许 20 个私有链接。
  • 每个私有链接允许 10 个私有域名。

要提高这些限制，请联系您的 Palantir 管理员。
