配置专用链接出口

专用链接（也称为 VPC 连接）是云提供商提供的服务，可实现 Palantir 平台与托管在同一云提供商上的其他系统之间的直接、安全连接。 了解更多关于专用链接的信息。

选择 出口 指从 Palantir 平台流向您的云 VPC 的流量。目前，用户可为以下服务配置专用链接出口：

  • 托管在 AWS 上的 Palantir 平台 连接到托管在 AWS 中的客户服务。
  • 托管在 Azure 上的 Palantir 平台 连接到托管在 Azure 中的客户服务。

本页面概述了如何在 Control Panel 中配置和管理专用链接出口，以及这些创建的连接如何在 Palantir 平台中使用。

如果您想为进入 Foundry 的流量配置专用链接（即从您的网络发起请求 to Foundry），请查阅 专用链接文档.

限制

  • 每个注册环境最多允许 20 个专用链接。
  • 每个专用链接最多允许 10 个专用域名。

如需提高这些限制，请联系您的 Palantir 管理员。

专用链接出口支持通过专用出口访问 Azure 服务、部署在 Azure 上的用户自有资源,或部署在 Azure 上的第三方 API。

要为您的云提供商配置专用链接，请参阅以下文档：

  • 为 AWS 配置专用链接出口
  • 为 Azure 配置专用链接出口
