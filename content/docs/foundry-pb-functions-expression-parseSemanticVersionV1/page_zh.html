解析语义版本

支持环境：批量、流式

将语义版本字符串解析为逻辑类型。同时支持发布版本（例如 "0.987.0"）和带有预发布元数据的版本（例如 "0.987.0-16-gb3fb285"）。对于不符合预期格式的字符串，返回 null。

表达式类别： 字符串

声明的参数

  • 版本字符串： 语义版本字符串。同时支持发布版本 (major.minor.patch) 和带有预发布元数据的版本 (major.minor.patch-prerelease)。
    Expression<String>

输出类型： 语义版本

示例

示例 1：基本用例

参数值：

  • 版本字符串： version
版本输出
0.987.0-16-gb3fb285{
 major -> 0,
 minor -> 987,
 patch -> 0,
 prerelease -> [ 16-gb3fb285 ],
}
1.0.0-0-g0000000{
 major -> 1,
 minor -> 0,
 patch -> 0,
 prerelease -> [ 0-g0000000 ],
}
2.5.3-42-gabc1234{
 major -> 2,
 minor -> 5,
 patch -> 3,
 prerelease -> [ 42-gabc1234 ],
}
0.987.0-SNAPSHOT{
 major -> 0,
 minor -> 987,
 patch -> 0,
 prerelease -> [ SNAPSHOT ],
}
