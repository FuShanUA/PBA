入门

要开始使用 Workflow Lineage，请使用键盘快捷键 Cmd + i (macOS) 或 Ctrl + i (Windows) 以查看 Workflow Lineage 图，该图展示了支撑您资源的对象、操作和函数。您还可以通过以下应用程序中的 在 Workflow Lineage 中打开 导航选项导航到 Workflow Lineage，该选项通常位于 文件 或 操作.

以下应用程序支持这些功能：

  • Workshop
  • Ontology Manager 中的对象
  • 函数仓库
  • Quiver 仪表板
  • 机械
  • Slate
  • Chatbot Studio
  • Automate
  • 第三方应用程序
  • Developer Console（仅限键盘快捷键）
  • Marketplace（仅限键盘快捷键，位于草稿资源的概览选项卡中。）
  • Notepad（仅限导航选项）
  • Pipeline Builder 中的对象类型（仅限导航选项）

接口

工作流血缘的界面由两个主要组件组成，如下方概念截图所示：

  1. 图形面板： 支撑您工作流的实体及其之间关系的交互式图形视图。
  2. Workshop 面板： 所选 Workshop 应用的交互式视图。

图形面板

当您在图形面板上选择节点时，Workshop 面板中相应的 Workshop 组件会高亮显示。这样可以轻松查看正在使用特定节点的确切位置，并有助于显示特定对象的使用位置。

在图表中选择特定节点后，您可以使用 固定 选项将其固定到左侧边栏，或查看该节点的更多详细信息。

要查看特定节点的所有关联依赖项，请在图表上选择与您要查看的输入类型相对应的图标。

您可以在图表面板右上角的图例中查看各节点类型的图标。对象类型节点使用本体论中指定的图标表示。

在下面的示例中，我们希望查看依赖于 Outage Alert 对象的九个操作。在该对象上选择相同的内联图标位置，即可显示或隐藏这些依赖项。

通过选择特定节点，然后打开屏幕左侧的所选内容详细信息面板来查看该节点的详细信息。显示的详细信息因所选节点的类型而异。以下列出了可为每种资源找到的示例详细信息：

  • 对象： 属性列表、这些属性在整个工作流程中的使用位置（参见下方链接的属性来源说明）、关联、支撑数据源等。
  • 对象关联： 对象、函数、操作、Workshop 应用程序等对资源的使用情况。
  • 函数： 输入、输出、依赖项、代码仓库和其他相关的元数据。
  • 操作： API、RID、输入数据、本体论编辑和提交标准。
  • AIP Logic 函数： 依赖项、自动化以及有关创建详细信息的元数据。
  • 语言模型： 模型描述以及有关模型创建者和上下文窗口的元数据。
  • Workshop 应用： 有关创建以及操作、函数和对象依赖项的元数据。

支持多个本体论

工作流谱系图会显示来自所有相关本体论的资源，让您能够可视化跨本体论的关系。

如果对象、接口或操作节点属于其他本体论，该节点将显示为灰色，并且节点右上角会出现一个警告图标。

当您选择的本体论与这些节点自身所属的本体论不同时，操作类型节点和对象节点的功能将受到限制。例如，您只能对当前所选本体论内由函数支撑的操作执行批量更新。

如果存在多个本体论，图的右上角蓝色立方体旁也会出现一个警告图标。虽然您一次只能选择一个本体论，但您可以通过选择该立方体图标来查看图中存在的本体论并在它们之间切换。

更多详细信息

适用于 函数，当您选择节点时，您可以查看代码。这包括您的函数读取的对象以及逻辑说明。您还可以 批量升级 Workshop 应用中使用的函数。

对于 操作，您可以查看操作函数代码、操作日志，以及 升级操作。您还可以 批量更新操作的提交条件 和 批量删除操作和对象。

对于 对象，您可以预览对象数据。您还可以 批量删除操作和对象.

默认情况下，表示对象关联以及作为操作输入的对象的连线不会显示在图表上。要查看这些关系，请选择对象节点。您可以使用 Cmd + A （在 macOS 上）和 Ctrl + A （在 Windows 上）作为选择所有节点的快捷键。

您还可以在“ 关联 ”部分中查看对象关联，该部分位于“ 选择详情” 面板。将鼠标悬停在每个对象关联上，即可显示所有用法的预览。

选择关联即可查看完整详情。如果关联正在编辑中，相应用法旁边将显示一个笔形图标。

这些关联也会作为依赖项显示在下游资源中。

对于 Automations，您可以在 选择详情 侧边栏中查看属性用法和依赖项。在 条件本体论依赖，您可以查看自动化条件所依赖的特定对象属性的明细。将鼠标悬停在数字上即可查看具体的属性。

您还可以切换图表左上角的紫色闪电按钮，以查看触发自动化的操作和函数。

如果您有一个在属性为特定值时触发的自动化，工作流血缘将找到将该属性编辑为该值的操作或函数，并将其关联到该自动化。

Workshop 面板

在 Workshop 面板上，您可以选择不同的组件，并在工作流血缘图上查看高亮显示的相应节点。

在 Workshop 面板的底部， 实体 部分显示应用程序中使用的所有支撑对象和操作。选择特定实体时，您可以查看该实体在整个 Workshop 应用程序中的确切使用位置。

如果您的图上有多个 Workshop 应用程序，可以使用顶部的下拉菜单在不同 Workshop 应用程序视图之间切换。

要重新打开 Workshop 面板，请选择图上的任意 Workshop 应用程序，然后按 I，或双击该节点。

颜色图例选项

Workflow Lineage 提供颜色图例系统，可帮助管理安全性并查看特定应用程序的元数据。以下是颜色图例的一些示例：

常规

  • 节点类型： 显示图中每个节点所代表的资源类型。
  • 自定义颜色： 通过右键点击节点来创建新颜色组、选择现有颜色组，或将颜色从图例拖放到节点上，从而将颜色添加到图例中。

权限

  • 本体论权限： 请查阅 管理安全性 文档。
  • 资源权限： 请查阅 安全管理 文档。

使用情况

  • 使用情况： 根据应用程序在过去四周内在查看模式和编辑模式下的浏览次数，为 Workshop 应用程序应用颜色。
  • 已过期的函数： 查看 操作支撑的函数升级 部分。
  • 应用浏览量: 根据应用在过去四周内在查看和编辑模式下的浏览量,为 Workshop 应用着色。
  • 模型使用情况: 查看 AIP 使用指标 部分。
  • 本体论状态： 根据 Active、 Experimental、 Deprecated、 Example和 Promoted 状态为节点应用颜色。
  • 操作规则： 根据节点是运行函数、创建、修改还是删除对象，或者执行上述操作的任意组合，为节点应用颜色。
  • 自动化过期： 根据自动化节点的过期日期为其应用颜色。
  • 最后修改： 根据节点的最后修改日期为其应用颜色。

组织

  • 文件夹： 根据节点所在的文件夹为节点应用颜色。
  • 项目： 根据节点所在的项目为节点应用颜色。
  • 项目组合： 根据节点所在的项目组合为节点应用颜色。
  • 函数仓库： 根据函数节点所在的函数仓库为函数节点应用颜色。

文本节点

您可以在工作流血缘中添加文本节点，以帮助记录并引起对图中细节的关注。文本节点使用 Markdown 语法 ↗，并且可以像普通节点一样着色。它们不受布局选项的影响，也不会附加到图中的任何特定节点。

  1. 要向图中添加文本节点，请选择 文本 （位于图的左上角）。
  2. 双击文本节点即可编辑并添加 Markdown 文本。
  3. 选择 保存 完成后。

要为文本节点着色，请右键单击并选择 为节点着色。选择一种颜色或添加新颜色。

您还可以使用右下角的三条横线来调整文本节点的大小。如果文本长度超过文本节点的长度，节点将自动变为可滚动。

演示模式

工作流血缘中的演示模式让您能够创建和组织图的可视化快照（即“帧”），从而以无缝的方式展示您的工作流。

您必须先保存图，然后才能使用演示工具。

要创建帧，请调整图以捕获所需的配置。这可以包括节点的排列方式、节点颜色、颜色模式和缩放级别。当您对当前视图满意后，请选择 将状态另存为新帧。

每个创建的帧都会根据您演示中的帧数量获得一个默认名称，例如“帧 (1)”、“帧 (2)”等。如果您希望重命名某个帧，请选择该帧名称旁边的铅笔图标，然后输入您想要的标题。

目前无法直接编辑现有框架。如果需要更新框架，请根据需要调整图，将新状态另存为新框架，并删除旧框架。要删除某个框架，请选择所有框架的下拉列表，将鼠标悬停在要删除的框架上，然后选择红色垃圾桶图标。

请注意，演示模式仅捕获图界面。诸如 Workshop 侧面板以及底部和左侧面板等元素不会包含在保存的框架中。您可以使用快捷键 , 和 . 分别向后和向前切换您的演示框架。

提示：在演示框架中使用文本节点。这样，您便可以使用自定义注释或说明，引导查看者了解工作流的每个步骤。
