环境

Apollo 中的环境（Environment）是部署到同一基础设施中的一组实体（Entity），例如由在单个 Kubernetes 集群中运行的微服务组成的软件平台。代理（Agent）会将实体的当前状态报告回 Hub，并为实体执行计划（Plan）。环境之间彼此互不相交，因此每个实体仅属于一个环境。

Hub 是用于管理其他环境的环境；这些环境被称为该 Hub 的 Spoke 环境（Spoke Environment）。Hub 环境通常自行管理，但这并非严格要求。一个 Hub 环境也可以由另一个不同的 Hub 来管理，从而形成 Hub 与 Spoke 的层级结构。

环境不需要始终由 Hub 管理。在此类环境未被 Hub 主动管理的期间，称其为断开连接状态。例如，运行在车辆上的环境就可能出现这种情况：静止时连接到 Hub 进行升级，而在移动时则会在一段时间内处于断开连接状态。

环境设置

一个 Apollo Hub 可以管理多个 Spoke 环境。Apollo Hub 会存储每个 Spoke 环境的设置，其中包括应存在于该环境中的实体列表、这些实体订阅的发布渠道，以及其他特定于实体或环境的信息(例如有关维护窗口的信息)。

环境配置

每个环境都有自己的顶级配置，称为“环境配置”，可用于为该环境存储额外的任意配置。环境配置可用于描述适用于整个环境的设置，并可被该环境中单个实体的配置引用。
