数据支撑字段

日落

对于 Foundry 上的数据录入或回写工作流，Foundry Forms 已不再是推荐方案。建议改用 Foundry Ontology 构建用户输入工作流，将相关数据结构表示为对象类型，并通过 Actions 配置回写交互。详情请参阅《Forms 概览》文档。 在 Foundry Forms 中，每个表单字段都可以配置一个或多个验证器，以防止格式不正确的输入。以下是一些验证器示例： 文档。

数据支撑字段将表单链接到 Foundry 中已存在的数据。本页讨论 Foundry 表单中可用的七种数据支撑字段。

用户下拉列表

直方图 用户下拉列表 字段允许填写者选择一个 Foundry 用户。该字段显示用户姓名，但记录用户 ID。用户可以配置以下选项：

  • 允许 多选.
  • 如果只有一个可用值，则预填该字段。
  • 设置一个 Placeholder.
  • 在下拉列表下方隐藏已选用户列表。
  • 使用直方图中的 代码编辑器 来设置 onlyUsersInGroupIds: list<string>.

对象下拉列表

直方图 对象下拉列表 字段允许填写者选择给定类型的对象。该字段显示对象的标题，但记录其主键。用户可以配置以下选项：

  • 根据属性值指定筛选条件。要被筛选，属性必须在本体论中配置 低基数 渲染提示。
  • 指定应搜索哪些属性。
  • 允许 多选.
  • 如果只有一个可用值，则预填该字段。
  • 显示悬停对象属性的预览。
  • 隐藏对象类型图标。
  • 设置一个 Placeholder.
  • 使用直方图中的 代码编辑器 来设置 noResultsText: string and displayedProperties: list<string>.

对象属性下拉列表

直方图 对象属性下拉列表 字段允许填写者选择给定对象类型的属性值。用户可以配置以下选项：

  • 根据另一个属性的值指定筛选条件。
  • 允许 多选.
  • 如果只有一个可用值，则预填该字段。
  • 允许创建给定值以外的值。
  • 设置一个 Placeholder.
  • 使用直方图中的 代码编辑器 来设置 noResultsText: string.

数据集值下拉列表

直方图 数据集值下拉列表 字段允许填写者选择给定数据集的列值。用户可以配置以下选项：

  • 根据另一列的值指定筛选条件。
  • 允许 多选.
  • 如果只有一个可用值，则预填该字段。
  • 允许创建给定值以外的值。
  • 设置一个 Placeholder.
  • 使用直方图中的 代码编辑器 来设置 noResultsText: string.

要使用此字段，数据集必须 被索引到 Lime 中.

对象提供程序

直方图 对象提供程序 字段为只读，显示给定类型的已选对象。用户可以配置以下选项：

  • 根据属性值指定筛选条件。
  • 显示摘要视图或所有对象的可折叠列表。
  • 使用直方图中的 代码编辑器 来设置 maxObjects: integer.

对象属性显示

直方图 对象属性显示 字段为只读，显示所选对象的指定属性。用户可以配置以下选项：

  • 指定对象的主键或引用该主键的字段。
  • 隐藏对象类型图标。
  • 在以下情况下自定义消息：
    • 未选择任何对象。
    • 值为空。
    • 请求失败。
    • 对象“缺失”（不存在或填写者没有相应权限）。
  • 指定在以下情况下如何处理：
    • 请求失败。
    • 对象“缺失”。

如果引用启用了多选的字段，对象属性显示将以逗号分隔显示所有对象的属性。

用户属性

直方图 用户属性 字段为只读，显示所选 Foundry 用户的指定属性。用户可以配置以下选项：

  • 指定用户 ID 或引用该 ID 的字段。
  • 指定格式（例如， Last name, first name).
  • 在以下情况下自定义消息：
    • 未选择任何用户。
    • 值为空。
    • 请求失败。
    • 用户“缺失”（不存在或填写者没有相应权限）。
  • 指定在以下情况下如何处理：
    • 请求失败。
    • 用户“缺失”。

如果引用启用了多选的字段，用户属性显示将以逗号分隔显示所有用户的属性。
