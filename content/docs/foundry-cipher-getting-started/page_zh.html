创建 Cipher 通道

创建 Cipher 通道时，系统会首先要求您在创建密钥之前选择一种加密算法。有两种方法可以创建新的 Cipher 通道：

方式一：通过平台文件系统创建 Cipher 通道

导航到您选择的项目，然后通过选择以下选项来创建新的 Cipher 通道 + 新建 > Cipher 通道。选择您想要的算法；我们推荐使用 AES_SIV (AES-256-SIV) 来对加密值执行连接操作。

如果您无法在 Foundry 文件系统中创建 Cipher 通道，请联系您的 Palantir 代表寻求帮助。

方式二：通过 Cipher 应用程序创建 Cipher 通道

导航到面板左侧，在以下位置找到 Cipher 平台应用 > 数据治理，然后按照方式一中的相同说明操作。

如何选择您的加密算法

屏幕上的指南将引导您完成使用所需协议创建 Cipher 通道的过程。以下是一些额外细节，可能会帮助您根据您的用例决定选择哪种配置：

  • 算法： Cipher 目前支持以下算法：
    • 基于文本的：AES_GCM_SIV 概率加密算法、AES_SIV (AES-256-SIV) 确定性加密算法、SHA-256 哈希算法（带 pepper）以及 SHA-512 哈希算法（带 pepper）。
    • 基于图像的： 视觉混淆图像打乱.

哈希与加密之间的关键区别在于 加密的 值在用户拥有适当权限的情况下可以被解密，而 哈希的 值无法通过加密操作进行去混淆或重新识别。如果您的用例需要重新识别，我们建议使用加密。

概率加密与确定性加密之间的关键区别如下：

  • 概率加密： 相同的输入总是会产生不同的输出。
  • 确定性加密： 相同的输入总是会产生相同的输出。
  • 哈希： 始终是确定性的。

视觉混淆图像打乱算法是确定性的且可逆的。

在确定性和概率算法之间进行选择时，需要考虑以下事项：

  • 如果您需要对加密数据执行连接或聚合操作，则需要使用确定性算法。
  • 如果您要加密的数据基数较低或具有众所周知的统计分布，您可能需要选择概率算法，以限制针对加密数据的字典攻击或统计攻击的风险。

如何配置您的密码系统密钥

屏幕上的指南将引导您完成配置密码系统的过程。根据您之前选择的加密算法，您将有不同的密钥格式可供选择，以保护您的敏感数据。

  • 密钥：
    • 加密： 有两种密钥检索方法可用于从您的密钥派生出密钥：
      • 拉伸密钥派生（推荐）：Cipher 服务将通过应用一种传统上可以增强密钥的方法，从您的密钥派生出密钥。您可以通过点击密钥按钮随机生成一个密钥。
      • 单一密钥：此方法不包含派生函数。如果您已经拥有一个设计良好的 AES_SIV 密钥并希望将其直接用作密钥，我们建议使用此方法。该密钥应输入为长度为 64 的 base64 编码字符串。
    • 哈希： 哈希密钥创建：
      • 我们建议您自己在终端中运行命令来创建哈希密钥（至少 14 个字符且随机生成）。
      • 或者，您可以通过点击密钥按钮随机生成一个密钥。
    • 视觉混淆： 图像打乱种子：
      • 提供一个长的随机数，该随机数将用作种子来生成序列，以重新排列和修改图像中的像素。

点击 创建 cipher 通道 将完成 Cipher 通道的创建过程。

操作用户许可证

An 操作用户许可证 （以前称为“前端许可证”）使 Foundry 用户能够加密或解密单个值。使用此许可证执行的所有操作都是完全可审计的。

操作用户许可证的两个可配置权限是：

  • 单个值的加密/哈希： 通过 Foundry 应用程序进行单值加密或哈希。您可以为此操作设置速率限制计数器。
  • 单个值的解密： 通过 Foundry 应用程序进行单值解密。您可以为此操作设置速率限制计数器。此配置有助于允许用户通过诸如 Workshop 和 Object Explorer.

速率限制是一种可选配置，用于指示个人在配置时间内允许执行的单值加密操作次数。如果用户超过限制，他们将被阻止，直到该时间段重置。

绕过检查点

允许许可证绕过 检查点 意味着该许可证可以在无法显示检查点的地方使用，例如 函数 或直接 API 调用。此许可证的使用仍可在单元格级别进行审计并受速率限制。

数据管理员许可证

A 数据管理员许可证 （以前称为“高信任许可证”）使 Foundry 用户能够加密或解密 数据集的整列 使用 Pipeline Builder 和 Contour 等工具。此配置对于受益于点击式工具的用户以及有严格安全要求的用户都很有帮助。了解更多关于 在 Pipeline Builder 中使用 Cipher.

数据管理员许可证的两个可配置权限是：

  • 列级加密/哈希： 通过 Pipeline Builder 和 Contour 等工具对数据集列进行加密或哈希。
  • 列级解密： 通过 Pipeline Builder 和 Contour 等工具对数据集列进行解密。

管理员许可证

An 管理员许可证 （以前称为“Transforms 许可证”）使 Foundry 用户能够在代码仓库中加密或解密数据集的整列，并授予他们对加密密钥的访问权限。

允许在 Transforms 中进行操作实际上授予了用户对加密密钥的访问权限。请确保仅将此许可证的访问权限授予具有较高权限的用户。

管理员许可证的两个可配置权限是：

  • 加密/哈希管理员： 在代码仓库中对数据集列进行加密或哈希，以及加密密钥访问权限。
  • 解密管理员： 在代码仓库中对数据集列进行解密，以及解密密钥访问权限。

操作指南

熟悉上述步骤后，请参阅本教程，它将引导您完成使用 Cipher 应用程序执行加密操作的过程。

本教程使用虚拟的员工数据。本文档中共享的所有信息（包括但不限于图像和随附的数据集）均为虚拟数据。

复现步骤

开始之前，请下载 虚拟员工数据集 和 将其上传到 Foundry.

  1. 创建 Cipher 通道 在您的落地项目中。
  2. 创建数据管理员许可证 并附带加密许可。
  3. 使用 Pipeline Builder 加密敏感列： 创建新管道并选择 + 新建 > 管道 在右上角将员工数据集导入 Pipeline Builder。然后，选择 Cipher encrypt 转换，使用您刚刚创建的数据管理员许可证，并将其应用于 Employee_name 数据集的列。该列现在应该已被加密。加密完成后，您可以添加一个 Object type 管道输出与您的数据集，并使用 Employee_number 作为主键和标题。（了解更多关于 如果希望用户在每次运行预览前手动确认，请开启)

  1. 添加对象输出： 导航至 输出设置 在下方的旋转图标上 Pipeline outputs。选择 Target ontology 和 Output folder and 保存。访问此数据集中的任何对象时，您会注意到之前加密的一组值现在已无法访问且无法查看。下一步将提供有关如何解密这些值的说明。

  1. 创建操作用户许可证： 返回您的 Cipher Channel 并创建一个新的 操作用户许可证 （带有解密许可）。此许可证将允许您对对象执行解密操作。按照与上述相同的操作，您现在应该能够解密该对象的值。
