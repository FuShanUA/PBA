将 Quiver 仪表板添加到 Marketplace 产品

用途 Foundry DevOps 以将您的 Quiver 仪表板包含在 市场产品 中，以便其他用户安装和重用。 了解如何创建 Marketplace 产品。

支持的功能

支持具有以下功能的 Quiver 仪表板：

  • 对象分析卡片，例如筛选对象集、集合运算和关联对象集。
  • 基于对象的可视化（图表），例如条形图、折线图和热力网格。只要底层的转换表受支持，Vega 绘图也可以被打包。
  • 时间序列图表和绘图，包括事件和分组绘图。
  • 表格，包括大多数透视表，以及带有分组、连接和筛选等转换的转换表。
  • 基本可视化，包括数值卡片、字符串卡片、文本卡片和日期/时间卡片均受支持。

如何打包仪表板

  1. 在仪表板设置窗格的右侧，选择 启用 Marketplace 模板化 option.
  2. 选择 运行验证 按钮，以识别潜在的 Marketplace 模板化问题（如有）。
  3. 如果验证器未显示任何错误，则仪表板的 发布 or 重新发布 按钮还将保存一个可用于 Marketplace 的仪表板版本。
  4. 在新的或现有的 Marketplace 产品.

Linter 错误

Linter 最多可能指示三类主要错误：

  • 不支持的卡片：该卡片目前不支持 Marketplace 模板化。
  • 不支持的配置：该卡片受支持，但其配置不受支持（例如下方透视表示例中的情况）。请查看提供的错误消息以了解更多信息。
  • 意外错误：在大多数情况下，解决上述两类问题即可消除所有意外错误。如果意外错误仍然存在，请联系 Palantir Support。

验证过程会考虑分析中所有卡片和转换的底层逻辑和依赖关系，而不仅仅是仪表板上直接可见的内容。如果某个与 Marketplace 不兼容的卡片存在仪表板上使用的依赖项，验证将失败。请查看任何被标记卡片的完整依赖链，以识别并解决兼容性问题。

您可以无需对每个仪表板单独进行 lint 检查，而是为整个分析启用 Marketplace lint，以便在工作时自动运行验证。启用分析范围的 lint 后， 保存 按钮旁会出现一个 Marketplace 验证指示器，显示当前验证状态以及发现的错误和警告数量。选择该指示器可查看验证详情。

在监听器设置向导的 全局设置 面板中，选择 启用 Marketplace lint 选项，为分析中的所有仪表板启用 Marketplace 模板化，并启用分析范围的 linter。您仍然可以在单个仪表板的设置中禁用该仪表板的模板化。

Marketplace 安装所需的输入

如果验证成功， 查看输入 选项将显示在页眉中。选择它将显示仪表板打包到 Marketplace 时所需的对象类型、对象实例、函数和关联类型的列表。对于对象类型输入，将鼠标悬停在 属性 每个输入右侧的文本上，可查看需要映射的属性类型列表。

从已安装的仪表板创建分析

虽然底层的 Quiver 分析不会随仪表板一起打包，但您可以通过选择 从仪表板创建分析.

从已安装的仪表板创建新的 Quiver 分析。创建的分析将包含此仪表板的副本、仪表板中所有可见的卡片及其上游依赖项。

创建的分析及其仪表板将与已安装的仪表板断开连接。对分析所做的修改不会更新已安装的仪表板，对已安装的仪表板所做的更改也不会自动合并到分析中。

功能使用注意事项

该功能的能力仍在积极开发中。请注意以下重要的使用注意事项。

不支持的卡片和配置

某些从底层数据派生其配置的卡片在打包为 Marketplace 产品时支持有限。有关更多详细信息，请参阅下方的透视表和数据集部分。

时间序列

大多数 Foundry 时间序列功能在 Marketplace 产品中受支持。但是， 时间序列度量 目前在 Marketplace 中不受支持。

为确保与 Marketplace 兼容，您的仪表板必须：

  • 不在时间序列功能和转换中使用度量功能。
  • 不在转换表或对象集视图中添加度量列。这些列可以从转换表显示设置中移除。

如果 linter 检测到使用了任何度量，linter 将抛出不支持的配置错误，并详细说明有问题的卡片和/或度量。

作为使用度量功能的替代方案，您可以直接从其 传感器对象导入序列，这是一种受支持的方法。

透视表

直方图 透视表卡片 可用，但在下游存在转换表时存在限制，会影响列重命名和行操作。请确保您的卡片：

  • 不包含任何列属性，因为这些列将基于底层数据。
  • 为输入透视表卡片的任何聚合配置标签，以确保列名稳定且唯一。

此外，如果透视表下游存在 Selected Object Set 卡片，其选定的数据将在打包前被清除。

数据集

使用 DataFrame 数据类型的卡片可以打包，但存在限制。列名在打包和安装过程中保持不变，因此不会更新以反映所安装的对象类型。如果仪表板安装时的对象类型与打包时的不同，仪表板中的数据集卡片（及其下游卡片）可能无法加载。具体而言，属性类型 API 名称或支撑数据集列名必须与原始对象类型中的名称匹配，具体取决于 Rename column names to API names 已启用。
