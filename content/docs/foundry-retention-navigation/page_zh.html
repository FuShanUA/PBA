访问保留策略应用程序

保留策略应用程序在每个 空间 中均可用，前提是您的组织已在 Administration 中的 Application Access 或 Data Governance 中为您的组织启用该应用程序 the Palantir platform。要访问该应用程序，请导航到 控制面板，然后选择 保留策略.

主页

保留策略主页列出了应用于所选空间的推荐策略、自定义策略和旧版策略。

使用右侧的筛选栏按名称筛选策略。

选择 > 图标以查看策略详情。

推荐策略视图

查看特定推荐策略的详情时，您将看到该策略中选定使用的数据集和事务列表，如下图所示：

直方图 要将两个数据集进行联合操作，请在工作区中选择第一个数据集节点，然后点击 部分列出了该策略中包含的数据集，随后是用于确定将被删除的事务的事务选择器列表。在示例中，该策略选择了空间中的所有数据集；对于每个数据集，该策略将删除所有已中止的事务。

空间管理员无法编辑推荐策略。如果您需要禁用某个推荐策略，请联系 Palantir Support。

自定义策略视图

与推荐策略类似，您将看到该策略中选定使用的数据集和事务列表，如下图所示：

与推荐策略不同，自定义策略可以通过点击 编辑 按钮，然后点击 创建变更审批请求 按钮（在进行更改后）来进行编辑。

策略的添加、更改或删除可能需要审批请求，而不是直接保存。如果是这样，在为审批请求提供标题和描述后，您将被引导至 审批 应用程序。如果您的权限允许，该请求可能会自动执行（无需任何其他审批）；或者根据您的实例和 空间 的配置情况，可能需要其他用户进行进一步审批。如果您希望阻止审批请求自动执行，请提交支持工单。

旧版策略视图

某些 Foundry 实例包含一组以 YAML 格式表示的旧版策略。这些策略已被视为弃用。

只有当您拥有旧版策略所在 Edit 仓库的权限时，才能编辑该策略。
