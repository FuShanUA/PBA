编辑结构体属性类型

  1. 在 Ontology Manager 中，打开左侧边栏中的 对象类型 选项卡，然后选择一个现有的对象类型。
  2. 在对象类型详情页面中，打开左侧边栏中的 属性 选项卡，然后从 属性 表中选择相关的结构体属性类型。
  3. 在 属性编辑器 面板中，滚动至 结构体字段 部分，然后选择您要编辑的结构体字段。所做的编辑数量将显示在 Ontology Manager 界面的右上角。
  1. 在 编辑结构体字段 对话框中进行必要的编辑，然后选择 确认。

请注意，更改结构体字段的 API 名称将导致生成新的结构体字段 RID。这将覆盖现有索引，类似于更改属性类型的属性 ID 时的行为。任何引用已更新的结构体字段的应用程序也需要相应进行更新。
