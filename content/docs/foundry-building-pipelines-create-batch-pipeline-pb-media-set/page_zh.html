使用 Pipeline Builder 创建媒体集批处理管道

在本教程中，您将使用 Pipeline Builder 创建一个包含媒体集的标准批处理管道，以从 PDF 中提取文本。

本示例使用 Palantir 发布的公开文档的 PDF 文件。

在本教程结束时，您将拥有一个如下所示的管道：

该管道将生成一个包含所提取 PDF 文本的新对象输出，可用于进一步探索。

第 1 部分：初始设置

首先，创建一个新管道。

  1. 登录 Foundry 后，访问 如果希望用户在每次运行预览前手动确认，请开启 （位于左侧导航栏）。如果 Pipeline Builder 不在应用程序列表中，请选择 “查看全部” 并找到 如果希望用户在每次运行预览前手动确认，请开启 图表工具 构建和监控管道 区域的字段中添加命令。

  2. 接下来，在 Pipeline Builder 主页面的右上角，选择 新建管道添加小部件 批处理管道。在 选择批处理计算, 更快 默认处于选中状态。在本示例中，请选择 标准.

    并非所有 Foundry 环境都提供创建流式管道的功能。如果您的用例需要此功能，请联系 Palantir Support 了解更多信息。

  3. 选择保存管道的位置。您不能将管道保存在个人文件夹中。

  4. 选择 创建管道.

第 2 部分：添加媒体集

现在，您可以向管道工作流中添加数据集。在本教程中，您将使用 Palantir 公开文档的 PDF 文件。

  1. 在 Pipeline Builder 页面上，选择 添加 Foundry 数据 （位于主页上）。



    您也可以选择 添加数据 操作（位于顶部面板上）。



    或者，您可以从计算机中拖放文件以用作媒体集。

  2. 如果您选择了 添加数据 or 添加 Foundry 数据，您将可以选择所需的媒体集。



  3. 选择所有媒体集后，请选择 添加数据.

  4. 导入媒体集后，您将能够看到带有缩略图预览的媒体集。



第 3 部分：媒体集转换

添加原始媒体集后，您可以执行一些基本转换。在此工作流中，您将从这些 PDF 文件中提取文本。

从 PDF 中提取文本

您可以使用 媒体引用直接转换媒体或从媒体中提取信息。在本示例中，您将从 Media set of Annual Letters 媒体集中提取文本。

  1. 从左侧面板中选择 Media set of Annual Letters 节点。

  2. 选择 转换.



  3. 搜索并选择 从 PDF 中提取文本 转换（从下拉菜单中选择）以打开面板。



  4. 根据您的需求选择提取方法，并填写其余参数。

  • Raw text：计算机生成的 PDF
  • OCR: Photocopies
  • Layout aware：文本和边界框



  1. 选择 保存您的更改。 以将转换添加到您的管道中。

  2. 将鼠标悬停在提取的文本上时，您的输出应如下所示：



    您现在可以对提取的文本列运行可用的字符串转换。

  3. 选择 关闭 （位于右上角）以返回您的管道图。



（可选）语义搜索工作流

如果需要，您可以继续使用 语义搜索工作流 处理您提取的文本。

第 4 部分：添加输出

现在您已完成从 PDF 中提取文本，并可能运行了额外的字符串转换，您可以添加一个输出。在本教程中，您将添加一个对象输出。

  1. 在监听器设置向导的 Transforms 在您完成转换的节点上，选择 添加输出.



  2. 选择 新建对象类型.



  3. 为您的对象类型命名，并通过选择 请选择一个本体论.



  4. 选择 编辑 来设置本体论，并编辑任何列映射。请确保为主键选择一个有效的列。



第 5 部分：构建管道

  1. 要构建您的管道，请确保选择 保存，然后选择 Deploy > Deploy pipeline.



  2. 您应该会看到 Initializing deployment 图表工具 Deploy Pipeline 侧边栏选项。



  3. 选择 查看部署历史 以跟踪您的部署进度。您将被引导至管道中的 History 标签页，您可以在其中查看部署的状态和历史记录：





（可选）第 6 部分：本体论之外

部署完成且对象初始化后，您应该能够直接对对象输出执行操作。选择 创建 Workshop 模块 以使用您的管道输出生成一个 Workshop 模块。

通过这最后一步，您已生成了管道输出和一个 Workshop 模块。

FAQ

我可以在从媒体中提取数据之前先对其进行转换吗？

是的，您可以在从媒体中提取数据之前先对其进行转换，这适用于许多提取操作，包括提取文本和使用大语言模型（LLM）。例如，假设有一个媒体集，其中包含需要在执行基于 OCR 的文本提取之前顺时针旋转 90 度的横向图像。您可以添加一个表达式来旋转图像，然后添加一个表达式来使用 OCR 提取文本。

为了安全地将管道结果写入数据集输出，您必须从输出 schema 中移除媒体引用列，因为转换后的媒体引用不是有效的列输出。

为此，请使用输出对话框移除该列。
