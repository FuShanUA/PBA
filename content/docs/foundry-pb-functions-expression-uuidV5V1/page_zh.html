UUID V5

适用于：批处理、流式处理

使用 SHA-1 哈希算法（RFC 4122），根据命名空间 UUID 和名称字符串生成确定性的 UUID v5。相同的命名空间和名称将始终生成相同的 UUID。如果命名空间不是有效的 UUID，则返回 null。

表达式类别： 字符串

已声明的参数

  • 名称： 要与命名空间一起进行哈希运算以生成确定性 UUID 的名称字符串。
    Expression<String>
  • 命名空间 UUID： 用作命名空间的有效 UUID 字符串。
    Expression<String>

输出类型： String

示例 1：基本情况

描述： 根据命名空间 UUID 和名称字符串生成确定性的 UUID v5。

参数值：

  • 名称： name
  • 命名空间 UUID： namespace
