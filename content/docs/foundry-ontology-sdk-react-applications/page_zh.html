OSDK 文档

OSDK 与语言无关。除了为 TypeScript 提供 NPM（Node Package Manager）库之外，我们还支持适用于 Python 的 Pip 和 Conda、适用于 Java 的 Maven，以及适用于任何其他语言的 OpenAPI 规范。您可以通过以下链接查看其他 OSDK 和 Developer Console 文档：

  • 本体论 SDK 概述

  • 引导创建新的 TypeScript 后端应用程序
  • 引导创建新的 Python 应用程序

OSDK React 库

使用以下库来构建基于 OSDK 的自定义 React 界面：

  • @osdk/react: 提供类型化的 hooks、共享缓存、操作、函数以及自定义的数据驱动界面。
  • @osdk/react-components: 提供预构建的、可感知本体论的界面元素。该库基于 @osdk/react.
