对等配置文件

Beta

对等配置文件正处于 Beta 开发阶段，您的租户中可能无法使用该功能。在活跃开发期间，功能可能会发生变化。如有关于启用对等配置文件的问题，请联系 Palantir 支持团队。

对等配置文件定义了数据如何通过 对等连接 在 Foundry 租户之间共享，并可作为一个可重用的模板：您只需定义一次对等配置，Foundry 便会将该配置一致地同时应用到多个连接。

使用对等配置文件来简化跨对等连接的授权数据共享

对等配置文件简化了授权数据共享的配置和管理，具体通过 本体论 和 文件 对等互联，跨多个 对等连接 在 Foundry 注册网络中进行，尤其是当多个注册需要相同的对等互联配置时。

虽然您可以逐个配置每个对等连接，但建议您使用对等配置文件来定义您的对等配置 一次 并将其应用于注册网格中所有需要的地方，例如连接到多个边缘注册的中心枢纽。

此外，对等配置文件可以简化跨多个对等连接的数据共享，使您能够：

  • 自动创建和配置对等连接： 使用对等配置文件自动创建对等连接、共享本体论中的数据以及配置文件对等。
  • 使您的连接网格面向未来： 加入网格的新注册会自动收到正确的配置，无需任何手动设置步骤。
  • 强制实施一致的配置： 使用同一配置文件的每个注册都会获得相同的数据共享设置，从而降低不匹配或出错的风险。
  • 通过 Marketplace 分发对等配置文件： 配置文件可以发布到 Marketplace，从而可通过熟悉的自助服务工作流轻松地将其安装到目标注册上。

关键概念

Mesh

网格是由相互连接的 Apollo 环境组成的安全网络，可跨多个对等连接自动启用数据共享，这些对等连接由对等配置文件定义。

在创建对等配置文件之前，请联系 Palantir 支持团队为您创建一个网格，其中包含您计划通过对等配置文件连接的所有环境。

配置文件对

您将为在 Peer Manager 中配置的每个对等配置文件创建一个配置文件对，对等连接的每一侧各有一个配置文件。这两个配置文件会自动互为镜像。

例如，考虑一个设置，其中包含一个 中心 和多个 分支 注册，其中：

  • 中心（Hub）是核心或主要注册。
  • 分支（Spokes）是连接到中心的注册。

如果中心配置文件被配置为 导出 某种对象类型，则相应的分支配置文件将自动设置为 导入 同一对象类型。创建对等配置文件时，您 只需 配置该配置文件对的一侧，因为 Peer Manager 会为您生成对应的配置文件。

远程策略

安装配置文件时，您可以选择它适用于哪些远程注册。可用选项包括：

  • 全部： 应用于所有可用的远程注册。
  • 特定注册： 应用于单个指定的注册。
  • 网格： 应用于由 Palantir 支持团队创建的网格内的所有注册。
  • 网格节点标签： 应用于网格中具有特定标签的注册。此选项对于定位较大网络的子集非常有用。

对等节点配置文件配置

使用单个对等节点配置文件捆绑对等连接的配置，以便共享本体论资源和文件。

对等连接

对等配置文件可以自动创建和管理对等连接，包括：

  • 连接安全性： 定义允许哪些分类标记和安全标签跨连接流动。数据必须满足这些要求才能共享。请查看 连接安全性文档 以了解更多信息。
  • 允许的数据类型： 共享本体论资源和文件，并指定其方向（导出、导入或双向）。

本体论对等连接

本体论对等连接 同步 对象类型 和 关联类型 各注册之间。在对等配置文件中，您可以指定：

  • 要共享哪些对象类型。
  • 每种对象类型的流动方向（从中心导出、导入到分支，或双向流动）。
  • 要包含哪些关联类型。

这可以实现跨注册环境的对象同步，包括实时操作对等同步，使用户在一个注册环境中所做的编辑能够流向其他注册环境。

文件对等同步

文件对等同步 可同步 Gotham 文件，例如 Gaia 地图（同步在注册环境之间进行）。在对等配置文件中，您可以指定：

  • 要包含哪些文件类型。
  • 每种文件类型的对等方向。
  • 用户应看到的用于发起文件对等的对等标签。

未包含在配置文件中的文件类型不受影响。

如何创建和使用对等配置文件

步骤 1：创建对等配置文件对

  1. 打开 Peer Manager 并导航至 对等配置文件 标签页。
  2. 选择 创建对等配置文件对。
  3. 选择 更改 在 设置位置 部分，并选择一个 项目 以保存对等配置文件。
  4. 为 Hub 配置文件和 Spoke 配置文件输入名称，在 为该对命名 部分。术语 Hub 和 Spoke 是您的对等连接每一侧的占位符。

选择 切换视角 以在配置对等配置文件时，在 hub 和 spoke 视角之间切换。Peer Manager 会自动将一侧的更改镜像到另一侧。

  1. （可选）在……的顶部启用自动创建对等连接 创建和设置 部分。
  2. 设置 对等连接安全性 ，方法是选择相关的 分类标记 和 其他标记。
  3. 要为本体论资源选择治理策略，请在 本体论 部分中设置其共享方向。
  4. 要为文件选择治理策略，请在 文件 部分中设置其共享方向。
  5. 将所有对象类型和关联类型添加到对等方，在 本体论对等互连 部分，并配置其共享方向。

接下来，请按照以下说明，在 文件对等互连 部分中为所选文件类型设置对等互连配置：

  1. 选择 添加 并选择相关文件类型，然后再选择 添加 [N] 种文件类型.

  1. 从 文件类型 列表中选择一种文件类型，以在屏幕右侧显示该类型的对等配置抽屉。
  2. 选择您所需的 导出选择 配置，以对等该类型的所有文件，或允许用户通过应用对等标签来选择要对等哪些文件。

  1. （可选）如需创建对等标签，请选择 “添加 > 新建对等标签” （位于 “对等标签” 部分），以打开 “新建对等标签” 模态框。
  2. 请提供面向用户的 名称 和 描述 （用于对等标记），然后输入唯一的 ID。
  3. 选择 创建 以关闭模态框并将标签重新添加到 对等标签 部分。
  4. （可选） 筛选文件 以仅通过对等连接发送在指定时间窗口内已更新的文件。
  5. 选择 保存。

现在您已为对等配置文件配置好文件对等，请选择 创建对等配置文件，Peer Manager 将创建两个对等配置文件草稿：对等连接两端各一个。

步骤 2：发布到 Marketplace

查看 Marketplace 和 DevOps 文档，然后再继续操作，以便详细了解如何在您的 Foundry 注册实例上通过 Marketplace 店面创建、发布和安装产品。

您选择 创建对等配置文件后，Peer Manager 会加载 后续步骤 ，以便将您配对中的每个配置文件发布到 Marketplace，并使其可供在中心与分支注册实例上安装。Peer Manager 提供核对清单复选框，供您跟踪进度。

选择 DevOps ↗ 以将每个配置文件作为预配置的 产品草稿在 DevOps 中打开。

第 3 步：在目标注册项上安装

使用 Marketplace 将已发布的配置文件安装 到每个目标注册项上。在安装过程中，请选择：

  • 本地 空间 （位于注册上）。
  • 远程策略，用于确定此配置文件应连接到哪些远程注册。

安装完成后，该配置文件将自动创建或配置相应的对等连接，并根据您的对等连接设置开始共享数据。

了解有关 Marketplace 中安装的更多信息。

安装后，您将无法编辑对等配置文件。请卸载该对等配置文件，进行并保存更改，然后将其重新安装到目标注册上。

步骤 4：监控和管理您的对等配置文件

在每个目标注册上安装对等配置文件后，您可以在 已安装 部分（位于 对等配置文件 页面）中选择它，以查看其：

  • 连接状态，其中显示每个对等连接的运行状况，并在连接不正常时显示故障排除信息，例如未找到网络路径、安全设置不匹配，或者提示远程端尚未安装其对应的配置文件。
  • 本体论映射进度，用于量化每个连接上成功映射的本体论资源数量。

常见问题

安装对等配置文件时会发生什么？

网格内的对等连接将按照配置文件中定义的配置自动创建。如果对等连接已存在，则会将配置文件中的配置应用于该现有连接。

对等配置文件是否会处理后续加入网格的新注册？

是的，这取决于所安装的对等配置文件使用的远程策略。例如，如果对等配置文件使用 Mesh 远程策略，则对等配置文件将应用于任何当前的 以及 属于指定网格的未来对等连接。

如果对等连接的远程端尚未安装其对等配置文件，会怎样？

连接将显示一个状态，表明远程系统尚未安装匹配的配置。一旦远程端安装了相应的中心或分支配置文件，连接将变为健康状态。
