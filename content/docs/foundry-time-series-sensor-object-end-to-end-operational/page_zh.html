在 Workshop 和 Quiver 中使用传感器对象类型时间序列数据

要开始使用传感器对象类型时间序列数据，请打开 Flight Sensor Data 模块。你可以使用平台的 Quicksearch 功能找到该模块。在你使用传感器对象类型时间序列数据配置自己的 Workshop 模块时，此示例模块将作为你的参考。

在本指南结束时，我们的模块将使你能够按出发时间和机场筛选航班。然后， Object Table 部件 将显示航班列表，你可以选择航班以查看关联的传感器对象时间序列数据。

使用 Flight Sensor 对象集

创建一个 新建 Quiver 分析 ，并使用 Flight Sensor 对象类型集，方法是选择 对象 （从顶部菜单栏中）并搜索 Flight Sensor 对象类型。选择 添加对象集 以将对象集表格添加到画布上。

为航班 ID 添加两个字符串参数

  1. 从屏幕左侧，选择 (x) 以打开 参数 configuration.
  2. 选择 + 以添加一个参数，然后选择 字符串 （从下拉菜单中）。该字符串参数将表示航班 ID，您将检索具有该 Flight Sensor 的对象 flight_id property.
  3. 将字符串参数重命名为 "Flight Id"，以便于跟踪。
  4. 对第二个航班 ID 重复步骤 1-3，并将其标记为 "Flight Id 2"。

为传感器名称添加一个字符串参数

  1. 导航到屏幕左侧。
  2. 选择 + 以添加一个参数，然后选择 字符串 （从下拉菜单中）。该字符串参数将表示传感器名称，您将筛选 Flight Sensor 与从 Workshop 模块传入的传感器名称匹配的对象。
  3. 将字符串参数重命名为 "Sensor name"，以便于跟踪。
