transforms.api.FoundryDataSidecarFileSystem

class transforms.api.FoundryDataSidecarFileSystem(param, read_only=False, read_mode='current')

用于在轻量级单节点转换中读取和写入原始数据集文件的文件系统。

返回 FoundryDataSidecarFile 用于读取和写入数据集中文件的对象。

ls(glob=None, regex='.*', show_hidden=False)

从数据集的根目录开始，递归遍历所有目录，并列出与给定模式匹配的所有文件。

  • 参数：
    • glob (str ↗ , 可选) – 一种 Unix 文件匹配模式。还支持 globstar。
    • regex (str ↗ , 可选) – 用于匹配文件名的正则表达式模式。
    • show_hidden (bool ↗ , 可选) – 包含隐藏文件，即以 ‘.’ 或 ‘_’ 为前缀的文件。
  • 生成： FileStatus – 逻辑路径、文件大小和修改时间戳。

open(path, mode='r', **kwargs)

以给定模式打开 FoundryFS 文件。

应在 with 语句中使用，尤其是在写入文件时。

  • 参数：
    • path (str ↗) – 文件在数据集中的逻辑路径。
    • mode (str ↗) – 文件打开模式，默认为读取。
    • **kwargs – 其余关键字参数将传递给 io.open() ↗。
  • 返回： 附加到流的 Python 类文件对象。
  • 返回类型： File
