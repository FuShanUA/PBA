实现接口

接口定义完成后，任何符合接口定义的对象类型都可以实现该接口。这意味着对象类型必须具有满足接口所需属性的属性、满足所有必需链接类型约束的链接，以及满足接口上定义的所有必需操作类型约束的操作类型。

使用对象类型实现接口表示该对象类型是本体论中该接口的一个具体实例。此声明可为对象类型提供额外的功能，即：

  • 对象集服务针对该接口的搜索将返回实现该对象类型的匹配对象。
  • 实现该对象类型的对象既可以在被指定为具体对象类型时使用其本地 API 名称进行交互，也可以在被指定为接口类型时使用属性和链接的接口 API 名称进行交互。

简而言之，实现接口允许应用程序使用者通过接口定义与任何及所有实现对象进行交互。这样，应用程序代码便可以使用接口作为 API 层来编写，而无需应用程序单独支持每个实现对象类型。此外，通过将接口用作应用程序 API 层，只需让新的对象类型实现应用程序接口即可将其添加到应用程序中，而无需修改代码来显式支持新的对象类型。

如何在 Ontology Manager 中实现接口

按照以下步骤使用对象类型实现接口。

1. 选择您的接口和对象类型

首先，在 Ontology Manager 中导航到该对象类型并打开 接口 标签页。选择 + 实现新接口 （位于页面右上角）。

在出现的对话框中，选择要实现的接口。

或者，导航到接口概览页面并选择 + 新建 菜单中选择 实现 区域的字段中添加命令。

然后，选择要实现该接口的对象类型。

2. 映射本地属性

要实现接口，对象类型必须声明现有对象属性到所需接口属性的映射。如果某个接口属性被标记为 可选，则可以跳过映射。

3. 映射链接类型约束

如果接口上声明了任何必需的 链接类型约束 ，则必须在对象类型上选择满足每个必需链接类型约束的链接类型。您还可以选择为任何非必需的链接类型约束提供链接映射。您可以选择现有的链接类型，也可以创建新的链接类型来满足每个约束。

4. 映射操作类型约束

如果接口上声明了任何必需的 操作类型约束 ，则必须在对象类型上选择满足每个必需操作类型约束的操作类型。您还可以选择为任何非必需的操作类型约束提供操作映射。

创建接口实现后，从对象类型的 接口 选项卡配置参数映射。在将更改保存到本体论之前，您必须将任何必需的参数约束映射到具体操作类型上兼容的必需参数。

5. 保存更改

选择 保存 以将更改应用到您的本体论。

如何在 Pipeline Builder 中实现接口

按照以下步骤在 对象类型输出 上实现接口（在 Pipeline Builder 中）。

1. 打开输出类型配置

选择您想要实现接口的对象类型输出，然后选择 编辑 选项。

2. 选择要实现的接口

选择 实现接口.

然后，选择要实现的接口并选择 实现并转到映射.

3. 映射本地属性

要实现接口，对象类型必须包含该接口的共享属性 or 声明现有对象属性到接口共享属性的映射。同时存在于接口和对象类型上的共享属性将被自动映射。对象类型上不存在的任何共享属性将需要您手动输入映射以满足接口定义。

4. 查看已实现的接口

您可以在输出类型配置面板中查看此对象类型实现的接口。

Pipeline Builder 目前不支持在实现接口时进行关联类型约束或操作类型约束映射。如果您的接口包含必需的关联类型约束或必需的操作类型约束，则必须通过 Ontology Manager 实现该接口。
