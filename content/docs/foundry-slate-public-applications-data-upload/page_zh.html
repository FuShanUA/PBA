为公开应用上传数据

启用数据上传

要通过公开应用上传数据，需要通过查询提供两个安全上传数据源：

  1. 用于生成安全通道和令牌的数据源。它可以是以下之一：
    • 一个名为以下名称的 SERVICE API 数据源 secure-upload
    • 一个名为以下名称的 HTTP JSON 数据源 secure-upload-raw-oauth
  2. 用于使用生成的安全令牌上传 JSON blob 的数据源。它最常见的名称是 secure-upload-raw.

您可以通过创建一个公开应用并新建一个查询来检查它们的可用性。如果安全上传数据源不可用，请联系 Palantir Support。

公开应用可以配置为允许用户向 Foundry 上传数据。上传数据的用户无需拥有 Foundry 的访问权限。但是，只有具有相应资源权限的 Foundry 用户才能访问已上传的数据。

要在您的公开应用中设置数据上传，请按照以下说明操作：

1. 创建一个空数据集

在您选择的 Project 或文件夹中创建一个新的数据集资源。

2. 创建通道

在您的公开 Slate 应用中，基于以下任一数据源创建一个新查询 secure-upload or secure-upload-raw-oauth 数据源。通过勾选位于以下选项旁边的下拉框中的复选框，将查询设置为仅手动运行 测试.

为您的通道选择一个唯一的 ID，例如 slate-app-name-data-upload。该 channelId 不得包含空格。请求正文需要您之前创建的空数据集的 RID。您可以从数据集的 URL 中获取数据集 RID，例如 ri.foundry.main.dataset.abcd1234-1234-5678-9000-1234abcd1234.

对象浏览器 可用 服务中，选择 Channel Service，然后选择 Put channel 来自 端点 来创建一个临时的实体级别维护窗口。

在监听器设置向导的 channelId 字段中，输入您的通道的唯一 ID。

3. 创建令牌

创建通道后，您需要创建一个令牌。提交安全上传查询以及向数据集上传数据都需要此令牌。您需要指定一个过期日期。最长过期时间取决于您所在注册组织的的安全上传配置。基于以下数据源创建一个新查询 secure-upload or secure-upload-raw-oauth 数据源。将查询设置为仅手动运行。

使用以下方式创建令牌 secure-upload

从可用服务中，选择 Token Service，然后选择 创建令牌 来自 端点 来创建一个临时的实体级别维护窗口。

4. 创建用于数据上传的查询

要允许用户提交查询，您还需要再创建一个查询：

  1. 选择 secure-upload-raw 作为数据源。
  2. 打开以下选项附近的下拉菜单 测试 并选择您希望数据何时提交（点击按钮时或满足其他条件时，与常规查询一样）。请求正文定义了要捕获并上传到之前创建的数据集中的字段。即使在初始提交之后，您也可以编辑这些字段。在修改之前提交的条目在新增字段下将不显示任何值。

停止数据上传

要停止向数据集上传新条目，你需要同时 取消发布应用程序 并删除在最后一次查询中用作身份验证标头的令牌。

虽然取消发布会对未经过身份验证的用户隐藏应用程序，但未经过身份验证的用户仍可以调用公开的 secure-upload 数据源。删除令牌对于维护应用程序安全非常重要。

请将生成的令牌存储在安全的位置，因为没有恢复选项，而且你需要令牌的值才能删除它。要删除令牌，请按照以下步骤操作：

  1. 在 Slate 中，创建一个查询，将 secure-upload or secure-upload-raw-oauth 作为源。
  2. 打开以下选项附近的下拉菜单 测试 并勾选 手动 复选框以手动运行此查询。
  3. 配置并运行查询：
    • <OAuthAccessTokenURL> secure-upload:
      1. 选择 Token Service from 可用服务.
      2. 选择 删除令牌 from 端点.
      3. 以字符串形式输入要删除的令牌，例如， 1abcdefgha2bcdef3ghabcdefg.
    • <OAuthAccessTokenURL> secure-upload-raw-oauth:
      1. 使用要删除的令牌，例如， 1abcdefgha2bcdef3ghabcdefg，并在查询编辑器中输入以下 JSON：
