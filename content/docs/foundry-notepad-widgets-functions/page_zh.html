@Function()
public flightAlertCalculateUrgency(flightAlerts: ObjectSet<FlightAlertWorkshopTutorial>):
    FunctionsMap<FlightAlertWorkshopTutorial, string> {
    const map = new FunctionsMap<FlightAlertWorkshopTutorial, string>();
    flightAlerts.all().forEach(flightAlert => {
        const hoursDelayed = flightAlert.timeOfDelayHours
        if (hoursDelayed! > 4) {
            map.set(flightAlert, "High")
        }
        else if (hoursDelayed! > 2) {
            map.set(flightAlert, "Medium")
        }
        else {
            map.set(flightAlert, "Low")
        }
    });
    return map;
}

批量函数生成器对象集限制

或 和 表格行生成器 对象集在模板生成期间受到限制。在模板生成过程中，使用中间对象集执行批量函数，这些中间对象集是限制所提供输入对象集大小的结果。

接受的函数输入和输出

非批量函数所需的输出

非批量函数必须返回以下类型之一，以便在Notepad模板中使用：

  • 布尔
  • 日期
  • 双精度浮点数
  • Float（浮点）
  • 整数
  • 长整数
  • 字符串

批量函数所需的输入和输出

有效的批量函数必须至少有一个参数类型为 ObjectSet<K>，并且必须返回类型为 FunctionsMap<K, V>的值。类型 V 必须是下列接受类型之一：

  • 布尔
  • 日期
  • 双精度浮点数
  • Float（浮点）
  • 整数
  • 长整数
  • 字符串

目前，以集合或列表作为参数的函数不被视为有效的批量函数。

小部件属性

  • 批量/非批量： 允许用户选择配置批量函数还是非批量函数。仅在函数小部件嵌套在生成器部分内时显示。
  • 函数： 要运行的函数。如果上面选择了批量选项，则只有批量函数可用。
  • 函数版本： 要运行的函数版本。
  • 函数输入： 传递给函数的值。可用参数由所选函数定义。
  • 函数结果： 函数执行后生成的输出。结果可以以各种格式解析，例如纯文本或 《Markdown》：. 当前仅支持对非批处理函数的Markdown解析。
