Workflow 血缘中的分支

Workflow 血缘支持全局分支，让您能够先在分支上检查、编辑和验证工作流资源，然后将更改合并到 main。这样，您就可以更轻松地在隔离的分支环境中开发和测试端到端工作流更改，然后再将其推广到生产环境。

有关全局分支概念和工作流程的一般信息，请参阅 全局分支文档。



添加、移除和修改资源

在全局分支上工作时，您可以从多个受支持的分支感知入口点打开 Workflow 血缘，包括：

  • AI FDE 面板,可通过右键单击全局分支标签或选择全局分支上下文来添加。




  • 全局分支底部栏。



  • 全局分支主分支页面。



  • 全局分支提案页面。



符合条件的资源会自动添加到图中,分支侧面板可帮助您查看任何已添加或修改的资源。您还可以使用 Cmd+I (macOS) 或 Ctrl+I (Windows) 从分支上受支持的资源在同一分支上下文中打开 Workflow Lineage。此功能在 Workshop、Ontology Manager、AIP Logic 和 Pipeline Builder 的对象类型输出中均受支持。

跨应用兼容性

通过工作流血缘中的全局分支功能，您可以对函数仓库、操作规则、本体论状态、使用情况以及过时的依赖项使用分支感知的配色模式。



您还可以执行受支持的批量编辑，包括为操作类型或 Workshop 升级函数版本、删除本体论资源以及更新操作类型的提交条件。



此外，您可以搜索并添加在分支上创建的资源，包括对象类型、操作类型、函数和接口。侧面板可帮助您查看已修改的资源，并添加尚未显示在图中的已修改资源。

已知限制

  • 搜索中的对象类型组仅反映属于该 main 分支的对象类型组。
  • 目前不支持在分支上批量升级逻辑。
