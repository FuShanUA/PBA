VS Code 工作区中的全局分支

VS Code 工作区中的全局分支支持 Python 转换 仓库和 TypeScript v1 函数仓库。有关支持全局分支的资源类型完整列表，请查阅 集成文档。

在 VS Code 中工作时，您可以创建和访问全局分支，并对 Python 转换和 TypeScript v1 函数仓库使用其他受支持的工作流。 这些工作流既可用于 VS Code 工作区 （部署在 Palantir 基础设施上），也可用于本地 VS Code（通过 适用于 Visual Studio Code 的 Palantir 扩展）。

全局分支和代码仓库分支

VS Code 中的仓库有两类分支：

  • 一个 代码仓库分支 是您仓库的底层 git 分支。
  • 一个 全局分支 可以包含跨多个 Palantir 应用程序的变更，让您能够在单个分支上开发和测试端到端工作流。全局分支必须基于 main 仓库的分支。

在 Palantir 扩展中，选项卡式分支选择器可让您在同一位置创建和检出代码仓库分支与全局分支。

分支任务栏

当您在 VS Code 工作区中打开受支持的仓库时， 分支任务栏 会显示为编辑器底部的蓝色条，位于 Code 页面上。任务栏会显示您的当前分支，并使其与 VS Code 保持同步。终端、命令面板和编辑器中反映的分支始终与任务栏中显示的分支保持一致。

任务栏仅在 VS Code 工作区中可用。在本地 VS Code 中，请使用 Palantir 扩展查看和切换您的分支。

创建全局分支

您可以通过以下任一入口创建全局分支：

  • 分支任务栏 （仅限 VS Code 工作区）：打开任务栏中的分支选择器并创建新分支。
  • Palantir 扩展 （VS Code 工作区和本地 VS Code）：在侧边栏的 Palantir 面板中打开标签式分支选择器，选择 全局分支 选项卡，并创建新分支。
  • 命令面板 （VS Code 工作区和本地 VS Code）：按 Cmd+Shift+P （macOS）或 Ctrl+Shift+P （Windows/Linux），然后运行 Palantir: Create Global Branch。
  • “分支”页面 在代码工作区中：从代码仓库的 分支 页面创建全局分支。

从上述任一入口进入，都会打开“创建分支”对话框。

检出全局分支

您可以通过以下任一入口检出现有的全局分支：

  • 分支任务栏 （仅限 VS Code 工作区）：打开任务栏中的分支选择器，然后选择一个分支。
  • Palantir 扩展 （VS Code 工作区和本地 VS Code）：在侧边栏的 Palantir 面板中打开带标签页的分支选择器，并从 全局分支 标签页中选择一个分支。
  • 命令面板 （VS Code 工作区和本地 VS Code）：按 Cmd+Shift+P （macOS）或 Ctrl+Shift+P （Windows/Linux），然后运行 Palantir：签出全局分支。

除分支任务栏外，每个入口点都会打开相同的分支选择器，它会将分支分组为多个部分，帮助您快速找到相关分支：

  • main 分支
  • 您的包含此仓库的分支
  • 您的分支
  • 所有其他分支

签出分支时，将适用以下行为：

  • 将仓库添加到分支： 如果仓库尚未在您选择的分支上，系统会提示您在检出完成前先添加该仓库。
  • 未提交的更改： 如果您有未提交的更改，系统会弹出一个对话框，提示您在检出或添加到分支操作继续之前先解决这些更改。这可以防止您的编辑器与当前活动分支失去同步。

在分支上开发转换

您可以在全局分支上开发 Python 转换。该 预览 和 构建 面板针对您当前检出的分支运行。

了解有关开发 Python 转换的更多信息。

在分支上开发函数

对于 TypeScript v1 函数仓库，这些面板也会在您当前活动的全局分支上下文中运行：

  • 实时预览： 针对分支上的资源预览您的函数。
  • 已发布预览： 预览您在分支上发布的函数版本。
  • 资源导入: 导入并修改可供您的函数使用的本体论资源。

您可以通过为函数版本添加标签，将其发布到全局分支上。在您的 VS Code 工作区的 标签 页面中为版本添加标签，或使用 标签版本 Palantir 扩展中的操作。当您处于全局分支时，将基于该分支创建标签。
