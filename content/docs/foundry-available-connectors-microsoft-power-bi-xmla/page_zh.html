Microsoft Power BI® XMLA

以下页面介绍用于数据集成的 Microsoft Power BI® XMLA 连接器。如果您正在寻找有关 Power BI® 连接器以从 Power Query 界面访问 Foundry 资源的信息，请查阅我们的 分析连接文档.

Microsoft Power BI® XMLA 连接器是一种 由 Palantir 提供的驱动程序 （用于 Microsoft Power BI® XMLA）。

要创建新的 Microsoft Power BI® XMLA 源，请按照 Palantir 提供的驱动程序的标准设置流程，然后使用以下部分进行 Microsoft Power BI® XMLA 特定的配置和网络设置。有关完整的属性参考，请参阅 官方 Microsoft Power BI® XMLA 驱动程序文档 ↗.

配置

以下属性为必填项或推荐项。

属性是否必填？描述默认值
AuthScheme ↗推荐连接到 Microsoft Power BI XMLA 时使用的身份验证类型。AzureServicePrincipal
AzureTenant ↗推荐标识用于访问数据的 Microsoft Power BI XMLA 租户。接受租户的域名（例如 contoso.onmicrosoft.com ）或其目录（租户）ID。—
InitiateOAuth ↗推荐网络GETANDREFRESH
OAuthClientId ↗推荐《OAuthClientSecret ↗》—
OAuthClientSecret ↗推荐指定分配给自定义 OAuth 应用程序的客户端密钥。此机密值用于向 OAuth 授权服务器验证应用程序的身份。（仅适用于自定义 OAuth 应用程序。）—
PowerBIEnvironment ↗推荐指定用于 API 请求的 PowerBI 环境。NONE
Workspace ↗推荐指定要连接的 Premium Power BI 工作区，使用以逗号分隔的工作区名称列表。—

OAuth 2.0 身份验证

此连接器支持 OAuth 2.0 身份验证。请按照 Palantir 提供的驱动程序的 OAuth 2.0 指南 来配置和授权连接。
