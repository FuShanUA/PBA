媒体集（非结构化数据）

A 媒体集 是具有共同模式（例如相同格式文件）的媒体文件集合。媒体集专为处理大规模非结构化数据而设计，支持对音频、图像、视频和文档等媒体项进行处理。媒体集提供灵活的存储访问、计算优化以及针对特定模式的转换，以增强媒体工作流和管道。

媒体集工作流示例包括：

  • 使用 Pipeline Builder 从 PDF 中提取文本以实现内容分析
  • 在 Map 应用中使用栅格切片（TIFF、NITF）执行地理空间分析
  • 使用 Pipeline Builder 处理医学影像文件（DICOM 格式）

如需了解有关媒体集以及如何在 Foundry 中处理媒体的更多信息， 请访问 媒体集文档.
