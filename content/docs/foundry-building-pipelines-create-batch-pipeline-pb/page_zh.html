使用 Pipeline Builder 创建数据集批处理管道

在本教程中，您将使用 Pipeline Builder 创建一个简单的管道，其输出为包含航班警报信息的单个数据集。然后，您可以使用 Contour 或 Code Workbook 等工具分析此输出数据集，以回答诸如哪些航线面临最大中断风险等问题。

下面使用的数据集可以在数据集导入步骤中按名称搜索；您可以在您的 Foundry 文件系统中找到它们。

在本教程结束时，您将拥有一个如下所示的管道：

该管道将生成一个新的数据集输出 Flight Alerts Data 您可以在平台中将其用于进一步探索。如需更详细的演练，请查看 关于构建您的第一个管道的深度课程 ↗ （位于 Palantir Learning 门户）。

第 1 部分：初始设置

首先，创建一个新管道。

  1. 登录 Foundry 后，选择 应用程序 （在左侧导航栏中）以搜索并打开 如果希望用户在每次运行预览前手动确认，请开启



  2. 接下来，在 Pipeline Builder 落地页上，选择 新建管道添加小部件 批处理管道。在 选择批处理计算，然后使用 标准.



并非所有 Foundry 环境都提供创建流式管道的功能。如果您的用例需要此功能，请联系 Palantir Support 了解更多信息。

  1. 选择保存管道的位置。您不能将管道保存在个人文件夹中。



  2. 选择 创建管道.

第 2 部分：添加数据集

现在，您可以向管道工作流中添加数据集。请使用虚构或开源数据的示例数据集。

在 Pipeline Builder 页面上，选择 添加数据集 （来自 Foundry）。

或者，您可以从计算机中拖放文件作为数据集。

在此演练示例中，您可以添加 passengers_preprocessed, flight_alerts_raw日 status_mapping_raw 数据集。要添加选定的数据集，请选择该数据集。然后，选择内联的 + 图标，或选择 添加到选择.

选择所有所需数据集后，选择 添加数据集.

第 3 部分：清洗数据

添加原始数据集后，您可以执行一些基本的清洗转换来继续定义您的管道。您将对三个原始数据集进行转换。

数据集 1

第一步是清洗 passengers_preprocessed 数据集。首先设置一个 cast 转换，将 dob 列名更改为 dob_date 同时将值转换为 MM/dd/yy 格式。

Cast 转换

  1. 选择 passengers_preprocessed 节点。

  2. 选择 转换.



  3. 搜索并选择 cast 转换（从下拉菜单中），以打开 cast 配置面板。



  4. 在 来推导每个新列。 字段中，选择 dob；对于 类型中，选择 Date.

  5. 输入 MM/dd/yy 选项卡中为 格式 类型。请务必使用大写的 MM 以确保 cast 转换成功。将输出列名更改为 dob_date.

    您的 cast 面板应如下所示：



  6. 选择 保存您的更改。 以将转换添加到您的管道中。

Title case 转换

现在，您可以格式化 flyer_status 列的值，使其以大写字母开头。

  1. 在转换搜索字段中，搜索并选择 标题大小写 转换以打开 title case 配置面板。

  2. 在监听器设置向导的 来推导每个新列。 字段中，从下拉菜单选择 flyer_status 列。

    您的 title case 面板应如下所示：



  3. 选择 保存您的更改。 以将转换添加到您的管道中。

  4. 在转换配置窗口的左上角，重命名该转换 Passengers_Clean.



  5. 选择 Back to graph （位于屏幕右上角）以返回您的管道图表。



数据集 2

现在，清洗 flight_alerts_raw 数据集。第一步是设置另一个 cast 转换，将 flight-date 列的值转换为 MM/dd/yy 格式。

Cast 转换

  1. 选择 flight_alerts_raw 图中的数据集节点。

  2. 选择 转换.



  3. 搜索并选择 cast 转换，以打开类型转换配置面板。您可以阅读选择框右侧列出的函数定义，以了解有关该函数的更多信息。



  4. 在监听器设置向导的 来推导每个新列。 字段中，从下拉菜单选择 flight_date 列。

  5. 选择 Date 来自 类型 字段下拉菜单。

  6. 输入 MM/dd/yy 选项卡中为 格式 类型。请务必使用大写的 MM 以确保类型转换成功。

    您的 cast 面板应如下所示：



  7. 选择 保存您的更改。 以将转换添加到您的管道中。

清理字符串转换

现在，添加一个 清理字符串 转换，它将移除 category 列值中的空白字符。例如，该转换会将 delay··· 字符串值转换为 delay.

  1. 在下拉菜单中搜索并选择清理字符串转换，以打开清理字符串配置面板。

  2. 在监听器设置向导的 来推导每个新列。 字段中，从下拉菜单选择 category 列（从下拉菜单中选择）。

  3. 勾选所有三个 清理操作 选项的复选框：

    • 将空字符串转换为 null
    • 将多个连续的空白字符合并为单个空格
    • 去除字符串开头和结尾的空白字符

    您的清理字符串面板应如下所示：



  4. 选择 保存您的更改。 以将转换添加到您的管道中。

  5. 在转换配置窗口的左上角，重命名该转换 Flight Alerts - Clean.

  6. 选择 Back to graph （位于右上角）以返回您的管道图。



数据集 3

最后，清理 status_mapping_raw 数据集。

清理字符串转换

您只需对该数据集应用 清理字符串 转换。

  1. 选择 status_mapping_raw 图中的数据集节点。

  2. 选择 转换.



  3. 在监听器设置向导的 搜索转换和列... 字段中，从下拉菜单选择 mapped_value 列（从下拉菜单中选择）。



  4. 在同一字段中，从下拉菜单搜索并选择清理字符串转换。

  5. 勾选所有三个 清理操作 选项的复选框：

  • 将空字符串转换为 null

  • 将多个连续的空白字符合并为单个空格

  • 去除字符串开头和结尾的空白字符

    您的清理字符串面板应如下所示：



  1. 选择 保存您的更改。 以将转换添加到您的管道中。

  2. 在转换配置窗口的左上角，重命名该转换 Status Mapping - Clean.

  3. 选择 Back to graph （位于右上角）以返回您的管道图。

    您可以看到刚刚添加的转换与所应用的数据集之间的连接。



第 4 部分：连接数据集

现在，您可以使用 连接（join）来组合一些已清理的数据集。连接允许您组合至少具有一个匹配列的数据集。您将在管道工作流中添加两个连接。

连接 1

您的第一个连接将组合两个已清理的数据集。

  1. 选择 Flight Alerts - Clean 转换节点。这将是连接的左侧。

  2. 选择 连接.



  3. 从左侧面板中选择 Status Mapping - Clean 节点，将其添加为连接的右侧。

  4. 选择 开始时间 以打开连接配置面板。



  5. 验证 连接类型 设置为 Left join.

  6. 设置 匹配条件 列设置为 status 等于 value.

  7. 选择 显示高级选项 以查看其他配置选项。

  8. 设置 前缀 将右侧 Status Mapping - Clean 数据集的 status.

    您的连接配置面板应如下所示：



  9. 选择 保存您的更改。 以将该连接添加到您的管道中。

  10. 在 预览 窗格（位于配置窗口底部）中查看连接输出表的预览。



  11. 在连接配置窗口的左上角，重命名该连接 Join Status.

  12. 选择 Back to graph （位于右上角）以返回您的管道图。



  13. 为了使图表更易于阅读，请选择 的 图标以自动排列数据集，或手动将两个相连的数据集拖到彼此相邻的位置。



连接 2

对于第二个连接，将您的第一个连接输出表与另一个原始数据集进行组合。

  1. 将 priority_mapping_raw 数据集添加到图中，方法是选择 添加数据集.

  2. 选择 Join Status 节点（您刚刚添加到图中的节点）。这将是连接的左侧。

  3. 选择 连接.

  4. 选择 priority_mapping_raw 数据集节点，将其添加为连接的右侧。

  5. 选择 开始时间 以打开配置面板。



  6. 验证 连接类型 设置为 Left join.

  7. 设置 匹配条件 列设置为 priority 等于 value.

  8. 选择 显示高级选项 以查看其他配置选项。

  9. 设置 前缀 将右侧 priority_mapping_raw 数据集的 priority.

    您的连接配置面板应如下所示：



  10. 选择 保存您的更改。 以将该连接添加到您的管道中。

  11. 在 预览 窗格（位于配置窗口底部）中查看连接输出表的预览。



  12. 在连接配置窗口的左上角，重命名该连接 Join (2).

  13. 选择 Back to graph （位于右上角）以返回您的管道图。

您现在可以看到刚刚添加的连接与所应用的数据集之间的连接关系。

第 5 部分：添加输出

现在您已完成数据的转换和结构化，可以添加输出了。在本教程中，您将添加一个数据集输出。

  1. 在监听器设置向导的 管道输出 在 Pipeline Builder 图形右侧的侧边栏中，为输出命名 Flight Alerts data添加依赖项。然后选择 添加数据集输出.
  2. 关联 Join (2) 通过选择连接节点右侧的白色圆圈并将其连接到 Flight Alerts data dataset.
  3. 选择 使用输入 schema 以使用现有 schema。
  4. 从这里开始，选择要保留的数据列。在本例中，将所有数据保留在一起。



第 6 部分：构建管道

要构建您的管道，请选择 部署 在图形的右上角。然后，选择 保存并部署.

您应该会看到一条小提示，表明部署成功。选择 要在标记和发布函数的过程中查看进度，请选择 在提示框中以打开 构建进度 页面预览同步的数据。

在此页面上，您可以监控构建进度，直到数据集输出准备就绪。

您现在可以通过选择以下方式访问您的数据集 Actions > Open.

通过最后这一步，您生成了管道输出。此输出是一个数据集，可以在 Foundry 的其他应用程序中进一步探索，例如 Contour or 代码仓库（Code Repositories）.
