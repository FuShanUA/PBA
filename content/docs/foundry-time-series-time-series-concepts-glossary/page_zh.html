概念词汇表

以下列表解释了在 Foundry 中创建时间序列时使用的关键概念。我们建议您熟悉这些概念，以便更好地了解如何有效地 设置 和 如何使用时间序列 在您的组织中的相关内容。

时间序列

由一个或多个时间戳和值对组成的数据。每对表示某个时间点上的一个量，因此每组对可随时间测量某个量；每组都需要唯一的标识符。例如，一组机器可能各自带有多个传感器，每个传感器以固定的频率记录该传感器所在机器的值；每台机器的每个传感器都需要有唯一的标识。

时间序列对象类型

一种对象类型（例如， Machine），其中每个对象通过 时间序列属性 (TSP)关联到一个或多个时间戳和值对集合。以对象为中心的 Foundry 应用程序（如 Quiver、Vertex 和 Workshop）支持对 TSP 进行分析。

时间序列对象类型支撑数据集

创建 时间序列对象类型所需的数据集；每行表示该时间序列对象类型的单个对象（例如， Machine 123），并具有以下 schema：

列类型描述
主键String[Required] 每行的主键
序列 IDString[Required] A 序列 ID 每个 TSP 对应的
<column name><column type>[Optional] 每个对象的附加信息
<column name><column type>[Optional] 每个 TSP 的附加配置信息

序列 ID

时间序列对象类型中的外键，用于从 时间序列同步中获取值。通常，序列 ID 在时间序列对象类型支撑数据集中是唯一的，并且与其在时间序列同步中的对应行具有一对多关系。

时间序列属性 (TSP)

提供随时间变化的值的属性（例如温度传感器读数）。时间序列对象类型支撑数据集中的每个序列 ID 列都映射到一个 TSP。

时间序列同步

时间序列同步将时间序列数据（为 TSP 提供值）索引到 Foundry 的时间序列数据库中。同步的每一行表示某个 TSP 在单个时间点的值（例如， Machine 123 在 2023 年 1 月 1 日 12:00:00 的温度为 100*F）。同一序列 ID 的所有值应包含在同一个同步中。这些值通过其序列 ID 获取；因此，单个同步可以包含多个序列 ID 的所有值。该同步应作为目标输出类型创建于 如果希望用户在每次运行预览前手动确认，请开启 中，并恰好包含以下列：

列类型描述
序列 IDString[Required] TSP 所引用的时间戳和值对集合的序列 ID；它们必须与 TSP 的序列 ID 匹配。
时间戳Timestamp, Long[Required] 测量该量的时间。
标题可将排序方式切换为Integer, Float, Double, String[Required] 在测量时该量的值。 String 类型表示 Categorical 时间序列；每个分类时间序列最多可以有 10,000 个唯一变体。

如果分类时间序列超过 10,000 个唯一变体的限制，该序列 ID 将报错，并且不再可在平台中访问。

限定序列 ID

限定序列 ID 具有以下形式： "{"seriesId":"<replace with series ID>","syncRid":"<replace with sync RID containing this series ID>"}"。由多个时间序列同步支撑的时间序列属性的值必须是限定序列 ID，并且必须格式化为不含换行符或空格的 JSON 字符串。 了解有关设置限定序列 ID 的更多信息.

传感器对象类型

具有一个默认 TSP 的时间序列对象类型，该 TSP 关联到其为其记录时间序列数据的对象类型。被关联的对象类型有时被称为 根对象类型.

派生序列

派生序列是通过公式计算得出的时间序列，该公式以时间序列作为输入并将其保存为模板。这些模板在时间序列目录或 Quiver 中编写，可以从时间序列属性中引用，以便在本体论感知应用中使用。

绑定对象类型

可以从中解析给定派生序列的时间序列对象类型。该对象类型在派生序列创建期间指定。

Codex 模板

Codex 模板用于存储模板化的派生序列公式，该公式在派生序列被可视化或在其他计算中使用时于运行时执行。
