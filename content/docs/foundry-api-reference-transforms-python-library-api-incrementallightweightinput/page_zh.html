transforms.api.IncrementalLightweightInput

class transforms.api.IncrementalLightweightInput(alias, rid, branch=None)

在运行时传递给增量 ContainerTransform 对象的输入对象。

其目的是模拟 transforms.api.IncrementalTransformInput API 的一个子集，同时提供对底层 foundry.transforms.Dataset的访问。

属性 alias

此参数所关联的数据集的别名。

arrow(mode='added')

包含数据集完整视图的 PyArrow 表。

  • 参数： mode (str ↗) – 读取模式，取值为 current、 previous或 added。默认为 added。

属性 branch

此参数所关联的数据集的分支。

dataframe(mode='added')

包含数据集完整视图的 pandas DataFrame。

  • 参数： mode (str ↗) – 读取模式，取值为 current、 previous或 added。默认为 added。

属性 end_transaction_rid

输入数据集的结束事务。

  • 类型： str ↗

filesystem(mode='added')

以只读模式访问文件系统。

构造一个 FoundryDataSidecarFileSystem 对象，用于直接访问数据集的文件。

  • 参数： mode (str ↗) – 读取模式，取值为 current、 previous或 added。默认为 added。

pandas(mode='added')

包含数据集完整视图的 pandas DataFrame。

  • 参数： mode (str ↗) – 读取模式，取值为 current、 previous或 added。默认为 added。

path(mode='added')

下载数据集的底层文件并返回其路径。

  • 参数： mode (str ↗) – 读取模式，可选值为 current、 previous或 added。默认值为 added。此参数仅在 @incremental 为 added 且 v2_semantics 为 True时适用。

polars(lazy=False, mode='added')

包含数据集完整视图的 Polars DataFrame 或 LazyFrame。

  • 参数：
    • lazy (bool ↗ ， 可选) – 是否返回 LazyFrame 或 DataFrame。默认值为 False。
    • mode (str ↗) – 读取模式，可选值为 current、 previous或 added。默认值为 added。

属性 rid

此参数所关联的数据集的唯一资源标识符。

属性 start_transaction_rid

输入数据集的起始事务。

  • 类型： str ↗
