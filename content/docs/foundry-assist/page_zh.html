AIP Assist

AIP Assist 是一款由大语言模型 (LLM) 驱动的支持工具，旨在帮助用户在 Palantir 平台上导航、理解和创造价值。用户可以用自然语言向 AIP Assist 提问，并获得针对其问题的实时帮助。

使用 AIP Assist 的优势包括：

  • 用户友好的界面： AIP Assist 由大语言模型 (LLM) 驱动，拥有直观的界面，让用户能够轻松提问，并获得相关、自然且易于理解的回复。
  • 实时协助： AIP Assist 提供实时协助，使用户能够快速解决问题和疑问，从而提高用户的工作效率，并减少对支持团队的依赖。
  • 多语言支持： AIP 可以使用所有常用语言回答问题。
  • 上下文感知： AIP Assist 专为保持对话上下文而设计，能够感知您当前所处的 Foundry 应用程序。
  • Foundry 级别的安全性： AIP Assist 完全遵循 Palantir 的 AI 伦理原则 ↗ ，且不会访问您的数据。
  • 迭代改进： 用户可以对 AIP Assist 回复的质量提供反馈，帮助在开发过程中持续改进该工具。

访问 AIP Assist

AIP Assist 仅在您的平台管理员 已在 Control Panel 中启用 AIP时才可用。

您可以在工作区导航栏底部选择 AIP Assist，或使用键盘快捷键（MacOS 上为 Cmd+Shift+U，Windows 上为 Ctrl+Shift+U）来访问它。AIP Assist 将显示在面板中，如下方截图所示：

从 AIP Assist 获取支持

用户可以在 提问... 输入框中以纯文本形式输入查询。AIP Assist 基于 Palantir 的平台文档进行训练，并使用自然语言处理（NLP）和第三方大语言模型（LLM）来解析用户的查询并提供最相关的回复，同时符合 Palantir 的安全标准。

通过模式和 AIP Chatbots 聚焦您的 AIP Assist 体验

AIP Assist 提供了多种开箱即用的预配置模式，可根据您的工作流为您提供更加量身定制的体验。以下是可用模式的概述：

  • AIP Assist（默认）： 在平台文档、开发者文档和自定义内容源之间进行动态选择。
  • 平台文档助手： 基于平台文档回答问题。
  • 开发者助手： 专注于 Foundry API 和常见的开发者示例。
  • AIP Chatbots： 由用户开发、由 LLM 驱动的交互式助手，配备企业专属信息。请参阅 Assist 中的 AIP Chatbots 以获取更多信息。

添加自定义内容源以增强 AIP Assist

您可以添加自定义内容源并使用它们来改善 AIP Assist 体验。目前有两种方法可以添加可向 AIP Assist 注册的自定义内容源：

  1. （推荐） Notepad 文档
  2. 平台内 自定义文档 （Markdown 文件位于代码仓库中的 documentation 类型仓库内）。

请参阅 向 AIP Assist 注册自定义内容源 以了解更多信息。

在 AIP Assist 中使用自定义源

创建并注册自定义源后，有两种使用它来增强 AIP Assist 体验的选项：

  1. 将其添加到默认的 AIP Assist 知识库。

  2. 创建 AIP 聊天机器人。

将内容源添加到默认的 AIP Assist 知识库后，该内容源将连同在您的注册环境中为 AIP Assist 预加载的更广泛搜索上下文一起被纳入。相比之下，AIP Assist 聊天机器人是交互式的、由 LLM 驱动的助手， 仅 将所提供的自定义内容源用作搜索上下文，使其成为专注于您在 Palantir 平台上工作流的量身定制支持工具。

注意：AIP 功能的可用性可能会发生变化，且可能因客户而异。
