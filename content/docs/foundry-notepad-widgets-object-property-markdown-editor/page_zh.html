对象属性 Markdown 编辑器

该 对象属性 Markdown 编辑器 小组件允许您在 Notepad 文档中显示和编辑 Markdown 格式的对象属性。选择 + 小组件 或在段落字段中按 / 以打开 小组件插入菜单 ，并将 对象属性 Markdown 编辑器 小组件添加到您的文档中。

该小组件支持 CommonMark ↗ 规范，但以下情况除外：

  • 图像
  • HTML
  • 链接引用
  • 嵌套在另一个列表中、但并非该列表直接子级的列表（例如，一个列表中包含引用块，而该引用块中又包含另一个列表）。

小组件属性

  • 对象选择： 要显示其属性的对象。
  • 属性： 定义要显示的对象属性。
  • 允许编辑： 指定用户是否能够编辑该属性。如果禁用此选项，则无论是否配置了行内编辑，用户都将无法进行更改。

编辑

您可以使用该小组件通过相应的 基于操作的行内编辑来编辑属性。配置行内编辑后，从文档中选择该小组件以打开 Markdown 编辑器。输入您的修改内容并在工具栏中保存更改，以更新本体论中的属性。

您还可以使用工具栏查看和编辑原始 Markdown。

为了阻止冲突的更改，当您或其他用户在文档中选中该小部件时，Notepad 会阻止其他用户编辑该小部件。
