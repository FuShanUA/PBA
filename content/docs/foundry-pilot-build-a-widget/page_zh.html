构建自定义小部件

Pilot 可以构建 自定义小部件 以及完整应用程序。自定义小部件是一种嵌入 Workshop 应用程序中的沙盒化前端组件，而非独立托管的应用程序。构建小部件使用与 构建应用程序相同的对话式工作流程，不同之处在本页面中有所说明。要创建新项目，请参阅 入门指南。

开始构建小部件

在 Pilot 欢迎屏幕上，选择 自定义小部件集 而非 OSDK 应用程序，然后描述您想要构建的小部件并选择 创建小部件集。Pilot 会预配一个隔离的容器，并根据您的提示词生成小部件。

与构建应用程序时一样，您可以在聊天面板中与 Pilot 对话。您可以在 行动模式和规划模式之间切换，附加 上下文，并选择 模型。

Pilot 生成的内容

Pilot 会生成一个在 Workshop 应用程序内渲染的小部件。单个项目可以包含多个小部件，Pilot 会将它们作为一个小部件集一起发布。Pilot 通过两种机制将每个小部件与其宿主应用程序连接：

  • 参数： 小部件从 Workshop 接收的类型化输入，例如对象集、字符串或数字。
  • 事件： 微件发回给 Workshop 的输出，用于在用户交互时更新变量。

Pilot 在构建过程中会定义这些参数和事件。有关微件如何与其宿主应用程序通信的背景信息，请参阅 参数和事件。

微件在受限的沙箱中运行。在向 Pilot 发出提示时，请注意以下事项：

  • 微件会适应 Workshop 主题，包括 深色主题。
  • 微件尺寸遵循 自动调整大小 规则。
  • 对浏览器功能和外部网络请求的访问受到限制。要请求更多浏览器功能，请参阅 启用更多 iframe 属性。

预览您的微件

该 预览 标签页会在 Workshop 微件沙箱中渲染您的微件，让您可以查看其嵌入后呈现的确切外观。在编辑器视图中，预览默认使用本地生成的种子数据。要针对真实的本体论数据进行预览，请使用 种子数据 / 生产数据 开关切换到生产数据。

如果您更改了微件的参数或事件，请在微件预览中选择 重新加载微件开发模式 ，以将更改应用于正在运行的预览。

使用本体论

微件通过 OSDK对您的本体论进行读取和写入，并使用在 Workshop 中查看该微件的人员的权限。在 本体论 选项卡中，您可以引用现有实体，或者在允许修改的情况下，让 Pilot 提议新的实体。Pilot 允许更改的内容由您控制，相关设置位于 本体论选项卡。

在构建过程中，模型绝不会访问您的真实数据。即使您针对生产数据进行预览，您的数据对模型仍保持隐藏。详情请参阅 种子数据与实时数据。

后续步骤

  • 部署自定义微件：将您的微件发布到微件注册表，并将其嵌入 Workshop 应用程序中。
  • 构建应用程序：构建独立的托管应用程序。
