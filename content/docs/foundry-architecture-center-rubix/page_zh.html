Rubix 底层平台

AIP、Foundry 和 Apollo 均在一个经过加固、可自动扩缩容且高可用的 Kubernetes 实现中运行，该实现名为 Palantir Rubix ↗。

基于 Palantir 数十年来 构建安全软件的经验，Rubix 的开发目标是扩展开源容器化的核心优势，并提供在世界上最严苛的环境中运行所需的各种功能。这包括具有强制轮换周期的临时计算节点、默认安全的网络、动态且智能的自动扩缩容，以及一系列满足最严格认证标准（包括 FedRAMP High、DOD DISA IL-5/IL-6 和 CMMC）的功能。

Rubix 架构最初是为了托管 Palantir 自身的软件而开发的，但如今已被各种规模的软件公司用于将其产品部署到其自行选择的任何环境中，包括世界上限制最严格、最复杂的环境。

Rubix 设计的核心是一套不可妥协且环环相扣的假设：任务关键型软件必须在设计上确保安全、具备高可用性，并能够快速演进。

安全性

Rubix 旨在防范战术性和高级持续性威胁向量。

每个工作负载都会根据必要要求进行安全隔离，从而使需要提升权限的运维任务能够安全执行，并与在精确管控权限下运行的应用驱动型执行相区分。环境中的每个元素都严格实施加密，并且工作负载之间的每次交互都必须按照不可变配置进行身份验证、授权和记录。

Palantir 构建了 Rubix 的最初版本，旨在通过 Spark 计算运行时开创这种安全且可自动扩缩容的范式。如今，这一范式已扩展至 AIP、Foundry 和 Apollo 中的每一个运行时和服务结构，从管理系统连接、数据集成、模型管理、应用开发、智能体构建，一直到开发者工具链。

高可用性

高可用性与 Rubix 的短暂性机制紧密交织；Rubix 环境中的节点存续时间不得超过 48 小时。这确保了每个服务——无论是面向用户的本体论管理器，还是用于转换数据流的后端服务——都为应对中断而设计，并具备弹性故障转移能力。Rubix 还减少了基础设施团队进行人工干预的需求，因为过时的实例会被自动替换，而驱动这一替换的逻辑中融入了从全球性能表现中汲取的经验。

从安全角度来看，激进的节点轮换确保攻陷单个节点并不足以让攻击者获得对环境的持久访问权限。在运维层面，这种短暂性与一个多维度的节点排空和终止管道协同运作，该管道采用基于策略的节点选择，以平稳的方式避免系统失稳。

Rubix 作为 Palantir 各项服务的基底

无论对基础设施团队、平台团队还是客户团队，Rubix 都能带来效率提升。通过为 Palantir 的核心服务提供安全且一致的基底，它使基础设施团队能够在 AWS、Azure、Google Cloud、Oracle Cloud 或本地部署环境中部署 AIP、Foundry、Apollo 及相关依赖产品——并保持完全一致的运维特性。

对于将新功能和新服务交付到托管基础设施中的 Palantir 团队而言，Rubix 提供了可靠且统一的基底，抽象并屏蔽了不同环境与提供商之间的特有差异。

对于希望安全地托管自定义应用、容器化模型以及其他与 Kubernetes 兼容的工作负载（例如通过 Compute Modules）的客户开发者而言，可以透明地利用 Rubix 的所有核心优势。这包括智能工作负载分发、一系列精密的需求感知算法，以及其他可推动持续成本优化的功能。

Apollo 与“Day 2”运维

Rubix 与……协同工作 Apollo 为“Day 2”基础设施运维提供强大的任务控制。

Apollo 的职责之一是计算和传输 计划 用于给定 Palantir 环境中数百个服务各自的安装、升级和回滚。

为确保零停机升级,Apollo 要求每个软件服务都以专为“蓝/绿”发布策略设计的多节点配置进行部署。与一次性全量发布策略不同,蓝/绿模式首先构建一个并行的绿色环境,并在其与现有蓝色环境并行运行的同时监控其性能。如果绿色环境在指定时间段内成功运行,流量将逐渐从蓝色节点重定向到绿色节点(并且根据强制轮换机制,蓝色节点将被直接销毁)。

如果没有 Rubix 的强约定 API 层，这种零停机架构将无法实现。Apollo 利用该 API 层将复杂的部署意图转换为资源级指令，用于服务创建、状态监控、产品版本管理、配置管理等。

一次构建，随处运行

Rubix 为 Palantir 的“一次编写，随处交付”开发理念奠定了基础。Rubix 在 Kubernetes 核心优势的基础上，进一步增强其安全性、高可用性和可部署性，从而能够快速将软件发布到世界上最关键的环境中。

除了赋能 Palantir 的开发者团队之外，Rubix 现在还能帮助希望将自有端到端解决方案部署到受监管环境中的软件团队（使他们能够通过 Palantir FedStart 实现 FedRAMP 合规）。

Rubix 还使整个政府机构能够通过 Mission Manager 产品安全地加速供应商的入驻与管理。随着 Palantir 的客户和合作伙伴不断推进其最关键的使命，并挑战长期以来主导软件基础设施的过时传统观念，Rubix 将持续演进，以满足他们最迫切的需求。
