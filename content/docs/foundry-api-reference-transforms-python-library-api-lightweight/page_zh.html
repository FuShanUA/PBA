transforms.api.lightweight

transforms.api.lightweight(_maybe_function=None, *, cpu_cores=2, memory_mb=None, memory_gb=None, gpu_type=None, container_image=None, container_tag=None, container_shell_command=None)

自版本 3.85.0 起已弃用：请改用 transforms.api.transform.using()。

将转换变为轻量级转换。

要使用此装饰器， foundry-transforms-lib-python 必须作为依赖项添加。

轻量级转换是一种无需 Spark、在单个节点上运行的转换。对于中小型数据集，轻量级转换速度更快且更具成本效益。轻量级转换还提供了更多用于访问数据集的方法；但是，它们仅支持常规转换 API 的一个子集，包括 pandas、Polars（通过 transform_polars），以及文件系统 API。有关更多信息，请参阅 Python 转换文档 ↗。

要使用 Polars，请将 polars 声明为运行依赖项，并添加到您的 meta.yml。

  • 参数：
    • cpu_cores （float ↗ ， 可选） – 为转换的容器请求的 CPU 核心数。可以是小数。
    • memory_mb （float ↗ ， 可选） – 为容器请求的内存量，以 MB 为单位。
    • memory_gb （float ↗ ， 可选） – 为容器请求的内存量，以 GB 为单位。默认值为 16 GB。
    • gpu_type （str ↗ ， 可选） – 为转换分配的 GPU 类型。
    • container_image （str ↗ , 可选) – 用于转换容器的镜像。
    • container_tag (str ↗ , 可选) – 用于转换容器的镜像标签。
    • container_shell_command (str ↗ , 可选) – 容器启动后要在其中执行的 shell 命令。如果未指定，则会生成一个默认命令，从而执行被装饰的转换。默认值可通过被装饰的转换的 default_container_entrypoint 属性获取。

访问执行上下文

您可以选择向轻量级转换的 compute 函数注入上下文对象，只需添加一个 ctx 参数。当存在时， ctx 是一个 transforms.api.LightweightContext，等同于 transforms.api.TransformContext （用于单节点计算）。它通过 abort_job()、 auth_header以及 is_incremental提供作业控制和元数据。

>>> @transform.using(
...     my_input=Input('/input'),
...     my_output=Output('/output')
... )
... def compute(ctx, my_input, my_output):
...     if not ctx.is_incremental:
...         ctx.abort_job()
...     my_output.write_pandas(my_input.pandas())

详情请参阅 transforms.api.LightweightContext。

注意事项

可以指定 memory_gb 或 memory_mb ，但不能同时指定两者。

轻量级转换不支持 Spark 配置文件。

如果设置了 container_image、 container_tag 或 container_shell_command 中的任意一个，则 container_image 和 container_tag 都必须设置。如果 container_shell_command 未设置，则会使用默认入口点，该入口点将初始化一个 Python 环境并执行转换中指定的用户代码。

指定 container_* 参数的做法被称为自带容器（BYOC）工作流。在这种情况下，主要保证是用户代码仓库中的所有文件都将在 $USER_WORKING_DIR/user_code 运行时在容器内可用，并且 Python 环境也将可用。

该 container_image 必须可从代码仓库的产物支撑仓库中获取。更多详情，请参阅 BYOC 文档 ↗。

一个有效的 container_image的 Dockerfile 示例如下所示：
