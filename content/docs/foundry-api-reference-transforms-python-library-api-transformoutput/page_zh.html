transforms.api.TransformOutput

class transforms.api.TransformOutput(rid, branch, txrid, dfreader, dfwriter, fsbuilder, mode='replace')

在运行时传递给 Transform 对象的输出对象。对于增量转换， IncrementalTransformOutput 扩展 TransformOutput ，使其支持增量读取模式和写入语义。

abort()

中止此输出的所有工作。在调用此方法之前或之后，对来自此输出的写入器所做的任何工作都将被忽略。

property batch_incremental_configuration

将以批处理方式读取的增量输入的配置。

  • 类型： BatchIncrementalConfiguration

property branch

数据集的分支。

  • 类型： str ↗

property column_descriptions

数据集的列描述。

  • 类型： Dict[str, str]

property column_typeclasses

数据集的列类型类。

  • 类型： Dict[str, str]

dataframe()

返回一个 pyspark.sql.DataFrame ↗ ，其中包含数据集的完整视图。

  • 返回： 数据集的 DataFrame。
  • 返回类型： pyspark.sql.DataFrame ↗

property end_transaction_rid

输入数据集的结束事务。

  • 类型： str ↗

filesystem()

构造一个用于写入 FoundryFS 的 FileSystem 对象。

  • 返回： 用于写入 Foundry 的 FileSystem 对象。
  • 返回类型： FileSystem

classmethod from_transform_output(instance, delegate)

将 TransformOutput 实例中的字段设置为委托 TransformOutput 中的值。

pandas()

pandas.DataFrame ↗：一个包含数据集完整视图的 Pandas 数据框。

property path

数据集的 Compass 路径。

  • 类型： str ↗

property rid

数据集的资源标识符。

  • 类型： str ↗

set_mode(mode)

更改数据集的写入模式。

  • 参数： mode (str ↗) – 写入模式，为 replace、modify 或 append 之一。在 modify 模式下，写入的任何内容都会附加到数据集。在 replace 模式下，写入的任何内容都会替换数据集。在 append 模式下，写入的任何内容都会附加到数据集，且不会覆盖现有文件。

写入数据后无法更改写入模式。

历史

  • 在 1.61.0 版本中新增。

属性 start_transaction_rid

输入数据集的起始事务。

  • 类型： str ↗

write_dataframe(df, partition_cols=None, bucket_cols=None, bucket_count=None, sort_by=None, output_format=None, options=None, column_descriptions=None, column_typeclasses=None)

将给定的 DataFrame ↗ 写入数据集。

  • 参数：
    • df (pyspark.sql.DataFrame ↗) – 要写入的 PySpark DataFrame。
    • partition_cols (List [str ↗ ] , 可选) – 写入数据时要使用的列分区。
    • bucket_cols (List [str ↗ ] , 可选) – 用于对数据进行分桶的列。如果指定了 bucket_count ，则必须指定。
    • bucket_count (int ↗ , 可选) – 桶的数量。如果指定了 bucket_cols ，则必须指定。
    • sort_by (List [str ↗ ] , 可选) – 用于对分桶后的数据进行排序的列。
    • output_format (str ↗ , 可选) – 输出文件格式，默认为 parquet.
    • options (dict ↗ , 可选) – 额外选项，将传递给 org.apache.spark.sql.DataFrameWriter#option(String, String).
    • column_descriptions (Dict [str ↗ , str ↗ ] , 可选) – 列名与其字符串描述的映射。此映射会与 DataFrame 的列取交集，且所包含的描述长度不得超过 800 个字符。
    • column_typeclasses (Dict [str ↗ , List *[*Dict [str ↗ , str ↗ ] ] ] , 可选) – 列名与其列类型类的映射。列表中的每个类型类都是一个 Dict[str, str]，其中只有两个键有效； name 和 kind。每个键都映射到用户想要的对应字符串，最多 100 个字符。示例 column_typeclasses 值为 {"my_column": [{"name": "my_typeclass_name", "kind": "my_typeclass_kind"}]}.

write_pandas(pandas_df)

将给定的 pandas.DataFrame ↗ 写入数据集。

  • 参数： pandas_df (pandas.DataFrame ↗) – 要写入的 DataFrame。
