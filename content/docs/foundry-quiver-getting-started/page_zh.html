开始使用

以下教程介绍如何使用 Quiver 分析来自 本体论.

创建 Quiver 分析

要创建新的 Quiver 分析，请展开左侧的 Foundry 侧边栏，然后选择 “查看全部” （位于 Applications 部分）。您可以在 Analytics & Operations 区域的字段中添加命令。

下找到 Quiver。从这里开始，选择 +New Analysis来开始新的分析，然后为新分析选择一个文件夹并选择 保存。您也可以打开现有分析或创建 不同类型的分析.

要练习这些步骤，请学习 learn.palantir.com ↗ 上的 Quiver 数据分析课程.

添加对象数据

创建新分析后，您就可以开始添加一些对象数据。选择 +Add data to analysis 来添加初始数据。您可以随时从 Add data 已应用标签 分析顶部栏.

选择 +Add data to analysis 添加更多数据。这将打开 Quiver 的 搜索栏 来浏览本体论中的对象类型。选择一个对象类型将其添加到您的分析中。添加对象类型后，选择 X （位于右上角）以关闭搜索栏。现在您的分析中应该有一个对象集卡片，其中显示了集合内对象的表格预览，以及右上角所有对象的计数。

在下面的示例中，我们搜索与 "nyc" 相关的对象并添加 NYC Buildings 对象类型。

筛选对象

接下来，使用对象属性通过 筛选对象集 卡片来筛选对象。将鼠标悬停在上一步添加的对象集卡片上，以显示卡片下方的 后续操作菜单 。然后，选择 Filter > Filter object set 来添加新卡片。

在下面的示例中，我们筛选出仅包含 2010 年至 2020 年间建造的、类型为 building or garage.

构建图表

接下来，通过创建条形图来可视化筛选后的对象。将鼠标悬停在筛选对象集卡片上，以显示卡片下方的后续操作菜单。然后，选择 Visualize > Bar chart 来创建条形图。使用右侧的编辑器面板配置条形图。指定 分组依据 配置来定义条形图的类别，然后配置其他设置，例如数据系列指标或分段。您还可以从 显示 标签页。

在下面的示例中，我们创建了一个条形图，显示按 Building Type分组的平均屋顶高度。然后我们按 Year Constructed进行分段。最后，我们设置图表格式，将方向更改为 垂直 ，并将分段显示更改为 突出。在新图表中，我们可以看到，从 2010 年到 2020 年，纽约建筑的平均屋顶高度稳步上升，而车库的平均屋顶高度则缓慢下降。

您现在拥有了一个包含筛选对象和自定义图表的完整分析。

添加时间序列数据

在 Foundry 中， 时间序列 存储为 时间序列属性 （存储在本体论中）。您可以通过选择 时间序列 菜单中选择 Add data 已应用标签 分析顶部栏将时间序列属性添加到您的 Quiver 分析中。这将打开时间序列搜索栏，让您浏览带有时间序列的对象，并将其时间序列属性添加到您的分析中。

在下面的示例中，我们在 Weather stations 对象类型中搜索 "newark"，然后添加 Temperature 时间序列属性（用于 Newark Liberty International 机场）。关闭搜索栏后，此数据被添加到 时间序列图表 中并显示温度图。最后，我们在时间序列图表上点击并拖动以进行时间范围选择，然后选择 Zoom to selection 以导航到最近的时间范围的数据。

派生时间序列

您可以通过应用 时间序列转换，从原始时间序列中派生出新的时间序列。首先，将鼠标悬停在时间序列图表上，以在下方显示后续操作菜单。选择 添加图表 以浏览可能的转换列表。选择一个转换，将新的时间序列图表添加到您的图表中。然后，您可以使用右侧的编辑器面板配置该图表。

在下面的示例中，我们使用 滚动聚合 图表对输入温度时间序列进行转换，以派生出 30 天滚动平均值。

设置时间序列格式

现在，您可以通过在编辑器面板的 显示 选项卡中添加格式配置，在视觉上将派生图表与原始图表区分开来。时间序列图表具有多种显示选项，例如颜色、线宽、渐变底纹和点样式。添加显示配置后，您可以将派生图表移动到其自己的图表中。通过拖动图表的图例项或使用后续操作菜单中的 移动图表 部分，可在图表之间移动图表。

在下面的示例中，我们将滚动平均值的图表线加粗、显示渐变，并将颜色更改为紫色。然后，我们通过将其图例项拖出到分析画布上，将其移动到其自己的图表中。

您现在拥有一个包含已转换和已格式化时间序列的完整时间序列分析。接下来， 查找异常 使用 时间序列搜索 卡片在您的时间序列中查找异常，或者创建一个 仪表板 来分享您的分析。
