Lakehouse Iceberg REST 目录

通过 Google Cloud Storage 连接器将 Foundry 连接到 Google Cloud Lakehouse。Lakehouse 被配置为 Google Cloud Storage 数据源上的 Iceberg 目录。注册的虚拟表使用 Iceberg 格式，并指向该 Lakehouse 目录中的表。

受支持的功能

功能状态
虚拟表🟢 正式可用
手动注册🟢 正式可用
自动注册🟢 正式可用
表输入🟢 正式可用： Iceberg ↗ in 代码仓库, 如果希望用户在每次运行预览前手动确认，请开启
表输出🟢 正式可用： Iceberg ↗ in 代码仓库, 如果希望用户在每次运行预览前手动确认，请开启
增量管道🟢 正式可用： APPEND only
计算下推🔴 不可用

设置

Lakehouse 目录设置是 Google Cloud Storage 连接器配置的一部分。要配置 Lakehouse，请在 Google Cloud Storage 数据源上添加 Catalog 设置，然后选择 Lakehouse 目录.

有关构建自定义主题的示例，请参阅 Google Cloud Storage Lakehouse 目录设置 了解身份验证、网络和数据源配置详情的说明。

注册虚拟表

要从 Lakehouse 注册表，请打开已配置的 Google Cloud Storage 数据源，并使用 格式 设置为 Iceberg。请参阅 Google Cloud Storage 注册说明 了解完整工作流程。
