函数支撑的操作

在操作类型中，规则定义了应用操作时对象应如何变化。许多操作类型可以使用简单规则来定义，这些规则允许您创建、修改和删除对象，或在对象之间创建和删除关联。

但在某些情况下，简单规则不足以描述您想要进行的更改。例如，您可能希望：

  • 修改当前关联在一起的多个对象。例如，您可能希望将某个 Incident 对象的 status 字段设置为 Closed，并将所有关联的 Alert 对象的 status 设置为 Resolved。
  • 基于更复杂的逻辑修改对象的属性。例如，您可能希望根据从多个对象读取数据的业务逻辑计算一个值，然后将该值写入某个对象属性。
  • 创建多种不同类型的对象，并在它们之间建立关联。

为了支持此类用例，可以将操作类型配置为调用一个函数，该函数定义了应如何修改对象的逻辑。这些操作类型通常被称为函数支撑操作。通过使用函数，您可以创建任意复杂程度的操作类型，读取任意数量的对象，并根据需要修改对象。

尽管函数支撑操作类型非常灵活，但您应注意它们同时受到操作类型限制和函数执行限制的约束。
