连接器

直方图 数据连接 应用旨在提供 Foundry 与您的系统之间的连接。本页面概述了可用的连接器。

文件系统和 blob 存储

包括：

  • Amazon S3
  • OneLake 和 Azure Blob 文件系统 (ABFS)
  • 目录（代理级文件系统）
  • FTP/FTPS
  • Google Cloud Storage
  • HDFS
  • 网络文件系统 (NFS)
  • 服务器消息块（SMB）
  • SFTP
  • SharePoint Online

JDBC 数据源
