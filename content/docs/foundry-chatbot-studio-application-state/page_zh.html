应用程序状态

您可以在 AIP Chatbot 上配置多个字符串或对象集应用程序变量，以配置 应用程序状态（之前称为 参数。当带有应用程序变量的 AIP Chatbot 嵌入到 Workshop 应用程序 中的 Workshop 时，将显示变量列表。然后，您可以将每个应用程序变量映射到相应类型的 Workshop 变量 ，以在其他小组件中显示输出。

在 AIP Chatbot Studio 中配置应用程序状态

设置 AIP Chatbot 的应用程序状态时，请配置以下内容：

  • 确定应用程序变量： 确定 LLM 应与哪些对象集或字符串变量进行交互。这些变量可以是 LLM 将结果写入的新变量，也可能是您工作流中已存在的变量，例如表示用户当前所选内容的变量。
  • 命名并描述变量： 为每个变量编写一段说明其作用的描述。该描述将被注入到聊天机器人的提示词中，为 LLM 提供何时使用给定变量的上下文。
  • 设置值可见性： 您可以通过设置值可见性来选择聊天机器人是否可以查看值。我们建议仅在必要时才允许 LLM 读取值，以减少混淆。例如，如果您使用对象集变量作为 本体论上下文的输入，则该变量无需对 LLM 可见；对象集值的相关内容将包含在每个循环的系统提示词中。但是，如果您有一个包含系统提示词动态部分的字符串变量，则该变量 必须 必须设置为可见，以便 LLM 能够读取变量的内容。
  • 将变量添加为输入： 您可以选择将变量配置为本体论检索上下文的输入，从而为语义搜索提供确定性输入，或向 LLM 提供完整的对象集。此外，函数支撑的上下文可以接收多个输入变量，以便在运行函数时包含有状态信息。 对象查询 工具 还可以为每种对象类型接收一个初始对象集变量，为 LLM 应用其他筛选器或聚合提供起点。

应用程序状态还可以在用户定义的 系统提示词 中通过斜杠命令进行引用 / （使用键盘上的）。

可以使用 调试应用程序状态 部分来测试应用程序状态。您可以手动覆盖每个变量的值，当聊天机器人更新变量值时，调试部分将提供可视化反馈。

使用聊天机器人更新应用程序变量

您配置的应用程序变量可以通过聊天机器人的 ，以及 或 检索上下文 进行修改，该上下文已添加到应用程序状态配置中。变量可以通过工具或上下文的输出进行确定性更新，也可以通过 更新应用程序变量 工具进行非确定性更新。

自动变量更新

变量可以配置为使用 对象查询 工具、函数支撑的上下文或本体论上下文输出的值进行确定性更新。在每次执行上下文或工具后，Chatbot Studio 将记录最新输出，并在 LLM 完成流式传输后将映射的应用程序变量更新为输出值。我们建议采用确定性更新而非非确定性更新，以避免 LLM 混淆。在某些情况下，您可能希望完全对 LLM 隐藏变量值。

确定性工具输入

直方图 操作 和 函数 ，以及 可以配置为使用来自应用程序变量的输入，而不是通过 LLM 动态生成输入。此功能允许您将预定的值直接传递给工具，从而提高一致性并减少 token 使用量。

此功能仅支持字符串和对象集输入类型。传递的值会固定为推理循环开始时变量的初始值，这意味着同一查询中先前工具调用的更新不会反映在作为确定性输入传递的值中。

使用 LLM 更新变量

如果您希望 LLM 配置要更新的新变量，或根据当前用户查询有条件地应用更新，请添加 更新应用程序变量 工具。此工具支持 LLM 可更新的变量列表。

作为引用的变量

您还可以配置一个对象集变量，在用户选择引用时进行更新。所配置的对象集变量将更新为包含被引用对象的静态对象集。

在 Workshop 中配置

如果 AIP Chatbot 已配置应用程序状态，您可以在 Workshop 中配置聊天机器人的应用程序变量。请查看 Workshop 应用程序 文档以了解更多信息。
