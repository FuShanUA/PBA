从有序的 GeoPoint 行创建简单几何图形

支持环境：Batch

给定一个 GeoPoint 列和一个排序方式，通过按指定顺序连接这些 GeoPoint，返回一个多边形或线字符串。此函数假定数据为表格形式，其中单行表示线字符串或多边形外壳中的单个 GeoPoint，并有一列指定这些点的顺序。对于多边形，该顺序应标识沿外壳逆时针移动时的各个点。给定这些点的顺序和分区（分组），该函数通过按 order-by 列的升序连接 GeoPoint 来为该分区构建所需的几何图形。

表达式类别： 地理空间

声明的参数

  • GeoPoint： 用于构建几何图形的 GeoPoint 列。数据集中的每一行应代表一个单独的 GeoPoint。如果存在空值，这些行将被忽略。
    Expression<GeoPoint>
  • 排序依据（升序）： 用于对 GeoPoint 进行排序以构建线串或所需多边形外壳的值列。如果组内的值相同，则排序是随机的。如果存在空值，这些行将被忽略。
    Expression<Byte | Date | Decimal | Double | Float | Integer | Long | Short | Timestamp>
  • 输出几何类型： 输出应为多边形还是线串。
    Enum<LineString, Polygon>

输出类型： 几何

示例

示例 1：基础用例

参数值：

  • GeoPoint： geo_point
  • 排序依据（升序）： order
  • 输出几何类型： LINE_STRING

给定输入表：

geo_pointorder
{
 latitude -> 0.0,
 longitude -> 0.0,
}		0
{
 latitude -> 1.0,
 longitude -> 0.0,
}		1
{
 latitude -> 1.0,
 longitude -> 1.0,
}		2

输出： {"type":"LineString","coordinates": [[0.0,0.0],[0.0, 1.0],[1.0,1.0]]}
