表格

Insight 中的 表格 选项卡以表格形式呈现分析对象，属性名称作为列标题，每行代表一个单独的对象实例。

选择状态

选中某一行会将其高亮显示，并打开对象面板视图，即完整对象视图的精简版本。

表格中可使用以下键盘快捷键：

  • 多选： Cmd+Click （macOS）或 Ctrl+Click （Windows）可选择多个单独的行。
  • 范围选择： 选中一行，然后 Shift+Click 另一行，即可高亮显示两行之间的所有行。
  • 取消全选： 当已选中多行时，选中任意一行即可取消全选。

表格左侧的多选按钮可一次性选择多个对象。表格顶部的多选按钮用于选中或取消选中所有行。

属性

表格右上角提供属性搜索栏，显示当前可见的属性数量。表格中未显示的属性可通过属性配置面板添加，该面板可通过右上角的齿轮图标打开。只能搜索表格中当前显示的属性。匹配项会显示在下拉列表中，并在表格中高亮显示。

属性配置

配置面板提供对所有对象类型属性的访问。可以搜索并添加表格中当前未包含的属性，并可通过拖拽修改属性顺序。 截断表格中的文本 选项默认处于启用状态。禁用该选项后，将显示较长字段的完整文本，这可能会增加行高。

派生属性

派生属性 是在运行时根据对象上其他属性或关联的值计算得出的。要添加派生属性，请通过齿轮图标打开属性配置面板，然后选择 + 添加派生属性 （位于面板底部）。随后可根据需要添加关联属性或属性聚合。

多对象类型分析

如果分析路径包含多个对象类型，每个对象类型都会在表格中显示为一个可选择的表头。每个对象类型都可以开启或关闭，所有可见对象类型的属性都会显示在表格和属性配置面板中。

数据操作

Insight 允许您直接从分析结果中创建、更新和删除对象，从而将数据写回本体论。

权限

要执行写操作，您需要满足以下条件：

  • 编辑权限 （针对本体论中的对象类型）
  • 写入权限 到底层数据源
  • 项目权限 如果对象类型的作用域限定为某个项目

如果您需要写入权限，请联系您的 Foundry 管理员。

选择对象

在执行操作之前，请先选择要修改的对象。在结果表中，选中各个对象旁边的复选框，或选中表头复选框以选择所有可见对象。所选数量会显示在工具栏中。

当结果跨越多个页面时，选中表头复选框会选中所有符合已应用筛选条件的对象，而不仅仅是当前页面上的对象。

行操作

工具栏中的 操作 菜单提供了本体论中为该对象类型定义的操作。

  1. 选择一个或多个对象。
  2. 选择 操作 以查看可用操作。
  3. 选择一个操作。
  4. 完成操作表单或工作流。

可用操作取决于您的本体论配置。常见示例包括将对象分配给用户、触发工作流或更新相关对象。

创建对象

  1. 选择 创建 （在工具栏中）。
  2. 选择要创建的对象类型。
  3. 填写属性值。
  4. 选择 创建。

该表单会显示对象类型上定义的所有属性。必填属性会带有标记。

更新对象

  1. 选择一个或多个对象。
  2. 选择 编辑 （在工具栏中）。
  3. 修改属性值。
  4. 选择 保存。

批量更新

当选中多个对象时，您可以一次性更新所有对象的共享属性。仅修改您要更改的属性；未修改的属性将保留其现有值。
