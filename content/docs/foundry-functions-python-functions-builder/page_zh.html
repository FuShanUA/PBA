在 Pipeline Builder 中使用 Python 函数

Pipeline Builder 同时支持 Java 和 Python 用户定义函数（UDF）。 详细了解 Java UDF。

前提条件

本指南假设您已经编写并发布了一个 Python 函数。请查阅我们的 Python 函数入门 文档以获取教程。

架构

Python 函数以 Sidecar 容器的形式在 Pipeline Builder 管道中运行。这意味着该函数无需部署，并且会随管道规模动态伸缩。嵌入式函数可以 预览 ，与 Pipeline Builder 中的其他转换类似。

Python 函数如何处理数据

在 Pipeline Builder 中将 Python 函数用作用户定义函数（UDF）时，该函数会 每行运行一次。Pipeline Builder 不会将整个表、 pandas DataFrame 或 Spark DataFrame 传递给您的函数。相反，您需要将一个或多个输入列映射到函数的参数，Pipeline Builder 会为每一行调用该函数，并将该行的单元格值作为参数传递。

您的函数返回的值将成为输出表中的一个新列，每行生成一个值。因此，Python UDF 返回标量（单值）类型，例如 str、 int、 float、 bool或 datetime 而不是 DataFrame。没有可返回的 DataFrame 类型：管道构建器从每一行的返回值中组装出的列 即为 最终得到的表格输出。

以下示例将两列作为输入，并为每行返回一个 str 值，管道构建器会将该值写入一个新列：

from functions.api import function

@function
def full_name(first_name: str, last_name: str) -> str:
    return f"{first_name} {last_name}"

当您 配置该转换时，请将 first_name 和 last_name 参数映射到相应的输入列。当该转换运行时，管道构建器会针对每一行对 full_name 进行求值，并将返回的字符串写入新的输出列。

如需受支持的输入和输出类型及其对应的 Python 类型的完整列表，请参阅 类型参考。 本体论类型 在该参考中不受管道构建器支持：接受或返回其中一种类型的函数无法导入，也不会出现在可用函数列表中。

返回结构体

要从单个函数返回多个相关值，请返回 自定义类型（结构体） 而非标量。管道构建器会以单个结构体列的形式添加返回的值，其中自定义类型的每个属性对应一个字段。然后，您可以使用 Get struct field 转换来提取各个字段。

from dataclasses import dataclass
from functions.api import function, Double

@dataclass
class Stats:
    total: Double
    average: Double

@function
def compute_stats(a: Double, b: Double) -> Stats:
    total = a + b
    return Stats(total=total, average=total / 2)

在 Pipeline Builder 管道中使用您的函数

请按照以下步骤在您的管道中准备并配置 Python 函数：

  1. 打开您想要在其中使用 Python 函数的 Pipeline Builder 管道。
  1. 使用以下两种方法之一将您的 UDF 导入 Pipeline Builder：
    • 在图视图中：
      1. 选择 Reusables （位于管道图上部），然后选择 用户定义的函数。



        2. 选择 导入 UDF ，然后在可用函数中搜索，找到您想要使用的函数 3. 选择 添加 （位于函数名称旁）。该函数随后应显示一个 已导入 标签。



        4. 关闭导入对话框，然后选择 转换 （位于您的 Pipeline Builder 图中您想要使用该函数的位置）。 5. 从转换列表中，找到 UDFs 标签页（位于左侧），以查看您导入的函数。
    • 使用转换选择器：
      1. 选择 转换 （位于 Pipeline Builder 图上）。
      2. 输入您想要导入的 UDF 的名称。



        3. 选择 搜索未导入的 UDF。 4. 将鼠标悬停在所需的 UDF 上，然后选择 导入。



  2. 填写转换定义，指定输入列和参数，然后选择 应用。

现在,您应该可以在 Pipeline Builder 图表中看到您的 Python 函数,并可以预览该函数的输出。

在 Pipeline Builder 中进行外部 API 调用

要从 Pipeline Builder 向外部系统进行 API 调用,您可以发布一个 可访问外部系统的 Python 函数。这将使您能够编写与外部系统通信的逻辑,并将其用作管道的一部分。

要在 Pipeline Builder 中用作用户自定义函数 (UDF),函数中使用的所有数据源都必须配置为可导入到管道中。要配置此设置,请在 Data Connection 中导航到该数据源,然后转到 连接设置 > 代码导入配置 选项卡:

在该数据源上启用此选项并发布 Python 函数后,即可像使用任何其他 Python 函数一样在管道中使用该函数。

在 Pipeline Builder 中访问本体论

Pipeline Builder UDF 不支持通过 FoundryClient() 或本体论 SDK (OSDK) 直接访问本体论。实例化 FoundryClient() 并从 UDF 访问本体论将返回 EnvironmentNotConfigured 错误。此限制有助于防止数据在构建之间被取消标记或泄露。

要从 Pipeline Builder UDF 访问本体论数据，请考虑以下方法：

  • 使用外部源： 为执行本体论查询的 Python 函数创建一个外部源，然后将该源导入到您的 Pipeline Builder UDF 中。这样可以避免在 UDF 上下文中直接进行本体论查询所带来的身份验证和权限问题。要配置该源，请在 Data Connection 中导航到该源并启用 连接设置 > 代码导入配置 如 上文所述。
  • 联接本体论支撑的数据集： 如果您的使用场景允许，请维护一个单独的数据集来保存相关的本体论支撑数据，并将其联接到您的管道中。这样可以避免调用本体论 API，并支持去重或存在性检查。
