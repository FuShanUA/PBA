Spark UI

Spark 有自己的 Web UI ↗ ，它作为 Foundry 的补充 Spark详细信息 页面，提供额外的信息，包括：

  • 执行器生命周期信息，例如执行器的启动和关闭。
  • 更大规模的任务和执行器指标样本，包括峰值内存使用量。
  • 执行期间使用的所有 Spark 配置。

查看 Spark UI

要查看 Transforms 作业的 Spark UI，请将该作业作为 调试作业重新运行。你会看到一个 Spark UI 按钮；选择它将打开 Spark 的 Web UI。

Spark 事件会在延迟 1-2 分钟后出现在 Spark UI 中。

在 Foundry 中使用 Spark UI

Spark 的 Web UI 内容详尽，但并未以针对 Foundry 定制的方式呈现信息。下面，我们为在 Foundry 作业中浏览 Spark 的 Web UI 提供建议。

SQL 执行

Spark 可以将 SQL 查询拆分为主查询和一个或多个子查询。在某些情况下，子查询比主查询更有意义。Foundry 中的许多数据集写入就是如此。

查看 "Writing dataset ..." SQL 执行时，你可以在 Sub Execution IDs.

下找到与该写入关联的查询图

直方图 职位招聘 选项卡显示 Transforms 作业会触发一个初始 count 作业。该 count 作业的目的是尽早请求执行器分配，同时运行时执行额外的设置（包括安装依赖项）。这提高了在转换准备运行时执行器可用的可能性。
