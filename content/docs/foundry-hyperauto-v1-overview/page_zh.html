HyperAuto V1 [已停用]

日落

HyperAuto V1 目前处于 日落 阶段，并将在未来某个日期被弃用。目前仍提供全面支持。不建议创建新的 V1 管道，用户应从 HyperAuto V1 迁移到 V2，具体步骤详见 迁移文档.

HyperAuto V1（也称为 SDDI 或 Bellhop）是 Palantir 源到价值自动化套件的第一个版本。 HyperAuto V2 已针对 SAP 发布，强烈建议将该数据源与 HyperAuto V2 配合使用，但 HyperAuto V1 目前仍支持多种源类型，包括：

  • Salesforce
  • Oracle NetSuite
  • SAP（不建议使用 V1；请使用 V2 instead)

HyperAuto V1 的详细文档可在平台内查看。在那里，查看 软件定义数据集成 以了解各种配置选项。

架构

HyperAuto V1 由三个组件组成，旨在以最少的工作量将数据从原始源集成到本体论：

  1. 连接器 以安全且优化的方式在源系统之间大规模传输数据。
  2. 数据源探索 允许以引导式方式进行快速数据发现，并提供“购物车”式体验，用于快速批量创建和配置数据同步。
  3. 自动管道生成 使用自动生成的数据管道将原始数据转换为精选的 Foundry 数据集和对象类型，并将其放入 本体论 中。

管道生成

自动管道生成 为集成常见源系统创建开箱即用的数据管道。这些管道会对数据进行准备，使其可供本体论和工作流使用。由于管道生成内置了每个源系统的相关知识，使用此功能可以提高效率，并且无需完全理解每个底层源系统的复杂细节。

生成的管道包括四个主要步骤：

  • 源特定的预处理 生成一组具有预定义 schema 的元数据数据集。这些元数据包含理解来自源系统的数据所需的信息。
  • 清洗库 对所有数据集应用标准化的数据清洗步骤，确保流入系统的每条数据都遵循最佳实践。
  • 核心生成 执行数据富化、列重命名、去重和数据合并，以生成可用于本体论中的分析、报告和工作流的可用数据。
  • 派生元素 为高级工作流提供预定义支持，包括生成连接表、时间序列数据集和富化列，这些内容提供丰富的派生信息，同时也会输入到本体论中。

本体论创建

在自动生成管道之后，HyperAuto V1 还支持自动生成 本体论 。这完成了数据集成过程，借助广泛的 本体论感知应用程序 （在 Foundry 中）的更多信息。
