Notepad

是否可以在 Notepad 中通过 Object Property 或 Object Card 小部件显示关联对象的属性？

目前无法在 Notepad 中显示关联对象的属性。但是，在 Notepad 模板中，您可以配置一个函数来返回关联的对象。

时间戳： 2024年4月16日

是否支持在 Notepad 模板的页眉/页脚中嵌入变量？

目前不支持直接在模板的页眉/页脚中嵌入变量，但可以将小部件复制到页眉/页脚菜单中作为一种变通方法。

时间戳： 2024年4月16日

是否可以在 Notepad 的 Table 小部件中合并单元格？

目前无法在 Table 小部件中合并单元格。

时间戳： 2024年4月16日

如何在文档中开启滚动条旁边的目录？

可以通过视图菜单启用目录。

时间戳： 2024年4月13日

在 Notepad 中，是否可以将章节生成器中对象的属性作为输入传递给 Quiver 仪表板图表？

无法传递对象的属性。但是，可以传递整个对象。

时间戳： 2024年7月24日

是否可以将 Notepad 添加为可供 AIP Assist 用于回答问题的文档？

是的，可以将 Notepad 文档添加为自定义文档，供 AIP Assist 在回答问题时参考。您可以通过“操作”下拉菜单中的“添加到 AIP Assist”选项，只需极少的配置即可将 Notepad 文档添加到 AIP Assist。

时间戳： 2024年11月13日
