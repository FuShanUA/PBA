部署工作流

您可以在 Rules 应用程序中部署新的 Foundry Rules 工作流。通过该应用程序，生成 所需的对象 以及工作流所需的操作。

  1. 部署新的 Rules 工作流： 在侧边栏中找到并选择 Foundry Rules 应用程序，然后选择 基于规则的数据管道。



  2. 提供配置： 该应用程序将为您创建一个新项目，其中包含相关的支撑数据集、Foundry Rules 工作流和 Workshop 应用程序资源。



    • 选择相关的 空间。
    • 选择相关的 本体论。如果您有多个本体论，请选择包含您想要定义规则的所有对象类型的本体论。
    • 规则编辑器组用作操作的提交条件。该组中的用户可以创建用于添加、编辑和删除规则的提案，还可以对提案做出决定。此配置仅作为起点，因为您稍后可以针对规则操作配置提交条件。要更改操作类型的提交条件，请查看 常见问题解答。

  3. 部署： 填写完字段后，选择 部署。部署过程在后台进行，大约需要两到三分钟，在此期间您可以安全地离开当前页面。待处理和已完成的安装可在主页的以下位置找到： 待处理的安装 或 现有规则工作流。在现有工作流列表中，所有工作流的默认名称均为 "Foundry Rules Workflow"，并带有时间戳。您可以通过重命名项目文件夹中的相应资源来重命名工作流。



完成上述步骤后，了解如何 配置工作流。

常见问题

如何更改操作类型的提交条件？

要更新操作类型的提交条件，请前往 Workshop 应用程序，选择 编辑。然后，查看右侧的规则编辑器配置面板，如下所示。

然后，将光标悬停在与 创建添加提案操作的“创建添加规则的提案”下拉选项同一行的“i”图标上。

在新的弹出窗口中，选择 查看操作配置。

在此处，您将能够更改 提交条件。
