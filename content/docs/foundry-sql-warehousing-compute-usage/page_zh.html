在 Foundry 中使用 SQL 的计算用量

在 Foundry 中使用 SQL 仓库运行查询或构建会消耗计算资源，以计算秒为单位计量。本页面介绍了 SQL 仓库如何使用计算资源，以及使用量如何归因到 Foundry 资源以用于报告。使用量可在以下位置查看： 资源管理应用程序。

按查询类型划分的 Foundry 计算用量

下表按查询类型列出了 SQL 仓库查询所使用的 Foundry 计算资源，并提供了相关详细文档的链接。
