授权角色

摘要

Palantir Foundry Connector 2.0 for SAP（"Connector"）使用四种类型的角色。

  • 服务角色： 运行 Connector 需要这些角色。请勿修改这些角色。
    • /PALANTIR/SERVICE_SLT: 用于 SLT 的 Palantir 服务角色
    • /PALANTIR/SERVICE_SLT_740: 用于 SAP_BASIS 7.4 的 Palantir 服务角色（技术组件版本，适用于 SAP NetWeaver 和 SAP S/4HANA 系统）
    • /PALANTIR/SERVICE_USER: Palantir 服务角色
  • 内容角色： 从 SAP 系统提取数据需要这些角色。可根据业务需求复制和修改这些角色。
    • /PALANTIR/CONTENT_BEX_ALL: BEx 访问角色
    • /PALANTIR/CONTENT_DM_ALL: 数据模型访问角色
    • /PALANTIR/CONTENT_EXT_ALL: 提取器内容访问
    • /PALANTIR/CONTENT_FUNCTION_ALL: 函数访问角色
    • /PALANTIR/CONTENT_INFOPROV_ALL: InfoProvider 内容访问
    • /PALANTIR/CONTENT_SLT_ALL: SLT 访问角色
    • /PALANTIR/CONTENT_TABLE_ALL: 表内容访问
    • /PALANTIR/CONTENT_TCODE_ALL: 事务代码内容访问
    • /PALANTIR/CONTENT_HANAVIEW_ALL: HANA 信息视图内容访问
    • /PALANTIR/CONTENT_CDS_ALL: ABAP CDS 视图内容访问
  • 回写角色： 如果启用从 Foundry 到 SAP 系统的回写功能，则需要这些角色。
    • /PALANTIR/OAUTH_CLIENT: Palantir Foundry OAuth 2.0 客户端角色
  • 监控和调试角色： 这些角色用于向 Foundry 公开 SAP 系统信息，以实现远程监控。
    • /PALANTIR/MONITORING: 监控
    • /PALANTIR/DEBUG_USER: 调试用户访问

服务角色

  • /PALANTIR/SERVICE_USER: 这是用户运行 Connector 服务的基本角色。对 Connector 的每个请求都会检查此角色。此角色中的授权对象如下：
    • /PALAU/SRV: 具有 03（显示）和 16（执行）活动的 Palantir 服务授权对象。
    • S_BTCH_JOB: （后台处理：后台作业操作）Connector 会运行后台作业（例如分页或清理操作）；因此需要此授权对象。
    • S_TCODE: （事务启动时的事务代码检查）仅适用于 SU53 和 ST22 事务（SAP 中的授权检查工具和运行时错误），是调试和正确日志记录机制所必需的。
    • S_RFC_ADM: （RFC 目标管理）此对象用于 36（检查）和 39（扩展检查）活动，以确定 RFC 连接是否处于活动状态以及是否已检查授权测试。
    • S_RFC: （RFC 访问授权检查）此对象用于在 SLT 和远程代理场景中以 16（执行）活动运行远程函数调用。
    • /SDF/E2E: （端到端诊断授权）此对象用于从 Foundry 对提取过程运行追踪，具有 03（显示）活动。
    • S_ADMI_FCD: （系统授权）此对象用于使用 PADM（使用事务 SM04、SM50 进行进程管理）、ST0R（分析追踪）、ST22（跨客户端转储分析）运行检查和追踪。
    • S_BTCH_JOB: （后台处理：后台作业操作）此对象用于将 Connector 提取作为后台作业运行，具有除 MODI（修改其他用户的作业）之外的所有活动。
    • S_DATASET: （文件访问授权）此对象用于在 SAP 中使用 SAT 生成和访问追踪文件，具有 33（读取）、A6（带过滤读取）、A7（带过滤写入）活动。
    • S_TABU_NAM: （通过通用标准工具访问表）此对象用于以 03（显示）活动访问 /PAL*、DMC*、IUUC* 表。
    • S_TABU_DIS: （表维护（通过 SM30 等标准工具））此对象用于以 03（显示）活动访问表。

仅当您连接到 SAP Landscape Transformation 复制服务器时，才需要以下角色：

  • /PALANTIR/SERVICE_SLT: 运行 SLT API 需要此角色。此角色中的授权对象如下：
    • S_DMIS: （SAP SLO 数据迁移服务器的授权对象）此对象仅限于 03（显示）活动，用于检查 API 端点并调用它们。
  • /PALANTIR/SERVICE_SLT_740: 如果 SAP SLT 运行在 SAP_BASIS 7.4+ 上，则需要额外的授权对象。这些对象如下：
    • S_DMC_S_R: （MWB：发送方/接收方中的读/写授权）Foundry 需要此对象来访问 SLT 队列。
    • S_BTCH_ADM: （后台处理：后台管理员）此对象代表 SAP SLT 为连接器管理后台作业，例如复制对象定义、复制过程对象，以及启动向 SLT 队列的复制。
    • S_DMIS: （SAP SLO 数据迁移服务器的授权对象）此对象仅限于 03（显示）活动，用于检查 API 端点并调用它们。
    • S_DMIS_MOM: （MWB / 迁移对象建模器的授权）

内容角色

这些角色作为示例包含在内。请通过复制这些角色并限制对系统中所需对象的访问，来调整授权配置文件的内容。

连接器角色

  • /PALANTIR/CONTENT_TABLE_ALL: 需要此角色才能从数据库表和视图中提取数据。
    • /PALAU/TAB: Palantir 表授权对象：默认情况下，所有表均被允许，并带有 * wildcard.
  • /PALANTIR/CONTENT_DM_ALL： 需要此角色才能从数据库表中提取数据模型。
    • /PALAU/DMO: Palantir 数据模型授权对象：默认情况下，所有表均被允许，并带有 * wildcard.
  • /PALANTIR/CONTENT_FUNCTION_ALL: 需要此角色才能从 SAP 系统运行 RFC 函数。根据所使用的业务功能，可能需要额外的授权。
    • /PALAU/FUN: Palantir 函数授权对象：默认情况下，所有函数均被允许，并带有 * wildcard.
  • /PALANTIR/CONTENT_TCODE_ALL: 需要此角色才能从 SAP 系统运行事务代码（ALV SE38 报表）。根据所使用的业务功能，可能需要额外的授权。
    • /PALAU/TCO: Palantir 事务代码授权对象：默认情况下，所有事务代码均被允许，并带有 * wildcard.
  • /PALANTIR/CONTENT_HANANVIEW_ALL: 需要此角色才能从 HANA 信息视图中提取数据
    • /PALAU/HAN: Palantir HANA 授权对象：默认情况下，所有 HANA 信息视图均被允许，并带有 * wildcard.
  • /PALANTIR/CONTENT_CDS_ALL: 需要此角色才能从 ABAP CDS 视图中提取数据
    • /PALAU/CDS: Palantir CDS 授权对象：默认情况下，所有 CDS 视图均被允许，并带有 * wildcard.

仅当您连接到 SAP Business Warehouse (BW) 服务器时，才需要以下角色：

  • /PALANTIR/CONTENT_BEX_ALL: 需要此角色才能从 SAP BW（Business Warehouse）BEx 查询中提取数据。
    • /PALAU/BEX: （Palantir BEx 授权对象）：默认情况下，所有 BEx 查询均被允许，并带有 * wildcard.
  • /PALANTIR/CONTENT_EXT_ALL ：需要此角色才能从 SAP BW（Business Warehouse）提取器（启用 ODP）中提取数据。
    • /PALAU/EXT: Palantir 提取器授权对象：默认情况下，所有启用 ODP 的提取器均被允许，并带有 * wildcard.
  • /PALANTIR/CONTENT_INFOPROV_ALL: 需要此角色才能从 SAP BW（Business Warehouse）InfoProvider 中提取数据。
    • /PALAU/INF: Palantir InfoProvider 授权对象：默认情况下，所有 InfoProvider 均被允许，并带有 * wildcard.
    • S_RS_AUTH: 角色中的 BI 分析授权：这是 BW 系统中的所有分析授权。请相应地进行调整。
    • S_RS_COMP: Business Explorer - 组件：这是 BW 系统中所有 BEx 对象的授权。请相应地进行调整。
    • S_RS_COMP1: Business Explorer - 组件：所有者的增强：这是 BW 系统中所有 BEx 对象的授权。请相应地进行调整。

仅当您连接到 SAP Landscape Transformation (SLT) 复制服务器时，才需要以下角色：

  • /PALANTIR/CONTENT_SLT_ALL 需要此角色才能从 SLT 队列中提取数据，这些队列将所连接系统中的表复制到 SAP SLT。
    • /PALAU/SLT: （Palantir SLT 授权对象）：默认情况下，所有表均被允许，并带有 * wildcard.

回写角色

  • /PALANTIR/OAUTH_CLIENT: 当从 Foundry 向 SAP 系统启用回写时，需要此角色。它为 OAuth 2.0 配置提供所需的授权对象。
    • S_SERVICE: 检查外部服务的启动。这些服务受到以下限制： /PALANTIR/* services.
    • S_OA2C_ADM: OAuth 2.0 客户端配置
    • S_OA2C_USE: OAuth 2.0 客户端使用
    • S_SCOPE: OAuth 2.0 范围。此角色仅限于 /PALANTIR/SRV_0001 范围，该范围用于通过 SAP 函数进行 Palantir Foundry 回写。

用于监控和调试的角色

  • /PALANTIR/MONITORING: 需要此角色才能通过 Connector 对 SAP 系统进行远程监控。它提供广泛的系统信息，例如运行时错误分析（ST22）、SAP 系统日志（SM21）、SAP 后台作业监控（SM37）、授权分析（SU53）、Internet Communication Manager（ICM）、系统资源监控（ST02,ST06）、SAP SLT Cockpit（LTRC）、SAP SLT 操作增量队列监控（ODQMON).
  • /PALANTIR/DEBUG_USER: 发生事件时，Palantir 支持团队需要此角色；开发人员可能需要在 SAP 系统中调试该问题。此角色汇集了 Connector 开发团队所需的所有授权对象。

Remote Agent 角色

Remote Agent 角色与主连接器的相应角色相同。这些角色可以在安装了 Connector Remote Agent 的远程系统中进行维护。

适用于 SAP_BASIS 7.0 及更高版本的角色

  • /PALANTIR/CONTENT_RBEX_ALL: 远程 BEx 内容访问
  • /PALANTIR/CONTENT_RFUNCT_ALL: 远程函数内容访问
  • /PALANTIR/CONTENT_RTCODE_ALL: 远程事务代码内容访问
  • /PALANTIR/CONTENT_RINFOPRV_ALL: 远程 InfoProvider 内容访问
  • /PALANTIR/CONTENT_RTABLE_ALL: 远程表内容访问
  • /PALANTIR/SERVICE_USER: Palantir 服务角色

适用于基础版本 46C、620 或 640 的角色

  • /PALAGT47/CONTENT_RTABLE_ALL: 远程表内容访问
  • /PALAGT47/SERVICE_USER: Palantir 服务角色
