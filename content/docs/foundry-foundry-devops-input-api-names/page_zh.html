输入 API 名称

输入 API 名称用于在公开的 Marketplace API 中标识您产品的输入。调用方使用这些稳定的名称来发现输入、为安装和升级提供值，以及检查安装的当前输入。有关更多信息，请参阅 Marketplace 安装 API 参考.

每个输入的 API 名称与其显示标题是分开的，并且在产品版本之间保持不变。如果您的产品版本包含输入，请在通过 Foundry API 发布以供安装之前启用 API 名称生成。

启用 API 名称

要在以下情况下生成名称： 创建产品 或准备新版本时：

  1. 打开 设置 在您的产品草稿中。
  2. 选择 Foundry API 设置 并启用 为输入启用 API 名称.

DevOps 会根据输入标题自动分配名称。例如，标题为 Source dataset 的输入可以获得 API 名称 sourceDataset.

查看并自定义名称

在 输入 表中选择一个输入以打开其 详情 面板，然后选择其 API 名称 值进行编辑。请选择调用方能够理解的描述性名称。

自定义名称时，请遵循以下规则：

  • 使用 1 到 100 个字符。
  • 以字母或下划线开头，后跟字母、数字或下划线。支持 Unicode 标识符，且必须使用 NFKC 规范化。
  • 请勿使用保留关键字： y, n, yes, no, true, false, on, off，或 null，无论大小写如何。
  • 为顶层输入以及共享同一父级的嵌套输入使用不同的名称。

公开 API 使用以点分隔且包含父级名称的名称来引用嵌套输入。例如， customerId 列位于 sourceDataset 之下，被引用为 sourceDataset.customerId。将该列自身的 API 名称设置为 customerId；API 会自动添加父级名称。

要同时编辑多个名称，请选择多个输入并选择 设置 {N} 个 API 名称，其中 {N} 是所选输入的数量。查看您的更改并选择 保存.

本体论 API 名称

输入 API 名称用于标识产品内的输入。由 输入预设 使用的本体论资源 API 名称用于标识为这些输入提供的资源。

API 名称稳定性

新产品版本会保留先前发布的输入 API 名称，以便调用方可以继续使用其现有的输入映射。

更改已发布的输入 API 名称或禁用 为输入启用 API 名称 可能会破坏现有工作流。禁用生成会清除草稿版本的所有已分配名称。

如果您进行上述任一更改，发布对话框会要求您在继续之前确认潜在影响。为避免影响调用方，请在发布之前恢复先前的名称或重新启用生成。
