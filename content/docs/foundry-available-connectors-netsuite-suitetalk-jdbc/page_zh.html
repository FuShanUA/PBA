在 NetSuite 中配置用户角色和权限

NetSuite 中的访问控制通过为用户分配角色来配置；每个角色是一组权限的集合，定义了用户可以执行的任务以及可以访问的数据。我们建议为将连接到 Foundry 的用户进行如下配置：

  1. 创建一个具有适当权限的专用角色。

    1. 在 NetSuite 的工具栏中，选择 设置 > Users/Roles（用户/角色） > Manage Roles（管理角色） > 新建 并为该角色提供一个明确的名称。我们建议使用 foundry-role.
      • 您可以选择勾选 Web Services only（仅 Web 服务） 配置复选框。
    2. 通过导航到角色页面底部并选择，为该角色添加系统级权限 权限 > 设置。您需要添加的最低必要权限为：
      • Log In using access tokens（使用访问令牌登录）,
      • SOAP Web Services（SOAP Web 服务）,
      • Other Custom Fields（其他自定义字段）,
      • Custom Body Fields（自定义正文字段）,
      • Custom Item Fields（自定义项目字段）,
      • 请记住 保存 这些权限。
    3. 通过导航到角色页面底部并选择，为该角色添加您希望能够从 Foundry 查询的表的表权限 权限 > 列表。选择所需的表，然后选择 将 then 保存.

  2. 将新角色分配给用户。

    1. 在 NetSuite 的工具栏中，选择 设置 > Users/Roles（用户/角色） > Manage Users（管理用户）。选择您要用于连接 Foundry 的用户，然后选择 编辑.
    2. 在 Data Connection 中导航至 访问权限 选项卡，并确保 Give Access（授予访问权限） 复选框已勾选。
    3. 在监听器设置向导的 角色 选项卡，从下拉列表中选择新创建的角色（foundry-role），然后选择 将 用户偏好 保存.

要验证您是否添加了正确的权限，请以已分配新角色的用户身份登录，并检查您是否可以查看所有预期的数据。

在 NetSuite 中配置集成和访问令牌

NetSuite 中的集成记录用于管理与外部系统的连接。我们建议进行如下配置以连接到 Foundry：

  1. 使用 TBA 创建新的集成记录（参见 更多详情 ↗).
    1. 在 NetSuite 的工具栏中，选择 设置 > Integration（集成） > Manage Integrations（管理集成） > 新建 并为该集成提供一个明确的名称。我们建议 foundry-integration.
    2. 确保 Monday is 已启用 并且仅 Token-based Authentication（基于令牌的身份验证） 被勾选。所有其他复选框均应取消勾选。
    3. 在您 保存，请记下 CLIENT ID and CLIENT SECRET。您将需要它们来配置 Foundry。

CLIENT ID 和 CLIENT SECRET 仅在您首次保存集成记录时显示。要获取新值，您必须重置 CLIENT ID 和 CLIENT SECRET，这将使之前的值失效。

  1. 创建并分配 TBA 令牌。
    1. 在 NetSuite 的工具栏中，选择 设置 > User/Roles（用户/角色） > Access Tokens（访问令牌） > 新建.
      • 如果您无法管理其他用户的令牌，请导航到左下角的 设置 NetSuite 主页上的面板并选择 Manage Access Tokens（管理访问令牌）.
    2. 选择新创建的 应用 (foundry-integration 在我们的示例中），您已为其分配新创建角色的用户（foundry-role）以及新创建的角色。
      • 如果您无法管理其他用户的令牌，您的用户将被默认选中。请确保您的用户已被分配新创建的角色（foundry-role）。
    3. 在您 保存，请记下 TOKEN ID and TOKEN SECRET。您将需要它们来配置 Foundry。

TOKEN ID 和 TOKEN SECRET 仅在您首次保存令牌时显示。您需要创建新令牌以获取新的 TOKEN ID 和 TOKEN SECRET.
