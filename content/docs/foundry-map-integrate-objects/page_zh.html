本体论对象

Map 应用程序支持附加了地理空间数据的本体论对象。

本体论原生表示

点、线和多边形几何图形可以在本体论中通过 geopoint 或 geoshape 属性类型来指定。请参阅 地理空间文档中的本体论部分 以了解更多详情。

圆形

可以在对象类型上指定圆形几何图形，方法是选择一个 半径 属性，该属性位于 地理空间 部分（在对象类型的 功能 选项卡中）。半径属性可以是任何以米为单位的数值属性。

圆形几何图形仅在地图上渲染，不会编入索引以供搜索。如果您需要基于圆形几何图形对对象进行地理空间搜索，则需要使用 多边形来近似表示圆。

分级统计图

要渲染 分级统计图可视化，您需要配置本体论，以便将对象分组到各个区域中。有两种方法可以实现，即 边界标识符 和 关联对象。

边界标识符

地图支持为配置了某些常见区域标识符类型的对象渲染分区统计图——包括 ISO 3166 国家代码、美国各州缩写等。这些边界类型的多边形几何数据内置于地图应用程序中，因此如果您的数据已经附加了其中一种标识符类型，数据集成将变得更加轻松。这些标识符的配置方式是将特定的 值类型 附加到您想要在地图上显示的对象类型的属性上。

要配置边界标识符，请先在 Marketplace 中搜索并安装 "Choropleth Value Types" 产品。该产品包含地图应用程序知道如何渲染为分区统计图的本体论值类型。

当前支持的区域类型及其标识方式如下：

  • Admin 0（全球第 0 级行政边界）
    • ISO 3166 alpha-2 国家代码
    • ISO 3166 alpha-3 国家代码
  • 美国各州
    • FIPS 代码
    • USPS 缩写
  • 美国各县
    • FIPS 代码
    • ANSI 代码

如果您的对象类型已经具有包含其中一种标识符的属性，请在 Ontology Manager 中该属性的 值类型 下拉菜单中选择相应的值类型。

如果您想为上述某种区域类型显示分区统计图，但您的数据中包含的是纬度/经度点，而不是受支持的标识符之一，请使用 Marketplace 中的“分区统计图边界数据集”产品来附加区域标识符。该产品包含的数据集中含有各区域的实际几何图形和其他元数据。请使用管道构建器的 几何相交联接 来查找每个点所在的区域并附加相应的区域标识符，然后在本体论管理器中配置相应的值类型。

关联对象

如果您想为未包含在上述内容中的区域类型显示分区统计图，或者想要对区域几何图形和区域属性进行更多控制，可以创建一个具有您所选区域几何图形的对象类型。然后从您要聚合的对象类型到该区域对象类型创建一个多对一关联。

例如，假设您想要显示一个分区统计图，展示每个销售区域所下订单的总价值。为此配置本体论的一种简单方法是：

  • 一个“销售区域”对象类型，带有一个 geoshape 属性，其中包含每个销售区域的几何图形。
  • 一个“订单”对象类型，包含以下属性：
    • “销售区域”，其中包含每个订单下单所在区域的主键
    • 一个“金额”，其中包含订单的总金额
  • 一个从“订单”到“销售区域”的多对一关联

要显示分区统计图（choropleth）：

  1. 使用 搜索对话框 将您的“订单”对象添加到地图中
  2. 添加一个 Choropleth 显示 ，用于“订单”图层
  3. 选择 关联对象 选项（位于“ 区域 ”部分中），然后选择从“订单”对象指向其对应“销售区域”的关联类型。
  4. 将“金额”属性用于 样式聚合 ，以控制每个区域的颜色

H3 六边形

对象可以包含字符串属性，其中含有来自 H3 地理空间索引系统 ↗的 H3 单元格 ID。这些将在地图上渲染为相应的六边形。

要指定某个字符串属性包含 H3 单元格 ID，请在 H3 单元格 （位于对象类型的“ 功能 ”选项卡中的“地理空间”部分）下选择该属性。

H3 六边形仅在 Map 上渲染，不会被编入搜索索引。如果您需要对象能够基于 H3 六边形进行地理空间搜索，则需要将 H3 单元格 ID 转换为 GeoJSON 多边形，并将它们包含在一个 geoshape 属性，如上文所述。

地理配准图像

对象可以附加地理配准图像，例如卫星照片、航空影像或纸质地图的扫描件。地理配准图像需要两个属性：

  • 图像 URL String 属性，包含要渲染的图像的 URL。支持的图像文件扩展名包括 .png, .jpg, .jpeg, .gif, .webp, .bmp, .ico, 以及 .svg。图像 URL 属性的 ID 用于配置图像边界属性。
  • 图像边界 geoshape 属性，包含一个四边形 GeoJSON Polygon，表示图像的地理配准边界。该多边形必须按顺时针顺序指定其顶点，从左下角开始。
    • 图像边界属性必须具有一个类型类，用于指示图像 URL 属性的 ID，格式如下：
      • Kind: geo
      • Value: bounds.<image URL property ID> 其中 <image URL property ID> 是图像 URL 属性的 ID。
    • 例如，如果图像 URL 属性的 ID 为 image_url ，则类型类为：Kind: geo, Value: bounds.image_url

带有地理配准图像的对象会被编入索引以用于地理空间搜索，与所有 geoshape 属性一样。

来自媒体集的切片影像 [Beta]

Beta

在 Maps 中使用媒体引用目前处于 beta 开发阶段，您的注册中可能尚未提供。功能在开发过程中可能会发生变化。

地理配准的栅格影像也可以采用切片形式显示，方法是将 GeoTIFF 影像（.tiff, .tif）上传到 媒体集。在此基础上，具有 媒体引用属性 的对象类型即可添加到地图中，并且当用户在地图上平移或缩放时，只会加载影像的可见部分。

轨迹对象

对象可以具有数值 时间序列属性 ，用于表示对象随时间变化的纬度和经度，让用户能够查看对象随时间推移的移动路径及其在任意时间点的位置。

要为对象类型配置轨迹，请选择 “轨迹纬度” 和 “轨迹经度” 属性（位于 “地理空间” 部分，该部分位于对象类型的 “功能” 选项卡中）。这两个属性必须是表示对象位置随时间变化的数值时间序列属性。请参阅 时间序列设置 ，以了解有关配置时间序列的更多信息，以及 轨迹显示 ，以了解有关地图中轨迹可视化选项的更多信息。

事件对象

事件对象是在某个时间点或时间段内发生的本体论对象。对象类型可以通过指定 事件开始时间 和 事件结束时间 的时间戳属性来配置为事件，这些属性位于对象类型的 事件 部分，该部分位于对象类型的 功能 选项卡中。

地图上的事件对象

如果将事件对象添加到地图中，可以将它们配置为仅在事件处于当前状态时显示（即所选时间戳位于事件期间内时）。

与地图上的对象相关联的事件对象

如果地图上的对象关联了事件对象，则可以将这些事件对象添加到 序列 面板以进行时间分析，并且可以将当前事件数量指示器添加到对象标签中。例如， road 对象可以在地图上表示为线条，而 road 对象可能具有关联的 traffic accident 事件；随后，用户便可以使用这些指示器在任意时间点查看每条道路的交通事件数量。

要实现这一点，事件对象类型必须配置 事件意图 （用于指示事件的严重程度），相关设置位于对象类型的 事件 部分，该部分位于对象类型的 功能 选项卡中。
