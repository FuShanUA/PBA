Google Pub/Sub

将 Foundry 连接到 Google Pub/Sub，以实时从主题读取数据到 Foundry 流中。

数据模型

连接器不会解析消息内容，任何类型的数据都可以同步到 Foundry。所有内容均以未解析的形式上传到 data 列下。使用下游流式转换（例如， parse_json in 如果希望用户在每次运行预览前手动确认，请开启）来解析数据。 id 列将显示从 Pub/Sub 接收到的消息 ID。

5986326266478130test-payload

设置同步时，Foundry 中数据集的 schema 必须与 上述 schema 匹配。

性能与限制

连接器使用单个消费者线程从 Pub/Sub 同步消息。从 Foundry 向 Pub/Sub 导出数据时，Foundry 数据流的每个分区使用一个线程。

流式同步会基于 Foundry 中的输出数据集创建订阅，因此配置的凭据必须具有创建订阅的权限。如果配置了多个导入从同一主题读取数据，它们将各自创建自己的订阅并读取该主题上的所有消息。

流式同步旨在成为一致的长期运行作业。流式同步的任何中断都可能导致服务中断，具体取决于预期的结果。

身份验证

在两种可用的身份验证方法之间进行选择：

  • GCP 实例账号： 请参阅 Google Cloud 文档 ↗ 了解如何设置基于实例的身份验证。

    • GCP 实例身份验证仅适用于通过在 GCP 中经过适当配置的实例上运行的代理进行操作的连接。

  • 服务账号密钥文件： 请参阅 Google Cloud 文档 ↗ 了解如何设置服务账号密钥文件身份验证。密钥文件可以作为 JSON or PKCS8 凭据提供。

配置的凭据必须具有以下访问权限：

  • 对于同步：
    • roles/pubsub.viewer
    • roles/pubsub.subscriber
    • projects.subscriptions.create
  • 对于导出：
    • roles/pubsub.publisher
