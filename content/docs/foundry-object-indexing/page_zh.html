索引

在本体论中， 索引 是指通过专用数据库，使 Foundry 数据源中的表格数据或其他形式的数据可供更快的数据检索操作使用的过程。

本文档的这一部分描述了对象存储 v2 的索引过程，其中索引由对象数据漏斗服务（“Funnel”）负责监督。Funnel 服务负责编排 Funnel 管道，以在本体论中创建和修改对象实例，并确保数据和元数据保持最新。

Funnel 管道有两种主要类型， Funnel 批处理管道 和 Funnel 流式管道，用户可以根据其数据源情况、延迟和工作流要求以及成本考量，选择采用其中一种索引机制。
