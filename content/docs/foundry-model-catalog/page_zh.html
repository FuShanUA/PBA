Model Catalog

您可以在 Control Panel中启用 Model Catalog。

Model Catalog 是 Foundry 中的一个 AIP 应用程序，旨在帮助用户发现和了解 Palantir 提供的所有模型。

Model Catalog 使构建者能够：

  • 查看 AIP 中可用的模型并发现新模型。
  • 为您的用例选择合适的模型。即将推出的更新将提供更多用于比较和决策的工具与基准。
  • 通过 Marketplace 使用基本模板和完整的用例模板开始工作流。
  • 使用沙盒/演练场测试不同的模型。

Model Catalog 目前不包含自定义 ML/AI 模型，仅包含 LLM。您可以在 Modeling Objectives中找到 ML/AI 模型。

Model Catalog 有两个主要视图：

  • Model Catalog 主页
  • 模型实体页面

Model Catalog 主页

Model Catalog 主页是一个发现和导航界面，显示用户在其 Foundry 注册中可用的所有大语言模型。

查看 AIP 中可用模型的完整列表。

在主页上筛选模型有几种方式：

  • 生命周期状态
    • 实验性： 实验性模型可能被提供商或 Palantir 视为实验性，这表明 API 可能发生变化、token 容量可能受限、在 AIP 应用中的行为可能无法获得完全支持，或者可能出现其他不稳定的行为。所有模型在首次于 AIP 中可用时都将处于实验性状态。实验性模型通常用于探索和测试，对长期稳定性和支持的重视程度较低。模型在满足 Palantir 的性能和可用性标准后，会从实验性升级为稳定状态。这些标准包括但不限于：在保持可用的同时具备足够的吞吐量来处理生产工作负载的请求、可在所有 AIP 应用中使用，以及广泛的区域可用性。

注册管理员可以启用或禁用 实验性 模型，具体是在其注册的 AIP 设置 部分（位于 控制面板 ）中进行，这样模型目录便只会显示处于 稳定 生命周期阶段的模型。

  • 稳定： 稳定或正式发布（GA）的模型是经模型提供商和 Palantir 双方认可的可靠模型。这些模型提供强大的功能、有保障的支持，并专为长期生产使用而设计。模型的区域可用性因各模型提供商所提供的产品而异。您可以在 受支持的 LLM 文档 中查阅按区域划分的完整模型可用性列表，并可在模型选择器中查看各模型的状态信息。在收到模型提供商规定的下线日期后，Palantir 会将模型从稳定转为下线，并通过 升级助手通知用户这一变更。

  • 下线： 下线模型将在未来几个月内被弃用，具体时间由模型提供商确定并公布。在规定的弃用日期之后，下线模型不能再为新的工作流提供支持，但仍可能支持现有工作流。与稳定模型相比，下线模型将不会获得同等水平的技术支持。在收到模型提供商规定的弃用日期后，Palantir 会将模型从下线转为已弃用，并通过 升级助手通知用户这一变更。如需了解有关下线模型的更多信息，请查阅 模型弃用文档。

  • 已弃用： 在其停用期结束后，Palantir 会与模型提供商协调，从 Foundry 中移除或弃用模型。已弃用的模型无法支持现有工作流（包括新的 API 调用），因此项目必须在模型被弃用之前迁移到稳定的模型，以维持功能。Foundry 会保留已弃用模型的历史数据和日志，并确保其可被访问。有关已弃用模型的更多信息，请查阅 模型弃用文档。

  • 类型

    • 补全模型： 补全模型旨在通过预测和补全输入文本来生成与上下文相关的文本。这使其适用于内容生成、自动补全、翻译和问答等任务。
    • 嵌入模型： 嵌入模型将单词和句子等离散数据转换为连续的向量表示。它最常用于语义搜索和其他信息检索用例。
    • 视觉模型： 视觉模型经过训练，可以分析和解释视觉输入，从而能够识别对象、对图像进行分类，并支持针对图像和视频数据的各种计算机视觉任务。

  • 模型创建者

    • 模型创建者是指负责创建、开发和维护特定 LLM 的组织。示例包括 OpenAI、Anthropic、Google Gemini 和 Mixtral AI。模型创建者可以直接提供其 LLM，也可以通过与其他组织的合作来提供，例如 OpenAI 通过 Azure 提供，Anthropic 通过 AWS 提供。某些模型可能由 Palantir 提供和托管，例如 Llama 和 Mixtral。

如果某个模型不可用或显示为灰色，则表示该模型未针对您的注册启用。要启用某个模型，请联系您的平台管理员或 Palantir 代表。

了解有关模型启用的更多信息。

模型实体页面

每个模型都有一个实体页面，其中包含三个主要部分：

  • Playground： 供构建者试用不同模型的界面。
  • 如何使用： 首先创建一个资源，其中已预先填充了开始构建工作流所需的内容。模型目录目前支持函数和转换。
  • 模型描述： 基本描述、法律免责声明、模型的上下文窗口（如 token 限制）、训练数据截止日期等。

模型比较页面

模型目录比较页面允许构建者高效地比较和评估各种 LLM 的性能。该界面允许用户选择两个 LLM，并在相同的补全或视觉任务上对它们进行测试。这有助于做出明智的决策，使构建者能够快速选择最适合其工作流程的模型。
