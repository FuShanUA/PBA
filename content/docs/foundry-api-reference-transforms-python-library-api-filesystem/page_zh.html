transforms.api.FileSystem

class transforms.api.FileSystem(foundry_fs, read_only=False)

一个用于在 Spark 转换中读取和写入原始数据集文件的文件系统对象。

有关轻量级单节点转换，请参阅 transforms.api.FoundryDataSidecarFileSystem。

files(glob=None, regex='.*', show_hidden=False, packing_heuristic=None)

创建一个 DataFrame ↗ ，其中包含此数据集中可访问的路径。

该 DataFrame ↗ 按文件大小进行分区，其中每个分区包含的文件路径的总大小至多为 spark.files.maxPartitionBytes 字节；如果单个文件大于 spark.files.maxPartitionBytes，则该文件将单独占用一个分区。文件大小的计算方式为其在磁盘上的文件大小加上 spark.files.openCostInBytes。

  • 参数：
    • glob (str ↗ , 可选) – Unix 文件匹配模式。还支持 globstar。
    • regex (str ↗ , 可选) – 用于匹配文件名的正则表达式模式。
    • show_hidden (bool ↗ , 可选) – 包含隐藏文件，即以“.”或“_”开头的文件。
    • packing_heuristic (str ↗ , 可选) – 指定用于将文件装箱到 Spark 分区的启发式算法。可选值为 ffd (首次适应递减)或 wfd (最差适应递减)。虽然 wfd 往往会产生不太均匀的分布，但其速度要快得多，因此 wfd 是包含大量文件的数据集的推荐选择。如果未指定启发式算法，系统将自动选择一种。
  • 返回： 一个由 (path, size, modified) 组成的 DataFrame
  • 返回类型： pyspark.sql.DataFrame ↗

属性 hadoop_path

获取数据集的 Hadoop 路径，可用于需要直接进行 Hadoop IO 的代码。

  • 返回： 支撑该 FileSystem 的数据集的 Hadoop 路径或 None
  • 返回类型： string

ls(glob=None, regex='.*', show_hidden=False)

从数据集的根目录开始，递归遍历所有目录，并列出与给定模式匹配的所有文件。

  • 参数：
    • glob (str ↗ , 可选) – 一种 Unix 文件匹配模式。还支持 globstar。
    • regex (str ↗ , 可选) – 用于匹配文件名的正则表达式模式。
    • show_hidden (bool ↗ , 可选) – 包含隐藏文件，即以 ‘.’ 或 ‘_’ 为前缀的文件。
  • 生成： FileStatus – 逻辑路径、文件大小（字节）和修改时间戳（自 1970 年 1 月 1 日 UTC 以来的毫秒数）

open(path, mode='r', **kwargs)

以给定模式打开 FoundryFS 文件。

  • 参数：
    • path (str ↗) – 文件在数据集中的逻辑路径。
    • mode (str ↗) – 文件打开模式，默认为读取。
    • **kwargs – 其余关键字参数将传递给 io.open() ↗.
  • 返回： 一个附加到流上的 Python 类文件对象。
  • 返回类型： File
