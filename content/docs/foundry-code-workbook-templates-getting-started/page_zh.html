def bar_chart_of_row_counts(titanic_dataset):
    import matplotlib.pyplot as plt
    from pyspark.sql import functions as F
    import numpy as np

    input_df = titanic_dataset
    categorical_column = "Sex"

    # calculate the counts
    total = input_df \
        .groupBy(categorical_column) \
        .agg(F.count("*").alias("count")) \
        .orderBy("count")

    # convert summarized dataset to pandas
    total_pdf = total.toPandas()

    # plotting code
    fig = plt.figure()
    ax = fig.add_subplot(111)

    y_pos = np.arange(len(total_pdf[categorical_column]))
    ax.set_yticks(y_pos)
    ax.barh(y_pos,total_pdf["count"])
    ax.set_yticklabels(total_pdf[categorical_column])
    plt.xlabel("count")
    plt.ylabel(categorical_column)

    plt.tight_layout()
    plt.show()

    # return the aggregated dataframe to save it as a dataset
    return total

当您运行此转换时，上面显示的图表将出现在您的 Workbook 中图形的转换节点里。您还可以将鼠标悬停在转换节点中的图表上并选择 查看图像来进入全屏图像视图。也可以从内容侧边栏和可视化选项卡访问此图像查看器。

创建模板

接下来，将此转换转换为模板，以便进行泛化和重用。点击 操作 代码编辑器右上角的按钮，然后点击 创建模板.

您现在将进入全屏编辑器中的模板创建视图。 在模板编辑器中，您可以编辑模板的名称、描述和参数。将此模板命名为 Bar Chart of Row Counts by Categorical Variable，并为其添加如下描述： Create a transform with a bar chart of the row counts of 1 categorical column in any input dataset.

任何输入数据集——在本例中，只有 titanic_dataset ——都会自动添加为类型为 dataset 的模板参数。点击 titanic_dataset 在模板编辑器中进行更改。由于此模板应该是通用的，请将参数名称从 titanic_dataset to input_dataset 更改，并添加描述。

这会将代码的此部分添加为类型为 column 的参数，源数据集为 input_dataset。在模板编辑器中，编辑 param1 参数名称并将其重命名为 selected_column.

在本示例代码中，我们在转换顶部将列名定义为变量，因此只需对其进行一次参数化。在对其他转换进行模板化时，您可以使用 将 按钮来添加同一参数的更多实例。

接下来，选择此模板是否应默认保存为数据集。勾选 保存为数据集 复选框后，添加模板时将默认作为持久化转换添加。如果 保存为数据集 保持未勾选状态，模板将默认作为非持久化转换应用。在本例中，请选择默认保存为数据集，因为输出将在其他应用程序中使用。

最后，点击 创建模板 按钮以创建并保存模板。每当您创建新模板时，都需要选择一个文件夹来保存它。在本示例中，您可以将模板保存在您的主文件夹中。

模板只能被拥有访问权限的用户发现和使用，因此您可以在仍在处理模板时将其保存在主文件夹中，待想要推广供更广泛使用时再将其移动到共享文件夹。模板还可以添加到 数据目录.

使用模板

创建并保存模板后，您可以通过点击操作的方式使用模板。

要查看可用模板，请点击 浏览所有模板 在转换创建视图中。

浏览模板支持按名称、描述和标签搜索模板，也可以基于收藏夹、最近使用的模板或文件结构进行浏览。要应用模板，请点击其名称并选择"选择"。添加你刚刚创建的模板。

将模板添加到图中后，你可以重命名该转换并填写输入。分配 input_dataset 参数，方法是点击 点击此处添加数据集 并点击 titanic_dataset 在图中。现在你可以选择任意列作为 selected_column 参数，以基于该列创建图表。

选择 运行 来计算该转换。对于输出可视化的转换，图视图是图中的默认视图。你可以右键点击并选择 编辑 用户偏好 显示表格视图 以表格形式查看该节点。

编辑模板
