分析类型

Foundry 分析套件同时支持点选式分析（无代码或低代码）和基于代码的数据分析，并提供针对不同分析和数据源类型优化的工具，以及用于仪表板和报告的工具。

工具和支持的工作流程摘要如下：

点选式分析基于代码的分析
表格数据Contour代码仓库（Code Repositories）
对象数据（本体论）Insight、Quiver
时间序列数据的流可在代码仓库（Code Repositories）
地图（地理空间）数据Map、Contour、Quiver、Insight

点选式分析

Foundry 提供多种点选式分析工具：Contour、Insight 和 Quiver。

  • Contour 支持对 表格数据 进行大规模数据分析。
  • Insight 专为运营用户设计，用于分析本体论并创建 对象集.
  • 的流可在 支持高级本体论分析、仪表板创建以及 时间序列 data.

此外， 对象浏览器 是一个用于 本体论层 的搜索和发现工具，支持跨本体论搜索并查找单个对象。

Contour、Insight 和 Quiver 允许您：

  • 无需代码即可对数据进行可视化、筛选和转换。
  • 利用表达式语言进行更高级的转换和聚合。
  • 组织复杂的分析。
  • 创建交互式仪表板，让其他人以引导式、结构化的方式探索和研究数据。
  • 与同事分享分析结果。

在下方详细了解这些工具所优化的具体使用场景。

Contour

Contour 适用于以下分析用例：

  • 您要使用的部分或全部数据未映射到本体论中： 一般来说，我们建议尽可能使用 本体论层 尽可能将数据映射到本体论，但在某些情况下这可能并不合适，例如不会再次清洗或复用的一次性上传。并非所有数据都适用于本体论层。例如，Contour 可用于查看管道中的中间数据集。
  • 您需要对超大数据集进行操作： Contour 旨在促进对超大数据集的分析操作，而 Quiver 支持最多 50,000 行的对象聚合。
  • 您希望将分析结果作为新数据集共享，以便在其他 Foundry 工具中使用。 了解如何将结果保存为数据集.
  • 您希望构建参数化分析，以便在不同数据视图和结果之间轻松切换。

了解如何开始使用 Contour。

Insight

Insight 适用于以下分析场景：

  • 您的数据已映射到本体论中： Insight 利用本体论数据，例如对象类型、接口、关联类型和操作。
  • 您需要在无代码的情况下执行临时分析： 可视化分析路径使您可以逐步构建复杂查询，同时支持简单和复杂的下钻工作流程。
  • 您希望探索对象之间的关系： 直方图 关联 步骤允许您沿着关联查找本体论中相互连接的对象，并根据关联属性筛选数据。
  • 您希望将数据写回本体论： Insight 支持根据您的分析结果创建、更新和删除对象。

对象浏览器

用户可以在其中进行简单的基于对象的分析工作流 对象浏览器。Object Explorer 是一个搜索和分析工具，用于解答有关本体论层中任何内容的问题。用户可以在 Object Explorer 中以可视化方式构建搜索查询，从简单的筛选到 Search-around，以找到感兴趣的对象。Object Explorer 适用于以下分析工作流：

  • 您想要在整个本体论中搜索词条： Object Explorer 提供了一个搜索入口，用于在整个本体论中查找对象或对象类型。搜索结果页面支持查看对象实例和对象类型结果。
  • 您想要探索某个对象类型及其属性： Object Explorer 是查找相关对象数据和查看 Object Views 的绝佳起点。
  • 您的最终目标是创建相关对象的列表（对象集）： Object Explorer 支持创建对象探索和对象列表，以便与他人共享或在其他应用程序（如 Quiver 或 Insight）中使用，以进行进一步分析。 了解有关探索和对象列表的更多信息。

代码仓库（Code Repositories）

Code Workbook 是一款应用程序，允许用户使用直观的图形界面来分析和转换数据。

Code Workbook 的设计秉持以下原则：

  • 迭代速度： 用户可以快速测试并优化转换与可视化逻辑，从而得出有效结果。
  • 低门槛： Code Workbook 的图形界面以及对使用预编写逻辑的支持，旨在让具有不同技术水平的用户都能轻松上手。
  • 协作： 不同用户群体可以共享逻辑，并在 Code Workbook 中协同完成同一项分析。
  • 模型创建： 用户可以在 Code Workbook 中迭代 Foundry 模型，并轻松查看模型阶段和指标。然后可以将模型提交到建模目标（Modeling objectives）并在运营中使用。
  • 平台互操作性： 用户可以通过将可视化添加到 Notepad 并将可用于生产环境的管道提升到 Code Repository，从而在整个平台上将其成果投入生产。

Code Workbook 的主要功能包括：

  • An 交互式控制台 ，可快速迭代转换逻辑并进行临时数据探索。
  • 可视化支持 ，可使用常用软件包（Matplotlib、Plotly、Seaborn）创建详细且可交互的图像。
  • 模板 ，可通过简单界面复用复杂且特定领域的逻辑。
  • 支持 多种语言 （Python、SQL、R）的代码和模板，允许用户为分析选择最佳语言，并在单个分析中利用多种语言。
  • 分支 ，通过隔离不同用户的修改来促进协作。
  • An 直观的用户界面 ，便于自定义 Spark 环境及设置转换的输入类型，并查看节点间的关系。

了解如何开始使用 Code Workbook。

Code Workbook 并未针对构建生产管道进行优化。如果您正在构建或维护生产管道，请使用 Code Repositories 应用程序，它包含版本历史、分支和拉取请求以及其他对构建稳健管道至关重要的功能。更多信息请参阅 Foundry 中用于编写基于代码的转换的工具的此对比。
