代码仓库中的“重置”选项是如何工作的？

“重置”选项相当于一次 git reset 操作，即丢弃该分支所有未提交的更改，并将该分支重置为最新提交。

主题链接： https://community.palantir.com/t/reset-button-in-code-repositories/744 ↗

有没有办法基于输入数据集的历史版本来预览或构建转换？

具体来说，在代码仓库中，无法选择特定的输入事务（请参阅现有的 Input 类参数）。不过，你可以调用 createBranch 端点，该端点接受一个 transactionRid 参数，该参数可以设置为之前的事务。然后，你就可以在转换中使用这个分支（branch 是 Input 类的一个参数）。

此外，处理历史数据最简单的方式是使用 Contour：你可以非常轻松地将输入数据集的版本更改为之前的版本，请参阅 文档。

主题链接： https://community.palantir.com/t/preview-on-historical-dataset/189 ↗
