身份验证

对 Slack 的身份验证使用持有者令牌（bearer token）执行。可以使用与 Slack 工作区中已安装的 Slack 应用关联的机器人用户令牌来提供该令牌。

使用机器人令牌可以创建持久且持久的源，而不会直接关联到单个用户。要创建 Slack 应用并获取其机器人令牌，请按照 Slack 文档中的步骤操作：

  • 在目标工作区中创建 Slack 应用。↗
  • 为应用配置所需的作用域。↗
    • 请参阅 权限 以了解所需作用域的详细信息。
  • 将应用安装到目标工作区。↗
    • 应用安装可能需要 Slack 工作区管理员的批准。对应用作用域的任何添加也需要重新安装。
    • 安装完成后，请按照 Slack 文档中的步骤找到并复制已安装应用的机器人令牌，然后将其粘贴到 Data Connection 中 Slack 源的凭据设置中（参见 配置选项).

网络

Slack 连接器需要网络访问 slack.com 端口 443。如果您的源在 Foundry 中运行，请确保存在 出口策略 到该地址的访问权限。

对于在代理上运行的源，代理主机必须能够通过网络访问此域。

配置 Slack 同步

Slack 连接器支持高级同步配置，以确定将哪些数据以及多少数据引入 Foundry。

在探索可用的同步并将其添加到连接器后，导航至 编辑同步。在左侧的 同步 面板中，找到要配置的同步并选择 > （位于右侧）。

选项是否必填？描述
Table是选择要将 Slack 中的哪个表复制到 Foundry。请参阅 数据模型 以了解支持的表。
Column selectionNo选择要同步到 Foundry 的列的子集。请查看下方的 列选择 部分以了解更多信息。
Row filtersNo启用并添加筛选器，以根据列值移除不符合条件的行。请查看 行筛选器 部分以了解更多信息。
LimitNo向底层查询添加 SQL limit 子句。此设置可用于限制单次运行中同步到 Foundry 的行数。
IncrementalNo启用以将数据分小批量同步到 Foundry。请查看 增量式 部分以了解更多信息。

增量

通常，同步会导入目标表中所有匹配的行，无论数据在两次同步之间是否发生变化。相比之下，增量同步会维护有关最近一次同步的状态，并且仅从目标中摄取新的匹配行。

从 Slack 摄取大型表时可以使用增量同步。要使用增量同步，表必须包含一个严格单调递增的列。此外，所读取的表必须包含具有以下数据类型之一的列：

  • DATE
  • TIMESTAMP

数值列类型：

  • int
  • TINYINT
  • SMALLINT
  • INTEGER
  • long
  • BIGINT
  • NUMERIC
  • NUMBER
  • DECIMAL
  • DEC

字符串列类型：

  • string
  • VARCHAR
  • CHAR
  • NVARCHAR
  • NCHAR
  • LONGNVARCHAR
  • LONGVARCHAR

增量同步需要以下配置：

选项是否必填？描述
列是选择将用于增量摄取的列。如果表不包含任何支持的列类型，下拉菜单将为空。
Initial value是开始同步数据的起始值。

同步配置示例：

  • 直方图 Messages 表包含配置的持有者令牌有权访问的每个通道的所有非线程回复消息。
  • 该表有一个 CreatedTime 时间戳列，用于表示消息创建时间戳。
  • 可以将同步配置为仅使用 CreatedTime 列作为 增量列 来摄取新消息，以进行 APPEND 事务同步，并指定开始读取消息的初始起始时间戳值。
  • 运行初始同步时，将摄取在起始时间戳或之后创建的所有消息。
  • 在下一次同步中，仅摄取在上一次同步的最新 CreatedTime 时间戳或之后创建的消息。
  • 可以使用类似的增量同步配置，从 MessageReplies 表同步线程消息回复，使用其 CreatedTime 时间戳列。

列选择

选择要同步到 Foundry 的列。如果未选择任何列，则所有列都将同步到 Foundry。

所有列名必须以下划线或英文字母开头。列名只能包含下划线、英文字母或数字。

以下是有效列名的示例：

  • _colum_name
  • a_column_name_123

以下是无效列名的示例：

  • 1ColumnName；以数字开头。
  • a-column-name*；包含连字符和星号。
  • å-column-name；包含非英文字符。

行筛选器

可以添加筛选器以减少同步的行数，或单独选择哪些行将被同步到 Foundry 中。要配置行筛选器，必须成功预览表格。在配置行筛选器之前，我们建议使用以下方式刷新预览 Preview of inbound data 位于界面底部的部分。可以刷新预览以验证所添加筛选器的行为。

筛选器配置由一组条件组成，每行必须满足这些条件才能被同步到 Foundry 中。每组条件可以设置为在满足以下情况时匹配 all 所有条件匹配，或者 at-least one 个条件匹配。条件集可以嵌套，以便对导入内容进行更细粒度的控制并提供高度灵活性。这些等价于 AND 和 OR 标准 SQL 中的语句。

条件本身是对 Slack 中表格某一列的值与可在界面中输入的值之间的简单比较。例如，条件 CreatedAt 等于 12/04/2021 将仅导入那些其中 CreatedAt 列的值为 12/04/2021的行。列的数据类型决定了支持的比较操作。

比较操作

筛选器支持以下操作：

  • EQUAL TO
  • GREATER THAN
  • LESS THAN
  • GREATER THAN OR EQUAL TO
  • LESS THAN OR EQUAL TO
  • NOT EQUAL TO
  • IS NULL
  • IS NOT NULL

这些比较操作的行为与标准 SQL 中相应操作的行为等价。

字符串类型的列还支持 Like 和 Not like 使用标准 SQL-92 语法的运算符。
