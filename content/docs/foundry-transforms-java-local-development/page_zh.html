设置 Java 本地开发

可以对 Java 转换仓库进行本地开发，从而实现高速迭代开发。

为 Java 转换仓库设置本地开发

克隆仓库

  1. 在仓库的菜单栏中，选择 本地工作 并复制仓库 URI，也称为 "git remote URL"。

仓库 URI（git remote URL）包含与您的账户关联的敏感信息，不应共享。为维护平台安全，请勿 不 将此链接分享给其他人或公开发布。

  1. 使用命令行，运行 git clone <URI> 在本地计算机上您选择的目录中。然后使用 cd 命令导航到该仓库。

局限性

  • 为克隆授予的令牌是短期有效且只读的，但向您的仓库推送的情况除外。
  • 您仍需要将更改推送到 Foundry 以发布作业规范或工件，或者在您希望运行检查或构建时进行推送。

预览

数据集预览在本地开发中受支持。请参阅 本地预览 以了解更多详情。

设置开发环境

前提条件

  • 确保已安装 Java 17，并且环境变量 JAVA_HOME 指向正确的 Java 安装。您可以从以下链接下载 Java 17： Oracle 网站 ↗.

设置 JAVA_HOME 环境变量,具体取决于您的操作系统:

  • Windows:运行 SETX JAVA_HOME -m "<java-home-dir>" (在 PowerShell 中)。这会修改系统环境变量,您需要重启 shell 才能使更改生效。或者,您也可以运行 [System.Environment]::SetEnvironmentVariable("JAVA_HOME", "<java-home-dir>") 来设置 JAVA_HOME (在当前运行的进程中)。
  • Linux 或 macOS：运行 export JAVA_HOME=<java-home-dir>.
  • 请按照概述的步骤，确保您的仓库已升级到最新的模板版本 此处.

配置 IDE

  • 安装 IntelliJ Idea ↗ 在你的机器上。
  • 打开你的命令行终端，使用以下命令进入包含你的代码仓库的目录： cd ，然后运行 ./gradlew openIdea。此 Gradle 任务将生成一个 IntelliJ Idea 项目并将其打开。
    • 在 Windows 上， ./gradlew openIdea 命令必须在 Git BASH 中运行，而 Git BASH 内置于 Git for Windows ↗.

局限性

  • Gradle 命令必须在终端中使用 ./gradlew来运行，而不是使用 IntelliJ 的 Gradle 插件。
  • 本地开发适用于 Java 17 及以下的 Java 版本，目前尚不支持任何更高的 Java 版本。
