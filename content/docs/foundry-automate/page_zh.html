Automate

Automate 是一款完全向后兼容的产品，可取代 Object Monitoring ，成为平台中所有业务自动化的统一入口。

Automate 是一款用于业务自动化的应用程序。借助 Automate，您可以定义持续检查或按计划检查的条件，以及在满足指定条件时自动执行的效果。

条件可以是 基于时间的条件 （ 对象数据条件 构建于 Foundry 本体论之上（ Alert 具有优先级的对象 high 被添加时触发

可用效果：

  • 提交 Foundry 操作
  • 触发 AIP Logic 函数
  • 执行 Foundry 函数
  • 发送带附件的平台通知和电子邮件通知

若要详细了解如何配置效果（包括回退效果和执行设置），请参阅 效果 文档。

用例

Automate 可用于各种不同的自动化工作流，包括：

  • 定时发送报告与摘要： 指定时间，并将每周报告发送给预定义的收件人列表。由 Notepad、 Notepad 模板或 Contour 仪表板 生成的 PDF 可自动附加到电子邮件中。
  • 数据警报： 定义并监视对象集，并在满足特定数据条件时向用户发出警报；例如，当未解决的问题对象总数超过阈值时。
  • 工作流自动化： Automate 可用于自动对满足指定条件的对象数据执行操作。可以自动化的部分任务包括：
    • 检查数据异常，并自动将这些对象传入包含修复逻辑的操作，以解决该问题。
    • 监视建议或潜在操作，并在满足预先配置的事件和时间条件时自动应用它们。此类操作可能包括通过 Webhooks 向外部系统发起 API 调用，以直接在外部系统中应用变更。
  • 已监视的搜索： 配置自动化，以便在已保存的对象探索出现新结果或搜索的所有结果满足聚合条件时发出通知；例如，所有传感器对象中的最高温度超过阈值。

最佳实践

请遵循 性能最佳实践 以最大限度地减少计算资源消耗，并大规模高效地运行自动化。
