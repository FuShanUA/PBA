开始使用

在此之前，请先考虑学习批处理管道教程

以下说明将逐步介绍一个简单的 Java 数据转换。如果您刚开始接触数据转换，建议先学习批处理管道教程 如果希望用户在每次运行预览前手动确认，请开启 or 代码仓库 。

按照以下步骤开始编写您的第一个 Java 转换：

  1. 创建一个新的 Transforms Java 代码仓库。导航到一个项目，选择 + 新建 > 代码仓库，然后选择 Python 位于 “语言模板”下方的下拉菜单中）.

  2. 下载此示例数据集： Download titanic.zip。将该数据集导入 Foundry。

  3. 导航到您的代码仓库。您的数据转换代码位于 myproject/datasets/HighLevelAutoTransform.java。此文件中的示例代码已被注释掉，因此在继续之前请务必取消注释。

  4. 通过替换以下内容来更新输入数据集： /path/to/input/dataset 为您的 titanic 数据集的完整路径。

  5. 通过替换以下内容来更新输出数据集： /path/to/output/dataset 为您期望的输出数据集位置的完整路径。

  6. 修改默认的转换代码，以根据性别筛选 titanic 数据集，获取所有女性乘客。在以下位置更新您的数据转换代码： my_compute_function:

@Compute
// Replace this with the full path to your output dataset.
@Output("/path/to/output/dataset")
// Replace this with the full path to your "titanic" dataset.
public Dataset<Row> myComputeFunction(@Input("/path/to/input/dataset") Dataset<Row> myInput) {
    return myInput.filter(myInput.col("Sex").equalTo("female"));
}

  7. 成功将更改提交到您的分支后，您就可以打开并构建您的输出数据集了！

此示例定义了一个使用自动注册的高级转换。有关 Transforms Java 支持的不同类型的数据转换的更多信息，以及模板项目结构和包含文件的说明，请参阅 此文档.
