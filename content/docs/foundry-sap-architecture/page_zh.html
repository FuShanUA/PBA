有关将 SAP 数据与 Foundry 集成的 SAP 认可架构，请参阅 （如果使用代理 worker）。。SAP Data Accelerator 通过 SAP Cloud Connector 将流量路由到安装在您的 SAP 环境中的 ABAP 附加组件。

以下三种模式描述了附加组件的安装位置及其访问源 SAP 系统的方式。使用 SAP Data Accelerator 时，请配置一个 您必须正确配置出站策略（如果使用 并按照 SAP Data Accelerator 设置指南.

直接连接到 SAP ERP 或 BW 系统

在此场景中，Palantir Foundry Connector 2.0 for SAP Applications（"Connector"）直接安装在包含待读取数据或承载待执行函数/查询的 SAP ERP 或 Business Warehouse (BW) 系统上。

通过 SAP SLT Replication Server 连接到 SAP ERP 系统

在此场景中，Connector 安装在 SAP SLT Replication Server 上，并在该服务器与源 ERP 系统之间建立远程函数调用 (RFC) 连接。基于数据库触发器，数据从每个源 ERP 表复制到 SLT 系统中相应的 Operational Delta Queue (ODQ)。

通过网关连接到远程 SAP ERP 系统

此场景适用于源 ERP 系统不满足安装 Connector 的最低要求的情况（SAP_BASIS 是同时适用于 SAP NetWeaver 和 SAP S/4HANA 系统的技术组件版本，需为 7.4 SP5 或更高版本）。在此场景中，Connector 的主要组件安装在满足最低要求的"网关"应用服务器上，并在该服务器与源 ERP 系统之间建立 RFC 连接。Connector 的远程代理组件安装在源 ERP 系统上，用于协助读取数据或执行函数/查询。
