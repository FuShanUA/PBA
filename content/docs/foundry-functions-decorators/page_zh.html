装饰器

以下文档专门针对 TypeScript v1 函数。如需更 强大的功能（包括对本体论 SDK 的支持和可配置的资源请求），我们建议 迁移到 TypeScript v2。

TypeScript ↗ 函数被声明为 TypeScript 类 ↗的方法。函数若要被发现和发布，需满足以下几个要求：

  • 该方法必须是 public
  • 该方法所属的类必须从 functions-typescript/src/index.ts 文件中导出
  • 该方法必须使用从 @foundry/functions-api 包导入的以下装饰器之一进行装饰：
    • @Function() 用于通用函数。
    • @OntologyEditFunction() 用于支撑操作的函数。
      • 对象溯源信息可以选择性地通过 @Edits([object type]) 装饰器在使用@OntologyEditFunction() 方法时指定。
      • 对象溯源信息将在 @Edits([object type]) 装饰器缺失时，通过静态代码分析尽力推断。
    • @Query({ apiName: "userDefinedAPIName"}) 用于要通过 Foundry API执行的只读查询。请注意，此装饰器不应与 @Function 装饰器一起使用；应单独使用。

import { Function, OntologyEditFunction, Query, Integer, Edits } from "@foundry/functions-api";
import { Employee, Objects, ObjectSet } from "@foundry/ontology-api";

export class MyUsefulFunctions {
    @Function()
    public incrementNumber(x: Integer): Integer {
        return x + 1;
    }

    @Edits(Employee)
    @OntologyEditFunction()
    public updateName(employee: Employee, newName: string): void {
        employee.firstName = newName;
    }

    @Query({ apiName: "getEmployeesByName" })
    public async getEmployeesByName(name: string): Promise<ObjectSet<Employee>> {
        return Objects.search().employee().filter(employee => employee.firstName.exactMatch(name));
    }
}

任何私有方法或未使用相关装饰器修饰的方法都不会发布到函数注册表中。这允许用户创建辅助函数和实用工具，以供重用或组织代码。

重新发布

请注意，TypeScript 仓库中的每个函数都由其类名和方法名唯一定义——如果更改类名或方法名，该函数将以新的标识符发布。
