适用于 Visual Studio Code 的 Palantir 扩展

VS Code 工作区和适用于 Visual Studio Code 的 Palantir 扩展与微软没有任何关联，也未获得微软的背书。

适用于 Visual Studio Code 的 Palantir 扩展旨在集成您在 代码仓库 中看到的许多功能与 VS Code。该扩展的功能目前专注于 Python 转换。

访问该扩展

适用于 VS Code 的 Palantir 扩展既可以在 Palantir 平台中作为 VS Code 工作区的一部分使用，也可以作为可下载的扩展用于您本地版本的 VS Code。

如需在这些选项之间进行选择的指导，请查阅我们关于 如何在本地开发与 VS Code 工作区之间进行选择.

从 VS Code 工作区

Palantir 扩展在 VS Code 工作区中默认可用。请查阅 VS Code 工作区文档 以了解更多信息。

本地

Palantir 扩展也可用于本地开发，并且是 Python 转换本地开发的推荐方法。

即使您的注册中可以使用该扩展，您也可能没有在本地使用该扩展所需的权限。需要平台管理员启用本地扩展使用权限，他们可以通过 控制面板设置.

为了在本地进行预览，用户必须启用上述控制面板设置，并且对预览输入具有 downloader 权限，这些预览输入为 s3-proxy:datasets-read 和 api:datasets-read。这些是允许用户在本地下载整个数据集的特权操作，应谨慎授予。在无法授予用户此权限的情况下，仍可通过 代码工作区来使用 VS Code 开发者体验，以保证严格的数据控制。

1. 下载 Palantir 扩展

  1. 导航到 VS Code 工作区，然后选择屏幕右上角 VS Code 按钮旁边的设置图标。
  2. 选择 本地 VS Code 从下拉菜单中选择此项，以更改默认按钮语言。
  3. 选择更新后的 本地 VS Code 按钮，并按照弹出窗口中的说明下载该扩展。

注意：只有在您从未安装过该扩展的情况下，才需要下载该扩展。

适用于 Visual Studio Code 的 Palantir 扩展尚未在 Visual Studio Code Marketplace 中提供。目前您只能从 Palantir 平台下载该扩展。

2. 安装该扩展

通过执行以下步骤之一来安装该扩展：

  • 将 VSIX 文件拖放到 VS Code 的 扩展 侧边栏中，或者
  • 使用命令 Extensions: Install from VSIX...

3. 打开 Palantir 代码仓库

安装 Palantir 扩展后，您应该会在 VS Code 侧边栏上看到 Palantir 标志。在侧边栏中，您可以执行以下操作之一：

  • 打开您已克隆的 Palantir 仓库，或者
  • 选择 克隆仓库 来克隆一个新的 Palantir 仓库。为此，请打开一个 Palantir 仓库并复制 git 远程 URL 链接。
