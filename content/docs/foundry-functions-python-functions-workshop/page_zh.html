在 Workshop 中使用 Python 函数

前提条件

本指南假设您已经编写并发布了 Python 函数。请查阅 Python 函数入门 文档以获取教程。有关如何使用 Python SDK 查询本体论的示例，请参阅 Python 本体论 SDK 文档。

在 Workshop 中使用该 Python 函数

在 Workshop 中，从模块左侧的 变量 标签页中搜索该 Python 函数。 Serverless 函数和已部署函数 都会显示在此处。Serverless 函数始终可以在任意版本上运行，且无需手动部署。已部署函数会显示一个图标，该图标针对函数和函数版本分别显示以下三种状态之一：

  • 运行中： 此函数和版本可以处理请求。
  • 已停止： 此函数和版本不可用。在函数选择器中，将鼠标悬停在信息图标上，选择 配置 ，然后 创建并启动部署 ，使该函数可用。
  • 升级中： 此函数和版本尚不可用。

发布新版本

在任意给定时间，函数的代码仓库仅托管一个版本。为了以最短的停机时间对函数进行更改，我们建议添加一个新函数（例如 function_v1），并进行更改和打标签，详见 此处。从标签和发布下的已发布函数中，选择 在本体论管理器中打开。

在本体论管理器中，选择要在应用程序中使用的函数仓库版本，然后选择 升级。

将所有使用此仓库中函数的下游应用程序更新到你已部署的新版本。请注意，之前的部署版本将不再运行，因此在进行此更改时，你的应用程序将会有短暂的停机时间。你将拥有 function_v0 和 function_v1 ，两者同时可用，因此虽然你需要切换到新的部署版本，但无需更改你正在使用的函数。当 function_v0 不再被使用时，即可删除该函数。

调试错误

如果你的函数在 Workshop 中未按预期工作，请先检查问题是否与函数的逻辑或响应能力有关。如果问题出在逻辑上，请检查支撑代码仓库中的源代码。如果问题是函数无响应或抛出错误，请按照以下步骤操作：

  1. 请在函数选择器下拉菜单中检查您选择的版本当前是否正在运行。
  1. 如果该函数未部署或 Upgrading，请将鼠标悬停在该函数的信息图标上并选择 配置。这将带您进入 Ontology Manager，您可以在其中选择 开始部署 以使您的函数重新运行。
  1. 如果您的函数 Running ，或者您需要了解有关部署行为的更多信息，请在 Ontology Manager 的左侧面板中选择 部署 以查看详细日志。此外，若要查看 SLS 日志，请选择 实时查看。

创建函数支撑的列

要创建函数支撑的列，您必须发布满足以下要求的函数：

  • 函数的输入参数必须包含一个对象集参数（导入自 ontology_sdk.ontology.object_sets），并可选择包含其他输入参数。此对象集参数将使表中显示的对象能够传入函数，进而生成所需的派生列。请注意， list[ObjectType] 参数在这里也适用，但并不推荐这种性能较低的选项。

  • 函数的返回类型必须为 dict[ObjectType, ColumnType]，其中 ColumnType 是该列所需的 类型 ，或者 dict[ObjectType, CustomType] 以从函数返回多个列。要了解更多信息，请参阅 自定义类型。

配置并发布满足上述条件的函数后，您可以在 对象表格 小部件配置中配置函数支撑的属性列。

from functions.api import Date, Integer, String, function
from ontology_sdk import FoundryClient
from ontology_sdk.ontology.object_sets import MyObjectTypeObjectSet
from ontology_sdk.ontology.objects import MyObjectType

@function
def function_backed_column_single_col(
    selected_objects: MyObjectTypeObjectSet
) -> dict[MyObjectType, Integer]:
    final_dict = {}

    for curr_obj in selected_objects:
        final_dict[curr_obj] = 10 # The value can be defined for any arbitrary logic

    return final_dict

from dataclasses import dataclass

@dataclass
class CustomType:
    column_name_a: int
    column_name_b: int

@function
def function_backed_column_multiple_cols(
    selected_objects: MyObjectTypeObjectSet, some_other_parameter: String
) -> dict[MyObjectType, CustomType]:
    final_dict = {}

    for curr_obj in selected_objects:
        final_dict[curr_obj] = CustomType(column_name_a=10, column_name_b=20)

    return final_dict
