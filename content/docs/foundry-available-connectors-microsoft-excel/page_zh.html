Microsoft Excel

Microsoft Excel 连接器是一个 由 Palantir 提供的驱动程序 ，用于 Microsoft Excel。

要创建新的 Microsoft Excel 源，请按照 Palantir 提供的驱动程序的标准设置流程，然后使用以下各节进行 Microsoft Excel 特定的配置和网络设置。有关完整的属性参考，请参阅 官方 Microsoft Excel 驱动程序文档 ↗.

简介

Microsoft Excel 连接器从文件存储中读取工作簿，并将其工作表和单元格区域公开为关系表。

读取操作可能会修改工作簿

要在不更新工作簿的情况下读取存储的公式值，请设置 Recalculate ↗ to FALSE，尤其是在其他进程也向该工作簿写入数据时。默认情况下，连接器在读取时会重新计算受已更改单元格影响的公式，并将结果写回工作表。

对于计划读取，请使用 功能允许将外部系统的数据同步到Foundry 以将这些表写入数据集。参见 写入数据 以更新工作簿。

要从计算机一次性上传 Excel 文件， 将其拖入 Foundry.

支持的存储系统包括 Amazon S3、Azure Blob Storage、OneDrive、SharePoint 和 SFTP 服务器。参见 ConnectionType 参考文档 ↗ 以获取完整列表。

选择 Excel 连接器

Palantir 提供三种 Excel 连接器，适用于不同的存储位置和访问方法。

连接器使用场景：
Microsoft Excel（本页面）您需要从存储在受支持的文件存储系统中的工作簿将工作表和单元格区域读取为关系表。
Microsoft Excel Online您需要通过 Microsoft Graph 访问 OneDrive for Business 或 SharePoint Online 中的工作簿，并使用 Microsoft Entra ID 身份验证。
Microsoft SharePoint Excel您需要访问本地 SharePoint Server 2010 或 2013 部署中的工作簿。对于 SharePoint Online，请使用 Microsoft Excel Online。

当您的工作簿具有一致的表格结构，并且需要将工作表或单元格区域直接公开为源表时，请使用 Microsoft Excel 连接器。

如需在工作表选择、单元格区域、数据类型和工作簿特定解析方面获得更大的灵活性，请使用其存储连接器将工作簿作为文件摄取。存储连接器包括 Amazon S3, Microsoft OneDrive, Microsoft SharePoint日 Google Drive。然后在转换中使用 转换的 Excel 解析器Workshop parseExcel 函数 在 Pipeline Builder 中进行解析，或使用诸如 pandas.read_excel or openpyxl.

身份验证

要对保存您工作簿的存储系统进行身份验证，请设置 ConnectionType 为相应的存储系统。请查阅 CData ConnectionType ↗ 和 AuthScheme ↗ 文档以了解支持的身份验证方法和所需属性。

例如，要使用委托的 Microsoft Entra ID 身份验证访问 OneDrive 中的工作簿，请设置 ConnectionType to OneDrive, AuthScheme to AzureAD日 InitiateOAuth to REFRESH。提供您应用程序的 OAuthClientId 和 OAuthClientSecret，然后按照 OAuth 2.0 身份验证 指南操作。

读取数据

要将 Excel 数据读取到 Foundry 中，请在源资源管理器中选择一个工作表并 设置批量同步.

每个工作表都是 CData 目录下的一个表，其架构为该工作簿。要发现多个工作簿，请设置 URI 为文件夹而非单个文件。连接器将发现该文件夹中的工作簿。

Excel 列可以包含不同类型的值，因此包含数字的列可能会被读取为文本。要将这些值用作数字，请在同步后在转换中转换列类型。

要允许源连接到您的存储系统，请添加一个 网络出口策略 用于其存储和身份验证端点。所需的端点取决于所选的 ConnectionType, AuthScheme、存储账户和区域。

如果存储系统无法从 Foundry 直接访问，请配置一个 代理出口策略 ，并确保代理主机可以访问所需的端点。

from io import BytesIO
from typing import Any

from openpyxl import load_workbook


def read_worksheet_rows(
    workbook_bytes: bytes,
    worksheet_name: str,
) -> list[dict[str, Any]]:
    workbook = load_workbook(
        BytesIO(workbook_bytes),
        read_only=True,
        data_only=True,
    )
    try:
        worksheet = workbook[worksheet_name]
        rows = worksheet.iter_rows(values_only=True)
        raw_headers = next(rows, None)
        if raw_headers is None:
            return []

        headers = [
            str(header) if header is not None else f"column_{index + 1}"
            for index, header in enumerate(raw_headers)
        ]
        return [
            dict(zip(headers, row))
            for row in rows
            if any(value is not None for value in row)
        ]
    finally:
        workbook.close()

from io import BytesIO
from typing import Any

from openpyxl import load_workbook


def update_workbook_cell(
    workbook_bytes: bytes,
    worksheet_name: str,
    cell_reference: str,
    value: Any,
) -> bytes:
    workbook = load_workbook(BytesIO(workbook_bytes))
    try:
        workbook[worksheet_name][cell_reference] = value
        output = BytesIO()
        workbook.save(output)
        return output.getvalue()
    finally:
        workbook.close()

局限性

  • .xlsm 工作簿是只读的。 该驱动程序支持 仅读取操作 ↗ 针对启用宏的工作簿。请对另存为 .xlsx instead.
  • 旧版 .xls 格式不受支持。 只能读取 Microsoft Excel 2007 及更高版本生成的 Office Open XML 格式。
  • 要检查你的编辑库是否保留了工作簿的内容，请先在副本上测试下载、编辑和上传工作流。例如， openpyxl 不会保留所有工作簿功能 ↗，包括某些形状。
