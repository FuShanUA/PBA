角色在 Foundry 设置的“角色”部分中进行管理。

自定义默认角色

要为您的组织自定义角色，您必须在 Control Panel 中被授予组织管理员权限。

理解角色和操作

要理解角色自定义，我们需要再深入一层来了解操作。

操作是 Foundry 应用程序检查的单个权限，用于验证用户是否有权限执行给定操作。角色是操作的集合：当您在某个资源（如项目或数据集）上授予某人角色时，您就是在授予他们对该资源及其下所有子资源的一组操作。每个操作都有一个名称和唯一标识符。

例如，默认 Owner 角色中包含（但较低级别角色中不包含）的一个操作名为“更改默认分支”（标识符为： stemma:mutate-default-branch），它允许您更改代码仓库的默认分支。当您在项目上授予用户 Owner 角色时，该用户将被授予 stemma:mutate-default-branch 该项目中所有资源上的此权限，因此他们可以更改其中任何代码仓库的默认分支。

创建自定义角色

角色管理界面位于平台设置页面的“角色”选项卡下。

您可以创建自己的全新自定义角色。您可能希望创建自己的自定义角色，以支持组织中不同类型的用户，例如下面详述的 Merger or Supporter 角色。

要创建自己的自定义角色，只需点击“新建角色”，系统将弹出“新建角色”对话框：

您可以“包含”其他角色。对于上面的新 Merger 角色，其中包含了 Viewer 角色，这意味着 Viewer 授予的所有权限都将在 Merger 角色中被授予。创建后，您可以通过添加更多操作来自定义此角色。

编辑默认角色

您只能为自定义 角色集编辑默认角色（例如 Viewer）。因此，要自定义组织的角色，您首先需要创建一个由默认角色组成的自定义角色集，然后即可编辑这些默认角色。

例如，如果您希望实例上的所有 Editor 都能够更改仓库的默认分支，只需编辑 Editor 角色以包含此操作即可。

自定义角色示例

以下是一些自定义角色示例，如果它们适用于您的情况，您可以创建这些角色。

Merger

Merger 角色提供合并到受保护分支的能力，应在 Viewer 角色之外额外授予。创建一个包含以下操作的自定义角色：

  • 管理 Artifacts 仓库
  • 合并到受保护分支
  • 合并拉取请求
  • 更新拉取请求

Supporter

Supporter 能够查看与项目相关的问题，但无法查看任何元数据（如 schema、数据集名称等）。这主要面向 Palantir 或第三方支持团队，他们可能尚未加入或未被授权查看某些数据。可以通过包含以下操作来创建 Supporter 角色：

  • 应用分配规则
  • 归档问题
  • 编辑问题
  • 关闭并重新打开问题
  • 查看问题

角色集

角色集是一组角色，允许在组织级别自定义角色权限，并在特定上下文中使用，例如在项目或本体论中。角色集在以下情况下增加了灵活性： 组织 在同一个 注册 中的用户需要不同的角色时。角色集提供以下保证：

  • 同一集中的角色不依赖于该集之外的任何角色。
  • 所有角色属于且仅属于一个角色集。
  • 集中的角色属于同一组织，并被统一授予权限。
  • 角色集中的角色设计为在同一上下文中协同工作。目前，角色集可用的三种上下文是 Project 上下文、本体论上下文和 Marketplace Installation 上下文。

每个注册（enrollment）都至少有三个默认角色集：Project 默认角色集（Owner、Editor 等）、本体论默认角色集（Ontology Owner、Ontology Editor 等）以及 Marketplace Installation 默认角色集（Marketplace Installation Editor、Marketplace Installation Viewer 等）。默认角色集及其中的角色对所有组织始终可用。

创建新角色集

角色管理员必须拥有 Manage roles and role sets 其所管理角色的组织上的权限。该权限在 Control Panel 中通过 Organization Administrator 角色授予。只有拥有此权限的管理员才能为组织创建新角色集，并自定义属于该组织的角色集中的现有角色。

要为特定组织自定义角色，管理员应首先创建新的角色集。

为此，请执行以下操作：

  1. 输入 平台设置 旁的复选框，并点击 创建角色集 位于右上角的角色部分下。
  2. 填写新角色集表单。

创建新角色集时，管理员需要从现有角色集中复制角色。之后，管理员只需在现有角色集的基础上进行相关更改即可。

此外，在复制 Project 默认角色集或依赖于 Project 默认角色集的其他角色集时，新复制的角色集将随 Project 默认角色集的任何角色更新而自动更新。随着 Foundry 的持续开发，Palantir 可能会添加新角色；自动接收这些权限更新可以减少未来的管理工作。

创建上述角色集后，任何拥有 Manage roles and role sets Org B 权限的管理员都可以编辑这个新角色集。

应用角色集

角色集只能在空间级别应用。该空间内的所有 Project、文件夹和文件只能使用空间设置中所应用角色集中定义的角色。要进行管理，管理员可以：

  1. 通过导航到模块的 空间管理 页面中访问这些指标，该页面位于 控制面板.
