配置旧版对象视图

要访问旧版对象视图配置，请导航至某个对象类型的对象视图编辑器，选择 管理标签页 齿轮图标，然后将鼠标悬停在某个标签页上以选择 在旧版编辑器中打开 图标。

配置标签页

基于小组件的旧版标签页会显示按分区组织的小组件列表。您可以在标签页设置中添加、删除和重新排序小组件，或导航至其他设置。

配置小组件

旧版对象视图标签页的构建块称为 小组件。小组件有时也称为 分区 或 插件。小组件是在对象视图上显示某种形式的数据的主要方式。使用小组件可将数据可视化为 KPI 或图表、安排整个对象视图的布局，并操控所显示的数据。

对象视图中提供多种小组件类型：

  • 属性和关联
  • 可视化
  • 筛选器
  • 布局
  • 嵌入其他应用程序和文件

特定于小组件的设置

小组件用于可视化或操控与对象相关的数据。 小组件通常访问以下内容之一：

  • 当前对象的属性
  • 与当前对象关联的对象
  • 对与当前对象关联的对象的属性进行的聚合

在对象视图上配置组件时，请确定要可视化的对象及属性。您必须事先在本体论元数据中设置相关对象并定义关联。

每个组件的具体设置因其提供的功能而异。一般来说，组件特定配置包含两个主要部分：

  • 该 对象模型 配置需要选择对象或关联对象以及要使用的属性。例如，配置图表时，您可能需要按目的地聚合机场中的所有航班。
  • 该 视觉 配置需要选择图表类型、颜色、格式、文本标签等选项。

组件格式设置

所有组件均具有默认格式设置：

常规

  • 标题： 添加要在组件头部显示的标题。默认情况下，显示内容为组件名称或空白。必须为组件添加标题后才能保存。
  • 图标： 选择要在组件头部左上角显示的图标。每个组件都有默认图标。
  • 帮助信息： 默认为空，您可以添加文本向用户说明该组件。

布局

  • 对齐： 您可以选择小部件是占满对象视图的整个宽度，还是设置为右对齐或左对齐，以便将两个小部件并排放置。默认情况下，对齐方式设置为全宽。
  • 尺寸： 并非所有小部件都提供尺寸设置。当该设置可用时，您可以控制对象视图内相应部分的最小高度和最大高度。

复用小部件配置

您可以通过复制 YAML 配置来复用之前创建的小部件的配置。在对象视图编辑界面的右上角选择代码图标即可访问该配置。然后，将该配置复制并粘贴到新小部件的 YAML 配置中。
