关联

Links 部件用于显示对象之间的关联关系，并提供对这些路径的探索。配置 Links 部件的模块构建者可以：

  • 选择输入对象集，其中可以包含一种或多种对象类型
  • 选择要展开、显示和排序的具体关联

配置选项

Links 部件具有以下配置选项：

  • 输入数据
    • 导入对象集： 确定将在部件内显示的数据。模块构建者可以复用在此模块中其他位置创建的现有对象集变量，也可以内联定义新的对象集变量。在此处选择对象集后，下方的某些配置选项将变为可配置状态。
    • 从场景加载数据： 启用 场景 variables.
  • 关联类型配置
    • 要显示的关联类型： 默认情况下，关联部件中会显示所有关联。通过选择“指定关联类型”，可以配置细粒度控制和功能，例如关联级别的排序。更多详细信息请参见以下部分， 指定的关联配置选项.
    • 默认关联展开： 指定默认情况下在第一层级自动展开的关联数量。
  • 关联对象配置

    • 启用关联类型上的探索： 在每个关联类型级别，启用一个按钮以允许在 Object Explorer 中查看该关联类型。

    • 启用关联对象上的打开对象视图： 为每个关联对象启用一个按钮，以允许在 Object Explorer 中打开该关联对象的对象视图。

    • 启用悬停时的对象预览： 当悬停在关联对象的标题上时，预览该关联对象的属性。默认情况下，弹出窗口包含关联对象的重要属性，但可以通过指定关联来配置为自定义属性。

指定的关联配置选项

下图显示了 Links 部件及其配置面板在选择了 指定关联类型 时的初始状态：

Links 部件针对指定关联的配置面板选项如下：

  • 选择关联类型
    • 关联类型： 选择起始对象集后，从下拉列表中选择要在部件上显示的关联类型。
    • 关联类型标签覆盖： 可以用新标签覆盖该关联类型的标签。
  • 关联类型配置
    • 关联对象排序依据： 选择关联类型后，可以配置属性和排序方向。
  • 关联对象配置
    • 在对象预览中显示属性： 如果启用了“启用悬停时的对象预览”，则可以将指定关联类型的关联对象配置为在预览弹出窗口中显示其重要属性或指定属性。
