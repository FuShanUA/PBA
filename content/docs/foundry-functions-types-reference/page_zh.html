尽管两者 Integer 和 Long 都对应于 Python 类型 int，但任何直接在函数签名中标记为 int 的字段都将以类型注册 Integer。因此，我们建议改用 API 中的 Integer or Long 类型来注册数值数据类型。类似的准则也适用于 Float 和 Double；如果 Python 类型 float 直接出现在函数签名中，默认情况下它将被注册为 Float 。

标量类型

标量类型表示单个值，通常用于保存文本、数值或时间数据。

在 JavaScript 和 TypeScript 中，有一种 number 类型通常用于同时表示整数和浮点数值。为了提供进一步的类型验证和结构，我们仅支持从 @foundry/functions-api 包（用于 TypeScript v1 函数）和 @osdk/functions 包（用于 TypeScript v2 函数）导出的数值别名。类似地，在 Python 函数中处理数值类型时，我们建议使用从 functions.api 模块导出的类型别名。

3
4export class MyFunctions {

8        const employeeOne = Objects.search().employee().filter(e => e.id.exactMatch(1)).all()[0];
9        employeeOne.markingsProperty = markings;
10    }
11}

可选

  • 在 TypeScript 函数中，可选参数声明为 varName?: T or varName: T | undefined。例如，一个具有名为 value 的可选整数参数的函数 value?: Integer or value: Integer | undefined可以声明为以下两种形式之一。TypeScript 函数还可以通过指定 T | undefined类型来声明可选的返回类型。例如，一个可能返回 Integer 或不返回任何值的函数，其返回类型为 Integer | undefined.

结构体/自定义类型

自定义类型由其他受支持的类型（包括其他自定义类型）组成，并可在函数签名中使用。

  • 在 TypeScript 函数中，自定义类型是使用 interface 关键字定义的用户自定义 TypeScript 接口。

    • 可选字段可以通过以下方式支持：使用 ? 可选标记，或与 undefined.

  • 在 Python 函数中，自定义类型是用户自定义的 Python 类。

    • 要成为有效的自定义类型，该类必须符合以下要求：
      • 该类的所有字段都必须有类型注解。
      • 字段类型必须是受支持的类型；可以使用原始 API 类型或原生 Python 类型（如上表所定义）。
      • 直方图 __init__ 方法必须只接受与字段同名且具有相同类型注解的命名参数。
    • 直方图 dataclasses.dataclass ↗ 装饰器可用于自动生成符合这些要求的 __init__ 方法。

聚合类型

聚合类型可以从函数中返回，供平台的其他部分使用，例如 来运行该专业代码代理。你还可以通过.

中的图表。支持两种聚合类型：

  • A 二维聚合 将单个桶键映射到一个数值。例如，可用于表示诸如具有特定职位的员工数量之类的聚合。
  • A 三维聚合 将两个桶键映射到一个数值。例如，可用于表示按每个员工的职位和所属办事处统计的员工数量之类的聚合。

聚合可以按多种类型作为键：

  • 布尔 桶表示的值为 true or false.
  • 字符串 桶可用于表示分类值。
  • 范围 桶表示桶键为值范围的聚合。这些可用于表示图表中的直方图或日期轴。
    • 数值范围，包括 整数 and 双精度浮点数，表示对数值进行分桶的聚合。

对象集

有两种方式可以将对象集合传入和传出函数：对象的具体集合（例如数组），或对象集。

向函数传递对象数组可以在具体对象列表上执行逻辑，但需要预先将对象加载到函数执行环境中。而对象集（object set）则允许您执行筛选、search-around 和聚合操作，并且仅在您请求时才加载最终结果。

我们建议使用对象集而不是数组，因为对象集通常能实现更好的性能，并允许将超过 10,000 个对象传入函数。

下面的示例展示了如何在不将对象加载到内存的情况下筛选对象集，使您能够将筛选后的对象集返回到应用程序的其他部分。

通知

函数可以返回通知类型，以便灵活地配置应在平台中发送的通知。例如，您可以编写一个函数，接受诸如 User 和对象类型等参数，并返回带有已配置消息的通知。

  • A Notification 由两个字段组成：一个 ShortNotification and EmailNotificationContent.
  • A ShortNotification 表示通知的摘要版本，将在 Foundry 平台内显示。它包括一个简短的 heading, content，以及一组 Links.
  • EmailNotificationContent 表示通知的富文本版本，可以通过电子邮件在外部发送。它包括一个 subject要发布的组件集版本包含在此清单文件中。当使用 body （由无头 HTML 组成），以及一组 Links.
  • A Link 具有一个面向用户的 label 以及一份 linkTarget。该 LinkTarget 可以是 URL、 OntologyObject，或 rid （指向 Foundry 中的任何资源）。

有关如何使用 Notifications API 的示例，请查阅 我们的指南.

函数可以接受和返回媒体项。在 TypeScript v1 中，使用 MediaItem 类型。在 TypeScript v2 和 Python 中，使用 Media 作为输入和输出类型。调用方可以将现有的 MediaReference（例如对象上的媒体属性）传入函数。下游使用者可以使用返回的值来获取内容、获取元数据，或将其附加到另一个对象。有关更多信息，请查阅关于 媒体.

1import { Function, MediaItem } from "@foundry/functions-api";
2

6        const mimeType: string = media.mimeType;
7        // Fetch type-specific metadata (page count, dimensions, duration, and so on)
8        const metadata = await media.getMetadataAsync();
9        // Read the binary contents as a Blob
10        const contents: Blob = await media.readAsync();
11        // Narrow to a specialized subtype to call type-specific methods
12        if (MediaItem.isDocument(media)) {
13            const text = await media.extractTextAsync({ startPage: 0, endPage: 1 });
14        } else if (MediaItem.isAudio(media)) {
15            const transcript = await media.transcribeAsync();
16        }
17        return undefined;
18    }
19}

几何类型

几何类型表示函数中的空间数据和地理形状。支持两种几何类型：

  • 地理点 表示具有纬度和经度坐标的单个地理位置。
  • 地理形状 表示任何有效的 GeoJSON 几何图形，包括点（Point）、多边形（Polygon）、线串（LineString）及其他形状。

这些类型遵循 GeoJSON 规范 ↗ 并可用于空间操作、地图绘制和地理分析。请注意，根据 GeoJSON 规范，位置参数遵循经度、纬度的顺序。
