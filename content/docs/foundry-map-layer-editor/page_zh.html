地图图层编辑器

地图图层编辑器应用程序允许您创建、编辑和预览地图图层。地图图层包含地理空间数据，并定义这些数据的可视化方式。您可以在 地图应用程序 和 Workshop 地图小组件中使用地图图层。

地图图层编辑器提供了一个点击式 UI，用于配置包含矢量或栅格数据的地图图层。如果您需要更强的控制能力，或希望使用更高级的地图功能，则可以改为编写一份 Mapbox GL JS 样式规范文档 ↗。

创建新的地图图层

在 Foundry 中，导航到您希望创建地图图层的文件夹，然后选择 地图图层 （来自 新建 菜单）：

然后，添加数据源，或选择编写 Mapbox JSON 文档，以开始配置您的图层。

我们建议仅在需要矢量或栅格图层不支持的功能时，才使用 Mapbox JSON 文档。

您可以在右侧的 图层预览 面板中实时预览您的地图图层。

创建或修改地图图层后，请务必点击 保存 ，以使该图层在地图应用程序中可用。

矢量图层

矢量图层显示来自 GeoJSON 或矢量切片源的几何数据。指定数据源的方式有四种：

  • GeoJSON 文件： 选择一个 手动上传的 GeoJSON 文件。
  • 数据集 GeoJSON 文件： 选择一个数据集，然后选择该数据集中包含的 GeoJSON 文件。
  • GeoJSON URL： 输入 GeoJSON 文件的 URL。
  • MVT URL： 输入矢量切片集的 URL。

添加数据源后，您可以添加一个或多个显示项，以配置数据在地图上的可视化方式。

栅格图层

栅格图层显示来自栅格切片集的位图数据。通过指定切片集的 URL 来配置栅格数据源。

栅格图层可用的显示选项如下：

  • 不透明度： 图层显示的不透明或透明程度。
  • 采样： 当地图放大到需要放大栅格影像时使用的插值方法。
    • 线性： 使用最接近的源像素的平均值进行插值，在过度放大时可能会导致图像模糊。
    • 最近邻： 通过选择最近的源像素进行插值，在过度放大时会产生清晰但像素化的外观。
  • 缩放级别： 显示该图层的最大和最小缩放级别。

对象图层

对象图层直接显示来自本体论的数据。只有已同步到 OSS 或 OQL（已弃用）并具有 geopoint 或 geoshape 属性类型的对象类型，才能通过对象图层显示。

尽管对象图层需要 OSS 或 OQL（已弃用），但并非所有实例都提供此功能。请联系您的 Palantir 代表以了解更多信息。

对象图层提供两种方式来指定您要渲染的数据：

  • 对象类型： 选择一个对象类型，并可选择定义筛选器。所有匹配的对象都将显示在您的地图图层中。
  • 已保存的对象集： 选择一个 从 Object Explorer 保存的探索。图层应用将显示您保存的探索中包含的所有对象。

对象图层显示的配置选项与矢量图层相同。

Mapbox JSON 图层

对于 Mapbox JSON 图层，您可以在地图图层编辑器中编辑 JSON 文档。编辑器会验证 JSON 并突出显示任何错误。

JSON 内容必须符合 Mapbox GL JS 样式规范 ↗，但仅支持 sources 和 layers 属性（且两者均为必需）。
