你可以将所有数据集连接到合并面板（该面板可接受不限数量的输入），也可以框选所有输入，然后点击合并转换选项。

该 时间限定去重 函数将丢弃任何晚于配置的事件时间窗口到达的行，无论其是否为重复行。

时间戳： 2024年3月20日

我能否用新数据集替换管道 A 的输出，然后让管道 A 原先的输出数据集成为另一个管道（管道 B）的输出，同时确保所有管道的输出架构相同？

可以。您可以在 Pipeline Builder 中使用新输出覆盖数据集，这是一项一次性操作，会将现有数据集的所有权变更为新输出。只要您拥有必要的权限并按照所需步骤操作，就可以将所需的数据集配置为管道 B 的输出。所有管道输出架构都必须与输入转换节点的架构相匹配，这对于避免错误并成功部署管道至关重要。

时间戳： 2024年4月13日

如何在 Pipeline Builder 管道中将 null 字符串值映射到特定字符串（例如 "no data"）？

在 Pipeline Builder 管道中，有两种方法可以实现此目的：

  1. 使用 Coalesce 函数。例如， A = coalesce(A, "no data")。如果 A 是 null，则将返回 "no data"。
  2. 使用 Case 看板。

两种方法都允许将 null 值映射到指定的字符串。

时间戳： 2024年7月11日

是否有方法可以插补 null 一组列中的值？

是的，您可以使用 Apply To Multiple Columns 转换来插补 null 不同列中的值。
