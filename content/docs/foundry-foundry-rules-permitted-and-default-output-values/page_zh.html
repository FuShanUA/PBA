允许和默认输出值

工作流输出指定工作流中所有 Foundry 规则输出的目标位置和格式。在 规则编辑器中每条规则的末尾，在 规则输出 逻辑块中，作者将为每个工作流输出分配列或静态值。分配值可确保在需要时规则输出的值已定义，并确保数据能够以正确的数据类型安全地流入工作流输出数据集。

该 允许和默认输出值 部分可用于简化分配过程，并进一步自定义规则输出逻辑块。创建新规则时会自动分配默认值，并且可以将分配列或静态值的选项限制为仅允许两种值类型中的一种。

配置选项

配置分为两个部分：列值和静态值。这两个部分都取决于输出字段类型。如果任何配置不完整或无法满足，错误图标将指示相应问题。如果规则作者提供的值不符合要求（例如不在所需范围内的整数），同一错误图标也会在规则输出逻辑块中指示问题。 对于类型为 String的输出值，提供了一个可将字段设为字符串模板的选项。字符串模板是静态值和列值的组合。如果 字段为字符串模板 选项被选中，则无法进行进一步配置。

列值

列值是指在应用规则逻辑后，来自底层数据集某一列的值。规则作者编写规则逻辑时，实际数据是未知的，输出列只能通过类型或输入属性名称进行限制。可以为列值配置以下选项：

  • 任意： 任何现有列都可以分配给此输出字段。
  • 无： 此输出字段仅接受静态值。不允许引用列。
  • 选择： 指定列选项集中的任何列都可以分配给此字段。

静态值

静态值是指规则作者在创建或编辑规则时手动输入的值。您可以限制这些值，使其处于数字或日期范围内，或确保多个值的输入具有正确的长度。用户输入和值选择将显示为下拉菜单，以便规则作者更轻松地输入正确的值。可以为静态值配置以下选项：

  • 任意： 任何具有正确字段类型的值都可以分配给此输出字段。
  • 无： 此输出字段仅接受列引用。不允许使用静态值。
  • 选择： 指定值集中的任何值都可以分配给此输出字段。可选择允许其他值。选项将按其标签显示。
  • 范围： 仅允许处于指定范围内的静态值。此选项仅适用于数字和日期类型。
  • 用户： 指定的 Foundry 用户集合中的任何用户均可分配到此字段。如果未选择任何用户，则不会应用任何限制。此选项仅适用于字符串类型。

对于 允许多值的类型，这些限制适用于输入中的每一项。例如，输入中的每个整数必须在所需范围内，每个用户必须是预先选定的用户之一，或者每个项目必须是带标签的项目选项之一。
