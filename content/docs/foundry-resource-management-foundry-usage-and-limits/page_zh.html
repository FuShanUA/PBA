Foundry 使用情况和限制

使用直方图中的 Foundry 使用情况和限制 资源管理中的页面，以识别使用情况何时接近或超出注册层级限制，并确定哪些组织贡献了该注册的使用量。

此页面仅用于观察使用情况。您无法在此页面上配置或更改限制。要请求更高的注册层级限制，请使用 请求提高限制 选项或联系 Palantir 支持.

开始之前

要查看 Foundry 使用情况和限制，您需要 访问资源管理的权限 以及读取使用指标的权限。在注册层级，具有 Resource management viewer（资源管理查看者） 角色的用户默认拥有此权限。在组织层级，具有 组织管理员 角色的用户默认拥有此权限。

Foundry 报告以下服务的使用指标：

  • 本体论读取
  • 平台 API
  • 函数计算

只有当在您的环境中为某服务配置了注册层级限制时，该服务才会显示在页面上。

查看注册使用率

  1. 打开 资源管理.
  2. 选择 Foundry 使用情况和限制 在侧边栏中。
  3. 选择一个服务。该列表包含您的环境中已配置注册层级限制的服务。
  4. 选择预设时间范围或定义自定义范围。可用范围取决于注册的指标保留期限。

直方图 注册使用率 图表会比较请求使用量与所选服务随时间变化的注册层级限制。值为 100% 表示在显示的时间间隔内使用量达到了注册限制。大于 100% 的值表示报告的使用量超出了限制。

图表显示每个组织对注册使用率的贡献。如果注册只有一个组织，图表将显示单条序列。对于包含多个组织的注册，请使用图例或将鼠标悬停在图表上来识别每条序列。在图表中选择一个范围以查看更短的时间范围。

按组织比较使用情况

直方图 组织 表格汇总了所选服务和时间范围内的请求使用量。如果注册只有一个组织，表格将显示单个条目。对于包含多个组织的注册，表格会分别列出每个组织。请将此表格与 注册使用率 图表结合使用，以识别使用量贡献最多的组织。

UI 在表格中将共享的注册层级限制称为“注册配额”。 最大注册配额使用率 是该组织在所选时间范围内注册层级限制的最高百分比。 平均注册配额使用率 是该组织在所选时间范围内限制的平均百分比。

组织对注册使用率的贡献并不是组织特定的限制。该百分比将该组织的请求使用量与共享的注册层级限制进行比较。

按用户查看使用情况

在 组织 表格中选择一个组织，以查看按用户细分的其使用情况。用户细分保留了所选的服务和时间范围，便于您识别该组织内使用量贡献最多的用户。

请求提高限制

要为所选服务请求更高的注册层级限制，请选择 请求提高限制 位于匹配条件侧边栏中列出的 注册使用率 图表联系 Palantir Support。请包括请求的增加量、需要的原因以及任何其他背景信息。

解读数据

使用指标按时间间隔汇总，因此最近的请求可能需要一小段时间才会显示在图表和表格中，因为使用报告需要收集和处理。

此页面仅包含计入页面上显示的注册层级限制的请求。它并不代表所有计算、存储或计费使用量。要分析这些资源，请使用 概述 和 了解如何通过 资源管理中的页面。
