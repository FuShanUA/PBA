发布与版本管理

模块 版本管理 允许构建者安全且迭代地构建 Workshop 应用程序；通过 发布 模块的稳定版本，可以控制最终用户可访问的版本。这样就可以在实际运行的 Workshop 应用程序上持续开发，而无需在保存模块时将更改暴露给最终用户。

版本历史与设置

“版本”对话框是构建者查看模块已保存版本历史的地方。每个已保存的版本都会显示时间戳、编辑者以及描述（如果有）。对于每个已保存的版本，构建者可以选择：

  • 发布此版本： 发布模块的一个已保存版本，供查看者访问。
  • 查看此版本： 查看模块在特定版本时的状态。查看非发布版本时，模块顶部会出现一条警告横幅。

  • 回退到此版本： 将历史版本保存为模块的最新版本。系统会自动生成一条描述回退操作的说明。
编辑模块的先前版本

要编辑模块的先前版本，请按照以下步骤操作： * 确保 保存时自动发布 开关在“版本”对话框中处于关闭状态。 * 回退到您想要编辑的版本。 * 使用以下功能创建所选模块版本的副本： File > Duplicate File。 * 将原始模块回退到最新版本，并对您创建的副本进行所需的任何编辑。

“版本”对话框也是构建者编辑与保存和版本管理操作相关设置的地方：

  • 保存时自动发布： 此开关控制保存时是否自动发布新版本。
  • 保存时始终提示添加版本描述： 此开关控制保存新版本时是否提示构建者添加可选的描述。添加描述有助于记录对模块所做的更改，并积累更丰富的模块历史记录。可以在模块的“版本”对话框中查看、添加和编辑描述。

查看版本之间的更改

使用直方图中的 变更日志面板 来可视化模块版本之间的差异。您可以选择：

  • 范围选择： 选择起始版本和结束版本，以查看这些版本之间的所有更改。
  • 单一选择： 选择单个版本，将其与上一个版本进行比较。

变更日志面板会突出显示新增、删除、更改、移动以及新近未使用的元素。您可以检查 JSON 差异以查看具体的修改内容，并查看可视化层级结构以了解更改与嵌套组件之间的关系。

分支与变基

在分支上进行开发时，您可能需要在将 Workshop 更改合并到 main if main 之前先进行变基（如果自您上次保存以来 main 已发生更改）。变基会将您分支上的更改应用到模块的最新

版本，并显示所有必须解决的合并冲突。变基用户界面使用 变更日志面板 来可视化更改并突出显示冲突，例如同一个 widget 在 main 和您的分支上都被修改的情况。解决冲突后，保存以完成变基，然后继续将您的分支合并到 main.

有关完整的操作指南，请参见 变基与冲突解决.
