核心概念

图层

A 图层 是用于构建地图的地理数据集合。Foundry Map 应用程序支持多种图层，可以组合起来形成强大的地理空间可视化效果：

  • 基础图层： 基础图层通过渲染世界的地理特征（包括道路、城市、边界、地名等）为地图提供基础。可用的基础图层包括浅色主题、深色主题和卫星影像等。使用选择器更改基础图层 图层 面板中进行管理。

您还可以选择使用以下不同类型的图层：

  • 对象图层： 用于利用 对象上的地理空间数据 （来自您的本体论）。
  • 关联图层： 在执行 Search Around 后显示对象之间的关系。
  • 叠加图层： 使用 现在允许用户通过点击式界面将栅格瓦片数据添加到图层。配置完成后，地图图层即可供用户在 创建高质量的可视化效果，只需创建一次即可导入到一个或多个地图中。
  • 注释图层： 绘制形状以突出显示地图的特定区域并提供相关背景信息。阅读更多关于 创建注释.

对象样式

直方图 样式 您应用于对象的样式决定了它们在地图上的外观。

时间选择

每个地图都有一个 选定时间，它始终位于当前选定的 一个内。时间窗口决定了地图加载和显示 时间序列 数据的时间段。 基于时间的样式 可以使用时间选择来有选择地控制具有时间数据的对象的不透明度。阅读更多关于操作 时间选择.
