从 Gaia 创建本体论对象

类似于您 将本体论中的数据添加到 Gaia 地图的方式，您也可以通过在对象类型中标记对象，从您绘制的形状、放置的点或在地图上配置的战术图形创建本体论对象，该对象类型实现了 Gaia Geoshape Creatable、Gaia Geopoint Creatable 或 MILSTD 2525C Symbol 接口。

通过 Palantir 的 Defense OSDK提供的 MILSTD 2525C Symbol 接口取代了 Gaia Milsym Creatable 接口，后者目前处于开发过程中的 计划弃用 阶段，并将于 2026 年 7 月之前被弃用。如有关于 Defense OSDK 接口可用性或 Gaia Milsym Creatable 接口在您的注册中弃用的疑问，请联系 Palantir 支持团队。

如果 两种 接口均在您的注册中可用，请实现 MILSTD 2525C Symbol 接口，而非 Gaia Milsym Creatable 接口。

要从 Gaia 地图创建本体论对象，您的注册必须同时使用 Foundry 和 Gotham。

以下各部分概述了将 Gaia 形状、点和战术图形与本体论集成的端到端流程：

  • 安装所有必要的 Marketplace 产品。
  • 在由受限视图支撑的受支持对象类型上实现 Gaia Geoshape Creatable 接口。
  • 在由受限视图支撑的受支持对象类型上实现 Gaia Geopoint Creatable 接口。
  • 在由受限视图支撑的受支持对象类型上实现 MILSTD 2525C Symbol 接口。
  • 注册您的本体论，并在 Gaia 中搜索您的对象类型。
  • 了解创建对象的入口点。
  • 在您的地图上绘制一个新形状，并在您的对象类型中对其进行标记。
  • 在您的地图上放置一个新点，并在您的对象类型中对其进行标记。
  • 根据您在地图上绘制的形状配置战术图形，并在您的对象类型中对其进行标记。

安装必备的 Marketplace 产品

Marketplace 是 Foundry 的应用商店，提供已发布的数据产品或可供用户安装的平台资源集合。您可以通过 搜索... 栏或您主屏幕上的 Applications 门户访问 Marketplace。

启动 Marketplace 后，请安装以下产品：

  • 来自 Core Ontology Store 的 Core Property Types，其中包含核心共享属性类型（例如对象的分类和地理形状），可用于您本体论中的多个对象类型。
  • 来自 Gaia App Store 的 Gaia Geoshape Creatable 接口，用于描述地理空间对象类型的形状，从而支持对具有相同形状的其他对象类型进行一致的建模和交互。
  • 来自 Gaia App Store 的 Gaia Geopoint Creatable 接口，用于描述单点对象类型的位置。

来自 Core Ontology Store 的 Core Property Types

请联系 Palantir 支持团队，将 Core Ontology 作为 Foundry 产品 安装到您的 Foundry 注册环境中（如果 Marketplace 中未提供包含 Core Property Types 产品的 Core Ontology Store）。

来自 Gaia App Store 的 Gaia Geoshape Creatable 接口

在 Foundry 中， 接口 存在于您的本体论中，用于描述对象类型的形状及其功能，从而支持对具有相同形状的对象类型进行一致的建模和交互。您可以在多个对象类型上实现接口，并且接口可以扩展任意数量的其他接口。在对象类型上实现 Gaia Geoshape Creatable 接口后，您就可以使用在 Gaia 地图上绘制的形状在您的本体论中创建对象。

Gaia Geoshape Creatable 接口取代了已弃用的 Gaia Geocreatable 接口。如果您无法访问 Marketplace 中的 Gaia Geoshape Creatable 接口，请联系 Palantir 支持团队。

要从 Marketplace 安装 Gaia Geoshape Creatable 接口：

  1. 返回 Marketplace 并搜索 Gaia App Store （在 搜索商店...中）。
  2. 选择 Gaia Geoshape Creatable 产品。
  3. 选择屏幕右侧的蓝色 安装 按钮以启动草稿安装。您也可以选择为安装添加描述性后缀。
  4. 指定一个 命名空间 ，您的安装将保存到其中。Marketplace 将自动创建一个新的 项目 ，位于所选的 命名空间中。
  5. 在 权限下配置产品的分类和访问控制。您在 基于分类的访问控制 (CBAC) 下选择的分类定义了安装的 最高 分类。
  6. 选择 下一步 以启动安装窗口的 输入 页面。
  7. 选择 共享属性 选项卡（位于左侧面板中的 输入 下方），以将 Geoshape 您的本体论中的共享属性映射到您的新接口。
  8. 选择 下一步 以启动安装窗口的 内容 页面。

  1. 您可以选择开启 为本体论实体添加前缀 选项，并输入有效的前缀。请注意，您的前缀不能包含某些特殊字符，例如圆括号或方括号。
  2. 选择哪些 本体论架构迁移 以在屏幕右侧启用。如需了解更多架构管理信息，您可以查阅现有的 对象编辑和物化文档。
  3. 请更新 新版本 中的自动配置，根据您的使用场景按需调整，然后再选择 下一步。Marketplace 会对某些产品进行预配置，使其自动升级。
  4. 查看您的接口配置，然后选择 安装。

来自 Gaia App Store 的 Gaia Geopoint Creatable 接口

要从 Marketplace 的 Gaia App Store 安装 Gaia Geopoint Creatable 接口，请在商店菜单中选择 Gaia Geopoint Creatable 相应产品。Marketplace 的接口安装工作流在不同接口之间是通用的，因此您可以按照上述 Geoshape Creatable 接口安装说明 中概述的相同步骤进行操作，但需注意以下区别：

  • 在 共享属性 部分（位于 输入 窗口中），将 Geopoint 本体论中的共享属性映射到 Gaia Geopoint Creatable 接口。

创建实现 Gaia Geoshape Creatable 接口的对象类型

Gaia 可以发现您本体论中由 数据集 或 受限视图 支撑的对象类型（前提是这些对象类型实现了 Gaia Geoshape Creatable 接口）。在以下部分中，您将：

  • 创建支撑对象类型的数据集或受限视图。
  • 创建对象类型并确保其与 Gotham 集成。
  • 配置操作类型以在 Gaia 中启用对象创建。
  • 实现 Gaia Geoshape Creatable 接口。

创建支撑对象类型的数据集或受限视图

如果您计划根据用户的分类来保护对象，或通过应用 标记 来控制文件访问，则应创建受限视图。如果您的用例不需要基于分类的访问或标记所提供的额外对象安全性，则应创建一个数据集来支撑您的对象类型。

要创建可与 Gaia 集成的对象类型，您首先需要创建一个数据集或受限视图，其中至少包含以下列：

  • Geoshape，您需将其设置为 string ，以便 Gaia 自动填充您所绘制对象的形状。
  • Object ID，您需将其设置为 string ，以便 Foundry 为您创建为对象的每个 Gaia 形状自动填充唯一 ID。这将用作您对象类型的主键。
  • Classification，您需将其设置为 array ，用于捕获对象的分类。 Classification 列 仅 在受限视图支撑您的对象类型时才需要。

您可以根据具体用例在数据集或受限视图中配置其他列，例如 Name、 Category或 Notes 设置为 strings 的列，以捕获用户输入的关于该对象的描述性信息。

选择 新建 按钮，在您的项目中上传现有文件，例如 .csv，或使用 Fusion 来创建独立数据集或为您的受限视图提供支撑的数据集。如果您使用数据集为您的对象类型提供支撑，则可以跳过下方的受限视图创建说明，并继续 创建您的对象类型。

您可以在 Foundry 的 安全 和 对象权限 文档中参阅更多受限视图创建说明。

您的受限视图应包含一个 细粒度策略 ，该策略根据用户的 分类访问权限限制用户对视图中数据的访问。请在 创建“{restricted view}” 窗口中，将编写细粒度策略作为第一步。

如果对象包含用于限制其访问权限的 CBAC 或强制标记属性，则 Foundry 会使用从 Gaia 地图继承的 CBAC 或强制标记创建对象，并且 不会 应用该地图的安全和共享设置中定义的组限制。

创建一个对象类型，并确保其与 Gotham 集成

配置好您的受限视图后，启动 Ontology Manager 并按照以下步骤创建您的对象类型：

  1. 选择 新建 > 对象类型 （位于屏幕右上角）。
  2. 选择 使用现有数据源 并选择 选择数据源 以查找并 选择 您的受限视图，然后选择 下一步。
  3. 为您的对象类型命名，并选择性地填写 描述。
  4. 将 Object ID 设置为 主键 ，并将 Name 设置为 标题。
  5. 确保 Classification的 属性 是字符串数组，且 Geoshape的 属性 是 geoshape。仅当您的对象类型由受限视图支撑时，才需要验证前者。

  1. 选择 创建，因为您将在 创建对象类型之后 生成并配置操作类型。

在 Ontology Manager 中查看您的草稿对象类型后，接下来您将选择 Classification 和 Geoshape 属性，作为您本体论中的共享属性类型。选择 属性 面板（位于 概览 下方），并按照以下步骤完成共享属性类型的选择流程：

如果您使用数据集来支撑您的对象类型，而该数据集 不 包含 Classification 属性，则应针对您的 Geoshape 属性完成以下步骤 1 和 4。

  1. 选择 Classification 从您的属性列表中以启动 属性编辑器 窗口，该窗口位于屏幕右侧。
  2. 更新 基础类型 下拉菜单，使其分别包含 Mandatory control 和 CBAC Marking。
  3. 配置该属性的 最高分类。

如果您无法选择 强制控制 作为 Classification的基础类型，请联系您的 Palantir 支持团队，因为 强制控制 标记并非在所有 Foundry 租户中普遍可用。

  1. 滚动到窗口底部的 共享属性 部分，并使用下拉菜单将 Classification 指定为共享属性。

针对您的 Geoshape 属性，重复上述步骤 1 和 4，因为您 无需 配置其强制控制标记或分类。

选择屏幕顶部的绿色 保存 按钮，以便在继续操作之前将增量更改发布到您的本体论。

如果您的 Foundry 租户包含地图渲染服务 (MRS)，那么您的本体论中具有地理空间属性类型的对象类型将自动与 Gotham 集成，您可以继续 创建操作类型以在 Gaia 中启用对象创建。请按照 Gotham 集成文档 中的步骤来检查您的租户是否包含 MRS。如果您的租户 不 包含 MRS，那么 请按照相关说明操作 以将您本体论中的数据与 Gotham 集成。

如有关于 MRS 安装或功能的问题，请联系 Palantir 支持团队。

创建并配置操作类型，以在 Gaia 中启用对象创建

创建对象类型并确保其与 Gotham 集成后，请导航返回 概述 窗口（位于 Ontology Manager 中）。在此，创建一个 操作类型 ，使用户能够从形状创建和编辑对象，并配置其属性，例如 Name 和 Category，所有这些操作均可在 Gaia 中完成。

您的 Foundry 注册必须包含 MRS 才能在 Gaia 中编辑本体论对象，因为此功能不适用于通过类型映射添加到 Gaia 的对象。如有关于 MRS 安装或功能的问题，请联系 Palantir 支持团队。

请按照以下步骤配置您的操作类型：

  1. 选择 新建 （位于 操作类型 部分，即您对象类型的 概述 窗口中），以启动 创建新操作类型 弹出窗口。

如果您无法选择 新建 按钮（位于 操作类型中），则可以开启 允许编辑 （针对您的对象类型，在 数据源 窗口中）。

  1. 选择 修改或创建对象 （位于 对象操作 下方），然后选择 下一步。
  2. 选择 自动生成主键 （位于 或通过以下方式创建新对象 下拉菜单中）。
  3. 选择 添加属性 以将您现有的所有属性添加到该操作类型，然后选择 下一步 以配置操作类型的元数据。

您只需要映射 Classification 属性，前提是受限视图支撑您的对象类型。

  1. 为您的操作类型命名，并可根据需要输入描述和更新其默认图标。
  2. 选择可执行该操作的 组织、 组或 用户 ，然后选择 创建。

选择屏幕顶部的绿色 保存 按钮，以便在继续操作之前发布对本体论的增量更改。

接下来，您将配置操作类型的 规则 和 参数 ，请按照以下步骤操作：

  1. 选择 规则 （位于屏幕左侧）。
  2. 验证 Geoshape 属性配置，方法是选择箭头图标，该箭头图标紧邻 配置参数。
    • 确保 Geoshape 属性的类型为 Geoshape 或 String ，从 Type 下拉菜单（位于屏幕右侧）中进行选择。
    • 确保 Disabled 选项在 常规 面板中处于选中状态，因此用户无法手动配置 Geoshape的位置。

  1. 选择您的 Classification 属性，可在屏幕左侧的 表单内容 面板中选取，并验证其 类型 是 Mandatory control。仅当受限视图支撑您的对象类型时，您才需要配置一个 Classification 属性。
  2. 选择 返回表单 并移除 Object Id 从 若要形成内容 ，请选择 X 图标（位于 Object Id 面板的最右侧）。Foundry 会自动为从 Gaia 创建的每个对象生成唯一的 ID。
  3. 选择绿色的 “保存” 屏幕顶部的按钮，以将您的操作类型配置保存到本体论。

实现 Gaia Geoshape Creatable 接口

在本体论管理器中创建和配置您的对象类型的最后一步是实现 Gaia Geoshape Creatable 接口，该接口是您 先前从 Marketplace 安装的。返回到您的对象类型的 概览 页面，并按照以下步骤实现该接口，然后再将更改保存到您的本体论：

  1. 导航至 接口 下方窗口 对象视图 在屏幕左侧。
  2. 选择 实现新接口 并搜索 Gaia Geoshape Creatable 然后再选择 下一步.
  3. 选择 请选择一个选项 > 替换现有 以将您本体论的 Geoshape 共享属性类型映射到实现该接口的对象类型。
  4. 选择 确认 以关闭 实现接口 窗口并 保存 新配置的接口到您的本体论中。

创建一个实现 Gaia Geopoint Creatable 接口的对象类型

要创建实现 Gaia Geopoint Creatable 接口的对象类型，您可以按照 上文针对 Gaia Geoshape Creatable 接口的对象类型创建说明 中概述的相同步骤进行操作，但各部分有以下区别：

  • 创建支撑对象类型的受限视图。
    • 创建一个 Geopoint 而不是 Geoshape 列。
  • 创建对象类型并确保其与 Gotham 集成。
    • 在对象类型创建窗口中，确保 Geopoint的 属性 为 geopoint。
  • 配置操作类型，以便在 Gaia 中创建对象。
    • 确保您的 Geopoint 属性的 类型 位于 Geopoint 您的操作类型的 参数 窗口中。
  • 实现 Gaia Geoshape Creatable 接口。
    • 搜索 Gaia Geopoint Creatable 而不是 Gaia Geoshape Creatable 接口。
    • 在映射您本体论的共享属性类型时，请选择 替换现有 ，用于 Geopoint 而不是 Geoshape 属性。

创建一个实现 MILSTD 2525C Symbol 接口的对象类型

与 Gaia Geoshape Creatable 和 Gaia Geopoint Creatable 接口不同，您 必须 使用受限视图来支撑实现 MILSTD 2525C Symbol 接口的对象类型。

要创建实现 MILSTD 2525C Symbol 接口的对象类型，您可以按照 上文针对 Gaia Geoshape Creatable 接口的对象类型创建说明中概述的相同步骤 进行操作，但每个部分有以下区别：

  • 创建由对象类型支撑的受限视图。
    • 您将 只 需要创建 Object ID， Classification，以及 Title 列。
  • 创建一个对象类型，并确保其与 Gotham 集成。
    • 在对象类型创建窗口中，将 Object ID 设置为 主键 并将 Title 设置为 标题。

在 配置操作类型以启用对象创建时，请确保 至少 映射 Classification、 Symbol Anchor Points和 SIDC 属性（在 创建新操作类型 窗口中），然后再选择 下一步。

选择绿色的 保存 按钮（位于屏幕顶部），以便在继续操作之前将增量更改发布到您的本体论。

接下来，您将配置操作类型的 规则 和 参数 ，具体步骤如下：

  1. 选择 规则 （位于屏幕左侧）。
  2. 选择您的 Classification 属性右侧的箭头图标，以 配置参数。

  1. 如果 Classification 您的对象类型上的属性由共享属性类型实现，那么您应该开启 禁用 ，位于 常规 部分，以确保自动创建的对象从您的 Gaia 地图中继承其分类标记。如果您想在创建时手动设置分类标记，则不要开启 已禁用。
  2. 选择 添加 下方 设置参数的最大分类 以确保操作类型的最高分类与对象类型的最高分类相匹配。

  1. 选择绿色的 保存 按钮（位于屏幕顶部），以将操作类型发布到您的本体论中。

由于 目前尚不支持在操作中使用结构体属性，您将无法配置 Speed Modifier (Z) 或 Altitude/Depth Modifier (X) 属性作为操作类型参数。

  • 实现 Gaia Geoshape Creatable 接口。
    • 搜索 MILSTD 2525C Symbol 而不是 Gaia Geoshape Creatable 接口。
    • 在映射本体论的共享属性类型时，请选择 替换现有 为您的 Classification 属性，并 创建仅编辑属性 为其余属性。

注册您的本体论及其类型

现在，您已拥有实现了 Gaia Geoshape Creatable、Gaia Geopoint Creatable 和 MILSTD 2525C Symbol 接口的对象类型，并且这些对象类型包含相应的操作类型，使用户能够配置其在 Gaia 地图上通过绘制的形状、放置的点位和配置的战术图形所创建的对象。接下来，您将注册您的本体论、对象类型和操作类型，注册位置为 Gaia 的管理应用程序或 Control Panel 扩展，具体取决于您的注册情况。

要访问 Gaia 的管理应用程序,您必须是平台管理员。要访问 Gaia 的 Control Panel 扩展,您必须被授予 组织管理员 角色。

如果您无法访问管理应用程序或 Control Panel 扩展,请就相关访问问题联系 Palantir 支持团队。

要注册您的本体论、对象类型和操作类型,请启动 Gaia 的管理应用程序或 Control Panel 扩展,并按照以下步骤操作:

  1. 找到 本体论配置 (管理应用程序)/本体论 （Control Panel 扩展）面板并验证您的本体论配置。如果您的本体论尚未配置，请选择面板左侧的开关以设置 本体论配置/本体论 为 overridden （管理员应用）/Override （Control Panel 扩展）。
  2. 将您的本体论的 RID 和 API 名称输入到 本体论 RID 和 API 名称 文本框中。

在 Gaia 地图上创建对象的入口点

Gaia 提供了两个不同的入口点，可用于在您的地图上创建对象，这些入口点决定了显示在 对象类型 下拉菜单中的可用对象类型列表。

  • 请先选择对象类型： 当您从工具栏下拉菜单中选择对象类型时，Gaia 会列出实现受支持接口的所有对象类型，包括 Gaia Geoshape Creatable、Gaia Geopoint Creatable、MILSTD 2525C Symbol 和 Gaia Milsym Creatable 接口。选择对象类型后，Gaia 会筛选可用的绘图工具，以 仅显示 与对象类型所实现的接口兼容的工具。例如，选择实现了 Gaia Geoshape Creatable 接口的对象类型后，将仅显示形状绘图工具。随后，当您选择某个绘图工具时，Gaia 会打开左侧面板，您的对象类型已预先填充在 对象类型 下拉菜单中。

一个对象类型可以实现多个接口。例如，如果某个对象类型同时实现了 Gaia Geopoint Creatable 和 Gaia Geoshape Creatable 接口，那么从工具栏中选择该对象类型时，将同时显示点符号和所有形状绘图工具，同时过滤掉符号 搜索 菜单。

  • 请先选择绘图工具： 在未选择对象类型之前先选择绘图工具时,Gaia 会打开左侧面板,且不会预先选择任何对象类型。在这种情况下, 对象类型 下拉菜单仅列出实现与所选工具相匹配的接口的对象类型。例如,选择点符号时,仅显示实现 Gaia Geopoint Creatable 接口的对象类型。
