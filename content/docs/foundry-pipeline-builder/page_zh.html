Pipeline Builder

Pipeline Builder 是 Foundry 的主要数据集成应用程序。您可以使用 Pipeline Builder 构建数据集成管道，将原始数据源转换为干净的输出，为后续分析做好准备。

借助 Pipeline Builder 和强大的后端模型，会编码的用户和不会编码的用户可以在管道工作流中协同合作。Pipeline Builder 的架构同时利用了 Spark 和 Flink，并融合了由 Palantir 开发的自定义库和服务所支持的各种高级功能。用户无需编写需要进行冗长健康检查的代码；Pipeline Builder 在精简的点击式构建器界面之下集成了多种编程语言，用户无需具备专门的编程语言知识，即可通过该界面应用数据转换。

Pipeline Builder 使用新一代数据转换后端，该后端专门设计用于在逻辑创建与执行之间充当中介。当用户描述想要构建的管道时，后端会编写转换代码并对管道完整性进行检查，识别重构错误并提供解决方案，以确保构建健康。由于后端在逻辑创建与执行之间充当中间层，构建者可以在构建管道之前解决 schema 问题，并节省以往花费在计算和代码检查上的时间。

功能

Pipeline Builder 包含专注于对管道进行全面创建、维护和控制的功能。

  • 直观的用户界面： 用户使用基于图形和表单的界面来编写管道，这些界面会提供反馈，包括联接键和列类型转换建议。

  • 类型安全的函数： 函数采用强类型，可以立即标记错误，而无需等到构建时。

  • 严格的输出检查： 如果未通过预期的输出检查，则会阻止构建，以避免无意间造成下游中断。

  • 自动构建路径剪枝： Pipeline Builder 会对未连接到输出的转换路径进行剪枝，以避免构建中出现不必要的计算。

  • 抽象实现细节： 用户专注于描述端到端管道和期望的输出。构建、同步及其他编排均由 Pipeline Builder 后端自动处理。

  • 独立的管道逻辑： Pipeline Builder 可以连接到不同的逻辑执行引擎，包括 Spark、Flink、Azure 实例等。

  • 可复用性： 使用 子图 来提取管道逻辑并将其作为可复用块加以复用。

  • 完整的版本控制： 用户可以单独起草管道、在同一个管道上进行协作，或恢复到以前的版本。

  • 媒体处理转换： 用户可以在其管道中将媒体集作为转换输入进行传递。

  • 大语言模型 (LLM)： 使用 LLM 和 AIP 转换您的数据。使用 LLM 评估套件 来在部署前测试您的 LLM 转换。

  • 训练好的模型： 导入机器学习模型以在您的管道中生成预测。

  • Model Studio 集成： 使用 Train in Model Studio 操作直接在 Model Studio 中打开数据集进行模型训练。

  • 地理空间转换： 使用 Pipeline Builder 加载、转换和输出不同形式的地理空间数据。

  • 更快速的管道： 构建由 DataFusion 提供支持的更快速批处理管道和增量管道，可显著提升执行速度，尤其是对于通常运行时间不超过 15 分钟的管道。了解如何 创建更快速的管道。

  • 流式处理能力： Pipeline Builder 支持编写以实时延迟执行的管道。此功能并非在所有 Foundry 环境中都可用。如果您的工作流需要使用流式管道，请联系您的 Palantir 代表。

  • 外部管道： 将计算下推到 Databricks 和 Snowflake 等外部系统，可使用 外部管道。外部管道需要 虚拟表 输入和输出，且须来自与您的计算相同的源。

工作流

Pipeline Builder 遵循一个工作流，其中包含从导入数据到交付正常构建的以下步骤。

  • 输入： 添加新的数据源或添加更多数据集。
  • 转换： 对数据进行转换、联接或合并，以获得所需的输出。
  • 预览： 应用转换后，预览输出。
  • 交付： 管道完成后，构建管道输出。
  • 输出： 为您的管道添加对象类型、关联类型或数据集输出。
