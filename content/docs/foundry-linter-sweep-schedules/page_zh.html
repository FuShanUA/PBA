扫描计划

Linter 扫描计划是一种 Linter 配置，它定义了以下内容：

  • 资源范围： 将按计划进行扫描的一组 Foundry 资源。
  • 规则范围： 将针对资源范围运行的一组规则。

扫描计划必须属于某个 空间，并且规则将针对属于该空间的 Project 中的 Foundry 资源运行。您可以在 Linter 配置 标签页（位于注册设置中）查看、编辑或创建新的 Linter 配置，入口在 控制面板。在此处您可以配置扫描计划。这些计划仅适用于页面左上角栏中指定的空间。

直方图 Linter 配置 页面列出了指定空间的现有扫描计划。在这里，您可以查看最近扫描的状态并创建新的扫描计划。每个计划都可以通过 操作 来创建一个临时的实体级别维护窗口。

您还可以通过选择 最近的扫描.

编辑扫描计划

您可以在 编辑扫描计划 页面预览同步的数据。

规则范围

规则范围允许用户定义 规则 扫描计划将使用的规则。有三种定义规则范围的方式：

  • 规则预设： 一组可以批量添加的推荐规则。例如，添加 PIPELINE_COST_RULES 预设将添加所有与成本相关的规则。
  • 规则： 您可以多选特定规则以包含在规则范围内。
  • 排除规则： 您可以指定要从扫描计划中移除的规则。

操作顺序遵循上面列出的顺序：首先应用规则预设，然后添加单个规则，最后从规则范围中移除排除的规则。

资源范围

资源范围定义了哪些 Project 在扫描计划的范围之内。默认情况下，当前空间中的所有 Project 都在扫描范围内。用户也可以缩小范围，仅包含选定的 Project。
