预览与逻辑

通过数据血缘关系界面，您可以查看选定数据集或媒体集的预览，也可以检查相关代码，从而了解数据集或媒体集背后的逻辑。

预览

要预览数据集或媒体集，请在数据血缘关系图中将其选中，然后在界面左下角选择 预览 选项卡。

媒体集

展开媒体集预览后，您可以查看媒体集的内容。 了解有关媒体集的更多信息。

DataFrame

展开数据集预览后，您可以滚动浏览选定数据集的前 300 行。您还可以使用预览窗口右侧的 搜索列... 字段来查找特定列。根据数据集包含的数据类型不同，其预览效果也会有所差异。

逻辑

选择 选项卡，选择 选项卡可查看选定数据集或媒体集的代码逻辑。在 选项卡，选择 视图中，您可以进行快速编辑、搜索项目，或在存储库或其他用于生成数据的应用程序中打开代码。上传和回写的数据集没有可在数据血缘中查看的关联代码。
