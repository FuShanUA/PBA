Foundry 托管的 OAuth 应用程序

OAuth 应用程序是托管在 Foundry 中的 pro-code OSDK 应用程序，支持使用授权许可流程进行交互式用户身份验证。这些应用程序利用 Foundry 安全原语来支持交互式自定义应用程序。

Foundry 托管的 OAuth 应用程序非常适合以下用例：

  • 交互式 Web 应用程序 需要用户身份验证。
  • 多用户应用程序 其中不同用户需要不同的权限。
  • Pro-code 自定义应用程序 使用 OSDK 构建并托管在 Foundry 上。

架构

User → Foundry Subdomain → OAuth Flow → OSDK App → Foundry APIs

Foundry 托管的应用程序部署在专用子域名上（例如 https://subdomain-for-app.your-foundry-domain.com/），并遵循带有 OAuth 重定向的登录流程，其中同意授权是可配置的。

先决条件

在设置 Foundry 托管的 OAuth 应用程序之前，请确保满足以下条件：

  • Foundry 平台已配置为使用 消费者模式。
  • 您拥有 正确的权限 以创建和托管 Developer Console 应用程序。
  • 您拥有或可获取 前端开发经验 来构建应用程序。

设置

步骤 1：创建 OSDK 应用程序

请按照 我们的文档 创建新的 OSDK 应用程序。

  1. 创建应用程序： 使用 Developer Console 创建新的前端应用程序。
  2. 配置 OAuth 设置： 使用公共客户端进行用户身份验证。
  3. 定义应用程序限制： 配置访问 Foundry 资源所需的限制。

步骤 2：开发您的 OSDK 应用程序

使用 OSDK 框架构建您的前端应用程序。您可以在我们的 OSDK 文档中查看 TypeScript 示例。

步骤 3：将应用程序部署到 Foundry

部署您的 OSDK 应用程序 以在 Foundry 上托管，并记住您的子域名。

步骤 4：验证消费者访问权限

  1. 配置应用程序权限： 向您的消费者基于规则的组授予对已部署 OSDK 应用程序的访问权限。
  2. 在 Developer Console 中检查消费者访问权限： 如果用户缺少任何权限，请将其添加到消费者空间内的必要项目中，以授予其访问权限。
  3. 测试用户流程： 验证消费者用户能够在拥有适当权限的情况下访问应用程序。

故障排除

  • 权限问题： 在 Check Access 面板中确认用户可以访问应用程序中的所有资源。
  • 作用域错误： 在 Developer Console 中验证 OAuth 客户端是否具有正确的作用域。

用户体验问题

  • 多次登录提示： 请查阅我们的 消费者模式入门文档 ，以了解如何通过默认身份提供程序隐藏登录页面。

您现在拥有一个可正常运行的 Foundry 托管应用程序，可供外部消费者安全使用。您的 OSDK 应用程序为经过身份验证的用户提供对 Foundry 数据和功能的安全访问，同时保持适当的权限边界和用户隔离。
