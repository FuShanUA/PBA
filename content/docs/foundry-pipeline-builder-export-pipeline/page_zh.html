导出管道代码

以代码形式导出管道的功能仅支持默认批处理（Spark）管道。更快的管道和流式管道不支持此功能，导出选项不会出现在 设置 菜单中（针对这些管道类型）。

在 Pipeline Builder 中构建时，您可以将管道代码导出到现有的 Java 转换仓库。当您需要访问特定的 Java 库时，此导出功能非常有用。

在导出过程中，您的管道将被转换为 Java 转换代码，然后推送到目标仓库。请牢记此过程的以下注意事项：

  • 目标仓库指定分支上的任何现有代码或文件都将被删除。
  • Java 转换代码的新输出可能并不总是与 Pipeline Builder 管道的输出完全相同。请参阅 将 Pipeline Builder 导出为 Java 转换 以了解更多详情。
  • 此过程是不可逆的，这意味着对 Java 转换代码的任何更改都无法推送回 Pipeline Builder 管道。
  • 某些管道转换无法转换为代码。

打开您要导出的管道并导航至 Settings > Export code。此时将弹出一个窗口，您可以在其中搜索并选择现有的目标 Java 转换仓库。然后，选择导出来源的 Pipeline Builder 分支，并可选择创建一个新分支在目标仓库中使用。

管道导出将在 transforms-java/src/main/java/com/ 中可用，位于您的仓库中，形式为 PipelineLogic.java 和 PipelineOutputs.java 文件。

将 Pipeline Builder 导出为 Java 转换

将 Pipeline Builder 管道导出为 Java 代码时，重要的是要认识到新输出可能并不总是与原始管道输出完全相同。原因如下：

  • 代码生成限制：许多 Pipeline Builder 功能是 Foundry 特有的，在导出中不受完全支持。这些包括：

    • 用户自定义函数（UDF）
    • LLM 调用和模型调用，包括嵌入
    • 媒体操作
    • Geotime 功能

    不支持的功能将显示为 todo 生成的代码中的占位符块，需要手动实现。

  • 与原生 Spark 的差异：Pipeline Builder 中的某些表达式经过优化，其实现方式与原生 Spark 不同，以获得更高的可靠性和更好的错误处理。我们无法导出这些自定义优化，必须恢复为原生 Spark 表达式，而这些表达式在这些边缘情况下可能表现不同。

代码生成中所有其他受支持的表达式均已通过 Spark 测试用例进行验证。导出为 Java 转换应被视为一个起点，用户可以据此进行手动验证，以确保完全准确。

导出为 PySpark

Pipeline Builder 仅支持将管道导出为 Java（Spark）转换。没有内置功能可将 Pipeline Builder 管道导出为 PySpark 转换。

如果您需要 PySpark 代码，可以使用上述过程将 Pipeline Builder 管道导出为 Java Spark 代码，然后使用大语言模型（LLM）将导出的 Java Spark 代码转换为 PySpark。此转换过程可能需要手动验证以确保准确性，类似于 将 Pipeline Builder 导出为 Java 转换.
