生成对象视图 URL

在开发对象视图的过程中，您可能需要生成链接到特定对象或用于搜索对象的 URL。

如果您将这些视图嵌入到 iframe 中而不是以链接的形式提供，请附加一个 URL 查询参数 embedded=true，这样加载的视图将不包含工作区侧边栏。

要了解如何创建链接到搜索或 Exploration 的 URL，请参阅 生成 Object Explorer URL.

生成对象链接

您可以通过三种方式关联到对象。

选项 1

/workspace/hubble/external/object/v0/<object-type-id>?<primary-key-property-id>=<primary-key-property-value>

例如：

/workspace/hubble/external/object/v0/aircraft?aircraftId=1234

选项 2

/workspace/hubble/external/search/v2/?objectId=<objectRid>

当主键属性值可能包含特殊字符时，建议使用此方式。

此 URL 会在 Object Explorer 的上下文中加载 Object View。若要加载不带任何额外包装的 Object View，请创建如下 URL /workspace/hubble/objects/<objectRid>。若要在 iframe 中嵌入 Object View，请改用选项 3。

选项 3

/workspace/object-view/<objectRid>

此 URL 是独立的 Object View 路由，加载时始终不显示 Workspace 侧边栏。若要加载不带页眉的 Object View，请附加一个 URL 查询参数 shouldHideHeader=true。若要以深色模式加载视图，请附加 inDarkMode=true构造一个本体论编辑容器。例如： /workspace/object-view/<objectRid>?shouldHideHeader=true&inDarkMode=true.

页眉功能（例如评论以及在 Object Explorer 中开始探索的选项）可能与 /workspace/hubble/* 路由中的不同。
