添加数据集

要开始构建管道，请使用以下四种方法之一将数据添加到您的图表中：

  • Data Connection 应用程序
  • 从 Foundry 中选择数据集或媒体集
  • 手动上传数据
  • 在管道文件中手动输入数据

从 Data Connection 向 Pipeline Builder 添加数据

要访问来自数据源的数据，请导航至 数据连接 应用（位于 Foundry 导航侧边栏中）。找到您要集成的数据源，然后点击 开始构建管道。为新管道选择一个位置，然后点击 保存。这将创建一个新管道，并且与您的数据源连接的所有同步都将导入到您的 Pipeline Builder 图表中。

您不能将新管道保存到您的个人文件文件夹。请设置 推荐的项目结构 ，以便在开发流程的一开始就组织好数据安全和治理。

将 Foundry 中的数据添加到 Pipeline Builder

要导入 Foundry 文件系统中已存在的数据集或媒体集，请进入 Pipeline Builder 应用程序并选择 添加 Foundry 数据 （位于图表空间中央）。搜索并选择一个可用的数据集，然后选择 添加数据.

您可以通过逐个添加多个数据集或媒体集并选择 添加到所选内容来添加多个数据集或媒体集；全部选择完成后，选择 添加数据.

将数据从您的计算机上传到 Pipeline Builder

您也可以从您的计算机上传数据集或媒体集文件。选择 从您的计算机上传 以选择您要添加的文件，或将文件拖放到您的图表上。

在 Pipeline Builder 中手动输入数据

也可以通过定义数据表并手动填充数据来创建输入数据集。

手动输入的表仅支持作为批处理管道的输入。它们与 更快的管道.

不兼容。通过选择列名称和类型来定义新表的架构，然后手动向表中添加值。手动输入的表可以随时修改。

要从手动输入的表中删除行，请选择一行或多行，右键单击并选择 删除行 or 删除多行 （位于上下文菜单中）。

在管道中可以创建的手动输入表的数量是有限的。当管道达到此限制时，错误消息会提供有关如何解决该问题的指导。您可以使用提供的对话框查看和删除未使用或已归档的手动输入表，以释放容量。

查看大型手动输入表的提议更改时，您可能会遇到较长的加载时间。作为替代方案，您可以并排查看原始表。

下表列出了手动输入表中一些最常见的列类型：

列类型格式
字符串所有字符
时间戳mm/dd/yyy hh:mm:ss；可以使用其他时间戳
格式
日期mm/dd/yyyy
布尔0 → false，非 0 → true
二进制所有字符，将显示为 base64
整数、长整数正数和负数，无小数点
双精度浮点数正数和负数，包括小数点
数组相同类型的值的列表，输入为 [value1, value2]

选择 数组 列类型后，双击单元格或键入 [ 以打开一个弹出窗口，您可以在其中向数组添加字符串值。您必须以这种方式输入数组字符串值；不能直接粘贴。

后续步骤

将数据集或媒体集添加到 Pipeline Builder 后，您可以更改它们的 计算模式，选择 转换数据, 功能，并选择，或使用 在 Model Studio 中训练 操作直接在 Model Studio 中打开您的数据集以进行模型训练。
