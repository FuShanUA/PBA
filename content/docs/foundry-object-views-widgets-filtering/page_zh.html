筛选

许多对象视图要求用户在图表、表格、聚合指标和 KPI 等可视化组件上进行筛选。 筛选器组件 允许用户应用不同类型的筛选器，以便下钻到该对象视图中关联对象的特定子集。

此类别包含多个筛选器组件：

  • 若要按预定义属性（包括字符串、数值和日期）进行筛选，可使用 多选筛选器、 下拉筛选器、 按钮筛选器或 日期范围筛选器。
    • 使用 关联对象筛选器侧边栏 可获得更灵活的筛选功能
  • 使用 筛选器沙箱容器 可让某些筛选器仅作用于当前视图的一部分。
  • 使用 筛选器容器 可将预定义的筛选器仅应用于对象视图中的部分组件。
  • 使用 活动筛选器 以概览当前应用于对象视图的所有筛选器。

除了这些仅用于筛选的核心筛选器组件之外，还有一些专用于可视化、但也支持一定筛选功能的组件，例如图表。 条件容器 可根据用户与之交互的筛选器来显示/隐藏内容。

常见问题与注意事项：

  • 为了激活筛选器，使其在对象视图（Object View）单个标签页内的不同组件之间应用，甚至跨标签页应用， 您需要勾选“交叉筛选”复选框 ，该复选框位于右侧栏编辑器中的“设置”下。筛选器将不会应用于未勾选此复选框的标签页。

  • 为了使筛选器能够 跨不同标签页应用，请确保在您希望跨其进行筛选的所有标签页中，标签页“设置”下的“filterSet 值”具有完全相同的文本值。该值区分大小写。

    • 在这种情况下，使用相同 filterSet 值的筛选器将受到相同活动筛选器的影响。例如，如果标签页 A 和标签页 B 共享相同的 filterSet 值，那么在标签页 A 上应用的任何筛选器也将应用于标签页 B，反之亦然。

  • 在所有筛选器配置中，您选择的是与当前正在编辑的对象相关联的关联对象（Linked Object），而不是您正在编辑的对象本身。

    • 示例：如果您正在配置“机场”的对象视图，并且有“航班”与之关联，您可能会在航班上使用不同的可视化效果（时间线、图表、以表格列出所有航班），并希望针对“航班”的不同属性设置筛选器（例如，按航空公司筛选、按日期筛选、按出发城市筛选）。
    • 因此，在配置筛选器之前，您当前的对象需要已关联到另一个对象。关联的设置是在本体论管理器中完成的。

  • 大多数筛选器小部件仅添加一项可选功能，允许用户在本地针对其当前浏览对象的当前视图应用筛选器。

    • 大多数筛选器小部件不允许您预先配置默认启用的筛选器来为用户缩小视图范围（筛选器容器是一个例外，它确实允许您设置预配置的筛选器）。
    • 用户可以在当前对象的当前视图上激活筛选器，但一旦切换到其他对象或进行刷新，这些筛选器便不再适用。

多选筛选器

多选筛选器允许用户通过多个值来筛选对象视图，各值之间为“或”（OR）关系。它将保留满足至少一个所选值的所有条目。

配置

注意：始终必需的每项设置旁均标有 (*) 符号。

  • [必需] 要筛选的关联对象： 选择此筛选器要应用的关联对象。组件配置中将只为您提供与您当前正在配置的对象相链接的对象（如本体论管理器中所定义）。
    • 示例：在一个 Airport 对象视图中，该视图包含 Flights 对象的视图，并且涉及指向 Airport的两种链接：“Arriving Flights”和“Departing Flights”。如果您将多选筛选器的关联对象设置为“Arriving Flights”，则该筛选器将应用于所有同样涉及该对象“Arriving Flights”的其他组件。
  • [必需] 要筛选的属性： 选择要用于筛选的属性：(1) 首先需要为筛选器选择对象类型；然后 (2) 选择该对象上要用于筛选的属性。
    • 选中后，该值列表将在对象视图中通过带有多选下拉列表的筛选框提供给用户。受此筛选器影响且与此筛选器共享同一对象的所有其他小组件，都将被筛选为仅显示具有所选属性值（一个或多个）的对象实例。
    • 示例：在查看一个包含来自 20 个出发地的到达航班的机场对象时，用户有一个附加小组件，显示从这些出发地到达的所有航班的表格。用户为该对象选择一个多选筛选器 Arriving flights，然后选择属性 Origin City ，用于该 Flights 对象。下拉筛选器将向用户显示全部 20 个出发地。用户选择部分出发地后，表格小组件将仅显示来自这部分出发地的到达航班。
  • [可选] 筛选器标签： 将在对象视图的筛选框旁边显示给用户。
  • [可选] 筛选器选项的最大数量： 决定要筛选的属性将显示多少个不同的值。默认设置为 100。

常见问题与注意事项：

  • 配置完成后，您需要在右侧的配置编辑器设置中勾选“allow cross-filtering”（允许交叉筛选）复选框（详见上文），才能使筛选器作用于对象视图。

下拉筛选器

此筛选器可包含一个或多个筛选条件，每个筛选条件针对单个属性提供单选下拉列表，从而允许用户使用值下拉列表来筛选对象视图中的其他小部件。

配置

对于您想要配置的每个下拉筛选选项，您需要先点击“Add Item”（添加项）。只需再次点击“Add Item”，即可在单个小部件下添加多个下拉筛选器（它们将并排显示）。

添加项后，配置菜单会提供两种“Filter Type”（筛选器类型）选项：

选项 1 - 动态列表：

这是较为简单的选项，与大多数筛选器小部件一样，可以轻松地为下拉列表选择对象和属性：

  • [必填] 要筛选的关联对象： 选择此筛选器要应用到的关联对象。小部件配置将仅提供与您当前正在配置的对象相关联的对象（如 Ontology Manager 中所定义）。
  • [必填] 要筛选的属性： 选择您要用于筛选的属性：(I) 首先需要为筛选器选择对象类型；然后 (II) 选择该对象中您希望用于筛选的属性。
    • 选定后，受此筛选器影响且与此筛选器关联到同一对象类型的所有其他小组件，会将所有关联对象筛选为仅保留属性值与下拉列表中所选值相同的对象。
  • [可选] 筛选器的标签： 将在对象视图中显示给用户，位于筛选框旁边。
  • 启用“全部”筛选选项开关： 如果筛选器需要为必选项，请将此开关保持关闭，以强制用户选择一个值。如果可以选择所有值（不按任何值筛选），请打开此开关。如果您希望选择多个值，请改用多选筛选器小组件。

选项 2 - 值列表：

这是较为复杂的选项，专用于您希望定义一个精确的筛选值列表的情况，该列表将是完整下拉列表的子列表。您需要手动输入希望包含在下拉筛选器中供用户选择的每一个值。配置方法如下：

  • [必填] 要筛选的关联对象： 选择此筛选器要应用到的关联对象。
  • [必填] 要筛选的属性： 选择您希望用于筛选的属性：（I）首先需要为筛选器选择对象类型；然后（II）选择该对象中您希望用于筛选的属性。
    • 选择后，所有受此筛选器影响且与此筛选器涉及同一对象类型的其他小组件，都会从全部关联对象中筛选，仅保留属性值与下拉列表中所选值相同的对象。
  • [必填] 筛选属性值： 您需要手动输入希望包含在此下拉筛选器中供用户使用的每一个值，然后点击“创建”将其添加。
    • 输入的值区分大小写，并将按照输入的顺序显示；值一经输入便无法重新排列，除非移除值（点击“X”）并重新输入。
    • 显示的值数量最多为 100 个。
    • 默认提供“All”选项。您可以根据需要移除该选项并重新添加（“All”，区分大小写）。
  • [可选] 筛选器标签： 将显示在对象视图中的筛选框旁，供用户查看。

常见问题与注意事项：

  • 在以下情况下，请考虑使用多选筛选器代替下拉筛选器：(a) 您需要选择多个选项的功能；(b) 您不需要多个下拉列表（不过这也可以通过筛选器容器解决）。
  • 下拉控件与“Active Widget”之间的交互有限。即使已切换并启用“Enable 'All' filter option”，用户仍然无法执行“Clear filter”操作，除非他们在多选筛选器中明确选择“All”。
  • 完成配置后，您需要在右侧配置编辑器的设置中勾选“allow cross-filtering”复选框（详见上文），才能使筛选器作用于对象视图。
  • UI 在单个下拉筛选器小部件下可显示的下拉筛选框数量有限（约 7-8 个不同的下拉筛选框）。在极少数情况下，如果单个对象视图需要更多下拉筛选器，请使用额外的下拉筛选器或使用筛选器容器。

按钮筛选器

此小部件会创建一个按钮，单击即可筛选到预定义的值集合：文本（字符串）值、数值范围或日期范围。再次单击该按钮可取消对所选内容的筛选。

这是一种固定筛选器；一旦由对象视图编辑器完成配置，最终用户便无法进行任何配置选择。

请注意，按钮在选中或取消选中时会改变颜色。您可以添加 活动筛选器 以使状态更加直观。

配置完成后，其外观如下所示：

配置

首先，选择按钮筛选器类型：

  • 值列表：用于筛选文本属性（字符串）。
  • 范围：用于筛选数值属性（如整数或双精度浮点数）。
  • 日期范围：用于筛选日期属性列表。

对于所有 3 种类型的按钮筛选器，您都将拥有以下配置：

  • [必填] 要筛选的对象： 选择此筛选器要应用到的关联对象。

  • [必填] 要筛选的属性： 选择您希望用于筛选的属性：（I）您需要先为筛选器选择对象类型；然后（II）选择该对象中您希望用于筛选的属性。

    • 选择后，受此筛选器影响且与此筛选器涉及相同对象类型的所有其他小组件，将从所有关联对象中筛选缩减为仅包含属性值符合筛选条件的对象。

  • [必填] 从此处开始，按钮的设置因按钮类型而异：

    • 值列表： 手动输入您希望用于筛选的确切值列表，各值之间用“OR”语句连接。请注意，此项区分大小写，且顺序无法简单地重新排列。重新排列值的方法是删除并重新编写整个值列表。另请注意，如果您同时应用“All”选项和另一个特定值 X，则筛选器将仅应用于值 X。
    • 范围： 提供数值的下限和上限。请至少在其中一个中输入值：
      • 下限 = 大于或等于；
      • 上限 = 小于或等于；
      • 同时填写两者即可实现范围筛选。
      • 如果您希望使用“大于”筛选，请务必删除上限中的 0；反之，如果您希望使用“小于”筛选，请删除下限中的 0。
    • 日期范围： 提供包含 2 个选项的切换开关——精确日期（“从 1\1\2019 到 31\12\2019”）或相对于当前时间（“上个月”或“两年前至一年前之间”）。配置本身通过标准日历日期选择器完成。

  • [可选] 按钮标签： 在按钮上显示的文本。此为可选项，但最佳做法是为按钮设置标签。

  • [可选] 按钮颜色： 默认颜色为灰色。要为按钮选择其他颜色，请使用 Blueprint 标准颜色（参见 https://blueprintjs.com/docs/#core/colors）或使用内部的 Palantir Blueprint 库。基本颜色（“Blue”、“Red”、“Yellow”等）同样适用。

    • 未选中的按钮将显示为淡化颜色。只有在被点击后，它才会变为您所选的颜色。
    • 日期范围按钮没有选择按钮颜色的选项。

常见问题与注意事项：

  • 为了给用户提供更多灵活性，可以考虑使用：
    • “日期范围筛选器”，而非“日期范围按钮筛选器”；
    • “多选筛选器”或“下拉筛选器”，而非“值列表按钮筛选器”。
  • 请注意，有两种方法可以表明按钮筛选器的功能：(I) 为按钮设置清晰的标签；(II) 添加“生效筛选器”小部件，该小部件会显示所有筛选器，包括通过点击按钮筛选器所筛选出的实际值。
  • 按钮筛选器默认处于关闭状态，因此必须点击该按钮才能应用筛选。
  • 配置完成后，您需要在右侧的配置编辑器设置中勾选“allow cross-filtering”（允许交叉筛选）复选框（详见上文），才能使筛选器作用于对象视图。

日期范围筛选器

日期范围筛选器允许用户基于特定日期属性，将其对象视图筛选到某个日期范围内。 配置完成后，对象视图中的任何小部件都会在用户选择日期范围并点击 提交后受到影响。视图将仅显示所选日期属性中的日期处于该范围内的对象实例。

请注意，您需要插入要筛选的对象的 ID，该对象通常是您当前正在配置的对象的关联对象（Linked Object）。

配置完成后，效果如下所示：

配置

  • [必填] 要筛选的对象： 选择要应用此筛选器的关联对象。
  • [必填] 要筛选的属性： 选择要用于筛选的属性：（I）您首先需要为筛选器选择对象类型；然后（II）选择该对象中您希望用于筛选的属性。
    • 选定后，所有其他受此筛选器影响且与此筛选器涉及同一对象类型的小组件，都会从所有关联对象中筛选，仅保留所选日期属性在此日期范围内的对象。
  • [可选] 筛选器标签： 将在对象视图（Object View）中显示给用户，位于筛选框旁边。

  • 配置完成后，您需要在右侧配置编辑器的设置中勾选“allow cross-filtering”（允许交叉筛选）复选框（详见上文），才能使筛选器作用于对象视图。

关联对象筛选器侧边栏

此小组件可创建灵活的筛选体验，允许用户从关联对象的所有属性中选择任意一组特定值，对当前的对象视图进行筛选。

此小组件为用户提供了高度的选择自由，但也增加了复杂性。它要求用户理解并熟悉关联对象的属性，而所有其他筛选器小组件（例如下拉筛选器、按钮筛选器）则会预先配置这些属性。

配置完成后，其效果如下所示：

配置

此小组件的配置只需选择您希望对象视图据以进行筛选的关联对象。其余配置（即选择用于筛选的具体属性和值）完全由用户自行决定，并且仅在其本地视图中生效。用户一旦刷新页面或切换到其他对象，就需要重新配置这些筛选器。

常见问题与注意事项：

  • 为某一属性选择的所有值之间将使用“OR”（或）语句。不同属性的值之间将使用“AND”（与）语句。
    • 示例：在处理“机场”对象时，对象视图编辑器选择为关联对象“到达航班”添加关联对象筛选器侧边栏。用户可以选择按属性“月份”进行筛选，仅选择一月至六月；也可以按“航空公司名称”进行筛选，选择达美航空和联合航空。该视图将被筛选为仅显示该机场内一月至六月之间（一月或二月……或六月）、且属于联合航空或达美航空的所有到达航班。

筛选器沙盒容器

筛选器沙盒容器使您能够将小部件组织到一个容器中，使容器内的所有筛选器都被沙盒化，这意味着它们仅会影响该容器内的其他小部件，也仅会受到该容器内其他小部件的影响。

配置

添加筛选器沙盒容器小部件，然后通过点击“添加项”将现有小部件添加到容器中。 从小部件选择器中选择要添加的小部件。

另一个配置选项是筛选器集标识符。默认情况下，每个新的筛选器沙盒都会生成一个新的唯一值。如果希望与以下对象共享筛选器，则可以更改该值：

  • 筛选器沙盒容器 - 为两者设置相同的筛选器集标识符值。
  • 另一个标签页上的所有小部件 - 在目标标签页上启用跨区块筛选，并为其设置相同的筛选器集标识符值。

常见问题与注意事项：

  • 此容器始终启用交叉筛选（即筛选器会影响容器内的其他小部件，同时也会受其影响）。
  • 如需对容器内的小部件进行交叉筛选，请使用此容器而非筛选器容器小部件来进行沙箱处理。如需小部件仅受预定义筛选器的影响，请使用禁用了筛选器订阅的筛选器容器。
  • 如果您既需要沙箱内的交叉筛选，又需要预定义筛选器，请使用筛选沙箱容器，并在其中添加一个筛选器 容器，同时启用筛选器的发布和订阅。

筛选器容器

此小部件支持创建一个独立的小部件子集，并将一组 预定义筛选器 仅应用于其中的小部件。

此筛选器子集可基于以下属性类型的任意组合进行定义：（1）文本（字符串）值列表；（2）数值范围；及\或（3）日期范围。

请勿将此小部件用作筛选沙箱，因为它仅支持预定义筛选器。

注意:要获得一个筛选沙箱容器(即让筛选条件仅应用于容器内部,且不受外部筛选条件的影响),请使用 筛选沙箱容器 作为替代。

配置

筛选容器配置包含两个部分:

第 1 部分 - 将预配置的筛选条件应用于容器内的所有小部件

这些预定义的筛选条件在默认情况下 仅会应用于容器内的小部件。容器内的预定义筛选条件可以是以下三种筛选类型的任意组合:

  • 值列表 - 用于筛选文本属性(即字符串)
  • 范围 - 用于筛选数值属性(即整数、双精度浮点数)
  • 日期范围 - 用于筛选日期属性列表

对于每个默认筛选条件,您需要配置以下内容:

  • [必填] 要筛选的关联对象: 选择此筛选条件所应用的关联对象。小部件配置中仅提供与当前对象相关联的对象(如本体论管理器中所定义)。
  • [必填] 要筛选的属性: 选择您想要用于筛选的属性:(I)您需要先为筛选条件选择对象类型;然后 (II) 选择该对象中您希望用于筛选的属性。
    • 选择后,此容器内与同一对象类型相关的所有其他小部件,其筛选范围将从所有关联对象缩小至仅包含属性值满足筛选条件的那些对象。
  • [必填]从此处开始,不同筛选器类型(文本值列表、数值范围、日期范围)的设置有所不同:
    • 值列表: 手动输入您希望筛选的确切值列表,各值之间使用“OR”语句连接。请注意,该筛选区分大小写,且值的顺序无法直接重新排列。若要重新排列值,只能删除并重新编写整个值列表。另请注意,如果您同时应用“全部”选项和另一个特定值 X,则筛选器将仅应用于值 X。
    • 范围: 这允许您设置数值范围的下限和上限。请至少在其中一个中输入数值:
      • 下限 = 大于或等于;
      • 上限 = 小于或等于;
      • 同时填写两者即可创建范围筛选器。
      • 如果您希望实现“大于”筛选,请务必删除上限中的 0;反之,若要实现“小于”筛选,请删除下限中的 0。
    • 日期范围: 提供了一个包含 2 个选项的切换开关——精确日期（“从 1\1\2019 到 31\12\2019”）或相对于当前时间的日期（“上个月”或“介于两年前与一年前之间”）。配置本身通过标准的日历日期选择器完成。
  • [可选] 筛选器标签： 用于文档说明的内部标签，不会在任何地方向用户显示。可选。

交叉筛选设置：

  • 嵌套节是否订阅筛选器？ 如果您希望筛选器容器受到容器外部所应用筛选器的影响——这些筛选器既可来自包含该容器的标签页，也可来自与当前标签页共享交叉筛选的其他标签页。这还会使其使用容器内的其他筛选器组件，例如选中了某个柱形的图表组件或多选筛选器。
  • 嵌套节是否发布筛选器？ 如果您希望筛选器容器内部的筛选器在容器外部生效——既作用于包含该容器的标签页，也作用于与当前标签页共享交叉筛选的其他标签页。这不适用于预定义筛选器，仅适用于容器内的任何附加筛选器组件。

如何使用这些切换开关？

  • 两个开关均关闭 - 预定义筛选器仅在容器内生效,但容器既不发布也不使用任何其他筛选器 - 无论这些筛选器位于容器内部还是外部。
  • 仅开启 Subscribe 开关 - 容器会受外部筛选器的影响,但容器内的筛选功能不生效,预定义筛选器除外。
  • 仅开启 Publish 开关 - 容器内的筛选器组件仅在容器外生效,而在容器内不生效。容器内只有预定义筛选器会生效。
  • 两个开关均开启 - 标签页上的所有筛选器在任何位置均生效,但本容器中的预定义筛选器除外。

常见问题与注意事项:

  • 预定义筛选器仅在容器内生效,不会应用于容器外的任何组件。这一规则仅适用于这些预定义筛选器,而不适用于可在容器内配置的其他筛选器组件。正在寻找沙箱容器功能?请尝试 筛选器沙箱容器。
  • “筛选器容器”中的预定义筛选器不会在 UI 中向用户显示,用户也无法将其移除,除非您按照以下步骤操作:
    • 在“筛选器容器”内添加一个“活动筛选器”组件,以将其显示出来。
    • 请确保“Enable removing default filters”开关已开启（默认为开启状态）。否则，即使使用“Active Filter”移除选项，用户也无法移除这些筛选器。
  • 在筛选器容器内应用筛选器时，还会移除筛选器组件中不匹配的选项，例如 下拉筛选器。如果不希望出现此行为，请改用 筛选器沙箱容器 。

第 2 部分 - 将筛选器容器用作组件容器

像配置任何其他容器一样配置此容器内的视图。您添加的每个组件都会订阅筛选器容器的预定义筛选器，以及任何其他被定义为会影响该组件的筛选器。

单击“Add Section”后，您将获得与主对象视图或其他带嵌套选项卡的组件（例如任何容器组件）上的任何其他“Add Section”相同的配置体验。

分区布局：

此设置决定筛选器容器内的组件是垂直堆叠（一个位于另一个下方，此为默认设置）还是水平排列（一个挨着一个，从左到右）。

活动筛选器

此小组件会显示当前应用于对象视图的所有筛选器的摘要，并允许用户移除单个筛选器或清除所有筛选器。此筛选器无需任何配置。

活动筛选器是一个实用的视觉指示，可帮助用户了解其对象视图中当前处于活动状态的筛选器。当对象视图包含多个筛选小组件（包括使用图表进行的筛选）时，尤其是在使用筛选器容器或按钮筛选器的情况下，活动筛选器的可见性对用户体验非常重要。
