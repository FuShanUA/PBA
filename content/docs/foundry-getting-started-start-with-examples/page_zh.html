从 Examples 开始

要开始使用 Palantir 平台，您可以使用 Examples，它是 Build with AIP 的一个平台内组件。Examples 是一个综合性资源库，旨在促进学习和高效使用平台。Examples 为应用构建者和开发者提供参考示例、教程和入门套件，以便快速开发新应用。

主要功能

Examples 内置了两项功能，以支持用户学习：

  • 自带数据： 带有“自带数据”标签的 Examples 可让您使用自己的数据轻松安装复杂的工作流。找到 使用自己的数据 部分并选择 安装，然后从桌面拖放文件（或上传 Foundry 中的现有资源）。



  • 操作指南： 获取分步指南，了解如何使用 AIP Assist 构建此特定工作流。



访问示例

您可以从左侧的工作区导航栏访问示例，然后前往 支持 > 探索示例。此外，您还可以直接从应用程序启动页面探索各应用程序专属的示例。
