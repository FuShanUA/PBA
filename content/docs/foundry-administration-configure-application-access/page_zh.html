配置应用程序访问

该 应用程序访问 部分位于 Control Panel 中，允许相应的管理员控制用户和组对 Foundry 中特定工具的访问范围。

限制应用程序访问的一种常见使用模式是，避免在 Foundry 中通过自定义应用程序进行操作，或仅使用一小组精选分析和其他资源的用户分心或产生混淆。限制这组用户可使用的应用程序范围，可以简化他们的 Foundry 体验。

另一种常见模式是使用应用程序访问功能，让平台管理团队或一组高级用户提前访问 测试版 应用程序，同时限制其对更广泛用户群体的可用性。

这甚至可以延伸到移除对几乎所有 Foundry 应用程序的访问权限。在这种情况下，用户将只能访问面向最终用户的应用程序，例如 Slate 和 Workshop。

应用程序访问并非安全功能；它只是为无需查看某些应用程序的用户简化前端用户体验。请参阅 安全文档 以获取有关如何通过权限正确限制功能访问的指导。

要查看和配置 Control Panel 中的应用程序访问部分，用户需要 “管理应用程序访问”权限。 工作流，该工作流由 用户体验管理员 角色授予。角色在 组织权限 选项卡中进行管理，该选项卡位于控制面板中。

变更请求

更改应用程序访问配置将在 审批。这些请求可以在 控制面板中的审批收件箱 中查看，请求类型为 应用程序访问变更请求。系统将保留所有更改的历史记录。

配置审批策略

默认情况下，应用程序访问变更请求将自动自行批准并应用。可以在 高级设置 选项卡中进行配置。

选择 管理 以请求更改审批策略。这将打开一个对话框，您可以在其中选择要应用于应用程序访问请求的新策略。

选择所需的新审批策略，然后选择 请求变更。这将在审批中生成一个变更请求。审批策略的更改需要由具有 管理应用程序访问 工作流的用户（变更请求创建者除外）进行批准。

一旦获得批准，更新后的审批策略将立即开始应用于应用程序访问变更请求。

限制平台访问

默认情况下，Foundry 用户可以访问 Foundry 平台的大部分内容。通过应用程序访问功能，可以为不同的组灵活定制 Foundry 体验。

限制最严格的配置是完全移除对 Foundry 平台的访问权限。有两种选项可用于限制对 Foundry 平台的访问：允许列表或阻止列表。 除组成员以外的所有人 限制属于至少一个指定组的用户的访问权限。 仅限组成员 限制的是 不 属于任何指定组的用户的访问权限。对 Foundry 平台访问受限的用户将只能访问在 Slate 或 Workshop 中构建、且已被明确授予资源级访问权限的面向使用者的应用程序。对于这些用户，Foundry 侧边栏将被隐藏，且他们将无法导航至 Foundry 的任何其他部分。请注意，应用程序访问在应用程序级别运作；这些控制措施不区分读取和写入权限。

要限制哪些用户能够访问整个 Foundry 平台：

  1. 选择 管理 （位于 Foundry 平台 旁边），以打开配置 Foundry 平台访问权限的对话框。
  2. 选择 除组成员以外的所有人 或 仅以下组的成员。
  3. 搜索根据之前的选择应有权或无权访问平台的用户组。
  4. 选择 请求并应用更改 以创建更改请求并立即应用该更改。

请注意，具有 用户体验管理员 角色的用户账户必须至少保留在一个仍具有 Foundry 平台访问权限的组中，否则该账户将失去对 Control Panel 的访问权限，无法再管理这些设置。

自定义应用程序访问权限

可以按应用程序对 Foundry 平台的范围进行限制。无权访问某个应用程序的用户将无法从侧边栏或 Application Portal中发现该应用程序。此外，当这些用户尝试通过无权访问的 URL 访问应用程序时，将会看到 403 "Permission denied" 错误消息。

所有应用程序按类别和 生命周期阶段分组，并按字母顺序排序。

选择 管理 以打开用于配置单个应用程序访问权限的对话框。要为多个应用程序配置相同的访问设置，请切换页面顶部的 管理多个应用程序 开关，并选择要更新的应用程序。

在这种情况下，管理对话框会显示所有选定的应用程序及其当前的生命周期阶段和访问设置。

请注意，Control Panel 无法被完全禁用。至少需要一个您所属的组拥有访问权限，否则您将无法再管理这些设置。

生命周期阶段更新

应用程序遵循 开发生命周期。当应用程序从一个生命周期阶段过渡到下一个阶段时，同一批用户将保持访问权限，但以下情况除外：

  • 当应用程序正式发布时，所有用户都将自动获得访问权限，除非该应用程序在实验或 beta 阶段已被明确禁用。将被自动启用的 beta 应用程序在 应用程序访问 中显示为“尚未启用”而非“已禁用”，以指示此状态。
  • 当应用程序被弃用时，所有用户都将失去对其的访问权限。

为了突出显示重要的生命周期阶段更新，某些应用程序会显示在页面顶部，直到其设置得到确认或更新为止：

  • 已正式发布但先前被禁用的应用程序： 在实验或 beta 阶段被明确禁用或仅限特定用户组使用的应用程序，在这些应用程序进入正式发布阶段后仍将保持受限状态。可使用快速操作来保留该限制，或在其新的生命周期阶段为所有用户启用该应用程序。
  • 近期已退役且已启用的应用程序： 当应用程序进入退役阶段时，此前拥有访问权限的用户将保持其访问权限。此时不建议使用该应用程序，但仍会为关键 bug 修复提供支持。如果已设定弃用时间线（通常为 12 个月），则会公布弃用日期，并在应用程序访问页面上将其显示在该应用程序旁边。请与用户协作，在弃用日期之前减少该应用程序的使用，然后将其禁用。
  • 已弃用且已启用的应用程序： 在应用程序处于设定了弃用日期的退役阶段期间，预计所有用户都已迁移到其他工作流。已弃用的应用程序可能随时从您的 Foundry 安装中消失，不应再使用。

请注意，所有应用程序生命周期阶段都将提前两周在文档的 公告 部分中公布。在 平台管理 联系信息 也将收到有关这些变更的电子邮件。
