配置应用程序访问权限

直方图 应用程序访问 控制面板中的部分允许相应的管理员控制用户和组对 Foundry 中特定工具的访问范围。

限制应用程序访问权限的一个常见使用场景是，为 Foundry 中使用自定义应用程序或仅使用一组精选分析和其他资源的用户减少干扰或避免混淆。限制该用户组可用的应用程序范围可以简化他们的 Foundry 体验。

另一种常见模式是使用应用程序访问权限，让平台管理团队或一组高级用户提前访问 测试版 应用程序，同时限制更广泛的用户群体使用这些应用程序。

甚至可以做到移除几乎所有 Foundry 应用程序的访问权限。在这种情况下，用户只能访问面向消费者的应用程序，例如 Slate 和 Workshop。

应用程序访问权限不是一项安全功能；它只是为无需查看某些应用程序的用户简化前端用户体验。请参阅 安全文档 以了解如何正确设置功能的权限。

要查看和配置控制面板中的应用程序访问权限部分，用户需要 管理应用程序访问权限 工作流，该工作流由 用户体验管理员 角色授予。角色在 组织权限 控制面板中的选项卡进行管理。

变更请求

更改应用程序访问权限配置将在 审批中生成一个变更请求。这些请求可以在 控制面板中的审批收件箱 中查看，请求类型为 应用程序访问权限变更请求。所有更改的历史记录都将被保留。

配置审批策略

默认情况下，应用程序访问权限变更请求将被自动自我批准并应用。这可以在 部分中选择 标签页。

选择 管理 中请求更改审批策略。这将弹出一个对话框，您可以在其中选择应用于应用程序访问权限请求的新策略。

选择新的所需审批策略，然后选择 请求变更。这将在审批中生成一个变更请求。审批策略的更改需要由具有 管理应用程序访问权限 工作流的用户（变更请求作者除外）批准。

批准后，更新后的审批策略将立即开始应用于应用程序访问权限变更请求。

限制平台访问

默认情况下，Foundry 用户可以访问 Foundry 平台的大部分功能。通过应用程序访问权限，可以为不同的用户组灵活定制 Foundry 体验。

最严格的配置是完全移除 Foundry 平台访问权限。有两种限制 Foundry 平台访问权限的选项：允许列表或阻止列表。 除指定组的成员外的所有人 限制属于至少一个指定组的用户的访问权限。 仅指定组的成员 限制 不 不属于任何指定组的用户的访问权限。对 Foundry 平台访问受限的用户只能访问使用 Slate 或 Workshop 构建的、且已被明确授予资源级访问权限的面向消费者的应用程序。对于这些用户，Foundry 侧边栏将被隐藏，并且他们将无法导航到 Foundry 的其他任何部分。应用程序访问权限在应用程序级别运行；这些控制不区分读取和写入权限。

要限制哪些用户能够整体访问 Foundry 平台：

  1. 选择 管理 + 新建 Foundry 平台 以弹出用于配置 Foundry 平台访问权限的对话框。
  2. 选择 除指定组的成员外的所有人 or 仅指定组的成员.
  3. 搜索用户组，根据先前的选择，这些用户组应或不应具有平台访问权限。
  4. 选择 请求并应用变更 以创建变更请求并立即应用。

具有 用户体验管理员 角色的用户账户必须保留在至少一个拥有 Foundry 平台访问权限的组中，否则该账户将失去对 Control Panel 的访问权限，从而无法再管理这些设置。

自定义应用程序访问权限

Foundry 平台的范围可以按应用程序进行限制。没有某个应用程序访问权限的用户将无法从侧边栏或 Application Portal中发现该应用程序。此外，当他们尝试通过无权访问的 URL 访问某个应用程序时，将看到 403 "权限被拒绝"错误消息。

所有应用程序按类别和 生命周期阶段进行分组，并按字母顺序排序。

选择 管理 以打开用于配置单个应用程序访问权限的对话框。若要为多个应用程序配置相同的访问设置，请切换 管理多个应用程序 （位于页面顶部），并选择要更新的应用程序。

在这种情况下，管理对话框会显示所有选定的应用程序及其当前的生命周期阶段和访问设置。

Control Panel 无法被完全禁用。至少一个您所属的组需要拥有访问权限，否则您将无法再管理这些设置。

生命周期阶段更新

应用程序遵循 开发生命周期。当应用程序从一个生命周期阶段过渡到下一个阶段时，同一组用户将保持访问权限，但以下情况除外：

  • 当应用程序正式发布（general availability）时，所有用户将自动获得访问权限，除非该应用程序在实验阶段或测试阶段已被明确禁用。将被自动启用的测试版应用程序在 应用程序访问 中显示为"尚未启用"而非"已禁用"，以指示此状态。
  • 当应用程序被弃用时，所有用户将失去对其的访问权限。

为了突出显示重要的生命周期阶段更新，某些应用程序会显示在页面顶部，直到其设置被确认或更新：

  • 已正式发布但先前被禁用的应用程序： 在实验阶段或测试阶段被明确禁用或仅限特定用户组使用的应用程序，在正式发布后仍将保持受限状态。可使用快捷操作来保持限制，或在其新的生命周期阶段为所有用户启用该应用程序。
  • 已启用但近期下线的应用程序： 当应用程序进入下线（sunset）阶段时，之前拥有访问权限的用户将保持访问权限。此时不建议继续使用该应用程序，但仍会提供对关键错误修复的支持。如果已设置弃用时间线（通常为 12 个月），弃用日期将被公布并显示在应用程序访问页面上该应用程序的旁边。请与用户合作，在弃用日期之前减少该应用程序的使用，然后将其禁用。
  • 已弃用但仍处于启用状态的应用程序： 预期所有用户在应用程序处于带弃用日期的下线阶段期间已迁移到其他工作流程。已弃用的应用程序可能随时从您的 Foundry 安装中消失，不应再被使用。

所有应用程序生命周期阶段将提前两周在 公告 文档的相应部分中公布。在 平台管理 联系信息 中配置的地址也将收到有关这些更改的电子邮件通知。
