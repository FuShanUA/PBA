键盘快捷键

本页面列出了 Code Workbook 中当前可用的 macOS 和 Windows 键盘快捷键。

选择 帮助 菜单（位于左上角），然后选择 ⌘ 键盘快捷键 以查看包含所有键盘快捷键的弹出窗口。此外，您还可以通过以下方式查看所有键盘快捷键： Shift+?.

macOS 快捷键

编辑器

  • 在控制台中运行所选代码： Cmd+Shift+Enter
  • 打开补全建议： Tab
  • 关闭全屏查看器或编辑器 / 清除新节点： Esc
  • 打开全屏编辑器： Cmd+Alt+E

执行

  • 运行所选数据集： Cmd+Enter
  • 运行所有已保存的数据集： Cmd+Alt+Enter

图表

  • 删除选定的节点： Del
  • 删除选定的节点： Backspace
  • 缩放至选定的节点： Space
  • 布局所有图节点： Cmd+Shift+A
  • 按颜色组布局所有图节点： Ctrl+Shift+G
  • 布局选定的图节点： Cmd+L
  • 选择下一个节点： Right arrow
  • 选择上一个节点： Left arrow
  • 选择所有图节点： Cmd+A

工作簿

  • 导入数据集： Cmd+Alt+R
  • 打开分支菜单： Cmd+B
  • 在工作簿中搜索： Cmd+Shift+F
  • 关闭所有辅助面板： Ctrl+Cmd+C

  • 布局所有图节点： Ctrl+Shift+A
