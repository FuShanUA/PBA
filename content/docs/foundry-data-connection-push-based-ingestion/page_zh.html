将数据推送到流中

Foundry 中的大多数数据摄取侧重于从源系统拉取数据并将其同步到数据集或流中。

通过流，Foundry 支持 借助流，Foundry 还支持 以支持基于事件的工作流。

如果您已经为数据配置了 Foundry 源，则可能需要改为连接该源。了解如何 设置流式同步 与现有源配合使用，或了解如何 设置 Kafka 源.

如果您需要从无法与 Foundry 正确进行身份验证或不符合标准流架构的系统接收入站 webhook，请考虑使用 监听器.

Foundry 中的基于推送的记录摄取遵循与典型 REST 服务相同的原则。我们通过一系列 REST 端点公开一个基于推送的 API，该 API 可以使用记录并将其写入流和数据集。推送到流中需要以下高级信息：

  • 流的数据集资源标识符。
  • 分支的名称。
  • 用于对请求进行身份验证的令牌。

下面，我们将讨论将数据推送到流中所需的步骤：

  1. 设置 一个新流。
  2. 推送记录 到流中。
  3. 共享 该流。
  4. 测试 该流。

第 1 部分：初始设置

首先，开始创建流的工作流程。

  1. 登录 Foundry。
  2. 导航到 项目.
  3. 选择 + 新建 在右上角。
  4. 向下滚动并选择 Stream.

接下来，我们必须定义流的架构、吞吐量和键。

  • 模式 定义流数据的结构和类型。
  • 吞吐量 表示数据处理速率，将影响流中使用的分区数量。在我们的 吞吐量 and 分区 documentation.
  • 键 用于在使用多个分区时保证唯一 ID 的顺序。在我们的 流式处理键 documentation.

在本教程中，我们将创建一个简单的单分区流。

  • 将架构设置为 sensor_id: String, temperature: Double日 created_at: Timestamp.
  • 将吞吐量设置为 Normal.

然后，配置您的流。

  • 通过选择 Generate from JSON sample... 按钮并粘贴您现有的 JSON blob，从现有 JSON blob 自动生成架构。
  • 设置 （CDC）同步。Db2 CDC 同步是通过 如果您要从关系数据库流式传输实时更新。
  • 考虑流的并行性要求，以确定是否需要更高的吞吐量设置。查看我们的 分区 文档以了解更多信息。
  • 考虑在使用多个分区时设置键以保证顺序。

在选择 创建流之前，您必须解决所有验证错误。将鼠标悬停在页面底部的工具提示上，以了解有关错误的更多详细信息。

选择 创建流 按钮，导航到 连接 页面。在此处，您可以指定如何连接到流式数据。

第 2 部分：将记录推送到流中

我们现在已准备好连接流。

  1. 对于基于推送的摄取，请选择 通过 API 连接 区域的字段中添加命令。

    任何能够发出 HTTP 请求的语言或技术都可用于推送记录。我们提供了 cURL、Python、通过 Node 的 JavaScript 以及 Java 的示例。如果您想通过 Foundry 同步摄取数据而不是将数据推送到 Foundry，请查看如何 设置流式同步.

    在本示例中，我们将选择 cURL.

    然后您将进入 推送 数据工作流页面。

  2. 接下来，选择一种身份验证机制。我们支持两种对请求进行身份验证的方式：

    • 使用第三方应用程序推送（推荐）： 此方法使用 OAuth2 工作流创建可用于将记录推送到流中的安全令牌。
    • 使用个人令牌推送： 此方法使用用户生成的令牌，仅用于测试目的。

  3. 在本教程中，请选择 使用第三方应用程序推送 方法。您需要一个通过客户端凭据授予进行身份验证的应用程序，以便 Foundry 向其颁发客户端 ID、客户端密钥和服务用户。通过您的注册中可用的任何途径创建该应用程序：

    • 开发者控制台（推荐）： 设置客户端凭据，选择 后端服务 ，该选项位于 应用程序类型 页面并 应用权限 ，该选项位于 权限 页面。获得客户端 ID 和密钥后，请继续执行下方的第 8 步。第 9 至 11 步仅适用于控制面板路径，因为选择 应用权限 已启用客户端凭据授权。
    • 控制面板： 如果开发者控制台未对您启用，请按照 注册第三方应用程序 注册一个已启用客户端凭据授权的机密客户端。下方的第 4 至 11 步将逐步介绍此路径。

    任一路径都要求在应用程序的操作限制中包含 api:use-streams-write 操作，然后才能将记录推送到流中；请参阅 操作限制.

  4. 控制面板路径： 选择 前往第三方应用程序 以在您的 Foundry 平台设置中打开第三方应用程序管理页面。

  5. 选择 注册新应用程序 位于屏幕右上角。

  6. 选择一个名称，并将客户端类型设置为 服务器应用程序.

  7. 选择 创建， 然后系统将向您显示客户端 ID 和密钥。

    离开此页面后将无法再访问客户端密钥。请务必将其存储在安全的位置。

  8. 现在，您可以将客户端 ID 和密钥添加到 推送 工作流页面。

  9. 下拉菜单中）。 配置应用程序 部分，然后选择 第三方应用用户界面 以打开 第三方应用 管理页面（位于您的 Foundry 平台设置中）。

  10. 接下来，启用 客户端凭据授权 设置，对分支的合并保留实质性的控制权。

  11. 最后，点击 保存 在右上角。

第 3 部分：共享流

现在，我们需要与我们创建的应用程序共享该流。

  1. 首先，返回 推送 工作流页面。在工作流中的 使用您的新应用程序 部分，找到您生成的客户端 ID。

  2. 接下来，选择 共享 在右上角以打开 角色 流的 详情 侧边栏（位于屏幕右侧）。

  3. 将客户端 ID 复制并粘贴到 角色 搜索字段中，以找到您创建的应用程序。选择 + 以搜索并选择 Editor 组织概览

  4. 选择 保存 在侧面板底部以共享该流。

  5. 返回推送工作流并选择 下一步。
