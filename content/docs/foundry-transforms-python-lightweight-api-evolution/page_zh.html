轻量级转换 API 的演进

用于 轻量级计算 的转换 API 随着时间的推移不断演进，以支持更加精简的语法选项。

请参阅此页面，了解轻量级 API 演进的详细信息。

要开始编写轻量级转换，请参阅 快速入门 ，或参阅 Python 转换中的 Polars 和 pandas 示例。这些页面介绍了如何将轻量级转换用作默认计算选项。

旧版语法：@lightweight 装饰器

轻量级计算的原始语法是 @lightweight 装饰器。此语法选项仍完全受支持。

from transforms.api import transform, lightweight, Input, Output


@lightweight
@transform(
    output=Output("/path/data/output"),
    input=Input("/path/data/input"),
)
def clean(output, input):
    df = input.pandas()
    output.write_table(df)

轻量级的更新语法

访问轻量级转换的推荐新语法是 @transform.using。此 API 无需额外的轻量级导入，并简化了以默认方式创建轻量级转换的过程。

新 API 适用于 transforms 版本 3.68.0 及更高版本。要在代码仓库中使用此功能，请通过 仓库升级指南升级您的仓库。请确保 transformsLangPythonPluginVersion 为 1.978.0 或更高版本。

要了解有关 transforms 版本的更多信息，请参阅 transforms 版本概览。

from transforms.api import transform, Input, Output


@transform.using(
    output=Output("/path/data/output"),
    input=Input("/path/data/input"),
)
def clean(output, input):
    df = input.pandas()
    output.write_table(df)

总而言之，您可以使用以下任一语法选项创建轻量级转换：

  • 更新后的 API：
    @transform.using(...)
  • 显式引用轻量级的更新后 API：
    @transform.lightweight(...)
  • 使用 @lightweight 装饰器的旧版 API：
    @lightweight
    @transform(...)

Spark 的更新语法

除了新的默认轻量级 API 之外，还有一个适用于 Spark 的新 transforms API。推荐语法为 @transform.spark.using。

新 API 适用于 transforms 版本 3.95.0 及更高版本。要使此 API 在代码仓库中可用，请按照 仓库升级指南升级您的仓库。请确保 transformsLangPythonPluginVersion 等于 1.1003.0 或更高版本。

@transform.spark.using(
    output=Output("/path/data/output"),
    input=Input("/path/data/input"),
)
def clean(output, input):
    df = input.dataframe()
    output.write_dataframe(df)

Databricks Connect 的更新语法

要定义通过 Databricks Connect 将计算下推到 Databricks 的转换，请使用组合装饰器 @transform.databricks.using。这种标准化语法取代了之前混合使用 @databricks 和 @transform 装饰器的模式。

您可以链式调用配置方法来指定计算和依赖项：

  • with_compute(cluster_id="<cluster-id>") 用于连接到特定的 Databricks 计算集群
  • with_dependencies(dependencies=["<dependency>"]) 用于在 Databricks 计算上安装 UDF 所需的 Python 包

默认情况下，Databricks Connect 会使用无服务器计算建立会话。

from pyspark.sql.functions import col
from transforms.api import transform
from transforms.tables import DatabricksInput, DatabricksOutput, TableInput, TableOutput

@transform.databricks.using(
    source_table=TableInput('/Project/folder/input'),
    output_table=TableOutput(
        '/Project/folder/output',           # Register virtual table in Foundry
        'ri.magritte..source.1234',         # Databricks source connection RID
        'CATALOG.SCHEMA.TABLE',             # Unity Catalog table target in Databricks
    ),
).with_compute(cluster_id="<cluster-id>")
def compute(source_table: DatabricksInput, output_table: DatabricksOutput):
    df = source_table.dataframe()
    df = df.filter(col('id') > 1)
    output_table.write_dataframe(df)

from pyspark.sql.functions import udf
from pyspark.sql.types import StringType
from transforms.api import transform
from transforms.tables import DatabricksOutput, TableOutput

@udf(returnType=StringType())
def get_joke():
    from pyjokes import get_joke
    return get_joke()

@transform.databricks.using(
    output_table=TableOutput(
        '/Project/folder/output',
        'ri.magritte..source.1234',
        'CATALOG.SCHEMA.TABLE',
    ),
).with_dependencies(dependencies=["pyjokes<1"])
def compute(output_table: DatabricksOutput):
    df = output_table.spark_session.range(1, 10)
    df = df.withColumn('jokes', get_joke())
    output_table.write_dataframe(df)

排查 @transform.using 的版本错误

如果您收到类似以下内容的错误消息，则可能是您使用的 transforms 库版本较旧，不支持更新后的语法。

  • Usage of transform.using() on outdated repository
  • A function object does not have an attribute using

要解决此问题，请尝试以下选项：

  • 将您的仓库升级到最新版本的 transforms 库和仓库模板，具体请遵循 仓库升级指南。
  • 切换到 旧版语法.
