使用 OAuth 2.0 的用户归属 SAP 写回

本页面包含以下操作的说明： 在 SAP 中设置 OAuth 2.0 服务器 和 在 Foundry 中设置 OAuth 2.0 客户端.

在 SAP 中设置 OAuth 2.0 服务器

前提条件

  • Palantir Foundry Connector 2.0 for SAP Applications（"Connector"）的 SP21 或更高版本
  • SAP 中的 Foundry 技术用户应为 SYSTEM user
  • /PALANTIR/OAUTH_CLIENT 应分配给 Foundry 技术用户以及任何希望从 Foundry 回写至 SAP 的最终用户
  • /PALANTIR/CONTENT_FUNCTION_ALL 应分配给最终用户
  • 以下所有服务 /sap/public/bc 节点需要激活（用于 OAuth 2.0 配置）
    • /sap/bc/sec/oauth2*
    • /default_host/sap/bc/webdynpro/sap/oauth2_authority
  • SAP Gateway 已激活
  • SAP_BASIS（技术组件版本，适用于 SAP NetWeaver 和 SAP S/4HANA 系统）7.4 SP09 或更高版本（支持 OAuth 2.0 和 OData）

请参阅

  • Note 1688545 - AS ABAP 中 OAuth 2.0 服务器的故障排除 ↗ （需要 SAP 登录）
  • 帮助：AS ABAP 的 OAuth 2.0 服务器 ↗

OAuth 2.0 配置

  1. 运行 SOAUTH2 transaction.
  2. 选择 创建....
  3. 输入 Foundry 技术用户的用户名作为 OAuth 2.0 客户端 ID.
  4. 选择 下一步 >.
  5. 输入 Foundry 技术用户的用户名作为 用户 ID.
  6. 确保 客户端用户 ID 和密码 and SSL 客户端证书 均已勾选。
  7. 选择 下一步 >.
  8. 设置 重定向 URI as https://<FOUNDRY_DOMAIN>/workspace/oauth2-clients/callback.
  9. 选择 下一步 >.
  10. 添加一个 作用域分配 并带有 OAuth 2.0 作用域 ID of /PALANTIR/SRV_0001 以及描述，例如 Palantir Foundry writeback using SAP functions.
  11. 选择 下一步 > 用户偏好 完成.

OData 配置

  1. 在监听器设置向导的 维护服务 页面，按照服务层级结构找到 opu > odata > palantir.
  2. 右键点击 palantir 并选择 激活服务.
  3. 选择 是 出现提示时。
  4. 在 创建/更改服务 标签页中，选择 GUI 配置 under 交互式选项.
  5. 添加名称为以下内容的参数 ~CHECK_CSRF_TOKEN 以及值 0 (zero).
  6. 按照此处说明禁用 CSRF_TOKEN 验证： https://help.sap.com/doc/saphelp\_hba/1.0/de-DE/e6/cae27d5e8d4996add4067280c8714e/content.htm
  7. 运行 /IWFND/MAINT_SERVICE transaction.
  8. 选择 添加系统别名 under 系统别名.
  9. 添加具有以下值的系统别名：
    • 服务文档标识符： /PALANTIR/SRV_0001
    • 用户角色： blank
    • 主机名： blank
    • SAP 系统别名： LOCAL
    • 元数据默认值： unchecked
    • 默认系统： checked
    • 技术服务名称： /PALANTIR/SRV
    • 外部服务名称： ODATA_SRV
    • 版本： 1
    • 用户名： blank

在 Foundry 中设置 OAuth 2.0 客户端

这遵循了以下内容中概述的通用方法 配置出站应用程序 但已针对 SAP 系统进行了专门调整。

选择与您的 SAP 连接相匹配的设置：

  • 如果您的 SAP ERP 源使用 （如果使用代理 worker）。，请按照 使用 SAP Data Accelerator 的出站应用程序设置.
  • 对于使用代理出口策略的连接，请按照 出站应用程序设置.

出站应用程序设置

  1. 导航到控制面板并选择 Outbound 应用程序 under 组织设置.
  2. 选择 新建应用.
  3. 提供一个 应用程序名称，例如您的 SAP 系统的名称。
  4. 设置 批准提示 来描述授权操作，例如， Allow Foundry to act on your behalf in SAP?.
  5. 自动预览行为 OAuth 2.0 服务器连接，请选择 Foundry Worker option.
  6. 设置 授权页面 URL 到 SAP OAuth 2.0 授权端点，包括 SAP HTTPS 端口。请将 <SAP_DOMAIN> 替换为您的 SAP 主机名，并将 <SAP_PORT> 替换为其 HTTPS 端口：
https://<SAP_DOMAIN>:<SAP_PORT>/sap/bc/sec/oauth2/authorize
  1. 设置 令牌端点 URL 到 SAP OAuth 2.0 令牌端点，包括 SAP HTTPS 端口：
https://<SAP_DOMAIN>:<SAP_PORT>/sap/bc/sec/oauth2/token
  1. 自动预览行为 出站策略，选择一个 代理出口策略 通过 Data Connection 代理 路由流量，该代理安装在您的网络中并可访问 SAP 系统。

  1. 自动预览行为 OAuth 2.0 设置，设置 客户端 ID 为 SAP OAuth 2.0 服务器配置中的客户端 ID。在 作用域获取资源，请将 /PALANTIR/SRV_0001.
  2. 保存该出站应用程序。
  3. 现在，创建 SAP webhook 时即可使用此出站应用程序。

有关出站应用程序配置选项的更多详细信息，请参阅 配置出站应用程序.

使用 SAP Data Accelerator 的出站应用程序设置

要通过 SAP Data Accelerator 启用用户归属回写，请在您的 SAP ERP 源上创建两个 webhook：一个 获取令牌 webhook 以及一份 刷新令牌 webhook。然后，在出站应用程序中同时选择这两个 webhook。这些 webhook 使用源的认证和 SAP Data Accelerator 连接设置来交换和刷新令牌。

在开始之前，请完成 SAP OAuth 2.0 服务器设置 和 将您的 SAP ERP 源配置为使用 SAP Data Accelerator。您还需要 管理出站应用程序.

创建获取令牌和刷新令牌 webhook

为两个 webhook 关闭函数配置

创建获取令牌 webhook 和刷新令牌 webhook 时，请关闭 函数配置。如果启用此设置，webhook 将作为函数发布，无法在出站应用程序中使用。

用途 在选择每个 webhook 的 后，为其插入示例 任务类型。它会自动填充任务主体模板，并创建输入和输出参数，包括其类型以及到响应字段的映射。使用下方的参数表检查生成的配置。

获取令牌和刷新令牌 webhook 的授权

对于这两个 webhook，请将 出站应用程序 设置为 保持为未选择状态 位于 Request configuration > Authorization。它们使用 SAP 源的认证来为出站应用程序获取和刷新令牌。如果在此处选择该应用程序，将产生循环依赖。

对于这两个 webhook，请将 Webhook 安全性 设置为默认值 Write API.

请按照以下说明在同一个 SAP ERP 源上创建两个 webhook：

  1. 首先，创建获取令牌 webhook。在 Data Connection 中打开该源并选择 创建 webhook.
  2. 为 webhook 输入名称，例如 Get OAuth Token，并关闭 函数配置.
  3. 在您的终端会话中将 任务类型 to sap-erp-oauth2-token-webhook-task in 请求配置,
  4. 选择 在选择每个 webhook 的 在空的 任务主体模板 旁边，以生成获取令牌 webhook 配置。对照下方的参考检查生成的参数，然后保存该 webhook。
  5. 接下来，在同一个源上创建刷新令牌 webhook。输入名称，例如 Refresh OAuth Token.
  6. 关闭 函数配置 并设置 任务类型 to sap-erp-oauth2-refresh-webhook-task.
  7. 选择 在选择每个 webhook 的 以生成刷新令牌 webhook 配置。对照下方的参考检查生成的参数，然后保存该 webhook。

配置出站应用程序

请按照以下说明使用两个已保存的 webhook 来配置 OAuth 2.0 连接：

  1. 在 Control Panel 中，打开 Organization settings > Outbound applications 并选择 新建应用.
  2. 提供一个 应用程序名称 以及一个 批准提示的源（例如 Allow Foundry to act on your behalf in SAP?.
  3. 自动预览行为 OAuth 2.0 服务器连接中，选择 本地部署的 webhook，其标记为 遗留版。此选项允许出站应用使用 SAP 源的 Data Accelerator 连接。源本身继续在 Foundry worker 上运行。
  4. 自动预览行为 源连接，选择您创建 webhook 时所用的 SAP ERP 源。
  5. 在您的终端会话中将 令牌 Webhook 使用以下方式连接到 webhook sap-erp-oauth2-token-webhook-task and 刷新令牌 Webhook 使用以下方式连接到 webhook sap-erp-oauth2-refresh-webhook-task.
  6. 在您的终端会话中将 授权页面 URL to https://<SAP_DOMAIN>/sap/bc/sec/oauth2/authorize。请使用用户可以从其浏览器访问的 SAP URL。此交互式授权步骤需要从用户的计算机进行访问，即使令牌交换和刷新使用 SAP Data Accelerator。
  7. 自动预览行为 OAuth 2.0 设置，设置 客户端 ID 导出到 OAuth 2.0 客户端 ID 在以下位置创建的 SAP OAuth 2.0 配置。按照这些说明，这是 Foundry 技术用户的 SAP 用户名。
  8. 将 /PALANTIR/SRV_0001 under 作用域.
  9. 保存该出站应用程序。

使用出站应用进行回写

在同一个 SAP ERP 源上，创建或编辑 调用您的 BAPI 的 webhook。对于此 BAPI webhook，请在以下位置下选择已保存的应用 Request configuration > Authorization > Outbound application。当用户运行回写工作流时，如果用户尚未持有有效令牌，Foundry 会提示其授权访问 SAP。随后回写将使用该用户的 SAP 授权，并在需要时由刷新令牌 webhook 获取新的访问令牌。
