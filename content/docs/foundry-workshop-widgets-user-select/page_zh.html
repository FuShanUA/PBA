用户选择

使用直方图中的 用户选择 用于通过单选或多选下拉菜单选择一个或多个用户的微件。

配置选项

  • 添加一个新的标签页。创建后，选择包含该标签页的框以进行配置。 为微件设置可选标签，以在下拉菜单上方显示文本。
  • 占位符： 设置可选的占位符文本，在微件处于空选择状态时显示
  • 选定的用户：
    • 如果选择设置为“单选”，微件将显示为单选下拉菜单。
      • 输出变量： 微件的输出变量，用于存储用户选择的选项。如果选择设置为“单选”，输出变量将是一个字符串变量，包含所选用户的 ID。
      • 允许清除： 切换以启用/禁用清除所选下拉菜单选项的功能。
    • 如果选择设置为“多选”，微件将显示为多选下拉菜单。
      • 输出变量： 微件的输出变量，用于存储用户选择的一个或多个选项。如果选择设置为“多选”，输出变量将是一个字符串数组变量，包含所选一个或多个用户的 ID。
    • 指定 Multipass 组 ID： 提供一个包含组 ID 的字符串数组变量，以将下拉菜单中显示的用户筛选为指定组中的用户。用户必须拥有 View group membership 对所配置组的组织角色，否则将看到权限错误，参见 有关如何思考问题类别并识别它们的更多细节.

Multipass 组 ID 权限

如果提供了 Multipass 组 ID，用户需要拥有 View group membership 对该组所属组织的权限，否则将在此微件中看到权限错误。此权限可以从 Settings > Platform Settings > Organizations 中授予，方法是选择感兴趣的组织，然后选择 管理 为 组织权限。了解更多关于 管理组的信息.
