在 Foundry Marketplace 中安装产品

当您找到想要安装的产品后，Marketplace 将引导您完成创建安装作业、映射任何所需的输入以及查看产品的输出。有关基本安装的分步演练，请参阅 开始使用.

创建安装作业

要开始安装产品，请选择 创建新安装 ，该按钮位于 Marketplace 界面的右上角。勾选产品卡片上的复选框以选择要安装的产品。您可以选择一个或多个产品一起安装。选定产品后，请选择 创建新安装 （位于页面底部）。

或者，在产品的详情页面上，选择右上角的 再次安装 按钮来安装该产品。如果您已有权访问现有安装，此按钮将改为提示您 打开，这会将您导航到现有安装，您可以在其中 升级 它。您可以选择 再次安装 （如果您希望再次安装该产品，例如，您想使用不同的输入创建新版本）。如果该产品版本已被发布者召回， 安装 按钮将被禁用。

在本示例中，我们将选择 再次安装。一个 创建安装作业 对话框将出现，供您配置安装位置。

配置以下设置：

  • 项目： 直方图 项目 ，您安装的资源将位于该项目中。选择 最后，选择所需的起始数据集。 以选择其他项目。
  • 项目锁定： 对于 生产模式安装，建议启用项目锁定以防止对已安装资源进行不必要的更改。选择 锁定项目 以锁定该项目。了解更多关于 项目锁定.
  • 将产品安装到多个文件夹或项目中： 如果您希望将每个产品安装到单独的位置，请选择此选项。
  • 空间： 您已安装资源所在的空间。此项会根据您选择的项目自动选定。
  • 本体论： 直方图 本体论 ，任何对象、关联、操作以及 函数 都将在其中创建。此项会根据空间自动选定。如果您没有看到所需的本体论，请联系您的平台管理员，因为这表示您没有编辑权限。
  • 安装后缀： （可选）自定义内容将安装到的项目的名称。例如，您可以添加后缀以区分此安装与其他安装，或区分不同的环境（例如 DEV, TEST，或 PROD增量同步 使用 DevOps 进行发布管理.

直方图 新安装 部分列出了将要安装的产品及其版本号。您可以使用版本下拉菜单更改版本。

选择 创建 以创建安装作业草稿。

General

创建安装作业后，您将进入安装作业草稿的 General 页面。此页面显示一个依赖关系图，展示草稿中的产品及其关系。

左侧面板显示草稿的导航：

  • 常规： 依赖关系图和关联产品面板。
  • 输入： 安装的输入映射配置。
  • 输出： 将要创建的所有资源的摘要。

关联产品

直方图 添加可用的关联产品 面板位于 General 页面上，显示可以满足草稿中输入的产品。关联产品可以作为外部引用添加，也可以包含在草稿中以安装或升级其版本。

您可以按空间筛选关联产品面板，以仅显示同一空间中的安装；也可以按商店筛选，以查找来自其他商店的产品。

选择关联产品旁边的添加（+）图标以查看选项。如果该关联产品的现有安装可用，您可以引用它来满足输入，而无需创建新安装。如果现有安装有可用升级，系统将予以提示。

您可以选择：

  • 引用现有安装 以使用已安装的内容来满足输入需求。外部引用可以跨存储链接，这对于 跨存储链接产品.
  • 升级现有安装 （如果有更新的版本可用）。
  • 创建新安装 以将链接产品包含在您的草稿中。作业中包含的安装必须来自同一存储和空间。

添加链接产品后，依赖关系图会更新以显示新的关系。底部的横幅会指示待处理的更改。选择 应用更改 以确认。

应用后，关系图会显示安装作业的最终结构，展示哪些产品是新安装，哪些是被引用的现有安装，以及它们之间的关系。在下面的示例中， Supply Chain Core Ontology 是一个外部引用，它将为此作业提供输入，但不会作为此作业的一部分进行升级。 Inventory Timeline Starter Pack 将作为新安装与此产品一同包含在此作业中 Inventory Management, Visibility and Simulation.

要在添加链接产品后对其进行修改，请在关系图中选择产品节点以查看选项，例如 包含在草稿中 or 从草稿中移除.

有关链接产品工作原理的更多信息，请参阅 关联产品.

输入

选择 输入 在左侧面板中配置安装所需的输入。 输入 页面显示必需和可选输入的数量及其满足状态。由链接产品满足的输入默认处于隐藏状态。

输入按类型分组（例如数据集、Multipass 组、本体论架构迁移或安装前缀）。您可以使用列表顶部的控件对输入进行搜索、筛选和分组。

筛选和搜索输入

直方图 输入 页面支持强大的筛选选项，用于管理大量输入。选择筛选图标以打开 一个 面板，您可以在其中按以下条件筛选：

  • 状态： 仅显示缺失、有错误、可选或已满足的输入。
  • 类型： 筛选特定输入类型，例如对象类型、关联类型、Multipass 组或安装前缀。
  • 最大值: 按输入所属的产品筛选输入。

您还可以使用搜索栏按名称搜索输入，并使用 分组依据 这将打开一个对话框，您可以在其中为实体应用和编辑标签。

通常，评估套件列名称和函数输入会匹配，但这不是必需的。

要映射必需输入，请从列表中选择它。右侧面板会显示 配置 选项卡，您可以在其中搜索并选择满足该输入的资源。

直方图 下游 选项卡显示安装中的哪些资源依赖于此输入，帮助您了解为什么需要它。

批量设置输入

要一次配置多个相同类型的输入，请选中要配置的每个输入旁边的复选框。右侧面板将显示 批量设置输入 视图，显示所选的输入，并允许您对所有输入应用相同的配置。

本体论安装前缀

直方图 本体论安装前缀 输入允许您使用用户指定的前缀自定义所有对象类型、关联类型和操作类型的名称。您可以选择将前缀应用于 仅显示名称 或同时应用于 显示名称和 API 名称.

占位符输入

要在所有资源可用之前部署 Marketplace 产品，您可以创建临时存根资源以继续安装。目前仅支持数据集输入。

要生成占位符输入，请选择 操作 面板顶部或分析器模式横幅中选择 输入 页面，然后选择 占位符输入。或者，您也可以选择 生成占位符 ，在单个输入的工具栏中 配置 标签页。

将出现一个对话框，您可以在其中选择保存占位符输入的文件夹，并选择要为其生成占位符的输入。选择 生成占位符输入 以创建占位符。

一旦实际资源可用，您可以通过选择省略号（...）并选择 编辑.

从文件夹自动选择

您也可以从现有文件夹中自动选择输入。选择 操作 面板顶部或分析器模式横幅中选择 输入 页面，然后选择 从文件夹自动选择 以使用指定文件夹中的资源自动映射输入。

输入覆盖

当您手动提供本应自动填充的输入（例如通过默认值或关联产品）时，就会发生覆盖。

要显示覆盖，请启用 显示覆盖 开关进行控制，该开关位于本体论管理器的 设置 面板中进行管理。

启用此开关后，输入列表中将显示覆盖标签，并在具有覆盖的输入的映射图标上显示标记。选择映射图标可查看该输入当前的填充方式以及在其他情况下的填充方式。

共有三种覆盖类型，下面按优先级从最低（覆盖）到最高（不必要的覆盖):

  • 覆盖： 本应以其他方式（例如通过默认值）填充的输入改为手动提供。
  • 关联产品覆盖： 本应通过关联产品填充的输入改为手动提供。
  • 不必要的覆盖： 输入被手动设置为与被覆盖的候选对象本应提供的值相同的值。

在上图中， Text Embedding 3 Small 输入被标记为 不必要的覆盖 ，因为它被手动设置为其默认值。

具有 覆盖 的输入在其映射图标上显示灰色标签和灰色标记。具有 关联产品覆盖 或 不必要的覆盖 的输入在其映射图标上显示橙色标签和橙色标记。

If 不必要的覆盖 or 关联产品覆盖 存在时， 输入 计数下方会出现提示，如上图所示。 清理 选项（也可在 操作 菜单中找到）会打开以下对话框：

在此对话框中，您可以清除 不必要的覆盖 和 关联产品覆盖。关联产品覆盖列在 关联安装候选对象 选项卡上。被清除的输入将改由其被覆盖的候选对象填充。对于 不必要的覆盖，结果值与您手动提供的值相同。对于 关联产品覆盖，值可能不同。

输出

选择 输出 在左侧面板中。此页面汇总了安装将创建的所有资源，并按类型分组（例如操作类型、数据健康检查、数据集、文件夹和 Workshop 应用程序）。

直方图 输出 页面还会在任何输出需要注意时显示警告。您可以使用列表顶部的控件对输出进行搜索、筛选和分组。

选择某个输出后，其详细信息将显示在右侧面板中：

  • 配置： 显示将为此输出生成的内容。
  • 上游： 显示此输出依赖哪些输入或其他资源。

安装

映射所有必需输入后，选择 安装 （右上角）以开始安装。这将提交安装草稿，并启动一个作业来创建资源。您将被重定向到作业页面，可在其中监控进度。

如果存在警告（由右上角的警告计数指示），您应在继续之前查看这些警告。选择警告指示器以查看任何问题。警告不会阻止安装，但必须在安装前解决阻止性验证错误。
