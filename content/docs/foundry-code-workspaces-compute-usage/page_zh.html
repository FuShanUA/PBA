使用 Code Workspaces 的计算用量

使用 代码工作区，用户可以安全地连接到现有的内部系统，并在数据上构建分析、模型、应用程序或完整的工作流，同时享有 Foundry 的访问控制和数据权限管理。

Code workspaces 会启动专用的 Foundry 计算模块来执行任务，使用期间将消耗 Foundry 计算秒数。

定价

Code workspace 的使用量以 Foundry 计算秒数进行跟踪（参见 用量类型）。只要工作区处于启动中或活跃状态，就会持续计算计算秒数。确定所用计算秒数的因素有以下几项：

  • 虚拟 CPU（vCPU）的数量。
  • RAM 的 GiB（吉比字节）数。
  • 所使用的工作区。
  • GPU 的数量和类型。

衡量 Foundry 计算

当打开 Code Workspace 时，Foundry 将为该工作区启动一个专用的计算会话。会话的状态为 STARTING 直到会话可用，随后变为 INITIALIZING，然后是 RUNNING。当用户手动停止会话，或在超过自动关闭超时时间后未检测到任何用户交互时，会话将变为 STOPPING 用户偏好 IDLE。Foundry 计算秒数仅在会话处于 INITIALIZING or RUNNING.

以下列出了工作区的所有可能状态。code workspace 使用计算的状态以右箭头（→）标示。

  • STARTING：请求了新会话
  • → INITIALIZING：会话可用且正在配置中
  • → RUNNING：会话可用且可使用
  • STOPPING：会话正在停止
  • IDLE：会话已停止
  • FAILED：发生错误
  • TERMINATING：会话将被永久删除
  • NOT STARTED：此工作区没有可用会话

Code Workspaces 以与平台内其他可伸缩计算相同的方式度量计算秒数。请查阅通用的 Foundry 计算文档 以了解其度量方式的说明。

使用 Code Workspaces 调查 Foundry 计算使用情况

Foundry Code Workspaces 将所有相关计算归因于文件系统中的工作区资源。您始终可以在 资源管理应用程序.

了解 Code Workspaces 中 Foundry 计算使用情况的驱动因素

Code Workspace 会话的计算使用量与会话可用的专用计算资源以及会话的时长成正比。

要管理会话的硬件大小，请前往 Settings > Compute Resources。您可以从多种不同的会话大小中进行选择。所选的 CPU 和内存可扩展至您项目中的最大可用值 资源队列的项目中的训练任务。如果您的注册使用了 托管计算配置文件，则您可以选择的计算由导入到您项目中的计算配置文件决定。请参阅下面的截图，了解如何选择大小以及如何选择性地为工作区分配 GPU。包含您工作区的项目中的资源队列决定了可用的 GPU。了解更多关于 在项目中使用 GPU 和 利用 GPU 进行模型训练.

长时间运行的会话比短时间运行的会话使用更多计算。请务必调整您的自动关闭时间，使其与您的工作方式保持一致，以避免使用不必要的计算。当您确定工作已完成时，应手动停止会话。
