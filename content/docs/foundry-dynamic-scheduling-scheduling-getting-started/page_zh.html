开始使用

以下指南提供了实现动态排程工作流第一版本的步骤。请查看各章节中引用的文档以获取更多信息。

1. 创建核心本体论对象

您必须创建以下核心对象类型来构建动态排程工作流：

  • 创建一个 Schedule 对象类型。它表示资源被分配到的事件、任务或时段。例如，您的 Schedule 对象类型可以是 Maintenance Tasks，它们需要被分配给 Technicians.
    • 该对象类型必须具有包含外键的属性，以便与资源对象类型建立关联。
    • 此对象类型可以具有一个 fixed duration 布尔属性，用于强制执行或不强制执行 Schedule.
    • 的静态时长。
  • 您必须启用对此对象的编辑，因为开始/结束/时长以及与资源的关联将在整个过程中被编辑。 Technician).
  • 创建一个或多个资源对象类型，表示要分配到排程中的资源。例如，需要执行任务的人员（ Schedule 创建 Resource 对象类型分别执行此操作。
  • 对象类型之间的关联。 Schedule。请参阅 拖放 的文档以获取更多信息。
    • 保存处理程序必须修改该 Schedule 对象上的以下参数。每个参数都必须标记为可选。
      • 资源 ID（资源对象的外键）
      • 开始时间
      • 结束时间
    • 您操作中的参数 ID 必须与排程对象类型中使用的属性 ID 完全匹配（例如，如果您的属性是 start_time，则参数 ID 也必须是 start_time).

请查阅 动态排程本体论基元文档 以获取有关每个对象类型架构的更多信息。

2. 在 Workshop 中配置小部件

创建核心对象后，您现在可以配置小部件以在 Workshop 中使用。

排程甘特图配置至少需要：

  • 时间线数据： 定义图表全局边界的开始和结束时间戳。
  • 行数据： 直方图 Resource 对应于图表每一行的对象。
  • 输入数据（Pucks）： 至少一个排程图层，包含：
    • 日程对象集： 直方图 Schedule 此图层的对象。
    • 关联资源属性： 关联每个 Schedule “分配至航班”操作会将 Resource object.
    • 开始时间属性 and 结束时间属性： 定义每个 Schedule 对象开始和结束时间的属性。
    • 保存处理程序操作： 对应的保存处理器操作，用于 Schedule object.
      • 您应在配置选项中使用下拉菜单中提供的小部件参数来指定默认的保存处理器操作参数。

请查阅 排程甘特图小部件文档 的文档以获取更多信息。
