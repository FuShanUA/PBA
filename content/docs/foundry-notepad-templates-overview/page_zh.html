Notepad 模板

Notepad 模板可作为蓝图，用于根据新输入从现有内容生成新文档。

模板接受字符串、对象或对象集等输入。模板中的微件可以配置为使用这些参数。基于输入创建新模板副本时，内容会动态调整。

某些 Notepad 微件专为在模板中使用而设计。

  • 直方图 表格行生成器 允许您根据作为输入传递的对象集中的每个对象生成一个表格行。
  • 直方图 章节生成器 为每个对象生成整个章节。
  • 直方图 函数 微件支持从 TypeScript 函数.

从模板生成文档

模板必须先发布，然后才能用于生成文档。以下介绍从模板生成文档的方法。

从 Notepad 主页

您可以在 Notepad 主页上通过选择 从模板新建 选项，或通过选择 从此模板新建 图标，从模板生成文档。

注意： 这将从模板的 最新 已发布版本生成文档。

从 Notepad 应用程序页眉

您可以在 Notepad 应用程序页眉中通过打开 文件 菜单并选择 从此模板新建 选项。

注意： 这将从模板的 最新 已发布版本生成文档。

从 Workshop
