平台内自定义文档

您可以创建、发布和管理托管在 Palantir 平台上的自定义文档，方法是使用 文档代码仓库。这些“自定义文档”可以 由 AIP Assist 建立索引，从而使 AIP Assist 能够使用您组织的文档回答查询。

您可以通过以下方式访问自定义文档：

  • 从应用程序启动器
  • 如果您的工作区中当前存在自定义文档，可通过左侧边栏中的 ? 帮助图标。
  • 直接使用您的注册文档 URL： https://<your-enrollment>/workspace/documentation/

请参阅 以下章节 了解如何在您的注册中配置平台内文档应用程序标题的详细信息。

请注意，平台内文档应用程序可能包含默认发布且并非来自自定义文档仓库的核心文档页面（例如，有关在数据集成中安装 SAP 连接器的信息）。

平台内文档应用程序标题

您的自定义文档应用程序的标题基于在 Control Panel中配置的 Palantir 平台标题。例如，如果您的平台标题是 ABC，则应用程序标题将为 ABC documentation。平台标题可以在 Control Panel 的 Platform experience 设置中进行配置。如果未在 Control Panel 中设置平台标题，或将其设置为 Palantir，自定义文档应用程序的标题将默认为 Custom documentation。

代码仓库文档模板

Palantir 的平台内自定义文档使用 代码仓库中的专用文档模板。该文档模板要求按照特定的方式组织文件，以便自定义文档服务对其进行发现和发布。平台内自定义文档页面使用 Markdown 编写，与标准 Markdown 有几处重要的 差异。
