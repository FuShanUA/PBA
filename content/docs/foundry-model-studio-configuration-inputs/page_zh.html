输入

Model Studio 接受 Foundry 数据集 作为训练作业的输入。每个训练器定义其期望接收的数据集类型。

数据集映射

配置向导的数据集配置页面中的每张卡片都是输入可映射到的特定数据集。有些数据集是必需的，而另一些是可选的。例如，测试数据集通常是可选的，因为训练作业会将 20% 的数据拆分出来用作测试数据集。

此外，数据集的列必须映射到特定的列类型，以便训练器知道哪些列是重要的。例如，时间序列预测训练器可能会定义它需要一个目标列、一个时间戳列和一个可选的 item_id 列。每个列映射定义了一组特定的列类型要求，列必须满足这些要求才能被选择。

数据集列也可以被忽略。当列被忽略时，它将在训练期间从数据集中删除。

预览

选定的数据集也可以进行预览。预览窗口允许您在设置输入时检查数据集，并查看不同列的统计信息。

筛选

筛选器应用于非 Parquet ↗ 数据集不支持下推筛选。您可能需要为配置分配更多内存，以防止出现内存不足错误。

数据集筛选允许您移除数据集中满足给定条件的行。如果您的数据集包含大量空值，或者您想忽略匹配某个条件的一部分行，这是一种不错的策略。

下推筛选是一种适用于 Parquet ↗ 数据集的筛选策略，允许在作业期间下载数据之前应用筛选器。这可以让您减少该作业所需的总内存量。在 Foundry 中生成的数据集（例如来自 Pipeline Builder的输出）通常支持下推筛选，而上传的数据集（例如 CSV 文件）则不支持。
