SAP Ariba Procurement

SAP Ariba Procurement 连接器是一个 由 Palantir 提供的驱动程序 ，用于 SAP Ariba Procurement。

要创建新的 SAP Ariba Procurement 数据源，请按照 Palantir 提供的驱动程序的标准设置流程操作，然后使用以下章节进行 SAP Ariba Procurement 特定的配置和网络设置。有关完整的属性参考，请参阅 官方 SAP Ariba Procurement 驱动程序文档 ↗。

Beta

SAP Ariba Procurement 连接器正处于 beta 开发阶段，在您的注册中可能不可用。在积极开发过程中，功能可能会发生变化。

配置

以下属性为必填或推荐属性。

属性是否必填？描述默认值
API ↗必填指定您希望提供程序从中检索 SAP Ariba 数据的 API。PurchaseOrdersBuyerAPI-V1
APIKey ↗必填您的 OAuth 应用程序密钥。—
AuthScheme ↗必填设置连接到 SAP Ariba 时要使用的身份验证类型。OAuthClient
Environment ↗推荐连接到 SAP Ariba 时要使用的环境。PRODUCTION
MaxThreads ↗推荐指定提供程序可对 SAP Ariba 执行的最大并发请求数。5
