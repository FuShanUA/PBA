transforms.api.transform

class transforms.api.transform(**kwargs)

将计算函数包装为 Transform 对象。

该 transform 装饰器用于从计算函数构造一个 Transform 对象。用于输入、输出或其他参数的名称应为被包装计算函数的函数参数。在计算时，参数会被实例化为由各参数类型定义的具体对象。

>>> @transform(
...     first_input=Input('/path/to/first/input/dataset'),
...     second_input=Input('/path/to/second/input/dataset'),
...     first_output=Output('/path/to/first/output/dataset'),
...     second_output=Output('/path/to/second/output/dataset'),
... )
... def my_compute_function(first_input, second_input, first_output, second_output):
...     # type: (TransformInput, TransformInput, TransformOutput, TransformOutput) -> None
...     first_output.write_dataframe(first_input.dataframe())
...     second_output.write_dataframe(second_input.dataframe())
  • 参数： **kwargs (Param) – kwargs 由命名的 Param 或其子类组成。

计算函数负责将数据写入其输出。

可选的上下文参数

您可以在计算函数中选择性地接受一个上下文对象，方法是添加一个 ctx 对于常规的 Spark 转换，上下文是一个 transforms.api.TransformContext，它提供了运行时信息和实用工具，例如 abort_job()、 auth_header、 environment、 fallback_branches、 parameters和 spark_session。

...     df = my_input.dataframe()
...     # Optionally use ctx, for example, to access parameters or abort the job
...     if ctx.parameters.get('abort'):
...         ctx.abort_job()
...     my_output.write_dataframe(df)

对于使用 transform.using(...)创建的轻量级转换，注入的上下文是一个 transforms.api.LightweightContext，它提供了方法和属性，例如 abort_job()、 auth_header和 is_incremental。

增量执行

要以增量方式运行转换，请使用 incremental 装饰器对其进行包装。增量装饰器使用输出构建历史记录来确定先前的状态，并将 TransformInput、 TransformOutput和 TransformContext 转换为其对应的增量版本。

# Spark transform, executed incrementally
@incremental()
@transform(
    first_input=Input('/path/to/first/input/dataset'),
    first_output=Output('/path/to/first/output/dataset'),
)
def my_compute_function(first_input, first_output):
    first_output.write_dataframe(first_input.dataframe())

classmethod using(**kwargs)

通过转换类构造轻量级转换。

轻量级转换是一种无需 Spark、在单个节点上运行的转换。对于中小型数据集，轻量级转换速度更快且更具成本效益。轻量级转换还提供了更多访问数据集的方法；但是，它们仅支持常规转换 API 的一个子集，包括 pandas、Polars（通过 transform_polars），以及文件系统 API。轻量级转换不支持 Spark 配置文件。

此方法仅接受输入/输出参数。可以通过链式调用其他方法来配置资源需求和容器设置。

有关更多信息，请参阅 转换 Python 概述。有关基于 Polars DataFrame 的转换，请参阅 transform_polars。

对于文件级访问，常规 Spark 转换使用 transforms.api.FileSystem，而轻量级转换使用 transforms.api.FoundryDataSidecarFileSystem。

  • 参数： **kwargs – 命名的 LightweightInput 或 LightweightOutput 对象，用作转换的输入和输出。
  • 返回： 一个可通过链式调用其他方法进行配置的构建器对象。
