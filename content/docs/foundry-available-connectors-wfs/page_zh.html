Web 要素服务 (WFS)

将 Foundry 连接到 WFS ↗ 版本 1.1.0 服务器，并将地理空间数据拉取到 Foundry 数据集中。

设置

  1. 打开 Data Connection 应用程序，然后选择 + New Source （位于屏幕右上角）。
  2. 选择 WFS （位于 Protocol sources下的可用连接器类型中）。
  3. 选择使用 通过互联网的直接连接 ，或者通过 中间代理进行连接。
  4. 请按照附加的配置提示，并参考下方各部分中的信息，继续完成连接器的设置。

了解更多关于 设置连接器 在 Foundry 中。

源配置

在 连接详细信息 页面上，输入 上游主机 URL 到 WFS Source Config 面板以连接到单个 WFS 服务器。

授权

WFS 连接器目前支持两种类型的授权配置： 无授权 和 GEOAxIS。如果您选择 GEOAxIS，则您还必须上传连接服务器所需的任何非个人实体（NPE）证书和私钥。要上传 NPE 证书或私钥，请选择 更多选项 ，然后再选择 配置服务器证书 用于 NPE 证书，或 配置客户端证书 用于私钥。

可选源配置

该 更多选项 菜单提供了两个额外的配置选项：

  1. 使用小写 WFS 请求： 默认情况下，WFS 连接器会将所有查询参数作为大写字符串发送。如果您的服务器以区分大小写的方式处理这些参数，您可以将连接器切换为使用小写查询参数。
  2. 标头覆盖： 使用此选项可为 WFS 连接器发出的所有请求配置附加标头。

网络

您必须通过端口 443 访问您的 WFS 服务器。请确保 出口策略 存在于该数据源。

数据源预览

配置数据源后，在屏幕右侧选择 预览数据源 ，以查看 WFS 服务器上可用要素图层的名称。

同步配置

创建源后，您可以 创建同步 ，将特定要素类型的数据导入 Foundry。您需要在以下位置指定要导入的要素名称： WFS 要素导入配置。

默认情况下，WFS 连接器会创建一个包含两列的数据集：一列用于要素 ID，另一列用于该要素属性的 JSON 字符串。您可以选择将连接器配置为解析来自 WFS 服务器的 schema 定义，从而创建一个数据集，其中为要素类型的每个属性各提供一个类型化列。为此，请将 要素导入模式 从 JSON 转换为 Schematized。

该 Schematized 导入模式可能会导致具有许多属性的要素类型构建时间更长，或者在 WFS 服务器具有非标准架构定义的情况下，构建更容易失败。

可选同步配置

更多选项 菜单提供了两个额外的配置选项：

  1. 导入的最大批次大小： WFS 连接器会创建数据批次以导入到 Foundry 中，而批次大小可能会影响性能，具体取决于所导入要素的几何类型。通常，拉取较复杂几何图形的同步应使用较小的批次大小，而拉取简单几何图形（如点）的同步则可以使用较大的批次大小。同样，您可以通过增大批次大小来修复失败的构建，使连接器每次请求都能从 WFS 服务器拉取更多数据。默认批次大小为 1000 个要素。
  2. 每秒发送到上游的最大请求数： 如果要同步的数据量很大，WFS 连接器的构建可能会运行很长时间。如果客户端在短时间内发送过多请求，上游 WFS 服务器可能会对该客户端进行速率限制。为避免触及服务器速率限制，您可以在同步级别配置速率限制。默认的同步速率限制为每秒 10 个请求。

WFS 限制

WFS 连接器可能会因服务器 1.1.0 规范的以下限制而失败：

  • 规范违规： 如果服务器不遵循 WFS 1.1.0 规范，则 WFS 连接器就无法正确查询要素。连接器会使用 GetFeature 请求来返回所获取要素的数量，但某些服务器始终返回 0。在这种情况下，连接器无法确定要获取多少数据，将会退出。
  • 包含大量要素的小型地理区域： WFS 1.1.0 WFS 未提供对要素数据进行分页的机制，因此连接器将尝试分批获取数据。如果某个小区域中的数据量超出单个批次可容纳的范围，连接器将无法导入这些数据，并且同步会失败。默认情况下，最小区域为单个 10 公里 × 10 公里的区域。虽然此设置不可配置，但默认批次大小可以在同步级别进行配置。
