适用于 SAP 应用程序的 Palantir Foundry Connector 2.0 Cockpit

适用于 SAP 应用程序的 Palantir Foundry Connector 2.0（"Connector"） Cockpit 是用于管理 Connector 参数的界面。SAP 用户可以通过 SAP GUI，使用 /n/PALANTIR/COCKPIT 事务代码访问该界面。

管理

此选项卡提供用于管理 Connector 的主要工具的访问入口。

维护配置表

核心 Connector 参数在此配置表中进行维护。这些参数控制 Connector 的行为。

这些参数在以下文档中有详细说明： 性能参数、 如何配置 Remote Agent 并注册 Connector，以及 用于解决已知 SAP 问题的参数.

数据传输监控器

此选项卡包含用于控制 Connector 如何记录数据传输的设置。

调整日志表

此选项将调整日志表以安排清除日志的作业。从 v1.4.0 或更早版本升级时，此选项非常有用。数据库表中新增了字段；此操作将从现有记录中填充新字段。如果您是从 1.4.0 或更高版本开始运行 Foundry 同步，则无需使用此选项。

Foundry 同步日志报告

此选项报告所有 Foundry 同步的日志头、日志项和页面信息。

清除日志

此选项卡包含用于控制日志保留的设置。

安排作业

此选项安排一个作业来清除日志表。参数如下：

  • 恢复： 指示计划作业将在多少小时后重新启动。换言之，它是计划作业的频率（以小时为单位）。默认值： 24 （表示作业将每天运行）。
  • 低相关性数据： 指示项数据（低相关性）在删除前保留多少天。项数据包括日志项的消息、页面项表以及增量表信息的项数据。默认值： 31 （表示项数据将在 1 个月后删除）。
  • 高相关性数据： 指示头数据（高相关性）在删除前保留多少天。默认值： 365 （表示头数据将在 1 年后删除）。对于增量更新，此参数应至少为 31。
  • 仅在已传输到 Foundry 时： 指示在删除项数据时，仅删除已传输到 Foundry 的数据。如果启用此参数，所有尚无法传输到 Foundry 的数据也将被删除。默认值：启用。

更多详情，请参阅 设置和配置日常维护

敏感数据

此选项卡提供用于控制如何处理敏感数据的设置的访问入口。

加密和数据脱敏配置

数据脱敏和加密可以在 数据脱敏 标签页。

配置在对象类型、对象和字段级别进行设置，使用以下参数：

  • 对象类型： 源对象的对象类型。可能的条目包括：
    • TABLE
    • BEX
    • EXTRACTOR
    • FUNCTION
    • INFOPROVIDER
    • SLT
  • 对象（Object）: 对象名称。（SFLIGHT 在上面的示例中使用。）
  • 字段： 读取后需要进行脱敏/加密的字段。输出中的每个字段都需要创建新行。
  • 脱敏模式引擎： 模式匹配期间使用的引擎。支持正则表达式。
  • 模式： 用于模式匹配的模式。默认情况下，留空将匹配整个字段值。
  • 掩码字符： 模式匹配后要替换的掩码值。可输入的选项包括：
    • 清除匹配字符 – 将模式替换为空格。
    • '* : 将模式替换为 * 字符。每个字符都将被替换为星号符号。
    • '# : 将模式替换为 # 字符。每个字符都将被替换为井号符号。
  • 加密算法： 加密时使用的算法。支持的算法为 AES12CBC。
  • 哈希算法： 哈希时使用的算法。支持的算法包括：
    • MD5
    • SHA1
    • SHA256
  • 掩码列显示： 显示/隐藏掩码列。选项包括：
    • 在同一列中显示：掩码列将在原始列名下显示。需要填写掩码属性。
    • 在新列中显示：掩码列将在 COL_NAME_MASKED 列中显示。
    • 隐藏列：掩码列将不会显示。
  • 加密列显示： 显示/隐藏加密列。选项包括：
    • 在同一列中显示：加密列将在原始列名下显示。需要填写加密属性。
    • 在新列中显示：加密列将在 COL_NAME_ENC 列中显示。
    • 隐藏列：加密列将不会显示。
  • 哈希列显示： 显示/隐藏哈希列。选项包括：
    • 在同一列中显示：哈希列将在原始列名下显示。需要填写哈希属性。
    • 在新列中显示：哈希列将在 COL_NAME_HASH 列中显示。
    • 隐藏列：哈希列将不会显示。

配置完成后，用户可以返回 SAP Cockpit 屏幕。

预筛选器

全局筛选器（预筛选器）用于控制从 SAP 系统中提取的敏感数据。SAP 管理员可以指定预定义的筛选器，这些筛选器会与 Foundry 请求的筛选器合并。即使这些筛选器值未在 Foundry 的同步定义中指定，它们也会被自动添加到请求中。

要指定筛选器，请使用与 Foundry 同步定义中相同的语法。 了解有关同步语法的更多信息.
