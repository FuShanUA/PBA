在 Notepad 中使用自定义函数

要在 Notepad 中使用自定义函数，您必须首先创建一个函数。函数可以用 TypeScript 或 Python 编写；请参阅 函数文档 以了解用例、支持的功能以及函数创建指南。创建自定义函数后，请按照以下步骤在 Notepad 中使用它：

  1. 在 Notepad 中，打开或创建一个文档或文档模板。在文档中填充内容，并通过以下两种方式之一选择函数输入：
    • 手动高亮相关内容并选择 使用 AIP 编辑 （在工具栏中）。
    • 将光标置于相关内容上并选择 使用 AIP 编辑 在工具栏中。系统将自动为您进行块级选择。

如果您的注册未启用 AIP，Notepad 中的自定义函数仍然可用。请改为使用 使用 AIP 编辑中，选择 使用函数编辑 在工具栏中，并跳过第二步。

  1. 选定内容后，将出现一个弹出菜单。选择 函数 选项以使用自定义函数编辑所选内容。
  2. 在函数弹出窗口中，选择一个函数及该函数的输入类型。在 函数输入 这将打开一个对话框，您可以在其中为实体应用和编辑标签。
  1. 中选择纯文本或 Markdown。您可以选择预览输入，然后运行该函数。
