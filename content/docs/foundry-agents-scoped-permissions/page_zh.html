专业代码代理的作用域权限

专业代码代理通过 本体论 SDK (OSDK)、 本体论 MCP (OMCP)以及 Palantir MCP 进行身份验证，并默认获得作用域权限。您无需预配客户端 ID 和密钥，也无需传递 Foundry 令牌即可调用工具。

作用域权限的工作原理

当您使用 代理模板创建专业代码代理时，Foundry 会代表您预配代理调用 OSDK、OMCP 和 Palantir MCP 所需的凭据。该模板会在运行时通过代理库提供的辅助函数解析连接详细信息，包括服务 URL 和授权标头。您的代理代码会请求已配置的客户端或 MCP 连接，并直接使用。

由于凭据受作用域限制且由平台管理，代理代码中不需要以下内容：

  • 客户端 ID 和密钥
  • Foundry 令牌
  • 手动 OAuth 客户端设置

专业代码代理只能访问其作用域所允许的资源。访问权限由 本体论绑定 （在代理发布时选择）以及 应用程序限制 （适用于底层客户端）共同管控。

获取本体论 MCP 连接

代理库（@palantir/agent-templates-bundle) 公开了一个辅助函数，可返回可直接使用的本体论 MCP 连接。该连接包含已解析的 URL 和授权标头，因此无需客户端 ID、密钥或 Foundry 令牌。有关实现细节，请参阅 专业代码代理模板。

获取 OSDK 客户端

代理库还提供了一个辅助函数，用于构造绑定到您所选本体论的 OSDK 客户端。有关实现细节，请参阅 专业代码代理模板。
