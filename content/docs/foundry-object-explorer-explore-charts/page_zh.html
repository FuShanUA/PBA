使用图表进行探索

选择要探索的对象类型后，Explore 视角会显示用于搜索和筛选的图表。

图表

图表是用户在 Object Explorer 中进行筛选时的主要交互点。每个图表都表示对主对象类型或关联对象类型上某个属性字段的聚合。默认情况下，系统会为所选对象类型上的每个重要属性显示一个图表；不过，用户可以自定义并 保存自己的默认布局，而管理员可以 为所有用户保存全局默认布局。

添加、移除和排列图表

点击当前视图底部的 添加图表 卡片，即可向您的探索中添加图表。这会打开一个搜索栏，用于搜索所选对象类型及关联对象上的属性。选择要聚合的属性后，该图表将显示在您的探索中，而 添加图表 卡片会向下移动一个位置。

此外，也可以从探索搜索栏中的筛选器添加图表。在搜索栏中添加新筛选器时，会出现一个 将图表添加到视图 按钮。选择该按钮会将图表添加到探索布局中的第一个位置。

要移除图表，请将鼠标悬停在探索中的图表标题上。此时会显示一个 X 图标：点击该图标可将图表从视图中移除，但不会移除搜索中的任何筛选条件。

可以通过拖放操作对图表进行重新排序和调整大小。单击并按住图表标题中的空白区域，即可显示用于对图表重新排序的界面。在布局中移动图表时，其他图表会随之移动以填补其留下的空白空间。

要水平调整图表大小，请单击并按住图表的一条边缘并拖动，以将其缩小或放大。在探索布局中，每个图表可以填充其中一列或两列。

如果 Listogram 图表包含五个以上的值，点击 显示更多 和 显示更少 将垂直调整图表大小。

关联对象上的图表

要基于关联对象的属性进行筛选，请从搜索菜单的左侧选择一种关联对象类型。

在探索视图中，图表标题将指示该图表正在基于关联对象的属性进行筛选。在所附示例中，顶部两个图表基于所选类型的属性进行筛选，底部两个图表基于关联对象的属性进行筛选。

图表类型

对象资源管理器支持多种适用于不同属性类型的图表。以下是每种类型的摘要和示例。

列表图

列表图显示非数值属性的聚合。这适用于 String、Boolean 和 Array 属性。在此示例中，图表列出了员工的所有名字，以及具有该名字的员工数量。

列表图还可以结合数值属性的聚合来显示属性——例如，按州显示企业各特许经营店的平均收入。

列表图的配置包括：

  • 聚合类型
    • 例如，与其显示每个机场的*航班*数量，不如显示*平均* 飞行时间
  • 排序类型和方向
    • 例如，按计数升序排序，或按属性值的字母顺序排序

要对列表图进行筛选，请单击要筛选的值。可以使用图表底部的下拉菜单来保留或排除所选的值。

饼图

非数值属性（布尔值和字符串）也可以使用饼图显示。请在图表配置选项中选择 饼图 选项。

直方图

直方图以条形图的形式显示数值或日期属性的聚合。

直方图会自动缩放以适应所有相关数据，并自动分桶，以便于更轻松地进行选择。无需额外配置。要进行筛选，可以选择某个特定的桶（如左图所示），或点击并拖动以选择自定义范围（如右图所示）。使用图表底部的输入框编辑范围的起点和终点。

网格图

网格图显示两个属性的彩色图表：X 轴上的所选属性和另一个 分组依据 位于 Y 轴上的属性。

打开图表的配置以修改坐标轴、排序信息和颜色刻度。

要使用网格图进行筛选，请点击网格中的一个区块。按住 ctrl 或 command 以点击连续范围内的多个选项。

单一统计

单一统计图表显示一组对象在某个数值属性上的聚合值。选择一个属性和一种聚合类型（求和、平均值、最小值、最大值、计数和唯一计数）。此图表不能用于筛选。

统计表

统计表以可排序表格的形式显示按另一个属性分组的数值属性的聚合值。可用的聚合类型包括求和、最小值、最大值、平均值和计数。

配置选项包括所显示的指标、用于分组的属性，以及在表格底部显示汇总行。

要进行筛选，请选择所需分组属性对应的行。

地图

聚类地图

默认情况下，任何 geopoint 类型属性都会显示为聚类地图，其中的气泡按比例缩放，可显示对象数量或另一个聚合的结果。

配置选项包括更改所执行的聚合类型以及聚合所基于的属性（例如，不显示机场数量，而是显示每个区域内出发航班的总数）。

您可以通过点击这些气泡进行地理空间筛选，然后点击 应用筛选 在地图³下方。

撤销和重做探索中的更改

要撤销或重做探索中的更改，请使用视角栏左侧的按钮。目前，系统会保存最近 5 个探索状态以供撤销和重做。可以撤销的操作包括：

  • 在搜索栏中或从图表中编辑筛选器
  • 更改图表布局（添加新图表或重新排列现有图表）
  • 更改探索视角
  • 将探索透视到关联的对象类型

保存布局

布局允许用户为特定对象类型创建可共享的视图。可共享的视图包括已添加的图表、表格的列配置以及表格的任何排序配置。

要保存布局，请打开屏幕左上角的布局选择器（A）并选择 将当前视图（例如图表、排序等）另存为新布局 （B）。

在弹出的窗口中，设置 初始视角 （C），用于控制布局最初打开的是“探索”选项卡（图表）还是“结果”选项卡（表格）。您还可以通过勾选 “仅限自己” （D）复选框（位于 “设置为默认布局”下方），将该布局设为此对象类型的个人默认布局，这表示每当您对该对象类型开始新的探索时，都会默认选择此布局。

如果您是 管理员用户，则可以通过勾选 “所有用户” 复选框（E）（位于 “设置为默认布局” 下方），将某个布局设为所有用户的全局默认布局。

请注意，如果单个用户为某一对象类型设置了自己的默认布局，则该布局将优先于已设置的任何全局默认布局。

预览面板

在探索视图的右侧，一个最多包含 20 条结果的列表会显示探索内容的预览。

点击预览卡片，可在对象视图标签页中打开该对象。要按单个属性排序，请使用预览列表子标题中的 排序依据 选项。要按多个属性排序，请将鼠标悬停在标题上，然后选择此处图示的齿轮图标。这将打开一个对话框，您可在其中配置多个属性的排序，这些排序随后将按顺序应用。
