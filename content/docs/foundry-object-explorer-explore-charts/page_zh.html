使用图表进行探索

选择要探索的对象类型后，Explore 视图会显示用于搜索和筛选的图表。

图表

图表是用户在 Object Explorer 中进行筛选的主要交互点。每个图表表示主对象类型或关联对象类型上某个属性字段的聚合。默认情况下，所选对象类型上的每个显著属性都会显示一个图表；但是，用户可以自定义并 保存自己的默认布局，而管理员可以 为所有用户保存全局默认布局.

添加、删除和排序图表

点击当前视图底部的 添加图表 卡片，将图表添加到你的探索中。这会打开一个搜索栏，用于搜索所选对象类型和关联对象上的属性。选择要聚合的属性后，图表将显示在你的探索中，并且 添加图表 卡片会向下移动一个位置。

此外，也可以从探索搜索栏中的筛选器添加图表。在搜索栏中添加新筛选器时，会出现一个 将图表添加到视图 按钮。选择该按钮会将图表添加到探索布局的第一个位置。

要删除图表，请将鼠标悬停在探索中该图表的标题上。会出现一个 X 图标：点击该图标会将图表从视图中移除，但不会移除搜索中的任何筛选器。

可以通过拖放来重新排序和调整图表大小。点击并按住图表标题中的空白区域，会显示用于重新排序图表的界面。在布局中移动图表时，其他图表会移动以填补其空出的位置。

要水平调整图表大小，请点击并按住图表的一条边缘，然后拖动以缩小或放大。每个图表可以占据探索布局中的一列或两列。

如果 Listogram 图表的值超过五个，点击 以显示接下来的五行。 和 显示更少 将垂直调整图表大小。

关联对象上的图表

要筛选关联对象的属性，请从搜索菜单的左侧选择一个关联对象类型。

在探索视图中，图表标题会指示它正在筛选关联对象的属性。在附带的示例中，顶部两个图表筛选所选类型的属性，底部两个图表筛选关联对象的属性。

图表类型

Object Explorer 支持针对不同属性类型的多种图表。以下是每种类型的摘要和示例。

Listogram

Listogram 显示非数值属性上的聚合。这适用于 String、Boolean 和 Array 属性。在此示例中，图表列出了员工的所有名字以及具有该名字的员工数量。

Listogram 还可以显示带有数值属性聚合的属性——例如，按州显示企业每个分店的平均收入。

Listogram 的配置包括：

  • 聚合类型
    • 例如，不显示每个机场的*航班*数量，而是显示*平均值* 飞行时间
  • 排序类型和方向
    • 例如，按数量升序排序，或按属性值按字母顺序排序

要在 listogram 上进行筛选，请点击要筛选的值。可以使用图表底部的下拉菜单保留或排除所选的值。

饼图

非数值属性（布尔值和字符串）也可以使用饼图显示。选择 饼图 选项（通过图表配置选项）。

直方图

直方图显示数值或日期属性上的条形图聚合。

直方图会自动缩放以适应所有相关数据，并自动分桶，以便于选择。无需额外配置。要进行筛选，可以选择某个特定的桶（如左图所示），或点击并拖动以选择自定义范围（如右图所示）。使用图表底部的输入框编辑范围的起点和终点。

网格图

网格图显示两个属性的颜色图表：X 轴上的所选属性和另一个 分组依据 Y 轴上的属性。

打开图表配置以修改坐标轴、排序信息和颜色刻度。

要使用网格图进行筛选，请点击网格的某个分段。按住 ctrl or command 以点击连续范围内的多个选项。

单一统计值

单一统计值图表显示一组对象在某个数值属性上的聚合值。选择一个属性和一种聚合类型（求和、平均值、最小值、最大值、计数和唯一计数）。此图表不能用于筛选。

统计表

统计表以可排序的表格形式显示按另一个属性分组的数值属性的聚合值。可用的聚合方式包括求和、最小值、最大值、平均值和计数。

配置选项包括要显示的指标、分组依据的属性，以及在表格底部显示汇总行。

要进行筛选，请选择所需分组依据属性对应的行。

地图

聚类地图

任何 geopoint 类型属性的默认设置是聚类地图，其中缩放的气泡显示对象数量或其他聚合的结果。

配置选项包括更改执行的聚合类型以及聚合所基于的属性（例如，不显示机场数量，而是显示每个区域内出发航班总数）。

您可以通过点击这些气泡进行地理空间筛选，然后点击 应用筛选 （位于 3地图下方）。

撤销和重做对探索的更改

要撤销或重做对探索的更改，请使用透视栏左侧的按钮。目前，最近 5 个探索状态会被保存以供撤销和重做。可以撤销的操作包括：

  • 编辑筛选条件（在搜索栏中或从图表中）
  • 更改图表布局（添加新图表或重新排列现有图表）
  • 更改探索透视
  • 将探索透视切换到关联的对象类型

保存布局

布局允许用户为特定对象类型创建可共享的视图。可共享的视图包括已添加的图表、表格的列配置以及表格的任何排序配置。

要保存布局，请打开屏幕左上角的布局选择器（A）并选择 将当前视图（例如图表、排序等）保存为新布局 (B).

在弹出的窗口中，设置 初始视图 (C），该选项控制布局初始打开时显示的是“探索”（Explore）选项卡（图表）还是“结果”（Results）选项卡（表格）。您还可以通过勾选 仅限自己 (D）复选框，将该布局设为此对象类型的个人默认布局，该选项位于 设为默认布局下方，这意味着每当您开始对该对象类型进行新的探索时，系统都会默认选择此布局。

如果您是 管理用户，则可以通过勾选 所有用户 复选框（E）在 设为默认布局 下方，将某个布局设为所有用户的全局默认布局。

如果某个用户为某一对象类型设置了自己的默认布局，则该布局将优先于任何已设置的全局默认布局。

预览面板

在探索视图的右侧，最多显示 20 条结果的列表会显示探索内容的预览。

点击预览卡片可在对象视图（Object View）选项卡中打开该对象。要按单个属性排序，请使用 使用多个值轴 选项。要按多个属性排序，请将鼠标悬停在标题上并选择此处所示的齿轮图标。这将打开一个对话框，可配置多个属性的排序，这些排序将按顺序应用。
