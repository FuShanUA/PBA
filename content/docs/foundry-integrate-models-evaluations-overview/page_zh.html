评估

An 评估 是指标、图像、图表和表格的集合，用于记录特定模型版本在给定测试数据集上的表现。评估让开发者能够定义评估逻辑，将结果写入与模型关联的评估集，并可在模型页面上进行可视化和比较。

由于每个评估都绑定到单个模型版本，评估集让您能够跟踪模型重新训练时某项指标在各版本间的演变。

评估集

An 评估集 是对采用相同方法论的评估进行逻辑分组。每个评估始终与一个评估集关联，一个评估集包含该方法论在各模型版本中生成的所有评估，因此您可以在模型重新训练时比较相同的分析。一个模型最多可以有 100 个评估集。

In 代码仓库，这种分组由 @pm.transforms.evaluation 装饰器强制执行：评估集名称在转换定义中是固定的，因此该转换的每次运行都会向同一个评估集写入一个新的、可比较的评估。要以不同方式评估模型，请定义一个使用不同评估集名称的单独转换。

例如，一个预测房价的回归模型可能有两个不同的评估集：

  • 全国误差分析： 评估所有预测的总体误差指标（平均绝对误差、R²）。
  • 价格层级分析： 按价格区间（经济型、中档和豪华型）细分评估误差指标，包括每个区间的残差分布图，以揭示模型是否对特定区间系统性地高估或低估。

创建评估

直方图 ModelInput 类用于在以下环境中导入和使用模型： 代码仓库 提供了创建评估的钩子。请确保您已 升级您的代码仓库 并已将 palantir_models 库升级到 >= 0.2384.0 ，然后再编写评估逻辑：

from transforms.api import transform, Input
import palantir_models as pm
from palantir_models.transforms import ModelInput

# This decorator is required to be applied to create evaluations.
# The decorator indicates the evaluation set that will be written to on the model input(s).
@pm.transforms.evaluation("error_analysis")
@transform.using(
    input_data=Input("..."),
    model_input=ModelInput("..."),
)
def compute(input_data, model_input):
    evaluation = model_input.create_evaluation(name="my-evaluation")

评估名称不需要唯一。重复使用的名称会自动变为唯一，因此相同的代码可以多次运行而无需重命名评估。如果未提供名称，则使用评估集名称。

由于评估构建在现有的 Python 转换基础设施之上，当构建成功时，评估会自动提交到模型输入上的评估集。如果构建失败，评估将被中止，不会发布任何结果。

编写评估逻辑的代码仓库必须与被评估的模型位于同一个项目中。完整示例（包括如何控制评估哪个模型版本）请参见 编写并运行评估。如需为回归和分类模型记录一组标准指标而无需自行编写逻辑，请参见 内置评估器。您还可以使用 操作 下拉菜单 在评估视图中设置评估逻辑按计划运行。

日志记录

评估支持四种类型的日志：指标、图像、图表和表格。

子集

子集允许您使用 prefix/name 命名约定将相关的指标、图像、图表和表格分组。任何遵循此模式的日志都可以在 UI 中按 prefix or value 进行分组，便于比较不同细分或条件下的同一指标。

# These three metrics are automatically grouped under "nationwide"
evaluation.log_metrics({
    "nationwide/mae": 14250.0,
    "nationwide/r2": 0.91,
})

# These are grouped under their respective region prefixes
evaluation.log_metrics({
    "northeast/mae": 12100.0,
    "northeast/r2": 0.93,
    "southeast/mae": 13800.0,
    "southeast/r2": 0.90,
    "west/mae": 16500.0,
    "west/r2": 0.88,
})

前缀是任意的——系统会按第一个 /之前的所有内容进行分组。数据如何划分为子集的逻辑完全由您决定。

记录指标

可以使用 Evaluation.log_metric 和 Evaluation.log_metrics 函数记录指标。指标值必须是数字（int or float).

    "r2": 0.91,
})

限制

下表列出了 Foundry 中与评估相关的限制。

描述限制
指标名称最大长度100 个字符
图像、图表或表名称最大长度100 个字符
图像说明最大长度200 个字符
每张图像、图表或表的最大上传大小5 MB
每个表的最大行数100,000
每个模型的最大评估集数量100

如需提高这些限制，请联系 Palantir 支持。

请查阅 模型评估 Python API 参考 的文档以获取更多信息。
