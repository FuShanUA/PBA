安装适用于 SAP 应用程序的 Palantir Foundry Connector 2.0

适用于 SAP 应用程序的 Palantir Foundry Connector 2.0（"Connector"）以 SAP 附加组件的形式交付，需通过以下方式安装 SAINT （SAP 附加组件安装工具）。该附加组件以 SAR 格式交付，文件名模式如下： FOUNDRY-SAPCONN-INST-SP00SPXX.SAR

SP00SPXX 表示来自以下位置的安装文件 SP00 to SPXX 其中 XX 是支持包级别。

如果 Connector 安装在 BW/4HANA or S/4HANA上，请在安装中包含属性变更包（Attribute Change Packages）。自 SP22 起，这些包已包含在安装文件中。

以下是设置 Connector 所需的高层级步骤：

  1. 下载安装包.
  2. 安装 Connector 附加组件 via SAINT.
  3. 在以下系统中为 Foundry 创建一个 System 类型（类型 B）的技术用户 SU01。该用户由 Foundry 代理用于系统间调用，不用于登录 SAP GUI。如果您计划稍后启用 通过 OAuth 2.0 进行的用户归属回写 ，则用户类型 必须 be System.
  4. 运行安装后向导.

安装过程中涉及两个不同的 SAP 用户。在本页面中，它们的称呼如下：

术语定义
执行用户 （Basis 管理员）以交互方式登录以运行以下操作的人工 SAP 管理员（Dialog 用户） SAINT、安装后向导以及 PFCG。需要 SAINT / PFCG / SU01 authorizations.
Foundry 技术用户一个 System 类型（类型 B）用户，无交互式登录，由 Foundry 代理用于 RFC/HTTPS 调用。接收 /PALANTIR/* 由安装后向导分配的角色。

前提条件

  • SAP_BASIS（技术组件版本，适用于 SAP NetWeaver 和 SAP S/4HANA 系统）7.4 SP5 或更高版本

or

  • SAP_BASIS 7.5(无最低 SP 级别要求)

这些均为最低版本。连接器支持所有更高的 SAP_BASIS 版本,包括基于 SAP_BASIS 8.x 的 SAP S/4HANA 版本(例如 SAP_BASIS 816)。

请确保已阅读以下 SAP 说明，并在适用的情况下遵循相关步骤：

  • SAP OSS 说明 2645739 - ABAP 附加组件 OCS 包未经过数字签名

安装 Connector 附加组件

  1. 登录 SAP 系统客户端 000 使用有权使用以下工具的用户 SAINT.
  2. 运行 SAINT transaction.
  3. 导入 FOUNDRY-SAPCONN-INST-SP00SPXX.SAR 到 SAP 服务器；选择 安装包 > 加载包 > 从前端.

对于某些 SAINT/SPAM 版本，SPAM 或 SAINT 设置可能会影响安装过程。请禁用 无法进行签名检查，未实施 SAP 说明 2520826 项，位于 导入期间的检查 部分下。在某些 SPAM 版本中，此项完全没有描述，但仍应禁用。

  1. 选择 开始时间 以进行安装。
  2. 可用包会被列出。如果没有列出，请点击筛选器图标以取消激活筛选器。
  3. 选择 继续 以进入下一步。
  4. 对于 Connector 安装，请选择 PALANTIR and PALCONN.
  5. 选择 继续 以进入支持包选择。
  6. 从列表中选择可用的最高支持包，并确保两个组件选择了相同的 SP 级别。
  7. 确认安装队列并点击 继续.
  8. 选择 在对话框模式下继续 用于准备阶段， 立即在后台继续 用于其他阶段，然后开始安装。

如果安装过程中出现警告，请按照警告消息中描述的步骤进行解决。在大多数情况下，对于 Connector 和远程代理安装，警告消息可以忽略。特别是标题为"打开的数据提取请求"的警告消息可以忽略，因为安装不会对 DDIC 结构进行更改，因此不会导致打开的数据提取请求终止。

  1. 选择 完成 以完成安装。

运行安装后向导

Connector 安装后向导简化了 Connector 附加组件安装后的设置活动。要执行安装后配置，Basis 管理员（即执行用户， 不 Foundry 技术用户）需通过 SAP GUI 登录主客户端（而非 000）。安装后向导在该管理员的会话下运行，并 配置 Foundry 技术用户；Foundry 技术用户本身从不进行交互式登录。可以通过事务代码访问安装后向导 /n/PALANTIR/POST_INST 或从 Connector 菜单（事务代码： /n/PALANTIR/).

向导步骤

共有 10 个步骤，可以一起运行，也可以单独运行。要完成安装，所有步骤都需要启用。如果这不是 SLT 安装，请禁用 创建 SLT 配置。SLT 配置在第 7 步中详细说明。

执行用户（运行向导的 Basis 管理员）需要拥有足够的权限，才能将所需的授权角色分配给 Foundry 技术用户。此过程类似于通过 SU01 事务代码维护用户。如果用户分配单独完成，请禁用 Assign Roles to Foundry User 和 Perform Healthcheck.

1. 运行卸载修正

此步骤运行一个后台程序，用于修复 Connector 对象目录中的 SAP 软件包。此修正程序可随时运行，不会产生不良副作用。

2. 激活 SICF 服务

此步骤激活数据传输所需的两个 Connector 服务。如有需要，也可以通过 SICF 事务代码手动完成。这两个服务是：

  • /default_host/sap/palantir
  • /default_host/sap/opu/odata/palantir

3. 生成角色

Connector 拥有自己的一套角色，这些角色在安装过程中导入。安装后，这些角色处于未生成状态。如有需要，可以通过 PFCG 事务代码使用 Utilities > Mass Generation.

  • /PALANTIR/CONTENT_BEX_ALL
  • /PALANTIR/CONTENT_CDS_ALL
  • /PALANTIR/CONTENT_HANA_ALL
  • /PALANTIR/CONTENT_DM_ALL
  • /PALANTIR/CONTENT_EXT_ALL
  • /PALANTIR/CONTENT_FUNCTION_ALL
  • /PALANTIR/CONTENT_INFOPROV_ALL
  • /PALANTIR/CONTENT_SLT_ALL
  • /PALANTIR/CONTENT_TABLE_ALL
  • /PALANTIR/CONTENT_TCODE_ALL
  • /PALANTIR/DEBUG_USER
  • /PALANTIR/MONITORING
  • /PALANTIR/OAUTH_CLIENT
  • /PALANTIR/SERVICE_SLT
  • /PALANTIR/SERVICE_SLT_740
  • /PALANTIR/SERVICE_USER

4. 将角色分配给 Foundry 技术用户

步骤 3 中的所有 Palantir 角色将分配给在选择屏幕中定义的 SAP 用户。这应该是上述高级步骤第 3 步中创建的 System 类型的 Foundry 技术用户，而不是执行用户。

如果此步骤生成有关角色分配、无法检索用户详细信息或缺少权限的错误消息，则表明执行用户没有足够的权限。在这种情况下，请按照错误消息中的建议更正执行用户的授权，然后重新运行该程序。

如果此步骤生成的错误消息表明 Foundry 技术用户已被锁定，请联系锁定所有者解除锁定，然后重新运行该程序。

8. 执行健康检查

Connector 拥有多种指标来衡量其在已安装的 SAP 系统中的健康状况。Connector 在以下类别中执行健康检查：

  • AGENT：检查 RFC 连接和源系统授权。 仅适用于 通过网关的远程连接.
  • AUTHORIZATION：检查 Foundry 用户是否存在缺失的授权 SM53.
  • CONNECTOR：检查系统中是否已安排 Connector 清理作业。
  • ROLE：检查 Foundry 用户的角色和授权配置文件。
  • SLT：检查 SLT 配置是否正确且健康；例如，BADI_Implementation 是否处于活动状态、Context 是否处于活动状态、是否已安排 SLT 清理作业，或源系统连接是否正常。

9. 浏览器测试 URL

安装完成后，务必通过 Web 浏览器进行连接测试，以检查 Connector 是否正常运行。所需的 URL 由安装后向导生成。

有多种不同的测试可用。第一个和第二个测试是对 Connector 服务的同步调用；第三个和第四个用于批量提取。

  • 关于： Connector 的“关于”页面。
  • T000 表： 使用以下对象类型直接提取 T000 表 table 对象类型。
  • T000 与 Paging-Init： 使用以下方式初始化 T000 表的后台提取 table 对象类型。
  • T000 与 Paging-Read 第 1 页： 将检索由上一个 URL 初始化的进程的第一页。

性能参数

Connector 具有以下性能参数，以在系统资源不足以服务 Foundry 时避免不必要的系统负载。这些设置会与 ST06 的值进行比较。下面列出的默认参数值适用于最新 Connector 版本的全新安装。

  • MEMORY_FREE: 空闲内存百分比。如果该百分比低于系统默认值或用户定义的值，提取将停止。Connector 默认值为 5%.
  • CPU_IDLE: CPU 空闲百分比。Connector 默认值为 5%.
  • CPU_USER: 用户事务占用的 CPU 利用率。Connector 默认值为 80%.
  • CPU_LOAD: CPU 总利用率。Connector 默认值为 80%.

ST06 关键指标由 SAP 提供给 Connector。如果 虚拟化的增强监控 已激活，则操作系统特定的信息会补充虚拟化特定的信息。这可能会影响 ST06 指标并误导 Connector。详情请参阅 SAP OSS 文章 2266266。

初始系统默认值特意设置得较为保守。如果您希望将其覆盖为更宽松的值，请通过 /n/PALANTIR/PARAM 事务进行维护。
