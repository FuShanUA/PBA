WebSocket 监听器安全性

WebSocket 监听器与标准的 Foundry 数据摄取方式不同，因此在启用连接之前，请确保您已理解这些安全范式。

请求授权

每种 WebSocket 监听器类型都具有由外部系统定义的特定身份验证要求。监听器会实现这些外部系统制定的安全协议，而这些协议差异很大。Palantir 不对这些外部系统协议的适用性或有效性作出任何保证。

您有责任确保自己了解每种协议针对传入的连接和数据提供或不提供哪些保证。

每种监听器实现的具体协议可在 配置安全 部分（位于监听器的 配置连接 页面）以及外部系统的文档中找到。

可导出标记验证

WebSocket 监听器在处理数据时，标记验证会作为一种安全控制，用于防止未经授权的数据外泄。系统会确保输出所使用的任何数据均满足监听器配置的可导出标记要求。

默认情况下，只有不带安全标记的数据才能被读取并纳入您的计算模块输入中。如果您的计算模块需要处理带有安全标记的数据，您必须在监听器设置中明确配置允许导出哪些标记。只有有权解除这些标记的用户才能将其添加到配置中。

子域名

WebSocket 监听器可以挂载到专用子域名，从而实现精细化的入口控制、全面的治理工作流，并将安全性较低的端点与环境的主要注册域名隔离开来。 详细了解监听器子域名。

端点轮换

如果监听器的端点遭到入侵，您可以将其轮换为新的端点。 详细了解端点轮换。
