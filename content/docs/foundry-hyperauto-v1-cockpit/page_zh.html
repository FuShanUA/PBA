SDDI 驾驶舱

日落

HyperAuto V1 目前处于 日落 阶段，并将在未来某个日期被弃用。目前仍提供全面支持。不建议创建新的 V1 管道，用户应从 HyperAuto V1 迁移到 V2，具体步骤详见 迁移文档.

SDDI 驾驶舱 是配置和执行 SDDI 流程的中心场所，引导您从同步的创建和配置，到数据管道的生成以及本体论的创建。

驾驶舱的左侧面板列出了各个 SDDI 流程步骤以及这些步骤的状态。点击每个步骤时，右侧主区域会显示您可以针对该特定 SDDI 流程步骤执行的不同操作。

初始状态

在开始之前，需要将驾驶舱连接到一个正常运行的 SDDI 实例。 要配置您的第一个 SDDI 实例，请参阅 开始使用.

访问现有的驾驶舱

要查看已配置的 SDDI 实例，请导航至 源概览 在 Data Connection 中所附加源的页面，然后选择 编辑管道生成器设置.

驾驶舱控件

驾驶舱的左侧面板列出了三个阶段：

  1. 同步数据
  2. 管道生成
  3. 本体论变更

同步数据

在同步数据阶段，您可以浏览来自源的数据，并创建到 Foundry 的新同步。它还会自动将 SDDI 正常运行所需的元数据表配置到 Foundry 中。最后，它允许您触发将此数据摄取到 Foundry 中。

管道生成

管道生成阶段允许您通过点击操作与 SDDI 自动管道生成器仓库进行交互，以生成和构建数据管道，并导航至 SDDI 数据血缘。

SAP 源在 SDDI 源资源管理器中配置

管道配置仅适用于非 SAP 源。对于 SAP 源，管道配置在适用于 SAP 的 SDDI 源资源管理器中设置。

本体论变更

在本体论变更步骤中，您可以预览可基于在 SDDI 自动管道生成器 仓库中指定和处理的数据集进行批量处理的本体论变更。

访问故障排除

从工作区导航栏的以下位置访问驾驶舱： 软件定义数据集成.

权限可通过 Control Panel 的 应用程序访问 页面进行配置。如果您没有访问 SDDI 驾驶舱的权限，请联系您的 Foundry 平台 IT 管理员或 Palantir 支持。
