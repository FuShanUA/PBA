产品、发布和版本

产品（Product）是可在 Apollo 中部署的软件组件。产品概念的设计十分灵活，可涵盖安装在环境（Environment）中的所有单个服务。

产品的每个版本都会在 Apollo 中创建为一个发布（Release）。发布包含产品的代码以及 Apollo 用于管理该产品的元数据。

本页面详细介绍了产品和发布，以及它们与 Apollo 中其他关键概念之间的关系。

Maven 坐标

Apollo 使用 Maven 坐标 ↗ 来标识产品和发布。一个 Maven 坐标包含三个组成部分：

  • group：组代表拥有该产品的组织。您应选择一个能代表您自己组织的组。例如，com.palantir 是一个有效的组。多个产品可以使用相同的组。
  • artifactId: 制品 ID 是 Product 的名称。例如，wordpress 和 apollo-demo-app 都是有效的制品 ID。此字段在每个组内必须唯一，这意味着一个组只能拥有一个具有特定制品 ID 的 Product。我们建议制品 ID 在 Apollo 中总体保持唯一。
  • version: 此字段表示正在您的实体上运行的 Product 版本。例如，1.1.0 和 1.1.0-rc1 都是有效的版本。有关 Apollo 中版本的更多信息，请参阅Product 版本规范。

Products

Product 由Maven 坐标中的 group:artifactId 唯一标识，在 Apollo 中称为 ProductId。例如，一个名为 new-product 的 Product 可能拥有 ProductId com.palantir.example:new-product。

Apollo 支持 Helm chart 和 Asset 作为Product 类型。

产品可以从内部仓库获取，并作为持续集成（CI）管道的一部分发布，也可以直接从开源构件仓库中拉取。每个产品在 Apollo 中都有一个所属团队，其成员负责管理产品维护窗口和产品晋升管道配置。

了解更多有关管理产品的信息。

产品发布

产品发布是发布到产品目录中的带版本号的代码构件。每个产品发布都由一个Maven 坐标标识，其中每个版本代表该产品的不同发布。例如：

1
2
3
com.palantir.apollo-developers:apollo-demo-app:1.0.0
com.palantir.apollo-developers:apollo-demo-app:1.1.0
com.palantir.apollo-developers:apollo-demo-app:1.2.0

Apollo 会在产品主页上显示所有使用相同 ProductId 发布的版本。通常，某个团队将负责具有特定 ProductId 的所有产品发布。

您可以通过在左侧菜单面板中选择产品名称并导航至 Releases 标签页，来查看产品及其关联的产品发布。

产品目录

产品目录是已发布到 Apollo Hub 的所有产品的清单。该目录包含每个产品版本的详细信息，包括现有依赖项、召回信息以及它所属的发布渠道。

通过在左侧菜单面板中选择产品来浏览产品目录。您可以筛选产品列表，以查看没有联系团队的产品、Palantir 产品以及与特定联系团队关联的产品。

版本

只有当版本可排序时，Apollo 功能才可用。例如，实体的报告版本必须可排序，以便 Apollo 能够识别实体可升级到的更新版本。

Apollo 支持以下格式的版本号：

版本类型可排序示例正则表达式
发布版本是1.0.0^[0-9]+\.[0-9]+\.[0-9]+$
发布版本快照是1.0.0-1-gaaaaaaa^[0-9]+\.[0-9]+\.[0-9]+-[0-9]+-g[a-f0-9]+$
候选发布版本是1.0.0-rc1^[0-9]+\.[0-9]+\.[0-9]+-rc[0-9]+$
候选发布版本快照是1.0.0-rc1-1-gaaaaaaa^[0-9]+\.[0-9]+\.[0-9]+-rc[0-9]+-[0-9]+-g[a-f0-9]+$

版本排序的具体细节定义于Apollo 产品规范 - 产品版本规范。以下示例展示了不同类型的版本之间如何相互交互。
