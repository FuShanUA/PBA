教程：创建您的第一个图表

在本教程中，您将创建一个简单的图表，展示常见的数据集成模式。该模式包括连接到外部系统、转换数据、构建本体论，以及创建面向用户的应用程序。

完成本教程后，您将了解如何：

  • 向图表添加组件节点。
  • 在节点之间创建连接。
  • 将相关节点分组。
  • 保存您的图表。

创建新图表

  1. 在您的 Foundry 环境中导航到 Solution Designer。
  2. 选择 新建图表 从主屏幕。
  3. 将打开一个空白画布，您可以在其中通过添加节点、从以下位置加载图表来开始构建您的图表 调度指标，或浏览参考示例。

添加您的第一批节点

按照以下各部分的说明构建一个图表，展示数据从外部系统流经 Foundry 并进入 Workshop 应用程序。

添加外部系统节点

  1. 选择 组件 按钮（位于左上方工具栏中），或按 Cmd/Ctrl + B 以打开组件搜索和选择弹窗。
  2. 选择 外部系统 （位于组件搜索和选择弹窗的左侧面板中）。
  3. 选择相关的 外部系统 类型，例如 数据存储 or 文件存储，该节点将显示在您的画布上。

添加数据获取节点并将其连接到您的外部系统节点

接下来，添加一个节点来表示 Foundry 如何连接到外部系统。

  1. 打开组件搜索和选择弹窗（Cmd/Ctrl + B).
  2. 搜索并添加一个 数据获取 节点，例如 数据连接器 or 数据连接代理.
  3. 将鼠标悬停在 外部系统 节点的右侧连接柄。
  4. 点击并拖动到 数据获取 节点的左侧连接柄。

完成数据流

按顺序添加以下节点，继续构建图表：

  1. 数据集： 打开组件搜索和选择弹窗，搜索并选择 DataFrame.
  2. Pipeline Builder： 添加一个 如果希望用户在每次运行预览前手动确认，请开启 节点以表示数据转换。
  3. 数据集： 添加另一个 DataFrame 节点以表示转换后的数据。
  4. 对象类型： 选择 静态： 按钮（位于左上方工具栏中），选择 新建对象节点，并从您的本体论中选择一个对象类型。您也可以创建一个通用对象节点 不 （如果您愿意，可以将其关联到现有对象类型）。
  5. Workshop： 添加一个 来运行该专业代码代理。你还可以通过 节点以表示面向用户的应用程序。
  6. 用户组： 添加一个 用户组 节点以表示一组用户及其需要执行的任务。

您的图表现在展示了一个完整的数据集成和应用程序工作流。

将相关节点分组

为了组织您的图表，请将数据转换组件分组在一起。

创建分组

  1. 按住 Cmd （macOS）或 Ctrl （Windows）并选择 如果希望用户在每次运行预览前手动确认，请开启 node.
  2. 继续按住 Cmd/Ctrl 代码仓库 DataFrame 节点，紧接在 如果希望用户在每次运行预览前手动确认，请开启之后，该节点表示转换后的数据。
  3. 验证两个节点均显示高亮边框，表明它们已被选中。
  4. 选择 组 按钮，位于 添加文本节点 在图表工具栏中。
  5. 系统会在两个选定的节点周围创建一个分组容器。

为分组命名

  1. 选择新创建的 组 在您的画布上。
  2. 选择默认的 组 标签，为分组提供一个描述性名称，例如 Data Transformation.
  3. 在画布上分组边界以外的任意位置单击，然后 保存 您的更改。

您的图表现在具有逻辑分组，使您更容易理解工作流的架构。

添加描述和上下文

添加节点描述

您可以为各个节点添加备注，以记录其用途：

  1. 选择 如果希望用户在每次运行预览前手动确认，请开启 node.
  2. 选择 输入描述... 并添加描述，例如： Cleanses and transforms raw data into business-ready datasets.
  3. 对图表中的其他关键节点重复此过程。

添加用于注释的文本节点

要为图表添加一般性注释：

  1. 选择 添加文本节点 按钮，位于左上方工具栏中，画布上会出现一个文本节点。
  2. 选择 双击以编辑 以编辑文本。
  3. 输入图表的描述，例如： This diagram represents our core data integration pattern for external vendor data.
  4. 选择并拖动文本节点，将其放置在图表顶部附近。

保存图表

现在您的图表已完成，将其保存到 Foundry 文件系统：

  1. 选择 保存 在 Solution Designer 页眉中。
  2. A 保存 如果这是您首次保存，系统会渲染一个模态框，您可以在其中输入 文件名的源（例如 First Diagram，并选择一个保存 位置.
  3. 选择 保存 以完成保存过程。

您的图表现已保存，并且在您进行后续更改时会自动保存。选择 草稿已保存 从文件页眉中查看一个模态框，其中包含有关自动保存草稿的更多信息。

后续步骤

现在您已创建了第一个 Solution Designer 图表，可以通过以下方式继续探索其功能和特性：

  • 探索参考模式： 选择 参考图表 在屏幕左侧的导航栏中，浏览预构建的行业和技术模式。
  • 关联资源： 在图表中选择节点，并使用 关联资源 按钮（位于节点工具栏中），将其连接到实际的 Foundry 数据集、管道或应用程序。
  • 使用 AIP Architect： 尝试 AIP Architect 根据您的需求生成工作流计划。
  • 审查您的图表： 用途 AIP Critic 获取针对您的架构的 AI 驱动的反馈。
  • 自定义图表视图： 打开 图表设置 尝试不同的显示选项，例如仅图标模式或边动画。

有关图表功能和特性的更多详细信息，请参阅 图表.

提示

  • 从概念入手： 从高层组件开始，稍后再细化。您无需在初稿中指定确切的数据集或管道。
  • 充分使用分组： 按功能对节点进行分组（例如“数据摄取”、“处理层”、“应用层”），使复杂图表更易于浏览。
  • 利用模式： 浏览参考架构库，寻找符合您用例的成熟模式。您可以加载某个模式并进行自定义，而无需从头开始。
  • 根据反馈迭代： 使用 AIP Critic 验证您的设计，然后根据建议进行优化。
  • 考虑分层： 将图表按逻辑层次从左到右组织（数据源 → 摄取 → 处理 → 本体论 → 应用 → 用户），以便于理解。
