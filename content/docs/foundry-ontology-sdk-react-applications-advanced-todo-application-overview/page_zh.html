使用 OSDK 构建高级待办事项应用程序

该 高级待办事项应用程序，可在 VS Code 工作区中使用，演示了如何通过构建待办事项应用程序作为实际示例来使用本体论 SDK (OSDK) 的高级功能。您将了解 OSDK 的许多功能，包括以下文档章节中所讨论的功能：

  • 本体论接口
  • 使用媒体集处理媒体内容
  • 运行时派生属性
  • 平台 SDK

应用程序参考文档分为以下几个部分：

架构与配置： 架构与配置概述对高级待办事项应用程序的配置、所需安装以及应用程序架构进行了总结。

useProjects： 该 useProjects 钩子为在 React 应用程序中管理待办事项项目提供了全面的接口。该钩子利用本体论 SDK (OSDK) 与后端服务进行交互，提供获取项目以及每个项目中任务的实时统计数据的功能。

useTasks： 该 useTasks 钩子是一个自定义 React 钩子，用于管理待办事项应用程序中与特定项目相关联的任务。它利用 OSDK 来获取任务数据、将其与用户信息关联，并通过订阅提供实时更新。该钩子旨在与 SWR（stale-while-revalidate）策略配合使用，以实现高效的数据获取、缓存和状态管理。

useCodingTask: 该 useCodingTask 钩子是一个自定义 React 钩子，用于在待办事项应用程序中获取和管理编码任务数据。该钩子通过用户信息和元数据来丰富基本任务数据。

useCodingTask: 该 useLearningTask 钩子是一个自定义 React 钩子，用于在待办事项应用程序中获取和管理学习任务数据。该钩子通过用户信息、媒体内容和元数据来丰富基本任务数据。

useAdmin: 该 useAdmin 钩子是一个自定义 React 钩子，用于从 Foundry Admin API 获取用户数据。它利用 SWR（stale-while-revalidate）库实现高效的数据获取和缓存。
