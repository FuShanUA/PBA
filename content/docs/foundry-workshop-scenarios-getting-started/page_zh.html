开始使用

本教程涵盖 临时场景 （也称为动态场景），它们仅存在于当前会话中，不会被持久化。有关包含场景感知组件（如场景摘要、带场景比较的 XY 图表以及带场景变量的指标卡片）的更全面教程，请参阅 临时场景。要了解如何将场景元数据持久化为本体论对象，请参阅 将场景元数据存储为对象.

在本教程中，我们将逐步构建一个由场景驱动的基本模块。

首先，创建一个全新的 Workshop 模块。

首先，导航到 设置 左侧面板，并确保在 高级功能.

在侧边栏部分，添加一个场景管理器组件。

这是 Workshop 中特定于场景的组件之一，用于创建和管理将在整个模块中使用的场景。

暂时可以保持配置选项不变；我们稍后会再回到这些选项。

在模块主体中，添加一个 指标卡片.

你可以使用任何对象集来填充表格，但我们建议从已至少关联一个 操作 的对象类型开始。

现在，添加一些要在表格中显示的属性。

在属性下方，你将看到在此组件中启用场景比较的选项（即对象表格是一个场景感知组件）。

启用后，你可以选择由场景管理器组件生成的场景数组变量。这将使表格中的数据反映管理器中对场景的任何修改，而不是原始本体论中的数据。

不过，此时我们尚未对场景应用任何修改，因此数据应该是一样的。

添加一个 按钮组 组件，以便你可以配置一个要应用于场景的操作。

选择一个修改表格中该类型对象的操作。

为了将此操作应用于场景而不是真实的本体论，请启用“应用于场景”选项，并从管理器中选择活动场景变量。

使用新配置的操作，尝试将表格中任意对象的属性更改为新值。

但是，在应用操作之前，请通过点击“创建”按钮在管理器组件中创建一个新场景。

此操作 不 尚未应用于本体论，仅存在于场景中。

我们还可以通过再次选择管理器中的 创建 按钮来创建另一个用于比较的场景。创建后，你将在对象表格中看到第二个场景的值与第一个场景并排显示，但仅在存在差异的列中显示。由于第二个场景尚未被修改，它应该显示本体论中的值。

某些组件（如表格）可以接受任意数量的场景并显示结果。

现在在表格上方添加一个包含 图表：XY（Chart: XY） 小部件。

XY 图表组件与表格一样支持任意数量的场景，并且可以在不同的图层中配置不同的场景。

尝试探索各种图层类型，看看多个场景在其中是如何可视化的。

你还可以配置分组和聚合，它们会正确地遵循场景值。

我们还可以从 Scenarios 向 Metric 卡片填充值。 现在添加一个新的 Metric 卡片部件。

在 Metric 卡片配置中，创建一个新的数值指标，其值由新的对象集聚合变量定义。

在对象集聚合变量配置窗格中，有一个 Scenario config 部分，可接受 Scenario 变量。 如果选中，对象集聚合将在应用 Scenario 的修改后执行。

类似地，对象属性变量也有 Scenario 配置部分。 通过这种方式，您可以将 Scenarios 中的变量值配置到本身不支持 Scenario 的部件中使用（例如 metric 卡片，它没有显式的 Scenario 配置部分）。

此处选择了 Scenario Selector 输出变量，因此您可以看到聚合结果随选择而变化。
