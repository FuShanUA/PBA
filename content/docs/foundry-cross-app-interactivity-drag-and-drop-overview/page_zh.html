拖放

拖放功能允许用户通过将数据从一个应用程序拖动到另一个应用程序，轻松地在应用程序之间移动数据。一个常见的例子是，您在将图像拖放到文件夹中时可能已经使用过此功能。我们将可以拖入或拖出数据的组件称为 拖放集成点。只需添加一个拖放集成点，您就可以将您的应用程序与其他支持拖放功能的应用程序连接起来，从而创建新的工作流。

拖放功能是一项被广泛接受的 Web 标准，可实现应用程序之间的无缝集成。本文档介绍了 Palantir 特定的拖放建议和指南，支持将数据拖入和拖出 Palantir 平台，包括与 Gotham、Foundry 以及用户开发的应用程序之间的拖放操作。请参阅 Palantir 媒体类型 以了解有关 Palantir 特定拖放功能的更多信息。

核心概念

要实现拖放功能，您需要熟悉四个主要概念：

  1. DataTransfer 对象
  2. 媒体类型
  3. 拖动区域
  4. 放置区域

DataTransfer 对象

DataTransfer 对象就像一个容器，当您在计算机上将内容从一个地方移动或复制到另一个地方时，它会保存相关信息。DataTransfer 对象（也称为 "DataTransfers"）在拖放操作中使用，例如将图片从一个文件夹移动到另一个文件夹，或在复制粘贴操作中使用，例如复制文本并将其粘贴到文档中。在拖放的上下文中，DataTransfer 对象也被称为拖动载荷（drag payload）。

DataTransfer 可以保存不同类型的信息，例如文本或图像。DataTransfer 对象最初是专门为拖放而设计的，但现在也用于其他功能。请参阅 MDN 上关于 DataTransfers 的文档 ↗ 以了解更多信息。

媒体类型

媒体类型（以前称为 MIME 类型）表示所传输数据的性质。媒体类型在 DataTransfer 对象上用于标识所传输数据的类型。例如，包含文本 "Hello" 的 DataTransfer 可能具有一个 text/plain 媒体类型，允许接受文本作为有效媒体类型的组件访问该文本。请参阅 MDN 上关于媒体类型的文档 ↗ 以了解更多信息。

完整的 MDN 接受的媒体类型列表 ↗ 适用于常规拖放功能。请参阅 Palantir 媒体类型 以下内容，以了解有关 Palantir 特定功能的更多背景信息。

Palantir 媒体类型

Palantir 媒体类型表示 Palantir 平台特有的概念。在您的应用程序中添加 Palantir 特定的拖放支持，将使用户能够在您的应用程序与 Palantir 平台之间移动数据。我们已有接受标准媒体类型的拖放区域，但我们建议在构建拖放工作流时将 Palantir 媒体类型添加到拖动载荷中，以提高互操作性。

Palantir 平台具有一些拖放区域，这些区域会向拖动载荷添加 Palantir 媒体类型，或接受包含这些媒体类型的拖动载荷。例如， 对象 媒体类型表示 Foundry 对象资源标识符（RID）数据，它并不是一种被普遍使用的媒体类型，例如 image/jpeg。相反，对象媒体类型表示 Palantir 特有的概念，在应用程序之间移动此类型的数据需要 Palantir 媒体支持。

当前支持的 Palantir 媒体类型包括 对象 和 对象集.

拖动区域

拖动区域是 文档对象模型（DOM）↗ 上的交互元素，允许用户"抓取"数据并将其传输到其他位置。当用户发起拖动时，会触发一个 dragstart 事件。拖动区域的工作方式是监听 DOM 元素上的 dragstart 事件并向 DataTransfer 添加额外数据。

放置区域

放置区域是 DOM 上的交互元素，允许用户通过将数据“放置”到元素上来传输数据。放置区域的工作原理是监听 ondrop DOM 元素上的事件，并在事件触发时从事件的 DataTransfer 中访问信息。为了获得最佳用户体验，放置区域应设置样式，以便在拖放操作期间提供视觉反馈。放置区域可以选择仅接受一部分媒体类型，因此针对媒体类型对放置区域是否有效的视觉反馈，可使拖放功能更加直观且易于使用。

拖放的工作原理

综合以上概念，拖放交互是一种被广泛接受的 Web 标准，由 DataTransfer 驱动，它保存用户正在拖动的数据。当拖动区域最初被拖动时，数据会连同与所传输数据类型对应的媒体类型一起添加到 DataTransfer 中。然后，这些数据可以被拖动到可以访问拖动负载的放置区域上。放置区域可以根据拖动负载的媒体类型有选择地接受数据，使你能够为用户量身定制可用的拖放交互。
