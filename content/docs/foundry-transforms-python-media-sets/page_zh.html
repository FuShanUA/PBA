在 Python 转换中使用媒体集

您可以使用 媒体集 在 Python 转换中用于 PDF 文本提取、光学字符识别（OCR）、图像切片、元数据解析等。以下章节将介绍如何在 Python 代码仓库中设置媒体集，以及如何使用 Python 转换对媒体集进行读取和写入。

以下是一个分步示例，展示如何 使用 Code Repositories 创建媒体集批处理管道.

您还可以了解如何 使用媒体集编写增量转换.

媒体转换目前不支持在 Code Repository 的 Preview 功能中使用。任何使用媒体集的转换都可以构建，但无法预览。

将 transforms-media 库导入到您的代码仓库中

要使用特定于媒体集的装饰器，您首先需要导入 transforms-media 库到您的代码仓库中。您可以通过导航到 ”面板中找到。 例如，要使用 Code Repositories 界面左侧的文件抽屉来完成此操作。搜索 transforms-media，然后安装该库。

在您的代码仓库中添加对 transforms-media 的依赖。

您必须使用 @transform 装饰器来处理媒体集。媒体集的输入和输出可以通过 transforms.mediasets.MediaSetInput 和 transforms.mediasets.MediaSetOutput 规范来传入。在构建期间，这些规范会被解析为 transforms.mediasets.MediaSetInputParam 和 transforms.mediasets.MediaSetOutputParam 对象。这些 MediaSetInputParam 和 MediaSetOutputParam 对象提供对计算函数中媒体集的访问。任意数量的媒体集输入或输出都可以与其他任意有效的转换输入和输出（例如表格数据集）组合使用。例如：

创建媒体集

除了使用媒体集创建对话框在项目或文件夹中创建媒体集之外，您还可以直接在 Code Repositories 中创建媒体集，用作 Python 转换的输出。

首先，在 MediaSetOutput 规范中为新媒体集选择输出位置和名称。

选择您刚刚定义的路径，此时该路径应该以红色下划线标示；将鼠标悬停在上面时，您应该会看到一条错误消息，指示该媒体集不存在。

从该行左侧的灯泡图标中，选择 创建媒体集.

按照对话框步骤选择所需的 媒体集架构 ，并完成新媒体集上任何其他所需的配置。

选择 创建Workshop MediaSetOutput 规范将使用您提供的详细信息进行填充。这些注解字段定义了媒体集的创建方式。

新媒体集将在 Python 转换首次构建后创建，此后不应再编辑注解字段。

from transforms.api import transform, Output
from transforms.mediasets import MediaSetInput, MediaSetOutput
from pyspark.sql import functions as F
from pyspark.sql.types import StringType


@transform.spark.using(
    pdfs=MediaSetInput('/examples/PDFs'),
    output_images=MediaSetOutput('/examples/JPEGs'),
    output_references=Output('/examples/JPEG listing')
)
def upload_images(ctx, pdfs, output_images, output_references):

    def upload_jpg(media_item_rid, path):
        with pdfs.transform_document_to_jpg(media_item_rid, 0) as jpeg:
            response = output_images.put_media_item(jpeg, path)
        return response.media_item_rid

    upload_udf = F.udf(upload_jpg, StringType())

    listed_pdfs = pdfs.list_media_items_by_path(ctx)
    media_reference_template = output_images.media_reference_template()
    uploaded_jpegs = listed_pdfs\
        .withColumn('uploaded_media_item_rid', upload_udf(F.col('mediaItemRid'), F.col('path')))\
        .select('path', 'uploaded_media_item_rid')\
        .withColumn("mediaReference", F.format_string(media_reference_template,
                                                      'uploaded_media_item_rid'))

    column_typeclasses = {'mediaReference': [{'kind': 'reference', 'name': 'media_reference'}]}
    output_references.write_dataframe(uploaded_jpegs, column_typeclasses=column_typeclasses)

媒体集写入模式

可以使用以下两种写入模式之一向媒体集写入数据：

  • modify：上传的项目将添加到媒体集分支中的现有项目之外。
  • replace：上传的项目将完全替换媒体集分支。

默认写入模式取决于媒体集的 事务策略 。事务性媒体集默认使用 replace。非事务性媒体集使用 modify 写入模式，且无法更改，因为非事务性媒体集中的分支无法重置为空。

媒体集输出的写入模式可以在运行时动态更改。这在根据管道中的自定义条件决定是否完全替换输出的场景中非常有用。

要更改媒体集的写入模式，您可以使用 .set_write_mode() 媒体集输出上的方法。在项目上传到输出之前，可以随时更改写入模式。例如：

import os


@transform.spark.using(
    output_media_set=MediaSetOutput("/path/media_set_output", should_snapshot=False),
    input_dataset=Input("/path/dataset_of_raw_files"),
)
def compute(input_dataset, output_media_set):
    all_files = list(input_dataset.filesystem().ls())
    for current_file in all_files:
        with input_dataset.filesystem().open(current_file.path, 'rb') as f:
            filename = os.path.basename(current_file.path)
            output_media_set.put_media_item(f, filename)

从文档中提取布局感知内容

使用直方图中的 extractLayoutAwareTextV2 操作来配置输出格式（TEXT, MARKDOWN，或 HTML）、处理模式（ELECTRONIC, SCAN，或 AUTO）以及页面范围。了解更多关于 文档转文本媒体转换的信息.

处理媒体集时，您可以使用转换从文档中提取内容，例如段落、标题和表格，以及有关此内容布局的元数据。此提取转换可在 PDF 和图像媒体集上运行。

对于特别复杂的文档，将提取的边界框传递给视觉模型可能会产生更好的结果。

对于 PDF 文档，V2 响应是一个包含以下内容的对象：一个 pages 数组，其中包含每个请求页面的块数组。每个块都包含类型、置信度、ID、边界框、提取的文本以及从零开始的页码。使用 format 设置为 TEXT时，块文本是一个带标记的值，例如 {"type": "text", "text": "Extracted content"}.

import json

from transforms.api import transform, Output
from transforms.mediasets import MediaSetInput, MediaSetInputParam
from pyspark.sql.functions import udf


@transform.spark.using(
    output=Output('ri.foundry.main.dataset.0-1-2-3-4'),
    media_input=MediaSetInput('/examples/input_pdfs'),
)
def compute(media_input: MediaSetInputParam, output):

    def extract_all_text(media_item_rid):
        metadata = media_input.get_media_item_metadata(media_item_rid)
        pages = metadata.document.pages
        if pages is None:
            return ""

        extracted_pages = []
        for page in range(pages):
            response = media_input.transform_media_item(media_item_rid, str(page), {
                "type": "documentToText",
                "documentToText": {
                    "operation": {
                        "type": "extractLayoutAwareTextV2",
                        "extractLayoutAwareTextV2": {
                            "pageRange": {
                                "startPageInclusive": page,
                                "endPageExclusive": page + 1
                            },
                            "config": {
                                "mode": "SCAN",
                                "format": "TEXT",
                                "languages": [{"type": "language", "language": "ENG"}]
                            }
                        }
                    }
                }
            })
            extracted_pages.extend(response.json()["pages"])
        return json.dumps({"pages": extracted_pages})

    extract_text_udf = udf(extract_all_text)

    result = media_input.dataframe().withColumn("text", extract_text_udf("mediaItemRid"))

    column_typeclasses = {
        "mediaReference": [{"kind": "reference", "name": "media_reference"}]
    }

    output.write_dataframe(result, column_typeclasses=column_typeclasses)

使用 OCR 将 PDF 文档集转换为文本

此转换使用传统的光学字符识别（OCR）从 PDF 文档中提取文本，而不是使用由视觉语言模型执行提取的 AI 驱动 OCR。 了解有关使用视觉语言模型提取 PDF 文档内容的更多信息。.

参数：

  • 语言中均受支持 (list[str]）：用于 OCR 的语言列表。默认为英语。所有有效代码可在 Tesseract 文档 ↗ 中的 languages 部分找到。
  • scripts (Optional[list[str]]）：用于 OCR 的脚本列表。默认为 None。所有有效代码可在 Tesseract 文档 ↗ 中的 scripts 部分找到。
  • media_item_rid (Optional[str]）：如果指定，将对指定的项而不是整个媒体集运行转换。默认为 None.
  • start_page (Optional[int]）：从零开始的 OCR 起始页。仅适用于 PDF 媒体集。默认为 0 （第一页）。
  • end_page (Optional[int]）：从零开始的 OCR 结束页（不包含）。仅适用于 PDF 媒体集。默认为 None （最后一页）。
  • return_structure (str): item_per_row or page_per_row。仅适用于对整个 PDF 媒体集的转换。默认为 item_per_row.
  • suppress_errors (bool）：指定错误处理行为。如果为 True，则会捕获错误，并且错误消息将返回到输出中。如果为 False，则不会捕获任何错误，并且构建将失败。默认为 True。仅适用于对整个媒体集的转换。

返回：

  • 一个 DataFrame、字符串列表或单个字符串。
    • str：对单个图像的转换。
    • list[str]：对单个 PDF 的转换。
    • DataFrame：对整个媒体集的转换。
      • 对于 PDF（item_per_row）：列为 media_item_rid, path, media_reference, extracted_text (list[str]).
      • 对于 PDF（page_per_row）或图像集：列为 media_item_rid, path, media_reference, page_number, extracted_text (str).

将音频转录为文本

将包含语音的音频文件转录为文本。

参数：

  • media_item_rid (Optional[str]）：如果指定，将对指定的项而不是整个媒体集运行转换。默认为 None.
  • 语言 (Optional[str]): 转录所使用的语言。默认为 None，在这种情况下将自动检测。有效语言可在 Whisper GitHub 仓库 ↗ under LANGUAGES.
  • performance_mode (Literal["more_economical", "more_performant"]): 转录所使用的性能模式。默认为 more_economical.
  • output_format (Literal["text", "segments"]): 输出的格式。默认为 text.
  • add_timestamps (Optional[bool]): 控制是否将时间戳添加到转录结果中。默认为 False。仅在 output_format 为以下值时适用 text.
  • suppress_errors (bool）：指定错误处理行为。如果为 True，则会捕获错误，并且错误消息将返回到输出中。如果为 False，则不会捕获任何错误，并且构建将失败。默认为 True。仅适用于对整个媒体集的转换。

返回：

  • DataFrame 或单个字符串。
    • str: 适用于对单个项目的转换。
      • text: 转录的文本。
      • segments: 包含转录片段的 JSON 对象，包括时间戳、片段置信度及更多详细信息。
    • DataFrame: Columns are media_item_rid, path, media_reference, transcription (str)。适用于对整个媒体集的转换。
