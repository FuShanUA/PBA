为 Entra ID (Azure AD) 配置 SAML 2.0 集成

本节包含 Entra ID（以前称为 Azure AD）特有的步骤，用于配置 SAML 2.0 集成，这些步骤属于更广泛的 通过 SAML 2.0 进行端到端身份验证教程。

您还可以找到 快速入门指南 ↗ ，请参阅 Microsoft 文档。

如果您收到了用于配置初始 SAML 集成的 Foundry 设置链接，请跳至下一步。否则，您可以添加新的 SAML 提供商：

  1. 转到 Control Panel 中的 身份验证 选项卡。
  2. 选择 添加提供商，输入名称（例如 My Azure AD SAML），然后选择 创建。
  3. 在 SAML 部分中，配置 SAML 集成元数据和其他值。

在 Azure Portal ↗中，选择 Microsoft Entra ID，然后选择 企业应用程序和 新建应用程序。搜索 Palantir Foundry ，然后选择 创建。

创建完成后，在 入门 框中选择 2. 设置单一登录。

系统随后会提示您选择单一登录方法。请选择 SAML。

SAML 集成元数据

在 Foundry 中，下载 SAML 集成元数据 XML，使用 上传元数据文件将 XML 上传到 Azure，然后选择 保存。

属性映射

您可以在 属性映射中为用户属性定义以下映射。如果使用 Foundry 设置链接，Azure 属性映射将被预先填充。

  • ID： NameID
  • 用户名： http://schemas.xmlsoap.org/ws/2005/05/identity/claims/name
  • 电子邮件： http://schemas.xmlsoap.org/ws/2005/05/identity/claims/emailaddress
  • 名字： http://schemas.xmlsoap.org/ws/2005/05/identity/claims/givenname
  • 姓氏： http://schemas.xmlsoap.org/ws/2005/05/identity/claims/surname

如果您想要配置提供商组，请选择 添加组声明 ，该选项位于 用户属性和声明 下（在 Azure 门户中）。在 Foundry 中，添加 http://schemas.microsoft.com/ws/2008/06/identity/claims/groups 作为 组属性映射，且不设置 用户组属性模式。

身份提供商元数据

在 Azure AD 中，使用 联合元数据 XML （位于 SAML 签名证书下）旁的链接下载您的身份提供商元数据 XML 文件，然后将其上传到 Foundry 中的 身份提供商元数据 区块。

完成并保存

在 Foundry 中，在 电子邮件域下添加与此 SAML 2.0 集成关联的电子邮件域。

最后，保存您的 SAML 2.0 集成，然后继续进行 多因素身份验证。
