资源选择

数据选择规则 允许您定义为 Export Pipeline 构建的 Bundle 的内容。 资源选择规则 允许您进一步筛选 导出哪些资源。这使您能够灵活地在 Bundle 中包含或排除特定的 Apollo 资源。

要开始使用，请选择一个可用的预设或创建自定义选择。

资源选择预设

Product Release 和元数据

此预设包含根据数据选择规则选择的所有 Product Release 和元数据。使用此预设，可通过新的 Product Release 及其关联的工件更新您的 Target Hub 中的 Product Catalog，并更新所有资源的元数据。使用此预设创建的 Bundle 大小可能高达 100GB 以上。

仅元数据

此预设仅包含由数据选择规则选择的资源的元数据。此元数据包括：

  • 环境元数据（例如配置）
  • 召回
  • Release Channel 成员资格（例如，Product Release 是否已标记到某个 Release Channel）
  • 模块定义
  • 团队
  • 漏洞抑制和报告

使用此预设可更新您的 Target Hub 中的元数据，而无需传输大型工件。使用此预设创建的 Bundle 大小通常仅为几 MB。

自定义

要在 Bundle 中包含一组特定资源，您可以创建自定义选择。请参阅 支持的资源 以获取可用资源及其描述的完整列表。

高级设置

您还可以通过展开 高级设置 菜单来配置资源选择的高级设置。

您可以通过开启 包含未来资源类型，在 Bundle 中自动包含添加到 Apollo Export 的新资源类型。禁用此选项后，您需要手动将新资源类型添加到管道中。

支持的资源

Apollo 会导出以下资源：

  • 产品： 一个 产品，由其产品 ID 标识。不含子资源时通常小于 1MB。
    • 产品发布元数据： 单个 产品发布的元数据，由其 Maven 坐标标识。包括原始的不可变 清单 以及可变元数据，例如发布渠道成员资格和相关的 召回。
    • 产品发布可变元数据： 单个产品发布的可变元数据，由其 Maven 坐标标识。包括可变元数据，例如发布渠道成员资格。
    • 容器镜像： 可部署到容器运行时的软件。对于类型为“service”的产品，这包括主镜像和任何其他容器镜像。对于其他产品类型（例如“terraform-module”），这包括纯文本文件。如果您的目标并非这些运行时环境，可以排除容器镜像。文件大小通常在几兆字节到数吉字节之间。
    • 产品二进制文件： 一个压缩的 tar 文件（.tgz），包含类型为“service”、“daemon”和“asset”的产品的可执行文件。此制品用于基于 VM 的环境中的资产和可执行文件安装。如果您仅部署到容器运行时，则可以排除产品二进制文件。文件大小通常在几兆字节到数吉字节之间。
    • 漏洞抑制： 针对产品中检测到的漏洞的已批准抑制。抑制会防止漏洞发现变为活动状态并导致召回。这使您能够在不立即造成中断的情况下管理风险。
    • SLS 配置： 安装类型为“service”或“k8s-app”的产品所需的 YAML 配置文件。大小通常小于 1MB。对于这些类型的版本发布，必须传输这些文件，否则将无法部署。
    • 资产二进制文件： 一个压缩的 tar 文件（.tgz），包含与“asset”类型的产品发布相关联的静态文件。这些文件既可以作为静态资源提供给浏览器上的前端应用程序，也可以作为数据供其他系统进程使用。文件大小通常在 1MB 到 1GB 之间。
    • 召回： 召回 （针对产品）可阻止升级到指定范围内受影响的产品发布。导出时将对敏感元数据进行脱敏。
  • 模块： 一个 模块 定义，通常小于 1MB。模块定义中引用的产品和产品发布将使用“产品”和“产品发布”元数据类型单独传输。
  • 环境： 环境元数据，包括所有已声明的实体、实例组、K8S 命名空间、网络安全规则，以及环境及其实体的配置。
  • 漏洞扫描报告： 针对 Bundle 中的工件检测到的漏洞报告。该报告由 Apollo Hub 生成。
  • 团队： 团队标识符。不包含团队成员资格，必须在 Target Hub 中进行配置。
  • 联系团队： 联系团队标识符。不包含团队成员资格，必须在 Target Hub 中进行配置。
  • Bootstrap 计划： 一组用于将实体直接部署到目标环境中 Kubernetes 集群的任务。此类型专用于构建新的远程 Apollo Hub,通常不会包含在生成的 Bundle 中。
