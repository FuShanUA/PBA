开始使用

本指南将向您展示如何在 Python transforms 仓库中设置数据期望。有关数据期望的高层次概述，请参阅 文档.

仓库设置：transforms-expectations 库

在 Code Repository 左侧打开库搜索面板。 transforms-expectations 库应该已经安装。通过检查已安装库的列表来验证这一点。如果 transforms-expectations 尚未安装，请立即搜索并安装它。

转换设置

将 expectations 和 Check 导入到您的 transforms 文件中：

Copied!
1
2
from transforms.api import transform_df, Input, Output, Check
from transforms import expectations as E

对于常见的 schema 和列期望，请导入相应的类型库。

类型期望使用 Polars 类型 ↗ 进行单节点计算（无论使用哪种引擎），并使用 Spark SQL 类型 ↗ 进行 PySpark 计算。您必须导入相关的库并正确引用类型，如下例所示。

创建检查

单个检查的基本结构：

Copied!
1
Check(expectation, 'Check unique name', on_error='WARN/FAIL')
  • expectation - 单个 expectation，它可以是多个子期望的复合期望（例如使用 any/all 运算符）
  • 检查唯一名称 - 该名称在 transform 中必须唯一（输出和输入之间不能共享相同名称），并将在各应用中标识该检查（例如 Data Health、Builds 应用）
  • on_error - 定义当期望未满足时作业的行为：
    • FAIL （默认）- 如果检查失败，作业将被中止
    • WARN - 作业将继续运行，并生成警告，由 Data Health 处理

。部分设置也可以在源级别进行配置。 on_error='FAIL' 在单节点 transform 的 虚拟表 输出中不受支持。

将检查分配给数据集

每个检查应传递给单个输入或输出。将单个检查作为 checks=check1 传递，或在数组中传递多个检查： checks=[check1, check2, ...]

使用多个检查可以创建更清晰易读的期望结构，并分别控制每个有意义的检查的行为。

以下是对输出进行简单主键检查的示例：

from transforms.api import transform, Input, Output, Check
from transforms import expectations as E
import polars as pl


@transform.using(
    output=Output(
        "/path/dataset",
        checks=Check(E.primary_key('id'), 'Primary Key', on_error='FAIL')
    ),
    input=Input("/path/input"),
)
def compute(output, input):
    input_df = input.polars()
    return output.write_table(input_df)

复杂检查

您还可以使用复合期望添加更复杂的检查。例如，让我们检查列 age 在给定范围内是否不为 null。请注意，我们可以定义复合期望并在 transform 中的多个检查中使用它，对错误应用不同的行为。

即使检查由复合期望组成，它也会作为整体被监控。如果您想监控（即观察并接收通知）复合期望的特定部分，建议将其拆分为多个不同的检查。

from transforms.api import transform, Input, Output, Check
from transforms import expectations as E
import polars as pl


# We assume an age is valid if it is between 0 and 200.
expect_valid_age = E.all(
    E.col('age').non_null(),
    E.col('age').gte(0),
    E.col('age').lt(200)
)


@transform.using(
    output=Output(
        "/path/dataset",
        checks=[
            Check(E.primary_key('id'), 'Primary Key', on_error='FAIL'),
            Check(expect_valid_age, 'Valid age on output', on_error='FAIL')
        ]
    ),
    input=Input(
        "Users/data/input",
        checks=Check(expect_valid_age, 'Valid age on input', on_error='WARN')
    )
)
def compute(output, input):
    input_df = input.polars()
    return output.write_table(input_df)
