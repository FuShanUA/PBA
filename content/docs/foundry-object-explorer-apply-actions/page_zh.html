应用操作

在探索中，视图右上角的按钮会分类并列出与当前对象集或所选内容相关的操作。三个主要类别分别是 “操作” 用于数据回写， “打开方式” 用于将您当前的探索转移到其他平台应用程序，以及 “导出” 用于将数据带出平台，例如导出到 Excel 电子表格中。

操作

操作类型 在本体论中配置后会首先显示，并附带名称和描述。选择其中一项将打开一个表单，供您填写参数并提交操作。探索中当前选定的对象集（如果未选择任何对象，则为所有对象）会直接传递到表单中，因此只需配置其余参数。请注意，如果所选对象的数量超过 1000，则操作不可用。

Object Explorer 会使用相关的所选对象预填操作参数。如果不确定应预填哪个参数，则会将决定权留给用户，并且不会提供任何预填。

在其他应用程序中打开

如果有方法可在其他应用程序中打开当前结果集，这些选项将显示在 "打开方式" 标题下方。

导出

导出对象集的方式（例如导出到 Excel 或将对象 ID 复制到剪贴板）会显示在此处。
