使用 Handlebars 访问值

Slate 使用 Handlebars ↗ 在查询、函数和小组件中进行模板化。Handlebars 模板被包裹在 {{ }} 中，并且可以访问 Slate 对象，例如小组件、变量以及查询/函数的结果。例如，如果你有一个下拉小组件 w1，你可以使用模板访问所选的值 {{w1.selectedValue}}。Slate 会自动对模板进行求值，并用求值结果替换它。

Handlebars 模板还可以调用辅助函数。更多信息请参见 辅助函数.

可以引用哪些 Slate 对象？

变量

你可以访问 变量 在变量编辑器中使用 {{variableName}}定义的变量。例如，如果你有一个变量 var1 = {"a": [1,2,3]}，那么模板 {{var1.a.[0]}} 的求值结果为 1。 你还可以访问 Slate 的 环境变量，包括有关当前应用程序用户或用户专用存储的信息。例如，使用模板 {{$global.user.firstName}} 将显示用户的名字。

查询

你可以访问 查询结果。例如， {{myQuery}} 包含来自 SQL 或 HttpJson 查询的结果。还有一个隐藏的 _response 字段，其中包含一些元数据。

函数

你可以访问 函数 的返回值，方法是将函数名包裹在 handlebars 中。例如， {{myFunction}}.

小部件属性

你可以访问某些小组件属性。具体来说，模板可以访问叶子属性（包括数组及其子属性）。例如，假设我们有一个图表小组件。

Handlebars 可以在哪里使用？

查询编辑器

查询编辑器中的 Handlebars 模板总是被替换为字符串值。如果模板的求值结果不是字符串，则该值会首先被转换为字符串。这是因为查询本身始终是一个字符串。例如：

Copied!
1
SELECT {{column w8.selectedValues}} FROM allNamed WHERE name = {{param w12.selection.xValues}};

非字符串值会使用 toString 方法进行转换。这对于整数和布尔值通常没有问题，但对于更复杂的对象可能会产生意外的输出。例如，对某个对象运行 toString 的求值结果为 [object Object]，这可能不是你想要的结果。你可以使用类似 {{jsonStringify myObject}} 的辅助函数来解决这个问题。

函数编辑器

与查询不同，函数编辑器中的 Handlebars 模板总是被替换为其求值结果。例如：

Copied!
1
2
var a = {{query1}};  // query1 is an object
var b = a.results[0];  // You can access its properties.

在函数编辑器中不能使用辅助函数，你必须直接引用 Slate 对象。此外，你不能设置变量或属性值，因为你无法更改函数外部的任何状态。例如：

Copied!
1
2
var c = {{jsonStringify query1}}; //invalid - cannot use helpers
{{var1}} = [1,2,3];  // invalid - cannot set global variables

小组件属性编辑器

当应用程序处于 编辑 模式时，你可以在小组件的属性编辑器中使用 handlebars。在小组件中，Handlebars 模板必须始终包裹在双引号中 "" ，因为花括号不是有效的 JSON 语法。

通常，小组件中的模板会被替换为字符串。如果求值结果不是字符串，Slate 将对该值运行 toString 。此规则有一些例外。当以下条件成立时，Slate 会直接用求值结果替换模板：

  1. 只有一组括号 {{}} AND
  2. 括号之外没有其他字符（包括空格）。

Handlebars 不能在哪里使用？

  • Handlebars 不能在变量编辑器中使用。
  • Handlebars 不能在样式编辑器中使用。
  • Handlebars 不能在应用程序的视图模式下使用。如果你在小组件或文本字段中输入 handlebars，该表达式既不会被求值也不会被替换。

教程：关联小组件

以下教程将教你如何创建一个按钮，让用户可以选择了解某个特定航班中某架飞机的更多信息。这需要我们在两个小组件之间创建一个关联。

要关联微件，您必须知道微件的名称以及要关联的属性。在我们的例子中，我们希望获取 tail_num 原始表格中所选行的值，但我们在表格中配置选择时使用了 flight_id 作为主键。

这是使用另一个辅助函数的理想时机。由于获取所选表格行的列值是一种常见模式，我们可以使用一个函数来实现：

function getRowData(s){
    var returnObj = {};
    var index = data[selectionColumn].indexOf(s);

    //this iterates through each array in the object data
    //value is the actual array, and key is the key for that array
    _.forOwn(data, function(value, key){
        returnObj[key] = value[index];
    });

    return returnObj;
}

// The same data as is fed into the table
var data = {{f_data}};

// The current selection in the table
var selection = {{w_mainTable.selectedRowKeys}};

// The column configured as the table primary key
var selectionColumn = {{w_mainTable.selectionIdentityColumnId}}

var rowData = _.map(selection, getRowData);

return rowData;

在上面的代码中添加一个名为 f_selectedRowValues 的新函数。将 var data 值的 Handlebar 模板改为指向 {{q_allFlights}} 和 selectionColumn 和 selection 变量指向我们的 w_flightTable.

要理解 selectedRowKeys 是什么，请回顾表格微件的代码。我们设置了 "selectionIdentityColumnId" to "flight_id"。这意味着列 flight_id 被用作给定行的唯一键。一旦用户在表格中选择了一行，该唯一键（航班 ID 号）就会被添加到 selectedRowKeys.

selectedRowKeys 是表格微件的一个属性，只能通过用户交互来修改。编辑微件时，您可以在 JSON 编辑器下方看到用户交互属性的只读值。

现在，我们可以通过选择 测试 来验证函数行为。

选择函数配置完成后，我们可以添加一个文本微件，将其命名为 w_linkingButton 并将其移动到表格上方。在该微件的属性编辑器中，切换到 HTML 选项卡（位于 内容 并输入以下内容：

接下来，我们通过将用户输入添加到基础 URL 来构建一个链接。然后，我们设置显示文本。

此外，我们可以添加一小段样式代码，使微件右对齐，以便更容易对齐：

sl-text {text-align: right}

文本和链接都依赖于上面配置的选择函数： {{f_selectedRowValues.[0].tail_num}}. f_selectedRowValues 指的是我们之前在本教程中创建的从表格选择中读取数据的函数。

当没有选择任何内容时，文本微件将显示 了解更多飞机信息。此时选择它会跳转到一个失效的链接。

一旦在表格中选择了一行，按钮文本将更新以反映所选内容的名称；选择该按钮将带您进入正确的网页。
