用例开发

Palantir 平台旨在通过一系列强大的用例开发工具赋能多元化的构建者社区，其中包括应用程序构建工具、工作流构建工具、集成 分析工具、 开发者工具。其中每一款都利用了 Foundry 的核心安全、血缘、数据和计算基元的强大功能，让团队能够专注于交付运营能力，而非管理基础设施。Palantir 平台中的每款工具都旨在持续且安全地丰富 本体论中包含的一组一致数据和逻辑资产。这使得知识能够随着运营工作流在企业范围内的大规模扩展而不断累积。

应用程序构建

Palantir 平台提供多种构建应用程序的方式，以满足不同的需求：

  • Workshop 是一款无代码、面向对象的运营应用程序构建器，也是将对象、关联和操作转化为交互式工作流的最快方式。
  • OSDK React 应用程序 让您能够使用 React 构建完全自定义的用户界面，由 本体论 SDK (OSDK)提供支持，可在您需要超出 Foundry 内置工具所能提供的体验时使用。 Pilot 提供了一种精简的、由 AI 驱动的方式，可通过自然语言提示来构建这些 OSDK 应用程序。
  • 自定义小组件 让技术构建者能够通过自定义前端代码扩展 Workshop，添加量身定制的功能，而无需从头开始构建独立的应用程序。
  • Slate 是一款低代码拖放式构建器，可用于构建运营应用程序、交互式仪表板和自定义着陆页，还可选择使用 HTML、CSS 和 JavaScript 进行自定义。
  • 代码工作区应用程序 让您能够在第三方 IDE 中构建和发布交互式 Streamlit、Dash 和 Shiny® 应用程序，并以 Foundry 数据和治理为支撑。

Workshop

Workshop 是一款灵活的、面向对象的应用程序构建工具。Workshop 利用 本体论 中的语义基元（如对象和关联）和动态基元（如操作和函数），从而实现交互式 Web 和移动应用程序的快速交付。Workshop 中的应用程序构建体验让用户能够利用无代码、低代码和基于代码的小组件创建功能强大的应用程序。无需任何技术专业知识即可开始使用小组件进行构建，并将对象、关联和操作串联成由用户驱动的工作流，这些工作流 远超仪表板 或被动可视化。同时，基于代码的增强可通过 函数 可以无缝嵌入到 Workshop 小组件中，以实现复杂的交互、级联流程和复杂的数据捕获。当工作流需要内置小组件无法提供的功能时，您可以使用 自定义小组件 来扩展 Workshop 应用程序，从而在无需离开 Workshop 的情况下添加量身定制、基于代码的组件。

了解有关 Workshop 的更多信息。

OSDK React 应用程序

OSDK React 应用程序 让您能够使用 React ↗构建完全可自定义的用户界面，此类应用由 Ontology SDK (OSDK) 提供支持，并通过 Developer Console创建。通过将 Foundry 作为您的后端，您可以将 React 生态系统与本体论的大规模查询、编辑和细粒度治理控制相结合，安全地交付定制应用程序。要在无需从代码着手的情况下构建 OSDK React 应用程序， Pilot 提供了一种精简的 AI 驱动体验，可根据自然语言提示生成本体论实体、设计和前端，并引导您完成部署。

了解有关 OSDK React 应用程序的更多信息。

自定义小组件

自定义小组件 允许技术构建者使用自定义前端代码安全地扩展 Workshop 应用程序。无需从头开始构建独立的应用程序，您可以实现并非开箱即用的功能，例如定制的可视化效果或面向特定学科的本体论对象视图，并将其直接嵌入 Workshop 模块中。您还可以在 Workshop 中嵌入单个整页自定义小部件，将自定义代码的灵活性带入 Workshop 框架。

了解更多有关自定义小部件的信息。

Slate

Slate 为构建者提供了一套灵活的工具，可快速创建运营应用程序和交互式仪表板。Slate 使应用程序开发人员能够通过拖放界面构建动态且响应迅速的应用程序，从而缩短开发时间并降低成本。Slate 不仅包含与 Foundry 本体论无缝集成的功能，还使开发人员能够使用 HTML、CSS 和 JavaScript 完全自定义应用程序。

了解更多有关 Slate 的信息。

代码工作区应用程序

代码工作区应用程序 让您构建和发布交互式 Web 应用程序，使用 Streamlit ↗ 或 Dash ↗ （适用于 Python）以及 Shiny® ↗ （适用于 R），直接在第三方 IDE 中进行，这些 IDE 位于 代码工作区。数据科学家和开发人员可以基于 Foundry 数据将分析转化为运营应用程序，这些应用程序托管在 Foundry 容器中，并内置了平台的版本控制、分支和数据治理功能。

工作流构建与管理

Palantir 平台中主要的工作流构建和管理工具包括 Workflow Lineage， Automate， Solution Designer，以及 Use Cases。

Workflow Lineage

Workflow Lineage 提供了一个交互式工作区，用于理解和管理应用程序及其底层流程。借助 Workflow Lineage，您可以探索工作流，并查看有关对象、操作、函数、大语言模型和应用程序的详细信息。对于正在创建、调试或维护工作流的应用程序构建者而言，Workflow Lineage 尤为有用。在更改或扩展工作流时，溯源图、更深入的属性和 Workshop 小部件/变量溯源以及升级工具都非常有帮助。

Automate

Automate 为您提供了在平台中设置和执行所有业务自动化的统一入口。Automate 应用程序允许用户定义条件和效果；条件会被持续检查，当满足指定条件时，效果会被自动执行。

了解有关 Automate 的更多信息。

Carbon

Carbon 支持为特定用户组配置定制的平台体验，即所谓的工作区。Carbon 可为需要执行关键运营工作流的技术水平较低的用户提供聚焦的体验。每个 Carbon 工作区都是一组经过精心整理的应用程序和资源，可对其进行配置，以优化特定的一组运营和最终用户工作流。例如，一个飞机零部件维护工作区可能包含：一个 Workshop 应用程序，其中包含需要维护的零部件的动态更新列表，以及用于对每个零部件进行分类处理的本体论驱动的操作；另一个用于调查每个零部件维护问题的应用程序；以及一个展示维护趋势随时间变化的 Quiver 分析。Carbon 能够将丰富多样的 Foundry 应用程序和分析功能整合到聚焦的运营体验中。

了解更多关于 Carbon 的信息。

Solution Designer

Solution Designer 是一款交互式工具，用于创建使用 Palantir 平台构建的解决方案的架构表示，包括第一方和第三方集成点的表示、指向平台资源的链接、按需访问文档和最佳实践等。

了解更多关于 Solution Designer 的信息。

开发者工具链

Palantir 开发者工具链 使您能够使用自己的工具在 Palantir 平台之上构建自己的应用程序。

Palantir 开发者工具链的核心是 Ontology SDK (OSDK) ，生成于 Developer Console。该 Ontology SDK 以适用于 TypeScript 的 npm 包或适用于 Python 的 pip 或 Conda 包的形式创建，且仅包含您本体论中预先选定的子集。该 SDK 允许您访问对象类型、应用操作来更新本体论中的数据、调用函数，并运行 AIP Logic 函数，适用于 已启用 AIP 的 注册。该 Developer Console 还包含特定于本体论的文档，其中涵盖为您的应用程序选择的实体。应用程序使用 OAuth 流程作为公共或机密客户端来访问数据。

了解更多关于 Ontology SDK 的信息。

您也可以直接使用 Foundry 的 REST API 以便从任何语言或运行时针对本体论查询对象、执行操作和调用函数，适用于完全在 Foundry 之外构建的应用程序。
