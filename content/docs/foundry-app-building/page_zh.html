工作流血缘

工作流血缘 提供了一个交互式工作区，用于理解和管理应用程序及其底层流程。借助 Workflow Lineage，您可以探索工作流，并查看有关对象、操作、函数、大语言模型和应用程序的详细信息。对于正在创建、调试或维护工作流的应用程序构建者而言，Workflow Lineage 尤为有用。在更改或扩展工作流时，溯源图、更深入的属性和 Workshop 小部件/变量溯源以及升级工具都非常有帮助。

碳

碳 支持为特定用户组配置定制的平台体验，即所谓的工作区。Carbon 可为需要执行关键运营工作流的技术水平较低的用户提供聚焦的体验。每个 Carbon 工作区都是一组经过精心整理的应用程序和资源，可对其进行配置，以优化特定的一组运营和最终用户工作流。例如，一个飞机零部件维护工作区可能包含：一个 Workshop 应用程序，其中包含需要维护的零部件的动态更新列表，以及用于对每个零部件进行分类处理的本体论驱动的操作；另一个用于调查每个零部件维护问题的应用程序；以及一个展示维护趋势随时间变化的 Quiver 分析。Carbon 能够将丰富多样的 Foundry 应用程序和分析功能整合到聚焦的运营体验中。

开发者工具链

Palantir 开发者工具链 使您能够使用自己的工具在 Palantir 平台之上构建自己的应用程序。

Palantir 开发者工具链的核心是 本体论 SDK (OSDK) ，生成于 自定义小部件。该 Ontology SDK 以适用于 TypeScript 的 npm 包或适用于 Python 的 pip 或 Conda 包的形式创建，且仅包含您本体论中预先选定的子集。该 SDK 允许您访问对象类型、应用操作来更新本体论中的数据、调用函数，并运行 AIP Logic 函数，适用于 已启用 AIP 的 注册。该 Developer Console 还包含特定于本体论的文档，其中涵盖为您的应用程序选择的实体。应用程序使用 OAuth 流程作为公共或机密客户端来访问数据。

了解更多关于 Ontology SDK 的信息。
