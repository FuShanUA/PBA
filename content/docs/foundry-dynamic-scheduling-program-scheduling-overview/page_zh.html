项目集排期小部件

项目集排期 小部件是一种 Workshop 小部件,可按时间顺序呈现项目集、项目和任务。使用它可以跨工作流跟踪进度、直观展示任务之间的相互关系,并识别可能影响下游交付成果的阻碍因素。该小部件适用于任何具有表示开始和结束时间的日期或时间戳属性的对象类型。

配置项目集排期小部件的模块构建者可以:

  • 在交互式时间线上跟踪项目和任务的进度,任务显示为体现其计划工期的圆片。
  • 以圆片之间的箭头直观呈现任务依赖关系,方便用户识别阻碍因素,并了解延误如何在项目集中逐级传导。
  • 在时间线旁将任务整理到由可折叠分组构成的分层表格中——例如按项目、团队或阶段进行分组。

圆片类型

数据层中的每个任务或事件都会以 圆片 的形式显示在时间线上。圆片类型按数据层进行配置,决定了条目的可视化方式以及可用的交互。

  • 标准圆片: 表示跨越一定时间范围的任务或活动的矩形条。它们支持依赖箭头，用于可视化任务之间的依赖关系。
  • 背景puck： 带阴影的矩形区域，表示较宽的时间段，例如项目阶段、规划周期或评审窗口。背景puck为位于其前面的任务提供视觉上下文，但它们是只读的，用户无法对其进行编辑。
  • 事件puck： 位于单个时间点的细垂直标记。它们可以表示里程碑、截止日期或关键决策点。

依赖关系

Program Scheduling 小部件可以将任务依赖关系可视化为连接时间轴上相关puck的箭头，帮助用户理解顺序约束并识别哪些任务正在阻塞下游工作。依赖关系按图层配置，具体方法是在对象类型上选择一个数组属性，该属性引用同一图层中其他对象的主键。

  • 依赖箭头仅适用于标准puck。
  • 将鼠标悬停在某个puck上会高亮显示其依赖链，从而更容易追踪哪些任务被阻塞以及哪些任务正在阻塞其他任务。
  • 您可以在默认情况下隐藏箭头，方法是使用“ 默认隐藏箭头 ”界面选项。用户可以在运行时切换箭头的可见性。

小部件布局

下图提供了完整小部件布局的概览。

  1. 时间轴： 小部件主体显示沿水平时间轴定位的任务块，该时间轴由可配置的开始和结束时间戳控制。如果进行了编辑， 保存更改 按钮将显示在右侧。
  2. 行： 主体左侧显示按可配置属性（如项目、团队或阶段）组织的分层行表格。组可以展开或折叠。
  3. 依赖关系： 箭头将相关的任务块连接起来，以可视化顺序约束并突出显示阻碍因素。
  4. 详情卡片： 选择任务块会打开一个详情卡片，其中显示所选任务的属性。用户还可以在此视图中编辑和遍历关联。
