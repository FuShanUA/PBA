Workshop 中的拖放

拖放功能允许用户通过将数据从一个应用程序拖动到另一个应用程序，轻松地在应用程序之间移动数据。请参阅 拖放文档 以了解更多信息。

在 Workshop 中，多个组件支持拖放操作，可实现 跨应用程序交互 以及微件之间的交互。下文将详细介绍这些组件和交互。

Workshop 放置区域

放置区域是交互式组件，允许用户通过将数据“放置”到元素上来传输数据。以下是可以配置为放置区域的 Workshop 组件，请参阅 放置区域文档 以了解更多信息。

区块拖放区域用法

在区块组件配置为拖放区域后，用户可以将对象拖放到该区块上。使用 增强功能，用户可以将 Gotham 和 Foundry 对象都拖放到此拖放区域。

此拖放区域接受 Foundry 对象 RID 和 Foundry 对象集 媒体类型。请参阅 媒体类型文档 以了解更多信息。

拖动区域

拖动区域是允许用户“抓取”数据并通过拖动将其传输到拖放区域的交互式元素。以下是可配置为拖动区域的 Workshop 组件。请参阅 拖动区域文档 以了解更多信息。

以下拖拽区域可以借助 增强功能被拖拽到 Gotham 和 Foundry 中接受对象媒体类型的放置区域上。请注意，如果不使用增强功能，这些拖拽区域只能将数据传输到接受其特定媒体类型的放置区域。

对象集标题拖拽区域

要将 对象集标题 组件配置为拖拽区域，请选择该组件，并在右侧的配置面板中切换 启用拖拽 开关。该拖拽区域可用于传输 Foundry 对象集 RID。

启用此功能后，该组件可以被拖拽到兼容的放置区域以传输数据。如果不使用增强功能，该组件只能被拖拽到接受 Foundry 对象集 媒体类型的放置区域。请参阅 媒体类型文档 以了解更多信息。

对象表格单元格拖拽区域

单元格位于 对象表格 中，可以被拖拽到兼容的放置区域以传输数据。如果不使用增强功能，该拖拽区域可以被拖拽到接受 Foundry 对象 RID 媒体类型的放置区域。请参阅 媒体类型文档 以了解更多信息。

对象视图拖拽区域

图标位于 对象视图小组件 标题可以拖放到兼容的放置区域上。在没有富化的情况下，此拖动区域与接受 Foundry 对象 RID 媒体类型的放置区域兼容。请参阅 媒体类型文档 以了解更多信息。

小组件内的重新排序

某些 Workshop 小组件提供的拖放交互仅在小组件自身内部进行，而不会将数据传输到放置区域。例如， Object List 小组件可以配置为允许用户通过拖动对象卡片来重新排序项目。

在 Object List 中启用重新排序时：

  • 在单个 Object List 小组件内支持重新排序
  • 不支持在网格布局中重新排序
  • 该小组件仅显示前 500 个对象

有关此配置的更多信息，请参阅 Object List 文档。
