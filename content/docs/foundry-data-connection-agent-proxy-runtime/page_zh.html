代理网络代理配置参考

本页面描述了通过代理（agent）作为网络代理时可用的配置选项，适用于 agent 代理出站策略 on 您必须正确配置出站策略（如果使用 连接，并假设您已经熟悉 数据连接代理 及其 通用配置选项.

用作代理的代理程序为 Foundry 中的服务提供了一条网络路径，使其能够访问位于另一个网络中、无法通过 Foundry 网络直接访问的系统。 当 Foundry 托管在云端时，需要使用代理来访问无法通过互联网访问的系统。当 Foundry 托管在私有网络中时，需要使用代理来访问其他网络中的系统，其中可能包括在无法直接访问的情况下的公共互联网。

代理网络代理使 Foundry 中的应用程序能够像直接通过 Foundry 网络连接到数据源一样运行，并且可以配置多个代理，以便通过交替的维护窗口避免停机。请按照以下指南配置和管理用作代理的代理程序。

代理网络代理专用的安全控制

为确保通过代理的连接只能访问所需的资源，提供了多种安全控制。

安全控制分为 强制性的 且无法禁用的，或 可选 且默认不启用的。

数据源配置强制执行

数据源上定义的 URL 中的主机名和端口将访问限制为仅该主机名和端口（在连接到代理网络代理时）。尝试连接到任何其他主机名或端口将导致代理返回 HTTP 403（未授权）响应代码。

这可以在导入连接并在代码中使用时防止未经授权的连接。

如果仅使用此安全控制，请确保能够将代理分配给特定数据源的用户也受到信任，可以连接到从代理主机可访问的任何系统。

要进行配置，请导航至 代理设置，然后切换 高级 中的 管理配置 部分。在 YAML 文件中，为 agentProxyConfiguration 添加一个块，其缩进级别与 security 执行函数

代理允许列表（本地文件）

用于 Foundry 中的代理允许列表 的相同配置也可以在代理主机本身的文件中设置，从而防止 Foundry 中的用户编辑该配置。

要在本地配置代理允许列表，请按照以下步骤操作：

  1. 通过 SSH 登录到代理的主机。
  2. 创建一个名为 agentProxyConfig 的文件夹，位于包含您的 magritte-bootvisor-<version> （根文件夹）的同一目录中。
  3. 在新创建的 agentProxyConfig 文件夹中，创建一个名为 agentProxyConfig.yml.
  4. 直方图 agentProxyConfig.yml 文件，并且 agentProxyConfig folder 必须 必须以 root 用户创建，并且必须设置文件权限以防止 agent 写入此文件或文件夹。Agent 将 不 在 agentProxyConfig.yml 文件存在且可写，或某个父目录可被 agent 写入时，运行 agent 代理功能。
  5. 此文件的内容与 agent 设置界面中可用的配置相同。

代理主机防火墙

与任何 agent 一样， 我们建议在主机上设置防火墙，以将连接限制为仅必要的连接.

连接池配置

Agent 代理维护一个连接池用于处理请求。您可以根据工作负载配置连接池大小以优化性能。

要配置连接池，请导航至 代理设置，然后切换 高级 中的 管理配置 部分。在 YAML 文件中，将连接池设置添加到 agentProxyConfiguration 块中的其他字段：

agentProxyConfiguration:
  maxConnections: 250
  coreConnections: 100
选项默认值描述
maxConnections300Agent 代理可以打开的最大连接数。
coreConnections20池中维护的最小连接数。

某些连接器（例如 Databricks）可能会同时打开大量连接。如果您在使用 agent 代理策略时观察到 agent 上出现连接池耗尽错误，请考虑增加 maxConnections 和 coreConnections 值。
