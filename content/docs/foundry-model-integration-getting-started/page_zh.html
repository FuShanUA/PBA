开始使用

在开始建模工作流之前，请确保您对 Foundry 的核心概念有较高层次的理解， 代码仓库, Python 转换, 本体论日 函数.

如果您是 Foundry 新用户， 监督学习教程 提供了从设置新项目到将模型部署到生产环境的完整演练。

请查阅 专属页面 以详细了解选择合适工具时需要考虑的因素。

常见的模型创建工作流

  • 在 Jupyter® 中使用来自 Palantir 平台的数据训练模型 代码工作区, 代码仓库，或在 模型工作室 中进行无代码模型训练
  • 导入模型权重并将其注册为模型
  • 导入容器并将其注册为模型
  • 注册外部托管的模型

部署模型以进行推理和使用

  • 将模型用作 Python 转换的输入
  • 在 Pipeline Builder 中使用模型
  • 在 Modeling Objectives 中创建批量部署 and 评估模型性能
  • 配置实时部署以将模型作为 REST 端点提供服务

注册模型以在本体论中使用

  • 注册实时部署以用作函数
  • 在另一个函数中使用该模型函数，以利用模型预测编写自定义业务逻辑
