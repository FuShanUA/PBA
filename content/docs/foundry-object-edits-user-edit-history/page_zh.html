启用用户编辑历史

跟踪对索引到 Object Storage v2 中的对象的用户编辑历史。可使用以下方式启用或禁用此功能 跟踪用户编辑历史 开关进行控制，该开关位于本体论管理器的 数据源 选项卡中，如下面的屏幕截图所示。

要允许用户编辑， Edits 开关 必须处于启用状态。

编辑历史会记录对对象的每一次编辑，无论该编辑是如何进行的。如果要记录编辑背后的决策，包括用户提交的参数值以及提交时的上下文，请在操作类型上启用 操作日志 。

编辑历史时间戳

编辑历史使用 UTC 提交时间戳，该时间戳由操作在准备将编辑提交到 Object Storage v2 时捕获。当操作类型具有 操作日志时，同一操作的操作日志和编辑历史条目使用相同的时间戳。此时间戳并不表示编辑在查询中变为可见的确切时间。

由 Current User/Time in 操作规则 提供的时间戳表示操作执行的开始时间，并在整个执行过程中保持不变。因此，由此规则设置的时间戳属性的值可能早于编辑历史时间戳。

常见问题与注意事项

  • 编辑历史反映的是启用 跟踪用户编辑历史后对对象所做的更改。在此功能激活之前所做的任何更改都不会被跟踪。
  • 启用 跟踪用户编辑历史后，需要几分钟时间进行初始化。在这段短暂的时间内，用户无法对这些对象执行操作。
  • 如果您正在从 Object Storage v1 迁移到 Object Storage v2，请确保在迁移过程中勾选 preserve edit history ，以便保留编辑历史。
  • 有权访问对象当前状态（具有相同主键的对象）的用户可以访问该对象的完整历史。这意味着，如果某个对象被删除后又重新创建，用户仍然可以查看删除操作之前发生的历史。

启用 跟踪用户编辑历史Workshop 编辑历史小组件 后，可将其添加到 Workshop 模块或由 Workshop 支撑的对象视图中，以显示编辑历史。

禁用编辑历史

禁用 跟踪用户编辑历史 将永久删除此对象类型的所有现有编辑历史。在保存本体论之前，用户将收到警告，并且必须确认知晓编辑历史将被删除。
