指标卡片（Metric Card）

直方图 指标卡片（Metric Card） 小部件以可配置的卡片式界面显示 Workshop 变量值。通常，指标卡片用于突出显示 Workshop 模块中的关键数据。配置指标卡片小部件的模块构建者可以：

  • 将一组指标一起显示。
  • 使用条件格式来引起对指标的注意，并帮助用户解读指标值。
  • 设置指标的布局样式，使其以卡片、标签或列表的形式显示。
  • 显示时间序列数据，包括显示时间序列历史记录的迷你图。

下面的屏幕截图展示了如何在 Workshop 模块中使用指标卡片小部件来显示不同国家 COVID-19 疫苗接种的统计数据。后续示例也将沿用此示例场景。

指标配置

可以使用以下选项配置每个单独的指标：

  • 标签
    • 为指标设置可选标签。此文本显示在单个指标的顶部。
  • 描述
    • 设置可选的静态或变量支持的描述文本。当用户将鼠标悬停在信息图标上时，将显示该描述，如下所示。

  • 值类型

    • 指定要显示的值是字符串还是数字。
    • 此部分还配置以下选项：
      • 值： 用于填充指标的值必须由相应类型的 Workshop 变量支撑。因此，如果值类型设置为字符串，用户必须选择一个字符串变量来填充指标。类似地，如果值类型设置为数字，用户必须选择一个数值变量。参见 变量 以了解有关 Workshop 变量的更多信息。
      • 数字格式化： 此可选配置仅适用于数字值类型。用户可以指定值格式化方案来显示变量的数值，包括显示的小数位数。要限制指标显示的小数位数，请设置 max 值，位于 Fraction digits 字段中；小数位数超过该值的数值将被四舍五入到该长度。例如，将最大小数位数设置为 2 displays 3.14159 as 3.14。了解更多关于 和.
      • 条件格式化： 此可选配置允许用户对显示的指标值应用基于规则的格式设置，如下例所示：如果指标值小于或等于零，则以红色显示，否则以绿色显示。了解更多信息，请访问 条件格式设置.



  • 显示次要指标？ 一个可选配置，用于在同一指标显示中，在主指标下方显示第二个指标。将此开关设置为 Yes 会打开次要指标的值类型配置，该配置与主指标的配置类似。

  • 显示可视化？ 一个可选配置，用于显示描绘指标时间序列历史记录的迷你图。将此开关设置为 Yes 会打开包含以下选项的配置界面：

    • 位置： 指定迷你图应显示在 Side-by-side （旁边）还是 Stacked （下方）与指标值一起显示。

    • 时间序列集： 要可视化的时间序列。这是使用 Time series set 变量指定的，如下面的屏幕截图所示。参见 变量 以了解有关 Workshop 变量（包括时间序列集变量）的更多信息。



    • 时间范围： 指定应显示数据的时间范围。预设选项包括 All time, Last hour, Last day日 Last week，但选择 Custom range 会打开一个详细范围选择器，您可以在其中指定 Exact 或 Relative 范围。参见 Workshop 中的时间序列属性 以了解有关指定时间范围的更多信息。

    • 基线： 当此参数开启时，会随迷你图一起渲染一条基线，以帮助直观地解读趋势。参见 Workshop 中的时间序列属性 以了解有关指定基线的更多信息。

  • 交互式指标： 一个可选配置，用于触发 command, 操作，或 事件（event） （在选择卡片时）。默认为 无交互。如果您选择 事件要发布的组件集版本包含在此清单文件中。当使用 切换到 {tab name} or 切换到 {page name} 事件也可以使指标显示为选中状态。有关更多信息，请参阅 选中状态.
