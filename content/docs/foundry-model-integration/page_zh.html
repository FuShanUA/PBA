模型连接与开发

在 Palantir 平台中， 模型 是封装任意机器学习逻辑的制品。模型可在数据管道、本体论和应用层的工作流中使用，以支持各种不同的用例。

Palantir 采用全面的方式来实现模型集成。模型既可以在平台内基于集成数据进行开发，也可以在外部开发后以库、制品、容器或 API 的形式导入。

完成集成后，模型即可与平台工具配合使用，用于推理、部署、治理、ML Ops 和落地应用。模型创建和使用过程中的每一步都受到平台在血缘、安全、版本控制、可重现性和审计方面的保障。

来源

任何形式的模型都可以在平台内开发（例如，使用 scikit-learn、TensorFlow 和 OR-tools 等开源工具或自定义库），也可以从外部环境导入（如笔记本、第三方数据科学产品或容器注册表），或配置为外部托管的 API。

建模目标

建模目标 充当针对特定问题的“任务控制中心”，简化模型管理、评估、审查、发布和部署。除了便捷的用户界面之外，建模目标还提供治理与权限层、自动化层（例如对候选模型进行统一评估），以及用于模型持续、零停机部署的 CI/CD 层。

建模目标能够实现完整的 模型生命周期 ，适用于任何建模问题，包括传统上 ML Ops 工具未能解决的问题，例如仿真和优化。

借助建模目标，组织可以超越单纯构建数据管道的范畴，安全地将模型部署到运营环境中，供做出决策的用户和系统使用。模型投入运营后，Foundry 能够基于生产数据、结果、应用和用户操作实现 ML 反馈闭环。这些反馈闭环为建模团队提供了强大的数据资产，可用于监控、理解和改进生产性能，以及适应新情况。

本体论中的模型

本体论是 Palantir 平台的运营层。本体论将数字资产与其在现实世界中的对应实体相连接，从而支持各种不同类型的用例。

一旦模型集成到平台中，即可使用 Modeling Objectives 部署模型，并在本体论层中注册以供使用。这样，运营交互式工作流便可由高可信度模型支撑，从而助力快速、关键的决策。
