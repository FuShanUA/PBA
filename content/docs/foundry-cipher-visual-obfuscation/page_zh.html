使用 Cipher 进行视觉混淆

直方图 视觉混淆 Cipher 中的算法用于对图像的某些部分进行混淆。拥有相应 Cipher 许可证访问权限的用户可以使用解密 Cipher 许可证查看原始图像数据。

Cipher 使用 Cipher 通道的图像加扰种子对多边形中像素的 RGB 值进行加扰，从而对图像进行混淆。该操作是可交换且可逆的。因此，对于已加扰的图像，Cipher 将应用反向加扰来恢复像素的原始值。这不仅仅是叠加层；像素本身会被处理。

此图像是在 “Car Parts and Car Damages” 数据集 ↗ 之上应用 Cipher 的示例，该数据集由 “Humans in the Loop” 在 CC0 许可证下提供。

复现步骤

  1. 设置相关的 Cipher 资源。

    1. 创建一个 Cipher 通道 并附带 视觉混淆 algorithm.
    2. 颁发一个管理员许可证 which 允许加密。向相关管理员用户授予此许可证的访问权限。
      • 注意：视觉混淆目前仅在代码仓库中受支持，因此您需要 授予加密密钥访问权限 在此许可证上。
    3. 颁发一个操作用户许可证 which 允许解密。向操作用户授予此许可证的访问权限。

  2. 设置您的数据。

    1. 将您的图像导入到媒体集中.
      • 注意：视觉混淆目前仅支持 PNG 图像。PNG 是无损格式；因此，加密和解密不会留下压缩伪影。
    2. 创建一个图像类型为 PNG 的输出媒体集。

  3. 对您的图像进行视觉混淆。

    1. 设置一个带有媒体集输入和媒体集输出的 Python 转换.
    2. 使用转换对图像区域进行混淆.

  4. [Beta] 在 Workshop 中使用图像显示小组件与加密图像进行交互。

    1. 将您混淆后的图像支撑到 本体论 对象中，使用管道构建器。
    2. 使用此架构（或等效架构）将您的多边形支撑到另一个本体论对象中：
      • polygonId: 主键
      • imagePath: 字符串；用于关联混淆图像的外键。
      • cipherChannelRid: 字符串；用于加密此多边形的 Cipher 通道的 RID。格式应遵循以下结构： ri.bellaso.main.cipher-channel.<uuid>
      • polygon: 字符串；多边形，以坐标列表表示，经 JSON 序列化。示例： [[0,0][100,0][100,100][0,100]].
      • label: 字符串（可选）；多边形的标签。
    3. 将多边形作为多对一关联关联到混淆图像。
    4. 在 Workshop 应用程序中，使用多边形对象设置图像显示小组件。
    5. 选择所需区域并选择 解密所选区域 以查看原始图像。
