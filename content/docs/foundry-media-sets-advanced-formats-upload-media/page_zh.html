上传媒体

本指南介绍如何创建用于上传媒体的工作流。推荐的方法是设置一个用于上传媒体的操作，并在 Workshop 中使用按钮组小部件调用该操作。请参阅 上传媒体 以了解更多信息。

先决条件

在开始之前，请确保您已具备：

  • 一个带有 媒体引用属性的对象类型。
  • 在您的本体论中创建操作类型的权限。请参阅 本体论权限 以了解更多信息。

第 1 部分：创建带有媒体引用参数的操作类型

首先，您将创建一个操作，允许用户将媒体上传到您的对象类型。

  1. 在 Ontology Manager 中，导航到您的带有媒体引用属性的对象类型。从操作类型部分选择 新建 。



  2. 依次完成对话框中的各个步骤，为操作类型配置规则和参数。





第 2 部分：配置媒体引用参数

在您的操作表单中，导航到 媒体引用 参数部分。支持的渲染选项为 文件选择器 和 文本输入。

  1. 在 显示下，选择 文件选择器 以启用拖放上传。



    您还可以使用开关将媒体引用参数设置为可选或必填。



  2. 选择 表单 布局来执行单个上传。若要一次上传多个媒体文件，可以使用 表格 布局选项。



第 3 部分：将操作添加到 Workshop

保存操作类型后，您可以将其以内联方式添加到 Workshop 应用程序中，或使用 按钮组 小部件。

  1. 在您的 Workshop 应用程序中，添加一个 按钮组小部件。



  2. 选择 操作 （位于 ON CLICK下方），然后选择您创建的操作。



  3. 在 Workshop 中选择该按钮，然后将文件拖放到操作表单或表格中。

有关在 Workshop 应用程序中使用媒体的更多信息，请参阅 在 Workshop 中使用媒体。
