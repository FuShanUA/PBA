临时场景

临时场景仅在当前会话中创建和使用。其元数据不会持久保存在平台中，并且在用户结束当前会话（例如在 Workshop 中）时将被删除。这些场景非常适合快速、即席的"what-if"（假设）分析，在这类分析中，您无需协作或共享结果。它们让您能够试验不同的操作，而不会影响您本体论的状态，也不会让工作区堆满不必要的已保存场景。

Workshop 教程

在本教程中，您将逐步构建一个基本的 Workshop 应用程序来支持临时场景。

第一部分：添加 Scenario Manager 小部件

  1. 在一个新建的空白 Workshop 模块中，导航至 设置 面板（位于左侧导航栏），并确保 场景 设置已在 高级功能 部分中启用。



  2. 在侧边栏部分中，添加一个 场景管理器 小部件。这是 Workshop 中特定于场景的小部件之一，用于创建和管理将在整个模块中使用的临时场景。



  3. 在右侧的小部件设置面板中，配置 动态场景 字段以使用新的动态场景。 创建 按钮将出现在小部件的中央。



第二部分：添加对象表格小部件

  1. 从模块主体中，添加一个 对象表格 小部件。



  2. 您可以使用任何对象集来填充表格，但我们建议从已配置了至少一个关联 操作 的对象类型开始。



  3. 现在，添加一些要在表格中显示的属性。

  4. 在属性下方，启用以下选项： 从场景加载数据 到此小部件中。此选项可有效地使对象表格小部件具备场景感知能力。

  5. 选择由场景管理器小部件生成的场景数组变量。这将使对象表格小部件中的数据反映场景管理器小部件中对场景所做的任何修改，而非原始本体论。



第三部分：添加场景摘要小部件

  1. 要预览您将对场景所做的更改，请将 场景摘要 小部件添加到您的模块中。

  2. 在小部件配置中，连接到由场景管理器小部件生成的活动场景变量。



    此时，尚未对场景应用任何修改；数据应保持不变。

第四部分：配置操作

  1. 添加 按钮组 小部件，以配置要应用于您的场景的操作。



  2. 选择一个可修改表格中对象类型的操作。

  3. 若要将此操作应用于某个场景而非本体论，请启用 应用于场景 选项，并从菜单中选择活动场景变量。



  4. 使用新配置的操作，尝试将表格中任意对象的属性更改为新值。

  5. 在应用该操作之前，要在 Scenario Manager 微件中创建一个新场景，请选择 Create。

第五部分：添加图表小部件

  1. 为了更好地可视化结果，在表格上方添加一个包含 Chart: XY 小部件的分区。



Chart: XY 小部件支持任意数量的场景，不同的场景可以在不同的图层中进行配置。



2. 尝试探索各种图层类型，看看多个场景在其中是如何可视化的。

  1. 您还可以配置 分组 以及其他聚合操作，它们将正确遵循场景值。



第 VI 部分：添加指标卡小部件

  1. 您还可以从场景中为指标卡填充值。添加一个新的 指标卡 小部件。



  2. 您可以配置来自场景的变量值，以在本身不具备场景感知能力的小部件中使用。例如，指标卡小部件没有明确的场景配置区域。取而代之的是，在指标卡配置中创建一个新的数值指标，其值由新的对象集聚合变量定义。



    在变量配置窗格中， 场景 部分允许您添加场景变量。如果选中,聚合将应用场景中的修改后运行。同样,对象属性变量配置也支持场景。



后续步骤

现在您已经创建了第一个场景,我们建议您尝试教程中所用场景专属 Workshop 小组件的各种配置和布局。
