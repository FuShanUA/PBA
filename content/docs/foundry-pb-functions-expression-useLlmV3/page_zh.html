使用 LLM

适用于：Batch、Faster

使用可配置的提示词调用 LLM。

表达式类别： 字符串

已声明的参数

  • 模型： 要使用的 LLM 模型。
    模型
  • 提示词： LLM 模型的用户提示词。媒体项也可以用作提示词。支持图像和 PDF。PDF 在传递给 LLM 之前将被转换为图像列表。如果整个提示词为空或为 null，则输出将为 null。但是，如果提示词中的个别列为 null，它们将被视为 。
    List<Expression<AnyType>>
  • List<Expression<AnyType>> 系统提示词：
    List<Expression<AnyType>>
  • 要传递给 LLM 模型的系统提示词。系统提示词中不支持媒体引用。 List<Expression<AnyType>> 可选
    Enum<Simple, With errors>
  • 输出模式： 选择以简单输出方式进行输出，此时输出即为输出类型参数所指定的类型，错误以 null 形式返回；或者输出一个结构体，以输出（其类型为输出类型）和错误作为字段。 Enum<Simple, With errors>
