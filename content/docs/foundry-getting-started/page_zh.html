Palantir 入门

Palantir 平台旨在帮助您利用数据解决现实世界中的问题。Palantir 平台的使用者包括：

  • 各类组织： 从早期初创公司，到跨国企业，再到世界各地的政府机构。
  • 各类用户： 从 IT 管理员、软件工程师和数据科学家，到护士、技术人员和操作员。

获取访问权限

如果您已准备好开始，但尚未获得 Palantir 平台的访问权限，您可以：

  • 注册 AIP Developer Tier ↗ 以获取平台访问权限，并使用试用账户开始构建。
  • 注册 AIP Bootcamp ↗ 与 Palantir 工程师并肩协作，在数小时或数天内从零实现用例。

开始构建您的用例

获得平台访问权限后，我们建议您参考以下资源，以帮助您开始使用 Palantir 平台：

  • 示例 是一个包含参考示例、教程和入门套件的综合资源库，可帮助您快速开发新应用程序，旨在促进学习和平台的高效使用。
  • Palantir Learning ↗ 门户提供课程、工作流教程、认证等资源，帮助您从平台中获得最大价值。
  • AIP Assist 是一款由大语言模型（LLM）驱动的工具，旨在帮助您浏览和理解 Palantir 平台并利用平台创造价值。您可以在平台内通过界面左下角的专用图标访问 AIP Assist。
  • Solution Designer 是一款交互式工具，用于为 Palantir 平台创建解决方案的架构表示。如果您已经拥有某个 enrollment 的访问权限，可以在以下网址找到 Solution Designer： <your-enrollment-URL>/workspace/solution-design。
