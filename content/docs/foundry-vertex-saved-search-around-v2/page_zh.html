Saved Search Around V2

您的租户可能未启用 Saved Search Around V2。在已启用的情况下，它会取代 V1 周边搜索 面板。如果您无法添加 任意对象类型 步骤到您的 周边搜索 面板，则您的租户使用的是 Saved Search Around V1。如果您没有看到 Stage Query.

从图上的对象运行基本的 Search Around 是探索本体论并将相关对象添加到图中的快捷方式。要创建跨不同对象类型的多步骤、经过筛选的图，请使用 周边搜索 面板。它提供了一个点击式界面，让您在生成新图的同时构建逻辑。然后，您可以将构建的 Search Around 保存为资源，并在其他 Vertex 图和模板中重复使用。与 Saved Search Around V1，您可以：

  • 从多种类型的对象开始，并在每个步骤中匹配多种对象类型。
  • 使用 任意对象类型 步骤作为匹配所有对象类型的通配符。
  • 在每个步骤中遍历多种关联类型，并选择每种关联的方向。
  • 基于对象支撑的关联类型的属性进行筛选。
  • 重复某个步骤或一组步骤，并添加跳过步骤的备选路径。
  • 将 Saved Search Around 打包到 市场产品.

Saved Search Around 的工作原理

Saved Search Around 分两个阶段运行：路径规划，然后是路径执行。规划阶段将您构建的定义转换为具体的查询路径列表。执行阶段针对您的本体论运行这些路径，并将结果添加到图中。

路径规划

查询路径是本体论中一条具体的路线，受 Search Around 中定义的步骤约束。完成 Search Around 的构建后，选择 Stage Query 以在执行前检查查询路径。

在运行任何内容之前，规划可能会失败或返回警告。例如，当 Search Around 超过最大查询深度或查询路径数量时就会发生这种情况。有关更多信息，请参阅 限制.

路径执行

生成计划后，选择您要运行的查询路径，提供任何所需的参数值，然后选择 运行。未选择路径的查询不会运行。每个查询路径分三个阶段运行：

  1. 向前搜索： 从起点开始，一次一步地沿着连接前进，并记录每个探索过的连接。
  2. 向后剪枝： 从最后一步往回处理，移除不会产生有效结果的已探索对象。
  3. 连接关联： 仅返回存活路径上的关联。这些关联会被添加到图中。

每个查询路径的结果会在该路径执行完成后立即添加到图中。剪枝就是为什么后续步骤中的筛选可以缩小先前步骤结果的原因。

您可以 暂停 执行、 恢复 中断的运行，或 重新开始 已完成的运行。返回编辑状态以更改查询。

In 执行选项，启用 在得到结果时暂停执行 以在查询路径找到结果后暂停。这让您可以在继续处理其他路径之前检查结果。

单个查询路径可能会失败。在将图视为完整的关系集合之前，请查看它们的状态以及任何 限制警告 。

定义起始和结束对象

Search Around 中的每个查询路径都从起始块中的一个对象运行到结束块中的一个对象。

起始块： 起始块包含您的起始对象，即当前在图上选中的对象。要更改起始对象，请更改您的选择。起始块会自动更新，并显示每个选中的对象类型及其对象数量。您可以从多种类型的对象开始。

选择 锁定起始对象 以在更改图选择时保留当前输入。解锁后可再次使用图选择作为输入。

结束块： 结束块是 Search Around 中的最后一步，以 结束时间 和旗帜图标标记。当您在其下方添加步骤时，新步骤将成为结束块。您可以像配置其他步骤一样配置结束块，包括对象类型、关联类型、筛选器和交集对象。

当您知道问题的两端时，例如出发机场和到达机场，请先定义起始块和结束块，然后在它们之间添加步骤。 联程航班示例 采用了这种方法，在结束块上使用交集对象以在单个机场结束。

添加步骤

定义起始对象后，您可以通过添加步骤来描述 Search Around 的其余部分。您可以按对象类型、关联类型或两者同时约束每个步骤。

对于每个步骤，选择 对象类型 以精确指定结果中出现的对象类型。要通过本体论中的所有关联对象构建路径，请选择 任意对象类型 来替代。

添加步骤或分区A Runway 步骤，后跟一个 任意对象类型 step

您还可以选择特定的关联类型和关联方向，可以代替对象类型使用，也可以与对象类型一起使用，以进一步约束结果。

筛选结果

如果在步骤中选择了特定的对象类型，您可以通过应用属性筛选器来筛选返回的对象。为此，请选择对象类型旁边的筛选器图标，然后选择要筛选的属性。您可以为步骤中的每个对象类型指定不同的筛选器。一个对象类型上的筛选器不会约束其他对象类型的结果。

同样，您可以按对象支撑的关联类型进行筛选。如果某个步骤使用的关联类型由本体论中的对象支撑，您可以按该支撑对象的属性进行筛选。

将结果限制为特定对象

您还可以通过选择以下选项，将对象类型步骤限制为一组预定义的对象 添加交集对象。这对于诸如“查找从 A 出发且经过 B 的路径”之类的问题非常有用。在下图中，一个 Runway 步骤被限制为五个指定的跑道。 联程航班示例 使用交集对象在单个机场结束搜索。

您可以直接在图上选择交集对象。除非您添加其类型，否则与步骤类型不匹配的对象将被排除。在选择交集对象时，起始对象保持锁定状态。运行查询之前，请检查起始输入。

重复和跳过步骤

默认情况下，Search Around 是线性的：其查询路径从顶部步骤到底部步骤构建。您还可以重复一组步骤，或让某些查询路径跳到结束步骤或另一个中间步骤。为支持这些用例，Saved Search Around V2 提供了多种方法来定义穿过步骤的替代路径。

步骤循环： 步骤循环会将单个步骤重复指定的次数。要使步骤循环产生结果，该步骤必须是 任意对象类型 步骤，或使用具有指向自身的关联的对象类型。以下示例查找起始对象四跳范围内的任何类型的对象。

区块循环： 要重复一组步骤，请创建一个区块。然后，您可以像为步骤循环指定重复次数一样，为该区块指定重复次数。以下示例展示了一个包含两者的区块 Airport 和 Flight 对象。区块让您能够查找重复模式，例如机场到航班再到机场再到航班。要使区块循环产生结果，区块最后一步中的对象类型与第一步中的对象类型之间必须存在关联。

跳过循环： 跳过循环会创建跳过后续步骤的查询路径。要绘制跳过循环，请选择要从中跳出的块，然后绘制一个箭头指向要跳至的步骤。在以下示例中，一个跳过循环从起始块运行到结束块。它添加了一条直接从起始机场到丹佛国际机场的查询路径，与经过 任意对象类型 步骤中丢弃已添加的属性。

参数

参数使 Search Around 可重用，让您无需编辑其步骤即可更改其筛选器中的值。要查看或创建参数，请选择 查看参数 （位于右上角的 周边搜索 面板。要创建参数，请选择 添加参数 并选择一种类型：字符串、数字、布尔值、日期或时间戳。

添加参数后，您可以为其赋值，或选择编辑按钮来更改其名称、描述、默认值以及是否为必填项。每当加载 Search Around 时都会使用默认值。

您可以在任何类型匹配的筛选器字段中使用参数。为此，请选择一个筛选器，打开 参数 选项卡，然后从下拉菜单中选择一个参数。当您更改参数的值时，使用该参数的每个筛选器都会更新为新值。

当 Search Around 具有参数时，您可以在运行时提供参数值，可以在图表中提供，也可以作为 Vertex 模板的一部分提供。例如，当图表嵌入到 Workshop 中时，Workshop 变量可以提供参数值。

保存和加载

要在其他图表或图表模板中重用 Search Around，请将其保存为资源。选择 Search Around 所在选项卡上的下拉菜单，然后选择 保存。在 保存 search around 对话框中，输入 文件名 并选择一个 位置.

在同一对话框中，您可以指定一组起始对象类型。您保存的 Search Around 会显示在 周边搜索 菜单中，适用于所有 Vertex 图中这些类型的对象。

要打开已保存的 Search Around，请选择 + 图标，位于 周边搜索 面板标题中，然后选择 加载 Search Around 并从资源选择器中选择该 Search Around。Search Around 会使用您当前在图上选择的对象作为其起始对象。若要改为启动一个新的空白 Search Around，请选择 创建 Search Around.

在早期版本中保存的 Search Around

如果您的注册中启用了 Saved Search Around V2，您仍然可以打开和使用在 V1 中创建的任何 Search Around。首次打开时，系统会显示一条警告，要求您在再次保存之前验证迁移后的 Search Around 是否正确。在您明确以 V2 格式保存之前，您的 Vertex 图和模板将继续运行 Search Around 的 V1 版本。

如果 V1 筛选器使用的属性或参数无法加载，迁移警告会指出在保存时被丢弃的筛选器。请在保存之前解决这些输入问题或重新创建筛选器。丢弃筛选器可能会返回比原始 Search Around 更多的结果。

V1 Search Around 与 V2 兼容，但有一个例外：

如果范围筛选器的最小值和最大值输入顺序颠倒，V1 会自动交换它们。V2 不会这样做，因此值颠倒的范围筛选器不会返回任何结果。在以 V2 格式保存 V1 Search Around 之前，请检查范围筛选器。

限制

为了保护服务并防止代价高昂的查询，已保存的 Search Around 受以下限制约束。列出的值为默认值，您的注册可能配置了不同的值。

大多数限制不会导致 Search Around 失败。相反，Search Around 会返回部分结果，并附带一条警告，说明达到了哪个限制。如果您看到限制警告，请在运行之前添加筛选器或交集对象、减少循环重复次数，或排除较长的查询路径。

路径规划限制

路径规划仅使用您本体论中的对象类型和关联类型。这些限制取决于 Search Around 的形状，而不是它找到的对象数量。
