自动化历史

自动化历史会跟踪与各个自动化的条件评估和自动化元数据变更相关的事件。

基于自动化条件（如 Automation triggered 和 Automation recovered）的历史保存在用户级别。您只能查看自动化是否为您触发，而无法查看是否为其他用户触发（即使该自动化由您创建）。您可以在下文了解有关 历史可见性 的更多信息。

单个自动化的历史记录显示在单个自动化视图中的 历史 选项卡下。

查看事件详情

选择某个事件以查看完整的执行时间线，包括条件评估详情、效果执行状态、时间戳以及任何错误。

在事件详情视图中，选择单个效果即可打开包含详细跟踪日志的底部面板。您还可以选择触发该效果的对象，以在 Object Explorer 中查看该对象。

历史可见性

历史可见性取决于自动化的 范围模式：

  • 项目范围的自动化： 满足某次运行的标记要求的所有用户均可查看历史记录，从而支持团队协作。
  • 用户范围的自动化： 默认情况下，历史记录仅对所有者可见。启用共享历史可使触发事件对其他用户可见，同时保持效果执行详细信息的私密性。
    • 用户范围自动化的共享历史： 您可以在 Automate 编辑页面上启用共享历史记录。选择 摘要 > 安全设置，选择 用户范围，然后开启 生成共享历史事件。启用共享事件后，您可以通过切换 仅显示我的事件 来仅查看您自己的事件，该开关位于 事件日志 表格顶部，该表格位于 Automate 的 历史记录 页面。

共享事件会表明执行已发生，但效果执行详细信息（包括效果状态、成功/失败、失败消息和效果日志）仍仅对所有者可见。

事件类型

事件描述
Automation triggered当满足自动化条件或阈值条件从 false 变为 true时记录。
Automation recovered当阈值条件从 true 变为 false时记录。只有对象集上的阈值条件才会生成此事件。
Condition edited当任何用户更新自动化条件时记录。
Subscribed当您订阅自动化时记录。未订阅期间的历史记录不会被记录或显示。
Unsubscribed当您取消订阅自动化时记录。未订阅期间的历史记录不会被记录或显示。
Evaluation failed当自动化因任何原因评估失败时记录。在自动化的 历史记录 标签页中查看失败详情。当条件评估成功但通知或操作效果失败时，也可能出现此事件。
Paused当任何用户暂停自动化，或自动化因失败次数过多而自动暂停时记录。已暂停的自动化不会被评估。
Resumed当自动化取消暂停时记录。
Muted当任何用户将自动化静音时记录。静音适用于所有订阅者。被静音的自动化仍会进行评估，但不会触发通知效果或操作效果。
Unmuted当自动化取消静音时记录。静音期结束后，自动化会自动取消静音。

保留

自动化历史记录会保留六个月，之后会被永久删除。若要存储超过六个月的历史记录，请使用操作将数据保存到一个长期存在的对象中，该对象像其他任何对象类型一样受到管理和控制，同样位于 本体论。

数据被删除后，便会从自动化的 历史记录 标签页中移除。

您可以使用 回退效果 将失败消息和错误信息持久化到本体论对象中。这样，无论是执行成功（通过标准操作效果）还是执行失败（通过回退效果），您都可以保留相关数据，且不受保留期限限制。
