标准对象视图

当您在本体论中创建并配置 对象类型 时，Foundry会自动创建一个标准对象视图，为该对象类型下的所有对象提供标准化呈现，确保其他用户能够全面了解该对象类型的架构和关联。标准对象视图与对象类型的配置相匹配，会在专用表格中重点展示突出属性；如果属性的 基础类型 是时间序列、媒体引用或地理空间属性，则会以其他可视化格式展示。普通属性显示在常规表格中，隐藏属性则不可见。

虽然标准对象视图适用于所有对象类型，但您可以创建 已配置视图 ，以便根据任何对象类型在您的本体论中的功能，为其提供情境化且精心策划的对象视图体验。当您创建已配置对象视图时，Foundry会将其设为用户的默认视图；不过，用户也可以选择标准视图，以标准格式查看对象数据。

突出属性的显示

Foundry会将 突出属性 显示在标准对象视图的顶部，以便用户立即了解对象最重要的信息。

显示行为

标记为突出的属性会根据其类型获得增强的视觉呈现：

  • 媒体引用属性： 使用专用媒体查看器渲染，可查看所有受支持的媒体类型。
  • 时间序列属性： 显示为交互式图表，呈现数据随时间变化的模式。
  • 地理空间属性： 具有突出的 geohash、geoshape 或地理时间序列引用 (GTSR) 属性的对象将在 地图上渲染。时间序列属性若 表示对象的纬度和经度随时间变化 ，也会显示在地图上。
  • 其他属性类型： 所有其他突出属性都会以更大的卡片式格式显示，并置于展示其余标准属性的表格上方。

关联对象组件

通过 关联对象 组件，您可以直接遍历 关联对象 ，而无需离开标准对象视图。

使用标准对象视图的 关联对象 组件可以：

  • 查看按关联类型分组的关联对象。
  • 内联预览关联对象的属性，无需离开当前视图。
  • 在新标签页中打开一部分关联对象，以便进一步探索。
  • 在标准对象视图的侧面板中预览选定的关联对象。

标准对象视图在面板形态下的显示行为

您还可以在标准对象视图的 面板 形态中使用其所有功能。
