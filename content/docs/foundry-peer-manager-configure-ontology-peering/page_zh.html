配置本体论对等互连

在您 建立两个空间之间的对等互连关系后，您可以使用 Peer Manager 创建并批准 对象类型 映射，以便通过该连接对其对象进行对等互连。

注意

若要通过对等互连关系同步对象和关联，待对等互连的对象类型必须同时存在于两个注册中，并且其属性必须保持同步。如果属性失去同步，对等互连关系将无法发送新的对象数据，直到恢复同步为止。请使用 Marketplace 在源注册中创建一个 产品 ，该产品包含待对等互连的对象类型，之后再将产品部署到远程注册。当源注册中的对象类型发生架构变更时，远程注册便可以通过该产品配置的 发布渠道接收这些更新。

请先查看 本体论对等互连的核心概念 ，然后再继续操作。

使对象类型可用于对等互连

导航到 Peer Manager，并按照以下说明，在对等连接的 两端 （本地端和远程端）进行操作，以使对象类型可用于对等互连：

  1. 选择相关的对等连接，然后从屏幕顶部选择 本体论 选项卡。
  2. 选择 未映射 标签页，然后再选择 + 添加本体论实体。
  3. 搜索并选择一个或多个要通过该连接使其可用于对等的对象类型，然后再选择 确认选择 以启动 配置对等权限 弹出窗口。
  4. 您可以选择更改 Peer Manager 的默认对等权限状态，该状态允许 同时 导出和导入关联本体论资源的数据。

如果您想要建立单向的对象类型对等关系，即本地空间向远程空间发送对象 而不 接收远程端所做的对象编辑，则可以选择 阻止导入。

  1. 选择 添加本体论实体 以完成将对象类型添加到 未映射 部分，该部分位于 本体论标签页。

创建对象类型映射

当您使对象类型在对等连接的两侧均可用于对等后，接下来即可按照以下说明，从关系的任一侧配置对象类型映射：

  1. 将来自 本地本体论 和 远程本体论 的相应对象类型在 未映射 部分中进行对齐，该部分位于 本体论 标签页。
  2. 选择 + （位于 远程本体论 对象类型右侧）以启动 创建本体论映射 弹出窗口。
  3. 在 Map properties 部分中，映射本地和远程对象类型之间对应的属性。

您无需映射每个属性；但是，必须映射希望通过已建立的连接进行对等的所有属性。

  1. 配置对等关系的 Source data 和 Actions 方向性，请在 Configure peering 部分中进行设置。 了解有关对等关系方向性的更多信息。

  • Source data 是对象类型的基础数据，来源于其支撑数据源，例如 数据集、 虚拟表或 受限视图。是否支持源数据对等取决于支撑数据的类型以及环境类型。 了解有关源数据对等的更多信息。

  • Actions 会根据应用到 Source data上的用户编辑生成数据。在大多数情况下，如果为该对象类型启用了编辑，则应对 Actions 进行双向对等，因此您应确保 同时选中 Export 和 Import 。

  1. 在 Summary 部分中查看该对象类型的配置，然后选择 Submit 以保存映射。

在您点击提交后，Foundry 会立即为您的对象类型实例化对等关系。您可以在 Peer Manager 的 Overview 面板中监控连接的运行状况。
