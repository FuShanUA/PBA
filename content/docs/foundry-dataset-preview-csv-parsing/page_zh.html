CSV 解析

Foundry 支持 CSV 数据集。这些是包含 CSV 格式文件的数据集。

CSV 格式可以使用不同的分隔符、引号字符和转义字符。为了管理这些差异，您可以定义控制 CSV 文件解析方式的参数。这些参数存储在数据集的 schema 中。Foundry 会使用推断功能为给定数据集建议一组合理的参数，但结果应经过验证，必要时进行修改。

Foundry 中的解析

Foundry CSV 数据集通常会将 TextDataFrameReader 定义为其 dataFrameReaderClass （在 schema 中）。这支持一组自定义参数，可以帮助有效处理杂乱的数据。在执行时，这会委托给 Spark CSV DataFrameReader ↗ ，以获得最佳的性能和可靠性。

配置

在 Foundry 中，您可以在任何数据集上查看 schema，方法是在 数据集预览 应用程序中导航到 详情 选项卡并选择 模式。有关 schema 的更多详细信息，请参阅 DataFrame 文档。

CSV schema 可以在 Edit Schema UI 中进行操作，该界面可从 数据集预览 查看预览选项卡时访问。这将有助于直观地了解可用选项以及它们对输出数据集的影响。在 CSV 文件严重格式错误的情况下，您可能需要手动编辑 schema 才能获得所需的输出。

下面描述的 schema 选项仅适用于由 CSV 文件构建的数据集。

Spark CSV 选项

如果您已经熟悉 Spark CSV DataFrameReader，可以配置 dataFrameReaderClass 设置为 DataSourceDataFrameReader 和 format 设置为 csv 菜单中选择 customMetadata.

有关构建自定义主题的示例，请参阅 Spark CSV DataFrameReader 文档 ↗ 以查看支持的选项列表。您可以像这样将配置添加为键值对：
