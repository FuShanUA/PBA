图表模式

Quiver 提供两种视图模式来构建您的分析： 画布 模式和图表模式。在图表模式中，卡片以图表上的节点形式表示，输入和输出通过链接表示。图表采用从左到右的布局，便于追踪数据的流向。

您可以通过屏幕右上角的视图模式切换开关查看当前视图模式并在视图模式之间切换。您可以在 视图模式设置.

紧凑的节点设计

图表上的每个节点都以紧凑的形式显示其标题、标识符和类型。您可以通过节点的 更多操作 菜单或右键单击节点来执行常见操作，例如配置输入、将节点添加到画布或删除节点。这种紧凑的布局使图表保持快速响应，即使对于包含许多卡片的大型分析也是如此。

预览面板

卡片输出显示在屏幕底部的专用预览面板中。选择一个节点即可查看其预览。您可以将预览固定，使其在您浏览图表时保持可见，或者在分屏布局中并排查看两个预览。即使您选择了其他节点，固定的预览仍会保持打开状态，便于比较不同卡片的输出。

图表与画布相互独立

在图表模式中添加的卡片不会自动放置到画布上。您可以随时通过节点的操作菜单将节点添加到画布或从画布中移除，因此您可以先专注于在图表中构建分析，之后再管理画布布局。

在画布模式中，您也可以将卡片从画布上移除而不将其从分析中删除。有关更多详细信息，请查阅画布模式文档中的 删除卡片部分 。

删除卡片

当您删除一个被其他卡片用作输入的卡片时，会弹出一个对话框，提供处理删除的选项：

  • 删除并从下游卡片中移除： 将卡片从分析中完全移除，并将其作为输入从所有下游卡片中分离。依赖卡片中相应的输入配置将被设置为空，这些卡片可能因此进入错误状态。
  • 删除此卡片及其所有后代卡片： 删除该卡片以及所有依赖于它的卡片。这对于一次性移除图表的整个分支非常有用。

在图表上查看卡片

在画布中，您可以通过卡片右上角的 更多操作 菜单中的两个选项之一切换到图表模式来查看卡片依赖关系：

  • 在图表中查看 将视图切换到图表模式，以所选卡片为中心，并显示图表上所有其他卡片的上下文。
  • 在图中查看依赖项 将视图切换到图表模式的 依赖视图，该视图仅显示所选卡片及其依赖项。要再次查看整个图表，请选择 退出依赖关系视图.

依赖关系视图

在大型分析中，可能很难追踪某个特定卡片是如何创建的，或者哪些卡片依赖于它。依赖视图会缩小图表范围，仅显示所选卡片及其上游和下游依赖项。

要进入依赖视图，请右键单击某个节点并选择 查看依赖项。您也可以在画布中选择卡片 在图中查看依赖项 中的 更多操作 菜单中选择复选框来自定义可用的工具。

要退出依赖视图并查看整个图表，请选择 退出依赖关系视图 （位于图表左上角）。

节点交互

您可以通过多种方式与图表上的节点进行交互：

  • 选择 某个节点以将其高亮显示。该卡片的预览将显示在 预览面板.
  • 双击 节点可将其缩放并居中显示在屏幕上，同时在右侧打开卡片编辑器。在适用的情况下， 后续操作菜单 会显示在节点下方。
  • 右键单击 节点可打开上下文菜单，其中包含查看依赖关系、隐藏节点、管理画布布局以及分配颜色分组等操作。
  • 拖动 在处于 选择模式 时，在图表背景上拖动可选择多个节点以进行 批量操作.

从图表中选择输入

在图表模式下配置节点时，您可以直接从图表中选取节点来选择其输入，而无需在列表中搜索。打开节点的卡片编辑器，然后选择输入字段。图表中符合条件的节点会高亮显示，您可以选择其中一个将其设置为输入。这在大型分析中尤为实用，因为滚动下拉列表比直观地选择附近的节点更慢。

批量操作

在处于 选择模式时，您可以通过在图表背景上拖动来选择多个节点。选中后， 图表导航工具栏 中会出现一个工具栏，其中包含以下操作：

  • 节点着色： 将所选节点分配到 颜色分组.

  • 隐藏： 将所选节点从视图中移除，但不会将其从分析中删除。

  • 画布整理： 将所选节点添加到画布、在画布之间移动它们，或将其从画布中移除。

  • 复制到新分析： 创建一个包含所选节点副本的新分析。

  • 复制到现有分析： 将所选节点复制到另一个现有分析中。

  • 删除： 从分析中删除所选节点。

图表导航

您可以通过选择节点并将其拖动到所需位置来调整图表布局。如果您想清理布局并将节点重置到原始位置，请选择 布局节点。您还可以在 在默认的 和 选择模式 之间切换，以控制鼠标交互是移动图表还是选择和取消选择节点。

在图表的左下角，导航按钮允许您放大和缩小、缩放以使所有节点适应屏幕，以及重置图表布局。

您还可以通过在图表背景上上下滚动来放大和缩小。

整理您的图表

随着分析的扩展，您可以使用 颜色组 为相关节点分配颜色，并在视觉上区分图表的不同部分。颜色分组可以折叠为单个节点或隐藏，以减少杂乱。您还可以 隐藏单个节点并对图表进行筛选 （按节点类型、画布、仪表板或函数）。
