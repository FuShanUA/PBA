在转换中使用矢量数据 [旧版]

直方图 geospatial-tools 库不再积极开发；请改用 Pipeline Builder 来加载、转换和处理地理空间数据。本页所述的地理空间数据类型操作功能已被 Pipeline Builder 的地理空间功能所取代。 了解有关 Pipeline Builder 地理空间功能的更多信息。

Geospatial Tools 是一个 Python 库，托管可复用的逻辑，用于在 Foundry 中对矢量地理空间数据管道执行常见转换。此库中提供的函数旨在用于 Python 转换中，以便将这些常见操作与管道其余逻辑的集成流程化。

请注意，此功能已被 Pipeline Builder 的地理空间功能所取代。您应使用 Pipeline Builder 而不是 geospatial-tools 库，因为该 geospatial-tools 库不再维护，可能无法按预期运行。

本页的文档将保留作为参考，直到该 geospatial-tools 库。

该库目前包含以下辅助函数：

  • 清理地理空间数据
  • 空间函数
  • 空间连接

用法

所有使用该 geospatial-tools 库的转换都需要使用 @geospatial() 装饰器（位于任何其他装饰器之上，例如 @transform_df() 和 @configure()）。这将在您的 Spark 环境中启用 Apache Sedona，并添加用于在 PySpark DataFrame 上执行空间连接的绑定。

Copied!
1from transforms.api import transform_df, configure, Input, Output
2from geospatial_tools import geospatial
3
4@geospatial()
5@configure(...)
6@transform_df(...)
7def compute(input_df):
8    ...

清理地理空间数据

Foundry 中干净的地理空间数据应满足：

  1. 表格化，因此数据可以在 Spark 转换中使用
  2. 格式化为有效的 GeoJSON ↗ 或 geohash，因此数据可以在 Foundry 本体论中使用
  3. 使用 EPSG:4326 ↗ CRS 进行投影，以便空间连接的双方使用相同的投影，并且 Foundry 地图能够正确渲染要素。

直方图 geospatial-tools 库提供了 clean_geometry() 和 lat_long_to_geometry() 来执行步骤 (2) 和 (3)。如果您的原始数据是 GeoJSON、Shapefile、GDB、KML 或 KMZ，您可以使用 内置解析辅助函数 来执行步骤 (1)。

clean_geometry()

clean_geometry(geometry, input_crs, geometry_format='geojson', lat_long=False, output_format='geojson')

通过使几何列有效并将其 CRS 规范化为 EPSG:4326 来清理地理空间几何列。

  • 参数
    • geometry (str）：输入几何列的名称。
    • input_crs (str）：输入几何的 CRS。
    • geometry_format (str，可选）：输入几何格式。支持的格式为 geojson, geohash （包含以下内容的字符串 latitude,longitude), wkt日 wkb。默认为 geojson.
    • lat_long (bool，可选）： True 如果输入几何坐标的顺序为 latitude,longitude，对于 geohash 输入很可能是这种情况，但对于 geojson or wkt。默认为 False.
    • output_format (str，可选）：输出几何格式（geojson or geohash）。默认为 geojson.
  • 示例 
    Copied!
    1from transforms.api import transform_df, Input, Output
2from geospatial_tools import geospatial
3from geospatial_tools.functions import clean_geometry
4
5@geospatial()
6@transform_df(
7    Output('/my/output/dataset'),
8    raw_df=Input('/my/input/dataset'),
9)
10def compute(raw_df):
11    clean_df = raw_df.withColumn('geometry', clean_geometry('geometry', 'EPSG:26910'))
12    return clean_df

lat_long_to_geometry()

lat_long_to_geometry(lat, long, input_crs, output_format='geojson')

将经度和纬度列转换为已清理的几何列。

  • 参数
    • lat (str）：输入纬度列的名称。
    • long (str）：输入经度列的名称。
    • input_crs (str）：输入几何的 CRS。
    • output_format (str，可选）：输出几何格式（geojson or geohash）。默认为 geojson.
  • 示例 
    Copied!
    1from transforms.api import transform_df, Input, Output
2from geospatial_tools import geospatial
3from geospatial_tools.functions import lat_long_to_geometry
4
5@geospatial()
6@transform_df(
7    Output('/my/output/dataset'),
8    raw_df=Input('/my/input/dataset'),
9)
10def compute(raw_df):
11    clean_df = raw_df.withColumn('geohash', lat_long_to_geometry('latitude', 'longitude', 'EPSG:26910', output_format='geohash'))
12    return clean_df.drop('latitude', 'longitude')

解析辅助函数

geojson_to_dataframe()

geojson_to_dataframe(dataset, properties=None, glob='*.geojson', batch_size=100000)

将 GeoJSON 文件转换为 dataframe。使用流处理来处理超大文件，而不会耗尽驱动程序内存。

  • 参数
    • dataset (transforms.api.Input）：包含 GeoJSON 文件的输入数据集。
    • properties (list[str]，可选）：要为其创建列的属性列表。如果未提供，所有属性将包含在 JSON "properties" 列中。
    • glob (str，可选）：用于识别数据集中 GeoJSON 文件的 glob 模式。默认为 *.geojson.
    • batch_size (int，可选）：每批次处理的记录数。如果驱动程序内存不足，应减小批次大小。默认值为 100000。
  • 示例 
    Copied!
    1from transforms.api import transform, Input, Output
2from geospatial_tools import geospatial
3from geospatial_tools.parsers import geojson_to_dataframe
4
5@geospatial()
6@transform(
7    output=Output('/my/output/dataset'),
8    raw=Input('/my/input/dataset'),
9)
10def compute(raw, output):
11    return output.write_dataframe(
12        geojson_to_dataframe(raw)
13    )

空间连接

DataFrame.spatial_join()

DataFrame.spatial_join(right_df, on, how='inner', **kwargs)

使用空间交集连接两个 dataframe。

  • 参数
    • right_df (PySpark DataFrame)：连接的右侧。
    • on (tuple<str, str>)：以下内容的元组 (left_geometry_column_name, right_geometry_column_name).
    • how (str，可选)：：连接类型（支持与常规 PySpark 连接相同的连接类型）。默认值为 inner.
    • library (str，可选)：：可以是 h3 or sedona，具体取决于您想要用于执行连接的库。默认值为 h3.
    • resolution (int，可选)：：用于连接的 H3 分辨率（注意：这不会影响结果，仅影响优化）。如果在 library='sedona'时包含此参数，则会引发异常。如果未包含，将推断出一个最佳猜测分辨率。
    • left_partitions (int，可选)：使用时对左侧数据集默认重新分区方案的可选覆盖 library=sedona。使用 H3 时如果包含此参数，将引发异常。

    • left_pk (str，可选)：连接左侧的主键列。如果未设置，将自动生成主键。
    • right_pk (str，可选)：连接右侧的主键列。如果未设置，将自动生成主键。
  • 示例 
    Copied!
    1from transforms.api import transform_df, Input, Output

geopandas_spatial_join()

geopandas_spatial_join(df_left, df_right, geometry_left, geometry_right, how='inner', op='intersects')

计算两个 Geopandas 数据集的空间连接。实现 Geopandas 的 'sjoin' 方法。要求两个数据集都包含 GeoJSON 几何列，其名称作为 geometry_left 和 geometry_right 参数传入。

  • 对于大规模数据，请使用 DataFrame.spatial_join 上文所述的函数。
  • 参数
    • df_left (pandas.DataFrame ↗)：左侧输入数据集。
    • df_right (pandas.DataFrame ↗)：右侧输入数据集。
    • geometry_left (str)：左侧数据集几何列的名称。
    • geometry_right (str)：右侧数据集几何列的名称。
    • how (str，可选)：连接类型，取值为 {left, right, inner}。默认值为 inner.
    • op (str，可选)：连接条件，取值为 {intersects, contains, within}。默认值为 intersects.
  • 示例 
    Copied!
    1from transforms.api import transform, Input, Output
2from geospatial_tools.spatial_joins import geopandas_spatial_join
3
4@transform(
5    output=Output('/my/output/dataset'),
6    input_df_left=Input('/my/input/dataset/left'),
7    input_df_right=Input('/my/input/dataset/right'),
8)
9def join(ctx, output, input_df_left, input_df_right):
10  df_left = input_df_left.dataframe().toPandas()
11  df_right = input_df_right.dataframe().toPandas()
12  geometry_left = 'geometry'
13  geometry_right = 'geometry'
14
15  joined = geopandas_spatial_join(
16        df_left,
17        df_right,
18        geometry_left,
19        geometry_right,
20        how='inner',
21        op='intersects'
22    )
23    joined = ctx.spark_session.createDataFrame(joined)
24    output.write_dataframe(joined)
