布局

有多种内置的图节点着色选项，可为您提供更多有关管道的信息：

着色选项描述
无颜色将完全移除着色
自定义颜色允许您选择节点并通过点击 颜色 button
数据目录根据节点所属的 Data Catalog 集合为其着色。如果节点属于多个集合，则会被着色为“属于多个集合”
文件夹根据资源所在文件夹的名称为节点着色
问题根据分配给节点的 Foundry issue 数量为节点着色。此选项还允许您按 issue 标签进行筛选。
权限根据用户对数据或资源的访问级别为节点着色。如果您有权访问图中的资源，此视图还允许您选择任意 Foundry 用户并查看其权限。
项目根据节点所属的 Foundry Project 为其着色。
仓库根据用于创建节点的代码仓库为节点着色。您可以按仓库名称或仓库类型（例如 Code Repository、Code Workbook）为节点着色。
资源概览此视图根据资源的详细信息为节点着色。资源的详细信息通常指资源的创建方式（例如在 Contour、Code Workbook、Fusion 电子表格同步中创建，或通过上传创建等）。
资源类型根据 Foundry 资源类型为节点着色。
构建状态指示图中每个数据集的当前构建状态。如果节点已分组，则显示较严重的状态。
数据健康指示资源健康检查的状态，并支持仅筛选已关注的健康检查。如果节点已分组，则组的颜色指示该组中最严重的健康检查状态。
已过时此选项指示数据或逻辑相对于数据集祖先是否已过时。
相对于父级已过时 表示资源的直接父级已更新，而资源本身尚未相应更新。
相对于祖先已过时 表示资源与其直接父级保持同步，但上游存在已更新的资源。此选项允许您筛选两种类型的更新：数据和逻辑。
数据已过时 表示数据在某个祖先中已更新，而资源尚未在构建中获取该更新。
逻辑已过时 表示 job-specs 已更改。
计划数量指示数据集上设置的构建计划数量，并可选择筛选掉已暂停的计划。
同步状态如果数据集上设置了同步，此选项将指示同步的状态
上次构建时间指示自数据集上次成功构建以来经过的时间。
构建时长根据每个资源最近一次成功构建，此选项将指示大致的构建时长
文件根据与文件相关的指标为图中的节点着色：平均文件大小、文件数量和数据集大小
行数统计根据每个数据集中的行数为节点着色。如果行数不存在，可以在数据集详情辅助工具或 Foundry 的数据集视图（数据集应用）中计算。
Spark 使用情况根据给定时间段内的 Executor 运行/CPU 时间为每个节点着色
用户浏览量根据过去四周的用户浏览总次数为节点着色
分支指示图中每个节点当前查看的分支。
代码状态指示此节点/数据集的代码状态。
CI 运行中 表示此节点的 CI 检查当前正在运行。
CI 失败 表示此节点的 CI 检查失败。
已过期 表示此节点的代码已过期。
不可用 表示该节点/数据集不是 stemma 后端，或者用户缺少权限。
存储指示数据的存储位置。将是 Foundry 除非您正在使用 虚拟表.
计算指示图中每个节点所使用的计算引擎。对于在 Foundry 中运行的转换，这将显示所使用的计算类型（例如 Spark 或 Flink）。对于使用计算下推的转换，这将指示所使用的外部计算引擎（例如 BigQuery、Databricks 或 Snowflake）。
事务类型指示每个节点的事务类型：追加或快照
