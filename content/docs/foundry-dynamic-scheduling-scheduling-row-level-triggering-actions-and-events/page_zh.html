在行上触发操作和事件

本体论操作使您能够在本体论中创建、修改和删除对象。Workshop 事件使您能够触发弹出窗口、切换分区、切换选项卡、更新变量值等。在每一行上，您都可以配置可由最终用户触发的操作和事件。

操作和事件可通过以下方式触发：

  • 行右键菜单
  • “选择行时”事件

行右键菜单

可在以下位置配置行级右键菜单： 行配置 > 右键菜单。可以通过拖动菜单项来重新排列菜单选项。可用的右键菜单选项将在以下各节中详细介绍：

  • 操作类型
  • Workshop 事件

操作类型

常见用途：

  • 编辑行对象上的属性；
  • 在甘特图中右键单击的时间点创建一个新对象。
  1. 为此菜单选项提供自定义名称。
  2. 选择要在单击时触发的任意本体论操作类型。此操作可以与 resource object type 相关，但并非必需。
  3. 使用 Workshop 变量或调度甘特图特定变量预填充操作类型的参数：
    • 资源对象： 自动使用您右键单击的行对象填充。
    • 选定的开始时间戳： 自动填充您右键单击的行中位置的时间戳。在行中的空白区域右键单击时非常有用。

Workshop 事件

常见用途：

  • 触发弹出框以显示所选行的更多详细信息
  • 打开另一个 Workshop 应用程序或页面，并将所选行预先填充为输入。
  1. 为此菜单选项提供自定义名称。
  2. 选择单击时要触发的 Workshop 事件。通常使用甘特图的选定内容输出变量作为对所选行的引用。

“行选择时”事件

“行选择时”事件可在配置中右键菜单的下方进行配置。启用后，当用户选择（单击）行标题时，将触发这些事件。事件可以是任何 Workshop 事件。
