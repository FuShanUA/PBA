将 OSDK 包添加到现有应用程序

本页将引导您完成向现有应用程序添加 OSDK 包的过程。如果您还没有应用程序，请参阅 初始化新 OSDK 应用程序。

本指南介绍如何将 OSDK 添加到使用公共 OAuth 的面向客户端的应用程序。对于使用服务用户的后端服务，请参阅 使用服务用户初始化新 OSDK TypeScript 应用程序。

1：前提条件

创建 Developer Console 应用程序

请按照 创建新的 Developer Console 应用程序 页面中列出的步骤操作。

设置令牌

在本地环境中导出您的令牌。下面的示例使用了一个样例个人访问令牌，但您可以在 Developer Console 中生成有效期更长的令牌。由于这是您的个人访问令牌，因此不应将其提交到源代码管理中。

Copied!
1
export FOUNDRY_TOKEN=<YOUR-TOKEN-FROM-GETTING-STARTED-PAGE>

检查 Node 版本

Typescript SDK 需要 Node 18 或更高版本才能正常运行。要查看您当前使用的 Node 版本，请使用以下命令。

Copied!
1
node --version

2：将 OSDK 添加到现有项目

设置 NPM 注册表

将以下代码添加到您的仓库或用户 .npmrc 文件中，并将任何 < > 替换为特定于应用程序的值：

//<REGISTRY-URL-FROM-OVERVIEW-PAGE>:_authToken=${FOUNDRY_TOKEN}
<PACKAGE-NAME>:registry=https://<REGISTRY-URL-FROM-OVERVIEW-PAGE>

如果在安装软件包时遇到 404 错误，可能是 npm 使用了其他注册表而非 Foundry 注册表。请检查并移除任何可能覆盖现有设置的 npm 注册表配置：

  1. 运行 npm config delete registry 以移除任何可能覆盖您项目设置的全局 npm 注册表配置。
  2. 请确保没有其他 .npmrc 文件在您的项目或用户目录中设置了不同的注册表 URL。
  3. 请确认您 .npmrc 中的注册表 URL 与 Developer Console 中该 SDK 的 概览 页面上的 URL 一致。
  4. 请确保 FOUNDRY_TOKEN 环境变量已设置为有效的令牌。

可选：设置证书

如果您的组织要求网络流量使用证书，您可能需要告知 Node 该证书的存放位置。

Copied!
1
export NODE_EXTRA_CA_CERTS="/path/to/my.crt"

import { createPublicOauthClient } from "@osdk/oauth";
import { createClient } from "@osdk/client";
import { <ANY-OBJECT-NAME> } from "<PACKAGE-NAME>";
import React, { useEffect } from "react";

const auth = createPublicOauthClient("<YOUR-CLIENT-ID>", "<YOUR-FOUNDRY-URL>", "<YOUR-REDIRECT-URL>");
const client: Client = createClient("<YOUR-FOUNDRY-URL>", "<YOUR-ONTOLOGY-RID>", auth);

export default function SimpleReactComponent() {
    useEffect(() => {
        if (auth.getTokenOrUndefined()) {
            auth.refresh().catch(() =>
            /**
               If we cannot refresh the token (for example, if the user is not logged in) we initiate the login flow in Foundry
               Once login is complete, the user will be redirected back to http://localhost:8080/auth/callback
            **/
            auth.signIn())
        } else {
            client(<ANY-OBJECT-NAME>).fetchPage({ $pageSize: 10 }).then((object) => {
                console.log(object.data);
            });
        }
    }, []);
};

使用 OSDK React 软件包（可选）

如果您的应用程序使用 React，您可以使用以下库：

@osdk/react

使用 @osdk/react 来获得类型化钩子、共享缓存、操作、函数以及自定义的数据驱动界面。

安装最新版本的 @osdk/react：

Copied!
1
npm install @osdk/react@latest

@osdk/react-components

使用 @osdk/react-components 来获取预构建的、感知本体论的界面元素。该库基于 @osdk/react。

安装最新版本的 @osdk/react-components:

Copied!
1
npm install @osdk/react-components@latest
