SQL

SQL 是一种在线提供大量外部文档的语言。以下是使用 SQL 编写数据转换的一些主要优势：

  • SQL 是性能最高的语言（包括大多数 Spark 优化）。
  • Transforms SQL 为您提供了一个 SQL 草稿板，允许您运行示例 SQL 查询以检查您的 SQL 语法。

了解更多关于 SQL Transforms 的信息。

或

Python 是一种在线提供大量外部文档的语言。您可能希望使用 Python 编写数据转换，以便利用 Python 特有的功能和库。Python API 比其他语言（如 SQL）更底层。以下是使用 Python 的一些主要优势：

  • 直方图 transforms Python 库 是一个公开文件读写等功能的 API。当您想要解析和清理数据时，基于文件的数据转换在数据转换管道的早期阶段非常有用。
  • 对使用外部库（如 pandas、NumPy 和其他机器学习库）提供一流支持。
  • 您可以访问完整的 Spark Python (PySpark) API，其中包含其他语言不支持的 Spark 附加功能。

了解更多关于 Python Transforms 的信息。
