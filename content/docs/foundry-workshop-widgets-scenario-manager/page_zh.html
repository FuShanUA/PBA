小工具：Scenario Manager

直方图 Scenario Manager 小工具允许用户在 Workshop 模块中以交互方式创建和管理场景。配置 Scenario Manager 小工具的模块构建者可以：

  • 将 Scenario Manager 包含在模块中，使模块用户能够创建、编辑和删除场景。

下面的截图展示了在对象表的信用“余额”列中并排比较多个场景的示例。场景 1 显示了由操作修改后的“余额”，而场景 2 显示了本体论中的默认值。用户可以在 Scenario Manager 中在这两个场景之间进行选择。

配置选项

对于 Scenario Manager 小工具，核心配置选项如下：

  • 输入数据
    • 静态场景： 包含在管理器列表中但用户无法直接追加或删除的场景。这在包含来自对象集的已保存场景时特别有用。
    • 动态场景： 包含用户在使用模块时创建的场景的场景数组变量。如果某个场景同时出现在静态和动态列表中，则它将从动态列表中移除。
    • 活动场景： 此场景变量将保存管理器中当前选定的场景。该变量可用作其他小工具的输入，以应用操作或显示所选场景的结果。
  • 模型选项
    • 显示名称： 为您的模型提供显示名称。
    • 模型： 选择要与您的场景关联的相关模型。
    • 域： 提供模型/场景计算应在其上执行的域。
