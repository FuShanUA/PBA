模块接口

模块接口是一组变量，当 嵌入式时，这些变量可以映射到父模块中的变量，并从 URL 初始化。您可以将模块接口视为 Workshop 模块的 API。

模块接口变量与 本体论接口不同，后者定义跨对象类型的共享属性和关联。模块接口变量定义 Workshop 模块用于嵌入和 URL 初始化的输入和输出。

要将变量添加到模块接口，请导航到该变量的 设置 面板，添加外部 ID，并确保模块接口的开关已启用。您还可以为模块接口变量指定显示名称和描述，当模块被嵌入或在 打开 Workshop 模块事件.

嵌入模块接口

中使用时，这些信息将会显示。嵌入模块时，该模块的模块接口变量可用于将父模块变量映射到子模块接口变量。当接口变量在父模块和嵌入的子模块之间建立映射时，Workshop 使用父模块的变量定义，并忽略嵌入模块自身的接口变量定义。您可以在 接口配置 嵌入模块文档中了解更多相关内容。

使用模块接口变量在父模块和子模块之间或在同级嵌入模块之间进行通信。这些共享的接口变量可以支撑共享状态，例如选定的对象、选定的选项卡或是否显示叠加层。有关使用变量控制布局状态的更多详细信息，请参阅 变量支撑的布局。嵌入模块可以通过事件修改接口变量的值，从而使引用这些变量的其他位置能够响应更新后的值。详情请参阅 跨嵌入模块通信.

打开 Workshop 模块事件

打开 Workshop 模块事件可用于避免手动创建 URL，如下所述。所选模块的接口将会显示，允许将变量值从当前模块传递到所选模块的接口变量。当事件被调用时，URL 会使用当前值打开所选模块。

在编辑模式下，当您从模块引用打开一个模块时（例如，在独立的编辑器中打开嵌入的子模块），该模块将使用从源模块传递过来的任何模块接口变量的当前值打开。这使您能够使用引用该模块时存在的相同状态来调试打开的模块。

使用模块接口变量创建 URL

除了打开 Workshop 模块事件之外，还可以手动动态生成 URL，以便使用模块接口变量的 URL 查询参数值共享指向应用程序状态的自定义链接。为此，请按照以下步骤操作：

  1. 登录您的 Workshop 应用。
  2. 从浏览器复制 URL。请确保处于查看模式而非编辑模式。此 URL 是固定的，因此您可以与拥有正确权限的其他用户共享。
  3. 现在，返回编辑模式。
  4. 选择 变量 菜单位于左侧边栏中。
  5. 创建一个 New variable > String > Static.
  6. 转到变量 设置 选项卡，并添加外部 ID。
  7. 将 ? 追加到步骤 2 中的 URL 后面，然后是外部 ID、 =以及您想要设置的值。例如， ?interfaceVariable=123。您可以通过添加与符号 & 后跟额外的外部 ID、等号 = 和值的方式来添加其他模块接口变量。

模块接口变量在模块首次加载时从 URL 参数初始化。模块加载后更改 URL 不会动态更新变量值。要在运行时更新变量值，请使用 Workshop 事件，例如 的选项卡将成为所选选项卡，在平局的情况下优先选择最早的选项卡。 事件或 模块加载时 事件。

链接现已可以使用，并将模块接口变量定义为 URL 中设置的值。此链接可以通过使用 变量转换动态生成，其值来自操作表单、函数或其他变量转换。

出于测试目的，您可以更改 /latest/ to /dev/ URL 中的值，链接将重定向到 Workshop 应用程序的最后保存版本，而不是最后发布版本。
