事件

Workshop 模块中的事件使您能够在用户执行给定操作时触发特定行为。事件可以从许多组件触发，包括 按钮组, 对象表格 在选择行时、 String Dropdown 在选择或取消选择时，以及 选项卡 组件。请在我们的 事件触发和导航组件 文档中了解更多信息。可用事件的完整列表记录如下，但可用的事件类型可能因组件而异。

事件执行顺序

Workshop 中的事件按其配置顺序依次执行。要重新排序组件上的两个或多个事件，请在配置面板中上下拖动事件卡片。事件不会等待先前事件的依赖计算完成后再执行。

关键行为

当 的选项卡将成为所选选项卡，在平局的情况下优先选择最早的选项卡。 事件触发时：

  • 源变量值会立即复制到目标变量值。
  • 当下一个配置的事件执行时，目标变量值将是最新的。
  • 在下一个配置的事件执行之前，依赖于目标变量的下游变量不会是最新的。

对于其他更新变量值的事件类型，此行为类似。

局限性

Workshop 不支持强制事件等待所有下游更新完成后再继续执行下一个事件。

如果您的工作流需要在事件之间完整传播下游更新，请将事件拆分为多个由用户触发的事件。这样可以在触发下一个事件之前完成下游计算。

展开/折叠/切换 {section name}

对于模块中的每个可折叠区域，可以使用以下三个事件：

  • 展开： 展开事件名称中指定的区域。
  • 折叠： 折叠事件名称中指定的区域。
  • 切换： 如果事件名称中指定的区域当前处于折叠状态，则展开该区域；如果当前处于展开状态，则折叠该区域。

如果指定区域有一个支撑折叠状态的布尔变量，则此变量的值不会因这些事件之一而更新。如果您希望此变量值与该区域的折叠状态保持同步，可以使用 设置变量值 事件。

变量

变量 事件为应用构建者提供了在 Workshop 模块中更改变量值的方法。

重置 {variable name} 值

重置 {variable name} 值 事件会将所选变量的值设置为其默认值，即在变量定义中配置的值。此选项适用于静态变量。

重新计算 {variable name}

重新计算 {variable name} 事件将根据所选变量的输入值和变量定义重新计算其值。此选项适用于非静态变量类型，对于管理没有 Automatic 重新计算行为的变量的重新计算特别有用。

配置选项
  • 目标变量： 用于流式传输响应的字符串变量。
  • 提示词： 发送给 LLM 的提示。可以是字符串变量或返回字符串的函数。

AIP Assist

直方图 Send to AIP Assist 事件提供了一种将提示作为静态文本或字符串变量发送到 AIP Assist 并自动运行查询的方法。当此事件被触发时，AIP Assist 侧边栏将自动打开（如果尚未打开）。为了进一步定制用户体验，构建者还可以提供默认聊天机器人——一种由 LLM 驱动、配备企业特定知识的助手——来回答有关自定义运营主题的查询。AIP Assist 聊天机器人使用自定义内容作为其搜索上下文，并且可以在 Chatbot Studio （前身为 Agent Studio）[Beta] 中进行配置。

在事件配置过程中可以选择默认的 AIP Assist 聊天机器人，使构建者能够针对给定上下文选择合适的聊天机器人。聊天机器人可以被授予访问自定义内容的权限，例如有关所使用应用程序的文档或其他操作流程，以便在相关时机提供有针对性的帮助。选择聊天机器人是可选的，用户也可以在 AIP Assist 侧边栏中选择专用聊天机器人。通过选择默认聊天机器人，构建者可以确保为任务选择了正确的聊天机器人，而无需依赖最终用户进行手动选择。事件中发送的提示可以是静态文本或动态变量，使构建者能够根据提示和接收代理自行定制用户体验。

  4. 选择 +添加事件 ，然后选择 发送至 AIP Assist 从选项列表中。

  5. 通过选择提示词应为 选项。 文本还是计算值来配置事件 变量.

    • 静态： 对于此选项，只需输入提示词文本。当按钮被选中时，该文本将作为提示词发送到 AIP Assist。例如：“库存管理应用使用什么阈值来决定何时创建‘低库存警报’？”
    • 选择此资源模式时，输入资源由一个字符串变量提供，该变量应包含图、图指针或图模板的 RID。 对于此选项，您必须 配置一个字符串类型的变量 以用于 Send to AIP Assist 事件，并使用 选择变量 dropdown.

模块状态

模块状态事件允许用户在其会话期间控制某些模块级别的行为。

启用或禁用自动刷新更新

您可以通过配置 Workshop 事件（例如通过按钮组组件）让用户在会话期间暂停或恢复自动刷新更新的应用：

  • 启用自动刷新更新： 允许自动刷新的更新生效。
  • 禁用自动刷新更新： 阻止自动刷新的更新生效。
