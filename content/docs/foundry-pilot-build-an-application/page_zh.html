构建应用程序

本页面将引导您完成 Pilot 应用程序的构建生命周期，从本体论生成到种子数据。如需创建新的应用程序，请参阅 快速入门。如需部署到生产环境，请参阅 部署应用程序。

如果您要构建的是自定义组件而非应用程序，请参阅 构建自定义组件。

本体论生成

在您描述应用程序后，Pilot 会分析您的提示词，并使用本体论架构师智能体为您的应用程序创建数据模型。Pilot 会根据您的提示词创建以下资源：

  • 对象类型 ，用于表示应用程序中的核心实体。例如，任务管理应用程序可能包含 Task、 Project以及 Team Member 等带有相关属性的对象类型。
  • 操作类型 ，用于您的工作流。例如， Create Task、 Update Task Status、 Assign Task以及 Delete Task。
  • 关联类型 ，用于定义对象类型之间的关系。例如， Task 与 Project 之间的关联，用于表明某个任务所属的项目。

本体论架构师会在聊天面板中记录设计决策，并解释每个实体背后的理由。您可以切换到 本体论 选项卡来查看生成的本体论图。有关本体论图的更多详细信息，请参阅 本体论选项卡 文档。

要完善本体论，请在聊天面板中输入指令。例如，你可以让 Pilot 添加新属性、更改属性类型，或在对象类型之间创建新的关系。

如果你将现有的本体论实体作为上下文附加，Pilot 将使用这些实体，而不是创建重复项。参见 提供上下文和附件 以了解详情。

设计规范

本体论定义完成后，设计代理将为你的应用程序创建详细的设计规范。设计代理会读取本体论和你的需求，然后生成包含以下内容的设计规范：

  • 调色板和语义状态颜色
  • 排版，包括字体系列、字号和行高
  • 应用程序主视图的布局
  • 表单设计和交互模式，例如悬停状态、动画和验证反馈

你可以在聊天面板中查看设计规范的摘要。设计规范将指导后续的前端生成。

前端生成

应用构建代理使用本体论和设计规范实现前端。该代理执行以下任务：

  • 读取设计规范、本体论定义和 OSDK 文档
  • 构建一个使用 OSDK hooks 进行实时数据加载和变更的 React 应用程序
  • 生成用于创建、更新、筛选和删除记录的组件

当智能体完成后， 预览 标签页会显示应用在容器中运行的实时预览。您可以与预览交互以测试功能，而 设备选择器 则可让您以不同的屏幕尺寸预览应用。

种子数据

在编辑器视图中，Pilot 会在容器中生成种子数据，从而确保 AI 智能体绝不会访问真实的企业数据。这样可以防止 Pilot 将生产环境的值硬编码到您的应用代码中。您可以在 本体论 标签页中查看生成的记录，方法是选择一个对象类型节点并打开数据预览面板。详情请参阅 本体论标签页 文档。

要使用真实的本体论数据验证您的应用，请切换到 部署 视图。在部署分支上，本体论架构的更改仅限于该分支，不会影响 Main ，直到您合并。在 Main上，应用中执行的任何操作都是对本体论的实时编辑。详情请参阅 部署应用。

迭代您的应用

初始构建完成后，您可以通过后续提示词来完善您的应用。

  • 添加功能： 描述新功能，Pilot 会根据需要更新本体论、设计和代码。
  • 修复问题： 如果预览显示意外行为，请描述问题，Pilot 会进行调查并应用修复。
  • 更改设计： 请求更改颜色、布局或排版，设计代理会更新规范。
  • 上传参考资料： 附加文档、图像或线框图以引导 Pilot。参见 提供上下文和附件。
  • 直接编辑代码： 代码标签页提供了一个嵌入式编辑器，您可以在其中直接对应用程序源代码进行更改。
  • 切换模型或模式： 使用不同的 AI 模型，或根据任务在行动模式和规划模式之间切换。参见 模型和代理模式 以获取更多信息。

如果您在 预览 标签页中遇到构建错误，可以选择 使用 Pilot 修复 ，以提示 Pilot 自动诊断并解决该问题。
