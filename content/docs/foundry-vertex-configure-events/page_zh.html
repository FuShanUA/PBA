配置事件

在 Vertex 中，事件是一种 对象类型 的对象，表示在一段时间内发生的事情。示例包括设备警报、维护窗口或运输延迟。要为事件配置对象类型，该对象类型必须具有记录每个事件开始和结束时间的时间戳属性。事件与 时间序列属性不同，后者存储随时间变化的测量值；请参阅 事件和时间序列 的文档以获取更多信息。

要为事件配置对象类型，请打开其 功能 在 Ontology Manager 中的选项卡，并启用 事件 开关。将时间戳属性分配给 事件开始时间 和 事件结束时间，还可以选择设置 描述 和 关联对象，然后选择 保存.

Ontology Manager 会将这些分配保存为事件元数据，并使用主键作为事件标识符。Vertex 会优先使用指定的开始时间、结束时间和描述属性，而不是相应的旧版类型类。

事件时间筛选需要同时指定开始属性和结束属性。单个事件可以具有空的结束值；筛选器会将该事件视为开放式。空值与未配置结束属性的对象类型是不同的。

旧版类型类

没有事件元数据的对象类型仍可以使用以下属性类型类。下面的表示法结合了 种类 (timeseries），并 名称 值；请参阅 类型类参考 了解详情：

类型类属性
timeseries.event_id事件标识符，通常是主键。
timeseries.event_start_time事件开始的时间戳。
timeseries.event_end_time事件结束的时间戳。该属性必须被指定，但单个事件的值可以为空。
timeseries.event_descriptionVertex 的可选字符串描述。

使用 Vertex 无需移除现有配置。请使用 事件 本页顶部所述的功能控件，在 Ontology Manager 中配置或更新这些分配。

事件颜色和严重性

添加 Vertex 类型类以设置事件颜色或严重性。您可以将其放置在任何属性上，通常是主键：

  • 橙色： kind: vertex, name: event_intent.warning
  • 红色： kind: vertex, name: event_intent.danger
  • 蓝色： kind: vertex, name: event_intent.primary
  • 绿色： kind: vertex, name: event_intent.success

您可以在 Ontology Manager 中的事件对象的 功能 在 Ontology Manager 中事件对象的选项卡，或直接在对象属性的类型类中。
