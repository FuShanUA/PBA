为首次部署做好准备

Beta

SuperRepo 目前处于 beta 开发阶段，可能无法在您的 enrollment 上使用。功能在持续开发期间可能会发生变化。

SuperRepo 部署基于 Foundry Marketplace。您的 SuperRepo 会编译为一个原生 Marketplace 产品，您可以在 enrollment 上使用 Foundry CLI来安装它。

您可以从任何位置进行部署，具体取决于您的 SuperRepo 源代码所在的位置：通过 Foundry CI (Jemma) 从 Palantir 平台部署、从您自己的计算机部署，或从任何 CI 系统部署。

第 1 步：配置部署

配置部署目标并映射所需的输入，例如目标命名空间、 Project和网站域名。

在您的 SuperRepo 根目录下运行 foundry deploy configure 。该命令会以交互方式引导您完成配置。

完成后，它会将 env.yml 写入您的仓库根目录。此文件保存您的部署配置，并在每次后续部署中重复使用。

提交 env.yml 到您的仓库。当您通过标签部署时，Foundry CI 会读取该文件，详见 从 Palantir 平台部署。

若要稍后更改任何输入，请重新运行 foundry deploy configure 。

第 2 步：部署

在成功配置部署并获得您的 env.yml 文件后，您就可以将产品部署到您的 Foundry enrollment。

从 Palantir 平台部署

如果您的源代码托管在 Palantir 平台内，请为您的 SuperRepo 仓库添加标签，其余工作将由 Foundry CI 处理。

  1. 在平台内置的 VS Code 编辑器中打开您的仓库。
  2. 选择 为版本添加标签 （位于右上角）。
  3. 输入标签名称，然后选择 创建标签。

创建标签会触发部署作业。要跟踪其进度，请打开 标签 选项卡，并选择 检查 列中的条目。

从 Palantir 平台外部部署

要从 Foundry CI 外部部署， FOUNDRY_TOKEN 环境变量必须设置为具有 Foundry DevOps 发布权限的令牌。请参阅 使用 Foundry 进行身份验证 ，以了解 CLI 如何读取此变量。

如果您的源代码托管在其他位置，请从您的终端或任何 CI 系统进行构建和部署：

第 3 步：验证您的安装

部署步骤成功后，您可以在 Marketplace中查看您的安装。

如果您有一个 本体论 SDK React 应用程序，则还需完成两个步骤，您的应用程序才可供访问。打开您已安装的 Developer Console 应用程序，然后：

  1. 在 网站托管 > 网站域名下，请确认您的网站域名已获批准。
  2. 在 网站托管 > 资源，确认最新资产已部署。如果尚未部署，请选择您的版本旁边的选项菜单，然后选择 部署到生产环境。
