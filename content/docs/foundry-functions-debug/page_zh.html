调试函数

以下文档专用于 TypeScript v1 函数。如需更 强大的功能（包括对本体论 SDK 和可配置资源请求的支持），我们建议 迁移到 TypeScript v2。

在编写函数时，您可能需要检查执行状态，以解决代码正确性或性能方面的问题。以下是可用于此目的的功能。请注意，这些调试步骤也适用于 单元测试。

创作调试器

使用代码仓库中的调试器工具来检查单元测试运行时的行为。设置断点以暂停单元测试的执行，以便检查变量并理解函数和库。

设置断点

要使用调试器，您需要设置断点。这些断点指示了调试器应暂停代码执行的具体位置，使您能够与变量进行交互。

通过选择每行代码边距处的淡红色圆点来设置断点。调试器会 在 所标记的行运行之前暂停执行。如有需要，您可以在多个文件中设置多个断点。

运行调试器

在实时预览期间

在代码中添加断点后，选择 运行和调试，位于函数面板中。

在测试期间

在代码中添加断点后，选择 运行测试，位于代码编辑器中单元测试的旁边。

使用调试器

调试器启动后，调试器面板将打开，并在遇到的第一个断点处暂停。调试器左侧栏可用于导航代码、删除断点，以及完成或停止调试会话。

在导航代码时，编辑器会高亮显示将要执行的下一行代码。使用以下按钮推进调试器：

  1. 恢复执行： 继续执行，直至完成或在下一个断点处暂停。
  2. 单步跳过： 执行该行代码，而不进入内部函数。
  3. 单步进入： 如果该行代码中存在内部函数，则进入该内部函数。
  4. 单步跳出： 跳出内部函数并推进调试器。
  5. 停止执行： 完全停止调试器。
  6. 删除断点： 从仓库中删除所有断点，并在不暂停执行的情况下运行单元测试。
  7. 设置： 打开/关闭调试器（不清除断点）。
  8. 文档： 打开文档以了解更多详细信息。

检查变量

调试器运行时，您可以在代码执行的确切位置检查变量和数据。

帧

帧表示调试器当前处于活动状态的函数或存在断点的函数。每个帧都显示函数名称，后跟该函数所在的文件名称和行号。

选择某个帧以检查该帧内的变量，并对其运行控制台命令。

变量

变量部分显示执行转换时局部变量和全局变量中存储的值。

控制台

控制台允许您在运行调试器时使用 JavaScript 控制台命令与数据进行交互。

请注意，控制台在所选帧的上下文中运行。尝试对属于其他帧的局部变量执行命令将导致错误。

控制台日志记录

函数支持在执行期间输出控制台日志以用于调试。为此，只需使用 console.log 命令来输出日志。例如：
