建模目标设置

建模目标具有许多可用的配置选项，如下所述。您可以从建模目标主页点击进入建模目标设置页面 建模目标设置 （位于界面右上角）。

检查

目标检查是一种确保模型在投入运营之前通过预定义质量检查的方法。有关目标检查的完整详细信息，请参阅以下文档： 如何为所有提交设置检查.

部署

部署设置页面定义了 Python 模型提交在批量或实时部署中投入运营之前必须满足的模型提交部署配置文件要求。

模型元数据

提交到建模目标的模型可以在建模目标内具有特定于模型提交的元数据。可以为特定目标配置该元数据，以确保跟踪模型的相关信息。有关完整的配置详细信息，请参阅以下文档： 如何配置目标元数据.

外观

通过外观设置，您可以配置单个建模目标以浅色模式还是深色模式显示。

高级

高级设置页面包含非标准配置选项。通常，不应调整建模目标的高级设置。提供这些设置是为了与旧功能保持向后兼容。

评估设置

评估仪表板有两个高级配置选项： 仅显示由评估配置生成的指标 和 在评估仪表板中显示固定的标签页.

仅显示由评估配置生成的指标

当建模目标设置为仅显示由评估配置生成的指标时，只有通过 评估配置 创建的指标才会显示在 评估仪表板上。我们建议启用此设置，以确保建模目标中的模型采用标准的评估流程。如果未启用此设置，建模目标将无法知道所显示的模型指标是否为最新。

通过旧版管道管理配置的指标管道不会显示，除非 仅显示由评估配置生成的指标 被关闭。

在某些情况下，例如在评估配置发布之前配置的建模目标，或具有 在代码中定义的指标的非生产建模目标，显示来自建模目标评估配置之外的指标可能更为可取，可以通过此设置启用该功能。

在评估仪表板中显示固定的标签页

此外，建模目标上的评估仪表板可以配置为在评估仪表板的子集标签页旁显示 自定义指标视图 。

推理和指标数据集命名

由旧版指标管道管理生成的数据集，如果多个建模目标在同一输出文件夹中创建推理和指标数据集，可能会产生命名冲突，从而导致意外行为。此问题已在更新后的评估仪表板和配置中得到解决。

为了保持向后兼容，可以使用旧版的推理和指标数据集命名方案。

更新后的命名约定：

  • 推理数据集： inference_<Model Submission Name>_<Evaluation Dataset Name>-<Generated Hash>
  • 指标数据集： metrics_<Model Submission Name>_<Evaluation Dataset Name>_<Evaluation Library Name>-<Generated Hash>

旧版命名约定：

  • 推理数据集： <Model Submission Name> inference
  • 指标数据集： <Model Submission Name> metrics
