导出

Notepad 文档专为打印和导出为 PDF 或 DOCX 而设计，支持修改页面方向、定义页面页眉和页脚，以及针对组件的打印专用设置。

导出文档

通过使用以下方式导出文档： 文件 右上角的菜单， 导出，然后选择 导出为 PDF or 导出为 DOCX。文档渲染完成后，Notepad 将以所选文件格式保存您的文档。

渲染超时

导出时后台渲染时间有上限。如果文档包含许多需要长时间计算的图表，可能会达到该限制，导致图表无法完全加载。在这些情况下，请使用下文讨论的 以打印模式打开 选项。

特定页面设置

Notepad 提供额外的页面设置，供您在导出文档之前进行微调。要配置页面设置，请选择 页面设置 （位于 Notepad 左侧面板中）。

以字符串形式摄取日期字段。当 SAP 日期字段中包含具有特殊含义但无法解析的值，且需要在下游进行处理时，此选项非常有用。

Notepad 文档的默认页面大小为 Letter（8.5 x 11 英寸）。使用 以字符串形式摄取日期字段。当 SAP 日期字段中包含具有特殊含义但无法解析的值，且需要在下游进行处理时，此选项非常有用。 下拉菜单选择其他大小。

可用的页面大小选项包括：

  • Letter
  • 法务
  • Tabloid
  • A3
  • A4
  • A5

页面方向

默认情况下，文档以纵向模式显示。要将文档更改为横向模式，请选择 纵向 or 或 位于 页面方向.

页面页眉和页脚

页面页眉和页脚仅在打印或导出文档时可见。要启用页面页眉或页脚，请启用 页面页眉 or 页面页脚 选项。

分页符组件

使用直方图中的 分页符组件 来插入自定义分页符。分页符仅在打印时显示。

组件打印配置

某些组件支持打印专用的配置选项。可用时，可通过选择组件、打开 微件属性 面板并选择 打印配置.

选项包括 缩放, 在新页面上打印日 展开滚动条.

缩放

导出文档时，可用的水平空间可能受限（即使在横向模式下），这并不适合某些可视化内容。例如，可在屏幕上水平滚动的宽表格需要进行调整以适应页面。 缩放级别 配置允许您通过缩小显示内容来实现这一点。

在新页面上打印

默认情况下，如果空间有限，组件会在新页面上打印。对于显示表格或跨越多页的组件，这可能不是理想的行为。在这些情况下，您可以禁用在新页面上打印。

展开滚动条

用途 打印时自动展开表格高度 以在打印时完全展开滚动条，确保垂直滚动的部分完全展开。此功能目前仅支持 Contour 表格以及 Quiver 对象表和数据透视表。

导出为 PDF

您可以使用以下方式以适合打印的视图打开文档： 以打印模式打开 按钮。页面和所有图表完全加载后，您可以使用 Ctrl+P （Windows）/Cmd + P （macOS）键盘快捷键或右上角的打印按钮，将页面保存为 PDF 或进行打印。

请务必根据文档的 纵向 or 或 基于 页面方向 设置打印布局。确保页面大小与您选择的 Notepad 页面大小相匹配。选择 默认 边距选项以确保内容对齐。

导出为 DOCX

测试版

Notepad 中的 DOCX 导出处于 测试版 开发阶段。在积极开发期间,功能可能会发生变化。

Notepad 目前支持以下组件的 DOCX 导出：

  • Clip
  • Code Workbook 图表
  • Contour 图表
  • 文件引用（Compass）
  • 图像
  • 对象卡片
  • 对象媒体预览
  • 对象属性
  • 分页符
  • Quiver 分析图表
  • Quiver 仪表板图表
  • Solution Designer 图表
  • 表格
  • Vertex 图谱
  • 映射

DOCX 导出不保证保留 Notepad 文档中的所有样式和布局。以下部分描述了您最可能遇到的调整和限制，但也可能出现其他差异。

自动调整

导出为 DOCX 时会自动应用以下调整：

  • 内容会进行缩放以匹配其在 Notepad 中的布局。 图像、表格、分栏和文本会调整大小，使文档以与在 Notepad 中相同的方式填满 Word 页面。宽度和字号使用不同的缩放系数，因此文本及其旁边的图像可能按不同的比例缩放。
  • 图像会调整大小以适应页面。 任何宽度超过可用页面宽度的图像都会在保持原始比例的情况下缩小以适应页面。图像的高度始终遵循其原始宽高比。
  • 高亮颜色会以近似值代替。 Microsoft Word 仅支持 16 种高亮颜色，因此 Notepad 会选择与您的高亮颜色最接近的可用颜色。

不支持的内容

导出为 DOCX 时，以下内容不会包含在内：

  • 嵌套在其他表格中的表格不会被导出。
  • 表格单元格内的分栏会垂直排列，而不是并排显示。
  • 清单会导出为普通的项目符号列表，不包含复选框。
  • 深度嵌套的列表最多支持九级缩进。
  • 微件会导出为静态 PNG 图像。微件在导出后不会保留任何交互功能。仅支持以下列出的微件类型 导出为 DOCX ；其他微件不会被导出。
  • 占位符不会被导出。
