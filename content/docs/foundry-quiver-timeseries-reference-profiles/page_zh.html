参考曲线

参考曲线定义了传感器在特定过程中的预期行为。要构建参考曲线，需要选择一组过程运行或事件（即“黄金批次”），且这些运行的整体过程均按预期执行。随后，可以使用这些运行对应的传感器数据来构建参考曲线边界，通常采用均值加上或减去 n 各时间点的标准差。该范围表示传感器在该过程中的预期运行窗口。

例如，考虑在受控条件下定期进行的茶叶浸泡过程中的水温传感器。通过选择浸泡过程正常完成的批次，我们可以使用这些运行中的温度数据为该传感器建立上限和下限。这样，我们就能将未来的茶叶浸泡周期与参考曲线进行比较，以检测偏离正常运行的情况。

在截图中，阴影区域显示了水温传感器的预期运行范围，其计算方式为所选黄金批次曲线的平均值加上或减去两倍标准差。

Quiver 中的参考曲线

该 参考曲线边界 卡片可快速构建由平均值加减 n 标准差定义的参考曲线，前提是提供一组相对时间下的曲线。

为参考轮廓边界构建输入序列的过程包括：

  1. 选取传感器
  2. 将传感器数据筛选至过程（事件）发生的时间
  3. 将序列相对于各自的过程开始时间进行对齐

事件比较卡片

该 事件比较卡片 可获取单个时间序列和 事件集，并比较序列在所提供事件期间的行为。事件比较的输出是一个分组时间序列，可用作参考轮廓边界卡片的输入。

请参阅 分析事件数据 ，了解构建事件集的其他方法。

转换表

要在参考轮廓构建中使用多个时间序列，需要 转换表 。具体操作如下：

  1. 在转换表中联接时间序列和事件数据，并使用 筛选时间序列转换 将每个序列筛选至事件的开始和结束时间。
  2. 使用 相对时间序列转换 将每个序列与其关联的事件开始时间对齐。
  3. 从转换表中添加一个分组时间序列图卡片，并选择筛选和相对对齐的时间序列。
  4. 使用 参考轮廓边界 卡片，并以分组时间序列图作为输入。

或者，如果您不需要可视化各个筛选和相对对齐的曲线，可以跳过分组时间序列图。在这种情况下，您可以直接从转换表构建参考轮廓边界卡片。

参考轮廓边界也可以手动构建。请按照上述步骤操作，但不要使用参考轮廓边界卡片，而是使用 线性聚合卡片 来选择并聚合转换表中的所有筛选和对齐的时间序列。重复这些步骤，构建曲线的平均值聚合和标准差聚合。最后，使用 时间序列公式卡片 来创建上界（$average + (2 * $standard_deviation）和下界（$average - (2 * $standard_deviation）。此方法还支持使用自定义逻辑来定义上界和下界（例如滚动窗口边界）。

派生序列中的参考轮廓

可以为 派生序列 构建参考轮廓曲线，并通过时间序列属性进行引用，从而支持在 Quiver 之外使用参考轮廓。

推荐的本体论结构

选择黄金批次的流程通常因每个应用而异，我们建议采用灵活的本体论结构，使其既能管理参考档案元数据，又能构建模板化的派生序列。

  • 参考档案对象类型：作为参考档案的元数据，与相关的时间序列对象和事件对象建立关联。它将是派生序列的根对象类型，并支持无缝构建 模板化的派生序列。
  • 时间序列对象类型：包含一个时间序列属性，表示待分析的传感器数据，例如温度序列。
  • 事件对象类型：表示为构建参考档案而被认定为黄金批次的工艺运行或批次。包含表示事件/工艺/批次时间边界的开始时间戳和结束时间戳。

时间序列对象类型和事件对象类型都必须共享同一个通用键（属性值），才能实现关联。通过按通用键将二者连接，便可以专门在关联的黄金批次事件期间评估时间序列数据。

派生序列既可以从参考档案对象类型上的时间序列属性中引用，也可以作为关联的传感器对象类型上的传感器对象来引用。

此结构可基于过程事件灵活地选择和聚合时间序列数据,从而支持在各种应用中稳健地构建参考概况。您可以创建一个 Workshop 模块来启用对参考概况对象的管理。

派生序列逻辑

该 关联序列聚合卡片 允许您指定输入对象,并定义前后搜索逻辑来收集和聚合关联的时间序列对象。您可以选择包含用于搜索事件对象的逻辑。如果提供了事件对象,则时间序列对象与事件对象之间需要有一个公共键。这可确保仅在关联事件期间对生成的时间序列进行评估。

要在派生序列中构建参考概况:

  1. 创建两个与事件对齐的关联序列聚合。
    • 输入对象应为参考概况对象之一。
    • 第一个关联序列将创建平均值聚合,第二个将创建标准差聚合。
  2. 使用 时间序列公式卡片 来构建上界($average + 2 * $standard_deviation)和下界($average - 2 * $standard_deviation)。
