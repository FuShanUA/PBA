数据源

Foundry 中的计算模块在“零信任”安全模型下运行，确保最大程度的隔离与安全性。默认情况下，这些模块不具备任何外部网络访问权限，包括对其他 Foundry 服务的访问。这种严格的隔离对于维护安全的环境至关重要。

要为计算模块启用外部网络访问，您必须通过 Data Connection 应用程序显式配置数据源。数据源还支持安全存储访问外部系统所需的凭据，供计算模块使用。以下章节概述了在计算模块中使用数据源来打包网络策略和凭据的过程。

向计算模块添加数据源

在 Data Connection 中创建数据源

  1. 在 Data Connection 应用程序中创建数据源，并附加所需的网络策略和机密。

  2. 请确保满足以下配置：

    • 数据源必须与计算模块位于同一个项目中。
    • 在 代码导入 配置选项卡中，选择 允许将此数据源导入计算模块。

    • 为数据源添加一个 API 名称，您将在计算模块中使用该名称访问数据源。

将数据源添加到计算模块配置中

在计算模块中，选择 配置 > 数据源 > 添加数据源。

在计算模块中访问数据源凭证

当计算模块启动时，数据源凭证会以 JSON 的形式挂载到一个文件中，该文件的路径包含在 SOURCE_CREDENTIALS 环境变量中。要访问这些凭证，请执行以下操作：

  1. 读取由 SOURCE_CREDENTIALS 环境变量指向的文件。
  2. 将内容解析为 JSON 字典。
  3. 访问特定凭证时，先指定数据源的 API 名称，再指定密钥的名称。

某些数据源（例如 REST 数据源）需要在指定的密钥名称前添加 additionalSecret 前缀（例如， additionalSecretMySecretName）。

import json
import os

with open(os.environ['SOURCE_CREDENTIALS'], 'r') as f:
    credentials = json.load(f)

# Access a specific secret (when using a REST source, secrets are prefixed with 'additionalSecret')
secret = credentials["<Source API Name>"]["<Secret Name>"]

您可以使用 计算模块 SDK ↗ 来简化此过程。详情请参阅下方章节。

Python 计算模块 SDK

该 计算模块 SDK ↗ 提供了一个简化接口，用于在 Python 中访问数据源及其凭证。您无需手动读取环境变量并解析 JSON，可以直接使用该 SDK 获取数据源、密钥和 HTTPS 连接。

要使用该 SDK，请安装 sources extra 并导入 get_source （来自 compute_modules.sources_v2 模块）：

from compute_modules.sources_v2 import get_source
from external_systems.sources import Source

source: Source = get_source("<SOURCE_API_NAME>")

# Retrieving a secret
secret = source.get_secret("<SECRET_NAME>")

# Making an HTTPS request
https_connection = source.get_https_connection()
client = https_connection.get_client()
url = https_connection.url

response = client.get(url).text

该 get_source 函数会返回一个 Source 提供以下方法的对象：

  • get_secret("<SECRET_NAME>")：按名称从源中检索特定的机密。
  • get_https_connection()：返回配置了源的网络策略和凭据的 HTTPS 连接对象。请使用 get_client() 在连接上获取 HTTP 客户端，并使用 url 获取基础 URL。

管理源

要在计算模块上添加或移除源，必须先停止计算模块。如果计算模块正在运行，则无法添加或移除源。此外，对源的网络策略所做的更改需要完全重启计算模块才能生效。对凭据的更改将在计算模块的滚动升级中体现。
