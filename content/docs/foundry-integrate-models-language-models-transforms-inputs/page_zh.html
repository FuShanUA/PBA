语言模型类

palantir_models 提供一组可在 Python 转换中使用的类。

类描述
OpenAiGptChatLanguageModelInput一种 FoundryInputParam，绑定到语言模型服务中的 OpenAiGptChatLanguageModel API。可在 Python 转换装饰器中使用。
GenericChatCompletionLanguageModelInput在 Python 转换中将模型绑定到通用聊天补全 API。
GenericCompletionLanguageModelInput一种 FoundryInputParam，绑定到语言模型服务中的 GenericCompletionLanguageModel API。可在 Python 转换装饰器中使用。
GenericEmbeddingModelInput一种 FoundryInputParam，公开语言模型服务中的 GenericEmbeddingsModel API。可在 Python 转换装饰器中使用。
OpenAiGptChatLanguageModel提供 OpenAI 聊天补全模型的客户端。
GenericChatCompletionLanguageModel提供通过通用聊天补全 API 进行文本对话的客户端。
GenericCompletionLanguageModel提供一个客户端，用于执行 AIP 中可用的任何聊天补全模型。
GenericEmbeddingModel提供一个客户端，用于执行 AIP 中可用的任何嵌入模型。
