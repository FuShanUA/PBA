从 SAP 摄取 HANA 视图

要将 HANA 视图中的数据提取到 Foundry，该 HANA 视图需要发布为外部视图。本文档介绍了执行此操作的步骤。

前提条件

  • SAP HANA Studio 或适用于 Eclipse 的 SAP HANA Tools
  • 适用于 Eclipse 的 ABAP Development Tools

这些工具可从以下位置获取 SAP 开发工具 ↗.

外部视图

外部视图是 ABAP 数据字典中的一种特殊视图，用于在 ABAP 程序中定义 SAP HANA 视图。

外部视图只能使用 ABAP Development Tools (ADT) 创建，且仅当当前数据库为 SAP HANA 数据库时才可创建。

激活外部视图时，会在 SAP HANA 数据库上创建一个以该视图名称命名的别名，指向该 SAP HANA 视图。外部视图的字段名称可以与 SAP HANA 视图的字段名称不同。这会将 HANA 特定的数据类型映射到 ABAP 数据字典中的预定义类型。下表列出了当前支持的 HANA 特定数据类型，并指明它们默认映射到哪些 ABAP 数据字典类型。

HANA 类型含义ABAP 数据字典中的类型
SMALLINT2 字节整数INT2
INTEGER4 字节整数INT4
BIGINT8 字节整数INT8
DECIMAL压缩数字DEC
SMALLDECIMAL压缩数字DEC
FLOAT二进制浮点数FLTP
NVARCHARUnicode 字符串CHAR
VARBINARY字节字符串RAW
BLOB字节字符串RAWSTRING
NCLOBUnicode 字符串STRING

外部视图可以在基于 SAP GUI 的 ABAP Workbench 中使用 ABAP 数据字典工具进行显示，但无法编辑。

在 SAP HANA 视图之上创建外部视图

  1. 创建新的 ABAP 仓库对象并选择 字典视图.
  2. 在下一个屏幕中，选择 外部视图 选项，并为外部视图指定名称和描述。
  3. 接下来，您可以验证从 SAP HANA 视图到外部视图的列映射。
  4. 您可以使用 SE16 事务代码显示外部视图的内容，以对其进行测试。

在 Foundry 中摄取 HANA 视图

创建外部视图后，即可通过 SAP 连接器摄取，只需选择 HANA 视图对象类型 在配置同步时。
