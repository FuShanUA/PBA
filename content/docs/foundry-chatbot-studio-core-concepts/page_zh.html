核心概念

以下核心概念对于理解并充分利用 AIP Chatbot Studio（之前称为 AIP Agent Studio）至关重要。您可以在 开始使用 教程中了解更多相关信息。

AIP Chatbots

AIP Chatbots（之前称为 AIP Agents）是配备了企业特定信息和工具的交互式助手。

应用状态

直方图 应用状态，之前称为 参数，是提示词中的应用变量，用于自定义和控制 LLM 的行为。它们支持动态输入，并可根据任务需求进行调整。

指令和描述

指令、工具描述和变量描述会被编译到 LLM 的原始系统提示词中。这会教 LLM 如何利用可用的上下文来完成一项任务。

对于指令，请以最重要的信息开头，例如任务的概述。随后提供必要的数据以及使用 应用状态 和 ，以及.

对于每个工具和变量描述，请为 LLM 提供关于如何以及何时使用该特定上下文的具体步骤。请记住，LLM 只能访问您明确提供的信息。

检索增强生成（RAG）

检索增强生成利用外部数据源为 LLM 动态提供相关信息。这种方法通过确保 LLM 的回答基于最新且符合上下文的数据，从而提升其回答质量。

检索上下文

检索上下文是指为响应每条消息而检索到的特定信息，用于生成回复。其流程如下：

  1. 用户发送一条新消息。
  2. 根据用户的消息，从已配置的数据源中获取相关内容。
  3. 将相关内容连同用户的消息一起提供给 LLM。

有关更多详细信息，请查看图形模式文档中的 检索上下文 文档。

工具

工具 是 LLM 可以使用的外部功能或 API，用于执行特定操作或获取其基础能力之外的信息。

有关更多详细信息，请查看图形模式文档中的 ，以及 文档。

向量嵌入

嵌入是文本的数值表示，能够捕捉语义含义。它们用于高效地比较和检索相似的文本片段。在 AIP Chatbot Studio 中，嵌入有助于识别相关文档和上下文，以提供准确的回复。

上下文窗口

上下文窗口是指 LLM 一次可以处理的文本量（通常以 token 为单位）。在 AIP Chatbot Studio 中，上下文窗口包括系统提示词、对话历史以及为协助 LLM 而注入的信息（包括检索上下文、应用状态和工具）。超出上下文窗口将导致错误，提示用户创建新会话以继续交互。

将 Chatbot 作为函数

Chatbot 可以发布为 函数，从而可以在平台上任何可执行函数的地方使用。例如，构建者可以将 AIP Chatbots 发布为函数，以便在 AIP 评估中进行评估，使用 发布后，我们建议在自动化 chatbot 工作流，或在 代码仓库中使用 chatbot。更多信息请参阅 将 chatbot 作为函数 文档。
