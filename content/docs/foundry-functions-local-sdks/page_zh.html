本地本体论 SDK

TypeScript v2 和 Python 函数支持 本地本体论 SDK，其中 OSDK 会根据您的资源导入自动生成，而无需手动进行版本管理或作为单独的软件包安装。这意味着 SDK 类型始终与最新的资源导入保持同步。完整功能需要使用本地 SDK 全局分支 支持。

设置新的本地 SDK

如果这是您第一次为代码仓库创建本地 SDK，请按照以下步骤操作：

  1. 打开 “资源” Code Repositories 或 VS Code 中的侧边面板。
  2. 在面板的右下角，选择 选择。一个 修改导入资源 标签页将在您的代码编辑器中打开。
  3. 从下拉菜单中选择一个可用的本体论。
  4. 在侧边面板中，选择要导入的对象类型、关联类型、接口类型和其他实体。

当您从本体论中添加实体时，SDK 会自动更新到新版本，并且代码绑定将在您的代码仓库中生成。然后，您可以从 SDK 软件包导入本体论实体，并在函数签名中使用它们。当您为函数标记版本时，SDK 会在 CI 中生成并与您的函数版本捆绑在一起，反映标记时本体论的状态。

从命令行生成 SDK

如果您没有使用 VS Code，可以使用 ./rune 命令行工具生成和重新生成本地 SDK。首先，准备开发环境：

Copied!
1
./rune env prepare

首次生成 SDK 时，请提供软件包名称：

Copied!
1
./rune sdk generate --sdk-package-name ontology

软件包名称决定了代码中本体论实体的导入路径（例如， import { MyObjectType } from "@ontology/sdk"）。您可以选择任何软件包名称，但 ontology 是默认约定。

更改资源导入后重新生成 SDK：

Copied!
1
./rune sdk generate

If ./rune 在您的代码仓库中缺失，请运行 .palantir-scripts/install-rune 来安装它。

将现有代码仓库迁移到本地 SDK

要将代码仓库从独立 SDK 迁移到本地 SDK：

  1. 找到 functions.json 文件在您的代码仓库中，然后设置 useSdkSidebar to false.

  2. 在 Data Connection 中导航至 “资源” 侧边面板。选择 迁移 顶部的选项以生成本地 SDK 并提交自动生成的更改。对于 TypeScript v2，这会更新您的 package.json 和 package-lock.json 文件。对于 Python，这会更新您的 meta.yaml 和 hawk.lock 文件。
