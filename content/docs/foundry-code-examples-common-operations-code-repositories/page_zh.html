在 PySpark 中创建稳定的主键

此代码使用了 PySpark 中的 concat_ws() 和 sha2() 函数，通过拼接多个列并可选地对结果进行哈希处理，来创建稳定且唯一的主键。这种方法可确保主键稳健、稳定，并能有效地唯一标识数据集中的行。

主键应当唯一、非空且稳定。使用非确定性或不稳定的主键（例如单调递增的 ID 或随机数）可能会导致以下几种问题：

  1. 对象标识：本体论中的对象通过其主键进行标识。如果支撑数据集的每次构建都生成一组新的 ID，则对对象所做的编辑可能会丢失。
  2. 变更跟踪：如果主键不稳定且不可重现，跟踪数据集和行的变更就会变得困难。
  3. 管道一致性：对生成主键的管道或依赖该数据集的下游管道进行增量运行，可能会导致数据重复和其他不一致问题。

创建主键的一个良好实践是使用数据集中能够唯一标识每一行的列组合。例如，在考勤数据集中， student ID 和 date 列的组合可以唯一标识每一行。

以下是一个代码片段示例，用于为数据集生成主键，其中每行由列 A、B 和 C 唯一标识。 concat_ws() 函数用于拼接，而 sha2() 函数可根据需要确保每个键具有相同的长度和格式。

from pyspark.sql import functions as F

# Concatenate all columns
df = df.withColumn("primary_key", F.concat_ws(":", "A", "B", "C"))

# Optionally create a hash to ensure the same length and format for all keys
df = df.withColumn("primary_key", F.sha2(F.col("primary_key"), 256))

遵循这些最佳实践，您可以确保主键稳健、稳定且有效，能够唯一地标识数据集中的各行。
