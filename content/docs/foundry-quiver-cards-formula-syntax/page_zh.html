公式语法

Quiver 允许您绘制自定义数学表达式，并使用公式指定筛选条件。我们在公式中支持以下结构：

  • 值
  • 输出类型
  • 运算符
  • 内置函数
  • 控制流
  • 语言参考

值

  • 数字： 除了标准数字（例如 6, 3.14159, -128）之外，Quiver 还支持科学计数法： 1.602e-19.
  • 绘图引用： 每个绘图在创建时都会被分配一个参数名称，您可以使用 $ sign: $A 引用参数名称为 A日 $A + $B 计算两个绘图的总和。
  • 布尔值： 使用逻辑运算符时，请使用布尔值 true and false 。
  • 时间引用： 在公式中使用函数 secondsSince("time") and millisecondsSince("time")来引用时间。时间项需要采用 ISO-8601 格式 ↗。例如， secondsSince("1970-01-01T00:00:00+00:00") 计算自 1970 年 1 月 1 日（UTC）以来的秒数。
  • NaN： 表示未定义或无法表示的值，例如空值。

输出类型

公式只能输出数字或字符串，不能输出布尔值。此外，输出必须是 同质的，即公式在所有求值过程中必须始终只输出数字或只输出字符串。

如果您需要输出类似布尔值的值，可以考虑以下替代方案：

  • 对于数字输出： 用途 1 表示 true， 0 表示 false。例如： $A > 0 ? 1 : 0
  • 对于字符串输出： 用途 "true" and "false" 字符串。例如： $A > 0 ? "true" : "false"

运算符

  • 数值运算符： Quiver 支持 +, -, *, /，以及求余运算符 %: 10 % 7 的计算结果为 3。您还可以使用括号 () 来强制指定优先级。这些运算符的结果为双精度数字。
    • 您不能使用 ^ 进行幂运算。请参阅下文 pow 中的 内置函数 函数来进行幂运算。
  • 比较运算符： Quiver 支持 == 判断相等， != 判断不等， >, <, >=, <= 用于比较。这些运算符的结果为布尔值。
  • 逻辑运算符： 您可以使用逻辑 AND（&&）和逻辑 OR（||）运算符组合布尔值。Quiver 还支持逻辑 NOT 运算符（!），用于反转布尔值。
  • 位运算符： 您可以对数值执行按位 AND（&）、按位 OR（|）、按位 XOR（^）和按位 NOT（~）运算。您还可以执行按位移位： << 用于左移， >> 用于保留符号的算术右移， >>> 用于补 0 的逻辑右移。

控制流

Quiver 支持三元运算符 a ? b : c 来表达“如果 a 则 b 否则 c”。例如，在每个时间点， $A > 0 ? $B * 10 : $C * 10 取值为 $B * 10 如果 $A 在该时间的值大于 0；否则，其取值为 $C * 10.

还可以使用 NaN 值，以在输入序列缺失值时返回替代值。例如，在每个时间点， @M != NaN ? @M : @K 取值为 @M 如果它有数值；否则，其取值为 @K.

你可以利用代码库升级拉取请求中的 return 和 skip 语句来“提前”停止，并返回一个值或指示不应返回任何值（例如，过滤掉某个点）。

语言参考

基本类型和赋值

变量使用 var 关键字声明。 = 符号用于为变量赋值。变量可以是数字（双精度）、布尔值或字符串。

var a = 6;
var b = 3.14159;
var c = 1.602e-19; // Exponential notation is supported
var d = 1.602E-19; // Exponents are not case-sensitive

var boolean_example = true;
var boolean_example = false; // re-assign to false

var string_example = "high";

表达式

数值

您可以将字面量和变量组合成更复杂的表达式。

基本数学运算符是 +, -, *, /。要计算余数，请使用 %.

var a = 2 + 2; // a has value 4
a = 3 * 7; // a has value 21
a = 3.5 / 7; // a has value 0.5
a = 10 % 7; // a has value 3

运算符优先级符合预期。您可以使用括号 ( ) 将表达式分组。

var a = 5 + 3 * 2; // a has value 11
var b = (5 + 3) * 2; // b has value 16

您还可以使用上述五个运算符的赋值版本。

var a = 10;
a *= 2; // a now has value 20
a += 3; // a now has value 23
a -= 5; // a now have value 18
a /= 3; // a now has value 6
a %= 5; // a now has value 1

布尔

您可以使用比较运算符比较数字 <, <=, >, >=。这些运算符产生布尔（true or false）结果。

可以使用 ==检查相等性，使用 !=.

然后可以将这些表达式与逻辑运算符组合 && 和 ||.

你可以利用代码库升级拉取请求中的 ! 运算符来反转布尔结果（true 变为 false, false 变为 true).

字符串

可以使用 ==检查相等性，使用 !=.

var a = "high";
var b = "low";

// compare values
var c = a == a; // true
var d = a != b; // true
