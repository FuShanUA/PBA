调试 Python 转换

本指南概述了 Python 转换中可用的调试技术。有关错误和异常的更多信息，请参阅 Python 文档 ↗.

使用调试器

调试器是识别和解决 Python 转换中问题的有用工具。您可以设置断点来暂停转换执行，并检查变量、查看 DataFrame，以及理解函数和库。

详细了解您所选 IDE 的调试器：

  • VS Code 调试器。
  • Code repositories 调试器。

阅读 Python 回溯信息

A 回溯（traceback） 在 Python 中是一条错误消息，其中包含导致错误的函数调用序列，在其他编程语言中也称为堆栈跟踪。在 Python 中，任何未处理的异常都会产生回溯信息，并且最近的调用位于底部。

大多数 Python 转换运行时故障都以回溯信息的形式呈现，因此了解如何阅读它们非常重要。

class Stats(object):

    nums = []

    def add(self, n):
        self.nums.append(n)

    def sum(self):
        return sum(self.nums)

    def avg(self):
        return self.sum() / len(self.nums)


def main():
    stats = Statistics()
    stats.add(1)
    stats.add(2)
    stats.add(3)
    print(stats.avg())


main()

与其他编程语言中的堆栈跟踪不同，Python 回溯信息最后显示最近的调用。自下而上，回溯信息显示以下内容：

  • 异常名称， NameError ↗。有许多 内置 Python 异常类 ↗，但代码也可以定义自己的异常类。
  • 异常消息， name 'Statistics' is not defined。此消息包含对调试最有用的信息。
  • 导致抛出异常的函数调用序列： File "test.py", line 23, in <module> 后跟相关代码行（第 16 行）。

通过此回溯信息，我们可以看到异常发生在 test.py 菜单中选择 main 方法的第 16 行。具体来说，导致错误的代码行是 stats = Statistics()，抛出的异常是 NameError。由此我们可以推断出名称 Statistics 不存在。回顾示例代码，似乎应该使用名称 Stats 而不是 Statistics.

日志记录

对于日志记录，您可以使用以下选项：

  • 简单 print 语句。此方法适用于标准（轻量级）转换，但不适用于 Spark 转换。
  • 标准 Python logging 模块 ↗。此方法适用于所有转换类型，但仅保存 INFO级别及更高级别的日志。

日志可在 VS Code 的 输出 ，并用于 构建应用程序 位于 Actions > View logs.

以下代码示例演示了如何输出日志以帮助调试：

import logging

@transform.using(
    output=Output("/path/output"),
    input=Input("/path/input"),
)
def my_compute_function(output, input):
    input_df = input.polars()
    log.info("Number of rows: %d", input_df.height)
    print("Number of columns: " + str(input_df.width))
    output.write_table(input_df)

@transform_df(
   Output("/path/output"),
   input=Input("/path/input"),
)
def my_compute_function(input):
    log.info("Number of rows: %d", input.count())

构建指标

使用直方图中的 指标 遥测选项卡来诊断与资源相关的问题，例如内存不足（OOM）错误或构建缓慢。该选项卡显示内存和 CPU 利用率图表，展示您的转换是受内存限制、受 CPU 限制，还是使用的资源少于分配的资源。

访问构建指标：

  1. 从数据集预览、数据血缘或 Builds 应用程序查看构建报告。
  2. 从构建中选择一个作业，然后导航到 Telemetry > Metrics.

详细了解如何解读 内存和 CPU 利用率指标.

你可以利用代码库升级拉取请求中的 指标 遥测选项卡适用于使用轻量级计算引擎的转换，但不适用于 Spark 转换。
