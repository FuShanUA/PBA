使用服务用户初始化一个新的 OSDK TypeScript 应用程序

如 权限类型 部分所述，OSDK 可用于根据服务用户的权限而非最终用户的权限来查询数据。以下演练展示了如何使用 Next.js© ↗ （外部）通过 OSDK 和服务用户获取数据。

在开发使用机密客户端的服务或应用程序时，系统会随您的 Developer Console 应用程序一起创建一个服务用户。如果您计划使用属于默认组织以外其他组织的本体论来创建应用程序，则必须完成相应步骤来 共享并启用该应用程序。

1. 使用 Developer Console 创建 OSDK 包

请按照 创建新的 Developer Console 应用程序中的步骤操作，并使用以下特定于后端服务的选择：

  • 在 应用程序类型 页面上，选择 后端服务。

  • 在 权限 页面上，选择 应用程序的权限。

Developer Console 将根据应用程序名称为此应用程序创建服务用户。在上面的示例中，所生成的服务用户的名称为 Ontology SDK application using service user。除了 提交标准 对于任何操作类型，您都必须授予此服务用户所需的权限，以便 读取对象类型的数据 （您将在下一步中选择这些对象类型）。

  • 在 “资源” 页面上，选择 “是，生成本体论 SDK”。

  • 选择要使用的本体论。

请注意，本体论 SDK 一旦生成，与之关联的本体论将无法更改。

  • 选择您希望包含在 OSDK 包中的对象类型和操作类型。在本练习中，请选择任意一个可供您使用的对象类型。

查看并确认您输入的信息，然后选择 “创建应用程序” 以查看新应用程序的客户端密钥。请复制并妥善保存该密钥，因为这是您唯一一次可以看到它。

如果您丢失了客户端密钥，可以在 “OAuth 与限制” 页面上轮换并获取新密钥。请注意，这将导致使用此服务用户和密钥的现有应用程序无法正常工作。

当您 为 Marketplace 打包机密客户端应用程序时，客户端密钥不会包含在内。安装后，您必须在目标环境中生成新的密钥：导航至 “OAuth 与限制” 并选择 “轮换密钥”。

最后，选择 “生成第一个版本” 以使用您新创建的 OSDK。

2. 安装生成的 SDK 包

OSDK 生成完成后，您将看到一组安装步骤，指导您在代码项目中安装生成的 SDK。

3. 在代码项目中使用 OSDK

在本演练中，我们使用 Next.js© ↗。Next.js 支持在服务器端渲染代码，这是我们的服务用户示例所必需的。要初始化一个新的 Next.js 项目，请参阅 Next.js© 文档 ↗ 。

import { createConfidentialOauthClient } from "@osdk/oauth";
import { createClient } from "@osdk/client";

export const auth = createConfidentialOauthClient(
    process.env.CLIENT_ID!,
    process.env.CLIENT_SECRET!,
    process.env.STACK_URL!,
);

export const client = createClient(
    process.env.STACK_URL!,
    <ONTOLOGY-RID>,
    auth
)

创建一个 .env 文件，其中包含相同的变量。 请勿将此文件提交到您的代码仓库。

import { Country } from "@serverside-osdk-example/sdk";
import { client, auth } from "./client";
import { Osdk } from "@osdk/client";

async function getCountries(): Promise<Osdk.Instance<Country>[]> {
    // Handle authentication
    await auth.signIn();
    // You need to give the service user read access to the ontology
    try {
        const resp = await client(Country).fetchPage();
        return resp.data;
    } catch (err) {
        console.log(err);
    }
    console.log("No countries found");
    return [];
}

export default async function Home() {
    const countries: Osdk.Instance<Country>[] = await getCountries();
    return (
        <main>
            <div>
                {countries.map((country: Osdk.Instance<Country>) => (
                    <span key={country.$primaryKey}>{country.countryName}</span>
                ))}
            </div>
        </main>
    );
}
