已配置对象视图概览

已配置对象视图是可自定义、可复用的对象数据表示形式。您可以通过以下方式构建 完整 和 面板 对象类型对象视图 Workshop 模块，从而灵活控制对象在整个平台上的呈现方式。

Foundry 会为所有对象类型默认创建一个 标准对象视图 。当您创建已配置对象视图时，它将成为用户的默认视图，不过用户可以通过对象视图自带的切换按钮切换回标准对象视图。此外，在使用自定义标头的 Palantir 应用程序（如 Gaia 或 Vertex）中渲染对象视图时，用户可以将鼠标悬停在省略号抽屉图标上，以在标准视图和已配置视图之间切换。

在 Workshop 中，标准对象视图与已配置对象视图之间的切换功能尚未提供。

默认配置

系统会为每个对象类型自动创建默认的已配置对象视图。默认完整对象视图包含一个重要属性列表（如果没有重要属性，则包含所有非隐藏属性），以及该对象的关联列表。默认面板包含相同的属性列表。默认视图会动态更新以反映对对象类型所做的更改（例如新增属性或属性重命名），但对象视图一经编辑即变为用户管理，后续所有更新都必须手动进行。

权限

编辑对象类型的对象视图所需的权限取决于该对象类型的权限模型：

  • 如果对象类型使用旧版数据源派生权限，则用户必须拥有 Object View Admin 应用程序权限（位于 控制面板中），以及该对象类型的任一输入数据集上的 Editor 角色。
  • 如果对象类型使用 本体论角色，则用户只需拥有该对象类型上的 Ontology Editor 角色。
  • 如果对象类型使用 基于项目的权限，则用户只需拥有该对象类型上的 Editor 角色（位于包含该对象类型的 Compass 项目上）。

除非您通过旧版配置选项手动将对象视图标签页的 Workshop 模块转换为独立模块，否则该 Workshop 模块的权限将由对象类型管理。这可确保模块与对象类型之间的权限保持一致，因此有权编辑或查看该对象类型的用户也将能够编辑或查看对象视图内的所有模块。

编辑已配置对象视图

访问已配置对象视图配置的方式有多种。

对象类型的对象视图可以在 对象视图 标签页中进行预览（位于 Ontology Manager 中）。在标头中，您可以选择并固定一个默认显示对象进行预览。您还可以预览完整和面板两种形态，并测试对象视图在浅色和深色模式下的显示效果。可以使用标头右侧的 编辑 选项来访问已配置对象视图的编辑功能。

在 Object Explorer 中，查看对象时可以通过选择以下方式访问对象类型的已配置对象视图 More > Advanced > Edit object view.

在应用程序中查看面板对象视图时，可以将鼠标悬停在下拉省略号上并选择以下方式访问配置 编辑。该下拉菜单仅对有权编辑对象视图的用户显示。

这些编辑入口将进入已配置对象视图编辑器，您可以在其中管理对象视图标签页，并使用 Workshop 模块的所有标准功能编辑内容。发布后，编辑内容将应用于该对象类型的所有对象。有关更多编辑信息，请参阅 完整对象视图配置 和 面板对象视图配置.
