了解过期的数据集

数据集可能未更新的原因有多种。常见的排查场景包括：

  • 我的数据集构建是否失败？
  • 是否存在尚未构建且未更新的上游数据集？
  • 我们是否已从数据源收到最新数据？

您可以使用 Data Lineage 轻松回答这些问题。

  • 首先，在 Data Lineage 中打开感兴趣的数据集并右键单击节点，以验证管道中每个资源的状态。

  • 然后,选择 展开节点。通过单击上方的双左箭头，您可以查看该数据集的所有祖先节点 展开父级.

  • 接下来，选择 构建状态 中的 节点颜色选项 Data Lineage 右上角的下拉菜单，以查看管道中每个资源的构建状态。通过这种管道视图，诊断过期的数据集将变得更加容易。
