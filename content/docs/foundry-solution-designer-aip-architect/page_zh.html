AIP Architect

AIP Architect 为 Solution Designer 带来了由大语言模型（LLM）驱动的功能，使您能够将一组工作流需求转化为使用 Palantir 平台构建解决方案的分步实施计划。您可以使用 Solution Designer 探索各种选项、规划工作流，并以 AIP Architect 作为 AI 向导来加速构建过程。

如果您能向 AIP Architect 描述您希望使用该平台实现的目标——例如遇到的问题、任何约束或需求，甚至是对期望的解决方案或输出的想法——那么 AIP Architect 将以 工作流图的形式为您创建一份实施计划。AIP Architect 工作流图借鉴组件库与实施模式库，描述工作流的各个组成部分以及它们如何组合成解决方案架构，从而为您提供在平台上高效构建的计划。

开始使用 AIP Architect

在 Solution Designer 中，可以通过多种方式使用 AIP Architect。

在 Solution Designer 的初始主页上，您可以选择 开始规划 以打开 AIP Architect 向导。

或者，在新的 Solution Designer 图表中，选择 开始规划 以启动 AIP Architect 向导。

或者，在现有的 Solution Designer 图表中，您可以选择图表工具栏中的 概念 图标，以添加 AIP Architect 概念节点。这样，您就可以自动生成实施计划并跳过 AIP Architect 向导，从而利用 AI 生成的工作流计划来增强现有图表。

AIP Architect 向导

打开 AIP Architect 向导后，系统将通过多个提示引导您向 AIP Architect 提供信息，例如：

  • 您想要构建的内容（即最终产品或交付物）
  • 此工作流的数据源
  • 您希望如何构建工作流（具体而言，您希望使用多少代码）

描述您工作流的最终产品或交付物

AIP Architect 向导的第一步是提供有关您要构建内容的信息。这可以是数据集、应用、文档、仪表板或其他内容。

选择工作流的最终产品或交付物后，系统会提示您描述您可能有的任何工作流要求；请在此处概述您设想的工作流。

例如，假设您想要构建一个用于安排医院护士班次的应用程序。下方截图显示了输入包含这些工作流需求的提示后向导的状态。

AIP Architect 在构建您的解决方案设计图时，会使用您提供的工作流摘要来生成建议。您可以在规划过程中随时修改摘要，以便根据更新后的需求重新生成建议。

编辑工作流摘要

当您对工作流的理解不断深入或需求发生变化时，您可以编辑工作流摘要：

  1. 在 AIP Architect 侧边栏中找到工作流摘要部分。
  2. 选择工作流摘要旁边的 编辑 图标。
  3. 修改文本以反映您更新后的需求。
  4. 选择 更新 以根据新的摘要重新生成建议。

AIP Architect 在为概念节点生成实现模式时将使用更新后的摘要，从而确保建议与您当前的工作流愿景保持一致。

您的工作流提示可以很简单，例如护士排班示例中使用的提示：

我想要构建一个为医院护士安排班次的应用程序。我希望根据护士偏好和预测需求来优化这些排班。

您还可以向 AIP Architect 提供更详细的工作流需求，例如以下提示词：

我在一家制造公司工作，我们需要生成覆盖全部 SKU 的需求预测。我需要同时利用内部数据（例如历史销售和库存）以及外部数据（例如天气模式），为每个 SKU 确定最佳策略。

除了前瞻性预测之外，我还想针对相关输入进行“假设（what-if）”模拟。我想使用自然语言提示词，例如“如果下个月天气比预期更冷会怎么样？”或“如果我将价格提高 10% 会怎么样？”。然后，我想编排参数变更来执行模拟。

主要特性：

  • 实时需求模拟：利用相关系数或置信区间等模型输出，为高管和规划人员提供易于使用的模拟驾驶舱。
  • 面向业务用户的界面：帮助非技术背景的业务专家利用自身业务经验，推动针对真实数据的模型迭代与验证。
  • 高度可配置的建模：以日、周、月或年度的节奏，跨客户、SKU 和产品线实施符合业务需求的预测。

描述工作流的源数据

在向 AIP Architect 提供初始工作流信息后，AIP Architect 向导将询问您有关驱动此工作流的数据。首先，系统会提示您选择此工作流的数据源。选项包括：

  • 外部数据源/系统
  • 手动上传
  • 现有 Foundry 数据
  • 用户输入数据（例如，来自用户提交的表单）

然后，您可以提供有关数据更新频率、数据规模以及数据特殊属性的信息（例如，数据是否为地理空间、时间序列、媒体等）。这些信息有助于 AIP Architect 推荐最合适的平台应用程序来执行工作流并交付所需的结果或输出。

描述您希望如何构建工作流

最后，AIP Architect 会询问您希望以何种方式构建工作流——此处的选项包括“无代码”（点选式）、“低代码”（编写基本函数）和“专业代码”（主要在代码编辑器中工作）。根据您对此问题的回答，AIP Architect 将选择符合您在构建工作流时希望使用的代码量的平台应用程序。完成选择后，请选择 生成工作流图 以创建您的工作流图。

规划您的工作流

工作流图生成后，您将看到工作流的抽象表示形式，即一系列由箭头连接的“概念节点”。每个概念节点代表目标工作流的一个通用部分，例如数据寻源、数据处理、本体论或应用程序构建。

概念节点

这些概念节点可作为工作流实现的参考。要指示 AIP Architect 生成更详细的工作流实现，请选择一个概念节点（本体论节点除外，该节点 将在下文中讨论），然后选择 Select implementation 下拉菜单。AIP Architect 将为您的工作流建议可能的实施方案。

预览实施方案

在确定采用某一实现模式之前，您可以先在图上预览该模式：

  1. 选择一个概念节点。
  2. 选择 Select implementation 以查看建议的模式。
  3. 选择一个建议的模式进行预览。
  4. AIP Architect 将在您的图上以预览叠加层的形式显示实现模式节点，并提供 AI 生成的上下文来解释该方法。
  5. 查看该实现，以确保其符合您的需求。
  6. 选择 Insert into graph 以将该实现添加到您的图中，或选择 Cancel 以尝试其他模式。

预览功能允许您在不使图表变得杂乱的情况下探索多种实现方案，从而帮助您针对工作流的每个部分就最佳方案做出明智的决策。

流式上下文

AIP Architect 在生成实现建议的同时会提供实时说明。您将看到：

  • 对建议实现模式的简要描述。
  • 该模式为何适合您工作流需求的理由。
  • 模式中包含的关键组件及其作用。
  • 此方法的注意事项或权衡取舍。

说明内容会在生成过程中以流式方式实时呈现，因此您可以在完整建议仍在准备时就开始阅读。

您可以为所有非本体论概念节点添加实现计划。AIP Architect 将根据提供的上下文自动将各节点连接在一起。您还可以添加其他概念节点（例如分析节点或建模节点），方法是选择左侧工具栏中的 概念 图标。

用户可以修改 AIP Architect 生成的计划。AIP Architect 在为工作流的其他部分生成实现时，会将用户所做的更改纳入考虑。

本体论节点

本体论节点与其他概念节点的不同之处在于， 选择实现 下拉菜单会被替换为 生成数据模型 下拉菜单。 生成数据模型 下拉菜单提供了一个用户可编辑的提示词，您可以在其中描述您希望本体论模型呈现的样子；根据此提示词，AIP Architect 将在图谱上生成一组对象类型、对象类型属性和关联类型。

模型选择

AIP Architect 使用大语言模型来生成工作流计划和实施建议。如果您的环境中有多个可用的 AI 模型，您可以选择要使用的模型：

  1. 打开 AIP Architect 选项卡（位于 Solution Designer 中）。
  2. 导航至 模型选择 部分。
  3. 从可用选项中选择您偏好的模型。

不同的模型可能会生成不同风格的建议，或具有不同的优势。选择模型时，请考虑以下因素：

  • GPT-5（推荐）： 性能均衡，具备强大的架构推理能力，并支持视觉功能。
  • 专用模型： 某些模型可能针对特定领域或用例进行了优化。
  • 可用性： 模型取决于您组织的 AI 配置和许可情况。

所选模型将应用于所有 AIP Architect 操作，包括抽象图谱生成、实施模式建议和上下文解释。

如果 AIP 功能不可用，请验证 已为您的租户启用 AIP 并且已配置至少一个受支持的 LLM。如果您需要访问 AIP 功能，请联系您的 Foundry 管理员。

构建您规划的工作流

生成工作流计划后，您就可以开始使用 AIP Architect 实际构建工作流。左侧的 AIP Architect 侧边栏会显示工作流实施计划的概览，该计划是根据工作流图自动生成的。

AIP Architect 将使用 Walkthrough 助手引导您完成工作流的创建过程。要开始操作，请选择 保存并开始构建.

此时，系统将显示 AIP Architect Walkthrough 面板，为您提供实际实施过程的分步指南。您可以跳转到演练的任意部分，或使用顶部的 下一步 和 上一步 导航按钮按顺序浏览各步骤。

从这里开始，您可以使用所示的应用程序来构建可运行的工作流。
