事务选择器

以下列表描述了在 Retention 应用中配置保留策略时可使用的事务选择器。

以下文本中的 this format 表示可在每个策略上定义的参数。

仅存在于分支中

删除出现在 唯一 给定分支中的事务。

接受 1 个参数： branch

示例： "仅存在于分支中 main"

设置"仅存在于分支中 main"将不会删除前两个 SNAPSHOT 事务，因为它们也是 SNAPSHOT 功能分支上事务的根事务。

不存在于分支中

删除除给定分支中的事务之外的所有事务。

接受 1 个参数： branch

示例： "不存在于分支中 main"

事务数量

事务数量选择器允许您定义要保留的事务，而不是指示要删除的事务。

仅保留属于 number of transaction to retain 任意分支上最近包含数据的事务之列的事务。当且仅当以下条件成立时，事务才被定义为包含数据：

  • 事务已提交。
  • 事务不是 DELETE transaction.

所有已中止的事务都不包含数据，将被删除。由于此选择器不区分 SNAPSHOT, APPEND，或 UPDATE 事务，我们建议在增量管道中使用 viewCount 选择器。

接受 1 个参数： number of transactions to retain

示例： "事务数量 2"

此选择器确保每个分支上至少有 2 SNAPSHOT 个事务可用。功能分支可能有 3 个事务；最旧的事务同时也是分支 main上的第 2 个事务，因此不会被删除。

视图数量

视图数量选择器允许您定义视图中要保留的事务，而不是指示视图中要删除的事务。

视图数量选择器仅保留最近 number of views to retain 数据集视图中的事务。由于视图被定义为仅包含已提交的事务，因此所有已中止的事务也会被删除。例如， numViewsToRetain: 1 表示最新视图之前的所有事务（即最新 SNAPSHOT 事务之前的所有事务）以及所有已中止的事务都将被删除。

接受 1 个参数： number of views to retain

示例： "视图数量 1"

早于特定时长

此选择器选择早于给定时长的事务。

接受 1 个参数： duration

已被投影（高级）

对于具有 投影的数据集，此选择器选择已传播到所有投影的事务。

活动视图中无文件（高级）

此选择器会选择所有不在最新视图中的事务。它还会选择最新视图中其文件已全部被较新事务中的文件取代的事务。将其与 允许从最新视图删除 一起使用，以允许保留策略删除仍属于该视图的已被取代的事务。

忽略隐藏文件

隐藏文件是指不包含数据集数据的文件。如果文件名以 .开头，或以 _ 开头且不包含 =的源（例如 _driver.log。当返回 忽略隐藏文件 被禁用时， 活动视图中没有文件 在确定某个事务在活动视图中是否仍有文件时，会考虑这些文件。

忽略隐藏文件 是 活动视图中没有文件 选择器的一个选项。启用它后，在评估该选择器时仅考虑数据文件。这样，即使某个事务的隐藏文件仍然存在，只要其数据文件都不在活动视图中，该事务就可以被选中。

仅存在于早于特定时长的视图中（高级）

选择仅存在于早于给定时长的视图中的事务。视图年龄定义为视图中最新事务的关闭时间与当前时间之间的时间差。如果视图中有未关闭的事务，则该视图中的任何事务都不会被删除。

接受 1 个参数： duration

是派生的（高级）

选择派生的事务。这些是通过运行 build 生成的事务。通过手动上传数据或通过 Data Connection 创建的事务不被视为派生事务。
