空值处理

A null 值表示缺失或未知的数据。本页面介绍 Pipeline Builder 如何处理 null 值在筛选器所使用的条件中， 连接，而 条件分支 转换的代码中。

条件与空值

筛选器、Case 条件和连接匹配条件都会评估一个布尔条件，该条件可能返回三种结果之一： True, False，或 null。只有当条件的结果为 True。一个 False or null 结果时，条件才被视为满足。

Pipeline Builder 提供两种相等形式，它们在空值安全性上有所不同：

  • 等于 and 不等于 是空值安全的：比较 null to null returns True，以及比较 null 与任何其他值会返回 False。当你希望对 null 值进行比较和匹配时，请使用这些运算符。
  • 等于（非空值安全） and 不等于（非空值安全） return null 如果任意一侧为 null。当你希望排除涉及 null 的值时，请使用这些运算符。

若仅测试数据是否缺失，请使用 为空 和 不为空。这些运算符始终返回 True or False.

各转换如何使用结果

  • 筛选器： 仅在条件满足时保留该行。返回 False or null 的行将被移除。
  • Case： 按顺序评估每个分支条件，并返回第一个条件满足的分支的值。返回 null 结果的条件被视为不满足，该分支将被跳过，因此该行会继续落入下一个分支或默认值。
  • 连接： 仅在匹配条件满足时才匹配两行。返回 null 结果的条件被视为不满足，因此这两行不匹配。在内连接中，未匹配的行会被丢弃；在左连接、右连接或外连接中，这些行会被保留，并 null 为来自不匹配一侧的列填充

当条件比较的列可能包含 null 值时，请使用空值安全的相等运算符或显式的 为空 检查，以便按照你的意图处理缺失数据。
