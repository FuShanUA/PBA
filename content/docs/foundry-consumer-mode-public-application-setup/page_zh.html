设置公共应用程序

以下各部分中的说明概述了设置 公共应用程序 的端到端流程，涉及 开发者控制台 和 控制面板。

需要信息安全官审查

公共应用程序会向公共互联网上的任何人公开本体论数据和操作。每个应用程序都需要您注册中的一名 信息安全官 来 在启用前审查并批准预期用例。请先与您的 信息安全官 讨论您的预期用例、公开的本体论资源以及目标受众，然后再完成以下在开发者控制台中创建公共应用程序的步骤。

先决条件

在设置公共应用程序之前，请确保：

  • 您的 Foundry 注册支持公共应用程序。如果您不确定，请联系 Palantir 支持团队。
  • 您拥有 开发者控制台权限 ，这是创建新应用程序所必需的。
  • 您可以在您的注册中找到一名 信息安全官 ，其既能批准该用例，也能批准控制面板中的子域注册。这两项批准均由同一角色执行。
  • 您有权取消每个 标记 在您打算添加到应用程序中的每个资源上。如果不这样做，Foundry 将阻止添加该资源，因为该资源不符合相应的出口管制要求。

步骤 1：在开发者控制台中创建应用程序

  1. 导航到开发者控制台并选择 + 新建应用程序。
  2. 逐步完成创建向导，并在 资源 页面上启用本体论 SDK。
  3. 展开 高级 部分，该部分位于 应用程序类型 步骤中，然后选择 公共应用程序。

  1. 继续完成开发者控制台的创建流程，并选择 创建应用程序。

公共应用程序在读取或写入数据时会使用服务用户进行权限验证。当您在开发者控制台中创建应用程序时，Foundry 会创建该服务用户；此后，您可以将 Foundry 资源的权限授予该服务用户。

步骤 2：请求无需身份验证的子域名和无需身份验证的端点

  1. 选择 网站托管 （位于左侧面板）。
  2. 输入子域名，然后选择 请求应用程序域名。Foundry 将通过以下网址为您的应用程序提供服务： <your-subdomain>.<your-enrollment>.palantirfoundry.com。 请求在自定义域名上托管 ，以在您选择的域名上托管应用程序，例如 custom-domain.com。

  1. 当您为公共应用程序请求域名时，Foundry 会自动请求一个公共互联网域名，使未经身份验证的用户能够访问该应用程序并加载其静态资源。请确认您是否希望您的公共应用程序额外 启用未经身份验证的 Foundry API 调用，该选项会在无需身份验证的情况下公开所有 OSDK 资源。选中该复选框以启用此功能，然后选择 请求 以继续。

  1. 如果您选择 启用未经身份验证的 Foundry API 调用，Developer Console 会提示您确认用户能够发起未经身份验证的 Foundry API 调用所带来的额外风险。请选择 提交请求 ，但需先逐一审阅并确认每一项。

步骤 3：在 Control Panel 中为公共应用程序请求审批

您所在注册中的 信息安全官 必须批准您的子域名注册请求，审批在 Control Panel 的 审批收件箱中进行。

如果您是 信息安全官，请按照以下说明审阅并批准该请求：

  1. 请审阅 理由说明 部分中的内容，以判断请求者的使用场景是否有效。
  2. 请确认该公共应用程序请求针对的是未经身份验证的子域名，并检查其是否启用了未经身份验证的 Foundry API 调用。审批表单中的 审阅者任务 部分会明确说明是否 此域已禁用通过 Multipass 进行的身份验证 或 此子域已启用免身份验证端点 以指示其中一个或两个条件是否为真。
  3. 批准， 拒绝，或 关闭 该请求。

步骤 4：等待域准备就绪

在 信息安全官 于 Control Panel 中批准您的请求后，返回至 Developer Console 中的 网站托管 标签页并刷新页面。几分钟后，域状态将从 预配中 转换为 域就绪。Developer Console 还会显示一个状态标签，用于指示该应用程序是否启用了未经身份验证的 API 调用。

请查阅 Developer Console 文档 ，以了解有关使用 OSDK 构建纯前端应用程序的更多信息。

步骤 5：添加未经身份验证的本体论资源

如果您的公共应用程序启用了未经身份验证的 API 调用，接下来可以选择 Developer Console 中的 Ontology SDK 标签页，以将所有必需的对象类型和操作类型添加为应用程序 资源。Foundry 强制执行 针对公共应用程序的严格出口管制，因此只有在您有权对其所有标记和组织标记解除密级时，才能添加资源。Foundry 将公共应用程序限制为少量本体论操作，因此您应查阅 当前支持的操作列表 以便在填充应用程序资源之前确认您预期的工作流程是否受支持。

将所有相关本体论资源添加到应用程序后，Developer Console 会提示您在保存前审查每项更改。保存后，应用程序范围内的所有资源将无需身份验证即可访问。

步骤 6：创建关联的代码仓库

在您 Public Application 的 Ontology SDK 资源添加完毕后，接下来您将按照以下步骤创建一个 代码仓库 ，并将其关联到您的应用程序：

  1. 选择 代码仓库 ，该选项位于 Developer Console 中您应用程序的 Development 部分。
  2. 从 Authless code template创建一个新的代码仓库。该模板为使用无身份验证的本体论 API 的网站提供了所需的脚手架。
  3. 等待网站的初始构建完成。构建状态会显示在您代码仓库的 Tags 标签页中，而指向您网站的链接会显示在 Website hosting下。

您关联的代码仓库中存放着您 Public Application 的代码。请查阅 Developer Console 文档中的现有操作指南，了解如何 将您的 OSDK 添加到应用程序 并以多种语言引导其开发，例如 TypeScript、 Python或 Java。

步骤 7：验证未经身份验证的访问

在无痕或隐私浏览器窗口中打开您公共应用程序的子域名 URL，应用程序将正常加载，而不会显示 Foundry 登录提示。
