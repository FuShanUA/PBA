停止维护

Foundry Rules 的时间序列功能目前处于 停止维护 阶段，并将在未来的某个日期被弃用。目前仍提供全面支持。我们建议您将工作流迁移到 时间序列警报自动化 ，以满足任何新的时间序列规则需求。

除了对数据集和对象进行操作外，Foundry Rules 还允许用户管理使用时间序列数据的规则。借助 Foundry Rules，用户可以编写规则来识别数据中感兴趣的时间段。这些时间间隔由 Foundry Rules 以行的形式输出，可在下游使用，用于警报或其他用例。Foundry Rules 目前支持转换现有时间序列，例如使用聚合、公式和导数，以及基于多个条件识别时间间隔。

Foundry Rules 基于 Foundry 中的 时间序列 构建，并支持 时间序列属性 和度量。

要在 Foundry Rules 中使用时间序列，请遵循 部署说明。

时间序列看板

规则可以包含所有标准的 Foundry Rules 逻辑，以及两种类型的时间序列看板： 添加时间序列 和 时间序列搜索。

“添加时间序列”看板

添加时间序列板块接受一个序列作为输入，并生成一个修改后的序列，供后续板块使用。转换后的序列通过名称 (1) 和操作 (2) 定义，并附带该操作所需的配置。例如，下图所示的板块添加了一个新序列 $baseline，该序列是使用1000天的滚动聚合创建的。可以使用“预览时间序列”按钮 (3) 预览生成的时间序列。

时间序列搜索板块

时间序列搜索板块根据指定的条件为输入集中的每个对象生成区间。条件可以引用与原始根对象关联的序列，以及由先前的 添加时间序列 板块创建的任何序列。对象上现有的度量以 @为前缀，而作为规则一部分添加的任何序列则以 $为前缀。匹配条件的区间也可以使用“预览区间”按钮进行预览。

对于输入中的每个根对象，一组匹配的区间将作为一系列包含区间数据的列存在于输出数据集中：开始时间、结束时间和持续时间。
