创建模型适配器

创建模型适配器有两种主要方法：

  • 通过独立的 模型适配器库 模板，适配器将作为 Python 库 发布到您的 Foundry 环境中，供多个使用方仓库共享。
  • 通过在模型发布来源的资源本地定义适配器类：
    • 在代码仓库中使用 模型训练模板.
    • 在 Jupyter® 代码工作区中，通过在与 notebook 分离的 Python 文件中定义适配器。

直方图 模型适配器库 模板适用于以下情况：

  1. 容器支持的模型
  2. 外部模型
  3. 创建可跨仓库共享的模型适配器

直方图 模型训练 模板适用于大多数在 Foundry 中通过 Code Repositories 中的 Python 转换创建的模型。通过将模型适配器定义集成到转换仓库中，您可以比使用 Model Adapter Library 模板。

在 Jupyter® 工作区中训练模型时，适配器必须在单独的 .py 文件中定义并导入到 notebook 中。

模型适配器库模板

要创建容器、外部或可重用的 Python 转换模型适配器，请打开 Code Repositories 应用程序 ，然后选择 模型适配器库.

直方图 模型适配器库 在 src/model_adapter/ 目录中包含一些示例实现。使用此模板生成的模型适配器具有可配置的包名称，初始名称从仓库名称派生。您可以在隐藏的 condaPackageName 文件中查看和修改 gradle.properties 值（空格和其他特殊字符在 - 发布的库中将被替换为

与其他 Python 库仓库一样，标记提交将发布新版本的库。这些已发布的库可以导入到其他 Python 转换仓库中，用于模型训练和推理。

一个仓库可以发布多个模型适配器。任何额外的适配器实现文件必须作为引用添加到 build.gradle 适配器模板的隐藏文件中的模型适配器模块列表中。默认情况下，只有 model_adapter.example_adapter 会被发布。

适配器的实现取决于所生成的模型类型。详情请参阅 外部模型适配器文档，或查看 容器模型适配器示例.

模型训练模板

要使用 Code Repositories 在 Foundry 中直接创建模型，请打开 Code Repositories 应用程序 并选择 模型训练 模板。此仓库允许您编写 Python 数据转换 来训练模型并运行推理。

使用此模板生成的模型适配器无法自定义包名称或进行标记。适配器将在名为 transforms-model-training-<repository rid>的库中发布，版本将从 Git 提交派生。包的完整名称和版本可以在 Palantir 模型页面上查看。必须将此库添加到下游仓库中，才能将模型作为 ModelInput加载。如果这不适合您的使用场景，模型适配器库模板允许您同时配置版本和包名称。

要了解更多信息，请阅读 使用训练模板在 Foundry 中训练模型.

代码工作区

要在 Jupyter® 工作区中创建模型，请打开 链接进行访问。 左侧边栏中的选项卡并选择 Add model > Create new model。将生成一个骨架模型适配器，位于以您为模型提供的别名命名的 .py 文件中。

在 Jupyter® 工作区中，适配器类必须定义在单独的 .py 文件中并导入到 notebook。不支持直接在 notebook 单元格中定义适配器类。发布模型时，适配器和工作目录中的其他 Python 文件会被打包成一个名为 cws_adapter的库，版本号根据最新的 Git 标签生成。

要了解更多信息，请阅读 在 Jupyter® notebook 中训练模型.
