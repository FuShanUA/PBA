定义并运行 Slate 函数

直方图 函数编辑器 允许您在可通过 Handlebars 访问的项目（例如查询结果、全局变量和小组件属性）上定义并运行 JavaScript 函数。

Slate 函数仅在 Slate 中可用，与 Foundry 函数不同；Foundry 函数可在整个平台范围内访问。您可以在 Slate 中使用 Slate 平台编辑器访问 Foundry 函数。请参阅 函数文档 的文档以获取更多信息。

您还可以在 Slate 函数中使用 Platform SDK (PSDK)来调用 Foundry API。Slate 为支持的 SDK 版本提供了预配置的客户端和代码补全功能。

函数无法访问 DOM 或 Slate 空间 且不会保存任何状态。

函数通常用于轻量级数据处理任务，例如字符串解析。函数支持异步语法（包括 async, await 关键字和 promise）。

函数按顺序运行，而非并行运行。Slate 会从队列中一次执行一个函数，因此每个函数必须完成后才能开始下一个。即使函数使用异步调用，这一点也适用：等待长时间运行操作的函数会阻塞队列，直到其完成，从而延迟后续的所有函数。请避免依赖函数并发运行。

文档级函数库

用户可以编写带参数的可重用 JavaScript 函数。这有助于重构代码并减少函数中代码的复制粘贴。您还可以使用 重新运行所有函数 按钮。

默认可用的 JavaScript 库

为了增强函数的使用，Slate 默认附带以下外部 JavaScript 库： Lodash ↗, Math.js ↗, Moment ↗, Numeral ↗日 es6-shim ↗。在编写函数时，欢迎随意使用这些库。

除非所有用户都被要求使用支持这些特性的浏览器，否则请勿使用 ES6 语法特性。

上传自定义外部库

您可以上传外部 JavaScript 库以在 Slate 函数中使用：

  • 应用程序库： 在 函数 面板中添加库。这些库仅在该 Slate 应用程序中可用。
  • 平台范围的库： 使用直方图中的 管理面板 为您的 Foundry 实例中的所有用户和应用程序上传库。

示例 1：添加两个 widget 属性

此函数将两个下拉小组件的值相加，并在文本小组件中显示结果。

打开函数编辑器并添加一个名为 addNumbers的函数。添加以下 JavaScript 代码：

然后，在文本小组件中，通过在 Handlebars 中引用函数名称来显示返回值 {{addNumbers}}.

函数编辑器不接受任何类型的 辅助函数 。

此函数解析查询结果中的每个元素。假设有一个名为 asteroids 的查询，它返回以下 JSON：

var asteroids = {{asteroids}};
var formattedNames = [];
var circumference = [];

for (var i = 0; i < asteroids.name.length; i++) {
  formattedNames.push(formatName(
    asteroids.name[i], asteroids.id[i]));
  circumference.push(asteroids.diameter[i] * 3.14);
}

return {
  name: formattedNames,
  diameter: asteroids.diameter,
  circumference: circumference
};

function formatName(name, designation) {
  return name + " (" + designation + ")";
}
