日志搜索

该 搜索日志 标签页位于 Workflow Lineage 中,可让您搜索过去 30 天内由选定的源执行器生成的所有 服务日志 。与针对单次执行的服务日志视图不同,日志搜索会聚合给定源执行器发起的每次执行所产生的日志,因此适用于排查反复出现的错误,或在多次运行中查找特定日志消息。

源执行器是调用链中的第一个可执行资源,可以是函数、操作、自动化、AIP Logic、AIP Agent 或模型实时部署。当函数由另一个资源(例如 AIP Logic、语言模型或 AIP Agent)支撑时,日志搜索面板会将支撑资源(而非底层函数)显示为源执行器。

访问日志搜索

要访问日志搜索:

  1. 打开 Workflow Lineage 并导航到包含您的资源的工作流。
  2. 选择一个可执行资源节点。
  3. 选择底部面板中的 搜索日志 标签页。

搜索日志

搜索栏位于 搜索日志 面板顶部,接受文本查询。输入搜索词后,结果将填充到结果表中。搜索区分大小写,并匹配完整的日志行,包括 消息 和 Content 字段。

您可以使用 * 作为通配符来匹配任意字符序列。例如：

  • connection failed 匹配包含确切短语 "connection failed" 的日志行
  • timeout*retry 匹配包含 "timeout" 且后跟 "retry"（两者之间可以有任意字符）的日志行
  • Error 匹配 "Error"，但不匹配 "error" 或 "ERROR"

“搜索日志”选项卡会显示所选资源作为 源执行器的执行日志。该资源被其他资源调用时产生的日志不会包含在内。在下面的示例中，该函数在执行期间产生了日志，但它并非源执行器——它是由某个自动化调用的。从该函数进行搜索不会返回任何结果；要查找这些日志，请改为从自动化节点进行搜索。

源执行器建议

如果未找到所选资源的任何日志， “搜索日志” 面板会检查该资源最近是否被其他源执行器调用，并将这些源执行器显示为建议。选择某个建议的源执行器，即可导航到图中的相应节点并改为搜索其日志。面板标题还会显示一个 “最近也由以下资源执行” 指示器。您可以选择此指示器来查看并导航到源执行器。

筛选结果

筛选器侧边栏位于 搜索日志 面板左侧，可帮助您缩小日志结果范围。选择筛选器图标可展开或折叠该侧边栏。可用的筛选器如下：

  • 日志级别： 按严重级别筛选日志。从下拉列表中选择一个日志级别，以仅显示与该级别匹配的日志。可用的级别包括 ERROR、 FATAL、 WARN、 INFO、 DEBUG和 TRACE。默认情况下，将显示所有日志级别。
  • 时间戳范围： 将结果限制在特定的时间窗口内。您可以从预定义的相对时间范围中进行选择，例如 Past 1 day 或 Past 1 hour，也可以指定自定义日期和时间范围。默认范围为 Past one day。可选择的最大范围为 30 天，与日志保留期一致。
  • 产出资源： 按产出日志的资源筛选日志。当源执行器的调用链包含多个下游资源，而您希望单独查看来自特定函数、操作、自动化、AIP 逻辑或 AIP 智能体的日志时，可使用此筛选器。选择该筛选器旁边的清除按钮可移除所选内容。

当多个筛选器处于活动状态时，它们将通过 AND 逻辑进行组合；仅返回与所有选定筛选器匹配的日志条目。选择 重置 （位于侧边栏顶部）以清除所有筛选条件并返回默认视图。

了解结果表

搜索结果显示在按时间戳排序的表格中，最新的日志排在最前面。该表格包含以下列：

列描述
日志级别颜色编码的图标，用于指示严重程度：红色表示 ERROR 和 FATAL，橙色表示 WARN，而中性色表示 INFO、 DEBUG和 TRACE
时间戳记录该日志条目的日期和时间
消息主要日志消息。选择该字段可打开详情对话框
内容额外的结构化内容，通常采用 JSON 格式。选择该字段可打开详情对话框
生成资源发出该日志条目的资源

与搜索查询匹配的文本会在 消息 和 内容 列中高亮显示。

将鼠标悬停在日志行上时， 查看追踪 按钮会显示在该行的右侧。选择此按钮可打开 追踪视图 ，查看产生该日志条目的执行。这样，您就可以查看完整的执行时间线，并确定日志是在调用链中的哪个位置发出的。

查看日志详情

选择任意 消息 或 内容 单元格以打开包含完整日志条目的详情对话框。该对话框提供：

  • 消息 和 内容 选项卡，用于在两个字段之间切换
  • 一个文本搜索栏，用于在日志条目中查找特定内容
  • 一个 自动换行 开关，便于阅读较长的日志行
  • 针对结构化内容的自动 JSON 格式化

日志保留和分页

日志搜索涵盖最近 30 天的日志。超过 30 天的日志会被自动删除，且无法恢复。结果以每页 100 条的方式加载。滚动到表格底部可加载更多结果。日志不会实时流式传输；要查看初始搜索之后产生的新日志，请刷新页面。

权限

日志搜索使用与 执行历史相同的权限模型。要搜索某个资源的日志，您必须拥有该资源的 编辑 权限。如果已为源执行者的项目启用日志访问，并且您拥有所有必需标记的访问权限，则可以搜索所有执行的日志。如果未启用日志访问，您只能搜索过去 24 小时内自己执行的日志，但您仍必须拥有该资源的 编辑 权限。在 CBAC 堆栈，此自执行例外不适用；必须启用日志访问才能搜索日志。

有关日志访问配置的完整详细信息，请参阅 日志权限。
