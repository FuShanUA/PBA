编辑元数据

晚于 创建您的用例 通过现有或新的支撑 Project，您可以修改有助于定义您的用例的元数据。这些元数据可以在您的用例概览页面中找到，包括用例名称、描述、所有者和状态。

名称

点击页面顶部的用例名称并在文本字段中进行编辑，即可更改您的用例名称。

描述

点击页面顶部的描述并在文本字段中进行编辑，即可更改您的用例描述。 作为构建者，您可以使用此字段来记录用例，描述其用途以及任何有助于日后维护的相关信息。

在相关情况下，在用例的描述或文档中记录该用例所需的数据、受影响的利益相关者、访问边界、审查点和保留期限预期。这为未来的构建者和审查者提供了保持预期目的所需的背景信息。审查 实践中的隐私与公民自由 以了解在规划过程中需要考虑的问题。

您还可以通过导航到应用程序页面并编辑描述字段，为用例中的每个应用程序添加描述。

文档

您可以使用 Markdown 语言查看和编辑用例文档。选择以展开文档部分 Show documentation > Edit.

在 Markdown 编辑器中，使用 编写 选项卡输入或更新用例文档，以及 预览 选项卡在保存前查看您的更改。

要编辑用例文档，您必须拥有 用例编辑者或所有者角色 以及项目的编辑权限 封面页面 因为用例文档存储在支撑项目的封面页面上。

所有者

您可以为用例分配两种类型的所有者： 技术 和 业务。两者都可以分配给单个用户或群组。

  • 技术所有者： 技术所有者通常是正在开发用例的应用程序构建者。

    • 创建用例的用户是该用例的默认技术所有者。

  • 业务所有者： 业务所有者通常是跟踪用例工作流进度和财务细节的用户。

    • 您的用例没有默认分配的业务所有者。

要更改用例的所有者，请将鼠标悬停在名称或空白字段上并选择铅笔图标。这将打开一个搜索下拉菜单，您可以在其中滚动浏览或搜索可用的用户或群组。

状态

您可以为用例分配与其运行状态相关的状态：

  • Active（活跃）： 已在您的 Foundry 实例中发布并运行。
  • Experimental（实验性）： 正在进行中，尚未正式发布。
  • Deprecated（已弃用）： 不再运行。

要将我们的用例状态从 Experimental to Active更改，请选择状态下拉菜单，选择 Active，然后点击 更改状态.

如果当用例的对象类型或操作类型处于 Active 状态时，您将用例状态更改为 Experimental or Deprecated 状态下拉菜单附近和左上角侧边栏中会出现警告标志，表示资源状态与用例状态之间存在不一致。我们通常不建议造成这种差异。
