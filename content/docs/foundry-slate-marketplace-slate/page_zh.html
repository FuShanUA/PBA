将 Slate 应用添加到 Marketplace 产品

用途 Foundry DevOps 以将您的 Slate 应用包含在 市场产品 中，供其他用户安装和复用。Marketplace 支持单页和多页 Slate 应用，包括不加载数据的静态应用。所有页面、路由和页面结构在打包和安装过程中都会保留。 了解如何创建您的第一个产品。

本页面介绍 Slate 应用的打包。有关 Developer Console 应用的信息，请参阅 使用 Marketplace 安装 Developer Console 应用.

将 Slate 应用添加到产品

要将 Slate 应用添加到产品，请先 创建一个产品，然后选择 功能，并选择。选择 添加文件 选项，以便从 Compass 文件系统中导航到 Cipher 资源，并将其添加到您的产品中。

使用 Marketplace 参数变量打包 Slate 应用

您可以将 局部变量 标记为 Marketplace 参数，允许用户在产品安装过程中自定义其值。这对于配置各安装实例的设置和默认值非常有用，无需在安装后修改 Slate 应用代码。

要将变量标记为 Marketplace 参数：

  1. 打开 变量 面板，该面板位于您的 Slate 应用中。
  2. 选择您想要使其可配置的局部变量。
  3. 选择该变量的菜单并启用 Marketplace 参数 选项，然后选择类型（字符串或布尔值）。

被标记为 Marketplace 参数的变量将在 变量 面板中显示视觉指示符。当用户安装产品时，可以在安装过程中为这些参数提供自定义值。

只有主文档页面上的局部变量可以标记为 Marketplace 参数。共享变量以及多页应用中其他页面上的变量目前不支持作为 Marketplace 参数。

打包使用 Code Sandbox 部件的 Slate 应用

Code Sandbox 部件依赖外部库的 Slate 应用可以通过 Marketplace 打包。

如果您希望在安装时生成库文件的副本，请确保在创建产品时将这些库的文件包含在 文件 管理速率限制 内容 选项卡中。当用户安装该产品时，他们将在自己的项目中获得这些文件的副本。Code Sandbox 部件随后将引用他们的库文件副本。

Slate 还支持通过 CDN 链接提供库（例如， https://unpkg.com/browse/chart.js@2.7.1/）。CDN 链接保持不变，因此安装后的 Slate 应用将具有相同的 CDN 链接。这可能意味着用户需要配置其 CSP 以允许这些 CDN 链接。

有关在 Code Sandbox 部件中使用库的更多信息，请参阅 Code Sandbox 部件文档.

打包使用 Ontology SDK 的 Slate 应用

使用 本体论 SDK （OSDK）的 Slate 应用可以通过 Marketplace 打包。Foundry DevOps 会在打包过程中自动处理 OSDK 本体论依赖，因此无需手动配置依赖。

OSDK 打包的工作原理

当您发布使用 OSDK 的 Slate 应用时，预构建的 OSDK 包会自动包含在 Marketplace 包中。这意味着在安装过程中，该包将被直接复制而不是从头重新生成，从而显著缩短安装时间。

重新打包现有应用以加快安装速度

在预构建包优化推出之前打包的 Slate 应用在安装时仍会重新生成 OSDK 包。要利用更快的安装速度，请发布现有 Marketplace 产品的新版本。新版本将自动包含预构建的 OSDK 包。

要重新打包您的应用：

  1. 在 Foundry DevOps.
  2. 中打开该产品。
  3. 创建产品的新版本。

发布新版本。

无需对 Slate 应用本身进行任何更改。预构建的包会在发布过程中自动包含。

如果 API 名称不匹配，Slate 函数代码将与目标环境中的本体论实体不匹配。不匹配的问题可以在安装后通过手动更新 Slate 函数代码来解决。

在以下情况下，安装过程中可能会发生 API 名称冲突：

  • 当目标环境中存在具有相同 API 名称的本体论实体时。例如，如果两个环境都有一个名为 flights.
  • 当对象的 API 名称与其显示名称不匹配时。例如，如果一个显示名称为 flights 的对象类型的 API 名称为 flightsXYZ，则在安装时它将被赋予默认 API 名称 flights 。在这种情况下，Slate 函数代码将不再与 API 名称匹配，并且如果已存在 API 名称为 flights 的对象类型，则可能会发生命名冲突。

这适用于所有本体论实体，包括对象类型、关联类型、操作类型和函数。

为防止 API 名称冲突：

  • 使用描述性的显示名称，以使生成的 API 名称不太可能与现有名称冲突。
  • 检查目标环境中的现有对象类型。
  • 如果 API 名称在安装过程中发生更改，请准备好更新 Slate 函数代码。

仅支持最新版本的函数。在将 OSDK 与 Marketplace 一起使用时，不支持版本化函数。如果您的应用程序引用了较旧版本的函数，请将其更新到最新版本并重新打包您的应用程序。

不支持的功能

使用 Marketplace 打包 Slate 应用程序时，不支持以下功能：

  • 不支持自定义数据源（包括 Postgres 查询）。 API Gateway 是唯一支持的数据源。有关更多信息，请参阅 API Gateway 查询.
  • 不支持全局样式表。
  • Foundry Form and Time Series 不支持小组件。
