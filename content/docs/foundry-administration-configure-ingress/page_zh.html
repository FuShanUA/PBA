配置网络入口

网络入口是指从 Foundry 外部发起的连接。在使用我们托管的软件即服务（SaaS）平台时，Control Panel 提供允许列表配置，用于定义可以从何处建立此类连接。

必须在 Control Panel 中配置适当的网络入口规则，以便用户登录并浏览 Foundry，以及支持需要访问 Foundry 的进程， 例如为 Data Connection 设置代理。

您的注册可能尚未开通在 Control Panel 中配置网络入口的功能。

在 Control Panel 中配置网络入口

配置网络入口允许列表的功能可在 网络入口 选项卡（位于 Control Panel）中使用。拥有信息安全官或注册管理员角色的用户可以使用此功能。这些角色由注册管理员 在 注册权限 选项卡（位于 Control Panel）中授予。

支持两种类型的规则：

  • 在 允许的 IP 地址范围 部分：可指定采用 CIDR 表示法的 IPv4 地址范围，并允许从这些范围建立入口连接。最多可配置 500 个 CIDR 块。
  • 在 允许的国家/地区 部分：可指定入口连接的来源国家/地区。

规则采用累加方式；只要满足基于 IP 的规则或国家/地区规则中的任意一条，即可建立连接。

通过虚拟专用网络 (VPN) 连接的用户，将基于该 VPN 的出口 IP 判断是否允许访问。

注意事项：基于国家/地区的允许列表

使用基于国家/地区的允许列表而非严格的基于 IP 的允许列表时，请务必了解便利性与安全性之间的权衡。虽然仍需要身份验证，但使用宽泛的网络允许列表可能会大大增加以下风险：

  • 基于身份的攻击
    • 示例：身份验证材料泄露、账户接管、暴力破解和凭据窃取。
  • 社会工程攻击和基于 Web 的攻击
    • 示例：中间人攻击、DNS 投毒以及其他有针对性的网络钓鱼。
  • 对底层基础设施和应用程序的漏洞利用
    • 示例：零日漏洞利用。

Palantir 建议采用严格的 IP 允许列表作为纵深防御控制措施，通过拒绝攻击者实施攻击所需的网络访问权限，来显著降低这些风险。

基于国家/地区的允许列表通过对传入连接的 IP 进行地理标记来运作。此行为可能受到 Palantir 用于实现此功能的第三方数据质量问题的影响。可能会出现误报和漏报，这对于 IP 地理标记工具而言属于预期现象。

提交变更请求

鉴于配置网络入口的敏感性，所有入口变更都必须经过 审批工作流。完成修改后，选择 请求变更 选项（位于页面右下角），并为变更提供理由。对于入口配置存在建议变更的每个域，将分别创建审批请求。默认情况下，管理员可以批准自己的入口变更请求。但是，审批工作流可确保变更在生效前得到审查，并提供所有修改的历史记录。

高级设置

在 高级设置下，您可以开启或关闭 Palantir 访问 ；开启 Palantir 访问 后，即可启用来自 Palantir 企业网络的入口网络访问，而无需显式允许 Palantir 的企业 IP。

Palantir 访问 如果您正获得 Palantir 工程师的支持，而这些工程师通过专用身份验证提供商和 Palantir 网络访问您的注册环境，则通常应开启此设置。请注意，Palantir 访问通过 VPN 进行，并不局限于某一个地理区域。

与 IP 和国家级别允许列表类似， Palantir 访问 设置是叠加的：如果您的网络入口配置允许来自美国的连接，并且启用了此开关，则将可以从美国以外的企业网络位置进行访问。
