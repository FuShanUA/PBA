将您自己的模型接入 AIP

自带模型(Bring-your-own-model, BYOM),在 Palantir 平台中也称为注册模型(registered models),是一项功能,可为希望在各类 Palantir 开发者产品中将自己的 LLM 或账户连接到 AIP 的客户提供一流支持。这些产品包括 AI FDE、AIP Analyst、AIP Chatbot Studio、AIP Logic、Workshop、代码仓库(Code Repositories)中的 TypeScript 函数、管道构建器(Pipeline Builder,即将推出)等。

为了提供更大的灵活性并支持诸如面向数据主权的自托管模型等能力,平台支持通过多种方式为注册模型提供支撑;请查阅下方 模型来源 部分,以了解更多信息。

何时使用

根据 LLM 支持情况和可行性,我们通常建议使用由 Palantir 提供的、来自模型提供商(例如 OpenAI、Azure OpenAI、AWS Bedrock、xAI、GCP Vertex)的模型,或使用由 Palantir 自托管的开源模型(例如 Llama 模型)。

但是,您可能更希望将自己的模型或账户接入 AIP。我们建议仅在以下情况下使用注册模型:您因法律和合规原因无法使用 Palantir 提供的模型,或者您拥有自己微调的或具有其他独特性的 LLM,并希望在 AIP 中加以利用。

我们于 2026 年 3 月推出了已注册模型的新实现，以提供针对最常见模型提供商 API 优化的简化集成，本页面对此进行了介绍。这一新实现在更多 AIP 应用（如 AI FDE 和 AIP Analyst）中提供了更优的性能和操作功能。它还支持原生工具调用和推理，同时为 AIP 提供基础设施工具，例如启用速率限制、 Resource Management中的使用情况可观测性、 Control Panel中的权限控制以及模型选择器。得益于这些增强功能，我们建议使用新实现，而不是此前通过 函数接口注册 LLM 的方法。

如果您之前使用函数接口注册过模型，请参阅 《使用函数接口注册 LLM [旧版]》文档。如果已注册模型无法很好地满足您的用例，请联系 Palantir 支持团队。

支持的应用和功能

已注册模型的 BYOM 实现支持以下 AIP 应用和其他平台功能：

  • AI FDE
  • AIP Analyst
  • AIP Chatbot Studio
  • AIP Logic
  • Workshop （通过 AIP Chatbot Studio 或 AIP Logic）
  • TypeScript 函数 （位于 代码仓库）

此外，该实现还提供以下 AIP 基础设施工具：

  • 跨 AIP 应用的模型选择器
  • Control Panel 权限和启用
  • 资源管理 应用程序速率限制和使用情况可观测性

不支持的应用程序和功能

已注册模型的 BYOM 实现目前不支持以下应用程序或功能：

  • AIP Assist，包括 代码仓库中的代码辅助
  • Pipeline Builder 的 生成 和 解释 功能

模型来源

您可以使用以下任一来源来支撑已注册模型：

  • REST API 来源： 通过数据连接中的 REST API 来源连接外部托管的模型提供商或账户。当您的模型提供标准提供商 API 时，建议采用此路径。更多信息请参阅关于 如何注册和使用您自己的模型的文档。
  • 计算模块： 使用您托管的模型服务器来支撑该模型，可将该服务器托管在 计算模块中、您自己的硬件和 GPU 上、本地部署或物理隔离环境中，或将其用作自定义代理层。请查阅关于 由计算模块支撑的模型 的文档以了解更多。

已注册模型支持的功能

LLM 速率限制

已注册模型支持 LLM 速率限制的方式与 Palantir 提供的模型相同。 注册管理员 必须定义注册级别和用户级别的速率限制，这一操作发生在 模型注册期间。

  • 注册速率限制 适用于项目级别的所有速率限制。
  • 项目级速率限制 默认为注册限制的 70%，但可以在资源管理应用程序的 AIP 使用情况和限制 选项卡中进行配置。
  • 用户速率限制 用于管控 AI FDE、AIP Analyst 和其他按用户归属的应用程序中的每用户消耗量。

权限与启用

  • 注册模型： 只有 注册管理员 可以在控制面板中注册新模型或编辑注册信息。管理员还必须对关联的数据连接源拥有 Owner 或 Editor 权限，才能注册、编辑或删除已注册的模型。
  • 注册时源权限即被切断： 模型注册后，其与底层数据连接源的关联将与最终用户访问权限解耦。最终用户无需对源拥有任何权限即可使用已注册的模型；访问权限仅由控制面板中配置的已注册模型启用设置来管控。
  • 使用已注册的模型： 使用已注册的模型进行构建的权限，或以最终用户身份使用这些模型的权限，均通过控制面板中的已注册模型启用设置进行管理。可将访问权限授予整个注册或特定用户组，这与标准 AIP 启用的工作方式类似。
  • 禁用模型： 已注册的模型可随时在控制面板的 AIP 设置中禁用。 扩展，从而防止其在各个 AIP 应用中使用。

常见问题

是否可以使用自托管模型？

可以。您可以在计算模块中自托管模型，并将其注册为 由计算模块支撑的模型。请按照指南中的说明 自托管模型。

注册模型是否支持标记？

目前，注册模型 不 支持标记。 注册管理员 可以在 Control Panel 中限制哪些用户可以使用注册模型，以及在 Resource Management 应用程序中限制哪些项目可以获得这些模型的容量。

注册模型的成本是如何处理的？

Palantir 不会对使用注册模型收取额外的平台费用。调用您在外部托管的模型所产生的费用将由您的模型提供商直接计费。注册模型的成本不会显示在 Resource Management 应用程序中。

为什么 AIP Assist 和 Pipeline Builder 的 Generate 和 Explain 功能不受支持？

这些原生平台功能依赖于对 Palantir 所提供模型的评估和测试，我们无法保证它们在不熟悉的客户模型上能够正常运行或提供高质量的体验。目前没有计划通过注册模型支持这些原生助手功能。
