开始使用

本指南将教你如何通过 Tableau 对 Foundry 进行身份验证、选择数据集，并开始构建你的第一个交互式仪表板。

在 Tableau 中选择 Foundry 作为你的数据源

  1. 启动 Tableau 并选择 连接到数据.
  2. 自动预览行为 到服务器，点击 更多.
  3. 搜索并选择 Foundry by Palantir.

输入你的 Foundry URL

在监听器设置向导的 Foundry by Palantir 对话框中，在 服务器 字段中输入你的 Foundry URL。你可以通过登录 Foundry、复制 URL 并删除 https:// 前缀以及 .com.

之后的所有内容来找到你的 Foundry URL。例如，如果你的 Foundry 超链接是 https://myfoundrylink.palantir.com/workspace/home，你应该输入 myfoundrylink.palantir.com 到 Tableau 提示中。

向 Foundry 进行身份验证

有三种对 Foundry 进行身份验证的方式： Foundry OAuth, Foundry Token or Foundry OAuth 客户端凭据。OAuth 是在 Tableau Desktop 中开始开发的最简单方式。

如果在发布时报表应依赖于查看报表的用户的权限，则应使用 OAuth 方法。这将在用户访问报表时提示其进行身份验证。如果报表对所有查看者使用一组静态凭据即可，则建议使用客户端凭据方法以获得长期可维护性，但需要 Foundry 管理员进行初始配置。

报表一经发布，就无法从 Tableau Server 网页界面更改身份验证方法。相反，应在 Tableau Desktop 中使用所需的身份验证方法重新发布报表。

Foundry OAuth 身份验证

  1. 编辑标签 身份验证 下拉菜单中，选择 Foundry OAuth.
  2. 在监听器设置向导的 OAuth URL 字段中，输入 https:// 以及你在 服务器 field.
  3. 选择 登录，你将被重定向到浏览器中的登录窗口。
  4. 登录后，选择 允许 以授权 Tableau 使用你的 Foundry 账户进行连接。
  5. 当你被重定向到显示消息“Tableau created this window to authenticate. It is now safe to close it”的网页后，关闭该窗口并返回 Tableau Desktop。

如果你在登录 Foundry 时收到错误，可能是你的组织尚未为 Tableau 启用 OAuth 登录选项。在这种情况下，请联系你的 Foundry 管理员寻求支持，并参考 启用 OAuth 客户端的说明.

使用 OAuth 发布报表

如果你打算在使用 OAuth 时将带有嵌入凭据的报表发布到 Tableau Server，你首先需要在 Tableau Server 中配置凭据，方法是导航到 My Account Settings > Saved Credentials for Data Sources 在 Tableau Server 中。请参阅 Tableau 文档中的 管理数据连接的已保存凭据 ↗ 的文档以获取更多信息。

Foundry 令牌身份验证

  1. 编辑标签 身份验证 下拉菜单中，选择 Foundry Token.
  2. 在监听器设置向导的 令牌 字段中，输入唯一的 用户生成的令牌.
  3. 点击设置菜单下的 登录.

Foundry 第三方应用程序客户端凭据（自 Tableau 连接器版本 2.6.0 起可用）

第三方应用程序客户端凭据是发布仅需要静态凭据的报表时推荐使用的方法。此类凭据没有过期时间。

Foundry 管理员需要配置一个第三方应用程序。 按照说明 配置该应用程序。选择 机密客户端 选项，并确保 客户端凭据授权 已启用。请勿 不 启用本体论 SDK。

为第三方应用程序的服务用户授予适当的权限。Tableau 中的数据访问将反映服务用户的访问级别。

在 Tableau 中，在 身份验证 下拉菜单下，选择 Foundry OAuth 客户端凭据。在 OAuth Client ID 字段中输入第三方应用程序的客户端 ID，并在 令牌 字段中输入客户端密钥。然后，选择 登录.

如果你在 Tableau Server 中工作，并尝试将已发布报表的身份验证方法更改为客户端凭据，可能会因 Tableau Server 的已知问题而收到错误。相反，应在 Tableau Desktop 中重新发布报表以使用客户端凭据身份验证。

选择你的数据集

按照上述说明操作后，你应该会在 连接 下的左侧边栏中看到列出的 Foundry 环境。

要开始使用特定数据集，请使用左侧边栏中的导航选项。在 数据库 部分，从下拉菜单中选择一个 Foundry 项目。然后在 表格 部分，使用搜索字段按名称或完整路径查找数据集。

加载数据集后，选择 连接 模式（实时 or 提取），然后像往常一样继续创建您的 Tableau 仪表板。

高数据规模与 Tableau 数据提取

可以通过使用 Tableau 数据提取 ↗来处理更高的数据规模，并确保查询在由 Foundry SQL Server 处理时符合“直接读取条件”。参见 架构 以了解直接读取功能的详细信息。
