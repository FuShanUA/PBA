可视化本体论数据

地图的主要功能是支持对您本体论中的地理空间数据进行可视化和分析。一旦您 向地图添加了对象，您就可以配置样式设置，以呈现对象的各种属性。总体而言，对象图层包含多个显示（例如图标、线条、多边形），用于表示地图上的对象。每个显示都可以设置样式，以表示对象的不同属性，例如颜色、大小和不透明度。

编辑图层样式

要编辑图层的样式，请从「图层」面板中选择一个图层条目。图层详情面板将打开，其中包含多个以标签页形式呈现的部分：

  • 样式： 配置各个显示的外观，或定义可应用于多个显示的默认设置。
  • 图例： 控制此图层的样式信息在「图例」面板中的显示方式。

图层样式

「 样式 」部分允许您配置 「共享默认设置」 ，这些设置适用于图层中的所有 显示 。默认颜色和不透明度可以关联到特定 显示 ，以共享一致的样式。请参阅 「基于值的样式」 和 「不透明度样式」 部分，了解有关如何配置颜色和不透明度的更多信息。

显示

一个对象图层可以包含多个 显示，其中每种显示都是在地图或时间轴上表示该图层对象的一种不同方式。通过组合多个显示，您可以创建复杂的可视化效果，以同时表示多个属性，并在您放大时提供更详细的视图。可用的各种显示类型包括：

  • 图标和圆圈： 根据地理点属性进行放置。
  • 线条和多边形： 基于地理形状属性或多个地理点属性。
  • 轨迹线、面包屑和热力图： 帮助可视化随时间移动的对象。

您可以使用 添加显示 选项来添加新显示，该选项位于 样式 部分下方。

添加显示菜单包含两个部分：

  • 显示预设： 选择图层对应的对象类型上可用的属性，然后将配置为使用该属性的显示添加到地图中。
  • 可用显示： 从地图可渲染的各种显示类型中进行选择。只有能够针对该图层的对象类型进行完整配置的显示才会被启用。

每个显示都包含许多可自定义的属性，这些属性在各显示的对应页面中有详细介绍。显示上的大多数属性都遵循下一部分中所述的基于值的样式设置范式。

基于值的样式设置

使用 基于值的样式设置 来根据与对象关联的值控制为该对象渲染的显示外观。例如，您可以将图标的颜色配置为表示气象站的温度，或将圆圈的大小配置为表示公司的员工人数。使用基于值的样式设置的最常见属性类型是颜色和数值属性（例如线宽、图标大小、圆圈半径等）。

其理念是：对于每个正在渲染的对象，您需要指定一个 值源，用于确定为每个正在渲染的对象进行样式设置时使用的值。然后，指定将值转换为样式属性（例如颜色、大小、不透明度）的方式。每个可设置样式的属性通常可用的值源如下：

  • 固定值： 显式选择单个样式值，该样式值将统一应用于图层中的所有对象。
  • 属性： 根据对象上的属性对每个对象进行样式设置。
  • 函数： 根据由 函数计算的值对每个对象进行样式设置。
  • 度量： 根据 时间序列度量对每个对象进行样式设置。

选择要使用的值后，将其转换为样式值（颜色、线条宽度、圆半径等）的配置取决于您要设置样式的属性类型。

颜色样式设置

以下各节介绍了每种属性类型可用的颜色样式设置选项。

固定

使用固定颜色样式时，请使用颜色选择器选择一种颜色，该颜色将统一应用于图层中的所有对象。

基于值的

当按具有数值的函数、属性或时间序列进行着色时，请使用渐变编辑器将值映射为输出颜色。可以通过选择渐变条上的点来编辑渐变中使用的颜色。颜色渐变的数值范围（最小值/最大值）会自动推断得出，但可以关闭该功能以手动设置范围。

当按具有字符串值的函数、属性或时间序列进行着色时， 颜色映射 下拉菜单包含将值映射为颜色的方法：

  • 手动： 为每个值明确指定要使用的颜色。
  • 自动： 自动从配色方案中分配颜色，以便区分不同的值，而无需配置特定值。
  • 无： 尝试将每个值直接应用为十六进制颜色。

数值样式

以下各节介绍可用于每种类型属性的数值样式选项。

固定

使用固定数值样式时，可通过滑块或在输入字段中输入精确数字来指定数值。

基于值

对数值属性（例如线宽或图标大小）进行样式设置时，只有具有数值的属性才能用作值源。要配置从所选值源到样式属性的映射，请选择一个 数值映射 选项：

  • 缩放： 定义一个线性比例，将对象的值转换为用于样式设置的数值。



    • 顶行控制样式属性的最小值和最大值，而底行确定与这些最小值/最大值相对应的值范围。
    • 在本示例中，线宽将为 1 像素（当对象的"Departing Flights"属性值为 20时），而线宽为 10 像素（当属性值为 500时）。

  • 无： 属性值将直接用作样式属性，不进行任何缩放或转换。

不透明度样式

使用 不透明度 部分，用于控制图层中对象的透明度。

“ 取值来源 ”下拉菜单包含指定不透明度的多种方式：

  • 固定： 选择一个统一应用于图层中所有对象的不透明度。

  • 按时间： 在渲染 轨迹 或属于 事件的对象时，将基于全局 时间选择来控制其不透明度。



    • 激活不透明度： 设置对象或点被视为处于激活状态时的不透明度。
    • 非激活不透明度： 设置对象或点被视为未处于激活状态时的不透明度。
    • 激活时间缓冲： 设置事件或轨迹点的时间戳必须与当前时间光标在时间上相距多近才会被视为处于激活状态。
    • 淡出持续时间： 设置对象变为非激活状态后，其不透明度从激活不透明度淡出至非激活不透明度所需的时间段。
    • 发生前隐藏： 启用后，对象将完全隐藏，直到时间光标经过事件开始时间或轨迹点的时间戳。

    “ 取值来源 ”下拉菜单和“ 按时间 ”不透明度选项仅在为 轨迹 或具有 事件数据的对象设置样式时才会显示。否则，不透明度部分将仅显示固定不透明度选项。

标签

定义自定义标签，以文本形式在地图上展示重要信息。使用以下属性控制标签在每个显示中的呈现方式：

  • 可见性： 配置标签在地图上何时显示。
    • 始终可见： 父级显示所表示的每个对象都会显示标签。
    • 仅在悬停时： 当用户将光标悬停在一个或多个对象上时，标签将以光标弹窗的形式显示。
    • 隐藏： 不显示任何标签信息。
  • 样式： 对于始终可见的标签，可使用以下选项控制标签内容的外观。
    • 卡片： 标签显示在纯色背景上，以确保高对比度和可读性。
    • 极简： 标签内容仅以文本形式显示，以获得更简洁、更不突兀的外观。
  • 启用标题： 以粗体文本和更不透明的背景显示标签的第一行项目，使关键信息一目了然。
  • 显示缺失数据： 在标签中包含值为 null 或空值的行条目。

请注意，对于使用 基于切片的加载方法的图层，不支持标签和附加工具提示内容。如果需要标签或自定义工具提示内容，请确保使用“对象”加载方法。

对象图层的标签内容

对于由对象支撑的图层，标签可包含以下内容：

  • 属性（包括 时间序列属性）
  • 函数
  • 系列
  • 关联对象计数

添加后,各个标签行还支持以下操作:

  • 拖动以重新排序
  • 编辑显示名称
  • 显示/隐藏行标题

属性或系列也可以使用选择面板中的 … 菜单进行添加,该菜单在鼠标悬停于某个属性或系列上时显示,如下图所示。

按缩放级别控制显示的可见性

使用 缩放级别 部分来控制图层中对象的可见性范围。插入符号表示您当前的缩放级别。

当视口的缩放级别处于有效范围内时,相应的显示将呈现在地图上;当缩放级别超出该范围时,相应的显示将被隐藏。

缩放级别配置仅适用于已切换为 可见。

图例

从 图层 详细信息面板中,使用 图例 标签页,以预览和控制图层的呈现方式。默认情况下,此标签页会包含该图层各显示的样式信息。标题开关决定此图层及其关联的显示是否会出现在 图例 面板中。切换行级别的复选框即可隐藏或显示各个条目。
