导出

Notepad 文档专为打印和导出为 PDF 或 DOCX 而设计，支持修改页面方向、定义页眉和页脚，以及为小部件配置打印专用设置。

导出文档

要导出文档，请使用右上角的 “文件” 菜单，选择 “导出”，然后选择 “导出为 PDF” 或 “导出为 DOCX”。文档渲染完成后，Notepad 将以所选的文件格式保存您的文档。

渲染超时

导出时，后台渲染时间设有上限。如果文档中包含许多需要长时间计算的图表，则可能会达到该上限，导致图表无法完全加载。在这些情况下，请使用 “以打印模式打开” 选项（详见下文）。

特定页面设置

Notepad 提供了额外的页面设置，供您在导出前对文档进行微调。要配置页面设置，请选择 “页面设置” （位于 Notepad 的左侧面板中）。

页面大小

Notepad 文档的默认页面大小为 Letter（8.5 x 11 英寸）。请使用 “页面大小” 下拉菜单来选择其他尺寸。

可用的页面大小选项如下：

  • Letter
  • Legal
  • Tabloid
  • A3
  • A4
  • A5

页面方向

默认情况下，文档以纵向模式显示。要将文档更改为横向模式，请选择 “纵向” 或 横向 在...下方 页面方向。

页眉和页脚

页眉和页脚仅在打印或导出文档时可见。要启用页眉或页脚，请启用 页眉 或 页脚 选项。

分页符小部件

使用 分页符小部件 插入自定义分页符。分页符仅在打印时显示。

小部件打印配置

某些小部件支持特定于打印的配置选项。这些选项可用时，可通过以下方式访问：选择小部件，打开 小部件属性 面板，并选择 打印配置。

选项包括 缩放， 在新页面上打印，以及 展开滚动条。

缩放

导出文档可能会限制可用的水平空间（即使在横向模式下），这并不适合某些可视化内容。例如，在屏幕上可以水平滚动的宽表格需要进行调整才能适应。 缩放级别 配置允许您通过缩小所显示的内容来做到这一点。

在新页面上打印

默认情况下，如果空间有限，小部件将在新页面上打印。对于显示表格或跨越多页的小部件，这可能不是理想的行为。在这些情况下，您可以禁用在新页面上打印。

展开滚动条

使用 打印时自动扩展表格高度 以在打印时完全展开滚动条，确保垂直滚动的部分完全展开。此功能目前仅支持 Contour 表格以及 Quiver 对象表格和数据透视表。

导出为 PDF

您可以通过 “以打印模式打开” 按钮在适合打印的视图中打开文档。页面和所有图表完全加载后，您可以使用 Ctrl+P (Windows)/Cmd + P (macOS) 键盘快捷键或右上角的打印按钮，将页面另存为 PDF 或进行打印。

请务必将打印布局设置为 纵向 或 横向 ，具体取决于您文档的 页面方向 。请确保页面大小与您选择的 Notepad 页面大小相匹配。请选择 默认 边距选项，以确保内容对齐。

导出为 DOCX

Beta

Notepad 的 DOCX 导出功能目前处于 beta 开发阶段。在活跃开发期间，功能可能会发生变化。

Notepad 目前支持将以下小组件导出为 DOCX：

  • 剪辑
  • Code Workbook 图表
  • Contour 图表
  • 文件引用（Compass）
  • 图像
  • 对象卡片
  • 对象媒体预览
  • 对象属性
  • 分页符
  • Quiver 分析图表
  • Quiver 仪表板图表
  • Solution Designer 图表
  • 表格
  • Vertex 图
  • 地图

DOCX 导出不保证保留 Notepad 文档中的所有样式和布局。以下各节介绍了您最有可能遇到的调整和限制，但可能还会出现其他差异。

自动调整

导出为 DOCX 时，会自动应用以下调整：

  • 内容会进行缩放，以匹配其在 Notepad 中的布局。 图像、表格、栏和文本会调整大小，使文档以与 Notepad 中相同的方式填满 Word 页面。宽度和字号使用不同的缩放系数，因此文本及其旁边的图像的缩放比例可能不同。
  • 图像大小会调整为适合页面。 任何宽度超过可用页面宽度的图像都会缩小以适应页面，同时保持其原始比例。图像的高度始终遵循其原始宽高比。
  • 高亮颜色会以近似颜色代替。 Microsoft Word 仅支持 16 种高亮颜色，因此 Notepad 会选择与您的高亮颜色最接近的可用颜色。

不支持的内容

导出为 DOCX 时，不包括以下内容：

  • 嵌套在其他表格中的表格不会被导出。
  • 表格单元格内的栏会垂直排列，而不是并排显示。
  • 清单会导出为普通的项目符号列表，不包含复选框。
  • 深度嵌套的列表最多支持九级缩进。
  • 小组件将以静态 PNG 图像的形式导出。小组件在导出后不会保留任何交互功能。仅支持 导出为 DOCX 中列出的小组件类型；其他小组件不会被导出。
  • 占位符不会被导出。
