在本体论中使用媒体

使用媒体引用将媒体本体化

使用 媒体引用对象属性 以便在基于本体论构建的应用程序中高效显示您的媒体。优化包括在 Workshop 或 Object Explorer 中实现更快速、更具交互性的预览，以及在 Map 中为地理空间影像提供切片支持。

使用媒体引用属性的自定义逻辑

将具有媒体引用对象属性的对象用于 对象上的函数.

您可以直接读取原始媒体项。此外，您还可以对媒体项执行常见的类型特定操作，例如：

  • 对文档进行 OCR
  • 从文档中提取文本
  • 音频转录
  • 读取媒体项元数据

通过 OSDK 利用媒体

如果您正在以 Foundry 作为后端构建应用程序，则可以利用 OSDK 中的媒体功能.

使用注意事项

  • 在操作表单中上传的媒体文件仅在表单成功提交后才会被上传到支撑媒体集，以确保取消或失败的提交不会在媒体集中产生孤立的媒体文件。
  • 不支持将媒体引用列表用作对象上的属性类型。
