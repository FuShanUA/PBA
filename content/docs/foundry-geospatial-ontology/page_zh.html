在本体论中使用地理空间数据

直方图 geospatial-tools 库不再积极开发；请改用 Pipeline Builder 来加载、转换和处理地理空间数据。本页所述的地理空间数据类型操作功能已被 Pipeline Builder 的地理空间功能所取代。 了解有关 Pipeline Builder 地理空间功能的更多信息。

如何配置包含矢量数据的本体论数据集

Foundry 的 geospatial-tools 库 的开发目的是解析、清理矢量数据，并将 shapefile 和 GeoJSON 等格式的矢量数据转换为可添加到本体论中的数据集。但是，此功能已被以下功能取代 Pipeline Builder 的地理空间功能所取代。您应使用 Pipeline Builder 而不是 geospatial-tools 库，因为该 geospatial-tools 库不再维护，可能无法按预期运行。

如何指定点和形状几何

Foundry 支持两种地理空间属性类型，每种类型都需要特定的字符串格式：使用 geopoint 属性类型来表示单个 点，而 geoshape 属性类型来表示 多边形和线.

点

点几何可以使用 geopoint 属性类型来指定。 geopoint 属性的内容应为以下格式之一的字符串：

  • latitude,longitude: For example, 57.64911,10.40744。坐标必须使用 WGS 84 坐标参考系统（标准经纬度）。 了解有关坐标参考系统和投影的更多信息。
  • A Geohash ↗: For example, u4pruydqqvj。Geohash 将被转换为点，使用 Geohash 矩形的左下角。

具有 geopoint 属性的对象会被索引以用于地理空间搜索。

多边形和线

多边形和线几何可以使用 geoshape 属性类型来指定。 geoshape 属性必须是满足以下要求的 GeoJSON Geometry 字符串：

  • 必须是 GeoJSON LineString、Polygon、MultiLineString、MultiPolygon、MultiPoint 或 Point。但是，Point 几何应 不 使用 geoshape 属性类型；使用 geopoint 属性类型 来表示 Point 几何。
  • 必须 不 是 Feature、FeatureCollection 或 GeometryCollection。
  • 必须符合 GeoJSON 规范 (RFC 7946) ↗.
  • 必须使用 WGS 84 坐标。
  • 多边形和多多边形必须符合 GeoJSON 规范的有效性要求。多边形和多多边形必须是闭合的，外环使用右手/逆时针方向，且不得自相交。

Mapbox Boundaries

与 Mapbox ↗ 合作，Foundry 为创建等值线式图层提供内置支持，并提供多种可用于定义区域边界的选项。

借助 Boundaries，您可以将 Foundry 数据集和/或本体论与一组托管地理要素相连接，这些要素表示各种类型的边界，例如行政区划或邮政编码区域。Mapbox Boundaries 中的多边形经过边缘匹配，可实现无缝的全球覆盖，因此您可以创建精确的数据可视化和准确的分析。

图层类型、级别和世界观

Mapbox 提供多种类型、级别和世界观的边界数据。您可以使用 Boundaries Explorer 应用 ↗，以及 有关不同边界类型的更多文档 ↗.

使用 Mapbox Boundaries

以下说明适用于最新版本的 Mapbox Boundaries (v4)。如果您已经在使用较早的版本，请先 迁移您的管道和应用程序 。

安装 Mapbox Boundary 定义

Mapbox boundary 定义 v4 可在 Foundry Marketplace 中下载。要从您的 Foundry 实例访问：

  1. 导航至 /workspace/marketplace/discovery 在您的 Foundry 实例上。
  2. 搜索“Mapbox”或使用 商店 筛选器在左侧面板中筛选“Foundry Store”。
  3. 从左侧面板中选择 Mapbox Boundary Definitions v4 product.
  4. 点击设置菜单下的 安装。如果有人已经安装了这些边界数据集，您将看到 打开 ，您可以从中导航到当前的安装。

  1. 安装时：
    1. 选择一种 空间 以指定安装位置。
    2. 由于该产品仅包含数据集，因此不需要本体论。
    3. 启用 安装后缀 来自定义数据集安装到的项目名称。
    4. 选择 安装 在左侧面板底部。
  2. 安装任务完成后，点击 查看安装 （位于产品名称右侧）以导航到该安装。

  1. 您可以通过选择右侧面板中的位置链接来访问已安装的边界数据集。默认情况下，只有您可以访问此项目，但您可以 在右侧的项目详情面板中添加其他用户和组.

当新的次要边界数据集版本可用时，您可以通过安装页面顶部显示的横幅进行升级。主要版本发布将作为新的数据源产品提供。

产品会安装到一个默认禁用编辑的新项目中，以确保安全升级（例如，当有额外的边界数据集可用时）。因此，我们建议将使用这些数据集的内容（例如分析、管道等）保存在其他项目中。如果您需要编辑项目本身，可以通过选择 设置 在左侧面板中，然后 解锁，如下所示。

将 Mapbox ID 集成到管道中

为了使用 Mapbox Boundaries，您需要一个 mapbox ID ，用于标识特定层级上特定类型的边界所对应的区域。这些 ID 可以在 边界元数据文件 ↗中找到，这些文件作为 Mapbox Boundary definitions 产品的一部分自动提供。请参阅 安装 Mapbox definitions 获取说明。

安装元数据文件后，在 Foundry 中将它们与您的数据进行关联，以添加 mapbox_id 列。根据边界的类型和层级，元数据文件将包含其他 ID 和/或名称列，您可以将它们用作与您自己的数据进行关联的键。

本 mapbox_id 列将用于配置下游应用程序以显示基于边界的地图。

从 Mapbox Boundaries v3 迁移到 v4

如果您目前使用的是旧版本的 Mapbox Boundaries 数据（如 V2 或 V3），我们强烈建议升级到 v4。除了获取边界本身的更新外，V4 版本还支持在工具提示中更可靠地显示区域名称，并支持 Mapbox 边界支撑的地图图层自动缩放至合适大小等改进。

从 v3 迁移到 v4 时，有一些边界存在破坏性变更。请查看 破坏性变更的详细变更日志 ↗ ，然后再继续。

要迁移管道中的数据，您可以：

  • 利用 V3 到 V4 ID 映射表 ↗，这些表包含在 Mapbox boundary definitions V4 产品中。使用 V3 中的 feature_id 列，将其与您现有的边界数据进行关联，并引入 v4 中新增的 mapbox_id 列。请务必手动处理上述任何重大变更。
  • 或者，您也可以直接按照上述说明操作，使用边界元数据 CSV 文件从头开始关联 mapbox_id 列。

在将 mapbox_id 列添加到您的管道/本体论后，请重新配置下游应用程序以使用 v4 边界，并选择此新列以及相应的边界类型/级别。
