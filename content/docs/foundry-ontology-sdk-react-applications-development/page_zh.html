开发环境

本页面将引导您完成使用平台内 VS Code 工作区构建 OSDK React 应用程序的开发工作流程。

开始使用

要在您的代码环境中启用开发功能，您需要 设置您的 Developer Console。在设置过程中，您必须选择 创建面向客户端的应用程序 以启用从 Developer Console 创建代码仓库的功能。

要使用 VS Code 工作区，请打开 Developer Console 并选择 创建代码仓库 图表工具 分支回退 部分（位于左侧面板中）。此操作将使用默认的 React 模板初始化您的仓库。然后您可以选择 在 VS Code 中打开 以启动平台内工作区。

仓库模板将包含一个集成了授权功能和 Ontology SDK 的基本 React 应用程序。

开发生命周期

VS Code 工作区启动后，您应该会在左侧看到代码编辑器，在右侧看到应用程序的实时预览。您可以像在本地环境中工作一样开始编辑代码。

编辑

现在您可以开始构建您的 React 应用程序。请务必在编写代码后进行编辑和测试，然后使用 git 命令或 VS Code 界面提交并推送您的更改，使其对项目中的其他开发者可见。在终端中运行 npm run lint, npm run test日 npm run build 以确保检查能够通过。

您还可以参考 本体论 标签页（位于左侧面板中）以查看为您的 OSDK 生成的文档和代码片段，并返回 Developer Console。

部署

要部署 React 应用程序，您必须首先创建一个发布版本。这通常使用 git tag 命令完成，您可以在其中设置版本号，然后将其推送到您的仓库：

发布版本通过检查后，您将能够在 Developer Console 中查看您的应用程序。

内容安全策略

默认情况下，我们会应用严格的内容安全策略（CSP）。这意味着对非 Foundry URI 的请求将失败，必须明确允许才能访问。

要检测 CSP 错误，请使用 F12 键并查看控制台中的日志。如果存在 CSP 失败，您将看到类似于以下所示的错误：

您可以为您的 VS Code 工作区应用临时 CSP。出于安全原因，此 CSP 不会应用于此工作区的其他用户，并且在工作区暂停或重启时会过期。

在 VS Code 工作区内测试应用程序后，请确保为您的 Developer Console 应用程序更新 CSP。

开发技巧

待办事项（To Do）应用程序教程

如果您是 Developer Console 和 OSDK 的新用户，我们建议您按照我们的其中一个教程入门。导航到 使用 AIP 构建 应用程序并安装我们的示例工作流程之一。

渐进式 Web 应用程序（PWA）

为了获得优化的编辑体验，您可以选择将您的工作区安装为渐进式 Web 应用程序（PWA）。PWA 将支持一些常用的快捷键，例如 Cmd+W （macOS）用于关闭标签页。

禅模式（Zen mode）

为了获得接近原生的 VS Code 体验，我们建议使用禅模式。选择 View > Activate Zen mode 以启用。禅模式将隐藏平台界面，并使 VS Code 占据整个浏览器窗口。要退出禅模式，请将鼠标悬停在三个点 ... 上（位于屏幕顶部中央）。

PR 预览 [Beta]

测试版

React 应用程序的 PR 预览功能目前处于 测试版 开发阶段，可能无法在您的注册租户中使用。功能在积极开发过程中可能会发生变化。

为了提高项目效率并简化协作，您可以在推送更新之前访问 React 应用程序更改的 PR 预览。PR（拉取请求）预览基于您在拉取请求中提交的代码，提供 React 应用程序的可运行版本。您可以在更改合并到主分支和生产状态之前预览应用程序的所有建议更改，从而更轻松地检查是否存在不良结果，并在更改进入生产环境之前验证面向用户的工作流程。以前，构建者、设计师和应用程序团队的其他成员需要创建开发环境才能查看更改。PR 预览功能消除了这一要求，可以更快地验证设计和功能方面的生产更改，并实现更高效、更协作的流程。

PR 预览功能适用于任何托管在使用 Developer Console 的 Foundry 代码仓库中的 OSDK React 应用程序 网站托管功能.

按照以下步骤开始使用 PR 预览：

  1. 首先，在 Developer Console 中生成一个应用程序。

  2. 然后，为该应用程序配置网站托管。



  3. 选择使用 VS Code 工作区 以利用 适用于 Visual Studio Code 的 Palantir 扩展中提供的开发者功能。您也可以在 代码仓库中打开您的应用程序代码。在任一环境中，您都可以在代码仓库中创建分支、通过提交实现代码更改并推送更新。您可以使用以下终端命令或环境界面进行更改：

    1. 创建新分支： git checkout -b myFeatureBranch main
    2. 实现代码更改并提交您的工作： git commit -am "implement UI change to show PR Preview"
    3. 将您的更改推送到代码仓库： git push --set-upstream origin myFeatureBranch

  4. 完成所需的更改且所有检查完成后，如果您之前在 VS Code 工作区中工作，请返回 Code Repositories。

  5. 在 Data Connection 中导航至 版本控制 屏幕顶部的选项卡，然后选择 拉取请求.

  6. 选择您想要预览的拉取请求，然后选择 预览 （位于右下角）以打开 React 应用程序的预览版本。



您还可以通过导航到 提交 选项卡，找到分支上每个提交的 PR 预览链接。PR 预览仅在拉取请求创建后的七天内可用。七天之后，预览将过期。

预览权限

要访问 React 应用程序的 PR 预览功能，用户必须拥有 Developer Console 授予的应用程序相应权限。要管理这些权限，请在 Developer Console 中打开您的应用程序，然后导航到 共享 （位于左侧边栏）。

要进行更改、为应用程序代码创建拉取请求以及与其他用户共享 PR 预览，您必须拥有 Owner or Editor 权限。要与未获得编辑您的应用程序代码或配置权限的用户共享 PR 预览，请将其添加为 Viewer 位于 共享托管网站.
