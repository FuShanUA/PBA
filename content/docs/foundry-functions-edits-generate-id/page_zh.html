为新对象生成唯一 ID

在编写 本体论编辑函数 时，如果该函数会创建对象，您可能需要为新建的对象生成唯一 ID。

TypeScript v2

TypeScript v2 没有内置或平台特定的 UUID 生成器。请使用标准的 UUID 库，例如 uuid 软件包 ↗ （来自 npm）。

安装该软件包

将 uuid 软件包添加到仓库的依赖项中：

Copied!

2
npm install uuid
npm install --save-dev @types/uuid

import { v4 as uuidv4 } from 'uuid';

export default function createFlightScenario(): void {
    const uniqueId = uuidv4();
    // Use uniqueId as the primary key for your new object
}

TypeScript v1

以下文档特定于 TypeScript v1 函数。如需 更强大的功能（包括对本体论 SDK 的支持和可配置的资源请求），我们建议您 迁移到 TypeScript v2。

在 TypeScript v1 函数中，请使用 @foundry/functions-utils 软件包来生成全局唯一标识符。

导入该软件包

该 @foundry/functions-utils 软件包默认已安装，但如果该软件包未包含在 package.json 文件中：

  • 在 "dependencies" 部分中，添加 "@foundry/functions-utils": "0.1.0"

如 有关添加依赖项的文档中所述，请记得重启 Code Assist，以便新软件包可用于自动补全。

在代码中使用该软件包

要生成唯一 ID，您可以使用 Uuid.random() 实用函数（来自 @foundry/functions-utils 软件包）。以下代码示例展示了如何在示例本体论编辑函数中使用 random 函数。

import { OntologyEditFunction, Timestamp } from "@foundry/functions-api";
import { Objects } from "@foundry/ontology-api";
import { Uuid } from "@foundry/functions-utils";

export class ExampleEditFunctions {
    @Edits(FlightScenario)
    @OntologyEditFunction()
    public createFlightScenario(): void {
        const scenario = Objects.create().flightScenarios(Uuid.random());
        scenario.scenarioName = "New scenario";
        scenario.creationTime = Timestamp.now();
    }
}
