转换媒体

除了 转换表格形式的结构化数据之外，Pipeline Builder 还允许您转换非结构化数据，这类数据在 Palantir 平台中以媒体集的形式表示。

转换媒体通常意味着以下两种情况之一：要么 处理 媒体，要么 从媒体中提取信息 。处理媒体的转换将接收媒体输入并生成媒体输出。从媒体中提取信息的表达式将接收媒体输入并生成表格输出。

您可以在 Pipeline Builder 中开始转换非结构化数据，前提是先将 来自 Foundry 的数据 以 媒体集 的形式添加到您的工作区。

媒体集输入无需转换为表格。将媒体集输入添加到管道后，可以将其作为媒体集或表格输入进行读取，这意味着您可以应用媒体转换或表格表达式，而无需对其进行转换。

要将媒体引用纳入数据集输出，请将媒体集作为表格输入读取，并将其媒体引用列联接到您的输出数据中。

选择媒体集

若要对媒体集应用转换，请在工作区中选择一个媒体集节点，然后选择 转换。

搜索转换

在转换页面中，按名称搜索转换类型，或浏览可用转换列表。您还可以选择左侧的 媒体 类别，以仅浏览可用的媒体转换。

切分 PDF 文档是通过 处理 媒体本身来转换媒体的一个示例。不过，您可能希望 提取信息 ，而不是处理文档。

筛选媒体集

该 筛选媒体集 转换使您能够根据各种条件筛选媒体集。在处理包含不同架构和格式的项的多模态媒体集时，此功能尤其有用。

通过使用 具有媒体架构 表达式作为条件，您可以将多模态媒体集过滤为仅包含符合指定架构和格式的项目。生成的过滤后媒体集节点的类型会被收窄，从而解锁后续特定于架构的转换，例如 从 PDF 提取文本 和 裁剪图像。

例如，如果您有一个同时包含 PDF 文档和图像的媒体集，您可以使用 过滤媒体集 转换，配合 具有媒体架构 表达式来创建仅包含 PDF 文档的过滤后媒体集，然后将 PDF 文本提取 转换应用于过滤后的结果。

媒体转换和表达式，例如 PDF 文本提取，需要来自实际媒体集的输入。 从包含文件的数据集生成的媒体引用 （例如，使用 获取媒体引用（数据集） 转换）不被接受，并将被拒绝。

目前无法从已转换的媒体中提取信息，也无法转换数据集中引用的媒体。

此外，在使用包含已删除项的媒体集输入时，也无法在变更日志模式下转换媒体。

Pipeline Builder 不支持对媒体集进行增量转换。若要对媒体集实现增量处理，请改用 Python 转换 。
