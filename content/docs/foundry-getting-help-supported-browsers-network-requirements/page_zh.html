支持的浏览器和端点要求

以下页面列出了 Palantir 平台支持的浏览器以及该平台的端点网络要求。

支持的浏览器

下表按设备列出了浏览器支持情况。请注意,并非所有 Palantir 应用程序都专为在移动设备上使用而设计;下面的移动设备表仅适用于支持移动设备的应用程序。

为获得最佳效果,请尽可能使用 Google Chrome 或 Microsoft Edge。对于下列浏览器,我们完全支持其过去一年内发布的任何版本。发布时间为一年至两年的较旧版本可获得部分支持,而发布超过两年的浏览器版本则不受支持。

浏览器桌面设备移动设备

Mozilla Firefox有限支持：仅为最近六个月内发布的版本提供关键错误修复不支持

客户端端点网络要求

由于 Palantir 平台的主要前端是一个 Web 应用程序，建议用户使用 受支持的浏览器 以获得最佳运行效果。

然而，在极少数情况下，即使使用了受支持的浏览器，网络设置较为特殊的用户仍可能遇到问题。

为了帮助调试，本页面记录了 Foundry 对客户端端点网络设置的一些假设。

WebSocket 支持

许多平台内应用程序使用 WebSockets ↗ 在客户端与服务器之间进行通信，并且 Palantir 平台假定 WebSocket 连接是可行的。

某些代理服务器需要特殊配置或软件升级才能支持 WebSocket 连接。如果用户通过不支持 WebSocket 的代理连接到 Palantir 平台，平台的大部分功能可能无法使用。

HTTP/2 支持

HTTP/2 支持对于 Palantir 平台的流畅性能至关重要，因为它有助于促进处理 Foundry 应用程序向后端发送的大量并发请求。

请注意，代理服务器可能会将 HTTP/2 连接降级为 HTTP/1.1，这可能导致 Foundry 应用程序运行缓慢，甚至影响可用性。

如果您在使用 Palantir 平台时遇到运行缓慢的情况，并且您与平台的连接经过代理服务器，则应排查代理服务器降级连接的可能性。
