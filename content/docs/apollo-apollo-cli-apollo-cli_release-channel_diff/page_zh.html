apollo-cli release-channel diff [实验性]

此命令为 实验性。要 启用此命令，请运行 apollo-cli configure 命令并启用 V2 experimental commands。

比较环境中产品在两个发布渠道之间的发布版本

比较两个发布渠道，并显示源渠道上存在 但目标渠道上不存在的产品发布版本，仅限特定环境中使用的产品。

这对于识别哪些发布版本需要从一个渠道晋升到另一个渠道非常有用。

使用示例：

比较环境中产品在 DEV 渠道与 STABLE 渠道之间的发布版本

apollo-cli release-channel diff -e apollo-env-123 -s DEV -t STABLE

apollo-cli release-channel diff -e apollo-env-123 -s DEV -t STABLE

apollo-cli release-channel diff -e apollo-env-123 -s DEV -t STABLE -o json

以 JSON 格式输出

apollo-cli release-channel diff -e apollo-env-123 -s DEV -t STABLE --all
