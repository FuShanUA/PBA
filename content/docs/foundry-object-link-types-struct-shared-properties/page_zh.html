结构体属性与共享属性类型

结构体属性可供本地属性类型和共享属性类型使用。在将本地属性类型转换或提升为共享属性类型时,需要重新映射结构体字段。由共享属性类型支撑的本地结构体属性类型将继承共享属性类型的字段,但结构体字段资源标识符 (RIDs) 除外。随后,结构体字段元数据(显示名称、描述、别名)将从共享属性类型继承,但结构体字段将保留其原始 RID。

创建结构体类型的共享属性

  1. 在本体论管理器中,您可以通过两种方式创建结构体类型的共享属性:

    • 在主页右上角,选择 新建 > 共享属性

    • 选择 共享属性 > + 新建共享属性

  2. 在主面板中,选择 新建共享属性 按钮。这将打开一个辅助工具,您可以在其中配置共享属性的元数据,包括名称、描述、别名和 API 名称。然后选择 下一步 以继续。

  3. 配置基础类型、值类型、可见性,以及是否要求该属性必须有值。

  4. 选择要将此共享属性保存到的项目。

  5. 返回本体论管理器后,在右上角选择 保存 以 对您的本体论进行更改。

附加 struct 类型的共享属性

  1. 在 Ontology Manager 中，打开 Properties 标签页，然后从 Properties 表中选择所需的属性。
  2. 在右侧的 Property editor 中，向下滚动到 Shared property ，然后在 Assign下选择一个共享属性。这将在两个属性之间共享属性元数据。

注意： 在将共享属性类型分配给本地 struct 属性类型后，若要添加新的 struct 字段，您必须将新的 struct 字段添加到共享属性类型中，并针对由该共享属性支撑的所有本地 struct 属性类型将这些字段映射到数据源列。

将 struct 属性类型转换为共享属性

以下说明详细介绍了如何将 struct 属性转换为由共享属性类型支撑的 struct 属性。

  1. 在 Ontology Manager 中，打开 Properties 标签页，然后从 Properties 表中选择所需的属性。
  2. 在右侧的 Property editor 中，向下滚动并选择 Convert to a shared property，该操作将通过共享属性类型支撑此 struct 属性。
