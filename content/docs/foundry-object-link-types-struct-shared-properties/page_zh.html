结构体属性和共享属性类型

结构体属性可以由本地属性类型和共享属性类型使用。在转换或将本地属性类型提升为共享属性类型时，需要重新映射结构体字段。由共享属性类型支撑的本地结构体属性类型将继承共享属性类型的字段，但结构体字段资源标识符 (RID) 除外。结构体字段元数据（显示名称、描述、别名）将从共享属性类型继承，但结构体字段将保留其原始 RID。

创建结构体类型的共享属性

  1. 在 Ontology Manager 中，您可以通过两种方式创建结构体类型的共享属性：

    • 从主页右上角，选择 New > Shared property

    • 选择 Shared properties > + New shared property

  2. 在主面板中，选择 新建共享属性 按钮。这将打开一个助手，您可以在其中配置共享属性的元数据，包括名称、描述、别名和 API 名称。然后选择 属性，然后选择 以继续。

  3. 配置基础类型、值类型、可见性，以及是否要求该属性必须具有值。

  4. 选择要将此共享属性保存到的项目。

  5. 返回 Ontology Manager，选择 保存 在右上角 将更改应用到您的本体论.

附加结构体类型的共享属性

  1. 在 Ontology Manager 中，打开左侧边栏中的 属性 选项卡，然后从 属性 table.
  2. 在监听器设置向导的 在 在右侧，向下滚动至 共享属性 并选择 分配下的共享属性。这将在两个属性之间共享属性元数据。

注意： 在将共享属性类型分配给本地结构体属性类型后添加新的结构体字段时，您必须将新的结构体字段添加到共享属性类型，并将其映射到由该共享属性支撑的所有本地结构体属性类型的数据源列。

将结构体属性类型转换为共享属性

以下说明详细介绍了如何将结构体属性转换为由共享属性类型支撑的结构体属性。

  1. 在 Ontology Manager 中，打开左侧边栏中的 属性 选项卡，然后从 属性 table.
  2. 在监听器设置向导的 在 在右侧，向下滚动并选择 转换为共享属性，这将使用共享属性类型来支撑该结构体属性。
