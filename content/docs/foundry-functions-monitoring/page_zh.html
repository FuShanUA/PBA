函数监控

可以对 Foundry 中的函数进行监控，以跟踪其性能和可靠性。本页面介绍了可用的函数监控功能。

您还可以查看实时 函数指标 （位于 Ontology Manager 中），其中包括每种函数类型的成功次数和失败次数以及 P95 持续时间。

可用的监控规则

Foundry 中的函数监控支持以下规则类型：

  1. 函数持续时间 p95： 当第 95 百分位的执行时间超过阈值时发出警报。
  2. 时间窗口内的函数失败次数： 当总失败次数在特定时间范围内超过阈值时发出警报。此规则会跟踪所有失败类型。
  3. 时间窗口内面向用户的函数失败次数： 当面向用户的失败次数在特定时间范围内超过阈值时发出警报。此规则仅跟踪由函数代码抛出的面向用户的错误。
  4. 时间窗口内非面向用户的函数失败次数： 当非面向用户的失败次数在特定时间范围内超过阈值时发出警报。此规则会排除面向用户的错误，因此适用于监控基础设施和系统级失败。

有关每种规则类型的详细配置选项和参数，请查阅 监控规则参考文档。

设置函数监控

要为您的函数设置监控，请按照创建监控视图和规则的标准流程操作：

  1. 创建监控视图，具体方法请参见 监控视图概览文档。
  2. 请按照 添加监控规则一节中的说明，为函数添加监控规则。
  3. 配置适当的阈值和严重性级别。
  4. 请遵循 警报订阅指南设置警报通知。

动态范围

函数监视器支持将 Workflow Lineage、 Workshop和 OSDK 应用 作为动态范围。当您选择其中一种范围时，监视器会自动跟踪该范围资源所使用的所有函数，并在添加或移除函数时自动调整，无需进一步干预。
