Google Drive

The Google Drive connector is a Palantir-provided driver for Google Drive.

To create a new Google Drive source, follow the standard setup flow for Palantir-provided drivers, then use the sections below for Google Drive-specific configuration and networking. For the complete property reference, see the official Google Drive driver documentation ↗.

Choose a Google Drive operation

Choose the source and operation based on the result you need:

TaskFoundry pathResult
Explore or sync file recordsGoogle Drive connector, including its Files tableFile metadata such as ID, name, MIME type, and size.
Extract one file in a batch syncGoogle Drive connector's DownloadFile stored procedureBase64-encoded file content in the output dataset.
Read a blob file on demandPython or TypeScript v2 Function using a separate OAuth-backed REST API sourceFile content from Google Drive files.get with alt=media ↗.
Create or replace a blob file on demandPython or TypeScript v2 Function using the same REST API sourceA Drive API upload ↗ that changes the external file.

The Files table's FileData property ↗ does not turn a file-content download into a dataset column. Use the metadata sync to discover file IDs, then pass an ID to DownloadFile or an on-demand Function. For a Function, the calling user must have access to the file, and the outbound application's authorized scope must permit the operation. See the Drive API access boundaries.

Extract a file with a batch sync

To extract one file, run the Google Drive DownloadFile stored procedure ↗ in a sync definition:

Copied!
1
EXECUTE DownloadFile Id = '<FILE_ID>', LocalFile = ''

With LocalFile empty, the output dataset contains the file content in FileData, encoded as Base64 by default. Decode it to binary in a downstream data transformation. Use a source with Readonly unset or set to false: Readonly=true rejects stored procedures ↗.

Read and write blob files with the Drive API

For on-demand file-content operations, configure a separate REST API source backed by an OAuth 2.0 outbound application. Enable exports and source imports, then import the source into a Python or TypeScript v2 Functions repository. Replace <SOURCE_RID> in each example with the RID of that imported REST API source. Run the Function on behalf of a user who has authorized the application. This source uses the calling user's delegated access; it does not reuse the service-account JSON from the metadata source. See OAuth 2.0 in Functions for runtime and authorization requirements.

Allow the REST source to reach only the API host www.googleapis.com:443 and the OAuth hosts accounts.google.com:443 and oauth2.googleapis.com:443.

Choose the Google Drive scopes ↗ for the files each operation needs:

OperationScopeAccess boundary
Read files the application can accesshttps://www.googleapis.com/auth/drive.fileFiles created or opened with the application, or selected by the user for the application through Google Picker.
Read any file the user can accesshttps://www.googleapis.com/auth/drive.readonlyAll user-accessible Drive files; this is a restricted scope.
Create or replace an eligible filehttps://www.googleapis.com/auth/drive.fileNew files and eligible existing files; a file ID alone does not grant edit access.

Public applications requesting drive.readonly must meet Google's restricted-scope verification requirements ↗.

A direct Function call in Workshop cannot start interactive authorization. To offer first-time authorization there, use a separate function-backed action; otherwise, the user must authorize the same outbound application before calling these Functions. Use serverless mode so the user's OAuth credential can refresh.

Read one blob file

Use Google Drive files.get with alt=media ↗ to read blob bytes. Check the file's metadata and download capability before using this with an arbitrary file ID. Native Google Workspace documents require files.export ↗ in a supported format. These examples return blob bytes as a base64 string.

import base64

import requests
from functions.api import function
from functions.sources import get_source


SOURCE_RID = "<SOURCE_RID>"


@function(sources=[SOURCE_RID])
def read_google_drive_blob(file_id: str) -> str:
    source = get_source(rid=SOURCE_RID)
    session = requests.Session()
    proxy = source.get_https_proxy_uri()
    if proxy:
        session.proxies.update({"http": proxy, "https": proxy})
    session.headers["Authorization"] = (
        f"Bearer {source.get_session_credentials().get().access_token}"
    )

    response = session.get(
        f"https://www.googleapis.com/drive/v3/files/{file_id}",
        params={"alt": "media", "supportsAllDrives": "true"},
        allow_redirects=False,
    )
    if not 200 <= response.status_code < 300:
        raise RuntimeError(f"Google Drive returned {response.status_code}")
    return base64.b64encode(response.content).decode("ascii")

import { getFetch, getSource } from "@palantir/functions-sources";

const SOURCE_RID = "<SOURCE_RID>";
export const config = { sources: [SOURCE_RID] };

export default async function readGoogleDriveBlob(fileId: string): Promise<string> {
  const source = await getSource({ rid: SOURCE_RID });
  const credentials = await source.sessionCredentials?.get();
  if (credentials?.type !== "oauth") throw new Error("Authorize the source first");
  const sourceFetch = await getFetch(source);

  const response = await sourceFetch(
    `https://www.googleapis.com/drive/v3/files/${fileId}?alt=media&supportsAllDrives=true`,
    {
      headers: { Authorization: `Bearer ${credentials.accessToken}` },
      redirect: "error",
    },
  );
  if (!response.ok) throw new Error(`Google Drive returned ${response.status}`);
  return Buffer.from(await response.arrayBuffer()).toString("base64");
}

import base64

import requests
from functions.api import function
from functions.sources import get_source


SOURCE_RID = "<SOURCE_RID>"


@function(sources=[SOURCE_RID])
def create_google_drive_blob(
    parent_folder_id: str, file_name: str, mime_type: str, content_base64: str
) -> str:
    source = get_source(rid=SOURCE_RID)
    session = requests.Session()
    proxy = source.get_https_proxy_uri()
    if proxy:
        session.proxies.update({"http": proxy, "https": proxy})
    session.headers["Authorization"] = (
        f"Bearer {source.get_session_credentials().get().access_token}"
    )

    created = session.post(
        "https://www.googleapis.com/drive/v3/files",
        json={"name": file_name, "mimeType": mime_type, "parents": [parent_folder_id]},
        params={"fields": "id", "supportsAllDrives": "true"},
        allow_redirects=False,
    )
    if not 200 <= created.status_code < 300:
        raise RuntimeError(f"Google Drive returned {created.status_code}")
    file_id = created.json()["id"]

    uploaded = session.patch(
        f"https://www.googleapis.com/upload/drive/v3/files/{file_id}",
        params={"uploadType": "media", "supportsAllDrives": "true"},
        data=base64.b64decode(content_base64),
        headers={"Content-Type": mime_type},
        allow_redirects=False,
    )
    if not 200 <= uploaded.status_code < 300:
        raise RuntimeError(f"Google Drive returned {uploaded.status_code}")
    return file_id

import { getFetch, getSource } from "@palantir/functions-sources";

const SOURCE_RID = "<SOURCE_RID>";
export const config = { sources: [SOURCE_RID] };

export default async function createGoogleDriveBlob(
  parentFolderId: string, fileName: string, mimeType: string, contentBase64: string,
): Promise<string> {
  const source = await getSource({ rid: SOURCE_RID });
  const credentials = await source.sessionCredentials?.get();
  if (credentials?.type !== "oauth") throw new Error("Authorize the source first");
  const sourceFetch = await getFetch(source);
  const created = await sourceFetch(
    "https://www.googleapis.com/drive/v3/files?fields=id&supportsAllDrives=true",
    {
      method: "POST",
      headers: { Authorization: `Bearer ${credentials.accessToken}`, "Content-Type": "application/json" },
      body: JSON.stringify({ name: fileName, mimeType, parents: [parentFolderId] }),
      redirect: "error",
    },
  );
  if (!created.ok) throw new Error(`Google Drive returned ${created.status}`);
  const { id } = (await created.json()) as { id: string };

  const uploaded = await sourceFetch(
    `https://www.googleapis.com/upload/drive/v3/files/${id}?uploadType=media&supportsAllDrives=true`,
    {
      method: "PATCH",
      headers: { Authorization: `Bearer ${credentials.accessToken}`, "Content-Type": mimeType },
      body: Buffer.from(contentBase64, "base64"),
      redirect: "error",
    },
  );
  if (!uploaded.ok) throw new Error(`Google Drive returned ${uploaded.status}`);
  return id;
}
