控制面板

可以使用 控制面板配置各种组织范围的地图设置。要修改地图设置，您需要 Map Admin 组织概览

某些组织级别的设置，用户可以在 设置菜单.

地图默认值

  • 默认视口 定义创建新地图时用户将看到的初始视图，包括中心点（纬度和经度）和缩放级别。
  • 默认时间选择 定义用户选择时间范围时将显示的日期选项范围。
  • 默认单位系统 为所有用户和/或特定用户组设置不同的单位系统（公制、英制或海制）。用户可以在 地图设置.

    • 下时地图检查更新的时间序列数据的频率。 默认轮询间隔：
    • 设置新地图的默认轮询间隔（以秒为单位）。用户可以在地图中覆盖此设置。 最小允许轮询间隔：
  • 设置允许的最小轮询间隔覆盖值（以秒为单位）。用户无法为单个地图设置小于此值的轮询间隔。 时间序列点数：
    • 定义每个轨迹要加载的点数。 默认时间序列点数：

  • 对象搜索限制： 用户在单个地图上覆盖默认点数时可以指定加载的最大点数。

直方图 API 密钥 Mapbox：在地图上启用“查找位置”

“查找位置”

功能使用 Mapbox 的专有地理编码服务。要为您的组织启用此功能，您需要配置一个组织特定的 Mapbox API 密钥，其中包含对 Mapbox 地理编码 API 的访问权限。

Bing 地图：启用 Bing 地图底图层

要使用 Bing 地图底图层（而非默认的 Mapbox 底图层），请输入 Bing 地图 API 密钥。

底图

启用 Mapbox 底图

禁用 Mapbox 样式后，Foundry 平台中的地图应用程序和小组件将默认使用第一个自定义底图。

自定义底图
