控制面板

各种组织级别的地图设置均可在 控制面板中进行配置。若要修改地图设置，您需要拥有 Map Admin 角色。

某些组织级别的设置，用户可以在 设置菜单中以用户级别或地图级别进行覆盖。

地图默认设置

  • 默认视口 定义用户在创建新地图时看到的初始视图，包括中心点（纬度和经度）和缩放级别。
  • 默认时间选择 定义用户选择时间范围时显示的日期选项范围。
  • 默认单位系统 为所有用户和/或特定用户组设置单位系统（公制、英制或航海制）。用户可以在 地图设置中覆盖此默认设置。

数据加载

  • 时间序列轮询间隔： 定义地图在 "查看最新"模式下检查时间序列数据更新的频率。
    • 默认轮询间隔： 设置新地图的默认轮询间隔（以秒为单位）。用户可以在地图中覆盖此设置。
    • 允许的最小轮询间隔： 设置允许覆盖的最小轮询间隔（以秒为单位）。用户无法为单个地图设置小于此值的轮询间隔。
  • 时间序列数据点： 定义每条轨迹要加载的点数。
    • 默认时间序列点数： 要加载的默认点数。
    • 最大点数： 在单个地图上覆盖默认点数时，用户可以指定加载的最高点数。
  • 对象搜索限制： 控制用户可通过搜索对话框向地图添加的最大对象数量。
  • 周边搜索限制： 控制用户通过单次周边搜索可以向地图添加的最大对象数量。
  • 自动对象搜索： 控制对象搜索结果是随输入自动加载，还是需要手动触发。

API 密钥

Mapbox：在地图上启用“查找位置”

该 查找位置 功能使用 Mapbox 提供的专有地理编码服务。要为您的组织启用此功能，您需要配置一个特定于组织的 Mapbox API 密钥，且该密钥需包含对 Mapbox Geocoding API 的访问权限。

Bing Maps：启用 Bing Maps 底图

要使用 Bing Maps 底图而非默认的 Mapbox 底图，请输入 Bing Maps API 密钥。

底图

启用 Mapbox 底图

禁用 Mapbox 样式后，Foundry 平台中的地图应用程序和小组件将默认使用第一个自定义底图。

自定义底图

使用栅格瓦片（Raster tiles）或 Mapbox JSON 添加自定义底图。

水印配置

水印可以配置为默认水印，也可以按组配置。水印将叠加显示在底图上。
