词集比率

支持场景：批处理、流式处理

计算两个字符串之间的词集比率。词集比率是一种描述两个字符串相似程度的指标，将返回一个介于 0 和 1 之间的值，其中 0 表示两个字符串之间没有任何相似之处，1 表示两个字符串相同（或其中一个是另一个的子字符串）。

表达式类别： 距离度量、字符串

已声明的参数

  • 忽略大小写： 比较左右字符串时是否要忽略大小写？
    Literal<boolean>
  • 左侧： 要比较的左侧字符串。
    Expression<String>
  • 右侧： 要比较的右侧字符串。
    Expression<String>

输出类型： Double

示例

示例 1：基本情况

参数值：

  • 忽略大小写： false
  • 左侧： left
  • 右侧： right
左右输出
你好，世界世界，你好1.0
你好你好，世界0.5
你好 你好 世界你好，世界0.8181818181818181
你好告别0.46153846153846156
空字符串空字符串1.0

示例 2：基本情形

描述： 通过将忽略大小写设置为 true，不同大小写的字母将被视为相等。

参数值：

  • 忽略大小写： true
  • 左侧： left
  • 右侧： right
左右输出
你好你好，世界1.0
你好 你好 世界你好，世界1.0
你好告别0.46153846153846156
