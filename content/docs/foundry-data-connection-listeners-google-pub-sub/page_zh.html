设置 Google Cloud Pub/Sub 监听器

本指南逐步展示如何为 Google Pub/Sub 配置监听器，以便将事件从 Pub/Sub 主题实时传送到 Foundry 流式数据集。

Google Pub/Sub 可与多种 Google Cloud 服务结合使用，将事件路由到 Foundry。例如，它可用于从 Gmail 帐户流式传输电子邮件。 查看 Google 提供的从 Gmail 进行流式传输的相关指南 ↗。

详细了解 Google Pub/Sub。↗

前提条件

在配置之前，请确保：

  • 您所在注册的入口策略已进行适当配置，可接受 Google Pub/Sub 请求。您可以将 您 Google Cloud 区域的 IP ↗加入允许列表，或者将相应的国家/地区加入允许列表。 了解如何配置入口。 请注意，在实施监听器之后，提供商可能随时更改 IP，而您需要相应地更新入口。

  • 您拥有 Google Cloud Console 中 Pub/Sub 的访问权限。

操作说明

  1. 如果您还没有 Pub/Sub 主题，请先创建一个。该主题是将推送到您的 Foundry 监听器的事件流。



  2. 导航至 监听器 选项卡（位于 Data Connection 中）。通过在监听器类型菜单中选择 Google Cloud Pub/Sub 来创建 Foundry Pub/Sub 监听器。此步骤不会完成监听器的设置，但必须执行此步骤才能生成监听器 URL，该 URL 随后将在步骤 3 中使用。



  3. 为步骤 1 中的 Google Pub/Sub 主题创建订阅。

    a. 选择 推送 作为订阅类型。

    b. 将步骤 2 中生成的 URL 复制到您的推送订阅的 URL 字段中。

    c. 勾选复选框以启用 身份验证。 在外部文档中查看 Pub/Sub 身份验证信息。↗

    • 选择用于身份验证的服务账号。
    • 要使用共享密钥，请在 URL 字段中将您的共享密钥作为查询参数输入到监听器端点 URL 之后。示例： ?token=<YOUR_TOKEN>

    d. 保存您的订阅。



  4. 将 服务账号电子邮件地址、可选的 受众声明和可选的 共享密钥 复制到监听器配置中（如下所示），然后点击 继续。



  5. 现在需要信息安全官的管理员审批。请查看开关的描述。

  6. 选择 启动 （位于监听器 测试 页面），以开启您的监听器并开始接收事件。

  7. 向您的主题发送一条测试消息，然后查看它出现在监听器测试界面中。





有效负载以 base64 编码形式到达。您可以在流式管道中使用 base64 解码转换看板对其进行解码，以获取消息的字符串表示形式。
