Code Sandbox

Code Sandbox 小部件是一个安全的沙盒，供您实现自己的自定义小部件以扩展 Slate 的功能。您可以构建自己的自定义可视化、利用第三方 JavaScript 库，或构建高级的工作流交互。您可以定义渲染、小部件模型和事件交互，使您的小部件与应用程序的其余部分集成。外部 JavaScript 库可以加载到 Project 中的文件夹内，并在您的小部件中引用。

不支持调试自定义小部件代码

Code Sandbox 小部件可在您的 Slate 应用程序中解锁高级的自定义开发功能。通过 Code Sandbox 小部件实现自定义功能时，应清楚了解所涉及的技术复杂性以及成功开发所需的长期维护工作。小部件开发由您自行决定并自担风险；不提供自定义代码调试方面的支持。

JavaScript 库

这是一个 Project 路径数组，这些路径将被下载并按顺序在小部件内执行；或者是一个同时被 CORS 和 CSP 策略允许的 URL 数组（可以混合使用）。

下载将使用浏览器，因此 URL 必须被 CORS 和 CSP 策略允许。如果您希望在 Foundry 中托管库，可以将它们托管在 Blobster 中并使用 cookie 身份验证的 API，或者将脚本放入资产服务器中。对此字段进行更改将导致整个小部件重新加载和刷新。（这些库本身可以调用 SlateFunctions 以使其能够与 Slate 的特定功能进行交互）。

导入的 JavaScript 库必须将其功能分配到全局可用的作用域，才能通过 JavaScript 标签页引用（例如打包为 UMD 模块，或显式地将功能分配给 window).

HTML

这是一段 HTML 字符串，将在微件加载时渲染。

请勿在此处使用 Handlebars。HTML 标签 <script> 将无法 运行，你需要将所有 JavaScript 提取到 JavaScript 标签页中。

CSS

这是一段 CSS 字符串，将在微件加载时渲染。

请勿在此处使用 Handlebars。此处指定的 CSS 允许你 覆盖在 iframe 边框中渲染的 CSS，而不是在 框架内部。相同的边框样式也可以通过 附加 CSS 类 和 自定义样式 在微件的顶层 “样式” 标签页。

CSS 库

CSS 库功能允许你加载 CSS，以便使用 CSS 样式（例如 Blueprint）来创建自定义微件。你可以在微件的 HTML/CSS 标签页中访问它。

CSS 库的工作方式类似于 Code Sandbox 的 JavaScript 库。CSS 库接受一个项目路径数组，这些文件将被下载并按顺序在微件中渲染；或者接受一个同时被 CORS 和 CSP 策略允许的 URL 数组（可以混合使用）。下载将使用浏览器，因此 URL 必须被 CORS 和 CSP 策略允许。如果你希望在 Foundry 中托管 CSS 库，可以将它们托管在 Blobster 中并使用 cookie 认证的 API，或者将脚本放入资产服务器。对此字段进行更改将导致整个微件重新加载和刷新。

CSS 库文件的内容使用纯 CSS 即可；请确保不要使用 HTML <style> 标签包裹 CSS 样式。

交互标签页

这是让微件与 Slate 范式进行交互的控件。Code Sandbox 微件与 Slate 其余部分之间的所有交互都应通过状态、事件或 操作之一来传递。

我们建议你仅通过此交互标签页传入 Handlebars。直接在 JavaScript 框中使用 Handlebars 仍然可行（例如，在不使用 SlateFunctions.watch or SlateFunctions.getState的情况下传入某些状态），但不推荐这样做，因为整个微件每次都会重新加载和刷新。

Monday

这是一个表示微件当前配置的 JSON blob。这类似于 Slate 中其他微件使用的 状态，不同之处在于它嵌套在此字段下，以允许其他 元字段。状态可以在微件内部修改，也可以 按照通常的做法在状态中放入 Handlebars。

要从微件内部修改状态，请使用 SlateFunctions.setState 在 JavaScript 中。其他向微件传递状态的 Slate 函数为 SlateFunctions.watch 和 SlateFunctions.getState （参见下面的示例）。

有多种方式可以使用此字段向 Code Sandbox 微件加载额外的运行时代码（例如，将 JavaScript 传入状态并在稍后加载）。但是，不建议使用这些方式，因为此字段的用途是表示微件的状态。

Slate 函数

这些原生函数允许你与 Slate 特定的功能进行交互，并暴露给在小部件内运行的 JavaScript。这些函数允许你通过事件、Action 和状态更改与 Slate 应用程序的其余部分进行交互。

onAction

数据方向：Slate 上下文 → 小部件

SlateFunctions.onAction 允许你注册一个回调，以便在你的小部件上调用 Action 时触发。其参数为 Action 的名称以及收到 Action 时要调用的函数。该函数被调用时，唯一的参数是随 Action 一起传递的 'body'。

然后，你需要在下方的 Interaction 选项卡中列出你的 Action。

示例

  • 事件面板能够检测到此 Action，因为该 Action 已在 Code Sandbox 小部件的 Interaction 中注册 操作 box.

watch

数据方向：Slate 上下文 → 小部件（持续监视）

SlateFunctions.watch 旨在帮助你检测 state 字段的更改，其方式类似于 AngularJS 中的 watch。 SlateFunctions.watch 接受一个字符串和一个函数作为其参数。当字符串所表示的那部分 state 发生更改时，所提供的函数将被调用，并以新状态和旧状态作为参数。这可能是最有用的函数，也是你如何通过传入 Interaction 选项卡的 Handlebars 将数据传递到小部件中的方式（例如"First Argument": "{{handlebars}}").

例如，如果你的 state 有两个字段——height 和 width——并且你想在 height 更改时调用一个函数，你可以调用 SlateFunctions.watch("height", <insert function here>)。如果初始字符串为空，则该函数将在任何 state 更改时被调用。

示例

此示例使用 Slate 的 Input 小部件，该小部件将 state 传递给 Code Sandbox 小部件并显示它：

数据方向：Slate 上下文 → 小部件（非持续，一次性“获取”）

此函数返回小部件的当前 state，该 state 最初由 state 字段填充。

SlateFunctions.getState 返回小部件当前 state 的 JSON 对象，该 state 最初由 state 字段填充。你可以访问该对象的不同属性（即不同的“state”）。

SlateFunctions.getState 将返回你的 state 字段的 JSON 对象，你可以访问该对象的不同属性（即不同的“state”）。

setState

数据方向：部件 → Slate 上下文。

SlateFunctions.setState 会修改部件的状态，这既影响使用 Handlebars 引用该部件状态的外部部件，也影响未来的 getState 调用。它接受两个参数：表示要修改的状态部分的字符串，以及表示该部分新值的 JSON 数据块。

例如，如果您希望将部件的视图高度设置为 4 但保留所有其他属性，您可以调用 SlateFunctions.setState("view.height", 4)。如果您想覆盖 整个状态（而不仅仅是高度），可以将 "" 作为第一个参数传入，而不是 "view.height".

加载顺序

Code Sandbox 部件按以下顺序加载：

  1. Slate（包含该部件的父框架上下文）先加载，然后加载部件 iframe。
  2. Slate 将部件的 "state" 发送给该部件（详情请参见下文的 Interactions），随后发送 CSS、HTML、库和 JavaScript。
  3. iframe 接收并设置以下内容：
    • 附加 CSS 和 HTML。
    • 执行库
    • 执行 JavaScript
    • 触发相应的 "SlateFunctions"（输入）。
  4. 用户与部件框架交互（更新状态、触发事件、创建操作等）。这些操作反过来又可以修改或生成 "SlateFunctions"，并从部件发送到父级 Slate 框架。如果这些部件输出被指定为 Interactions（输出），则可以在 Slate 的其余部分中使用。

安全性

此部件的安全模型与 Slate 函数的安全模型非常相似。代码将在沙盒化的 iframe 中执行，输入和输出通过 postMessage 传输。这使我们能够安全地执行不受信任的 JavaScript 代码。唯一的修改是 iframe 在页面上可见，这并不会改变安全模型。

调试技巧

在 Chrome 控制台中，您可以选择默认为 top 的下拉菜单，然后选择 codeSandboxIframe.html。这会使您在控制台中输入的任何 JavaScript 在 widget 的环境中执行。这在您尝试弄清楚如何让 widget 正常工作时非常有用，因为对 JavaScript 字段的更改会强制重新加载 widget。

第三方代码

我们建议在使用第三方代码时遵循以下通用方法：

  • 检查许可证以确保您可以使用它。
  • 通过寻找包含尽可能少的独立 JavaScript 代码块的示例，来最大限度地降低代码复杂度。
  • 如果 JavaScript 使用了任何库，请从源处下载 .js 文件，并将上传文件的 Foundry Project 路径放入 library 部分。您也可以直接链接 URL，并在之后进行测试，以确保它不与 CSP 或 CORS 策略冲突。
  • 确保 HTML <script> </script> 标签中的所有 JavaScript 都被重构出来并放入 JavaScript 部分。
  • 使用 Slate 函数进行交互：
    • 使用以下方式将您需要的任何数据从 Slate 传递到自定义 Code Sandbox SlateFunctions.getState.
    • 要将 widget 内的交互传达给 Slate 的其余部分，您可以标记 SlateFunctions.triggerEvent 到该函数。
    • 要让 widget 响应来自 Slate 其余部分的 Action，您可以标记 SlateFunctions.onAction 到该函数。
