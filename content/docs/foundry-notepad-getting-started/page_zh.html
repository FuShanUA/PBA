开始使用

本教程将引导您创建一个新的 Notepad 文档，添加文本、图像和表格，然后将文档导出为 PDF 或 DOCX。

创建 Notepad 文档

有多种方法可以创建新的 Notepad 文档：

  • 将鼠标悬停在 Foundry 侧边栏中的 Notepad 应用程序图标上，然后选择 新建文档.
  • 选择 + New > Notepad document ，置于 项目 folder.
  • 在项目文件夹中的任意位置右键单击，然后选择 New > Notepad document.

创建文档后，首先添加一个标题：输入您的标题文字，然后选择 大标题 在顶部工具栏中，以相应地设置文本格式。

接下来，向文档中添加一些文本，并添加第二列以在其旁边放置图像。为此，请先选择 添加列 在工具栏中，然后将现有图像拖放到新列中，或者直接从剪贴板粘贴图像。

最后，在文档底部插入一个表格。为此，请通过在段落中键入 / 快捷方式，或在工具栏中选择 + 微件 并搜索以下内容来打开小部件插入菜单 表格.

导出 Notepad 文档

To 导出文档以与他人共享，请选择 文件 菜单，然后选择 导出为 PDF or 导出为 DOCX 以触发文档渲染过程。当 Notepad 完成渲染后，Foundry 会自动下载并以相应的文件格式保存文档。

搜索 Notepad 文档

使用直方图中的 搜索文档 栏，在 Notepad 主页上搜索您可以访问的任何文档。

要从当前查看的文档导航到 Notepad 主页，请选择 File > Open document.
