对象上的函数

您可以使用 Python 本体论 SDK 编写与本体论交互的函数。

生成 Python 本体论 SDK

要生成 Python 本体论 SDK 客户端，请导航至 资源导入 侧边栏 并选择 添加 > 本体论。然后，选择您所需的本体论，并导入您希望在 函数中与之交互的对象和关联。保存以确认您的选择后，将出现一个横幅，指示尚未创建相应的 OSDK。

导航至 SDK 生成 选项卡以生成并安装 OSDK。

如果 SDK 生成返回如下导入错误 cannot import name 'Equipment2' from 'ontology_sdk.ontology.objects'，请确认您已在界面底部的蓝色栏中选择了本体论。导入对象类型并不会选择 SDK 生成所需的本体论。

如果尚未生成 OSDK，系统将提示您为生成的包输入名称。 生成第一个版本后，包名称将无法更改。

选择 创建新版本后，您可以在此视图中监控生成进度。

生成完成后，您需要使用 按钮安装新生成的版本。

这将在任务运行器面板中触发交互式安装。 该任务成功完成后（任务运行器将显示 BUILD SUCCESSFUL），OSDK 的代码补全功能即可在您的代码辅助会话中使用。

该 meta.yml 文件也将被更新，以包含对生成的包的引用。 您可以手动更新 meta.yml ，而不是使用安装助手，但如果您手动更新 meta.yml，您将需要重新构建代码辅助会话以使这些更改生效。

每当您在侧边栏中导入其他资源时，系统都会提示您生成并安装包含这些资源的新版本 OSDK。 此外，如果您修改了已导入的资源（例如，向已导入的对象类型添加新属性），则需要生成新的 OSDK 版本以使这些更改生效。

生成的 OSDK 还为结构体属性提供了类。请从每个结构体属性类所属的对象特定模块中导入该类：

示例

以一个名为 Aircraft 且属性为 brand 和 capacity的对象类型为例，您可以编写一个 接受 Aircraft 对象的函数，并按如下方式对其进行总结：

from functions.api import function
from ontology_sdk.ontology.objects import Aircraft

@function
def aircraft_input_example(aircraft: Aircraft) -> str:
    return f"{aircraft.brand} aircraft, holds {aircraft.capacity} passengers"

此外，如果您想搜索 Aircraft 满足特定容量阈值的对象，可以编写 以下内容：

from functions.api import function
from ontology_sdk import FoundryClient
from ontology_sdk.ontology.objects import Aircraft
from ontology_sdk.ontology.object_sets import AircraftObjectSet

@function
def aircraft_search_example() -> AircraftObjectSet:
    client = FoundryClient()
    return client.ontology.objects.Aircraft.where(Aircraft.object_type.capacity > 100)

from functions.api import function
from ontology_sdk.ontology.object_sets import AircraftObjectSet

@function
def aircraft_dataframe_example(aircrafts: AircraftObjectSet) -> int:
    df = aircrafts.to_dataframe()
    return df['capacity'].sum()
