Foundry Map：在 Foundry 中进行地理空间分析

发布日期：2022-11-22

绘制您世界的数字孪生

借助 Foundry Map，您现在可以在统一的地理空间环境中汇集并分析数据。数据导入本体论后，即可将对象引入 Map，与栅格影像和地理空间图层一起进行分析。不同技术水平的用户现在都可以构建、管理和搜索自主的地理空间应用程序，并在整个 Foundry 中轻松共享和使用这些应用。

使用 Foundry Map 来：

  • 探索地理空间对象之间的关联，并遍历物理网络。
  • 可视化来自多种来源的情境地理空间数据，包括大规模矢量数据和卫星影像。
  • 查看时间数据，例如事件或对象随时间移动的轨迹。
  • 使用边界框和多边形相交查询，以地理空间方式搜索点数据和多边形数据。
  • 通过绘制形状与地图交互，添加注释，或执行地理空间操作（例如创建区域或面积）。

通过轨迹分析跟踪您的资产

Foundry Map 提供实时和历史位置数据，使用户能够可视化指定对象随时间变化的轨迹和移动情况。此功能可应用于任何移动资产，例如飞机、船舶和包裹。

轨迹分析还可以与其他时间数据（例如传感器、IoT 数据流和事件）相结合。首先选择任意历史、当前和/或未来时间范围，然后确定特定时间点来分析对象的位置。这使您能够更好地了解特定时刻世界的整体状态。

为您的时间序列数据添加色彩

借助强大的颜色控制功能，Foundry Map 让可视化模式、进行预测和回答关键问题变得更加容易。用户可以根据数据值更改地图上对象的颜色和样式，并将时间序列、时间相关属性和相关事件汇集在一起，进行针对性的情境分析。例如，此地图展示了雪崩区域、气象站和 SNOTEL 站的组合，显示随时间变化的积雪深度、位置以及用颜色编码的严重程度。在一个屏幕中获得整体直觉，然后使用图表轻松查看感兴趣的特定点，或跳转到 的流可在 以进行专门的时间序列分析。

我应该在什么时候使用 Foundry Map？

我们建议在地理空间工作流中使用 Foundry Map，尤其是在同时依赖地理空间和时间信息的分析中。Foundry Map 可用于独立分析、作为生成新地图的模板，或作为强大的地理空间组件嵌入到 Workshop 应用程序中。

Foundry Map 的推出不影响其他 Foundry 应用程序中现有地图的使用。现有的地图组件（例如 Slate、Contour 和 Quiver）将继续像以前一样运行。

访问 Foundry Map 文档 了解如何设置您的第一张地图。

Slate：重新设计的依赖关系图

发布日期：2022-11-10

今天，我们自豪地推出全面重构的依赖关系图！依赖关系图帮助用户调查和理解 Slate 应用程序中不同组件之间的关联，并管理成熟应用程序的复杂性。

在此更新中，其他应用程序组件（如操作、事件和全局变量）现在也会在图中呈现。节点视觉重新设计和新的布局引擎提高了可读性，尤其是在复杂视图中。而且，通过小部件、函数和查询配置面板中的快速链接，比以往任何时候都更容易进入图视图。

在文档中了解有关新依赖关系图的更多信息。

Foundry Reports 即将下线

发布日期：2022-11-01

注意： 本通知宣布将 弃用 Foundry Reports 功能，转而支持 Foundry 中的其他报告、仪表盘和协作工具。

自2023年5月初起，大多数客户将无法再创建新的 Foundry Report[1]，现有的（"旧版"）Foundry Report 将变为只读。除非需要编辑，旧版 Foundry Report 无需转换或迁移到新格式。

所有客户现在可以使用以下选项来替代 Report 的 仪表板 和 报告 功能：

  • Contour 仪表板 适用于由 Contour 分析驱动的内容。Contour 仪表板相比 Report 提供了更强的交互性，例如图表间筛选功能，以及在迭代分析时通过简单的拖放界面构建仪表板。Contour 仪表板还支持全屏演示视图和 PDF 导出。 开始使用 Contour 仪表板。
  • Quiver 仪表板 适用于由 Quiver 分析驱动的内容。Quiver 仪表板提供了 Foundry Report 无法实现的功能，因为 Report 不支持嵌入大多数 Quiver 可视化类型。 开始使用 Quiver 仪表板。
  • 或 适用于跨产品报告。借助 Notepad，您可以创建实时更新和静态（“时间点”）文档、为文档添加批注、在平台内共享文档，以及将文档导出为 PDF。 开始使用 Notepad。

在禁用新 Report 创建功能之前，Palantir 将提供以下功能：

  • 支持将 Contour 仪表板导出为 PDF（预计2022年底推出）。
  • 支持按计划通过电子邮件发送 Notepad 文档（预计2023年初推出）。
  • 支持将旧版 Report 转换为 Contour 仪表板或 Notepad 文档（预计2023年初推出）。

联系方式 Palantir 支持 如有任何疑问，请联系我们。

[1] 对于需要使用 Code Workbooks 中的内容创建仪表板的客户，我们仍将支持编辑现有 Report 和创建新 Report。阅读更多关于此用例的信息 此处.

更多亮点

为了形成闭环，流数据有时需要在 Foundry 中经过富化和转换后回流到源系统。我们已推出其中部分导出连接器的测试版，并正在投入打造一流的导出解决方案。

应用中新增了分析选项卡 | 资源管理应用中的分析选项卡让用户有机会更深入地探索其使用数据。用户可以按使用账户、项目、本体论和来源来探索使用情况。使用量可以分组汇总探索，也可以在单个 Foundry 数据集或资源的级别查看。

Analytics | Contour

为 Contour 地图板添加自定义分桶颜色样式的等值线图功能 | 新地图板中的等值线图层现在可以使用用户自定义的分桶进行着色。用户可以为分桶定义自定义范围以及代表这些分桶的颜色。地图将使用这些信息来决定每个区域应显示的颜色。

Analytics | Notepad

允许从 Notepad 模板导出 PDF 而不保存 Notepad | 此前，通过 Workshop 的 Notepad 模板按钮从模板生成并下载为 PDF 的 Notepad 文档总是需要保存到 Compass 中。新的"从 PDF 导出保存 Notepad"选项（新控件的默认选项）提供了不保存生成文档的选项。

新增打印页面尺寸选项 | 为 Notepad 文档引入了配置页面尺寸的新打印选项。可用选项包括：letter（当前默认）、legal、tabloid、A3、A4 和 A5。更多信息请参阅 Notepad 文档.

Analytics | Quiver

新增创建数组转换 | 新增了通过引用现有数组或手动指定值（静态值、引用列或引用参数）来定义数组的功能。这可以用作单个卡片，也可以在转换表中应用。

由转换表支持的改进版事件图 | 更新后的 更新了时间序列搜索（TSS）和多时间序列搜索（MTSS） 现在除了对象集之外，还可以绘制来自转换表的事件数据。借助转换表，您可以在绘图之前修改（例如日期偏移）或丰富底层事件数据。图表在时间线上绘制事件，突出显示每个时间间隔内的事件数量。将鼠标悬停在某个时间间隔上会显示该间隔内的事件列表，将鼠标悬停在某个事件上会显示该事件的详细信息。颜色和事件详细信息也是可配置的。

卡片编辑器中的新依赖项视图 | 在卡片编辑器中新增了依赖项视图，显示所选卡片的数据血缘（输入和输出卡片），以便在无需离开画布的情况下简化依赖项跟踪。为了简化依赖项导航，点击输入或输出卡片将把焦点切换到该卡片。

转换表的新输入类型（时间序列） | 时间序列图现在可以 作为转换表的输入。这会将时间序列数据转换为表格格式，以便对其进行操作、编辑或丰富。

为从 Quiver 调用对象函数 (FoO) 和操作添加了数组输入类型支持 | 现在可以将 Quiver 中的数组基元传递给定义了数组输入的 FoO 函数和操作。

日期/时间布尔转换已发布 | 新增了使用 布尔日期/时间转换 比较时间戳的功能，包含以下转换： before, on or before, after, on or after, on, not on日 between.

转换表的新输出类型（表格时间序列） | 新增了直接 将表格格式的时间序列数据 （时间戳和值）通过转换表转换为 Quiver 时间序列的功能，从而能够使用 Quiver 中提供的所有时间序列可视化和转换。

应用构建 | Slate

添加依赖关系图弹出窗口 Chart XY 小部件：支持累积总和序列 依赖项查看器 现在可以像其他编辑器面板一样在新全屏窗口中打开。

移除代码沙箱权限检查 Chart XY 小部件：支持累积总和序列 代码沙箱 小组件现在对所有用户可用，不再需要特权权限。

Shift 点击允许选择小组件 | 现在可以通过按住 Shift or Cmd/Ctrl将 Slate 小组件侧边栏中的小组件添加到多选组。以前，只有画布上所做的选择才能添加到多选组。
