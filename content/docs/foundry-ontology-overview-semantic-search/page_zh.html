语义搜索

语义搜索是一种基于文本固有含义或上下文进行搜索的方法，而非仅仅依赖关键词或其他传统搜索方法。

语义搜索是通过使用 AI 模型将文本转换为向量来实现的，这些向量是数字数组，被称为“嵌入”（embeddings）。如果模型有效，那么在 N 维空间中彼此接近的向量（每个向量的维度为 N）就是具有相似底层含义或语义含义的向量。例如，“口罩”（face mask）的嵌入向量会更接近“面部遮挡物”（face covering）的嵌入向量，而不是“呼吸器”（respirator）的嵌入向量。

如果嵌入的文本随后与 本体论中的特定对象相关联，那么您由搜索驱动的运营工作流将变得更加有用。查找相关实体或与特定搜索查询相关的实体，只需在 N 维空间中查找最近的向量即可。
