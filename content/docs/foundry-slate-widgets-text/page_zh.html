图像小部件

直方图 图像 小部件是文本小部件的简单扩展。该小部件使用 HTML 图像标签来创建图像。您需要先将图像上传到 Foundry，或将其托管在 Slate 可以访问的其他位置，然后设置图像标签 src 属性为图像 URL。对于托管在 Foundry 中的图像，图像 URL 为 https://<FOUNDRY_URL>/blobster/api/salt/<RID>。您可以通过在 Foundry 中打开图像、右键单击图像并复制图像地址来访问此 URL。请按照以下示例在您的图像小部件配置中进行设置：

<img src="https://<FOUNDRY_URL>/blobster/api/salt/<RID>">

卡片小部件

直方图 卡片 小部件是文本小部件的扩展。该小部件使用 HTML div 来创建卡片，并使用 每个 语句来填充它们。当您向应用程序添加卡片小部件时，该小部件会预填充一些骨架代码，您可以替换这些代码来自定义您的卡片。

  • #each : 集合是要迭代以创建相应数量卡片的对象列表。您还需要取消注释 /each 文本末尾的
  • item 键： 设置为 this 在双花括号中，以允许选择卡片。
  • 标题： 这是显示为每张卡片标题的文本。要从查询中选择项目，您可以使用语法 lookup query.value @index 在 handlebars 中。
  • 内容： 这是每张卡片上标题后面的文本。它可以像标题一样从查询中提取。

文本小部件

文本小部件是 Slate 中用途最广泛的小部件之一。它也是许多其他小部件（如 HTML、图像、卡片和列表）的基础。这些小部件本质上是以一些默认代码开头的文本小部件，为您提供正确的选项。

文本小部件有两种模式： Markdown 模式 和 HTML 模式。Markdown 是一种可渲染为 HTML 的轻量级标记语言，因此您在 HTML 模式下可以做的任何事情，在 Markdown 模式下也可以完成。Markdown 模式让您可以利用更简单、可读性极强的 Markdown 语法。例如，要将某些文本设置为标题（H1），只需在其前面添加 # 符号：
