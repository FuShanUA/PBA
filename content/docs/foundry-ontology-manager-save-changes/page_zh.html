将更改保存到本体论

保存您的更改

您在 Ontology Manager 中所做的任何更改都会以进行中的状态本地存储。要使这些本体论更改对其他人可用并反映在面向用户的应用程序中，您必须保存您的更改。要保存更改：

  1. 选择 保存 从应用程序右上角的应用程序标头中。
  1. 打开 查看编辑 对话框来查看您的所有更改。
  2. 最后，选择 保存 以更新本体论。

处理错误和警告

如果 保存 按钮呈灰色，您可能遇到了阻止保存的错误。要解决此问题，您可以：

  • 滚动浏览您的更改并查看内联的错误消息，或者
  • 选择 错误 位于顶部的选项卡 查看编辑 对话框中查看阻止您保存的错误。

直方图 查看编辑 对话框还会以内联方式以及在 警告 选项卡中显示警告，提示您建议进行的更改。虽然必须处理错误才能保存，但警告不会阻止您保存。

如果收到错误，您可以使用打开快捷方式导航到需要在保存前编辑的资源。

对函数的更改只能在函数仓库中进行，而不能在 Ontology Manager 中进行。您可以从 Ontology Manager 中的函数实体视图导航到函数仓库。

处理更新和合并冲突

直方图 保存 如果自您开始进行更改以来，其他用户已保存了本体论，按钮也可能呈灰色。您需要选择 更新 从查看编辑对话框的顶部，将其他用户的更改与您自己的更改合并。

其他用户所做的更改与您工作状态中的更改之间可能存在合并冲突。系统将提示您解决这些冲突。您可以选择保留本体论最新版本中的更改，或者用您工作状态中的更改覆盖它们。

放弃您的更改

本体论中您编辑的每个资源在 查看编辑 对话框中都会有自己的条目。您可以通过将鼠标悬停在 查看编辑 对话框中的条目上并选择垃圾桶图标，来放弃您对某个资源所做的更改。

您可以随时通过选择 放弃 应用程序右上角标头中的按钮，或通过选择 放弃 在底部 查看编辑 对话框中，放弃您对本体论所做的所有未保存的更改。

回复警告消息

当您在 查看编辑 对话框中查看您的更改时，您可能会收到一条警告消息，提示您在保存前确认该警告。

对对象类型及其属性的编辑可能会对依赖这些对象类型的应用程序产生破坏性影响。此外，如果某个对象类型启用了回写功能，在编辑该对象类型时应格外小心，以确保不会删除对该类型对象所做编辑的历史记录。

有关哪些更改可能具有破坏性的完整说明，请阅读更多关于 潜在的破坏性更改.

在您仔细阅读警告消息中详述的更改影响并理解这些更改的含义后，您可以输入您编辑的实体的名称以继续保存。

保存失败时的故障排除

如果在保存时，支持本体论的后端服务遇到问题，您将收到一条错误消息“toast”（弹出窗口），如下图所示。在解释您无法保存原因的文本末尾，会显示错误消息的名称。错误消息名称将以以下前缀开头 OntologyMetadata: or Phonograph2:.

在本体论文档中，包含了对本体论进行不同更改时最常见错误的参考说明。如果您看到错误消息，请在文档中搜索该错误，以查看该错误及其修复方法是否已被记录。
