保存对本体论的更改

保存您的更改

您在 Ontology Manager 中所做的任何更改都会以进行中状态存储在本地。若要让这些本体论更改可供其他人使用并反映在面向用户的应用程序中，您必须保存所做的更改。要保存更改：

  1. 选择 保存 ，该按钮位于应用程序右上角的应用程序标头中。
  1. 打开 审阅编辑 对话框以查看您的所有更改。
  2. 最后，选择 保存 以更新本体论。

处理错误和警告

如果 保存 按钮呈灰色，则可能存在导致您无法保存的错误。要解决此问题，您可以：

  • 滚动浏览您的更改并查看内嵌的错误消息，或者
  • 选择 错误 选项卡，该选项卡位于 审阅编辑 对话框顶部，以查看阻止您保存的错误。

该 审阅编辑 对话框还会以内嵌方式显示警告，并在 警告 选项卡中显示与建议您进行的更改相关的警告。虽然必须先处理错误才能保存，但警告不会阻止您保存。

如果您收到错误，可以使用打开快捷键导航到保存之前需要编辑的资源。

对函数的更改只能在函数仓库中进行，而不能在本体论管理器中进行。您可以从本体论管理器中的函数实体视图导航到函数仓库。

处理更新和合并冲突

该 保存 按钮也可能呈灰色，这是因为自您开始进行更改以来，其他用户已保存了本体论。您需要选择 更新 （位于评审编辑对话框顶部），以将其他用户的更改与您自己的更改合并。

其他用户所做的更改与您工作状态中的更改之间可能存在合并冲突。系统将提示您解决这些冲突。您可以选择保留本体论最新版本中的更改，或使用您工作状态中的更改将其覆盖。

放弃您的更改

您在本体论中编辑的每个资源都将在 评审编辑 对话框中拥有自己的条目。您可以放弃对某个资源所做的更改，方法是将鼠标悬停在 评审编辑 对话框中的相应条目上，然后选择垃圾桶图标。

您可以随时放弃对本体论所做的所有未保存的更改，方法是选择 放弃 按钮（位于应用程序右上角的页眉中），或选择 放弃 （位于 查看编辑 对话框底部）。

响应警告消息

当您在 查看编辑 对话框中审阅您的更改时，可能会收到一条警告消息，提示您在保存前确认该警告。

对对象类型及其属性所做的编辑，可能会对依赖这些对象类型的应用程序造成破坏性影响。此外，如果某个对象类型启用了写回功能，则在编辑该对象类型时应格外谨慎，以确保对该类型对象所做编辑的历史记录不会被删除。

若要全面了解哪些更改可能具有破坏性，请详细了解 潜在破坏性更改。

在仔细阅读警告消息中详述的更改影响并理解这些更改的后果之后，您可以输入所编辑实体的名称以继续保存。
