媒体集

媒体集 使您能够存储、转换和处理您的媒体文件。媒体集可在整个平台中使用，为您的工作流提供支持。

有关如何将媒体集成到您的工作流的更多信息，请参阅相关文档：

受支持的媒体集架构

媒体集具有架构类型，用于定义可存储在媒体集中的文件类型，例如文档、图像或音频。每个媒体集还具有主格式，用于指定该媒体集中所有文件必须采用的文件格式。

媒体集支持的文件格式如下：

  • 音频
    • WAV（.wav）
    • FLAC（.flac）
    • MP3（.mp3）
    • MP4（.mp4）
    • NIST SPHERE（.sph）
    • WEBM（.webm）
  • DICOM
    • DICOM（.dcm）
  • 文档
    • PDF（.pdf）
    • DOCX（.docx）（作为 附加输入格式）
    • PPTX（.pptx）（作为 附加输入格式）
    • TXT（.txt）（作为 附加输入格式)
  • 电子邮件
    • EML (.eml)
  • 图像
    • PNG (.png)
    • JPEG (.jpg, .jpeg)
    • JP2K (.jp2)
    • BMP (.bmp)
    • TIFF (.tiff, .tif)
    • NITF (.nitf)
  • 电子表格
    • XLSX (.xlsx)
  • 视频
    • MP4 (.mp4)
    • MOV (.mov)
    • TS (.ts)
    • MKV (.mkv)

某些格式带有额外的限制。媒体集不支持需要专有功能才能查看的 PDF 文件,也不支持受密码、数字签名或加密保护的 PDF 文件。对于 XLSX 文件,媒体集不支持某些高级功能,例如复杂公式或嵌入式文件(包括图像)。

附加输入格式

媒体集还可以具有附加输入格式,以便将其他文件格式接受到媒体集中。上传后,这些文件将自动转换为主要格式。上传时仅接受指定的附加输入格式。

可以在创建媒体集时配置附加输入格式,也可以在媒体集详细信息选项卡下进行配置。

无法为 虚拟媒体集指定附加输入格式。

某些文件类型只能作为附加输入格式进行处理。例如 DOCX (.docx)、PPTX (.pptx) 和 TXT (.txt) 文件可以作为附加输入文件格式上传到 PDF (.pdf) 媒体集，即使不支持将其用作主要文件格式。

请注意，并非所有主要格式都支持附加输入格式。

多模态媒体集

媒体集还可以配置为多模态媒体集，从而允许上传任何文件格式。这对于需要多种媒体架构类型文件的工作流非常有用。

多模态媒体集存在一些限制。平台内预览仅适用于使用 受支持的架构类型的媒体项。此外，对于 附加输入格式 ，在使用虚拟多模态媒体集时也不支持预览。 访问模式 可与使用受支持架构类型的媒体项配合使用，但您需要先验证或过滤其架构。架构类型不受支持的媒体项无法与访问模式一起使用。

媒体引用

媒体集中的项可以通过 媒体引用进行引用。媒体引用使您能够在 Foundry 中使用媒体项，而无需复制媒体项本身。

您可以使用媒体引用来引用数据集中的媒体集项。这对于以表格形式将媒体项与元数据或其他信息相关联非常有用。例如，您可以将原始 PDF 与其文件名、页数和提取的文本作为附加列进行关联。

您还可以将媒体引用用作 模型适配器 的输入，用于批量推理管道。

要为您的媒体集生成媒体引用列表，请使用 “将媒体集转换为表行” 转换（在管道构建器中）。您还可以在 Python 转换中生成媒体引用，方法是导入 transforms-media 库并调用 list_media_items_by_path_with_media_reference 方法。

即使 路径 已被较新的上传覆盖，指向“被覆盖”媒体项的已保存媒体引用仍将继续渲染并引用原始项。

媒体引用类型

媒体引用可以指向以下两个位置之一：

  • 一个 媒体项 ，位于媒体集中。这是由 “将媒体集转换为表行” 转换以及 list_media_items_by_path_with_media_reference 上述方法生成的引用类型。媒体项支持 管道构建器中的全部媒体转换和表达式，例如 PDF 文本提取和 OCR。
  • 一个 文件 在常规 Foundry 数据集（由平台的目录服务支撑）中，而非媒体集中。此引用类型由 获取媒体引用（数据集） 转换生成，该转换位于 Pipeline Builder 中，可读取文件数据集，并为每个文件生成媒体引用和基本元数据。这些引用有助于在表格数据集中关联文件元数据，但不能作为 Pipeline Builder 中媒体转换和表达式的输入，因为它们需要实际的媒体集条目。

如果您需要在 Pipeline Builder 媒体转换中使用来自数据集的文件，请先将这些文件加载到媒体集中（例如，通过 Python 转换 使用 MediaSetOutput），然后从该媒体集而非源数据集生成媒体引用。

从媒体集中删除媒体条目

软删除

在平台中删除媒体条目后，该条目将不再可见，但其原始数据并未被永久删除。如果该媒体条目被直接链接，则仍可访问。

您可以从媒体集中删除媒体条目，方法是选择要删除的媒体条目，然后选择 删除 操作。为防止意外删除，此操作将要求您在弹窗中再次选择 删除 以确认您确实要删除媒体项。

成功删除该项后，媒体集将刷新并显示成功消息。现在您可以查看不含已删除媒体项的媒体集。

删除限制

对于通过构建管道更新的媒体集，不支持删除媒体项。
