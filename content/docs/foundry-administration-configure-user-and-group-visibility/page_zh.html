配置用户和组的可见性

成员发现 设置位于控制面板中，允许管理员控制组织内的用户是否可以发现同一组织中的其他用户和组。此功能通过阻止用户查看其组织中的其他成员，提供增强的隐私和安全隔离。

默认情况下，组织中的用户可以发现同一组织内的其他用户和组。禁用成员发现会阻止这种可见性，同时保持管理员和应用程序操作的正常功能。

当为组织禁用用户发现时，只有组织管理员才能查看该组织内的其他用户。组织的访客成员也可能同时是该组织的组织管理员。有关访客成员的更多信息，请参阅 注册和组织访问.

成员发现设置仅影响您组织内的发现。要管理跨组织协作，请参阅 跨组织协作.

配置成员发现设置

按照以下指南为组织配置成员发现设置：

  1. 导航至 控制面板 > 组织管理.
  2. 找到您的组织并选择 操作 > 管理成员发现.



  3. 配置成员发现设置：
    • 发现用户： 关闭此开关可防止该组织中的用户发现同一组织中的其他用户。
    • 发现组： 关闭此开关可防止本组织中的用户发现同一组织内的群组。


  4. 选择 保存 以应用更改。

消费者模式的优势

在消费者模式下运行时，配置私有组织可带来显著优势。

用户隐私

消费者无法看到其他消费者用户，从而在不同客户账户之间维护隐私。这确保了来自不同组织或客户群体的用户无法发现彼此的存在。

群组隔离

防止发现内部管理群组及其他消费者专用群组。用户将无法浏览或发现对其不可见的群组。

安全增强

减少有关组织结构和成员构成的信息披露。通过防止用户收集组织结构情报，限制了攻击面。

预期行为

管理员可以按预期看到所有用户，确保管理功能在消费者用户可见性受限的情况下仍能继续正常运行。

对功能的影响

成员发现设置不影响现有权限或访问权限。当禁用用户或群组可见性时，任何依赖于用户访问用户或群组详细信息能力的逻辑都可能失败。受限视图将继续正常工作，但任何依赖用户或群组可见性的用户自定义逻辑将无法访问该信息。

禁用成员发现功能后,相关功能将受到以下影响:

  • 用户无法: 浏览或搜索其组织内的其他用户和群组。
  • 用户可以: 根据跨组织可见性设置,与其他组织的用户和群组进行协作。
  • 管理员仍可: 对所有用户和群组的完整可见性和管理能力。
  • 应用程序可以: 凭借现有权限和访问模式正常运行。
