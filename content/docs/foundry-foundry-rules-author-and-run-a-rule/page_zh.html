编写并运行规则

以下步骤将指导您完成在 Workshop 应用程序中编写和运行规则的过程。

  1. 查找 Workshop Rule 应用程序： 在工作流配置界面中，选择文件夹，然后选择 Workshop 应用程序。





  2. 编写规则： 在上一步创建的 Workshop 应用程序中，点击 新建 按钮以开始创建规则。

    • (a) 在规则顶部的表单中填写名称、描述和其他信息。
    • (b) 编写您希望规则执行的逻辑。例如，这可以是一个简单的筛选器。
    • 点击 提交更改 ，为此新规则创建提案。



  3. 批准提案： 在 Workshop 应用程序的 提案 选项卡中，选择左侧新创建的提案。

    • 选择 批准 以将其激活为规则。



  4. 构建规则回写数据集和规则输出数据集： 导航至在 配置工作流时创建的输出数据集。规则回写数据集是规则对象类型的 回写数据集或物化数据集 ，其中保存了 转换管道 应用于您的工作流输入的规则。

    • 选择 操作，然后 探索数据血缘 以查看输入数据集。



    • 同时选中规则回写数据集 (d) 和输出数据集 (e)。

    • 在同时选中这两个数据集后，右键单击并选择 构建。



    • 构建完成后，输出数据集将包含新规则的结果。今后，这两个数据集可以放置在 计划任务 上，以使输出保持最新。
