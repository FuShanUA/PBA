转换媒体

媒体可以通过 管道构建器 和 代码仓库进行转换。

管道构建器适用于常见的媒体转换工作流，例如从文档和图像中提取文本、转录音频、将媒体与 LLM 结合使用等。

相比之下，代码仓库可用于更复杂或需要更细粒度控制的工作流，例如增量管道、从非媒体集输入中读取数据、使用外部库等。

这两种工具都可用于转换输入媒体集、写入输出媒体集以及写入输出数据集。但是，某些功能（例如以增量方式读取和写入媒体集，以及在媒体转换中使用表格数据）仅在代码仓库中受支持，而在管道构建器中不受支持。

访问模式

高级用户和开发者可以利用媒体集 访问模式，这些是预先配置的转换，可按需对媒体集中的媒体项执行。访问模式具有用于存储和优化调优的持久化策略，从而可以选择在每次请求时重新计算、在首次请求后无限期持久保留输出，或缓存一段时间。

Palantir 平台利用访问模式来优化处理或渲染媒体集项。例如：

  • Workshop 中 PDF 的缩略图和预览
  • Preview 应用程序中的缓冲音频波形
  • Map 中的切片卫星影像

默认可用的访问模式集合是根据所配置的媒体集架构确定的。其他转换仅能通过 API 调用注册为媒体集的访问模式。
