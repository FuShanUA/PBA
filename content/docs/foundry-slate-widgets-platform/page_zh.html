平台小部件类别包含以下小部件：

  • 对象卡片
  • 资源选择器
  • 时间序列
  • 操作

对象卡片

对象卡片小部件以 ObjectRID 作为输入。它将渲染在 Ontology 应用中定义的迷你对象视图（卡片）。对象卡片将关联到其 Object Explorer 对象视图。

表格格式

可以将此小部件与可重复容器结合使用，以填充对象视图表格。

例如，假设你有一个返回 RID 数组的 Slate 函数。你可以将对象卡片小部件插入可重复容器中以创建“表格视图”。你需要使用可重复容器的索引为对象小部件建立索引，因此在“Object RID”中你将指定： {{lookup f_function1 w_repeating_container.index}}.

这将根据函数返回的 RID 和可重复容器的索引，使用内置函数 lookup 建立卡片列表。

获取对象 RID

要获取 ObjectRID 输入，你有以下几种选择：

选项 1：Slate 提供了一个点击式 UI，即 对象集面板，你可以在其中进行对象查询，而无需手动构建查询。

选项 2：你可以通过导航到特定对象的对象视图并选择操作下拉菜单来获取该对象的 ObjectRid。在剪贴板中，它允许你复制 URL 链接。复制 URL 链接的最后一段，即 ?objectId={ObjectRID} （例如，如果 URL 是 ...?objectId=ri.phonograph2-objects.main.object.09d2e0e9-dd3c-49b2-8b96-0cb1bf005c1d 那么你的 ObjectRID = ri.phonograph2-objects.main.object.09d2e0e9-dd3c-49b2-8b96-0cb1bf005c1d).

选项 3：要从 ObjectTypeId 和 ObjectPrimaryKey 获取 ObjectRID，你需要使用 Get Object by Locator 端点。虽然 ObjectTypeId 和 ObjectPrimaryKey 可以在其他地方用于参数化 Object Explorer URL 链接，但在 Slate 中它们需要被解析为 ObjectRID。你可以动态组合 ObjectTypeId 和 ObjectPrimaryKey，并将其传入 Slate 查询以检索 ObjectRID（前提是端点已在你的实例上公开，并且你已将其设置为数据源）。

资源选择器

资源选择器小部件允许你在 Compass 中选择文件。

此小部件不会在页面上创建可视元素。相反，它会公开一个用于打开资源选择器的操作，以及一些用于处理所选资源的事件。

事件

  • w_resource_selector_1.didClose: 当资源选择器关闭时会触发此事件。
  • w_resource_selector_1.selectedRid.changed: 在资源选择器中选择资源时会触发此事件。 {{sl_event_value}} 将设置为所选资源的 RID。

操作

操作名称描述
w_resource_selector_1.open触发此操作将打开资源选择器对话框。

时间序列

Slate 的时间序列小部件提供了一种可视化时间序列图表的便捷方式。你可以使用系列 ID 将多个系列添加到同一图表中。你还可以通过以下方式配置可视化：

  • 指定标题、单位和颜色，或禁用十字线或图例。
  • 动态定义时间范围以指定视图窗口。
  • 为数据开启“流式模式”。

操作

Slate 的 操作小部件 允许 Slate 执行在操作中预配置的业务逻辑。将小部件添加到页面后，你可以：

  • 选择你有权访问的 Foundry 操作，
  • 直接或通过 Slate 的 handlebars 将默认参数传入你的操作表单，以及
  • 直接使用操作表单的 Submit 按钮提交，或通过 Slate 事件-操作对间接提交 w_widget.submit.

此外，Slate 还提供了以下与操作表单相关的 Slate 事件：

  • 提交（w_widget.success/w_widget.failure)
  • 验证状态（w_widget.ValidationSuccess/w_widget.ValidationFailure扩展而来），以及目标项目的
  • 渲染变更（w_widget.transitioned and w_widget.cssClassesUpdated).

最后，如果需要向用户隐藏 UI 并通过 Slate 事件触发提交，您还可以通过切换控件阻止操作表单显示。请参阅 Slate 事件 的文档以获取更多信息。

在 Slate 中使用 Foundry 操作之前，需要先创建该操作。请参阅 操作文档 的文档以获取更多信息。

对象定位器仅标识操作应用于哪个对象，它本身不会更改任何属性。修改对象的规则定义了提交会更新哪些属性，并 将每个属性映射到一个值 （例如操作类型的其他参数之一）。

例如，以在 操作类型入门中构建的工单优先级操作类型为例，其 Priority 参数接受 P0, P1，或 P2。在控件配置中，对象定位器会填充 Ticket 对象引用参数，并 P0 填充 Priority 参数。提交时，操作类型的规则会将 P0 写入所引用工单的 Priority 属性。

也可以在操作类型本身上配置默认值，使其在使用该操作类型的每个应用中都生效；请参阅 设置参数默认值。在 Slate 控件中设置的默认值优先于在操作类型上设置的默认值。

日期预填

日期应采用 ISO 8601 格式；例如， YYYY-MM-DD （例如 1990-01-12）是一种有效的日期格式。

时间戳预填

时间戳应遵循 ISO 8601 格式： YYYY-MM-DD[T]HH:mm:ss.SSS[Z] （例如 1990-01-12T23:00:00.000Z）。
