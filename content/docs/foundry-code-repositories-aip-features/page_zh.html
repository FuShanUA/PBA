Code Repositories 中的 AIP 功能

以下是 Code Repositories 中 AIP 驱动的功能列表。

AIP Assist

通过以下方式访问 AIP Assist 功能 向 AIP Assist 提问 选项、编辑器的右键菜单或内联选项，并使用 AIP Assist 增强您对代码的理解。

可以通过导航到以下位置来配置 Code Repositories 中的 AIP Assist 功能 Ask AIP Assist > Configure AIP Settings > AIP features.

代码解释

您现在可以在 Code Repositories 中使用 AIP 来解释代码片段或整个文件的用途。

查找错误

在 Code Repositories 中使用 AIP 来检查和调试您的代码。

转换

Code Repositories 中的 AIP 可以将您的代码转换为各种语言，例如 Python、SQL、Mesa 或 Java。

上下文感知附件

上下文感知附件允许用户将代码片段、文件和仓库附加到与 AIP Assist 的对话中。这些附件提供的上下文可以丰富 AIP Assist 的知识，并使其能够更准确地回答与代码相关的问题。您可以通过 AIP Assist 侧边栏或从以下位置附加支持的资源 向 AIP Assist 提问 来创建一个临时的实体级别维护窗口。

还可以通过高亮显示所需代码、右键单击并选择以下选项来附加代码片段 附加到 AIP Assist （从上下文菜单中选择），或直接使用显示在所选代码上方的内联代码辅助选项。

内联代码辅助 [Beta]

测试版

内联代码辅助目前处于 测试版 开发阶段，可能无法在您的注册租户中使用。功能在积极开发过程中可能会发生变化。

当高亮显示代码片段时，Code Repositories 现在提供内联代码辅助功能。 解释, 查找错误日 提问 选项会显示在所选代码片段的上方，使用户能够直接从代码中获取 AIP Assist 的针对性帮助。

可以通过打开以下位置来禁用此功能 向 AIP Assist 提问 编辑器右上角的下拉菜单并选择 配置 AIP 设置。在 AIP 功能 部分中，您可以配置 在所选代码上方显示 AIP Assist 操作 选项及其他 AIP 功能，以满足您的需求。

您还可以从以下位置访问这些 AIP Assist 功能 向 AIP Assist 提问 下拉菜单，或通过右键单击高亮显示的代码片段并从上下文菜单中选择可用的 AIP Assist 选项之一。

AI 错误增强器

AI 错误增强器提供全面的错误解释和建议的代码更改（如有），并提供对源文档的访问以获取更多信息。此功能可在以下 Foundry 应用中使用：

代码仓库

在 Code Repositories 中，该功能显示在 检查 和 预览 区域的字段中添加命令。

构建

在 Builds 中，此功能位于 作业状态菜单.

代码自动补全

该功能目前仅适用于 Python 仓库。

代码自动补全可以通过解析您当前打开的文件来自动提供相关的自动生成代码，帮助您朝着目标生成代码。

  • 要接受建议，请按 tab.
  • 要忽略建议，请按 esc，或开始输入其他内容。

可以直接在窗口底部的编辑器状态栏中切换代码自动补全的开启或关闭，或通过导航到 Settings (purple cog icon) > Preferences > AIP Features.

注意：AIP 功能的可用性可能会发生变化，且不同客户之间可能存在差异。
