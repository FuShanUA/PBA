安装

Palantir 模型上下文协议 (MCP) 使外部 AI 系统能够读取 Foundry 中的数据和元数据，并使用已配置的用户令牌权限通过 AI 友好的 API 端点进行交互。一旦外部系统通过 Palantir MCP 访问数据，其使用的治理责任将从 Palantir 转移到该外部系统，数据安全将取决于您与该外部系统的关系。使用 Palantir MCP 并不意味着将使用 Palantir 的 AI 模型；AI 模型提供方由您所连接的外部系统决定，例如 GitHub Copilot 对应的 Microsoft，或 Cursor。

以下说明介绍了如何在受支持的 IDE 中设置 Palantir MCP。或者，使用 AI 开发工具 （可在 VS Code 工作区中使用）来访问 Palantir MCP。

1. 在控制面板中启用 Palantir MCP

平台管理员必须首先通过 Control Panel 启用 Palantir MCP 以供使用。可针对特定的用户或群组子集配置访问权限。Palantir MCP 位于 Control Panel 的 代码仓库。

2. 配置您的 IDE 以使用 Palantir MCP

请参阅以下工具的说明：

  • Claude Code
  • Cline
  • Continue
  • Cursor
  • VS Code Copilot
  • Windsurf

Claude Code

  1. 生成用户令牌 （来自 Palantir），然后将其添加以替代 <token> （在下方代码中）。
  2. 替换 <your-foundry-hostname> （替换为您的 Foundry 主机名（例如， mycompany.palantirfoundry.com）。请勿添加 "https://" 前缀。
  3. 请参阅 Claude Code 文档 ↗ 以在您的 Claude Code CLI 中安装 Palantir MCP，特别是关于确定 MCP 应安装在哪个作用域的相关文档。我们建议将 MCP 安装在 项目作用域 ↗ 级别，以便将 MCP 服务器配置的作用域限定在当前项目。
  4. 请在终端中运行以下命令：
Copied!
1export FOUNDRY_HOST="<your-foundry-hostname>"
2export FOUNDRY_TOKEN=<token>
3claude mcp add palantir-mcp \
4    --scope project \
5    -e FOUNDRY_TOKEN='${FOUNDRY_TOKEN}' \
6    -- npx "-y" "palantir-mcp" "--foundry-api-url" "https://$FOUNDRY_HOST"

Cline

  1. 生成用户令牌 （来自 Palantir），然后在下方代码中将 <token> 替换为该令牌。
  2. 请将 <your-foundry-hostname> 替换为您的 Foundry 主机名（例如， mycompany.palantirfoundry.com）。
  3. 请查看 Cline 文档 ↗ 使用以下配置将 Palantir MCP 安装到您的 Cline 扩展中。
Copied!
1{
2    "mcpServers": {
3        "palantir-mcp": {
4            "command": "npx",
5            "args": [
6                "-y",
7                "palantir-mcp",
8                "--foundry-api-url",
9                "https://<your-foundry-hostname>"
10            ],
11            "env": {
12                "FOUNDRY_TOKEN": "<token>"
13            },
14            "disabled": false
15        }
16    }
17}

继续

  1. 生成用户令牌 （来自 Palantir），然后用它替换 <token> （在下方代码中）。
  2. 替换 <your-foundry-hostname> 为您的 Foundry 主机名（例如， mycompany.palantirfoundry.com）。
  3. 请查阅 Continue 文档 ↗ 以使用以下配置将 Palantir MCP 安装到您的 Continue 扩展中。
Copied!
1mcpServers:
2  - name: palantir-mcp
3    command: npx
4    args:
5      - "-y"
6      - "palantir-mcp"
7      - "--foundry-api-url"
8      - "https://<your-foundry-hostname>"
9    env:
10        FOUNDRY_TOKEN: "<token>"

  3. 请查看 Cursor 文档 ↗ 以使用以下配置将 Palantir MCP 安装到你的 Cursor IDE 中。

VS Code 中的 Github Copilot

  1. 生成用户令牌 （来自 Palantir），然后将其添加以替代 <token> 在下方代码中。
  2. 将 <your-foundry-hostname> 替换为您的 Foundry 主机名（例如， mycompany.palantirfoundry.com）。
  3. 请参阅 VS Code 文档 ↗ 以使用以下配置将 Palantir MCP 安装到您的 VS Code IDE 中。
Copied!
1"mcp": {
2    "inputs": [
3        {
4            "type": "promptString",
5            "id": "foundry-token",
6            "description": "Foundry user token",
7            "password": true
8        }
9    ],
10    "servers": {
11        "palantir-mcp": {
12            "type": "stdio",
13            "command": "npx",
14            "args": [
15                "-y",
16                "palantir-mcp",
17                "--foundry-api-url",
18                "https://<your-foundry-hostname>"
19            ],
20            "env": {
21                "FOUNDRY_TOKEN": "${input:foundry-token}"
22            }
23        }
24    }
25}
