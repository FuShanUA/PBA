时间轴

您可以使用时间轴查看基于时间的数据，以及配置时间窗口和 选定时间。您可以设置 选定时间和时间范围，进一步检查对象基于时间的属性，并在给定时间范围内筛选出特定对象。

时间轴可用于查看 事件，例如 事件对象 和 时间轴几何图形、 轨迹面包屑以及 时间序列。

即使时间轴未打开，时间轴的时间范围和 选定时间 仍会影响地图上可见的任何基于时间的数据。

基本控件

打开并启用时间轴

选择 时间轴 （位于地图画布左下方）以显示或隐藏时间轴。

将地图嵌入到 Workshop 中并使用 地图小组件时，您可以将时间轴配置为默认打开。

调整选定时间

时间轴上的光标位置表示地图的 选定时间。您可以通过以下方式调整选定时间：

  • 双击或右键单击时间轴。
  • 将光标拖动到新位置。
  • 选择时间轴标头中间的日期或时间戳，以显示日期和时间选择器。

要为游标指定更具体的日期，您可以点击游标表单来输入具体的日期和时间。

选择 查看最新 以将所选时间设置为当前时间。处于 最新数据 视图时，所选时间将自动更新以与当前时间保持一致。使用 最新数据 模式并结合 流式数据 ，以在地图上可视化实时更新的数据。

使用日期和时间选择器时，您只能选择对象图层当前时间范围内的时间。

您可以 在控制面板中为所有地图配置时间序列在 查看最新 模式下的默认时间选择和轮询间隔。此外，您还可以在设置面板中配置 每个地图的轮询间隔、时区和时间格式。

调整时间范围

您可以在时间轴右上角的标头中查看 时间范围 ，也可以从时间轴视图的开始时间和结束时间来查看。您可以按照以下指南，使用鼠标或触控板调整时间范围。

滚动控制：

  • 使用鼠标滚轮放大或缩小时间轴，并按 Cmd （macOS） /Ctrl （Windows），然后滚动以平移时间范围。
  • 使用触控板，通过垂直轻扫或向内/向外捏合来放大或缩小时间轴。

选择 时间范围 （位于时间轴标头右上角的功能区中），为时间轴输入特定的日期和时间范围。

若要获取基于时间轴中数据的自动时间窗口，请选择 缩放以适应 按钮（以双向箭头标识）。

筛选时间窗口

您可以通过以下方式筛选地图上的事件：

  • 按住 Shift，然后在时间轴上选择一个点，并在时间轴上拖动光标以创建时间筛选窗口。
  • 使用 时间筛选 按钮（位于时间轴的控制栏中）。

该 时间筛选 也可在地图画布顶部使用。地图上与筛选条件匹配的对象完全不透明，而与时间筛选不匹配的对象则会淡化显示。

时间轴回放

您可以使用播放按钮（⏵）自动移动时间光标；回放速度可通过速度预设（1x、2x、5x、10x、100x 等）进行调整。

光标将自动循环遍历时间轴上的时间窗口；如果存在时间筛选器，则会循环遍历该时间筛选器。

展开时间轴

当时间轴处于折叠状态时，添加到时间轴的数据不可见。不过，您仍可以更改时间范围、筛选后的时间窗口以及 所选时间。

若要让每种对象类型显示在各自的时间轴行中，请选择时间轴控制栏中的 展开 （）。

向时间轴添加数据

添加到时间轴的所有数据均按对象类型进行分组。

事件

事件对象

事件对象 将自动向时间轴添加事件图层。

时间轴几何图形

若要让新的时间轴事件几何图形图层显示在时间轴上，请添加 时间轴几何图形 （来自 图层 面板）。 详细了解如何为时间轴几何图形应用自定义样式。

轨迹面包屑

带有面包屑几何图形的轨迹也会渲染在时间轴上，具体取决于 时间范围 和地图视口。

您可以通过将所选时间移动到其他时间点，以动画方式呈现对象沿其轨迹的路径。

若要让新的轨迹面包屑图层渲染在时间轴上，请添加 轨迹面包屑几何图形 （来自 图层 面板）。

在时间轴上添加轨迹面包屑图层后，您可以从时间轴图例中该图层的条目访问更多时间轴几何操作，例如 更多样式设置 ，可在 “图层” 面板中进行。

时间序列 [Beta]

查阅 时间序列文档 以了解如何在地图的时间轴中添加和配置时间序列。

常见问题

对于大型对象集，基于时间的数据在地图或时间轴上是否可见？

如果您添加大型（超过 1,000 个对象）对象集，地图会自动在地图上加载对象，加载方式为 基于切片的加载。

对于基于切片的加载， 时间轴事件、基于时间的样式以及 筛选后的时间窗口 将不可用。要解决此问题，请切换到 基于对象的 加载。这可能还需要减少对象数量以提升性能。

为什么我在地图上看不到时间序列样式？

如果来自时间序列属性的样式不可见，这表示 Map 无法从时间属性中派生颜色。您应验证 所选时间 是否包含您的数据。

为什么我在地图上的对象上看不到基于时间的不透明度？

选择一个不可见的特定对象，并检查该对象上的时间戳或日期属性是否与 所选时间匹配。 您只能在 事件对象上配置基于时间的对象不透明度。

为什么我在地图上看不到任何轨迹面包屑？

带有面包屑几何图形的轨迹也会根据 时间范围在时间轴上渲染。

为什么我在时间轴上看不到任何基于时间的数据？

如果时间轴上没有任何可见内容，请使用 缩放以适应 按钮，在时间轴的 时间范围内显示地图上的时间事件。

可见时，时间轴会显示表示对象时间属性的线条。

此外，时间轴还会显示表示对象属性中时间范围的条形。
