本体论 SDK (OSDK)

本体论软件开发工具包（OSDK）允许您直接从开发环境访问本体论的全部功能。OSDK 支持 TypeScript 的 npm、Python 的 pip 或 Conda、Java 的 Maven，以及适用于其他任何语言的 OpenAPI 规范。

通过将 Foundry 用作后端，您可以利用本体论执行大规模查询和 Foundry 回写的强大能力，并结合细粒度的治理控制，加速安全开发可为您的组织赋能的应用程序。

要创建和管理 OSDK 应用程序，请使用 开发者控制台。本节涵盖特定于 SDK 的参考文档。

OSDK 的优势

构建 OSDK 旨在提供以下几项主要优势：

  • 加速开发： 借助 OSDK，您可以快速开始开发由 Foundry 本体论提供支持的应用程序。通过提供易于使用的本体论 API 访问方式，OSDK 使您只需极少的代码即可对本体论进行读取和回写。
  • 强大的类型安全性： 为 OSDK 生成的函数和类型仅基于与您相关的本体论子集。类型和函数从您的本体论生成，使您能够直接在编辑器中查询和探索您的本体论。
  • 集中式维护： 由于本体论在 Foundry 中进行集中构建和管理，您可以专注于应用程序构建，并减轻构建数据基础通常所需的维护负担。
  • 从设计上确保安全： OSDK 使用一个令牌，其作用域仅限于您希望应用程序访问的本体论实体，此外还受到用户自身对数据权限的约束。
仅在读取时强制执行

行级和列级访问控制（包括 受限视图、 对象安全策略以及 属性安全策略）会过滤用户通过 OSDK 可读取的内容。用户永远无法读取其无权查看的数据。这些控制措施不会延伸到 OSDK 响应负载，也不会延伸到您的应用程序对数据执行的任何操作。为了在数据向下游流动时保持数据受到保护，请将这些控制措施与 标记 或 基于分类的访问控制结合使用。有关完整模型，请参阅 访问控制传播。

此外，用于前端开发的 TypeScript 绑定为开发人员提供了一种便捷的方式，使其能够在 Foundry 上快速构建 React 应用程序。

生成的代码使用了有关本体论的元数据，包括属性名称和描述。您可以直接在编辑器中查看这些元数据。

入门

如果您使用代码而非 UI 来定义本体论，请考虑创建一个 SuperRepo ，而不是按照以下步骤操作。如果本体论和应用程序需要共同演进，并且您希望将它们作为单一工件进行版本控制和发布，那么 SuperRepo 是一个合适的选择。在 SuperRepo 中，您的对象类型、关联和操作使用 本体论即代码 进行声明，并与您的 函数 和前端位于同一个代码仓库中。OSDK 在本地生成，并会在这些定义发生变化时重新生成，因此您可以在单个编辑与预览循环中扩展本体论并使用新的类型，而无需在每次更改之间重新发布 SDK 版本。

要使用 OSDK 构建应用程序：

  1. 创建新应用程序 （在 Developer Console 中）
  2. 使用以下针对特定语言的指南之一来初始化您的应用程序：
    • TypeScript （或 将 OSDK 添加到现有的 TypeScript 应用程序中）
    • Python
    • Java
  3. （可选） 在 Foundry 上托管您的应用程序

如果您现有的应用程序在初始化时未使用 OSDK，请参阅 向已初始化的代码仓库添加 OSDK 以了解集成说明。

您还可以在 计算模块 中使用 OSDK，以便在容器化应用程序中与 Foundry 本体论对象进行交互。
