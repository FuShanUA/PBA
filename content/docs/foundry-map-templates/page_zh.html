地图模板

地图模板是一款强大的工具，可用于生成地图，其中包含用户在地理空间分析任务中可能需要的所有数据。

地图模板可用于生成新地图，还可以通过 小组件嵌入到 Workshop 模块中。

创建地图模板

首先，创建一个标准地图，作为您希望生成的地图的示例。然后，点击 保存旁边的向下箭头，再点击 另存为模板...。

配置地图模板

参数

地图模板允许您配置两类参数，这些参数可用于配置以下 Search Arounds：

  • 对象参数： 定义将使用哪些对象类型来生成最终的地图。
  • 非对象参数： 为基本数据类型定义附加输入。例如， string， float， double， integer， long， boolean， date，或 timestamp 输入。

Search Arounds

接下来，您可以配置与您的模板相关联的 Search Arounds 。每个对象参数都可以与 Search Arounds 相关联，这些 Search Arounds 既可以是使用本体论关联的简单 Search Arounds，也可以是 Search Around 函数。

Search Around 函数的任何非对象参数都可以映射到一个值，该值既可以是常量，也可以是参数。要将函数输入映射到参数，请点击输入框左侧的 参数 按钮，然后从下拉菜单中选择一个参数。

图层

对象图层可以配置为：

  • 常量： 该图层（包括其中的所有对象）将按原样包含在模板中
  • 样式： 此图层中的当前对象将被忽略，但所有图层样式都将包含在模板中。如果随后将此类型的对象添加到地图中（例如，通过模板 SearchArounds 或由用户添加），它们将以此方式进行相应的样式设置。
  • 或者，可以通过点击图层上的 X 来移除该图层，使其不包含在模板中。

叠加图层既可以包含在模板中，也可以移除。

系列

如果您在地图上固定了系列，则可以选择在生成的模板中包含或移除这些系列。

界面

生成的地图的界面可以通过以下方式进行配置：

  • Workshop 模块： 允许用户看到返回所选 Workshop 模块的链接。
  • 系列面板： 打开 Series 面板 （这是创建新的模板地图时的默认行为）。
  • 视口设置（飞至地图上的对象）： 自动将地图居中于地图上存在的对象。

使用地图模板

打开模板后，系统将提示您为模板参数提供值。

也可以使用 URL 查询参数将对象或对象集预加载到模板中：

  • 单个对象： 使用 objectRids 查询参数 objectRids=<object_rid>
  • 多个对象： 使用 objectRids 查询参数，并以逗号分隔对象 RID objectRids=<first_object_rid>,<second_object_rid>
  • 对象集： 使用 objectSetRid 查询参数 objectSetRid=<object_set_rid>

要与给定的参数值进行交互，请点击 参数 （位于顶部工具栏中）。这将允许您选择用作给定对象参数值的所有对象，或更改参数值以重新生成地图。

模板也可以嵌入到 Workshop 中，方法是使用 相应的小部件。
