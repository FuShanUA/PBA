地图模板

地图模板是一种强大的工具，可以生成包含用户进行地理空间分析任务所需全部数据的完整地图。

地图模板可用于生成新地图，也可以使用以下组件嵌入到 Workshop 模块中 微件.

创建地图模板

首先，创建一个标准地图作为您希望生成的地图的示例。然后，点击位于以下位置旁边的向下箭头 保存，然后点击 另存为模板....

配置地图模板

参数

地图模板允许您配置两种参数，可用于配置以下内容 Search Arounds:

  • 对象参数： 定义将用于生成结果地图的对象类型。
  • 非对象参数： 定义基本数据类型的其他输入。例如， string, float, double, integer, long, boolean, date，或 timestamp inputs.

Search Arounds

接下来，您可以 配置 Search Arounds 与您的模板关联。每个对象参数都可以与 Search Arounds 关联，后者可以是使用本体论关联的简单 Search Arounds，也可以是 Search Around 函数。

Search Around 函数的任何非对象参数都可以映射到一个值，该值可以是常量或参数。要将函数输入映射到参数，请点击 参数 输入框左侧的按钮，并从下拉菜单中选择一个参数。

图层

对象图层可以配置为：

  • 常量： 该图层（包括其中的所有对象）将原样包含在模板中
  • 样式： 该图层中的当前对象将被忽略，但所有图层样式将包含在模板中。如果随后将此类型的对象添加到地图中（例如，通过模板 SearchArounds 或由用户添加），它们将以此方式进行样式设置。
  • 或者，可以通过点击以下按钮删除该图层 X 在该图层上，使其不包含在模板中。

叠加图层可以包含在模板中，也可以被删除。

序列

如果您在地图上固定了系列，可以选择在生成的模板中包含或删除这些系列。

界面

生成的地图的界面可以通过以下方式进行配置：

  • Workshop 模块： 允许用户查看返回到所选 Workshop 模块的链接。
  • 系列面板： 打开 系列面板显示与所选对象相关的时间序列数据。 默认情况下，在创建新的模板地图时。
  • 视口设置（飞至地图上的对象）： 自动将地图居中于地图上存在的对象。

使用地图模板

打开模板后，系统将提示您为模板参数提供值。

也可以使用 URL 查询参数将对象或对象集预加载到模板中：

  • 单个对象： 使用直方图中的 objectRids 查询参数 objectRids=<object_rid>
  • 多个对象： 使用直方图中的 objectRids 查询参数，对象 RID 之间用逗号分隔 objectRids=<first_object_rid>,<second_object_rid>
  • 导入对象集： 使用直方图中的 objectSetRid 查询参数 objectSetRid=<object_set_rid>

要与给定的参数值进行交互，请点击 参数 位于顶部工具栏中。这将允许您选择用作给定对象参数值的所有对象，或更改参数值以重新生成地图。
