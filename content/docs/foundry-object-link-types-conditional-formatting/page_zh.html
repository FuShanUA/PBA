条件格式 支持为任何属性配置规则，并决定该属性的值在面向用户的应用程序中将如何呈现（例如颜色、对齐方式等）。在本体论管理器中配置条件格式后，格式规则将在对象资源管理器、对象视图、Quiver 和 Workshop 中生效。

对于示例 Aircraft 对象类型（位于对象资源管理器中，如上图所示）， type 和 wifi 属性的值显示在根据特定条件应用的彩色框中。添加这些内容的主要好处是使信息更易于快速理解。如果分析师要查找“JFK”机场内所有没有 WiFi 的“A320”飞机，只需看一眼上面的结果，就能看出“Q-AAY”正是他们需要的那架飞机。

我们来看看这些条件是如何应用的。

  • 对于属性 wifi，如果表中每个对象的该属性值为“true”，我们将其设为绿色；如果为“false”，则设为红色。
  • 对于属性 type，我们会根据与“A320”、“A321”和“A330”的精确匹配来分配颜色。

添加条件格式

在属性编辑器中：

  1. 选择要为其添加条件格式的属性。
  2. 您将在属性窗格中看到条件格式；请选择 添加规则 按钮。
  1. 点击新创建的默认规则以打开 编辑条件格式规则 编辑器。 请继续阅读，以了解更多有关规则编辑器各组件的信息。
  2. 修改规则。

复制规则

在属性编辑器中：

  1. 选择要从中复制条件格式规则的属性。

  2. 您将在属性窗格中看到条件格式；选择 复制规则 按钮以打开 复制规则 对话框。

  1. 选择要将条件格式规则复制到的属性。

如果要复制到的属性已经具有自己的条件格式规则，这些规则将被新规则覆盖。

复制后的规则将继续引用其原始属性。例如，如果某规则规定 wifi 值在“true”时应显示为绿色，而该规则被复制到 customer experience 属性，那么 customer experience 属性的值在对象的 wifi 值为“true”时也将显示为绿色。要更改规则引用的属性，只需选择该规则，然后从规则编辑器中的 属性 下拉列表中选择新的属性。

常见问题

这是否适用于现有的类型类？

条件格式的优先级高于现有的类型类（但有一个例外情况，详见 以下问题）。如果您同时配置了两者，将显示条件格式。不过，您可以在一个属性上使用条件格式，在另一个属性上使用类型类。

这是否适用于 Object Views 中的可编辑属性？

条件格式适用于已配置为支持 行内编辑的属性。条件格式不支持旧版 hubble:editable 属性类型类。
