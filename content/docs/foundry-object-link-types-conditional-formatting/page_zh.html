条件格式化 支持为任何属性配置规则，并决定该属性的值在面向用户的应用程序中如何呈现（例如颜色、对齐方式等）。在 Ontology Manager 中配置条件格式后，格式规则将应用于 Object Explorer、Object Views、Quiver 和 Workshop。

看看这些条件是如何应用的。

  • 对于属性 wifi，如果表中每个对象的该属性值为“true”，我们将其指定为绿色；如果为“false”，则指定为红色。
  • 对于属性 type，我们根据“A320”、“A321”和“A330”之间的精确匹配来指定颜色。

添加条件格式

在属性编辑器中：

  1. 选择要添加条件格式的属性。
  2. 您将在属性面板上看到条件格式；选择 添加规则 button.
  1. 点击新创建的默认规则以打开 编辑条件格式规则 editor. 继续阅读以了解规则编辑器各组件的更多信息.
  2. 修改规则。

复制规则

在属性编辑器中：

  1. 选择要从中复制条件格式规则的属性。

  2. 您将在属性面板上看到条件格式；选择 复制规则 按钮以打开 复制规则 对话框。

  1. 选择要将条件格式规则复制到哪些属性。

如果要复制到的属性已有自己的条件格式规则，这些规则将被新规则覆盖。

复制的规则将继续引用其原始属性。例如，如果某条规则规定 wifi 当值为“true”时显示为绿色，而该规则被复制到 customer experience 属性，那么 customer experience 属性的值在对象的 wifi 值为“true”时也会显示为绿色。要更改规则引用的属性，只需选择该规则并从 属性 规则编辑器中的下拉菜单中选择新属性。

FAQ

这是否适用于现有的类型类？

条件格式的优先级高于现有的类型类（有一个例外，详见 以下问题）。如果两者均已配置，将显示条件格式。不过，您可以在一个属性上使用条件格式，在另一个属性上使用类型类。

这是否适用于 Object Views 中的可编辑属性？

条件格式支持配置为 内联编辑的属性。对于使用旧版 hubble:editable 属性类型类的属性，条件格式将被禁用。
