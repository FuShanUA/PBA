窗口函数

直方图 PostgreSQL 文档 ↗ 对窗口函数的定义如下：

A 窗口函数 对与当前行以某种方式相关的一组表行执行计算。这类似于可以使用聚合函数执行的计算类型。但与常规聚合函数不同的是，使用窗口函数不会导致行被分组为单个输出行——各行保持其独立的标识。在幕后，窗口函数能够访问的不仅仅是查询结果的当前行。

本文档介绍了您可能希望在 Contour 表达式中使用的一些窗口函数的语法。有关窗口函数的更多背景信息，请参阅以下其他资源：

基本语法

在最基本的形式下，窗口函数可以分解为：

<function> OVER <some window>

等于 函数 是 支持的聚合函数 和 窗口 是表中行的子集。

您可以通过使用 () 来省略窗口——这会将函数应用于 所有 表中的所有行。

以下示例将在每一行中添加一个条目，其中包含 date 列中的最大值。

MAX("date") OVER ()

PARTITION BY

您还可以在窗口定义之前添加一个可选的 PARTITION BY 子句。 PARTITION BY 根据给定列中的值对窗口内的行进行分组。然后，聚合函数将 分别应用于每个分区.

例如，在一个包含人员记录的表中，以下表达式计算男性和女性的总数，并为每行中该行性别值添加一个计数：

COUNT("person_id") OVER (PARTITION BY "gender")

ORDER BY

对于您 do 定义窗口的表达式，您必须指定窗口的边界以及如何对表中的行进行排序。此子表达式可以简化为：

<how to sort table> ROWS BETWEEN <start location> AND <end location>

其中“如何对表排序”是指（1）按哪一列排序以及（2）升序还是降序排序。

指定窗口边界（“起始位置”和“结束位置”）有以下几种可能性：

  • UNBOUNDED PRECEDING：从表的开头到当前行。
  • n PRECEDING (e.g. 2 PRECEDING）：从当前行之前的 n 行到当前行。
  • CURRENT ROW
  • n FOLLOWING (e.g. 5 FOLLOWING）：从当前行到当前行之后的 n 行。
  • UNBOUNDED FOLLOWING：从当前行到表的末尾。

以下是一个示例表，其中标注了上述每种可能性：

...        |

(来源： blog.jooq.org ↗)

因此，给定一个包含销售记录的表，您可以使用以下表达式来查找最近 5 次销售的平均值：

AVG("sale_value") OVER (ORDER BY "date_of_sale" ASC 
    ROWS BETWEEN 4 PRECEDING AND CURRENT ROW)

“最近 5 次销售”即为窗口。 OVER 之后的子表达式按日期对表进行排序，然后针对每一行，计算前 4 行和当前行的平均值。

综合运用

以下复杂示例将上述所有语法结合在一起。 此表达式显示按产品类别分组的、截至当前销售的累计销售数量。

COUNT("sale_id") OVER (PARTITION BY "product_category" 
    ORDER BY "date_of_sale" ASC 
    ROWS BETWEEN UNBOUNDED PRECEDING AND CURRENT ROW)

条目现在按 分区 排序——换句话说，表先进行分区，然后在每个分区内对行进行排序。

更多示例

假设您有一个记录所购商品的表。您可以使用以下窗口函数派生一个新列，用于计算购买金额的累计总和：

SUM("item_cost") OVER (ORDER BY "purchase_date" ASC 
    RANGE BETWEEN UNBOUNDED PRECEDING AND CURRENT ROW )

要计算按 类别分组的累计总和，您可以添加分区：

SUM(“item_cost”) OVER (PARTITION BY “category” 
    ORDER BY “purchase_date” ASC 
    RANGE BETWEEN UNBOUNDED PRECEDING AND CURRENT ROW)

这将按“类别”列对行进行分区，在每个类别内按购买日期对行进行排序，并计算该类别中所有商品成本的累计总和。

非确定性

并列的排序值可能导致不同运行之间的结果不同

使用 ROW_NUMBER, FIRST, LAST, ARRAY_AGG，或 ARRAY_AGG_DISTINCT时，在窗口函数中，请注意非确定性问题。假设我们按列 A 进行分区并按列 B 排序。如果对于列 A 的相同值，存在多行列 B 的值也相同，那么这些窗口函数的结果可能是非确定性的——即在给定相同输入数据和逻辑的情况下，它们可能产生不同的结果。
