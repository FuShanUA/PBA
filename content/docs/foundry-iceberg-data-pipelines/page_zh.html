使用 Iceberg 表构建数据管道

您可以在 Python 转换 和 Pipeline Builder中使用 Foundry Iceberg 表作为输入和输出。本页概述了可用的工作流。

编写体验计算引擎非增量仅追加增量变更日志增量客户端加密

所有 Foundry 管理的 Iceberg 表都必须使用服务器端加密。最后一列指的是 客户端加密 选项，以及给定的管道类型目前是否支持读取和写入带有这一额外 Iceberg 表加密 ↗层的表。

请注意，用于单节点 Python 转换的 Foundry API 支持读取和写入客户端加密的 Iceberg 表，但该场景目前不支持谓词下推。

使用 Pipeline Builder 构建管道

Pipeline Builder 提供用于构建数据管道的无代码图形界面。

您可以在 Pipeline Builder 中将 Iceberg 表用作输入和输出：

  1. 打开 Pipeline Builder 并创建标准或更快的批量管道。
  2. 选择 Add Foundry data，然后选择现有的 Iceberg 表。
  3. 添加并连接工作流所需的转换。
  4. 在管道输出面板中，选择 Add pipeline output。
  5. 选择 Foundry Iceberg table，然后配置输出名称和位置。
  6. 预览结果，然后部署管道。

若要以增量方式处理输入，请使用标准 Spark 管道，并将 Iceberg 输入的计算模式设置为 Incremental。

仅当管道所在的项目配置了 Iceberg 存储时，才会显示将 Iceberg 表创建为管道输出的选项。请参阅 在 Control Panel 中配置 Iceberg 设置 了解详情。
