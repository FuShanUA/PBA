文档处理

本页面将讨论从 PDF 文档或图像中提取数据的一些实用注意事项。

数据提取

本页面提供了使用 管道构建器 解析 PDF 以进行语义搜索的基本指南，并就如何在 Workshop 应用中呈现信息提供了建议（当您只有文本内容时）。

语义搜索是处理 PDF 的强大工具，尤其是当内容被拆分为较小的“块”（chunks）并分别进行嵌入时，它可以帮助用户和工作流找到原本可能难以获取的重要信息。考虑到 PDF 中往往被忽视的海量非结构化知识，这一点尤其有用。

要使用此功能，只需将您的 PDF 上传到 Foundry，提取文本，对文本进行分块，搜索这些文本块，并在侧边渲染相应的 PDF 来展示搜索结果，以便用户进行事实来源的交叉验证。

请按照以下步骤导入 PDF 并从中提取文本：

  1. 将 PDF 作为媒体集导入。
  2. 将媒体集添加到管道构建器。
  3. 使用 获取媒体引用 看板。

  1. 使用 文本提取 看板。

分块

本页概述了如何将一种基本的分块策略纳入您的 语义搜索 工作流。分块在此上下文中是指将较大的文本片段拆分为较小的文本片段。这样做是有益的，因为嵌入模型对文本输入长度存在最大限制，而且至关重要的是，较小的文本片段在搜索期间会更具语义区分度。分块通常用于解析大型文档，例如 PDF。

主要目标是将长文本拆分为较小的“块”，每个“块”都有一个对应的本体论对象， 该对象关联回 原始对象。

分块在哪里进行？

分块由 Chunk string 板在 Pipeline Builder中执行。从转换菜单中添加该板，然后配置以下参数：

  • 表达式： 要拆分为块的文本列。
  • 块大小： 每个块的大致字符数。
  • 块重叠： 每个块与上一个块共享的字符数，这有助于保留跨块边界的上下文。
  • 分隔符： 该板用于拆分文本的有序、按优先级排列的分隔符列表。该板首先使用优先级最高的分隔符进行拆分，只有当块仍大于块大小时，才会转到下一个分隔符。

有关完整的参数参考，请参阅 Chunk string 函数文档。

分块示例

作为起点，我们将展示如何在 管道构建器中无需使用代码即可实现基本的分块策略。对于更高级的策略，我们建议使用 代码仓库 作为管道的一部分。

为了便于说明，我们将使用一个包含两列的简单两行数据集： object_id 和 object_text。为了便于理解， object_text 以下示例特意保持简短。

object_idobject_text
abcgold ring lost
xyzfast cars zoom

我们通过使用 Chunk String 看板来启动该过程，该看板会引入一个额外的列，其中包含一个数组，数组元素为 object_text 分割后得到的较小片段。该看板支持多种分块方法（例如重叠和分隔符），以确保每个语义概念保持连贯且唯一。

下方截图展示了 Chunk String 板块展示了一种简单的策略，您可以根据自己的用例对其进行调整。以下配置将尝试返回大小约为 256 个字符的文本块。实际上，该板块会按照优先级最高的分隔符拆分文本，直到每个文本块等于或小于文本块大小。如果不再有优先级最高的分隔符可用于拆分，而某些文本块仍然过大，板块将转而使用下一个分隔符，直到所有文本块都等于或小于文本块大小，或者没有更多可用的分隔符为止。最后，该板块将确保对于每个识别出的文本块，紧随其后的文本块与前一个文本块存在重叠，且该重叠覆盖前一个文本块的最后 20 个字符。

object_idobject_textchunks
abcgold ring lost[gold,ring,lost]
xyzfast cars zoom[fast,cars,zoom]

接下来，我们希望数组中的每个元素都有自己独立的一行。我们将使用 按位置展开数组 板块将我们的数据集转换为包含六行的数据集。每行中的新列（如下所示）都是一个结构体（映射），包含两个键值对，即数组中的位置和数组中的元素。

object_idobject_textchunkschunks_with_position
abcgold ring lost[gold,ring,lost]{position:0, element}
abcgold ring lost[gold,ring,lost]{position:1, element}
abcgold ring lost[gold,ring,lost]{position:2, element}
xyzfast cars zoom[fast,cars,zoom]{position:0, element}
xyzfast cars zoom[fast,cars,zoom]{position:1, element}
xyzfast cars zoom[fast,cars,zoom]{position:2, element}

接下来，我们将把 position 和 element 提取到它们各自的列中。

abcgold ring lost[gold,ring,lost]{position:1, element}1ring

xyzfast cars zoom[fast,cars,zoom]{position:0, element}0fast
xyzfast cars zoom[fast,cars,zoom]{position:1, element}1cars
xyzfast cars zoom[fast,cars,zoom]{position:2, element}2zoom
