容器限制

Palantir 通过安全计算模式（seccomp）限制各种系统调用（syscall）在我们的基础设施中运行。Seccomp 是 Linux 内核中的一项安全功能，允许将系统调用（syscall）限制应用于进程或容器。

Seccomp 过滤器提供了一种将容器可发起的系统调用列入允许列表的方法，并支持多种处理未列入允许列表的系统调用的方式，包括 LOG， KILL，以及 ERRNO 配置文件：

  • LOG 允许未列入允许列表的系统调用运行，但会将其记录到 auditd/osquery 以进行进程审计。
  • KILL 终止任何发起未列入允许列表的系统调用的进程。
  • ERRNO 阻止系统调用运行，但不会生成日志事件。

Seccomp 使我们能够通过阻止/记录被视为不安全或可用于逃逸容器的系统调用来减小容器的攻击面。这样做可在容器与主机之间以及容器彼此之间提供额外的安全层。您可以在下方找到我们在 Palantir 平台中自动阻止的系统调用列表。

如果您的应用程序发起了下方列出的系统调用，该进程将被终止，并且我们的事件响应团队将收到通知。如果您的使用场景需要使用这些系统调用，请联系 Palantir 支持团队获取帮助。

Linux 调用描述
ACCT ↗启用或禁用伯克利软件套件（BSD）风格的进程记账。
ADD_KEY ↗在内核中创建密钥。如果密钥已存在，则会被更新。
AFS_SYSCALL ↗未实现
BPF ↗对伯克利数据包过滤器（Berkeley Packet Filters）执行操作。
CLOCK_SETTIME ↗设置指定时钟的时间。
CREATE_MODULE ↗在 2.6 版本之后已弃用；内核创建可加载模块条目。
DELETE_MODULE ↗尝试按名称移除未使用的可加载模块。
FANOTIFY_INIT ↗需要 CAP_SYS_ADMIN 权限；创建 fanotify 组并返回事件队列的描述符。
FINIT_MODULE ↗将 ELF 映像加载到内核空间并执行符号重定位。
GETPMSG ↗未实现
GET_KERNEL_SYMS ↗在 2.6 版本之后已弃用；将内核符号复制到表中。
GET_MEMPOLICY ↗获取线程的非统一内存访问（NUMA）策略；每个 NUMA 节点都有独立的内存控制器，跨节点访问速度较慢。
INIT_MODULE ↗将 ELF 映像加载到内核空间。
IOPERM ↗设置端口输入/输出权限；仅适用于 i386。
IOPL ↗已弃用，建议改用 ioperm；仅适用于 i386；更改输入/输出特权级别。
KCMP ↗比较两个进程，以确定它们是否共享内核资源（例如虚拟内存）。
KEXEC_FILE_LOAD ↗加载可通过重启执行的新内核。
KEXEC_LOAD ↗加载一个新的内核，之后可通过重启来执行。
KEYCTL ↗从用户空间操作内核密钥管理功能。
LOOKUP_DCOOKIE ↗返回目录项的路径。
MBIND ↗为一段内存范围设置内存策略；与 NUMA 节点配合使用。
MIGRATE_PAGES ↗将进程中的所有页面移动到另一组节点；需要 CAP_SYS_NICE。
MSGRCV ↗System V 消息队列操作。
MOUNT ↗挂载文件系统；需要 CAP_SYS_ADMIN。
MOVE_PAGES ↗将进程的各个页面移动到另一个节点。
NAME_TO_HANDLE_AT ↗获取路径名的句柄，并通过句柄打开文件。
NFSSERVCTL ↗自 Linux 3.1 起已弃用；内核 NFS 守护进程的接口。
OPEN_BY_HANDLE_AT ↗与 NAME_TO_HANDLE_AT 类似；不是返回句柄，而是使用句柄打开文件。
PERF_EVENT_OPEN ↗设置性能监控。
PIVOT_ROOT ↗更改根挂载；需要 CAP_SYS_ADMIN。
PKEY_ALLOC ↗分配或释放保护密钥。
PKEY_FREE ↗分配或释放保护密钥。
PKEY_MPROTECT ↗对内存区域设置保护。
PROCESS_VM_READV ↗在进程地址空间之间传输数据。
PROCESS_VM_WRITEV ↗在进程地址空间之间传输数据。
PUTPMSG ↗未实现
QUERY_MODULE ↗在 2.6 中已弃用；向内核查询与模块相关的各种信息。
QUOTACTL ↗操纵磁盘配额；需要 CAP_SYS_ADMIN。
REBOOT ↗重新启动或启用重启组合键（CTRL-ALT-DEL）。
REQUEST_KEY ↗向内核的密钥管理设施请求密钥。
SECURITY ↗未实现
SETDOMAINNAME ↗获取或设置 NIS 域名；需要 CAP_SYS_ADMIN。
SETHOSTNAME ↗获取或设置主机名；需要 CAP_SYS_ADMIN。
SETNS ↗将线程重新分配到某个命名空间；必须在目标命名空间中具有 CAP_SYS_ADMIN。
SETSID ↗创建会话并设置进程组 ID。
SETTIMEOFDAY ↗设置时间和时区/CAP_SYS_TIME。
SET_MEMPOLICY ↗设置默认的 NUMA 内存策略。
SWAPOFF ↗禁用文件/设备上的交换空间；需要 CAP_SYS_ADMIN。
SWAPON ↗启用文件/设备上的交换空间；需要 CAP_SYS_ADMIN。
SYSFS ↗获取文件系统类型信息。
SYSLOG ↗读取和/或清空内核消息环形缓冲区。
TUXCALL ↗未实现
UMOUNT2 ↗卸载文件系统；需要 CAP_SYS_ADMIN。
UNSHARE ↗将进程执行上下文的部分内容分离；某些（但并非全部）选项需要 CAP_SYS_ADMIN。
USELIB ↗已弃用；加载供调用进程使用的共享库。
USERFAULTFD ↗创建用于处理用户空间缺页错误的文件描述符。
USTAT ↗已弃用；提供文件系统统计信息。
VHANGUP ↗虚拟断开终端；需要 CAP_SYS_TTY_CONFIG。
VSERVER ↗未实现
_SYSCTL ↗已弃用；读取和写入系统参数。
