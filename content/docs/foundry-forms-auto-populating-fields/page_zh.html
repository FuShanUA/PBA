自动填充字段

日落

对于 Foundry 上的数据录入或回写工作流，Foundry Forms 已不再是推荐方案。建议改用 Foundry Ontology 构建用户输入工作流，将相关数据结构表示为对象类型，并通过 Actions 配置回写交互。详情请参阅《Forms 概览》文档。 在 Foundry Forms 中，每个表单字段都可以配置一个或多个验证器，以防止格式不正确的输入。以下是一些验证器示例： 文档。

您可以使用自动填充表单字段来捕获有关表单的元数据，例如响应的创建者和创建时间。本页讨论在向表单添加字段时可用的七种自动填充字段类型。

计算

直方图 计算 字段基于其他单值字段显示计算值。用户可以配置以下选项：

  • 创建引用其他字段值的公式。您可以使用 expr-eval 库 ↗.
  • 支持的任何公式。自定义当公式计算结果为 NaN, infinity或其他错误时存储的值。
  • 指定 Output （数字、日期或时间戳）。
  • 设置 Number precision.
  • 提供 Default missing value 为每个参数提供值。
  • 设置 Unit label （例如， kg or lbs).
  • 使用直方图中的 代码编辑器 来设置 placeholder: string.

创建时间

直方图 创建时间 字段显示条目的创建或修改时间。用户可以配置以下选项：

  • 指定 Recorded format （例如 "YYYY/MM/DD" 或 "DD.MM.YYYY"）。
  • 将值记录为同时表示时区的时间戳，或记录为存储该位置当前时间的简单表示形式。
  • 记录打开表单而非提交表单的时间。

如果您开启 记录为本地日期或时间戳 选项，该字段将存储用户所在时区的当前时间。因此，不同条目上的时间可能无法反映它们实际发生的顺序。如果您在时间戳格式中包含 z 选项，则可以表达创建条目时所在的时区。

直方图 创建时间 字段可用于跟踪哪些条目是最新的、随时间推移创建了多少条目，以及它们往往在一天中的什么时间被创建。

创建者

直方图 创建者 字段显示条目创建者或修改者的用户 ID。

此字段可以与用户属性字段结合使用，以获取当前用户的姓名或电子邮件地址。

修改时间

直方图 修改时间 字段显示条目的最新修改时间。用户可以配置以下选项：

  • 指定 Recorded format （例如 "YYYY/MM/DD" 或 "DD.MM.YYYY"）。
  • 将值记录为同时表示时区的时间戳，或记录为存储该位置当前时间的简单表示形式。
  • 记录打开表单而非提交表单的时间。

与 创建时间 字段一样，如果您在字段配置中开启 记录为本地日期或时间戳 选项，该字段将存储用户所在时区的当前时间。因此，不同条目上的时间可能无法反映它们实际发生的顺序。如果您在时间戳格式中包含 z 选项，则可以表达创建条目时所在的时区。

直方图 修改时间 字段可用于跟踪哪些条目是最新的、条目被编辑的频率，或者自创建以来发生了哪些更改并需要下游更新。

修改者

直方图 修改者 字段显示条目修改者的用户 ID。

此字段可以与用户属性字段结合使用，以获取当前用户的姓名或电子邮件地址。

模板

直方图 模板 字段基于其他单值字段的值显示拼接值。用户可以配置以下选项：

  • 创建引用其他字段值的模板。
  • 使用直方图中的 代码编辑器 来设置 placeholder: string and errorValue: string.

示例

  • 假设您想在调查中组合评分字段和评论字段。您可以将 "score" 作为变量 a 将 "comment" 作为 b。然后，创建模板 {{a}} - {{b}} 并获得如下形式的结果 5 - very satisfied.

  • 要使用表单中所引用对象的属性，您可以使用对象属性显示字段来选择该属性，隐藏该字段，并从模板字段中引用它。

  • 您可以使用字段配置转换根据表单中值的其他条件来更改模板使用的字段或格式。例如，您可以要求受访者从下拉列表中选择标准响应，或者让他们在文本字段中编写自定义响应。将根据受访者的操作使用不同的模板。
