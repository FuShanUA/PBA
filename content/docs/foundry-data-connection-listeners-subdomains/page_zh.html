监听器子域名

HTTPS 和 WebSocket 监听器可以挂载到专用子域名，从而实现细粒度的入口控制、全面的治理工作流，并将安全性较低的端点与环境的主要注册域名隔离开来。之后，所有发往已挂载监听器的请求都必须通过该子域名进行。

监听器只能挂载到单个子域名，但一个子域名可以由多个已挂载的监听器共享。

监听器子域名的可用性

并非所有 Foundry 注册都支持自助使用监听器子域名。若要在 FedRAMP 和本地部署注册中使用，请联系 Palantir 支持团队。

创建监听器子域名

在将监听器挂载到子域名之前，您需要先在 Control Panel 中创建该子域名。

导航至 Control Panel > Domains & certificates，找到您想要为其创建新子域名的域名，然后选择 请求监听器子域名。请求提交后，新子域名需要由在该注册中具有 Information Security Officer 角色的用户批准。

每个注册最多只能有三个监听器子域名。如需更多，请联系 Palantir 支持团队。

入口允许列表

监听器子域名可以配置为两种模式之一：自定义入口或继承入口。

自定义入口

具有自定义入口的子域将拥有与其父域相互独立的入口配置。例如，您的注册可能仅允许来自您公司 IP 地址的入口流量。但是，可以将监听器子域配置为允许来自整个国家/地区或特定 IP 范围的入口流量，即使您原本并不希望允许这些来源访问您注册的其余部分。

为特定用例配置大小适当的入口允许列表可帮助您降低风险，尤其是在监听器使用非标准身份验证或授权协议的情况下。

监听器子域入口配置的一些示例场景可能包括：

  • 当外部系统未发布任何具体的 IP 地址列表，或者其发布的列表频繁变更时，为外部系统部署所在的区域添加覆盖整个国家/地区的入口。
  • 配置较小的 IP 范围（小于注册的主入口允许列表），以允许向仅具备基本授权或请求头密钥验证的监听器发送请求。

子域创建后，您可以在以下位置管理入口： 控制面板 > 网络入口。 了解更多有关入口配置的信息。

继承的入口

在某些情况下，为主域名配置的入口允许列表足以供监听器使用。此时，您可以创建子域名来继承父域名的入口允许列表配置。父域名入口配置的任何更改都会自动反映到子域名。

子域名一经创建，便无法再配置自定义入口。

使用监听器子域名

  1. 在 Data Connection 中导航至 监听器 标签页，然后选择一个监听器。
  2. 在监听器设置向导的 配置连接 步骤中，选择一个监听器子域名。
  3. 为您的监听器请求子域名后，系统将创建一个 Approvals 请求，管理员需要先批准该请求，监听器才可供访问。

挂载获得批准后，监听器将能够通过指定的端点处理请求（如果监听器尚未运行，则需在其启动后进行）。

更改监听器的子域名

如果您需要更改监听器当前使用的子域名，可以在 配置连接 步骤中选择一个新的子域名。这是一个破坏性操作，如果监听器正在使用中，将导致停机。

监听器将立即停止处理通过旧子域发送的请求，并且在新的子域挂载获得批准之前，将无法处理任何后续请求。届时，所有对旧端点的使用都需要切换到使用新子域的端点。

迁移到子域

对于在注册中推出子域功能之前创建的监听器，可以使用零停机迁移路径。创建新的监听器子域后，请导航至监听器设置向导中的 配置连接 步骤，并按照提供的说明操作。

端点轮换

如果监听器的端点遭到泄露，可在零停机的情况下将其迁移到新端点。

迁移端点使用方式的步骤如下：

  1. 生成一个新端点，并为旧端点添加过期日期。此时您应该有两个可用的端点。
  2. 将旧端点的所有用法替换为新端点。
  3. 删除旧端点。

为支持此过程，监听器提供了端点轮换机制。要轮换您的端点，请导航至监听器设置中的 配置 标签页，并找到 轮换端点 选项。请注意，您一次最多只能拥有两个端点，且最多只能有一个 活跃 端点。活跃端点是指未设置过期日期的端点。

轮换端点时，您可以选择为端点设置过期日期以实现零停机轮换，也可以选择立即将其删除。端点过期后，将无法再处理事件。

为端点设置过期时间后，如果需要更多时间将您的使用迁移到新端点，您可以延长该过期时间。

端点一旦过期，您将无法再修改过期日期。您必须删除已过期的端点，并通过执行另一次端点轮换来生成新的端点。
