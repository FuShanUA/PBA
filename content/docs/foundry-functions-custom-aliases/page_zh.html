自定义别名

自定义别名是存储字符串值的命名引用，这些字符串值可以是配置参数、功能标志或特定于环境的设置。通过使用自定义别名而非硬编码值，您可以将函数逻辑与特定配置解耦，并使您的函数可跨环境移植。

自定义别名存储用于配置的字符串值。若要在函数中按名称引用语言模型，请参阅 模型别名。

定义自定义别名

要定义自定义别名，请打开 TypeScript v2 或 Python 代码仓库，然后按照以下步骤操作：

  1. 打开 资源导入 侧面板，然后选择 Platform SDK 标签页。您将看到自定义别名部分。

  1. 选择 新建别名 以打开别名创建对话框。提供 键 作为别名名称，并提供 值 以与之关联，然后选择 创建。

别名键在仓库内必须唯一。

  1. 自定义别名将显示在 自定义别名 部分中。

编辑自定义别名

要编辑现有的自定义别名，请导航到 自定义别名 部分，该部分位于 Platform SDK 选项卡。选择别名旁边的铅笔图标，即可内联编辑其值。您还可以点击三个点来编辑别名键，或彻底删除该别名。

要在函数中使用自定义别名，请导入别名实用工具，并通过其键引用该别名：

在 Marketplace 中使用自定义别名

当您将使用自定义别名的函数添加到 Marketplace 产品时，这些别名会自动显示为 输入中的可配置参数。安装人员无需修改函数源代码，即可设置适合其环境的别名值。

设置描述

为了帮助安装人员了解如何配置别名，您可以为别名参数添加描述。在 输入 中选择该别名，以打开 详细信息 面板，然后在 常规 选项卡上输入描述。

添加预设

您可以为别名定义预设值，供安装人员在安装过程中选择。在 详细信息 面板中，选择 预设 选项卡，然后选择 手动覆盖 来定义一组允许的值。

安装体验

在安装过程中，安装人员将看到别名描述，并可以从预设值中进行选择或手动配置别名。安装完成后，该函数会将别名解析为安装人员所配置的值。
