Dataset row count

How can I calculate in bulk the number of rows in many datasets?

This code uses the Foundry API to trigger row count computation for a list of dataset RIDs and then read the results. Computation cannot be batched, so the code sends one POST request per dataset to the Foundry Stats API with the dataset RID and branch as parameters. Each POST request only queues the computation and returns the resolved dataset view, not the row count. The code then reads every result with a single POST request to the batch endpoint, which accepts a list of dataset RID and branch pairs and returns one response per request in the same order; split very large lists into smaller batches. Computation is asynchronous and can take a minute or longer for a large dataset, so repeat the batch request until each dataset reports a status of SUCCEEDED; the following code waits one minute between reads. The statuses ABSENT, PENDING, and RUNNING mean the row count is not available yet, while FAILED means the computation will not produce one. The returned rowCount is a wrapper object rather than a number, and an exactly computed count is available at exactValue.value as a decimal string.

Foundry also records statistics while a dataset is built, but that collection is best effort: it can time out or fail without failing the build, so build-time row counts are missing for some datasets. Triggering computation as shown below produces a row count for a dataset that has no recorded statistics.

# Base variables
base_url = "https://STACK_NAME.palantircloud.com"
branch = "master"

DATASETS_RIDS = [
    "ri.foundry.main.dataset.6d2cd3de-0052-xxxxx-c7ae2c4ab1d8"
]

headers = {
    'Authorization': 'Bearer eyg_PUT_YOUR_TOKEN_HERE_xxxx',
    'Content-Type': 'application/json'
}

# Proxies
proxyDict = {
    # "https": "https://proxyIfNeeded:port"
}

# Retries
retry = Retry(connect=1, backoff_factor=0.5)
adapter = requests.adapters.HTTPAdapter(max_retries=retry)
http = requests.Session()
http.mount("https://", adapter)

def trigger_row_count(dataset_rid, branch):
    response = http.post(f'{base_url}/foundry-stats/api/stats/datasets/{dataset_rid}/branches/{branch}', headers=headers,
                         proxies=proxyDict)
    raw_response = response.text
    curr_response = json.loads(raw_response)
    pprint.pprint(curr_response)

    return curr_response

def get_row_counts(dataset_rids, branch, attempts=12, delay=60):
    row_counts = {}
    pending_rids = list(dataset_rids)

    for _ in range(attempts):
        stats_requests = [{'datasetRid': pending_rid, 'branch': branch} for pending_rid in pending_rids]
        response = http.post(f'{base_url}/foundry-stats/api/stats/batch/stats', headers=headers,
                             proxies=proxyDict, data=json.dumps(stats_requests))
        if not response.ok:
            print(f"Could not read row counts: {response.text}")
            return row_counts

        # The batch endpoint returns one response per request, in the order the requests were sent.
        still_pending_rids = []
        for dataset_rid, curr_response in zip(pending_rids, json.loads(response.text)):
            status = curr_response['status']
            if status == 'SUCCEEDED':
                result = curr_response['result']
                row_counts[dataset_rid] = result[result['type']]['stats']['rowCount']
            elif status == 'FAILED':
                print(f"Row count computation failed for {dataset_rid}")
            else:
                still_pending_rids.append(dataset_rid)

        pending_rids = still_pending_rids
        if not pending_rids:
            break

        time.sleep(delay)

    for pending_rid in pending_rids:
        print(f"Row count for {pending_rid} is still not ready")

    pprint.pprint(row_counts)

    return row_counts

for curr_dataset_rid in DATASETS_RIDS :
    trigger_row_count(curr_dataset_rid, branch)

get_row_counts(DATASETS_RIDS, branch)

        global_list_fields[curr_key] = global_list_fields.get(curr_key, 0) + 1

print("Unsorted dict")
pprint.pprint(global_list_fields)

sorted_dict = {k: v for k, v in sorted(global_list_fields.items(), key=lambda item: item[1])}
