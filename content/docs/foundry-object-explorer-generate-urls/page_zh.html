生成对象资源管理器 URL

在开发对象视图的过程中，或在将对象视图集成到 Slate 应用程序或外部系统时，您可能需要生成指向特定对象或搜索对象的 URL。

要了解如何创建指向特定对象视图的 URL，请参阅 生成对象视图 URL （位于对象视图文档中）。

生成纯关键字搜索

如果您的文本包含特殊字符或空格，则需要对其进行编码：

encodeURIComponent("hello world");

创建 URL：

<BASEURL>/hubble/external/keyword/v0/<MY_ENCODED_TEXT>

链接到探索

Object Explorer 可以打开指向特定对象类型、已保存的探索或包含 URL 中所述筛选条件的新搜索的链接。每种类型的链接都可以在默认的 Explore 视图中打开（以图表形式显示汇总结果），也可以在表格形式的 Results 视图中打开，方法是将参数 perspectiveId=results 追加到链接 URL 的末尾。

打开对象类型以进行探索

特定对象类型的探索可以通过 objectTypeId URL 参数打开。例如：

/workspace/hubble/exploration?objectTypeId=aircraft.

若要在 Results 视图中打开，请追加 perspectiveId=results 参数：

/workspace/hubble/exploration?objectTypeId=aircraft&perspectiveId=results

加载已保存的探索或对象集

使用直方图中的 saved 路由来打开已保存的探索或对象集。

/workspace/hubble/exploration/saved/ri.object-set.main.versioned-object-set.4b117663-06d7-4bd1-a2be-8e1ba20998cb

要加载由其他 Foundry 应用创建的对象集，请使用 external/objectSet 路由。

/workspace/hubble/external/objectSet/v0/ri.object-set.main.object-set.f6916120-5b52-4312-8be4-9f5764983907

上面的示例可能已过时。请使用以下说明查找最新格式。

还有更多类型的筛选器可用，包括：

  • numberRangeFilter: min （可选数字）， max （可选数字）
  • relativeDateFilter: sinceDaysAgo （可选数字）， untilDaysAgo （可选数字）
  • timestampRangeFilter: startMillis （可选数字）， endMillis （可选数字）
  • relativeTimestampFilter: sinceMillisAgo （可选数字）， untilMillisAgo （可选数字）

值的类型必须与该属性在 Object Explorer 中默认显示的控件类型相匹配。例如： valuesFilter 用于直方图控件； textFilter 用于文本框。

生成这些筛选器的推荐方法是：

  1. 打开 Object Explorer 并构建一个示例搜索，为所有希望生成的筛选器选择示例值

  2. 打开 Chrome 控制台（右键单击 -> 检查元素）。请确保检查的是 Object Explorer 提供的元素（例如结果数量），而不仅仅是打开 Chrome 控制台。

  3. 运行 await hubble_get_current_search() 在控制台中。

这将返回当前筛选器集合的 JSON，您可以用它来确定正确的格式，并为这些值添加替换项。

您可以拥有多个 PROPERTY 筛选器，但只能有 1 个 LINK 筛选器。

  1. 对其进行 URL 编码：

encodeURIComponent(<MY_FILTERS>);

  1. 创建 URL：

<BASEURL>/hubble/external/search/v2/{<ENCODED-URL-FROM-ABOVE>}
