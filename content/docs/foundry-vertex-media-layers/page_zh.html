媒体图层和图像注释

Vertex 中的媒体图层允许您在地图或图像上对对象进行可视化和标注，从而支持对数据进行空间分析和上下文理解。您可以将对象添加为叠加层，根据属性对其进行筛选，并创建交互式标注。

本文档部分使用 来自 Wikimedia Commons 的公共领域图像 ↗ 作为示例，通过在 Vertex 中叠加对象的示意图，以概念方式构建一艘二战时期的海军舰船。

在本示例结束时，我们将在 Vertex 中获得一个交互式舰船图，其中带有显示叠加在图像上的若干舱室的标注。

配置

Pipeline Builder 配置

要开始在 Vertex 中使用媒体，请确保您至少拥有一个具有以下配置的对象类型： 媒体引用在我们的示例中，我们使用一个由图像媒体集创建的对象类型。我们还有两个将用于在 Vertex 图中创建标注的对象类型。

在下面的 Pipeline Builder 图中， Wikipedia commons... 媒体集输出 [Ships] Ship diagram 对象类型。 Text - Ship annotations 数据集输出 [Ship] Text Annotations 对象类型。最后， Ship annotations 数据集输出 [Ships] Annotation 对象类型。

选中后，您可以在预览面板中查看组成 Wikipedia commons... 媒体集的各个 PNG 图像。

选择 [Ships] Ship diagram 对象类型会显示图像媒体引用和 RID 的预览。

通过双击同一节点，我们可以查看 [Ships] Ship diagram 对象类型的属性，这些属性派生自源数据集的列。

我们可以选择 [Ships] Annotation 对象类型以查看源数据集的预览，其中包括 annotation, coordinates日 hexcolor 列的区域。

双击同一节点将显示 [Ships] Annotation 对象类型的属性，这些属性派生自源数据集的列。

我们将 Annotation 和 Text annotation 对象类型与其相关的 Ship diagram 对象类型通过 File Name 外键属性.

进行了关联。现在我们已经了解了基于媒体的对象类型与标注对象类型之间的关系，我们可以继续在 Ontology Manager 中进行配置，为对象类型在 Vertex 图中使用时设置默认行为。

Ontology Manager 配置

在 Ontology Manager 中导航到您的基于媒体的对象类型。从 功能 选项卡中，选择要用作媒体图层中默认图像的图像引用。从 图像引用属性 这将打开一个对话框，您可以在其中为实体应用和编辑标签。

现在我们可以配置 Annotation 对象类型，以定义其在 Vertex 中使用时的行为。

在概览页面中，我们可以查看我们创建的两个 操作类型（action types） 用于 Annotation 对象类型： Create [Ships] Annotation 和 Edit annotation coordinates。我们可以在 Vertex 图中使用这些操作类型来创建或编辑图像标注。

选择操作类型以查看其概览页面。我们可以看到，例如， Create [Ships] Annotation 操作类型被设置为使用 Annotation name, Coordinates, Hexcolor日 File Name 属性运行。

您可以配置对象类型的哪个属性默认用作图像标注的像素空间边界框坐标。在同一个 功能 选项卡中，从 图像标注坐标属性 下拉菜单中可用的属性中进行选择。在我们的示例中，我们选择 Coordinates 属性。

将对象添加为媒体图层

在 Ontology Manager 中确认您的配置后，您可以将对象添加到 Vertex 图中。选择 + Add object 以打开对象搜索界面。

您可以按名称、类型或其他标识属性进行搜索。您还可以使用下拉菜单筛选仅包含媒体引用的对象类型。

在对话框的右下角，使用下拉菜单指定如何将对象添加到 Vertex。 对象 是默认选项，它将使用配置的 Ontology Manager 对象类型图标和颜色将对象添加到图中。选择 带媒体的对象 选项以添加并查看对象上的标注。

选择完所有要添加到 Vertex 的对象后，选择 全部添加 or + 添加所选对象 将它们添加到您的图表中，它们将作为媒体图层显示。

设置媒体图层样式并进行探索

除非 在 Ontology Manager 中进行了其他配置，否则媒体图层默认将使用第一个媒体引用来显示对象。不过，您也可以使用从左侧 图层 面板访问的图标样式选项来自定义媒体图层对象的视觉外观。如果要显示的对象具有多个媒体引用，您可以选择要使用哪一个。

右键单击图表以使用“周围搜索”功能来探索相关对象，并通过连接的数据扩展您的媒体图层可视化。

如果您没有 配置图像标注坐标属性 ，您也可以使用样式选项来选择将哪个属性用作图像标注的像素空间边界框坐标。

在媒体图层中选择对象以查看其属性并与之交互。所选内容将高亮显示所选对象并显示相关信息。

使用标注图层样式菜单设置标注的样式，包括填充颜色和轮廓颜色。

创建图像标注

标注允许您在媒体图层中标记特定区域或特征。要创建新标注，请右键单击媒体图层对象以打开上下文菜单，然后选择 创建标注.

直接在图像上绘制标注，拖动以定义形状。绘制完成后，您可以调整标注的大小并移动它。

如果您配置了操作类型来为与媒体对象类型关联的对象创建标注，您将在下拉菜单中看到运行这些操作的选项。在我们的示例中，我们可以看到 Create [Ships] Annotation 以及一份 Create [Ships] Text annotation.

选择要运行的操作类型，然后填写表单为您的新标注对象命名。请注意，标注的坐标将用作新对象的边界框坐标，具体取决于您为对象类型配置操作的方式。

现在，您可以在图表的媒体图层中查看带有相关标注的对象。

修改现有标注

要修改现有标注，请找到并选择要编辑的对象。在本示例中，我们使用的是一个 Linen locker 之前已标注的对象。

当您移动标注或调整其大小时，任何可以修改该对象类型的操作类型都会显示在标注下方。在我们的示例中，我们可以运行 Edit annotation coordinates 操作类型来更新标注的新位置。

使用编辑表单更新对象的像素空间边界框坐标，该坐标由我们刚刚绘制的形状填充。

完成更改后，请查看更新后的对象以确保您的修改已正确应用。编辑后的标注将在媒体图层中反映您的更改。
