使用 MCP Inspector 进行调试

MCP Inspector ↗ 是一个用于测试和调试 MCP 服务器的开源开发者工具。它提供了一个交互式界面，您可以在其中连接到任何 MCP 服务器、浏览可用工具、通过自定义输入执行这些工具并检查响应。这使得它非常适合在将您的本体论 MCP (OMCP) 服务器连接到 AI 智能体之前验证其配置是否正确。

先决条件

在将 MCP Inspector 与您的本体论 MCP 服务器配合使用之前，请确保您已在 Developer Console 中为您的应用程序启用了本体论 MCP。请参阅 入门 以了解设置说明。

运行 MCP Inspector

要使用您的本体论 MCP 服务器启动 MCP Inspector，请前往 MCP 页面（位于 Developer Console 中您的应用程序下），并按照其中提供的运行 MCP Inspector 的说明进行操作。该页面会显示特定于您应用程序的连接配置。

MCP Inspector 应用程序启动后，请务必展开 Authentication 部分并添加客户端 ID，然后再选择 Connect。请注意，如果您使用的是机密客户端，则可能还需要添加客户端密钥。

在连接过程中，工具可能需要几秒钟才能可用。

使用 MCP Inspector 调试工具

MCP Inspector 连接到您的本体论 MCP 服务器后，您就可以使用它来列出、执行和检查应用程序所公开的工具。

列出可用工具

选择 工具 选项卡，即可在 MCP Inspector 中查看由本体论 MCP 服务器公开的所有工具。每个工具都会显示其名称和描述。此列表应与您在应用程序限制中配置的本体论资源相匹配，包括搜索工具、操作工具和查询工具。

如果列表中缺少某个工具，请确认相应的本体论资源已包含在您的 应用程序限制。

查看工具历史记录

使用 历史记录 部分（位于 工具 标签页），即可查看向您的 MCP 服务器发出的所有请求的日志，包括工具执行及其响应。这可以帮助您跟踪交互顺序，并识别工具中的任何错误或异常行为。

运行工具

按照以下步骤执行工具：

  1. 从列表中选择一个工具，以查看其输入架构。
  2. 在输入表单中填写必填参数。MCP Inspector 会显示每个工具的预期参数类型和描述。
  3. 选择 运行工具 以在您的本体论 MCP 服务器上执行该工具。

查看工具执行结果

运行工具后，MCP Inspector 会将响应显示在 结果 面板中。

您可以查看以下内容：

  • 成功响应： 返回的数据，例如搜索工具返回的对象属性或操作执行的结果。
  • 错误响应： 指示请求问题的错误消息和错误代码，例如缺少必需参数或权限错误。

使用响应详情来验证您的工具是否返回预期的数据，并诊断工具配置或权限方面的问题。

局限性

目前，本体论 MCP 不支持提示或资源，因此 MCP inspector 中的 Prompts 和 Resources 标签页将显示为空列表。
