多节点模板

Code Workbook 支持用于模板化工作流的多节点模板。一个模板可以由多个其他模板创建而成，并且您可以将这些模板中参数的值绑定在一起。

下面的示例使用 titanic_dataset 来模板化一个工作流，该工作流选择两个数值列并将它们绘制在两个图表中。第一个图表是这两个数值列的散点图。第二个图表是基于数值列筛选的乘客是否幸存的直方图。

以下是我们正在模板化的工作流的可视化概览：

创建模板

首先，创建一个从输入数据集中选择两个数值列的模板，以及 Survived。将此模板命名为 Filter.

其次，创建一个绘制两个数值列散点图的模板，将输入数据集读取为 Pandas 数据框。将此模板命名为 Scatterplot.

最后，创建一个基于两个数值列和两个模板化输入筛选输入数据集的模板，将输入数据集读取为 Spark 数据框。

创建多节点模板

选中所有三个模板并右键打开菜单，然后选择 创建新模板。您现在应该能看到模板编辑器。

我们想要关联 col1 参数的值，并关联 col2 参数的值。首先，点击进入 Filter 模板。点击进入 col1，然后选择 创建共享参数 在下拉菜单中。

在右侧，一个名为 col1 的新参数已创建。在右侧窗格中选择 titanic_dataset 作为源数据集。然后，点击进入另外两个模板，并选择将 col1 关联到新的 col1 多节点模板参数。对 col2重复此操作，然后保存多节点模板。

使用多节点模板

我们之前创建的三个模板现在是一个多节点模板的一部分。

点击进入 Filter 模板。在 col1 和 col2 参数旁边，有一个图标指示此参数值由多节点模板参数控制。

选择 View Group 在窗格顶部。您现在会看到一个视图，其中突出显示了多节点模板中的节点，并列出了模板中的共享参数。您可以在此视图中更改 col1 和 col2 的值，并且三个节点中的所有实例也将随之更改。

如果您在子节点窗格中更改共享参数的值，该值在多节点模板中的所有实例中也会被更改。
