为 Microsoft Graph API 设置 Webhook

本指南分步介绍如何为 Microsoft Graph API 配置 webhook，以便从 Foundry 访问 Microsoft Cloud 服务资源。

详细了解 Microsoft Graph API ↗。

先决条件

在配置之前，您必须：

  • 通过在浏览器中输入 login.microsoftonline.com 登录您的 Microsoft 账户，以完成身份验证并生成可用于创建 webhook 的访问令牌。
  • 配置 网络出口策略 ，同时适用于 login.microsoftonline.com 和 graph.microsoft.com ，以允许来自 Foundry 的出站连接。

操作说明

  1. 创建 REST API 源 ，供您的 webhook 使用。
  2. 将 login.microsoftonline.com 和 graph.microsoft.com 作为该源的 域名 包含在内，且不设置任何 身份验证 限制。
  3. 设置所有必要的 附加密钥，例如 TenantId、 ClientId 和 ClientSecret ，您将使用它们对 login.microsoftonline.com进行身份验证。完成 在 Microsoft Entra 中注册应用程序 ↗后，即可找到这些值。
  4. 将您 先前创建 的网络出口策略添加到 网络连接 部分，然后选择 保存并继续。

配置 REST API 源后，接下来您将配置 webhook 以发出两个 POST 请求：

  1. 使用在源上创建的 login.microsoftonline.com 凭据登录，以获取短期有效的访问令牌。
  2. 调用 graph.microsoft.com 将首次调用响应中的访问令牌用作该调用身份验证标头中的持有者令牌。
