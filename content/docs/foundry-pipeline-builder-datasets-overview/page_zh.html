数据集

要创建管道，请选择一个数据输入作为起点。将数据输入添加到管道后，可以对数据进行清洗、转换，并与其他数据组合，以便在平台中部署以供进一步使用（例如，作为本体论的一部分）。

Pipeline Builder 支持以下形式的数据输入： 结构化, 半结构化日 非结构化 数据。

结构化数据 通常以以下形式出现： 数据集 ，由包含表格数据以及数据集中各列元数据的文件组成。列元数据与相应的数据集一起存储为 模式。Pipeline Builder 还支持以手动输入数据、上传数据、数据同步以及以下形式输入结构化数据： 虚拟表.

半结构化数据 指的是 数据集 ，由没有 schema 的文件组成，因此数据是非表格形式的。因此，半结构化数据集有时被称为“无 schema”数据集。Pipeline Builder 支持以下形式的半结构化数据：CSV、JSON、GeoJSON、XML、Microsoft Excel、KML、shapefile、纯文本和电子邮件文件。您可以使用解析转换函数将半结构化文件转换为表格形式，并受益于 schema 安全性。例如， 从 Excel 文件中提取行 转换会读取 .xls, .xlt, .xltm, .xltx, .xlsx日 .xlsm 文件。对于 XML 数据，Pipeline Builder 可以从 XSD 文件自动生成 schema——将您的 XSD 文件上传到原始数据集，并在 Parse XML 转换中引用它们，即可自动创建相应的 schema 结构。了解如何 在管道中转换数据.

非结构化数据 指的是其他非表格形式的数据，包括视觉媒体、PDF 文档、音频等。Pipeline Builder 支持以下形式的非结构化数据输入： 媒体集.

在 Pipeline Builder 中定义工作流的第一步是向您的工作区添加一个或多个数据输入。了解如何 添加数据 or 更改输入计算模式 请参阅以下文档，并访问以下内容以了解 Foundry 中有关数据的更多信息： 数据集成.
