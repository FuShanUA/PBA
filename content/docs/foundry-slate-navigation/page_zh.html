导航

Slate 的编辑模式包含四个主要区域：

  1. 操作栏： 您可以在此处找到应用名称、 操作 下拉菜单、退出至查看模式的按钮，以及用于打开各种编辑面板的按钮。
  2. 组件列表： 组件列表会列出应用中的所有组件。如果应用中包含工具栏，该列表会分为工具栏组件和画布组件。
  3. 画布： 应用的主要工作区。可以在这里重新排列组件并测试布局选项。通过右上角的下拉菜单更改屏幕尺寸，可以预览应用在不同屏幕上的显示效果。
  4. 组件编辑器： 从组件列表或画布中选中某个组件后，可以通过 组件编辑器 对其进行配置。

此外，还有一些在画布前方弹出的面板：

  • 查询编辑器
  • 函数编辑器
  • 平台编辑器
    • 对象集
    • 对象上下文
    • Foundry 函数
  • 事件编辑器
  • 依赖关系图
  • 样式编辑器
  • 变量编辑器

直方图 全局搜索 在编辑器模式下，使用键盘快捷键 Cmd+K （macOS）或 Ctrl+K （Windows），可用于搜索并跳转到 Slate 查询、函数、对象、变量和小组件。Slate 的全局搜索还会保留您的搜索历史，以便优先显示最近的结果。选择某个结果将打开相应的 Slate 编辑器面板。

撤销支持

Slate 支持撤销删除所有资源类型，包括小组件、文件夹、数据集同步、函数、对象集、对象上下文、变量、查询、局部模板、事件-操作以及容器标签页。要撤销删除，请在删除后出现的提示框中选择撤销按钮，或使用键盘快捷键 Cmd+Z （macOS）或 Ctrl+Z (Windows)。

撤销小组件删除会恢复其事件和操作连线，包括保留的小组件的事件连接到已删除小组件的操作的情况。一次只显示一个撤销提示：新的删除会替换之前的提示，任何文档编辑都会关闭待处理的提示。

组件编辑器

组件编辑器包含三个选项卡，用于对选中的组件进行编辑配置。

属性选项卡： 主要的编辑选项卡，用于更改组件的属性。可用的选项因组件类型而异。

布局选项卡： 用于设置组件的位置和尺寸，并应用自定义样式。

JSON 选项卡： 如果 属性 标签页未提供您所需的设置，可在此标签页中编辑小组件的原始 JSON 配置。每个小组件都以包含最常用属性的模板代码开头，并且在 属性 标签页中更改的字段也会显示在 JSON 标签页中。编辑器会显示 JSON 错误，并启用 更新 仅在您进行有效更改后。对于值较长的交互属性，请选择 以显示接下来的五行。 以展开或折叠完整内容。

未通过 属性 选项卡暴露的状态由 Slate 在内部管理，因此在 JSON 选项卡中修改 Slate 的默认值时需仔细检查，以避免出现意外行为。

事件选项卡： 部分组件具有关联事件，可以在此处进行配置。
