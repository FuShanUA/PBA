故障排除

本页面提供了在使用 Solution Designer 时可能遇到的常见问题的解决方案。

自动保存问题

自动保存反复失败

如果自动保存反复失败或显示错误状态：

  • 检查权限： 确认您拥有图表资源的编辑权限。在页眉中选择资源名称以查看权限。
  • 手动保存： 尝试通过选择页眉中的 保存 来手动保存图表。如果手动保存也失败，请记下错误信息并联系您的 Foundry 管理员。
  • 检查连接： 请确保您的网络连接稳定，因为自动保存功能需要连接到 Foundry 后端。
  • 重新加载图表： 关闭并重新打开图表。重新加载后，自动保存功能可能会恢复。
  • 导出为备份： 如果无法保存，请将图表导出为 JSON 文件以防止数据丢失，然后联系您的 Foundry 管理员。

保存时冲突

如果在保存图表时看到冲突解决对话框：

  • 检查是否存在多个编辑者： 其他用户可能正在同时编辑该图表。为避免冲突，请在编辑共享图表之前与团队成员协调。
  • 查看您的更改： 将您的更改与服务器上的版本进行比较。
  • 选择一个选项：
    • 保留您的更改： 使用您的更改覆盖服务器版本。
    • 保留服务器更改： 放弃您的更改并加载服务器版本。
    • 取消： 退出保存操作并手动合并更改。

AIP 功能

AIP Architect 或 AIP Critic 不可用

如果 AIP 功能未出现在 Solution Designer 中：

  • 检查 AIP 状态： AIP 功能必须 为您的注册启用。请联系您的 Foundry 管理员以请求访问权限。
  • 验证模型可用性： 至少一个受支持的 LLM 必须由您的 Foundry 管理员配置于 Model Catalog.
  • 验证浏览器兼容性： 请确保您使用的是受支持的浏览器。目前支持 Chrome、Edge、Firefox 和 Safari。

模型选择中未显示可用模型

如果 AI 模型 选择下拉列表为空：

  • LLM 服务可能不可用： 语言模型服务可能未配置或暂时不可用。请联系您的 Foundry 管理员，以确认至少有一个受支持的 LLM 已配置且可用。
  • 检查权限： 您可能没有访问语言模型的权限。请联系您的 Foundry 管理员。

图像到图表的转换功能已禁用

如果您无法上传图像以转换为图表：

  • 确保您可以访问具备视觉能力的模型： 图像转换需要具备视觉能力的模型（如 GPT-4o）。请查看 模型 下拉菜单位于 上传图像 模态框中，以验证具备视觉能力的模型可用且已被选中。

AIP Architect 的建议似乎不准确

如果 AIP Architect 的建议与您的需求不符：

  • 优化您的工作流摘要： 编辑您的工作流摘要，以便更具体地说明您的需求、约束条件或期望的方法。
  • 尝试不同的实现方式： 请先预览多个建议的实现模式，再选择其中一个。
  • 选择其他模型： 某些模型可能对特定类型的工作流产生更好的效果。
  • 进行手动调整： AIP Architect 提供了一个起点；您应始终根据自身的具体需求审查并完善生成的建议。

导出问题

无法导出图表

如果导出选项被禁用：

  • 确保您的图表已保存： 导出前必须先保存图表。请先选择 保存 。
  • 检查您的编辑权限： 导出功能需要对图表资源拥有编辑权限。只读查看者无法导出图表。
  • 刷新以解决浏览器问题： 请尝试刷新页面或使用其他浏览器。

导出的图像质量较差

如果您导出的 PNG 文件质量较差：

  • 更改分辨率： 图像会自动以 2 倍缩放比例导出，以获得更高的清晰度。如果需要更高的分辨率，请尝试放大图表的特定部分并使用 导出选定节点 功能。
  • 将复杂图表拆分为多个部分： 超大型图表可能会超出浏览器的渲染限制。请考虑将图表拆分为较小的部分。

AIP Critic PDF 导出失败

如果 AIP Critic PDF 导出失败：

  • 检查对话长度： 过长的对话历史记录可能因数据量过大而无法导出。如需讨论其他主题，请尝试开启新的评审对话。
  • 减轻浏览器的内存负担： Solution Designer 会在您的浏览器中生成 PDF。如果浏览器内存不足，请关闭其他标签页后重试。

画布和图表问题

节点或边消失

如果节点或边不可见：

  • 调整您的画布位置： 使用画布工具栏中的 使所有节点适应视图 按钮，以重新居中视图。
  • 更改您的缩放级别： 您可能缩放得太近或太远。请调整缩放级别，或使用 使所有节点适应视图。
  • 在小地图上定位节点： 使用小地图（如果在 图表设置中启用）来定位并导航至您的节点。
  • 撤销误删的节点： 如果您误删了节点，请使用 Cmd/Ctrl + Z 来撤销该操作。

无法编辑图表

如果您无法编辑节点或创建连接：

  • 检查图表是否已锁定： 检查画布工具栏中是否启用了图表锁定。选择锁定图标以解锁图表，这将禁用平移模式并使图表恢复到可编辑状态。
  • 验证您的权限： 验证您是否拥有图表资源的编辑权限。
  • 检查您是否使用了只读链接： 如果您通过只读链接访问图表，则将无法进行编辑。

自动布局效果不佳

如果自动布局功能未能按预期排列节点：

  • 检查图表的结构： 自动布局最适用于树状或分层结构。包含大量交叉连接的复杂图可能需要手动布局。
  • 对节点进行分组： 在应用自动布局之前，先对相关节点进行分组，可获得更好的效果。
  • 进行手动调整： 将自动布局作为起点，然后手动调整节点位置以提高清晰度。

加载和导入

无法从文件系统加载图表

如果无法加载已保存的图表：

  • 检查您的权限： 请确认您对该资源至少拥有读取权限。

从 JSON 导入图表失败

如果导入 JSON 图表失败：

  • 请确保您的格式有效： JSON 必须采用正确的 Solution Designer 格式。请确保该 JSON 是从 Solution Designer 导出的。

获取更多帮助

如果您仍然遇到问题：

  1. 检查您的浏览器控制台： 打开您浏览器的开发者控制台 (F12 (Windows), Option + Cmd + i (macOS)) 并检查错误消息。向您的 Foundry 管理员报告问题时，请附上这些错误。
  2. 将图表导出为备份： 将您的图表导出为 JSON，以防止数据丢失。
  3. 联系支持团队： 请联系您的 Foundry 管理员或 Palantir 支持团队，并提供以下信息：
    • 问题描述。
    • 重现问题的步骤。
    • 浏览器控制台中的任何错误消息。
    • 您使用的浏览器及其版本。
    • 如相关，请提供图表 JSON 的副本（请确保其中不包含敏感数据）。
