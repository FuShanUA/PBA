Spark 配置文件

仓库设置用于指定 Spark 配置文件 以在仓库中使用。在仓库设置中配置 Spark 配置文件后，您可以 在代码中使用该配置文件.

在应用给定配置文件之前，必须先将其导入到项目中。配置文件有两种类型：

  • 非受限配置文件：所有用户都可以导入到仓库的配置文件。
  • 受限配置文件：只有管理员才能导入的配置文件。

仓库中已可使用的 Spark 配置文件位于 Spark 部分，在 设置 “代码” 已启用的配置文件.

导入 Spark 配置文件

为了在转换作业中使用 Spark 配置文件，必须先将该配置文件导入到包含该作业的项目中，否则在尝试发布转换时检查将会失败。

可以使用代码仓库编辑器中的 Spark 配置选项卡来浏览 Spark 配置文件并将其导入到项目中。

要将配置文件导入到项目中，请前往 设置 选项卡并选择 Spark。点击 添加配置文件 在下拉列表中找到所需的配置文件。将鼠标悬停在您需要的配置文件上：

  • 如果该配置文件是非受限的，您可以点击 导入 将该配置文件导入到项目中。
  • 如果该配置文件是受限的，您可能会在其旁边看到一个锁形图标。

默认情况下，任何 资源管理 管理员都拥有导入受限 Spark 配置文件所需的权限。此外，可能存在一个名为 spark-profile-admins 的用户组，同样拥有所需的权限。普通用户必须请管理员将配置文件导入到其项目中，然后才能使用。

已启用 Spark 配置文件

项目中已启用的所有配置文件都可以在 引用 面板中找到，该面板位于项目的摘要侧边栏中。导入到仓库后，配置文件会自动添加为整个项目的引用，并作为“已启用的配置文件”供项目中的所有仓库使用。
