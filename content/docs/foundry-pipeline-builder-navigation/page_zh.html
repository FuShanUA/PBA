导航

本页面介绍 Pipeline Builder 的界面、导航控件和可用工具。

登录页面

打开 Pipeline Builder 时，你会看到一个登录页面，其中显示你的管道以及每个管道的关键信息。在登录页面上，你可以：

  • 查看每个管道的当前流式数据集状态
  • 查看管道部署状态
  • 查看每个管道使用的后端类型
  • 按收藏筛选管道
  • 切换收藏以快速访问常用管道

从登录页面选择一个管道以将其打开，并访问 Edit、Proposals 和 History 视图。

Edit、Proposals 和 History 视图

用户可以通过顶部工具栏在 Pipeline Builder 中访问三种不同的视图：Edit、Proposals 和 History。

编辑

Edit 视图是你开始构建管道工作流的地方。它分为四个部分：顶部工具栏、详情侧边栏、图表和预览窗格。

顶部工具栏

顶部工具栏允许你管理视图、监控构建检查状态以及编辑构建设置。

  • 撤销/重做： 撤销或重做工作流中的最近操作。
  • 分支下拉菜单： 查看你当前工作的分支名称，或切换到另一个分支。你还可以选择 创建新分支. 了解更多关于分支的信息。
  • 保存： 保存你的进度。当你的更改保存到分支时，会出现已填充的 已保存 状态。

对管道分支的更改不会自动保存。若要正确保存对管道分支的更改，你必须在离开图表标签页之前手动保存更改。

  • Proposals 下拉菜单： 打开 Proposals 下拉菜单以管理当前分支的提案。

    • 查看提案： 如果当前分支有未处理的提案，选择此选项可查看并导航到这些提案。
    • 创建新提案： 保存更改后，选择此选项以请求合并到主分支。不支持从主分支合并。

  • 部署： 在管道通过验证检查后，选择 部署 来构建你的管道输出。

  • 构建设置： 更改构建的计算配置文件。

    • 默认： 默认的自动缩放配置文件，使用最少量的执行器核心和内存。
    • 提供缓慢扩容和快速缩容的计算资源。 缓慢扩容、快速缩容的计算配置。
    • 大： 缓慢扩容、快速缩容的计算配置。使用更大配置文件的构建可能完成得更快，但计算成本更高。

  • 构建和检查状态： 查看构建同步的状态以及检查通过和失败的情况。

  • 共享： 打开 详情侧边栏 以访问管道的共享选项。



详情侧边栏

详情侧边栏允许你查看管道的元数据、访问要求和角色。点击右上角的图标可展开和折叠侧边栏。

  • 描述： 编写或编辑管道的描述。

  • 浏览量： 过去 30 天内你的管道被浏览的总次数。

  • 关注者： 关注你的管道工作流进度的用户总数。点击此选项可关注你当前正在查看的管道。

  • 评论： 通过 评论 标签页查看和管理管道工作流上的评论。你可以添加新评论、编辑现有评论、跨不同更改进行评论以及解决评论。选择此选项可发布评论或在侧边栏中查看所有评论。

  • 协作者： 在管道上协作的用户。点击 要在标记和发布函数的过程中查看进度，请选择 以查看用户是何时被添加为工作流协作者的。

  • 访问权限： 显示管道所属的组织以及你在管道文件上拥有的角色。点击 要在标记和发布函数的过程中查看进度，请选择 以查看和管理访问设置。

    • 访问要求： 显示访问管道所需的组织和标记要求。

      • 组织： 用户必须所属才能访问管道的组织。
      • 标记： 用户必须有权访问才能访问管道的标记。
        • 数学运算 打开一个窗格，用于搜索并向管道工作流添加标记要求。

    • 角色： 显示您在管道上的角色。

      • 管理： 打开一个窗格，用于管理角色并共享管道工作流。
        • 关联共享： 切换以开启关联共享，并向通过可共享链接访问管道的用户授予角色。
        • 添加用户或组： 搜索用户或组，以授予其对管道工作流的访问角色。

    • 检查访问权限： 检查特定用户或组的访问要求。

      • 检查： 打开一个窗格，用于搜索并检查用户或组的访问权限。
        • 检查访问权限： 使用搜索字段查找用户或组。
          • 选择用户或组： 检查用户是否满足访问要求，并查看其在管道工作流上被分配的角色。



  • 其他信息： 显示管道的其他元数据。

    • 位置： 管道在 Foundry 文件结构中的位置。
    • 修改时间： 管道上次修改的日期和时间。

图表

图（graph）是用户添加数据、创建参数和描述转换的地方。它是 Pipeline Builder 应用程序的主视图。

  • 平移模式： 允许通过点击并拖动在图中导航。

  • 拖拽选择模式： 在图中点击并拖动以选择多个节点。要从平移模式快速切换到此模式，请在 shift 点击并拖动经过节点时按住该键。

  • 选择： 选择图中的所有节点。

  • 移除： 从管道中移除图中选定的节点。

  • 布局： 均匀分布并组织图中的节点。

  • 添加数据集： 打开一个窗口，用于搜索并向图中添加数据集。

  • 参数： 配置并添加可重用的转换参数。

    • 添加参数： 为新参数命名并分配其值。

  • 转换： 在图中选择数据集节点以进行转换、连接或合并。在图上选择数据集还会打开一个弹出菜单，允许您添加或编辑转换。

  • 编辑： 在图中选择一个转换节点以编辑转换设置。



  • 图例： 显示应用于数据集和转换的颜色指示。

    • 添加颜色： 从颜色选择器中选择一种新颜色，分配给图中的节点。



  • 输出侧边栏： 在侧边栏中，查看管道数据集的构建要求、编辑架构并添加输出。使用 Builder 图最右侧的“展开”符号来展开输出侧边栏。



    • 数据集： 显示管道中描述的数据集输出、健康验证以及任何架构错误。
      • 编辑架构： 识别架构错误、移除或添加列，并使用输入架构来解决错误。
      • 删除数据集输出： 从管道中移除选定的数据集输出。
      • 添加输出： 为管道构建创建新的数据集输出。
    • 对象类型： 显示指导管道集成的对象类型输出。
      • 添加输出： 打开一个窗口，用于创建新的对象类型输出、从数据集架构生成对象类型，或添加现有对象类型。
    • 关联类型： 显示指导管道集成的关联类型输出。
      • 添加输出： 打开一个窗格，用于从两个对象类型创建对象关联。

  • 缩放设置： 选择放大、缩小或缩放以适应您的图。

  • 复制节点： 您可以在不同的 Pipeline Builder 部署之间以及同一资源内部复制和粘贴节点，使用 Cmd + C 和 Cmd + V （MacOS）或 Ctrl + C 和 Ctrl + V （Windows）。这可用于复制管道的某些部分或整个管道。

预览面板

预览面板允许您查看单个所选节点的样本数据。当您选择一个节点时，预览面板会打开，并自动运行从原始数据集到所选节点的逻辑。选择图表左下角的图标可展开或收起预览面板。

您可以在您的 用户偏好设置 中配置预览行为，以在运行预览之前要求确认。

  • 名称： 显示所选节点的名称。您可以在此字段中编辑节点名称。
  • 搜索： 在数据中搜索列名称。

您还可以通过右键单击数据集节点并单击 打开.

提案

在提案视图中，您可以查看此管道的所有未处理、已合并或已关闭的提案。从下拉菜单中选择一个筛选器，可查看该状态类别下的所有提案。

每个提案都会显示创建日期和时间、创建它的用户，以及表示未处理、已合并或已关闭状态的图标。

在提案中，您可以通过 评论 侧边栏中的选项卡查看和管理评论。您可以直接在节点差异视图中添加或修改评论、编辑现有评论、跨不同更改进行评论，以及解决评论，从而在审查过程中促进协作。

历史记录

历史视图允许您查看管道工作流任何分支中的近期活动。从下拉菜单中选择一个分支以查看其历史记录。

点击设置菜单下的 操作 以创建新分支、查看详细信息，或查看每个已保存版本所做的更改。

在分支菜单中输入新分支的名称，随后点击

此选项允许您基于所选分支创建一个新分支。

查看详细信息

直方图 查看详细信息 选项会打开图表的只读版本，显示保存该活动时管道的状态。此选项是跟踪工作流随时间发展的有用方式，且不会面临回退到管道早期状态的风险。

查看更改

与 查看详细信息 选项类似，您可以 查看更改 以了解特定时间点的管道修改。但在此视图中，图表以拆分视图显示差异，即 差异，即上一次保存与应用更改之间的差异。

查看提案

查看提案允许构建者审查和编辑现有提案。在提案的“更改”选项卡中，您可以将节点或设置更改标记为已审查，并跟踪您的进度。“更改”侧边栏会以视觉方式区分已审查和未审查的项目，节点上的对勾徽章表示哪些更改已被审查，标题中的进度条显示整体审查进度。您可以在“更改”选项卡中或直接在图表上将项目标记为已审查。
