产品发布标签

您可以将标签应用于产品发布，以便为其标记相关信息并定义晋级要求。例如，您可以创建一个标签，将其添加到已经过扫描和审批的发布中，并要求所有发布在晋级到特定发布渠道之前都必须带有此标签。

将标签应用于产品发布

要为产品发布应用标签，请导航到产品发布概览页面并选择 编辑标签... 选项（位于 操作 下拉菜单中）。

这将打开一个菜单，您可以在其中管理产品发布的标签。您可以在 已应用 部分中查看已应用的标签。您可以从 更多 部分中选择要应用于产品发布的标签。

选择标签后，您可以选择标签右侧的铅笔图标并输入值。

完成后，请选择 应用 以保存您的更改。

发布晋级的标签要求

您可以使用标签来定义发布在被添加到发布渠道之前必须满足的条件。这些条件称为 标签要求。当发布渠道定义了标签要求时，所有发布都必须满足这些要求才能进入该发布渠道。标签要求分为两种类型：

  • 无论标签值如何，产品发布上都必须存在的标签 ID。例如，您可以设置一项要求，规定所有产品发布都必须具有标签 ID apollo-product-definition-available 才能进入发布渠道。
  • 可以强制要求标签 ID 和值的配对。例如，您可以要求产品发布具有 ID 为 scanned-and-approved 以及值 true 才能被允许加入发布渠道。
