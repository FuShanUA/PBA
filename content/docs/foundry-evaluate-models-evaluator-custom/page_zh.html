自定义评估库

评估库是 Foundry 中已发布的 Python 包，用于生成模型评估器。评估库可用于衡量模型性能、模型公平性、模型稳健性以及其他指标，并可在不同的 建模目标.

除了 Foundry 为 二分类 和 回归 模型提供的默认模型评估器之外，Foundry 还允许您创建 自定义 模型评估器，该评估器可在建模目标中原生使用。

建模目标内部的自定义评估器

自定义评估器、其配置选项以及生成的指标将显示在“建模目标”应用程序中，其名称和描述在评估器实现顶部的文档字符串中指定。

自定义评估器发布后，任何对已发布库具有查看权限的用户都可以在“建模目标”应用程序中使用它。这使您能够编写可重用的逻辑，在整个组织内计算标准化指标。

自定义评估器可在建模目标的评估库配置中进行选择；该库可根据评估器定义的参数进行配置。

创建自定义评估器

要创建自定义评估器：

  1. 创建 一个代码仓库，来自 Model Evaluator Template Library.
  2. 实现 您的自定义评估器。
  3. 添加参数 到您的自定义评估器。
  4. 提交并 发布新标签 包含您的更改。

评估器模板结构

直方图 模型评估器模板库 在文件中有一个示例实现 src/evaluator/custom_evaluator.py。任何 评估器 Python 接口的实现都会自动注册，并在您 发布其仓库的新版本 并附带新的仓库版本标签后可用。

包含自定义评估器逻辑的仓库可以发布多个评估器。任何额外的评估器实现文件都需要作为引用添加到评估器模板中的模型评估器模块列表中 build.gradle 评估器模板的。

  • display-name：评估器的显示名称
  • description：评估器的描述

您可以选择添加零个或多个以下内容：

  • param：自定义评估器的配置参数
  • metric：评估器生成的指标

from pyspark.sql import DataFrame
from pyspark.sql import functions as F
from foundry_ml_metrics.evaluation import ComputedMetricValue, Evaluator

class CustomEvaluator(Evaluator):
    """
        :display-name: Row Count Evaluator
        :description: This evaluator calculates the row count of the input DataFrame.

        :metric Row Count: The row count
    """

    def apply_spark(self, df: DataFrame) -> List[ComputedMetricValue]:
        row_count = df.count()

        return [
            ComputedMetricValue(
                metric_name='Row Count',
                metric_value=row_count
            )
        ]

参数化评估器

通过提供配置参数，可以使评估器在“建模目标”应用程序中可配置。 配置参数将在运行时由“建模目标”应用程序填充为用户输入的值。 当用户在建模目标中配置自动评估时，将有机会配置这些参数的值。

允许的配置字段包括：

  • int：整数
  • float：浮点数
  • bool：布尔值（True 或 False）
  • str：字符串值
  • Field[float]：输入 DataFrame 中的浮点列
  • Field[int]：输入 DataFrame 中的整数列
  • Field[str]：输入 DataFrame 中的字符串列

可以通过将参数包装在 Optional （来自内置 typing 包）中使其变为可选。

例如：

  • 一个可选的 str 将是 Optional[str]
  • 一个可选的 Field[str] 将是 Optional[Field[str]]

带有配置字段的示例评估器

    • 一个整数值，名称为 value 以及描述 Filtered value.

from pyspark.sql import DataFrame
from pyspark.sql import functions as F
from foundry_ml_metrics.evaluation import ComputedMetricValue, Evaluator, Field

class CustomEvaluator(Evaluator):
    """
        :display-name: Configurable Row Count Evaluator
        :description: This evaluator calculates the row count of the input DataFrame, filtered to the specified value.

        :param column: Filtered column
        :param value: Filtered value

        :metric Row Count: The unfiltered row count
        :metric Filtered Row Count: The filtered row count
    """

    column: Field[int]
    value: int

    def __init__(self, column: Field[int], value: int):
        self.column = column
        self.value = value

    def apply_spark(self, df: DataFrame) -> List[ComputedMetricValue]:
        column_name = self.column.name
        column_value = self.value

        row_count = df.count()

        filtered_row_count = df.filter(
            F.col(column_name) == column_value
        ).count()

        return [
            ComputedMetricValue(
                metric_name='Row Count',
                metric_value=row_count
            ),
            ComputedMetricValue(
                metric_name='Filtered Row Count',
                metric_value=filtered_row_count
            )
        ]

    Metric computed by one of the evaluators comprising metric name, value, and subset information.

    metric_name: str
    metric_value: MetricValue

    def __init__(self, metric_name, metric_value):
        self.metric_name = metric_name
        self.metric_value = metric_value

MetricValue

A MetricValue 可以是以下任意一种：

  • 数值，类型为以下之一：
    • int
    • np.int8
    • np.int16
    • np.int32
    • np.int64
    • np.uint8
    • np.uint16
    • np.uint32
    • np.uint64
    • float
    • np.float32
    • np.float64
  • 图表，类型为以下之一：
    • matplotlib.Figure
    • matplotlib.pyplot.Figure
  • 实现了以下方法之一的任意类：
    • get_figure(self) -> Figure：许多 seaborn 图表都实现了此函数。
    • save(self, path: str)：许多 seaborn 图表都实现了此函数。
    • savefig(self, path: str)
  • 一个 BarChart
  • 一个 LineChart
