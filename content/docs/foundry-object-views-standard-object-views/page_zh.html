标准对象视图

当您在您的本体论中创建并配置 对象类型 时，Foundry 会自动创建一个标准对象视图，为该对象类型下的所有对象提供标准化表示，确保其他用户能够全面了解其架构和关联。标准对象视图通过在专用表格中突出显示重要属性来匹配对象类型的配置；如果属性的 基类型 是时间序列、媒体引用或地理空间属性，则以其他可视化格式呈现。普通属性显示在常规表格中，隐藏属性则不可见。

虽然标准对象视图适用于所有对象类型，但您可以创建 配置视图 为任何对象类型提供基于其在您的本体论中功能的情境化且经过精心策划的对象视图体验。当您创建配置的对象视图时，Foundry 会将其作为用户的默认视图提供；不过，用户也可以选择标准视图，以标准格式查看对象数据。

突出属性显示

Foundry 会显示 突出属性 在标准对象视图的顶部，以便即时提供有关对象最重要信息的背景。

显示行为

标记为突出的属性会根据其类型获得增强的视觉呈现效果：

  • 媒体引用属性: 通过专用媒体查看器渲染，用于查看所有支持的媒体类型。
  • 时间序列属性: 显示为交互式图表，展示时间数据模式。
  • 地理空间属性: 具有显著 geohash、geoshape 或地理时间序列引用 (GTSR) 属性的对象将渲染在 地图。在时间序列属性中， 表示对象随时间变化的纬度和经度的属性 也会显示在地图上。
  • 其他属性类型： 所有其他重要属性都会以更大的卡片式格式显示，并置于展示其余标准属性的表格上方。

关联对象组件

该 关联对象 组件使您能够遍历 关联对象 ，直接在标准对象视图中。

使用 关联对象 组件（标准对象视图的一部分）来：

  • 查看按关联类型分组的关联对象。
  • 无需离开当前视图，即可内联预览关联对象的属性。
  • 在新标签页中打开关联对象的子集，以便进一步探索。
  • 在标准对象视图的侧边面板中预览选定的关联对象。

面板中标准对象视图的显示行为

您还可以在标准对象视图的 面板 形态中与其全部功能进行交互。
