Iceberg 表属性

Iceberg 表在其元数据中包含一个表属性的键值映射。初始的表属性映射在创建表时设置，随后可以使用 ALTER TABLE ... SET TBLPROPERTIES。Iceberg 规范保留了一组关键属性，Foundry 也提供了一组键，用于跟踪 Foundry 特定的元数据，例如表 RID。

Foundry 特定属性

Foundry 特定属性包括：

属性描述用户编辑
created-at表创建时间戳（跨目录约定）✅ 允许
foundry.branch.*跟踪 分支范围的 schema、分区规范和排序顺序❌ 不允许
foundry.rid表的 RID❌ 不允许
foundry.table-version内部目录标记❌ 不允许

Iceberg 规范属性

Iceberg 规范还保留了一组核心 Iceberg 表属性 ↗。

Foundry 的 Iceberg REST 目录对某些核心 Iceberg 表属性施加了以下约束：

属性Foundry 默认值用户编辑
encryption.*作为 Iceberg 表加密 的一部分进行设置（若启用）❌ 不允许
format-version请参阅 格式版本默认值✅ 允许
history.expire.max-snapshot-age-ms2592000000 （30 天）✅ 允许
write.metadata.delete-after-commit.enabledfalse❌ 不允许
write.metadata.previous-versions-max1❌ 不允许
write.object-storage.enabledtrue❌ 不允许
write.object-storage.partitioned-pathsfalse❌ 不允许
write.data.path❌ 不允许
write.folder-storage.path❌ 不允许
write.location-provider.impl❌ 不允许
write.metadata.path❌ 不允许
write.object-storage.path❌ 不允许

在 Foundry 提供默认值的情况下，该默认值优先于开源 Iceberg 规范的默认值。任何未显式设置的属性均使用 Iceberg 规范的默认值。

Foundry 应用的默认设置可能会发生变化。若要保证特定的属性值，请务必按照下文所述，在您的表上显式设置这些值。

在转换中设置特定的表属性

您可以手动设置特定的表属性，例如，通过在 Iceberg 维护页面中运行 ALTER TABLE 语句，或在您的转换代码中指定属性。

import polars as pl
from transforms.api import transform
from transforms.tables import IcebergOutput, TableOutput


@transform.using(output=TableOutput("/path/table"))
def compute(output: IcebergOutput) -> None:
    df_custom = pl.DataFrame({"phrase": ["Hello", "World"]})
    output.write_table(df_custom)

    tbl = output.iceberg().table()
    with tbl.transaction() as txn:
        txn.set_properties({
            "write.delete.mode": "merge-on-read",
            "write.update.mode": "merge-on-read",
            "write.merge.mode": "merge-on-read",
            "history.expire.max-snapshot-age-ms": "0",
        })

from transforms.api import TransformContext
from transforms.api import transform
from transforms.tables import (
    TableOutput,
    TableTransformOutput,
)


@transform(
    output=TableOutput("/path/table")
)
def compute(ctx: TransformContext, output: TableTransformOutput):

    spark = ctx.spark_session

    df_custom = spark.createDataFrame([["Hello"], ["World"]], schema=["phrase"])
    output.write_dataframe(df_custom)

    identifier = output.identifier
    spark.sql(f"""
    ALTER TABLE {identifier}
    SET TBLPROPERTIES (
        "write.delete.mode": "merge-on-read",
        "write.update.mode": "merge-on-read",
        "write.merge.mode": "merge-on-read",
        'history.expire.max-snapshot-age-ms' = '0'
    )
    """)

请仅在写入输出表之后再设置表属性。这可确保在设置属性之前表已存在，并可防止 Spark 的 write_dataframe 所执行的替换操作使用默认值覆盖您偏好的属性值。
