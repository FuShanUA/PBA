在 Slate 中使用 Platform SDK (PSDK)

Platform Software Development Kit (PSDK) 允许您从以下位置调用 Foundry API： Slate 函数。您可以使用它来检索数据集元数据、处理本体论对象，以及访问其他受支持的平台 API。

您必须使用 Slate 中配置的客户端，来源为 @slate/psdk。从以下位置导入操作： @osdk/foundry 并将客户端作为第一个参数传入。您无需创建客户端或提供身份验证令牌。请求使用运行该 Slate 应用程序的用户的权限。操作和参数遵循标准的 Foundry SDK API，但受 Slate 的 受支持操作列表.

不同于 本体论 SDK (OSDK)限制，PSDK 不要求您先选择本体论实体或生成库即可使用。

启用 Platform SDK

要在您的应用程序中启用 PSDK：

  1. 在编辑模式下打开您的 Slate 应用程序。
  2. 打开 函数 面板并找到 ”面板中找到。 例如，要使用 section.
  3. 选择 在控制面板中启用 + 新建 Foundry SDK 并等待 SDK 版本显示。

选择 用途 以复制一个入门示例，然后将其粘贴到 Slate 函数中。

当您在 Slate 函数中添加来自以下位置的导入时，Slate 也会自动启用 PSDK： @slate/psdk or @osdk/foundry 到 Slate 函数中。保存您的应用程序以保留 SDK 配置。

PSDK 需要经过身份验证的访问，并且在 公共应用程序中不受支持.

Platform SDK 版本

Slate 会自动加载您的 Foundry 实例上可用的最新 SDK 版本，该版本与应用程序配置的主版本匹配并满足其最低次版本要求。兼容的次版本和补丁更新无需手动更新软件包。

例如，配置为版本 2.66 的应用程序可以使用更新的兼容 2.x 版本。Slate 不会自动将应用程序升级到新的 SDK 主版本，且手动主版本升级目前尚不可用。当其可用时，请查看 SDK 发布说明 ↗ 以了解可能需要更新您的函数的重大变更，并在升级前测试您的应用程序。

显示数据集名称

在此示例中，您有一个名为 Sales的数据集。一个 Slate 变量保存其资源标识符 (RID)，一个函数使用 Get Dataset API检索其名称，一个 Text 部件显示 Sales。应用程序的每个用户都必须具有访问该数据集的权限。

  1. 在监听器设置向导的 变量 面板中， 创建一个变量 ，命名为 v_dataset_rid 并将其数据集 RID 作为默认字符串值。例如，输入 "ri.foundry.main.dataset.00000000-0000-0000-0000-000000000001"，将示例 RID 替换为您自己的 RID。

  2. 在监听器设置向导的 函数 面板中，创建一个名为 f_dataset_name 的函数，并输入以下 JavaScript 代码：

import { client } from "@slate/psdk";
import { Datasets } from "@osdk/foundry";

const dataset = await Datasets.Datasets.get(client, {{v_dataset_rid}});
return dataset.name;

  3. 选择 测试 以运行该函数并验证其结果是否为 Sales.

  4. 添加一个 文本小部件 并将其内容设置为 {{f_dataset_name}}。该部件显示 Sales.

  5. 保存您的应用程序。

直方图 {{v_dataset_rid}} 表达式将当前变量值传入函数。您可以使用相同的模式将其他 Slate 变量、部件属性或函数结果传入 PSDK 操作。

为 Slate 改编公共 API 示例

直方图 Foundry API 参考 描述了操作及其参数。在为 Slate 改编其 TypeScript 示例时：

  • 保留来自以下位置的操作导入： @osdk/foundry.
  • 导入 client from @slate/psdk 而不是创建客户端或提供身份验证令牌。Slate 会处理连接和身份验证。
  • 使用 JavaScript，不带 TypeScript 类型注解。

您无需安装 npm 软件包或生成 SDK 库。示例可能使用您的 SDK 版本中不可用的操作，因此请检查 Foundry SDK 旁边显示的版本，然后再进行改编。有关更多背景信息，请参阅 Platform SDK 概述.

支持的操作

Slate 目前允许以下路径前缀下的 API 请求：

  • 本体论资源： /api/v2/ontologies/
  • 数据集： /api/v2/datasets/
  • 附件： /api/v2/attachments/
  • 模型： /api/v2/models/
  • 操作： /api/v2/operations/

相同的资源路径在以下位置下也被允许： /api/v1/。操作必须在您的 SDK 版本和 Foundry 实例中可用，并且您必须具有所需的权限。

对其他端点（例如 Admin API）的请求会被阻止，即使这些操作出现在代码补全中。

请求错误

被阻止的请求会报告 Fetch is restricted for <URL>.，其中 <URL> 是请求的 URL。这表示 Slate 在联系端点之前拒绝了该请求。

失败的 HTTP 请求会抛出错误。结构化的 API 错误包括 statusCode 以及（当服务器提供时） errorName, errorCode, errorInstanceId日 parameters。例如，数据集请求返回 HTTP 404 时，所选字段可能如下所示：

故障排除

  • 平台 SDK 加载错误： 如果旁边出现错误图标 Foundry SDK 菜单中选择 ”面板中找到。 例如，要使用 部分，请将鼠标悬停在上面以查看错误消息。如果 在控制面板中启用 在尝试失败后再次出现，请选择它以重试。
  • 被阻止的端点： 请检查 API 参考文档中操作的 URL 是否与以下之一匹配 允许的路径前缀。操作出现在代码补全中并不意味着 Slate 允许该操作。
  • 权限错误： 请验证运行 Slate 应用程序的用户是否可以访问资源并执行所请求的操作。您作为应用程序作者自身的访问权限不会赋予其他用户访问权限。

要检查失败的函数，请选择 测试 菜单中选择 函数 面板。您还可以在 健康检查对话框.
