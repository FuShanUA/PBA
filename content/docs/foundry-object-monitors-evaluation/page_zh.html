评估

对象监视器已被 Automate取代。Automate 是一款完全向后兼容的产品，可为平台中的所有业务自动化提供统一入口。

对象监视器按订阅者分别进行评估，操作效果也按订阅者分别执行。这确保了依赖用户属性的数据访问权限和操作验证都能得到遵守，同时允许用户为各自的工作流配置对象监视器。

实时评估

某些输入和条件组合支持实时评估。支持实时评估的对象监视器将被持续评估。通知或操作通常会在检测到变更后的几分钟内执行。如果从管道构建中同步了大量变更，则使用这些对象作为输入的监视器评估及其后续操作或通知可能需要更长的执行时间。

要支持实时评估，必须满足以下所有条件：

  • 输入对象类型已迁移到 Object Storage v2 （在本体论配置中）。
  • 输入对象类型包含的对象实例少于 1000 万。如果某个条件正在进行实时评估，而该对象类型因新增对象而增长并超出此限制，则监视器将无法完成评估。
  • 输入对象集定义仅使用针对字符串、数字范围或布尔属性的精确匹配筛选器。
  • 输入对象集定义不包含关联对象属性或数组属性。
  • 该规则使用了 事件条件 来检测输入中添加或移除的对象。

计划监控器

实时评估仅适用于来自管道构建的更改。通过操作所做的更改可能需要长达七个小时才能被对象监控器检测到。要缩短此时间，请添加一个 通知规则 ，用于任何必须立即触发通知的操作。

虽然实时评估目前不支持计划监控器，但可以将函数支撑的操作配置为当对象监控器在特定时段内检测到事件时运行，并使用 TypeScript 检测当前时间/日期。此代码片段展示了一个示例：

非实时评估

无法进行实时评估的对象监视器将通过轮询机制进行评估。监视器保证会在上一次评估后的 24 小时内完成评估。为了分散大量监视器的评估负载，无法明确安排基于轮询的评估发生的具体时间。基于轮询的监视器的上次评估时间会被存储并显示在 Object Monitors 应用界面的监视器概览面板中。

手动评估

非实时的对象监视器也可以通过 Object Explorer 界面进行手动评估。此选项主要用于在设置非实时监视器时进行测试。
