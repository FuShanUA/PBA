导航

Map 应用程序允许您平移、缩放、旋转或倾斜地图，以便于查看和分析。您还可以使用快捷方式快速居中地图，或使用 选择 面板在地图上定位对象、位置和坐标。

基本地图控件

  • 若要平移，请在地图视口中单击并拖动，或使用键盘上的方向键。
  • 若要缩放，请使用以下方式之一：
    • 直方图 放大 and 缩小 左下角的按钮
    • 鼠标滚轮
    • 直方图 + and - 键盘上的按键
  • 若要旋转和倾斜地图，请在按住 Ctrl（Windows）或 Cmd（macOS）的同时单击并拖动。

将地图居中于项目

媒体 0 键盘上的键以导航地图并显示所选对象。如果您未选择任何对象， 0 将导航地图以显示地图上的所有对象。

使用查找面板

直方图 选择 面板允许您导航到已添加到地图中的对象，以及位置和坐标。

在地图上查找对象

选择 地图上的对象 选项卡，然后输入搜索查询以按标题或属性值查找对象。选择某个结果 将使地图导航到该对象。

查找位置

需要 API 密钥

您的组织必须已配置 控制面板中的 Mapbox API 密钥 此功能才可用。

选择 位置 选项卡，然后输入查询以按地址或名称查找位置。选择某个结果将使地图导航到该位置，并显示带有该位置地址的标记。您可以通过单击结果列表中地址旁边的 眼睛 图标来隐藏该标记。

导航到坐标

选择任一 地图上的对象 or 位置 选项卡后，您可以在搜索输入框中输入坐标，并通过选择结果将地图导航到该坐标。使用 显示坐标 按钮将在您指定的坐标处添加文本注释。
