导航

Map 应用程序允许您平移、缩放、旋转或倾斜地图，以便于查看和分析。您还可以使用快捷键快速将地图居中，或使用 “查找” 面板来定位地图上的对象、位置和坐标。

基本地图控件

  • 要平移地图，请在地图视口中点击并拖动，或使用键盘上的方向键。
  • 要缩放地图，请使用以下方法之一：
    • 左下角的 “放大” 和 “缩小” 按钮
    • 鼠标滚轮
    • 键盘上的 + 和 - 键
  • 要旋转和倾斜地图，请在按住 Ctrl（Windows）或 Cmd（macOS）的同时点击并拖动。

将地图居中于项目

按下 0 键，即可导航地图以显示您选择的对象。如果未选择任何对象， 0 将导航地图，使地图上的所有对象都能显示。

使用“查找”面板

通过 “查找” 面板，您可以导航到已添加到地图中的对象以及位置和坐标。

在地图上查找对象

选择 “地图上的对象” 选项卡，然后输入搜索查询，以按标题或属性值查找对象。选择某个结果后， 地图将导航至该对象。

查找位置

需要 API 密钥

您的组织必须已配置 控制面板中的 Mapbox API 密钥 ，此功能才可用。

选择 位置 选项卡，然后输入查询，按地址或名称查找位置。选择某个结果后，地图将导航至该位置，并显示带有该位置地址的标记。您可以在结果列表中点击地址旁边的 眼睛 图标来隐藏该标记。

导航至坐标

无论选择 地图上的对象 还是 位置 选项卡，您都可以在搜索输入框中输入坐标，并通过选择相应结果将地图导航至该坐标。使用 显示坐标 按钮将在您指定的坐标处添加文本标注。
