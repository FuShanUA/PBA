类型转换

支持环境：Batch、Faster、Streaming

将表达式转换为给定类型。

表达式类别： 转换，常用

声明的参数

  • 表达式： 要转换的表达式。
    Expression<AnyType>
  • 类型： 要转换到的类型。
    Type<C>

类型变量约束： C 接受 AnyType

输出类型： C

示例

示例 1：基础用例

参数值：

  • 表达式： a
  • 类型： Array<String>
a输出
[ 12.3, 20.1 ][ 12.3, 20.1 ]
