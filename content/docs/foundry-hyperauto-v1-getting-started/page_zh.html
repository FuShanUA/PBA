开始使用 HyperAuto V1

日落

HyperAuto V1 目前处于 日落 阶段，并将在未来某个日期被弃用。目前仍提供全面支持。不建议创建新的 V1 管道，用户应从 HyperAuto V1 迁移到 V2，具体步骤详见 迁移文档.

本指南适用于 HyperAuto V1。如果您使用的是 HyperAuto V2，请参阅 HyperAuto V2 入门 来替代。

以下步骤将指导您创建 SDDI 实例：

  1. 您可以从 侧边栏打开 SDDI Cockpit，或访问 [foundryinstance URL]/workspace/sddi-app 并选择 创建新实例.

  2. 按照屏幕上的说明选择相应的源类型。

  3. 输入您偏好的仓库名称，并选择所需的仓库位置以及管道输出文件夹位置。对于管道输出文件夹，HyperAuto 会提供建议的位置。

  4. 配置一个要应用 HyperAuto 的数据连接源。该源的类型应与您在第 2 步中选择的源类型相同。分别为原始数据和元数据指定文件夹位置。这些文件夹随后将存放从源同步的原始数据集和元数据数据集。

  5. 在同步数据步骤中同步数据库元数据表。这将从您的源系统同步相关的元数据表，并将其添加到指定的自动管道生成器仓库中，以便在后台生成管道。

您的 SDDI 实例现在应已正常运行，并已准备好清理源中的表。 要了解有关配置和执行 SDDI 流程的更多信息，请导航至 Cockpit.
