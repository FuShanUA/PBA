配置并应用样式

Slate 构建在 Palantir 开源 Blueprint 框架之上，与其他任何网站一样，使用 CSS 为 DOM 设置样式。这为小部件提供了一致的外观和体验，并内置了“深色模式”切换开关。这些不是“皮肤”或“模板”，而是内置于每个 Slate 小部件中。

这意味着，如果您的应用程序设计需要特定的 UI，您的开发工作将集中于提供一组样式覆盖来提供新规则。这会增加一定的复杂性，因为您必须了解 Slate 默认样式应用在何处，然后生成具有正确特异性级别的 CSS 选择器来覆盖它。

在应用程序中开发样式时，您最好的帮手是 Chrome 开发者工具——特别是“检查器”——它让您可以查看网页中任何元素的渲染 HTML 和 CSS。右键点击 → “检查”将打开检查器并高亮显示所点击的元素。这是识别哪些类应用于哪些元素，以及因此需要扩展或覆盖哪些类的关键。

从技术上讲，您在 Slate 应用中编写的 CSS 是一种称为 Less ↗ 的预编译方言。Less 提供了简化冗长 CSS 的语法，是在保持可读性的同时编写复杂样式的强大工具。在页面加载时，所有 LESS 都会被编译为 CSS，因此当您检查渲染后的页面时，如果您使用了 LESS 功能，可能会看到差异。请阅读 LESS 文档以了解常见模式和有用功能的更多信息。

小部件样式

在监听器设置向导的 样式 输入区域位于 显示 每个单独小部件的配置中，您可以在小部件级别定义不同的样式和类。这些样式仅在所选小部件上可用。如果该小部件是容器，则其所有嵌套子级也可以使用这些样式。

与将样式存储在中心位置相比，在小部件中编写的样式可能难以管理或跟踪。对于较大的项目，您应避免将样式放入各个小部件中，而是通过样式面板来管理样式。

样式表

最简洁的模式是在 样式 面板中定义新类，并使用 附加类 配置将它们应用于各个小部件。有两种不同类型的样式表可用于支持更复杂的样式。

本地样式表

本地样式表在应用程序级别定义样式和类。每个 Slate 应用程序都恰好有一个本地样式表，可以在整个应用程序中引用。

Blueprint 样式

Slate 使用由 Blueprint ↗ 提供的样式，这是 Palantir 创建的开源框架。

您可以在应用程序中使用许多 Blueprint 类和图标，以在 HTML 中构建常见的 UI 元素，帮助您的应用程序与平台其余部分更无缝地匹配，并实现专业、生产级的外观和体验。

颜色

Blueprint 提供了一系列 核心和扩展颜色名称 ↗ ，这些颜色的选择考虑到了 WCAG 2.0 合规性（用于无障碍应用程序设计）。

可以使用 LESS 变量在 Slate 样式中直接引用这些颜色。

组件

Blueprint 中有许多组件可用于创建动态用户交互元素或为您的应用程序增添一份精致感，从 按钮 ↗ to 进度条 ↗ to 标签 ↗.

要在 Slate 中使用这些组件，请注意每个组件的 CSS API （而非 JavaScript API）部分，以了解您是否可以使用相关的 pt-x 类和 HTML 元素在 Slate 中创建类似的组件。

图标

引用 Blueprint 图标的方法因版本而异。要引用 Blueprint 图标，请按照适用于您特定版本的 Icon CSS API 说明操作。

动态样式的模式

由于 Slate 的样式需要在页面加载时确定，因此所有 CSS 样式必须是静态的。这意味着，例如，您不能在 CSS 类中放入 Handlebars 语句来尝试让 widget 更改颜色或更改任何其他属性。不过，有几种不同的模式可以实现动态样式。

动态“附加类”

虽然您不能 生成 or 修改 即时类，但您可以使用 Handlebars 来模板化每个 widget 的 附加类 配置。常见的模式是预先定义多个不同的类，然后使用函数来确定在特定情况下应应用哪些类。如果您正在构建一个大型的有状态应用程序——参见上文相关章节——那么您可能希望有一个中央函数来确定在任何给定条件下应用于所有不同 widget 的正确类，然后返回 widget 与要应用的正确类之间更复杂的映射。

通过这种方式，您可以轻松构建一个通过更改颜色、图标或其他显示属性来响应的应用程序，甚至可以通过显示和隐藏整个 widget 来调整自身大小。有关此特定模式的更多信息，请参见上文的响应式布局章节。

Style 属性

虽然应用程序的 CSS 必须预先编译，但 HTML widget 上的 style 属性可以使用 Handlebars 进行模板化。这仅适用于 HTML widget 或您提供要在单元格中显示的 HTML 的表格；在这些情况下，您可以动态生成 CSS 并将其放入该元素的 style 属性 ↗ 中。

深色模式加载屏幕

在初始页面加载期间，您通常会看到深色侧边栏加载白色屏幕。要加载完全深色的屏幕，您可以使用查询参数 ?$theme=dark 以与侧边栏一致的深色主题加载整个页面。

这是一次性加载，如果不添加查询参数，将不会在页面刷新后保留。而且它仅在 Slate 应用程序开始加载后才适用，而不适用于浏览器仍在路由到应用程序的期间。

自定义字体

Slate 支持使用自定义字体，以进一步使应用程序的外观符合您组织的需求。要使用自定义字体，必须先将该字体作为 otf 文件上传到 Foundry。上传后，即可通过 Styles 工作表导入字体，并使用字体文件的 rid 将其分配给某个字体族。
