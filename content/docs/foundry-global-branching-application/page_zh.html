Global Branching 应用程序

Global Branching 应用程序使您能够维护组织的分支。您可以将 Global Branching 应用程序用作分支和提议的集中管理中心，从而创建新分支、查看分支和提议，以及批准和合并提议。

主页

主页为您提供提议和分支的概览。

在 您的未决提议 部分中，您可以查看和访问您的活动提议。提议是一种用于审查和批准在分支中所做更改的机制。

在 您的未决分支 部分中，您可以查看和访问您的未决分支。分支是一个独立的环境，您可以在其中试验和测试想法，而不会影响 main。在此部分中，您可以创建提议、归档现有分支或创建新的全局分支。请注意，归档带有未决提议的分支也会关闭该提议。

未决分支既包括活动分支，也包括非活动分支。

在页面底部，您可以使用快捷方式导航到您已合并的提议、已关闭的提议或已归档的分支。选择其中任一项即可进入相应的选项卡。

分支

该 分支 选项卡允许您查看您有权访问的所有分支，并列出其名称、状态、创建者和创建日期。您还可以导航到与分支关联的提案，或直接从此列表中为分支创建提案。

您可以执行以下操作：

  • 新建： 创建新分支。
  • 归档： 归档打开的分支。此操作将关闭所有打开的提案。
  • 筛选： 按以下条件筛选分支： “状态” 和 “创建者”，并使用搜索栏按名称查找分支。

要导航到包含更多详细信息的特定分支页面，请选择其对应的行。

分支页面

分支 “概览” 选项卡提供有关分支的综合信息，并允许您创建提案或导航到关联的现有提案。详细信息包括：

  • 分支的名称和当前状态。
  • 已修改的资源。
  • 有关分支的概要信息，包括分支上次更新的时间、分支创建日期、分支创建者、所选空间、组织和本体论。
  • 评论区。

分支 “安全” 选项卡允许分支所有者和空间管理员管理角色分配。请参阅 分支安全 以了解更多信息。

提案

“ 提案” 选项卡允许您查看您有权访问的提案，并列出其名称、状态、创建者和创建日期。

您可以执行以下操作：

  • 筛选： 按 状态 和 创建者筛选提案，并使用搜索栏按名称查找提案。
  • 关闭： 通过选中提案左侧的复选框来关闭提案。

要导航到包含更详细信息的特定提案页面，请选择其对应的行。

选择某个提案将显示该提案的详细信息。

提案页面

提案 概述 选项卡汇总了有关您的提案的信息，使您能够在从编辑和测试到审查和合并的整个开发过程中跟踪其状态。该 概述 选项卡的中央部分是相应分支上已修改资源的列表。对于列表中的每个资源：

  • 根据资源的审批策略管理审阅者。请参阅 向提案添加审阅者 和 资源保护和审批策略 以了解更多信息。
  • 导航到资源的审阅体验。
  • 查看检查状态并解决所有失败的检查。请查看 检查 以更好地了解此功能。
  • 查看更多选项菜单（...）以执行其他操作，例如从分支中移除该资源。

您还可以在 Workflow Lineage 和 Data Lineage 中打开修改后的资源。

提案的「 更改 」标签页允许您查看和审核提案中所有资源的更改。使用左侧的导航面板浏览已修改的资源，并查看每个资源的检查和审批状态。选择一个资源以：

  • 查看该资源在分支上的更改。
  • 查看检查和审批状态。
  • 如果您具有所需权限，可在分支上批准或拒绝更改。
  • 在资源菜单中查看其他资源操作。

更改查看器适用于 Global Branching 支持的所有资源类型，但 Workshop、Pipeline Builder 和 AIP Logic 除外。

「 合并历史 」标签页集中了有关提案合并尝试的信息，并显示合并特定资源时遇到的任何错误。此标签页仅在第一次合并尝试后才会出现。
