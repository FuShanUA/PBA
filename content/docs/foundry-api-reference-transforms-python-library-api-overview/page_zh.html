transforms.api

Transforms Python API 提供一系列类和装饰器，用于构建 Pipeline。此页面是一个参考索引。在下表中选择任意名称，即可查看该函数或类的文档，包括其参数和示例。

最小示例

新建的 Python transforms 仓库包含一个 src/myproject/datasets/examples.py 文件，该文件从 transforms.api导入。以下转换读取一个数据集并写入一个数据集。只需替换这两个数据集路径，它即可直接运行：

from transforms.api import Input, Output, transform, LightweightInput, LightweightOutput


@transform.using(
    output_dataset=Output("/path/to/output/dataset"),
    input_dataset=Input("/path/to/input/dataset"),
)
def compute(input_dataset: LightweightInput, output_dataset: LightweightOutput) -> None:
    output_dataset.write_table(input_dataset.polars(lazy=True))

from transforms.api import transform_df, Input, Output


@transform_df(
    Output("/path/to/output/dataset"),
    hair_eye_color=Input("/path/to/input/dataset"),
)
def filter_hair_color(hair_eye_color):
    return hair_eye_color.filter(hair_eye_color.hair == "Brown")

要在 Polars、pandas、DuckDB 和 PySpark 计算引擎之间进行选择，请参阅 计算引擎。

函数

名称描述
configure([profile, allowed_run_duration, ...])用于修改 Spark 转换配置的装饰器。
incremental([require_incremental, ...])用于将输入和输出转换为其对应的 transforms.api.incremental 形式的装饰器。
lightweight([_maybe_function, cpu_cores, ...])用于将转换变为轻量级转换的装饰器。
transform(**kwargs)将计算函数包装为 Transform 对象。
transform_df(output, **inputs)将包装好的计算函数注册为 DataFrame 转换。
transform_pandas(output, **inputs)将包装好的计算函数注册为 pandas 转换。
transform_polars(output, **inputs)将包装后的计算函数注册为 Polars 转换。
