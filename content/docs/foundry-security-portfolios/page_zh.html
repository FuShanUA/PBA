项目组合

项目组合允许用户在空间内组织项目。每个项目组合包含多个项目，而每个项目仅属于一个项目组合。任何有权访问空间的用户都可以查看该空间的项目组合，但用户仍需单独获得权限才能查看项目组合内的项目。

创建项目组合

拥有空间 Editor 角色的用户可以在项目组合页面创建项目组合。每个项目组合必须属于一个空间并具有唯一名称。项目组合创建者可以选择性地提供简短的文本描述，并通过图片或图标颜色配置项目组合的缩略图。缩略图应为正方形，并会被压缩尺寸。

编辑项目组合元数据

管理员和策展人可以通过右上角的“操作”菜单编辑项目组合的元数据。名称、描述和徽标均可编辑，但项目组合在创建后无法在不同空间之间移动。

管理员和策展人还可以为项目组合添加 Markdown 文档。所有可以查看该项目组合的用户都可以查看此文档。

管理项目组合内容

创建项目组合后，管理员可以使用 添加项目 对话框，将同一空间中的项目添加到该项目组合中。该对话框会显示与项目组合处于同一空间的所有项目，包括已属于其他项目组合的项目。由于项目只能属于一个项目组合，将项目移动到另一个项目组合会将其从原项目组合中移除。

选择要包含在此项目组合中的项目后，用户可以选择更改每个项目的显示名称。这是一个可选步骤。

其他项目组合策展人

通常，只有拥有 Editor 角色的用户才能管理空间中项目组合的内容。为了扩展项目组合的管理权限，拥有管理权限的用户可以打开项目组合的侧边栏并编辑其 策展人列表。这些用户将可以在该项目组合中添加或移除项目，以及编辑其描述和文档。

项目组合目录

在项目中固定的资源会显示在项目组合的目录中，并按项目或资源类型分组。管理员可以通过在 添加内容 对话框中搜索资源，来推广项目组合中各项目的资源。

项目侧边栏

项目侧边栏显示已添加到项目组合中的项目列表。通过项目侧边栏，用户可以打开各个项目，项目组合管理员也可以添加或移除项目。
