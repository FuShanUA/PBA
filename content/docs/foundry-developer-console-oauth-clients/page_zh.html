独立 OAuth 客户端 [旧版]

独立 OAuth 客户端现已过时，无法再创建。要设置新客户端，请按照以下步骤 创建不受限制的应用程序。要迁移现有客户端，请参阅 迁移独立 OAuth 客户端 （见下文）。

独立 OAuth 客户端是自定义应用程序的旧版轻量级替代方案。请考虑将独立 OAuth 客户端替换为 不受限制的自定义应用程序，它提供了限制、指标和 SDK 生成等新功能。

用户无法再创建独立 OAuth 客户端。现有的独立 OAuth 客户端可迁移至 Developer Console 应用程序。

迁移独立 OAuth 客户端

将独立 OAuth 客户端迁移至 Developer Console 应用程序后，即可使用以下功能：

  • 本体论和 Platform SDK
  • 网站托管
  • 应用程序限制
  • DevOps 支持
  • 指标

要迁移独立 OAuth 客户端：

  1. 打开现有的独立 OAuth 客户端。
  2. 选择 迁移至 Developer Console 应用程序。
  3. 在迁移向导中选择位置和最高分类级别（如适用）。
  4. 查看 Developer Console 应用程序的用户权限。
  5. 选择 提交 以完成迁移。

迁移后，新创建的应用程序将显示在所选位置。您可以像对任何其他 Developer Console 应用程序一样，对该应用程序执行操作。使用您的客户端的现有工作流不受影响。

在 Developer Console 中管理独立 OAuth 客户端

导航至 OAuth 客户端列表 并选择您要管理的客户端。请注意，您必须在 OAuth 客户端所属组织中拥有 管理 OAuth 2.0 客户端 权限，才能管理该 OAuth 客户端。

现在，您将看到 概览 页面，您可以在其中编辑应用程序详细信息，例如应用程序名称、描述和徽标。您还可以选择删除该应用程序，只需展开 危险区域。

从这里，您可以导航至 OAuth 与权限 页面，您可以在其中查看和管理客户端详细信息。您还可以选择与其他组织共享该应用程序，这将使他们能够为自己的用户启用该应用程序。
