导航

Use Cases 应用程序包含多种导航功能和工具，可在 Foundry 资源之间实现流畅的工作流程。我们建议您在创建第一个用例之前，先熟悉 Use Cases 应用程序中的各个页面和元素。

点击以下图标开始浏览 Use Cases 应用 应用程序 （位于 Foundry 导航侧边栏中）。如果 Use Cases 应用程序未显示在此处，请选择 “查看全部” 以展开应用程序列表。

主页

Use Cases 应用程序的首个视图是主页，您可以在其中查看和搜索所有用例，也可以创建新用例。

搜索

使用直方图中的 搜索栏 （位于屏幕右上角）以搜索现有的用例、应用程序或本体论资源。

您的用例

在本部分中，您将找到您最近使用的用例列表。用例带有以下标记 活跃, 实验性，或 已弃用 状态：

  • 活跃： 已在您的 Foundry 实例中发布并运行。
  • 实验性： 正在进行中且尚未正式发布。
  • 已弃用： 不再运行。

了解更多关于 用例元数据.

选择一个用例，在用例概览页面中查看更多详细信息。

在 Foundry 应用程序之间导航

使用 Use Cases 应用管理资源的便利之一，是能够在您的用例与其他 Foundry 应用程序之间来回导航。当您希望专注于某个特定用例但又需要更新应用程序或编辑本体论组件时，这一功能尤为实用。

打开用例中包含的资源时，您会在界面中看到一个内置的导航面包屑标头。这使您在查看或修改资源后能够轻松返回您的用例。导航标头如下图所示：

本体论管理器

Use Cases 应用程序允许您通过点击对象类型页面右上角的 在 Ontology Manager 中查看和编辑 直接跳转到 Ontology Manager 中的对象类型定义页面。

要返回您的用例，请点击 返回 [用例名称] （位于本体论页面左上角）。

了解更多关于 本体论 以及如何 编辑对象类型.

在 Use Cases 应用程序与 Project 视图之间导航

每个用例都有一个支撑 Project，用于存储该用例中使用的应用程序和其他资源。您随时可以在 Project 视图与 Use Cases 应用程序视图之间切换。

要从用例视图切换到 Project 视图，请选择 切换到 Project 视图 （位于左侧菜单底部）。

要切换回用例视图，请选择 切换到用例视图 （位于 Project 视图底部）。
