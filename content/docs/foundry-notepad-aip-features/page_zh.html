Notepad 中的 AIP 功能

Foundry Notepad 提供一系列 AIP 功能，旨在帮助您更快、更高效地分享本体论洞察。您可以在 Notepad 中使用 AIP 自动进行拼写检查、缩短、修改或翻译您的文本，同时保留其现有格式。您还可以使用 函数 通过在 AIP Logic 或其他已发布函数中配置的自定义行为来修改 Notepad 内容。

Notepad 的 AIP 功能包括：

  • 自定义提示： 在 输入提示... 字段中输入您自己的指令，以对文本应用自定义转换。
  • 修正拼写和语法： 支持英语、法语、德语、日语、韩语、西班牙语和乌克兰语。
  • 更改写作风格： 在“专业”（适用于报告）或“自信”（适用于公告）风格之间进行选择。
  • 缩短： 使文本块更加简洁。
  • 翻译： 将文本从一种受支持的语言翻译为另一种语言。
  • 预览多个命令： 预览对同一文本块执行多个 AIP 操作的结果，例如先修正拼写，然后使文本简洁，再翻译成法语，最后替换您的原始文本。
  • 函数： 使用接受字符串输入的平台内函数来替换文档或模板中的文本。这些函数可与其他 AIP 操作结合使用。如果未启用 AIP，您仍可以使用函数编辑 Notepad 内容。请参阅 自定义函数 以了解更多详情。

激活 AIP 功能

要在 Notepad 中使用 AIP，请选择 使用 AIP 编辑 工具栏中的按钮。

注意：AIP 功能的可用性可能会发生变化，且不同客户之间可能存在差异。
