翻译、本地化 (l10n) 与国际化 (i18n)

应用构建者现在可以通过 Translations 功能，为 Workshop 应用中支持的字符串类型提供翻译。借助此功能，可以手动或（在已启用的租户中）借助 AIP 将 Workshop 应用本地化 (l10n) 和国际化 (i18n) 为多种语言。如果 Workshop 应用已使用此功能翻译为某种语言，查看者在其浏览器语言环境下将看到该模块的翻译视图。

要启用此功能，请导航至 设置 选项卡（编辑模式下），并开启 翻译 菜单中选择 高级功能 部分。启用后，将出现一个新的 翻译 选项卡，应用构建者可在其中为其模块配置翻译。

可翻译的内容

Workshop 应用中的以下内容可以翻译：

  • 模块标题 标题
  • 区块标题 Title(s) and 选项卡
  • 来自以下小部件的静态文本，例如：
    • Tabs 小部件 标签
    • Button Group 小部件 文本 and 描述
    • Metric Card 小部件 标签 and 描述
    • ，而配置为使用数组的循环部分将包含一个 内容
  • Object Table 和 Object List 小部件 列标题
  • 透视表小部件 聚合标题
  • Filter List 小部件 区块标题

翻译方法

Workshop 应用中有效字符串的翻译既可以由应用构建者手动完成，也可以在启用了自定义工作流的租户中使用 AIP 自动生成。

手动翻译

模块中的字符串可由应用构建者手动翻译。选择目标语言后，模块中检测到的每个可翻译字符串都会显示一个输入字段，用于手动输入翻译。添加翻译后，可以直接在模块中预览，以便立即查看。

使用 AIP 自动翻译

模块中的字符串也可以使用 AIP 进行翻译。使用 AIP 翻译字符串需要配置 用于自定义工作流的 AIP 功能.

为了向 AIP 提供执行字符串翻译所需的上下文，必须定义模块的起始语言，并设置目标语言。 翻译 带有紫色 AIP 图标的选项可用于使用 AIP 自动翻译模块中检测到的所有符合翻译条件的字符串。翻译结果可以在模块中立即预览，以便查看并在必要时进行手动编辑。

对翻译满意后，即可将这些翻译 标记为已完成 这实质上是将这些字符串标记为已供应用构建者审核。模块中检测到的任何新增或修改的字符串（例如，添加新按钮或编辑区块标题时）将显示在 待翻译 部分中，与已翻译和已审核的字符串区分开来。

预览翻译

在编辑模式下，可以通过导航至 翻译 选项卡并选择所配置的目标语言，直接在模块中预览翻译后的文本。
