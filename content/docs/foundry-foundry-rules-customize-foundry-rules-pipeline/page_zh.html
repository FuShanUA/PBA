自定义您的 Foundry Rules 管道

自定义 Foundry Rules 管道是一项高级功能，面向经验丰富的 Foundry 管道作者。此类自定义可能会增加工作流管理员的实施和维护负担。

Foundry Rules 开箱即用，用户无需编写任何管道逻辑。但在某些用例中，需要自定义 Foundry Rules 管道才能实现原本无法达成的结果。

用例

自定义 Foundry Rules 管道可带来多项潜在优势，包括：

  • 对不同规则子集的运行方式和运行时间进行细粒度控制。
  • 在运行规则逻辑之前对 Foundry Rules 输入进行预处理的能力。
  • 在 增量转换中运行 Foundry Rules 的能力。这要求规则逻辑与增量数据兼容。

Foundry Rules 输出的后处理（例如添加列）可通过专门的下游转换来实现。我们不建议仅为对 Foundry Rules 输出进行后处理而自定义 Foundry Rules 管道。

说明

流式工作流目前不支持自定义管道。

您可以通过启用自管理转换、选择自定义转换仓库、保存 Foundry Rules 工作流，然后生成 Foundry Rules 管道代码并将其保存到所选仓库，来部署您自己的自定义 Foundry Rules 管道。为此，请按照以下说明操作：

  1. 点击齿轮图标以打开高级设置菜单。

  2. 启用 启用自管理转换 选项。

  3. 点击 使用自定义转换仓库 （位于 转换配置 部分）。您可以 部署新仓库 （推荐）或选择 选择现有仓库 来查找并选择您要使用的仓库。

  4. 保存您的 Foundry Rules 工作流。

  5. 要生成并复制您的 Foundry Rules 管道代码，请点击 生成，然后点击 复制。

  6. 如果您之前选择的是现有仓库，请创建一个名为 FoundryRulesTransform 的文件，该文件位于 rules.transforms 目录中，并将复制的代码粘贴到该文件中。如果在第 3 步中选择了新部署的仓库，请找到 “FoundryRulesTransform” 并将代码粘贴进去。
