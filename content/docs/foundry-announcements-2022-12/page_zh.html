控制面板：Foundry 自助式管理

发布日期：2022-12-13

注册并管理您的 Foundry 环境

借助控制面板，Foundry 的全套治理和管理功能现在可以通过统一的自助式界面访问。此操作视图使平台管理员能够监督 Foundry 的使用情况，并轻松配置安全和访问设置。

控制面板使管理员能够：

  • 配置 Foundry 注册的 authentication, 权限以及应用程序设置。
  • 监控使用指标并管理资源配置文件，以管理不断增长的 Foundry 合作项目。
  • 帮助促进 用户 之间的协作，并利用 Foundry 强大的访问控制。

在每个层级配置安全和设置

Foundry 的安全控制由多个组件组成： 注册, 组织, 用户组和用户。注册代表 Foundry 的一个实例，可以包含一个或多个组织。在单个组织内，管理员可以在用户或用户组级别控制数据访问。

设置在注册和组织级别均可配置，并且可以初始化、扩展和审查。这些设置包括：

  • 注册级别的控制：

    • 用户身份验证
    • 注册
    • 配置 permissions
    • 联系信息
    • 通知
    • 受信任用户
    • 网络出站策略
    • 对象数据库

  • 组织级别的控制：

    • 审计日志
    • 电子邮件设置
    • 工作区
    • 使用指标
    • 第三方管理
    • 资源限制
    • 配置文件

设置复杂的协作工作流

随着您的注册规模扩大以及合作机会的出现，可以使用控制面板来促进无缝的 跨组织协作。可以将其他组织添加为协作者，使外部实体的用户能够协同工作。如果工作流需求发生变化，只需返回控制面板更新用户和组的发现设置，或查看协作组织列表以确保适当的信息传输。

控制面板还可以通过在注册和组织级别管理设置和权限，来促进更复杂的协作工作流。例如，管理员可以划定访问边界、管理联合协作，以及配置用户发现其他用户的能力。

我应该在什么时候使用控制面板？

控制面板有助于管理您 Foundry 注册的安全和配置。管理员可以使用控制面板在注册和组织级别访问、审查以及 委派权限 给特定用户。

如果您是 Foundry 平台的管理员，请查看 控制面板文档 以确保您的配置满足 Foundry 用户的日常需求。

Workshop：Quiver 嵌入小组件的输出变量

发布日期：2022-12-08

Quiver 仪表板嵌入小组件现在在 Workshop 中支持输出变量！这使得嵌入的 Quiver 仪表板与其父 Workshop 模块之间能够实现更强的交互性和共享状态，并为利用 Quiver 灵活的可视化和转换语法与 Workshop 强大的工作流构建能力的创意工作流释放了巨大潜力。

按照以下 指南 开始，了解如何在 Workshop 模块中嵌入 Quiver 仪表板。

更多亮点

数据集端点

获取特定本体论的元数据 | 一个 新的获取本体论端点 可用于获取特定本体论的元数据。此前，相同的元数据可以通过 "列出本体论"端点 获取所有本体论的元数据。

管理 | Control Panel

为组织启用 TPA | 组织管理员现在可以使用控制面板代表其组织管理与 第三方应用程序 的集成。

Analytics | Contour

在 Contour 仪表板文本单元格中实现表格 | 文本单元格 在 Contour 仪表板中现在支持添加表格布局。

Analytics | Quiver

Quiver 范围选择 | 用户现在可以在分析中的时间序列图中使用范围选择（例如， 以交互方式查看不同范围的范围统计数据).

为弹出窗口使用新的行选择器 | 从转换表列中弹出时间序列单元格时，现在会添加一个由“表行选择器参数”控制的时间序列图（可在 参数面板中查看）。在参数中更改行将更新该列中绘制的时间序列。

新增日期/时间戳布尔转换 | 新增了日期和时间布尔比较功能，可按转换表中列的时间戳进行时间过滤。

重新设计的对象集和对象卡片，显著提升可用性 | 此更新提升了 对象集和对象 卡片类型的可用性。例如，对象集卡片中的时间序列属性现在可以直接在表格中以迷你图形式呈现。对象表格的显示也经过重新排版，为属性值提供更多空间。对象属性以及与该对象关联的可用时间序列数据，现在可以直接在卡片中添加和删除，从而提升了存储在对象的时间相关属性中或作为度量存储在关联对象上的时间序列数据的可发现性。新卡片还通过一键弹出操作，简化并缩短了从对象集深入到单个对象的特定时间序列图或属性指标的流程。对象集的行可以作为对象卡片弹出，所有属性都可以作为时间序列图或对象属性（指标）卡片弹出。

应用构建 | Slate

在 Slate 中触发打印事件 | 现在可以通过新增的 print 操作（通过 Slate 事件提供）来触发浏览器打印对话框。使用 onPrint 事件可在打印对话框之后触发后续操作。请注意，Slate 应用需要添加额外的 CSS 和/或调整应用布局，才能获得满意的打印效果。

重新设计编辑器视图中的 Slate 页眉 | 完全 重新设计的页眉 位于 Slate 的编辑模式中。更新和重组后的视图与 Foundry 中其他资源类型的行为和模式保持一致。

变量面板中的当前值列 Chart XY 小部件：支持累积总和序列 变量 面板现在除了可编辑的默认值外，还显示当前值的只读视图。

引入事件和操作 | 事件 及其输入和触发器现在已包含在 依赖关系查看器 中，与其他应用节点并列。

应用构建 | Workshop

瀑布图小部件，v1 | 新增了瀑布图小部件，用于可视化一系列连续的数值，以便更好地理解其累积效应。

数据集成 | 构建计划

在构建计划概览页面中查找所有计划 | 新增了在 构建计划概览 页面中搜索用户有权查看的所有计划的功能。要查找所有计划，请移除任何已应用的搜索条件。 计划 随后可按名称或暂停状态进行过滤，也可以进行排序。

数据集成 | 代码仓库

转换现在支持 Python 3.9 | 在转换中新增了对 Python 3.9 的支持。Python 3.9 的优势包括新的语法特性，例如 dict 新增的联合运算符、标准集合中的类型提示泛型、装饰器语法的放宽限制，以及新的内置功能，例如移除前缀和后缀的字符串方法。完整功能列表请参阅官方 Python 3.9 发行说明 ↗.

改进了预览输入配置的界面 | 配置 预览的输入数据集 在代码仓库中已整合到单个对话框中。对于带有 schema 的数据集，可以选择使用原始输入、同一仓库中该输入的最近预览、另一个数据集，或应用了自定义过滤器的原始输入来运行预览。预览中可以对输入进行采样，以提高迭代速度并确保样本中包含相关数据。

数据集成 | 数据连接

[DC] 推出 Asana 连接器 | 新增了 Asana 的集成功能。现在支持从 Asana 同步到 Foundry 数据集。

Ontology | Map

将地图导出为图像 | 用户现在可以将当前 地图模板 （在 Workshop 中使用）的状态作为图像直接复制到剪贴板，以便粘贴到其他应用中，包括 或，或下载为 PNG 图像文件。

本体论 | 本体论管理

OMA 中属性映射性能改进 | 属性映射性能已得到改进，其中一项计算的速度现在提升了一倍。

OMA 中支持数据源 RID 搜索 | 在 Ontology Manager 中启用了一种基于数据源 RID 的搜索类型。例如，当用户想要查找错误消息中引用的内容时，此搜索类型非常有用。

Ontology Usage 现已正式发布！ | Ontology Usage 标签页现已可用。对于给定的对象类型，Usage 标签页可让您查看读取和写入随时间的演变、随时间变化的活跃用户数量，以及按应用程序类型划分的使用情况。要了解如何启用此功能， 请参阅文档.

Security | Projects

为项目默认角色引入命名空间设置 | 管理员现在可以管理应用于项目内新建项目的默认角色 空间。项目所有者可以按项目覆盖此值。平台管理员可通过右上角的按钮进行命名空间配置，位于 项目与文件 视图中进行编辑或删除。

禁止从“您的文件”引用到其他项目 | 此前，位于项目中的数据管道可以依赖位于特定账户的“您的文件”位置中的数据集。今后，将无法在其他项目中引用存储在“您的文件”中的数据集。这强制执行了推荐的数据治理和管道开发实践，并消除了当与“您的文件”位置关联的账户被禁用时生产数据管道发生故障的可能性。 阅读有关此变更的更多信息.
