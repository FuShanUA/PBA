执行模式设置

您可以为 Logic 函数选择以下两种执行模式之一： 用户作用域 执行和 项目作用域 执行。用户作用域执行是默认模式。

用户作用域执行

配置为用户作用域模式时，Logic 函数将使用运行该 Logic 函数的用户的权限来执行。

在用户范围模式下，每个用户只能查看自己的执行日志，而无法查看其他用户运行 Logic 函数的日志。执行日志将保留 24 小时。

项目范围执行

配置为项目范围模式时，Logic 函数将使用包含该 Logic 函数的项目的权限运行。在项目范围模式下，执行日志对所有拥有项目访问权限的用户可见。

项目范围执行要求 Logic 函数使用的所有资源也必须导入到与该 Logic 函数相同的项目中。此外，用户还需要对这些资源上的标记拥有访问权限。

您可以在执行模式设置中检查是否已导入所有必需的资源；如果缺少某个资源，您可以直接从配置中导入该资源。

运行历史数据集

使用项目范围的执行时，您可以配置一个数据集，用于记录所有运行历史。每次执行都会在该数据集中记录为一个新行，并且会保留过去 10000 次运行。
