Quiver 中的 AIP 功能

Quiver 的 AIP 功能旨在帮助您使用自然语言提示执行数据分析。除了从 AIP Assist 获得与 Quiver 相关问题的有用回答外，用户还可以使用：

  • AIP Generate 来添加和配置卡片，生成 分析 中的后续步骤，同时让用户保持在决策环中。
    • AIP 如何使用本体论数据
  • AIP 配置 来更改现有的 卡片配置 只需描述应如何操作数据或 Quiver 卡片。
    • 配置时间序列图表

AIP 功能的可用性可能会发生变化，并且在不同注册之间可能有所不同。

生成分析

AIP Generate 功能目前主要支持对象和对象集卡片。支持的卡片右侧会标有 AIP 图标。

您可以使用 AIP Generate，通过 继续分析自 下方文本输入框，从现有卡片或分析中的数据生成分析，该操作栏会提示您 Enter a query to continue the exploration.

在文本输入框中写下您想要执行的分析操作，AIP Generate 将使用 Palantir 提供的大语言模型 (LLM).

为获得最佳效果，请尽可能详细描述。您可以尝试以问题的形式表述提示，例如“销售额随时间如何变化？”，或者使用指令式语气，例如“显示按月分组的销售额随时间变化的条形图”或“显示营销支出的总和，行按广告渠道分组，列按零售商分组”。

准备好后，选择 AIP 建议的选项之一来生成卡片并将其添加到画布中，您可以在画布上根据需要进行其他配置。

如果 AIP 认为该提示需要多个步骤，则 AIP Generate 会在选项标题旁包含一个 + 后续跟进 操作标签，您可以将光标悬停在其上以查看它将执行的生成卡片的额外步骤。

AIP Generate 会进入 Chain Of Thought 模式（当您选择包含 + 后续跟进 操作标签的选项时），使您能够根据初始提示查看其逻辑。它根据您的提示配置卡片后，AIP Generate 会自动输入其中包含的步骤 + 后续跟进 以及先前步骤的历史记录。

选择 AIP Generate 的选项之一以继续，或选择 重置 以返回原始输入提示。

选择 Tab 在 AIP Generate 的文本输入框中按键盘上的相应键，可将最近的提示加入队列，便于迭代。

此外，您可以选择并启动 AIP Generate （从画布顶部操作栏），使 AIP 能够更自主地行动，并在无需人工指导的情况下执行多步骤分析。

在查询框中输入您接下来想要执行的操作。AIP 会在您输入时建议提示补全。

准备好后，选择 生成.

要更仔细地查看每张卡片，您可以使用鼠标滚动手势在图表上放大和缩小并拖动图表，或者选择左下角的按钮。

将光标悬停在卡片上，可查看关于为何选择特定卡片以及如何根据相应提示配置这些卡片的有用说明。

要将生成的图表添加到分析画布，请选择 添加卡片。然后您可以进一步修改或最终确定每张卡片的配置或可视化。

AIP 如何使用本体论数据

为了高效回答用户提示，AIP 仅使用对象集数据的摘要版本，即“属性值提示”，如下所示：

  • 字符串属性类型：最多计算 100 个唯一值

  • 数值属性类型：计算最小值、最大值和平均值

这些摘要允许在进行定量描述（如高、低和中）时确定阈值，还可用于纠正列名和属性值的拼写错误。

配置卡片

您可以使用 AIP Configure 更新卡片配置。

要访问 AIP Configure，请选择 修改 按钮（位于 AIP Generate 输入栏中）。

接下来，输入您想要对卡片所做的更改的描述，例如“将图例移至底部并将样式更改为分组”或“将指标更改为销售额总和，并将 y 轴标题更新为总销售额”。在您输入时，AIP 会生成多个卡片配置建议。每个建议都会显示与提示中某一部分匹配的配置设置，您可以单独接受或拒绝这些建议。

准备好后，选择一个或多个 AIP 建议，AIP 会立即将其应用到卡片上。

如果您希望 AIP 进行其他配置，可以输入新的提示并重复该过程。

某些卡片，例如 Vega Plots，支持使用 AIP Configure 进行下游分析，但不支持 不 AIP Generate。

借助 AIP Configure，即使不熟悉每个 Quiver 卡片提供的所有可视化设置，每个人现在都可以获得完美的可视化效果。

时间序列

当用于分析 时间序列 图表时，AIP 会作用于绘图中的各个时间序列，而不是绘图容器。

在绘图中选择要分析的时间序列后，AIP Configure 会出现。
