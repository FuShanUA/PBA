探索相关时间序列

Vertex 图允许您与 时间序列 进行交互，以可视化整个系统中的变化，并深入分析，从而展示过去决策、当前状态和未来潜力的影响。

并非所有客户部署都包含时间序列。如果您想进一步了解这些功能，请联系您的 Palantir 代表。

查看相关时间序列： 选择对象后，您将在选择侧边栏的 “序列” 选项卡中看到相关时间序列。选择为您的对象显示的各个时间序列旁边的 ... 后，您将看到菜单中出现多个选项。

在序列视图中打开： 将时间序列添加到序列视图后，时间轴可视化将显示在图的底部。您可以使用序列视图在时间中移动：点击您希望查看的时间点，或使用序列面板底部的时间轴滚动浏览。

在 Quiver / Object Explorer 中打开： 选择 “在 Quiver 中打开” 或 “在 Object Explorer 中打开” 选项将打开一个新窗口，让您能够更详细地查看时间序列。

添加到扩展标签/读数： 这将在所选对象的标签上显示时间序列值。选择 添加到读数 可让您将时间序列值添加到图表中，而无需附加到对象标签，从而可以将这些值放置在系统或流程中最相关的位置。
