Iceberg 表上的标记

标记 限制对敏感数据的访问。Iceberg 表可以从上游输入继承标记，这与 Foundry 数据集类似。但是，Iceberg 快照可能导致标记对表访问的管控比对数据集更为严格。例如，在某个分支上添加的标记可能会影响对 main 以及其他分支的访问。仅删除添加了标记的分支，其本身并不足以将该标记从表中移除。

Iceberg 上的标记是表级别的

虽然标记直接与接收该标记的 Iceberg 快照相关联，但它对读取访问的影响实际上是全表范围的。这是因为 Iceberg 元数据文件涵盖了表中来自所有分支和标签的快照。要读取该元数据文件，用户通常必须满足其中包含的每个快照上的标记，除非 stop_propagating 已被应用。

实际上，用户必须满足表中任何快照上的所有标记才能读取该表。即使这些标记与用户并未直接尝试访问的分支或快照相关，情况也是如此。

移除继承的标记

请根据您是有意移除标记要求，还是移除过时的已标记历史记录，来选择相应的移除工作流。

选项 1：停止传播标记

当您有意从数据中移除标记要求时，请使用 stop_propagating 工作流 以获得移除继承标记的批准。

此方法对于增量管道和非增量管道都很有用。在增量情况下，这使您无需完全重建即可取消该表的标记。请注意，仅当目的是暴露已标记的数据时，才应使用停止传播。

选项 2：移除过时的已标记历史记录

已标记的快照在变得过时且不再属于当前血缘后，可能仍会保留在表历史中。若要在这种情况下从表中移除标记，请按照以下步骤操作：

  1. 确保已标记的快照不再被任何分支或标签引用。
    • 如果您的快照位于可以删除的分支上，您可以通过删除该分支来做到这一点。
    • 如果您的快照位于 main 或另一个不应删除的分支上，请确保分支头部具有不依赖于已标记快照的当前快照。实现此目的的一种方法是运行表替换操作，该操作会完全替换当前快照，且不将已标记的快照作为父快照。
  2. 使已标记的快照过期 （需在其不再被引用后执行），并确认目标快照不再显示在 快照 标签页中。

您必须能够访问已标记的表，并且能够执行 运行维护所需的操作 才能进行此清理。
