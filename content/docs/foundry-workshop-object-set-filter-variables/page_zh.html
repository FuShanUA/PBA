对象集筛选器变量

对象集筛选器变量 用于跟踪对象集的筛选状态,通常由诸如 Filter List、 XY Chart、 Vega Chart 或 Pivot Table 等组件输出。随后,可将对象集筛选器应用于对象集变量,或在组件配置中用于筛选对象集。

创建对象集筛选器变量

可以将对象集筛选器变量创建为空变量,然后在组件配置中使用,以捕获用户在组件中所做的选择。

还可以通过选择对象类型、属性类型以及这些属性类型的值,来指定筛选器的默认状态。这些值可以以内联方式指定,也可以指定为变量。

如果选择多个对象类型,建议基于所有对象类型共享的属性进行筛选。否则可能会导致意外行为,尤其是在从 Marketplace 部署模块时。

在指定属性后，如果您希望筛选器与对象类型无关，也可以移除指定的对象类型。请注意，除非至少指定了一个对象类型，否则您无法添加额外的属性筛选器，或为属性值选择变量。

支持的起始筛选器

对象集的初始状态也可以通过对象集筛选器变量来定义。目前，您可以通过以下方式对初始筛选器进行筛选或排除：

  • IS：这将返回属性值与筛选查询完全匹配的对象。
  • NULL：这将返回属性值为 null 的对象。
  • CONTAIN：这将返回属性包含筛选查询的对象。例如，如果属性值为 id000123 且筛选查询为 id0001，则视为匹配。此匹配行为目前仅限于前缀；目前不支持匹配字符串的任意部分。例如，如果属性值为 id000123 且筛选查询为 d0001，则不视为匹配。

筛选值提取

对于某些工作流，从对象集筛选器中提取特定的筛选值并在模块的其他位置使用可能会很有帮助。以下是一些可能有价值的示例用例：

  1. 您希望提取用户的筛选值，并将其从初始对象类型转换到具有不同数据模型的第二个对象类型。例如，如果用户最初在 Email Date 属性上进行筛选（该属性属于 Email 对象），而您希望转换该筛选条件，使其也适用于 Call Date 属性（该属性属于 Phone Call 对象）。
  2. 用户在 Filter List 小部件中筛选出给定的警报类型，而您希望将其选择的警报类型提取到字符串变量中，然后使用该变量来预填充一个 Create New Alert 操作。
  3. 用户已在 Exploration Search Bar 小部件中将筛选范围缩小到某些属性，而您希望使用 模块接口变量 提取其筛选状态并保存为动态 URL 参数，以便模块在重新加载时能够应用这些相同的所选内容。

为此，您可以使用变量来表示属性值，从而指定筛选变量的默认状态，并启用 在筛选值更改时更新所使用的变量。

当筛选器值更新为与默认筛选器结构相匹配的筛选器时，所配置的默认值中每个变量的值都将更新为从该筛选器中提取的值。

使用上面的筛选器，当在筛选器列表中选择每场得分的范围时，由这些提取变量支撑的数值输入将会更新。

只能提取以下值类型：

  • 数值范围
  • 日期/时间范围
  • 字符串词项
    • 应配置数组变量来提取多个值。如果配置的是非数组变量，则只会提取第一个筛选值。

将提取的值应用于另一个属性

提取会将值写入默认筛选器中所使用的变量；它本身并不会针对另一个属性生成筛选器。因此，上述第一个用例需要第二步，即在针对新属性的筛选器中复用所提取的变量：

  1. 在初始对象集筛选器变量上，针对源属性指定默认筛选器（Email Date 如上例所示）使用变量作为其值，并开启 在筛选器值更改时更新所使用的变量。当用户进行筛选时，提取的值会被写入这些变量。
  2. 在目标属性上配置第二个筛选器（Call Date 如上例所示），并使用相同的变量。可以将其配置为第二个对象集筛选器变量的默认状态，并将该变量应用于目标对象集，也可以直接在目标对象集变量上配置筛选器。

由于第二个筛选器从变量而非原始筛选器读取其值，因此它会将这些值应用于目标属性。对象集筛选器变量不能用作另一个筛选器中的值，因此提取的值必须通过受支持的基元变量或受支持的基元列表（如 Date、Timestamp、Numeric 或 String）才能在两个筛选器之间传递。

如果用户的筛选器不再包含源属性，则用于提取的变量将被清除。仅依赖这些变量获取值的筛选器随后会被丢弃，而不是匹配不到任何对象，因此依赖的对象集不再按目标属性进行筛选。

限制

筛选器值必须与默认筛选器的形状相匹配，才能进行提取。请查看一些可能出现此情况的已知情形：

  • 深度嵌套或不相交的范围筛选器（例如数据透视表或某些图表选择可能输出的筛选器）不支持提取，或者可能以意想不到的方式运行。
  • 当前筛选器值必须与对象集筛选器变量定义所提供的包含边界的小于等于 (LTE) 或大于等于 (GTE) 行为相匹配。
  • 取反的筛选器值还必须在筛选器变量的默认配置中进行取反。
  • 该 XY 图表组件 若带有数值轴，则目前不支持提取。
  • 提取会按属性将传入的筛选器与默认筛选器进行匹配，因此它只会更新两者中均存在的属性所对应的变量。仅靠提取本身不会针对不同的属性生成筛选器。
