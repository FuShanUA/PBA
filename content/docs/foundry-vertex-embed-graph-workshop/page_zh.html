在 Workshop 模块中嵌入图

图、图模板和图示均可嵌入 Workshop 模块，让用户能够在 Workshop 工作流中直接与 Vertex 可视化交互。通过这种集成，强大的数据探索和可视化体验得以成为更大型 Workshop 模块的一部分。

可以直接将 Workshop 变量的值作为参数传递给图模板，从而实现根据用户交互或工作流状态动态更新的数据驱动型可视化体验。

在 Workshop 模块中嵌入模板有三个主要步骤：

  1. 在 Workshop 中添加 Vertex 图小部件
  2. 选择资源
  3. 配置小部件

在 Workshop 中添加 Vertex 图小部件

在 Workshop 模块中您选择的任意部分，点击 + 图标或 +Add widget 按钮以打开小部件菜单，然后搜索 Vertex Graph 小部件。

选择资源

在小部件编辑器中，通过点击 Select来选择要嵌入的图、图模板或图示资源。只有兼容的资源才会显示在资源选择器中。

配置小部件

对于 Vertex 图 小部件，其配置按多个部分进行组织。每个部分分别控制小部件行为和外观的不同方面。

输入

输入 部分控制所显示的图或模板及其接收数据的方式。

  • 资源
    • 静态： 选择此资源模式时，将使用资源选择器选择单个输入资源。该资源可以是图、图模板或图示。
    • 变量： 选择此资源模式时，输入资源由一个字符串变量提供，该变量应包含图、图指针或图模板的 RID。
    • 覆盖图 RID： （可选）如果所选资源是图模板，您可以提供一个用于显示的图 RID，而不是使用模板及其参数生成图。这样便可以从保存在对象属性中的 RID 加载现有图。请参阅 保存和共享图探索 部分以了解详情。
  • 参数
    • 嵌入图模板时，可以使用 Workshop 变量为模板参数提供值。模板中定义的每个参数都将显示在此处以供配置。
    • 对于对象类型参数，请从 Workshop 中选择一个对象集变量。
    • 对于非对象参数，请根据参数类型提供适当的值。
  • 子图
    • 嵌入包含多个子图的现有图或图表资源时，您可以通过从 Workshop 中选择包含该子图中任意对象的对象集变量，来选择要显示的子图。
  • 刷新键
    • 每当该变量的值发生变化时，小部件都会对图进行完整重新加载。这对于根据工作流状态变化触发刷新非常有用。
  • 参数更改时追加
    • 启用后，更改参数时将新对象追加到现有图中，而不是从头开始重新生成图。
  • 场景
    • 从场景加载数据： 启用此开关后，将使用场景而非基础本体论来加载给定资源。
    • 应用场景后重新生成图： 设置后，每次修改场景时都会刷新图。

以前，模板输入是通过一个包含图模板中定义的所有必需对象类型的单一输入对象集变量来提供的。现在不建议这样做，因为它仅适用于没有非对象参数且每个对象类型只有一个对象参数的模板。如果您希望使用此功能，请选择 使用旧版输入对象集 复选框，并提供一个对象集变量。

交互

该 交互 部分配置用户如何与图进行交互，以及图如何与其他 Workshop 组件进行交互。

  • 所选对象
    • 此选项输出当前所选对象的对象集。随后可以在当前模块内的下游小组件中使用此对象集。
    • 当用户在图中选择对象时，此变量将自动填充所选内容。
  • 所选对象更改时
    • 配置在图中所选对象发生更改时触发的 Workshop 事件。
    • 这可用于打开抽屉以查看所选对象的更详细视图、触发另一个小组件的刷新，或执行任何其他 Workshop 事件操作。
  • 成功应用操作时
    • 配置在用户于图中成功应用操作时触发的 Workshop 事件。
    • 此事件在底层操作成功执行后触发。
  • 缩放至对象集
    • 每当输入发生更改时，都会将视口设置为显示给定对象集中的对象。
    • 这允许您以编程方式使图聚焦于特定对象。
  • 子图上的对象
    • 输出包含当前所选子图上所有对象的对象集。
    • 这对于捕获当前视图上可见的所有对象以供在其他小组件中使用非常有用。
  • 将对象添加到子图
    • 将给定的对象添加到当前选定的子图。
    • 这允许您通过编程方式从其他小部件将对象添加到图中。
  • 可用操作
    • 控制用户在图界面中可直接使用的操作。
    • 选项包括：
      • 全部： 图中任何对象上的所有操作均可用。
      • 部分： 仅明确选定的操作可用。
      • 无： 没有可用的操作。

时间配置

时间配置 部分控制时间在图中的表示方式和交互方式。

  • 选定时间
    • 控制图上的选定时间。
    • 选定时间决定了图中或选择面板中所显示时态数据的读数。
    • 只有当时间轴、时间选择面板或系列面板之一处于启用状态时，才能选择时间。
    • 选定时间默认为图加载时的时间。
    • 选项：
      • 默认： 时间选择不通过变量进行同步。
      • 时间戳变量： 将图的可视化效果与 Workshop 变量同步，该变量的类型为 Timestamp。
      • 日期变量： 将图的可视化效果与 Workshop 变量同步，该变量的类型为 Date。
  • 时间窗口
    • 控制图上使用的时间窗口。时间窗口决定了任何时态图表上显示的数据范围。
    • 只有当启用了时间线、时间选择面板或序列面板之一时,才能选择时间窗口。
    • 默认时间窗口在控制面板中配置。
    • 选项:
      • 默认: 时间窗口未与变量同步。
      • 时间戳: 使用两个 Workshop 变量定义时间窗口,变量类型为 Timestamp。
        • 开始: 时间窗口的开始。
        • 结束: 时间窗口的结束。
      • 日期: 使用两个 Workshop 变量定义时间窗口,变量类型为 Date。
        • 开始: 时间窗口的开始。
        • 结束: 时间窗口的结束。

功能

该 功能 部分控制小部件用户可用的功能特性。

  • 只读模式
    • 启用后,此设置将移除编辑功能并隐藏编辑工具栏。
    • 这对于创建仅供查看的可视化非常有用,适用于用户不应能够修改图的场景。
  • 启用切换到 Vertex 应用
    • 启用后,会显示一个按钮,允许用户在保留当前图状态的情况下打开 Vertex 应用。
    • 这提供了从 Workshop 中嵌入的图到完整的 Vertex 应用的无缝过渡,以便执行更高级的操作。
  • 启用导出为 PNG
    • 启用后，允许用户将当前图表导出为 PNG 图像。
    • 用户需要拥有对嵌入资源的前端导出权限才能使用此功能。
  • 保存设置
    • 控制用户是否可以保存当前图表状态。
    • 选项：
      • 禁用： 用户无法保存图表。
      • 启用： 用户可以保存图表，并可进行其他配置：
        • 默认资源名称： 指定新保存图表的名称。
          • 静态： 使用固定的文本字符串作为名称。
          • 变量： 使用 Workshop 字符串变量作为名称。
        • 默认文件夹： 指定新保存图表的存储位置。
          • 文件夹引用： 选择特定文件夹。
          • 静态 RID： 使用特定的文件夹 RID。
          • 变量： 使用包含文件夹 RID 或路径的 Workshop 变量。
        • 创建新图表时： 配置图表保存时执行的操作。
          • 事件： 保存图表时触发 Workshop 事件。
          • 操作： 保存图表时执行 Foundry 操作。
            • 已保存图表的 RID、已保存图表的名称以及当前用户的 ID 可作为该操作的特殊输入。
            • 所有必需参数都必须配置默认值。
        • 显示保存对话框： 控制保存时是否显示资源对话框。
          • 无： 不显示对话框；使用默认名称和位置保存资源。
          • 资源对话框： 系统会提示用户选择名称和位置。
        • 另存为版本化图： 启用后，即使图之前未版本化，也会将其保存为版本化图。版本化图支持自动保存和版本历史记录。

界面

该 界面 部分控制小部件用户可见的 UI 元素和面板。

  • 图例/对象面板
    • 启用后，此开关将显示左侧面板，其中包含图层、选择、搜索、直方图和信息面板（在下方启用时显示）。
  • 系列面板
    • 启用后，此开关将在小部件底部显示系列面板。
    • 系列面板显示与所选对象相关的时间序列数据。
  • 时间选择面板
    • 启用后，此开关将在小部件右上角显示时间滑动条。
    • 此面板允许用户与时间数据交互并选择特定时间点。
  • 启用时间轴
    • 启用后，此开关将显示数据的时间轴视图。
    • 这提供了按时间顺序排列的事件和数据点视图。
  • 时间轴是否打开
    • 控制首次加载模块时时间轴是打开还是关闭。
  • 启用图层面板
    • 启用后，此开关允许显示图层面板。
    • 图层面板提供用于切换不同数据图层可见性的控件。
  • 启用选择面板
    • 启用后，此开关允许显示选择面板。
    • 选择面板显示当前所选对象的详细信息。
  • 启用搜索面板
    • 启用后，此开关允许显示搜索面板。
    • 搜索面板提供在图中查找对象的功能。
  • 启用直方图面板
    • 启用后，此开关允许显示直方图面板。
    • 直方图面板显示图中对象属性值的分布情况。
  • 启用信息面板
    • 启用后，此开关允许显示信息面板。
    • 信息面板提供有关图的高级概览元数据，包括其图层的图例。
  • 启用版本历史面板
    • 启用后，此开关允许显示版本历史面板。
    • 版本历史面板显示已版本化图的先前版本。
  • 启用添加对象
    • 启用后，此开关允许用户向图中添加新对象。
  • 图例/对象面板是否折叠
    • 控制在首次加载模块时图例/对象面板处于折叠还是展开状态。
    • 这有助于管理小部件中的初始可视空间分配。
  • 启用子图导航菜单
    • 启用后,此开关允许用户在子图之间导航并创建新的子图。
    • 如果图包含多个子图,则无论此设置如何,导航菜单都会始终显示。
  • 输入不完整消息
    • 当图模板因缺少必需输入而无法运行时,会在对话框中向用户显示此消息。
    • 使用此字段可自定义在未提供必需模板参数时向用户显示的消息。

模式

图模板参数化

嵌入图模板时,可以使用 Workshop 变量对其进行参数化。这样您就可以创建根据用户输入或工作流中的其他数据动态更新的可视化效果。

保存并共享图探索

一种常见的模式是设置一个图模板，用户可将其应用于某个初始对象，然后保存当前的探索内容，以便日后继续探索。 这样，用户便可以从模板化的工作流开始，进行一些额外的调查，并捕获在与图交互过程中发现的有趣见解或关系。 随后，保存的图可以作为引用添加到对象中，从而便于与他人共享或日后再次查看。

要实现此模式，请按照以下步骤操作：

  1. 为对象类型添加一个属性 ，用于存放已保存的图的 RID。
    • 此属性必须是一个字符串，其 值格式化 使用 资源 RID 选项。
    • 此属性必须具有一个关联的 操作 ，用于设置该值，并在将图保存为资源后使用。
    • 此对象通常就是作为参数传递给图模板的同一个对象，但也可以是单独的特定对象类型，专门用于存放已保存的图，且通常与被探索的对象相关联。
  2. 创建一个图模板 ，并将其配置为执行初始探索。
  3. 将图模板嵌入 Workshop 模块中 ，使用 Vertex 图小部件。
    1. 要选择图模板，请在 资源 部分中使用 静态 选项。
    2. 为模板配置任意参数。
    3. 使用 “覆盖图 RID” 选项来指定包含已保存图 RID 的对象属性。
      • 该对象可以与传递给模板的对象相同；如果图是在关联对象上引用的，也可以使用通过搜索关联获得的 Workshop 变量或单独的已保存图列表来发现该对象。
  4. 在挂件配置中启用保存设置 ，以允许用户保存其当前图状态。
    • 使用 “创建新图时” 选项来运行将属性值设置为已保存图 RID 的操作。
    • 配置操作参数时，请务必将特殊的 “已保存图 RID” 值传递给相应的参数。

按照此模式，当用户选择保存图标时，当前图状态将保存为资源，并且对象上的属性将更新为已保存图的 RID。当用户再次访问该对象时，已保存的图将使用 “覆盖图 RID” 选项加载。
