代码查看器

代码查看器是 Code Workspaces 中的一个只读界面，用于浏览、比较和共享仓库的已提交状态。可将其作为统一的参考，用于在 Foundry 编辑器、本地开发环境或 AI 辅助工作流中开发的代码。

代码查看器显示仓库中存储的已提交状态。编辑器中的更改只有在提交并同步后才会显示。它与 VS Code、JupyterLab® 和 RStudio® Workbench 一并提供。无需创建或启动编辑器工作区，即可使用代码查看器。

浏览代码

要打开代码查看器：

  1. 打开 Code Workspaces。
  2. 打开一个仓库。
  3. 选择页面页眉中的 代码查看器 标签页。

使用代码查看器可以：

  • 浏览分支、标签或提交上的文件。
  • 按文件名搜索，或在文件内容中搜索。
  • 以渲染后的文档或源代码形式查看受支持的文件，包括 Markdown 文件和 Jupyter® 笔记本。
  • 在函数仓库中预览已发布的函数。

比较更改

要比较仓库历史记录中的两个点：

  1. 选择 比较更改。
  2. 为比较的每一侧选择一个分支，然后选择一个提交或标签。
  3. 选择已更改的文件以查看并排差异。

共享代码

指向分支的链接会随着分支的推进而变化。要共享指向确切提交和行范围的稳定引用：

  1. 选择某个行号。要选择一个范围，请跨行号拖动或按住 Shift 的同时选择另一行。
  2. 打开 行操作 菜单（位于选区旁边）。
  3. 选择 复制永久链接。

在编辑器中继续

要进行更改，请选择相应编辑器的标签页，例如 VS Code， Jupyter，或 RStudio。

默认情况下，当您打开 已停止的 VS Code 工作区时，代码查看器会打开，而其工作区会话会在后台启动。 VS Code 标签页图标会显示工作区状态。工作区就绪后，代码查看器会保持打开状态，因此请选择 VS Code 以继续编辑。

要禁用此行为，请选择 设置 > 首选项，然后取消勾选 工作区加载时打开代码查看器。
