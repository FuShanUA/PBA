TypeScript v1 函数中的语言模型

本页面介绍 TypeScript v1 函数。有关 TypeScript v2 或 Python 的信息，请参阅 TypeScript v2 和 Python 函数中的语言模型。要使用本体论 SDK 和可配置的资源请求， 请迁移到 TypeScript v2。

Palantir 提供了一组可在函数中使用的语言模型。 详细了解 Palantir 提供的 LLM。

前提条件

要使用 Palantir 提供的语言模型， 必须先在您的部署环境中启用 AIP。您还必须拥有相应权限才能使用 AIP builder 功能。

导入语言模型

要开始使用语言模型，您必须按照以下步骤将特定模型导入到您编写函数的代码仓库中：

  1. 导航并打开 模型导入 侧面板，以查看所有已导入的模型。
  1. 要导入新的语言模型，请选择 添加 按钮（位于 资源导入 面板右上角），然后选择 模型。这将打开一个新窗口，您可以在其中查看可供您使用的 Palantir 提供的模型。

  1. 您还将看到一个标签页，您可以在其中查看之前通过 Modeling Objectives 应用程序或直接模型部署创建的自定义模型。有关使用这些模型的更多信息，请参阅 模型上的函数 文档。

  2. 选择您想要导入的模型，然后选择 确认选择 以将这些模型导入您的仓库。任务运行器将执行 localDev 任务，生成用于与这些模型交互的代码绑定。

  3. 导入语言模型后，在侧边栏中选择模型，即可查看该模型提供的详细功能。您还可以复制代码片段，以帮助您导入模型并编写使用该模型的函数。

编写使用语言模型的函数

至此，您现在可以编写使用已导入语言模型的函数。在本示例中，假设您导入的是 GPT-4.1。

首先，将以下导入语句添加到您的文件中：

import { Function, Uses } from "@foundry/functions-api";
import { Gpt41 } from "@foundry/languagemodelservice/models";

每个语言模型都将提供具有强类型输入和输出的生成方法。例如，GPT-4.1 模型提供 createChatCompletion、 createChatVisionCompletion和 createChatCompletionStreamed 等不同的 API，可用于与模型进行交互。在导入模型的后续版本中，功能列表可能会扩展。

Foundry 必须知道您从已发布的函数中调用了哪些模型方法。静态分析会自动检测大多数调用；静态分析遗漏的调用会导致运行时错误，提示您添加 @Uses 装饰器，该装饰器可补充自动检测到的使用情况。请在装饰器的 queries 键下声明模型方法，如下方示例和模型详情面板中的代码片段所示。

在以下示例中，将使用提供的 GPT-4.1 模型对用户提供的一段文本或图像执行简单的情感分析。该函数会将文本分类为"Good"、"Bad"或"Uncertain"。

const SYSTEM_PROMPT =
    "Provide an estimation of the sentiment the text the user has provided. \
You may respond with either Good, Bad, or Uncertain. Only choose Good or Bad if you are overwhelmingly \
sure that the text is either good or bad. If the text is neutral, or you are unable to determine, choose Uncertain.";

export class MyFunctions {
    @Function()
    @Uses({ queries: [Gpt41.createChatCompletion] })
    public async llmFunction_createChatCompletion(userPrompt: string): Promise<string | undefined> {
        const response = await Gpt41.createChatCompletion({
            messages: [
                {
                    role: "SYSTEM",
                    content: SYSTEM_PROMPT,
                },
                {
                    role: "USER",
                    content: userPrompt,
                },
            ],
            params: {
                temperature: 0,
            },
        });
        return response.type === "ok" ? response.value.completion : "error";
    }

    @Function()
    @Uses({ queries: [Gpt41.createChatVisionCompletion] })
    public async llmFunction_createChatVisionCompletion(
        userPrompt: string,
        pngBase64String: string,
    ): Promise<string | undefined> {
        const response = await Gpt41.createChatVisionCompletion({
            messages: [
                {
                    role: "USER",
                    content: [
                        { type: "text", text: userPrompt },
                        {
                            type: "genericMedia",
                            genericMedia: {
                                mimeType: "IMAGE_PNG",
                                // Base64 encoded PNG String
                                content: pngBase64String,
                            },
                        },
                    ],
                },
            ],
            params: {
                temperature: 0,
            },
        });
        return response.type === "ok" ? response.value.completion : "error";
    }
}

此后，该函数便可在整个平台中使用。

该 @Uses 装饰器 也适用于导入的模型。请将这些调用声明于 queries，例如 @Uses({ queries: [Gpt41.createChatCompletion] })。

@Function()
@Uses({ queries: [Textembedding3large.createEmbeddings] })
public async llmFunction_embeddings(inputs: string[]): Promise<Double[][]> {
    const response = await Textembedding3large.createEmbeddings({ inputs });
    return response.type === "ok" ? response.value.embeddings : [[]];
}

此功能最常用于执行 语义搜索 工作流。

在函数中从旧版语言模型升级

函数中更新的语言模型提供了更高级的功能，例如更好地支持视觉和流式传输。我们强烈建议您升级仓库，以充分利用最新的 AIP 产品。如果您是从一个没有 旧版语言模型 导入的新仓库开始，则可以跳过以下步骤。

以下过程将导致您的代码仓库出现编译时中断，因为代码语法将会更新。请参阅侧边栏中每个已更新模型的代码片段来更新您的代码。

  1. 如果您已有 旧版语言模型 导入，侧边栏中将显示升级警告图标。请选择 选择导入 以打开模型导入对话框。
  1. 在模型导入对话框中，选择 修复 以移除所有已弃用的旧版语言模型。
  1. 重新选择要迁移到更新后的语言模型版本的模型。您可以在对话框中央的详细信息面板中查看此版本支持的其他功能。
  1. 现在，您可以在侧边栏中查看更新后的模型导入。选择某个模型将显示包含代码片段的详细信息面板，帮助您更新代码以利用这些额外功能。

性能注意事项

某些模型可能会应用速率限制，限制在特定时间段内可传递的令牌数量。该限制将与适用于函数的任何标准限制一起强制执行。

注意：AIP 功能的可用性可能随时变化，且可能因客户而异。
