命令

使用 命令 小部件将内联 命令 嵌入到 Notepad 文档中。选择 + 小部件 或 / 在段落字段中输入以添加命令，使您能够从 Notepad 执行其他 Palantir 应用程序中的操作。 命令 小部件与 应用配对 协同工作，以连接应用程序状态，并在整个 Palantir 平台中实现跨应用程序工作流。

小部件属性

  • 命令： 选择要执行的命令。点击 浏览所有命令... 即可打开一个模态窗口，其中包含各个 Palantir 应用程序中的所有可用命令及其支持文档。
  • 参数： 如有必要，请配置该命令的可选参数和必需参数。例如，您可以选择性地配置映射到对象属性值的参数。
  • 显示： 为文档中显示的小部件自定义图标和/或文本标签。

示例：使用配对的 Gaia 地图构建简报工作流

要执行以下工作流，您的注册环境必须同时使用 Foundry 和 Gotham。如对 Gotham 在您注册环境中的可用性有疑问，请联系 Palantir 支持团队。

请先创建一个新的 Notepad 文档，并在另一个浏览器标签页中打开您的 Gaia 地图，然后按照以下说明将两者配对，并使用 命令 小部件的 Select clip 命令来构建简报工作流。

  1. 选择右上角功能区中的 App Pairing 图标，将您的 Notepad 文档与 Gaia 地图配对。
  2. 将 Command 小部件插入到您的 Notepad 文档中，方法是按下 / 并选择 Insert。

  1. 选择 Gaia > Clips > Select clip ，该选项位于配置面板的 Add Command 下拉菜单中。
  2. 选择 Add an optional parameter... ，然后选择 Clip GID。
  3. 从 Select from paired apps 菜单中选择 Gaia 地图上的现有剪辑。

  1. 选择 Icon 并设置 Text ，该文本将显示在 Notepad 文档中的图标旁边。

配置好 Select clip 后，您可以将 Notepad 文档与 Gaia 地图并排放置，然后点击您设置的图标，即可在 Gaia 中打开该剪辑。
