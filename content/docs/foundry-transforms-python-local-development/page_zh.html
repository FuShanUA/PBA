设置 Python 本地开发

可以对 Python transforms 仓库进行本地开发，从而实现高速迭代开发。

在本地使用您的 Python transforms 仓库

在您的 Python transforms 仓库中进行本地开发有两种选择：

  • 选项 1： 使用适用于 Visual Studio Code 的 Palantir 扩展 [推荐]
  • 选项 2： 克隆仓库

选项 1：使用适用于 Visual Studio Code 的 Palantir 扩展 [推荐]

要启用适用于 Visual Studio Code 的 Palantir 扩展和本地预览功能，请联系您的平台管理员修改 Code Repositories 设置 （位于 Control Panel 中）。该扩展 默认启用 当使用 VS Code 工作区.

前提条件

  • 请确保您已安装 Visual Studio Code ↗ installed.
  • 下载 Palantir 扩展 （适用于 Visual Studio Code，前提是该扩展已在您的环境中启用）。

优势

  • 预览您的 Python transforms 直接在本地 Visual Studio Code 环境中进行。适用于 Visual Studio Code 的 Palantir 扩展支持完整数据集（无采样预览），因此您可以在不损失精度的情况下预览完整数据集。要在本地运行预览，您需要平台管理员通过 Control Panel 启用本地预览。
  • 发起构建 直接在您自己的代码编辑器中完成。
  • 调试您的代码 并直接在编辑器中运行测试。
  • 利用 库面板 来添加库。

故障排除

如果您遇到意外的语言服务器错误（例如导入失效），可能是 Python 解释器的自动设置失败了。要解决此问题，您可以通过导航到 命令面板 ↗，然后输入 Python: Select interpreter 并选择与路径匹配的 Python 解释器来手动设置解释器 .maestro/bin/python。该 .maestro 如果 Palantir 扩展成功运行了 Palantir: Install Python environment 命令。

选项 2：克隆仓库

前提条件

  • 请按照以下步骤确保您的仓库已升级到最新模板版本 此处.
  • 请确保环境变量 CI, JEMMA日 CA 未被设置。
  • 如果在 Apple 芯片 Mac 上运行，请确保已安装 Rosetta 2 ↗ 。您可以通过运行以下命令来安装 Rosetta 2 /usr/sbin/softwareupdate --install-rosetta --agree-to-license 在终端中。

在本地克隆仓库

  1. 在仓库的菜单栏中，选择右侧的桌面图标 数据血缘 以打开对话框并复制给定的仓库 URL。

  1. 使用命令行，运行 git clone <URL> 在您的本地机器上，选择您喜欢的目录。然后，使用 cd 命令导航到该仓库。

局限性

  • 克隆所授予的令牌有效期较短，需要每 7 天刷新一次。
  • 您仍需将更改推送到 Foundry 才能发布作业规范或构建产物，或者如果您希望运行检查或构建。

预览

本地开发支持数据集预览。请参阅 本地预览 以了解更多详情。
