查看审计日志详情

日志详情面板显示单条审计日志：谁执行了该操作、哪个服务处理了它、他们请求了什么以及结果如何。在可能的情况下，Audit Explorer 会显示可读的名称而非原始标识符，并对常见事件进行汇总，因此您无需阅读嵌套的 JSON 即可查看日志。

所有屏幕截图均使用虚构数据。

打开日志详情

在 日志 搜索标签页的表格中选择一行，即可在右侧面板中打开该日志。选择行中的链接、按钮或菜单不会打开该面板。了解更多关于 该 日志 table.

媒体 Up Arrow or Down Arrow 的信息，可在已加载的日志之间切换。要关闭面板，请选择面板标题栏中的 X 图标或按 Cmd+M （macOS）或 Ctrl+M （Windows）。当面板关闭时，相同的快捷键会打开表格中可见的第一条日志。

面板标题栏显示事件类型（如 事件类型 列中所示）以及时间。右键单击事件名称可对其进行筛选或转到新的搜索。右键单击时间可将搜索时间范围缩放到其前后的一段时间窗口，或将其复制。

更多亮点

直方图 概述 标签页显示摘要卡片、 申请 和 结果 卡片以及其余列。

摘要卡片

摘要卡片显示谁执行了该操作、在哪里运行以及结果如何。只有当审计表格包含相应的列时，才会显示对应字段。

  • 用户： 用户的全名，带有指向其个人资料的链接。
  • 组织： 用户所属组织的显示名称。
  • 生产者： SERVER 如果日志由服务端代码生成，或 CLIENT 如果日志由客户端代码生成。
  • stack 字段： 生成日志的环境，如 audit.3 模式.
  • 服务： 生成日志的服务，后跟产品版本（如果日志中包含）。
  • 结果： 事件的结果，例如 SUCCESS, ERROR，或 UNAUTHORIZED.

将鼠标悬停在名称上可查看其存储的值（例如用户 ID），然后选择 复制到剪贴板 将其复制。右键单击 用户, 配置, Service，或 stack 值可对其进行筛选、转到新的搜索，或按显示原样复制名称。了解更多关于 单元格操作.

请求和结果卡片

直方图 申请 卡片显示日志的 requestFields，即事件开始时已知的参数。 结果 卡片显示其 resultFields，即事件产生的信息。它们的内容取决于事件的 审计日志类别。有关字段定义，请查阅 audit.3 schema 参考.

每个卡片都显示带有可读标签和资源名称的解析视图。要查看原始 JSON，请选择 显示原始 JSON （卡片标题栏中的代码图标）。 申请 和 结果 卡片中的值没有右键单击筛选选项。对于常见类型的事件，卡片会显示 事件摘要 而不是相应的原始字段。

其余列

在 结果 卡片下方， 概述 标签页会列出审计表格中不属于标准 audit.3 schema 的任何列。标准 audit.3 导出没有额外的列，因此只有当您的审计表格包含其他列时才会显示此列表。只有当额外列在 日志 按钮旁的下拉菜单中访问。

面板不会显示 Categories, 选项卡中一次为多个, 用户, Origins, 环境, 乘积，或 Sequence ID 列或 productId 和 date 字段。要查看这些值，请将相应列添加到 日志 按钮旁的下拉菜单中访问。

高级标签页

直方图 高级 标签页显示有助于您查找相关日志并详细调查事件的标识符：

  • 会话 ID： 会话的 ID（如果日志中包含）。
  • 令牌 ID： API 令牌的 ID（如果日志中包含）。
  • 事件 ID： 可审计事件的标识符。一个事件可以生成多条共享同一事件 ID 的日志。
  • 日志条目 ID： 此日志的唯一标识符。
  • 追踪 ID： 请求的追踪 ID，用于查找来自其他服务的相关日志。
  • 原点： 发起机器尽力而为的标识符，例如 IP 地址。
  • 来源源站: 由网络连接确定的网络请求来源。
  • 主机: 生成日志的服务器。
  • 用户代理: 发送请求的浏览器或客户端软件。

客户端可以伪造 Origin 值,使其显示为发送请求的机器以外的其他机器。请勿将 Origin 视为请求来源的证明。 Origin 和 来源源站 可能包含 IP 地址,而 IP 地址属于个人身份信息 (PII)。

选择 复制到剪贴板 以复制某个值,或右键单击某个值以对其进行筛选。要查看共享同一会话 ID 的所有日志,请使用 会话浏览器标签页.

会话标签页

如果审计表包含 checkpoint_interaction_rid 列(标准 audit.3 架构中不包含该列),则会显示 会话 标签页,紧邻 高级 标签页。该标签页显示事件所引用的 检查点 交互,包括已存档的项目以及用户给出的理由。要在 Checkpoints 中打开该交互,请选择 在 Checkpoints 应用中查看。如果该标签页显示的是一条消息,请查看 检查点理由.

事件摘要

对于某些类型的事件, 申请 和 结果 卡片会显示可读的摘要,而不是其涵盖的字段。摘要可能会省略某些细节。要查看每个字段的原始记录内容,请选择 显示原始 JSON。要展开摘要中缩短的列表,请选择 全部显示 N.

操作日志

当日志记录了已应用的本体论操作且该操作类型写入 操作日志、一个 操作日志 卡片显示在 申请 卡片上方,并显示以下内容:

  • 操作类型,链接到 Ontology Manager
  • 操作日志的摘要文本(如果有)
  • A 参数 组,包含记录的值
  • An 编辑 组,包含已编辑的对象,链接到 Object Explorer

要在 Object Explorer 中打开操作日志对象,请选择共享图标。如果您无法查看操作类型或其操作日志对象,或者操作日志对象没有记录的值,则不会显示该卡片。

本体论搜索和加载

对于本体论对象搜索和加载,卡片会显示以下内容:

  • 搜索的对象类型,链接到 Ontology Manager
  • 搜索查询,包含查询文本、匹配类型和搜索的属性
  • 属性筛选器,包含每个筛选器的属性、运算符和值
  • 请求的对象, 加载的对象日 返回的对象,按对象类型分组并链接到 Object Explorer
  • 加载的属性

函数执行

对于函数执行,卡片会显示 已执行的函数 及其版本、传递给它的 参数 及其 返回值。如果解析的版本与请求的版本不同,则会同时显示两个版本。

审计日志搜索

Audit Explorer 会记录用户运行的每次搜索 。要查找这些日志,请选择 提交 Audit Explorer 查询 菜单中选择 选择事件类型 对话框,或按事件名称筛选 AUDIT_EXPLORER.QUERY_SUBMIT。这些日志显示为 提交 Audit Explorer 查询 菜单中选择 事件类型 列公开变更数据源中的相关行。 申请 卡片会显示用户搜索的内容:

  • 时间范围： 搜索的时间范围。对于相对范围，例如 过去 24 小时，摘要还会显示其覆盖的时间窗口。
  • 查询筛选器： 搜索的筛选器，以只读筛选器标签的形式显示。

直方图 结果 卡片显示用户所搜索的审计表。

作为隐私最佳实践，请定期审查审计数据的搜索记录。审计日志可能包含 PII，因此访问这些日志的人员应保持可问责性。请查看 实践中的隐私与公民自由 以了解有关可问责监督的指导。

如果搜索内容过长而无法完整记录，摘要会注明某些筛选器或值缺失。搜索日志只有在审计导出将其添加到您的审计表后才会显示。请查看如何 检查数据新鲜度.

群组成员变更

对于群组成员变更，卡片会显示发生变更的 组 ，随后是 新增 N 成员 和 已移除 N 成员 列表。

名称解析与原始值

在整个面板中，Audit Explorer 会根据您自身权限允许查看的内容，将标识符替换为可读名称。您无法查看的对象、对象类型、操作类型和函数会显示为原始标识符。您无法查看或已不存在的其他资源会显示为锁形图标和工具提示 No permissions to view type.

摘要卡片和其余列遵循 日志 表中的列格式。如果您选择 显示原始值 （在列标题菜单中），匹配的面板字段也会显示原始值。 申请 和 结果 卡片使用其自身的 显示原始 JSON 选项。了解更多关于 列选项的信息.
