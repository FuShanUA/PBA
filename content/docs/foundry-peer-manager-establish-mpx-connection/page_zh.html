建立 Multipass exchanger 连接

Multipass exchanger (MPX) 连接使 注册管理员 能够在两个注册之间跨网络建立安全通信通道，作为 创建对等连接的前提。在建立 MPX 连接之前，请联系 Palantir Support 协助配置您要连接的 注册 之间所需的网络设置，包括防火墙规则、证书信任以及注册之间进行通信所需的任何其他网络配置。

以下各节中的说明概述了 注册管理员 在 每个 注册上为建立连接而必须执行的操作，例如生成邀请码、与另一位 注册管理员共享该邀请码，并将邀请码粘贴到 Peer Manager 的 “网络连接” 选项卡中。

当两个注册之间存在可用的网络连接时，请使用 MPX 连接。如果没有可用的网络连接， 请建立数据中继连接 作为 MPX 连接的替代方案。数据中继连接通过注册现有的跨域解决方案建立对等连接。

协调连接方向

在通过选择 “新建 MPX 邀请” （位于 “网络连接” 标签页（Peer Manager）中，请与对方注册实例的管理员协调，以便双方在生成各自的邀请码时选择相互匹配的方向：

  • 双向连接：要创建一个网络流量双向传输的连接， 双方 管理员均选择 双向。
  • 单向连接，从 Enrollment A 到 Enrollment B： 要创建一个单向连接，其中 Enrollment A 发起网络请求至 Enrollment B：
    • 位于 Enrollment A 上的管理员选择 仅出口。
    • 位于 Enrollment B 上的管理员选择 仅入口。

创建新的 MPX 邀请码

在您与对方 注册实例管理员共同确定连接方向后，请从 新建 MPX 邀请 下方列出的选项中进行选择，以生成可共享的邀请码：

  • 双向：两个系统均可相互发起网络请求。如果两个注册实例都具有稳定的 IP，请使用此选项。
  • 仅出口：只有您的注册实例会发起网络请求。如果您的系统没有稳定的 IP，请选择此选项。
  • 仅入口：只有远程注册实例会发起网络请求。如果远程注册实例没有稳定的 IP，请选择此选项。

选择方向后，Peer Manager 会显示 新建 MPX 邀请 对话框，您可以在其中复制邀请码，分享给对方 注册管理员。

输入 MPX 邀请码

从对方注册的 注册管理员 处收到邀请码后，请按照以下步骤在您的注册中输入该代码并完成您这一端的连接：

  1. 选择 输入代码 （位于 新建 MPX 邀请旁边）。
  2. 将邀请码粘贴到 输入 MPX 邀请码 对话框中。Peer Manager 会验证该代码，并引导您进入 MPX 连接创建页面。
  3. 提供一个 名称 ，用于该 MPX 连接。
  4. 确认 网络出口策略 已在您的注册中配置，如 “开始之前” 部分所述。
  5. 选择 创建连接。

两位管理员都必须 创建自己的邀请码 ，并 输入对方注册的 MPX 邀请码。在两个注册上均建立 MPX 连接后，您可以返回 Peer Manager 来 创建对等连接 （使用该 MPX 连接）。
