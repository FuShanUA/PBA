当前支持的功能

您可以从 公共应用程序中调用有限的一组本体论操作。虽然当前支持的操作集特意保持在较小范围内，但随着更广泛的可观测性和速率限制控制功能的发布，所支持的操作列表将会不断扩展。

支持的操作

以下本体论操作可以从公共应用程序调用：

操作描述限制
获取本体论完整元数据检索本体论的完整元数据，包括对象类型、关联类型、操作类型、查询和接口。无。
加载本体论元数据检索请求体中指定的本体论特定子集的元数据。无。
应用操作使用提供的参数应用操作，并将结果写入本体论。函数支撑的操作被阻止。既不支持批量操作的应用，也不支持 webhook。
加载对象集从提供的对象集定义加载本体论对象。支持加载多个对象、按主键加载单个对象以及加载关联对象。SearchAround、 FilteredObjectSets，以及 orderBy 子句不受支持。

当前不支持

以下功能明确 无法 从公共应用程序调用：

  • 所有函数的执行，包括查询、函数支撑的操作和函数支撑的批量操作。
  • 聚合与搜索，包括 searchObjects 和 aggregateObjects。
  • 复杂 search-arounds 和 派生属性。
  • 本体论中的接口。
  • 附件，支持上传和下载。
  • 媒体，支持上传和下载。
  • 时间序列流式传输端点，包括 streamAllPoints 和 streamValues。

此外，您无法从 Public Application 中调用任何非本体论平台 API，例如用于平台管理、模型创建、调度编排或聊天机器人交互的 API。

为何存在这些限制

Public Application 公开的每个端点都可以被任何满足应用入口策略的人访问，而这些策略的范围可能广泛到整个开放互联网。受支持的操作集仅限于成本有界且数据形状可预测的操作，以确保对公共暴露面的滥用不会导致无限制的计算支出，也不会外泄非预期的数据。

出于同样的原因，函数驱动的工作流被排除在外：恶意用户可能会针对您所在注册环境的计算资源构造开销巨大的查询。如果您的工作流需要对通过 Public Application 提交的数据进行更繁重的处理，请在 Foundry 中异步执行这些处理。例如，您可以配置一个非函数支撑的操作来写入提交内容，然后使用 Automate 按受控的节奏对新对象作出响应。

例外情况和未来发展

如果您的工作流依赖于支持范围之外的操作，请联系 Palantir 支持。例外情况将逐案评估，且任何例外情况仍需获得您所在注册中的 信息安全官 的用例审批后方可启用。支持范围将随平台版本的发布而不断扩大：

  • 按应用程序的计算可观测性，以便尽早检测滥用行为。
  • 超出当前每应用程序限制的更强速率限制控制。

该路线图有意保持保守：公共应用程序是无需 Foundry 账户即可访问注册中的数据和计算资源的第一个入口，因此平台只会在保障该攻击面安全所需的保护措施到位后，才会启用更多功能。
