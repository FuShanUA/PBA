为 CSV 或 JSON 文件推断 schema

在 Foundry 中，如果数据集具有 schema，处理起来会最为方便。Foundry 允许您通过选择数据集中的 应用 schema 按钮，为包含 CSV 或 JSON 文件的数据集手动添加 schema。该 应用 schema 按钮将基于数据的一个子集自动推断 schema。应用 schema 后，选择 编辑 schema 即可在数据集视图中修改列类型，或应用其他解析选项来丢弃不规则行、更改编码，或添加其他列，例如文件路径、行的字节偏移量、导入时间戳或行号。

基于初始数据集文件静态应用的 schema 可能会随着数据的变化而过时。因此，让 Spark 在半结构化数据的转换管道中将动态推断 schema 作为第一步会很有帮助。

在每次管道构建时动态推断 schema 会带来性能开销，因此应谨慎使用此技术（例如，仅在 schema 可能发生变化时使用）。

动态 schema 推断只是使用 SparkSession.read ↗读取数据集全部或部分文件的众多用例之一，如下例所示。如果您的用例实际上并不需要动态 schema 推断行为，请通过设置 inferSchema to False （这将导致所有列均为字符串类型）来禁用它，或者省略该选项并 显式传入 schema ↗。禁用自动 schema 推断将显著提升性能和一致性，尤其是对于 增量管道 而言，因为增量批次之间不同的 schema 推断结果可能会引发问题。

以下是 CSV 和 JSON 输入的示例。

Parquet 是 Transforms 的默认输出文件格式，不允许自动推断的 schema 中可能出现的某些特殊字符。因此，我们建议您使用 sanitize_schema_for_parquet （如下例所示），以防止潜在问题。

from transforms.api import transform, Input, Output
from transforms.verbs.dataframes import sanitize_schema_for_parquet

@transform(
    output=Output("/Company/sourceA/parsed/data"),
    raw=Input("/Company/sourceA/raw/data_csv"),
)
def read_csv(ctx, raw, output):
    filesystem = raw.filesystem()
    hadoop_path = filesystem.hadoop_path
    files = [f"{hadoop_path}/{f.path}" for f in filesystem.ls()]
    df = (
        ctx
        .spark_session
        .read
        .option("encoding", "UTF-8")  # UTF-8 is the default
        .option("header", True)
        .option("inferSchema", True)
        .csv(files)
    )
    output.write_dataframe(sanitize_schema_for_parquet(df))

from transforms.api import transform, Input, Output
from transforms.verbs.dataframes import sanitize_schema_for_parquet

@transform(
    output=Output("/Company/sourceA/parsed/data"),
    raw=Input("/Company/sourceA/raw/data_json"),
)
def read_json(ctx, raw, output):
    filesystem = raw.filesystem()
    hadoop_path = filesystem.hadoop_path
    files = [f"{hadoop_path}/{f.path}" for f in filesystem.ls()]
    df = (
        ctx
        .spark_session
        .read
        .option("multiline", False)  # False is the default; use True if each file contains a single JSON object instead of newline-delimited JSON objects
        .json(files)
    )
    output.write_dataframe(sanitize_schema_for_parquet(df))
