添加来自其他 Foundry 应用程序的内容

添加来自 Contour 的看板

如果您想展示单个 Contour 分析的结果，可以考虑使用 Contour 仪表板模式来创建交互式仪表板。 了解更多关于 Contour 仪表板模式的信息。

分析的编辑者和查看者都可以将看板添加到报告中。

要将 Contour 看板添加到报告中：

  1. 打开您的 Contour 分析。

  2. 滚动到相应的看板，然后点击 更多操作 看板标题栏中的按钮（...).



  3. 点击设置菜单下的 发送到报告），然后从菜单中选择一个报告：

    • 从 最近的报告 部分选择一个最近的报告，或者
    • 点击设置菜单下的 新建报告 来创建一个新报告，或者
    • 点击设置菜单下的 浏览文件 从 Foundry 的其他位置选择一个报告。



    当看板成功添加到您选择的报告时，您应该会看到一个确认提示。



添加来自 Code Workbook 的看板

报告是将来自不同工作流的内容整合到一个地方的好工具。

最佳实践

要在报告中查看并交互 Code Workbook 可视化内容，我们建议授予用户对底层 Code Workbook 的编辑权限。只有查看权限的用户只能看到由具有编辑权限的用户先前计算过的输入数据和参数组合。

  3. 点击设置菜单下的 添加到报告），然后从菜单中选择一个报告：

    • 从 最近的报告 部分选择一个最近的报告，或者
    • 点击设置菜单下的 新建报告 来创建一个新报告，或者
    • 点击设置菜单下的 浏览文件 从 Foundry 的其他位置选择一个报告。



    当看板成功添加到您选择的报告时，您应该会看到一个确认提示。



添加来自 Object Explorer 的视图

报告是将来自不同工作流的内容整合到一个地方的好工具。

Object Explorer 提供多种类型的视图，每种视图都可以添加到报告中：

  • 对象 - 特定对象的完整视图
  • 部分 - 对象视图中的某个部分
  • 列表 - 多个对象的表格列表

将对象视图添加到报告

要将 Object Explorer 中的对象视图添加到报告中：

  1. 在 Object Explorer 中打开一个对象视图。

  2. 点击设置菜单下的 操作 在页面右上角。

  3. 点击设置菜单下的 添加到报告。



  4. 从菜单中选择一个报告。

    • 从 最近的报告 部分选择一个最近的报告，或者
    • 点击设置菜单下的 新建报告 来创建一个新报告，或者
    • 点击设置菜单下的 浏览文件 从 Foundry 的其他位置选择一个报告。



将对象视图的某个部分添加到报告

此工作流在某些 Foundry 安装中可能被禁用。如果您没有看到下文所述的“添加到报告”按钮，请联系您的 Palantir 代表。

要将 Object Explorer 中的对象视图添加到报告中：

  1. 在 Object Explorer 中打开一个对象视图。

  2. 滚动到您想要添加到报告的部分，然后点击部分标题栏中的**添加到报告**。



  3. 从菜单中选择一个报告。

    • 从 最近的报告 部分选择一个最近的报告，或者
    • 点击设置菜单下的 新建报告 来创建一个新报告，或者
    • 点击设置菜单下的 浏览文件 从 Foundry 的其他位置选择一个报告。



将列表添加到报告

要将 Object Explorer 中的对象列表添加到报告中：

  1. VS Code 工作区 列表 中。

  2. 点击设置菜单下的 操作 在应用程序标题栏中。

  3. 点击设置菜单下的 添加到报告 在出现的菜单中。



  4. 从菜单中选择一个报告：

    • 从 最近的报告 部分选择一个最近的报告，或者
    • 点击设置菜单下的 新建报告 来创建一个新报告，或者
    • 点击设置菜单下的 浏览文件 从 Foundry 的其他位置选择一个报告。



在上述每个工作流中，当看板成功添加到您选择的报告时，您应该会看到一个确认提示。

要将 Fusion 电子表格添加到报告中：

  1. 在 Fusion 中打开一个电子表格。

  2. 值 文档 标签页。

  3. 点击设置菜单下的 添加到报告



  4. 点击设置菜单下的 选择报告 在出现的侧边栏中，并从菜单中选择一个报告。



  5. 在侧边栏中自定义任何其他设置。

  6. 点击蓝色的 添加到报告 侧边栏底部的按钮。

添加来自 Quiver 的图表

报告是将来自不同工作流的内容整合到一个地方的好工具。

报告仅支持添加来自 Quiver v1 的 Quiver 时间序列图表。 或 是大多数新报告用例的推荐工具，并支持嵌入所有 Quiver 图表。

要将 Quiver 图表添加到报告中：

  1. 打开一个 Quiver 分析。

  2. 找到相应的看板，然后点击 将图表添加到报告 （位于看板标题栏中）。



  3. 在出现的菜单中选择一个报告。



  4. 点击设置菜单下的 OK 在出现的“确认保存”对话框中。 注意： 这也会保存您的分析。



    当看板成功添加到您选择的报告时，您应该会看到一个确认提示。
