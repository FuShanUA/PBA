迁移现有 Project

除了创建 新的用例 Project之外，Use Cases 应用程序还允许您将现有 Foundry Project 迁移为用例支撑 Project。

按照以下步骤将现有 Project 迁移为用例。

  1. 首先，导航到您要迁移为用例的 Foundry Project。在 Foundry 导航侧边栏中，选择 Projects & files > Projects 以查看您可用的 Project。找到包含用例所需资源的 Project，并打开该文件夹。

  2. 在 Project 概览页面中，选择 Actions > Create use case. 这将启动将现有 Project 迁移为新用例的过程。

  1. 迁移完成后，将打开一个新页面，显示您的新用例的概览以及 Project 中包含的所有资源。
