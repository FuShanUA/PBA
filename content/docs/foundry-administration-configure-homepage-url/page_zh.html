配置平台体验

您可以使用控制面板中的 平台体验 页面来配置整体平台体验的设置。要查看 平台体验 选项卡，您必须具有以下 角色之一：

  • 注册管理员 （在 注册权限 扩展中授予）。
  • 组织管理员 或 用户体验管理员 （在 组织 权限 扩展中授予）。

配置主页 URL

组织的主页 URL 可以按组织或按用户组在控制面板的 平台体验 选项卡中进行配置。

一些常见配置示例：

  • 大多数新的 Foundry 注册都会显示一个默认的叙事主页，以帮助用户了解 Foundry 平台。该主页的 URL 为 /narrative。
  • 如果要将 Slate 仪表板用作组织的主页，请将该值设置为 /slate/<dashboard-rid-or-permalink>。
  • 如果要将 Carbon 工作区用作组织的主页，请将该值设置为 /carbon/<workspace-rid>

如果某些用户组应被定向到与组织默认主页不同的主页 URL，您可以在左侧边栏的 组覆盖 下添加特定于组的覆盖设置。如果用户是某个条目所列任一组的成员，则将使用列表中第一个符合条件的条目。

配置可用语言

您可以从 Platform experience 扩展中为用户提供英语以外的其他语言。

有权使用其他语言的用户将在其 Foundry 侧边栏中看到用于选择语言的区域设置切换器。如果启用了 尊重用户的浏览器语言偏好 或 在对值进行本地化时始终使用浏览器的语言偏好 选项，用户最初会以其网络浏览器偏好设置中优先级最高的可用语言查看 Foundry。否则，在用户从语言切换器中选择其他语言之前，将默认使用英语。

Foundry 中的某些小组件会遵循用户的浏览器语言偏好，必要时可能需要更新浏览器的语言设置。

配置平台徽标

如果您拥有 Enrollment 管理员 权限，则可以为每个 Enrollment 配置平台徽标。如果您没有这些权限，则只能为每个 组织配置徽标。

平台 Logo 可以按 Enrollment 和组织进行配置，用您选择的图像替换默认 Palantir Logo 的所有出现位置。您最多可以提供四种不同的 Logo 尺寸：favicon、小、中和大。如果您没有为每种尺寸都提供图像，Foundry 将使用合适的回退尺寸。favicon 没有任何回退行为。自定义 Logo 时，您应该上传一个 favicon 和 至少 一种其他尺寸的图像。

配置平台标题

如果您拥有 Enrollment 管理员 权限，则可以按 Enrollment 配置平台标题。如果您没有这些权限，则只能按组织配置 Logo。

平台标题可以按 Enrollment 和组织进行配置，并使用提供的标题替换对平台的引用。默认平台标题为 Palantir。您可以在 平台标题 标签页中配置此项，该标签页位于 Platform experience 扩展中。

配置新的平台标题后，此更新也会反映在您的平台内文档名称中。例如，如果您将平台重命名为 ABC，平台内 文档应用程序将从默认 Custom documentation 标题更改为 ABC documentation。

配置平台版本

该 平台版本切换器 可让您在平台的不同版本之间进行选择。例如，某些用户可能更愿意使用平台的 测试版 ，以便抢先体验尚未在 稳定 版本中推出的新功能。

要查看和配置控制面板中的 “平台版本” 选项卡，用户需要 “管理平台版本” 工作流，该工作流由 “用户体验管理员” 角色授予。角色在控制面板的 “组织权限” 选项卡中进行管理。

平台版本

通过平台版本切换器，可以使用以下三种平台版本： 稳定版、 测试版和 先前版本。

稳定版

稳定版本经过了严格测试，并且得到了广泛使用。绝大多数用户将使用稳定版本。

测试版

Beta 版本是未来的稳定版本，其中包含当前稳定版本尚未提供的新变更和新功能。由于 beta 版本较新，该版本中的变更可能未经过稳定版本那样严格的测试，您可能会遇到意外行为。在 Palantir 平台上进行构建时，选择加入 beta 版本有助于提前获取新功能。

先前版本

先前版本是指紧邻当前稳定版本之前的稳定版本。当稳定版本发生变更时，切换到先前版本可用于查看旧版 UI，但不建议将先前版本用于日常使用。用户可以临时查看先前版本，但系统会自动将其切回默认版本（参见 配置用户的默认平台版本）。

平台版本切换器

要更改平台版本，请前往左侧边栏底部的账户设置，然后选择 平台版本 旁边的当前版本，以打开平台版本切换器。选择其他版本后，页面将重新加载并载入新版本。

向用户显示的默认版本由 控制面板中的默认平台版本设置。当查看稳定版本以外的平台版本时，侧边栏中会显示一个小标签，提示用户正在查看不同的版本。

限制对平台版本切换器的访问

可以限制组织中的用户访问侧边栏中的平台版本切换器。要更改切换器的访问权限，请导航至 “平台体验” 扩展，然后转到 “平台版本” 标签页。

选择 “管理” （位于 “平台版本切换器” 旁边），以弹出更改平台版本切换器设置的对话框。

选择所需的访问权限，然后选择 “为您的组织请求并应用更改”。这将在 控制面板的“审批收件箱” 中创建一个更改请求，该请求将自动完成自我批准并被应用。要查看所有历史更改，请选择 “平台版本切换器请求” （在“审批收件箱”中）。

配置用户的默认平台版本

此外，管理员还可以配置用户组，使其默认使用 beta 平台版本。如果这些用户中有人有权访问平台版本切换器，他们仍然可以从 beta 版本切换到其他版本。这使您能够选择一组默认使用 beta 版本的高级用户，让他们在您的其他用户看到新功能之前先试用这些功能。

要配置哪些用户应默认看到 beta 版本，请选择 管理 （位于 默认平台版本旁）。在对话框中，选择需要使用 beta 版本的组；未包含在所选组中的用户将默认看到稳定版本。

完成配置后，请选择 为您的组织请求并应用更改。这将在 控制面板的审批收件箱 中创建一个更改请求，该请求将自动自我批准并应用。要查看过去的所有更改，请选择 平台版本默认值请求 （在审批收件箱中）。

配置静态横幅

您可以为每个组织配置一个静态横幅，该横幅会显示在每个页面的顶部、底部或顶部和 底部。 横幅文本 字段支持基本的 Markdown 语法。默认情况下， 此设置处于禁用状态。
