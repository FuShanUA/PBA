添加 npm 依赖项

以下文档专用于 TypeScript v1 函数。如需更 强大的功能，包括对 Ontology SDK 的支持和可配置的资源请求，我们建议 迁移到 TypeScript v2。

函数仓库使用 npm ↗ 来管理依赖项，包括用于基于 Foundry 本体论生成代码以及在您的代码中发现函数的包。您可以使用 npm 将外部依赖项安装到您的仓库中，使用标准包来处理数字和日期、执行统计计算或处理 XML 等数据格式。

请注意，函数运行时仅支持纯 JavaScript 库——任何依赖 NodeJS 运行时并进行系统调用的包均不受支持。

启用从公共 npm 注册表获取依赖项

默认情况下，函数仓库不会从公共 npm 注册表获取包。

如果您的仓库尚未从公共 npm 注册表获取依赖项，当您在代码仓库中打开一个 package.json 文件时，将会显示一个用于启用该功能的横幅。

在代码仓库中添加依赖项

您可以使用“库”（Libraries）侧边栏向您的函数仓库添加包，该侧边栏位于 代码仓库。搜索所需的软件包,然后选择一个结果以查看最新版本等详细信息。结果中包含的软件包来自 Foundry 和 https://npmjs.com。

选择是否将该软件包添加到 dependencies 还是 devDependencies (位于您的 package.json 文件中)。选择 “添加并安装库” 以将该软件包添加到您的仓库中。

如果该软件包的源仓库尚未配置为支撑仓库,系统将弹出一个对话框,提示您导入额外资源。该 “添加并安装库” 按钮会自动将该软件包及其依赖项导入到您的函数仓库中,并更新您的 package.json 和 package-lock.json。

正在运行的安装任务完成后,该软件包即可在您的仓库中使用。

如果您使用的 typescript-functions 模板版本低于 0.520.0,则通过任务运行器进行的安装将被禁用。在这种情况下,请提交您更新后的 package.json 文件,确保检查顺利通过,然后重启 Code Assist 以使新软件包可用。

手动添加依赖项

您可以通过修改 package.json 文件(位于代码仓库中)来手动添加软件包。如果您需要安装特定版本的软件包,这可能很有用。打开 package.json,添加您的依赖项,并从 https://npmjs.com中选择相应的版本,然后选择 “提交”. 确认检查成功通过后，请重启 Code Assist 以使新包可用。
