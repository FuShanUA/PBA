节点指示器

节点指示器显示在数据集节点的顶部，并提供有关资源的附加信息。

指示器类型描述
未解决的问题此指示器表示图中该节点当前存在未解决的问题。将鼠标悬停在此信号上可显示未解决问题的数量。
定义对象类型此指示器显示在用于定义本体论对象类型的数据集上。将鼠标悬停在右箭头上可以展示这些关联的对象类型。 了解有关对象类型的更多信息。
同步带有此指示器的数据集已同步到其他数据库或系统。您可以通过选择节点并打开“属性”面板，或在数据集预览中打开“详情”标签页（右键点击节点并点击 打开).
已删除此指示器显示在表示已删除数据集或制品的节点上。已删除的节点也会部分淡化显示，其名称会被划掉。
