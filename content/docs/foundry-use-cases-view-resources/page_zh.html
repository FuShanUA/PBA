查看资源

创建新用例后，您可以在用例概览页面中查看已连接的应用程序和本体论资源。如果您是从现有的支撑 Project 创建的用例，这些资源将自动显示在您的用例中。如果您在创建新用例的同时创建了新的 Project，则需要 添加应用程序资源 或数据源，然后才能查看它们及其连接的本体论组件。

用例概览提供元数据，包括用例工作流程的描述、用例负责人的姓名以及用例的状态。概览中还包含以下部分： 应用程序, 本体论日 支撑数据 资源。本体论资源按对象类型和操作类型进行分类。选择概览或左侧边栏中的部分标题即可打开资源页面。
