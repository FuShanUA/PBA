JDBC 系统的表导出功能现已推出

发布日期：2024-06-25

现在可以通过以下方式将数据集导出到外部 JDBC 系统 。对于在 z/OS 或 LUW（Linux, Unix, Windows）上运行的 Db2 数据库，不需要额外配置。但是，对于在 IBM iSeries 或 AS/400 上运行的 Db2 数据库， （位于 Data Connection 中）。表导出为配置表格数据导出提供了全新的用户体验，包括直观的界面、丰富的导出模式选择，以及浏览目标系统以配置导出的能力。表导出适用于 自定义 JDBC 系统 ，支持直接连接和代理运行时两种配置方式。

导出模式

表导出支持六种不同的导出模式，以满足您的独特需求：

  • 高效地将数据集镜像到外部表（推荐): 外部表将始终与您在 Foundry 数据集中看到的内容保持一致。
  • 导出完整数据集而不截断： 始终导出 Foundry 数据集整个视图的快照，而不先截断外部表。
  • 导出完整数据集并截断： 截断（删除）目标表，然后导出当前完整数据集视图的快照。
  • 增量导出： 导出 唯一 当前视图中未导出的事务，而不截断目标表。
  • 增量导出并截断： 截断（删除）目标表，然后仅导出当前视图中之前未导出的事务。
  • 增量导出，若不满足条件则失败 APPEND: 仅导出当前视图中未导出的事务，如果存在 SNAPSHOT, UPDATE，或 DELETE 事务（首次运行之后）则失败。

Pipeline Builder 中的预览速度更快

发布日期：2024-06-17

得益于缓存增强，Pipeline Builder 预览现在显著加快。内部测试显示，计算时间从 40 秒缩短至 1 秒，将资源密集型预览的速度提高了 40 倍。此功能现已在所有注册中正式可用。

缓存改进带来的更快预览

缓存改进使 Pipeline Builder 中的节点能够使用已预览的上游节点的缓存（即“存储”）结果。这使下游节点可以跳过重新计算，快速显示您的数据预览。

Pipeline Builder 改进的缓存功能包括：

  • 减少冗余计算： 现在，在 Pipeline Builder 中，只有在缓存节点的下游进行预览时才会计算额外的节点。
  • 高效缓存： 计算开销较高的节点（例如 join 和 use LLM ）现在会被主动缓存，使下游节点避免重复且耗时的计算。

用户将受益于快速预览和降低的处理成本，在开销较高的节点下游工作时节省时间和资源。使用缓存的上游预览结果的预览上将显示闪电图标，如下所示：

改进的节点缓存

在此更改之前，如果您在不进行任何逻辑更改的情况下预览同一节点两次，它会缓存第一次预览的结果并在第二次预览时复用。但如果您随后预览下游节点，它将无法访问其他缓存的节点结果，上游节点需要从头开始重新计算。

现在，Pipeline Builder 中的所有节点预览都可以利用缓存结果，因此只需计算额外的下游节点。

以以下示例数据集为例：

如果您预览 C，则节点 Dataset → A → B → C 会被计算。在此更改之前，如果您随后预览 D:

  • 节点 Dataset → A → B → C 会被重新计算，此外 D.

此更改后，如果您预览 D 在 C:

  • 只有节点 C → D 会被计算，因为节点 D 现在可以使用来自节点的缓存结果 C.

请注意，所有节点预览最多计算 500 行。无法从此功能中受益的操作包括更改行数的操作、联接、聚合或逻辑更改。

Hawk 提供了增强的性能和可维护性，确保更高效、更可靠的 Python 环境管理体验。Hawk 的初步测试显示，在解析和安装新包时，检查执行时间相比 Mamba 提升了约 25%。此外，Hawk 基于积极维护的库构建，确保核心基础设施保持最新和安全。

新的 Python 代码仓库将自动开始使用 Hawk。对于现有仓库，您可以通过选择 ... 然后选择 升级.

将您的 Python 仓库升级到新的 Hawk 环境管理系统。

在使用 Hawk 的 Python 仓库中，您可以在 检查 选项卡中查看指示某些任务正由 Hawk 而非 Mamba 执行的日志行。例如，您可以查看日志行 Executing task 'runVersions' with 'HAWK'.

在 Slate 中推出 OSDK [Beta]

本体论软件开发工具包（OSDK）允许您直接在开发环境中访问本体论的全部功能。在所有租户上，OSDK 现已在 Slate 中可用，您可以通过在 Slate 中编写函数来转换本体论数据，从而与本体论进行交互。

借助 OSDK，Slate 与本体论之间的集成更加紧密。例如，构建者可以在专用接口中访问对象类型、关联类型和操作，并可在本体论发生更改时随时生成和更新 OSDK 包。

通过构建能够轻松遍历对象类型的应用程序，并在代码中与本体论的丰富内容进行完整交互，使用操作为贵组织最重要的工作流打造功能丰富且高度定制的应用程序。

Slate 允许在 平台 标签页中使用 Foundry 函数，并支持处理非本体论数据源，为应用程序构建者提供高度灵活的环境。

应用程序构建者现在可以在 Slate 中使用 OSDK 功能，以构建与本体论交互的产品。

更多亮点

管理 | Control Panel

空间现已在控制面板中管理 | 为了整合和简化 Foundry 中的管理设置， 空间 （此前称为 命名空间）的空间现已在控制面板的租户设置下进行管理。

尽管 空间（Spaces） 标签页对所有人可见，但管理单个空间所需的权限保持不变。要进行配置，需要满足访问要求并且 被授予相关空间上的角色。欲了解更多详情，请查阅我们的 空间文档.

Analytics | Notepad

通过 Notepad 模板增强文档创建功能 | Notepad 应用程序现在包含一项增强功能，允许用户从最新发布的 Notepad 模板版本即时生成文档。这一新功能可通过应用程序主页或应用程序头部中的文件菜单便捷地访问。

Analytics | Quiver

时间序列洞察的渐变显示优化 | Quiver 现在提供渐变显示选项，可为时间序列图表配置颜色填充。这提升了同一图表中绘图重叠时的可读性，并有助于识别量级随时间的相对变化。

应用构建 | Slate

Slate 侧边栏体验增强 | Slate 中重新设计的侧边栏引入了更加统一的用户界面。此次更新将应用程序布局、数据管理、逻辑操作和调试的基本工具集中到一个易于访问的面板中，提升了用户体验，并帮助新用户更顺畅地上手。

版本历史中 Slate 文档的 JSON 导出增强 | 版本对话框现在支持导出任意所选版本的 Slate 文档 JSON。此增强功能确保编辑者可以轻松访问和导出任何现有版本的文档 JSON。

应用构建 | Workshop

新增排序选项 | 对象列表小部件现在支持对多个属性进行排序，并支持对函数支撑的属性进行排序。

Workshop 中的虚拟化对象列表 | 对象列表小部件现在利用虚拟化技术大幅提升性能，尤其是对于包含大量元素的列表。

Workshop 中的小部件配置增强 | Workshop 操作小部件现在支持表格数据输入配置，支持同时创建多行新数据，或上传包含多行数据的电子表格来填充输入表格。此功能解锁了需要大量手动数据输入的工作流。

增强的分支与主版本模块比较 | 更改日志面板现在支持在分支中工作时选择最新的主版本进行比较，从而简化模块差异对比流程。此次更新对于使用分支工作流的用户尤为有利。

数据集成 | 数据连接

数据连接中增强的 Webhook 访问 | 用户现在可以通过导航到相应数据源，直接查看和管理与该数据源关联的 webhook。此前提供的列出所有 webhook 的页面已被弃用。

本体论 | 本体论管理

本体论管理器上传中改进的主键处理 | 对操作（Actions）表格录入模式的增强现在确保了在文件上传过程中更直观的主键处理。有效的主键会自动关联到对象引用表单参数的相应对象。无法解析的主键会被及时高亮显示，以便在上传界面中直接编辑。此次更新简化了通过 CSV 上传填充表格操作时的数据修正流程。

Ontology | Vertex

Vertex 图层中改进的图标个性化功能 | Vertex 为图层引入了改进的图标个性化功能，使用户能够根据对象属性定制图标，或从扩展的静态图标库中进行选择。这一改进为图表示中的节点可视化提供了定制化的方式，满足不同工作流程的多样化需求。

Security | Approvals

改进的 Approvals 操作和状态 | Approvals 中的访问请求已得到简化；可用操作现在显示在请求级别，而非任务级别。审批人现在可以对多个任务应用操作。这提高了所有可用操作的可发现性和可解释性，并简化了请求处理流程。新的访问请求状态（例如 Pending approval, Closed, Action required、 和 Completed ）已引入，以便更好地传达请求的状态。

改进的 Approvals 收件箱搜索 | Approvals 收件箱现在允许用户基于所包含的项目、用户或组来筛选请求，此外还有现有的筛选条件。这些新筛选条件仅适用于访问请求，并通过使访问请求审查更高效来显著提升用户体验。之前显示在表格标题中的筛选条件现在移至左侧边栏。
