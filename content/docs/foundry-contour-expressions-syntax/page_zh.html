语法和支持的函数

有关表达式面板的介绍，请参阅 使用表达式面板的指南。本文档是使用 Contour 丰富表达式语言的资源，可用作类型、运算和函数的参考。

数据类型

您可以在表达式中使用以下数据类型：

  • 字符串
  • 整数
  • 双精度浮点数
  • 布尔
  • 日期

字符串

字符串用单引号表示：

'This is a string'

This is a string

在字符串中添加第二个单引号来转义单引号：

'I''m a string'

I’m a string

使用 || 运算符将列作为字符串连接：

"Gender" || "MaritalStatus"

您还可以将列与常量连接。

'$' || ("salaryColumn"/1000.0) || 'k'

整数

整数是非浮点数：

5

双精度浮点数

双精度数是浮点数：

5.7

布尔

布尔变量可以是 true or false。布尔变量不区分大小写。

日期

您可以将格式为 YYYY-MM 或 YYYY-MM-DD 的字符串转换为日期：

CAST('2016-12-06' AS DATE)

您还可以将字符串转换为时间戳：

CAST('2016-12-06 01:12:34' AS TIMESTAMP)

对时间戳执行运算时，最简单的方法是先将时间戳转换为 long 类型，或者如果需要毫秒精度，则转换为 double 类型。这将为您提供 UNIX 时间中的秒数。

例如，假设您有两个时间戳列：“start”和“end”。要确定两个时间之间的分钟数，您可以使用以下表达式：

(CAST("end" as LONG) - CAST("start" as LONG)) / 60.

将 long 类型转换为时间戳时，假定 long 值以秒为单位。如果您的数据以毫秒为单位，请在转换之前除以 1000。

算术

将数值列（整数或双精度数）与其他数值列或常量相加、相减、相乘和相除： +, -, *, /

  • "tipAmount" / "fare"
  • "diameter" * 3.14

比较

使用 > （大于）、 >= （大于或等于）、 < （小于）、 <= （小于或等于）比较任意类型的列之间以及列与常量之间的关系。结果为一个布尔列。

  • "age" > "averageAge"
  • "totalDistance" < 5

比较两个字符串时，Contour 使用字典顺序。在比较包含数字的字符串时，这可能与直觉相反。例如：

  • 'Alligator' < 'Boat' => TRUE，因为 'A' 的编码小于 'B'
  • 'Alliance' < 'Alligator' => TRUE，因为 'a' 小于 'g'
  • 'Zoo' < 'alpha' => TRUE，因为 'Z' 小于 'a'
  • 'Zoo' < 'Zoologist' => TRUE，因为如果一个字符串是另一个字符串的前缀，则较短的字符串被认为更小
  • '1' < '2' => TRUE，因为字符串字符 '1' 小于字符串字符 '2'
  • '10' < '2' => TRUE，因为其第一个字符串字符 '1' 小于字符串字符 '2'；这是字符串 '10' 和 '2' 的比较，而不是整数 10 和 2 的比较
  • '10' < '20' => TRUE，因为 '1' 小于 '2'

相等比较

检查某一行在两列中是否具有 相同 值，使用 ==，或 不同 值，使用 !=.

  • "cityOfBirth" == "cityOfResidence"

您还可以将列值与常量进行比较。

  • "Gender" == 'M'
与 Spark SQL 的行为差异

在 Contour 表达式语言中，使用 NULL 进行相等比较时具有以下行为。

  • NULL = 'DATA' => FALSE
  • NULL != 'DATA' => TRUE
  • NULL = NULL => TRUE
  • NULL != NULL => FALSE

但是，在 Spark SQL 中，所有这些表达式都返回 NULL。在 Contour 表达式和 Spark SQL 之间进行转换时，务必考虑这一行为差异，以产生一致的结果。

布尔比较

通过使用布尔逻辑评估一个或多个列来派生新的布尔列。

  • "Age" >=70 AND "Gender" = 'M'

类型转换

类型转换允许您更改列或表达式的类型。您可以转换为布尔值、整数、双精度数、日期和时间戳。

  • CAST("startDate" AS DATE)
  • CAST("startTime" AS TIMESTAMP)
  • CAST("numParticipants" AS INTEGER)

Like

在列中搜索指定的模式。请参阅 SQL LIKE ↗ 以了解更多信息。

空值检查

检查某个值是否 IS NULL or IS NOT NULL。返回一个布尔值。

优先级

表达式中运算的优先级在以下列表中详细说明，从最高优先级到最低优先级。同一行上的运算具有相同的优先级。

  1. +、-、NOT（一元）
  2. ||（二元）
  3. *、/、%（二元）
  4. +、-（二元）
  5. <、<=、>、>=（二元）
  6. =、==、!=、<>、IS、IS NOT、LIKE、RLIKE（二元）
  7. IS NULL、NOT NULL（一元）
  8. IN、NOT IN
  9. AND（二元）
  10. OR（二元）

数学与数值函数

  • ABS：计算绝对值。
  • CBRT：计算给定值的立方根。
  • CEIL：计算给定值向上取整的结果。
  • COS：计算给定值的余弦。
  • EXP：计算给定值的指数。
  • FACTORIAL：计算给定值的阶乘。
  • FLOOR：计算给定值向下取整的结果。
  • FORMAT_NUMBER：将数值列 arg0 格式化为类似“#,###,###.##”的格式，四舍五入到 arg1 位小数，并以字符串列的形式返回结果（注意：arg1 必须是整数字面量）。
  • ISNAN：当且仅当该列为 NaN 时返回 true。
  • LN：计算给定值的自然对数。
  • LOG：以 arg0 为底计算 arg1 的对数（注意：arg0 必须是数值字面量）。
  • POW：返回 arg0 的 arg1 次幂的值。
  • RAND：根据提供的种子 arg0，为每一行返回一个介于 0 和 1 之间的随机数。
  • ROUND：返回将 arg0 四舍五入到 arg1 位小数后的值（注意：arg1 必须是整数字面量）。
  • RTRIM：去除指定字符串值右端的空格。
  • SIN：计算给定列的正弦。
  • SQRT：计算指定浮点值的平方根。
  • TAN：计算给定值的正切。

字符串函数

引用 name 列的示例假定该列包含值 Jane.

  • CONCAT：将多个输入字符串列连接为一个字符串列。例如， CONCAT("firstName", "lastName") returns JaneDoe when firstName is Jane and lastName is Doe.
  • CONCAT_WS：使用给定的分隔符将多个输入字符串列连接为一个字符串列（注意：arg0 必须是字符串字面量）。例如， CONCAT_WS(' ', "firstName", "lastName") returns Jane Doe when firstName is Jane and lastName is Doe.
  • FORMAT_STRING：根据 Java Formatter ↗ 格式化参数，并以字符串列的形式返回结果。例如， FORMAT_STRING('%.2f', "salary") returns 1234.50 when salary is 1234.5.
  • LENGTH：计算给定字符串或二进制列的长度。例如， LENGTH("name") returns 4.
  • LEVENSHTEIN：计算两个字符串列之间的编辑距离。例如， LEVENSHTEIN("wordA", "wordB") returns 3 when wordA is kitten and wordB is sitting.
  • LOWER：将字符串列转换为小写。例如， LOWER("name") returns jane.
  • LPAD：返回字符串列 arg0，使用字符串 arg2 在左侧填充至长度 arg1（注意：arg1 必须是整数字面量，arg2 必须是字符串字面量）。例如， LPAD("id", 5, '0') returns 00042 when id is 42.
  • LTRIM：去除指定字符串值左端的空格。例如， LTRIM("name") returns Jane when name is Jane （已去除前导空格）。
  • REGEXP_EXTRACT：将字符串列 arg0 与正则表达式 arg1 进行匹配，并提取指定的分组 arg2（从 1 开始索引）。如果正则表达式未匹配，或指定的分组未匹配，则返回空字符串（注意：arg1 必须是字符串字面量，arg2 必须是整数字面量）。例如， REGEXP_EXTRACT("email", '([^@]+)@', 1) returns jane when email is jane@example.com.
  • REGEXP_REPLACE：将 arg0 中所有与 arg1 匹配的文本替换为 arg2。例如， REGEXP_REPLACE("phone", '[^0-9]', '') returns 5551234 when phone is 555-1234.
  • REVERSE：反转字符串列并将其作为新的字符串列返回。例如， REVERSE("name") returns enaJ.
  • RPAD：返回字符串列 arg0，使用字符串 arg2 在右侧填充至长度 arg1（注意：arg1 必须是整数字面量，arg2 必须是字符串字面量）。例如， RPAD("code", 5, '*') returns AB*** when code is AB.
  • SPLIT：围绕正则表达式字符串 arg1 拆分字符串列 arg0，返回单个数组列而不是每个分隔符一个列（注意：arg1 必须是字符串字面量）。由于 arg1 是正则表达式，若要按字面匹配任何正则表达式特殊字符，请对其进行转义；参见 使用特殊字符拆分列。例如， SPLIT("fullName", ' ') 返回数组 ['Jane', 'Doe'] when fullName is Jane Doe.
  • SUBSTRING：返回 arg0 的一部分，从索引 arg1（从 1 开始）开始，长度为 arg2（注意：arg1 和 arg2 必须是整数字面量）。例如， SUBSTRING("name", 1, 3) returns Jan.
  • TRIM：去除指定字符串列两端的空格。例如， TRIM("name") returns Jane when name is Jane .
  • UPPER：将字符串列转换为大写。例如， UPPER("name") returns JANE.

日期/时间函数

有关派生相对日期的更多信息和示例，请参阅 有关派生相对日期的参考文档.

  • ADD_MONTHS：返回 arg0 之后 arg1 个月的日期（注意：arg1 必须是整数字面量）
  • CURRENT_DATE：以日期列的形式返回当前日期。 这些值仅在重新计算路径时更新。为避免各看板之间的值不一致，建议每天更新路径。
  • CURRENT_TIMESTAMP：以时间戳列的形式返回当前时间戳。 这些值仅在重新计算路径时更新。
  • CURRENT_UNIX_TIMESTAMP：以秒数形式返回当前时间戳。 这些值仅在重新计算路径时更新。
  • DATE_ADD：返回 arg0 之后 arg1 天的日期（注意：arg1 必须是整数字面量）。
  • DATE_FORMAT：将日期/时间戳 arg0 转换为按 arg1 指定格式的字符串（注意：arg1 必须是字符串字面量）。
  • DATE_SUB：返回 arg0 之前 arg1 天的日期，并遵循 Java SimpleDateFormat ↗ （注意：arg1 必须是整数字面量）。
  • DATE_TRUNC：返回按格式 arg0 指定的单位截断的日期/时间戳 arg1。
  • DATE_DIFF：返回从 arg1 到 arg0 的天数。
  • DAY_OF_MONTH：从给定的日期/时间戳/字符串中提取月份中的日期并以整数形式返回。
  • DAY_OF_WEEK：从给定的日期/时间戳/字符串中提取星期几并以整数形式返回。范围从 1（星期日）到 7（星期六）。
  • DAY_OF_YEAR：从给定的日期/时间戳/字符串中提取一年中的天数并以整数形式返回。
  • FROM_UTC_TIMESTAMP：给定时间戳列 arg0（对应于 UTC 中的某个时刻），返回对应于给定时区 arg1 中同一时刻的另一个时间戳。（注意：arg1 必须是字符串字面量）。
  • HOUR：从给定的日期/时间戳/字符串中提取小时数并以整数形式返回。
  • LAST_DAY：给定日期列，返回该日期所属月份的最后一天。
  • MINUTE：从给定的日期/时间戳/字符串中提取分钟数并以整数形式返回。
  • MONTH：从给定的日期/时间戳/字符串中提取月份并以整数形式返回。
  • MONTHS_BETWEEN：返回日期 arg0 和 arg1 之间的月数。
  • QUARTER：从给定的日期/时间戳/字符串中提取季度并以整数形式返回。
  • SECOND：从给定的日期/时间戳/字符串中提取秒数并以整数形式返回。
  • TO_UNIX_TIMESTAMP：使用给定的模式字符串 arg1 转换时间字符串 arg0，失败时返回 null（注意：arg1 必须是字符串字面量）。
  • TO_UTC_TIMESTAMP：给定时间戳列 arg0（对应于给定时区 arg1 中的某个时刻），返回对应于 UTC 中同一时刻的另一个时间戳。（注意：arg1 必须是字符串字面量）。
  • WEEK_OF_YEAR：提取 ISO 周 ↗ 编号，并以整数形式从给定的日期/时间戳/字符串中返回。
  • YEAR：从给定的日期/时间戳/字符串中提取年份并以整数形式返回。

数组函数

有关数组函数的更多信息和示例，请参阅 有关数组函数的参考文档.

  • ARRAY：创建包含所有输入列的数组。
  • ARRAY_CONTAINS：如果数组列 arg0 包含值 arg1，则返回 true（注意：arg1 必须是字面量）。
  • ARRAY_GET_AT_INDEX：返回数组列 arg0 中索引为 arg1（从 1 开始计数）的元素（注意：arg1 必须是整数字面量）。要在此后的看板中使用该列，请显式转换此函数的结果。
  • ARRAY_LENGTH：返回给定数组的长度。当输入为 null.
  • ARRAY_JOIN：返回将数组列 arg0 以分隔符字符串 arg1 连接而成的字符串（注意：arg1 必须是字符串字面量）。
  • ARRAY_SORT：如果 arg1 为 true，则按升序对输入数组 arg0 进行排序；如果 arg1 为 false，则按降序排序（注意：arg1 必须是布尔字面量）。
排序列中的并列值可能导致不确定的结果

使用 ROW_NUMBER, FIRST, LAST, ARRAY_AGG，或 ARRAY_AGG_DISTINCT时，在窗口函数中，请注意非确定性问题。假设我们按列 A 进行分区并按列 B 排序。如果对于列 A 的同一个值，存在多行列 B 的值相同，那么这些窗口函数的结果可能是非确定的——即对于相同的输入数据和逻辑，可能产生不同的结果。

窗口函数

窗口函数需要 OVER 子句；更多信息和示例请参阅 有关窗口函数的参考文档.

  • CUME_DIST：返回窗口分区内值的累积分布，即位于当前行之前的行所占的比例。
  • DENSE_RANK：返回窗口分区内行的排名，排名之间没有间隔。
  • EXPLODE：为给定数组列中的每个元素创建一个新行，并丢弃包含 null 的行。要在此后的看板中使用该列，请显式转换此函数的结果。
  • EXPLODE_OUTER：为给定数组列中的每个元素创建一个新行。要在此后的看板中使用该列，请显式转换此函数的结果。
  • FIRST：返回组中的第一个值。
  • LAG：返回列 arg0 中当前行之前第 arg1 行的值；如果当前行之前的行数少于 arg1，则返回 null。例如，arg1 为 1 时，将返回窗口分区中任意给定位置的前一行（注意：arg1 必须是整数字面量）。
  • LAST：返回组中的最后一个值。
  • LEAD：返回列 arg0 中当前行之后第 arg1 行的值；如果当前行之后的行数少于 arg1，则返回 null。例如，arg1 为 1 时，将返回窗口分区中任意给定位置的下一行（注意：arg1 必须是整数字面量）。
  • NTILE：返回有序窗口分区中的 ntile 组 ID（从 1 到 arg0，含边界）。例如，如果 arg0 为 4，则前四分之一的行将获得值 1，第二个四分之一获得 2，第三个四分之一获得 3，最后一个四分之一获得 4（注意：arg0 必须是整数字面量）。
  • PERCENT_RANK：返回窗口分区内行的相对排名（即百分位数）。
  • RANK：返回窗口分区内行的排名。
  • ROW_NUMBER：返回窗口分区内从 1 开始的连续编号。

聚合函数

聚合函数可用于聚合表达式和窗口函数中。

  • ARRAY_AGG：返回由输入列的聚合值组成的数组。
  • ARRAY_AGG_DISTINCT：返回由输入列的去重聚合值组成的数组。
  • AVG：返回组中值的平均值。
  • COUNT：返回组中项目的数量。
  • COUNT_DISTINCT：返回组中项目的数量（注意：只能与 聚合 表达式看板中的选项一起使用。不能与 添加新列, 过滤 or 替换列).
  • CORR：返回两列的皮尔逊相关系数。
  • MAX：返回组中表达式的最大值。
  • MEAN：返回组中值的平均值。
  • MIN：返回组中表达式的最小值。
  • STDDEV：返回组中表达式的样本标准差。
  • SUM：返回表达式中所有值的总和。
  • SUM_DISTINCT：返回表达式中不同值的总和（注意：不能用于窗口函数）。
  • VARIANCE：返回组中值的无偏方差。

杂项函数

  • COALESCE：返回第一个非空的列，如果所有输入均为空则返回 null。
  • GREATEST：返回值列表中的最大值，跳过空值。
  • HASH：计算给定列的哈希码，并将结果作为 int 列返回。
  • ISNULL：当且仅当该列为 null 时返回 true。
  • LEAST：返回值列表中的最小值，跳过空值。
  • MD5：计算二进制列的 MD5 摘要，并将该值作为 32 字符的十六进制字符串返回。
  • MONOTONICALLY_INCREASING_ID：返回一个单调递增的 ID。 这些值在每次计算路径时可能会发生变化。
  • SHA1：计算二进制列的 SHA-1 摘要，并将该值作为 40 字符的十六进制字符串返回。
  • GET_JSON_OBJECT：根据 JSON 路径 ↗ 从 JSON 字符串中提取 JSON 对象，并返回所提取 JSON 对象的 JSON 字符串。以下是一些示例：
    • $.field
    • $['field']
