二元分类评估器

默认的 评估库 之一，在建模目标中是 二分类 评估器。该库提供了一组用于评估二元分类模型的常用核心指标。

包含的指标

以下指标会针对评估仪表板中配置的每个 子集桶生成。例如，如果生成的子集在模型预测列或标签列中不包含两个类别，则可能无法在所有子集上生成全部指标。

默认的二元分类评估器会生成以下数值指标：

  • 行数： 评估数据集中的记录数量。
  • 先验概率： 评估数据集中正结果的比例。先验概率 不 不是模型性能的直接衡量指标，但可用于为其他指标提供背景参考。
  • 准确度： 被正确分类的记录比例。模型的准确率介于 0 和 1 之间，准确率为 1 表示模型正确分类了评估数据集中的每条记录。
  • Precision： 真阳性数除以真阳性数与假阳性数之和。该值介于 0 和 1 之间，1 表示完美的模型精确率。
  • 召回率： 真阳性总数除以真阳性数与假阴性数之和。该值介于 0 和 1 之间，1 表示完美的模型召回率。也称为 灵敏度.
  • F1 分数： 精确率和召回率的调和平均值，计算方法为精确率与召回率的乘积除以精确率与召回率之和。模型的 F1 分数介于 0 和 1 之间，1 表示模型正确分类了评估数据集中的每条记录。
  • 马修斯相关系数 (MCC)： 一种衡量模型性能的数值指标，它对两个分类类别的标签值与预测值之间的数值相关性进行同等程度的综合。因此，只有当分类器在两个类别上都表现良好时，MCC 才会较高。MCC 介于 -1 和 1 之间，分数为 1 表示正确分类了每条记录。
  • ROC AUC 分数 （需要概率）: ROC（接收者操作特征）曲线下的面积；AUC 表示“曲线下面积”(Area Under Curve)。取值范围为 0 到 1，分数为 1 表示完美模型，分数为 0.5 是随机猜测模型的预期分数。

默认的二元分类评估器会生成以下图表：

  • 混淆矩阵： 显示评估数据集中预测的真阳性、真阴性、假阳性和假阴性的数量。
  • 分数分布： 模型在评估数据集上的预测的条形图。
  • 概率分布 （需要概率）: 模型在评估数据集上输出概率的条形图。桶宽度为 0.05，因此在 [0.0, 1.0] range.
  • ROC 曲线 （需要概率）: 绘制不同概率下的真阳性率与假阳性率。曲线越陡峭通常表示模型性能越好。
  • 真阳性率 (TPR) 曲线 （需要概率）: TPR 曲线绘制真阳性率与模型预测概率的关系。
  • 假阳性率 (FPR) 曲线 （需要概率）: FPR 曲线绘制假阳性率与模型预测概率的关系。
  • 提升度曲线 （需要概率）: 显示模型在每个概率下的提升度；提升度是衡量模型在正类别上相对于随机机会的性能指标。

配置

完整的配置说明，请参阅 如何配置模型评估库.

必填字段

二元分类评估器需要以下必填字段。这些列的预期值类型为整数。

  • inference_field: 表示模型预测分类的列。此评估器假定 1 为正类别， 0 为负类别。
  • actual_field: 包含模型预测应与之比较的值的列。此评估器假设 1 为正类别， 0 为负类别。

可选字段

  • probability_field: 这是一个可选字段，表示正预测类别的概率。当提供 probability_field 时，默认的二分类评估库将生成以下指标：

    • ROC AUC 分数
    • ROC 曲线
    • TPR 曲线
    • FPR 曲线
    • 提升度曲线

  • max_samples_for_roc 用于生成模型 ROC 曲线的最大样本数。如果未提供，则默认为 200.
