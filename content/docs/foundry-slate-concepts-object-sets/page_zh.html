创建或检索对象集

平台选项卡下的对象集面板允许您：

  • 创建对象集（可带或不带筛选条件），无需任何额外的服务配置。
  • 通过模板点表示法（例如 {{s_object_set1.data.property1}}).
  • 使用以下方式访问对象 RID {{s_object_set1.objectRids}}.

有两种模式：

  • Builder 模式，允许您使用 GUI（图形用户界面）构建对象集，以及
  • RID 模式，允许您通过引用以下内容来构建对象集 object set RID 或 versioned object set RID.

对象集筛选器构建器模式

要创建对象集 s_object_set1，请选择基础对象类型，然后可选择使用 AND/OR 逻辑添加筛选器。筛选器的字段会考虑对象的属性数据类型。例如，数值属性将采用数字范围作为筛选条件。您还可以在每个筛选级别中进一步嵌套单独的 AND/OR 筛选器，以将对象限定为特定结果。

您还可以在筛选字段中使用 Slate 的 handlebars，以便根据动态变化的输入对对象集进行参数化。

筛选字段还支持使用多词筛选器和通配符筛选器进行模板化：

  • 要使用多词筛选器进行模板化，您可以直接传入多个词（例如 ["value1", "value2"]).
  • 或者，您也可以传入一个 Handlebars 模板，直接引用一个输出多个词的函数。
    • 例如，如果 {{f_my_filters}} returns ["value1", "value2"]，您可以使用 {{f_my_filters}} 直接在对象集编辑器中。

对象集结果以表格形式返回在字段 data 中，并且还包含字段中的所有对象 RID objectRids.

对象集限制结果

对象集筛选器还允许您设置返回对象数量的上限。这在概念上类似于 SQL 的 LIMIT 子句，可实现更快的测试和迭代。

如果限制小于结果总数， getNextPage 和 getPreviousPage 事件可用于对结果进行分页。在返回大量结果时，这可以提升性能。

聚合

可以使用对象集编辑器在 平台 选项卡中对对象集进行简单聚合计算。要创建聚合，请开启 聚合 位于 输出选项 并选择 添加聚合。聚合基于上述定义的结果对象集。

聚合可以使用以下聚合类型之一：计数、平均值、求和、最大值、最小值或基数。在计算除计数以外的聚合时，必须选择一个数值属性。

您可以通过选择以下选项，基于一个对象集计算多个聚合 添加聚合。使用聚合时，预览将仅显示聚合的结果。但是，在函数、Widget 以及 Slate 的其他部分中通过 handlebars 引用对象集时，仍可访问具体的对象。

多维聚合

要对多个维度的对象集数据进行聚合（例如包含“分组依据”或分段），需要编写一个 函数 (TSv1) ，以便在为生成的桶计算指标之前对数据进行分组和分段。

这些函数返回 聚合类型 Slate 会将其解析为用于配置图表和其他 Slate widget 的并行列表数据结构。

直方图 有关如何调用 Foundry 函数的文档 中进一步详细介绍了这些来自 Slate 的交互。

对象集排序

结果对象集可以按任意参数以升序或降序排序。可以为排序配置多个属性，排序属性从上到下依次应用。限制设置仅在排序之后生效。

对象集 RID 模式

在对象集 RID 模式中，Slate 的对象集面板能够接收 object set RID 以及一个 versioned object set RID 并将其解析回 Slate 的数据数组格式。

这意味着除了使用 Slate 的参数化对象集构建器之外，您还可以灵活地传递 RID。
