管理访问权限

谁可以在 Control Panel 中管理权限？

被授予 Enrollment 管理员 角色的用户可以在 选项卡 标签页中管理其注册的权限。相反，被授予 组织管理员 角色的用户可以在 组织权限 标签页中管理其组织的权限。未被授予这些角色的用户将无法访问这些标签页。

为什么我在 Control Panel 中看不到某个设置标签页？

Control Panel 中的设置以侧面板上的标签页形式呈现，并按注册/组织级别分组。这些设置标签页仅对拥有相关权限的用户可见。例如， 身份验证 标签页需要 管理 SAML 提供商 工作流。

如果您在 Control Panel 中无法看到某个特定的设置标签页，可以通过点击侧面板中的搜索或使用 Cmd+J（MacOS）或 Ctrl+J（Windows）键盘快捷键来打开搜索对话框，然后搜索相关设置。如果您看到类似如下消息 Contact your organization administrator to grant you access （如下所示），请让管理您注册/组织权限的人员为您授予正确的角色。

在某些情况下，您可能会看到类似如下消息 Contact Palantir Support to unlock these settings，这表示该功能处于测试版或限量发布阶段。

如果您不确定应授予哪个角色，请使用 注册/组织权限 中的搜索功能来查找关键词。该搜索将覆盖角色名称、描述和工作流，以及每个角色所启用的设置。

管理组织访问权限

用户可以通过两种方式访问组织：作为用户的 主组织，或作为用户拥有 访客访问权限.

主组织

的组织。每个用户都有一个主组织。用户的主组织可以在创建用户时分配，通过您的 SAML 设置进行映射（可在 Admin > Authentication > Organization assignment获取），或在 用户 界面中管理。

用户的主组织决定：

  • 在用户个人资料中显示的组织。
  • 用户对来自其他组织的用户的可见性。
  • 用户创建的新项目和组的默认组织标记；默认情况下，资源仅限于主组织内的用户访问。

对组织的访客访问

除主组织外，用户还可以被授予对其他组织的访客访问权限。组织的访客是指可以查看该组织中的项目、文件、用户、组、标记类别和收藏集的用户。访客可以是用户或组。

假设用户 Alice 拥有对组织 X 的访客访问权限。对组织 X 的访客访问权限允许 Alice 查看以组织 X 为主组织的用户，但不能查看组织 X 的其他访客用户。以组织 X 为主组织的用户始终可以查看组织 X 的访客用户，除非 用户可见性 对组织 X 已禁用。

您可以在 访客成员资格 Ontology Manager 组织权限 页面预览同步的数据。
