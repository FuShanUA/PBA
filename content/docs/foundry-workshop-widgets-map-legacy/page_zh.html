Map [Legacy]

旧版

Map [Legacy] 目前处于 旧版 阶段，预计不会再进行额外开发。仍提供全面支持。我们建议在构建新模块或更新现有工作流时使用新的 Map 组件。

Map [Legacy] 与 Map 的对比

该 Map 组件是大多数用例的推荐选择，因为它提供了更强大的功能和更现代的界面。但是，对于较新的 Map 组件不支持的用例，Map [Legacy] 组件可能仍然有用。以下是这两个组件的对比，可帮助您决定使用哪一个：

组件要求Map [Legacy]Map
大规模对象集有限支持支持
时间相关的样式不支持支持
针对复杂几何图形的优化性能不支持支持
移动端兼容性支持不支持
非 WebGL 环境支持不支持

请考虑在新项目中或更新现有配置时过渡到 Map 组件，因为它通常能提供更好的性能和持续的功能更新。

Map [Legacy] 概述

Map [Legacy] 组件以简化的地理空间可视化方式显示对象数据。

这些地图可视化由两种类型的图层组成：

  • 基础图层： 该图层也称为切片图层，提供背景地图图像。
  • 叠加图层： 在基础图层之上将数据表示为点或形状。

Map [legacy] 小部件支持使用 MapboxGL ↗进行地图渲染。如果用户的浏览器不支持 WebGL，地图将使用 Leaflet ↗进行渲染。

Map [legacy] 小部件使用 Mapbox 作为其底图影像的主要来源，并为无法代理 Mapbox 的安全网络支持自定义底图影像来源。要了解有关 Web 地图技术的更多信息，请参阅 Mapbox 文档 ↗。

图层类型

在 Map [Legacy] 小部件中，叠加图层在地图的基础图层之上将数据表示为点或形状。Map [Legacy] 小部件包含以下类型的叠加图层：

  • 点
  • 聚合
  • 分区统计图
  • 线段
  • 静态
  • 已保存

点

点 图层使用点或标记来表示地图上的单个对象，这些对象通过以经纬度对形式存储的 geopoint 属性进行绘制。可以根据所绘制对象的属性为点设置颜色、图标类型和大小的样式。

有关配置信息，请参阅下方的 配置点图层 部分。

示例：一张地图，以点的形式显示医院位置，并按可用医院床位数着色。

聚类

聚类 图层非常适合基于 geopoint 位置属性的大型对象集。聚类与点类似，但并非为每个对象绘制单个标记，而是根据对象与聚类之间的地理邻近度，对要绘制的对象进行聚合。可以配置聚类的大小和/或颜色，以表示给定区域内对象的数量，或者表示其他聚合函数的结果，例如某个区域内所有对象的某个属性的总和或平均值。

有关配置信息，请参阅 配置聚类图层 部分。

示例：一张地图，显示全国范围内气象站的总体地理分布。

分区统计图

Map [Legacy] 小部件的 分区统计图 图层会显示国家或省份等区域，并根据该区域所代表对象的某个属性或聚合值对这些区域着色。这提供了一种可视化不同区域之间差异或模式的方法，还可以选择查看这些值随时间的变化情况。

有关配置信息，请参阅 配置分区统计图图层 部分。

为了支持在函数中对 H3 六边形进行自定义聚合，还可以使用分区统计图层将 H3 六边形映射为单独的区域。请参阅下方的 为 H3 配置分区统计图层 章节。

示例：各州的地图，其中每个州按其人口密度着色。

线段

线段 图层将各个对象绘制为连接两点的线段。

有关配置信息，请参阅下方的 配置线段图层 章节。

示例：显示航线的地图，其中出发机场与目的地机场通过表示航线的线条连接。

静态

静态 图层显示无法动态筛选的信息，这些信息来自对象数据以外的数据源。这些图层通常最适合用于提供背景信息，以便为同一地图上的其他数据图层提供上下文。该图层的数据可以采用 GeoJSON ↗ 格式提供，或通过矢量图层提供。

有关配置信息，请参阅下方的 配置静态图层 章节。

示例：显示各区域发生恶劣天气事件风险的图层。

已保存

已保存 图层显示在 地图图层编辑器 并保存为独立的资源。这些图层可以跨多个应用程序共享，并且通常用于在 Foundry 中以一致的方式提供背景信息。

核心配置

以下示例展示了一个新添加且尚未配置的 Map [Legacy] 部件及其配置面板。

对于 Map [Legacy] 部件，核心配置选项如下：

  • 地图样式： 此设置控制所显示的底图瓦片。
    • 默认情况下，这些瓦片从 Mapbox 加载，相关使用已由现有的企业许可证涵盖。Mapbox 的瓦片支持多种主题，包括 Light、Dark、Satellite 等。
    • 或者，您也可以通过 Internal 设置选择自定义瓦片源；有关配置自定义地图样式/底图瓦片源的更多详细信息，请联系您的 Palantir 代表。
  • 地图视口： 您可以选择让地图自动缩放以适应可见数据的范围，也可以选择在地图首次加载时使用预先配置的视口。
    • 缩放以适应： 地图将自动缩放以适应可见数据的边界，并会随数据变化（例如，由筛选导致的变化）自动调整。
      • 最大自适应缩放级别： 此设置用于设定地图自动缩放的最大缩放级别。
    • 初始视口： 初始加载时显示的预配置视口；使用此设置时，除非重新加载页面或标签页，否则地图的视口不会被重置。
  • 图例： 有多种与图例相关的配置设置：
    • 是否显示或隐藏整个图例
    • 位置和方向
    • 图例是否可折叠（以节省地图上的空间）
    • 可切换图层： 最终用户是否可以自行显示/隐藏各个地图图层
  • 数据图层： 一个 数据图层 是基于对象集的地图图层。数据图层类型包括点、聚类、分区统计图和线。每种类型都有各自特定的设置，但所有数据图层都共享以下配置选项：
    • 要映射的对象集： 这是数据层的输入变量，用于确定将在地图上显示的数据。这使得模块构建者可以定义新的对象集变量，或复用在 Workshop 模块中其他位置创建的现有对象集变量。
    • 选择、可见性和事件配置： 请参阅下方的 配置选择、可见性和事件 部分以了解更多信息。请注意，这些配置选项显示在图层配置窗格的底部附近。
    • 以下是有关其他特定于图层的配置选项的更多详细信息：
      • 点图层配置
      • 聚合图层配置
      • 分级统计图层配置
      • 线图层配置
  • 静态图层： 数据图层与静态图层之间的主要区别在于，静态图层不 需要 对象集即可显示。因此，静态图层无法进行动态筛选。可以将静态图层配置为与对象集建立连接（但这并非必需），这样当鼠标悬停在静态图层的某个区域上时，就会显示本体论中相应对象的详细信息。请参阅 静态图层配置 部分以了解更多信息。
  • 启用在地图上绘制形状： 此设置决定了在地图上绘制形状的能力。当此配置选项设置为 Yes时，将显示更多详细信息。欲了解更多信息，请参阅以下 配置绘图控件 部分。
  • 包含时间步进器： 此设置显示地图在不同时间/日期时刻的状态。当此配置选项设置为 Yes时，将显示更多详细信息。欲了解更多信息，请参阅以下 配置时间步进器控件 部分。
  • 已发布的视口筛选器： 此设置有助于根据小部件中地图的可见边界来筛选对象集。欲了解更多信息，请参阅以下 配置视口筛选控件 部分。
  • 启用常规位置搜索： 启用后，用户将在其地图的左上角看到一个搜索图标，可用于搜索世界上的任何位置或地址。用户可以放大地图并在指定位置设置标记。搜索结果的标题和地理坐标点数据将存储在一个字符串变量中，必须先初始化该变量，标记才能显示在地图上。
  • 显示用户当前位置： 启用后，用户的当前位置将根据其设备的地理位置信息显示在地图上。若要让用户能够缩放至其当前位置，可启用一个额外的按钮，该按钮将显示在地图的左下角。请注意，并非所有设备和浏览器都支持此设置。

配置点图层

对于点图层，主要配置选项如下：

  • 地理点属性： 正在映射的对象集上的地理点属性类型，其中包含用于指示集合中每个对象位置的地理点（经纬度对）。
  • 搜索结果页数： 此项决定将要加载的对象数量。最多可加载 10,000 个对象。
  • 图例标题： 描述用例/系列的图例标签。
  • 样式设置： 允许为每个点配置 图标类型、 颜色和 大小 ，其中每一项均可设置为静态样式，或根据与每个点对应的对象上所选属性的值设置为动态数据驱动样式。有关配置的更多详细信息，请参阅下方的 非聚合值系列配置 和 颜色配置 部分。
  • 要在对象预览中显示的属性： 悬停/单击每个点时显示的工具提示可以显示任意一组已配置的属性（例如 prominent、 specific或 none）。
  • 点连接配置： 允许用线连接各个点，前提是数据可排序。此配置选项在设置为 用线连接后会显示更多详细信息。
    • 排序属性类型： 用于对点进行排序的属性；排序顺序决定哪些点相互连接。
    • 排序顺序： 对点进行排序的顺序。
    • 颜色： 连接各点的线条颜色。
    • 宽度： 连接各点的线条宽度。
    • 描边： 连接各点的线条描边。

配置聚类图层

对于聚类图层，主要配置选项如下：

  • 地理点属性： 所映射对象集上的地理点属性类型，其中包含用于指示集合中每个对象位置的地理点（经纬度对）。定义聚类时会考虑附近的地理点。
  • 聚合： 允许配置聚合，以计算每个聚类应显示的值。例如，下方截图展示了一个聚类图层的配置，该图层显示美国机场的离港航班总数（效果类似于上方显示的地图）。请参阅 聚合值系列配置 以下章节，了解有关配置的更多详情。

  • 大小配置： 允许定义聚类大小，既可以是单一大小（均匀聚类），也可以是动态大小（根据上述配置的聚合返回的值进行缩放）。
    • 单一大小： 聚类将具有统一的大小。
      • 大小： 聚类的大小。每个聚类将具有统一的大小。
      • 图例标签： 定义用例/系列的标签。
    • 按值自动缩放： 聚类大小将基于底层数值。
      • 刻度类型： 用于计算聚类大小值的数学刻度类型（例如线性、对数或平方根）。如果您的数据非常偏斜，则对数或平方根缩放可能比线性缩放更适合。
      • 最大下界： 自动计算的刻度所允许的最高下界。如果存在低于此界限的数据值，刻度将扩展以包含这些值。
      • 最小上界： 自动计算的刻度所允许的最低上界。如果存在高于此界限的数据值，刻度将扩展以包含这些值。
  • 颜色配置： 允许定义簇的颜色。簇既可以统一着色，也可以根据值着色。有关更多配置详情，请参阅下方的 颜色配置 章节。
  • 不透明度配置： 允许为簇定义单一且统一的不透明度。
  • 图例标签： 定义用例/系列的标签，显示在图例中。
  • 值格式化程序： 允许以不同的格式表示值。例如，若要将值表示为百分比，请将 % 设置为值格式化程序。指定的值应为 d3-format 字符串 ↗。

配置分区统计图层

对于 分区统计图层，主要配置选项如下：

  • 图例标题： 此标题位于该图层图例部分中系列级图例标题的上方。图层中的每个系列都可以选择提供图例标题。
  • 分区统计图层配置： 分区统计图层和线图层可以是 聚合 或 非聚合。 所有分区统计图层通常都会显示某种类型的区域，例如国家或省份；两种聚合类型的区别在于，输入对象集中的每个对象是否对应一个给定区域（非聚合），还是一个给定区域内可能包含一个或多个对象（聚合）。
    • 聚合： 显示区域(例如国家或省份),这些区域的颜色基于对由该区域所表示的对象执行的聚合结果。例如,基于一组输入费用显示每个国家成本与数量之比的地图。
      • 区域 ID 属性类型: 允许选择一个 区域 ID 属性。聚合将在此属性上执行,以计算每个区域中的数据值。此 区域 ID 属性的值必须与下方所选边界源的区域 ID 完全匹配,这一点至关重要。
      • Choropleth 边界源: 允许选择图层的边界源。下面 choropleth boundary source 列出了三种受支持的源的详细信息: Mapbox、 GeoJSON和 Vector。
      • 聚合值配置: 允许定义一个聚合系列列表,其中在每个系列中,所绘制的对象会根据其区域 ID 进行聚合。区域颜色可配置为表示给定区域中的对象数量,或表示其他聚合函数的结果,例如某个区域内各对象某项属性的总和或平均值。有关更多配置详情,请参阅下方 聚合值系列配置 和 颜色配置 部分。
    • 非聚合: 显示根据各区域所表示对象的 属性值 进行着色的区域。例如，一张包含美国各州的地图，其中每个州按其人口密度着色，而人口密度是州对象类型上的一个属性类型。
      • 区域 ID 属性类型： 允许选择 区域 ID 属性。该属性值用于唯一标识每个区域，也是在选择“区域”时进行筛选所依据的属性。请务必确保此 区域 ID 属性的值与下方所选边界源的区域 ID 完全匹配。
      • Choropleth 边界源： 允许选择图层的边界源。下面 choropleth boundary source 是三种受支持来源的详细信息： Mapbox、 GeoJSON和 Vector。
      • 非聚合值配置： 允许定义非聚合系列列表，其中每个系列的区域颜色均可配置，以表示所绘制对象的属性值。有关更多配置详细信息，请参阅下方的 非聚合值系列配置 和 颜色配置 章节。
      • 搜索结果页数： 这决定了将加载的对象数量，其中每页为 1000 个对象。每个非聚合图层最多可加载 10,000 个对象（10 页）。
      • 要在对象预览中显示的属性： 悬停/点击每个点时显示的工具提示可以显示任意一组已配置的属性（例如 prominent、 specific或 none）。 等值区域图边界源： 要配置等值区域图层，您必须指定用于定义所显示区域的边界来源。边界数据有多种可能的来源：
  • Mapbox 源： 这是配置等值区域图的最简单方法，前提是您希望显示世界各地的通用区域（例如国家、州、县等）。此选项利用了 Mapbox 企业边界集 ↗。了解如何 在您的 Foundry 实例上安装 Mapbox 边界数据集。
    • Mapbox 企业边界版本： 目前支持两个 Mapbox 版本（V3 和 V4）。我们建议使用 V4 以获取最新的边界。
      • Mapbox 源配置 ID： 允许选择 边界类型和数据级别 ↗。Mapbox Boundaries 数据根据边界所服务的功能分为五大类型： admin、 legislative、 locality、 postal 以及 统计数据。在每个边界类型中，要素按不同编号的级别组织成层次结构。通常，编号较大的级别会嵌套在编号较小的级别之下。例如，在美国，县（admin level 2）是州（admin level 1）的细分，而州又是国家（admin level 0）的细分。
        • 该 区域 ID 属性类型必须与该图层所需的 Mapbox 要素 ID 相匹配，无论您选择哪种边界级别。这些要素 ID 值的映射关系可通过已导入的数据集获取，该数据集应已存在于平台上。如果您不知道如何找到这些映射关系，请联系您的 Palantir 代表。
      • Worldview: 该 功能 ↗ 会在存在多个版本的边界时，为不同的受众渲染地图边界；当前可用的选项包括美国、日本、印度和中国。
  • GeoJSON 数据源： 如果您有通过 GeoJSON 定义的简单自定义区域，或者无法从您的环境中访问 Mapbox API（例如，由于网络限制），则此选项非常有用。此选项利用 GeoJSON ↗ 格式的数据。
    • 聚合 GeoJSON： 允许以单个 GeoJSON 文件（上传至项目）的形式定义边界集。如果形状数量或形状复杂度的规模总体较低、要绘制的对象规模较大，且每个区域可能代表一个或多个对象（因此对象会被聚合），则此选项最为理想。
      • GeoJSON 源 RID： 已上传的 GeoJSON 文件的资源 RID。
      • 区域 ID 要素属性： GeoJSON 中包含每个区域 ID 的属性 ID。GeoJSON 中的这些值将与对象上的区域 ID 属性（在上方定义）进行匹配。
      • 区域显示名称要素属性： GeoJSON 中包含每个区域显示名称的属性 ID。
    • 非聚合 GeoJSON： 允许选择输入对象的 geoshape 属性，该属性包含地图上每个区域/对象的 GeoJSON。如果形状规模或形状复杂度较高，但对象规模仍然可控，则此选项最为理想。每个对象只能对应一个形状，且每个形状只能对应一个对象。
      • GeoJSON 几何属性类型： 定义 GeoJSON 几何图形的属性类型（支持类型为 geoshape 或 string）。
  • 矢量数据源： 如果您的自定义边界定义高度详细或规模极大，则此选项最为有用，因为与基本 GeoJSON 相比，矢量数据源能够提供性能优势。此选项要求通过瓦片服务器托管矢量数据源（可以是内部或外部瓦片服务器）。
    • 源 URL： 托管在某个瓦片服务器上的瓦片集的完整 URL。
    • 图层名称： 给定的已配置瓦片源中矢量图层的 ID。
    • 区域 ID 要素属性： 每个矢量要素内包含各区域 ID 的属性 ID。矢量要素中的这些值将与对象上的区域 ID 属性（如上文所定义）进行匹配。
    • 区域显示名称要素属性： 每个矢量要素内包含各区域显示名称的属性 ID。仅聚合矢量数据源支持此属性。
    • 最小缩放： 如果地图缩放级别低于最小缩放级别，则不会查询瓦片源（且不会显示该图层）。
    • 最大缩放： 如果地图缩放级别高于最大缩放级别，则不会查询切片源（且图层不会显示）。

import { Function, Double, FunctionsMap} from "@foundry/functions-api";
import { Objects, ObjectSet, CovidPositive, CovidTest, H3Hexagon} from "@foundry/ontology-api";


export class MyFunctions {

    @Function()
    public async calculateCovidPositivityRate(hexes: ObjectSet<H3Hexagon>,
                                       positives: ObjectSet<CovidPositive>,
                                       tests: ObjectSet<CovidTest>): Promise<FunctionsMap<H3Hexagon, Double>> {
        const map = new FunctionsMap<H3Hexagon, Double>();
        // Set max buckets to 6000 to allow aggregations for all H3 hexagons and resolution 2
        const max_buckets = {maxBuckets: 6000}

        const positives_bucketed = await positives
            .groupBy(positive => positive.hex_index.exactValues(max_buckets))
            .count();

        // Convert the results to a map to make the lookup more efficient than a bucketed array
        const positives_hex_map = new Map();
        positives_bucketed.buckets.forEach((bucket: any) => {
            positives_hex_map.set(bucket.key, bucket.value);
        });

        const tests_bucketed = await tests
            .groupBy(test => test.hex_index.exactValues(max_buckets))
            .count();

        const tests_hex_map = new Map();
        tests_bucketed.buckets.forEach(bucket => {
            tests_hex_map.set(bucket.key, bucket.value);
        });

        hexes.all().forEach(hex => {
            const positive_count = positives_hex_map.get(hex.hex_index);
            const test_count = tests_hex_map.get(hex.hex_index);
            if ((positive_count !== undefined) && (test_count !== undefined)) {
                map.set(hex, positive_count/test_count * 100);
            }
        });

        return map;
    }
}

配置线段图层

对于 线图层，主要配置选项如下：

  • 图例标头： 在此图层的图例部分中，位于系列级图例标题上方的标题。图层内的每个系列都可以选择提供图例标题。
  • 线图层配置： 与分区统计图一样，线图层可以分为 聚合 或 非聚合。线图层显示某种类型的线段；聚合图层与非聚合图层的区别在于，输入对象集中的每个对象是否对应于某条给定的线（非聚合），还是一个或多个对象可以对应于某条给定的线（聚合）。
    • 聚合： 显示的线会根据该线所表示的一个或多个对象的聚合结果进行着色。例如，一张显示某条给定航线上所有航班平均延误时间的地图。
      • Segment ID 属性类型： 允许选择 Line Segment ID 属性。系统将基于该属性执行聚合，以计算所显示每条线的数据值。此 Segment ID 属性的值必须与下方所选线图层源的要素 ID 完全匹配。
      • 线图层源： 允许选择图层的线源。以下 line layer source 是聚合线图层所支持的两种源的详细信息： GeoJSON 和 矢量。
      • 聚合系列配置： 允许定义聚合系列列表，其中在每个系列中，所绘制的对象会根据其分段 ID 进行聚合。线条的颜色可配置为表示给定线条的对象数量，或表示其他聚合函数（例如线条内各对象的某个属性的总和或平均值）。有关更多配置详情，请参阅下文的 聚合值系列配置 和 颜色配置 部分。
    • 非聚合： 显示根据该线条所表示对象的 属性值 来着色的线条。例如，一张显示电力线路的地图，按线路的当前运行状态着色。
      • 分段 ID 属性类型： 允许选择 分段 ID 属性。该属性值唯一标识每条线，并且是选择“线”时用于筛选的属性。此 分段 ID 属性的值必须与下方所选线图层源的要素 ID 完全匹配，这一点至关重要。
      • 线图层源： 允许选择图层的线源。下面 line layer source 详细介绍了三种受支持的源： 点对点、 GeoJSON和 矢量。
      • 非聚合系列配置： 允许定义非聚合系列列表，其中每个系列的线条颜色均可配置，用于表示所绘制对象的属性值。有关更多配置详情，请参阅 非聚合值系列配置 和 颜色配置 章节。
      • 搜索结果页数： 此设置决定将加载的对象数量，每页为 1000 个对象。每个非聚合图层最多可加载 10,000 个对象（10 页）。
      • 在对象预览中显示的属性： 悬停/点击每个点时显示的工具提示可显示任意一组已配置的属性（例如 prominent、 specific或 none）。 线图层来源： 以下是加载源信息以指定线条如何绘制在线图层上的不同方法：
  • 点到点： 对于输入对象集中的每个对象，此方法将在提供的起点和终点地理点之间绘制一条直线。请注意，此选项仅适用于非聚合线图层。
  • GeoJSON 源： 如果您有通过 GeoJSON 定义的简单自定义线条，或者您的环境中无法访问 Mapbox API（例如由于网络限制），则此选项非常有用。此选项利用 GeoJSON 中的数据（https://geojson.org/) 格式。
    • 聚合 GeoJSON： 允许以单个 GeoJSON 文件（上传至 Foundry）的形式定义线路。当线路数量/线路复杂度的规模总体较低、要绘制的对象规模较高，且每条线路可表示一个或多个对象（即对象被聚合）时，此选项最为理想。
      • GeoJSON 源 RID： 已上传 GeoJSON 文件的资源 RID。
      • 区域 ID 要素属性： GeoJSON 中包含每条线路要素 ID 的属性 ID。GeoJSON 中的这些值将与对象上的分段 ID 属性（在上方定义）相匹配。
      • 区域显示名称要素属性： GeoJSON 中包含每个线路分段显示名称的属性 ID。
    • 非聚合 GeoJSON： 允许选择输入对象的 geoshape 属性，其中包含地图上每条线路的 GeoJSON。当线路规模或线路复杂度较高、但对象规模仍可控时，此选项最为理想。每个对象只能对应一条线路，同样，每条线路也只能对应一个对象。
      • GeoJSON 几何属性类型： 定义 GeoJSON 几何图形的属性类型（支持类型为 geoshape 或 string）。
  • 矢量数据源： 如果您的自定义线条定义高度详细或规模非常大，则此选项最为有用，因为与基本 GeoJSON 相比，矢量数据源具有性能优势。此选项要求矢量数据源通过切片服务器进行托管（可以是内部的，也可以是外部的）。
    • 源 URL： 托管在某个切片服务器上的切片集的完整 URL。
    • 图层名称： 指定的已配置切片源中矢量图层的 ID。
    • 区域 ID 要素属性： 每个矢量要素中包含每条线 ID 的属性 ID。矢量要素中的这些值将与对象上的分段 ID 属性（如上文所定义）进行匹配。
    • 区域显示名称要素属性： 每个矢量要素中包含每条线显示名称的属性 ID。仅聚合矢量数据源支持此选项。
    • 最小缩放： 如果地图缩放级别低于最小缩放级别，则不会查询切片源（且图层不会显示）。
    • 最大缩放： 如果地图缩放级别高于最大缩放级别，将不会查询切片源（且不会显示该图层）。

@Function()
    public costToVolume(expenses: ObjectSet<Expense>): FunctionsMap<string, Double> {
        const map = new FunctionsMap<string, Double>();
        const costsPerCountry = expenses
            .groupBy(expense => expense.countryId.topValues())
            .sum(expense => expense.cost);
        const volumePerCountry = expenses
            .groupBy(expense => expense.countryId.topValues())
            .sum(expense => expense.volume);
        costsPerCountry.buckets.forEach(bucket => {
            var volume = volumePerCountry.buckets.find(b => b.key === bucket.key);
            map.set(bucket.key, bucket.value / volume);
        });
        return map;
    }

  • 图层 Z 索引： 此选项控制重叠图层的显示顺序。工具提示内容和选择交互将优先为 z-index 较高的图层显示。
  • 启用单选模式： 将此选项切换为 True 将禁用一次选择多个对象的功能。每次后续选择都会移除之前的选择。
  • 初始隐藏： 将此选项切换为 True 将允许图层在首次加载地图时隐藏。如果该图层属于某个组，则以第一个图层配置的设置为准。
  • 图层组名称： 允许将图层分组，并在图例的下拉列表中一起显示。
  • 对象集选择筛选器： 在地图上进行选择时发布的筛选器。
  • 选择时的事件： 允许配置 Workshop 事件 （例如使抽屉展开），以在地图上进行选择时触发。
  • 可见性条件： 允许根据 Workshop 变量的状态/值对此图层的可见性进行条件控制。默认情况下，如果未配置任何条件，则始终显示该图层。

对于 绘图控件，核心配置选项如下：

  • 半径/圆形控件： 将控件设置为可见后，您可以在地图上绘制一个 圆形 形状，并显示半径。要绘制圆形，请选择左上角的圆形按钮，在地图上任意位置单击以设置圆心，释放鼠标按键，然后将鼠标从圆心处移开。
    • 控件按钮选项：
      • 工具提示标签： 当光标悬停在左上角的圆形按钮上时提供标签。
      • 是否禁用： 将此项设置为 true 会禁用圆形按钮。
    • 形状样式选项：
      • 填充颜色： 设置所绘制形状的颜色。默认颜色为 #F29D49，即浅橙色的十六进制代码。
      • 填充不透明度： 设置所绘制形状的不透明度，范围从 0 到 1，其中最大不透明度为 1。
      • 边框颜色： 设置所绘制形状的边框颜色。默认颜色为 #F29D49，即浅橙色的十六进制代码。
      • 边框不透明度： 设置所绘制形状的边框不透明度。
      • 距离单位： 显示所绘制圆形的半径时使用的单位。可用选项包括千米、米、英里、码和英尺。
  • 多边形控件： 将控件设置为可见后，您可以在地图上绘制 多边形 形状。要绘制多边形，请先选择左上角的多边形按钮，然后在地图上点击。每次点击都会标记多边形的一个点，边将在连续两点之间绘制。
    • 控制按钮选项：
      • 工具提示标签： 当光标悬停在左上角的多边形按钮上时，会显示标签。
      • 是否禁用： 将其设置为 true 会禁用多边形按钮。
    • 形状样式选项：
      • 填充颜色： 设置所绘制形状的颜色。默认颜色为 #F29D49，这是浅橙色的十六进制代码。
      • 填充不透明度： 设置绘制形状的不透明度，范围为 0 至 1，其中最大不透明度为 1。
      • 边框颜色： 设置绘制形状的边框颜色。默认颜色为 #F29D49，这是浅橙色的十六进制代码。
      • 边框不透明度： 设置绘制形状的边框不透明度。
      • 距离单位： 千米、米、英里、码和英尺是各种可用的选项。
  • 删除控件： 将控件设置为可见后，即可删除地图上绘制的形状。要删除绘制的形状，请先选择左上角的删除按钮，然后点击该绘制的形状。
    • 控制按钮选项：
      • 工具提示标签： 当鼠标悬停在左上角的删除按钮上时提供标签。
      • 是否禁用： 将此项设置为 true 会禁用删除按钮。
  • 单次绘制模式： 启用后，地图上一次只能绘制一个形状，绘制新形状时会删除旧形状。
  • 已发布的筛选器： 输出一个对象集筛选器变量，用于根据绘制形状的边界对正在映射的对象集进行筛选。
  • 已发布的绘制几何图形： 此选项允许将绘制的形状几何图形发布到字符串变量。这使您能够将绘制的形状几何图形写入新属性。
  • 绘制时的事件： 此选项控制在地图上绘制形状时触发一个或多个 Workshop 事件。

配置时间步进器控件

Map [Legacy] 小部件内置了一个 时间步进器 ，允许用户在时间上向前和/或向后“步进”，以查看地图上的数据如何随时间变化。

时间步进器的工作原理是将对象集筛选器（与用户所选的时间窗口相对应）发布到已配置的对象集筛选器变量。此筛选器变量可用于筛选支撑地图上所显示一个或多个图层的对象集，以便仅返回与该时间窗口相关的对象。

为了充分利用时间步进器，我们建议所使用的时序对象包含按某个时间单位记录测量值的对象。每个对象都应具有可用于筛选的日期或时间戳属性，以便在筛选给定时间窗口时，能够加载单个对象（或聚合该窗口中的对象），从而获取要在地图上显示的数据。

时间步进器的核心配置选项如下：

  • 时间步进器类型： 此选项允许基于日期或时间戳设置时间步进器。
  • 默认窗口开始日期（时间戳）： Map [Legacy] 部件首次加载时的默认日期（时间戳）。
  • 最小窗口开始日期（时间戳）： 用户可选择的日期（时间戳）范围的下限。
  • 最大窗口开始日期（时间戳）： 用户可选择的日期（时间戳）范围的上限。
  • 显示关于投影的警告： 当时间步进器处于未来时间时显示的信息按钮的可配置文本。
  • 显示关于历史数据的警告： 当时间步进器处于过去时间时显示的信息按钮的可配置文本。
  • 信息图标工具提示文本： 用于帮助向用户传达信息的工具提示文本。
  • 已发布筛选器： 输出一个对象集筛选器变量，允许根据时间步进器中选择的日期（时间戳）范围对正在映射的对象集进行筛选。
  • 小步长： 允许配置小步长的行为。这定义了点击小步长时时间将回退/前进的幅度。
  • 大步长： 允许配置大步长的行为。这定义了点击大步长时时间将回退/前进的幅度。
  • 窗口大小： 定义从开始日期起的日期（时间戳）范围。例如，对于基于日期的时间步进器，如果开始日期是1月1日 ，且窗口大小为1天，则所选日期范围将从1月1日 到1月2日 。

配置视口筛选器控件

以下屏幕截图展示了一个 视口筛选器的配置示例。

视口过滤器会输出一个对象集过滤器变量；这允许根据小部件中地图的可见边界，对正在映射的对象集进行过滤。例如，对于一个映射了机场位置的地图，如果用户缩放到美国，视口过滤器将生成一个过滤器变量，允许将对象集过滤为仅包含美国机场的对象。

要使分级统计（choropleth）图层使用视口过滤，正在映射的对象类型需要具有地理点（geopoint）属性；该属性可以是该区域的质心。
