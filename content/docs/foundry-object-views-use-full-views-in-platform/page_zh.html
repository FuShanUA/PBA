使用完整对象视图

完整对象视图可全面展示对象的数据。它们是对象在平台内的主要视图，可在平台应用程序中访问，也可嵌入到自定义 Workshop 应用程序中。

Workshop

Workshop 的对象视图组件 可在自定义 Workshop 应用程序中显示详细的对象视图。当配置为显示完整对象视图时，该组件通常用于叠加层或模态窗口中，以适应完整页面的分辨率。

Object Explorer

在 Object Explorer中，您可以搜索对象，然后将其选中以打开完整对象视图，从而提供有关本体论中所定义对象的详细信息。

平台应用程序

诸如 Vertex、Maps 和 Gaia 之类的应用程序使用面板对象视图，为所选对象提供可自定义的紧凑视图。在面板中，选择对象的标题将在可移动且可调整大小的模态窗口中打开完整对象视图。
