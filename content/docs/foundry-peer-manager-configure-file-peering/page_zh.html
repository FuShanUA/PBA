配置文件对等互连

在您 建立两个空间之间的对等互连关系之后，您可以使用 Peer Manager 来配置文件对等互连。文件对等互连使您能够将 Gotham 文件（例如 Gaia 地图）通过对等连接在您的注册与另一个注册之间进行同步。

若要在空间之间实现文件对等互连，您的注册必须同时使用 Foundry 和 Gotham。

如有关于 Gotham 文件或平台中提供的附加文档的问题，请联系 Palantir 支持团队。

为每种文件类型启用文件对等功能

在能够通过对等连接对等传输文件之前，请先在 Peer Manager 中导航到相应连接并选择 设置 （位于顶部功能区）以确保 该连接的设置 已启用文件导出和导入。

配置对等连接的文件导出和导入设置后，请选择 文件 以设置每种文件类型所需的对等行为。请选择一个 文件类型 (可在 文件对等 面板中找到),即可在屏幕右侧的抽屉式弹出窗口中打开其配置。

您必须在 两端 (即对等连接的本地端和远程端)上配置文件类型对等行为。

在抽屉式弹出框中，您可以设置文件的 导出选择 以自动导出所有文件，或仅导出基于所应用的标签或时间参数选定的文件。
