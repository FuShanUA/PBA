Vega 图表

Quiver 允许用户使用 Vega 或 Vega-Lite 库创建完全可自定义的交互式可视化。查看 和 和 语法创建完全可自定义的交互式可视化效果。 文档以获取灵感和示例。

Vega 允许您以简洁的 JSON 规范形式创建、保存和共享交互式可视化设计，该规范描述了可视化外观和行为。

Vega 和 Vega-Lite 允许您以简洁的 JSON 规范的形式创建、保存和共享交互式可视化设计，该规范描述了可视化的外观和行为。Vega 支持多种可视化设计，例如：

  • 转换 ↗ and 转换 ↗
  • 地图投影 ↗
  • 坐标轴 ↗
  • 图例 ↗
  • 图形标记 ↗
  • Workshop：全新关联小部件 例如矩形、线条、绘图符号等。

Vega-Lite 是在 Vega 之上构建的更高级语言，为编写常见可视化提供了更简洁、更便捷的方式。我们建议从 Vega-Lite 开始，因为 Vega-Lite 语法比 Vega 更易于阅读、编写和调试。如果 Vega-Lite 的选项不够用，请考虑使用 Vega。

配置 Vega 图表

要配置 Vega 图表，请将鼠标悬停在所需的卡片上，选择 可视化 并在下拉菜单中导航到（或搜索） Vega 图 在下拉菜单中。选择 Vega 图 以打开配置菜单。

在编辑器菜单中，选择配置 Vega 图表或 Vega-Lite 图表。常见可视化的模板（包括气泡图、箱线图、旭日图等）可在 选择模板 下拉菜单中找到，如下图所示。

选择 Vega 图表模板后，系统将提示您通过将相关参数映射到转换表数据源的列来填写所选图表的参数。

填写模板参数后，选择 保存您的更改。 以生成您的 Vega 图表。应用模板时：

  • 凡留空的字段，均使用参数名称作为默认值。
  • 已填写的模板将覆盖编辑器中的任何当前值。

配置数据输入

Vega 图表接受以下数据输入：

  • 转换表： 任何转换表都可用作 Vega 图表的输入。从对象集添加 Vega 图表时，还会自动将一个支撑转换表添加到 分析内容 面板（但不添加到画布）。
  • 数组： 数组会被解析为具有单个命名列的转换表 ARRAY_VALUES.

在其他应用程序中嵌入 Vega 图表

Vega 编辑器包含两个有用的设置，可用于使用 Quiver 仪表板在 Workshop 中嵌入 Vega 图表：

  • 自动缩放图表： 启用自动缩放图表后，您的 Vega 图表将根据提供的数据自动调整以适应卡片尺寸。
  • 默认样式： 向 Vega 规范注入一些自动调整大小和样式配置，使图表外观与 Quiver 卡片样式相匹配。禁用时，Vega 可视化将与公共 Vega 网站上的样式一致。

使用 AIP 配置 Vega 图表

AIP 可以仅使用自然语言中对你所需图表或图表修改的描述，帮助生成 Vega 图表配置。用户只需描述想要创建或修改的图表，AIP 就会根据提示词给出建议，帮助简化容易出错的 Vega JSON 图表配置。

描述所需的 Vega 图表

要使用 AIP，请选择 AIP 配置 （位于 Vega 图表卡片右上角）。然后，提供提示词，选择 组织，并查看 AIP 生成的建议。要接受建议，请选择 保存您的更改。。如果你希望 AIP 提供其他建议，请编辑提示词，然后选择 重新配置。

在下面的示例中，用户向 AIP 提示：“在散点图上显示 ph 与 caffeine 的关系，并在 x 轴 13 处和 y 轴 6 处各画一条红线”。AIP 根据提示词建议了一个图表配置，其中包含两个关注的数值属性（咖啡因和 pH 值）。

要接受 AIP 提议的更新，请选择 保存您的更改。。Vega 图表将基于更新后的 Vega 规范渲染可视化。

在现有图表的基础上构建

AIP 可以识别并区分提示词中包含的抽象概念，并利用这些信息帮助生成或修改 Vega 图表。例如，AIP 可以引用之前生成的图表的特征，让你能够“在现有图表的基础上”进行构建。

在下图中，用户提供的提示词为：“图中的两条线将点分成了 4 个象限。为每个象限着不同的颜色。”AIP 识别出由垂直线和水平线定义的区域是象限，尽管当前图表配置中不包含任何象限的定义或配置。

AIP 准确地生成了符合用户提示词的所需图表，并在初始图表的基础上进行了构建。

使用 AIP Generate 创建 Vega 图表

使用 AIP 生成的 Quiver 分析图表可以包含 Vega 图表。要让 AIP 生成 Vega 图表而不是 Quiver 原生可视化（如折线图或散点图），请在提示词中明确指出 AIP 应返回“Vega 图表”。例如，一个准确的提示词可以是：“使用 vega plot 在散点图上显示 caffeine 与 ph 的关系。”

注意：AIP 功能的可用性可能会发生变化，且不同客户之间可能存在差异。

Vega-Lite 选择

为 Vega-Lite 图表配置选择

Vega-Lite 选择是用于构建交互式可视化的强大且高度可定制的功能。Vega-Lite 库内置支持 选择 ↗，Quiver 中的 Vega-Lite 图表可以配置为将选择输出为转换表。用户可以利用选择数据对下游卡片进行参数化、构建下钻工作流并继续分析。Vega-Lite 选择的行为与对象集图表选择不同，需要进行额外的设置步骤。

Vega-Lite 使用户能够通过 两种类型的选择 ↗:

  • 点 选择：选择单个点，或按住 shift 在画布上选择多个点。
  • 区间 选择：拖动以在画布上选择一个有界的矩形区域。

并非所有 Vega-Lite 图表类型都支持选择。例如，箱线图和置信区间图不支持。请查看下面的 常见问题部分 ，了解已知支持选择的图表类型。

要将图表选择数据输出为转换表，请执行以下步骤：

  1. 打开 Vega 图表卡片的配置面板，并滚动到 选择选项。然后，开启 将点选择输出为转换表 和/或 将区间选择输出为转换表.

  2. 在 Vega 图表的 JSON 编辑器中，向 params 字段添加选择参数。请查看 （位于 Quiver 集合中）以了解更多信息。如需设计灵感和更高级的使用案例，请查看 以了解有关选择参数的更多信息。

    1. 该参数必须命名为 quiverDefaultClick 用于点选择，或 quiverDefaultBrush 用于区间选择。

    2. 设置 type 属性设置为 point 为 quiverDefaultClick，或 interval 为 quiverDefaultBrush.

    3. 指定一个或多个 编码 ↗ 菜单中选择 encodings 属性。这些是您希望在其上进行选择的字段，例如 x, y，或 color。编码决定了值如何被选择以及输出哪些信息。

  3. 做出选择后，将显示一个包含选择数据的卡片页脚。选择 输出选择 以将选择数据输出为转换表。或者，使用 Vega 图表的后续操作菜单并选择 转换 > 新建转换表.

    • 点选择以编码字段和值的表格形式输出，其中每列对应一个字段，每行代表一个选定的点。



    1. 区间选择在字段为连续字段时输出为区间边界的范围（最小值、最大值），在字段为离散字段时输出为值的数组。



与对象集图表不同（在对象集图表中，选择是一种输出过滤后对象集的下钻操作），Vega 图表无法根据当前选择自动过滤输入数据。相反，Vega 图表将输出给定编码的选定值，这些输出可用于手动对输入表构建过滤器。更多信息请查看以下部分： 构建下钻工作流.

自定义选择参数的示例

请参考提供的 Vega 图表模板，以获取常见可视化（例如气泡图和热力网格）中选择设置的其他示例。这些模板可在以下位置找到： 选择模板 配置编辑器中的下拉菜单。

点选择参数的示例

...

  {
    "name": "quiverDefaultClick", // Define point selection parameter
    "select": {
      "type": "point",
      "encodings": ["x"] // Select all points with the same "x" value
    }
  }
],
"encodings": [
  "x": ...
  "y": ...
  "color": {
    "condition": [
      {
        "param": "quiverDefaultClick",
        "empty": false,
        "value": "orange" // Conditionally color selected points
      }
    ]
  },
]


...
"params": [
  {
    "name": "quiverDefaultClick",
    "select": {
      "type": "point",
      "encodings": ["color"] // Select all data with the same "color" encoding
    }
  }
]

区间选择参数的示例

...
"params": [
  {
    "name": "quiverDefaultBrush",
    "select": {
      "type": "interval",

    }
  }

构建下钻工作流

来自 Vega-Lite 图表的选择数据可用于构建下钻工作流，其中图表选择充当过滤器，用户可以基于上游选择继续对数据子集进行分析。以下步骤描述了如何构建下钻工作流。

  1. 按照上述步骤设置选择参数，并将当前选择输出为转换表。



  2. 选择 将列弹出为数组 以将该属性转换为数组。





  1. 使用选定值作为过滤参数，过滤原始转换表的副本（或从中派生转换表的根对象集的副本）。



  1. 过滤后的表现在将根据上游图表选择动态更新。



常见问题与限制

任何类型的 Vega-Lite 图表都可以配置选择吗？

并非所有 Vega-Lite 图表类型都支持选择。尽管 Vega 文档没有提供受支持图表类型的完整列表，但以下是一个非详尽的列表：

  • 支持： 条形图、散点图、热力网格、折线图、饼图（仅支持点选择）、瀑布图（仅支持点选择）、地理坐标投影、GeoJSON 地图（仅支持点选择）
  • 不支持： 箱线图、置信区间图

我可以在单个图表规范中定义多个选择参数吗？

每个图表仅限于一个点选择参数和一个将数据输出到 Quiver 的区间选择参数。这是 Quiver 设置的限制；虽然 Vega 允许定义多个参数（只要它们具有唯一的名称），但只有命名为 quiverDefaultClick 和 quiverDefaultBrush 的参数才会被输出为 Quiver 转换表。

即使我将某个轴添加到了选择参数的编码列表中，也无法选择该轴的子集。这是什么原因？

检查该轴上的值是否在 Vega 规范中被聚合。Vega 不支持对由 Vega 聚合的字段进行选择。例如，如果 y 编码字段包含如下代码片段所示的内联聚合，用户将无法选择 y 轴的子集。

"encodings": {
  "y": {
    "field": $C.field_y,
    "aggregate": "avg"
  },
  ...
}

要在 y 轴上启用选择功能，请先在 Quiver 中聚合数据（例如使用数据透视表），然后再将其传入 Vega。

为什么我会收到 Invalid data selection 错误，即使 spec 编译通过，我在尝试进行选择时仍会出错？

请检查以下内容：

  • 确保所有选择参数都具有非空的 encodings 字段。每个参数必须指定一个或多个编码以输出选择信息。
  • 如果是区间选择，请检查选择参数中定义的编码是否包含非轴字段。Vega 不支持对非轴编码字段（如 color, shape等）进行区间选择。从 encodings 数组中移除这些字段应可解决该错误。

Vega 绘图对象限制

Quiver 中的 Vega 绘图限制为 50,000 个对象。如果您需要可视化超过此限制的数据集，请考虑使用 对象集图表 or 数据集图表，这些图表不受规模限制。
