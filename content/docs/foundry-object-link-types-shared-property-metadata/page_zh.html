元数据参考

共享属性在本体论中由以下元数据表示：

  • 名称： 共享属性的名称。
  • 描述： 有关共享属性的说明文本，任何人都可以在用户应用程序中阅读。例如， start date 共享属性的描述可能是 The day the employee began new hire training。
  • RID： 为 Foundry 中的每个资源自动生成的唯一标识符。属性的 RID 将在整个平台的错误消息中被引用。
  • 基本类型： 指示此属性的值类型，并确定用户应用程序中可用的一组操作。例如， start date 属性的基本类型为 date。用户应用程序将允许您使用此属性配置时间轴小部件。
  • 值格式化： 根据属性的基本类型，可以对属性应用数值格式化、日期和时间格式化、用户 ID 和资源 ID 格式化，从而在用户应用程序中将原始值转换为更易读的形式。详细了解 值格式化。
  • 类型类： 由用户应用程序解释的附加元数据。详细了解 类型类。
  • 渲染提示： 向用户应用程序提供的指示，说明如何渲染该属性，其渲染方式可能与相同基础类型的大多数属性不同。许多渲染提示可用于影响定义该属性的对象类型的重新索引性能。例如，如果您预计不会有任何用户在用户应用程序中对 start date 属性进行搜索或排序，则可以取消选择 searchable 和 sortable 渲染提示，从而提高 Employee 对象类型的重新索引性能。详细了解 渲染提示。
  • 可见性： 向用户应用程序提供的指示，说明应以何种显著程度显示该属性。 prominent 属性将使应用程序优先向用户显示该属性。 hidden 属性将不会出现在用户应用程序中。默认情况下， start date 属性将具有 normal 可见性。
  • 用法： 使用共享属性的对象类型。例如， start date 属性可由 Employee、 Contractor以及本体论中的其他对象类型使用。
