升级

手动升级

当某个安装有可用的新版本时,您可以在安装页面将其暂存以进行升级。该安装将显示 升级 徽章,并出现在右侧的 已选 面板中。

要将多个安装一起暂存并在同一个作业中升级,您可以导航到每个安装页面并将它们添加到已选列表中。选定所有所需的安装后,选择 创建安装作业 以开始升级。

如果您不想升级到最新版本,或者想要降级到较早的版本,可以选择省略号(...)并选择 升级或降级到版本。请参阅 降级 了解更多信息。您还可以 编辑 安装,这将在现有版本上创建另一个安装作业。这可用于编辑输入,或在不更改产品版本的情况下强制重新运行安装作业。

进入升级草稿时,您可能需要填写新的输入或解决升级引起的任何新错误。 输入 页面将显示任何尚未满足的必填输入,以及任何存在阻断错误的输入。

自动升级 [Beta]

Beta

Marketplace 中的自动升级功能处于 beta 开发阶段,可能尚未在您的注册中提供。在开发过程中,功能可能会发生变化。

默认情况下,自动升级对于 Production mode 和 Bootstrap mode 产品处于禁用状态。您可以在 安装设置中配置自动升级设置。自动升级设置包括以下内容:

  • 您希望接收自动升级的 维护窗口 。选择 始终开放 后,即可在升级可用时立即获取升级。升级将导致已安装资源停机;我们建议添加维护窗口以避免停机。
  • 您的安装应跟踪的 发布渠道 。在您配置的任何维护窗口期间,只要升级无需手动操作,您的安装就会自动升级到标记为该发布渠道的版本。

发布渠道是分层而非互斥的。具体取决于所跟踪的渠道:

  • Release: 安装将接收标记为 Release、 Test或 Stable的版本。
  • Test: 安装将接收标记为 Test 和 Stable的版本。
  • Stable: 安装将接收标记为 Stable的版本。

如果新产品版本包含需要映射的新输入，或者出现任何验证错误，则升级仍需要手动操作。如果出现这种情况，系统将引导您完成相同的手动配置工作流程，如同 手动升级。

降级

要将产品降级到以前的版本或升级到特定版本，请先选择安装页面右上角的省略号。然后，选择 升级或降级到版本。

此时将显示一个对话框，您可以在其中选择版本。完成选择后，要启动升级或降级过程，请选择 创建草稿。
