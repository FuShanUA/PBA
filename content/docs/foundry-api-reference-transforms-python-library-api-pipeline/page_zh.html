transforms.api.Pipeline

类 transforms.api.Pipeline

用于对一组对象进行分组的对象 Transform 对象进行语义搜索。

add_transforms(*transforms)

注册给定的 Transform 对象到管道实例。

  • 参数： *transforms (转换) – 要注册的转换。
  • 引发：
    • ValueError – 如果多个 Transform 对象写入到同一个 Output alias.
    • ValueError – 如果多个 Transform 对象具有相同的计算函数引用。

discover_transforms(*modules)

递归查找并导入模块，注册每个模块级别的转换。

此方法从给定模块的 __path__开始递归查找并导入模块。找到的每个模块都会被导入，且任何属于 Transform 实例的属性（由转换装饰器构造）都将被注册到管道。
