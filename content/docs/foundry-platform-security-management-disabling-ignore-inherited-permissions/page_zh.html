迁移并停用"忽略继承权限"设置 [计划弃用]

计划弃用

直方图 忽略继承权限 设置正处于 计划弃用 开发阶段，自 2024 年 12 月起，大多数注册环境已无法使用此功能。仍在使用 忽略继承权限 设置的环境强烈建议按照以下指南迁移此用法，转而使用其他安全功能。

如果您在此迁移过程中需要额外帮助，请联系 Palantir Support。

当在平台上的文件夹或文件上启用"忽略继承权限"设置时，对该文件夹或文件（以及其中的子文件夹和文件）的所有权限都将被撤销，除非这些权限被显式添加到某个文件夹或文件上。例如，授予用户 Viewer Project 上的权限不会自动授予 Viewer 启用了"忽略继承权限"的文件夹上的权限。

在停用"忽略继承权限"设置时，我们建议将文件夹或文件的内容移动到另一个 项目 具有您所需的特定权限，或者将文件夹或文件替换为 标记。Project 和标记是首选工具，因为与"忽略继承权限"设置不同，它们可以明确定义查看底层数据所需的条件。

以下是迁移并停用"忽略继承权限"设置的步骤概要：

  1. 首先在 升级助手 应用程序中选择一个需要迁移的文件夹或文件。
  2. 完成文件夹或文件上所有必需的更新。
  3. 考虑您的迁移选项，并决定哪种最适合您的情况。
  4. 执行迁移。
  5. 在文件夹或文件上停用"忽略继承权限"。
  6. 返回 Upgrade Assistant，确认不再存在与此文件夹或文件对应的待处理操作。

迁移步骤

1. Upgrade Assistant

在 Foundry 中前往 Upgrade Assistant 应用程序，并导航到启用了"忽略继承权限"的特定文件夹或文件。选择该文件夹或文件以开始迁移流程。

2. 完成必需的更新

如果您看到"需要更新"提示，请选择 更新。这样做可以将停用"忽略继承权限"设置的过程与停用并迁移"传播查看要求"设置的额外要求分开。了解更多关于此 额外必需迁移.

3. 选择迁移方式

有多种不同的方法可以迁移并停用"忽略继承权限"设置。您选择的方法取决于数据的敏感程度、平台上已存在的 Project 和标记，以及您企业的安全架构。以下是迁移选项列表，以及您应该提出以帮助决定后续步骤的问题：

  • 停用该权限： 此文件夹或文件是否需要与其父 Project 不同的权限？启用"忽略继承权限"是否出于已不再相关的历史原因？如果是这种情况，您可以停用"忽略继承权限"。
  • 移动到另一个 Project： 是否存在另一个 Project 使用了您在此文件夹或文件上强制执行的更严格权限？目标 Project 是否拥有相似的用户群体？如果是，您可以将此文件夹或文件的内容移动到该现有 Project 中。
  • 创建新 Project： 此数据是否需要一个尚不存在的独立空间？此文件夹是否已足够大，可以从拥有自己的 Project 中受益？如果是，请考虑创建一个新 Project 并将文件夹或文件移动到其中。
  • 应用现有标记： 数据是否敏感，是否存在在语义上代表此数据的现有标记？您是否希望对这些资源进行下游保护？如果是，请考虑将现有标记应用于此文件夹或文件。
  • 创建新标记： 此文件夹或文件中的数据是否敏感且唯一？您是否希望对此文件夹或文件的内容进行下游保护？如果是，请考虑创建新标记并将其应用于该文件夹或文件。

4. 完成迁移

以下是执行上述迁移选项的说明。

移动到另一个项目

在将文件夹或文件的内容移动到另一个项目之前，请查看目标项目的权限。您可能需要将其他用户添加到目标项目中，以在启用“忽略继承权限”设置的情况下镜像文件夹和文件的原始安全设置。

要将文件夹或文件的内容移动到另一个项目，您至少需要 Editor 对目标项目的权限。选中这些资源，然后右键单击并选择 移动。有关详细说明，请查阅我们关于 移动和共享项目资源.

创建新项目

要创建新项目，请按照以下步骤 创建项目。您应该在项目上分配权限，以便启用了“忽略继承权限”设置的原始文件夹或文件的用户拥有相同的权限。这样可以确保没有人失去对这些资源的访问权限。

To 移动内容 将文件夹或文件的内容移动到此新项目，选中这些资源，然后右键单击并选择 移动.

应用现有标记

将所有使用“忽略继承权限”设置访问该文件夹或文件的用户添加为现有标记的成员。这可确保迁移后没有人会失去访问权限。

用户被添加为现有标记的成员后，他们可能能够查看整个平台中应用了此标记的任何数据。

在应用现有标记之前，请查看 应用标记的步骤。请考虑应用标记的下游影响以及可能将下游用户锁定在外的情况。准备好后，请在启用了“忽略继承权限”设置的文件夹或文件上应用该标记。

创建新标记

首先， 创建新标记。然后，将所有在启用“忽略继承权限”设置的情况下可访问该文件夹或文件的用户添加为此新标记的成员。这可确保迁移后没有人会失去访问权限。

与 应用现有标记类似，请查阅有关如何 应用标记步骤 的文档，然后再应用该标记。

5. 在文件夹或文件上禁用“忽略继承权限”

完成迁移后，请务必在最初应用该设置的文件夹或文件上禁用“忽略继承权限”。您可以在 设置 文件夹或文件视图右侧面板的选项卡中找到此设置。在禁用之前，请确认迁移已完成。如果相关资源是不再包含任何内容的文件夹，您可能可以删除该文件夹。

禁用后，您将无法重新启用“忽略继承权限”设置。

6. 确认操作已完成

返回 Upgrade Assistant，确认不再存在与此文件夹或文件对应的待处理操作。
