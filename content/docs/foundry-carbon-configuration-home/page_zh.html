主页配置

切换到 主页 配置选项卡来配置您工作区的主页。在 主页 配置选项卡（如下所示）中，您可以配置 徽标, 副标题日 精选项目 工作区的相关内容。

徽标

默认情况下，您的工作区将在 Carbon 主页顶部中间展示 Palantir 徽标。您可以展示已上传到 Foundry 的自定义徽标，方法是导航到 徽标 部分并点击 选择徽标.

继续在 Project 中选择您的图像文件。该图像文件现在将替换您 Carbon 工作区中的默认徽标。

要调整徽标的大小，请展开 尺寸 部分，您可以在其中设置最大宽度和/或高度。

要移除自定义徽标，您可以将鼠标悬停在徽标预览上并选择 x 图标。

副标题

在监听器设置向导的 副标题 部分，您可以添加要在主页上徽标下方显示的副标题。例如，您可以提供欢迎消息或工作区的描述。

精选项目

Carbon 工作区可以醒目地展示三个列（标记为 A、B 和 C），这些列可以包含 精选项目。有多种类型的 精选项目 可以展示，包括对象、对象类型、保存的探索等。我们建议精心策划主页，以确保工作区为用户的工作展示最有用的资源。

可选地，列 A、B 和 C 可以包含将资源分组在一起的小组件。小组件可以进行自定义配置，或者您可以从默认选项列表中进行选择，例如用户收藏的对象或保存的探索。

在自定义可配置的小组件中，可以通过将鼠标悬停在项目上并选择编辑图标来自定义每个项目的外观，这将打开一个编辑对话框。

小组件的显示可以通过添加标题和描述以及选择将项目显示为列表还是卡片来进一步配置。 列表 显示紧凑，并显示资源图标以及每个元素的名称。 卡片 显示较大，可以为每个元素包含自定义缩略图。当项目数量较少时，卡片通常更有用。这些选项可以通过展开小组件编辑器中的 元数据和显示 部分进行配置。

由模块支持的主页

构建者还可以配置模块作为工作区的主页。选择 用 Compass 资源替换主页 （位于主页配置选项卡上）将打开一个对话框，允许选择模块和参数。

如果主页正在使用模块，构建者可以将工作区重置为上次配置的默认主页。
