Quiver 最佳实践

以下章节介绍了使用 Quiver 时需要牢记的最佳实践和注意事项，尤其是提高性能方面的内容。

分析结构

Quiver 使用 画布 来显示和组织分析中的卡片。处于非活动状态的画布标签页中的任何内容都不会被渲染或查询，因此如果您的分析包含大量卡片，可以考虑将分析拆分为多个画布。同样，任何隐藏的绘图都不会被查询；您可以隐藏那些可能不需要查看但对分析而言必需的绘图或图表。

为了进一步减少分析中的计算量，您可以更新 加载设置 （位于 全局设置 中），以使该分析使用 “仅可见项” 而非 “所有项”。此更改可以提升大型画布的性能，但请注意，卡片将在变为可见时才加载。每次滚动到画布的不同区域时，您都需要等待卡片计算完成。

您可以轻松地在画布之间移动卡片，方法是使用 分析内容 面板，或者您可以将特定卡片移动到其他画布，方法是使用 移至画布 选项，该选项位于卡片的 更多操作 菜单中。

此外，您还可以将卡片或整个画布复制到新的分析中。

图形模式

在 图模式下，卡片仅在显示其预览时才会进行计算。采用紧凑的节点设计时，只有当节点在 预览面板中被选中或固定时，才会显示预览，而不是同时为所有节点进行渲染。对于大型分析，请避免固定不必要的预览，以降低计算成本和时间。

您可以使用 颜色分组 来整理相关节点，并折叠或隐藏您当前未处理的分组，从而进一步简化该图。 筛选工具 在 Analysis Contents 面板中还允许您按类型、画布、仪表板或函数来缩小可见节点的范围。

转换表

Quiver 转换表 是一项强大的功能，允许您对对象或从对象派生的表格数据执行批量分析。但是，转换表可能需要大量计算资源。因此，允许的最大行数为 50,000。如果您的输入对象集较大，我们建议使用 筛选对象集 来减少行数，然后再将其传入转换表。

由于转换表计算是在浏览器中执行的，某些分析的性能可能会因您的硬件而异（例如内存大小）。

此外，单个转换表中的所有转换都会按顺序计算。例如，如果您有四个数值公式，则每个公式会依次计算。此行为可能会导致性能限制。您可以通过并行化计算并将转换拆分到多个转换表中来提高性能。

转换表计算

转换表采用分页方式，这意味着仅会计算可见的行。例如，如果表中包含 50,000 行，但只有 100 行在视图中可见，则结果仅基于可见的 100 行进行计算。但是，某些操作需要计算整个表。这些操作包括任何可视化或图表、聚合以及联接。

迷你图

以迷你图形式呈现时，表中的每个时间序列单元格都会作为独立查询进行计算和计费。因此，对所有行应用时间序列操作可能会导致高昂的计算成本。例如，如果转换表中的 100 行包含时间序列聚合，则所需的计算量相当于对 100 个 Quiver 图表应用聚合。

要提高加载性能并降低成本，您可以更新 视图范围设置 迷你图范围以限制计算规模。默认情况下，时间序列迷你图始终会加载序列的“完整范围”，并包含所有数据。

物化

如果您正在使用不含时间序列或数据编辑功能的转换表，请考虑使用 物化 来提升性能。物化可将计算从浏览器中卸载，从而在表连接和聚合等操作中提升性能。物化也没有 50,000 行的限制，让您能够轻松处理大规模数据集。您可以随时从物化切换到转换表，而不会丢失已添加的输入和配置。但请注意，由于转换表操作是在浏览器中完成的，因此速度可能会较慢。

您无法从转换表切换到物化。

物化不支持时间序列操作；如果您需要分析时间序列数据，请使用转换表。

对象集周边搜索

Quiver 允许您 搜索周边至关联对象 （从对象集出发）。如果您的对象集使用的是 Object Storage V1 (Phonograph)，则您的输入对象集包含的对象数必须少于 100,000 个。如果您的输入对象集使用的是 Object Storage V2 (OSv2)，则生成的关联对象集包含的对象数必须少于 1000 万个。

当您使用 筛选对象集卡片 并尝试使用关联对象进行筛选时，这些限制同样适用。

时间序列

默认情况下，Quiver 会为每个时间序列渲染 1,000 个桶，以提升性能。如果您需要以更细的粒度查看序列，可以调整坐标轴，方法是： 平移和缩放 至所需的时间范围。

某些时间序列可能因索引 水化而需要更长时间才能加载。不过，一旦某个序列完成水化，后续的任何查询加载速度都会快得多。

如果您正在处理大型时间序列，并且希望避免对整个序列进行水化，应先使用 筛选时间序列 卡片，并配合明确的时间范围筛选条件来缩减序列。然后，在该筛选后的序列基础上计算后续的所有操作。这样，只需针对所需的时间范围（而非完整范围）对序列进行水化。

时间序列卡片的性能直接取决于序列中的数据点数量；请考虑使用 采样时间序列 来减少数据点数量。将数据筛选至特定时间范围还可以加快后续任何操作的计算速度。使用 时间序列搜索卡片 时，您也可以指定时间范围以提升性能，因为默认的搜索范围是整个序列。

点集

以下卡片未进行分桶。相反，每次基于该序列运行计算时，序列中涉及的所有数据点都会被重新计算：

  • 分类时间序列
  • 表格时间序列
  • 事件指标序列
  • 代码函数时间序列
  • 预测时间序列

对于较大的序列，分析性能可能会迅速下降。Quiver 对这些时间序列类型设有 25,000 个数据点的限制，但我们建议限制序列大小以提高性能。

流式传输

Quiver 有两种时间序列流式传输模式：分析范围流式传输和单轴流式传输。默认情况下， 分析范围流式传输 将在按下轴上的 “流式传输” 按钮时激活。这会使指标卡片随新的时间序列数据一同更新，但由于缓存清除操作增多，性能会有所下降。若要在保持最佳性能的同时实现时间序列流式传输，请启用 “单独流式传输轴” 设置，该设置位于 各时间轴的配置中 ，这些时间轴均位于分析中。

仪表板

在将 Quiver 仪表板嵌入其他 Foundry 应用时，应尽可能使用标签页。与 Quiver 分析中的画布一样，非活动仪表板标签页中的内容不会被渲染或查询。尽可能将仪表板拆分为多个标签页，将缩短加载时间并提升仪表板的性能。

Notepad 集成

在将多个图表嵌入 Notepad 文档时，请使用具有相同输入的仪表板小部件，以复用相同的计算缓存并提升性能。
