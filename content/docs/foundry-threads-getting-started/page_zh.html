开始使用

本教程将引导您完成一个简单的工作流程：上传文档、与文档进行交互，以及与 AIP Chatbot 进行交互。

访问 AIP Threads

可以通过平台的工作区导航栏或使用快速搜索快捷键来访问 AIP Threads CMD + J （macOS）或 CTRL + J (Windows)。

文档模式

AIP Threads 具有两种文档模式： 完整文档文本 和 相关文档分块 （测试版）。完整文档文本会从文档中提取全部文本，而相关文档分块仅提取语义上最相关的分块。

完整文档文本适用于简短精炼的文档，或者需要 LLM 审阅全部内容的场景。对于较大的文档，或者需要关注特定章节或细节时，相关文档分块模式更为高效。请注意，使用完整文档文本可能会受到上下文窗口的限制。为避免超出 LLM 的上下文容量，请切换到相关文档分块模式。

使用相关文档分块模式时，分块策略默认采用每个分块 4096 个字符（约 1024 个 token）、512 个字符的分块重叠（约 128 个 token），以及 文本嵌入 ada-002 作为嵌入模型。无法访问 ada-002 模型的注册可以使用不同的嵌入模型。

引用

模型已被指示在每次回答时提供对原始文档的引用，用户应验证 LLM 的回复。引用应指向 PDF 文档中相应的页码，以指明信息的来源。

如果您想更改某个会话上下文中的文档，可以创建新会话并重新选择感兴趣的文档，或者选择 使用当前配置开始新会话，可通过本页面下文中定义的 模型下拉菜单 进行访问。

会话配置

以下部分概述了可用的各种配置选项。

模型模式

用户可以选择用于与文档交互的 LLM。您可以使用的模型是 您注册中已启用模型的一个子集.

用户可以修改系统提示词，它是用自然语言编写的、针对 LLM 的指令。如果您想修改系统提示词，请记住，LLM 只能访问您专门提供给它的数据。在默认的 AIP Threads 体验中，这仅指您添加到会话中的文档。这与以下情况不同： AIP Chatbot 模式.

用户可以调整模型温度,以权衡更聚焦、更具确定性的输出(默认值 0)与更随机的输出(最大值 1).

将 Thread 配置升级为 AIP Chatbot

如果您发现某个特定文档、一组文档或模型和提示词配置非常有价值,值得再次使用或与其他用户共享,则可以将该 Thread 配置升级为 AIP 聊天机器人 ,只需使用模型配置下拉菜单中提供的选项即可。

这将带您进入 AIP Chatbot Studio，您可以在那里 完成聊天机器人的配置。在 AIP Chatbot Studio 中发布并刷新 AIP Threads 后，您将可以在 AIP Threads 中再次与其进行交互。

AIP Chatbot 模式

要选择一个 AIP 聊天机器人 进行交互，请使用下拉菜单。
