可视化评估

发布后，评估即可立即在模型页面的 评估 标签页。

在左侧边栏中，您可以看到所有可用的 评估集 （这些评估集是在该模型上创建的）。选择某个评估集会更新 概述 标签页中的主表，显示该评估集中的所有评估。

默认情况下，评估表会显示来自每个分支的所有评估，并按模型版本分组。这些分组按所评估模型版本的创建时间降序排列。您可以使用 分支 表格顶部的控件来筛选可见的模型版本分组，仅显示来自特定分支的分组，并使用 分组依据 控件更改分组策略。

选择一个评估

要可视化某个评估的指标，请将鼠标悬停在评估表中的相应行上，然后选择 操作，然后选择 查看指标:

这会导航到 指标 标签页，并渲染该评估的所有指标。要向视图中添加更多评估，请使用 比较评估 选择器来选择更多评估。

该选择器列出和分组评估的方式与 概述 标签页相同：评估按模型版本分组，并按时间降序排列。

导航回模型版本

要导航回某个评估对应的模型版本，您可以将鼠标悬停在 比较评估 选择器中已选中的评估上：

将显示一个弹出窗口，其中包含有关模型版本的一些元数据，以及一个用于在模型视图中导航到该模型版本的链接。

运行评估

评估也可以按临时方式运行。在评估视图中，选择 运行 页面顶部的选项。这将显示一个对话框，引导您完成评估的运行：

该对话框提供了选择要运行的确切模型版本的选项，并将针对源代码仓库中最新的评估逻辑执行。

创建计划

要为评估创建计划任务，请选择 操作 页眉中的下拉菜单，然后选择 管理调度。可以将计划任务设置为在发布新模型版本时自动运行评估，或按计划进行自动漂移检测。

选项卡

所选评估的结果被组织到四个标签页中： 指标, 图像, 绘图日 表格。选择一个标签页以查看相应的结果，每个标签页将在以下章节中介绍。

指标标签页

直方图 指标 标签页会渲染一个表格，显示该评估记录的所有数值指标。默认情况下，这些指标按 子集分组，但可以使用 分组依据 表格顶部的控件进行更改。按子集分组时，会添加一个默认的 总体 分组，用于归组所有非子集指标。

选择多个评估时，指标将并排显示以便比较。

可以使用 Evaluation.log_metric 和 Evaluation.log_metrics 函数在 Python 中记录指标。

图像标签页

在监听器设置向导的 图像 标签页中，每张卡片代表一张图像。比较评估时，如果图像具有相同的名称，则会并排渲染：

选择一张图像可将其展开，并显示 和 选项以保存该图像。

可以使用 Evaluation.log_image 在 Python 中记录图像。

图表标签页

在监听器设置向导的 绘图 标签页中，每张卡片代表一个图表。比较评估时，如果图表具有相同的名称，则会并排渲染：

渲染的图表是交互式的：将鼠标悬停可查看数据点，还支持平移和缩放。

可以使用 Evaluation.log_plot 在 Python 中记录图像。

表标签页

在监听器设置向导的 表格 标签页中，使用单张卡片来渲染所选表格。使用表格名称选择器可选择要可视化的其他表格：

可以使用 Evaluation.log_table 在 Python 中记录图像。
