控制项

控制组件类别包含以下组件：

  • 按钮
  • 复选框
  • 下拉菜单
  • 输入框
  • 多选框
  • 单选按钮
  • 分段控件
  • 滑块
  • 文本域
  • 开关

下拉菜单组件

下表提供了下拉菜单组件可用属性的使用详情。表格后附有若干示例。

属性

属性描述类型必需修改者
disabled指定用户是否可以与该组件交互。默认为 false。值通常为返回布尔值的模板表达式（例如 “{{w1.on}}”）。boolean是直接编辑
defaultPosition指定下拉菜单打开时默认显示在组件的顶部还是底部。有效值为 “top” 和 “bottom”。stringNo直接编辑
fuzzySearchEnabled切换搜索的模糊匹配。boolean是直接编辑
displayValues下拉菜单中显示的值。如果未指定，则使用 ‘values’。any[]No直接编辑
groups对应的 ‘values’ 条目将显示在的分组。any[]No直接编辑
maintainValidSelection指示当组件失效时，只要当前选中的值仍然有效，是否应保持其为选中值。boolean是直接编辑
searchText用于筛选 ‘values’ 数组的搜索文本。详情请参见 serverSearchEnabled。string是用户交互
selectedDisplayValue下拉菜单显示的值。string是用户交互
selectedValue用户当前选中的下拉菜单值。any是用户交互
serverSearchEnabled指示用户输入的搜索文本是否应触发新的查询。否则，将在本地搜索 ‘values’ 数组以查找匹配项。boolean是直接编辑
values用于设置 ‘selectedValue’ 的值来源。如果使用了 displayValues，则应与其一一对应。any[]是直接编辑

滑块组件

下表提供了滑块组件可用属性的使用详情。表格后附有若干示例。

属性

属性描述类型必需修改者
disabled指定用户是否可以与该组件交互。默认为 false。值通常为返回布尔值的模板表达式（例如 “{{w1.on}}”）。boolean是直接编辑
formatMode指定如何格式化滑块标签。“Grouped”使用指定的分隔符将数字分组。例如：如果分隔符为逗号，1000000 将变为 1,000,000。“Numeric”将使用提供的 Numeral.js ↗ 格式来格式化值。“Time”将使用提供的 moment.js ↗ format.string是直接编辑
formatter当选择“Numeric”或“Time”时，此属性保存格式字符串。stringNo直接编辑
from启用范围模式时，此属性保存范围下限的值。否则，它保存与单个滑块手柄当前位置相关联的值。number是用户交互
groupingDelimiter选择“Grouped”格式时，此属性保存用于分隔各组的分隔符字符串。stringNo直接编辑
max可选的最大值。number是直接编辑
min可选的最小值。number是直接编辑
numLabels要显示的坐标轴标签数量。如果未提供值，则默认为 6。number是直接编辑
postfix附加到所有值后面的文本。例如：“ €” 会将 “100” 转换为 “100 €”stringNo直接编辑
prefix添加到所有值前面的文本。例如：“$” 会将 “100” 转换为 “$100”stringNo直接编辑
rangeEnabled指定是启用值范围选择还是仅启用单点选择。boolean是直接编辑
step可选值的步长。numberNo直接编辑
to启用范围模式时，此属性保存范围的上限值。numberNo用户交互
updateOnSlide指定滑块的值何时更新。“Release” 表示在释放手柄后更新值。“Slide” 表示在拖动滑块时更新值。由于性能影响，除轻量操作（如 UI 更新）外，应避免使用 “Slide”。“Slide” 更新会节流至 100 毫秒。boolean是直接编辑

  "prefix": "$",
  "rangeEnabled": true,
  "to": 50
}
