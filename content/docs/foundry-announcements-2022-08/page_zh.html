Pipeline Builder：新一代数据集成

发布日期：2022-08-18

旨在实现数据管道的快速、灵活和可扩展交付

大规模构建管道通常是一项成本高昂且受制于门槛的工作，需要深厚的技术知识、预算和时间投入，以确保管道健康、全面。由于存在这些基本要求，许多用户难以使用数据集成，执行成本高昂，且维护极其困难。

我们创建了 Pipeline Builder，让用户能够专注于描述他们想要构建的管道，而无需担心细节。

高速构建管道

Pipeline Builder 为批处理、微批处理和流式工作流提供托管的、无服务器的支持，覆盖各种目标输出，同时大规模地统一处理构建、刷新和其他编排任务。

  • 立即对数据（结构化、非结构化、IoT）应用转换，无需启动环境或编写样板代码。
  • 在构建失败时即时获得反馈，无需对整个数据集进行耗时且耗费资源的检查。
  • 通过整个管道中细粒度的列级溯源，使调试更加容易。
  • 受益于 Foundry 世界一流的安全基元，包括基于目的的访问控制、Palantir 的选择性加密技术 Cipher 等。
  • Pipeline Builder 仅物化管道指定目标所需的数据，从而在大规模场景下节省计算和存储成本。

在不牺牲多功能性的前提下实现精简的数据集成

Builder 旨在满足任何数据集成需求，提供数百种常用函数，并具备轻松添加新函数的能力。Pipeline Builder 还支持后端扩展，能够采用不同的执行引擎（例如，用于小规模数据的内存引擎；用于经典批处理管道的 Spark；用于低延迟流式管道的 Flink）。无论底层计算模式如何，Builder 的后端都能确保一致的体验。

此外，多个用户现在可以在管道构建过程中提供输入，而不受其技术能力的限制。协作和导出为代码是内置的必要功能，可帮助构思、创建和审查。如有需要，您可以使用"导出为代码"功能获取管道的 Java Spark 版本。

我应该在什么时候使用 Pipeline Builder？

Pipeline Builder 使用 Palantir 全面的内置数据转换套件，创建从数据源到最终输出的端到端管道。在为分析和应用构建集成数据时使用它。

如果高度定制的集成需要代码，可以使用 Authoring 通过 SQL、Python 和 Java 对数据应用转换。对于大多数工作流，Pipeline Builder 和 Authoring 相辅相成，Authoring 仓库的输出可以作为 Builder 管道的输入，反之亦然。两种工具都通过版本控制提供协作功能。集成完成后，如需分析，可以考虑以下工具：

  • Code Workbooks： 使用交互式控制台快速迭代转换逻辑、进行临时数据探索，并使用常用软件包（Matplotlib、Plotly、Seaborn）创建详细的交互式图像。
  • Quiver： 用于原生时间序列分析和对象数据的搜索与可视化。通过可视化点击界面和强大的图表库，在 Ontology 层中利用高级分析工作流。Quiver 分析可以模板化为只读仪表板，供更广泛的用户使用。

Pipeline Builder 是一款功能强大的数据集成工具，可涵盖管道的端到端创建和管理。要了解有关 Pipeline Builder 的更多信息，请观看我们的 发布视频 ↗，或 查阅我们关于 Pipeline Builder 的文档.

Notepad：Foundry 中的现代报告工具

发布日期：2022-08-15

快速分享洞察并自动生成报告

Notepad 是一款富文本编辑器，使用户能够在 Foundry 平台中分享洞察并自动化持续报告的生成。Notepad 生成的报告以 Foundry 的本体论为支撑，让用户能够快速了解文档中所使用的任何数据源的历史和背景。借助历史血缘，您的团队可以通过追溯原始输入，轻松解释过去的报告版本或决策。此外，Notepad 文档还能通过展示使用了相同输入数据的相关内容，帮助您将信息串联起来。

凭借现成的背景信息和知识，用户可以在先前发现的基础上构建工作流，而无需完全从零开始。

使用 Notepad 进行下一代报告

Notepad 是一款富文本编辑器，能够嵌入来自整个 Foundry 平台的越来越多的数据源——包括 Contour、Quiver、Foundry Code Workbook 和 Object Explorer。Notepad 支持文档模板化，让您只需一键即可创建最新版本的定期报告。

  • 嵌入来自其他 Foundry 应用的图表、表格和图形。阅读所有 支持的集成请参阅我们的公开文档.
  • 维护指向嵌入对象和资源的结构化关联，这些关联会自动成为底层本体论的一部分。围绕任何给定文档输入的清晰血缘支持可复现性和可理解性。
  • 冻结内容以捕获特定时间点的上下文。
  • 将文档模板化，以便基于新输入轻松创建报告版本。
  • 导出为 PDF 并打印所有 Notepad 文档，可对导出呈现效果进行细粒度控制（嵌入外观、分页符等）。

充分利用 Notepad 的全部潜力

Notepad 旨在涵盖从临时报告到模板化定期报告的各种用例：

  • 临时笔记记录： 集成来自其他 Foundry 分析应用（如 Quiver）的流程工件和结果。复制并粘贴图表和表格，以实现持久且精确的文档记录。
  • 平台内文档记录： 与平台资源的深度集成支持直接创建文档。
  • 定期报告： 使用模板创建蓝图，让您一键生成最新报告。
  • 模板化导出： 文档和嵌入的工件已针对导出进行优化。使用模板生成并下载适合分享的 PDF 导出文件。

Notepad 与 Foundry 应用的强大集成以及灵活的编辑选项，使其能够满足各种用例的需求。

我应该在什么时候使用 Notepad？

使用 Notepad 来整合洞察，并创建易于构建和阅读的文档。根据您的最终输出，判断 Foundry 生态系统中最适合您的工具：对于基于实时更新和静态文档的大多数报告用例，推荐使用 Notepad。若要根据用户输入或图表选择执行动态筛选（例如用于展示分析结果的仪表板），请考虑：

  • Quiver 仪表板 适用于对象或时间序列数据
  • Contour 仪表板模式 适用于表格数据
  • 来运行该专业代码代理。你还可以通过 适用于低代码或无代码仪表板以及更高级的运营应用

如果您想了解如何无缝报告并构建跨 Foundry 生态系统中各产品集成的文档，请参阅 Notepad 文档.

Slate：全局样式表

发布日期：2022-08-11

Slate 全局样式表为应用构建者提供了一站式解决方案，用于为多个 Slate 应用设置样式。

Slate 使用户能够为任何应用创建并应用自定义样式，但在组织内的多种应用之间保持样式一致可能颇具挑战且耗费资源。借助全局样式表，应用构建者只需一键即可将自定义品牌样式应用于所有 Slate 应用。

一种样式，处处适用

即使多人共同构建应用，您现在也可以打造紧凑、一致且易于识别的视觉品牌。

由于利益相关者通常会在工作流中使用多个 Slate 应用程序来深入分析数据，构建者现在可以使用全局样式表为所有应用程序打造一致的样式，以确保统一的外观和体验。当您需要在用户群体中实现应用程序的一致性和可访问性时，即可构建全局样式表。

  • 多个构建者可以访问为同一组织定制的自定义设计库。
  • 选择一个全局样式表，并开启"在应用程序中使用"，使同一命名空间中的任何应用程序采用相同的基础设计准则。
  • 以产品支持的方式，将应用程序设计作为一站式流程的一部分进行构建。
  • 只需轻松嵌入一次无障碍 UI 元素。

为每种所需的视图类型构建一个全局样式表，以实现灵活搭配的适用性

例如，这可能意味着为地图创建一个全局样式表，为收件箱视图创建另一个，再为图表或图形创建一个。当使用两个或更多相同组件时，可以开启多个样式表以组合使用。例如，如果您有一个 Slate 仪表板，可以应用"仪表板"样式。如果您的应用程序在深色模式下查看效果更佳，且应用程序构建者已完成相关设置，则可以选择"深色模式"样式。同样，同一组织的应用程序可以采用相同的品牌风格和体验。

在设计本地或全局样式表之间做出选择时，请考虑您的样式需求

如果您正在为一个端到端使用多个应用程序的工作流进行创建，您可能需要构建全局样式表，供工作流链中的其他应用程序构建者使用，从而节省时间和精力。对于需要匹配企业级品牌形象的稳定生产应用程序，请创建全局样式表，以确保从构建者到最终用户的每个人都能受益于一致的样式，从而增强 Slate 应用程序的熟悉度和可访问性。

如果您有一个仅在单个本地应用程序中可用的自定义样式，且该样式在外观上必须保持独特，请改为构建本地样式表。此外，如果您在持续迭代应用程序的外观和体验，也可以考虑继续使用本地样式表。待样式最终确定并获准在不同应用程序中使用后，您还可以将其转换为全局样式表。

对于任何形状或规模的应用程序，样式表都是提供优质用户体验的关键。请先阅读以下内容开始使用 Slate 样式表文档.

更多亮点

分析：Contour

允许设置默认分析视图 | 引入了一项新设置，用于更改打开分析时的默认视图。用户现在可以将分析配置为默认在仪表板中打开，或仅在查看者缺少编辑权限时才在仪表板中打开。要更改此设置，请导航至设置侧边栏，并从以下选项中进行选择 默认打开位置 这将打开一个对话框，您可以在其中为实体应用和编辑标签。

在 Contour 分析中复制和粘贴画板 | 画板现在可以在单个 Contour 分析中进行复制、剪切和粘贴。要复制画板，请使用 ... 任意画板上的下拉菜单，然后选择 复制 or 剪切。随后可以使用新的 粘贴画板 选项将画板粘贴到同一分析中路径上画板之间的任意位置。
