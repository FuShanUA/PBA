4. 教程 - 将模型投入生产

在继续本教程之前，您应该已经完成了 建模项目设置 和 模型训练 以及（可选地） 模型评估 教程。此时，您的建模目标中应该至少有一个模型。

在本教程的这一步骤中，您将获取您的机器学习模型，并设置该模型的生产用途。

  1. 在建模目标中发布模型.
  2. 创建用于批处理的批量部署.
  3. 为您的模型创建交互式实时端点.

4.1 在建模目标中发布模型

现在我们有了一个模型，可以将其部署到生产环境。根据该模型的预期用途，我们可以通过几种方式之一将其投入生产。模型可以从建模目标中部署，建模目标提供功能齐全的发布和模型管理，包括文档、评估以及对来自多个支撑模型的提交进行比较的支持。

从建模目标进行部署可以通过以下方式完成：

  • 在批量部署中： 为数据集生成预测，推荐用于一次性为一组记录计算预测。
  • 在实时部署中： 将模型托管在 REST 端点之后，推荐用于从外部系统使用模型，或者您需要与模型进行实时交互。
  • 在 Python 转换中： 适用于在转换中进行快速迭代。

此外，偏好更轻量级设置的用户可以在转换中导入模型以进行批量推理，如 在 Code Repositories 中运行批量推理的教程中所述，或者使用以下方式将其部署在 REST 端点之后 直接部署 ，而无需创建建模目标。

了解更多关于 建模目标中的实时部署与直接部署之间的区别.

什么是建模目标中的发布？

批量部署和实时部署由模型发布支撑。如果您在建模目标中发布新模型，该建模目标中的部署将自动升级为使用新发布的模型。

这使模型使用者无需担心模型的具体实现即可使用模型。数据科学家可以专注于改进模型，而应用开发者则专注于构建有用的应用程序。

发布管理

发布和部署分为暂存环境和生产环境两类。模型开发者可以在正式发布到生产环境之前将模型发布到暂存环境。这会升级暂存部署，而生产部署保持不变。然后，数据科学家或应用构建者可以在模型投入生产之前在暂存环境中测试新模型。

所有发布以及发布模型的个人都会被记录，以确保团队可以跟踪在什么时间使用了哪个模型。这有助于回答监管问题，例如 GDPR 或欧盟《人工智能法案》所要求的问题。

这有助于在需要时与其他团队有效沟通上游问题和平台问题，并减少解决问题的时间。它还可以提高平台的调试技能。 导航到建模目标中的主页，并滚动到发布部分。选择 发布到暂存环境，然后选择箭头图标将模型发布到生产环境。您需要为发布指定一个发布编号，例如 "1.0"。

4.2 如何创建用于批处理的批量部署

批量部署将从输入数据集创建一个 Foundry 转换。批量部署的输出是一个数据集，该数据集是使用模型对输入数据集运行推理（生成预测）的结果。

这有助于在需要时与其他团队有效沟通上游问题和平台问题，并减少解决问题的时间。它还可以提高平台的调试技能。 点击创建部署 并配置生产批量部署。为部署指定名称 Batch deployment 和描述 Production batch deployment。选择 housing_inference_data 您之前创建的数据集作为输入数据集，并在您的 data 文件夹中创建新的输出数据集，文件夹名为 house_price_predictions中的分支提案。选择 创建部署 以保存配置。

现在，您可以安排批量部署的计划，这样每当有新模型发布时，您的输出数据集就会自动更新——确保您始终使用最佳的预测结果。在输出数据集上添加计划，使输出数据集在收到新逻辑时自动重建。

这有助于在需要时与其他团队有效沟通上游问题和平台问题，并减少解决问题的时间。它还可以提高平台的调试技能。 在部署表中选择您的批量部署。选择名为以下名称的输出数据集 house_price_predictions。在 All actions中，选择 管理调度。在 house_price_predictions 数据集上，选择 创建新计划 -> 当满足多个时间或事件条件时，当 house_price_predictions 数据集收到 New logic时。最后，选择 保存 以保存该计划。

最后，由于我们尚未更新 house_price_predictions 数据集，我们可以运行它来生成预测。构建完成后，您可以打开 house_price_predictions 数据集，在 prediction 列中查看新生成的预测结果。

这有助于在需要时与其他团队有效沟通上游问题和平台问题，并减少解决问题的时间。它还可以提高平台的调试技能。 选择 立即运行 在计划视图中构建 house_price_predictions 数据集。构建完成后，您可以通过右键单击 house_price_predictions 数据集并选择以下选项，打开输出数据集查看生成的预测结果 打开.

4.3 如何为您的模型创建交互式实时端点

实时部署是一个可查询的端点，在 REST 端点背后托管生产模型。当您希望以交互方式使用模型时，实时部署非常有用，可以通过以下方式进行查询：

  • 模型上的函数： 模型上的函数 支持直接从 将收集到的信息存储在 or 来运行该专业代码代理。你还可以通过 Foundry 中的应用程序查询模型。
  • 实时外部系统： 例如需要根据用户行为生成实时预测的网站。
  • CURL： 用于在本地测试您的模型。

在本示例中，您可能希望构建一个交互式仪表板，允许用户输入某个普查区的详细信息，并查看其对房屋中位价的影响。

创建实时部署的能力 可以与创建批量部署的能力分开设置权限，因此即使您之前能够创建上述批量部署，此选项也可能不可用。如果不可用，请联系 Palantir 支持。

这有助于在需要时与其他团队有效沟通上游问题和平台问题，并减少解决问题的时间。它还可以提高平台的调试技能。 在目标主页中， 点击创建部署 并配置生产实时部署。为该部署命名 Live deployment 和描述 Production live deployment. 点击创建部署 以保存配置。

实时部署可能需要几分钟才能启动。初始化完成后，您可以设置实时运营应用程序来连接该模型。

这有助于在需要时与其他团队有效沟通上游问题和平台问题，并减少解决问题的时间。它还可以提高平台的调试技能。 选择您的实时部署。部署升级完成后，打开 查询 标签页。粘贴以下示例并选择 运行 以测试该模型。

from transforms.api import transform, Input
from palantir_models.transforms import ModelOutput
from main.model_adapters.adapter import SklearnRegressionAdapter


def derive_housing_age_per_income(X):
    X['housing_age_per_income'] = X['housing_median_age'] / X['median_income']
    return X


def train_model(training_df):
    from sklearn.ensemble import RandomForestRegressor
    from sklearn.impute import SimpleImputer
    from sklearn.pipeline import Pipeline
    from sklearn.preprocessing import StandardScaler, FunctionTransformer

    numeric_features = ['median_income', 'housing_median_age', 'total_rooms']

    numeric_transformer = Pipeline(
        steps=[
            ("rooms_per_person_transformer", FunctionTransformer(derive_housing_age_per_income, validate=False)),
            ("imputer", SimpleImputer(strategy="median")),
            ("scaler", StandardScaler())
        ]
    )

    model = Pipeline(
        steps=[
            ("preprocessor", numeric_transformer),
            ("regressor", RandomForestRegressor())
        ]
    )
    X_train = training_df[numeric_features]
    y_train = training_df['median_house_value']
    model.fit(X_train, y_train)

    return model

@transform.using(
    training_data_input=Input("<YOUR_PROJECT_PATH>/data/housing_training_data"),
    model_output=ModelOutput("<YOUR_PROJECT_PATH>/models/random_forest_regressor_model"),
)
def compute(training_data_input, model_output):
    training_df = training_data_input.pandas()
    model = train_model(training_df)

    # Wrap the trained model in a ModelAdapter
    foundry_model = SklearnRegressionAdapter(model)

    # Publish and write the trained model to Foundry
    model_output.publish(
        model_adapter=foundry_model
    )
