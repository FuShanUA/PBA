SQL 工作表

工作表是在以下产品中组织 SQL 工作的主要方式 SQL Studio。您可以在草稿板中开始编写、私下保存工作表，或在准备好共享时将其保存到项目中。

草稿板

直方图 草稿板 是用于一次性分析的私有编辑器。它不会保存为 Foundry 资源，也无法与其他用户共享。

草稿板没有版本历史记录。如果其内容被替换或覆盖，将无法恢复。

保存工作表

当您希望在草稿板之外保留 SQL 代码时，可将其保存为工作表。您可以将工作表保存到以下任一位置：

  • 私下保存： 该工作表仅您本人可以访问，并显示在 SQL Studio 中。
  • 保存到项目中： 该工作表将成为所选项目中的 Foundry 资源，可与有权访问该项目的其他用户共享。

之后，当私有工作表准备好共享时，您可以将其保存到项目中。

项目工作表可以从 SQL Studio 或 Compass中打开。您还可以将嵌入式 SQL 控制台（console） 中的查询保存为工作表。

保存和恢复版本

每次手动保存都会创建一个新的工作表版本。您可以打开工作表的版本历史记录来查看或恢复早期版本。

在手动保存之间，SQL Studio 会自动保留未保存的更改，以便进行中的工作在会话之间仍然可用。在您手动保存工作表之前，这些更改不会创建版本。

共享和编辑工作表

对项目工作表的访问权限取决于工作表操作以及用户对其项目的访问权限：

  • 工作表读取 允许用户打开和查看已保存的工作表。
  • 工作表写入 允许用户创建、编辑和保存工作表。

有关相应的角色操作，请参阅 SQL 权限.

发布本体论 SQL 函数

An 本体论 SQL 函数 必须先保存为项目工作表，然后才能发布。私有工作表无法发布为本体论 SQL 函数。
