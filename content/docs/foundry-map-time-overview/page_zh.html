地图中的时间与时态数据

地图提供了一系列功能，可用于可视化和处理随时间变化的数据。时态数据有多种形式，每种形式都可以通过不同的方式使用和可视化。

地图上可用的基于时间的数据类型

时间序列

时间序列 是随时间变化的测量值。您可以在本体论中将时间序列值配置为 时间序列属性。使用时间序列来 为地图上的对象设置样式 ，并在 时间轴中查看它们。

事件

事件对象 是具有额外元数据的对象，这些元数据将对象与特定时间或时间范围相关联。事件对象可用于 控制地图上对象的不透明度 ，并可在 时间轴中可视化。

轨迹

使用 轨迹 来表示位置随时间变化的对象。 轨迹样式选项 可让您自定义如何可视化对象随时间变化的位置。

所选时间与时间范围

地图上显示的所有时间数据都会遵循当前选定的时间和时间范围，使您能够查看数据随时间变化的情况，并检查过去的特定时间点。

选择 查看最新数据 以启动 最新数据 视图，其中选定时间将自动更新以匹配当前时间。使用 最新数据 视图，并结合 流式数据 来可视化地图上实时更新的数据。

地图的选定时间和时间范围显示在 时间轴。

例如，根据选定时间的不同，基于时间的样式颜色也会有所不同。

即使未打开时间轴，选定时间和时间范围也会影响数据在地图上的显示方式。

调整选定时间、时间范围和筛选的时间窗口

使用 时间轴 来调整：

  • 选定时间
  • 时间范围
  • 筛选的时间窗口
