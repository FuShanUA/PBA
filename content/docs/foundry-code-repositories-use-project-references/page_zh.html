使用 Project 引用

项目引用 为具有更高权限的用户（通常是数据集或管道的所有者）提供一种机制，允许在其他 Project 中发现和使用其数据。中间 Project 可用作权限边界或发现中心，其中拥有管道某一部分的用户可以对可共享版本的数据集进行解密、整理或分发，并将其提供给下游使用者。

Project 引用在 Project 之间移动数据时增加了一层额外的审查，通过明确确认数据集何时从 Project 导出或导入到 Project。

操作说明

  1. 代码编辑器会告知用户，由转换生成的输出必须位于代码仓库的 Project 范围内。例如，如果你的代码仓库位于名为 "Data Cleaning Project" 的项目中，则代码仓库的输出只能位于 "Data Cleaning Project" 中，而不能位于任何其他项目中。
  2. 当存在来自 Project 范围之外的输入数据集时，代码编辑器会标记该数据集必须添加为 Project 引用。通过点击灯泡图标，可以将该输入数据集添加为 Project 引用。
  3. 也可以从以下位置添加对 Project 外部数据集的引用 Projects 与文件.
  4. 如果仓库的语言包已过时，则在更新之前将无法强制执行 Project 范围。Code Repositories 会标记这些包需要更新，点击出现的更新按钮即可解决此问题。
  5. 只能将来自 Project 范围之外的数据集的 Project 引用添加为输入数据集，而不能添加为输出数据集。尝试输出到 Project 范围之外的数据集将触发 AccessOutsideProjectDenied error.
