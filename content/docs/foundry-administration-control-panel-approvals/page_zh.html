Control Panel 中的 Approvals

Control Panel 提供了专用的 Approvals 集成，旨在简化在 Control Panel 中请求、批准敏感工作流并维护其历史记录的流程。

Approvals 收件箱

所有审批都会显示在 Control Panel 的 Approvals 收件箱中。要访问，请选择 Approvals 选项卡（位于 Control Panel 侧边栏最顶部）。

支持的工作流

Control Panel 与 Approvals 的集成正在积极开发中。目前支持的工作流包括：

  • 配置网络入口
  • 配置网络出口
  • 配置 Ontology SDK Web 托管
