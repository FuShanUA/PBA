transforms.api

The Transforms Python API provides classes and decorators for constructing a Pipeline. This page is a reference index. Select any name in the following tables to view the documentation for that function or class, including its parameters and examples.

Minimal example

A new Python transforms repository includes a src/myproject/datasets/examples.py file that imports from transforms.api. The following transform reads one dataset and writes one dataset. It runs as-is once you replace the two dataset paths:

from transforms.api import Input, Output, transform, LightweightInput, LightweightOutput


@transform.using(
    output_dataset=Output("/path/to/output/dataset"),
    input_dataset=Input("/path/to/input/dataset"),
)
def compute(input_dataset: LightweightInput, output_dataset: LightweightOutput) -> None:
    output_dataset.write_table(input_dataset.polars(lazy=True))

from transforms.api import transform_df, Input, Output


@transform_df(
    Output("/path/to/output/dataset"),
    hair_eye_color=Input("/path/to/input/dataset"),
)
def filter_hair_color(hair_eye_color):
    return hair_eye_color.filter(hair_eye_color.hair == "Brown")

To choose between the Polars, pandas, DuckDB, and PySpark compute engines, see Compute engines.
