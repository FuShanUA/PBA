在 Pipeline Builder 中批量迁移管道

使用 Pipeline Builder 中的批量迁移功能，可在管道、项目或注册级别创建并运行迁移。通过在单个工作流中迁移多个管道，您可以减少重复的手动工作、简化维护，并保持管道配置的一致性。

批量迁移不会直接更改管道，而是会为每个符合条件的管道创建一个 提案 。请查看并合并每个提案，以将更改应用到管道的 main 分支的情况下对分支执行操作。

Pipeline Builder 支持以下批量迁移：

  • 将标准批处理管道迁移到 更快的管道
  • 在以下位置批量替换模型： 使用 LLM 节点和 Text to embeddings expressions

所需权限

您需要针对所选迁移范围具备以下权限：

  • 项目： Edit 对每个所选项目的权限。
  • 管道： Edit 对每个所选管道的权限。
  • 注册中的所有内容： 运行注册范围迁移的权限，注册管理员默认拥有该权限。

配置批量迁移

要在 Pipeline Builder 中配置批量迁移，请按照以下步骤操作：

  1. 从 Pipeline Builder 的 登录页面，请选择 迁移 顶部栏中的选项卡。

  2. 在 迁移管道 页面上，选择 创建迁移。迁移名称对注册中的所有用户可见，但用户只能查看其有权访问的资源。

  3. 在迁移配置菜单中，输入一个 名称 作为迁移名称，或保留默认名称。

接下来，选择迁移 类型 并完成该类型的步骤：

  • 转换为 Faster： 迁移到 faster 管道
  • 替换模型： 替换模型

迁移到 faster 管道

在创建迁移之前，请查看 faster 管道的已知限制。与 转换单个管道不同，批量迁移会为每个兼容的管道创建一个提案，并跳过不兼容的管道。

  1. 在迁移配置菜单中，选择 转换为 Faster.

  2. 自动预览行为 选择管道，选择迁移范围：

    • 项目： 包含一个或多个项目中的所有管道，包括其文件夹中的管道。
    • 管道： 选择要包含的单个管道。
    • 注册中的所有内容： 包含您注册中的所有管道。

    在本示例中，选择 项目 并添加包含您要迁移的管道的项目。

  3. 选择 创建迁移 位于菜单右下角，用于打开迁移详情。要按状态筛选管道，请使用搜索栏右侧的 显示所有管道 下拉菜单。有关每种管道状态的定义以及管道可能被跳过的原因，请参见 管道状态.

  4. 当提案可用时，选择 查看提案 （位于管道旁边）。您可以在迁移继续处理其他管道的同时查看提案。

    本体论编辑： 查看并批准管道更改.

替换模型

  1. 在迁移配置菜单中，选择 替换模型.

  2. 在左侧下拉菜单中选择当前模型，在右侧下拉菜单中选择其替换模型。要在同一迁移中替换更多模型，请选择 添加映射.

  3. 按照 迁移到 faster 管道 中的步骤 2–4 选择范围、创建迁移并查看其提案。

取消迁移

如果您需要取消正在运行的迁移（例如因为配置错误而创建的），请选择进度指示器旁边的停止图标。取消后处理会逐渐停止，已创建的提案仍可供查看。

管道状态

迁移详情视图会显示每个管道的状态，指示其提案是否已创建。

状态描述
未开始此管道的处理尚未开始。
进行中处理正在进行中，尚未记录最终结果。
成功已创建迁移提案。请查看并合并该提案以应用更改。
失败在检查管道或准备其提案时发生错误。
已跳过此迁移不适用于该管道。请查看下方各迁移类型的条件。
已取消在记录最终结果之前，处理已被取消。

跳过管道的条件取决于迁移类型：

  • 转换为 Faster： 如果管道不是标准批处理管道（例如已使用更快管道的管道），或者未通过 更快转换兼容性检查.
  • 替换模型： 如果管道未使用映射中的任何源模型（例如这些模型已被替换），则跳过该管道。

未来版本计划支持更多迁移类型。
