过滤列表

直方图 过滤列表 小部件用于可视化对象数据的高级摘要，并允许用户在该摘要内进行筛选。配置筛选列表小部件的模块构建者可以使用以下功能：

  • 直方图和分布图可可视化属性类型中最常见的属性值，并支持按属性值进行筛选。
  • 关键词搜索组件允许用户根据输入的搜索词对对象集进行广泛筛选。
  • 单选和多选组件支持对给定属性类型的所有值进行搜索和筛选。
  • 输出对象集筛选变量允许将此小部件内应用的筛选条件应用于模块中的下游对象集变量。
  • 能够通过输出对象集筛选变量设置默认筛选条件。
  • 允许用户添加和移除属性类型筛选器的选项。

配置选项

对于筛选列表小部件，核心配置选项如下：

  • 输入数据
    • 对象集
      • 此输入变量决定小部件内将显示的对象数据。
      • 模块构建者可以复用在此模块中其他位置创建的现有对象集变量，也可以内联定义新的对象集变量。
      • 下面显示的许多其他配置选项只有在填充此对象集参数后才能进行配置。
  • 筛选器配置
    • 添加筛选器
      • 在此处选择某个属性将使该属性显示在筛选列表中，并可供用户筛选。
    • 筛选组件

      • 此选项决定每个属性在筛选列表中的可视化方式。

      • 选项包括关键词、直方图、单选和多选下拉菜单、分布图、单日期和多日期选择器以及时间线显示。

      • 对于字符串属性，所有属性都会显示筛选组件菜单，包括不支持精确匹配的属性。不支持精确匹配的属性会显示 关键词 搜索选项，而其他选项则显示为禁用状态，并带有解释其不可用原因的工具提示。派生属性也支持关键词搜索，从而支持对计算属性值进行筛选。

      • 对于在 Ontology Manager 中启用了正则表达式查询的字符串属性，正则表达式搜索可作为筛选选项。当选择 关键词 选项时，界面会指示该属性是否已针对正则表达式搜索建立索引。

    • 允许用户添加和移除筛选器
      • 如果启用，用户将在 添加筛选器 小部件内看到一个按钮，并能够添加和移除可筛选的属性。
  • 布局配置
    • 垂直布局
      • 此选项将以垂直滚动的方式从上到下排列所有筛选器。
    • 胶囊布局
      • 此选项将在交互式胶囊中水平排列所有筛选器。选中后，胶囊会打开一个包含筛选配置界面的弹出窗口。
  • 输出数据
    • 筛选输出
      • 此变量在筛选列表中扮演两个角色。
      • 第一个角色是作为小部件的输出变量，即一个包含小部件当前应用的筛选条件的对象集筛选变量，可用于筛选此模块中的对象集变量。
      • 第二个角色是提供为筛选列表设置默认筛选条件的方法；为此变量设置默认值后，在初始加载此模块时，这些默认属性筛选器将应用于筛选列表中。
      • 只要属性 ID 匹配，筛选输出可用于筛选不同对象类型的对象集。要检查两个不同对象类型的属性 ID 是否相同，请导航到 Ontology Manager 并查找属性 ID。
      • 筛选后的值也可以通过设置从 widget 的筛选输出字段中提取 筛选值提取 （在对象集筛选变量上），从而在模块中的其他位置使用这些值。

筛选多种对象类型的对象集

您可以使用变量存储多个不同对象类型的对象集的并集，并将其传递给 Filter List widget。Filter List 将提供以下筛选选项：

  • 公共属性： 不同对象类型共有的属性。这些属性必须具有相同的 属性 ID 才能匹配在一起。共享属性的对象类型必须使用相同的 Object Storage 版本（V1 或 V2）。
  • 单一属性： 仅存在于其中一种对象类型上的唯一属性。该属性不会出现在任何其他对象类型中。

Filter List widget 的输出变量随后可用于筛选包含并集对象集的变量，并且所有对象类型的实例都将被筛选。

基于关联属性进行筛选

上的对象类型 Object Storage v1 的关联对象筛选限制为 100,000 个对象。如果您的关联对象类型包含超过 100,000 个对象，请考虑 迁移到 Object Storage v2.

要基于关联对象属性进行筛选，请在 基于关联进行筛选 已应用标签 添加筛选器... 来创建一个临时的实体级别维护窗口。

选择后，点击关联配置以添加筛选部分。您将看到与 筛选器配置 中描述的选项 配置选项部分类似的设置，以及一些额外的选项。

  • 具有关联
    • 直方图 Has Link 筛选器是关联对象筛选所独有的，用于基于关联的存在与否进行筛选。例如：“筛选所有 Task 中具有指向 Person."
  • 显示选项
    • 内联
      • 内联显示选项将把关联筛选器与非关联筛选器并排显示（在同一分组中）。
    • 突出
      • 分组选项将在视觉上将关联筛选器归入一个部分，并添加对象图标和关联对象计数，如下面的截图所示。
      • 默认折叠： 启用后，该选项将在模块加载时默认以折叠状态显示关联筛选器分组。

高级筛选

Filter List widget 通过关键字搜索 widget 支持更高级的工作流。将搜索类型切换为高级语法后，您可以将搜索操作相互串联，并通过括号定义操作的顺序。如果未定义括号，将使用常见的布尔逻辑来确定运算符的优先级，顺序如下：引号、括号、NOT、AND、OR。

新的高级关键字搜索 widget 可以通过 Filter List widget 访问。配置 Filter List widget 后，任何关键字搜索筛选组件的下拉 UI 中都会提供高级语法选项。
