SQL Studio

SQL Studio 是 Foundry 的专用应用程序，用于针对数据集、表和本体论对象类型编写和运行 SQL 查询。SQL Studio 支持交互式分析工作流、对表格数据的读写操作，以及编写 本体论 SQL 函数（测试版）。

SQL Studio 基于 Foundry 的两个 SQL 引擎构建： 本体论 SQL 用于查询本体论对象类型和 Furnace 用于查询表格数据，它们共享通用的 Spark SQL 方言。有关在特定资源（如数据集或对象类型）上下文中进行嵌入式 SQL 访问的信息，请参阅 SQL 控制台。

访问 SQL Studio

由 Foundry 管理员启用后，即可从以下位置访问 SQL Studio：

  • 该 应用程序 菜单。
  • 任意嵌入式 SQL 控制台中的展开选项。
  • 从 Compass 浏览器中打开 SQL 工作表。

要启用 SQL Studio，Foundry 管理员可以导航至 应用程序访问 控制面板的页面。

模式

SQL Studio 支持两种模式，这些模式决定了哪个计算引擎执行您的查询，以及您可以查询哪些资源。

您可以通过资源浏览器工具栏中的模式选择器在不同模式之间进行切换。当前模式决定了浏览器中显示哪些资源，以及由哪个引擎执行您的查询。

数据模式

在 数据模式，您可以查询表格数据，例如表格 数据集、 Iceberg 表和 虚拟表，方法是使用 Furnace SQL 引擎。

数据模式同时支持读取和写入操作：

  • SELECT 查询。
  • CREATE TABLE 操作。
  • INSERT， UPDATE，以及 DELETE 对 Iceberg 表的操作。

对象模式

在 对象模式中，您可以查询本体论对象类型和多对多关联，使用的是 本体论 SQL 引擎。对象模式为只读，并支持 SELECT 针对对象类型的查询，这些对象类型定义于 本体论管理器。

工作表

工作表是您在 SQL Studio 中组织工作的主要方式。SQL Studio 同时支持临时和持久的工作表工作流。

草稿板

该 草稿板 是一个用于一次性分析的临时编辑器。草稿板内容不会保存为 Foundry 资源，也不会与其他用户共享。

已保存的工作表

您可以将您的代码保存为 SQL 工作表 以将其持久化为 Foundry 资源。您可以选择以下两种方式之一来保存工作表：

  • 私密，仅您本人可以访问，且仅在 SQL Studio 中可见。
  • 保存到项目中，使工作表成为项目资源，可与有权访问该项目的其他用户共享。

工作表版本管理

已保存的工作表具有版本管理功能。每次手动保存都会创建一个新版本，您可以在工作表的版本历史记录中查看并恢复该版本。在两次手动保存之间，未保存的更改会被自动暂存，以便进行中的工作可以跨会话保留；自动暂存的更改不会创建新版本。

请注意，草稿区不进行版本控制。如果草稿区中的工作内容被替换或覆盖，将无法找回。

编写和运行查询

SQL Studio 使用 Foundry 的 Spark SQL 方言 （适用于数据模式和对象模式）。编辑器提供语法高亮、表、对象类型和列名称的自动补全，以及行内错误报告。

要运行查询，请选择 运行 按钮（位于编辑器工具栏中），或使用键盘快捷键。若只需运行查询的一部分，请突出显示相关的 SQL 并运行所选内容。

在数据模式下，表标识符通过文件系统路径或资源标识符（RID）进行引用，并用反引号包裹：

Copied!
1SELECT * FROM `branch_name`.`/path/to/dataset`;

在对象模式下，对象类型通过其 RID 进行引用：

Copied!
1SELECT * FROM `ri.ontology.main.object-type.<object-type-rid>`;

如需完整的语法参考，请参阅 SQL 方言 文档。如需针对特定模式的指导，请参阅 Furnace 和 Ontology SQL。

AI 辅助查询生成

SQL Studio 包含一个对话式 AIP 侧面板，可用于生成、解释和调试 SQL 查询。该面板可在编辑器旁使用，并支持在单个会话内进行多轮交互。

AIP 面板可以访问：

  • 编辑器的当前内容。
  • 查询中引用的任何数据集、表或对象类型的架构。
  • Foundry 的 SQL 方言，包括当前模式支持的函数和语法。

生成 SQL 时，面板可以用新代码替换编辑器中的内容，也可以将新代码追加到现有查询中。每个提示和响应都会保留在会话中，以便您通过对话方式对生成的输出进行迭代。

AIP 侧边面板面向已启用 AIP 与核心助手功能权限 的用户开放。

预览和可视化结果

运行查询后，结果显示在编辑器下方的结果面板中。

默认预览限制为 1,000 行。具有 适当权限 可以在 SQL Studio 设置菜单中配置 SQL Studio，使每个查询最多返回 10,000 行。

结果可以采用表格或图表的形式进行可视化。这两种可视化方式均受预览限制的约束。例如，如果查询产生 100,000 行匹配结果，默认情况下，您将只能查看仅包含前 1,000 行的表格或图表。

本体论 SQL 函数

您可以创建并发布 本体论 SQL 函数（Beta） ，此操作可在 SQL Studio 中完成。本体论 SQL 函数是针对本体论对象的可重用、参数化 SQL 查询，可发布为本体论函数，并可在整个 Foundry 中调用。

连接外部工具

若要通过 Furnace 引擎查询表格数据，您还可以使用以下方式从外部连接：

  • Arrow Flight SQL，或
  • REST API

若要通过本体论 SQL 引擎查询对象类型，您可以使用 本体论 MCP 服务器从外部连接，该服务器会向兼容 MCP 的客户端公开本体论 SQL。

角色和权限

对 SQL Studio 的访问由在整个 Foundry 范围内适用的相同 SQL 和下载控制角色管控。有关可用角色及其如何与 SQL 访问权限交互的详细信息，请参阅 SQL 权限。
