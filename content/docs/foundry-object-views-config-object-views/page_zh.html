编辑已配置的完整对象视图

对于所有对象类型，默认的已配置完整对象视图会显示一个 属性列表小部件 ，用于展示该对象类型的重要属性，以及一个 关联小部件 ，用于显示对象的关联（如有）。要对已配置完整对象视图进行更改，请使用其中一个 编辑入口点 导航到已配置对象视图编辑器。进入编辑器后，即可像配置常规 Workshop 模块一样配置已配置完整对象视图各标签页的内容。

编辑对象视图标签页

完整对象视图有两个可编辑的部分：标签页和标签页内容。每个对象视图标签页都由一个 Workshop 模块支撑，使您能够使用 Workshop 来创建具有高级功能和特性的对象视图内容。您可以使用 Workshop 标签页来：

  • 完全灵活地控制 布局
  • 灵活且动态地加载信息，使用 Workshop 变量
  • 显示模拟或由模型支撑的结果，使用 情景

使用对象视图编辑器

对象视图编辑器中有三个主要部分： 页眉、 对象标题栏和 Workshop 模块。

页眉中的面包屑导航会显示本体论名称、对象类型和形态因子。形态因子是一个下拉菜单，可用于在编辑完整版和面板版对象视图之间进行切换。其下方显示对象视图和当前 Workshop 模块的版本号。在右侧，您可以选择不同的对象进行预览、保存并发布您的编辑，以及在 Object Explorer 中打开该对象。

在对象标题栏中，您可以通过选择齿轮图标来管理标签页。每个标签页对应一个 Workshop 模块。如果仅配置了一个标签页，则在查看对象视图时将隐藏标签页标题，尽管该标题在编辑模式下会显示。

选择齿轮图标会打开一个对话框，您可以在其中添加、重新排序、重命名和删除对象视图标签页。删除标签页也会删除该标签页所包含的 Workshop 模块。

此对话框还允许您配置标签页的 可见性设置，或者访问旧版对象视图编辑器以编辑其他 旧版配置选项。

标签页的内容可以像常规 Workshop 模块一样进行编辑。编辑完成后， 保存并发布 按钮将保存并发布标签页的编辑以及对当前模块的编辑， 除非已禁用自动发布功能。
