开始使用

Carbon 权限

要配置 Carbon Workspace，Foundry 开发人员需要具备 正确的权限.

本指南演示了如何使用 Foundry Training and Resources 项目中的资源创建一个简单的 Carbon 工作区，该项目是 Foundry 平台的一部分。最终成果是一个航空工作区，供航空公司分析师查看与特定航线性能相关的警报。该工作区包含指向相关应用程序和数据的快速链接，以及对分析师常用单个对象的访问。

示例 Aviation Workspace 展示了 Carbon 配置的最基本内容，可用作简单参考。Carbon 文档的其余部分包含对可用配置选项的完整说明。

创建新工作区

要配置新的 Carbon 工作区，请先打开 Carbon 工作区 （来自 Application Portal）。然后，按照说明 创建新的 Carbon 工作区.

编辑模式概览

每个 Carbon 工作区在右侧栏中都有一组四个配置标签页：

  1. 常规: 控制工作区的元数据和全局配置。
  2. 主页: 管理登录页面的内容，包括徽标、搜索和列内容，或使用自定义资源替换主页。
  3. 菜单: 选择要填充到工作区顶部菜单栏中的资源和链接。
  4. 访问权限: 确定工作区在启动器中的可见性、工作区的存储位置，以及用户组的默认工作区。

首先，添加一个 名称 和 描述 菜单中选择 General 标签页。

更新主页

默认主页采用三列布局，每列填充一个或多个 精选项目块。列上方是可选的徽标和 Object Explorer 搜索栏。

在处理列内容之前，请先限制可从搜索栏搜索的对象类型。如果已配置 对象类型组 ，请在 组 列表中进行选择，或切换到 对象类型（object types） 列表并选择一个或多个对象类型以限制搜索结果。

要处理主页内容，请在 A 列中添加与此工作区相关的对象类型列表，为 Object types (prominent & selected) 添加一个新块，并选择 List 选项，该选项允许自动选择显示的每个对象类型。

更新菜单栏

直方图 菜单栏 包含指向在工作区上下文中打开的 Foundry 资源的链接。在本示例中，我们添加了两个 Workshop 模块，即 Route Alert Inbox 和 Flight Command Center。这些 Anchored Modules 将成为工作区中的永久标签页。其他资源可以添加为 New-Tab Modules，它们将显示在下拉列表中，并在被选中时在新标签页中打开。

更新菜单栏后，返回主页配置并在 B 列 中添加一个包含 All menu bar items 内容的新块，该块将自动填充菜单栏中配置的所有资源。这些资源将在 在 工作区保存后填充。

保存工作区

在编辑界面的右上角，点击 保存 按钮以保存工作区的新版本，然后点击 x 图标退出编辑模式，并以用户视角查看工作区。
