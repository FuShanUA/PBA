Object Storage v1 与 Object Storage v2 之间的重大变更

从 Object Storage v1（Phonograph）到 Object Storage v2（OSv2）的过渡是一次重大的架构转变，需要进行多项重大变更。旧版 Object Storage v1（Phonograph）拥有庞大的 API 表面积，直接暴露了大量底层数据库功能。相反，新的 Object Storage v2 架构通过 Object Data Funnel 服务将对象同步到专门的对象数据库中，以获得规模、性能、灵活性和安全性方面的提升。这一架构转变带来了两类主要的重大变更：

  • 专门的对象数据库是针对特定用例设计的，可能无法提供与 Object Storage v1 相同的功能。这可能要求工作流在 OSv2 中的建模方式与在 OSv1 中有所不同。
  • 分离 关注点维度 在 Object Storage v1 中已被整合的功能，需要对一些直接与 OSv1 API 交互的现有查询进行重构。

这些重大变更可能会阻止某些由 OSv1 支撑的对象类型在未经重构或修复的情况下迁移到 OSv2。有关 迁移到 OSv2 的文档包含更多信息，说明了这些问题如何呈现给用户，以及如何执行从 OSv1 到 OSv2 的迁移。

永久性重大变更

本部分提供了 Object Storage v1（Phonograph）与 Object Storage v2（OSv2）之间重大变更的列表。在尝试将任何对象类型迁移到 OSv2 之前，应先解决这些重大变更。OSv1 与 OSv2 之间的所有这些变更旨在提高进入本体论的数据质量、确保更具确定性的行为，并提升整个平台的可读性。

操作与编辑

  • OSv2 仅支持通过操作进行用户编辑。在迁移到 OSv2 之前，所有现有的针对 OSv1 编辑 API 的直接查询都必须重构为使用操作。
  • OSv2 将“回写数据集”重命名为“物化”。在 OSv1 中，回写数据集是必需的；在 OSv2 中，物化是可选的。参见 物化 以了解物化数据集的更多详细信息。

编辑历史

  • 从 OSv1 迁移到 OSv2 时，可以选择保留对象的编辑历史。
    • 启用此选项将在迁移过程中包含编辑历史，这会产生额外的处理和存储计算成本。
    • 如果未启用此选项，来自 OSv1 的先前编辑将持续存在；但是，来自 OSv1 的完整编辑历史在 OSv2 中将不可用。迁移完成后，将无法从 OSv1 恢复完整的编辑历史。用户需要确认，在迁移到 Object Storage v2 时，用户编辑（操作）的历史将不会被保留，操作日志除外。
  • 跟踪用户编辑历史 将需要在 Ontology Manager 中为 OSv2 中的对象类型启用，并且需要更新对象视图以添加 编辑历史小组件 以显示用户的编辑历史。
  • 用户还可以配置 操作日志 对象类型，以通过其他方式捕获操作如何影响对象；另请参阅 操作日志时间线小组件 以显示针对目标对象的操作历史。

数据限制

OSv2 对主键和属性类型强制实施数据限制，以确保进入本体论的数据质量。有关完整的限制列表，请参阅相关文档： OSv2 数据限制.

变更日志与增量更新

  • 对于具有变更日志数据源的对象类型，OSv2 不考虑“以最新时间戳为准”的语义，该语义适用于 旧版变更日志数据集.
    • 默认情况下，OSv2 会对所有管道进行增量索引；所有相关的变更日志计算均由 Funnel 在后台自动执行，这使得“changelog Python 装饰器”变得过时。
  • OSv2 对 geopoint 属性执行更严格的验证。

监控

  • OSv2 对象类型只能通过 监控视图进行监控，该功能取代了 Object Storage v1（Phonograph）同步状态健康检查.

Object Set Service (OSS) 变更

  • OSS API 不支持查询字符串；OSv1 则支持查询字符串。
  • OSS 基数指标 不 在包含来自 Object Storage v1 和 Object Storage v2 的对象的对象集（例如多后端对象集）上受支持。

暂时性破坏性变更

本部分列出了 Object Storage v1（Phonograph）与 Object Storage v2（OSv2）之间当前的功能差距。这些功能正在开发中，随着重大变更的解决，此列表将会更新。

  • OSv2 目前不支持连接此类调度：其上游和下游目标之间的路径会经过物化。
  • OSv2 目前不支持自定义分析器。
  • Foundry Rules Archetypes 目前不支持 OSv2 的完整功能集。例如，不支持由多个数据源支撑的对象类型以及具有多个物化的对象类型。您可以参阅 Foundry Rules 文档 以了解更多详情。
