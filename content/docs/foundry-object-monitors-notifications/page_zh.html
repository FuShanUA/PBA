通知

对象监控器的订阅者可以选择在监控器出现新活动时接收通知。

通知默认对所有订阅者启用，但可以针对单个订阅者禁用。要禁用通知，请在 Object Monitors 应用中配置或编辑监控器时，点击 订阅者 选项卡中的铃铛图标。

单个用户还可以配置自己希望如何接收来自 Object Monitors 的通知。您可以在监控器配置模态框的 通知 选项卡中配置通知，且偏好设置将全局应用于该用户订阅的所有监控器。

类别活动类型
Triggered监控器已触发
Recovered监控器已恢复
Errors评估失败
Other info条件已编辑、 已订阅、 已取消订阅、 已静音、 已取消静音、 已禁用，或 已启用

自定义通知内容

为 监控器已触发 和 监控器已恢复 活动发出的通知可以自定义。在 Object Monitors 应用中配置或编辑监控器时，您可以在 通知 选项卡中提供自定义通知配置。

模板化渲染

使用模板化渲染时，自定义内容（包括主题、正文、链接标签和链接目标）会直接显示在所提供的表单中。如有需要，还可以在高级电子邮件配置中使用 HTML。可在表单右侧查看平台内通知和电子邮件通知的预览。

基于函数的渲染

使用基于函数的渲染时，自定义内容由函数使用所提供的通知返回类型返回。对于具有事件条件的监视器，函数可接受 ObjectSet<> 所监视对象类型的对象，从而可以将监视器检测到的对象的相关数据直接提取并渲染到通知内容中。
