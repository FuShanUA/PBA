Beta

SuperRepo 目前处于 beta 开发阶段，在您的注册中可能尚不可用。在积极开发期间，功能可能会发生变化。

SuperRepo 是 Foundry 开发者体验的发展方向。本页面上的各项功能正在积极开发中，目前尚未推出，且可能会发生变化。

问题与反馈

如有任何关于 SuperRepo 的问题，请在 Palantir 开发者社区 ↗ 中使用 superrepo 标签 ↗发布帖子。这些帖子还有助于团队确定应优先构建本页面上的哪些功能。

函数

函数支持正在扩展，不再局限于 TypeScript v2 函数。 Python 函数 即将推出：您将能够在同一个代码仓库中与 TypeScript 函数一起定义、测试和部署 Python，并使用相同的预览和部署工作流。本节的其余功能都将以此为基础。

除新增语言之外，函数还在向两个方向扩展其覆盖范围。智能体引擎和 Agent SDK 将允许您定义自定义的 pro-code 智能体 与您的本体论交互，并将智能体开发引入这些智能体所操作的领域模型所在的同一仓库中。外部源支持将允许您的 SuperRepo 函数调用 Palantir 平台之外的 API，因此集成无需再存在于单独的组件中。

平台覆盖范围

除函数之外，SuperRepo 可以声明的组件集合将会不断扩大，以覆盖平台的更多部分。

Automate 是正在开发中的新增功能之一：以原生方式基于您的 本体论即代码 和 本体论 SDK 定义的专业代码自动化，从而使作用于您对象上的触发器和效果与对象本身一同进行版本管理和部署。数据管道支持也在计划之中，届时将把生成您对象数据的转换层纳入与其所支撑的本体论相同的仓库和发布周期。

对于您目前可以声明的组件，请查看 核心概念 和 高级工作流。 常见问题解答 介绍了 SuperRepo 尚不支持的功能。
