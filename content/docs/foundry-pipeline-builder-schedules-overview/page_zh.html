计划

计划 在 Pipeline Builder 中用于运行 构建 定期执行。配置计划是确保管道数据对最终用户和下游工作流保持最新状态的重要环节。

定时构建任务的触发条件可配置为：

  • 指定时间
  • 数据更新时
  • 逻辑更新时
  • 上述条件的任意组合

定时构建任务的构建范围可配置为：

  • 单个数据集
  • 单个数据集及其所有依赖项
  • 依赖于某个数据集的所有数据集
  • 连接两个数据集的所有数据集
  • 上述配置的任意组合

默认情况下，当同一计划的另一次运行正在进行时，该计划不会启动新的运行。启用 允许重叠运行 可在上一次运行完成之前处理新的输入数据。您还可以使用此设置通过一个计划保持多个数据集的最新状态。

您可以直接在 Pipeline Builder 中设置基本构建计划，并在数据集视图中导航到高级设置和状态报告。可随时编辑或删除计划，并查阅我们的 最佳实践 以优化管道管理。
