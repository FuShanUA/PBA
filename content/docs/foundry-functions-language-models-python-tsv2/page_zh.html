TypeScript v2 和 Python 函数中的语言模型

前提条件

要使用 Palantir 提供的语言模型， 必须在您的注册中启用 AIP。您还必须有权使用 AIP 构建器功能。

Palantir 提供了一组可在函数中使用的语言模型。 详细了解 Palantir 提供的 LLM。

导入语言模型

要开始使用语言模型，您必须按照以下步骤将特定模型导入到您的函数代码仓库中：

  1. 打开 Platform SDK 标签页，该标签页位于 Resource imports 面板中。

  1. 要导入新的语言模型，请选择 Add > Models （位于右上角）。将会打开一个窗口，您可以在其中查看可用的 Palantir 提供的模型和已注册的模型。

  1. 选择要导入的模型，然后点击 Confirm selection。将会打开一个配置对话框，您可以在其中为每个选定的模型配置别名。点击别名旁边的笔形图标进行编辑，或选择保留默认值。

每个模型都必须有一个别名，且该别名在仓库中必须唯一。

  1. 导入的模型将显示在 Platform SDK 标签页中，该标签页位于 Resource imports 侧面板。您可以通过选择别名旁边的笔形图标来直接编辑任何别名。

您还可以定义 自定义别名 于 Platform SDK 标签页中。自定义别名存储配置参数、功能标志或特定于环境的设置，安装者可在 Marketplace 安装过程中对其进行自定义。

编写使用语言模型的函数

TypeScript v2 和 Python 函数中的语言模型使用代理端点与模型进行交互。以下示例使用了 OpenAI 聊天补全代理端点。您可以从文档侧面板中选择其他提供商。

第三方库（例如下例中的 openai ）并未预先安装。请从左侧面板的 Libraries 部分安装它们。

要在函数中使用已导入的语言模型，请先导入必要的实用工具：

export default async function callOpenAi(client: PlatformClient, prompt: string): Promise<string> {
    const oaiClient = new OpenAI({
        apiKey: await getFoundryToken(client),
        baseURL: getOpenAiBaseUrl(client),
        fetch: createFetch(client),
    });

    const completion = await oaiClient.chat.completions.create({
        model: Aliases.model("{MY_ALIAS}").rid,
        messages: [
            { role: 'user', content: prompt },
        ],
        reasoning_effort: "minimal",
        max_completion_tokens: 200,
    });

    return completion.choices[0]?.message.content ?? "";
}

@function
def get_chat_completion(prompt: str) -> str:
    client = OpenAI(
        api_key=get_foundry_token(preview=True),
        base_url=get_openai_base_url(preview=True),
        http_client=get_http_client(preview=True),
    )

    completion = client.chat.completions.create(
        model=model("{MY_ALIAS}").rid,
        messages=[
            {
                "role": "user",
                "content": prompt,
            },
        ],
    )

    return str(completion.choices[0].message.content)
