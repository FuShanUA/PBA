非结构化数据上的管道

正如 数据集的概述中所讨论的，Foundry 中的非结构化数据与表格数据一样，以数据集中的文件集合形式存储。

以下功能在结构化和非结构化数据的管道中工作方式完全相同：

  • 管道可以设置为增量式，以优化计算性能。
  • 您可以为管道编写单元测试。
  • 计算输出数据集使用 构建 and 调度.
  • Foundry 的 管道安全 功能可提供稳健的端到端安全保障。

与表格数据管道的一些区别包括：

  • 文档中的大多数指导和示例代码都专注于处理数据框（dataframe），而非结构化数据所使用的输入类型并非数据框。
  • 您必须使用较低级别的文件系统 API 来读取和写入非结构化数据集中的文件。
  • 由于非结构化数据集没有 schema，一些专注于验证表格数据集行和列的功能不可用。
  • 可以使用 Spark 并行处理非结构化文件，但这些 API 比数据框处理的 API 级别更低、更复杂。

要开始使用非结构化数据上的管道，请参阅 Python 和 Java 转换文档中的相关部分：

  • Python 转换：读取和写入非结构化文件
  • Java 转换：读取和写入非结构化文件

一旦非结构化数据经过清理和规范化，您就可以使用 代码仓库（Code Repositories） 在 Python 和 R 中分析非结构化数据集并训练机器学习模型。 了解有关在 Code Workbook 中访问非结构化数据的更多信息.
