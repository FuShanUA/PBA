网络出口可观测性

控制面板中的可观测性

在 网络出口策略 页面中， 可观测性 标签页中包含导入此策略的每个数据连接源的网络出口策略使用情况日志和指标。

在源选择器中选择数据连接源，并查看使用该策略创建的网络出口日志和指标。

构建中的可观测性

构建遥测数据中包含网络出口日志。若要仅查看网络出口日志，请添加建议的 Network egress logs 筛选器。

日志定义

源自不同来源的网络出口日志可用于帮助诊断所有 Foundry 网络层方法（例如 直接连接 或 agent 代理 策略）中的连接问题。

connectivity-sidecar 来源

connectivity-sidecar 将连接路由到用于透明代理路由的相应网络出口策略。

出口日志

出口日志包含以下参数：

  • connection_id：连接的唯一标识符。
  • response_flags：响应可以是成功或失败。
  • bytes_sent：从 sidecar 发送到出站代理的字节数。
  • bytes_received：sidecar 从出站代理接收到的字节数。
  • duration_ms：连接持续时间（以毫秒为单位）。
  • destination_port：连接的目标端口。
  • metadata：
    • network_policy：尝试进行出口时使用的网络出口策略的资源标识符。
    • source：尝试为其进行出口的数据连接源的资源标识符。
    • network_type：类型可以是 direct 或 agent proxy。
    • network_resources：如果是 agent proxy 网络出口策略，则为数据连接代理 ID。

DNS 查询日志

DNS 查询日志包含以下参数：

  • answer_count：DNS 响应中返回的 DNS 记录数。
  • connection_id：连接的唯一标识符。
  • parse_status：解析传入 DNS 消息的结果。
  • pod_name：发起 DNS 请求的 pod 名称。
  • query_class：所请求的 DNS 资源记录的类别。对于 Internet，该值几乎总是 1。
  • query_name：DNS 查询中的主机名。此项会记录为 不安全参数。
  • query_type：所请求的 DNS 资源记录的类型（例如，IPv4 对应 1，NS 对应 2）。
  • response_code：DNS 响应码。
  • return_message：人类可读的字符串版本，对应 response_code。
  • sources：与 DNS 查询关联的源 ID。

egress-proxy origin

egress-proxy 是处理显式代理连接的服务。

on-prem-proxy origin

on-prem-proxy 是在 Foundry 中运行的服务，会将流量代理到 数据连接代理 （当使用 agent 网络出口策略时）。

agent-proxy origin

agent-proxy 是运行在 数据连接代理 （位于私有网络中）上的服务。它会为以下策略打开到最终目的地的连接： 代理网络出站策略。

直接连接

直接连接出站有两种可能的结果：成功或失败。

出站成功

流量已成功从 Palantir 平台出站。连接仍可能因目标端的入站防火墙、身份验证或 TLS 握手问题而失败，但由于流量已离开 Palantir 平台，这仍被视为成功的出站。

出站失败

流量未能从 Palantir 平台出站。

后续步骤：

  • 验证尝试出站所使用的地址和端口是否存在，并确保 Palantir 平台的直连网络能够解析它们。
  • 如果流量仍无法出站，请联系 Palantir 支持团队。

代理连接

代理连接有两种可能的结果：出站成功或出站失败。

出站成功

流量已成功通过代理转发到该策略的数据连接代理之一。连接仍可能因目标端的入站防火墙、身份验证或 TLS 握手问题而失败，但由于流量已通过代理转发到支撑数据连接代理，这仍被视为成功的出站。

出站失败

流量未能从 Palantir 平台出站。

后续步骤：

  • 请验证尝试出站时使用的地址和端口是否已在数据连接源中导入相应的网络出站策略。
  • 请确保该代理策略的所有支撑数据连接代理均处于健康状态。
  • 如果流量仍无法代理至数据连接代理，请联系 Palantir 支持团队。

限制

仅对使用 TCP 级别允许列表的网络出站策略提供网络出站可观测性。
