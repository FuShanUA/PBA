分支任务栏

分支任务栏内置于与 Global Branching 集成的应用程序中。该任务栏会向用户提示其正在分支上下文中进行操作。

通过任务栏，您可以查看您的活动分支、在不同分支之间切换、检查已修改的资源，并导航至提案创建、审查和合并工作流的各个阶段。

在受支持的应用程序中，分支任务栏显示为底部的蓝色条。

在 不受支持的应用程序中，任务栏显示为灰色条。

分支选择器

分支选择器便于在现有分支之间切换，包括 main 分支。它还支持创建分支。

已修改资源面板

资源面板允许您查看并导航到您分支上的任何已修改资源。创建提案后，您可以管理审查者并查看检查状态。

您还可以通过资源面板在 Workflow Lineage 和 Data Lineage 中打开已修改的资源。

创建提案并合并更改

“ Create proposal ”选项将为现有分支生成提案。提案创建后，您可以通过选择 View proposal”导航到该提案。当所有检查通过后，“ Merge proposal ”选项将被启用。
