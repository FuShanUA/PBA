模板

代码模板通过将代码抽象为简单的基于表单的界面，使具有不同技术水平的用户能够进行协作。用户选择的值会被代入代码模板中，然后可以像 Workbook 中的任何其他转换一样运行。

任何可以用代码创建的转换（包括 Matplotlib 或 Plotly 可视化）都可以用代码模板创建。要动手试用模板，请按照 模板教程.

搜索与发现

所有可用模板都可以在模板浏览器中找到。要打开模板浏览器，请点击 + New Transform （位于屏幕左上角）并选择 模板，或选择 + 按钮（将鼠标悬停在现有转换上时显示）并选择 模板.

模板浏览器会显示最近使用的模板，并支持根据关键词、模板作者、标签等进行搜索。

使用代码模板

在图表上选择代码模板后，屏幕底部会向用户显示一个简单的表单输入界面，而不是代码编辑器。模板代码中的参数会呈现为供用户填写的输入项。

输入类型

  • 数据集： 数据集字段的值必须是当前工作簿中的有效数据集。当用户点击数据集输入字段时，系统会提示他们从图表中选择一个输入数据集。数据集输入还可以配置为始终映射到同一个输入数据集；例如，某个代码模板可能始终依赖于特定的本体论数据集。更多信息请参见 创建和编辑模板 部分。
  • 列： 系统会提示用户从其中一个输入数据集中选择一个或多个列。列参数可以配置为选择单个列或列的列表。
  • 文本： 允许用户输入自由文本值的文本输入字段。
  • 数字： 必须填写数值的输入字段。
  • 选择： 允许用户从预定义的可能值列表中进行选择。
  • 多选： 允许用户从预定义的可能值列表中选择任意数量的值。
  • 布尔值： 允许用户在 True 和 False 之间切换值的开关。
  • 显示 允许用户输入任意数量的值，这些值会作为值列表传递给底层代码。

填写输入字段后，模板转换可以像代码转换一样运行：选择 运行 按钮，或在图表上打开上下文菜单并选择 运行.

用途 Toggle View 以预览模板生成的底层代码。

创建和编辑模板

任何代码转换都可以转换为代码模板，以便无需重新编写任何代码即可重复应用相同的转换。要创建代码模板或编辑现有模板，请选择 Create/Edit template 选项（位于代码编辑器标题栏上）。

创建代码模板的方法是将代码转换中的某些值指定为参数，并添加有关允许用户输入的输入类型的元数据。当您选择创建模板时，系统会将您带入全屏编辑器的分屏视图。屏幕左侧的代码编辑器允许您选择要参数化的代码片段；屏幕右侧的模板编辑器允许您配置每个参数的元数据。

默认情况下，创建新模板时，输入会被转换为数据集类型的参数。可以编辑这些参数，为其提供更具描述性的名称和描述。模板本身也应被赋予标题和详细描述。

要创建新参数，请选择 添加新参数 选项（在模板编辑器或代码编辑器中均可）。系统将提示您高亮一段文本，该文本将被参数的输入值替换。如果您希望添加同一参数的多个实例，可以通过选择 将 按钮来完成，该按钮位于模板编辑器中代码实例列表的旁边。

添加参数后，您必须选择参数类型：数据集、列或变量。如果选择 提供，您可以根据需要在应用中自由使用。例如，您可以通过 Markdown 微件直接向用户展示扫描数据，配置对象集变量以实现对象查找，或者利用扫描数据预填操作表单输入项，从而将数据捕获至 Foundry。 ，您还应为该变量选择一个参数类型：文本、数字、单选、多选、布尔值或列表。列输入可以选择性地配置为创建多个列的列表，数据集也可以配置为默认使用特定的输入数据集。我们建议您为所有参数添加描述，并为所有变量类型的参数提供默认值。

首次创建模板时，该模板所在 Workbook 中可用的全局函数将自动附加到模板代码的内容中，以便在其他 Workbook 中使用。模板无法访问其应用所在 Workbook 中的全局代码。

模板的版本历史会被保存，对模板的新编辑始终会保存为该模板的新版本。对模板的编辑不会自动更新该模板的实例；如果模板的实例使用的是过时的版本，每个实例都会包含更新到最新版本的提示。

最佳实践

  • 尽可能包含默认值。
  • 为模板和模板参数创建详细的描述。
  • 建立一种组织方案，使用户能够轻松找到与其工作流程最相关的模板。这通常意味着创建一个包含高质量、经过审核的模板的专用公共文件夹。模板可以按工作流程分组到文件夹中。可以配置默认的模板文件夹。
