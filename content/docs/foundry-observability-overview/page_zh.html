可观测性

Palantir 平台提供内置工具，用于监控资源健康状况、调试开发和生产环境中的问题、跨服务追踪执行情况，以及大规模分析遥测数据。

监控： 您可以使用 Data Health 工具来监控平台。借助 Data Health，您可以设置规则并为故障、延迟等定义阈值；按资源或跨项目大规模配置监控器；通过 PagerDuty、Slack、Webhook 或 Foundry 通知接收警报；并查看执行次数和 P95 延迟 指标 过去30天内。

调试： 该 Workflow Lineage 工具可让您探索和调查平台历史记录和日志。您可以查看七天的 执行历史，按状态、用户、持续时间或版本进行筛选，并精准定位需要关注的具体执行。Workflow Lineage 还使您能够 搜索所有日志 以查找来自某个源执行器所有执行的特定日志消息、错误或模式。

跟踪: 要可视化跨越函数、操作和 LLM 调用的完整请求链路，您可以使用 跟踪视图。跟踪视图使您能够深入钻取任何操作，查看其持续时间、输入、输出和错误。

分析： 如需对日志数据进行进一步分析，您可以 导出 Foundry 日志、指标和追踪数据到流式数据集，以支持您自己的仪表板、管道或自定义可观测性工作流。

监控

监控工具可帮助您持续跟踪资源的健康状况和稳定性，主动检测问题，并在出现问题时收到警报。

Data Health 是用于监控平台资源健康状况的主要应用程序。Data Health 提供两组功能：

  • 监控视图: 您可以跨项目、文件夹、应用程序或单个资源，使用基于范围的监控规则来大规模监控 Foundry 资源。
  • 健康检查: 可以对单个资源配置详细的健康检查，包括对数据集、计划和表进行内容和架构验证。

监控视图和健康检查都会在检测到问题时生成警报。警报可以通过 Foundry 通知或通过 外部系统 例如 PagerDuty 或 Slack。

指标

Foundry 提供跨多种资源类型的指标，帮助您监控健康状况和性能随时间的变化。

  • 函数、 操作和 AIP Logic： 要查看过去 30 天内近实时的成功/失败次数和 P95 执行时长，请使用 本体论管理器 或 工作流血缘。
  • 流和计算模块： 访问指标，请前往 指标 选项卡，以监控长时间运行的计算工作负载的运行状况和稳定性。

调试

调试工具通过提供对执行细节、日志和跟踪信息的可见性，帮助您调查开发和生产环境中出现的问题。

AIP 可观测性

AIP 可观测性 功能位于 Workflow Lineage 使您能够全面深入地了解您的 AIP 和本体论工作流的执行情况。使用 AIP 可观测性功能来了解您的智能体、函数、语言模型、自动化、操作和本体论的性能。

AIP 可观测性功能可用于深入了解 指标, 执行历史, 分布式追踪, 日志记录，以及 日志搜索。

日志

您可以查看用于运行代码的第三方库（例如使用流时的 Kafka）生成的日志，以及代码发出的日志。多种类型的作业均提供日志：

  • 批处理和流式转换： 可以在转换的作业报告中查看实时日志。
  • 计算模块: 可以在计算模块概览页面中查看日志。
  • 函数: 可以在工作流血缘中查看日志。

您还可以 跨日志搜索 某一源执行器所有执行的记录，以查找特定的日志消息、错误或模式。源执行器是调用链中的第一个可执行资源，例如函数、操作、自动化、AIP Logic、AIP 智能体或模型实时部署。

日志导出

您的注册中可能无法使用日志导出功能。请联系 Palantir 支持团队了解更多信息。

为了满足平台内工具现有功能之外的任意处理需求，您可以在指定文件夹中创建一个包含组织所有遥测数据的流。其中包括日志、指标和追踪数据。可以使用 Foundry 的数据分析工具套件分析该流中的数据，或 导出到第三方系统。

在“配置日志”页面上详细了解如何将日志导出到流。
