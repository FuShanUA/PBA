在平台中使用函数

本节介绍了在整个 Foundry 平台中使用函数的各种方式。此列表基本保持最新，但可能存在此处未收录的其他函数使用方式。

Workshop

Workshop 以多种方式支持与函数集成，使您能够在 Workshop 中构建的模块中使用自定义逻辑。

变量

大多数 Workshop 变量 可以是函数支撑的，允许应用构建者使用函数计算值，然后在整个 Workshop 中使用这些值。默认情况下，当变量所依赖的另一个变量更新时，该变量的值将重新计算。这样便可根据用户反馈灵活地重新计算值——例如，当用户编辑输入组件时，依赖的函数支撑对象集变量将自动重新计算。

函数支撑的变量会缓存相同输入的结果，而不是重新计算。配置变量的 重新计算行为，或使用 设置变量值 事件来显式触发重新计算。

如需了解更多，请查看 有关如何使用函数支撑 Workshop 变量的教程。

以下是 Workshop 变量类型与其在 TypeScript 中的等价类型之间的映射。每种给定类型的 Workshop 变量都可以由返回所列有效类型之一的函数来支撑。 请参阅文档，了解更多关于可用函数类型的信息。

  • 布尔值： boolean
  • 字符串： string
  • 数值： Integer, Long, Float, Double
  • 日期： LocalDate
  • 时间戳： Timestamp
  • 数组： BaseType[] 或 Set<BaseType>
  • 对象集： ObjectSet<ObjectType> （推荐）， ObjectType[]或 Set<ObjectType>

对象表格：派生属性

Workshop 的 对象表格 小部件可以配置为计算由函数支撑的列，该列可以根据用户输入进行更新，并会在最终用户滚动浏览表格时实时重新计算。你可以查看 使用此功能的完整教程。

由函数支撑的列可以返回媒体引用。当函数返回 mediaReference 类型且带有 mimeType 和 reference 属性时，对象表格会自动将结果渲染为媒体而非原始数据。这样便可在表格列中基于自定义函数逻辑呈现动态媒体。

图表：派生聚合

Workshop 的 图表：XY 小部件支持使用由函数支撑的聚合来按需派生聚合值。如果你希望聚合数据基于用户选择，这会很有用。要在图表小部件中使用函数，只需点击配置图表图层并选择 函数聚合。

一个 聚合 API 的参考 现已可用。对于更高级的用例，您可能需要阅读相关文档，了解 如何计算自定义聚合。

操作

操作类型 使应用程序能够以灵活且安全的方式对 Foundry 本体论中的对象进行更改，并触发外部通知和副作用。在操作中，函数提供了完全的灵活性，使代码作者能够定义应如何更新对象或如何配置副作用。

函数支撑的操作

函数支撑的操作使用 本体论编辑 API 来定义应如何更新对象的逻辑。这使您能够在代码中表达复杂的编辑——例如，更新与某个起始对象关联的所有对象。 请参阅有关如何端到端使用函数支撑的操作的教程。

副作用：通知

可以将操作配置为向指定用户发送通知。您可以使用函数来计算哪些用户应接收通知，以及通知本身的内容。这提供了灵活性，例如加载存储在对象中的收件人用户 ID，或根据对象数据渲染电子邮件内容。要了解更多信息，请查阅 有关通知的完整文档 以及 关于如何使用函数来配置 Notifications 的指南。

副作用：Webhooks

还可以将操作配置为在应用时触发 Webhook。Webhooks 可实现 Foundry 与其他系统的集成，使用户应用的操作能够写回 Foundry 之外的 API。您可以使用函数来计算应发送给将要执行的 Webhook 的参数，从而支持诸如基于对象数据填充 Webhook 参数之类的工作流。 查看有关 Webhooks 的完整文档。

Slate

Slate 原生支持查找和使用函数，位于 Platform 标签页中。编辑 Slate 文档时，打开 Platform 标签页并添加一个 Foundry 函数 在左下角。现在，您可以搜索函数、配置参数，并在您的 Slate 文档中使用结果。

请注意，出于历史原因，Slate 产品有自己的一套“函数”概念，它们是位于每个 Slate 文档中的 JavaScript 逻辑代码片段。因此，函数产品被称为“Foundry 函数”并位于 Platform Platform

您可以将 Slate 函数与 Foundry 函数结合使用——例如，您可以先从 Foundry 函数返回数据，然后在 Slate 函数中对其进行处理，或者使用 Slate 函数计算需要传递给 Foundry 函数的参数。

Quiver

对象集图表 在 Quiver 中使用与 Workshop 的 Chart: XY 小组件相同的底层组件。因此，您也可以在 Quiver 分析中使用函数支撑的聚合。

代码函数对象集 和 代码函数分类图表 卡片支持带有对象参数的函数。可通过引用另一张卡片或在卡片编辑器中选择对象来设置参数值。

您还可以从 Quiver 搜索对话框中添加代码函数。该 代码函数 类别支持对象集、分类图表、数值和时间序列输出。

Automate

Automate 允许您创建函数支撑的自动化任务，这些任务会在满足指定条件时自动执行函数。

配置函数效果时，您可以选择函数并指定其版本。对于稳定版本（1.0.0 及以上），您可以启用自动升级到兼容版本。Automate 中的函数会异步执行，最长可运行 4 小时。

请注意，具有本体论编辑返回类型的函数在 Automate 中用作效果时，将不会应用这些编辑。要了解更多信息，请参阅 函数效果文档。
