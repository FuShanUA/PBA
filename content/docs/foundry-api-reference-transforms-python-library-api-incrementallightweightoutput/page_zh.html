transforms.api.IncrementalLightweightOutput

class transforms.api.IncrementalLightweightOutput(alias, rid, branch=None)

在运行时为增量 ContainerTransform 对象传递给用户代码的输出对象。

其目的是模拟 transforms.api.IncrementalTransformOutput API 的一个子集，同时提供对底层 foundry.transforms.Dataset的访问。

属性 alias

该参数所关联的数据集的别名。

arrow(mode='current', schema=None)

包含数据集视图的 PyArrow 表。

  • 参数：
    • mode (str ↗) – 读取模式，取值为 current、 previous 或 added。 默认为 current。
    • schema (FoundryFieldSchema , 可选) – 用于构造空表的 schema，仅在数据集为空时使用。请提供一个 FoundryFieldSchema，例如 FoundryFieldSchema(columns=[FoundryFieldColumn("column_a", FoundryFieldType.ARRAY)], format=FileType.PARQUET)。

属性 branch

该参数所关联的数据集的分支。

path(mode='current')

下载数据集的底层文件并返回指向这些文件的路径。

  • 参数： mode (str ↗) – 读取模式，取值为 current， previous，或 added。默认为 current。该参数仅在 @incremental 被添加且 v2_semantics 为 True时适用。

property path_for_object_store_write_table

返回指向存储桶的虚拟对象存储路径，该存储桶将被映射到输出事务中。该路径并不直接指向云存储中的存储桶，而是指向本地 S3 代理，以便查询引擎对数据执行异步、优化的 IO 操作。

put_metadata(column_descriptions=None)

用于在上传原始 Parquet 文件后完成数据集处理的方法。此方法将从上传的 Parquet 文件推断并上传 Foundry Schema（若已存在则会覆盖），同时更新数据集上的列描述元数据。

必须在将一个或多个 Parquet 文件上传到输出数据集之后调用此方法，以便推断 schema。如果在文件成功上传之前调用此方法，则会抛出错误。

  • 参数： column_descriptions (Dict [str ↗ , str ↗ ] , 可选) – 列名称到其字符串描述的映射。该映射会与 DataFrame 的列取交集，且所含描述不得超过 800 个字符。

read_unstaged_dataset_as_polars_lazy()

将数据集的本地版本读取为 Polars LazyFrame。

此方法用于在数据集上计算期望（expectations）。此操作必须在数据集提交之前完成，因为期望失败时可能会中止构建。

set_mode(mode)

设置输出数据集的模式。

  • 参数： mode (str ↗) –

    写入模式，为 replace、modify 或 append 之一。在 modify 模式下，写入的任何内容都会追加到数据集，也可能会覆盖现有文件。在 append 模式下，写入的任何内容都会追加到数据集，且不会覆盖现有文件。在 replace 模式下，写入的任何内容都会替换数据集。

    写入数据后，无法更改写入模式。

write_table(df, column_description=None, column_descriptions=None)

将 pandas DataFrame、Arrow Table、Polars DataFrame 或 LazyFrame 写入 Foundry 数据集。

此函数包含三个操作：将 df 本身上传到数据集、推断 schema 并将其写入数据集（如果已存在则覆盖），以及更新列描述元数据。若要仅更新元数据而不上传数据，请使用 put_metadata() 作为替代。

出于兼容性原因， column_description 和 column_descriptions 均可接受。但是，同时只能提供其中一个。

  • 参数：
    • df – pd.DataFrame, pa.Table, pl.DataFrame, pl.LazyFrame, duckdb.DuckDBPyRelation 或 pathlib.Path （包含要上传的数据），或者 None 仅从事务中先前写入的数据推断 schema。
    • column_description (Dict [str ↗ , str ↗ ] , 可选) – 已弃用，请使用 column_descriptions 作为替代。
    • column_descriptions (Dict [str ↗ , str ↗ ] , 可选) – 列名到其字符串描述的映射。该映射会与 DataFrame 的列取交集，且所包含的描述不得超过 800 个字符。
  • 返回值： None
