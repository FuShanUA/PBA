配置规则操作

在 2022 年 7 月之前，Foundry Rules（以前称为 Taurus）使用 Foundry Actions 作为规则输出。仅当您在 2022 年 7 月之前部署了 Foundry Rules 时，本节内容才与您相关。

规则操作是 Foundry Rules 中的一种手段，用于对规则的输出强制实施输出架构。这是通过使用 Foundry Actions 作为指定列名称和类型的机制来实现的。规则操作是一种将在 Foundry Rules 中使用的 Foundry Action。

上图中的操作仅 在转换中使用 ，并且不会单独运行。该操作（1 ，如上图所示）未配置任何规则会比较方便，这样即使运行该操作，也不会产生任何效果。

该操作的参数将在 Foundry Rules Workshop 应用程序中呈现给最终用户，并可供映射到规则逻辑所输出的列（2 ，如上图所示）。

  • 参数类型将用于强制实施正确的列类型。例如，如果使用了日期类型的参数，则只有日期和时间戳类型的列才能映射到该参数。此外，如果参数 ID 与您规则中的列名或对象属性 ID 相匹配，则将使用该列/属性来预填充此参数。
  • 任何被标记为必填的参数在 Foundry Rules Workshop 应用程序中也将是必填的。类似地，可选参数可以留空而不映射任何列，这等同于为该参数提供 null 值。
  • 参数名称将在 Foundry Rules Workshop 应用程序中用作标签，而参数 ID 将用作 转换生成的数据集中的列名。
  • 除参数 ID 外，输出数据集还将包含一个 taurus_rule_id 列，用于指示生成该行的规则的规则 ID。

定义 提交条件 （3）是保存操作的一项要求。规则操作最常见的提交条件是检查 当前用户 属于拥有编辑 Foundry Rules 工作流权限的用户组。在 Foundry Rules 应用中编辑规则时，将应用此验证。
