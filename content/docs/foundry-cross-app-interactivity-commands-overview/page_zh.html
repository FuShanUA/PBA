命令

命令是一种专业代码语言，使 Palantir 应用程序能够声明可由应用程序本身、其他 Palantir 应用程序、工作区组件或 AIP Chatbots执行的客户端操作。命令的开发基于以下原则：构建者应能够配置可在各 Palantir 应用程序中使用的命令，以安全地自动完成应用程序中的手动任务和操作。命令为用户和 LLM 提供了一种用于客户端交互的共同语言。

通过将一个或多个命令添加到 Workshop 模块，您可以在其他 Palantir 平台应用程序中配置并执行操作，而这些应用程序由您 以微件形式嵌入。此外，您还可以通过以下方式使用命令：

  • 作为 AIP Chatbot Studio 中的工具 来创建 AIP Chatbots ，它们能够从任何与命令互操作的应用程序读取数据并向其写入数据。
  • 以内联方式作为 Notepad 文档的一部分。

您可以在 Workshop 中通过三个现有微件来触发命令：

  • 按钮组，通过配置一个按钮，使其在 点击时触发命令。

  • 指标卡片，通过配置一个可触发命令的交互式指标。

  • 应用配对，通过添加一个基于应用程序中变量更新的命令触发器。

请按照以下说明配置命令，可使用 按钮组、 指标卡片或 应用配对 小部件。

使用按钮组小部件配置命令

导航到您的 Workshop 模块并添加按钮组小部件以打开 小部件设置 面板 （位于屏幕右侧）。请按照以下说明配置触发命令的按钮：

  1. 选择 按钮 1 ，位于 按钮配置 部分（ 小部件设置 面板）。
  2. 在 文本 输入框中输入按钮的显示名称。
  3. （可选）配置按钮的 颜色、 左侧图标和 右侧图标。

如果命令具有关联的图标，Workshop 默认会自动使用该关联填充 颜色 和图标选项。

  1. 编写一段描述，当用户在 Workshop 中将鼠标悬停在您的按钮上时，该描述将显示为工具提示。

您可以开启 条件可见性 并配置一个 布尔变量 ，当条件满足时，将禁用命令或将其从用户视图中隐藏。

  1. 选择 命令 （位于“ 点击时 ”下拉菜单中）。
  2. 选择 “添加命令 > 浏览所有命令...” 以打开 “选择命令...” 弹出窗口。

  1. 搜索并 选择 要配置的命令，例如 “绘制多边形”。选中后，您可以在右侧面板中查看该命令的使用文档。

  1. 添加来自 参数默认值 部分的可选形状样式参数，例如 填充颜色 和 填充图案。

  1. 您也可以在 指定目标应用 部分中更改默认状态（默认为 配对应用）；选择 新建地图 以在新的 Gaia 地图上执行命令，或选择 打开现有地图... 以将形状添加到现有地图。如果您已通过 应用配对小组件将 Workshop 与其他应用配对，则可以使用默认设置。

默认情况下，命令的目标是 配对应用。如果您的 Workshop 包含多个配对的应用，则在执行命令时，系统会提示您选择一个应用。

  1. 您也可以将命令的输出映射到 Workshop 模块中新建或现有的 变量 。

创建命令链

您可以通过选择 添加命令 来将多个命令链接在一起，该按钮位于 输出变量下方。链式命令将按照您将其添加到 Workshop 模块中的顺序执行，使您能够将一个命令的输出作为另一个命令的输入进行传递。

要创建有效的命令链，所有命令必须来自同一个源应用程序，例如 Gaia 或 Graph。如果某个命令失败，链式执行将继续执行下一个命令。

使用 提示命令输入对话框 部分（位于 小组件设置 面板），可根据以下条件配置用户提示，以便用户查看或填写命令输入：

  • 始终提示： 始终显示命令表单弹出窗口，使用户在每次执行命令时都能验证并编辑其中的输入值。
  • 从不提示，缺少必需输入时跳过： 从不显示命令表单弹出窗口，即使用户输入无效也是如此。如果输入无效，Workshop 将跳过该命令并继续执行链中的下一个命令。这是使用 App Pairing 小组件配置的命令链的默认行为。
  • 缺少任何输入时提示： 当缺少任何输入（必需或可选）时，显示命令表单弹出窗口。
  • 仅在缺少必需输入时提示： 当缺少任何必需输入时，显示命令表单弹出窗口。这是使用 Button Group 小组件配置的命令链的默认行为。

无论您是配置单个命令还是创建命令链，都可以使用 命令完成时 部分，在命令完成时触发 操作 或 事件 。命令会在触发变量发生变化后立即触发。为避免发送过时数据，请配置 监听器 以直接监听派生变量。完成后，请选择 保存并发布 （位于屏幕顶部），将您的更改保存到 Workshop。

使用指标卡小部件配置命令

导航到您的 Workshop 模块并添加指标卡小部件，以打开 小部件设置 面板 （位于屏幕右侧）。请按照以下说明配置在选择时会触发命令的交互式指标卡：

  1. 选择 指标 1 ，可在 指标配置 部分（位于 小部件设置 面板中）找到。
  2. 选择 命令 （位于 交互式指标 下拉菜单中）。
  3. 请按照按钮组小部件说明中的步骤 6-10 操作 ，以选择并配置您的命令。

当用户选择交互式指标时，命令便会触发。您还可以创建 命令链 ，并按照相同流程配置完成操作，详情请参阅 按钮组小部件部分。

使用应用配对小部件配置命令

您可以配置 App Pairing 小部件，使其在 Workshop 模块中的变量发生更新时触发一个或多个命令。编辑 Workshop 模块时，选择现有的 App Pairing 小部件以启动 “小部件设置” 面板（位于屏幕右侧）。请按照以下说明配置触发器，以执行单个命令或实例化一系列命令：

  1. 选择 “添加命令触发器” （位于 “变量更新时触发命令” 部分，该部分位于 “小部件设置”面板中）。
  2. 设置 “监听器” 以标识在发生更改时触发命令的变量。
  3. （可选）添加 “条件触发器” （基于新的或现有布尔变量）。Workshop 会在该变量的值为 false 时跳过命令执行 false。

设置好命令触发器后，选择 “添加命令” 并 按照与 Budget Group 小部件相同的说明进行操作， 以在 App Pairing 小部件中创建一个或多个命令。
