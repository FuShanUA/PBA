创建自定义文档仓库

设置新的自定义文档仓库主要有两个步骤：

  • 创建新的自定义文档仓库
  • 将自定义文档仓库加入允许列表

创建新的自定义文档仓库

自定义文档可以在 代码仓库 应用程序中创建和发布。首先，您需要使用 文档 模板。

在您希望存储文档仓库的位置，选择 新建 并选择 代码仓库。然后，使用任一 查找并选择仓库类型 搜索栏或 要构建其他内容吗? 向导来初始化一个新的 文档 类型代码仓库。

您将能够指定文档仓库的名称及其位置。请注意,由于文档仓库是 Compass 资源,保存仓库的位置将 决定用户对文档的访问权限。

将自定义文档仓库加入允许列表

要使自定义文档仓库可发布，必须将该仓库加入允许列表，以便文档服务能够发现并发布这些文档。要将文档仓库加入允许列表以进行发布，请前往 控制面板 > 文档 > 自定义文档 ，并为您的仓库开启 配置哪些代码仓库可以发布文档 设置。

请注意，如果您刚刚创建了新的文档仓库，首次提交将无法通过检查，并出现 PERMISSION_DENIED 错误。这是因为仓库创建后会自动运行检查，而仓库必须先加入允许列表才能通过检查，但仓库在创建之前无法被加入允许列表。加入允许列表后，重新触发检查即可成功发布文档。
