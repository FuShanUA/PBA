邮件监听器安全

邮件监听器在处理传入的电子邮件之前，会对其进行多层安全验证。

电子邮件身份验证

所有传入的电子邮件在被接受之前，必须通过以下 AWS SES 身份验证检查。

检查描述
SPF （发件人策略框架）验证发送服务器是否经授权可代表发件人的域发送邮件。
DKIM （域名密钥识别邮件）使用加密签名验证电子邮件在传输过程中未被篡改。
DMARC （基于域名的消息身份验证）验证电子邮件是否符合发件人域发布的身份验证策略。
垃圾邮件检测扫描电子邮件中是否存在已知的垃圾邮件特征。
病毒扫描扫描电子邮件内容和附件中是否存在恶意软件。

如果任何一项检查未通过，该电子邮件将被拒绝，且不会转发以进行处理。

发件人允许列表

每个邮件监听器都必须配置发件人允许列表，以控制哪些发件人可以向该监听器投递电子邮件。您可以将访问权限限制为以下范围：

  • 特定电子邮件地址： 仅接受来自所列地址的电子邮件。
  • 整个域： 接受来自指定域的所有电子邮件。
安全

默认情况下，电子邮件监听器不接受来自任何发件人的电子邮件。您必须先明确配置允许哪些发件人，监听器才会处理任何传入的电子邮件。

附件限制

为防止传递潜在的恶意内容，电子邮件监听器默认会阻止某些 MIME 类型。被阻止的类型包括可执行文件和脚本格式，例如：

  • 应用程序可执行文件 (例如 .exe, .msi)
  • Shell 脚本 (例如 .sh, .bat)
  • JavaScript 文件

大小限制

单封电子邮件（包括所有附件）的大小限制为 40 MB。超过此限制的电子邮件将被拒收。
