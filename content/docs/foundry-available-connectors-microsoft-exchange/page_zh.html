Microsoft Exchange

Microsoft Exchange 连接器是一种 由 Palantir 提供的驱动程序 用于 Microsoft Exchange。

要创建新的 Microsoft Exchange 源，请按照 Palantir 提供的驱动程序的标准设置流程，然后使用以下部分进行 Microsoft Exchange 特定的配置和网络设置。有关完整的属性参考，请参阅 官方 Microsoft Exchange 驱动程序文档 ↗.

受支持的功能

功能状态
探索🟢 正式可用
批量同步🟢 正式可用
增量🟢 正式可用
OAuth 2.0 身份验证🟢 正式可用
表导出🟢 正式可用

配置

以下属性为必填项或推荐项。

属性是否必填？描述默认值
DefaultGroups ↗必填确定在 Microsoft Exchange 中访问组范围资源时的默认组上下文。AllGroups
DefaultUser ↗必填确定在 Microsoft Exchange 中访问用户范围资源时的默认用户上下文。CurrentUser
Server ↗必填指定要连接的 Microsoft Exchange 服务器的 URL。https://outlook.office365.com/EWS/Exchange.asmx
AuthScheme ↗推荐指定用于连接到 Microsoft Exchange 服务器的身份验证方案。AzureServicePrincipal
AzureTenant ↗推荐标识用于访问数据的 Microsoft Exchange 租户。接受租户的域名（例如 contoso.onmicrosoft.com ）或其目录（租户）ID。—
GroupId ↗推荐指定要访问其数据的 Microsoft Exchange 组的 ID。—
InitiateOAuth ↗推荐网络GETANDREFRESH
OAuthClientId ↗推荐《OAuthClientSecret ↗》—
OAuthClientSecret ↗推荐指定分配给自定义 OAuth 应用程序的客户端密钥。此机密值用于向 OAuth 授权服务器验证应用程序的身份。（仅适用于自定义 OAuth 应用程序。）—
Office365Environment ↗推荐指定使用 MSGraph 架构时用于 Graph API 请求的 Office 365 环境。NONE
Platform ↗推荐指定建立连接时要面向的 Microsoft Exchange 平台。Exchange_Online
Schema ↗推荐指定连接到 Microsoft Exchange 平台时要使用的架构。EWS
UserId ↗推荐指定要访问其数据的 Microsoft Exchange 用户的 ID。—

网络

下表列出了源运行时必须能够访问的域。

为每个域名添加相应的 出口策略。如果该源托管在本地且无法从 Foundry 直接访问，请改用 代理出口策略 作为替代。代理主机本身也必须能够访问所列出的域。请参阅 使用代理作为代理服务器 了解详情。

域名必需
<Server>始终。对于 Exchange Online，请使用 Server=' https://outlook.office365.com/EWS/Exchange.asmx'

OAuth 2.0 身份验证

此连接器支持 OAuth 2.0 身份验证。请按照 Palantir 提供的驱动程序的 OAuth 2.0 指南 来配置和授权连接。
