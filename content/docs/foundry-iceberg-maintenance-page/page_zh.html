Iceberg 表维护

该 维护 标签页位于 Foundry Iceberg 表上，允许您配置和运行表维护程序，例如压缩、快照过期、孤立文件清理等。这些程序可通过优化文件布局和大小来帮助保持表的高性能，并确保随着数据不断写入和重写，存储占用量始终保持在有限范围内。

访问和使用维护页面

该 维护 标签页仅在 Foundry Iceberg 表上可用。要访问维护页面，请在 数据集预览 中打开 Iceberg 表资源，然后选择 维护 标签页。

维护标签页概述

该 维护 标签页分为三个面板：

  • 作业： 按时间顺序排列的此表维护运行列表，包括状态、开始/结束时间，以及用于在 Builds 应用中打开相应构建的链接。
  • 任务： 为此表配置的一组维护任务，包括为这些任务配置的所有当前计划。
  • 配置面板： 在创建或编辑任务时打开。允许您选择程序、配置其参数、附加计划（可选）并保存。

添加维护任务

  1. 选择 添加任务。
  2. 在配置面板中，从下拉菜单中选择一个 程序 。
  3. 配置程序字段，以便在默认参数值的基础上修改任何设置。
  4. 可以选择启用 调度信息 并配置 cron 触发器。
  5. 选择 添加任务。

保存后,新任务将显示在 任务 面板中。

编辑和删除任务

在 任务 面板中选择一个任务,即可在配置面板中打开它。您可以更改其任何字段或其调度,或者使用 删除任务来删除该任务及其关联的调度。

任务类型

维护选项卡支持以下任务类型:

  • Rewrite data files
  • Rewrite manifests
  • Expire snapshots *
  • Remove orphan files
  • Custom SQL (用于任意 Iceberg 过程或 DML 操作)

您可以在维护配置面板中直接找到有关这些任务的更多详细信息和文档。

有关查看、创建和编辑每种任务所需的操作,请参阅 Iceberg 表权限。创建 Custom SQL 任务需要内置过程之外的额外操作。

运行 expire snapshots时要格外小心。过期的快照将从表中移除,且无法恢复。这意味着将无法再回滚到过期的快照或对其进行时间旅行。这些快照的下游消费者也可能受到影响,包括任何依赖读取先前快照进行增量解析的增量管道。

有关快照保留、孤立文件清理以及考虑灾难恢复的延迟文件删除的更多信息,请参阅 Iceberg 表保留。
