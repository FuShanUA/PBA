为 4.6C/620/640 安装远程代理

适用于 SAP 应用程序的 Palantir Foundry Connector 2.0（"Connector"）4.6C/620/640 远程代理以 SAP 请求的形式提供，需通过 SAP 传输管理系统进行传输。您可以按照以下步骤将请求导入 SAP 系统。

安装步骤

  1. 下载安装包.
  2. 将 4.6c、4.70 (620/640) 的 Connector 远程代理解压到一个文件夹中。如果 SAP 系统是 Unicode 系统，则应使用 Unicode 请求；否则应使用非 Unicode 请求。文件如下所示（请求编号可能因所安装的版本而异）：
  • Connector 文件
    • K900xxx.C46
    • R900xxx.C46
  • 远程代理文件
    • K900xxx.C46
    • R900xxx.C46
  1. 以 "R" 开头的文件名是 数据文件；以 "K" 开头的文件名是 cofiles。请将文件相应地复制到 SAP 应用服务器上下列出的对应文件夹中：
    /usr/sap/trans/cofiles
    /usr/sap/trans/data
  1. 使用有权使用 STMS（SAP 传输管理系统）的用户登录 SAP 系统。
  2. 运行 STMS transaction.
  3. 选择传输的目标系统。
  4. 在工具栏菜单中，选择 Extras > Other Requests > 将 然后输入请求编号。（请求编号如下： C46K9000xx。前 3 位数字是请求文件的扩展名；其余数字是解压文件中的 K 文件名。）
  5. 该请求已列在导入队列中。现在点击请求编号以选择该请求，然后选择 导入 在工具栏上。
  6. 转到 Options 标签页中，选择 将传输请求保留在队列中以便稍后导入 and 忽略无效的组件版本。然后开始传输。
  7. 点击工具栏上的日志按钮检查导入日志。
  8. 检查是否有任何错误消息。成功导入应无错误地完成。
  9. 控制面板 PFCG 事务代码，并为以下角色生成授权配置文件：
    • /PALAGT47/SERVICE_USER
    • /PALAGT47/CONTENT_RTABLE_ALL

配置

Connector 与 Connector 远程代理通过 SAP 远程函数调用 (RFC) 进行通信。因此，需要两个 RFC 连接：一个从 Connector 到远程代理，另一个从远程代理到 Connector。下一节将详细介绍如何创建这些 RFC 连接。

RFC 配置

RFC 配置需要四个步骤：

  1. 创建到 SAP 系统的 RFC 连接。
  2. 创建从 Connector 到远程 SAP 系统的 RFC (SOURCE)。
  3. 创建从远程 SAP 系统到 Connector 的 RFC (TARGET)。
  4. 通过 Web 浏览器测试 Connector 远程代理。

创建到源/目标系统的 RFC 目标连接

在本节中，需要两个 RFC 连接：一个从 Connector 到远程代理，另一个从远程代理到 Connector。请查看 创建 RFC 连接指南.

对从远程 SAP 系统到 Connector 的目标 RFC 定义重复相同的步骤。您可以不将其命名为 SAP\_SOURCE，而将其命名为 SAP\_TARGET。（这些名称可以自由定义。）

配置远程代理并注册 Connector

  1. 登录到主 Connector 系统。
  2. 运行事务 /n/PALANTIR/PARAM_A1.
  3. 输入以下参数值：
    • Agent ID: AGENT 标识符（也称为 CONTEXT）
    • 是否为 4.7 或更早版本： AGENT 版本标志
    • Agent Desc: AGENT 描述（供参考）
  4. 运行事务 /n/PALANTIR/PARAM_A2 并输入以下参数：
    • Agent ID: AGENT ID（如上一步所定义）
    • Param ID: PARAM ID（参数的分类）
    • Param Name: 参数名称（由 AGENT 使用）
    • Param Value: 参数值（由 AGENT 使用）

局限性

适用于 4.6C/620/640 的 Connector Remote Agent 具有以下限制：

  • 仅支持 table 接口。
  • 仅支持 single 增量类型。
  • useTsvFormat:true 应在 数据连接源配置 中设置（位于 Foundry 中）。因此，即使 Foundry 中已存在可用于主 Connector 实例的源，也建议为 4.6C/620/640 创建单独的源。
