Explore object relationships

Vertex allows you to visualize and quantify cause and effect across the digital twin of your real-world organization. Using Vertex, you can access and explore existing graphs that have been published by your organization or build new graphs.

Start a new exploration

Vertex can be launched from the Foundry workspace sidebar's Apps section, under the Operational Applications header. To launch a new exploration, select Vertex from the list of applications and click on the + New Graph icon.

When starting a new exploration, a blank workspace will open where you can choose to + add objects to get started. From the object search pop-up, select the object(s) you are interested in exploring to begin creating your graph.

Object selection panel

When you click on an object on the graph, the selection panel will automatically open to display the properties of the object.

Selecting the (+) symbol at the bottom right corner of the selection panel will allow you to add derived property functions. In this case, a simple function calculates the total number of alerts on routes related to the airport. Derived properties are shown at the top of the selection panel.

Explore related objects

Vertex allows you to traverse operational relationships to build out your graph visualization. From an individual node or group of nodes, you can right-click to see your selection, layout, and exploration options.

Search Around

Select from the list of related objects to add them to the graph. The total number of objects of each type is shown within the dropdown list. With many objects, consider selecting Open next to the number of objects to include additional filters. This opens the Search Around panel, where you can add filters and search across multiple steps.

The Search Around menu also includes the following default options for common use cases:

  • All linked objects: Adds every linked object to the graph immediately. This option is also available from the Add all linked objects quick-edit button and the Cmd+Shift+S (macOS) or Ctrl+Shift+S (Windows) keyboard shortcut.
  • Shortest path: Finds the shortest path from the first selected object to the second, and stops at the first result. This option is only available when exactly two objects are selected.
  • Links to objects on graph: Discovers links between the selected objects and other objects already on the graph. This option is also available from the Cmd+Option+S (macOS) or Ctrl+Alt+S (Windows) keyboard shortcut.

Types of Search Around

Vertex supports three types of Search Around:

  • Ontology Search Arounds: Also called relations, these traverse the link types defined in your Ontology. Relations defined in your Ontology will automatically appear in Vertex Search Around menus.
  • Search Around functions: Run a function that starts from one or more objects and returns a graph of results. Functions are useful for traversals that may not have a direct ontological relationship.
  • Saved Search Arounds: Build a Search Around step by step in the Search Around panel, then save it as a resource to reuse across graphs and templates. Depending on your enrollment, refer to Saved Search Around V1 or Saved Search Around V2.

Navigate the current graph selection

To explore objects already loaded on the graph, use the selection operations:

  • Press L to select linked objects.
  • Press Shift+L to expand the current selection to linked objects.
  • Use the selection menu to select linked objects by type or follow a particular link.

These operations change the selection. Use a Search Around when you want to retrieve additional objects from the Ontology.

Press ? to view keyboard shortcuts. Where the operation palette is enabled, use Cmd+K (macOS) or Ctrl+K (Windows) to find operations.

Histogram filters

Once you have built your object graph, you can explore and filter the graph using the histogram filters. The histogram displays the properties for selected objects and provides the total values for each. Selections made in the histogram will be reflected in the graph, giving you additional granularity in exploration.
