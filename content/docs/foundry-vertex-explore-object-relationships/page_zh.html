探索对象关系

Vertex 让您能够可视化并量化现实世界组织的数字孪生中的因果关系。使用 Vertex，您可以访问并探索您的组织已发布的现有图，或构建新图。

开始新的探索

Vertex 可以从 Foundry 工作区侧边栏的 Apps 部分启动，该部分位于 Operational Applications 标题下方。要启动新的探索，请从应用列表中选择 Vertex ，然后点击 + New Graph 图标。

开始新的探索时，会打开一个空白工作区，您可以选择 + add objects 来开始。在对象搜索弹出窗口中，选择您有兴趣探索的对象，开始创建您的图。

对象选择面板

当您点击图中的某个对象时，选择面板将自动打开以显示该对象的属性。

选择 (+) 符号（位于选择面板右下角）即可添加 派生属性函数。在本例中，一个简单的函数会计算与该机场相关的航线上的警报总数。派生属性显示在选择面板的顶部。

探索相关对象

Vertex 允许您遍历业务关系来构建图可视化。您可以在单个节点或一组节点上右键单击,以查看选择、布局和探索选项。

周边搜索

从相关对象列表中进行选择,将其添加到图中。每种类型的对象总数都会显示在下拉列表中。当对象数量较多时,您可以考虑使用对象数量旁边的筛选图标来添加更多筛选条件。这将打开 周边搜索 面板,您可以在其中添加筛选条件并跨多个步骤进行搜索。

构建多步骤周边搜索

从图中的对象运行基本的周边搜索,是探索您的本体论并快速将相关对象添加到图中的绝佳方式。当您想要创建跨越不同对象类型的多步骤筛选图时, 周边搜索 面板提供了一个点选式界面,让您在生成新图时构建逻辑。

您可以访问 周边搜索 面板,方法是点击筛选图标,该图标位于基本 周边搜索 下拉列表或工作区右侧提供的选项卡。要开始 Search Around，请选择单个对象或多个相同类型的对象；然后，您可以通过选择一个关联，从所选内容创建 Search Around。

如果您想更新起始对象集，请选择一个新对象（或一组对象），然后点击 设置起始对象 选项，将鼠标悬停在起始对象框上时会出现该选项。

查找相关对象

选择要添加的相关对象后，找到的对象数量将显示在结果对象类型旁。要进一步筛选返回的对象，请点击 添加筛选器 按钮，并选择您希望用于筛选结果对象集的属性。

筛选对象集后，您可以选择立即将其添加到图中，或跨多个对象继续构建多步骤的 Search Around，方法是使用 添加关联 按钮。

Search Around 中的下一个关联将上一个关联产生的结果对象集作为其起始对象集。使用这个新 Search Around 所生成的对象集，您可以找到更多相关对象并将其添加到图表中；在本例中，即关联 1 中所生成的航班的目的地机场。

添加新的相关对象集后，您可以进一步筛选该对象集。应用筛选器后，起始对象集将被筛选为仅包含与筛选后的结果对象集相连的对象。在本例中，有 157 个航班飞往纽约州的机场。

选择 添加到图表 ，以便根据 Search Around 面板中定义的遍历生成新的图表。生成图表可能需要一些时间，具体取决于 Search Around 的复杂程度。

添加参数

为了增强 Search Around 的可复用性，您可以定义可在整个 Search Around 中使用的参数。选择 查看参数 按钮（位于面板右上角）以查看现有参数或创建新参数。选择 添加参数 按钮以选择要添加的参数类型。

添加参数后，您可以为其指定值，或选择编辑按钮来更改其名称、描述和默认值，该默认值将在加载此 Search Around 时使用。

然后，您可以在任何相应类型的筛选字段中使用此参数。要使用参数，请选择筛选字段旁边的参数切换开关，然后从下拉菜单中选择一个参数。更改参数值时，Search Around 将会更新，以在使用该参数的任何位置反映新值。

保存和加载

如果您想在其他图或图模板中重复使用此 Search Around，可以将其保存为资源。为此，请选择您要保存的 Search Around 对应标签页旁边的下拉菜单。这将打开一个模态框，您可以在其中选择保存 Search Around 的名称和位置。

当通过 Search Around 标签页标题栏中的 + 图标添加新 Search Around 时，选择 加载 Search Around 选项将打开一个资源选择器，允许您选择要打开的 Search Around。加载 Search Around 后，系统会提示您从图中选择对象，用作 Search Around 的起始对象集。只能选择相应类型的对象。

直方图筛选器

构建对象图后，您可以使用直方图筛选器对图进行探索和筛选。直方图会显示所选对象的属性，并提供每个属性的总值。在直方图中做出的选择将反映在图中，让您能够以更细的粒度进行探索。
