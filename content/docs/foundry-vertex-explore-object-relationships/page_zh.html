探索对象关系

Vertex 让您能够可视化并量化现实世界组织的数字孪生中的因果关系。使用 Vertex，您可以访问并探索您的组织已发布的现有图，或构建新图。

开始新的探索

Vertex 可以从 Foundry 工作区侧边栏的 应用程序 部分启动，该部分位于 “运营应用程序” 标题下方。要启动新的探索，请从应用列表中选择 和 ，然后点击 + 新建图谱 图标。

开始新的探索时，会打开一个空白工作区，您可以选择 + 添加对象 来开始。在对象搜索弹出窗口中，选择您有兴趣探索的对象，开始创建您的图。

对象选择面板

当您点击图中的某个对象时，选择面板将自动打开以显示该对象的属性。

选择 (+) 符号（位于选择面板右下角）即可添加 派生属性函数。在本例中，一个简单的函数会计算与该机场相关的航线上的警报总数。派生属性显示在选择面板的顶部。

探索相关对象

Vertex 允许您遍历业务关系来构建图可视化。您可以在单个节点或一组节点上右键单击,以查看选择、布局和探索选项。

周边搜索

从相关对象列表中进行选择，将其添加到图中。每种类型的对象总数显示在下拉列表中。如果对象较多，请考虑选择 打开 （位于对象数量旁边）以添加更多筛选条件。这将打开 周边搜索 面板，您可以在其中添加筛选条件并在多个步骤中进行搜索。

直方图 周边搜索 菜单还包含以下适用于常见用例的默认选项：

  • 所有关联对象： 立即将每个关联对象添加到图中。此选项也可以通过 添加所有关联对象 快速编辑按钮和 Cmd+Shift+S （macOS）或 Ctrl+Shift+S （Windows）键盘快捷键使用。
  • 最短路径： 查找从第一个选定对象到第二个选定对象的最短路径，并在找到第一个结果时停止。此选项仅在恰好选中两个对象时可用。
  • 指向图中对象的关联： 发现所选对象与图中已有其他对象之间的关联。此选项也可以通过 Cmd+Option+S （macOS）或 Ctrl+Alt+S （Windows）键盘快捷键使用。

Search Around 的类型

Vertex 支持三种类型的 Search Around：

  • 本体论 Search Around： 也称为关系，这些会遍历 关联类型（link types） 中定义的关系。在本体论中定义的关系将自动出现在 Vertex Search Around 菜单中。
  • Search Around 函数： 运行一个 函数 ，它从一个或多个对象开始并返回结果图。函数适用于可能没有直接本体论关系的遍历。
  • 已保存的 Search Around： 在 周边搜索 面板中逐步构建 Search Around，然后将其保存为资源，以便在图和模板中重复使用。根据您的注册情况，请参阅 Saved Search Around V1 or Saved Search Around V2.

导航当前图选择

要浏览已加载到图中的对象，请使用选择操作：

  • 媒体 L 以选择关联对象。
  • 媒体 Shift+L 以将当前选择扩展到关联对象。
  • 使用选择菜单按类型选择关联对象或跟随特定关联。

这些操作会更改选择。当您想要从本体论中检索其他对象时，请使用 Search Around。

媒体 ? 以查看键盘快捷键。如果启用了操作面板，请使用 Cmd+K （macOS）或 Ctrl+K （Windows）来查找操作。

直方图筛选器

构建对象图后，您可以使用直方图筛选器对图进行探索和筛选。直方图会显示所选对象的属性，并提供每个属性的总值。在直方图中做出的选择将反映在图中，让您能够以更细的粒度进行探索。
