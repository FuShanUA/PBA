设置参数默认值

操作类型参数的默认值用于在操作表单中预填充参数。默认值在参数级别配置，并在 Workshop、Object Explorer、Object Views、Quiver 和 Slate 中受支持。可以部署默认值来标准化多个使用方应用中的操作逻辑，从而无需在每个应用中单独添加默认值。

可以将参数设置为默认值，以显示固定值或所选对象的属性。

默认值与局部变量的交互

局部默认值（例如 Workshop 变量）始终优先于全局默认值。将任何 Workshop 变量传递给带有默认值的操作时，操作表单将使用 Workshop 变量中的值进行预填充。同样的模式也适用于 Object Views 中的环境变量以及 Slate 中的默认值。操作的每个实例中提供的默认值优先。因此，任何向默认值的迁移都需要移除局部覆盖。

配置默认值

选择任意参数都会打开该参数的参数配置视图。请选择该参数应默认为固定值，还是默认为某个对象参数的属性值。

静态默认值

设想一个示例操作类型，它将所选 Aircraft 对象的 Type 属性修改为 A320。要进行配置，请点击 Type 参数并添加静态默认值。

若要在不使用默认值的情况下实现类似的用户体验，则需要在每个使用该参数的应用程序中配置输入值。更新此行为（例如更改为 A380）将需要手动修改该行为，且可能需要跨多个应用程序进行修改。

对象属性默认值

要将对象属性设置为参数的默认值，首先选择要配置的对象参数。考虑一种名为 Change Airplane Details 的更通用的操作类型，例如，用户在进行编辑之前需要知道某个属性的当前值。这可以通过将每个参数的值配置为从当前选择的对象（在本例中为要修改的 Plane 对象）预填充来实现。只有输入列表中位于该参数上方的对象引用参数才可用作默认值。

在 Object Explorer 中，Change Airplane Details 操作将预填充当前值。在本例中，用户可以选择仅修改一个属性，而其余属性保持不变。无论在何处提交该操作，此相同的默认值逻辑都将存在。请注意，一旦操作用户更新此默认值，Lifetime Hours 值将显示为已编辑。

类型类预填充

操作参数可以通过类型类标注来预填充特殊值（例如自动生成的 UUID 或当前用户的 ID）。本体论文档提供了可用类型类的完整列表。

在大多数情况下，您应该将参数可见性设置为 hidden，以便用户不会手动更改这些特殊的预填充值。
