Iceberg 变更日志与 CDC 管道

Foundry 转换让您能够轻松构建强大且可扩展的变更数据捕获（CDC）管道，并充分利用 Apache Iceberg 的变更日志和快照功能。您可以在转换中使用 CDC，高效处理自上次管道运行以来新增、更新或删除的记录，从而实现高效、增量、低延迟的数据移动与处理。

除了在数据集上对仅追加（append-only） 增量转换 的现有支持之外，Foundry 现在通过 transforms-tables 库为 Iceberg 表提供完整的 CDC 处理支持。此功能利用了 Iceberg 的 变更日志视图 ↗ 来获取 Iceberg 表快照之间的插入、更新和删除记录。

CDC 处理的优势

在 Iceberg 表中使用 CDC 可带来多项优势，包括：

  • 高效的增量处理： CDC 避免在每次运行时重新处理整个数据集，从而提升性能并降低成本。
  • 流式与实时管道： CDC 通过仅处理新增和变更的记录，实现低延迟的数据移动。
  • 审计与缓慢变化维度（SCD）： 借助 CDC，您可以跟踪变更前后的数据，从而支持完整的审计追踪或 SCD Type 2 实现。

from transforms.api import incremental, transform
from transforms.tables import TableInput, TableOutput

@incremental(v2_semantics=True).with_table_incremental_options(table_read_mode="changelog")
@transform.spark.using(
    source=TableInput("<PATH>/your_iceberg_input_table"),
    output=TableOutput("<PATH>/your_iceberg_output_table"),
)
def cdc_transform(ctx, source, output):
    # Read only the changes since the last run
    changelog_df = source.changelog(["your_primary_key"])
    # Apply your business logic to the changelog
    output.apply_changelog(changelog_df, ["your_primary_key"])
