创建新的对象监控器

日落

对象监视器已被 发布后，我们建议在取代。Automate 是一款完全向后兼容的产品，可为平台中的所有业务自动化提供统一入口。

在创建对象监控器之前，您需要先将数据集成到您的 Foundry 本体论中。如果您的数据尚未集成，请了解如何 创建您的本体论 。

从 Object Explorer 创建

在 Object Explorer 中保存探索后，可以通过点击 监视器 在屏幕右上角进行创建。可以通过点击 保存 在探索视图中保存探索，并选择一个 Project 或文件夹作为目标位置。

创建对象监控器

保存探索后，点击 监视器 以打开一个视图，显示所有以该探索作为输入的对象监控器。在新创建的探索中，此列表为空。

点击设置菜单下的 添加新监控器 以打开新监控器的简化设置视图。

添加监控器名称、可选描述和监控器 条件.

包含嵌套子条件的高级条件无法在此视图中配置，而必须在 Object Monitors 应用程序中创建和修改。

您还可以选择将默认保存位置从 私有 更改为公共 Project。如果您计划添加更多订阅者，我们建议将保存的探索和监控器存储在共享的 Project 中。

输入所需信息并点击保存后，您将返回到该探索的监控器列表。此列表现在将包含新创建的监控器。

保存后

监控器保存后，可以使用更多选项。

有关监控器的元数据（包括其保存位置、创建时间和最后更新时间）显示在 详情 选项卡中。此选项卡还显示 过期日期 ，并允许您将过期时间延长三个月。

可以在 订阅者 选项卡中添加或删除订阅者，并且可以针对每个订阅者启用或禁用通知。

可以选择在 操作 标签页。

了解更多关于 配置操作 与 Object Monitors 结合使用。

快速操作下拉菜单提供了禁用或静音监控器的选项，以及通过将监控器移至回收站来删除它的选项。

从 Object Monitors 应用程序创建

Object Monitors 应用程序显示给定用户在所有 Project 中所有可用监控器的概览。请按照以下步骤在应用程序界面中创建新监控器。

  1. 点击 添加监控器 在右上角创建新监控器。
  1. 为新监控器选择保存位置。对于将有多个订阅者的监控器，我们建议将其存储在共享的 Project 中。
  1. 提供完整的条件配置。配置选项因您选择使用 事件（event） or 阈值 条件而异。监控器 输入 必须使用在 Object Explorer 中创建的现有已保存探索。如果所需的输入探索不存在，请 创建它 在 Object Explorer 中创建，然后返回此步骤。

可以从 订阅者 标签页。

  1. 点击设置菜单下的 保存 以存储并启用您的新监控器。
