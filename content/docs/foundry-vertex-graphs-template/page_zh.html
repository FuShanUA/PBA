创建图模板

Vertex 图模板是一类资源，可根据参数生成具有既定样式的图。它们支持以下工作流：

  • 将图分析从一个对象/对象集透视到另一个对象/对象集。
  • 为使用者创建一个编码图生成工作流的可重用资源。
  • 将图模板嵌入到另一个 Foundry 应用程序中，例如 Object View 或 Workshop 应用程序。

任何 Vertex 分析都可以转换为图模板。将分析转换为模板后，可以更轻松地进行后续的同类分析。

在本示例中，我们通过分析某个航班 Delay Event 及其关联的 Aircrafts 以及同一天其他延误的 Flights （在 Airports）来探索航空公司的航班延误情况，此分析使用了 Search Around 函数。生成下方所示的航班延误调查图的分析是以自由形式执行的，没有强加的结构。通过基于该分析创建图模板，我们可以在未来的调查中重复使用此分析模板。

要将此分析转换为图模板，请打开右上角工具栏中的保存选项，然后选择 另存为模板...。

这将打开一个助手，您可以在其中选择 配置参数。图模板参数分为两类： 对象参数 和 非对象参数。

对象参数是模板的对象输入，这些对象将在使用模板时被添加到图中。添加对象参数后，您还可以对图模板用户提供的对象执行 Search Around 和函数。

非对象参数是一种附加参数，可用作自定义 Search Around 函数或已保存的 Search Around 的实参。非对象参数支持的类型与 Search Around 函数支持的非对象实参一致。

接下来，您可以 配置 Search Around ，使其与您的模板关联。每个对象参数都可以与 Search Around 相关联，这些 Search Around 可以是使用本体论关联的简单 Search Around、Search Around 函数，也可以是使用 Search Around 侧边栏构建的已保存的 Search Around。传给 Search Around 函数或已保存的 Search Around 的任何非对象实参都可以映射到一个值，该值可以是常量，也可以是参数。要将输入映射到参数，请点击输入框左侧的参数按钮，然后从下拉菜单中选择一个参数。

添加所需的参数和 Search Around 后，您可以 配置图层 以及与模板关联的图层样式。纳入样式的图层将按其在图上的当前样式进行保存。排除的图层将不会在保存的模板中包含其图层样式。

最后，在选择了要应用的布局以及要保留当前分析中的哪些图设置后，您可以查看 模板摘要 ，并选择保存您的模板。

使用图模板

打开模板后，系统将提示您为模板参数提供值。

还可以使用 URL 查询参数将对象或对象集预加载到模板中：

  • 对象： 使用查询参数 objectRid=<your_object_rid_here>
  • 对象集： 使用查询参数 objectSetRid=<your_object_set_rid_here>

要与给定的参数值进行交互，请使用顶部工具栏中的 参数 按钮。这将允许您选择用作给定对象参数值的所有对象，或更改参数值以重新生成图。

模板还可以使用 Vertex 组件嵌入到 Workshop 中。
