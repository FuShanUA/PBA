创建产品

本页面包含在 Foundry DevOps 中创建新 产品 的说明。用户可以 浏览 和 安装可用产品 通过 Marketplace 店面进行。阅读更多关于 您可能希望为其创建产品的用例.

有关同时打包多个产品的说明，请参阅 打包多个产品.

选择一个商店

要创建新产品，请选择一个 商店 用于发布您的产品。要选择现有商店或创建新商店，请选择右上角的 更改商店 选项。

新商店会保存到某个项目中，并继承该项目的权限。具体而言，对商店所在项目拥有编辑权限的任何人都可以在该商店中创建新产品和编辑现有产品，而对商店所在项目拥有查看或编辑权限的任何人都可以从该商店安装产品。

选择商店后，选择 产品 or 创建新组 开始创建您的产品。

配置新产品草稿

在左上角的 设置产品标题... 输入框中为您的产品草稿提供一个名称。

启动产品草稿时，您可以：

  • 添加资源： 从项目、文件夹或本体论中手动选择资源，将其打包为输出。
  • 跟踪文件夹： 产品将 跟踪源文件夹。产品的新版本将自动引入该文件夹中的新输出。

在下面的示例中，我们选择手动添加资源。在任何时候，草稿都可以 迁移到文件夹跟踪.

添加输出

选择 添加输出 以选择要包含在产品草稿中的输出；这些输出是用户安装您的产品时 Marketplace 会重新创建的资源。您可以选择 添加文件 以选择 Compass 文件系统中的大多数资源类型。如果某个资源无法通过 Compass 选择，则 DevOps 会提供自己的选择选项，例如 添加本体论资源.

DevOps 会自动识别资源依赖关系，因此您应该先添加最下游的资源。例如，如果您想打包一个 Workshop 应用程序 和四个 对象类型（object types），您只需添加 Workshop 应用程序即可。

DevOps 还支持批量添加输出。要一次性批量添加输出，请选择 从文件夹添加所有文件。您还可以使用 从数据血缘添加 和 从工作流血缘添加 以从图形化依赖关系视图中添加资源。如果需要一种更自动化的输出跟踪方式，在产品演进时与源文件夹同步更改，请考虑 跟踪源文件夹.

将输出添加到产品草稿后，选择一个资源以启动其 详情 面板，该面板位于屏幕右侧。

打包 数据集 作为输出时，使用 包含静态数据 选项会读取其底层文件，这需要对数据集执行 foundry-data-proxy:get-files (和) 操作。在 限制下载的租户中，此操作可能通过其他角色授予，而非 Owner，因此即使您已拥有该数据集，也可能需要额外的角色（例如 Exporter 角色）才能打包数据集。详情请参阅 数据集打包权限.

选择 依赖项 选项卡以查看输出的依赖项，DevOps 也会将其显示为 输入.

添加输入

当您向产品草稿添加输出时，DevOps 会自动将输出依赖项显示为 输入 。安装您成品产品的用户必须提供资源以满足每个输入。

在设计产品时，您可以将输入提升为输出。选择省略号图标，然后选择 移至输出 （位于输入行上），将其提升为输出。

您也可以批量将输入移至输出，方法是选择多个输入并选择 将 {N} 项移至输出 （位于屏幕底部的弹出窗口中）。

一般而言，如果您希望安装者提供自己的资源版本，例如他们自己的 数据集 或对象类型，则应将该需求列为输入。如果您希望产品为安装者提供资源，则应将该输入提升为输出。

如果您迭代地将所有输入提升为输出，则安装您产品的用户在安装过程中无需映射任何内容。

某些输入类型无法移动，例如 参数 or 组，因为 DevOps 需要其配置才能进行安装。

要查看特定输入的更多信息，请选择该输入以启动 详情 面板。 关联类型图 选项卡包含哪些内容资源需要此输入的信息。在此处，您还可以配置 预设 ，预设允许您限制输入的选项并为安装者提供默认值。

如果调用方将通过公开的 Marketplace API 安装您的产品，请配置 输入 API 名称 然后再发布。这些名称可让调用方在提供安装值时识别各个输入。

管理输入和输出

DevOps 提供多种选项，帮助您管理具有大量输出的产品。使用 按文件夹分组 中的 输出 面板可在启用 文件夹结构 的情况下预览输出在其目标文件夹中的位置，以便在安装过程中复制打包资源的组织结构。

您还可以在两个 输入 和 输出 面板的功能区中选择筛选图标，以筛选它们显示的资源。例如，这使您可以仅显示具有错误消息或属于特定类型的资源。

产品规模限制

一个产品总共可包含 15,000 个输入和输出，包括嵌套资源（如数据集列和对象类型属性）。大多数产品都低于此限制。如果您接近此限制，相关数字不是您添加的资源数量，而是这些资源展开后的输入和输出数量。

DevOps 会在您构建产品时验证产品大小。当达到限制的 75% 或以上时， 产品限制 计数器会显示在左下角，并且 草稿状态 面板中会出现警告。当达到限制的 100% 时，警告将变为阻断性错误，您必须移除输出或重构产品才能继续。

选择 查看详细信息 ，该选项位于 产品限制 计数器以打开 产品打包限制 对话框，该对话框会报告您的输入和输出总数与限制的对比，并按资源类型细分该数量。

请将警告视为需要采取行动的时点，因为诸如向打包数据集添加列之类的普通更改可能会使后续版本超出限制。如果产品过大，请考虑将其拆分为多个较小的产品并 将它们打包在一起 ，以便 DevOps 解析它们之间的依赖关系。

预览关联产品

选择 关联产品 选项卡（位于产品左侧面板中），以预览所有可用的 关联产品，它们可以为您的产品提供输入。

还可以使用 按关联产品分组 中的 输入 表格，以预览每个上游关联产品提供的输入。

添加产品文档

选择 文档 选项卡（位于产品左侧面板中），以添加对在店面中 浏览产品的用户可见的信息。使用 描述 部分，在添加用作产品 缩略图.

的图片之前，您可以添加其他 图像 作为产品内容的预览。或者，您也可以输入较长的 产品描述 的定义，使用 Markdown ↗ 语法，其中包含详细的产品使用说明。

配置产品设置

选择 设置 选项卡以配置其他产品设置。

文件夹结构

通过开启以下选项来启用文件夹结构 文件夹结构 以使 DevOps 在安装过程中创建与原始组织结构相匹配的文件夹。

DevOps 会将文件夹打包至最低公共祖先，安装时这些文件夹将被安装项目替换。

如果您产品的资源组织在专用文件夹或项目中，请考虑 跟踪源文件夹 以便在产品演进时自动管理输出。

安装模式

用途 安装模式 以为产品的任何安装设置默认设置。这些设置可以在每次安装时进行更改。

  • 生产模式： 当您希望集中管理所有安装并使用自动升级等功能时，推荐使用此模式。默认情况下，安装会禁用自动升级。安装者可以选择锁定其项目以确保安全升级。
  • 单例模式： 与生产模式的设置相同，但限制每个空间和本体论中只能安装一次该产品。
  • 引导模式： 当您预期安装者会将您的产品作为其自定义工作的起点时，推荐使用此模式。默认情况下，安装会禁用自动升级，安装者可以在其拥有编辑权限的任何位置进行安装。

构建设置

用途 构建设置 以确定 DevOps 是否在 Marketplace 安装作业期间自动构建数据集和模型。这可确保 DevOps 在作业完成时为所有新部署的资源填充数据集。

审查与发布

对产品满意后，请选择 发布 以将产品发布到店面。这将启动 审查更改并发布 弹出窗口，您可以在其中查看产品中的更改并添加 更新日志描述。发布可能需要几分钟时间，具体取决于产品的大小。
