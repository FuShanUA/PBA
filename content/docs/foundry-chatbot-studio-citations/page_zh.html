引用

具有文档上下文或本体论上下文的 AIP 聊天机器人会输出引用，选中时会链接到源材料。这些引用还会显示在 来源 下拉菜单中，该菜单位于每条消息的底部，让用户清楚地了解每个回复中使用和引用的具体上下文。

对于其他类型的上下文，例如由函数支持的上下文或工具，默认情况下不提供引用。但是，用户可以提示聊天机器人包含引用。如果 LLM 以正确的引用格式响应，对话用户界面将呈现该引用。请参阅 引用格式 以获取完整的格式列表，并参阅 用于引用的自定义提示 了解如何在您的聊天机器人中使用这些格式。

引用格式

AIP 聊天机器人界面目前支持以下引用格式：

  • 本体论对象引用 可以以下面两种格式之一返回。选择引用气泡将链接到该对象的 Object Explorer 视图。

    Copied!
    1
<citation><key>ri.phonograph2-objects.main.object....</key></citation>

    其中 <key></key> 标签包含对象 RID。

    Copied!
    1
<citation><objectTypeId>...</objectTypeId><primaryKey>...</primaryKey></citation>

    其中 <objectTypeId></objectTypeId> 标签包含对象类型 ID（可在 Ontology Manager 中找到），而 <primaryKey></primaryKey> 标签包含该对象主键的值。

  • 文档（PDF）引用 应按以下格式返回：

    Copied!
    1
<citation><mediaSetKey>ri.mio.main.media-set...</mediaSetKey><mediaItemKey>ri.mio.main.media-item...</mediaItemKey></citation>

    选择引用气泡将打开一个对话框，其中显示文档的第一页。如果您希望在引用中指定文档的某一页，可以提供一个 page 标签，如下所示：

    Copied!
    1
<citation><mediaSetKey>ri.mio.main.media-set...</mediaSetKey><mediaItemKey>ri.mio.main.media-item...</mediaItemKey><page>12</page></citation>

    然后，文档对话框将显示文档中的该页面。

  • 外部 URL 引用 应按以下格式返回：

    Copied!
    1
<citation><name>My Website</name><href>www.mywebsite.com</href></citation>

    引用气泡将显示所提供的名称，例如 My website，选择它后将链接到所提供的 URL，例如 www.mywebsite.com。

您可以设置一个具有本体论上下文的聊天机器人，使其能够按上述三种格式中的任意一种引用对象，方法是导航至本体论上下文配置面板下的 引用 标签页。

引用设置

引用设置允许您在全局范围内启用或禁用引用，并覆盖默认的点击行为。

本体论引用和文档引用的默认点击行为是打开相应的文档或本体论对象。您可以针对每种对象类型，在细粒度级别上覆盖默认的本体论上下文。可以通过以下方式实现：

  • 打开外部 URL
  • 打开 PDF 文档
  • 更新变量

引用变量更新

带有本体论对象引用的聊天机器人还可以配置为在选中对象引用时更新应用程序变量。这使得 AIP 聊天机器人的使用者能够在对话面板之外显示有关被引用对象的附加信息。

这方面的一个常见示例是 Workshop 中的 AIP 聊天机器人小部件，您可以在其中使用应用程序状态来配置在选中时显示的弹出式叠加层。您可以在下方的 与 Workshop 叠加层集成 部分中找到有关如何进行此设置的分步说明。

对于使用函数支撑上下文的聊天机器人，您可以使用以下 自定义提示之一，让聊天机器人返回对象引用。

如果您的函数处理多种对象类型，则它返回的引用中可能有些对应于对象类型 A，另一些对应于对象类型 B，依此类推。要处理此类情况，您可以为您的函数创建多个引用变量，具体可在 引用设置。当选中引用时，与对象类型匹配的引用变量将被设置为包含所引用对象的对象集，而所有其他引用变量将被设置为空对象集。这种方法可确保在任何给定时间只有最相关的引用变量会被填充。

与 Workshop 覆盖层集成

在 AIP Chatbot Studio 中配置变量更新后，您可以将其连接到 Workshop 中的 AIP Chatbot 微件。有关 AIP Chatbot 微件的更多信息，请参阅 应用程序状态。

  1. 在 Workshop 中，为您在聊天机器人中配置的每个引用变量创建一个空对象集变量。每当选中来自 AIP Chatbot 微件的引用时，这些变量就会被填充。
  2. 在 Workshop 模块中创建一个覆盖层。
  3. 将覆盖层设置为 基于变量的可见性 ，并创建一个布尔变量来检查您在第一步中配置的 Workshop 变量是否为空。如果您有多个引用变量，可以创建多个覆盖层，或者创建单个覆盖层，其可见性由多个布尔变量的并集确定。

在选择引用时出现的弹出式覆盖层通常能为 AIP Chatbot 小组件的用户带来最佳用户体验。不过，如需探索其他选项，请前往 Workshop 文档。
