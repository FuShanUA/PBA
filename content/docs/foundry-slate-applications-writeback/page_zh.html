使用操作写回数据

您可能希望配置您的 Slate 应用程序，以便用户在交互式应用程序中的操作可以"写回"到 Foundry 中的底层数据资产。在 Slate 中执行写回的推荐方式是使用 本体论操作。要直接写回数据，您可以使用 OSDK 操作 or API Gateway 查询。如果您更倾向于为此目的使用提交表单，请考虑使用 操作小部件.

除了通过平台选项卡从本体论层读取数据外，Slate 还支持通过操作使用以下方式写回到本体论 操作小部件.

Slate 到本体论的写回是通过小部件配置的，而不是通过平台选项卡，以便开发人员可以选择利用自动生成的操作表单。这使开发人员无需从 Slate 小部件重新创建所有表单元素。

在此设置中，通常将操作小部件放置在 对话框 容器中，并通过 Slate 事件 触发容器在需要显示表单时打开。

或者，可以关闭表单显示，在这种情况下，小部件配置将作为模板，根据应用中其他小部件的用户交互和输入来收集要提交的值。然后通过事件触发提交，最常见的是来自 按钮小部件.

操作小部件还提供了 Slate 事件 的钩子，用于广播操作的验证状态以及提交成功或失败的信息。

请查阅相关文档以了解 操作 有关如何构建和配置操作的更多详细信息，以及有关 操作小部件 在 Slate 中进行小部件配置的详细信息。
