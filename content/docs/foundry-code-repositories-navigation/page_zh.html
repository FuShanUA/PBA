分支选项

使用分支下拉菜单选择一个现有的沙箱分支进行工作。或者，点击 图标以创建一个新的沙箱分支，其中包含现有分支上代码的副本。要在您的仓库中编辑代码，您必须在沙箱分支中工作——受保护分支无法直接编辑。

您可以选择 Code Repositories 分支 ，或者对于支持的仓库类型，选择 全局分支. 全局分支可以包含跨多个 Palantir 应用程序的更改。支持的仓库类型包括 创建更复杂的管道。, TypeScript v1、TypeScript v2 和 Python 函数日 为全局分支配置的 Ontology SDK (OSDK) React 应用程序. 了解有关全局分支的更多信息.

全局分支必须基于仓库的默认分支，而 Code Repositories 分支可以基于任何分支。

代码编辑器选项

在您的仓库中编写和编辑代码时，您可以执行以下操作：

  • 值 按钮以在输入数据集的样本上运行转换。这是一种在真实数据上预览代码更改的快速方法。
  • 值 按钮以运行当前文件中定义的所有单元测试。参见 Python 测试 or Java 测试 以了解如何向您的仓库添加单元测试。
  • 值 按钮以提交沙箱分支中的任何更改。提交更改后，系统将对您的代码运行自动检查。
  • 如果您选择一个数据集源文件（定义转换的文件，参见例如 创建更复杂的管道。），您可以点击 按钮，在对您的代码运行自动检查后，构建新版本的输出数据集。点击该按钮将触发对 当前文件的所有输出数据集的构建；如果当前文件不生成任何数据集，则不会触发构建。
  • 值 按钮以创建新的 拉取请求 其中包含您的更改。这使其他人可以在您的代码合并到主代码之前对其进行审查和评论。
  • 点击 ... 按钮以访问若干其他操作：
    • 合并： 将另一个分支合并到您当前的分支。
    • 重置： 将所有文件的内容重置为与远程分支上的最新提交一致。这将清除您分支上尚未提交的任何更改。
    • 升级： 将您的分支升级到最新的语言版本。

文件编辑器

值 图标以创建新文件、文件夹或子项目。如果您想向 Code Repository 添加另一个特定语言的子项目，请选择“新建子项目”选项。

辅助面板

Foundry Explorer 辅助面板

直方图 Foundry Explorer 辅助面板是一个文件导航界面，让您可以快速浏览所有文件和文件夹。选择特定数据集后，您可以点击“打开”以查看完整的数据集。

问题辅助面板

直方图 问题 辅助面板会告诉您代码中检测到的任何问题。点击此处列出的特定问题即可打开有问题的代码。

调试器辅助面板

直方图 调试器 允许您在转换运行时检查其行为（参见 调试转换).

预览辅助面板

直方图 预览 helper 允许您在输入数据集的有限样本上运行代码，以便在不提交更改的情况下快速预览代码（参见 预览转换).

测试 Helper

当您的仓库包含单元测试时（参见 Python 测试 和 Java 测试）， 测试 Helper 允许您运行这些测试并显示其结果。

文件更改 Helper

直方图 文件更改 helper 可用于查看当前文件的所有未提交更改，以及比较文件的历史版本。

构建 Helper

直方图 构建 helper 允许您触发数据集构建并查看构建进度。选择一个数据集源文件，然后选择 构建 来构建新版本的输出数据集，并对您的代码运行自动检查。然后，您可以在 构建 helper 中查看正在运行的任务的进度。选择 构建 Code Repositories 界面右上角的按钮等同于从此 helper 触发构建。

文档 Helper

直方图 文档 helper 包含可用于编写代码的可用语言的参考文档。如需产品内文档中未提供的更详细的语言专属文档，请参阅 支持的语言.

SQL Scratchpad

直方图 SQL helper 允许您快速测试 SQL 查询。编写一个 SQL 查询并点击 来预览查询结果。您也可以通过选择相应的 .sql 文件并点击来测试您在仓库中已编写的现有查询 .

要在 SQL Scratchpad 中访问输入数据集的特定分支，请在查询前加上分支名称：例如 SELECT * FROM `branch_A`.`/path/to/dataset`。如果未指定分支，将默认使用 master.

要查看标记为收藏的查询，请转到 标签页。要查看在 SQL helper 中运行的查询历史记录，请转到 标签页。

状态栏

状态栏提供有关环境状态和检查结果的信息。您可以在状态栏中找到的信息包括：

  • Code Assist 状态 - Code Assist 对于检测代码中的问题和运行预览至关重要。您可以在没有 Code Assist 的情况下编写代码，但需要它正常运行才能完成您的工作。将鼠标悬停在 Code Assist 状态上可获取初始化进度的详细信息。如果 Code Assist 初始化失败，请提交支持请求。
  • 问题 - 当在您的代码中检测到问题时，状态栏左侧会出现一个指示。点击该指示可打开问题 helper。
  • 检查状态 - 检查状态显示在状态栏的右侧。有关检查的更多详细信息，请参见 检查标签页.
  • 文件保存 - 在任何更改之后，文件保存状态会显示自动保存的进度。

分支标签页

在监听器设置向导的 提供了专为数据转换量身定制的版本控制体验，支持团队在同一工作簿中同时处理逻辑与数据。 标签页中，您可以查看 Code Repository 中现有分支的列表——包括您自己的分支以及其他用户的分支。点击 按钮可创建一个新的沙箱分支，其中包含特定分支上代码的副本。

每个列出的分支都包含一个摘要，具有以下可用功能：

  • “检查”列指示某个分支是否已通过自动代码检查。
  • “拉取请求”列会告诉您分支中是否存在任何现有的 拉取请求 ，并允许您创建新的 拉取请求。 要创建一个新的 拉取请求 （其中包含分支上的更改），请点击“提议更改”按钮。这将创建一个新的 拉取请求 ，用于将您的更改合并到 master 分支（默认）。如果您想将更改合并到其他分支而不是 master，请从下拉菜单中选择其他分支。 如果您没有看到创建新 拉取请求的按钮，则表示某个分支已存在一个 拉取请求 。点击“打开”/“已关闭”/“已合并”按钮可打开完整的 拉取请求.
  • 点击分支名称旁边的“查看代码”可查看该分支上的代码。
  • 要删除分支，请点击 icon. 您不应删除非您创建的分支，否则可能导致他人的工作丢失。

您还可以创建新分支和新的 拉取请求 来自 文件更改.

标签标签页

在监听器设置向导的 标签 选项卡中，您可以访问 标签列表，标签类似于不可变的分支。标签可以通过为其指定版本号或名称，用于标记代码的重要版本以供将来参考。要创建新标签，请选择 新标签。标签可以基于分支的当前版本创建，也可以基于任意提交创建。

为了强制所有标签名称遵循特定的命名规范，您可以在名为 tagNameValidation 的文件中添加配置块，该文件位于仓库根目录。示例配置块及所需的 repoSettings.json 字段，请参见 regex 和 errorMessage 字段，请参见 高级仓库设置.

有关推荐的 git 开发工作流程的更多信息，请参阅 开发者最佳实践.

拉取请求标签页

在监听器设置向导的 拉取请求 选项卡中，您可以找到有关 拉取请求 在您的代码仓库中的信息。 拉取请求 允许用户查看分支上的更改历史记录，并在合并更改之前逐行审查您的代码。每当您想将分支上的更改合并到主代码时，您都应该创建一个新的 拉取请求.

值 按钮以创建新的 拉取请求。默认情况下，新创建的 拉取请求 会将您的更改合并到仓库的主分支（通常是 master 分支）。请选择您希望基于哪个分支来创建新的 拉取请求 。您还可以创建 拉取请求 来自 文件更改.

筛选拉取请求

您可以通过点击拉取请求列表顶部的“打开”/“已关闭”按钮，在打开和已关闭的 拉取请求 列表之间切换，并使用搜索栏根据标题或作者进一步筛选列表。

审查拉取请求

点击其中一个 拉取请求 以逐行审查提议的代码更改并添加评论。根据仓库设置，每个 拉取请求 在合并之前可能至少需要一次批准的审查。

在审查 Transforms 代码的更改时，您还可以查看 这些更改如何影响您的数据集.

检查标签页

在监听器设置向导的 检查 选项卡中，您可以查看每个分支上正在运行和已完成的检查的摘要。使用下拉分支菜单选择其他分支。点击特定检查可查看更详细的信息。

检查选项卡还将包含为您的仓库定义的任何单元测试的输出。您可以为 或 和 Python.

如果您的堆栈上启用了 AIP， 错误增强器小部件 将补充失败检查的详细信息视图，帮助您更好地理解和解决出现的问题。

设置标签页

在设置选项卡中，代码作者可以配置其个人编辑器偏好设置，仓库管理员可以控制仓库的行为和策略。要了解有关设置选项卡的更多信息，请参见 管理代码仓库.

中的大多数选项 设置 选项卡面向管理员，仅对具有相应权限的用户（默认为仓库所有者）可用。
