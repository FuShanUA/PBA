由计算模块支撑的模型

由计算模块支撑的模型允许您在 计算模块 中托管大语言模型服务器，并将其注册为 AIP 中的一等模型。注册后的模型将显示在所有 受支持的应用程序的模型选择器中，就像 Palantir 提供的模型或通过 REST API 注册的模型一样。

此方法适用于两种主要场景：

  • 在您自己的计算资源上自托管模型： 您可以使用由计算模块支撑的模型在您自己的 GPU 上运行开源或自定义模型，以满足数据主权、本地部署或隔离网络部署、成本控制或抢先体验新发布模型的需求。
  • 构建自定义代理或联合层： 您可以使用由计算模块支撑的模型来重新映射 API 格式、注入提示词、在数据到达外部提供商之前对其进行脱敏处理，或者在单个注册模型背后联合跨多个提供商的请求。

前提条件

您的计算模块应用必须满足以下要求，才能将其注册为模型源：

  • 提供受支持的提供商 API 格式： 您的容器必须公开符合以下任一 受支持的提供商 API 格式的 API。诸如 vLLM 和 Ollama 之类的推理服务器默认公开兼容的 API。

  • 设置应用程序端口： 您必须在 Dockerfile 中添加一个 application.port 标签，指向您的模型服务器所监听的端口。例如 LABEL application.port='8000'。如需通用容器指南，请参阅 计算模块容器文档。

  • 将最小副本数设置为至少一个： 为您的计算模块配置至少一个副本。请参阅有关 最小副本数 的文档以了解详情。

注册并使用模型

您必须是 Enrollment 管理员 才能注册模型。

您的计算模块运行后，请在控制面板中将其注册为模型：

  1. 导航至 AIP 设置 扩展，并选择 已注册模型 选项卡。

  2. 选择 注册模型。

  3. 选择您的计算模块作为源。

  4. 配置 模型 ID。将其设置为您的模型服务器所期望的标识符，例如推理服务器所使用的模型名称。

  5. 定义模型的能力。启用 推理、 结构化输出和 工具调用 可确保 AI FDE 和 AIP Analyst 能够使用该模型。

  6. 为模型定义速率限制。请参阅 已注册模型支持的功能 ，以了解有关 Enrollment 和用户速率限制的详情。

  7. 为您的 Enrollment 或特定用户组启用已注册模型的访问权限。

您注册的模型现在将出现在所有 受支持应用程序的模型选择器中。

后续步骤

现在您已拥有由计算模块支撑的注册模型，您可以使用该计算模块 通过 AIP 自托管模型，或者您也可以使用该计算模块 构建代理层或联合层。
