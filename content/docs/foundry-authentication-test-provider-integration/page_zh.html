启用并测试身份提供商集成

启用身份验证

您必须先启用 SAML 或 OIDC 提供商才能测试您的集成。如果使用 Foundry 设置链接，请跳到下一步。否则，请前往 提供商管理 页面并开启 启用提供商 以启用所需的提供商。之后您即可使用新的集成登录 Foundry。

测试集成

要验证身份提供商集成的配置，您可以创建测试登录。如果使用 Foundry 设置链接，请点击 登录 Foundry 以自动创建一个测试登录。

或者，在平台内导航至 SAML or OIDC 页面并选择 测试 SAML 用户偏好 创建新测试。有两种测试方式：

  • 选择 登录 Foundry 以亲自测试集成。
  • 使用剪贴板复制登录 URL 并发送给其他人。对方尝试登录后，您将能够在摘要视图中看到结果。

您（或收到 URL 的人）登录后，您将能够看到测试结果。这些测试结果会说明登录是否成功，并捕获从您的提供商接收到的用户属性快照。

您可以在 属性预览 标签页中打开该测试，以预览这些属性在 Foundry 中的映射方式。当您更改属性映射配置时，结果将反映在该面板中。

测试结果将在一个月后自动删除。
