变量

变量 由模块构建者用于配置数据在 Workshop 模块中的流动方式。可用 变量类型 的列表如下所示。

要访问 Workshop 模块中的现有变量或定义新变量，请打开 变量 菜单，该菜单位于左侧边栏。

直方图 变量 面板（如上所示）显示模块中当前存在的变量列表、一个加号 + 用于添加新变量的选项、用于创建变量文件夹的文件夹图标、用于按名称或唯一 ID 搜索变量的输入框、用于打开 变量血缘图的选项，以及一个用于根据定义类型或已启用的设置来显示变量的筛选器。变量列表包含分区，可帮助您快速找到相关变量：当选中某个小部件时，某个分区会显示该小部件使用的变量；当未选中任何小部件时，某个分区会显示当前页面中使用的变量。

从左侧列表中选择一个变量后，您可以在变量列表右侧打开的窗口中查看和修改该变量的配置。可用的配置选项如下：

  • 变量名称： 选择变量名称或铅笔图标以编辑名称。使用描述性名称来记录您的模块，并便于日后查找变量。名称在模块内必须唯一。如果名称与现有变量冲突，Workshop 会附加一个数字后缀。匹配不区分大小写，因此 MyVar 和 myvar 重复。如果清除某个名称，Workshop 会恢复其先前的值。要对相关变量进行分组，请选择 变量 面板标题中的文件夹图标来创建变量文件夹，然后将变量分配给它。您还可以在名称前添加上下文标识符，例如 $page_ or $tab_，后跟页面或标签页名称，以便相关变量排列在一起。例如，使用 $page_Dashboard_filterState or $tab_Overview_selectedObject.

  • 变量定义类型： 变量名称旁边有一个下拉菜单，提供有关如何定义给定变量以及如何为其填充数据的选项。可用选项会因所选变量类型而异，可能包括以下选项：

    • 静态： 用于手动设置变量值
    • 函数： 用于由函数支撑、动态计算的变量
    • 给定一个对象和该对象类型的指定属性，返回属性值。 用于从对象集聚合派生的变量
    • 对给定的对象集中的对象是否存在进行布尔检查。 用于与单个对象的所选属性值关联的变量
      • 注意： 复杂且性能不佳的对象属性 在 Workshop 中不受支持作为变量。
    • 对象集定义： 专门用于由所选对象类型、筛选器和关联对象遍历定义的对象集变量
    • 变量转换： 用于将变量值定义为一系列常见操作，可能会引用其他变量；请查看 变量转换 文档以了解更多信息。
    • SQL 查询： 用于通过针对模块中的对象集和其他变量运行本体论 SQL 查询来计算的变量；请查看 SQL 查询变量 文档以了解更多信息。

  • 删除变量（垃圾桶图标）： 模块中未被使用（被小部件或下游变量使用）的变量可以被删除。

  • 从当前变量创建新变量（仅限对象集变量）： 在复制变量按钮旁边， 从当前变量创建新变量 按钮允许您创建一个新的对象集变量，该变量自动将当前对象集作为其输入。当您希望在保持对源变量引用的同时，基于现有对象集的配置进行构建时，这非常有用。

  • 变量定义配置： 屏幕的主要部分，用于配置变量的具体细节。此处提供的选项会根据所选的变量类型和变量定义类型而变化，并会提供屏幕上的说明。

  • 变量设置： 变量设置面板允许配置外部 ID，以及为给定变量启用以下哪些功能。

    • 模块接口
    • 路由
    • 状态保存

变量延迟加载

在查看和编辑模式下，Workshop 可以将变量计算延迟到可见的 widget、布局或其他必需的变量需要该值时再进行。这也适用于嵌入模块中的变量。例如，仅在隐藏标签页中使用的变量，其计算可以等到该标签页显示时再执行。某些用途（例如控制布局可见性）在某个部分处于隐藏状态时仍可能触发计算。参见 加载和数据刷新 的文档以获取更多信息。

变量加载指示器

Workshop 在评估变量时会显示加载指示器。

变量类型

Workshop 支持以下变量类型：

  • 数组： 接受布尔值、日期、数值、地理点、地理形状、字符串、时间戳或结构体值的数组。
  • 布尔值： 接受以下类型的值： true or false。可从静态值或函数、聚合或对象属性的输出进行初始化。
  • 日期： 接受日期。可从静态值或函数、聚合或对象属性的输出进行初始化。
  • GeoPoint： 接受地理点。从对象属性进行初始化。
  • 地理形状（GeoShape）： 接受地理形状。从对象属性或函数的输出进行初始化。
  • 数值： 接受数值，包括整数和浮点数。可从静态值或函数、聚合或对象属性的输出进行初始化。
  • 导入对象集： 存储一个或多个对象的集合。可以从对象类型、 本体论接口或其他对象集变量进行初始化。然后，你可以按属性值或 Filter 变量对其进行筛选，或通过 Search Around 关联到关联的对象。你还可以通过 共享属性类型 or 对象支撑的关联类型.
  • 对象集过滤器： 存储一组用于过滤对象集变量的属性类型/属性值对。从对象类型以及一组属性类型/属性值过滤对进行初始化。参见 对象集过滤变量 的文档以获取更多信息。
  • 或 接受文本。可从静态值或函数、聚合或对象属性的输出进行初始化。
  • 结构体： 存储将字符串 fieldID 映射到值的复合类型。目前不支持嵌套结构体，但结构体字段值可接受任何其他 Workshop 变量类型。从函数的输出进行初始化。参见 结构体变量 的文档以获取更多信息。
  • Timestamp： 接受时间戳。可从静态值或函数、聚合或对象属性的输出进行初始化。
  • 时间序列集： 存储单个对象的时间序列属性，并可选择对其应用时间序列转换。参见 Workshop 中的时间序列属性 的文档以获取更多信息。

重新计算变量值

对于支持的变量定义， 重新计算变量值 控制 Workshop 是自动重新计算值、仅在事件触发时重新计算，还是在模块加载时以及事件触发时重新计算。参见 变量重新计算行为 以了解可用选项、支持的定义和限制。

变量血缘图

在 变量 面板的页眉中选择网络中心图标，以打开变量血缘图。该图显示模块中的变量和控件之间的相互依赖关系。使用它来调试重新计算行为、追踪哪些控件读取或写入某个变量，以及理解应用程序元素之间的关系。

要探索特定变量，请在 变量 面板中打开特定页面所在行的 查看血缘 位于 变量使用情况 在其详情面板中。Workshop 会打开该图，并添加该变量及其直接上游依赖项和下游使用者。现有的图节点保持不变。当图处于打开状态时，从列表中选择另一个变量会仅添加该变量。关闭并重新打开该图会保留其节点。

展开图表

图表上的每个节点代表一个变量或控件。具有依赖关系的节点在其顶部和底部边缘有箭头标记。选择箭头可展开节点的父级（上游依赖项）或子级（下游使用者），并在模块中追踪一系列关系。使用 全部显示 图表头部中的操作可展开完整的应用程序图表，或 清除 以移除所有节点并关闭详情面板。

图表头部中的撤销和重做选项可在展开、折叠和选择操作之间向前和向后切换，与模块自身的撤销/重做控件相对应。

每个节点可以显示变量所使用的页面和覆盖层，以及变量被计算的时间。

页面和覆盖层

节点会标记其被引用的页面和覆盖层。切换 显示页面和覆盖层 头部中的选项可显示一个图例，列出正在使用的每个页面和覆盖层。图例仅列出在可见图表节点上出现的页面和覆盖层，因此列表范围仅限于您在图表中可以看到的内容。

计算时间

开关 显示计算时间 头部中的选项可显示每个变量的时间信息。计算时间指的是变量的值在应用程序中最后一次被计算的时间（即用户所看到的时间），而不是底层数据在应用程序之外最后一次更新的时间。重新计算耗时较长的变量可能需要重构：例如，将复杂的函数支撑变量拆分为较小的部分，或更改上游变量的重新计算行为以避免不必要的计算。
