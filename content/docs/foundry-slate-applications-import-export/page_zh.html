导入、导出和复制应用程序

不建议使用这些工作流来共享或复制复杂的应用程序。相反，请使用 Marketplace 集成 在 Foundry 实例之间共享应用程序，或使用 另存为 在同一 Foundry 注册中复制应用程序。

导入 Slate 应用程序

要在编辑模式下导入 Slate 应用程序，请选择 文件 > 导入 JSON 以打开 导入 Slate JSON 对话框。将 .slate.json 文件拖到放置区域，或选择 浏览 以选择本地文件。对话框会显示文件名和大小。上传过程中，对话框会显示加载状态并禁用所有输入。如果上传失败，对话框将保持打开状态，并通过 toast 通知显示错误，以便您重试。

如果 JSON 文件中定义的永久链接是新的且唯一的，系统将提示您选择创建新 Slate 文档的位置。如果 Slate 文档 JSON 中定义的永久链接在 Foundry 中已存在，则会使用导入的 JSON 文件的内容创建现有 Slate 文档的新版本。

JSON 导入仅包含应用程序逻辑。Slate 不会自动创建辅助资源，例如图像、文件、对象、数据集和数据源。如果引用的数据源不可用，导入将失败。如果 JSON 包含引用未配置数据源的查询，您可能会遇到错误 You don't have permission to edit queries for all datasources in this document. 要解决此错误，请在导入前从 Slate JSON 中删除这些查询，或先配置所引用的数据源。对其他不存在资源的引用会在您打开应用程序时导致错误。请在编辑模式下手动更新引用来解决这些错误。对于使用 本体论 SDK的应用程序，导入后您可能还需要手动重新生成 OSDK bundle。

导出 Slate 应用程序

要导出 Slate 应用程序，请选择 导出 菜单中选择 文件 下拉菜单（在编辑模式下）。这会将一个 JSON 文件下载到您的本地计算机，其中包含 Slate 应用程序的配置。该配置包括小部件、函数、查询逻辑、事件、变量和样式。它不包含 Foundry 上应用程序本身未包含的其他资源，例如全局样式表、对象、数据源、数据集、操作、图像、视频、JavaScript 以及导入到代码沙盒中的 CSS 库。

复制 Slate 应用程序

可以通过选择 另存为 选项（位于 文件 下拉菜单下，在编辑模式下）来复制 Slate 应用程序。系统将弹出窗口，让您为复制的应用程序输入新位置和名称。新应用程序仅包含原始应用程序的最新版本，并将其存储为 v1。对于使用 本体论 SDK的应用程序，现有 OSDK bundle 将从源应用程序复制，而不是重新生成。

复制 Slate 小部件

您还可以在 Slate 应用程序之间重用小部件。要复制小部件，请先在 Slate 应用程序左侧的布局窗格中选择它。然后，按 Cmd+C （macOS）或 Ctrl+C （Windows）。最后，导航到您的第二个 Slate 应用并按 Cmd+V （macOS）或 Ctrl+V （Windows）以粘贴复制的小部件。

覆盖 Slate 应用程序

直方图 另存为 选项还允许您覆盖现有的 Slate 应用程序。您可以使用此功能来暂存或提升应用程序。要覆盖 Slate 应用程序，请在文件浏览器中选择一个现有应用程序作为保存应用程序的位置。覆盖应用程序时，将创建一个新版本，并复制当前应用程序所选版本的内容。
