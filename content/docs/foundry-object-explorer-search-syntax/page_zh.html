搜索语法

Object Explorer 支持搜索所有对象及其属性。为了帮助您找到所需内容，本页面将介绍适用于 全局搜索栏的搜索语法。

引号

默认情况下，在搜索栏中输入的各个单词将彼此独立地进行搜索。例如，搜索 yellow cab 将返回所有对象，其属性值匹配 yellow 或 cab。

可以使用引号来更改此行为。在 Object Explorer 中搜索 "yellow cab" 将返回所有对象，其一个或多个属性值中包含精确短语 yellow cab 。像这样搜索短语通常会比搜索单个单词返回更少的结果。

逻辑运算符（not/and/or）

运算符 NOT、 AND和 OR 可用于增强 Object Explorer 中的文本搜索功能。

连接运算符

使用 AND 和 OR 作为连接运算符来组合两个不同的搜索条件。具体来说，您可以使用 AND 来搜索同时满足两个条件的项，而 OR 则搜索满足至少一个条件的项。例如，要搜索同时涉及曼哈顿和布鲁克林的出租车行程，可以搜索 Manhattan AND Brooklyn类似地，要搜索涉及曼哈顿或布鲁克林的出租车行程，可以搜索 Manhattan OR Brooklyn。

否定运算符

与同时应用于多个条件的联接运算符（如 dogs AND cats 或 vanilla OR chocolate）不同， NOT 运算符应用于单个条件，以搜索 不 满足该条件的元素。

例如，如果您搜索 NOT Brooklyn，则 Object Explorer 将返回所有搜索结果， 但不包括 提及布鲁克林的结果。 NOT 运算符还可应用于复合条件。或者，搜索 NOT (Manhattan OR Brooklyn) 将返回所有搜索结果， 但不包括 提及布鲁克林或曼哈顿的结果。

组合使用运算符

使用引号创建的短语也可以纳入搜索中。例如， "yellow cab" AND Manhattan 是一个有效的表达式。

逻辑运算符也可以使用括号构建成更复杂的表达式。例如，此搜索将返回不引用曼哈顿但引用黄色或绿色出租车的对象： ("yellow cab" OR "green cab") AND (NOT Manhattan)。

通配符

  • ?：问号可用于替换单个字符。
    • 搜索 qu?ck 将返回 quick、 quack、 qu4ck等结果。
  • *：星号可用于替换零个或多个字符。
    • 搜索 bro* 将返回 bro、 brother、 broadcasting等结果。
    • 还支持前导通配符：搜索 *smith 将返回 smith、 Goldsmith、 Blacksmith等结果。前导通配符需要 启用前导通配符 渲染提示需在 Ontology Manager中的字符串属性上启用。有关更多信息，请参阅 渲染提示。

组合使用前导和尾随通配符（*term*）不受支持。您可以使用前导通配符（*term）或尾随通配符（term*），但不能同时使用两者。如果您需要执行此类查询，请考虑使用其他工具，例如 Contour。

有关文本搜索在整个平台中的工作原理的详细说明（包括分析器行为以及 Workshop 和 Functions API 中的搜索功能），请参阅 了解文本搜索。

模糊搜索

在搜索词末尾使用 ~ 运算符，可对相似词和完全匹配项执行“模糊”匹配。例如， quikc~ 将返回 quick 和 quack的结果。
