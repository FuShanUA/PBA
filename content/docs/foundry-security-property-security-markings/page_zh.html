属性安全标记

请先查看 标记 和 基于分类的访问控制（CBAC） 的相关文档，然后再进一步了解 Foundry 中的属性安全标记。

属性安全标记会显示通过 对象和属性安全策略 配置的标记和 CBAC 值。当您在以下 Workshop 组件中查看或选择属性时：

  • 属性列表
  • 对象列表
  • 对象表格

属性安全标记严格仅用于提供信息，呈现为紧凑的灰色药丸标签，选中时会展开窗口视图。

Foundry 会对照安全标记验证每个属性，以确保所有具有相应访问权限的用户都能查看其值，即使您在任一受支持的组件中关闭了药丸标签的可见性也是如此。属性安全标记隐藏了查看属性数据所需要求的一些复杂性。例如，带有 Mock Unclassified CBAC 标记的属性，若位于同样带有 Mock Secret CBAC 标记的对象中，将显示为 Mock Unclassified （在对象视图中）。但是，用户必须拥有对 Mock Secret CBAC 标记的访问权限，才能查看该属性的数据。

详细了解 Foundry 的严格访问要求和用户权限控制。

随着该功能在持续开发过程中不断成熟，查看属性安全标记的功能将扩展至更多 Workshop 组件和其他 Foundry 应用程序。

在 Workshop 中查看属性安全标记

开启 显示安全标记 （位于 小组件设置 标签页），在 Workshop 中配置属性列表、对象列表或对象表格小组件时，再从以下显示选项中进行选择：

  • 响应式： 在空间允许时显示完整的安全标记，并显示截断的标签以适应可用空间。悬停时，Foundry 会在工具提示中显示完整的标记。此选项不适用于对象表格小组件。
  • 完整标签： 始终显示完整的安全标记，在宽度较小时自动换行。
  • 仅图标： 显示标记图标，仅在悬停时显示完整的安全标记。

如果您的注册中不包含 CBAC 标记，则无需从上述选项中进行选择。Foundry 仅在包含强制标记的属性旁边显示标记盾牌图标，并在悬停时呈现标记标签。

在对象列表或属性列表小组件中，选择属性值右侧的属性安全标记胶囊，以呈现展开视图。

要在对象表格小组件中呈现同样的展开视图，请将鼠标悬停在表格中的属性值上。

属性基础类型的预期行为

属性安全标记的显示行为因属性的 基类型而异。

  • 结构体： 在 结构体 字段中，每个值都包含相同的属性安全标记，Foundry 会将其显示在单个药丸中。

  • 数组： 在以数组形式包含多个值的基类型中，每个值都包含相同的属性安全标记，Foundry 会将其分别显示在单独的药丸中。

  • 派生属性： 对于 派生属性 ，每个值可能具有不同的安全标记，无论该属性是使用 Collect list 聚合方法从其他单一属性还是结构体属性派生的。

不支持的属性基类型

目前，Foundry 不支持以下属性基类型的属性安全标记：

  • 以下类型的数组：
    • Cipher text
    • 媒体引用
    • 附件
  • Geoshape
  • 地理时间序列引用
  • 时间序列
  • 向量

此外，当您将光标悬停在 Object Table 小部件中的属性值上时，Foundry 不会渲染以下属性基类型的属性安全标记：

  • 附件
  • Cipher text
  • 地理时间序列引用
  • 媒体引用
  • 向量
