Cloud Fetch

Cloud Fetch 是 Databricks JDBC 驱动程序的一项功能。Cloud Fetch 通过云存储实现从 Databricks 到 Foundry 的并行数据提取，与传统的单线程传输相比，性能最高可提升 10 倍。

启用后，可能需要额外的网络策略来允许与云存储服务（AWS S3、Azure Data Lake Storage 或 Google Cloud Storage）的出站连接，Databricks 会将查询结果临时存储在这些服务中。如果您使用的是 Foundry worker 连接，则需要为工作区存储桶创建出站策略。这是 Cloud Fetch 使用的云存储位置。

查看 Databricks 官方文档 ↗ 了解详情。

对存储位置的外部访问（仅限虚拟表）

直方图 虚拟表 本文档的部分提供了有关 外部访问 在 Unity Catalog 中的详细信息及其启用的功能。外部访问需要与表的存储位置（托管或外部）建立网络连接。需要为每个存储位置创建出站策略，才能受益于外部访问所启用的功能。

更多选项:SSL 和主机名验证

您可能还需要传入一个 JDBC 属性以允许自签名证书。

如何判断是否需要此属性:

  • SSL 连接会验证服务器证书。通常,SSL 验证通过证书链进行。默认情况下,代理和 Foundry worker 均信任大多数行业标准证书链。
  • 服务器必须提供完整的证书链,SSL 验证才能正常工作。要获取 Databricks 服务器的证书链,请运行命令 openssl s_client -connect {hostname}:{port} -showcerts,然后使用 OpenSSL 命令行实用程序或任何其他可用工具验证该链。
  • 如果您连接的服务器使用自签名证书,或者防火墙对连接执行 TLS 拦截,则连接器必须信任该证书。详细了解 在基于代理的连接中使用证书.
  • 如果您正在创建 Foundry worker 连接并使用自签名证书,则需要为其添加一个 JDBC 属性 AllowSelfSignedCerts=1 property.

如何添加允许自签名证书的属性:

  • 在 连接详情 页面,位于 。这两项配置均可通过在数据连接中导航到相应数据源并打开 select 更多选项 then 属性 ↗.
  • 自动预览行为 属性 ↗ 配置中,选择 添加属性 then 新建属性 然后输入 AllowSelfSignedCerts 作为键，并将 1 作为值。

当 AllowSelfSignedCerts 属性设置为 1时,SSL 验证将被禁用。在这种情况下,连接器不会针对信任库验证服务器证书,也不会验证服务器的主机名是否与服务器证书中的公用名或主题备用名称匹配。

直方图 AllowSelfSignedCerts 属性和其他 JDBC 属性在 Databricks 驱动程序文档 ↗中有所说明。本文档中概述的 JDBC 属性特定于 Databricks 驱动程序,与其他源类型有所不同。

虚拟表

虚拟表 允许您连接到在 Databricks Unity Catalog 中注册的数据。这使您既可以从 Foundry 读取和写入 Databricks 中的表,也可以将计算从 Foundry 中的管道下推到 Databricks。本部分提供了有关在 Databricks 中使用虚拟表的其他详细信息。本部分不适用于同步到 Foundry 数据集的情况。

Databricks 连接器在使用虚拟表公开 Delta Lake 和 Apache Iceberg 的功能时提供增强功能。此功能需要 外部访问 在 Unity Catalog 中启用。启用后，外部访问允许 Foundry 使用 Unity REST API 和 Iceberg REST 目录访问表，并在底层存储位置读取和写入数据。Unity Catalog 凭据分发用于确保对云对象存储的安全访问。除增强功能外，这还可以提高对这些表进行读取和写入的性能。

如果您满足以下条件，Databricks 连接器会自动公开 Delta Lake 和 Apache Iceberg 功能：

  1. 在 Unity Catalog 中启用外部访问。
  2. 组织 网络出口策略 允许从 Foundry 连接到表的存储位置。
  3. 在源上配置可以从 Unity Catalog 获取分发凭据的凭据。

读取或写入表的连接将使用 Delta Lake 或 Apache Iceberg 客户端直接连接到存储位置。读取或写入表时不会使用 Databricks 计算。Unity Catalog REST API 将用于某些元数据操作，例如确定所访问表的类型。

请参阅 Databricks 官方文档 ↗ 以了解有关外部访问以及如何确定表存储位置的更多信息。请参阅 网络 本文档的相关章节，了解启用对存储位置的网络访问的详细信息。

使用外部访问需要 Unity Catalog 凭据分发。并非所有表类型和表功能都支持凭据分发。例如，视图或带有行筛选器的表不支持凭据分发。请参阅 Databricks 官方文档 ↗ 以了解有关凭据分发及其要求的更多信息。

如果不满足上述任何要求，将使用 JDBC 建立与 Databricks 的连接。JDBC 与用于 同步对象，您的计算函数必须接受一个名为 Databricks 官方文档 ↗ 以了解有关通过 JDBC 连接到 Databricks 的更多信息。

class FoundrySourceIdTokenSource(oidc.IdTokenSource):
    """Supply refreshable Foundry identity tokens to the Databricks SDK."""

    def __init__(self, refreshable):
        self._refreshable = refreshable

    def id_token(self) -> oidc.IdToken:
        # This field holds the Foundry identity token, not a Databricks token.
        return oidc.IdToken(jwt=self._refreshable.get().access_token)


def read_connection_settings(source: ResolvedSource):
    configuration = source.source_configuration

    if configuration.type != "databricks":
        raise ValueError("Expected a Databricks connection")

    authentication = configuration.authentication
    if authentication.type != "workflowIdentityFederation":
        raise ValueError("Expected OIDC federation authentication")

    client_id = authentication.service_principal_application_id
    if not client_id:
        raise ValueError("A service principal application ID is required")

    hostname = configuration.host_name.removeprefix("https://").rstrip("/")

    return hostname, configuration.http_path, client_id


def configure_egress(source: ResolvedSource) -> None:
    proxy = source.get_https_proxy_uri()
    if proxy:
        os.environ["HTTPS_PROXY"] = proxy
        os.environ["HTTP_PROXY"] = proxy

    certificates = source.server_certificates_bundle_path
    if certificates:
        os.environ["REQUESTS_CA_BUNDLE"] = str(certificates)
        os.environ["SSL_CERT_FILE"] = str(certificates)


def create_workspace_client(
    source: ResolvedSource,
    hostname: str,
    client_id: str,
) -> WorkspaceClient:
    refreshable = source.get_session_credentials()

    @credentials_strategy("foundry-source-oidc", [])
    def foundry_oidc(config: Config):
        return oidc_credentials_provider(
            config,
            FoundrySourceIdTokenSource(refreshable),
        )

    return WorkspaceClient(
        host=f"https://{hostname}",
        client_id=client_id,
        credentials_strategy=foundry_oidc,
    )


def get_exchanged_access_token(client: WorkspaceClient) -> str:
    authorization = client.config.authenticate().get("Authorization", "")
    scheme, _, access_token = authorization.partition(" ")

    if scheme.lower() != "bearer" or not access_token:
        raise RuntimeError("Expected a Databricks bearer token")

    return access_token


@external_systems(
    databricks_source=Source("<source_rid>"),
)
@transform.using(
    output=Output("<output_dataset_rid>"),
)
def compute(output, databricks_source: ResolvedSource):
    hostname, http_path, client_id = read_connection_settings(
        databricks_source
    )
    configure_egress(databricks_source)

    client = create_workspace_client(
        databricks_source,
        hostname,
        client_id,
    )

    # Validate authentication without logging or persisting identity details.
    client.current_user.me()

    # The SDK exchanges the Foundry identity token for a Databricks OAuth token.
    access_token = get_exchanged_access_token(client)

    with databricks.sql.connect(
        server_hostname=hostname,
        http_path=http_path,
        access_token=access_token,
    ) as connection:
        with connection.cursor() as cursor:
            cursor.execute("""
                SELECT COUNT(*) AS visible_table_count
                FROM `<catalog_name>`.`information_schema`.`tables`
                WHERE table_schema = '<schema_name>'
            """)
            row = cursor.fetchone()

            if row is None:
                raise RuntimeError("Catalog query returned no result")

            visible_table_count = int(row[0])

    output.write_table(
        pl.DataFrame({
            "check_id": ["databricks_oidc_catalog_access"],
            "identity_check_succeeded": [True],
            "catalog_query_succeeded": [True],
            "visible_table_count": [visible_table_count],
        })
    )

如果您只需要 Databricks REST API，请直接使用 WorkspaceClient 并省略 get_exchanged_access_token；SDK 会在每次调用时为您附加并刷新交换的令牌。

有关在启用 OIDC 的源中使用会话凭据的更多详细信息，请查阅 Python 中的源 文档。
