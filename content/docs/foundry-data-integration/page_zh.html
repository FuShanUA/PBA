数据连接与集成

Foundry 提供了一套高度可配置的数据连接与集成工具，其功能远远超出了典型的提取-转换-加载（ETL）或提取-加载-转换（ELT）解决方案。Foundry 的设计初衷是通过一整套丰富的功能为数据团队带来力量倍增效应，从而随着时间推移不断降低数据集成的成本。虽然商品化云服务可以为基本管道和实验提供存储与计算资源，但要为关键业务运营管理、交付和验证数据集，还需要许多额外的能力层。Foundry 旨在充当全球最复杂环境的数据集成支柱。

连接数据

这一切始于一个可扩展的数据连接框架，该框架能够与所有类型的源系统（结构化、非结构化或半结构化）以及所有关键的数据传输方式（如批处理、微批处理或流式传输）建立连接。该功能与平台的数据转换和数据管理功能相集成，其中包括完整的数据版本血缘、用于协作管理数据提取的细粒度安全控制，以及数据同步配置的分支功能。

详细了解如何在 Foundry 中连接数据。

数据转换

对于 数据转换，Foundry 提供了一个可扩展、可伸缩的 数据构建系统 它利用多模态计算来生成输出数据集。Foundry 的计算无关型“Build”框架提供完全集成的安全性和数据血缘，并支持混搭使用第三方计算运行时。Foundry 还包含一套集成功能，涵盖数据转换编写、变更管理、数据质量、管道调度和元数据内省，这些功能协同运作，为数据工程师提供一个“任务控制中心”。

管道管理

Foundry 的 管道管理 功能将变更管理、数据质量与数据加载等特性相结合。

管道构建器应用程序支持快速、灵活且可扩展的数据管道交付，同时提供稳健性与安全性。 了解更多关于管道构建器的信息。

数据工程师可以为生产管道定义严格的发布流程，其中包括健康检查，确保只有完全合规的数据才会被部署到生产环境。发现问题时，平台会针对检测到的差异提供诊断信息。

诊断功能不仅可在 Foundry 的集成分析和建模工具中使用，也可供通过 REST API 或其他接口访问输出数据的任何第三方工具使用。
