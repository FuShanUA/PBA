活动

对象监控器已被 Automate取代。Automate 是一款完全向后兼容的产品，为平台中的所有业务自动化提供统一入口。

对象监控器活动会根据条件以及在特定元数据属性发生更改或更新时进行记录。

用户订阅的所有监控器的活动时间线显示在对象监控器应用程序的 概览 页面上。

单个监控器的活动时间线显示在该监控器概览面板的 历史记录 标签页中。

活动事件类型

Monitor triggered

Monitor triggered 会在阈值条件的状态从 false 变为 true 时记录，以及在事件条件检测到事件时也会记录。

Monitor recovered

Monitor recovered 会在阈值条件的状态从 true 变为 false时记录。事件条件绝不会导致 monitor recovered 活动。

Condition edited

Condition edited 会在任意用户更新监控器条件时记录。

Subscribed

Subscribed 会在您订阅监控器时记录。您未订阅期间的活动将不会被记录或显示。

Unsubscribed

Unsubscribed 会在您取消订阅监控器时记录。您未订阅期间的活动将不会被记录或显示。

Evaluation failed

Evaluation failed 在监视器因任何原因评估失败时记录。有关失败的详细信息可在该监视器的活动 历史 视图中查看。 Evaluation failed 在监视器条件已成功评估但通知或操作失败的情况下也可能显示。

Muted

Muted 在任一用户将监视器静音时记录。静音适用于所有订阅者。静音的监视器仍会被评估，但不会触发任何副作用（例如通知或操作）。

Unmuted

Unmuted 在监视器被取消静音时记录。静音适用于所有订阅者，静音时间段到期后，监视器将自动取消静音。

Disabled

Disabled 在任一用户禁用监视器或监视器因活动过多而被自动禁用时记录。禁用适用于所有订阅者。已禁用的监视器不会被评估。

Enabled

Enabled 在监视器被重新启用时记录。启用适用于所有订阅者，禁用时间段到期后，监视器将自动重新启用。
