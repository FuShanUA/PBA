将旧版 Foundry 报告转换为 Contour 或 Notepad

旧版 Foundry 报告可以转换为 Contour 仪表板或 Notepad 文档。

在转换过程中，原始报告不会被删除，您可以多次转换同一份报告。除非需要编辑，否则旧版报告无需转换。

报告转换完成后，您可以选择其中一个转换后的资源作为“指定替代品”，使其成为原始报告的权威转换版本。

选择 Contour 或 Notepad

Foundry 报告会根据报告内容推荐最合适的工具，但您也可以按照下文说明选择转换为 Contour 仪表板或 Notepad 文档。

  • Contour 仪表板 最适合由 Contour 分析驱动的内容。与报告相比，Contour 仪表板提供了更强的交互性，例如图表间筛选功能，以及在迭代分析的同时通过简单的拖放界面构建仪表板。Contour 仪表板还支持全屏演示视图和 PDF 导出。在以下情况下选择 Contour 仪表板：
    • 您的报告仅包含 Contour 嵌入内容。
    • 您的报告使用了参数。
  • Notepad 文档 最适合跨产品报告。使用 Notepad，您可以创建实时更新和静态（“时间点”）文档、为文档添加批注、在平台内共享文档，以及将文档导出为 PDF。在以下情况下选择 Notepad 文档：
    • 您不需要参数或图表间筛选提供的交互性。
    • 您的报告包含 Contour 仪表板不支持的嵌入内容，例如 Quiver 图表、Code Workbook 可视化或对象视图。此类报告仍可转换为 Contour 仪表板，但这些小部件将被替换为指向其在 Foundry 中源资源的链接。

转换报告

按照以下步骤转换旧版报告（示例图像中使用的所有数据均为虚构）：

  1. 在 Foundry 报告中打开该报告。

  2. 选择 转换报告 在报告顶部的横幅中。



  3. 按照报告转换对话框中的步骤操作，系统将引导您选择 Contour 或 Notepad 作为转换目标并确认您的选择。



  4. 为转换后的资源选择名称和保存位置。

选择指定替代品

旧版 Foundry 报告至少转换为 Contour 或 Notepad 一次后，您可以通过原始报告顶部显示的横幅访问转换后的资源。您还可以选择其中一个资源作为原始报告的指定替代品。

选定指定替代品后，任何在报告应用程序中打开原始报告的用户都会在顶部显示的横幅中看到指向新 Contour 仪表板或 Notepad 文档的链接。

如果您在选定指定替代品后改变主意，可以将该资源降级，并选择其他资源替代。
