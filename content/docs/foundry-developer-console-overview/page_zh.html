Developer Console

使用 Developer Console 构建和管理 自定义应用程序 及其关联的授权客户端和 SDK。自定义应用程序允许开发者通过托管在 Foundry 内部或外部的自定义逻辑来扩展 Foundry 的功能。旧版 Oauth 客户端也在 Developer Console 中进行管理。

自定义应用程序

自定义应用程序的主要组件如下：

  1. 授权客户端： 一个 OAuth 客户端 允许人类用户和服务用户通过编程方式访问 Foundry。
  2. SDK： 从添加到应用程序中的资源生成的一个或多个 SDK。请参阅 应用程序限制。
  3. SDK 文档： 针对应用程序的 SDK 定制的自动生成的 API 文档和代码片段。
  4. 权限： 用户和应用程序级别的访问控制。请参阅 权限。
  5. 指标： 应用程序的使用情况和性能洞察。请参阅 应用程序指标。
  6. Web 托管（可选）： 在 Foundry 子域名上托管自定义前端。
  7. 代码仓库（可选）： 用于应用程序代码的关联代码仓库资源。

OAuth 客户端

OAuth 客户端是一种与自定义应用程序类似的旧版基元，但仅包含授权客户端，而不包含 以上所列的任何其他功能。OAuth 客户端通常用于向程序化用户授予不受限制的访问权限。建议 不受限制的应用程序 来代替 OAuth 客户端。

开发者控制台首页

开发者控制台首页列出了您有权访问的自定义应用程序和 OAuth 客户端。

有关访问权限要求的更多信息，请查阅 权限文档。

应用程序页面

应用概览

在应用概览页面，您可以：

  • 查看网站托管状态和生成的 SDK 版本。
  • 查看应用 OSDK 中包含的本体论资源。
  • 编辑应用元数据或删除应用。

关于 OAuth 客户端，请参阅 在 Developer Console 中管理 OAuth 客户端。

OAuth 与限制

为您的应用程序配置身份验证流程和资源访问限制。这些限制确保令牌仅授予对已批准给该应用程序的资源的访问权限。

深入了解 配置权限 和 应用程序限制。

SDK 文档

每个应用程序都包含自动生成且针对其 SDK 内容定制的 API 文档。您可以通过在左侧面板中选择 API 文档 来访问它。

API 文档包括：

  • 适用于您的应用程序专属 SDK 的安装指南。
  • 用于加载单个对象和分页获取数据的代码示例。
  • 每个本体论对象类型、操作类型和函数的参考资料。

使用语言下拉菜单在 TypeScript、Python 和其他受支持的语言之间切换。

共享与令牌

与用户、组和组织共享您的应用程序。生成长期有效的限定作用域令牌，用于程序化访问。

Web 托管

直接在 Foundry 上托管纯前端应用程序（如 React 单页应用），无需使用外部托管基础设施。

如需了解更多详情，请查阅相关文档： 在 Foundry 上托管 OSDK 应用程序。

指标

监控应用程序性能，包括请求量、成功率和 API 延迟。

了解更多关于应用程序指标的信息。

限制

默认情况下，每个 Developer Console 应用程序的数据资源和资源访问限制总数上限为 1000。如果遇到此限制，请联系 Palantir 管理员。
