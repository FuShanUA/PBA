卡片

在 Quiver 中，探索和分析通过卡片来执行，卡片可以串联在一起以执行复杂的操作。有些卡片用于创建图表或执行计算，另一些卡片则用于通过筛选、连接、派生新列等方式来处理数据。

Quiver 中的每个卡片接受零个或多个输入，并产生特定类型的输出，例如 object set, time series, categorical chart, number等。这些类型共同构成了 Quiver 的 数据模型，并定义了卡片如何串联在一起。

可以通过选择卡片右上角的 图标，在编辑器面板中配置卡片。

画布和图表

Quiver 提供两种视图模式来构建您的分析： 画布 模式和 图表 模式。

A 画布 是一个页面，您可以在其中显示、重新排列和调整分析中卡片的大小。一个分析可以包含多个画布。

与 Contour 路径不同，Quiver 画布仅用于显示和组织。在画布上重新排列卡片不会影响底层数据转换的顺序。

In 图形模式中，卡片表示为节点，它们之间的连接表示为链接，采用从左到右的布局，便于跟踪数据流。您可以使用 颜色组日 隐藏或筛选节点 来组织图表，以专注于分析的特定区域。

在图表模式下添加的卡片不会自动放置到画布上。您可以随时在画布上添加或移除卡片。

图表模式最适合表格分析，而画布模式最适合时间序列分析。无论数据类型如何，画布模式更适合展示最终输出（如图表和表格），而图表模式更适合检查卡片依赖关系。

对象

在 Quiver 中，来自 本体论 的对象被用作表格分析的主要数据输入。Quiver 原生支持许多不同的卡片，用于筛选、转换和可视化对象数据。

对于对象数据的高级转换，例如派生属性和关联对象之间的连接，用户还可以利用 Quiver 的 转换表, 数据集日 函数 卡片套件。

了解更多关于对象分析的信息。

时间序列

Quiver 支持 时间序列 分析。时间序列主要通过 时间序列属性添加到 Quiver 中；不过，您也可以直接查看 时间序列同步 。 函数支持的时间序列 使用 Python 函数动态生成时间序列，用于实时预测和自定义分析。

Quiver 提供了丰富的 转换 和 可视化 库，用于时间序列数据。Quiver 还支持高级时间序列工作流，例如 异常检测 和 事件分析.

此外，时间序列转换可以保存为 派生序列，或用于通过 时间序列自动化.

参数

Quiver 参数允许您轻松切换数据和结果的不同视图。创建参数后，您可以在卡片中使用它们，并在仪表板中公开这些参数。这样，仪表板的最终用户就可以与所呈现的数据和结果进行实时交互。

保存和版本控制

Quiver 分析通过点击应用程序右上角的保存按钮手动保存。同时还提供版本历史记录，允许您查看或将分析恢复到之前保存的版本。此外，在每次保存操作之间，Quiver 会自动保存您的“工作”状态（将其存储在 state URL 变量中，例如 state=j05na7mun3）。这使您可以刷新页面并恢复到确切的分析状态，即使您尚未保存。如果您分享带有 state 变量设置的 URL 链接，该链接将打开该工作状态，而不是最新的分析版本。

如果多个用户同时处理同一个分析，他们可以独立工作而互不干扰，但保存更改时会覆盖彼此保存的更改。
