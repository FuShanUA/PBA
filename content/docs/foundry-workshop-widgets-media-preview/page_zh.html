《媒体预览》：

媒体预览小组件可用于在给定受支持的媒体源的情况下显示图像、音频、视频和文档媒体。目前支持的媒体源包括媒体 URL、附件属性和媒体引用属性。

配置选项

  • 媒体字符串
    • 媒体字符串选项支持以以下三种格式引用的图像来渲染媒体预览：
      • Blobster RID，例如， ri.blobster.main.image.ab1c23d4-56ef-789g-h012-3456ij78k90l.
      • 媒体 URL
        • 如果引用来自媒体集的媒体 URL，该 URL 应采用以下格式： https://{my-foundry-url}/mio/api/media-set/{media set rid}/items/{media item rid}.
        • 如果引用来自数据集的媒体 URL，该 URL 应采用以下格式： https://{my-foundry-url}/foundry-data-proxy/api/web/dataproxy/datasets/{dataset rid}/transactions/{transaction rid}/{filename} or https://{my-foundry-url}/foundry-data-proxy/api/web/dataproxy/datasets/{dataset rid}/views/{branch name}/{filename}.
        • 如果引用外部媒体 URL，请确保已在您的注册环境中配置访问权限 内容安全策略 settings.
      • 带有 Base64 编码媒体的数据 URL，例如， data:image/png;base64,{base64-encoded image}.
  • 附件属性
    • 定义一个包含单个对象的对象集，并选择附件类型的属性，以渲染该对象的媒体预览。
  • 媒体引用属性
    • 定义一个包含单个对象的对象集，并选择 媒体引用 类型的属性，以渲染该对象的媒体预览。

局限性

  • 媒体预览小组件不支持查看嵌入在 PDF 文件中的附件。要访问 PDF 中嵌入的文件，请下载该 PDF 并在本地 PDF 查看器应用程序中打开。

专用媒体预览小组件

媒体预览小组件可显示所有类型的媒体，而下面列出的专用媒体预览小组件只能显示特定类型的媒体，但为其特定媒体类型提供了额外的功能。

  • PDF 查看器小组件
    • 支持显示注释，并提供其他额外的配置选项。
  • 视频显示小组件
    • 支持额外的视频特定配置，例如跳转到特定帧，以及通过拖动/定位移动到特定时间戳。
  • 音频和转录显示小部件
    • 支持额外的音频特定配置，例如通过拖动/定位移动到特定时间戳，以及转录显示和交互。
