使用本体论管理器添加时间序列属性并配置地理空间功能

本指南参考了有关 在时间序列对象类型上设置时间序列属性的文档。虽然您可以根据需要向对象类型添加任意数量的时间序列属性，但本教程将指导您向您的对象类型添加两个时间序列属性，这两个属性分别基于 latitude 和 longitude 列，这两列来自 Ship 对象类型的 支撑数据集（在管道构建器中创建）。

在本指南结束时，您的 Ship 对象类型将拥有两个时间序列属性（Latitude Series 和 Longitude Series）以及配置用于在 Foundry 地图上可视化船舶移动的地理空间轨迹功能。

第一部分：在本体论管理器中创建一个 Ship 对象类型

请按照以下说明，在您的本体论中创建一个新的 Ship 对象类型，并将您 转换后的数据 作为支撑数据集：

  1. 导航至 本体论管理器 ，并从屏幕右上角选择 新建 > 对象类型 。
  2. 选择 使用现有数据源 （位于 创建新对象类型 弹出窗口中），然后选择您转换后的数据集。

  1. 选择 下一步 ，并将 Ship 设置为对象类型的 名称 ，然后可选择输入 描述。提供名称和描述后，选择 下一步。
  2. 设置 Ship Id 属性作为 “主键” 和 “标题” ，用于该对象类型。
  3. 选择您要生成的 操作类型 ，并可选择限制哪些用户可以提交这些操作。
  4. 请先选择一个项目来保存该对象类型并在其中生成操作类型，然后再选择 “创建”。

在您选择 “创建”后，Foundry 会关闭 “创建新对象类型” 窗口，并将您引导至 Ontology Manager 中该对象类型的概览页面，您可以在其中配置其时间序列属性。

第二部分：为该 Ship 对象类型配置时间序列属性

  1. 选择 “功能” 选项卡（位于屏幕左侧 “可观测性”下方）。
  2. 选择 “时间序列” 面板，然后选择 “开始使用” 以启动 “时间序列属性设置” 弹出窗口。
  3. 请从 Longitude Series Id 该 “对象类型属性” 下拉菜单中选择，然后选择 “下一步”。
  4. 选择 “选择文件...” 以找到 您在 Pipeline Builder 中创建的时间序列同步 ，然后选择 “下一步”。

  1. 选择 “标准时间序列属性” （位于弹出窗口的 “本体论设置” 部分），然后选择 “添加属性”。

在您选择 “添加属性”后，Foundry 会关闭 “时间序列属性设置” 弹出窗口，并引导您返回 “时间序列” 部分（位于 “功能” 面板中）。接下来，选择 添加 属性，并重复上述第 2–5 步以配置 Latitude Series Id 属性。

完成 Latitude Series Id 属性的设置后， 保存 您对本体论的更改。

第三部分：确保每个时间序列属性都表示地理空间特征

在 功能 标签页中，向下滚动并选择 地理空间 面板。接下来，将您的 Latitude Series Id 和 Longitude Series Id 属性分别设置为 轨迹纬度 和 轨迹经度 属性，然后再保存您对本体论的更改。

现在，时间序列属性和地理空间功能均已配置完成，接下来您将 在地图上可视化船舶轨迹。
