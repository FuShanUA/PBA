第三方应用程序所有权

自动化可以由第三方应用程序而非个人用户拥有。这会将执行历史和权限与组织服务账户绑定，从而实现集中管理，并确保无论团队发生何种变动都能保持连续性。

您可以在创建自动化时将所有权分配给第三方应用程序，也可以 转移现有自动化的所有权。

了解第三方应用程序所有权

Foundry 中的第三方应用程序是基于 OAuth2 的集成，可让外部应用程序或服务安全地与 Foundry 资源进行交互。请参阅 第三方应用程序概览 以了解更多信息。对于自动化所有权，第三方应用程序提供了一个可独立于个人用户拥有自动化的服务用户，具有以下几项优势：

  • 团队连续性：当团队成员离职或不在办公室时，自动化仍会继续运行。
  • 集中式权限：独立于各个团队成员管理自动化权限。
  • 持久的历史记录：执行历史仍可访问，以供调试和审计，适用于 项目范围的自动化。
  • 简化的访问控制：使用 项目范围的自动化在团队之间共享执行历史，并通过在多个自动化中使用同一个第三方应用程序客户端来集中管理权限。

由第三方应用程序拥有的自动化的权限

当自动化由第三方应用程序拥有时，以下各项适用：

  • 条件评估 使用服务用户的权限。
  • 操作和逻辑效果 以服务用户身份执行。
  • 通知效果 继续使用每个收件人各自的权限。
  • 执行历史记录 对团队成员的可见性取决于其权限。 请参阅历史记录可见性设置 以了解更多信息。

这可确保自动化行为保持一致且可预测，权限明确定义并绑定到服务账户而非个人用户。

设置第三方应用程序

在转移自动化所有权之前，请通过在 Control Panel 或 Developer Console 中注册应用程序来创建并配置 OAuth2 客户端。请参阅 注册第三方应用程序 以获取完整指导。

前提条件

要创建用于自动化所有权的第三方应用程序，您必须具备以下条件：

  • 您所在组织中的第三方应用程序管理员角色
  • 该 Manage OAuth 2.0 clients 权限

创建新的第三方应用程序并获取凭据

要注册新的第三方应用程序，请在注册应用程序时选择以下设置：

  • 客户端类型： 机密客户端
  • 客户端凭据授权： 已启用

此操作会创建一个可以拥有自动化的服务用户。在注册过程中，请立即保存客户端 ID 和客户端密钥。该密钥仅显示一次。

应用程序限制不属于注册的一部分。应用程序创建后，请将其设置为 不受限制 ，具体操作请参阅 配置应用程序限制。

请妥善保管客户端密钥。如果丢失，您将需要 轮换该密钥。请注意，轮换密钥 不会 破坏该第三方应用程序所拥有的现有自动化。

如需有关注册应用程序和获取凭据的完整分步说明，请参阅 注册第三方应用程序 以及 开发者控制台概述。

管理所有权

注册第三方应用程序并配置其权限后，您可以创建由第三方应用程序拥有的新自动化，或将现有自动化的所有权转移给该应用程序的服务用户。

在尝试分配第三方应用程序所有权之前，请确保您具备以下条件：

  • 第三方应用程序的客户端 ID。
  • 该应用程序的客户端密钥。
  • 确认服务用户已被授予现有自动化或将在其中创建新自动化的文件夹的编辑者角色。
  • 确认服务用户具有执行自动化操作的相应权限，并且该应用程序未受限制。您可以在创建应用程序后，在 OAuth 和限制 页面上设置限制。

如果您没有客户端 ID 和客户端密钥，请参阅 创建新的第三方应用程序并获取凭据。

对由第三方应用拥有的自动化进行后续编辑时，需要在保存前提供凭据（客户端 ID 和客户端密钥）。

创建新自动化时添加第三方应用所有权

创建新自动化时，请按照以下步骤将所有权分配给服务账户：

  1. 配置您的自动化并选择 创建自动化。
  2. 在 另存为... 对话框中，滚动至底部的 提供客户端凭据 部分。
  3. 选择 第三方应用。
  4. 输入您的客户端 ID 和客户端密钥。
  5. 选择 保存。

您可以在 自动化详情 部分（位于 自动化概览 页面）确认自动化的所有权。

将所有权转移给服务用户

请按照以下步骤为现有自动化转移所有权：

  1. 在 Automate 中，选择该自动化以打开 自动化概览 页面。
  2. 在 操作 下拉菜单中，选择 管理所有权。

  1. 输入您的客户端 ID 和客户端密钥，然后选择 确认并保存。

转移所有权后，第三方应用将在 自动化详情 部分中显示为自动化的所有者。该自动化将继续使用服务用户的权限不间断运行。先前的执行历史记录将保持完整，授权用户仍可访问。

从服务用户转移所有权

按照以下步骤将所有权从第三方应用程序转移回个人用户：

  1. 在 Automate 中，选择自动化以打开 自动化概览 页面。
  2. 在 操作 下拉菜单中，选择 管理所有权。
  3. 在 管理自动化所有权 对话框中，选择 确认并保存 以将所有权转移回您自己。

请确保您的用户账户拥有先前授予服务用户的所有权限。否则，自动化可能无法执行某些操作。
