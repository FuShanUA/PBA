展示可视化

在 Code Workbook 中创建可视化后，您可能希望在 Code Workbook 的上下文之外将其展示给协作者。

将可视化添加到 Notepad

在 Code Workbook 中生成的可视化可以在 Notepad 文档中展示。您可以将来自 Foundry 各处的各种资源嵌入到 Notepad 文档中，包括 Contour 看板、Quiver 画布和 Code Workbook 可视化，还可以使用文本、表格和图像为文档添加注释。您还可以创建 Notepad 模板，允许 Workshop 应用程序中的用户根据给定的蓝图生成新的 Notepad 文档。 了解有关 Notepad 的更多信息。

您可以通过右键单击图表上的节点并单击以下按钮，将 Code Workbook 可视化添加到 Notepad 文档中： 可嵌入的 Foundry 应用程序。现在，该图像已复制到您的剪贴板，可以粘贴到任何 Notepad 文档中。

将可视化添加到 Reports

Foundry Reports 可用性

自 2022 年 10 月 3 日起，Foundry Reports 默认不再对新客户开放。如果您的用例需要访问 Foundry Reports，请联系您的 Palantir 代表。对于现有用户，仍支持使用 Foundry Reports 创建包含 Code Workbook 中生成的可视化的仪表板。

在 Code Workbook 中生成的可视化可以添加到 Foundry Report 中进行展示和协作。您可以通过打开“可视化”选项卡并单击以下按钮，将可视化添加到 Report 中： 添加到 Report，或者通过右键单击图表上的节点并单击以下按钮： 添加到 Report.
