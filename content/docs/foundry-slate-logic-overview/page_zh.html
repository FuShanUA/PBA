逻辑

应用程序通常需要在数据呈现给用户或以其他方式可视化之前对其进行修改或丰富。同样，应用程序可能需要额外的信息才能按您的预期运行。例如，您可能希望指定某个 widget 必须具有适当的配置才能成功运行，或者某些信息根据应用程序的状态显示。Slate 提供了多种基元来管理和操作状态与数据。

函数 是可以读取 Handlebars 并返回任何类型输出的 JavaScript 代码片段。函数可以处理来自查询的数据，接收 widget 或变量的状态并构造新值，或者为 widget 准备类。了解更多关于 Slate 中的函数.

Handlebars 在组件之间传递值，在事件中使用函数的输出或查询的结果。Handlebars 让您通过两个花括号访问当前流经应用程序的所有信息 {{ }}。了解更多关于 在 Slate 中使用 Handlebars.

变量 存储应用程序状态、用户输入或默认值。通过 URL 参数或事件设置变量值。 变量 面板提供了一个类似电子表格的界面，您可以在其中调整列宽、编辑单元格、使用上下文菜单，以及上传 CSV 文件来初始化或更新表格值。了解更多关于 Slate 中的变量.

事件 由单个事件和用户操作组成。事件触发应用程序中的活动；例如，您可以配置一个事件，在选中按钮时提交查询，或在对话框关闭后显示提示信息。事件和操作处理 Slate 内部的各种自动化交互。了解更多关于 Slate 中的事件和操作.
