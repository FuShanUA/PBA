transforms.api.Input

class transforms.api.Input(alias=None, branch=None, description=None, stop_propagating=None, stop_requiring=None, checks=None, failure_strategy=None, transaction_limit=None)

转换数据集输入的规范。

该类是 transforms.api.FoundryInputParam的具体子类。请参阅该页面了解基本参数语义，包括 instance()、 json_value、 schema和 input_results。

若要指定多个输入，请使用 transforms.api.InputSet。

  • 参数：
    • alias (str ↗ , 可选) – 数据集资源标识符（RID）或数据集的 Compass 绝对路径。如果未指定，该参数将处于未绑定状态。
    • branch (str ↗ , 可选) – 用于解析输入数据集的分支名称。如果未指定，则在构建时解析。
    • description (str ↗ , 可选) – 输入的描述。
    • stop_propagating (Markings , 可选) – 要停止从此输入传播的安全标记。
    • stop_requiring (OrgMarkings , 可选) – 输出上不再需要的组织标记。请使用 OrgMarkings 来指定适用的标记 ID 和可选分支。
    • checks (List [Check ] , Check) – 一个或多个 Check 对象。
    • failure_strategy (str ↗ , 可选) – 输入更新失败时使用的策略。必须为 continue 或 fail。如果未指定，则默认为 fail。
    • transaction_limit (int ↗ , 可选) – 从增量输入中读取的最大事务数。

input_results(instance, **kwargs)

生成一个映射，将输入 RID 映射到 TransformsInputResult。结果将被合并到 TransformJobResult。

  • 参数： instance – 一个对象，其类型由以下内容生成： instance()。

历史记录

  • 在 1.53.0 版本中的更改：现在继承自 FoundryInputParam。

static instance(context, json_value)

使用来自 JobSpec 参数的原始 JSON 值和特定上下文创建参数实例。

返回值将被注入到转换计算函数中。

  • 参数：
    • context (ParamContext) – 一个上下文对象，包含创建实例时可能需要的属性。
    • json_value (any) – 从 JobSpec 参数中反序列化得到的任意原始值。

property json_value

返回此参数要放入 JobSpec 的 JSON 值。

如果返回值为 None，则该参数被视为未绑定。如果任何转换的参数未绑定，则该转换将被视为未绑定。对于未绑定的转换，JobSpec 不会被发布。

static lightweight_instance(_context, json_value)

从解析后的 JSON 值实例化一个输入类型。

property schema

返回此类型参数的 JSON schema。必须返回有效的 JSON schema。
