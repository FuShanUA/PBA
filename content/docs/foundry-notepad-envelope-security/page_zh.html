信封安全 [Beta]

Beta

Notepad 中的信封安全功能处于 beta 开发阶段，且仅在使用 基于分级的访问控制 (CBAC) 的部署上可用。受支持的微件和文档功能集将在未来版本中不断扩展。如果您在已启用 CBAC 的部署上无法使用信封安全功能，请联系 Palantir 支持团队以请求访问权限。

信封安全 将 Foundry 可在 Notepad 文档中加载的数据限制在由文档自身的 CBAC 分类和 标记所定义的安全边界内。当您在文档上启用信封安全时，文档的 文件标记 将限制可在该文件中添加和查看的数据，而不是使用每个用户各自的标记成员身份来确定他们可以查看的内容。启用信封安全的 Notepad 文档可以安全导出，并附带准确反映其内容分类的横幅。

何时使用信封安全

在以下情况下，应对文档应用信封安全：文档内容安全性的强制执行和传达必须独立于 作用域会话 用户所在的工作环境。此外，当您需要执行以下操作时，可以在 Notepad 中使用信封安全功能：

  • 撰写一份文档，其内容必须保持在特定分类级别或以下，无论编辑该文档的用户的访问级别如何。
  • 导出带有横幅的文档，该横幅反映的是文档自身的分类，而非用户的会话最高横幅。
  • 共享一份内容对所有授权查看者均相同的文档。

如果您不需要这些保证，请使用常规的 Notepad 文档，该文档支持全套 小部件 ，同时会根据每个查看者的标记成员身份为其筛选动态加载的内容。

创建信封安全文档

请按照以下说明操作，通过标准 Notepad 创建对话框来创建具有信封安全的文档。

  1. 选择 + 新建 > Notepad 文档 ，以从 项目创建新的 Notepad 文档。
  2. 开启 强制安全 以启用信封安全。文档的分类和标记将与 项目分类 以及所在项目的项目标记保持一致。
  3. 选择 完成 以创建文档。

创建文档后，您将无法启用或禁用信封安全。要在信封安全文档与普通 Notepad 文档之间进行转换，请新建所需类型的文档。此外，您无法为信封安全文档分配与其所属项目不同的分类。信封安全 Notepad 文档在创建时的分类必须与其所属项目的分类相匹配。

与普通文档一样，在 Notepad 中创建信封安全文档后，您将能够查看其 大纲、 版本历史和 页面设置。

横幅显示

受信封保护的文档会显示根据文档文件标记生成的横幅。

  • 在记事本中查看文档时： 记事本会在文档顶部渲染一个横幅，只要文档处于打开状态，该横幅便始终可见。
  • 将文档导出为 PDF 或 Word 后： 导出的文档使用文件标记横幅。对于受信封保护的文档，自定义导出横幅选择器将被禁用。
  • 在 Workshop 中查看嵌入的文档时： Workshop 除了渲染 Workshop 会话横幅外，还会在嵌入文档周围渲染文件标记横幅。

支持的小部件

目前，受 Envelope 保护的文档仅支持一组有限的小部件，这些小部件不会动态加载数据：

  • 锚点链接
  • 水平分割线
  • LaTeX
  • 分页符
  • 表格
  • 用户提及

Notepad 会筛选 + Widget 菜单，在受信封保护的文档中仅显示上述列出的受支持的 widget，包括用于 页眉和页脚的菜单。

不支持的功能

以下 Notepad 功能在受信封保护的文档中不可用：

  • 模板： 无法从 模板创建信封安全文档，也无法将信封安全文档另存为模板。
  • Marketplace 打包： 无法将信封安全文档打包为 Marketplace 产品。
  • 锁定和解锁小组件数据： 由于不支持任何加载数据的小部件， 锁定和解解锁小部件数据 的功能不会公开。
  • 引用数据面板： 左侧边栏中的引用数据面板处于隐藏状态，因为文档中没有任何小部件会加载引用的资源。
  • “使用 AIP 编辑”和“使用函数编辑”： 基于 AIP 的编辑已被禁用，因为无法将已标记的内容传递给任意函数。
  • 应用配对： 应用配对 不受支持，因为它与不受支持的 命令小部件结合使用。
  • 添加到 AIP Assist： 不支持将受信封保护的文档添加到 AIP Assist。
  • 添加自动化： 您无法配置 自动化集成 于受信封保护的文档。

编辑受信封保护的文档

按照与编辑普通 Notepad 文档相同的工作流编辑受信封保护的文档，但存在以下差异：

  • 粘贴包含不受支持小组件的内容（例如从普通 Notepad 文档复制的内容）时，这些小组件将从粘贴的内容中移除。
  • Notepad 会拒绝将不受支持的小组件插入文档的更新。如果粘贴或其他编辑操作未通过验证，则不会应用该更改，页面将自动刷新。

创建副本并移动受信封保护的文档

为受信封保护的 Notepad 文档创建副本时，无论目标 Project 的分类如何，副本都会保留与原始文档相同的分类和标记。

将受信封保护的文档移入另一个项目时，文档的密级和标记保持不变。文档的密级必须处于目标项目允许的密级范围内，介于其 项目密级 与 项目最高密级之间，以确保文档仍可访问。
