选择导入数据集的分支

Code Workbook 实现了分支 回退机制 ，用于导入的数据集，这意味着将使用 Workbook 中的分支层级结构来确定导入数据集的拉取来源。

例如，假设您的 Workbook 包含两个分支 master 和 develop，而您的输入数据集 titanic 也同时具有这两个分支。当您位于 develop 分支时，导入的数据集将默认从 develop拉取。如果另一个数据集仅存在于 master 而不存在于 develop，则输入数据将从 master.

这种回退结构可实现实用的工作流程。例如，如果您从另一个 Workbook 或代码仓库导入了数据集，并希望使用该 Workbook 或仓库的分支版本来测试您的转换，只需在您的 Workbook 中创建一个同名分支，导入的数据集就会自动回退到相应的分支。
