本体论编辑

除了编写从本体论读取数据的函数外，您还可以编写创建对象并编辑对象属性和关联的函数。 本页面记录了函数中可用的对象编辑 API。 有关编辑函数工作原理的更多详细信息，请参阅 概述页面。

Python 还支持 分阶段写入，它提供写后读保证，并允许嵌套调用其他分阶段写入函数。当函数必须查询其刚编辑的数据时，请使用分阶段写入。

为了使函数中创建的编辑实际生效，本体论编辑函数 必须配置为 函数支撑的操作。 以这种方式配置操作可以让您提供额外的元数据、配置权限，并在各种操作界面中访问该操作。 正如 文档中所指出的，在操作之外运行编辑函数实际上不会修改任何对象数据。

警告

在编辑对象后立即搜索它们可能会返回意外结果。请参阅 注意事项部分 了解详情。

定义编辑函数

编辑本体论的函数必须：

  • 使用 @function(edits=[MyObjectType]) 装饰器（从 functions.api 导入）来指定要编辑的对象类型。
  • 具有显式的 list[OntologyEdit] 返回类型提示，该提示导入自 functions.api。

构造本体论编辑容器

要在 Python 函数中执行本体论编辑，请先从 OSDK 客户端构造一个本体论编辑容器。例如：

Copied!
1
ontology_edits = FoundryClient().ontology.edits()

此容器用于跟踪函数中所做的所有编辑。

更新属性

Python 函数中的本体论对象默认为只读。尝试修改其属性将抛出异常。

要编辑对象，请先使用本体论编辑容器获取该对象的可编辑视图，既可以从现有对象实例获取：

Copied!
1
editable_object = ontology_edits.objects.MyObjectType.edit(my_object)

也可以通过给定的对象主键获取：

Copied!
1
editable_object = ontology_edits.objects.MyObjectType.edit(object_primary_key)

获得可编辑对象后，即可通过为对象重新分配属性值来编辑属性值。例如：

Copied!
1
editable_employee.last_name = new_name

在同一次函数执行的后续部分访问 last_name 属性值（所属对象为 editable_employee ）时，将得到刚刚设置的新值。但是，原始的不可编辑对象将 不会 反映这些更改。

数组属性 在可编辑对象上为只读。要修改数组，请创建该数组的副本，修改副本，然后更新属性：

Copied!

# Copy to a new array
array_copy = list(editable_object.my_array_property)
# Now you can modify the copied array
array_copy.append(new_item)
# Then overwrite the property value
editable_object.my_array_property = array_copy

请注意，现有对象的主键属性值无法更新。

编辑结构体属性

Beta

结构体属性是 Python 函数中的一项测试版功能。您可以使用 beta 参数（在 @function 装饰器上）启用结构体属性，并从特定于对象的本体论 SDK 模块中导入生成的结构体属性类。

创建对象时，请先调用 create()，然后将结构体属性分配给返回的可编辑对象。结构体属性无法直接传递给 create() 作为关键字参数。

from functions.api import function, OntologyEdit
from ontology_sdk import FoundryClient
from ontology_sdk.ontology.objects import MyObjectType
from ontology_sdk.ontology.objects.my_object_type import MyStructPropertyClass

@function(beta=True, edits=[MyObjectType])
def create_object(primary_key: str) -> list[OntologyEdit]:
    ontology_edits = FoundryClient().ontology.edits()

    new_object = ontology_edits.objects.MyObjectType.create(primary_key)
    new_object.my_struct_property = MyStructPropertyClass(
        first_field="Example value",
        second_field=True,
    )

    return ontology_edits.get_edits()

生成的结构体属性类会将其 Python 字段名称转换为相应的本体论 API 名称。用户定义的类或 dataclass 无法用来替代它。

要更新现有结构体属性中的某个字段，请在更改该字段后将完整的结构体属性重新分配给可编辑对象：

Copied!

editable_object = ontology_edits.objects.MyObjectType.edit(my_object)

struct_property = editable_object.my_struct_property
struct_property.first_field = "Updated value"
editable_object.my_struct_property = struct_property

直接更改字段（例如 editable_object.my_struct_property.first_field = "Updated value"）不会注册本体论编辑。

创建对象

您可以在本体论编辑容器上使用 MyObjectType.create() 方法创建新对象。创建新对象时，您必须为其主键指定一个值。

在此示例中，我们使用给定的 ID 创建一个新的 Ticket 对象，并设置其 due_date 属性，并通过修改 assigned_tickets 关联，将其分配给给定的 Employee。

from datetime import datetime, timedelta

from functions.api import function, Integer, Array, OntologyEdit
from ontology_sdk import FoundryClient
from ontology_sdk.ontology.objects import Employee, Ticket

@function(edits=[Employee, Ticket])
def create_new_ticket_and_assign_to_employee(
    employee: Employee,
    ticket_id: Integer
) -> list[OntologyEdit]:
    ontology_edits = FoundryClient().ontology.edits()

    new_ticket = ontology_edits.objects.Ticket.create(ticket_id)
    new_ticket.due_date = datetime.now() + timedelta(days=7)

    editable_employee = ontology_edits.objects.Employee.edit(employee)
    editable_employee.assigned_tickets.add(new_ticket)

    return ontology_edits.get_edits()

除了主键之外，非结构体属性值也可以直接传递给 create 方法。例如：

Copied!
1
2
new_due_date = datetime.now() + timedelta(days=7)
new_ticket = ontology_edits.objects.Ticket.create(ticket_id, due_date=new_due_date)

删除对象

你可以通过调用本体论编辑容器上的 MyObjectType.delete() 方法来删除对象。

在此示例中，我们删除分配给给定员工的所有工单：

Copied!
1
2
for ticket in employee.tickets:
    ontology_edits.objects.Ticket.delete(ticket)

也可以使用主键而非实例来删除对象：

Copied!
1
ontology_edits.objects.Ticket.delete(ticket_id)
