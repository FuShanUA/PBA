对象视图版本控制

保存到对象视图的编辑内容将存储为新版本。一个版本可以包含多项更改，例如添加、编辑和删除标签页。版本控制使您能够：

  • 通过增量保存更改，安全地迭代对象视图
  • 控制发布哪个版本并使其对用户可见
  • 在较新版本包含错误时重新发布较旧版本
  • 通过为版本添加描述与其他编辑者协作

对象视图中包含的每个 Workshop 模块都有各自独立的 版本 两个版本号均显示在 对象视图编辑器页眉.

保存新版本

编辑对象视图后，您可以通过选择 保存 对象视图编辑器页眉中的按钮来保存更改。如果 自动发布新版本 已启用，该按钮将显示为 保存并发布 ，并将同时发布标签页更改以及当前 Workshop 模块的所有更改。默认情况下会启用自动发布。

禁用 自动发布新版本 后将显示两个独立的按钮，分别用于保存和发布。 保存 按钮将同时保存标签页和 Workshop 模块的更改，而 发布 按钮将把这两项更改发布给用户。

在编辑 Workshop 模块时，它会像任何其他 Workshop 模块一样定期自动保存，但在对象视图发布之前，这些更改不会对用户可见。

最佳实践

如果您的对象视图被大量用户积极使用，或者有多个编辑者在协作编辑该视图，我们建议禁用自动发布。这可以改善协作并降低中断用户工作流程的风险。

访问以前的版本

要查看对象视图的以前版本列表，请在对象视图编辑器页眉中选择蓝色的对象视图版本号。这将打开一个对话框，显示所有以前版本的日期、作者和描述。通过此对话框可以预览所有版本。

  • 当前发布的版本将带有绿色对勾标记。
  • 以前发布过的版本将显示灰色对勾。
  • 从未发布过的版本将没有对勾。
