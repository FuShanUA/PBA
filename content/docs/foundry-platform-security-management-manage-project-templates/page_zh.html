管理项目模板

项目模板可以标准化 空间内项目的创建和配置。

诸如《通用数据保护条例》（GDPR）之类的治理框架可通过配置平台安全基元来获得支持，例如 角色、 组、 标记和 项目约束等。​这些配置可以通过项目模板进行编码，并对所有新项目强制实施。​这使组织能够为所创建的项目设置治理护栏。

目前，项目模板支持配置角色、群组、标记和项目约束。文件夹结构和其他功能最终也将获得支持。这些功能将逐步开发。

管理

空间所有者可以创建、编辑和删除项目模板。可在各空间级别管理项目模板，方法是导航至 控制面板 > 项目模板 并选择所需的 空间 在页面顶部的下拉菜单中。

选择 创建模板 在右上角的 项目模板 页面来创建新模板。这将打开项目模板创建向导，您可以在其中定义模板的名称、描述、变量、角色、标记等信息。

变量

模板创建支持使用变量对组和标记的名称等内容进行参数化。变量是在模板部署（即创建项目时），在模板创建向导的 变量 部分中定义的。

这一点尤其有用，因为项目模板支持配置新的组和标记，它们会在模板部署和项目创建时自动创建。例如，一个名为 project name 的变量可用于创建遵循以下惯例的组： project name + role.

角色

设置 默认角色 会为满足组织和标记要求的用户在所创建的项目上授予角色。此外，还可以将现有用户和组配置为在基于此模板创建的所有项目中拥有指定角色。如果 项目创建者 被指定了角色，则创建该项目的用户将获得指定的角色。

通常的做法是设置查看者组、编辑者组和所有者组，其中所有者组对查看者组和编辑者组拥有管理权限。这可以在项目模板中完成。创建所需的组，然后向所有者组授予对其他组的权限。

标记

在创建项目时，可以应用新的或现有的标记。在项目中获得角色授权的所有用户或群组将自动获得所有新标记的成员资格。

项目约束 可以作为模板的一部分进行指定。如果 允许的标记 被选中，则任何新标记都将自动被允许。新标记不能在 禁止的标记中指定。

项目部署

所有创建的项目均使用模板。默认的项目模板会创建一个空项目，并将项目创建者设为其所有者。如果某个空间配置了多个项目模板，则用户在创建项目时可以选择使用哪一个。

在某个空间中拥有 editor 权限的用户可以在该空间中创建项目。根据项目模板的定义，项目创建者可能需要相应的额外权限。例如，如果模板会导致创建新的组或标记，或者应用现有的标记，则创建该项目的用户必须拥有相应的权限才能执行这些操作。
