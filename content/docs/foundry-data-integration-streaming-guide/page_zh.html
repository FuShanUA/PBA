流式资源指南

本页面列出了在实现端到端流式工作流时可能需要参考的资源。

Data Connection 支持将来自各种流式平台的数据同步到 Foundry 流式数据集中，随后可在 流式管道中使用。流式同步使数据能够以低延迟、高吞吐量的方式流入 Foundry，以支持实时决策流程。

有两种方法可以将流式数据同步到 Foundry：

  • Data Connection 支持从流式平台拉取记录到 Foundry。与批量同步一样，数据从流中读取并使用 代理架构.
  • 如果需要，Foundry 支持通过 流代理.

将记录从流直接推送到 Foundry 流中。Foundry 可以连接到多种流式数据源。提供专用连接器的数据源包括：

  • Apache Kafka
  • Amazon Kinesis
  • Amazon SQS
  • Aveva PI
  • Google Pub/Sub

对于没有专用连接器的流式数据源，您可以使用 外部转换连接到它们。这包括以下数据源：

  • ActiveMQ
  • Amazon SNS
  • IBM MQ
  • RabbitMQ
  • MQTT [Beta]
  • Solace
