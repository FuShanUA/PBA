核心概念

本页面介绍了 Foundry DevOps 和 Foundry Marketplace 的核心概念。我们建议您在继续之前先阅读本页面，因为 Foundry DevOps 和 Marketplace 使用了专门的术语（例如“产品").

乘积

在 Foundry DevOps 中，“产品”是产品构建者提供的可安装的 Foundry 资源集合。构建者可以在以下位置创建新产品： Foundry DevOps.

示例产品类型包括：

  • 本体论： Foundry 本体论的一个实例，可以是全面的行业标准 本体论 或一个本体论片段。
  • 用例： 一个用例可以简单到只是一个 Workshop 应用程序 也可以涉及多个 Workshop 应用程序的组合， 函数日 Carbon 工作区.
  • 管道： 管道的范围可以从单个数据转换一直到按顺序排列的多个转换和数据连接的组合。
  • 建模： 一个容器化的可执行文件 模型 封装任何功能逻辑，包括机器学习、预测、优化、物理模型和业务规则。

每个产品都有输出，或 内容，这些输出在产品安装时生成。产品可能要求安装者映射 输入 以便生成输出内容。

产品是用户可以 浏览 和 安装 的原子单位，通过 Marketplace 店面进行。

产品版本

产品构建者 创建 和 发布新版本 每次想要调整现有产品内容或添加新产品内容时，都会发布产品的新版本。安装时，我们通常建议选择 最新的产品版本。当有新的产品版本可用时，安装者可以 手动升级或选择自动接收新版本.

商店

商店是产品的集合；这些产品通常具有共同的用途。产品构建者可以 将新产品发布到商店。您的 Foundry 实例上显示的商店可以是本地的（例如，由您组织内在您的 Foundry 实例上工作的构建者创建）或远程的（例如， Foundry Store ，该商店对所有 Foundry 用户开放并由 Palantir 维护）。

安装

An 安装 是在安装者满足产品的所需输入（如果有）时创建的。每个产品可以安装多次。通常在以下情况下会创建多个安装：

  • 不同的用户群体需要同一产品。例如，您可以在多个支持团队中安装一个工单管理产品，并使用他们的工单数据作为输入。
  • 您需要为不同的开发环境创建安装。例如，您可以将一个工单管理产品安装到预生产 空间 and 本体论，然后再安装到生产空间和本体论中，每个环境都有各自的输入数据和特定于环境的设置，例如 发布渠道和升级窗口.
