对象类型组（Object type groups）

对象类型组是一种分类基元，可帮助用户更好地搜索和探索其本体论。组是使用 Ontology Manager 创建和管理的，通常由本体论 所有者和编辑者.

组配置

组通过组菜单创建和管理，该菜单可在 Ontology Manager 侧边栏中访问。

组也可以直接添加到对象类型，方法是选择 编辑组 在对象类型概览页面中。

组搜索和发现

组可在 本体论管理器的 搜索 栏和 搜索 栏对话框中搜索。本体论管理器中的对象类型表支持按组显示和筛选。组也会显示在 对象浏览器主页.

组权限

要查看对象类型组，用户必须对该对象类型组所在的项目拥有 查看者 权限。

旧版组迁移

自 2024 年 5 月 22 日起，本页面所述的 组 原语已取代旧版组基于标签的系统。

在大多数情况下，旧版组已于该日期自动迁移为对象类型组。如需手动操作，则会通过升级助手干预通知本体论所有者。

组名称可见性

以前，如果某个组内的所有对象类型对特定用户均不可发现（例如，由于对支撑数据集的访问控制），则该组对该用户也不可发现。如上文关于 组权限的部分所述，现在所有组对任何能够查看本体论的用户都是可发现的。此变更使组可见性与其他 本体论原语 以提高治理的清晰度和透明度。

部分可见组的迁移

无法被一个或多个用户发现的旧版组不符合自动迁移的条件。在这些情况下，系统通过 Upgrade Assistant 干预通知本体论所有者需要采取手动操作。

2024 年 5 月 22 日，无法安全迁移的旧版组已在 Workshop 和 Object Explorer 等所有应用程序中对操作用户隐藏。为了提供向后兼容性，旧版组的名称仍作为 类型类元数据 存储在对象类型上。

本体论所有者可以继续使用 Ontology Manager 手动迁移这些隐藏的旧版组。为此，请导航至 本体论配置 菜单（位于左下角），然后选择 批准所有组进行迁移.
