查看结果

结果视图以表格形式显示您探索过程中发现的对象。要在表格中加载更多对象，请向下滚动。

按列对表格排序

结果表可以按应用了 Sortable renderHint 的属性进行排序。要按特定列进行排序，请单击列标题中的下拉箭头。

一旦某列被用于排序，其标题中就会显示排序图标。如果选择了多个列进行排序，则最后选择的列优先。先前的排序会在其排序图标旁显示一个数字，以表示排序顺序，如下所示。

从下拉菜单中选择“清除所有排序”，可将排序重置为原始状态。

配置列

更改列顺序

可以通过拖动列标题上的手柄图标来重新排列列。

用户可以从列标题下拉菜单中选择“冻结 X 列”选项，以便在结果表中向右滚动时保持最左侧的 X 列可见。复选框列也计入此数量。

调整列宽

要调整列宽，请将列标题的右侧拖动到所需宽度。该边界以蓝色高亮显示，位于配置下拉菜单的右侧。

添加和删除列

要隐藏单个列，请从列标题下拉菜单中选择“隐藏此列”选项。

要同时重新排序和配置多个列，请选择“配置列”以打开以下菜单。

左侧面板显示表格的默认列，而右侧面板则显示所有可能列的当前顺序和可见性。使用快捷按钮隐藏或添加所有列，或使用顶部的搜索栏搜索特定列以切换其可见性。

通过将列拖动到所需位置来更改列的顺序，或使用下方菜单将列移至顶部或底部。

选择“在此表格中不截断文本”后，如果文本属性在现有列宽内无法完整显示，将自动换行显示。

使用右下角的按钮保存您的配置。管理员可以通过将当前视图另存为新布局并将其设置为所有用户的默认布局，来更新此表格的默认配置。 了解有关更新默认配置的更多信息。

预览结果

要在新的 Object Explorer 标签页中打开某个对象的对象视图，请单击该对象所在行中的 Title 列。要在 Results 标签页中打开对象视图的预览，请单击相应行中的复选框或任意其他列，以选择一个或多个对象。

选择对象后，Selection Preview 面板将从右侧打开。要关闭此面板以查看完整表格视图，请使用 "collapse" 图标(),该图标位于面板左上角。

如果选择了多个对象，则可以预览前二十个对象中任意一个对象的对象视图，这些对象视图以卡片列表的形式显示在对象视图上方。

若要同时比较两个对象的对象视图，请选择右上角的下拉菜单，然后选择“Compare objects”。

查看时间序列属性

时间序列属性可以在 Results View 中与常规属性一起查看。时间序列属性是一种对象属性，用于存储带时间戳的值的历史记录。 详细了解时间序列属性。

在下面的示例中，Results View 显示了 Country 对象，该对象包含三个时间序列属性： COVID19 New Tests、 COVID19 New Deaths和 COVID19 New Cases。每列左侧显示时间序列的最新观测值，右侧显示可视化该时间序列历史记录的迷你图。

内联编辑

配置了内联编辑操作的属性可以在 Object Explorer 结果页面中直接编辑。当用户满足内联编辑操作的提交条件后，鼠标悬停时值旁边会出现一个笔形图标。点击该值即可启用可编辑字段，具体取决于属性的类型。若要提交，需要再次满足提交条件，否则提交按钮将不可选择。
