发布平台内自定义文档

每个文档仓库都是从中发布的自定义文档的“事实来源”；每次构建仅发布文档仓库中当前存在的文件。此前从该文档仓库发布的任何内容都将从平台内自定义文档站点中移除。

示例： 假设您创建并发布了关于产品 A 的自定义文档。随后，您从文档仓库中删除了产品 A 的文件，并添加了产品 B 和产品 C 的新文档。在下一次合并和发布之后，平台内自定义文档将包含产品 B 和产品 C 的文档，但不再包含产品 A 的文档。

自定义文档发布工作流

当构建在 master 分支上运行时，将发布自定义文档。其他分支不会发布平台内自定义文档。您可以在提交的检查中查看发布过程的状态。

理想的工作流程是创建一个新分支，编写或编辑所需的文档内容，然后在 master 分支上发起拉取请求（PR）。将自定义文档 PR 合并到 master 会触发构建以发布文档。

请注意，将更改提交到 master 分支本身并不会将这些更改传播到平台内的自定义文档中；需要执行构建。

已发布的更改何时会显示在自定义文档中？

发布后，对之前已发布文件的更改将立即显示。新增文档页面、删除文档页面或修改整体内容结构的更改，将在自定义文档服务重新编译其文档状态后才会显示。默认情况下，此操作每小时进行一次，但管理员可以调整该时间间隔。

移除或删除自定义文档

仅删除文档代码仓库并 不会 移除或取消发布平台内自定义文档中的文档。若要移除或取消发布自定义文档页面，您必须先从文档仓库中删除不需要的文件，然后 重新发布 该仓库。这将取消发布不需要的文档内容。

只有在您从中移除所有内容 之后 才能删除已发布的文档代码仓库 docs 文件夹 并 重新发布了仓库。

在平台内自定义文档中，已删除的页面何时会消失？

删除后，各个自定义文档页面将立即消失。已删除文档的主页条目和目录将在文档服务于内部重新编译其文档状态后消失。默认情况下，此操作每小时执行一次，但管理员可以调整该时间间隔，以使更改更快显示。
