提交消息设置

默认情况下，点击提交按钮或构建数据集时会自动生成提交消息。您可以禁用此选项以鼓励编写更有意义的消息。提交消息对话框将在每次提交前打开，并要求提交一条消息。

数据集别名

在代码中可以通过数据集在 Foundry 中的确切位置（路径）或其唯一资源标识符（RID）来引用数据集。虽然两种方式均有效，但建议尽可能使用 RID，因为这样可以将资源从一个位置移动到另一个位置，而无需对仓库中的代码进行任何更新。

仓库编辑器的自动补全功能允许您在输入时搜索数据，无论您输入的是路径、RID 还是自由文本。当您从结果列表中选择一个数据集时，编辑器将根据设置插入其路径或 RID：

  • 尽可能自动转换为 RID - 此选项将插入 RID 数据集的（路径或 RID），并提供将转换中的任何路径转换为 RID 的选项。编辑器将在 RID 上方显示数据集名称，并允许根据需要进行编辑。
  • 不要自动将位置更改为 RID - 此选项将插入 路径 数据集的（路径或 RID），并允许在可能的情况下将 RID 转换为路径。

外部系统

信息安全官可以为仓库启用与外部系统的交互。这是一项高级功能，允许开发人员编写 外部转换，通过 agent-proxy与开放互联网或本地部署系统上的 Web 服务和 API 进行交互的 Python 代码。此功能只应在面向高度受信任开发人员的仓库上启用，因为与外部系统的交互无法保证遵循 Foundry 严格的数据溯源和访问控制实践。安全官可以通过配置允许导出的强制控制标记来限制允许与外部系统交互的数据范围。
