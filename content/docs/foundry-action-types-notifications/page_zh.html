通知

可以通过以下方式向操作添加通知： 添加新规则 这将打开一个对话框，您可以在其中为实体应用和编辑标签。 了解有关如何添加通知的更多信息。

配置通知需要指定 接收者 和 内容。以下各节将详细介绍这些选项。

接收者

配置通知的 接收者 选项允许您指定一组 Foundry 用户，这些用户将在操作运行时收到通知。通知将单独发送给每个接收者。不支持将用户添加为电子邮件通知的抄送（CC）接收者。

有多种受支持的指定接收者的方式：

  • 静态： 在配置中，您可以选择一组在操作运行时始终会收到通知的用户或组。

  • 从参数指定： 如果操作有一个 Foundry 用户或组 ID 类型的参数，您可以将其指定为通知的接收者。

    • 这可用于允许发送方在使用此操作的应用程序或模块的用户界面中选择一个或多个接收者，或者自动检测并向运行该操作的用户发送通知。

  • 从对象参数的属性指定： 如果操作有一个对象参数，且该对象的某个属性包含 Foundry 用户或组 ID，您可以将该参数的属性指定为接收者。这也适用于 Foundry 用户和组 ID 的列表。

  • 从函数指定： 如果上述选项无法满足您的用例，您可以编写一个自定义函数，该函数接收操作参数并返回应收到通知的用户或组列表。 了解有关如何编写返回用户或组列表的函数的更多信息。

    基于函数的接收者用例示例包括：

    • 组合其他接收者选项；例如，通知 assignee 从对象参数的属性指定的接收者，同时始终通知一组静态的额外接收者。
    • 基于其他参数或参数属性值的接收者选择；例如，每当 EMEA 出现新任务时，通知一组用户；每当北美出现新任务时，通知另一组用户。
    • 任何不符合结构化选项的其他自定义逻辑。

接收者可以更改通知的送达方式偏好。例如，某个用户可能选择仅在网页浏览器中接收通知，而另一个用户可能选择同时接收平台内提示和电子邮件。如果用户在个人偏好设置中关闭了操作通知，他们将不会收到通知。但是，他们登录 Foundry 后仍可在 Workspace 中依次点击 "Notifications" 和 "See All" 查看其通知。

内容

有多种自定义通知内容的选项。内容可以通过以下方式配置： 模板 或通过自定义 函数提供。选择模板内容将允许您直接在配置对话框中配置完整内容。函数内容将要求您拥有一个已发布的函数，该函数返回相应的通知类型。

内容组件

  1. 主题： 通常，内容会包含主题行。默认情况下，所有送达机制的主题行相同。

  2. 正文： 通知的正文。对于平台内通知，正文将显示在通知提示框内。对于电子邮件，正文将呈现在电子邮件的正文部分。

  3. 链接： 您可以指定一个链接。该链接将显示为通知正文内容下方的一个按钮。按钮的文本可以自定义。

    • 配置关联时可使用以下选项：
      • 关联到现有对象参数
      • 关联到 Workshop 应用
      • 关联到 Carbon 工作区
      • 关联到新创建的对象

  4. 高级电子邮件配置： 配置通知时，您可以指定自定义内容正文，用于通过电子邮件发送通知。此选项允许您使用 HTML 实现更高级的格式设置，平台内通知不支持这些格式。预览将显示通知的外观（不包括任何参数引用）。只有当接收者将其偏好设置为通过电子邮件接收通知时，才会收到此内容。

可以在上述的主题、正文和关联中使用三重大括号来引用参数和用户属性。编辑某个部分时，点击可用参数之一将自动为该参数或用户属性生成正确的大括号引用。

  1. 来自函数： 选择“来自函数”时，您无需配置上述各部分，而是必须提供一个返回 Notification 对象的函数，该对象带有指定自定义内容各部分的相应属性。如果符合以下任一情况，您可能需要使用函数：
    • 通知内容因接收者或操作的输入参数不同而完全不同。
    • 您希望电子邮件和平台内通知使用不同的主题行。
    • 您希望使用完整的链接 URL，包括指向 Foundry 之外的外部系统或应用程序的链接。
    • 您希望在渲染内容时执行 Search Around、聚合操作，或查询超出参数所提供范围的数据。
    • 您有任何其他无法通过模板内容选项实现的自定义需求。

有关 Notification 返回类型的更多信息，请参阅 函数文档.

用于生成通知内容的任何本体论数据将反映应用当前操作的编辑之前的本体论状态。为了让通知接收者能够访问特定对象的最新状态，可以在通知中嵌入通过对象参数引用的对象链接，或新创建对象的链接（如果这些对象是通过“创建对象”规则而非函数创建的）。

其他关键信息

最大接收者数量限制

  • 使用“来自函数”选项渲染通知内容时，接收者数量最多为 50 人。在内容配置选项下选择“来自函数”时，配置面板中会显示警告，并且每次运行操作时都会检查接收者数量。如果接收者数量超过限制，将显示红色错误提示，操作将无法运行。
  • 当使用“模板”选项直接在配置对话框中配置内容时，单个操作通知的接收者数量最多为 500 人。

内容长度限制

  • 主题的最大长度为 250 个字符。
  • 正文的最大长度为 1,000 个字符。为电子邮件渲染自定义 HTML 内容时，最大长度为 51,200 个字符。

请注意，这些最大内容长度在通知渲染时会被验证和截断。这意味着如果渲染的内容是动态的（例如，通知内容包含对象数据），任何超过允许最大长度的内容都将被截断，并以结尾省略号表示 ....

严格脱敏

如果您的 Foundry 实例启用了出站电子邮件通知的“严格脱敏”或“组脱敏”，将不会渲染自定义通知内容。相反，用户将收到如下所示的通用消息。选择“查看”将引导他们进入 Foundry，在其中可以查看完整的通知内容。 了解有关 Foundry 中电子邮件内容脱敏的更多信息。

收件人用户账户

  • 在发送通知之前，组将被解析为单个用户，以便检查数据权限。
  • Foundry 用户和组 ID 可以通过“设置”下的“账户”找到。通知的配置界面在选择一组静态收件人时提供了用户和组选择器。这只会显示配置该操作的用户具有足够权限的用户和组。
  • 如果收件人是通过引用对象属性配置的，请确保该属性以字符串形式存储 Foundry 用户或组 ID。您可以使用条件格式来显示关联的用户或组显示名称（更多详情，请参阅 ）。支持的选项包括全局值格式化（如在 Ontology Manager 中所配置的；参见).
  • 不支持直接发送到电子邮件地址。

指向新创建对象的链接

链接新对象时必须引用其主键，因为在渲染通知时对象 RID 尚未生成。

示例： 您有一个创建新 task 对象的操作，并且在创建任务时会生成唯一 ID。在您的操作通知中，您可以使用 Object Explorer 提供的参数选项渲染指向新创建对象的链接.

  • 使用函数生成的内容时，有两种受支持的指定 URL 链接的方式：
    • 完整链接示例： https://<your-foundry-instance>.com/workspace/module/view/latest/<module-rid>
    • 相对链接示例： /module/view/latest/<module-rid>

收件人所需的数据访问权限

  • 用户只能收到包含其有权查看的数据的通知。
  • 在有多个收件人的情况下，所有收件人都必须有权访问通知内容中渲染的对象数据。
  • 配置操作时，在 安全与提交条件 选项卡底部有两种处理通知失败的方法：
    • 要求所有用户都具有权限（默认）： 如果任何收件人没有所需的访问权限，尝试应用操作时将显示错误。如果发生这种情况，不会编辑任何数据，也不会发送任何通知。
    • 要求任一用户具有权限： 如果至少有一个用户可以查看该对象，操作将成功。只有具有权限的用户才会收到通知。

覆盖并禁用电子邮件内容脱敏

如果组织设置允许，您可以为特定操作类型绕过在组织级别设置的其他严格脱敏设置，并拥有一种发送未脱敏内容的操作类型。

要覆盖电子邮件通知的脱敏，请导航至 安全与提交 选项卡，然后选择 Notification settings > Disable notification redaction.

要了解如何为组织启用此功能，请参阅 电子邮件脱敏文档页面.
