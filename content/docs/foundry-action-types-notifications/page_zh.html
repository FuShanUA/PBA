通知

可以通过 添加新规则 下拉菜单为操作添加通知。 了解有关如何添加通知的更多信息。

配置通知需要指定 收件人 和 内容。以下部分提供了有关这些选项的更多详细信息。

收件人

配置通知的 收件人 选项可让您指定在操作运行时将收到通知的一组 Foundry 用户。通知将单独发送给每位收件人。不支持将用户添加为电子邮件通知的抄送（CC）收件人。

支持通过以下几种方式指定收件人：

  • 静态： 在配置中，您可以选择一组在操作运行时始终会收到通知的用户或组。

  • 从参数获取： 如果操作的某个参数是 Foundry 用户或组 ID，您可以将其指定为通知的收件人。

    • 这可用于让发送方在使用此操作的应用程序或模块的用户界面中选择一个或多个收件人，也可用于自动检测并向运行该操作的用户发送通知。

  • 从对象参数的属性获取： 如果操作具有对象参数，并且该对象的某个属性包含 Foundry 用户或组 ID，您可以将该参数的这一属性指定为接收者。对于 Foundry 用户和组 ID 的列表，同样可以这样做。

  • 通过函数： 如果您的用例未被上述选项涵盖，您可以编写一个自定义函数，该函数接收操作参数并返回应收到通知的用户或组的列表。 了解有关如何编写返回用户或组列表的函数的更多信息。

    基于函数确定接收者的用例示例包括：

    • 组合用于接收者的其他选项；例如，通知 assignee 从对象参数的属性中指定的接收者，同时还始终通知一组固定的附加接收者。
    • 基于其他参数或参数的属性值选择接收者；例如，每当 EMEA 出现新任务时，通知一组用户；每当北美出现新任务时，通知另一组用户。
    • 任何不属于结构化选项的其他自定义逻辑。

接收者可以更改其通知送达方式的偏好设置。例如，一位用户可能选择仅在网页浏览器中接收通知，而另一位用户则可能选择同时接收平台内提示和电子邮件。如果用户在个人偏好中关闭了操作通知，则不会收到通知。不过，用户在登录 Foundry 后，仍可前往 Workspace 中的“通知”并点击“查看全部”来查看自己的通知。

内容

有多种选项可用于自定义通知的内容。内容可以通过 模板 进行配置，也可以通过自定义 函数提供。选择模板内容后，您可以直接在配置对话框中配置完整内容。选择函数内容则需要您拥有一个已发布的函数，该函数会返回相应的通知类型。

内容组件

  1. 主题： 通常，内容会包含主题行。默认情况下，所有送达机制使用相同的主题行。

  2. 正文： 通知的正文。对于平台内通知，正文将显示在通知提示框内。对于电子邮件，正文将呈现在电子邮件正文中。

  3. 关联： 您可以指定一个链接，它将显示为通知正文内容正下方的一个按钮。该按钮的文本可自定义。

    • 以下选项可用于配置链接：
      • 链接到现有对象参数
      • 链接到 Workshop 应用
      • 链接到 Carbon 工作区
      • 链接到新创建的对象

  4. 高级电子邮件配置： 配置通知时，您可以指定在通过电子邮件发送通知时使用的自定义内容正文。此选项允许您使用 HTML 实现更高级的格式设置，而平台内通知不支持此类格式。预览将显示通知的外观（不包括任何参数引用）。仅当收件人将其首选项设置为通过电子邮件接收通知时，才会收到此内容。

可以在上述的主题、正文和链接中使用三重花括号来引用参数和用户属性。编辑某个部分时，点击任一可用参数，系统将自动为该参数或用户属性生成正确的花括号引用。

  1. 来自函数： 选择“来自函数”时，您无需配置上文列出的各个部分，而是必须提供一个返回 Notification 对象，其中包含适当的属性，用于指定自定义内容的各个部分。如果适用以下任一情况，您可能需要使用函数：
    • 通知内容会因收件人或操作的输入参数而完全不同。
    • 您希望为电子邮件通知和平台内通知设置不同的主题行。
    • 您希望使用完整的链接 URL，包括指向位于 Foundry 之外的外部系统或应用程序的链接。
    • 您希望在渲染内容时执行超出参数所提供范围的 Search Arounds、聚合或数据查询。
    • 您有任何其他无法通过模板内容选项实现的自定义需求。

有关 Notification 返回类型的更多信息，请参阅 函数文档。

用于生成通知内容的任何本体论数据都将反映当前操作的编辑被应用之前的本体论状态。为了让通知收件人能够访问特定对象的最新状态，可以在通知中嵌入指向通过对象参数引用的对象的链接，或指向新创建对象的链接（如果这些对象是通过"创建对象"规则而非函数创建的）。

示例配置

这是一个通知的示例配置。

  1. 收件人 配置
  2. 内容 配置
    • 可选择模板（在本体论应用对话框中直接配置）或函数（指定一个函数，返回格式完整的 Notification 对象）。
  3. 主题 行（用于模板通知）。

  7. 用于电子邮件的自定义 HTML 内容 （配合模板通知使用，可选）。

其他关键信息

收件人数量上限

  • 使用“从函数”选项渲染通知内容时，最多可有 50 位收件人。在内容配置选项下选择“从函数”时，配置面板中会显示警告，并且每次运行操作时都会检查收件人数量。如果收件人数量超过上限，将显示红色错误提示，并且操作将无法运行。
  • 在配置对话框中使用“模板”选项直接配置内容时，单个操作通知最多可有 500 位收件人。

内容长度限制

  • 主题的最大长度为 250 个字符。
  • 正文的最大长度为 1,000 个字符。在为电子邮件渲染自定义 HTML 内容时，最大长度为 51,200 个字符。

请注意，这些最大内容长度在渲染通知时会被验证并截断。这意味着，如果渲染的内容是动态的（例如，通知内容包含对象数据），任何超出允许最大长度的内容都将被截断，并以结尾的 ...。

严格脱敏

如果您的 Foundry 实例启用了出站电子邮件通知的“严格脱敏”或“群组脱敏”功能，则不会渲染自定义通知内容。用户将改为收到如下所示的通用消息。选择“查看”会将他们引导至 Foundry，在其中可以查看完整的通知内容。 了解有关 Foundry 中电子邮件内容脱敏的更多信息。

收件人用户账户

  • 系统会将群组解析为单个用户，以便在发送通知之前检查对数据的权限。
  • Foundry 用户和群组 ID 可通过“设置”下的“账户”找到。通知配置界面在选择一组静态收件人时提供了用户和群组选择器。其中仅会显示配置该操作的用户拥有足够权限的用户和群组。
  • 如果收件人是通过引用对象属性配置的，请确保该属性以字符串形式存储 Foundry 用户或组 ID。您可以使用条件格式来显示关联的用户或组显示名称（更多详情，请参阅 值格式化文档）。
  • 不支持直接发送到电子邮件地址。

指向新创建对象的链接

在链接新对象时，您必须引用其主键，因为在呈现通知时，对象 RID 尚未生成。

示例： 您有一个用于创建新 task 对象的操作，并且在创建任务时会生成唯一 ID。在您的操作通知中，您可以使用 Object Explorer 提供的参数选项来呈现指向新创建对象的链接。

  • 使用函数生成的内容时，可通过两种受支持的方式指定 URL 链接：
    • 完整链接示例： https://<your-foundry-instance>.com/workspace/module/view/latest/<module-rid>
    • 相对链接示例： /module/view/latest/<module-rid>

收件人所需的数据访问权限

  • 用户只能接收包含其有权查看的数据的通知。
  • 在存在多个收件人的情况下，所有收件人都必须有权访问通知内容中呈现的对象数据。
  • 在配置操作时，有两种处理通知失败的方法，位于侧边栏的 安全与提交条件 选项卡底部：
    • 要求所有用户都拥有权限（默认）： 如果任何收件人没有所需的访问权限，尝试应用操作时将显示错误。如果发生这种情况，将不会编辑任何数据，也不会发送任何通知。
    • 要求任一用户拥有权限： 只要至少有一名用户可以查看该对象，操作就会成功。只有拥有权限的用户才会收到通知。

覆盖并禁用电子邮件内容脱敏

如果组织设置允许，你可以针对特定操作类型绕过在组织级别设置的其他严格脱敏设置，从而拥有一种发送未脱敏内容的操作类型。

要覆盖电子邮件通知的脱敏设置，请导航至 安全与提交 选项卡，然后转到 通知设置 > 禁用通知脱敏。

要了解如何为组织启用此功能，请参阅 电子邮件脱敏文档页面。
