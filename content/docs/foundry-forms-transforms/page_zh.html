转换

日落

对于 Foundry 上的数据录入或回写工作流，Foundry Forms 已不再是推荐方案。建议改用 Foundry Ontology 构建用户输入工作流，将相关数据结构表示为对象类型，并通过 Actions 配置回写交互。详情请参阅《Forms 概览》文档。 在 Foundry Forms 中，每个表单字段都可以配置一个或多个验证器，以防止格式不正确的输入。以下是一些验证器示例： 文档。

转换是一组工具，允许用户在表单中创建动态依赖关系。通过指定字段的条件修改，用户能够更高效、更准确地引导受访者填写的数据。

在创建并配置新字段后即可使用转换。共有五种类型的转换，它们都可以组合使用，以便在受访者填写表单时为其带来不同的结果。

隐藏字段

直方图 hide field 转换允许用户根据其他字段的值对受访者隐藏某个字段。通过减少不适用字段造成的干扰，此转换可以帮助受访者更快地完成表单。

示例

Hide Field B if Field A has value X.

显示字段

直方图 show field 转换允许用户根据其他字段的值向受访者显示某个字段。与 hide field类似，此转换可以帮助受访者更快地完成表单，仅显示适用的字段。

示例

Show Field B if Field A has value X.

禁用字段

直方图 disable field 转换允许用户根据其他字段的值禁用某个字段。与 hide field 转换不同，使用 disable field 转换后的字段仍然可见；这些字段可以配置为向受访者显示重要信息，引导他们前往其他未作答或以某种方式作答后导致当前无法输入值的字段。

示例

Disable Field B if Field A has value X.

更新配置

直方图 update configuration 转换允许用户根据其他字段的值更新字段的配置。几乎所有选项都可以更改，但必须保持不变的选项除外，包括tag, uri, defaultValue, transforms 本身，以及 附件 字段中可用的选项。

示例

Add [required validator] to Field B if Field A has value X.

更改字段类型

直方图 change field type 转换允许用户根据其他字段的值更改字段的类型。

示例

Change type of Field B to [Text Area] if Field A has value X.

添加转换

要向字段添加转换，请完成以下步骤：

  1. 首先，双击某个字段，在右侧打开可视化编辑器。

  2. 在 转换 标签页中，选择 添加新转换，然后选择一种类型。

  3. 选择转换所依赖的字段（可用选项将以紫色高亮显示）。

  4. 配置条件；例如， Has no value.

  5. 如果使用 更新配置 or 更改字段类型 转换，请定义结果。

  6. 选择右下角的绿色 保存 按钮。

创建复杂条件

添加具有简单条件的转换后，可以按如下方式创建更复杂的条件：

  1. 在可视化编辑器的 转换 选项卡中，选择转换配置右上角的铅笔图标。
  2. 选择 + 在转换的现有条件下方，选择配置新条件。
  3. 使用直方图中的 是/否 and 与/或 下拉菜单来创建复杂的条件树。将鼠标悬停在 是/否 下拉菜单上，可以查看哪些条件通过 与/或.

示例

Show Field C if Field A has value X and Field B does not have value Y.

定义多个转换

可以通过点击面板底部的 添加新转换 按钮，向单个字段添加多个转换。转换按定义的顺序应用；如果存在任何冲突，以最后一个转换为准。

示例

Change [Label] of Field B to "Zip Code" if Field A has value X. Add 5-digit [regex validator] to Field B if Field A has value X.

一个字段不应同时具有 show 以及一份 hide 转换。如果希望字段默认隐藏，可以将它们合并为一个 show 转换；否则合并为一个 hide 转换。
