核心概念

本页介绍了Cipher的核心概念。

通道

A Cipher 通道 是 Foundry 的一个资源，可以在文件系统工作区中看到。通道是创建加密或哈希框架的起点。通道描述了一种特定的协议，用于混淆或解混淆值，包括加密算法、加密密钥的参数和值，或者哈希算法和密钥。

了解如何创建 Cipher 通道。

许可证

A 密钥许可证 是文件系统工作区中可访问的 Foundry 资源，用于控制对给定 Cipher Channel 中定义的加密操作的使用权限。每个 License 恰好对应一个父级 Channel。拥有查看 License 权限的用户可以使用该 License 允许的所有 Channel 操作。与其他 Foundry 资源一样，License 可以被移动和共享；但是，任何更改都会影响用户对与该 License 关联的 Channel 的可访问性。

了解如何颁发密钥许可证。

密钥加密值

使用密钥加密的值遵循一种称为 密钥加密值 的格式，其语法如下： CIPHER::<channel-rid>::<encrypted-value>::CIPHER。此格式使密钥服务能够收集解密值所需的元数据，前提是用户拥有正确的权限。
