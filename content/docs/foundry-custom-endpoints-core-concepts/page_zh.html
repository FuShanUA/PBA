核心概念

端点定义

端点定义定义了一个 API 端点，该端点接收标头、查询、路径和正文参数，以调用 Foundry 函数 或 操作 ，并传入这些参数。端点定义属于单个端点集。

端点集

端点集是一种用于对相关端点进行分组的 Compass 资源。此资源用于管理开发人员查看、编辑、发布和部署端点定义的权限。您可以在 配置 选项卡中与端点集的端点定义进行交互。

子域名

必须先通过 Control Panel 注册并批准子域名，端点才能提供服务。子域名为访问已部署的端点发布版本提供自定义域名。

创建新的端点集时，系统将提示您 注册子域名。您必须为每个端点集注册一个子域名，才能将该子域名关联到您的端点定义。通过 Control Panel 手动创建的独立子域名不受 Custom Endpoints 支持。

端点集发布与发布版本

您必须先发布端点集，才能为其创建带版本的快照。发布端点集会创建一个与语义化版本绑定且不可变的发布版本，其过程类似于使用 Git。发布会捕获当前状态，就像 git commit一样，并会为其分配语义化版本标签，类似于 git tag。每个端点集发布版本都是不可变的，但可以删除。

部署端点集发布版本

只有在将端点集发布版本部署到子域之后，端点才能被访问。可以同时部署多个发布版本。请求使用 endpoint-api-version 标头中指定的版本，未指定时默认使用最新部署的版本。
