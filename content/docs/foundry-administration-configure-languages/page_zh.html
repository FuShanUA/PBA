配置平台体验

您可以使用以下页面配置整体平台体验的设置： 平台体验 控制面板中的页面。要查看 平台体验 标签页，您必须拥有以下角色之一：

  • Enrollment 管理员 在以下位置授予的 选项卡 extension.
  • 组织管理员 or 用户体验管理员 在以下位置授予的 组织权限 extension.

配置主页 URL

组织的首页 URL 可以按组织或按用户组在以下位置配置： 平台体验 选项卡下找到。

一些常见设置的示例：

  • 大多数新的 Foundry 注册将显示一个默认的叙事主页，帮助用户了解 Foundry 平台。该主页的 URL 为 /narrative.
  • 如果 将收集到的信息存储在 仪表板应用作组织的主页，请将该值设置为 /slate/<dashboard-rid-or-permalink>.
  • 如果 碳 工作区应用作组织的主页，请将该值设置为 /carbon/<workspace-rid>

如果某些用户组应被引导到与组织默认设置不同的主页 URL，您可以在以下位置添加特定于组的覆盖设置： 组覆盖 （位于左侧边栏）。如果用户是列表中任何组的成员，将使用该列表中的第一个条目。

配置可用语言

除了英语之外，您还可以在以下位置为用户提供其他可用语言： 平台体验 扩展。

拥有其他语言访问权限的用户将在其 Foundry 侧边栏中看到一个区域设置切换器，用于选择语言。如果 遵循用户的浏览器语言偏好 or 在本地化值时始终使用浏览器的语言偏好 选项已启用，用户最初将看到 Foundry 以其网络浏览器偏好中设置为最高优先级的可用语言显示。否则，默认使用英语，直到用户从语言切换器中选择其他语言。

Foundry 中的某些小部件会设置为用户的浏览器语言偏好，必要时可能需要更新浏览器语言设置。

配置平台徽标

平台徽标可以按注册和组织进行配置，将默认 Palantir 徽标的所有出现替换为您选择的图像。按注册配置徽标需要 Enrollment 管理员 权限。如果没有这些权限，您只能按组织配置徽标。您最多可以提供四种不同的徽标尺寸：favicon（网站图标）、小、中和大。如果您没有为每种尺寸提供图像，Foundry 将使用合适的备用尺寸。favicon 没有任何备用行为。自定义徽标时，您应该上传一个 favicon 和 至少 其他三种尺寸之一。

配置平台标题

平台标题可以按注册和组织进行配置，并使用提供的标题替换对平台的引用。按注册配置标题需要 Enrollment 管理员 权限。如果没有这些权限，您只能按组织配置标题。默认的平台标题为 Palantir。您可以在以下位置进行配置： 平台标题 Ontology Manager 平台体验 扩展。

配置新的平台标题后，此更新也会反映在平台内文档的名称中。例如，如果您将平台重命名为 ABC，平台内文档应用程序将从默认的 Custom documentation 标题更改为 ABC documentation.

配置平台版本

直方图 平台版本切换器 允许您选择使用不同版本的平台。例如，某些用户可能更愿意使用 测试版 版本的平台，以便在 稳定 版本的平台上可用之前更早地访问新功能。

要查看和配置 平台版本 控制面板中的标签页，用户需要 管理平台版本 工作流，该工作流由 用户体验管理员 角色授予。角色在以下位置管理： 组织权限 控制面板中的标签页。

平台版本

通过平台版本切换器可以使用三种平台版本： 稳定, 测试版日 预先.

稳定

稳定版已经过严格测试，并被广泛使用。绝大多数用户将使用稳定版。

测试版

Beta 版是未来的稳定版，包含当前稳定版尚未提供的新变更和新功能。由于 Beta 版较新，此版本中所做的变更可能未经过与稳定版同样严格的测试，您可能会遇到意外行为。在 Palantir 平台上进行构建时，选择加入 Beta 版有助于提前使用新功能。

先前版本

先前版本是指紧邻当前稳定版之前的稳定版。当稳定版发生变更时，切换到先前版本可用于查看旧版 UI，但不建议将先前版本用于日常使用。用户可以临时查看先前版本，但之后会自动切回其默认版本（参见 配置用户的默认平台版本).

平台版本切换器

要更改平台版本，请导航到左侧边栏底部的账户设置，然后选择旁边的当前版本 平台版本 以打开平台版本切换器。选择其他版本将重新加载页面并加载新版本。

向用户显示的默认版本由 Control Panel 中的默认平台版本设置决定。当查看非稳定版的平台版本时，侧边栏中会显示一个小标签，以指示用户正在查看其他版本。

限制对平台版本切换器的访问

可以限制您组织中用户对侧边栏中平台版本切换器的访问。要更改切换器的访问权限，请导航到 平台体验 扩展，然后转到 平台版本 标签页。

选择 管理 + 新建 平台版本切换器 以弹出更改平台版本切换器设置的对话框。

选择所需的访问权限，然后选择 为您的组织请求并应用更改。这将在 Control Panel 的审批收件箱 中创建一个变更请求，该请求将自动获得自我批准并应用。要查看所有过去的更改，请选择 平台版本切换器请求 （在审批收件箱中）。

配置用户的默认平台版本

管理员还可以将用户组配置为默认使用 Beta 平台版本。如果这些用户中的任何用户有权访问平台版本切换器，他们仍然可以从 Beta 版本切换到其他版本。这使您可以选择一组应默认使用 Beta 版本的高级用户，以便他们可以在其余用户看到新功能之前先试用这些功能。

要配置哪些用户应默认看到 Beta 版本，请选择 管理 + 新建 默认平台版本。在对话框中，选择要使用 Beta 版本的组；不在所选组中的任何用户将默认看到稳定版。

配置完成后，请选择 为您的组织请求并应用更改。这将在 Control Panel 的审批收件箱 中创建一个变更请求，该请求将自动获得自我批准并应用。要查看所有过去的更改，请选择 平台版本默认请求 （在审批收件箱中）。

配置静态横幅

您可以为每个组织配置一个静态横幅，该横幅显示在每个页面的顶部、底部或顶部和底部。 横幅文本 字段支持基本的 Markdown 语法。此设置默认处于禁用状态。
