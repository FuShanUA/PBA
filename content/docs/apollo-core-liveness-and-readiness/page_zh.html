存活性和就绪性

Apollo 会使用 Kubernetes 探针自动从受管环境中收集存活性和就绪性信息。有关如何配置这些探针的更多信息,请查阅 Kubernetes 文档 ↗。

存活性

存活探针的定义目的是能够判断服务实例(例如 Kubernetes 中的容器 Pod)是否正在运行。通常,这些探针被配置为对服务实例执行定期检查(例如 HTTP 请求或 gRPC 请求)。存活探针失败表明服务实例已进入无法使用的状态,需要重新启动。

就绪性

就绪探针使服务所有者能够在服务启动后告知基础设施其服务何时已准备好接受网络流量。这通常在服务需要时间执行某些启动操作(例如在接受网络请求之前建立数据库连接)时非常有用。

在 Kubernetes 中进行配置

在 Kubernetes 环境中运行时，Apollo 支持从 Kubernetes 检索工作负载的存活和就绪信息，并将其展示给 Apollo Hub 中的用户。这些信息是从 Apollo 管理的每个实体自动收集的。
