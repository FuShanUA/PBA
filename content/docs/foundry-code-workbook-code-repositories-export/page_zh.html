导出到代码仓库

Python 和 SQL 代码可以从 Code Workbook 导出到代码仓库。将代码迁移到代码仓库对于生产管道非常有用，因为它提供完整的 git 版本控制以及多种高级管道工具。 了解更多关于代码仓库的信息。

导出时，将在仓库中创建一个新分支，其中 Code Workbook 代码会被转换为其对应的代码仓库形式。由于这是尽力而为的转换，您可能需要调整代码来移动文件、更改数据集名称和路径、调整导入的包等。

导出是一次性的单向导出。后续对 Code Workbook 的编辑不会自动推送到代码仓库，也不支持将相同的数据集重复导出到同一仓库。代码无法从代码仓库导出回 Code Workbook。此外，执行导出的用户必须对目标代码仓库至少拥有 Editor 权限。

支持的类型

目前，仅支持 SQL 节点或具有 Pandas 或 Spark 数据框输入和输出的 Python 代码节点。导出的节点集必须相互连接，且以导入的数据集为根。

输入类型为 Python 转换输入或对象的节点不受支持。

在将代码导出到代码仓库之前，请确保代码仓库支持所需的语言。例如，如果您同时导出 SQL 和 Python 节点，可能需要向仅支持 SQL 或仅支持 Python 的仓库添加新的子项目。

如何导出

To export, from a Code Workbook, go to the Settings cog > Export to Code Repository Helper:

点击 Select Repository 并选择一个代码仓库：

使用左侧面板中的复选框选择要导出的数据集。

图表显示哪些数据集可以导出（白色），哪些不可导出（灰色）。导出必须是一个连通图，因此将节点添加到选择中可能会使更多节点可供导出。将鼠标悬停在已禁用的节点上会说明其无法被选择的原因。

准备好导出后，点击 Create pull request

将在所选的代码仓库中创建一个新分支，其中包含从 Code Workbook 导出的代码。点击 "View pull request" 可在代码仓库中打开该拉取请求。

在此处您可以检查导出的代码，并进行任何所需的编辑，例如数据集路径和名称。

验证 transforms-python/src/codeWorkbookExport 中导出的数据集是否已导入并添加到您的管道中 transforms-python/src/myproject/pipeline.py （按需操作）。

Code Workbook 中的任何自定义包版本都将被添加到 transforms-python/conda_recipe/meta.yml.

Code Workbook 和代码仓库不支持完全相同的包集合。虽然大多数包应该可以正常工作，但某些包可能无法通过仓库检查。

准备就绪后，即可创建 PR，并按照常规流程将导出的代码合并到管道中。

写入相同的数据集

默认情况下，导出到代码仓库将写入新的数据集。如果您希望写入与 Code Workbook 相同的数据集，请按照以下步骤操作：

  1. 导航到由 Export to Code Repository 操作在仓库中创建的分支。将输出数据集路径更改为所需数据集的路径。
  2. 对于每个数据集，请导航到 Details 数据集页面的选项卡，并删除该数据集的作业规范。这是允许仓库接管该数据集所必需的操作。
  3. 创建 PR 并按照常规流程将代码合并到管道中。当 CI 检查在仓库中运行时，将在目标数据集上创建新的作业规范。

将这些数据集传输到仓库后， 您将无法再使用原始 Code Workbook 写入这些数据集。 您可能希望删除已导出的节点以避免混淆。
