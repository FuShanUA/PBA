Palantir MCP

Palantir MCP 是 Model Context Protocol ↗的一种实现。Palantir MCP 使 AI IDE 和 AI 智能体能够在 Palantir 平台内自主设计、构建、编辑和审查端到端应用程序,涵盖从数据集成到本体论配置以及应用开发的方方面面。此外,您还可以使用 Palantir MCP 允许外部 AI 系统查询文档、元数据和数据,并在平台上执行高级任务。开发人员可以使用 Palantir MCP 自动执行辅助任务,同时专注于自己正在构建的系统。

在开始使用 Palantir MCP 之前,请先查看我们的安装指南和其他资源:

  1. 请按照 安装说明 将 Palantir MCP 安装到您的 IDE 中。或者,您可以使用 AI 开发工具 可在 VS Code 工作区中使用，以访问 Palantir MCP。
  2. 请查阅 Palantir MCP 入门指南。
  3. 请查阅我们的 安全与数据流文档。

我应该在什么时候使用 Palantir MCP？

Palantir MCP 为开发者提供两项主要优势：

  1. 上下文： Palantir MCP 为 LLM 智能体提供上下文，帮助其导航内部 Palantir 资源库并理解 Foundry 架构。
  2. 工具： Palantir MCP 为 LLM 智能体提供工具，用于探索您的本体论和 Foundry 项目并执行操作。

用于消费的本体论 MCP

Palantir MCP 专为本体论构建者设计，可以修改本体论类型，但无法写入本体论数据。相比之下， 本体论 MCP (OMCP) 使本体论使用者能够通过外部 AI 代理安全地读取和写入您本体论中的数据。本体论 MCP 会以 MCP 工具的形式公开您应用程序的对象类型、操作类型和查询函数。Copilot Studio 或 Gemini Enterprise 等外部系统可以使用这些 MCP 工具来执行操作和写入数据，同时通过应用程序限制来约束代理可以执行的操作。如需了解有关启用本体论 MCP 的更多信息，请参阅 开发者控制台文档。

使用 Palantir 库和 API

在提供了适当代码上下文的前提下，LLM 代理非常擅长编写与新系统和库集成的代码。Palantir MCP 会在必要时为 LLM 提供具体示例。该 MCP 会识别您当前的代码仓库，并针对代码仓库类型（例如 OSDK 代码仓库、Python 转换和 Typescript 函数）注入量身定制的上下文。此外，该 MCP 还会搜索 Palantir 的代码片段索引，并为不适合特定代码仓库的库提供上下文。

构建 OSDK 应用程序

Palantir MCP 提供在 Foundry 中执行操作的工具。具体来说，MCP 可以搜索您的本体论、安全地修改本体论，以及更新您的 Developer Console 应用程序。例如，您可以要求它 Find me the object/links/functions to {do something}， Create this object-type/link-type and integrate it with my application，或 Apply this proposal to my Developer Console application。
