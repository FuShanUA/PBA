Kiosk 模式

Kiosk 模式使构建者能够为 Workshop 应用启用长期且受限的会话，从而可以安全地长时间展示这些应用。

Kiosk 模式会话是只读的，这意味着无法触发对象编辑和创建等本体论回写，并且其权限范围有所缩减，从而限制了会话中可查看的内容。有关 Kiosk 模式会话范围内包含哪些实体的详细信息，请参阅 此处。

Kiosk 模式会限制权限并限制内容访问。如果您想在不更改权限的情况下，为截图或屏幕共享在视觉上隐藏数据，请改用 脱敏模式 。

为 Workshop 模块配置 Kiosk 模式

Kiosk 模式设置可以按 组织 在 控制面板中进行配置和管理。

将模块添加到 Kiosk 模式设置的白名单后，拥有启动 Kiosk 模式会话权限的构建者可以导航到 高级功能 区（位于该模块的 设置 面板中），并启用 Kiosk 模式 开关来启动会话。 打开 kiosk 按钮将显示在模块的右上角。选择此按钮将打开一个模态框，其中概述了模块当前已发布版本中在会话期间可见的内容。这包括对象类型、关联类型、函数以及其他嵌入式 Foundry 应用程序。查看模块内容范围后，请选择 启动会话 以开始自助服务终端模式会话。

在控制面板和 Workshop 中为模块配置并启用自助服务终端模式后，您还可以在查看模式下启动自助服务终端模式会话，只需选择 打开自助服务终端。

要结束自助服务终端模式会话，请选择 退出自助服务终端模式。管理员还可以在 会话启动历史记录 表格中结束当前处于活动状态的自助服务终端模式会话，该表格位于 控制面板的自助服务终端模式设置部分。

自助服务终端模式会话范围

在自助服务终端模式下，模块的权限范围将被缩小，以限制在活动会话中可查看的内容。因此，模块处于自助服务终端模式时您可查看的内容，可能与处于查看或编辑模式时可查看的内容有所不同。

在 Kiosk 模式会话中可查看且处于会话范围内的内容将显示在 范围内的内容 部分，该部分位于 启动 Kiosk 会话 模态框中。请注意，来自嵌入式 Workshop 模块的嵌套实体将自动包含在 Kiosk 模式会话中并可查看。但是，来自其他嵌入式 Foundry 应用程序的嵌套实体不会自动包含。

以下两个示例说明了 Kiosk 模式如何缩小实体权限范围，以限制会话中可查看的内容：

  • 通过 Vertex Graph 小部件嵌入的 Vertex Graph 可能会引用 Workshop 模块中未直接存在的对象类型。这意味着，当启动 Kiosk 模式会话时，该对象类型将不会包含在会话范围内，并且在 Kiosk 模式下将不可查看。
  • 如果相应的关联类型不存在于 Workshop 模块中，则在模块内对对象类型执行 search around 的函数在 Kiosk 模式下可能会失败。

您可以使用 启动 Kiosk 会话 以确定在 kiosk 模式下哪些实体会存在或缺失。要将缺失的实体纳入 kiosk 模式会话的范围内，您可以在模块中的某个位置添加对该实体的直接引用。

限制

  • 由受限视图数据源支撑的对象类型在 kiosk 模式下不受支持。
  • 出于安全目的，所有嵌入式 Slate 应用程序均已被禁用，因为它们能够写回本体论。
  • 在开发 OSDK 应用程序时，应用程序构建者有责任确保 iframe 的内容妥善管理授权或令牌，以使授权在整个 kiosk 会话期间保持有效。请查看 刷新访问令牌 以了解更多信息。
  • 标准的非活动超时对话框仍会出现在 kiosk 模式会话中。虽然 kiosk 会话被设计为长时间运行，但出于安全原因，它们仍遵循平台的会话超时策略。
