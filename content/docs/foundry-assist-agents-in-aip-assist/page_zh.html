将 AIP Chatbots 部署到 AIP Assist

在 AIP Assist 中提供自定义内容源，可显著扩展用户可获取的应用协助。此功能还可与 AIP Chatbot Studio (前身为 AIP Agent Studio)集成，允许用户设置由 LLM 驱动的专用助手，这些助手可使用自定义内容源、来自本体论的上下文或诸如 函数等工具。开发人员现在无需编码或 LLM 专业知识，即可创建定制的助手。

作为一个示例用例，假设开发人员正在构建一个需要向数百或数千名用户推出的应用程序。借助 AIP Chatbot Studio 与 AIP Assist 的集成，开发人员现在可以快速配置并交付自定义的 LLM 助手(即 AIP Chatbots),以基于自定义内容源提供即时、交互式的支持。

AIP Chatbots 与 Chatbot Studio

要理解此功能，请先熟悉 AIP Chatbot 的概念以及 AIP Chatbot Studio 应用程序：

AIP Chatbots: 交互式的 LLM 驱动助手，配备企业专属的信息和工具。

AIP Chatbot Studio: 允许用户构建无代码的 AIP Chatbots,并将其部署在 Palantir 平台内部，同时可通过我们的 OSDK进行外部部署。

创建内容并注册自定义源

创建由自定义来源支持的 AIP 聊天机器人的第一步是将您的自定义内容导入 Palantir 平台。目前有两种方法可以添加可向 AIP Assist 注册的自定义内容源：

  1. （推荐） Notepad 文档
  2. 平台内 自定义文档 （Markdown 文件存放在 documentation 类型仓库中，该仓库位于代码仓库内）。

在本教程中，我们将探讨第一个选项。有关此功能的更多信息，请参阅 向 AIP Assist 注册内容源。

此功能目前可能并非在所有注册中都可用。如果您没有看到向 AIP Assist 添加 Notepad 文档的选项，请联系您的 Palantir 代表，以确认您的注册是否符合条件。

  1. 在 Notepad 中，选择 + 新建文档来创建新文档。编写或粘贴您的内容，并为文档提供标题和内容的简要描述。在下面的示例中，我们添加了有关我们的示例应用程序（库存管理应用程序）的信息。

  1. 请务必使用标题和小节来组织您的内容。采用标题结构可以显著提高回复的准确性，因为内容会根据标题进行分段。请参阅 自定义内容源最佳实践 以了解更多信息。

  2. 在 AIP Assist 中注册您的内容。要执行此操作，请选择 操作 > 添加到 AIP Assist。请注意，在文档变得可被 AIP Assist 发现后，此内容可能需要一段时间才会显示。

  1. 为您的文档添加标题和简要说明文档内容的描述，然后保存。AIP Assist 和 AIP Chatbot 现在将知晓此文档。

注意： 这不会以任何方式影响 AIP Assist 或 AIP Chatbot 的行为。这只是使内容可供 AIP Assist 使用。您仍需要构建并部署一个利用该内容的 AIP Chatbot。

创建 AIP Chatbot 并将其部署到 AIP Assist

  1. 导航到 AIP Chatbot Studio 应用程序并选择 + 新建 AIP Chatbot。

  2. 系统将显示一个设置向导，协助您完成 AIP Chatbot 的创建。首先，为您的聊天机器人命名并添加描述。这些信息将在用户发现和使用您的聊天机器人时显示，因此请务必使其具有描述性。您还可以为您的聊天机器人提供一个图标，以帮助用户发现它：

注意： AIP 聊天机器人是 Palantir 文件系统资源。它们的权限将继承自其保存所在的文件系统位置。用户只有对该保存位置拥有读取权限， 以及 对支撑它的自定义内容源拥有访问权限，才能访问您的聊天机器人。

  1. 保存聊天机器人后，您将被重定向到 AIP Chatbot Studio 编辑器。导航至 聊天机器人配置 部分，然后在 检索上下文 下选择 自定义文档上下文 并选择您先前已索引的文档。如果它未出现在列表中，请返回第一步，并确保您已将其添加到 AIP Assist。您可以选择多个不同的文档作为 AIP 聊天机器人的搜索上下文。请参阅 AIP Chatbot Studio 文档 以了解有关其他 AIP 聊天机器人功能的更多信息。

  1. 您还可以选择希望聊天机器人使用的模型。您的聊天机器人用户应拥有对该模型的访问权限。此外，您可以通过提供自定义指令来自定义 AIP 聊天机器人的行为。

  1. 选择右上角的蓝色对勾图标来发布您的 AIP Chatbot。这将发布聊天机器人的第一个版本 (1.0)。此后您所做的任何更改，都需要发布新版本才能生效。

  1. 使聊天机器人可在 AIP Assist 中使用。为此，请打开 使用情况 部分，并启用 AIP Assist 开关。

与您的新 AIP Chatbot 互动

现在您已经创建了 AIP Assist Chatbot，并为其提供了对您 Notepad 内容的访问权限，可以开始在 AIP Assist 中与它互动了。

  1. 在 AIP Assist 中开始一段新对话。您应该会看到您的新聊天机器人已出现在 AIP Assist 模式 选择器中。

  1. 选择您的聊天机器人，提出您的第一个问题吧！
