将 AIP Chatbots 部署到 AIP Assist

通过 AIP Assist 提供自定义内容源，可以极大地扩展用户可用的应用协助功能。此功能还与 AIP聊天机器人工作室 （前身为 AIP Agent Studio）集成，允许用户设置由 LLM 驱动的专用助手，这些助手可使用自定义内容源、来自本体论（Ontology）的上下文或诸如 函数等工具。开发人员现在无需编程或 LLM 专业知识即可创建定制的助手。

作为一个示例用例，假设开发人员正在构建一个需要向数百或数千名用户推出的应用程序。借助 AIP Chatbot Studio 与 AIP Assist 的集成，开发人员现在可以快速配置并交付由 LLM 驱动的自定义助手（即 AIP Chatbots），以便基于自定义内容源提供即时、交互式的支持。

AIP Chatbots 与 Chatbot Studio

要理解此功能，请先熟悉 AIP Chatbot 的概念以及 AIP聊天机器人工作室 应用程序：

AIP Chatbots： 交互式、由 LLM 驱动的助手，配备企业特定的信息和工具。

AIP Chatbot Studio： 允许用户构建无代码的 AIP Chatbots，并在 Palantir 平台内部部署，或通过我们的 OSDK.

创建内容并注册自定义源

创建由自定义源支撑的 AIP Chatbots 的第一步是将您的自定义内容上传到 Palantir 平台。目前有两种添加自定义内容源的方法，这些内容源可注册到 AIP Assist：

  1. （推荐） Notepad 文档
  2. 平台内 自定义文档 （Markdown 文件位于代码仓库的一个 documentation 类型的存储库中）。

在本教程中，我们将探讨第一种方法。有关此功能的更多信息，请参阅 向 AIP Assist 注册内容源.

此功能目前可能并非在所有租户（enrollment）上都可用。如果您没有看到向 AIP Assist 添加 Notepad 文档的选项，请联系您的 Palantir 代表，以确认您的租户是否符合条件。

  1. 在 Notepad 中，通过选择 + New document来创建新文档。编写或粘贴您的内容，并为文档指定标题和简要的内容描述。在下面的示例中，我们添加了有关示例应用程序——库存管理应用程序（Inventory Management Application）的信息。

  1. 请务必将内容组织为标题和小节。拥有标题结构可显著提高响应的准确性，因为内容会根据标题进行分段。请参阅 自定义内容源最佳实践 的文档以获取更多信息。

  2. 将您的内容注册到 AIP Assist。您可以通过选择 Actions > Add to AIP Assist来完成。文档变为 AIP Assist 可发现的状态可能需要一些时间。

  1. 为您的文档指定标题和简要说明文档内容的描述，然后保存。AIP Assist 和 AIP Chatbots 现在将能够识别此文档。

注意： 这不会以任何方式影响 AIP Assist 或 AIP Chatbots 的行为。这只是使内容对 AIP Assist 可用。您仍需构建并部署一个利用该内容的 AIP Chatbot。

创建 AIP Chatbot 并将其部署到 AIP Assist

  1. 在 Data Connection 中导航至 AIP聊天机器人工作室 应用程序，然后选择 + New AIP Chatbot。

  2. 系统将显示一个设置向导来协助您创建 AIP Chatbot。首先为您的聊天机器人指定名称和描述。这些信息将在用户发现和使用您的聊天机器人时显示，因此请确保描述清晰。您还可以为您的聊天机器人提供一个图标，以帮助用户发现它：

注意： AIP Chatbots 是 Palantir 文件系统资源。它们的权限将继承自保存它们的文件系统位置。只有对保存位置具有读取权限的用户才能访问您的聊天机器人 和 以及对其支撑的自定义内容源的访问权限。

  1. 保存聊天机器人后，您将被重定向到 AIP Chatbot Studio 编辑器。导航到 聊天机器人配置 部分，然后在 检索上下文 select 自定义文档上下文 下，选择您之前索引的文档。如果它没有出现在列表中，请返回第一步并确认您已将其添加到 AIP Assist。您可以选择多个不同的文档作为 AIP Chatbot 的搜索上下文。参见 AIP Chatbot Studio 文档 以了解其他 AIP Chatbot 功能的更多信息。

  1. 您还可以选择聊天机器人要使用的模型。您的聊天机器人用户应有权访问该模型。此外，您可以通过提供自定义指令来自定义 AIP Chatbot 的行为。

  1. 通过选择右上角的蓝色对勾图标来发布您的 AIP Chatbot。这将发布聊天机器人的第一个版本 (1.0)。此后您所做的任何更改都需要发布新版本才能生效。

  1. 使聊天机器人可在 AIP Assist 中使用。为此，请打开 用法 部分，并启用 AIP Assist toggle.

与您的新 AIP Chatbot 交互

现在您已经创建了 AIP Assist Chatbot 并为其提供了对您 Notepad 内容的访问权限，您可以开始在 AIP Assist 中与它进行交互了。

  1. 在 AIP Assist 中开始新的对话。您应该会在 AIP Assist 中看到您的新聊天机器人可用 模式 selector.

  1. 选择您的聊天机器人，提出您的第一个问题吧！
