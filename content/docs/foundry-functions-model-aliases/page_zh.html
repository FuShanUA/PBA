模型别名

模型别名是语言模型的命名引用，提供了一种在代码中引用语言模型的便捷方式。

有关在函数中使用语言模型的完整演练，请参阅 TypeScript v2 和 Python 函数中的语言模型。

定义模型别名

要定义模型别名，请打开一个 TypeScript v2 或 Python 代码仓库，并按照以下步骤操作：

  1. 打开 Platform SDK 选项卡（位于 资源导入 面板中）。

  1. 要导入新的语言模型，请选择 添加 > 模型 （位于右上角）。系统将打开一个窗口，您可以在其中查看可用的 Palantir 提供的模型和已注册的模型。

  1. 选择要导入的模型，然后选择 确认选择。系统将打开一个配置对话框，您可以在其中为每个选定的模型配置别名。选择别名附近的笔图标进行编辑，或选择保留默认值。

别名键在仓库中必须唯一。

  1. 导入的模型将显示在 Platform SDK 选项卡中（位于 资源导入 侧边面板）。您可以通过选择别名旁边的笔图标来内联编辑任意别名。

在代码中使用模型别名

要在函数中使用模型别名，请导入别名实用工具并按名称引用该别名。该别名会解析为模型 RID，您可以将其传递给模型客户端：

Copied!
1
2
3
import { Aliases } from "@osdk/functions";

const modelRid = Aliases.model("gpt5Nano").rid;
Copied!
1
2
3
from functions.aliases import model

model_rid = model("gpt5Nano").rid

有关使用别名调用语言模型的完整示例，请参阅 编写使用语言模型的函数。

模型别名适用于添加到 Marketplace 产品中的函数，但在安装过程中无法重新映射。如果别名引用的模型在目标环境中不可用，函数将在运行时无法解析该别名。

相关内容

您还可以定义 自定义别名 ，用于配置参数、功能标志或特定于环境的设置等字符串值。自定义别名会显示在 Platform SDK 选项卡中，并且可以使函数跨环境移植。
