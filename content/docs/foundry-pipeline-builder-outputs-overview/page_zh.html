输出

管道输出 是 Pipeline Builder 中管道的最终结果；输出可以是数据集、 虚拟表，或本体论组件，例如对象类型、对象关联或时间序列。

输出可帮助您描述管道，从添加数据到创建转换逻辑。在部署第一个管道构建后会创建输出，并允许您在其他 Foundry 应用程序中扩展您的工作流和 Project 功能。

要添加输出，请选择 添加管道输出 （位于图右侧的输出面板中）。

系统将打开一个侧面板，您可以在其中选择要添加的输出类型。

请查看以下各节，了解每种输出类型的详细信息。

数据集

A 数据集 是 Foundry 中的基本元素。Pipeline Builder 中的工作流以添加数据集开始，继而对数据集进行转换，并可以以数据集作为输出结束。当您想要构建一个生成干净的、经过转换的数据的管道时，请添加数据集作为输出。您可以在 Ontology Manager 中使用最终数据集作为本体论构建的基础。

了解更多关于 添加数据集输出.

媒体集

A 媒体集 是具有共同架构（例如相同格式的文件）的媒体文件集合。媒体集支持多种形式的非结构化数据，包括视觉媒体、PDF 文档、音频等。当您想要构建一个生成干净的、经过转换的媒体的管道时，请添加媒体集作为输出。

了解更多关于 添加媒体集输出.

文件

使用 文件 输出可从转换后的文件数据生成文件和文件集。选择要输出的转换，然后选择 添加输出 和 输出文件.

地理时间序列同步

地理时间序列 可用于随时间推移跟踪实体的地理位置，由不同的观测数据组成。每个观测数据包含标识符、时间戳、位置和其他用户指定的属性。您可以在 Pipeline Builder 管道中添加地理时间序列同步输出，使 Foundry 中的批量或流式地理时间数据可供下游应用程序（例如 Map 应用程序）使用。来自 Foundry 的地理时间观测数据是在 Pipeline Builder 中写入的。

了解更多关于 在 Pipeline Builder 中添加地理时间序列同步.

要在 Pipeline Builder 中使用地理时间序列同步输出，您的租户必须启用地理时间序列。如需了解有关启用此功能的更多问题，请联系您的 Palantir 代表。

虚拟表 [Beta]

A 虚拟表 充当指向 Foundry 外部源系统中某个表的指针，允许您在 Foundry 中使用该数据而无需将其摄取。与数据集类似，您可以将虚拟表添加到管道中，继续进行转换，并以虚拟表或数据集作为输出结束。当您想要使用外部系统进行存储时，请使用虚拟表作为输出。管道可以混合使用数据集和虚拟表；例如，您可以从数据集开始并将输出写入外部，也可以从虚拟表开始并将输出写入 Foundry。

了解更多关于 添加虚拟表输出.

本体论输出

将本体论元素作为输出添加到管道中，可引导您的工作流从原始数据集到已清理和结构化的数据，这些数据定义了全局本体论中的新对象类型元素。借助 Pipeline Builder，您可以在一个工作流界面中添加和编辑对象类型、关联类型和时间序列，而无需导航回 Ontology Manager。

An 对象类型 是现实世界实体或事件的架构定义。将对象类型输出添加到工作流中，有助于引导数据转换为已定义的元素，您可以使用这些元素在 Foundry 中构建应用程序，包括 来运行该专业代码代理。你还可以通过 模块或 将收集到的信息存储在 应用程序。您还可以选择性地 实现接口 在对象类型输出上映射接口属性到对象类型属性。

对象关联

A 关联类型 是两种对象类型之间关系的模式定义。 链接 指两个对象之间该关系的单个实例。如果在管道中添加两个对象类型输出，可以创建关联来定义它们之间的关系，并将其添加到全局本体论中。使用对象关联在 Workshop 和 Slate 中构建强大的应用程序。

时间序列同步

时间序列数据 是由一个或多个时间戳和值对组成的数据；这些值对用于测量随时间变化的量。这可以包括测量每年的销售量、每天的总航班数、每小时的生产产出，或亚秒级分辨率的高频温度读数。在管道中添加时间序列同步输出，以为时间序列属性提供支撑数据索引。
