手动执行

你可以对已有的对象集手动运行自动化任务。这在回填数据或在更大范围发布前测试自动化任务时非常实用。

您可以手动执行已暂停的自动化。当您使用 立即运行时，系统会显示警告，确认计划的和实时的触发器仍处于禁用状态。已过期、已删除（trashed）以及其他被禁用的自动化将继续阻止所有执行。

手动执行的运行者将被认定为在 Automate 界面中选择 执行 的用户。用户必须对 Automate 资源拥有 Compass 编辑权限，才能手动执行自动化任务。

若要手动执行自动化任务，首先请 创建新的自动化任务 并配置所需的效果。接着，打开该自动化任务并进入 执行 标签页。

自动化任务被手动执行时，该任务配置的效果将立即触发（视具体条件而定，可选作用于用户自定义的对象集）。

示例：通过手动执行进行修复

大量积压的数据可能会导致手动执行时出现快照过期错误。要解决此问题，可使用基于函数的对象集，以可控批次的方式处理积压数据：

  1. 创建一个返回最旧的 N 对象（需要处理的对象）的函数。例如， oldestNObjectsWithBlankField(int count) 返回按最后编辑时间戳排序的对象，并带有数量限制。
  2. 将自动化任务配置为使用调用该函数生成的对象集。
  3. 以合理的批次大小重复手动执行该自动化任务，并等待每次执行完成。
  4. 继续手动执行，直到积压的对象少于 100,000 个。
  5. 一旦积压数据处理完毕，常规的基于条件的自动化任务即可在新对象到达时进行处理。

执行设置

执行设置提供了多个可配置参数：

  • 指定对象集： 对于 对象集条件，你可以指定输入对象集。有关对象集大小限制，请参阅关于 限制 的文档。该对象集包含的对象类型必须与自动化条件中配置的类型一致。该对象集中的所有对象都会触发自动化任务，并作为 New object 参数传入任何效果中。目前支持三种对象集类型：

    • 已定义对象集： 静态（手动选择的对象），或动态（通过对所选对象集设置筛选条件定义）。
    • 已保存对象集： 作为 Palantir 资源保存的对象集。
    • 函数生成的对象集： 选择一个函数并使用静态值定义其参数。该函数必须返回与条件对象集对象类型相同的对象集。

  • 批次大小： 批次大小决定每次执行包含的对象数量。例如，若批次大小为 100 个对象，而已定义对象集中有 1,000 个对象，则该自动化任务将分 10 次独立执行（每次处理 100 个对象），每次执行间隔 1 分钟。对象的分区采用非确定性的随机顺序。

    • 如果自动化任务的条件不涉及对象集，则不会显示批次大小配置项。

  • 并行度： 并行度指定并行运行的批次数量。数值越大，执行速度越快。

  • 通知接收者： 手动执行支持向所有用户发送通知。

    触发手动执行时，系统将使用发起执行的用户令牌来评估对象集。这确保了评估过程严格遵守执行用户的权限和访问控制。

监控执行结果

运行手动执行后，您可以在事件历史记录中查看执行结果。查看效果执行时，可以使用以下可观测性功能：

  • 火焰图： 查看跨函数、操作和语言模型的执行流程。利用时间和批次关系信息来监控并行度并识别故障。
  • 服务日志： 查看 token 使用情况、日志消息、错误和追踪信息。
