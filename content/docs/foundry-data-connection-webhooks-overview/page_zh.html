Webhook

您可以使用 Data Connection 来配置 。操作可以对 Foundry 本体论中的数据进行编辑，或通过 以将 Foundry 连接到 Foundry 之外的系统和工作流。

本部分包含有关 出站 webhook（Foundry 向另一个系统发出请求）的信息。如果您需要接收 入站 webhook（另一个系统向 Foundry 发送请求），请考虑使用 监听器 来替代。

每个 webhook 都提供了一种向 Foundry 之外的外部系统发出请求的方式。例如，您可以创建一个 webhook，当用户在 Foundry 应用程序中选择按钮时，该 webhook 会向外部服务器执行 HTTP 请求，从而将该应用程序连接到现有的工作流和源系统。

每个 webhook 都与 Data Connection 中的单个 源 相关联。源存储连接到外部系统所需的凭据。根据 webhook 所关联的源的类型，可以使用某些任务类型。例如，在使用 REST时，您可以灵活地配置应向外部服务发出的 HTTP 调用。

可以灵活配置 webhook 以接受特定输入并捕获外部系统请求的输出。此外，您还可以对 webhook 执行设置时间、并发和速率限制。有关详细的配置选项，请参阅 webhook 参考.
