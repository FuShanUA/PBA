在 Foundry 应用程序中解密单个值

在对象中渲染加密值

经 Cipher 加密的属性值可以有选择地解密，以便在 Workshop 和 Object Explorer中查看。拥有相关 Cipher 许可证访问权限的用户在填写理由提示后即可解密相应的值。

您必须在 属性 视图中指定此解密设置，该视图位于 Ontology Manager中。对于每个经 Cipher 加密的字段，请转到 Property Type 字段，然后从下拉菜单中选择 Cipher text 。您还可以选择 Plaintext Type 来捕获加密前的数据类型，并指定 Default Encryption Cipher Channel 用于加密对初始为空或未加密字段所做的编辑。

标记为 CipherText 的属性将使用 Encrypted Value 渲染器进行渲染。这将使每个值能够在大多数 Foundry 前端中被渲染并可供选择，包括 Workshop 和 Object Explorer。

如果您希望允许用户更新加密值（例如，纠正拼写错误），我们建议使用 updateAsync 函数，并将其挂接到 操作。

若要允许进行内联编辑，请添加 cipher: editable 类型类应用于该属性。通常不建议采用此方法，因为它要求将您的对象存储在 Object Storage v1 中，并允许通过 API 调用进行编辑。用户需要拥有支持加密的相应许可证才能编辑值。

以前，字符串属性是使用 Encrypted Value 渲染器进行渲染的，具体方法是使用 RID Renderer 选项，该选项位于 Ontology App 的 Value Formatting 部分中。我们建议您改用 CipherText 属性类型。
