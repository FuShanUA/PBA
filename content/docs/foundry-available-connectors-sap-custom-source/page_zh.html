SAP（自定义源）

SAP（自定义源）连接器允许您使用手动配置的源将 Foundry 连接到 SAP 系统，该源采用 magritte-sap-source 连接器类型。此连接器使用基于 YAML 的自定义设置，而非较新的 SAP 连接器中提供的引导式配置。

新的 SAP 集成应使用 SAP ERP 或 SAP SLT 连接器。这些连接器使用更新且性能更高的 API 从 SAP 读取数据，并提供引导式设置体验。SAP（自定义源）连接器适用于在这些连接器类型推出之前建立的现有集成。

使用 SAP（自定义源）连接器需要安装 Palantir Foundry Connector 2.0 for SAP Applications 附加组件 ，并将其安装在目标 SAP 应用层上。

设置

  1. 打开 Data Connection 应用程序，然后选择 + 新建源 （位于屏幕右上角）。

  2. 选择 添加自定义源。

  3. 为源指定名称和位置。

  4. 在自定义 YAML 部分中，输入源定义：

    Copied!
    1
2
3
type: magritte-sap-source
url: https://<host>:<port>/sap/palantir
usernamePassword: <username>:{{password}}
    • <host> 是 SAP 应用服务器的主机名。
    • <port> 是 Internet Communication Manager (ICM) 的 HTTPS（或 HTTP）端口。
    • 用户名和密码是安装 Connector时为 Foundry 创建的技术用户的。

    输入 {{password}} （完全按照所示内容）。保存后，在对话框右侧的 加密值 中输入密码值。

  5. 选择 保存。

了解有关在 Foundry 中 设置连接器 的更多信息。

网络和连接

请确保正确配置 出站策略 以允许 Foundry 访问 SAP 系统。对于本地部署的 SAP 环境， agent 代理策略 通常是正确路由流量所必需的。

许多 SAP 系统使用自定义签名证书，这可能在首次配置连接时导致 SSL 握手异常。请确保您拥有来自系统的正确自定义证书，并 将其添加到源中。

  2. 对于远程连接和 SLT 连接，请选择相应的上下文。

  3. 选择感兴趣的表或模块，并将其添加到图中。

批量同步

创建同步

为要提取到 Foundry 的每个 SAP 对象创建一个同步。

同步配置界面有两种模式： 基本 和 高级。该 高级 选项卡以YAML格式呈现完整的同步定义，并且下文所述的某些对象类型和配置参数需要使用该选项卡。您可以切换回基本视图，但任何在UI中没有对应项的YAML属性都不会显示，并且会丢失。

  1. 在源概览页面中，选择 + 新建 （在批量同步旁边）。
  2. 配置标准设置：名称、目标数据集和计划。
  3. 将 事务类型 设置为以下选项之一：
    • APPEND ——用于增量更新。请参阅 增量同步 以了解详情。
    • SNAPSHOT ——用于全量加载。
  4. 请选择一个 SAP对象类型 （请参阅下文的 SAP对象类型 部分。）
  5. 如果使用SLT或连接到远程系统，请选择一个 上下文。请参阅 安装远程代理 ，了解有关上下文的详细信息。
  6. 输入 对象名称。输入时，该字段会根据所选的SAP对象类型推荐匹配的对象。
  7. 如果要配置增量同步，请指定一个 增量字段。
  8. （可选）在 Extras 选项卡中配置其他参数。

BEx 查询配置

BEx 是基于 SAP BW InfoProvider 构建的多维查询框架。BEx 查询使用标准的 SAP BW 访问方法，并继承所有 SAP BW 授权概念。它们代表应用于 InfoProvider 视图的业务逻辑。

如果 BEx 查询包含动态列（即某特性与关键指标一同置于列上，使每个关键指标都随特性值重复出现），则会生成动态输出。Foundry 不支持动态列——请相应地调整查询。

当您选择 BW BEx 查询 作为对象类型时，同步编辑器会显示专用的 BEx 查询构建器，其中包含以下选项：

选项描述
使用技术名称在技术列名称与人类可读（因语言而异）的列名称之间切换。
删除列从输出中删除关键特征。
自由特征将自由特征（如 BEx 查询中所定义）添加到输出中。
筛选在查询运行后筛选数据（查询后筛选）。
BEx 查询输入变量为 BEx 查询输入变量提供筛选值。

有关 BEx 分页配置，请参阅 高级 YAML 参数 （位于同步参数部分）。

函数配置

SAP 函数模块既可以从 SAP 系统中提取数据，也可以将数据写回 SAP 系统。连接器只能从具有至少一个表格输出参数的函数中提取数据。

Foundry 技术用户需要以下授权角色才能提取函数结果：

  • /PALANTIR/SERVICE_USER
  • /PALANTIR/CONTENT_FUNCTION_ALL
  • 运行特定函数所需的任何授权角色或对象

如果函数返回多个输出参数，请使用 paramName 参数来指定要写入 Foundry 数据集的输出：

type: magritte-sap-source-adapter
sapType: function
obj: BAPI_USER_GETLIST
paramName: USERLIST

类型YAML 语法

结构（字典）PARAM_NAME: '{"FIELD1": "value1", "FIELD2": "value2"}'
表格（字典列表）PARAM_NAME: '[{"FIELD1": "value1"}, {"FIELD1": "value2"}]'

表格类型输入参数的示例：

增量同步

增量同步是有状态的同步，可从同一表启用追加式事务。要启用增量同步，请将 事务类型 设置为 APPEND。

可用的增量类型如下：

增量类型描述
单个字段导入单个字段大于或等于已导入的最大值的行。
多个字段与单个字段相同，但使用 OR 运算符组合多个字段。适用于同时存在 "created" 和 "last updated" 时间戳字段的情况。字段之间用逗号分隔。
拼接字段与多个字段相同，但将字段拼接在一起而不是用 OR 组合。适用于存在单独的 "last updated date" 和 "last updated time" 字段的情况。
使用变更文档表根据 SAP 变更文档表（CDHDR 和 CDPOS）中的更新导入行。适用于目标表缺少单调递增字段的情况。请注意，某些对象可能无法捕获插入操作。
使用 twin 或 twinjoin 表当单独的 "twin" 表中的字段满足增量条件时，从目标表导入行。twinjoin 表允许将目标设为多个表的联接。

对象类型单个字段多个字段拼接字段变更文档表孪生表SAP 内置复制基于请求
表✓✓✓✓✓✓

SLT✓

BEx 查询或函数不支持增量更新。这些对象类型的所有同步均为全量提取。

增量字段理想情况下应为单调递增的值。系统使用“大于或等于”比较,以避免同步在某个日期中途运行时遗漏数据。因此,Foundry 数据集中可能会出现重复值,应作为转换管道的第一步将其删除。

对于表类型增量同步,请使用 maxRowsPerSync 设置(通过 高级 选项卡进行配置)来限制每次运行返回的大致行数。当网络故障等间歇性问题可能中断长时间运行的同步时,这对于将大型表的初始同步拆分为一系列更小、更具弹性的运行非常有用。参见 高级 YAML 参数 以了解配置详情。

孪生表配置

该 增量孪生表 设置指定了孪生表。该 增量孪生映射 设置定义了主表与孪生表之间的连接条件。

映射语法：

{PRIMARY_TABLE_NAME}-{FIELD_NAME}={TWIN_TABLE_NAME}-{FIELD_NAME}

多个连接条件可以用分号组合（即 AND 运算符）。

针对 InfoProvider 的基于请求的增量

在 SAP BW 中，DSO 和 InfoCube 使用数据传输进程（DTP）进行加载。每个 DTP 都会创建一个加载请求，连接器会使用这些请求来捕获变更数据。

此功能仅支持未压缩的请求。在加载到 Foundry 之前，请求不得进行压缩。如果请求在加载前被压缩，同步将失败，且必须重新执行初始加载。

通过 高级 选项卡进行配置：

Copied!
1
2
3
4
type: magritte-sap-source-adapter
sapType: infoprovider
obj: <technical-name-of-infoprovider>
incrementalType: REQUEST

重置增量状态

若要强制执行全量重新加载并重新初始化增量摄取：

  1. 切换到 高级 选项卡（位于同步配置中）。
  2. 将 resetIncrementalState: true 添加到 YAML 中。
  3. 将事务类型设置为 SNAPSHOT （保留所有 incremental* 参数不变）。
  4. 运行同步。此操作会执行全量快照，并替换数据集中的所有文件。
  5. 将 resetIncrementalState: true 从 YAML 中移除。
  6. 将事务类型改回 APPEND。

后续同步将照常恢复增量追加。

调试日志记录

调试日志记录会在 SAP 系统中启动一个在同步期间运行的后台进程。这可能会大量消耗资源并影响其他用户。请谨慎使用。

设置为 开启 ，即可为此同步启用调试日志记录。

持续资源检查

当 开启时，所有分页请求都会接受资源检查（内存、CPU）。当 关闭时，仅检查初始页面请求。请参阅 性能参数 了解详情。

资源检查

禁用资源检查后，无论可用内存、CPU 和进程数量如何，同步都会运行。这可能给 SAP 系统带来过大负载。请谨慎使用。

设置为 关闭 ，即可为此同步禁用所有资源检查。

筛选

筛选从 SAP 提取的数据。所有字段名称必须与数据字典匹配。

运算符含义
,OR
;AND
:介于
=等于
!=不等于
>, >=, <, <=比较
*通配符

示例：

  • 价格介于 500 和 650 之间： PRICE=500:650
  • 客户 A、B 或 C： CUSTOMER=A,B,C
  • 价格介于 500 和 650 之间 AND 客户 A、B 或 C： PRICE=500:650;CUSTOMER=A,B,C
  • 物料以 PAL、DIS 或 SAP 开头： MATERIAL=PAL*,DIS*,SAP*
  • 2019 年 8 月 9 日当天或之后的日期（格式为 YYYYMMDD）： DATE>=20190809

动态筛选器

动态筛选器使用特殊关键字和函数来创建更灵活的筛选表达式。自加载项版本 SP26 及更高版本起可用。

固定关键字

关键字说明
[CURRENTYEAR]当前年份，采用 YYYY 格式。
[TODAY]今天的日期，采用 YYYYMMDD 格式。
[LASTDAYOFMONTH]当月最后一天，采用 YYYYMMDD 格式。
[LASTDAYOFLASTMONTH]上月最后一天，采用 YYYYMMDD 格式。
[FIRSTDAYOFMONTH]当月第一天，采用 YYYYMMDD 格式。
[FIRSTDAYOFLASTMONTH]上月第一天，采用 YYYYMMDD 格式。

日期计算函数

函数说明
[ADDDAY]向所选日期添加天数。示例： [ADDDAY(22102022,1)] → 23102022。
[ADDMONTH]向所选日期添加月数。
[ADDYEAR]向所选日期添加年数。
[GETMONTH]以两位数值（01–12）形式返回所选日期的月份。
[GETDAY]以两位数值形式返回当月的第几天。
[GETYEAR]返回所选日期的年份。

函数可以直接与固定关键字一起使用，也可以嵌套使用：

  • 单个函数： [ADDDAY([TODAY], 1)]
  • 嵌套： [GETDAY([ADDDAY([FIRSTDAYOFMONTH], -1)])]

示例：

  • 今天之后的记录： BUDAT>[TODAY]
  • 上个月最后一天之后的记录： BUDAT>[ADDDAY([FIRSTDAYOFMONTH], -1)]

流式同步

Beta

来自 SAP 的流式同步功能目前处于 beta 开发阶段，您的注册环境中可能无法使用此功能。功能在开发过程中可能会发生变化。

流式同步仅支持通过 SAP SLT Replication Server 建立的连接，并且要求源配置有显式的 SLT 连接类型（请参阅上方的 启用流式同步 ）。

每个流式同步都会在 SLT Replication Server 中创建并订阅自己的操作增量队列 (ODQ)。Foundry 会定期轮询该队列（默认间隔：1 秒）：

  • 如果队列为空，则在下一次轮询之前不会发出更多请求。
  • 如果队列中有 50,000 条或更少的记录，则会同步使用这些记录。
  • 如果记录超过 50,000 条，则会分页使用。

为了获得最低延迟，SLT Replication Server 的可用对话工作进程数量应至少与活动流式同步的数量相同。

创建流式同步

  1. 打开 SAP 源。在 概览 页面，向下滚动到流式同步表，然后选择 + 创建流式同步。

  2. 输入要流式传输的 SAP 表的名称。

  3. 为输出流式数据集选择一个位置。

    在继续之前，请确保屏幕底部的预览窗格已完成加载。流式数据集的架构由此预览生成。在某些情况下，预览可能仅显示架构而不显示数据——这已经足够。

  4. 选择 创建流式同步。你可以选择立即启动流，也可以在创建后手动启动。

为确保流在 Data Connection 代理或 SAP 系统停机后自动重启， 设置一个计划 ，该计划应用于流式数据集，并使用 1 分钟的时间触发器。

吞吐量与分区键

将吞吐量设置从 正常 切换为 极高 可能会提升性能，但会增加所使用的分区数量。当使用多个分区时，必须设置分区键，以确保来自 SAP 的唯一记录之间的顺序。这些键应对应于 SAP 中相应表的主键。

Webhooks

SAP Webhook 使你能够从 Foundry 中调用业务 API (BAPI)，将数据写回 SAP。请参阅 Webhooks 以获取有关如何设置 webhook 的概述。

SAP webhook 支持 Foundry 工作节点 连接（位于 Foundry 托管的云计算中）。对于 SAP webhook，我们建议使用此运行时来执行，而不是通过 数据连接代理。在 Foundry 工作节点上配置的现有 SAP 数据源将自动受益于云端执行，无需迁移；在数据连接代理上运行的 SAP 数据源应 切换到 Foundry 工作节点 以利用云端执行的 webhook。
