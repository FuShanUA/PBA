《共享 Python 代码库》

在多个 Python transforms 仓库之间共享代码的推荐工作流是发布一个 Python 库包——具体来说，一个 Conda ↗ 库。版本为 1.23.1 及以上的 Python transforms 仓库支持发布 Python 库。

发布 Python 库

以下是发布 Python 库所需的步骤：

  1. 创建一个新仓库 ，用于存放共享库的 Python 代码。

  2. 为仓库命名。 初始化时，库将以仓库名称命名。其他代码仓库将使用此名称来发现和使用您的库。之后您可以通过访问 gradle.properties 文件并编辑 condaPackageName 参数来重命名（此文件是隐藏的，因此您可能需要先在文件编辑器中选择“显示隐藏文件”）。 condaPackageName 只能包含 ASCII 小写字母、数字或连字符，任何既非字母数字也非连字符的字符序列都将被替换为单个连字符。例如， my_library repo 将被发布为 my-library-repo日 Foobar _baz$$$ 将被发布为 foobar-baz-.

  3. 选择 创建 按钮，位于 Python Library 模板部分。

  4. 创建包： 库中任何包含 __init__.py 文件的文件夹都将作为包发布。您的仓库在初始化时会包含这样一个文件夹——可根据需要重命名并添加更多包。

  5. 创建模块： 在包文件夹中，您可以添加包含代码的 Python 文件。这些模块之后将被其他仓库导入。

  1. 为仓库打标签： 准备好发布时，导航到“Branches”标签页，选择“Tags”并创建新标签。默认情况下，Python 库仅针对已打标签的提交发布。要更改此默认行为，您必须修改 build.gradle file.

标签名称必须符合 SLS 版本规范，具体见 SLS Versions 文档 ↗.

  1. 检查成功完成后，您的库版本将被发布。您可以在仓库的标签列表和 Checks 标签页中查看检查状态。默认情况下，只有当您创建标签时，库的更改才会发布，您可以针对某个分支的当前状态或特定提交创建标签。检查通过后，用户将能够升级到最新版本，但使用方仓库不会在新版本发布时自动升级。要手动将仓库升级到最新版本，请查阅以下文档： 发现和使用 Python 库 以及 Conda 锁定文件 以重新解析 Conda 环境。

  2. 确保为库的使用者授予相应权限。默认情况下，用户应在您的共享仓库上拥有“Viewer”角色。在 transform 仓库设置的 Artifacts 标签页下添加对库仓库的引用。

此时，您的库应已可供其他应用和仓库使用。阅读更多关于 发现和使用 Python 包.

查找 Python 库的使用者

要查看哪些仓库正在使用您发布的库，请导航到 Artifact Repositories 界面 并使用 搜索 标签页来定位您的库。找到您感兴趣的版本并展开 下载量 列以查看 </> 消费者 区域的字段中添加命令。
