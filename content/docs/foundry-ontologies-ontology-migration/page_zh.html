将本体论资源迁移到另一个本体论

每个本体论资源都与其创建时所在的本体论相关联。创建后，您可以使用以下方法将资源从一个本体论移动到另一个本体论 本体论管理器。迁移资源可能会更改其权限，但不会更改底层数据或输入数据源上的权限。迁移对象类型时，默认会保留对象编辑。

支持的资源和限制

您可以选择以下本体论资源进行迁移：

  • 关联类型
  • 操作类型
  • 共享属性（Shared properties）
  • 接口
  • 对象类型组（Object type groups）
值类型无法迁移

值类型 与 空间 相关联，且不属于本体论资源，因此您无法将其迁移到另一个本体论。迁移对象类型或共享属性不会迁移其值类型。如果要迁移使用值类型的对象类型或共享属性，您需要在迁移前取消分配该值类型。

除非对象类型最初是在默认本体论中创建的，否则您无法将对象类型从私有本体论迁移到默认本体论。迁移对象类型组时，您还必须选择该组中要迁移的对象类型。

开始之前

保存或放弃任何待处理的本体论更改，并确保您有权将资源迁移到目标本体论。查看 权限 将应用于已迁移资源的权限，包括从其目标项目继承的权限。

识别迁移中所有相关的连接资源，例如通过您要从一个本体论迁移到另一个本体论的关联类型连接的对象类型。如果您的选择中缺少所需的本体论资源，迁移将失败。

迁移所选资源

按照以下说明将资源从一个本体论迁移到另一个本体论：

  1. 打开 本体论管理器。使用左侧边栏顶部的本体论选择器切换到拥有这些资源的本体论。

  2. 再次打开本体论选择器并选择 迁移本体论实体.

  3. 在监听器设置向导的 类型 步骤中，选择 迁移实体 以迁移单独选择的资源，然后选择 属性，然后选择.

  4. 在监听器设置向导的 组织 步骤中，选择 目标本体论，然后选择 属性，然后选择。该 源本体论 是您在打开对话框之前选择的本体论。

  5. 在监听器设置向导的 选择 步骤中，使用资源选项卡和搜索字段查找资源。在左侧面板中选择资源，将其添加到右侧面板的迁移选择中。使用 添加相关实体 对所选对象类型或操作类型进行操作，以包含其相关资源。

  6. 查看所有资源选项卡中的选择，然后选择 属性，然后选择.

  7. 如果 保存位置 步骤会针对存储在项目中的资源显示，请在目标本体论的空间中选择一个目标项目，然后选择 属性，然后选择。在继续之前查看项目的权限。

  8. 在监听器设置向导的 确认 步骤中，查看源本体论、目标本体论和所选资源。选择 迁移 以立即执行迁移；无需单独保存。
