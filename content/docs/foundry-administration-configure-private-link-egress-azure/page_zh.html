为 Azure 配置专用链接出口

本页面概述了如何为部署在 Azure 上的 Palantir 平台配置和管理专用链接出口,以连接到 Azure 中托管的客户服务,该功能由 Azure Private Link ↗提供支持。

专用链接出口支持通过专用出口访问 Azure 服务、部署在 Azure 上的用户自有资源,或部署在 Azure 上的第三方 API。

配置专用链接

导航到 专用链接 选项卡,该选项卡位于 Control Panel 的 网络出口 页面,即可管理专用链接。

要成功创建专用链接连接:

  1. 为您的目标资源创建专用链接服务。
  2. 允许 Palantir 平台访问目标资源。
  3. 提供目标资源的详细信息。
  4. 创建网络出口策略。

为您的目标资源创建专用链接服务

支持专用终结点的 Azure 服务

许多 Azure 服务原生支持专用终结点,使您能够通过专用链接连接到这些服务,而无需创建自定义专用链接服务。支持专用终结点的 Azure 服务的完整列表可在 Azure 文档 ↗中找到。

对于这些服务,Azure 会自动提供必要的专用链接服务配置,您只需创建专用终结点连接即可。

允许 Palantir 平台访问目标资源

要使 Palantir 平台能够创建指向您的 Azure 资源的专用终结点连接，您必须配置可见性设置，并可选择配置自动审批设置。

对于自定义专用链接服务

对于自定义 专用链接服务 ↗，请按照以下步骤操作：

  1. 在以下位置查找 Palantir 平台的 Azure 订阅 ID： 控制面板 > 网络出口 > 专用链接。



  2. 将 Palantir 订阅 ID 添加到对您的专用链接服务具有可见性的订阅列表中。这使 Palantir 平台能够请求访问该服务。

  3. （可选）为 Palantir 订阅 ID 启用自动审批，以便自动批准连接请求，从而无需手动审批。

对于 Azure PaaS 服务

对于大多数 Azure PaaS 服务（例如 Azure Storage、Azure SQL Database、Azure Key Vault、Cosmos DB 等），默认行为如下：

  • 任何知道该资源 ID 或名称的用户都可以查看该资源。
  • 任何在其订阅中拥有足够 Azure 权限的用户都可以尝试创建指向您的资源的专用终结点。
  • 这将触发手动审批工作流，您需要在其中接受或拒绝连接请求。

自动审批配置因 Azure 服务而异。某些服务支持预先批准的订阅，而其他服务则需要对每个连接请求进行手动审批。有关详细说明，请查阅针对您的具体服务的 Azure 文档。

提供目标资源的详细信息

要在 Control Panel 中创建专用链接，您需要获取想要连接的目标资源的 Azure 资源 ID。

  1. 导航到 Control Panel > 网络出口 > 专用链接 并选择 新建专用链接。
  2. 输入您的 Azure 资源的 资源 ID 。资源 ID 是指向您的资源的完整 Azure Resource Manager 路径。
  3. （可选）指定 子资源 ，如果您想要连接到目标资源的特定子资源（例如 blob 用于 Azure Storage，或 sqlServer 用于 Azure SQL Database）。

标准专用链接

标准专用链接是连接大多数 Azure 资源和自定义专用链接服务时的默认配置。对于 Azure SQL Database、Azure Key Vault、Azure Cosmos DB、自定义专用链接服务以及其他 Azure PaaS 服务，请使用标准专用链接。创建标准专用链接时，您需要提供资源 ID，并可以选择指定子资源。

高级设置：

  • DNS 区域： 用于名称解析的专用 DNS 区域（例如 privatelink.blob.core.windows.net）。如果指定了 DNS 记录，则为必需。
  • DNS 记录： 可以选择为专用链接指定自定义 DNS 记录。如果添加 DNS 记录，则还必须指定 DNS 区域。

对于标准专用链接，DNS 配置为可选项。如果未指定，则必须直接使用 Azure 生成的专用终结点 IP 地址。

存储专用链接

将存储专用链接专门用于 Azure 存储帐户（资源 ID 中包含 /Microsoft.Storage/storageAccounts/ 的资源）。与标准专用链接不同，存储专用链接会自动定义 DNS 配置，以处理存储资源的 Azure 网络边缘情况。系统会生成所需的 DNS 区域和记录，格式为 {storage-account-name}.privatelink.{sub-resource}.core.windows.net。

有关存储专用链接的重要说明：

  • DNS 配置由系统自动管理，无法更改。
  • 系统将为存储帐户的专用终结点创建相应的 DNS 记录。
  • 必须根据要访问的存储服务指定子资源（blob、file、table、queue、dfs）。

提供上述详细信息后，选择 创建。

专用链接可能具有以下状态：

  • 正在创建： 专用链接的创建已开始。
  • 正在创建云资源： 正在预配 Azure 专用终结点和相关云资源。
  • 正在等待云资源： 正在等待 Azure 完成专用终结点的预配。
  • 等待接受： 专用链接正在等待服务提供商接受（适用于某些 Azure 服务）。
  • 就绪： 专用链接已成功创建，并且可以正常运行。

创建专用链接出站策略

成功创建专用链接后，请创建专用链接出站策略，以允许对目标资源进行出站访问。

  1. 若要创建网络出站策略，请在控制面板中选择以下选项： 操作 > 创建网络出站策略 。
  2. 选择 专用链接 类型的地址，并在创建网络出站策略时为每个条目输入目标资源的端口。这些已创建的策略会显示在控制面板中的以下位置： 操作 > 查看网络出站策略 。

在专用链接处于 就绪 状态且已创建网络出站策略后，即可在 Palantir 平台中使用该专用链接。

管理专用链接

可对专用链接执行的操作显示在专用链接详情页面的 操作 菜单下；此外，在专用链接页面中，每个条目也会显示相应的可用操作。

更新专用链接

专用链接的 DNS 区域、 DNS 记录和 TCP 端口 可通过选择以下选项进行更新： 操作 > 更新。

删除专用链接

若要删除私有链接，请选择 操作 > 删除。
