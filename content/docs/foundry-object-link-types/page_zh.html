类型参考

在定义本体论时，您可以使用各种各样的类型来表示您导入 Foundry 的数据的真实世界定义。Foundry 中使用的类型分为 本体论 类型或 数据 类型：

  • 本体论类型 用于将真实世界领域建模为本体论。
  • 数据 类型用于表示数据值。Foundry 中的数据类型借鉴了以下标准中的类似概念： RDF ↗、 OWL ↗ 和 XSD ↗。

本体论资源

以下类型可用于构建和定义您的本体论。

对象类型

一个 对象类型 是真实世界实体或事件的架构定义，由各个对象组成。例如， JFK 和 LHR 都可以是 Airport 对象类型的对象。

了解更多关于对象类型的信息。

属性

一个 属性 是对象类型的一种特征，用于描述真实世界实体或事件。例如，如果 LHR 是 Airport 对象类型的一个对象， name 和 country 是 Airport的属性。 LHR 对象，其属性值如下：

  • name： LHR
  • country： 英国

了解更多关于属性的信息。

共享属性

一个 共享属性 是一种可用于本体论中多个对象类型的属性。共享属性可实现跨对象类型的一致数据建模和属性元数据的集中管理。

了解更多关于共享属性的信息。

关联类型

一种 关联类型 是两个对象类型之间关系的模式定义。一种 关联 是指两个对象之间该关系的单个实例。

了解更多关于关联类型的信息。

操作类型

一种 操作类型 是针对对象、属性值和关联的一组更改或编辑的模式定义，用户可以一次性完成这些更改或编辑。操作类型还包括操作发生时产生的副作用行为。一旦在本体论中配置了操作类型，最终用户就可以通过应用操作来更改对象。

了解更多关于操作类型的信息。

对象类型组

对象类型组是一种分类基元，可帮助用户更好地搜索和探索其本体论。

了解更多关于对象类型组的信息。

接口

一种 接口 是描述对象类型的结构及其功能的本体论类型。接口提供对象类型多态性，支持对具有相同结构的对象类型进行一致的建模与交互。

对象类型与对象之间的区别

为了阐明对象类型与对象之间的区别，下面提供了示例。请注意，同样的区别也适用于关联类型和关联。

对象类型定义

对象类型定义（有时简称为“对象类型”）是指有关本体论实体（例如对象类型、关联类型和操作类型）的类型级别信息。例如，对象类型的元数据可能包括显示名称、属性名称、属性数据类型和描述。元数据并不指对象类型属性或主键的实际数据或值；这些被视为本体论数据。

对象实例

对象实例（有时简称为“对象”）是本体论实体特定实例的实际主键值和属性值。例如，一个 Airplane 对象类型可以有一个对象实例，该实例的 Plane ID 属性的值为 my_plane_id1，而其 Maximum Occupancy 属性的值为 240。

值类型

值类型 是围绕字段类型构建的语义封装，由元数据和约束组成，可增强类型安全性、提高表达能力并提供额外上下文。值类型封装特定于领域的数据类型，并以可在整个平台范围内重用的方式强制执行数据验证。常用的值类型包括电子邮件地址、URL、UUID 和枚举。

虽然字段类型和基类型是静态定义的，但值类型是在给定 空间的上下文中进行定制的。因此，用户无法创建新的字段类型或基类型，但可以创建 值类型 ，且这一过程是动态的。
