为 AWS 配置专用链接出口

本页面概述了如何为托管在 AWS 上并连接到客户服务的 Palantir 平台配置和管理专用链接出口，该功能由 AWS PrivateLink ↗提供支持。

专用链接出口支持以私有方式连接到 AWS 服务、部署在 AWS 上的用户自有资源，或部署在 AWS 上的第三方 API。

配置专用链接

导航至 专用链接 标签页（位于 Control Panel 的 网络出口 页面），以管理专用链接。

要成功创建专用链接连接：

  1. 为您的目标资源创建终端节点服务。
  2. 允许 Palantir 平台访问目标资源。
  3. 提供目标资源的终端节点服务名称。
  4. 创建网络出口策略。

为您的目标资源创建终端节点服务

AWS 服务

兼容专用链接的 AWS 服务及其终端节点服务名称的列表可在 AWS 文档 ↗中找到。对于 AWS 服务，无需创建终端节点服务；可以使用 AWS 提供的终端节点服务名称。支持专用链接的 AWS 服务的一个示例是 Amazon Bedrock ↗。

不支持与 AWS S3 的专用链接。请使用 同区域 S3 存储桶策略 以实现与 S3 的私有连接。

AWS 上的用户自有资源

对于部署在 AWS 上的用户自有资源，请按照 AWS 文档 ↗中的步骤创建终端节点服务。用户自有资源的一个示例是由 AWS RDS ↗提供支持的数据库。

AWS 上的第三方 API

对于部署在 AWS 上的用户自有第三方 API，请按照 AWS 文档 ↗中的步骤创建终端节点服务。如果由另一方拥有，请向其请求 VPC 终端节点服务名称。例如，可以按照 Snowflake 文档 ↗中所示的方式请求 Snowflake 的 VPC 终端节点服务名称。

此外，如果服务使用的自定义传输层安全性 (TLS) 证书对私有链接的 AWS 生成的域名 ↗ 无效，则需要请求第三方 API 的私有域名。例如，可以按照 Snowflake 文档 ↗中的说明找到 Snowflake 的私有域名。以下是一个第三方私有域名的示例：

abc.us-east-1.privatelink.snowflakecomputing.com

允许 Palantir 平台访问目标资源

要通过私有链接访问目标资源，请允许 Palantir 平台访问该资源。将 Palantir 平台的 AWS 账户添加到您的终端节点服务的允许主体列表中，具体步骤请参阅 AWS 文档 ↗。允许的主体应如下所示：

arn:aws:iam::<palantir_platform_aws_account_id>:root

提供目标资源的端点服务名称

  1. 导航至 控制面板 > 网络出口 > 私有链接 并选择 新建私有链接 以创建私有链接。

  2. 为私有链接的目标资源输入以下详细信息：

    • 端点服务名称： 在上述步骤中获取的目标资源的端点服务名称。



    • 高级设置：

      • 私有域名： 如果私有链接出口指向具有自定义 TLS 证书的资源，请在此处添加这些域名条目。Palantir 平台将为这些域名创建 CNAME 记录，这些记录映射到私有链接的另一端。
      • TCP 端口： 添加应允许通过此私有链接的端口；默认端口为 443。



  3. 提供上述详细信息后，选择 创建。

私有链接可能具有以下状态：

  • 正在创建： 已开始创建私有链接。
  • 正在创建云资源： 正在预配云资源。
  • 正在管理 DNS： 正在管理 DNS 记录。
  • 正在等待云资源： 正在等待云提供商创建资源。
  • 等待接受： 私有链接正在等待服务提供商接受。
  • 就绪： 私有链接已成功创建。

如果私有链接处于 失败 状态，则发生了以下错误之一：

  • 失败： 连接请求失败。请检查您在 AWS 中的虚拟私有云 (VPC) 终端节点服务配置的权限，然后重新创建。
  • 已拒绝： 服务提供商拒绝了连接请求。VPC 终端节点服务的所有者已拒绝该连接，请联系他们以继续。
  • 已过期： 连接请求已过期。VPC 终端节点服务的所有者未及时接受连接，请重新创建私有链接。
  • 超时： 私有链接创建超时。这可能是暂时性错误，请将其删除并重试。如果重试未能解决问题，请联系 Palantir 支持团队。
  • 验证失败： 私有链接验证失败。请联系您的 Palantir 管理员以继续。
  • 云提供商错误： 云资源创建失败。请联系您的 Palantir 管理员以继续。
  • DNS 管理失败： DNS 管理失败。请联系您的 Palantir 管理员以继续。

创建私有链接出站策略

成功创建私有链接后，请创建 私有链接出站策略 以允许出站访问目标资源。

  1. 要创建网络出站策略，请选择 Actions > Create network egress policy （在 Control Panel 中）。
  2. 请选择 私有链接 类型的地址，并在创建网络出口策略时逐项输入目标资源的端口。这些已创建的策略显示在 操作 > 查看网络出口策略 （位于控制面板中）。

需要出口策略的情况

  • 默认域名需要网络出口策略。如果您要连接到第三方 API，且不打算使用 AWS 生成的默认域名，则网络出口策略 并非 必需。



  • 如果您打算使用区域域名，请为这些区域域名创建网络出口策略。如果您的 VPC 与 Palantir 平台位于同一 AWS 区域，则使用同一区域的域名可能更高效。



  • 如果已配置私有域名，请为其创建网络出口策略。



    当私有链接处于 就绪 状态且已创建网络出口策略后，即可在 Palantir 平台中使用该私有链接。

管理私有链接

可对私有链接执行的操作显示在 操作 （位于私有链接详情页面）下，以及私有链接页面中每个条目处。

更新私有链接

私有链接的 私有域名 和 TCP 端口 可以通过选择 操作 > 更新来更新。

删除私有链接

要删除私有链接，请选择 操作 > 删除。

共享网络出口策略

将已创建的网络出口策略共享给需要通过私有链接向目标资源进行出口访问的用户。在要共享的域名或 IP 上，选择 操作 > 查看网络出口策略 并导航至网络策略页面。在网络策略页面上，选择 操作 > 管理共享 并添加要与之共享该网络出口策略的用户或用户组。

使用私有链接

Data Connection 数据源

在 Data Connection 中， 配置数据源时使用 默认域名或第三方 API 域名，并附加已创建的网络出口策略。配置完成后，通过预览或浏览数据源来测试连通性，并验证数据源中的数据是否准确。

Snowflake 数据源

要创建通过私有链接连接的 Snowflake 数据源，请按照以下步骤操作：

  1. 在 Snowflake 中将 Palantir 平台的云提供商账户加入允许列表。
  2. 在 Control Panel 中创建私有链接。
  3. 在 Data Connection 中创建 Snowflake 数据源。

在 Snowflake 中将 Palantir 平台的云提供商账户加入允许列表

为了让 Palantir 平台创建指向 Snowflake 的私有链接，需要在您的 Snowflake 账户中将 Palantir 平台的账户加入允许列表。为此，请执行以下操作：

  1. 在以下位置查找 Palantir 平台的云提供商账户 ID： 控制面板 > 网络出口 > 私有链接 ，如下图所示：



  2. 向 Snowflake 提交一个 支持工单 ↗ ，并提供以下信息：
    • Palantir 平台的云提供商账户 ID（请注明云提供商：AWS、Azure 或 GCP）。
    • Snowflake 账户的 URL。
    • 请说明需要将上述账户 ID 加入允许列表，以便与 Palatir 建立私有连接。请注意， SYSTEM$AUTHORIZE_PRIVATELINK 无法使用，因为 Palantir 用户无法直接访问底层云提供商基础设施，且不会获得所需的 federated_token。

在 Snowflake 将 Palantir 平台的云提供商账户加入允许列表后，请继续执行下一步。

在控制面板中创建私有链接

在 Palantir 平台与 Snowflake 之间创建私有链接之前，请先运行命令 SYSTEM$GET_PRIVATELINK_CONFIG ↗从 Snowflake 获取私有链接配置。该命令会输出在 Palantir 平台中创建私有链接所需的信息。

  1. 要创建私有链接，请导航至 控制面板 > 网络出口 > 私有链接 > 新建私有链接。



  2. 输入上述输出中的以下详细信息，以创建私有链接：
    • 端点服务名称： 输入 privatelink-vpce-id ，该值来自 SYSTEM$GET_PRIVATELINK_CONFIG的输出。
    • 高级设置：
      • 私有域名： Palantir 平台会将这些 URL 映射到 Snowflake 私有链接的另一端，并通过私有链接路由流量，同时保持 Snowflake 使用在线证书状态协议（OCSP）来确保安全。如需了解更多关于 配置 VPC 网络 ↗ 的信息，请参阅 Snowflake 文档。以下值可通过 SYSTEM$GET_PRIVATELINK_CONFIG获取：
        • privatelink-account-url
        • privatelink-connection-ocsp-urls
        • privatelink-connection-urls
        • privatelink-ocsp-url
        • regionless-privatelink-account-url
        • regionless-snowsight-privatelink-url
        • snowsight-privatelink-url
      • TCP 端口： 输入 443 和 80 ，如 Snowflake 文档 ↗中所述。

配置完成后，选择 Create 以创建私有链接。当私有链接处于 Ready 状态时，继续执行下一步。

在 Data Connection 中创建 Snowflake 数据源

  1. 要在 Data Connection 中创建 Snowflake 数据源，请导航至 Data Connection > New Source > Snowflake。
  2. 配置该数据源，并在 连接详细信息 中执行以下操作，以使用已创建的私有链接：
    • 账户标识符： 输入为其创建私有链接的 Snowflake 账户的 ID。
    • 私有链接： 切换此开关以使用私有链接。
