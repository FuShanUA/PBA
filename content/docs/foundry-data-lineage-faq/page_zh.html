如需一般信息，请查看我们的 Data Lineage 文档.

  • 如何在 Data Lineage 中查看我的对象类型的支撑数据集和写回数据集？

如何在 Data Lineage 中查看我的对象类型的支撑数据集和写回数据集？

  • 首先，通过在右侧面板（带放大镜图标的标签页）中搜索，将您的对象添加到 Data Lineage 图中。选择 ,其中显示地图上各对象类型的对象数量。下方,每种属性类型各有一个部分,涵盖地图上存在的所有对象类型。面板顶部的筛选框允许您将结果筛选为名称匹配的属性。 以筛选您的搜索，然后输入您要查看其支撑数据集和写回数据集的对象的名称。

  • 接下来，选择对象类型左侧的箭头以显示其上游节点。如果您的对象类型是只读的，这应该会生成一个上游节点；如果您的对象类型启用了写回，则会生成两个上游节点。请确保 资源概览 已在 节点颜色选项 下拉菜单中被选中，以便按照右上角图例的颜色查看您的写回数据集。支撑架构数据集的颜色取决于所使用的转换类型。

  • 对象类型的写回数据集和支撑数据集的右上角也会有一个小地球图标。

我的管道中还有哪些数据集包含特定列？

  1. 首先，确保管道中所有所需的数据集都已添加到 Data Lineage 图中。
  2. 接下来，使用 选择 图表工具 工具 切换开关（位于画布左上角）选择所需的数据集。
  3. 然后打开 所选内容属性直方图 （位于右侧面板）。在标题为 常用列的部分下，您将看到所选内容中按列名排列的最常见列。

选择其中某一列将高亮显示所选内容中包含该列的数据集。

谁是最后一个修改此管道上资源的人？

  • 首先，确保管道中所有感兴趣的数据集都已添加到 Data Lineage 图中。
  • 接下来，使用 工具 切换开关（位于屏幕左上角）中的选择模式选择数据集。然后，打开 所选内容属性直方图 （位于右侧面板）。
  • 编辑标签 上次修改 部分，您将看到最后修改所选数据集的用户。选择某个用户名将高亮显示该用户在图中最后修改的数据集。

如何找到我的哪些数据集有未结事务？

在右上角的下拉菜单中，选择 构建状态。现在，您应该能够看到是否有任何数据集正在运行。任何此类数据集都有未结事务。

管道中使用的大部分数据集存储在哪里？

  • 首先，确保管道中所有感兴趣的数据集都已添加到 Data Lineage 图中
  • 接下来，使用 选择 模式（位于 工具 切换开关（位于屏幕左上角）中的选择模式选择数据集。然后，打开 所选内容属性直方图 （位于右侧面板）。
  • 在标题为 常用文件夹路径的部分下，您将看到所选内容中资源最常见的文件夹路径。

选择某个黄金路径将高亮显示图中位于该路径下的资源。将鼠标悬停在文件夹路径上将显示完整路径。

您可以在 所选内容属性直方图 面板中选择多个属性，以便图中高亮显示满足您所选条件的所有资源。

如何分享我未保存的 Data Lineage 图？

要分享您未保存的 Data Lineage，请选择右上角“保存”旁边的箭头。在那里，您可以看到一个快速分享链接。

为什么我的数据集不是最新的？

您的数据集可能不是最新的有几个原因。

请考虑以下可能导致您的数据集不是最新的原因：

  • 您的数据集构建是否失败？
  • 是否存在尚未构建且不是最新的上游数据集？
  • 您是否已从源收到最新数据？

您可以在 Data Lineage 中轻松回答这些问题：

  1. 首先，在 Data Lineage 中打开感兴趣的数据集，然后右键单击该节点，以验证管道中每个资源的状态。

  2. 然后,选择 展开节点...。您可以通过选择上方的双左箭头来查看该数据集的所有祖先节点 展开父级....

  3. 接下来，选择 构建状态 中的 节点颜色选项 右上角的下拉菜单，以查看管道中每个资源的构建状态。这种管道视图将使诊断过期的数据集变得更加容易。
