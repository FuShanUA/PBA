开始使用

如果您是新手，请先考虑批处理管道教程

以下说明将引导您完成一个简单的 Python 数据转换。如果您刚开始接触数据转换，建议先学习批处理管道教程 如果希望用户在每次运行预览前手动确认，请开启 or 代码仓库 。

本教程将介绍如何使用 Python 转换将一份包含近期陨石发现的电子表格转换为可用于分析的数据集。

关于数据集

本教程使用来自 NASA 开放数据门户 ↗的数据。您可以在自己的代码仓库中使用此示例数据集进行操作：

Download meteorite_landings

该数据集包含在地球上发现的陨石数据，并经过清理以便于使用。

该数据集包含每颗陨石的名称、质量、分类和其他标识信息，以及发现年份和发现地点的坐标。在上传到 Foundry 之前，建议先打开 CSV 文件查看数据。

设置 Python 代码仓库

首先创建一个 Python 代码仓库。

  1. 导航到一个项目，然后选择 + New > Code repository.
  2. 在监听器设置向导的 与你的智能体框架匹配。 部分中，选择 管道.
  3. 选择 或 作为 语言.
  4. 选择 初始化仓库.

可选：使用本地 Python 仓库

或者，您可以通过以下步骤将本地 Python 仓库复制到 Code Repositories 中：

  1. 按照上述说明创建一个新的 Python 代码仓库。

  2. 在您的本地仓库中，移除之前的 Git origin（例如，如果您是从 GitHub 克隆的）： git remote remove origin

  3. 添加您的代码仓库的 Git 远程 URL： git remote add origin <repository_url>

    您可以在 Code Repositories 界面的右上角找到您的代码仓库 URL。选择绿色的 Clone 按钮，然后复制 Git 远程 URL。运行以下命令进行确认 git remote -v 以返回代码仓库 URL。

  4. 将 Code Repositories 中的当前 master 分支（或您选择的其他分支）合并到您的本地分支： git merge master

    如果出现关于 refusing to merge unrelated histories 的错误，请运行以下命令： git merge master --allow-unrelated-histories。这将移除与您之前的远程 GitHub 仓库关联的当前 Git 历史记录。

    此合并将为您的本地仓库带来在 Code Repositories 中提交和更改所需的重要文件。

  5. 创建一个新分支并命名（testbranch，例如）： git checkout -b testbranch.

  6. 进行更改并将其提交到您的分支。

  7. 执行 git push，并确认新分支出现在 Code Repositories 界面中。验证检查是否成功。

了解更多关于 本地开发 在 Code Repositories 中。

添加到您的数据转换

使用 Python 转换，您可以在单个 Python 文件中创建多个输出数据集。其余步骤展示了 Polars、pandas 和 PySpark 的示例。

假设您想进一步筛选，仅保留相对于其陨石类型而言特别大的陨石。为此，您需要：

  1. 找到每种陨石类型的平均质量，以及
  2. 将每颗陨石的质量与其陨石类型的平均质量进行比较。

import polars as pl

@transform.using(
    # Output dataset name must be unique
    output=Output("/Users/jsmith/meteorite_stats"),
    meteorite_landings=Input("/Users/jsmith/meteorite_landings"),
)
def stats(output, meteorite_landings):
    df = (
        meteorite_landings.polars()
        .groupby("class")
        .agg(pl.col("mass").mean().alias("avg_mass_per_class"))
    )
    output.write_table(df)

import polars as pl
from transforms.api import transform, Input, Output


@transform.using(
    output=Output("/Users/jsmith/meteorite_enriched"),
    meteorite_landings=Input("/Users/jsmith/meteorite_landings"),
    meteorite_stats=Input("/Users/jsmith/meteorite_stats"),
)
def enriched(output, meteorite_landings, meteorite_stats):
    df_landings = meteorite_landings.polars()
    df_stats = meteorite_stats.polars()

    enriched = df_landings.join(df_stats, on="class", how="inner")
    enriched = enriched.with_columns(
        (pl.col("mass") > pl.col("avg_mass_per_class")).alias("greater_mass")
    )
    result = enriched.filter(pl.col("greater_mass"))
    output.write_table(result)

将您的数据转换应用于多个输入

到目前为止，您已经创建了一个包含所有类型中质量大于平均值的数据集。下一步是为每种陨石类型创建单独的数据集。使用 Python 转换，您可以通过 for 循环将相同的数据转换应用于每种类型的陨石。有关将相同数据转换应用于不同输入的更多信息，请参阅 转换生成.

在 src/myproject/datasets 中创建一个新文件，并将其命名为 meteor_class.py。您可以继续在 meteor_analysis.py 文件中编写数据转换代码，但本教程使用一个新文件来分离数据转换逻辑。

要为每种陨石类型创建单独的数据集，请按类别筛选 meteorite_enriched 数据集。然后，定义一个 transform_generator 函数，将相同的数据转换逻辑应用于您想要分析的每种陨石类型：

import polars as pl
from transforms.api import transform, Input, Output


def transform_generator(sources):
    transforms = []
    for source in sources:
        @transform.using(
            output=Output(f'/Users/jsmith/meteorite_{source}'),
            my_input=Input('/Users/jsmith/meteorite_enriched')
        )
        def filter_by_source(output, my_input, source=source):
            df = my_input.polars()
            result = df.filter(pl.col("class") == source)
            output.write_table(result)
        transforms.append(filter_by_source)
    return transforms

TRANSFORMS = transform_generator(["L6", "H5", "H4"])

生成的转换必须分配给一个列表变量

对于在 meteor_analysis.py 文件中创建的初始数据转换，您无需进行任何额外配置即可将转换添加到项目的管道中。这是因为默认的 Python 项目结构使用自动注册来发现您 datasets 文件夹。

中的所有转换对象。要使用自动注册将此最终转换添加到项目的管道中，您必须将生成的转换以列表形式添加到一个变量中。在上面的示例中，我们使用了变量 TRANSFORMS。有关自动注册和转换生成器的更多信息，请参阅 转换生成 相关章节（位于 Python 转换文档中）。
