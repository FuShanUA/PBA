创建敏感数据扫描

一次性敏感数据扫描和定期敏感数据扫描均通过相同的用户工作流进行配置。首先，导航到 Sensitive Data Scanner 应用程序并选择 创建新的敏感数据扫描。这将打开一个概述页面，说明创建敏感数据扫描的步骤：

  1. 选择要扫描的资源： 此部分允许您指定要扫描的数据集。参见 选择要扫描的资源 以了解更多详情。
  2. 选择匹配条件： 如果您需要查找的敏感数据类型目前在您的空间中尚无对应的匹配条件，您也可以在此部分创建匹配条件。参见 创建匹配条件 以了解更多详情。
  3. 选择匹配操作： 如果您希望 Sensitive Data Scanner 执行的操作在您的 空间中尚不存在匹配操作，您也可以在此部分创建新的匹配操作。参见 创建匹配操作.
  4. 审查并运行： 创建扫描前的最终检查。

选择要扫描的资源

资源类型

使用直方图中的 资源类型 部分以选择一个或多个 数据集, 虚拟表，或 媒体集 进行扫描。Sensitive Data Scanner 支持包含音频、文档或图像文件格式的媒体集。

包含的数据集和文件夹

您可以通过选择 添加资源 位于 包含的数据集和文件夹来明确包含要扫描的数据集或文件夹。如果您添加了文件夹，这些文件夹中的所有数据集都将被扫描，除非它们已被明确排除。您必须在此部分中至少包含一个文件夹（包括空间/项目）或数据集才能继续。

排除的数据集和文件夹

同样，您可以通过选择 添加资源 位于 排除的数据集和文件夹来明确排除要扫描的数据集或文件夹。如果您添加了文件夹，这些文件夹中的所有数据集都将被排除在扫描之外，除非它们已被明确包含。您无需明确排除任何资源（此部分可以留空）。

在极少数情况下，某个资源既被包含又被排除，此时最具体的包含或排除将优先生效。例如，某个数据集可能被包含，但它位于一个被排除的文件夹中。在这种情况下，该数据集（被包含）比其父文件夹（被排除）更具体，因此该数据集将被扫描。

扫描策略

以下扫描策略选项允许您进一步细化敏感数据扫描的行为。

选定的事务类型

Sensitive Data Scanner 允许您根据某些数据集属性指定要扫描的数据集。有两种选项：

  • 仅扫描源数据集： 允许您仅扫描常见的源数据集类型。这些数据集通常表示 Foundry 中未从其他数据集派生的新数据。 仅扫描源数据集 是推荐选项，因为它允许您通过监控 Foundry 中的“数据边界”来查找敏感数据，而无需扫描您空间中的所有数据集。
    • 通过（取消）勾选各种资源类型的复选框，您还可以更精确地缩小应/不应扫描哪些类型的数据集的范围，例如 手动输入的数据, 上传的数据集, 数据连接同步等。
    • 您还可以选择扫描 虚拟表 以查找 PII。 虚拟表 是指向 Foundry 之外源系统中表的指针；此选项使您能够扫描联邦数据以查找 PII。这些源系统必须在扫描时可访问，扫描才能成功。
  • 扫描所有数据集： 扫描所有数据集，包括派生数据集。由于扫描的数据集更多，此选项比仅扫描源数据集需要更多的计算资源来执行。

行选择策略

此外，您还可以配置要扫描的行数。

  • 直方图 扫描所有行 选项将扫描 整个 数据集。这通常是推荐选项，因为只有全面扫描才能保证扫描结果的正确性，所有包含触发所选匹配条件值的数据集都将被标记。此选项可能导致较长的扫描时间，具体取决于所配置匹配条件的复杂程度以及所扫描数据集的大小。
  • 直方图 仅扫描随机行子集 选项允许您扫描随机采样的行子集，而不是扫描整个数据集。此方法可以降低运行资源密集型匹配条件所产生的计算成本。
    • 注意： 指定的数字仅为近似值，行数少于指定行数的数据集将被完整扫描。

扫描计划

在监听器设置向导的 扫描计划 部分，您有两种选项来配置扫描的运行时间：

  • 一次性扫描： 扫描将立即在指定资源筛选器内的所有数据集上运行。稍后更新、创建或添加的数据集将不会被扫描。
  • 定期扫描： 扫描将按照所选计划定期在指定资源筛选器内的所有资源上运行：
    • 每日： 每天 00:00 UTC
    • 每周： 每周二 00:00 UTC
    • 每月： 每月第 1 天 00:00 UTC
    • 持续： 每当指定资源筛选器内的给定数据集添加新数据时，即扫描该数据集。

对于定期扫描，您可以选择 对所有匹配的数据集执行初始扫描 以立即扫描所有当前数据集。这可确保即使数据集稍后未更新，也会被扫描。

包含和排除的标记

与显式包含和排除数据集及文件夹类似，您可以根据数据集上的标记来包含和排除数据集。这是一项高级功能，通常用于排除已受保护的数据集。例如，在下面的截图中，我们可以看到带有 PII（个人身份信息）标记的数据集将不会被扫描，因为此 PII 标记可能是在先前敏感数据扫描中出现匹配后应用的。

选择匹配条件

创建敏感数据扫描的第一步是选择您要查找的特定匹配条件，然后是敏感数据扫描器在发现匹配时应执行的特定匹配操作。

在选择匹配条件时，请考虑您要查找哪些敏感数据，以及您的空间中已有哪些可用的匹配条件。如果所需类型的敏感数据没有对应的匹配条件，您可以 创建新的匹配条件。对于使用语言模型匹配条件的扫描， LLM 使用量将归属于 每个被扫描的资源。

选择匹配操作

在选择匹配操作时，请考虑检测到敏感数据后的适当响应。您可以在三种类型的操作之间进行选择：

  • 创建问题：通知指定的用户组发现了敏感数据。
  • 应用标记：对包含敏感数据的数据集设置访问控制。
  • 混淆数据：使用以下方式对匹配的数据进行加密或哈希处理 密码.

您也可以选择完全不应用任何匹配操作。

如果您的空间中不存在适当的匹配操作，您可以创建一个。参见 创建匹配操作 以了解更多详情。

测试您的匹配条件

如果您的敏感数据扫描涉及大量数据集，建议在继续之前先测试匹配条件。配置错误的匹配条件可能会产生误报，导致不必要的问题、数据集上的标记或数据混淆。要测试匹配条件，请选择 无匹配操作 用于您的扫描。扫描完成后，如果您已验证匹配条件与预期的数据格式一致，您可以在扫描的概览页面上应用其他匹配操作。

审查 应用其他匹配操作 以了解更多详情。

应用其他匹配操作

对于过去七天内创建的非活动扫描，您可以选择其他匹配操作，以应用于扫描发现的敏感数据。

要应用 应用标记 匹配操作，您必须拥有 所需的标记权限.

定期扫描

对于定期扫描，其他匹配操作仅适用于在选择其他匹配操作之前识别到的匹配项。如果扫描稍后被重新激活，定期扫描检测到的任何未来敏感数据将不会自动应用之前选择的其他匹配操作。

在扫描概览页面底部查看其他匹配操作的应用状态。

撤销匹配操作

对于过去七天内创建的非活动扫描，您可以撤销之前应用于扫描发现的敏感数据的匹配操作。对于 创建 issue 匹配操作，这将导致删除由该操作创建的 issue。对于 应用标记 匹配操作，这将涉及移除由该操作应用的标记。

要撤销 应用标记 匹配操作，您必须拥有 所需的标记权限.

混淆数据 操作无法撤销。

定期扫描

对于定期扫描，仅会撤销执行匹配操作撤销之前该操作产生的结果。如果扫描稍后被重新激活，即使匹配操作已被撤销，定期扫描发现的任何未来敏感数据仍将应用该匹配操作（如果该操作在初始扫描设置中已配置）。要阻止定期扫描在再次激活后继续执行某些匹配操作，请在重新激活扫描之前编辑定期扫描以移除该匹配操作。

在扫描概览页面底部查看匹配操作撤销的状态。
