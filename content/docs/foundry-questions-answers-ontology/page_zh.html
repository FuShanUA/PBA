如何编辑 OSv2 对象类型的物化受限视图 (RV) 上的细粒度策略？

要编辑 OSv2 对象类型的物化受限视图 (RV) 上的细粒度策略，您必须编辑支撑该对象类型的 RV 上的策略，随后这些策略将传播到物化的 RV。

时间戳： 2024年4月10日

是否可以通过在属性中填充 RID 数组来将多个非结构化文件附加到对象上？

不可以，无法以这种方式附加文件。您需要通过操作显式地建立附件的父子关系。

时间戳： 2024年4月16日

在 MDO 对象中的两个受限视图之间移动列，会更改属性的 API 名称和 RID 吗？

在受限视图之间移动列时，标识符将保持不变，因此属性 API 名称和属性 rid 不会改变。

时间戳： 2024年4月16日

在选择了“应用最新值”策略作为编辑冲突解决方法的场景中，如果用户编辑了一个之前为 null的字段，并且管道已运行，但该字段仍为 null 在管道中，该属性将显示什么？

当管道运行时，如果 时间戳 属性更新为比编辑更晚的时间戳，则该属性将恢复为 null。如果时间戳属性保持不变（或为 null），则用户的编辑将胜出。

时间戳： 2024年6月13日

如何将 true 或 false 映射为操作表单中的“是”或“否”，而无需将该属性转换为字符串？

这可以通过布尔属性配置中的 约束 部分来实现：选择 多项选择 和 手动定义选项，然后设置不同的显示值，分别对应 true 和 false。

时间戳： 2024年6月26日

如果通过操作创建了一个新对象，且该对象由受限视图（Restricted View）支撑，那么它会对所有人可见吗？在某一列中指定值是否会根据该列限制访问权限？

是的，该对象的可见性由受限视图策略决定。如果创建对象时未在受限视图策略所使用的列中指定任何值，则其可见性将取决于这些策略，这可能导致该对象对所有人隐藏。

时间戳： 2024年6月25日

更改物化（materialization）的列名会对本体论编辑产生什么影响？

更改物化只会影响物化本身以及任何下游内容。这不会影响存储在 Object Storage v2 中的编辑信息。

时间戳： 2024年3月7日

什么是 geohash 属性？

Geohash 属性是一种遗留类型，曾在本体论中用于表示地理空间数据。它们已被重命名为 geopoint 以提高清晰度，且没有任何功能变化。

时间戳： 2025年5月13日
