搜索对象

使用 Object Explorer 主页 上的全局搜索栏进行搜索的结果将显示在搜索结果页面上：

您的查询在搜索栏中可见且可编辑（如下方A所示）。

该页面分为多个标签页 （B）：

  • 默认情况下会显示 “全部” 标签页，其中包含所有结果。
  • 匹配的结果可以筛选到不同的标签页中：
    • “对象” （C）、
    • “对象类型” （D）和
    • “工件” （E）。

此搜索结果页面还包含一个 侧边栏 （如下方F 所示）。

使用侧边栏进行导航

这些结果均按其类型分类。左侧的导航菜单（如上图中 F 所示）可以帮助您浏览不同的类别。

选择任一分区的标题也会将结果筛选为该类型。如果该类型的结果数量超过 “所有结果” 视图中所显示的默认数量（如下图中 1 所示），则还会显示该类型的所有结果。

  • 第一项，即 “所有结果” （如下图中 1 位于上方图片中），会显示每个类别的匹配项示例。进入页面时，此功能默认处于启用状态。
  • 接下来是 “对象类型筛选器”(2)。点击其中任意一个，将显示该特定对象类型的更多匹配项。点击 “查看其他 X 个筛选器 >” （位于该区域底部），会将标签页从“全部”切换为“对象”，您可以在其中浏览对象结果和筛选器的完整列表。
  • “对象类型组”(3) 会按关联的组筛选结果。点击 “查看全部筛选器 >” （位于该区域底部），以将标签页从“全部”切换为“对象类型”，您可以在其中浏览对象类型结果的完整列表。
  • 最后是 “制品”(4)中的匹配项，分为"探索与列表"、"比较视图"和"模块"。点击 “查看全部筛选器 >” （位于该区域底部），以将标签页从“全部”切换为“制品”，您可以在其中浏览完整的结果列表。

结果类型

Object Explorer 搜索栏会搜索平台中的所有对象（(C) 位于顶部图片中），以及与对象相关的资源，例如对象类型 (D)、已保存的探索、列表、比较和模块 (E)。

对结果进行排序

在单个对象结果部分中，结果的排序方式如下：

  • 所有显著对象类型都会显示在非显著对象类型之前。
  • 在显著结果和非显著结果中，对象类型按该类型的单个对象结果数量（升序）排序。换言之，结果数量最少的显著对象类型会最先显示，然后是结果数量较多的显著对象类型，接着是（与其他非显著类型相比）结果数量最少的非显著对象类型，依此类推。

隐藏的对象类型或属性类型不会在此处或 Object Explorer 中的其他任何位置显示为搜索结果。

探索与特定结果关联的对象

对于单个对象的匹配项（2 如上图所示），将鼠标悬停在该结果上时，系统会提供相应选项，让你能够通过特定关联开始探索与该单个结果相连的对象。

示例：如果你搜索机场“SFO”，可以将鼠标悬停在该结果上，并开始探索抵达该机场的航班。
