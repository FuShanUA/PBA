使用侧边栏进行导航

这些结果均按其类型进行分类。左侧的导航菜单（如 F 上图所示）可以帮助您浏览不同的类别。

选择任何部分的标题也会将您筛选到该类型的结果。如果该类型的结果数量超过在 所有结果 视图中默认显示的数量（由 1 下图中的标识所示），这还将向您显示该类型的所有结果。

  • 第一项， 所有结果 （如 1 上图所示）会显示每个类别的匹配示例。这是进入页面时的默认状态。
  • 接下来是 “对象类型筛选器”(2)。点击其中任何一个都会显示该特定对象类型的更多匹配结果。点击 “查看其他 X 个筛选器 >” （位于该部分底部）会将标签页从“全部”切换到“对象”，您可以在其中浏览完整的对象结果和筛选器列表。
  • “对象类型组”(3) 按关联的组筛选结果。点击 “查看所有筛选器 >” （位于该部分底部）会将标签页从“全部”切换到“对象类型”，您可以在其中浏览完整的对象类型结果列表。

结果的类型

Object Explorer 搜索栏可搜索平台中的所有对象（(C) 见顶部图片），以及与对象相关的资源，例如对象类型 (D)、已保存的探索、列表、比较和模块 (E).

隐藏的对象和属性类型永远不会显示为搜索结果，也不会在 Object Explorer 的其他任何地方显示。

对结果进行排序

在单个对象结果部分中，结果的排序方式如下：

  • 所有显著对象类型显示在非显著对象类型之前。
  • 在显著和非显著结果中，对象类型按该类型的单个对象结果数量升序排序。换言之，结果数量最少的显著对象类型将首先显示，然后是结果数量较多的显著对象类型，接着是结果数量最少的非显著对象类型（与其他非显著类型相比），依此类推。

浏览与特定结果关联的对象

对于单个对象的匹配项（2 如上图所示），将鼠标悬停在结果上，您可以选择通过特定关联开始对该单个结果的关联对象进行探索。

示例：如果您搜索机场“SFO”，可以将鼠标悬停在结果上，并开始探索抵达该机场的航班。
