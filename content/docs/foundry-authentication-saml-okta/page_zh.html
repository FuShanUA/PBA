为 Okta 配置 SAML 2.0 集成

本节包含特定于 Okta 的步骤，用于配置 SAML 2.0 集成；这些步骤属于更广泛的 端到端 SAML 2.0 身份验证教程。

如果您收到了用于配置初始 SAML 集成的 Foundry 设置链接，请跳至下一步。否则，您可以添加新的 SAML 提供程序：

  1. 前往控制面板中的 身份验证 选项卡。
  2. 选择 添加提供程序，输入名称（例如 My Okta SAML），然后选择 创建。
  3. 在 SAML 部分中，配置 SAML 集成元数据和其他值。

在 Okta 中，要创建 SAML 应用集成，请按照 这些说明 ↗。

SAML 集成元数据

从 Foundry 控制面板（如左侧所示）复制以下值，以便在 Okta 的 编辑 SAML 集成 页面（如右侧所示）中使用：

FoundryOkta
断言使用者服务 (ACS) URL单点登录 URL
实体 ID受众 URI（SP 实体 ID）

属性映射

Okta 并未定义无需进一步配置即可使用的标准 SAML 属性（超出 NameID）。属性需要先在 Okta 中定义，然后才能在 Foundry 中进行映射。

在 Okta 中，作出以下属性声明：

名称名称格式值
firstNameBasicuser.firstName
lastNameBasicuser.lastName
emailBasicuser.email

您可以在 属性映射中为用户属性定义以下映射。如果使用 Foundry 设置链接，Okta 属性映射将被预先填充。

  • ID： NameID
  • 用户名： NameID （或者， email）
  • 电子邮箱： email
  • 名字： firstName
  • 姓氏： lastName

您还可以定义属性映射，将您现有的 Okta 组镜像到 Foundry 中。在 Okta 中定义一个或多个组属性语句，并在 组属性映射中进行映射。

身份提供方元数据

在 Okta 中，完成 SAML 应用集成的创建，然后导航至 登录 选项卡，在 身份提供方元数据下方以 XML 文件的形式获取身份提供方的元数据。请将此文件上传到 Foundry 中的 身份提供方元数据 部分。

完成并保存

在 Foundry 中，在 电子邮件域名下方添加与此 SAML 2.0 集成关联的电子邮件域名。

最后，保存您的 SAML 2.0 集成，然后 继续进行多因素身份验证。
