必填属性

必填属性是必须有值的对象类型属性。您可以使用此对象类型属性来验证不存在该属性值为 null 的对象；如果该属性是数组属性，则验证不存在空数组。此验证适用于来自支撑数据源的数据以及通过操作进行的编辑。

必填属性概要

在使用必填属性时，请记住以下几点：

  • 在将数据索引到对象中时会进行验证： 对 null 值的检查是在将支撑数据源索引到 Object Storage 时进行的。这意味着，如果支撑必填属性的列包含 null 值，本体论修改本身仍会成功。
  • 数组属性不能为空： 将数组属性设置为必填可确保其中至少存在一个元素。
  • 通过操作进行的更改会在应用时进行验证： 如果您尝试通过操作向属性写入 null 值或空值，该操作将无法执行。
  • 仅在 Object Storage v2 中可用： 只有使用 Object Storage v2 的对象类型才支持必填属性。

创建必填属性

  1. 导航至 本体论管理器。
  2. 选择对象类型，然后选择要设置为必填的属性。
  3. 选择 创建属性 ，并填写必要的详细信息，包括属性名称、类型和描述。
  4. 在 配置 部分中，开启 必填 开关。
  5. 保存 对本体论所做的更改，并等待重新索引完成。

请注意，如果该属性的支撑列上当前存在任何 null 值，重新索引将会失败。要解决此问题，您必须更新支撑数据源以使该列不再包含 null 值，或者取消该属性的必填设置。

允许空数组的必填属性

您可以将必填属性配置为允许空数组。这意味着该属性仍会拒绝 null 值，但会接受空数组。这对于绝不能为 null、但可以配置为允许空数组的强制控制属性非常有用。详细了解 强制控制属性。

需要注意的是，对于映射到某个参数的属性，如果该参数未被设置，操作将向该属性写入一个空数组。这意味着，如果您有一个允许空数组的必填属性，而您在操作中将该参数留空，则操作将成功执行并向该属性写入一个空数组。如果您不希望出现这种行为，并希望强制用户始终通过操作为该属性设置值，则不应在必填属性上允许空数组。

具有多个支撑数据源的对象类型的必填属性

您有时可能会遇到由多个数据源支撑的对象类型的必填属性中出现空值的情况。当对象的记录存在于某些数据源中，但在提供该必填属性的数据源中缺失时，就会出现这种现象。
