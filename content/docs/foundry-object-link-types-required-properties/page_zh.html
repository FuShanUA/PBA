必填属性

必填属性是必须具有值的对象类型属性。您可以使用此对象类型属性来验证没有对象在此属性上具有空值，或者如果它是数组属性，则没有空数组。此验证适用于来自支撑数据源的数据以及通过操作进行的编辑。

必填属性摘要

使用必填属性时，请记住以下几点：

  • 验证在数据被索引到对象时进行： 空值检查在支撑数据源被索引到对象存储时进行。这意味着，如果支撑必填属性的列包含空值，本体论修改本身仍会成功。
  • 数组属性不能为空： 将数组属性设置为必填可确保至少存在一个项目。
  • 通过操作进行的更改在应用时进行验证： 如果您尝试通过操作向属性写入空值或空数组，该操作将无法执行。
  • 仅在对象存储 v2 中可用： 必填属性仅由使用对象存储 v2 的对象类型支持。

创建必填属性

  1. 导航至 本体论管理器.
  2. 选择对象类型，然后选择要设置为必填的属性。
  3. 选择 创建属性 并填写所需的详细信息，包括属性名称、类型和描述。
  4. 编辑标签 配置 部分，打开 必需 toggle.
  5. 保存 您对本体论的更改，并等待重新索引完成。

如果属性的支撑列上当前存在任何空值，重新索引将失败。要解决此问题，您必须更新支撑数据源以使该列不再包含空值，或者取消该属性的必填设置。

允许空数组的必填属性

您可以将必填属性配置为允许空数组。这意味着该属性仍将拒绝空值，但将接受空数组。这对于永远不能为空但可配置为允许空数组的强制控制属性非常有用。了解更多关于 强制控制属性.

操作将向任何映射到参数但未设置该参数的属性写入空数组。这意味着，如果您有一个允许空数组的必填属性，而您在操作中将参数留空，操作将成功执行并向该属性写入空数组。如果您不希望出现此行为，并希望强制用户始终通过操作为此属性设置值，则不应在必填属性上允许空数组。

具有多个支撑数据源的对象类型的必填属性

您有时可能会遇到由多个数据源支撑的对象类型的必填属性中出现空值的情况。当对象的记录存在于某些数据源中，但在提供必填属性的数据源中缺失时，就会出现这种现象。
