关联对象视图

此小部件主要用于显示 表格 视图，展示某一类型的所有关联对象及其相关属性。该表格还支持选择关联对象的子集，以便在其他 Foundry 应用中打开或执行已配置的对象操作。 除表格视图外，还提供简单的列表视图和卡片视图。

配置

设置选项卡

配置包含 3 个部分：

  • 同步至数据集
    • 要显示的关联对象：选择您希望显示的关联对象。小部件配置提供在 本体论配置中定义为与当前对象关联的对象。可通过直接关联或使用中间对象类型的传递关联来选择对象类型。
    • 要显示的属性:
      • 所有属性 - 显示所有定义为“突出”或“普通”的属性，但不包括“隐藏”属性。允许使用 Properties to Exclude 选择器(见下文)排除特定的一组属性。
      • 突出属性 - 仅显示在本体论管理器中定义为“突出”的属性。允许使用 properties to exclude 选择器(见下文)排除特定的一组属性。
      • 特定属性 - 打开一个包含该关联对象所有属性的多选下拉菜单，供选择。
      • 无属性 - 不显示任何属性。
    • 要排除的属性：选择您希望从显示中排除的属性。适用于 所有属性 and 突出属性 options.
  • 视图选项 - 选择默认向最终用户显示的视图类型。最终用户仍可在界面中（小部件标题栏上）切换到其他 2 种视图。
    • 表格视图 - 最常用的视图，显示包含所有值的表格，并提供快速筛选搜索。
    • 卡片视图 - 每个关联对象的紧凑卡片视图，显示属性（如在 1b 中所选）。此选项不具备表格视图的完整功能。例如，它不支持选择或对象操作。
      • 注意：对于卡片显示选项，有一个名为“卡片宽度”的辅助配置，用于确定这些卡片的视觉密度。它对表格或列表视图选项没有影响。
    • 列表视图 - 所选关联对象的所有实例的简单列表视图，不支持任何选择选项，也不显示任何关联属性。
  • 搜索与筛选 - 为表格视图添加搜索和筛选功能
    • 结果限制 - 限制显示的最大结果数量。您希望显示的结果越多，视图加载所需的时间就越长。此项与最小/最大高度配置（请参阅下方“格式”选项卡）共同决定此小部件在整个视图中所占的空间。
    • 启用搜索与筛选 - 开启后，小部件将具备搜索和筛选功能。包括基本或高级搜索功能：
      • 基本 - 在小部件标题栏上提供一个用于自由文本搜索的简单搜索栏。
      • 高级 - 拥有完整的筛选器侧边栏，提供详细的筛选选项，包括一个开关，用于为最终用户默认展开或折叠侧边栏。与基本的自由文本搜索不同，此搜索允许基于属性类型进行更复杂的筛选（字符串支持自由文本和多选，时间戳支持日期范围，double/integer 支持数值）。此搜索栏基于旧版对象资源管理器的功能和 UI。

格式选项卡：

在组件配置中的格式选项卡下，除了标题、图标、信息和布局的默认设置外，您还可以控制该部分的最小和最大高度（可选）。

常见问题与注意事项：

  • 此组件 受其他组件的筛选器影响 （如果开关已打开）- 但 不会发布筛选器 给与其共享交叉筛选的其他组件，即使筛选器侧边栏已打开。实际上，内部筛选器仅限于对象表格组件的上下文中。
  • 条件格式和值渲染器 - 表格中的值可以使用条件格式和值渲染器进行渲染。

时间轴

创建按日期和时间排序、自上而下显示的按时间顺序排列的事件列表。此时间线由必须至少具有一个时间戳的关联对象构建，通常是事件，即具有定义某个持续时间的开始和结束时间戳的对象。 此组件可以包含一种或多种直接关联到当前对象的类型，或通过关联对象关联的类型。它还可以通过不同的日期属性显示同一事件，如下例所示。

对于图形时间线，请使用 分组事件时间线和表格 小部件。

配置

设置选项卡

  • 添加一个或多个关联对象（事件） - 首先，通过点击“添加事件类型”，添加至少一种您希望在时间线上显示的关联对象类型。您可以添加多种类型的关联对象：
    • 在时间线上显示完全不同事件的不同对象类型。示例：与飞机关联的对象既是航班事件，也是飞机维护事件。
    • 显示同一关联对象类型的事件，但通过不同的日期属性或不同定义的关联类型。示例：
      • 关联到机场对象的航班事件通过不同的日期属性显示在同一时间线上：(1) “计划到达时间”，(2) “实际到达时间”，(3) “预计出发时间”。时间线将显示所有航班的按时间顺序排列的列表，在这种情况下每个航班最多会出现 3 次。
      • 一个机场对象可以同时具有到达航班和出发航班，它们都关联到该机场并显示在同一时间线上。
  • 选择您希望添加的事件对象类型 - 对于您希望添加的每个事件对象，请配置该对象类型的详细信息：
    • 选择关联对象类型 - 可以是直接关联对象或扩展关联。
      • 直接关联对象的示例：当前对象是一个机场，您希望显示到达航班和出发航班的时间线。
      • 扩展对象（二度）的示例：当前对象是一个机场，您希望显示一个时间线，其中包含关联到该机场的到达航班所关联的所有飞机对象。
  • 定义用于在时间线上对事件进行排序的日期属性 - 选择您希望用于在时间线上对事件进行排序的关联对象属性。该属性必须是时间戳/日期，因此配置中只会建议此类属性。
  • 选择要从关联对象中显示的属性.
    • 选择您希望显示的属性：
      • 所有属性 - 如果关联对象具有许多属性，则不建议使用，因为时间线会变得拥挤且难以浏览。
      • 重要属性 - 仅显示在 Ontology Manager 中被定义为 Prominent 的属性。
      • 特定属性 - 打开一个包含该关联对象所有属性的多选下拉菜单，供选择。
      • 无属性 - 时间线上仅显示关联对象的标题。
    • 选择您希望排除的属性 - 仅适用于前两个选项（所有属性和重要属性）。
  • 选择要显示的标题 ，用于时间线上的每个事件。共有三个选项：
    • 对象名称 作为标题（例如事件名称）- 这是最常用的选项，也是默认选项。
    • 日期属性名称 作为标题 - 如果您希望使用多个属性显示来自关联对象的事件（例如“计划到达时间”、“实际到达时间”、“预计出发时间”等），此选项非常有用。提醒：在这种情况下，每个基于不同属性的关联都应在 Timeline 组件中单独配置 - 请参见上文第 1 点）。
    • 自定义名称 - 为该类型的所有关联对象添加自由文本描述的选项。例如，如果您在同一时间线下同时关联到达航班和出发航班，您可能希望将所有到达航班的标题描述为“到达”，将所有出发航班的标题描述为“出发”。

格式选项卡

在组件配置中的格式选项卡下，除了标题、图标、信息和布局的默认设置外，您还可以控制该部分的最小和最大高度（可选）。

常见问题与注意事项

  • 此组件支持搜索和排序（最早优先、最新优先）。但是，它不支持筛选，因此不受筛选器影响。如需筛选功能，请考虑使用 分组事件时间线和表格 widget.
  • 如果您希望在图形时间线上显示事件（而不仅仅是按时间顺序排列的列表），请考虑使用 分组事件时间线和表格 widget.
  • 如果您希望显示甘特图样式的时间线，可以使用“关联对象甘特图”组件。如果该组件不可用，请联系您的 Palantir 代表了解更多详情。它适用于显示数量较少、具有明确开始和结束日期的事件，例如项目时间线。
  • 关于时间序列可视化，请联系您的 Palantir 团队以了解有关 Quiver 的更多详情，Quiver 可以嵌入到对象视图中。您也可以使用 Charts 组件（或嵌入来自 Contour 或 Quiver 的图表），并在 X 轴上使用日期/时间属性。
  • 缺少日期的事件不会显示在事件列表中。系统会显示一条消息，提醒用户存在缺失的事件。
  • 出于性能原因，默认仅显示 50 个关联对象。当用户向下滚动列表时，将每次显示 100 个其他对象。

设置

  • 添加一个或多个关联对象（事件） - 首先，点击“添加项目”，添加至少一种您希望在时间线上显示的关联对象类型。您可以添加多种类型的关联对象：

    • 显示同一关联对象类型的事件，但通过不同的日期属性或不同定义的关联类型。示例：
      • 与 Airport 对象关联的航班事件通过不同的日期属性显示在同一时间线上：(1) “计划到达时间”，(2) “实际到达时间”，(3) “预计出发时间”。在这种情况下，每个航班最多会出现 3 次。
      • 一个机场对象可以同时具有到达航班和出发航班，它们都关联到该机场并显示在同一时间线上。
  • 选择您希望添加的事件对象类型 - 对于您希望添加的每个事件对象，请配置该对象类型的详细信息：
    • 选择关联对象 - 可以是直接关联对象或扩展关联。
      • 直接关联对象的示例：当前对象是一个机场，您希望显示到达航班和出发航班的时间线。
      • 扩展对象（第二级）示例：当前对象是一个 Airport，而您希望显示所有与该 Airport 关联的到达航班所关联的 Aircraft 对象的时间线。
  • 配置视觉格式选项
    • 最大事件数 - 此选项目前不可用。
    • 颜色 - 为此项配置下的所有事件选择颜色。使用 Blueprint 标准颜色 ↗ 或基本颜色名称 - “蓝色”、“红色”、“黄色”等。
    • 系列名称 - 此时间线下所有事件的描述，将显示在图形时间线的图例上。
  • 定义用于在时间线上对事件进行排序的日期属性 - 选择您希望使用关联对象的哪个属性来在时间线上显示事件。该属性必须是时间戳/日期，因此配置中只会建议此类属性。
  • 事件分组依据 - 选择如何在图形时间线上对事件进行分组。每个组将在图形时间线中显示为单独的水平事件线，并上下堆叠。有两种选项：
    • 常量 - 当前项将分组在单个时间线上，标题定义为自由文本值。在这种情况下，如果您希望将其他时间线添加为单独的行，则必须定义其他项。
    • 属性 - 将事件拆分为多个单独的时间线，每个时间线上的事件根据该属性的不同值进行分组。
      • 示例：显示 Airport 对象的所有到达航班的时间线时，可以选择“航空公司名称”属性，为每家航空公司设置单独的时间线，该航空公司的所有航班都显示在其专属时间线上。下方的列表将包含来自所有航空公司的所有航班事件的按时间顺序排列的列表。
  • 列表中显示的属性 - 选择您希望在 widget 的第二部分（即列表）中显示的属性：
    • 选择您希望显示的属性：
      • 所有属性 - 如果关联对象具有许多属性，则不建议使用，因为时间线会变得拥挤且难以浏览。
      • 重要属性 - 仅显示在 Ontology Manager 中被定义为 Prominent 的属性。
      • 特定属性 - 打开一个包含该关联对象所有属性的多选下拉菜单。选择要显示的特定属性。
      • 无属性 - 时间线上仅显示关联对象的标题。
    • 属性筛选器 - 一个可选开关，用于添加基于单个属性的筛选器，以仅包含特定值。这些值必须以区分大小写的自由文本字符串形式显式输入。
  • 图形时间线的其他配置（这些配置仅适用于时间线组件，对表格组件无效）
    • 默认显示的分组 - 应在时间线中显示多少条时间线，或具体显示哪些时间线作为单独的行。在这两种情况下，用户都会看到一个包含所有其他分组的多选辅助工具。
      • 最大数量 - 在图形时间线中显示的不同分组和不同时间线的最大数量，以数字（值）表示。
      • text:
    • 分组排序依据 - 时间线可以有多条水平线，这允许您通过以下 3 种方式之一对这些线进行排序：
      • 配置顺序 - 您配置不同项的顺序
      • 名称 - 所有分组的字母顺序，从顶部的 A 到底部的 Z
      • 最近事件 - 最近事件所在的分组位于顶部

格式

在 Format 选项卡下，除了 Title、Icon、Info 和 Layout 的默认设置外，您还可以控制该部分的最小和最大高度。这两项设置均为可选项。

常见问题与说明

  • 最终用户可以使用自由文本筛选器或日期范围来筛选时间轴，但这些筛选器不会被发布，且不会 不 影响其他组件。
