可视化

可视化小组件 以图表、透视表、时间轴、地图和其他可视化（包括简单文本和指标）形式显示与当前对象相关的数据。 在其他 Foundry 应用中创建的可视化同样可以嵌入 - 请参阅 应用和文件 类别，了解有关嵌入 Slate 应用、Contour 看板、Foundry 报告、Fusion 电子表格以及 Quiver 时间序列或图表的更多信息。

关联对象视图

此小组件主要用于显示 表格 视图，其中显示某种类型的所有关联对象及其相关属性。表格还支持选择关联对象的子集，以便在其他 Foundry 应用中打开或执行已配置的对象操作。 除表格视图外，还提供简单的列表视图和卡片视图。

配置

设置选项卡

配置包含 3 个部分：

  • 数据
    • 要显示的关联对象：选择您希望显示的关联对象。小组件配置会提供与当前对象链接的对象，其定义见 本体论配置。请通过直接关联，或通过使用中间对象类型的传递关联来选择对象类型。
    • 要显示的属性：
      • 所有属性 - 显示所有定义为突出或常规的属性，但不显示任何隐藏属性。允许使用 Properties to Exclude 选择器排除特定的一组属性（见下文）。
      • 突出属性 - 仅显示在本体论管理器中定义为突出的属性。允许使用 properties to exclude 选择器排除特定的一组属性（见下文）。
      • 特定属性 - 打开一个多选下拉列表，其中包含该关联对象的所有属性，以供选择。
      • 无属性 - 不显示任何属性。
    • 要排除的属性：选择您希望从显示中排除的属性。适用于 所有属性 和 突出属性 选项。
  • 视图选项 - 选择默认向最终用户显示哪种视图类型。最终用户仍可在 UI 中（在小组件标题栏上）切换到其他两种视图。
    • 表格视图 - 最常用的视图，以表格形式显示所有值，并支持快速筛选搜索。
    • 卡片视图 - 每个关联对象的精简卡片视图，其中显示属性（如 1b 中所选）。此选项不具备表格视图的全部功能。例如，它不支持选择或对象操作。
      • 注意：对于卡片显示选项，还有一个名为“卡片宽度”的次级配置，用于决定这些卡片的视觉密度。它对表格或列表视图选项没有影响。
    • 列表视图 - 所选关联对象所有实例的简单列表视图，不提供任何选择选项，也不显示任何关联属性。
  • 搜索和筛选 - 为表格视图添加搜索和筛选功能
    • 结果限制 - 限制要显示的最大结果数量。您希望显示的结果越多，视图加载所需的时间就越长。此设置与最小/最大高度配置（参见下方“格式”选项卡）共同决定此小部件在整体视图中所占的空间大小。
    • 启用搜索和筛选 - 开启此开关可在小部件上使用搜索和筛选功能。其中包括基本或高级搜索功能：
      • 基础 - 在小部件标题栏处提供一个用于自由文本搜索的简单搜索栏。
      • 高级 - 提供一个包含详细筛选选项的完整筛选器侧边栏,其中包括一个开关,用于控制该侧边栏对最终用户默认是展开还是折叠。与基础自由文本搜索不同,此搜索支持基于属性类型的更复杂筛选(字符串类型支持自由文本和多选,时间戳类型支持日期范围,double/integer 类型支持数值筛选)。此搜索栏基于旧版对象资源管理器(Object Explorer)的功能和 UI。

格式选项卡:

在小部件配置的格式选项卡下,除了默认的标题、图标、信息和布局之外,您还可以控制该部分的最小高度和最大高度(可选)。

常见问题与注意事项:

  • 此小部件 会受筛选器的影响 ,这些筛选器来自其他小部件——如果该开关已开启——但 不会将筛选器发布 至与之共享交叉筛选功能的其他小部件,即使筛选器侧边栏处于打开状态也是如此。实际上,内部筛选器仅限于该对象表格小部件的上下文中。
  • 条件格式和值渲染器 - 表格中的值可通过条件格式和值渲染器进行渲染。

时间轴

创建按日期和时间排序、自上而下显示的事件时间顺序列表。此时间线由关联对象构成，这些关联对象必须至少具有一个时间戳，且通常为事件，即具有开始和结束时间戳、用于定义一定持续时间的对象。 此小部件可包含一种或多种类型的对象，这些对象直接与当前对象关联，或通过某个关联对象进行关联。它还可以按不同的日期属性显示同一事件，如下面的示例所示。

对于图形时间线，请使用 分组事件时间线和表格 小部件。

配置

设置选项卡

  • 添加一个或多个关联对象（事件） - 首先，点击“添加事件类型”，添加至少一种您希望在时间线上显示的关联对象类型。您可以添加多种类型的关联对象：
    • 在时间线上显示完全不同的对象类型，这些对象是完全不同的事件。示例：与某架飞机关联的关联对象既包含航班（Flights）事件，也包含飞机维护（Aircraft Maintenance）事件。
    • 显示属于同一关联对象类型的事件，但按不同的日期属性显示，或使用不同定义的关联类型。示例：
      • 与机场对象关联的航班事件根据不同的日期属性显示在同一条时间线上：(1)“计划到达时间”、(2)“实际到达时间”、(3)“预计起飞时间”。时间线将按时间顺序显示所有航班的列表，在本例中，每个航班最多会出现 3 次。
      • 一个机场对象可以将关联到它的到达航班和出发航班同时显示在同一条时间线上。
  • 选择您想要添加的事件对象类型 - 对于您想要添加的每个事件对象，请配置该对象类型的详细信息：
    • 选择一种关联对象类型——直接关联对象或扩展关联。
      • 直接关联对象的示例：当前对象是一个机场，您想要显示到达航班和出发航班的时间线。
      • 扩展对象（二度）的示例：当前对象是一个机场，您想要显示一条时间线，其中包含与关联到该机场的到达航班相关联的所有飞机对象。
  • 定义用于对时间线上的事件进行排序的日期属性 - 选择您希望用来对时间线上的事件进行排序的关联对象属性。该属性必须是时间戳/日期，因此配置中只会建议此类属性。
  • 选择要显示关联对象中的哪些属性。
    • 选择您希望显示哪些属性：
      • 所有属性 - 如果关联对象有很多属性，则不建议选择此项，因为时间线会变得拥挤且难以浏览。
      • 重要属性 - 仅限在本体论管理器中定义为“重要”（Prominent）的属性。
      • 特定属性 - 打开一个多选下拉菜单，其中列出该关联对象的所有属性，供您从中选择。
      • 无属性 - 仅在时间线上显示关联对象的标题。
    • 选择您希望排除的属性 - 仅适用于前两个选项，即“所有属性”和“重要属性”。
  • 选择要显示哪个标题 用于时间线上的每个事件。共有三个选项：
    • 对象名称 作为标题（例如事件名称）- 这是最常用的选项，也是默认选项。
    • 日期属性名称 作为标题 - 如果您希望使用多个属性来显示来自关联对象的事件（例如“计划到达时间”、“实际到达时间”、“预计出发时间”等），这将非常有用。提醒：在这种情况下，基于不同属性的每个关联都应在时间线小组件中单独配置 - 请参见上文第 1 点）。
    • 自定义名称 - 为该类型的所有关联对象添加自由文本描述的选项。例如，如果您将到达航班和出发航班都关联到同一时间线下，您可能希望使用标题“到达”描述所有到达航班，使用“出发”描述所有出发航班。

格式选项卡

在小组件配置的格式选项卡下，除了标题、图标、信息和布局的默认设置外，您还可以控制该部分的最小和最大高度（可选）。

常见问题和注意事项

  • 此小组件支持搜索和排序（最旧优先、最新优先）。但是，它不支持筛选，因此不受筛选器的影响。如需筛选功能，请考虑使用 分组事件时间线和表格 小组件。
  • 如果您希望在图形时间线上显示事件（而不仅仅是以按时间顺序排列的列表形式），请考虑使用 分组事件时间线和表格 小部件。
  • 如果您希望显示甘特图样式的时间线，可以使用“关联对象甘特图”小部件。如果该小部件不可用，请联系您的 Palantir 代表以了解更多详情。这适用于显示数量较少且具有明确开始和结束日期的事件，例如项目时间线。
  • 对于时间序列可视化，请联系您的 Palantir 团队以了解有关 Quiver 的更多详情，Quiver 可以嵌入到对象视图中。您还可以使用图表小部件（或嵌入来自 Contour 或 Quiver 的图表），并在 X 轴上使用日期/时间属性。
  • 缺少日期的事件不会显示在事件列表中。系统将显示一条消息，提醒用户存在缺失的事件。
  • 出于性能原因，默认情况下仅显示 50 个关联对象。当用户向下滚动列表时，将每次显示 100 个额外的对象。

分组事件时间线和表格

此小部件包含两个组件：(1) 关联对象的时间线，以及 (2) 在下方列出关联对象的表格。关联对象可以按属性进行分组，并可通过文本、日期范围和外部筛选器进行筛选。

分组的事件将绘制在不同的平行线上,每条线仅包含具有特定属性值的事件,类似于数据透视表。在下面的示例中,每个城市对应一条单独的线,该城市所有到达(红色)或出发(蓝色)的航班均显示在该线上。

此小组件可以包含一种或多种类型的对象,这些对象直接与当前对象关联,或通过关联对象进行关联。此外,它还可以通过不同的日期属性显示同一事件(示例如下)。

配置

设置

  • 添加一个或多个关联对象(事件) - 首先,点击“添加项目”,添加至少一个您希望在时间轴上显示的关联对象类型。您可以添加多种类型的关联对象:
    • 在时间轴上显示不同的对象类型,这些是完全不同的事件。示例:与某架飞机关联的对象既包含航班事件,也包含维护事件。
    • 显示同一关联对象类型的事件,但依据不同的日期属性,或使用不同类型的关联定义。示例:
      • 与机场对象关联的航班事件通过不同的日期属性显示在同一时间线上：(1) “计划到达时间”，(2) “实际到达时间”，(3) “预计出发时间”。在这种情况下，每个航班最多会出现 3 次。
      • 机场对象可以将与之关联的到达航班和出发航班显示在同一时间线上。
  • 选择您想要添加的事件对象类型 - 对于您想要添加的每个事件对象，请配置该对象类型的详细信息：
    • 选择关联对象 - 可以是直接关联对象，也可以是扩展关联。
      • 直接关联对象的示例：当前对象是机场，您想要显示到达航班和出发航班的时间线。
      • 扩展对象（二度）的示例：当前对象是机场，您想要显示与关联到该机场的到达航班相关联的所有飞机对象的时间线。
  • 配置视觉格式选项
    • 最大事件数 - 此选项目前不起作用。
    • 颜色 - 为此条目配置下的所有事件选择颜色。使用 Blueprint 标准颜色 ↗ 或基本颜色名称 - “蓝色”、“红色”、“黄色”等。
    • 系列名称 - 此时间线下所有事件的描述，将显示在图形时间线的图例中。
  • 定义用于对时间线上的事件进行排序的日期属性 - 选择您希望使用关联对象的哪个属性在时间线上显示事件。该属性必须是时间戳 / 日期，因此配置中仅建议此类属性。
  • 事件分组依据 - 选择如何在图形时间线上对事件进行分组。每个分组将在图形时间线中显示为单独的水平事件线，彼此上下堆叠。共有两个选项：
    • 常量 - 当前项将分组在单一时间线上，其标题定义为自由文本值。在这种情况下，如果您希望将其他时间线添加为单独的线条，则必须定义其他项。
    • 属性 - 将事件拆分为多条独立的时间线，并根据该属性的不同值在各时间线上对事件进行分组。
      • 示例：在显示某个机场对象的所有到达航班的时间线时，可以选择“航空公司名称”属性，为每家航空公司创建单独的时间线，该航空公司的所有航班都将显示在其专属时间线上。下方的列表将按时间顺序列出所有航空公司的所有航班事件。
  • 列表中显示的属性 - 选择您希望在微件的第二部分（即列表）中显示的属性：
    • 选择您希望显示的属性：
      • 所有属性 - 如果关联对象具有大量属性，则不建议选择此选项，因为时间线会变得拥挤且难以浏览。
      • 重要属性 - 仅显示在本体论管理器中被定义为“重要”（Prominent）的属性。
      • 特定属性 - 打开一个包含该关联对象所有属性的多选下拉列表。请选择要显示的特定属性。
      • 无属性 - 时间线上仅显示关联对象的标题。
    • 属性过滤器 - 一个可选的开关，用于添加基于单个属性的过滤器，以仅包含特定值。这些值必须以区分大小写的自由文本字符串形式明确键入。
  • 图形时间线的附加配置（这些配置仅适用于时间线组件，对 表格组件无效）
    • 默认显示的分组 - 应在时间线中显示多少条时间线，或具体显示哪些时间线，作为单独的线条。在这两种情况下，用户都会看到一个包含所有其他分组的多选辅助工具。
      • 最大数量 - 在图形时间线中显示的不同分组和不同时间线的最大数量，以数字（值）表示。
      • 明确列表 - 输入您希望显示的分组值的确切列表（文本，区分大小写）。
    • 分组排序依据 - 时间线可以有多条水平线，此选项允许您通过以下三种方式之一对这些线进行排序：
      • 配置顺序 - 您配置不同项目时的顺序
      • 名称 - 所有分组按字母顺序排列，顶部为 A，底部为 Z
      • 最近事件 - 最近发生事件的分组排在最上方
    • 图表最大高度 - 设置小部件中图形时间轴的最大高度（以像素为单位）。要设置整个小部件的高度，请参阅配置中“格式”选项卡下的“大小调整”选项。

格式

在“格式”选项卡下，除了标题、图标、信息和布局这些默认设置外，您还可以控制该部分的最小和最大高度。这两项设置均为可选。

常见问题与注意事项

  • 最终用户可以使用自由文本筛选器或日期范围来筛选时间轴。请注意，这些筛选器不会被发布，也 不会 影响其他小部件。
  • 如果启用了跨部分筛选，此小部件将受其他筛选小部件的影响。
