对象时间线

对象时间线视图按时间顺序显示单个对象的完整变更历史，并将每次变更归因于做出该变更的智能体或人类。此视图可帮助您将编辑追溯至产生该编辑的执行、查看其背后的 token 用量和运行时间，并确定可优化的步骤。

要访问对象时间线，请执行以下任一操作：

  • 在 Autopilot中，从 图视图 切换到对象时间线。

  • 在 Object Explorer中，在对象视图中选择 更多 （前提是您的对象已启用编辑历史）。

查看对象活动

对象时间线会显示由智能体或人类执行的编辑，并为每次变更提供完整归因。您可以：

  • 查看哪些智能体或人类对对象执行了操作。
  • 监控 token 用量、智能体覆盖率和运行时间。
  • 将编辑追溯至产生该编辑的执行。

查看汇总指标

对象的汇总指标为您提供了优化的起点：

  • 总 token 用量： 所有执行中消耗的 token 数量。
  • 总运行时间： 从第一次执行到最后一次执行的时长。
  • 等待时间： 等待人工输入所花费的时间，与总运行时间显示在同一单元格中。
  • 智能体覆盖率： 对象历史中有多少是由智能体驱动的，多少是由人类驱动的。

优化您的工作流

使用时间线和摘要指标，找出您的工作流在哪些环节花费最多的时间和令牌：

  • 每个步骤的令牌使用量 让您快速识别哪些步骤消耗最多，从而知道该把重点放在哪里——无论是完善提示词还是切换模型。
  • 一目了然的时间细分 帮助您发现运行过程中时间消耗在哪里，从而识别可以自动化的手动步骤，以缩短整体工作流时长。

探索时间线

时间线中的每一行代表对对象执行操作的智能体或人类：

  • 条形： 表示执行。
  • 菱形标记： 表示通过操作对本体论中的对象所做的编辑。

各行与标记按时间顺序共同显示，展示不同参与者如何随时间处理同一对象。时间线还可帮助您识别重叠活动，并了解某个执行何时从另一个执行接续。

选择某个条形或菱形标记，即可打开侧面板，其中显示所选活动的详细信息，包括：

  • 执行指标，例如 token 用量、运行时间和成本。
  • 对对象所做的编辑。
  • 负责每次编辑的执行。

使用侧面板将对象编辑追溯至相应的执行，并调查导致对象整体运行时间和成本的活动。
