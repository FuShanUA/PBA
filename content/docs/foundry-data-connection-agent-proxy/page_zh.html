Agent 代理配置参考

本页面介绍将 Agent 用作网络代理时，通过 Agent 代理出站策略 在 Foundry worker 连接上可用的配置选项，并假定您已经熟悉 数据连接 Agent 及其 通用配置选项。

用作代理的 Agent 为 Foundry 中的服务提供了一条网络路径，使其能够访问位于独立网络中、无法通过 Foundry 网络直接访问的系统。 当 Foundry 托管在云端时，需要使用代理来访问无法通过互联网访问的系统。当 Foundry 托管在私有网络中时，需要使用代理来访问其他网络中的系统，其中可能包括无法通过其他方式访问的公共互联网。

Agent 代理使 Foundry 中的应用能够像直接通过 Foundry 网络连接到数据源一样运行，并且可以为其配置多个 Agent，以支持交替的维护窗口，从而避免停机。请按照以下指南配置和管理用作代理的 Agent。

将 Agent 用作数据连接源的代理

您必须先 设置一个 Agent 然后才能将其用作代理。已用于 代理工作进程 源的现有代理无需额外配置即可复用。

设置好代理后，创建一个 代理出口策略 来使用该代理。然后，您可以创建一个源并为其分配该策略。

特定于代理的安全控制

为确保通过代理的连接只能访问所需资源，提供了多项安全控制。

安全控制要么是 强制性的 （无法禁用），要么是 可选的 （默认不启用）。

可用的安全控制配置如下：

安全控制是否必需？描述
源配置强制执行是代理始终只允许流量访问已分配的源上配置的主机名和端口。
代理允许列表（Foundry）可选在 Foundry 中配置允许列表，以便在流量到达代理之前对其进行过滤。只有代理资源所有者才能修改该设置。
代理允许列表（本地文件）可选在代理主机上创建允许列表，供本地代理进程在您的网络中强制执行。只有对代理主机具有 SSH 访问权限的用户才能修改该设置。
代理主机防火墙可选设置主机级防火墙控制，以限制代理仅与其预期的目标系统通信（强烈建议）。这些防火墙独立于 Foundry 运行，并可增加一层额外的安全防护。

源配置强制执行

连接到代理时，源上定义的 URL 中的主机名和端口会将访问限制为仅该主机名和端口。尝试连接到任何其他主机名或端口都将导致代理返回 HTTP 403（未授权）响应代码。

这可以防止在代码中导入和使用该连接时出现未经授权的连接。

如果仅使用此安全控制，请确保能够将代理分配给特定源的用户同样受到信任，可以连接到从代理主机可访问的任何系统。

代理允许列表（Foundry）

在 Foundry 中配置允许列表，将特定代理的连接限制为特定的 IP 地址或 CIDR 块，而不考虑所分配的源。

要进行此配置，请导航至 代理设置，然后切换 高级 选项（位于 管理配置 部分）。在 YAML 文件中，添加一个 agentProxyConfiguration 块，其缩进级别与 security 块相同。

列出您希望允许代理连接的 CIDR 块和端口。例如：

代理允许列表（本地文件）

用于 Foundry 中的代理允许列表 的相同配置也可以在代理主机本身的文件中进行设置，从而防止 Foundry 中的用户编辑该配置。

要在本地配置代理允许列表，请按照以下步骤操作：

  1. 通过 SSH 登录到代理主机。
  2. 创建一个名为 agentProxyConfig 的文件夹，该文件夹与您的 magritte-bootvisor-<version> 位于同一目录（即根目录）。
  3. 在新创建的 agentProxyConfig 文件夹中，创建一个文件，文件名为 agentProxyConfig.yml。
  4. 该 agentProxyConfig.yml 文件和 agentProxyConfig 文件夹 必须 由 root 用户创建，并且必须设置文件权限，以防止代理写入此文件或文件夹。代理将 不会 在以下情况下运行其代理功能： agentProxyConfig.yml 文件存在且可写，或者其中一个父目录可被代理写入。
  5. 此文件的内容与代理设置界面中提供的配置相同。

例如：

代理主机防火墙

对于任何代理， 我们建议在主机上设置防火墙，仅允许必要的连接。

连接池配置

agent 代理会维护一个用于处理请求的连接池。您可以根据工作负载配置连接池大小,以优化性能。

要配置连接池,请导航至 Agent 设置,然后开启 高级 选项(位于 管理配置 部分)。在 YAML 文件中,将连接池设置添加到 agentProxyConfiguration 块中:

Copied!
1
2
3
agentProxyConfiguration:
  maxConnections: 250
  coreConnections: 100
选项默认值描述
maxConnections300agent 代理可打开的最大连接数。
coreConnections20连接池中维护的最小连接数。

某些连接器(例如 Databricks)可能会同时打开大量连接。如果您在使用 agent 代理策略时发现 agent 上出现连接池耗尽错误,请考虑增大 maxConnections 和 coreConnections 的值。
