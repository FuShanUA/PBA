向 Marketplace 产品添加同步或导出

用途 Foundry DevOps 以将您的 Data Connection 同步和导出包含在 市场产品 中，以便其他用户安装和重用。 了解如何创建您的第一个产品。

支持的功能

标准 同步 和 流式同步 均可包含在 Marketplace 产品中。此外，Data Connection 导出 可以与同步一起打包到 Marketplace 产品中。

将 Data Connection 同步和导出添加到产品

要向产品添加 Data Connection 同步或导出，请先 创建一个产品中的分支提案。选择 添加输出，然后选择一个 Data Connection 源。该对话框将引导您完成整个过程，并允许您将同步和导出都包含在 Marketplace 产品中。
