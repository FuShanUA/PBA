为什么在 Foundry Automate 中，自动化生成的 Notepad PDF 对某些用户会无法渲染？

对于无法访问 Notepad 模板所需触发对象的用户，自动化生成的 Notepad PDF 将无法渲染。要解决此问题，必须授予这些用户访问该触发对象的权限。

时间戳： 2024年4月13日

如何配置自动化，使其在工作流中的所有子作业执行完毕后才触发，而不是在每个单独的子作业上触发？

您可以使用返回已完成父作业的函数生成条件，并设置一个效果，即更新父级状态的操作。但请注意，此函数生成条件的最大频率为一小时一次。

时间戳： 2024年4月9日

通过 Marketplace 分发时，如何处理自动化的过期日期？

带有过期日期的自动化无法在 Marketplace 中打包。您必须在打包该自动化之前移除其过期日期。

时间戳： 2026年6月2日

在 Automate 中，是否可以在不使用函数的情况下，在电子邮件的主题和内容中使用对象属性？

目前，Automate 尚不支持在不使用 Function 的情况下在电子邮件主题和内容中使用对象属性的功能，且近期没有实现此类功能的计划。

时间戳： 2024年2月26日

如何解决自动化触发过于频繁，并且会在最近编辑过的现有对象上触发，而非仅对新对象执行操作的问题？

为确保自动化仅应用于新对象，您应确保对象集定义中的任何筛选条件都无法通过编辑现有对象来满足。如果您希望自动化仅针对新对象触发，请不要在对象集上指定任何筛选条件。此外，请确保在自动化设置中正确配置批处理大小。

时间戳： 2024年3月13日

Foundry Automate 是否支持基于 Webhook 的操作实现逐对象执行？

是的，Foundry Automate 支持基于 Webhook 的操作实现逐对象执行。您可以配置并行的逐对象 Webhook，为每个单独的对象执行操作。

时间戳： 2024年4月17日
