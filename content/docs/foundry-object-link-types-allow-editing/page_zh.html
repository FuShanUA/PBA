允许用户编辑对象和关联

从 Foundry 对象应用程序编辑数据

您可以允许用户应用程序（如 Workshop 和 Object Views）中的用户编辑属性值、添加和移除关联，以及创建和删除对象。您还可以根据用户所做的编辑配置副作用（如通知）。

配置此功能的受支持方式是在本体论管理器中创建和配置操作类型。 详细了解如何设置操作类型。

如果您想通过操作填充对象类型上的每个属性，可以 创建不带支撑数据源的对象类型。要在原本由数据源支撑的对象类型上通过操作填充单个属性，请创建一个 仅编辑属性.

本文档的其余部分将介绍在用户执行操作之前，需要对对象类型和关联类型进行哪些配置。

从外部应用程序编辑数据

直方图 对象 API 为外部客户端提供端点，以便在完全强制执行权限的情况下写入和更新对象、属性和关联。

设置前提条件

为了让用户能够执行操作类型配置中定义的操作，必须创建回写数据集。回写数据集在构建时会读取用户所做的编辑，并反映任何给定对象的最新状态。

编辑内容将写入回写数据集，而不是支撑对象类型或关联类型的数据集。这确保用户在分析中既能访问原始数据，也能访问编辑后的数据。

要设置回写数据集：

  1. 在 Data Connection 中导航至 数据源 您想要对其启用编辑的对象类型或关联类型的页面。
  2. 选择 生成 菜单中选择 写回数据集 部分页面以创建新的回写数据集。系统将打开一个对话框，要求您选择要放置该数据集的项目。请选择一个位置。
  3. 请确保您希望其能够编辑对象类型或关联类型的用户对该写回数据集拥有编辑权限。
  4. 请确保您希望其能够查看对象类型或关联类型更改的用户对该写回数据集拥有查看权限。
    • 查看对象和关联的能力由对象类型和关联类型的支撑数据源控制。
    • 查看对象和关联上的编辑的能力由回写数据集上的权限控制。
    • 如果用户仅有前者的访问权限，则只能看到未应用编辑的对象。如果用户拥有后者的访问权限，则可以同时看到编辑内容和对象当前的状态。
