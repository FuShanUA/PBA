可观测性图表

该 可观测性图表 组件可直接在 Workshop 应用中绘制单个资源随时间变化的平台遥测数据。您可以使用此组件将实时运行指标（例如执行次数、延迟和计算利用率）与工作流的其余部分一同嵌入，使操作人员能够一目了然地发现整个工作流的趋势、异常和性能变化。

配置可观测性图表组件的模块构建者可以：

  • 为以下资源绘制指标： 函数、 操作或 计算模块。
  • 选择要为所选资源绘制的指标（例如，函数的执行次数或 P95 持续时间）。
  • 从 Workshop 变量派生可见时间范围，并允许用户直接在图表上刷选一个范围来更新这些变量。
  • 展开图表以便仔细查看，或在 Workflow Lineage 中查看，以调试底层的执行情况。

下面的屏幕截图展示了一个 可观测性仪表板 ，由多个可观测性图表组件构建而成：一个 Escalate Order 操作的执行次数和 P95 持续时间，以及一个 triagePatient 函数的相同指标。模块顶部的一个时间范围控件可驱动全部四个图表。

此处显示的指标与平台其他位置呈现的近实时指标相同。请查看我们的 本体论和 AIP 可观测性指标文档 以了解更多详情。可观测性图表（Observability Chart）小组件让您能够将这些指标嵌入到专门构建的 Workshop 应用程序中。

配置选项

小组件设置面板如下所示，配置为绘制某个 triagePatient 函数在由变量支撑的时间范围内的执行情况。

资源类型

选择要绘制其指标的资源类型。其余配置选项取决于此选择。支持的资源类型包括：

  • 函数
  • 操作
  • 计算模块

资源

选择要在图表中绘制的具体资源——函数、操作类型或计算模块。每个小组件只能绘制一个资源；可添加多个可观测性图表小组件来并排比较多个资源。

指标

选择要为所选资源绘制的指标。可用指标取决于资源类型：

  • 函数 和 操作：
    • 执行次数： 随时间变化的成功和失败次数。
    • P95 时长： 随时间变化的第 95 百分位执行时长。
  • 计算模块：
    • CPU： 随时间变化的 CPU 利用率。
    • 内存： 随时间变化的内存使用量。

时间范围

可见时间窗口由两个时间戳变量控制：

  • 开始时间
  • 结束时间

使用 Workshop 变量 来支撑这些选项，以控制所显示的范围，例如，通过 日期/时间选择器（Date/Time Picker） 在模块中的其他位置。这些变量也是小部件的输出。当用户直接在图表上选择一个范围时，小部件会将新的边界值写回 开始时间 和 结束时间 变量。这样您就可以交互式地缩放图表，并根据所选范围驱动其他小部件。

交互性

  • 范围选择： 在图表上拖动以选择范围会更新 开始时间 和 结束时间 变量，从而缩放图表，并可筛选或更新绑定到这些变量的任何其他小部件。
  • 显示图例： 切换图例显示，该图例会标注图表中的每个系列。
  • 展开： 将图表展开到更大的对话框中，以便进行更细致的查看。
  • 运行历史： 选择 运行历史 以打开资源的 运行历史 （位于工作流血缘中），并调查该指标背后的各项执行、日志和追踪记录。

可用性

只有在底层资源正在报告指标时，遥测数据才可用。如果找不到该资源，或者计算模块当前未在运行或没有活跃会话，小部件会显示一条消息来代替图表，而不是显示空白绘图。
