设计最佳实践

为移动设备上的交互进行设计需要考虑与桌面设备用户不同的一系列因素。屏幕视口尺寸不同，用户可能使用触摸屏与组件进行交互，而且用户对移动设备上的交互类型有着不同的期望。此外，您还应注意应用程序可能如何在 iOS 和 Android 等各种操作系统上使用。

尽管 Workshop 会尝试在移动应用中调整小组件以提供适合移动设备的用户体验，但为用户打造流畅体验的责任最终在于您。本页面介绍了一系列移动应用设计的最佳实践，并详细说明如何使用 Workshop 中提供的概念来实现高质量的用户体验，包括使用 下按颜色组排列图中的节点。 和 小组件 。

我们建议移动设计遵循以下最佳实践：

  • 避免使用可折叠区域，优先让用户滚动浏览内容
  • 使用大按钮以确保适合移动设备的点击目标
  • 使用抽屉进行复杂的数据输入
  • 导航到子页面以实现多步交互
  • 使用导航栏扩展您的应用，或将其拆分为多个应用

优先使用可滚动内容

桌面应用中的一种常见模式是在应用的左侧和右侧使用可折叠面板（或侧边栏）。这些面板通常用于显示可配置的筛选器，或表格或列表中某个项目的详细信息。

可折叠区域在移动设备上存在一些问题。首先，定位并点击用于切换区域的控件可能比较困难；其次，屏幕空间通常不足以让可折叠区域提供自然的用户体验。

相反，请尝试使用 Flow 布局 来显示一系列可供用户滚动浏览的小组件。垂直滚动是在移动设备上显示大量内容的自然方式，用户可以轻松地滚动浏览一系列小组件以找到所需的信息。

如果您需要在屏幕上始终显示某些摘要信息或操作按钮，请使用包含 Flow 的 Toolbar 或 Rows 布局。这样，您可以让某些小组件始终显示在屏幕的顶部或底部，同时保留用户滚动浏览主要内容主体的能力，如下例所示。

确保适合移动设备的点击目标

桌面设备用户通常使用鼠标和键盘与应用进行交互。使用鼠标可以让用户精确地点击按钮和其他控件。然而，在带有触摸屏的移动设备上，用户可能难以与最初为桌面使用而设定尺寸的按钮进行交互。

在移动应用中添加按钮组（Button Group）小组件时，我们建议在大多数情况下选择 Large 样式 选项，以确保按钮在触摸屏上易于选择。在适当的情况下，我们还建议启用 填充可用水平空间 选项，以进一步增大控件目标的大小。

当需要向最终用户显示多个按钮选项时，请将按钮组配置为菜单（Menu）按钮类型。在移动应用中，这会显示一个顶级按钮，点击后将打开底部抽屉，让用户选择您配置的其中一个嵌套按钮。

在抽屉中进行数据输入

桌面应用程序通常有充足的屏幕空间来显示多个输入组件，可使用文本输入、数值输入或筛选列表等小部件。有时，这些组件会嵌套在可折叠区域中，以保持界面的整洁和条理性。

在移动应用程序中，我们建议使用 抽屉式（drawer） 布局来提供专注的数据录入体验。这符合 iOS 设计指南中关于使用 模态呈现（modality）↗ 来帮助用户专注于特定范围或复杂任务的建议。

因此，移动端 Workshop 应用程序会自动在抽屉中显示操作表单。当你添加 按钮组（Button Group）小部件时，该小部件在被选中后会以全页抽屉的形式显示。

除了操作表单之外，当用户需要输入多条信息时，你也应考虑在 Workshop 中添加抽屉。一个常见的例子是，用户需要自定义多个筛选条件，应用于他们正在查看的一组对象。你可以创建一个包含筛选列表小部件的抽屉，让用户配置筛选条件，然后添加一个用于打开该抽屉的按钮组小部件。

有关设置抽屉的分步指南，请参阅教程中关于 添加筛选抽屉.

使用子页面进行多步骤交互

基于上述最佳实践，当你需要用户查看特定对象以了解详情或执行操作时，你应该创建一个新的 page 来显示该对象的完整详情。在 移动应用启动器 中打开的 Workshop 应用程序支持浏览器级别的前进和后退交互，让用户可以在子页面之间进出导航，从而在 Android 和 iOS 上提供自然的体验。

使用导航栏扩展你的应用程序

在桌面应用程序中，通常使用标签页布局在单一界面中包含许多不同的功能。标签页与可折叠区域的组合可用于创建复杂且数据丰富的界面，支持开放式分析，并在屏幕上展示大量信息。

移动应用程序通常应比桌面应用程序更贴合目标用户群体的特定需求。因此，移动应用程序中的每个顶级页面应相当简单，通常只允许用户浏览和筛选一组对象，然后导航到另一个页面以查看详情并执行操作。

随着应用程序变得越来越复杂，并为某个用户群体包含多个工作流，你应该使用 移动导航栏 来呈现用户可以访问的多个页面。每个导航项可以将用户带到不同的顶级页面，通常用于显示不同类型的对象，或提供多种方式来搜索同一组对象。

例如，在一个用于向技术人员展示任务的应用程序中，一个名为“我的任务”的标签页可以显示分配给当前用户的所有活动任务，另一个名为“任务搜索”的标签页可以支持在所有技术人员中搜索任务，最后一个名为“历史记录”的标签页可以显示用户之前完成的任务记录。

有关如何配置导航栏的详细信息，请参阅 导航栏小部件 页面预览同步的数据。

导航栏支持在屏幕底部显示最多四个标签页，你可以使用子菜单显示其他导航项。但是，如果你的应用程序已经发展到拥有多个标签页的程度，你应该考虑将这些功能拆分到多个应用程序中。用户可以使用 应用启动器在不同应用程序之间进行导航，让每个应用程序具有单一且明确的目标有助于保持功能的简洁，并确保你的应用程序保持良好的性能。
