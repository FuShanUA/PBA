捆绑包分块

捆绑包分块允许将捆绑包拆分为多个文件，这些文件可以单独（且无需按顺序）导入到目标中心。将捆绑包的所有分块导入目标中心后，系统便会处理该捆绑包。

当传输介质存在物理限制（例如 4GB DVD），或者在下载和上传大型捆绑包（例如 10 GB 以上）时遇到可靠性问题，捆绑包分块会很有帮助。本指南将介绍如何设置捆绑包分块。

先决条件

要设置捆绑包分块，您必须拥有导出管道。了解有关创建导出管道的更多信息。

设置捆绑包分块

  1. 导航到 Export 应用程序并选择一个 Export 管道。在管道设置的构建设置部分,输入 4 到 16 GB 之间的最大传输大小。请注意,如果将来更改了大小限制,更新后的最大传输大小将仅适用于更改设置之后创建的 Bundle。因此,最好设置一个可行的良好初始值，例如,4 GB 是 DVD 的典型大小。



  2. 导航到 Export 管道并构建 Bundle。如果 Bundle 的总大小大于上一步中指定的最大传输大小，则 Bundle 将被分块。



  3. 导航到 Bundle 的下载选项卡。您可以在Bundle 分块部分查看每个分块的大小、单独下载分块或批量下载分块。



  4. 下载分块并将其导入另一个 Target Hub。

将分块导入 Target Hub

  1. 导航到 Target Hub 中的 Import 应用程序。拖放或选择您要上传的分块。



  2. 上传完成后，导航到 Import 应用程序中的导出管道。上传成功后，您可以选择 查看 Bundle 或管道链接。您可以在该管道的导入收件箱中查看新的分块 Bundle。



  3. 在所有分块上传完成之前，Bundle 状态将显示仍需上传的分块。收到所有分块后，将处理 Bundle 导入。Bundle 处理完成后，即成功导入 Target Hub 以供使用。
