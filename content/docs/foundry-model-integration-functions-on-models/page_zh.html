模型上的函数

您可以将模型部署为函数，以便在最终用户应用中实时使用模型，例如 来运行该专业代码代理。你还可以通过, 将收集到的信息存储在, 操作日 更多。模型函数还可以在其他函数中使用，以便在代码中编写涉及该模型的自定义业务逻辑。

为您的模型发布函数

可以为具有以下配置的模型发布函数： 已配置的实时部署，或为 建模目标实时部署.

了解有关如何配置和管理模型函数的更多信息.

在代码中调用模型函数

您可以从 TypeScript v1、TypeScript v2 和 Python 函数中调用模型函数。TypeScript v2 和 Python 仓库仅支持 与本体论绑定的模型函数。生成的 Ontology SDK 会在每种语言中公开该模型函数。

下面是一个简化示例，该函数调用一个接受输入的实时部署 Double[] 并返回一个 Double[] 在模型 API 中称为 output_df 的输出。所有三个示例都通过名称引用模型 API 输入；此示例假定该输入名为 input_df.

下面的 TypeScript v1 示例展示了一个与空间绑定的模型函数。2026 年 2 月及之后创建的模型函数改为与本体论绑定。对于这些函数，请导入 Queries （来自 @foundry/ontology-api 并调用 Queries.modelDeployment({ input_df: inputs })。请参阅 与本体论绑定的 TypeScript v1 形式 以获取完整示例。

import { Function, Double } from "@foundry/functions-api";
import { ModelDeployment } from "@foundry/models-api/deployments";

@Function()
public async predictValues(inputs: Double[]): Promise<Double[]> {
    const modelOutput = await ModelDeployment({ input_df: inputs });
    return modelOutput.output_df;
}

import { Client } from "@osdk/client";
import { Double } from "@osdk/functions";
import { modelDeployment } from "@ontology/sdk";

async function predictValues(client: Client, inputs: Double[]): Promise<Double[]> {
    const modelOutput = await client(modelDeployment).executeFunction({
        input_df: inputs
    });
    return modelOutput.output_df;
}

export default predictValues;

@function(beta=True)

        input_df=inputs
