数据集预览

数据集预览应用程序为您提供有关给定数据集的各类详细信息，包括元数据、构建历史、健康状况等。对于流式数据集，还提供其他功能，包括查看流式作业的信息和指标，以便对流性能进行故障排查和调试。

下方截图显示了数据集预览应用程序的界面。以下各节将对带编号的部分进行更详细的说明。

1. 数据集标头

页面标头标识所选数据集，并提供基本信息，例如其名称、显示名称（如有）、位置以及所选分支。标头还支持一些与文件相关的操作，例如共享、移动、重命名等。

2. 信息面板

信息面板提供有关数据集的元数据以及一些基本管理操作。该面板分为三个部分：

  • 关于： 信息包括数据集的创建和更新时间、创建以及最后更新数据集的用户、表的大小、用于创建数据的任何工具和输入数据集、标签等。此外，还提供了一个 编辑架构 视图，位于 更新者 部分将为 CSV 和 JSON 文件推断架构。在此，用户还可以应用额外的解析选项来删除不规则行、更改编码或添加其他列（如文件路径、行的字节偏移量、导入时间戳或行号）。对于其他文件类型，可在 架构 部分中进行架构编辑，该部分位于 详情 标签页下。
  • 列： 有关数据集中各个列的信息，包括数据类型、描述和数据统计信息（空值百分比、分布和样本）。
  • 计划： 有关任何已配置的构建 计划 的信息，这些计划将运行以更新数据集。

3. 标签页视图

预览

该 预览 标签页以表格形式提供数据样本，并允许对完整数据集进行轻量交互。有关预览表格的更多信息，请参阅 4. 预览表格。

历史

该 历史 标签页视图提供历史作业（构建）信息。页面右侧的 摘要 视图显示随时间推移的作业状态汇总信息。

左侧面板中显示作业列表及其状态和持续时间。选择某个作业后，右侧将显示详细的 作业 视图，其中显示详细的作业信息，包括进度、规范、构建日志、文件和生成的架构。

流式数据集

在流式数据集中， 历史记录 选项卡仅当视图设置为 归档时才会显示。 历史记录 选项卡会将归档事务与流式作业一同显示。

从历史事务创建分支

您可以使用 历史记录 选项卡，针对您的数据中尚未被 保留策略删除的历史事务创建分支。从左侧面板中选择一个先前的事务，然后选择省略号（...）图标以 创建分支。

详情

详情视图提供有关数据集的更多技术信息，以及一些管理操作：

  • 架构： 提供有关表架构（列规范）的完整信息，并允许您编辑架构（如适用）。
  • 文件： 显示构成数据集的文件列表，并允许您下载这些文件。
  • 作业规范： 显示作业规范，其中包含构建数据集所需的基本信息。Furnace SQL 输出可以在此部分中保留多个 SQL 定义 。
  • 同步： 呈现数据同步到不同数据库的状态和详细信息。对于某些同步类型，可以应用其他设置。
  • 自定义元数据： 允许您向数据集添加自定义信息字段。在此部分中添加的字段将显示在概述页面的信息面板中。
  • 资源使用指标： 提供图表和信息，展示数据集磁盘和 Spark 使用情况随时间的变化。
  • 上次运行详情（仅适用于流）： 显示有关最新流运行的详细信息。

流（仅适用于流式数据集）

当数据集是流式数据集时， 流 选项卡将显示流式处理作业的当前和历史信息。通过更改时间段，您可以浏览在该时间段内流式传输该数据集的作业的日志和详细信息。

指标（仅适用于流式数据集）

当数据集是流式数据集时，指标选项卡会显示用于分析和排查流式处理作业性能的图表及相关交互。其中包含一个用于选择指标以可视化趋势的下拉菜单，菜单中突出显示了推荐的调试指标。指标图表可以展开以进行详细查看，并显示阈值和带有调试链接的警告指示器。

故障排除和调试模式

您可以使用页面右上角的开关启用专用的故障排除模式。该模式提供分步操作指南,帮助您调试数据流中断问题。从右侧面板中选择内联指标标签,即可突出显示相应的图表,轻松定位问题来源。

健康状况

该 健康状况 选项卡提供了用于监控 数据健康状况的工具。该页面会显示特定资源上的健康检查、按特定监控视图分组的资源监控规则,以及影响该资源的相关计划构建。选择任意一行即可查看健康检查和监控规则的历史报告。

流式数据集

在流式数据集中, 健康状况 选项卡仅在视图设置为 归档时才会显示。此时,这些检查将针对归档数据集而非数据流。

对比

使用 对比 选项卡可比较两个不同的数据集。选择该选项卡并选择要与之比较的数据集。 对比 选项卡可通过以下几种方式使用:

  • 比较两个独立的数据集,以了解它们之间的差异。
  • 将数据集与同一数据集的较早事务进行比较,以查看其随时间的变化。
  • 将数据集的原始版本与另一个分支进行比较，以查看合并该分支将如何影响数据集。
流式数据集

在流式数据集中， 比较 选项卡只有在视图设置为 存档时才会显示。之后，您便可以将存档数据集与其他非流式数据集进行比较。

4. 预览表

使用预览表可以了解数据的结构，并快速探索数据集中的值。

默认情况下，预览表将显示有限的数据样本；确切的行数显示在预览表标题栏中。但是，对数据执行的任何操作（如筛选或排序）都将应用于完整数据集，并增加预览样本的大小。根据行数的不同，您在预览中可能无法看到整个数据集。

预览表提供了多项实用功能：

  • 选择某一列的菜单，即可对该列数据进行排序、筛选和生成图表。
  • 选择单个单元格，可在预览中排除或仅包含所选值。
  • 报告并查看各个列上的问题。
  • 搜索特定列名称。
流式数据集

流式数据集的数据预览表会提供最近流式传输行的少量样本。当设置为 实时更新时，它会自动更新。排序、筛选和图表功能仅在页面设置为 存档 时才可用，并且仅反映存档数据集的状态。

手动上传文件

在数据集预览中，您可以直接将以下类型的文件上传到数据集中： .csv、 .tsv、 .xls、 .xlsm和 .xlsx。

对于 .csv 和 .tsv 文件，Foundry 将尝试推断新文件的架构。如果新文件的文件名和架构与之前上传的文件相同，您可以在现有数据集中 更新数据 。如果文件名与之前上传的文件不同，您可以 追加数据 到现有数据集。

以下步骤适用于上传所有文件类型：

  1. 导航到您偏好的文件夹并创建数据集。

  1. 将文件拖放到数据集预览窗口中。

5. 操作

「 所有操作 」下拉菜单提供了对 Foundry 工具和操作的快速访问，让您能够分析、探索、转换和管理数据。某些操作，例如 分析 （在 Contour 中）和 构建，会显示在操作菜单之外，以便快速访问。
