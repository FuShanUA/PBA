数据集预览

数据集预览应用程序为您提供有关给定数据集的各种详细信息，包括元数据、构建历史、健康状况等。对于流式数据集，还提供其他功能，包括查看流式作业的信息和指标，以排查和调试流性能。

下面的截图展示了数据集预览应用程序的界面。带编号的各部分将在后续章节中详细说明。

1. 数据集页眉

页面页眉标识所选数据集，并提供基本信息，例如名称、显示名称（如果存在）、位置以及所选分支。页眉还支持一些与文件相关的操作，例如共享、移动、重命名等。

2. 信息面板

信息面板提供有关数据集的元数据以及一些基本的管理操作。该面板分为三个部分：

  • 关于： 信息包括数据集的创建和更新时间、创建和最后更新数据集的用户、表的大小、用于创建数据的任何工具和输入数据集、标记等。此外，在 编辑 schema 视图下也可使用 更新者 部分，该视图会为 CSV 和 JSON 文件推断 schema。在此，用户还可以应用其他解析选项来丢弃不规则行、更改编码，或添加其他列，例如文件路径、行的字节偏移量、导入时间戳或行号。对于其他文件类型，可以在 模式 部分下的 详情 tab.
  • 使分区垂直拆分，从而在模块中有效地创建一个新列。 有关数据集中各列的信息，包括数据类型、描述和数据统计信息（空值百分比、分布和样本）。
  • 计划： 有关任何已配置的构建 计划 的信息，这些计划将运行以更新数据集。

3. 标签页视图

预览

直方图 预览 标签页以表格形式提供数据样本，并允许与完整数据集进行轻量交互。在 4. 预览表格.

历史记录

直方图 历史记录 标签页视图提供历史作业（构建）信息。页面右侧的 摘要 视图显示随时间推移的作业状态汇总信息。

在左侧面板中，会显示作业列表及其状态和持续时间。选择某个作业后，右侧会显示详细的 作业 视图，其中显示详细的作业信息，包括进度、规范、构建日志、文件以及生成的 schema。

在流式数据集中， 历史记录 标签页仅在视图设置为 表中，可通过点击时才会显示，并且它会与流式作业一起显示归档事务。

从历史事务创建分支

你可以利用代码库升级拉取请求中的 历史记录 标签页，在尚未被 保留策略删除的数据历史事务上创建分支。从左侧面板中选择一个先前的事务，然后选择省略号（...）图标以 在分支菜单中输入新分支的名称，随后点击.

详情

详细信息视图提供有关数据集的其他技术信息，以及一些管理操作：

  • Schema: 提供表 schema（列规范）的完整信息，并允许您编辑 schema（如果适用）。
  • 文件： 显示构成数据集的文件列表，并允许您下载这些文件。
  • 作业规范： 显示作业规范，其中包含数据集构建所需的基本信息。Furnace SQL 输出可以在此部分保留多个 SQL 定义 。
  • 同步： 显示数据同步到不同数据库的状态和详细信息。对于某些同步类型，可以应用其他设置。
  • 自定义元数据： 允许您向数据集添加自定义信息字段。在此部分添加的字段将显示在概览页面的信息面板中。
  • 资源使用指标： 提供数据集随时间推移的磁盘和 Spark 使用情况的图表和信息。
  • 上次运行详情（仅适用于流）： 显示有关最新流运行的详细信息。

流（仅适用于流式数据集）

当数据集是流式数据集时， Stream 选项卡将显示流式作业的当前和历史信息。通过更改时间范围，您可以浏览在该时间段内为该数据集进行流式传输的作业的日志和详细信息。

指标（仅适用于流式数据集）

当数据集是流式数据集时，指标选项卡会显示用于分析和排查流式作业性能问题的图表及相关交互。它包含一个用于选择指标以可视化趋势的下拉菜单，其中突出显示了推荐的调试指标。指标图表可以展开以查看详细信息，并显示阈值和带有调试链接的警告指示器。

排查和调试模式

您可以使用页面右上角的开关启用专用的排查模式。该模式提供分步操作指南来调试流中断问题。从右侧面板中选择内联指标标签，以突出显示相应的图表，从而轻松定位问题的根源。

健康

直方图 健康 选项卡提供了用于监控 数据健康的工具。该页面显示针对特定资源的健康检查、按特定监控视图分组的资源监控规则，以及影响该资源的相关计划构建。选择任意一行即可查看健康检查和监控规则的历史报告。

在流式数据集中， 健康 标签页仅在视图设置为 表中，可通过点击。此后，检查将引用归档数据集而不是流。

比较

使用直方图中的 比较 选项卡来比较两个不同的数据集。选择该选项卡并选择一个要与之比较的数据集。 比较 选项卡可以通过以下几种方式使用：

  • 比较两个独立的数据集以了解它们之间的差异。
  • 将数据集与同一数据集的较早事务进行比较，以查看其随时间的变化。
  • 将数据集的原始版本与不同的分支进行比较，以查看合并该分支将如何影响数据集。

在流式数据集中， 比较 标签页仅在视图设置为 表中，可通过点击。然后您就可以将归档数据集与其他非流式数据集进行比较。

4. 预览表格

使用预览表来了解数据的结构，并快速浏览数据集中的值。

默认情况下，预览表将显示有限的数据样本；确切的行数显示在预览表头部。但是，对数据执行的任何操作（例如筛选或排序）都将应用于整个数据集，并增加预览样本的大小。根据行数的不同，您可能无法在预览中看到整个数据集。

预览表提供了多项实用功能：

  • 选择列的菜单可对该列数据进行排序、筛选和生成图表。
  • 选择单个单元格，以从预览中排除或仅包含所选的值。
  • 报告和查看各个列上的问题。
  • 搜索特定的列名称。
流式数据集

流式数据集的数据预览表提供最近流式传输的行的小样本。当设置为 实时更新时，它会自动更新。排序、筛选和生成图表功能仅在页面设置为 表中，可通过点击 时可用，并且仅表示归档数据集的状态。

手动上传文件

在数据集预览中，您可以将以下类型的文件直接上传到数据集中： .csv, .tsv, .xls, .xlsm日 .xlsx.

对于 .csv 和 .tsv 文件时，Foundry 将尝试推断新文件的 schema。如果新文件的文件名和 schema 与之前上传的文件相同，您可以 更新数据 在现有数据集中。如果文件名与之前上传的文件不同，您可以 追加数据 到现有数据集。

以下步骤适用于上传所有文件类型：

  1. 导航到您偏好的文件夹并创建一个数据集。

  1. 将文件拖放到数据集预览窗口中。

5. 操作

直方图 所有操作 下拉菜单提供对 Foundry 工具和操作的快速访问，使您能够分析、探索、转换和管理数据。某些操作（例如 分析 （在 Contour 中）和 构建）会显示在操作菜单之外，以便快速访问。
