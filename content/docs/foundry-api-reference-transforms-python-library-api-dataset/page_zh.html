foundry.transforms.Dataset

class foundry.transforms.Dataset(alias)

一个类，表示支撑 Foundry 数据集视图的文件。

建议使用静态 Dataset.get() 工厂方法，而不是直接调用构造函数。

静态方法 get(alias)

为给定的别名创建一个新的 Dataset 实例。

  • 参数： alias (str ↗) – 数据集的别名。
  • 返回： 一个新的 Dataset 实例。
  • 返回类型： Dataset

属性 alias

数据集的别名。

  • 类型： str ↗

属性 schema

数据集的 Foundry 字段结构。

  • 类型： FoundryFieldSchema

属性 write_table_path

数据集文件在磁盘上的路径，用于 write_table。

  • 类型： str ↗

属性 lazy_write_table_path

指向存储桶的对象存储路径，该存储桶将被映射到输出事务中。

  • 类型： str ↗

read_table(columns=None, row_limit=None, format='dataframe', mode='current', force_dataset_download=False, schema=None)

将表格型 Foundry 数据集读取为 pandas DataFrame、Polars DataFrame、Arrow Table 或原始文件路径。

  • 参数：
    • columns (List [str ↗ ] , 可选) – 要读取的列子集。
    • row_limit (int ↗ , 可选) – 要读取的最大行数。
    • format (str ↗ , 可选) – 输出类型。为以下值之一： "arrow"、 "pandas"、 "dataframe" （pandas 的别名，默认值）、 "polars"、 "lazy-polars"或 "path"。当设置为 "path"，则会返回指向原始数据集文件的路径。
    • mode (str ↗ , 可选) – 读取模式，取值为 "current"、 "previous"或 "added"之一。默认为 "current"。
    • force_dataset_download (bool ↗ , 可选) – 是否必须重新下载数据集，即使该数据集已存在于本地内容中。默认为 False。
    • schema (FoundryFieldSchema , 可选) – 读取空的增量输出时要应用的 schema。
  • 返回： 以请求的格式返回的数据集内容。
  • 返回类型： pyarrow.Table ↗ | pandas.DataFrame ↗ | polars.DataFrame ↗ | polars.LazyFrame ↗ | str ↗

当设置了 columns、 row_limit或通过 where() 方法应用的筛选器时，输出 format 必须为 "arrow"、 "dataframe"、 "pandas"或 "polars"之一，且 mode 必须为 "current"。

write_table(df, column_descriptions=None)

将表格数据上传到 Foundry 数据集。此操作会上传数据、推断出 schema，并更新列描述元数据。

接受 pandas DataFrame、Arrow Table、Polars DataFrame、DuckDB PyRelation，或指向原始数据集的路径（字符串或 pathlib.Path）。

  • 参数：
    • df – 要上传的数据。接受 pandas.DataFrame ↗、 pyarrow.Table ↗↗ polars.DataFrame 、、DuckDB PyRelation，或匹配 write_table_path的路径。
    • column_descriptions (Dict [str ↗ , str ↗ ] , 可选) – 列名到其字符串描述的映射。此映射会与 DataFrame 的列取交集，且所包含的描述不得超过 800 个字符。
  • 返回： None

put_metadata(column_descriptions=None)

在上传原始 Parquet 文件后最终确定数据集。此方法会从上传的 Parquet 文件推断 Foundry 架构，并更新数据集上的列描述元数据。

在一个或多个 Parquet 文件上传到输出数据集后，必须调用此方法，以便能够推断架构。如果在文件成功上传之前调用此方法，则会抛出异常。

  • 参数： column_descriptions (Dict [str ↗ , str ↗ ] , 可选) – 列名到其字符串描述的映射。此映射会与数据集的列取交集，且所包含的描述不得超过 800 个字符。
  • 返回： None

set_write_mode(mode)

设置数据集的写入模式。

  • 参数： mode (str ↗) – 写入模式，为以下值之一： "replace"、 "modify"，或 "append"。在 modify 模式下，写入的任何内容都会追加到数据集中，并可能覆盖现有文件。在 append 模式下，写入的任何内容都会追加到数据集中，且不会覆盖现有文件。在 replace 模式下，写入的任何内容都会替换数据集。
  • 返回： None

写入数据后，无法更改写入模式。

files(mode='current', show_hidden_files=False)

列出 Foundry 数据集中的文件。

  • 参数：
    • mode （str ↗ ， 可选）– 读取模式，为以下值之一： "current"、 "previous"或 "added"。默认为 "current"。
    • show_hidden_files （bool ↗ ， 可选）– 是否列出隐藏文件。默认为 False。
  • 返回： 数据集中的文件集合。
  • 返回类型： FileCollection

upload_file(path, logical_path=None)

将本地文件上传到 Foundry 数据集。

  • 参数：
    • path （str ↗）– 要上传的本地文件的路径。
    • logical_path （str ↗ ， 可选）– Foundry 数据集中的目标路径。如果未提供，文件将使用与本地文件相同的名称上传到根目录。
  • 返回： 上传的 Foundry 数据集文件的名称。
  • 返回类型： str ↗

upload_directory(local_dir_path)

将本地目录上传到 Foundry 数据集。目录内递归找到的所有文件都将被上传。

  • 参数： local_dir_path (str ↗) – 要上传的本地目录的路径。
  • 返回： 本地文件路径到对应的 Foundry 数据集文件路径的映射。
  • 返回类型： Dict [str ↗ , str ↗ ]

where(operand_filter)

对数据集应用行筛选器。返回数据集，以便进行链式调用。筛选器在 read_table 被调用时应用。

  • 参数： operand_filter – 使用 Column.get()构建的筛选表达式。
  • 返回： 筛选后的数据集。
  • 返回类型： Dataset

在 Column上支持的运算符：

  • ==、 !=、 >、 >=、 <、 <=
  • .isnull()
  • .isin(values)
  • .between(lower, upper)

要组合筛选器，可使用 & （与）、 | （或）和 ~ （非）。

select(*column_names)

从数据集中选择一部分列。返回数据集，以便进行链式调用。

  • 参数： column_names (str ↗) – 要选择的列的名称。
  • 返回： 应用列选择后的数据集。
  • 返回类型： Dataset

limit(row_limit)

设置要读取的最大行数。返回数据集，以便进行链式调用。

  • 参数： row_limit (int ↗) – 最大行数。
  • 返回： 应用行数限制后的数据集。
  • 返回类型： Dataset

abort()

中止此数据集上的所有工作。在调用此方法之前或之后写入的任何数据都将被忽略。

  • 返回： 已中止的数据集。
  • 返回类型： Dataset
