传感器对象类型设置

本页面包含有关如何设置和配置传感器对象类型的说明。

如果您预期时间序列数据仅出现在给定对象类型的一部分对象上，则应继续创建链接回这些根对象类型的传感器对象。但是，如果您预期时间序列数据出现在给定对象类型的（几乎所有）对象上，则应直接在该对象类型上添加 TSP。在以下内容中了解有关这些设置选项的更多信息 时间序列文档.

前提条件：时间序列对象类型支撑数据集

首先，请按照以下说明操作 创建新的时间序列对象类型。您的时间序列对象类型支撑数据集应具有以下架构：

列类型描述
主键String[Required] 每行的主键。
序列 IDString[Required] A 序列 ID 用于唯一的 TSP。如果您的传感器对象类型由多个时间序列同步支撑，您将需要一个 限定序列 ID。TSP 不能作为主键或标题属性。
传感器名称String[Required] 用于标识给定传感器对象的时间序列数据所代表内容的名称。链接到单个根对象的所有传感器对象的传感器名称必须唯一。
外键String[Required] 用于将传感器对象类型链接到根对象类型的外键。主键可以用于此目的，但传感器对象类型至少需要一个关联类型。
是否为分类数据Boolean[Required if the TSP is backed by multiple syncs of both numerical and categorical types] 的布尔值 true 表示给定的传感器对象具有分类时间序列数据，否则数据将被视为数值数据。如果您是从 Measures 设置迁移而来，此项之前称为 is_enum.
单位String[Optional] 应为给定传感器对象显示的单位。
内部插值String[Optional] 应为给定传感器对象使用的内部插值。

设置传感器对象类型

在监听器设置向导的 功能 页面中，选择 开始使用 于 时间序列 区域的字段中添加命令。

按照对话框中的前两个步骤操作，以 设置您的 TSP。在 时间序列设置 对话框的最后一步中，选择 传感器对象类型 选项旁边的警告图标：

传感器对象类型配置选项

添加该属性后，您将看到一个展开的 传感器对象类型配置 部分，位于 时间序列属性 表格下方，包含以下配置选项：

  • 传感器关联 （必填）
    • 您必须至少选择一个关联类型，将此传感器对象类型链接到其记录时间序列数据的根对象类型。
    • 您还必须选择包含此关联类型的传感器名称的属性。
  • 主传感器关联 （如存在则为必填）
    • 仅当您的 Foundry 实例中仍可访问旧版本的 Quiver 时，此项才会出现。
    • 如果此项出现，您必须选择一个关联类型和传感器名称，以与上方传感器关联部分中已配置的条目之一相匹配。
  • 是否为分类数据？ （如果 TSP 由不同类型的多个同步支撑，则为必填）
    • 如果您的 TSP 由数值和分类同步混合的多个同步支撑，您必须选择一个布尔属性，用于指示传感器对象是否具有分类时间序列数据。
  • 单位 （可选，推荐）
    • 可选择包含每个传感器对象时间序列数据单位的属性。
  • 内部插值 （可选）
    • 可选择包含每个传感器对象时间序列数据应使用的内部插值类型的属性。
    • 有效值为：
      • LINEAR：在两个点之间进行线性插值。仅适用于数值时间序列。
      • NEAREST：取最近点的值。
      • PREVIOUS：取前一个点的值。
      • NEXT：取下一个点的值。
      • NONE：从不插值。

传感器对象类型的单位和插值应在传感器对象类型配置部分中设置，而不是通过基础格式化程序设置。

从 Measures 迁移

如果您在 Ontology Manager 中对象类型的 功能 页面看到如下所示的警告，则该对象类型之前被配置为 Measure。Measures 正在被弃用。您可以在类似的工作流程中改用传感器对象类型。

您的对象类型可能已经完全或部分迁移到传感器对象类型。如果您看到 开始使用 按钮，位于 时间序列 已应用标签 功能 页面，则您的 Measure 尚未迁移。要将您的 Measure 迁移到传感器对象类型，请按照以下步骤操作。如果您看到绿色勾选标记后跟 全部完成 菜单中选择 传感器对象类型 部分，则您的对象类型已完全迁移。本页底部包含一个示例。如果您的设置与这两种描述都不匹配，则您处于部分迁移状态。请按照屏幕上的提示完成迁移。

除非您确定知道哪个时间序列同步回您的 Measure，否则我们不建议进行迁移。如果您不确定哪个时间序列同步回您的 Measure 但仍想迁移，请联系 Palantir Support。

  1. 确定哪个（或哪些）时间序列同步回您的 Measure。如果有多个时间序列同步支撑您的 Measure，您将需要生成限定序列 ID。了解更多关于 设置限定序列 ID.
  2. 在 Measure 对象类型中，序列 ID 列可能被用作主键。这对于传感器对象类型是不允许的，因为 TSP 不能用作主键。根据用作主键的列，您有以下选项：
    • 选项 1： 如果您可以使用非序列 ID 的列作为主键，则无需进一步操作。
    • 选项 2： 如果您之前将序列 ID 列用作 Measure 的主键，则需要创建一个新列作为主键。
      • 创建此列的最简单方法是打开生成支撑数据集的 Pipeline Builder 管道或 Code Repository，并创建一个与序列 ID 重复的列。
      • 注意： 任何没有重复值的非时间序列属性都可以用作主键。请选择最适合您用例的属性。
    • 选项 3： 如果由于您的 Measure 由多个时间序列同步支撑而不得不重新格式化序列 ID 列，只要该列是唯一标识符，您就可以使用原来的序列 ID 列作为主键。
  3. 在 Ontology Manager 中打开 Measure 并打开 功能 页面。选择 开始使用 并填写流程 如上文所述。该 传感器对象类型 开关应处于开启状态，并且许多选项可能已经为您预先填写。
