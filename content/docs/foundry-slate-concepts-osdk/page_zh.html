在 Slate 中使用本体论 SDK (OSDK)

本体论软件开发工具包 (OSDK) 允许构建者在 Slate 的代码环境中充分利用本体论的全部功能。OSDK 可作为 Functions 编辑器中的一个库进行访问，为您的本体论中的对象类型、关联类型、操作和函数提供类型安全的访问。

Slate 中的 OSDK 使用与以下相同的底层 API： 场景支持功能适用于。Slate 使用 JavaScript，但提供 IntelliSense 以实现代码补全和类型提示。

概述

Slate 中的 OSDK 面板使您能够：

  • 选择要使用的本体论
  • 配置数据实体，包括对象类型、关联类型、操作类型和函数
  • 生成根据您选择的实体定制的自定义 OSDK 库
  • 查看每个实体的文档和代码片段
  • 在将更改提交到您的应用程序之前跟踪更改

开始使用

访问 OSDK 面板

  1. 在编辑模式下打开您的 Slate 应用程序。
  2. 在左侧边栏中，选择 OSDK 图标以打开 OSDK 面板。
  3. 如果您尚未配置 OSDK，您将看到本体论选择界面。

选择您的本体论

  1. 在 选择本体论 下拉菜单中，选择您要访问的本体论。
  2. 选择 确认选择 以保存您的选择。

可用的本体论取决于您的平台设置和权限。您可能只能访问一个本体论。稍后若要切换到其他本体论，您需要删除并重新配置 OSDK。

添加数据实体

选择本体论后，您可以在 OSDK 配置中添加四种类型的实体：

对象类型和关联类型

对象类型表示本体论中的核心数据实体。关联类型定义对象类型之间的关系，并嵌套显示在其父对象类型下。

  1. 在监听器设置向导的 对象类型 部分中，选择 + button.
  2. 使用搜索对话框查找并选择对象类型。
  3. 当您选择一个对象类型时，任何关联的关联类型都会自动可用。
  4. 依赖项会自动解析，因此如果您添加一个关联类型，所需的对象类型也会被包含在内。

操作类型

操作类型允许您执行修改本体论数据的操作。

  1. 在监听器设置向导的 操作类型 部分中，选择 + button.
  2. 搜索并选择您需要的操作类型。
  3. 操作所需的对象类型依赖项会自动添加。

函数

函数允许您调用本体论中定义的自定义逻辑。

  1. 在监听器设置向导的 函数 部分中，选择 + button.
  2. 浏览并选择您想要包含的函数。

没有 API 名称或编辑本体论的函数无法被选择。

生成 OSDK

配置完实体后：

  1. 检查您的选择。带有橙色指示器的实体有未保存的更改。
  2. 选择 生成 OSDK 以创建您的自定义 OSDK 库。
  3. 等待生成过程完成。
  4. 生成后，OSDK 即可在您的 Slate 函数中使用。

生成标签显示应用程序的 OSDK 版本。

在 Slate 函数中使用 OSDK

直方图 函数编辑器 允许您访问和转换通过 OSDK 获取的数据。要开始使用，请在 OSDK 面板中选择任何实体，以在右侧面板中查看其文档和代码片段。这些片段针对您的特定配置量身定制，可直接复制到您的 Slate 函数中。

例如，选择一个对象类型会显示：

  • 所有属性的列表，包括其 API 名称和类型。
  • 用于加载单个对象、获取分页、筛选等的代码片段。
  • 您生成的 OSDK 的确切导入语句和方法调用。

有关筛选、聚合、操作和其他操作的详细语法参考，请参阅 TypeScript OSDK 指南。Slate 使用 OSDK 版本 1 并基于 JavaScript，因此省略了类型注解。

使用 pivotTo 遍历关联

在 OSDK 中配置关联类型后，使用 pivotTo 方法从对象集中的每个对象遍历关联到其关联的对象。

例如，如果您有一个 Dealer 对象类型，其中包含一个指向 orders 对象类型的 Order 关联，您可以为一组经销商检索相关的订单：

const linkedOrders = await client.ontology.objects.Dealer
    .pivotTo("orders")
    .fetchPage({ pageSize: 30 });

import { client } from "@slate/osdk";

function getLinkedOrders(source) {

}

要使用 pivotTo:

  1. 请在您的 OSDK 配置中包含该关联类型。
  2. 在监听器设置向导的 OSDK 面板中，添加一个对象类型并在右下角部分选择相关的关联。
  3. 生成 OSDK。 pivotTo 方法随后即可使用，并且对已配置的关联名称是类型安全的。

在 OSDK 面板中选择一个关联类型，以查看为该关联生成的代码片段，包括您配置中确切的对象类型和关联 API 名称。

管理您的 OSDK 配置

查看实体文档

在 OSDK 面板中选择任意实体，即可在右侧面板中查看详细文档，包括：

  • 对象类型的属性定义
  • 操作和函数的参数规范
  • 针对您所选实体定制的代码片段

跟踪更改

OSDK 面板会显示未保存更改的指示器：

  • 已添加的实体在生成之前会显示橙色指示器
  • 已移除的实体会显示删除线，并提供撤销选项
  • 选择 放弃更改 以恢复到上次生成的配置

重新生成 OSDK

如果您需要重新生成 OSDK（例如，在 Ontology 更改之后）：

  1. 选择旁边的下拉箭头 生成 OSDK.
  2. 选择 重新生成上次 OSDK.

查看生成日志

要排查生成问题：

  1. 选择旁边的下拉箭头 生成 OSDK.
  2. 选择 查看最新生成日志.

排查 OSDK 加载错误

如果 OSDK 加载失败，Slate 会在健康检查对话框中显示错误。

  1. 通过选择 操作栏.
  2. 选择 OSDK 选项卡以查看详细的错误信息和指导。
  3. 使用对话框中的直接链接打开 OSDK 配置面板并修复问题。

有关健康检查对话框的更多信息，请参阅 调试应用程序.

导入或复制应用程序时的 OSDK 行为

当您 导入或复制 使用 OSDK 的 Slate 应用程序时，OSDK 包的行为会有所不同：

  • 导入应用程序： JSON 导入不会自动包含 OSDK 包。导入后，您可能需要通过选择 重新生成上次 OSDK 来自 生成 OSDK dropdown.
  • 复制应用程序： 使用 另存为 来自 文件 下拉选项会从源应用程序复制现有的 OSDK 包。如果保存副本后 OSDK 加载失败，Slate 会显示一个提示，指示您重新生成 SDK 或刷新页面。

删除 OSDK

要完全移除 OSDK 配置：

  1. 选择 更多 面板标题中的菜单（三个点）。
  2. 选择 删除 OSDK.
  3. 确认删除。

删除 OSDK 会移除所有配置和生成的代码。此操作无法撤销，如果以后需要，您将需要重新配置 OSDK。

最佳实践

  1. 从小处着手： 仅添加您需要的对象类型和操作。以后随时可以添加更多。
  2. 使用错误处理： 始终检查响应类型，以便优雅地处理错误。
  3. 对大型数据集进行分页： 用途 fetchPage() 使用适当的页面大小，而不是一次性加载所有对象。
  4. 利用文档面板： 选择实体以查看针对您的特定配置的最新代码片段。
  5. 保存您的应用程序： 生成 OSDK 后，保存您的 Slate 应用程序以持久化该配置。
