查找和使用数据

搜索

直方图 查找和使用数据 搜索面板使您可以轻松地将数据和对象拉入 Fusion。可以通过选择 查找和使用数据 框（位于 Fusion 工作表右上角）来访问搜索面板。

您可以直接在搜索输入区域（"搜索单元格或关键字"）中输入值进行搜索，也可以点击"目标"图标然后选择单元格值。

您还可以选择要搜索的特定对象类型或数据集。如果所选数据集未建立索引，系统将提示您为其建立索引。

导入数据

找到要导入的数据后，请选择 使用数据 并打开 导入数据 面板将其带入工作表，最多可导入 2,000 行。

直方图 导入数据 面板会将搜索结果中使用的任何筛选条件添加为导入查询的筛选条件。例如，如果您搜索 Red 并选择 使用数据 一组在 color 属性或列上匹配的汽车，您的初始查询将以如下形式开始：cars where color == red.

从这里您可以添加更多筛选条件，并最终将结果数据以数组、下拉列表或多选下拉列表的形式添加到工作表中。

数据集数组

以数据集数组形式导入会向工作表添加一个 lookup_array 函数。数据集数组不包含来自源的列名。请参阅 查找数据集 以了解有关如何使用查找的更多信息。

要展开来自 lookup的结果数组，您可以 Shift+拖动 该单元格，将其拆分为各个单独的单元格。

数据集下拉列表和数据集多选下拉列表

向工作表添加数据集下拉列表时，会为每个导入的列在单个单元格中放置一个单选下拉列表。数据集多选下拉列表的功能相同，但允许选择多个值。然后，您可以使用此下拉列表为工作表的其他部分提供支持。

可以对数据集下拉列表单元格应用格式设置，包括合并或调整单元格大小、设置字体大小以及设置背景填充。

导入对象

与数据集类似，如果对象不受受限视图支撑，您可以使用筛选条件来细化导入到工作表中的对象列表。筛选条件可以是值或单元格引用。单元格引用将根据单元格的值进行筛选，使您能够创建动态工作表，其中对象集将根据其他值或选择进行更新。在此示例中，底层数据来自 U.S. Census Bureau ↗.

在下方， City 对象类型具有一个筛选条件，其中 State 等于单元格 B2的值。当前单元格值为 Arizona，并筛选出 State is Arizona的城市。单元格值可以更改，这将更新筛选条件。

应用筛选条件后，您可以选择 重新加载 以查看生成的对象集。您可以将此对象集以对象下拉列表或对象表格的形式导入到工作表中。默认情况下，单个对象下拉列表或对象表格最多可以拉入 200 个对象。

对象下拉列表

将对象以下拉列表的形式添加到工作表时，会在单个单元格中放置一个下拉列表。您可以使用此下拉列表为工作表的其他部分提供支持。

对象下拉列表单元格将显示当前选定的对象以及对象图标。然后，您可以选择该单元格以打开下拉列表并选择另一个对象。

可以对对象下拉列表单元格应用格式设置，包括合并或调整单元格大小、设置字体大小以及设置背景填充。

对象表格

可以对对象表格进行格式设置以用于展示，或在工作表的其他地方使用。

对象下拉列表和对象表格可以组合起来创建一个简单的仪表板：为实现这一点，可以使用对象下拉列表来选择对象，这些对象随后可用作对象表格中的筛选器。

Fusion 工作表不能同时包含对象和数据集同步导出。如果您已有对象，系统将阻止您添加新的数据集同步，反之亦然。
