SAP Concur

SAP Concur 连接器是一种 由 Palantir 提供的驱动程序 ，用于 SAP Concur。

要创建新的 SAP Concur 源，请按照 Palantir 提供的驱动程序的标准设置流程，然后使用以下部分进行 SAP Concur 特定的配置和网络设置。有关完整的属性参考，请参阅 官方 SAP Concur 驱动程序文档 ↗.

测试版

SAP Concur 连接器目前处于 测试版 开发阶段，可能无法在您的注册租户中使用。功能在积极开发过程中可能会发生变化。

配置

以下属性为必填项或推荐项。

属性是否必填？描述默认值
Region ↗必填服务器所在的区域。有效值为 US、EU 和 CN。US
AuthScheme ↗推荐用于身份验证的方案。接受的条目为 OAuth、OAuthPassword 和 CompanyLevelAuth。OAuthPassword
ConcurInstanceURL ↗推荐要使用的服务器 URL。新的服务器 URL 与旧版身份验证方法向后兼容，因此仅在必要时进行设置。例如， https://us2.api.concursolutions.com 用于某些生产账户，而 https://us-impl.api.concursolutions.com 用于沙盒账户。—
InitiateOAuth ↗推荐网络GETANDREFRESH
LoginId ↗推荐用户的登录 ID。如果与 OAuth 2.0 访问令牌关联的用户账户具有以下角色之一的 Concur 账户，则可以使用：Professional 的 Web Services Administrator 或 Standard 的 Can Administer。—
OAuthClientId ↗推荐指定创建自定义 OAuth 应用程序时分配的客户端 ID。（也称为消费者密钥。）此 ID 用于向 OAuth 授权服务器注册自定义应用程序。—
OAuthClientSecret ↗推荐指定创建自定义 OAuth 应用程序时分配的客户端密钥。（也称为消费者机密）。此密钥用于向 OAuth 授权服务器注册自定义应用程序。—
Password ↗推荐用于对用户进行身份验证的密码。—
UserId ↗推荐SAP Concur 用户的唯一标识符。仅用于公开 SAP Concur API 的 V4 端点的表。—
Username ↗推荐用于向 SAP Concur 进行身份验证的用户账户。—
UseSandbox ↗推荐网络FALSE

为每个域名添加相应的 出口策略。如果该源托管在本地且无法从 Foundry 直接访问，请改用 代理出口策略 。代理主机本身也必须能够访问所列出的域。请参阅 使用代理作为代理服务器 了解详情。

域名必需

eu2.api.concursolutions.comIf UseSandbox=FALSE （默认）AND Region=EU
www-eu2.api.concursolutions.comIf UseSandbox=FALSE （默认）AND Region=EU - OAuth 授权 URL

OAuth 2.0 身份验证

此连接器支持 OAuth 2.0 身份验证。请按照 Palantir 提供的驱动程序的 OAuth 2.0 指南 来配置和授权连接。
