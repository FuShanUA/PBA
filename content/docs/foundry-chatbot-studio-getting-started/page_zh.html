开始使用

本指南将引导您在 AIP Chatbot Studio（原 AIP Agent Studio）中构建您的第一个 AIP Chatbot。您将打开该应用程序，创建并配置聊天机器人，对其进行测试，然后发布供其他人使用。

前提条件

开始之前，请确保你具备以下条件：

  • 您的注册中已启用 AIP 以及使用权限 用于自定义工作流的 AIP 功能，其中包括 AIP Chatbot Studio
  • 至少一个大语言模型（LLM） 您注册中已启用模型的一个子集
  • 在以下位置创建文件的权限： 项目 或文件夹（用于保存您的 AIP Chatbot）

访问 AIP Chatbot Studio

要打开 AIP Chatbot Studio：

  1. 在监听器设置向导的 工作区导航侧边栏 在平台左侧的 应用程序 以打开 应用程序门户.
  2. 输入 Chatbot 在搜索框中输入，然后选择 AIP聊天机器人工作室 从结果中。

或者，选择 搜索… 在侧边栏中，或按 Cmd+J （macOS）或 Ctrl+J （Windows）以打开 快速搜索。然后，输入 AIP Chatbot Studio 代码仓库 AIP聊天机器人工作室 结果。

如果 AIP Chatbot Studio 未出现在您的搜索结果中，您可能无权访问它。请让您的平台管理员查看 先决条件 和 应用程序访问 你的注册的设置。

AIP Chatbot Studio 打开后会显示主页，其中列出了您最近打开的聊天机器人以及参考示例。要查看您可以访问的所有聊天机器人，请选择 所有.

创建 AIP Chatbot

AIP Chatbot 作为文件保存在项目或文件夹中，并且与平台中的其他资源一样具有细粒度的访问控制。

要创建 AIP Chatbot：

  1. 在 AIP Chatbot Studio 主页上，选择 新建 AIP Chatbot 在右上角。

  2. 选择默认名称（My New Chatbot 后跟时间戳）并为您的聊天机器人输入名称。您可以选择添加描述和头像图片，以契合您的应用场景。您的聊天机器人的用户会看到这些详细信息。如果您不添加头像，AIP Chatbot Studio 将使用灰色机器人图标。

  3. 自动预览行为 保存位置，然后使用 选择一个位置。在 选择项目或文件夹 对话框中，从 位置 下拉菜单中选择一个项目或文件夹，或选择 浏览 以导航到相应位置。然后，选择 保存。如果您没有合适的位置，并且您拥有 创建项目的权限中，选择 浏览，然后选择 + 创建新项目.

  4. 选择 创建聊天机器人 在右下角。在您选择保存位置之前，此按钮不可用。您的新聊天机器人将在 AIP Chatbot Studio 编辑器中打开。

您也可以直接从项目中创建 AIP Chatbot。在以下位置打开项目或文件夹： 文件，然后选择 + New > AIP Chatbot.

或者， 在 AIP Threads 中创建 AIP Chatbot.

设置 AIP Chatbot

编辑器左侧包含一列图标，用于打开不同的面板。将鼠标悬停在图标上可查看其名称。您可以使用以下面板来设置您的聊天机器人：

  • 聊天机器人配置： 选择模型、编写指令，并添加您的聊天机器人可以使用的信息和工具。
  • 对话设置： 自定义对话体验，例如用户开始对话时看到的提示。

编辑器中央的聊天面板让您可以 测试您的聊天机器人 同时进行配置。

编辑器打开时会显示在 监控 面板上。要开始设置您的聊天机器人，请选择 聊天机器人配置.

选择大型语言模型（LLM）

自动预览行为 模型设置，从 模型 下拉菜单中选择一个模型。您可用的模型是以下模型的子集： 您注册中已启用模型的一个子集。您的聊天机器人的用户也应有权访问此模型。

设置温度

使用直方图中的 温度 滑块来确定专注且确定性的输出（默认值 0）与更随机的输出（最大值 1).

添加信息和工具

AIP Chatbot 可以仅使用其模型和指令进行响应。要让其响应基于您企业的信息，或让其执行操作，请在以下位置添加以下任意内容： 聊天机器人配置 面板中绑定到 Workshop 变量和事件:

  • 检索上下文: 选择 添加检索上下文 以在每条消息中包含相关的本体论对象、文档或函数输出。检索上下文简单、快速，推荐用于大多数用例。请确保聊天机器人的用户有权访问所配置的检索上下文，以避免运行时出现错误。
  • 工具: 选择 添加工具 以让聊天机器人查询对象、运行函数、执行操作等。对于复杂且需要执行操作的聊天机器人，请使用工具。
  • 应用状态: 选择 添加变量 以在聊天机器人部署到 来运行该专业代码代理。你还可以通过 或外部应用程序时为其提供状态。

添加对话开场白

要针对您预期的工作流自定义聊天机器人，请选择 对话设置 （位于编辑器左侧）。在 对话指南下，在 输入占位符 字段中输入文本，并在 起始提示下添加示例提示。用户在开始对话时会看到这些内容。

测试您的 AIP Chatbot

要测试您的聊天机器人，请在编辑器中央的聊天面板中输入消息。聊天面板使用您当前的配置，包括尚未保存的更改。要 查看聊天机器人如何生成回复，请展开回复上方的推理步骤，或选择回复下方的 展开所有推理步骤 图标。

保存、查看和发布 AIP Chatbot

当您对聊天机器人的回复感到满意时，请保存并发布它：

  1. 选择 保存 （位于编辑器右上角）。要为保存的版本添加描述，请选择旁边的向下箭头 保存，然后选择 保存并添加描述.

  2. 选择 发布 以使您的聊天机器人可在生产环境中使用。 发布 及其旁边的发布设置图标在您有未保存的更改时不可用。

要以最终用户的视角查看您的 AIP Chatbot 的实际运行情况，请选择 要在标记和发布函数的过程中查看进度，请选择 并选择所需的版本。

要授予其他用户访问您的聊天机器人的权限，请选择 共享 （位于编辑器右上角）。如果您的项目仅允许 在项目级别授予角色，请改为在项目上为用户授予角色。用户还需要访问您的聊天机器人所使用的模型和数据源。

您还可以 将您的聊天机器人发布为函数，这允许您通过 发布后，我们建议在 和 AIP 评估运行它。为此，请选择旁边的发布设置图标 发布中，选择 从聊天机器人发布函数，选择一个本体论，并输入函数详细信息。然后，选择 发布聊天机器人和函数.

跟踪 AIP Chatbot 反馈和使用情况

发布聊天机器人后，使用编辑器左侧的面板了解它的使用情况：

  • 监控： 查看会话数和用户数，以及用户标记为有帮助或无帮助的会话百分比。用户通过在对话中点赞或点踩来提供此反馈。
  • 用法： 查看您的聊天机器人在哪些地方被使用，例如在 Workshop 应用程序、自动化流程和外部部署中。您还可以开启 AIP Assist 以使最新发布的版本在 AIP Assist.
