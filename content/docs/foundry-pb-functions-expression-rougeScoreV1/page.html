ROUGE score

Supported in: Batch

Computes ROUGE precision, recall, and F-measure for predicted and target text. Text is lowercased; only ASCII letters and digits are compared. All other characters are treated as word separators. Returns null if either input is null or the text cannot be scored, including when it exceeds the scorer's size limits.

Expression categories: Distance measurement, String

Declared arguments

  • Prediction: The machine-generated text to evaluate.
    Expression<String>
  • ROUGE type: The ROUGE variant used to compare the texts.
    Enum<ROUGE-1, ROUGE-2, ROUGE-3, ROUGE-L, ROUGE-Lsum, ROUGE-Lsum (detected sentences)>
  • Target: The reference text to compare against.
    Expression<String>
  • optional Use stemmer: Stem words before comparing them.
    Literal<Boolean>

Output type: Struct<precision, recall, fmeasure>
