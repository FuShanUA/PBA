Platform announcements

Platform announcements let administrators share messages across an organization or with selected recipient groups. You can configure each announcement's intent (info, warning, or critical) to match your message, as well as how it appears when users first see it and after they have read it.

Manage announcements

You can configure announcements in the Notifications application at https://<your-foundry-url>/workspace/notifications/. The Manage announcements button in the application header is enabled only for announcement administrators.

Required permissions

You are an announcement administrator for an organization if you have the Manage announcements workflow for that organization. You can grant this workflow through a role in the Organization permissions settings in Control Panel. Learn more about organization permissions and roles.

To create, publish, or revoke an announcement, you must have the Manage announcements workflow for all recipient organizations.

Create announcements

To create an announcement, select Manage announcements > Create announcement.

Content

Every announcement has a title and a body. The body supports a subset of Markdown formatting, including bold, italics, and links.

Appearance

Announcement settings include initial appearance, persistent appearance, intent, and an expiry date. The appearance settings control how the announcement is displayed at two stages:

  • Initial appearance: How the announcement appears when a user first sees it.
  • Persistent appearance: How the announcement appears after a user has read it.

Appearance options include an indicator, a banner, and a blocking pop-up dialog. The dialog requires users to acknowledge the announcement by selecting a button.

You can also configure the announcement's intent as info, warning, or critical. The intent determines its visual styling to match the nature of your message.

Every announcement has an expiry date. After it expires, the announcement is no longer actively displayed using its configured appearance. It remains accessible to its selected recipients in the notifications application.

Recipients

You can send announcements only to recipients in organizations for which you have the Manage announcements workflow. A user can receive an announcement only if their primary organization is one of the selected recipient organizations.

You can further limit recipients by selecting groups within the recipient organizations. Group selection only narrows the audience; it never includes users whose primary organization is outside the selected recipient organizations.

Publish or revoke an announcement

An announcement is shown to recipients only after you publish it. You can undo publication by revoking the announcement, which removes it from recipients' view.

To publish or revoke an announcement, you must have the Manage announcements workflow for all recipient organizations. See required permissions.

View announcements

As a recipient, you can view published announcements according to the appearance settings chosen by the administrator. If an announcement appears as a dialog, select its acknowledgment button to continue.

You can view all published announcements for which you are a recipient in the notifications application at https://<your-foundry-url>/workspace/notifications/, including expired announcements. Expired announcements remain available there even though they are no longer actively displayed using their configured appearance.

The announcements indicator is only visible when you are a recipient of an active announcement: one that is published and has not expired.
