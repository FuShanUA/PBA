创建转换

可以在代码仓库中使用文件模板配置向导来创建转换。该向导使您能够选择转换类型，然后通过为转换所需的变量（例如输入或输出数据集）提供值来引导创建一个最小示例。

要开始使用该向导，请创建新的 Python 转换仓库。该向导将自动打开。在现有仓库中，可以通过选择 “添加” ，然后选择 “从模板新建文件” （位于“文件”侧面板中）来打开该向导。

打开该向导后，系统将提示您选择模板。每个模板都代表一种转换类型。其中提供了图示和说明，以帮助您对比不同选项之间的差异，并为您的用例确定正确的选择。可用模板包括：

  • 轻量级转换： 通常建议用于处理少于 1000 万行数据集的转换。
  • Spark 转换： 利用分布式计算，为处理超过 1000 万行数据集的转换提供更佳的性能。

选择模板后，请选择 “下一步” 以打开模板配置页面。在此，您可以通过提供所需的值并从整个 Foundry 中选择资源来配置模板。此页面会根据当前配置显示转换的实时预览；修改任何输入或输出变量都会更新预览。您的配置在此阶段会自动进行验证，在创建转换之前必须先解决所有错误。

常见的验证错误包括：

  • 使用来自不同项目的资源： 输入和输出资源必须与仓库位于同一项目中。
  • 参数名称重复： 转换中的所有参数名称必须唯一。
  • 未提供必需的参数： 某些模板需要至少一个输入或输出变量。请提供有效的变量值以解决此错误。

配置有效后，您将能够通过选择 生成文件来创建您的转换。这将在您的仓库中创建一个新文件，其内容与配置页面预览中显示的内容一致。如果模板需要特定的支撑依赖项或库，系统将自动对其进行配置，以确保您的转换正确运行。
