防范恶意文件

大多数 IT 和安全团队都会维护工具和控制措施，以防止计算机上出现恶意文件。此类控制措施通常包括基于网络或基于终端的扫描和监控，并且理想情况下应覆盖您的整个 IT 足迹（用户工作站、管理系统、服务器等）。

当您的团队开始使用 Foundry 同步和存储文件时，务必将 Foundry 也纳入恶意文件和恶意软件防护的范围。

Foundry 控制措施

Foundry 是一个大规模数据平台，具有无限的用例和潜在功能。因此，Foundry 不会对上传某些具有潜在风险的文件或文件类型（如可执行文件）施加一刀切的限制。相反，Foundry 已部署安全措施，可以安全地支持可能需要不受限制上传的用例。

Foundry 中针对文件上传的安全控制措施包括：

  • 对上传端点实施二进制执行限制。
  • 上传服务的进程隔离，防止权限提升或横向移动。
  • 对前端导入实施文件大小限制。

其他建议

尽管 Foundry 基于平台的文件控制措施可以有效缓解恶意文件带来的风险，但 Foundry 是 共享安全责任模型的一部分，我们的安全工程师建议 Foundry 客户在其环境中维护额外的安全控制措施，以防止恶意软件的传播：

  • 客户系统应运行信誉良好且最新的反恶意软件工具。
  • 反恶意软件工具最好能提供定期扫描和实时检测功能。
  • 客户应强制使用大多数主流网络浏览器中内置的恶意软件防护功能。
