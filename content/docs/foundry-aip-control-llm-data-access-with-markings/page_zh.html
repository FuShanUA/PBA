使用标记控制 LLM 数据访问

注册管理员可以配置哪些 强制标记 允许用于对 AIP 语言模型的请求。使用此策略可防止模型接收来自 Foundry 会话的请求，这些会话可以访问受已批准集合之外的强制标记保护的数据。该策略适用于交互式 AIP 使用和自动化工作流。

允许的标记如何运作

注册策略适用于每个 Palantir 提供的模型系列。它也是没有模型特定策略的已注册模型的默认策略。

直方图 数据访问 设置提供以下选项：

  • 允许任何数据： 不基于强制标记访问限制请求。
  • 仅允许以下标记： 仅当请求令牌可用的每个强制标记都包含在配置的允许列表中时，才允许请求。

允许列表不要求请求中的数据带有选定的标记之一。没有强制标记的请求令牌可通过此检查。

配置允许列表时，AIP 会评估用户当前 Foundry 会话中可用的所有强制标记（如请求令牌上所示）。相同的令牌级检查适用于自动化工作流。如果令牌包含允许列表之外的任何强制标记，AIP 将拒绝该请求，即使请求中包含的数据没有该标记。

例如，考虑一个允许标记 A 和 B:

允许的标记请求令牌可用的强制标记结果原因
A, B无允许令牌没有允许列表之外的强制标记。
A, BA允许A 包含在允许列表中。
A, BB允许B 包含在允许列表中。
A, BA, B允许每个强制标记都包含在允许列表中。
A, BA, C拒绝C 未包含在允许列表中。

如果用户的会话包含的强制标记多于模型策略允许的数量，用户可以选择一个 限定范围的会话 来限制其会话中可用的标记。当限定范围的会话不包含模型允许列表之外的强制标记时，请求将通过此数据访问检查。

配置注册策略

要为 Palantir 提供的模型和没有模型特定策略的已注册模型配置默认策略：

  1. 在 Control Panel 中，打开 AIP 设置 extension.
  2. 在 AIP 设置 选项卡，找到 数据访问 section.
  3. 选择 允许任何数据 or 仅允许以下标记.
  4. 如果您选择了 仅允许以下标记中，选择 编辑，选择至少一个强制标记，然后选择 保存您的更改。.
  5. 保存您的更改。

保存允许列表策略之前，必须至少选择一个强制标记。

配置已注册模型覆盖

直方图 数据访问 步骤在注册或编辑模型时是可选的。没有模型特定策略的已注册模型使用注册策略。如果配置模型特定策略，它将完全取代注册策略，并且可以更严格或更宽松。

已注册模型设置生效策略
未配置使用注册策略。
允许任何数据允许任何数据，即使注册策略有允许列表。
仅允许以下标记仅允许选定的强制标记，无论注册允许列表如何。

要配置覆盖：

  1. 在 Control Panel 中，打开 AIP 设置 扩展，并选择 已注册模型 tab.
  2. 注册一个模型，或选择一个现有模型并选择 编辑.
  3. 转到 数据访问 step.
  4. 选择 允许任何数据 or 仅允许以下标记.
  5. 如果您选择了 仅允许以下标记中，选择 编辑，选择至少一个强制标记，然后选择 保存您的更改。.
  6. 保存您的更改。
