函数

函数 使代码编写者能够编写可在运营场景中快速执行的逻辑，例如旨在为决策流程赋能的仪表板和应用程序。此类逻辑在服务器端的隔离环境中执行。

值得注意的是，函数为基于本体论编写逻辑提供一流支持。这包括支持读取各种对象类型的属性、遍历关联，以及灵活地进行本体论编辑。

函数的常见用例包括：

  • 返回对象集或变量值，以用于 Workshop。
  • 在派生表格列中显示转换后的值，使用 Workshop 的函数支持列。
  • 聚合对象类型的值以显示为 Workshop 图表。
  • 表达对本体论的复杂编辑以更新多个对象，可借助 函数支持的操作。
  • 在后端运行逻辑以返回要在前端显示的信息，使用 Slate。
  • 计算自定义指标或聚合，以显示在 Quiver。
  • 查询外部系统以丰富本体论中的对象，可借助 外部函数。
  • 通过增量流式传输结果来实现实时体验，尤其适用于 语言模型。
  • 将 Python 函数用作边车容器，运行于 Pipeline Builder。

函数支持的语言为 TypeScript ↗ 和 Python ↗。

有关各语言的功能支持以及选择语言或语言版本的更多信息，请参阅 语言功能支持规范。
