类型类

类型类可以应用于属性、链接类型和操作类型。除了 analyzer 类型类种类（会影响 索引 行为）之外，类型类还定义了额外的元数据，可由与本体论交互的用户应用程序进行解释。例如，某些 hubble 属性类型类的规范会影响属性值在 对象视图.

下表提供了已知类型类的列表。该表中的列如下所示：

  • 直方图 已弃用 列指示某个类型类是否仍受支持。
    • 直方图 已弃用 列还指示某个类型类现在是否应在 功能 page.
      • 在本体论管理器中，对象类型现在具有一个 功能 页面，用于配置历史上定义为类型类的功能。所有受支持的类型类的配置都将迁移到 功能 page.
  • 直方图 类型 列指示类型类是应用于属性、链接类型（以前称为关系）还是操作类型。
  • 直方图 种类 and 名称 列包含来自两个用户自定义字段的字符串值，这些字段是在本体论管理器中添加类型类时设置的。这些值由 Foundry 产品用于标记类型类。
  • 直方图 描述 列描述了用户应用程序在与已添加所列类型类的属性值、链接或操作交互时的预期行为。
    • 对象浏览器 是一个使用 hubble 类型类的应用程序。
    • 的流可在 是一个使用 timeseries 类型类的应用程序。
