类型类

类型类可应用于属性、关联类型和操作类型。除了 analyzer 类型类的种类会影响 索引 行为之外，类型类定义的是附加元数据，可供与本体论交互的用户应用程序进行解读。例如，某些 hubble 属性类型类的规范会影响属性值在 对象视图中的呈现方式。

下表列出了已知的类型类。此表中的各列如下：

  • “ 已弃用 ”列指示类型类是否仍受支持。
    • “ 已弃用 ”列还指示类型类现在是否应在 “功能” 页面中进行配置。
      • 在 Ontology Manager 中，对象类型现在拥有一个 “功能” 页面，用于配置以往被定义为类型类的功能。所有受支持的类型类的配置都将迁移至 “功能” 页面。
  • “ 类型 ”列指示类型类是应用于属性、关联类型（以前称为 relation）还是操作类型。
  • “ 种类 ”和“ 名称 ”列包含来自两个用户自定义字段的字符串值，这两个字段是在 Ontology Manager 中添加类型类时设置的。Foundry 产品会使用这些值来标记类型类。
  • “ 描述 列描述了当用户应用程序与已添加所列类型类的属性值、关联或操作交互时的预期行为。
    • Object Explorer 是一个使用 hubble 类型类的应用程序。
    • Quiver 是一个使用 timeseries 类型类的应用程序。
