Foundry 数据集 ODBC 驱动程序

要安装该驱动程序，请下载下方由 Palantir 签名的安装程序文件，并按照屏幕上的说明操作。请参阅 ODBC 设置指南 以获取配置 Foundry 连接的更多说明。

此安装程序支持 Windows 64 位。目前不支持 Windows 32 位、Mac 和 Linux。

结果预览默认为1000行。在SQL Studio中，用户可以从设置菜单将预览限制扩展到10000行。

  • Foundry ODBC 驱动程序 3.41.0（Windows x64）↗

Foundry 数据集 JDBC 驱动程序

要安装该驱动程序，请下载下方的 .jar 文件，并按照特定应用程序文档中的说明将其放置到您计算机上的相应目录中。请参阅 JDBC 设置指南 以获取配置 Foundry 连接的更多说明。

需要 Java 11 或更高版本。

结果预览默认为1000行。在SQL Studio中，用户可以从设置菜单将预览限制扩展到10000行。

  • Foundry JDBC 驱动程序 3.41.0（JRE 11+）↗

Foundry 数据集 Tableau 连接器（2021.1+）

Foundry 数据集 Tableau 连接器是由 Palantir 签名的 Tableau 连接器，此处以 Tableau 连接器（.taco）包文件的形式提供。

该连接器也可在 Tableau Exchange ↗ 上获取。Tableau Exchange 上列出的版本与下方链接中的版本没有区别。

结果预览默认为1000行。在SQL Studio中，用户可以从设置菜单将预览限制扩展到10000行。

  • foundry-jdbc-2.6.0.taco ↗

Foundry 数据集 Tableau 连接器

如果您的 Tableau 版本介于以下版本之间，请使用此版本的连接器： 2019.4 和 2021.1。此版本提供与上述版本相同的功能，但仅支持令牌身份验证（不支持 OAuth），并且必须通过 RID/路径而非搜索来加载数据集。
