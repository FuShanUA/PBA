操作指标

操作指标显示过去30天内某种操作类型的近实时使用情况。您可以通过 本体论管理器中的操作类型概览页面，或在 工作流血缘 中选择特定执行的操作节点来访问这些指标。以下指标可用：

  • 成功/失败指标： 通过成功和失败计数监控您的操作当前状态。这有助于快速识别问题并支持主动排查，使您能够在故障发生时立即处理。
  • P95 时长指标： 跟踪每种操作类型的第95百分位（P95）执行持续时间。此指标突出显示执行时间的上限，帮助您检测性能瓶颈，并优化工作流程以实现一致且高效的运行。
