探索数据血缘

数据血缘可帮助您了解数据的来源。在 Data Lineage 应用中有多种方式可以探索数据管道。请考虑以下常见路径：

  1. 使用 搜索 辅助工具，找到您的资源（例如数据集或对象类型）并将其添加到图表中。

  2. 点击节点左侧的箭头以显示该资源的直接父级。

  1. 要扩展图表，请在图表上选择下一个资源并点击 图表工具 图表工具中的按钮。

  2. 点击 V 形按钮可定义要显示的层级数。点击双 V 形按钮可一直展开到原始数据（或一直展开到最终的下游资源）。

同时添加过多节点可能会影响图表的性能和可用性。请通过检查 图表工具 工具中的节点数量，将节点保持在可管理的数量。

您可以通过选择 图表工具 按钮并添加两个资源之间的所有节点或所有共同祖先/下游资源，来查找图表中两个节点之间的关系。

  1. 通过选择数据集并使用底部面板显示数据预览，获取有关某个数据集的更多信息。

  2. 点击 选项卡，选择 以查看该数据集是如何创建的。

  1. 点击 在 Code Workbook 中查看 or 在代码仓库中查看 以查看原始代码并根据需要进行更改（需具备相应权限）。

某些选项可能因资源类型而异，对某些数据集不可用。例如， 选项卡，选择 仅适用于 Code Workbook 或代码仓库。对于没有代码可显示的 Fusion 工作表同步，您可以选择查看源工作表并在其中进行更改（如果您具有相应的权限）。
