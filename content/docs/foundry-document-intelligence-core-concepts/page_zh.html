核心概念

传统提取

传统提取配置基于并非由大语言模型支撑的算法，例如 PDF 元数据提取、光学字符识别（OCR）检测和布局检测。AIP Document Intelligence 中的这些配置由 transform media item 端点提供支持。

详细了解如何在 AIP Document Intelligence 中使用文档提取媒体转换。

预处理

对于处理更复杂文档的用例，将 VLM 与预处理技术相结合已被证明相当成功。在 配置 > 生成式 AI，开启 预处理文档。文档预处理实质上会对文档运行传统的 OCR（光学字符识别），然后会将该输出 连同 文档页面本身一同传递给 VLM，从而为模型提供更多上下文，以便成功分析文档。

评估

目前，只有当您的注册环境中可以使用 Anthropic Claude 4 Sonnet 时，您才能执行提取评估。

对于提取策略的每次运行，您都可以选择查看定性评分标准，该标准会利用您所选的 VLM 作为评判者。我们对提示词进行了微调，以便将各个方面按 1（最差）到 5（最佳）进行排名，包括给定策略对表格、表头等内容的提取效果。评估功能可让您在测试不同提示词和策略时快速迭代并做出判断。

部署路径

当您对某个特定策略感到满意后，便可将其部署到批量管道中，以便在更广泛的数据集上运行。目前，我们仅支持 Python 转换部署路径。

Python 转换

您可以将策略导出为完全动态的 Python 转换仓库模板；数据集 RID/路径、模型 RID/路径、自定义提示词以及所选配置均会自动完成配置。我们建议您在触发构建之前先验证这项工作。
