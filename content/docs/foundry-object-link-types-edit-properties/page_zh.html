编辑对象类型属性

删除属性

在属性编辑器的属性窗格中，将鼠标悬停在要删除的属性上，然后选择 删除属性。

  • 请注意，属性的删除仅在保存更改后才会生效，并且会导致引用该属性的任何视图或应用程序出错。
  • 具有 active 状态的属性 无法 删除。
    • 详细了解 状态。

更改支撑属性的列

在属性编辑器的属性窗格中，将鼠标悬停在要取消映射的属性上，然后选择 取消关联属性。要将属性关联到新列，请将鼠标悬停在该属性上，然后选择 映射到列。

编辑属性类型的元数据

您可以通过选择属性类型来编辑该属性类型的元数据，如下图所示。

编辑属性元数据的可用选项分为四个不同的选项卡，这些选项卡可用于访问以下配置：

  1. 显示名称和描述： 选择现有的显示名称或描述即可编辑文本。
  2. 状态： 选择现有状态以打开可用状态的下拉列表。从 deprecated、 experimental和 active 状态中进行选择。
    • 详细了解 状态。
  3. API 名称： 选择现有 API 名称以更改其值。
    • 请注意，您 无法 更改处于 active 状态的属性的 API 名称。
      • 阅读有关 状态的更多信息。
      • 阅读有关 有效 API 名称的更多信息。
  4. 键： 指示属性是否为对象类型的标题键或主键。
    • 请注意，您 无法 更改处于 active 状态的对象类型的主键。
      • 阅读有关 键 以及 状态的更多信息。
  5. 值格式化： 对属性值应用特殊格式化器，使其在应用程序中更易于阅读。
    • 阅读有关 值格式化器的更多信息。
  6. 条件格式： 对属性应用规则，以指定其在应用程序中的渲染方式。
    • 阅读有关 条件格式的更多信息。
  7. 属性基础类型： 从下拉列表中选择属性的基础类型。属性的类型限制了可对其值执行的操作集合。
    • 例如，基础类型为 timestamp 的属性可显示在 Object Explorer 的时间轴小组件中。
    • 如果属性的类型与其支撑列的类型不兼容，您将收到错误。

如果您更改了对象属性类型，则还必须更新与该对象上的属性交互的操作所预期的类型。为此，请在 Ontology Manager 中打开该操作并编辑预期的类型。

  1. 类型类： 将类型类应用为可由应用程序解释的附加元数据。
    • 请参阅 类型类文档 以获取可用类型类的列表。
  2. 渲染提示： 从提供的清单中选择要应用于属性的渲染提示，以改进属性值渲染和索引到 Object Storage v1 (Phonograph) 中的方式。
    • 请参阅 渲染提示文档 以获取可用渲染提示的说明。
  3. 可见性： 选择当前的可见性设置，以打开包含可用可见性选项的下拉列表。 prominent 属性将使应用程序优先向用户显示该属性。 hidden 属性不会出现在用户应用程序中。

更改属性元数据后，请对受影响的对象启动重新索引，以更新本体论。

批量编辑多个属性

您可以在属性编辑器中按住 Cmd/Ctrl 键的同时选择多个属性。选中多个属性后，即可使用以下批量编辑操作：

  • 更改基础类型。
  • 添加/移除类型类。
  • 更改渲染提示。
  • 更改可见性。
  • 添加/移除值格式化。

您还可以在属性编辑器外部批量编辑上述部分字段，方法是选择 属性 页面（位于对象类型视图的侧边栏中）。只需勾选要编辑的属性旁边的复选框，表格顶部就会出现一个包含批量编辑选项的新行。
