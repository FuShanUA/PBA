故障排除

本页面包含在使用适用于 Visual Studio Code 的 Palantir 扩展时可能遇到的问题的故障排除提示。

Code Workspaces 错误

Palantir 平台中的 VS Code 使用 Code Workspaces 基础设施；请参阅 Code Workspaces 故障排除页面 的文档以获取更多信息。

VS Code Workspace 无法加载或显示空白屏幕

如果 VS Code 无法加载或仅显示空白屏幕，可能是浏览器缓存的问题。在这种情况下，请对浏览器页面执行强制重新加载以解决您的问题。

  • 按住 Cmd （macOS）或 Ctrl （Windows），然后选择 重新加载.
  • 用途 Cmd+R （macOS）或 Ctrl+R （Windows）以重新加载。
  • 在 Chrome 中，打开 开发者工具 面板，方法是导航到 View > Developer > Developer Tools 或使用 F12 键。然后，右键单击 重新加载 搜索栏左侧的按钮，并选择 清空缓存并强制重新加载.
