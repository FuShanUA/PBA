Pipeline Builder 是 Foundry 的主要应用程序，可在提供稳健性和安全性的同时，快速、灵活且可扩展地交付数据管道。借助 Pipeline Builder，最终用户和数据工程师可以在图形和表单环境中协作，集成数据、创建业务逻辑转换，并为生产管道定义严格的发布流程。用户无需编写代码即可构建提供实时反馈的管道。此外，Pipeline Builder 使用健康检查，确保只有完全合规的数据才会被部署到生产环境。 了解有关 Pipeline Builder 的更多信息。

代码仓库

Code Repositories 提供基于 Web 的集成开发环境 (IDE)，用于在 Foundry 中编写生产就绪的代码并进行协作。该应用程序提供了一种用户友好的方式来与底层 Git 仓库进行交互。 了解有关 Code Repositories 的更多信息。

最佳实践

我们建议在 Pipeline Builder 中构建您的管道设计。这样做可以：

  • 通过易于理解的点击式界面，实现不同用户组之间的协作。
  • 利用 Pipeline Builder 的安全护栏进行安全且高效的数据转换和管道管理，从而保障管道健康。

当用户需要 Pipeline Builder 中不提供的基于代码的专用逻辑时，应使用 Code Repositories 创建这些阶段并添加到主管道中。此类专用场景的一些示例包括：

  • 进行 API 调用
  • 使用自定义库
  • 添加基于代码的逻辑概念

由于 Pipeline Builder 和 Code Repositories 都使用 Foundry 数据集作为输入和输出，因此在 Code Repositories 中构建的管道输入可以添加到 Pipeline Builder 中管道的前面、后面或中间。无论使用哪个应用程序创建管道，都可以在 Data Lineage 中为整个管道配置调度和健康检查。 了解有关 Data Lineage 的更多信息。
