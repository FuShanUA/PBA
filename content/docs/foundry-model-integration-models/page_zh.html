在 Foundry 中， 模型 是一种用于推理的工件，包含机器学习、预测、优化、物理模型或业务规则。在某个用例中，模型对您的数据进行编码以创建预测并支持决策。

在 Palantir 内部开发或集成到 Palantir 中的模型提供：

  • 完整的版本历史、细粒度的模型权限管理、自动依赖管理、模型血缘以及 API 管理
  • 通过 模型部署
  • 实现实时推理的无代码托管，以及无代码批处理和 流式推断 通过 Pipeline Builder 训练模型节点
  • 在数据管道中实现，以及通过 《建模目标》 application
  • 与 Foundry 本体论绑定，支持通过以下方式进行运营化： Foundry 应用, 模型上的函数日 场景 infrastructure.
  • 在 中的依赖项和操作探索 工作流血缘，包括使用已训练模型的函数及其实时部署 API、健康状态、日志和指标

架构

实现运营化。Palantir 中的模型资源由两个相关但不同的组件组成：

  1. 模型产物： 模型权重 or 容器，用于保存训练好的模型。
  2. 模型适配器: 描述平台如何与 模型产物 交互，以加载、初始化模型并使用模型执行推理的逻辑和环境依赖项。

适配器作为 Python 库的一部分发布，以便与存储的模型工件进行通信。它使平台能够加载、初始化任何类型的模型并对其运行推理。适配器设计灵活，可用于封装 Foundry 中支持的各种模型类型：

  • 在 Foundry 中训练的模型，位于 代码仓库, Jupyter 代码工作区，或 Model Studio
  • 手动上传的 模型文件或检查点
  • 链接进行访问。 以容器形式上传
