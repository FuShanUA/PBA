导入对象、接口和关联类型

您希望在函数中使用的任何对象、接口或关联类型，都必须导入到您的代码仓库所在的项目中。选择 资源导入 侧边栏，以查看已导入到项目中的对象类型。

您的组织可能没有 Airport 和 Flight 对象。在按照这些步骤操作时，请使用您有权访问的任何对象类型。

要导入其他对象类型，您需要选择 添加 按钮，该按钮位于 资源导入 选择本体论后，将出现一个搜索模态框。您的本体论将取决于组织中可用的对象类型。首先，选择几个对象类型以及连接它们的关联类型。本示例将导入

和 Airport 和 Flight 对象，以及它们之间的关联类型。

您还可以通过选择 接口 来导入本体论接口，该选项位于 添加 按钮下方。

选择 保存 以将本体论类型导入到项目中。Code Assist 将自动重启以重新生成代码绑定，从而反映您导入的新对象和关联类型。

现在，您可以在代码中从 @foundry/ontology-api 包中导入本体论类型。如果您使用的是私有本体论，包名将改为 @foundry/ontology-api/<ontology-api-name>。

Code Assist 启动后，若要查看所有可用的对象类型，您可以使用 Ctrl + 点击 @foundry/ontology-api 包名。打开的 index.ts 文件显示了可导入到代码中的所有有效对象类型：

如果您有权访问多个本体论，可以使用选择器来选择要使用的本体论。目前，尚不支持将多个本体论导入到单个项目中。
