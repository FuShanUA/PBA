应用程序指标 [Beta]

Beta

应用程序指标目前处于 Beta 开发阶段，您的注册环境中可能无法使用此功能。在开发过程中，功能可能会发生变化。

应用程序指标通过一组图表提供有关应用程序性能随时间变化情况的洞察。这些图表包括随时间推移的请求数量、请求成功率，以及与您所调用的 API 端点相关的延迟。

在 Developer Console 中，从左侧菜单导航至 指标 页面，以查看有关 OSDK 使用情况的指标。

目前，指标存在约 24 小时的延迟，并支持查看最多过去 30 天的历史数据。

您必须使用 受支持的 OAuth 流程 之一，才能为您的应用程序收集指标。使用在此 OAuth 流程之外生成的 API 令牌进行的 API 调用，将不会被收集到您应用程序的指标中。例如，如果您在 TypeScript 或 Python 中使用 UserTokenAuth 进行连接，则您通过此客户端发起的调用将不会显示在指标应用中。但是，如果您使用 PublicClientAuth 或 ConfidentialClientAuth进行连接，则您的调用将显示在 Developer Console 中。

配置时间段

您可以使用顶部导航栏中的时间范围选择器来配置指标显示的时间段。可用的预设选项包括一天、两天、七天、14 天和 30 天。您还可以选择 “自定义” 下拉菜单，以选取过去 30 天内的任意时间段。

查看时间段为五天或更短的指标时，数据点会按小时分桶显示。当时间段超过五天时，数据点则会按天分桶显示。

API 延迟

“延迟” 卡片可让您查看您的 OSDK 发起的 API 调用延迟的第 50、75、95 和 99 百分位数。
