transforms.api.LightweightOutput

class transforms.api.LightweightOutput(alias, rid, branch=None)

在运行时传递给用户代码的输出对象。

其目的在于模拟 transforms.api.TransformOutput API 的一个子集，同时提供对底层 foundry.transforms.Dataset的访问。

属性 alias

该参数所关联的数据集的别名。

arrow()

包含数据集完整视图的 PyArrow 表。

属性 branch

该参数所关联的数据集的分支。

dataframe()

包含数据集完整视图的 pandas DataFrame。

filesystem()

访问文件系统。

构造一个 FoundryDataSidecarFileSystem 对象，用于直接访问数据集的文件。

pandas()

包含数据集完整视图的 pandas DataFrame。

path()

下载数据集的底层文件并返回指向这些文件的路径。

属性 path_for_object_store_write_table

返回指向存储桶的虚拟对象存储路径，该存储桶将被映射到输出事务中。此路径并非直接指向云存储中的存储桶，而是指向本地 S3 代理，以允许查询引擎对数据执行异步且经过优化的 IO。

属性 path_for_write_table

返回数据集文件的路径，以便与 write_table一起使用。

polars(lazy=False)

包含数据集完整视图的 Polars DataFrame 或 LazyFrame。

  • 参数： lazy (bool ↗ , 可选) – 是否返回 LazyFrame 或 DataFrame。默认为 False.

put_metadata(column_descriptions=None)

在上传原始 Parquet 文件后完成数据集最终化的方法。此方法将从上传的 Parquet 推断并上传 Foundry Schema（如已存在则会覆盖），并更新数据集上的列描述元数据。

必须在一个或多个 Parquet 文件上传到输出数据集之后调用此方法，以便推断 Schema。如果在文件成功上传之前调用此方法，则会抛出错误。

  • 参数： column_descriptions (Dict [str ↗ , str ↗ ] , 可选) – 列名与其字符串描述的映射。此映射会与 DataFrame 的列求交集，且所包含的描述长度不得超过 800 个字符。

read_unstaged_dataset_as_polars_lazy()

将数据集的本地版本读取为 Polars LazyFrame。

此方法用于在数据集上计算期望（expectations）。这必须在数据集提交之前完成，因为期望失败时可能会导致构建中止。

属性 rid

此参数所关联数据集的唯一资源标识符。

set_mode(mode)

设置输出数据集的模式。

  • 参数： mode (str ↗) –

    写入模式，为 replace、modify 或 append 之一。在 modify 模式下，写入的所有内容都会追加到数据集，且可能会覆盖现有文件。在 append 模式下，写入的所有内容都会追加到数据集，并且不会覆盖现有文件。在 replace 模式下，写入的所有内容会替换数据集。

    写入数据后，无法再更改写入模式。

属性 transaction_rid

输出数据集上的事务。

  • 类型： str ↗

write_dataframe(df, column_description=None, column_descriptions=None)

将任意受支持类型的 DataFrame 写入数据集。

出于兼容性原因， column_description 和 column_descriptions 均可接受。但是，同时只能提供其中一个。

  • 参数：
    • df – pd.DataFrame, pa.Table, pl.DataFrame, pl.LazyFrame, duckdb.DuckDBPyRelation 或 pathlib.Path ，其中包含要上传的数据。
    • column_description (Dict [str ↗ , str ↗ ] , 可选) – 已弃用，请使用 column_descriptions 来代替。
    • column_descriptions (Dict [str ↗ , str ↗ ] , 可选) – 列名称到其字符串描述的映射。该映射会与 DataFrame 的列取交集，且所包含的描述不得超过 800 个字符。
  • 返回： None

write_pandas(df, column_description=None, column_descriptions=None)

将给定的 pandas.DataFrame ↗ 写入数据集。

出于兼容性原因， column_description 和 column_descriptions 均可接受。但是,同一时间只能提供其中一个。

write_table(df, column_description=None, column_descriptions=None)

将 pandas DataFrame、Arrow Table、Polars DataFrame 或 LazyFrame 写入 Foundry 数据集。

此过程包含三个操作:将 df 本身上传到数据集,推断 schema 并将其写入数据集(若已存在则覆盖),以及更新列描述元数据。若只想更新元数据而不上传数据,请改用 put_metadata() 。

出于兼容性原因, column_description 和 column_descriptions 均可接受。但是,同一时间只能提供其中一个。

  • 参数:
    • df – pd.DataFrame, pa.Table, pl.DataFrame, pl.LazyFrame, duckdb.DuckDBPyRelation 或 pathlib.Path 其中包含要上传的数据,或 None 以仅从事务中先前写入的数据推断 schema。
    • column_description (Dict [str ↗ , str ↗ ] , 可选) – 已弃用,请改用 column_descriptions 。
    • column_descriptions (Dict [str ↗ , str ↗ ] , 可选) – 列名到其字符串描述的映射。此映射会与 DataFrame 的列取交集,且所含描述不得超过 800 个字符。
  • 返回: None
