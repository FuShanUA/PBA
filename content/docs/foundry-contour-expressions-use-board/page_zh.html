使用表达式面板

除了直方图和图表等可视化工具之外，Contour 还提供了表达式面板，让您可以使用 Contour 丰富的表达式语言从数据中派生新列、执行复杂的筛选或执行复杂的聚合。Contour 的表达式语言是一种自定义语言，其中包含了来自 SparkSQL 的许多函数。

表达式中的列名区分大小写。此外，您可以在书写时使用或不使用双引号。例如， year("birthdate_col") 等价于 year(birthdate_col)。为保持一致，本文档中的列名书写方式为 ，使用 双引号。

筛选出所有 category 不为 null：

使用特殊字符拆分列

拆分 categories 列按 |。由于 | 是特殊字符的一个示例，因此需要对其进行转义才能被视为字面字符。

SPLIT("categories", '\|')

使用 LIKE 搜索模式

查找 MIN 或 MAX 所在行

数据分析中的一项常见任务是查找某个分区内某列取最小值或最大值的行。例如，您可能有一个包含患者记录的数据集，想要查找每位患者最早到访办公室的日期。您可以使用两个表达式来查找这些行。

首先，派生一个新列来查找分区的最小值或最大值。在下面的示例中，我们确定每辆出租车（通过牌照号识别）最近一次的行程，创建一个新列 most_recent_ride ，其中包含一个 窗口函数 (OVER):

max("pickup_datetime") OVER (PARTITION BY "medallion")

然后添加一个筛选表达式，将每行的上车日期值与其所在分区的最大值进行比较：

"pickup_datetime" == "most_recent_ride"

已保存的表达式

在 Contour 中，您可以保存表达式，以便在分析和路径之间轻松复用逻辑，并与他人共享逻辑。假设您创建了一个表达式，该表达式创建一个新列，当列 True 的值为 room_type 时，其值为 Private room日 False 否则为其他值。您想保存此表达式，以便其他人可以使用此逻辑。

点击设置菜单下的 保存表达式 （位于表达式面板的左下角）。

您可以选择不带参数保存表达式，也可以选择将某些值定义为表达式的参数。如果您保存的表达式不带参数，则在应用时，表达式的逻辑将保持与您定义的完全一致。如果您选择定义参数，用户将能够为参数选择不同的值。在下图中， True 和 False 值是可参数化的。

当您或其他用户选择应用此表达式时，系统将提示您为 true_value 和 false_value选择值。在这里，这些值映射到 Private room 和 Not private room.
