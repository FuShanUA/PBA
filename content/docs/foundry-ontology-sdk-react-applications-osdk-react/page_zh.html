构建应用程序，请使用 @osdk/react

该 @osdk/react 库将本体论软件开发工具包（OSDK）连接到 React 组件生命周期。它提供了类型化的 Hook 和共享缓存，让您无需单独管理每个请求及其状态，即可加载和更新本体论数据。

我们建议始终使用 @osdk/react 来构建基于 OSDK 的 React 应用程序。它提供了一种更具声明性且更易于维护的方式来与您的本体论数据交互。

功能

使用 @osdk/react，您可以：

  • 使用类型化的 React Hook 查询对象、对象集、关联和聚合。
  • 应用并验证操作，包括乐观更新。
  • 调用本体论函数并跟踪其依赖项。
  • 在组件之间共享规范化的缓存对象。
  • 在执行操作后自动同步受影响的缓存对象。

import { Todo } from "@my/osdk";
import { useOsdkObjects } from "@osdk/react";

function TodoList() {
  const { data, error, isLoading } = useOsdkObjects(Todo, {
    orderBy: { createdAt: "desc" },
    where: { isComplete: false },
  });

  if (data == null && isLoading) {
    return <div>Loading...</div>;
  }

  if (error) {
    return <div>Error: {error.message}</div>;
  }

  if (data == null) {
    return <div>No todos found</div>;
  }

  return (
    <div>
      {data.map(todo => <div key={todo.$primaryKey}>{todo.title}</div>)}
    </div>
  );
}
