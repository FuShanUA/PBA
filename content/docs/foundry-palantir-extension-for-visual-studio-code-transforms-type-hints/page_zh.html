转换类型提示

适用于 Visual Studio Code 的 Palantir 扩展包含一个 linter，用于确保在您的 Python 代码中正确使用转换参数类型。该 linter 会建议代码操作来添加或更新转换参数类型提示，从而确保 Python 语言服务器提供准确的代码补全。

该 linter 会自动插入所需的 import 语句，并为函数参数添加正确的类型提示。

禁用类型提示

您可以在设置中全局禁用类型提示建议，或使用行内注释指示 linter 跳过特定行或文件。

在设置中禁用类型提示

要禁用类型提示，请前往 Settings > Extensions > Palantir > Transforms > Language Server > Diagnostics，并取消勾选该复选框。这等同于将 "palantir.transforms.languageServer.diagnostics.enabled": false 添加到您的 settings.json 文件中。

注释行为

# palantir: ignore-next-line忽略下一行的类型提示
# type: ignore如果放在文件开头，则忽略所有类型提示；如果放在其他位置，则忽略特定行的类型提示
# noqa忽略同一行的类型提示
