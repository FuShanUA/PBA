Saved Search Around V1

This page describes Saved Search Around V1. On enrollments where Saved Search Around V2 is enabled, V2 replaces the V1 Search Around panel and adds support for multiple object types per step, wildcard steps, repeated steps, and object-backed link types. If you can add an Any Object Type step in your Search Around panel, your enrollment uses V2. Search Arounds you save in V1 remain available after your enrollment moves to V2.

Build multi-step Search Arounds

Running basic Search Arounds from objects on your graph is a quick way to explore your Ontology and add related objects to the graph. To create a multi-step, filtered graph that crosses different object types, use the Search Around panel. It provides a point-and-click interface to build out logic as you generate a new graph.

To open the Search Around panel, select the filter icon in the Search Around dropdown menu, or select the Search Around tab on the right side of the workspace. To start a Search Around, select one or more objects of the same type, then choose a link to create a Search Around from your selection.

To change your starting objects, select one or more new objects. Then, hover over the starting objects box and select Set starting objects.

Find related objects

After you select the related objects to add, the panel shows the number of objects found next to the resulting object type. To filter the returned objects, select Add filter and choose the property to filter by.

After you filter your object set, you can add the results to your graph immediately. You can also select Add link to continue building a multi-step Search Around.

Each new link uses the resulting object set from the previous link as its starting object set. From that set, you can find more related objects to add to the graph. In this example, the second link finds the destination airports for the flights returned by Link 1.

You can then filter the new object set. When you apply a filter, the starting object set is reduced to the objects connected to the filtered results. In this example, 157 flights depart to an airport in New York state.

Select Add to graph to generate a new graph from the traversals defined in the Search Around panel. Complex Search Arounds may take longer to generate.

Add parameters

To make Search Arounds reusable, you can define parameters that you can use throughout the Search Around. To view or create parameters, select View parameters in the top right corner of the panel. To create a parameter, select Add parameter and choose a parameter type.

After you add a parameter, you can give it a value, or select the edit button to change its name, description, and default value. The default value is used whenever the Search Around is loaded.

You can use a parameter in any filter field of a matching type. To do this, select the parameter toggle next to the filter field, then choose a parameter from the dropdown menu. When you change the value of a parameter, every filter that uses it updates to the new value.

Save and load

To reuse a Search Around in other graphs or in graph templates, save it as a resource. To do this, select the dropdown menu on the tab for the Search Around, then choose a name and location in the dialog that opens.

To open a saved Search Around, select the + icon in the Search Around tab header, then select Load Search Around and choose the Search Around from the resource picker. After the Search Around loads, select objects on the graph to use as its starting objects. You can only select objects of the appropriate type.
