Saved Search Around V1

本页面介绍 Saved Search Around V1。在已启用 Saved Search Around V2 的租户上，V2 会取代 V1 周边搜索 面板，并支持每个步骤包含多种对象类型、通配符步骤、重复步骤以及对象支撑的关联类型。如果您可以在 Any Object Type 面板中添加 周边搜索 步骤，则您的租户使用的是 V2。您在 V1 中保存的 Search Around 在租户升级到 V2 后仍然可用。

构建多步骤周边搜索

从图上的对象运行基本的 Search Around 是探索本体论并将相关对象添加到图中的快捷方式。要创建跨不同对象类型的多步骤、经过筛选的图，请使用 周边搜索 面板。它提供了一个点击式界面，让您在生成新图的同时构建逻辑。

要打开 周边搜索 面板，请在 周边搜索 下拉菜单中选择筛选器图标，或选择工作区右侧的 周边搜索 选项卡。要启动 Search Around，请选择一个或多个相同类型的对象，然后选择一个关联，以基于所选内容创建 Search Around。

要更改起始对象，请选择一个或多个新对象。然后，将鼠标悬停在起始对象框上并选择 设置起始对象.

查找相关对象

选择要添加的相关对象后，面板会在结果对象类型旁边显示找到的对象数量。要筛选返回的对象，请选择 添加筛选器 并选择要用于筛选的属性。

筛选对象集后，您可以立即将结果添加到图中。您也可以选择 添加关联 以继续构建多步骤 Search Around。

每个新关联都使用上一个关联的结果对象集作为其起始对象集。您可以从该集合中找到更多相关对象以添加到图中。在此示例中，第二个关联查找关联 1 返回的航班的目的地机场。

然后您可以筛选新的对象集。应用筛选器时，起始对象集会缩减为与筛选结果相连的对象。在此示例中，有 157 个航班飞往纽约州的某个机场。

选择 添加到图表 以根据 周边搜索 面板中定义的遍历生成新图。复杂的 Search Around 生成时间可能较长。

添加参数

为了使 Search Around 可重复使用，您可以定义可在整个 Search Around 中使用的参数。要查看或创建参数，请选择 查看参数 面板右上角的。要创建参数，请选择 添加参数 并选择参数类型。

添加参数后，您可以为其赋值，或选择编辑按钮来更改其名称、描述和默认值。每当加载 Search Around 时都会使用默认值。

您可以在任何类型匹配的筛选字段中使用参数。为此，请选择筛选字段旁边的参数切换开关，然后从下拉菜单中选择一个参数。当您更改参数的值时，使用该参数的每个筛选器都会更新为新值。

保存和加载

要在其他图或图模板中重复使用 Search Around，请将其保存为资源。为此，请选择 Search Around 选项卡上的下拉菜单，然后在打开的对话框中选择名称和位置。

要打开已保存的 Search Around，请选择 + 图标（位于 周边搜索 选项卡标题中），然后选择 加载 Search Around 并从资源选择器中选择该 Search Around。Search Around 加载后，请在图上选择要用作其起始对象的对象。您只能选择相应类型的对象。
