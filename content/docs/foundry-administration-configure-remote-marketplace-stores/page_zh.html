配置远程 Marketplace 商店

部分 Marketplace 商店是远程的，也就是说，它们在一个 Foundry enrollment 上创建，然后可供其他 Foundry enrollment 使用。例如， Foundry Store 由 Palantir 提供，其中包含诸如 Mapbox 边界数据集等产品。虽然在您的 Foundry enrollment 上创建的商店会 继承其保存位置的访问权限，但对远程商店的访问权限可在 Control Panel 中配置。远程商店由 Palantir 在您的 Foundry enrollment 上提供。某些商店可供所有客户使用（例如 Foundry Store 和 Reference Resources），而其他商店则可能是为了满足您组织内的特定用例而添加的。

用户创建的 Marketplace 商店默认为 enrollment 本地商店。请参阅 DevOps 文档 以了解跨 enrollment 共享产品的相关信息。

远程商店权限

远程商店设置按组织进行配置。设置可由具有 Organization Administrators 角色的用户进行配置，并可由具有 Organization Settings Viewer 角色的用户查看。

一旦远程商店在您的 Foundry 组织中可用：

  • 如果商店已开启，该商店及其产品将对所有用户可见，显示在 Marketplace。默认情况下，如果来自其他注册的新商店可供您的组织使用，该商店将被启用。
  • 您可以将访问权限限制为组织内用户组的特定成员。如果您为某个用户组设置权限，而该组的用户跨越多个组织，则只有您组织中该组的成员才能查看该商店。
  • 如果商店已关闭，任何用户都将无法在 Marketplace中看到该商店或其产品。
