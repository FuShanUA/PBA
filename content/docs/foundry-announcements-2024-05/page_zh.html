Pipeline Builder 现在支持在 LLM 运行中输出错误

发布日期：2024-05-23

您现在可以将 LLM 输出列配置为在行失败时同时包含输出值和错误消息，从而更轻松地调试与 LLM 相关的问题。借助此功能，您将在输出列中以结构体的形式同时收到 LLM 响应和错误消息。这种对 LLM 错误的透明化使调试处理问题以及了解模型幕后运行情况变得更加容易。错误消息示例可能包括：

  • "超出上下文限制"
  • "无法强制转换为提供的输出类型"
  • "输入提示为空或为空值"

配置为包含错误的 LLM 提示示例。

要使用此功能：

  1. 在 Pipeline Builder 中，打开一个 Use LLM 节点并创建提示。
  2. 找到 输出类型 section.
  3. 启用 包含错误 checkbox.

包含 LLM 错误消息时，节点输出将为结构体类型，其中同时包含常规输出值（可以是任何受支持的输出类型，包括结构体）和相关的错误消息。

结构体输出类型（包含数组、字符串和整数）及所包含错误消息的示例。

您可以通过取消选中 包含错误 复选框，轻松开启或关闭此功能，从而灵活控制错误透明度。

Slate 中的页面和共享变量简介

发布日期：2024-05-23

页面 使应用构建者能够将应用 UI、逻辑和资源（数据、变量、函数、事件）拆分到单个应用内的不同页面中，为每个页面提供独立的作用域并单独加载，包括组件、函数、查询等。此外，您现在可以对变量进行更细致的控制，能够按页面作用域（"local" 和 "shared"）对其进行配置，其中共享变量可从任何页面访问，从而提升应用设计、性能和用户体验。

加快应用加载速度

拆分 Palantir Slate 应用的一种常见模式是使用选项卡式容器。但是，这种方法可能导致页面加载量非常大，限制开发人员对数据加载的控制程度，并且由于只有单个组件和组件列表，会带来组件可维护性和组织方面的挑战。

从选项卡式容器切换到页面后，较大的应用可以更快地加载信息，因为它们仅加载与每个页面特定作用域相关的数据。

现在可以在单个 Slate 应用中构建多个页面。

这种方法能够将应用的逻辑流程划分到具有有意义命名 URL 路由的各个页面中。此外，在分享指向 Slate 应用的链接时，可以使用 URL 中的页面名称直接导航到该页面。

现在可以将应用逻辑流程划分到具有有意义命名 URL 的各个页面中。

提高应用稳定性

将复杂 Slate 应用的逻辑拆分到页面中还可以简化重构，从而提高可维护性和性能。

页面之间的无缝导航

新的 onNavigate 事件和 navigateTo 操作支持在同一应用内的页面之间进行简单的导航。导航到某个页面时，将更新 URL 路由以指向目标页面。

导航到某个页面时，URL 路由将更新为指向目标页面。

在页面之间共享应用程序状态

新建的 Shared 变量可在任何 Slate 页面中访问，从而实现跨页面的应用程序级状态共享。

为 Ontology 用户编辑和数据源更新引入冲突解决策略 [GA]

发布日期：2024-05-23

Foundry Ontology 中的对象实例既可以由输入数据源创建和修改，也可以由用户编辑创建和修改。当单个对象实例（例如具有特定主键值的某一行或某个对象）同时接收来自输入数据源和用户编辑的数据时，这些接收到的值必须通过以下方式透明地解决： 冲突解决策略.

您可以 配置 对象类型级别的冲突解决策略。在 Ontology Manager 中选择一个对象类型，然后导航至 数据源 区域的字段中添加命令。

请注意，冲突解决策略仅支持 Object Storage v2 对象类型.

冲突解决策略

Ontology 编辑有两种冲突解决策略：

  • 应用用户编辑（默认）：使用此策略时，对象实例的最终状态始终由应用于它的用户编辑决定，而不受该对象实例未来任何数据源更新的影响。
  • 应用最新值（有限测试版）：使用此策略时，仅当用户编辑的时间戳值比该对象实例的数据源更新时间戳值更新时，才会应用用户编辑。

此策略还要求数据源包含一个 Timestamp 类型的属性；Date 属性类型不适用于此选项。 时间戳 属性用于评估应应用用户编辑还是输入数据源更新。

在 Ontology Manager 中配置冲突解决策略。

为多个数据源配置不同的解决策略

您可以为对象类型的每个输入数据源配置不同的冲突解决策略。例如，对于由两个数据源支撑的对象类型，您可以将一个数据源配置为使用 应用用户编辑 策略，而将另一个数据源配置为使用 应用最新值 策略的一部分。

在 Ontology Manager 中为多个数据源配置冲突解决策略。

如果用户编辑更新了跨多个数据源的属性，Ontology Manager 将根据支撑该属性的数据源的冲突解决策略来决定是始终应用还是有条件地应用这些编辑。

隆重推出 AIP Accelerate [Beta]，您的 LLM 工作流笔记本环境。

发布日期：2024-05-21

AIP Accelerate 是一个用于构建由大语言模型（LLM）驱动的工作流的笔记本环境。AIP Accelerate 将于 6 月 3 日当周在所有租户中推出，使您能够快速迭代利用各种形式数据的 LLM 提示词，无论是从 Foundry 导入的数据集，还是您电脑上的文件。借助 AIP Accelerate 提供的 LLM 操作库，您可以构建复杂的思维链、解读上传的图像，并生成由 LLM 驱动的洞察。凭借对最新生成式 AI 模型的支持，AIP Accelerate 是一个将 LLM 能力用于调查分析型业务工作流的沙盒环境。

AIP Accelerate 登录页面。

LLM 的响应效果在很大程度上取决于上下文环境。AIP Accelerate 使您能够通过使用 上下文线程来仔细管理提供给 LLM 的上下文。上下文线程是 Accelerate 的主要组件之一，表示提供给大语言模型的信息链。单元格通过上下文线程将信息向下传递给其子单元格。工作流构建者可以使用上下文线程摆脱线性对话模式，构建不受单一上下文路径限制的工作流。此外，AIP Accelerate 利用平台内的基元，对各种形式的结构化和非结构化数据（如表格数据、PDF 或图像文件）执行操作，以进行复杂分析。

AIP Accelerate 上下文线程，其中子 LLM 单元格继承其父单元格的上下文，延续对话。

在上图中，我们有一个由两个单元格组成的上下文线程。我们可以继续嵌套单元格以深入与 LLM 的对话，也可以在任意单元格之后分支，走另一条路径。

安全且可定制的 AI 驱动分析

AIP Accelerate 的主要功能包括：

  • 用户友好的界面： AIP Accelerate 拥有直观的界面，使工作流构建者能够轻松使用 LLM 构建复杂的多维分析。
  • 生成式 AI 模型： 自定义在执行基于文本和视觉的任务时使用哪些可用的 LLM。
  • 对真实数据进行操作： 将 LLM 部署到平台内的数据上，例如数据集或媒体集（图像或 PDF 文档）。
  • 共享结果： 将分析结果保存为新数据集，供其他 AIP 工具使用，或与其他用户共享工作流。
  • 数据安全： AIP Accelerate 建立在同样严格的 安全 模型之上，该模型治理着 Palantir 平台的其余部分，包括基于用户的数据权限。这些平台安全控制仅授予 LLM 完成任务所需的访问权限。

AIP Accelerate 正在积极开发中，对更多操作的支持即将推出。

借助全新的 AIP Assist 代码工具，我们现在能够针对多个应用和功能返回包含准确的 Palantir 专用代码的答案。例如，您可以提出与本体论相关的问题（“如何编写本体论编辑函数？”），或询问特定语言（“如何在 Python 转换中并行解析原始文件？”）。此前，AIP Assist 只能使用通用的非 Palantir 代码提供针对一般用例的答案。通过这些改进，开发人员将能够获得准确、具体的代码，直接支持他们在代码仓库中的工作流程。

  • 或
  • TypeScript
  • SQL
  • pandas
  • Contour 表达式语言

全新的代码工具提升了 AIP Assist 中的代码响应质量。

随着 Palantir 工程师不断更新和扩展我们的代码示例集合，全新的代码工具将持续改善 AIP Assist 中的开发人员体验；这些示例 现已在我们文档中提供，将为解决复杂问题和转换提供用例指导和灵感。

即时修复编译器错误

AIP Assist 现已与 TypeScript 编译器集成，可标记类型不匹配、未处理的 promise 等问题。当 AIP Assist 根据问题生成初始代码后，代码将经过编译器检查以发现错误，并允许用户直接在 Assist 界面中提交更改。

直接在 AIP Assist 中编译 TypeScript 错误。

在 TypeScript 编译器工作的过程中，AIP Assist 会收到反馈，从而迭代优化生成的代码。编译器会调整类型、添加缺失的类型定义、纠正 promise 处理方式，并确保代码符合 TypeScript 的严格类型要求。每次迭代都会由编译器重新检查，直到代码编译无错误为止。

AIP Assist 不仅能解决即时的代码问题，还能帮助开发人员了解如何在未来避免类似问题。

Ontology Manager 已更新为仅预先加载与单个用户最相关的资源，从而显著提升了启动性能。从本周开始，您在 Ontology Manager 中工作时可以体验到更快的加载速度。无需用户操作即可启用此增强功能。
