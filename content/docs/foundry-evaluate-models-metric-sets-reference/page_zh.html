MetricSets 参考 [计划弃用]

计划弃用

指标集是为使用数据集支撑的模型而构建的，使用的是 foundry_ml，该库已于 2025 年 10 月 31 日起正式弃用。对于新的实现，我们建议使用 experiments 来替代。虽然对于使用 palantir_models构建的模型，指标集不会显示在模型页面上，但仍可以为模型编写指标集并在 《建模目标》.

A metric set 用作命名指标的容器，我们将命名指标定义为模型输出的任何汇总。 支持的指标类型包括数值、图表和图像。

在 Python 中，指标集通过 MetricSet 包中的 foundry_ml_metrics 类来实现（需要在 foundry_ml 环境配置中添加相应依赖）。

所有指标都可以通过 MetricSet.add 方法添加，该方法具有以下参数：

  • name 指标的字符串名称
  • value 要添加的指标值
  • subset A dict<str, str> 描述该指标所对应的数据子集
  • stage Foundry ML 模型阶段或阶段 uuid，用于将其关联到特定阶段， 默认为最后一个模型阶段

Code Repositories 中的 MetricSets

Code Repositories 中的指标集仅用于向后兼容最初作为数据集支撑模型构建的模型。请勿在新的实现中使用，并尽可能将现有指标集替换为 experiments 。

虽然对于使用 palantir_models构建的模型，指标集不会显示在模型页面上，但仍可以为模型编写指标集并在 《建模目标》.

import uuid
from transforms.api import transform, Input, Output
from palantir_models.transforms import ModelInput

from foundry_ml_metrics import MetricSet # add foundry_ml_metrics to your environment

@transform(
    evaluation_data_input=Input("path_to_input"),
    model_input=ModelInput("path_to_model"),
    metric_set_output=Output("path_to_output"),
)
def compute(evaluation_data_input, model_input, metric_set_output):
    metric_set = MetricSet(
        # Pass the "hash" part of the model version identifier, for example, given
        # ri.models.main.model-version.6c0f17a8-ad73-46a4-b86e-8d0a13327ef2,
        # only pass 6c0f17a8-ad73-46a4-b86e-8d0a13327ef2.
        model=uuid.UUID(
            # The model_version_rid property is only available on the ModelInput class
            # for versions of palantir_models greater or equal to 0.1602.0.
            model_input.model_version_rid.replace("ri.models.main.model-version.", "")
        ),
        input_data=evaluation_data_input
    )
    metric_set.add(name='Accuracy', value=0.8)
    metric_set.add(name='F1', value=0.95)
    metric_set.save(metric_set_output)

接下来，将 evaluation_data_input 数据集配置为 Modeling Objectives 评估配置中的评估数据集。然后，指标将显示在 Modeling Objectives 评估视图中该数据集下。

输入数据集

输入数据集是对模型所应用的特定数据版本的显式引用，指标即基于该数据计算得出。 通过手动跟踪这些数据，您可以创建模型性能的记录和完整溯源。在 Modeling objective 中对多个模型进行相互评估时，此功能是必需的，以确保这些模型是基于相同的数据进行评估的。

输入数据集必须以 Python 转换输入 合并到 MetricSets 类型传递，以便获取适当的元数据。注意：Code Workbook 仅对导入的数据集支持此功能。按照最佳实践，我们必须在与测试/训练拆分不同的工作簿中进行验证。

指标类型

数值指标

数值指标是最基本的指标类型，通常是分析师对模型性能的第一手洞察。 数值指标就是简单的 Python int or float 类型，只需将其添加到指标集中即可。

图表指标

图表提供了超越简单数值指标的模型性能可视化。 foundry_ml 支持以多种格式直接保存数据以支撑图表。 由于数据已保存，因此可以实现更强大的模型比较能力，尤其是在 Modeling objectives 中。

所有支持的图表均由 foundry_ml_metrics.charts 包中导入。

验证数据子集

模型性能通常在数据集的不同子集之间存在差异。 为了帮助分析这一点， MetricSet.add 方法接受一个 subset 参数， 一个字符串 -> 字符串的 Python 字典，用于描述您所应用的任何筛选条件。筛选条件的语义化名称可帮助用户了解其模型在代表现实世界问题的不同数据切片上的性能。

指标和子集将显示在建模目标中。

例如，在经典的开源鸢尾花数据集上，您可能正在计算模型在低于平均和高于平均花瓣长度上的准确率。

def compute_accuracy(testing_df):
    # An implementation of accuracy
    compute_accuracy = ...

    metric_set = foundry_ml_metrics.MetricSet(
        model = Model,
        input_data=testing_df
    )

    # Compute scores on all data
    predictions = Model.transform(testing_df)
    # subset = {} indicates overall, the default
    metric_set.add(name='accuracy', subset={}, value=compute_accuracy(predictions))

    # Filter data
    predictions_long = predictions.filter('sepal_length > 3')
    metric_set.add(name='accuracy', subset={'sepal_length': 'long'}, value=compute_accuracy(predictions_long))

    predictions_short = predictions.filter('sepal_length < 3')
    metric_set.add(name='accuracy', subset={'sepal_length': 'short'}, value=compute_accuracy(predictions_short))

可以向子集字典提供任意数量的字段。

更新指标

指标集以数据集的形式表示，并且 通过 Foundry 构建计算。当模型就地更新或有新的输入数据版本可用时，您必须重新构建指标集，因为它与模型和输入数据集的特定版本相关联。

重要的是，如果您更新并重新运行模型，您还需要重新构建关联的指标集，以防止信息过时，因为它们与特定的模型（和输入数据集）版本相关联。否则，您将无法在模型预览中看到指标。
