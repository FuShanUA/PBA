规则逻辑

每个 Foundry 规则都有与之关联的逻辑。此逻辑由三个部分组成：

  1. 输入： Foundry 规则的数据输入。
  2. 逻辑块： 将应用于所选输入的转换。
  3. 规则输出： 规则的输出格式。

所有屏幕截图均使用示例数据。

输入

Foundry 规则的输入既可以是数据集，也可以是对象，具体取决于使用场景。但是，将对象用作输入可提供更友好的用户界面以及额外的功能，例如筛选值的自动补全下拉菜单。

规则作者可用的数据集和对象由工作流所有者在 Foundry Rules 工作流配置中进行配置。由受限视图支撑的对象无法直接用作输入；相反，工作流所有者必须将支撑该受限视图的数据集配置为 备用支撑数据集。

Foundry Rules 不支持由多个数据源支撑、具有多个物化或使用仅编辑属性的对象类型。

逻辑块

应用于规则输入的转换以一系列逻辑块的形式表示。可用的转换包括筛选、表达式、聚合和联接。此外，还可以配置这些转换中哪些可供最终用户使用。了解更多关于 启用可选功能的信息。

每个逻辑块会获取上一个块/数据源输出的行，并对其应用转换，从而输出一组新的行和列。如需查看输出，请点击该块右上角的 预览 按钮。

规则输出

规则的末尾是规则输出。每个规则输出都对应一个输出数据集，具体在 Foundry Rules 工作流配置中进行配置。因此，所选输出指定了 Foundry 规则所输出行的目标位置和格式。每个字段的界面可以根据 其接受的值类型进行定制。 生成的输出数据集将包含使用该输出的所有规则所输出的行。此行为旨在使不同规则的输出更容易保持一致。

规则输出允许工作流所有者强制规定规则作者必须从其逻辑中输出的确切列和类型。在视觉上，这种强制规定以表单的形式呈现，其中每个表单输入都对应于输出数据集中的一个列。

如果同一应用程序中的不同 Foundry 规则必须输出具有不同架构的行，则可以配置多个不同的规则输出以供选择。或者，如果这些架构相似，那么将某些操作参数配置为可选，可能会比创建新的规则操作更容易。
