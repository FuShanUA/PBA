在为组管理配置服务用户时，Developer Console 的令牌与第三方应用程序的令牌有什么区别？

Developer Console 中创建的应用程序默认为受限应用程序，因此其令牌仅限于添加到应用程序限制中的项目和操作。这就是为什么受限应用程序的令牌不适合用于组管理。请在 Developer Console 中创建应用程序，然后将其设置为不受限；参见 创建不受限应用程序。该 不受限 Control Panel 在以下情况下提供的项目访问设置： 为组织启用应用程序时 在此处不适用。它仅管理通过授权码授予（authorization code grant）代表用户授权的应用程序。

能否使用 Upload File Foundry API 中的端点将文件从本地机器上传到 Foundry 数据集？

可以， Upload File 该端点用于将文件从本地机器上传到现有的 Foundry 数据集。

为什么用户在使用后端服务/客户端凭据 OSDK 客户端向 stream-data-proxy 写入行时会收到 403 PermissionDenied 错误，如何解决此问题？

受限的 Developer Console 应用程序只能调用添加到其限制中的操作，无法调用 底层服务端点 例如 stream-data-proxy。可以直接调用这些端点的独立 OAuth 客户端已无法再创建。请改为将应用程序设置为不受限，并请求所需命名空间的 api:* 作用域；参见 创建不受限应用程序 和 作用域前缀.

能否将 OSDK 固定在 Python 3.9 版本，以避免与其他需要 Python 3.9 的包发生冲突？

不能。Python OSDK 要求 Python 版本 >=3.10 且 <3.15。其他包需要升级到受支持的 Python 版本。

是否有可用的 C# SDK 来与 API 配合使用？如果没有，替代解决方案是什么？

没有，目前没有可用的 C# SDK。替代解决方案是导出 OpenAPI 并使用开源生成器，例如 OpenAPI Generator ↗ 来创建 C# 客户端。此外， Microsoft 的 OpenAPI.NET SDK ↗ 可与 .NET 的 OAuth 库 ↗ 配合用于 C# 生成器，以管理 OAuth。

如何使用 Typescript SDK 对字符串属性执行 contains 搜索？

当前的 Typescript SDK 不支持任意子字符串匹配；它只能匹配完整词条和前缀。

为什么 /loadObjects API 调用不返回使用继承的共享属性 API 名称的属性？

直方图 /loadObjects API 调用不返回使用继承的共享属性 API 名称的属性，因为接口被视为视图。当您查看具体对象类型时，您看到的是本地属性；而当您将其作为接口查看时，您看到的是共享/接口属性。这种设计意味着属性取决于上下文，即它们是被视为本地具体对象的一部分，还是接口的一部分。

如何在 Python OSDK 中为每次调用添加自定义标头？

在 Python OSDK 中，可以通过更新 FoundryClient 实例的会话标头来为每次调用添加自定义标头，如下所示：

client = FoundryClient(auth=auth, hostname="<https://YOUR_ENROLLMENT.palantirfoundry.com>")
client._session._session.headers = client._session._session.headers.update({
"YOUR_API_KEY_HEADER": "key_goes_here"
})

MyObject = client.ontology.objects.MyObject
print(MyObject.take(1))

如何解决在尝试登录 OSDK 应用程序时遇到的 Authorization error invalid_request Client authentication failed 问题？

请确保应用程序已为正确的组织启用。OSDK 应用程序需要为以下组织启用：

  • 应用程序创建后所属的组织。如果创建者对该组织拥有管理员权限，则会自动启用。
  • 任何其他有用户打算使用该应用程序的组织。这必须手动完成，且访客成员身份不适用。
