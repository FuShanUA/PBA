在为组管理配置服务用户时,来自 Developer Console 的令牌与来自第三方应用程序的令牌有什么区别?

Developer Console 应用程序在创建时即为受限应用程序,因此其令牌仅限于已添加到应用程序限制中的项目和操作。这就是受限应用程序的令牌不适合用于组管理的原因。请在 Developer Console 中创建应用程序,然后将其设置为不受限;请参阅 创建不受限应用程序。 不受限 项目访问设置是 Control Panel 在 为组织启用应用程序时提供的 。该设置在此处并不适用。它仅管控通过授权码模式代表用户获得授权的应用程序。

时间戳: 2024年4月13日

Foundry API 中的 Upload File 端点能否用于将文件从本地计算机上传到 Foundry 数据集?

可以。 Upload File 端点用于将文件从本地计算机上传到现有的 Foundry 数据集。

时间戳: 2024年3月21日

为什么用户在尝试使用后端服务/客户端凭据 OSDK 客户端向 stream-data-proxy 写入行时,会收到 403 PermissionDenied 错误,又该如何解决?

受限的 Developer Console 应用只能调用已添加到其限制中的操作，而无法调用 底层服务端点 ，例如 stream-data-proxy。能够直接调用这些端点的独立 OAuth 客户端现已无法创建。请改为将应用设置为不受限制，并请求 api:* 您所需命名空间的 scope；请参阅 创建不受限制的应用 和 Scope 前缀。

时间戳： 2024年3月21日

能否将 OSDK 固定到 Python 3.9 版本，以避免与需要 Python 3.9 的其他包发生冲突？

不能。Python OSDK 要求 Python 版本 >=3.10 且 <3.15。其他包需要升级到受支持的 Python 版本。

时间戳： 2026年7月2日

是否有可用于与 API 交互的 C# SDK？如果没有，替代解决方案是什么？

没有，目前没有可用的 C# SDK。替代解决方案是导出 OpenAPI，并使用类似 OpenAPI Generator ↗ 的开源生成器来创建 C# 客户端。此外， Microsoft 的 OpenAPI.NET SDK ↗ 可用于 C# 生成器，并搭配 适用于 .NET 的 OAuth 库 ↗ 来管理 OAuth。

时间戳： 2024年3月2日

如何使用 Typescript SDK 来执行 contains 在字符串属性上进行搜索？

当前的 TypeScript SDK 不支持任意子字符串匹配；只能匹配完整词条和前缀。

为什么 /loadObjects API 调用不返回使用继承的共享属性 API 名称的属性？

该 /loadObjects API 调用不会返回使用继承的共享属性 API 名称的属性，因为接口被视为视图。当您查看具体对象类型时，您拥有的是本地属性；而当您将其作为接口查看时，您拥有的是共享/接口属性。这种设计意味着，属性是基于上下文的，具体取决于它们被视为本地具体对象的一部分，还是接口的一部分。

时间戳： 2024年3月27日

如何在 Python OSDK 中为每次调用添加自定义标头？

在 Python OSDK 中，可以通过更新该 FoundryClient 实例的会话标头，为每次调用添加自定义标头，具体如下：

client = FoundryClient(auth=auth, hostname="<https://YOUR_ENROLLMENT.palantirfoundry.com>")
client._session._session.headers = client._session._session.headers.update({
"YOUR_API_KEY_HEADER": "key_goes_here"
})

MyObject = client.ontology.objects.MyObject
print(MyObject.take(1))

时间戳： 2024年4月15日

在尝试登录 OSDK 应用程序时，如何解决 Authorization error invalid_request Client authentication failed 问题？

请确保应用程序已为正确的组织启用。该 OSDK 应用程序需要为以下组织启用：

  • 应用程序创建后所属的组织。如果创建者对该组织拥有管理员权限,则会自动启用此项。
  • 用户打算使用该应用程序的任何其他组织。此操作必须手动完成,且访客成员身份不适用。

时间戳: 2024年12月2日
