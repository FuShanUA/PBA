AIP Logic 与 Automate 的集成

AIP Logic 现在可以实现自动化，使得本体论编辑可以自动应用或暂存以供人工审核。这些自动化可以在现有对象上触发，或在创建新对象时触发。

如何从 Automate 调用 AIP Logic 函数取决于是否 暂存写入 启用了执行模式：

  • 启用暂存写入： 该函数必须由一个操作类型封装，并通过操作效果调用。AIP Logic 提供一个 “创建操作” 按钮来生成操作类型。详情请参阅 AIP Logic 中的暂存写入.
  • 禁用暂存写入： 该函数可以通过 Logic 效果直接调用，如 使用 Logic 效果创建自动化.

为暂存写入 Logic 函数创建自动化

要从 Automate 调用暂存写入 Logic 函数，必须先创建一个由该函数支撑的操作类型，然后在自动化中使用操作效果。

  1. 在您的 AIP Logic 文件中，导航至 用法 选项卡并选择 “创建操作” 以生成一个由您的 Logic 函数支撑的操作类型。
  2. 使用一个 操作效果 在 Automate 中创建提交该操作的自动化。

由 Logic 函数生成的操作支持与旧版自动化相同的审核工作流。您可以将自动化配置为将操作暂存为提案以供人工审核，而不是自动应用这些操作。

仅当操作的目的、潜在影响和恢复路径足以证明其合理性时，才选择自动执行。对于影响重大或含义不明确的操作，隐私最佳实践是将其暂存为提案。暂存可防止操作在审核者检查并接受提案之前更改数据。如果没有此审核，错误的提案可能会大规模更新运营数据。审核 实践中的隐私与公民自由 以获取有关人工代理和监督的指导。

有关创建和管理操作类型的更多详细信息，请参阅 AIP Logic 中的暂存写入.

使用 Logic 效果创建自动化

本节中的工作流适用于返回本体论编辑列表作为输出的 Logic 函数，这是禁用暂存写入时的旧版行为。这些函数通过 Logic 效果直接调用。

您可以在 AIP Logic 文件中使用 用途 右侧的选项开始创建新的自动化。

这样做将弹出一个新窗口，其中包含基于您的 Logic 指令预先填充的自动化流程。

您设置的条件将监控一个对象集，并为每个新增对象触发 Logic 效果或自动运行编辑。了解如何 设置自动化.

确认新自动化的名称和设置后，选择 保存自动化.

保存后您将被重定向到 自动化概览 屏幕。

概览屏幕显示自动化流程、状态和事件图表，该图表在自动化被触发时会自动更新。

如果您将自动化配置为暂存操作以供审批，而不是自动运行编辑，请打开 提案 左侧导航栏中的标签页。该标签页显示需要审核的代理提案。

要审核这些 Agent 提案，请执行以下操作之一：

  • 通过导航到模块的 提案 导航栏中的标签页。
  • 在 Agent 提案 部分中，选择 要在标记和发布函数的过程中查看进度，请选择.

在 提案 标签页中，选择特定提案以查看其创建原因。

此外，建议的操作将在屏幕底部预览。通过选择 Agent 决策日志 选项卡（位于 查看提案详情，您可以检查 LLM 生成建议操作所遵循的决策过程。

当您接受提案时，操作将被自动执行，提案卡片将被移至 已应用 列。

FAQ

以下是关于 AIP Logic 集成的一些常见问题。

为什么我看不到任何提案？

出于安全考虑，未处理的提案仅在 24 小时内可见，且仅对创建自动化的用户可见。较旧的提案将不可见。

为什么 创建自动化 按钮不可用？

AIP Logic 输出必须返回一个本体论编辑，自动化才能运行。

当现有自动化中使用的 Logic 函数启用暂存写入时会发生什么？

现有自动化将继续针对之前发布的旧版函数运行。如果函数的输出类型是本体论编辑列表，则启用或禁用分阶段写入会发布一个新的主版本，因为输出类型将根据 Logic 配置更改为不同的类型。自动化不会跨主版本自动升级。

要将自动化迁移到分阶段写入版本：

  1. 选择 “创建操作” 在您的 AIP Logic 文件中生成操作类型。
  2. 在自动化中，将 Logic 效果替换为 操作效果 以提交生成的操作。
  3. 保存自动化。

更多详情，请参阅 迁移现有自动化.

为什么自动化摘要页面中没有条件块？

确保 AIP Logic 输入是一个对象。
