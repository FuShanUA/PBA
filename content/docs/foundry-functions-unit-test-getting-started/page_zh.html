快速开始

函数功能内置了对 Jest ↗ 单元测试的支持。请按照本指南中的步骤，为您的代码仓库设置单元测试工具。

默认情况下，函数功能在测试文件 functions-typescript/src/__tests__/index.ts中包含一个单元测试。您可以在 __tests__ 文件夹内的任意位置创建测试文件。

示例

例如，我们可能想要测试以下函数 addOne ，该函数位于 functions-typescript/src/index.ts中：

import { Function, Integer } from "@foundry/functions-api";

export class MyFunctions {

    @Function()
    public addOne(n: Integer): Integer {
         return n + 1;
    }
}

我们可以测试该函数 addOne ，方法是编写以下测试 test add one：

import { MyFunctions } from ".."

describe("example test suite", () => {
    const myFunctions = new MyFunctions();
    test("test add one", () => {
        expect(myFunctions.addOne(42)).toEqual(43);
    });
});

请参阅 Jest API ↗ ，了解可供您使用的完整测试 API 的详细信息。

运行测试

您可以点击位于右上角的 Test 按钮来运行所有测试，也可以点击每个测试行号旁边的三角形“播放”按钮来单独运行各个测试。
