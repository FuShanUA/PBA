通过类型映射启用 Gotham 集成

包含 Map Rendering Service 的注册租户可以跳过类型映射

如果您的注册租户包含 Map Rendering Service (MRS)，那么您 不 需要完成类型映射流程以启用 Gotham 集成。您可以 从以下位置创建新的本体论对象 or 将现有对象添加到 Gotham，无需额外配置。请按照以下说明检查您的注册租户是否包含 MRS。

如对 MRS 的可用性、安装或 Gotham 中提供的其他文档有疑问，请联系 Palantir Support。

如何检查您的注册租户是否包含 MRS

  1. 启动 Quicksearch 以搜索并选择 Gaia Home.
  2. 打开现有的 Gaia 地图或创建新地图。
  3. 选择 数据源 （位于左侧面板）。
  4. 在 Object search 菜单中选择 查找... 搜索栏中进行搜索。

如果您能够找到并选择 对象搜索，则您的注册租户包含 MRS。

使用类型映射为本体论创建统一的表示形式

类型映射支持在 Foundry 和 Gotham 之间为本体论创建统一的表示形式，并在 Foundry 的 本体论管理器 应用程序中进行管理。您可以基于现有的 Foundry 对象类型、属性类型和共享属性类型创建新的 Gotham 类型，并且这些类型会随着本体论的发展保持同步。完成类型映射流程后，Gotham 将能够通过 Object Set Service 查询 Foundry 对象类型及其元数据——这是一个支持对象数据搜索、筛选、聚合和加载的 Foundry 后端服务。

类型映射仅适用于同时使用 Foundry 和 Gotham 的注册租户，并且在使用前必须由平台管理员启用。一旦为某个 Foundry 本体论启用类型映射，就无法将其禁用。每个 Gotham 安装只能有一个 Foundry 本体论启用类型映射。如需类型映射启用方面的帮助，请联系 Palantir Support。

何时对本体论中的对象类型进行类型映射

如果您的注册租户不 包含 MRS，请按照以下说明 在 Ontology Manager 中对对象类型进行类型映射 ，且满足以下任一条件：

  • 您计划使用不属于 战术图形 or MIL-STD 2525 符号. Blueprint ↗ 的自定义符号体系。无论是否进行类型映射，均支持
  • 符号。您计划配置 搜索模板要发布的组件集版本包含在此清单文件中。当使用 函数支撑的 Enterprise Map Layer (EML)，或 版本化对象集支撑的 EML 以将本体论中的数据添加到 Gaia。

在 Foundry 的 Ontology Manager 中开启类型映射

要将 Foundry 本体论中的数据与 Gotham 集成，您首先需要按照以下步骤在 Foundry 的 Ontology Manager 中为目标对象类型开启类型映射：

  1. 从主屏幕启动 Ontology Manager。
  2. 找到并选择要进行类型映射的对象类型。
  3. 选择 功能 （位于对象类型的左侧面板中）。
  4. 下拉菜单中）。 Gotham 集成 面板中开启 Allow objects of this type to be accessed from Gotham applications.

类型映射的对象必须包含一个 geopoint 属性才能在 Gaia 地图上显示。该属性可以是对象类型支撑数据集的原生属性，也可以由纬度/经度对派生，或 geopoint 使用 Pipeline Builder 的 创建本体论地理点 转换功能生成。

配置对象类型的父类别和 Gotham 属性类型

一旦您开启了 Gotham 集成，您可以按照以下步骤基于现有的 Foundry 对象类型创建新的 Gotham 对象类型，指定对象类型的 父类别，并配置其 属性类型:

  1. 选择 创建新的对象类型 于 。这意味着，如果您的 Quiver 仪表板输入类型为布尔值、数字或时间，则需要从 Carbon 以字符串形式传入。有关类型映射信息，请参阅下方的映射表。 部分， Gotham 集成 以基于现有的 Foundry 对象类型在 Gotham 中创建新的对象类型。

  2. 确定 父类别 在 Gotham 中新对象类型的类型，请在以下选项之间进行选择： Entity （例如人员、组织或车辆）、 Event （例如航班、会议或音乐会）或 Document （例如 PDF 文件、文本文档或报告），具体取决于您的使用场景。

  3. 使用直方图中的 属性类型 部分，将 Foundry 对象类型属性映射到 Gotham——属性可以共享或克隆到 Gotham 本体论中。完成某个属性的配置后，您会在该属性名称旁看到一个蓝色 Mapped 标记。

    • Do not map property to Gotham 是默认选项——未映射的 Foundry 属性不会传播到 Gotham 本体论中。
    • Assign to shared property 使您能够选择一个 现有的 共享属性进行映射。
    • Promote to shared property 会创建一个 新的 共享属性，供其他对象使用。
    • Create a local clone of the property in Gotham 会在 Gotham 中创建所选属性的副本，该副本与其应用程序兼容。

    Foundry 会自动对所有共享属性进行类型映射，使其在 Gotham 中可用。

  4. 选择右下角的绿色 保存 按钮（位于屏幕顶部功能区右侧），然后进行查看。

  5. 查看对对象类型所做的更改，然后选择 保存到本体论.

将更改保存到本体论后，向上滚动回到 Gotham 集成 已应用标签 功能 对象类型的页面。您现在将看到一个 Gotham URI 分配给该对象类型，并且能够查看 Installation status 由 Gotham 报告的

Foundry 的本体论管理器将显示以下安装状态之一：

  • Ready to integrate：对象类型已准备好进行类型映射，以启用 Gotham 集成。
  • Installation in progress：对象类型的安装过程正在进行中。
  • Installation complete：安装过程已完成，因此该对象类型可在 Gotham 中使用。
  • Installation failed: {failureMessage}：对象类型的安装至少失败过一次，并将在下一次安装运行时重试。 {failureMessage} 概述了失败原因。常见的安装失败包括：
    • 实时重建索引：如果 Gotham 上正在运行实时重建索引，则无法更新本体论。在此期间，更改不会暂存，安装将失败，并在实时重建索引完成后自动重新运行。
    • 所需类型未安装：要成功安装对象类型，必须完成所有相关的属性安装（即映射），包括共享属性类型。
    • 其他本体论更新：如果有其他本体论更新正在并发运行，则类型映射器将无法更新本体论，并将自动重新运行。

一旦对象类型的安装状态显示为 Installation complete，您就可以在 Gotham 的应用程序中搜索并使用您的对象类型。

要在 Gotham 中弃用已进行类型映射的对象类型，您可以在 Foundry 的本体论管理器中删除该对象类型。在 Foundry 中删除后，相应的对象类型及其属性类型将无法在 Gotham 中访问，也无法供其应用程序使用。

Gotham 会沿用 Foundry 数据集的安全性和标记，这意味着通过类型映射在 Gotham 中提供的 Foundry 数据将保留相同的访问控制和分类。
