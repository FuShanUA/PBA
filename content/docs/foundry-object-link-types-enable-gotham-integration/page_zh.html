通过类型映射启用 Gotham 集成

注意

如果您的注册包含 Map Rendering Service (MRS)，那么您 不 需要完成类型映射流程即可启用 Gotham 集成。您可以 创建新的本体论对象，其来源为 或 将现有对象添加到 Gotham，无需额外配置。请按照以下说明检查您的注册是否包含 MRS。

如果您对 MRS 的可用性、安装或其在 Gotham 中的补充文档有任何疑问，请联系 Palantir 支持团队。

如何检查您的注册是否包含 MRS

  1. 启动 Quicksearch 以搜索并选择 Gaia Home。
  2. 打开现有的 Gaia 地图或创建新的 Gaia 地图。
  3. 选择 Data sources （位于左侧面板）。
  4. 搜索 Object search ，请在 Find... 搜索栏中进行搜索。

如果您能够找到并选择 Object search，则您的注册包含 MRS。

使用类型映射为您的本体论创建统一表示

类型映射可跨 Foundry 和 Gotham 为您的本体论实现统一表示，您可以在 Foundry 的 Ontology Manager 应用程序。您可以基于现有的 Foundry 对象类型、属性类型和共享属性类型创建新的 Gotham 类型，这些类型将随着您的本体论不断演变而保持同步。完成类型映射流程后，Gotham 将能够通过 对象集服务 查询 Foundry 对象类型及其元数据。该服务是一个 Foundry 后端服务，支持对象数据的搜索、筛选、聚合和加载。

注意

类型映射仅适用于同时使用 Foundry 和 Gotham 的部署环境，并且必须由平台管理员启用后方可使用。一旦为某个 Foundry 本体论启用了类型映射，便无法将其禁用。每个 Gotham 安装实例中只能有一个 Foundry 本体论启用类型映射。如需协助启用类型映射，请联系 Palantir 支持团队。

何时对您的本体论中的对象类型进行类型映射

请按照以下说明操作 ，并在 Ontology Manager 中对对象类型进行类型映射，前提是您的部署环境未 包含 MRS ，且以下任一条件成立：

  • 您计划使用的自定义符号未以 战术图形 或 MIL-STD 2525 符号的形式存在。 Blueprint ↗ 符号无论是否启用类型映射均受支持。
  • 您计划配置 搜索模板，一种 由函数支撑的企业地图图层（EML），或 版本化对象集支撑的 EML 以将本体论中的数据添加到 Gaia。

在 Foundry 的本体论管理器中启用类型映射

要将您的 Foundry 本体论中的数据与 Gotham 集成，您需要先按照以下步骤，在 Foundry 的本体论管理器中为感兴趣的对象类型启用类型映射：

  1. 从您的主屏幕启动本体论管理器。
  2. 找到并选择要进行类型映射的对象类型。
  3. 选择 功能 （位于对象类型的左侧面板中）。
  4. 向下滚动到 Gotham 集成 面板，并启用 Allow objects of this type to be accessed from Gotham applications。

注意

类型映射的对象必须包含一个 geopoint 属性，才能在 Gaia 地图上显示。该属性可以是对象类型支撑数据集的原生属性，也可以从纬度/经度对派生，或者 geopoint 通过管道构建器的 create Ontology geopoint 转换功能派生。

配置对象类型的父类别和 Gotham 属性类型

启用 Gotham 集成后，您可以按照以下步骤创建派生自现有 Foundry 对象类型的新 Gotham 对象类型，指定该对象类型的 父类别，并配置其 属性类型：

  1. 选择 创建新对象类型 ，该选项位于 对象类型 部分，属于 Gotham 集成 以在Gotham中基于现有的Foundry对象类型创建新对象类型。
  2. 确定 父类别 （即Gotham中新对象类型的父类别），请在 Entity （例如人员、组织或车辆）、 Event （例如航班、会议或演唱会）或 Document （例如PDF文件、文本文档或报告）中进行选择，具体取决于您的使用场景。
  3. 使用 属性类型 部分将Foundry对象类型的属性映射到Gotham——属性可以共享或克隆到Gotham本体论中。在特定属性上完成该配置后，您将看到一个蓝色的 Mapped 标签显示在该属性的名称旁边。
    • Do not map property to Gotham 是默认选项——未映射的Foundry属性将不会传播到Gotham本体论中。
    • Assign to shared property 使您能够选择一个 现有的 共享属性来进行映射。
    • Promote to shared property 会创建一个 新的 共享属性，供其他对象使用。
    • Create a local clone of the property in Gotham 会在Gotham中创建所选属性的副本，该副本与Gotham的应用程序兼容。

Foundry会自动对所有共享属性进行类型映射，使其在Gotham中可用。

  1. 选择绿色的 保存 按钮（位于屏幕顶部功能区的右侧），然后查看。
  2. 查看对您的对象类型所做的更改，然后选择 保存到本体论。

保存对本体论的更改后，向上滚动回到 Gotham 集成 部分，该部分位于 Capabilities 页面（属于你的对象类型）。现在，你将看到一个 Gotham URI （已分配给该对象类型），并且能够查看 Installation status （由 Gotham 报告）。

Foundry 的 Ontology Manager 将显示以下安装状态之一：

  • Ready to integrate：对象类型已准备好进行类型映射，以启用 Gotham 集成。
  • Installation in progress：该对象类型的安装过程正在进行中。
  • Installation complete：安装过程已完成，因此该对象类型可在 Gotham 中使用。
  • Installation failed: {failureMessage}：该对象类型的安装至少失败过一次，并将在下一次安装运行时重试。该 {failureMessage} 概述了失败原因。常见的安装失败包括：
    • 实时重建索引：如果 Gotham 上正在运行实时重建索引，则无法更新本体论。在此期间，系统不会暂存更改，而是会让安装失败，并在实时重建索引完成后自动重新运行。
    • 未安装所需的类型：若要成功安装对象类型，必须完成所有相关的属性安装（即映射），包括共享属性类型。
    • 其他本体论更新：如果有本体论更新正在并发运行，类型映射器将无法更新本体论，并将自动重新运行。

一旦您的对象类型的安装状态显示为 Installation complete，您将能够在 Gotham 的应用程序中搜索和使用您的对象类型。

要在 Gotham 中弃用类型映射的对象类型，您可以在 Foundry 的 Ontology Manager 中删除该对象类型。在 Foundry 中删除后，相应的对象类型及其属性类型将无法在 Gotham 中访问，也无法供其应用程序使用。

Gotham 会沿用 Foundry 的数据集安全性和标记，这意味着通过类型映射在 Gotham 中提供的 Foundry 数据将保留相同的访问控制和分类。
