代码仓库

代码仓库 提供了一个基于 Web 的集成开发环境 (IDE)，用于在 Foundry 中编写生产就绪的代码并进行协作。该应用程序提供了一种用户友好的方式来与底层 Git 仓库交互，并提供一系列附加功能：

  • 所有常见的 Git 版本控制任务，包括分支、提交和标记发布版本，都可以通过 Web UI 执行
  • 仓库通过以下功能集成了对代码审查和协作的支持 拉取请求，包括对高度可配置权限的支持，以确保代码库的质量
  • 每种仓库类型都包含有助于代码编写体验的集成功能，包括 IntelliSense、代码检查和错误检查，以及丰富的帮助对话框

要在熟悉的 IDE 中编辑和管理代码，请使用 VS Code 工作区 或 适用于 Visual Studio Code 的 Palantir 扩展。要在不打开编辑器的情况下浏览和共享已提交的代码，请使用 代码查看器 （位于 Code Workspaces 中）。

仓库类型

Code Repositories 支持创建多种类型的仓库。下面介绍最常见的仓库类型。

  • 转换 仓库支持编写数据转换逻辑，并包含支持预览和调试转换的功能。支持的语言包括 或, Python日 SQL
  • 函数 仓库支持编写可在运营场景中以低延迟执行的业务逻辑，并原生支持从 Foundry 本体论访问数据。Code Repositories 环境支持基于本体论数据类型的自动补全，并使代码作者能够在编写函数时预览函数。函数可以使用 TypeScript or 或.
  • 模型开发 在 Code Repositories 中受支持。 了解有关如何在 Code Repositories 中开发模型的更多信息。
