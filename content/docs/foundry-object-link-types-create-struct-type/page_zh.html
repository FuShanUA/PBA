创建结构体属性类型

如需创建并配置新的结构体属性，请前往 对象类型 页面（位于 Ontology Manager 中）。有关结构体属性的更多信息，请参阅 概览。

  1. 在 Ontology Manager 中，打开左侧边栏中的 对象类型 标签页，然后选择一个现有的对象类型。
  2. 在对象类型详情页面中，打开左侧边栏中的 属性 标签页，然后选择 创建属性 按钮（位于 属性 表格右上角）。
  1. 在 属性编辑器 面板中，添加名称和描述，然后选择 结构体 （在 基本类型 下拉菜单中）。
  1. 向下滚动到 数据 部分，并从下拉菜单中选择一个 支撑列 。
  1. 在 结构体字段 部分，选择 添加字段，然后选择 新建字段。
  1. 为新的结构体字段命名，并可选择添加描述。
  2. 最后，将数据源中的某一列映射到新的结构体字段。
