连接数据

除 转换单个数据集之外，Pipeline Builder 还允许您通过连接（join）和合并（union）将数据集整合在一起。

连接（join）会将两个至少有一个匹配列的数据集组合在一起。根据您配置的连接类型，连接输出可以组合匹配的行并排除不匹配的行。

配置连接

在连接表单中，您可以编辑连接类型、选择匹配条件以及预览输出表。

  • 连接类型： 选择是创建左连接、右连接、内连接还是外连接。
    • 左侧： 保留左表中的所有行以及右表中匹配的行。
    • 右侧： 保留右表中的所有行以及左表中匹配的行。
    • 内连接： 仅保留两个表中匹配的行。
    • 外连接： 保留两个表中的所有行，并为 null 不匹配的行填充列。
  • 匹配条件： 从左侧数据集中选择一列，将其标记为与右侧数据集中的某一列相等。例如，左侧 city 数据集中的 Clean Facility Data 列等于右侧 CITY 数据集中的 Facility Person dataset.
  • 预览： 查看右侧和左侧输入数据集的预览数据。应用连接后，可查看输出表的预览数据。如果应用连接时出现任何错误，请在 错误 tab.

上述及后续示例中的所有数据均为随机生成，不具有代表性。

您可以选择在连接中包含特定列，并为右表添加前缀。选择 显示高级选项 以展开前缀和列字段，为右表输入前缀，并选择要包含在连接中的列。在下面的示例中，我们保留了左侧数据集的所有列，仅包含右侧数据集的 STATE 和 population 列。
