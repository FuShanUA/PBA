源别名

源别名是已命名、可移植的引用，指向 Data Connection 源。通过使用别名键而非特定源标识符来引用源，您可以将函数逻辑与任何单一源解耦。这使您的函数在不同环境之间保持可移植性。

导入源

要导入源：

  1. 打开 TypeScript v2 或 Python 代码仓库，然后导航至 资源导入 面板。

  2. 选择 Ontology SDK 选项卡。

  3. 选择 添加 > 源。

  4. 搜索并选择要导入的源，然后选择 确认选择。

添加源别名

导入源后，您可以为其添加别名：

  1. 在 资源导入 面板中，在 源部分下找到该源。

  2. 选择 添加别名 （位于源名称下方）。

别名键在仓库内必须唯一。

编辑源别名

要编辑现有的源别名，请导航至 源 部分（位于 资源导入 面板中）。选择别名旁边的铅笔图标，即可进行内联编辑。

在代码中使用源别名

要在函数中使用源别名，请在声明和检索源的所有位置通过别名键来引用该别名。将别名键传递给 sources 配置以及 getSource (TypeScript v2) 或 get_source (Python)：

import { getSource, getHttpsConnection, getFetch } from "@palantir/functions-sources";

export const config = {
    sources: ["demoSource"]
}

async function myExternalFunction(): Promise<string> {
    const source = await getSource("demoSource");
    const { url } = getHttpsConnection(source);
    const fetch = await getFetch(source);

    const response = await fetch(url);

    return response.text();
}

from functions.api import function
from functions.sources import get_source


@function(sources=["demoSource"])
def my_external_function() -> str:
    source = get_source("demoSource")
    url = source.get_https_connection().url
    client = source.get_https_connection().get_client()
    response = client.get(url)
    return response.text

有关在函数中使用数据源的更多信息（包括访问凭据和使用预配置的客户端），请参阅 从函数发起 API 调用。

在 Marketplace 中使用数据源别名

当您将使用数据源别名的函数添加到 Marketplace 产品时，每个已设置别名的数据源都会显示为 数据连接源下的一个可配置输入项。安装人员可以在安装过程中将每个输入数据源映射到其环境中的可用数据源，而无需修改函数源代码。

设置描述

为了帮助安装人员了解应提供哪个数据源，您可以为数据源输入项添加描述。在 输入 下选择该数据源，以打开 详情 面板，然后在 常规 选项卡上输入描述。

安装体验

在安装过程中，安装人员可以看到数据源描述，并可以选择适合其环境的数据源。Marketplace 会自动将所选数据源重新映射到定义的别名，因此函数代码保持不变。
