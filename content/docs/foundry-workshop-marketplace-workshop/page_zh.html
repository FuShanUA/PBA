将 Workshop 应用程序添加到 Marketplace 产品

用途 Foundry DevOps 以将您的 Workshop 应用程序包含在 市场产品 中，以便其他用户安装和重用。 了解如何创建 Marketplace 产品。.

支持的功能

所有正式发布的 Workshop 功能均支持打包，但静态/对象支撑场景除外。

将 Workshop 应用程序添加到产品

要将 Workshop 应用程序添加到产品，首先 创建一个产品，然后选择 功能，并选择。选择 添加文件 选项以从 Compass 文件系统中导航到 Cipher 资源，并将其添加到您的产品中。

选择应用程序后，如果收到任何错误消息，请访问 打包错误检查器 以获取更多信息。我们建议在尝试打包应用程序之前启用该检查器。

安装配置

如果您创建了希望作为 Marketplace 产品一部分包含的 Workshop 应用程序，请启用 安装配置 （如下方 Workshop 设置中所示），它为 调试打包错误 何时 创建产品 以及创建 安装参数 以在安装过程中公开。

打包错误检查器

要成功打包 Workshop 应用程序，DevOps 必须能够成功识别所有应用程序依赖项，例如应用程序中使用的对象类型。启用 安装配置后，任何错误都将显示在应用程序右上角的警告旁边。

错误可能需要大约 5-10 秒才会显示，具体取决于应用程序的大小。如果没有错误，则不会显示任何内容。

某些 Foundry 注册默认为所有用户启用 Marketplace 检查。在默认启用检查的情况下，Marketplace 会为每个 Workshop 模块提供检查反馈，包括您不打算打包的模块。请利用此反馈在开发过程中识别打包问题。

通常的最佳做法是在尝试于 DevOps 中打包应用程序之前启用检查器并检查错误。如果您在启用检查器之前尝试打包，则存在任何未解决的问题时，系统会引导您使用该检查器。

检查器显示的常见错误包括：

  • 您的应用程序引用了对象类型变量的属性，由于尚未与 Marketplace 完全集成的新功能而无法解析。要解决此错误，您可以使用变量的 模块接口 设置，对分支的合并保留实质性的控制权。

  • 您的应用程序引用了已被删除或主键已重命名的属性或对象类型。要解决此问题，请将属性或对象类型引用替换为新的属性或对象类型，或者如果不再需要该引用，则将其删除。

  • 您的应用程序使用了尚未配置打包的自定义 widget。请联系您的 Palantir 代表以获取进一步帮助。

  • 您的应用程序使用 Resource List widget 引用 Compass 资源。Resource List widget 不支持自动检测 Compass 资源作为 Marketplace 打包的输入。使用此 widget 的应用程序在部署期间需要手动配置依赖项。

安装参数

启用 安装配置后，将在 设置下方显示一个新面板。可以从此面板配置两种类型的安装参数： string 和 boolean 参数。

用途 string 参数，以允许在安装时自定义应用程序标题等内容。例如，您可以使用 string 参数，允许安装者在安装您的产品时使用其组织名称自定义应用程序。

用途 boolean 参数，以根据安装者的偏好显示/隐藏内容。例如，您可以使用 boolean 参数，允许安装者在相关时显示应用程序中的特定图表。

创建安装参数后，您可以将这些参数连接到 Workshop 变量。

当其他用户安装您的产品时，这些参数将显示为 输入.
