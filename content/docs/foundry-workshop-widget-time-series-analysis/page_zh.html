时间序列分析

该 时间序列分析 组件使用户能够在 Workshop 应用程序框架内灵活、独立地研究时间序列数据。

可用图表

要从本体论中添加时间序列数据，可使用 + Add Data 搜索栏，然后通过选择 New Plot来派生新图表。图表可以在同一分析中的多个画布上进行组织。

时间序列图表

  • 布林带： 在移动平均值上下按可配置的标准差数绘制上轨和下轨。
  • 合并时间序列： 将多个时间序列合并到单个图表中，并指定如何处理重叠的时间点（例如平均值、最小值或最大值）。
  • 累积聚合： 显示序列在整个序列长度上或特定时间段内的累积值。
  • 导数： 显示所选输入序列中每个点的变化率。
  • DSP 滤波器： 应用数字信号处理滤波器（巴特沃斯、切比雪夫或逆切比雪夫）来降低时间序列中的噪声。
  • 事件统计： 在事件发生的时间区间内对时间序列进行聚合，每个事件返回一个数据点。
  • 筛选时间序列： 根据时间范围或数学条件保留或移除时间序列中的点。
  • 公式时间序列： 使用 Quiver 的 公式语言对一个或多个时间序列应用数学公式来创建新绘图。
  • 积分： 计算时间序列曲线下的面积，即导数的逆运算。
  • 线性聚合： 计算多个时间序列随时间变化的线性聚合。
  • 周期性聚合： 通过在固定时间段内聚合数据来对时间序列进行降采样，每个时间段生成一个数据点。
  • 滚动聚合： 基于滚动窗口函数和聚合方法为每个数据点计算一个新数据点，通常用于平滑序列。
  • 采样： 以恒定频率对时间序列进行重采样，以填补空缺或更改数据速率。
  • 移动时间序列： 将序列的时间按指定时长向前或向后移动。

事件集

  • 关联事件集： 通过遍历对象关系并指定哪些属性包含开始和结束时间戳，从本体论中的关联对象创建事件集。
  • 时间序列搜索： 根据时间序列数据的条件创建事件集，识别与指定模式或阈值匹配的时间范围。

可视化选项

绘图 小组件底部的面板包含所有绘图类型通用的设置和信息。特定于绘图类型的数据配置由小组件右侧的编辑器面板进行控制。列的可见性、顺序、排序和宽度均可自定义。使用 配置列 菜单可对列顺序进行细粒度控制，并可添加非默认列。

可从面板标题栏快速切换以下可视化选项：

显示

  • 图表： 绘图渲染所在的画布图表。
  • 线条样式： 将绘图线条渲染为实线或虚线。
  • 线条宽度： 绘图线条的粗细。
  • 渐变： 切换绘图线条下方的渐变着色。
  • 点形状： 数据点的形状（圆形、三角形、正方形、菱形或无）。
  • 点大小： 数据点的大小。当点形状设置为“无”时禁用。

坐标轴

  • 坐标轴： 绘图分配到的 Y 轴。可从具有兼容单位的现有坐标轴中进行选择，或创建新坐标轴。
  • 单位： Y 轴的单位。支持单位转换（例如，从米转换为千米）或自定义标签覆盖。
  • 自动缩放： 切换自动坐标轴缩放以适应数据范围。
  • 坐标轴最小值： Y 轴范围的最小值。启用自动缩放时禁用。
  • 轴最大值： Y 轴范围的最大值。启用自动缩放时禁用。

本体论

  • 根对象： 时间序列属性所在的本体论对象，或当时间序列是 传感器时的根对象。选择不同的对象将更新图表以及任何依赖的派生图表。当所有图表具有相同的根对象时，可使用列标题中的按钮批量更新此列。
  • 传感器对象： 与时间序列关联的传感器对象（如适用）。
  • 属性： 时间序列属性或传感器名称。选择不同的属性将更新图表以及任何依赖的派生图表。当所有图表使用相同的属性时，可使用列标题中的按钮批量更新此列。

统计信息

  • 最小值： 当前视图范围内图表的最小值。
  • 最大值： 当前视图范围内图表的最大值。
  • 平均值： 当前视图范围内图表的平均值。

事件

  • 事件数量： 事件集图表在当前视图范围内的事件数量。
  • 事件高亮： 切换图表中事件发生时间范围的高亮显示。

可以从 列配置 菜单中添加更多配置：

轴显示选项

  • 对齐轴： 将轴对齐到图表的左侧或右侧。
  • 对数刻度： 使用对数刻度显示轴。
  • 反转轴： 反转轴的方向。

点显示选项

  • 点填充： 数据点的填充颜色。当点形状设置为“无”时禁用。
  • 点轮廓宽度： 数据点的轮廓宽度。当点填充设置为“无”或与绘图颜色相同时禁用。

插值

  • 内部插值： 用于连接时间序列内各数据点的插值方法。
  • 外部插值： 在第一个数据点之前和最后一个数据点之后使用的插值方法。

详细了解可用的插值选项。

配置选项

添加数据选项

  • 允许用户从本体论中选择时间序列数据， 并可选择限制可用的对象类型。若要进一步缩小可用系列的范围，请为每种对象类型应用对象集筛选器。
  • 使用对象集控制系列： 通过指定对象集和时间序列属性，使用一组受控的时间序列初始化分析。用户无法删除或编辑这些序列的数据配置，但可以在 绘图详情 面板中自定义显示。
  • 添加初始事件集： 使用由对象集支撑的事件集初始化分析，并指定用于事件开始和结束时间的属性。用户无法删除或编辑这些序列的数据配置，但可以在 绘图详情 面板中自定义显示。

绘图选项

  • 新绘图放置位置： 选择默认将新绘图添加到哪个画布。
  • 自定义可用绘图类型： 控制在 新建绘图 菜单中可用的派生绘图类型及其显示顺序。
  • 自定义可用事件集类型： 控制用户可添加哪些类型的事件集。

图表选项

  • 叠加 Y 轴： 启用后，Y 轴将以透明叠加层的形式呈现。否则，Y 轴会将图表数据移至一侧。
  • 默认折叠 Y 轴： 初始时折叠 Y 轴以节省图表空间。
  • 折叠时显示 Y 轴边界： 在轴折叠时显示轴边界。
  • 工具提示选项： 配置工具提示的可见性、显示的值、时间和标签格式、文本换行以及有效数字位数。
  • 启用 UTC 时间格式： 以 UTC 格式显示图表时间值。
  • 跨画布同步 X 轴： 在多个画布之间缩放或平移时，保持 X 轴视图范围同步。
  • 默认视图范围： 分析中时间序列图表的初始视图范围。可用选项包括：
    • 完整数据范围： 使用所包含时间序列的开始日期和结束日期。请注意，对于大型时间序列，这可能会对性能产生负面影响。
    • 固定日期范围： 使用 Workshop 变量定义绝对开始日期和结束日期。
    • 相对日期范围： 使用 Workshop 变量定义相对于页面加载时间的范围（例如，“2 周前到现在”）。

资源选项

  • 启用分析保存： 保存并共享分析以供将来参考。分析可以保存为 私有 或 公开。
    • 配置默认保存位置： 选择文件夹或使用字符串变量提供默认保存位置。
    • 不允许用户选择保存位置： 始终使用默认保存位置，并在 UI 中隐藏保存位置选择。
  • 输出分析 RID： 将当前分析的资源标识符存储到字符串变量中，以便在 Workshop 应用程序的其他位置使用。
  • 自动加载分析： 指定在小部件初始化时自动加载的分析。小部件配置中的显示选项（例如工具提示选项）将覆盖保存在分析中的选项，但从该小部件保存分析时，分析将保留其原始设置。
    • 加载时不清除： 禁用时，更新自动加载的分析 RID 将重置小部件的视图状态。启用后，更新分析 RID 会将新分析添加到视图状态中，但不会清除当前正在查看的分析。

保存分析以供日后使用

  • 另存为时间序列分析资源： 开启 启用分析保存 配置，允许用户保留并轻松共享其分析。保存的分析可以在独立的资源视图中打开，也可以使用其 RID 加载到 Workshop 小部件中。
  • 在 Quiver 中打开： 选择 在 Quiver 中打开 （位于小部件标题栏右上角），将当前分析转移到完整的 Quiver 分析中，以执行更高级的时间序列工作流。此操作将创建一个包含相同画布和图表的新 Quiver 分析。请注意，在 Quiver 分析中所做的更改 不会 反映回 Workshop 小部件中。
