更新对等连接的设置

在您或其他注册管理员 创建对等连接后，您可以在 Peer Manager 中查看该连接时，通过 设置 选项卡修改其状态、安全性或对等数据类型。

修改对等连接的状态

使用 状态 部分中的下拉菜单，选择 已禁用以禁用对等连接。

如果 任一 方（对等连接的本地端或远程端）选择禁用连接，所有数据将停止对等传输。在连接重新启用之前，数据不会进行对等传输。

修改对等连接的安全性

安全性 部分使您能够修改 对等连接的安全性。选择 管理 以更改已配置的 分类标记 或 其他标记。

安全性修改会更改可通过连接进行对等传输的数据，因此 所有 安全性更改必须先获得远程注册方的批准才能生效。当对等连接的一方更改安全性时，Peer Manager 将在连接的另一端打开一个变更请求以供批准。
