FAQ

在 Foundry 中是否有一个集中位置可以查看所有用户上传的镜像？

是的；Control Panel 为 Foundry 管理员提供了查看推送到平台的所有镜像的能力，以及 查看和召回这些镜像中存在的任何漏洞.

容器支撑的模型是否与实时部署兼容？

是的，容器模型可以在 实时 和 批量 部署中使用。

在创建要推送到 Foundry 的镜像时，是否应使用特定的基础镜像？

不，没有提供也不要求标准基础镜像。但是，推送的所有镜像必须遵守 镜像要求.

镜像是否必须公开标准 API？

不；Foundry 与镜像的交互方式将由 模型适配器实现定义。 此自定义适配器示例 中反映的常见模式是构建镜像以在特定端口上侦听输入，然后让模型适配器发送 post 请求。

容器化模型的最大镜像大小是多少？

通常，大于 22 GB 的镜像会在 Docker push 步骤中超时。如果您的使用场景需要更大的镜像，请联系您的 Palantir 代表。

Foundry 是否支持运行基于 Windows 的容器？

不；推送到平台的所有镜像必须 为 Linux 平台构建 ，因为 Foundry Kubernetes 集群中的实体是 Linux 机器。

我可以在模型中使用多个容器吗？

是的；可以将多个镜像 配置为支撑某个模型版本，但不支持编排功能。所有容器将在执行时同时启动，无法保证容器的启动顺序。

容器支撑的模型是否在所有 Foundry 实例上都受支持？

不。所有用户提供的容器工作流都需要 Rubix ↗ 引擎作为支撑基础设施。此外，您需要在 控制面板.

如何在模型上启用遥测？

要在模型上启用遥测，请创建新的模型版本并开启 启用遥测 菜单中选择 第三步 中启用。镜像必须在 /bin/sh中包含 shell 可执行文件，并且镜像必须支持 shell 命令 set 和 tee.

遥测是否适用于所有类型的模型？

不，容器化模型的遥测仅在 Python 转换 和 实时部署中有效，但不会为批量部署输出容器日志。

如何测试我的容器是否具备遥测所需的命令和设置？

您可以通过运行 docker run --entrypoint /bin/sh <EXAMPLE_IMAGE>:<IMAGE_TAG_OR_DIGEST> -c 'set -a && tee -a' && echo "Telemetry compatible"来测试。如果输出为 Telemetry compatible ，则表示可以为该容器启用遥测。
