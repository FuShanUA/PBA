支持的语言和版本

Code Workbook 目前支持三种语言:Python、R 和 SQL。

Code Workbook 目前支持的 Python 版本包括 Python 3.10 和 Python 3.12。不支持较低版本的 Python,使用这些版本的环境将无法解析。我们强烈建议使用最新可用的 Python 版本,因为 Palantir Foundry 会停止支持已被 视为生命周期结束 ↗ 的 Python 版本(依据 Python 开发者文档)。

目前支持的 R 版本包括 R 3.6、R 4.0、R 4.1 和 R 4.2。不支持 R 3.3、R 3.4 和 R 3.5 版本,其对应的环境将无法初始化。

Code Workbook 支持的 SQL 方言为 Spark SQL ↗.

要在 Code Workbook 配置文件上启用特定语言,请参阅以下文档中的 Conda 环境部分: 配置 Code Workbook 配置文件 文档。下面针对每种支持的语言提供了一系列示例,详见各自的介绍: 或, R日 SQL.

在工作簿中启用语言

支持的语言需要特定的配置才能正常运行,相关内容将在以下各节中讨论。

启用 R

R 尚不支持自助服务。

要在 Code Workbook 中创建 R 转换,必须满足以下两个条件:

  • 必须在您的租户上专门启用 R 语言。请联系您的 Palantir 代表以获取启用方面的帮助。
  • 软件包 vector-spark-module-r 必须存在于工作簿当前使用的环境中。可以通过以下任一方式实现:
    • 在控制面板中切换配置文件配置中的 R 复选框。这将自动将该 vector-spark-module-r 软件包添加到配置文件的环境中。
    • 手动添加 vector-spark-module-r 到环境中,使用 添加软件包 这将打开一个对话框，您可以在其中为实体应用和编辑标签。

请参阅 配置 Code Workbook 配置文件 的文档以获取更多信息。

启用 Python

软件包 vector-spark-module-py 必须存在于工作簿当前使用的环境中。可以通过以下任一方式实现:

  • 在控制面板中切换配置文件配置中的 Python 复选框。这将自动将该 vector-spark-module-py 软件包添加到环境中。
  • 手动添加 vector-spark-module-py 到环境中,使用 添加软件包 这将打开一个对话框，您可以在其中为实体应用和编辑标签。

请参阅 配置 Code Workbook 配置文件 的文档以获取更多信息。

启用 SQL

SQL 转换无需任何额外的软件包即可运行。因此,对于任何给定的配置文件,SQL 转换默认始终可用。

如果您不打算在某个配置文件上使用 Python 或 R,可以考虑移除相关的 vector-spark-module 软件包以精简您的环境。需要时您随时可以重新添加。

Python 简介

Python 转换

Python 转换定义为一个 Python 函数,具有任意数量的输入、至多一个输出,以及可选的一个或多个可视化。通过将某个转换的别名作为函数参数进行引用,Code Workbook 会自动将该别名的输出作为此转换的输入传入。有关 Code Workbook 中转换的更多信息,请参阅 转换概览 文档。

Python 转换的一个简单示例可以包括:以单个 PySpark DataFrame 作为输入,使用 PySpark 语法转换数据,并输出转换后的 Spark DataFrame。

from pyspark.sql import functions as F
def filtering_before_pandas(input_spark_dataframe):
    # Use PySpark to filter the data
    filtered_spark_df = input_spark_dataframe.select("name", "age").filter(F.col("age") <= 18)

    # Convert to a pandas df, which collects the data to the driver
    pandas_df = filtered_spark_df.toPandas()

    # Perform pandas operations
    mean_age = pandas_df["age"].mean()
    pandas_df["age_difference_to_mean"] = pandas_df["age"] - mean_age

    # Output the resulting DataFrame
    return pandas_df

R 简介

R 转换被定义为一个 R 函数，可具有任意数量的输入、至多一个输出，以及可选的一个或多个可视化。通过将某个转换的别名作为函数参数引用，Code Workbook 会自动将该别名的输出作为该转换的输入传入。有关 Code Workbook 中转换的更多信息，请查阅 转换概览 文档。

output_dataset <- function(spark_df) {
    library(tidyverse)

    # Use SparkR to filter the data
    input_dataset_filtered <- SparkR::select(spark_df, 'column_A', 'column_B')

    # Convert to R data.frame
    local_df <- SparkR::collect(input_dataset_filtered)

    # Use tidyverse functions to transform your data
    local_df <- local_df %>% dplyr::filter(column_A == true) %>% dplyr::mutate(new_column = 1000)

    # Output an R data.frame
    return(local_df)
}

R 故障排除

当 Code Workbook 中导入的数据集被读取为 R data.frame 时，该数据集会通过收集到驱动程序的方式从 Spark DataFrame 转换为 R data.frame。

  • 您无法将任意大的数据读取为 R data.frame。数据大小受限于 Spark 模块上的驱动程序内存。要处理大数据，请考虑先将数据集读取为 Spark DataFrame，使用 SparkR 将数据转换为较小的规模，然后调用 SparkR::collect() 将其转换为 R data.frame。或者，在使用 R 之前，先使用 Python 或 SQL 将数据转换为较小的规模。
  • 将某些数据类型收集到 R data.frame 时存在一些已知问题。在大多数情况下，收集数据时我们会使用一个名为 r-arrow ↗的库，它可以加快序列化和反序列化的速度。特别是，使用 r-arrow 时 Long, Array, Map, Struct日 Datetime 类型无法转换。请考虑删除这些列，或将其转换为其他数据类型（例如 String）。当尝试将包含这些类型的输入读取为 R data.frame 时，界面中会显示警告。

Code Workbook 中的 R 是单线程的，这意味着在同一个 Spark 模块上一次只能运行一个 R 作业。如果您同时启动多个 R 作业，它们将串行运行；排队中的作业将显示为 "Queueing in Code Workbook"。

  • 如果您有长时间运行的作业，或转换结果被保存为数据集的作业，我们建议您运行批量构建。批量构建将在其自己的 Spark 模块上运行，使您可以继续在同一个工作簿或共享该 Spark 模块的其他工作簿中进行迭代。

SQL 简介

Code Workbook 支持的 SQL 方言为 Spark SQL ↗。唯一支持的输入和输出类型是 Spark DataFrame。

一个简单的 SQL 转换示例可以在连接键上连接两个输入 DataFrame。

Copied!

2

SELECT table_b.col_A, table_b.col_B, table_a.*
FROM table_a
JOIN table_b ON table_a.col_C == table_B.col_C

要为 SQL 节点添加父级，仅在代码中引用别名是不够的。您必须通过选择输入栏来使用 UI，或者使用 + 按钮。
