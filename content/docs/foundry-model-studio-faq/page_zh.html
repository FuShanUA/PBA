常见问题

我可以在 Model Studio 中使用对象或媒体集作为输入吗？

不可以，Model Studio 唯一接受的输入是数据集。要实现与使用对象输入类似的结果，您可以使用该对象的支撑数据源作为输入。

为什么我的建模目标评估结果显示我的模型准确率为 100%？

默认 二元分类 和 回归 评估器基于以下假设运行：在输入数据集上运行推理时，输出数据集将同时包含目标列和预测列。然而，Model Studio 训练器默认将预测列名称设置为目标列名称，这会在评估推理作业期间覆盖目标列，并生成不符合评估器假设的数据集。

要解决此问题，您可以在 Model Studio 配置中覆盖预测列名称。手动设置一个与目标列名称不同的预测列名称，以免模型覆盖目标列。
