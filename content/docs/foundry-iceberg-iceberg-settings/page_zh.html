在 Control Panel 中配置 Iceberg 设置

Iceberg 表设置以注册为单位在 Control Panel中进行配置。通过此界面，相关管理员可以配置 Iceberg 存储和加密设置，并为 Iceberg 表在各个项目中的写入方式设置默认值。

要访问 Iceberg 设置，请打开 Control Panel （位于 Applications 门户中），并搜索 Iceberg 表设置 页面。

所需权限

只有拥有 Enrollment Administrator 或 Information Security Officer 角色的用户才能在 Control Panel 中修改 Iceberg 设置。

验证 Iceberg 是否已启用

您可以通过检查 Enable Foundry Iceberg 是否已在 Iceberg 表设置页面顶部开启，来验证您的注册是否可使用 Iceberg。

对于标准企业级 Foundry AWS、Azure 和 GCP 云环境，Iceberg 默认可用。对于本地部署或其他类型的 Foundry 云环境，请联系 Palantir 支持团队获取帮助。

配置 Iceberg 加密设置

Foundry 为 Iceberg 表提供两层加密：

  • 服务器端加密 (SSE) [必需]： 对存储桶中的静态数据进行加密。对于 Foundry 管理的存储，SSE 默认处于启用状态。对于客户管理的存储桶，您必须在存储桶上启用 SSE，以确保静态数据已加密。
  • 客户端加密 (CSE) [可选] 应用 Iceberg 表加密 ↗ 在数据文件写入存储位置之前对其进行加密，在标准服务器端加密的基础上提供额外的一层加密。

客户端 Iceberg 表加密是一项较新且仍在持续发展的功能，目前尚未得到所有 Foundry 功能、外部计算引擎或连接 Iceberg 表的工具的支持。在实现更广泛的兼容性之前，启用该功能可能会导致部分功能受限。

配置存储位置

Foundry 支持以下 存储选项 （适用于 Iceberg 表）：

  • Foundry 管理的存储： 由 Palantir 提供的托管存储。
  • 自带存储桶（BYOB）： 客户管理的存储桶。

要添加客户管理的存储桶，请先按照说明设置您的 BYOB 源。创建源后，您可以在 Control Panel 界面中，通过 配置存储桶 （位于 Iceberg 存储桶部分）来选择该源。您可以配置多个存储位置，并将其用于不同的项目，以组织 Iceberg 表数据的写入位置。

您还可以在此页面上为您的 BYOB 存储桶配置高级存储设置，例如访问委托（Access delegation）详细信息和自定义 FileIO 配置属性。

配置 Iceberg 存储和加密默认设置

您可以配置整个注册范围内如何写入 Iceberg 表的默认设置，并可选择为特定项目或命名空间覆盖这些默认设置。

注册范围级默认设置

在 配置全局 Iceberg 存储 部分中：

  • 默认允许向所有项目写入 Iceberg 表： 启用后，默认情况下可以向任何项目写入 Iceberg 表。禁用后，Iceberg 仅在具有显式覆盖设置的项目中可用。
  • 新建 Iceberg 表的默认存储： 选择新建 Iceberg 表默认使用的存储位置。
  • Iceberg 表加密（客户端加密）： 选择启用还是禁用 客户端 Iceberg 表加密。

项目级或命名空间级覆盖设置

要为特定项目或命名空间覆盖注册范围级默认设置，请选择 添加项目或命名空间 ，位于 自定义存储 部分。对于每个项目或命名空间，您可以覆盖：

  • 该项目中 Iceberg 表的存储位置
  • Iceberg 表的客户端加密设置

项目级或命名空间级覆盖设置仅适用于项目中新写入的表。现有表将保留其当前的存储位置和加密设置。

修改现有设置

当您修改存储设置（例如存储位置或加密配置）时，新设置仅适用于新创建的表。现有表不会被迁移，其加密设置也不会被更改。
