入门

要开始使用计算模块，您可以使用您偏好的开发环境。只需几分钟，您就能创建并部署一个计算模块，并在 Foundry 中对其进行测试。

在 Foundry 中，选择一个文件夹，然后选择 + 新建 > 计算模块，然后按照对话框中的步骤，从一个空的由计算模块支撑的函数或管道开始。请根据您的执行模式，参考下方文档执行后续步骤；或者，若想获得更无缝的体验，请选择 文档 选项卡（位于您的计算模块中），即可跟随平台内的指导进行操作。

构建由计算模块支撑的函数

计算模块通过开源 SDK 支持多种语言。请选择最适合您的团队和用例的语言：

  • Python： 使用 开源 Python 库 ↗。
  • Java： 使用 开源 Java 库 ↗ 与 com.palantir.computemodules:lib 依赖项。
  • Node.js: 使用 开源 TypeScript 库 ↗。

请查看以下 SDK 指南，了解详细的 API 文档、身份验证模式、类型系统和代码示例：

  • Python SDK：包括 @function 装饰器、类型化函数、流式处理、身份验证、OSDK 集成和日志记录
  • Java SDK：包括 ComputeModule 构建器、类型定义、身份验证、OSDK 集成和日志记录
  • TypeScript/Node.js SDK：包括函数注册、TypeBox 模式定义、流式处理和 SLS 日志记录

如果您希望创建自己的客户端，或使用 SDK 不支持的其他语言实现计算模块，请查阅有关如何实现的文档 自定义计算模块客户端.

前提条件：

  • 安装 Docker Desktop
  • 安装以下任意一项：
    • Python 3.9 或更高版本
    • Java 21 或更高版本
    • Node.js 18 或更高版本

理解您的函数代码

在使用计算模块函数时，您的函数将始终接收两个参数： 事件对象 和 上下文对象。

上下文对象： 一个包含您的函数可能需要的元数据和凭证的对象参数。示例包括用户令牌、源凭证和其他必要数据。例如，如果您的函数需要调用 OSDK 来获取本体论对象，则上下文对象会包含用户访问该本体论对象所需的令牌。

事件对象： 一个包含您的函数将要处理的数据的对象参数。包括传递给函数的所有参数，例如 x 和 y 在 add 函数中，并且 name 在 hello 函数中。在 Python 中，这是一个 dict；在 Java 中，这是一个 JSON 节点对象；在 Node.js 中，这是一个普通 JavaScript 对象。

如果您为事件/返回对象使用静态类型，该库会将有效负载/结果转换为该静态类型对象。请查阅相关文档以了解 自动函数架构推断 以获取更多信息。

函数结果将作为 JSON blob 传递，因此请确保函数能够被序列化为 JSON。

创建您的第一个容器

现在，您可以使用 Artifact 仓库将代码发布到 Foundry，该仓库将用于存储您的 Docker 镜像。

  1. 创建或选择一个 Artifact 仓库，以将您的代码发布到 Foundry。为此，请导航至您计算模块中的 文档 选项卡。然后，找到与此外部文档页面对应的平台内文档部分： 构建由计算模块支撑的函数 > 创建您的第一个容器。在那里，您可以 创建或选择代码仓库。
  2. 在下一页上，从下拉菜单中选择 发布到 DOCKER 并按照页面上的说明推送您的代码。
  3. 在 配置 标签页（位于您的计算模块中），选择 添加容器。然后，选择您的 Artifact 仓库以及您推送的镜像。
  4. 选择 更新配置 以保存您的更改。
  5. 配置更新后，您即可启动计算模块，只需前往 概览 页面，使用底部 Query 面板对其进行测试，并查看日志。

使用代码仓库构建

作为本地开发的替代方案，您可以直接在 Foundry 平台中使用代码仓库构建 Python 计算模块。这种方法提供了一体化的开发体验，内置版本控制、依赖管理和容器镜像发布功能。

前提条件

  • 了解 函数执行模式 及其配置。
  • 熟悉 代码仓库。

创建 Python 计算模块代码仓库

  1. 在 Foundry 中，导航到某个文件夹并选择 + New > Code Repository。
  2. 选择 Python 计算模块 作为仓库类型。
  3. 为您的仓库命名并选择 创建。

代码仓库将预先配置计算模块所需的项目结构，包括一个 src/ 目录和默认配置文件。

在代码仓库中编写函数

在 src/ 目录中，打开 app.py 文件，并使用 @function 装饰器来定义您的函数：

Copied!
1from compute_modules.annotations import function
2
3@function
4def add(context, event):
5    return str(event['x'] + event['y'])
6
7@function
8def hello(context, event):
9    return 'Hello ' + event['name']

如需支持自动架构推断的类型化输入和输出，请使用 TypedDict 或 dataclass 类型，具体请参阅 自动函数模式推断 文档。

添加 Python 库

您可以通过两种方式向计算模块代码仓库添加 Python 库：

  • 使用 Settings 面板： 导航至 Settings > Libraries ，在您的代码仓库中添加所需的库。
  • 使用 meta.yaml： 直接在仓库根目录下的 meta.yaml 配置文件中添加依赖项。

标记版本

代码准备就绪后，在代码仓库中标记一个版本以创建镜像：

  1. 选择 标记版本 从仓库工具栏中。
  2. 输入版本号（例如， 0.0.1）。
  3. 选择 标签 以创建该版本。

这将创建一个可关联到您的计算模块的容器镜像。

将镜像关联到您的计算模块

  1. 导航至你的计算模块的 「配置」 选项卡。
  2. 选择 「添加容器」。
  3. 选择你的代码仓库以及你创建的带标签版本。
  4. 选择 更新配置 以保存您的编辑。

导入函数

计算模块运行后，您可以导入您的函数：

  1. 导航至 函数 标签页（位于计算模块应用中）。
  2. 选择 导入 以查看正在运行的计算模块中检测到的函数列表。
  3. 选择要注册的函数并确认导入。

您的函数现在可在整个 Foundry 平台上使用，包括在 Workshop 和 Slate 应用程序中。

构建由计算模块支撑的管道

计算模块可以在容器化环境中作为数据管道输入和输出之间的连接器运行。在本示例中，您将构建一个简单的用例，以流式数据集作为计算模块的输入和输出，定义一个将输入数据翻倍的函数，并将其写入输出数据集。您将使用假设数据来模拟一个正常工作的数据管道。

先决条件

  • 了解 管道执行模式 及其配置。
  • 设置 输入和输出流。
  • 安装 Docker Desktop。
  • 安装 Python 3.9 或更高版本

Copied!
1import os
2import json
3import time
4import requests
5
6# Read the bearer token for input and output access
7with open(os.environ['BUILD2_TOKEN']) as f:
8    bearer_token = f.read()
9
10# Read input and output resource information
11with open(os.environ['RESOURCE_ALIAS_MAP']) as f:
12    resource_alias_map = json.load(f)
13
14input_info = resource_alias_map['identifier you put in the config']
15output_info = resource_alias_map['identifier you put in the config']
16
17input_rid = input_info['rid']
18input_branch = input_info['branch'] or "master"
19output_rid = output_info['rid']
20output_branch = output_info['branch'] or "master"
21
22FOUNDRY_URL = "yourenrollment.palantirfoundry.com"
23
24def get_stream_latest_records():
25    url = f"https://{FOUNDRY_URL}/stream-proxy/api/streams/{input_rid}/branches/{input_branch}/records"
26    response = requests.get(url, headers={"Authorization": f"Bearer {bearer_token}"})
27    return response.json()
28
29def process_record(record):
30    # Assume input stream has schema 'x': Integer
31    x = record['value']['x']
32    # Assume output stream has schema 'twice_x': Integer
33    return {'twice_x': x * 2}
34
35def put_record_to_stream(record):
36    url = f"https://{FOUNDRY_URL}/stream-proxy/api/streams/{output_rid}/branches/{output_branch}/jsonRecord"
37    requests.post(url, json=record, headers={"Authorization": f"Bearer {bearer_token}"})
38
39# Run the pipeline autonomously
40while True:
41    records = get_stream_latest_records()
42    processed_records = list(map(process_record, records))
43    [put_record_to_stream(record) for record in processed_records]
44    time.sleep(60)

了解您的管道代码

为了与输入和输出进行交互，我们提供了 不记名令牌和输入/输出信息。

然后，您可以编写代码来与输入和输出进行交互并执行计算。代码片段提供了对两个流式数据集进行管道化处理的简单示例：

  • 它会使用 bearer token 和输入信息，通过调用 stream-proxy 服务，从输入流数据集中读取最新记录。
  • 然后，它会执行计算（在上面的示例中，将数据加倍）。数据格式取决于您自己的输入数据。
  • 接着，它会使用 bearer token 和输出信息将结果写入输出流数据集。
  • 最后，由于您无法查询管道模式计算模块，代码会在脚本末尾自主运行管道，而该脚本将在容器启动时执行。
