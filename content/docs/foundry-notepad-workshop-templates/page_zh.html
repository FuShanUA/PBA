生成并导出文档

要允许他人基于您的模板或字符串变量生成新文档，请使用 Notepad: 新建 Notepad 按钮 小部件。您还可以选择允许将这些文档导出为 PDF。

Notepad: 新建 Notepad 按钮小部件

直方图 Notepad: 新建 Notepad 按钮 小部件允许您从模板或 Workshop 字符串变量创建并导出 Notepad 文档。

从模板生成文档

首先，添加 Notepad: 新建 Notepad 按钮 小部件到您的 Workshop 模块。然后，从屏幕右侧的配置选项中选择 Template(s) 选项，然后选择 + 选择。在文件系统视图中，浏览找到您的 Notepad 模板文件，将其添加到 文档模板 列表。 接下来，选择新的模板条目以打开其配置，然后选择一个 模板版本。如果没有可用版本，请在新标签页中打开模板并 发布模板版本。选择版本后将自动加载模板所需的 连接，这些参数在生成时传递。 菜单中选择 模板输入 区域的字段中添加命令。

您可以为模板指定一个 菜单显示名称 （可选）。如果您未设置显示名称，则将使用 自定义文本 来自 按钮显示 设置。

模板输入

根据模板及其版本，您的 Notepad 模板可能会使用多个模板输入。对于其中每个输入，请关联一个 Workshop 变量 ，其数据类型（字符串、数字、日期、时间戳、对象或对象集）应与您要用作模板输入的类型相同。每当选择 Notepad: 新建 Notepad 按钮 。

如果您的输入参数需要单个对象，请务必将其关联到包含一个对象的 Workshop 对象集变量。

从字符串变量创建文档

要从 Workshop 字符串变量（而非文档模板）创建 Notepad 文档，请选择 字符串 配置选项（位于右侧面板中）。变量值可以按照我们的 现有 Markdown 功能.

在操作中使用生成的 Notepad RID

要将生成的 RID 传递给操作，相应的参数必须具有已配置的类型类。为此，请在 Ontology Manager 中打开操作参数并添加一个 notepad:notepad_rid 类型类于 详情 标签页。
