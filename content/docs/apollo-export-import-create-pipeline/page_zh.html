创建和修改导出管道

本指南将介绍如何 创建、 编辑，以及 删除 导出管道，该管道定义了 Apollo 将在捆绑包中包含哪些资源，您可以将这些捆绑包导出并发送到目标中心。

创建导出管道

要创建导出管道，请选择 Export （位于左侧边栏的 Applications 菜单中）。

然后选择 Create Pipeline （位于 Actions 下拉菜单中）。

这将打开导出管道创建表单。

首先，您应为导出管道输入名称和描述。请勿在导出管道的名称中包含敏感信息或个人 身份信息。

构建设置

接下来，您应配置导出管道的构建设置。

有两种构建策略：

  • 增量： 使用此策略时，只有导出管道中之前的捆绑包尚未交付的信息才会包含在新捆绑包中。例如，如果您使用 Select Product 策略并创建捆绑包，则任何后续的捆绑包构建都不会包含任何之前已导出的产品发布版本。此策略可减小捆绑包大小并缩短传输时间，但要求必须按顺序处理所有捆绑包。
  • 快照： 使用此策略时，每次构建都会对选择器规则进行完全重新评估。所有 Bundle 数据（包括产品发布、元数据和模块信息）都将包含在 Bundle 中，无论这些信息是否已由导出管道中之前的 Bundle 交付。

通常，您应始终使用 增量 构建策略。 快照 策略仅建议用于一次性传输。

接下来，选择 Apollo 为此导出管道构建和导出 Bundle 的频率。您可以选择一种默认构建频率，也可以使用 Cron 调度来定义自定义频率。

接下来，按需配置 Bundle 分块设置 ，以及创建 检查点 Bundle的频率。

最后，您可以选择为此导出管道禁用 Bundle 预览 。默认情况下，Bundle 预览处于启用状态。 Bundle 预览允许您在构建之前查看 Bundle 的内容。

高级设置

您可以配置是否在缺少资源的情况下仍构建 Bundle。如果启用此设置且某个资源缺失，Bundle 构建将在没有该资源的情况下继续进行。 例如，Product Release 可能引用注册表中不可用的容器镜像。如果禁用此设置，由于找不到该资源，Bundle 构建将失败。如果启用此设置，Bundle 构建将成功，且该容器镜像将从 Bundle 中省略。

数据选择规则

接下来，您将配置一个或多个数据选择规则。这些规则定义了为导出管道构建的 Bundle 的内容。要添加新规则，请选择 添加规则。您可以直接选择资源，也可以按标签选择资源。

了解有关数据选择规则的更多信息。

资源选择

定义数据选择规则后，您可以进一步自定义要导出的资源。选择一个预定义预设，或创建自定义选择。

了解有关资源选择的更多信息。

必需的资源标签

您还可以添加标签要求，资源必须满足这些要求才能被导出。

了解有关标签要求的更多信息。

风险管理

您可以配置管道风险管理策略。

了解更多有关 Bundle 安全性的信息。

提交

选择 “提交” 以在您完成编辑后创建变更请求。变更请求获得批准后，您的更改将生效。若要查看您新建的导出管道，您可以导航至 “所有管道” 表格（位于 “导出”中）。

修改导出管道

您可以在 Apollo 中编辑、归档和删除导出管道。为此，请导航至 “所有管道” 表格（位于 “导出”中）。选择一个导出管道，然后选择所需的操作。

如果您的导出管道状态与 Target Hub 的实际状态不同步，请更新您的 Target Hub 版本 以反映这些差异。

移除导出管道

归档导出管道后，您将无法再修改导出管道设置。Apollo 将不再为该导出管道创建 Bundle，您也将无法手动创建 Bundle。归档导出管道后，您可以将其取消归档，以便能够修改设置并为该导出管道构建 Bundle。

删除导出管道时，您将移除该导出管道的 Bundle 历史记录和历史设置。此操作无法撤销。

要将导出管道从 Apollo 中完全移除，您必须 归档 然后 删除 它。
