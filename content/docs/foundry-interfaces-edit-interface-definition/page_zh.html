编辑接口定义

重大变更

鉴于接口会公开 API 名称，对接口定义的任何变更都有可能破坏下游应用程序，并且必然会破坏现有的对象实现。在向接口添加新的必填属性、关联类型约束或操作类型约束时，所有使用该接口的对象类型的实现 必须 在同一次本体论更新中一并完成。我们还建议同时更新接口定义和使用方。

如果您的下游应用程序无法与接口变更同时更新，您可以改为创建新版本的接口（作为 扩展 或独立接口），并尽快迁移到新的接口定义。

添加新属性

在 属性 选项卡（接口配置）中，选择 新建属性。这将会打开一个接口属性配置侧面板。

用于编辑属性元数据的可用选项分为四个不同的选项卡，通过这些选项卡可访问以下配置：

  1. 显示名称和描述： 点选现有的显示名称或描述即可编辑文本。
  2. API 名称： 点选现有的 API 名称即可更改其值。
  3. 属性基础类型： 从下拉菜单中选择属性的基础类型。属性类型限定了可对其值执行的操作集合。
    • 例如，基础类型为 timestamp 的属性可以显示在 Object Explorer 的时间线小组件中。
  4. 主键约束： 指示属性是应作为主键，还是不能作为主键。

如果您更改接口属性类型，则还必须更新实现该接口的所有对象类型。

  1. 类型类： 将类型类作为附加元数据应用，可由应用程序进行解析。
    • 请查阅 类型类文档 以获取可用类型类的列表。
  2. 渲染提示： 通过从清单中选择渲染提示，改进属性值渲染并索引到对象存储 v1（Phonograph）的方式。
    • 有关构建自定义主题的示例，请参阅 渲染提示文档 ，以了解可用渲染提示的相关说明。
  3. 可见性： 选择现有可见性，以打开可用可见性选项的下拉菜单。 prominent 属性将使应用程序优先向用户显示该属性。 hidden 属性不会出现在用户应用程序中。

添加共享属性

在 属性 选项卡（位于接口配置中）中，选择 添加共享属性 并选择要添加到接口的共享属性。

添加关联类型约束

在 关联类型约束 标签页中，选择 创建新关联类型约束 并添加必要的 约束元数据.

添加操作类型约束

在 操作类型约束 标签页中，选择 创建新操作类型约束 并添加必要的 约束元数据 和 参数约束.

移除属性

在 属性 标签页中，选择 ... （位于要从接口中移除的属性旁边）。或者，打开接口属性侧面板，并选择右上角的垃圾桶图标。

移除或编辑关联类型约束

在 关联类型约束 标签页中，选择 ... 位于您想要编辑或从接口中移除的关联类型约束旁边。

如果要编辑约束，您可以像首次 创建关联类型约束 时那样更新元数据。

移除或编辑操作类型约束

在 操作类型约束 标签页中，选择 ... （位于您想要编辑或从接口中移除的操作类型约束旁边）。

如果要编辑约束，您可以像首次 创建操作类型约束 时那样更新元数据。
