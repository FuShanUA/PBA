Sensitive Data Scanner

Sensitive Data Scanner（SDS，前身为“Foundry Inference”）可帮助组织发现并保护 Foundry 中的敏感数据。治理用户可以使用 SDS 指定要识别的敏感数据模式，以及在发现此类敏感数据时采取的相应自动化操作。

根据这些指令，Sensitive Data Scanner 可以在所有指定的数据集上运行一次性扫描或按计划重复执行的扫描。Sensitive Data Scanner 使治理用户能够深入洞察并掌控其在 Foundry 中的数据，同时简化了对全球数据保护法规的合规工作。

我们建议新用户查阅 Sensitive Data Scanner 的 核心概念 以及如何 创建敏感数据扫描的说明。查阅 SDS 最佳实践指南 ，以缩短扫描计算时间、提升工作流效率，并根据资源权限管理用户交互。

如需了解 Foundry 中其他可帮助您的组织遵守 GDPR、CCPA、LGPD 及其他隐私法律的功能，请参阅我们的 数据保护与治理页面。

您的注册中可能默认未启用 Sensitive Data Scanner。要启用该功能，请按照以下说明操作：

  1. 导航至 Control Panel。
  2. 从左侧边栏中选择您的组织。
  3. 选择 应用程序访问。
  4. 向下滚动以找到 敏感数据扫描器 ，它位于 安全与治理 部分下，然后选择 管理 选项。
