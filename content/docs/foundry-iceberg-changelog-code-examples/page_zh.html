示例:Python 转换中的变更日志视图

本页面提供在 Python 转换中处理 CDC(变更数据捕获)和 Iceberg 变更日志的代码示例。

请特别注意以下模式和最佳实践:

  • 始终使用 @incremental(v2_semantics=True) 来处理 Iceberg 表。
  • 将 .with_table_incremental_options(table_read_mode="changelog") 添加到装饰器中。如果不添加,转换将以仅追加模式解析其输入,并且 source.changelog() 会引发错误。请参阅 增量读取模式 以了解详情。
  • 使用 source.changelog([identifier_columns]) 来获取自上次运行以来每个唯一行(由标识符列定义)的变更。
  • 在合并之前,对变更日志应用逻辑(例如清理、去重或数据增强)。
  • 使用 output.apply_changelog(changelog_view_df, [identifier_columns]) 来合并变更(包括 upsert 和删除)。
  • 仅在增量上下文不可用时(例如,在首次运行时),才回退到全量快照覆盖。

示例:增量复制

此示例是一个简单的 CDC 工作流,它在应用所有必要的过滤后,使用变更日志 API 将变更从源 Iceberg 表复制到目标表。

from transforms.api import (
    IncrementalTableTransformInput,
    IncrementalTransformContext,
    incremental,
    transform,
)
from transforms.tables import TableInput, TableOutput, TableTransformOutput

@incremental(v2_semantics=True).with_table_incremental_options(table_read_mode="changelog")
@transform.spark.using(
    source=TableInput("<PATH>/input"),
    output=TableOutput("<PATH>/output"),
)
def incremental_cleanup(
    ctx: IncrementalTransformContext,
    source: IncrementalTableTransformInput,
    output: TableTransformOutput,
):
    # Create a changelog view from the last seen Iceberg snapshot ID.
    changelog_view_df = source.changelog(["id"])

    # Read the changelog view, then merge into the target Iceberg table.
    output.apply_changelog(
        changelog_view_df.filter(...),  # Changelog view with any transformation logic applied
        ["id"]  # Identifier column(s)
    )

关键点:

  • source.changelog([identifier_cols]) 仅返回自上次运行以来新增、已更改或已删除的行。
  • 变更日志数据帧可以被修改,但 _change_type 列必须保留,前提是您打算使用 apply_changelog。
  • output.apply_changelog(df, identifier_columns) 将变更合并到目标表中。每一行都根据其 _change_type 值及其在输出表中基于标识符的匹配项：
    • INSERT/UPDATE_AFTER：更新任何与标识符列匹配的现有行，如果没有匹配项，则插入新行。 UPDATE_BEFORE 被忽略。
    • DELETE：删除输出表中与标识符列匹配的任何现有行。

变更日志性能优化

  • 变更日志的读取和更新在增量更改时性能最佳。将整个输入表作为变更日志进行读取和应用可能会很慢，因为需要在较大的快照范围内对行更改进行关联。为提升性能，请使用 ctx.is_incremental 对代码进行分支，并在转换未以增量方式运行时（例如首次运行时）回退到完整快照覆盖。

def changelog_with_fallback(ctx, source, output):
    if ctx.is_incremental:
        changelog_df = source.changelog(["id"])
        output.apply_changelog(changelog_df.filter(...), ["id"])
    else:
        # Full snapshot overwrite
        output.write_dataframe(source.dataframe().filter(...))

  • 提供标识符列时，变更日志视图的创建性能更佳，因为这可以实现更简单的内部分区。如果未传递标识符列，系统将生成净变更日志，其效率可能较低。请参阅 变更日志技术入门 ，了解有关使用净变更日志的更多详细信息。
