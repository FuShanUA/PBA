值类型约束

每种值类型都可以选择定义一个约束来实施数据验证。您可以在 创建新值类型时 于 Value Type Manager 应用程序中配置这些约束。可用的值类型约束及其适用的基本类型如下：

  • 枚举（多选一）： 一种表示允许值静态集合的约束。
    • 有效的基本类型： String、Boolean、Decimal、Double、Float、Integer 或 Short。
    • 对于 String 属性，枚举值可以选择区分大小写或不区分大小写。
  • 范围： 最小值、最大值或允许值的范围。
    • 有效的基本类型： Decimal、Double、Float、Integer、Short、Date、Timestamp、String 或 Array。
    • 对于 String 属性，约束的是字符串的长度。
    • 对于 Array 属性，约束的是数组的大小。

此外，以下属性类型还提供额外的特定于类型的约束：

  • String：
    • 正则表达式： 字符串必须匹配的正则表达式模式。可以选择让正则表达式验证在仅匹配属性值的子字符串时通过。
    • RID： 字符串必须是有效的 rid。
    • UUID： 字符串必须是有效的 UUID。
  • Array：
    • 唯一性： 数组中的所有元素都必须唯一。
    • 嵌套： 值类型约束可以应用于数组中的元素。例如，可以将正则表达式约束应用于数组中的每个字符串。
  • 结构体：
    • 元素约束： 结构体字段标识符与值类型引用之间的映射，其中结构体字段标识符指明了所引用的值类型应应用于哪个结构体组件。
