仪表盘

通过 Foundry 分析构建交互式仪表板主要有两种方式： Contour 仪表板 和 Quiver 仪表板。在某些情况下，您可能希望使用 Code Workspaces 仪表板, 或，或 自定义应用程序 作为替代。本页面将讨论您可以使用哪些工具以及何时使用它们。

了解 Contour 与 Quiver 之间的区别。

Contour 仪表板

Contour 仪表板用于展示 Contour 分析中的内容，例如分析结果和发现。这些仪表板支持图表间筛选、内联参数引用、全屏演示视图以及 PDF 导出。

Quiver 仪表板

Quiver 仪表板用于以只读的交互式仪表板形式展示 Quiver 分析中的内容。

Quiver 仪表板可以作为独立仪表板使用，也可以嵌入到 对象视图, Workshop 应用程序，或 Notepad 文档中。Quiver 仪表板还可以显示在 碳 中，并直接交付给运营用户。

其他展示工具

或

Contour 仪表板和 Quiver 模板最适合在 Foundry 中直接使用，因为其交互式设计允许用户通过参数和图表选择来处理实时数据。相比之下， 或 专为侧重于创建可导出的静态内容的报告工作流而设计。此外，Notepad 文档可以包含来自多个应用程序的内容（包括 Contour 板和 Quiver 卡片），而 Contour 仪表板和 Quiver 模板仅支持来自各自应用程序的内容。由于侧重于静态内容，用户无法直接在 Notepad 中进行分析或创建图表。

了解有关报告工作流的更多信息。

自定义应用程序

Contour 仪表板和 Quiver 模板经过优化，可轻松展示分析结果的交互式视图，而应用程序构建工具（如 Workshop）可能更适合某些用例。具体而言，如果您的用例需要完全自定义和布局灵活性、多步骤工作流或数据回写，您应考虑 Foundry 的 应用程序构建工具.

Quiver 仪表板可以嵌入到 Workshop 应用程序中，从而为运营用户提供更复杂的分析内容。
