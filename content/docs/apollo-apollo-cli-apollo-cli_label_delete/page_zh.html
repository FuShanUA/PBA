参数： Apollo 资源的类型 （参见下方的“支持的资源类型”） 资源的标识符 — 格式取决于 资源类型（也见下方）

示例： apollo-cli label delete product-release com.palantir.product:foo:1.0.0

支持的资源类型： product-release 标识符：maven 坐标（例如 com.palantir.product:foo:1.0.0）

从父命令继承的标志

标志用途
--apollo-client-id用于生成 Bearer Token 的客户端 ID
--apollo-client-secret用于生成 Bearer Token 的客户端密钥
--apollo-token用于需要身份验证的端点的 Bearer Token
--apollo-token-provider指定用于经过身份验证的 Apollo 端点调用的 Bearer Token 是如何提供的。有效值为 "auto"、"static"、"service-user" 或 "sso"（默认值为 "auto"）。如果指定了 "auto"，则根据已有配置选择模式：如果设置了 "apollo-token"，则选择 "static"；如果同时设置了 "apollo-client-id" 和 "apollo-client-secret"，则选择 "service-user"；否则选择 "sso"（交互式浏览器登录）。如果同时设置了 Bearer Token 和（客户端 ID 或客户端密钥），则会报错。如果指定了 "static"，则使用 "apollo-token" 提供的令牌。如果指定了 "service-user"，则使用 "apollo-client-id" 和 "apollo-client-secret" 从 Multipass 生成令牌。如果指定了 "sso"，则使用针对 Multipass 的基于浏览器的交互式 SSO 登录（支持 YubiKey 等硬件密钥）；生成的令牌会按配置档案缓存并静默刷新。当命令首次需要令牌且不存在有效的缓存令牌时，将自动触发登录流程。
--apollo-urlApollo 的基础 URL，用于推导 API 端点
--debug启用调试级别的日志记录
-e, --environment用于环境作用域命令的环境 ID（包括后缀）
--http-timeout所有 Apollo 请求的超时时间（以分钟为单位）
-k, --insecure-skip-verify跳过服务器证书验证
-o, --output输出格式 (json,yaml,pretty)
--profile使用配置文件中的特定配置档案
--quiet不将日志输出打印到 stderr
--space-id用于某些空间作用域命令的 Space ID
--sso-callback-port用于 SSO OAuth 回调的本地环回端口；设为 0 时会选择一个可用的临时端口
