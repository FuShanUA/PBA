Iceberg 表与 Foundry 数据集

Iceberg 表 和 数据集 都是可用于在 Foundry 中表示表格数据的资源类型。Iceberg 表提供了与更广泛的 Iceberg 生态系统的互操作性以及行级编辑和变更日志等功能，而数据集目前支持更多的 Foundry 功能。

Iceberg 表的优势

Iceberg 表的以下优势目前在 Foundry 中可用：

  • 互操作性： 开放的 Iceberg 格式意味着第三方工具可以更轻松地读取和写入 Palantir Iceberg 表。
  • 压缩： 支持 压缩 而不影响增量读取。
  • 行编辑： 支持 DELETE、 UPDATE和 MERGE INTO 语句，这些语句允许您有条件地修改行，而无需重新创建快照。
  • 变更日志： 以增量方式消费 行的删除和更新。
  • 增强的表历史记录： 增强的历史视图，可展示 Iceberg 表元数据 ↗。

Iceberg 表不支持的 Foundry 功能

请注意，Iceberg 表目前不支持某些 Foundry 功能，包括：

  • Foundry 视图 （Iceberg 视图 ↗ 同样不受支持）
  • 受限视图
  • 流式处理
  • 时间序列同步
  • 投影
  • 对象物化

细粒度访问控制

细粒度访问控制所支持的方法取决于用户在何处访问数据：

  • 在本体论中： 由 Iceberg 表支撑的对象类型可以使用 对象和属性安全策略 进行行级和列级访问控制。您的注册环境可能不支持在 Iceberg 支撑的对象类型上使用这些策略。请联系 Palantir 支持团队以请求访问权限。
  • 在表级别： Iceberg 表无法直接支撑 受限视图。如果您需要在本体论之外进行行级访问控制，请创建一个从 Iceberg 表读取数据的 Foundry 数据集，然后基于该数据集创建受限视图。

Iceberg 表还支持用于全表访问控制的标记。请参阅 Iceberg 表上的标记。

Marketplace 支持

您可以将托管的 Iceberg 表打包到 Marketplace 产品 中，并 将这些产品安装 到目标环境中。每个已安装的表必须使用与打包的表相同的 存储类型 ：Foundry 托管存储或自带存储桶（BYOB）存储。例如，使用 Foundry 托管存储的表无法作为使用 BYOB 存储的表进行安装，反之亦然。

Iceberg 表与 Foundry 数据集之间的显著差异

需要注意 Iceberg 表与 Foundry 数据集之间的以下行为差异。

  • 默认分支： Iceberg 的主分支称为 main，而 Foundry 的主分支称为 master。在 Foundry 与 Iceberg 的集成中， main 和 master 被视为相同,这意味着在 master 上运行的 Foundry 作业将写入 Iceberg 表的 main。请参阅 分支 以详细了解 Foundry 如何按分支隔离架构变更。
  • 标记: 任何保留的 Iceberg 快照所继承的标记都可能阻止不满足该标记的用户读取整个表,包括原本未标记的分支。数据集标记的强制执行范围则更窄,仅限于所请求的视图。请参阅 Iceberg 表上的标记 以了解详情和有关取消标记工作流的指导。
  • 自动架构演进: Iceberg 表的架构演进并非总是自动进行的。某些工作流(例如表替换)会自动演进表的架构;然而,其他工作流则需要显式的架构演进命令或设置,例如 ALTER TABLE。通过 Foundry 的转换 API 和管道构建器进行写入时,Foundry 在非增量运行时会使用表替换来为您处理此问题。其他工作流(例如增量架构演进)可能会失败,需要手动解决。请参阅 Apache Iceberg 有关架构演进的文档 ↗ 以了解详情。

Iceberg 术语辨析

Iceberg 引入的某些术语在 Foundry 中并不总有直接对应的概念:

Iceberg 术语含义Foundry 辨析
表元数据 ↗描述 Iceberg 表的结构、架构和状态的元数据。Foundry 还会跟踪所有格式的表和数据集的元数据，但此元数据由 Foundry 服务在内部管理。对于 Iceberg 表，Foundry 会通过 Iceberg 目录以 JSON 文件的形式显式公开原生 Iceberg 元数据。
快照 ↗表在特定时间点的状态记录。每次数据修改时，Iceberg 都会创建一个新快照。Iceberg 快照大致相当于 Foundry 中的 事务。但是，Foundry 以不同的方式使用 "快照" 一词：在 Foundry 中，"快照"指的是完全替换数据集中所有数据的事务，而 Iceberg 快照则捕获所有类型的数据操作，包括增量变更。参见 Iceberg 快照类型 ，以完整区分 Foundry 目录数据集事务类型与 Iceberg 快照类型。
