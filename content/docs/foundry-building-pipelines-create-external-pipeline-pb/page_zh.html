Pipeline Builder 中的外部管道

如果您是 Pipeline Builder 的新用户，请先查看 如何在 Pipeline Builder 中创建批处理管道 ，然后再继续。

Pipeline Builder 现在提供 外部管道，它可将计算下推到外部计算引擎。其功能类似于 Python 转换中的计算下推，并允许在外部数据仓库计算的基础上使用 Foundry 的管道管理、数据血缘和安全功能。

与 Python 转换中的计算下推一样，外部管道的所有输入和输出都必须是 虚拟表。

使用外部计算构建的表可以通过 Foundry 的调度工具与使用 Foundry 原生计算构建的数据集和表组合在一起，让您能够在整个流程的每个步骤都使用最合适的计算，从而编排复杂的多技术管道。

Pipeline Builder 支持的外部计算引擎

目前，Pipeline Builder 支持的外部计算引擎为 Databricks 和 Snowflake。要使用其他外部计算引擎（如 BigQuery），请使用 带计算下推的转换。

源类型状态
BigQuery不可用
Databricks正式发布
Snowflake正式发布

创建新的外部管道

  1. 打开 Pipeline Builder 并选择 创建新管道。
  2. 为管道输入名称并选择所需位置后，请选择 批量管道 > 外部 （在配置设置中），然后选择 下一步。
  3. 搜索并选择您的 受支持的外部源 ，然后将其导入管道。
  4. 现在，您可以将该源中的虚拟表添加到图中，并照常创建管道。
  5. 所有管道输出都将是 虚拟表输出 （位于源中）。
  6. 准备好构建后，请保存并部署管道。管道将使用外部计算运行，然后将结果输出为虚拟表，并存储在源系统中。

所有输入和输出表必须是您在管道设置过程中选择的同一源中的虚拟表。对于 Databricks 外部管道，仅支持 Databricks 表。对于 Snowflake 外部管道，仅支持来自同一外部卷的 Snowflake 虚拟表。使用外部管道时，不支持将 Foundry 数据集作为输入或输出。

配置构建设置

您可以在构建设置面板中编辑管道源，并配置特定于源的计算选项。

外部计算的配置位于 默认计算配置文件 构建设置下。

源类型计算配置文件描述
Databricks无服务器使用 Databricks Connect 的无服务器计算（默认）。请参阅 Databricks 官方文档 ↗ 以了解有关 Databricks Connect 中计算选项的更多信息。
Databricks经典计算指定经典计算集群的集群 ID。如果未指定，Spark 集群 ID 将从数据源配置中派生。如果数据源配置为使用 SQL 仓库，则必须提供该 ID。
Snowflake计算仓库指定用于计算的 Snowflake 仓库。如果未指定，将使用在数据源上配置的计算仓库。

已知限制

外部管道目前不支持与标准批处理管道相同的转换和表达式集。

由于外部管道与批处理管道之间存在差异，您应始终使用 预览 或通过检查构建输出来验证结果。

目前不支持的功能和表达式包括：

  • 增量计算
  • LLM 功能
  • 媒体集操作
  • Union
  • 用户自定义函数
  • 地理空间操作
