如何在我的代码仓库中启用 linter？

您可以在自己的代码仓库中的 transforms-python/build.gradle 中取消注释与 lint 相关的行。这将启用一个 linting 任务，该任务会提供有关违反 pep8 或 pylint 格式规则的提示。

如何在 Spark 配置文件中实现执行器的自动扩缩容，以便根据转换输入数据的大小进行动态调整？

通过启用动态分配（dynamic allocation）可以实现执行器的自动扩缩容。动态分配可自动扩缩执行器数量，但无法自动调整执行器/驱动程序的内存。DYNAMIC_ALLOCATION_MAX_64 和 DYNAMIC_ALLOCATION_ENABLED 等特定配置文件支持此功能。更多信息以及内置了动态分配配置的配置文件列表，请参阅 Spark 配置文件参考文档。

如何在我的 Python 代码仓库中启用自动格式化工具？

在提交代码时，选择 提交前格式化 选项将运行 formatCode 任务。该任务可以使用 ruff 或 black 作为格式化工具。具体可以通过取消注释 transforms-python/build.gradle 文件中与格式化工具相关的相应行来进行控制。

应采取哪些步骤来排查和解决转换中报错信息为 No module named <module-name>; <package-name> is not a package 的导入错误？

要排查并解决导入错误，请按照以下步骤操作：

  1. 验证库的安装情况，并确保其已正确安装在您的代码仓库中。
  2. 检查是否存在隐藏文件，并确保环境配置已正确设置。
  3. 通过查看软件包解析日志来解决任何软件包冲突。
  4. 如有必要，可通过创建新的提交来重新触发环境解析。
  5. 如果该模块之前可以正常工作但现在停止工作，请检查库的版本差异，确认是否存在重大破坏性变更。

在转换中，写入 pandas dataframe 的正确方法是什么？

要写入 pandas dataframe，您应该使用 .write_pandas() 方法。如果您遇到 AttributeError: 'DataFrame' object has no attribute '_jdf'，这意味着您正在使用一个为 pyspark dataframe 设计的方法来处理 pandas dataframe。

时间戳： 2024年5月30日

是否可以在没有输出数据集的转换上设置计划，以便触发 Python 脚本来调用外部 API？

不可以，在没有输出数据集的情况下无法为转换设置计划。推荐的解决方案是将来自外部 API 的响应跟踪记录到输出数据集中，以便进行日志记录。或者，也可以使用通过 Automate 触发的函数来运行任意代码，但拥有输出数据集对于日志记录仍然很有价值。
