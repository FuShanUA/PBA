示例用例

使用 Vertex 探索关联数据、模拟决策并可视化运营流程。

模拟、动态分析与决策优化

使用在 Foundry 中发布的模型、预测或业务逻辑来探索您的数字孪生：

  • 在整个网络中运行“假设”分析和模拟，以比较决策、事件或系统变更的影响。
  • 将真实世界的上下文应用于模拟，以量化拟议变更的影响。
  • 连接数字孪生中的流程和系统，以跨团队和数据源分析运营情况。

预测性维护

在本体论中连接设备、传感器读数和维护历史记录，以了解资产健康状况并规划维护：

  • 比较传感器时间序列（如温度或振动）与相关的维护事件。
  • 使用在 Foundry 中发布的模型的预测结果来评估设备故障风险。
  • 探索关联资产并比较维护场景，以了解对生产的潜在影响。

本体论编辑： 探索相关时间序列 和 运行场景.

开放式图调查

从感兴趣的对象开始，随着新问题的出现，探索本体论中的关系：

  • 沿着关联发现相关对象并扩展您的图。
  • 使用多步 Search Around 和筛选器来追踪路径并聚焦于相关的连接。
  • 保存图并与其他调查人员共享，以共同审查调查结果。

本体论编辑： 探索对象关系, 使用函数构建高级 Search Around日 保存并共享图.

测试版

Vertex中的绘图功能正处于 测试版 阶段，可能无法在您的注册中使用。在积极开发期间，功能可能会发生变化。要启用此功能，请联系平台管理员在控制面板中修改Vertex设置。

使用图表绘制功能来：

  • 创建运营的数字孪生，以测试不同条件如何影响结果。
  • 配置对象支撑的系统图或生产图表，用于物料处理、设备调优、生产和供应链管理等流程。
  • 使用建模对象与流程之间的预定义关系，可视化整个系统中的物料流和事件。
  • 根据属性、指标或度量来设置对象图或图表的样式，以定制您的系统可视化。
