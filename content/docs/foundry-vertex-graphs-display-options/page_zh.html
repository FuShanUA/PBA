对象和边的显示选项

Vertex 允许您为图中的对象和边配置动态样式。设置样式并配置关键属性读数后，您可以使用时间选择窗口查看这些关键属性随时间的变化情况。

图布局

自动布局选项

您可以在工作区顶部的工具栏中找到多种预定义的布局选项。选择后，对象和边将自动移动，让您在探索关系时对图进行排列。这些布局中的许多都包含用于修改其行为的高级参数。选择相应布局旁边的齿轮图标即可访问这些参数。

以下是每种布局的高级参数。请注意， 自动 和 圆形 布局没有高级参数。

层级（从左到右/从上到下）

  • 反转： 反转层级的顺序；从左到右变为从右到左，从上到下变为从下到上。
  • 根节点： 选择一个节点作为层级的根。如果选择了 Automatic ，系统将根据边的方向为您选择一个根节点。

网格

  • 交错： 提供对奇数行元素进行偏移的选项。
  • 网格尺寸： 指定对网格中行数或列数的约束。 Automatic 模式将尝试使用相同数量的行和列。

水平行/垂直列

  • 排序依据： 用于对节点进行排序的对象属性。
    • 默认使用升序。
    • 如果未选择 Order by 属性,则布局将保留行原有的水平节点顺序,或列原有的垂直节点顺序。
    • 分组节点以及由不包含指定属性的对象支撑的任何节点,在升序时将排在开头,在降序时将排在末尾。
    • 此选择列表中将只显示数值属性。
    • 不同对象上名称相同的属性将一起排序。
  • 反转： 在升序和降序之间切换排序顺序。此选项仅在选择了 Order by 属性时才会显示。

径向

  • 中心节点： 指定应显示在布局中心的节点。
  • 密度： 一个介于 1 到 5(含 1 和 5)之间的值,用于确定节点之间的间距。

聚类

  • 聚类依据： 指定节点聚类所依据的属性。
    • 如果未选择属性,此布局将按对象类型聚类。
    • 已分组的节点以及任何由不具有所选属性的对象支撑的节点将被聚集在一起。
    • 只有具有 渲染提示 Selectable 或 Low Cardinality 的属性才会出现在此下拉列表中。
    • 不同对象上名称匹配的属性将被聚集在一起。

笛卡尔

  • X/Y 属性： 用作布局中节点 x 和 y 坐标的属性。
    • 坐标将被归一化，以便在执行布局时节点能够容纳在视口内。
    • 除非选择了 x 属性、y 属性或两者，否则不会执行笛卡尔布局。
    • 已分组的节点以及任何由不具有所选属性的对象支撑的节点将保持其在布局前的位置。
    • 只有具有 渲染提示 Selectable 或 Low Cardinality 的属性才会出现在此下拉列表中。
    • 不同对象上名称匹配的属性将被一起排序。
  • X/Y 反转： 反转 x 和 y 坐标。只有在选择属性后，才会显示反转开关。

按对象类型对节点分组

随着您添加更多相关对象，您可能需要开始将对象分组为图中的单个节点。选择要分组的对象后，请使用工作区顶部的布局工具栏对所选对象进行分组或取消分组。

将多个对象分组为单个节点后，您将在工作区左侧的选择面板中看到已分组对象的完整列表。如果您只想取消分组节点中的部分对象，请使用选择面板选择这些对象，然后选择 取消分组 （如下所示）。这也可以使用直方图中的 筛选至 功能来完成。

按对象类型的属性分组

使用直方图，您可以探索所选对象的属性，也可以按显示的值对对象进行分组。这将更改图中对象的布局，以反映新的分组。

将节点分组为边

某些对象是事务性的，会在系统中的其他节点/对象之间移动。例如，航班往返于 Departure Airport 和 Destination Airport 作为事务性对象。在此示例中，您可以将订单对象分组到边上，并能够根据关键属性/指标设置边的样式。

选择该边并选择 取消分组 （位于右键菜单中），以显示之前分组到该边中的所有对象。或者，您也可以先使用直方图或选择面板选择要取消分组的对象，从而仅取消分组其中的部分对象。

您可以在 Ontology Manager → Capabilities 选项卡中将事务性对象自动分组到相关的边中。 了解更多有关关联合并的信息。

图层样式选项

图层是指同一对象类型的对象节点或节点之间的边关系。这些图层可以通过多种布局选项进行单独配置，从而实现灵活的可视化，并与您系统的数字孪生进行直观交互。

使用左侧边栏中的图层样式面板，您可以单独设置节点和边的样式，也可以根据对象属性及相关时间序列/测量值来设置样式。图层样式使您能够可视化关键信息、计算指标，并根据参数化条件设置样式，以显示当前或模拟的系统状态。

对象样式

选择 样式选项 （位于您想要配置的对象类型旁边），以打开样式菜单。

着色依据

选择 填充颜色 下拉菜单，以选择用于设置样式的参数以及该图层中所有对象的颜色。您可以选择时间序列度量作为 着色依据 参数，该参数将根据所选的时间窗口动态更新样式。您还可以在为节点着色时使用 派生属性函数。

副标题

您可以基于对象类型或对象的选定属性，为每个对象添加副标题。副标题将显示在图中所有相同类型的对象上。

扩展标签

选择 扩展标签 可让您为所选的对象节点添加特定读数。您可以从实际时间序列读数或模拟值中进行选择，以便在单一视图中比较当前状况与建模状况。

设置扩展标签样式后，您可以从工作区左侧的对象选择面板中选择要显示的属性或时间序列。

徽章

节点样式

您可以选择将对象显示为默认节点或完整的对象卡片。

边样式

边表示对象之间的关系，可以设置其样式，以可视化系统或流程中节点之间的交互。

选择 样式选项 ，以配置您想要设置的边。

线条颜色

您可以根据对象类型或相关对象的共同属性来设置边的颜色。

线条类型

您可以将绘制的线条设置为直线、曲线或正交线。

标签

当边上有分组在一起的对象时，您可以根据对象的单个属性或聚合属性来配置标签，以显示关键指标。

线条宽度

您可以根据对象的属性为边应用不同的宽度。通过应用不同的线条宽度，您可以表示对象（例如机场）之间事务（例如航班）的流动情况和数量。

徽章

与对象节点一样，您可以添加徽章来指示关联到特定边关系的事件数量。在这里，您可以看到有一个延误航班事件。

本体论级别的边方向配置

向图中添加关联时，默认情况下，边箭头从关联的右侧指向左侧。例如，对于在本体论中配置为多对一关联类型的关联，箭头将从“一”侧指向“多”侧。可以使用以下本体论类型类对每种关联类型进行配置：

  • 主要方向： kind: vertex, name: link_primary_direction
    • 当放置在关联的某一侧时，表示边箭头应指向关联该侧的对象。
  • 无方向： kind: vertex, name: link_undirectional
    • 当放置在关联的任一侧时，表示边上不应显示箭头。
  • 双向： kind: vertex, name: link_bidirectional
    • 当放置在关联的任一侧时，表示边的两侧都应显示箭头。

还可以使用图层样式选项按图隐藏或反转边箭头。

已保存的样式

配置完成后，您可以为同一图形保存不同的样式选项，从而提供系统的不同视图。例如，您可以将一组机场之间的航班视图配置为按航空公司的关键绩效指标设置样式。然后，您可以使用采用不同样式的同一图形来显示相同航线上的客户满意度。

已保存的选择

您还可以将图形上选定的对象组保存为已保存的选择。为此，请选择包含所需对象的任意数量的节点和边，然后选择 保存当前选择中的对象 （可在右键菜单或工具栏的 选择 菜单中进行）。

每个已保存的选择都有一个关联的名称和颜色，显示在图层面板的 已保存的选择 区域中。图形上的每个对象（以边或节点的形式表示）周围都会有一个分段边框，各段的颜色对应于该对象所属的已保存的选择。每个对象可以根据需要属于任意多个已保存的选择，但边框仅会显示前三个已保存选择的颜色。

要快速选择已保存选区中存储的所有对象，请在鼠标悬停于该选区上时选择快速选择操作。

您可以在图层面板中编辑已保存选区。要编辑已保存选区的名称，只需选中该名称，输入新名称，然后按 Enter 键。要删除已保存选区或编辑其颜色，请选择 ... 图标（）。将鼠标悬停在已保存选区上时即可执行此操作。您还可以为每个已保存选区开启或关闭边框，方法是使用眼睛图标（）。

要编辑已保存选区中的对象，可以在图表上选择对象，然后选择 ... （）按钮，再使用 添加所选对象 或 移除所选对象 选项。
