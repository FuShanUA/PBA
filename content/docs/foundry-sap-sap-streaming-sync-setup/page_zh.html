SAP SLT

SAP SLT 连接器允许您通过 SAP Landscape Transformation (SLT) 复制服务器将 Foundry 连接到 SAP 系统。基于数据库触发器，数据会从源 SAP ERP 系统复制到 SLT 系统中相应的操作增量队列 (ODQ)。SAP SLT 连接器使 Foundry 能够与以下内容交互：

  • 从源 ERP 系统复制的 SLT 复制服务器表
  • SLT 复制服务器系统中的本地表

使用 SAP SLT 源需要安装 Palantir Foundry Connector 2.0 for SAP Applications 附加组件 （安装在 SAP SLT 复制服务器上）。如需了解更多信息，请参阅 通过 SLT 进行连接.

API 版本

SAP SLT 复制同步通过以下两种 API 之一提取数据。请在 API 版本 批量或流式同步编辑器的卡片中选择该 API。

API描述
OData使用 SAP 的 通过 OData 进行基于 ODP 的数据提取 ↗。允许每个表为源进行身份验证的 SAP 用户保留一个活动订阅。不包括远程上下文或并行分页。当加载项支持 OData 时，新同步默认使用 OData。
ODP使用 SAP 基于 RFC 的 ODP 数据复制 API（ODP-RFC）。允许每个表有多个订阅，使不同的同步能够独立摄取同一个表。包括远程上下文和并行分页。SAP 正在限制对此 API 的访问。

SAP 正在限制对 ODP-RFC API 的访问，详见 SAP Note 3255746 ↗。使用 ODP API 的 SLT 同步在 SAP 的安全补丁（拒绝未经授权的 ODP-RFC 调用）应用到您的 SAP 系统后将失败。请将这些同步迁移到 OData.

OData API 要求 SAP 加载项版本 2.34（SP34）或更高版本，并带有 PALODATA 组件 安装在 SLT 系统上，以及 SAP_BASIS 7.50 SP09 或更高版本。我们建议使用 SP39 Fix Pack 4 或更高版本。了解更多关于 前提条件和配置.

请按照 为 SAP SLT 同步使用 OData 来：

  • 使用 OData 创建新同步。
  • 将现有的批量和流式同步从 ODP 迁移到 OData，同时保留其输出数据集。

重置队列注册

使用 OData API 时，为某个表配置的第一个同步会为源的 SAP 用户占用活动订阅。 重置队列注册 会重置当前同步自身的订阅。它无法接管另一个同步持有的订阅；在这种情况下，运行将失败并显示 You cannot reset this sync, an active sync is already configured for this table。要解决与另一个同步的冲突，请与您的 SAP Basis 团队协调终止该订阅，或使用其他 SAP 用户。了解更多关于 订阅冲突.

对于批量同步，请使用 重置增量状态 而非此设置来重新加载表。对于流式同步，请使用 （位于源概览页面上）。.

启用重置队列注册后，每次批量同步运行时都会触发完整重新加载。在流式同步上，它会随每个轮询请求一起发送，并可能在运行期间反复重新初始化流。请保持此设置处于关闭状态。
