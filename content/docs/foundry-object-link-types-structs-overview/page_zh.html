结构体

一个 结构体 是一种本体论属性的 基础类型 ，它允许单个属性包含多个字段而非一个值。您在定义属性时声明这些字段，并且每个字段都有自己的名称和类型。您可以通过这种方式对许多常见的对象属性进行建模。例如，一个 Full Name 属性可以包含字段 firstName 和 lastName，而一个 Address 属性可以包含 street、 city、 postalCode和 country。

结构体属性由单个数据源列支撑，该列的类型本身就是一个结构体。在 Ontology Manager 中，您将该列选为属性的 支撑列 ，此操作是在您 创建结构体属性时进行的。字段值最初可以位于不同的数据源中，只要您在本体论中定义该属性之前将它们合并到单个结构体类型的列中即可。

结构体配置

结构体属性具有以下约束：

  • 结构体属性不能包含另一个结构体。
  • 结构体字段不能是数组，但结构体属性本身可以包含结构体数组。
  • 结构体属性必须至少有一个字段。
  • 结构体属性字段目前仅支持以下类型：
    • BOOLEAN
    • BYTE
    • DATE
    • DECIMAL
    • DOUBLE
    • FLOAT
    • GEOPOINT
    • INTEGER
    • LONG
    • SHORT
    • STRING
    • TIMESTAMP

查询语义

结构体的索引方式类似于 ElasticSearch 对象字段类型 ↗，这意味着查询会独立评估每个字段条件。当结构体属性包含数组时，即使该数组中没有任何单个结构体满足所有条件，查询仍然可以匹配某个对象。

例如，考虑一个 Full Name 属性，该属性包含一个值数组。如果某个对象存储了 [{"firstName": "Ada", "lastName": "Chen"}, {"firstName": "Blake", "lastName": "Moreau"}]，则针对 "firstName": "Ada" AND "lastName": "Moreau" 的查询会匹配该对象。第一个值满足 firstName 条件，而第二个值满足 lastName 条件，因此两个条件均得到满足，尽管没有任何单个值能同时满足这两个条件。

当前支持级别

对结构体属性的支持仍在不断扩展，因此在 Palantir 平台中的可用性各不相同。目前，以下应用程序和服务支持结构体：

  • 本体论管理器： 定义和编辑结构体。
  • 操作： 创建和修改结构体属性值。
  • 管道构建器： 定义和编辑结构体。
  • Workshop： 显示结构体属性并将其用作变量。
  • Marketplace： 打包和安装结构体属性。
  • 对象浏览器： 根据结构体属性值搜索对象。结构体字段搜索功能正在开发中。
  • 本体论 SDK： 加载结构体属性，并根据结构体属性值搜索对象。并非每个本体论 SDK 都支持结构体属性，因此请参阅 不支持的属性类型 文档。
  • 函数： TypeScript v2 和 Python 函数支持结构体参数和结构体属性编辑。请参阅适用于 TypeScript v2 和 Python 函数的结构体属性编辑文档。

Object Storage v1 (Phonograph) 将不支持结构体。目前，您只能从数据集和受限视图创建结构体属性。
