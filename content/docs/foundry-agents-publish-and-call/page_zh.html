发布并调用专业代码代理

每个专业代码代理在发布时都会附带一个本体论绑定和一个代理 API 名称。发布后，该代理的函数可从 Workshop 和 Ontology SDK (OSDK) 中调用，无需额外配置。

本体论绑定

本体论绑定会将您的专业代码代理与特定本体论相关联。该绑定决定了代理可以通过其 限定范围的权限访问哪些本体论资源。

为了确保每个专业代码代理都绑定到本体论，代理配置页面包含一个必选的 本体论 选择器。请在发布前选择您的代理将读取和写入的本体论。

代理 API 名称

每个专业代码代理在发布时都会获得一个代理 API 名称，用于在从 Workshop 或 OSDK 调用时标识该代理的函数。代理 API 名称源自仓库名称，您可以在代理配置页面的 代理 API 名称 字段中进行编辑。

发布专业代码代理

发布代理时，Foundry 会使用其本体论绑定和代理 API 名称注册该代理，并将其作为函数公开。发布后，调用该代理无需任何进一步配置。

触发专业代码代理

代理函数异步运行，不受同步函数五分钟执行时间限制的约束。

从 Automate 触发代理（推荐）

我们建议在触发代理时使用 Automate。配置一个带有 函数效果 的自动化，该效果指向您的代理函数。代理以触发该自动化的用户身份运行，或以支撑该自动化的服务用户身份运行。

从 Workshop、本体论 SDK 或本体论操作触发代理

您还可以在可调用异步函数的任何位置调用代理函数，包括 Workshop、 本体论 SDK和本体论操作。

直接调用代理函数时，请注意以下事项：

  • 该函数不返回任何值： 代理函数返回 Void，因此不能作为查询函数来调用。要从 Workshop、本体论 SDK 或本体论操作中调用它，请将其作为函数效果来调用，或将其封装在一个 TypeScript 本体论编辑函数 中，该函数会调用代理。
  • 通过本体论使用结果： 由于该函数不返回值，请让您的代理将其对话记录或结果写入本体论对象，然后读取这些对象以使用输出内容。此模式同样适用于使用 AIP Evals对代理输出进行评分的情况。
  • 不支持流式调用和批量调用。

向专业代码智能体传递参数

专业代码智能体接受 参数 ，这些参数定义在 AgentArguments schema 中，该 schema 位于 agent/index.ts。

当你触发专业代码智能体时，请提供一个 JSON 对象，其键需匹配你的 AgentArguments schema。对于本体论对象，请传递主键值而非整个对象，并在智能体内部重新获取这些对象，可使用 Ontology SDK 或 Ontology MCP。

要在开发过程中本地运行专业代码智能体，请通过模板的 start 命令来提供参数，使用 --json-args 来传入内联 JSON，或使用 --json-args-file 来指定 JSON 文件：
