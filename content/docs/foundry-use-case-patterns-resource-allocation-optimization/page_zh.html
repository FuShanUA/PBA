资源分配与优化

组织每天都在决定如何分配其资源，无论是确定生产哪些产品， 分配电动汽车充电站组合以实现投资回报最大化，或 整合货运以节省运输成本.

通过创建组织运营现实的数字孪生，Foundry 利用组织的数字化表示来驱动和优化资源分配决策。

解决方案

资源分配与优化是指在一系列约束条件下，以最大化或最小化特定目标的方式使用可用资源的任务。组织面临着各种此类分配和优化问题。

资源分配和优化工作流要求组织收集、清洗、转换和建模相关数据，以便做出最优分配决策。这通常通过在单一数据源之上运行的专业软件来完成，而这类软件无法适应新的现实和不断变化的组织动态；或者通过费力地整理众多数据源（跨越大量电子表格和数据库）来完成。这会导致：

  • 分配决策临时进行、交付周期长且缺乏响应性
  • 由于数据不完整而做出非最优决策
  • 不会随时间改进的开环决策：
    • 决策的效果未被衡量和跟进
    • 建模假设未经验证和改进

借助 Foundry，组织能够创建闭环分配优化工作流，实现可重复、及时的决策，使用完整的数据全貌，并能够随着组织环境的演变而适应和改进。

场景评估与优化探索应用

模拟的最优分配、候选场景或“假设分析”场景通过自动化转换生成。最优分配或备选场景可以在使用 来运行该专业代码代理。你还可以通过 or 将收集到的信息存储在 构建的无代码或低代码应用中进行探索和评估。

例如，在 装载利用率提升 用例中，系统会向用户呈现整合货运（整车装载）以节省运输成本的建议机会。装载计划员查看机会仪表板，了解涉及自己负责货运的潜在整合机会，并通知相关利益相关者（工厂、客户、承运商等）。这些机会考虑了额外停靠点、重新安排的取货/送货预约以及工厂/客户约束。然后，装载计划员对该机会进行批准、拒绝、整合或重新分配。

将分配决策连同每个决策的上下文写回，意味着可以随时间比较和评估预测结果与实际结果。通过基于观测数据训练新模型或更新编码的动态，可以提高模型准确性，从而改进决策。

要求

无论使用哪种模式，底层数据基础均由管道以及与外部源系统的同步构建而成。

数据集成管道

数据集成管道以多种语言（包括 SQL、Python 和 Java）编写，用于将数据源集成到主题本体论中。

数据连接器

Foundry 可以 同步数据 从多种来源同步数据，包括 FTP、JDBC、REST API 和 S3。从各种来源同步数据并汇编最完整的 事实来源 是实现最高价值决策的关键。
