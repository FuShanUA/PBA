TypeScript v1 函数入门

以下文档专门针对 TypeScript v1 函数。有关此页面的 TypeScript v2 版本，请参阅 TypeScript v2 函数入门。如需更多 强大功能，包括对本体论 SDK 的支持和可配置的资源请求，我们建议 迁移到 TypeScript v2。

创建 TypeScript v1 函数仓库

导航到您选择的任意项目，然后通过选择 + New > Repository来创建新的代码仓库。选择 TypeScript 函数模板以初始化您的仓库。

创建仓库后，导航到 functions-typescript/src/index.ts 文件。

编写函数

此仓库中的函数必须在 TypeScript 类中定义，且该类必须从 functions-typescript/src/index.ts 文件中导出。您可以在 index.ts中预填充的示例内编写函数，也可以创建一个新文件。如果创建新文件，请确保从 index.ts中导出您的类。

在实时预览中测试

添加新函数后，您可以在函数助手中运行它。打开 函数 助手并选择 实时预览。选择 range 函数，输入输入值，然后选择 运行 ，即可运行代码。

选择右上角的 提交 ，将您的更改提交到您仓库的 master 分支。

发布函数

提交您的工作后，您将看到 标记版本 选项。这将发布您仓库中的所有函数。

选择 标记版本 ，从 master 分支创建发布标记。根据更改的范围设置标记名称，然后选择 标记并发布。

要在标记和发布函数时查看进度，请选择 查看 弹出窗口或导航到 标签 选项卡。待 步骤 2：发布 完成后，选择已发布的函数，即可在函数注册表中查看它们。

在权限传播期间，函数可能无法立即在 Workshop 或函数注册表中按名称搜索到。

使用新函数

在标记检查通过后，导航回 代码 选项卡（位于 代码仓库 中），然后选择 函数 助手。现在，您应该能够看到您的新 range 函数位于 已发布 部分。选择并运行该函数。
