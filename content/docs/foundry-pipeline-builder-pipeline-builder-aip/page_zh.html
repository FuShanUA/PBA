Pipeline Builder 中的 AIP 功能

Pipeline Builder 提供了一系列 AIP 功能，可帮助您构建自定义工作流，并更好地理解和管理您的管道。

AIP 功能的可用性可能随时变化，且不同客户之间可能存在差异。

用于自定义工作流的 AIP 功能

要使用以下功能，用户必须 被授予用于自定义工作流的 AIP 功能权限 （由平台管理员授予）。

使用LLM节点

直方图 使用LLM节点 功能提供了一种便捷的方法，可大规模地对您的数据执行大语言模型（LLM）。您可以在各种数据转换之间无缝地融入 LLM 处理逻辑，无需编写代码即可将 LLM 集成到您的管道中。

除了 Palantir 提供的模型之外， 使用 LLM 节点还支持 已注册的模型 ，这些模型由 Data Connection 中的 REST API 数据源支撑 或 计算模块。选择 已注册 标签页，在模型选择器中选择您已注册的模型之一。

您还可以配置备用模型以提高韧性。通过指定一个按优先级排序的模型列表，当主模型遇到不可重试的错误时，系统会自动按顺序尝试后续模型。当触发备用模型时，会显示一条调试消息通知您模型已切换。

文本转嵌入

文本嵌入的计算成本较高，可能会导致预览和构建速度变慢。

您可以使用 Text to embeddings 表达式将文本嵌入为向量，只需为其提供要转换为嵌入向量的字符串。这些向量旨在捕捉单词或短语的语义含义，从而支持高级文本分析和操作。

您还可以选择由 已注册模型支撑的嵌入模型，无论其是通过 Data Connection 中的 REST API 数据源支撑 或 计算模块.

LLM 评估套件

直方图 LLM 评估套件 让您可以在将 LLM 转换和逻辑部署到管道之前对其进行测试。您可以在评估套件中配置多个评估，并在隔离的测试环境中运行它们，以观察其行为。

评估套件旨在与 使用LLM节点配合使用。每个评估会对测试数据运行一个 Use LLM 节点以及一个或多个评估器，然后报告模型输出与您预期结果的对比情况。

Pipeline Builder 助手功能

解释

使用直方图中的 解释 功能，在开发过程的每个步骤中动态获取管道的描述。让您的协作者随时了解当前状态，为新的审批者提供有价值的背景信息，或以极低的维护成本促进新团队成员之间的知识传递。

要使用解释功能，请选择标记为 AIP 的紫色灯泡图标，该图标位于 Pipeline Builder 图表的顶部中央。按照弹出窗口中的说明，在图表上选择作为输入的表。长按并选择某个节点可将其添加到选区或从选区中移除。您的选区必须至少包含一个转换节点，并且必须是具有单一输出的连通节点集合。

长按并选择某个节点可将其添加到选区或从选区中移除。您的选区必须至少包含一个转换节点，并且必须是具有单一输出的连通节点集合。

最后，选择 解释 xx 个节点 以生成转换说明。

您也可以通过选择单个节点并选择紫色 解释 按钮（显示在右侧的菜单中）来解释该节点。

此外，您还可以选择解释节点内的任意一组转换。

转换助手

转换助手功能可以帮助您充分利用 Pipeline Builder 中提供的众多转换选项。借助 AIP 的强大功能，正则表达式助手可以根据您的输入生成正则表达式并更新现有表达式。此外，使用时间戳格式化工具，您可以快速转换 cast board 中的值 string 合并到 timestamp.

生成提案描述

您还可以在 Pipeline Builder 中使用 AIP，在创建提案时生成提案描述，从而快速描述您的更改。

为此，请首先选择 点击 在右上角。这将带您进入提案创建视图。

现在选择紫色 生成 按钮。AIP 将为您分支上管道的更改撰写提案描述。

在此示例中，有多项更改，包括对某些管道设置的更改。AIP 会为您描述所有这些更改。

您还可以在文本框中输入其他上下文、提请注意特定更改，甚至在选择之前先撰写粗略的提案描述 生成。AIP 将利用这些内容来增强其提案描述。生成的描述将添加到您的文本下方，并有清晰的分隔。

要重新生成或更改您提供的描述，请在选择之前确保文本框中仅包含相关文本 生成。为获得最佳效果，应删除所有其他文本，包括之前生成的任何描述。

生成

使用直方图中的 生成 功能，可根据用户提示创建新的数据转换逻辑。AIP 可以访问 Pipeline Builder 中您可用的全套数据转换，并为您的特定需求推荐最合适的转换。这通过使用元数据生成逻辑，为推荐转换所使用的推理和依据提供了透明度，同时不会暴露底层数据。最后，AIP 转换会像常规数据转换一样保存到您的管道逻辑中，从而实现与现有工作流的无缝集成。

要使用生成功能，请选择紫色 AIP 图标（位于 Pipeline Builder 图表顶部中央）。按照弹出窗口中的说明，在图表上选择作为输入的节点。按住 Cmd （MacOS）或 Ctrl （Windows）并选择一个节点，可将其添加到选区或从选区中移除。

接下来，输入供 AIP 评估的提示，然后选择 生成 开始运行。

这将返回一个或多个以紫色高亮显示的转换节点，并附带对所生成转换的描述。

要继续转换，请选择 返回生成。选择下一组节点并输入下一个提示，以继续构建您的管道。

要查看最近的提示，请选择输入框。您可以通过选择历史记录条目来重试任何提示，系统将自动选中原始输入。
