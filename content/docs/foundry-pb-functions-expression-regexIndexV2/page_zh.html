正则表达式索引

适用于：批处理、Faster、流式处理

返回一个索引数组（以 Unicode 码点计数），表示正则表达式模式在给定表达式中出现的位置。

表达式类别： 正则表达式、字符串

已声明的参数

  • 表达式： 要与正则表达式匹配的表达式。
    Expression<String>
  • 正则表达式： 用于查找索引的正则表达式。
    Expression<String>

输出类型： Array<Integer>

示例

示例 1：基本案例

描述： 您可以查找正则表达式模式及其索引。

参数值：

  • 表达式： ababab
  • 正则表达式： ab

输出： [ 0, 2, 4 ]

示例 2：基本情况

描述： 重叠的匹配不会被单独考虑；整个匹配片段将被视为单个匹配。

参数值：

  • 表达式： abcdcef
  • 正则表达式： .c.

输出： [ 0 ]

示例 3：基本情况

描述： 正则表达式模式有时无法匹配输入字符串，从而产生空数组。

参数值：

  • 表达式： abdefg
  • 正则表达式： cd

输出： [ ]
