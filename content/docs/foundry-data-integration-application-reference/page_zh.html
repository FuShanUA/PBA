Pipeline Builder 具有直观的点击式界面和强大的后端模型，使技术和非技术用户能够比在以代码为主的应用程序中更快地定义和部署管道。精简的构建器界面允许用户在应用数据转换的同时进行数据集结构检查，从而节省通常在构建时用于计算和检查的时间与成本。完整的版本控制和可扩展性等附加功能使 Pipeline Builder 成为安全协作的理想应用程序。

代码仓库

代码仓库 是 Foundry 用于编写代码的主要接口，最常用于以 Python、Java 和 SQL 创建数据管道。Code Repositories 在 git 服务器之上提供了一个集成开发环境 (IDE)，支持管道逻辑的协作与治理，并提供编写、测试和预览数据转换逻辑的原生支持。Code Repositories 还可用于编写 机器学习模型 和本体论 函数.

如果您对数据科学和基于代码的分析感兴趣， 代码仓库（Code Repositories） 可能更适合您的使用场景。 了解 Code Workbook、Code Workspaces 和 Code Repositories 之间的区别的更多信息。

调度指标

调度指标 是一款展示数据如何在 Foundry 中流动的应用程序。您可以使用它来探索 Foundry 中的任何资源如何与其他资源相连，跨越单个 Project 或使用场景的边界。这包括对数据源、数据集、分析、本体论对象和关联类型以及面向用户的应用程序的支持。除了探索连接关系之外，您还可以使用 Data Lineage 查看数据预览、查看用于派生任何数据的逻辑，并管理计划管道。

数据连接

数据连接 是用于将数据同步到 Foundry 并管理相关资源（包括源凭据）的应用程序。初始设置完成后，Data Connection 可以轻松探索数据源并同步新数据以进行使用场景开发，同时遵守大规模管理源系统和使用场景所需的全套治理控制。

数据集预览

数据集预览 是一款用于查看和理解 数据集的应用程序。从任何其他应用程序打开数据集时，会显示数据集的内容以及一系列上下文信息。这包括有关数据集所有权、数据集随时间的变化、任何适用的健康检查以及更多详细信息。

数据健康

数据健康 用于管理 数据质量 （跨所有数据管道）。管道维护者可以执行健康检查，以快速了解其管道的性能和可靠性，并订阅 监控视图 的警报，以支持广泛的数据管道维护工作流。

构建

构建应用程序 （以前称为 Job Tracker）允许您查看 Foundry 中发生的所有 构建 ，并探索每个构建的详细信息，包括有关执行进度、调度以及过往成功率和失败率的信息。Builds 应用程序还使您能够访问有关底层执行的 Spark 执行引擎的细粒度信息，从而支持调试和优化工作流。
