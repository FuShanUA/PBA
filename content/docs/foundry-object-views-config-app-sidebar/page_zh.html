配置应用程序侧边栏

该 应用程序侧边栏 用于显示和嵌入与当前对象相关的应用程序、分析、操作和其他资源。应用程序侧边栏在视觉上将这些资源与该对象的主要内容区分开来。

应用程序侧边栏支持嵌入所有基于对象的应用程序，包括 Workshop、 Quiver、 Slate、 操作类型等。添加到侧边栏后，您可以在对象的上下文中打开这些应用程序。侧边栏还允许通过参数化 URL 链接到其他应用和外部网站。

在下面的示例中，您可以看到一个 Airport 对象。“正文”选项卡包含该对象的主要信息，而相关应用程序包括：

  • 一个有关航班延误的 Workshop 警报收件箱，用于对流量进行分类处理；
  • 一个用于管理机场旅客容量的 Slate 应用程序；以及
  • 一个专用于机场新冠疫情响应的应用程序。

设置应用程序侧边栏

应用程序侧边栏是针对每个对象视图（Object View）的可选附加功能，需主动启用。在您向其中添加分组之前，该侧边栏对用户不可见。该 “添加新分组” 选项位于 “侧边栏” 选项卡，或展开侧边栏本身（如下图所示）。构建者添加应用程序和/或操作并发布该版本后，侧边栏将显示给最终用户。如果侧边栏仅包含一个或多个空分组，则不会显示。

添加应用程序和/或操作并发布更改后，侧边栏将显示给用户。如果侧边栏仅包含一个或多个空分组，则不会显示。

编辑应用程序侧边栏

应用程序侧边栏是模块化且可配置的。侧边栏可以划分为多个分组，每个分组中包含不同的应用程序卡片和操作。

侧边栏为其中的每个分组和应用程序卡片提供了专门的配置。如下图中编号所示，选项包括：

  1. 使用以下选项编辑整个分组：

    • （a）配置分组标题
    • （b）重新排序分组内的应用程序卡片和操作
    • （c）删除整个分组
    • （d）编辑可见性（使分组仅对特定用户配置文件可见）

  2. 编辑特定应用程序卡片，这将打开一个二级菜单，使您能够：

    • （A）添加或更改用于单个卡片的应用程序资源（更多详情见下文）
    • (B) 覆盖标题
    • (C) 覆盖图标
    • (D) 在卡片上使用缩略图；缩略图必须上传到 Foundry 并保存在文件夹中
    • (E) 选择卡片模式或紧凑模式
    • (F) 添加参数

  3. 编辑支撑应用程序（这将在源应用中打开特定模块，例如 Workshop 或 Slate）

  4. 向组中添加新应用程序

  5. 向组中添加新操作

  6. 添加新组

在侧边栏中添加/更改应用程序

将应用程序添加到侧边栏有两种主要方法：

  1. 对于嵌入了对象视图的对象应用程序（Workshop、Quiver、Slate 等）：

    • 选择 添加应用程序，选择一个应用程序（例如 Workshop）以打开资源选择器，并选择您想要嵌入的特定资源（例如 Workshop 模块）。
    • Workshop 和 Slate 应用程序的参数配置允许您将当前对象的属性、关联对象集或预定义值的详细信息传递到关联资源中。
    • 参数值可以在嵌入的 Workshop 或 Slate 应用程序中作为与参数名称同名的变量进行访问。在 Workshop 中，这些必须在变量 设置 面板中配置为模块接口变量。

  2. 若要让其他 Foundry 应用程序和外部网站在新标签页中打开：

    • 添加一个 应用程序链接 以创建带有参数化 URL 的新卡片。
    • 侧边栏上的所有链接都将在新的浏览器标签页中打开，而不是像上文提到的对象应用程序那样嵌入。
    • 这些 URL 既可用于 Foundry 应用程序（例如 Workshop、Vertex、另一个对象视图或 Foundry 文档），也可用于外部网站。
    • URL 卡片需要一个模板，用于组合地址和/或在参数配置中定义的任何参数。要将参数放入 URL 中，请按如下方式包裹参数名称： {{parameterName}}。如果该属性是一个完整的 URL，请勾选 编码属性值 以将其标记为完整的 URL，并仅将 {{parameterName}} 包含在 URL 文本框中。
    • 默认情况下，可以使用以下参数获取当前对象的详细信息： {{objectId}} & {{objectTypeId}}。

如果用户没有嵌入式应用程序的权限，则无法将其打开，但仍会看到应用程序卡片。请确保为侧边栏中的每个应用程序设置正确的权限。
