本体论 MCP (OMCP)

本体论 MCP (OMCP) 是开发者控制台的一项功能，可将应用程序的本体论资源公开为模型上下文协议 (MCP) 工具。这使 AI 代理和外部系统能够作为 MCP 客户端与您的本体论进行交互。

什么是本体论 MCP？

本体论 MCP 可将应用程序的本体论资源（如对象类型、操作类型和查询函数）作为 MCP 工具提供。外部 AI 代理随后可以发现并使用这些工具来读取对象、执行操作以及从本体论中查询数据。

该 模型上下文协议 ↗ 是一种开放标准，可使 AI 系统安全地连接到外部数据源和工具。启用本体论 MCP 后，您的应用程序将成为一个 MCP 服务器，AI 代理可作为 MCP 客户端连接到该服务器。

本体论 MCP 与 Palantir MCP 的对比

Ontology MCP 与 Palantir MCP 用途不同：

  • Ontology MCP (OMCP) 面向本体论 消费者：即外部 AI 智能体，它们需要安全地 写入数据 到您的本体论。本体论 MCP 允许 LLM 智能体读取对象、执行预定义操作并查询数据，同时通过 应用程序限制来约束该智能体可以执行的操作。这使得外部智能体能够安全地与生产环境中的本体论数据交互。

  • Palantir MCP 专为 本体论构建者而设计，例如从事 OSDK 应用程序、数据集、转换和本体论开发工作的开发人员。Palantir MCP 提供了 70 多种工具，用于构建和修改本体论 类型 （对象类型、关联类型、操作类型），但无法写入实际的本体论数据。Palantir MCP 专注于开发工作流，而非生产数据交互。

总结：本体论 MCP 支持对本体论数据进行受控写入，而 Palantir MCP 支持修改本体论结构。

LLM 免责声明

通过在本地设备上启用本体论 MCP 并配合托管在 Palantir AIP 之外的 LLM 使用，您将使 Palantir 环境中的数据可供外部 MCP 客户端访问。请确保此操作符合您所在组织的政策。

将本体论 MCP 与外部 AI 系统配合使用时，请考虑以下几点：

  • 在启用本体论 MCP 之前，请审查您所在组织的数据治理与合规政策。
  • 请确保通过 MCP 暴露的本体论资源符合您的数据安全要求。
  • 使用 应用程序限制 和 权限 以限制对敏感资源的访问。
