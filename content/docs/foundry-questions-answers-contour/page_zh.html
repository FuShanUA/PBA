Contour

是否可以添加 URL 参数，以便在全屏模式下打开 Contour 仪表板并收起参数窗格？

目前没有 URL 参数可以在打开 Contour 仪表板时自动收起参数窗格，但您可以在仪表板处于全屏模式时复制链接，导航到该链接时便会以全屏模式打开仪表板。

时间戳： 2024年4月16日

Contour 目前是否有版本控制或历史记录功能？

没有，Contour 目前没有任何版本控制功能。如果您需要执行带有版本管理和修订历史的分析，我们建议使用 Code Workbook。

时间戳： 2024年4月16日

如何创建一个新列来计算两个日期列之间的天数？

要计算两个日期列之间的天数，请在表达式看板中使用 date_diff 函数。
