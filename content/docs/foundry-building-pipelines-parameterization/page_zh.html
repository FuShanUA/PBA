参数化 [Beta]

Beta

计划参数化目前处于 beta 开发阶段，您的租户中可能尚未提供此功能。该功能目前仅适用于 Python 转换，并且在持续开发期间，功能可能会发生变化。

参数化使转换逻辑能够使用不同的参数值运行。

在 Python 转换中定义参数

要使用参数化，您必须先在转换逻辑中定义参数，并验证您的 仓库 是否满足以下版本要求：

  • transformsVersion 必须为 10.96.0 或更高版本。
  • transformsLangPythonPluginVersion 必须为 1.1137.0 或更高版本。

如果不满足，请按照 仓库升级指南 中的说明进行操作，以确保您的仓库满足上述版本要求。

每个参数都具有名称、类型和默认值。

  • 参数名称： 由 Python 变量名声明。
  • 参数类型： 为 StringParam、 IntegerParam、 FloatParam或 BooleanParam之一。
  • 参数默认值： 未指定参数时使用的值，即转换并非通过参数化计划构建。

在计划编辑器中启用参数化

转换逻辑准备就绪后， 在 Data Lineage 中创建新计划，然后启用 参数化 选项。在目标数据集的转换上定义的参数将在此处可用。

标准模式

在标准模式下，您在计划任务中提供参数值，这些值将在计划任务运行时传递给您的转换。

要使用转换上为参数定义的默认值，请在计划任务中隐藏该参数。

以下示例显示了 risk_factor 参数已隐藏，且 town_name 被设置为 "New York" （针对此计划任务）。

并行化模式（高级）

并行化模式允许您创建一个调度，该调度可以使用不同的参数值运行相互独立的并行构建，并汇总其结果。

运行设置

在并行化模式下，参数值并不直接在调度上提供，而是由该调度的运行设置来定义。

运行设置是一组参数值，其中包括特殊的 运行设置键 参数的唯一值。创建并行化调度时，您需要将其中一个参数指定为运行设置键，用于标识该运行设置。

您可以独立并行地构建各个运行设置，而无需等待其他运行设置完成构建。Foundry 会将每个成功构建的输出数据存储在配置的 联合视图输出中。

要管理调度的运行设置，请在现有并行化调度上选择 指标与历史 ，然后导航至 运行设置 选项卡。

创建运行设置

要创建新的运行设置：

  1. 选择 创建运行设置。
  2. 填写运行设置的参数值，并为运行设置键参数提供唯一值。
  3. 选择 保存 以创建运行设置。

构建运行设置

要构建现有运行设置：

  1. 在 运行设置 列表中找到该运行设置。
  2. 在相应的行上选择 立即构建 。

如果构建成功,这些行将出现在已配置的 联合视图输出中。

编辑运行设置

要更改现有运行设置的参数值:

  1. 在 运行设置 列表中找到该运行设置。
  2. 在相应的行上选择 (•••) 菜单图标,然后选择 编辑。
  3. 根据需要更新参数值,然后选择 保存。

下次构建该运行设置时,将使用更新后的参数值。在重新构建部署之前,先前构建产生的旧行将一直保留在已配置的联合视图输出中。

删除运行设置及其输出数据

要移除运行设置及其添加到联合视图输出中的行:

  1. 在 运行设置 列表中找到该运行设置。
  2. 在相应的行上选择 (•••) 菜单图标,然后选择 删除。
  3. 确认删除。

删除运行设置后,其相应的行将从已配置的 联合视图输出中移除。

联合视图输出

当并行运行设置的构建成功时，输出数据集的内容将不会在主调度分支上进行更新。相反，数据行的内容会被收集到一个输出联合 视图 中，该视图由您在调度中配置。

您可以在创建或编辑调度时配置联合输出。对于调度中的每个目标数据集，您可以选择一个联合视图，用于存储生成的数据行。

为并行化调度使用操作类型

并行化调度在运行设置由 操作类型构建时最为有用。 了解有关创建可运行调度的操作类型的更多信息。

当您通过操作运行并行化调度时，Foundry 会使用该操作提供的参数值自动创建一个新的运行设置，并立即触发构建。

如果已存在运行设置键值相同的运行设置，则会在触发构建之前更新该运行设置的参数值。

限制

以下限制适用于所有参数化调度：

  • 在计划创建后，无法编辑该计划中定义的参数类型和名称。您必须创建新的计划才能使用新参数。
  • 参数化计划无法作为 Marketplace 产品的一部分包含在内。

以下附加限制适用于并行化模式的计划：

  • 一个计划一次最多可以有 1,000 个运行设置。
  • 只有表格类型的 Foundry 数据集才支持在输出联合视图中收集并行运行的结果。
  • 并行化模式下的计划不支持定义自动触发器；只能手动运行，方法是使用 运行设置 或执行 操作。
