时间序列分析和对象集路径分析资源可以通过 在 Quiver 中打开 选项转换为 Quiver 分析。这将创建一个具有相同数据和配置的新 Quiver 分析。请注意，Quiver 分析无法转换为简化的分析类型，并且对新 Quiver 分析所做的更改不会反映在原始的对象集路径分析或时间序列分析中。

Quiver 分析

Quiver 分析 提供一整套强大的分析功能，包括对对象数据和时间序列数据的支持，以及一个全面的 卡片 用于数据转换和可视化，并能创建交互式 仪表板。

主要功能包括：

  • 无需代码即可对对象和时间序列数据进行可视化、筛选和转换
  • 将分析参数化，以便在数据的不同视图和结果之间轻松切换
  • 创建可嵌入操作应用程序中的交互式仪表板，例如 Workshop
  • 在报表应用程序中嵌入图表，例如 Notepad
  • 使用 转换表 和 物化 以进行更高级的转换和聚合

我们建议在以下情况下使用 Quiver 分析：

  • 您需要更高级的分析操作，例如本体论 SQL、转换表或物化。
  • 您想要构建交互式仪表板并与他人分享。
  • 您需要在单个分析中同时处理对象数据和时间序列数据。
  • 您需要对分析进行参数化，以便从不同视图查看数据。

时间序列分析

时间序列分析提供精简的接口，专注于即席时间序列分析。它专为希望快速可视化和比较时间序列数据、而无需面对 Quiver 分析全部复杂性的用户而设计。

主要功能包括：

  • 从本体论添加时间序列数据
  • 执行诸如联合、公式、筛选等时间序列操作
  • 可视化来自关联对象或条件的事件集
  • 快速切换底层数据，以比较从不同根对象开始的值

在以下情况下，我们建议使用时间序列分析：

  • 您仅处理时间序列数据。
  • 您希望快速可视化并比较多个时间序列。
  • 您无需根据您的分析构建仪表板。
  • 您希望构建一个固定流程的环境，供操作用户在 Workshop 应用程序中执行时间序列分析。

对象集路径分析

对象集路径分析提供了一个精简的界面，可通过一系列对输入对象集进行筛选、转换和可视化的卡片来调查对象数据。它专为希望在无需面对 Quiver 分析全部复杂性的情况下，对对象数据执行简单即席分析的用户而设计。

主要功能包括：

  • 根据对象属性和关联对象筛选对象集
  • 使用柱状图、折线图、饼图、热力网格和瀑布图可视化数据
  • 在表格和单一属性值卡片中显示对象数据
  • 探索关联对象之间的关系

在以下情况下，我们建议进行对象集路径分析：

  • 您仅处理对象数据。
  • 您希望快速筛选、聚合和可视化对象集。
  • 您无需根据分析结果构建仪表板。
  • 您希望为运营用户构建一个规范化的环境，以便在 Workshop 应用程序中执行对象集分析。
