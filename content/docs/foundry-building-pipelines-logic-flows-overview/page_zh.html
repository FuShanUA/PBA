Logic Flows [已停用]

Logic Flows 允许您在 Foundry 中自动化常见的工作流程。Logic Flows 与 Foundry 的构建和调度基础设施集成，以便将其纳入您的数据管道中。

日落

截至 2024 年 8 月，Logic Flows 处于 日落 开发阶段，并将在未来的某个日期被弃用。目前仍提供完整支持，但 Logic Flows 不应用于新的开发。我们建议将您的工作流程迁移到其他应用程序和工具，以满足您的用例需求：

  • AIP Logic： 利用 LLM 的强大功能来自动化和支持关键任务，包括将非结构化输入中的关键信息连接到您的本体论、解决调度冲突、通过找到最佳分配来优化资产性能、应对供应链中的中断等。
  • 操作： 构建自动化事务，根据您定义的逻辑和标准更改对象属性。

核心概念

An 自动化 是一种使用 Builds 与 Foundry 服务 API 交互的脚本，旨在替代平台中手动重复的操作。它的行为与 Foundry 中的其他作业类似，但它不使用数据集作为输入或输出。Palantir 维护着一个精选的自动化库。

自动化将资源作为 参数 以及一个 JSON 配置.

自动化的特定实例称为 连接流。连接流是使用项目、参数和配置创建的。

连接流：

  • 在单个 项目
  • 上定义和执行，根据参数和配置运行，并在创建连接流时进行验证
  • 可以作为 计划任务
  • 的一部分运行，也可以通过 Logic Flows UI、Data Lineage 或 Builds 应用程序手动运行
  • 在运行之间不存储信息，因此创建新的连接流不会改变后续运行的结果
  • 无法编辑
  • 可以归档
