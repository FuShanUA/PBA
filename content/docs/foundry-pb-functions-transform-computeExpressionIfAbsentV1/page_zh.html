表达式缺失时计算

支持环境：Batch、Faster

为新行计算表达式，给定键的值只会被计算一次，即使跨多次构建也是如此。

转换类别: Other

声明的参数

  • 数据集： 要应用表达式的数据集。
    表格
  • 表达式： 当键不存在结果时要计算的表达式。
    Expression<AnyType>
  • 键： 结果存储在此键下。对于给定的键，结果永远不会被计算两次。
    List<Expression<Array<AnyType> | Binary | Boolean | Byte | Date | Integer | Long | Short | String | Struct | Timestamp>>
  • 存储 ID： 用于存储结果的存储 ID。如果更改此 ID，所有结果将失效。同一管道中不能使用相同的 ID 两次。
    Literal<String>
  • 可选 始终重新计算 null 结果： 如果为 true，即使结果满足用户提供的存储条件，存储中的任何 null 结果也将始终被重新计算。这适用于简单值以及 {ok, error} 结构体。请注意，为了维护存储不变性，每当此值更改时必须重置存储。
    Literal<Boolean>
  • 可选 禁用存储： 如果为 true，存储将被完全禁用，所有存储参数将被忽略。此时转换将像常规的应用表达式一样运行。
    Literal<Boolean>
  • 可选 在以下情况下不存储结果： 某些结果可能不需要存储。例如，错误结果或 null 结果。根据结果，选择不应存储的值。默认情况下，null 结果不会被存储。
    Expression<Boolean>
