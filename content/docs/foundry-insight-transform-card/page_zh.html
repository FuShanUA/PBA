转换卡片

使用 转换 卡片在您的分析路径中对数据执行操作，例如集合运算、分组和 SQL。

集合运算

在 Insight 中， 集合运算 转换提供以下三种操作类型：

  • 并集： 将对象集合并为单个对象集。输入对象集可以是已发布的对象集，也可以是 Workbook 中的路径。合并不同的对象类型时，该操作类似于全外连接，会将所有对象类型的属性添加到表格和图表视图中。处理并集结果时，您可以按匹配项对行进行排序，这有助于快速识别同一对象类型的筛选后集合之间的重叠。

  • 交集： 保留在所有选定对象集中均出现的对象。交集只能应用于单个对象类型，因此对象集选择器仅显示与路径中对象类型匹配的路径或对象集。

  • 差集： 从对象集中移除对象。与交集类似，差集运算只能应用于单个对象类型，因此对象集选择器仅显示与路径中对象类型匹配的路径或对象集。

可视化

使用 分组 聚合，或创建 属性图表 或 Vega 图表 以可视化您分析中的数据。

分组依据

该 分组依据 操作会按一个或多个属性对行进行聚合：

  • 用于分组的属性： 选择一个或多个属性作为分组依据。未在此处选择的属性可用作聚合目标。

  • 聚合： 至少选择一个聚合指标（例如 Count）。可以添加多种聚合类型，并可根据需要重命名列。



选择 显示结果 以查看分析路径中的 分组依据 表。

使用分组依据表进行筛选

选择 分组依据 表中的行，会对底层数据应用筛选器，而不会修改数据。选择一行或多行即可启用筛选；表格左上角的标签将从 Select a row to filter results 更新为 Filtering on [1] row。要移除筛选器，请选择 X。

属性图表

属性图表会在分析路径内显示所选属性值的直方图。在图表中选择一个范围，会对底层数据应用筛选器，而不会修改数据。如需类似功能，请使用您工作簿中的 图表 标签页。

Vega 图表

Vega 是一个完全可自定义的开源可视化库。在 Insight 中，Vega 图表只能与来自 SQL 沙箱 卡片，并且不支持直接使用来自分析路径的本体论数据。有关配置详情，请查看 Vega 文档 ↗。

查询

SQL

此工具可用于编写 SQL 表达式并转换路径数据。仅当分析路径包含单个对象类型时才支持 SQL；当存在多个对象类型时，该功能将被禁用。SQL 沙箱支持与其他对象类型进行联接，而无需依赖本体论关联类型。要引用对象类型进行联接，请使用反引号。

Insight 中的 SQL 沙箱默认采用以下查询：

SELECT * FROM Path 
LIMIT 10

Path 指的是添加此卡片时分析路径中的数据。如果在 SQL 卡片之前应用了筛选器，SQL 将对这些筛选后的数据进行操作。

有关受支持的语法和其他 SQL 用法的更多信息，请查看 本体论 SQL 文档。

SQL 结果

SQL 沙箱结果显示在 SQL 预览 表中。SQL 工具基于数据的物化副本运行，因此其输出未经过本体化处理，无法直接在路径中使用。通过选择 SQL 沙箱 卡片，即可在预览表中查看 SQL 结果，或将其下载为 CSV 文件。

SQL 沙盒和筛选卡片

由于 SQL 沙盒不影响路径数据，因此在 SQL 沙盒之后添加的任何筛选卡片都会基于 SQL 步骤之前的路径数据进行筛选。在下面的示例图片中，SQL 结果为 1 而对象计数仍为 10，因为查询无法直接影响路径结果。在 SQL 步骤之后应用筛选卡片将显示所有 10 对象。
