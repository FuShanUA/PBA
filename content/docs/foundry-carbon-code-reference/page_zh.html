YAML 配置参考

Carbon 工作区既可以直接通过 YAML 进行编辑，也可以通过图形用户界面进行编辑。本页面包含配置 Carbon 工作区不同部分的 YAML 示例，并以 Claims Portal 为例。Claims Portal 示例的完整 YAML 可参见 YAML 代码示例.

包含模块项的自定义分区 - 带有模块接口变量的 Workshop 模块

Copied!
1

4

16
17
18
19
configuration:
  homePage:      
    columns:      
      - sections:
          - title: null
            description: null
            contents:
              type: custom
              custom:
                items:
                  - type: module
                    module:
                      displayMetadata: {}
                      moduleRid: ri.workshop.main.module.525ab70b-d24b-42f4-ad25-a407f0273b83
                      parameterValues:
                        variable.status:
                            type: string
                            string:
                                string: Open

要向 Workshop 模块传入模块接口变量，请将其添加到 parameterValues 映射中，并加上 variable. 前缀。在上面的示例中，一个外部 ID 为 status的模块接口字符串变量被传入 Workshop 模块，其值为 Open.
