API：模型评估

模型评估 Python API 提供了一组方法，用于创建评估并向其记录指标、图像、图表和表格。

palantir_models.transforms.evaluation

直方图 palantir_models.transforms.evaluation 装饰器会创建一个评估。将其应用于包装一个转换，并指明 评估集 写入模型输入的位置：

from transforms.api import configure, transform, Input
import palantir_models as pm
from palantir_models.transforms import ModelInput

# This decorator is required to be applied to create evaluations.
# The decorator indicates the evaluation set that will be written to on the model input(s).
@pm.transforms.evaluation("error_analysis")
@transform.using(
    input_data=Input("..."),
    model_input=ModelInput("..."),
)
def compute(input_data, model_input):
    evaluation = model_input.create_evaluation(name="my-evaluation")

在上面的示例中，评估将写入 error_analysis 评估集 ，该选项位于 model_input 模型。如果评估集尚不存在，则会在转换首次运行时自动创建。

参数

  • evaluation_set_name: str
    • 要写入评估的评估集的名称。必须是非空字符串。

ModelInput.create_evaluation

palantir_models.transforms.ModelInput.create_evaluation(name: Optional[str] = None) -> Evaluation

  • 创建并返回一个 Evaluation 用于由此 ModelInput.
  • 加载的模型。必须在用以下装饰器装饰的转换中调用： @pm.transforms.evaluation.
  • 返回的评估与该转换生成或使用的模型版本相关联。在成功构建结束时，评估会自动提交到评估集；如果构建失败，评估将被中止。
  • 调用 create_evaluation 在同一个转换中多次调用将返回相同的评估实例。
Copied!
1
evaluation = model_input.create_evaluation(name="my-evaluation")

参数

  • name: Optional[str]
    • 评估的名称。如果未提供，则使用评估集的名称。名称不需要唯一；重复使用的名称会自动变为唯一。

palantir_models.evaluations.Evaluation

用于记录模型评估结果的类。一个 Evaluation 是从一个 ModelInput 的定义，使用 create_evaluation 创建的，并捕获单个模型版本在一组测试数据上的表现。

与 实验不同，评估记录的是单个结果快照而非分步时间序列，因此其记录方法不接受 step 参数选择一个百分比。

函数描述
log_metric(key, value)向评估记录单个指标。
log_metrics(metrics)向评估记录一组指标。
log_image(name, image, caption)向评估记录一张图像。
log_plot(name, plot_data, description)向评估记录一个图表。
log_table(name, table, description)向评估记录一个表格。

直方图 evaluation_rid 属性返回评估的资源标识符 (RID)。

Evaluation.log_metric

palantir_models.evaluations.Evaluation.log_metric(key: str, value: Union[int, float])

  • 记录单个指标 value 在给定的 key.
  • 下。指标值必须是数字 (int or float).
  • 记录到现有键会覆盖之前的值。

evaluation.log_metric("mae", 14250.0)

参数

  • key: str
    • 要写入的指标的名称。
  • value: Union[int, float]
    • 要写入的数字值。

Evaluation.log_image

palantir_models.evaluations.Evaluation.log_image(name: str, image: Union[str, bytes, "PIL.Image.Image"], caption: Optional[str] = None)

  • 向评估记录一张图像。
  • 图像必须是 PNG 图像的路径、PNG 图像字节或 Pillow ↗ 图像。其他图像格式将被拒绝。

    • 随图像一起写入的可选说明文字。
