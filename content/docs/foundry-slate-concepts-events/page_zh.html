配置事件和操作

直方图 事件面板 在 Slate 中允许应用程序构建者配置 操作 在特定 事件 发生时执行。

操作 是对应用程序行为的更改，包括打开或关闭对话框/提示框、运行查询或设置变量值。

事件 是触发器，例如用户与应用程序的交互（用户点击、值更改或对话框的打开和关闭）或数据加载状态（查询运行完成），用于触发某个操作。

直方图 事件面板 显示 Slate 应用程序中配置的所有事件/操作对。你还可以使用 Handlebar 引用和 JavaScript 为事件定义自定义逻辑，以控制发送到触发操作的值。就像 函数一样，事件 JavaScript 无法访问 DOM 或 Slate 空间，且不会保存任何状态。

与仅使用 Handlebar 引用相比，事件和操作可以实现更强大的应用程序行为控制。

事件编辑器不接受任何类型的 辅助函数 。

示例 2：将变量设置为下拉列表值的两倍

此事件将把变量设置为下拉列表中所选值的两倍。注意：此示例仅用于说明目的；通常这类事情应使用 slate 函数来完成。

假设有一个名为 w_selectionDropdown 的下拉小组件，其中包含用户可以选择的各种数字，以及一个变量 v_doubleSelection 用于包含所选值的两倍。然后，要创建此事件，请打开事件面板并创建一个新事件。选择 w_selectionDropdown.selectedValue.changed 作为事件， v_doubleSelection.set 作为操作。然后在事件面板中按如下方式填写代码：

var dropdownSelectionValue = {{slEventValue}};

{{slEventValue}} 是事件面板中的一个特殊 Handlebars 值。如果触发操作具有某个关联值，那么 {{slEventValue}} 将是该关联值。在 .changed 操作的情况下， {{slEventValue}} 是关联小组件属性更改后的值 to.

因此，每当下拉列表发生更改时，代码将获取下拉列表更改后的值，将其加倍并返回。返回值由 .set 操作用于将变量设置为返回的值。结果是，每当下拉列表发生更改时，代码将获取下拉列表的新值，将其加倍，并将变量设置为该加倍后的值。

示例 3：在变量中持续记录随时间累积的对象列表

此事件将记录用户在下拉列表中选择的所有值的历史，以便此值列表可以在应用程序的其他地方以某种方式使用。

假设有一个名为 w_selectionDropdown 其中包含用户可以选择的选项，以及一个变量 v_selectionHistory 用于包含选择历史。然后，要创建此事件，请打开事件面板并创建一个新事件。选择 w_selectionDropdown.selectedValue.changed 作为事件， v_selectionHistory.set 作为操作。然后在事件面板中按如下方式填写代码：

示例 4：有条件地在按钮点击时触发手动查询

此事件将在按钮被点击时运行查询——但前提是用户已在所需的输入组件中输入数据 w_input1 和 w_input2.

假设有两个输入组件（用户可输入的文本字段），分别名为 w_input1 和 w_input2。此外，假设有一个名为 w_buttonConditional 的按钮和一个手动查询 q_queryConditional.

进一步假设该查询依赖于用户在输入框中输入的值，也就是说， w_input1.text 和 w_input2.text ，如果这两个输入没有值，运行查询将毫无意义——因此即使按钮被点击，我们也不希望在它们为空时运行查询。我们可以通过以下方式实现。创建一个新事件，然后选择 w_buttonConditional.click 作为事件， q_queryConditional.run 作为操作。然后在事件面板中按如下方式填写代码：

{{slDisableAction}} 是事件面板中的一个特殊 handlebars 值。从面板中的代码返回此值将禁用触发的操作。换句话说——如果 w_input1 or w_input2 中的任何一个为空，就会返回此特殊值，查询 q_query 将不会运行。如果这两个输入 do 都有值，则不会返回任何内容，操作将正常进行。
