在 Workshop 中使用操作

Foundry 中的操作允许用户根据定义的规则集（称为操作类型）编辑、创建、删除和关联对象数据。例如，一个操作可能允许用户执行以下一项或多项操作：

  • 创建一个新的 Flight 对象并填写其 Flight Number, Time of Departure, Origin日 Destination properties.
  • 修改现有的 Flight 对象以更改 Destination property.
  • 将特定的 Flight 对象关联到特定的 Passenger object.
  • 删除一个 Flight 因误操作而创建的对象。

通过为复杂的对象数据编辑创建用户友好的包装器，操作使应用创建者能够使用有意义且安全的构建块来实现用户对对象数据的回写。这些构建块随后可以：

  • 在多个应用程序（如 Workshop 或对象视图）中使用，以支持业务流程工作流。
    • 表单组件会根据操作定义自动生成，因此对对象数据的回写及其关联的用户界面无需单独定义。Workshop 与操作的核心交互详见下文。
  • 进行细粒度的权限设置，以针对不同用户和条件支持不同的回写权限。
    • 例如，可以允许分析师开始一项新的调查，但结束调查的能力可能仅限于经理用户组的成员。

在本体论管理器中定义操作

本节提供了一个侧重于在 Workshop 中使用操作的操作配置概念性示例；有关定义操作的完整详情，请参阅 操作文档。有关定义操作类型的分步教程，请参阅 操作入门.

此示例仅用于说明，您可能无法完全按照所述完成每个步骤。由于您的 Foundry 本体论是根据您的需求和数据定制的，您可能无法访问完成本教程所需的本体论对象。

要创建、配置或编辑操作类型，特定的 Palantir Foundry 用户必须属于 actions-admins 组。在 Workshop 中应用现有操作不需要此成员资格。

操作管理员可以在本体论管理器中创建、配置和编辑操作类型。要访问，请选择 本体论管理器 （位于 Apps 侧边栏）。 操作类型 选项卡（见下方截图）提供了现有操作类型的列表，可以选择这些操作类型进行查看和编辑。 新建操作类型 按钮允许您从头开始定义新的操作类型。或者，您也可以直接从操作类型所基于的对象类型创建操作类型。导航到该对象类型并选择 创建新操作类型 （位于操作类型框中）。

选择 创建新操作类型 按钮以开始。在此示例中，定义一个“修改航班目的地”操作，允许用户修改 Destination 现有航班对象上的属性。

创建向导将引导您完成引导新操作类型的最重要步骤。输入 显示名称 并选择 修改 图表工具 更改对象 选项来配置您的操作类型。在对象下拉菜单中，选择您之前创建的 Flight 对象，然后选择 Comment 和 Destination 此操作类型应修改的属性。

操作类型定义的第一个选项卡称为 概述 ，允许您定义 API 名称 （唯一 ID）、面向用户的 显示名称、面向用户的 描述日 状态 操作的相关信息。其中一些字段已根据上一步骤自动填写。请使用如下所示的值填写缺失的字段。API 名称 在保存后无法编辑，因此在选择 API 名称时务必谨慎。

接下来，选择此操作类型定义的 规则 标签页。您可以在此处配置操作类型的核心内容：其 规则 或输出/执行。选择对象类型以及您希望此操作类型执行的更改类型后，您可以看到被配置为修改规则的规则以及已添加的属性。如有需要，您可以从下拉菜单中添加其他属性。

直方图 参数 标签页列出了操作类型的参数（即输入）。这些参数已由 规则 区域的字段中添加命令。

接下来，为您的操作类型配置一些基本 提交条件 。在本示例中，目标是确认用户输入了有效的三字符机场代码（例如 EWR）作为其修改后的目的地。导航至 安全与提交条件 选项卡并选择 添加条件 菜单中选择 提交条件 部分。在本示例中使用 参数 条件模板来比较 Destination 属性与正则表达式（例如 ^[A-Z]{3}$）；这样您就可以确认为目的地参数输入的值正好是三个字符。为了让用户了解提交未通过某个条件的更多原因，请在侧边栏底部添加一条错误消息。

要测试新的操作类型，请导航回 参数 标签页，并使用屏幕右侧的表单预览来测试您的操作类型。您可以输入不同的值并选择 提交 按钮。这仅测试操作是否可提交，并不会实际提交操作。

您现在已经完成了第一个操作类型的配置，需要将其保存到我们的本体论中。为此，请选择 保存 屏幕右上角的按钮，查看模态框中显示的修改列表，然后再次选择 保存 两次以确认。

您的第一个操作类型现已保存，我们可以前往 Workshop 构建一个模块，允许用户执行此操作类型。

在 Workshop 中使用操作

以下部分假定您熟悉构建 Workshop 模块。请参阅 此页面 以获取涵盖这些主题的教程。

在 Workshop 中，操作可以通过多种不同的微件（widget）向用户公开，包括按钮组（Button Group）和 内联操作微件（Inline Action widget）。下面的示例从一个航班收件箱（Flight Inbox）模块开始，介绍如何在此 Workshop 模块中通过按钮组触发操作。

按钮组

Workshop 中的按钮组微件允许模块构建者向其模块添加一个或多个按钮。在本示例中，我们将重点介绍如何使用按钮组在 Workshop 中公开操作。

在按钮组中配置操作

将按钮组添加到您的 Workshop 模块后，在屏幕上的模块中单击按钮组将在屏幕右侧打开该微件的配置面板。核心配置选项可以在 小部件设置 标签页中找到，并分为三个部分—— 按钮类型, 按钮配置日 显示与格式设置。该 按钮类型 和 显示与格式设置 部分控制按钮布局和高级显示选项。本示例重点介绍 按钮配置 部分，模块构建者可以在其中配置基本显示选项，并确定选择按钮时如何应用操作。

在 Workshop 应用程序的 按钮配置 部分中，您可以调整 文本, 颜色, 左侧图标日 右侧图标 选项来控制按钮的显示。例如，为我们打算通过按钮触发的“修改目的地”操作配置这四个选项。

上述配置将生成一个如下所示的按钮。使用适当的文本、颜色和图标准确地标注按钮，将帮助用户了解选择该按钮后会发生什么。您可以选择预设意图（none, 主要, success, warning，或 danger），或指定自定义颜色，包括通过十六进制代码指定。

现在按钮已标注完毕，我们继续前往 设置标签页的标签。 部分来连接我们预期的操作。为此，请选择 Select an action... 下拉菜单，然后筛选并选择“Modify Destination”操作。选择后，将显示以下内容，其中包含我们在上面创建“Modify Destination”操作时定义的所有三个操作参数。

用途 参数默认值 来为操作参数设置可选的默认值。选择 添加所有参数 可一次性配置所有参数，或选择 Remove all parameters 来清除它们。每个参数对应操作类型定义中的一个输入，例如对象列表、对象引用、整数或字符串。每个参数有两种选项：

  • 将默认值设置为 Workshop 模块中的变量
    • 为此，我们可以选择 Selected Flight 参数的“无默认值”值，并将其改为航班对象表输出的“Active object”变量。设置完成后，将出现其他选项，可将参数设置为 Visible （默认值可由用户在操作表单中进一步修改）、 隐藏 （该参数在操作表单中对用户完全隐藏），或 已禁用 （参数在操作表单中对用户显示为只读）。在本示例中，保留默认选项 Visible.
  • Leave no default
    • 无默认值的参数在操作表单中最初将显示为空字段，其值将由用户输入。
    • 在本示例中，我们将 Modified Destination 和 Comment(s) 字段保留为无默认值。

从按钮组应用操作

在按钮组中配置操作后，当用户在 Workshop 模块中选择 Modify Destination 按钮时，将看到一个操作表单出现。字段的默认值基于上述配置； Selected Flight 字段根据模块变量自动填充，而 Modified Destination 和 注释 字段则留空供用户输入。

在上面的表单中， 1 issue 在操作表单的左下方被标记。将鼠标悬停在 1 issue 文本上，用户可以看到问题在于 Modified Destination 字段当前不是有效的三字符机场代码。

当操作表单填写完毕且所有参数通过验证后，即可提交操作（提交按钮将可用）。

选择提交后，用户将看到模块顶部出现一个绿色提示，表明操作已成功完成，且所选 Flight 对象已更新以反映所输入的更改。

将事件与操作链接

要在操作生命周期的特定时刻运行 Workshop 事件，请在组件配置底部选择以下事件触发器之一：

  • 操作提交开始时： 在操作提交开始时运行事件。
  • 操作提交成功完成时： 在操作提交成功后运行事件。

使用这些触发器可在操作工作流中刷新数据、导航到其他页面或更新变量。

从媒体上传器组件触发操作

当用户通过媒体上传器组件上传文件时，也可以触发操作。这对于依赖新上传媒体的工作流非常有用，例如处理、扩充或链接工作流。

媒体上传器（Media Uploader）小部件被标记为 媒体上传器（旧版） ，显示在小部件选择器中，并且在配置新的媒体上传器时，媒体集目标会被隐藏。要上传到媒体集，请使用按钮组（Button Group）打开操作表单，或使用 内联操作微件（Inline Action widget）。数据集和文件夹目标仍然可用。

在配置媒体上传器以在上传时触发操作时，您可以在操作的参数配置中使用特殊的文件标识符值来引用已上传的文件：

  • 对于上传到数据集的文件，文件标识符即为上传的文件名。
  • 对于上传到 Compass 文件夹的文件，文件标识符即为上传文件的 RID。
  • 对于上传到媒体集的文件，文件标识符即为上传文件的媒体引用。

如果启用了多文件上传，则配置的操作会针对每个上传的文件各触发一次，文件标识符对应于正在处理的特定文件。

有关设置详情（包括按钮配置、上传目标、允许的文件扩展名、动态目标和多文件选项），请参阅 媒体上传器小部件文档.
