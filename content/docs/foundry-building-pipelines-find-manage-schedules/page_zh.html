查找和管理计划任务

计划 可以使用 Build Schedules 应用程序进行搜索和管理，该应用程序允许您为搜索应用条件和筛选器。例如，您可以搜索特定用户暂停的计划任务，或搜索限定在某个 Project 范围内的计划任务，并按名称筛选、按最近一次运行排序。

要访问 Build Schedules 应用程序，请在 Build schedules 浏览器左侧的 Foundry 导航侧边栏中查找。

在 Build Schedules 登录页面上，您将首先看到您创建的计划任务。搜索参数存储在页面链接中，允许您为页面添加书签或将链接发送给其他用户。

添加搜索条件

要查找其他计划任务，请选择 Add more schedules to view。计划任务只要匹配任一搜索条件即会被找到。可用的搜索条件包括：

  • 文件： 根据计划任务在 Foundry 中构建的数据集或其他文件查找计划任务。如果未指定分支，将使用默认分支。
  • 用户： 查找由所选用户最近更新的计划任务。
  • 项目： 查找限定在给定 Project 范围内的计划任务。此参数目前不支持用户范围的计划任务。

进一步筛选和选项

计划任务列表可以通过计划任务名称（如果计划任务上有名称）和暂停状态进一步细化。还可以按名称、创建日期、最近运行日期或计划任务的最近更新日期进行排序。

计划任务信息

对于每个计划任务，会显示其配置以及最近运行的详细信息。以下详细信息显示在最近 10 次运行中（如果计划任务运行次数少于 10 次，则显示更少）：

  • 总计算量： 计划任务最近运行的总 CPU 时间。
  • 中位持续时间： 计划任务最近成功构建的构建持续时间中位数。
  • 平均频率： 计划任务最近平均运行的频率。

彩色圆点表示计划任务的最近运行，最右侧为最近一次运行。将鼠标悬停在圆点上可查看更多详细信息，或者对于运行了构建的计划任务，点击圆点可查看该构建的构建报告。

计划任务操作

可以对找到的计划任务单独或批量执行操作。每个计划任务卡片上的菜单包含用于在以下位置编辑计划任务的链接： 调度指标 以及指向 Metrics and History 页面的链接，您可以在该页面查看计划任务性能和历史记录的更多详细信息，并设置健康检查。此外还有用于切换暂停、运行或删除计划任务的控件。

还可以批量暂停、启用或删除计划任务：

  1. 选择 Select schedules… 在页眉中。
  2. 选择您要对其执行操作的计划任务。
  3. 从页眉中选择一个操作。
