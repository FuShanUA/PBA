将值存储在变量中

您在 变量编辑器 中定义的变量可在整个 Slate 应用程序中访问。您可以在查询和小组件中引用它们，甚至可以通过事件或 URL 设置它们的值。

变量的有效类型为 Number, String, Boolean, Array, Object日 Null.

创建变量

要创建变量，请按照以下说明操作：

  1. 在左侧边栏中，选择 (x) 图标以打开变量编辑器。将鼠标悬停在 (x) 图标上将显示单词 变量.
  2. 选择 + 添加新变量.
  3. 选择变量的页面作用域 - 共享（在每个页面上均可访问）或局部（仅在创建变量时所编辑的页面上可访问）。
  4. 选择 名称 列中的文本，然后为变量输入新名称。

Slate 会检测变量名称是否存在冲突，并在输入有效名称之前阻止用户保存该变量。 共享变量名称必须在所有页面、小组件、事件、查询和函数中唯一。 局部变量名称在页面内必须唯一，且不能与 环境变量.

  1. 发生名称冲突。为变量输入默认值。Slate 将根据输入的值推断变量类型。

变量的值不会在页面加载之间持久保存。当 Slate 应用程序重新加载时，它将使用默认变量值。 要在页面加载之间持久保存变量值，请使用 用户存储 变量来访问用户在其 Foundry 会话中设置的语言。

变量编辑器不仅显示每个变量的页面作用域、名称和默认值，还提供变量当前值的只读视图，以防其通过事件或直接通过 URL 进行了更改。

表格变量

直方图 变量 面板支持将表格数据存储为变量。您可以使用电子表格编辑器直接输入数据或上传 CSV 文件。您之前在 数据集 面板中管理的数据集现在存储为共享变量，并保留相同的功能。

创建表格变量

请按照以下说明创建表格变量：

  1. 在左侧边栏中，选择 X 图标以打开变量编辑器。
  2. 选择 + 添加新变量.
  3. 选择变量的页面作用域（共享或局部）。
  4. 为变量输入名称。
  5. 在默认值字段中，输入面向列的 JSON 以初始化表格结构，例如： {"column1": ["row1", "row2"], "column2": ["row1", "row2"]}，或者如果值为空，直接选择 表格 选项卡。

直方图 表格 选项卡提供了一个电子表格编辑器，允许您直接编辑数据。

当变量值为空时，此选项卡处于启用状态， {}，或者包含格式为 { columnName: [value1, value2, ...], ... }的面向列的 JSON。所有列必须具有等长的数组。如果您的变量包含不同的格式（例如面向行的 JSON，如 [{...}, {...}]），则 表格 选项卡处于禁用状态。

上传 CSV 文件

您可以通过以下步骤上传 CSV 文件来填充表格变量：

  1. 选择一个现有的表格变量或创建一个新变量。
  2. 打开 表格 tab.
  3. 使用上传选项从您的计算机中选择一个 CSV 文件。
  4. CSV 数据将被解析并显示在电子表格编辑器中。

电子表格编辑器支持以下功能：

  • 直接编辑单元格值
  • 右键单击上下文菜单以获取更多选项
  • 添加和删除行与列

Slate 应用程序的默认大小限制为 2 MB。请避免上传大型 CSV 文件，因为它们会占用此限制。如果您的应用程序超出大小限制，您将无法保存更改。对于大型数据集，请考虑使用 查询 或 OSDK 来获取数据。

通过事件更新变量

事件 可用于设置变量的新值。每个变量都会自动提供一个 .set 事件。要更新变量的值，只需在事件内容中返回一个新的合法值即可。事件逻辑还可以将变量的当前值作为输入。更新时也可以更改变量值的类型（例如从 String 更改为 Number）；但是，这可能会破坏变量的依赖关系。

URL 中的变量

您可以在 URL 查询参数中使用变量（添加到 URL 中的附加信息，用于帮助设置 Slate 页面的状态）。URL 参数始终会覆盖默认参数。

通常，使用以下语法向 URL 添加变量：

  • 单个变量： ?variableName=value
  • 多个变量： ?variableName=value&otherVariableName=otherValue

查询参数区分大小写。此外，即使传递的值是数字、布尔值或对象，从 URL 查询参数中检索到的变量值也会是字符串。可以使用 Handlebar 辅助函数，或通过 函数.

示例：在函数中使用环境变量

以下示例使用 $global 变量的不同属性，以相应的语言向用户问候：

// 'de' represents the German locale
// English is the default language
if ({{$global.locale}} == 'de') {
    return "Willkommen " + {{$global.user.firstName}}
} else {
    return "Welcome " + {{$global.user.firstName}}
}

用户存储变量

直方图 sl_user_storage Slate 中的

变量会在每次应用程序加载时为每个用户保留其值，这与页面加载时重置为默认值的其他变量不同。用户存储变量允许应用程序构建者在应用程序上下文中为单个用户存储信息，例如用户对特定应用程序的偏好设置。

通过事件，可以将值存储在用户存储中，以便在应用程序的多个会话之间访问。用户存储限制为 10 kB，可通过 slate.setUserStorage 操作来设置自定义 favicon。 slate.refreshUserStorage 可在用户跨多个浏览器标签页或窗口使用应用程序时调用。当在某个标签页或窗口中将存储设置为新值时，可以通过调用刷新操作将该值拉取到另一个窗口中。

在页面加载时从用户存储初始化变量

sl_user_storage 可能尚未完全加载，当 slate.ready 事件触发时。要在用户存储加载后从中初始化本地变量，请使用 slate.userStorageChanged 事件。此事件在 sl_user_storage 更新时触发，并通过 {{slEventValue}}.
