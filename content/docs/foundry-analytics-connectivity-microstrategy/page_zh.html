从 MicroStrategy 连接到 Foundry 数据集

MicroStrategy 分析平台包含一个经 MicroStrategy 认证的连接器，使用户能够轻松创建由 Foundry 数据集支撑的 MicroStrategy 报告和档案。该连接器与 Foundry 访问控制兼容，包括细粒度权限。

支持的产品

  • MicroStrategy Workstation 作为预览功能（2021 Update 8 版本）
  • MicroStrategy Workstation（2021 Update 9 版本或更高版本）
  • MicroStrategy Library（2021 Update 9 版本或更高版本）

身份验证方法

  • 用户生成的令牌

安装

第 1 部分：验证连接器已安装在 MicroStrategy 中

如果您使用的是 2021 Update 8 版本 的 MicroStrategy，Palantir Foundry 连接器应已作为 预览功能 ↗安装。请通过以下步骤进行验证：

  1. 打开 MicroStrategy Workstation 并启用预览功能。
  2. 选择旁边的加号 数据来源，位于 Administration 左侧边栏部分。
  3. 在支持的数据源列表中搜索 "Palantir Foundry"。如果在列表中找到它，请继续第 2 部分以安装 JDBC 驱动程序。

如果您使用的是 2021 Update 9 版本或更高版本，Palantir Foundry 连接器应已安装在您的 MicroStrategy 版本中。请通过以下步骤进行验证：

  1. 打开 MicroStrategy Workstation。
  2. 选择 数据来源 图表工具 Administration 左侧边栏部分。
  3. 在支持的数据源列表中搜索 "Palantir Foundry"。如果在列表中找到它，则无需单独安装 JDBC 驱动程序；请继续前往 用法 部分。

如果您没有看到 Palantir Foundry 在支持的数据源列表中，请联系您的 MicroStrategy 支持代表以了解后续步骤。您可能需要升级到最新的 MicroStrategy 版本和 MicroStrategy Workstation。

第 2 部分：安装 Palantir Foundry JDBC 驱动程序

如果您使用的是 2021 Update 8 版本，请先安装 Foundry 数据集的 JDBC 驱动程序，以完成 Foundry MicroStrategy 集成的设置。请前往 下载：Foundry 数据集 JDBC 驱动程序 下载并安装该驱动程序。

如果您使用的是 2021 Update 9 版本或更高版本，Foundry JDBC 驱动程序已预装在 MicroStrategy Windows Workstation 和 MicroStrategy Intelligence Server 中。只有当您想使用本地档案访问 Foundry 数据时，才需要为 MicroStrategy Mac Workstation 安装 JDBC 驱动程序。

如果您在安装过程中遇到任何问题，请联系您的 Palantir 代表。

现在连接器已安装完毕，您可以在 MicroStrategy 中构建由 Foundry 数据集支撑的报告和档案。

用法

本指南将介绍如何通过 MicroStrategy 对 Foundry 进行身份验证、选择数据集，并开始构建您的第一个档案。

第 1 部分：创建 Foundry 数据源

在 MicroStrategy 中创建 Foundry 数据源有两种选择：

  • 选项 1：在 MicroStrategy Workstation 中创建 Foundry 数据源
  • 选项 2：使用 MicroStrategy 数据集创建 Foundry 数据源

选项 1：在 MicroStrategy Workstation 中创建 Foundry 数据源

  1. 如果您使用的是 2021 Update 8 版本 的 MicroStrategy，请启用 Preview Features 菜单中选择 帮助 菜单。如果您使用的是 2021 Update 9 版本或更高版本，请继续下一步。



  2. 编辑标签 Administration Workstation 侧边栏的部分，点击旁边的加号图标 数据来源.
  3. 在支持的数据源列表中查找并选择 "Palantir Foundry"。




  4. 为数据源指定名称，并保持数据库版本不变。然后，选择您将使用该连接的 MicroStrategy 项目。选择 Default Database Connection 下拉菜单，然后 Add New Database Connection.



  5. 按照提示添加有关您的 Foundry 连接的详细信息，包括 连接属性.



选项 2：使用 MicroStrategy 数据集创建 Foundry 数据源

  1. 如果您使用的是 2021 Update 9 版本或更高版本，您可以使用 MicroStrategy 数据集创建 Foundry 数据源。禁用 Enable New Data Import Experience 菜单中选择 帮助 您 Workstation 的菜单。



  2. 编辑标签 了解如何通过 部分，选择旁边的加号图标 数据集添加小部件 Data Import Cube 菜单中选择 Create Dataset dialog.



  3. 在 数据来源 窗口中搜索 "Palantir Foundry" 并从列表中选择它。



  4. 选择 Select Import Options 窗口中的任意选项，然后选择 属性，然后选择。在本指南中，我们将选择 Select Tables option.



  5. 在 从表导入 窗口中，选择旁边的加号图标来 数据来源.



  6. 按照下方第 2 部分中显示的步骤提供连接属性。



第 2 部分：配置 Foundry 连接设置

要创建与 Foundry 的连接，您必须提供以下连接属性：

  • 服务器： 您通常用来访问 Foundry 的 URL，例如 <subdomain>.palantirfoundry.com.
  • 目录： Foundry 项目的路径，例如 /MyOrg/MyProject。此字段仅在 2021 Update 9 版本或更高版本中为必填项。设置此属性可以解决 MicroStrategy 中的表浏览问题。如果您使用的是 2021 Update 8 版本，请切换到 高级 选项卡，并在 其他连接字符串参数.
  • 令牌： 在 Foundry 中生成的有效用户令牌。MicroStrategy 连接器仅支持基于令牌的身份验证。请参阅 用户生成的令牌 文档，其中包含如何获取令牌的说明。
  • 其他连接字符串参数（可选）： 切换到 高级 选项卡，并指定任何其他连接参数。参数之间应使用 & 符号分隔，例如 OptionalParam1=<VALUE>&OptionalParam2=<VALUE>。在以下文档中查找连接参数的完整列表： 参数参考 ，这是 Foundry 数据集 JDBC 驱动程序的文档。如果您使用的是 2021 Update 9 版本或更高版本, Dialect 已设置为推荐值 SPARK ，以便在 MicroStrategy 中实现 Foundry 的最佳集成，且此设置无法更改。



第 3 部分：连接到 Foundry 并选择数据集

  1. 使用左侧的导航侧边栏选择 数据集，然后选择 Data Import Cube or 智能多维数据集.
  2. 连接到 Foundry 并选择数据集：
    • 如果您使用的是 2021 Update 8 版本，选择 Enable New Data Import Experience 图表工具 帮助 菜单。选择您在前述步骤中创建的 Foundry 数据源，连接到它，然后导入您的 Foundry 数据集。
    • 如果您使用的是 2021 Update 9 版本或更高版本，在数据源列表中搜索 "Palantir Foundry"，选择它，然后在 Select Import Options 窗口中选择任意选项。在 从表导入 窗口中，选择您之前创建的 Foundry 数据源，连接到它，并导入您的 Foundry 数据集。
  3. 继续在 MicroStrategy 中构建您的报表。
