事件

事件是 对象类型 或 时间轴几何图形 ，其中包含有关特定时间点或时间段的时间信息；最常见的情况是，事件对象具有标记时间段开始和结束的时间戳属性。事件对象在地图画布上呈现为图标，同时在屏幕底部的时间轴面板中以时间轴几何图形的形式呈现；您可以对这两者进行样式设置，以帮助用户更好地理解对象事件与时间的关系。

事件对象

事件对象是一种 对象类型 ，其中包含有关特定时间点或时间段的时间信息。最常见的情况是，事件对象具有用于标记时间段开始和结束的时间戳属性。 详细了解如何在本体论中配置事件。

在您 将事件对象作为图层添加到您的地图后，您便可以应用自定义样式、探索其关联的事件，并在 时间线中查看事件时间段。

事件对象会自动填充时间轴中的事件图层，并可通过添加与事件对象开始和结束时间相同的时间轴几何图形来设置样式。左侧面板的 样式 部分还提供了其他显示选项：

  • 形状： 默认使用开始和结束时间属性绘制条形。对象类型的开始和结束时间在 本体论管理器的 功能 选项卡中进行配置。
  • 颜色： 选择 颜色 来为事件对象的图标着色，可使用 固定颜色、 函数、 属性或 关联传感器。

如果在 图层 面板中添加时间轴几何图形，它将覆盖此事件图层在时间轴中的外观。但是，事件的开始和结束时间仍可用于地图上基于不透明度的样式设置。

使用事件对象进行样式设置

您可以在地图上为事件对象设置样式，使其仅在当前 时间选择 与事件时间段重叠时才可见。利用此功能，地图可随时间推移动态响应，并仅显示当前相关的事件对象。 详细了解如何使用事件对象进行样式设置。

关联事件

关联事件是指与另一个对象相关联的事件对象。在地图上,您可以通过选择该对象并打开 事件 标签页来查看这些关联事件。如果当前选定的时间介于某个事件的开始时间和结束时间之间,该事件将显示在 活动事件 部分中。否则,该事件将被视为非活动事件,您可以使用 显示非活动事件 选项来显示该事件。

当关联事件属于 地理空间对象类型 时,请单击 + 将其添加到您的地图:

每个事件都有您可以执行的相应操作:

  • 使用 图标将选定的时间窗口设置为与该事件的时间端点相匹配。
  • 使用 图标在 Object Explorer 中打开该事件。

在序列面板上显示 [计划弃用]

右键单击某个对象并选择 打开关联事件 以打开关联事件并将其添加到 序列面板。结合重要时间段分析您的时间序列数据,并调整时间选择,使地图反映您所关注的时间。

时间线几何图形

时间线几何图形由事件对象的成对时间戳属性定义，在地图的时间线中渲染为事件图层，并可通过对象属性设置样式。与渲染为地图图层的事件对象相比，时间线几何图形提供了额外的自定义样式选项。
