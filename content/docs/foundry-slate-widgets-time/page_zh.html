时间

时间小部件类别包含以下小部件：

  • 日历
  • 日期选择器
  • 日期范围选择器
  • 时间轴

日历小部件

下表提供了日历小部件可用属性的使用详情。

属性

属性描述类型必需修改者
areEventsAllDay一个布尔值数组，用于确定相应的事件是否为全天事件。全天事件将显示在视图的“全天”部分，并且只会显示在完全处于开始时间和结束时间之内的日期上。此外，当选中全天事件时，其开始时间和结束时间将反映调整后的时间边界。例如：从“1月1日 03:00”到“1月3日 03:00”的全天事件将渲染为“1月1日 00:00”到“1月3日 00:00”。如果留空，事件将默认为全天 = false。jsonNo直接编辑
dateRangeEnabled将日期范围添加为与当前视图对应的日历标题。根据视图的不同，这将是当前显示的日、周或月。string是直接编辑
defaultDate页面加载时日历默认显示的日期。如果设置为空字符串，视图将默认为“今天”，从而使范围与页面加载时的当前日期相匹配。string是用户交互
eventEnds每个事件的结束时间。json是直接编辑
eventNames在每个事件上显示的名称。json是直接编辑
eventSeries一个标签（字符串）数组，用于将事件分组为系列以便设置样式。如果留空，事件将使用默认样式显示。jsonNo直接编辑
eventStarts每个事件的开始时间。json是直接编辑
pagingEnabled添加按钮，用于按当前显示的时间间隔向前和向后移动，以及一个返回当前日期的按钮。boolean是直接编辑
pagingYearEnabled添加额外的按钮，用于将当前查看的时间范围向前或向后移动一整年boolean是直接编辑
selectedIndex日历上所选事件的索引。如果未选择任何事件，则为“null”number是用户交互
viewDefault应用程序加载时将渲染的视图类型（日、周、月）。此视图中显示的日期由“defaultDate”的值确定。默认为“月”视图。string是用户交互
viewType控制可通过“日”和“周”按钮访问的视图（如果这些按钮已启用）。当类型设置为“List”时，事件将按照提供给小部件的顺序显示为项目列表，而不是按照其开始时间的顺序。当类型设置为“Time”时，事件将显示为跨越事件发生时段的块。显示类型对月视图没有影响。string是直接编辑
viewSwitchingEnabled启用/禁用在日/周/月视图之间切换的按钮。默认情况下，这些按钮处于启用状态。boolean是直接编辑

日期选择器小部件

下表提供了日期选择器小部件可用属性的使用详情。表格后面附有若干示例。

属性

属性描述类型必需修改者
disabled指定用户是否可以与小部件交互。默认为 false。值通常是生成布尔值的模板化表达式（例如“{{w1.on}}”）。boolean是直接编辑
displayFormat用于在选择器的输入框中显示所选内容的格式。必须是有效的 moment.js 格式 ↗.stringNo直接编辑
maxDate可选择的最大日期，格式为字符串。如果留空，则使用默认的最大日期（今年的12月31日）。日期必须使用 ISO 8601 标准 ↗.stringNo直接编辑
minDate可选择的最小日期，格式为字符串。如果留空，则使用默认的最小日期（过去20年中的1月1日）。日期必须使用 ISO 8601 标准 ↗.stringNo直接编辑
placeholder未选择日期时用作占位符的文本。string是直接编辑
timeEnabled指定是否应在日期选择器旁显示时间选择器。boolean是直接编辑
timePickerPrecision确定时间选择器的精度。number是直接编辑
value当前选择内容，格式化为字符串。string是用户交互
valueFormat“value”字段的输出字符串格式。必须是有效的 moment.js 格式 ↗。如果未提供或设置为 null，将使用 ISO 8601 格式。stringNo直接编辑

日期范围选择器 widget

下表提供了日期范围选择器 widget 可用属性的使用详情。表格后附有若干示例。

属性

属性描述类型必需修改者
disabled指定用户是否可以与小部件交互。默认为 false。值通常是生成布尔值的模板化表达式（例如“{{w1.on}}”）。boolean是直接编辑
displayFormat显示日期的格式。必须是有效的 moment.js 格式 ↗.stringNo直接编辑
fromDateValue当前“起始”日期选择，格式化为字符串。日期必须使用 ISO 8601 标准 ↗.string是用户交互
maxDate用户可在日期选择器中选择的最大日期，格式化为字符串。如果留空，则使用默认的最大日期（今年的 12 月 31 日）。日期必须使用 ISO 8601 标准 ↗.stringNo直接编辑
minDate用户可在日期选择器中选择的最小日期，格式化为字符串。如果留空，则使用默认的最小日期（过去 20 年的 1 月 1 日）。日期必须使用 ISO 8601 标准 ↗.stringNo直接编辑
shortcutLabels显示快捷方式时要显示的快捷范围名称，例如“最近 3 天”或“最近 3 个月”。如果未提供标签，则使用默认的快捷范围和标签。string[]是直接编辑
shortcutRanges每个快捷方式的日期范围。每个范围必须使用 ISO 8601 标准 ↗[from_date_string, to_date_string], e.g. [‘2016-05-01’, ‘2016-05-10’] or [‘2016-05-01 16:00’, ‘2016-05-01 18:00’]string[][]No直接编辑
shortcutsEnabled确定是否显示日期范围快捷方式（例如最近 3 天、最近 3 个月等）。booleanNo直接编辑
toDateValue当前“结束”日期选择，格式化为字符串。日期必须使用 ISO 8601 标准 ↗.string是用户交互
timeEnabled指定是否在日期选择器旁显示时间选择器。boolean是直接编辑
timePickerPrecision确定时间选择器的精度。number是直接编辑

时间线 widget

下表提供了时间线 widget 可用属性的使用详情。表格后附有若干示例。

属性

属性描述类型必需修改者
cssClasses类名数组，每个类名将添加到时间线上对应的事件。string[]No直接编辑
dates日期数组，表示要在时间线上显示的事件。将按提供的顺序显示。any[]是直接编辑
details要在相应事件标题下方显示的补充详细信息。string[]No直接编辑
titles要在时间线上显示的事件名称/标题。string[]是直接编辑
