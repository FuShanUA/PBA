探索用户会话

Audit Explorer 中的会话浏览器标签页列出的是会话，而不是单条审计日志。会话是共享同一会话 ID 的审计日志集合，记录在 sid 字段中，位于 audit.3 模式。使用会话浏览器标签页可以查看每个会话的开始和结束时间、包含的审计日志数量以及所属用户。然后，你可以在搜索标签页中打开某个会话的审计日志。

所有屏幕截图均使用虚构数据。

打开会话浏览器标签页

  1. 在 Audit Explorer 中选择一个审计表 。
  2. 在标签栏中，选择 新建标签页 (the + icon).
  3. 选择 会话浏览器.

新标签页显示 过去 7 天 内的会话，并保留自己的筛选器。你可以像对待 搜索标签页一样对其进行重命名、复制或归档。归档会话浏览器标签页会将其时间范围和用户筛选器保存为 最近搜索 中的常规搜索，因此无法将其恢复为会话浏览器标签页。归档不会保存 仅显示带有检查点的会话 设置，对分支的合并保留实质性的控制权。

筛选会话

如果某个会话的任意审计日志符合以下筛选条件，该会话就会显示在列表中：

  • 时间范围： 与搜索标签页中的 时间范围控件 工作方式相同。
  • 按用户筛选： 选择一个或多个用户。只有所选用户的审计日志才会计入每个会话的 开始, 结束日 事件 值。仅当审计表具有可筛选的 uid 列时，才会显示此筛选器。
  • 仅显示带有检查点的会话： 仅显示与检查点交互关联的会话。此筛选器需要 检查点交互数据.

Audit Explorer 会记录对时间范围或用户筛选器的每次更改，以及你每次选择 刷新会话的操作，其方式与 记录搜索相同。日志不会显示搜索来自会话浏览器标签页，并且 Audit Explorer 不会记录对 仅显示带有检查点的会话.

查看会话表

直方图 会话 面板最多列出 1,000 个会话，最新的排在最前面。当表达到此限制时，页眉会显示 1,000 most recent sessions。要查看较旧的会话，请缩小时间范围或按用户筛选。

该表包含以下列：

  • 将属于同一 会话 ID。
  • 开始 and 结束： 会话中第一条和最后一条匹配审计日志的时间，以你的 本地时区.
  • 时长： 之间的时间 开始 and 结束，四舍五入到最接近的分钟。
  • 事件： 会话中符合时间范围和用户筛选条件的审计日志数量。计数可能包含 重复行.
  • 用户： 与会话关联的用户。选择该名称可打开该用户的个人资料。
  • 检查点交互： 与会话关联的检查点交互，或 None。如果 Checkpoints 应用可用，选择该 ID 可打开该交互。

阅读该表时，请注意以下几点：

  • 如果某个会话跨越时间范围的边界，该表仅包含范围内的部分，因此该会话看起来更短且事件更少。
  • 每行仅显示一个用户和一个检查点交互，即使会话包含更多内容。要查看全部内容，请 打开该会话的日志.
  • 没有会话 ID 的审计日志不会显示在会话浏览器标签页中。请使用 搜索标签页 来查看它们。

要再次运行查询，请选择 刷新会话 （刷新图标）在面板页眉中。要停止正在运行的查询，请选择 取消。该表可以显示以下消息之一，而不是会话：

  • No sessions found：匹配的审计日志均没有会话 ID。
  • Loading stopped: You selected 取消 在任何会话加载之前。请选择 刷新会话 以重试。
  • Sessions are unavailable for this table：审计表缺少一个 sid 类型的列 string要发布的组件集版本包含在此清单文件中。当使用 time 列，或两者都缺少。

如果查询失败，表格会显示错误消息。

查看会话详情

  1. 在会话表中，选择一个会话行以打开 会话 面板。请选择行中除用户名或检查点交互 ID 之外的任意位置。
  2. 查看摘要字段以及任何 检查点理由.
  3. 要查看各个审计日志，请选择 查看此会话的日志.

Audit Explorer 会打开一个名为 会话 后跟会话 ID 的新搜索标签页。其侧边栏有一个 会话 ID 筛选器，其时间范围设置为该会话的 开始 和 结束 时间。如果您按用户进行了筛选，该标签页可能会包含同一会话中其他用户的审计日志，其计数可能与 事件不同。时间范围仅覆盖会话中匹配的部分，因此请扩大范围以查看完整会话。

查看检查点理由

如果您的组织使用 检查点，Audit Explorer 可以显示用户提交检查点时提供的理由。这需要一个 checkpoint_interaction_rid 列将审计日志链接到检查点交互。 audit.3 schema 未定义此列，因此您必须通过自定义转换将其添加到表中。当该列存在时，Audit Explorer 会添加以下内容：

  • 直方图 仅显示带有检查点的会话 filter
  • 直方图 检查点交互 会话表中的列
  • A 检查点理由 部分（位于 会话 panel
  • A 会话 AIP 使用量与限制 日志详情面板 搜索标签页的

前三个要求该列为字符串类型。 会话 标签页在该列存在时始终显示。

直方图 检查点理由 部分以及 会话 标签页显示以下内容：

  • 检查点类型、提交检查点的用户以及日期和时间。如果检查点记录指定了代理用户，该用户会显示在 理由提供者之后。如果 Checkpoints 应用程序可用，请选择 在 Checkpoints 应用中查看 以打开该交互。
  • 检查点所应用的项目，例如资源、标记、用户、组或限定范围的会话。 受限会话 项目指的是访问设置，而不是审计日志会话。您无法查看的标记仅显示为计数，例如 +2 unknown markings.
  • 每个检查点提示，后跟用户在 用户响应, 用户选择，或 用户确认下的回答。Audit Explorer 按字母顺序列出提示，而不是按用户回答的顺序。

如果 Audit Explorer 无法显示理由，它会显示以下消息之一：

  • No checkpoint justifications for this event：会话或审计日志未链接到检查点交互。
  • Checkpoints is not available：您的注册中未提供 Checkpoints 应用程序。
  • Justifications could not be loaded：您可能没有查看检查点记录的权限。请查看 查看检查点记录的权限.
  • No justifications found：Audit Explorer 未找到该检查点交互的任何检查点记录。
