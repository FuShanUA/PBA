SAP ERP

SAP ERP 连接器允许您将 Foundry 连接到 SAP 的本地部署 ERP Central Component (ECC) 和 S/4 HANA（本地部署和 Cloud Private Edition ↗）。SAP ERP 连接器使 Foundry 能够与多种类型的 SAP 数据进行交互，包括：

  • SAP 应用程序表
  • SAP CDS 视图
  • SAP HANA 信息视图
  • SAP BW 内容提取器（仅限远程连接）
  • SAP 事务代码和 ABAP 报表
  • SAP 函数模块
  • SAP 媒体（DMS 文档）

使用 SAP ERP 数据源需要安装 Palantir Foundry Connector 2.0 for SAP Applications 附加组件 在目标 SAP 应用层上。

设置

  1. 打开 数据连接 应用程序，并选择 + 新建源 （位于屏幕右上角）。
  2. 从可用的连接器类型中选择 SAP ERP 。
  3. 按照后续配置提示，使用以下各部分中的信息继续设置您的连接器。

了解更多关于 在Foundry中设置连接器 的信息。

连接类型

SAP ERP连接器支持两种连接类型：

连接类型描述
直连直接连接到SAP系统。这是默认设置。
远程（通过网关）通过网关连接到远程SAP系统。启用 通过网关连接 开关，并提供 Context 值以标识远程系统。

连接类型决定了哪些 SAP对象类型 可用。了解更多关于 远程连接 和 远程代理配置的信息。

身份验证

SAP ERP连接器支持以下身份验证方法：

身份验证方法描述
基本身份验证提供安装 连接器时创建的技术用户的用户名和密码。
身份验证令牌提供用于身份验证的令牌。
自定义身份验证标头提供自定义身份验证标头。
无身份验证如果已通过证书在代理计算机上设置了身份验证，请使用此选项。

网络和连接

请确保正确配置 出站策略 以允许 Foundry 访问 SAP 系统。对于本地部署的 SAP 环境， agent 代理策略 通常是正确路由流量所必需的。

许多 SAP 系统使用自定义签名的证书，这可能在首次配置连接时导致 SSL 握手异常。请确保您已从系统中获取正确的自定义证书，并 将其添加到源中。

SAP Data Accelerator

要通过 SAP Data Accelerator （SAP 提供的托管连接服务，用于通过 SAP Cloud Connector 公开的系统）访问此 SAP 系统，请将源的 host 和 port 设置为您的 Cloud Connector 虚拟主机和端口。然后，分配 Palantir 提供的客户端证书，允许通往 SAP Data Accelerator 控制平面和数据平面的出站流量，并添加 SAP Data Accelerator 属性并填入您的控制平面 URL。此路径需要使用 Foundry worker。

批量同步

创建同步

  1. 在源概览页面中，选择 + New （位于批量同步旁边）。
  2. 配置标准设置：名称、目标数据集和调度计划。
  3. 将 事务类型 设置为以下值之一：
    • APPEND —— 用于增量更新。请参阅 增量同步 了解详情。
    • SNAPSHOT —— 用于全量加载。
  4. 从下拉列表中选择一种 SAP 对象类型 （请参阅 SAP 对象类型 见下文）。
  5. 输入 “对象名称”。输入时，该字段会根据所选的对象类型建议匹配的对象。
  6. （可选）在 “额外” 选项卡中配置其他参数。

SAP 对象类型

可用的对象类型取决于源上配置的 连接类型 。

对象类型直接远程（通过网关）描述
ERP 表✓✓从 SAP ABAP 数据字典中的任意 ERP 表或视图提取数据，包括簇表、池表和自定义 Z* 表。
CDS 视图✓从 ABAP CDS（核心数据服务）视图提取数据，包括使用 WITH PARAMETERS声明的视图。请参阅下方的 “CDS 视图参数” 。
HANA 视图✓从在 SAP 应用层中启用的 HANA 视图提取数据。请参阅 “从 SAP 摄取 HANA 视图” 以了解前提条件。
BW 内容提取器✓运行 ERP 业务内容提取器。仅当启用 “通过网关连接” 且在源上设置了 “上下文” 值时，才会出现在对象类型下拉列表中。请将其用于 APPEND 支持增量提取的提取器。请参阅下方的 “配置提取器”。
事务代码✓✓运行 SAP 事务代码或 ABAP 报表，并摄取渲染后的输出。请参阅下方的 “事务代码参数” 。
函数模块✓✓调用 SAP 函数模块（如 BAPI）并摄取结构化响应。请参阅 函数模块参数 下方内容。

增量同步

增量同步支持从同一表中执行追加式事务。要启用增量同步，请将 事务类型 设置为 APPEND。

可用的增量模式取决于对象类型：

增量模式ERP 表CDS 视图HANA 视图BW 内容提取器
多个字段✓✓✓
拼接字段✓✓✓
变更文档表✓
孪生表✓
SAP 内置增量✓
  • 多个字段： 导入任一指定字段值大于或等于已导入最大值的行。请用逗号分隔各字段。
  • 拼接字段： 与多个字段模式相同，但会将字段值拼接在一起，而不是使用 OR 进行组合。
  • 变更文档表： 根据 SAP 变更文档表中的更新导入行。有两种可用的子模式： 仅 CDPOS 或 CDHDR 和 CDPOS。
  • 孪生表： 当单独的“孪生”表中的某个字段满足增量条件时，从目标表导入行。
  • SAP 内置增量： 使用提取器的原生变更数据捕获机制。

增量字段理想情况下应为单调递增的值。系统使用“大于或等于”比较，以避免同步在给定日期中途运行时遗漏数据。Foundry 数据集中可能出现重复值，应在转换管道中作为第一步将其删除。

事务代码和函数模块对象类型不支持增量同步；它们始终以快照方式运行。

对于表类型增量同步， 每次同步的最大行数 设置会限制每次运行返回的大致行数。如果间歇性问题（例如网络故障）中断了长时间运行的同步，可使用该设置将大型表的初始同步拆分为一系列更小、更具弹性的运行。

孪生表配置

使用 孪生表 作为增量模式时， 增量孪生表 设置用于指定孪生表的名称，而 增量孪生映射 设置定义主表与孪生表之间的连接条件。映射条目采用以下形式：

{PRIMARY_TABLE_NAME}-{FIELD_NAME}={TWIN_TABLE_NAME}-{FIELD_NAME}

使用分号（AND 运算符）组合多个连接条件。

重置增量状态

若要强制执行完全重新加载并重新初始化增量摄取，请启用 重置增量状态 同步上的切换开关。这将对来自 SAP 的数据执行完整快照，并替换数据集中的所有文件。同步完成后，请禁用该切换开关，以便后续同步恢复增量追加。

重置增量状态适用于以下对象类型：ERP 表、CDS 视图、HANA 视图和 BW 内容提取器。

常规参数

筛选器

添加条件组，然后在每个组内配置字段、运算符和值行。所有字段名都必须与 SAP 数据字典相匹配。

  • 对于日期列，请使用 YYYYMMDD （例如， 20210101 表示 2021 年 1 月 1 日）。
  • The is like 和 is not like 运算符支持 * 通配符（例如， A*12* 匹配以 A 开头且包含 12的任意字符串）。
  • 筛选值还可以使用 动态筛选 关键字和日期计算函数。

动态筛选器

动态筛选值使用特殊关键字和日期计算函数，使筛选表达式更加灵活。在附加组件版本 SP26 及更高版本中可用。可在任何接受筛选值的地方使用它们。

固定关键字

关键字描述
[CURRENTYEAR]当前年份，采用 YYYY 格式。
[TODAY]今天的日期，采用 YYYYMMDD 格式。
[LASTDAYOFMONTH]本月最后一天，采用 YYYYMMDD 格式。
[LASTDAYOFLASTMONTH]上个月最后一天，采用 YYYYMMDD 格式。
[FIRSTDAYOFMONTH]本月第一天，采用 YYYYMMDD 格式。
[FIRSTDAYOFLASTMONTH]上个月第一天，采用 YYYYMMDD 格式。

日期计算函数

函数描述
[ADDDAY]向所选日期添加天数。示例： [ADDDAY(22102022,1)] → 23102022。
[ADDMONTH]向所选日期添加月数。
[ADDYEAR]向所选日期添加年数。
[GETMONTH]以两位数（01–12）的形式返回所选日期的月份。
[GETDAY]以两位数的形式返回当月的第几天。
[GETYEAR]返回所选日期的年份。

函数可以直接与固定关键字一起使用，也可以嵌套使用。例如， [ADDDAY([TODAY], 1)] 或 [GETDAY([ADDDAY([FIRSTDAYOFMONTH], -1)])]。

事务代码参数

当对象类型为 事务代码，对象名称指的是 SAP 事务代码或 Advanced Business Application Programming (ABAP) 报表，并且可以使用以下附加字段：

参数描述
程序类型指定对象名称指的是事务代码还是 ABAP 报表。必填。

CDS 视图参数

使用 WITH PARAMETERS 子句声明的 Core Data Services (CDS) 视图要求在同步时提供其参数。当对象类型为 CDS View时， CDS 视图参数 可选属性接受由 parameter name 和 parameter value 组成的行。参数名称必须与 CDS 视图中声明的名称匹配；未知或缺失的参数会导致同步失败。空行将在保存时被丢弃。

参数描述
函数输入参数由 parameter name 和 parameter value 对组成的行,这些行将作为函数模块的 IMPORTING 参数传递。大多数 BAPI 都需要。
函数调用后提交启用后,会在函数调用后发出 COMMIT WORK 语句。对于依赖提交操作来持久化其更改的标准 BAPI,必须启用此设置。默认关闭。

媒体集

SAP ERP 连接器支持 媒体集 ，用于摄取存储在 SAP 文档管理系统 (DMS) 中的媒体文件和文档。

要创建新的媒体摄取：

  1. 导航到源概览页面。
  2. 选择 + 新建 旁边的 媒体集同步。
  3. 定义您的媒体集格式。提供特定格式后，您将能够在下游数据转换中使用特定于该格式的转换步骤。阅读更多关于 媒体集格式的信息。
  4. 使用源探索工具（该工具按文档类型组织文件）来选择要引入的文件，或直接在 筛选器 部分中定义您自己的筛选器。

探索

当您选择 子文件夹或媒体文件时，您可以选择特定的文档类型（如 CPD）来引入所有关联的文档，也可以选择单个文档以仅引入该特定文件。

媒体筛选器

可对媒体集同步应用以下筛选器：

筛选器描述
排除已同步的文件跳过路径已存在于媒体集中的文件。
路径匹配仅同步与正则表达式模式匹配的文件。默认为 .pdf.
文档类型按 SAP 文档类型筛选。
文件大小限制仅同步指定大小限制内（以字节为单位）的文件。

示例：选择文档类型

SAP 媒体文档类型由首字母缩写和对其用途的简明英文描述指定。按文档类型筛选时，您可以使用缩写表示形式来缩小媒体引入的范围。

Webhooks

SAP webhook 允许您从 Foundry 调用 BAPI（业务 API）将数据写回 SAP。请参阅 Webhooks ，了解如何设置 webhook 的概览。

SAP webhook 支持 Foundry 工作进程 连接在 Foundry 管理的云计算中运行。对于 SAP Webhook,我们建议使用此运行时,而不是通过 数据连接代理来执行。在 Foundry 工作进程上配置的现有 SAP 源将自动受益于云端执行,无需迁移;在数据连接代理上运行的 SAP 源应 切换到 Foundry 工作进程 ,以利用云端执行的 Webhook。

在代码仓库中使用

可将 SAP ERP 源导入到 Python 外部转换 或 函数中,使您的代码能够直接访问 SAP 附加组件的 REST API。当批量同步、媒体集同步或 Webhook 无法提供足够的控制时,可使用此方法。例如,从 Workshop 操作中同步调用 BAPI、循环遍历大型输入数据集并逐行调用 BAPI、根据 Foundry 端数据获取特定 DMS 文档,或在单次构建中串联多个 SAP 调用。

以下示例将使用下列端点,所有端点均相对于源 URL(https://<host>:<port>/sap/palantir):

端点用途
POST /v2/function/{functionName}/writeback同步调用单个函数模块（BAPI）。
POST /v2/function/{functionName}/parallel_writeback同步调用具有批量输入的函数模块，并在服务器端并行处理。
GET /v2/get_documents列出 DMS 文档，可选择按文档类型、文件格式、文件名或对象关联进行筛选。
GET /v2/get_document按 ID 下载单个 DMS 文档。

在使用这些示例之前，请先将 SAP ERP 数据源导入您的仓库：

  • 对于转换，请参照 设置外部转换 并使用 external_systems 装饰器。
  • 对于函数，请参照 从函数发起 API 调用 并在 @function(sources=[...]) 装饰器中声明数据源。

示例：通过 BAPI 写回 SAP（转换）

from transforms.api import Input, Output, transform
from transforms.external.systems import external_systems, Source, ResolvedSource


@external_systems(
    sap_source=Source("<source_rid>"),
)
@transform(
    sales_order_updates=Input("<input_dataset_rid>"),  # columns: sales_doc_id, purchase_date (YYYYMMDD)
    writeback_results=Output("<output_dataset_rid>"),
)
def update_purchase_dates(ctx, sap_source: ResolvedSource, sales_order_updates, writeback_results):
    base_url = sap_source.get_https_connection().url
    client = sap_source.get_https_connection().get_client()

    results = []
    for row in sales_order_updates.dataframe().collect():
        response = client.post(
            f"{base_url}/v2/function/BAPI_SALESORDER_CHANGE/writeback",
            json={
                "commit": True,
                "input": {
                    "SALESDOCUMENT": row.sales_doc_id,
                    "ORDER_HEADER_IN": {"PURCH_DATE": row.purchase_date},
                    "ORDER_HEADER_INX": {"UPDATEFLAG": "U", "PURCH_DATE": "X"},
                },
                "output": ["RETURN"],
            },
        )
        response.raise_for_status()
        results.append({
            "sales_doc_id": row.sales_doc_id,
            "purchase_date": row.purchase_date,
            "status_code": response.status_code,
            "sap_return": str(response.json().get("RETURN", [])),
        })

    writeback_results.write_dataframe(ctx.spark_session.createDataFrame(results))

设置 "commit": true ，适用于需要提交语句来持久化其更改的标准 BAPI。请使用 metadata 端点（GET /v2/function/{functionName}/metadata）在调用函数之前了解其预期的输入和输出结构。

示例：通过 BAPI 写回 SAP（函数）

from functions.api import function
from functions.sources import get_source


@function(sources=["sap_source"])
def update_sales_order_purchase_date(sales_doc_id: str, purchase_date: str) -> str:
    """Updates the purchase date on a sales order via BAPI_SALESORDER_CHANGE.

    Args:
        sales_doc_id: SAP sales document number.
        purchase_date: New purchase date in YYYYMMDD format.

    Returns:
        A string representation of the SAP RETURN table, useful for surfacing
        any error or warning messages back to the caller.
    """
    source = get_source("sap_source")
    base_url = source.get_https_connection().url
    client = source.get_https_connection().get_client()

    response = client.post(
        f"{base_url}/v2/function/BAPI_SALESORDER_CHANGE/writeback",
        json={
            "commit": True,
            "input": {
                "SALESDOCUMENT": sales_doc_id,
                "ORDER_HEADER_IN": {"PURCH_DATE": purchase_date},
                "ORDER_HEADER_INX": {"UPDATEFLAG": "U", "PURCH_DATE": "X"},
            },
            "output": ["RETURN"],
        },
        timeout=30,
    )
    response.raise_for_status()
    return str(response.json().get("RETURN", []))

该源必须 启用代码导入和导出功能 ，才能供函数使用。将 SAP RETURN 中严重性非零的消息呈现为 面向用户的错误 ，以便调用方能够对此做出响应。

from transforms.api import Input, Output, transform
from transforms.external.systems import external_systems, Source, ResolvedSource


@external_systems(
    sap_source=Source("<source_rid>"),
)
@transform(
    sales_order_updates=Input("<input_dataset_rid>"),
    writeback_results=Output("<output_dataset_rid>"),
)
def update_purchase_dates_parallel(
    ctx, sap_source: ResolvedSource, sales_order_updates, writeback_results
):
    base_url = sap_source.get_https_connection().url
    client = sap_source.get_https_connection().get_client()

    bulkinput = [
        {
            "SALESDOCUMENT": row.sales_doc_id,
            "ORDER_HEADER_IN": {"PURCH_DATE": row.purchase_date},
            "ORDER_HEADER_INX": {"UPDATEFLAG": "U", "PURCH_DATE": "X"},
        }
        for row in sales_order_updates.dataframe().collect()
    ]

    response = client.post(
        f"{base_url}/v2/function/BAPI_SALESORDER_CHANGE/parallel_writeback",
        json={
            "commit": True,
            "output": ["RETURN"],
            "bulkinput": bulkinput,
            "parallel": True,
            "paralleljobs": 5,
            "functioncallperjob": 10,
        },
    )
    response.raise_for_status()

    results = [
        {"index": i, "result": str(r)} for i, r in enumerate(response.json())
    ]
    writeback_results.write_dataframe(ctx.spark_session.createDataFrame(results))

调整 paralleljobs （在 SAP 中启动的后台作业数）和 functioncallperjob （每个作业处理的调用数），具体取决于工作负载以及 SAP 系统上的可用容量。设置 "parallel": false 以回退到顺序执行，同时仍使用单个批量请求。

import io
from transforms.api import transform
from transforms.external.systems import external_systems, Source, ResolvedSource
from transforms.mediasets import MediaSetOutput


@external_systems(
    sap_source=Source("<source_rid>"),
)
@transform(
    documents=MediaSetOutput("<media_set_rid>"),
)
def fetch_dms_documents(ctx, sap_source: ResolvedSource, documents):
    base_url = sap_source.get_https_connection().url
    client = sap_source.get_https_connection().get_client()

    # List documents in DMS, filtered by document type and file format.
    list_response = client.get(
        f"{base_url}/v2/get_documents",
        params={"DOCUMENTTYPE": "CPT", "FILEFORMAT": "pdf"},
    )
    list_response.raise_for_status()

    for doc in list_response.json():
        document_id = doc["DOCUMENT_ID"]
        document_name = doc["DOCUMENT_NAME"]

        download_response = client.get(
            f"{base_url}/v2/get_document",
            params={"DOCUMENT_ID": document_id},
        )
        download_response.raise_for_status()

        documents.put_media_item(io.BytesIO(download_response.content), document_name)

要从 Foundry 输入数据集驱动数据摄取，例如仅获取由一系列 EBELN （采购订单）值，请调用 /v2/get_documents 并使用 OBJECTLINK 筛选器，或将每个 DOCUMENT_ID 直接传递至 /v2/get_document （来自输入行）。
