工作簿

您在 Code Workbook 中交互的主要资源是 工作簿。工作簿用于从 Foundry 导入数据集，并对这些输入数据集进行转换，目的包括：

  • 清洗和关联从外部数据源导入的原始数据，以为其他用户生成经过整理的数据集。
  • 分析已处理的数据源以获取有用的洞察。
  • 训练和应用模型以进行预测分析。
  • 创建参数化可视化以在报告中展示。

图表

工作簿界面的核心组件是图（Graph）。图表示数据如何通过工作簿中的逻辑步骤流动以生成输出。

输入数据集从 Foundry 的其他位置导入，用作工作簿中的源数据。除输入数据集外，图中的每个节点都表示一个 和构建数据的方法是应用一个联合操作。联合操作将两个数据集合并，以包含每个数据集的所有行。在Pipeline Builder中，联合操作会保留所有行，包括重复的行。。转换是一段逻辑，可以返回输出数据框或模型，并可能渲染可视化。转换可以保存为派生 数据集。当转换保存为派生数据集时，运行该转换会自动将结果写入 Foundry，从而可以在 Code Workbook 之外使用这些结果，并轻松与他人共享。

Code Workbook 中提供三种类型的转换：

  • 选项卡，选择 转换允许您编写代码来处理输入并返回结果。
  • 模板 转换为转换代码提供了基于表单的界面，使代码的复用和共享变得简单。
  • 手动输入 转换允许用户将数据输入到节点中。

浏览图

点击图中的任意转换即可打开 逻辑 面板（位于界面底部）。您可以在其中查看和编辑转换逻辑，并查看转换输出。在 Windows 上可以使用 Ctrl+Click 或在 macOS 上使用 Cmd+Click 在图中选择多个转换。

为帮助浏览大型工作簿，您可以使用图左下角的缩放选项，其中包括 缩放以适应 按钮，该按钮会缩放图以将所有转换纳入视野。

与转换交互

与转换交互的一种关键方式是通过 上下文菜单，您可以通过点击图中每个转换右上角的省略号（...）打开，或者在图或侧边栏中右键点击该转换来打开。

此菜单提供一系列实用的操作，包括添加新的下游转换、运行与此数据集关联的转换，或从工作簿中删除此转换。对于保存为数据集的转换， 操作 选项允许您访问与该数据集关联的常规 Foundry 操作。

如果您选择了多个转换（在 Windows 上使用 Ctrl+Click 或在 macOS 上使用 Cmd+Click），可以在图上的任意位置右键点击，为所有选中的转换打开上下文菜单。这对于添加具有多个输入的新转换，或同时运行多个转换非常有用。

将鼠标悬停在工作簿中的数据集名称上时，会打开一个工具提示，显示该数据集在 Foundry 中的完整路径。

现在可以使用自定义描述进行注释，以说明其在分析上下文中的内容或用途。要添加描述，请选择路径顶部的“点击添加描述”字段。

您可以切换到工作簿顶部的路径（Paths）视图。路径视图是一种替代模式，允许在工作簿中进行线性开发。路径视图非常适合针对单个数据集进行深入分析并执行顺序转换步骤的工作流。

路径可以从导入到工作簿中的数据集或在工作簿中创建的转换开始。在路径视图中，使用左侧边栏在路径之间导航。

在路径视图中创建的所有转换也会保存到图中。点击路径节点上的 在图中打开转换 图标（）即可从路径节点导航到图。

在 Graph 中，您可以通过查看节点之间边上的标注来了解哪些节点属于某个路径。将鼠标悬停在标注上即可打开源路径。

您也可以点击节点上的 Path 图标，在其源路径中打开它。

全屏编辑器

您可能希望专注于某个转换，并在全屏模式下与该转换进行交互。在 Graph 或 Paths 视图中，点击展开按钮（）即可在全屏编辑器中查看给定节点。

在全屏模式下，您可以使用停靠操作或拖放来重新排列标签页，从而同时查看两个标签页。

要退出全屏编辑器并返回 Graph 或 Paths，请使用 Esc 键或选择折叠按钮（).

窗格

Code Workbook 有三个界面窗格 - 内容, 全局代码日 控制台 - 在 Graph、Paths 视图和全屏编辑器中始终可用。

内容

在界面左侧，点击 内容 栏以打开 Workbook 内容窗格。

在 Graph 模式下，内容窗格会显示 Graph 中所有转换的列表，以便概览整个 Workbook。默认情况下，该转换列表按拓扑顺序排序；输入数据集位于顶部，最下游的转换位于底部。列表中每个转换旁边都有一个缩放按钮，可将图形居中显示在该转换上。您也可以使用空格键放大选定的转换。点击 编辑已保存的数据集 以更改哪些转换（如果有）会被保存为数据集。

在 Paths 视图中，内容窗格会显示工作簿中所有转换的迷你图形，便于在节点之间快速导航。

全局代码

使用直方图中的 全局代码窗格 （位于 Workbook 界面右侧）来定义代码（如变量或函数），这些代码将在该工作簿中该语言的所有代码转换中可用。例如，您可以使用全局代码来定义将在多个转换中使用的常量，或定义您希望反复使用的辅助函数。 了解更多关于如何使用全局代码的信息。

控制台

在工作簿右侧， 控制台 提供 REPL（读取-求值-打印循环），可对图形上的任何数据集进行快速的临时分析。 了解更多关于如何在每种 Workbook 语言中使用控制台的信息。

在控制台下方，使用变量窗格可在控制台中设置给定转换的输入类型。

若控制台命令返回数据框（dataframe），可点击 + 添加至图 按钮，将控制台命令转化为一个转换。这样一来，可以先在控制台中调试逻辑，再将其提升为可重复执行的转换。

你可以利用代码库升级拉取请求中的 键盘快捷键 将代码从转换直接发送至控制台。
