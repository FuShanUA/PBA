管道

仓库中的每个 Python transforms 子项目都会公开一个 transforms.api.Pipeline 对象。该 Pipeline 对象用于执行以下操作：

  1. 在 Foundry 中注册数据集，并附带有关如何构建这些数据集的说明。
  2. 定位并执行 @transform 在 Foundry 构建期间负责构建给定数据集的逻辑。

在大多数情况下，默认的仓库设置会自动注册转换，而 Pipeline 对象不需要特殊配置。

向管道添加转换

当与您项目的管道相关联的转换将某个数据集声明为 Output时，您就可以在 Foundry 中构建该数据集。将转换添加到 Pipeline 对象的两种推荐方式是 自动注册 和 手动注册。

如果您有更高级的工作流，和/或希望将每个转换显式添加到您项目的管道中，则可以使用手动注册。否则，强烈建议您使用自动注册，以确保您的注册代码简洁且集中。使用自动注册时， discover_transforms 方法会递归发现模块级别定义的所有转换。请参阅以下章节以了解更多信息。

自动注册

该 discover_transforms 方法会导入其找到的每个模块。因此，您导入的模块中的任何代码都将被执行。

随着项目复杂度的增长，手动向 Pipeline 对象添加转换可能会变得非常繁琐。为了解决这一问题， Pipeline 对象提供了 discover_transforms() 方法，用于递归发现 Python 模块或包中的所有转换。

from transforms.api import Pipeline
import my_module  # This is where your transform definition lives


my_pipeline = Pipeline()
my_pipeline.discover_transforms(my_module)

手动注册

可以手动将转换添加到 Pipeline 对象中，方法是使用 add_transforms() 函数。该函数接受任意数量的转换，并将它们添加到管道中。它还会检查是否有两个转换声明了相同的输出数据集。

@transform.using(
    my_output=Output('/path/to/output/dataset'),
    my_input=Input('/path/to/input/dataset')
)
def my_compute_function(my_output, my_input):
    my_output.write_table(my_input.polars())

my_pipeline = Pipeline()
my_pipeline.add_transforms(my_compute_function)

转换生成

如果您想定义一个创建多个输出的数据转换，可以使用转换生成，也可以 定义多输出转换。使用转换生成时，可能需要针对每个输出分别读取并处理一次相同的输入。而使用多输出转换，则只需读取并处理一次输入即可。如需了解更多信息，请查阅以下文档： 优化多输出转换。

您可能希望在多个转换中复用相同的数据转换逻辑。例如，请考虑以下场景：

  • 您有一个包含各州信息的输入数据集。您有一段代码，可按州筛选输入，然后计算各种统计数据。
  • 您有多个可能包含空值的输入数据集。您有可以移除任何空值的代码。

在这两种情况下，跨多个转换使用相同的数据转换代码会非常有用。您无需为每个输出分别定义一个转换对象，而是可以使用 for 循环生成转换对象，并将其批量注册到项目的管道中。

import polars as pl
from transforms.api import transform, Input, Output


def transform_generator(sources):
    transforms = []
    # This example uses multiple input datasets. You can also generate multiple outputs
    # from a single input dataset.
    for source in sources:
        @transform.using(
            my_input=Input('/sources/{source}/input'.format(source=source)),
            output=Output('/sources/{source}/output'.format(source=source))
        )
        def compute_function(my_input, output, source=source):
            # To capture the source variable in the function, pass it as a keyword argument with a default value.
            df = my_input.polars()
            filtered = df.filter(pl.col('source') == source)
            output.write_table(filtered)
        transforms.append(compute_function)
    return transforms

TRANSFORMS = transform_generator(['src1', 'src2', 'src3'])

def transform_generator(sources):
    transforms = []
    # This example uses multiple input datasets. You can also generate multiple outputs
    # from a single input dataset.
    for source in sources:
        @transform.using(
            my_input=Input('/sources/{source}/input'.format(source=source)),
            output=Output('/sources/{source}/output'.format(source=source))
        )
        def compute_function(ctx, my_input, output, source=source):
            # To capture the source variable in the function, pass it as a keyword argument with a default value.
            conn = ctx.duckdb().conn
            query = conn.sql(f"""SELECT * FROM my_input WHERE source = '{source}'""")
            output.write_table(query)
        transforms.append(compute_function)
    return transforms

TRANSFORMS = transform_generator(['src1', 'src2', 'src3'])

from transforms.api import transform, Input, Output

def transform_generator(sources):
    transforms = []
    # This example uses multiple input datasets. You can also generate multiple outputs
    # from a single input dataset.
    for source in sources:
        @transform.using(
            my_input=Input('/sources/{source}/input'.format(source=source)),
            output=Output('/sources/{source}/output'.format(source=source))
        )
        def compute_function(my_input, output, source=source):
            # To capture the source variable in the function, pass it as a keyword argument with a default value.
            df = my_input.pandas()
            filtered = df[df['source'] == source]
            output.write_table(filtered)
        transforms.append(compute_function)
    return transforms

TRANSFORMS = transform_generator(['src1', 'src2', 'src3'])

重要注意事项

请仔细阅读以下注意事项，以了解如何避免错误和失败。

  • 捕获源值： 要在函数中捕获源变量，您必须在计算函数中传入带有默认值的 source 关键字参数。
  • 使用 for 循环生成转换： 用于生成转换对象的循环必须位于函数内，因为 Python 的 for 循环不会创建新的作用域。如果不使用函数，自动注册将错误地仅发现 for 循环中定义的最后一个转换对象。此函数应返回生成的转换对象的列表，且返回值应赋给一个变量。在配置为可通过 自动注册 发现的模块中遵循这些标准，将使您能够在生成的转换中使用自动注册。或者，您也可以使用 手动注册。
  • 对输入数据集列表的更改： 如果输入数据集列表在两次构建之间发生了变化，例如，输入数据集列表是从一个在两次构建之间被修改的文件中读取的，则构建将会失败。这是因为新的数据集引用在该构建的作业规范中找不到。
  • 动态输入/输出命名： 转换中无法进行动态输入/输出命名。当 CI 作业运行时，输入和输出之间的所有关系都会被确定，包括唯一标识符与数据集名称之间的关联。不存在的输出数据集将被创建，并且 JobSpec 会被添加到其中。
    • 构建数据集时，系统会从 JobSpec 中获取对代码仓库、源文件以及创建该数据集的函数入口点的引用。随后，系统会启动构建过程，并调用您的函数以生成最终结果。如果您的输入或输出发生了更改，而又启动了构建过程，则会导致错误，因为 JobSpecs 已不再有效。这会破坏唯一标识符与数据集名称之间的关联。
  • 在代码仓库中进行手动注册： 代码仓库中的 构建 按钮可能无法用于手动注册，并且会显示 在所请求文件的管道中未发现转换 错误。您仍可以使用 数据血缘 或数据集预览来构建这些数据集。

入口点

默认入口点和 Pipeline 对象设置足以满足大多数用例。仅对于多管道仓库或不同的目录结构，才建议配置入口点。

负责执行 Python 转换的运行时需要能够找到项目的 Pipeline 对象。要导出 Pipeline 对象，请将其添加到 entry_points 参数中，该参数位于 setup.py 文件，位于 Python 转换子项目中。有关入口点的更多信息，请参阅 setuptools 库文档 ↗。

默认情况下，每个 Python 子项目都必须导出一个 transforms.pipelines 入口点，名为 root。此入口点引用模块名称和 Pipeline 属性。

例如，如果您有一个 Pipeline （名为 “my_pipeline”）定义在 myproject/pipeline.py 中，如下所示：

    entry_points={

在上面的代码中， root 指的是您要导出的 Pipeline 对象的名称。 myproject.pipeline 指的是包含您的 Pipeline的模块，而 my_pipeline 指的是该模块中定义的 Pipeline 属性。
