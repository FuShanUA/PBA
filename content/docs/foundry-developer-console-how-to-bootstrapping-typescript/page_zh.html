初始化一个新的 OSDK TypeScript 应用程序

本页将逐步引导您使用 @osdk/create-app CLI 工具，基于流行的 JavaScript 框架创建前端应用程序。

如果您想为现有应用程序添加 OSDK 支持，请查阅我们关于 将 OSDK 添加到现有应用程序的文档。

1：前提条件

创建 Developer Console 应用程序

请按照 创建新的 Developer Console 应用程序 页面中列出的步骤操作。

设置您的令牌

在本地环境中导出您的令牌。以下示例使用了一个示例个人访问令牌，但您可以在 Developer Console 中生成一个有效期更长的令牌。此令牌不应提交到源代码管理中，因为它是您的个人访问令牌。

export FOUNDRY_TOKEN=<YOUR-TOKEN-FROM-GETTING-STARTED-PAGE>

检查 Node 版本

Typescript SDK 需要 Node 18 或更高版本才能运行。要检查您当前使用的 Node 版本，请输入以下命令：

Copied!
1

2. 快速开始： @osdk/create-app

npm create @osdk/app@latest -- \
    --application <RID OF YOUR DEVELOPER CONSOLE APPLICATION> \
    --foundryUrl <YOUR FOUNDRY URL> \

该 @osdk/create-app CLI 会生成与您的应用程序 OSDK 包的生成器版本相匹配的客户端代码。默认情况下，新应用程序会使用 TypeScript OSDK v2 生成器生成 SDK，其生成的客户端代码将使用 createClient 和 createPublicOauthClient如果您的应用程序的 SDK 是由旧版 TypeScript OSDK 1.x 生成器生成的，则生成的 client.ts 将改为使用已弃用的 FoundryClient 和 PublicClientAuth 导入。如果出现这种情况，请查看下方的 故障排除 部分。

您的项目文件现已在以您输入的项目名称命名的目录中生成。可以通过运行以下命令来启动本地开发服务器：

使用 OSDK React 包（可选）

如果您的应用程序使用 React，您可以使用以下库。

@osdk/react

使用 @osdk/react 来实现类型化钩子、共享缓存、操作、函数以及自定义的数据驱动界面。

安装最新版本的 @osdk/react：

Copied!
1
npm install @osdk/react@latest
@osdk/react-components

使用 @osdk/react-components 来获取预构建的、可感知本体论的界面元素。该库基于 @osdk/react。

安装最新版本的 @osdk/react-components：

Copied!
1
npm install @osdk/react-components@latest

故障排除

生成的代码使用旧版的 FoundryClient 和 PublicClientAuth 导入

该 @osdk/create-app CLI 会搭建与您应用程序的 OSDK 包生成器版本相匹配的客户端代码。如果生成的 client.ts 文件中包含类似以下的导入，则您应用程序的 SDK 是使用旧版 TypeScript OSDK 1.x 生成器生成的：

Copied!
1
import { FoundryClient, PublicClientAuth } from "@<application-name>/sdk";

TypeScript OSDK v2 会将这些导入替换为 createClient （来自 @osdk/client 包）以及 createPublicOauthClient （来自 @osdk/oauth 包）。要生成现代客户端代码，请使用 TypeScript OSDK v2 生成器重新生成您的 SDK：

  1. 在 Developer Console 中，打开您应用程序的 SDK 版本 标签页。
  2. 使用 TypeScript OSDK v2 生成器生成新版本。
  3. 重新运行上文所示的 npm create @osdk/app@latest 命令，或将您的 SDK 包依赖项更新为新生成的版本。

有关这两个版本之间的差异以及如何更新现有代码的完整说明，请参阅 TypeScript OSDK 迁移指南。
