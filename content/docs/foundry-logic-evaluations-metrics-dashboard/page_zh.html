评估指标仪表板

评估套件运行产生的指标会被收集到报告中，这些报告可在 AIP Evals 指标仪表板中查看。在此，您可以查看图表和统计数据，或比较评估函数的汇总结果和/或各个测试用例的结果。请注意，仪表板视图不支持指标目标。

要访问仪表板，请选择 查看指标仪表板 （在 Logic 侧边栏的运行结果视图中），或在评估套件页面上的 运行测试 选项卡。

如需进行更深入的分析和调试，您可以访问 LLM 跟踪查看器。请导航至 查看测试 选项卡，然后双击进入某个测试用例以打开跟踪查看器。在此，您将能够查看执行信息，了解函数结果是如何计算得出的。如果您使用的是自定义 LLM 作为评判者的评估器，LLM 跟踪查看器还将包含有关 LLM 评判者决策过程的信息。
