IBM Cloud Data Engine

IBM Cloud Data Engine 连接器是一个 由 Palantir 提供的驱动程序 用于 IBM Cloud Data Engine。

要创建新的 IBM Cloud Data Engine 源，请按照 Palantir 提供的驱动程序的标准设置流程，然后使用以下部分进行 IBM Cloud Data Engine 特定的配置和网络设置。有关完整的属性参考，请参阅 IBM Cloud Data Engine 官方驱动程序文档 ↗.

测试版

IBM Cloud Data Engine 连接器处于 测试版 开发阶段，可能无法在您的注册租户中使用。功能在积极开发过程中可能会发生变化。

受支持的功能

功能状态
探索🟡 Beta
批量同步🟡 Beta
增量🟡 Beta
OAuth 2.0 身份验证🟡 Beta

配置

以下属性为必填项或推荐项。

属性是否必填？描述默认值
ApiKey ↗必填用于向 IBM Cloud 标识用户的 API 密钥。—
CloudObjectStorageCRN ↗推荐在 IBM Cloud 中唯一标识您的 Cloud Object Storage 实例的 CRN。—
InitiateOAuth ↗推荐网络REFRESH
SqlQueryCRN ↗推荐在 IBM Cloud 中唯一标识您的 SQL Query 实例的 CRN。—

网络

下表列出了源运行时必须能够访问的域。

为每个域名添加相应的 出口策略。如果该源托管在本地且无法从 Foundry 直接访问，请改用 代理出口策略 作为替代。代理主机本身也必须能够访问所列出的域。请参阅 使用代理作为代理服务器 了解详情。

域名必需
iam.bluemix.net始终
api.dataengine.cloud.ibm.com始终。新的 v3 端点，除非使用较旧版本的驱动程序，否则很可能需要/使用该端点
<Region>.cloud-object-storage.appdomain.cloud始终。Region 连接属性已映射（也可能由 IBM 返回或作为 CRN 的一部分）
resource-controller.cloud.ibm.com如果未提供 CRN
sql-api.ng.bluemix.net旧的 v2 端点，已被 api.dataengine.cloud.ibm.com 取代
