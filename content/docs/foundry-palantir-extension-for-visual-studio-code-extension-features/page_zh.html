功能列表：适用于 Visual Studio Code 的 Palantir 扩展

本页面介绍了适用于 Visual Studio Code 的 Palantir 扩展中可用的功能。

  • 转换预览
    • 活动预览
    • 代码定义的输入筛选器
  • 调试转换
  • 构建转换
  • 转换类型提示
  • Python 库
    • 调试 Python 环境

命令

以下各节列出了适用于 Visual Studio Code 的 Palantir 扩展中可用的命令。在 Palantir 生态系统中处理 Python 转换（例如在管道开发过程中）时，可以使用这些命令来优化您的工作流程。

如果某个命令未集成到界面中，您可以使用 命令面板来调用它。您可以使用以下快捷键访问命令面板： Cmd+Shift+P （macOS）或 Ctrl+Shift+P （Windows/Linux）键盘快捷键。

预览并构建

运行预览

执行当前转换文件的预览。

  • 命令： palantir.transforms.previewFile
  • 图标：

在 Foundry 上构建

在 Foundry 上为所选文件启动构建流程。

  • 命令： palantir.transforms.buildFile
  • 图标：

打开预览面板

显示预览面板，以便快速访问转换预览。

  • 命令： palantir.transforms.openPreviewPanel

转换管理

创建新转换

初始化新的转换项目。

  • 命令： palantir.transforms.createTransform

安装 Python 环境

设置开发转换所需的 Python 环境。

  • 命令： palantir.transforms.initializePythonEnvironment

安装 Python 测试环境

设置用于转换开发的 Python 测试环境。

  • 命令： palantir.transforms.initializePythonTestEnvironment

仓库与文件管理

在浏览器中打开文件

在 Web 浏览器中打开当前选定的文件。

  • 命令： palantir.openFileInBrowser

打开仓库

提供在 Web 浏览器中快速访问仓库的方法。

  • 命令： palantir.openRepository

无障碍

高对比度显示

提供一种在 VS Code 中快速切换高对比度主题与普通主题的方法。

  • 命令： palantir.toggleHighContrastTheme
  • 键盘快捷键（macOS/Windows）： ctrl + option + h / ctrl + alt + h

仅用于本地开发的命令

克隆代码仓库

允许克隆仓库以进行本地开发。

  • 命令： palantir.cloneRepository

重启 Code Assist 工作区

重启 Code Assist 的工作区。

  • 命令： palantir.code-assist.restartWorkspace

刷新令牌

刷新身份验证令牌以维持对 Palantir 服务的访问权限。

  • 命令： palantir.refreshToken
  • 图标：

代码片段

Visual Studio Code 中的代码片段 ↗ 是便于输入重复代码模式的模板。

以下是适用于 Visual Studio Code 的 Palantir 扩展中所有可用代码片段的列表。符号 → 表示 Tab 键。

长格式代码片段

代码片段输出代码模板
python_transform→Python 转换
polars_transform→使用 Polars 的 Python 轻量级转换
pandas_transform→使用 pandas 的 Python 轻量级转换

简短代码片段

代码片段输出代码模板
ptf→Python 转换
pltf→使用 Polars 的 Python 轻量级转换
pdtf→使用 pandas 的 Python 轻量级转换
