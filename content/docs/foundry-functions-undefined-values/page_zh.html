处理 undefined 值

以下文档特定于 TypeScript v1 函数。如需更 强大的功能（包括对本体论 SDK 和可配置资源请求的支持），我们建议 迁移到 TypeScript v2。

以下是两种有用的模式，可用于处理 undefined 值，这些值可能在访问属性或关联时返回。

显式检查

@Function()
public getFullName(employee: Employee): string {
    if (!(employee.firstName && employee.lastName)) {
        throw new UserFacingError("Cannot derive full name because either first or last name is undefined.");
    }
    return employee.firstName + " " + employee.lastName;
}

通过检查 firstName 和 lastName 两个字段是否均已定义，TypeScript 编译器就能知道带有 return 语句的最后一行能够正确编译。这种方法的好处是类型检查更加显式，而且在存在 undefined 值的情况下，你可以抛出更明确的错误，指出问题所在。

非空断言运算符

你可以使用 TypeScript 的 非空断言运算符 ↗ （!）来忽略 undefined 的情况。

Copied!
1
2
3
4
@Function()
public getFullName(employee: Employee): string {
    return employee.firstName! + " " + employee.lastName!;
}

这种方法只是绕过了 TypeScript 编译器，并断言你所访问的字段是已定义的。虽然这样可以让代码更简洁，但当其中一个字段实际上是 undefined时，可能会导致晦涩难懂的错误。我们建议尽可能进行显式检查。
