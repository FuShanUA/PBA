配置 Code Workspaces 计算配置文件

Code Workspaces 计算配置文件让资源管理员能够标准化和限制计算资源（CPU 和内存）， 代码工作区 在整个注册中可以使用的资源。你可以在以下位置配置计算配置文件： 代码工作区 设置位于 控制面板.

默认情况下，代码工作区的计算配置文件管理处于禁用状态：在创建或配置工作区时，用户可以选择的 CPU 和内存上限为 资源队列的项目中的训练任务 支撑其项目的资源中的最大可用值。当你启用 Code Workspaces 的计算配置文件管理后，工作区可用的计算资源将改由导入到其项目中的计算配置文件决定。管理配置文件有助于你标准化计算资源并控制使用成本。

启用计算配置文件管理

  1. In 控制面板，请选择 代码工作区 你的注册的设置。
  2. 启用 Code Workspaces 的计算配置文件管理.
  3. 从左侧面板中选择 默认可导入计算配置文件。注册中的每个用户在创建或配置代码工作区时都可以将此配置文件导入到他们的项目中。默认 Medium 配置文件（最多 2 个 CPU 和 16 GB 内存）适用于大多数轻量级代码执行。
  4. 保存您的更改。

启用计算配置文件管理，并为注册选择默认可导入计算配置文件。

计算配置文件如何影响用户

在受管理的注册中，用户在 高级配置 已应用标签 配置并保存 对话框中分两步选择计算资源。用户首先选择一个计算配置文件，然后在该配置文件范围内分配计算资源。

在受管理的注册中，导入的计算配置文件决定了工作区计算分配滑块的上限。

选择计算配置文件

直方图 项目中导入的计算配置文件 下拉菜单决定了工作区可用的最大计算资源。用户可以从下拉菜单中选择：

  • 已导入到项目中的最大配置文件。此配置文件始终可选，因为项目中的每个代码工作区都可以使用它。
  • 用户有权导入的更大配置文件。非资源管理员的用户只能导入 默认可导入计算配置文件.

为工作区分配计算资源

直方图 工作区计算分配 滑块位于下拉菜单下方，用于分配所选配置文件的一个子集。它不能超过上面选择的配置文件，并且计算资源仍受项目 资源队列的项目中的训练任务.

为项目授予更大的计算资源

要为项目提供比注册默认值更多的计算资源，资源管理员可以将更大的配置文件导入到该项目中。然后，项目中的每个代码工作区都可以使用最高达该配置文件的计算资源，无论是由谁导入的。请查看 选项卡允许您查看分配给该项目的 以了解项目可用的最大计算资源。

从项目中移除计算配置文件

要阻止项目使用已导入的配置文件：

  1. 打开项目的 引用 部分，然后选择 外部引用.
  2. 选择要移除的配置文件导入。
  3. 选择 移除引用 在右上角。

权限

启用计算配置文件管理、选择 默认可导入计算配置文件以及将更大的配置文件导入项目需要 资源管理管理员 注册上的角色。请参阅 配置访问权限 以了解如何授予注册资源管理角色。
