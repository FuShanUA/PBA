创建拖放集成点

以下教程仅涵盖在传输或接受相同媒体类型的拖放区域之间进行拖放。例如，如果你的拖拽区域添加了 Foundry 对象 RID 媒体类型数据到 DataTransfer，你只能将其拖放到接受 Foundry 对象 RID 媒体类型的放置区域上。如果你希望支持将 Foundry 对象 RID 数据放置到接受 Gotham 对象 媒体类型的放置区域上，例如，你需要 为你的对象启用类型映射 并按照 富化教程 在本教程之后进行操作。

拖放允许用户在应用程序内部和应用程序之间动态移动数据。以下教程将教你如何在你的应用程序与 Palantir 平台（包括 Gotham 和 Foundry）之间拖拽数据。只需为你的应用程序添加一个拖放集成点，用户就可以在你的应用程序与 Palantir 平台之间无缝执行工作流。

实现拖放区域包含两个主要组件：

创建拖拽区域:

  1. 使 HTML 元素可拖拽
  2. 向 DataTransfer 添加数据

创建放置区域:

  1. 使条目能够放置到你的放置区域上
  2. 处理放置操作
  3. 为你的放置区域设置样式

我们建议安装最新版本的平台，以提高你的应用程序与 Palantir 平台之间的拖放互操作性。

创建拖拽区域

拖拽区域是一个交互式 DOM 元素，允许用户“抓取”数据并通过将其“放置”到放置区域上来传输到其他位置。拖拽区域将数据写入 DataTransfer 对象，从而在用户拖动 draggable 元素时传输数据。以下步骤详细说明如何使元素 draggable、向 DataTransfer 对象添加数据以及处理拖拽事件。请参阅 拖拽区域 和 DataTransfer 对象 以了解这些概念的详细信息。

使 HTML 元素可拖拽

通过设置 draggable 属性设置为 true将 HTML 元素设为拖拽区域。要将数据附加到拖拽事件，请添加 ondragstart 处理器，它将在 DataTransfer 上设置数据。

function handleDragStart(event) {
    event.dataTransfer.setData(
        <media type>,
        <data>
    );

   event.dataTransfer.effectAllowed = "move";
}

替换 <media type> 以上内容使用被拖拽数据的媒体类型，例如 application/x-vnd.palantir.rid.phonograph2-objects.object 用于 Foundry 对象 RID。将 <data> 替换为数据的序列化版本，使用 JSON.stringify 将数据转换为字符串。请参阅 Palantir 媒体类型文档 以确定适合你的用例的正确媒体类型。

向 DataTransfer 添加数据时请牢记安全问题。任何放置区域都将能够访问这些数据。

function handleDragStart(event) {
    const foundryObjectRids = ["ri.phonograph2-objects.main.object.XXXXXXX", "ri.phonograph2-objects.main.object.YYYYYYY"]
    event.dataTransfer.setData(
        "application/x-vnd.palantir.rid.phonograph2-objects.object",
        JSON.stringify(foundryObjectRids)
    );

    event.dataTransfer.effectAllowed = "move";
}

此处理器将 Foundry 对象 RID 媒体类型添加到 DataTransfer。任何接受 Foundry 对象 RID 数据的放置区域都将能够以 foundryObjectRids 的形式接收数据，当被拖拽的 DataTransfer 被放置时。

此时，你应该能够从你的拖拽区域拖放到接受 DataTransfer 中媒体类型的放置区域上。请参阅 Palantir 媒体类型 以根据媒体类型找到接受你的拖拽负载的放置区域。

创建放置区域

放置区域是 DOM 上的交互式元素，用于接收来自拖拽区域的“放置”数据。放置区域的工作方式是监听 ondrop 事件，并在事件触发时从事件的 DataTransfer 访问信息。请参阅 放置区域 和 DataTransfer 对象 以了解更多信息。

你可以通过添加 ondragover 处理器将 HTML 元素转换为放置区域，该处理器会阻止默认事件行为。添加 ondrop 处理器来处理被放置的 DataTransfer。

步骤如下：

  1. 使条目能够放置到你的放置区域上
  2. 处理放置操作
  3. 为你的放置区域设置样式

本教程介绍如何创建一个接受 Foundry 对象 RID 媒体类型的拖放区域，但您的实现可以将其替换为您选择的媒体类型。

处理放置操作

  1. 创建一个函数来处理拖放操作，方法是在数据被拖放后从 DataTransfer 访问数据，并阻止默认的事件行为（即打开链接数据）。调用 DataTransfer 的 getData 函数以字符串格式从 DataTransfer 返回数据。 getData 如果 DataTransfer 没有数据，或者 DataTransfer 没有该媒体类型的数据，则返回空字符串。请参阅 MDN getData 文档 ↗ 以了解有关此方法的更多信息。

function handleDrop(event) {
    // prevent default open-link behavior
    event.preventDefault();

    // get Foundry object RIDs data
    const data = event.dataTransfer.getData(
        "application/x-vnd.palantir.rid.phonograph2-objects.object"
    );

    try {
        if (data != null && data !== ""){
            // try to parse the returned data
            const dataParsed = JSON.parse(data);

            // print the data
            console.log(dataParsed);

            // do something with the data
            doCoolThingWithFoundryObjects(dataParsed);
        }
    } catch (error) {
        console.error("Unable to parse data", error)
    }
}

为你的放置区域设置样式

为您的拖放区域应用样式至关重要，这样用户才能看到拖放区域是否接受其拖动载荷。否则，拖放区域的可用性将不尽如人意。我们建议根据拖动载荷对拖放区域是否有效，或者拖放区域是否需要执行额外的工作来确定是否接受该拖动载荷，为拖放区域应用不同的样式。拖放区域的样式应在拖放完成后清除，这将在下面的步骤中介绍。

在本教程结束时，如果您的拖放区域接受拖动载荷，它将“亮起”，但本教程不涵盖实现 设计指南中概述的“无效”和“加载中”样式。我们建议实现这些额外的样式，以获得更加连贯且用户友好的拖放交互体验。

完成步骤一到四后，当用户将具有可接受媒体类型的载荷拖到您的应用程序上时，您的拖放区域应该会“亮起”。完成步骤五到七后，当用户从您的应用程序内部开始拖动时，您的拖放区域将“亮起”。完成步骤八后，下图所示的悬停样式将应用于您的拖放区域。

  1. 复制 CSS 类实现。为了向您的拖放区域应用样式，请为您的样式创建一个 CSS 文件，并从 设计指南中添加适当的拖放区域样式类，其中包含基于拖放区域大小的不同样式建议。

  2. 通过编写一个函数，在拖动载荷包含可接受的媒体类型时有条件地添加样式，从而在您的拖放区域接受拖动载荷时添加样式。此函数使用 classlist ↗ 属性，在拖放区域接受拖动载荷时为其添加一个额外的类名。请参阅 设计指南 以了解 CSS 拖动悬停样式。

function conditionallyApplyStylingToDropZone(event, className){
    // our drop zone accepts the drag payload if it has a Foundry object RIDs media type
    if(event.dataTransfer?.types.includes("application/x-vnd.palantir.rid.phonograph2-objects.object")){
        const dropzone = document.getElementById("my-cool-drop-zone");
        if(dropzone != null){
            // add the style's classname
            dropzone.classList.add(className);
        }
    }
}

let dragInsideApplicationCount = 0;

function handleDragEnter(event){
    if(dragInsideApplicationCount === 0){
        maybeApplyValidStylingToDropZone(event, "valid-small");
    }

    dragInsideApplicationCount += 1;
}

function handleDragLeave(event){
    if(dragInsideApplicationCount === 1){
        removeValidStylingFromDropZone("valid-small");

}

document.addEventListener("drag-enter", handleDragEnter, {capture: true});
document.addEventListener("drag-leave", handleDragLeave, {capture: true});

上面的代码只有在拖拽是从外部应用程序或窗口上的拖拽区域发起时，才会使放置区域亮起。若要让放置区域在拖拽负载来自您自己的应用程序时也亮起，请添加一个 dragstart 监听器，具体说明见下一步。

function handleDrop(event) {
    // prevent default open-link behavior
    event.preventDefault();

    // perform some styling cleanup
    // remove CSS classes now that there is no active drag payload
    removeStylingFromDropZone("valid-small-hover");
    removeStylingFromDropZone("valid-small");

    // reset counters
    dropHoveringOverDropZoneCount = 0;
    dragInsideApplicationCount = 0;

    // get Foundry object RIDs data
    const data = event.dataTransfer.getData(
        "application/x-vnd.palantir.rid.phonograph2-objects.object"
    );

    try {
        if (data != null && data !== ""){
            // try to parse the returned data
            const dataParsed = JSON.parse(data);

            // print the data
            console.log("dropped data: ", dataParsed);

            // do something with the data
            doCoolThingWithFoundryObjects(dataParsed);
        }
    } catch (error) {
        console.error("Unable to parse data", error)
    }
}
