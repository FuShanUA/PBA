基础类型

属性基础类型定义了可在属性中存储的数据类型。有关所有受支持的属性基础类型的完整参考，请参阅 属性概览。

基础类型 用于在对象上定义属性。属性的基础类型决定了该属性在用户应用程序中可用的操作集合。所有字段类型均为有效的基础类型，但不包括 Map 和 Binary 类型。

基础类型还包括以下高级类型：

  • 向量： 一种用于在对象上存储 向量 以供语义搜索使用的类型。
  • Geopoint： 一种用于定义表示地理 点的属性的类型。
  • Geoshape： 一种用于定义表示地理 形状的属性的类型。
  • 附件： 一种用于在对象上存储文件以供 对象上的函数使用的类型。
  • 时间序列： 一种用于将属性定义为 时间序列的类型。
  • 地理时间序列： 一种用于将属性定义为对 地理时间序列的引用的类型。
  • 媒体引用： 一种用于定义 媒体文件引用的类型。
  • 密文： 一种用于存储经 Cipher编码的字符串值的类型。
  • 结构体： 一种用于定义基于架构、具有 多个字段的属性的类型。

所有基础类型都可以在数组中使用，以表示属性的多个值，但不包括 Vector 和 Time series 类型。

复杂属性基础类型

某些属性基础类型需要额外配置，或具有特定的使用场景。请参阅以下章节，了解下列属性基础类型的相关信息：

  • 媒体引用： 引用存储在媒体集中的媒体项。
  • Struct 类型： 包含多个字段的复杂结构化数据。

媒体引用

一个 媒体引用 属性类型允许您在对象上使用媒体，例如图像、视频、音频文件和文档。一个 媒体引用 指向 媒体集中的特定媒体项。媒体引用包含有关媒体文件的信息，这意味着 Foundry 可以在使用媒体引用的任何地方显示该媒体。

配置媒体引用属性

具有媒体引用属性的对象类型由数据集支撑。支撑数据集必须包含一个媒体引用列，该列将映射到媒体引用属性。这种列类型专为存储媒体引用值而设计，可确保本体论对象与媒体集之间的正确集成。

此外，媒体引用属性必须具有一个 媒体源，可在对象类型的“ 功能 ”选项卡中进行配置。该媒体源应为媒体引用所指向的媒体集。

结构体

结构体 是本体论属性的一种基础类型，允许用户创建基于架构且具有多个字段的属性。结构体属性是从结构体类型的数据集列创建的。要了解有关结构体的更多信息，请参阅完整的 结构体 文档。
