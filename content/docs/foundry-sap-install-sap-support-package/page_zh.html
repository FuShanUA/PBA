安装支持包

支持包是在初始安装包之后交付的一系列错误修复和新功能的集合。

对于适用于 SAP 应用程序的 Palantir Foundry Connector 2.0（"Connector"），应通过 SPAM（支持包管理器）遵循标准的支持包安装流程。

在安装支持包期间，请暂停日常维护作业计划以及所有使用该 Connector 的 Foundry 数据同步。否则，后台进程持有的数据库锁可能导致安装失败。

使用 SAR 格式的安装文件（FOUNDRY-SAPCONN-INST-SP00SPXX.SAR). XX 表示支持包级别。根据系统上已安装的支持包级别，SPAM 将加载必要的文件以执行升级。

  1. 下载安装包.
  2. 使用有权使用 SPAM 的用户登录 SAP 系统 client 000。
  3. 运行 SPAM 事务。
  4. 从应用服务器导入包。
  5. 要进行导入，请选择 安装包 > 加载包 > 从前端 （位于工具栏菜单中）。
  6. 定义支持包安装的队列。 所有 Connector 组件应一起升级：请将 PALCONN and PALANTIR 组件一起升级，或将 PALANTIR and PALAGENT 组件一起升级。
  7. 选择应用程序组件。要将 PALANTIR 组件一起升级，请选择 所有组件，然后仅选择 PALANTIR 组件并升级到所需的支持包级别。请确保在升级过程中未选择任何其他组件。
  8. 在 SPAM: Import: Queue 对话框中，将 准备 as 在对话框中启动 以及所有其他步骤设置为 在后台继续.

如果安装过程中出现警告，请按照警告消息中描述的步骤进行处理。在大多数情况下，Connector 和 Remote Agent 安装中的警告消息可以忽略。特别是标题为 "Open Data Extraction Requests" 的警告消息可以安全地忽略。

  1. 导入成功完成后，请确认队列。

保持 SPAM/SAINT SP 级别和 tp/R3Trans 补丁处于最新状态至关重要。如果在 DDIC_ACTIVATION期间出现问题，请使用 SAP 提供的批量激活程序（RADMASG0）并启用 强制激活标志.

支持包之间可能存在 SAP 安全更新，从而新增授权对象。因此，如果使用了自定义角色，强烈建议将 /PALANTIR/* 角色的内容与自定义角色进行比较。如果使用了 /PALANTIR/* 角色，请确保所有用户比较已完成，授权配置文件已生成且状态为绿色。
