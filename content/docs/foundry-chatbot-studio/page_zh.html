AIP Chatbot Studio

AIP Chatbot Studio 此前称为 AIP Agent Studio，而 AIP Chatbots 此前称为 AIP Agents。

AIP Chatbot Studio 允许用户构建称为 AIP Chatbots 的交互式助手，这些助手配备企业特定的信息和工具，既可以在平台内部部署，也可以通过 本体论 SDK 和 平台 API 在外部部署。

在 AIP Chatbot Studio 中构建的聊天机器人由大语言模型（LLM）、本体论、文档和自定义工具驱动。AIP Chatbots 可以集成到应用程序中，以实现动态、上下文感知的读写工作流，让您能够自动执行任务并减少与应用程序的手动交互。

以下示例展示了一个 AIP Chatbot，它在回答用户关于美联储近期新闻发布会的问题时，会使用应用程序变量将经过筛选的视频转录文本对象集作为上下文。

上述 AIP Chatbot 还可以部署在 Workshop 应用程序 中，使用户能够与所选视频进行交互。

AIP Chatbot Studio 建立在同样严格的 安全 模型之上，该模型治理着 Palantir 平台的其余部分。这些平台安全控制仅向 LLM 授予完成任务所需的访问权限。
