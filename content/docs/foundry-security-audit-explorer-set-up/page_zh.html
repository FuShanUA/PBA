设置 Audit Explorer

Audit Explorer 读取 audit.3 来自审计表的审计日志：一个 Iceberg 表，一个 audit.3 审计导出 写入的表。您可以在 Audit Explorer 中创建导出。如果您已有审计表，请跳至 选择审计表.

所有屏幕截图均使用虚构数据。

前提条件

要设置 Audit Explorer，您需要满足以下条件：

  • 应用程序访问权限： Audit Explorer 处于测试阶段，可能不适用于您的租户。请查看如何 访问 Audit Explorer.
  • Foundry Iceberg： 您的租户必须启用 Iceberg。请查看如何 验证 Iceberg 是否已启用。审计表的文件夹必须位于使用 Foundry 托管的 Iceberg 存储。如果 默认允许所有项目写入 Iceberg 表 处于关闭状态，则该项目可能需要 Iceberg 覆盖.

权限

Audit Explorer 使用您现有的 Foundry 权限。每项任务都需要各自的权限：

  • 创建审计导出权限： 您需要拥有 audit-export:orchestrate-v3 操作权限，针对您导出其日志的组织。默认情况下， 组织管理员 角色授予此操作权限。详情请查看 导出权限.
  • 创建 Iceberg 表权限： 您需要在审计表所在的文件夹中创建资源的权限。
  • 读取 Iceberg 表权限： 您需要拥有 table:read 操作权限，针对该审计表，并且您必须满足该表上的所有 标记。详情请查看 Iceberg 表权限.
  • 导出设置权限： 要打开 导出设置，您必须是导出所属组织的管理员。每项设置还需要对该审计表的各自操作权限：
    • 暂停或恢复导出： audit-export:update-export-state
    • 更改构建冷却时间： audit-export:update-minimum-build-cooldown
    • 更改保留期限： iceberg:write-maintenance-tasks and iceberg:write-sql-maintenance-tasks

确认使用指南

首次打开 Audit Explorer 时， 欢迎使用 Audit Explorer 对话框会出现。在您选择 我了解之前，Audit Explorer 不会显示任何审计数据。该对话框涵盖以下指南：

  • 用于监督与合规： 仅将 Audit Explorer 用于经授权的系统监督和合规用途。
  • 将审计日志视为敏感信息： 审计日志可能包含个人身份信息，包括姓名、电子邮件地址和其他敏感的使用数据。只有具备必要安全资质的用户才能查看。
  • 您的搜索会被记录： Audit Explorer 中的所有搜索都会成为审计日志。

选择 我了解 以继续。如需先了解更多信息，请选择 了解审计日志 以打开 审计日志 文档。

要重新阅读该指南，请选择 使用指南 （位于应用程序页眉中）。

创建 Iceberg 审计导出

直方图 开始使用 对话框会创建一个 audit.3 直接写入新 Iceberg 表的审计导出，该表即成为您的审计表。该导出使用与 导出设置 在 Control Panel 中相同的设置。它会持续添加新日志，构建之间无需等待。

要创建导出，请按照以下步骤操作：

  1. 打开 Audit Explorer。在 未选择审计表 页面上，选择 开始使用。如果 开始使用 未出现，则您无法在您的租户上创建审计导出。请改为选择现有审计表，或联系您的平台管理员。
  2. 自动预览行为 创建 Iceberg 表中，选择 配置 您要导出其日志的组织。该列表仅显示您可以在其中创建审计导出的组织。如果您可以为自己的组织创建审计导出，则默认会选择该组织。
  3. 为你的专业代码智能体输入 表名，或保留默认名称， Audit logs。然后选择一个 目标文件夹.
  4. 自动预览行为 导出日志起始时间，选择要导出的最早日期，以 UTC 为准。默认为 90 天前。您只能导出仍然可用的日志。
  5. 自动预览行为 保留期（天），输入日志的保留时长，范围为 1 到 730 天。默认为 90 天。每天，表维护会删除 date 早于保留期的日志。如果起始日期早于保留期，第一次每日维护将删除早于该期间的日志。
  6. 自动预览行为 访问标记，请至少选择一个 标记 以将该表限制为需要访问权限的合格审核者。审计日志可能包含个人身份信息和搜索查询。Audit Explorer 还会应用组织的标记。
  7. 选择 创建 Iceberg 导出。在 Audit Explorer 创建导出期间，您无法关闭该对话框。
  8. 当 Iceberg table created 出现后，选择 在此表中浏览日志。日志将在首次构建完成后出现，这可能需要几分钟时间。

更改导出设置

组织管理员可以在 Audit Explorer 中更改 Iceberg 审计导出的设置。选择 导出设置 （齿轮图标），位于侧边栏顶部的表名称旁边，或会话浏览器标签页上的表名称旁边。 导出设置 仅对审计导出写入的表显示。

直方图 导出设置 对话框包含以下设置：

  • 导出状态： 显示导出是否处于 Running, Paused，或 Stopped中的分支提案。选择 暂停导出 以在当前构建完成后停止新构建。现有日志仍可访问，保留期继续生效。选择 恢复导出 以重新开始构建。您无法恢复已停止的导出；请创建新的导出来收集更多日志。
  • 构建冷却时间： 导出在两次构建之间等待的时长，范围为 有新数据可用时立即构建 to 1 天。选择一个预设，或选择 自定义… 以输入最多 1,440 分钟，然后选择 保存冷却时间。在 Audit Explorer 中创建的导出初始没有冷却时间。更改冷却时间不会恢复已暂停的导出。
  • 保留期： 日志的保留时长，范围为 1 周 to 2 年。选择一个预设，或选择 自定义… 以输入 1 到 730 天，然后选择 保存保留期 并确认。更改将在下一次计划维护时生效。如果表的保留任务在 Audit Explorer 之外被更改，请在表的 维护 page instead.

当您缩短保留期时，下一次计划维护将永久删除早于新保留期的日志。

如果您没有更改某项设置的权限，对话框会显示 You do not have permission to change this setting. 您还可以在 Control Panel 中暂停和恢复导出。了解更多关于如何 更新或禁用导出数据集.

选择审计表

要打开审计表，请按照以下步骤操作：

  1. 在 未选择审计表 页面上，选择 选择审计表。或者，选择 选择现有表 菜单中选择 开始使用 dialog.
  2. 在监听器设置向导的 选择审计表 对话框中，找到您的审计表并选择它。您只能选择 Iceberg 表。

如果该表没有 必需的列，则会显示错误而不是日志。

Audit Explorer 在您下次访问时会打开上次选择的表，即使该表未通过列检查。要切换表，请选择 更改表 （铅笔图标），位于搜索标签页上侧边栏顶部的表名称旁边。

要共享表，请从浏览器的地址栏复制 URL。该链接会打开表，但不会打开您的搜索筛选条件，也不会授予接收者对该表的访问权限。

检查数据新鲜度

在搜索标签页上，侧边栏顶部的卡片会显示所选表的名称。在旁边 刷新，它会显示该表最新审计日志的时间，例如 5m ago。该时间不受您的搜索筛选条件影响。它会自动更新，并且在您每次选择 刷新时更新。将鼠标悬停在该时间上可查看确切时间。如果表为空、Audit Explorer 无法查询最新日志、侧边栏处于折叠状态，或者在 会话浏览器标签页.

上，该时间不会显示。日志需要一定时间才能到达审计表。请查看 audit.3 和 以了解交付延迟。如果导出已暂停或具有较长的构建冷却时间，新日志会较晚到达。请查看该表的 导出设置.

表与预期的模式不匹配

当表缺少必需的列或 Audit Explorer 无法读取该表时，Audit Explorer 会显示 The selected table does not match the expected audit log table schema. 。例如，您可能没有查看该表的权限、可能不满足其标记要求，或者该表可能已被删除。

当您打开一个表时，Audit Explorer 会检查它是否包含以下六列：

  • time，带有 timestamp or date type
  • logEntryId，带有标量类型，例如 string or long (not map, array，或 struct)
  • uid
  • name
  • categories
  • service

要查找原因，请阅读 错误详情。其中列出了缺失的列或错误的类型，或者显示 Foundry 在读取该表时返回的错误。您可以复制它以与您的管理员或 Palantir Support 共享。要打开其他表，请选择 选择另一个表.
