按钮组

直方图 按钮组 小部件允许应用构建者向 Workshop 模块添加可触发的按钮 操作 和 Workshop 事件、打开 URL 或启动导出。配置按钮组小部件的构建者可以执行以下操作：

  • 在以下三种按钮类型中进行选择：
    • 内联 提供单一选项的按钮
    • 菜单 提供多个选项的按钮
    • 两部分 包含一个主按钮以及一个附加选项菜单的按钮。
  • 组织 设置标签页的标签。 为每个按钮设置触发操作、触发一组事件、打开 URL 或开始导出。
  • 通过设置每个按钮的颜色、图标、大小和填充选项来调整样式。
  • 根据布尔变量的值配置条件禁用状态或条件可见性。

按钮配置选项

下面的截图展示了按钮组小部件中单个按钮可用的配置选项：

  • 添加按钮： 选择此选项会向此按钮组添加另一个按钮 / 菜单项。
  • 复制按钮： 选择此选项会创建现有按钮配置的副本，使构建者能够快速复制按钮设置。
  • 按钮文本： 此参数设置给定按钮或菜单项的显示文本。
  • 按钮颜色： 此配置控制给定按钮或菜单项的颜色。您可以选择带有关联颜色的预设“意图”，也可以指定自定义颜色。意图选项及其关联颜色包括 无, 主要 (blue), 成功 (green), 警告 （琥珀色）和 危险 （红色）。您可以使用自定义选项从更多种颜色选项中进行选择，包括使用十六进制代码设置颜色。
  • 左侧图标： 此参数控制显示在按钮 / 菜单项显示文本左侧的图标。设置为 空白 以不显示图标。
  • 右侧图标： 此参数控制显示在按钮 / 菜单项显示文本右侧的图标。设置为 空白 以不显示图标。
  • 描述： 此参数将在用户将鼠标悬停在按钮上时作为工具提示显示。
  • 徽章： 如果开启了条件可见性，以下选项将可用：
    • 条件可见性： 这是用于确定按钮条件状态的变量。
    • 状态为 false 时： 此选项控制当所选变量值为 false 时，按钮应被禁用还是隐藏。
  • 点击时： 此选项控制用户与按钮或菜单项交互时触发的操作。选项包括触发 操作、一个或多个 Workshop 事件、打开 URL 或启动导出。如果配置了多个 Workshop 事件，变量状态的更新可能无法在其余事件运行之前完成。完整的 设置标签页的标签。 options 列表见下文.
  • 显示与格式设置
    • 极简样式： 如果启用，此选项会移除按钮的边框。如果已应用颜色，按钮 / 菜单项的背景色和文本色将反转（例如，主要意图按钮可以从蓝色背景和白色文本翻转为白色背景和蓝色文本）。
    • 标签样式： 如果启用，此选项会将给定按钮调整为更窄的标签样式。
    • 大样式： 如果启用，此选项会增加按钮的整体大小。
    • 在行和列布局中填充可用水平空间： 如果启用，此按钮组将填充其所在区块的水平空间。
  • 场景
    • 使用按钮组创建操作时，您可以选择将该操作应用于 Scenario 还是本体论（Ontology）。
    • 应用于场景： 启用此开关可将此操作应用于 Scenario，而不是主本体论（Ontology）。
    • 选择场景变量： 选择要应用此操作的 Scenario 变量。

设置标签页的标签。

按钮可以触发操作、布局事件、URL 以及不同类型的导出。每个选项的详细说明如下。

操作

操作允许用户以预定义的方式轻松创建、编辑、删除和关联对象，并可由 Workshop 事件触发。例如，应用程序构建者可以在模块中配置一个按钮组（Button Group）小部件，以触发“修改航班目的地”操作，允许用户编辑 Destination 所选对象上的属性 Flight 对象。

了解更多关于 在 Workshop 模块中配置和公开操作.

有关操作的更多一般性详细信息，请查阅我们的 操作类型文档.

将事件与操作链接

配置按钮以触发操作时，您还可以配置在操作生命周期的特定时刻发生的 Workshop 事件。在小部件配置的底部，选择以下事件触发选项之一：

  • 在操作提交开始时： 配置的事件在操作提交开始时发生。
  • 在操作提交成功完成时： 配置的事件在操作成功提交后发生。

这允许您在单个按钮上链接操作和事件，从而实现诸如刷新数据、导航到其他页面或在操作完成后更新变量等工作流。

函数支撑导出

函数支撑导出接收一个函数及其输入，并将输出下载为指定的文件类型。支持的文件类型包括 CSV、TXT、JSON、XML、PDF、DOCX 和 XLSX。以下是按钮组小部件中函数支撑导出定义的示例：

函数支撑导出仅支持返回字符串输出的函数——基于文本的格式使用纯文本，二进制格式使用 base64 编码的字符串。返回其他输出类型（如 zip 文件）的函数不会出现在函数选择器中。要下载不支持的文件类型，请考虑创建一个 OSDK 自定义小部件，直接调用您的函数并启用 allow-downloads iframe 属性。

函数输出必须是字符串，其编码由导出文件类型决定：

  • 基于文本的格式（CSV、TXT、JSON、XML）： 函数应返回表示文件内容的纯字符串。
  • 二进制格式（PDF、DOCX、XLSX）： 函数应返回文件字节的 base64 编码字符串。在 Python 中，你可以返回 bytes 。不要在返回的字符串中包含 MIME 类型前缀（例如， data:application/pdf;base64,），否则导出将无法下载。Workshop 会根据导出配置中选择的文件类型推断 MIME 类型。

如果函数支撑的导出失败，错误提示会显示具体的失败原因。如果底层函数抛出 UserFacingError，则会向用户显示抛出的错误消息。对于无法识别的错误类型，将显示通用错误消息。

导出媒体

导出媒体事件接收一个已导出项的列表，并触发下载与这些项关联的所有媒体。要配置导出项，请选择对象集、媒体类型、媒体属性以及要下载的最大对象数。你可以为下载的媒体配置自定义文件名，并支持替换当前时间戳、原始文件名以及非主键对象属性值。如果未提供自定义文件名，则将使用原始文件名。
