配置目标元数据

当模型提交到建模目标时，默认会收集有关该模型和版本的某些元数据。此外，您还可以定义附加到每个提交模型的额外上下文特定元数据。

不同团队有不同的职责或希望跟踪的必需信息。例如，您可能希望监控合规代码、模型供应商 ID 或任务跟踪器（如 Jira）中的工单编号。自定义元数据使您能够跟踪与模型关联的任何想要捕获的信息。

直方图 显示元数据 选项卡位于 设置 页面提供更改每个目标收集的默认元数据显示选项的功能。但是，该选项卡中的所有元数据（无论选中与否）都将显示在 模型详情 部分中，针对每次模型提交。

直方图 自定义模型元数据 选项卡提供用于配置额外自定义元数据字段的界面。

支持多种元数据类型。

提供 JSON 编辑器选项，可轻松在目标之间复制/粘贴元数据。

向目标添加自定义元数据后，当有人提交模型时，提交者将可以填写这些自定义元数据字段。
