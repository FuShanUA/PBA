Pilot 工作区

Pilot 工作区是你与 AI 智能体交互来构建、预览和完善应用程序的地方。本页面介绍工作区的各个区域。

工作区布局

工作区分为两个主要区域：

  • 聊天面板 （左侧）：你可在其中提供指令、查看智能体活动并管理上下文附件的 AI 聊天界面
  • 应用程序视图 （中部）：用于预览、检查和调试应用程序的标签页视图

聊天面板

聊天面板是你与 Pilot 交流的主要界面。它包含以下内容：

  • 消息历史： 显示你的提示词、智能体回复、工具执行情况和推理步骤。Pilot 会实时显示每个智能体正在执行的操作，包括文件读取、编辑和 bash 命令。
  • 提示词输入： 底部的文本区域，你可在其中输入指令。选择 发送 或按 Enter 以提交提示词。
  • “添加”菜单： 选择 添加 以将上下文附加到提示词中，包括现有的本体论实体、文档和图像。请参阅 提供上下文和附件 了解详情。
  • “更多”菜单： 选择 更多 菜单以获取其他选项，包括选择模型和清除聊天记录。有关可用模型的详细信息，请参阅 模型和智能体模式。

当 Pilot 生成设计师或本体论架构师等专用子代理时，聊天面板会为该子代理的活动显示一个单独的线程。您可以在主线程和子代理线程之间切换，以跟进它们的工作。

预览选项卡

该 预览 选项卡会显示您生成的应用程序在已预配的容器中运行的实时预览。当 Pilot 修改应用程序代码时，预览会自动更新。

该 预览 选项卡包含一个浏览器样式的工具栏，具有以下功能：

  • 导航按钮： 用于在预览中导航的后退、前进和重新加载控件。
  • URL 栏： 显示当前预览的 URL。
  • 设备选择器： 在桌面、平板电脑和移动设备的视口尺寸之间切换，以便在不同屏幕尺寸下预览您的应用程序。预览会自动缩放以适配所选的设备框架。

在编辑器视图中，预览使用来自 Pilot 容器的种子数据。在部署视图中，您的应用程序会连接到真实的本体论数据。在部署分支上，schema 变更的作用域仅限于该分支；而在 Main上，任何操作都是对本体论的实时编辑。

当您构建自定义小组件时，该 预览 选项卡会在 Workshop 小部件沙盒中渲染您的小部件，以便您查看其嵌入后的实际显示效果。小部件预览不包含浏览器样式的导航工具栏。如果您更改了小部件的参数或事件，请选择 重新加载小部件开发模式 以将更改应用到正在运行的预览。请参阅 构建自定义小部件。

本体论选项卡

该 本体论 选项卡会以交互式图形显示 Pilot 为您的应用程序创建的对象类型、操作类型和关系。有关详细的分步说明，请参阅 本体论选项卡 文档。

代码选项卡

该 代码 选项卡提供了一个嵌入式代码编辑器，您可以在其中查看和编辑所生成应用程序的源代码。该编辑器使用与代码工作区相同的界面。您还可以通过聊天界面修改代码。

更多选项卡（...）

更多（...）选项卡目前包含一个项目， Pilot 日志，其中显示来自 Pilot 开发服务器的实时容器日志。您可以使用此选项卡执行以下操作：

  • 监控构建输出和编译状态。
  • 调试运行时错误。
  • 查看依赖项安装进度。

您可以使用复制按钮将日志内容复制到剪贴板。

内容标头

内容标题栏位于选项卡视图上方，提供以下功能：

  • 编辑器/部署切换开关： 在编辑器视图（种子数据）和部署视图（真实本体论数据）之间切换。详情请参阅 部署应用程序。
  • 版本选择器： 查看应用程序的版本并在各版本之间切换。
  • 选项卡导航： 在 预览、 本体论、 代码和 Pilot 日志 选项卡之间切换。
  • 状态指示器： 选择以打开状态监控弹出框。

编辑器视图和部署视图

内容标题栏中的 编辑器/部署 切换开关控制应用程序显示的数据。

  • 编辑器视图： 显示使用 Pilot 容器内生成的种子数据的应用程序。这是构建过程中的默认视图。种子数据可防止 AI 代理访问或硬编码真实的企业数据。
  • 部署视图： 使用分支上的真实本体论数据展示您的应用程序。发布前可使用此视图验证应用程序在生产数据下能否正常运行。

有关部署流程的完整演练，请参阅 部署应用程序。

在构建自定义小部件时，工作区还会显示 种子数据/生产数据 切换开关。此切换开关可在您构建的过程中，将预览在本地生成的种子数据和真实本体论数据之间切换。即使在预览生产数据时，模型也绝不会访问您的真实数据。有关小部件工作流程，请参阅 构建自定义小部件。

状态监控

内容标头右上角的状态指示器会显示您 Pilot 会话的整体健康状况。选择它可打开状态监控弹出窗口，其中会显示以下信息：

  • Pilot 状态： Pilot 连接是否正常或已断开连接。
  • 开发服务器： 开发服务器是否正在运行、处于非活动状态，或存在构建错误。
  • 依赖项： 软件包依赖项是否已安装、正在安装或安装失败。
  • 可部署性： 应用程序是否已准备好部署、无法部署，或存在无效的本体论实体。
  • 升级： 依赖项是否为最新版本或已过时。

每个状态项都包含一个用于解决问题的操作。对于大多数问题，您可以选择 使用 Pilot 修复 以提示 Pilot 诊断问题并自动应用修复。
