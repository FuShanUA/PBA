Struct 主字段 [Beta]

测试版

Struct 主字段位于 测试版 开发阶段，可能无法在您的注册租户中使用。功能在积极开发过程中可能会发生变化。

Struct 主字段 使您能够指定 struct 的 核心值和补充元数据。例如，一个 Address struct 可以包含捕获 streetName 和 postalCode 作为其主值的字段，而其他字段如 collectionDate 和 collectorName 则表示描述 Address 如何获取的元数据。

许多 struct 属性遵循这种模式：一个或多个字段包含您最关心在应用程序中显示的主要数据，而其他字段提供上下文、跟踪信息或审计详情。

您可以将任何 受支持的 struct 字段类型 指定为主字段。

何时使用 struct 主字段

在以下情况下使用 struct 主字段：

  • 您的 struct 除了表示补充元数据的字段外，还包含核心值字段。
  • 您希望表格显示更简洁，同时不失去对元数据的访问。
  • 您需要 实现接口 仅使用 struct 中的单个字段或字段子集。

配置 struct 主字段

  1. 导航至 本体论管理器.
  2. 通过选择以下内容搜索并选择您的对象类型 ,其中显示地图上各对象类型的对象数量。下方,每种属性类型各有一个部分,涵盖地图上存在的所有对象类型。面板顶部的筛选框允许您将结果筛选为名称匹配的属性。 under “资源” 在左侧面板中。
  3. 从您的对象类型的 属性 tab.
  4. 中选择要配置的 struct 属性 结构体字段 已应用标签 General 在右侧属性编辑器面板中出现的选项卡中选择要指定的字段。
  1. 默认启用预览确认 Struct 主字段 菜单中选择 编辑 {propertyName} struct 字段 弹出窗口，然后选择 确认。您可以通过点击并拖动字段的面板来指定多个主字段并重新排序，以便更清晰。
  1. 保存 您的更改。已配置的主字段会显示 Struct 主字段 标签，位于 结构体字段 list.

struct 主字段在应用程序中的显示方式

支持 struct 主字段的应用程序在紧凑视图（例如 对象表格 和 对象列表 中的小部件 来运行该专业代码代理。你还可以通过）中仅显示主字段，同时通过展开视图或悬停提供对完整 struct 的访问。这使您能够快速浏览最重要的数据而无需查看每个 struct 字段，同时在需要时仍能检查完整的 struct。

应用程序通过多种方式支持 struct 主字段：

  • 仅主字段： 在紧凑视图（如表格或摘要卡片）中仅显示主字段。
  • 带悬停的主字段： 默认显示主字段，并在悬停时显示元数据字段。
  • 完整 struct： 在需要完整信息的详细视图或表单中显示所有字段。

将 struct 字段与接口配合使用

您可以将任何 struct 字段映射到接口属性。在实现接口时，您可以从 struct 属性中选择特定字段来满足接口约定并满足属性要求。

例如，如果接口需要 String 属性来唯一标识，该属性名为 cityName，您可以使用 struct 属性的 city 字段来满足它。接口选择器会显示所有可用的 struct 字段及其类型，允许您选择合适的字段。

将 struct 字段映射到接口属性后，实现会显示所使用的 struct 属性和特定字段。

主字段在选择器中会带有 Struct 主字段 标签，便于识别。但是，无论字段是否被指定为主字段，您都可以从 struct 中选择任何字段。

将主字段与属性归约器结合使用

将 struct 主字段与 属性归约器 结合使用，以在 struct 数组属性表示和接口实现方面实现更大的灵活性。单个 struct 数组属性可以实现需要 Struct Array、主字段的数组类型 Struct或主字段的基础类型的接口。

有关构建自定义主题的示例，请参阅 属性归约器文档 以获取详细示例和实现选项。

限制和注意事项

  • 查询行为： 查询作用于所有 struct 字段，而不仅仅是主字段。您可以基于 struct 中的任何字段进行搜索和筛选。

常见问题

我可以稍后更改哪些字段是主字段吗？

可以，您可以随时在 Ontology Manager 中重新配置主字段。这可能会导致某些接口实现失效，您需要对其进行更新。

主字段会影响 Foundry 存储数据的方式吗？

不，主字段仅影响 Foundry 显示数据和实现接口的方式。底层 struct 包含所有字段且保持完整保真度，因此所有字段仍可查询和访问。

我可以在 struct 数组中使用主字段吗？

可以。主字段适用于 同时 单个 struct 属性和 struct 数组属性。当与 reducers结合使用时，您可以在 Foundry 跨应用程序表示该属性的方式上获得最大的灵活性。

我是否需要配置主字段才能在接口中使用 struct 字段？

不需要。无论是否被指定为主字段，您都可以将任何 struct 字段映射到接口属性。主字段只是在接口选择器中提供一个视觉指示，并影响应用程序在紧凑视图中显示 struct 的方式。
