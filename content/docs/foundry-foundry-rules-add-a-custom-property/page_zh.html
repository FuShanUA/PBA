添加自定义属性

在 Foundry Rules 中，一种常见的自定义操作是为规则对象和提议对象添加自定义属性。自定义属性可让您跟踪默认配置之外的额外元数据。要添加自定义属性，请按照以下步骤操作：

  1. 在 Ontology Manager 中，将该属性（例如 severity）添加到规则对象。

对象属性必须由输入数据集中的某一列支撑。

对于自动生成的空输入数据集，请直接在 Details 标签页中通过复制并修改现有的列定义来编辑架构。

对于来自现有管道的规则，请在转换中添加新列。

  1. 将相应的 current_<PROPERTY> 和 new_<PROPERTY> 属性（例如 current_severity 和 new_severity）添加到提议对象。
  2. 为提议对象的 current_<PROPERTY> 属性标注类型类 foundry-rules.property-diff-for:new_<PROPERTY> （例如 foundry-rules.property-diff-for:new_severity）。

每个类型类都有一个 kind 和一个 name，写作 kind.name。以 foundry-rules.property-diff-for:new_<PROPERTY>为例，其 kind 为 foundry-rules ，其 name 为 property-diff-for:new_<PROPERTY>。

  1. 在 Foundry Rules 设置中，编辑每一种会修改或创建规则对象或提议对象的操作类型，为其添加新自定义属性对应的参数。请参照另一个类似属性（例如 rule_name ）的示例，以了解需要添加的内容。

  2. 在 Workshop 应用中，添加一个 Workshop 变量，用于获取所选规则的自定义属性。您可以通过定义一个新的 objectProperty 变量，并将现有的 selectedRule 变量作为对象集输入来完成此操作。

    在 Rule Editor 的配置侧边栏中，将此 Workshop 变量设置为“Create a proposal to edit rule”操作的默认值。

  3. 如果提案小部件未正确显示差异，请按照以下步骤操作：

    • 在 Workshop 应用中，将 new_<PROPERTY> 属性添加到 按部分分组的属性 （在 Proposal Reviewer 小部件配置中）。此处无需选择“current”值。

    • 如有需要，可编辑属性名称以移除“new”前缀。

    • 将 foundry-rules.property-diff-for:ID_OF_NEW_PROPERTY 类型类添加到 current 属性，该属性属于 提案对象。
