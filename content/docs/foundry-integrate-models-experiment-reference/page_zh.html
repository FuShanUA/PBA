API：模型实验

模型实验 Python API 提供了一组用于将指标和超参数写入实验的方法。本页面包含有关 palantir_models.experiments 包中可用函数和类的信息。

palantir_models.experiments.Experiment

用于跟踪模型训练实验的类。可以从任意 ModelOutput 类创建实验。

Copied!
1
model_output.create_experiment(name="experiment-name")
函数描述
log_param(key, value)向实验记录单个参数。
log_params(parameter_map)向实验记录一组参数。
log_metric(name, value, step)将指标值记录到实验中的给定序列下。
log_metrics(metric_values, step)将一组指标值记录到实验中的给定序列下。
log_image(name, image, caption, step)将图像记录到实验中的给定序列下。
as_mlflow_run()创建上下文块，并将活动的 MLflow run 设置为写入该实验。

palantir_models.experiments.ErrorHandlerType

一个枚举，用于控制在运行实验代码时如何处理错误。它专门管理由非用户代码引起的错误，例如写入指标时的网络错误，或实验大小超限。

变体描述
ErrorHandlerType.FAIL遇到任何错误即失败。会将错误重新抛出给调用方。
ErrorHandlerType.WARN在首个错误时发出警告，然后忽略其余错误。
ErrorHandlerType.SUPPRESS不记录任何内容。

在创建实验时，可以将所需的错误处理程序类型传递给 ModelOutput.create_experiment ，如下所示：

from palantir_models.experiments import ErrorHandlerType
model_output.create_experiment(
    name="mnist-experiment",
    error_handler_type=ErrorHandlerType.WARN
)

Experiment.log_metric

palantir_models.experiments.Experiment.log_metric(metric_name: str, metric_value: float, step: Optional[int] = None)

  • 将指标值记录到序列中。
  • 如果序列不存在（尚未向其记录过数据），则会创建一个。
  • 如果 step 已提供，则会尝试在该步骤进行记录。如果已向该步骤记录过数据，将引发错误。
  • 如果 step 未提供，则序列的当前步骤将自动递增 1。
Copied!
1
2
experiment.log_metric(metric_name="train/loss", metric_value=1.5)
experiment.log_metric(metric_name="train/loss", metric_value=0.9) # will auto-increment the step

参数

  • metric_name： str
    • 要向其写入值的指标序列名称。
  • metric_value： float
    • 要写入的值。
  • step： Optional[int]
    • 可选的写入步骤。如果提供的步骤小于当前步骤，将引发错误。如果未提供步骤，则会自动递增。

Experiment.log_metrics

palantir_models.experiments.Experiment.log_metrics(values: Dict[str, float], step: Optional[int] = None)

  • 的批量版本 log_metric。
  • 将所有提供的值在同一步骤记录到各自的序列中。
  • 如果任一序列不存在（尚未向其记录过数据），则会创建该序列。
  • 如果 step 已提供，则将尝试在该步骤进行记录。如果该步骤已在任何序列上被记录过，将引发错误。
  • 如果 step 未提供，则所有序列的当前步骤将各自自动递增 1。
Copied!
1
2
3
4
experiment.log_metrics(values={
    "train/loss": 1.5,
    "train/acc", 0.7
})

参数

  • values: Dict[str, float]
    • 指标名称到指标值的映射。
  • step: Optional[int]
    • 要写入的可选步骤。如果提供的步骤小于正在写入的任何序列的当前步骤，将引发错误。如果未提供步骤，每个序列的步骤将各自自动递增。

Experiment.log_image

palantir_models.experiments.Experiment.log_image(series_name: str, image: Union[str, bytes, "PIL.Image.Image"], caption: Optional[str] = None, step: Optional[int] = None)

  • 将图像记录到序列中。
  • 图像必须是 PNG 图像的路径、PNG 图像字节或 Pillow ↗ 图像。
  • 如果序列不存在（尚未被记录过），将创建一个新序列。
  • 如果 step 已提供，则将尝试在该步骤进行记录。如果该步骤已被记录过，将引发错误。
  • 如果 step 未提供，则序列的当前步骤将自动递增 1。
Copied!
1
experiment.log_image("bounding_boxes", image="/path/to/image.png", caption="My caption", step=1)

参数

  • series_name: str
    • 要写入值的图像序列的名称。
  • image: Union[str, bytes, "PIL.Image.Image"]
    • 要写入的图像。
  • caption: Optional[str]
    • 随图像一同写入的可选说明文字。
  • step: Optional[str]
    • 要写入的可选步骤。如果提供的步骤小于当前步骤，将引发错误。如果未提供步骤，步骤将自动递增。
