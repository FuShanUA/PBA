共享安全责任模型

Foundry 的安全是 Palantir 与 Palantir 客户之间的共同责任。虽然 Palantir 负责我们控制范围内服务各层级的 Foundry 安全，但客户在确保其数据受到保护方面也发挥着至关重要的作用。

直方图 共享责任模型 是一种已被许多主要基于云的软件公司采用的框架，用于划分客户与云提供商之间的安全责任。作为云提供商，Palantir 负责安全 of 云本身，而客户负责安全 in 云中的内容。

在实践中，这意味着 Palantir 和底层的基础设施即服务（IaaS）提供商负责通过管理物理安全、主机基础设施、网络控制和应用安全来保护 Foundry。同时，客户对其选择在 Foundry 中托管的内容负有责任：具体而言，即客户数据和用户身份/访问配置。共享责任模型让客户能够控制自己的数据、数据的使用方式以及谁可以访问数据，并免除了客户对底层基础设施安全的担忧。

共享责任模型可以分解为双方的责任：

Palantir ↘客户 ↘
Foundry 服务客户数据
传输中和静态加密客户构建的应用程序
网络流量保护身份和访问管理（IAM）
操作系统、网络和防火墙配置资源权限（RBAC）
基础设施级监控和告警应用级监控和告警
持续交付、自动升级和补丁
基础服务：
→ 计算
→ 存储
→ 数据库
→ 网络
全球基础设施：
→ 区域
→ 可用区

作为客户，您在保护数据方面的某些责任可能因环境和架构而异，但您始终负责以下事项：

  • 通过 单点登录（SSO）为您的用户管理访问和身份。这包括强制执行多因素身份验证。如果您没有单点登录提供商，我们或许可以为您提供。
  • 确保上传到环境的任何数据是适当的，并符合您自己的政策和义务。
  • 确保您的用户应用适当的 自主访问控制（角色） and 强制访问控制（标记）.
  • 监控 应用级安全审计日志 以确保您的用户对平台的使用是适当的，并符合您自己的政策和义务。

如果您对共享责任模型有任何疑问或顾虑，请联系您的 Palantir 代表。
