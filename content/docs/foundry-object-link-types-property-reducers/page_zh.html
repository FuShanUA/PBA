属性缩减器 [Beta]

测试版

属性缩减器目前处于 测试版 开发阶段，可能无法在您的注册租户中使用。功能在积极开发过程中可能会发生变化。

A 属性缩减器 使您能够将 数组属性 转换为数组中的单个值，用于显示和接口实现。缩减不会 不 更改底层的属性类型或存储的属性数据；而是在读取属性值时提供对数组中缩减后值的访问。

例如，将缩减器应用于包含多个检查日期的数组，可以在表格或应用程序中查看属性时仅显示最近的日期，同时确保完整数组仍可用于查询和其他操作。支持缩减器的应用程序（例如 来运行该专业代码代理。你还可以通过）还使您能够在悬停或展开视图中查看完整数组。

缩减器适用于包含数值、时间、字符串和布尔基本类型的数组属性。您可以缩减 循环布局支持遍历各种数组类型，包括字符串、布尔值、数字、日期、时间戳和 数组，依据是使用受支持基本类型的任意结构体字段。请查看 下表 以了解属性缩减器支持的基本类型。

何时使用属性缩减器

在以下情况下使用属性缩减器：

  • 您的历史数据或时间数据存储在数组中，例如检查日期、状态更新或测量读数。
  • 您希望在表格或应用程序中显示最新/最早、最高/最低或第一个/最后一个数组值，同时保留属性的完整历史记录。
  • 数组属性需要非数组类型来令人满意地实现 接口属性.

受支持和不受支持的基本类型

缩减器基于底层基本类型作用于数组属性。下表对支持和不支持缩减器的数组子类型进行了分类。

受支持的基本类型

属性缩减器可用于包含以下子类型的数组：

类别基本类型缩减器选项
数值Byte, Short, Integer, Long, Float, Double, Decimal最高、最低
时间Date, Timestamp最近（最新）、最早（最早）
字符串String第一个、最后一个（按字典顺序）
布尔Booleantrue 在前、false 在前
结构体按任意受支持的结构体字段 如下所述取决于结构体字段的基本类型

不受支持的基本类型

属性缩减器 不 可用于包含以下子类型的数组：

  • Attachment
  • Cipher Text
  • Geohash
  • Geoshape
  • Geotemporal Series Reference
  • Marking
  • Media Reference
  • Time Dependent
  • Vector

对结构体数组的支持

缩减器基于特定的 字段 作用于结构体数组，而不是结构体本身。您只能按使用 受支持基本类型 之一的结构体字段进行缩减。您还可以使用不同的结构体字段配置多个缩减器，以处理并列的情况。

为结构体数组配置属性缩减器

结构体数组为缩减器提供了最大的灵活性。您可以基于结构体中使用 受支持基本类型 的任意字段进行缩减，并配置多个缩减器以处理并列的情况。

示例：客户评论历史记录

考虑一个 Product 对象类型，包名称为 customerReviews 结构体数组属性，它包含以下字段：

  • rating (Integer）：一到五星的评分。
  • reviewDate (Date）：客户发布评论的日期。
  • reviewerName (String）：评论者的姓名。
  • verifiedPurchase (Boolean）：指示购买是否经过验证。

以下是一个 Product 对象 customerReviews 属性的示例数据，如下所示：

ratingreviewDatereviewerNameverifiedPurchase
52024-11-20Alice Chentrue
32024-11-15Bob Smithfalse
42024-11-22Carol Leetrue

配置单个 reducer

请查阅 属性 reducer 配置说明 和 受支持基本类型 表，然后再开始。您可以在结构体字段上配置单个 reducer，Foundry 会使用该 reducer 将结构体数组缩减为单个结构体，并根据配置了 reducer 的字段对显示的值进行排序。

  • 单个 reducer： 渲染最新的 reviewDate.
  • 结果： 显示包含 Carol Lee 的四星评价的结构体，日期为 2024-11-22.

用户仍可查询并访问完整的评价历史。

配置多个 reducer

您可以配置多个 reducer 来处理并列的情况：

  • 主 reducer： 对结构体进行排序，并显示具有最新 reviewDate.
  • 回退 reducer： 渲染最高的 rating.
  • 用例： 如果两条评价发布在同一天，则渲染评分较高的评价。

回退 reducer 唯一 在主 reducer 产生多个结果时生效。主 reducer 始终首先进行评估，只有在主条件上并列的项才会被回退 reducer 进一步缩减。对于任何其他已配置的 reducer，此缩减行为会重复进行。

reducer 在应用程序中的显示方式

支持 reducer 的应用程序会在表格或列表等紧凑视图中显示缩减后的值，同时通过展开视图或悬停机制提供对完整数组的访问。这种方式让用户无需查看冗长的数组表示即可快速浏览数据，同时在需要时仍能检查完整的数组。

例如，某个应用程序可能只在表格单元格中显示 2024-11-22 （最近的日期），但当用户悬停或展开该单元格时会显示完整的日期数组。

将属性 reducer 与接口结合使用

使用属性 reducer 可确保数组属性能够实现非数组接口属性。这样，包含数组数据的对象类型就可以映射到 接口属性 期望单个值的接口。

示例：通过接口实现渲染最近的设备维护日期

接口： Asset

  • 属性： lastMaintenanceDate (Date)

对象类型： Equipment

  • 属性： maintenanceHistory (Date array)
    • 值： [2024-01-15, 2024-03-22, 2024-11-01]
  • Reducer： 最新版 maintenanceHistory date.
  • 实现： Date 数组属性通过配置的 reducer 实现单个 Date 用户在通过接口查看该属性时将看到 2024-11-01 。

直方图 Equipment 对象类型可以实现 Asset 接口，因为 reducer 允许将其 maintenanceHistory 数组属性表示为单个 Date 值。当用户通过 Equipment 接口查看 Asset 对象时，只会看到最近的维护日期。

当在对象类型上使用缩减后的数组值来满足作为 接口操作参数的接口属性时，在该类型的对象上调用该操作将返回错误。但是，对于未通过缩减数组值实现该接口的对象，您仍可使用该接口操作。

将属性 reducer 与结构体主字段结合使用

当您将属性 reducer 与 结构体主字段结合使用时，您可以启用属性显示，并扩展它们可实现的接口的数量和形态。

请考虑以下 Event 对象类型，其中包含一个 Locations 属性，该属性是一个结构体数组：

对象类型： Event

  • 属性： locations (Struct array)
    • 结构体字段： streetName (String), dateCollected (Date), numberOfGuests (Integer).
  • 配置的主字段： streetName
  • 配置的 reducer： 按以下字段取最新值： dateCollected.

使用 streetName 字段配置为主字段，并以最新的 dateCollected 作为属性 reducer，这样可以实现多种接口实现选项：

配置可以实现
未配置任一功能Struct Array only
仅主字段Struct Array, String Array
仅 reducerStruct Array, Struct
两者均已配置Struct Array, String Array, Struct, String

例如，在同时配置了 struct 主字段和属性 reducer 的情况下，您可以使用 locations 属性来满足 单个 来自接口的字符串属性，例如 Event street name 来自下图中的概念性 Event 接口。

当您同时配置 struct 主字段和属性 reducer 时，转换将：

  • 应用配置的属性 reducer，根据日期获取最近的位置。
  • 提取配置的主字段并将其值作为字符串返回。

这意味着单个属性可以实现需要以下任一类型的接口： Struct Array, String Array, Struct，或 String.

限制和注意事项

  • 无法直接查询归约后的值： 您无法基于归约后的值进行筛选或查询。查询作用于完整数组，而非归约后的表示形式。
  • 归约或 struct 主字段实现不支持接口操作： 接口操作 若编辑通过属性 reducer 或 struct 主字段 实现的属性，则在对该类型的对象调用时会返回错误。这是因为归约值和 struct 主字段值无法转换回底层的对象属性。例如，从数组中选择一个元素的 reducer 没有可用于重建完整数组的逆运算；提取字段子集的 struct 主字段无法填充其余字段。不针对这些属性的接口操作，或针对在不使用 reducer 或 struct 主字段的情况下实现接口的对象的接口操作，均可正常工作。

常见问题

配置后可以更改或移除 reducer 吗？

可以，您可以随时在 Ontology Manager 中修改或移除 reducer。更改无需重新索引，且会立即生效。

如果多个条目在 reducer 条件上并列怎么办？

对于 struct 数组，您可以配置备用 reducer 来处理并列情况。备用 reducer 仅对在主 reducer 上并列的条目进行求值。对于原始类型数组或没有备用 reducer 的 struct，将以确定但无序的方式返回并列值之一。

可以对仅编辑属性使用 reducer 吗？

可以，您可以为 仅编辑属性配置 reducer。reducer 配置与属性是否具有支撑列无关。

reducer 是否在所有应用程序中都能正常工作？

各应用程序正在逐步推出对归约属性的支持。如果您为某个属性配置了 reducer，而所使用的应用程序尚不支持 reducer，这不会破坏任何现有功能；该属性将继续以数组形式显示。只有支持 reducer 的应用程序才能显示归约后的值。
