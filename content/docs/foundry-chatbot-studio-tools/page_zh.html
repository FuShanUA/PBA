工具

工具是可供大语言模型（LLM）使用的外部功能或 API，用于执行特定操作或获取其固有能力之外的信息。工具尤其适用于让 LLM 决定控制流并构造输入。

工具模式

使用工具模式设置来控制如何向 LLM 提供已配置的工具，以及 LLM 如何调用这些工具。可用的工具模式设置包括：

  • 提示式工具调用： 此模式将指令插入提示中以提供工具，并允许 LLM 使用这些工具。处于此工具模式的聊天机器人一次只能调用一个工具，因此在回答需要多次工具调用的复杂查询时可能耗时更长。此模式支持所有工具类型以及所有 可用模型.
  • 原生工具调用： 此模式利用受支持模型的内置功能来提供工具，并允许 LLM 直接调用这些工具。由于更高的 token 效率以及此模式下聊天机器人可以并行调用多个工具，其速度和性能优于提示式工具调用。此模式目前仅可用于 Palantir 提供的部分模型以及以下工具类型：操作、对象查询、函数和更新应用变量。如果您需要使用原生工具调用模式不支持的模型或工具类型，请改用提示式工具调用模式。
