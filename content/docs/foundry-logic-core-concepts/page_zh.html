核心概念

以下核心概念对于理解和充分利用 AIP Logic 至关重要。您可以在 入门 教程中了解更多相关信息。

Logic 函数

Logic 函数接收诸如本体论对象或文本字符串等输入，并返回一个输出，该输出可以是值（如字符串）、对象或对本体论本身的编辑。

Logic 函数可以像平台中的任何其他函数一样被利用和使用，例如在 Workshop 模块中。要编辑本体论，Logic 函数必须先发布，然后通过操作调用。有关更多信息，请参阅如何 使用 Logic 函数 在操作中。

块

逻辑函数由 块组成。块有多种不同的用途，例如读取或写入本体论、执行计算、聚合数据、调用其他函数或与 LLM 交互。块的输出可在后续块中使用，从而能够通过将块串联在一起来构建复杂的操作。

评估

发布逻辑函数后，您可以配置 评估，使您能够为 Logic 函数编写详细的测试。AIP Logic 的评估可用于：

  • 调试并改进 Logic 函数和提示词。
  • 比较不同模型（如 GPT-4 与 GPT-3.5）在您的函数上的表现。
  • 检查 Logic 函数多次运行之间的差异。

调试

编写 Logic 函数后，您可以将该函数作为测试运行。运行您的函数将打开 Debugger 面板，其中会显示 Logic 函数中各组件块的 LLM 思维链 (CoT)。查看 LLM 的 CoT 可以展示 LLM “思维过程”的每个具体步骤，并提供有关 LLM 所用辅助工具的信息，从而使调试更加轻松。
