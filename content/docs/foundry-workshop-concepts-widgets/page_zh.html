小部件

小部件 是 Workshop 模块用户界面的核心构建块。每个小部件都是一个独立的功能单元，您可以将其放置在模块中 如果配置了多个，例如表格、图表、筛选器或按钮。小部件通过模块的 变量 相互传递数据，而不是直接相互引用。例如，筛选列表小部件输出一个应用于对象集变量的筛选器，而对象表格小部件显示该对象集。由于小部件通过变量共享数据，您可以添加、重新排列或替换小部件，而无需重新构建模块的其余部分。

小部件主要设计用于与 本体论配合使用。它们显示对象及其属性，让用户筛选和探索对象数据，并触发 操作 将决策写回本体论。这些功能共同让构建者能够构建用户如何达成并记录决策的结构，这也是 运营应用程序 与只读仪表板的区别所在。

要构建应用程序，请将小部件放入布局中，并根据您的用例配置每个小部件的输入和输出变量、显示选项和操作。如果内置小部件无法满足您的用例，您可以构建一个 自定义小部件.

要向模块添加小部件，请将鼠标悬停在任意空白区域上以显示 + 添加小组件 按钮，然后选择它。你也可以选择 + 某个区域或模块标题中的按钮。然后，从打开的小部件选择器弹窗中选择所需的小部件。

中所使用的高级配置。

一旦小部件被添加到 Workshop 模块中，选择该小部件即可在屏幕右侧显示其配置选项。下面的示例将在展示如何配置 Filter List 小部件的同时，解释 Workshop 小部件的一般核心概念。

小部件设置

小部件的核心配置选项位于 小部件设置 选项卡中。模块构建者将在此配置小部件的输入和输出变量（即最初填充小部件的数据，以及适用时由小部件生成和输出的数据），以及任何其他配置和显示选项。

在上面 Filter List 小部件的示例中，核心配置选项如下：

  • 对象集： 这是 Filter List 小部件的输入变量，用于确定可用的筛选选项。此配置可以接受在此 Workshop 模块中其他位置定义的现有对象集变量，或要创建的新对象集变量。
  • 筛选列表： 此选项用于确定将在小部件中显示的筛选选项。一旦 对象集 被填充后，此配置选项将显示更详细的内容；它将显示初始对象集中的属性类型，并允许对所有属性按关键字搜索以及按关联对象的存在进行筛选。
  • 允许用户添加和移除筛选条件： 此选项为小部件添加一个用户界面，允许模块用户添加和移除所显示的筛选条件。
  • 筛选输出： 此选项是一个作为小部件输出的对象集筛选变量。此筛选条件可应用于另一个对象集变量，以筛选指定变量中的对象。默认情况下，将 Filter List 小部件添加到模块时会创建一个输出变量。

复用小部件

配置小部件后，您可以将其复制以在模块中的任何位置复用。此功能对于重新创建复杂的小部件配置特别有用；但是，如果小部件配置可能随时间频繁变化，则 嵌入式 Workshop 模块小部件 可能更为合适。要复制小部件以供复用，请选择该小部件并使用 Cmd+C （macOS）或 Ctrl+C (Windows)。使用 Cmd+V （macOS）或 Ctrl+V (Windows) 将小部件粘贴到 未使用的小部件 区域，该区域位于 下按颜色组排列图中的节点。 左侧面板中部分的底部。通过选择以下选项将小部件添加到您的模块： + 添加小组件，然后在 未使用的小部件 小部件选择器模态框的选项卡中找到它。

或者，也可以使用 复制分区 中的控件来复制、剪切和粘贴小部件。

输入和输出变量

输入和输出变量控制数据在 Workshop 模块内的流动方式。

输入变量定义传递给给定小部件的数据，通常随后会在小部件中显示。输入变量的一个示例是传递给对象表格、筛选列表、图表和地图小部件的对象集输入。

输出变量定义从给定小部件传出的数据，随后由下游的小部件或其他变量使用。输出变量的示例包括对象表格小部件生成的“所选对象”对象集输出，或字符串下拉小部件生成的“所选值”字符串输出。

上面的“小部件配置”示例详细说明了如何为对象表格小部件配置输入变量（对象集）和输出变量（活动对象和所选对象）。有关变量的更多详细信息，请参阅 变量文档.

小部件的类型

小部件提供多种用途，从可视化信息到在 Workshop 模块中触发事件和数据写回。 小部件概述 列出了许多常用的 Workshop 小部件，并分为以下几类：

  • 核心显示组件
  • 可视化微件
  • 筛选小部件
  • 事件触发和导航小部件
  • AIP 小部件
  • 可观测性小部件
  • 嵌入 Foundry 应用程序
  • 跨应用程序交互

格式化

许多小部件提供格式化选项，帮助用户设置显示样式。其中两个选项是值格式化和条件格式化。

数值格式化

数值格式化 在面向用户的应用程序中渲染值时应用特殊格式，使原始值更易于显示。例如，Workshop 中的值格式化可用于在对象表格小部件中设置时间序列属性列以及在指标卡片小部件中设置时间序列属性显示时渲染值。此格式化仅对 Workshop 模块本地有效，而非对本体论全局有效。 进一步了解如何设置数值格式化。

数值格式化包括控制显示小数位数的选项。使用 Fraction digits 字段可设置小数点后显示的最小和最大位数；设置最大值会将较长的数值四舍五入到该长度，而不会更改底层数据。您还可以控制有效数字、整数位数、分组分隔符和表示法。请参阅 添加值格式化 以获取完整的选项列表。

下面的示例展示了如何使用值格式化来设置对象表格中名为 Weekly Cases的列中所显示值的样式，该列显示每个国家/地区每周观察到的 COVID-19 病例数。

条件格式化

条件格式化 应用规则来确定数字和迷你图的样式。在 Workshop 中，条件格式化可用于设置对象表格小部件中时间序列属性列以及指标卡片小部件中时间序列属性显示的样式。此格式化仅对 Workshop 模块本地有效，而非对本体论全局有效。 进一步了解如何设置条件格式化。
