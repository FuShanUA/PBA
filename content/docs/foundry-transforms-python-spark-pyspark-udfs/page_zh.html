概念：用户自定义函数

用户自定义函数（UDF）允许您在 PySpark 中使用自己的任意 Python 代码。例如，您可以使用 UDF 从数据集每一行的复杂文本格式中解析信息。

声明后，UDF 的工作方式与 PySpark 内置函数类似，例如 concat, date_diff, trim等。

动机

不太直观的是，在正常情况下，数据实际上从不会被真正引入到您的 Python 代码中。当您使用 PySpark 操作 DataFrame 时，您其实是在描述 Spark 集群为得到最终的 DataFrame 而应以分布式、并行方式执行的步骤。这使得 Spark 和 Foundry 几乎可以 无限扩展，但这也引入了少量的 UDF 设置工作，以便将代码注入集群并在实际数据上运行。PySpark 会将您的 UDF 代码发送到运行您查询的每台服务器。

考虑 UDF 的替代方案

当 PySpark 的内置函数能够表达相同的逻辑时，请避免使用 UDF，因为 UDF 的速度明显更慢。如果您必须使用 UDF，请参阅 PySpark 风格指南 以了解最佳实践。

"Weather report: rain 55-62"

假设我们想从以下天气格式中获取最低温度，在本例中为 55。我们可以编写以下普通 Python 函数：

def extract_low_temperature(weather_report):
    return int(weather_report.split(' ')[-1].split('-')[0])

围绕以下函数创建 UDF： extract_low_temperature 函数来将其集成到您的 PySpark 查询中。创建 UDF 需要提供函数及其在 PySpark 类型系统中的预期返回类型。

# Import the necessary type
from pyspark.sql.types import IntegerType

# Wrap our function as a UDF
low_temp_udf = F.udf(extract_low_temperature, IntegerType())

现在，可以在 DataFrame 上使用该 UDF，并将整列作为参数。

df = df.withColumn('low', low_temp_udf(F.col('weather_report')))

from pyspark.sql.types import StringType

def weather_quality(temperature, windy):
    if temperature > 70 and windy == False:
        return "good"
    else:
        return "bad"

weather_udf = F.udf(weather_quality, StringType())

df = df.withColumn('quality', weather_udf(F.col('temp'), F.col('wind')))

调试 UDF

Spark 不会将在 UDF 内部写入的日志包含在顶层驱动程序日志中。要检查 UDF 内部的值，请创建一个将调试信息作为列返回的临时 UDF。有关更多技巧，请参阅 日志记录。
