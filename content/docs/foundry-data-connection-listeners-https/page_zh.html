HTTPS 监听器

HTTPS 监听器通过 HTTPS 端点接收来自外部系统的入站 webhook 请求。事件被写入 流，从而支持通过 Automate、 流式管道，或使用流的支撑数据集进行批处理。

何时使用 HTTPS 监听器

您可以在以下情况下使用 HTTPS 监听器：

  • 外部系统支持出站 webhook。
  • 当外部系统发生变更时，您需要接收事件通知。
  • 外部系统无法使用标准 OAuth 2.0 或 Foundry API 进行身份验证。

配置监听器

导航至 Data Connection > Listeners ，以将 Palantir 平台连接到外部系统和工作流。有关如何安全地配置监听器和传入数据的信息，请参阅 HTTPS 监听器安全 文档。

您可以在 Data Lineage 中探索监听器的流式数据集，以更好地了解数据转换和数据流。

吞吐量和限制

只有低吞吐量的事件流才应推送到 HTTPS 监听器。HTTPS 监听器的速率限制约为每秒 100 个请求，因此需要显著更高吞吐量的集成应使用 流式同步 或 公共流式 API 端点 （如有可能）。

如果您的用例需要比当前提供的更高的速率限制，并且监听器是唯一合适的集成选项，请联系 Palantir Support 讨论提高此限制。

单个事件和请求负载的大小限制为 1 MB，因为这是输出流式数据集中的最大行大小。Foundry 会拒绝超出此限制的事件。
