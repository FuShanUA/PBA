在表单中，简单字段用于向填写者收集基本输入。本页面讨论 Foundry Forms 中可用的各种简单字段类型，但不包括 附件 字段。

标注

直方图 标注 字段用于向填写者突出显示重要内容，并支持 Markdown 格式。用户可以配置以下选项：

  • 创建引用其他字段值的内容。
  • 设置标题、背景颜色和图标。
  • 添加已上传到 Foundry 或可从 Foundry 访问的其他站点上的图片。

标注字段的值永远不会写入支撑对象类型或电子表格。如果您需要使用在其他字段中写入的值来模板化某些文本，可以使用 模板字段.

复选框

直方图 复选框 字段以复选框形式显示一组选项。用户可以配置以下选项：

  • 提供一系列可选的 Values 及其显示的 Labels.
  • 在您的终端会话中将 Default values.
  • 以水平或垂直方式显示复选框。

日期选择器

直方图 日期选择器 字段允许填写者输入日期或时间戳。用户可以配置以下选项：

  • 设置 Time Precision （日、分、秒或毫秒）。
  • 设置 Recorded format （默认为 YYYY-MM-DD （日期使用 YYYY-MM-DDTHH:mm:ss.SSSZZ （时间戳使用）。
  • 强制设置最小/最大日期。
  • 禁用过去/未来的日期。
  • 使用填写日期预填字段。

默认的最小和最大日期为距当前日期 25 年，但可以通过更改其配置值将其设置为更远的过去或未来。例如，您可以通过将最小日期设置为 1900 年，来允许选择 25 年以前的出生日期。

在日期选择器字段中，日期始终根据用户所在的时区进行选择和显示。但是，当日期值写入支撑电子表格或对象类型时，始终以 UTC 格式写入，以便在不同时区之间保持兼容。

下拉菜单

直方图 下拉菜单 字段以下拉菜单形式显示一组选项。用户可以配置以下选项：

  • 提供一系列可选的 Values 及其显示的 Labels.
  • 在您的终端会话中将 Default values.
  • 允许 多选.
  • 如果只有一个可用值，则预填该字段。
  • 允许创建给定值以外的其他值。
  • 设置 Placeholder.
  • 使用直方图中的 代码编辑器 来设置 noResultsText: string.

地理编码选择器

直方图 地理编码选择器 字段允许填写者输入地址。使用 代码编辑器，用户可以设置 placeholder: string.

地图选择器

直方图 地图选择器 字段允许填写者输入坐标。使用 代码编辑器，用户可以配置以下选项：

  • 在您的终端会话中将 placeholder: string.
  • 在您的终端会话中将 location: [double, double].
  • 在您的终端会话中将 initialZoom: double.
  • 在您的终端会话中将 displayFormat: "latlng" | "mgrs".
  • 在您的终端会话中将 mapboxAccessToken: string.
  • 在您的终端会话中将 mapboxStyles: list<string> (view Mapbox 文档 ↗).

数值

直方图 数值 字段允许填写者输入数字。用户可以配置以下选项：

  • 设置 Default value.
  • 设置 Unit label （例如， kg or lbs).
  • 设置 Placeholder.
  • 显示递增/递减按钮并指定其位置。
  • 使用 代码编辑器:
    • 在您的终端会话中将 clampValueOnBlur: boolean.
    • 在您的终端会话中将 min: double.
    • 在您的终端会话中将 max: double.
    • 在您的终端会话中将 stepSize: double.
    • 在您的终端会话中将 minorStepSize: double.
    • 在您的终端会话中将 majorStepSize: double.

单选按钮

直方图 单选按钮 字段以单选按钮形式显示一组选项。用户可以配置以下选项：

  • 提供一系列可选的 Values 及其显示的 Labels.
  • 设置 Default value.
  • 以水平或垂直方式显示单选按钮。

资源选择器

直方图 资源选择器 字段允许填写者从 Foundry 中选择资源。用户可以指定是否允许填写者选择文件夹、数据集或任何资源类型。

滑块

直方图 滑块 字段允许填写者选择一个数字。用户可以配置以下选项：

  • 强制设置最小/最大值。
  • 设置 Step size and Label step size.
  • 设置 Unit label （例如， kg or lbs).
  • 指定所选值的标记方式。
  • 使用 代码编辑器:
    • 在您的终端会话中将 initialValue: double.
    • 在您的终端会话中将 labelPrecision: double.
    • 在您的终端会话中将 showTrackFill: boolean.

文本

直方图 文本 字段允许填写者输入单行文本。用户可以配置以下选项：

  • 设置 Default value.
  • 设置 Placeholder.

文本区域

直方图 文本区域 字段允许受访者输入多行文本。用户可以配置以下选项：

  • 设置 Default value.
  • 设置 Placeholder.
  • 设置默认和最大行数。

URL

直方图 URL 字段允许受访者输入超链接。用户可以配置以下选项：

  • 设置 Default value.
  • 设置 Placeholder.
  • 当格式无效时显示警告，并自定义显示的消息。
