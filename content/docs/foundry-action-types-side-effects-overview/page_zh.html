副作用

操作类型旨在支持组织内各类决策流程。当本体论作为决策流程的记录系统时，使用规则来定义对象修改，使您能够以极高的灵活性表达业务流程。为了支持各类组织流程，操作类型还支持一些附加功能：

  • 对于实时流程，您可能需要通知用户系统中正在发生的变化，以便他们能够相应地采取操作。
  • 当 Foundry 之外的系统是您组织的事实来源时，您可能需要与其他系统集成以支持现有的业务流程。这种模式有时被称为“决策编排”。

操作类型中的副作用使您能够将数据发送到 Foundry 之外，以便与现有的组织流程集成。副作用主要有两种类型：

  • 通知允许您灵活配置在应用操作时应如何通知用户。这包括向平台上的用户发送电子邮件的功能。
  • Webhook允许您以高度灵活的方式连接到 Foundry 之外的系统，包括向 REST API 或 ERP 系统发送请求。这使您能够写入组织中的其他源系统，或通过与消息系统集成来更灵活地向用户发送通知。
