从预训练文件发布模型

Palantir 支持创建一个封装平台外部生成的权重的模型。这些文件可以包括开源模型权重、在本地开发环境中训练的模型、在 代码工作区 应用中训练的模型，以及来自遗留系统的模型权重。

创建 Palantir 模型后，Palantir 提供以下功能：

  • 与批处理管道和实时模型托管的集成。
  • 完整的版本控制、细粒度权限管理以及受治理的模型血缘。
  • 通过以下方式进行模型管理和实时部署： 《建模目标》.
  • 与本体论绑定，支持通过以下方式进行运营化： 模型上的函数 以及假设情景分析。

从模型文件创建模型

要从模型文件创建模型，您需要准备以下内容：

  • 可上传到 Palantir 的模型文件
  • A 模型适配器 用于告知 Palantir 如何加载模型并使用模型运行推理

1. 将模型文件上传到非结构化数据集

首先，将您的模型文件上传到 Palantir 平台中的非结构化数据集。通过选择以下选项在 Project 中创建新数据集： +New > Dataset 在 Project 中。

然后,选择 导入新数据 然后从您的计算机中选择要上传到模型的文件。

如有需要，您可以将多个不同的文件上传到同一个数据集。该数据集将是非结构化的，即它不会具有表格形式的 schema。

2. 创建模型训练仓库以定义模型适配器逻辑

创建一个新的代码仓库，用于管理从非结构化数据集读取模型文件的逻辑。该逻辑会将这些文件封装在模型适配器中，并将其发布为模型。在 Code Repositories 应用中，选择初始化一个 模型集成 仓库，使用 模型训练 语言模板。

查看完整文档： 模型训练模板 和 模型适配器 API 以供参考。

3. 将权重发布为模型

要将非结构化数据集中的模型文件发布为 Palantir 模型，您必须编写一个完成以下操作的转换：

  1. 从非结构化数据集中将已保存的模型文件加载到合适的 Python 对象中
  2. 使用已加载的 Python 对象实例化模型适配器
  3. 将模型适配器发布为模型资源

您可以将加载和发布模型的逻辑放在仓库中的 model_training 文件夹中。

如需更多信息，我们建议您查阅以下文档：

  • 完整的 模型适配器 API 定义
  • 如何 从非结构化数据集读取文件
  • 如何 使用模型训练模板创建并发布模型适配器
  • An 本地训练模型的封装示例

定义模型训练逻辑后，选择 构建 以执行该逻辑，读取模型文件并发布模型。

from transforms.api import transform, Input
from palantir_models.transforms import ModelOutput, copy_model_to_driver

import palantir_models as pm

import os
import pickle

@transform(
    model_files=Input("<Model Files Dataset>"),
    model_output=ModelOutput("<Your Model Path>")
)
def compute(model_files, model_output):
    # all the files from the dataset are copied onto the driver
    model_files_path = copy_model_to_driver(model_files.filesystem())

    # for example, if you had a model saved as in a pickle file, you would then load that using pickle
    with open(os.path.join(model_files_path, "model.pkl"), 'rb') as file:
        model = pickle.load(file)

    wrapped_model = ExampleModelAdapter(model)
    model_output.publish(
        model_adapter=wrapped_model
    )

class ExampleModelAdapter(pm.ModelAdapter):

    @pm.auto_serialize
    def __init__(self, model):
        self.model = model

    @classmethod
    def api(cls):
        pass  # Implement the API of this model

    def predict(self, df_in):
        pass # Implement the inference logic

相同的文件加载逻辑适用于大多数其他情况，其中库（如 PyTorch 或 TensorFlow）可能提供将序列化文件读取为 Python 对象的方法。
