函数中的插桩与遥测

可以从函数中发出某些类型的遥测数据，以便对生产工作流进行监控和调试。

要了解如何查看函数发出的遥测数据，请参阅我们的 本体论与 AIP 可观测性文档。

支持的遥测类型

下表概述了每种函数语言支持的遥测类型。请注意，对于所有类型的函数，系统都会自动创建一个覆盖函数总执行时长的 span，以及一条请求日志。

语言日志Spans指标
TypeScript v1是仅限产品定义的 span[1]仅限产品定义的指标[2]
TypeScript v2是是[3]仅限产品定义的指标[2]
Python是是[3]仅限产品定义的指标[2]

[1] TypeScript v1 函数中的产品定义 span 包括对象加载和查询执行等操作。

[2] Foundry 会记录所有类型函数的总执行时长。

[3] TypeScript v2 和 Python 函数会自动对所有出站网络请求进行插桩，但也可以添加自定义 span。

日志

您可以从函数发出自定义日志并进行回溯查看。以下示例演示了如何从 TypeScript v1、TypeScript v2 和 Python 函数发出日志。

在 TypeScript v2 函数中，Foundry 会设置 OpenTelemetry SDK 的全局日志记录器提供程序，你将能够从中获取日志记录器。如果你想使用第三方库进行日志记录，则必须对其进行配置，使其通过从全局日志记录器提供程序中获取的日志记录器来输出日志。

import { logs } from "@opentelemetry/api-logs";

const logger = logs.getLogger("my-function");

export default function myFunction(name: string): string {
    logger.emit({
        body: "This is a custom log line.",
        attributes: {
            name
        },
    });

    // You can also use the global console object
    console.log(`This is a custom log line, ${name}.`);

    return `Hello, ${name}!`;
}

import logging

from functions.api import function

logger = logging.getLogger(__name__)

@function
def my_function(name: str) -> str:
    logger.info("This is a custom log line.")
    return f"Hello, {name}!"

日志记录最佳实践

请遵循以下日志记录实践：

  • 选择合适的日志级别： 使用 INFO 记录常规操作， WARN 记录可恢复的问题， ERROR 记录故障，以及 DEBUG 记录详细诊断。
  • 包含相关上下文： 添加标识符、计数和操作详情，以帮助理解执行流程。
  • 避免记录敏感数据： 请勿记录凭据、可能包含敏感信息的完整 API 响应，或其他安全敏感内容。

有关编写有效日志、查看服务日志以及按日志级别筛选的详细指南，请参阅 服务日志与调试。

跨度

你还可以在 TypeScript v2 和 Python 函数中创建自定义跨度，以跟踪特定操作的持续时间。以下示例演示了如何创建自定义跨度。

在 TypeScript v2 和 Python 函数中，Foundry 会设置 OpenTelemetry SDK 的全局 tracer provider，您可以从中获取 tracer。如果您想使用第三方库进行追踪，则必须将其配置为通过从全局 tracer provider 获取的 tracer 来发出 trace。

import { trace } from "@opentelemetry/api";
import { Integer } from "@osdk/functions";

const tracer = trace.getTracer("my-function");

export default function sqrt(n: Integer): Integer {
    const sqrt = tracer.startActiveSpan("my-custom-span", (span) => {
        try {
            return Math.sqrt(n);
        } finally {
            span.end();
        }
    });

    return sqrt;
}

import math

from functions.api import function

from opentelemetry import trace

tracer = trace.get_tracer(__name__)

@function
def sqrt(n: int) -> int:
    with tracer.start_as_current_span("my-custom-span"):
        return math.sqrt(n)
