电子表格显示小组件

电子表格显示小组件会显示对象的 媒体引用 属性中的电子表格文件。

此小组件提供了一种在 Workshop 模块中直接可视化电子表格数据的方式，让用户能够查看电子表格内容并与之交互，例如通过创建注释。

配置选项

电子表格显示： 配置对象类型和媒体引用，并启用可选注释。

  • 包含单个对象的对象集： 一个包含单个对象的对象集，该对象带有媒体引用属性
  • 电子表格媒体引用属性： 一个 媒体引用 属性，其中包含电子表格媒体引用。
  • 电子表格注释： 启用此可选配置以在电子表格上显示注释。

电子表格注释输入： 配置一个或多个注释图层。

  • 注释图层名称： 注释图层的自定义名称。
  • 对象集： 一个包含注释数据的对象集。
  • 工作表名称属性： 一个包含注释所在工作表名称的属性。
  • 单元格范围属性： 一个包含注释单元格范围的属性。该属性可以是 string 或 struct：
    • 一个 string ，采用遵循 {"startRow": 0, "startCol": 0, "endRow": 0, "endCol": 0}的 JSON 格式。
    • 一个 struct ，包含字段 startRow (integer)、 endRow (integer)、 startCol (integer)和 endCol (integer)。
    • 该范围使用零基索引；单元格 A1 等于 (0,0)，且从单元格 A1 到 B2 的范围等于 {"startRow": 0, "startCol":0, "endRow": 1, "endCol": 1}。

现有批注交互： 用于跟踪所选批注的可选配置。

  • 所选批注： 要跟踪的现有批注。
    • 一次只能选择一个批注。当选择发生变化时，预览会定位到所选批注。
    • 如果批注的单元格范围超出工作表边界，预览会跳转到该工作表，但不会跳转到该单元格范围。
    • 如果预览中不存在该工作表名称，则不会执行任何操作。

批注交互： 配置要在小部件中显示的一个或多个操作。

  • 要显示的图标： 操作的自定义图标。
  • 名称： 操作的自定义名称。
  • 对批注执行的操作： 要在批注上执行的操作。
  • 参数默认值：
    • 工作表名称： 当前工作表名称（字符串）。
    • 单元格范围： 所选的单元格范围（字符串）。
  • 其他选项
    • 有效时隐藏表单并立即应用： 启用后，如果配置的操作已包含所有必需信息，则会立即应用该操作，而不是显示表单。
