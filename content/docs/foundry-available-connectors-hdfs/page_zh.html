HDFS

将 Foundry 连接到 Hadoop 分布式文件系统 (HDFS)，以从 HDFS 读取数据并将其同步到 Foundry 数据集。

受支持的功能

功能状态
探索🟢 正式可用
批量导入🟢 正式可用

数据模型

连接器可以将任何类型的文件传输到 Foundry 数据集中。文件格式会被保留，在传输过程中或传输之后不会应用任何 schema。请对输出数据集应用任何必要的 schema，或者 编写下游转换 来访问数据。

性能与限制

可传输的文件大小没有限制。但是，网络问题可能导致大规模传输失败。特别是，运行时间超过两天的直接云同步将被中断。为避免网络问题，我们建议使用较小的文件大小，并限制每次同步执行中摄取的文件数量。同步可以 被安排 频繁运行。

网络

我们建议使用 HDFS scheme ↗ （如果可用），因为它具有更快的 RPC 性能。或者， WebHDFS ↗ 是一个 HTTP REST API，支持 HDFS 的完整 FileSystem 接口。一些示例如下：

  • hdfs://myhost.example.com:1234/path/to/root/directory
  • webhdfs://example.com/path
  • swebhdfs://example.com/path

所需的网络端口因所选 scheme 而异。对于 HDFS scheme，这些端口通常是 NameNode 服务器上的 8020/9000，以及 DataNode 上的 1019、50010 和 50020。对于 WebHDFS scheme，所需端口通常为 9820。

证书和私钥

SSL 连接会验证服务器证书。通常，SSL 验证通过证书链进行；默认情况下，代理和 Foundry worker 都信任大多数行业标准证书链。如果您连接的服务器使用自签名证书，或者在验证过程中存在 TLS 拦截，则连接器必须信任该证书。了解更多关于 在 Data Connection 中使用证书.

从 HDFS 同步数据

访问 Explore 选项卡，以交互方式浏览已配置的 HDFS 实例中可用的数据。选择 New Sync 以定期将数据从 HDFS 拉取到 Foundry 中的指定数据集。

增量导出

对于增量导出，请设置 incrementalType to incremental。首次导出将导出所有文件，随后的导出将仅包含新的事务（前提是前一个事务仍存在于数据集中）。

type: export-hdfs-task
directoryPath: /exports/incremental/
incrementalType: incremental

连接重试

如果您遇到与 HDFS 集群的连接问题，可以为每个文件配置重试次数。设置 retriesPerFile: 1 将尝试导出每个文件两次（一次初始尝试加一次重试）。
