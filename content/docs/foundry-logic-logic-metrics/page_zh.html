AIP Logic 指标

AIP Logic 资源由函数支撑。当 AIP Logic 资源执行时，系统会显示底层函数执行的相关指标，包括成功和失败次数以及过去 30 天内的 P95 执行时长。

您可以在 本体论管理器 或 工作流血缘中查看这些指标。在工作流血缘中，选择特定执行对应的 AIP Logic 节点。由此可以查看以下信息：

  • 成功/失败指标： 监控您的 AIP Logic 执行的当前状态，包括底层函数的成功和失败计数。

  • P95 时长指标： 跟踪第 95 百分位数 (P95) 执行时长，帮助您检测性能瓶颈并优化工作流。

您还可以访问 运行历史，其中提供了过去七天执行情况的完整视图。深入了解 AIP 可观测性。

所有指标均使用来自 Foundry 遥测服务 (FTS) 的最新数据进行近实时更新。这可确保您能够获取最新信息，用于监控、调试和维护 AIP Logic 资源的健康状况。

AIP Logic 执行的失败类型遵循与 函数失败类型相同的类别。请参阅 函数指标 文档，以获取完整的失败类别列表。

权限

要查看 AIP Logic 指标，您必须是 viewer 在 AIP Logic 资源上。
