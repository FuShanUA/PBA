Logic 函数的评估套件

Logic 预览 面板非常适合一次性测试，但为了对您的 Logic 函数更有信心，针对多种输入进行测试非常重要。

本教程将带您使用 AIP Evals 为一个简单的 Logic 函数创建评估套件。

从 Logic 创建评估套件

在本示例中，我们有一个 Logic 函数，它以餐厅评论作为输入，并根据评论的情感将其分类为正面或负面。我们希望创建包含评论输入和预期情感输出的测试用例来验证我们的函数。

保存 Logic 函数后，有几种创建评估套件的选项：

  • 在 预览 面板中，您可以通过选择 添加为测试用例.
  • 在 Evals 面板中，您可以选择 手动设置测试 来创建一个空的评估套件，或选择 使用 AI FDE 生成 以 AI FDE 为您生成测试用例和评估器。AI FDE 将在新标签页中打开，并以您的 Logic 函数作为上下文。

创建或生成评估套件后，您可以通过选择 编辑测试 在 AIP Evals 面板中添加或修改测试用例。这将打开测试用例编辑器，您可以在其中为每个测试用例配置输入并保存评估套件。

当您选择 添加为测试用例 菜单中选择 预览 面板时，AIP 将尝试根据输入参数为您的测试用例提供一个描述性名称。您也可以选择测试用例名称旁边的紫色 AIP 星形图标来生成建议的名称。

添加测试用例后，您可以通过选择 运行评估套件 菜单中选择 Evals 面板来运行评估套件。这将运行套件中的所有测试用例。套件运行完成后，通过选择 最近一次运行 区域的字段中添加命令。

如果您是从 手动设置测试 菜单中选择 Evals 面板或 添加为测试用例 菜单中选择 预览 面板创建的评估套件，AIP Evals 将输出函数的返回值，但不会提供汇总的性能指标。要扩展您的评估套件，请添加一个 评估器 来将 Logic 函数生成的输出与预期值进行比较并计算汇总指标。在本示例中，使用内置的 精确字符串匹配 评估器。实际上，根据函数的性质，您可能需要使用其他评估器或编写自定义评估器。

要添加评估器，请选择 + 添加 在测试用例配置标题栏中，然后选择 Exact string match > Add。这将添加评估器并打开评估器编辑器，您可以在其中将评估器输入映射到函数输出和测试用例列。在本例中，将函数输出映射到实际值，并为预期值创建一个新参数。这将在测试用例编辑器中添加一个新列，您可以在其中为每个测试用例输入预期的情感。

您可以为每个指标配置目标。对于布尔指标，请选择 true or false 值是否被视为通过的结果。对于数值指标，请选择值越高越好还是越低越好，并根据需要设置阈值。评估套件将根据这些目标自动确定每个测试用例的 passed or failed 状态。

保存后，您可以再次运行评估套件，以查看函数的汇总指标以及基于您配置的目标的每个测试用例的 passed or failed 结果。

您不必在每次修改函数后都运行整个套件。您可以通过选择侧边栏中测试用例旁边的播放图标来运行单个测试用例。这对于调试和快速迭代您的函数非常有用。
