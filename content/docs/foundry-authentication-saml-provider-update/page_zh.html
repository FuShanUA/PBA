在控制面板中更新 SAML 提供商

从一个 SAML 身份提供商迁移到另一个身份提供商，所需的工作流程超出了在控制面板中创建和禁用 SAML 提供商的范围。您需要完成就地 SAML 提供商更新流程或外部到外部 SAML 提供商更新流程。当用户使用新的 SAML 提供商登录 Foundry 时，Foundry 会为他们配置一个新的重复用户账户。来自新提供商的群组也会被复制。未正确执行提供商更新可能导致的部分后果包括：

  • 用户将失去对其先前主文件夹的访问权限，因为他们将获得一个新的主文件夹。
  • 用户将失去对与其共享的所有内容的访问权限，无论是直接共享还是通过来自先前提供商的群组共享。
  • 共享对话框中将出现重复的用户和群组，这可能会造成混淆。

为防止出现上述问题，在切换到使用新提供商之前，必须将用户从旧 SAML 提供商迁移到新 SAML 提供商。有两种方案可供选择：

就地 SAML 提供商更新

这是最简单的选项，仅当当前身份提供程序和目标身份提供程序共享相同的属性时才应采用。特别是，ID 属性映射到的值 不得更改 否则用户将在 Foundry 中获得一个全新的预配账户。

如果新身份提供程序中传入的用户或组的 ID 属性与现有 ID 属性不同，请按照外部到外部 SAML 提供程序更新流程操作。

请按照以下步骤执行就地 SAML 提供程序更新：

  1. 在 Control Panel 中，导航到 身份验证 选项卡（位于 注册设置下）。找到您想要更新的 SAML 提供程序，然后点击 操作 下拉菜单并选择 管理。

    在 SAML 部分中，选择 管理。

  2. 下载 SAML 集成元数据 XML。在身份提供程序端更新您的 SAML 应用程序。

  3. 在 身份提供程序元数据下，将新的身份提供程序联合元数据文件上传到 Control Panel。

  4. 测试 新集成是否按预期工作，并确认用户属性未发生变化，且不会为用户在 Foundry 中预配新的账户。

外部到外部 SAML 提供程序更新

请按照以下步骤执行外部到外部 SAML 提供程序更新：

  1. 在 Control Panel 中，导航到 身份验证 选项卡（位于 注册设置。在 身份验证提供商下，选择 添加提供商 并添加新的提供商。

    了解有关 配置 SAML 2.0 集成 以添加新 SAML 提供商的更多信息。

  2. 测试 新的 SAML 集成（使用测试账户）。

  3. 暂时禁用该集成，以避免同时启用重复的提供商。

  4. 请联系您的 Palantir 代表，帮助将用户从旧提供商迁移到新提供商。
