获取选项

Java OSDK 使用 FetchRequest 用于单对象和流式选项，以及 FetchPageRequest 用于手动分页选项。

。部分设置也可以在源级别进行配置。支持的方法描述
FetchRequest.includeRids()fetch(), fetchStream()包含对象的 RID。默认值为 false.
FetchRequest.loadPropertySecurityMetadata()fetch(), fetchStream()包含属性级别的安全元数据。默认值为 false.
FetchRequest.includeAllBaseObjectProperties()界面 fetchStream()读取接口对象集时，包含底层具体对象类型的所有属性。此设置对对象类型查询没有影响。
FetchPageRequest.pageSize()fetchPage()设置页面中请求的对象数量。默认值为 1,000.
FetchPageRequest.pageToken()fetchPage()通过传入上一页的页面令牌来加载下一页 Page.
FetchPageRequest.includeRids()fetchPage()包含每个对象的 RID。默认值为 false.
FetchPageRequest.loadPropertySecurityMetadata()fetchPage()包含属性级别的安全元数据。默认值为 false.

例如，以下请求在加载一个对象时包含 RID 和属性安全元数据：

聚合

聚合允许您对一组数据计算汇总统计信息。它们有助于从大型数据集中理解模式和洞察，而无需手动分析每个单独的数据点。您可以组合多个聚合操作来创建更复杂的查询，从而更深入地洞察数据。

此端点利用了该对象类型所使用的基础对象同步技术。如果 Restaurant 由 Object Storage v2 支撑，则没有请求限制。如果 Restaurant 由 Object Storage v1 (Phonograph) 支撑，则有 10,000 条结果的限制；如果请求超过 10,000 个 Restaurants ，将抛出 ObjectsExceededLimit 错误。

对 Restaurants.

  • where Filter （可选）：对特定属性进行过滤。可用的操作取决于属性的类型。

public interface Media {

    /**
     * Get the identifier for the media reference.
     */
    MediaReferenceId getId();

    /**
     * Fetch an object's media reference property metadata.

}
