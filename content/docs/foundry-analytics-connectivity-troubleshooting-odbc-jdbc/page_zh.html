配置 ODBC 和 JDBC 驱动程序时的问题排查

"ODBC ERROR [IM003] Specified driver could not be loaded"

问题

在 Windows 上尝试使用 ODBC 驱动程序时出现以下错误：

ODBC: ERROR [IM003] Specified driver could not be loaded due to system error 126: The specified module could not be found. (FoundrySqlDriver, C:\Program Files\Palantir\Foundry ODBC Driver\bin64\<ModuleName>.dll)

解决方案

请确保您已安装最新的 Microsoft Visual C++ Redistributable ↗ 到主机上。

"FoundrySqlServer:InvalidDatasetCannotAccess"

问题

使用 Palantir Foundry 的 ODBC 驱动程序、JDBC 驱动程序或 BI 工具连接器运行 SQL 查询时出现以下错误：

FoundrySqlServer:InvalidDatasetCannotAccess

解决方案

查询中引用的数据集无法访问，原因可能是该数据集或分支不存在，或者 ODBC 连接中配置的用户账户没有查看该数据集的权限。另一个错误， FoundrySqlServer:NotAuthorizedToReadInputs，表示查询输入的权限验证失败，而不是数据集无法访问。

请采取以下任一操作来验证对查询中引用数据集的访问权限：

  • 使用相关用户账户登录 Foundry，导航到相关数据集，并确保可以按预期访问数据。
  • 具有足够权限的人员可以按照 权限检查指南 中的说明，代表相关账户验证访问权限。

"FoundrySqlServer:TooManyRows"

问题

使用 Palantir Foundry 的 ODBC 驱动程序、JDBC 驱动程序或 BI 工具连接器运行 SQL 查询时出现以下错误：

FoundrySqlServer:TooManyRows

解决方案

出于性能原因，某些 SQL 查询会受到行数限制。请查阅 Foundry SQL Server 执行引擎 的文档，了解这些限制以及如何定义避免触发限制的查询。

使用自定义 SSL 证书时的连接错误

问题

尝试使用 JDBC 或 ODBC 驱动程序连接到 Foundry 时，您可能会遇到错误消息，指出驱动程序无法与 Foundry 建立安全连接。错误消息可能如下所示：

Dialogue transport failure; PKIX path building failed: sun.security.provider.certpath.SunCertPathBuilderException: unable to find valid certification path to requested target

此错误表示驱动程序在连接到您的 Foundry URL 时，无法验证服务器的 SSL 证书是否由受信任的证书颁发机构 (CA) 签名。这可能是因为您的操作系统信任库中不包含该 CA，或者驱动程序无法访问操作系统信任库。

您可能在以下场景中遇到自定义 CA 和证书：

  • 您的 Foundry URL 使用的是您组织的域名，而不是 Palantir 提供的域名（例如， foundry.[your-organization].com 而非 [your-organization].palantirfoundry.com).
  • 您的组织网络配置了 TLS 解密/检查，这会导致驱动程序看到的证书与 Foundry 最初提供的证书不同。

解决方案

请使用以下任一方法，确保驱动程序能够访问您组织使用的自定义证书链。

方法 1：将自定义证书链加载到操作系统信任库中

默认情况下，驱动程序在验证 SSL 证书时使用操作系统的默认信任库。请联系您组织的 IT 支持，了解是否可以将您组织的自定义证书链添加到其中。如果可以，驱动程序将能够验证与 Foundry 的连接，无需任何额外配置。

方法 2：以 PEM 格式手动提供自定义证书链

如果您的组织无法将自定义证书链加载到操作系统的默认信任库中，您可以手动向驱动程序提供证书链。为此，请获取 PEM 格式的证书链，并使用 TrustStorePath 连接参数 指定该文件的路径（适用于 JDBC 或 ODBC 驱动程序）：

  1. 从受信任的连接获取证书链。 例如，如果您已经可以在 Google Chrome 中访问 Foundry，请按照以下说明以 PEM 格式导出证书链。如果您使用其他浏览器，请参阅该浏览器的文档以获取导出证书链的说明。

    1. 打开 Google Chrome，并在新标签页中打开您的 Foundry URL。
    2. 点击地址栏中的挂锁图标，选择 连接是安全的，然后选择 证书有效.

    如果 Chrome 报告连接不安全和/或证书无效，则可能存在另一个问题，导致您的计算机与 Foundry 之间的所有连接出现证书信任错误。请咨询您组织的 IT 支持和 Palantir 支持以获取帮助。

    1. 选择 详情 tab.
    2. 选择 导出....
    3. 选择 Base64 编码的 ASCII 证书链 作为导出格式，并选择保存证书文件的位置。选择 保存.

  2. 通过指定以下内容将驱动程序配置为使用证书链 TrustStorePath 连接参数。 该属性的值应为上一步中导出文件的完整路径。请参阅 ODBC 和 JDBC 驱动程序：连接参数 以了解如何指定连接参数。
