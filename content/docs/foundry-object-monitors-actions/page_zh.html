操作

对象监视器已被 Automate取代。Automate 是一款完全向后兼容的产品，可为平台中的所有业务自动化提供统一的入口。

操作 可在对象监视器触发或恢复时自动运行。

配置操作

订阅者可以将操作配置为在出现新的 监视器已触发 活动事件时运行。评估完成后，监视器会立即自动提交该操作。如果多个用户配置了操作，则会为每个用户分别运行这些操作。

受影响的对象

对于事件条件，监视器检测到的对象集可以作为对象集参数传递给操作。在 操作 标签页（位于 监视器配置 页面）中，应将该参数配置为接受一个 ObjectSet<> （对象类型与被监视的对象相同）。此时，系统将显示一个选项，供用户选择以提供该对象集。

此对象集不能用作操作通知的输入；只有配置了操作效果的用户才能访问该次监视器执行所对应的受影响对象集。

操作可见性设置

并非所有操作都适合与对象监控器配合使用。在本体论管理器中配置操作类型后，您便可以禁止相应操作出现在对象监控中。创建操作类型后，从 操作类型 列表中点击相应的操作类型即可查看其详情，然后点击左侧面板中的 安全与提交条件 标签页。接着，找到 前端消费者 部分，然后关闭“允许对象监控器提交此操作”的开关。

权限

操作与订阅该监控器的特定用户相关联。这意味着，配置操作的订阅者必须满足该操作的 提交条件 。

不能代表其他订阅者配置操作。

由于操作是代表特定用户运行的，因此如果该用户取消订阅，或者该用户的账户被禁用或删除，操作将不再运行。
