在工作区应用程序中，如何添加诸如 dash-core-components 和 plotly之类的依赖项？

使用托管的 Conda/PyPi 环境时，您 JupyterLab® 代码工作区中的依赖项会自动在您已发布的应用程序中可用。请查看 托管的 Conda/PyPi 环境 以了解更多信息。

通过位于您仓库根目录的 environment.yml 文件为应用程序添加依赖项的做法现已 弃用。请迁移至 托管的 Conda/PyPi 环境。启用此功能后重启工作区时，我们将尝试自动迁移您的 environment.yml 文件。

时间戳： 2024年9月24日

为什么 Jupyter® 笔记本会在两次工作区重启之间消失，以及如何防止此问题？

如果在重启前未同步更改，或者在从检查点恢复时出现失败，Jupyter® 笔记本可能会在两次工作区重启之间消失。可以通过确保定期同步更改，并通过工作区日志验证检查点的上传来防止此问题。此外，需要注意的是，检查点会在 30 天后被删除，因此定期同步对于避免丢失工作成果至关重要。
