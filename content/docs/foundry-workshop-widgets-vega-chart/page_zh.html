数据配置

Vega 图表小部件有三种不同的配置选项，允许你灵活地将对象数据从你的本体论（Ontology）转换为预期的 Vega 和 Vega-Lite 格式，然后将其注入到你的 JSON 规范中。

  • 导入对象集： 指定应包含在数据中的对象集及其属性。



  • 聚合： 指定对象集，按带有分桶策略的属性进行分组，并进行聚合。每个数据点将包含每个分组属性的值，以及以指定的聚合名称为键的聚合值。



  • 函数： 指定一个返回结构体列表的函数，该列表将直接用作数据。

直方图 Long 类型在两个 TypeScript 版本中的含义不同。在 TypeScript v1 中， Long 别名 number；在 TypeScript v2 中， Long 别名 string。一个 marketCap 字段的类型为 Long 因此在 TypeScript v2 中会以字符串形式传递到图表。任何声明该字段的 Vega 或 Vega-Lite 编码 quantitative 可能无法按预期绘制。请使用 Double 当图表轴上的值必须为数值时，因为 Double, Integer日 Float 别名 number 在两个 TypeScript 版本中均适用。 Long 是从 @foundry/functions-api 在 TypeScript v1 中导入，而在 @osdk/functions 在 TypeScript v2 中导入。在 Python 中， Long 来自 functions.api 并对应于 int，因此此差异不适用；请使用 Long 别名而不是裸的 int来标注该字段，后者会被识别为 Integer.

Vega 与 Vega-Lite

该小部件允许您指定是使用 Vega-Lite 还是 Vega 来进行您的规范。

如果您要制作常见的图表，我们建议使用 Vega-Lite，因为它更简洁的语法以及对 选择参数的支持。对于更复杂的可视化效果，您可以使用 Vega。查看 语法创建完全可自定义的交互式可视化效果。 和 和 示例，以了解两者都能支持的功能。该小部件使用 Vega-Lite 5.18.

主题配置

为了便于重用，您可以配置一个主题，该主题将被注入到规范中。默认主题与XY图表小部件的Blueprint样式相匹配，但您也可以从字符串变量中指定自己的自定义主题，或者完全关闭主题。

有关构建自定义主题的示例，请参阅 vega-themes 仓库 ↗ 如果您想修改我们的默认 Blueprint 主题，可以在

选择参数（仅限 Vega-Lite）

Workshop 推荐使用 Vega-Lite 模式的首要原因是 Vega-Lite 支持 选择参数 ↗. 在 Vega 图表小部件中，您可以配置多个选择参数，每个参数都有一个名称和一个输出变量。输出变量可以是对象集过滤器或字符串。

由于选择可以在规范的多个不同位置进行指定，因此此配置不会自动注入到规范中。作为构建者，您需要负责为每个配置的参数名称在规范中包含一个选择参数。
