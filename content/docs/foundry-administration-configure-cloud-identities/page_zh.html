配置云身份

云身份允许您在不使用静态凭证的情况下对云提供商资源进行身份验证。

直方图 云身份 控制面板中的页面仅在满足以下条件时才会显示：

  • 您的 Foundry 注册托管在 AWS 中。
  • 您的 Foundry 注册运行在 Rubix（Palantir 基于 Kubernetes 的基础设施）上。

云身份身份验证允许 Foundry 访问您云提供商中的资源，包括 Amazon AWS、Microsoft Azure 或 Google Cloud Platform。云身份在 注册 级别在控制面板中进行配置和管理，并应在设置单个源连接时导入到 数据连接.

必须授予 Foundry 生成的云身份对目标云平台中资源的访问权限。在可用的情况下，建议使用云身份而非基于静态凭证的身份验证。

适用于 AWS 的云身份

要访问 AWS 资源，云身份表示在托管您 Foundry 注册的 AWS 账户中生成的 AWS Identity and Access Management (IAM) 角色。

自 2024 年 4 月起，您可以在控制面板中为每个注册创建最多 15 个云身份。如果您需要更多云身份，请提交支持工单以讨论您的注册可能可用的选项。

为您的注册启用 AWS 云身份

要为您的注册生成云身份，请导航至 Enrollment Settings > Cloud Identities （位于控制面板侧边栏中）。访问此页面需要 Manage cloud identity configuration 工作流，该工作流被授予给 Enrollment administrator 和 Information security officer 角色。

选择 创建身份 以生成云身份和关联的 IAM 角色。该角色的 Amazon Resource Number (ARN) ↗ 将会显示。

云身份一旦创建便无法删除，且其名称无法编辑。使用多个云身份的用户应注意需要新云身份的原因。

要使云身份的 IAM 角色能够进行身份验证并访问资源，您必须在 AWS 账户中创建一个单独的 IAM 角色并创建两个策略。

策略 1： 您必须创建一个信任策略，允许云身份的 IAM 角色担任在您 AWS 账户中创建的 IAM 角色。

启用后， 云身份 凭据选项将可用于在 Foundry 中与您的 S3 源配合使用，位置在 连接详情 页面（位于 Data Connection 中）。

使用云身份验证时，角色 ARN 将显示在凭据部分。选择 云身份 选项后，将预先选择一个默认云身份。如果您的租户上存在多个云身份，下拉菜单将允许您从列表中选择一个。选择云身份后，您还必须配置以下内容：

  1. 在目标 Amazon AWS 账户中配置一个 Identity and Access Management (IAM) 角色。
  2. 授予 IAM 角色对您希望连接的 S3 存储桶的访问权限。通常，您可以通过 存储桶策略 ↗.
  3. 来实现。在 S3 源配置详情中，在以下位置添加 IAM 角色： Security Token Service (STS) 角色 ↗ 配置。Foundry 中的云身份 IAM 角色将尝试 在访问 S3 时代入 AWS 账户 IAM 角色 ↗.
  4. 配置相应的信任策略 ↗ ，以允许云身份 IAM 角色代入目标 AWS 账户的 IAM 角色。
