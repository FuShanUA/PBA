配置云身份

云身份允许您在不使用静态凭证的情况下向云提供商资源进行身份验证。

仅当满足以下条件时，Control Panel 中的云身份页面才会显示：

  • 您的 Foundry 注册托管在 AWS 中。
  • 您的 Foundry 注册运行在 Rubix（Palantir 基于 Kubernetes 的基础设施）上。

云身份验证允许 Foundry 访问您云提供商中的资源，包括 Amazon AWS、Microsoft Azure 或 Google Cloud Platform。云身份在 Control Panel 的注册级别进行配置和管理，并应在 Data Connection 中设置单个源连接时导入。

必须为 Foundry 生成的云身份授予对目标云平台资源的访问权限。在可用的情况下，建议使用云身份而非基于静态凭证的身份验证。

适用于 AWS 的云身份

为了访问 AWS 资源，云身份代表在托管您 Foundry 注册的 AWS 账户中生成的 AWS Identity and Access Management (IAM) 角色。

截至2024年4月，您可以在 Control Panel 中为每个注册创建最多15个云身份。如果您需要额外的云身份，请提交支持工单，以讨论可能适用于您的注册的选项。

为您的注册启用 AWS 云身份

要为您的注册生成云身份，请导航至 Control Panel 侧边栏中的注册设置 > 云身份。访问此页面需要 Manage cloud identity configuration 工作流，该工作流已授予给 Enrollment administrator 和 Information security officer 角色。

选择创建身份以生成云身份及关联的 IAM 角色。该角色的Amazon 资源编号（ARN）↗将会显示。

云身份一经创建便无法删除，且其名称无法编辑。使用多个云身份的用户应注意需要创建新云身份的原因。

要使云身份的 IAM 角色能够进行身份验证并访问资源，您必须在您的 AWS 账户中创建一个单独的 IAM 角色并创建两个策略。

策略 1：您必须创建一个信任策略，允许云身份的 IAM 角色担任在您的 AWS 账户中创建的 IAM 角色。

除这些策略之外，Foundry 与您的 AWS 账户之间的直接连接还需要进行网络配置。请在您的 AWS 网络上将必要的 Foundry Rubix IP 加入允许列表，并验证相关的出口策略已添加到您的 Foundry 注册中。您可以在 Control Panel 的网络出口选项下找到您注册对应的 Foundry Rubix IP，并设置必要的出口策略。

如果您的 S3 存储桶与您的 Foundry 实例托管在同一区域，则您必须使用单独的流程来允许对这些存储桶的出口访问；来自 Foundry Rubix 的网络流量将改为来自用于连接 S3 的 Amazon VPCE。VPCE 标识符可在 Control Panel 的网络出口部分的S3 存储桶策略选项卡下获取。根据 S3 源的配置方式，VPCE 标识符也可以通过 Data Connection 应用程序公开。了解更多关于连接同区域 S3 存储桶的信息。

在配置 S3 源时使用云身份

启用后，在 Data Connection 的连接详情页面上，云身份凭据选项即可用于您在 Foundry 中的 S3 源。

使用云身份进行身份验证时，角色 ARN 将显示在凭据部分。选择云身份选项后，将预先选择一个默认云身份。如果您的注册中存在多个云身份，则可以通过下拉菜单从列表中选择一个。选择云身份后，您还必须配置以下内容：

  1. 在目标 Amazon AWS 账户中配置 Identity and Access Management (IAM) 角色。
  2. 授予 IAM 角色访问您希望连接到的 S3 存储桶的权限。通常，您可以通过存储桶策略 ↗来实现。
  3. 在 S3 源配置详细信息中，在安全令牌服务 (STS) 角色 ↗配置下添加 IAM 角色。Foundry 中的云身份 IAM 角色将尝试在访问 S3 时担任 AWS 账户 IAM 角色 ↗。
  4. 配置相应的信任策略 ↗，以允许云身份 IAM 角色担任目标 AWS 账户 IAM 角色。
