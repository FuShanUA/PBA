管理组织和空间

组织

组织权限应通过 控制面板进行管理。进一步的组织配置则在 Foundry 设置选项卡中进行管理。

组织权限

组织各自拥有一组权限，用于控制用户如何与资源上的组织访问要求进行交互。这些权限在 控制面板中进行管理。

标记权限

组织使用两项权限来控制用户如何修改资源上的组织访问要求：

  • 应用组织： 允许用户将此组织添加到资源。拥有此权限的用户可以将该组织作为访问要求应用于资源、文件夹或项目。
  • 扩展访问： 允许用户通过添加其他组织或移除此组织来扩展对资源的访问。如果用户需要通过修改资源上的组织访问要求来扩大可访问该资源的受众范围，则需要此权限。

有关这些术语的更多信息，请参阅 安全术语表。

常见错误：缺少“扩展访问”权限

如果用户在尝试将资源移动到其他组织或从资源中移除组织后收到错误提示，指出其缺少 “扩展访问” 权限，则管理员必须授予该用户 “扩展访问”权限 源组织的权限可在 控制面板 中查看，方法是导航至 组织权限 > 标记权限。

主文件夹与组织

启用 Foundry 主文件夹后，系统会自动使用用户所属的组织对其进行标记。

Beta

禁用主文件夹的配置选项正处于开发的 beta 阶段，在您的环境中可能无法使用。功能在积极开发期间可能会发生变化。请联系 Palantir 支持团队，申请获取此功能的访问权限。

空间

空间 已更名，先前的名称为 命名空间。

空间设置在 控制面板 中的 空间管理 页面（位于环境设置中）上进行管理。

创建空间

在 空间管理 页面上，选择 + 创建空间。

在创建空间的过程中，系统会要求您指定以下设置：

  • 访问要求： 用户需要获得至少一个组织的权限才能访问此空间。此空间中的项目仅对此列表中的组织可见。
  • 删除策略： 定义空间及其项目的删除时间。只有在此策略中的所有组织均被删除后，该空间才会被删除。
  • 文件系统： 项目数据的存储位置。创建后无法更改。
  • 使用量账户： 跟踪资源使用成本。为此空间中的项目设置默认结算账户。可按项目进行覆盖。
  • 资源队列： 项目获取计算资源的来源。此空间中的所有项目均使用此队列。
  • 角色集： 控制哪些角色可供项目使用。默认为 Project defaults，但您也可以使用 自定义角色集 来替代。

如果您是注册管理员但无法创建新空间，可能是因为您的注册不符合要求或已达到配额限制；请联系 Palantir 支持团队了解更多信息。

管理空间

从 操作 下拉菜单中，您可以 管理 空间的设置。除上述设置外，您还可以配置：

  • Maven 标识符： 唯一标识从此空间发布的资源。
  • 项目继承角色： 空间内所有项目继承的角色。这些角色授权会显示在此空间中项目的 Compass 侧面板中。共有两个继承角色授权选择器，一个用于常规项目，一个用于锁定的 Marketplace 项目。

从 空间权限 页面，您可以设置用户在空间中拥有的角色。每个空间都自带一组默认角色，并支持创建自定义角色，以便在管理权限时拥有更大的灵活性。对于每个角色，您可以打开工作流下拉菜单，查看该角色所授予的权限。选择某个角色后，右侧面板中会显示该角色的授权情况，您可以在其中添加或移除用户。

要创建自定义角色，请选择 + 新建角色 （位于页面右上角），然后选择要包含在此角色中的工作流。创建自定义角色后，您可以按照授予其他角色的相同方式将该角色授予用户。自定义角色可通过 操作 菜单（位于每个自定义角色右上角）进行编辑或删除。

自定义角色是“冻结”的，这意味着添加到默认角色的新工作流不会自动应用于自定义角色。要在自定义角色中包含新的工作流，请选择 编辑角色 并手动添加它们。

旧版空间可能提供额外的配置设置。以下是这些设置的说明：

  • 角色： 用户必须在相应空间中拥有角色并满足其访问要求，才能创建项目或管理空间设置。
  • 文件夹和文件上的角色授予： 启用后，默认情况下可以在新项目中的文件夹和文件上为用户分配角色。此设置仅在创建新项目时初始化此行为，并不会对现有项目强制执行此行为。详细了解如何禁用 文件夹和文件上的角色授予。
