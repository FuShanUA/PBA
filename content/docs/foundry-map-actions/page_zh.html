操作

使用 操作 功能，在 Map 应用程序中根据地图上绘制的点、多边形或线来创建或编辑对象。

针对形状和点的操作

当你在地图上右键单击时，菜单中的 操作 条目会显示适用于地理空间点的所有操作，如下所示。

在你 绘制形状之后， 工具栏中的“操作”按钮会显示适用于你所绘制的多边形、线或点的所有操作：

从其中一个菜单中选择操作后，可能需要你提供额外参数。在这种情况下，Map 会显示一个对话框，供你输入这些额外参数：

如果没有额外参数，或者在你提交对话框中的表单后，Map 应用程序会执行该操作，并将该操作创建的所有地理空间对象添加到你的地图中。

针对本体论对象的操作

使用 操作 按钮，该按钮位于 Selection 面板中，可对所选对象执行地理空间操作。选择操作后，系统会提示你编辑或创建形状，具体取决于该操作中指定的配置。

当你单击 “完成” 在形状绘制或编辑工具上，可能存在您需要提供的其他参数。在这种情况下，Map 会显示一个对话框，供您输入这些额外参数：

如果没有额外参数，或者在您提交对话框中的表单后，Map 应用程序将执行该操作，并更新您的地图以反映该操作所创建或修改的任何对象。
