入门

本教程介绍如何创建由本体论编辑函数支撑的操作类型。

前提条件

在本教程中，我们将使用与操作入门教程中相同的 Demo Ticket 对象类型和示例对象。

首先，编写一个本体论编辑函数来为您的操作执行所需的编辑。这需要：

  • 使用对象上的函数 TypeScript 模板设置仓库，
  • 将相关对象类型导入到您的仓库中，以及
  • 发布本体论编辑函数供操作读取。

有关这些步骤的信息可以在函数文档中找到：

  • 入门：按照本教程创建基本的函数仓库并发布函数。
  • 对象上的函数：按照本教程创建使用对象数据的函数。
  • 本体论编辑：使用此参考创建本体论编辑函数。

自动升级

您可以选择为操作引用的函数启用自动升级。启用后，操作将依赖函数的某个版本范围，并在运行时解析版本。

要为操作启用自动升级，请导航到操作的规则部分并选择函数参数。在函数下拉列表中，选择您希望运行的函数的最低版本，并启用自动升级选项。这将对应于一个版本范围依赖项，其中包含所选最低版本的所有向后兼容版本，例如次要版本或补丁版本升级。

对于格式为 0.y.z 的函数版本，自动升级处于禁用状态。这些版本保留用于初始开发阶段，在此阶段函数 API 和行为可能会频繁变化，不应视为稳定版本。请参阅有关选择发布版本的文档。

安全性

如果为函数支撑的操作启用了自动升级，则没有该操作的编辑权限的用户可以通过更改支撑函数来修改操作的行为。这是因为函数的编辑权限与操作的权限没有绑定。

破坏性变更

自动升级可能由于有问题的函数发布版本中的破坏性变更而导致操作执行失败。

溯源

操作的溯源是根据所选最低函数版本的溯源设置的。如果较新的函数发布版本返回的编辑超出了此溯源范围（例如，额外的对象类型），操作执行将失败。

目前，溯源仅由操作在运行时可以编辑的对象类型组成。
