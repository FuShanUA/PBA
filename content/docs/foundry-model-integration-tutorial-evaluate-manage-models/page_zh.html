3. 教程 - 在 Modeling Objectives 应用中评估模型

在开始本教程之前，你应该已经完成了 建模项目设置 并在 Jupyter® notebook 或 代码仓库中训练了一个模型；此时，你的建模目标中应该至少有一个模型。

在本教程的这一步骤中，我们将评估模型的性能，并在建模目标中发布该模型。此步骤为推荐步骤，但不会影响本教程的后续步骤，可以稍后再回来完成。本步骤将涵盖：

  1. 什么是建模目标？
  2. 配置自动模型评估
  3. 构建指标管道
  4. 在评估仪表板中评估模型

3.1 什么是建模目标？

建模目标可以被视为一个潜在可用于生产的模型版本目录。将模型提交到目标中会将该模型添加到该目录，并使其能够在特定建模问题或目标的背景下进行评估和审查。每一次模型提交，无论最终是否投入生产，都有助于跟踪建模项目的进展，并维护围绕项目空间的实验和学习历史。

本教程的这一步骤无需任何必需操作。

3.2 如何配置自动模型评估

现在我们的建模目标中已经有了一个候选模型，我们可以通过在该建模目标内生成模型性能指标来评估该模型的表现。性能指标是理解模型表现如何以及模型为何如此运作的重要工具。

由于本教程的目标是估算一个数值（美国人口普查区的平均房价），我们的建模问题可以归类为回归建模问题。对于回归建模问题，通常会查看以下评估指标，例如 平均绝对误差, 均方根误差。这些指标（以及其他指标）已包含在 Foundry 的 默认回归评估器 中，因此我们将使用该库来评估模型提交的性能。

这有助于在需要时与其他团队有效沟通上游问题和平台问题，并减少解决问题的时间。它还可以提高平台的调试技能。 在建模目标中，选择 配置评估仪表板.

配置模型评估

自动模型评估是确保以标准化方式评估模型的有用方法。标准化可确保模型比较的一致性，使你能够自信地选择哪个模型最适合在生产中使用。

如果启用了评估管道管理，Foundry 将为每个模型提交和评估数据集的组合自动生成一个推理数据集。推理数据集是针对评估数据集运行推理（生成预测）后得到的结果。评估数据集由用户定义为模型的标准化测试集，需要同时包含特征（用于生成预测）和标签（用于将模型推理与真实标签进行比较）。

这有助于在需要时与其他团队有效沟通上游问题和平台问题，并减少解决问题的时间。它还可以提高平台的调试技能。 要配置管道管理，请选择 编辑 ，然后选择以下两个选项： 生成推理和指标管道 和 在模型提交时自动运行推理和指标。然后， 保存 以确认你的管道管理设置。

这有助于在需要时与其他团队有效沟通上游问题和平台问题，并减少解决问题的时间。它还可以提高平台的调试技能。 要配置评估数据集，请选择 添加评估数据集，然后选择你在 housing_test_data 数据集 教程中创建的 模型训练 作为你的评估数据集。选择你的 data 文件夹作为推理目标和指标目标。选择 选择数据集和文件夹.

配置评估库

评估库是一个可参数化的 Foundry 库，可用于获取推理数据集并生成评估指标，这些指标将被添加到建模目标中的评估仪表板。Foundry 附带了以下默认评估库 回归 和 二分类 但你也可以 创建自定义评估库 以针对你的特定建模问题。

为了评估添加到此建模目标的所有模型，所有模型提交必须一致地生成其评估分数。在此建模目标中，我们期望所有模型生成一个名为 prediction 的推理列，该列是一个 float.

这有助于在需要时与其他团队有效沟通上游问题和平台问题，并减少解决问题的时间。它还可以提高平台的调试技能。 选择 选择评估库 用户偏好 回归默认库。将 inference_field 配置为 prediction ，类型为 float，将 actual_field（我们要估计的属性）配置为 median_house_value ，并将 histogram_bins 留空。 保存 以保存评估库配置。

配置评估子集

设置评估子集是模型评估中的一个可选步骤，允许您针对评估数据的特定部分独立生成指标。这些指标都可以在评估仪表板中单独分析。

在以下情况下，您可能需要启用评估子集：

  • 您想了解数据中是否存在某些模型表现优于其他部分的细分群体。这可以为此模型在生产环境中的使用范围提供参考。
  • 您想了解模型表现较差的领域，以便集中未来的开发工作。
  • 您想确保模型不会对评估数据中的受保护群体产生偏见。

在本例中，我们将检查模型在平均房龄小于 5 年或大于 30 年的情况下的表现。

这有助于在需要时与其他团队有效沟通上游问题和平台问题，并减少解决问题的时间。它还可以提高平台的调试技能。 选择 添加评估子集 ，接着运行 housing_median_age 字段。由于这是一个数值字段，我们可以定义要使用的定量分桶策略。在本例中，我们将使用 范围切分 ，分桶为 5 和 30.

这有助于在需要时与其他团队有效沟通上游问题和平台问题，并减少解决问题的时间。它还可以提高平台的调试技能。 保存 子集配置。

此子集配置将在每个评估数据集上针对四组不同的数据评估模型。

  • Overall：这是整个评估数据集。
  • housing_median_age (<5)：评估数据集经过筛选，其中 housing_median_age 小于 5。
  • housing_median_age (>= 5, < 30)：评估数据集经过筛选，其中 housing_median_age 大于或等于 5 但小于 30。
  • housing_median_age (>= 30)：评估数据集经过筛选，其中 housing_median_age 大于或等于 30。

这将使我们能够确定模型在 housing_median_age 不同的记录上的行为是否相似。

这有助于在需要时与其他团队有效沟通上游问题和平台问题，并减少解决问题的时间。它还可以提高平台的调试技能。 选择 保存配置 （位于页面右上角）以保存并返回评估仪表板。从现在起，您提交到此目标的任何模型都将自动生成并构建可用于评估模型的推理数据集和指标数据集。

3.3 如何构建指标管道

配置指标管道后，每次您向此建模目标提交模型时，都会创建并启动推理数据集和指标数据集。如果配置为如此，Foundry 还将自动运行这些数据集，并将指标添加到建模目标的评估仪表板中。

在本例中，由于我们已经将该模型添加到此目标，我们需要手动启动这些数据集的构建。

创建评估管道可能需要几分钟时间，因此您可能需要等待，直到 构建 操作变为可用。

这有助于在需要时与其他团队有效沟通上游问题和平台问题，并减少解决问题的时间。它还可以提高平台的调试技能。 选择 构建评估 （位于评估仪表板右上角），然后选择 housing_test_data 作为评估仪表板，并选择 linear_regression_model 作为要评估的模型。然后， 构建 以启动推理和指标构建。

构建启动后，您可以通过评估仪表板右上角的最近构建下拉列表查看这些构建的进度。根据 Foundry 实例的负载情况，运行评估管道可能需要几分钟时间。

3.4 如何在评估仪表板中评估模型

在继续本教程之前，您的评估仪表板应已成功完成您先前创建的推理数据集和指标数据集的构建。指标完成后，您将能够查看并比较您添加到此建模目标中的所有模型的指标。这为您的建模项目创建了一个集中式的性能数据源。

在回归评估库中，我们生成了一系列可在评估仪表板中查看的指标。这些指标让我们了解模型在未见过的测试数据上预测标签（人口普查区域的中位房价）的准确程度。

确定使用哪些指标以及什么才算足够的性能会因项目而异。这个过程通常需要与利益相关者讨论，但在我们的虚构示例中，我们将认为该模型表现足够好。在本例中，均方根误差为 82639.10 意味着，平均而言，模型预测值与未见过的测试数据中的标签相差 $82,639.10。

这有助于在需要时与其他团队有效沟通上游问题和平台问题，并减少解决问题的时间。它还可以提高平台的调试技能。 刷新页面，选择 housing_test_dataset 数据集 在左侧栏的数据集选择器中，然后选择 linear_regression_model 从模型选择器中。

评估仪表板还向我们展示了按我们先前定义的子集细分的模型性能。评估仪表板中的标签页反映了我们可以查看指标的可用子集组。在本例中，我们可以看到模型在房龄中位数介于 5 到 30 年之间的区域表现最佳。

这有助于在需要时与其他团队有效沟通上游问题和平台问题，并减少解决问题的时间。它还可以提高平台的调试技能。 选择 housing_median_age 评估仪表板顶部的标签页。
