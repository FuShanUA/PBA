向已引导初始化的仓库添加 OSDK

本指南介绍了如何向最初引导初始化时未包含 OSDK 的仓库添加 OSDK。本指南假设您的仓库是通过 Foundry 中的 Developer Console 引导初始化的，或者是在本地使用 @osdk/create-app CLI 引导初始化的。如果您使用的是自定义设置，某些步骤可能需要进行调整。

所需更改

请按照以下步骤将 OSDK 添加到您的应用程序中。

1. 更新 index.html

将以下 meta 标签添加到 <head> 部分内，该部分位于您的 index.html 文件：

Copied!
1<!DOCTYPE html>
2<html>
3  <head>
4    <!-- Other head content -->
5    <meta name="osdk-ontologyRid" content="%VITE_FOUNDRY_ONTOLOGY_RID%" />
6    <!-- Other head content -->
7  </head>
8  <body>
9    <!-- Body content -->
10  </body>
11</html>

2. 更新环境文件

将以下环境变量添加到项目中的所有环境变量文件中。例如： .env.development， .env.production，以及 .env.code-workspaces：

VITE_FOUNDRY_ONTOLOGY_RID=<ri.ontology.main.ontology.your-ontology-rid>

替换 <ri.ontology.main.ontology.your-ontology-rid> 为您 OSDK 的本体论 RID。

你可以在 Ontology Manager 中找到本体论 RID。

3. 更新 client.ts

读取本体论 RID 并初始化客户端对象：

Copied!
1- import { createPlatformClient, type PlatformClient } from "@osdk/client";
2+ import { type Client, createClient } from "@osdk/client";
3
4+ const ontologyRid = getMetaTagContent("osdk-ontologyRid");
5
6- export const client: PlatformClient = createPlatformClient(foundryUrl, auth);
7+ export const client: Client = createClient(foundryUrl, ontologyRid, auth);

4. 更新 package.json

将你的 OSDK 包添加为依赖项：

Copied!
1{
2  "dependencies": {
3    + "<osdk-package-name>/sdk": "latest"
4    // Other dependencies
5  }
6}

将 <osdk-package-name> 替换为你的 OSDK 包名称。

你可以在以下位置找到 OSDK 包名称： 开发者控制台 > 概览 > 生成的 SDK.

5. 更新 .npmrc

仅当您在本地开发环境中引导了仓库时，才需要执行此步骤。

如果您在 Foundry 中引导了仓库，请跳过此步骤。

添加您的 OSDK 包的注册表 URL。

+ <osdk-package-name>:registry=<registry-url>

替换 <osdk-package-name> 和 <registry-url> 替换为您的 OSDK 软件包名称和注册表 URL。

  • 您可以在以下位置找到软件包名称和注册表 URL： 开发者控制台 > 概览 > 生成的 SDK。
  • 请勿将 /sdk 包含在 OSDK 软件包名称中。

以下是一个示例 .npmrc 文件：

//hostname.palantirfoundry.com/artifacts/api/:\_authToken=${FOUNDRY_TOKEN}
@osdk-package:registry=https://hostname.palantirfoundry.com/artifacts/api/repositories/ri.artifacts.main.repository.45660bd6-de33-442e-9f48-a0c02372b906/contents/release/npm
