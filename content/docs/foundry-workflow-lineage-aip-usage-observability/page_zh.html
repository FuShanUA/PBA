AIP 使用指标与可观测性

之前称为 Workflow Builder 的应用程序现在更名为 Workflow Lineage。

要开始使用 Workflow Lineage，请打开一个 Workshop 应用程序或函数仓库，并使用键盘快捷键 Command + I （macOS）或 Ctrl + I （Windows），以查看相关的 Workflow Lineage 图，该图展示了支撑此应用程序的对象、操作和函数。

AIP 使用指标

以下部分将帮助您了解可在 Workflow Lineage 中查看的各种 AIP 使用指标。

模型使用着色

工作流血缘（Workflow Lineage）允许您查看模型请求和令牌使用情况的模型指标。模型使用情况指标分为三种类型：

  • 成功： 指定模型尝试中成功的模型请求总数或所使用的令牌总数。
  • 已尝试： 模型进行的尝试总数，包括成功尝试和受速率限制的尝试。
  • 受速率限制： 总计 受速率限制的尝试 发出的。

在 模型使用量下，指定您要查看的是 模型请求 还是 Token 使用量 指标。

模型请求 显示您的工作流谱系中模型节点上指定请求的总数。

令牌用量 显示 Workshop 应用、Automations 或第三方 OSDK 应用所使用的令牌数量。Logic 节点上的令牌计数是 Logic 应用调试器中使用的令牌数量。

模型用量图表

您可以在折线图中查看 Workshop 应用、Automations 和第三方应用（本体论 SDK 应用）随时间变化的令牌用量或模型请求数，方法是选择相应节点并打开底部的 模型用量图表 面板。

要查看特定资源的具体值，请将鼠标悬停在图表本身上。上文所述颜色图例中使用的相同筛选条件也会显示在图表面板中。

批量替换模型

确定要迁移或替换的模型使用情况后，打开 替换模型 选项卡（位于底部面板），以便在单次操作中替换多个 AIP Logic 函数中的语言模型。有关分步说明，请参阅 批量替换模型 文档。

AIP 可观测性

Workflow Lineage 提供可观测性功能,帮助您监控和调试 AIP 工作流。您可以跟踪执行历史记录、可视化分布式追踪、访问详细日志,并分析函数、操作、语言模型和自动化的性能指标。

有关 AIP 可观测性功能的详细信息,请查看 AIP 可观测性文档。
