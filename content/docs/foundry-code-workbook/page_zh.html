旧版

Code Workbook 处于 旧版 开发阶段，预计不会再进行额外开发。仍提供完整支持。我们建议探索其他应用程序和工具，以满足您的用例需求。

Code Workbook 是一款应用程序，允许用户通过直观的图形界面使用代码分析和转换数据。

目标

Code Workbook 的设计秉持以下原则：

  • 迭代速度： 用户可以快速测试和优化转换与可视化逻辑，从而产出有用的结果。
  • 低入门门槛： Code Workbook 的图形界面以及复用预先编写的逻辑的能力，旨在让不同技术水平的用户都能轻松上手。
  • 协作： 不同的用户群体可以在 Code Workbook 中共享逻辑，并在同一项分析中协同工作。
  • 平台互操作性： 用户可以通过将可视化添加到 Notepad、将可用于生产的管道提升到代码仓库以及迭代机器学习模型，在整个平台上将研究成果投入生产。

功能

Code Workbook 的主要功能包括：

  • 一个 交互式控制台 ，可用于快速迭代转换逻辑并进行即席数据探索。
  • 可视化支持 ，可使用常用软件包（Matplotlib、Plotly、Seaborn）创建详细的交互式图像。
  • 模板 通过简单的接口实现复杂且特定领域逻辑的复用。
  • 多语言支持 针对代码和模板语言，让用户能够为分析选择最合适的语言。
  • 分支功能 通过将用户的更改相互隔离来促进协作。
  • 一个 点选式用户界面 让用户能够轻松自定义 Spark 环境、为转换设置输入类型，并查看节点之间的关系。
