参数

参数是操作类型的输入。它们是规则与其他 Foundry 应用程序（例如 Workshop、Slate 和 Object Views）之间的接口。参数被视为包含外部值的变量。每个参数都由一个类型定义，该类型决定了它可以接受哪些值。除了类型之外，参数还有各种其他潜在配置。每个参数都可以单独配置是否在表单中公开，以及是否允许用户更改。

您可以使用值类型约束操作参数，以便在整个 Foundry 中复用校验规则。

参数在整个操作类型中传递值，并可在规则中被引用，以将值传回对象、关联或副作用；也可在提交条件中被引用，以检查操作是否可以提交；还可在操作更改对象属性之前访问该属性的当前值；或在覆盖中被引用，以更改后续参数的配置。

例如，参数可以采用操作类型中某种 Ticket 对象类型的形式，允许用户修改所选工单的状态。Status 参数定义为字符串。提交操作时，对象类型参数将获取所选 Ticket 对象的值，而 Status 参数包含未来的状态。随后，操作类型将这两个参数值传递给规则并执行规则以编辑对象。

参数还可以从宿主应用程序接收值，这使您能够在操作更改属性值之前捕获该值。作为 Workshop 中的变量，previous_status 可以获取所选 Ticket 对象的 Status 属性的当前值。该值可以传递给操作中的隐藏参数 Previous Status，而 Status 参数可以包含更新后的状态。提交操作后，操作类型会将 Previous Status 和 Status 的值都传递给规则并执行规则以编辑对象。
