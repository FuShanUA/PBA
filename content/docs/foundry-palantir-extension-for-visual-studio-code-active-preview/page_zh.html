主动预览

主动预览是一项专为您开发转换时提供快速反馈而设计的功能。借助主动预览，每次保存更改时预览都会自动更新，让您在编写或更新代码时立即查看结果或错误。

启用主动预览后，您的转换会在每次保存时重新执行。这意味着以下几点：

  • 预览面板始终显示最新的中间结果或错误。
  • 每次更改后，您无需手动触发新的预览。
  • 系统会使用大量缓存来加快处理速度，因此与普通预览相比，您可以更快地获得结果。

主动预览中的缓存

主动预览使用缓存来加快预览速度。其中包括：

  • 项目资源和上下文
  • 有关您的项目及其依赖项的信息
  • 网络检查和设置文件内容
  • 数据集的内存缓存

何时使用 Active Preview

Active Preview 非常适合以下工作流：

  • 使用开销较大的代码定义筛选器进行预览： 代码定义筛选器的结果会被缓存，从而使后续预览速度更快。
  • 迭代开发： 在频繁更改转换逻辑时进行影响评估。
  • 预览设置缓慢的转换： 通过额外的缓存减少等待时间。

由于 Active Preview 将筛选后的输入数据集存储在内存中，因此它最适合小到足以装入可用内存的数据集。

启用 Active Preview

开启 Active Preview 启动预览后。

启用后，您在同一工作区中启动的任何预览都将以 Active Preview 会话的形式启动。要退出 Active Preview，可以 中止 当前会话，或关闭该选项。

最佳实践和注意事项

  • 在 Active Preview 运行期间，请勿更改转换的名称或位置： 如果需要编辑这些配置，请中止 Active Preview 会话，进行更改，然后重新启动。
  • 缓存和项目更新： 有时，由于存在大量缓存，项目中其他位置的更改（例如引用）可能不会立即显示在您的预览中。如果您需要立即查看更新，请停止并重新启动 Active Preview。
  • 自动保存会被自动禁用： 在 Active Preview 运行期间，只有当您手动保存工作时，才会触发预览。退出 Active Preview 后，将重新启用自动保存。

  • 注意外部请求： 每次保存都会触发新的预览。如果您的转换向外部 API 发出请求，这些端点可能会收到比平时更多的流量。
  • 一次只能运行一个预览： 在 Active Preview 运行期间，您无法启动其他预览或使用调试模式。如需切换，请先禁用 Active Preview。
  • 编辑 setup.py： 如果您需要修改您的 setup.py 文件，请在 Active Preview 会话之外进行此操作，以获得最佳效果。
