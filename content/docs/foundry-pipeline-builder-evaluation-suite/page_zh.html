Pipeline Builder 中的 LLM 评估套件

Pipeline Builder 中的大语言模型（LLM）评估套件可让您在将 LLM 转换和逻辑部署到管道中之前对其进行测试。您可以在评估套件中配置多个评估，并在隔离的测试环境中运行它们，以观察其行为。

评估套件旨在与 Use LLM 节点配合使用。每个评估都会使用测试数据和一个或多个评估器来运行 Use LLM 节点，然后报告模型输出与预期结果的对比情况。

本指南涵盖以下内容：

  • 导航至评估套件
  • 创建新评估
  • 配置评估
  • 运行评估并检查结果
  • 支持的评估器

导航至评估套件

选择屏幕右侧工具栏底部的评估套件图标，即可打开评估套件。

在 Evaluation suites 面板中，您可以选择现有的评估，也可以创建新的评估。要创建新的评估，请选择 + New （位于面板右上角）。

创建新评估

在图中选择您要评估的 Use LLM 节点，然后选择 Start。

启动新评估后，Pipeline Builder 会打开评估套件配置视图。

配置您的评估

通过添加测试数据、为评估命名、添加评估器以及选择输出数据集来配置您的评估。

添加测试数据

要导入现有的 Foundry 数据集，请选择 + 添加 （位于 测试数据 字段中），或者选择输入节点并点击 选择。要手动输入数据，请选择输入节点并点击 输入。

您的测试数据应包含您想要作为 Use LLM 节点输入进行评估的所有列。此外，在使用有此要求的评估器时，还应包含一个含有预期 LLM 输出的列。

为评估命名并添加评估器

在面板右上角的文本框中为您的评估命名。然后，选择 + 图标（位于 评估器 标签旁）即可添加评估器。此时会显示一个可用评估器菜单，您可以从中选择一个或多个评估器。

当您选择某个评估器时，Pipeline Builder 会打开该评估器的配置页面。下面的示例使用 精确字符串匹配 评估器，该评估器会将 实际值 列与 预期值 列，并基于 通过条件返回布尔结果。您还可以设置可选的 区分大小写 和 修剪空白字符 参数。应用配置后，选择右上角的 关闭 即可退出此视图。

选择输出数据集

在 评估套件输出 字段中，选择现有数据集，或创建一个新数据集来存储您的评估输出。

运行评估并查看结果

您必须拥有管道的编辑权限，才能运行评估套件。

配置评估后，选择 运行评估套件 （位于屏幕右上角）。

要跟踪评估进度，请选择屏幕右上角的 打开构建报告 链接。

在构建报告中，监控评估运行的进度。

评估构建完成后，在屏幕底部的 评估结果 标签页中查看结果预览。

支持的评估器

Pipeline Builder 评估套件支持以下评估器：

  • 精确字符串匹配（可配置）： 检查实际字符串是否与预期字符串完全匹配。默认：匹配区分大小写，并包含空白字符。
  • 整数范围： 检查实际值是否在预期值的范围内。仅支持整数。
  • 精确数值匹配： 检查两个数字是否完全相等。支持 integer、long、float、double 和 short 类型。
  • 精确字符串数组匹配（可配置）： 检查两个字符串数组是否包含相同的元素。默认：比较依赖于顺序、区分大小写，并包含空白字符。
  • 精确数值数组匹配（可配置）： 检查两个数值数组是否包含相同的元素。支持 integer、long、float、double 和 short 类型。默认：默认情况下比较依赖于顺序。
  • 精确时间匹配： 检查两个时间值是否完全相等。支持 Date 和 Timestamp 值。
  • 通用精确匹配： 检查实际值是否与预期值完全相同。比较时会对数值类型进行强制转换（例如，integer 可以与具有相同值的 double 匹配），date 和 timestamp 类型也是如此。对象和对象集按引用进行比较，结构体和映射按无序键值对进行比较，列表按有序元素进行比较，模型按标识符和参数进行比较。如果存在适用于您的数据类型的特定类型评估器，请使用该评估器，因为它们提供细粒度的比较选项和更好的类型安全性。
  • 浮点数范围： 检查实际值是否位于预期值的范围内。所有数值类型均可用作参数。
  • 时间范围： 检查实际值是否位于预期值的范围内。仅支持 Date 和 Timestamp 值。
  • Levenshtein 距离： 通过计算将一个序列转换为另一个序列所需的最少单字符编辑次数（插入、删除或替换），来衡量两个序列之间的差异。
  • 字符串长度： 检查实际字符串的长度是否在预期范围内。
  • 关键字检查器： 检查实际文本中是否包含特定关键字。
  • 正则表达式匹配： 检查实际字符串是否与预期的正则表达式匹配。
  • LLM 评判： 使用 LLM 评估用户定义的条件对给定值是否成立。当条件满足时返回 true ，否则返回 false。接受除引用类型（对象定位器、对象 RID、对象集或模型）之外的任何类型作为实际值。需要将条件参数写成清晰、可验证的断言，并提供一个可用于评估的模型。
