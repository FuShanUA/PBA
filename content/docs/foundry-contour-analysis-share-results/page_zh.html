分享结果

在 Contour Dashboard 模式中分享

分享分析结果的最简单方式是创建一个 仪表板。仪表板是分析中的一个独立视图，创建者可以在其中展示带有文本注释的结果。

可以使用仪表板预览面板在分析过程中轻松构建仪表板。主要功能包括图表间筛选、内联参数引用、全屏演示视图以及 PDF 导出。

了解更多关于 Contour Dashboard 模式的信息。

在 Notepad 中分享

Notepad 是 Foundry 的主要报告工具，推荐用于大多数报告使用场景。使用 Notepad，您可以创建实时更新和静态（“时间点”）文档、为文档添加注释、在平台内共享文档，以及将文档导出为 PDF。

在 Notepad 中，您可以将来自 Contour 的结果与来自各种 Foundry 来源（包括 Quiver、Code Workbook 和 Object Explorer）的内容一起展示。

要将 Contour 图板添加到 Notepad，请打开分析中图板右上角的 ... 菜单，然后选择 可嵌入的 Foundry 应用程序。这会将图板复制到剪贴板，使您能够将图板粘贴到 Notepad 中。您也可以通过将鼠标悬停在图板上并选择，从 Contour 仪表板中复制 Contour 图板 复制 按钮。
