采用直接连接策略的 Foundry worker（也可称为“直接连接”）是访问接受来自 Foundry 入站流量的外部系统（例如 REST API 和云/SaaS 系统）的推荐默认方式。

采用代理代理策略的 Foundry worker

采用代理代理策略的 Foundry worker（也可称为“代理代理”或“代理瘦模式”连接）是访问托管在私有网络上的外部系统的推荐架构。它需要使用 数据连接代理.

在此场景中，代理充当简单的网络隧道，本身不执行任何数据处理。
