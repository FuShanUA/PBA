资源配置

本页面介绍单节点转换的资源配置。分布式 Spark 转换通过 Spark 配置文件 进行配置，以便对大量资源消耗加以控制。

转换资源可以通过在转换装饰器上调用 with_resources 来进行配置。

使用 指标遥测选项卡 来监控构建的内存和 CPU 利用率，并调整资源设置。对于使用轻量级计算引擎的转换，可以使用相应指标。

from transforms.api import transform, Input, Output


@transform.using(
    output=Output("/path/output"),
    input=Input("/path/input"),
).with_resources(
    cpu_cores=1
)
def my_compute_function(output, input):
    ...

可以配置以下选项：

  • cpu_cores: 为转换的容器请求的 CPU 核心数。可以为小数，默认值为 2。
  • memory_gb: 为容器请求的内存量，单位为 GB。
  • memory_mb: 为容器请求的内存量，单位为 MB。
  • gpu_type: 为转换分配的 GPU 类型，以字符串形式提供。

只能配置 memory_gb 和 memory_mb 中的一个。

默认情况下，允许的最大值为 8 个核心和 64 GB 内存。如需提高这些上限，请联系 Palantir 支持团队。

下面是核心数、内存和 GPU 类型的配置示例。

from transforms.api import transform, Input, Output


@transform.using(
    output=Output("/path/output"),
    input=Input("/path/input"),
).with_resources(
    cpu_cores=8,
    memory_gb=32,
    gpu_type="NVIDIA_T4"
)
def my_compute_function(output, input):
    ...

GPU 预配

只有当 GPU 对转换所在的项目可用 时，才能在 Python 转换中使用。

并非所有 GPU 类型在所有环境中都可用。

以下是可以为转换提供的 GPU 类型：

  • "NVIDIA_T4"
  • "NVIDIA_V100"
  • "NVIDIA_A10G"
  • "NVIDIA_A100"
  • "NVIDIA_A16"
  • "NVIDIA_H100"
  • "NVIDIA_H200"
  • "NVIDIA_L4"
  • "NVIDIA_L40S"

有关 GPU 使用的示例（包括使用 cuDF 进行 GPU 加速的 Polars），请参阅 高级单节点计算选项。
