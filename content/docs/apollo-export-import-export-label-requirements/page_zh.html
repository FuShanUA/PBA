标签要求

导出资源时，您可能希望确保仅导出满足特定标签要求的资源。示例如下：

  • 要求产品发布通过漏洞扫描（带有 vulnerability-scanner.example.build/security-scan-outcome=pass）。
  • 要求环境在 AWS 上运行（带有 cloud-service-provider=aws）。
  • 排除与 Lilliput V5 不兼容的产品发布（带有 apollo/lilliput-v5-incompatible=true）。

您可以通过导出管道设置中的必需资源标签和排除资源标签面板，在管道中配置这些要求：

默认情况下，无论标签值如何，Apollo 都会过滤所有具有指定标签的资源，这适用于标签包含和排除两种情况。要定义要过滤的特定值，您必须选择添加值并输入至少一个值。

在下面的示例中，管道要求所有导出的产品发布都带有 apollo.palantir.com/all-container-images-available 标签，并且特别要求该值为 true。

您可以指定任意数量的值。如果定义了多个值，只要存在其中一个指定的值，资源即满足标签要求。

标签排除优先于标签包含。也就是说，如果某个资源既满足必需标签，又满足排除标签，则该资源将被排除在管道之外。

标签要求仅适用于标签本身指定的资源类型。在本示例中，该标签仅适用于产品发布，不会对任何其他资源类型作要求。

您可以为同一导出管道添加多个标签要求。每个标签要求将独立生效。如果同一资源类型存在多个标签要求，则必须全部通过，资源才能被导出。
