使用代码仓库创建媒体集批处理管道

本指南将引导您完成一个使用 代码仓库 应用程序的简单转换示例。您将学习如何使用媒体集编写和编辑 Python 代码。

1. 创建仓库

首先，创建一个新仓库。为此，请导航到 Foundry 中的一个 项目 ，然后选择 + 新建 在右上角，然后选择 代码仓库.

在本指南中，我们将编写一个 Python 转换。为您的仓库命名并选择 或 在下拉菜单中的 “语言模板”下方的下拉菜单中）。然后，选择 初始化仓库.

2. 导入您的数据

如果您已经导入了要使用的原始媒体集，可以直接进入下一步。否则，请参阅关于 如何将媒体导入 Foundry.

3. 导入 transforms-media 库

要使用媒体集转换，您必须导入 transforms-media 库。

在 Data Connection 中导航至 ”面板中找到。 例如，要使用 选项，然后搜索并选择 transforms-media 库。然后，选择 添加并安装库.

状态应显示为 库已安装 安装完成后。

4. 编辑代码

创建新文件

创建 Python 转换仓库时应自动生成一个 examples.py 文件，您可以将其作为基础。您可以通过选择省略号图标、选择 重命名来重命名该文件，并相应地为文件命名。

如果您想创建新文件，请选择省略号图标并选择 新建文件 图表工具 数据集 目录。请确保在此工作流程中创建的是 Python 文件。

确保输出文件存在

如果您要创建媒体集输出文件，请务必在转换装饰器中引用它之前先创建该文件。

您可以通过导航到您的 Project 文件夹（您最初创建 Python 转换代码仓库的地方）并选择 New > Media set 从下拉菜单中。

用途 get_media_item(), get_media_item_by_path()，或 list_media_items_by_path_with_media_reference()

要转换媒体集中的每个媒体项，您必须在转换中使用 get_media_item() or get_media_item_by_path().

对 get_media_item() 和 get_media_item_by_path() 调用会返回一个类似 Python 文件流的对象。所有被 io.open() ↗ 所接受的所有选项也都受支持。项以流的形式读取，这意味着不支持随机访问。

您可以按如下方式引用单个媒体项：

示例：将 PDF 媒体集转换为新的 PNG 媒体集

在本示例中，我们将遍历 PDF 媒体集中的所有媒体项，并将它们保存为 PNG 图像。

请注意， list_media_items_by_path_with_media_reference() 返回一个数据框（dataframe），这允许您对输出执行 PySpark 函数。在本示例中，我们将收集 mediaItemRid 列的值并以数组的形式进行遍历：

from transforms.api import transform
from transforms.mediasets import MediaSetInput, MediaSetOutput


@transform(
    pdfs=MediaSetInput('INPUT_MEDIA_SET_PATH'),
    output_pngs=MediaSetOutput('OUTPUT_MEDIA_SET_PATH')
)
def upload_images(ctx, pdfs, output_pngs):
    media_items_listing = pdfs.list_media_items_by_path_with_media_reference(ctx)
    rid_list = media_items_listing.rdd.map(lambda x: x.mediaItemRid).collect()

    for rid in rid_list:
        output_png = pdfs.transform_document_to_png(rid, 0)
        output_pngs.put_media_item(output_png, "PNG_"+rid)

4. 测试您的更改

编写完数据转换代码后，您应该测试所做的更改。测试可确保您的代码在合并更改之前按预期工作。

在 Foundry 中，媒体集可以像代码仓库一样进行分支。分支对于测试多步骤数据管道的设计非常有用。例如，您可以在不影响不依赖您分支的用户的下游依赖项的情况下，隔离地测试数据管道各部分的更改。

5. 提交您的更改

现在，您可以在 Code Repositories 中提交更改，以标记您所完成的工作。在提交之前，您的工作默认会自动保存。提交会在您到达一个停止点时专门标记您的一组更改。

选择 提交 按钮以提交您的更改并对代码运行自动检查。选择 构建 按钮也会提交您的更改、运行自动代码检查，并开始构建您的输出数据集。若要在不构建数据集的情况下快速测试您的更改以确保代码通过代码检查，请选择 提交。否则，您可以直接跳到 合并并构建您的更改.

6. 合并并构建您的更改

对新媒体集输出感到满意后，与协作者合作合并、构建并查看更改。
