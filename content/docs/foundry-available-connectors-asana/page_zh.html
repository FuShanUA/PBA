配置 Asana 同步

Asana 连接器支持高级同步配置，以确定将哪些数据以及多少数据导入 Foundry。

在浏览可用表并将其添加到连接后，导航至 编辑同步。在左侧的 同步 面板中，找到要配置的同步并选择 > （位于右侧）。

选项是否必填？描述
Table是选择应将 Asana 中的哪个表复制到 Foundry。请参阅 数据模型 以了解支持的表。
Column selectionNo选择要同步到 Foundry 中的列的子集。请查看 列选择 部分以了解更多信息。
Row filtersNo启用并添加筛选器，以根据列值移除不符合条件的行。请查看 行筛选器 部分以了解更多信息。
LimitNo在底层查询中添加 SQL limit 子句。此设置可用于限制单次运行中同步到 Foundry 的行数。
IncrementalNo启用以将数据分小批量同步到 Foundry。请查看 增量式 部分以了解更多信息。

增量

通常，同步会导入目标表中所有匹配的行，无论同步之间数据是否发生变化。相比之下，增量同步会维护最近一次同步的状态，并且仅从目标表中摄取新的匹配行。

从 Asana 摄取大型表时可以使用增量同步。要使用增量同步，表必须包含一个严格单调递增的列。此外，被读取的表必须包含具有以下数据类型之一的列：

  • DATE
  • TIMESTAMP

数值列类型：

  • int
  • TINYINT
  • SMALLINT
  • INTEGER
  • long
  • BIGINT
  • NUMERIC
  • NUMBER
  • DECIMAL
  • DEC

字符串列类型：

  • string
  • VARCHAR
  • CHAR
  • NVARCHAR
  • NCHAR
  • LONGNVARCHAR
  • LONGVARCHAR

增量同步需要以下配置：

选项是否必填？描述
列是选择用于增量摄取的列。如果表不包含任何受支持的列类型，下拉菜单将为空。
Initial value是开始同步数据的起始值。

示例： 一个 5TB 的表包含数十亿行我们希望同步到 Asana 的数据。该表有一个 单调递增列 中的一个顶层键下定义，该键名为 id。可以将同步配置为每次摄取 5000 万行,使用该 id 列作为 增量列,初始值为 -1,配置的限制为 5000 万行。

首次运行同步时，前 5000 万行(基于 id升序排列)中包含 id 值大于 -1 的行将被摄取到 Foundry 中。例如，如果此同步运行了多次，且上次运行期间摄取的最大 id 为 19384004822,则下一次同步将摄取接下来的 5000 万行，从第一个 id 大于 19384004822的行开始，依此类推。

列选择

选择要同步到 Foundry 中的列。如果未选择任何列，则所有列都将同步到 Foundry 中。

所有列名必须以下划线或英文字母开头。列名只能包含下划线、英文字母或数字。

以下是有效列名的示例：

  • _colum_name
  • a_column_name_123

以下是无效列名的示例：

  • 1ColumnName;以数字开头。
  • a-column-name*;包含连字符和星号。
  • å-column-name;包含非英文字符。

行筛选器

可以添加筛选器来减少同步的行数，或者单独选择要同步到 Foundry 中的行。要配置行筛选器，表的预览必须成功。在配置行筛选器之前，我们建议使用 Preview of inbound data 界面底部的部分刷新预览。可以刷新预览以验证所添加筛选器的行为。

筛选器配置由一组条件组成，每行必须满足这些条件才能被同步到 Foundry 中。每组条件的求值方式可以是：当 all 所有条件匹配时匹配，或当任一 at-least one 条件匹配时匹配。条件组可以嵌套，以便对导入内容提供更细粒度的控制并提供高度灵活性。这些等效于标准 SQL 中的 AND 和 OR 语句。

条件本身是将 Asana 中表的某一列的值与可在界面中输入的值进行简单比较。例如，条件 CreatedAt 等于 12/04/2021 将仅导入那些 CreatedAt 列的值为 12/04/2021的行。列的数据类型决定了支持的比较操作。

比较操作

筛选器支持以下操作：

  • EQUAL TO
  • GREATER THAN
  • LESS THAN
  • GREATER THAN OR EQUAL TO
  • LESS THAN OR EQUAL TO
  • NOT EQUAL TO
  • IS NULL
  • IS NOT NULL

这些比较操作的行为与标准 SQL 中相应操作的行为等效。

字符串类型的列还支持 Like 和 Not like 运算符，这些运算符使用标准 SQL-92 语法。
