数据集选择器

每个数据集选择器都可以配置为 Select or Exclude 符合选择器条件的数据集。例如， Select 派生数据集将把范围缩小为仅包含派生数据集。 Exclude 文件夹中的数据集 /palantir/finance 将通过不包含给定文件夹中的数据集来缩小范围。

某些数据集选择器还包含第二个参数，例如要从策略中包含或排除的文件夹列表或 worker 类型列表。

以下列表描述了在 Retention 应用中配置保留策略时可用的数据集选择器。

在以下数据集中

根据给定的 RID 选择所有数据集，即使你重命名数据集，RID 也不会改变。

了解如何识别数据集的 RID。

接受 1 个参数： list of datasets （按 RID 保存的数据集列表）。

示例

Select 以下数据集： <list of datasets>

以下文件夹中的数据集

根据给定的 RID 选择给定文件夹或项目中的所有数据集。将来在这些文件夹或项目中创建的任何数据集也将受此策略约束。

接受 1 个参数： list of folders （按 RID 保存的文件夹或项目列表）。

示例

Select 以下文件夹中的数据集： <list of folders>

是派生数据集

当且仅当以下条件成立时，数据集才被定义为派生数据集：

  • 该数据集在其主分支中包含一个 JobSpec 。
  • 该数据集具有非零数量的数据集输入。

不符合这些条件的数据集，包括原始数据集、从外部源摄取的数据集以及从未在主分支上构建的数据集，将不会被此选择器选中。

接受一个可选的 worker type 列表作为参数： 直方图 worker type 列表是在 JobSpec 的 workerType 字段中指定的一组 worker 类型（例如， transforms 和 phonograph2-writeback 如下图中所示）。如果此字段留空，此选择器将影响所有派生数据集。

示例

Select 具有以下 worker 类型的派生数据集： transforms, phonograph2-writeback

是否为 transforms 数据集

直方图 筛选具有 transform 类型的 transforms 数据集 选择器用于标识由 transforms 构建的数据集。与 是派生数据集不同，此选择器按 transform 类型而非 worker 类型进行筛选。

接受一个可选的 transform type 列表作为参数： 当数据集的 transform 类型或 transform 别名与指定的值之一匹配时，该数据集即为匹配。如果将列表留空，此选择器将匹配所有 transforms 数据集。

示例

选择 筛选具有 transform 类型的 transforms 数据集 in 选择 模式并将 transform 类型设置为 projection 以针对 投影数据集.

在回收站中

选择位于回收站中的数据集。

不接受任何参数。

示例

Select 回收站中的数据集

组合选择器示例

为了演示数据集选择器及其组合使用方式，请考虑以下两个示例：

在特定文件夹中应用带豁免的宽泛策略

以下数据集选择器集合将选择 空间 中不在 folderA:

  • Select 空间中的所有数据集
  • Exclude 回收站中的数据集
  • Exclude 以下文件夹中的数据集： folderA

选择项目中的所有数据集（除一个外）

以下数据集选择器集合将选择 folderA 中除 Incremental dataset:

  • Exclude 以下数据集： Incremental Dataset
  • Select 以下文件夹中的数据集： folderA

保护数据集免受保留策略影响

你可以保护特定数据集免受 给定保留策略 的影响，方法是使用 排除 模式配合 在以下数据集中 选择器。这会根据 RID 将单个数据集从该策略中排除。

此排除仅适用于你正在配置的策略。在同一 空间 中运行的其他保留策略——包括推荐的（平台管理的）策略以及任何其他自定义策略——仍可能标记被排除数据集上的事务。要完全保护数据集，请审查可能适用于它的每个策略。
