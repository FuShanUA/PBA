可复用逻辑

在分析应用中，您可以选择将逻辑片段保存下来供其他用户复用。这有助于减少重复工作、缩短价值实现时间，并让用户能够利用领域专家或更具技术能力的协作者所创建的逻辑。

Contour

在 Contour 中，您可以 保存表达式 以便在不同分析和路径之间轻松复用逻辑，并与他人共享逻辑。保存的表达式可用于创建或替换列，或用于执行聚合操作。 了解有关 Contour 的更多信息。

代码仓库（Code Repositories）

Code Workbook 模板通过将代码隐藏在简单的表单界面之后，为技术能力较强的用户提供了一种轻量级的方式，与不太擅长编写代码的用户进行协作。用户选择的值会被代入模板中，随后即可像工作簿中的任何其他转换一样运行。任何可以用代码创建的转换（例如 Matplotlib 或 Plotly 可视化），都可以通过代码模板来构建。 了解有关 Code Workbook 的更多信息。
