构建转换

Palantir 的 Visual Studio Code 扩展让您可以直接在编辑器中进行构建。在 预览 和 调试 转换之后，构建是在完整生产数据集上运行代码之前的最后一步。构建在 Palantir 平台上执行，您无需离开 VS Code 环境即可监控其进度、查看日志并进行管理。

构建与预览

  • 使用预览 在开发和使用示例数据或特定数据子集测试转换逻辑时。
  • 使用构建 当您准备好在完整生产数据集上运行转换并将更改提交到管道时。

如何启动构建

您可以通过以下三种方式在本地 VS Code 环境或平台内的 VS Code 工作区中启动构建：

方法 1：命令面板

选择 Palantir: Build on Foundry 选项（来自命令面板）。

方法 2：Palantir 侧边面板

选择 构建 图标（来自 Palantir 侧边面板）。

方法 3：构建面板

打开 构建 面板并选择 构建 选项。

了解构建过程

您可以从打开的 Palantir 仓库中对任何文件启动构建。

要构建文件，您必须将所有本地更改推送回远程仓库。

一旦您的本地分支与远程分支同步，构建过程将执行必要的检查，并在 Palantir 平台上使用完整数据集运行构建。

在 Data Connection 中导航至 构建 面板以查看构建状态、访问日志并监控您的输出数据集。
