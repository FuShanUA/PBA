已配置面板对象视图

您可以构建两种类型的已配置面板对象视图，以显示某个对象类型的一个或多个对象： 对象实例面板 显示单个对象，而 对象集面板 则将多个对象显示为一个对象集。两种类型的已配置对象视图共享相同的 编辑入口 和配置体验。

对象实例面板

默认的对象实例面板视图会显示一个 属性列表小组件 ，用于显示 重要属性 ，这些属性属于该对象类型的单个实例。

对象集面板

对象集面板显示同一对象类型的多个实例的聚合视图。默认的对象集面板提供选项卡式布局，其中包含两个用于浏览对象集合的接口：

  • 其中 “图表” 选项卡最多显示五个 XY 图表 ，用于可视化按属性值分组的对象聚合。
  • 而 “列表” 选项卡会显示一个 对象列表小组件 ，其中每个对象最多显示三个属性，包括对象标题、重要属性以及媒体（若有）。

编辑已配置面板对象视图

要对任一类型的已配置面板对象视图进行更改，请使用其中一个 编辑入口 以导航至已配置的对象视图编辑器。进入编辑器后，您可以自定义已配置的面板对象视图的内容，就像自定义 Workshop 模块一样。

如果您正在配置对象实例面板视图，但想要切换为对象集，请先从顶部功能区选择 对象实例 ，然后从下拉菜单中选择 对象集 。您也可以使用同一菜单 从 对象集 切换到 对象实例。

在左侧面板的设置部分中， 模块类型 部分允许您配置编辑画布的大小，以便更轻松地构建紧凑的模块。

  • 编辑显示大小： 在下拉菜单中选择某个选项将调整画布中面板的预览大小。面板的实际大小会因设备和应用程序而异，因此这只是构建者用来估算不同工作流中可用空间的一个工具。
    • 显示选项包括与不同平台应用程序中面板大小相匹配的 应用程序预设 、常用的 分辨率预设，以及 手动输入 模块的高度和宽度（以像素为单位）。
  • 在画布中显示分辨率选择器： 启用后，编辑器左下角将显示一个分辨率选择器，允许构建者直接在画布上编辑模块的显示尺寸。
  • 适应画布： 当分辨率尺寸超过画布尺寸时，分辨率选择器旁将出现一个按钮，可在将整个面板适应视图与以标准缩放比例查看面板之间切换。
