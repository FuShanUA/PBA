网络访问与身份验证

在 Workshop 中开发的移动应用本质上只是针对移动浏览器使用进行了优化的 Web 应用。因此，用户在平板电脑或手机设备上访问这些 Web 应用时无需安装任何内容。但是，必须确保您的用户设备能够在网络层面访问您的 Foundry 环境，并且您的用户能够成功通过 Foundry 的身份验证。

本页面介绍了您应如何考虑网络访问和身份验证、可能遇到的常见问题以及这些问题的可能解决方案。您可能需要与 IT 部门的同事合作来调试和修复任何问题，尤其是与网络访问相关的问题。

从宏观层面来看，确保用户访问可以分解为以下两个主要部分：

  • 确保网络访问
  • 确保用户能够进行身份验证

确保网络访问

由于 Foundry 可以部署在多种不同的环境中，从 Palantir 托管的 SaaS 环境到本地部署配置，因此没有一种单一的解决方案可以确保用户从其移动设备访问 Foundry。在本节中，我们将介绍一系列为您的用户启用访问权限的选项。

实现移动设备访问 Foundry 的最常见方法包括：

  • 使用企业 Web 浏览器
  • 使用移动 VPN
  • 将 IP 区域加入允许列表

使用企业 Web 浏览器

许多组织已经部署了 MDM（移动设备管理）解决方案来管理移动设备，而大多数 MDM 解决方案都包含一个可用于访问公司内部资源的安全 Web 浏览器。如果您的组织已设置 MDM，则可能可以使用 MDM 支持的浏览器来访问 Foundry。

这种方法的主要缺点是，MDM 支持的 Web 浏览器渲染 Web 组件的方式可能与 Safari、Chrome 或 Edge 等标准浏览器不同。因此，与常用浏览器相比，用户体验可能会较差。此外，任何没有组织管理设备的用户都将无法访问 Foundry。

如果您知道您的用户群体已经拥有由组织 MDM 管理的设备，那么使用 MDM 支持的 Web 浏览器可能是最直接、最安全的方案。

下一步： 联系您组织的 IT 部门，了解是否已有企业 MDM 部署，以及 MDM 的 Web 浏览器是否可以配置为启用对您 Foundry 环境的访问。

使用移动 VPN

您的组织可能支持 VPN，以便员工在离开办公场所时也能访问公司资源。许多 VPN 解决方案也支持在移动设备上访问，使用户能够连接到 VPN，然后使用设备的标准 Web 浏览器访问内部资源。

这种方法的主要优点是用户可以使用标准浏览器，例如 Safari 或 Chrome。缺点是用户每次使用 Foundry 时，除了初始设置 VPN 客户端之外，还需要执行连接 VPN 的额外步骤。如果您的用户已经习惯这种工作流程，这可能不是问题，但对于向一组以前从未使用过移动 VPN 的用户推出应用来说，这可能会带来问题。

下一步： 联系您组织的 IT 部门，了解是否有可用的移动 VPN 客户端。如果有，请验证您的用户是否可以访问该 VPN，以及使用该 VPN 是否能够访问您的 Foundry 环境。

将 IP 区域加入允许列表

By 在 Control Panel 中配置网络入口，您可以选择允许来自您的用户所在某些国家/地区的广泛网络访问。

这种方法的好处是，允许名单区域中的用户可以从任何设备访问您的 Foundry 环境，而无需 MDM 管理的设备或 VPN 客户端（如果您之前使用的是严格的基于 IP 的允许名单）。此方法为用户提供了更流畅的登录体验。但是，您的组织可能不放心允许来自更广泛网络范围的流量进入您的 Foundry 环境。

确保用户能够进行身份验证

一旦您的用户能够在网络层面访问 Foundry，他们需要导航到 移动应用启动器 并向 Foundry 进行身份验证。这要求您的用户拥有用户账户，并完成贵组织的 SSO 身份验证流程。我们将在下文介绍这两个步骤的一些注意事项。

确保用户拥有账户

访问 Foundry 始终需要用户账户。移动设备用户的账户相关注意事项可能与桌面用户不同。根据我们的经验，一些针对移动设备使用场景的用例可能涉及出人意料复杂的设备环境：

  • 某些用例要求承包商能够从 Foundry 访问数据或向 Foundry 提交数据。如果您的用例面向的是非贵组织员工的广泛用户群体，您应确保这些用户拥有账户并能够 进行身份验证 以访问 Foundry。
  • 某些移动用例针对在共享设备上的使用。例如，工厂车间可能有用于访问 Foundry 中数据的平板设备。这些设备不属于单个用户，而是在工作环境中由多人共享。在这种情况下，您应确认哪些用户将登录到每台设备。如有必要，可以为每个工作站配置一个专用用户账户，可以在您的身份提供商中配置，也可以使用 Foundry 的 内部域。如果您需要启用此类身份验证模式，请联系您的 Palantir 代表以了解更多信息。

验证最终用户身份验证流程

由于身份验证流程是端到端用户体验的关键部分，您应验证最终用户在移动设备上的身份验证体验。用户每次需要进行身份验证时都必须完成贵组织的 SSO 流程，并且需要完成 MFA（多因素身份验证）流程。

此外，贵组织的身份提供商决定了用户需要多久重新向 Foundry 进行一次身份验证。如果登录超时设置得非常频繁，可能会给最终用户体验带来额外的阻碍，因为用户可能需要在一天中频繁进行身份验证。如果这给您的用户造成了问题，请联系您的 IT 部门，讨论在您的身份提供商中延长会话时长。
