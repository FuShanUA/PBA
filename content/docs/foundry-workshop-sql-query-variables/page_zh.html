SQL 查询变量

A SQL 查询变量 是一种 Workshop 变量，其值通过针对模块中的对象集和其他变量运行 SQL 查询来计算。您只需在变量编辑器中编写一条 本体论 SQL SELECT 语句，将对象集和接口集变量绑定为表，将其他变量绑定为参数。每当输入发生变化时，Workshop 都会将查询解析为变量值。

SQL 查询变量最适合 在 SQL 中很常见但在其他地方难以表达的计算。例如，诸如 RANK(), ROW_NUMBER(), LAG()日 LEAD() 之类的窗口函数可让您直接针对本体论数据计算排名、累计总和和环比比较，而无需编写和部署函数。它们还可有效用于 将复杂的本体论查询合并为单个请求，例如联接多个对象集并返回一个 结构体数组 用于 自定义小部件.

何时使用 SQL 查询变量

请考虑 SQL 查询变量与其他计算变量值的方式的对比：

  • SQL 查询变量： 适用于特定于某个 Workshop 应用程序的值，且其逻辑最适合用 SQL 编写。由于查询是在模块内部定义的，因此无需单独发布或进行版本管理。
  • SQL 函数: 当您的逻辑需要在多个应用程序和 Foundry 界面之间共享和重用时使用。SQL 查询变量的作用域仅限于定义它们的模块，无法在其他地方重用。
  • TypeScript 和 Python 函数支持的变量: 当逻辑更容易用 TypeScript 或 Python 表达，或者需要超出 SQL SELECT statement.
  • 变量转换: 适用于定义为一系列常见操作的简单应用程序内逻辑，无需编写查询或代码。
  • 对象集变量: 适用于应用程序内对对象集的原生点击式转换，例如按属性值筛选或透视到关联对象。

支持的变量类型

直方图 SQL 查询 定义类型可用于以下变量类型：

变量类型变量期望的查询结果
字符串, 数值, 布尔, 日期, 时间戳恰好一行一列。
字符串, 数值, 布尔, 日期，或 时间戳数组恰好一列，且少于 10,000 行。
结构体恰好一行。每列将成为一个结构体字段。
结构体数组少于 10,000 行。每行将成为一个结构体。

目前，对象集、地理点和地理形状变量无法由 SQL 查询支撑。

创建 SQL 查询变量

  1. 打开 变量 面板，然后选择或创建一个受支持类型的变量。
  2. 将 变量定义类型 下拉菜单设置为 SQL 查询.
  3. 在编辑器中，添加查询所引用的表和参数，编写查询，然后选择 保存并运行 以执行查询并填充变量。

添加表

对象集变量会以表的形式提供给您的查询。在 表格中，选择 添加表下，选择一个对象集变量，并为其指定一个 别名。在查询中使用以下语法引用该表： @alias 语法：

Copied!
1
SELECT COUNT(*) FROM @orders;

别名必须以字母或下划线开头，且只能包含字母数字字符或下划线。使用以下方式限定表中的列： @alias.column_name。命名为 date 的列必须使用反引号进行转义：

Copied!
1
SELECT AVG(@orders.total) FROM @orders WHERE @orders.`date` >= '2026-01-01';

每个绑定的表必须至少选择一个列。使用表绑定下方的列搜索来添加查询所引用的属性。未定义任何列的表绑定将失败并出现错误 Table binding '@alias' does not have any columns defined.

对象集变量和 接口 集变量都可以绑定为表。对于接口集变量，查询可用的列是接口的属性，因此单个查询可以跨越实现该接口的每个对象类型。

联接多个表

您可以在查询中绑定多个表并对它们进行连接。连接必须基于主键和外键关系，将一个表的外键属性与另一个表的主键进行匹配：

Copied!
1
2
3
SELECT COUNT(*)
FROM @orders
INNER JOIN @customers ON @orders.customerId = @customers.id;

子句中使用的每一列都必须在其表绑定所选择的列中，这与您在 ON 列表中指定列的方式相同。 SELECT 列表中的列相同。

尚不支持多对多关系，因为它们是通过连接表而非直接的主键和外键关系来解析的。

添加参数

其他变量可以作为参数绑定到您的查询中。在 参数中，选择 添加参数下，选择一个变量并为其指定别名。使用相同的 @alias 语法引用该参数。变量的当前值会在执行时被替换，并且每当绑定的参数发生变化时，查询都会重新计算：

Copied!
1
SELECT COUNT(*) FROM @orders WHERE @orders.region = @selectedRegion;

编写并运行查询

查询编辑器可以自动补全您绑定的表、列和参数。选择 保存并运行，或使用 Cmd + Enter （macOS）或 Ctrl + Enter （Windows）键盘快捷键来执行查询并更新变量值。该查询使用本体论 SQL 方言；请参阅 SQL 方言参考 以了解支持的语法和函数。

展开编辑器下方的 查询预览 面板，查看查询实际返回的行和列。预览最多读取 50 行并显示原始 SQL 结果，因此在您仍在调整变量本身会拒绝的查询时，它仍然很有用。

结果形状

变量类型决定了 Workshop 如何读取查询结果。在所有情况下，行的顺序都是查询返回的顺序；当顺序很重要时，请使用 ORDER BY 。

标量变量

标量变量要求恰好一行一列。返回多于一行或多于一列的查询会失败，而不是静默地读取第一个值。

数组变量

数组变量要求恰好一列。每一行都会贡献到数组中，而本身是数组字段的单元格会将其所有元素展平并贡献到单个有序数组中：

Copied!
1
2
3
4
5
-- One array cell: resolves to ['a', 'b', 'c']
SELECT array('a', 'b', 'c') AS value;

-- One scalar per row: resolves to one array of all returned names
SELECT name FROM @employees ORDER BY name;

需要注意的其他行为：

  • 空值会被跳过 （在行级别和元素级别均是如此）。
  • 空结果会设置一个空数组 ，而不是让变量保持未设置状态。
  • 结果最多限制为 10,000 行。 返回 10,000 行或更多行的查询会失败，并提示您在查询中添加 LIMIT ，而不是截断数组。

结构体变量

折线图 循环布局支持遍历各种数组类型，包括字符串、布尔值、数字、日期、时间戳和 变量，字段是从查询结果派生的，而不是在变量配置中声明的。以下三条规则定义了其行为：

  1. 每一列都成为一个结构体字段，以该列命名。
  2. 每一行都成为一个结构体。
  3. 结构体不能嵌套。

变量类型决定外部形状，而查询决定字段：

变量类型查询结果变量值
结构体一行一个结构体
结构体多于一行错误
结构体没有行变量未设置
结构体数组少于 10,000 行每行一个结构体
结构体数组没有行空数组

每次成功运行都会重新派生字段，将新增、删除、重命名和类型更改应用到变量。如果某个小部件绑定的字段不再被新查询返回，该绑定就会失效。在更改结构体查询所选择的列之后，请检查您的小部件配置。

返回 NULL 的列会生成一个该字段没有值的结构体。该字段本身仍然存在于变量上。

结构体查询的要求

每个字段必须恰好来自一列，这对 SELECT 列表提出了一些要求：

  • 每一列都必须有一个可用的名称。 列名会成为字段名，因此它们必须是普通的标识符。请为计算列指定别名，例如 SELECT COUNT(*) AS order_count.
  • 列名必须唯一。 返回两个同名列的查询会失败；请使用以下方式为每个列指定别名： AS.
  • Struct、map 和 binary 类型的列不能作为字段。 使用以下方式将 struct 列展开为每个字段一列： @alias.column.* 而不是直接选择该 struct 列。
  • 支持数组列。 类型为 ARRAY<STRING> 的列会生成一个包含字符串列表的字段。不支持将 struct 数组作为字段。

以下示例展示了绑定表 @t 在这些规则下的应用，该表包含一个 name 列和一个 addr struct 列，其中包含一个 city 字段：

SELECT name FROM @t;          -- Struct: {'name': 'Ada'}
SELECT @t.addr.* FROM @t;     -- Struct: {'city': 'Springfield'}; note that this requires the column reference @t.
SELECT @t.addr FROM @t;       -- Error: expand the struct column instead
SELECT name, name FROM @t;    -- Error: duplicate column name
SELECT COUNT(*) FROM @t;      -- Error: give the column an alias
使用 .* 展开现有的 struct 属性

当您的对象类型已经具有 struct 属性时，无需手动列出其每个字段。将 .* 追加到该属性以将其展开为每个字段一列，这些列随后会成为您的 struct 变量的字段：

Copied!
1
2
SELECT @t.structField.*
FROM @t;

具有 street, city日 postalCode 个字段的 struct 属性会生成包含同样三个字段的 struct 变量。选择不带 .* 的属性会失败，因为 struct 列本身不能作为字段。要将展开的属性与其他列组合，请同时选择两者： SELECT @t.name, @t.addressStruct.* FROM @t。请确保展开后的字段名称与其他列名不冲突。

保存 struct 查询

对于 struct 值的变量，查询及其派生字段会一起保存。 保存并运行 会先运行查询，只有在查询成功且其列可以支撑 struct 时，才会保存查询及其派生的字段。如果查询执行失败或返回的列无法支撑 struct，则不会保存任何内容。您的草稿会保留在编辑器中，之前保存的查询和字段仍然有效。失败信息会同时显示在查询预览上方以及编辑器中的行内错误提示中。

保存的字段还会在变量于运行时解析时进行验证，因此如果已发布应用的基础数据发生了变化，系统会报告一个指明受影响列的错误，而不是解析为不同的结构。

使用 AIP 生成 SQL

您可以根据自然语言描述生成查询，而无需手动编写。输入描述您想要计算的值的提示，AIP 会使用您配置的表、参数以及变量的输出类型生成 SQL 查询。AIP 仅限于本体论 SQL 方言以及您已定义的别名，因此生成的查询只会引用该变量可用的表、列和参数。生成的查询会填充到编辑器中并自动运行；请查看结果，并在需要时编辑查询。

示例：使用窗口函数对对象进行排名

窗口函数是使用 SQL 查询变量的常见原因。以下查询绑定一个 @employees 对象集和一个 @department 参数，并返回所选部门中收入最高者的姓名：

SELECT name
FROM (
    SELECT name AS name,
           RANK() OVER (ORDER BY salary DESC) AS salary_rank
    FROM @employees
    WHERE department = @department
)
WHERE salary_rank = 1;

示例：以 struct 形式返回摘要

struct 变量可以在一个查询中携带多个相关的计算值，供 widget 逐字段绑定。以下查询返回一个汇总所选部门信息的 struct：

SELECT COUNT(*) AS headcount,
       AVG(salary) AS average_salary,
       MAX(salary) AS top_salary
FROM @employees
WHERE department = @department;
