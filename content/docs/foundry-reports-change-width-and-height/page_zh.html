更改宽度和高度

Foundry 报告中的内容按行组织，每行至少包含一个 widget。

更改行宽

每行可以以三种宽度之一显示：

  • 全宽。 填充页面宽度的 100%。最小压缩至 600px 。
  • 中等。 以 820px的宽度显示。最小压缩至 540px 。
  • 窄。 以 570px的宽度显示。最小压缩至 540px 。

默认情况下，添加到报告中的 widget 将以中等宽度显示在各自的行上。

更改一行的宽度

要更改一行的宽度：

  1. （如有需要） 切换至编辑模式。

  2. 值 布局控制 按钮（位于行的右侧）。



  3. 选择新的宽度（窄, 中，或 全宽).



更改所有内容的宽度

为方便起见，您还可以通过一次操作将报告中的所有内容更改为 全宽 宽度。参见 将报告中的所有内容显示为全宽 了解详情。

更改行高

大多数 widget 也可以垂直调整大小。这对于调整图表以及其他会拉伸以填充其可用容器的内容非常有用。

自动高度

默认情况下，widget 会自动调整自身大小，并根据 widget 类型选择合理的初始高度。

某些 widget 会始终自动调整大小以适应其内容，无法手动调整。具体包括：

  • 文本 widget（参见 在报告中添加文本)
  • 表格 widget（参见 向报告中添加表格扩展而来），以及目标项目的
  • 图像和视频（参见 向报告中添加新的图像或视频).

从其他 Foundry 应用程序添加的 widget 通常可以垂直调整大小。

固定高度

在允许的情况下，更改行的高度会将高度“固定”为一个可能与自动值不同的值。

要手动调整行的高度：

  1. （如有需要） 切换至编辑模式。

  2. 将鼠标光标移到某个 widget 或某行 widget 的底部边缘上。

  3. 点击并按住 行调整大小 按钮（如果出现）。



  4. 向上或向下拖动以调整大小，然后释放鼠标。



将报告中的所有内容显示为全宽

如有需要，您可以调整报告中各个行的大小（参见 更改行的宽度和高度）。但是，某些报告可能包含许多在 全宽 宽度下看起来最佳的 widget。为方便起见，您可以通过一次操作将报告中的所有内容更改为 全宽 宽度。

要将整个报告更改为 全宽 宽度：

  1. （如有需要） 切换至编辑模式。

  2. 值 设置按钮 （位于应用程序页眉中）。



  3. 点击设置菜单下的 以全宽显示 （在出现的菜单中）。
