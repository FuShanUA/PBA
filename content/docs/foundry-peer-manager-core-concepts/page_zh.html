核心概念

本页面介绍了与 Peer Manager 相关的对等互连核心概念。

对等连接

建立后，您可以使用对等连接在不同 空间 之间共享数据，这些空间分属两个 Foundry 注册。对等连接的配置控制可以对等互连的数据类型、数据对等互连的方向，以及一组 分类 和其他 标记 可以通过该连接进行对等传输。

数据类型

通过对等连接，您可以对等传输 Foundry 对象， 在 Object Explorer 中配置的对象集，以及 Gotham 文件。

目前尚无法通过已建立的对等连接对其他 Foundry 资源进行对等连接，例如 Workshop 应用。但是，您可以使用 Marketplace 来分发 Workshop 应用程序以及其他 Foundry 数据产品。当 Marketplace 和对等互连结合使用时，您将能够跨各个注册创建实时协作工作流。

连接安全性

对等连接的安全性定义了允许通过该连接进行对等互连的安全标记集合。

对等连接上的 分类 标记定义了允许进行对等互连的最高分类。带有 基于分类的访问控制 (CBAC) 标记级别不超过对等连接 CBAC 的资源将被允许进行对等互连。

对等连接上的 标记 提供了额外一级的访问控制，因为要对等的资源上的任何标记 都必须 包含在对等连接的安全设置中。

只有满足对等连接安全要求的数据才能通过该连接进行对等。请查看下表，以帮助您了解对等安全在实践中如何运作。

对等连接管理权限

用户只有在能够管理关联的本地空间时，才能管理对等连接。

您的注册信息如何显示给远程对等方

当您与另一个注册建立对等关系时,远程对等注册上的用户可以通过其 平台标题来识别您的注册,该标题由 注册管理员 在控制面板中进行配置。对等管理器会在 远程注册 下方显示平台标题,位于 对等连接 选项卡中，与已配置的对等连接一同显示。

任何参与对等连接的注册都应配置平台标题，以确保远程对等方能够清楚地识别该注册。如果未设置平台标题，Peer Manager 将回退到描述性可能较低的标识符，例如空间名称。

除了平台标题之外，Peer Manager 还会将您注册的中等尺寸 平台徽标 在其配置完成后共享给远程对等方。

对等作业

Peer Manager 通过对等作业在空间之间发送数据。每个作业对应于按特定方向发送的特定数据类型。Peer Manager 会将给定连接的所有作业列在该连接的 概览 页面。
