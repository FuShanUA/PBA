在开始本教程的这一步骤之前，你应该已经完成了 建模项目设置。在本教程中，你可以选择在 Jupyter® 笔记本中 或在 Code Repositories 中训练模型。Jupyter® 笔记本适用于快速、迭代式的模型开发，而代码仓库适用于生产级的数据和模型管道。

在本教程的这一步骤中，我们将在 代码仓库中训练模型。本步骤将涵盖：

2c.2 如何拆分用于测试和训练的特征数据

@transform.spark.using(
    features_and_labels_input=Input("<YOUR_PROJECT_PATH>/data/housing_features_and_labels"),

2c.3 如何在 Code Repositories 中编写模型训练逻辑

Foundry 中的模型 由两个组件组成：模型工件（模型训练作业中生成的模型文件）和模型适配器（一个描述 Foundry 应如何与模型工件交互以执行推理的 Python 类）。

模型训练模板由两个模块组成： model_training 用于训练作业， model_adapters 用于模型适配器。

模型依赖项

模型训练几乎总是需要添加包含模型训练、序列化、推理或评估逻辑的 Python 依赖项。Foundry 支持通过 conda 添加依赖项规范。这些依赖项规范用于创建解析后的 Python 环境，以执行模型训练作业。

在 Foundry 中，这些已解析的依赖项会自动与您的模型打包在一起，以确保您的模型自动具备执行推理（生成预测）所需的所有逻辑。在本示例中，我们将使用 pandas 和 scikit-learn 来生成我们的模型，并使用 dill 来保存我们的模型。

这有助于在需要时与其他团队有效沟通上游问题和平台问题，并减少解决问题的时间。它还可以提高平台的调试技能。 在左侧边栏中，选择 ”面板中找到。 例如，要使用 并为 scikit-learn, pandas日 dill添加依赖项。然后选择 提交 以创建解析后的 Python 环境。

模型适配器逻辑

模型适配器 为 Foundry 中的所有模型提供标准接口。该标准接口确保所有模型都可以立即在生产应用中使用，因为 Foundry 会处理加载模型及其 Python 依赖项的基础设施、公开其 API 以及与您的模型进行交互。

为了实现这一点，您必须创建一个 ModelAdapter 类的实例来充当此通信层。

需要实现 4 个函数：

  1. 模型保存和加载： 为了重用您的模型，您需要定义模型的保存和加载方式。Palantir 提供了许多 默认方法 用于序列化（保存），在更复杂的情况下，您可以 实现自定义序列化 logic.
  2. api: 定义模型的 API，并告知 Foundry 您的模型需要什么类型的输入数据。
  3. predict: 由 Foundry 调用以向您的模型提供数据。您可以在此处将输入数据传递给模型并生成推理（预测）。

import palantir_models as pm


class SklearnRegressionAdapter(pm.ModelAdapter):

    @pm.auto_serialize
    def __init__(self, model):
        self.model = model

    @classmethod
    def api(cls):
        columns = [
            ('median_income', float),
            ('housing_median_age', float),
            ('total_rooms', float),
        ]
        return {"df_in": pm.Pandas(columns)}, \
               {"df_out": pm.Pandas(columns + [('prediction', float)])}

    def predict(self, df_in):
        df_in['prediction'] = self.model.predict(
            df_in[['median_income', 'housing_median_age', 'total_rooms']]
        )
        return df_in

from transforms.api import transform, Input
from palantir_models.transforms import ModelOutput
from main.model_adapters.adapter import SklearnRegressionAdapter


def train_model(training_df):
    from sklearn.impute import SimpleImputer
    from sklearn.linear_model import LinearRegression
    from sklearn.pipeline import Pipeline
    from sklearn.preprocessing import StandardScaler

    numeric_features = ['median_income', 'housing_median_age', 'total_rooms']
    numeric_transformer = Pipeline(
        steps=[
            ("imputer", SimpleImputer(strategy="median")),
            ("scaler", StandardScaler())
        ]
    )

    model = Pipeline(
        steps=[
            ("preprocessor", numeric_transformer),
            ("classifier", LinearRegression())
        ]
    )
    X_train = training_df[numeric_features]
    y_train = training_df['median_house_value']
    model.fit(X_train, y_train)

    return model

@transform.using(
    training_data_input=Input("<YOUR_PROJECT_PATH>/data/housing_training_data"),
    model_output=ModelOutput("<YOUR_PROJECT_PATH>/models/linear_regression_model"),
)
def compute(training_data_input, model_output):
    training_df = training_data_input.pandas()
    model = train_model(training_df)

    # Wrap the trained model in a ModelAdapter
    foundry_model = SklearnRegressionAdapter(model)

    # Publish and write the trained model to Foundry
    model_output.publish(
        model_adapter=foundry_model
    )

from transforms.api import transform, Input, Output, LightweightInput, LightweightOutput
from palantir_models.transforms import ModelInput
from palantir_models import ModelAdapter

@transform.using(
    testing_data_input=Input("<YOUR_PROJECT_PATH>/data/housing_test_data"),
    model_input=ModelInput("<YOUR_PROJECT_PATH>/models/linear_regression_model"),
    predictions_output=Output("<YOUR_PROJECT_PATH>/data/housing_testing_data_inferences")
)
def compute(
        testing_data_input: LightweightInput,
        model_input: ModelAdapter,
        predictions_output: LightweightOutput
    ):
    inference_outputs = model_input.transform(testing_data_input)
    predictions_output.write_pandas(inference_outputs.df_out)

2c.6 如何查看模型并将其提交到建模目标

模型构建完成后，您可以通过选择 linear_regression_model 菜单中选择 model_training/model_training.py 文件，或者导航到我们之前创建的文件夹结构中的模型来打开该模型。

模型视图包含模型的训练来源、用于生成该模型的训练数据集、模型 API，以及该模型发布时所用的模型适配器。重要的是，您可以将多个不同的版本发布到同一个模型；这些模型版本可在左侧边栏的下拉菜单中找到。

由于模型版本与训练时使用的特定模型适配器相关联，因此您需要重新发布并构建模型训练流程，才能对模型适配器逻辑进行任何更改。

这有助于在需要时与其他团队有效沟通上游问题和平台问题，并减少解决问题的时间。它还可以提高平台的调试技能。 选择 linear_regression_model 在代码中导航到您创建的模型资产，选择 提交到建模目标 并将该模型提交到您在 本教程第 1 步中创建的建模目标。系统会要求您提供提交名称和提交所有者。这是用于在建模目标中唯一跟踪模型的元数据。将模型命名为 linear_regression_model 并将您自己标记为提交所有者。
