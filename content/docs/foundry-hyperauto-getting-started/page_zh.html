HyperAuto V2 入门

本指南适用于 HyperAuto V2。要开始使用 HyperAuto V1，请参阅 HyperAuto V1 文档.

如果您没有与系统的直接连接，并且正在处理静态数据，您可以创建一个 基于文件夹的管道 而不是按照以下步骤操作。

按照以下步骤创建您的第一个 HyperAuto 管道：

  1. 在 Data Connection 中导航至 支持的源 您想要从中同步数据。您可以在 Foundry 实例的 数据连接 应用中找到所有源的列表。

  2. 从源的特定概览选项卡中，选择 创建 HyperAuto 管道 以打开 HyperAuto 管道向导。

  3. 定义新的 HyperAuto 管道资源的名称和位置，以及任何相应的生成资源。HyperAuto 管道必须与输入数据集位于同一项目中。

  4. 如果适用，请选择源子系统（例如 SAP 源的 "context"），以及摄取方法（批量或流式，请参阅 架构 以了解更多信息）。

  5. 在监听器设置向导的 输入配置 步骤中，选择您想要从中处理数据的源表。您可以单独选择表、按类别（"模块"）选择或按工作流选择。您还可以选择没有 Data Connection 同步的表作为输入。如果所选输入已有同步，HyperAuto 将默认使用最近的一次同步。要重新配置所选输入，请将鼠标悬停在 配置输入 表格按钮上。在此菜单中，您可以选择其他现有同步或创建新同步。

  6. 确定所需的管道配置，包括语言和转换选项。有关更多信息，请参阅 配置选项.

  7. 选择 创建 HyperAuto 管道。您的新 HyperAuto 管道将被创建并开始处理数据。您将被重定向到管道的概览页面，您可以在其中监控生成进度。

  8. 生成成功后，您可以使用概览页面来管理和监控管道及其相关资源，包括输入同步和数据集，以及输出数据集和对象。

    • 选择 查看构建器管道 以打开只读的构建器管道，并更详细地查看转换逻辑。

    • 直方图 配置 选项卡显示 HyperAuto 管道的输入和管道配置。选择 编辑 在此选项卡中新建一个 提案 并更新配置。
