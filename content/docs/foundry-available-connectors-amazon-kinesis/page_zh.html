性能与限制

该连接器始终为源 Kinesis 流上的每个活跃分片使用单个消费者线程。

流式同步旨在成为持续一致运行的长期任务。根据预期结果的不同，流式同步的任何中断都可能导致服务中断。

目前，流式同步存在以下限制：

  • 对于旧版 ）或您的代理网络（如果使用 源，任务会在代理维护窗口期间（通常每周一次）重启以获取升级。预期停机时间少于五分钟。为实现高可用性，请通过两个维护窗口互不重叠的代理进行连接。

消息顺序

Kinesis 连接器可保证具有相同 partition_key的消息按顺序送达。具有不同 partition_key 值的消息可能会以任意顺序处理。

网络

连接器必须有权访问 AWS Kinesis API，如果使用 STS 角色，则还必须有权访问 AWS STS API。

  • Kinesis API： https://kinesis.<region>.amazonaws.com
  • STS API： https://sts.<region>.amazonaws.com

将数据导出到 Kinesis

该连接器支持在 Data Connection 中导出到外部 Kinesis 流。
