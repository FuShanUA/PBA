KNN 联接

支持环境：批处理

根据距离度量，为左侧数据集中的每一行返回右侧数据集中最近的 'k' 行。

转换类别：联接

已声明的参数

  • 左侧选择列的条件： 左侧输入架构中的所有列都将接受测试，以判断它们是否符合此条件。如果符合，该列将被选中并包含在输出中。
    ColumnPredicate
  • 用于选择右侧列的条件： 右侧输入 schema 中的所有列都会经过测试，以判断它们是否匹配此条件。如果匹配，该列将被选入输出。
    ColumnPredicate
  • 距离度量表达式： 左侧和右侧数据集各列之间的距离度量表达式。例如：Levenshtein 距离。
    Expression<Numeric>
  • K 最近邻： 要返回的最近邻行数，即如果 k=2，则输出行数将至少翻倍，并且会从右侧连接最近的 2 行。如果出现并列情况，则可能会返回更多行。
    Literal<Integer>
  • 左侧数据集： 要在连接中使用的左侧数据集。
    表格
  • 排名列名称： 用于存储距离排名的列的名称。
    Literal<String>
  • 右侧数据集： 要在联接中使用的右侧数据集。
    表格
  • 可选 来自右侧的列的前缀： 要添加到右侧所有列的前缀。
    Literal<String>

示例

示例 1:基本情况

参数值:

  • 左侧要选择的列的条件:
    columnNameIsIn(
     columnNames: [tail_number, airline],
    )
  • 右侧要选择的列的条件:
    columnNameIsIn(
     columnNames: [fuzzy_airline, home_airport],
    )
  • 距离度量表达式：
    alias(
     alias: distance,
     expression:
    levenshteinDistance(
     ignoreCase: true,
     左： airline,
     右： fuzzy_airline,
    ),
    )
  • K 近邻： 2
  • 左侧数据集： ri.foundry.main.dataset.left
  • 排名列名称： rank
  • 右侧数据集： ri.foundry.main.dataset.right
  • 来自右侧的列的前缀： null
