Flow Capture

Flow Capture 目前处于 beta 开发阶段，可能无法在您的注册环境中使用。功能在开发过程中可能会发生变化。要启用 Flow Capture，请联系您的平台管理员以 修改应用程序访问权限 （在 Control Panel 中）。

Flow Capture 是一款用于在 Foundry 中录制工作流并将其转换为结构化、可自定义文档的工具。当您在录制会话中浏览应用程序时，它会记录鼠标点击、屏幕截图、可选的音频（附带转录）以及上下文元数据。捕获的素材可以进行编辑、与提示词和模型选择相结合，并转换为您可以查看、编辑和导出的 Markdown 文档。

应用程序访问权限

要激活 Flow Capture，请在 Control Panel 的 应用程序访问 部分中启用它。您可以 配置检查点 ，以便在用户执行敏感操作（例如导出生成的内容）之前向其发出警告。

主要功能

屏幕截图

Flow Capture 为用户提供了自动捕获和手动捕获选项。屏幕截图会存储为单独的快照资产，既可以结合上下文包含在最终文档中，也可以作为独立图像包含在内。

带转录的录音

在 Flow Capture 会话期间，您可以选择录制麦克风音频。音频文件及其转录会作为资产存储，并可通过提供额外的上下文和指令来丰富文档生成。

图像编辑

直接在 Flow Capture 中对捕获的图像进行裁剪和模糊处理，以便在生成或导出之前移除或遮盖敏感区域。

可自定义内容

添加提示词以提供额外的上下文（例如风格指南、期望的结构或额外指令），从而调整所生成 Markdown 的语气、详细程度和结构。

编辑模式和查看模式

Flow Capture 提供编辑模式和查看模式，让用户能够创建和预览生成的文档。查看模式以演示或预览的形式显示生成的文档，而编辑模式可用于修改生成的 Markdown、创建更多录制内容，以及在重新生成、保存或导出之前调整图像或转录。

LLM 模型选择与模板

选择系统提示词或模板以及模型,以影响内容的生成方式。常规文档和功能请求是不同内容类型的示例。模型和模板会影响风格、长度以及技术细节的详细程度。

导出

以多种格式导出最终文档,例如 Notepad 文档、 Walkthroughs、PDF 或包含图像和 Markdown 的 zip 压缩包。

用户有责任确保对所创建的 Flow Capture 资源应用与标记和基于组的访问相关的适当安全检查，以反映所捕获内容的安全检查。
