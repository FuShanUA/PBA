创建接口

按照以下步骤在 本体论管理器.

  1. 首先，通过检查 本体论 下拉菜单（位于左侧面板顶部）来确认您正在使用所选的本体论。

  2. 要创建新接口，您可以执行以下任一操作：

    • 在页面右上角，选择 New > Interface.
    • 在左侧面板中，选择 Interfaces > + New interface 图表工具 “资源” 部分。然后，从 接口 页面上，选择 新接口 （位于屏幕右上角）。

  3. 帮助页面的第一页提供了有关接口的信息。选择 属性，然后选择.

  4. 输入接口的显示名称和 API 名称。您还可以选择性地提供接口描述并选择合适的图标。

  5. 为接口添加属性。您可以在接口上本地定义属性（推荐）或使用 共享属性。对于每个属性，请选择其是否为 必填 or 可选.

    对于 必填 属性，任何实现该接口的对象类型都必须提供从本地属性到接口属性的映射。对于 可选 属性，在实现时可以跳过映射。在构建 Marketplace 包时，可选属性非常有用，可让您迭代接口而不会引入难以解决的升级阻碍。

  6. 选择要保存此接口的项目，然后选择 创建.

  7. 返回 Ontology Manager 后，选择 保存 在右上角 将更改应用到您的本体论.

创建接口关联类型（可选）

如果您希望此接口关联到另一个接口或对象类型，可以选择性地添加任意 接口关联类型 到该接口。

  1. 选择 关联类型约束 在左侧面板中。
  2. 然后,选择 创建新关联类型约束 在右上角。

如果您的建模用例需要接口关联类型，则任何实现该接口的对象类型都必须添加满足接口关联类型约束的新建或现有关联类型。

创建接口操作类型约束（可选）

如果您希望接口在实现它的各对象类型之间定义预期的操作能力，可以选择性地添加 接口操作类型约束 到该接口。

  1. 选择 操作类型约束 在左侧面板中。
  2. 选择 循环布局模块选择与嵌入式模块小部件模块选择类似，需要选择一个子模块。构建者可以通过指南针资源选择器选择现有模块，或者使用.
  3. 添加约束元数据，选择是否必须实现，并配置任何参数约束。

如果您的建模用例需要接口操作类型约束，则任何实现该接口的对象类型都必须将该约束映射到满足接口操作类型约束的具体操作类型。
