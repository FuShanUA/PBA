自动生成输入数据

在 Pipeline Builder 中创建 手动输入数据集 时，您可以生成概念数据来填充您的数据集。

手动输入数据集和概念数据生成不适用于 CBAC 技术栈上的快速（轻量级）管道。如果您需要此功能，请改用标准（Spark）管道。

为此，在您的手动输入数据集中，选择 生成概念数据.

在左侧，选择您要为其生成数据的列。然后，在 自动填充方式 字段中，选择该列应包含的数据类别。要查看概念数据示例的效果，请选择 示例.

要指定要生成的行数，您可以为 选择行数 字段中，复制在 Quiver 仪表板中定义的对象输入名称。

如果您想预览手动输入的表，请选择 预览。这将在底部面板中打开一个名为 预览生成的数据.

配置完列后，选择 生成表 （位于右侧）。

组织管理员 生成表 将覆盖手动输入表中任何先前存在的数据。

如果您想保留某些列的值，可以使用特定列旁边的锁定选项。当列被锁定后，即使重新生成表，该列中的值也将保持不变。

您还可以使用另一个数据集来生成外键。这会将该数据集与另一个数据集中的列进行关联。

Pipeline Builder 中可以自动填充的其他数据示例包括：

  • 城市： 生成随机城市名称。
  • 公司： 虚构的公司名称。
  • 常量： 始终生成相同的值。
  • 国家代码： 两位字母的国家代码。
  • 电子邮件： 有效但为概念性的电子邮件地址。
  • 名字： 包含概念性名字的字符串。
  • 外键： 将该数据集与另一个数据集中的列进行关联。
  • 全名： 将名字和姓氏组合成单个字符串。
  • 姓氏： 概念性姓氏。
  • 显示 从预定义列表中选取加权随机值。
  • 空值： 始终生成 null。
  • 其中之一： 从加权生成器列表中随机选择。
  • 街道地址： 随机街道地址。
  • 模板： 使用辅助函数根据模板生成随机字符串。
  • 美国州名： 随机美国州名。
  • 美国州代码： 随机的美国两位字母州名缩写。
  • 美国邮政编码： 位于指定州内的邮政编码。
  • UUID： 通用唯一标识符。

使用 LLM 生成数据

如果现有的自动填充类别均无法满足您的需求，您可以使用大型语言模型（LLM）根据您的自定义列描述生成数据。

要选择 LLM 选项，请在 自动填充方式，然后使用 使用 LLM 生成.

下选择。在列提示中，输入您要生成数据的清晰描述。您可以通过键入来引用其他列 /[name of column]

强烈建议提供示例单元格值，以帮助 LLM 理解您期望的数据类型和格式。您可以在以下位置为 LLM 提供示例单元格值以供参考 示例单元格值.

LLM 生成的数据最多可预览 10 行。

生成大量行或使用复杂提示可能需要长达一分钟的时间。
