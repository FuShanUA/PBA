显示建议值

在向报表添加参数后（参见 从其他 Foundry 应用程序添加参数），您可以将其关联到数据集以显示 建议值 （来自特定列）。您也可以手动输入一组要显示的建议。

显示建议值可以让报表编辑者和查看者更容易选择有效的参数值，并了解该参数可接受的取值范围。

建议值可以为 String 类型和 Number 类型的参数显示，但不能为 Date 类型的参数显示。

从数据集添加建议值

  1. （如有需要） 切换至编辑模式。
  2. 点击参数旁边的齿轮图标，打开其“参数设置”菜单。
  3. 点击设置菜单下的 显示建议（来自关联列）.
  4. 点击设置菜单下的 关联到某列的值…，并选择一个数据集列（如果您在此处没有看到任何列，请参见 故障排除部分 下方内容）。如果报表中添加的构件有多个输入数据集，请向下滚动以查看所有输入数据集的列。
  5. 点击设置菜单下的 保存.

现在，当您点击参数的输入框内部时，应该会看到来自该数据集列的建议值列表。

手动添加建议值

要为特定参数添加一组建议值而不将其关联到数据集，请添加 手动建议.

  1. （如有需要） 切换至编辑模式。

  2. 点击齿轮图标 （位于参数旁边）以打开其“参数设置”菜单。

  3. 点击设置菜单下的 显示建议（来自关联列）.

  4. 点击设置菜单下的 关联到某列的值…，并选择一个数据集列（如果您在此处没有看到任何列，请参见 故障排除部分 下方内容）。

  5. 点击设置菜单下的 或手动输入值.

  6. 输入一组建议，每行一条建议。



  7. 点击设置菜单下的 保存 在“手动输入的建议”对话框中。

  8. 点击设置菜单下的 保存 在“参数设置”对话框中。

现在，当您点击参数的输入框内部时，应该会看到您刚刚输入的建议值列表。

移除建议值

要完全移除特定参数的建议值：

  1. （如有需要） 切换至编辑模式。

  2. 点击参数旁边的齿轮图标，打开其“参数设置”菜单。

  3. 点击设置菜单下的 显示建议（来自关联列） 以禁用建议：



  4. 点击设置菜单下的 保存.

当您点击参数的输入框内部时，将不再看到建议值列表。此时，您需要手动输入值。

故障排除

关联列中存在的建议值未显示

您可能会在参数上看到警告标志，并显示错误消息 Due to a high number of distinct values, the list of suggestions is incomplete. Please choose from the list of precomputed values or enter a new value.

报表使用 Foundry Stats 服务来填充建议值。出于性能原因，如果关联列的不同值数量很多，报表可能不会显示该列中的所有不同值。如果某个特定值未出现在建议列表中， 您可以在参数下拉框中输入任意值 以照常使用该值。您可以联系您的 Palantir 代表，以了解有关 Foundry Stats 计算限制的更多信息。

关联到列后未看到任何建议值

如果支撑数据集是最近添加或更新的，您可能会在看到建议值之前遇到延迟。这些值通过 Foundry Stats 服务填充。此问题通常会在几分钟后自行解决。

如果您仍然遇到问题，下一步请导航到支撑数据集，查看该数据集是否已计算统计信息。在 dataset-app 中，查看“大小”字段。如果有一个链接显示 计算以查看所有统计信息，请点击该链接，等待统计信息计算完成，然后查看报表中是否出现建议值。如果您继续遇到问题，请联系您的 Palantir 代表。

未看到任何可关联的数据集列

您需要先向报表添加至少一个数据支撑的构件，然后才能在“参数设置”菜单中看到建议的数据集列。例如，向报表添加 Contour 看板（来自 Contour）后，将显示该 Contour 看板上游所有数据集的所有列。

未看到来自其他可关联数据集的列

在列下拉菜单中，将显示为报表中小组件提供数据的数据集中的列。假设您向报表中添加了一个基于数据集 A 的图表。在另一个路径中，您使用了数据集 B，但数据集 B 的任何后代都未添加到报表中。 只有来自数据集 A 的列才会出现在建议值下拉菜单中。要将参数关联到数据集 B，您可以通过 join 或 union 使数据集 B 成为图表的输入。或者，您也可以添加一个使用数据集 B 作为输入的小组件。

数据集使用行级策略服务（Row-Level Policy Service），但无法将参数关联到列

如果数据集使用行级策略服务（Row-level Policy Service），则无法将参数关联到该数据集中的列。您可以手动添加建议值。

在受限视图（Restricted View）下将参数关联到列

如果您基于受限视图（Restricted View）进行构建，则无法将参数关联到列。您可以手动添加建议值。
