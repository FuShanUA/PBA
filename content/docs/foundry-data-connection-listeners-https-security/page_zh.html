HTTPS 监听器安全性

HTTPS 监听器与标准的 Foundry 数据摄取不同,因此在启用连接之前,请确保您已了解这些安全范式。

请求授权

HTTPS 监听器的请求接口由外部系统定义,因此它们不符合标准的 Foundry 身份验证或授权机制。相反,监听器会实现由这些外部系统制定的安全协议,而这些协议差异很大。

Palantir 不对这些外部系统协议的适用性或有效性做出任何保证。您有责任确保自己了解每个协议针对传入的请求和数据提供了哪些保证、未提供哪些保证。

每个监听器所实现的具体协议可以在监听器设置向导的 配置 步骤中找到,也可在外部系统的文档中找到。

脱敏与数据安全

有时会对传入数据执行最低限度的脱敏操作。需要注意的是,这些脱敏机制属于尽力而为,Palantir 无法保证令牌等敏感数据会从请求体中被完全脱敏。

对于 HTTPS 监听器,必须 同时保护您的监听器和输出流的安全。这包括通过将两者置于受限项目来限制对它们的访问，以及在必要时将 标记 应用于监听器。

子域名

可以将 HTTPS 监听器挂载到专用子域名，从而实现细粒度的入口控制、全面的治理工作流，并将安全性较低的端点与环境的主要注册域名隔离。 了解有关监听器子域名的更多信息。

端点轮换

如果监听器的端点遭到入侵，可以将其轮换为新的端点。 了解有关端点轮换的更多信息。
