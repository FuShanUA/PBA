值类型

值类型 是围绕 字段类型 的语义包装器，其中包含的元数据和约束可以增强类型安全性、提升表达能力并提供额外上下文。值类型封装特定领域的数据类型，并以可在整个平台中复用的方式实施数据验证。与定义和构建本体论的对象类型、属性、关联类型或其他类型不同，值类型与平台中的 空间 相关联。一个空间只能包含一个本体论。值类型只能在其定义所在的空间中使用。值类型不可用于默认本体论。

数据集 字段类型 和属性 基本类型 反映了编程语言中的基元类型。这些类型与领域无关，且不提供任何领域上下文。相比之下，值类型捕获数据的上下文和语义含义，并集中进行数据验证。用户直接从值类型中定义和使用含义，而无需依赖列名或属性描述等周边信息。值类型还会对 Builder 管道和本体论中的数据强制执行其验证约束，因此数据集成人员和本体论管理人员可以确保其数据流和模型中语义类型的正确性。

例如，用户可以定义一个带有正则表达式约束的“email”值类型，以确保使用该值类型的任何属性都表示有效的电子邮件地址。这样，此值类型便可在多个对象类型和管道中重复使用，而无需为每个此类属性复制验证逻辑。此外，使用此值类型的每个属性都会被明确理解为包含电子邮件地址。

由于值类型旨在跨多个管道和对象类型重复使用，因此它们 受到权限管控 以确保用户能够在需要的地方应用它们，并 有版本管理 以处理破坏性和非破坏性修改。

首先，请学习如何 创建新的值类型 或 使用现有值类型 （在属性上）。
