HyperAuto V2 支持的数据源

本页描述了控制对 Foundry 中 SQL 功能访问的 数据连接 HyperAuto V2 支持的数据源类型。

SAP

数据源连接

HyperAuto V2 支持来自以下来源的数据： Foundry SAP 数据源。 支持 SAP ECC 和 S/4HANA，无论是否配备相应的 SLT 复制服务器（流式传输需要 SLT）。数据源必须满足以下最低要求才能获得支持：

  • SAP 托管数据源（magritte-sap-source）版本： 1.25.0
  • Palantir Foundry Connector for SAP 版本： SP26 (2.26.0)

有关如何在 Foundry 中设置 SAP 的更多信息，请查阅 SAP 安装加载项指南.

基于文件夹的数据

HyperAuto V2 也可以在没有直接连接的情况下，基于 SAP 数据的静态副本运行。在这种情况下，您需要将以下数据字典表作为数据集上传：

  • DD02L (SAP Tables)
  • DD02T (SAP DD: SAP Table Texts)
  • DD03L (Table Fields)
  • DD04T (R-3 DD: Data element texts)
  • DD05S (Foreign key fields)
  • DD08L (R-3 DD: relationship definitions)

所有需要使用 HyperAuto 处理的后续表，都必须作为 Foundry 数据集上传到单个文件夹中。

有关 HyperAuto 如何处理静态数据的更多信息，请查阅 基于文件夹的 SAP 管道文档.
