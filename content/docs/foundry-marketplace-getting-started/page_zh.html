开始使用

本教程将介绍基本的安装流程。有关所有可用选项的完整参考，请参阅 安装产品.

在本教程中，您将使用一个包含汽车零部件问题的示例数据源安装一个告警收件箱应用程序，我们已将该数据源作为独立的 Marketplace 产品提供。

首先，在您的 Foundry 实例中导航到 Marketplace 并搜索 Marketplace Getting Started Tutorial。如果您找不到这些产品，请联系 Palantir Support 以验证您的访问权限。

选择要安装的产品

在搜索结果中，选择 创建新安装 （位于右上角）。这将启用选择模式，允许您勾选每个产品卡片上的复选框。选择 Marketplace Getting Started Tutorial - Alert Inbox 和 Marketplace Getting Started Tutorial - Datasource 两个产品。选中这两个产品后，选择 创建 2 个新安装 （位于页面底部）。

创建安装任务

A 创建安装任务 对话框将会出现，允许您一次性配置两个产品的安装位置。选择一个项目，然后选择 创建 以创建安装任务草稿。有关所有可用设置的完整说明，请参阅 创建安装任务.

常规

创建安装任务后，您将进入安装任务草稿的 常规 页面。该页面显示一个依赖关系图，展示所选产品之间的相互关系。在本教程中， Alert Inbox 产品依赖于 Datasource 产品。

左侧面板显示草稿的导航，包括 输入 和 输出 页面。关联产品面板允许您添加可用的关联产品，以完成草稿中的输入。

输入

选择 输入 （位于左侧面板）。由于 Datasource 和 Alert Inbox 产品都包含在同一个安装任务中， Car Part Issues 数据集输入（由 Alert Inbox 所需）会自动由 Datasource 产品的输出完成。已完成的输入默认处于隐藏状态。

要查看已完成的输入，请选择 查看设置 ，然后启用 显示由关联产品完成的输入。您将看到 Car Part Issues 数据集及其列映射（由 Marketplace Getting Started Tutorial - Datasource 产品。

直方图 输入 页面显示尚未完成的其余可选输入。在本教程中，您无需配置任何其他输入。诸如 允许本体论架构迁移 和 本体论安装前缀 等可选输入可在需要时进行配置，但并非安装成功所必需。

您可以使用列表顶部的控件按类型搜索、筛选和分组输入。选择某个输入将显示其 配置 和 下游 标签页（位于右侧面板）。

输出

选择 输出 （位于左侧面板）。该页面提供安装将创建的所有资源的摘要，并按类型分组。

对于 Alert Inbox 产品，您将看到以下输出：

  • 对象类型： Workshop Design Hub - Car Part Issue
  • 操作类型： Reopen Car Part Issue, Workshop Design Hub - Close Car Issue, Workshop Design Hub - Edit Car Issue Details
  • 数据集： Workshop Example - Car Part Issues
  • Workshop 应用程序： Marketplace Tutorial - Alert Inbox

选择某个输出将显示其 配置 标签页（位于右侧面板），显示将要生成的内容的详细信息。

安装

对配置满意后，选择 安装 （位于右上角）以开始安装。您将进入安装任务页面，可以在其中监控进度。安装完成后，选择 查看安装 （位于右上角）。

打开您的应用程序

从您的安装中，在新标签页中打开您的 Marketplace Tutorial - Alert Inbox 应用程序。您的 Car Part Issue 对象可能需要几分钟时间进行索引，在此之前您的应用程序将不可用。

您现在拥有一个告警收件箱 Workshop 应用程序，可帮助您分类处理 Car Part Issues - Source 问题。只要所需的输入列存在，您就可以使用任何问题源再次安装此应用程序，以将其用于新的用例。
