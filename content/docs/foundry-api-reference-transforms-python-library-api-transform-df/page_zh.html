transforms.api.transform_df

transforms.api.transform_df(output, **inputs)

将包装的计算函数注册为 DataFrame 转换。

该 transform_df 装饰器用于从计算函数构造一个 Transform 对象，该计算函数接受并返回 pyspark.sql.DataFrame ↗ 对象。类似于 transform() 装饰器，输入名称将成为计算函数的参数名称。但是， transform_df 仅接受单个 Output 规范作为位置参数。计算函数的返回值也是一个 DataFrame ↗ ，并会自动写入到单个输出数据集。

>>> @transform_df(
...     Output('/path/to/output/dataset'),  # An unnamed Output spec
...     first_input=Input('/path/to/first/input/dataset'),
...     second_input=Input('/path/to/second/input/dataset'),
... )
... def my_compute_function(first_input, second_input):
...     # type: (pyspark.sql.DataFrame, pyspark.sql.DataFrame) -> pyspark.sql.DataFrame
...     return first_input.union(second_input)
  • 参数：
    • output (Output) – 该转换的单个 Output 规范。
    • **inputs (Input) – kwargs 由命名的 Input 规范组成。

您可以使用 incremental 装饰器包装 DataFrame 转换，以增量方式运行。当 @incremental 包装 transform_df时，输入会使用 added 模式读取，而写入模式由 @incremental确定。如果您需要使用非默认模式读取或写入，请改用 transform() 装饰器。
