常见问题

标准 Markdown 与自定义文档所需的语法之间有什么区别？

平台内自定义文档与标准 Markdown 之间最重要的区别如下：

  • 页面标题必须使用 @ 语法来指定（@name 用于 overview.md 或 @title 用于非概览页面），而不是 H1 标题（#）。请注意，实际文件名和 @title 不必相同。
  • 所有页面都必须在 ordering.md 文件中指定，才能成功发布。
  • 所有页面都必须具有 章节注解 （例如， @concept 或 @howto）。

平台内自定义文档是否支持更新日志？

不支持，目前不支持自定义文档的更新日志。

自定义文档是否支持分支？

您可以在文档仓库的分支上进行工作，但只有 master 分支会发布到平台内自定义文档。

为什么 Markdown 格式在提示框中无法显示？

由于 标注 是使用 HTML 指定的，因此在标注中的 <div> 和 </div> 之间无法使用 Markdown 格式；例如，要在标注内加粗文本，应使用 HTML 语法 <strong>This is bold text.</strong> 而非 Markdown 语法 **This is bold text.**
