核心概念

接口

Workflow Builder 分为三个区域： 图形、 侧面板和 底部面板。

  1. 图： 图是您构建工作流的核心画布。每个逻辑组件都是一个 节点，而节点之间的连接定义了各节点的执行顺序，以及对象如何从一个节点流向下一个节点。您可以在一个 Workflow Builder 图中拥有多个工作流。

  2. 侧面板： 侧面板提供以下功能：

    • 工作流概览： 工作流的高层级摘要，包括其节点和总体逻辑路径。
    • 可复用参数： 已保存的参数值，可在整个工作流中引用，无需每次重新输入。
    • 预览： 在部署之前，使用示例输入运行工作流以验证其行为。请参阅 预览。
    • 工作流执行： 触发并监控工作流的实时执行。
    • 运行历史： 过去执行的记录，包括其输入、输出和状态。您还可以使用 发送到预览 按钮，将之前的任何一次运行发送到预览。



    • 版本历史： 工作流随时间推移的变更日志，您可以在其中查看或回退到早期版本。

  3. 底部面板： 底部面板包含以下功能：

    • 工作流对象： 查看工作流中对象的表格。您可以筛选对象，并选择要显示的属性类型。



    • 对象监视列表： 通过可自定义的监视列表跟踪对象的流转情况，以便在生产环境中测试、调试和监控您的工作流。

节点类型

在 Workflow Builder 中，通过在图上放置节点并按顺序连接来构建工作流。节点类型包括 触发器, 计算, 使用 LLM, 分叉, 效果， 循环，以及 子图。通过选择底部面板顶部的图标，向图中添加节点。您也可以选择图中当前已有的某个节点，并从菜单中的列表进行选择。

触发器

一个 触发器 节点用于启动工作流。您可以自定义触发器，使其按特定时间计划或在本体论对象发生更改时激活。

计算

使用 计算 节点来运行现有函数或构建新转换，无需输入代码。

要运行现有函数，请选择 运行函数 （该选项位于面板右上角的下拉菜单中）。

如需在不输入代码的情况下构建新转换，请改为从下拉菜单中选择 “构建转换” 选项。

Use LLM

该 use LLM 节点提供了一种在您的工作流中执行大语言模型（LLM）的便捷方式。

您还可以调用本体论工具，供模型在完成任务时使用。工具是可由大语言模型（LLM）用来执行特定操作或检索信息的外部功能或 API，例如操作、对象查询或函数。

选择右侧的工具图标开始使用。

分叉

使用 分叉 节点可根据条件将工作流分支为多个路径，使不同的情况执行不同的逻辑。每个分叉节点都有一个关联的 分叉后 节点，用于指定在所有分叉情况都完成后要运行的逻辑。分叉后节点始终与其对应的分叉节点绑定，无法单独编辑或移动。

分叉可以嵌套在其他分叉和循环中。

效果

使用效果节点可以调用操作或不执行任何操作。操作可以包括编辑本体论对象或发送通知。

使用 不执行任何操作 选项，用于分叉节点中无需执行任何操作的分支。这样，在预览工作流时便能轻松查看采用了哪条路径。

子图

子图允许您将一组节点组合为可重复使用的单元。这样便可以通过将常规节点与子图节点相结合来构建复杂的工作流。要创建子图，请选择 子图 页面顶部的选项。

构建子图的方式与构建任何其他以触发器开始的工作流相同。但是，不是使用标准的 触发器 节点，而是以 子图 节点。

要使用现有的子图，请选择 调用子图 节点选项（在向图中添加节点时）。

子图目前无法在不同的 Workflow Builder 图之间复用。但是，您可以直接复制并粘贴子图，或者复制并粘贴使用子图的工作流。粘贴工作流时，子图会自动添加到您的新 Workflow Builder 图中。

循环

使用 循环 节点来遍历元素列表（例如对象集）。对于每个循环节点，您必须定义以下内容：

  • 元素变量名称： 表示列表中的单个项目，在循环内使用。
  • 索引变量名： 当前项的索引。索引从 0 开始。

每个循环节点都有一个关联的 循环后 节点，用于指定在所有迭代完成后要运行的逻辑。循环后节点始终与其循环节点绑定，无法单独编辑或移动。

循环可以嵌套在其他循环和分支中。

预览

构建工作流后，您可以在发布前对其进行端到端测试。在侧面板中执行预览，无需离开图。

开始预览

选择 + 添加 在您要预览的工作流上，然后选择要针对其运行的输入。您可以选择多个真实对象并同时通过工作流运行它们，而且可以根据需要并行运行任意数量的测试。

查看预览路径

预览运行让您可以观察每个对象在图中的移动过程，并查看它经过的确切路径，包括它在分叉处沿哪个分支行进。

预览是实时的；一旦启动，当您编辑图时，运行会自动重新执行，因此您可以立即查看每项更改的效果。

停止预览模式

要退出预览模式，请选择 暂停 图标（位于图表顶部或侧边栏中），或选择 全部停止 （位于侧边栏顶部）。

查看所选节点的值

您可以检查每个节点的运行情况。要查看某个节点的值，请将鼠标悬停在侧边栏中的该节点上。

由于预览是在真实对象上运行的，因此您可以在发布工作流之前，确认其在实际数据上的行为符合预期。

查看预览输出和编辑

预览完成后，执行路径会自动折叠以显示 输出 部分，其中列出了每个已创建、已编辑或已删除的对象。展开任意行即可查看该对象的确切值。
