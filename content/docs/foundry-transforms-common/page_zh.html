在本地开发中预览转换

在本地开发中使用 VS Code 预览转换有两种主要方法：

  • 使用适用于 Visual Studio Code 的 Palantir 扩展预览 Python 转换
  • 使用基于 Gradle 的本地预览来预览 Java 转换

使用适用于 Visual Studio Code 的 Palantir 扩展进行预览（仅限 Python）

适用于 Visual Studio Code 的 Palantir 扩展支持本地预览功能。请参阅 扩展文档 以了解安装说明。安装扩展并准备好预览环境后，您的转换应会自动显示在 Preview 选项卡中，如下所示。

您还可以为 Python 转换运行本地预览。在本地运行预览时，数据集的部分内容会流式传输到您的计算机。如需更多信息，请查阅 转换预览文档。

基于 Gradle 的 Java 本地预览

本部分详细介绍了在本地开发中预览 Python 和 Java 转换所需的步骤。如需更多背景信息，请查阅我们关于 Java 本地开发的文档。您还可以详细了解 如何预览转换。基于 Gradle 的本地预览会在 Foundry 中远程执行预览。

先决条件和限制

本地预览支持要求本地分支必须跟踪一个远程分支,即本地分支至少需要推送一次,这是在本地开发的现有前提条件之外的额外要求。请注意以下额外限制:

  • 预览 URI 只能由运行该预览的用户访问,且仅在临时期限内可用。

运行数据集预览

在运行预览之前,您必须设置本地开发环境,并确保您的仓库已 升级到最新模板版本。

  1. 运行 ./gradlew displayTransformsList 这将返回所有可用转换的列表。

  2. 运行 ./gradlew datasetPreview --transformId=<transformId> 并将 <transformId> 替换为其中一个转换 ID(上方截图中的蓝色文本),这将返回一个 Foundry 链接,您可以在其中访问已计算完成的预览。

  3. (可选)将 --printMode=table 标志添加到上述命令中,以直接在您的终端中打印所有已预览数据集的前 10 行,而不是为您提供预览链接。

  4. (可选)要在预览中包含输入文件,请添加 --inputFiles=<datasetAlias>:<path> 其中 <datasetAlias> 是所选转换函数的输入数据集之一,而 <path> 是输入数据集中的文件路径。

  5. (可选)要在预览中包含输出文件,请添加 --outputFiles=<datasetAlias>:<path> 其中 <datasetAlias> 是所选转换函数的输出数据集之一，且 <path> 是输出数据集内的文件路径。
