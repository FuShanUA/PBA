音频和转录显示小部件

音频和转录显示小部件基于对象上的 媒体引用 属性来可视化和播放音频。它还可用于通过包含转录片段的对象集来显示转录并与之交互。

要在 Workshop 中直接录制音频,请使用 音频录制小部件,该小部件会将录音上传到媒体引用或媒体集,之后您可以在此处播放和可视化这些录音。

与 媒体预览小部件相比,音频和转录显示小部件提供了更多音频专用的配置选项,例如时间戳驱动的行为。 转录组件提供以下功能:

  • 音频播放器和转录视图之间的同步播放
  • 说话人显示,便于轻松导航至感兴趣的说话人
  • 操作配置选项,用于实现高级功能,例如转录编辑

配置选项

音频

  • 包含单个对象的对象集: 具有媒体引用属性的对象。
  • 音频媒体引用属性: 该 媒体引用 对象属性,即音频媒体引用。
  • 跳转到时间戳(秒): 一个可选的数值变量,用于将音频跳转到特定的时间戳。
    • 如果给定数字大于音频的长度，将跳转到音频的末尾。
    • 如果给定数字小于零，将跳转到音频的开头。
    • 用户交互时，播放将正常进行。

转录（可选）

  • 启用转录： 可选择在音频上方显示交互式转录。
    • 分段对象集： 一个包含分段的对象集，这些分段包含所选属性。
    • 转录内容： 包含分段文本的字符串对象属性。
    • 开始时间戳（毫秒）： 包含分段开始时间戳（以毫秒为单位）的数值对象属性。
    • 结束时间戳（毫秒）： 包含分段结束时间戳（以毫秒为单位）的数值对象属性。
    • 说话人分离： 切换以启用或禁用甘特图的说话人显示。
      • 说话人： 包含说话人姓名或 ID 的字符串对象属性。
      • 说话人分离显示： 选择 播放器 或 甘特图 可视化选项。
    • 启用操作： 启用将在鼠标悬停在分段上时显示在工具栏中的操作。
      • 图标： 选择一个图标，用于在工具栏中表示此操作。如果未设置图标，将默认使用铅笔图标。
      • 操作标签： 设置操作名称，该名称将显示在图标的工具提示中。
      • 操作： 设置一个可以从分段工具栏触发的操作。可以通过 Selected segment 变量引用悬停的分段。如需了解有关操作的更多信息，请查阅我们的 操作类型文档。
