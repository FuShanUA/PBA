通过 AWS PrivateLink 连接到 Foundry

AWS PrivateLink ↗ 允许用户通过私有 AWS 网络访问 Foundry，而无需经由公共互联网。AWS Private Link 支持不同 VPC（虚拟私有云）区域之间的连接。请注意，跨区域支持可能存在额外限制；请联系您的 Palantir 代表并告知所需的 (start_region, destination_region) 组合，以确认是否支持。请注意，AWS PrivateLink 是一项 AWS 服务。

AWS PrivateLink 到 Foundry 的入口流量

流量可以通过 AWS 骨干网络从客户的虚拟私有云（VPC）传输到 Foundry VPC。PrivateLink 流量和经由公共互联网访问 Foundry 的流量可同时获得支持，具体方法是 使用 Control Panel 配置额外的 IP 白名单。

设置 AWS PrivateLink 到 Foundry 的入口流量

  1. 将您的 AWS 账户 ID ↗ 发送给您的 Palantir 代表。
  2. Palantir 会返回 VPC 终端节点服务名称。VPC 终端节点服务名称示例： com.amazonaws.vpce.<REGION>.vpce-svc-<18_CHARACTER_UID>。
  3. 在 AWS 控制台中，前往 VPC > Endpoints > Create Endpoint创建 VPC 终端节点。 a. （可选）为您的终端节点添加名称标签。 b. 选择 “其他终端节点服务”。 c. 在 “服务类别” 部分，粘贴 Palantir 终端节点服务名称，然后选择 “验证服务”. d. 填写您希望通过 Private Link 连接到 Foundry 的 VPC、子网和安全组的其余详细信息。请注意，安全组应允许通过 443 端口（HTTPS）连接到 Foundry。 e. 选择 创建端点 （位于页面底部）以创建新的端点。
  4. 请将您新创建的端点 ID（可在 AWS VPC 控制台的“端点”部分中找到）和该端点所在的 AWS 区域，以及您的 Foundry 注册 ID 和每个需要通过 Private Link 获得访问权限的组织的组织 ID，一并提供给您的 Palantir 代表。Foundry 注册 ID 和组织 ID 可在 Control Panel中找到。

Foundry Control Panel 中 Foundry 注册 ID 的屏幕截图：

  1. 添加一条 DNS 条目（CName 或 A-Record），将 Foundry 域名指向 VPC Endpoint Universal DNS 名称。如果您在 AWS 中执行此操作，建议创建 A-Record 别名 （在 Route53 中），具体操作请参见 AWS 文档（关于使用 Route53 路由到 VPC Endpoint）↗。Universal DNS 名称可在 “DNS 名称” （位于 AWS VPC 控制台的 “端点” 部分中）下找到。
  2. （有条件）如果 Foundry 域名 归您所有 （即该域名 并非 Palantir 所拥有的域名，例如 *.palantirfoundry.com），则还需要进行额外的配置，以便将内部 Foundry 服务也通过该端点进行传输；这些步骤在以下文档中有所说明： 客户拥有的私有链接。
  3. 刷新并清除浏览器缓存后，从您的 VPC 到 Foundry 的所有流量都将通过私有链接而非公共互联网进行路由。

针对 AWS PrivateLink 的 Foundry 出站流量

从 Foundry 到其他 AWS VPC 的流量也可以配置为通过 AWS 骨干网络而非公共互联网进行路由，即使 Foundry 实例的 VPC 与目标 VPC 位于不同的 AWS 区域也是如此。

某些 AWS 服务支持通过 AWS 骨干网络发送所有流量 而无需承担使用自定义 PrivateLink 的额外 AWS 费用，方法是使用 AWS Gateway Endpoints ↗目前支持的 AWS 服务如下：

  • S3： 您可以在 Foundry Control Panel 中直接为 S3 设置 AWS Gateway Endpoint，方法是 创建 S3 存储桶同区域策略。
  • DynamoDB： 请联系您的 Palantir 代表，为 DynamoDB 设置 AWS Gateway Endpoint。

对于所有其他 AWS 服务或任何其他类型的流量，必须在 AWS 中设置 PrivateLink（VPC 终端节点）并在 Foundry 中进行配置。此设置过程完全自助，具体说明见 私有链接出站文档。

常见问题

创建 VPC 终端节点时，我收到 "Unable to verify service name"（无法验证服务名称）错误。

请确保在第一步中已向您的 Palantir 代表发送了正确的 AWS 账户 ID。请注意，如果账户 ID 以零开头，这些零仍必须包含在 ID 中。

Palantir 能否为我提供 AWS 联合令牌？

不能；您必须使用 Palantir 的 Endpoint Service 名称来创建 VPC 终端节点，具体方法请参见 Foundry 入站设置指南中的步骤 1-3。

是否可以通过 VPC 对等连接将我的非 Foundry VPC 连接到 Foundry 的 VPC？

不能，不支持与非 Palantir 网络进行 VPC 对等连接；我们建议改用私有链接，具体说明请参见本页文档。

是否可以在我的非 Foundry VPC 与我的 Foundry 实例之间设置跨区域私有链接？

可以，AWS PrivateLink 支持跨区域私有链接。请参见 入站 和 出站 上述说明以建立此连接。
