向 AIP Assist 注册自定义内容源

使用 AIP Assist 加快工作流程和新用户上手，并通过允许它从自定义内容源提供针对性指导来实现支持自动化。您可以允许 AIP Assist 提供来自平台内 自定义文档 或来自 Notepad 文档的内容，方法是 注册 您的内容源，使其对 AIP Assist 可用。为此，请根据您的内容源，按照以下步骤针对 Notepad 或平台内 自定义文档进行操作。之后， 还需要在 Control Panel 中进行额外配置 以允许 AIP Assist 在回答用户查询时提供您的内容。

在大多数情况下，我们推荐使用 Notepad，因为它可以通过嵌入其他应用（如 Workshop）在 Palantir 平台中获得广泛使用。欲了解更多信息，请查阅 Notepad 文档。如果平台内 自定义文档 更适合您的使用场景但尚未启用，请联系您的 Palantir 代表为您的租户启用该功能。

我们强烈建议您在编写和更新内容时查阅 自定义内容源的最佳实践 。

将 Notepad 作为 AIP Assist 的内容源

此功能目前可能并非在所有租户上都可用。如果您没有看到将 Notepad 文档添加到 AIP Assist 的选项，请联系您的 Palantir 代表，了解您的租户是否符合条件。

以下说明详细介绍了如何将 Notepad 文档添加为 AIP Assist 自定义内容源：

  1. 通过选择 + New Document创建一个 Notepad 文档，或导航到现有文档。请确保您的文档属于某个 项目.

  2. 打开 操作 下拉菜单（位于 Notepad 文档右上角），然后选择 Add to AIP Assist。这将打开一个对话框，您可以在其中授予 AIP Assist 访问您文档的权限。随着文档变得对 AIP Assist 可发现，此选项可能需要一些时间才会显示。

  1. 切换 Add to AIP Assist 选项，并填写 文档标题 and 描述 字段。这些字段应具有描述性，并针对您文档中的内容具体填写。

  1. 选择 保存 并确保显示成功消息，确认文档已被摄取到 AIP Assist 中。

您的内容现已被摄取到 AIP Assist 中，并将在 Control Panel 中提供用于 可见性配置。请确保首先按用户和组为 Notepad 文档配置可见性设置，因为 AIP Assist 会遵循现有权限。

将平台内自定义文档作为 AIP Assist 的内容源

要使用此功能，您必须已在 Code Repositories 中拥有一个文档仓库。如果您的租户尚未启用此功能，请联系您的 Palantir 代表以启用 documentation 类型的仓库，或者在仓库创建后（如果功能已启用）将其加入白名单。

要授予 AIP Assist 访问您的平台内 自定义文档的权限，请向您的文档仓库添加内容，并选择将信息提供给 AIP Assist。

  1. 确保您已在 Code Repositories 中初始化一个文档仓库。通过在 （尽管这仍然是一种强大而灵活的方法），并且无需离开 Slate 即可轻松计算总和、平均值等简单指标。详情请参阅 folder.
  1. 在“product”文件夹（下方的“Custom_Docs_Support_Alert_Example”）中，创建一个 overview.md 文件，包含 @name and @description，后跟 Markdown 格式的文档。

  1. 当您完成向文档仓库填充内容后，将现有的 _aip-assist.json 文件（位于仓库顶层）重命名为 aip-assist.json. 原始文件可能会在一段时间后重新生成；无需采取任何操作。

  2. 在此文件中，列出您希望加入 AIP Assist 的“product”文件夹及其描述。该描述将提供给 AIP Assist，以便它评估何时查询自定义文档。请确保描述全面且简洁。提交您的更改，并确保文档作为检查的一部分发布。

FAQ

自定义文档或 Notepad 文档中的内容更新会反映在 AIP Assist 向用户提供的信息中吗？

平台内自定义文档或 Notepad 文档中的每次更新都会自动传播并更新我们的数据库。无需进一步操作即可更新 AIP Assist 中的内容。

为什么 AIP Assist 的回复中看不到图片？

目前，AIP Assist 仅显示来自 Palantir 公共文档和平台内自定义文档的图片，但我们也在努力支持 Notepad 图片。在此期间，我们建议在图片下方添加描述。这些文本将显示在 AIP Assist 中，并且会在答案中添加行内引用。当用户选择引用时，他们将被重定向到您的内容，在那里可以查看任何相关图片。

为什么 Notepad 中的操作下看不到 AIP Assist 按钮？

目前，您无法将空的 Notepad 文档添加到 AIP Assist，因此请确保您的文档包含内容。如果您刚刚添加了内容或将大型文档粘贴到 Notepad 中，请给它一些时间进行更新，因为新资源的传播可能需要一些时间。

请确保您的注册中已启用 AIP，并且您的 Notepad 文档位于 项目中，并且该项目具有组织 标记.
