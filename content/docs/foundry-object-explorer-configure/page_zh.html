配置对象资源管理器

主页上可自定义的对象类型分组

要创建对象类型并将其添加到组中，请访问该对象类型的 元数据小部件 （位于本体论管理器中）。您必须拥有该本体论的编辑者权限才能执行此操作。

如果配置了自定义组，任何不属于某个组的非隐藏对象类型将被放入页面底部名为“其他”的组中。

从操作成功提示中关联到对象视图

操作成功应用后，可以将成功提示（弹出式确认消息）配置为显示指向已创建或修改的对象实例的对象视图的超链接。这为新建或修改的对象提供了快速访问对象视图的途径。

要以这种方式配置成功提示，您需要向相关 创建对象 操作的主键参数或相关 修改对象 操作的对象引用列表参数添加一个新的类型类（参见下方代码）。可以使用本体论编辑器应用添加该类型类，这要求您拥有本体论编辑权限。

以下示例展示了如何添加一个成功提示，该提示关联到新创建的对象实例的对象视图。

  1. 本体论操作“创建新飞机”允许我们创建一个新的飞机对象实例。
  1. 在弹出菜单中，输入相关信息，然后选择“提交”。在本例中，将创建一个 Id 为 187 且飞机注册号为 Q-AHE 的飞机对象实例。
  1. 现在我们已在主键参数上添加了上述类型类，成功提示将显示指向新创建对象实例的超链接 Q-AHE。点击该超链接将跳转到此对象实例的对象视图。

在对象资源管理器中隐藏操作

操作将自动显示在对象资源管理器的三个位置，如 操作类型文档中所述。要隐藏某个对象类型的操作，请添加 hubble-oe:hide-action 类型类到本体论编辑器应用中的对象引用列表参数。您需要拥有本体论编辑权限才能执行此操作。

动态对象集上的操作

此功能仍在开发中，可能会被弃用 未启用 自动迁移。因此，使用它意味着您将来可能需要手动迁移您的操作。如果您计划使用此特定功能，请先联系您的 Palantir 代表。

在某些情况下，您可能希望将探索结果用作动态对象集，而不是静态对象集。动态对象集保存为所应用筛选器的表示形式。因此，当新数据匹配（或不匹配）这些筛选器时，对象集将随之更新。

此功能最典型的用例是将动态对象集的引用作为属性值添加到对象实例上。

以下示例展示了如何创建一个操作，允许您将动态的 Aircraft 对象集分配给一个 Airline 对象，基于飞机制造商序列号（MSN）。

  1. 确保该 Airline 对象类型具有一个 String 属性（在本例中为 Aircraft Set），您可以在其中添加对一组“飞机”对象的引用作为值。为该属性启用值格式化，并选择 此属性必须具有一个关联的 （从下拉菜单中）。这样，分配给该属性的对象集 RID 将显示为指向对象资源管理器中对象集的链接。
  1. 现在您已准备好创建操作。在该操作上，添加一个 Modify Object（修改对象） 规则到 Airline 对象类型的 Aircraft Set property.
  1. 在 Aircraft Set 参数上，添加以下类型类，其中 <OBJECT_TYPE_ID> 是您希望此操作在探索视图中作为选项显示的对象类型的对象类型 ID（在本例中，即 Aircraft 对象类型）。

这将自动为当前探索创建一个动态对象集，并将其分配给 Aircraft Set 属性，位于您从下拉菜单中选择的 Airline 对象上。
