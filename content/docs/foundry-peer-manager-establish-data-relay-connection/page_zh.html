建立数据中继连接

数据中继连接使 注册管理员 能够在两个 注册 之间通过现有的跨域解决方案（CDS）而非直接网络连接交换数据。与 Multipass 交换器（MPX）连接类似，数据中继连接是 创建对等连接的前提条件。

当这两个注册之间没有可用的直接网络连接时，请使用数据中继连接，这意味着您必须使用现有的 CDS 来交换数据。如果这两个注册之间有可用的网络连接，请改为 建立 MPX 连接 。

在 Peer Manager 中，您可以通过配置一个或多个 CDS 通道 来为每个远程注册建立数据中继连接。每个通道在单一方向（导出 或 导入）上通过一种类型的 CDS 传输方式路由数据，例如共享文件目录、HTTP 端点、S3 存储桶或 Lattice ↗ 服务。以下各节中的说明概述了 注册管理员 在 每个 注册上为建立连接而必须采取的操作。

与远程管理员协调 CDS 通道详细信息

在任一 注册管理员 创建通道时，请与远程 enrollment 的管理员协调以下事项，以确保连接两侧的 CDS 通道相互匹配：

  • 每个通道的方向： 每个通道仅在一个方向上发送数据。要将数据从 Enrollment A 导出到 Enrollment B， Enrollment A 上的管理员需要创建一个 Export 通道， Enrollment B 上的管理员需要创建一个 Import 通道。要双向发送数据， 双方 管理员都需要创建一对相互匹配的 Export 和 Import 通道。
  • 连接类型： 通道两侧必须使用相同的连接类型。例如，如果导出侧使用 HTTP，则导入侧也必须使用 HTTP。可用的连接类型如下：
    • File： 导出侧将数据以文件形式写入某个目录，导入侧则从该目录读取数据。
    • HTTP： 数据通过网络发送。此选项还支持任何可配置为透传 HTTP 请求的 CDS。
    • S3： 导出侧将数据写入 S3 存储桶，导入侧从该存储桶读取数据，并在处理完成后删除文件。
    • Lattice： 双方均使用 Kubernetes 服务账户身份验证或静态令牌连接到 Lattice 服务 URI。
  • 通道密钥（可选）： 如果导出方使用密钥对传出负载进行签名，则导入方必须注册相同的密钥以验证传入负载。
  • 远程注册 RID： 每位管理员在创建自己的通道时都必须提供对方注册的 RID。要查找注册 RID，请使用 Foundry API 中的 Get Current Enrollment 端点，或导航到 Control Panel 并从 URL 中获取 RID： https://{FOUNDRY_URL}/workspace/control-panel/enrollment/{ENROLLMENT_RID}/home。

创建 CDS 通道

与另一位管理员协调好 CDS 通道后，请在您的注册中按照以下步骤创建您负责的每个 CDS 通道：

  1. 在 Peer Manager 中，打开 网络连接 选项卡。
  2. 在 通过 CDS 发送数据 部分中，选择 新建 CDS 通道 ，Peer Manager 会将您引导至 新建通道 页面。
  3. 填写 通道详情 部分：
    • 通道名称： 用于标识通道的名称。
    • 通道描述 （可选）：关于通道用途的简短描述。
    • 远程注册 RID： 通道另一侧注册的 RID。
    • 通道密钥 （可选）：用于对传出负载进行签名或验证传入负载的密钥。通道两侧的密钥必须一致。
    • 要覆盖的通道 （可选）：此通道将覆盖的只读通道的名称。
    • 方向： 如果此通道向远程注册发送数据，请选择 导出 ；如果此通道从远程注册接收数据，请选择 导入 。
  4. 请查看 Guard 配置部分。对于 导出 通道，您必须设置与您的 CDS 兼容的 Schema 版本 ，因为接受默认值可能会导致通道创建失败。
  5. 在 集成 部分中，从可用选项中选择该通道承载的数据类型：
    • 对等互连： 通过该通道路由两个注册用于协调对等连接和对等互连作业的控制平面流量。您必须选择此集成，才能将该通道用作 对等连接的底层传输。
    • 聊天： 在两个注册的用户之间路由跨注册的聊天消息。
    • Geotime： 在两个注册之间路由 地理时间数据，例如位置和轨迹。
    • 心跳： 通过该通道路由周期性心跳信号，以便每个注册都能检测该通道是否可达并正常运行。
  6. 如有需要，可切换 对等媒体集 ，以配置额外的管道，在 媒体集 与支持二进制文件的辅助 CDS 通道之间传输二进制数据。
  7. 选择 连接类型 与另一位管理员在 通道配置 部分中选择的内容相匹配，并为该传输方式填写相应的配置字段。
  8. 选择 保存更改 以创建通道，该通道将显示在 网络连接 选项卡的 CDS 通道表中。

如果需要双向发送数据，请重复上述步骤，创建一个方向相反的第二个通道。

后续步骤

在两位管理员均创建好相互匹配的 CDS 通道并确认通道运行正常后，您可以返回 Peer Manager， 创建对等连接 来使用这些数据中继通道。在 Peer Manager 的 网络连接 选项卡中，您可以查看和管理与远程注册关联的 CDS 通道。
