模型和智能体模式

Pilot 支持多种 AI 模型和两种智能体模式，这些模式控制着 Pilot 处理您指令的方式。本页介绍了可用的选项以及各自的使用时机。

可用模型

Pilot 支持来自多个提供商的模型。您可以从聊天面板中的 More 菜单中选择模型。可用的模型系列包括：

  • Claude（Anthropic）： Claude Opus 和 Claude Sonnet 变体
  • GPT（OpenAI）： GPT 模型变体
  • Gemini（Google）： Gemini Pro 变体

不同模型各有优势。一般而言，较大的模型在处理复杂任务时能产生质量更高的输出，而较小的模型在执行简单更改时响应更快。您可以在会话期间随时切换模型，而不会丢失工作进度。

智能体模式

Pilot 以两种模式之一运行，可通过提示词输入框旁边的模式切换开关进行控制。

行动模式

行动模式是默认模式。当您提交提示词时，Pilot 会立即执行更改。智能体会读取您的指令、做出决策，并将更改应用于本体论、设计和代码，而无需等待中间审批。

当您希望 Pilot 自主工作，并且可以接受在更改应用后再进行审查时，可使用行动模式。

计划模式

在计划模式下，Pilot 会在执行更改之前制定详细计划。提交提示后，Pilot 会概述其打算执行的操作，并等待您的批准后再继续。

在以下情况下使用计划模式：

  • 您希望在应用提议的更改之前先对其进行审查。
  • 您正在对本体论或应用程序进行重大结构性更改。
  • 您希望在 Pilot 开始工作之前了解更改的范围。

若要在模式之间切换，请选择聊天面板中提示输入框旁边的模式切换开关。当前模式显示为 行动 或 计划。

子代理

Pilot 会将工作委派给专门的子代理，每个子代理专注于应用程序的特定方面。子代理如下：

  • 本体论架构师： 定义和修改对象类型、操作类型、关联类型及其属性。
  • 设计师： 创建设计规范，包括调色板、排版、布局和交互模式。
  • 应用构建器（前端架构师）： 使用本体论和设计规范实现 React 应用程序。
  • 种子数据生成器： 创建逼真的示例数据，用于在容器中测试应用程序。

当子智能体处于活动状态时，聊天面板会在单独的线程中显示其活动。您可以展开该线程，以了解子智能体的推理过程和工具使用情况。

智能体工具

Pilot 智能体使用一组工具来构建和修改您的应用程序。您无需直接调用这些工具。Pilot 会根据您的指令选择并使用合适的工具。

Pilot 会自动使用智能体工具。您可以通过自然语言提示与 Pilot 交互，由 Pilot 决定使用哪些工具。

智能体可以使用以下工具：

  • 文件操作： 读取、写入和编辑源代码文件
  • 搜索工具： 查找文件以及按模式搜索文件内容
  • Shell 命令： 运行构建命令、安装依赖项以及执行脚本
  • 本体论搜索： 查询现有的本体论对象类型、操作类型和函数
  • 版本控制： 提交和推送代码更改
