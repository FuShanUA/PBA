联接数据集

Contour 提供多种不同的看板来执行连接操作。本指南将教你：(1) 如何使用每种看板来连接数据集，(2) 每种看板的 SQL 等价写法，以及 (3) 性能方面的注意事项。

连接看板

连接看板允许你将当前工作数据集与另一个数据集进行连接，并将匹配的结果合并到你的数据中。以下是概览：

示例

假设你有一个包含客户购买信息的表格。

customer_iditem_idpurchase_dateprice
1019991/1/200050
1219971/1/200035
…

你可能还有第二个表格，其中包含库存中所有商品的信息：

item_iditemweight_kg
999烤面包机1
997煎锅0.5
…

你可以使用连接看板来丰富你的起始数据集（transactions），为其添加每个所购商品的信息。

如果你的数据集中存在同名的列，Contour 会提示你为这些列名添加前缀。在本例中，两个数据集都有一个名为 item_id的列。请为来自传入数据集的列应用前缀 “inv”（用于 inventory）。

如果你不想将重复的 item_id 列添加到连接后的结果数据集中，可以取消选择来自传入数据集的该列。

丰富后的数据集将如下所示：

customer_iditem_idpurchase_datepriceinv_iteminv_weight_kg
1219971/1/200035煎锅0.5
1019991/1/200050烤面包机1
…

连接看板的配置

选择要执行的连接类型：左连接（Add columns）、内连接（Intersection）、右连接（Switch to dataset）或全连接（Incorporate all data, matching rows where possible).

选择要将另一个数据集中的哪些列添加到当前工作集。默认情况下，会返回第一个数据集中的所有列。

然后从每个数据集中选择一个或多个键。如果你使用多个连接键，可以选择 匹配任一条件 or 匹配所有条件 。

对于全连接，将返回两个数据集中的所有行；这意味着任一数据集的连接列都可能出现空值，因为两个列之间不会进行合并处理。

合并看板

使用合并看板可以基于另一个数据集来修改当前数据集。你可以追加来自另一个数据集的数据（添加行）、筛选数据集以仅保留在另一个数据集中存在的数据（保留行）、或根据另一个数据集中存在的数据移除数据（移除行）。你可以选择根据列在数据集中的位置或列名进行匹配。

union 面板的配置

选择 保留行, 添加行，或 移除行，然后选择要与之比较的集合。

对于 保留行 和 移除行，您可以选择 出现在 or 匹配依据.

  • 使用 出现在，您可以选择按 按位置 or 按名称.
  • 使用 匹配依据，您必须指定用于连接的列（每个集合各一列）。
Union 要求列数相同

执行 union 时，两个数据集必须具有相同的列数。因此，在使用 union 面板时，如果架构可能发生变化，务必小心。例如，位于已切换为透视数据的数据透视表下游的 union 面板，可能会因架构变化而出现列数的意外变化。

数据类型

检查您的结果集，以确保数据类型符合预期。

使用 union 面板时，请注意列的数据类型。兼容的列类型将被转换。举个具体例子，请考虑以下两个数据集。

dataset1

ID (int)Name (string)
555Alice
666Bob

dataset2

ID (long)Name (string)
555Alice
999Chloe

从 dataset1开始，如果我们 按位置添加行 （来自 dataset2，则结果集如下所示：

ID (long)Name (string)
555Alice
666Bob
555Alice
999Chloe

从 dataset1开始，如果我们 保留行 AI 出现在 dataset2 按位置，则结果集如下所示：

ID (long)Name (string)
555Alice

尽管起始集合中的 ID 列是 int 类型，但在结果集中它是 long 类型。 保留行 AI 出现在 使用 Intersect 函数 （在 spark 中）。

从 dataset1开始，如果我们 移除行 AI 出现在 dataset2 按位置，则结果集如下所示：

ID (long)Name (string)
666Bob

同样，尽管起始集合中的 ID 列是 int 类型，但在结果集中它是 long 类型。 移除行 AI 出现在 使用 Except 函数 （在 spark 中）。

性能考量

  • 在为连接两个表选择键时，应尽可能使用唯一 ID（如主键）。我们 强烈 建议不要使用外键连接——这样做会导致 Spark 崩溃。
  • 您应该使用 保存为数据集 功能，在复杂连接或表达式之后“保存”您的工作，然后再继续。这将使下游查询的性能更好，因为连接已持久化到磁盘。

检查结果

连接数据集之后，最好查看一下连接集的表，以检查结果是否符合预期。选择 表格 （在操作栏中）以添加一个表面板，然后滚动浏览您的新连接集。
