示例：上传 scikit-learn 模型

以下文档提供了一个示例，说明如何将现有模型文件中的模型集成到 Foundry 中。有关分步指南，请参阅我们关于如何 从预训练文件发布模型.

从模型文件创建模型

以下示例使用了一个在本地通过 Iris 分类数据集 ↗ （由 UC Irvine 发布）训练的模型。该数据集包含四个特征； sepal_length, sepal_width, petal_length 和 petal_width 可用于构建一个预测鸢尾花物种的模型。

在本示例中，我们假设模型是在本地作为 K 近邻分类器 ↗ 并使用 scikit-learn 库 ↗训练的。本示例还假设模型是使用 Python 3.8.0 和 scikit-learn 1.3.2.

训练完成后，模型被保存为 pickle 文件 ↗，定义如下。

from sklearn.datasets import load_iris
from sklearn.model_selection import train_test_split
from sklearn.neighbors import KNeighborsClassifier

import pickle

iris = load_iris()
X = iris.data
y = iris.target

X_train, X_test, y_train, y_test = train_test_split(
    X, y, test_size=0.4, random_state=4)

knn = KNeighborsClassifier(n_neighbors = 5)
knn.fit(X_train, y_train)

with open("iris_model.pkl", "wb") as f:
    pickle.dump(knn, f)

from transforms.api import transform, Input
import palantir_models as pm
from palantir_models.transforms import ModelOutput
from palantir_models.serializers import DillSerializer
import pickle


@transform(
    model_files=Input("<Your Input Path>"),
    model_output=ModelOutput("<Your Output path>")
)
def compute(model_files, model_output):
    fs = model_files.filesystem()
    with fs.open("iris_model.pkl", "rb") as f:
        model = pickle.load(f)

    model_adapter = IrisModelAdapter(model, "target")
    model_output.publish(
        model_adapter=model_adapter
    )


class IrisModelAdapter(pm.ModelAdapter):

    @pm.auto_serialize(
        model=DillSerializer(),
        prediction_column_name=DillSerializer()
    )
    def __init__(self, model, prediction_column_name):
        self.model = model
        self.prediction_column_name = prediction_column_name

    @classmethod
    def api(cls):
        column_names = ["sepal_length", "sepal_width", "petal_length", "petal_width"]
        columns = [(name, float) for name in column_names]
        inputs = {"df_in": pm.Pandas(columns=columns)}
        outputs = {"df_out": pm.Pandas(columns=columns + [("target", int)])}
        return inputs, outputs

    def predict(self, df_in):
        inference_data = df_in

        predictions = self.model.predict(inference_data.values)
        inference_data[self.prediction_column_name] = predictions
        return inference_data

4. 使用已发布的模型

模型发布后，即可在平台中使用它进行推理。在本示例中，我们将 创建一个新的建模目标 并提交模型。

  1. 导航到您希望目标所在的项目文件夹，然后选择以下选项来创建新的建模目标 New > Modeling Objective。这将打开 Modeling Objectives 应用。

  1. 接下来，向目标提交一个模型。在 Model Submissions > Submit a Model 部分中，选择 Add Model 以打开一个对话框，如下图所示。

  1. 选择 从 Foundry 提交模型，然后选择 属性，然后选择 以打开一个对话框，您可以在其中从模型在平台中的位置加载已发布的模型。

  1. 模型提交后，您将被引导回建模目标概览页面，其中 Model submissions 部分将显示有关提交的信息。

  1. 从 Model submissions 部分选择新提交的模型以打开模型页面。

  1. 选择 Create new release （位于右上角）以打开一个创建新版本（release）的窗口。

  1. 创建版本后，通过选择屏幕左上角的名称返回建模目标概览页面。向下滚动到 Deployments，然后选择 Create deployment 以打开另一个对话框窗口。

  1. 填写设置表单，然后选择 Create deployment （位于右下角）。返回建模目标概览页面，向下滚动到 Deployments，然后选择新部署的模型进行测试。

  1. 在 Query （位于页面左上角）选项卡，通过添加值并观察输出来测试模型。

有关创建和查询实时部署的更多详细信息，请参阅 实时部署文档.
