将场景元数据存储为对象

您可以在本体论中定义和存储场景的元数据，其中每个对象代表一个场景，从而创建一个 持久化 场景。

存储在本体论中后，场景即可共享和协作。团队可以并排比较多个持久化场景，附加包括描述和作者信息在内的丰富元数据，并将场景与相关对象关联，以便于组织管理。持久化场景继承 Foundry 的权限和治理模型，确保妥善的访问控制，并为决策过程创建持久的审计跟踪。

在 Ontology Manager 中配置

若要在 Ontology Manager 中配置场景对象类型，请按照以下步骤操作：

  1. 在 Ontology Manager 中，导航至 对象类型 选项卡并选择 + 新建对象类型。

  2. 按照配置向导操作。在第 3 步（属性）中，选择 添加 一个接口，然后搜索 本体论场景 接口。请确保 场景引用 已映射到对象类型的主键，然后完成其余步骤。



  3. 创建新对象类型后，打开 属性 选项卡并确认 主键 属性的值类型为 场景引用 已分配给它。

  4. （可选）添加其他属性以存储有关场景的元数据，例如 创建者 或 描述. 保存配置并等待初始同步完成。

场景上的函数

所有函数（AIP Logic 函数除外）都可以直接在场景上运行。如果它们从本体论读取数据，则会读取场景上本体论的状态。如果它们对本体论进行编辑，则会在场景上进行这些编辑。如果您想在场景上使用 AIP Logic，请联系 Palantir 支持。
