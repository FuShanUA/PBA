Iceberg 存储架构

Palantir 支持使用 Iceberg 格式，既可以作为托管 Iceberg 表，也可以作为虚拟 Iceberg 表。

托管 Iceberg 表由 Foundry 的 Iceberg 目录进行管理。虚拟 Iceberg 表是使用外部存储的 虚拟表 ,并由外部 Iceberg 目录管理，例如 Glue ↗、 Horizon ↗、 Polaris ↗ 或 Unity ↗。

Foundry 托管的 Iceberg 表可以使用 Foundry 托管的存储或 BYOB 存储，也可以将两者结合使用，让不同的项目或命名空间指向不同的存储位置。

存储配置选项

对于 Foundry 托管的表，支持在 AWS、Azure 和 GCP 上进行存储。

请注意，在所有情况下都需要服务器端加密 (SSE)。客户端加密 (CSE) 可通过 Iceberg 表加密 ↗ 选择性地应用，作为数据写入存储前的额外加密层。更多信息，请参阅 加密设置。

支持与功能

托管 Iceberg 表和虚拟 Iceberg 表可与大多数核心 Foundry 功能配合使用。

对于托管 Iceberg 表，Foundry 通过其 Iceberg REST 目录实现来管理表。这为 Foundry 启用了额外功能，例如用于配置维护操作的引导式前端。

有关当前功能可用性的信息，请参阅 Iceberg 表不支持的 Foundry 功能。

加密设置

本节介绍 Foundry 管理的 Iceberg 表的加密设置和配置选项。

服务器端加密 (SSE)

所有表均强制使用服务器端加密 (SSE)。对于由 Foundry 管理的存储，Palantir 会强制执行加密。对于客户提供的存储桶，客户管理员必须在存储桶上强制实施 SSE。

客户端加密 (CSE)

客户端 Iceberg 表加密 ↗ 可在 Control Panel中启用或禁用。Iceberg 表加密会在数据写入存储位置之前，先在 Foundry 内使用客户端加密 (CSE) 对数据进行加密，从而在服务器端加密的基础上提供额外一层加密保护。

客户端 Iceberg 表加密是一项较新且仍在持续发展中的功能，目前尚未获得所有 Foundry 功能、外部计算引擎或连接 Iceberg 表的工具的支持。在更广泛的兼容性可用之前，启用该功能可能会导致部分功能受限。

项目级存储设置

存储位置和客户端加密 (CSE) 设置可以独立配置，并在 enrollment 的 "default"（默认）级别应用，同时可选择为特定项目或命名空间覆盖设置。这样便可根据需要将不同的存储设置应用于不同的 Iceberg 表子集。这些设置通过 Control Panel进行管理。
