开始使用

本指南将教你如何通过 Report Builder 对 Foundry 进行身份验证、选择数据集，并开始构建你的第一个报告。

在 Report Builder 中将 Foundry 添加为你的数据源

  • 在 Report Builder 中，点击“报告数据”窗格中的工具栏。点击“新建”，然后点击“数据源”。“数据源属性”对话框随即打开。
  • 在“名称”文本框中，输入任意方便的名称，例如 FoundrySqlServer。点击“使用嵌入在我的报告中的连接”选项。
  • 点击“选择连接类型”下拉菜单并选择 ODBC，使你的窗口如下所示：

构建你的连接字符串

现在，你需要为你的 Foundry 连接创建连接字符串，方法是将以下基础连接字符串粘贴到 Report Builder 中的“连接字符串”文本框中，并替换 '' 和 ''，具体说明如下：

  • 基础连接字符串： DSN=FoundrySql;BaseUrl=<URL>;PWD=<Token>
  • URL： 将你的 Foundry 连接 URL 添加为“基础 URL”。你的 Foundry 连接 URL 是你通常用来访问 Foundry 的链接。为此，请将 '' 替换为此路径，方法是登录 Foundry，复制 URL，并删除 https:// 前缀以及其后的任何内容 .com.
  • 令牌： 按照以下说明操作 生成令牌 以在 Foundry 中生成私有身份验证令牌。获得令牌后，你可以将其粘贴到基础连接字符串的 '' 部分。
  • 你的 Foundry 数据源现在应该已连接。你现在可以尝试点击“测试连接”按钮。如果此时收到错误，请确保你已完成 安装说明.

点击“确定”并继续下一步。

你的凭据现在应已保存在 Report Builder 中，并且在其有效期内将继续有效。在令牌有效期到期之前，系统不会再次提示你输入令牌。届时，你可以再次按照上述说明生成新令牌。

连接到 Foundry 并查询你的数据集

  • 再次使用左侧的“报告数据”窗格，点击“新建”，然后点击“添加数据集”。
  • 系统将提示你为数据集输入名称。点击“使用嵌入在我的报告中的数据集”选项，然后从下拉菜单中选择 FoundrySqlServer。
  • 要开始使用特定数据集，请将数据集文件路径或 RID 复制到“查询”文本框中。你可以在 Foundry 中找到这些值，方法是导航到所需数据集的“关于”页面，点击“查看更多”，然后复制“RID”值或“位置”。（参见 指南：在 Foundry 中识别数据集的 RID 或文件路径.)
  • 构建你的 SQL 查询，并像往常一样继续构建你的报告。
