媒体集转换 API

媒体集转换 API 提供了在 Python 转换中对媒体集进行转换的方法。该 API 支持对媒体集执行多种操作，例如使用光学字符识别（OCR）提取文本、调整图像大小、将文档转换为图像等。

from transforms.mediasets.inputs import MediaSetInputParam
from transforms.api import transform, Output, TransformOutput
from transforms.mediasets import MediaSetInput

@transform(
    media_input=MediaSetInput("/path/to/media_set"),
    dataset_output=Output("/path/to/output")
)
def compute(ctx, media_input: MediaSetInputParam, dataset_output: TransformOutput):
    # Create a MediaSetInputTransform instance
    transform = media_input.transform()

    # Apply transformations
    result = transform.ocr()

    # Write the result to output
    dataset_output.write_dataframe(result)

    ctx,

    multimodal_output: MediaSetOutputParam,

        ),

def write(
    self,
    media_transform: MediaSetInputTransform,
    output_path: Callable[[str, Optional[int]], str] = prefix_path,
    suppress_errors: bool = False,
    return_dataframe: bool = False,
) -> Union[str, DataFrame, None]:

将 MediaSetInputTransform 写入输出媒体集。

参数：

  • media_transform (MediaSetInputTransform): 一个已应用于媒体集输入的媒体集转换。例如： media_transform = img_input.transform().resize()
  • output_path (Callable[[str, Optional[int]], str], optional): 一个为每个媒体项确定输出路径的函数。它接受原始路径和可选的页码作为输入，并返回新路径。默认会在原始路径前添加 "transformed"。对于为每个输入媒体项输出多个项的媒体转换，这些项的路径将自动附加一个标识值。例如， crop 对图像应用多个裁剪的转换将自动在路径中包含裁剪参数（x_offset、y_offset、width、height）。
  • suppress_errors (bool): 指定错误处理行为。如果为 True，错误会被捕获，并且错误消息将返回到 dataframe 的 media_reference 列中，前提是 return_dataframe 为 True。如果为 False，则不会捕获任何错误，构建将会失败。默认值为 False。仅适用于针对整个媒体集的转换。
  • return_dataframe (bool, optional）：仅适用于媒体集级别的转换。如果为 True，则返回一个包含 media_item_rid、path 和 media_reference 列的 dataframe。该 dataframe 表示写入输出媒体集的媒体项。默认值为 False。如果为 True，将对媒体集转换进行惰性求值。

返回：

  • None、DataFrame 或字符串。
    • str：适用于对单个媒体项的转换。返回生成的媒体引用字符串。
    • None：适用于对整个媒体集的转换。如果 return_dataframe 设置为 False，则返回 None。
    • DataFrame：适用于对整个媒体集的转换以及 return_dataframe 设置为 True 的情况。列为 media_item_rid, path, media_reference.

API 参考

ocr()

使用 OCR 从 PDF 或图像中提取文本，并以字符串形式返回提取的文本。建议用于图像和扫描文档。

参数：

  • languages (list[str]）：用于 OCR 的语言列表。默认为英语。所有有效代码均可在 Tesseract 文档 ↗ 中的 languages 部分找到。
  • scripts (Optional[list[str]]）：用于 OCR 的文字系统列表。默认值为 None。所有有效代码均可在 Tesseract 文档 ↗ 中的 scripts 部分找到。
  • media_item_rid (Optional[str]): 如果指定，将对指定项而非整个媒体集运行转换。默认值为 None。
  • start_page (Optional[int]): 用于 OCR 的起始页码（从零开始索引）。仅适用于 PDF 媒体集。默认值为 0 （第一页）。
  • end_page (Optional[int]): 用于 OCR 的结束页码（从零开始索引，不含该页）。仅适用于 PDF 媒体集。默认值为 None （最后一页）。
  • return_structure (str): item_per_row 或 page_per_row。仅适用于对整个 PDF 媒体集执行的转换。默认值为 item_per_row。
  • suppress_errors (bool): 指定错误处理行为。如果 True，则会捕获错误，并在输出中返回错误消息。如果 False，则不会捕获任何错误，构建将失败。默认值为 True。仅适用于对整个媒体集执行的转换。

返回：

  • DataFrame、字符串列表或单个字符串。
    • str：对单个图像执行的转换。
    • list[str]：对单个 PDF 执行的转换。
    • DataFrame：对整个媒体集执行的转换。
      • 对于 PDF (item_per_row): 各列为 media_item_rid, path, media_reference, extracted_text (list[str])。
      • 对于 PDF (page_per_row) 或图像集：各列为 media_item_rid, path, media_reference, page_number, extracted_text (str)。

示例：

Copied!
1
2
df = media_set.transform().ocr()
dataset_output.write_dataframe(df)

extract_raw_text()

从 PDF 中提取原始文本。推荐用于以电子方式生成的文档。

参数：

  • media_item_rid (Optional[str]): 如果指定,将对指定的项目而不是整个媒体集运行转换。默认为 None.
  • start_page (Optional[int]): 用于文本提取的零索引起始页。默认为 0(第一页)。
  • end_page (Optional[int]): 用于文本提取的零索引结束页(不包含)。默认为 None (最后一页)。
  • return_structure (str): item_per_row 或 page_per_row。仅适用于对整个 PDF 媒体集的转换。默认为 item_per_row.
  • suppress_errors (bool): 指定错误处理行为。如果为 True,则会捕获错误,并在输出中返回错误消息。如果为 False,则不会捕获任何错误,并且构建将失败。默认为 True。仅适用于对整个媒体集的转换。

返回:

  • 一个 DataFrame 或字符串列表。
    • str: 适用于对单个图像的转换。
    • list[str]: 适用于对单个 PDF 的转换。
    • DataFrame: 适用于对整个媒体集的转换。
      • PDF (item_per_row): 列包括 media_item_rid, path, media_reference, extracted_text (list[str]).
      • PDF (page_per_row) 或图像集: 列包括 media_item_rid, path, media_reference, page_number, extracted_text (str).

示例:

resize()

将图像调整为指定的尺寸。

参数:

  • media_item_rid (Optional[str]): 如果指定，将对指定的项而非整个媒体集运行转换。默认为 None。
  • width (Optional[int]): 调整大小后图像的目标宽度。默认为 1024。如果未提供 height，则必须提供该参数。
  • height (Optional[int]): 调整大小后图像的目标高度。默认为 1024。如果未提供 width，则必须提供该参数。
  • maintain_aspect_ratio (bool): 指定是否保持图像的原始宽高比。如果为 True，则会在保持宽高比的同时调整图像大小，以适应指定尺寸。默认为 True。
  • output_format (str): 输出图像的格式，例如 PNG 或 JPEG。默认为 PNG。

返回：

  • 一个 MediaSetInputTransform 实例，其中包含调整大小转换，可用于进一步的转换。

示例：

tile()

从图像生成 Slippy 地图瓦片(EPSG 3857)。仅支持 TIFF 或 NITF 格式的地理嵌入图像,最大尺寸为 1 亿平方像素。

参数:

  • media_item_rid (Optional[str]): 如果指定，则将对指定的项而非整个媒体集运行转换。默认值为 None。
  • zoom (Union[int, Column]): 瓦片的缩放级别。必须为非负整数。在缩放级别 0时，整个世界可容纳于单个瓦片中。每增加一级，空间分辨率便会翻倍，瓦片数量则会增至四倍。默认值为 0。
  • x (Union[int, Column]): 指定缩放级别下的瓦片列索引。从西向东递增。有效范围： 0 <= x < 2**zoom。默认值为 0。
  • y (Union[int, Column]): 指定缩放级别下的瓦片行索引。从北向南递增。有效范围： 0 <= y < 2**zoom。默认值为 0。
  • df (Optional[DataFrame]): 指定传入列输入时要与之连接的 DataFrame。瓦片处理将仅应用于同时存在于输入媒体集和所提供的 DataFrame 中的媒体项。必须与 on 参数一起提供。
  • on (Optional[Literal["media_item_rid", "media_reference"]]): 当指定 df 时用于连接的列名。这会使瓦片操作与正确的媒体项相对应。
  • output_format (str): 输出图像的格式，例如 PNG 或 JPEG。默认值为 PNG。

返回：

  • 一个实例，类型为 MediaSetInputTransform 实例，其中包含切片转换，允许进行进一步的转换。

示例：

encrypt()

使用提供的密码图像密钥对图像的指定区域进行加密。

参数：

  • polygons (Union[list[api.Polygon], Column])：要加密的区域，以多边形的形式指定。
  • cipher_license_rid (Union[str, Column])：用于加密的密码许可证 RID。
  • media_item_rid (Optional[str])：如果指定，将对指定的媒体项而非整个媒体集运行转换。默认为 None。
  • df (Optional[DataFrame])：指定在传递列输入时用于连接的 DataFrame。加密将仅应用于同时存在于输入媒体集和所提供的 DataFrame 中的媒体项。必须与 on 参数一起提供。
  • on (Optional[Literal["media_item_rid", "media_reference"]])：当指定 df 时用于连接的列名。这会将加密操作与正确的媒体项对齐。
  • output_format (str)：输出图像的格式，例如 PNG 或 JPEG。默认为 PNG。

返回：

  • 一个 MediaSetInputTransform 实例，其中包含加密转换，允许进行进一步的转换。

示例：
