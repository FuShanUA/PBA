核心概念

本页面介绍 Model Studio背后的核心概念。

模型

模型 为在 Foundry 中集成模型提供通用接口。Model Studio 训练运行会生成一个模型，可用于下游应用，例如 Python 转换、 管道构建器、 函数，等等。

实验

实验 是一种工件，表示模型训练作业期间产生的一组指标。Model Studio 生成的每个模型版本都将有一个关联的实验，用于显示有关该训练作业的代表性参数和指标。例如，某些训练器可能会将训练期间生成的模型集成以图表形式呈现在 图表 标签页。

训练器

Model studio 训练器是用于训练模型的实际模型训练实现。每个训练器都针对特定任务。

  • 时间序列预测: 通过分析训练数据中的模式来预测未来值。
  • 回归： 通过学习训练数据中输入特征与目标变量之间的关系来预测连续数值。
  • 分类： 通过识别训练数据中的模式和差异，将输入数据分配到预定义的类别或分类中。

训练作业

从 Model Studio 启动的训练作业将始终基于最新的训练配置运行。连续运行多个作业将继续使用相同的配置，但由于输入数据不断变化，输出可能会有所不同。每次运行都会被跟踪，并可在 Model Studio 主页中查看.

训练作业在 Foundry 中以标准转换的形式运行，这意味着数据血缘将得到尊重，并且应用于输入数据集的所有标记也将应用于输出模型。

计算用量以 Foundry 计算秒数进行测量和报告。请查阅我们的 使用类型文档 以了解更多详细信息。

参数

每个训练器都定义了一组可用于控制训练作业的参数。训练器还提供该训练器特有的独特参数。

配置模型工作室时，平台内文档将提供有关各参数的详细信息。您可以查看训练器的文档页面，以详细了解该训练器的参数。
