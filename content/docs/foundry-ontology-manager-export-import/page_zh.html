导出、编辑和导入本体论

您不应依赖导出的 JSON 架构，因为它可能会随时间而变化。

本体论架构定义存储在 JSON 文件 ↗中。本体论 JSON 文件可以导出，并使用代码编辑器或文本编辑器进行编辑，然后重新导入到 Foundry。此导入/导出功能为高级用户提供了两种工作流程：

  • 如果您更喜欢通过代码进行本体论编辑，可以导出本体论 JSON 文件，在代码编辑器或文本编辑器中直接编辑该 JSON 文件，然后将修改后的本体论 JSON 文件重新导入平台，从而绕过 Ontology Manager 界面。
  • 如果您想将一个本体论的当前工作状态复制到另一个本体论，可以将该本体论的当前状态导出为 JSON 文件，然后将复制的 JSON 重新导入平台（并在代码编辑器中对 JSON 进行所需的修改）。

导出

您可以导出自己的本体论工作状态，方法是从应用程序主页中选择 高级 设置页面，然后选择 导出。导出内容包括您当前工作状态中的所有更改。

导入

您可以导入之前导出的本体论工作状态，方法是选择 高级 设置页面，然后选择 导入。系统将提示您从本地驱动器中选择一个本体论文件。

接下来，选择 导入， 此操作将根据 JSON 文件在应用程序中重新创建整个工作状态。您将在应用程序标头中看到文件中所做的需要保存的更改数量。

如果导出的本体论工作状态的属性上配置了条件格式规则，则无法将其导入到导出该工作状态的本体论以外的其他本体论中。

故障排除

错误： OntologyMetadata:UnreferencedRuleSets

如果您收到错误 OntologyMetadata:UnreferencedRuleSets，则说明您正在尝试导入的本体论工作状态中包含未在该本体论中定义的条件格式规则，这些规则无法转移过来。您需要在导入之前从本体论工作状态中删除这些条件格式规则。
