Pipeline Builder 中的子图

Beta

Pipeline Builder 中的子图目前处于 beta 开发阶段，您的注册环境中可能无法使用该功能。在持续开发期间，功能可能会发生变化。

Pipeline Builder 中的子图功能允许您将一个或多个转换打包成可复用的块。随后，您可以在管道中的任意位置应用该块，而无需每次重新构建逻辑。子图具有以下几项优势：

  • 复用逻辑： 将复杂逻辑打包，并将其应用于多个管道或分支。
  • 减少重复： 只需更新一次子图，即可对其所有实例生效。
  • 简化管道： 用单个子图节点替换冗长的节点链，使图形更易于阅读和维护。

本指南将介绍如何：

  • 从头开始创建新子图
  • 向您的管道中添加子图
  • 从现有节点创建子图
  • 添加多输入子图

从头开始创建新子图

您可以在 Reusables 菜单中创建和管理可复用的子图。

  1. 在 Pipeline Builder 中，打开要在其中定义子图的管道。

  2. 在图形顶部，选择 Reusables，然后选择 Subgraphs。

  3. 在 Subgraphs 窗口中，选择 Add custom subgraph。

配置子图输入

此时会打开一个新的空子图。

  1. 选择 Add input 在画布中央。

  2. 一个 输入 节点将出现。选择其下方的 编辑 。

  3. 在右侧窗格中，为此输入配置 必需列 。您可以手动添加列，也可以从现有数据集复制架构：

    • 要手动添加列，请选择 添加列 并输入列名称。
    • 要从现有数据集复制架构，请选择 从数据集。

如果您选择 从数据集，请选取要使用其架构的数据集，然后点击 选择按钮进行确认。输入节点现在需要来自所选数据集的列。

构建子图逻辑

定义好输入后，您就可以像构建任何其他管道一样构建子图：

  1. 从输入节点开始，使用节点菜单添加转换、拆分、联接和其他逻辑。
  2. 在转换路径的末尾创建一个 输出 节点。
  3. 确保在 输出 节点架构中正确定义所有预期的输出列。

完成后，选择右上角的 应用所有子图更改 。为子图指定一个清晰的名称。在此示例中，子图名为 Manually created subgraph。选择 关闭 以退出子图编辑器。您的子图现在可以用作可复用块。

向管道添加子图

您可以在输出与子图的输入架构相匹配的任何节点之后添加子图。有两种入口方式：

  • 在工具栏中，选择 将子图应用于表格。

  • 在节点菜单中，选择 子图。

选择并映射子图

  1. 选择子图应从其开始的管道节点。

  2. 选择 将子图应用于表格，或选择 子图 （位于节点菜单中）。

  3. 在出现的横幅中，打开 选择子图 下拉菜单并选择您的子图。

  4. 将子图的 输入 映射到图中所选的节点。如果您从该节点开始，Pipeline Builder 会自动完成此映射。选择 开始。

查看并应用

子图配置面板随即打开：

  • 输入 显示所选节点如何为子图提供输入。
  • 配置 在子图没有需要配置的参数时为空。

查看 输出 标签页以确认生成的架构，然后选择 应用 和 关闭。

如果子图的输入未包含所有必需的输入列，架构错误将显示在 错误 标签页和管道图中。

从现有节点创建子图

您可能已经有一个想要重复使用的节点序列。您可以将这些节点直接转换为子图，或者将它们替换为已创建的子图。

选择要打包的节点

  1. 在主管道中，选择要打包的节点。例如，您可以选择由连接、排序和聚合组成的序列。
  2. 右键单击所选内容，然后选择 子图。
  3. 要将节点打包成新的子图，请选择 创建子图。要将所选节点替换为现有子图，请选择 替换为子图。

此时会打开一个新的子图编辑器，其中包含所选节点以及自动创建的 输入 和 输出 节点（其架构已填充）。

当子图有效且未出现架构错误时，请选择 应用所有子图更改。

添加多输入子图

当您的子图具有多个输入时，您需要在应用子图时分别映射每个输入。

  1. 在主图中，选择与每个子图输入对应的起始节点。
  2. 从工具栏中选择 将子图应用于表格 ，或从节点菜单中选择 子图 。
  3. 从下拉菜单中选择您的子图。
  4. 在 映射输入 部分，将每个子图输入映射到图中的一个节点。例如，将 Student 映射到重命名转换，并将 Class 映射到类型转换。选择 开始。

子图配置窗口随即打开，其中显示已映射的输入和输出预览。确认输出无误后，选择 应用 和 关闭。

返回主画布后，该子图将显示为一个单独的节点，其输出架构（例如 class_id 和 avg_score）会显示在预览面板中。

然后，您可以重新连接相关节点以使用子图输出，并在其他位置使用同一子图的其他实例来替换重复的逻辑。
