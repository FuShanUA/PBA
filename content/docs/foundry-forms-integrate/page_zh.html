可以使用两个 Slate 微件在 Slate 中嵌入表单：

  • Foundry Form
  • Iframe

使用 iframe 时，可以使用以下 URL 参数自定义表单的显示：

  • embedded=true：在 iframe 中嵌入表单时必须提供。
  • noHeader=true：将移除表单的页眉。
  • progressOnly=true ：将仅渲染进度条作为页眉；当 noHeader=true.
  • forceDarkMode=true：将以深色模式渲染表单。

对象浏览器

可以使用三种 区块微件 在对象视图中嵌入表单：

  • 编辑对象表单
  • 创建关联对象表单
  • iframe

此外，Forms 支持 批量编辑多个对象 （通过一个以对象为支撑的表单）。

编辑对象表单

要添加 编辑对象表单 区块：

  1. 创建 与对象类型关联的表单 X.
  2. 导航到以下对象的 Object View： X，然后选择 操作 从您的本地克隆创建并推送 git 标签，例如 编辑对象视图.
  3. 将 编辑对象表单 section.

直方图 Default Form ID 可以在 Forms URL 中找到： /workspace/fforms/v1/entry/<form-id>/new.

在监听器设置向导的 Prefilled Values 区块：

  • 可以使用 Code Editor.
  • 值本身可以是静态的（2000-01-01）或取自当前对象的某个属性（{{start_date}}，其中 start_date 是对象类型的属性 ID X).

直方图 Conditional Form 区块可用于根据某个属性的值渲染不同的表单。

创建关联对象表单

添加和配置此区块的方式与 编辑对象表单非常相似，但有两个显著区别：

  1. 该区块应添加到以下对象的 Object View 中： Y，该视图与 X.
  2. 表单可以基于最近关联的对象进行预填，并且可以提供排序属性来自定义“最近”的定义。

批量编辑多个对象

默认情况下，此功能在以对象为支撑的表单上是禁用的。通过切换 允许此表单批量编辑（在操作菜单中） 菜单中选择 设置 选项卡（位于表单右侧的 Visual Editor 中）来启用它。

默认情况下，您最多可以通过一个表单编辑 200 个对象。如果您的用例需要更大的限制，请联系您的 Palantir 代表。

启用后，请按照以下步骤批量编辑多个对象：

  1. 导航到 Object Explorer 并选择要编辑的对象。
  2. 选择 添加输入参数 按钮并选择 在 [name-of-the-form] 中编辑 [number-of-selected-objects] 个对象.
  3. 表单将在对话框中打开，允许您覆盖所有选定对象上的属性。

处于批量编辑模式的表单将覆盖所有选定对象上该表单中的所有属性。我们建议在此类表单中仅使用必填字段。使用 required 验证器确保在提交前已填写值。
