在 AIP Chatbot Studio 中将命令用作工具

您可以将 命令 作为 工具添加到 AIP 聊天机器人，使聊天机器人能够在 Palantir 应用程序中与用户交互并代表用户执行操作。命令直接在用户的应用程序中运行，可访问当前的应用程序状态和屏幕。这实现了传统后端工具难以支持的集成。例如，聊天机器人可以使用命令来导航用户界面，比如将视图设置为地图上的特定位置。

您还可以配置 Workshop 的 Button Group、 Metric Card和 App Pairing 小部件，用于在任何生成命令的应用程序中触发操作。

向 AIP 聊天机器人添加命令工具

一旦应用程序声明并生成命令，聊天机器人便可以将命令用作工具。要将命令作为工具添加到聊天机器人，请选择 Add tool > Commands ，该选项位于 Chatbot configuration 面板中。

请在 Search commands... 模态框中搜索并选择一个或多个命令。如需为某个命令的每个实例 配置不同的提示 ，可以多次选择该命令。将所选命令添加到您的聊天机器人，并根据需要应用配置。

将命令用作工具的 AIP 聊天机器人具有一个保留窗口，该窗口会在闲置 24 小时后自动过期。

配置命令工具 [Beta]

配置用作聊天机器人工具的命令的功能目前处于 beta 阶段。其配套界面在开发过程中可能会发生变化。如有关于在 AIP Chatbot Studio 中将命令配置为工具的问题，请联系 Palantir 支持团队。

在将一个或多个命令作为工具添加到您的聊天机器人后，您可以选择一个命令来打开一个模态框，其中包含聊天机器人用于指导其操作的附加配置。选择 显示更多 以呈现附加文档，帮助您进一步了解每个工具的可选配置设置，例如其输入参数以及调用时的预期行为。

查看以下章节，了解更多附加配置选项。

附加描述

提供特定于命令的上下文 ，以补充 用于帮助聊天机器人的支撑模型理解其将要执行的操作的默认文档。虽然每个命令都包含帮助聊天机器人将其用作工具的默认文档，但您可以在 附加文档 中提供更多详细信息，以帮助聊天机器人精确决定 何时 以及 如何 它应调用该工具。例如，您可以指示 移除所有要素 命令在绘制新要素之前移除临时要素（如果现有要素与新要素不存在某种关联）。

输入参数

某些命令在配置为工具时会接受输入参数。请使用 输入参数 为命令参数设置输入值，例如 填充图案 或 描边宽度 （适用于 绘制多边形 命令）。

默认情况下，聊天机器人会根据您的 指令 和用户的提示来确定所有必需参数的值。对于可选参数，聊天机器人可以选择根据您的 指令 和用户的提示来确定该值。

要覆盖默认行为，请选择 添加参数覆盖，选择要覆盖的参数，然后使用以下覆盖选项之一对其进行配置：

  • 聊天机器人决定（默认）： 由聊天机器人确定该值。这是默认行为。
  • 预设值： 硬编码一个静态值，以便始终将相同的值用作输入参数。
  • 应用程序变量： 使用预配置的字符串或对象集 变量。
  • 不将参数传递给聊天机器人： 指示聊天机器人不要为可选参数提供值。此选项仅适用于可选参数。

在执行前请求用户批准

默认启用后，您的聊天机器人将要求用户查看命令负载数据，并 拒绝 或 批准 其提示产生的命令操作或输出，然后才会执行该命令。禁用后，您的聊天机器人将根据用户的提示执行命令，无需人工批准干预。

测试 AIP 聊天机器人将命令用作工具的能力

在 AIP Chatbot Studio 中配置命令后，您可以按照以下说明测试您的聊天机器人并验证其配置 ，然后 您 保存并发布 ，使其在生产应用程序中可用：

  1. 在单独的浏览器窗口中，打开生成您的聊天机器人命令工具的应用程序，并将其与 AIP Chatbot Studio 中包含您的聊天机器人的窗口并排放置。
  2. 选择 选择要配对的应用... > 配对 ，适用于在单独浏览器窗口中启动的应用程序（例如 Gaia 地图）。

  1. 在您的聊天机器人的聊天输入窗口中输入提示，以测试其将您添加的命令用作工具的能力。

当您对聊天机器人的配置感到满意后，即可发布该聊天机器人，将其用作嵌入 AIP Assist 中的助手，或在 Workshop 内的 AIP Chatbot 小组件中使用。

如果您 将聊天机器人发布为函数 ，并在不支持命令的环境中执行它（例如将其配置为在 Automate中构建的自动化中运行），则聊天机器人将忽略作为工具的命令。如果您对环境有任何疑问，请联系 Palantir 支持团队。

将您的聊天机器人与多个应用程序配对

通过 App Pairing，您的聊天机器人将自动发现您在浏览器中打开的其他应用程序。要将聊天机器人与多个应用程序实例配对，请选择 添加 （位于 已发现 应用程序旁边），以创建配对 组。

如果您的聊天机器人未与用于执行命令的应用程序配对，它将提示用户选择要配对的应用程序。

将您的聊天机器人嵌入 AIP Assist 或 Workshop

虽然您可以将 AIP Chatbot Studio 与已配对的应用程序结合使用来测试聊天机器人的性能，但您应将聊天机器人嵌入 Workshop 模块或 AIP Assist 面板中，以获得更流畅的用户体验。在这两种情况下，聊天机器人都会自动与其交互的应用程序配对。

将您的聊天机器人发布到 AIP Assist

要使您的聊天机器人可供 AIP Assist 使用，请在 AIP Chatbot Studio 中选择屏幕左侧的火箭图标以启动 使用情况 面板，然后选择 AIP Assist 开关。接下来，选择 发布 按钮（位于屏幕右上角）。这会将最新发布的聊天机器人版本部署到 AIP Assist，之后您将能够从 “与 AIP 聊天机器人对话” 菜单（位于 AIP Assist 聊天面板中）中选择它。

选择聊天机器人后，AIP Assist 将自动与目标应用程序配对，并且所有配置为工具的相关命令都将作用于该应用程序。如果您的聊天机器人包含适用于多个应用程序的工具，但 未 与这些应用程序配对，则 AIP Assist 将提示您在已打开的某个浏览器标签页中选择要配对的应用程序。

将您的聊天机器人添加到 Workshop

使用 Workshop 的 AIP Chatbot 小部件将您的聊天机器人嵌入模块中，您还可以使用 Iframe 小部件将一个或多个应用程序嵌入到 分区中 位于 AIP Chatbot 小部件旁边。Workshop 模块中的 AIP Chatbot 小部件和 iframe 嵌入式应用程序将自动配对，您配置为工具的所有相关命令都将作用于该 iframe 嵌入式应用程序。
