提取器

Palantir Foundry Connector 2.0 for SAP Applications（"Connector"）支持通过多种称为 SAP 提取器的提取接口进行数据摄取。这些提取器最初设计用于从 SAP 操作系统向 SAP Business Warehouse (BW) 提取数据。

提取器有 3 种类型：

  • 业务内容提取器 是 SAP 针对各种应用组件（如 FI、CO、LO Cockpit 等）标准预交付的提取器。它们在源系统中默认未激活，需要通过 RSA5 事务代码激活后方可使用。
  • 客户生成的提取器 通常基于客户实施和配置设置生成。
  • 通用提取器 具有高度可定制性。每个客户都可以基于数据库表/视图、信息集和函数模块生成自己的提取逻辑。这些提取器高度可定制，提取逻辑由客户控制。

Connector 只能使用启用 ODP 的提取器。完整的 "ODP Data Replication API 2.0" 需要相应组件（PI_BASIS、SAP_BW 或 DW4CORE）具备以下支持包 (SP)，参见 SAP Note 1931427 - ODP Data Replication API 2.0。在配置提取器之前，请确保每个源系统满足以下前提条件：

  • PI_BASIS 730 SP 14（属于 SAP NetWeaver 7.30 SP 14）+
  • PI_BASIS 731 SP 16（属于 SAP NetWeaver 7.03 SP 16 和 7.31 SP 16）+
  • PI_BASIS 740 SP 11（属于 SAP NetWeaver 7.40 SP 11）+
  • SAP_BW 750 SP 0（包含以前的 PI_BASIS 包）+
  • DW4CORE 100 SP 0（包含以前的 PI_BASIS 包）+
  • DW4CORE 200 SP 0（包含以前的 PI_BASIS 包）+

有关启用 ODP 的提取器所在源系统中的授权，请参阅 SAP Note 2855052 - ODP Data Replication API 2.0 所需的授权。 Connector 还有一个单独的提取器角色：将 /PALANTIR/CONTENT_EXT_ALL 授权角色分配给 Foundry 技术用户。

提取器配置

从单个源系统（Connector 版本低于 v2.20.0 (< SP20)）

  • 创建从 Connector 到提取器所在 SAP 源系统的 RFC 连接。
  • 使用直方图中的 /n/palantir/param 事务维护以下参数：
    • RFC 参数
      • 参数 ID： EXTRACTOR
      • 参数名称： RFC_CONFIGURATION
      • 参数值： <RFC connection name>
    • 上下文配置
      • 参数 ID： EXTRACTOR
      • 参数名称： CONTEXT_CONFIGURATION
      • 参数值： SAPI

从多个源系统（Connector 版本 v2.20.0 或更高 (>= SP20)）

从 Connector 的 SP20 开始，可以从多个源系统（也称为"上下文"）提取数据。

要配置多个上下文，请按照以下步骤操作：

  • 运行 /PALANTIR/PARAM_E1 事务并定义每个上下文：

    • 提取器 ID： <Source System ID>
    • 描述： <Description of Source System>

  • 运行 /PALANTIR/PARAM_E2 事务并定义每个上下文参数：

    • 提取器 ID： <Context ID>
    • 参数 ID： <Connector parameter ID>
    • 参数名称： <Connector parameter name>
    • 参数值： <Parameter Value>

    RFC 和 SOURCE 参数是特定于多上下文的；其他提取器参数为标准 Connector 参数.

  • 其中一个上下文可以设置为默认上下文。在这种情况下，如果 Foundry 未指定上下文信息，Connector 将使用默认上下文。要定义默认上下文，请运行 /PALANTIR/PARAM 事务并使用以下参数值：

    • 参数 ID： EXTRACTOR
    • 参数名称： DEFAULT_CONFIGURATION
    • 参数值： <EXTRACTOR ID>

使用提取器

  • 使用程序 RODPS_OS_EXPOSE 在 SAP 源系统中公开 SAP 提取器。
  • 重启 Foundry Data Connection 代理 以刷新缓存。
  • 创建新的 BW 内容提取器 sync.
