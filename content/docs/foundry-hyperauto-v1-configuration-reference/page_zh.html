配置参考

日落

HyperAuto V1 目前处于 日落 阶段，并将在未来某个日期被弃用。目前仍提供全面支持。不建议创建新的 V1 管道，用户应从 HyperAuto V1 迁移到 V2，具体步骤详见 迁移文档.

SDDI 的管道由完全自动化的代码仓库生成。要了解相关步骤，请阅读 管道生成. Cockpit 是与这些配置进行交互的默认位置，但如果要设置高级参数或配置非标准源类型，您可能需要手动修改配置文件。

配置在位于以下位置的两个主要文件中进行 transforms-bellhop/src/config/ 文件夹：

  • SourceConfig.yaml
  • PipelineConfig.yaml

本页所述的高级手动设置如果应用不当，可能会使您的 SDDI 管道进入损坏状态。在部署到生产环境之前，请务必先在分支上验证更改。

参数描述

参数描述
sourceName用于标识源系统的名称。用作主键和外键的前缀。
sourceRid附加到此 SDDI 实例的源的 RID。
sapContext（可选）SAP 上下文的详细信息。
rawFolderStructure定义原始数据和元数据所在的文件夹。
cleaningLibraries要应用于所有表的清理库列表。
deduplicationConfig（可选，默认值：None）用于指定去重逻辑所使用列的配置。
metadataSparkProfiles（可选，默认值：None）要应用于元数据生成的 Spark 配置文件列表。
languageKey（可选，默认值：'E'）富化处理中使用的语言。
deploymentSemanticVersion（可选，默认值：0）管道的语义化版本；递增该版本将强制生成快照。
tables来自该源且将由 SDDI 处理的表列表。

sapContext

（可选）SAP 上下文的详细信息。SAP Explorer 将使用此信息预选上下文。每个上下文都需要有其自己的 SourceConfig 文件。

rawFolderStructure

定义原始数据和元数据所在的文件夹。

字段：

  • raw: 用于摄取原始表的文件夹路径。
  • dataDictionary: （可选，默认值：raw）用于摄取元数据表的文件夹路径。

cleaningLibraries

要应用于所有表的清理库列表。清理函数定义在 transforms-bellhop/src/software_defined_integrations/transforms/cleaned/function_libraries.

添加或删除函数需要递增 deploymentSemanticVersion.

deduplicationConfig

（可选，默认值：None）用于指定去重逻辑使用哪些列的配置。此处定义的配置将应用于所有表。

字段：

  • comparisonColumns: 将根据这些列的最大值来确定主键的唯一性。
  • changeModeColumn: （可选）如果指定，在此列中值为 D 的行将被删除。

deploymentSemanticVersion

（可选，默认值：0）管道的语义化版本；递增该版本将强制生成快照。

请参阅 增量转换 以了解 deploymentSemanticVersion 对增量转换和快照转换的影响。

metadataSparkProfiles

（可选，默认值：None）要应用于元数据数据集生成的 Spark 配置文件列表（objects, fields, links 和 diffs).

请确保这些配置文件 已添加到仓库 在此处引用它们之前。

tables

来自已定义源、将由 SDDI 处理的表列表。

字段：

  • tableName: 元数据中该表的名称。
  • datasetTransformsConfig
    • datasetName: 原始数据的 Foundry 数据集名称。
    • deduplicationComparisonColumns: 用于对数据进行去重并指定去重逻辑使用哪些列的表级配置。在全局去重字段之后应用。
    • changeModeColumn: （可选）如果指定，在此列中值为 D 的行将被删除。在全局变更模式列之上应用。
    • batchUnionComponents: 在执行清理步骤之前应进行合并的输入数据集名称列表。
    • sparkProfiles: （可选）在不同转换阶段应用的 Spark 配置文件。
      • profiles: Spark 配置文件；请参阅 有关将它们添加到仓库的详细信息.
      • stages: （可选，默认值：None）要应用配置文件的转换阶段。值应为 [CLEANED, DERIVED, ENRICHED, FINAL, RENAMED, RENAMED_CHANGELOG] 之一。如果为 None，则配置文件将应用于所有阶段。
    • tableCleaningLibraries: 要应用于此表的清理库列表。清理函数定义于 transforms-bellhop/src/software_defined_integrations/transforms/cleaned/function_libraries。添加或删除函数将需要您递增 deploymentSemanticVersion.
    • enforceUniquePrimaryKeys: （可选，默认值：False）。如果为 True 且 deduplicationComparisonColumns 已定义，则保证在去重阶段每个主键仅保留一条记录。这可能导致非确定性行为。

sourceName: HyperAuto
sourceType: SAP_ERP
sourceConfigFileNames:
  - SourceConfig.yaml
outputFolder: /HyperAuto/source/output
workflows:
  my_workflow:
    variables:
      - name: my_variable_name
        value: my_variable_value
    enrichments:
      - my_enrichment_name
tables:
  ABCD:
    displayName: Header Table
    types:
      - OBJECT
  WXYZ:
    displayName: Item Table
    types:
      - OBJECT
      - METADATA
disableForeignKeyGeneration: False
disableEnrichedStage: False
disableRenamedStage: False

参数描述

参数描述
projectName项目名称。用作本体论对象的前缀。
sourceTypeSDDI 支持的数据源类型。应为 [SAP_ERP, SALESFORCE, ORACLE_NETSUITE] 之一。
sourceConfigFileNames要包含在管道中的 SourceConfig 文件名列表。
outputFolder定义输出数据集将写入的文件夹。
workflows要部署的工作流列表（包含配置）。
tables在此 SDDI 管道中处理的表列表。
disableEnrichedStage（可选，默认值：False）若启用，将不会生成富化数据集。请谨慎使用，因为启用后会破坏工作流。
disableRenamedStage（可选，默认值：False）若启用，将不会生成 renamed_changelog 数据集。请谨慎使用，因为启用后会破坏工作流。
disableForeignKeyGeneration若启用，将不会生成外键列。请谨慎使用，因为启用后会破坏工作流。

tables

在此 SDDI 管道中处理的表列表：

  • displayName: 表的人类可读名称。输出数据集名称将按以下形式构建 displayName (technicalName)
  • types: 此表表示的数据类型列表（可以有多个）。
    • 对象： 构成本体论中对象的主数据表。
    • 元数据： 包含对象信息以及主键构建信息的元数据表。
    • 自定义： 联接到主数据表的增强表，联接发生在 enriched SDDI 管道的步骤。
