形状

使用形状在地图上选择一个地理空间区域,以便在其中搜索对象、选择地图上已有的对象、执行操作或创建注释。

创建形状

对形状的所有可用操作都需要先有一个活动形状。请通过以下任一方式创建形状:

  • 使用 绘图工具自行构建形状。
  • 使用当前选定的对象和注释创建形状,使其覆盖 与您所选内容相同的地理空间区域。

绘制形状

在工具栏中选择一种 绘图方法 选项,或在键盘上按下 D 以在地图上手动绘制形状。

点击当前绘图模式即可打开下拉菜单,从中选择各种可用模式:

从选定内容

您还可以根据地图上当前选定的内容创建形状。右键点击任一选定的对象,然后使用 从选定内容创建形状 菜单项。

修改形状

您可以使用形状工具栏中的 修改 按钮来编辑地图上的活动形状。

有多种可用的修改工具:

  • 编辑点: 允许您拖动单个顶点来修改多边形、线条或点。
  • 缓冲区: 允许输入特定距离，以扩大或缩小形状的周长。
  • 平移： 允许通过拖动来移动整个形状。
  • 替换： 放弃当前绘制的形状，并打开绘图工具以绘制新形状。

完成修改后，使用 完成 按钮即可返回形状工具栏。

使用活动形状执行操作

在存在活动形状的情况下，使用 形状 工具栏执行各种操作：

  • 选择相交： 选择地图上所有位于可见图层中且与当前形状相交的对象。
  • 范围内搜索： 打开 添加对象 面板并筛选结果，以仅包含地理空间数据与当前形状相交的对象。请注意，只有具有 geohash 或 geoshape 属性 的对象才能被搜索。
  • 操作： 显示所有使用形状的可用本体论操作。有关配置地理空间操作的更多信息，请参阅 操作。请注意，只有在本体论中配置了地理空间操作后，操作按钮才会显示。
  • 删除： 从地图界面中移除所选形状。
