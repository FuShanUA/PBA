SAP ERP

SAP ERP 连接器允许您将 Foundry 连接到 SAP 的本地 ERP Central Component (ECC) 和 S/4 HANA（本地和 云私有版 ↗）。SAP ERP 连接器使 Foundry 能够与各种类型的 SAP 数据进行交互，包括：

  • SAP 应用程序表
  • SAP CDS 视图
  • SAP HANA 信息视图
  • SAP BW 内容提取器（仅限远程连接）
  • SAP 事务代码和 ABAP 报表
  • SAP 功能模块
  • SAP 媒体（DMS 文档）

使用 SAP ERP 源需要安装 Palantir Foundry Connector 2.0 for SAP Applications 附加组件 在目标 SAP 应用层上。

增量同步支持从同一表进行追加式事务。要启用增量同步，请设置 事务类型 to APPEND.

  • 多个字段： 导入指定字段中任意一个字段的值大于或等于已导入的最大值的行。字段之间用逗号分隔。
  • 拼接字段： 与多个字段模式相同，但会将字段值拼接在一起，而不是使用 OR 进行组合。
  • 变更文档表： 根据 SAP 变更文档表中的更新导入行。有两种子模式可用： 仅 CDPOS or CDHDR 和 CDPOS.
  • 孪生表： 当单独的“孪生”表中的某个字段满足增量条件时，从目标表导入行。
  • SAP 内置增量： 使用提取器原生的变更数据捕获机制。

增量字段理想情况下应为单调递增的值。系统使用“大于或等于”比较，以避免在同步于某个日期中途运行时遗漏数据。Foundry 数据集中可能出现重复值，应在转换管道的第一步中将其删除。

事务代码和函数模块对象类型不支持增量同步；它们始终以快照方式运行。

重置增量状态

要强制执行完整重新加载并重新初始化增量摄取，请启用 重置增量状态 同步上的开关。这会执行来自 SAP 的数据完整快照，替换数据集中的所有文件。同步完成后，请禁用该开关，以便后续同步恢复增量追加。

ERP 表、CDS 视图、HANA 视图和 BW 内容提取器对象类型支持重置增量状态。

媒体集

SAP ERP 连接器支持 媒体集 用于摄取存储在 SAP 文档管理系统 (DMS) 中的媒体文件和文档。

创建新的媒体摄取：

  1. 导航到源概览页面。
  2. 选择 + 新建 + 新建 媒体集同步.
  3. 定义您的媒体集格式。提供特定格式将使您能够在下游数据转换中使用特定于该格式的转换步骤。阅读更多关于 媒体集格式.
  4. 使用源探索工具（按文档类型组织文件）选择您要摄取的文件，或直接在 一个 section.

探索

当您选择 子文件夹或媒体文件中定义您自己的筛选器，您可以选择特定的文档类型（如 CPD）来摄取所有关联的文档，或选择单个文档以仅摄取该特定文件。

Webhook

SAP webhook 允许您通过从 Foundry 调用函数模块（通常是 BAPI，即业务应用程序编程接口）将数据写回 SAP。请参阅 Webhook 以了解如何设置 webhook 的概述。

SAP webhook 支持 您必须正确配置出站策略（如果使用 在 Foundry 托管的云计算中的连接。对于 SAP webhook，我们推荐使用此运行时，而不是通过 数据连接代理执行。在 Foundry worker 上配置的现有 SAP 源会自动受益于云执行，无需迁移；在数据连接代理上运行的 SAP 源应 切换到 Foundry worker 以利用云端执行的 webhook。

要调用 BAPI，请选择 sap-erp-run-function-webhook-task-v0 任务类型。

该 webhook 任务主体 是一个 JSON 文档，使用 Handlebars ↗ 语法编写，用于指定要调用的 SAP 函数模块、提供其输入并选择要返回的输出。

任务主体字段

字段必需类型描述
function-name是字符串要调用的 SAP 函数模块或 BAPI，例如 BAPI_SALESORDER_CHANGE.

Webhook 的执行可以在 SAP 端并行化。当 inputs 是包含多个对象的数组，或当您显式提供 parallel 块（即使是空块）时，会自动进行并行化。使用可选的 parallel 块来调整执行：

  • max-jobs —— 同时运行的最大作业数。
  • max-calls-per-job —— 每个作业处理的最大记录数。

省略的设置将使用 SAP 附加组件中定义的值，默认为 3 个作业，每个作业 4 次调用。

  • ROWNO 是匹配条目在您的 inputs 数组中的位置（从 1 开始），因此您可以将每个结果映射回其对应的输入。
  • MSG 是该记录的 SAP 消息日志。每条消息都有一个类型（MSGTYP: S 表示成功， E 表示错误， W 表示警告， I 表示信息，或 A 表示中止）和文本（MSGTXT）。由于每条记录都会报告自己的消息，您可以查看哪些记录成功、哪些记录失败。

不成功的 HTTP 响应会导致 webhook 返回错误。成功的 webhook 响应仍可能包含 SAP 业务错误。请请求并检查 SAP RETURN 输出（如果可用），并逐条检查记录的 MSG 条目，以确定所请求的更改是否成功。

切换到版本 2时，请移除任何大于 retries-per-request 的 0.

在代码仓库中使用

SAP ERP 数据源可以导入到 Python 外部转换 or 函数，使您的代码可以直接访问 SAP 附加组件的 REST API。当批量同步、媒体集同步或 webhook 无法提供足够的控制时，请使用此方法。例如，从 Workshop 操作中同步调用 BAPI、遍历大型输入数据集并逐行调用 BAPI、根据 Foundry 侧的数据获取特定的 DMS 文档，或在单次构建中串联多个 SAP 调用。

以下示例使用以下端点，均相对于数据源 URL（https://<host>:<port>/sap/palantir):

Endpoint用途
POST /v2/function/{functionName}/writeback同步调用单个函数模块（BAPI）。
POST /v2/function/{functionName}/parallel_writeback同步调用具有批量输入的函数模块，并在服务器端并行化。
GET /v2/get_documents列出 DMS 文档，可选择按文档类型、文件格式、文件名或对象关联进行筛选。
GET /v2/get_document按 ID 下载单个 DMS 文档。

  • 对于函数，请按照 在函数中进行 API 调用 并在 @function(sources=[...]) decorator.

from transforms.api import Input, Output, transform
from transforms.external.systems import external_systems, Source, ResolvedSource


@external_systems(
    sap_source=Source("<source_rid>"),
)
@transform(
    sales_order_updates=Input("<input_dataset_rid>"),  # columns: sales_doc_id, purchase_date (YYYYMMDD)
    writeback_results=Output("<output_dataset_rid>"),
)
def update_purchase_dates(ctx, sap_source: ResolvedSource, sales_order_updates, writeback_results):
    base_url = sap_source.get_https_connection().url
    client = sap_source.get_https_connection().get_client()

    results = []
    for row in sales_order_updates.dataframe().collect():
        response = client.post(
            f"{base_url}/v2/function/BAPI_SALESORDER_CHANGE/writeback",
            json={
                "commit": True,
                "input": {
                    "SALESDOCUMENT": row.sales_doc_id,
                    "ORDER_HEADER_IN": {"PURCH_DATE": row.purchase_date},
                    "ORDER_HEADER_INX": {"UPDATEFLAG": "U", "PURCH_DATE": "X"},
                },
                "output": ["RETURN"],
            },
        )
        response.raise_for_status()
        results.append({
            "sales_doc_id": row.sales_doc_id,
            "purchase_date": row.purchase_date,
            "status_code": response.status_code,
            "sap_return": str(response.json()),
        })

    writeback_results.write_dataframe(ctx.spark_session.createDataFrame(results))

在您的终端会话中将 "commit": true 适用于需要提交语句才能持久化其更改的标准 BAPI。使用 metadata 端点（GET /v2/function/{functionName}/metadata）在调用函数之前发现其预期的输入和输出结构。

from functions.api import function
from functions.sources import get_source


@function(sources=["sap_source"])
def update_sales_order_purchase_date(sales_doc_id: str, purchase_date: str) -> str:
    """Updates the purchase date on a sales order via BAPI_SALESORDER_CHANGE.

    Args:
        sales_doc_id: SAP sales document number.
        purchase_date: New purchase date in YYYYMMDD format.

    Returns:
        A string representation of the SAP RETURN table, useful for surfacing
        any error or warning messages back to the caller.
    """
    source = get_source("sap_source")
    base_url = source.get_https_connection().url
    client = source.get_https_connection().get_client()

    response = client.post(
        f"{base_url}/v2/function/BAPI_SALESORDER_CHANGE/writeback",
        json={
            "commit": True,
            "input": {
                "SALESDOCUMENT": sales_doc_id,
                "ORDER_HEADER_IN": {"PURCH_DATE": purchase_date},
                "ORDER_HEADER_INX": {"UPDATEFLAG": "U", "PURCH_DATE": "X"},
            },
            "output": ["RETURN"],
        },
        timeout=30,
    )
    response.raise_for_status()
    return str(response.json())

from transforms.api import Input, Output, transform
from transforms.external.systems import external_systems, Source, ResolvedSource


@external_systems(
    sap_source=Source("<source_rid>"),
)
@transform(
    sales_order_updates=Input("<input_dataset_rid>"),
    writeback_results=Output("<output_dataset_rid>"),
)
def update_purchase_dates_parallel(
    ctx, sap_source: ResolvedSource, sales_order_updates, writeback_results
):
    base_url = sap_source.get_https_connection().url
    client = sap_source.get_https_connection().get_client()

    bulkinput = [
        {
            "SALESDOCUMENT": row.sales_doc_id,
            "ORDER_HEADER_IN": {"PURCH_DATE": row.purchase_date},
            "ORDER_HEADER_INX": {"UPDATEFLAG": "U", "PURCH_DATE": "X"},
        }
        for row in sales_order_updates.dataframe().collect()
    ]

    response = client.post(
        f"{base_url}/v2/function/BAPI_SALESORDER_CHANGE/parallel_writeback",
        json={
            "commit": True,
            "output": ["RETURN"],
            "bulkinput": bulkinput,
            "parallel": True,
            "paralleljobs": 5,
            "functioncallperjob": 10,
        },
    )
    response.raise_for_status()

    results = [
        {"index": i, "result": str(r)} for i, r in enumerate(response.json())
    ]
    writeback_results.write_dataframe(ctx.spark_session.createDataFrame(results))

调整 paralleljobs （在 SAP 中启动的后台作业数）和 functioncallperjob （每个作业处理的调用数），具体取决于工作负载和 SAP 系统上的可用容量。将 "parallel": false 设置为回退到顺序执行，同时仍使用单个批量请求。

import io
from transforms.api import transform
from transforms.external.systems import external_systems, Source, ResolvedSource
from transforms.mediasets import MediaSetOutput


@external_systems(
    sap_source=Source("<source_rid>"),
)
@transform(
    documents=MediaSetOutput("<media_set_rid>"),
)
def fetch_dms_documents(ctx, sap_source: ResolvedSource, documents):
    base_url = sap_source.get_https_connection().url
    client = sap_source.get_https_connection().get_client()

    # List documents in DMS, filtered by document type and file format.
    list_response = client.get(
        f"{base_url}/v2/get_documents",
        params={"DOCUMENTTYPE": "CPT", "FILEFORMAT": "pdf"},
    )
    list_response.raise_for_status()

    for doc in list_response.json():
        document_id = doc["DOCUMENT_ID"]
        document_name = doc["DOCUMENT_NAME"]

        download_response = client.get(
            f"{base_url}/v2/get_document",
            params={"DOCUMENT_ID": document_id},
        )
        download_response.raise_for_status()

        documents.put_media_item(io.BytesIO(download_response.content), document_name)

要从 Foundry 输入数据集驱动数据摄取，例如，仅获取由 EBELN （采购订单）值列表所引用的文档，请调用 /v2/get_documents 并带有 OBJECTLINK 过滤器，或将每个 DOCUMENT_ID 直接传递给 /v2/get_document （使用输入行中的数据）。
