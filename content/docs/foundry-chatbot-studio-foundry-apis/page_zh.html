通过 Foundry API 使用 AIP 聊天机器人

要在 Foundry 平台之上构建应用程序并将聊天机器人嵌入到您的应用程序中，您可以使用 Palantir API。

我可以使用这些 API 做什么？

通过 API 与您的聊天机器人轻松构建多轮交互，并使用其选项来：

  • 为给定任务或上下文发起新对话，具体方法是 创建 与您的聊天机器人的新会话。
  • 编排复杂的往复任务提示，可使用 流式 或 阻塞式 API，其内置的状态管理功能可为您跟踪这些会话更新。
  • 通过 API 中的应用状态选项，向聊天机器人提供自定义应用程序输入。这些选项沿用了 parameter 之前在 Chatbot Studio 中使用的功能，现在以 Application state/variables 的形式提供。请使用 parameterInputs 字段以在请求中提供输入。使用 parameterUpdates 字段来获取阻塞式响应(或 在流式传输完成后加载会话交换 )以读取自定义输出。

对于无需进行大量会话管理的简单一次性任务,请考虑使用 作为函数的聊天机器人。您可以在第三方应用程序中使用 Palantir OSDK 将聊天机器人作为函数进行访问。

将 AIP 聊天机器人部署到 Developer Console 应用程序

配置并发布 AIP Chatbot 后，您可以创建并配置 Developer Console 应用程序，以便在自定义应用程序中与您的 AIP Chatbot 交互。

要让您的 Developer Console 应用程序使用 平台 API与您的 AIP Chatbot 交互，请按照 创建新的 Developer Console 应用程序 中的步骤操作，以创建可访问 Platform SDK 资源的新 SDK 应用程序：

要在本体论 SDK 应用程序中使用 AIP Chatbot，您必须将 AIP Chatbot 配置为仅使用单个本体论中的对象类型、操作类型或函数类型。

  1. 在 资源 页面，选择您的 AIP Chatbot 所使用的本体论，然后选择您的 AIP Chatbot 配置中使用的所有对象类型、操作类型和函数类型。请确保选择用于应用程序状态的类型，以及为您的 AIP Chatbot 配置的所有工具和检索上下文。
  2. 接下来，选择 Platform SDK 选项卡。在 项目访问下，添加包含您的 AIP Chatbot 的项目。要找到该 AIP Chatbot 所属的项目，请在 Chatbot Studio 中打开该 AIP Chatbot，并查看页眉中该 AIP Chatbot 名称旁边的文件系统路径详细信息。
  3. 如果您的 AIP Chatbot 配置为使用任何其他文件系统资源，例如媒体集，用于 文档上下文，请确保这些资源与您的 AIP Chatbot 位于同一个项目中，或者将这些资源所属的所有其他项目添加到 项目访问 部分。

  1. 最后，为 AIP Chatbots API 启用操作，相关设置位于 客户端允许的操作 表。要查看不同 AIP Chatbot 平台 API 所需的操作，请参阅 平台 API 文档。

要允许您的 Developer Console 应用程序在与 AIP Chatbot 的对话会话中创建和发送消息，您必须启用 AIP Chatbots 写入权限。

  1. 请参阅 Developer Console 文档步骤，以审查并最终完成您的应用程序的创建。

更新 Developer Console 应用程序中使用的 AIP Chatbot

在您将 Developer Console 应用程序配置为允许通过 Platform SDK 资源与 AIP Chatbot 进行交互后，如果您的 AIP Chatbot 所使用的任何本体论或平台资源被修改，您将需要更新该应用程序。

例如，如果您向 AIP Chatbot 添加任何新的对象类型、操作类型或函数类型，则必须将这些类型添加到您的应用程序在 Developer Console 中的 Ontology SDK 资源中。同样，如果您向 AIP Chatbot 添加任何平台资源（例如用于文档上下文检索的额外媒体集），则必须将这些资源添加到 Platform SDK 应用程序的资源。Developer Console 应用程序资源 不会 在您的 AIP Chatbot 使用的资源类型发生变化时自动更新。

在自定义应用程序中创建与 AIP Chatbot 的对话

要开始初始化新应用程序，请参阅以下语言的文档示例： TypeScript 或 Python，或者 将 SDK 添加到现有应用程序中。

创建应用程序后，请使用 Create Session 平台 API 为您的 AIP 聊天机器人创建新的对话。

该 会话 AIP Chatbot 的 API 需要您指定 agentRid 以供 AIP Chatbot 在对话会话交互中使用。

要找到该 RID，您可以打开 AIP Chatbot 所在的项目，选择该 AIP Chatbot，然后使用 复制到剪贴板 选项来复制文件概览中 元数据 下的 RID。

创建新会话后，请使用返回响应中的 sessionRid 值向 AIP Chatbot 发送新消息，并使用 Blocking continue session 或 Streaming continue session 平台 API 获取回复。使用阻塞式 API 可以等待 AIP Chatbot 的完整回复生成完毕后再接收，或使用流式 API 在 AIP Chatbot 生成回答文本的过程中接收文本流。

要加载会话的对话元数据，可以使用 Get Session API；要加载会话的交互历史（您的应用程序发送的消息以及 AIP Chatbot 的回复），可以使用 Get Content API。

您可以使用 Get Session Trace API 用于检索 AIP Chatbot 所执行的步骤序列，这对于调试或理解聊天机器人的推理过程非常有用。该端点需要一个 sessionTraceId ，您可以通过以下两种方式获取：

  • 对于新的交互：
    • 生成一个随机的 UUIDv4，用作 sessionTraceId ，在发送至 Blocking continue session 或 Streaming continue session API 的请求中。此选项允许您轮询 'Get Session Trace' API 并查看聊天机器人回答生成的实时追踪。
    • 检查 sessionTraceId 字段，该字段位于来自 Blocking continue session API 的响应中。
  • 对于已有的对话：
    • 检查 sessionTraceId 字段，该字段位于来自 Get Content API 的响应中的对话结果上。

请参阅平台 API 文档，获取有关如何在您的目标应用程序语言中使用这些 API 的代码示例。
