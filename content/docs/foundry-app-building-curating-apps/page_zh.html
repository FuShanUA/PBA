在 Applications Portal 中管理应用

Applications Portal 是一个用于发现和访问 Foundry 中所有应用的工具。这包括 (1) Foundry 核心平台应用，以及 (2) 管理员推广到 Applications Portal 的受信任自定义应用。

导航到 Applications Portal

您可以通过选择以下方式打开 Applications Portal： 应用程序门户 左侧边栏中的图标。您将能够查看在以下环境中构建的任何应用： 来运行该专业代码代理。你还可以通过, 将收集到的信息存储在，或 碳 您拥有以下权限的 推广。您还可以快速访问所有 Foundry 平台应用。

您可以将喜爱的应用“固定”到左侧边栏，以便快速访问。在 Applications Portal 中或编辑应用时，选择应用名称旁边的星形图标。固定后，一个名为 已推广的应用 的部分将显示在 Foundry 侧边栏中，其中包含您喜爱的已推广应用列表。

Applications Portal 的权限基于 文件系统权限。如果您拥有 Discoverer 角色，系统将提示您 请求访问权限.

Applications Portal 模式

Applications Portal 有两种使用模式：

  • 基础开箱即用模式：一个用于发现和了解所有 Foundry 平台应用的工具。无需管理员操作。即使没有任何已推广的自定义应用，Applications Portal 也是左侧边栏中不可或缺的工具。
  • 高级管理模式：管理员、Palantir 代表或客户治理团队将所有受信任的自定义应用推广到 Applications Portal。

Applications Portal 中的已推广应用

已推广应用是指被管理员标记为受信任且可用于生产环境的应用。每个已推广应用都包含以下必需的元数据，这些元数据将显示在 Applications Portal 和左侧边栏中：

  • 名称：可以与资源名称不同
  • 图标
  • 描述（可选）
  • 应用所有者
  • 缩略图
  • 集合和标签：您可以使用它们将已推广的应用分类到不同部分，并在 Applications Portal 中应用筛选器。集合是必需的，而标签是可选的。

已推广的应用会获得表示受信任内容的紫色对勾标记，类似于数据目录中的项目。

多租户注册中的每个注册或租户都有一个单独的 Applications Portal。用户可以查看的已推广应用仅限于其所属的 空间 所属的 配置。如果您有权访问共享空间，您还将看到该空间中的已推广应用。

将应用推广到 Applications Portal 的权限

管理员可以将 Workshop 模块、Slate 应用、Carbon 工作区或外部网页链接推广到 Applications Portal。将应用推广到 Applications Portal 的权限在以下位置授予： 控制面板。您必须拥有“Organization Administrator”或“User Experience Administrator”角色。您还必须是应用的编辑者或所有者才能推广该应用。

对于拥有应用及其空间至少 Discoverer 角色的所有用户，已推广的应用都会显示在 Applications Portal 中。

Applications Portal 中的分类

您可以使用集合和标签在 Applications Portal 中对应用进行分类，并应用筛选器以仅查看特定应用。

创建集合和标签或将其添加到已推广应用的权限与推广到 Applications Portal 的权限相同，均基于 Control Panel 中“Organization administrator”和“User experience administrator”角色。

和

集合在 Applications Portal 的左侧边栏中显示为各部分的标题。它们在 Applications Portal 中用作顶级类别，以策划您的体验。集合在 Data Catalog 中创建和管理。创建集合后，您可以从 Data Catalog 和文件系统中向其添加已推广的应用。

只有关联了已推广应用的集合才会显示在 Applications Portal 中，且前提是您有权查看/发现这些应用。如果某个集合没有关联任何已推广的应用，或者您无权访问该集合中的任何应用，则该集合不会显示。

标签

标签在已推广应用卡片上显示为标签，可以在 Applications Portal 的右上角进行筛选。您可以在以下位置创建和管理标签： 标签 平台设置的部分。标签创建后，可以在推广界面以及文件系统中添加到已推广的应用上。

只有关联了已推广应用的标签才会作为筛选器显示在 Applications Portal 中，且前提是用户有权查看/发现这些应用。如果某个标签未添加到任何已推广的应用，或者用户无权访问带有该标签的任何应用，则该标签不会显示。

在 Applications Portal 中管理平台应用

Foundry 平台应用包括 Quiver、Contour、Data Connection、Pipeline Builder 等工具。您可以在 Control Panel 的以下位置配置显示或隐藏用户平台应用的选项： 应用程序访问 选项卡。这使您可以仅在 Applications Portal 以及 Foundry 的其余部分中显示特定子组的应用。
