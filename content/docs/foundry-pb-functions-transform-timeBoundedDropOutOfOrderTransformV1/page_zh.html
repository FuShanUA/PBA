时间限定的乱序丢弃

支持环境：Streaming

删除所有键列值相同且乱序的行。如果某行根据排序列和排序方向本应出现在已接收的同键值行之前，则该行为乱序。两行比较时，先评估第一个排序列及其方向，当且仅当出现平局时才继续评估下一个排序列及其方向，依此类推，直到确定顺序或所有排序列均平局（此时两行相等）。每个键的当前最大值会被存储，直到在大于或等于过期时间的事件时间内没有再看到该键的新行。在某个键超过或达到过期时间未收到新行后，该键的任何新行都不会被丢弃，并将始终被存储为新的当前最大值。

转换类别: Other

声明的参数

  • 数据集： 用于丢弃乱序行的数据集。
    表格
  • 键过期时间单位： 存储给定键的最高记录的时间量单位。如果为某个键存储了状态，并且处理了一个具有大于此过期周期的水印的不同键，则该键的状态将过期，且该键的任何新记录都不会被丢弃。对于任何键，新记录都会将过期时间推迟到未来的这段时间之后，无论其是否具有最高的排序优先级。
    Enum<Days, Hours, Milliseconds, Minutes, Seconds, Weeks>
  • 键过期时间值： 存储给定键的最高记录的时间量值。如果为某个键存储了状态，并且处理了一个具有大于此过期周期的水印的不同键，则该键的状态将过期，且该键的任何新记录都不会被丢弃。对于任何键，新记录都会将过期时间推迟到未来的这段时间之后，无论其是否具有最高的排序优先级。
    Literal<Long>
  • 排序保证： 指定将定义流元素必须遵循的顺序的列和方向，以避免被丢弃。升序保证传入的流元素与所有之前的行相比必须相等或递增，才能避免被丢弃；降序则保证相反的情况。您可以指定多个列和方向，但第一列之后的列和方向仅在出现并列时才按顺序被考虑。在其他情况下它们不会生效。
    List<Tuple<Column<ComparableType>, Enum<Ascending, Descending>>>
  • 可选 按键分组的列： 用于按键对输入进行分区的列。共享相同键列值的行按接收顺序处理。具有相同键列的行的处理顺序可能与排序规范定义的顺序不同。当根据排序规范，某行应当被放置在已处理的具有相同键的存储最高优先级状态行之前时，该行被视为乱序。对于此类乱序行，只要该键的此类状态存在且尚未过期，它们就会在处理过程中被丢弃。
    Set<Column<Binary | Boolean | Byte | Double | Float | Integer | Long | Short | String | Timestamp>>
