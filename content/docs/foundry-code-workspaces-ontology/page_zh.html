与本体论交互

受限制的受支持视图支撑的本体论实体 和 查询函数 在代码工作区中尚不受支持。

代码工作区支持与 本体论 在 JupyterLab® 和 RStudio® 中使用对象、关联和操作类型进行交互。

创建新的本体论 SDK

要在代码工作区中创建新的本体论 SDK，请先导航至 本体论 侧边面板。每个代码工作区可以拥有一个 SDK，并且每个 SDK 可以创建多个版本。从 本体论 侧边面板中，选择 创建新 SDK 以打开 SDK 配置表单。

新的本体论 SDK 需要一个包名称和一个关联的本体论。包名称用于确定 SDK 在代码中的访问方式：包名称为 example 的 SDK 版本可以在库名称 example_sdk下导入。SDK 包名称只能包含字母、数字和连字符，并且不能以连字符结尾。发布后，SDK 包名称无法更改。

配置 SDK 后，选择 保存选择 以继续。

选择数据实体

直方图 本体论 侧边面板包含两个标签页： 数据实体 和 SDK 生成.

  • 直方图 数据实体 标签页用于从您的本体论中导入对象和操作类型。
  • 直方图 SDK 生成 标签页用于检查和安装 SDK 版本。

要选择数据实体，请导航至 数据实体 标签页。选择 将 并选择所需的数据实体类型，以打开资源选择器对话框，用于浏览和选择数据实体。选择数据实体后，可以使用 保存 侧边面板底部的按钮保存您的选择。选择 保存后，将生成一个可访问所选数据实体的新 SDK 版本。

当选择影响对象类型或将对象类型作为参数的操作类型时，这些对象类型也会自动添加到选择中。如果任何所选对象类型的支撑数据源尚未导入到您代码工作区的项目范围内，系统还会提示您确认自动导入这些数据源。

更改所选的本体论

要从不同的本体论导入本体论实体，请使用 数据实体 标签页中的本体论选择器。选择不同的本体论后，选择 保存 以应用更改并生成新版本。更改所选的本体论将重置 SDK 的数据范围，清除任何已选择的对象、操作或关联类型。

发布新的本体论 SDK 版本

配置完成后，可以使用 “生成新版本” 侧边面板底部的 本体论 按钮发布新的本体论 SDK 版本。已发布和待处理的版本可以通过 SDK 生成 标签页。

选择 “生成新版本”，新创建的版本将显示在 SDK 生成标签页中。在状态显示为“已发布”之前，SDK 版本无法使用。

发布失败的常见原因包括：

  • 使用操作类型但未导入依赖的对象类型。
  • 使用的对象类型的支撑数据源不在项目范围内。

在代码中使用本体论 SDK 版本

成功发布的版本可以在编辑器中导入并在代码中使用。首先，在 SDK 生成 Ontology Manager 本体论 侧边面板中点击您要使用的版本的卡片。这将展开卡片，显示针对您编辑器语言定制的多个代码片段。点击某个片段会将其添加到剪贴板，以便粘贴到您的编辑器中。

可见的片段会因编辑器语言而异。所有支持的语言都有“安装包”片段（用于安装 SDK 的某个版本）和“初始化客户端”片段（用于导入 SDK 并初始化 Foundry 客户端以与本体论交互）。

AircraftObject = client.ontology.objects.Aircraft

# Retrieve an object and view properties
my_aircraft = AircraftObject.get(1)
my_aircraft.date_of_manufacture

# Iterate over objects
for aircraft in AircraftObject.take(2):
    print(aircraft.current_location)

# Aggregations
AircraftObject.aggregate({"min_id": Aircraft.id.min(),
                          "max_id": Aircraft.id.max(),
                          "aircraft_count": Aircraft.count()}).compute()

# Filter
my_a330s = AircraftObject.where((Aircraft.type == "A330") | (Aircraft.id == 160)).take(1)

# Actions: Validate and apply
import datetime
from my_sdk_package.types import ActionMode

action_validation = client.ontology.actions.change_manufacture_date({"mode": ActionMode.VALIDATION_ONLY},
                                                                     aircraft=1,
                                                                     date_of_manufacture="2020-05-01")
if action_validation.result == "VALID":
    client.ontology.actions.change_manufacture_date(aircraft=1, date_of_manufacture="2023-05-26")

时间序列属性

要访问 时间序列属性 在工作区中，请按照上述步骤创建、发布并导入 Ontology SDK。然后访问时间序列属性，并使用 foundryTS 库对其进行操作。此示例展示了如何从一组 Denver 对象中检索 City 对象，并将其电价作为时间序列进行访问：

from my_sdk_package import FoundryClient
from foundryts import TimeSeries

client = FoundryClient()
city_objects = client.ontology.objects.City

denver = city_objects.get("Denver")  # This is the object's primary key
denver_electricity_price_tsp = TimeSeries.from_osdk(denver.electricity_price)

# Convert the series into a foundryts node
node = denver_electricity_price_tsp.node()

# Convert the series into a pandas dataframe
df = denver_electricity_price_tsp.to_pandas()

Code Workspaces 通过 reticulate ↗ 包支持在 R 中使用 OSDK，该包允许您在 R 中调用 Python。

此示例演示了如何将 Python OSDK 版本导入 R 并与对象类型进行交互。此示例假定您的 SDK 包含一个名为 "Aircraft" 的对象类型。术语 my_sdk_package 应替换为您 SDK 的包名称。

osdk <- import("my_sdk_package")
client <- osdk$FoundryClient()

aircraft_object = client$ontology$objects$Aircraft

# Retrieve 1 object
aircraft_object$take(1L)

# Retrieve object by ID
aircraft_object$get("1")

由于 R 和 Python 具有不同的默认数值类型，当 Python API 需要整数时，在 R 中必须使用 L 后缀。 请在 reticulate 的官方文档中了解更多信息。↗
