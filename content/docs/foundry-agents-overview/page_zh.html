专业代码代理

您可以在代码仓库中使用第三方代理 SDK 来构建由大型语言模型 (LLM) 支撑的代理。专业代码代理是在 Foundry 代码仓库中编写并作为 Foundry 函数发布的自定义逻辑。该代理可以对提示词进行推理，并调用在您的环境中读取和写入数据的工具。支持的第三方代理 SDK 包括 Claude Agent SDK、OpenAI Agents SDK 和 Google ADK。

专业代码代理可以完成诸如读取和写入本体论数据、构建平台资源以及迁移遗留系统等任务。有关使用专业代码代理的更多方式，请参阅 用例文档。

专业代码代理开箱即用，可使用限定范围的权限向 Ontology SDK (OSDK)、 Ontology MCP (OMCP)和 Palantir MCP 进行身份验证。您无需传递客户端 ID 和密钥即可调用工具。发布专业代码代理后，您可以通过 Workshop 或 Ontology SDK 调用它，无需任何额外配置。

专业代码代理的工作原理

专业代码代理在基于代理模板创建的代码仓库中定义。该模板包括：

  1. OSDK 客户端 绑定到您选择的本体论，用于读取和写入本体论数据。
  2. 本体论 MCP 和 Palantir MCP 配置，将本体论资源和平台工具公开给智能体的 LLM。
  3. 智能体的逻辑，您可以在其中定义提示词、智能体可调用的工具，以及智能体如何消费模型的响应流。

当您发布智能体时，Foundry 会为其注册本体论绑定和智能体 API 名称。 已发布的 智能体会以异步函数的形式公开。我们建议从 Automate触发智能体，但您也可以从 Workshop、本体论 SDK 和本体论操作中调用它们。

核心功能

  • 开箱即用的作用域权限： 专业代码智能体会使用 作用域权限 自动向 OSDK、OMCP 和 Palantir MCP 进行身份验证。您无需手动配置客户端凭据即可使用工具。
  • 适用于 Claude Agent SDK、OpenAI Agents SDK 和 Google ADK 的模板： 从 模板 创建您的专业代码智能体，该模板适用于 Claude Agent SDK ↗、 OpenAI Agents SDK ↗或 Google Agent Development Kit (ADK) ↗。每个模板都附带了针对 OMCP、Palantir MCP 和 OSDK 客户端的简化配置，通用设置由智能体库提供。
  • 发布时会附带本体论绑定和智能体 API 名称： 每个专业代码智能体都会 被发布 带有本体论绑定和智能体 API 名称，使其函数可在 Workshop 和 OSDK 中调用。
  • 通过全局分支开发： 开发、测试并发布 全局分支上的专业代码智能体 ，与已分支的本体论和应用程序更改并行，而不会影响 main。
  • 引导式演练： 创建专业代码智能体后， 在 Foundry 中构建智能体 着陆页将引导您完成 后续步骤 ，包括构建、发布和调用您的智能体。
  • 使用 Continue 构建您的智能体： 将 Palantir MCP 与 Continue ↗ 搭配使用，以 管理附加到专业代码智能体的 SDK 和 OMCP 作用域 ，所有操作均可直接在您的编辑器中完成。
