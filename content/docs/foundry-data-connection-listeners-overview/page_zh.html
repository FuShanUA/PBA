监听器

监听器使 Palantir 平台能够接收来自其他系统的事件，这些系统不直接支持 OAuth 2.0 身份验证，或无法提供与标准 Foundry API 端点兼容的可配置负载。

为了接受来自这些系统的入站连接，数据连接监听器会提供一个 URL 端点，为特定的外部系统实现相应的消息签名或其他验证方案，并提供一种简单且低延迟的机制，用于将数据馈送接收到 Foundry 中。

监听器的类型

Foundry 支持三种类型的监听器，每种监听器专为不同的集成场景和处理方式而设计：

HTTPS 监听器

HTTPS 监听器通过 HTTPS 端点接收来自外部系统的 webhook 请求。事件将被写入 流，从而支持通过 Automate、 流式管道进行处理，或使用该流的支撑数据集进行批处理。

WebSocket 监听器 [Beta]

Beta

WebSocket 监听器目前处于 beta 开发阶段，在您的环境中可能无法使用。在活跃开发期间，功能可能会发生变化。请联系 Palantir 支持团队，申请获取 WebSocket 监听器的访问权限。

WebSocket 监听器主要专为实时音频和电话工作流而设计，支持 Foundry 与 Twilio、Genesys 和 Azure Communication Services 等外部服务之间的双向通信。入站 WebSocket 连接直接由 计算模块 处理，您可以在其中托管自定义 WebSocket 服务器。

电子邮件监听器

Beta

电子邮件监听器目前处于 beta 开发阶段，可能无法在您的注册租户中使用。功能在积极开发过程中可能会发生变化。请联系 Palantir 支持团队，申请获取电子邮件监听器的访问权限。

电子邮件监听器允许 Foundry 通过专用电子邮件地址接收入站电子邮件，以进行下游处理。每个监听器都有一个唯一的电子邮件地址，其作用域限定为您的注册租户，并在转发内容之前执行发件人允许列表检查、电子邮件身份验证和附件验证。

何时使用监听器

监听器是将数据摄取到 Palantir 平台的众多选项之一。在设置监听器之前，请评估您的用例是否符合以下针对入站连接或无法自定义的外部系统的标准。

针对入站连接

仅当外部系统建立到 Foundry 的连接时，才能使用监听器进行入站连接。要从 Foundry 向外部系统发起请求，请使用 数据源。还提供无代码功能，例如 同步 和 出站 Webhook。此外，还可通过以下方式建立基于自定义代码的数据连接： 外部转换、 函数、 计算模块等。

当无法自定义外部系统时

仅当无法自定义外部系统以连接到 Foundry 时，才应使用监听器。例如，许多 webhook 和 WebSocket 提供商采用定制的负载格式，无法与 Foundry 正确进行身份验证，而是依赖于其他身份验证和验证协议。

对于可以自定义外部系统的情况（例如系统允许您编写自定义集成代码时），请使用 公共 API 。通过公共 API，您可以向流推送数据、向数据集上传数据，或直接与您的本体论交互。
