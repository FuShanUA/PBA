本体论对等互联

本体论对等互联使您能够将 对象 和 关联类型 从您的本体论同步到另一注册中的本体论，通过 对等连接。

关键概念

对象引用与映射

您可以跨 Palantir 应用程序，通过其唯一的 RID来引用单个对象或一组对象。对等操作会跨连接转换各注册特有的本体论 RID，以确保用户在 其 注册内的应用程序中操作时能够引用正确的对象。在您启用对等互联并配置对等连接之前，这些对象引用 仅 指向特定于注册的 RID。此转换是在两个注册之间同步 Gotham 文件（例如 Gaia 地图）所必需的。

要执行此转换，请创建一个 对象类型映射 ，以定义对象类型及其属性如何跨对等连接进行转换。您无需映射 每个 属性；但是，您必须映射希望通过已建立的连接进行对等同步的所有属性。

本体论数据对等互联的类型

源数据对等互联

源数据是来自支撑数据源（例如数据集或 Restricted Views）的本体论数据。源数据对等互联目前是 单向的。这意味着，当设置了源数据对等互连后，其中一个注册会提供所有源数据，而源数据无法向另一个方向流动。

如果两个注册都从相同的上游源系统接收数据，那么您可能无需配置源数据对等互连。如果属于这种情况，则您应该配置 操作数据对等互连 以在这两个注册之间同步用户所做的编辑。此外，对于没有源数据的对象类型（即完全由用户操作生成的对象类型），您无需配置源数据对等互连。

请查看以下信息，详细了解源数据对等互连当前的功能和限制：

  • 云端到边缘源数据对等互连： 支持云端注册与边缘注册之间的源数据对等互连。
  • 云端到云端源数据对等互连： 目前，将源数据从一个云端注册对等互连到另一个云端注册的唯一方式是通过由直连数据源支撑的对象类型。如果您的对象类型由其他源（例如数据集或 Restricted View）支撑，则应使用 Foundry 连接器在各注册之间同步源数据。
  • 数据集同步： 您可以使用 Foundry 连接器 在环境之间同步对象类型的支撑数据集或流，然后再建立对等连接以同步基于操作的编辑。源数据对等 无法 让您将云环境上由数据集或流支撑的对象对等连接到另一个云环境，其中远程对象 也 由单独的数据集或流支撑。
  • 流： 对于云环境，流既可以用作对象类型的数据源，也可以用作直接数据源的馈送。前者不支持操作或对等，后一种情况则支持操作、对这些操作进行对等，以及源数据的导出和导入。
  • 仅同步已更改的对象： 源数据对等仅同步因支撑数据集更新而发生更改的对象。例如，如果您的对象类型的支撑数据集的最近一次 快照 事务仅包含对五个对象的更改，则只有这五个对象会被同步。

操作数据对等

操作 数据是本体论数据，源自用户以对对象执行操作的形式提交的更改，例如创建、编辑或删除对象或关联。您可以在云环境 和 边缘 Foundry 环境之间配置操作数据对等。

您可以在任意数量的对等连接之间建立双向操作数据对等，并且数据将实时进行对等传输。此外，操作数据对等具有最终一致性：如果实时操作对等方出现故障，Peer Manager 将尝试重新发送数据，直到远程注册端确认收到为止。

请查看以下信息，了解操作数据对等当前的功能和限制：

  • 数据集支持： 您可以对等由数据集、受限视图和直接数据源支撑的对象类型，包括 多数据源对象类型。
  • 属性匹配： 操作数据对等定义了两个对象类型之间特定的属性到属性映射。属性不需要具有相同的 API 名称，但要使属性能够对等，两个对象类型的属性类型必须相同，例如 string 或 double。
  • 选定属性对等： 操作数据对等可以对等对象类型上的一部分属性，而非全部属性。
  • 不支持的属性类型： 操作数据对等尚不支持某些属性类型：
    • 密文
    • 时间序列 通过关联的传感器对象类型
    • 向量
  • 流支撑的对象类型： 尚不支持对流支撑的对象类型进行操作数据对等。

关联类型对等

关联类型 定义两个对象类型之间的关系，并随包含关联属性的对象类型自动对等互连。请查看以下指南，以确保在配置本体论对等互连关系时，对象的关联能够正确对等互连。

  • 外键关系： 关联作为属性存储在对象上，因此无需进行特定设置即可对等互连外键关联。相反，只要关联类型在两个本体论实例中均有定义，当两个被关联的对象完成对等互连时，这些关联也会随之对等互连。

  • 联接表数据集关系： 用于多对多关联，您必须对其进行配置才能进行对等互连。联接表可能包含来自支撑数据源的源数据，并且这些关联可以接受用户编辑。与对象类型类似，多对多关联类型可以同时包含源数据和操作数据。

  • 支撑对象关系： 用于多对多关联，当两个被关联的对象和支撑对象都完成对等互连时，该关联即被共享。

对等互连与自动化

当对象类型通过本体论对等互连接收更新时，这些对等互连的更改可以触发 Automate 监控该对象类型的自动化。在存在对等互连连接且两侧均运行相似自动化逻辑的环境中，这可能会导致重复或非预期的副作用。

为防止出现这种情况，您可以将自动化配置为跳过源自对等补丁的事件。有关此设置的详细信息，请参阅 自动化条件设置 文档。
