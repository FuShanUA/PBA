示例：发送新工单的每周报告

在本示例中，我们希望发送一份每周 Notepad 报告，其中包含上一周所有新建支持工单的列表。如果没有新工单，我们则不发送报告。我们将使用 Support Ticket 对象类型，这是我们在本示例中创建的自定义对象类型。

条件

我们首先在自动化创建向导中选择 Object added to set 条件。通过选择 Support Ticket 对象类型且不添加额外筛选器，自动化将在新工单创建时触发。

由于我们只想每周发送一次报告，我们为条件添加一个计划，并指定自动化应在每周一早上 8 点触发。

由于我们为对象添加条件添加了每周计划，自动化将在每周一检查上一周是否创建了新的 Support Ticket 对象。

效果

当条件满足时，我们希望发送一封附带 PDF 报告的电子邮件，其中包含上一周创建的所有支持工单。为此，我们首先添加一个通知效果。

由于 PDF 报告应针对上一周创建的所有支持工单生成，请保留默认的对象分组 为所有添加的支持工单发送一个通知。对于收件人，请添加一个包含目标用户的组。或者，如果只想通知被分配了新支持工单的用户，请仅选择由对象属性支撑的用户。

由于信息包含在附加的 PDF 中，我们不需要复杂的通知正文：相反，我们可以使用 纯文本通知 类型在 UI 中配置内容。我们还可以在通知中提供一个指向 的流可在 仪表板的链接。

将 Notepad 文档附加到通知

为了设置通知附件，我们将使用 Notepad 模板 来动态创建 Notepad 文档，并将该 Notepad 文档的 PDF 附加到我们的通知中。

首先，我们需要创建一个能够显示所需信息的 Notepad 模板。我们可以按照 Notepad 文档中概述的步骤 来操作。在我们的具体场景中，我们创建一个接受 Support Ticket 对象集作为模板输入的 Notepad 模板。利用模板输入，我们显示一个图表，并渲染一个表格，其中包含对象集中每个对象的标题和描述。
