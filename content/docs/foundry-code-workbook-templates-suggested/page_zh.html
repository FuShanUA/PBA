建议模板

对于相似数据集的组，您可能希望建议要应用的模板。例如，对于包含每月股票回报的一组数据集，您可能希望建议一个计算年化回报的模板。建议模板会显示在新建转换面板中的一个单独按钮内，使其更易于被发现。

在模板中配置输入标签

下面，我们看到一个根据月度回报计算年化回报的模板。对于任何带有标签 财务的数据集，该模板将显示在 建议 选项卡中，当用户以该数据集作为父级创建新转换时。

在创建或编辑模板时，在 输入标签 字段中配置所需的输入标签。您可以添加多个输入标签。

向数据集添加标签

向数据集添加输入标签的一种方法是在 Dataset-app 中打开该数据集。由于标签与数据集绑定，因此无法在 Code Workbook 中向未持久化的转换添加标签。这意味着未持久化的转换不支持建议模板。

在多节点模板中配置输出标签

您可以在多节点模板中将输出标签作为其一部分进行配置，而无需从 Dataset-app 手动添加标签。

设想一个包含两个节点的多节点模板，其中第二个节点的输出是一个包含每月股票回报的数据集。目标是让该数据集自动添加 财务 标签，这样配置了该输入标签的模板就会显示在建议模板下。

在创建或编辑多节点模板时，在 输出标签下设置所需的输出标签。当应用多节点模板时，输出标签将立即添加到由该多节点模板创建的数据集中。
