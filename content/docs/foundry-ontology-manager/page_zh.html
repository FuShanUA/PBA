本体论管理器

本体论管理器 （有时称为“本体论管理应用程序”或 OMA）使您能够构建和维护贵组织的本体论。您可以使用本体论管理器执行与本体论相关的各种活动，从创建新的对象类型和定义新的操作类型，到将数据连接到本体论，以及调查数据是否正在用户应用程序中更新。

访问应用程序

您可以通过以下三种不同的方式访问该应用程序：

  • 选择 本体论管理器 图标（位于工作区侧边栏的 应用 部分中）；
  • 在数据血缘中右键单击某个对象类型并选择 配置对象类型；或者
  • 将 /workspace/ontology 添加到您的 Foundry 主页 URL 末尾（例如， https://example.website.com/workspace/ontology）。

用户界面

本体论管理器界面分为以下几个元素，您将在整个文档中看到对这些元素的引用：

  • 本体论管理器导航
  • 发现视图
  • 对象类型视图
  • 属性编辑器视图
  • 关联类型视图
  • 操作类型视图
  • 函数类型视图

本体论管理器导航

本体论管理器的两个常驻元素是顶部栏和侧边栏。顶部栏和侧边栏作为导航元素，可让您直观地访问应用程序中的各种特性、功能和区域。

顶部栏具有三个主要功能。它允许用户搜索本体论资源、创建新的本体论资源，以及在分支之间导航或创建新分支。

侧边栏提供对本体论管理器中不同资源、页面或应用程序的便捷导航。

发现

发现视图提供了一个高度可自定义的着陆页，可根据您的偏好量身定制。默认情况下，发现视图会展示收藏的对象类型、最近查看的对象类型和收藏的组。

如果用户是首次使用该本体论，则会显示两个专门的版块：一个显示该本体论中最近修改的所有对象类型，另一个显示所有重要的对象类型。

发现视图可灵活配置页面上显示的版块，并控制每个版块中显示的项目数量。可用的版块包括“最近查看的对象类型”、“收藏的对象类型”和“收藏的组”。此外，您还可以选择为特定组添加单独的版块，以便浏览该组中的所有对象类型。

对象类型视图

选择某个对象类型会打开对象类型视图，其中包含以下组件：

  • 带有页面选择的侧边栏（位于下图左侧）
  • 所选页面（位于下图右侧）

对象类型的 概览 页面包含以下部分，各部分编号见下图：

  1. 对象类型元数据
  2. 属性
  3. 操作类型
  4. 关联类型图
  5. 依赖项
  6. 数据
  7. 使用情况

属性编辑器视图

从 属性 部分（位于对象类型的 概览 页面中）选择一个属性，以打开该应用程序的属性编辑器视图。

关联类型视图

从对象类型的 概览 选项卡的关联类型图中选择一个关联类型（见下图），即可打开关联类型视图（包含 概览 和 数据源 页面）。

操作类型视图

从对象类型的 概览 选项卡的操作类型部分中选择一个操作类型，即可打开操作类型视图，并可进一步访问 概览、 逻辑 和 可观测性 页面。

查看操作指标和监控规则

该 可观测性 选项卡显示该操作过去 30 天内的近实时 使用情况 ，以及为该操作定义的 监控规则 及其状态。 查看操作规则 ，以了解详细的操作监控规则配置选项。

函数类型视图

从对象类型的 概览 选项卡会打开函数类型视图，并可进一步访问 概览、 配置 和 可观测性 页面。

函数的使用历史

使用历史面板会记录使用过函数任意版本的应用程序，以及相应的版本信息。您可以通过该面板导航到这些应用程序，以便升级函数的版本。

查看函数的历史版本

默认情况下，将显示函数的最新版本。要查看其他版本，请使用左侧面板中的版本下拉选择器。

导航到函数代码仓库

对函数的修改只能在函数代码仓库中进行。要导航到该仓库，请使用 在代码仓库中打开 按钮，该按钮位于实体视图的右上角。

查看函数指标和监控规则

该 可观测性 选项卡会显示近实时的 函数使用情况 （过去 30 天内），以及为该函数定义的任何 监控规则 及其状态。 查阅函数规则 ，以了解详细的函数监控规则配置选项。
