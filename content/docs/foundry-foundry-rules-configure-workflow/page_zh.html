配置工作流

完成 部署工作流模板后，以下步骤将引导您完成 工作流的配置。

  1. 访问现有规则： 在 Foundry Rules 主页中，通过选择相应条目，从现有规则列表中进行选择。或者，您也可以导航到该规则所属的项目中进行选择，该项目位于 Files。



  2. 添加工作流输入： 查看该规则时，选择 Add Input 按钮，为工作流添加对象或数据集输入。该输入将可用作下一节中编写的规则的输入。

    • 您可以在此添加任意数量的输入，但所有工作流都必须至少包含一个输入。
    • 添加对象类型输入时，关联类型部分将显示在每个对象类型下方。选定的任何关联都将在 Rules Management 应用 中可用，用于将不同对象连接在一起。



由受限视图支撑的对象无法直接用作输入。相反，请将支撑该受限视图的数据集配置为 备用支撑数据集。

  1. 添加工作流输出： 在编辑器的第三部分中，点击 Add Dataset Output 并为规则结果将要输出到的数据集提供名称和位置。



    • 为输出提供一个名称，该名称将显示给 规则管理应用程序 中的规则作者 (a)。
    • 点击 添加列 以向输出添加至少一列 (b)。为该列指定一个在数据集中使用的名称，以及一个在规则应用程序中向规则作者展示的显示名称。您可以配置列的类型，并确定在编写规则时是否必须提供该列。进一步了解 允许的输出值和默认输出值。
    • 为您希望从规则结果中捕获的每项信息添加一列。例如，警报工作流可能包含以下列： Alert ID、 Severity和 Assignee ，以及一个用于捕获触发警报的对象的标识符的列（例如 Machine ID）。



  2. 保存工作流： 在配置编辑器的右上角，点击保存按钮。

    • 保存工作流后，您应该会看到编辑器顶部出现一个绿色横幅，表示 转换管道 已成功创建。



完成上述步骤后，了解如何 编写并运行规则.

高级配置

备用支撑数据集

您可以为对象输入配置备用支撑数据集。这意味着您的规则将针对所提供的备用支撑数据集进行评估，而不是本体论中配置的写回（或支撑）数据集。

这在以下情况下非常有用：

  • 在受限视图支撑的对象上编写规则
  • 在对象支撑数据的子集上运行规则
