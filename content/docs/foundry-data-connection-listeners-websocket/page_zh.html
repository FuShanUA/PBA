WebSocket 监听器

Beta

WebSocket 监听器目前处于 Beta 开发阶段，在您的租户中可能无法使用。功能可能会在持续开发期间发生变化。请联系 Palantir 支持团队，以请求获取 WebSocket 监听器的访问权限。

WebSocket 监听器主要为实时音频和电话工作流而设计，可实现外部服务与 Foundry 之间的双向通信。与 HTTPS 监听器 不同，后者接收 webhook 请求并写入流，而 WebSocket 监听器会保持持久连接，以便将数据持续流式传输到自定义 WebSocket 服务器，该服务器托管在 计算模块中。有关 HTTPS 监听器特有的安全注意事项，请参阅 HTTPS 监听器安全性。

由于 WebSocket 连接是双向的，您的计算模块还可以在连接处于活动状态时向源系统发回响应。例如，在电话工作流中，您可以处理传入的音频，并将生成的音频实时发回给呼叫者。

何时使用 WebSocket 监听器

您可以在以下情况下使用 WebSocket 监听器：

  • 外部系统使用 WebSocket 协议进行数据传输。
  • 集成需要双向通信，例如在通话期间发回响应。
  • 您正在处理来自电话系统的连续音频流。

设置 WebSocket 监听器

1. 创建 WebSocket 监听器

  1. 导航到 数据连接 > 监听器。
  2. 选择 创建新监听器 并选择所需的 WebSocket 连接器。

连接器可用性

如果您所需的连接器不存在，请联系 Palantir 支持团队为您的注册启用该连接器。

2. 配置端点

所有 WebSocket 监听器必须挂载在专用子域名上。您必须将 Foundry 实例配置为接受来自外部系统 IP 范围的入站连接。

  1. 要创建监听器子域名，请前往 控制面板 > 域名和证书。 了解有关监听器子域名的更多信息。
  2. 配置入口流量，以允许来自您外部系统的连接。请参阅 配置入口流量文档。
  3. 将该子域名挂载到您的监听器。此操作需要经过审批，之后您才能开始接收请求。

3. 配置安全性

每种 WebSocket 监听器类型都有特定的身份验证要求。请在 配置安全性 部分中配置相应的凭据，该部分位于您监听器的 配置连接 页面。

接下来，导航至 配置服务器 页面，并指定您的监听器应允许哪些可导出标记。 了解有关 WebSocket 监听器安全性的更多信息。

4. 配置计算模块

WebSocket 侦听器将传入数据路由到计算模块进行处理。创建侦听器时,系统会自动为您创建一个计算模块——这是目前在侦听器中处理 WebSocket 连接的唯一受支持方式。

要配置计算模块,请按照以下步骤操作:

  1. 从侦听器的 配置 页面,导航至关联的计算模块。
  2. 将您的计算模块所需的 Foundry 资源添加为输入和输出。默认情况下,计算模块没有任何权限——您必须为每个资源显式授予访问权限。 了解有关配置计算模块的更多信息。
  3. 启动您的计算模块并查看 日志 选项卡,以确认一切都按预期运行。

受支持的 WebSocket 侦听器

可使用以下 WebSocket 侦听器类型:

  • Twilio Media Streams ↗:通过 WebSocket 连接传输 Twilio 语音呼叫的实时音频。
  • Azure Communication Services ↗:从 Azure Communication Services 呼叫自动化工作流传输音频。
  • Genesys AudioHook ↗:使用 AudioHook 协议传输 Genesys Cloud 语音交互的实时音频。
