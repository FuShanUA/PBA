在 Slate 中使用 Foundry Functions

Foundry Functions 面板允许 Slate 执行在 Functions 仓库中编写的业务逻辑，作为“后端”服务。在这种模式下，可将 Slate 应用视为传统 Web 应用基础架构中的 客户端，将 Foundry Functions 实现视为 服务器，将本体论视为 数据库 。请查阅文档以了解如何 开始使用 Foundry Functions 或如何使用 小部件允许您使用.

Foundry Functions 面板允许您：

  • 选择您有权访问的 Foundry Function，
  • 选择该 Function 的版本（例如版本 0.0.5），
  • 如果 Function 允许，向 Function 传递类型化的输入（对于接受对象集作为输入的 Function，您可以通过 Handlebars 传入 Slate 定义的对象集作为输入并对其进行解析），以及
  • 通过引用 Function 的 handlebar 在 Slate 中使用该 Function 的类型化输出 {{ff_foundry_function1}}.

Function 需要先在 Function 仓库 中创建，然后才能在 Slate 中使用。

Slate 的实现方法

在编写用于 Slate 应用的 Function 时，您应考虑两种方法，它们的区别在于应用 逻辑 的实现位置。

  • 在 轻量 Functions 方法中，Function 只是对本体论 API 中数据的简单透传。任何额外的处理（例如，将某个值适当缩放以用作 Radius 的 散点图 图表数据）都在 Slate 应用中通过常规 JavaScript 函数完成。
  • 在 重量 Functions 方法中，所有业务和显示逻辑也会推入 Foundry Functions 层，Slate 应用本身只保留非常特定的格式化或显示逻辑以及实际的布局和小组件配置。

使用 Foundry Functions 来组织和管理复杂 Slate 应用的逻辑层具有显著的优势，例如：

  • 强类型，这是一种最佳实践，可以避免整类潜在的边缘情况。
  • 在仓库中工作，这为应用的前端和后端提供了独立的版本控制和协作，同时也支持组织和构建代码的标准实践。
  • 将应用逻辑与特定前端解耦 可创建可在其他应用中引用的可复用组件。

Function 输入和输出类型

Foundry Functions 支持多种标准、本体论生成的以及自定义的输入和输出类型，详见 Functions 输入和输出类型.

在 重量 Functions 方法中，通常会定义 自定义输入和输出类型 ，以便以填充特定图表或 HTML 小组件所需的精确格式返回数据。
