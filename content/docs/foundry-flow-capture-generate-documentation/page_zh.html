从工作流生成文档

在 录制工作流之后，您可以使用 Flow Capture 中编辑模式视图底部的提示栏来提供更多上下文并生成文档。建议添加目标受众、所需格式、风格指南或关于内容组织的具体说明，以改进生成的内容。

选择模型

从提示栏右上角的模型选择器中选择模型。不同的模型提供不同的上下文窗口大小、速度和成本特性。请选择最能满足您对准确性和 token 容量需求的模型。

不同模型支持的每次请求图片数量各不相同。如果您的查询失败，请选择其他模型并重试。

在此阶段，您还可以使用模型选择器左侧的选择器来更改提示模板。

将资产包含在 LLM 上下文中

请确保您希望提供给模型的截图和转录文本已包含在生成上下文中。已添加到 LLM 上下文中的转录文本和图像将显示紫色的 在上下文中 标签。 快照 标签位于提示栏左下角，将显示当前可供模型使用的图像数量。

在生成过程中，只有您已添加到上下文的资产才对模型可见。请注意，您也可以上传未在流程捕获会话中捕获的图像，并将其包含在 LLM 上下文中。

开始生成

  1. 验证您的提示词和资产。
  2. 选择 生成 （位于提示栏右下角）以开始生成过程。
  3. 等待模型完成。过程完成后，编辑器将在 文档 选项卡中显示生成的内容。

编辑生成的 Markdown

内容生成后，您可以通过切换到 文档 选项卡并在右上角选择 编辑 来编辑结果。内容将以 Markdown 语法显示。要预览结果，您可以切换回 预览。

生成模式

您还可以更改生成模式，以重新生成或修改现有文档。使用提示栏左上角的选择器选择以下生成模式之一：

  • 重新生成文档： 使用新提示覆盖现有文档。当您想要一个不依赖于当前已生成文本的全新文档时，请使用此选项。
  • 追加到或修改当前文档： 使用提示编辑现有文档。当您希望模型在保留其上下文的同时修改、扩展或更正当前文档时，请使用此选项。

导出生成的文档

Flow Capture 允许您以多种方式导出生成的内容：

  • 导出为 Walkthrough： 将内容转换为 Walkthrough。Walkthrough 强制采用分步结构，因此从 Flow Capture 导出后，Walkthrough 内容可能会有所不同。
  • 导出为 Notepad： 将内容转换为 Notepad 文档。
  • 导出为 .zip： 将 Markdown 内容和图像打包为可下载的 .zip 文件。
  • 导出为 PDF： 将 Markdown 内容渲染为可下载的 PDF 文档。
