Forms [停用过渡]

停用过渡

Forms 目前处于 停用过渡 阶段,并将在未来某个日期被弃用。目前仍提供全面支持。我们建议使用本体论构建用户输入工作流,将相关数据结构表示为对象类型,并通过操作和函数配置写回交互:

  • 操作: 在添加、编辑和删除数据的权限方面获得更稳健、更细粒度的控制,包括遵循受限视图以及配置复杂的条件权限。操作在 Workshop 和 Slate 中均获得原生支持,您可以在其中使用全套应用构建工具打造复杂的数据录入用户体验。操作还会自动为平台 API 生成 API 绑定,使您能够将数据写入外部数据系统或触发其他下游效应。
  • 函数: 操作可以由函数支撑,以实现更具表现力、更复杂的写回逻辑。

什么是 Forms?

Forms 是一款表单构建界面,可与其他 Foundry 应用程序无缝集成。 Forms 可提供直观的体验,同时不牺牲复杂的可配置性。

借助 Forms,即使是没有编程经验的用户,也能创建和管理自定义的数据录入与存储解决方案。用户可以使用 Forms 配置各种工作流,包括:

  • 定义动态字段以定向来自回复者的数据。
  • 将表单作为分区嵌入到 Object Explorer 和 Slate。
  • 将收集到的信息存储到 Fusion。

要开始使用 Forms，请学习如何 创建 表单或 查看和编辑 表单回复。
