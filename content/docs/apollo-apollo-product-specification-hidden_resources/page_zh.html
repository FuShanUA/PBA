资源 [Beta]

资源目前处于 Beta 状态，可能尚未在您的 Apollo Hub 上提供。请联系您的 Palantir 代表以了解更多信息。

本规范的这一扩展描述了产品如何声明所需的计算资源，其设计基于 Kubernetes 容器资源规范 ↗。 支持以下类型的计算资源：

  • CPU
  • 内存

声明计算资源请求和限制

在定义 Apollo 产品的 CPU 和内存需求时，开发者可以同时指定每个服务副本必须可用的最低资源量（“请求”）以及每个副本不应超过的最大资源量（“限制”）。 资源请求和限制将应用于服务的每个 副本。 这些请求和限制可以在 Apollo 产品的 configuration.yml 文件中的顶层 resources 字段下进行定义：

# configuration.yml 
resources:
  requests:
    cpu: 0.5
    memory: 1Gi
  limits:
    cpu: 2
    memory: 4Gi

支持的内存单位包括：

  • Ki（二进制千字节）
  • K（千字节）
  • Mi（二进制兆字节）
  • M（兆字节）
  • Gi（二进制吉字节）
  • G（吉字节）
  • T（太字节）

CPU 值可以以不带单位的浮点值形式提供，用于表示 CPU 核心数。例如，0.5 CPU 会被解释为单个核心 50% 的使用率。

默认值

resources.requests 和 resources.limits 均为可选字段，其子字段亦为可选。缺失值的处理方式如下：

  • 如果未指定 CPU 请求和 CPU 限制，则使用默认值 0.25。
  • 如果未指定内存请求和内存限制，则使用默认值 1G。
  • 如果仅为某个资源定义了限制值，则该资源的请求值将设置为相同的值。
