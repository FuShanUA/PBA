外部函数

外部函数允许您调用 webhook ，并在函数中使用它们与外部系统交互。您可以从使用以下工具构建的应用中调用这些系统： Workshop、 操作和 函数。

Webhook 也可以直接发布为可复用的本体论函数，而无需编写包装代码。要在 TypeScript v2 或 Python 函数中使用 webhook，请将其发布为 webhook 函数。将已发布的函数导入您的函数仓库，并 使用本体论 SDK 调用它。

要在函数中使用 webhook，您必须先配置一个 数据连接源 ，该源需支持 webhook 功能。通常为 REST API 源。对于 TypeScript v1 函数，在您获得配置了 webhook 的源后，即可将该源导入您的 函数仓库 ，并创建调用 webhook 和其他逻辑的函数。

您可以将外部函数应用于各种使用场景，包括以下几种：

  • 使用单个函数向外部服务器发出 HTTP 请求并创建一条记录，然后向本体论中写入一条匹配的记录。
  • 使用自定义的预处理和后处理逻辑封装 webhook 调用。如果需要通过自定义逻辑将函数输入转换为所需的 webhook 请求输入参数,或者在执行本体论编辑之前需要对 webhook 响应进行后处理,那么这种方式尤其有用。
  • 通过中间处理逻辑将多个外部 webhook 请求和本体论编辑串联在一起。单个 webhook 无法执行动态数量的外部请求,但可以使用外部函数来实现这一点。
  • 使用只读请求查询外部系统,以便在 Workshop 应用程序中临时呈现数据。

目前,外部函数尚不能用于从 TypeScript 代码中进行任意 API 调用,除非先在 Data Connection 中将该请求定义为 webhook。

概念

  • 一个 Data Connection 源 表示与外部系统的连接,包括有关如何访问该系统的任何配置(例如网络详细信息)以及安全存储的凭据。
  • Webhooks 是某些源类型支持的一项功能,允许您构建结构化请求,以交互方式运行并向该系统发送请求。
  • 一个 本体论编辑函数 是一种 函数 可在之后配置为 函数支持的操作 以向对象写回。它使用 @OntologyEditFunction() 装饰器进行标注。
  • 一个 查询函数 是一种只读函数，不会产生任何副作用，例如修改外部系统。它使用了 @Query() 装饰器。

创建 Data Connection 数据源

要从函数中连接到外部系统，您必须拥有一个可以连接到所需外部 API 的 REST API 数据源。您可以按照以下说明配置新的 REST API 数据源。

  1. 导航到 Foundry 中的 Data Connection 应用程序，然后选择 新建数据源。从选项列表中选择 REST API。

  1. 查看 概览 页面，然后选择 继续 （位于右下角）。系统将提示您选择连接运行时： Foundry worker、 agent worker或 agent proxy runtime（已弃用）。Foundry worker 是首选方法,适用于与可从 Foundry 网络直接访问的任何内容进行交互(通过 直接连接出站策略 或与托管在与 Foundry 网络不同的网络上的任何内容进行交互(通过 agent 代理出站策略。 我们将使用具有直接连接策略的 Foundry worker 连接到我们的免费词典 API。
