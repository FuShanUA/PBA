服务器设置

您现在可以在 Qlik Sense 中访问 Palantir Foundry 数据集，并使用它们构建交互式仪表板。要在 Qlik Sense 中使用 Foundry，您必须在 Qlik Sense 服务器上安装 Foundry ODBC 驱动程序。

请按照以下指南完成设置。这些步骤必须由有权访问 Qlik Sense 服务器的人员完成。

步骤 1：安装 ODBC 驱动程序

在 Data Connection 中导航至 下载页面：ODBC 驱动程序 以下载驱动程序。将其安装在 Qlik Sense 服务器上。

步骤 2：配置 Foundry DSN

Qlik Sense 要求预先配置 ODBC DSN。

  1. 在 Qlik Sense 服务器上，打开 Windows ODBC 管理工具，并为 FoundrySqlDriver.
  2. 将您的 Foundry URL 设置为服务器。
  3. 选择“Additional Properties”，并添加一个新属性 UserAgent 其值为 QLIKSENSE。这将启用针对 Qlik Sense 优化的设置。
  4. 点击设置菜单下的 OK 以保存 DSN。

我们建议将 DSN 中的访问令牌字段留空，稍后在 Qlik Sense 中创建连接时再进行设置。请记住，如果您在 DSN 中设置了令牌，则在 Qlik 中有权访问该 DSN 的任何人都将能够查看该令牌有权访问的数据。

UserAgent 属性

设置 UserAgent 属性非常重要。如果没有它，数据将无法正确加载。

（可选）步骤 3：预配置 Qlik Sense 连接

如果用户能够在 Qlik Sense 中创建自己的连接，则可以跳过此步骤。否则，您需要预配置 Foundry 连接并向用户授予访问权限。请参阅 入门指南 指南以了解如何创建连接。
