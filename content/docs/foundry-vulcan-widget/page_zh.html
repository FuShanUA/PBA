在 Workshop 模块中嵌入 Vulcan

您可以在 Workshop 模块中嵌入 Vulcan，方法是使用 Vulcan 小部件。该小部件提供与独立应用程序相同的 3D 视口和工具。其输入、输出和接口还可以连接到 Workshop 变量，使 Vulcan 能够与模块中的其他小部件进行交互。

在 Workshop 模块中嵌入 Vulcan 需要三个步骤：添加小部件、选择 CAD 对象以及配置小部件。

在 Workshop 中添加 Vulcan 小部件

在您希望显示 Vulcan 的 Workshop 区域中，选择 + 图标或 + 添加小部件 以打开小部件菜单，然后搜索并选择 Vulcan 小部件。

选择 CAD 对象

Vulcan 至少需要一个 CAD 对象才能进行渲染。CAD 对象是一种本体论对象，其某个属性携带 cad_media_reference 类型类。有关完整架构，请参阅 CAD 对象。

在 输入 > 模型下，添加一个模型，并将 模型对象 设置为包含该 CAD 对象的 Workshop 对象集。Vulcan 会加载该对象集中的第一个对象。要渲染多个模型，请为每个对象集添加一个单独的模型条目。

配置小部件

Vulcan 小部件配置分为以下几个部分。

输入

该 输入 部分控制小部件使用的本体论数据和场景：

  • 模型： 可重复的 CAD 模型输入列表。
    • 模型对象： 包含模型的对象集。
    • 选项： 仅适用于此模型的设置。 转换 和 零件着色 接受以下返回架构中所述的函数输出。
      • 标注对象： 与模型关联的标注所组成的对象集。每个对象必须遵循 标注架构。
      • 转换： 针对零件实例或装配体的转换覆盖。请参阅 转换返回架构。
      • 选定的零件 ID 和 选定的零件实例 ID： 用于当前选择的双向字符串变量。零件 ID 会选中该零件在此模型中的所有实例；而零件实例 ID 则只选中一个特定实例。
      • 零件着色： 颜色和不透明度覆盖。请参阅 零件着色返回架构。
      • 回退颜色： 一个 CSS 颜色值，用于此模型中未分配颜色的零件。此值会覆盖全局 回退颜色 （针对此模型）。
  • 测量对象 和 剖切面对象： 包含要显示的测量和要应用的剖切面的对象集。对象必须遵循相应的 测量 或 剖切面 架构。
  • 场景： 加载本体论对象时要使用的 Workshop 主场景。

转换返回架构

转换 接受包含以下字段的结构体列表：

字段必填类型描述
id是字符串要转换的零件实例或装配体 ID。
transform是数字数组恰好 16 个有限数字，按列主序表示 4×4 变换矩阵。

矩阵值必须使用以下顺序 [m11, m21, m31, m41, m12, m22, m32, m42, m13, m23, m33, m43, m14, m24, m34, m44]。Vulcan 会忽略缺少 ID 或矩阵无效的条目。

零件着色返回架构

零件着色 接受包含以下字段的结构体列表：

字段必填类型描述
partInstanceIds是字符串数组一个或多个要设置样式的零件实例或装配体 ID。
color否字符串CSS 颜色值，例如 #0055ff 或 rgb(0, 85, 255)。
opacity否数字基础不透明度，从 0 （表示透明）到 1 （表示不透明）。
selectedOpacity否数字选中或高亮显示时的不透明度，使用相同的 0 到 1 范围。

每个结构体必须至少定义 color， opacity或 selectedOpacity 之一才能影响模型。如果场景着色工具也指定了颜色，则以场景着色的值为准，同时所配置的不透明度值仍然有效。

交互

相机目标、位置和缩放绑定可双向工作。 交互 部分会将以下相机和场景交互状态连接到 Workshop 变量：

  • 相机目标 X / Y / Z： 相机面向的点。请配置全部三个坐标。
  • 相机位置 X / Y / Z： 相机的位置。请配置全部三个坐标。
  • 相机缩放： 相机的缩放级别。
  • 点击 X / Y / Z： 输出数值变量，用于表示用户最近在模型部件上选择的点的 3D 坐标。绑定全部三个变量即可重建所选点。

样式

颜色字段接受 CSS 颜色值。 样式 部分通过以下设置控制默认场景外观：

  • 回退颜色： 未指定颜色的部件所使用的颜色。若为某个模型指定了专属回退颜色，则该模型将优先使用该颜色。
  • 背景颜色： 3D 视口的背景颜色。

界面

默认情况下，所有选项均处于开启状态。 界面 部分控制哪些界面元素可用：

  • 显示侧边栏、 显示工具栏和 显示方位控制器： 控制场景树侧边栏、顶部工具栏和方位控制器的可见性。
  • 启用上下文菜单： 允许用户在部件上打开上下文菜单。
  • 默认展开侧边栏： 在小部件首次加载时打开侧边栏。

场景

默认情况下，Vulcan 使用完整模式、正交相机和轨道控制器。模式切换和零件信息功能均已开启；自动旋转已关闭。“ 场景 ”部分用于控制 Vulcan 呈现和导航模型的方式，具体设置如下：

  • 默认模式： 初始场景模式。
    • 完整： 显示装配后的模型和完整场景树。
    • 网格： 显示由唯一零件组成的可排序网格。
    • 组件： 聚焦于所选组件。
  • 启用模式切换： 显示用于切换场景模式的控件。
  • 相机模式： 使用 正交 或 透视 相机。
  • 控制器模式： 使用 轨道 或 轨迹球 相机控制器。
  • 启用场景自动旋转： 自动旋转场景。
  • 完整模式配置 > 选中时显示零件信息： 在完整模式下，用户选择零件时会显示零件信息。

工具

“ 工具 ”部分允许您隐藏模块不需要的功能。默认情况下，所有设置均处于开启状态。关闭某个设置，即可从嵌入式小组件中移除该工具的控件。每个工具的详细说明请参阅“ 工具 ”页面。

设置功能
启用标注工具在模型零件上创建标注。
启用网格样式工具针对单个网格的外观控件。
启用测量工具模型上各点之间的距离测量。
启用剖视图工具使用剖切平面生成模型剖面。
启用转换工具重新定位零件和装配体。
启用场景着色工具基于属性或函数为零件着色。

操作

该 操作 部分指定了哪些本体论操作会保存用户创建的内容。使用 注释操作、 测量操作和 剖切面操作 来为每种内容类型选择相应的操作。

如果您未配置操作，Vulcan 会发现具有所需参数类型类的操作，并让用户从匹配项中进行选择。配置操作后，保存将仅限于该操作，并可为其他操作参数提供默认值或用户输入字段。Vulcan 会提供 操作类型中列出的特定于工具的值。

输出

当配置了至少一个输出时，用户可以在测量工具中选择要将哪个测量结果发送到 Workshop。该 输出 部分通过以下设置将选定的测量结果发送到 Workshop 变量：

  • 测量场景距离： 以模型的场景单位表示的总测量距离数值。
  • 测量单位距离： 同一距离的格式化字符串，以用户选择的显示单位表示，例如 12.30 mm。如果模型没有可识别的单位，输出将使用 units。
