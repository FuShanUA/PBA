部署自定义 widget

部署 widget set 不同于 部署应用程序。widget 不需要应用程序专属的子域名,也不使用 Developer Console 应用程序。相反,Pilot 会将您的 widget 以版本化发布的形式发布到 Widget Registry,您可以将其嵌入到 Workshop 应用程序中。

实现本体论实体

如果您的 widget 仅引用已部署本体论中已有的实体,则可以跳过此步骤。

如果 Pilot 在构建您的 widget 时提出了新增或修改的本体论实体,请先使用 Global Branching 将其提升 Main 。请参阅 实现本体论实体。

打标签并发布

在 Deploy 视图中,打上发布标签,即可发布 widget set 的新版本。打标签会触发 Foundry CI 构建 widget set 并将该版本发布到 Widget Registry。有关底层的发布机制以及版本的计算方式,请参阅 发布 widget set。

发布新版本不会改变 widget 的现有使用情况。Workshop 应用程序将继续使用其配置时所用的版本,直到您将其更新为新版本。

在 Workshop 中嵌入 widget

小部件集发布后，将该小部件添加到 Workshop 应用程序中，并配置其参数和事件。请参阅 在 Workshop 中嵌入小部件.

发布更新

要交付更改，请继续在 Editor 视图中进行迭代，然后返回 Deploy 视图并标记新版本。新版本将发布到 Widget Registry，您可以更新 Workshop 应用程序以使用新版本。
