代码函数时间序列

代码函数时间序列卡片会绘制由 Python 函数返回的时间序列图。要返回时间序列，您必须返回一个 list[bytes] ，并将其格式化为 时间序列。

  • 从 选择函数... 下拉菜单中选择一个函数，该菜单位于屏幕右侧的卡片编辑器中。
  • 完成选择后，函数的输入项将显示在下方。请根据需要填写各输入项。
  • 启用 自动更新 选项，以便分析始终使用函数的最新版本。默认情况下，函数版本将设置为创建时可用的最新版本。您可以通过下拉菜单手动更改版本。

目前不支持分类时间序列输出。

输入类型

对象集、单个对象、数字、字符串、时间、布尔值、数字数组、字符串数组、时间数组、布尔值数组

输出类型

时间序列
